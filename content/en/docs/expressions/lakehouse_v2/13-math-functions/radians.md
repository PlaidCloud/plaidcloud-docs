---
title: RADIANS
---

Converts degrees to radians.

## Analyze Syntax

```python
func.radians(<x>)
```

## Analyze Examples

```python
func.radians(180)

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## SQL Syntax

```sql
RADIANS(<x>)
```

## SQL Examples

```sql
SELECT RADIANS(180);

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
