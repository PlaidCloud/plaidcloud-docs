---
title: POWER
---

Returns a number raised to the power of another number. Alias for `POW`.

## Analyze Syntax

```python
func.power(<x>, <y>)
```

## Analyze Examples

```python
func.power(2, 10)

┌────────┐
│ 1024.0  │
└────────┘
```

## SQL Syntax

```sql
POWER(<x>, <y>)
```

## SQL Examples

```sql
SELECT POWER(2, 10);

┌────────┐
│ 1024.0  │
└────────┘
```
