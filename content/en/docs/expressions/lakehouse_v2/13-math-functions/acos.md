---
title: ACOS
---

Returns the arc cosine of a number in radians.

## Analyze Syntax

```python
func.acos(<x>)
```

## Analyze Examples

```python
func.acos(0.5)

┌────────────────────┐
│ 1.0471975511965976  │
└────────────────────┘
```

## SQL Syntax

```sql
ACOS(<x>)
```

## SQL Examples

```sql
SELECT ACOS(0.5);

┌────────────────────┐
│ 1.0471975511965976  │
└────────────────────┘
```
