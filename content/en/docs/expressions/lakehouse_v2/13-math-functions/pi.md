---
title: PI
---

Returns the mathematical constant pi.

## Analyze Syntax

```python
func.pi()
```

## Analyze Examples

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## SQL Syntax

```sql
PI()
```

## SQL Examples

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
