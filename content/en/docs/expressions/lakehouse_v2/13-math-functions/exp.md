---
title: EXP
---

Returns e raised to the power of a number.

## Analyze Syntax

```python
func.exp(<x>)
```

## Analyze Examples

```python
func.exp(1)

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## SQL Syntax

```sql
EXP(<x>)
```

## SQL Examples

```sql
SELECT EXP(1);

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
