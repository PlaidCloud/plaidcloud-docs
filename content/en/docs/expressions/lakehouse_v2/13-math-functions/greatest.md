---
title: GREATEST
---

Returns the greatest value from a list of values.

## Analyze Syntax

```python
func.greatest(<val1>, <val2>[, ...])
```

## Analyze Examples

```python
func.greatest(3, 7, 1, 9, 4)

┌───┐
│ 9  │
└───┘
```

## SQL Syntax

```sql
GREATEST(<val1>, <val2>[, ...])
```

## SQL Examples

```sql
SELECT GREATEST(3, 7, 1, 9, 4);

┌───┐
│ 9  │
└───┘
```
