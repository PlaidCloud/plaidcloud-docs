Returns the tangent of a number in radians.

## Analyze Syntax

```python
func.tan(<x>)
```

## Analyze Examples

```python
func.tan(0)

┌─────┐
│ 0.0  │
└─────┘
```

## SQL Syntax

```sql
TAN(<x>)
```

## SQL Examples

```sql
SELECT TAN(0);

┌─────┐
│ 0.0  │
└─────┘
```
