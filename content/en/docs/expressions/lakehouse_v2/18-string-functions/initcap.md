---
title: INITCAP
---

Capitalizes the first letter of each word in a string.

## Analyze Syntax

```python
func.initcap(<str>)
```

## Analyze Examples

```python
func.initcap('hello world')

┌───────────────┐
│ 'Hello World'  │
└───────────────┘
```

## SQL Syntax

```sql
INITCAP(<str>)
```

## SQL Examples

```sql
SELECT INITCAP('hello world');

┌─────────────┐
│ Hello World  │
└─────────────┘
```
