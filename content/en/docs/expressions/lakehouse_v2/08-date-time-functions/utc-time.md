---
title: UTC_TIME
---

Returns the current UTC time.

## Analyze Syntax

```python
func.utc_time()
```

## Analyze Examples

```python
func.utc_time()

┌────────────┐
│ '18:30:00'  │
└────────────┘
```

## SQL Syntax

```sql
UTC_TIME()
```

## SQL Examples

```sql
SELECT UTC_TIME();

┌──────────┐
│ 18:30:00  │
└──────────┘
```
