---
title: DAYOFWEEK
---

Returns the day of the week index for a date (1=Sunday, 7=Saturday).

## Analyze Syntax

```python
func.dayofweek(<date>)
```

## Analyze Examples

```python
func.dayofweek('2024-06-15')

┌───┐
│ 7  │
└───┘
```

## SQL Syntax

```sql
DAYOFWEEK(<date>)
```

## SQL Examples

```sql
SELECT DAYOFWEEK('2024-06-15');

┌───┐
│ 7  │
└───┘
```
