---
title: BITAND
---

Returns the bitwise AND of two numeric values.

## Analyze Syntax

```python
func.bitand(<x>, <y>)
```

## Analyze Examples

```python
func.bitand(12, 10)

┌───┐
│ 8  │
└───┘
```

## SQL Syntax

```sql
BITAND(<x>, <y>)
```

## SQL Examples

```sql
SELECT BITAND(12, 10);

┌───┐
│ 8  │
└───┘
```
