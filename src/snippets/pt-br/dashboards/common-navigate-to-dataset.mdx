## Navegar até um conjunto de dados
Para visualizar e editar métricas e expressões calculadas, siga estas etapas:
1.  Faça login em plaidcloud.com e navegue até os painéis
2.  Em visualize.plaidcloud.com, navegue até Data > Datasets
3.  Pesquise um conjunto de dados para visualizar ou modificar
4.  Modifique o conjunto de dados passando o mouse sobre o botão `edit` abaixo de `Actions`
