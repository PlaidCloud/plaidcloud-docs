### Seletor de arquivo de importação

O seletor de arquivo desta transformação permite escolher um arquivo armazenado em um local de documentos do PlaidCloud para importação.

Você também pode escolher um diretório para importar, e todos os arquivos dentro dele serão importados como parte da execução da transformação.

<Aside type="caution">Ao escolher um diretório para importar, verifique se todos os arquivos têm o mesmo formato</Aside>

#### Seleção de uma conta de documentos

Escolha uma conta de documentos do PlaidCloud à qual você tenha acesso. Isso permite selecionar um diretório ou arquivo na próxima seleção.

Dentro de um projeto, a lista também oferece **Project Default** no topo, que representa a conta definida atualmente como padrão do projeto. Uma nova etapa pré-seleciona Project Default quando o projeto tem uma conta padrão; uma etapa existente mantém a conta com a qual foi salva até você alterá-la. Uma etapa deixada em Project Default é executada na conta que for a padrão do projeto no momento da execução; se nenhuma estiver definida, a execução falha e informa o nome do projeto, em vez de recorrer a outra conta.

#### Opção de pesquisa

A opção **Pesquisar** permite encontrar todos os arquivos correspondentes abaixo de um caminho de diretório especificado para importação. Isso pode ser especialmente útil quando é preciso incluir muitos arquivos, mas eles estão armazenados em diretórios aninhados ou misturados com outros arquivos do mesmo diretório que você não quer importar.

<Aside>Usar uma convenção de nomenclatura comum para arquivos de tipo e finalidade semelhantes facilita o uso de uma única etapa de importação</Aside>

O caminho de pesquisa selecionado é o diretório inicial da busca. O processo de pesquisa procura todos os arquivos nesse diretório, bem como nos subdiretórios, que correspondam às condições de pesquisa especificadas. Verifique se os critérios de pesquisa também podem ser aplicados aos arquivos dos subdiretórios.

A pesquisa pode ser aplicada com as seguintes condições:
 * **Exata**: corresponde exatamente ao texto da pesquisa
 * **Começa com**: corresponde a qualquer arquivo que comece com o texto da pesquisa
 * **Contém**: corresponde a qualquer arquivo que contenha o texto da pesquisa
 * **Termina com**: corresponde a qualquer arquivo que termine com o texto da pesquisa

Um assistente de IA ou a API REST também pode definir a pesquisa como `glob`, um padrão com curinga como `CO Store*.yxdb` comparado com o nome completo do arquivo sem diferenciar maiúsculas de minúsculas, ou `regex`, uma expressão regular com a qual o nome completo do arquivo deve corresponder. Uma expressão regular diferencia maiúsculas de minúsculas, a menos que comece com `(?i)`.

#### Opção de seleção de arquivo ou diretório

Quando é necessário importar um arquivo ou diretório de arquivos específico, escolher o arquivo ou o diretório é uma opção melhor do que usar a pesquisa.

Para selecionar o arquivo ou o diretório, basta usar o botão de procura para escolher o caminho na conta de documentos selecionada acima.

#### Substituição de variáveis

Tanto na opção de pesquisa quanto na opção de arquivo ou diretório específico, é possível usar variáveis no caminho, no texto da pesquisa e nos nomes de arquivo.

Um exemplo que usa a variável `current_month` para apontar dinamicamente para o arquivo correto:

```
legal_entity/inputs/{current_month}/ledger_values.csv
```
