### Origem da tabela


Especifique a tabela de dados de origem selecionando-a no menu suspenso.

### Colunas de origem


Especifique aqui as colunas a serem incluídas. Ao selecionar os botões **Inspecionar origem** e **Populate Source Mapping Table**, essas colunas ficam disponíveis para a operação de junção.

### Selecionar subconjunto dos dados de origem


Qualquer expressão Python válida é aceita para obter um subconjunto dos dados. Consulte [Expressões](/pt-br/reference/expressions/) para mais detalhes e exemplos.
