O seletor de arquivos nesta transformação permite escolher um arquivo armazenado em um local de documentos do PlaidCloud para importar.

Você também pode escolher um diretório para importar, e todos os arquivos dentro dele serão importados como parte da execução da transformação.

<Aside type="caution">Ao escolher um diretório para importar, verifique se todos os arquivos têm o mesmo formato</Aside>

### Conta de Origem

Escolha uma conta de documentos do PlaidCloud à qual você tenha acesso. Isso permite selecionar um diretório ou arquivo na próxima seleção.

Dentro de um projeto, a lista também oferece **Padrão do projeto** no topo — um substituto para a conta que o projeto tiver definida como padrão no momento. Uma nova etapa já vem com Padrão do projeto selecionado quando o projeto tem um; uma etapa existente mantém a conta com a qual foi salva até você alterá-la. Uma etapa deixada em Padrão do projeto é executada com a conta que for o padrão do projeto no momento — se nenhuma estiver definida, a execução falha e cita o projeto, em vez de recorrer a outra conta.

#### Opção de Pesquisa

A opção **Pesquisar** permite encontrar todos os arquivos correspondentes abaixo de um caminho de diretório especificado para importar. Isso pode ser particularmente útil se muitos arquivos precisam ser
incluídos, mas estão armazenados em diretórios aninhados ou misturados a outros arquivos do mesmo diretório que você não quer importar.

<Aside>Usar uma convenção de nomenclatura comum para arquivos de tipo e finalidade semelhantes facilita o uso de uma única etapa de importação</Aside>

O caminho de pesquisa selecionado é o diretório inicial da busca. O processo de pesquisa procura todos os arquivos dentro desse diretório, bem como nos subdiretórios, que
correspondam às condições de pesquisa especificadas. Verifique se os critérios de pesquisa também podem ser aplicados aos arquivos dos subdiretórios.

A pesquisa pode ser aplicada usando as seguintes condições:
 * **Exata**: corresponde exatamente ao texto pesquisado
 * **Começa com**: corresponde a qualquer arquivo que comece com o texto pesquisado
 * **Contém**: corresponde a qualquer arquivo que contenha o texto pesquisado
 * **Termina com**: corresponde a qualquer arquivo que termine com o texto pesquisado

Um assistente de IA ou a API REST também pode definir a pesquisa como `glob`, um padrão com curinga como `CO Store*.yxdb` comparado com o nome completo do arquivo sem diferenciar maiúsculas de minúsculas, ou `regex`, uma expressão regular com a qual o nome completo do arquivo deve corresponder. Uma expressão regular diferencia maiúsculas de minúsculas, a menos que comece com `(?i)`.

### Caminho do Arquivo de Origem

Quando um arquivo ou diretório de arquivos específico é necessário para a importação, escolher o arquivo ou diretório é uma opção melhor do que usar a pesquisa.

Para selecionar o arquivo ou diretório, basta usar o botão de navegação para escolher o caminho da conta de documentos selecionada acima.

#### Substituição de Variáveis

Tanto na opção de pesquisa quanto na opção de arquivo/diretório específico, é possível usar variáveis no caminho, no texto de pesquisa e nos nomes de arquivo.

Um exemplo que usa a variável `current_month` para apontar dinamicamente para o arquivo correto:

```
legal_entity/inputs/{current_month}/ledger_values.csv

```
### Tabela de Destino

A seleção de destino para importações é limitada a tabelas, já que as visões não contêm os dados subjacentes.

#### Opção Dinâmica

A opção Dinâmica permite especificar uma tabela usando texto, inclusive variáveis. Isso é útil ao empregar
fluxos de trabalho orientados por variáveis, em que as referências a tabelas e visões são relativas às variáveis especificadas.

Um exemplo que usa a variável `current_month` para apontar dinamicamente para a tabela de destino:

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>Se a tabela não existir, ela será criada dinamicamente quando o processo de importação for executado</Aside>

#### Opção Estática

Quando uma tabela específica é desejada como destino da importação, deixe a caixa *Dinâmico* desmarcada e selecione a tabela de destino.

Se a tabela de destino não existir, selecione o botão *Criar novo* para criar a tabela no local desejado.

O Explorador de tabelas está sempre disponível em qualquer seleção de tabela. Clique no botão Explorador de tabelas à direita da seleção de tabela e uma janela do Explorador de tabelas será aberta.
