### Seletor de arquivo de exportação

![Seletor de arquivo de exportação](/images/export_file_source_target.png)

O seletor de arquivo desta transformação permite escolher um destino para armazenar o resultado exportado em um documento do PlaidCloud.

Você escolhe um diretório e especifica um nome de arquivo para o arquivo de destino.


### Tabela de origem


#### Opção dinâmica

A opção dinâmica permite especificar uma tabela por meio de texto, incluindo variáveis. Isso é útil ao usar fluxos de trabalho orientados por variáveis, nos quais as referências a tabelas e visões são relativas às variáveis especificadas.

Um exemplo que usa a variável `current_month` para apontar dinamicamente para a tabela de origem:

```
legal_entity/inputs/{current_month}/ledger_values
```

#### Opção estática

Quando você quiser uma tabela específica como origem da exportação, deixe a caixa *Dinâmico* desmarcada e selecione a tabela de origem.


O Explorador de tabelas está sempre disponível em qualquer seleção de tabela. Clique no botão Explorador de tabelas à direita da seleção de tabela e uma janela do Explorador de tabelas será aberta.



#### Seleção de uma conta de documentos

Escolha uma conta de documentos do PlaidCloud à qual você tenha acesso. Isso permite selecionar um diretório na próxima seleção.

Dentro de um projeto, a lista também oferece **Project Default** no topo, que representa a conta definida atualmente como padrão do projeto. Uma nova etapa pré-seleciona Project Default quando o projeto tem uma conta padrão; uma etapa existente mantém a conta com a qual foi salva até você alterá-la. Uma etapa deixada em Project Default é executada na conta que for a padrão do projeto no momento da execução; se nenhuma estiver definida, a execução falha e informa o nome do projeto, em vez de recorrer a outra conta.

#### Caminho do diretório de destino

Selecione o ícone ***Procurar*** à direita de ***Caminho do diretório de destino*** e navegue até o local onde você quer salvar o arquivo.

#### Nome do arquivo de destino

Especifique o nome com o qual o arquivo exportado deve ser salvo.
