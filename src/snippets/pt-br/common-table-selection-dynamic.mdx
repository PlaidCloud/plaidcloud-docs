## Seleção de tabelas


Há duas opções para selecionar a tabela ou, na segunda opção, as tabelas:

A primeira opção é usar a lista suspensa ***Tabela específica*** para selecionar a tabela.

A segunda é usar a opção ***Tabelas correspondentes à pesquisa***, na qual você especifica o **Caminho de pesquisa** e o **Texto da pesquisa** para selecionar a tabela ou as tabelas que correspondem aos critérios de pesquisa.
Essa opção é muito útil se você tem um fluxo de trabalho que cria uma série de tabelas com nomes em comum, salvas com a data anexada.
