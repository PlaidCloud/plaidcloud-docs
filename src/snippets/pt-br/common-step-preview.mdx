### Pré-visualização

Clique em **Pré-visualização** na guia **Origem** para ver até 100 linhas do que a etapa leria, sem executá-la. Se o resultado for mais longo, a pré-visualização informa que mostra as primeiras linhas e que você precisa executar a etapa para ler todas.

A pré-visualização preenche as variáveis do projeto e do fluxo de trabalho do mesmo modo que uma execução. Ela não oferece suporte a formatos de variável como `{x:>9}` e não consegue preencher uma variável que só tem valor durante uma execução, como um valor de gatilho.

A pré-visualização apenas lê dados. Ela recusa uma consulta que possa alterar qualquer coisa e mostra uma mensagem em vez de linhas:

- **A pré-visualização só oferece suporte a funções SQL padrão. Execute a etapa para ver os resultados.** A consulta usa uma função que a pré-visualização não consegue verificar como somente leitura. Execute a etapa para ver o resultado.
- Uma consulta que não seja um único `SELECT`, ou cujas variáveis se expandam para uma instrução que grava, é recusada.

A pré-visualização não está disponível em um projeto bloqueado, em conexões SQL Server, Oracle ou SQLite, nem para etapas executadas por meio de um agente, como a etapa [Agent Remote Execution of SQL](/pt-br/reference/workflow-steps/agent/agent-remote-execution-of-sql/).
