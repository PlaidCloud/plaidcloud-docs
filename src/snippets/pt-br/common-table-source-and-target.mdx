### Origem e Destino

![Origem e destino](/images/table_source_and_target_EN.png)

Para definir as tabelas de origem e de destino, primeiro selecione a tabela de dados da qual extrair usando o menu suspenso **Tabela de origem**. Em seguida, selecione uma tabela existente como tabela de destino usando o menu suspenso **Tabela de destino** ou clique no sinal verde **"+"** para criar uma nova tabela como destino. 

#### Criação de Tabela
Ao criar uma nova tabela, você pode criá-la como **Visão** ou como **Tabela**. 
##### Visões:
As visões são úteis porque o tempo necessário para executar uma etapa é significativamente menor do que quando se usa uma tabela. A desvantagem das visões é que elas não são úteis para a exploração de dados no modo Detalhes da tabela.

##### Tabelas:
Ao usar uma tabela como destino, a etapa leva mais tempo para ser executada, mas a exploração de dados no modo Detalhes é muito mais rápida do que com uma visão.

<Aside>Use tabelas nas etapas principais dos seus fluxos de trabalho em que a validação de dados ou a capacidade de realizar análises ad hoc forem necessárias. Para todas as outras etapas, use visões para reduzir o tempo total de cálculo do fluxo de trabalho. É possível mudar uma tabela para visão e vice-versa, de modo que você sempre pode alterar o tipo da tabela de destino mais tarde.</Aside>
