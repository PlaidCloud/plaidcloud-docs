### Tabela de destino

![Tabela de destino](/images/table_target_table.png)

Para definir a tabela de destino, selecione uma tabela existente na lista suspensa **Tabela de destino** ou clique no sinal verde **"+"** para criar uma nova tabela como destino.

#### Criação de tabela
Ao criar uma nova tabela, você pode criá-la como **Visão** ou como **Tabela**.
##### Visões:
As visões são úteis porque o tempo necessário para executar uma etapa é bem menor do que quando se usa uma tabela. A desvantagem das visões é que elas não são úteis para explorar dados no modo Detalhes da tabela.

##### Tabelas:
Ao usar uma tabela como destino, a etapa leva mais tempo para ser executada, mas a exploração de dados no modo Detalhes é muito mais rápida do que com uma visão.

<Aside>Use tabelas nas etapas principais dos seus fluxos de trabalho, em que a validação de dados ou a capacidade de fazer análises ad hoc será necessária. Nas demais etapas, use visões para reduzir o tempo total de cálculo do fluxo de trabalho. É possível alterar uma tabela para visão e vice-versa, de modo que você sempre pode atualizar o tipo de destino da tabela mais tarde.</Aside>
