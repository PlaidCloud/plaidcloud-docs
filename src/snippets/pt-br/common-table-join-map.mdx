Especifique as condições de junção. **Detectar** preenche o **Join Map** com a primeira destas opções que as colunas das duas tabelas permitirem:

- as chaves de outra etapa de junção deste projeto que une as mesmas duas tabelas
- as chaves de uma métrica aprovada que as une
- as colunas-chave definidas em uma das tabelas, correspondidas na outra por nome ou, na falta disso, pela única coluna vinculada ao mesmo [elemento do projeto](/pt-br/guides/projects/data-model/)
- os elementos para os quais as duas tabelas têm uma coluna, como descrito abaixo
- as colunas com o mesmo nome em **Table 1** e **Table 2**
- colunas cujos nomes diferem apenas em maiúsculas ou sublinhados, ou uma coluna `id` correspondida a uma coluna com o nome da própria tabela, como `customer_id` para uma tabela chamada *Customers*

Uma linha abaixo do mapa informa qual delas foi usada, até você alterar o mapa. Detectar lê as colunas das tabelas, não as linhas, portanto verifique as chaves antes de salvar. **Inspecionar origem** preenche um **Join Map** vazio da mesma forma.

**Chaves de elementos compartilhados.** Uma coluna pertence a um elemento quando o nome dela é o nome do elemento ou um dos aliases dele. Para cada elemento para o qual as duas tabelas têm uma coluna, **Detectar** une a única coluna de cada lado, mesmo quando os nomes diferem. Quando uma tabela tem várias colunas para o elemento, **Detectar** une aquela cujo nome as duas tabelas têm e, caso contrário, deixa esse elemento de fora. Duas colunas cujos tipos são de naturezas diferentes, como texto e data, não são unidas. Quando exatamente uma das tabelas tem o nome de um elemento compartilhado, a junção é feita somente por esse elemento. Uma tabela tem o nome de um elemento quando o nome dela, sem considerar maiúsculas, é o nome do elemento, esse nome com um `s`, ou qualquer um dos dois depois de uma única palavra e um sublinhado, como `customer`, `customers` ou `dim_customer`. Um nome mais longo, como `sales_by_customer`, não conta, nem um cuja primeira palavra seja ela própria um elemento, como `customer_product`. A linha abaixo do mapa nomeia os elementos, como *Estas chaves são os elementos que as duas tabelas compartilham: customer, period.* Quando nenhum elemento dá um par, **Detectar** passa para as colunas com o mesmo nome.

A detecção por elemento tem dois limites:

- Ela une apenas colunas que pertencem a um elemento e não acrescenta colunas de mesmo nome ao lado delas. Quando a chave de uma tabela são várias colunas e algumas não são elementos, como as de um calendário fiscal, **Detectar** propõe apenas as colunas de elemento; adicione as outras você mesmo.
- Uma tabela cujo nome é uma palavra e um sublinhado antes do nome de um elemento é considerada a tabela própria desse elemento mesmo quando não é, como `ar_customer` ou `bank_account`, de modo que, quando ela é a única tabela nomeada para um elemento compartilhado, a junção é proposta somente por esse elemento.

**Elementos no mapa.** Cada coluna do mapa de junção que pertence a um elemento mostra o nome do elemento como uma etiqueta ao lado dela. Passe o mouse sobre a etiqueta para ver o elemento, a descrição dele e a dimensão que ele fornece. As observações abaixo do mapa orientam você, mas nunca impedem que você salve a etapa:

- Uma linha que une colunas de dois elementos diferentes recebe uma observação, como *A linha 2 combina elementos diferentes: customer e vendor.*
- Quando **Detectar** não encontra chaves, a observação *Nenhuma chave provável encontrada.* tem um link **Modelo de dados** que abre a página [Modelo de dados](/pt-br/guides/projects/data-model/) do projeto, onde você pode descrever como elementos as colunas que as suas tabelas compartilham.

Para adicionar colunas manualmente, clique com o botão direito em qualquer parte da seção e selecione **Inserir linha** ou **Anexar linha**, para adicionar uma linha antes da linha selecionada ou no final, respectivamente. Depois, digite os nomes das colunas a serem correspondidas de **Table 1** para **Table 2**. Para remover um campo do **Join Map**, basta clicar com o botão direito e selecionar **Excluir**.
