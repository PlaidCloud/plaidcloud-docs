Especifique as condições de junção. **Detectar** preenche o **Join Map** com a primeira destas opções que as colunas das duas tabelas permitirem:

- as chaves de outra etapa de junção deste projeto que une as mesmas duas tabelas
- as chaves de uma métrica aprovada que as une
- as colunas-chave definidas em uma das tabelas, correspondidas por nome na outra
- as colunas com o mesmo nome em **Table 1** e **Table 2**
- colunas cujos nomes diferem apenas em maiúsculas ou sublinhados, ou uma coluna `id` correspondida a uma coluna com o nome da própria tabela, como `customer_id` para uma tabela chamada *Customers*

Uma linha abaixo do mapa informa qual delas foi usada, até você alterar o mapa. Detectar lê as colunas das tabelas, não as linhas, portanto verifique as chaves antes de salvar. **Inspecionar origem** preenche um **Join Map** vazio da mesma forma.

Para adicionar colunas manualmente, clique com o botão direito em qualquer parte da seção e selecione **Inserir linha** ou **Anexar linha**, para adicionar uma linha antes da linha selecionada ou no final, respectivamente. Depois, digite os nomes das colunas a serem correspondidas de **Table 1** para **Table 2**. Para remover um campo do **Join Map**, basta clicar com o botão direito e selecionar **Excluir**.
