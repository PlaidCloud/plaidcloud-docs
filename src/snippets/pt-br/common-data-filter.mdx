Para oferecer o máximo de flexibilidade, há filtros de dados tanto nos dados de origem quanto nos dados de destino. Em conjuntos de dados maiores, filtrar linhas na origem pode ser especialmente vantajoso, pois as demais operações são executadas sobre um conjunto de dados menor.

#### Selecionar subconjunto de dados

Este tipo de filtro permite filtrar os dados de origem de entrada com base nas condições especificadas.

#### Aplicar filtro secundário aos dados de resultado

Este tipo de filtro permite aplicar um filtro aos dados de resultado já transformados, com base nas condições especificadas.
Aplicar um filtro ao resultado transformado permite fazer exclusões com base em resultados de cálculos complexos, sumarizações ou funções de janela.

#### Divisão final da tabela de dados (limite)

O recurso de divisão de linhas permite limitar as linhas do conjunto de resultados com base em um intervalo e um ponto de partida.

<Aside>Para manter a consistência, os resultados divididos devem ter uma ordenação especificada</Aside>

#### Sintaxe de filtro

A sintaxe de filtro usa o [Python SQLAlchemy](https://www.sqlalchemy.org), a mesma sintaxe das outras expressões.

Veja exemplos e funções de expressão na área [Expressões](/pt-br/reference/expressions/).
