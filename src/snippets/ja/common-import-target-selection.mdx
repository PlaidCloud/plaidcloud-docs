### ターゲットテーブル

ビューには基になるデータが含まれないため、インポートのターゲットとして選択できるのはテーブルのみです。

#### Dynamic オプション

Dynamic オプションでは、変数を含むテキストでテーブルを指定できます。テーブルやビューの参照が指定した変数に応じて決まる、変数駆動型のワークフローで便利です。

`current_month` 変数を使用して、ターゲットテーブルを動的に指定する例:

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>テーブルが存在しない場合は、インポートの実行時に動的に作成されます</Aside>

#### Static オプション

インポートのターゲットとして特定のテーブルを使用する場合は、*Dynamic* ボックスをオフのままにして、ターゲットテーブルを選択します。

ターゲットテーブルが存在しない場合は、*新規作成*ボタンを選択して、目的の場所にテーブルを作成します。

テーブルエクスプローラーは、どのテーブル選択でも常に利用できます。テーブル選択の右側にあるテーブルエクスプローラーボタンをクリックすると、テーブルエクスプローラーのウィンドウが開きます。
