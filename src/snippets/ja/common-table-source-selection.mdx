### テーブルソース


ドロップダウンメニューからソースデータテーブルを選択して指定します。

### ソース列


含める列をここで指定します。**ソースを検査**ボタンと**ソースマッピングテーブルを入力**ボタンを選択すると、これらの列を結合操作で使用できるようになります。

### ソースデータのサブセットの選択


データのサブセットを指定するには、有効な Python 式を使用できます。詳細と例については、[式](/ja/reference/expressions/)を参照してください。
