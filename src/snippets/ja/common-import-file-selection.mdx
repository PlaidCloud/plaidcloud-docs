### インポートファイルセレクター

このトランスフォームのファイルセレクターでは、インポート対象として、PlaidCloud のドキュメントの場所に保存されているファイルを選択できます。

ディレクトリを選択してインポートすることもできます。その場合、ディレクトリ内のすべてのファイルが、トランスフォームの実行の一部としてインポートされます。

<Aside type="caution">インポートするディレクトリを選択する場合は、すべてのファイルの形式が同じであることを確認してください</Aside>

#### ドキュメントアカウントの選択

アクセス権のある PlaidCloud のドキュメントアカウントを選択します。これにより、次の選択でディレクトリまたはファイルを選択できるようになります。

プロジェクト内では、リストの先頭に **Project Default** も表示されます。これは、プロジェクトに現在デフォルトとして設定されているアカウントの代わりとなる項目です。プロジェクトにデフォルトのアカウントがある場合、新しいステップでは Project Default が事前に選択されます。既存のステップは、変更するまで、すでに保存されているアカウントのままです。Project Default のままのステップは、実行時にプロジェクトのデフォルトであるアカウントに対して実行されます。デフォルトが設定されていない場合は、別のアカウントにフォールバックせず、実行が失敗し、プロジェクト名が示されます。

#### 検索オプション

**検索**オプションを使用すると、指定したディレクトリパス以下で一致するすべてのファイルを検索してインポートできます。多数のファイルを含める必要があるものの、それらがネストされたディレクトリに保存されている場合や、インポートしたくない他のファイルと同じディレクトリ内に混在している場合に、特に便利です。

<Aside>同じ種類や目的のファイルに共通の命名規則を使用すると、単一のインポートステップで扱いやすくなります</Aside>

選択した検索パスは、検索を開始するディレクトリです。検索処理では、そのディレクトリ内のすべてのファイルと、指定した検索条件に一致するサブディレクトリ内のファイルが検索されます。検索条件がサブディレクトリ内のファイルにも適用できることを確認してください。

検索には、次の条件を使用できます。
 * **完全一致**: 検索テキストと完全に一致するものを対象にします
 * **次で始まる**: 検索テキストで始まるファイルすべてを対象にします
 * **含む**: 検索テキストを含むファイルすべてを対象にします
 * **次で終わる**: 検索テキストで終わるファイルすべてを対象にします

AI エージェントまたは REST API では、検索を `glob`（`CO Store*.yxdb` のようなワイルドカードパターンで、大文字と小文字を区別せずファイル名全体と照合）または `regex`（ファイル名全体が一致する必要がある正規表現）に設定することもできます。正規表現は、`(?i)` で始まらない限り、大文字と小文字が区別されます。

#### ファイルまたはディレクトリの選択オプション

インポートするファイルまたはディレクトリが決まっている場合は、検索よりも、ファイルまたはディレクトリを直接選択する方法が適しています。

ファイルまたはディレクトリを選択するには、参照ボタンを使用して、上で選択したドキュメントアカウントのパスを選びます。

#### 変数の置換

検索オプションと、特定のファイル/ディレクトリを指定するオプションのどちらでも、パス、検索テキスト、ファイル名に変数を使用できます。

`current_month` 変数を使用して、正しいファイルを動的に指すようにした例:

```
legal_entity/inputs/{current_month}/ledger_values.csv
```
