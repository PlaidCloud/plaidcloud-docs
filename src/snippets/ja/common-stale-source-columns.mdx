**Join Map** または**ターゲット出力列**の行には、ステップの**ソース列**タブにもう一覧表示されていない列の名前が含まれていることがあります。たとえば、ソースの列を再度検査した後などです。ステップがそのような行を自動的に削除することはありません。代わりに、列名が ⚠ 警告マークの後ろに赤で表示され、カーソルを合わせると、どのソースのリストにその列がないかが表示されます。

**定数**、**式**、**件数 (NULLを含む)** の集計を持つターゲット出力列の行は、ステップがその行のソース列を読み取らないため、フラグ付けされることはありません。一度も検査されていないソースなど、リストが空のソースに対しては何も確認されません。

フラグ付けされた行が残ったままステップを保存すると、**古い列が見つかりました**ダイアログにテーブルごとに一覧表示され、次の3つの選択肢が表示されます。

- **すべて削除して保存** — フラグ付けされた行を削除してから保存します。
- **このまま保存** — ステップをそのまま保存します。
- **キャンセル** — 保存せずにステップに戻ります。

行を残したまま警告を解除するには、その列を**ソース列**タブのそのソースのリストに戻すか、リストに含まれる列を選択します。

保存時には、各ソーステーブルの現在の状態も確認されます。ソースのリストにあるものの、そのテーブルにはない列がある場合、**不足しているソース列**ダイアログが開き、テーブルと列が表示され、**このまま保存**または**キャンセル**を選択できます。行もフラグ付けされている場合は、両方が**古い列が見つかりました**ダイアログにまとめて表示されます。[ソーステーブルに存在しない列](/ja/reference/workflow-steps/tables/table-extract/#ソーステーブルに存在しない列)を参照してください。
