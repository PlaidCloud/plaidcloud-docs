#### ステップの実行時

Table Extract、Table Lookup、Table Inner Join、Table Cross Join、Table Outer Join、Table Anti Join、複数テーブル結合、Table Union Distinct、Table Union All、Table Pivot、Table Melt、Table In-Place Delete、Table Upsert、Table Append の各ステップは、実行時、何かを書き込む前に、ソーステーブルを確認します。この確認では、ステップが構築したクエリを、その時点の各ソーステーブルと照合します。

- ステップが読み取る列がテーブルにない場合、テーブルにない、またはステップのソース列にない結合キーがある場合、またはステップが読み取るソーステーブルが構築されていない場合、ステップは停止します。1つのエラーにすべての問題がそれぞれの修正方法とともに示されます。既存のターゲットテーブルは元の状態のまま残り、ステップが作成する必要があったターゲットテーブルは空のままになります。
- ステップが一覧に載せているが読み取らない列がテーブルにもうない場合は、警告が追加されます。ステップはその列なしで実行されます。
- Table Union Distinct と Table Union All は、構築されていないソーステーブルについては例外です。従来どおり、そのテーブルを警告なしで除外し、残りのテーブルをまとめます。ソーステーブルが1つも構築されていない場合は、失敗せずに警告を出して終了します。

ターゲットがビューであるステップはビューを作成するだけなので、一覧に載せている列と結合キーは、ウェアハウスがそのビューの作成を拒否する場合にのみ、そのテーブルと照合して確認されます。それ以外の場合は、構築されていないソーステーブル、またはステップの一覧にない結合キーがある場合にのみステップが停止し、警告は追加されません。

可能な場合、エラーにはテーブルを構築するステップが示され、テーブルに不足している列と名前が近い列（大文字小文字だけが異なる列など）がある場合は、その列も示されます。
