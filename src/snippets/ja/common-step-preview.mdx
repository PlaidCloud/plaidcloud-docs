### プレビュー

**ソース**タブで**プレビュー**をクリックすると、ステップが読み取る内容の最大100行を、実行せずに確認できます。結果がそれより長い場合、プレビューには最初の行のみが表示されていること、すべてを読み取るにはステップを実行する必要があることが表示されます。

プレビューは、実行時と同じ方法で、プロジェクト変数とワークフロー変数を埋め込みます。`{x:>9}`のような変数の書式指定には対応していません。また、トリガーの値のように、実行中にのみ値を持つ変数は埋め込めません。

プレビューはデータの読み取りのみを行います。何かを変更する可能性のあるクエリは拒否し、行の代わりにメッセージを表示します。

- **Preview only supports standard SQL functions. Run the step to see results.** クエリで、プレビューが読み取り専用かどうかをチェックできない関数が使用されています。結果を確認するには、ステップを実行してください。
- 単一の`SELECT`ではないクエリ、または変数が展開された結果として書き込みを行うステートメントになるクエリは、拒否されます。

プレビューは、ロックされたプロジェクト、SQL Server、Oracle、SQLiteの接続、および[Agent Remote Execution of SQL ステップ](/ja/reference/workflow-steps/agent/agent-remote-execution-of-sql/)のようにエージェント経由で実行されるステップでは利用できません。
