### エクスポートファイルセレクター

![エクスポートファイルセレクター](/images/export_file_source_target.png)

この変換のファイルセレクターでは、エクスポート結果を保存する PlaidCloud ドキュメントの保存先を選択できます。

ディレクトリを選択し、ターゲットファイルのファイル名を指定します。


### ソーステーブル


#### Dynamic オプション

Dynamic オプションでは、変数を含むテキストでテーブルを指定できます。テーブルやビューの参照が指定した変数に応じて決まる、変数駆動型のワークフローで便利です。

`current_month` 変数を使用して、ソーステーブルを動的に指定する例:

```
legal_entity/inputs/{current_month}/ledger_values
```

#### Static オプション

エクスポートのソースとして特定のテーブルを使用する場合は、*Dynamic* ボックスをオフのままにして、ソーステーブルを選択します。


テーブルエクスプローラーは、どのテーブル選択でも常に利用できます。テーブル選択の右側にあるテーブルエクスプローラーボタンをクリックすると、テーブルエクスプローラーのウィンドウが開きます。



#### ドキュメントアカウントの選択

アクセス権のある PlaidCloud ドキュメントアカウントを選択します。これにより、次の選択でディレクトリを選択できるようになります。

プロジェクト内では、リストの先頭に **Project Default** も表示されます。これは、プロジェクトで現在デフォルトに設定されているアカウントの代わりとなる項目です。プロジェクトにデフォルトがある場合、新しいステップでは Project Default が事前に選択されます。既存のステップは、変更するまで保存時のアカウントのままです。Project Default のままにしたステップは、実行時にプロジェクトのデフォルトになっているアカウントに対して実行されます。デフォルトが設定されていない場合は、他のアカウントにフォールバックせず、実行は失敗し、プロジェクトが示されます。

#### ターゲットディレクトリパス

**ターゲットディレクトリパス**の右側にある***参照***アイコンを選択し、ファイルの保存先に移動します。

#### ターゲットファイル名

エクスポートするファイルを保存する名前を指定します。
