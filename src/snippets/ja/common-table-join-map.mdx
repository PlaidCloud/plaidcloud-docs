![テーブルの Join Map](/images/table_join_map.png)

結合条件を指定します。**自動判定**は、2つのテーブルの列が当てはまる次の項目のうち、最初のものを使って **Join Map** を入力します。

- 同じ2つのテーブルを結合する、このプロジェクト内の別の結合ステップのキー
- それらを結合する承認済みメトリックのキー
- 一方のテーブルに設定されたキー列と、もう一方のテーブル内で名前が一致する列
- **Table 1** と **Table 2** で同じ名前の列
- 大文字・小文字やアンダースコアだけが異なる名前の列、または `id` 列と、テーブル名に由来する名前の列（たとえば、*Customers* テーブルに対する `customer_id`）

マップを変更するまで、マップの下の1行にどれを使用したかが表示されます。自動判定はテーブルの行ではなく列を読み取るため、保存する前にキーを確認してください。**ソースを検査**でも、空の **Join Map** が同じ方法で入力されます。

列を手動で追加するには、セクション内の任意の場所を右クリックし、**行を挿入**または**行を追加**を選択します。それぞれ、現在選択している行の前、または末尾に行が追加されます。続いて、**Table 1** と **Table 2** で照合する列名を入力します。**Join Map** からフィールドを削除するには、右クリックして**削除**を選択します。
