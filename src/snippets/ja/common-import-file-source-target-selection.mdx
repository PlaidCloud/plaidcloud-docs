この変換のファイルセレクターでは、PlaidCloud のドキュメントの保存場所にあるファイルを選択してインポートできます。

ディレクトリを選択してインポートすることもできます。その場合、変換の実行時にそのディレクトリ内のすべてのファイルがインポートされます。

<Aside type="caution">ディレクトリを選択してインポートする場合は、すべてのファイルの形式が同じであることを確認してください</Aside>

### ソースアカウント

アクセス権のある PlaidCloud のドキュメントアカウントを選択します。これにより、次の選択でディレクトリやファイルを選べるようになります。

プロジェクト内では、一覧の先頭に **Project Default** も表示されます。これは、プロジェクトでその時点のデフォルトに設定されているアカウントを表すものです。プロジェクトにデフォルトのアカウントがある場合、新しいステップでは Project Default があらかじめ選択されます。既存のステップは、変更するまで保存済みのアカウントを使い続けます。Project Default のままのステップは、実行時にプロジェクトのデフォルトになっているアカウントに対して実行されます。デフォルトが設定されていない場合、別のアカウントに切り替えることはせず、プロジェクト名を示して実行が失敗します。

#### 検索オプション

**検索** オプションを使うと、指定したディレクトリパス以下で一致するすべてのファイルを見つけてインポートできます。多くのファイルを含める必要があるものの、それらがネストされたディレクトリに保存されている場合や、同じディレクトリ内にインポートしたくないほかのファイルと混在している場合に特に便利です。

<Aside>種類や用途が同じファイルに共通の命名規則を使うと、1 つのインポートステップで扱いやすくなります</Aside>

選択した検索パスが、検索を開始するディレクトリになります。検索処理では、そのディレクトリとサブディレクトリ内で、指定した検索条件に一致するすべてのファイルが検索されます。検索条件がサブディレクトリ内のファイルにも適用できることを確認してください。

検索には次の条件を使用できます。
 * **完全一致**: 検索テキストと完全に一致するファイル
 * **次で始まる**: 検索テキストで始まるファイル
 * **含む**: 検索テキストを含むファイル
 * **次で終わる**: 検索テキストで終わるファイル

AI アシスタントや REST API では、検索を `glob` (`CO Store*.yxdb` のようなワイルドカードパターンを、大文字と小文字を区別せずにファイル名全体と照合) や `regex` (ファイル名全体が一致する必要がある正規表現) に設定することもできます。正規表現は、`(?i)` で始まらない限り大文字と小文字を区別します。

### ソースファイルパス

特定のファイルやファイルを含むディレクトリをインポートする必要がある場合は、検索を使うよりもファイルやディレクトリを直接選択するほうが適しています。

ファイルまたはディレクトリを選択するには、参照ボタンを使って、上で選択したドキュメントアカウント内のパスを選びます。

#### 変数の置換

検索オプションと、特定のファイル/ディレクトリを指定するオプションのどちらでも、パス、検索テキスト、ファイル名に変数を使用できます。

`current_month` 変数を使って正しいファイルを動的に指定する例:

```
legal_entity/inputs/{current_month}/ledger_values.csv

```
### ターゲットテーブル

ビューには実データが含まれないため、インポートのターゲットに選択できるのはテーブルのみです。

#### 動的オプション

動的オプションでは、変数を含むテキストでテーブルを指定できます。テーブルやビューの参照が指定した変数によって決まる、変数駆動のワークフローを使う場合に便利です。

`current_month` 変数を使ってターゲットテーブルを動的に指定する例:

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>テーブルが存在しない場合は、インポート処理の実行時に動的に作成されます</Aside>

#### 静的オプション

特定のテーブルをインポートのターゲットにする場合は、*Dynamic* ボックスをオフのままにして、ターゲットのテーブルを選択します。

ターゲットのテーブルが存在しない場合は、*Create new table* ボタンを選択して、目的の場所にテーブルを作成します。

テーブルエクスプローラーは、どのテーブル選択でも常に使用できます。テーブル選択の右側にあるテーブルエクスプローラーボタンをクリックすると、テーブルエクスプローラーのウィンドウが開きます。
