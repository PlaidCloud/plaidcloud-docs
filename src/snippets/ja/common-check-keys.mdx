**自動判定**の隣にある**キーを確認**は、テーブルの複数の行に現れる **Join Map** のキー値を数えます。結合先のテーブルでキー値が繰り返されている場合、それに一致する各行が一致した行の数だけ結果に現れるため、結果の行数が元のテーブルより多くなることがあります。

どのテーブルが確認されるかは、ステップによって異なります。

- **内部結合**と **Table Lookup**: Table 2。
- **外部結合**: 左結合の場合は Table 2、右結合の場合は Table 1、完全結合の場合は両方のテーブル。

結果は **Join Map** の下に表示されます。繰り返されているキー値の数とそれらを共有する行数が示され、繰り返しの多い上位5件までが一覧表示されます。カウントの対象は次のとおりです。

- このステップでそのテーブルに適用されているフィルター適用後の、現在のテーブル
- 行レベルセキュリティによりテーブルの一部しか表示できない場合は、表示できる行のみ。結果にはその旨が表示されます
- キーが空白の行は対象外です。空白のキーは他の行と一致しないためです。ただし、Alteryxから変換された結合のように、空白のキー同士を一致させる設定の内部結合または外部結合は例外で、この場合は空白のキーも1つのキー値として数えられ、**(空白)** として一覧表示されることがあります。

**Table Lookup** は行を繰り返しません。繰り返されているキーについては Table 2 の1行を保持し、各列の最小値（最小の数値、最も早い日付、並べ替え順で最初のテキスト）を採用するため、その行には Table 2 の異なる行の値が混在することがあります。この場合、**キーを確認**がその旨をお知らせします。使用する値を自分で選ぶには、Table 2 の各キーが1回だけ現れるようにしてください。

このチェックはウェアハウス内のテーブルを読み取るため、選択したときにのみ実行され、30秒で停止します。いずれかのテーブル、そのフィルター、**Join Map**、または外部結合の場合は**結合タイプ**を変更すると、結果はクリアされます。
