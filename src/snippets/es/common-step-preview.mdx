### Vista previa

Haga clic en **Vista previa** en la pestaña **Origen** para ver hasta 100 filas de lo que leería el paso, sin ejecutarlo. Si el resultado es más largo, la vista previa indica que muestra las primeras filas y que debe ejecutar el paso para leerlas todas.

La vista previa rellena las variables del proyecto y del flujo de trabajo de la misma manera que una ejecución. No admite formatos de variable como `{x:>9}` y no puede rellenar una variable que solo tiene valor durante una ejecución, como un valor de activación.

La vista previa solo lee datos. Rechaza una consulta que pudiera cambiar algo y muestra un mensaje en lugar de filas:

- **La vista previa solo admite funciones SQL estándar. Ejecute el paso para ver los resultados.** La consulta usa una función que la vista previa no puede comprobar como de solo lectura. Ejecute el paso para ver el resultado.
- Se rechaza una consulta que no sea un único `SELECT`, o cuyas variables se expandan en una instrucción que escribe.

La vista previa no está disponible en un proyecto bloqueado, en conexiones de SQL Server, Oracle o SQLite, ni para los pasos que se ejecutan a través de un agente, como [Agent Remote Execution of SQL](/es/reference/workflow-steps/agent/agent-remote-execution-of-sql/).
