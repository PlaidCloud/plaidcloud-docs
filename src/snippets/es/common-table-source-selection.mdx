### Tabla de origen


Especifique la tabla de datos de origen seleccionándola en el menú desplegable.

### Columnas de origen


Especifique aquí las columnas que desea incluir. Al seleccionar los botones **Inspeccionar origen** y **Populate Source Mapping Table**, estas columnas quedarán disponibles para la operación de combinación.

### Seleccionar un subconjunto de los datos de origen


Se acepta cualquier expresión de Python válida para obtener un subconjunto de los datos. Consulte [Expresiones](/es/reference/expressions/) para obtener más detalles y ejemplos.
