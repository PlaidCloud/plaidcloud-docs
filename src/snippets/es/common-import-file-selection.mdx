### Selector de archivo de importación

El selector de archivo de esta transformación le permite elegir un archivo almacenado en una ubicación de documentos de PlaidCloud para importarlo.

También puede elegir un directorio para importar, y todos los archivos de ese directorio se importarán como parte de la ejecución de la transformación.

<Aside type="caution">Al elegir un directorio para importar, asegúrese de que todos los archivos tengan el mismo formato</Aside>

#### Selección de una cuenta de documentos

Elija una cuenta de documentos de PlaidCloud a la que tenga acceso. Esto le permitirá seleccionar un directorio o un archivo en la siguiente selección.

Dentro de un proyecto, la lista también ofrece **Project Default** en la parte superior: un sustituto de la cuenta que el proyecto tenga establecida como predeterminada en ese momento. Un paso nuevo preselecciona Project Default cuando el proyecto tiene una; un paso existente conserva la cuenta con la que se guardó hasta que usted la cambie. Un paso que se deja en Project Default se ejecuta con la cuenta que sea la predeterminada del proyecto en ese momento; si no hay ninguna establecida, la ejecución falla y nombra el proyecto en lugar de recurrir a otra cuenta.

#### Opción de búsqueda

La opción **Buscar** permite encontrar todos los archivos coincidentes por debajo de una ruta de directorio especificada para importarlos. Puede ser especialmente útil si hay que incluir muchos archivos, pero están almacenados en directorios anidados o mezclados con otros archivos del mismo directorio que no desea importar.

<Aside>Usar una convención de nomenclatura común para los archivos de tipo y finalidad similares facilita el uso de un único paso de importación</Aside>

La ruta de búsqueda seleccionada es el directorio inicial en el que se busca. El proceso de búsqueda examinará todos los archivos de ese directorio, así como de sus subdirectorios, que cumplan las condiciones de búsqueda especificadas. Asegúrese de que los criterios de búsqueda también puedan aplicarse a los archivos de los subdirectorios.

La búsqueda puede aplicarse con las siguientes condiciones:
 * **Exacto**: coincide exactamente con el texto de búsqueda
 * **Comienza por**: coincide con cualquier archivo que comience por el texto de búsqueda
 * **Contiene**: coincide con cualquier archivo que contenga el texto de búsqueda
 * **Termina en**: coincide con cualquier archivo que termine en el texto de búsqueda

Un asistente de IA o la API REST también pueden establecer la búsqueda en `glob`, un patrón con comodines como `CO Store*.yxdb` que se compara con el nombre completo del archivo sin distinguir mayúsculas de minúsculas, o en `regex`, una expresión regular con la que debe coincidir el nombre completo del archivo. Una expresión regular distingue mayúsculas de minúsculas, salvo que empiece por `(?i)`.

#### Opción de selección de archivo o directorio

Cuando se necesita importar un archivo concreto o un directorio de archivos, elegir el archivo o el directorio es una opción mejor que usar la búsqueda.

Para seleccionar el archivo o el directorio, use el botón Examinar para elegir la ruta de la cuenta de documentos seleccionada anteriormente.

#### Sustitución de variables

Tanto en la opción de búsqueda como en la de archivo o directorio concreto, se pueden usar variables en la ruta, el texto de búsqueda y los nombres de archivo.

Un ejemplo que usa la variable `current_month` para apuntar dinámicamente al archivo correcto:

```
legal_entity/inputs/{current_month}/ledger_values.csv
```
