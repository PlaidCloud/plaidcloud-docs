### Selector de archivo de exportación

![Selector de archivo de exportación](/images/export_file_source_target.png)

El selector de archivo de esta transformación le permite elegir un destino donde almacenar el resultado exportado en un documento de PlaidCloud.

Usted elige un directorio y especifica un nombre de archivo para el archivo de destino.


### Tabla de origen


#### Opción dinámica

La opción dinámica permite especificar una tabla mediante texto, incluidas variables. Esto resulta útil en flujos de trabajo controlados por variables, en los que las referencias a tablas y vistas son relativas a las variables especificadas.

Un ejemplo que usa la variable `current_month` para apuntar dinámicamente a la tabla de origen:

```
legal_entity/inputs/{current_month}/ledger_values
```

#### Opción estática

Cuando se desea una tabla concreta como origen de la exportación, deje sin marcar la casilla *Dinámico* y seleccione la tabla de origen.


El Explorador de tablas está siempre disponible con cualquier selección de tabla. Haga clic en el botón Explorador de tablas situado a la derecha de la selección de tabla y se abrirá una ventana del Explorador de tablas.



#### Selección de una cuenta de documentos

Elija una cuenta de documentos de PlaidCloud a la que tenga acceso. Esto le permitirá seleccionar un directorio en la siguiente selección.

Dentro de un proyecto, la lista también ofrece **Project Default** en la parte superior: un sustituto de la cuenta que el proyecto tenga establecida como predeterminada en ese momento. Un paso nuevo preselecciona Project Default cuando el proyecto tiene una; un paso existente conserva la cuenta con la que se guardó hasta que usted la cambie. Un paso que se deja en Project Default se ejecuta con la cuenta que sea la predeterminada del proyecto en ese momento; si no hay ninguna establecida, la ejecución falla y nombra el proyecto en lugar de recurrir a otra cuenta.

#### Ruta del directorio de destino

Seleccione el icono ***Examinar*** a la derecha de la ***Ruta del directorio de destino*** y navegue hasta la ubicación donde desea guardar el archivo.

#### Nombre del archivo de destino

Especifique el nombre con el que se debe guardar el archivo exportado.
