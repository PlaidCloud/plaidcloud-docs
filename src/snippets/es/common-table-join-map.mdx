Especifique las condiciones de combinación. **Detectar** rellena el **Join Map** con la primera de estas opciones que puedan aplicar las columnas de las dos tablas:

- las claves de otro paso de combinación de este proyecto que combina las mismas dos tablas
- las claves de una métrica aprobada que las combina
- las columnas de clave definidas en una de las tablas, emparejadas en la otra por nombre o, si no, por la única columna vinculada al mismo [elemento del proyecto](/es/guides/projects/data-model/)
- los elementos para los que ambas tablas tienen una columna, como se describe a continuación
- las columnas con el mismo nombre en la **Tabla 1** y la **Tabla 2**
- las columnas cuyos nombres solo difieren en mayúsculas o guiones bajos, o una columna `id` emparejada con una columna que lleva el nombre de su tabla, como `customer_id` para una tabla llamada *Customers*

Una línea bajo el mapa indica cuál se usó, hasta que usted cambie el mapa. Detectar lee las columnas de las tablas, no sus filas, así que revise las claves antes de guardar. **Inspeccionar origen** rellena un **Join Map** vacío de la misma manera.

**Claves a partir de elementos compartidos.** Una columna pertenece a un elemento cuando su nombre es el del elemento o uno de sus alias. Para cada elemento para el que ambas tablas tienen una columna, **Detectar** empareja la única columna de cada lado, aunque sus nombres difieran. Cuando una tabla tiene varias columnas para el elemento, **Detectar** empareja la que tiene el mismo nombre en ambas tablas y, si no, omite ese elemento. No se emparejan dos columnas cuyos tipos son de clases distintas, como texto y fecha. Cuando exactamente una de las tablas lleva el nombre de un elemento compartido, la combinación se hace solo por ese elemento. Una tabla lleva el nombre de un elemento cuando su nombre, sin tener en cuenta las mayúsculas, es el del elemento, ese nombre con una `s`, o cualquiera de los dos después de una sola palabra y un guion bajo, como `customer`, `customers` o `dim_customer`. Un nombre más largo, como `sales_by_customer`, no cuenta, ni tampoco uno cuya primera palabra es a su vez un elemento, como `customer_product`. La línea bajo el mapa indica los elementos, por ejemplo *Estas claves son los elementos que ambas tablas comparten: customer, period.* Cuando ningún elemento da un par, **Detectar** continúa con las columnas con el mismo nombre.

La detección por elementos tiene dos límites:

- Solo empareja columnas que pertenecen a un elemento y no agrega columnas con el mismo nombre junto a ellas. Cuando la clave de una tabla es de varias columnas y algunas no son elementos, como las de un calendario fiscal, **Detectar** propone solo las columnas de elementos; agregue las demás usted mismo.
- Una tabla cuyo nombre es una palabra y un guion bajo antes del nombre de un elemento se considera la tabla propia de ese elemento aunque no lo sea, como `ar_customer` o `bank_account`, por lo que, cuando es la única tabla nombrada para un elemento compartido, la combinación se propone solo por ese elemento.

**Elementos en el mapa.** Cada columna del mapa de combinación que pertenece a un elemento muestra junto a ella el nombre del elemento como una etiqueta. Pase el cursor sobre la etiqueta para ver el elemento, su descripción y la dimensión que aporta. Las notas bajo el mapa le avisan, pero nunca le impiden guardar el paso:

- Una fila que empareja columnas de dos elementos distintos recibe una nota, por ejemplo *La fila 2 empareja elementos distintos: customer y vendor.*
- Cuando **Detectar** no encuentra claves, la nota *No se encontraron claves probables.* incluye un enlace **Modelo de datos** que abre la página de [Modelo de datos](/es/guides/projects/data-model/) del proyecto, donde puede describir como elementos las columnas que comparten sus tablas.

Para agregar columnas adicionales manualmente, haga clic con el botón derecho en cualquier punto de la sección y seleccione **Insertar fila** o **Anexar fila**, para agregar una fila antes de la fila seleccionada o al final, respectivamente. Después, escriba los nombres de las columnas que se deben emparejar de la **Tabla 1** con la **Tabla 2**. Para quitar un campo del **Join Map**, haga clic con el botón derecho y seleccione **Eliminar**.
