#### Cuando se ejecuta el paso

Los pasos Table Extract, Table Lookup, Table Inner Join, Table Cross Join, Table Outer Join, Table Anti Join, Combinación de varias tablas, Table Union Distinct, Table Union All, Table Pivot, Table Melt, Table In-Place Delete, Table Upsert y Table Append comprueban sus tablas de origen cuando se ejecutan, antes de escribir nada. La comprobación compara la consulta que construyó el paso con cada tabla de origen tal como está en ese momento:

- Una columna que el paso lee y que la tabla no tiene, una clave de combinación que la tabla no tiene o que no está en las columnas de origen del paso, o una tabla de origen que el paso lee y que no se ha creado detiene el paso. Un único error nombra todos los problemas, cada uno con su propia solución. Una tabla de destino que ya existía queda como estaba, y una que el paso tuvo que crear queda vacía.
- Una columna que el paso enumera pero no lee, y que la tabla ya no tiene, agrega una advertencia. El paso se ejecuta sin ella.
- Table Union Distinct y Table Union All son la excepción cuando una tabla de origen no se ha creado: la omiten, sin advertencia, y combinan el resto, como hasta ahora. Si no se ha creado ninguna de sus tablas de origen, terminan con una advertencia en lugar de fallar.

Un paso cuyo destino es una vista solo crea la vista, por lo que las columnas y las claves de combinación que enumera se comprueban con sus tablas únicamente cuando el almacén se negaría de todos modos a crear esa vista. En los demás casos, solo detiene el paso una tabla de origen que no se ha creado o una clave de combinación que el paso no enumera, y no se agrega ninguna advertencia.

Siempre que es posible, el error nombra el paso que construye una tabla, y cuando la tabla tiene una columna con un nombre parecido al de una que falta, por ejemplo uno que solo difiere en las mayúsculas y minúsculas, nombra también esa columna.
