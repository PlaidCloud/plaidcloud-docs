### Tabla de destino

La selección de destino para las importaciones se limita a tablas, ya que las vistas no contienen datos subyacentes.

#### Opción dinámica

La opción dinámica permite especificar una tabla mediante texto, incluidas variables. Esto resulta útil en flujos de trabajo controlados por variables, en los que las referencias a tablas y vistas son relativas a las variables especificadas.

Un ejemplo que usa la variable `current_month` para apuntar dinámicamente a la tabla de destino:

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>Si la tabla no existe, se creará dinámicamente cuando se ejecute el proceso de importación</Aside>

#### Opción estática

Cuando se desea una tabla concreta como destino de la importación, deje sin marcar la casilla *Dinámico* y seleccione la tabla de destino.

Si la tabla de destino no existe, seleccione el botón *Crear nuevo* para crear la tabla en la ubicación deseada.

El Explorador de tablas está siempre disponible con cualquier selección de tabla. Haga clic en el botón Explorador de tablas situado a la derecha de la selección de tabla y se abrirá una ventana del Explorador de tablas.
