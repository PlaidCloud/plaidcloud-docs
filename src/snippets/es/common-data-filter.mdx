Para ofrecer la máxima flexibilidad, hay filtros de datos disponibles tanto para los datos de origen como para los datos de destino. En conjuntos de datos grandes, puede ser especialmente beneficioso filtrar filas en el origen para que las operaciones restantes se realicen sobre un conjunto de datos más pequeño.

#### Seleccionar un subconjunto de datos

Este tipo de filtro permite filtrar los datos de origen entrantes según las condiciones especificadas.

#### Aplicar un filtro secundario a los datos resultantes

Este tipo de filtro permite aplicar un filtro a los datos resultantes posteriores a la transformación según las condiciones especificadas.
La posibilidad de aplicar un filtro sobre el resultado transformado permite realizar exclusiones basadas en los resultados de cálculos complejos, resúmenes o funciones de ventana.

#### Segmentación final de la tabla de datos (límite)

La capacidad de segmentación de filas permite limitar las filas del conjunto de resultados según un intervalo y un punto de inicio.

<Aside>Para mantener la coherencia, los resultados que se segmentan deben tener una ordenación especificada</Aside>

#### Sintaxis de filtros

La sintaxis de filtros utiliza [Python SQLAlchemy](https://www.sqlalchemy.org), que es la misma sintaxis que otras expresiones.

Consulte ejemplos y funciones de expresión en el área de [Expresiones](/es/reference/expressions/).
