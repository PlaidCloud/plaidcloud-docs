### Origen y destino

![Origen y destino](/images/table_source_and_target_EN.png)

Para establecer las tablas de origen y de destino, seleccione primero la tabla de datos de la que se extraerá mediante el menú desplegable **Tabla de origen**. A continuación, seleccione una tabla existente como tabla de destino mediante el menú desplegable **Tabla de destino** o haga clic en el signo verde **"+"** para crear una tabla nueva como destino. 

#### Creación de tablas
Al crear una tabla nueva, tendrá la opción de crearla como **Vista** o como **Tabla**. 
##### Vistas:
Las vistas son útiles porque el tiempo que necesita un paso para ejecutarse es considerablemente menor que cuando se usa una tabla. La desventaja de las vistas es que no son útiles para explorar datos en el modo de detalles de la tabla.

##### Tablas:
Cuando se usa una tabla como destino, un paso tarda más en ejecutarse, pero la exploración de datos en el modo de detalles es mucho más rápida que con una vista.

<Aside>Use tablas para los pasos clave de sus flujos de trabajo en los que sea necesaria la validación de datos o la posibilidad de realizar análisis ad hoc. Para todos los demás pasos, use vistas para reducir el tiempo total de cálculo del flujo de trabajo. Es posible cambiar una tabla a una vista y viceversa, de modo que siempre puede actualizar el tipo de destino de la tabla más adelante.</Aside>
