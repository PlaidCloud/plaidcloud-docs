## Selección de tablas


Hay dos opciones para seleccionar la tabla o, en la segunda opción, las tablas:

La primera opción es usar el menú desplegable ***Tabla específica*** para seleccionar la tabla.

La segunda es usar la opción ***Tablas que coinciden con la búsqueda***, en la que se especifican la **Ruta de búsqueda** y el **Texto de búsqueda** para seleccionar la tabla o las tablas que cumplen los criterios de búsqueda. 
Esta opción es muy útil si tiene un flujo de trabajo que crea una serie de tablas con nombres comunes que se han guardado añadiendo la fecha.
