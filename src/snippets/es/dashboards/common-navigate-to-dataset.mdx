## Navegar a un conjunto de datos
Para ver y editar métricas y expresiones calculadas, siga estos pasos:
1.  Inicie sesión en plaidcloud.com y navegue a los paneles de control
2.  Desde visualize.plaidcloud.com, navegue a Data > Datasets
3.  Busque un conjunto de datos para verlo o modificarlo
4.  Modifique el conjunto de datos colocando el cursor sobre el botón `edit` que aparece bajo `Actions`
