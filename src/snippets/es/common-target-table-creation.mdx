### Tabla de destino

![Tabla de destino](/images/table_target_table.png)

Para establecer la tabla de destino, seleccione una tabla existente con el menú desplegable **Tabla de destino** o haga clic en el signo **"+"** verde para crear una nueva tabla de destino. 

#### Creación de tablas
Al crear una nueva tabla, podrá crearla como **Vista** o como **Tabla**. 
##### Vistas:
Las vistas son útiles porque el tiempo que tarda en ejecutarse un paso es considerablemente menor que cuando se usa una tabla. La desventaja de las vistas es que no son útiles para explorar datos en el modo Detalles de la tabla.

##### Tablas:
Cuando se usa una tabla como destino, un paso tarda más en ejecutarse, pero la exploración de datos en el modo Detalles es mucho más rápida que con una vista.

<Aside>Use tablas para los pasos clave de sus flujos de trabajo en los que sea necesaria la validación de datos o la capacidad de realizar análisis ad hoc. Para el resto de los pasos, use vistas para reducir el tiempo total de cálculo del flujo de trabajo. Es posible cambiar una tabla a vista y viceversa, por lo que siempre podrá actualizar el tipo de destino de la tabla más adelante.</Aside>
