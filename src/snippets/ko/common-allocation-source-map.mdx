![배부 소스 맵](/images/allocation_source_map.png)

배부 소스 맵은 배부 단계에서 사용할 **배부할 값 테이블**의 열을 매핑하는 데 사용합니다.

#### 소스 검사 및 매퍼 채우기

**소스 검사** 메뉴 버튼을 사용하면 소스에서 대상으로 열을 매핑하는 추가 방법을 사용할 수 있습니다.

* 두 매핑 테이블 모두 채우기: 소스 데이터 테이블의 모든 값을 대상 데이터 테이블로 전파합니다. 기본으로 적용되는 동작입니다.
* 소스 매핑 테이블만 채우기: 소스 데이터 테이블의 모든 값만 매핑합니다. 소스 열 구조가 변경되어 기존 워크플로를 수정할 때 유용합니다.
* 대상 매핑 테이블만 채우기: 모든 값을 대상 데이터 테이블로만 전파합니다.

소스 및 대상 열 옵션만으로 충분하지 않은 경우 다음과 같은 여러 방법으로 대상 데이터 테이블에 다른 열을 추가할 수 있습니다.

* **모두 전파**는 이미 존재하는지 여부와 관계없이 모든 소스 열을 대상 데이터 테이블에 삽입합니다.
* **선택 항목 전파**는 선택한 소스 열만 삽입합니다.
* 대상 쪽에서 마우스 오른쪽 버튼을 클릭하고 **행 삽입**을 선택하면 현재 선택한 행 바로 위에 행이 삽입됩니다.
* 대상 쪽에서 마우스 오른쪽 버튼을 클릭하고 **행 추가**를 선택하면 대상 데이터 테이블의 맨 아래(맨 오른쪽)에 행이 삽입됩니다.

<Aside type="danger">*모두 전파*를 선택하면 대상 목록에 이미 있는 열이 중복됩니다</Aside>

#### 역할
데이터 매퍼의 각 열에는 역할을 지정해야 합니다.
- **Pass Thought** - 이 열은 배부 결과 테이블에 표시됩니다.
- **배부할 값** - 배부할 값이 들어 있는 열입니다.


#### 열 삭제

대상 데이터 테이블에서 열을 삭제하려면 삭제할 열을 선택한 다음 마우스 오른쪽 버튼을 클릭하고 **삭제**를 선택합니다.

#### 열 순서 변경

대상 데이터 테이블에서 열을 재정렬하려면 이동할 열을 선택합니다. 다음 중 하나를 사용할 수 있습니다.
* **일괄 이동 화살표**: 오른쪽 위의 화살표에서 원하는 이동 옵션을 선택합니다.
* **컨텍스트 메뉴**: 마우스 오른쪽 버튼을 클릭하고 **맨 위로 이동**, **위로 이동**, **아래로 이동** 또는 **맨 아래로 이동**을 선택합니다.

#### 결과를 고유 레코드로만 줄이기

고유한 옵션만 반환하려면 **고유** 메뉴 옵션을 선택합니다. 소스의 각 열에 대한 체크박스 집합이 표시됩니다. 고유한 결과만 반환할 열 옆의 체크박스를 선택하면 됩니다.

상황에 따라서는 요약을 대신 사용하는 것이 나을 수 있습니다.

고유 처리는 처음 발견한 고유 레코드를 유지하고 나머지는 버립니다. 실행 간 일관성이 중요하다면 데이터에 정렬을 적용하는 것이 좋습니다.

<Aside type="danger">고유성을 판단하는 데 모든 열을 선택하면 고유 처리가 적용되지 않은 것처럼 보일 수 있습니다. 데이터의 고유성을 정의한다고 판단되는 열만 선택하십시오.</Aside>

#### 집계 및 그룹화

결과를 집계하려면 **요약** 메뉴 옵션을 선택합니다. 대상 데이터 테이블의 각 열에 대한 선택 상자 집합이 표시됩니다. 각 열에 적절한 요약 방법을 선택합니다.

- 그룹화 기준
- 합계
- 최솟값
- 최댓값
- 첫 번째
- 마지막
- 개수
- 개수(null 포함)
- 평균
- 표준 편차
- 표본 표준 편차
- 모집단 표준 편차
- 분산
- 표본 분산
- 모집단 분산
- 고급 비그룹화(Non-Group_By)


<Aside>집계를 사용할 때는 모든 열에 요약 유형을 **반드시** 지정해야 합니다</Aside>

식, 정리, 상수 등 데이터 매퍼의 고급 사용법은 [고급 데이터 매퍼 사용법](/ko/reference/workflow-steps/common/advanced-data-mapper-usage/)을 참조하십시오.
