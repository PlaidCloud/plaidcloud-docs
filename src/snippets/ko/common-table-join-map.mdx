![테이블 조인 맵](/images/table_join_map.png)

조인 조건을 지정합니다. **Guess**는 두 테이블의 열로 적용할 수 있는 다음 항목 중 첫 번째 항목으로 **조인 맵**을 채웁니다.

- 같은 두 테이블을 조인하는 이 프로젝트의 다른 조인 단계의 키
- 두 테이블을 조인하는 승인된 지표의 키
- 한 테이블에 설정된 키 열을 다른 테이블에서 이름으로 일치시킨 것
- **테이블 1**과 **테이블 2**에서 이름이 같은 열
- 이름이 대소문자나 밑줄에서만 다른 열, 또는 `id` 열과 해당 테이블 이름을 딴 열(예: *Customers* 테이블의 `customer_id`)

맵을 변경하기 전까지는 맵 아래의 한 줄에 어떤 항목을 사용했는지 표시됩니다. Guess는 테이블의 행이 아니라 열을 읽으므로 저장하기 전에 키를 확인하십시오. **소스 검사**는 비어 있는 **조인 맵**을 같은 방식으로 채웁니다.

열을 직접 추가하려면 해당 섹션의 아무 곳이나 마우스 오른쪽 버튼으로 클릭하고 **행 삽입** 또는 **행 추가**를 선택합니다. 각각 현재 선택한 행 앞에 행을 추가하거나 맨 끝에 행을 추가합니다. 그런 다음 **테이블 1**과 **테이블 2**에서 일치시킬 열 이름을 입력합니다. **조인 맵**에서 필드를 제거하려면 마우스 오른쪽 버튼을 클릭하고 **삭제**를 선택하면 됩니다.
