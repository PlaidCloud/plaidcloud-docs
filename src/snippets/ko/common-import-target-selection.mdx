### 대상 테이블

뷰에는 기본 데이터가 없으므로 가져오기의 대상은 테이블로만 제한됩니다.

#### 동적 옵션

동적 옵션을 사용하면 변수를 포함한 텍스트로 테이블을 지정할 수 있습니다. 지정한 변수에 따라 테이블 및 뷰 참조가 달라지는
변수 기반 워크플로를 사용할 때 유용합니다.

`current_month` 변수를 사용하여 대상 테이블을 동적으로 가리키는 예는 다음과 같습니다.

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>테이블이 없으면 가져오기 프로세스가 실행될 때 동적으로 생성됩니다</Aside>

#### 정적 옵션

가져오기의 대상으로 특정 테이블을 사용하려면 *동적* 체크박스를 선택하지 않은 상태로 두고 대상 테이블을 선택합니다.

대상 테이블이 없으면 *새로 만들기* 버튼을 선택하여 원하는 위치에 테이블을 만듭니다.

테이블 탐색기는 모든 테이블 선택에서 항상 사용할 수 있습니다. 테이블 선택 오른쪽의 테이블 탐색기 버튼을 클릭하면 테이블 탐색기 창이 열립니다.
