**조인 맵** 또는 **대상 출력 열** 행에는 단계의 **소스 열** 탭에 더 이상 나열되지 않는 열 이름이 있을 수 있습니다(예: 소스의 열을 다시 검사한 후). 단계는 이런 행을 자동으로 제거하지 않습니다. 대신 열 이름이 ⚠ 경고 표시와 함께 빨간색으로 표시되며, 위에 마우스를 올리면 어느 소스의 목록에 해당 열이 없는지 알려 줍니다.

**상수**, **식** 또는 **개수(null 포함)** 요약이 지정된 대상 출력 열 행은 단계가 해당 행의 소스 열을 읽지 않으므로 표시되지 않습니다. 목록이 비어 있는 소스(예: 한 번도 검사하지 않은 소스)에 대해서는 아무것도 검사하지 않습니다.

표시된 행이 남아 있는 단계를 저장하면 **오래된 열 발견** 대화 상자에 테이블별로 해당 행이 나열되며 세 가지 선택지가 제공됩니다.

- **모두 제거 후 저장** — 표시된 행을 제거한 다음 저장합니다.
- **그대로 저장** — 단계를 현재 상태 그대로 저장합니다.
- **취소** — 저장하지 않고 단계로 돌아갑니다.

행을 유지하면서 경고를 없애려면 **소스 열** 탭에서 해당 열을 그 소스의 목록에 다시 추가하거나, 목록에 있는 열을 선택하십시오.

저장할 때는 각 소스 테이블도 현재 상태로 검사됩니다. 소스 목록에는 있지만 해당 테이블에는 없는 열이 있으면 테이블과 열을 알려 주는 **누락된 소스 열** 대화 상자가 열리며 **그대로 저장** 또는 **취소**를 선택할 수 있습니다. 표시된 행도 있으면 두 내용이 **오래된 열 발견** 대화 상자에 함께 나타납니다. [소스 테이블에 없는 열](/ko/reference/workflow-steps/tables/table-extract/#소스-테이블에-없는-열)을 참조하십시오.
