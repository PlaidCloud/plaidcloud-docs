#### 소스 테이블에 없는 열

저장할 때 소스 데이터 테이블 자체가 현재 상태로 검사됩니다. 단계의 소스 열에는 나열되어 있지만 테이블에는 없는 열(예: 앞선 단계에서 이름을 바꾸거나 삭제한 열)이 있으면 단계의 열이 최신 상태가 아니라는 뜻이며, 그런 열을 읽는 단계는 실행할 때 실패합니다. 이 경우 저장하면 각 테이블과 해당 테이블에 없는 열을 알려 주는 **누락된 소스 열** 대화 상자가 열리며, 두 가지 선택지가 있습니다.

- **그대로 저장** — 단계를 현재 상태 그대로 저장합니다.
- **취소** — 저장하지 않고 단계로 돌아갑니다.

테이블 쪽이 잘못되었을 수 있고 단계를 실행하기 전에 다시 바뀔 수도 있으므로 자동으로 제거되는 항목은 없습니다. 행이 더 이상 나열되지 않는 것으로 표시된 경우에는 두 내용이 **오래된 열 발견** 대화 상자에 함께 나타나며, **모두 제거 후 저장**은 표시된 행만 제거합니다. 소스 열 목록이 비어 있는 동안에는 대신 단계가 매핑하는 열을 검사하되, 열을 읽지 않는 **상수**, **식** 또는 **개수(null 포함)** 요약이 지정된 행은 제외합니다.

`{year}/Sales`처럼 변수로 지정한 소스는 저장하는 시점의 변수 값으로 검사하며, 대화 상자에는 `2026/Sales (from {year}/Sales)`와 같이 검사한 테이블 이름이 표시됩니다. 루프가 설정하는 변수에는 마지막 반복의 값이 들어 있으므로, 구조가 서로 다른 테이블을 반복하는 루프에서는 다음 실행에서 읽지 않을 테이블에 대해 경고가 표시될 수 있습니다. 아직 존재하지 않는 테이블(예: 워크플로의 앞선 단계에서 만드는 테이블), 변수에 값이 없는 소스, 단계가 실행 시 검색하여 찾는 테이블, 현재 읽을 수 없는 테이블은 검사하지 않습니다.
