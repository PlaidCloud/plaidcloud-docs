최대한의 유연성을 위해 데이터 필터는 소스 데이터와 대상 데이터 모두에서 사용할 수 있습니다. 대용량 데이터 세트에서는 소스에서 행을 먼저 걸러내어 나머지 작업을 더 작은 데이터 세트에서 수행하는 것이 특히 유용할 수 있습니다.

#### 데이터 하위 집합 선택

이 필터 유형은 지정한 조건에 따라 들어오는 소스 데이터를 필터링합니다.

#### 결과 데이터에 보조 필터 적용

이 필터 유형은 지정한 조건에 따라 변환된 후의 결과 데이터에 필터를 적용합니다.
변환 후 결과에 필터를 적용할 수 있으므로 복잡한 계산, 요약 또는 윈도우 함수의 결과를 기준으로 제외할 수 있습니다.

#### 최종 데이터 테이블 분할(제한)

행 분할 기능을 사용하면 범위와 시작 지점에 따라 결과 집합의 행 수를 제한할 수 있습니다.

<Aside>일관성을 위해 분할되는 결과에는 정렬을 지정해야 합니다</Aside>

#### 필터 구문

필터 구문은 다른 식과 동일한 구문인 [Python SQLAlchemy](https://www.sqlalchemy.org)를 사용합니다.

예제와 식 함수는 [식](/ko/reference/expressions/) 영역에서 확인하십시오.
