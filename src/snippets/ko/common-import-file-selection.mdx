### 파일 가져오기 선택기

이 변환의 파일 선택기를 사용하면 PlaidCloud 문서 위치에 저장된 파일을 가져오기 대상으로 선택할 수 있습니다.

디렉터리를 선택할 수도 있으며, 이 경우 변환을 실행할 때 해당 디렉터리 안의 모든 파일을 가져옵니다.

<Aside type="caution">가져올 디렉터리를 선택할 때는 모든 파일의 형식이 같은지 확인하십시오</Aside>

#### 문서 계정 선택

액세스 권한이 있는 PlaidCloud 문서 계정을 선택합니다. 선택한 계정을 기준으로 다음 선택 항목에서 디렉터리나 파일을 고를 수 있습니다.

프로젝트 안에서는 목록 맨 위에 **Project Default**도 표시됩니다. 이 항목은 프로젝트에 현재 기본값으로 설정된 계정을 대신합니다. 새 단계는 프로젝트에 기본 계정이 있으면 Project Default를 미리 선택하며, 기존 단계는 사용자가 변경하기 전까지 이전에 저장된 계정을 그대로 유지합니다. Project Default로 남겨 둔 단계는 실행 시점에 프로젝트의 기본 계정을 대상으로 실행됩니다. 기본 계정이 설정되어 있지 않으면 다른 계정으로 대체하지 않고 프로젝트 이름을 알려 주며 실행에 실패합니다.

#### 검색 옵션

**검색** 옵션을 사용하면 지정한 디렉터리 경로 아래에서 조건에 맞는 모든 파일을 찾아 가져올 수 있습니다. 가져올 파일이 여러 개인데 중첩된 디렉터리에 저장되어 있거나, 가져오지 않으려는 다른 파일과 같은 디렉터리에 섞여 있을 때 특히 유용합니다.

<Aside>유형과 용도가 비슷한 파일에 공통된 명명 규칙을 사용하면 하나의 가져오기 단계로 처리하기가 더 쉽습니다</Aside>

선택한 검색 경로는 검색을 시작할 디렉터리입니다. 검색 과정에서는 해당 디렉터리의 모든 파일과 하위 디렉터리에서 지정한 검색 조건에 맞는 파일을 찾습니다. 검색 조건이 하위 디렉터리의 파일에도 적용될 수 있는지 확인하십시오.

검색에는 다음 조건을 사용할 수 있습니다.
 * **정확히 일치**: 검색 텍스트와 정확히 일치하는 파일
 * **시작 문자열**: 검색 텍스트로 시작하는 모든 파일
 * **포함**: 검색 텍스트를 포함하는 모든 파일
 * **끝 문자열**: 검색 텍스트로 끝나는 모든 파일

AI 어시스턴트나 REST API에서는 검색을 `glob`(`CO Store*.yxdb`와 같은 와일드카드 패턴으로, 대소문자를 구분하지 않고 전체 파일 이름과 비교합니다) 또는 `regex`(전체 파일 이름이 일치해야 하는 정규식)로 설정할 수도 있습니다. 정규식은 `(?i)`로 시작하지 않으면 대소문자를 구분합니다.

#### 파일 또는 디렉터리 선택 옵션

특정 파일이나 디렉터리의 파일들을 가져와야 할 때는 검색보다 파일 또는 디렉터리를 직접 선택하는 방법이 더 좋습니다.

파일이나 디렉터리를 선택하려면 찾아보기 버튼을 사용하여 위에서 선택한 문서 계정의 경로를 고르면 됩니다.

#### 변수 치환

검색 옵션과 특정 파일/디렉터리 옵션 모두에서 경로, 검색 텍스트, 파일 이름에 변수를 사용할 수 있습니다.

`current_month` 변수를 사용해 올바른 파일을 동적으로 가리키는 예는 다음과 같습니다.

```
legal_entity/inputs/{current_month}/ledger_values.csv
```
