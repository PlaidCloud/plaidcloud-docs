이 변환의 파일 선택기를 사용하면 PlaidCloud 문서 위치에 저장된 파일을 선택하여 가져올 수 있습니다.

디렉터리를 선택할 수도 있으며, 이 경우 변환을 실행할 때 해당 디렉터리의 모든 파일을 가져옵니다.

<Aside type="caution">디렉터리를 선택하여 가져올 때는 모든 파일의 형식이 같은지 확인하십시오.</Aside>

### 소스 계정

액세스 권한이 있는 PlaidCloud 문서 계정을 선택합니다. 그러면 다음 선택 항목에서 디렉터리나 파일을 선택할 수 있습니다.

프로젝트 안에서는 목록 맨 위에 **Project Default**도 표시됩니다. 이 항목은 프로젝트에 현재 기본값으로 설정된 계정을 대신합니다. 프로젝트에 기본 계정이 있으면 새 단계에서는 Project Default가 미리 선택되며, 기존 단계는 사용자가 변경할 때까지 저장할 때 사용한 계정을 그대로 유지합니다. Project Default로 설정된 단계는 실행 시점에 프로젝트의 기본 계정으로 실행됩니다. 기본 계정이 설정되어 있지 않으면 다른 계정으로 대체하지 않고 해당 프로젝트 이름을 표시하며 실행이 실패합니다.

#### 검색 옵션

**검색** 옵션을 사용하면 지정한 디렉터리 경로 아래에서 일치하는 모든 파일을 찾아 가져올 수 있습니다. 포함해야 할 파일이 많은데 중첩된 디렉터리에 저장되어 있거나, 가져오지 않을 다른 파일과 같은 디렉터리에 섞여 있을 때 특히 유용합니다.

<Aside>유형과 용도가 비슷한 파일에 공통된 명명 규칙을 사용하면 하나의 가져오기 단계로 처리하기가 쉬워집니다.</Aside>

선택한 검색 경로는 검색을 시작할 디렉터리입니다. 검색 과정에서는 해당 디렉터리와 하위 디렉터리에 있는 파일 중 지정한 검색 조건과 일치하는 모든 파일을 찾습니다. 검색 조건이 하위 디렉터리의 파일에도 적용될 수 있는지 확인하십시오.

검색에는 다음 조건을 사용할 수 있습니다.
 * **정확히 일치**: 검색 텍스트와 정확히 일치하는 파일
 * **시작 문자열**: 검색 텍스트로 시작하는 모든 파일
 * **포함**: 검색 텍스트를 포함하는 모든 파일
 * **끝 문자열**: 검색 텍스트로 끝나는 모든 파일

AI 어시스턴트나 REST API에서는 검색을 `glob`으로 설정할 수도 있습니다. 이는 `CO Store*.yxdb`와 같은 와일드카드 패턴으로, 대소문자를 구분하지 않고 전체 파일 이름과 비교합니다. `regex`로 설정하면 전체 파일 이름이 정규식과 일치해야 합니다. 정규식은 `(?i)`로 시작하지 않는 한 대소문자를 구분합니다.

### 소스 파일 경로

가져올 특정 파일이나 파일 디렉터리가 정해져 있다면 검색보다 파일이나 디렉터리를 직접 선택하는 편이 좋습니다.

파일이나 디렉터리를 선택하려면 찾아보기 단추를 사용하여 위에서 선택한 문서 계정의 경로를 선택하기만 하면 됩니다.

#### 변수 대체

검색 옵션과 특정 파일/디렉터리 옵션 모두에서 경로, 검색 텍스트, 파일 이름에 변수를 사용할 수 있습니다.

다음은 `current_month` 변수를 사용하여 올바른 파일을 동적으로 가리키는 예입니다.

```
legal_entity/inputs/{current_month}/ledger_values.csv

```
### 대상 테이블

뷰에는 기본 데이터가 없으므로 가져오기의 대상으로는 테이블만 선택할 수 있습니다.

#### 동적 옵션

동적 옵션을 사용하면 변수를 포함한 텍스트로 테이블을 지정할 수 있습니다. 테이블과 뷰 참조가 지정한 변수에 따라 달라지는 변수 기반 워크플로를 사용할 때 유용합니다.

다음은 `current_month` 변수를 사용하여 대상 테이블을 동적으로 가리키는 예입니다.

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>테이블이 없으면 가져오기 프로세스가 실행될 때 동적으로 생성됩니다.</Aside>

#### 정적 옵션

특정 테이블을 가져오기 대상으로 사용하려면 *Dynamic* 확인란을 선택하지 않은 상태로 두고 대상 테이블을 선택합니다.

대상 테이블이 없으면 *Create new table* 단추를 선택하여 원하는 위치에 테이블을 만듭니다.

테이블을 선택할 때는 언제나 테이블 탐색기를 사용할 수 있습니다. 테이블 선택 항목 오른쪽의 테이블 탐색기 단추를 클릭하면 테이블 탐색기 창이 열립니다.
