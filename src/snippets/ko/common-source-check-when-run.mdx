#### 단계 실행 시

Table Extract, Table Lookup, Table Inner Join, Table Cross Join, Table Outer Join, Table Anti Join, 다중 테이블 조인, Table Union Distinct, Table Union All, Table Pivot, Table Melt, Table In-Place Delete, Table Upsert, Table Append 단계는 실행할 때 아무것도 기록하기 전에 소스 테이블을 검사합니다. 이 검사는 단계가 만든 쿼리를 그 시점의 각 소스 테이블과 비교합니다.

- 단계가 읽는 열이 테이블에 없거나, 조인 키가 테이블에 없거나 단계의 소스 열에 없거나, 단계가 읽는 소스 테이블이 아직 만들어지지 않았으면 단계가 중지됩니다. 하나의 오류가 모든 문제를 각각의 해결 방법과 함께 알려 줍니다. 이미 있던 대상 테이블은 그대로 유지되고, 단계가 새로 만들어야 했던 대상 테이블은 비어 있는 상태로 남습니다.
- 단계가 나열했지만 읽지 않는 열이 테이블에 더 이상 없으면 경고가 추가됩니다. 단계는 해당 열 없이 실행됩니다.
- Table Union Distinct와 Table Union All 단계는 아직 만들어지지 않은 소스 테이블에 대해서는 예외입니다. 이전과 마찬가지로 해당 테이블을 경고 없이 제외하고 나머지를 합칩니다. 소스 테이블이 하나도 만들어지지 않았으면 실패하는 대신 경고와 함께 종료됩니다.

대상이 뷰인 단계는 뷰만 만들기 때문에, 단계가 나열한 열과 조인 키는 웨어하우스가 어차피 해당 뷰 만들기를 거부하는 경우에만 테이블과 대조하여 검사합니다. 그 외의 경우에는 아직 만들어지지 않은 소스 테이블이나 단계에 나열되지 않은 조인 키만 단계를 중지시키며, 경고는 추가되지 않습니다.

가능한 경우 오류에는 테이블을 만드는 단계의 이름이 표시되며, 누락된 열과 이름이 비슷한 열(예: 대소문자만 다른 열)이 테이블에 있으면 그 열의 이름도 표시됩니다.
