### 미리 보기

**소스** 탭에서 **미리 보기**를 클릭하면 단계를 실행하지 않고 단계가 읽을 내용을 최대 100개 행까지 볼 수 있습니다. 결과가 더 길면 미리 보기에 처음 몇 개 행만 표시한다는 안내와 모든 행을 읽으려면 단계를 실행해야 한다는 안내가 나타납니다.

미리 보기는 실행할 때와 같은 방식으로 프로젝트 변수와 워크플로 변수를 채웁니다. `{x:>9}` 같은 변수 형식은 지원하지 않으며, 트리거 값처럼 실행 중에만 값이 있는 변수는 채울 수 없습니다.

미리 보기는 데이터만 읽습니다. 무언가를 변경할 수 있는 쿼리는 거부하고 행 대신 메시지를 표시합니다.

- **미리 보기는 표준 SQL 함수만 지원합니다. 단계를 실행하여 결과를 확인하십시오.** 쿼리가 미리 보기에서 읽기 전용임을 확인할 수 없는 함수를 사용합니다. 결과를 보려면 단계를 실행하십시오.
- 단일 `SELECT`가 아닌 쿼리나, 변수가 확장되어 쓰기 문이 되는 쿼리는 거부됩니다.

미리 보기는 잠긴 프로젝트, SQL Server, Oracle 또는 SQLite 연결, [Agent Remote Execution of SQL](/ko/reference/workflow-steps/agent/agent-remote-execution-of-sql/)처럼 에이전트를 통해 실행되는 단계에서는 사용할 수 없습니다.
