### 내보내기 파일 선택기

![내보내기 파일 선택기](/images/export_file_source_target.png)

이 변환의 파일 선택기를 사용하면 내보낸 결과를 저장할 PlaidCloud 문서 대상 위치를 선택할 수 있습니다.

디렉터리를 선택하고 대상 파일의 파일 이름을 지정합니다.


### 소스 테이블


#### 동적 옵션

동적 옵션을 사용하면 변수를 포함한 텍스트로 테이블을 지정할 수 있습니다. 지정한 변수에 따라 테이블 및 뷰 참조가 달라지는
변수 기반 워크플로를 사용할 때 유용합니다.

`current_month` 변수를 사용하여 소스 테이블을 동적으로 가리키는 예는 다음과 같습니다.

```
legal_entity/inputs/{current_month}/ledger_values
```

#### 정적 옵션

내보내기의 소스로 특정 테이블을 사용하려면 *동적* 체크박스를 선택하지 않은 상태로 두고 소스 테이블을 선택합니다.


테이블 탐색기는 모든 테이블 선택에서 항상 사용할 수 있습니다. 테이블 선택 오른쪽의 테이블 탐색기 버튼을 클릭하면 테이블 탐색기 창이 열립니다.



#### 문서 계정 선택

액세스 권한이 있는 PlaidCloud 문서 계정을 선택합니다. 그러면 다음 선택 항목에서 디렉터리를 선택할 수 있습니다.

프로젝트 안에서는 목록 맨 위에 **Project Default**도 표시됩니다. 프로젝트에 현재 기본값으로 설정된 계정을 대신하는 항목입니다. 프로젝트에 기본 계정이 있으면 새 단계에는 Project Default가 미리 선택됩니다. 기존 단계는 변경하기 전까지 이전에 저장된 계정을 유지합니다. Project Default로 둔 단계는 실행 시점에 프로젝트의 기본 계정을 대상으로 실행되며, 기본 계정이 설정되어 있지 않으면 다른 계정으로 대체하지 않고 프로젝트 이름을 알려 주며 실행이 실패합니다.

#### 대상 디렉터리 경로

**대상 디렉터리 경로** 오른쪽의 ***찾아보기*** 아이콘을 선택하고 파일을 저장할 위치로 이동합니다.

#### 대상 파일 이름

내보낸 파일을 저장할 이름을 지정합니다.
