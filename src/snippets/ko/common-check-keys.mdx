**키 확인**은 **추측** 옆에 있으며, **Join Map**에서 테이블의 둘 이상의 행에 나타나는 키 값의 수를 셉니다. 조인 대상 테이블에서 키 값이 반복되면, 해당 키와 일치하는 각 행이 일치하는 행마다 한 번씩 결과에 나타나므로 결과의 행 수가 처음 테이블보다 많아질 수 있습니다.

검사하는 테이블은 단계에 따라 다릅니다.

- **내부 조인**과 **Table Lookup** 단계: 테이블 2.
- **외부 조인**: 왼쪽 조인은 테이블 2, 오른쪽 조인은 테이블 1, 전체 조인은 두 테이블 모두.

결과는 **Join Map** 아래에 표시됩니다. 반복되는 키 값의 수와 해당 키를 공유하는 행의 수를 알려 주며, 가장 많이 반복되는 키를 최대 5개까지 나열합니다. 다음과 같이 계산합니다.

- 이 단계가 해당 테이블에 적용한 필터를 거친, 현재 상태의 테이블
- 행 수준 보안으로 테이블에서 볼 수 있는 범위가 제한되는 경우, 볼 수 있는 행만. 결과에 이 사실이 표시됩니다.
- 키가 비어 있는 행은 제외. 비어 있는 키는 다른 행과 일치하지 않기 때문입니다. 단, Alteryx에서 변환된 조인처럼 비어 있는 키끼리 서로 일치하도록 설정된 내부 조인 또는 외부 조인은 예외이며, 이 경우 비어 있는 키도 하나의 키 값으로 계산되어 **(공백)** 항목으로 나열될 수 있습니다.

**Table Lookup** 단계는 행을 반복하지 않습니다. 반복되는 키에 대해서는 테이블 2의 행 하나만 유지하며 각 열의 가장 낮은 값(가장 작은 숫자, 가장 이른 날짜, 정렬 순서상 첫 번째 텍스트)을 취하므로, 해당 행에는 테이블 2의 서로 다른 행의 값이 섞일 수 있습니다. 이런 경우 키 확인이 알려 줍니다. 사용할 값을 직접 선택하려면 테이블 2에서 각 키가 한 번만 나타나도록 하십시오.

이 검사는 웨어하우스의 테이블을 읽으므로 선택할 때만 실행되며 30초 후에 중지됩니다. 두 테이블 중 하나, 해당 필터, **Join Map** 또는 외부 조인의 **조인 유형**을 변경하면 결과가 지워집니다.
