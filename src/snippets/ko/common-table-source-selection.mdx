### 테이블 소스


드롭다운 메뉴에서 선택하여 소스 데이터 테이블을 지정합니다.

### 소스 열


포함할 열을 여기에 지정합니다. **소스 검사** 및 **소스 매핑 테이블 채우기** 버튼을 선택하면 이 열을 조인 작업에 사용할 수 있게 됩니다.

### 소스 데이터의 하위 집합 선택


유효한 Python 식이면 모두 데이터의 하위 집합을 지정하는 데 사용할 수 있습니다. 자세한 내용과 예제는 [식](/ko/reference/expressions/)을 참조하십시오.
