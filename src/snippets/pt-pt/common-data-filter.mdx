Para permitir a máxima flexibilidade, existem filtros de dados disponíveis nos dados de origem e nos dados de destino. Em conjuntos de dados maiores, pode ser especialmente vantajoso filtrar linhas na origem, para que as restantes operações sejam executadas sobre um conjunto de dados mais pequeno.

#### Selecionar subconjunto de dados

Este tipo de filtro permite filtrar os dados de origem recebidos com base nas condições especificadas.

#### Aplicar filtro secundário aos dados de resultado

Este tipo de filtro permite aplicar um filtro aos dados de resultado depois de transformados, com base nas condições especificadas.
A possibilidade de aplicar um filtro ao resultado transformado permite exclusões com base nos resultados de cálculos complexos, sumarizações ou funções de janela.

#### Divisão final da tabela de dados (limite)

A capacidade de divisão de linhas permite limitar as linhas do conjunto de resultados com base num intervalo e num ponto de partida.

<Aside>Para manter a consistência, os resultados que são divididos devem ter uma ordenação especificada</Aside>

#### Sintaxe de filtros

A sintaxe de filtros utiliza o [Python SQLAlchemy](https://www.sqlalchemy.org), que é a mesma sintaxe das outras expressões.

Consulte exemplos e funções de expressão na área [Expressões](/pt-pt/reference/expressions/).
