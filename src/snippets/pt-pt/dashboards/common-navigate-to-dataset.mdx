## Navegar até um conjunto de dados
Para ver e editar indicadores e expressões calculadas, siga os passos seguintes:
1.  Inicie sessão em plaidcloud.com e navegue até aos painéis de controlo
2.  Em visualize.plaidcloud.com, navegue até Data > Datasets
3.  Pesquise o conjunto de dados que pretende ver ou modificar
4.  Modifique o conjunto de dados passando o cursor sobre o botão `edit` por baixo de `Actions`
