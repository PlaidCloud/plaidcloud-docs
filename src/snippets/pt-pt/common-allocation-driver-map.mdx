O Mapa de dados de driver da alocação serve para mapear as colunas da **Tabela de dados de driver** que serão utilizadas no passo de alocação.

#### Inspeção e preenchimento do mapeador

O botão de menu **Inspecionar origem** oferece formas adicionais de mapear colunas da origem para o destino:

* Preencher ambas as tabelas de mapeamento: propaga todos os valores da tabela de dados de origem para a tabela de dados de destino. Este é o comportamento predefinido.
* Preencher apenas a tabela de mapeamento de origem: mapeia apenas todos os valores da tabela de dados de origem. É útil ao modificar um fluxo de trabalho existente quando a estrutura das colunas de origem mudou.
* Preencher apenas a tabela de mapeamento de destino: propaga todos os valores apenas para a tabela de dados de destino.

Se as opções de colunas de origem e de destino não forem suficientes, é possível adicionar outras colunas à tabela de dados de destino de várias formas:

* **Propagar tudo** insere todas as colunas de origem na tabela de dados de destino, quer já existam ou não.
* **Propagar selecionadas** insere apenas as colunas de origem selecionadas.
* Clique com o botão direito do rato no lado do destino e selecione **Inserir linha** para inserir uma linha imediatamente acima da linha selecionada.
* Clique com o botão direito do rato no lado do destino e selecione **Acrescentar linha** para inserir uma linha no fim (extrema direita) da tabela de dados de destino.

<Aside type="danger">Selecionar *Propagar tudo* duplica as colunas se estas já existirem na lista de destino</Aside>

#### Função

A cada coluna do mapeador de dados tem de ser atribuída uma função:
- **Source Relation** - Estas colunas têm colunas correspondentes na **Tabela de valores a alocar**.
- **Allocation Target** - As colunas serão o destino do passo de alocação e aparecerão na **Tabela de resultados da alocação**.
- **Valor de divisão** - Esta coluna contém os valores que serão utilizados para alocar os valores da **Tabela de valores a alocar**.

<Aside>A Tabela de dados de driver **tem** de ter pelo menos uma coluna com a função **Source Relation**. A coluna **Source Relation** tem de ter uma coluna correspondente com o mesmo nome na **Tabela de valores a alocar**.</Aside>

#### Eliminar colunas

Para eliminar colunas da tabela de dados de destino, selecione a(s) coluna(s) pretendida(s), clique com o botão direito do rato e selecione **Eliminar**.

#### Alterar a ordem das colunas

Para reorganizar as colunas da tabela de dados de destino, selecione a(s) coluna(s) pretendida(s). Pode utilizar:
* **Setas de movimentação em massa**: selecione a opção de movimentação pretendida nas setas no canto superior direito
* **Menu de contexto**: clique com o botão direito do rato e selecione **Mover para o início**, **Mover para cima**, **Mover para baixo** ou **Mover para o fim**.

#### Reduzir o resultado apenas a registos distintos

Para devolver apenas opções distintas, selecione a opção de menu **Distinto**. Isto alterna um conjunto de caixas de seleção para cada coluna da origem. Basta assinalar a caixa junto da coluna correspondente para devolver apenas resultados distintos.

Consoante a situação, pode ser preferível considerar a utilização de sumarização.

O processo de distinção mantém o primeiro registo único encontrado e descarta os restantes. Pode ser conveniente aplicar uma ordenação aos dados se a consistência entre execuções for importante.

<Aside type="danger">Selecionar todas as colunas para determinar a distinção pode dar a impressão de que esta não está a ser aplicada. Selecione apenas as colunas que considera definirem o caráter distinto dos dados.</Aside>

#### Agregação e agrupamento

Para agregar resultados, selecione a opção de menu **Resumir**. Isto alterna um conjunto de caixas de seleção para cada coluna da tabela de dados de destino. Escolha um método de sumarização adequado para cada coluna.

- Agrupar por
- Soma
- Mínimo
- Máximo
- Primeiro
- Último
- Contagem
- Contagem (incluindo nulos)
- Média
- Desvio padrão
- Desvio padrão da amostra
- Desvio padrão da população
- Variância
- Variância da amostra
- Variância da população
- Avançado sem Agrupar por


<Aside>Ao utilizar agregação, todas as colunas **têm** de ter um tipo de sumarização especificado</Aside>
