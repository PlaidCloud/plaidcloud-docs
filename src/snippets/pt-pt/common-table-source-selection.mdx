### Tabela de origem


Indique a tabela de dados de origem selecionando-a no menu pendente.

### Colunas de origem


Indique aqui as colunas a incluir. Ao selecionar os botões **Inspecionar origem** e **Populate Source Mapping Table**, essas colunas ficam disponíveis para a operação de junção.

### Selecionar subconjunto dos dados de origem


Qualquer expressão Python válida é aceite para obter um subconjunto dos dados. Consulte [Expressões](/pt-pt/reference/expressions/) para obter mais detalhes e exemplos.
