### Tabela de destino

A seleção de destino para importações está limitada apenas a tabelas, uma vez que as vistas não contêm dados subjacentes.

#### Opção dinâmica

A opção dinâmica permite especificar uma tabela através de texto, incluindo variáveis. É útil em fluxos de trabalho orientados por variáveis, em que as referências a tabelas e vistas são relativas às variáveis especificadas.

Um exemplo que utiliza a variável `current_month` para apontar dinamicamente para a tabela de destino:

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>Se a tabela não existir, será criada dinamicamente quando o processo de importação for executado</Aside>

#### Opção estática

Quando se pretende uma tabela específica como destino da importação, deixe a caixa *Dynamic* desassinalada e selecione a tabela de destino.

Se a tabela de destino não existir, selecione o botão *Criar novo* para criar a tabela na localização pretendida.

O Explorador de tabelas está sempre disponível com qualquer seleção de tabela. Clique no botão do Explorador de tabelas à direita da seleção da tabela e abre-se uma janela do Explorador de tabelas.
