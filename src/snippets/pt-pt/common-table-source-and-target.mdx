### Origem e destino

![Source And Target](/images/table_source_and_target_EN.png)

Para definir as tabelas de origem e de destino, selecione primeiro a tabela de dados da qual extrair através do menu pendente **Tabela de origem**. Em seguida, selecione uma tabela existente como tabela de destino através do menu pendente **Tabela de destino** ou clique no sinal **"+"** verde para criar uma nova tabela como destino. 

#### Criação de tabelas
Ao criar uma nova tabela, tem a opção de a criar como **Vista** ou como **Tabela**. 
##### Vistas:
As vistas são úteis porque o tempo necessário para a execução de um passo é significativamente menor do que quando é utilizada uma tabela. A desvantagem das vistas é que não são úteis para a exploração de dados no modo Detalhes da tabela.

##### Tabelas:
Quando se utiliza uma tabela como destino, a execução do passo demora mais, mas a exploração de dados no modo Detalhes é muito mais rápida do que com uma vista.

<Aside>Utilize tabelas nos passos fundamentais dos seus fluxos de trabalho, onde seja necessária a validação de dados ou a capacidade de realizar análises ad hoc. Em todos os outros passos, utilize vistas para reduzir o tempo total de cálculo do fluxo de trabalho. É possível converter uma tabela numa vista e vice-versa, pelo que pode sempre alterar mais tarde o tipo de destino da tabela.</Aside>
