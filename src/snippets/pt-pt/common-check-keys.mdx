**Verificar chaves**, junto a **Deduzir**, conta os valores de chave do **Join Map** que aparecem em mais do que uma linha de uma tabela. Quando um valor de chave se repete na tabela à qual se junta, cada linha que lhe corresponde aparece no resultado uma vez por cada linha correspondente, pelo que o resultado pode ter mais linhas do que a tabela de partida.

A tabela verificada depende do passo:

- **Junção interna** e **Table Lookup**: Table 2.
- **Junção externa**: Table 2 numa junção à esquerda, Table 1 numa junção à direita e ambas as tabelas numa junção completa.

A resposta aparece por baixo do **Join Map**. Indica o número de valores de chave repetidos e as linhas que os partilham, e lista até cinco dos mais repetidos. Conta:

- a tabela tal como está agora, após o filtro deste passo nessa tabela;
- apenas as linhas que pode ver, quando a segurança ao nível da linha limita o que vê da tabela. A resposta indica-o;
- nenhuma linha com uma chave em branco, porque uma chave em branco nunca corresponde a outra linha. A exceção é uma Junção interna ou externa configurada para fazer corresponder chaves em branco entre si, como pode acontecer numa junção convertida do Alteryx: aí, as chaves em branco contam como um valor de chave e podem ser listadas como **(em branco)**.

O **Table Lookup** nunca repete uma linha. Para uma chave repetida, mantém uma linha da Table 2, tomando o valor mais baixo de cada coluna (o menor número, a data mais antiga, o primeiro texto pela ordem de ordenação), pelo que essa linha pode misturar valores de linhas diferentes da Table 2. A verificação de chaves informa-o quando isso acontece; para escolher que valores são utilizados, faça com que cada chave apareça uma só vez na Table 2.

A verificação lê a tabela no seu data warehouse, pelo que só é executada quando a escolhe, e termina ao fim de 30 segundos. Alterar qualquer uma das tabelas, o respetivo filtro, o **Join Map** ou, na junção externa, o **Tipo de junção** limpa a resposta.
