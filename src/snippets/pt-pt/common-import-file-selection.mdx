### Seletor de ficheiro de importação

O seletor de ficheiro nesta transformação permite escolher um ficheiro guardado numa localização de documentos do PlaidCloud para importação.

Também pode escolher um diretório para importar, e todos os ficheiros desse diretório serão importados como parte da execução da transformação.

<Aside type="caution">Ao escolher um diretório para importar, certifique-se de que todos os ficheiros têm o mesmo formato</Aside>

#### Selecionar uma conta de documentos

Escolha uma conta de documentos do PlaidCloud a que tenha acesso. Isto permite-lhe selecionar um diretório ou um ficheiro na seleção seguinte.

Dentro de um projeto, a lista oferece também **Project Default** no topo — um substituto da conta que o projeto tem atualmente definida como predefinida. Um novo passo pré-seleciona Project Default quando o projeto tem uma; um passo existente mantém a conta com que já tinha sido guardado até a alterar. Um passo deixado em Project Default é executado na conta que for a predefinição do projeto nesse momento — se não houver nenhuma definida, a execução falha e indica o projeto, em vez de recorrer a outra conta.

#### Opção de pesquisa

A opção **Pesquisar** permite encontrar todos os ficheiros correspondentes abaixo de um caminho de diretório especificado para importar. Pode ser particularmente útil quando é necessário incluir muitos ficheiros, mas estes estão guardados em diretórios aninhados ou misturados com outros ficheiros no mesmo diretório que não pretende importar.

<Aside>Usar uma convenção de nomenclatura comum para ficheiros de tipo e finalidade semelhantes facilita a utilização de um único passo de importação</Aside>

O caminho de pesquisa selecionado é o diretório inicial sob o qual se pesquisa. O processo de pesquisa procura todos os ficheiros nesse diretório, bem como nos subdiretórios, que correspondam às condições de pesquisa especificadas. Certifique-se de que os critérios de pesquisa também se aplicam aos ficheiros dos subdiretórios.

A pesquisa pode ser aplicada com as seguintes condições:
 * **Exato**: corresponde exatamente ao texto de pesquisa
 * **Começa com**: corresponde a qualquer ficheiro que comece com o texto de pesquisa
 * **Contém**: corresponde a qualquer ficheiro que contenha o texto de pesquisa
 * **Termina com**: corresponde a qualquer ficheiro que termine com o texto de pesquisa

Um assistente de IA ou a API REST também pode definir a pesquisa como `glob`, um padrão com carateres universais como `CO Store*.yxdb` comparado com o nome completo do ficheiro sem distinguir maiúsculas de minúsculas, ou `regex`, uma expressão regular com a qual o nome completo do ficheiro tem de corresponder. Uma expressão regular distingue maiúsculas de minúsculas, a menos que comece com `(?i)`.

#### Opção de seleção de ficheiro ou diretório

Quando é necessário importar um ficheiro específico ou um diretório de ficheiros, escolher o ficheiro ou o diretório é uma opção melhor do que usar a pesquisa.

Para selecionar o ficheiro ou o diretório, utilize simplesmente o botão de procura para escolher o caminho da conta de documentos selecionada acima.

#### Substituição de variáveis

Tanto na opção de pesquisa como na opção de ficheiro/diretório específico, é possível usar variáveis no caminho, no texto de pesquisa e nos nomes de ficheiros.

Um exemplo que utiliza a variável `current_month` para apontar dinamicamente para o ficheiro correto:

```
legal_entity/inputs/{current_month}/ledger_values.csv
```
