#### Quando o passo é executado

Os passos Table Extract, Table Lookup, Table Inner Join, Table Cross Join, Table Outer Join, Table Anti Join, Junção de várias tabelas, Table Union Distinct, Table Union All, Table Pivot, Table Melt, Table In-Place Delete, Table Upsert e Table Append verificam as respetivas tabelas de origem quando são executados, antes de escreverem seja o que for. A verificação compara a consulta criada pelo passo com cada tabela de origem tal como está nesse momento:

- Uma coluna que o passo lê e que a tabela não tem, uma chave de junção que a tabela não tem ou que não consta das colunas de origem do passo, ou uma tabela de origem que o passo lê e que não foi criada impede o passo de avançar. Um único erro indica todos os problemas, cada um com a respetiva correção. Uma tabela de destino que já existia fica como estava, e uma que o passo teve de criar fica vazia.
- Uma coluna que o passo lista mas não lê, e que a tabela já não tem, acrescenta um aviso. O passo é executado sem ela.
- Table Union Distinct e Table Union All são a exceção para uma tabela de origem que não foi criada: tal como antes, deixam-na de fora, sem aviso, e combinam as restantes. Se nenhuma das respetivas tabelas de origem tiver sido criada, terminam com um aviso em vez de falharem.

Um passo cujo destino é uma vista limita-se a criar a vista, pelo que as colunas e as chaves de junção que lista só são verificadas em relação às respetivas tabelas quando o armazém de dados recusaria, de qualquer forma, criar essa vista. Nos restantes casos, apenas uma tabela de origem que não foi criada ou uma chave de junção que o passo não lista o impede de avançar, e não é acrescentado nenhum aviso.

Sempre que possível, o erro indica o passo que cria uma tabela e, quando a tabela tem uma coluna com um nome próximo do de uma coluna em falta, por exemplo uma que difere apenas na capitalização, indica também essa coluna.
