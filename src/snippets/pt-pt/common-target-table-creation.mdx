### Tabela de destino

![Tabela de destino](/images/table_target_table.png)

Para definir a tabela de destino, selecione uma tabela existente através da lista pendente **Tabela de destino** ou clique no sinal **"+"** verde para criar uma nova tabela como destino. 

#### Criação de tabelas
Ao criar uma nova tabela, pode criá-la como **Vista** ou como **Tabela**. 
##### Vistas:
As vistas são úteis porque o tempo necessário para executar um passo é significativamente inferior ao de uma tabela. A desvantagem das vistas é que não são adequadas para a exploração de dados no modo Detalhes da tabela.

##### Tabelas:
Quando se utiliza uma tabela como destino, a execução de um passo demora mais, mas a exploração de dados no modo Detalhes é muito mais rápida do que com uma vista.

<Aside>Utilize tabelas nos passos fundamentais dos seus fluxos de trabalho, onde seja necessário validar dados ou realizar análises ad hoc. Nos restantes passos, utilize vistas para reduzir o tempo total de cálculo do fluxo de trabalho. É possível converter uma tabela numa vista e vice-versa, pelo que pode sempre alterar mais tarde o tipo de destino da tabela.</Aside>
