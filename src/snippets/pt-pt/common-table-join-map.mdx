Especifique as condições de junção. **Deduzir** preenche o **Mapa de campos de junção da relação entre tabelas** com a primeira das seguintes hipóteses que as colunas das duas tabelas permitam:

- as chaves de outro passo de junção neste projeto que junta as mesmas duas tabelas
- as chaves de um indicador aprovado que as junta
- as colunas de chave definidas numa das tabelas, correspondidas na outra pelo nome ou, caso contrário, pela única coluna associada ao mesmo [elemento do projeto](/pt-pt/guides/projects/data-model/)
- os elementos para os quais ambas as tabelas têm uma coluna, como descrito abaixo
- as colunas com o mesmo nome em ambas as tabelas
- colunas cujos nomes diferem apenas em maiúsculas ou sublinhados, ou uma coluna `id` correspondida com uma coluna com o nome da sua tabela, como `customer_id` para uma tabela chamada *Customers*

Uma linha por baixo do mapa indica qual foi utilizada, até alterar o mapa. O Deduzir lê as colunas das tabelas, não as suas linhas, por isso verifique as chaves antes de guardar. **Inspecionar origem** preenche um **Mapa de campos de junção da relação entre tabelas** vazio da mesma forma.

**Chaves de elementos partilhados.** Uma coluna pertence a um elemento quando o seu nome é o nome do elemento ou um dos seus aliases. Para cada elemento para o qual ambas as tabelas têm uma coluna, o Deduzir emparelha a única coluna de cada lado, mesmo quando os nomes diferem. Quando uma tabela tem várias colunas para o elemento, o Deduzir emparelha a que tem o nome que ambas as tabelas têm e, caso contrário, deixa esse elemento de fora. Duas colunas cujos tipos são de espécies diferentes, como texto e uma data, não são emparelhadas. Quando exatamente uma das tabelas tem o nome de um elemento partilhado, a junção é feita apenas por esse elemento. Uma tabela tem o nome de um elemento quando o seu nome, ignorando maiúsculas, é o nome do elemento, esse nome com um `s`, ou qualquer um deles depois de uma única palavra e um sublinhado, como `customer`, `customers` ou `dim_customer`. Um nome mais longo, como `sales_by_customer`, não conta, nem um cuja primeira palavra seja ela própria um elemento, como `customer_product`. A linha por baixo do mapa indica os elementos, como *These keys are the elements both tables share: customer, period.* Quando nenhum elemento dá um par, o Deduzir passa às colunas com o mesmo nome.

A dedução por elementos tem dois limites:

- Emparelha apenas colunas que pertencem a um elemento e não acrescenta colunas com o mesmo nome a seguir a elas. Quando a chave de uma tabela é composta por várias colunas e algumas não são elementos, como as de um calendário fiscal, o Deduzir propõe apenas as colunas de elementos; acrescente as outras manualmente.
- Uma tabela cujo nome é uma palavra e um sublinhado antes do nome de um elemento é tomada como a tabela própria desse elemento mesmo quando não é, como `ar_customer` ou `bank_account`, pelo que, quando é a única tabela com o nome de um elemento partilhado, a junção é proposta apenas por esse elemento.

**Elementos no mapa.** Cada coluna do mapa de junção que pertence a um elemento mostra o nome do elemento como uma etiqueta a seu lado. Passe o cursor por cima da etiqueta para ver o elemento, a sua descrição e a dimensão que fornece. As notas por baixo do mapa aconselham-no, mas nunca o impedem de guardar o passo:

- Uma linha que emparelha colunas de dois elementos diferentes recebe uma nota, como *A linha 2 emparelha elementos diferentes: customer e vendor.*
- Quando o **Deduzir** não encontra chaves, a nota *Não foram encontradas chaves prováveis.* tem uma ligação **Modelo de dados** que fecha o passo e abre a página [Modelo de dados](/pt-pt/guides/projects/data-model/) do projeto, onde pode descrever como elementos as colunas que as suas tabelas partilham. Quando o passo tem alterações não guardadas, é-lhe perguntado primeiro se pretende descartá-las.

Para adicionar colunas manualmente, clique com o botão direito do rato em qualquer parte da secção e selecione **Inserir linha** ou **Acrescentar linha**, para adicionar uma linha antes da linha selecionada ou no fim, respetivamente. Depois, escolha as colunas a fazer corresponder em **Campo de table1** e **Campo de table2**. Para remover um campo do **Mapa de campos de junção da relação entre tabelas**, clique simplesmente com o botão direito do rato e selecione **Eliminar**.
