### Pré-visualização

Clique em **Pré-visualização** no separador **Origem** para ver até 100 linhas do que o passo leria, sem o executar. Se o resultado for mais longo, a pré-visualização indica que mostra as primeiras linhas e que tem de executar o passo para as ler todas.

A pré-visualização preenche as variáveis do projeto e do fluxo de trabalho da mesma forma que uma execução. Não suporta formatos de variáveis como `{x:>9}` e não consegue preencher uma variável que só tem valor durante uma execução, como um valor de acionamento.

A pré-visualização só lê dados. Recusa uma consulta que possa alterar alguma coisa e mostra uma mensagem em vez de linhas:

- **A pré-visualização só suporta funções SQL padrão. Execute o passo para ver os resultados.** A consulta usa uma função que a pré-visualização não consegue verificar como só de leitura. Execute o passo para ver o resultado.
- Uma consulta que não seja um único `SELECT`, ou cujas variáveis se expandam para uma instrução que escreve, é recusada.

A pré-visualização não está disponível num projeto bloqueado, em ligações SQL Server, Oracle ou SQLite, nem para passos que são executados através de um agente, como [Agent Remote Execution of SQL](/pt-pt/reference/workflow-steps/agent/agent-remote-execution-of-sql/).
