Specify join conditions. **Guess** fills the **Join Map** from the first of these that the two tables' columns can take:

- the keys of another join step in this project that joins the same two tables
- the keys of an approved metric that joins them
- the key columns set on one of the tables, matched by name in the other
- the columns with the same name in **Table 1** and **Table 2**
- columns whose names differ only in capitals or underscores, or an `id` column matched to a column named for its table, such as `customer_id` for a table named *Customers*

A line under the map says which it used, until you change the map. Guess reads the tables' columns, not their rows, so check the keys before you save. **Inspect Source** fills an empty **Join Map** the same way.

To add additional columns manually, right click anywhere in the section and select either **Insert Row** or **Append Row**, to add a row prior to the currently selected row or to add a row at the end, respectively. Then, type the column names to match from **Table 1** to **Table 2**. To remove a field from the **Join Map**, simply right-click and select **Delete**.
