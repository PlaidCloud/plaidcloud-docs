Pour offrir un maximum de souplesse, des filtres de données sont disponibles sur les données source et sur les données cible. Pour les jeux de données volumineux, il peut être particulièrement avantageux de filtrer les lignes dès la source afin que les opérations suivantes portent sur un jeu de données plus petit.

#### Sélectionner un sous-ensemble de données

Ce type de filtre permet de filtrer les données source entrantes selon les conditions spécifiées.

#### Appliquer un filtre secondaire aux données de résultat

Ce type de filtre permet d'appliquer un filtre aux données de résultat après transformation, selon les conditions spécifiées.
La possibilité d'appliquer un filtre au résultat transformé permet d'exclure des lignes en fonction du résultat de calculs complexes, de synthèses ou de fonctions de fenêtrage.

#### Découpage final de la table de données (limite)

Le découpage des lignes permet de limiter les lignes du jeu de résultats selon une plage et un point de départ.

<Aside>Par souci de cohérence, les résultats découpés doivent avoir un tri spécifié</Aside>

#### Syntaxe des filtres

La syntaxe des filtres utilise [Python SQLAlchemy](https://www.sqlalchemy.org), qui est la même syntaxe que celle des autres expressions.

Consultez des exemples et des fonctions d'expression dans la section [Expressions](/fr/reference/expressions/).
