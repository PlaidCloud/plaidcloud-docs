### Sélecteur de fichier d'importation

Le sélecteur de fichier de cette transformation vous permet de choisir un fichier stocké dans un emplacement de documents PlaidCloud pour l'importer.

Vous pouvez aussi choisir un répertoire à importer ; tous les fichiers qu'il contient seront alors importés lors de l'exécution de la transformation.

<Aside type="caution">Lorsque vous choisissez un répertoire à importer, assurez-vous que tous les fichiers ont le même format</Aside>

#### Sélection d'un compte de documents

Choisissez un compte de documents PlaidCloud auquel vous avez accès. Cela vous permet de sélectionner un répertoire ou un fichier dans la sélection suivante.

Dans un projet, la liste propose aussi **Projet par défaut** tout en haut : il représente le compte actuellement défini comme compte par défaut du projet. Une nouvelle étape présélectionne Projet par défaut lorsque le projet en a un ; une étape existante conserve le compte avec lequel elle a été enregistrée jusqu'à ce que vous le changiez. Une étape laissée sur Projet par défaut s'exécute avec le compte qui est le compte par défaut du projet au moment de l'exécution ; si aucun n'est défini, l'exécution échoue et nomme le projet au lieu de se rabattre sur un autre compte.

#### Option de recherche

L'option **Rechercher** permet de trouver tous les fichiers correspondants sous un chemin de répertoire donné pour les importer. C'est particulièrement utile lorsque de nombreux fichiers doivent être
inclus mais sont stockés dans des répertoires imbriqués ou mélangés à d'autres fichiers du même répertoire que vous ne voulez pas importer.

<Aside>Utiliser une convention de nommage commune pour les fichiers de même type et de même finalité facilite le recours à une seule étape d'importation</Aside>

Le chemin de recherche sélectionné est le répertoire de départ de la recherche. La recherche examine tous les fichiers de ce répertoire ainsi que des sous-répertoires qui
correspondent aux conditions de recherche spécifiées. Assurez-vous que les critères de recherche s'appliquent aussi aux fichiers des sous-répertoires.

La recherche peut s'appliquer selon les conditions suivantes :
 * **Exact** : correspond exactement au texte recherché
 * **Commence par** : correspond à tout fichier qui commence par le texte recherché
 * **Contient** : correspond à tout fichier qui contient le texte recherché
 * **Se termine par** : correspond à tout fichier qui se termine par le texte recherché

Un assistant IA ou l'API REST peut aussi définir la recherche sur `glob`, un motif à caractères génériques tel que `CO Store*.yxdb` comparé au nom de fichier complet sans tenir compte de la casse, ou sur `regex`, une expression régulière à laquelle le nom de fichier complet doit correspondre. Une expression régulière est sensible à la casse, sauf si elle commence par `(?i)`.

#### Option de sélection d'un fichier ou d'un répertoire

Lorsqu'un fichier précis ou un répertoire de fichiers doit être importé, choisir le fichier ou le répertoire est préférable à la recherche.

Pour sélectionner le fichier ou le répertoire, utilisez simplement le bouton Parcourir afin de choisir le chemin dans le compte de documents sélectionné plus haut.

#### Substitution de variables

Pour l'option de recherche comme pour l'option de fichier ou de répertoire précis, vous pouvez utiliser des variables dans le chemin, dans le texte de recherche et dans les noms de fichiers.

Exemple qui utilise la variable `current_month` pour pointer dynamiquement vers le bon fichier :

```
legal_entity/inputs/{current_month}/ledger_values.csv
```
