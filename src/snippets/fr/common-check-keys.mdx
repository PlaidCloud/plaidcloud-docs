**Vérifier les clés**, à côté de **Deviner**, compte les valeurs de clé de la **Join Map** qui apparaissent sur plusieurs lignes d'une table. Lorsqu'une valeur de clé se répète dans la table à laquelle vous joignez, chaque ligne qui y correspond apparaît dans le résultat autant de fois qu'il y a de lignes correspondantes ; le résultat peut donc comporter plus de lignes que la table de départ.

La table vérifiée dépend de l'étape :

- **Jointure interne** et **Table Lookup** : la Table 2.
- **Jointure externe** : la Table 2 pour une jointure gauche, la Table 1 pour une jointure droite, et les deux tables pour une jointure complète.

La réponse apparaît sous la **Join Map**. Elle indique le nombre de valeurs de clé répétées et les lignes qui les partagent, et liste jusqu'à cinq des plus répétées. Le décompte porte sur :

- la table telle qu'elle est actuellement, après le filtre de cette étape sur cette table ;
- uniquement les lignes que vous pouvez voir, lorsque la sécurité au niveau des lignes limite ce que vous voyez de la table. La réponse l'indique ;
- aucune ligne dont la clé est vide, car une clé vide ne correspond jamais à une autre ligne. L'exception est une jointure interne ou externe configurée pour faire correspondre entre elles les clés vides, comme peut l'être une jointure convertie depuis Alteryx : dans ce cas, les clés vides comptent comme une valeur de clé et peuvent apparaître dans la liste sous la forme **(vide)**.

**Table Lookup** ne répète jamais une ligne. Pour une clé répétée, elle conserve une seule ligne de la Table 2, en prenant la valeur la plus basse de chaque colonne (le plus petit nombre, la date la plus ancienne, le premier texte dans l'ordre de tri) ; cette ligne peut donc mélanger des valeurs issues de différentes lignes de la Table 2. Vérifier les clés vous signale ce cas ; pour choisir les valeurs utilisées, faites en sorte que chaque clé n'apparaisse qu'une fois dans la Table 2.

Le contrôle lit la table dans votre entrepôt de données ; il ne s'exécute donc que lorsque vous le choisissez, et il s'arrête après 30 secondes. Modifier l'une des tables, son filtre, la **Join Map** ou, dans la jointure externe, le **Type de jointure** efface la réponse.
