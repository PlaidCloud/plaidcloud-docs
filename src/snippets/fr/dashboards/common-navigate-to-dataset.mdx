## Accéder à un jeu de données
Pour afficher et modifier les métriques et les expressions calculées, procédez comme suit :
1.  Connectez-vous à plaidcloud.com et accédez aux tableaux de bord
2.  Depuis visualize.plaidcloud.com, accédez à Data > Datasets
3.  Recherchez un jeu de données à afficher ou à modifier
4.  Modifiez le jeu de données en survolant le bouton `edit` sous `Actions`
