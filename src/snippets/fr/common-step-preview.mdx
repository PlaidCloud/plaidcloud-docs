### Aperçu

Cliquez sur **Aperçu** dans l'onglet **Source** pour voir jusqu'à 100 lignes de ce que l'étape lirait, sans l'exécuter. Si le résultat est plus long, l'aperçu indique qu'il affiche les premières lignes et qu'il faut exécuter l'étape pour toutes les lire.

L'aperçu renseigne les variables de projet et de workflow de la même manière qu'une exécution. Il ne prend pas en charge les formats de variables comme `{x:>9}`, et il ne peut pas renseigner une variable qui n'a de valeur que pendant une exécution, comme une valeur de déclencheur.

L'aperçu ne fait que lire des données. Il refuse une requête susceptible de modifier quoi que ce soit et affiche un message au lieu de lignes :

- **Preview only supports standard SQL functions. Run the step to see results.** La requête utilise une fonction que l'aperçu ne peut pas vérifier comme étant en lecture seule. Exécutez l'étape pour voir le résultat.
- Une requête qui n'est pas un seul `SELECT`, ou dont les variables se développent en une instruction qui écrit, est refusée.

L'aperçu n'est pas disponible sur un projet verrouillé, sur les connexions SQL Server, Oracle ou SQLite, ni pour les étapes qui s'exécutent via un agent, comme [Agent Remote Execution of SQL](/fr/reference/workflow-steps/agent/agent-remote-execution-of-sql/).
