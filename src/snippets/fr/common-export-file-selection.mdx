### Sélecteur de fichier d'export

![Sélecteur de fichier d'export](/images/export_file_source_target.png)

Le sélecteur de fichier de cette transformation vous permet de choisir une destination pour stocker le résultat exporté dans un document PlaidCloud.

Vous choisissez un répertoire et indiquez un nom de fichier pour le fichier cible.


### Table source


#### Option dynamique

L'option dynamique permet de spécifier une table à l'aide de texte, y compris des variables. C'est utile dans les workflows pilotés par des variables, où les références de tables et de vues sont relatives aux variables spécifiées.

Exemple qui utilise la variable `current_month` pour pointer dynamiquement vers la table source :

```
legal_entity/inputs/{current_month}/ledger_values
```

#### Option statique

Lorsque vous souhaitez une table précise comme source de l'export, laissez la case *Dynamique* décochée et sélectionnez la table source.


L'Explorateur de tables est toujours disponible pour toute sélection de table. Cliquez sur le bouton Explorateur de tables à droite de la sélection de table : une fenêtre Explorateur de tables s'ouvre.



#### Sélection d'un compte de documents

Choisissez un compte de documents PlaidCloud auquel vous avez accès. Cela vous permet de sélectionner un répertoire dans la sélection suivante.

Dans un projet, la liste propose aussi **Projet par défaut** tout en haut : il représente le compte actuellement défini comme compte par défaut du projet. Une nouvelle étape présélectionne Projet par défaut lorsque le projet en a un ; une étape existante conserve le compte avec lequel elle a été enregistrée jusqu'à ce que vous le changiez. Une étape laissée sur Projet par défaut s'exécute avec le compte qui est le compte par défaut du projet au moment de l'exécution ; si aucun n'est défini, l'exécution échoue et nomme le projet au lieu de se rabattre sur un autre compte.

#### Chemin du répertoire cible

Sélectionnez l'icône ***Parcourir*** à droite du ***Chemin du répertoire cible*** et accédez à l'emplacement où vous souhaitez enregistrer le fichier.

#### Nom du fichier cible

Indiquez le nom sous lequel le fichier exporté doit être enregistré.
