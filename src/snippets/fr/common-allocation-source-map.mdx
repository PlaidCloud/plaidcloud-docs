Le mappage de la source d'allocation sert à mapper les colonnes de la **Table des valeurs à allouer** qui seront utilisées dans l'étape d'allocation.

#### Inspection et renseignement du mappeur

Le bouton de menu **Inspecter la source** offre d'autres façons de mapper les colonnes de la source vers la cible :

* Renseigner les deux tables de mappage : propage toutes les valeurs de la table de données source vers la table de données cible. C'est le comportement par défaut.
* Renseigner uniquement la table de mappage source : mappe uniquement les valeurs de la table de données source. C'est utile lorsque vous modifiez un workflow existant dont la structure des colonnes source a changé.
* Renseigner uniquement la table de mappage cible : propage toutes les valeurs uniquement vers la table de données cible.

Si les options de colonnes source et cible ne suffisent pas, vous pouvez ajouter d'autres colonnes à la table de données cible de plusieurs façons :

* **Tout propager** insère toutes les colonnes source dans la table de données cible, qu'elles y figurent déjà ou non.
* **Propager la sélection** insère uniquement les colonnes source sélectionnées.
* Faites un clic droit côté cible et sélectionnez **Insérer une ligne** pour insérer une ligne juste au-dessus de la ligne actuellement sélectionnée.
* Faites un clic droit côté cible et sélectionnez **Ajouter une ligne** pour insérer une ligne en bas (à l'extrême droite) de la table de données cible.

<Aside type="danger">Si vous sélectionnez *Tout propager*, les colonnes qui existent déjà dans la liste cible seront dupliquées</Aside>

#### Rôle
Chaque colonne du Data Mapper doit se voir attribuer un rôle :
- **Transmission directe** : ces colonnes apparaîtront dans la table de résultat de l'allocation.
- **Valeur à allouer** : c'est la colonne qui contient les valeurs à allouer.


#### Suppression de colonnes

Pour supprimer des colonnes de la table de données cible, sélectionnez les colonnes souhaitées, faites un clic droit, puis sélectionnez **Supprimer**.

#### Modification de l'ordre des colonnes

Pour réorganiser les colonnes de la table de données cible, sélectionnez les colonnes souhaitées. Vous pouvez utiliser l'une des deux méthodes suivantes :
* **Flèches de déplacement groupé** : sélectionnez l'option de déplacement souhaitée parmi les flèches en haut à droite.
* **Menu contextuel** : faites un clic droit et sélectionnez **Déplacer en haut**, **Monter**, **Descendre** ou **Déplacer en bas**.

#### Réduire le résultat aux enregistrements distincts

Pour ne renvoyer que les valeurs distinctes, sélectionnez l'option de menu **Distinct**. Un ensemble de cases à cocher s'affiche pour chaque colonne de la source. Il suffit de cocher la case en regard de la colonne correspondante pour ne renvoyer que les résultats distincts.

Selon la situation, il peut être préférable d'utiliser plutôt le résumé.

Le traitement des valeurs distinctes conserve le premier enregistrement unique trouvé et supprime les autres. Si la cohérence entre les exécutions est importante, il peut être utile de trier les données.

<Aside type="danger">Si vous sélectionnez toutes les colonnes pour déterminer le caractère distinct, il peut sembler que l'option n'est pas appliquée. Sélectionnez uniquement les colonnes qui, selon vous, définissent le caractère distinct des données.</Aside>

#### Agrégation et regroupement

Pour agréger les résultats, sélectionnez l'option de menu **Résumer**. Un ensemble de listes de sélection s'affiche pour chaque colonne de la table de données cible. Choisissez une méthode de résumé appropriée pour chaque colonne.

- Regrouper par
- Somme
- Min
- Max
- Premier
- Dernier
- Nombre
- Nombre (valeurs nulles incluses)
- Moyenne
- Écart type
- Écart type d'échantillon
- Écart type de population
- Variance
- Variance d'échantillon
- Variance de population
- Avancé hors regroupement


<Aside>Lorsque vous utilisez l'agrégation, un type de résumé **doit** être spécifié pour toutes les colonnes</Aside>
