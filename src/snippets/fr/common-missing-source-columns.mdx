#### Colonnes absentes de la table source

Lorsque vous enregistrez, la table de données source elle-même est vérifiée dans son état actuel. Une colonne que l'étape liste dans ses colonnes source mais que la table n'a pas, par exemple une colonne qu'une étape précédente a renommée ou supprimée, signifie que les colonnes de l'étape sont obsolètes, et une étape qui lit une telle colonne échoue à l'exécution. L'enregistrement ouvre alors une boîte de dialogue **Colonnes source manquantes** qui nomme chaque table et les colonnes qui lui manquent, avec deux choix :

- **Enregistrer quand même** : enregistre l'étape telle quelle.
- **Annuler** : revient à l'étape sans enregistrer.

Rien n'est supprimé à votre place, car la table peut être la source du problème et peut encore changer avant l'exécution de l'étape. Lorsque des lignes sont aussi signalées comme n'étant plus listées, les deux apparaissent ensemble dans la boîte de dialogue **Colonnes obsolètes détectées**, et **Tout supprimer et enregistrer** ne supprime que les lignes signalées. Tant que la liste des colonnes source est vide, ce sont les colonnes mappées par l'étape qui sont vérifiées, à l'exception des lignes ayant un résumé **Constante**, **Expression** ou **Nombre (valeurs nulles incluses)**, qui ne lisent aucune colonne.

Une source nommée à l'aide d'une variable, telle que `{year}/Sales`, est vérifiée selon la valeur de la variable au moment de l'enregistrement, et la boîte de dialogue nomme la table vérifiée, par exemple `2026/Sales (from {year}/Sales)`. Une variable définie par une boucle contient la valeur de sa dernière itération ; une boucle sur des tables de formes différentes peut donc avertir à propos d'une table que la prochaine exécution ne lira pas. Une table qui n'existe pas encore, par exemple une table créée par une étape antérieure du workflow, n'est pas vérifiée, pas plus qu'une source dont la variable n'a pas de valeur, qu'une table que l'étape trouve par recherche à l'exécution ou qu'une table qui ne peut pas être lue pour le moment.
