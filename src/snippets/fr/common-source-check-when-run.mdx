#### Lorsque l'étape s'exécute

Les étapes Table Extract, Table Lookup, Table Inner Join, Table Cross Join, Table Outer Join, Table Anti Join, Jointure multi-tables, Table Union Distinct, Table Union All, Table Pivot, Table Melt, Table In-Place Delete, Table Upsert et Table Append vérifient leurs tables source lorsqu'elles s'exécutent, avant d'écrire quoi que ce soit. La vérification compare la requête que l'étape a construite avec chaque table source telle qu'elle est à ce moment-là :

- Une colonne que l'étape lit et que la table n'a pas, une clé de jointure que la table n'a pas ou qui ne figure pas dans les colonnes source de l'étape, ou une table source que l'étape lit et qui n'a pas été construite arrête l'étape. Une seule erreur nomme chaque problème, avec sa propre correction. Une table cible qui existait déjà reste telle qu'elle était, et celle que l'étape a dû créer reste vide.
- Une colonne que l'étape liste sans la lire, et que la table n'a plus, ajoute un avertissement. L'étape s'exécute sans elle.
- Table Union Distinct et Table Union All font exception pour une table source qui n'a pas été construite : elles l'écartent, sans avertissement, et combinent les autres, comme auparavant. Si aucune de leurs tables source n'a été construite, elles se terminent par un avertissement au lieu d'échouer.

Une étape dont la cible est une vue ne fait que créer la vue ; les colonnes et les clés de jointure qu'elle liste ne sont donc vérifiées par rapport à ses tables que lorsque l'entrepôt refuserait de toute façon de créer cette vue. Dans les autres cas, seule une table source qui n'a pas été construite ou une clé de jointure que l'étape ne liste pas l'arrête, et aucun avertissement n'est ajouté.

Lorsque c'est possible, l'erreur nomme l'étape qui construit une table, et lorsque la table possède une colonne dont le nom ressemble à celui d'une colonne manquante, par exemple qui n'en diffère que par la casse, elle nomme aussi cette colonne.
