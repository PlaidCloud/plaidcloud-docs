### Table cible

La sélection de la cible pour les importations est limitée aux tables, car les vues ne contiennent pas de données sous-jacentes.

#### Option dynamique

L'option dynamique permet de spécifier une table à l'aide de texte, y compris des variables. C'est utile dans les workflows pilotés par des variables, où les références de tables et de vues sont relatives aux variables spécifiées.

Exemple qui utilise la variable `current_month` pour pointer dynamiquement vers la table cible :

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>Si la table n'existe pas, elle est créée dynamiquement lors de l'exécution de l'importation</Aside>

#### Option statique

Lorsque vous souhaitez une table précise comme cible de l'importation, laissez la case *Dynamique* décochée et sélectionnez la table cible.

Si la table cible n'existe pas, sélectionnez le bouton *Créer* pour créer la table à l'emplacement souhaité.

L'Explorateur de tables est toujours disponible pour toute sélection de table. Cliquez sur le bouton Explorateur de tables à droite de la sélection de table : une fenêtre Explorateur de tables s'ouvre.
