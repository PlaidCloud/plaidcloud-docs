### Option de suppression des fichiers après l'importation

Cette option permet au processus d'importation de supprimer le fichier du compte de documents PlaidCloud Document une fois l'importation terminée avec succès.

Elle peut être utile si les fichiers d'importation sont générés et peuvent être recréés à partir d'un système de référence, ou s'il n'y a aucune raison de conserver les fichiers d'entrée bruts
une fois qu'ils ont été traités.

Seuls les fichiers importés sont supprimés. Un fichier ignoré ou qui a produit un avertissement pendant l'importation reste dans le dossier.
