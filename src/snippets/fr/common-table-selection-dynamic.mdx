## Sélection des tables


Il existe deux options pour sélectionner la table ou, avec la seconde option, les tables à utiliser :

La première option consiste à utiliser la liste déroulante ***Table spécifique*** pour sélectionner la table.

La seconde consiste à utiliser l'option ***Tables correspondant à la recherche***, dans laquelle vous indiquez le **Chemin de recherche** et le **Texte de recherche** pour sélectionner la ou les tables qui correspondent aux critères de recherche. 
Cette option est très utile si vous avez un workflow qui crée une série de tables portant des noms communs, enregistrées avec la date en suffixe.
