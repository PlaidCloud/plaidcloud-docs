### Source et cible

![Source et cible](/images/table_source_and_target_EN.png)

Pour définir les tables source et cible, sélectionnez d'abord la table de données dont extraire les données avec le menu déroulant **Table source**. Sélectionnez ensuite soit une table existante comme table cible avec le menu déroulant **Table cible**, soit cliquez sur le signe **« + »** vert pour créer une nouvelle table comme cible. 

#### Création de table
Lorsque vous créez une nouvelle table, vous pouvez la créer soit comme une **Vue**, soit comme une **Table**. 
##### Vues :
Les vues sont utiles car le temps d'exécution d'une étape est nettement inférieur à celui d'une étape qui utilise une table. L'inconvénient des vues est qu'elles ne sont pas pratiques pour l'exploration des données dans le mode Détails de la table.

##### Tables :
Lorsqu'une table sert de cible, l'exécution d'une étape est plus longue, mais l'exploration des données en mode Détails est beaucoup plus rapide qu'avec une vue.

<Aside>Utilisez des tables pour les étapes clés de vos workflows, là où la validation des données ou la possibilité d'effectuer des analyses ad hoc sera nécessaire. Pour toutes les autres étapes, utilisez des vues afin de réduire le temps de calcul global du workflow. Il est possible de transformer une table en vue et inversement ; vous pouvez donc toujours modifier ultérieurement le type de la cible.</Aside>
