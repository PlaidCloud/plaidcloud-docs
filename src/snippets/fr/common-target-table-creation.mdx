### Table cible

![Table cible](/images/table_target_table.png)

Pour définir la table cible, sélectionnez une table existante à l'aide de la liste déroulante **Table cible**, ou cliquez sur le signe **« + »** vert pour créer une nouvelle table cible. 

#### Création de table
Lorsque vous créez une nouvelle table, vous pouvez la créer soit comme **Vue**, soit comme **Table**. 
##### Vues :
Les vues sont utiles car le temps d'exécution d'une étape est nettement inférieur à celui d'une étape qui utilise une table. L'inconvénient des vues est qu'elles se prêtent moins à l'exploration des données dans le mode Détails de la table.

##### Tables :
Lorsque la cible est une table, l'exécution d'une étape prend plus de temps, mais l'exploration des données dans le mode Détails est bien plus rapide qu'avec une vue.

<Aside>Utilisez des tables pour les étapes clés de vos workflows, lorsque la validation des données ou la possibilité d'effectuer des analyses ad hoc sera nécessaire. Pour toutes les autres étapes, utilisez des vues afin de réduire le temps de calcul global du workflow. Il est possible de convertir une table en vue et inversement ; vous pouvez donc toujours modifier plus tard le type de la table cible.</Aside>
