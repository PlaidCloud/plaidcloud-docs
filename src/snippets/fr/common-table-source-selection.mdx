### Table source


Indiquez la table de données source en la sélectionnant dans le menu déroulant.

### Colonnes source


Indiquez ici les colonnes à inclure. En sélectionnant les boutons **Inspecter la source** et **Populate Source Mapping Table**, vous rendez ces colonnes disponibles pour l'opération de jointure.

### Sélectionner un sous-ensemble des données source


Toute expression Python valide peut servir à créer un sous-ensemble des données. Pour plus de détails et d'exemples, consultez [Expressions](/fr/reference/expressions/).
