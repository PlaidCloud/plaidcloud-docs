Spécifiez les conditions de jointure. **Deviner** renseigne le **Mappage des champs de jointure entre les tables** à partir de la première de ces sources que les colonnes des deux tables peuvent fournir :

- les clés d'une autre étape de jointure de ce projet qui joint les deux mêmes tables
- les clés d'une métrique approuvée qui les joint
- les colonnes de clé définies sur l'une des tables, mises en correspondance dans l'autre par nom, ou sinon par l'unique colonne liée au même [élément de projet](/fr/guides/projects/data-model/)
- les éléments pour lesquels les deux tables ont une colonne, comme décrit ci-dessous
- les colonnes de même nom dans les deux tables
- les colonnes dont les noms ne diffèrent que par les majuscules ou les tirets bas, ou une colonne `id` mise en correspondance avec une colonne nommée d'après sa table, telle que `customer_id` pour une table nommée *Customers*

Une ligne sous le mappage indique laquelle a été utilisée, jusqu'à ce que vous modifiiez le mappage. Deviner lit les colonnes des tables, pas leurs lignes ; vérifiez donc les clés avant d'enregistrer. **Inspecter la source** renseigne un **Mappage des champs de jointure entre les tables** vide de la même façon.

**Clés issues d'éléments partagés.** Une colonne appartient à un élément lorsque son nom est celui de l'élément ou l'un de ses alias. Pour chaque élément pour lequel les deux tables ont une colonne, Deviner associe l'unique colonne de chaque côté, même si leurs noms diffèrent. Lorsqu'une table a plusieurs colonnes pour l'élément, Deviner associe celle dont le nom est commun aux deux tables, et sinon laisse cet élément de côté. Deux colonnes dont les types sont de natures différentes, comme un texte et une date, ne sont pas associées. Lorsqu'une seule des tables est nommée d'après un élément partagé, la jointure se fait sur cet élément seul. Une table est nommée d'après un élément lorsque son nom, sans tenir compte des majuscules, est le nom de l'élément, ce nom suivi d'un `s`, ou l'un ou l'autre après un seul mot et un tiret bas, comme `customer`, `customers` ou `dim_customer`. Un nom plus long, comme `sales_by_customer`, ne compte pas, pas plus qu'un nom dont le premier mot est lui-même un élément, comme `customer_product`. La ligne sous le mappage nomme les éléments, par exemple *Ces clés sont les éléments que les deux tables partagent : customer, period.* Lorsqu'aucun élément ne donne de paire, Deviner passe aux colonnes de même nom.

La détection par élément a deux limites :

- Elle n'associe que des colonnes qui appartiennent à un élément, et n'ajoute aucune colonne de même nom à côté. Lorsque la clé d'une table se compose de plusieurs colonnes dont certaines ne sont pas des éléments, comme celles d'un calendrier fiscal, Deviner ne propose que les colonnes d'élément ; ajoutez les autres vous-même.
- Une table dont le nom est un mot suivi d'un tiret bas puis du nom d'un élément est considérée comme la table propre à cet élément même si ce n'est pas le cas, comme `ar_customer` ou `bank_account` ; lorsque cette table est la seule nommée d'après un élément partagé, la jointure est proposée sur cet élément seul.

**Éléments dans le mappage.** Chaque colonne du mappage de jointure qui appartient à un élément affiche le nom de l'élément sous forme de pastille à côté d'elle. Survolez la pastille pour voir l'élément, sa description et la dimension qu'il fournit. Les remarques sous le mappage vous conseillent mais ne vous empêchent jamais d'enregistrer l'étape :

- Une ligne qui associe des colonnes de deux éléments différents reçoit une remarque, comme *La ligne 2 associe des éléments différents : customer et vendor.*
- Lorsque **Deviner** ne trouve aucune clé, la remarque *Aucune clé probable trouvée.* comporte un lien **Modèle de données** qui ferme l'étape et ouvre la page [Modèle de données](/fr/guides/projects/data-model/) du projet, où vous pouvez décrire sous forme d'éléments les colonnes que vos tables partagent. Lorsque l'étape comporte des modifications non enregistrées, il vous est d'abord demandé si vous voulez les abandonner.

Pour ajouter des colonnes manuellement, faites un clic droit n'importe où dans la section et sélectionnez **Insérer une ligne** ou **Ajouter une ligne**, afin d'ajouter une ligne avant la ligne actuellement sélectionnée ou à la fin, respectivement. Choisissez ensuite les colonnes à faire correspondre sous **Champ table1** et **Champ table2**. Pour retirer un champ du **Mappage des champs de jointure entre les tables**, faites simplement un clic droit et sélectionnez **Supprimer**.
