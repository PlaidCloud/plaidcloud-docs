Spécifiez les conditions de jointure. **Deviner** renseigne la **Join Map** à partir de la première de ces sources que les colonnes des deux tables peuvent fournir :

- les clés d'une autre étape de jointure de ce projet qui joint les deux mêmes tables
- les clés d'une métrique approuvée qui les joint
- les colonnes de clé définies sur l'une des tables, mises en correspondance par nom dans l'autre
- les colonnes de même nom dans **Table 1** et **Table 2**
- les colonnes dont les noms ne diffèrent que par les majuscules ou les tirets bas, ou une colonne `id` mise en correspondance avec une colonne nommée d'après sa table, telle que `customer_id` pour une table nommée *Customers*

Une ligne sous le mappage indique laquelle a été utilisée, jusqu'à ce que vous modifiiez le mappage. Deviner lit les colonnes des tables, pas leurs lignes ; vérifiez donc les clés avant d'enregistrer. **Inspecter la source** renseigne une **Join Map** vide de la même façon.

Pour ajouter des colonnes manuellement, faites un clic droit n'importe où dans la section et sélectionnez **Insérer une ligne** ou **Ajouter une ligne**, afin d'ajouter une ligne avant la ligne actuellement sélectionnée ou à la fin, respectivement. Saisissez ensuite les noms de colonnes à faire correspondre de **Table 1** à **Table 2**. Pour retirer un champ de la **Join Map**, faites simplement un clic droit et sélectionnez **Supprimer**.
