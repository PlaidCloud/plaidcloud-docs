### Dateiauswahl für den Import

Mit der Dateiauswahl in dieser Transformation wählen Sie eine Datei, die an einem PlaidCloud-Dokumentspeicherort liegt, zum Import aus.

Sie können auch ein Verzeichnis wählen. Dann werden alle Dateien in diesem Verzeichnis bei der Ausführung der Transformation importiert.

<Aside type="caution">Wenn Sie ein Verzeichnis zum Import wählen, stellen Sie sicher, dass alle Dateien dasselbe Format haben.</Aside>

#### Dokumentenkonto auswählen

Wählen Sie ein PlaidCloud-Dokumentenkonto, auf das Sie Zugriff haben. Anschließend können Sie in der nächsten Auswahl ein Verzeichnis oder eine Datei wählen.

Innerhalb eines Projekts bietet die Liste oben auch **Projektstandard** an, einen Platzhalter für das Konto, das im Projekt aktuell als Standard festgelegt ist. Ein neuer Schritt wählt „Projektstandard“ vorab aus, wenn das Projekt einen hat. Ein bestehender Schritt behält das Konto, mit dem er gespeichert wurde, bis Sie es ändern. Ein Schritt, der auf „Projektstandard“ steht, wird mit dem Konto ausgeführt, das zum Zeitpunkt der Ausführung der Projektstandard ist. Ist keiner festgelegt, schlägt die Ausführung fehl und nennt das Projekt, anstatt auf ein anderes Konto auszuweichen.

#### Option „Suchen“

Mit der Option **Suchen** finden Sie alle passenden Dateien unterhalb eines angegebenen Verzeichnispfads zum Import. Das ist besonders nützlich, wenn viele Dateien einbezogen werden sollen, aber in verschachtelten Verzeichnissen liegen oder mit anderen Dateien im selben Verzeichnis vermischt sind, die Sie nicht importieren möchten.

<Aside>Wenn Sie für Dateien ähnlicher Art und ähnlichen Zwecks eine einheitliche Namenskonvention verwenden, können Sie einen einzigen Importschritt nutzen.</Aside>

Der ausgewählte Suchpfad ist das Startverzeichnis der Suche. Die Suche berücksichtigt alle Dateien in diesem Verzeichnis sowie in den Unterverzeichnissen, die den angegebenen Suchbedingungen entsprechen. Stellen Sie sicher, dass sich die Suchkriterien auch auf die Dateien in den Unterverzeichnissen anwenden lassen.

Die Suche kann mit den folgenden Bedingungen erfolgen:
 * **Exakt**: Der Suchtext muss genau übereinstimmen.
 * **Beginnt mit**: Findet jede Datei, die mit dem Suchtext beginnt.
 * **Enthält**: Findet jede Datei, die den Suchtext enthält.
 * **Endet mit**: Findet jede Datei, die mit dem Suchtext endet.

Ein KI-Assistent oder die REST-API kann die Suche außerdem auf `glob` setzen, ein Platzhaltermuster wie `CO Store*.yxdb`, das ohne Beachtung der Groß-/Kleinschreibung mit dem gesamten Dateinamen verglichen wird, oder auf `regex`, einen regulären Ausdruck, dem der gesamte Dateiname entsprechen muss. Ein regulärer Ausdruck unterscheidet zwischen Groß- und Kleinschreibung, es sei denn, er beginnt mit `(?i)`.

#### Option „Datei oder Verzeichnis auswählen“

Wenn eine bestimmte Datei oder ein bestimmtes Verzeichnis mit Dateien importiert werden soll, ist die direkte Auswahl der Datei oder des Verzeichnisses besser als die Suche.

Um die Datei oder das Verzeichnis auszuwählen, wählen Sie über die Schaltfläche „Durchsuchen“ den Pfad im oben gewählten Dokumentenkonto.

#### Variablenersetzung

Sowohl bei der Suche als auch bei der Auswahl einer bestimmten Datei oder eines bestimmten Verzeichnisses können Sie Variablen im Pfad, im Suchtext und in Dateinamen verwenden.

Ein Beispiel, das die Variable `current_month` verwendet, um dynamisch auf die richtige Datei zu verweisen:

```
legal_entity/inputs/{current_month}/ledger_values.csv
```
