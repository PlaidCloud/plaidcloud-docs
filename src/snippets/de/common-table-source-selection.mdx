### Tabellenquelle


Geben Sie die Quelldatentabelle an, indem Sie sie im Dropdown-Menü auswählen.

### Quellspalten


Geben Sie hier die Spalten an, die einbezogen werden sollen. Über die Schaltflächen **Quelle untersuchen** und **Quellzuordnungstabelle füllen** werden diese Spalten für die Join-Operation verfügbar.

### Teilmenge der Quelldaten auswählen


Zur Auswahl einer Teilmenge der Daten ist jeder gültige Python-Ausdruck zulässig. Weitere Details und Beispiele finden Sie unter [Ausdrücke](/de/reference/expressions/).
