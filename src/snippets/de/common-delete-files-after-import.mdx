### Option „Dateien nach dem Import löschen“

Mit dieser Option löscht der Importvorgang die Datei nach einem erfolgreichen Import aus dem PlaidCloud-Dokumentenkonto.

Das ist nützlich, wenn die Importdateien aus einem führenden System neu erzeugt werden können oder es keinen Grund gibt, die Rohdateien nach ihrer Verarbeitung aufzubewahren.

Es werden nur Dateien gelöscht, die importiert wurden. Eine Datei, die übersprungen wurde oder beim Import eine Warnung ausgelöst hat, verbleibt im Ordner.
