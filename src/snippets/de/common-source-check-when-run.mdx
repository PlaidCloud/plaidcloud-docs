#### Wenn der Schritt ausgeführt wird

Die Schritte Table Extract, Table Lookup, Table Inner Join, Table Cross Join, Table Outer Join, Table Anti Join, Mehrtabellen-Join, Table Union Distinct, Table Union All, Table Pivot, Table Melt, Table In-Place Delete, Table Upsert und Table Append prüfen ihre Quelltabellen bei der Ausführung, bevor sie etwas schreiben. Die Prüfung vergleicht die Abfrage, die der Schritt erstellt hat, mit jeder Quelltabelle in ihrem aktuellen Zustand:

- Eine Spalte, die der Schritt liest und die die Tabelle nicht hat, ein Join-Schlüssel, den die Tabelle nicht hat oder der nicht in den Quellspalten des Schritts steht, oder eine Quelltabelle, die der Schritt liest und die noch nicht erstellt wurde, stoppt den Schritt. Ein Fehler nennt jedes Problem mit der jeweiligen Behebung. Eine bereits vorhandene Zieltabelle bleibt unverändert, und eine, die der Schritt erst anlegen musste, bleibt leer.
- Eine Spalte, die der Schritt aufführt, aber nicht liest und die die Tabelle nicht mehr hat, löst eine Warnung aus. Der Schritt läuft ohne sie weiter.
- Table Union Distinct und Table Union All sind die Ausnahme bei einer Quelltabelle, die noch nicht erstellt wurde: Sie lassen sie ohne Warnung weg und vereinigen die übrigen, wie bisher. Wurde keine ihrer Quelltabellen erstellt, werden sie mit einer Warnung beendet, statt fehlzuschlagen.

Ein Schritt, dessen Ziel eine Ansicht ist, erstellt nur die Ansicht. Die Spalten und Join-Schlüssel, die er aufführt, werden daher nur dort mit seinen Tabellen abgeglichen, wo das Warehouse die Erstellung dieser Ansicht ohnehin verweigern würde. Andernfalls stoppt ihn nur eine Quelltabelle, die noch nicht erstellt wurde, oder ein Join-Schlüssel, den der Schritt nicht aufführt, und es wird keine Warnung hinzugefügt.

Wo möglich, nennt der Fehler den Schritt, der eine Tabelle erstellt, und wenn die Tabelle eine Spalte mit einem ähnlichen Namen wie eine fehlende hat, etwa einem, der sich nur in der Groß- und Kleinschreibung unterscheidet, nennt er auch diese Spalte.
