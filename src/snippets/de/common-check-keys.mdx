**Schlüssel prüfen** neben **Erraten** zählt die Schlüsselwerte in der **Join Map**, die in mehr als einer Zeile einer Tabelle vorkommen. Wiederholt sich ein Schlüsselwert in der Tabelle, mit der Sie verknüpfen, erscheint jede passende Zeile so oft im Ergebnis, wie sie Treffer hat. Das Ergebnis kann daher mehr Zeilen enthalten als die Tabelle, mit der Sie begonnen haben.

Welche Tabelle geprüft wird, hängt vom Schritt ab:

- **Inner Join** und **Table Lookup**: Tabelle 2.
- **Outer Join**: Tabelle 2 bei einem Left Join, Tabelle 1 bei einem Right Join und beide Tabellen bei einem Full Join.

Das Ergebnis erscheint unter der **Join Map**. Es nennt die Anzahl der wiederholten Schlüsselwerte und der Zeilen, die sie gemeinsam haben, und führt bis zu fünf der am häufigsten wiederholten Werte auf. Gezählt werden:

- die Tabelle in ihrem aktuellen Zustand, nach dem Filter dieses Schritts für diese Tabelle;
- nur die Zeilen, die Sie sehen können, wenn die Sicherheit auf Zeilenebene einschränkt, was Sie von der Tabelle sehen. Das Ergebnis weist darauf hin;
- keine Zeilen mit leerem Schlüssel, da ein leerer Schlüssel nie mit einer anderen Zeile übereinstimmt. Eine Ausnahme ist ein Inner oder Outer Join, der so eingestellt ist, dass leere Schlüssel einander entsprechen, wie es bei einem aus Alteryx konvertierten Join der Fall sein kann: Dort zählen leere Schlüssel als Schlüsselwert und können als **(leer)** aufgeführt werden.

**Table Lookup** wiederholt nie eine Zeile. Bei einem wiederholten Schlüssel behält es eine Zeile aus Tabelle 2 und nimmt dabei für jede Spalte den niedrigsten Wert (die kleinste Zahl, das früheste Datum, den ersten Text in der Sortierreihenfolge). Diese Zeile kann daher Werte aus verschiedenen Zeilen von Tabelle 2 mischen. „Schlüssel prüfen“ weist darauf hin, wenn das passiert. Wenn Sie steuern möchten, welche Werte verwendet werden, sorgen Sie dafür, dass jeder Schlüssel in Tabelle 2 nur einmal vorkommt.

Die Prüfung liest die Tabelle in Ihrem Warehouse. Sie läuft deshalb nur, wenn Sie sie auswählen, und endet nach 30 Sekunden. Wenn Sie eine der beiden Tabellen, ihren Filter, die **Join Map** oder bei Outer Join den **Verknüpfungstyp** ändern, wird das Ergebnis gelöscht.
