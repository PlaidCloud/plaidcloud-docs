Legen Sie die Join-Bedingungen fest. **Erraten** füllt die **Join Map** mit der ersten der folgenden Möglichkeiten, die sich aus den Spalten der beiden Tabellen ergibt:

- die Schlüssel eines anderen Join-Schritts in diesem Projekt, der dieselben beiden Tabellen verknüpft
- die Schlüssel einer genehmigten Kennzahl, die sie verknüpft
- die Schlüsselspalten, die für eine der Tabellen festgelegt sind, in der anderen Tabelle nach Namen zugeordnet oder andernfalls über die eine Spalte, die an dasselbe [Projektelement](/de/guides/projects/data-model/) gebunden ist
- die Elemente, für die beide Tabellen eine Spalte haben, wie unten beschrieben
- die Spalten mit demselben Namen in **Tabelle 1** und **Tabelle 2**
- Spalten, deren Namen sich nur in der Groß-/Kleinschreibung oder durch Unterstriche unterscheiden, oder eine Spalte `id`, die einer nach ihrer Tabelle benannten Spalte zugeordnet wird, etwa `customer_id` für eine Tabelle namens *Customers*

Eine Zeile unter der Zuordnung zeigt, welche Möglichkeit verwendet wurde, bis Sie die Zuordnung ändern. „Erraten“ liest die Spalten der Tabellen, nicht ihre Zeilen. Prüfen Sie daher die Schlüssel, bevor Sie speichern. **Quelle untersuchen** füllt eine leere **Join Map** auf dieselbe Weise.

**Schlüssel aus gemeinsamen Elementen.** Eine Spalte gehört zu einem Element, wenn ihr Name der Name des Elements oder einer seiner Aliase ist. Für jedes Element, für das beide Tabellen eine Spalte haben, ordnet „Erraten“ die eine Spalte auf jeder Seite zu, auch wenn ihre Namen sich unterscheiden. Hat eine Tabelle mehrere Spalten für das Element, ordnet „Erraten“ den einen Namen zu, den beide Tabellen haben, und lässt dieses Element andernfalls aus. Zwei Spalten, deren Typen verschiedenen Arten angehören, etwa Text und Datum, werden nicht zugeordnet. Ist genau eine der Tabellen nach einem gemeinsamen Element benannt, erfolgt der Join allein über dieses Element. Eine Tabelle ist nach einem Element benannt, wenn ihr Name, ohne Beachtung der Groß-/Kleinschreibung, der Name des Elements ist, dieser Name mit einem `s` oder jeder von beiden nach einem einzelnen Wort und einem Unterstrich, etwa `customer`, `customers` oder `dim_customer`. Ein längerer Name wie `sales_by_customer` zählt nicht, ebenso wenig einer, dessen erstes Wort selbst ein Element ist, etwa `customer_product`. Die Zeile unter der Zuordnung nennt die Elemente, etwa *These keys are the elements both tables share: customer, period.* Ergibt kein Element ein Paar, geht „Erraten“ zu den Spalten mit demselben Namen über.

Die Elementvermutung hat zwei Grenzen:

- Sie ordnet nur Spalten zu, die zu einem Element gehören, und fügt keine gleichnamigen Spalten daneben hinzu. Besteht der Schlüssel einer Tabelle aus mehreren Spalten und gehören einige nicht zu einem Element, etwa die eines Geschäftskalenders, schlägt „Erraten“ nur die Elementspalten vor; ergänzen Sie die übrigen selbst.
- Eine Tabelle, deren Name aus einem Wort und einem Unterstrich vor dem Namen eines Elements besteht, gilt als die eigene Tabelle dieses Elements, auch wenn sie es nicht ist, etwa `ar_customer` oder `bank_account`; ist sie die einzige Tabelle, die nach einem gemeinsamen Element benannt ist, wird der Join allein über dieses Element vorgeschlagen.

**Elemente in der Zuordnung.** Jede Spalte in der Join-Zuordnung, die zu einem Element gehört, zeigt den Namen des Elements als Pill daneben. Bewegen Sie den Mauszeiger über die Pill, um das Element, seine Beschreibung und die Dimension zu sehen, die es liefert. Hinweise unter der Zuordnung beraten Sie, hindern Sie aber nie am Speichern des Schritts:

- Eine Zeile, die Spalten zweier verschiedener Elemente paart, erhält einen Hinweis, etwa *Zeile 2 verbindet unterschiedliche Elemente: customer und vendor.*
- Findet **Erraten** keine Schlüssel, enthält der Hinweis *Keine wahrscheinlichen Schlüssel gefunden.* einen Link **Datenmodell**, der die Seite [Datenmodell](/de/guides/projects/data-model/) des Projekts öffnet, auf der Sie die Spalten, die Ihre Tabellen gemeinsam haben, als Elemente beschreiben können.

Um weitere Spalten manuell hinzuzufügen, klicken Sie an einer beliebigen Stelle im Bereich mit der rechten Maustaste und wählen Sie **Zeile einfügen** oder **Zeile anhängen**, um eine Zeile vor der aktuell ausgewählten Zeile bzw. am Ende einzufügen. Geben Sie dann die Spaltennamen ein, die **Tabelle 1** und **Tabelle 2** zugeordnet werden sollen. Um ein Feld aus der **Join Map** zu entfernen, klicken Sie mit der rechten Maustaste und wählen **Löschen**.
