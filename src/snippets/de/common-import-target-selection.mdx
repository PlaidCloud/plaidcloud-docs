### Zieltabelle

Als Importziel können nur Tabellen gewählt werden, da Ansichten keine zugrunde liegenden Daten enthalten.

#### Option „Dynamisch“

Mit der Option „Dynamisch“ geben Sie eine Tabelle als Text an, auch mit Variablen. Das ist nützlich bei variablengesteuerten Workflows, in denen sich Verweise auf Tabellen und Ansichten nach den angegebenen Variablen richten.

Ein Beispiel, das die Variable `current_month` verwendet, um dynamisch auf die Zieltabelle zu verweisen:

```
legal_entity/inputs/{current_month}/ledger_values
```

<Aside>Wenn die Tabelle nicht existiert, wird sie beim Ausführen des Imports dynamisch erstellt.</Aside>

#### Option „Statisch“

Wenn eine bestimmte Tabelle als Ziel für den Import dienen soll, lassen Sie das Kontrollkästchen *Dynamisch* deaktiviert und wählen Sie die Zieltabelle aus.

Wenn die Zieltabelle nicht existiert, wählen Sie die Schaltfläche *Neu erstellen*, um die Tabelle am gewünschten Speicherort anzulegen.

Der Tabellen-Explorer steht bei jeder Tabellenauswahl zur Verfügung. Klicken Sie auf die Schaltfläche „Tabellen-Explorer“ rechts neben der Tabellenauswahl, um ein Tabellen-Explorer-Fenster zu öffnen.
