### Dateiauswahl für den Export

![Dateiauswahl für den Export](/images/export_file_source_target.png)

Mit der Dateiauswahl in dieser Transformation wählen Sie ein Ziel in einem PlaidCloud-Dokument, in dem das exportierte Ergebnis gespeichert wird.

Sie wählen ein Verzeichnis und geben einen Dateinamen für die Zieldatei an.


### Quelltabelle


#### Option „Dynamisch“

Mit der Option „Dynamisch“ geben Sie eine Tabelle als Text an, auch mit Variablen. Das ist nützlich bei variablengesteuerten Workflows, in denen sich Verweise auf Tabellen und Ansichten nach den angegebenen Variablen richten.

Ein Beispiel, das die Variable `current_month` verwendet, um dynamisch auf die Quelltabelle zu verweisen:

```
legal_entity/inputs/{current_month}/ledger_values
```

#### Option „Statisch“

Wenn eine bestimmte Tabelle als Quelle für den Export dienen soll, lassen Sie das Kontrollkästchen *Dynamisch* deaktiviert und wählen Sie die Quelltabelle aus.


Der Tabellen-Explorer steht bei jeder Tabellenauswahl zur Verfügung. Klicken Sie auf die Schaltfläche „Tabellen-Explorer“ rechts neben der Tabellenauswahl, um ein Tabellen-Explorer-Fenster zu öffnen.



#### Dokumentenkonto auswählen

Wählen Sie ein PlaidCloud-Dokumentenkonto, auf das Sie Zugriff haben. Anschließend können Sie in der nächsten Auswahl ein Verzeichnis wählen.

Innerhalb eines Projekts bietet die Liste oben auch **Projektstandard** an, einen Platzhalter für das Konto, das im Projekt aktuell als Standard festgelegt ist. Ein neuer Schritt wählt „Projektstandard“ vorab aus, wenn das Projekt einen hat. Ein bestehender Schritt behält das Konto, mit dem er gespeichert wurde, bis Sie es ändern. Ein Schritt, der auf „Projektstandard“ steht, wird mit dem Konto ausgeführt, das zum Zeitpunkt der Ausführung der Projektstandard ist. Ist keiner festgelegt, schlägt die Ausführung fehl und nennt das Projekt, anstatt auf ein anderes Konto auszuweichen.

#### Zielverzeichnispfad

Wählen Sie das Symbol ***Durchsuchen*** rechts neben dem ***Zielverzeichnispfad*** und navigieren Sie zu dem Speicherort, an dem die Datei gespeichert werden soll.

#### Zieldateiname

Geben Sie den Namen an, unter dem die exportierte Datei gespeichert werden soll.
