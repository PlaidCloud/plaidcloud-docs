### Zieltabelle

![Zieltabelle](/images/table_target_table.png)

Um die Zieltabelle festzulegen, wählen Sie entweder über die Dropdown-Liste **Zieltabelle** eine vorhandene Tabelle als Ziel oder klicken auf das grüne **„+“**, um eine neue Tabelle als Ziel zu erstellen.

#### Tabelle erstellen
Beim Erstellen einer neuen Tabelle können Sie wählen, ob sie als **Ansicht** oder als **Tabelle** erstellt wird.
##### Ansichten:
Ansichten sind nützlich, weil die Ausführungszeit eines Schritts deutlich kürzer ist als bei einer Tabelle. Der Nachteil von Ansichten ist, dass sie sich in der Detailansicht der Tabelle weniger gut zur Datenexploration eignen.

##### Tabellen:
Wenn eine Tabelle als Ziel verwendet wird, dauert die Ausführung eines Schritts länger, dafür ist die Datenexploration in der Detailansicht deutlich schneller als bei einer Ansicht.

<Aside>Verwenden Sie Tabellen für zentrale Schritte Ihrer Workflows, bei denen eine Datenvalidierung oder Ad-hoc-Analysen nötig sind. Verwenden Sie für alle übrigen Schritte Ansichten, um die Gesamtberechnungszeit des Workflows zu verkürzen. Eine Tabelle lässt sich in eine Ansicht umwandeln und umgekehrt, sodass Sie den Zieltabellentyp später jederzeit ändern können.</Aside>
