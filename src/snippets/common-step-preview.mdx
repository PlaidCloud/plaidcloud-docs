### Preview

Click **Preview** on the **Source** tab to see up to 100 rows of what the step would read, without running it. If the result is longer, the preview says it shows the first rows and that you need to run the step to read them all.

Preview fills in project and workflow variables the same way a run does. It doesn't support variable formats such as `{x:>9}`, and it can't fill in a variable that only has a value during a run, such as a trigger value.

Preview only reads data. It refuses a query that could change anything and shows a message instead of rows:

- **Preview only supports standard SQL functions. Run the step to see results.** The query uses a function Preview can't check as read-only. Run the step to see the result.
- A query that isn't a single `SELECT`, or whose variables expand to a statement that writes, is refused.

Preview isn't available on a locked project, on SQL Server, Oracle or SQLite connections, or for steps that run through an Agent, such as [Agent Remote Execution of SQL](/reference/workflow-steps/agent/agent-remote-execution-of-sql/).
