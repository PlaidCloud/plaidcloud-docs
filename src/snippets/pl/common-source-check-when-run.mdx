#### Kiedy krok jest uruchamiany

Kroki Table Extract, Table Lookup, Table Inner Join, Table Cross Join, Table Outer Join, Table Anti Join, Złączenie wielu tabel, Table Union Distinct, Table Union All, Table Pivot, Table Melt, Table In-Place Delete, Table Upsert i Table Append sprawdzają swoje tabele źródłowe podczas uruchomienia, zanim cokolwiek zapiszą. Sprawdzenie porównuje zapytanie zbudowane przez krok z każdą tabelą źródłową w jej stanie z tej chwili:

- Kolumna, którą krok odczytuje, a której nie ma w tabeli, klucz złączenia, którego tabela nie ma lub którego nie ma w kolumnach źródłowych kroku, albo tabela źródłowa odczytywana przez krok, która nie została zbudowana, zatrzymują krok. Jeden błąd wymienia każdy problem wraz z jego własnym sposobem naprawy. Tabela docelowa, która już istniała, pozostaje bez zmian, a ta, którą krok musiał utworzyć, pozostaje pusta.
- Kolumna, którą krok wymienia, ale nie odczytuje, a której tabela już nie ma, dodaje ostrzeżenie. Krok działa bez niej.
- Wyjątkiem są Table Union Distinct i Table Union All w przypadku tabeli źródłowej, która nie została zbudowana: tak jak dotąd pomijają ją bez ostrzeżenia i łączą pozostałe. Jeśli żadna z ich tabel źródłowych nie została zbudowana, kończą się ostrzeżeniem zamiast błędem.

Krok, którego celem jest widok, tylko tworzy ten widok, więc wymienione w nim kolumny i klucze złączenia są sprawdzane względem jego tabel tylko tam, gdzie hurtownia danych i tak odmówiłaby utworzenia tego widoku. W pozostałych przypadkach zatrzymuje go wyłącznie tabela źródłowa, która nie została zbudowana, lub klucz złączenia, którego krok nie wymienia, i nie jest dodawane żadne ostrzeżenie.

Tam, gdzie to możliwe, błąd wymienia krok, który buduje tabelę, a gdy tabela ma kolumnę o nazwie zbliżonej do brakującej, na przykład różniącej się tylko wielkością liter, wymienia także tę kolumnę.
