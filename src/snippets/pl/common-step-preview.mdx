### Podgląd

Kliknij **Podgląd** na karcie **Źródło**, aby zobaczyć do 100 wierszy tego, co krok odczytałby, bez jego uruchamiania. Jeśli wynik jest dłuższy, podgląd informuje, że pokazuje pierwsze wiersze i że aby odczytać wszystkie, trzeba uruchomić krok.

Podgląd podstawia zmienne projektu i przepływu pracy tak samo jak uruchomienie. Nie obsługuje formatów zmiennych, takich jak `{x:>9}`, i nie potrafi podstawić zmiennej, która ma wartość tylko podczas uruchomienia, na przykład wartości wyzwalacza.

Podgląd tylko odczytuje dane. Odrzuca zapytanie, które mogłoby cokolwiek zmienić, i zamiast wierszy pokazuje komunikat:

- **Preview only supports standard SQL functions. Run the step to see results.** Zapytanie używa funkcji, której Podgląd nie może sprawdzić jako tylko do odczytu. Uruchom krok, aby zobaczyć wynik.
- Zapytanie, które nie jest pojedynczym `SELECT` albo którego zmienne rozwijają się do instrukcji zapisującej, jest odrzucane.

Podgląd nie jest dostępny w zablokowanym projekcie, w połączeniach SQL Server, Oracle ani SQLite, ani w krokach uruchamianych przez agenta, takich jak [krok Agent Remote Execution of SQL](/pl/reference/workflow-steps/agent/agent-remote-execution-of-sql/).
