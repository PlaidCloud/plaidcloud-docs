#### 步骤运行时

Table Extract、Table Lookup、Table Inner Join、Table Cross Join、Table Outer Join、Table Anti Join、多表联接、Table Union Distinct、Table Union All、Table Pivot、Table Melt、Table In-Place Delete、Table Upsert 和 Table Append 步骤在运行时、写入任何内容之前，会检查其源表。该检查会将步骤构建的查询与每个源表此刻的状态进行比较：

- 步骤读取的列在表中不存在、联接键在表中不存在或不在步骤的源列中，或者步骤读取的源表尚未构建，都会使步骤停止。一条错误会列出每个问题及各自的修复方法。已存在的目标表保持原样，步骤需要新建的目标表则保持为空。
- 步骤列出但并不读取、且表中已不存在的列，只会增加一条警告。步骤会在没有该列的情况下运行。
- 对于尚未构建的源表，Table Union Distinct 和 Table Union All 是例外：它们会像以前一样跳过该表且不发出警告，并合并其余的表。如果其源表均未构建，它们会以警告结束，而不是失败。

目标为视图的步骤只会创建该视图，因此只有在仓库本来就会拒绝创建该视图时，才会根据其表检查步骤列出的列和联接键。其他情况下，只有尚未构建的源表或步骤未列出的联接键会使步骤停止，也不会添加警告。

只要可能，错误会指明构建该表的步骤；如果表中有一列的名称与缺失的列相近，例如仅大小写不同，也会指明该列。
