### 导入文件选择器

此转换中的文件选择器用于选择存储在 PlaidCloud 文档位置中的文件进行导入。

您也可以选择一个目录进行导入，该目录中的所有文件都将在转换运行时一并导入。

<Aside type="caution">选择目录进行导入时，请确保所有文件的格式相同</Aside>

#### 选择文档账户

选择您有权访问的 PlaidCloud 文档账户。这样您就可以在下一项选择中选取目录或文件。

在项目内，列表顶部还提供**Project Default**，代表项目当前设置为默认的账户。当项目设有默认账户时，新步骤会预先选中 Project Default；现有步骤会保留其已保存的账户，直到您更改为止。设为Project Default的步骤在运行时使用当时项目的默认账户；如果未设置默认账户，运行会失败并指明该项目，而不会回退到其他账户。

#### 搜索选项

**搜索**选项用于在指定目录路径下查找所有要导入的匹配文件。如果需要包含许多文件，但它们存储在嵌套目录中，或与同一目录中不想导入的其他文件混在一起，此选项会特别有用。

<Aside>为类型和用途相似的文件使用统一的命名约定，可以更方便地只用一个导入步骤完成导入</Aside>

所选的搜索路径是搜索的起始目录。搜索过程会查找该目录及其子目录中所有符合所指定搜索条件的文件。请确保搜索条件同样适用于子目录中的文件。

可使用以下条件进行搜索：
 * **精确**：与搜索文本完全匹配
 * **开头为**：匹配以搜索文本开头的任何文件
 * **包含**：匹配包含搜索文本的任何文件
 * **结尾为**：匹配以搜索文本结尾的任何文件

AI 助手或 REST API 还可以将搜索设置为 `glob`（通配符模式，例如 `CO Store*.yxdb`，对整个文件名进行匹配且忽略大小写），或 `regex`（整个文件名必须匹配的正则表达式）。正则表达式区分大小写，除非以 `(?i)` 开头。

#### 文件或目录选择选项

如果需要导入特定的文件或目录中的文件，选择文件或目录比使用搜索更合适。

要选择文件或目录，只需使用浏览按钮，在上面所选文档账户中选取路径。

#### 变量替换

无论使用搜索选项还是特定文件/目录选项，路径、搜索文本和文件名中都可以使用变量。

以下示例使用 `current_month` 变量动态指向正确的文件：

```
legal_entity/inputs/{current_month}/ledger_values.csv
```
