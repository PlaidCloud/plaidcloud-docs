**Join Map** 或 **目标输出列** 中的某一行，可能引用了步骤的 **源列** 选项卡中已不再列出的列，例如在重新检查某个源的列之后。步骤绝不会自动移除这样的行。相反，该列名会以红色显示在 ⚠ 警告标志之后，将鼠标悬停其上即可看到是哪个源的列表缺少该列。

带有 **常量**、**表达式** 或 **计数（含空值）** 汇总的目标输出列行永远不会被标记，因为步骤不会读取该行的源列。列表为空的源（例如从未检查过的源）不会进行任何检查。

保存仍带有被标记行的步骤时，会弹出 **发现过时列** 对话框，按表列出这些行，并提供三个选项：

- **全部移除并保存** — 移除被标记的行，然后保存。
- **仍然保存** — 按当前状态保存步骤。
- **取消** — 返回步骤而不保存。

若要保留某一行并清除其警告，请在 **源列** 选项卡上把该列重新添加到对应源的列表中，或者选择列表中已有的列。

保存时，还会按当前状态检查每个源表。如果某个源的列表中有某一列而其表中没有，则会弹出 **缺少源列** 对话框，指明该表和该列，并提供 **仍然保存** 或 **取消**。如果同时还有行被标记，两者会一并显示在 **发现过时列** 对话框中。参见[源表中缺少的列](/zh-cn/reference/workflow-steps/tables/table-extract/#源表中缺少的列)。
