### 预览

单击**源**选项卡上的**预览**，可查看步骤将读取内容的最多 100 行，而不运行它。如果结果更长，预览会说明它只显示了前几行，需要运行步骤才能读取全部行。

预览填充项目变量和工作流变量的方式与运行相同。它不支持 `{x:>9}` 之类的变量格式，也无法填充只在运行期间才有值的变量，例如触发值。

预览只读取数据。它会拒绝可能更改任何内容的查询，并显示一条消息而不是行：

- **预览仅支持标准 SQL 函数。请运行该步骤以查看结果。** 查询使用了预览无法确认是只读的函数。请运行步骤以查看结果。
- 不是单个 `SELECT` 的查询，或者其变量展开后成为写入语句的查询，会被拒绝。

在已锁定的项目中、在 SQL Server、Oracle 或 SQLite 连接上，或对于通过代理运行的步骤（例如 [Agent Remote Execution of SQL 步骤](/zh-cn/reference/workflow-steps/agent/agent-remote-execution-of-sql/)），预览不可用。
