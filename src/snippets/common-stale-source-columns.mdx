A **Join Map** or **Target Output Columns** row can name a column that the step's **Source Columns** tab no longer lists, for example after a source's columns were inspected again. The step never removes such a row for you. Instead, the column name is shown in red behind a ⚠ warning sign, and hovering over it tells you which source's list is missing the column.

A Target Output Columns row with a **Constant**, an **Expression** or a **Count (including nulls)** summary is never flagged, because the step doesn't read the row's source column. Nothing is checked against a source whose list is empty, for example one that was never inspected.

When you save a step that still has flagged rows, a **Stale Columns Found** dialog lists them by table and offers three choices:

- **Remove All and Save** — remove the flagged rows, then save.
- **Save Anyway** — save the step as it is.
- **Cancel** — go back to the step without saving.

To keep a row and clear its warning, add the column back to that source's list on the **Source Columns** tab, or pick a column the list contains.
