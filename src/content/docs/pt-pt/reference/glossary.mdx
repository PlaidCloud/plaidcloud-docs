Um único local de referência para os termos do produto. Se algo num guia ou numa página de referência utilizar uma palavra que consta aqui, é este o seu significado.

## Conta

Um início de sessão do PlaidCloud. Uma conta pertence a uma ou mais organizações e tem acesso concedido a áreas de trabalho específicas dentro dessas organizações.

## Assistente de IA

Uma interface de conversação, ao nível do projeto, dentro do PlaidCloud, para fazer perguntas sobre dados, gerar expressões e operar sobre projetos em linguagem natural. Consulte o [guia do Assistente de IA](/pt-pt/guides/ai-assistant/).

## Alocação

Uma operação de fluxo de trabalho que distribui valores de um conjunto de linhas («origem») para outro («destino») com base em dados de indutores e regras. Utilizada em preços de transferência, custeio baseado em atividades, reembolso de custos de TI, análise de rentabilidade e problemas semelhantes de distribuição de custos. Consulte [Alocações](/pt-pt/guides/allocations/).

## Ligação

Uma configuração guardada que permite ao PlaidCloud aceder a um sistema externo — uma base de dados, uma conta de armazenamento na nuvem, um ERP, uma API REST. As ligações são reutilizadas pelos passos do fluxo de trabalho, para que as credenciais fiquem num único local. Consulte [Ligações (guia)](/pt-pt/guides/connections/) · [Conectores (referência)](/pt-pt/reference/connectors/).

## Aplicação Dash

Uma aplicação interativa personalizada, criada sobre dados do PlaidCloud com a framework Plotly Dash, publicada a partir de um repositório Git e alojada em paridade com uma aplicação Panel de servidor. Consulte [Aplicações Dash](/pt-pt/guides/dash-apps/).

## Painel de controlo

Uma vista interativa publicada dos dados de um projeto, criada a partir de tabelas e vistas. Consulte [Painéis de controlo](/pt-pt/guides/dashboards/).

## Dimensão

Uma hierarquia — utilizada para segmentar e agregar dados. Os centros de custo, os produtos, a geografia e os períodos de tempo são dimensões comuns. As alocações utilizam dimensões para decidir o que alocar a quê. Consulte [Dimensões](/pt-pt/guides/dimensions/).

## Indutor

Numa alocação, os dados que determinam *como* os valores são distribuídos pelos destinos. Exemplo: se estiver a alocar custos de TI a unidades de negócio por número de efetivos, a tabela de efetivos é o indutor.

## Lakehouse

O armazenamento de dados analíticos subjacente ao PlaidCloud. A biblioteca de expressões tem versões por motor Lakehouse: **Lakehouse v1** (baseado em Databend) e **Lakehouse v2** (baseado em StarRocks). Consulte a [referência de expressões](/pt-pt/reference/expressions/).

## MCP

Model Context Protocol — o padrão que o PlaidCloud utiliza para se integrar com agentes de programação com IA (Claude Code, Cursor, Copilot, etc.). Consulte [Agentes de programação com IA](/pt-pt/integrations/ai-coding-agents/).

## Membro

Uma conta de utilizador com acesso concedido a uma área de trabalho. Os membros são atribuídos a grupos de segurança dentro da área de trabalho, que controlam o que podem fazer. Consulte [Gestão de acessos](/pt-pt/administration/access/).

## Organização

O limite de faturação e de identidade de nível superior no PlaidCloud. Uma organização contém uma ou mais áreas de trabalho e uma ou mais contas de membros.

## Aplicação Panel

Uma aplicação interativa personalizada, criada sobre dados do PlaidCloud, normalmente com a framework Panel. Consulte [Aplicações Panel](/pt-pt/guides/panel-apps/).

## PlaidLink

O daemon de ligação local do PlaidCloud — executa-se como serviço Windows, daemon Unix/Linux/Mac ou serviço em contentor para fazer a ponte entre os fluxos de trabalho do PlaidCloud e origens de dados locais. Consulte a [referência do PlaidLink](/pt-pt/reference/cli/plaidlink/).

## PlaidXL

O suplemento do PlaidCloud para Excel. Obtém e atualiza tabelas e dimensões de projetos em folhas de cálculo e adiciona fórmulas `PLAIDXL` que calculam valores agregados a partir de dados do PlaidCloud. Consulte a [referência do PlaidXL](/pt-pt/reference/cli/plaidxl/).

## Projeto

Uma unidade de trabalho dentro de uma área de trabalho. Cada projeto tem as suas próprias tabelas, fluxos de trabalho, dimensões e histórico de auditoria. Os projetos são isolados uns dos outros — não partilham estado. Consulte [Projetos](/pt-pt/guides/projects/).

## Publicar

Disponibilizar uma tabela de projeto para consumo externo (painéis de controlo, ferramentas de BI, sistemas a jusante). Consulte [Publicação de dados](/pt-pt/guides/data/publish/).

## Grupo de segurança

Um conjunto de permissões dentro de uma área de trabalho. Os membros são atribuídos a grupos de segurança para lhes conceder capacidades específicas (ler tabelas, editar fluxos de trabalho, gerir membros, etc.). Consulte [Grupos de segurança](/pt-pt/administration/access/managing-security-groups-and-assignments/).

## Passo

Uma única operação dentro de um fluxo de trabalho — importar um CSV, juntar duas tabelas, enviar uma notificação, executar uma alocação. Os passos organizam-se em categorias (importação, exportação, tabelas, alocação, dimensão, documento, notificações, etc.). Consulte a [referência de passos de fluxo de trabalho](/pt-pt/reference/workflow-steps/).

## Tabela

Dados estruturados em linhas e colunas dentro de um projeto. As tabelas provêm de importações, transformações ou origens externas.

## Vista

O resultado de uma consulta guardada, construído sobre uma ou mais tabelas. Comporta-se como uma tabela para os consumidores a jusante, mas os dados subjacentes são reavaliados na leitura.

## Fluxo de trabalho

Uma sequência de passos que opera sobre tabelas. A unidade de automatização no PlaidCloud. Os fluxos de trabalho podem ser executados em sequência, em paralelo, de forma condicional ou em ciclos. Consulte [Fluxos de trabalho (guia)](/pt-pt/guides/workflows/) · [Passos de fluxo de trabalho (referência)](/pt-pt/reference/workflow-steps/).

## Área de trabalho

Um ambiente isolado dentro de uma organização onde o trabalho efetivo acontece. As equipas utilizam normalmente uma área de trabalho por ambiente (desenvolvimento, teste, produção) ou por unidade de negócio. Os membros têm acesso concedido ao nível da área de trabalho. Consulte [Gestão de acessos](/pt-pt/administration/access/).
