## Descrição

Importa o detalhe das linhas de transação do razão geral do NetSuite, através da sua [ligação ao NetSuite](/pt-pt/guides/connections/netsuite/), para uma tabela de projeto — as linhas de lançamento por trás dos seus saldos, para reconciliação, análise detalhada ou uma demonstração de resultados detalhada. Escolha a ligação, indique uma tabela de destino e defina o período e a subsidiária; o passo obtém as linhas e escreve-as, sem SuiteQL para criar ou manter.

Este é um dos [passos de importação do NetSuite](/pt-pt/reference/workflow-steps/netsuite/) predefinidos. Cada um é executado sobre uma camada de leitura partilhada que atualiza o token OAuth, percorre os resultados grandes página a página e repete automaticamente os erros transitórios, pelo que uma importação de um período completo chega completa, sem ajustes manuais. Para saldos de período em vez de linhas, utilize [NetSuite: Importar saldos](/pt-pt/reference/workflow-steps/netsuite/import-balances/).

## Configuração

| Campo | Obrigatório | Notas |
|---|---|---|
| Ligação NetSuite | Sim | A ligação NetSuite através da qual ler, filtrada para ligações do tipo NetSuite. |
| Tabela de destino | Sim | A tabela de projeto para onde as linhas de transação são escritas. É totalmente substituída em cada execução. |
| Data de início | Não | A data de transação mais antiga a incluir, `YYYY-MM-DD`, inclusive. Deixe em branco para não ter limite inferior. Quando indicada juntamente com a Data de fim, a importação é automaticamente dividida em janelas de datas para ficar abaixo do limite de linhas do SuiteQL do NetSuite; consulte o aviso abaixo. |
| Data de fim | Não | A data de transação mais recente a incluir, `YYYY-MM-DD`, inclusive. Deixe em branco para não ter limite superior. |
| Subsidiária | Não | Um ID interno de subsidiária do NetSuite para restringir a importação a uma subsidiária. Deixe em branco para todas as subsidiárias. |
| Livro contabilístico | Não | Um ID interno de livro contabilístico do NetSuite. Deixe em branco para importar **apenas o livro principal (ID interno 1)** ou introduza `all` para somar todos os livros. |
| Número da conta | Não | Um número exato de conta do razão geral para restringir a importação a uma conta. Deixe em branco para todas as contas. |
| Período de lançamento | Não | Um ID interno de período de lançamento/contabilístico do NetSuite. Deixe em branco para todos os períodos. |

<Aside type="caution">
**Contas com vários livros:** uma conta do NetSuite com Multi-Book Accounting lança uma linha por livro por linha de transação, pelo que importar todos os livros sem filtro conta o total N vezes. Se deixar o Livro contabilístico em branco, importa **apenas o livro principal**. Defina-o como `all` apenas se pretender deliberadamente um total entre livros ou como o ID interno de um livro específico para obter só esse livro.
</Aside>

<Aside type="note">
Limite o período à fatia de que precisa. Cada execução substitui toda a tabela de destino, pelo que uma importação agendada volta a extrair o resultado completo de cada vez; uma janela de datas móvel mantém rápida uma importação recorrente do razão geral, em vez de reler todo o histórico.
</Aside>

<Aside type="note">
A API SuiteQL do NetSuite limita uma única consulta a cerca de 100 000 linhas sem o SuiteAnalytics Connect. Se indicar a Data de início e a Data de fim, o PlaidCloud divide proativamente a importação em janelas que ficam abaixo desse limite; o detalhe do razão geral é a importação com maior probabilidade de se aproximar dele, pelo que isto é mais relevante aqui do que em Importar saldos. Uma importação **sem limites definidos** que acabe por ultrapassar o limite falha com uma mensagem a pedir que adicione um intervalo de datas, em vez de devolver em silêncio um resultado truncado.
</Aside>
