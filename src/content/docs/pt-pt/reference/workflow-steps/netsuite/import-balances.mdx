## Descrição

Importa os saldos de contas do NetSuite, através da sua [ligação ao NetSuite](/pt-pt/guides/connections/netsuite/), para uma tabela de projeto — um balancete sobre o qual pode construir relatórios. Escolha a ligação, indique uma tabela de destino e defina o período e a subsidiária; o passo obtém os saldos e escreve-os, sem SuiteQL para criar ou manter.

Este é um dos [passos de importação do NetSuite](/pt-pt/reference/workflow-steps/netsuite/) predefinidos. Cada um é executado sobre uma camada de leitura partilhada que atualiza o token OAuth, percorre os resultados grandes página a página e repete automaticamente os erros transitórios, pelo que uma importação de um ano completo ou de todas as subsidiárias chega completa, sem ajustes manuais. Para uma importação ao nível das transações, utilize [NetSuite: Importar detalhe do razão geral](/pt-pt/reference/workflow-steps/netsuite/import-gl-detail/); para contas, subsidiárias e outras listas, utilize [NetSuite: Importar dados mestre](/pt-pt/reference/workflow-steps/netsuite/import-master-data/).

## Configuração

| Campo | Obrigatório | Notas |
|---|---|---|
| Ligação NetSuite | Sim | A ligação NetSuite através da qual ler, filtrada para ligações do tipo NetSuite. |
| Tabela de destino | Sim | A tabela de projeto para onde os saldos são escritos. É totalmente substituída em cada execução. |
| Data de início | Não | A data mais antiga a incluir, `YYYY-MM-DD`, inclusive. Deixe em branco para não ter limite inferior. Quando indicada juntamente com a Data de fim, a importação é automaticamente dividida em janelas de datas para ficar abaixo do limite de linhas do SuiteQL do NetSuite; consulte o aviso abaixo. |
| Data de fim | Não | A data mais recente a incluir, `YYYY-MM-DD`, inclusive. Deixe em branco para não ter limite superior. |
| Subsidiária | Não | Um ID interno de subsidiária do NetSuite para restringir a importação a uma subsidiária. Deixe em branco para todas as subsidiárias. |
| Livro contabilístico | Não | Um ID interno de livro contabilístico do NetSuite. Deixe em branco para importar **apenas o livro principal (ID interno 1)** ou introduza `all` para somar todos os livros. |
| Número da conta | Não | Um número exato de conta do razão geral para restringir a importação a uma conta. Deixe em branco para todas as contas. |
| Período de lançamento | Não | Um ID interno de período de lançamento/contabilístico do NetSuite. Deixe em branco para todos os períodos. |

<Aside type="caution">
**Contas com vários livros:** uma conta do NetSuite com Multi-Book Accounting lança uma linha por livro por linha de transação. Se deixar o Livro contabilístico em branco, importa **apenas o livro principal**, que é a escolha correta para um balancete normal. Defina-o como `all` apenas se pretender deliberadamente um total entre livros (que soma, em vez de reconciliar, os livros) ou como o ID interno de um livro específico para obter só esse livro.
</Aside>

<Aside type="note">
A Subsidiária e o Livro contabilístico recebem o ID interno do NetSuite, não um nome. Obtenha os IDs internos uma vez com [NetSuite: Importar dados mestre](/pt-pt/reference/workflow-steps/netsuite/import-master-data/) (tipo de registo **subsidiary**) e guarde-os numa pequena tabela de referência.
</Aside>

<Aside type="note">
A API SuiteQL do NetSuite limita uma única consulta a cerca de 100 000 linhas sem o SuiteAnalytics Connect. Se indicar a Data de início e a Data de fim, o PlaidCloud divide proativamente a importação em janelas que ficam abaixo desse limite, pelo que uma importação de um ano completo chega completa sem qualquer ação da sua parte. Uma importação **sem limites definidos** (Data de início ou Data de fim em branco) que acabe por ultrapassar o limite falha com uma mensagem a pedir que adicione um intervalo de datas, em vez de devolver em silêncio um resultado truncado.
</Aside>
