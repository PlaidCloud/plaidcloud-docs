## Descrição

Importa uma lista de dados mestre do NetSuite, através da sua [ligação ao NetSuite](/pt-pt/guides/connections/netsuite/), para uma tabela de projeto. Escolha um tipo de registo — contas, subsidiárias, departamentos, classes, localizações, fornecedores ou clientes — e o passo obtém a lista e escreve-a, sem SuiteQL para criar ou manter.

Os dados mestre são os dados de referência para os quais apontam as importações de saldos e de detalhe: as contas, subsidiárias e dimensões que as linhas do seu razão geral trazem como IDs internos. Importe a lista de que precisa para resolver esses IDs internos em nomes ou para alimentar pesquisas e junções a jusante. Este é um dos [passos de importação do NetSuite](/pt-pt/reference/workflow-steps/netsuite/) predefinidos, que são executados sobre uma camada de leitura partilhada que atualiza o token OAuth, percorre os resultados grandes página a página e repete automaticamente os erros transitórios.

## Configuração

| Campo | Obrigatório | Notas |
|---|---|---|
| Ligação NetSuite | Sim | A ligação NetSuite através da qual ler, filtrada para ligações do tipo NetSuite. |
| Tabela de destino | Sim | A tabela de projeto para onde a lista é escrita. É totalmente substituída em cada execução. |
| Tipo de registo | Sim | A lista mestre a importar: **account** (a predefinida), **subsidiary**, **department**, **class**, **location**, **vendor** ou **customer**. |
| Incluir inativos | Não | Desativado por predefinição, devolvendo apenas os registos ativos. Ative-o para incluir os registos marcados como inativos no NetSuite. |

<Aside type="note">
Utilize este passo para criar as pequenas tabelas de referência em que os outros passos do NetSuite se apoiam; por exemplo, importe **subsidiary** uma vez para associar o ID interno de uma subsidiária ao respetivo nome antes de restringir uma importação de [Importar saldos](/pt-pt/reference/workflow-steps/netsuite/import-balances/) ou de [Importar detalhe do razão geral](/pt-pt/reference/workflow-steps/netsuite/import-gl-detail/) a uma subsidiária.
</Aside>
