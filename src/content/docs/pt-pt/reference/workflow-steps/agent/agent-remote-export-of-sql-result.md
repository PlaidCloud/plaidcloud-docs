## Descrição



Executa SQL numa base de dados remota através de um agente PlaidLink e traz o conjunto de resultados de volta para o PlaidCloud como uma tabela de projeto. É utilizado quando a base de dados de origem não pode ser acedida diretamente a partir do PlaidCloud (firewall, apenas VPN, nas instalações), mas pretende, ainda assim, extrair dados da mesma.

O agente executa a consulta nas instalações e envia o resultado em fluxo contínuo para o PlaidCloud, pelo que as credenciais e os dados permanecem na sua rede até o resultado ser necessário.
