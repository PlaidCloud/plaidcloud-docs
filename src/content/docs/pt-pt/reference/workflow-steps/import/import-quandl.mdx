Para mais detalhes sobre os conjuntos de dados do Quandl, consulte o sítio Web oficial do Quandl aqui: http://www.quandl.com/.

## Itens de configuração específicos

### Especificação dos dados de origem

Aceder aos conjuntos de dados do Quandl requer uma conta de utilizador ou uma conta de convidado com acesso limitado. Isto requer configuração em Tools. Para obter detalhes sobre como configurar uma ligação de conta Quandl, consulte aqui: [PlaidCloud Tools – Ligação](/pt-pt/reference/connectors/).

Depois de configuradas todas as contas necessárias, selecione a conta adequada na lista pendente.

Em seguida, introduza os critérios para o código Quandl pretendido. Os utilizadores podem usar a funcionalidade **Pesquisar** para procurar conjuntos de dados. Em alternativa, os conjuntos de dados podem ser introduzidos manualmente. Para isso, o utilizador tem de introduzir a parte do URL a seguir a “[http://www.quandl.com](http://www.quandl.com/)”. 

Por exemplo, para importar o conjunto de dados das ações da Microsoft, que se encontra aqui (http://www.quandl.com/GOOG/NASDAQ_MSFT), introduza *GOOG/NASDAQ_MSFT* no campo Código Quandl.


### Seleção de dados


É possível fatiar os conjuntos de dados do Quandl na importação. As opções disponíveis incluem:


* Data de início: Utilize o seletor de datas para selecionar a data pretendida.
* Data de fim: Utilize o seletor de datas para selecionar a data pretendida.
* Agrupar: Agrega os resultados numa base diária, semanal, mensal, trimestral ou anual. Por predefinição, não há agregação.
* Transformação: Cálculos de resumo.
* Limitar linhas: O valor predefinido 0 devolve todas as linhas. Qualquer outro valor inteiro positivo especifica o limite de linhas a devolver do conjunto de dados.
