## Descrição


Importa ficheiros HDF5 (Hierarchical Data Format versão 5) para tabelas de projeto do PlaidCloud. O HDF5 é comum na computação científica, na troca de dados de aprendizagem automática e em qualquer contexto em que dados tipados e em colunas precisem de circular entre ferramentas Python/R/MATLAB.

Consulte a [documentação do HDF Group](http://www.hdfgroup.org/HDF5/) para a especificação do formato.

## Itens de configuração específicos


### Nome da chave

Os ficheiros HDF armazenam dados numa estrutura de caminhos. É necessária uma chave (caminho) como destino da tabela dentro do ficheiro HDF. Na maioria das situações, será *table*.
