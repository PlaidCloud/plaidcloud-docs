## Descrição


Importa dados tabulares de um ficheiro XML para uma tabela de projeto do PlaidCloud. Configure o caminho do elemento que identifica cada "linha" e mapeie os elementos filho ou atributos para colunas da tabela.

É comum em integrações empresariais mais antigas, na troca de dados B2B (RosettaNet, ebXML) e em formatos de declarações governamentais.


## Ler registos como

**Ler registos como** escolhe a forma como o ficheiro se transforma em tabelas:

* **Uma tabela por etiqueta de registo** (predefinição) — o separador **Etiquetas de registo** lista cada etiqueta a ler, e cada etiqueta é carregada na sua própria tabela, com o nome derivado do **Prefixo das tabelas de destino**.
* **Uma linha por elemento** — um elemento repetido é carregado numa tabela, uma linha por cada ocorrência. O separador **Etiquetas de registo** e o **Prefixo das tabelas de destino** ficam desativados.

Com **Uma linha por elemento**, defina:

* **Elemento XML** — o elemento que constitui uma linha. Se ficar em branco, é o elemento da primeira coluna, apresentado no campo.
* **Tabela de destino** — a tabela a carregar.
* **Colunas** — cada **Elemento filho ou atributo** e a **Coluna** em que é carregado. Todas as colunas são importadas como texto.
* **Remover espaços em redor dos valores** — remove os espaços iniciais e finais de cada valor.
* **Corresponder nomes com o respetivo prefixo de espaço de nomes** — faz corresponder os nomes de elementos e atributos tal como estão escritos no ficheiro, incluindo o prefixo.

São obrigatórios Ficheiro de origem, Tabela de destino e um Elemento XML ou pelo menos uma coluna. Alternar entre modos mantém no formulário as definições do outro modo, pelo que voltar atrás as restaura, mas ao guardar são removidas as definições do modo que abandonou; uma nota junto ao controlo explica-o.

Os passos guardados a partir do formulário leem as suas etiquetas de registo conforme definido no separador **Etiquetas de registo**.
