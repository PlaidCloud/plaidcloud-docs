## Descrição


Importa o resultado de uma consulta SQL feita a uma base de dados externa para uma tabela de projeto do PlaidCloud. A consulta é executada na base de dados remota; apenas o conjunto de resultados é trazido para o PlaidCloud.

Difere de [Importar tabelas de bases de dados externas](/pt-pt/reference/workflow-steps/import/import-external-database-tables/) porque é você que escreve o SQL — útil para junções, filtros ou agregações complexos que pretende que a base de dados de origem execute antes de os dados chegarem ao PlaidCloud.

### Dedução de tipos de coluna
As importações SQL têm a opção de tentar deduzir o tipo de dados durante o carregamento, ou de definir todas as colunas com o tipo Texto. Definir os tipos de dados dinamicamente pode ser mais rápido se os dados estiverem limpos, mas pode causar problemas em algumas circunstâncias.

Por exemplo, se a maior parte dos dados parecer numérica mas existir também algum texto, pode tentar defini-la como numérica, causando problemas de carregamento por tipos de dados incompatíveis. Ou pode haver problemas se existir um código de produto numérico de 16 dígitos, por exemplo. Cortaria os zeros à esquerda, resultando num número em vez de um código de 16 dígitos.

Definir os dados como texto, porém, exige um passo Extract posterior para converter para o tipo adequado quaisquer tipos de dados que não devam ser texto, como datas ou valores numéricos.

## Resolução de problemas

| Sintoma | Causa provável |
| --- | --- |
| O passo demorou visivelmente mais do que o habitual — até cerca de meia hora a mais — sem que nada mais na sua consulta, ligação ou volume de dados tenha mudado | O trabalhador em segundo plano que executa a importação foi interrompido a meio (um reinício ou despejo do lado da plataforma, e não algo no seu fluxo de trabalho), e a plataforma repetiu a importação da tabela por si. A repetição só começa quando a interrupção é detetada, o que explica o tempo adicional. |
| O passo terminou com sucesso mesmo assim após esse atraso | A repetição substitui por completo o conteúdo da tabela, pelo que o resultado é o mesmo que o de uma única execução limpa — não há mais nada a verificar ou refazer. |
| O passo falha com "has already been attempted and cannot be safely re-run" | Num passo Importar SQL, esta recusa já não acontece — uma interrupção a meio da execução é repetida. Continuará a vê-la, por conceção, ao [restaurar um arquivo de projeto](/pt-pt/guides/projects/archive-a-project/#restaurar-um-arquivo) ou ao [carregar uma dimensão](/pt-pt/reference/workflow-steps/dimensions/dimension-load/), onde voltar a executar criaria um duplicado em vez de substituir algo. Abra um pedido de suporte se a vir num próprio passo Importar SQL.
