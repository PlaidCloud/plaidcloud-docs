## Descrição


Importa o resultado de uma consulta SQL a uma base de dados externa para uma tabela de projeto do PlaidCloud. A consulta é executada na base de dados remota; apenas o conjunto de resultados é trazido para o PlaidCloud.

Difere de [Importar tabelas de bases de dados externas](/pt-pt/reference/workflow-steps/import/import-external-database-tables/) porque o SQL é escrito por si — útil para junções, filtros ou agregações complexos que pretende que a base de dados de origem execute antes de os dados chegarem ao PlaidCloud.

### Dedução de tipos de coluna
As importações SQL têm a opção de tentar deduzir o tipo de dados durante o carregamento ou de definir todas as colunas com o tipo Texto. Definir os tipos de dados dinamicamente pode ser mais rápido se os dados estiverem limpos, mas pode causar problemas em certas circunstâncias.

Por exemplo, se a maioria dos dados parecer numérica mas existir também algum texto, pode tentar defini-la como numérica, causando problemas de carregamento por tipos de dados incompatíveis. Ou podem surgir problemas se existir um código de produto numérico com 16 dígitos, por exemplo. Os zeros à esquerda seriam cortados, resultando num número em vez de um código de 16 dígitos.

Definir os dados como texto, no entanto, requer um passo Extract posterior para converter para o tipo adequado, como datas ou valores numéricos, os tipos de dados que não devem ser texto.

## Resolução de problemas

| Sintoma | Causa provável |
| --- | --- |
| O passo demorou visivelmente mais do que o habitual — até cerca de meia hora a mais — sem que nada mais na sua consulta, ligação ou volume de dados tenha mudado | O processo em segundo plano que executava a importação foi interrompido a meio (um reinício ou remoção do lado da plataforma, não algo no seu fluxo de trabalho), e a plataforma voltou a tentar a importação da tabela por si. A nova tentativa só começa depois de a interrupção ser detetada, o que explica o tempo adicional. |
| O passo terminou com êxito depois desse atraso | A nova tentativa substitui integralmente o conteúdo da tabela, pelo que o resultado é o mesmo que o de uma única execução limpa — não há mais nada a verificar ou a refazer. |
| O passo falha com "has already been attempted and cannot be safely re-run" | Num passo Importar SQL, esta recusa deixou de ocorrer — uma interrupção a meio da execução é repetida. Continuará a vê-la, por conceção, ao [restaurar um arquivo de projeto](/pt-pt/guides/projects/archive-a-project/#restaurar-um-arquivo) ou ao [carregar uma dimensão](/pt-pt/reference/workflow-steps/dimensions/dimension-load/), onde voltar a executar criaria um duplicado em vez de substituir algo. Abra um pedido de suporte se a vir num passo Importar SQL propriamente dito.
