## Descrição

Importe ficheiros Alteryx YXDB a partir do PlaidCloud Document. O YXDB é o formato de ficheiro binário nativo do Alteryx Designer para armazenar conjuntos de dados juntamente com os metadados dos campos.

As importações de YXDB são transmitidas através de armazenamento temporário, em vez de carregarem o ficheiro inteiro em memória, pelo que ficheiros muito grandes são importados sem esgotar a memória. Os tipos de dados do ficheiro — decimais, datas e carimbos de data/hora — são preservados na tabela de destino.

Se o ficheiro `.yxdb` configurado não existir mas existir um ficheiro `.parquet` com o mesmo nome na mesma pasta, o passo lê o ficheiro `.parquet` e mostra um aviso nesse sentido. Os fluxos de trabalho Alteryx convertidos escrevem as respetivas saídas `.yxdb` como ficheiros `.parquet` com o mesmo nome, pelo que um passo que lê um desses ficheiros `.yxdb` obtém os dados automaticamente. As importações que procuram ficheiros não utilizam esta alternativa.
