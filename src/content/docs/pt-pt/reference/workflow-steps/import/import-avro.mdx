## Descrição

Importe ficheiros Apache Avro a partir do PlaidCloud Document. O Avro é um formato de serialização de dados por linhas do projeto Apache Hadoop que armazena os dados juntamente com o respetivo esquema, o que o torna adequado para utilização em pipelines de dados e sistemas de streaming.

## Itens de configuração específicos

### Hora de modificação do ficheiro

Leia apenas os ficheiros alterados numa janela de tempo. **Modified After** lê apenas os ficheiros modificados pela última vez depois da hora que introduzir e **Modified Before** apenas os modificados antes dela; defina um ou ambos. Introduza uma hora no formato `YYYY-MM-DDTHH:MM:SS`, como `2026-10-01T00:00:00`. Uma hora é UTC, a menos que indique um fuso horário, como `2026-10-01T00:00:00-05:00`. Uma hora pode conter uma variável de fluxo de trabalho, que é lida quando o passo é executado.
