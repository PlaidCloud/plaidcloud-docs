## Descrição

Importe um ficheiro de extração IBM DB2 a partir do armazenamento do PlaidCloud Document. É útil quando o servidor DB2 só é acessível a partir de infraestrutura local: um processo externo envia a extração para o armazenamento do PlaidCloud Document e este passo lê-a a partir daí para uma tabela de projeto.

Para acesso em direto ao DB2 (sem ficheiro de extração), ligue-se através da ligação [IBM DB2](../../../connectors/databases/ibm-db2/) padrão e utilize [Importar tabelas de bases de dados externas](../import-external-database-tables/).
