## Descrição

Importe folhas de trabalho específicas de ficheiros Microsoft Excel a partir do PlaidCloud Document. O Analyze suporta o formato Excel antigo (XP/2003), bem como o novo formato (2007/2010/2013). Isto inclui, entre outros, os seguintes tipos de ficheiro:

* XLS
* XLSX
* XLSB
* XLSM

Os livros binários (XLSB), os ficheiros XLS antigos e os ficheiros ODS importam folhas de trabalho e intervalos de células da mesma forma que o XLSX.

As importações de Excel são transmitidas através de armazenamento temporário, em vez de carregarem o livro inteiro em memória, pelo que ficheiros muito grandes são importados sem esgotar a memória. Os tipos de dados de origem — decimais, datas e carimbos de data/hora — são preservados na tabela de destino, em vez de passarem por texto.

### Cabeçalho

Como os ficheiros Excel podem ou não conter cabeçalhos, o PlaidCloud permite utilizar os cabeçalhos, ignorá-los ou utilizar a ordem das colunas para determinar o alinhamento das colunas.
* **Sem cabeçalho**: O ficheiro não contém cabeçalho.  Utilize a lista de origem no *Data Mapper* para determinar o alinhamento das colunas
* **Tem cabeçalho - usar cabeçalho e substituir lista de campos**: O ficheiro tem um cabeçalho.  Utilize os nomes de cabeçalho especificados e ignore a lista de origem no *Data Mapper*.
* **Tem cabeçalho - ignorar cabeçalho e usar a lista de campos**: O ficheiro tem um cabeçalho, mas este deve ser ignorado.  Utilize os nomes de cabeçalho especificados pela lista de origem no *Data Mapper*.

Os espaços iniciais e finais e as quebras de linha nas células de cabeçalho são removidos dos nomes das colunas.

### Seleção de linhas

Para ficheiros de entrada com registos supérfluos, pode especificar um número de linhas a ignorar antes de processar os dados.  Isto é útil se os ficheiros contiverem blocos de cabeçalho que têm de ser ignorados antes de chegar aos dados tabulares.

Selecione **Keep Empty Text Cells As Empty String** para carregar uma célula de texto vazia como uma cadeia vazia em vez de NULL.

**Mais opções do Excel** contém os seguintes campos:

* **Omitir as linhas que a folha oculta** (`skip_hidden_rows`) — as linhas que a folha oculta não são importadas.
* **Importar uma célula com erro de fórmula como o texto do erro (#DIV/0!), não vazia** (`keep_error_cells`) — uma célula com erro de fórmula é importada como o respetivo texto de erro, como `#DIV/0!`, em vez de vazia.
* **Algarismos significativos** (`significant_digits`) — arredonda cada número decimal para este número de algarismos significativos. O Excel mantém 15.
* **Posição da folha** (`sheet_index`) — importa a folha de trabalho nesta posição (base 0) no livro, em vez das folhas de trabalho escolhidas por nome.

Em **Folhas de trabalho a importar**, selecione **Importar a primeira folha que tiver dados** (`sheet_first_with_data`) para importar a primeira folha de trabalho que tenha dados, ignorando as folhas vazias que a precedem. Quando nenhuma tem dados, é lida a primeira folha de trabalho do livro.

### Livro

**Variável da palavra-passe do livro** abre livros protegidos por palavra-passe. Introduza a variável de fluxo de trabalho ou de projeto que contém a palavra-passe, como `{xlsx_password}`, e não a palavra-passe em si: um passo cujo campo de palavra-passe contenha algo que não seja uma referência a uma variável é recusado quando o guarda, para que a palavra-passe nunca apareça no passo, nas suas versões ou nas suas cópias. Os passos que tinham uma palavra-passe escrita antes desta regra tiveram-na movida automaticamente para uma nova variável de projeto, visível apenas para Arquitetos, e passam agora a referenciar essa variável.

### O que ler

Cada entrada na importação seleciona uma folha de trabalho, um intervalo nomeado definido pelo livro ou um intervalo de células específico — os três são equivalentes e uma importação pode misturá-los em várias entradas.

* **Folha de trabalho**: Lê uma folha completa, selecionada por nome.
* **Intervalo nomeado**: Lê um intervalo para o qual o próprio livro define um nome. Os intervalos nomeados são listados juntamente com as folhas de trabalho no seletor (veja *Localizar folhas no ficheiro selecionado* abaixo), pelo que se seleciona um da mesma forma que uma folha.
* **Intervalo de células**: Lê um intervalo retangular específico que não corresponde a uma folha de trabalho nem a um nome do livro. Escolha a folha onde o intervalo se encontra e depois introduza o intervalo a seguir a um `$`. São suportadas três formas:
  * `Sheet1$A1:J100` — um intervalo limitado.
  * `Sheet1$A1:J` — sem limite final; lê a partir de `A1` até à última linha das colunas A a J.
  * `Sheet1$A:BJ` — colunas inteiras; lê as colunas A a BJ da folha, a forma que o Alteryx escreve para uma entrada Excel.

Os intervalos nomeados são lidos em livros XLSX e XLSM. Os livros XLSB, XLS e ODS oferecem folhas de trabalho e intervalos de células.

<Aside type="caution">Um intervalo nomeado que se refira a mais de uma área disjunta, ou um intervalo de células fora dos limites da folha ou invertido (por exemplo, com a célula final acima ou à esquerda da célula inicial), é rejeitado com um erro em vez de importado — para que uma importação nunca leia silenciosamente as células erradas.</Aside>

#### Folhas de trabalho a importar

Como os livros podem conter muitas folhas de trabalho com dados diferentes, é possível selecionar quais as folhas de trabalho a importar no processo de importação atual.  As opções são:

* Todas as folhas de trabalho
* Folhas de trabalho correspondentes à pesquisa
* Folhas de trabalho selecionadas

#### Utilizar a pesquisa de folhas de trabalho

A funcionalidade de pesquisa de folhas de trabalho permite incluir as folhas de trabalho que correspondem aos critérios de pesquisa.  Os critérios de pesquisa permitem:
* **Começa com**: O nome da folha de trabalho começa com o texto pesquisado
* **Contém**: O nome da folha de trabalho contém o texto pesquisado
* **Termina com**: O nome da folha de trabalho termina com o texto pesquisado

#### Localizar folhas no ficheiro selecionado

O botão de localizar folhas abre o ficheiro Excel e lista as folhas de trabalho e os intervalos nomeados disponíveis na tabela.  Marque as caixas de seleção na tabela para as folhas de trabalho e/ou intervalos nomeados a incluir na importação. Um livro dentro de um ficheiro `.zip` também funciona: as respetivas folhas de trabalho e intervalos nomeados são listados.

<Aside>Ao preencher o *Data Mapper*, é utilizada a primeira folha de trabalho, intervalo nomeado ou intervalo de células encontrado na lista. Certifique-se de que tudo o que é incluído no passo de importação tem um formato semelhante.</Aside>

#### Mapeamento de folhas

Um **Mapeamento de folhas** lê um conjunto diferente de folhas de trabalho de cada livro. Escolha uma **Tabela de mapeamento de folhas** com uma linha por folha de trabalho a ler, com a respetiva **Coluna do livro** a conter o caminho ou o nome do ficheiro do livro e a respetiva **Coluna da folha** a conter a folha de trabalho. Quando um mapeamento de folhas está definido, só são lidos os livros que a tabela indica, cada um para as folhas de trabalho que lista, pela ordem das linhas da tabela. Uma folha de trabalho em branco lê a primeira folha de trabalho do livro.

#### Ficheiros sem a folha de trabalho selecionada

Quando uma importação lê vários ficheiros, um ficheiro que não contenha a folha de trabalho selecionada, ou que não tenha nenhuma folha de trabalho correspondente à sua pesquisa de folhas, é ignorado. O passo termina com um aviso que indica o ficheiro ignorado e lista as folhas de trabalho que ele tem, e os outros ficheiros continuam a ser importados. Se todos os ficheiros forem ignorados, o passo ainda assim é bem-sucedido, a tabela de destino fica vazia e um aviso explica porquê. Os nomes das folhas de trabalho têm de corresponder exatamente, incluindo maiúsculas e minúsculas.

Um ficheiro ignorado permanece na pasta, mesmo com *Delete Files After Import* ativado, e emite novamente o aviso em cada execução até o remover ou corrigir. Os avisos de uma importação de vários ficheiros aparecem no passo: até cinco são listados, mais uma contagem dos restantes.

<Aside>Uma folha de trabalho vazia numa importação de várias folhas de trabalho carrega zero linhas dessa folha de trabalho — não faz falhar a importação.</Aside>

### Uma coluna de origem em várias colunas de destino

Uma única coluna de origem pode alimentar mais de uma coluna de destino. Mapeie a mesma coluna de origem em duas ou mais linhas de destino, cada uma com o seu próprio nome, tipo ou expressão. Por exemplo, leia `Amount` uma vez como coluna de texto e outra como coluna numérica, ou construa duas colunas de texto a partir da mesma célula. Uma coluna de destino numérica já não converte a origem antes de a sua expressão ser executada, pelo que uma expressão pode primeiro limpar um valor como `1,500`.

Isto funciona da mesma forma em todas as importações de ficheiros que utilizam o Data Mapper, exceto Importar CSV: Importar Excel, largura fixa, JSON, Avro, Parquet, DBF, XML e YXDB.
