## Descrição

O passo **Import dBASE** importa um ficheiro dBASE (`.dbf`) (que transporta o seu próprio esquema). É executado no motor de fluxos de trabalho; os resultados das macros empacotadas são uma aproximação da macro Alteryx.

As importações de dBASE são transmitidas através de armazenamento temporário, em vez de carregarem o ficheiro inteiro em memória, pelo que ficheiros muito grandes são importados sem esgotar a memória. Os tipos de dados do ficheiro — decimais, datas e carimbos de data/hora — são preservados na tabela de destino.

## Parâmetros

- **Origem** — o ficheiro `.dbf`.
- **Tabela de destino** — a tabela de saída.
- **Ignorar a reimportação se os ficheiros de origem não tiverem sido alterados** — uma execução do fluxo de trabalho ignora a importação se o ficheiro de origem e as definições do passo não tiverem sido alterados desde a última execução bem-sucedida. Ativado por predefinição; desmarque para reimportar sempre.
