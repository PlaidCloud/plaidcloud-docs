## Descrição



Importa ficheiros de dados SPSS (formatos .sav e .zsav) para tabelas de projeto do PlaidCloud. Útil para dados de inquéritos, dados de investigação em ciências sociais ou qualquer pipeline que interopere com ferramentas baseadas em SPSS.

As etiquetas de variáveis e as etiquetas de valores são preservadas sempre que o formato as suporta.
