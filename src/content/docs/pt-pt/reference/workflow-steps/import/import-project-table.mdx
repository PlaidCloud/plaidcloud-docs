## Descrição


Copia dados de uma tabela de um projeto diferente para o projeto atual. O inverso de [Export Project Table](/pt-pt/reference/workflow-steps/export/export-project-table/) — obtém em vez de enviar.

Útil quando um projeto de consolidação obtém dados de muitos projetos operacionais, ou quando os dados de referência estão centralizados num projeto e são lidos por outros. O projeto de origem tem de conceder a este projeto uma partilha de dados de **Leitura**.


## Gestão de partilha de dados

![Gestão de partilha de dados](/images/import_external_project_table_1.png)

Antes de poder importar uma tabela de outro projeto, esse projeto tem de permitir que este a leia. Abra o separador **Início** do projeto de **origem** e, em **Gestão de partilha de dados**, clique em **Nova partilha de dados**, selecione este projeto, marque **Leitura** em **Operações permitidas** e clique em **Adicionar partilha de dados**. Consulte [Partilhar dados entre projetos](/pt-pt/guides/projects/managing-projects/#partilhar-dados-entre-projetos).

O passo é executado com a identidade do próprio projeto, pelo que uma execução funciona através da partilha, seja quem for que a inicie.

<Aside type="note" title="Tabela de origem vazia">
Se a tabela de origem não tiver linhas quando o passo é executado, a importação termina com um aviso de que a origem estava vazia, em vez de um êxito silencioso — para que seja fácil detetar um destino inesperadamente vazio. Na maioria das vezes, isto significa que o fluxo de trabalho do projeto de origem ainda não tinha construído essa tabela; certifique-se de que a origem está preenchida (e, para execuções agendadas, ordenada para ser executada primeiro) antes da importação.
</Aside>

<Aside type="note" title="Eliminar uma tabela de origem">
A tabela de origem de que lê é tratada como estando em utilização por este passo. Se tentar eliminá-la, o PlaidCloud mostra a referência e pede-lhe que confirme uma eliminação forçada — marcando **Forçar a eliminação da tabela?** e escolhendo **Forçar eliminação** — em vez de uma eliminação simples, mesmo quando o passo de importação está num projeto diferente que partilha os dados. Nesse caso entre projetos, o aviso lista a referência sem indicar o passo do outro projeto, uma vez que pode não ter acesso a ele.
</Aside>
