## Descrição

O passo **Importar: Delimitado (por posição)** lê todas as colunas de um documento delimitado por posição, como colunas de texto com os nomes `Column_1` a `Column_N`, e ignora a linha de cabeçalho. Utilize-o quando o cabeçalho não pode dar nome às colunas, por exemplo quando um passo posterior promove uma linha de dados a cabeçalho.

## Parâmetros

- **Documento** — a conta de documentos e o caminho do ficheiro. Um caminho que termina em `.gz` é descomprimido.
- **Delimitador** — o delimitador de campos. A predefinição é uma vírgula.
- **Carácter de aspas** — a predefinição é aspas duplas.
- **Coluna do número de registo** *(opcional)* — uma coluna que numera os registos pela ordem do ficheiro. Deixe em branco para não escrever nenhuma.
- **Tabela de saída** — onde as linhas são escritas.

Um documento em falta não é um erro. O passo termina com um aviso que indica o caminho e escreve uma tabela vazia.
