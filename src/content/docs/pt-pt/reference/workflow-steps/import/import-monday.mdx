## Descrição

Importa os itens de um ou mais quadros [monday.com](https://monday.com/) para tabelas de projeto através de uma ligação monday.com. Utilize-o para trazer o acompanhamento de projetos, filas de entrada ou dados de tarefas operacionais para um fluxo de trabalho, juntamente com dados financeiros.

## Itens de configuração específicos

### Configuração da ligação

A ligação monday.com através da qual se faz a leitura.

### Tabela de destino

Uma linha por quadro: o **ID do quadro** a ler e a tabela de projeto onde é escrito. Um único passo pode importar vários quadros em simultâneo. Cada destino tem de ser uma tabela, não uma vista.
