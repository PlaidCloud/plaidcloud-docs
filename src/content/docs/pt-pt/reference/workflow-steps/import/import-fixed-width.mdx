## Descrição



Importa ficheiros de texto em que as colunas são definidas por posições de carateres em vez de delimitadores — o clássico formato de saída de mainframe / COBOL. Configure os limites das colunas (posição inicial, comprimento) por campo.

É habitual em exportações de ERP legados, declarações governamentais e formatos de extratos bancários em que os dados foram dispostos para apresentação em colunas fixas e não para análise com delimitadores.

As importações de largura fixa são transmitidas através de armazenamento temporário, em vez de carregarem o ficheiro inteiro em memória, pelo que ficheiros muito grandes são importados sem esgotar a memória.

### Cabeçalho

Como os ficheiros Excel podem ou não conter cabeçalhos, o PlaidCloud permite utilizar os cabeçalhos, ignorá-los ou utilizar a ordem das colunas para determinar o alinhamento das colunas.
* **Sem cabeçalho**: O ficheiro não contém cabeçalho.  Utilize a lista de origem no *Data Mapper* para determinar o alinhamento das colunas
* **Tem cabeçalho - usar cabeçalho e substituir lista de campos**: O ficheiro tem um cabeçalho.  Utilize os nomes de cabeçalho especificados e ignore a lista de origem no *Data Mapper*.
* **Tem cabeçalho - ignorar cabeçalho e usar a lista de campos**: O ficheiro tem um cabeçalho, mas este deve ser ignorado.  Utilize os nomes de cabeçalho especificados pela lista de origem no *Data Mapper*.

### Seleção de linhas

Para ficheiros de entrada com registos supérfluos, pode especificar um número de linhas a ignorar antes de processar os dados.  Isto é útil se os ficheiros contiverem blocos de cabeçalho que têm de ser ignorados antes de chegar aos dados tabulares.

### Larguras das colunas

Introduza as larguras das colunas separadas por vírgulas ou espaços.

### Disposição

| Definição | O que faz |
| --- | --- |
| Codificação | O conjunto de carateres do ficheiro: **UTF-8** (a predefinição), **EBCDIC (EUA, cp037)**, **EBCDIC (internacional, cp500)** ou **Latin-1**. Escolha uma página de códigos EBCDIC para um ficheiro de mainframe. |
| Registos a ignorar | Quantos registos ignorar no início do ficheiro, antes do cabeçalho ou dos dados. |
| Registos a descartar no fim | Quantos registos descartar do fim do ficheiro, como um registo final. |
| Um registo por linha | Ativado (a predefinição), cada linha é um registo. Desmarque-o para um ficheiro cujos registos estão dispostos em sequência sem quebras de linha; cada registo tem então o comprimento total das larguras das colunas. |
| Caracteres entre registos | Quando os registos não são um por linha, quantos carateres ignorar após cada registo, como um separador. |
| Remover espaços | Os espaços em branco removidos de cada valor: **Iniciais e finais** (a predefinição), **Apenas finais** ou **Nenhum**. |
