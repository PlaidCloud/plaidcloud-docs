## Descrição


Importa folhas de trabalho específicas de uma folha de cálculo do Google Sheets para tabelas de projeto do PlaidCloud. Útil para dados ad hoc que existem em folhas de cálculo — tabelas de indutores mantidas por utilizadores de negócio, mapeamentos de consulta, substituições manuais.

Autentica através de uma ligação Google; várias folhas de trabalho de uma folha de cálculo podem ser importadas num único passo.

## Parâmetros de importação


![Importar folha de cálculo Google](/images/import_file_google_target.png)
### Origem e destino
#### Conta Google

Aceder aos dados de uma folha de cálculo Google requer uma conta de utilizador Google válida. Isto requer configuração em Tools. Para obter detalhes sobre como configurar uma ligação de conta Google, consulte aqui: [PlaidCloud Tools – Ligação](/pt-pt/reference/connectors/).

Depois de configuradas todas as contas necessárias, selecione a **Conta Google** adequada na lista pendente.
#### Folha de cálculo

Em seguida, especifique a **Folha de cálculo** a importar a partir do menu pendente que contém todos os ficheiros disponíveis associados à **Conta Google** especificada.

<Aside>Certifique-se de que a conta de utilizador indicada tem acesso ao ficheiro especificado, sobretudo se o ficheiro pertencer a outro utilizador.</Aside>

### Tipo de cabeçalho

Como as folhas de cálculo Google podem ou não conter cabeçalhos, o PlaidCloud permite utilizar os cabeçalhos, ignorá-los ou utilizar a ordem das colunas para determinar o alinhamento das colunas.
* **Sem cabeçalho**: O ficheiro não contém cabeçalho.  Utilize a lista de origem no *Data Mapper* para determinar o alinhamento das colunas
* **Tem cabeçalho - usar cabeçalho e substituir lista de campos**: O ficheiro tem um cabeçalho.  Utilize os nomes de cabeçalho especificados e ignore a lista de origem no *Data Mapper*.
* **Tem cabeçalho - ignorar cabeçalho e usar a lista de campos**: O ficheiro tem um cabeçalho, mas este deve ser ignorado.  Utilize os nomes de cabeçalho especificados pela lista de origem no *Data Mapper*.

### Folhas de trabalho a importar

Como os livros podem conter muitas folhas de trabalho com dados diferentes, é possível selecionar quais as folhas de trabalho a importar no processo de importação atual.  As opções são:

* Todas as folhas de trabalho
* Folhas de trabalho correspondentes à pesquisa
* Folhas de trabalho selecionadas

#### Utilizar a pesquisa de folhas de trabalho

A funcionalidade de pesquisa de folhas de trabalho permite incluir as folhas de trabalho que correspondem aos critérios de pesquisa.  Os critérios de pesquisa permitem:
* **Começa com**: O nome da folha de trabalho começa com o texto pesquisado
* **Contém**: O nome da folha de trabalho contém o texto pesquisado
* **Termina com**: O nome da folha de trabalho termina com o texto pesquisado

#### Localizar folhas no ficheiro selecionado

O botão de localizar folhas abre o ficheiro Excel e lista as folhas de trabalho disponíveis na tabela.  Marque as caixas de seleção na tabela para as folhas de trabalho a incluir na importação.

<Aside>Ao preencher o *Data Mapper*, é utilizada a primeira folha de trabalho encontrada na lista. Certifique-se de que todas as folhas de trabalho incluídas no passo de importação têm um formato semelhante.</Aside>
### Cabeçalhos das colunas

<Aside>Devido a limitações técnicas, todas as colunas das folhas de cálculo Google são importadas com o tipo de dados String. Os tipos de dados booleano, numérico e/ou data/hora têm de ser especificados explicitamente no mapeador.</Aside>
