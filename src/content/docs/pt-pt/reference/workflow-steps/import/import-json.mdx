## Descrição

Importe ficheiros de texto JSON a partir do PlaidCloud Document.

Para mais detalhes sobre ficheiros JSON, consulte o sítio Web oficial do JSON aqui: http://json.org/.

Os ficheiros JSON *não* mantêm a ordem das colunas. A ordem das colunas no ficheiro de origem não reflete necessariamente a ordem das colunas na tabela de dados importada.

As importações de JSON são transmitidas através de armazenamento temporário, em vez de carregarem o documento inteiro em memória, pelo que ficheiros muito grandes são importados sem esgotar a memória. As colunas que só aparecem tarde num documento grande são incluídas na tabela importada. Os objetos e matrizes aninhados são importados como texto JSON compacto padrão, para que os passos seguintes os possam analisar com qualquer ferramenta JSON.

## Itens de configuração específicos

### Orientação dos dados JSON

Considere o seguinte conjunto de dados:

| ID | Name | Gender | State |
| 1 | Jack | M | MO |
| 2 | Jill | F | MO |
| 3 | George | M | VA |
| 4 | Abe | M | KY |

Os ficheiros JSON podem ser importados a partir de um de três formatos de dados:

* Records: Os dados são armazenados em conjuntos de dicionários Python, com cada linha armazenada no formato \{Column -> Value, …}. Por exemplo:


```json
[{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" }]
```

* Index: Os dados são armazenados em conjuntos de dicionários Python aninhados, com cada linha armazenada no formato \{Index -> \{Column -> Value, …},…}. Por exemplo:


```json
{ "0": { "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, "1": { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, "2": { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, "3": { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" } }
```

* Split: Os dados são armazenados num único conjunto de dicionário Python, com os valores guardados em listas. Por exemplo:


```json
{ "columns": ["ID", "Name", "Gender", "State"], "index": [0, 1, 2, 3], "data": [ [1, "Jack", "M", "MO"], [2, "Jill", "F", "MO"], [3, "George", "M", "VA"], [4, "Abe", "M", "KY"] ] }
```

Para além dos formatos acima, é aceite JSON delimitado por novas linhas (NDJSON): um objeto JSON autónomo por linha, sem matriz envolvente. Por exemplo:

```json
{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }
{ "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }
```


### Documento completo

Para manter intacto o JSON de cada ficheiro, selecione **Importar cada ficheiro como uma linha com todo o documento JSON** (`whole_document`) em **Mais opções de JSON**. Cada ficheiro é então importado como uma linha que contém todo o seu documento JSON, com os números mantidos tal como foram escritos.
