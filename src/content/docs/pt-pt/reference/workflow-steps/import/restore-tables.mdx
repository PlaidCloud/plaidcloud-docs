## Descrição

Restaura tabelas de projeto a partir de um arquivo criado por [Arquivar tabelas](/pt-pt/reference/workflow-steps/export/archive-tables/). Utilize-o para mover dados de tabelas entre projetos ou áreas de trabalho, ou para reverter para uma cópia guardada.

## Itens de configuração específicos

### Origem

O ficheiro de arquivo numa conta de documentos. O seletor também permite a correspondência por pesquisa — exata, começa com, termina com, contém ou glob — em vez de um caminho exato.

### Substituir

Desativado por predefinição. Quando desativado, uma tabela que já exista no projeto é deixada como está. Ative para substituir as tabelas existentes pelas cópias arquivadas.
