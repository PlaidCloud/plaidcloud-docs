## Descrição


Importa dados do Google BigQuery para uma tabela de projeto do PlaidCloud. Útil para organizações que utilizam o BigQuery como principal armazém de análise e que trazem conjuntos de dados específicos para o PlaidCloud para trabalho adicional de modelação ou alocação.

A autenticação utiliza uma conta de serviço do Google Cloud; o conjunto de dados e a tabela de origem são configurados ao nível do passo.
