## Descrição


Importa ficheiros de dados Stata (.dta) para tabelas de projeto do PlaidCloud. Útil para organizações que utilizam o Stata para análise econométrica ou estatística e que trazem os seus conjuntos de dados de trabalho para o PlaidCloud para processamento adicional.

As etiquetas de variáveis são preservadas sempre que o formato Stata as inclui.
