## Descrição

Importe ficheiros Apache ORC a partir do PlaidCloud Document. O ORC é um formato de armazenamento em colunas escrito pelo Hive e pelo Spark, com o esquema incluído no ficheiro.

O formulário do passo tem três separadores:

- **Parâmetros de importação** — o **Ficheiro de origem** (uma conta de documentos e o caminho do ficheiro ou da pasta) e a **Tabela de destino**, com **Remover carateres não ASCII** (`ascii_only`), **Eliminar ficheiro(s) após a importação** (`delete_file`) e **Ignorar a reimportação se os ficheiros de origem não tiverem sido alterados** (`skip_if_unchanged`).
- **Seleção de dados da tabela** — mapeia as colunas de origem para as colunas de destino, com **Resumir** e **Distinto**. **Preencher** lê as colunas e os respetivos tipos a partir do esquema incluído no ficheiro ORC.
- **Filtros de dados** — filtra as linhas antes e depois de resumir.

Quando o ficheiro não existe ou está vazio, **Preencher** responde *Nada para preencher* com um aviso que indica o caminho e mantém o mapeamento existente.

Os [projetos Prophecy migrados](/pt-pt/guides/workflows/migrate-prophecy-projects/) utilizam este passo para conjuntos de dados ORC.
