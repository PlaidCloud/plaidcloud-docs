## Descrição


Importa uma ou mais tabelas de uma base de dados externa (configurada através de um conector de base de dados) para tabelas de projeto. Suporta **carregamentos delta** — obtendo apenas as linhas que mudaram desde a última importação — e **remapeamento do nome da tabela** — colocando a tabela de origem no PlaidCloud com um nome diferente.

Utilize-o para manter as tabelas do PlaidCloud sincronizadas com sistemas de origem operacionais de forma agendada, sem reimportar todas as linhas de cada vez.

<Aside title="Inspecionar origem lê a base de dados externa">
Para uma tabela adicionada a este passo, o botão **Inspecionar origem** lê as colunas atuais dessa tabela diretamente da base de dados ligada e atualiza no local apenas o mapeamento dessa tabela. Utilize-o quando as colunas de uma tabela de origem tiverem mudado desde que configurou o passo, sem voltar a executar a deteção em toda a ligação.
</Aside>

<Aside title="Tipos de coluna do PostgreSQL">
Numa origem PostgreSQL, as colunas `uuid` são importadas como texto e as colunas `json`/`jsonb` são importadas como a respetiva representação de texto JSON.
</Aside>

<Aside title="As colunas numéricas são importadas como decimais exatos">
Uma coluna `numeric`/`decimal` de origem é importada como um valor decimal exato, com até 28 dígitos à esquerda da vírgula decimal e 10 dígitos à direita. Um valor com mais de 10 casas decimais é arredondado para caber; um valor com mais de 28 dígitos inteiros interrompe a importação, indicando a coluna.
</Aside>

<Aside type="caution" title="Um valor que não cabe na sua coluna interrompe a importação">
Se um valor de origem não couber na respetiva coluna de destino sem perda de dados — uma fração numa coluna de inteiros, um número demasiado grande para a sua coluna, ou `NaN`/`Infinity` numa coluna numérica —, a importação é interrompida com um erro que indica a coluna e o respetivo tipo de dados, em vez de truncar ou arredondar silenciosamente. No Data Mapper do passo, defina o **Tipo** dessa coluna para um que possa conter o valor e execute novamente a importação.
</Aside>
