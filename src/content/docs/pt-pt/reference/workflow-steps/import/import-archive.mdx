## Descrição


Importa um ficheiro de arquivo nativo do PlaidCloud de volta para uma tabela de projeto. O formato de arquivo preserva os tipos de coluna, os metadados e os índices que não sobrevivem a uma conversão de ida e volta para CSV.

Criado por [Export to Table Archive](/pt-pt/reference/workflow-steps/export/export-to-table-archive/). Utilizado para cópias de segurança de projetos, migrações entre áreas de trabalho ou ambientes e transferência fiável de dados com tipos.
