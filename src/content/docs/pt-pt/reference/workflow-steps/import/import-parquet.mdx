## Descrição

Importe ficheiros Apache Parquet a partir do PlaidCloud Document. O Parquet é um formato de armazenamento em colunas amplamente utilizado no ecossistema Hadoop e em plataformas de dados na cloud, que oferece compressão e codificação eficientes para grandes conjuntos de dados.

As importações de Parquet são transmitidas através de armazenamento temporário, em vez de carregarem o ficheiro inteiro em memória, pelo que ficheiros muito grandes são importados sem esgotar a memória. Os tipos de dados do ficheiro — decimais, datas e carimbos de data/hora — são preservados na tabela de destino, e as colunas de carimbo de data/hora mantêm a precisão completa de data e hora do dia.
