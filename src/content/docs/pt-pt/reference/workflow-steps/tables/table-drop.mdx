## Descrição

Remove totalmente uma tabela do projeto — tanto a definição da tabela como todos os seus dados. Esta ação é destrutiva e irreversível; depois de o fluxo de trabalho ser executado, a tabela deixa de existir.

Utilize-o quando as tabelas intermédias de um fluxo de trabalho já não forem necessárias a jusante (por exemplo, na limpeza após uma transformação com vários passos). Para esvaziar temporariamente uma tabela sem a remover, utilize antes o passo [Table Clear](/pt-pt/reference/workflow-steps/tables/table-clear/).
