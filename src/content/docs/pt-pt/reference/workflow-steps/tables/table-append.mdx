## Descrição

Adiciona linhas de uma tabela de origem ao fim de uma tabela de destino existente. As linhas existentes no destino são preservadas; apenas são inseridas linhas novas. Utilize-o quando os dados chegam de forma incremental (p. ex., extrações diárias, ficheiros de carga mensais) e pretende fazer crescer o destino ao longo do tempo em vez de o substituir.

Se precisar de eliminar duplicados ao acrescentar, siga com um passo [Table Union Distinct](/pt-pt/reference/workflow-steps/tables/table-union-distinct/) ou utilize [Table Upsert](/pt-pt/reference/workflow-steps/tables/table-upsert/) se algumas linhas atualizarem registos existentes por chave.

## O que é verificado ao guardar

- **O mapeamento é adequado a uma tabela de destino existente.** Quando a tabela de destino já existe, o passo não pode mapear uma coluna que a tabela não tem, nem dar a uma coluna um tipo diferente do da tabela. Numérico e moeda contam como o mesmo tipo. Uma coluna da tabela que o mapeamento omita é permitida e fica vazia nas linhas acrescentadas. A recusa indica cada diferença, por exemplo *The target columns must match the existing target table 'sales'. Types differ: amount (table: numeric, step: text).* Uma tabela de destino que ainda não exista, ou indicada com uma variável, é verificada quando o passo é executado.
- **Um mapeamento vazio é preenchido por si.** Ao guardar com uma tabela de origem escolhida mas sem colunas de origem ou de destino, o lado vazio é preenchido a partir da origem, tal como faria **Preencher ambas as tabelas de mapeamento**.
