## Descrição

Preenche uma tabela de destino a partir de um `SELECT` SQL escrito por si. Enquanto o passo [Table Extract](/pt-pt/reference/workflow-steps/tables/table-extract/) constrói a consulta a partir de colunas e expressões mapeadas, este passo entrega a consulta diretamente ao armazém de dados — para os casos em que o SQL é mais fácil de expressar diretamente do que de montar no mapeador.

Recorra a ele quando precisar de uma construção que o mapeador não cobre: uma CTE recursiva, uma função de janela sobre uma partição que o mapeador não consegue descrever, ou uma consulta a várias tabelas que um passo de junção tornaria mais complicada.

## Itens de configuração específicos

### Consulta SQL Select

O texto da consulta. Formate-o como SQL legível, em várias linhas e com indentação — uma coluna ou cláusula por linha — em vez de uma única linha longa; o passo preserva o que escrever e a pessoa que o abrir a seguir tem de o ler.

A consulta é executada no lakehouse do projeto, pelo que as funções disponíveis são as do conjunto [Lakehouse v1](/pt-pt/reference/expressions/lakehouse-v1/) ou [v2](/pt-pt/reference/expressions/lakehouse-v2/), consoante a área de trabalho.
