## Descrição

Preenche uma tabela de destino a partir de um `SELECT` SQL que escreve você mesmo. Enquanto [Table Extract](/pt-pt/reference/workflow-steps/tables/table-extract/) constrói a consulta a partir de colunas mapeadas e expressões, este passo entrega a consulta diretamente ao armazém de dados — para os casos em que o SQL é mais fácil de exprimir diretamente do que de montar no mapeador.

Recorra a ele quando precisar de uma construção que o mapeador não cobre: uma CTE recursiva, uma função de janela sobre uma partição que o mapeador não consegue descrever, ou uma consulta a várias tabelas que um passo de junção tornaria mais complicada.

## Itens de configuração exclusivos

### Consulta SQL Select

O texto da consulta. Formate-o como SQL legível, em várias linhas e indentado — uma coluna ou cláusula por linha — em vez de uma única linha longa; o passo preserva o que escrever e a pessoa seguinte que o abrir tem de o ler.

A consulta é executada no Lakehouse do projeto, pelo que as funções disponíveis são o conjunto [Lakehouse v1](/pt-pt/reference/expressions/lakehouse-v1/) ou [v2](/pt-pt/reference/expressions/lakehouse-v2/), consoante a área de trabalho.

<SnippetCommonStepPreview />

Ao contrário dos outros passos SQL, este passo não preenche variáveis, pelo que a sua pré-visualização também não.
