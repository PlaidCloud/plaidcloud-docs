## Descrição


Utilize-o, como seria de esperar, para executar uma operação de junção cruzada em 2 tabelas de dados, combinando-as numa única tabela de dados sem chave(s) de junção.


Um filtro de origem em qualquer das tabelas é aplicado antes de a junção ser dimensionada, pelo que uma junção cruzada filtrada sobre tabelas grandes é executada quando as linhas filtradas são suficientemente poucas.

Para mais detalhes sobre a metodologia da junção cruzada, consulte aqui: [Wikipedia SQL Cross Join](https://en.wikipedia.org/wiki/Join_%28SQL%29#Cross_join)

## Colunas indicadas em tempo de execução

Selecione **Transportar também colunas indicadas em tempo de execução** para transmitir, sem alterações, todas as colunas de origem que o passo não lista, tal como a tabela as tem quando o passo é executado. Utilize-o quando um passo anterior cria colunas cujos nomes dependem dos dados, como um pivot, e por isso não é possível listá-las ao criar o passo. Deixe a opção desativada para escrever apenas as colunas que listar.
