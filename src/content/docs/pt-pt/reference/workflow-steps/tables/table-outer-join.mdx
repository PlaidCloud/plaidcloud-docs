## Descrição

Utilize-o para executar uma junção externa em 2 tabelas de dados, combinando-as numa única tabela de dados com base na(s) chave(s) de junção indicada(s). O controlo **Tipo de junção** seleciona as linhas sem correspondência a manter — uma junção **à esquerda**, **à direita** ou **externa completa**. A predefinição é uma junção à esquerda (todas as linhas da Tabela A, com as colunas da Tabela B preenchidas onde as chaves correspondem).

Para mais detalhes sobre a metodologia da junção externa, consulte aqui: [Wikipedia SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## Colunas indicadas em tempo de execução

Selecione **Transportar também colunas indicadas em tempo de execução** para transmitir, sem alterações, todas as colunas de origem que o passo não lista, tal como a tabela as tem quando o passo é executado. Utilize-o quando um passo anterior cria colunas cujos nomes dependem dos dados, como um pivot, e por isso não é possível listá-las ao criar o passo. Deixe a opção desativada para escrever apenas as colunas que listar.

### Tipo de junção

Escolha como as linhas sem correspondência são mantidas:

- **Junção à esquerda** — mantém todas as linhas da Tabela A; as colunas da Tabela B só são preenchidas onde as chaves de junção correspondem. Esta é a predefinição.
- **Junção à direita** — mantém todas as linhas da Tabela B; as colunas da Tabela A só são preenchidas onde as chaves de junção correspondem.
- **Junção externa completa** — mantém todas as linhas das duas tabelas, quer tenham ou não correspondência do outro lado.

## Exemplos

### Juntar fabricantes de automóveis com modelos

Neste exemplo, considere as seguintes tabelas de dados de origem. A primeira é uma lista de fabricantes de automóveis.

| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |

A seguinte é uma lista de modelos de automóveis com um ID de fabricante. Repare que vários modelos não têm fabricante.

| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

Para obter uma lista de modelos por fabricante, faz sentido juntar por *Mfg_ID*. Ao recorrer a conceitos de junção externa, a saída consegue mostrar também os itens que não têm qualquer correspondência.

Em primeiro lugar, especifique os parâmetros de **Seleção de dados da tabela 1**. A tabela de dados de origem é selecionada e todas as colunas são listadas.

Em seguida, especifique os parâmetros de **Seleção de dados da tabela 2.** Mais uma vez, a tabela de dados de origem é selecionada e todas as colunas são listadas.

Por fim, as condições de junção são definidas no separador **Saída da tabela**. Com o botão **Deduzir**, o Analyze identifica corretamente a coluna *Mfg_ID* a utilizar como **Chave de junção**. Como este exemplo mantém as linhas sem correspondência de ambas as tabelas, defina o **Tipo de junção** como **Junção externa completa**. Por último, as 
**Colunas de saída de destino** são especificadas automaticamente com o botão **Propagar**. Isto inclui, na prática, todas as colunas de todas as tabelas, com as colunas de junção, como é óbvio, incluídas apenas uma vez. Repare que as colunas estão ordenadas alfabeticamente, primeiro por *Manufacturer* e depois por *ModelName*.

Como esperado, a saída final inclui todas as linhas das duas tabelas, tenham ou não correspondência em ambas. Assim, desta vez *Porsche* aparece mesmo sem ter modelos. Além disso, *Batmobile*, *Lightning McQueen* e *Optimus Prime* são incluídos nos resultados apesar de nenhum deles ter fabricante. Afinal, quem consegue dizer «Não» a eles?
