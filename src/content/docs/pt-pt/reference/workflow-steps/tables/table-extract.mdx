## Descrição


Usado para extrair dados de uma tabela de dados do Analyze existente para outra tabela de dados. Os exemplos incluem, entre outros, os seguintes:


* Ordenação
* Agrupamento
* Resumo
* Filtrar/selecionar subconjunto de linhas
* Eliminar colunas a mais
* Operações matemáticas
* Operações com cadeias de caracteres

<Aside>Não existem funções exclusivas desta transformação. Toda a ordenação, agrupamento, filtragem, etc. pode ser feita em qualquer outra transformação com os separadores **Colunas** e **Filtros**.</Aside>

## Colunas indicadas em tempo de execução

Selecione **Transportar também colunas indicadas em tempo de execução** para passar, sem alterações, todas as colunas de origem que o passo não lista, tal como a tabela as tem quando o passo é executado. Use-o quando um passo anterior cria colunas cujos nomes dependem dos dados, como uma pivotagem, de modo que não as pode listar ao construir o passo. Deixe-o desativado para escrever apenas as colunas que lista.

Quando está ativo, surge uma secção **Colunas carregadas**, e uma secção **Colunas nomeadas pelos dados** está sempre disponível. Têm estes campos:

* **Carregar como** (`carry_expression`) — escreva cada coluna transportada como esta expressão em vez de sem alterações, com `__column__` a representar a coluna transportada. É assim que um passo que agrupa integra colunas que só a execução nomeia; um passo que agrega não transporta nada sem isto. **Tipo das colunas carregadas** (`carry_dtype`) define o tipo de dados de cada coluna transportada (por predefinição, o seu próprio) e **Agregação das colunas carregadas** (`carry_agg`) define como um passo de agregação a trata (`dont_group` quando a expressão agrega).
* **Renomear colunas transportadas** (`carry_rename`) — mude o nome de cada coluna transportada cujo nome corresponda à expressão regular `pattern`, e que `keep` não abranja, colocando `replacement` no lugar de cada correspondência (`\1` para um grupo; as primeiras `max` correspondências, quando definido). `__index__` em `replacement` é a posição da coluna entre as colunas renomeadas, contada a partir de `start`. A um nome já ocupado é acrescentado ` (#n)`.
* **Colunas dinâmicas** (`dynamic_columns`) — colunas de destino nomeadas pelos dados, um conjunto por cada valor distinto que o passo lê da sua origem, escritas quando o passo é executado. Cada entrada indica `rows` (expressões `key`, `label`, `where` e `order` sobre a origem), uma coluna `target` ou lista de colunas que usa `__key__`, `__label__` e `__index__`, e `after`, a coluna de destino a seguir à qual as novas ficam (por predefinição, o fim). Os valores têm de ser texto, inteiro, booleano ou NULL, o passo escreve no máximo 1000 colunas e a saída tem de ser uma tabela. Quando o passo é executado, as expressões `rows` e o filtro do passo têm de cumprir as regras de [Funções e operadores recusados](/pt-pt/reference/workflow-steps/common/advanced-data-mapper-usage/#funções-e-operadores-recusados); caso contrário, o passo falha.
