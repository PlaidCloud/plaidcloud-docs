## Descrição


Utilizado para extrair dados de uma tabela de dados existente do Analyze para outra tabela de dados. Os exemplos incluem, entre outros, os seguintes:


* Ordenar
* Agrupar
* Sumarização
* Filtrar/selecionar subconjunto de linhas
* Eliminar colunas adicionais
* Operações matemáticas
* Operações com cadeias de caracteres

<Aside>Não existem funções exclusivas desta transformação. Toda a ordenação, agrupamento, filtragem, etc. pode ser realizada em qualquer outra transformação com os separadores **Seleção de dados da tabela** e **Filtros de dados**.</Aside>

## Colunas indicadas em tempo de execução

Selecione **Transportar também colunas indicadas em tempo de execução** para passar, sem alterações, todas as colunas de origem que o passo não lista, tal como a tabela as tem quando o passo é executado. Utilize-o quando um passo anterior cria colunas cujos nomes dependem dos dados, como uma tabela dinâmica, de modo que não é possível listá-las ao construir o passo. Deixe-o desativado para escrever apenas as colunas que lista.

Quando está ativado, aparece uma secção **Colunas carregadas** e fica sempre disponível uma secção **Colunas nomeadas pelos dados**. Têm os seguintes campos:

* **Carregar como** (`carry_expression`) — escreve cada coluna carregada como esta expressão em vez de sem alterações, com `__column__` a representar a coluna carregada. É assim que um passo que agrupa incorpora colunas que só a execução indica; um passo que agrega não carrega nada sem isto. **Tipo das colunas carregadas** (`carry_dtype`) define o tipo de dados de cada coluna carregada (por predefinição, o seu próprio) e **Agregação das colunas carregadas** (`carry_agg`) define como um passo de agregação a trata (`dont_group` quando a expressão agrega).
* **Renomear colunas transportadas** (`carry_rename`) — muda o nome de cada coluna carregada cujo nome corresponda à expressão regular `pattern` e não corresponda a `keep`, colocando `replacement` no lugar de cada correspondência (`\1` para um grupo; as primeiras `max` correspondências, quando definido). `__index__` em `replacement` é a posição da coluna entre as colunas renomeadas, contada a partir de `start`. Um nome já ocupado recebe ` (#n)` acrescentado.
* **Colunas dinâmicas** (`dynamic_columns`) — colunas de destino nomeadas pelos dados, um conjunto para cada valor distinto que o passo lê da sua origem, escritas quando o passo é executado. Cada entrada indica `rows` (expressões `key`, `label`, `where` e `order` sobre a origem), uma coluna `target` ou lista de colunas que utiliza `__key__`, `__label__` e `__index__`, e `after`, a coluna de destino após a qual as novas se seguem (por predefinição, o fim). Os valores têm de ser texto, inteiro, booleano ou NULL, o passo escreve no máximo 1000 colunas e o resultado tem de ser uma tabela.
