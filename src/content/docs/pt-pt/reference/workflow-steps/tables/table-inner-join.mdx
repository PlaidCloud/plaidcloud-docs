## Descrição


Utilize-o, como seria de esperar, para executar uma operação de junção interna em 2 tabelas de dados, combinando-as numa única tabela de dados com base na(s) chave(s) de junção indicada(s).


Para mais detalhes sobre a metodologia da junção interna, consulte aqui: [Wikipedia SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## Colunas indicadas em tempo de execução

Selecione **Transportar também colunas indicadas em tempo de execução** para transmitir, sem alterações, todas as colunas de origem que o passo não lista, tal como a tabela as tem quando o passo é executado. Utilize-o quando um passo anterior cria colunas cujos nomes dependem dos dados, como um pivot, e por isso não é possível listá-las ao criar o passo. Deixe a opção desativada para escrever apenas as colunas que listar.

## Exemplos


### Juntar fabricantes de automóveis com modelos


Neste exemplo, considere as seguintes tabelas de dados de origem. A primeira é uma lista de fabricantes de automóveis.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

A seguinte é uma lista de modelos de automóveis com um ID de fabricante. Repare que vários modelos não têm fabricante.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

Para obter uma lista de modelos por fabricante, faz sentido juntar por *Mfg_ID*.


Em primeiro lugar, especifique os parâmetros de **Seleção de dados da tabela 1**. A tabela de dados de origem é selecionada e todas as colunas são listadas.



Em seguida, especifique os parâmetros de **Seleção de dados da tabela 2**. Mais uma vez, a tabela de dados de origem é selecionada e todas as colunas são listadas.



Por fim, as condições de junção são definidas no separador **Saída da tabela**. Com o botão **Deduzir**, o Analyze identifica corretamente a coluna *Mfg_ID* a utilizar como **Chave de junção**. Por último, as 


**Colunas de saída de destino** são especificadas automaticamente com o botão **Propagar**. Isto inclui, na prática, todas as colunas de todas as tabelas, com todas as colunas de junção incluídas uma única vez. Repare que as colunas estão ordenadas alfabeticamente, primeiro por *Manufacturer* e depois por *ModelName*.



Como esperado, a saída final inclui apenas os valores que tinham correspondência nas duas tabelas. Assim, *Porsche* não aparece porque não tinha modelos. Da mesma forma, o 


*Batmobile* não tinha fabricante (era um modelo personalizado), pelo que não está incluído.
