## Descrição


Crie uma cópia de uma tabela de dados.




<SnippetCommonTableSourceAndTarget />



Ao efetuar a cópia, o Analyze verifica primeiro se a tabela de dados de destino já existe. Se existir, não é realizada qualquer ação, a menos que a caixa de verificação **Allow Overwriting Existing Table** esteja selecionada. Nesse caso, a tabela de destino é substituída.
