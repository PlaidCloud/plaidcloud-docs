## Descrição

O passo **Tabela: KNIME Random Sample** efetua o sorteio aleatório de um nó do KNIME com o gerador de números aleatórios que o KNIME utiliza, pelo que um nó com semente sorteia as mesmas linhas ou valores no PlaidCloud e no KNIME. Os [fluxos de trabalho do KNIME migrados](/pt-pt/guides/workflows/migrate-knime-workflows/) utilizam este passo para Row Sampler, Table Partitioner, Equal Size Sampling, Bootstrap Sampling, Shuffle, X-Partitioner e os nós de geração aleatória de dados.

O sorteio lê a tabela de origem para o fluxo de trabalho, pelo que aceita uma tabela com, no máximo, 10 000 000 de linhas; uma tabela maior faz o passo falhar.

O formulário do passo tem uma secção **Tabelas** para as tabelas de origem e de saída, uma secção **Sorteio** para o **Método**, a **Semente** e a dimensão da amostra, e uma secção **Colunas** para as colunas lidas e escritas.

## Configuração

- `source` e `target_frame` — a tabela a ler e a tabela a escrever.
- `position_column` — a coluna que contém a posição de cada linha, a partir de 0. A predefinição é `_knime_pos`.
- `method` — o sorteio:
  - `random`, `stratified`, `equal_exact` e `equal_approximate` mantêm as posições das linhas que um sorteio de Row Sampler, Table Partitioner ou Equal Size Sampling seleciona. `class_column` e `class_dtype` indicam a coluna de classe de um sorteio estratificado ou de dimensão igual.
  - Todos os outros métodos escrevem o sorteio ao lado das posições das linhas: `uniform`, `gaussian`, `gamma`, `beta`, `label`, `label_dependent`, `label_from_table`, `boolean`, `mersenne_twister`, `sobol` e `halton` (geração aleatória de dados), `shuffle`, `bootstrap`, `match` (Random Matcher), `item_insert` (Random Item Inserter), `stress` (Stresser), `sample_data` (Sample Data Generator, sem tabela de origem), `kfold` (partições do X-Partitioner), `p_square` (estimativas de percentis P² por grupo), `set_bits` (vetores de bits), `equal_count_edges` (os limites de contagem igual do Binner) e `border_texts` (os textos de limite do Auto-Binner).
- `seed` — a semente do fluxo aleatório. Se estiver vazia, usa o relógio, como o KNIME sem semente, pelo que as linhas variam de execução para execução.
- `count`, `percentage` e `relative` — quantas linhas sortear: uma contagem ou, com `relative`, uma percentagem. `count_column` obtém a contagem de uma coluna de origem, para uma contagem conhecida apenas quando o fluxo de trabalho é executado.
- `parameters` — as definições do nó que os métodos de sorteio leem, como a distribuição de um sorteio `gaussian` ou o número de partições de um sorteio `kfold`.
- `source_columns` e `target_columns` — para os métodos de sorteio, as colunas lidas e as colunas escritas, com a coluna de posição em primeiro lugar.
- `source_b` e `source_columns_b` — uma segunda entrada, como a tabela de categorias de `label_from_table` ou a tabela de onde `match` sorteia. `target_frame_b` e `target_columns_b` recebem os centros de agrupamento de `sample_data`.
