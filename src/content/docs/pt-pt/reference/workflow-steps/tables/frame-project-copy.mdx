## Descrição

Copia uma tabela de um projeto para outro. Utilize-o para trazer entre projetos uma tabela de referência partilhada, um conjunto de resultados publicado ou uma pesquisa baseada em dimensões, sem exportar para um ficheiro e voltar a importá-lo.

Ambos os lados são indicados explicitamente — um projeto e uma tabela de origem, e um projeto e uma tabela de destino. O projeto de destino começa por ser o projeto atual, mas pode ser qualquer projeto, pelo que um passo pode copiar para este projeto, a partir dele ou entre dois outros. A tabela de destino é criada se não existir e tem de ser uma tabela, e não uma vista.

## Gestão de partilha de dados

Uma cópia precisa de até duas partilhas de dados:

- **Leitura, do projeto de origem para o projeto de destino**, para que os dados da origem cheguem apenas aonde a origem os partilha. Abra o separador **Início** do projeto de **origem** e, em **Gestão de partilha de dados**, clique em **Nova partilha de dados**, selecione o projeto de destino, marque **Leitura** em **Operações permitidas** e clique em **Adicionar partilha de dados**.
- **Escrita, do projeto de destino para este projeto** — o projeto em que o fluxo de trabalho está, que faz a escrita — quando o destino é outro projeto. Abra o separador **Início** do projeto de **destino** e, em **Gestão de partilha de dados**, clique em **Nova partilha de dados**, selecione este projeto, marque **Escrita** em **Operações permitidas** e clique em **Adicionar partilha de dados**.

Assim, uma cópia para este projeto precisa apenas da partilha de leitura, e uma cópia dentro de um só projeto não precisa de nenhuma. Consulte [Partilhar dados entre projetos](/pt-pt/guides/projects/managing-projects/#partilhar-dados-entre-projetos).

Sem uma partilha de que precise, a gravação do passo é recusada e a execução falha, com uma mensagem que indica cada partilha a adicionar — por exemplo, *Project 'Sales' can't write to project 'Finance': in project 'Finance', under Data Sharing Management, add a data share for 'Sales' that allows Write.* Uma execução recusada deixa o projeto de destino como estava, sem criar a tabela de destino. Um projeto indicado como variável é verificado quando o passo é executado.

O passo é executado com a identidade do próprio projeto, pelo que uma execução funciona através das partilhas, seja quem for que a inicie.

## Parâmetros de cópia

### Ler de

- **Projeto de origem** — o projeto de onde copiar.
- **Tabela de origem** — a tabela a copiar, escolhida a partir do projeto de origem.

### Escrever em

- **Projeto de destino** — o projeto para onde copiar. Começa por ser o projeto atual.
- **Tabela de destino** — a tabela a escrever, escolhida a partir do projeto de destino. Escolher um **Projeto de destino** diferente limpa uma tabela que tenha escolhido a partir do anterior; uma tabela indicada por nome ou caminho é mantida e procurada no novo projeto.
- **Acrescentar aos dados existentes** — marque para adicionar as linhas copiadas ao que a tabela de destino já contém. Deixe desmarcada para substituir as linhas da tabela pelas da origem.

Um projeto guardado que não consiga ver, ou que tenha sido eliminado, é mostrado assinalado com **(em falta)** em vez de ser trocado por outro projeto.
