## Descrição


Utilizado para converter tabelas de dados longas e estreitas em tabelas de dados curtas e largas. As colunas selecionadas são transpostas, com os nomes das colunas convertidos em valores ao longo de várias colunas.


Talvez o exemplo mais fácil de compreender seja pensar numa tabela de dados com meses listados como linhas:





Pivotar esta tabela de dados converteria todas as linhas de meses em colunas.

### Seleção de colunas para pivotar

A **Coluna de categoria a transformar em cabeçalhos de coluna** é onde especifica a coluna da tabela de origem que será pivotada para linhas.

A **Coluna de valor a pivotar para valores de coluna** é a coluna que contém os valores na tabela de origem.

A **Opção de agregação de valores** é onde especifica como pretende agregar os dados.

Ambas as colunas têm de estar entre as colunas de saída do passo no separador **Seleção de dados da tabela**. Caso contrário, a gravação é recusada, por exemplo com *The category column 'month' isn't one of the step's output columns.*


O formulário tem ainda estes campos:

* **Coluna com a posição de cada categoria** (`column_order`) — uma coluna de origem que contém a posição de cada categoria. As colunas pivotadas surgem por ordem ascendente dessa posição, em vez de ordenadas por nome. Não é agrupada nem escrita.
* **Modelo de nome das colunas dinâmicas** (`column_name_template`) — dá a cada coluna pivotada o nome deste texto, com `{value}` substituído pelo valor da categoria, como `{value}+Sum`.

## Seleção de dados da tabela

![Table Pivot Data Selection](/images/table_pivot_2.png)


O separador Seleção de dados da tabela serve para mapear colunas da tabela de dados de origem para a tabela de dados de destino. Todas as colunas de origem no lado esquerdo da janela são mapeadas automaticamente para a tabela de dados de destino representada no lado direito da janela. Com o botão de menu **Inspecionar origem**, existem algumas formas adicionais de mapear colunas da origem para o destino:


* Preencher ambas as tabelas de mapeamento: propaga todos os valores da tabela de dados de origem para a tabela de dados de destino. É a opção predefinida.
* Preencher apenas a tabela de mapeamento de origem: mapeia apenas todos os valores na tabela de dados de origem. É útil ao modificar um fluxo de trabalho existente quando a estrutura das colunas de origem mudou.
* Preencher apenas a tabela de mapeamento de destino: propaga todos os valores apenas para a tabela de dados de destino.

Além de cada uma destas opções, cada escolha oferece a possibilidade de pré-visualizar os dados de origem.

Ao guardar com uma tabela de origem escolhida mas sem colunas de origem ou sem colunas de destino, o lado vazio é preenchido a partir da origem, tal como faria **Preencher ambas as tabelas de mapeamento**.



Se as opções de colunas de origem e de destino não forem suficientes, é possível adicionar outras colunas à tabela de dados de destino de várias formas:


* **Propagar tudo** insere todas as colunas de origem na tabela de dados de destino, quer já existissem ou não.
* **Propagar selecionadas** insere apenas as colunas de origem selecionadas.
* Clique com o botão direito do rato no lado do destino e selecione **Inserir linha** para inserir uma linha imediatamente acima da linha atualmente selecionada.
* Clique com o botão direito do rato no lado do destino e selecione **Acrescentar linha** para inserir uma linha no fim (extrema direita) da tabela de dados de destino.


<Aside type="danger">Selecionar **Propagar tudo** pode criar, na prática, um duplicado de todas as colunas. O Analyze não verifica se as colunas já estão mapeadas. Certifique-se de que não existem nomes de colunas duplicados.</Aside>




Para eliminar colunas da tabela de dados de destino, selecione as colunas pretendidas, clique com o botão direito do rato e selecione **Eliminar**.



Para reorganizar as colunas na tabela de dados de destino, selecione as colunas pretendidas, clique com o botão direito do rato e selecione **Mover para o início**, **Mover para cima**, **Mover para baixo** ou **Mover para o fim**.



Para devolver apenas opções distintas, selecione a opção de menu **Distinto**. Isto ativa um conjunto de caixas de verificação para cada coluna da origem. Basta assinalar a caixa junto à coluna correspondente para devolver apenas resultados distintos.

<Aside type="danger">Quando a tabela de dados de destino contém apenas um subconjunto da tabela de dados de origem, assinale a caixa de verificação apenas junto às colunas que **devem** ser incluídas na tabela de dados de destino. Assinalar todas as caixas pode produzir uma saída que não parece distinta.</Aside>




Para agregar resultados, selecione a opção de menu **Resumir**. Isto ativa um conjunto de listas pendentes para cada coluna da tabela de dados de destino. Estão disponíveis as seguintes opções de resumo:


* Agrupar por (definição predefinida)
* Soma
* Mínimo
* Máximo
* Primeiro
* Último
* Contagem
* Média
* Mediana
* Moda
* Desvio-padrão
* Variância
* Produto
* Valor absoluto
* Quantil
* Assimetria
* Curtose
* Desvio absoluto médio
* Soma cumulativa
* Mínimo cumulativo
* Máximo cumulativo
* Produto cumulativo




## Filtros de dados


Para permitir a máxima flexibilidade, estão disponíveis filtros de dados nos dados de origem e nos dados de destino. Para conjuntos de dados maiores, pode ser especialmente vantajoso filtrar linhas na origem, para que as restantes operações sejam realizadas sobre um conjunto de dados mais pequeno.



### Selecionar subconjunto de dados


Qualquer expressão Python válida é aceite para criar o subconjunto dos dados. Consulte [Expressões](/pt-pt/reference/expressions/)


para mais detalhes e exemplos.






### Aplicar filtro secundário aos dados do resultado


Qualquer expressão Python válida é aceite para criar o subconjunto dos dados. Consulte [Expressões](/pt-pt/reference/expressions/) para mais detalhes e exemplos



### Segmentação final da tabela de dados (limite)


Para limitar os dados, basta assinalar a caixa **Aplicar segmentador de linhas** e especificar o seguinte:


* **Linhas iniciais a ignorar:** linhas de dados a ignorar (a linha de cabeçalho das colunas não é incluída na contagem)
* **Terminar na linha:** última linha de dados a incluir. É diferente de simplesmente contar linhas no fim para as descartar
