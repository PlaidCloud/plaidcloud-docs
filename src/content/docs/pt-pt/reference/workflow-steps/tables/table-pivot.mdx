## Descrição


Usado para converter tabelas de dados longas e estreitas em tabelas de dados curtas e largas. As colunas selecionadas são transpostas, com os nomes das colunas convertidos em valores ao longo de várias colunas.


Talvez o exemplo mais fácil de compreender seja pensar numa tabela de dados com os meses listados como linhas:





Pivotar esta tabela de dados converteria todas as linhas dos meses em colunas.

### Seleção de colunas para pivotar

A **Coluna de categoria a transformar em cabeçalhos de coluna** é onde especifica a coluna da tabela de origem que será pivotada para linhas.
A **Coluna de valor a pivotar para valores de coluna** é a coluna que contém os valores na tabela de origem.
A **Opção de agregação de valores** é onde especifica como pretende que os dados sejam agregados.

Ambas as colunas têm de estar entre as colunas de saída do passo no separador **Colunas**. Caso contrário, guardar é recusado, por exemplo com *A coluna de categoria 'month' não é uma das colunas de saída do passo.*


O formulário tem também estes campos:

* **Coluna com a posição de cada categoria** (`column_order`) — uma coluna de origem que contém a posição de cada categoria. As colunas pivotadas surgem por ordem ascendente dessa coluna em vez de ordenadas por nome. Não é agrupada nem escrita.
* **Modelo de nome das colunas dinâmicas** (`column_name_template`) — dê nome a cada coluna pivotada com este texto, em que `{value}` é substituído pelo valor da categoria, como `{value}+Sum`.

## Seleção de dados da tabela

![Table Pivot Data Selection](/images/table_pivot_2.png)


O separador Seleção de dados da tabela serve para mapear colunas da tabela de dados de origem para a tabela de dados de destino. Todas as colunas de origem do lado esquerdo da janela são automaticamente mapeadas para a tabela de dados de destino representada no lado direito da janela. Com o botão de menu **Inspecionar origem**, existem algumas formas adicionais de mapear colunas da origem para o destino:


* Preencher ambas as tabelas de mapeamento: propaga todos os valores da tabela de dados de origem para a tabela de dados de destino. É o predefinido.
* Preencher apenas a tabela de mapeamento de origem: mapeia apenas todos os valores da tabela de dados de origem. É útil ao modificar um fluxo de trabalho existente quando a estrutura de colunas de origem mudou.
* Preencher apenas a tabela de mapeamento de destino: propaga todos os valores apenas para a tabela de dados de destino.

Além de cada uma destas opções, cada escolha oferece a possibilidade de pré-visualizar os dados de origem.

Guardar com uma tabela de origem escolhida mas sem colunas de origem ou sem colunas de destino preenche o lado vazio a partir da origem, tal como **Preencher ambas as tabelas de mapeamento** faria.



Se as opções de colunas de origem e de destino não forem suficientes, é possível adicionar outras colunas à tabela de dados de destino de várias formas:


* **Propagar tudo** insere todas as colunas de origem na tabela de dados de destino, quer já existissem ou não.
* **Propagar selecionadas** insere apenas a(s) coluna(s) de origem selecionada(s).
* Clique com o botão direito do rato no lado do destino e selecione **Inserir linha** para inserir uma linha imediatamente acima da linha atualmente selecionada.
* Clique com o botão direito do rato no lado do destino e selecione **Acrescentar linha** para inserir uma linha no fundo (extremo direito) da tabela de dados de destino.


<Aside type="danger">Selecionar **Propagar tudo** pode efetivamente criar um duplicado de cada coluna. O Analyze não verifica se as colunas já estão mapeadas. Certifique-se de que não existem nomes de colunas duplicados.</Aside>




Para eliminar colunas da tabela de dados de destino, selecione a(s) coluna(s) pretendida(s) e depois clique com o botão direito do rato e selecione **Eliminar**.



Para reorganizar colunas na tabela de dados de destino, selecione a(s) coluna(s) pretendida(s) e depois clique com o botão direito do rato e selecione **Mover para o início**, **Mover para cima**, **Mover para baixo** ou **Mover para o fim**.



Para devolver apenas opções distintas, selecione a opção de menu **Distinto**. Isto apresentará um conjunto de caixas de seleção para cada coluna da origem. Basta marcar qualquer caixa junto da coluna correspondente para devolver apenas resultados distintos.

<Aside type="danger">Quando a tabela de dados de destino contém apenas um subconjunto da tabela de dados de origem, marque a caixa de seleção apenas junto das colunas que **devem** ser incluídas na tabela de dados de destino. Selecionar todas as caixas de seleção poderia produzir uma saída que não parece distinta.</Aside>




Para agregar resultados, selecione a opção de menu **Resumir**. Isto apresentará um conjunto de caixas pendentes para cada coluna da tabela de dados de destino. Estão disponíveis as seguintes opções de resumo:


* Agrupar por (definida como predefinição)
* Soma
* Mínimo
* Máximo
* Primeiro
* Último
* Contagem
* Média
* Mediana
* Moda
* Desvio-padrão
* Variância
* Produto
* Valor absoluto
* Quantil
* Assimetria
* Curtose
* Desvio absoluto médio
* Soma cumulativa
* Mínimo cumulativo
* Máximo cumulativo
* Produto cumulativo




## Filtros de dados


Para permitir a máxima flexibilidade, estão disponíveis filtros de dados sobre os dados de origem e os dados de destino. Para conjuntos de dados maiores, pode ser especialmente vantajoso filtrar linhas na origem para que as restantes operações sejam executadas sobre um conjunto de dados mais pequeno.



### Selecionar subconjunto de dados


Qualquer expressão Python válida é aceite para criar o subconjunto dos dados. Consulte [Expressões](/pt-pt/reference/expressions/)


para mais detalhes e exemplos.






### Aplicar filtro secundário aos dados do resultado


Qualquer expressão Python válida é aceite para criar o subconjunto dos dados. Consulte [Expressões](/pt-pt/reference/expressions/) para mais detalhes e exemplos



### Segmentação final da tabela de dados (limite)


Para limitar os dados, basta marcar a caixa **Aplicar segmentador de linhas** e depois especificar o seguinte:


* **Linhas iniciais a ignorar:** linhas de dados a ignorar (a linha de cabeçalho das colunas não é incluída na contagem)
* **Terminar na linha:** última linha de dados a incluir. É diferente de simplesmente contar linhas no fim para as eliminar
