## Descrição

O passo **Tabela: Dividir texto** divide o texto de uma coluna num separador e escreve as partes como novas colunas ou como novas linhas. O número de colunas é decidido quando o passo é executado, a partir do valor com mais partes, pelo que não precisa de o saber antecipadamente.

## Origem e opções

- **Tabela de origem** e **Tabela de saída** — a tabela a ler e a tabela a escrever.
- **Coluna a dividir** — a coluna a dividir. Um número é dividido como texto.
- **Separador** — o texto literal entre as partes. Pode ter qualquer comprimento e não é um padrão. Os espaços são mantidos tal como foram escritos.
- **Dividir em** — **Colunas** ou **Linhas**.
  - **Colunas** escreve `<column>_1`, `<column>_2`, e assim sucessivamente, tantas quantas as do valor com mais partes. Um valor com menos partes fica com NULL nas restantes.
  - **Linhas** escreve uma linha por parte, com a parte no lugar da coluna. As partes vazias permanecem como linhas.
- **Remover espaços à volta de cada parte** — ativado por predefinição.
- **Manter a coluna original** — ativado por predefinição. No modo de colunas, mantém a coluna dividida. No modo de linhas, escreve também o valor por dividir em `<column>_original`.

Um resultado vazio substitui a tabela de saída. Nunca deixa linhas de uma execução anterior.

### Definições adicionais para colunas

**Mais opções de divisão** tem também estas definições quando se divide em colunas:

- **Prefixo do nome das partes** (`prefix`) — dá às partes o nome `<prefix><n>` em vez de `<column>_<n>`. **Número da primeira parte** (`start`, predefinição 1) é o número da primeira parte.
- **Nomes das colunas de partes** (`names`) — os nomes das colunas das partes, por ordem. São escritas exatamente essas colunas, a menos que ative **Escrever apenas tantas colunas nomeadas quantas o maior valor tiver** (`fit`): nesse caso, apenas tantas quantas as do valor com mais partes.
- **Tipo das partes** (`dtype`) — o tipo das partes: `text` (predefinição), `integer`, `bigint`, `double`, `boolean`, `date` ou `timestamp`. Uma parte que não possa ser lida como esse tipo fica NULL.
- **Caracteres a remover** (`strip`) — os caracteres retirados de ambas as extremidades de cada parte, em vez dos espaços que **Remover espaços à volta de cada parte** remove.
- **A coluna contém uma coleção do KNIME** (`collection`) — a coluna contém um valor de lista de um fluxo de trabalho KNIME convertido. Os seus elementos são as partes e o separador não é utilizado: um elemento em falta é NULL e uma lista vazia não tem partes.

**Nó do KNIME** (`knime_config`) executa com este passo um dos nós Line Chopper, Expand Vector ou Sample and Expand Vector do KNIME: `chopper` escreve os primeiros tokens separados por espaços em branco de uma coluna, `expand_vector` escreve os elementos de uma coluna de vetor como colunas, com as posições a manter listadas na tabela **Tabela de posições de elementos** (`source_b`), e `sample_expand_vector` expande uma amostra aleatória dos elementos, escrevendo os nomes das colunas amostradas na tabela indicada em **Tabela de nomes das colunas amostradas** (`targets`).
