## Descrição

O passo **Tabela: Função de texto** aplica uma função de texto às colunas de cada linha que a função lê e escreve o resultado numa nova coluna de uma cópia da tabela de origem. Um NULL em qualquer coluna lida pela função dá NULL.

## Origem e opções

- **Tabela de origem** e **Tabela de saída** — a tabela a ler e a tabela a escrever.
- **Função** — a função a aplicar. O formulário oferece as funções das duas tabelas abaixo e mostra um campo de coluna, com a designação do respetivo papel, para cada argumento que a função selecionada lê.
- **Colunas de argumentos** — as colunas que a função lê, pela ordem em que a tabela as lista. Todas são obrigatórias.
- **Coluna de saída** — o nome da coluna adicionada à cópia da origem.

| Função | Argumentos | Resultado |
| --- | --- | --- |
| `levenshtein` | Primeira coluna, Segunda coluna | Distância de edição com distinção entre maiúsculas e minúsculas, como número inteiro |
| `soundex` | Texto | Texto |
| `json_format` | JSON | Texto JSON formatado de forma legível |
| `json_field` | JSON, Caminho | Texto |
| `json_set_text`, `json_set_number`, `json_set_boolean` | JSON, Caminho, Valor | Texto JSON com o valor definido |
| `regex_match` | Texto, Padrão, Respeitar maiúsculas e minúsculas | Verdadeiro ou falso |
| `regex_search` | Texto, Padrão, Ocorrência, Respeitar maiúsculas e minúsculas | Posição, como número inteiro |
| `regex_extract` | Texto, Padrão, Ocorrência, Respeitar maiúsculas e minúsculas | Texto |
| `regex_replace` | Texto, Padrão, Substituição, Respeitar maiúsculas e minúsculas | Texto |
| `to_text_number` | Número, Padrão | Texto: o número escrito com um padrão ao estilo de DecimalFormat |
| `to_text_datetime` | Data/hora, Padrão | Texto: a data escrita com um padrão de data e hora |
| `parse_date` | Texto, Padrão | O texto lido como data |
| `parse_datetime` | Texto, Padrão | O texto lido como data e hora |

Uma análise Savant convertida pode conter qualquer uma destas funções, e estas são executadas da mesma forma. Uma função que o formulário não oferece mostra as colunas guardadas e é mantida exatamente como foi guardada.

### Mais funções

A lista **Função** oferece também estas funções. Os fluxos de trabalho KNIME convertidos também as utilizam.

| Função | Argumentos | Resultado |
| --- | --- | --- |
| `damerau_levenshtein`, `hamming`, `lcs` | Primeira coluna, Segunda coluna | A distância de edição correspondente, como número inteiro |
| `jaro`, `jaro_winkler` | Primeira coluna, Segunda coluna | 1 menos a semelhança, 0 para textos iguais |
| `ngram_distance` | Primeira coluna, Segunda coluna | 1 menos o coeficiente de Dice dos bigramas de caracteres |
| `jaccard_tokens`, `dice_tokens`, `cosine_tokens` | Primeira coluna, Segunda coluna | 1 menos a semelhança de conjuntos das palavras dos dois textos, 1 quando algum deles não tem palavras |
| `java_compare` | Primeira coluna, Segunda coluna | A diferença dos primeiros carateres distintos, tal como o `compareTo` do Java a fornece, como número inteiro |
| `java_regex` | Texto, Padrão, Substituição *(apenas no modo replace)* | Uma expressão regular Java lida de uma coluna: verdadeiro ou falso nos modos `matches` e `find`, texto em `extract` e `replace` |
| `knime_count` | Texto, Texto de pesquisa | Quantas vezes o texto de pesquisa ocorre, como número inteiro |
| `knime_binomial`, `long_pow` | Dois números | O coeficiente binomial, ou a potência inteira, em aritmética de 64 bits com ciclo de overflow |
| `encode`, `decode` | Texto | O texto como bytes base64 num conjunto de carateres, e vice-versa |
| `url_encode` | Texto | O texto codificado com percentagem como valor de formulário, com o espaço escrito `+` |
| `list_sort_numeric` | Texto | Uma lista guardada como texto separado, ordenada por valor numérico |
| `geojson_to_wkt` | JSON, Caminho | A geometria GeoJSON num caminho como `$.a[0]`, ou `$` para o próprio texto, como WKT |
| `json_patch_apply` | JSON | O documento com um JSON Patch ou Merge Patch aplicado |
| `json_diff` | Primeiro JSON, Segundo JSON | O JSON Patch que transforma o primeiro documento no segundo |
| `json_schema_check` | JSON | Os erros que o documento tem em relação a um Esquema JSON, como JSON; NULL quando não tem nenhum |
| `json_normalize` | JSON | O documento como texto JSON normalizado |
| `json_to_xml`, `xml_to_json` | Documento | O documento convertido em XML, ou em JSON |
| `xml_well_formed` | XML | O texto, quando é XML bem formado; caso contrário, NULL |
| `xslt` | XML, Folha de estilos | O documento transformado pela folha de estilos XSLT |
| `message_text`, `message_tool_calls` | JSON | O texto de uma mensagem de IA, ou as suas chamadas de ferramentas como JSON |

Defina as opções de uma função em `function_options`:

- `java_regex` — `mode`: `matches` (predefinição, o texto todo), `find` (em qualquer parte), `extract` (grupo `group` da primeira correspondência, predefinição 0) ou `replace` (todas as correspondências); `flags` `i` ignora maiúsculas e minúsculas.
- `knime_count` — `modifiers`: `i` ignora maiúsculas e minúsculas, `w` conta palavras inteiras entre espaços em branco.
- `encode` e `decode` — `charset`, um nome de conjunto de carateres Java; a predefinição é UTF-8.
- `json_patch_apply` — `patch`, a matriz JSON Patch ou o objeto Merge Patch; `merge` é verdadeiro para um Merge Patch; `keep` mantém o documento quando um teste do patch falha.
- `json_schema_check` — `schema`; `fail` interrompe o passo no primeiro erro em vez de o devolver.
- `json_normalize` — `comments` permite comentários `/* */` e `//`; `fail` (predefinição verdadeiro) interrompe o passo perante texto que não é JSON, e falso dá NULL.
- `json_to_xml` — `root`, `item`, `typed`, `parent_keys`, `namespace`, `text_key` e `text_key_enabled`. `xml_to_json` — `text_key`, `comments` e `pis`.
- `list_sort_numeric` — `separator`; `empty`, o texto escrito para uma lista sem elementos; e `missing`, o texto de um elemento em falta, ordenado em último lugar.

Por predefinição, o passo lê todas as colunas da origem e escreve todas as colunas da origem seguidas da coluna de saída. Defina `source_columns` para ler apenas algumas colunas e `target_columns` (cada uma `{source, target, dtype}`) para escolher e ordenar as colunas escritas. Uma coluna de destino com o mesmo nome da coluna de saída ocupa o seu lugar, com o tipo de dados indicado.
