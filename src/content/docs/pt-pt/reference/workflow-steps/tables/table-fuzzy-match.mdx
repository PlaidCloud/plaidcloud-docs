## Descrição

O passo **Fuzzy Match** emparelha linhas de duas tabelas (ou elimina duplicados numa só) com base em correspondências aproximadas de campos. É executado no motor de fluxos de trabalho; os resultados da macro empacotada são uma aproximação da macro do Alteryx.

## Parâmetros

- **Tabelas esquerda / direita** e a **Tabela de saída**.
- **Coluna do ID de registo**, **Limite** (0-100) e **Emitir também as linhas sem correspondência**.
- **Campos de correspondência** — os campos a comparar e a função de correspondência de cada um (exact / jaro / levenshtein / bestof / jaro_tfidf / bestof_tfidf).
