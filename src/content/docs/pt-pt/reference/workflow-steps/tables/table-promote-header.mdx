## Descrição

O passo **Tabela: Promover cabeçalho** toma uma linha da entrada e transforma os respetivos valores nos nomes das colunas, removendo depois essa linha. Utilize-o para um ficheiro cujo verdadeiro cabeçalho não é a primeira linha. O passo é executado quando o fluxo de trabalho é executado, pelo que os nomes provêm dos dados.

## Origem e opções

- **Tabela de origem** e **Tabela de saída** — a tabela a ler e a tabela a escrever.
- **Linha do cabeçalho** — a linha, contada a partir de 1, cujos valores dão nome às colunas. É removida dos dados. Deixe-a vazia para não promover nenhum cabeçalho e aplicar os passos de formatação aos nomes guardados.
- **Coluna da ordem dos registos** *(opcional)* — a coluna que ordena as linhas. Sem ela, as linhas são lidas como estão guardadas, pelo que a linha que dá nome às colunas pode variar de execução para execução.
- **Colunas quando a entrada está vazia** *(opcional)* — nomes, separados por vírgulas, das colunas de texto a escrever quando a entrada não tem linhas.

## Passos de formatação

Cada linha da grelha **Passos de formatação** altera os nomes promovidos.

| Definição | Opções |
| --- | --- |
| Ação | **Mudar o nome**, **Alterar tipo**, **Ocultar**, **Preencher vazios** |
| Critério de correspondência | **Contém**, **Começa com**, **Termina com** ou **Está vazio** |
| Texto correspondente | O texto a procurar no nome da coluna. Não é necessário para **Está vazio**. |
| Mudar o nome por | **Substituir texto**, **Adicionar antes** ou **Adicionar depois**, para uma mudança de nome |
| Substituir por | O novo texto para uma mudança de nome ou um preenchimento |
| Valor | O tipo para **Alterar tipo** |

Cada passo precisa de uma ação e de um critério de correspondência, e uma mudança de nome precisa de um método de mudança de nome e do respetivo texto.
