## Descrição


Se utiliza regularmente a função vlookup do Microsoft Excel, a transformação Table Lookup deverá parecer-lhe muito familiar. Serve essencialmente para a mesma função. Ao contrário da versão do Microsoft Excel, a transformação Table Lookup do PlaidCloud Analyze oferece maior flexibilidade, permitindo em especial a correspondência e o retorno de várias colunas.

## Exemplos


### Pesquisar informações da dimensão de produto


Neste exemplo, o modelador precisa de informações da tabela da dimensão de produto para dar sentido à tabela de factos de encomendas. Assim, a tabela *Import Order Fact* é selecionada como **Tabela de origem**. A tabela *Import Product Dim* contém as informações de pesquisa pretendidas, pelo que é selecionada como **Origem da tabela de pesquisa**. Embora estejam disponíveis, não são aplicados filtros à tabela de dados de pesquisa (nem a quaisquer outras tabelas de dados).



Na secção **Seleção de dados da tabela**, todas as colunas são mapeadas da tabela de dados de origem para a tabela de dados de destino. 



Não são aplicados **Filtros de dados** aos dados de origem nem aos de destino. 



Por fim, a tabela de dados de origem é comparada com a tabela de dados de pesquisa através do campo *Product_ID* existente em cada tabela. Apenas as colunas *Product_Description* e *Unit_Cost* são acrescentadas à tabela de dados de destino, sendo *Unit_Cost* renomeada para *Retail_Unit_Cost* no processo. 



Na tabela de dados de destino resultante, as colunas *Product_Description* e *Retail_Unit_Cost* foram adicionadas, com base nos valores correspondentes na coluna *Product_ID*.
