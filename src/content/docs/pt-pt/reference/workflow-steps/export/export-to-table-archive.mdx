## Descrição



Escreve uma tabela do PlaidCloud numa conta de documentos como um ficheiro de arquivo nativo do PlaidCloud. O arquivo preserva todos os tipos de coluna, índices e metadados que o PlaidCloud conhece — com mais fidelidade do que o CSV para circular entre projetos ou ambientes do PlaidCloud.

Combine-o com [Import Archive](/pt-pt/reference/workflow-steps/import/import-archive/) para voltar a trazer o arquivo para um projeto. É útil para cópias de segurança, migrações entre projetos e transferência de dados entre ambientes.
