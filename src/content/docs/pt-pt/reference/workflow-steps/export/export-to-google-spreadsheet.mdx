## Descrição


Exporta uma tabela de dados do Analyze para o Google Drive como uma folha de cálculo Google. É necessária uma conta Google válida para utilizar esta transformação. As credenciais do utilizador têm de ser configuradas no PlaidCloud Tools antes de utilizar a transformação.



## Parâmetros de exportação


### Origem e destino


Selecione a **Tabela de origem** do PlaidCloud Document através do menu pendente.



Em seguida, indique as informações da **Ligação de destino**. Para obter detalhes sobre a configuração de uma ligação a uma conta do Google Docs, consulte aqui: [PlaidCloud Tools – Ligação](/pt-pt/reference/connectors/). Depois de configuradas todas as contas necessárias, selecione a conta adequada na lista pendente.



Por fim, indique o **Nome da folha de cálculo de destino** e o **Nome da folha de trabalho de destino**. Se pretender, selecione a caixa de seleção **Acrescentar dados aos dados existentes da folha de trabalho** para acrescentar dados a uma folha de trabalho existente. Se a folha de trabalho de destino ainda não existir, será criada.



Uma folha de cálculo que ainda não existe é criada, tal como uma folha de trabalho em falta. É recusado um **Nome da folha de cálculo de destino** que seja usado por mais do que uma folha de cálculo na conta; mude o nome dos duplicados para que o nome seja único. Os valores são escritos tal como foram introduzidos, pelo que uma célula de texto que comece por `=` continua a ser texto e não se torna uma fórmula. Com **Acrescentar dados aos dados existentes da folha de trabalho** desmarcado, a folha de trabalho é limpa e redimensionada para a tabela antes de as linhas serem escritas.
