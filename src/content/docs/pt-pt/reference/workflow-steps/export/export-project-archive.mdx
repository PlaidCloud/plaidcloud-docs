## Descrição

Escreve um arquivo completo do projeto — fluxos de trabalho, definições de tabelas, dimensões, variáveis e definições — numa conta de documentos como um único ficheiro. Utilize-o para uma cópia de segurança num dado momento antes de uma grande alteração, ou para entregar um projeto a outra área de trabalho.

Isto arquiva o *projeto*, não apenas os seus dados. Para os dados das tabelas isoladamente, utilize [Export to Table Archive (passo)](/pt-pt/reference/workflow-steps/export/export-to-table-archive/).

## Itens de configuração exclusivos

### Diretório e nome de ficheiro de exportação

- **Diretório de exportação** — a conta de documentos e a pasta para onde o arquivo é escrito.
- **Ficheiro de destino** — o nome de ficheiro do arquivo.
