## Descrição

O passo **Export to PDF** escreve uma tabela como documento PDF numa conta de documentos. Lê as linhas diretamente, pelo que nenhum processo de exportação intervém pelo meio.

## Parâmetros

- **Tabela de origem** — a tabela a exportar.
- **Pasta de saída** — a conta de documentos e a pasta onde o PDF é escrito.
- **Nome do ficheiro** — o nome do PDF. `.pdf` é acrescentado quando o nome não o tem.
- **Escrever os nomes das colunas como linha de cabeçalho** — ativado por predefinição. O cabeçalho repete-se em todas as páginas.
- **Seleção de dados da tabela** — escolha e ordene as colunas escritas. O passo também pode escrever todas as colunas que a origem tiver quando o fluxo de trabalho for executado, em vez de uma lista.

## Esquema

- A página tem o tamanho carta na vertical e passa a horizontal quando a tabela tem mais de seis colunas.
- As linhas são escritas em blocos de 1000, repetindo o cabeçalho em cada bloco.
- Um valor nulo é uma célula vazia.
- Uma célula demasiado longa para uma página é truncada com reticências, e o passo avisa com os nomes das colunas que truncou.
- O PDF utiliza um tipo de letra Unicode quando o motor de fluxos de trabalho tem um. Sem ele, o PDF é composto em Helvetica, que apresenta apenas caracteres Latin-1, e o passo emite um aviso.
