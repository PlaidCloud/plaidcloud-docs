## Descrição



Escreve uma tabela de projeto PlaidCloud numa conta de documentos como um ficheiro CSV (valores separados por vírgulas). É o formato de exportação mais comum — suportado por praticamente todos os sistemas a jusante, ferramentas de folhas de cálculo e plataformas de BI.

Configurável: delimitador (vírgula, tabulação, barra vertical, personalizado), comportamento das aspas, linha de cabeçalho e codificação.

### Selecionar a compressão do ficheiro

Todos os ficheiros exportados são não comprimidos, mas estão disponíveis as seguintes opções de compressão:

* Sem compressão
* Zip
* GZip
* BZip2



### Formato dos dados

![Formato dos dados da exportação CSV](/images/export_file_csv_data_format.png)



#### Delimitador
A transformação Exportar CSV é utilizada para exportar tabelas de dados para ficheiros de texto delimitado guardados no PlaidCloud Document. Isto inclui, entre outros, os seguintes tipos de delimitador:


* Excel CSV (separado por vírgulas)
* Excel TSV (separado por tabulações)
* Separador definido pelo utilizador –>


	+ vírgula (,)
	+ barra vertical (|)
	+ ponto e vírgula (;)
	+ tabulação
	+ espaço ( )
	+ outro/personalizado (til, hífen, etc.)

Para especificar um delimitador personalizado, selecione **Separador definido pelo utilizador –>** e depois **Outro –>**, e escreva o delimitador personalizado na caixa de texto.


#### Caracteres especiais

A secção **Caracteres especiais** permite especificar como tratar dados com aspas e caracteres de escape. Escolha entre as seguintes definições:

* Caracteres especiais (QUOTE_MINIMAL): coloca entre aspas os campos com caracteres especiais (tudo o que confundiria um analisador configurado com o mesmo dialeto e as mesmas opções). Esta é a definição predefinida.
* Todos (QUOTE_ALL): coloca tudo entre aspas, independentemente do tipo.
* Não numéricos (QUOTE_NONNUMERIC): coloca entre aspas todos os campos que não sejam números inteiros ou de vírgula flutuante. Quando utilizado com o leitor, os campos de entrada sem aspas são convertidos em números de vírgula flutuante.
* Nenhum (QUOTE_NONE): não coloca nada entre aspas na saída. Os caracteres de aspas são incluídos na saída com o carácter de escape indicado pelo utilizador. Tenha em conta que só pode ser indicado um único carácter de escape.

Por predefinição, uma aspa dentro de um campo entre aspas é escrita duplicada (`""`). Ative `escape_quotes` para a escrever com o carácter de escape, como o Spark faz: com `\` como carácter de escape, o campo `say "hi"` é escrito `"say \"hi\""`. A definição está desativada por predefinição, pelo que as exportações existentes não se alteram. 

Por predefinição, um valor que contém um carácter de aspas é colocado entre aspas só por esse motivo. Desmarque **Colocar entre aspas os valores que contêm o caráter de aspas** para escrever esse valor sem aspas à volta, como o Spark faz com `escapeQuotes` desativado; um valor que contenha o delimitador ou uma quebra de linha continua a ser colocado entre aspas. A caixa está selecionada por predefinição. Desmarcada, o ficheiro é escrito pelo PlaidCloud e não pelo armazém.

Deixe **Carácter de aspas** vazio para escrever cada valor exatamente como está: nada é colocado entre aspas e nada tem escape. Um valor que contenha o delimitador ou uma quebra de linha é então lido como mais campos, pelo que deve escolher um delimitador que os seus dados não contenham.

#### Escrever o cabeçalho na primeira linha
Se esta caixa estiver selecionada, os cabeçalhos da tabela são exportados para a primeira linha. Se não estiver, o ficheiro exportado não terá cabeçalhos.

#### Incluir tipos de dados nos cabeçalhos
Se esta caixa estiver selecionada, os cabeçalhos do ficheiro exportado contêm o tipo de dados da coluna.

#### Fins de linha do Windows

Por último, a caixa **Utilizar fins de linha compatíveis com o Windows** está selecionada por predefinição para garantir a compatibilidade com sistemas Windows. Aconselha-se a deixar esta definição ativada, a menos que trabalhe num ambiente exclusivamente unix.




### Se o ficheiro existir

Em **Mais opções de CSV**, **Um ficheiro que já existe** (`if_exists`) decide o que acontece quando o ficheiro já lá está: `replace` (predefinição) escreve um novo ficheiro, `append` acrescenta as linhas ao fim do ficheiro existente sem linha de cabeçalho e `fail` interrompe o passo, sem escrever nada. Um acréscimo transfere o ficheiro, junta as linhas e volta a carregá-lo, pelo que, quando duas execuções acrescentam ao mesmo ficheiro em simultâneo, prevalece a última a terminar. Com `append`, selecione **Voltar a escrever o cabeçalho abaixo das linhas existentes** (`header_on_append`) para escrever novamente a linha de cabeçalho abaixo das linhas já existentes.

### Definições adicionais

**Mais opções de CSV** contém também estes campos:

* **Ordenar linhas por** (`sort_columns`) — ordena as linhas escritas por estas colunas de origem, começando pela primeira chave, cada uma com uma definição de **Coluna**, **Ascendente** e **Nulos**. Uma coluna de chave não tem de ser escrita. **Nulos** assume por predefinição primeiro na ordem ascendente e último na descendente. Não é utilizado com **Resumir** ou **Distinto**.
* **Fim de linha** (`line_ending`) — o fim de linha de todas as linhas, `\n`, `\r\n` ou `\r`, em vez de **Utilizar fins de linha compatíveis com o Windows**.
* **Colocar entre aspas** (`quote_mode`) — que valores são colocados entre aspas: **Nunca**, **Sempre**, **Todos os valores exceto números e booleanos** ou **Um valor que contém o delimitador**. Por predefinição, um valor é colocado entre aspas quando é necessário.
* **Aspa de fecho** (`quote_end`) — a aspa de fecho, quando difere da aspa de abertura.
* **Aspa de fecho dentro de um valor** (`quote_replacement`) — escrita no lugar de uma aspa de fecho dentro de um valor entre aspas. Se ficar vazio, a aspa é duplicada.
* **Delimitador dentro de um valor** (`delimiter_replacement`) — com **Colocar entre aspas** definido como **Nunca**, escrito no lugar do delimitador dentro de um valor.
* **Iniciar o ficheiro com uma marca de ordem de bytes** (`write_bom`) — inicia o ficheiro com uma marca de ordem de bytes.
* **Separador decimal** (`decimal_separator`) — o carácter escrito para a vírgula decimal de um número.
* **Linhas antes do cabeçalho** (`comment_lines`) — uma matriz JSON de linhas escritas tal como estão antes do cabeçalho.
* **Escrever números decimais como o Java** (`scientific_numbers`) — escreve um número decimal em notação científica a partir de 10 milhões e abaixo de 0,001, como `1.0E10`.
* **Escrever cada nome de ficheiro tal como indicado, sem acrescentar .csv ou .tsv** (`keep_file_extension`) — escreve cada nome de ficheiro exatamente como indicado.
* **Com gzip, guardar o ficheiro com o nome indicado, sem acrescentar .gz** (`exact_file_name`) — com compressão gzip, guarda o ficheiro com o nome indicado.
