## Descrição

Escreve as tabelas de projeto que selecionar numa conta de documentos como Parquet comprimido. Em conjunto com [Restaurar tabelas](/pt-pt/reference/workflow-steps/import/restore-tables/), move dados de tabelas entre projetos ou áreas de trabalho, ou guarda de parte uma cópia válida antes de uma alteração destrutiva.

## Itens de configuração exclusivos

### Tabelas

As tabelas de projeto a arquivar.

### Destino

A conta de documentos e o caminho para onde o arquivo é escrito.

### Compressão

- **Snappy** — o mais rápido, com tamanho de arquivo moderado
- **Zstandard** — arquivos mais pequenos, exige um leitor com Zstandard 0.8 ou posterior
