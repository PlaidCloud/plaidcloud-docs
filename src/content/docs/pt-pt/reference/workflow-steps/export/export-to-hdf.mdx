## Descrição


Exporta uma tabela de dados do Analyze para o PlaidCloud Document como um ficheiro HDF5.


Para mais informações sobre ficheiros HDF5, consulte o sítio Web oficial do HDF Group aqui: http://www.hdfgroup.org/HDF5/.

<SnippetCommonExportFileSelection />



### Tipo de ficheiro de saída


Todos os ficheiros exportados são não comprimidos, mas estão disponíveis as seguintes opções de compressão:


* Zip
* GZip
* BZip2
