## Descrição

Escreve tabelas de projeto numa base de dados externa através de uma [ligação](/pt-pt/reference/connectors/), em vez de num ficheiro. Utilize-o para devolver resultados modelados a uma base de dados de relatórios, a um armazém de dados ou a um sistema operacional.

É o espelho de [Importar tabelas de bases de dados externas](/pt-pt/reference/workflow-steps/import/import-external-database-tables/): várias tabelas movem-se num único passo, e as tabelas de destino podem ser selecionadas explicitamente ou encontradas por um padrão de pesquisa.

## Itens de configuração exclusivos

### Ligação

A ligação de dados que identifica a base de dados de destino.

### Tipo de exportação

Como cada tabela de destino é preparada antes de as linhas serem escritas:

- **Apenas acrescentar** — acrescenta linhas à tabela existente; falha se esta não existir.
- **Truncar e acrescentar** — esvazia a tabela, mantém a respetiva estrutura e depois escreve.
- **Criar e acrescentar** — cria a tabela se esta não existir e depois escreve.
- **Eliminar, criar e acrescentar** — elimina e recria a tabela e depois escreve. Utilize quando o esquema de origem tiver mudado.

### Nome do frame

O nome do frame sob o qual o passo é executado.

### Adicionar destinos

Utilize o botão de adicionar e remover destino para criar a lista de tabelas de destino. Selecione um destino para o configurar no painel da direita e utilize **Alternar selecionados** para ativar ou desativar a exportação dos destinos selecionados. A exportação não procura tabelas na base de dados de destino; adicione cada destino manualmente. [Importar tabelas de bases de dados externas](/pt-pt/reference/workflow-steps/import/import-external-database-tables/) é o passo para descobrir tabelas numa base de dados externa.

### Separadores do destino

Um destino selecionado tem três separadores.

#### Origem e destino

Escolha as tabelas de projeto a exportar e onde ficam.

- **Origem** — **Tabela específica** indica uma tabela de projeto, com uma opção **Dinâmico** para um nome que muda em tempo de execução. **Tabelas correspondentes à pesquisa** exporta todas as tabelas de projeto encontradas por um **Caminho de pesquisa** e um **Texto de pesquisa**, com correspondência **Exato**, **Começa com**, **Contém** ou **Termina com**.
- **Tabela externa de destino** — **Ativar para exportação** ativa ou desativa o destino. **Esquema de destino** e **Tabela de destino** indicam a tabela de destino. **Utilizar o mesmo nome da tabela de origem** reutiliza o nome de cada tabela de origem.

#### Seleção de dados da tabela

O mapeador de colunas do destino, num separador próprio de altura completa. **Inspecionar origem** lê as colunas da tabela de origem do projeto para o mapeador.

#### Filtros de dados

Filtre as linhas escritas no destino.
