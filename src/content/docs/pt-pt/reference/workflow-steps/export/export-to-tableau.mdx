## Descrição

O passo **Publish to Tableau** publica um extrato `.hyper` no Tableau Server ou no Tableau Cloud como origem de dados. Escreva primeiro o extrato com [Tableau Hyper Export](/pt-pt/reference/workflow-steps/export/export-hyper/) e publique-o depois com este passo. O passo inicia sessão com o token de acesso pessoal de uma [ligação Tableau](/pt-pt/reference/connectors/collaboration/tableau/), carrega o ficheiro por partes, para que o tamanho do ficheiro não fique limitado por um único pedido, e termina a sessão.

Um ficheiro de extrato em falta não é um erro. O passo avisa que nada foi publicado e o fluxo de trabalho continua.

## Parâmetros

- **Extrato Hyper** — o ficheiro `.hyper`, numa conta de documentos, a publicar.
- **Ligação Tableau** — a ligação Tableau através da qual publicar.
- **Nome da origem de dados** — o nome da origem de dados no Tableau. Deixe em branco para utilizar o nome do ficheiro do extrato sem a extensão.
- **Projeto** — o projeto do Tableau no qual publicar. Deixe em branco para utilizar o projeto Default do site. Um nome de projeto que o Tableau não tenha no site faz o passo falhar.
- **Se a origem de dados existir** — o modo de publicação. Consulte [Modos](#modos).
- **Chaves de correspondência** — as colunas que fazem corresponder as linhas, como lista separada por vírgulas. Obrigatório para **Upsert**, **Update** e **Replace Matching Rows**.

## Modos

| Modo | Quando a origem de dados existe | Quando não existe |
| --- | --- | --- |
| **CreateNew** | O passo falha. | Cria-a. |
| **Overwrite** | Substitui-a. | Cria-a. |
| **Append** | Acrescenta-lhe as linhas do extrato. | Cria-a. |
| **Upsert** | Atualiza as linhas cujas chaves de correspondência coincidem e adiciona as restantes. | Cria-a. |
| **Update** | Atualiza as linhas cujas chaves de correspondência coincidem e não adiciona nenhuma. | Emite um aviso e não altera nada. |
| **GroupReplace** | Elimina as linhas cujas chaves de correspondência coincidem e insere depois as linhas do extrato. | Cria-a. |

**Append**, **Upsert**, **Update** e **GroupReplace** procuram a origem de dados por nome no projeto escolhido, ou no projeto Default do site quando não foi escolhido nenhum, e publicam no projeto onde procuraram. Os modos com chave alteram as linhas da origem de dados no local, através das ações de atualização de dados do Tableau.

## Requisitos

- O endereço do servidor da ligação tem de utilizar `https`. Um servidor indicado com `http` faz o passo falhar, porque o token de acesso pessoal atravessaria a rede em claro. Um nome de anfitrião sem protocolo é interpretado como `https`.
- O servidor tem de estar acessível a partir da Internet. O PlaidCloud não publica num servidor Tableau numa rede privada.
- O proprietário do token de acesso pessoal precisa de permissão para publicar no projeto.
