## Descrição



Envia uma tabela PlaidCloud para uma base de dados Quandl (NASDAQ Data Link). Destina-se sobretudo a organizações que mantêm conjuntos de dados publicados no Quandl e pretendem atualizá-los a partir de um fluxo de trabalho PlaidCloud.

Requer credenciais da API do Quandl e uma base de dados de destino configurada para acesso de escrita do lado do Quandl.


## Origem e destino


Especifique os seguintes parâmetros:


* **Tabela de origem**: tabela de dados do Analyze a exportar
* **Ligação Quandl**: o acesso a conjuntos de dados do Quandl requer uma conta de utilizador ou uma conta de convidado com acesso limitado. Isto requer configuração em Ferramentas. Para obter detalhes sobre como configurar uma ligação a uma conta Quandl, consulte aqui: [PlaidCloud Tools – Ligação](/pt-pt/reference/connectors/)
* **Código Quandl**: utilize o botão **Pesquisar** para procurar conjuntos de dados. Em alternativa, os conjuntos de dados podem ser introduzidos manualmente. Para tal, o utilizador tem de introduzir a parte do URL a seguir a “[http://www.quandl.com](http://www.quandl.com/)”. Por exemplo, para importar o conjunto de dados das ações da Microsoft, que se encontra aqui (http://www.quandl.com/GOOG/NASDAQ_MSFT), introduza *GOOG/NASDAQ_MSFT* no campo Código Quandl
* **Nome do conjunto de dados**: nome do conjunto de dados a exportar para o Quandl
* **Descrição do conjunto de dados**: descrição do conjunto de dados a exportar para o Quandl
