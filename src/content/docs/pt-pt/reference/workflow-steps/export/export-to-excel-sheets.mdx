## Descrição

Escreve várias tabelas de projeto em diferentes folhas de um único livro
Microsoft Excel, preservando a formatação de um modelo formatado. Cada tabela preenche uma
folha com nome; o livro inteiro é criado a partir do modelo uma só vez e renderizado
numa única passagem, pelo que as folhas deixam de se sobrescrever mutuamente, como
aconteceria com exportações separadas de uma só folha que partilhassem um ficheiro de saída.

Utilize este passo quando um livro tem de conter mais do que uma folha de resultados —
por exemplo, um modelo de relatórios formatado com uma folha de dados, uma folha de resumo
e uma folha de parâmetros. Para uma única folha, ou para um livro simples sem formatação,
utilize antes [Export to Excel (passo)](/pt-pt/reference/workflow-steps/export/export-to-excel/).

A formatação do modelo transita para cada folha escrita: valores, formatos
numéricos, tipos de letra, preenchimentos, limites, células intercaladas e larguras de coluna. Um modelo que
contenha tabelas dinâmicas ou gráficos perde esses objetos quando as suas folhas são escritas —
a escrita não os reproduz.

## Parâmetros de exportação

### Ficheiro de saída

A conta de documentos e a pasta para onde o livro é escrito, em conjunto com o
**Nome do ficheiro** do livro.

### Ficheiro de modelo

O modelo formatado a partir do qual o livro é criado — uma conta de documentos e um caminho para
um ficheiro `.xlsx` existente cuja formatação todas as folhas escritas herdam. Quando não é indicado
nenhum modelo, o passo parte do ficheiro de saída existente, caso já exista.

### Compressão

Por predefinição, o livro é escrito sem compressão. Está disponível a compressão
Zip, GZip ou BZip2.

## Folhas

Cada entrada da tabela **Folhas** preenche uma folha de cálculo do livro:

| Campo | Finalidade |
| --- | --- |
| Origem | A tabela de projeto que fornece as linhas da folha. |
| Folha de destino | A folha do modelo a preencher. |
| Intervalo | Um intervalo opcional ao estilo A1 (por exemplo `A1:S1000000`) cujos valores existentes são limpos antes de a tabela ser escrita, deixando intocadas as células circundantes do modelo. |
| Escrever cabeçalho | Se deve escrever a linha de cabeçalho com os nomes das colunas. Ativado por predefinição. |
| Colunas | As colunas a escrever, por ordem, quando não pretende todas as colunas da tabela de origem. |

Estes campos também existem no formulário:

* **Um livro existente** (`if_exists`) — **Fazer a etapa falhar sem escrever nada** (`fail`) interrompe o passo quando o livro já existe. A predefinição, **Escrever as folhas nele** (`replace`), escreve-o.
* Numa entrada de folha, **Ordenar linhas por** (`sort_columns`) ordena as linhas escritas por estas colunas de origem, começando pela primeira chave, cada uma com uma definição de **Coluna**, **Ascendente** e **Nulos**; **Células em falta como** (`null_as`) é o texto escrito em todas as células em falta da folha, incluindo as colunas numéricas; e **Uma folha existente** (`if_sheet_exists`) decide o que acontece quando o livro já tem a folha: **Falhar o passo** (`fail`) interrompe o passo e **Deixar como está** (`skip`) deixa essa folha como está.

## Limites de tamanho

Cada folha está sujeita aos mesmos limites do Excel que uma exportação de uma só folha: no máximo
1 048 576 linhas (a linha de cabeçalho conta) e 16 384 colunas. Uma folha que
os excedesse interrompe o passo, em vez de produzir um ficheiro que o Excel recusa abrir.
Para dados acima destas dimensões, exporte antes para CSV ou Parquet.
