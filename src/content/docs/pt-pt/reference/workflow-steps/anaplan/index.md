Passos de fluxo de trabalho que leem do **Anaplan** através da sua [ligação Anaplan](/pt-pt/guides/connections/anaplan/): uma vista guardada pelo caminho de pedidos de leitura de grande volume, uma ação de exportação já existente através da Bulk API ou uma ou mais listas carregadas numa dimensão PlaidCloud. O Anaplan é acedido **diretamente na nuvem** através da respetiva API de integração — estes passos não têm um caminho através de agente local e nenhum deles escreve de volta no Anaplan.

## Passos

- [Anaplan: Ler vista](/pt-pt/reference/workflow-steps/anaplan/anaplan-read-view/) — leia uma vista guardada exatamente como foi guardada. Diretamente na nuvem.
- [Anaplan: Ler exportação](/pt-pt/reference/workflow-steps/anaplan/anaplan-read-export/) — execute uma ação de exportação já existente e carregue o respetivo ficheiro. Diretamente na nuvem.
- [Anaplan: Ler lista](/pt-pt/reference/workflow-steps/anaplan/anaplan-read-list/) — leia uma ou mais listas para uma dimensão PlaidCloud. Diretamente na nuvem.
