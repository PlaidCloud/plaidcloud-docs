## Descrição

Lê dados de uma vista guardada do **Anaplan** através da sua [ligação Anaplan](/pt-pt/guides/connections/anaplan/), pelo caminho de pedidos de leitura de grande volume do Anaplan. A vista é lida **exatamente como foi guardada** — este passo não permite seleção ad hoc de linhas, colunas ou páginas. Para ler uma fatia diferente, guarde uma vista diferente no Anaplan.

Este passo aparece no menu de passos em **Anaplan**.

O passo acede ao Anaplan **diretamente na nuvem** através da respetiva API de integração — não existe um caminho através de agente local.

<Aside type="tip">
Este conector é só de leitura e autentica-se com credenciais Basic (nome de utilizador e palavra-passe) ou com Certificado CA — consulte [Autenticação](/pt-pt/guides/connections/anaplan/#autenticação). O orçamento de pedidos do Anaplan é partilhado por todo o tenant, pelo que deve escalonar o agendamento deste passo em relação aos seus outros fluxos de trabalho Anaplan — consulte [Considerações sobre o agendamento](/pt-pt/guides/connections/anaplan/#considerações-de-agendamento).
</Aside>

## Configuração

### Origem e destino

| Campo | Obrigatório | Notas |
|---|---|---|
| Ligação Anaplan | Sim | A [ligação Anaplan](/pt-pt/guides/connections/anaplan/) através da qual se faz a leitura. |
| Ambiente | Sim | O ambiente da ligação. |
| Área de trabalho | Não | Substitui o ID da área de trabalho guardado na ligação. Detetada em direto a partir da ligação ou introduzida manualmente. |
| Modelo | Não | Substitui o ID do modelo guardado na ligação. Detetado em direto depois de escolhida uma área de trabalho ou introduzido manualmente. |
| Vista | Sim | A vista guardada do Anaplan a ler. Detetada em direto depois de escolhido um modelo ou introduzida manualmente. |
| Tentativas de consulta | Sim | Predefinição 120. Quantas vezes se consulta o pedido de leitura à espera da conclusão antes de o passo recusar, indicando o ID do pedido. Nunca submete silenciosamente um segundo pedido. |
| Intervalo de consulta (segundos) | Sim | Predefinição 5. Segundos de espera entre consultas. |
| Tabela de destino | Sim | A tabela onde a vista devolvida é carregada. |

## O que este passo não consegue representar

| Limitação | O que significa |
|---|---|
| Sem controlo da fatia | A vista é lida exatamente como foi guardada — sem seleção de linhas, colunas ou páginas. O seletor de páginas do Anaplan está documentado apenas no seu ponto de acesso síncrono de pré-visualização; o corpo do pedido de leitura de grande volume que este passo envia aceita um tipo de exportação e mais nada. Crie uma vista guardada diferente — normalmente um item de linha booleano mais um filtro — para ler uma fatia diferente. |
| Os tipos declarados só são aplicados quando os Line Items estão nas colunas | Com os Line Items no eixo das colunas da vista, cada coluna de dados é carregada com o tipo do formato Anaplan declarado do respetivo item de linha (Number, Text, Boolean, Date, Time Period ou List). Com os Line Items nas linhas (uma disposição normal de demonstração de resultados) ou totalmente ausentes da vista, todas as colunas de dados são carregadas como texto, com um aviso identificado — uma coluna de dados abrangeria, de outro modo, muitos itens de linha e, por isso, muitos formatos, enquanto uma coluna de tabela contém exatamente um tipo. |
| Os valores do seletor de páginas não são carregados como colunas | Os membros do seletor de páginas guardados numa vista seguem no cabeçalho do CSV e são consumidos aí — não aparecem como colunas na tabela de destino. |
| Os números ambíguos são recusados em vez de adivinhados | Um valor declarado como Number com separadores de milhares, ou que se lê igualmente como decimal simples ou como formato europeu (por exemplo, `1.234`), é recusado por nome em vez de interpretado — a menos que outro valor da mesma coluna esclareça qual a leitura correta. Este caminho de leitura não tem um campo de configuração regional com que resolver a ambiguidade. Um valor que seja interpretado é carregado com precisão total, sem erro de arredondamento, e uma célula em branco é sempre carregada como valor vazio. |
| Uma vista vazia é carregada vazia, com um aviso | Uma vista guardada cujo filtro não corresponde a nada substitui a tabela de destino por uma tabela vazia e emite um aviso — é um resultado normal, não uma falha. A exceção é uma vista sem nenhuma dimensão no eixo das linhas: não existe um canto com etiquetas de linha em relação ao qual verificar um resultado vazio, pelo que o passo recusa em vez de arriscar esvaziar a tabela por uma leitura errada do cabeçalho. |
| Só de leitura | Nunca se escreve nada de volta no Anaplan. |
