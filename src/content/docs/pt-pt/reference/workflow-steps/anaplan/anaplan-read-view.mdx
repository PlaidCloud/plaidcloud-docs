## Descrição

Lê dados de uma vista guardada do **Anaplan** através da sua [ligação Anaplan](/pt-pt/guides/connections/anaplan/), pelo caminho de pedidos de leitura de grande volume do Anaplan. A vista é lida **exatamente como foi guardada** — este passo não tem seleção ad hoc de linhas, colunas ou páginas. Para ler uma fatia diferente, guarde uma vista diferente no Anaplan.

Este passo aparece no menu de passos em **Anaplan**.

O passo chega ao Anaplan **diretamente na nuvem** através da sua API de integração — não existe caminho por agente local.

<Aside type="tip">
Este conector é só de leitura e autentica-se com credenciais Basic (nome de utilizador e palavra-passe) ou de certificado CA — veja [Autenticação](/pt-pt/guides/connections/anaplan/#autenticação). O orçamento de pedidos do Anaplan é partilhado por todo o inquilino, pelo que deve desfasar o agendamento deste passo relativamente aos seus outros fluxos de trabalho Anaplan — veja [Considerações sobre o agendamento](/pt-pt/guides/connections/anaplan/#considerações-sobre-agendamento).
</Aside>

## Configuração

### Origem e destino

| Campo | Obrigatório | Notas |
|---|---|---|
| Ligação Anaplan | Sim | A [ligação Anaplan](/pt-pt/guides/connections/anaplan/) através da qual ler. |
| Ambiente | Sim | O ambiente da ligação. |
| Área de trabalho | Não | Substitui o ID da área de trabalho guardado na ligação. Descoberto em tempo real a partir da ligação, ou escrito à mão. |
| Modelo | Não | Substitui o ID do modelo guardado na ligação. Descoberto em tempo real depois de escolhida uma área de trabalho, ou escrito à mão. |
| Vista | Sim | A vista guardada do Anaplan a ler. Descoberta em tempo real depois de escolhido um modelo, ou escrita à mão. |
| Tentativas de consulta | Sim | Predefinição 120. Quantas vezes consultar o pedido de leitura até estar concluído antes de o passo recusar, indicando o ID do pedido. Nunca submete em silêncio um segundo pedido. |
| Intervalo de consulta (segundos) | Sim | Predefinição 5. Segundos a esperar entre consultas. |
| Tabela de destino | Sim | A tabela onde a vista devolvida é carregada. |

## Pré-visualização

**Pré-visualização** no separador **Origem** mostra as colunas e os tipos de dados que esta leitura de vista produziria, sem executar o passo. Não está disponível num projeto bloqueado.

## O que este passo não consegue representar

| Limitação | O que significa |
|---|---|
| Sem controlo da fatia | A vista é lida exatamente como foi guardada — sem seleção de linhas, colunas ou páginas. O seletor de páginas do Anaplan só está documentado no seu endpoint de pré-visualização síncrono; o corpo do pedido de leitura de grande volume que este passo envia aceita um tipo de exportação e mais nada. Construa uma vista guardada diferente — habitualmente um item de linha booleano mais um filtro — para ler uma fatia diferente. |
| Os tipos declarados só são carregados quando Line Items está em Colunas | Com Line Items no eixo das colunas da vista, cada coluna de dados é carregada com o tipo do formato Anaplan declarado do respetivo item de linha (Número, Texto, Booleano, Data, Período de tempo ou Lista). Com Line Items nas linhas (um esquema de demonstração de resultados comum) ou totalmente ausente da vista, todas as colunas de dados são carregadas como texto, com um aviso identificado — uma coluna de dados abrangeria, de outro modo, muitos itens de linha, e portanto muitos formatos, enquanto uma coluna de tabela contém exatamente um tipo. |
| Os valores do seletor de páginas não são carregados como colunas | Os membros do seletor de páginas guardados numa vista seguem no cabeçalho do CSV e são consumidos aí — não aparecem como colunas na tabela de destino. |
| Os números ambíguos são recusados em vez de adivinhados | Um valor declarado como Número que tenha separadores de milhares, ou que se leia igualmente como um decimal simples ou como uma representação europeia (por exemplo `1.234`), é recusado pelo nome em vez de analisado — a menos que outro valor na mesma coluna esclareça qual a leitura correta. Este caminho de leitura não tem um campo de localização com que resolver a ambiguidade. Um valor que seja analisado é carregado com precisão total, sem erro de arredondamento, e uma célula em branco é sempre carregada como valor vazio. |
| Uma vista vazia é carregada vazia, com um aviso | Uma vista guardada cujo filtro não corresponde a nada substitui a tabela de destino por uma vazia e avisa — é um resultado normal, não uma falha. A exceção é uma vista sem nenhuma dimensão no eixo das linhas: não existe um canto com rótulos de linha contra o qual verificar um resultado vazio, pelo que o passo recusa em vez de arriscar esvaziar a tabela por uma leitura errada do cabeçalho. |
| Só de leitura | Nada é alguma vez escrito de volta no Anaplan. |
