## Descrição

Executa uma ação de exportação do Anaplan **já existente** através da sua [ligação Anaplan](/pt-pt/guides/connections/anaplan/) e carrega o ficheiro que ela produz como tabela. A ação de exportação já tem de existir no modelo — a API não consegue criar uma — e este passo não consegue restringir o que ela emite: o que a ação estiver configurada para exportar no Anaplan é exatamente o que é carregado.

Este passo aparece no menu de passos em **Anaplan**.

O passo acede ao Anaplan **diretamente na nuvem** através da sua Bulk API — não existe um caminho por agente nas instalações.

<Aside type="tip">
Este conector é só de leitura e autentica-se com credenciais Basic (nome de utilizador e palavra-passe) ou com certificado CA — consulte [Autenticação](/pt-pt/guides/connections/anaplan/#autenticação). O orçamento de pedidos do Anaplan é partilhado por todo o tenant, pelo que deve escalonar o agendamento deste passo relativamente aos seus outros fluxos de trabalho do Anaplan — consulte [Considerações sobre agendamento](/pt-pt/guides/connections/anaplan/#considerações-de-agendamento).
</Aside>

## Configuração

### Origem e destino

| Campo | Obrigatório | Notas |
|---|---|---|
| Ligação Anaplan | Sim | A [ligação Anaplan](/pt-pt/guides/connections/anaplan/) através da qual ler. |
| Ambiente | Sim | O ambiente da ligação. |
| Workspace | Não | Substitui o ID do workspace guardado na ligação. Descoberto em direto a partir da ligação, ou introduzido manualmente. |
| Model | Não | Substitui o ID do modelo guardado na ligação. Descoberto em direto depois de escolhido um workspace, ou introduzido manualmente. |
| Export | Sim | A ação de exportação do Anaplan a executar. Descoberta em direto depois de escolhidos o workspace e o modelo, ou introduzida manualmente. A sua seleção não pode ser substituída a partir daqui — é executada exatamente como configurada no Anaplan. |
| Tentativas de consulta | Sim | Predefinição 120. Quantas vezes consultar a tarefa de exportação para verificar a conclusão antes de o passo recusar, indicando o ID da tarefa. Nunca volta a submeter em silêncio — o Anaplan não documenta como distinguir dois ficheiros produzidos pela mesma ação de exportação, pelo que uma nova submissão arrisca associar o ficheiro errado a esta execução. |
| Poll Interval (seconds) | Sim | Predefinição 5. Segundos a aguardar entre consultas. |
| Tabela de destino | Sim | A tabela onde a exportação é carregada. Todas as colunas chegam como texto. |

## O que este passo não consegue representar

| Limitação | O que significa |
|---|---|
| Requer uma ação de exportação já existente | A API não consegue criar uma ação de exportação, e o pedido que este passo envia não leva qualquer parâmetro de ponto de vista, seleção de membros ou segmento — o que a ação estiver configurada para emitir no Anaplan é exatamente o que é carregado. Crie ou edite a ação de exportação no Anaplan para alterar o que ela produz. |
| Todas as colunas chegam como texto | O campo que o Anaplan publica para declarar os tipos das colunas de uma exportação é internamente inconsistente na própria documentação publicada do Anaplan, pelo que não é fiável para atribuir o tipo correto a uma coluna — nenhuma coluna é tipada a partir dele, de forma deliberada e permanente. Converta as colunas de que precisa num passo seguinte. |
| Números pedidos em formato dos EUA; uma coluna que continue agrupada é assinalada, não corrigida | A tarefa de exportação é submetida a pedir formatação numérica dos EUA. Uma coluna que continue a vir com separadores de milhares significa que a exportação não está a ser apresentada nesse formato — o passo carrega o valor sem alterações, como texto, e emite um aviso a indicar a coluna e um valor de exemplo, em vez de adivinhar qual é o caráter da vírgula decimal. Verifique essa coluna antes de a converter num passo seguinte: um `1.234.567` ao estilo europeu lido como `1.234` fica mil vezes menor. |
| Recusa em vez de carregar uma extração não fiável | O passo não carrega nada, em vez de uma tabela que parece completa e não é, quando: a tarefa de exportação falha ou não comunica êxito no Anaplan; a tarefa é cancelada; a tarefa ainda está em execução quando o orçamento de consultas do passo se esgota; o ficheiro produzido não tem quaisquer dados; o ficheiro produzido não pode ser associado à exportação que o gerou; ou o número de linhas lidas não coincide com a contagem de linhas que o próprio Anaplan comunica para a exportação. |
| Só de leitura | Nunca é escrito nada de volta no Anaplan. |
