## Descrição

O passo **Create Samples (macro)** reproduz a macro empacotada *Create Samples* do Alteryx. É executado no motor de fluxos de trabalho; os resultados das macros empacotadas são uma aproximação da macro do Alteryx.

## Parâmetros

- **Origem / Tabelas de saída**.
- **Estimação %** e **Semente aleatória**.
