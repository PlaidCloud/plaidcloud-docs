## Descrição

O passo **Heat Map (macro)** reproduz a macro empacotada *Heat Map* do Alteryx. É executado no motor de fluxos de trabalho; os resultados das macros empacotadas são uma aproximação da macro do Alteryx.

## Parâmetros

- **Origem / Tabelas de saída** e a **Distância máxima**.
