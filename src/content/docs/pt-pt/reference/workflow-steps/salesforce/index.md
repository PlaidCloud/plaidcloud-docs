Passos de fluxo de trabalho que leem dados do Salesforce através da sua [ligação Salesforce](/pt-pt/guides/connections/salesforce/). A lista de objetos, a lista de campos e o tipo de cada coluna provêm dos metadados da própria organização, pelo que não há nenhuma consulta para escrever nem nenhum tipo para adivinhar.

## Passos

- [Salesforce: Consultar objeto](/pt-pt/reference/workflow-steps/salesforce/query-salesforce-object/) — extraia um objeto padrão ou personalizado para uma tabela do projeto através da Bulk API 2.0, filtrado no Salesforce.
