Treine um modelo com qualquer tabela, transporte-o pelo fluxo de trabalho como uma tabela de modelo e pontue tabelas de dados com ele.

## Passos

- [ML: Treinar modelo](/pt-pt/reference/workflow-steps/machine-learning/ml-train/) — ajuste um modelo scikit-learn (classificação ou regressão) a uma tabela de origem e escreva uma tabela de modelo consultável com o modelo ajustado, os parâmetros, a lista de variáveis e as métricas de treino.
- [ML: Pontuar](/pt-pt/reference/workflow-steps/machine-learning/ml-score/) — pontue uma tabela de dados com uma tabela de modelo treinado e acrescente uma coluna de previsão.

Consulte [Migrar fluxos de trabalho Alteryx](/pt-pt/guides/workflows/migrate-alteryx-workflows/#conversões-de-machine-learning-assisted-modeling) para saber como os pipelines de Assisted Modeling do Alteryx são convertidos nestes passos.
