## Descrição

O passo **ML: Pontuar** pontua uma tabela de dados com um modelo treinado por [ML: Treinar modelo](/pt-pt/reference/workflow-steps/machine-learning/ml-train/) e escreve os dados com uma coluna de previsão acrescentada. Como o modelo chega como uma tabela normal, pode treinar uma vez e pontuar muitas tabelas, ou voltar a pontuar sempre que chegarem novos dados. O passo é executado como uma tarefa gerida do PlaidCloud (tal como o passo LLM).

## Separador de pontuação

- **Tabela de dados** — a tabela a pontuar. Tem de conter todas as colunas de variáveis com que o modelo foi treinado.
- **Tabela de modelo** — uma tabela de modelo escrita por um passo ML: Treinar modelo. O passo falha se a tabela estiver vazia ou se faltar alguma parte do modelo armazenado.
- **Tabela de saída** — onde os dados pontuados são escritos.
- **Coluna de previsão** — o nome da coluna acrescentada. Deixe em branco para utilizar `prediction`. O passo falha se o nome já existir na tabela de dados.

## Saída

A tabela de saída contém todas as colunas da tabela de dados mais a coluna de previsão: etiquetas de classe em texto para classificadores, valores numéricos para regressores. Os valores das variáveis são preparados exatamente como foram no momento do treino, e os valores categóricos que o modelo nunca viu durante o treino são ignorados em vez de causarem um erro.

A tabela de modelo tem de ter a forma que um passo ML: Treinar modelo escreve — o conjunto completo de colunas do modelo, um algoritmo conhecido e todas as partes do modelo armazenado presentes. O próprio modelo é carregado sob uma restrição que rejeita tudo o que esteja fora da pilha científica padrão, pelo que uma linha de modelo criada manualmente não pode executar código arbitrário.

### Mais colunas de saída

A secção **Opções de pontuação** tem os seguintes campos. Os fluxos de trabalho KNIME convertidos também os utilizam.

- **Colunas de probabilidade de classe** (`probability_column_template`) — para um classificador, acrescenta uma coluna de probabilidade por classe, com o nome definido por este modelo com `{class}` substituído. **Probabilidades antes da previsão** (`probabilities_first`) coloca-as antes da coluna de previsão, e **Ordenar as classes conforme aparecem pela primeira vez no treinamento** (`classes_in_domain_order`) ordena-as pela ordem em que as classes aparecem pela primeira vez nos dados de treino, em vez de ordenadas alfabeticamente.
- **Coluna de confiança** (`confidence_column`) — para um classificador, acrescenta a probabilidade da classe vencedora com este nome.
- **Coluna de variância** (`variance_column`) — para um regressor de floresta, acrescenta a variância das previsões das árvores com este nome.
- **Coluna de contagem de modelos** (`model_count_column`) — para um modelo de árvores, acrescenta o número de árvores com este nome.
- **Ordem das colunas acrescentadas** (`column_order`) — a ordem das colunas acrescentadas. Em branco: previsão, probabilidades, confiança, variância e, por fim, contagem de modelos.
- **Escrever em vez disso** (`report`) — escreve uma das tabelas do próprio modelo em vez dos dados pontuados, como `variable_importance`, `coefficients`, `statistics`, `pmml` (o modelo como documento PMML), `centers`, `cluster_counts` ou `association_rules`.
- **Formato do modelo** (`model_format`) — `pmml` pontua com um documento PMML: a tabela de modelo contém o documento, ou o modelo de um learner que tenha uma forma PMML.
- **Configurações do algoritmo** (`algorithm_settings`) — definições da pontuação ou do relatório específicas do algoritmo do modelo, como o número de componentes para que um modelo `pca` projeta.
- **Terceira tabela** (`source_c`) — uma terceira tabela que alguns algoritmos leem, como a floresta aleatória que um modelo `knn_distance` utiliza.

Um assistente de IA ou a API REST também pode definir `report` como `shap_values`.

## Limites e ressalvas

- **Conjunto de trabalho em memória** — a tabela de dados é lida para memória, pelo que o passo visa cerca de um milhão de linhas por execução.
- **Fluxos de trabalho Alteryx convertidos** — uma ferramenta Predict convertida fixa a coluna de previsão ao nome da variável-alvo com o sufixo `_predicted`.
