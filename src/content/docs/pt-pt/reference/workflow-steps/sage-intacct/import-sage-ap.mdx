## Descrição

Importe os cabeçalhos das faturas de Contas a Pagar do Sage Intacct através da API REST do Sage Intacct. Cada linha é uma fatura de AP, com o fornecedor, a data do razão geral, a data de vencimento, os totais e os campos de estado necessários para relatórios a jusante.

Utilize um [Sage Intacct REST Connector](../../../connectors/rest/sage-intacct/) configurado como origem. Para importar ao mesmo tempo o detalhe ao nível da linha, combine este passo com [Import Sage AP Lines](../import-sage-ap-lines/).

## Itens de configuração específicos

* **Ligação Sage** — a ligação REST do Sage Intacct de onde se lê. As ligações Sage são geridas em **Tools > Connections**.
* **ID da empresa** — a empresa do Intacct a consultar. Obrigatório se as credenciais de remetente abrangerem mais de uma empresa.
* **ID(s) de entidade (separados por vírgulas)** — restringe a importação a uma ou mais entidades do Intacct. Deixe em branco para importar todas as entidades a que o utilizador tem acesso.
