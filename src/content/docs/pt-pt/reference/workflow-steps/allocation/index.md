Passos de fluxo de trabalho para alocação de custos, imputação interna, preços de transferência e problemas semelhantes de distribuição de valores. Cada passo distribui valores de um conjunto de linhas de origem para um conjunto de destino, com base em dados de driver e num método.

## Passos

- [Allocation Rules](/pt-pt/reference/workflow-steps/allocation/allocation-rules/) — definir e aplicar regras de alocação com condições explícitas.
- [Allocation Split](/pt-pt/reference/workflow-steps/allocation/allocation-split/) — dividir valores de origem por destinos com uma tabela de indutores.
- [Etiquetagem baseada em regras](/pt-pt/reference/workflow-steps/allocation/rule-based-tagging/) — etiquetar linhas com atributos de uma dimensão antes de alocar.

## Relacionado

- [Alocações (guia)](/pt-pt/guides/allocations/) — conceitos e fluxos de trabalho completos para problemas de alocação.
- [Dimensões (guia)](/pt-pt/guides/dimensions/) — configure as hierarquias para onde as alocações distribuem os valores.
