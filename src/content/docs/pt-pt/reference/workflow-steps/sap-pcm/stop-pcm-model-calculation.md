## Descrição



Aborta um cálculo de modelo SAP PCM em curso. Útil quando um cálculo está a demorar demasiado, foi iniciado com dados de entrada incorretos ou precisa de ser parado para libertar recursos do servidor para uma tarefa de maior prioridade.

Se nenhum cálculo estiver em curso, o passo grava um aviso no registo do fluxo de trabalho e continua.


## As nossas credenciais


O PlaidCloud é um parceiro oficial da SAP e um fornecedor preferencial de serviços relacionados com a conceção e a implementação de modelos SAP PCM.




## Exemplos


Selecione Agente a utilizar na lista pendente, introduza “Model Name”, marque a caixa de seleção “Wait for Copy to Complete” e clique em “Save and Run Step”.
