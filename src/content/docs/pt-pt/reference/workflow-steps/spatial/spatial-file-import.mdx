## Descrição

O passo **Importação de ficheiro espacial** lê um ficheiro espacial — MapInfo `.TAB`,
ESRI `.shp`, `.kml`, `.geojson` ou SRC `.geo` — e os respetivos ficheiros auxiliares para uma
tabela, com uma linha por elemento e uma coluna de geometria WKT. É o equivalente da
ferramenta *Input Data* do Alteryx apontada a um ficheiro espacial e é executado no motor
de fluxos de trabalho (GDAL).

## Parâmetros de importação

- **Origem** — o ficheiro espacial no armazenamento de documentos. Os ficheiros auxiliares
  (por exemplo, os `.dat`/`.map`/`.id`/`.dbf` de um `.TAB`, ou os `.shx`/`.dbf`/`.prj` de um shapefile)
  são lidos automaticamente a partir do mesmo local.
- **Tabela de destino** — a tabela onde os elementos são escritos.

## Notas

O esquema de saída é obtido do ficheiro, pelo que não há mapeamento de colunas. A geometria
proprietária de um ficheiro SRC `.geo` não pode ser lida; os respetivos atributos `.dbf` são
importados com valores de geometria vazios.
