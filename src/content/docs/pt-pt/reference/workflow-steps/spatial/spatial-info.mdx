## Descrição

O passo **Spatial Info** mede cada geometria e acrescenta as medições como
colunas. É o equivalente da ferramenta *Spatial Info* do Alteryx e é executado no
motor de fluxos de trabalho.

As medições são **geodésicas WGS84**, não planares. Isto é importante: a forma SQL
destas medidas é um valor planar em graus² multiplicado por uma constante equatorial e,
como essa constante não diminui com a longitude à medida que a latitude aumenta,
**sobrestima** a área e o comprimento — cerca de um quarto a mais nas latitudes dos EUA.
Calculá-las de forma geodésica dá uma única resposta, coincidente com o Alteryx em todos os
armazéns de dados.

## Origem e opções

- **Tabela de origem** / **Tabela de saída** — as geometrias de entrada e o local
  onde as linhas medidas são escritas.
- **Coluna de geometria** — a coluna de geometria WKT a medir.
- **Medições** — as medidas a acrescentar. Cada seleção adiciona as colunas
  abaixo.
- **Raio da esfera (km)** *(opcional)* — mede numa esfera com este raio.
  Deixe em branco para medir no elipsoide WGS84.

## Colunas de saída

| Medição | Colunas adicionadas | Tipo |
|---|---|---|
| Área (milhas) | `AreaSqMi` | número |
| Área (km) | `AreaSqKm` | número |
| Comprimento (milhas) | `LengthMi` | número |
| Comprimento (km) | `LengthKm` | número |
| Coordenadas do centroide | `CentroidX`, `CentroidY` | número |
| Coordenadas do retângulo delimitador | `BR_Left`, `BR_Top`, `BR_Right`, `BR_Bottom` | número |
| Objeto centroide | `Centroid` | geometria WKT |
| Objeto retângulo delimitador | `BoundingRect` | geometria WKT |
| Polígono do retângulo delimitador | `BoundingRectPolygon` | geometria WKT |
| É válida | `IsValid` | booleano |
| Tipo de objeto | `SpatialObjType` | texto |
| Número de partes | `NumParts` | número |
| Número de pontos | `NumPoints` | número |
| Coordenadas do ponto final | `EndPointX`, `EndPointY` | número |
| Objeto ponto final | `EndPoint` | geometria WKT |

`IsValid` indica se a geometria tal como fornecida é uma forma válida, antes de qualquer reparação.

O objeto retângulo delimitador e o polígono do retângulo delimitador são serializados no
mesmo anel de cinco vértices em WKT, pelo que ambas as colunas têm o mesmo valor.

## Notas

O tipo de objeto, o número de partes, o número de pontos e os pontos finais são acrescentados com
nomes de coluna de melhor esforço — o Alteryx documenta as medidas mas não indica nenhuma coluna de saída,
pelo que os nomes exatos serão verificados com um fluxo de trabalho real num acompanhamento posterior.
O único tipo de informação não convertido é a **chave Peano**, um índice espacial
proprietário do Alteryx sem especificação pública: é ignorada, e a conversão emite
uma nota que a identifica, para que a omissão seja visível no fluxo de trabalho convertido.
