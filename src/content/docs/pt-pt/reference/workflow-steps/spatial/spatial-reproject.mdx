## Descrição

O passo **Espacial: reprojetar** transforma a geometria WKT de cada linha de um sistema de referência de coordenadas para outro e escreve o resultado numa tabela de saída, com as restantes colunas transportadas.

O formulário do passo tem uma secção **Tabelas** para as tabelas de origem e de saída e respetivas colunas, e uma secção **Projeção** para a coluna de geometria, os dois sistemas de coordenadas e a coluna de saída. Os [fluxos de trabalho KNIME migrados](/pt-pt/guides/workflows/migrate-knime-workflows/) utilizam este passo para os respetivos nós de projeção.

## Configuração

- **Tabela de origem** (`source`) e **Tabela de saída** (`target_frame`) — a tabela a ler e a tabela a escrever.
- **Coluna de geometria** (`geometry_column`) — a coluna que contém cada geometria em WKT. O valor predefinido é `SpatialObj`.
- **Sistema de coordenadas de origem** (`source_crs`) — o sistema de referência de coordenadas em que as geometrias estão, como `EPSG:4326`.
- **Sistema de coordenadas de destino** (`target_crs`) — o sistema de referência de coordenadas para o qual as projetar, como `EPSG:3857`.
- **Coluna de geometria projetada** (`output_column`) — a coluna que recebe a geometria projetada. Deixe-a vazia para substituir a própria coluna de geometria.
- **Colunas de origem** (`source_columns`) e **Colunas de saída** (`target_columns`) — as colunas lidas e as colunas transportadas, com os respetivos tipos de dados.

Uma linha sem geometria mantém uma geometria projetada vazia.
