## Descrição

O passo **Espacial: Ponto para linha** une pontos numa linha, escrita numa coluna chamada `SequenceLine`. Escreve uma linha por cada grupo, ou uma linha para todos os pontos quando não indica nenhum grupo.

## Origem e opções

- **Tabela de origem** e **Tabela de saída** — a tabela a ler e a tabela a escrever.
- **Coluna do ponto** — a coluna que contém os pontos WKT.
- **Agrupar por** *(opcional)* — uma linha por cada valor desta coluna. Deixe em branco para fazer de todos os pontos uma só linha.
- **Ordenar por** *(opcional)* — a coluna que ordena os pontos numa linha. Os números são ordenados como números e os outros valores como texto. Sem ela, os pontos mantêm a ordem de entrada.
