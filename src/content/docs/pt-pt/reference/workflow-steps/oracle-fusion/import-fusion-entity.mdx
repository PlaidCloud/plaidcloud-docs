## Descrição

Importa uma entidade do Oracle Fusion Cloud para uma tabela do projeto através da sua [ligação Oracle Fusion](/pt-pt/guides/connections/oracle-fusion/), chamando diretamente os pontos de acesso OData ou BI Publisher (BIP) do Fusion. Escolha a ligação, o tipo de entidade e os filtros pretendidos; o passo obtém os registos correspondentes e grava-os, sem necessidade de criar uma consulta OData.

Para uma extração demasiado grande para uma chamada direta, utilize antes o passo [Import Fusion Bulk Extract](/pt-pt/reference/workflow-steps/oracle-fusion/import-fusion-bulk-extract/).

## Configuração

| Campo | Obrigatório | Notas |
|---|---|---|
| Ligação Fusion | Sim | A ligação Oracle Fusion através da qual os dados são lidos. |
| Tabela de destino | Sim | A tabela do projeto onde os resultados são gravados. É totalmente substituída em cada execução. |
| Tipo de entidade | Sim | A entidade a importar. Por predefinição, `gl_balances`. Uma de `gl_balances`, `journal_batches`. |
| Filtros | Não | Filtros de intervalo (`ge`/`le`) em campos de data, período contabilístico e saldo/montante numérico, mais filtros de igualdade em campos discretos (razão, moeda). Cada entidade limita os filtros aos campos que o Oracle Fusion consegue realmente avaliar no servidor — um campo não suportado é rejeitado, não ignorado silenciosamente. |

### Entidades e campos filtráveis

| Tipo de entidade | O que importa | Campos filtráveis |
|---|---|---|
| `gl_balances` | Saldos de contas do razão geral | intervalo de períodos contabilísticos (`ge`/`le`), intervalo de contas, intervalo de montantes de saldo (`ge`/`le`) |
| `journal_batches` | Cabeçalhos e estado dos lotes de lançamentos | intervalo de datas (`ge`/`le`), intervalo de períodos contabilísticos (`ge`/`le`) |

<Aside type="note">
Um filtro de intervalo só precisa de um limite para ser útil — `accounting_date ge 2026-01-01` sem limite superior importa tudo a partir dessa data. Indique os dois limites para delimitar a extração com precisão.
</Aside>
