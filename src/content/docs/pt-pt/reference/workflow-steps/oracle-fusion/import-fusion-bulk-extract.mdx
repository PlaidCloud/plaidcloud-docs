## Descrição

Importa uma entidade do Oracle Fusion Cloud, através da sua [ligação ao Oracle Fusion](/pt-pt/guides/connections/oracle-fusion/), pelo caminho de extração em massa FBDI/BI Publisher da Oracle: o PlaidCloud submete uma tarefa de exportação, consulta-a periodicamente até estar concluída, transfere o ficheiro resultante e escreve-o numa tabela de projeto. Utilize este passo em vez do passo [Import Fusion Entity](/pt-pt/reference/workflow-steps/oracle-fusion/import-fusion-entity/) para uma importação demasiado grande ou lenta para uma chamada OData/BIP direta.

## Configuração

| Campo | Obrigatório | Notas |
|---|---|---|
| Ligação Fusion | Sim | A ligação Oracle Fusion através da qual ler. |
| Tabela de destino | Sim | A tabela de projeto para onde os resultados são escritos. É totalmente substituída em cada execução. |
| Tipo de entidade | Sim | Qual a entidade a extrair. Predefinição `gl_balances`. Uma de `gl_balances`, `journal_batches`. |
| Filtros | Não | O mesmo conjunto de filtros que o passo [Import Fusion Entity](/pt-pt/reference/workflow-steps/oracle-fusion/import-fusion-entity/): filtros de intervalo (`ge`/`le`) em campos de data, de período contabilístico e de saldo/montante numérico, além de filtros de igualdade em campos discretos. Aplicados ao nível da tarefa de extração. |

<Aside type="caution">
Este passo aguarda uma tarefa de exportação assíncrona — conte com um tempo substancialmente superior ao do passo [Import Fusion Entity](/pt-pt/reference/workflow-steps/oracle-fusion/import-fusion-entity/) para o mesmo número de linhas. Utilize-o apenas quando a importação for realmente demasiado grande para uma chamada OData/BIP direta.
</Aside>
