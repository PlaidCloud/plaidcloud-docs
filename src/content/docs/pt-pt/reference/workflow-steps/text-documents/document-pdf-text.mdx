## Descrição

Extrai o conteúdo de texto de um PDF para uma tabela. É o equivalente da ferramenta *PDF to Text* do Alteryx e é executado no motor de fluxos de trabalho, onde residem as bibliotecas de documentos.

Utilize-o para colocar o conteúdo dos PDF numa forma que o resto de um fluxo de trabalho consiga filtrar, analisar e juntar. Para uma extração ao nível da página e com perceção do esquema, utilize antes [PDF Text Extract](/pt-pt/reference/workflow-steps/text-documents/document-pdf-extract/).

## Origem e opções

- **Tabela de origem** / **Tabela de saída** — a tabela que indica os PDF e o local onde o texto extraído é escrito.
- **Colunas** — as colunas de origem a transmitir para a saída.
