## Descrição

O passo **PDF Text Extract** extrai texto de documentos PDF. É o equivalente da ferramenta correspondente do Alteryx e é executado no motor de fluxos de trabalho (as bibliotecas de ML / PLN / documentos são executadas na tarefa do executor).

## Origem e opções

- **Origem / Tabelas de saída** — os dados de entrada e o local onde o resultado é escrito.
- **PDF path column** (ou um **diretório** de PDFs).

## Colunas

O separador **Colunas** mapeia as colunas de entrada transmitidas para a saída.
