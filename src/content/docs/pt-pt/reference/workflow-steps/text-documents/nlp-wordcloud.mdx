## Descrição

O passo **Text Word Cloud** gera uma imagem de nuvem de palavras a partir de uma coluna de texto. É o equivalente da ferramenta correspondente do Alteryx e é executado no motor de fluxos de trabalho (as bibliotecas de ML / PLN / documentos são executadas na tarefa do executor).

## Origem e opções

- **Origem / Tabelas de saída** — os dados de entrada e o local onde o resultado é escrito.
- **Coluna de texto**, número máximo de palavras, dimensão da imagem e cor de fundo.

## Colunas

O separador **Colunas** mapeia as colunas de entrada transmitidas para a saída.
