## Descrição

O passo **Image OCR** extrai texto de imagens através de OCR. É o equivalente da ferramenta correspondente do Alteryx e é executado no motor de fluxos de trabalho (as bibliotecas de ML / PLN / documentos são executadas na tarefa do executor).

## Origem e opções

- **Origem / Tabelas de saída** — os dados de entrada e o local onde o resultado é escrito.
- **Coluna do caminho da imagem**.

## Colunas

O separador **Colunas** mapeia as colunas de entrada transmitidas para a saída.
