## Descrição


Envie uma mensagem direta (DM) do Twitter a partir de [@plaidcloud](https://twitter.com/plaidcloud).



### Conta do Twitter


Indique a conta do Twitter que vai receber a DM de @plaidcloud. Este utilizador tem de seguir @plaidcloud para receber a mensagem. É permitido, embora não obrigatório, antecipar o arroba (@) ao nome de utilizador.



### Mensagem


Introduza a mensagem pretendida. O Analyze não permite um valor com mais de 140 carateres.


Tenha em atenção que as Variáveis do projeto e as variáveis do fluxo de trabalho estão disponíveis para utilização com esta transformação.


<Aside type="danger">Ao utilizar variáveis, é possível gerar mensagens que excedam o limite de 140 carateres. Se isso acontecer, a mensagem NÃO é enviada. Em vez disso, o seguinte erro é escrito no registo: *Twitter API returned a 403 (Forbidden), There was an error sending your message: The text of your direct message is over 140 characters.</Aside>

## Exemplos

Neste exemplo, é enviada uma DM de [@PlaidCloud](https://twitter.com/plaidcloud) para [@tartansolutions](https://twitter.com/tartansolutions). São utilizadas variáveis de sistema na mensagem. A mensagem final é *Analyze Demo is running on #PlaidCloud*.
