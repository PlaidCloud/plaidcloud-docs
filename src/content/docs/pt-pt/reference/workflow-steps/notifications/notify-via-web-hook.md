## Descrição



Envia uma notificação através de um POST para um URL de webhook — útil para acionar ações personalizadas a jusante, alertar plataformas de integração (Zapier, n8n, Make) ou controlar bots do Slack/Teams/Discord que não utilizam conectores de primeira classe.

O formato da carga útil e quaisquer cabeçalhos personalizados são configuráveis. O serviço recetor é responsável pelo que acontece a seguir.
