## Descrição



Envia uma notificação por correio eletrónico a um grupo de distribuição do PlaidCloud — uma lista nomeada de destinatários gerida nas definições da área de trabalho. É útil para atualizações de estado, notificações de conclusão ou alertas de erro que tenham de chegar a um público definido.

As mensagens são enviadas a partir do serviço de notificações do PlaidCloud. Os grupos de distribuição são geridos centralmente, para que os autores de fluxos de trabalho não incorporem endereços de correio eletrónico nas definições dos fluxos de trabalho.


## Selecionar a lista de distribuição do PlaidCloud


Selecione uma única lista de distribuição no menu pendente. As listas de distribuição podem ser criadas em Ferramentas. Para obter detalhes sobre como criar uma lista de distribuição, consulte aqui: [Ferramentas do PlaidCloud – Distro](/pt-pt/administration/access/member-management/#gerir-listas-de-distribuição-distro).



## Mensagem


Indique o **Assunto** e o **Corpo** como pretender.



Tenha em atenção que as Variáveis do projeto e as variáveis do fluxo de trabalho estão ambas disponíveis para utilização com esta transformação, tanto na linha de assunto como no corpo da mensagem.



Além disso, é permitido código HTML normal no corpo para personalizar ainda mais o aspeto das mensagens de correio eletrónico.


## Exemplos


Neste exemplo, são utilizadas todas as variáveis de sistema. Além disso, é utilizado um pouco de HTML para formatar a primeira linha do corpo. A execução desta transformação envia o seguinte correio eletrónico a todos os membros indicados no grupo de distribuição:


* DE: [info@tartansolutions.com](mailto:info%40tartansolutions.com) (lembre-se de que todas as mensagens são enviadas deste endereço)
* Assunto: DEMO Analyze Demo Running


<Aside>Os destinatários individuais da mensagem de correio eletrónico **não** conseguem ver os nomes dos outros membros da lista de distribuição.</Aside>
