## Descrição

O **Map** gerado a partir da geometria de origem de um relatório composto. É o equivalente da ferramenta *Reporting* / *Portfolio Composer* correspondente do Alteryx e é executado no motor de fluxos de trabalho (reportlab / matplotlib); o renderizador é uma aproximação do resultado do Alteryx.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de saída** — a tabela onde o fragmento gerado é gravado.
- **Ordem do relatório** — a ordem desta parte num relatório composto.
- **Width / Height** — o tamanho do mapa gerado, em píxeis.

## A legenda do tema

Quando uma camada é sombreada por um valor, o mapa desenha uma única legenda que nomeia cada intervalo.

Um Report Map do Alteryx convertido mantém os nomes dos intervalos que o mapa original utilizava —
*High*, *Above Average*, *Average*, *Below Average*, *Low* num mapa temático
típico — e a legenda apresenta esses nomes. Um mapa que não atribui nomes aos intervalos identifica
cada um deles, em vez disso, com o intervalo de valores que abrange.

Como só é desenhada uma legenda, os nomes têm de pertencer aos intervalos de uma única camada. O passo
pára e indica-o, em vez de apresentar uma legenda que parece correta mas nomeia os intervalos errados, quando:

- os valores sombreados não chegam a todos os intervalos que o mapa nomeia, pelo que os nomes não podem
  ser associados aos intervalos efetivamente desenhados;
- apenas alguns dos intervalos têm nome;
- os intervalos pertencem a mais de uma camada, ou mais de uma camada está sombreada.

O sombreado por valor individual continua a nomear cada intervalo com o seu próprio valor, uma vez que
é isso que o intervalo é.

## Colunas

O separador **Colunas** mapeia as colunas de origem disponíveis para a parte do relatório.
