## Descrição

O bloco **Text** de um relatório composto. É o equivalente da ferramenta *Reporting* / *Portfolio Composer* correspondente do Alteryx e é executado no motor de fluxos de trabalho (reportlab / matplotlib); o renderizador é uma aproximação do resultado do Alteryx.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de saída** — a tabela onde o fragmento gerado é gravado.
- **Ordem do relatório** — a ordem desta parte num relatório composto.
- **Conteúdo de texto** — o texto a gerar.

## Referir uma coluna no texto

O conteúdo de texto pode indicar uma coluna entre parênteses retos, sendo o valor impresso
no seu lugar — `[Year] Results` imprime `2026 Results`. Um Report
Text do Alteryx convertido mantém as referências a campos que o respetivo texto já tinha, incluindo
a forma formatada que o Alteryx escreve como `[Year:A]`.

É composto um único texto para toda a tabela de origem, pelo que uma coluna que indique
tem de conter o mesmo valor em todas as linhas lidas. Resuma a coluna a montante se
contiver mais de um valor — um bloco de texto não consegue imprimir vários valores em simultâneo.

`[CurrentYear]` imprime o ano em que o relatório é gerado e não precisa de nenhuma coluna.

Algumas regras mantêm seguro o texto corrido habitual:

- Um nome que corresponda a uma coluna é sempre substituído.
- Um nome que não corresponda a nenhuma coluna interrompe o passo e indica-o, mas apenas quando
  não pode ser outra coisa senão uma referência — um formato escrito colado
  aos dois pontos, como em `[Quarter:A]`.
- O texto entre parênteses retos é impresso tal como o escreveu. `[12:30]` continua a ser uma hora
  e `[Note: continued]` continua a ser um aparte, porque um número isolado não é um nome de coluna
  e o texto corrido é que coloca um espaço depois dos dois pontos.

O próprio formato não é aplicado — o valor é impresso tal como a coluna o contém, pelo que
deve formatar a coluna a montante se precisar de separadores de milhares ou de um formato de data.

## Colunas

O separador **Colunas** mapeia as colunas de origem disponíveis para a parte do relatório.
