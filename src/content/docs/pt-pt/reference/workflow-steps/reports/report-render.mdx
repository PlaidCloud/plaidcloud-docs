## Descrição

O **Render** das partes de relatório compostas num documento PDF. É o equivalente da ferramenta *Reporting* / *Portfolio Composer* correspondente do Alteryx e é executado no motor de fluxos de trabalho (reportlab / matplotlib); o renderizador é uma aproximação do resultado do Alteryx.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de saída** — a tabela onde o fragmento gerado é gravado.
- **Ordem do relatório** — a ordem desta parte num relatório composto.
- **Width / Height** — o tamanho da imagem incorporada, em píxeis.
- **Ficheiro de saída** — o caminho no repositório de documentos para o ficheiro gerado.

- **Formato de saída** (`output_format`) — **PDF** (`pdf`, o predefinido) ou **Página HTML (autocontida)** (`html`) para gravar o relatório como uma única página HTML autocontida. Dê ao nome do ficheiro a extensão `.html`.
- **Segunda tabela de origem** (`source_b`) — uma segunda tabela de entrada, para que a geração componha as partes de ambas as entradas.

## Colunas

O separador **Colunas** mapeia as colunas de origem disponíveis para a parte do relatório.
