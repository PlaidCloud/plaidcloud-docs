## Descrição

A **Table** dos dados de origem de um relatório composto. É o equivalente da ferramenta *Reporting* / *Portfolio Composer* correspondente do Alteryx e é executado no motor de fluxos de trabalho (reportlab / matplotlib); o renderizador é uma aproximação do resultado do Alteryx.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de saída** — a tabela onde o fragmento gerado é gravado.
- **Ordem do relatório** — a ordem desta parte num relatório composto.
- **Colunas** — as colunas de origem a incluir (em branco = todas).

## Colunas

O separador **Colunas** mapeia as colunas de origem disponíveis para a parte do relatório.
