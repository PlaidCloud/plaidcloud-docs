## Blocos de construção de relatórios

Os fluxos de trabalho de relatórios do Alteryx convertidos montam um documento a partir destes passos. Chart,
Image, Map, Table e Text geram cada um uma parte; Layout, Visual Layout e
Overlay organizam as partes; Render grava o resultado composto num PDF.
