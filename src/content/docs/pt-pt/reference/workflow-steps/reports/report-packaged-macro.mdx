## Descrição

A **Macro empacotada** gera um pacote de relatório importado de uma *macro de relatório empacotada* do Alteryx. É um passo Report de primeira classe: a definição da macro incluída acompanha o passo automaticamente e a parte é gerada pelo mesmo caminho de artefactos de relatório que os restantes passos Report.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de destino** — a tabela onde o resultado gerado é gravado.
- **Ordem do relatório** — a posição desta parte num relatório composto.
