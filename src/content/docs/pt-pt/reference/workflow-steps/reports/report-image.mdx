## Descrição

A **Image** inserida num relatório composto. É o equivalente da ferramenta *Reporting* / *Portfolio Composer* correspondente do Alteryx e é executado no motor de fluxos de trabalho (reportlab / matplotlib); o renderizador é uma aproximação do resultado do Alteryx.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de saída** — a tabela onde o fragmento gerado é gravado.
- **Ordem do relatório** — a ordem desta parte num relatório composto.
- **Modo de imagem** — Static (uma imagem base64 em linha) ou Field (um caminho de ficheiro por linha).
- **Base64 image** — os dados da imagem em linha para o modo Static.

## Colunas

O separador **Colunas** mapeia as colunas de origem disponíveis para a parte do relatório.
