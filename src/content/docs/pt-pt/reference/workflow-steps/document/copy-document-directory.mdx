## Descrição


Copie um diretório completo dentro do PlaidCloud Document.



## Copiar diretório


Primeiro, selecione a conta adequada no menu pendente.



Em seguida, prima o botão **Procurar** para selecionar o diretório que pretende copiar.



## Selecionar destino


Primeiro, selecione a conta adequada no menu pendente.



Em seguida, prima o botão **Procurar** para selecionar o destino do diretório copiado. 



Se pretender, o diretório copiado pode receber um novo nome. Para o fazer, basta assinalar a caixa **Rename the Copied Folder to:** e escrever um novo nome.


<Aside>O comportamento predefinido é substituir tudo o que já exista. Tenha cuidado para não substituir acidentalmente.</Aside>
