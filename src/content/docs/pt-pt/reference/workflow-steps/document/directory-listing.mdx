## Descrição

Escreve uma tabela com a lista dos ficheiros de um diretório de documentos. Utilize-o para acionar passos seguintes com base nos ficheiros presentes — por exemplo, para percorrer todos os ficheiros de uma pasta ou para verificar o que um processo anterior entregou.

## Diretório

Selecione uma conta de documentos e prima o botão **Procurar** para escolher a pasta a listar.

## Opções

- **Padrão de ficheiro** *(opcional)* — um glob como `*.csv` para listar apenas os ficheiros correspondentes. Deixe em branco para listar tudo.
- **Incluir subdiretórios** — quando marcado, os ficheiros das pastas aninhadas também são listados.
- **Tabela de destino** — a tabela que recebe a listagem.

## Definições adicionais

As opções de **Que ficheiros** restringem a listagem:

- **Listar também as pastas, com uma coluna IsFolder** (`include_folders`) — lista também as pastas, como linhas. Cada linha passa então a ter uma coluna final `IsFolder`, verdadeira para uma pasta.
- **Listar primeiro o próprio diretório** (`include_root_folder`) — com `include_folders`, lista também o próprio diretório, em primeiro lugar.
- **Padrão do nome de ficheiro** (`file_name_filter`) — apenas ficheiros cujo nome corresponda. O **Tipo de padrão** é **Carácter universal** ou **Expressão regular** (`type`), e **Respeitar maiúsculas e minúsculas** define `case_sensitive`.
- **Padrão do nome de pasta** (`folder_name_filter`) — apenas entradas em pastas cujos nomes correspondam, na mesma forma; todas as pastas pelo caminho abaixo têm de corresponder.
- **Extensões** (`extensions`) — apenas ficheiros com uma destas extensões, sem o ponto. **Respeitar maiúsculas e minúsculas da extensão** (`extensions_case_sensitive`) faz a correspondência respeitando maiúsculas e minúsculas.
- **Incluir ficheiros ocultos (nome que começa por ponto)** (`include_hidden_files`) e **Incluir pastas ocultas e o que estiver abaixo delas** (`include_hidden_folders`) — desmarque qualquer uma para excluir ficheiros ou pastas cujo nome comece por ponto.
