## Descrição


Elimina um ficheiro existente no PlaidCloud Document.



## Ficheiro a eliminar


Em primeiro lugar, selecione a conta adequada no menu pendente.


Em seguida, prima o botão **Procurar** para selecionar o ficheiro a eliminar.

<Aside>Se o ficheiro não existir (já foi eliminado), não é realizada nenhuma ação.</Aside>
