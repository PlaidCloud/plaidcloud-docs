## Descrição


Crie um novo diretório dentro do PlaidCloud Document.



## Onde criar a nova pasta


Primeiro, selecione a conta adequada no menu pendente.



Em seguida, prima o botão **Procurar** para selecionar o diretório superior.



## Nome da nova pasta


Escreva o nome do novo diretório.


<Aside>Se o diretório já existir, não é tomada qualquer ação.</Aside>
