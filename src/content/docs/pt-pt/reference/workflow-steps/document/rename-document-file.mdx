## Descrição


Muda o nome de um ficheiro existente no PlaidCloud Document.



## Ficheiro a renomear


Em primeiro lugar, selecione a conta adequada no menu pendente.



Em seguida, prima o botão **Procurar** para selecionar o ficheiro a renomear.

<Aside>Se o ficheiro renomeado já existir, não é realizada nenhuma ação.</Aside>


## Mudar o nome para


Escreva o novo nome do ficheiro.
