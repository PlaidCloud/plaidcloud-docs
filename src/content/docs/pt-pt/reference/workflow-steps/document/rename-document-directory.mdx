## Descrição


Muda o nome de um diretório existente no PlaidCloud Document.



## Pasta a renomear


Em primeiro lugar, selecione a conta adequada no menu pendente.



Em seguida, prima o botão **Procurar** para selecionar o diretório a renomear.



## Mudar o nome para


Escreva o novo nome do diretório.


<Aside>Se o diretório renomeado já existir, não é realizada nenhuma ação.</Aside>
