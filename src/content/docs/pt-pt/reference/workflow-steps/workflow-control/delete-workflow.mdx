## Descrição


Elimine um fluxo de trabalho existente do PlaidCloud Analyze.



## Fluxo de trabalho a eliminar


Primeiro, selecione o **Projeto** que contém o fluxo de trabalho a eliminar no menu pendente **Projeto**.



Em seguida, selecione o fluxo de trabalho específico a eliminar no menu pendente **Fluxo de trabalho**.


<Aside type="danger">Não existe nenhuma caixa de diálogo para confirmar a eliminação. Certifique-se de que está a selecionar o fluxo de trabalho correto!</Aside>
