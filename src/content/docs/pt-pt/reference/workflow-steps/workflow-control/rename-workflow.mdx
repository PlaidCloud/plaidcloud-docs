## Descrição


Mude o nome de um fluxo de trabalho existente do PlaidCloud Analyze.

<Aside>Se o fluxo de trabalho com o novo nome já existir, será escrito no registo um erro a indicar que *Workflow \{workflow} in project \{project} already exists.* Não será tomada nenhuma ação. Isto limita, na prática, a transformação **Mudar o nome do fluxo de trabalho** a uma única utilização.</Aside>


## Fluxo de trabalho a mudar de nome


Em primeiro lugar, selecione o projeto que contém o fluxo de trabalho a mudar de nome no menu pendente **Projeto**.



Em seguida, selecione o fluxo de trabalho em causa no menu pendente **Fluxo de trabalho**.



Por fim, introduza o novo nome do fluxo de trabalho no campo **Mudar o nome para**. Lembre-se de que o nome deve ser único no projeto.
