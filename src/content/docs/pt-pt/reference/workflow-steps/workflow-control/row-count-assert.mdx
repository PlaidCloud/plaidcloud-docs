## Descrição

Faz falhar o fluxo de trabalho quando duas tabelas têm contagens de linhas diferentes. Utilize-o como barreira de qualidade de dados — por exemplo, para confirmar que uma tabela transformada manteve todas as linhas da sua origem, ou que uma reconciliação não eliminou nem duplicou registos. Quando as contagens coincidem, o fluxo de trabalho continua; quando diferem, o passo interrompe o fluxo de trabalho e escreve a mensagem de falha no registo do fluxo de trabalho.

## Configuração

- **Tabela esquerda** — a primeira tabela a contar.
- **Tabela da direita** — a segunda tabela a contar.
- **Mensagem de falha** — a mensagem apresentada quando as contagens diferem. Por predefinição, é «As contagens de linhas não coincidem».

Compare com [Gerar erro de fluxo de trabalho](/pt-pt/reference/workflow-steps/workflow-control/raise-workflow-error/) quando precisar de falhar com base numa condição arbitrária em vez de uma diferença na contagem de linhas.
