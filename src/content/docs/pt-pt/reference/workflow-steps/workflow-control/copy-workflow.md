## Descrição


Faça uma cópia de um fluxo de trabalho existente do PlaidCloud Analyze.



## Fluxo de trabalho a copiar


Primeiro, selecione o projeto que contém o fluxo de trabalho a copiar no menu pendente **Projeto**.



Em seguida, selecione o fluxo de trabalho específico a copiar no menu pendente **Fluxo de trabalho**.



Depois, introduza o nome do novo fluxo de trabalho no campo **Novo fluxo de trabalho**. Lembre-se: o nome deve ser único no projeto.
