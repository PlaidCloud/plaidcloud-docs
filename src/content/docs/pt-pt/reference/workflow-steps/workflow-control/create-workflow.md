## Descrição


Crie um novo fluxo de trabalho do PlaidCloud Analyze.



## Fluxo de trabalho a criar


Primeiro, selecione no menu pendente o projeto em que o novo fluxo de trabalho deve ser criado.



Em seguida, escreva um nome para o fluxo de trabalho. O nome deve ser único no projeto.
