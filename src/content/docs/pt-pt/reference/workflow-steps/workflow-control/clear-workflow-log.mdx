## Descrição


Limpe o registo de um fluxo de trabalho existente do PlaidCloud Analyze.



## Registo do fluxo de trabalho a limpar


Primeiro, selecione o **Projeto** que contém o registo do fluxo de trabalho a limpar no menu pendente **Projeto**.



Em seguida, selecione o registo específico do fluxo de trabalho a limpar no menu pendente **Fluxo de trabalho**.


<Aside type="danger">Não existe nenhuma caixa de diálogo para confirmar a eliminação. Certifique-se de que seleciona o registo do fluxo de trabalho correto.</Aside>
