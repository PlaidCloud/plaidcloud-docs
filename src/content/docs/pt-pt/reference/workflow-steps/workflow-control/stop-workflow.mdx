## Descrição


«Parar fluxo de trabalho» pára um fluxo de trabalho existente que esteja em execução.


<Aside>Se o fluxo de trabalho não estiver em execução quando este passo for executado, será escrito no registo um aviso a indicar que *Workflow is already stopped.</Aside>


## Fluxo de trabalho a parar


Em primeiro lugar, selecione o projeto que contém o fluxo de trabalho a parar no menu pendente **Projeto**.



Em seguida, selecione o fluxo de trabalho em causa no menu pendente **Fluxo de trabalho**.
