O PlaidCloud Lakehouse pode federar consultas diretamente sobre formatos de tabela aberta, permitindo-lhe consultar os dados no local sem os mover primeiro para o PlaidCloud. É útil para juntar dados do lakehouse com data lakes externos que já são geridos em Iceberg, Delta Lake ou Hudi.

## Formatos

- [Apache Iceberg](/pt-pt/reference/connectors/open-tables/iceberg/)
- [Delta Lake](/pt-pt/reference/connectors/open-tables/delta-lake/)
- [Apache Hudi](/pt-pt/reference/connectors/open-tables/hudi/)
- [Apache Hive](/pt-pt/reference/connectors/open-tables/hive/) — formato de tabela aberta Hive (distinto do [conector do motor de consultas Hive](/pt-pt/reference/connectors/databases/hive/))
