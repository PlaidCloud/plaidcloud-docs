**Apache Doris** é a base de dados analítica MPP de elevado desempenho da qual o StarRocks derivou. Utilize este conector para consultar implementações do Doris a partir de fluxos de trabalho do PlaidCloud. A ligação utiliza o protocolo de comunicação do MySQL com autenticação padrão por nome de utilizador e palavra-passe.

## Documentação de origem
[Documentação do Apache Doris](https://doris.apache.org/docs/4.x/gettingStarted/what-is-apache-doris).

A [página inicial do projeto Apache Doris](https://doris.apache.org/).

## Configuração

Este conector utiliza um fluxo de autenticação específico do fornecedor e é configurado diretamente a partir do ecrã **Ligações** da sua área de trabalho. Os campos de configuração apresentados dependem das credenciais que o administrador do seu tenant disponibilizou para a integração.

Consulte a [documentação do doris](https://doris.apache.org/docs/) para obter os pormenores de configuração mais recentes.

Se precisar de ajuda para configurar este conector para o seu tenant, contacte a sua equipa de conta — as credenciais específicas do conector, os URL dos ambientes e qualquer pré-aprovisionamento necessário têm normalmente de ser coordenados com o suporte do PlaidCloud.
