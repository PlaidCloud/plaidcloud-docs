O PlaidCloud disponibiliza conectores dedicados para os principais sistemas ERP empresariais. Cada ERP expõe os dados através da sua própria combinação de protocolos (RFC, SOAP, REST ou acesso direto à base de dados), pelo que cada conector encapsula o padrão adequado a esse fornecedor.

## SAP

- [SAP ECC / S/4HANA](/pt-pt/reference/connectors/erp/sap-ecc/): um único tipo de ligação serve ambos
- [SAP S/4HANA](/pt-pt/reference/connectors/erp/sap-s4/)
- [SAP Analytics Cloud (SAC)](/pt-pt/reference/connectors/erp/sap-sac/)
- [SAP Profitability and Performance Management (PaPM)](/pt-pt/reference/connectors/erp/sap-papm/)
- [SAP Profitability and Cost Management (PCM)](/pt-pt/reference/connectors/erp/sap-pcm/)
