O S/4HANA não tem um conector próprio. Partilha um tipo de ligação com o SAP ECC, porque o PlaidCloud acede a ambos através da mesma interface de Remote Function Call. No ecrã **Ligações**, escolha **New → Instância SAP ECC / S/4HANA**.

**[Conector SAP ECC e S/4HANA →](/pt-pt/reference/connectors/erp/sap-ecc/)**: todos os campos de configuração, para ambas as gerações.

## Documentação do fabricante

Consulte a [documentação do SAP S/4HANA](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE).

- [Passos SAP do fluxo de trabalho](/pt-pt/reference/workflow-steps/sap/): os passos que são executados com esta ligação.
