O PlaidCloud liga-se a anfitriões Git para que os fluxos de trabalho e as aplicações Panel possam ler a partir de repositórios sob controlo de versões. É útil para obter configuração, scripts ou ficheiros baseados em modelos que residem no controlo de código-fonte em vez de numa base de dados ou numa conta de documentos.

## Fornecedores

- [PlaidCloud Git](/pt-pt/reference/connectors/git/plaidcloud-git/) — o serviço Git gerido integrado na sua área de trabalho; sem URL de servidor nem credenciais para configurar
- [GitHub](/pt-pt/reference/connectors/git/github/)
- [GitLab](/pt-pt/reference/connectors/git/gitlab/)
- [Bitbucket](/pt-pt/reference/connectors/git/bitbucket/)
- [Azure Repos](/pt-pt/reference/connectors/git/azure-repos/)
- [AWS CodeCommit](/pt-pt/reference/connectors/git/codecommit/)
