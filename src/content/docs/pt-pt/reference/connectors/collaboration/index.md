O PlaidCloud liga-se a plataformas de conversação de equipa para que os fluxos de trabalho possam enviar notificações, alertas ou atualizações de estado diretamente para os canais que a sua equipa já acompanha. É utilizado sobretudo em conjunto com os passos de fluxo de trabalho [Notify via Slack](/pt-pt/reference/workflow-steps/notifications/notify-via-slack/) e [Notify via Microsoft Teams](/pt-pt/reference/workflow-steps/notifications/notify-via-microsoft-teams/).
