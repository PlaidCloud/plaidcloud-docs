A integração do PlaidCloud com o Jupyter permite que os cientistas de dados trabalhem com tabelas de projetos, executem consultas e utilizem o PlaidCloud como repositório de apoio a partir de ambientes de blocos de notas. A autenticação utiliza tokens OAuth, pelo que as mesmas credenciais funcionam na CLI, nos blocos de notas e na API REST.

## Tópicos

- [Linha de comandos](/pt-pt/reference/cli/jupyter/command-line/): a CLI autónoma para interações com scripts
- [Bloco de notas Jupyter](/pt-pt/reference/cli/jupyter/jupyter-notebook/): utilizar o PlaidCloud a partir de células de blocos de notas
- [Configuração de OAuth](/pt-pt/reference/cli/jupyter/oauth-setup/): configurar a autenticação
