O PlaidXL acrescenta ao Excel funções que leem dados do PlaidCloud diretamente para as células. Escreva `=PLAIDXL.` numa célula e o preenchimento automático do Excel apresenta-as, com uma breve descrição de cada argumento. O separador **Formulas** do painel de tarefas também pode escrever uma por si; consulte [Inserir uma fórmula a partir do painel de tarefas](#inserir-uma-fórmula-a-partir-do-painel-de-tarefas).

| Grupo | Funções | Utilize-as para |
|---|---|---|
| Listas | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Ver o que está disponível para construir |
| Tabelas | [`TABLE.GET_TABLE`](#get_table) | Ler uma tabela inteira para um intervalo |
| Hierarquias | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Dispor os nós de uma dimensão como linhas de um relatório |
| Valores | [`CELL`](#cell), [`CELLS`](#cells) | Calcular um valor agregado para qualquer combinação de nós |
| Blocos de construção | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Descrever a tabela, a medida, a agregação, os nós e a profundidade de detalhe que `CELL`, `CELLS` e `DRILL` utilizam |

[Criar um relatório com funções personalizadas](/pt-pt/reference/cli/plaidxl/build-a-report/) mostra estas funções a trabalhar em conjunto.

## Como funcionam as funções

- **Inicie sessão primeiro.** As funções leem com o seu início de sessão no PlaidCloud, por isso [inicie sessão](/pt-pt/reference/cli/plaidxl/connect/) a partir do painel de tarefas antes de as utilizar.
- **Leem a partir do projeto do livro.** Cada função lê a partir do projeto ligado ao livro no painel de tarefas. `GET_TABLE`, `TBL_LIST` e `DIM_LIST` aceitam também um ID de projeto opcional, para ler outro projeto sem alterar a ligação. Cada livro tem o seu próprio projeto, pelo que dois livros abertos podem ler de projetos diferentes.
- **Os resultados expandem-se.** Uma função que devolve uma lista ou uma tabela preenche as células abaixo (ou à direita). Deixe espaço para os resultados; se algo estiver no caminho, o Excel mostra um erro `#SPILL!`.
- **Recalcule para obter as alterações.** Uma fórmula do PlaidXL obtém os dados novamente quando um dos seus argumentos muda. Para obter novos dados no PlaidCloud, ou um projeto diferente ligado no painel de tarefas, force um recálculo completo — no Windows, prima **Ctrl+Alt+F9**. **Refresh All Tables** atualiza as tabelas obtidas, não as fórmulas.
- **Utilize os nomes exatos.** Escreva os nomes das tabelas, colunas, dimensões e nós exatamente como aparecem no PlaidCloud.

Os argumentos entre parênteses retos são opcionais.

## Listas

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Lista os nomes dos projetos que pode abrir, ordenados por nome.

- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição é `FALSE`, uma coluna.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Lista os nomes das tabelas de um projeto, ordenados por nome.

- `project_id` — o projeto a ler. Por predefinição é o projeto do livro.
- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição é `FALSE`, uma coluna.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Lista os nomes das colunas de uma tabela no projeto selecionado.

- `table_name` — o nome da tabela no PlaidCloud.
- `column_filter` — um tipo de dados, como `"text"`, para listar apenas as colunas desse tipo. Omita-o para listar todas as colunas.
- `orientation` — `"vertical"` (a predefinição) para uma coluna, ou `"horizontal"` para uma linha.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Lista os nomes das dimensões de um projeto.

- `project_id` — o projeto a ler. Por predefinição é o projeto do livro.
- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição é `FALSE`, uma coluna.

## Tabelas

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Devolve as linhas de uma tabela com uma linha de cabeçalho, expandidas a partir da célula da fórmula. Os valores vazios são devolvidos como células em branco.

- `table_name` — o nome da tabela no PlaidCloud.
- `project_id` — o projeto a ler. Por predefinição é o projeto do livro.
- `limit` — o número máximo de linhas a devolver. Por predefinição é 1 048 575, o máximo que uma folha de cálculo comporta abaixo de uma linha de cabeçalho.

`GET_TABLE` devolve todas as colunas. Para escolher colunas ou filtrar linhas, [obtenha antes a tabela a partir do painel de tarefas](/pt-pt/reference/cli/plaidxl/retrieve/#obter-uma-tabela).

## Hierarquias

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Dispõe os nós de uma dimensão, começando em `start_node` e descendo pelos seus descendentes. Cada geração tem mais quatro espaços de avanço do que o seu nó superior, e os grupos de destaque do Excel permitem-lhe recolher e expandir cada nível.

- `dimension_name` — o nome da dimensão, ou o seu caminho no projeto.
- `start_node` — o nó a partir do qual começar, como a raiz da dimensão.
- `hierarchy` — a [hierarquia alternativa](/pt-pt/guides/dimensions/dimensions/#hierarquias-alternativas-de-atributos) a seguir. Por predefinição é `"main"`.
- `orientation` — `"vertical"` (a predefinição) para listar os nós ao longo de uma coluna, ou `"horizontal"` para os listar ao longo de uma linha.
- `generation_limit` — quantas gerações devolver, contando `start_node` como a primeira: `2` devolve o nó inicial e os seus filhos. Omita-o para devolver todas as gerações.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

Devolve `start_node` e os nós abaixo dele que `drill_key` pede, ao longo de uma coluna, com avanço por geração e agrupados num destaque do Excel.

- `dimension_name` — o nome da dimensão, ou o seu caminho no projeto.
- `start_node` — o nó a partir do qual detalhar.
- `drill_key` — a profundidade do detalhe, a partir de [`DRILL_KEY`](#drill_key): todos os descendentes, apenas as folhas, um número de níveis ou um intervalo de gerações.
- `hierarchy` — a hierarquia alternativa a seguir. Por predefinição é `"main"`.

Por exemplo, `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` lista **Total** seguido de todas as regiões folha abaixo dele.

Os [comandos de expansão do friso](/pt-pt/reference/cli/plaidxl/ribbon/#drill-functions) fazem o mesmo para uma dimensão e um nó que tenha escrito em duas células, sem escrever uma fórmula.

## Valores

`CELL` e `CELLS` calculam uma medida — uma coluna numérica de uma tabela — agregada nos nós que escolher numa ou mais dimensões. Pense em cada chamada como uma interseção num relatório: **Revenue** para **EMEA** em **FY2026**.

Descreve-se a interseção com as funções de blocos de construção abaixo, normalmente nas suas próprias células, e depois passam-se essas células a `CELL` ou `CELLS` por qualquer ordem:

| Argumento | Construído com | Obrigatório |
|---|---|---|
| A tabela a ler | [`TABLE_REPR`](#table_repr) | Exatamente uma |
| A coluna a agregar | [`MEASURE`](#measure) para `CELL`, [`MEASURES`](#measures) ou várias células `MEASURE` para `CELLS` | Sim |
| Como a agregar | [`MEASURE_TYPE`](#measure_type) | Não — por predefinição é `sum` |
| Um filtro numa coluna | [`DIMENSION_REPR`](#dimension_repr) | Pelo menos um, um por coluna |

Cada filtro indica uma **coluna da tabela** e um valor. Quando essa coluna está ligada a uma dimensão no PlaidCloud, o valor é um nó, e o filtro inclui tudo o que se agrega nesse nó na hierarquia principal da dimensão — numa coluna **Region** ligada a uma dimensão de geografia, o nó **EMEA** abrange todos os países abaixo dele. Numa coluna que não está ligada a uma dimensão, o filtro corresponde exatamente ao valor.

Os exemplos desta página utilizam uma tabela cujas colunas **Region** e **Period** estão ligadas a dimensões. Utilize os nomes das colunas da sua própria tabela.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Devolve um número: a medida, agregada nas linhas que se encontram sob cada nó que passar.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` mostra a receita total de EMEA em FY2026.

Uma folha repleta de fórmulas `CELL` precisa de menos consultas por célula, porque o PlaidXL reutiliza durante um curto período os detalhes das colunas da tabela em vez de os obter para cada célula. Se não for possível calcular um valor, a célula mostra `#VALUE!` e, ao passar o rato por cima, é apresentado o motivo tal como o PlaidCloud o comunicou, como uma coluna de filtro que não está na tabela ou um nó sem membros. `CELLS` mostra o primeiro motivo para todo o resultado.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Como `CELL`, mas para várias medidas em simultâneo. Devolve um número por medida, ao longo de uma coluna, pela ordem em que as listou.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` passa todo o resultado expandido de `MEASURES`. `B2:B4` mostram a receita, o custo e as unidades de EMEA em FY2026.

## Blocos de construção

Estas funções não leem dados por si. Cada uma devolve um pequeno texto que descreve uma parte de um cálculo, pronto a passar a `CELL`, `CELLS` ou `DRILL`. Coloque-as em células que referencia, para que uma alteração — um período diferente, por exemplo — atualize todas as fórmulas que as utilizam.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

A tabela de onde `CELL` e `CELLS` leem, pelo seu nome no projeto selecionado.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

A coluna numérica que `CELL` agrega.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Várias colunas de medida para `CELLS`, a partir de um intervalo de células que contêm nomes de colunas. O resultado expande-se numa célula por coluna; passe-o a `CELLS` com o operador de expansão, como `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Como agregar a medida. `agg_function` é um dos seguintes, em minúsculas:

| Valor | Devolve |
|---|---|
| `sum` | O total (a predefinição quando não passa um tipo de medida) |
| `mean` | A média |
| `median` | O valor mediano |
| `min` | O menor valor |
| `max` | O maior valor |
| `std` | O desvio-padrão |
| `var` | A variância |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

Um filtro para `CELL` e `CELLS`. Passe um por cada coluna que pretenda filtrar.

- `dimension_name` — o nome de uma **coluna da tabela** — a coluna que contém os valores da dimensão, como `"Region"`. Tem de corresponder exatamente ao nome da coluna; uma coluna que não está na tabela devolve um erro.
- `start_node` — o nó em que agregar, como `"EMEA"`. Numa coluna que não está ligada a uma dimensão, o valor a corresponder.

Referencie uma célula para o nó, para construir uma grelha: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Os espaços iniciais e finais são ignorados, pelo que pode apontar para os nomes de nós com avanço que `DRILL` dispõe.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

A profundidade a que [`DRILL`](#drill) desce abaixo do seu nó inicial. `d_key` é texto simples, seja uma forma verbal ou uma chave de detalhe escrita por extenso:

| `d_key` | Detalha até |
|---|---|
| `"all"` | Todos os descendentes |
| `"leaves"` | Apenas as folhas, que são os nós sem nada abaixo |
| `"1 level"`, `"2 levels"`, … | Esse número de gerações abaixo |
| `">[...]"` | A chave de detalhe escrita por extenso, como na tabela seguinte |

Escreva o número em algarismos: `"2 levels"`, não `"two levels"`. Um `drill` inicial é ignorado, pelo que `"drill 2 levels"` também funciona.

Uma chave escrita por extenso conta as gerações abaixo do nó inicial, que é a geração 0 e está sempre incluído. Os números negativos contam a partir das folhas de cada ramo, pelo que uma hierarquia irregular funciona como seria de esperar.

| Chave | Inclui |
|---|---|
| `>[*]` ou `>[:]` | Todos os nós |
| `>[]` ou `>[-1]` | Apenas as folhas |
| `>[n]` | O nó inicial e `n` gerações abaixo dele. `>[0]` é apenas o nó inicial. |
| `>[a:]` | O nó inicial, depois a geração `a` e tudo o que está abaixo dela |
| `>[a:b]` | O nó inicial, depois as gerações de `a` até `b - 1` |
| `>[0:-k]` | O nó inicial e todos os nós que têm pelo menos `k` gerações abaixo, pelo que as últimas `k` gerações de cada ramo ficam de fora. `>[0:-1]` é todos os nós exceto as folhas. |
| `>[a:-k]` | O mesmo, começando na geração `a` |

Para a hierarquia `A`, com os filhos `B`, `C` e `D`, em que `B` tem `B1` e `B2` e `C` tem `C1`:

| Chave | Resultado |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Os nós são listados pela ordem da hierarquia, cada um sob o seu próprio nó superior, e os grupos de destaque do Excel seguem a mesma ordem. Os espaços dentro de uma chave são ignorados. Uma chave que não corresponda a uma destas formas devolve um erro que lista as formas válidas.

<Aside type="caution">
`>[-1]` e `>[0:-1]` significam algo diferente do que nas versões anteriores do PlaidXL, em que estavam invertidos. `>[-1]` devolve agora apenas as folhas e `>[0:-1]` tudo exceto as folhas. Reveja qualquer livro que tenha escrito uma chave de detalhe manualmente. As formas verbais `"all"`, `"leaves"` e `"2 levels"` não mudaram.
</Aside>

<Aside type="note">
`CELL`, `CELLS` e `DRILL` esperam o resultado destas funções de blocos de construção. Construa cada argumento com a respetiva função, em vez de escrever o texto por si.
</Aside>

## Inserir uma fórmula a partir do painel de tarefas

O separador **Formulas** do painel de tarefas escreve uma fórmula por si. Em **What do you want in the cell?**, escolha uma:

- **A whole table** (`GET_TABLE`) — escolha ou escreva a tabela e, opcionalmente, um número máximo de linhas.
- **One number** (`CELL`) — escolha ou escreva a tabela, escolha a **Column to total** e **How to combine the values**.
- **A list of dimension nodes** (`DRILL`) — escolha ou escreva a dimensão e o nó inicial, escolha **All levels**, **Lowest level only** ou **Down** um número de **levels** e, opcionalmente, uma **Alternate hierarchy**.

A pré-visualização de **Formula** mostra o resultado à medida que preenche os campos. Clique em **Insert in active cell** para a colocar na célula selecionada, ou em **Copy** para a colar por si. Escolher uma tabela no separador **Tables** ou uma dimensão no separador **Dimensions** preenche o campo correspondente.
