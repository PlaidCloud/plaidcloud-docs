O PlaidXL acrescenta ao Excel funções que leem dados do PlaidCloud diretamente para células. Escreva `=PLAIDXL.` numa célula e o preenchimento automático do Excel lista-as, com uma breve descrição de cada argumento. O separador **Formulas** do painel de tarefas também pode escrever uma por si; consulte [Inserir uma fórmula a partir do painel de tarefas](#inserir-uma-fórmula-a-partir-do-painel-de-tarefas).

| Grupo | Funções | Utilize-as para |
|---|---|---|
| Listas | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Ver o que está disponível para construir |
| Tabelas | [`TABLE.GET_TABLE`](#get_table) | Ler uma tabela inteira para um intervalo |
| Hierarquias | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Dispor os nós de uma dimensão como linhas de um relatório |
| Valores | [`CELL`](#cell), [`CELLS`](#cells) | Calcular um valor agregado para qualquer combinação de nós |
| Blocos de construção | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Descrever a tabela, o indicador, a agregação, os nós e a profundidade de detalhe que `CELL`, `CELLS` e `DRILL` utilizam |

[Criar um relatório com funções personalizadas](/pt-pt/reference/cli/plaidxl/build-a-report/) mostra estas funções a trabalhar em conjunto.

## Como funcionam as funções

- **Inicie primeiro a sessão.** As funções leem com o seu início de sessão no PlaidCloud, pelo que deve [iniciar sessão](/pt-pt/reference/cli/plaidxl/connect/) a partir do painel de tarefas antes de as utilizar.
- **Leem do projeto do livro.** Todas as funções leem do projeto associado ao livro no painel de tarefas. `GET_TABLE`, `TBL_LIST` e `DIM_LIST` também aceitam um ID de projeto opcional, para ler outro projeto sem alterar a associação. Cada livro tem o seu próprio projeto, pelo que dois livros abertos podem ler de projetos diferentes.
- **Os resultados expandem-se.** Uma função que devolve uma lista ou uma tabela preenche as células abaixo (ou à direita). Deixe espaço para os resultados; se algo estiver no caminho, o Excel mostra um erro `#SPILL!`.
- **Recalcule para obter as alterações.** Uma fórmula PlaidXL volta a obter os dados quando um dos seus argumentos muda. Para obter novos dados no PlaidCloud, ou um projeto diferente associado no painel de tarefas, force um recálculo completo — no Windows, prima **Ctrl+Alt+F9**. **Refresh All Tables** atualiza as tabelas obtidas, não as fórmulas.
- **Utilize os nomes exatos.** Escreva os nomes de tabelas, colunas, dimensões e nós exatamente como aparecem no PlaidCloud.

Os argumentos entre parênteses retos são opcionais.

## Listas

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Lista os nomes dos projetos que pode abrir, ordenados por nome.

- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição, `FALSE`, uma coluna.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Lista os nomes das tabelas de um projeto, ordenados por nome.

- `project_id` — o projeto a ler. Por predefinição, o projeto do livro.
- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição, `FALSE`, uma coluna.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Lista os nomes das colunas de uma tabela do projeto selecionado.

- `table_name` — o nome da tabela no PlaidCloud.
- `column_filter` — um tipo de dados, como `"text"`, para listar apenas as colunas desse tipo. Omita-o para listar todas as colunas.
- `orientation` — `"vertical"` (a predefinição) para uma coluna, ou `"horizontal"` para uma linha.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Lista os nomes das dimensões de um projeto.

- `project_id` — o projeto a ler. Por predefinição, o projeto do livro.
- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição, `FALSE`, uma coluna.

## Tabelas

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Devolve as linhas de uma tabela com uma linha de cabeçalho, expandidas a partir da célula da fórmula. Os valores vazios regressam como células em branco.

- `table_name` — o nome da tabela no PlaidCloud.
- `project_id` — o projeto a ler. Por predefinição, o projeto do livro.
- `limit` — o máximo de linhas a devolver. Por predefinição, 1 048 575, o máximo que uma folha de cálculo comporta abaixo de uma linha de cabeçalho.

`GET_TABLE` devolve todas as colunas. Para escolher colunas ou filtrar linhas, [obtenha antes a tabela a partir do painel de tarefas](/pt-pt/reference/cli/plaidxl/retrieve/#obter-uma-tabela).

## Hierarquias

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Dispõe os nós de uma dimensão, começando em `start_node` e descendo pelos respetivos descendentes. Cada geração tem um avanço de mais quatro espaços do que a geração superior, e os grupos de estrutura do Excel permitem recolher e expandir cada nível.

- `dimension_name` — o nome da dimensão ou o respetivo caminho no projeto.
- `start_node` — o nó a partir do qual começar, como a raiz da dimensão.
- `hierarchy` — a [hierarquia alternativa](/pt-pt/guides/dimensions/dimensions/#hierarquias-alternativas-de-atributos) a seguir. Por predefinição, `"main"`.
- `orientation` — `"vertical"` (a predefinição) para listar os nós ao longo de uma coluna, ou `"horizontal"` para os listar ao longo de uma linha.
- `generation_limit` — quantas gerações devolver, contando `start_node` como a primeira: `2` devolve o nó inicial e os respetivos filhos. Omita-o para devolver todas as gerações.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

Devolve `start_node` e os nós abaixo dele que `drill_key` pede, ao longo de uma coluna, com avanço por geração e agrupados numa estrutura do Excel.

- `dimension_name` — o nome da dimensão ou o respetivo caminho no projeto.
- `start_node` — o nó a partir do qual detalhar.
- `drill_key` — até onde detalhar, a partir de [`DRILL_KEY`](#drill_key): todos os descendentes, apenas as folhas, um número de níveis ou um intervalo de gerações.
- `hierarchy` — a hierarquia alternativa a seguir. Por predefinição, `"main"`.

Por exemplo, `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` lista **Total** seguido de todas as regiões folha abaixo dele.

Os [comandos de expansão do friso](/pt-pt/reference/cli/plaidxl/ribbon/#funções-de-detalhe) fazem o mesmo para uma dimensão e um nó que tenha escrito em duas células, sem escrever uma fórmula.

## Valores

`CELL` e `CELLS` calculam um indicador — uma coluna numérica de uma tabela — agregado pelos nós que escolher numa ou mais dimensões. Pense em cada chamada como uma interseção de um relatório: a **receita** de **EMEA** em **FY2026**.

Descreve a interseção com as funções de blocos de construção abaixo, normalmente nas suas próprias células, e depois passa essas células a `CELL` ou `CELLS` por qualquer ordem:

| Argumento | Criado com | Obrigatório |
|---|---|---|
| A tabela a ler | [`TABLE_REPR`](#table_repr) | Exatamente um |
| A coluna a agregar | [`MEASURE`](#measure) para `CELL`, [`MEASURES`](#measures) ou várias células `MEASURE` para `CELLS` | Sim |
| Como a agregar | [`MEASURE_TYPE`](#measure_type) | Não — a predefinição é `sum` |
| Um filtro numa coluna | [`DIMENSION_REPR`](#dimension_repr) | Pelo menos um, um por coluna |

Cada filtro indica uma **coluna da tabela** e um valor. Quando essa coluna está associada a uma dimensão no PlaidCloud, o valor é um nó e o filtro inclui tudo o que é agregado nesse nó na hierarquia principal da dimensão — numa coluna **Region** associada a uma dimensão geográfica, o nó **EMEA** abrange todos os países abaixo dele. Numa coluna que não está associada a uma dimensão, o filtro corresponde exatamente ao valor.

Os exemplos desta página utilizam uma tabela cujas colunas **Region** e **Period** estão associadas a dimensões. Utilize os nomes das colunas da sua própria tabela.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Devolve um número: o indicador, agregado pelas linhas que se encontram abaixo de todos os nós que passar.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` mostra a receita total de EMEA em FY2026.

Uma folha cheia de fórmulas `CELL` é recalculada rapidamente: quando um recálculo pede muitos valores da mesma tabela, o PlaidXL envia-os em conjunto para o PlaidCloud, em vez de um pedido por célula. Se não for possível calcular um valor, a célula mostra `#VALUE!` e, ao passar o rato por cima, mostra o motivo tal como o PlaidCloud o comunicou, como uma coluna de filtro que não está na tabela ou um nó sem membros. `CELLS` mostra o primeiro motivo para o resultado inteiro.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Como `CELL`, mas para vários indicadores de uma só vez. Devolve um número por indicador, ao longo de uma coluna, pela ordem em que os listou.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` passa o resultado expandido completo de `MEASURES`. `B2:B4` mostram a receita, o custo e as unidades de EMEA em FY2026.

## Blocos de construção

Estas funções não leem dados por si. Cada uma devolve um pequeno texto que descreve uma parte de um cálculo, pronto a passar a `CELL`, `CELLS` ou `DRILL`. Coloque-as em células que referencia, para que uma alteração — um período diferente, por exemplo — atualize todas as fórmulas que as utilizam.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

A tabela de onde `CELL` e `CELLS` leem, pelo respetivo nome no projeto selecionado.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

A coluna numérica que `CELL` agrega.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Várias colunas de indicadores para `CELLS`, a partir de um intervalo de células que contêm nomes de colunas. O resultado expande-se por uma célula por coluna; passe-o a `CELLS` com o operador de expansão, como `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Como agregar o indicador. `agg_function` é um dos seguintes, em minúsculas:

| Valor | Devolve |
|---|---|
| `sum` | O total (a predefinição quando não passa um tipo de indicador) |
| `mean` | A média |
| `median` | O valor central |
| `min` | O menor valor |
| `max` | O maior valor |
| `std` | O desvio-padrão |
| `var` | A variância |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

Um filtro para `CELL` e `CELLS`. Passe um por cada coluna que pretende filtrar.

- `dimension_name` — o nome de uma **coluna da tabela** — a coluna que contém os valores da dimensão, como `"Region"`. Tem de corresponder exatamente ao nome da coluna; uma coluna que não está na tabela devolve um erro.
- `start_node` — o nó até ao qual agregar, como `"EMEA"`. Numa coluna que não está associada a uma dimensão, o valor a corresponder.

Referencie uma célula para o nó, para criar uma grelha: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Os espaços iniciais e finais são ignorados, pelo que pode apontá-la para os nomes de nós com avanço que `DRILL` dispõe.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Até onde [`DRILL`](#drill) desce abaixo do respetivo nó inicial. `d_key` é texto simples, seja uma forma em palavras ou uma chave de detalhe escrita por extenso:

| `d_key` | Detalha até |
|---|---|
| `"all"` | Todos os descendentes |
| `"leaves"` | Apenas as folhas, que são os nós sem nada abaixo |
| `"1 level"`, `"2 levels"`, … | Essa quantidade de gerações abaixo |
| `">[...]"` | A chave de detalhe escrita por extenso, como na tabela seguinte |

Escreva o número em algarismos: `"2 levels"`, não `"two levels"`. Um `drill` inicial é ignorado, pelo que `"drill 2 levels"` também funciona.

Uma chave escrita por extenso conta as gerações abaixo do nó inicial, que é a geração 0 e está sempre incluído. Os números negativos contam a partir das folhas de cada ramo, pelo que uma hierarquia irregular funciona como seria de esperar.

| Chave | Inclui |
|---|---|
| `>[*]` ou `>[:]` | Todos os nós |
| `>[]` ou `>[-1]` | Apenas as folhas |
| `>[n]` | O nó inicial e `n` gerações abaixo dele. `>[0]` é apenas o nó inicial. |
| `>[a:]` | O nó inicial, depois a geração `a` e tudo o que está abaixo dela |
| `>[a:b]` | O nó inicial, depois as gerações de `a` até `b - 1` |
| `>[0:-k]` | O nó inicial e todos os nós que têm pelo menos `k` gerações abaixo, pelo que as últimas `k` gerações de cada ramo ficam de fora. `>[0:-1]` é todos os nós exceto as folhas. |
| `>[a:-k]` | O mesmo, começando na geração `a` |

Para a hierarquia `A`, com os filhos `B`, `C` e `D`, em que `B` tem `B1` e `B2` e `C` tem `C1`:

| Chave | Resultado |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Os nós são listados pela ordem da hierarquia, cada um sob o respetivo elemento superior, e os grupos de estrutura do Excel seguem a mesma ordem. Os espaços dentro de uma chave são ignorados. Uma chave que não corresponda a uma destas formas devolve um erro que lista as formas válidas.

<Aside type="caution">
`>[-1]` e `>[0:-1]` significam algo diferente nas versões anteriores do PlaidXL, em que estavam invertidos. `>[-1]` devolve agora apenas as folhas e `>[0:-1]` tudo exceto as folhas. Reveja qualquer livro que tenha escrito uma chave de detalhe manualmente. As formas em palavras `"all"`, `"leaves"` e `"2 levels"` não mudaram.
</Aside>

<Aside type="note">
`CELL`, `CELLS` e `DRILL` esperam o resultado destas funções de blocos de construção. Crie cada argumento com a respetiva função, em vez de escrever o texto você mesmo.
</Aside>

## Inserir uma fórmula a partir do painel de tarefas

O separador **Formulas** do painel de tarefas escreve uma fórmula por si. Em **What do you want in the cell?**, escolha uma:

- **A whole table** (`GET_TABLE`) — escolha ou escreva a tabela e, opcionalmente, um número máximo de linhas.
- **One number** (`CELL`) — escolha ou escreva a tabela, escolha **Column to total** e **How to combine the values**.
- **A list of dimension nodes** (`DRILL`) — escolha ou escreva a dimensão e o nó inicial, escolha **All levels**, **Lowest level only** ou **Down** um número de **levels** e, opcionalmente, uma **Alternate hierarchy**.

A pré-visualização de **Formula** mostra o resultado à medida que preenche os campos. Clique em **Insert in active cell** para o colocar na célula selecionada ou em **Copiar** para o colar você mesmo. Escolher uma tabela no separador **Tabelas** ou uma dimensão no separador **Dimensões** preenche o campo correspondente.
