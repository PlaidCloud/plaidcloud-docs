O PlaidXL acrescenta ao Excel funções que leem dados do PlaidCloud diretamente para as células. Escreva `=PLAIDXL.` numa célula e o preenchimento automático do Excel lista-as, com uma breve descrição de cada argumento. O separador **Formulas** do painel de tarefas também pode escrever uma por si; consulte [Inserir uma fórmula a partir do painel de tarefas](#inserir-uma-fórmula-a-partir-do-painel-de-tarefas).

| Grupo | Funções | Utilize-as para |
|---|---|---|
| Listas | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Ver o que está disponível para construir |
| Tabelas | [`TABLE.GET_TABLE`](#get_table) | Ler uma tabela inteira para um intervalo |
| Hierarquias | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Dispor os nós de uma dimensão como linhas de um relatório |
| Valores | [`CELL`](#cell), [`CELLS`](#cells) | Calcular um valor agregado para qualquer combinação de nós |
| Indicadores | [`METRIC`](#metric), [`METRIC_BREAKDOWN`](#metric_breakdown) | Ler um indicador de negócio governado, tal como os painéis de controlo o mostram |
| Blocos de construção | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Descrever a tabela, a medida, a agregação, os nós e a profundidade de detalhe que `CELL`, `CELLS` e `DRILL` utilizam |

[Criar um relatório](/pt-pt/reference/cli/plaidxl/build-a-report/) mostra-as a trabalhar em conjunto.

## Como funcionam as funções

- **Inicie sessão primeiro.** As funções leem com o seu início de sessão no PlaidCloud e as suas permissões, pelo que deve [iniciar sessão](/pt-pt/reference/cli/plaidxl/connect/) no painel de tarefas antes de as utilizar.
- **Leem do projeto do livro.** Cada função lê do projeto associado ao livro no painel de tarefas. `GET_TABLE`, `TBL_LIST` e `DIM_LIST` também aceitam um ID de projeto opcional, para ler outro projeto sem alterar a associação. Cada livro tem o seu próprio projeto, pelo que dois livros abertos podem ler de projetos diferentes.
- **Os resultados são distribuídos.** Uma função que devolve uma lista ou uma tabela preenche as células abaixo (ou à direita). Deixe espaço para os resultados; se algo estiver no caminho, o Excel mostra um erro `#SPILL!`.
- **Recalcule para obter as alterações.** Uma fórmula PlaidXL volta a obter dados quando um dos seus argumentos muda. Para obter novos dados no PlaidCloud, ou um projeto diferente associado no painel de tarefas, utilize o menu **Atualizar** da faixa de opções: **Recalculate PlaidXL formulas** recalcula todas as fórmulas PlaidXL do livro, e **Refresh this sheet** e **Refresh selection** recalculam as fórmulas que abrangem. **Refresh all tables** atualiza as tabelas obtidas, não as fórmulas. Consulte [Atualizar](/pt-pt/reference/cli/plaidxl/ribbon/#atualizar).
- **Utilize nomes exatos.** Escreva os nomes de tabelas, colunas, dimensões e nós exatamente como aparecem no PlaidCloud.

Os argumentos entre parênteses retos são opcionais.

## Listas

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Lista os nomes dos projetos que pode abrir, ordenados por nome.

- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição é `FALSE`, uma coluna.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Lista os nomes das tabelas de um projeto, ordenados por nome.

- `project_id` — o projeto a ler. Por predefinição é o projeto do livro.
- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição é `FALSE`, uma coluna.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Lista os nomes das colunas de uma tabela do projeto selecionado.

- `table_name` — o nome da tabela no PlaidCloud.
- `column_filter` — um tipo de dados, como `"text"`, para listar apenas as colunas desse tipo. Omita-o para listar todas as colunas.
- `orientation` — `"vertical"` (a predefinição) para uma coluna, ou `"horizontal"` para uma linha.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Lista os nomes das dimensões de um projeto.

- `project_id` — o projeto a ler. Por predefinição é o projeto do livro.
- `horizontal` — `TRUE` para listar ao longo de uma linha. Por predefinição é `FALSE`, uma coluna.

## Tabelas

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Devolve as linhas de uma tabela com uma linha de cabeçalho, distribuídas a partir da célula da fórmula. Os valores vazios voltam como células em branco.

- `table_name` — o nome da tabela no PlaidCloud.
- `project_id` — o projeto a ler. Por predefinição é o projeto do livro.
- `limit` — o número máximo de linhas a devolver. Por predefinição é 1 048 575, o máximo que uma folha de cálculo comporta abaixo de uma linha de cabeçalho.

`GET_TABLE` devolve todas as colunas. Para escolher colunas ou filtrar linhas, [obtenha antes a tabela a partir do painel de tarefas](/pt-pt/reference/cli/plaidxl/retrieve/#obter-uma-tabela).

## Hierarquias

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Dispõe os nós de uma dimensão, começando em `start_node` e descendo pelos seus descendentes. Cada geração tem um avanço de quatro espaços a mais do que o respetivo pai, e os grupos de esquema do Excel permitem reduzir e expandir cada nível.

- `dimension_name` — o nome da dimensão, ou o respetivo caminho no projeto.
- `start_node` — o nó a partir do qual começar, como a raiz da dimensão.
- `hierarchy` — a [hierarquia alternativa](/pt-pt/guides/dimensions/dimensions/#hierarquias-alternativas-de-atributos) a seguir. Por predefinição é `"main"`.
- `orientation` — `"vertical"` (a predefinição) para listar os nós ao longo de uma coluna, ou `"horizontal"` para os listar ao longo de uma linha.
- `generation_limit` — quantas gerações devolver, contando `start_node` como a primeira: `2` devolve o nó inicial e os seus filhos. Omita-o para devolver todas as gerações.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy], [exclude], [expand], [orientation])`

Devolve `start_node` e os nós abaixo dele que `drill_key` pede, com avanço por geração e agrupados num esquema do Excel.

- `dimension_name` — o nome da dimensão, ou o respetivo caminho no projeto.
- `start_node` — o nó a partir do qual detalhar. Deixe-o vazio (`""`) para começar nos nós de topo da dimensão.
- `drill_key` — até onde detalhar, a partir de [`DRILL_KEY`](#drill_key): todos os descendentes, apenas as folhas, um número de níveis ou um intervalo de gerações.
- `hierarchy` — a hierarquia alternativa a seguir. Por predefinição é `"main"`.
- `exclude` — nós a deixar de fora, com tudo o que está abaixo deles: um nó, uma lista ou um intervalo de células. O nó inicial nunca é deixado de fora.
- `expand` — nós cujos filhos devem também ser apresentados, mesmo abaixo da profundidade que `drill_key` pede: um nó, uma lista ou um intervalo de células. Só são abertos os nós que o detalhe mostra, pelo que, para abrir um neto, indique também o respetivo pai.
- `orientation` — `"vertical"` (a predefinição) para listar os nós ao longo de uma coluna, ou `"horizontal"` para os listar ao longo de uma linha, sem avanço e agrupados por coluna.

`exclude` e `expand` aceitam IDs de nós como texto ou números; as células vazias e os erros num intervalo são ignorados. Deixe um argumento vazio (`""`) para o ignorar, como em `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`.

Por exemplo, `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` lista **Total** seguido de todas as regiões folha abaixo dele.

Os [comandos de detalhe](/pt-pt/reference/cli/plaidxl/drill/) escrevem e editam fórmulas `DRILL` por si: selecione um nó e detalhe para baixo, detalhe para cima, mantenha ou remova nós.

## Valores

`CELL` e `CELLS` calculam uma medida — uma coluna numérica de uma tabela — agregada para os nós que escolher numa ou mais dimensões. Pense em cada chamada como uma interseção de um relatório: **Receita** de **EMEA** em **FY2026**.

Descreve-se a interseção com as funções de blocos de construção abaixo, normalmente nas suas próprias células, e depois passam-se essas células a `CELL` ou `CELLS` por qualquer ordem:

| Argumento | Construído com | Obrigatório |
|---|---|---|
| A tabela a ler | [`TABLE_REPR`](#table_repr) | Exatamente um |
| A coluna a agregar | [`MEASURE`](#measure) para `CELL`, [`MEASURES`](#measures) ou várias células `MEASURE` para `CELLS` | Sim |
| Como a agregar | [`MEASURE_TYPE`](#measure_type) | Não — por predefinição é `sum` |
| Um filtro numa coluna | [`DIMENSION_REPR`](#dimension_repr) | Pelo menos um, um por coluna |

Cada filtro indica uma **coluna da tabela** e um valor. Quando essa coluna está associada a uma dimensão no PlaidCloud, o valor é um nó, e o filtro inclui tudo o que é agregado nesse nó na hierarquia principal da dimensão, ou na hierarquia que indicar — numa coluna **Region** associada a uma dimensão de geografia, o nó **EMEA** abrange todos os países abaixo dele. Numa coluna que não está associada a uma dimensão, o filtro corresponde exatamente ao valor.

Os exemplos desta página utilizam uma tabela cujas colunas **Region** e **Period** estão associadas a dimensões. Utilize os nomes de coluna da sua própria tabela.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Devolve um número: a medida, agregada nas linhas que se encontram sob todos os nós que passar.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` mostra a receita total de EMEA em FY2026.

Escreva um número por cima de um `CELL` para o escrever no PlaidCloud. Consulte [Introduzir valores no PlaidCloud](/pt-pt/reference/cli/plaidxl/write-values/).

Uma folha cheia de fórmulas `CELL` calcula rapidamente: as fórmulas `CELL` que calculam em conjunto são enviadas ao PlaidCloud num só pedido, até 10 000 de cada vez, e o PlaidXL reutiliza os detalhes das colunas de uma tabela durante 30 segundos em vez de os obter para cada célula. Se um valor não puder ser calculado, a célula mostra `#VALUE!` e, ao passar o rato por cima, o motivo é apresentado tal como o PlaidCloud o comunicou, como uma coluna de filtro que não existe na tabela ou um nó sem membros. `CELLS` mostra o primeiro motivo para todo o resultado.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Como `CELL`, mas para várias medidas ao mesmo tempo. Devolve um número por medida, ao longo de uma coluna, pela ordem em que as listou.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` passa todo o resultado distribuído de `MEASURES`. `B2:B4` mostram a receita, o custo e as unidades de EMEA em FY2026.

## Indicadores

`METRIC` e `METRIC_BREAKDOWN` leem uma [definição de indicador](/pt-pt/integrations/ai-coding-agents/metric-definitions/) do projeto do livro: um número de negócio como *Net Revenue*, cujo cálculo está acordado e escrito no PlaidCloud. O valor é o que os painéis de controlo e o Weave mostram, calculado com o seu próprio acesso a linhas. **Metric...** na faixa de opções lista os indicadores do projeto com os respetivos valores atuais e escreve a fórmula por si; consulte [Inserir um indicador](#inserir-um-indicador).

Os filtros são valores de [`DIMENSION_REPR`](#dimension_repr), como em `CELL`, exceto que o primeiro argumento pode indicar tanto uma coluna pela qual o indicador pode ser repartido como a dimensão associada a ela. Um nó inclui tudo o que está abaixo dele. Passe um único filtro, ou um intervalo ou lista deles; os filtros vazios são ignorados. Uma fórmula pode utilizar uma hierarquia alternativa.

### METRIC

`=PLAIDXL.METRIC(name, [filter], ...)`

Devolve um número: o indicador, para as linhas sob todos os filtros que passar.

- `name` — o nome do indicador, um dos seus sinónimos ou o seu ID. A distinção entre maiúsculas e minúsculas não importa.
- `filter` — um filtro `DIMENSION_REPR`. Passe tantos quantos precisar.

```text
=PLAIDXL.METRIC("Net Revenue", PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA"))
```

Quando nenhuma linha corresponde, `METRIC` devolve `0`; quando o indicador não tem valor, a célula fica em branco.

### METRIC_BREAKDOWN

`=PLAIDXL.METRIC_BREAKDOWN(name, breakdown, [filter], ...)`

Devolve o indicador repartido por uma coluna: duas colunas, com cada membro de `breakdown` ao lado do seu valor, primeiro o valor mais elevado. Todos os membros são listados, sem linha de cabeçalho.

- `name` — o nome do indicador, um dos seus sinónimos ou o seu ID.
- `breakdown` — a coluna pela qual repartir o indicador, uma pela qual o indicador possa ser repartido.
- `filter` — um filtro `DIMENSION_REPR`. Passe tantos quantos precisar.

```text
=PLAIDXL.METRIC_BREAKDOWN("Net Revenue", "Region")
```

Os membros sem valor ficam em último, com um valor em branco. Quando nenhuma linha corresponde, devolve uma linha: um membro vazio e `0`.

### Erros de indicadores

Um indicador que não pode ser calculado mostra `#VALUE!`; passe o rato sobre a célula para ver o motivo:

| Mensagem | O que fazer |
|---|---|
| Indicador desconhecido ou coluna desconhecida | Verifique o nome. Quando existem correspondências próximas, a mensagem lista-as a seguir a **Did you mean**. |
| O nome corresponde a mais do que um indicador | Utilize o nome completo do indicador ou o respetivo ID. |
| **Your PlaidCloud role doesn't allow reading metrics in this project.** | Peça acesso a um proprietário do projeto. |
| **This PlaidCloud workspace doesn't serve metrics to Excel yet.** | Peça ao administrador que atualize a área de trabalho. |
| **PlaidCloud is busy; try again in** um número de segundos | O PlaidXL já tentou novamente. Recalcule após o tempo indicado. |
| **Choose a project in the PlaidXL pane first.** | Associe o livro a um projeto. |

## Blocos de construção

Estas funções não leem dados por si. Cada uma devolve um pequeno texto que descreve uma parte de um cálculo, pronto a passar a `CELL`, `CELLS` ou `DRILL`. Coloque-as em células que referencia, para que uma alteração — um período diferente, por exemplo — atualize todas as fórmulas que as utilizam.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

A tabela de onde `CELL` e `CELLS` leem, pelo respetivo nome no projeto selecionado.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

A coluna numérica que `CELL` agrega.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Várias colunas de medida para `CELLS`, a partir de um intervalo de células que contêm nomes de colunas. O resultado é distribuído numa célula por coluna; passe-o a `CELLS` com o operador de distribuição, como `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Como agregar a medida. `agg_function` é um destes valores, em minúsculas:

| Valor | Devolve |
|---|---|
| `sum` | O total (a predefinição quando não passa um tipo de medida) |
| `mean` | A média |
| `median` | O valor central |
| `min` | O menor valor |
| `max` | O maior valor |
| `std` | O desvio-padrão |
| `var` | A variância |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node, [hierarchy])`

Um filtro para `CELL`, `CELLS`, `METRIC` e `METRIC_BREAKDOWN`. Passe um para cada coluna pela qual pretende filtrar.

- `dimension_name` — o nome de uma **coluna da tabela** — a coluna que contém os valores da dimensão, como `"Region"`. Tem de corresponder exatamente ao nome da coluna; uma coluna que não existe na tabela devolve um erro.
- `start_node` — o nó até ao qual agregar, como `"EMEA"`. Numa coluna que não está associada a uma dimensão, o valor a corresponder.
- `hierarchy` — a hierarquia alternativa através da qual agregar o nó. Por predefinição é `"main"`.

Referencie uma célula para o nó para construir uma grelha: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Os espaços iniciais e finais são ignorados, pelo que pode apontar para os nomes de nós com avanço que o `DRILL` dispõe.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Até onde o [`DRILL`](#drill) vai abaixo do seu nó inicial. `d_key` é texto simples, seja uma forma em palavras ou uma chave de detalhe escrita por extenso:

| `d_key` | Detalha até |
|---|---|
| `"all"` | Todos os descendentes |
| `"leaves"` | Apenas as folhas, que são os nós sem nada abaixo |
| `"1 level"`, `"2 levels"`, … | Esse número de gerações para baixo |
| `">[...]"` | A chave de detalhe escrita por extenso, como na tabela seguinte |

Escreva o número em algarismos: `"2 levels"`, não `"two levels"`. Um `drill` inicial é ignorado, pelo que `"drill 2 levels"` também funciona.

Uma chave escrita por extenso conta as gerações para baixo a partir do nó inicial, que é a geração 0 e é sempre incluído. Os números negativos contam para cima a partir das folhas de cada ramo, pelo que uma hierarquia irregular funciona como seria de esperar.

| Chave | Inclui |
|---|---|
| `>[*]` ou `>[:]` | Todos os nós |
| `>[]` ou `>[-1]` | Apenas as folhas |
| `>[n]` | O nó inicial e `n` gerações abaixo dele. `>[0]` é apenas o nó inicial. |
| `>[a:]` | O nó inicial, depois a geração `a` e tudo o que está abaixo |
| `>[a:b]` | O nó inicial, depois as gerações de `a` até `b - 1` |
| `>[0:-k]` | O nó inicial e todos os nós que têm pelo menos `k` gerações abaixo, pelo que as últimas `k` gerações de cada ramo ficam de fora. `>[0:-1]` é todos os nós exceto as folhas. |
| `>[a:-k]` | O mesmo, a começar na geração `a` |

Para a hierarquia `A`, com os filhos `B`, `C` e `D`, em que `B` tem `B1` e `B2` e `C` tem `C1`:

| Chave | Resultado |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Os nós são listados pela ordem da hierarquia, cada um sob o seu próprio pai, e os grupos de esquema do Excel seguem a mesma ordem. Os espaços dentro de uma chave são ignorados. Uma chave que não corresponda a nenhuma destas formas devolve um erro que lista as formas válidas.

<Aside type="caution">
`>[-1]` e `>[0:-1]` significam algo diferente das versões anteriores do PlaidXL, em que estavam invertidos. `>[-1]` devolve agora apenas as folhas, e `>[0:-1]` tudo exceto as folhas. Reveja qualquer livro que tenha escrito uma chave de detalhe por extenso manualmente. As formas em palavras `"all"`, `"leaves"` e `"2 levels"` não mudaram.
</Aside>

<Aside type="note">
`CELL`, `CELLS` e `DRILL` esperam o resultado destas funções de blocos de construção. Construa cada argumento com a respetiva função em vez de escrever o texto por si.
</Aside>

## Inserir uma fórmula a partir do painel de tarefas

O separador **Formulas** do painel de tarefas escreve uma fórmula por si. Abra-o a partir do painel de tarefas, com **Formula...** na faixa de opções, ou com **Insert formula here...** no menu de contexto **PlaidXL**. Em **What do you want in the cell?**, escolha uma:

- **A whole table** (`GET_TABLE`) — escolha ou escreva a tabela e, opcionalmente, um número máximo de linhas.
- **One number** (`CELL`) — escolha ou escreva a tabela, escolha a **Column to total** e **How to combine the values**.
- **A list of dimension nodes** (`DRILL`) — escolha ou escreva a dimensão e o nó inicial, escolha até onde detalhar e, opcionalmente, uma **Hierarquia alternativa (opcional)**, nós a excluir e nós a abrir. **Linhas** pré-visualiza os nós que o detalhe lista. Consulte [Detalhe personalizado](/pt-pt/reference/cli/plaidxl/drill/#detalhe-personalizado).
- **A business metric** (`METRIC`) — consulte [Inserir um indicador](#inserir-um-indicador).

A pré-visualização da **Formula** mostra o resultado à medida que preenche os campos. Clique em **Insert in active cell** (ou prima **Ctrl+Enter**) para o colocar na célula selecionada, ou em **Copiar** para o colar por si. Escolher uma tabela no separador **Tabelas** ou uma dimensão no separador **Dimensões** preenche o campo correspondente.

### Inserir um indicador

Clique em **Metric...** no grupo **Inserir** da faixa de opções, ou escolha **A business metric** no separador **Formulas**.

1. Em **Metric**, escreva parte do nome ou de um sinónimo de um indicador, como `revenue`. Cada correspondência mostra o respetivo valor atual e descrição.
2. Utilize as teclas de seta ou clique para escolher um indicador.
3. Opcionalmente, acrescente filtros: escolha uma **Dimensão**, escreva um **Nó** e clique em **Adicionar filtro**.
4. Opcionalmente, escolha uma coluna em **Breakdown by (optional)** para escrever `METRIC_BREAKDOWN` em vez de um único número.
5. Clique em **Insert in active cell** ou em **Copiar**.
