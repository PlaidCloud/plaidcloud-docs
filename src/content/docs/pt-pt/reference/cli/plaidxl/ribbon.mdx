A instalação do PlaidXL acrescenta um separador **PlaidCloud** à faixa de opções do Excel, com seis grupos de comandos: **Ligar**, **Inserir**, **Atualizar**, **Drill**, **Escrita** e **Partilhar**. Os mais comuns também estão no menu de contexto **PlaidXL** e no separador **PlaidXL Cell**, e todos os comandos que têm um atalho de teclado mostram-no na respetiva dica.

Nenhum comando fica alguma vez a cinzento. Um comando atua sobre a fórmula, tabela ou nó do PlaidXL mais próximo da célula selecionada e, quando não há nada sobre que atuar, abre em vez disso a parte do painel de tarefas que ajuda.

Se executar um comando enquanto tem a sessão terminada, ou antes de o livro estar associado a um projeto, o PlaidXL abre o painel de tarefas e indica **Sign in to run** o comando, ou **Pick a project to run** o comando. Depois de entrar, o comando é executado na célula a partir da qual começou. Se entretanto mudou para outra folha ou escolheu outro projeto, não é executado e o PlaidXL informa-o disso.

## Ligar

| Comando | O que faz |
|---|---|
| **Open PlaidXL** | Abre o painel de tarefas do PlaidXL. |
| **Conta** | Abre o painel de tarefas para iniciar sessão, ou para escolher a sua área de trabalho e o seu projeto. |
| **Shortcuts** | Lista os atalhos de teclado do PlaidXL para que possa alterá-los. Consulte [Atalhos de teclado](#atalhos-de-teclado). |
| **Help** | Abre esta documentação. |

## Inserir

| Comando | O que faz |
|---|---|
| **Tabela...** | Abre o separador **Tabelas** para [obter uma tabela](/pt-pt/reference/cli/plaidxl/retrieve/#obter-uma-tabela). |
| **Dimensão...** | Abre o separador **Dimensões** para obter uma dimensão ou escolher os respetivos membros. |
| **Formula...** | Abre o separador **Formulas** para [criar uma fórmula PlaidXL](/pt-pt/reference/cli/plaidxl/functions/#inserir-uma-fórmula-a-partir-do-painel-de-tarefas) para a célula selecionada. |
| **Pick member...** | Abre o seletor de membros na dimensão da célula selecionada. Consulte [Escolher um membro](/pt-pt/reference/cli/plaidxl/drill/#escolher-um-membro). |
| **Metric...** | Abre uma lista pesquisável dos indicadores do seu projeto, com os respetivos valores atuais. Consulte [Inserir um indicador](/pt-pt/reference/cli/plaidxl/functions/#inserir-um-indicador). |
| **Build report...** | Abre o separador **Relatório** para estruturar um relatório em direto. Consulte [Criar um relatório](/pt-pt/reference/cli/plaidxl/build-a-report/). |
| **Perguntar ao Weave...** | Abre o separador **Weave** com a célula selecionada como contexto. Consulte [Perguntar ao Weave no Excel](/pt-pt/reference/cli/plaidxl/weave/). |

## Atualizar

O menu **Atualizar** contém quatro comandos:

| Comando | O que faz |
|---|---|
| **Refresh this sheet** | Recalcula as fórmulas PlaidXL da folha ativa e volta a obter as respetivas tabelas. |
| **Refresh selection** | Recalcula as fórmulas PlaidXL da seleção e volta a obter qualquer tabela que a seleção toque. Se nada do PlaidXL estiver selecionado, atualiza a folha. |
| **Refresh all tables** | Volta a obter todas as tabelas e dimensões do livro, com as colunas e o filtro que escolheu para cada uma. |
| **Recalculate PlaidXL formulas** | Recalcula todas as fórmulas PlaidXL do livro. |

Consulte [Atualizar tabelas](/pt-pt/reference/cli/plaidxl/retrieve/#refresh-all-tables) para ver o que aparece enquanto uma atualização decorre.

**Recalculate PlaidXL formulas** recalcula apenas as fórmulas PlaidXL, sem um recálculo completo do Excel. Quando termina, lista as folhas que recalculou e limpa o histórico de anulação do Excel. O PlaidXL mantém os detalhes das colunas de uma tabela durante 30 segundos, pelo que uma coluna ou dimensão cujo nome tenha mudado nos últimos 30 segundos pode demorar um pouco mais a aparecer.

## Drill

| Comando | O que faz |
|---|---|
| **Drill down** | Um menu: **One level**, **To lowest level**, **All levels** e **Custom drill...** dispõem os nós abaixo do nó selecionado. |
| **Drill up** | Reduz o nó selecionado de volta ao respetivo pai. |
| **Keep only** | Mantém apenas os nós selecionados no detalhe. |
| **Remove only** | Remove do detalhe os nós selecionados e tudo o que está abaixo deles. |
| **Show detail rows** | Coloca as linhas da tabela por trás do valor selecionado numa folha própria. |
| **Explicar este número** | Mostra de onde vem o valor selecionado. |

Selecione uma única célula para detalhar: os comandos de detalhe transformam-na numa fórmula `PLAIDXL.DRILL` em direto. Consulte [Detalhar, escolher membros e explicar números](/pt-pt/reference/cli/plaidxl/drill/).

## Escrita

| Comando | O que faz |
|---|---|
| **Save sheet to PlaidCloud...** | Escreve de volta no PlaidCloud, de imediato, as tabelas obtidas para esta folha. Consulte [Guardar uma tabela no PlaidCloud](/pt-pt/reference/cli/plaidxl/retrieve/#guardar-uma-tabela-no-plaidcloud). |
| **Undo last write** | Anula o último valor que escreveu no PlaidCloud ou a última gravação, a mais recente primeiro. Consulte [Anular uma escrita](/pt-pt/reference/cli/plaidxl/write-values/#anular-uma-escrita). |

## Partilhar

| Comando | O que faz |
|---|---|
| **Convert to values** | Um menu: **Whole workbook** ou **This sheet** substitui as fórmulas PlaidXL pelos respetivos valores atuais e memoriza as fórmulas. **Values only (no restore)** substitui-as sem guardar forma de voltar atrás. |
| **Restore PlaidXL formulas** | Repõe as fórmulas que **Convert to values** substituiu, em todas as folhas do livro. |

Utilize **Convert to values** para enviar um relatório a alguém que não tem o PlaidXL nem acesso ao projeto — de outro modo, veria erros onde estão as fórmulas PlaidXL. Converte todas as fórmulas que chamam uma função PlaidXL, incluindo uma que esteja dentro de outra fórmula, como `IFERROR`, e deixa as suas outras fórmulas como estão. É executado de imediato, sem perguntar antes, e indica quantas fórmulas converteu.

As fórmulas são guardadas com cada folha, pelo que **Restore PlaidXL formulas** continua a encontrá-las depois de mudar o nome ou mover uma folha. Não é necessário ter a sessão iniciada. Consulte [Partilhar uma cópia só com valores](/pt-pt/reference/cli/plaidxl/build-a-report/#partilhar-uma-cópia-só-com-valores).

<Aside type="caution">
Converta uma cópia guardada com outro nome e mantenha o seu relatório de trabalho como está. **Values only (no restore)** não pode ser anulado com **Restore PlaidXL formulas**.
</Aside>

## O menu de contexto

Clique com o botão direito do rato numa célula e escolha **PlaidXL** para estes comandos, cada um igual ao respetivo botão da faixa de opções:

- **Drill down one level**, **Drill down to lowest level**, **Drill down all levels**, **Custom drill...**, **Drill up**, **Keep only** e **Remove only**
- **Pick member...**
- **Explicar este número** e **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...**, que abre o separador **Formulas** para a célula

## O separador PlaidXL Cell

Quando a célula selecionada contém uma fórmula PlaidXL, faz parte dos resultados de uma fórmula PlaidXL ou está dentro de uma tabela obtida, o Excel mostra um separador **PlaidXL Cell** ao lado do separador **PlaidCloud**. Reúne os comandos dessa célula:

- **Drill** — **Drill down** (**One level**, **Lowest level**, **All levels**), **Drill up**, **Keep only** e **Remover**
- **Inspecionar** — **Explicar**, **Detail rows** e **Perguntar ao Weave**
- **Dados** — **Pick member**, **Refresh selection** e **Save sheet**

O separador volta a ocultar-se quando seleciona outra célula. As versões do Excel que não suportam separadores contextuais de suplementos não o mostram; todos os comandos continuam no separador **PlaidCloud**.

## Atalhos de teclado

Todos os atalhos são **Ctrl+Alt+Shift** e uma tecla no Windows, ou **⌘⌥⇧** e a mesma tecla no Mac:

| Tecla | Comando |
|---|---|
| **Descer** | Drill down one level |
| **Subir** | Drill up |
| **L** | Drill down to lowest level |
| **8** | Drill down all levels |
| **D** | Custom drill |
| **K** | Keep only |
| **X** | Remove only |
| **M** | Pick member |
| **E** | Explicar este número |
| **T** | Show detail rows |
| **R** | Refresh this sheet |
| **F** | Refresh selection |
| **A** | Refresh all tables |
| **C** | Recalculate PlaidXL formulas |
| **W** | Save sheet to PlaidCloud |
| **Z** | Undo last write |
| **P** | Open PlaidXL |
| **N** | Insert a formula |
| **B** | Build report |
| **I** | Insert a metric |
| **Q** | Perguntar ao Weave |

Para alterar um, clique em **Shortcuts** no grupo **Ligar**, ou escolha **Keyboard shortcuts** no menu da conta no painel de tarefas. Clique em **Set key** junto a um comando, prima a nova combinação e clique em **Guardar**; **Repor** repõe o original. Uma combinação que outro comando já utilize é assinalada, e guardá-la mesmo assim entra em vigor. Algumas versões do Office não permitem que os suplementos alterem atalhos, e mostram a lista sem **Set key**.
