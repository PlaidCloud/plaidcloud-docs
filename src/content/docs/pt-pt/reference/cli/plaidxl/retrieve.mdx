Depois de [iniciar sessão](/pt-pt/reference/cli/plaidxl/connect/), o painel de tarefas lista os seus projetos. Escolhe-se um projeto e, em seguida, obtêm-se as respetivas tabelas e dimensões para o livro.

## Escolher um projeto

A secção **Projeto** lista todos os projetos que pode abrir, nas mesmas pastas que vê no PlaidCloud. As pastas começam recolhidas; clique numa para a abrir ou escreva em **Filter projects by name** para reduzir a lista.

Clique num projeto para o selecionar. As respetivas tabelas aparecem no separador **Tabelas** e as dimensões no separador **Dimensões**.

O projeto selecionado é também aquele de que as [funções personalizadas](/pt-pt/reference/cli/plaidxl/functions/) e os comandos de pormenorização do PlaidXL leem. A seleção aplica-se a todos os livros que tenha abertos, não apenas a este.

### Definir um projeto predefinido

Para que um livro selecione sempre o mesmo projeto quando abre o respetivo painel de tarefas, selecione o projeto e clique em **Definir como predefinição**. A predefinição fica guardada no livro, pelo que acompanha o ficheiro até quem o abrir. **Clear Default** remove-a.

## Obter uma tabela

1. No separador **Tabelas**, clique numa tabela. Utilize **Filter tables by name** para a encontrar numa lista longa. As **Linhas** e as **Colunas** junto a cada tabela indicam a sua dimensão.
2. Em **Coluna**, desmarque a caixa de qualquer coluna de que não precise. Todas as colunas começam selecionadas.
3. Para obter apenas algumas linhas, selecione **Avançado** e crie um filtro. Consulte [Filtrar linhas](#filtrar-linhas).
4. Em **Select where to place this table**, escolha:
   - **Matching Worksheet** — uma folha de cálculo com o nome da tabela. O PlaidXL cria a folha se não existir e, se existir, escreve a tabela a partir da célula A1.
   - **Current Selection** — a partir da célula que selecionou na folha ativa.
5. Clique em **Retrieve Table**.

Os dados chegam com uma linha de cabeçalho, prontos a utilizar. A linha de cabeçalho está a negrito e sombreada, as colunas são dimensionadas para se ajustarem e os filtros ficam ativados. Uma tabela obtida para **Matching Worksheet** recebe também:

- Uma linha de cabeçalho fixa, para que permaneça visível ao deslocar-se.
- Um intervalo com nome sobre os dados, para que as fórmulas que o utilizam acompanhem o crescimento dos dados na atualização. O nome é o nome da folha de cálculo com um sublinhado à frente: uma tabela com o nome **Sample data** fica na folha `Sample_data`, com o intervalo com nome `_Sample_data`.

Para dar nome à folha de cálculo, o PlaidXL reduz o nome da tabela ao limite de 31 carateres do Excel, mantém apenas letras simples (A–Z), números e espaços, e converte os espaços em sublinhados. Uma tabela com o nome **Q3 Revenue (EMEA)** é obtida para a folha `Q3_Revenue_EMEA`. Os sublinhados e as letras acentuadas também são eliminados, pelo que **sales_2024** é obtida para a folha `sales2024`.

<Aside type="tip">As tabelas largas demoram a carregar no Excel. Desmarcar as colunas de que não precisa é a forma mais rápida de acelerar uma obtenção grande.</Aside>

### Tabelas apresentadas a vermelho

Uma tabela aparece a vermelho quando é demasiado grande para uma folha de cálculo — mais de 1 048 576 linhas ou 16 384 colunas — ou quando o PlaidCloud não consegue indicar o seu tamanho, como acontece com uma tabela que nunca foi carregada. Filtre as linhas com **Avançado** e desmarque colunas até caber. O PlaidXL obtém no máximo 1 048 575 linhas mais a linha de cabeçalho e para aí, sem aviso.

## Filtrar linhas

Selecione **Avançado** para abrir o construtor de filtros. Cada regra escolhe uma coluna, uma comparação como **Igual a**, **em**, **contém**, **Começa por** ou **está vazio**, e um valor. Utilize grupos **AND**, grupos **OR** ou ambos para combinar regras.

O filtro compara os valores como texto, pelo que corresponde a valores exatos e a padrões de texto. Não estão disponíveis intervalos de números ou datas; para obter um intervalo, filtre pelos valores de que precisa com **em** ou obtenha a tabela e filtre-a no Excel.

- Escreva os valores sem aspas: `EMEA`, não `"EMEA"`.
- Numa comparação que aceita vários valores, como **em**, separe os valores com uma vírgula e um espaço: `EMEA, APAC, NA`.

O filtro só se aplica enquanto **Avançado** estiver selecionado. O PlaidXL memoriza o filtro e as colunas que escolheu para cada tabela obtida e volta a utilizá-los quando atualiza.

## Refresh All Tables

**Refresh All Tables** — no painel de tarefas ou no friso, em **PlaidCloud → PlaidXL Controls** — obtém os dados atuais do PlaidCloud para todas as tabelas que obteve para o livro, com as colunas e o filtro que escolheu para cada uma.

Enquanto decorre, o separador da folha de cada tabela fica amarelo. Fica verde quando essa tabela está atualizada. As fórmulas que usam os dados voltam a calcular-se como habitualmente; atualize as tabelas dinâmicas criadas sobre eles com **Data → Refresh All** do Excel.

O PlaidXL guarda no livro a lista das tabelas obtidas, pelo que **Refresh All Tables** funciona para qualquer pessoa que abra o ficheiro e inicie sessão com acesso aos mesmos projetos.

Cada **Retrieve Table** adiciona a tabela à lista de atualização e não há forma de remover uma. Obtenha cada tabela uma vez e depois utilize **Refresh All Tables** para a atualizar — obter a mesma tabela outra vez faz com que cada atualização a obtenha duas vezes.

<Aside type="caution">
Uma tabela obtida para **Current Selection** é atualizada nas mesmas células da **folha que estiver ativa** quando clica em **Refresh All Tables**, substituindo o que lá estiver. Obtenha para **Matching Worksheet** as tabelas que pretende atualizar; estas são sempre atualizadas na sua própria folha.

Uma atualização escreve por cima dos dados antigos sem os limpar primeiro. Se uma tabela tiver agora menos linhas ou colunas do que antes, as linhas ou colunas a mais da obtenção anterior permanecem na folha. Limpe o conteúdo da folha antes de atualizar uma tabela que possa ter diminuído.
</Aside>

## Obter uma dimensão

O separador **Dimensões** lista as [dimensões](/pt-pt/guides/dimensions/dimensions/) do projeto.

1. Clique numa dimensão. Utilize **Filter dimensions by name** para a encontrar.
2. Em **Select where to place this dimension**, escolha **Matching Worksheet** ou **Current Selection**.
3. Clique em **Retrieve Dimension**.

O PlaidXL escreve os nós da dimensão numa só coluna, pela ordem da hierarquia. As dimensões não têm filtros de colunas nem de linhas, e **Refresh All Tables** não as atualiza — obtenha a dimensão novamente para receber as alterações.

Para dispor uma hierarquia com indentação e agrupamento em estrutura do Excel, ou para começar a partir de um nó específico ou de uma hierarquia alternativa, utilize antes [`PLAIDXL.DIMENSION.GET_DIMENSION`](/pt-pt/reference/cli/plaidxl/functions/#get_dimension) ou os [comandos de pormenorização](/pt-pt/reference/cli/plaidxl/ribbon/#drill-functions).

## Alterar dados

O PlaidXL lê do PlaidCloud e nunca escreve de volta. Pode editar, ordenar e adicionar fórmulas a uma folha obtida livremente, sem que nada no projeto se altere. Uma atualização escreve os dados atuais do PlaidCloud por cima do intervalo da tabela, por isso mantenha os seus próprios cálculos numa folha separada.

Para alterar os próprios dados, atualize-os no PlaidCloud — por exemplo, com um [fluxo de trabalho](/pt-pt/guides/workflows/) ou o [Editor de dados](/pt-pt/guides/projects/managing-data-editors/).
