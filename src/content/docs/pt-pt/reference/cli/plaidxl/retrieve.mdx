Depois de [iniciar sessão](/pt-pt/reference/cli/plaidxl/connect/), o painel de tarefas lista os seus projetos. Escolhe um projeto e, em seguida, obtém as respetivas tabelas e dimensões para o livro.

## Escolher um projeto

O cabeçalho do painel de tarefas mostra a sua área de trabalho e o projeto a que este livro está ligado. Clique no nome do projeto para abrir a lista de projetos, que mostra todos os projetos que pode abrir, nas mesmas pastas que vê no PlaidCloud. As pastas começam recolhidas; clique numa para a abrir ou escreva em **Filter projects by name** para reduzir a lista.

Clique num projeto para o selecionar. As suas tabelas aparecem no separador **Tables** e as suas dimensões no separador **Dimensions**.

### O projeto pertence ao livro

O projeto selecionado é guardado no livro, pelo que cada livro tem o seu próprio projeto. É o projeto de onde as [funções personalizadas](/pt-pt/reference/cli/plaidxl/functions/) e os comandos de detalhe do PlaidXL leem nesse livro. Se abrir dois livros, cada um lê do seu próprio projeto e, quando volta a abrir um livro, o painel de tarefas regressa ao respetivo projeto. O projeto acompanha o ficheiro para quem o abrir e iniciar sessão com acesso a ele.

Um projeto pertence a uma área de trabalho. Se [mudar de área de trabalho](/pt-pt/reference/cli/plaidxl/connect/#terminar-sessão-ou-mudar-de-área-de-trabalho), um livro ligado a um projeto da área de trabalho anterior fica sem projeto até escolher um. As tabelas que obteve da área de trabalho anterior permanecem no livro, mas são ignoradas por **Refresh All Tables**, e o painel de tarefas indica quantas são. Obtenha-as novamente na nova área de trabalho para as ligar.

## Obter uma tabela

1. No separador **Tables**, clique numa tabela. Utilize **Filter tables by name** para a encontrar numa lista longa. Os valores de **Rows** e **Columns** junto a cada tabela indicam a sua dimensão.
2. Em **Column**, desmarque a caixa de seleção de qualquer coluna de que não precise. Todas as colunas começam selecionadas.
3. Para obter apenas algumas linhas, selecione **Advanced** e crie um filtro. Consulte [Filtrar linhas](#filtrar-linhas).
4. Em **Select where to place this table**, escolha:
   - **Matching Worksheet** — uma folha de cálculo com o nome da tabela. O PlaidXL cria a folha se não existir e, se existir, escreve a tabela a partir da célula A1.
   - **Current Selection** — a partir da célula que selecionou na folha ativa.
5. Clique em **Retrieve Table**.

Os dados chegam com uma linha de cabeçalho, prontos a utilizar. A linha de cabeçalho está a negrito e sombreada, as colunas são ajustadas ao conteúdo e os filtros ficam ativados. Uma tabela obtida para **Matching Worksheet** recebe ainda:

- Uma linha de cabeçalho fixa, para que se mantenha visível ao deslocar.
- Um intervalo com nome sobre os dados, para que as fórmulas que o utilizam acompanhem os dados à medida que crescem na atualização. O seu nome é o nome da folha de cálculo com um sublinhado à frente: uma tabela chamada **Sample data** fica na folha `Sample_data`, com o intervalo com nome `_Sample_data`.

Para dar nome à folha de cálculo, o PlaidXL corta o nome da tabela para o limite do Excel de 31 carateres, mantém apenas letras simples (A–Z), números e espaços, e converte os espaços em sublinhados. Uma tabela chamada **Q3 Revenue (EMEA)** é obtida para a folha `Q3_Revenue_EMEA`. Os sublinhados e as letras acentuadas também são eliminados, pelo que **sales_2024** é obtida para a folha `sales2024`.

<Aside type="tip">As tabelas largas demoram a carregar no Excel. Desmarcar as colunas de que não precisa é a forma mais rápida de acelerar uma obtenção grande.</Aside>

### Tabelas apresentadas a vermelho

Uma tabela aparece a vermelho quando é demasiado grande para uma folha de cálculo — mais de 1 048 576 linhas ou 16 384 colunas — ou quando o PlaidCloud não consegue comunicar a sua dimensão, como numa tabela que nunca foi carregada. Filtre as linhas com **Advanced** e desmarque colunas até caber. O PlaidXL obtém no máximo 1 048 575 linhas mais a linha de cabeçalho e pára aí, sem aviso.

## Filtrar linhas

Selecione **Advanced** para abrir o construtor de filtros. Cada regra escolhe uma coluna, uma comparação como **igual a**, **em**, **contém**, **começa por** ou **está vazio**, e um valor. Utilize grupos **AND**, grupos **OR**, ou ambos, para combinar regras.

O filtro compara valores como texto, pelo que corresponde a valores exatos e a padrões de texto. Os intervalos de números ou datas não estão disponíveis; para obter um intervalo, filtre pelos valores de que precisa com **em**, ou obtenha a tabela e filtre-a no Excel.

- Escreva os valores sem aspas: `EMEA`, não `"EMEA"`.
- Numa comparação que aceita vários valores, como **em**, separe os valores com uma vírgula e um espaço: `EMEA, APAC, NA`.

O filtro só se aplica enquanto **Advanced** estiver selecionado. O PlaidXL memoriza o filtro e as colunas que escolheu com cada tabela obtida e volta a utilizá-los quando atualiza.

## Refresh All Tables

**Refresh All Tables** — no painel de tarefas, ou no friso em **PlaidCloud → Data** — obtém os dados atuais do PlaidCloud para todas as tabelas que obteve para o livro, com as colunas e o filtro que escolheu para cada uma.

Enquanto decorre, o separador da folha de cálculo de cada tabela fica amarelo. Fica verde quando essa tabela está atualizada. As fórmulas que utilizam os dados são recalculadas como habitualmente; atualize as tabelas dinâmicas criadas com base neles com **Dados → Atualizar Tudo** do Excel.

O PlaidXL guarda no livro a lista das tabelas obtidas, pelo que **Refresh All Tables** funciona para qualquer pessoa que abra o ficheiro e inicie sessão com acesso aos mesmos projetos.

Cada **Retrieve Table** acrescenta a tabela à lista de atualização e não há forma de remover uma. Obtenha cada tabela uma vez e depois utilize **Refresh All Tables** para a atualizar — obter a mesma tabela novamente faz com que cada atualização a obtenha duas vezes.

<Aside type="caution">
Uma tabela obtida para **Current Selection** é atualizada nas mesmas células da **folha que estiver ativa** quando clica em **Refresh All Tables**, substituindo o que lá está. Obtenha para **Matching Worksheet** as tabelas que pretende atualizar; estas são sempre atualizadas na sua própria folha.

Uma atualização escreve por cima dos dados antigos sem os limpar primeiro. Se uma tabela tiver agora menos linhas ou colunas do que antes, as linhas ou colunas a mais da obtenção anterior permanecem na folha. Limpe o conteúdo da folha antes de atualizar uma tabela que possa ter diminuído.
</Aside>

## Obter uma dimensão

O separador **Dimensions** lista as [dimensões](/pt-pt/guides/dimensions/dimensions/) do projeto.

1. Clique numa dimensão. Utilize **Filter dimensions by name** para a encontrar.
2. Em **Select where to place this dimension**, escolha **Matching Worksheet** ou **Current Selection**.
3. Clique em **Retrieve Dimension**.

O PlaidXL escreve os nós da dimensão numa coluna, pela ordem da hierarquia. As dimensões não têm filtros de colunas nem de linhas, e **Refresh All Tables** não as atualiza — obtenha a dimensão novamente para obter as alterações.

Para dispor uma hierarquia com avanço e agrupamento em destaque do Excel, ou para começar a partir de um nó ou de uma hierarquia alternativa específicos, utilize antes [`PLAIDXL.DIMENSION.GET_DIMENSION`](/pt-pt/reference/cli/plaidxl/functions/#get_dimension) ou os [comandos de detalhe](/pt-pt/reference/cli/plaidxl/ribbon/#drill-functions).

## Guardar uma tabela no PlaidCloud

Uma tabela que obteve para o livro pode ser guardada de volta, substituindo a tabela do PlaidCloud pelo que está na folha.

1. Vá para a folha de cálculo que contém a tabela obtida. Em **Save this sheet to PlaidCloud**, o painel de tarefas lista cada tabela ligada à folha ativa, com o respetivo número de linhas. Se a folha não tiver nenhuma, o painel indica que deve primeiro obter lá uma tabela.
2. Clique em **Save to PlaidCloud…** junto à tabela.
3. Leia a confirmação, que mostra a tabela, o número de linhas a escrever e as colunas, e clique em **Replace table**.

O PlaidXL lê a linha de cabeçalho e as linhas abaixo dela a partir do local para onde a tabela foi obtida. O cabeçalho tem de continuar a corresponder às colunas que obteve, e os valores são convertidos para o tipo de dados de cada coluna. Se um valor não puder ser convertido, nada é escrito e são listadas as linhas que falharam. As definições das colunas no PlaidCloud mantêm-se como estão.

### O que é guardado

- As células vazias e as células que mostram um erro são guardadas como vazias.
- As linhas acrescentadas diretamente abaixo da tabela são incluídas, até à primeira linha vazia.
- Uma única linha vazia no meio das linhas obtidas é ignorada; as linhas à sua volta continuam a ser guardadas. Duas ou mais linhas vazias seguidas, com dados abaixo, interrompem a gravação e indicam que linhas deve eliminar ou preencher.

### Antes de substituir uma tabela

- **Uma tabela filtrada.** Se obteve a tabela com um filtro, todas as linhas que o filtro deixou de fora são eliminadas do PlaidCloud. A confirmação indica-o e pede-lhe que assinale uma caixa antes de **Replace table** ficar ativo.
- **Colunas que não obteve.** Se obteve apenas algumas colunas, o PlaidXL pergunta **Empty columns that were not retrieved?** e indica-as pelo nome. Clique em **Write anyway** para esvaziar essas colunas no PlaidCloud, ou em **Cancel** para não escrever nada.
- **Outra pessoa alterou a tabela.** Quando o PlaidCloud consegue detetá-lo, a gravação é recusada se a tabela tiver mudado depois de a obter; obtenha-a novamente e volte a aplicar as suas edições. Quando não consegue detetá-lo, a confirmação indica-o, e tudo o que outras pessoas guardaram desde que obteve a tabela é substituído.
- **Um ponto de restauro.** O PlaidXL cria um ponto de restauro antes de escrever e mantém-no durante 7 dias. Se a escrita falhar, a tabela é reposta como estava. Uma tabela que não consegue criar um ponto de restauro pergunta **Write back without a restore point?**, e **Write anyway** avança sem ele.

Após uma gravação bem-sucedida, a mensagem de confirmação inclui **Restore previous version**. Abre a tabela no PlaidCloud, onde escolhe a versão imediatamente anterior a esta gravação no menu **As of**.
