## Transferir o Agente

Consulte as versões disponíveis em [PlaidCloud.com](https://plaidcloud.com/) para o **PlaidLink**

## Extrair o Agente

Extraia o ficheiro zip transferido para um local de instalação à sua escolha. Em geral, este local será:

```bash
C:\Users\<Username here>\src\plaidlink
```

## Criar um Ficheiro de Configuração

<Aside>Se estiver a atualizar a partir de uma versão anterior do agente, o ficheiro de configuração continua a ser válido e este passo pode ser ignorado</Aside>

Copie o ficheiro `config-dist.yaml` do diretório do agente para `%ProgramData\plaidcloud\` e mude o nome desta cópia para `config.yaml`

*(Edite esta configuração com os valores obtidos no PlaidCloud)*

## Instalar o Serviço do Agente

Execute o ficheiro `install_windows_service.bat` no diretório de instalação do agente OU

A partir de uma linha de comandos de administrador, navegue até ao diretório de instalação do agente e execute:

```bash
.\PlaidLink.exe install
```

## Executar o Agente

<Aside>Para instalar um serviço do Windows, é necessário ter privilégios de administrador</Aside>

Escreva **`Services`** na barra de pesquisa do Windows e abra o gestor de serviços. Na lista de serviços, localize **`PlaidCloud Agent`**.

Clique com o botão direito do rato no serviço e selecione **"Start"** para iniciar o agente.

## Impedir Atualizações

Se em algum momento pretender desativar a funcionalidade de atualização automática do agente, abra o ficheiro de configuração **'yaml'** do agente, 
adicione ao nível raiz do ficheiro uma linha com `freeze_updates: true` e reinicie o serviço do agente. 

<Aside type="caution">Não se recomenda desativar as atualizações automáticas a longo prazo</Aside>
