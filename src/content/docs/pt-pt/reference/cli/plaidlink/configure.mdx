O agente PlaidLink funciona em conjunto com o serviço PlaidCloud. O agente PlaidLink fornece a ligação necessária 
para operar com sistemas que não são acessíveis diretamente, como bases de dados e sistemas de ficheiros. O agente realiza várias ações essenciais, incluindo:

* Ler e escrever em bases de dados
* Ler e escrever ficheiros em unidades de rede e servidores
* Verificar condições de sensores
* Interagir com o SAP ECC e o SAP S/4HANA através de chamadas de função remotas (RFC)
* Interagir com o SAP Profitability and Cost Management (PCM)
* Enviar mensagens e notificações para sistemas remotos

## Criar um agente no PlaidCloud

A gestão dos agentes PlaidLink realiza-se no separador Analyze do PlaidCloud. O primeiro passo é criar uma nova instância de agente PlaidLink no PlaidCloud.

### Para criar um novo agente PlaidLink

1. Selecione o separador Analyze
2. Selecione o menu de ferramentas na parte superior
3. Clique em Agentes PlaidLink
4. Crie um novo agente com um nome adequado ao ambiente ou ao servidor em que será instalado para operações remotas

### Para ver as chaves pública e privada do agente

1. Clique no ícone de edição para ver o formulário
2. No fundo do formulário, encontra as chaves pública e privada que foram geradas aleatoriamente durante o processo de criação do agente

<Aside>Guarde estas chaves, pois serão utilizadas na configuração do agente no servidor remoto.</Aside>

### Para gerar novas chaves aleatoriamente

1. Clique no ícone Regenerate do registo do agente
2. Depois de as chaves serem regeneradas, não se esqueça de atualizar o ficheiro de configuração do agente com as novas chaves no servidor remoto.

<Aside>Guarde as chaves pública e privada para configurar o agente remoto no passo seguinte.</Aside>

## Acesso à conta de documentos

Se o agente precisar de aceder a uma conta de documentos para carregar ou transferir ficheiros, tem de lhe ser concedida permissão para aceder a essa conta de documentos.

### Para conceder acesso à conta

1. No separador Document, selecione Gerir contas
2. Quando a tabela de contas for apresentada, clique no ícone de agente da conta à qual o novo agente deve ter direitos de carregamento/transferência
3. Arraste o novo agente para a coluna Agentes atribuídos
4. Guarde o formulário de controlo de acesso.

<Aside>Os agentes só podem carregar e transferir ficheiros se lhes tiver sido concedido acesso a uma ou mais contas de documentos.</Aside>

## Acesso à ligação de dados

Se o agente precisar de aceder a uma ligação de dados, como uma base de dados, tem de lhe ser concedida permissão para aceder às informações da ligação de dados externa.


### Para conceder acesso à ligação


1. No separador Analyze, selecione o menu Tools
2. Clique em Ligações de dados externas
3. Quando a tabela de ligações de dados for apresentada, clique no ícone de agente da ligação à qual o novo agente deve ter direitos de utilização
4. Arraste o novo agente para a coluna Agentes atribuídos e guarde o formulário de controlo de acesso.

<Aside>As credenciais de ligação de dados dos agentes são geridas em Ligações de dados externas.</Aside>
