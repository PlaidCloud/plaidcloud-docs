Devolve a constante matemática e (número de Euler).

## Sintaxe de Analyze

```python
func.e()
```

## Exemplos de Analyze

```python
func.e()

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## Sintaxe SQL

```sql
E()
```

## Exemplos SQL

```sql
SELECT E();

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
