Devolve a constante matemática pi.

## Sintaxe de Analyze

```python
func.pi()
```

## Exemplos de Analyze

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## Sintaxe SQL

```sql
PI()
```

## Exemplos SQL

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
