## Onde consultar a sintaxe de referência

O PlaidCloud Lakehouse utiliza as bibliotecas de funções SQL dos motores subjacentes. Para pormenores sobre os argumentos de uma função, casos limite e o comportamento mais atual, consulte a documentação original em conjunto com os exemplos adaptados ao PlaidCloud aqui apresentados.

- **Lakehouse v1** → [Referência de funções SQL do Databend](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [Referência de funções SQL do StarRocks](https://docs.starrocks.io/docs/sql-reference/sql-functions/) (o PlaidCloud Lakehouse v2 acompanha o StarRocks 4.1)
