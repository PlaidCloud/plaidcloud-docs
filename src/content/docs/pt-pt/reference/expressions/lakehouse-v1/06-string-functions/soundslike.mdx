Compara a pronúncia de duas cadeias de caracteres através dos respetivos códigos Soundex. O Soundex é um algoritmo fonético que produz um código que representa a pronúncia de uma cadeia de caracteres, permitindo a correspondência aproximada de cadeias com base na pronúncia e não na ortografia. O PlaidCloud Lakehouse disponibiliza a função [SOUNDEX](../soundex), que permite obter o código Soundex de uma cadeia de caracteres.

SOUNDS LIKE é frequentemente utilizado na cláusula WHERE de consultas SQL para restringir linhas através de correspondência difusa de cadeias de caracteres, por exemplo em nomes e moradas; veja [Filtrar Linhas](#filtrar-linhas) em [Exemplos](#exemplos-sql).

<Aside>Embora a função possa ser útil para a correspondência aproximada de cadeias de caracteres, é importante notar que nem sempre é rigorosa. O algoritmo Soundex baseia-se nas regras de pronúncia do inglês e pode não funcionar bem com cadeias de outras línguas ou dialetos.</Aside>

## Sintaxe do Analyze

```python
func.sounds_like(<str1>, <str2>)
```

## Exemplos do Analyze

```python
func..sounds_like('Monday', 'Sunday')
┌───────────────────────────────────────┐
│ func..sounds_like('Monday', 'Sunday') │
├───────────────────────────────────────┤
│                                     0 │
└───────────────────────────────────────┘
```

## Sintaxe SQL

```sql
<str1> SOUNDS LIKE <str2>
```

## Argumentos

| Argumentos | Descrição |
|-----------|-------------|
| str1, 2   | As cadeias de caracteres que compara. |

## Tipo de Retorno

Devolve um valor booleano 1 se os códigos Soundex das duas cadeias de caracteres forem iguais (o que significa que soam de forma semelhante) e 0 caso contrário.

## Exemplos SQL

### Comparar Cadeias de Caracteres

```sql
SELECT 'two' SOUNDS LIKE 'too'
----
1

SELECT CONCAT('A', 'B') SOUNDS LIKE 'AB';
----
1

SELECT 'Monday' SOUNDS LIKE 'Sunday';
----
0
```

### Filtrar Linhas

```sql
SELECT * FROM  employees;
```
