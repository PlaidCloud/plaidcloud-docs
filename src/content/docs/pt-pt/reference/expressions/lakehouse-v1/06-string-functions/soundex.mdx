Gera o código Soundex de uma cadeia de caracteres.

- Um código Soundex é composto por uma letra seguida de três dígitos numéricos. A implementação do PlaidCloud Lakehouse devolve mais de 4 dígitos, mas pode aplicar [SUBSTR](../substr) ao resultado para obter um código Soundex padrão.
- Todos os caracteres não alfabéticos da cadeia de caracteres são ignorados.
- Todos os caracteres alfabéticos internacionais fora do intervalo A-Z são ignorados, a menos que sejam a primeira letra.


<Aside>O que é o Soundex? O Soundex converte uma cadeia de caracteres alfanumérica num código de quatro caracteres baseado na forma como a cadeia soa quando pronunciada em inglês. Para mais informações, consulte https://en.wikipedia.org/wiki/Soundex</Aside>

Veja também: [SOUNDS LIKE](../soundslike)

## Sintaxe do Analyze

```python
func.soundex(<str>)
```

## Exemplos do Analyze

```python
func.soundex('PlaidCloud Lakehouse')
┌──────────────────────────────────────┐
│ func.soundex('PlaidCloud Lakehouse') │
├──────────────────────────────────────┤
│ D153                                 │
└──────────────────────────────────────┘
```

## Sintaxe SQL

```sql
SOUNDEX(<str>)
```

## Argumentos

| Argumentos | Descrição               |
|-----------|-------------------------|
| str  | A cadeia de caracteres. |

## Tipo de Retorno

Devolve um código do tipo VARCHAR ou um valor NULL.

## Exemplos SQL

```sql
SELECT SOUNDEX('PlaidCloud Lakehouse');

---
D153

-- All non-alphabetic characters in the string are ignored.
SELECT SOUNDEX('PlaidCloud Lakehouse!');

---
D153

-- All international alphabetic characters outside the A-Z range are ignored unless they're the first letter.
SELECT SOUNDEX('PlaidCloud Lakehouse，你好');

---
D153

SELECT SOUNDEX('你好，PlaidCloud Lakehouse');

---
你3153

-- SUBSTR the result to get a standard Soundex code.
SELECT SOUNDEX('databend cloud'),SUBSTR(SOUNDEX('databend cloud'),1,4);

soundex('databend cloud')|substring(soundex('databend cloud') from 1 for 4)|
-------------------------+-------------------------------------------------+
D153243                  |D153                                             |

SELECT SOUNDEX(NULL);
┌─────────────────────────────────────┐
│ `SOUNDEX(NULL)`                     │
├─────────────────────────────────────┤
│ <null>                              │
└─────────────────────────────────────┘
```
