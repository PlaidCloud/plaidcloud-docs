Devolve a data e a hora atuais.

## Sintaxe do Analyze

```python
func.now()
```

## Exemplos do Analyze

```python
┌─────────────────────────────────────────────────────────┐
│  func.current_timestamp()  │         func.now()         │
├────────────────────────────┼────────────────────────────┤
│ 2024-01-29 04:38:12.584359 │ 2024-01-29 04:38:12.584417 │
└─────────────────────────────────────────────────────────┘
```

## Sintaxe SQL

```sql
NOW()
```

## Tipo de retorno

TIMESTAMP

## Aliases

- [CURRENT_TIMESTAMP](../current-timestamp)

## Exemplos SQL

Este exemplo devolve a data e a hora atuais:

```sql
SELECT CURRENT_TIMESTAMP(), NOW();

┌─────────────────────────────────────────────────────────┐
│     current_timestamp()    │            now()           │
├────────────────────────────┼────────────────────────────┤
│ 2024-01-29 04:38:12.584359 │ 2024-01-29 04:38:12.584417 │
└─────────────────────────────────────────────────────────┘
```
