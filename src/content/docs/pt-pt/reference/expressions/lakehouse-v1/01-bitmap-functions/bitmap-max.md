Obtém o valor máximo do bitmap.

## Sintaxe do Analyze

```python
func.bitmap_max( <bitmap> )
```

## Exemplos do Analyze

```python
func.bitmap_max(func.build_bitmap([1, 4, 5]))

┌───────────────────────────────────────────────┐
│ func.bitmap_max(func.build_bitmap([1, 4, 5])) │
├───────────────────────────────────────────────┤
│                                             5 │
└───────────────────────────────────────────────┘
```

## Sintaxe SQL

```sql
BITMAP_MAX( <bitmap> )
```

## Exemplos SQL

```sql
SELECT BITMAP_MAX(BUILD_BITMAP([1,4,5]));

┌─────────────────────────────────────┐
│ bitmap_max(build_bitmap([1, 4, 5])) │
├─────────────────────────────────────┤
│                                   5 │
└─────────────────────────────────────┘
```
