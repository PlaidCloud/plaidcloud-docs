Converte um objeto GEOMETRY numa representação em cadeia de caracteres. O formato de apresentação dos dados de saída é controlado pela definição `geometry_output_format`, que contém os seguintes tipos:

| Parâmetro         | Descrição                                                           |
|-------------------|---------------------------------------------------------------------|
| GeoJSON (predefinido) | O resultado GEOMETRY é apresentado como um objeto JSON em formato GeoJSON. |
| WKT               | O resultado GEOMETRY é apresentado como uma cadeia de caracteres em formato WKT. |
| WKB               | O resultado GEOMETRY é apresentado como um valor binário em formato WKB. |
| EWKT              | O resultado GEOMETRY é apresentado como uma cadeia de caracteres em formato EWKT. |
| EWKB              | O resultado GEOMETRY é apresentado como um valor binário em formato EWKB. |

## Sintaxe SQL

```sql
TO_STRING(<geometry>)
```

## Argumentos

| Argumentos   | Descrição                                            |
|--------------|------------------------------------------------------|
| `<geometry>` | O argumento tem de ser uma expressão do tipo GEOMETRY. |

## Tipo de retorno

String.

## Exemplos de SQL

```sql
SET geometry_output_format='GeoJSON';

SELECT
  TO_GEOMETRY(
    ST_GEOMETRYFROMWKT(
      'SRID=4326;LINESTRING(400000 6000000, 401000 6010000)'
    )
  ) AS pipeline_geometry;

┌────────────────────────────────────────────────────────────────────────────┐
│                              pipeline_geometry                             │

└────────────────────────────────────────────────────────────────────────────┘
```
