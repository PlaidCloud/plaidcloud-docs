A função COUNT() devolve o número de registos devolvidos por uma consulta SELECT.

<Aside type="caution">Os valores NULL não são contados.</Aside>

## Sintaxe do Analyze

```python
func.count(<column>)
```

## Exemplos do Analyze

```python
func.count(table.grade).alias('count_valid_grades')

| count_valid_grades |
|--------------------|
|          4         |
```

## Sintaxe SQL

```sql
COUNT(<expr>)
```

## Argumentos

| Argumentos | Descrição                                                                                                                                                       |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<expr>`  | Qualquer expressão. <br /> Pode ser o nome de uma coluna, o resultado de outra função ou uma operação matemática.<br />`*` também é permitido, para indicar uma contagem pura de linhas. |

## Tipo de retorno

Um inteiro.

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**
```sql
CREATE TABLE students (
  id INT,
  name VARCHAR,
  age INT,
  grade FLOAT NULL
);

INSERT INTO students (id, name, age, grade)
VALUES (1, 'John', 21, 85),
       (2, 'Emma', 22, NULL),
       (3, 'Alice', 23, 90),
       (4, 'Michael', 21, 88),
       (5, 'Sophie', 22, 92);

```

**Exemplo de consulta: contar alunos com notas válidas**
```sql
SELECT COUNT(grade) AS count_valid_grades
FROM students;
```

**Resultado**
```sql
| count_valid_grades |
|--------------------|
|          4         |
```
