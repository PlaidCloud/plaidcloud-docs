Função de agregação.

A função MEDIAN() calcula a mediana de uma sequência de dados numéricos.

<Aside type="caution">Os valores NULL não são contados.</Aside>

## Sintaxe do Analyze

```python
func.median(<expr>)
```

## Exemplos do Analyze

```python
func.median(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## Sintaxe SQL

```sql
MEDIAN(<expr>)
```

## Argumentos

| Argumentos | Descrição                |
|-----------|--------------------------|
| `<expr>`  | Qualquer expressão numérica |

## Tipo de retorno

O tipo do valor.

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**
```sql
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);
```

**Exemplo de consulta: calcular a mediana das notas dos exames**
```sql
SELECT MEDIAN(score) AS median_score
FROM exam_scores;
```

**Resultado**
```sql
|  median_score  |
|----------------|
|      85.0      |
```
