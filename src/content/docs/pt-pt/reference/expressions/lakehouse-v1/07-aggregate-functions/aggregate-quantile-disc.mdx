Função de agregação.

A função `QUANTILE_DISC()` calcula o quantil exato de uma sequência de dados numéricos.
`QUANTILE` é um alias de `QUANTILE_DISC`

<Aside type="caution">Os valores NULL não são contados.</Aside>

## Sintaxe do Analyze

```python
func.quantile_disc(<levels>, <expr>)
```

## Exemplos do Analyze

```python
func.quantile_disc([0.25, 0.75], table.salary).alias('salary_quantiles')

|  salary_quantiles   |
|---------------------|
| [55000.0, 65000.0]  |
```

## Sintaxe SQL

```sql
QUANTILE_DISC(<levels>)(<expr>)
    
QUANTILE_DISC(level1, level2, ...)(<expr>)
```

## Argumentos

| Argumentos | Descrição                                                                                                                                     |
|------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| `level(s)` | Nível ou níveis do quantil. Cada nível é um número de vírgula flutuante constante entre 0 e 1. Recomendamos utilizar um valor de nível no intervalo [0.01, 0.99] |
| `<expr>`   | Qualquer expressão numérica                                                                                                                   |

## Tipo de retorno

InputType ou matriz de InputType, consoante o número de níveis.

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**
```sql
CREATE TABLE salary_data (
  id INT,
  employee_id INT,
  salary FLOAT
);

INSERT INTO salary_data (id, employee_id, salary)
VALUES (1, 1, 50000),
       (2, 2, 55000),
       (3, 3, 60000),
       (4, 4, 65000),
       (5, 5, 70000);
```

**Exemplo de consulta: calcular os percentis 25 e 75 dos salários**
```sql
SELECT QUANTILE_DISC(0.25, 0.75)(salary) AS salary_quantiles
FROM salary_data;
```

**Resultado**
```sql
|  salary_quantiles   |
|---------------------|
| [55000.0, 65000.0]  |
```
