Função de agregação.

A função STDDEV_SAMP() devolve o desvio padrão da amostra (a raiz quadrada de VAR_SAMP()) de uma expressão.

<Aside type="caution">Os valores NULL não são contados.</Aside>

## Sintaxe do Analyze

```python
func.stddev_samp(<expr>)
```

## Exemplos do Analyze

```python
func.stddev_samp(table.height).alias('height_stddev_samp')

| height_stddev_samp |
|--------------------|
|      0.240         |
```

## Sintaxe SQL

```sql
STDDEV_SAMP(<expr>)
```

## Argumentos

| Argumentos | Descrição                |
|-----------|--------------------------|
| `<expr>`  | Qualquer expressão numérica |

## Tipo de retorno

double

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**
```sql
CREATE TABLE height_data (
  id INT,
  person_id INT,
  height FLOAT
);

INSERT INTO height_data (id, person_id, height)
VALUES (1, 1, 5.8),
       (2, 2, 6.1),
       (3, 3, 5.9),
       (4, 4, 5.7),
       (5, 5, 6.3);
```

**Exemplo de consulta: calcular o desvio padrão da amostra das alturas**
```sql
SELECT STDDEV_SAMP(height) AS height_stddev_samp
FROM height_data;
```

**Resultado**
```sql
| height_stddev_samp |
|--------------------|
|      0.240         |
```
