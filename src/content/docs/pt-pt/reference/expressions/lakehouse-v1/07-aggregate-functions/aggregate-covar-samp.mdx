Função de agregação.

A função covar_samp() devolve a covariância da amostra (Σ((x - x̅)(y - y̅)) / (n - 1)) de duas colunas de dados.

<Aside type="caution">Os valores NULL não são contados.</Aside>

## Sintaxe do Analyze

```python
func.covar_samp(<expr1>, <expr2>)
```

## Exemplos do Analyze

```python
func.covar_samp(table.items_sold, table.profit).alias('covar_samp_items_profit')

| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```

## Sintaxe SQL

```sql
COVAR_SAMP(<expr1>, <expr2>)
```

## Argumentos

| Argumentos |        Descrição         |
|-----------| ------------------------ |
| `<expr1>` | Qualquer expressão numérica |
| `<expr2>` | Qualquer expressão numérica |

## Tipo de retorno

float64; quando n &lt;= 1, devolve +∞.

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**

```sql
CREATE TABLE store_sales (
  id INT,
  store_id INT,
  items_sold INT,
  profit FLOAT
);

INSERT INTO store_sales (id, store_id, items_sold, profit)
VALUES (1, 1, 100, 1000),
       (2, 2, 200, 2000),
       (3, 3, 300, 3000),
       (4, 4, 400, 4000),
       (5, 5, 500, 5000);
```

**Exemplo de consulta: calcular a covariância da amostra entre artigos vendidos e lucro**

```sql
SELECT COVAR_SAMP(items_sold, profit) AS covar_samp_items_profit
FROM store_sales;
```

**Resultado**

```sql
| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```
