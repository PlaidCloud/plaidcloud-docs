Este tutorial configura um agente de programação com IA para interagir com a sua área de trabalho PlaidCloud através do **Model Context Protocol** (MCP). Depois de configurado, pode pedir ao agente que leia tabelas, execute fluxos de trabalho, crie alocações e responda a perguntas sobre os seus dados, diretamente a partir do editor.

Demora cerca de 20 minutos. Funciona com o Claude Code, o Cursor, o Claude Desktop, o ChatGPT, o GitHub Copilot e qualquer cliente compatível com MCP.

## O que vai criar

Uma ligação funcional entre o seu agente de programação com IA e a sua área de trabalho PlaidCloud, na qual o agente pode:

- Listar projetos, tabelas, fluxos de trabalho e dimensões
- Ler o conteúdo de tabelas
- Inspecionar definições de fluxos de trabalho
- Acionar execuções de fluxos de trabalho
- Responder a perguntas sobre os seus dados sem que tenha de mudar de contexto

## Pré-requisitos

- Uma área de trabalho PlaidCloud ([comece uma avaliação gratuita](https://app.plaidcloud.com) se ainda não tiver uma)
- Um agente de programação com IA que já utilize — Claude Code, Cursor, Claude Desktop, ChatGPT, Copilot ou Gemini
- O agente tem de suportar MCP (a maioria das ferramentas de IA atuais suporta)

## Passo 1: Encontrar o URL MCP da área de trabalho

Cada área de trabalho PlaidCloud expõe um ponto de acesso MCP em:

```text
https://<your-workspace>.plaid.cloud/mcp
```

Substitua `<your-workspace>` pelo subdomínio da sua área de trabalho — o mesmo que utiliza para iniciar sessão na IU do PlaidCloud.

## Passo 2: Obter um token de autenticação

<Steps>

1. Com a sessão iniciada no PlaidCloud num navegador, visite:
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. Copie o token de portador apresentado na página. Guarde-o em segurança — concede o mesmo acesso que a sua conta tem.

</Steps>

<Aside type="caution">
Trate o token como uma palavra-passe. Ignora a autenticação interativa e atua em seu nome. Se for divulgado, revogue-o a partir do mesmo ponto de acesso.
</Aside>

## Passo 3: Configurar o agente

<Tabs>

<TabItem label="Claude Code">

Execute no terminal:

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

Para autenticação com token estático (sem fluxo OAuth, mais simples para sessões longas), abra num navegador o URL do Passo 2, copie o excerto de configuração apresentado e cole-o no ficheiro `.mcp.json`.

Consulte a [configuração do Claude Code](/pt-pt/integrations/ai-coding-agents/claude-code/) para ver todas as opções.

</TabItem>

<TabItem label="Cursor">

Obtenha um token de portador em `https://<your-workspace>.plaid.cloud/mcp/setup/token` e adicione-o à configuração MCP do Cursor:

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

Consulte a [configuração do Cursor](/pt-pt/integrations/ai-coding-agents/cursor/) para ver todas as opções.

</TabItem>

<TabItem label="Claude Desktop">

Abra Definições → Programador → Servidores MCP e adicione:

- **URL do servidor**: `https://<your-workspace>.plaid.cloud/mcp`
- Utilize o início de sessão OAuth quando lhe for pedido

Consulte a [configuração do Claude Desktop](/pt-pt/integrations/ai-coding-agents/claude-desktop/) para ver todas as opções.

</TabItem>

<TabItem label="ChatGPT">

1. Definições → Conectores → Adicionar conector personalizado
2. Introduza:
   - **Nome**: `PlaidCloud`
   - **URL do servidor MCP**: `https://<your-workspace>.plaid.cloud/mcp`
3. O ChatGPT redireciona-o para o PlaidCloud para o início de sessão OAuth. Aprove a ligação.
4. Ative o conector em qualquer conversa que o deva utilizar.

Consulte a [configuração do ChatGPT](/pt-pt/integrations/ai-coding-agents/chatgpt/) para ver todas as opções.

</TabItem>

<TabItem label="Copilot">

Obtenha um token de portador e adicione-o a `.vscode/mcp.json`:

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

O VS Code lê este ficheiro no arranque e sempre que é alterado.

Consulte a [configuração do Copilot](/pt-pt/integrations/ai-coding-agents/copilot/) para ver todas as opções.

</TabItem>

</Tabs>

## Passo 4: Verificar a ligação

Peça ao agente algo simples:

> "Liste os projetos na minha área de trabalho PlaidCloud."

O agente deve responder com a lista de projetos. Se não o fizer, consulte os passos de resolução de problemas abaixo.

## Passo 5: Experimentar tarefas reais

Depois de ligado, experimente:

- **Explorar os dados**: "Que colunas tem a tabela `sales` do meu projeto Quickstart?"
- **Executar um fluxo de trabalho**: "Acione o fluxo de trabalho `monthly_close` no projeto Financials e avise-me quando terminar."
- **Criar algo**: "Crie um passo Table Lookup no meu fluxo de trabalho Test que filtre as encomendas dos últimos 30 dias."

As respostas do agente baseiam-se no estado real da sua área de trabalho — não em respostas genéricas.

## Resolução de problemas

Se o agente não conseguir contactar o PlaidCloud ou devolver erros de autenticação:

- **Token expirado** — renove-o em `https://<your-workspace>.plaid.cloud/mcp/setup/token`
- **Âmbitos incorretos** — algumas ferramentas exigem âmbitos específicos do PlaidCloud (por exemplo, `analyze.workflow.write`). Execute `mcp_introspect(name='<tool>')` no agente para ver os âmbitos necessários
- **Subdomínio da área de trabalho incorreto** — confirme iniciando sessão na IU do PlaidCloud; o subdomínio é a parte anterior a `.plaid.cloud`

Consulte a [resolução de problemas dos agentes de programação com IA](/pt-pt/integrations/ai-coding-agents/troubleshooting/) para mais informações.
