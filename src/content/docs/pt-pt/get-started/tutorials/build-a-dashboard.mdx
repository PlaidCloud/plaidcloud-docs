*~30 minutos · uma tabela publicada, um gráfico, um painel de controlo partilhado*

Tem uma tabela limpa publicada a partir de um fluxo de trabalho. Este tutorial transforma-a em algo que as pessoas conseguem ler de relance: um gráfico, depois um painel de controlo construído à sua volta e, por fim, um painel de controlo partilhado com as pessoas certas. Não é necessário SQL para ter um primeiro gráfico no ecrã — aponta, clica e consulta.

Se seguiu [Carregar, transformar e publicar dados](/pt-pt/get-started/tutorials/load-and-transform-data/), a tabela `sales_final` que publicou aí é exatamente o ponto de partida que este tutorial pressupõe. Qualquer tabela publicada serve igualmente.

## O Que Vai Construir

Um único painel de controlo com dois gráficos sobre uma tabela publicada — um Big Number com a receita total e um gráfico de barras que decompõe a receita por uma coluna de agrupamento — formatado, guardado e visível para a sua área de trabalho.

## Pré-requisitos

- Uma área de trabalho PlaidCloud e um projeto que possa abrir.
- Uma tabela **publicada** nesse projeto. Se não tiver uma, siga primeiro [Carregar, transformar e publicar dados](/pt-pt/get-started/tutorials/load-and-transform-data/) ou publique qualquer tabela existente — clique com o botão direito do rato nela no separador **Tabelas** e escolha **Set Published Table Reporting Name**. Consulte [Publicar tabelas](/pt-pt/guides/data/publish/).
- Nada para instalar na área de Painéis de controlo — a sua conta de painéis de controlo é criada automaticamente na primeira vez que abrir um painel de controlo a partir do PlaidCloud.

> **Só as tabelas publicadas chegam aos painéis de controlo.** Um painel de controlo lê uma tabela pelo seu nome de relatório publicado, não pelo nome interno da tabela. Se a sua tabela não aparecer como conjunto de dados mais tarde, a causa habitual é que nunca foi publicada ou foi publicada com um nome que não reconhece — verifique a coluna **Publicado como** no separador **Tabelas**.

## Passo 1: Abrir a Área de Painéis de Controlo

1. No seu projeto no PlaidCloud, abra a área **Painéis de controlo**.
2. Na primeira vez que o fizer, a sua conta de painéis de controlo é configurada automaticamente — não há nada para criar manualmente. O que pode ver resulta da sua pertença à área de trabalho e dos seus grupos de segurança.
3. A sua tabela publicada está agora disponível como **conjunto de dados**, porque pertence a um projeto a que tem acesso.

Para saber como a visibilidade dos painéis de controlo corresponde à pertença à área de trabalho, consulte [Utilizar painéis de controlo](/pt-pt/guides/dashboards/using-dashboards/).

## Passo 2: Preparar o Conjunto de Dados

Antes de criar gráficos, indique ao painel de controlo como cada coluna se deve comportar. É uma configuração única por tabela que faz o explorador de apontar e clicar funcionar bem.

1. Clique no ícone de edição do seu conjunto de dados.
2. Abra o separador **List Columns**.
3. Para cada coluna, defina as funções aplicáveis e depois **Guardar**:

| Definição | Ative quando |
|---|---|
| **Groupable** | Quiser decompor indicadores por este campo (região, produto, mês) |
| **Filterable** | Quiser filtrar por este campo |
| **Soma** / **Mínimo** / **Máximo** | For uma medida numérica que vai totalizar ou resumir |
| **Count Distinct** | Quiser contar valores únicos deste campo |
| **Is temporal** | For um campo de data ou hora |

> **Marque a sua coluna de data como temporal.** Os filtros temporais e os controlos «Since / Until» no explorador só funcionam numa coluna assinalada como **Is temporal**. É a definição mais facilmente esquecida.

## Passo 3: Criar o Seu Primeiro Gráfico

Comece no explorador, que abre numa Table View simples, e transforme-a num Big Number para a receita total.

> **Use a sua própria coluna de medida.** Este tutorial cria gráficos de uma coluna `revenue`, mas o pré-requisito é apenas «qualquer tabela publicada» — onde vir `revenue`, substitua pela coluna numérica que realmente pretende totalizar (`amount`, `sales`, `quantity`, etc.).

1. Clique no conjunto de dados para o abrir. Por predefinição, obtém uma **Table View**.
2. Na secção de indicadores, adicione a medida pretendida — para um total acumulado, escreva-a e escolha a sua coluna somada (por exemplo, um `SUM` de `revenue`), ou use **COUNT(\*)** para contar linhas.
3. Adicione os campos de **Agrupar por** pelos quais pretende decompor o número. Para um único número de destaque, deixe Agrupar por vazio.
4. Clique em **Consulta** para a executar e ver o resultado.
5. Desloque-se até **Chart Options** (ou ao seletor do tipo de visualização) e mude o tipo de gráfico para **Big Number**. Os gráficos podem ser Tabelas, Big Numbers, Gráficos de barras e mais — cada um apresenta o mesmo resultado da consulta de forma diferente.
6. Clique novamente em **Consulta** para redesenhar.

Agora crie um segundo gráfico que decomponha a mesma medida:

1. Inicie uma nova exploração sobre o mesmo conjunto de dados.
2. Mantenha o `SUM` de `revenue` como indicador e adicione um **Agrupar por** numa coluna agrupável, como `region` ou `product`.
3. Defina o tipo de gráfico como **Bar Chart** e **Consulta**.
4. Se só quiser as primeiras linhas, abra **Opções** e defina um **Limite de linhas** — por exemplo, `10` para um gráfico de barras com os dez primeiros.

> **Prefira a formatação na apresentação a alterar os dados.** Pode arredondar ou reformatar valores de duas formas: transformá-los na tabela ou formatá-los na apresentação. Formatar na apresentação é a escolha habitual — os valores subjacentes mantêm a precisão total e cada utilizador vê um número limpo. É o passo seguinte.

## Passo 4: Formatar os Números

As medidas em bruto chegam sem formatação. Corrija isso no gráfico, não nos dados.

- **Big Number:** edite o gráfico, abra o separador **Customize** e defina **Number Format**.
- **Tabela:** edite o gráfico, abra o separador **Customize**, selecione uma coluna numérica (apresentada com um `#`) em **Customize Column** e defina o respetivo **D3 Format**.

O valor predefinido é **Adaptive formatting**, que se ajusta aos valores. Para fixar um formato, escolha um na lista pendente ou escreva uma cadeia de formato D3:

| Formato | Entrada | Mostra |
|---|---|---|
| `,d` | `12345.67` | `12,346` |
| `$,d` | `12345.67` | `$12,346` |
| `$,.2f` | `12345.67` | `$12,345.67` |
| `,.2%` | `13.215` | `1,321.50%` |

A gramática completa de formatos — símbolos de moeda, preenchimento, precisão, prefixos SI — está em [Formatar números e outros tipos de dados](/pt-pt/guides/dashboards/formatting-numbers/).

> **Arredondar para o dólar inteiro? Use `,d` ou `$,d`, não `,.0f`.** A forma `,.0f` é uma origem conhecida de formatação de números incorreta; `,d` (decimal, arredondado para inteiro) é a forma fiável de eliminar as casas decimais.

## Passo 5: Adicionar uma Medida Calculada (Opcional)

Se o número pretendido não for uma coluna simples — um rácio, uma percentagem de margem, uma soma condicional — escreva-o como indicador. Os indicadores e as colunas calculadas são escritos em SQL ao estilo PostgreSQL no conjunto de dados.

```sql
SUM("revenue") / (COUNT(*) + 0.00001)
```

O `+ 0.00001` evita uma divisão por zero quando um grupo não tem linhas. Para mais padrões — lógica `CASE`, `COALESCE` para nulos, somas condicionais — consulte [Exemplos de indicadores](/pt-pt/guides/dashboards/example-metrics/) e [Exemplos de colunas calculadas](/pt-pt/guides/dashboards/example-calculated-columns/).

## Passo 6: Reunir o Painel de Controlo

Um painel de controlo é uma disposição de gráficos guardados. Associe cada gráfico que criou ao mesmo painel de controlo para que fiquem juntos.

1. Abra **Edit Chart** no seu Big Number.
2. Na secção **Painéis de controlo**, introduza o nome do painel de controlo em que deve aparecer. Se o painel de controlo ainda não existir, é aqui que lhe dá nome.
3. Guarde e repita para o seu gráfico de barras, apontando-o para o mesmo painel de controlo.
4. Abra o painel de controlo para ver ambos os gráficos. No modo de edição do próprio painel de controlo, pode organizar os mosaicos, redimensioná-los e adicionar filtros.

Para todo o leque de opções de disposição, filtros e interação, consulte [Conhecer os painéis de controlo](/pt-pt/guides/dashboards/learning-dashboard/).

## Passo 7: Partilhá-lo

Quem vê o painel de controlo resulta primeiro do acesso ao PlaidCloud e, depois, de quaisquer funções do serviço de painéis de controlo adicionadas.

- **Por predefinição, é visível para as pessoas do projeto.** A lista de painéis de controlo no PlaidCloud mostra os painéis de controlo publicados pertencentes a projetos a que uma pessoa tem acesso — por isso, qualquer pessoa que possa abrir o projeto encontra o seu painel de controlo, sem qualquer passo adicional.
- **Adicione proprietários dos gráficos à medida que avança.** Ao guardar um gráfico, adicione a todos os que precisam dele os **Proprietários** do gráfico — caso contrário, um colega pode deparar-se com um erro «requires the datasource… permission» num gráfico a que não consegue aceder. Adicionar proprietários ao guardar é mais fácil do que corrigir o acesso depois.
- **Restrinja a funções específicas apenas se precisar.** Um painel de controlo pode ser limitado a funções particulares no serviço de painéis de controlo, definidas nas propriedades do próprio painel de controlo. Um painel de controlo restrito fica oculto na lista para quem não tenha uma função correspondente — por isso, se restringir um, informe as pessoas que o devem ter. O acesso ao projeto no PlaidCloud continua a aplicar-se por cima: uma atribuição de função nunca dá acesso a um painel de controlo de um projeto a que alguém não consegue aceder.

Consulte [Utilizar painéis de controlo](/pt-pt/guides/dashboards/using-dashboards/) para as regras de visibilidade completas.

## Manter o Painel de Controlo Atual

Não atualiza os painéis de controlo manualmente. Quando um fluxo de trabalho volta a publicar a tabela por detrás de um gráfico, todos os gráficos que a leem descartam os resultados em cache e a próxima pessoa que abrir o painel de controlo vê os novos números.

> **Um painel de controlo com aspeto desatualizado quase nunca é a cache.** Se os números parecerem antigos após uma execução de um fluxo de trabalho, verifique o fluxo de trabalho — se a execução terminou e voltou a publicar a tabela esperada — e não a cache. Volte a publicar também com o **mesmo** nome publicado: os gráficos ficam associados a um nome, pelo que uma tabela reconstruída com um novo nome deixa os gráficos antigos a apontar para dados antigos.

Se alguma vez precisar de forçar a atualização, abra o menu junto a **Edit dashboard** e escolha **Force refresh dashboard**. Os detalhes completos, incluindo durante quanto tempo os resultados são mantidos, estão em [Cache dos painéis de controlo](/pt-pt/guides/dashboards/dashboard-caching/).
