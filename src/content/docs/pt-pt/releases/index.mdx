## Como são produzidas estas notas

Cada resumo mensal agrega as alterações substanciais disponibilizadas nos tenants durante esse mês civil. O trabalho puramente de infraestrutura (atualizações de imagens, refatorações internas, cortes de RC, rotação de segredos, afinação da observabilidade) é agrupado em etiquetas de tema em vez de listado linha a linha. Se um mês teve funcionalidades visíveis para os clientes, estas são destacadas explicitamente com uma estrutura Adicionado / Alterado / Corrigido / Segurança.

Para obter detalhes sobre uma versão em particular, contacte a sua equipa de conta.

De futuro, cada novo resumo mensal fica aqui disponível assim que é publicado.
