## Alterado

- **A documentação interativa da API passa a estar em cada tenant** — a Swagger UI, anteriormente disponibilizada a partir de um caminho central da documentação, está agora incorporada na instância de cada tenant. Aceda-lhe através da sua área de trabalho em vez de um URL separado.
- **PlaidLink atualizado** — foi distribuída uma nova compilação do PlaidLink; as instalações existentes continuam a funcionar, pelo que pode atualizar quando for conveniente.

## Adicionado

- **Base para o suporte a agentes de programação com IA** — a ligação inicial de ingress para os caminhos `/mcp` e `/.well-known/oauth-*` foi concluída este mês, permitindo as integrações MCP que passaram a estar visíveis para os utilizadores em maio.
- **Testes do StarRocks 4.1 (Lakehouse v2)** — o motor Lakehouse de nova geração está a ser validado com cargas de trabalho reais. Ainda sem alterações visíveis para os clientes; migrações opcionais a chegar mais tarde.
