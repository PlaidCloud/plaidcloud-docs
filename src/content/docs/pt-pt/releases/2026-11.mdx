## Adicionado

- **Os assistentes de IA podem anular a publicação de uma tabela e definir o público predefinido dos painéis de controlo de um projeto.** `publish_manage` anula a publicação de uma tabela juntamente com a respetiva vista publicada e qualquer conjunto de dados de painel de controlo que nenhum gráfico utilize; um conjunto de dados que um gráfico ainda utilize mantém-se, tal como a vista e o conjunto de dados quando uma vista de relatório é construída sobre a vista publicada, embora a publicação da tabela seja anulada. `project_upsert` define `dashboard_default_audience`, os grupos com quem são partilhados os novos painéis de controlo do projeto, e `[]` limpa-o. Consulte [Anular a publicação](/pt-pt/guides/data/publish/#anular-a-publicação-através-do-assistente-de-ia-ou-do-mcp) e [Definir o público predefinido através do assistente de IA ou do MCP](/pt-pt/guides/dashboards/control-who-can-see-a-dashboard/#definir-o-público-alvo-predefinido-através-do-assistente-de-ia-ou-do-mcp).

## Alterado

- **Os Arquitetos do projeto veem todas as linhas das tabelas com restrição de linhas nos painéis de controlo**, tal como veem no Analyze. Retirar o acesso de Arquiteto produz efeito imediato nos painéis de controlo — quer se altere a função de alguém, se remova essa pessoa ou o seu grupo do projeto, se altere o tipo de acesso do projeto, se restaure uma versão anterior do projeto ou se elimine um grupo de segurança. Um antigo Arquiteto deixa de ver todas as linhas dos dados com restrição de linhas. Consulte [Gerir o acesso a linhas](/pt-pt/administration/access/managing-security-groups-and-assignments/#gerir-o-acesso-a-linhas).
- **Uma ligação de painel de controlo aberta depois de a sessão ter expirado leva ao painel de controlo em questão assim que iniciar sessão.** Consulte [Utilizar painéis de controlo](/pt-pt/guides/dashboards/using-dashboards/).
- **As ferramentas MCP recusam um campo que não reconhecem** e indicam-no no erro, em vez de o ignorarem. `workflow_upsert` aceita `memo` e aceita `description` como outro nome para o mesmo campo. Consulte [Os campos desconhecidos são recusados](/pt-pt/integrations/ai-coding-agents/getting-started/#campos-desconhecidos-são-recusados).

## Corrigido

- **As definições de projeto inválidas são comunicadas com uma mensagem clara.** Um ambiente ou conta de documentos desconhecido, um slug que já está em uso ou reservado, ou um tipo de armazenamento ou modo de lançamento inválido devolve agora uma mensagem que identifica o problema, em vez de um erro genérico do servidor. Através da API REST, isto é um 400 em vez de um 500 e, através do assistente de IA ou do MCP, é um erro de argumento inválido.
