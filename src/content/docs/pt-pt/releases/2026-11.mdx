## Adicionado

- **Pré-visualização nos formulários dos passos.** Importar: SQL, Executar: SQL, Extrair: SQL, Exportar: SQL e Consulta Salesforce mostram até 100 linhas sem executar o passo, e as leituras de vistas e listas do Anaplan mostram as colunas e os tipos que produziriam. Clique em **Pré-visualização** no separador **Origem**. As variáveis são preenchidas tal como a execução as preencheria, mas os formatos de variável como `{x:>9}` não são suportados. A pré-visualização só executa funções SQL padrão; caso contrário, indica que deve executar o passo. Não está disponível em projetos bloqueados, nem para o passo Execute SQL baseado em agente. Consulte [Importar SQL](/pt-pt/reference/workflow-steps/import/import-sql/) e [Extrair SQL](/pt-pt/reference/workflow-steps/tables/table-extract-sql/).
- **Os assistentes de IA podem anular a publicação de uma tabela e definir o público predefinido dos painéis de controlo de um projeto.** `publish_manage` anula a publicação de uma tabela juntamente com a respetiva vista publicada e qualquer conjunto de dados de painel de controlo que nenhum gráfico utilize; um conjunto de dados que um gráfico ainda utilize mantém-se, tal como a vista e o conjunto de dados quando uma vista de relatório é construída sobre a vista publicada, embora a publicação da tabela continue a ser anulada. `project_upsert` define `dashboard_default_audience`, os grupos com os quais os novos painéis de controlo do projeto são partilhados, e `[]` limpa-o. Consulte [Anular a publicação](/pt-pt/guides/data/publish/#anular-a-publicação-através-do-assistente-de-ia-ou-do-mcp) e [Definir o público predefinido através do assistente de IA ou MCP](/pt-pt/guides/dashboards/control-who-can-see-a-dashboard/#definir-o-público-alvo-predefinido-através-do-assistente-de-ia-ou-do-mcp).

- **A voz no Weave em dispositivos móveis requer apenas um toque.** Toque no microfone, faça a sua pergunta e o Weave envia-a assim que parar de falar. Toque novamente no microfone para parar mais cedo; o microfone desliga-se sozinho se não for detetado som. Se sair do separador **Weave** ou colocar a aplicação em segundo plano a meio de uma frase, as suas palavras ficam na caixa da pergunta, por enviar, para que as possa rever. Executar, Pausar, Parar e Retomar ignoram um duplo toque acidental na respetiva confirmação. Requer a versão 1.3.0 ou posterior da aplicação. Consulte [Utilizar a voz](/pt-pt/guides/mobile-app/weave-on-mobile/#utilizar-a-voz).

## Alterado

- **Os formulários dos passos seguem um esquema comum.** Os separadores têm nomes padrão numa ordem padrão: Geral, Definições, Origem, Colunas, Filtros, Saída e Avançado, com Colunas de cabeçalho e Colunas de linha nos formulários de lançamento em ERP. Os campos obrigatórios estão assinalados com *, e um formulário só impede a gravação pelo que o passo necessita.
- **O menu de ações da linha (⋯) encontra-se na margem esquerda de cada linha da grelha.**
- **Os passos de escrita em ERP guardados sem definição de validação abrem como apenas validação.** Isto abrange SAP Post, SAP Attach, NetSuite Post, Oracle EBS GL e AP Post, e a exportação para Xero. Os passos explicitamente definidos para execução real mantêm-se em execução real.
- **As tarefas de longa duração mostram o progresso da mesma forma em todo o lado.**
- **Os passos REST, Import REST e Import Postman são convertidos em Pedido REST quando a área de trabalho é atualizada.** Um passo que não possa ser convertido corretamente mantém-se como estava. Consulte [Passo Pedido REST](/pt-pt/guides/workflows/rest-request-step/).
- **Os Arquitetos do projeto veem todas as linhas das tabelas com acesso restrito a linhas nos painéis de controlo**, tal como veem no Analyze. A remoção do acesso de Arquiteto produz efeito imediato nos painéis de controlo — quer altere a função de alguém, remova essa pessoa ou o respetivo grupo do projeto, altere o tipo de acesso do projeto, restaure uma versão anterior do projeto ou elimine um grupo de segurança. Um antigo Arquiteto deixa de ver todas as linhas dos dados com acesso restrito a linhas. Consulte [Gerir o acesso às linhas](/pt-pt/administration/access/managing-security-groups-and-assignments/#gerir-o-acesso-a-linhas).
- **Uma ligação para um painel de controlo aberta depois de a sessão ter expirado leva-o a esse painel de controlo assim que inicia sessão.** Consulte [Utilizar painéis de controlo](/pt-pt/guides/dashboards/using-dashboards/).
- **As ferramentas MCP recusam um campo que não reconhecem** e indicam-no no erro, em vez de o ignorarem. `workflow_upsert` aceita `memo` e aceita `description` como outro nome para o mesmo. Consulte [Os campos desconhecidos são recusados](/pt-pt/integrations/ai-coding-agents/getting-started/#campos-desconhecidos-são-recusados).
- **No Lakehouse v2, o lakehouse escreve ele próprio as exportações Parquet para o Google Cloud Storage.** Uma exportação para uma conta de documentos Google Cloud Storage vai diretamente para o contentor da conta, escrita com as credenciais da própria conta, em vez de todas as linhas passarem primeiro pelo PlaidCloud. As exportações para contas Amazon S3 e Azure Blob Storage funcionam como antes. Consulte [Passo Export to Parquet](/pt-pt/reference/workflow-steps/export/export-to-parquet/).

## Corrigido

- **As definições de projeto inválidas são comunicadas com uma mensagem clara.** Um ambiente ou uma conta de documentos desconhecidos, um slug já utilizado ou reservado, ou um tipo de armazenamento ou modo de lançamento inválido devolvem agora uma mensagem que identifica o problema em vez de um erro genérico do servidor. Através da API REST, trata-se de um erro 400 em vez de 500 e, através do assistente de IA ou MCP, de um erro de argumento inválido.
- **O pedido de valores de dimensão da API REST funciona.** `POST /rest/v1/analyze/query/retrieve-dimension-values` era tratado como um pedido de grelha e recusado por ser inválido. Agora devolve um valor agregado para cada coluna em `value_columns`, e uma grelha, com um valor para cada par de filtro de linha e filtro de coluna, tem o seu próprio `POST /rest/v1/analyze/query/retrieve-dimension-cells`.
- **As leituras lentas de tabelas e o processamento de ficheiros deixaram de atrasar outros pedidos.** Ler as colunas de uma tabela a partir do armazém de dados, registar um ficheiro do Data Foundation, exportar para Excel, ler a resposta de uma importação REST ou SOAP, localizar onde uma conta de documentos é utilizada e verificar o código ou o logótipo de uma aplicação Panel podiam, cada um, suspender todos os outros pedidos que o mesmo servidor estava a processar até terminarem. Agora são executados em paralelo com esses pedidos.
- **As caixas de diálogo de variáveis de projeto e de fluxo de trabalho permitem deslocamento.** Num ecrã pequeno ou com baixa resolução, a caixa de diálogo de adicionar e editar era mais alta do que a janela, pelo que os botões **Criar** e **Atualizar** podiam ficar fora de alcance. O formulário permite agora deslocamento e os botões mantêm-se na parte inferior.
- **Os ficheiros com mais de 256 MiB numa conta de documentos Azure Blob Storage podem ser copiados, movidos e renomeados.** Cada uma destas ações falhava num ficheiro desse tamanho, tal como mover ou mudar o nome de uma pasta que contivesse um.

## Segurança

- **Só os proprietários de uma conta podem restaurar as respetivas versões anteriores.** Restaurar uma conta de documentos para uma versão anterior, reter ou libertar uma versão e criar uma cópia de segurança passam a exigir que seja um dos proprietários da conta, e nenhuma destas ações está disponível numa conta gerida pelo sistema. Ver o histórico de versões de uma conta requer acesso à conta.
