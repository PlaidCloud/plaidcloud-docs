## Adicionado

- **Pré-visualização nos formulários de passos.** Os passos Importar: SQL, Execute: SQL, Extrair: SQL, Exportar: SQL e Salesforce Query mostram até 100 linhas sem executar o passo, e as leituras de vistas e listas do Anaplan mostram as colunas e os tipos que produziriam. Clique em **Pré-visualização** no separador **Origem**. As variáveis são preenchidas como a execução as preencheria, mas os formatos de variáveis como `{x:>9}` não são suportados. A pré-visualização só executa funções SQL padrão; caso contrário, indica que deve executar o passo. Não está disponível em projetos bloqueados, nem no passo Execute SQL baseado em agente. Consulte [Importar SQL](/pt-pt/reference/workflow-steps/import/import-sql/) e [Extrair SQL](/pt-pt/reference/workflow-steps/tables/table-extract-sql/).
- **Os assistentes de IA podem anular a publicação de uma tabela e definir o público predefinido dos painéis de controlo de um projeto.** `publish_manage` anula a publicação de uma tabela juntamente com a respetiva vista publicada e qualquer conjunto de dados de painel de controlo que nenhum gráfico utilize; um conjunto de dados que um gráfico ainda utiliza permanece, tal como a vista e o conjunto de dados quando uma vista de relatório é criada sobre a vista publicada, embora a tabela deixe de estar publicada. `project_upsert` define `dashboard_default_audience`, os grupos com quem são partilhados os novos painéis de controlo do projeto, e `[]` limpa-o. Consulte [Anular a publicação](/pt-pt/guides/data/publish/#anular-a-publicação-através-do-assistente-de-ia-ou-do-mcp) e [Definir o público predefinido através do assistente de IA ou do MCP](/pt-pt/guides/dashboards/control-who-can-see-a-dashboard/#definir-o-público-alvo-predefinido-através-do-assistente-de-ia-ou-do-mcp).

- **A voz no Weave em dispositivos móveis requer um único toque.** Toque no microfone, faça a pergunta e o Weave envia-a quando parar de falar. Toque novamente no microfone para parar antecipadamente; este desliga-se sozinho se não ouvir nada. Se sair do separador **Weave** ou passar a aplicação para segundo plano a meio da frase, as suas palavras permanecem na caixa da pergunta sem serem enviadas, para que possa revê-las. Executar, Pausar, Parar e Retomar ignoram um toque duplo acidental na respetiva confirmação. Requer a versão 1.3.0 ou posterior da aplicação. Consulte [Utilizar a voz](/pt-pt/guides/mobile-app/weave-on-mobile/#utilizar-a-voz).

## Alterado

- **Os formulários de passos seguem um único esquema.** Os separadores têm nomes padrão numa ordem padrão: Geral, Definições, Origem, Colunas, Filtros, Saída e Avançadas, com Colunas de cabeçalho e Colunas de linha nos formulários de lançamento ERP. Os campos obrigatórios são marcados com *, e um formulário só impede a gravação pelo que o passo necessita.
- **O menu de ações da linha (⋯) está na extremidade esquerda de cada linha da grelha.**
- **Os passos de escrita ERP guardados sem definição de validação abrem como apenas de validação.** Isto abrange SAP Post, SAP Attach, NetSuite Post, Oracle EBS GL e AP Post, e a exportação para o Xero. Os passos explicitamente definidos para execução em direto continuam em direto.
- **As tarefas de longa duração mostram o progresso da mesma forma em todo o lado.**
- **Os passos REST, Import REST e Import Postman são convertidos em Pedido REST quando a sua área de trabalho é atualizada.** Um passo que não possa ser convertido de forma limpa permanece como estava. Consulte [Passo Pedido REST](/pt-pt/guides/workflows/rest-request-step/).
- **Os Arquitetos de projeto veem todas as linhas das tabelas com restrição de linhas nos painéis de controlo**, de acordo com o que veem no Analyze. A remoção do acesso de Arquiteto tem efeito imediato nos painéis de controlo — quer altere a função de alguém, remova essa pessoa ou o respetivo grupo do projeto, altere o tipo de acesso do projeto, restaure uma versão anterior do projeto ou elimine um grupo de segurança. Um antigo Arquiteto deixa de ver todas as linhas dos dados com restrição de linhas. Consulte [Gerir o acesso a linhas](/pt-pt/administration/access/managing-security-groups-and-assignments/#gerir-o-acesso-a-linhas).
- **Uma ligação de painel de controlo aberta depois de a sessão ter expirado leva-o a esse painel de controlo assim que iniciar sessão.** Consulte [Utilizar painéis de controlo](/pt-pt/guides/dashboards/using-dashboards/).
- **As ferramentas MCP recusam um campo que não reconhecem** e indicam o seu nome no erro, em vez de o ignorarem. `workflow_upsert` aceita `memo` e aceita `description` como outro nome para o mesmo campo. Consulte [Os campos desconhecidos são recusados](/pt-pt/integrations/ai-coding-agents/getting-started/#campos-desconhecidos-são-recusados).

## Corrigido

- **As definições de projeto inválidas são comunicadas com uma mensagem clara.** Um ambiente ou uma conta de documentos desconhecidos, um slug já utilizado ou reservado, ou um tipo de armazenamento ou modo de lançamento inválidos devolvem agora uma mensagem que indica o problema em vez de um erro genérico do servidor. Através da API REST é um 400 em vez de um 500 e, através do assistente de IA ou do MCP, é um erro de argumento inválido.
- **O pedido de valores de dimensão da API REST funciona.** `POST /rest/v1/analyze/query/retrieve-dimension-values` era tratado como um pedido de grelha e recusado como inválido. Agora devolve um valor agregado para cada coluna em `value_columns`, e uma grelha, com um valor para cada par formado por um filtro de linha e um filtro de coluna, tem o seu próprio pedido, `POST /rest/v1/analyze/query/retrieve-dimension-cells`.
- **As leituras lentas de tabelas e o processamento de ficheiros já não atrasam outros pedidos.** Ler as colunas de uma tabela a partir do armazém de dados, registar um ficheiro do Data Foundation, exportar para Excel, ler a resposta de uma importação REST ou SOAP, localizar onde uma conta de documentos é utilizada e verificar o código ou o logótipo de uma aplicação Panel podiam, cada um, suspender todos os outros pedidos que o mesmo servidor estivesse a processar até terminar. Agora são executados em paralelo com esses pedidos.

## Segurança

- **Só os proprietários de uma conta podem restaurar as respetivas versões anteriores.** Restaurar uma conta de documentos para uma versão anterior, reter ou libertar uma versão e fazer uma cópia de segurança exigem agora que seja um dos proprietários da conta, e nenhuma destas ações está disponível numa conta gerida pelo sistema. Consultar o histórico de versões de uma conta requer acesso à conta.
