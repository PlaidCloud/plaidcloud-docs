O Arrow Flight SQL recebe uma instrução SQL e devolve o resultado em fluxo, em Arrow. Adequa-se às ferramentas de dados em Python, a clientes SQL como o DBeaver e ao Tableau Desktop. Envia uma instrução só de leitura sobre as tabelas do projeto, e o PlaidCloud filtra cada tabela lida para as linhas que o proprietário do cliente pode ver antes de a executar. Antes de se ligar, crie um cliente de feed de BI e adicione-o ao projeto; consulte [Ligar ferramentas de BI](/pt-pt/integrations/bi-tools/).

## Detalhes da ligação

| Definição | Valor |
| --- | --- |
| Ponto final | `grpc+tls://flightsql.<workspace host>:443` |
| URL JDBC | `jdbc:arrow-flight-sql://flightsql.<workspace host>:443/?useEncryption=true&project_id=<project id>` |
| Nome de utilizador | O ID do cliente |
| Palavra-passe | O segredo do cliente |
| Projeto | `project_id`: parte do URL JDBC, ou a opção ADBC `adbc.flight.sql.rpc.call_header.project_id` |

O **URL JDBC** do projeto está no cartão **Clientes de feed de BI** da respetiva página **Acesso e partilha**, pronto a copiar. A ligação é sempre cifrada, na porta 443.

Uma ligação lê um projeto. Para ler outro, ligue-se novamente com o ID desse projeto.

## Python

Instale o controlador ADBC Flight SQL com `pip install adbc-driver-flightsql pyarrow` e ligue-se com o ID e o segredo do cliente, aqui lidos de variáveis de ambiente:

```python
import os

import adbc_driver_flightsql.dbapi as flightsql

with flightsql.connect(
    "grpc+tls://flightsql.<workspace host>:443",
    db_kwargs={
        "username": os.environ["PLAIDCLOUD_CLIENT_ID"],
        "password": os.environ["PLAIDCLOUD_CLIENT_SECRET"],
        "adbc.flight.sql.rpc.call_header.project_id": "<project id>",
    },
    autocommit=True,
) as connection, connection.cursor() as cursor:
    cursor.execute(
        'SELECT region, SUM(amount) AS total FROM "Sales" WHERE fiscal_year = ? GROUP BY region',
        parameters=(2024,),
    )
    sales = cursor.fetch_arrow_table()
```

O feed não executa transações, por isso ligue-se com `autocommit=True`. `sales` é uma tabela Arrow:

- **pandas:** `sales.to_pandas()`
- **polars:** `polars.from_arrow(sales)`
- **DuckDB:** consulte-a pelo nome, como em `duckdb.sql("SELECT * FROM sales")`

Para um resultado grande, `cursor.fetch_record_batch()` lê-o um lote de cada vez, em vez de tudo de uma só vez.

## DBeaver

O DBeaver não inclui o controlador Apache Arrow Flight SQL, por isso adicione-o uma vez:

1. Escolha **Base de dados** > **Driver Manager** > **Novo**.
2. Dê um nome ao controlador, por exemplo `Arrow Flight SQL`, e defina **Class Name** como `org.apache.arrow.driver.jdbc.ArrowFlightJdbcDriver`.
3. Em **Libraries**, escolha **Add Artifact** e introduza `org.apache.arrow:flight-sql-jdbc-driver`, ou escolha **Adicionar ficheiro** e selecione o ficheiro `.jar` do controlador. Escolha **OK**.

Depois, ligue-se:

1. Escolha **Base de dados** > **New Database Connection** e selecione o controlador que adicionou.
2. Ligue-se por **URL**: cole o **URL JDBC** do projeto e introduza o ID do cliente como nome de utilizador e o segredo como palavra-passe.
3. Escolha **Finish**. As tabelas do projeto estão no esquema `plaid`.

No seu próprio programa Java, inicie o Java com `--add-opens=java.base/java.nio=ALL-UNNAMED`. Sem esta opção, o controlador liga-se e executa instruções simples, mas uma instrução com parâmetros `?` falha com `sun.misc.Unsafe or java.nio.DirectByteBuffer.<init>(long, int) not available`. O DBeaver já arranca com essa opção.

## Tableau Desktop e Tableau Server

1. Transfira o controlador JDBC Apache Arrow Flight SQL (`flight-sql-jdbc-driver`, um ficheiro `.jar`) e coloque-o na pasta de controladores do Tableau: `C:\Program Files\Tableau\Drivers` no Windows, ou `~/Library/Tableau/Drivers` num Mac. Depois, reinicie o Tableau.
2. Em **Ligar**, escolha **To a Server** > **Other Databases (JDBC)**.
3. Introduza o **URL JDBC** do projeto como **URL**, escolha **PostgreSQL** como **Dialect**, introduza o ID e o segredo do cliente como **Nome de utilizador** e **Palavra-passe**, e escolha **Sign In**.
4. As tabelas do projeto estão no esquema `plaid`.

Para atualizar um livro ou uma origem de dados publicados, o Tableau Server precisa do mesmo controlador instalado na sua própria pasta de controladores.

## O SQL que pode enviar

O feed lê SQL ao estilo PostgreSQL e aceita uma instrução só de leitura de cada vez:

- **Uma instrução:** um `SELECT`, um `WITH … SELECT`, ou um `UNION`, `INTERSECT` ou `EXCEPT` destes. Um `WITH` recursivo é recusado.
- **As tabelas do projeto, pelo nome:** escreva o nome de uma tabela sozinho, ou no esquema `plaid`, como em `plaid."Sales"`. Qualquer outro esquema ou catálogo é recusado.
- **Aspas:** um nome sem aspas corresponde independentemente das maiúsculas e minúsculas, pelo que `sales` corresponde a `Sales`. Um nome entre aspas tem de corresponder exatamente; coloque entre aspas um nome com espaços ou pontuação, como em `"Sales 2024"` ou `"Cost Center Name"`.
- **As cláusulas habituais:** junções, subconsultas, `GROUP BY`, `HAVING`, `ORDER BY`, `LIMIT`, `OFFSET`, `FETCH`, `DISTINCT`, `CASE`, `CAST` e funções de janela.
- **Funções:** as funções comuns de texto, números, datas, agregação e janela, incluindo `UPPER`, `LOWER`, `TRIM`, `SUBSTRING`, `REPLACE`, `CONCAT`, `ROUND`, `ABS`, `COALESCE`, `NULLIF`, `EXTRACT`, `DATE_TRUNC`, `CURRENT_DATE`, `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `ROW_NUMBER`, `RANK`, `LAG` e `LEAD`.
- **Parâmetros:** marcadores `?`, a cada um dos quais é atribuído um número, texto, verdadeiro ou falso, uma data, um carimbo de data/hora, ou NULL.
- **Comprimento:** até 65 536 carateres, com os respetivos parâmetros escritos.

Os valores vazios são ordenados da forma como o armazém de dados do projeto os ordena. Escreva `NULLS FIRST` ou `NULLS LAST` quando a ordem for importante.

Coloque entre aspas uma coluna com o nome de uma palavra que um armazém de dados conhece a respeito da sessão ou do relógio, como em `"user"` ou `"current_date"`. Sem aspas, a palavra pode não ler a sua coluna: o feed pode recusá-la, ou o armazém de dados pode ler o valor da própria sessão, tal como `current_date` lê a data de hoje. `user`, `system_user`, `current_role`, `current_database`, `sysdate` e `systimestamp` são sempre recusados sem aspas, com uma mensagem a pedir que os coloque entre aspas.

O feed recusa tudo o que escreve ou bloqueia (`INSERT`, `UPDATE`, `DELETE`, `MERGE`, `SELECT … INTO`), `VALUES`, `UNNEST`, `LATERAL`, a leitura de ficheiros, o time travel, `TABLESAMPLE`, `PIVOT` e qualquer função fora da sua lista. Uma recusa começa por "Nothing was run:" e indica o que recusou, para que possa reescrever essa parte.

<Aside type="note">
Cada tabela lida por uma instrução, seja diretamente, numa junção, numa subconsulta ou num `WITH`, é filtrada para as linhas que o proprietário do cliente pode ler antes de o resto da instrução a ver.
</Aside>

## O que os clientes veem

- **Esquema:** um esquema, `plaid`, sem catálogo.
- **Tabelas:** as tabelas do projeto apresentadas à função de acesso do cliente, pelos nomes que têm no projeto. Dois nomes que diferem apenas nas maiúsculas e minúsculas recebem cada um um sublinhado e um código curto criado a partir da respetiva tabela. As vistas não estão incluídas.
- **Colunas:** pelos nomes que têm no projeto, espaços incluídos, como em `"FULL YEAR"` ou `"Cost Center Name"`. Isto difere do OData, que mostra `FULL_YEAR`.
- **Chaves:** as chaves de atualização de uma tabela são a sua chave primária, e uma tabela sem chaves não tem chave primária. As tabelas não têm chaves estrangeiras.

Os carimbos de data/hora chegam em UTC.

## Limites e mensagens

Não há limite de linhas: um resultado é enviado em fluxo até terminar. As mensagens de início de sessão estão listadas em [Ligar ferramentas de BI](/pt-pt/integrations/bi-tools/#quando-uma-ferramenta-não-consegue-iniciar-sessão-ou-não-vê-tabelas). Estas são específicas do Flight SQL:

| Mensagem | O que fazer |
| --- | --- |
| Name the project to read with the project_id connection property … | Adicione `project_id` ao URL JDBC, ou defina a opção ADBC `adbc.flight.sql.rpc.call_header.project_id`. |
| This session reads another project. Connect again to read this one. | Uma ligação lê um projeto. Abra outra ligação para o outro projeto. |
| This session has ended. Connect again. | A sessão de uma ligação termina após 8 horas sem utilização, e 24 horas depois de ter começado. Ligue-se novamente. |
| This client was disabled or its secret has changed since this session began. Connect again. | Ligue-se novamente com o segredo atual. Se o cliente foi desativado, ative-o primeiro. Um cliente eliminado, ou cujo proprietário tenha a conta desativada, não se pode ligar. |
| The statement ran past the gateway's 3,600-second limit and was stopped. | Uma instrução pode ser executada durante uma hora, no máximo. Filtre-a ou agregue-a para devolver menos. |
| Nothing was run: … | A instrução contém algo que o feed não aceita; consulte [O SQL que pode enviar](#o-sql-que-pode-enviar). |
| The warehouse could not run the statement: … | O armazém de dados do projeto recusou a instrução, pelo motivo indicado. |
