O [modo de agente](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) do GitHub Copilot no VSCode suporta servidores MCP através de um `.vscode/mcp.json` ao nível da área de trabalho ou do utilizador (área de trabalho) ou do `mcp.json` global do VSCode (utilizador).

<Aside type="note">Procura o **Microsoft 365 Copilot** — o assistente no Teams e na aplicação Microsoft 365 — em vez do GitHub Copilot no seu IDE? Consulte [Microsoft 365 Copilot](/pt-pt/integrations/microsoft-365-copilot/).</Aside>

Também pode aceder a estes passos a partir da própria janela **Ligue a sua IA** do PlaidCloud (no menu do avatar) — encontre o GitHub Copilot no separador **Outro**, junto ao Gemini CLI e ao Codex CLI.

<Aside>O suporte MCP do Copilot depende do escalão do plano do Copilot e da definição `chat.mcp.enabled` no VSCode. Certifique-se de que ambos estão ativados antes de configurar servidores.</Aside>

## Configuração

1. Obtenha um token de portador visitando `https://<your-workspace>.plaid.cloud/mcp/setup/token` num navegador onde tenha iniciado sessão no PlaidCloud.

2. No VSCode, abra a paleta de comandos e execute **MCP: Add Server**, ou crie diretamente o `.vscode/mcp.json`:

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Volte a carregar o VSCode. Abra o painel de conversa do Copilot, mude a lista pendente de modo para **Agente** e confirme que as ferramentas do PlaidCloud aparecem na lista de ferramentas (normalmente apresentadas como `plaidcloud_*`).

## Utilização

Peça ao Copilot que execute diretamente operações do PlaidCloud:

- "Find all workflows in project `Q4 Forecast` whose last run failed."
- "Show me the schema of table `customers` and suggest indexes."
- "Run the `daily-load` workflow and report the run status."

O Copilot escolhe a ferramenta adequada, executa-a e cita os resultados na resposta. Nas operações destrutivas (eliminar, organizar, upsert sem `dry_run`), normalmente pede confirmação — reveja a ação planeada antes de aprovar.

## Atualizar o token

O VSCode lê o `.vscode/mcp.json` ao iniciar e quando o ficheiro é alterado. Quando o token expirar, volte a carregar `https://<your-workspace>.plaid.cloud/mcp/setup/token` e substitua o valor de `Authorization` — o VSCode volta a carregar o servidor automaticamente.

## Restringir a ferramentas específicas

Se pretender limitar as ferramentas do PlaidCloud que o Copilot pode chamar, utilize a lista de ferramentas permitidas por servidor do VSCode (Settings → Copilot → MCP → seleção de ferramentas específica do servidor). Isto é útil para sessões só de leitura ou para manter as ferramentas que alteram dados (`*_upsert`, `*_run`) protegidas por uma reativação explícita.
