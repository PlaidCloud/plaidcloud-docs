O [modo de agente](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) do GitHub Copilot no VSCode suporta servidores MCP através de um `.vscode/mcp.json` ao nível da área de trabalho ou do utilizador (área de trabalho) ou do `mcp.json` global do VSCode (utilizador).

<Aside type="note">Procura o **Microsoft 365 Copilot** — o assistente no Teams e na aplicação Microsoft 365 — em vez do GitHub Copilot no seu IDE? Consulte [Microsoft 365 Copilot](/pt-pt/integrations/microsoft-365-copilot/).</Aside>

Pode também chegar a estes passos a partir da janela **Ligue a sua IA** do próprio PlaidCloud — encontre o GitHub Copilot no separador **Outro**, junto ao Gemini CLI e ao Codex CLI.

<Aside>O suporte de MCP do Copilot depende do escalão do plano do Copilot e da definição `chat.mcp.enabled` no VSCode. Certifique-se de que ambos estão ativados antes de configurar servidores.</Aside>

## Configuração

1. Obtenha um token de portador visitando `https://<your-workspace>.plaid.cloud/mcp/setup/token` num navegador em que tenha sessão iniciada no PlaidCloud.

2. No VSCode, abra a paleta de comandos e execute **MCP: Add Server**, ou crie diretamente `.vscode/mcp.json`:

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Recarregue o VSCode. Abra o painel de conversação do Copilot, mude a lista pendente de modo para **Agent** e confirme que as ferramentas do PlaidCloud aparecem na lista de ferramentas (normalmente apresentadas como `plaidcloud_*`).

## Utilização

Peça ao Copilot que execute operações do PlaidCloud diretamente:

- "Encontra todos os fluxos de trabalho do projeto `Q4 Forecast` cuja última execução falhou."
- "Mostra-me o esquema da tabela `customers` e sugere índices."
- "Executa o fluxo de trabalho `daily-load` e indica o estado da execução."

O Copilot escolhe a ferramenta adequada, executa-a e cita os resultados na sua resposta. Nas operações destrutivas (eliminar, organizar, upsert sem `dry_run`), normalmente pede confirmação — reveja a ação planeada antes de aprovar.

## Atualizar o token

O VSCode lê `.vscode/mcp.json` no arranque e quando o ficheiro muda. Quando o token expirar, recarregue `https://<your-workspace>.plaid.cloud/mcp/setup/token` e substitua o valor de `Authorization` — o VSCode recarrega o servidor automaticamente.

## Restringir a ferramentas específicas

Se quiser limitar as ferramentas do PlaidCloud que o Copilot pode chamar, utilize a lista de ferramentas permitidas por servidor do VSCode (Definições → Copilot → MCP → seleção de ferramentas específica do servidor). Isto é útil em sessões só de leitura ou para manter as ferramentas que alteram dados (`*_upsert`, `*_run`) protegidas por uma reativação explícita.
