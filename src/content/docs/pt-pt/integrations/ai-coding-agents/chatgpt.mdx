O suporte do ChatGPT para servidores MCP adicionados pelo utilizador ainda está a ser disponibilizado e varia consoante o escalão do plano e a superfície. Esta página descreve o que funciona atualmente.

## ChatGPT Pro / Plus / Team — Conectores

Se o seu plano do ChatGPT disponibiliza a IU de **Conectores** (Definições → Conectores), pode adicionar o PlaidCloud como conector MCP personalizado:

1. Aceda a **Definições → Conectores → Adicionar conector personalizado**.
2. Introduza:
   - **Nome**: `PlaidCloud`
   - **URL do servidor MCP**: `https://<your-workspace>.plaid.cloud/mcp`
3. O ChatGPT redireciona-o para o PlaidCloud para o início de sessão OAuth. Depois de iniciar sessão, o PlaidCloud mostra uma página de **Pedido de acesso da aplicação** que indica a aplicação requerente e o URI de redirecionamento para o qual enviará as credenciais — verifique se estes correspondem ao ChatGPT antes de aprovar.
4. Ative o conector em qualquer conversa que deva poder utilizá-lo.

<Aside>A IU de Conectores pode não estar visível em todas as contas ou regiões. Se não vir "Adicionar conector personalizado", o seu plano ou a política da área de trabalho não permite atualmente servidores MCP adicionados pelo utilizador — utilize a alternativa abaixo.</Aside>

## ChatGPT Enterprise

Os administradores Enterprise podem fixar conectores MCP ao nível da área de trabalho através da consola de administração. Siga a mesma configuração OAuth acima, mas conte com um passo de aprovação da área de trabalho pelo seu administrador antes de o conector ficar utilizável.

## Alternativa — GPT personalizados com ações REST

Se a sua conta não suporta conectores MCP personalizados, pode ainda assim conduzir o PlaidCloud a partir do ChatGPT através de um **GPT personalizado** que chama a API REST do PlaidCloud como Ação OpenAPI:

1. A superfície REST do PlaidCloud é descrita pelo documento OpenAPI em `https://<your-tenant>.plaidcloud.org/openapi_rest.json`.
2. No ChatGPT, crie um GPT personalizado (Explorar GPT → Criar) e, em **Ações**, importe esse URL (ou cole o JSON).
3. Configure a autenticação como **OAuth** e aponte para os endpoints do Keycloak do PlaidCloud. O administrador do PlaidCloud pode fornecer os URL do realm e o ID do cliente.

Isto troca as convenções de nomes de ferramentas do MCP por endpoints REST diretos — um pouco mais verboso para o modelo navegar, mas funcionalmente equivalente para as operações de leitura/escrita que o PlaidCloud expõe.

## Porque é que o MCP nem sempre está disponível

O suporte de MCP da OpenAI continua a evoluir e as superfícies disponíveis (IU de Conectores, esquema de Ações, etc.) mudam entre escalões de planos e ao longo do tempo. Se o caminho oficial dos **Conectores** estiver aberto na sua conta, prefira-o — tem atualização OAuth integrada e uma experiência de chamada de ferramentas alinhada com o resto desta secção. Recorrer às Ações de GPT personalizado só é necessário quando o MCP ainda não está disponível na sua conta.
