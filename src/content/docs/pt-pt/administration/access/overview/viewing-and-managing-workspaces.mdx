As áreas de trabalho permitem que uma organização funcione como o seu próprio serviço baseado na nuvem, tanto para organizações pequenas como grandes. Por exemplo, as equipas pequenas podem ter uma única área de trabalho na organização, enquanto as organizações grandes podem ter centenas de áreas de trabalho especializadas.



As áreas de trabalho gerem o acesso e a visibilidade, ao mesmo tempo que proporcionam espaços isolados para os membros de uma organização trabalharem. O acesso às áreas de trabalho é atribuído aos membros num ambiente privado e multi-inquilino da organização. Com as áreas de trabalho, as equipas podem colaborar em projetos abertos em algumas áreas de trabalho, mantendo uma confidencialidade rigorosa noutras.



Como as áreas de trabalho estão totalmente isoladas, os dados não podem ser partilhados nem acedidos diretamente entre áreas de trabalho. No entanto, as áreas de trabalho podem aceder à mesma área de documentos partilhada, pelo que é possível partilhar ficheiros entre áreas de trabalho, se pretendido.



## Ver e gerir áreas de trabalho


Ver e gerir as áreas de trabalho de uma organização é simples. Tem de ser proprietário da organização para gerir áreas de trabalho. Para ver e gerir áreas de trabalho:


1. Selecione “Organization Settings” no menu no canto superior direito do navegador
2. Clique em “Workspaces”

Será apresentada uma tabela com todas as áreas de trabalho atuais da organização. A partir daqui, pode criar, atualizar, suspender e eliminar áreas de trabalho, adicionar aplicações às áreas de trabalho e gerir o acesso dos membros a cada área de trabalho.



### Criar uma área de trabalho


1. Selecione “Organization Settings” no menu no canto superior direito do navegador
2. Clique em “Workspaces”
3. Clique no botão “New Workspace”
4. Preencha os campos obrigatórios
5. Clique em “Submit”

<Aside>Por predefinição, o membro que criou a área de trabalho é-lhe atribuído automaticamente.</Aside>


### Atualizar uma área de trabalho


1. Selecione “Organization Settings” no menu no canto superior direito do navegador
2. Clique em “Workspaces”
3. Clique no ícone de edição da área de trabalho pretendida
4. Ajuste os campos conforme pretendido
5. Clique em “Submit”

### Suspender uma área de trabalho


1. Selecione “Organization Settings” no menu no canto superior direito do navegador
2. Clique em “Workspaces”
3. Desmarque a caixa de verificação “Active” da área de trabalho pretendida
4. Clique em “Submit”

### Eliminar uma área de trabalho


1. Selecione “Organization Settings” no menu no canto superior direito do navegador
2. Clique em “Workspaces”
3. Clique no ícone de eliminação da área de trabalho pretendida
4. Clique novamente em “Delete”

<Aside>A eliminação é uma ação permanente. Este processo elimina a área de trabalho e todos os dados associados. Certifique-se de que tem uma cópia de segurança de tudo o que precisa antes de o fazer.</Aside>


### Gerir as aplicações disponíveis na área de trabalho


Por predefinição, as novas áreas de trabalho têm três aplicações adicionadas automaticamente: Analyze, Document e Identity. Embora o Identity não possa ser removido, por ser essencial para gerir o acesso e as funções numa área de trabalho, o Analyze e o Document podem ser removidos. Para gerir as aplicações disponíveis numa área de trabalho, incluindo aplicações personalizadas:


1. Selecione “Organization Settings” no menu no canto superior direito do navegador
2. Clique em “Workspaces”
3. Clique no ícone de aplicações da área de trabalho cujas aplicações associadas pretende modificar
4. Se pretender remover uma aplicação, clique no ícone de eliminação da aplicação a remover e confirme a eliminação
5. Se pretender adicionar uma nova aplicação, clique no botão **Add App to Workspace**, selecione a aplicação que pretende adicionar, marque a caixa de verificação **Enable for Use** e clique no botão create
