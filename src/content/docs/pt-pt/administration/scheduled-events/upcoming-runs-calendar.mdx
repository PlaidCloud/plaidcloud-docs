## Descrição

O **Upcoming Runs Calendar** é uma pré-visualização só de leitura de quando os fluxos de trabalho agendados serão executados a seguir. Expande os mesmos agendamentos que determinam a execução real, pelo que o que vê no calendário é o que será executado — sem acionar nada.

Responde a duas perguntas a que a tabela Events, por si só, não consegue responder:

- **Quando é que tudo é executado?** Uma vista única das próximas execuções de todos os agendamentos ativados.
- **Há execuções que colidem?** Cada execução é desenhada como uma barra dimensionada de acordo com a duração típica do fluxo de trabalho, disposta lado a lado para que as janelas de execução sobrepostas sejam evidentes.

<Aside type="note">O calendário nunca inicia um fluxo de trabalho. Lê as próximas ocorrências do agendador e estima a duração de cada execução a partir do histórico de execuções anteriores. Os comprimentos das barras são uma estimativa e estão identificados como tal.</Aside>

## Vistas

Alterne entre três vistas:

- **Month** — uma grelha de calendário com as próximas execuções ao longo do mês.
- **Week** — uma semana de cada vez, com as execuções colocadas no dia e hora em que serão disparadas.
- **Agenda** — uma lista cronológica das próximas execuções.

Utilize **Previous**, **Next** e **Today** para se deslocar no tempo, **Refresh** para voltar a obter as ocorrências mais recentes e **Filter…** para restringir a agendamentos específicos.

<Aside>As horas são apresentadas no fuso horário de cada agendamento. Uma nota no calendário recorda-o disso, uma vez que uma área de trabalho pode ter agendamentos configurados em fusos horários diferentes.</Aside>

## Ler o calendário

- **As barras** representam uma execução agendada; barras mais compridas significam uma duração típica de execução mais longa.
- **Barras lado a lado** na mesma janela significam que essas execuções se sobrepõem — um sinal para escalonar os respetivos agendamentos se competirem pelos mesmos recursos ou dados.
- **No upcoming scheduled runs** aparece quando não há nada agendado no intervalo visível.

Os sensores (acionadores orientados por eventos) **não** são apresentados — disparam em resposta a eventos e não têm uma hora futura determinística.

## Âmbito

O calendário adapta-se ao local onde o abre:

- **Ao nível da área de trabalho ou do projeto** — a vista abrangente de resolução de conflitos, que mostra em conjunto as próximas execuções de todos os agendamentos ativados.
- **Um único agendamento** — uma janela de agenda focada apenas nas próximas execuções desse agendamento.
