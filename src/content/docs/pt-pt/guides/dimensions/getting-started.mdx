As dimensões são as hierarquias do PlaidCloud — as árvores que utiliza para organizar centros de custo, produtos, contas, geografia, períodos de tempo ou qualquer outra estrutura consolidada. São a base sobre a qual se constroem as alocações, os painéis de controlo e os relatórios.

## Quando utilizar uma dimensão

Recorra a uma dimensão quando precisar de:

- Consolidar valores das folhas para os nós superiores (somar o custo por departamento, depois por região e depois por empresa)
- Alocar de um conjunto de linhas para outro com base numa hierarquia partilhada (repartir o custo de TI pelas unidades de negócio)
- Segmentar um painel de controlo por uma estrutura mais profunda do que uma lista simples (aprofundar de continente → país → cidade)
- Aplicar a mesma lógica de agrupamento em vários locais — defina a árvore uma vez e faça referência a ela em todo o lado

Se os seus dados já são simples e unidimensionais, não precisa de uma dimensão. Uma tabela normal serve.

## Como as dimensões estão estruturadas

Cada dimensão tem uma **hierarquia principal** — a árvore canónica em que cada folha está registada exatamente uma vez. Por cima desta, pode sobrepor **hierarquias alternativas** que voltam a consolidar as mesmas folhas sob nós superiores diferentes (por exemplo, a árvore principal agrupa os centros de custo por departamento e uma alternativa agrupa-os por região).

Cada nó da árvore pode ter propriedades, aliases e valores, pelo que uma hierarquia é mais do que uma árvore de nomes — é uma estrutura com metadados a que as alocações e os relatórios podem fazer referência.

Para os pormenores sobre criar, copiar, ordenar e gerir dimensões, consulte [Utilizar dimensões (hierarquias)](/pt-pt/guides/dimensions/dimensions/).

## Como as dimensões são carregadas

As dimensões são normalmente preenchidas a partir de uma tabela de origem através de um fluxo de trabalho:

- **Formato nó superior-nó inferior** — duas colunas (nó superior, nó inferior), uma aresta por linha
- **Formato por níveis** — uma coluna por nível da hierarquia, um caminho completo por linha

Consulte [Carregar e descarregar dimensões](/pt-pt/guides/dimensions/loading-unloading/) para o processo de carregamento e o passo de fluxo de trabalho [Dimension Load](/pt-pt/reference/workflow-steps/dimensions/dimension-load/) para o conjunto completo de opções.
