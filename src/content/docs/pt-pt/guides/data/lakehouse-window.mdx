A janela **Lakehouse** mostra o que está em execução no seu Lakehouse e como está configurado. Na aplicação Analyze, clique em **Lakehouse** para a abrir; está disponível para os membros que podem ler o Lakehouse. Uma barra lateral no lado esquerdo lista as suas páginas.

| Página | O que mostra |
|---|---|
| **Consultas** | O que está em execução agora e o que foi executado recentemente. |
| **Perfil** | O plano e o custo de uma consulta. |
| **Carga** | O nível de ocupação do Lakehouse. |
| **Catálogo** | Os espaços de nomes e as tabelas de um catálogo do Lakehouse, com o detalhe de cada tabela. |

Em **Administration**, a barra lateral lista **Lakehouse catalogs**, **Database users** e **Compute**. **Database users** e **Compute** só são apresentados aos membros que têm a função de administrador do Lakehouse ou a função de cluster do Lakehouse, pelo que, sem essa função, a página não é listada.

## Consultas

**Running now** lista as consultas em execução no Lakehouse. **Atualizar a cada** define a frequência com que a lista é lida de novo enquanto a janela está aberta. Selecione uma consulta em execução e clique em **Stop query** para a terminar.

**Histórico** lista as últimas consultas, da mais recente para a mais antiga. Restrinja-a com **Search SQL**, **Any user**, **Any kind** e **Any duration**. Clique em **Copy SQL** para copiar a instrução de uma consulta.

![A página Consultas com as consultas em execução acima de um histórico de consultas filtrado pelo texto SQL](/images/lakehouse/lakehouse-queries.png)

Para ver como uma consulta foi executada, faça duplo clique na mesma ou selecione-a e escolha **Profile this query**. A janela abre **Perfil** no plano dessa consulta.

## Catálogo

![A página Catálogo com os espaços de nomes, as tabelas e o seletor do catálogo do Lakehouse](/images/lakehouse/lakehouse-catalog.png)

**Catálogo** tem, no seu cabeçalho, um seletor para o catálogo do Lakehouse. Escolha um espaço de nomes para listar as respetivas tabelas e, depois, selecione uma tabela para abrir o seu detalhe:

- **Colunas**, com o tipo de cada coluna e a indicação de se é obrigatória.
- As linhas, o tamanho e os ficheiros de dados do instantâneo atual.
- **Partitioning**, **Localização** e **Propriedades**.
- **Histórico**, uma linha por instantâneo com a respetiva hora, a operação e as **Rows added** e **Rows removed**.

![O detalhe de uma tabela a mostrar as respetivas colunas, os tipos e se cada uma é obrigatória](/images/lakehouse/lakehouse-table-columns.png)

Um valor que os metadados da tabela não contêm é apresentado como —.

### Copiar uma consulta de viagem no tempo

![O separador Histórico de uma tabela a listar três instantâneos com as linhas que cada um adicionou e removeu](/images/lakehouse/lakehouse-table-history.png)

Em **Histórico**, utilize a ação **Copy query as of this snapshot** da linha de um instantâneo, o ícone de cópia no início da linha. É copiada uma consulta que lê a tabela tal como estava nesse instantâneo, utilizando `FOR VERSION AS OF`, que pode colar num ecrã de consultas. A cópia só é oferecida para o catálogo predefinido do Lakehouse. Para percorrer ou reverter os instantâneos de uma tabela no Explorador de tabelas, consulte [Instantâneos de tabelas](/pt-pt/guides/data/table-snapshots/).

## Catálogos do Lakehouse, utilizadores de base de dados e computação

**Lakehouse catalogs** lista os catálogos registados para a sua área de trabalho. **Procurar** num catálogo abre-o em **Catálogo**.

**Database users** lista os utilizadores de base de dados que se podem ligar ao Lakehouse e permite adicioná-los, alterá-los e removê-los. **Compute** mostra o estado dos nós de computação do Lakehouse e oferece **Reiniciar computação**, um reinício faseado para quando as consultas estão bloqueadas. Substitui os nós de computação um de cada vez, pelo que as consultas em execução num nó que está a ser substituído falham, enquanto os outros nós continuam a servir novas consultas. Aplica-se um período de espera entre reinícios.

![A página Compute com cada parte do cluster pronta e o cartão de reinício faseado](/images/lakehouse/lakehouse-compute.png)
