Cada repositório pode alojar uma wiki — uma coleção separada de páginas Markdown para documentação que vive junto ao código sem se misturar com ele.

## Ativar a wiki

1. Abra o repositório e selecione **Definições**.
2. Em **Caraterísticas**, ative **Wiki**.
3. Surge um separador **Wiki** na navegação do repositório.

## Criar e editar páginas

1. Selecione o separador **Wiki**.
2. Se a wiki ainda não tiver páginas, selecione **Create the First Page**. Caso contrário, selecione **New Page**.
3. Introduza um título para a página. O título passa a ser o URL da página, por isso escolha algo claro e estável.
4. Escreva o conteúdo em Markdown e depois selecione **Save Page**.

A primeira página que criar passa a ser o **Início** da wiki — a página onde os visitantes aterram por predefinição. Para atualizar uma página existente, abra-a e selecione **Editar**. Cada gravação regista uma nova entrada no histórico de revisões da página.

<Aside>A wiki é versionada tal como o seu código. Abra a vista **Revisions** em qualquer página para consultar o respetivo histórico ou reverter para uma versão anterior.</Aside>

## Organizar a wiki

Duas páginas com nomes especiais controlam a navegação em toda a wiki:

- **\_Sidebar** — uma barra lateral personalizada apresentada em todas as páginas. Adicione aqui ligações para as suas páginas mais importantes.
- **\_Footer** — um rodapé apresentado no fim de todas as páginas.

Crie qualquer uma delas a partir de **New Page** com o nome exato indicado acima. Ligue páginas da wiki entre si com Markdown padrão, referenciando o slug da página:

```md
See the [Setup Guide](setup-guide) for installation steps.
```

Utilize títulos de página descritivos desde o início: o título passa a ser o URL e mudar o nome de uma página mais tarde quebra as ligações existentes para ela.

## Editar a wiki localmente

A wiki é, ela própria, um repositório Git, disponível no URL `.wiki.git` do seu repositório. Clone-a, edite os ficheiros Markdown no seu editor e envie as alterações de volta.

```bash
git clone https://git.example.plaidcloud.com/you/my-repo.wiki.git
cd my-repo.wiki
# edit or add .md files
git add .
git commit -m "Expand the setup guide"
git push
```

O mesmo token de acesso pessoal que utiliza para o repositório principal funciona aqui. Cada ficheiro Markdown torna-se uma página da wiki; o nome do ficheiro (sem a extensão `.md`) é o slug da página.
