Um quadro de projeto organiza issues e pull requests em colunas que representam as etapas do seu fluxo de trabalho, dando a toda a equipa uma vista partilhada do que está em curso, do que está bloqueado e do que está concluído.

## Criar um quadro

1. Abra o repositório e selecione o separador **Projetos**.
2. Selecione **Novo projeto**.
3. Introduza um nome para o quadro.
4. Escolha um modelo inicial — uma disposição básica **Por fazer / Em curso / Concluído** é uma boa predefinição — ou selecione um quadro vazio para construir a disposição de raiz.
5. Selecione **Create Project** para abrir o quadro.

<Aside>Um quadro criado a partir do separador **Projetos** de um repositório pertence a esse repositório. Os quadros que abrangem vários repositórios da sua área de trabalho são criados por um administrador a partir da área de Projetos ao nível da organização.</Aside>

## Configurar colunas

1. Para adicionar uma coluna, selecione **Adicionar coluna**, introduza uma etiqueta e guarde.
2. Para mudar o nome de uma coluna, abra as respetivas definições e escolha **Editar**.
3. Arraste os cabeçalhos das colunas para a esquerda ou para a direita para as reordenar.
4. Marque uma coluna como predefinida a partir das respetivas definições — qualquer cartão adicionado sem um destino específico fica nela.

## Adicionar e mover cartões

- Para adicionar uma issue ou um pull request existente, abra o menu de uma coluna e selecione **Add an item**; depois pesquise-o por título ou número.
- Para criar uma nova issue diretamente no quadro, selecione **+** dentro de uma coluna. A issue é guardada no repositório e surge imediatamente como cartão.
- Arraste um cartão para uma coluna diferente à medida que o trabalho avança. A posição do cartão reflete o seu estado atual; por si só, não altera as etiquetas nem os responsáveis da issue.

## Acompanhar o trabalho

O quadro dá-lhe, num relance, uma imagem da carga de trabalho da sua equipa sem abrir cada issue. Mantenha-o atualizado:

- Fechando uma issue ou integrando um pull request — o cartão passa para uma coluna de concluídos ou sai do quadro, consoante as definições de automatização do seu quadro.
- Combinando o quadro com **Marcos** quando pretende um objetivo com prazo juntamente com a vista Kanban. Os marcos acompanham uma data-limite e a percentagem de conclusão; o quadro acompanha o fluxo.
