O PlaidCloud Git inclui um registo de pacotes integrado para artefactos distribuíveis e o Git Large File Storage (LFS) para ficheiros binários grandes dentro dos seus repositórios.

## Acerca do registo de pacotes

O registo de pacotes é por proprietário e suporta uma vasta gama de formatos de ecossistema — npm, PyPI, Maven, NuGet, RubyGems, imagens de contentor e outros. Os pacotes são privados para a sua área de trabalho e só são acessíveis a membros autenticados.

Cada tipo de pacote tem o seu próprio ponto final em:

```
https://git.example.plaidcloud.com/api/packages/you/<type>
```

em que `<type>` é o identificador do ecossistema (por exemplo, `npm`, `pypi` ou `maven`).

## Autenticar no registo

As operações do gestor de pacotes utilizam o seu nome de utilizador do PlaidCloud Git e um token de acesso pessoal como palavra-passe. Consulte [Repositórios](/pt-pt/guides/git/repositories/) para saber como criar um token.

## Publicar um pacote

Os passos variam consoante o ecossistema, mas o padrão é o mesmo: aponte o seu gestor de pacotes para o URL do registo e execute o respetivo comando de publicação padrão.

No npm, adicione um `.npmrc` ao seu projeto para associar os pacotes ao registo:

```ini
@you:registry=https://git.example.plaidcloud.com/api/packages/you/npm/
//git.example.plaidcloud.com/api/packages/you/npm/:_authToken=YOUR_TOKEN
```

Depois, publique como habitual:

```bash
npm publish
```

No PyPI, Maven, NuGet e noutros ecossistemas, configure a definição de repositório ou de origem da ferramenta com o URL do registo correspondente e utilize o comando de publicação padrão dessa ferramenta (por exemplo, `twine upload`, `mvn deploy` ou `dotnet nuget push`).

## Instalar um pacote

Aponte o seu gestor de pacotes para o mesmo URL do registo e instale como habitual. Com o `.npmrc` acima configurado:

```bash
npm install @you/my-package
```

Para outros ecossistemas, adicione o registo como origem adicional na configuração da sua ferramenta e utilize o respetivo comando de instalação padrão.

## Ficheiros grandes com o Git LFS

O Git LFS mantém o seu repositório rápido, substituindo no histórico os ficheiros grandes ou binários por ponteiros leves e armazenando os dados dos ficheiros em separado. O LFS está ativado em todos os repositórios do PlaidCloud Git.

1. Instale o cliente LFS uma vez na sua máquina:

   ```bash
   git lfs install
   ```

2. Indique ao LFS que padrões de ficheiros deve acompanhar, a partir do interior do seu repositório:

   ```bash
   git lfs track "*.parquet"
   ```

   Isto cria ou atualiza o `.gitattributes`. Faça commit desse ficheiro:

   ```bash
   git add .gitattributes
   git commit -m "Track Parquet files with LFS"
   ```

3. Adicione e envie como habitual — os ficheiros correspondentes são carregados para o LFS automaticamente:

   ```bash
   git add data/large-dataset.parquet
   git commit -m "Add dataset"
   git push origin main
   ```

<Aside type="tip">O Git LFS destina-se a ficheiros grandes que fazem parte do histórico de um repositório e são obtidos com `git clone` ou `git pull`. O registo de pacotes destina-se a artefactos versionados e distribuíveis que os consumidores instalam com um gestor de pacotes. Se os colegas de equipa vão fazer `npm install` ou `pip install`, utilize o registo; se precisarem do ficheiro como parte de um checkout, utilize o LFS.</Aside>
