Um repositório contém os ficheiros, os ramos e o histórico de um projeto. Este guia explica como criar um repositório e ligar-se a ele a partir do seu computador.

## Criar um repositório

1. Abra o **Git** a partir da sua área de trabalho.
2. Selecione o menu **+** no canto superior direito e depois **New Repository**.
3. Introduza um nome e, opcionalmente, uma breve descrição.
4. Escolha a visibilidade. Os novos repositórios são **Privado** por predefinição — só os membros a quem conceder acesso os podem ver.
5. Opcionalmente, selecione **Initialize Repository** para adicionar um README, um `.gitignore` e uma licença.
6. Selecione **Create Repository**.

## Gerar um token de acesso pessoal

Como inicia sessão através do PlaidCloud, a sua conta não tem uma palavra-passe Git separada. Para clonar ou enviar por HTTPS a partir da linha de comandos, crie um token de acesso pessoal e utilize-o no lugar de uma palavra-passe.

1. Selecione o seu avatar no canto superior direito e depois **Definições**.
2. Abra o separador **Aplicações**.
3. Em **Manage Access Tokens**, introduza um nome que descreva onde vai utilizar o token (por exemplo, `laptop`).
4. Selecione os âmbitos de **Leitura** e **Escrita** do repositório para que o token possa clonar e enviar.
5. Selecione **Generate Token**.
6. Copie o token e guarde-o num local seguro. Não poderá voltar a vê-lo.

<Aside type="caution">Trate o token como uma palavra-passe — quem o tiver pode agir como si no Git. Gere um token separado por máquina para poder revogar um sem perturbar os restantes.</Aside>

## Clonar um repositório

1. Abra o repositório no PlaidCloud Git.
2. Selecione **Código** e depois copie o URL de clonagem **HTTPS**.
3. Num terminal, execute `git clone` com esse URL:

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. Quando o Git pedir credenciais, introduza o seu **nome de utilizador do PlaidCloud** e cole o **token de acesso** como palavra-passe.

<Aside>Para evitar ter de voltar a introduzir o token em cada envio, deixe que o assistente de credenciais do Git do seu sistema operativo o guarde: execute `git config --global credential.helper store` (ou `osxkeychain` no macOS) antes do primeiro envio.</Aside>

## Fazer commit e enviar alterações

A partir do interior de um repositório clonado:

1. Prepare as alterações: `git add .`
2. Registe-as com uma mensagem: `git commit -m "Describe what changed"`
3. Envie-as para o PlaidCloud Git: `git push`

Os seus commits surgem nas vistas **Commits** e **Atividade** do repositório e em qualquer ramo ou pull request que os inclua.

## Gerir o acesso e a visibilidade

Abra o separador **Definições** de um repositório para mudar o respetivo nome, alterar a visibilidade ou transferir a propriedade. Para permitir que outros membros contribuam, utilize **Definições → Collaborators** e adicione-os pelo nome de utilizador com uma função **Leitura**, **Escrita** ou **Administrador**.

<Aside>O acesso ao repositório também segue a pertença à sua área de trabalho e os grupos de segurança. Consulte [Gestão de acessos](/pt-pt/administration/access/) para saber como estes se traduzem em quem pode ver e editar um repositório.</Aside>
