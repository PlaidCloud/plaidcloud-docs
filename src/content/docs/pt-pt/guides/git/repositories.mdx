Um repositório contém os ficheiros, os ramos e o histórico de um projeto. Este guia explica como criar um repositório e ligar-se a ele a partir do seu computador.

## Criar um repositório

1. Abra **Git** a partir da sua área de trabalho.
2. Selecione o menu **+** no canto superior direito e, depois, **New Repository**.
3. Introduza um nome e, opcionalmente, uma descrição breve.
4. Escolha a visibilidade. Os novos repositórios são **Privado** por predefinição — só os membros a quem conceder acesso os podem ver.
5. Opcionalmente, selecione **Initialize Repository** para adicionar um README, um `.gitignore` e uma licença.
6. Selecione **Create Repository**.

## Gerar um token de acesso pessoal

Como inicia sessão através do PlaidCloud, a sua conta não tem uma palavra-passe Git separada. Para clonar ou enviar por HTTPS a partir da linha de comandos, crie um token de acesso pessoal e utilize-o no lugar da palavra-passe.

1. Selecione o seu avatar no canto superior direito e, depois, **Definições**. O cartão de configuração no separador **Git** também tem uma ligação direta para esta página.
2. Abra o separador **Aplicações**.
3. Em **Manage Access Tokens**, introduza um nome que descreva onde vai utilizar o token (por exemplo, `laptop`).
4. Selecione a permissão **write:repository** para que o token possa clonar e enviar.
5. Selecione **Generate Token**.
6. Copie o token e guarde-o num local seguro. Não poderá voltar a vê-lo.

<Aside type="caution">Trate o token como uma palavra-passe — quem o tiver pode agir como si no Git. Gere um token separado por máquina, para poder revogar um sem afetar os restantes.</Aside>

## Clonar um repositório

1. Abra **Git** na sua área de trabalho e selecione o botão de cópia junto do endereço de clonagem do repositório (selecione **How to clone** para ver os passos de configuração). Também pode selecionar **Código** no repositório e copiar o URL **HTTPS**.
2. Num terminal, execute `git clone` com esse URL:

   ```bash
   git clone <clone URL>
   ```

3. Quando o Git pedir uma palavra-passe, cole o **token de acesso**. Utilize o nome de utilizador que já consta do URL.
4. Defina o nome e o e-mail que o Git regista nos seus commits, com os valores que o cartão de configuração apresenta:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Para enviar, é necessário acesso de Contributor ou Administrator; como Leitor, pode ler mas não enviar. Consulte [Níveis de acesso](/pt-pt/guides/git/#níveis-de-acesso).

<Aside>Para evitar voltar a introduzir o token em cada envio, pode deixar que o assistente de credenciais do Git do seu sistema operativo o guarde, por exemplo `git config --global credential.helper osxkeychain` no macOS.</Aside>

## Fazer commit e enviar alterações

A partir de um repositório clonado:

1. Prepare as alterações: `git add .`
2. Registe-as com uma mensagem: `git commit -m "Describe what changed"`
3. Envie-as para o PlaidCloud Git: `git push`

Os seus commits aparecem nas vistas **Commits** e **Atividade** do repositório, e em qualquer ramo ou pull request que os inclua.

## Gerir o acesso e a visibilidade

Abra o separador **Definições** de um repositório para lhe mudar o nome, alterar a visibilidade ou transferir a propriedade. Para permitir que outros membros contribuam, utilize **Definições → Collaborators** e adicione-os pelo nome de utilizador com a função **Leitura**, **Escrita** ou **Administrator**.

<Aside>O acesso aos repositórios também segue a sua participação na área de trabalho e os seus grupos de segurança. Consulte [Gestão de acessos](/pt-pt/administration/access/) para saber como estes se refletem em quem pode ver e editar um repositório.</Aside>
