Um repositório contém os ficheiros, ramos e o histórico de um projeto. Este guia explica como criar um repositório e ligar-se a ele a partir do seu computador.

## Criar um repositório

1. Abra o **Git** a partir da sua área de trabalho.
2. Selecione o menu **+** no canto superior direito e depois **New Repository**.
3. Introduza um nome e, opcionalmente, uma descrição curta.
4. Escolha a visibilidade. Os novos repositórios são **Privado** por predefinição – somente os membros a quem conceder acesso podem vê-los.
5. Opcionalmente, selecione **Initialize Repository** para adicionar um README, um ficheiro `.gitignore` e uma licença.
6. Selecione **Create Repository**.

Os colaboradores não podem criar repositórios diretamente na organização Git da área de trabalho; os repositórios são criados pelo PlaidCloud.

## Gerar um token de acesso pessoal

Como entra pelo PlaidCloud, a sua conta não tem uma palavra-passe Git separada. Para clonar ou fazer push por HTTPS na linha de comando, crie um token de acesso pessoal e use-o no lugar da palavra-passe.

1. Selecione o seu avatar no canto superior direito e depois **Configurações**. O cartão de configuração no separador **Git** também tem um link direto para esta página.
2. Abra o separador **Aplicações**.
3. Em **Gerir tokens de acesso**, introduza um nome que descreva onde usará o token (por exemplo, `laptop`).
4. Selecione a permissão **write:repository** para que o token possa clonar e fazer push.
5. Selecione **Generate Token**.
6. Copie o token e guarde-o num local seguro. Não poderá voltar a vê-lo.

<Aside type="caution">Trate o token como uma palavra-passe – qualquer pessoa que o tenha pode agir como si no Git. Gere um token separado para cada máquina, para poder revogar um sem afetar os restantes.</Aside>

## Clonar um repositório

1. Abra o **Git** na sua área de trabalho e selecione o botão de copiar ao lado do endereço de clone do repositório (selecione **How to clone** para ver os passos de configuração). Também pode selecionar **Código** no repositório e copiar a URL **HTTPS**.
2. Num terminal, execute `git clone` com essa URL:

   ```bash
   git clone <clone URL>
   ```

3. Quando o Git pedir uma palavra-passe, cole o **token de acesso**. Use o nome de utilizador que já está na URL.
4. Defina o nome e o e-mail que o Git regista nos seus commits, usando os valores que o cartão de configuração mostra:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Precisa de acesso de Colaborador ou Administrador para fazer push; como Leitor, pode ler, mas não fazer push. Consulte [Níveis de acesso](/pt-pt/guides/git/#níveis-de-acesso).

<Aside>Para evitar introduzir o token novamente a cada push, pode deixar que o auxiliar de credenciais do Git do seu sistema operativo o armazene, por exemplo com `git config --global credential.helper osxkeychain` no macOS.</Aside>

## Fazer commit e push das alterações

A partir de dentro de um repositório clonado:

1. Adicione as suas alterações à área de stage: `git add .`
2. Registe-as com uma mensagem: `git commit -m "Describe what changed"`
3. Envie-as ao PlaidCloud Git: `git push`

Os seus commits aparecem nas vistas **Commits** e **Atividade** do repositório, e em qualquer ramo ou pull request que os inclua.

## Gerir acesso e visibilidade

Abra o separador **Configurações** de um repositório para renomeá-lo, alterar a visibilidade ou transferir a propriedade. Para permitir que outros membros contribuam, use **Configurações → Collaborators** e adicione-os por nome de utilizador com a função **Leitura**, **Escrita** ou **Administrador**.

<Aside>O acesso ao repositório também acompanha a sua participação na área de trabalho e os grupos de segurança. Consulte [Gestão de acesso](/pt-pt/administration/access/) para saber como eles definem quem pode ver e editar um repositório.</Aside>
