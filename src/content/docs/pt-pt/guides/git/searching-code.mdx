O PlaidCloud Git permite-lhe pesquisar código, ficheiros, issues e pull requests em todos os repositórios a que a pertença à sua área de trabalho lhe dá acesso.

## Pesquisar código

1. Selecione a caixa de pesquisa no topo de qualquer página e escreva a sua consulta.
2. Prima **Enter** para ver os resultados em todos os repositórios a que tem acesso.
3. Selecione um resultado para saltar diretamente para o ficheiro na linha correspondente.
4. Restrinja os resultados com os filtros **Repositório** e **Linguagem** na página de resultados.

<Aside>A pesquisa de código indexa o ramo predefinido. Para pesquisar noutro ramo, navegue até esse ramo e utilize a pesquisa dentro do repositório descrita abaixo.</Aside>

## Pesquisar dentro de um repositório

1. Abra um repositório e selecione o separador **Código**.
2. Prima **T** (ou selecione a caixa do localizador de ficheiros) para abrir o localizador de ficheiros.
3. Escreva parte de um nome de ficheiro ou de um caminho — a lista é filtrada à medida que escreve.
4. Selecione um ficheiro para o abrir e depois utilize a função de pesquisa na página do seu navegador (**⌘F** / **Ctrl+F**) para localizar uma linha específica.

<Aside type="tip">O localizador de ficheiros faz correspondência por segmentos de caminho, pelo que escrever `util/auth` apresenta `src/util/auth.py`, `lib/util/auth_helper.go` e caminhos semelhantes.</Aside>

## Filtrar issues e pull requests

Na lista de **Issues** ou de **Pull Requests**, combine a pesquisa por palavras-chave com filtros `key:value`:

| Filtro | Exemplo |
|---|---|
| Estado aberto ou fechado | `is:open`, `is:closed` |
| Etiqueta | `label:bug`, `label:"needs review"` |
| Responsável | `assignee:you` |
| Autor | `author:you` |
| Marco | `milestone:"v1.2"` |

Escreva os filtros diretamente na caixa de pesquisa, combine-os livremente e utilize o menu **Ordenar** para ordenar por **Atualizados recentemente**, **Mais comentados**, **Mais recente** ou **Mais antigo**.

<Aside>Coloque o nome de uma etiqueta entre aspas quando contiver espaços: `label:"needs review"`.</Aside>

## Sugestões para encontrar as coisas mais depressa

- **Expressões exatas** — coloque termos com várias palavras entre aspas (`"connection pool"`) para evitar correspondências parciais ruidosas.
- **Limitar a um repositório** — abra o repositório antes de pesquisar para que os resultados fiquem focados.
- **Nomes descritivos compensam** — repositórios e issues com nomes claros e específicos surgem na pesquisa de forma muito mais fiável do que os genéricos, como `misc`.
- **As etiquetas são metadados pesquisáveis** — uma issue bem etiquetada é mais fácil de filtrar do que uma enterrada em prosa, por isso aplique as etiquetas de forma consistente.
