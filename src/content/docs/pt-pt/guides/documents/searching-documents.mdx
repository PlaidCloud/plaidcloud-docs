## Descrição

O navegador de documentos inclui uma barra de pesquisa no topo da lista de ficheiros. As pesquisas são executadas em direto no sistema de armazenamento ligado (S3, Azure Blob, Google Drive, OneDrive, etc.), pelo que os resultados refletem o estado atual da conta e não um índice desatualizado.


## Executar uma pesquisa

1. Abra uma conta de documentos
2. Clique no campo **Pesquisar ficheiros…** no topo da lista de ficheiros
3. Escreva um padrão de nome
4. Veja os resultados a surgirem na lista de ficheiros

Prima `Esc` ou clique no ícone de limpar no fim do campo para sair do modo de pesquisa e regressar à lista de ficheiros normal. A linha de estado abaixo do campo mostra quantas pastas foram analisadas e quantas correspondências foram encontradas.


## Filtros avançados

Clique em `Advanced` junto ao campo de pesquisa para mostrar a linha de filtros. Combine qualquer um destes filtros com o padrão de nome:

* **Ext.:** — extensões separadas por vírgulas, por exemplo `pdf,xlsx`. Sem espaços.
* **Tipo:** — `Files & folders` (predefinido), `Files only` ou `Folders only`.
* **Tamanho (bytes):** — tamanho mínimo e/ou máximo.
* **Modificado:** — na data ou depois dela e na data ou antes dela, ambas no formato `YYYY-MM-DD`.

Os filtros aplicam-se em conjunto com o padrão de nome. Clique em `Clear` para limpar a consulta e todos os filtros.


## Destaque e revelação

* Enquanto a pesquisa decorre, os resultados surgem pela ordem de chegada, para que possa agir sobre as primeiras correspondências sem esperar.
* Quando o fluxo termina, a lista de ficheiros é reordenada por nome e a subcadeia correspondente é destacada em cada linha.
* Clique com o botão direito em qualquer resultado e selecione `Reveal in folder` para saltar para o ficheiro no diretório que o contém e sair do modo de pesquisa.


## Pesquisar em vários sistemas de armazenamento

A pesquisa utiliza a API de pesquisa do próprio sistema de armazenamento sempre que existe uma, pelo que os resultados correspondem ao que veria na interface nativa desse sistema:

* **Google Drive** — utiliza a API do Drive.
* **OneDrive / SharePoint** — utiliza o Microsoft Graph.

Nos armazenamentos de objetos (S3 e compatíveis com S3, Azure Blob, GCS, etc.), o PlaidCloud percorre os caminhos configurados em paralelo.


<Aside>Cada utilizador tem um limite de pesquisas simultâneas por conta, para que uma pesquisa pesada não prejudique os outros utilizadores. Se atingir o limite, a barra de pesquisa apresenta um erro — aguarde que uma das suas outras pesquisas termine e tente novamente.</Aside>
