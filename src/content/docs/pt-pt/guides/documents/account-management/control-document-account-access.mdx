Estão disponíveis quatro tipos de restrições de acesso para uma conta: Privada, Área de trabalho, Apenas membros e Grupo de segurança. O tipo de restrição definido para um utilizador pode ser editado a qualquer momento no formulário da conta.

<Aside>Nenhum dos níveis de acesso à conta revela as credenciais usadas para aceder aos documentos. Apenas os proprietários da conta podem ver as credenciais.</Aside>

## Atualizar o acesso à conta


1. Selecione `Document > Manage Accounts` no PlaidCloud
2. Entre no modo de edição da conta que pretende alterar
3. Selecione a restrição de nível de acesso pretendida em `Security Model`
4. Selecione o botão Guardar

<Aside>Consoante o Modelo de segurança selecionado, haverá diferentes opções para atribuir os membros ou grupos de segurança com permissão de acesso a partir da lista de contas em Gerir contas.</Aside>


## Opções de restrição


### Todos os membros da área de trabalho


Este acesso é o mais simples, pois concede acesso a todos os membros da área de trabalho e não requer qualquer atribuição adicional de membros.



### Apenas membros específicos


Esta definição de acesso requer a atribuição de cada membro a uma conta. Esta opção é particularmente útil quando combinada com a opção de início de sessão único de atribuir membros com base numa lista de grupos enviada com a autenticação. No entanto, em áreas de trabalho com um grande número de membros, esta abordagem exige muitas vezes mais esforço do que o desejável, e é aí que os grupos de segurança se tornam úteis. Para escolher apenas membros específicos:


1. Selecione o ícone de membros na lista Gerir contas
2. Arraste os membros pretendidos da coluna `Unassigned Members` à esquerda para a coluna `Assigned Members` à direita
3. Para remover membros, faça o contrário
4. Selecione o botão Guardar

### Apenas grupos de segurança específicos


Com esta opção, a permissão para aceder a uma conta é concedida a grupos de segurança específicos e não apenas a indivíduos. Com restrições de acesso baseadas na associação a um ou mais grupos de segurança, a administração de contas com um número de utilizadores muito superior torna-se muito mais simples. Para editar os grupos atribuídos:


1. Selecione o ícone de grupos na lista Gerir contas
2. Arraste os grupos pretendidos da coluna `Unassigned Groups` à esquerda para a coluna `Assigned Groups` à direita
3. Para remover grupos, faça o contrário
4. Selecione o botão Guardar

### Agentes remotos


Os agentes PlaidLink utilizam frequentemente contas de documentos para armazenar ficheiros ou mover ficheiros entre sistemas. Para permitir que os agentes remotos acedam a contas de documentos, é OBRIGATÓRIO que lhes seja concedida permissão. Trata-se de uma funcionalidade de segurança para limitar o acesso indesejado a informações potencialmente sensíveis. Para adicionar agentes:


1. Selecione o ícone de agente na lista Gerir contas
2. Arraste os agentes pretendidos da coluna `Unassigned Agents` à esquerda para a coluna `Assigned Agents` à direita
3. Para remover agentes, faça o contrário
4. Selecione o botão Guardar
