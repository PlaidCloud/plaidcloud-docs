Antes de retirar, substituir ou reconstruir uma conta de documentos, descubra tudo o que a utiliza e depois mude essas utilizações para outra conta.

## Ver onde uma conta é utilizada

1. Selecione `Document > Manage Accounts`.
2. Selecione o ícone **Utilizado por** na linha da conta.

**Onde é utilizado** lista cada utilização com o respetivo projeto, tipo, nome e a forma como a conta é utilizada:

| Coluna | Valores |
| --- | --- |
| Tipo | Passo, fluxo de trabalho ou predefinição de projeto |
| Utilizado | Diretamente; condição de contentor; predefinição de projeto; ou variável (pode ser utilizada) |

Os passos e fluxos de trabalho que a sua função não pode ver são contados, mas não nomeados. A lista é reunida projeto a projeto e indica quando pode estar incompleta ou que projetos nunca foram analisados.

Os manifestos do App Runner e as imagens de mosaico dos projetos não são analisados. Uma utilização proveniente de uma variável é listada, e a variável tem de ser atualizada manualmente.

## Reapontar uma conta

1. Em **Onde é utilizado**, selecione **Reapontar...**.
2. Escolha a conta para a qual pretende mudar e, depois, selecione **Pré-visualização**.
3. Reveja as utilizações. Ainda nada foi alterado. Desmarque as que pretende deixar como estão.
4. Selecione **Reapontar** e confirme.

Cada utilização apresenta então o seu resultado: **Alterado**, **Alterado desde a pré-visualização**, **Não permitido**, **O projeto está bloqueado**, **Já não existe** ou **Recusado**. Uma utilização que falhe não impede as restantes. Alterar a predefinição de um projeto requer um Arquiteto ou um administrador da área de trabalho.

As utilizações por variáveis nunca são alteradas. A pré-visualização indica cada variável e o passo a atualizar manualmente.

<Aside type="caution">Se reapontar para uma Unidade temporária pessoal, os fluxos de trabalho são executados como o projeto, que não consegue abrir essa unidade, e os passos reapontados falham quando são executados. O PlaidCloud avisa-o para cada projeto afetado.</Aside>

## Utilizar um assistente de IA

* O assistente de IA num projeto pode propor um reapontamento. Mostra as alterações num cartão de aprovação e só as aplica depois de as aprovar.
* Através de MCP, `document_account_describe(include=['used_by'])` lista as utilizações e `document_account_repoint` pré-visualiza e aplica um reapontamento.
