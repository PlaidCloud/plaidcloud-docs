Um **projeto** é a unidade de trabalho no PlaidCloud. Cada projeto possui os seus próprios dados, fluxos de trabalho, dimensões e histórico de auditoria. Os projetos não partilham estado entre si — estão isolados, o que os torna o limite natural para separar análises, processos de negócio ou produtos de dados distintos.

A maioria das equipas começa com um projeto por área analítica: um projeto para a alocação de custos de pessoal, outro para a análise de receitas, outro para o fecho mensal — tudo o que corresponda à forma como a equipa pensa o seu trabalho.
