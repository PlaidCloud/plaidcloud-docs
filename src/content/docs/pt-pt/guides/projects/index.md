Um **projeto** é a unidade de trabalho no PlaidCloud. Cada projeto tem os seus próprios dados, fluxos de trabalho, dimensões e histórico de auditoria. Os projetos não partilham estado entre si — são isolados, o que os torna a fronteira natural para separar análises, processos de negócio ou produtos de dados distintos.

A maioria das equipas começa com um projeto por área analítica: um projeto para a alocação de custos de pessoal, outro para a análise de receitas, outro para o fecho mensal — o que corresponder à forma como a equipa pensa o seu trabalho.
