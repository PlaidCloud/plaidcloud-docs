O PlaidCloud permite organizar e gerir hierarquias, incluindo etiquetas. As hierarquias estão disponíveis para todos os fluxos de trabalho de um projeto.



O PlaidCloud utiliza um sistema baseado em caminhos para organizar as hierarquias, tal como se navega numa série de pastas, o que permite uma organização mais flexível e lógica (hierarquia de controlo) das hierarquias. Com este sistema, as hierarquias podem ser movidas dentro de uma hierarquia de controlo, ou podem ser criadas várias referências a uma hierarquia a partir de diferentes locais da hierarquia de controlo (hierarquias alternativas). A capacidade de gerir hierarquias com este método permite que a estrutura reflita as necessidades operacionais, de relatórios e de controlo.



## Pesquisar


Para pesquisar hierarquias:


1. Utilize a caixa de filtro no canto inferior esquerdo da hierarquia de controlo
2. O filtro de pesquisa procura correspondências nos nomes e nas etiquetas das hierarquias e mostra os resultados na hierarquia de controlo acima


## Mover


Para mover uma hierarquia dentro da hierarquia de controlo:


1. Arraste-a para a pasta onde pretende colocá-la


## Mudar o nome


Para mudar o nome de uma hierarquia:


1. Clique com o botão direito do rato na hierarquia
2. Selecione a opção de mudar o nome
3. Escreva o novo nome e guarde-o
4. A hierarquia passa a ter o novo nome, mas mantém o identificador único original


## Limpar


Pode limpar uma única hierarquia ou várias.


Para limpar uma hierarquia:


1. Selecione as hierarquias na hierarquia de controlo
2. Clique no botão de limpar na barra de ferramentas superior


## Eliminar


### Pode eliminar uma única hierarquia ou várias.


Para eliminar uma hierarquia:


1. Selecione as hierarquias na hierarquia de controlo
2. Clique no botão de eliminar na barra de ferramentas superior

A operação de eliminação verifica se a hierarquia está a ser utilizada por passos de fluxo de trabalho, tabelas ou vistas. Em caso afirmativo, ser-lhe-á pedido que remova essas associações.

<Aside>Pode também forçar a eliminação da(s) hierarquia(s). A eliminação forçada da(s) hierarquia(s) deixa referências quebradas, pelo que deve ser utilizada com moderação.</Aside>



## Criar uma nova estrutura de diretórios


Para criar uma nova pasta:


1. Clique no botão Nova pasta na barra de ferramentas

Para adicionar uma pasta a uma pasta existente:


1. Clique com o botão direito do rato na pasta
2. Selecione Nova pasta.


## Marcar a hierarquia para funções de visualização


Para ver hierarquias por função:


1. Clique nas caixas de seleção Explorador ou Gestor

Para ver as hierarquias que precisam de ser atualizadas:


1. Selecione as hierarquias na hierarquia de controlo
2. Selecione a função de visualização pretendida no menu Ações da barra de ferramentas superior


## Memorandos para descrever o conteúdo das tabelas


Para adicionar um memorando a uma hierarquia:


1. Selecione a hierarquia
2. Atualize o memorando no formulário de contexto à direita


## Ver atributos adicionais da hierarquia


Para ver e editar atributos adicionais da hierarquia:


1. Selecione uma hierarquia
2. Veja o formulário de contexto da hierarquia à direita


## Duplicar uma hierarquia


Para duplicar uma hierarquia:



1. Selecione a hierarquia


2. Clique no botão de duplicar na barra de ferramentas superior
