As janelas do Analyze abrem-se umas sobre as outras — um fluxo de trabalho dentro de um projeto, um passo dentro desse fluxo de trabalho, uma tabela que abriu para verificar um resultado. Duas funcionalidades facilitam ver onde se encontra e voltar atrás: um **trilho de navegação** no título de cada janela e um **URL que acompanha aquilo que está a ver**, para que qualquer vista possa ser guardada nos marcadores ou enviada a um colega.

## O Trilho de Navegação

As janelas que pertencem a um projeto mostram a sua ascendência como título, na barra de título da janela:

```
My Project › Workflow › Nightly Load
```

Cada parte chama-se segmento e lê-se da esquerda para a direita, do contentor mais exterior para o interior:

1. **O projeto** — o projeto a que pertence aquilo que está a ver.
2. **O tipo de objeto** — Fluxo de trabalho, Tabela, Passo, Dimensão ou Editor de dados.
3. **O próprio objeto** — o fluxo de trabalho, a tabela, o passo, etc. atual. Este último segmento é onde já se encontra, pelo que não é clicável.

### Navegar com o Trilho

Selecione um dos dois primeiros segmentos para subir:

| Segmento | Dica | O que faz |
|---|---|---|
| O nome do projeto | Abrir projeto | Abre esse projeto ou coloca-o em primeiro plano se já estiver aberto |
| Fluxo de trabalho | Mostrar todos os fluxos de trabalho | Abre o projeto na respetiva lista de Fluxos de trabalho |
| Tabela | Mostrar todas as tabelas | Abre o projeto na respetiva lista de Tabelas |
| Passo | Mostrar todos os passos | Abre o projeto na respetiva lista de Passos |
| Dimensão | Mostrar todas as dimensões | Abre o projeto na respetiva lista de Dimensões |
| Editor de dados | Mostrar todos os editores de dados | Abre o projeto na respetiva lista de Editores de dados |

O segmento do tipo é a forma rápida de chegar a um elemento do mesmo nível: a partir de um fluxo de trabalho, um clique leva-o à lista completa de fluxos de trabalho do mesmo projeto, pronta para abrir outro.

<Aside type="note">
A janela de onde veio permanece aberta. Navegar com um trilho coloca o projeto em primeiro plano — não fecha aquilo que estava a ver e pode regressar a essa janela a partir da barra de separadores na parte inferior do ecrã.
</Aside>

### Onde Aparecem os Trilhos de Navegação

- Janelas de **Fluxo de trabalho** — a grelha de passos de um fluxo de trabalho padrão
- **Estruturador visual de fluxos de trabalho** — a vista de área de desenho de um fluxo de trabalho avançado
- **Explorador de tabelas**
- Janelas de **Passo** abertas isoladamente
- Janelas de hierarquia de **Dimensão**
- Janelas de **Editor de dados**

Um passo pode pertencer a mais do que um fluxo de trabalho, pelo que o trilho de um passo mostra `Project › Step › name` em vez de indicar um único fluxo de trabalho proprietário.

### Acesso por Teclado e Leitor de Ecrã

Os segmentos clicáveis são controlos normais: **Tabulação** move o foco para eles e **Enter** ou **Espaço** ativa o que tem o foco, pelo que nunca precisa de um rato para subir na hierarquia. Cada um é anunciado como um botão, o último segmento é anunciado como a página atual e os separadores `›` são ignorados em vez de lidos em voz alta.

### Sair de um Editor de Dados com Alterações Não Guardadas

O Editor de dados é a única janela que pergunta antes de um trilho de navegação o levar para outro local. Se tiver edições em curso, ao selecionar um segmento é apresentada a mensagem **Alterações não guardadas** — *Fechar o editor de dados sem guardar as alterações?* — com **Fechar editor** para sair mesmo assim. Cancele a mensagem e permanece no editor com as suas alterações intactas.

É a mesma mensagem que o botão **Fechar** do próprio editor apresenta, pelo que não existe nenhuma forma de sair de um Editor de dados que descarte o trabalho sem perguntar.

## Ligações Partilháveis

A barra de endereços indica sempre a janela que está em primeiro plano. Abra um fluxo de trabalho e o URL passa a ser a ligação desse fluxo de trabalho; abra uma tabela e passa a ser a ligação da tabela. Essa ligação é a unidade que partilha.

**Para partilhar aquilo que está a ver**, copie o URL da barra de endereços do navegador e envie-o. Qualquer pessoa com acesso a esse projeto abre a mesma vista. Guarde-o nos marcadores e continuará a funcionar mais tarde.

### O que Acontece Quando Alguém Abre a Ligação

Abrir ou atualizar uma ligação restaura o **contexto superior**, e não apenas a janela em causa. Uma ligação para um fluxo de trabalho volta a abrir também o respetivo projeto, pelo que chega com o projeto disponível na barra de separadores em vez de uma única janela solta — o mesmo local a que chegaria se tivesse navegado até lá.

### Formatos de Ligação

As ligações começam pelo projeto: primeiro o projeto, depois o objeto dentro dele, separados por `~`.

```
#p~my-project                        a project
#p~my-project~w~<workflow>           a standard workflow
#p~my-project~c~<workflow>           a workflow in the Visual Workflow Designer
#p~my-project~w~<workflow>~s~<step>  a step within a workflow
#p~my-project~t~<table>              a table in the Table Explorer
#p~my-project~d~<dimension>          a dimension hierarchy
#p~my-project~e~<editor>             a Data Editor
#home                                the Home landing page
```

Quando um projeto tem um nome de esquema, a ligação utiliza-o (`my-project` acima), o que a torna legível e estável. Caso contrário, é utilizado o identificador do projeto. Ambas as formas abrem o mesmo projeto.

<Aside type="note">
As ligações criadas antes do formato iniciado pelo projeto continuam a funcionar. As ligações antigas no estilo `?p=…&t=…` continuam a abrir a vista correta e a barra de endereços atualiza-se para o formato atual na sua primeira navegação.
</Aside>

### Quando Não É Possível Abrir uma Ligação

Se o objeto de uma ligação tiver entretanto sido eliminado, ou se não tiver acesso ao respetivo projeto, a ligação abre a aplicação sem essa vista, em vez de falhar. Fechar uma janela cuja ligação está na barra de endereços devolve o URL ao projeto proprietário, pelo que a barra de endereços nunca aponta para algo que já não está aberto.
