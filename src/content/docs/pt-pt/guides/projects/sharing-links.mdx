O PlaidCloud mantém a barra de endereço em sintonia com o que tem aberto. Abra um fluxo de trabalho, uma tabela, uma dimensão ou um ecrã em Painéis de controlo, Documentos ou Identidade, e o URL passa a ser uma **hiperligação direta** para esse item — copie esse URL, cole-o numa mensagem ou num pedido e quem o abrir chega ao mesmo ecrã.

## Copiar uma hiperligação

1. Abra o ecrã que pretende partilhar — um projeto, fluxo de trabalho, tabela, dimensão, editor de dados ou um ecrã de uma das outras aplicações.
2. Copie o URL completo da barra de endereço do navegador.
3. Envie-o.

Não existe um botão “partilhar” separado: a barra de endereço *é* a hiperligação. A funcionalidade de marcadores do navegador também funciona com estes URL, pelo que um ecrã a que regressa com frequência pode ser guardado como marcador como qualquer outra página Web.

<Aside type="note">
Uma hiperligação transporta apenas a *localização*, e não a permissão para a ver. Quem abrir a hiperligação continua a precisar de acesso ao projeto. Quem não o tiver não verá o objeto.

Uma hiperligação para uma aplicação que a pessoa não tem — porque a sua área de trabalho não a inclui, ou porque não lhe foi concedida — leva-a ao Início com uma nota a indicar que a hiperligação não estava disponível, em vez de parecer que nada aconteceu.
</Aside>

## Para o que pode criar hiperligações

### Analyze

| Ecrã | A hiperligação termina em |
|---|---|
| Projeto | `#p~<project>` |
| Fluxo de trabalho (grelha de passos) | `#p~<project>~w~<workflow>` |
| Fluxo de trabalho (área de desenho do Estruturador visual de fluxos de trabalho) | `#p~<project>~c~<workflow>` |
| Um passo dentro de um fluxo de trabalho | `…~w~<workflow>~s~<step>` ou `…~c~<workflow>~s~<step>` |
| Um passo isolado | `#p~<project>~s~<step>` |
| Explorador de tabelas | `#p~<project>~t~<table>` |
| Hierarquia da dimensão | `#p~<project>~d~<dimension>` |
| Editor de dados | `#p~<project>~e~<editor>` |
| Início | `#home` |

A parte da hiperligação referente ao projeto é o **esquema** do projeto quando este tem um esquema personalizado, pelo que as hiperligações aparecem como `#p~acme_budget~w~…` e não como uma sequência de hexadecimais. Os projetos que ficam no esquema predefinido utilizam, em vez disso, o identificador do próprio projeto. Ambas as formas abrem o mesmo projeto, pelo que uma hiperligação mais antiga continua a funcionar depois de definido um esquema.

### Painéis de controlo, Documentos e Identidade

Os ecrãs das outras aplicações são designados diretamente, pelo que as suas hiperligações aparecem como o próprio ecrã:

| Aplicação | Ecrã | Hiperligação |
|---|---|---|
| Painéis de controlo | Os meus painéis de controlo | `#dashboard.dashboards` |
| Painéis de controlo | Aplicações | `#dashboard.panel_apps` |
| Painéis de controlo | Jupyter Lite | `#dashboard.jupyterlite_deployments` |
| Documentos | Todas as contas | `#document.accounts` |
| Documentos | Contas partilhadas | `#document.shared_accounts` |
| Documentos | Contas privadas | `#document.private_accounts` |
| Documentos | Navegar pelos ficheiros de uma conta | `#document.browser~…` |
| Identidade | Membros | `#identity.members` |
| Identidade | Diretório de membros | `#identity.member_directory` |
| Identidade | Listas de distribuição | `#identity.distro.lists` |
| Identidade | Grupos de segurança | `#identity.security_groups` |
| Identidade | Auditoria de grupos de segurança | `#identity.security_group_audit` |
| Identidade | Âmbitos | `#identity.scopes` |
| Identidade | Sessões | `#identity.sessions` |
| Identidade | Clientes de API | `#identity.api_client_list` |
| Identidade | Registo de segurança | `#identity.security_log` |

Alguns ecrãs memorizam uma definição na hiperligação — as listas Membros e Diretório de membros guardam cada uma se estava a ver **Todos**, **Apenas ativos** ou **Apenas inativos**, e navegar por uma conta guarda qual a conta — o que o navegador mostra como um sufixo codificado a seguir ao nome do ecrã. Copie e cole o URL completo e este abre o ecrã em que estava; abri-lo quando esse ecrã já está aberto traz essa janela para a frente em vez de empilhar uma segunda.

<Aside type="note">
Estas hiperligações designam o ecrã, não um registo dentro dele. Uma hiperligação para Membros abre a lista de Membros; não abre o formulário de um membro.
</Aside>

## O que acontece quando alguém abre uma hiperligação

- **O projeto proprietário também é aberto.** Uma hiperligação para um fluxo de trabalho, tabela, passo, dimensão ou editor de dados abre também o respetivo projeto como um separador na parte inferior do ecrã, para que o destinatário chegue com o contexto envolvente e não com uma única janela solta.
- **Uma hiperligação para um passo seleciona o passo.** Uma hiperligação para um passo dentro de um fluxo de trabalho abre o fluxo de trabalho e realça esse passo — na área de desenho do Estruturador visual de fluxos de trabalho, o nó do passo fica selecionado.
- **Uma dimensão abre pronta para edição** quando o projeto está desbloqueado, e só de leitura quando está bloqueado — a mesma regra que se aplica quando a abre a partir do projeto.
- **Atualizar mantém-no onde está.** Recarregar a página volta a abrir o que a hiperligação designa, em vez de o devolver ao início.

## Mover-se entre ecrãs

O URL acompanha o que está a ver:

- Abrir um ecrã atualiza a barra de endereço, e o botão **Anterior** do navegador devolve-o ao ecrã anterior.
- **Qualquer que seja o caminho.** Abrir um fluxo de trabalho a partir do fluxo de atividade, de um cartão do Início, de uma ação **Detalhar para o fluxo de trabalho**, de uma listagem de “onde é utilizado” ou do registo atualiza a hiperligação tal como abri-lo a partir da lista de Fluxos de trabalho do projeto — e o mesmo acontece ao reabrir o ecrã em que já está.
- Selecionar o separador de uma janela na parte inferior do ecrã volta a colocar a hiperligação dessa janela na barra de endereço, pelo que alternar entre ecrãs abertos mantém o URL correto.
- Mudar para uma aplicação em que não está aberto nada que possa ter hiperligação **limpa** a hiperligação, em vez de a deixar a apontar para a aplicação que acabou de deixar.
- Fechar uma janela repõe o URL no ponto a partir do qual a abriu. Feche uma tabela que abriu a partir da área de desenho de um fluxo de trabalho e o URL regressa a essa área de desenho; feche uma que abriu a partir de um projeto e regressa ao projeto.
- Fechar a última janela de um projeto limpa a hiperligação.

## Hiperligações guardadas antes desta alteração

As hiperligações no estilo antigo `#te?p=…&t=…` continuam a funcionar. Abrir uma leva-o ao mesmo local e reescreve discretamente a barra de endereço na forma atual, pelo que, ao copiá-la de novo a partir daí, obtém a hiperligação mais recente e mais legível.
