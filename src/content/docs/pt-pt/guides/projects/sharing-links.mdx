O PlaidCloud mantém a barra de endereços alinhada com o que tem aberto. Abra um fluxo de trabalho, uma tabela, uma dimensão ou um ecrã em Painéis de controlo, Documentos ou Identidade, e o URL passa a ser uma **ligação direta** para esse item — copie esse URL, cole-o numa mensagem ou num pedido de suporte, e quem o abrir vai parar ao mesmo ecrã.

## Copiar uma ligação

1. Abra o ecrã que pretende partilhar — um projeto, fluxo de trabalho, tabela, dimensão, editor de dados ou um ecrã de uma das outras aplicações.
2. Copie o URL completo da barra de endereços do navegador.
3. Envie-o.

Não existe um botão de "partilha" separado: a barra de endereços *é* a ligação. A funcionalidade de marcadores do navegador também funciona com estes URLs, pelo que um ecrã a que regressa com frequência pode ser guardado nos marcadores como qualquer outra página Web.

<Aside type="note">
Uma ligação transporta apenas a *localização*, não a permissão para a ver. Quem abrir a ligação continua a precisar de acesso ao projeto. Quem não o tiver não verá o objeto.

Uma ligação para uma aplicação que a pessoa não tem — porque a sua área de trabalho não a inclui ou porque não lhe foi concedida — leva-a ao Início com uma nota a indicar que a ligação não estava disponível, em vez de parecer que nada acontece.
</Aside>

## Para o que pode criar ligações

### Analyze

| Ecrã | A ligação termina com |
|---|---|
| Projeto | `#p~<project>` |
| Fluxo de trabalho (grelha de passos) | `#p~<project>~w~<workflow>` |
| Fluxo de trabalho (área de desenho do Estruturador visual de fluxos de trabalho) | `#p~<project>~c~<workflow>` |
| Um passo dentro de um fluxo de trabalho | `…~w~<workflow>~s~<step>` ou `…~c~<workflow>~s~<step>` |
| Um passo isolado | `#p~<project>~s~<step>` |
| Explorador de tabelas | `#p~<project>~t~<table>` |
| Hierarquia de dimensão | `#p~<project>~d~<dimension>` |
| Editor de dados | `#p~<project>~e~<editor>` |
| Início | `#home` |

A parte do projeto na ligação é o **esquema** do projeto, quando este tem um personalizado, pelo que as ligações se lêem como `#p~acme_budget~w~…` em vez de uma cadeia hexadecimal. Os projetos que permanecem no esquema predefinido utilizam o identificador próprio do projeto. Ambas as formas abrem o mesmo projeto, pelo que uma ligação mais antiga continua a funcionar depois de definido um esquema.

### Painéis de controlo, Documentos e Identidade

Os ecrãs das outras aplicações têm nomes diretos, pelo que as respetivas ligações se lêem como o próprio ecrã:

| Aplicação | Ecrã | Ligação |
|---|---|---|
| Painéis de controlo | Painéis de controlo | `#dashboard.dashboards` |
| Painéis de controlo | Aplicações | `#dashboard.panel_apps` |
| Painéis de controlo | Notebooks | `#dashboard.jupyterlite_deployments` |
| Documentos | Gerir | `#document.accounts` |
| Documentos | As suas contas | `#document.your_accounts` |
| Documentos | Navegar pelos ficheiros de uma conta | `#document.browser~…` |
| Identidade | Membros | `#identity.members` |
| Identidade | Diretório | `#identity.member_directory` |
| Identidade | Listas de distribuição | `#identity.distro.lists` |
| Identidade | Grupos de segurança | `#identity.security_groups` |
| Identidade | Auditoria de grupos | `#identity.security_group_audit` |
| Identidade | Todos os âmbitos | `#identity.scopes` |
| Identidade | Sessões | `#identity.sessions` |
| Identidade | Clientes de API | `#identity.api_client_list` |
| Identidade | Registo de segurança | `#identity.security_log` |

Alguns ecrãs memorizam uma definição na ligação — as listas Membros e Diretório de membros guardam, cada uma, se estava a ver **Todos**, **Apenas ativos** ou **Apenas inativos**, e a navegação numa conta guarda qual a conta — que o navegador mostra como um sufixo codificado a seguir ao nome do ecrã. Copie e cole o URL completo e este abre o ecrã em que estava; abri-lo quando esse ecrã já está aberto traz essa janela para a frente em vez de empilhar uma segunda.

<Aside type="note">
Estas ligações indicam o ecrã, não um registo dentro dele. Uma ligação para Membros abre a lista de membros; não abre o formulário de um membro.
</Aside>

## O que acontece quando alguém abre uma ligação

- **O projeto a que pertence também é aberto.** Uma ligação para um fluxo de trabalho, tabela, passo, dimensão ou editor de dados abre também o respetivo projeto como um separador na parte inferior do ecrã, para que o destinatário chegue com o contexto envolvente em vez de uma única janela solta.
- **Uma ligação para um passo seleciona o passo.** Uma ligação para um passo dentro de um fluxo de trabalho abre o fluxo de trabalho e destaca esse passo — na área de desenho do Estruturador visual de fluxos de trabalho, o nó do passo fica selecionado.
- **Uma dimensão abre pronta para edição** quando o projeto está desbloqueado, e só de leitura quando está bloqueado — a mesma regra que se aplica quando a abre a partir do projeto.
- **Atualizar mantém-no onde está.** Recarregar a página volta a abrir o que a ligação indica, em vez de o devolver ao início.

## Mover-se entre ecrãs

O URL acompanha o que está a ver:

- Abrir um ecrã atualiza a barra de endereços, e o botão **Anterior** do navegador devolve-o ao ecrã anterior.
- **Independentemente de como lá chegou.** Abrir um fluxo de trabalho a partir do fluxo de atividade, de um cartão do Início, de uma ação **Detalhar para o fluxo de trabalho**, de uma listagem de "onde é utilizado" ou do registo atualiza a ligação tal como abri-lo a partir da lista de fluxos de trabalho do projeto — e o mesmo acontece ao reabrir o ecrã em que já está.
- Selecionar o separador de uma janela na parte inferior do ecrã coloca novamente a ligação dessa janela na barra de endereços, pelo que alternar entre ecrãs abertos mantém o URL fiel.
- Mudar para uma aplicação em que nada que admita ligação está aberto **limpa** a ligação, em vez de a deixar a apontar para a aplicação que acabou de deixar.
- Fechar uma janela repõe o URL no ponto de onde a abriu. Feche uma tabela que abriu a partir de uma área de desenho de fluxo de trabalho e o URL regressa a essa área de desenho; feche uma que abriu a partir de um projeto e regressa ao projeto.
- Fechar a última janela de um projeto limpa a ligação.

## Ligações guardadas antes desta alteração

As ligações no estilo mais antigo `#te?p=…&t=…` continuam a funcionar. Abrir uma leva-o ao mesmo local e reescreve discretamente a barra de endereços na forma atual, pelo que voltar a copiá-la a partir daí dá-lhe a ligação mais recente e mais legível.
