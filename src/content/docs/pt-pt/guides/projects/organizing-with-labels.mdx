## Descrição

As **Etiquetas** são marcadores de texto livre que associa aos objetos de um projeto — o próprio projeto, os seus fluxos de trabalho, passos, tabelas, dimensões, editores de dados e funções definidas pelo utilizador. Utilize-as para agrupar itens relacionados segundo o que for importante para si (uma fase do trabalho, um sistema de origem, um responsável, uma versão) e depois voltar a encontrar rapidamente esses itens.

As etiquetas são guardadas em minúsculas e apresentadas como pequenos chips onde quer que o objeto apareça, pelo que um conjunto consistente de etiquetas se torna uma forma leve de segmentar um projeto grande.

## Onde gerir as etiquetas

Todos os objetos etiquetáveis têm uma caixa **Etiquetas** no respetivo painel de detalhes:

- **Etiquetas do projeto** — na página inicial do projeto
- **Etiquetas do fluxo de trabalho**, **Etiquetas do passo**, **Etiquetas da tabela**, **Etiquetas da dimensão**, **Etiquetas do editor de dados** e **Etiquetas da UDF** — no painel de detalhes do item correspondente
- **Etiquetas** — no separador **Geral** do formulário de um passo de fluxo de trabalho

A caixa lista as etiquetas atuais do objeto como chips e disponibiliza um campo para adicionar mais, com um botão **Adicionar** junto ao campo.

## Adicionar uma etiqueta

1. Clique em qualquer ponto da caixa **Etiquetas** para colocar o cursor no campo de introdução.
2. Escreva o texto da etiqueta.
3. Clique em **Adicionar**, ou prima **Enter** (ou escreva uma vírgula), para a adicionar.

A nova etiqueta aparece como um chip e o campo de introdução é limpo para poder adicionar outra. Os chips passam para mais do que uma linha à medida que adiciona etiquetas, pelo que nada fica oculto.

<Aside type="note">
As etiquetas são convertidas automaticamente em minúsculas. Se a etiqueta que escrever já existir nesse objeto, o PlaidCloud informa-o e não adiciona uma duplicada.
</Aside>

<Aside type="note">
Num passo de fluxo de trabalho que está a criar pela primeira vez, as etiquetas que escrever ficam retidas até guardar o passo e só então são associadas a este. Todas as outras caixas **Etiquetas** guardam cada etiqueta assim que a adiciona.
</Aside>

## Remover uma etiqueta

- Clique no **×** de um chip para remover essa etiqueta, ou
- Com o campo de introdução vazio, prima **Backspace** para remover o último chip.

## Encontrar itens por etiqueta

As etiquetas aparecem como chips na coluna **Etiquetas** das listas do projeto — Fluxos de trabalho, Passos, Tabelas, etc. Para restringir uma lista aos itens que têm uma determinada etiqueta, escreva a etiqueta na caixa de filtro da lista; a pesquisa faz corresponder o texto das etiquetas juntamente com o nome do item. Passe o rato sobre um chip demasiado longo para a sua coluna para ver a etiqueta completa.
