## Descrição

**Página inicial do projeto** é o ponto de partida num projeto. Uma barra lateral à esquerda lista seis páginas: **Visão geral**, **Variáveis**, **Agendamentos e sensores**, **Acesso e partilha**, **Dados e ligações** e **Aplicações e identidade visual**. A Visão geral resume o projeto. As outras cinco páginas são onde se alteram as definições do projeto.

O indicador de **Variáveis** na barra lateral mostra quantas variáveis o projeto tem. O indicador de **Agendamentos e sensores** mostra quantos agendamentos e sensores estão ativos.

Um projeto bloqueado é só de leitura. As suas páginas apresentam um aviso que diz "Este projeto está bloqueado, pelo que é só de leitura. Desbloqueie-o em Visão geral para fazer alterações." e os respetivos controlos ficam desativados.

## Visão geral

![Página Visão geral da página inicial do projeto, com o nome do projeto, seis mosaicos, Coming up e Project defaults](/images/projects/project-home-overview.png)

A parte superior da página mostra o nome do projeto e se está **Editável** ou **Só de leitura**.

- **Descrição.** Clique no lápis para editar a descrição no próprio local. Prima Enter para guardar ou Escape para cancelar.
- **Etiquetas.** Escreva uma etiqueta em **Adicionar uma etiqueta…** e clique em **Adicionar**. Consulte [Organizar o trabalho com etiquetas](/pt-pt/guides/projects/organizing-with-labels/).
- **Bloquear** e **Unlock** alternam o projeto entre editável e só de leitura.

Os mosaicos contam o que o projeto contém:

| Mosaico | Mostra |
|---|---|
| **Tabelas** | Tabelas no projeto. |
| **Fluxos de trabalho** | Fluxos de trabalho no projeto. |
| **Passos** | Passos em todos os fluxos de trabalho. |
| **Variáveis** | Variáveis do projeto. |
| **Tabelas publicadas** | Tabelas que publicou. |
| **Tamanho dos dados** | O que as tabelas do projeto armazenam. Clique para abrir **Armazenamento**. Consulte [Gerir o armazenamento](/pt-pt/guides/projects/managing-storage/). |

Se algumas linhas do projeto estiverem filtradas para si, **Tamanho dos dados** mostra um traço porque o total não seria exato.

**Coming up** lista as próximas três execuções agendadas com os nomes dos respetivos fluxos de trabalho, e o número de sensores ativos. **View schedules ›** abre **Agendamentos e sensores**.

**Project defaults** mostra os valores de **Ambiente**, **Armazenamento de tabelas**, **Acesso** e **Lançamento ERP** que os fluxos de trabalho e os passos utilizam, a menos que definam os seus próprios. **Change settings ›** abre a página onde os pode alterar.

Os botões do cabeçalho são:

- **Relatório do projeto** cria um relatório do projeto como **Documento PDF** ou **HTML interativo**.
- **Exportar arquivo** guarda o projeto como um arquivo.
- **Atualizar** recarrega os mosaicos e as listas da página.

## Variáveis

A página **Variáveis** lista as variáveis do projeto numa grelha. Um fluxo de trabalho ou passo refere-se a uma variável pelo nome como `{name}`, e a variável própria de um fluxo de trabalho substitui uma variável do projeto com o mesmo nome.

A grelha mostra **Nome**, **Valor**, **Memorando**, **Última atualização** e **Por**. Utilize **Filtro** para restringir a lista, **Nova variável** para adicionar uma e **Editar** ou **Eliminar** para a linha selecionada.

## Agendamentos e sensores

![Página Agendamentos e sensores com uma faixa de resumo e duas grelhas](/images/projects/project-home-schedules.png)

Esta página mostra o que inicia automaticamente os fluxos de trabalho do projeto. Uma faixa de resumo mostra a próxima execução, o número de agendamentos ativos e em pausa, e o número de sensores ativos.

- Os **Agendamentos** executam um fluxo de trabalho segundo um calendário. A grelha mostra **Nome**, **Fluxo de trabalho**, **Execuções** (o calendário e o seu fuso horário), **Próxima execução** e **Estado**.
- Os **Sensores** executam um fluxo de trabalho quando chegam novos dados. A grelha mostra **Nome**, **Watches**, **Início** (o fluxo de trabalho), **Last triggered** e **Estado**.

**Estado** é **Ativo**, **Paused** ou, para um sensor com um problema, **Failing**. Cada grelha tem **New schedule** ou **Novo sensor**, **Editar**, **Eliminar** e **Filtro**. Abra **Ações** para **Activate** ou **Deactivate** a linha selecionada.

**Calendar view** mostra as próximas execuções num calendário, para que possa detetar conflitos de agendamento.

## Acesso e partilha

Esta página define quem pode aceder ao projeto e aos seus dados.

- **Project access** define **Who can open this project**: **Todos os membros da área de trabalho**, **Apenas grupos de segurança específicos** ou **Apenas membros específicos**. **Edit groups ›** e **Edit members ›** abrem as listas para escolher.
- **Dashboard audience** define a **Default audience for new dashboards**: todos no projeto ou grupos específicos. Cada painel de controlo pode alterar o seu próprio público. Consulte [Controlar quem pode ver um painel de controlo](/pt-pt/guides/dashboards/control-who-can-see-a-dashboard/).
- **Partilhas de dados** lista os projetos que podem ler tabelas deste. Consulte [Partilhar dados entre projetos](/pt-pt/guides/projects/managing-projects/#partilhar-dados-entre-projetos).

## Dados e ligações

![Página Dados e ligações com ligações, armazenamento de tabelas e lançamento ERP](/images/projects/project-home-data.png)

Estas definições aplicam-se a todos os fluxos de trabalho e passos do projeto, a menos que um fluxo de trabalho ou passo defina as suas próprias.

- **Ambiente da ligação** escolhe as credenciais que um passo utiliza quando não escolhe nenhuma. A página avisa-o quando uma ligação do projeto não tem configuração para o ambiente selecionado.
- **Conta de documentos predefinida** escolhe onde os passos leem e escrevem ficheiros.
- **Armazenamento de tabelas predefinido** escolhe onde são criadas as novas tabelas.
- **Time travel retention** define durante quantos dias são conservadas as versões anteriores dos dados das tabelas. As tabelas que herdam esta definição também conservam um histórico mais longo. O histórico que já expirou não pode ser recuperado.
- **Modo de lançamento** define como o projeto envia lançamentos contabilísticos para os ERP ligados. É um limite máximo para o projeto: a execução de um fluxo de trabalho não pode lançar de forma mais permissiva do que esta definição. **Real** lança normalmente. **Simular** constrói e valida, mas nunca lança nem contacta o ERP. **Desligado** ignora os passos de lançamento.
- **Write authorizations** mostra quantas ligações ERP estão autorizadas para lançamento. Os administradores podem clicar em **Manage authorizations ›**.

## Aplicações e identidade visual

Esta página abrange as aplicações criadas sobre os dados do projeto.

- **Aplicações Panel** mostra quantas aplicações foram criadas sobre o projeto. **Open Panel apps ›** abre-as e **Nova aplicação Studio** inicia uma.
- **Branding** define o logótipo e as cores que as aplicações do projeto utilizam. **Edit branding ›** abre as definições.
- **Home tile image** é a imagem apresentada no mosaico do projeto na página Home. Clique em **Escolher...** para escolher uma imagem ou em **Limpar** para a remover.
