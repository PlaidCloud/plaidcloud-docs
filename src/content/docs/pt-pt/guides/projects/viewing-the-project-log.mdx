## Ver e ordenar o registo do projeto

À medida que ocorrem ações num projeto, como atribuir novos membros ou executar fluxos de trabalho, o Registo do projeto guarda os eventos. O Registo do projeto consolida a vista 
de todos os registos individuais dos fluxos de trabalho para proporcionar uma visão mais abrangente das atividades do projeto. O PlaidCloud permite também ao utilizador ordenar e 
filtrar um Registo do projeto e ver os detalhes de uma entrada de registo em particular.


**Para ver o Registo do projeto:**
1. Abra o Analyze
2. Selecione “Projetos”
3. Clique no ícone de registo

**Para ordenar e filtrar o Registo do projeto:**
1. Clique no pequeno ícone à direita do registo e à esquerda da “mensagem de registo”
2. Selecione os critérios pretendidos

**Para ver os detalhes de uma entrada de registo em particular:**
1. Clique com o botão direito do rato na entrada de registo pretendida
2. Veja a caixa “Mensagem de registo” para obter os detalhes

## Limpar o registo do projeto

Pode ser desejável limpar o Registo do projeto de vez em quando

<Aside>Limpar o Registo do projeto inclui eliminar todos os subregistos de cada fluxo de trabalho</Aside>

**Para limpar o Registo do projeto:**
1. Abra o Analyze
2. Selecione “Projetos”
3. Clique no ícone de registo
4. Clique no botão “Limpar registo”
