O [Data Foundation](/pt-pt/guides/projects/data-foundation/) reúne os dados de todos os sistemas ERP e instâncias que ligar num único Common Finance Model, e o Sage Intacct é um dos ERP que lê diretamente. A ligação utiliza os Intacct Web Services: uma autorização de remetente para o PlaidCloud e um utilizador de Web Services só de leitura. Esta página destina-se ao administrador do Sage Intacct que faz essa configuração e ao utilizador do PlaidCloud que lha pede.

O PlaidCloud só lê dados. Ninguém envia uma palavra-passe por email.

## Enviar o pedido de acesso

Na página **Sistemas** do projeto, em **Data Foundation** no **Início**, escolha o seu sistema em **Sistema**, em **Adicionar um sistema**, e clique em **Ainda não tem acesso?**. O sistema fica a aguardar acesso e é apresentado um único pedido que abrange os sistemas do projeto. Clique em **Copiar pedido** para o colar na sua própria mensagem ou em **Enviar pedido por email** para o abrir no seu programa de correio com o assunto "Acesso ao PlaidCloud."

## O que o administrador do Sage Intacct configura

<Steps>

1. **Autorizar o PlaidCloud como remetente de Web Services.** Em **Company > Admin > Web Services authorizations**, adicione o Sender ID que o PlaidCloud lhe indicou. Envie de volta o Sender ID e a palavra-passe de remetente que a Sage emitiu para ele.

2. **Criar um utilizador de Web Services.** Em **Company > Admin > Users**, crie um utilizador do tipo "Business" com a opção "Web services only" e uma função com permissão **View** sobre:

   | Área | Objetos |
   |---|---|
   | Razão geral | Contas, contas estatísticas, lançamentos de diário (todos os diários, incluindo os diários de ajustamento), saldos de contas, períodos de relato, taxas de câmbio, orçamentos |
   | Empresa | Entidades (localizações), departamentos, classes, projetos |
   | Contas a receber | Clientes, faturas, ajustamentos, pagamentos |
   | Contas a pagar | Fornecedores, faturas de fornecedores, ajustamentos, pagamentos |
   | Gestão de tesouraria | Contas à ordem |
   | Controlo de inventário | Artigos |
   | Introdução de encomendas | Transações (faturas de venda e as notas de crédito e devoluções que as anulam), se pretender vendas |

   Dê ao utilizador acesso ao nível superior da empresa e a todas as entidades sobre as quais o PlaidCloud reporta. Se as definições de transação das suas notas de crédito e devoluções não se chamarem Sales Credit Memo e Sales Return, indique os respetivos nomes ao utilizador do PlaidCloud.

3. **Permitir o endereço IP do utilizador** se a sua empresa restringir os Web Services por IP.

</Steps>

## O que enviar de volta

| O administrador envia | Introduzido no PlaidCloud como |
|---|---|
| O ID da empresa | **ID da empresa** |
| O ID do utilizador de Web Services | **Nome de utilizador do utilizador de serviço Web** |
| O Sender ID | **ID do cliente** |
| A palavra-passe de remetente | **Segredo do cliente** |
| Os nomes das definições de transação das suas notas de crédito e devoluções, se não forem os predefinidos | A definição de sistema **Credit memo and return document types** (predefinições: Sales Credit Memo, Sales Return) |
| As entidades que o PlaidCloud pode ler | Em **Opções**, **Empresas**: assinale-as, ou nenhuma para todas |

As palavras-passe passam pelo seu gestor de palavras-passe, nunca por email. A equipa do utilizador do PlaidCloud introduz por si própria a palavra-passe de remetente como **Segredo do cliente**. As entidades que são as eliminações da sua própria empresa ficam na definição de sistema **Elimination entities**.

## Verificar o acesso

De volta ao PlaidCloud, depois de o sistema ser adicionado, clique em **Testar ligação** na respetiva linha da página **Sistemas**. O teste lê os conjuntos de dados obrigatórios e apresenta cada um como **Legível**, **Permissão em falta** ou **Erro**. Os opcionais, assinalados abaixo, não fazem parte do teste: se o Sage Intacct recusar um deles, após o carregamento seguinte as verificações de prontidão, no painel de controlo **CFM-Accounting - Close and assurance**, indicam o objeto a conceder.

| Conjunto de dados | Permissão de que necessita |
|---|---|
| Entidades | Empresa: Entidades (View) |
| Plano de contas | Razão geral: Contas e contas estatísticas (View) |
| Departamentos | Empresa: Departamentos (View) |
| Clientes | Contas a receber: Clientes (View) |
| Produtos | Controlo de inventário: Artigos (View) |
| Taxas de câmbio | Razão geral: Taxas de câmbio (View) |
| Calendário fiscal | Razão geral: Períodos de relato (View) |
| Balancete | Razão geral: Saldos de contas (View) |
| Razão geral | Razão geral: Lançamentos de diário (View) |
| Saldo de fim de mês (opcional) | Razão geral: Saldos de contas (View) |
| Saldos bancários (opcional) | Gestão de tesouraria: Contas à ordem (View), com o saldo de fim de mês |
| Sites (opcional) | Empresa: Entidades (localizações) (View) |
| Centros de lucro (opcional) | Empresa: Classes (View) |
| Projetos (opcional) | Empresa: Projetos (View) |
| Fornecedores (opcional) | Contas a pagar: Fornecedores (View) |
| Linhas de vendas (opcional) | Introdução de encomendas: Transações (View) |
| Linhas de faturas de fornecedores (opcional) | Contas a pagar: Faturas de fornecedores e ajustamentos (View) |
| Itens em aberto e Pagamentos (opcional) | Contas a receber: Faturas, ajustamentos e pagamentos, e Contas a pagar: Faturas de fornecedores, ajustamentos e pagamentos (View) |
| Orçamento (opcional) | Razão geral: Orçamentos (View) |
| Indutores de alocação (opcional) | Razão geral: Saldos de contas (View) |

Quando falta um conjunto de dados, o teste indica a permissão a adicionar. Peça ao administrador que a adicione à função e teste novamente. Uma empresa que não utilize um conjunto de dados opcional carrega na mesma tudo o resto. Quando o Sage Intacct recusa uma leitura a partir da qual são construídos as faturas de fornecedores, os itens em aberto ou os pagamentos de um mês, esse mês mantém as linhas que já tinha e é lido novamente no carregamento seguinte.

Quem introduziu um lançamento de diário, quando, quem o aprovou e o que estorna são lidos a partir do lote do lançamento. Uma função que não consiga ler o lote deixa-os vazios.
