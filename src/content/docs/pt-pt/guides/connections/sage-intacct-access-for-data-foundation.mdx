O [Data Foundation](/pt-pt/guides/projects/data-foundation/) reúne os dados de todos os sistemas ERP e instâncias que ligar num único Common Finance Model, e o Sage Intacct é um dos ERP que lê diretamente. A ligação utiliza os Intacct Web Services: uma autorização de remetente para o PlaidCloud e um utilizador de Web Services só de leitura. Esta página destina-se ao administrador do Sage Intacct que faz essa configuração e ao utilizador do PlaidCloud que lha pede.

O PlaidCloud só lê dados. Ninguém envia uma palavra-passe por email.

## Enviar o pedido de acesso

No separador **Base** do projeto, escolha **Criar uma nova ligação** em **Ligação Sage Intacct**. O formulário mostra o pedido completo. Clique em **Copiar pedido** para o colar na sua própria mensagem, ou em **Enviar pedido por email** para o abrir no seu programa de correio com o assunto "Read-only Sage Intacct access for PlaidCloud (Web Services)."

## O que o administrador do Sage Intacct configura

<Steps>

1. **Autorizar o PlaidCloud como remetente de Web Services.** Em **Company > Admin > Web Services authorizations**, adicione o Sender ID que o PlaidCloud lhe indicou. Envie de volta o Sender ID e a palavra-passe de remetente que a Sage emitiu para ele.

2. **Criar um utilizador de Web Services.** Em **Company > Admin > Users**, crie um utilizador do tipo "Business" com a opção "Web services only" e uma função com permissão **View** sobre:

   | Área | Objetos |
   |---|---|
   | Razão geral | Contas, lançamentos de diário (todos os diários, incluindo os diários de ajustamento), saldos de contas, períodos de relato, taxas de câmbio, orçamentos |
   | Empresa | Entidades (localizações), departamentos, classes, projetos |
   | Contas a receber | Clientes |
   | Controlo de inventário | Artigos |
   | Introdução de encomendas | Transações (faturas de venda e as notas de crédito e devoluções que as anulam), se pretender vendas |

   Dê ao utilizador acesso ao nível superior da empresa e a todas as entidades sobre as quais o PlaidCloud reporta. Se as definições de transação das suas notas de crédito e devoluções não se chamarem Sales Credit Memo e Sales Return, indique os respetivos nomes ao utilizador do PlaidCloud.

3. **Permitir o endereço IP do utilizador** se a sua empresa restringir os Web Services por IP.

</Steps>

## O que enviar de volta

| O administrador envia | Introduzido no PlaidCloud como |
|---|---|
| O ID da empresa | **ID da empresa** |
| O ID do utilizador de Web Services | **Web services user ID** |
| A palavra-passe do utilizador de Web Services | **Web services password** |
| O Sender ID | **Sender ID** |
| A palavra-passe de remetente | **Sender password** |
| Os nomes das definições de transação das suas notas de crédito e devoluções, se não forem os predefinidos | A definição de sistema `credit_documents` (predefinições: Sales Credit Memo, Sales Return) |
| As entidades que o PlaidCloud pode ler | Escolhidas em **Entidades** no PlaidCloud |

As palavras-passe passam pelo seu gestor de palavras-passe, nunca por email. A equipa do utilizador do PlaidCloud cola a **Web services password** e a **Sender password** no PlaidCloud por si própria. As entidades que são as eliminações da sua própria empresa ficam na definição de sistema `elimination_entities`.

## Verificar o acesso

De volta ao PlaidCloud, introduza os valores e clique em **Testar ligação**. Cada conjunto de dados aparece como **Legível**, **Permissão em falta** ou **Erro**:

| Conjunto de dados | Permissão de que necessita |
|---|---|
| Entidades | Empresa: Entidades (View) |
| Plano de contas | Razão geral: Contas e contas estatísticas (View) |
| Departamentos | Empresa: Departamentos (View) |
| Clientes | Contas a receber: Clientes (View) |
| Produtos | Controlo de inventário: Artigos (View) |
| Taxas de câmbio | Razão geral: Taxas de câmbio (View) |
| Calendário fiscal | Razão geral: Períodos de relato (View) |
| Balancete | Razão geral: Saldos de contas (View) |
| Razão geral | Razão geral: Lançamentos de diário (View) |
| Linhas de vendas | Introdução de encomendas: Transações (View) |
| Orçamento | Razão geral: Orçamentos (View) |
| Indutores de alocação | Razão geral: Saldos de contas (View) |

Quando falta um conjunto de dados, o teste indica a permissão a adicionar. Peça ao administrador que a adicione à função e teste novamente. As linhas de vendas, o orçamento e os indutores de alocação são opcionais: uma empresa que não os utilize carrega na mesma tudo o resto.
