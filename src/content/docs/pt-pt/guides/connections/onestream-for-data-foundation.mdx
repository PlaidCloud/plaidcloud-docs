Ligue o PlaidCloud ao **OneStream** para que o Data Foundation possa ler os seus resultados consolidados e reconciliar com eles a demonstração de resultados de gestão do grupo. O OneStream é suportado através do respetivo conector: o PlaidCloud inicia sessão com credenciais de cliente OAuth 2.0 e lê um adaptador de dados que o administrador do OneStream cria. Só lê. Se indicar uma sequência de Data Management, o PlaidCloud executa primeiro essa sequência para atualizar o que o adaptador lê, e não executa mais nada.

O OneStream é uma origem de resultados com que reconciliar, não de linhas do razão: as suas linhas são carregadas como o cenário `Consolidated` da tabela de orçamento do modelo, versão `OneStream`. Consulte [Reconciliar com o seu sistema de consolidação](/pt-pt/guides/projects/data-foundation/#reconciliar-com-o-seu-sistema-de-consolidação).

<Aside type="note">
As colunas do adaptador são um contrato que acorda com o administrador do OneStream. Quando o adaptador é criado de acordo com esta página, as suas linhas são carregadas como descrito abaixo. Compare os resultados do primeiro carregamento com um relatório do OneStream em que confie.
</Aside>

## O que o administrador do OneStream configura

O separador **Base** redige um pedido de acesso para lhe enviar. Esse pedido solicita o seguinte.

1. Um cliente para o PlaidCloud no serviço de identidade do OneStream que utilize a concessão de **credenciais de cliente**, com um utilizador de serviço que possa executar o adaptador e, se pretender que o PlaidCloud atualize primeiro os resultados, a sequência de Data Management.

2. Na aplicação e na área de trabalho sobre as quais reporta, um adaptador de dados com o nome **Foundation_Results** que devolve uma tabela dos resultados consolidados com exatamente estas colunas:

   | Coluna | Contém |
   |---|---|
   | `entity` | O membro de consolidação: uma entidade, um membro de eliminação ou o total do grupo. |
   | `account` | O código da conta. Apenas contas de base. |
   | `time` | O mês, como `YYYY-MM`. |
   | `scenario` | O cenário. |
   | `view` | `YTD` ou `Periodic`. O PlaidCloud lê apenas as linhas da vista que escolher. |
   | `amount` | Um número, no sinal e na escala que os seus relatórios mostram. |
   | `currency` | A moeda em que o montante está expresso: a moeda de relato do seu grupo. |
   | `flow`, `ud1`, `ud2`, `ud3`, `ud4` | Dimensões de fluxo e definidas pelo utilizador. Apenas membros de base. |

   Sirva membros de base das dimensões de conta, de fluxo e definidas pelo utilizador. A linha de um membro pai contaria os seus filhos duas vezes. O adaptador lê o membro de consolidação a partir da variável de substituição `Member` e a vista a partir de `View`.

3. Os membros a ler: as entidades, os membros de eliminação e o total do grupo.

## Criar a ligação

<Steps>

1. Abra **Tools > Connections** e clique em `New Connection`, e depois escolha **OneStream**. Ou crie-a a partir do separador **Base** quando adicionar a origem.

2. Preencha os campos:

   | Campo | Valor |
   |---|---|
   | Anfitrião | O URL base do OneStream, começado por `https://`. |
   | ID do cliente | O ID de cliente do cliente PlaidCloud. |
   | Segredo do cliente | O respetivo segredo. Guardado cifrado e nunca mais apresentado. |
   | URL do token | Deixe em branco para usar o anfitrião seguido de `/identity/connect/token`. |
   | Aplicação predefinida | Utilizada por uma leitura que deixe a aplicação em branco. |
   | Área de trabalho predefinida | Utilizada por uma leitura que deixe a área de trabalho em branco. |
   | Tempo limite (segundos) | O valor predefinido é 120. |

3. Clique em `Create`.

</Steps>

## Adicioná-lo a um projeto do Data Foundation

No separador **Base**, adicione a ligação como origem, como faria com qualquer outra (consulte [Ligar o seu ERP](/pt-pt/guides/projects/data-foundation/#ligar-o-seu-erp)), e escolha os membros de consolidação a ler. Depois, responda ao que descreve os montantes do adaptador:

| Definição | O que significa |
|---|---|
| Membros | Os membros de consolidação a ler, com uma chamada ao adaptador para cada um. |
| Vista | Se os montantes do adaptador são acumulados no ano (o predefinido) ou periódicos. As linhas acumuladas no ano são carregadas como montantes periódicos. |
| Sinal | **Natural**: cada conta com o seu próprio sinal, como o OneStream o comunica (o predefinido). **Débito positivo**: débitos positivos. |
| Escala | O multiplicador para unidades monetárias inteiras: `1000` quando o OneStream serve milhares. |
| Mês de início do ano fiscal | O mês em que o seu ano fiscal começa, para converter de acumulado no ano para periódico. |
| Aplicação, área de trabalho | Substituem as da ligação. |
| Variáveis de substituição | Variáveis adicionais que o adaptador lê, por exemplo `Time=2026M1`. |
| Sequência de Data Management | Uma sequência executada antes da leitura para atualizar o que o adaptador lê. |

Mapeie os membros do OneStream para as suas entidades com um ficheiro de mapa de códigos que se aplique a esta origem. Consulte [Mapeamento de entidades](/pt-pt/guides/projects/data-foundation/#mapeamento-de-entidades). A origem não lê nenhuma janela de histórico: as próprias variáveis de substituição do adaptador delimitam-na.

Um carregamento em que o adaptador não devolve linhas termina com um aviso, não com um erro, e a tabela fica vazia.
