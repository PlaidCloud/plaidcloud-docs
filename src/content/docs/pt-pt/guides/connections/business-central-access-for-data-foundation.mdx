O [Data Foundation](/pt-pt/guides/projects/data-foundation/) reúne os dados de todos os sistemas ERP e instâncias que ligar num único Common Finance Model, e o Microsoft Dynamics 365 Business Central é um dos ERP que lê diretamente. A ligação utiliza uma aplicação Microsoft Entra ID com credenciais de cliente, um conjunto de permissões só de leitura e algumas páginas publicadas como serviços Web. Esta página destina-se ao administrador do Business Central que faz essa configuração e ao utilizador do PlaidCloud que lha pede.

O PlaidCloud só lê dados. Ninguém envia um segredo do cliente por email.

## Enviar o pedido de acesso

No separador **Base** do projeto, escolha **Criar uma nova ligação** em **Ligação Business Central**. O formulário mostra o pedido completo. Clique em **Copiar pedido** para o colar na sua própria mensagem, ou em **Enviar pedido por email** para o abrir no seu programa de correio com o assunto "Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials)."

## O que o administrador do Business Central configura

<Steps>

1. **Registar uma aplicação no Microsoft Entra ID.** Em **App registrations > New registration**, adicione um segredo do cliente e tome nota do ID do diretório (inquilino), do ID da aplicação (cliente) e do segredo.

2. **Adicionar a aplicação no Business Central.** Abra **Microsoft Entra Applications**, adicione a aplicação, defina o respetivo estado como **Ativado** e atribua-lhe os conjuntos de permissões **D365 READ** e **D365 BASIC** para cada empresa sobre a qual reporta. Não lhe atribua um conjunto de permissões de escrita.

3. **Publicar páginas como serviços Web.** Em **Search > Web Services > New**, publique estas páginas exatamente com estes nomes de serviço e com **Published** assinalado. A API standard não inclui os respetivos campos:

   | Página | Nome do serviço | Notas |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | Custo das mercadorias vendidas; opcional |
   | 120 G/L Budget Entries | `GLBudgetEntries` | Orçamentos; opcional |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | Indutores estatísticos; opcional |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | Dimensões de atalho 3 a 8; opcional |
   | 479 Dimension Set Entries | `DimensionSetEntries` | Dimensões de atalho 3 a 8; opcional |

4. **Indicar ao utilizador do PlaidCloud duas escolhas:** o código de origem sob o qual os seus ajustes de auditoria são lançados (o PlaidCloud assume `ADJUSTMENT`) e qual a dimensão que corresponde ao seu departamento (o PlaidCloud assume a Global Dimension 1, com o nome `DEPARTMENT`).

</Steps>

## O que enviar de volta

| O administrador envia | Introduzido no PlaidCloud como |
|---|---|
| O ID do diretório (inquilino) | **Directory (tenant) ID** |
| O nome do ambiente, por exemplo `production` | **Nome do ambiente** |
| O ID da aplicação (cliente) | **Application (client) ID** |
| O segredo do cliente | **Segredo do cliente**, introduzido através do formulário, não por email |
| O nome da dimensão que corresponde ao seu departamento | A definição de sistema `department_dimension` |
| As empresas que o PlaidCloud pode ler | Escolhidas em **Companies** no PlaidCloud (pelo menos uma) |

As empresas que são empresas de consolidação ficam na definição de sistema `consolidation_companies`, para que os seus lançamentos não sejam contados como atividade de uma empresa. As taxas de câmbio provêm de uma só empresa: indique-a na definição de sistema `rate_company`, ou o PlaidCloud utiliza a primeira empresa.

## Verificar o acesso

De volta ao PlaidCloud, introduza os valores e clique em **Testar ligação**. Cada conjunto de dados aparece como **Legível**, **Permissão em falta** ou **Erro**:

| Conjunto de dados | O que necessita |
|---|---|
| Entidades, Plano de contas, Clientes, Produtos, Taxas de câmbio, Balancete | Acesso à API (conjunto de permissões D365 READ) |
| Calendário fiscal | O serviço Web `AccountingPeriods` |
| Departamentos | O serviço Web `DimensionValues` |
| Razão geral | O serviço Web `GLEntries` |
| Linhas de vendas, Orçamento, Indutores de alocação | Opcional |

Quando falta um conjunto de dados, o teste indica que permissão ou serviço Web deve ser adicionado. Peça ao administrador que o adicione e teste novamente. As linhas de vendas, o orçamento e os indutores de alocação são opcionais: um ambiente que não os utilize carrega na mesma tudo o resto.
