O [Data Foundation](/pt-pt/guides/projects/data-foundation/) reúne os dados de todos os sistemas ERP e instâncias que ligar num único Common Finance Model, e o Dynamics 365 Finance and Operations é um dos ERP que lê diretamente. A ligação utiliza uma aplicação Microsoft Entra ID com um segredo do cliente para os dados mestre e o ponto final SQL do seu Fabric (Synapse) Link para o diário geral. Esta página destina-se ao administrador do Dynamics 365 que faz essa configuração e ao utilizador do PlaidCloud que lha pede.

O PlaidCloud só lê dados. Ninguém envia um segredo do cliente nem uma palavra-passe SQL por email.

## Enviar o pedido de acesso

No separador **Base** do projeto, escolha **Criar uma nova ligação** em **Dynamics 365 Finance and Operations connection**. O formulário mostra o pedido completo. Clique em **Copiar pedido** para o colar na sua própria mensagem, ou em **Enviar pedido por email** para o abrir no seu programa de correio com o assunto "Read-only Dynamics 365 Finance and Operations access for PlaidCloud."

## O que o administrador do Dynamics 365 configura

<Steps>

1. **Registar uma aplicação no Microsoft Entra ID** para o PlaidCloud, com um segredo do cliente. Tome nota do respetivo ID da aplicação (cliente), do ID do diretório (inquilino) e do segredo.

2. **Associar a aplicação a um utilizador.** No Dynamics 365, em **System administration > Setup > Microsoft Entra ID applications**, adicione o ID do cliente e associe-o a um utilizador com uma função que possa ver, para cada entidade legal que pretende carregar:

   - Razão geral: entidades legais, calendários fiscais, contas principais, valores de dimensões financeiras, taxas de câmbio
   - Contas a receber: clientes e linhas de faturas de clientes
   - Gestão de informação de produtos: produtos libertados
   - Gestão de inventário: existências disponíveis e transações de inventário (opcional)
   - Orçamentação: lançamentos do registo de orçamento (opcional)

3. **Configurar o Fabric Link para o diário geral.** As linhas do diário geral são lidas a partir do ponto final SQL do seu Fabric (Synapse) Link, não do serviço OData. Confirme que o Fabric Link está ativo para estas tabelas e crie nesse ponto final um início de sessão SQL só de leitura para o PlaidCloud:

   - `generaljournalaccountentry`
   - `generaljournalentry`
   - `fiscalcalendarperiod`
   - `dimensionattributelevelvalue`, com uma linha por cada valor de dimensão de cada combinação de dimensões financeiras e o nome da respetiva dimensão

</Steps>

## O que enviar de volta

| O administrador envia | Introduzido no PlaidCloud como |
|---|---|
| O URL do ambiente, `https://<name>.operations.dynamics.com` | **URL do ambiente** |
| O ID do diretório (inquilino) | **Directory (tenant) ID** |
| O ID da aplicação (cliente) | **Application (client) ID** |
| O ponto final SQL, a base de dados e o início de sessão do Fabric Link | Uma ligação SQL separada no PlaidCloud, escolhida na definição de sistema `fabric_connection_id` |
| As categorias de conta principal das suas contas de custo das mercadorias vendidas (o PlaidCloud assume `COGS`) | A definição de sistema `cogs_categories` |
| As categorias de conta principal das contas que não são operacionais: juros, imposto sobre o rendimento, ganhos e perdas cambiais, outros rendimentos | A definição de sistema `non_operating_categories` |
| A dimensão financeira que nomeia o parceiro intercompanhia de uma linha (o PlaidCloud assume `IntercompanyPartner`) | A definição de sistema `ic_partner_dimension` |
| As entidades legais que o PlaidCloud pode ler | Escolhidas em **Legal entities** no PlaidCloud |

O segredo do cliente e a palavra-passe do início de sessão SQL nunca são enviados por email. A equipa do utilizador do PlaidCloud cola o **Segredo do cliente** no PlaidCloud por si própria, e a ligação SQL guarda o início de sessão SQL. As entidades legais que são entidades de consolidação ficam na definição de sistema `consolidation_companies`, para que os seus lançamentos não sejam contados como atividade de uma empresa.

## Verificar o acesso

De volta ao PlaidCloud, introduza os valores e clique em **Testar ligação**. Cada conjunto de dados aparece como **Legível**, **Permissão em falta** ou **Erro**:

| Conjunto de dados | Permissão de que necessita |
|---|---|
| Entidades | Razão geral: Ver entidades legais |
| Calendário fiscal | Razão geral: Ver calendários fiscais |
| Plano de contas | Razão geral: Ver contas principais |
| Departamentos | Razão geral: Ver valores de dimensões financeiras |
| Clientes | Contas a receber: Ver clientes |
| Produtos | Gestão de informação de produtos: Ver produtos libertados |
| Taxas de câmbio | Razão geral: Ver taxas de câmbio |
| Balancete, Razão geral | Ver o razão geral (o diário, através do Fabric Link) |
| Linhas de vendas, Saldos de inventário, Orçamento | Opcional |

Quando falta um conjunto de dados, o teste indica a permissão a adicionar. Peça ao administrador que a adicione à função e teste novamente. As linhas de vendas, os saldos de inventário e o orçamento são opcionais: um ambiente que não os contenha carrega na mesma tudo o resto.
