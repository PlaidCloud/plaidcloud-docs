## Descrição

A clonagem duplica a configuração de uma ligação existente — anfitrião, porta, opções, referência às credenciais — para que possa editar alguns campos e guardá-la como uma nova ligação, em vez de voltar a introduzir todas as definições.

A clonagem funciona para todos os tipos de ligação de dados externa: base de dados, ERP, REST, serviço na cloud, Git e documentos.


## Clonar uma ligação

1. Abra **Tools > Connections**
2. Selecione a ligação que pretende copiar
3. Clique em `Clone` na barra de ferramentas (ou clique com o botão direito do rato na linha e selecione `Clone`)
4. Edite o nome da nova ligação e quaisquer campos que devam ser diferentes
5. Clique em `Save`


## Ações apenas para proprietários

`Edit`, `Clone` e `Delete` só estão disponíveis nas ligações de que é proprietário. Se esses botões da barra de ferramentas estiverem a cinzento para a linha selecionada, não é o proprietário — peça ao proprietário que clone a ligação por si, ou que o adicione como proprietário adicional através de `Edit Owners`.

<Aside>A clonagem copia a configuração, mas não os resultados de testes nem o histórico de execuções. Teste a ligação clonada antes de depender dela num fluxo de trabalho.</Aside>
