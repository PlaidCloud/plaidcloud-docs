O [Data Foundation](/pt-pt/guides/projects/data-foundation/) reúne os dados de todos os sistemas ERP e instâncias que ligar num único Common Finance Model, e o SAP ECC é um dos ERP que lê diretamente. O PlaidCloud chega ao sistema através de um agente [PlaidLink](/pt-pt/reference/cli/plaidlink/) instalado na sua própria rede, por RFC. Esta página destina-se ao administrador SAP que faz essa configuração e ao utilizador do PlaidCloud que lha pede.

O PlaidCloud só lê dados. Ninguém envia uma palavra-passe por email.

## Enviar o pedido de acesso

Na página **Sistemas** do projeto, em **Data Foundation** no **Início**, escolha o seu sistema em **Sistema**, em **Adicionar um sistema**, e clique em **Ainda não tem acesso?**. O sistema fica a aguardar acesso e é apresentado um único pedido que abrange os sistemas do projeto. Clique em **Copiar pedido** para o colar na sua própria mensagem ou em **Enviar pedido por email** para o abrir no seu programa de correio com o assunto "Acesso ao PlaidCloud."

## O que o administrador SAP configura

<Steps>

1. **Instalar o pacote ABAP do PlaidCloud** (grupo de funções de `Z_PLAIDCL_B5_READ_TABLE`) no mandante a partir do qual reporta, e instalar um agente PlaidLink que consiga chegar ao sistema por RFC.

2. **Criar um utilizador de comunicação**, por exemplo `PLAIDCLOUD_RFC`, com uma função que contenha estas autorizações:

   - `S_RFC`: executar o grupo de funções de `Z_PLAIDCL_B5_READ_TABLE`.
   - `S_TABU_NAM` (visualização, `ACTVT` 03) para as tabelas abaixo.

   | Tabelas | O que contêm |
   |---|---|
   | `T001` | Códigos de empresa |
   | `T009`, `T009B`, `T001B` | Variantes de ano fiscal e períodos de lançamento |
   | `SKA1`, `SKAT` | Contas do razão |
   | `FAGL_011PC`, `FAGL_011ZC` | Versão da demonstração financeira |
   | `CSKS`, `CSKT` | Centros de custo |
   | `SETHEADER`, `SETNODE` | Grupos de centros de custo e de centros de lucro |
   | `CEPC`, `CEPCT` | Centros de lucro (opcional) |
   | `KNA1`, `KNVV`, `KNVH` | Clientes e a respetiva hierarquia |
   | `MARA`, `MAKT`, `T006A` | Materiais e unidades |
   | `TCURR`, `TCURF`, `TCURX` | Taxas de câmbio e casas decimais das moedas |
   | `BKPF`, `BSEG` | Documentos contabilísticos e respetivas linhas |
   | `FAGLFLEXT`, ou, no razão geral clássico, `GLT0` | Totais do razão geral |
   | `CSKB`, `CSKU`, `COEP` | Elementos de custo e linhas de controlling: repartições e alocações |
   | `COSP`, `COSS`, `COSR` | Plano de centros de custo e indicadores estatísticos (opcional) |
   | `VBRK`, `VBRP`, `KONV` | Documentos de faturação e respetivas condições de preço (opcional) |
   | `T001K`, `MBEW`, `MBEWH` | Áreas de avaliação, valores de existências de materiais e preços-padrão (opcional) |
   | `T001W`, `TKA02` | Centros (plants), lidos como sites, e a área de controlling de cada código de empresa (opcional) |
   | `T016T`, `TKUKT`, `KNVP`, `TSPAT`, `T052U` | Nomes de setores de atividade e de classificações de clientes, o comercial de cada cliente, nomes de divisões e de condições de pagamento (opcional) |
   | `T012K`, `T012T` | Contas de bancos próprios (house banks), para saldos bancários (opcional) |
   | `LFA1`, `LFB1` | Fornecedores (opcional) |
   | `RBKP`, `RSEG` | Faturas de fornecedores (opcional) |
   | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` | Encomendas de compra e respetivas receções e faturas (opcional) |
   | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095`, `ANLC`, `ANEP`, `ANEA`, `ANLP` | O registo de ativos fixos e os respetivos movimentos (opcional) |
   | A tabela de itens de linha da área de resultados (`CE1` seguido do respetivo nome) | CO-PA por avaliação (opcional) |

   Os itens em aberto e os pagamentos são lidos a partir dos itens de linha de clientes e de fornecedores de `BSEG`, com os respetivos cabeçalhos `BKPF`.

3. **Responder às questões contabilísticas** (ver abaixo).

</Steps>

### Questões a que o administrador responde

| O administrador indica-lhe | Introduza no PlaidCloud em **Definições do sistema** |
|---|---|
| O tipo de taxa de câmbio que contém a taxa média. O PlaidCloud calcula a média das taxas desse tipo em cada mês. É frequentemente `M`. | **Average rate type** |
| O tipo de taxa de câmbio que contém a taxa de fecho, a sua taxa no fim do mês. Se não indicar nenhum, a taxa de fecho é a taxa `M`. | **Closing rate type** |
| Se o sistema executa o novo razão geral (`FAGLFLEXT`) ou o clássico (`GLT0`) | **General ledger totals table** |
| A versão da demonstração financeira que reporta a demonstração de resultados de gestão e o balanço | **Financial statement version** |
| Quais dos seus nós são receita, custo das vendas, gasto operacional, não operacional, ativo, passivo, capital próprio e intercompanhia | **Account type of each statement node**: uma linha por nó, no formato `node = type`, com um tipo que a caixa liste, como `Revenue` ou `Asset`. **Intercompany statement nodes** indica os nós intercompanhia. Ambas só se aplicam quando **Financial statement version** está definida. |
| Que a transferência de saldos para o ano seguinte foi executada para cada ano fiscal sobre o qual reporta (`FAGLGVTR`, ou `F.16` no razão geral clássico) | Nada a introduzir. Os saldos de abertura são lidos a partir da tabela de totais. |
| A área de amortização de cada livro de ativos, contabilístico ou fiscal. A primeira é a do registo. O PlaidCloud assume que a área `01` é o livro contabilístico. | **Depreciation area of each book** |
| O tipo de movimento de cada tipo de transação de ativos, pelo seu primeiro dígito. O PlaidCloud assume `1` aquisição, `2` alienação, `3` transferência, `6` amortização e `9` abertura. | **Movement type of each transaction type** |
| A tabela de itens de linha da área de resultados, se pretender CO-PA por avaliação. Sem nenhuma indicada, não é lido nenhum CO-PA. | **Operating concern line item table** |
| O campo de valor CO-PA de cada conta, e quais deles são custos | **Value field of each CO-PA account**, **CO-PA cost value fields** |

## O que enviar de volta

| O administrador envia | Introduzido no PlaidCloud como |
|---|---|
| O ID do sistema e o servidor de aplicação (ou servidor de mensagens e grupo de início de sessão) | **Anfitrião** e **Número do sistema** ou, com **Usar ligação multissistema com balanceamento de carga**, **Anfitrião MS**, **Servidor MS**, **ID do sistema** e **Grupo** |
| O mandante | **Cliente** |
| O nome do utilizador de comunicação | **Utilizador** |
| A palavra-passe do utilizador de comunicação, através do seu gestor de palavras-passe | **Palavra-passe**, que a sua equipa introduz por si própria |
| O nome do agente PlaidLink que chega ao sistema | A definição de sistema **PlaidLink agent** |
| Os códigos de empresa que o PlaidCloud pode ler | Em **Opções**, **Empresas**, que o SAP não consegue listar: introduza os códigos de empresa, separados por vírgulas, ou deixe vazio para carregar todos os códigos de empresa |

<Aside type="caution">
Nunca envie a palavra-passe por email. **Palavra-passe** é um segredo: é guardada na ligação e nunca mais é apresentada.
</Aside>

## Verificar o acesso

O SAP é lido através de um agente PlaidLink, pelo que **Testar ligação** não o lê: é o primeiro carregamento que o lê e que indica uma tabela que o utilizador não possa ler. Cada conjunto de dados lê:

| Conjunto de dados | Tabelas que lê |
|---|---|
| Entidades | `T001` |
| Calendário fiscal | `T001`, `T009`, `T009B`, `T001B` |
| Taxas de câmbio | `TCURR`, `TCURF` |
| Plano de contas | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC`, `CSKB`, `CSKU` |
| Departamentos | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| Centros de lucro | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| Clientes | `KNA1`, `KNVV`, `KNVH` |
| Produtos | `MARA`, `MAKT`, `T006A` |
| Razão geral | `BKPF`, `BSEG`, `COEP` |
| Balancete | `FAGLFLEXT` ou `GLT0` |
| Linhas de vendas | `VBRK`, `VBRP`, `KONV` |
| Orçamento | `COSP`, `COSS` |
| Indutores de alocação | `COSR` |
| Saldos de inventário | `MBEW`, `MBEWH`, `T001K` |
| Saldo de fim de mês | `FAGLFLEXT` ou `GLT0`, o saldo no fim de cada mês |
| Saldos bancários | `T012K`, `T012T`, com o saldo de fim de mês da conta do razão de cada banco próprio |
| Sites | `T001W`, `T001K` |
| Fornecedores | `LFA1`, `LFB1` |
| Linhas de faturas de fornecedores | `RBKP`, `RSEG`, `BKPF` |
| Encomendas de compra | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` |
| Itens em aberto, Pagamentos | Itens de linha de clientes e de fornecedores de `BSEG`, `BKPF` |
| Ativos fixos | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095` |
| Movimentos de ativos | `ANLC`, `ANEP`, `ANEA`, `ANLP` |
| Custos-padrão | `T001K`, `MBEW`, `MBEWH` |
| CO-PA por avaliação | A tabela indicada em **Operating concern line item table** |

Quando um carregamento indicar uma tabela que o utilizador não pode ler, peça ao administrador que a adicione à função e carregue novamente. Os centros de lucro, as linhas de vendas, o orçamento, os indutores de alocação, os saldos de inventário e todos os conjuntos de dados a partir do saldo de fim de mês são opcionais: um sistema que não contenha algum deles carrega na mesma tudo o resto. Os saldos bancários, os itens em aberto ou os pagamentos de um mês que o SAP recuse mantêm as linhas que já tinham.

As contas de bancos próprios que partilham uma conta do razão têm uma única linha de saldo entre elas, tal como a conta do razão tem um único saldo.
