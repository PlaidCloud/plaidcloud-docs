O Launcher é a primeira coisa que vê depois de iniciar sessão numa área de trabalho. Reúne
aquilo com que trabalha mais — projetos, fluxos de trabalho, tabelas, painéis de controlo,
aplicações Panel, dimensões, editores de dados e documentos — numa única página de mosaicos,
para que possa retomar o trabalho onde o deixou sem procurar em cada aplicação.

## Faixas

A página está organizada em três faixas, de cima para baixo. Uma faixa só aparece quando
tem algo para mostrar.

- **Requer atenção** — fluxos de trabalho cuja execução mais recente falhou, para que os problemas
  surjam assim que chega. Cada cartão liga diretamente à execução falhada e
  pode **Dispensar** um que já tenha tratado.
- **Afixados** — tudo o que marcou como favorito, pela ordem em que o afixou.
  Qualquer tipo de item pode ser afixado aqui (consulte [Afixar](#afixar-favoritos)).
- **Recentes** — projetos, painéis de controlo e aplicações Panel que abriu ou editou
  recentemente.

<Aside type="note">
Apenas projetos, painéis de controlo e aplicações Panel aparecem por recência — normalmente há
demasiados fluxos de trabalho, tabelas, dimensões, editores de dados e documentos para os listar
dessa forma. Dê destaque aos que consulta com frequência afixando-os e ficarão à sua espera na
faixa **Afixados**.
</Aside>

## Mosaicos de projeto

Um mosaico de projeto resume o projeto num relance:

| Estatística | Significado |
|---|---|
| **Execuções de fluxos de trabalho** | Execuções de fluxos de trabalho concluídas na janela recente |
| **Última execução** | Quando terminou a execução mais recente |
| **Fluxos de trabalho** | Fluxos de trabalho que o projeto contém |
| **Tabelas** | Tabelas que o projeto contém |
| **Registos** | Total de linhas nessas tabelas (um `~` assinala uma estimativa) |

Um projeto sem histórico de execuções mostra **Última edição** em vez dos valores de execução, e
as contagens são totalmente omitidas quando são zero.

### Imagens de mosaico

Cada mosaico de projeto tem uma imagem de fundo esbatida. Por predefinição, é a
ventoinha do PlaidCloud, mas pode dar a um projeto a sua própria imagem — um logótipo de cliente,
por exemplo, ou algo que identifique o trabalho num relance — para que se destaque num
Launcher cheio.

Para a definir:

1. Abra o projeto e aceda ao respetivo separador **Início**.
2. Desloque-se até **Imagem do mosaico de acesso rápido** na parte inferior da coluna esquerda.
3. Escolha a conta de documentos que contém a imagem e depois **Procurar** o ficheiro
   de imagem.
4. Utilize **Limpar** para voltar à predefinição.

A imagem é esbatida por trás das estatísticas para que estas continuem legíveis, por isso escolha
algo que se leia bem quando desvanecido. As imagens largas adaptam-se melhor à forma do mosaico
do que as altas. Precisa de permissão para editar o projeto para definir isto; um
leitor só de leitura vê o seletor desativado.

<Aside type="note">
Qualquer pessoa que consiga ver o projeto vê a imagem do respetivo mosaico, mas a imagem é fornecida
apenas a quem também consegue ler a conta de documentos onde se encontra. Um leitor
sem esse acesso vê simplesmente a ventoinha predefinida.
</Aside>

Os mosaicos de painéis de controlo funcionam de forma diferente — mostram uma miniatura gerada automaticamente
do próprio painel de controlo, por isso não há nada a escolher.

## Abrir itens

Cada cartão e linha de lista tem uma ação principal e, quando faz sentido, ações
adicionais:

| Item | Abre | Também disponível |
|---|---|---|
| Projeto | O projeto | |
| Fluxo de trabalho | O fluxo de trabalho | Executar, Abrir a última execução, estado em direto **Em execução** |
| Tabela | A tabela | Abrir no Explorador de tabelas |
| Dimensão | O respetivo editor de hierarquia | |
| Editor de dados | O respetivo projeto | |
| Painel de controlo | O painel de controlo | Abrir num novo separador |
| Aplicação Panel | A aplicação | Abrir num novo separador |
| Aplicação Dash | A aplicação | Abrir num novo separador |
| Documento | O ficheiro ou a pasta | |

Um fluxo de trabalho em execução mostra um indicador de estado em direto que se atualiza sozinho — sem
necessidade de atualizar a página.

## Afixar (favoritos)

Clique na **estrela** em qualquer cartão ou linha de lista do Launcher para o afixar. Os itens afixados
aparecem sempre na faixa **Afixados**, independentemente de há quanto tempo os utilizou,
para que aquilo que lhe interessa nunca saia do seu alcance.

Também pode afixar a partir do local onde já trabalha, sem abrir primeiro o Launcher
— procure a coluna da estrela:

- **Projetos, fluxos de trabalho, tabelas, dimensões e editores de dados** — a coluna
  da estrela na lista de cada um, dentro do projeto.
- **Painéis de controlo**, **aplicações Panel** e **aplicações Dash** — a coluna da estrela em Os meus
  painéis de controlo e As minhas aplicações Panel.
- **Documentos** — clique com o botão direito num ficheiro *ou* numa pasta no navegador de documentos e
  escolha **Afixar no Launcher**.

Clique numa estrela acesa em qualquer lado para desafixar. Os itens afixados em qualquer lugar refletem-se
de imediato no Launcher.

## Mosaicos ou lista

Utilize o botão **Mosaicos / Lista** na barra de ferramentas para alternar entre a vista de cartões
espaçosa e uma lista densa de uma linha por item. A sua escolha é memorizada e a alternância é
instantânea — redesenha o que já está carregado sem obter dados novamente.

## Filtrar por tipo

A linha de chips à esquerda da barra de ferramentas tem um chip por tipo, cada um com o seu próprio
ícone — **Projetos**, **Painéis de controlo**, **Aplicações Panel**, **Fluxos de trabalho**, **Tabelas**,
**Dimensões**, **Editores de dados** e **Documentos**. Um chip premido significa que esse
tipo é mostrado; clique nele para ocultar esse tipo das faixas **Recentes** e **Afixados**.
O seu filtro é memorizado entre visitas.

A faixa **Requer atenção** nunca é filtrada — um fluxo de trabalho com falhas aparece sempre,
mesmo quando o chip do respetivo tipo está desligado.

## Pesquisa e comandos

Prima **Ctrl/Cmd-K** em qualquer ecrã — ou clique em **Pesquisar** na barra de ferramentas do
Launcher — para abrir a paleta de comandos. A única exceção é o Registo de lançamentos,
que mantém **Ctrl/Cmd-K** para a sua própria paleta.

Antes de escrever, lista duas coisas:

- **Ações** — comandos que pode executar a partir daqui: ir para Início, Projetos,
  Painéis de controlo ou Documentos, alternar entre o aspeto claro e escuro, ligar a sua IA e obter ajuda.
  As ações **Ir para** só aparecem para as aplicações que a sua área de trabalho tem.
- **Recentes** — as últimas oito coisas que abriu, da mais recente para a mais antiga: projetos,
  fluxos de trabalho, tabelas, dimensões, editores de dados, painéis de controlo, aplicações Panel e
  documentos abertos a partir do Launcher ou da paleta, e todos os projetos que abre
  em qualquer lugar. Algo aberto a partir do interior de um projeto — um fluxo de trabalho, por exemplo, ou uma
  dimensão — não é adicionado. Esta lista é mantida no seu navegador, pelo que não é
  partilhada entre dispositivos, e é independente da faixa **Recentes** do Launcher
  (consulte [Faixas](#faixas)).

Comece a escrever e ambas as listas são restringidas em simultâneo — os carateres que escreve só têm
de aparecer por ordem, pelo que `proj` encontra **Ir para Projetos** — com a correspondência mais próxima
em primeiro lugar. A partir de dois carateres, a paleta também pesquisa em projetos,
fluxos de trabalho, tabelas, painéis de controlo e aplicações Panel e adiciona esses resultados abaixo,
agrupados por tipo, cada um com as mesmas ações de abertura e estrela de afixar que no quadro.
Um resultado que já é apresentado em **Recentes** não é repetido.

- **Cima / Baixo** movem a seleção.
- **Enter** executa a ação selecionada ou abre o item selecionado.
- **Escape** fecha a paleta.

As dimensões, os editores de dados e os documentos não são pesquisáveis — chegue a eles
afixando-os, a partir de **Recentes** depois de os abrir a partir do Launcher, ou a partir
do projeto a que pertencem.

Clicar num resultado abre-o; clicar na respetiva **estrela** afixa-o e deixa a paleta
aberta, para que possa afixar várias coisas de uma só vez.

## Atualizar

O Launcher atualiza-se sozinho quando regressa a ele e os dados ficaram
desatualizados. Para obter imediatamente os dados mais recentes, clique em **Atualizar** na barra de ferramentas.

## Começar noutro local

O Launcher é onde o PlaidCloud abre por predefinição. Para começar antes noutra aplicação,
desative **Iniciar no Iniciador** no menu Opções.

## Aspeto (claro, escuro, automático)

O botão **Aspeto** na barra de ferramentas superior — o ícone de contraste junto ao
menu da conta — alterna o PlaidCloud entre um aspeto claro e um escuro. Aplica-se
em todo o lado: o Launcher, todas as aplicações e todas as janelas e caixas de diálogo
dentro delas.

| Escolha | O que faz |
| --- | --- |
| **Claro** | Utiliza sempre o aspeto claro, independentemente da configuração do seu dispositivo. |
| **Escuro** | Utiliza sempre o aspeto escuro, independentemente da configuração do seu dispositivo. |
| **Automático (sistema)** | Segue a definição de aspeto do seu sistema operativo. |

**Automático (sistema)** é a predefinição e acompanha o seu sistema em direto: se o seu
computador estiver configurado para mudar para escuro ao fim do dia, o PlaidCloud acompanha no mesmo
momento, sem recarregar. Escolher **Claro** ou **Escuro** fixa o aspeto e
ignora a definição do sistema a partir daí.

<Aside type="note">
A sua escolha é memorizada no navegador em que a fez, pelo que não é transportada
para outro navegador ou outro computador — defina-a uma vez em cada um.
Limpar os dados do site no seu navegador repõe-na em **Auto**. Se o seu navegador bloquear o
armazenamento local (alguns modos de navegação privada fazem-no), o seletor continua a funcionar durante a
sessão, mas volta a começar em **Auto** da próxima vez.
</Aside>

O conteúdo incorporado mantém as suas próprias cores: os painéis de controlo e as aplicações Panel não são
reestilizados por esta definição.
