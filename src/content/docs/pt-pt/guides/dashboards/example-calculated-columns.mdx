## Descrição

Os dados nos painéis de controlo podem ser enriquecidos com colunas calculadas.  Cada conjunto de dados contém uma secção para colunas calculadas.  As colunas calculadas podem ser escritas e modificadas com SQL no estilo PostgreSQL.

<SnippetDashboardsCommonNavigateToDataset />

## Exemplos
### Count
```sql
COUNT(*)
```

### Min
```sql
min("MyColumnName")
```

### Max
```sql
max("MyColumnName")
```

### Coalesce (útil para converter nulos em 0.0, por exemplo)
```sql
coalesce("BaselineCost",0.0)
```

### Substring
```sql
substring("PERIOD",6,2)
```

### Cast
```sql
CAST("YEAR" AS integer)-1
```

### Concat
```sql
concat("Biller Entity" , ' ', "Country_biller")
```

### To_char
```sql
to_char("date_created", 'YYYY-mm-dd')
```

### Left
```sql
left("period",4)
```

### Divide
divisão, com um truque para evitar erros de divisão por zero
```sql
sum("so_infull")/(count(*)+0.00001)
```
<Aside>Uma forma melhor de o fazer seria verificar se o denominador é nulo ou zero e depois usar coalesce para zero, em vez de tentar a divisão.</Aside>


### Instrução condicional
```sql
CASE WHEN "Field_A"= 'Foo' THEN max(coalesce("Value_A",0.0)) - max(coalesce("Value_B",0.0)) END
```
```sql
CASE WHEN "sol_otif_pod_missing" = 1 THEN
'POD is missing.'
ELSE
'POD exists.'
END
```
```sql
case when "Customer DC" = "origin_dc" or "order_reason_type" = 'Off Schedule' or "mot_type" = 'UPS' then
    'Yes'
else
    'No'
end
```
```sql
CASE WHEN "module_type" is NULL THEN '---' ELSE "module_type" END
```
```sql
CASE WHEN "NODE_TYPE" = 'External' THEN '3rd Party' ELSE "ENTITY_LOCATION_DESCRIPTION" END
```

### Concatenar
```sql
concat("Class",' > ',"Product Family",' > ',"Meta Series")
```
