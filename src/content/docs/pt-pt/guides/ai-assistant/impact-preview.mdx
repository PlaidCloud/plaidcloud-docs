## Descrição

Abra um passo guardado e, acima dos botões **Guardar**, o Weave indica o que uma alteração ao
passo alcançaria:

> As alterações a este passo afetam 8 passos a jusante em 2 fluxos de trabalho.

A frase conta os passos que leem uma tabela escrita por este passo, os passos
que leem o que esses escrevem, e assim sucessivamente, até dez passos a jusante. É
lida a partir das definições guardadas dos passos do projeto, pelo que é instantânea, é
uma contagem exata dos passos que listam estas tabelas como origem, e não envolve
IA. Está lá para informar a gravação, não para a condicionar: pode
sempre guardar.

<Aside type="note">
A frase descreve o passo tal como foi guardado pela última vez. Se estiver a alterar a tabela
que o passo escreve, os passos que leem a tabela antiga são os listados
até guardar, e são afetados: deixam de receber o que este passo
escrevia.
</Aside>

## O que a frase diz

| O Weave diz | O que significa |
| --- | --- |
| As alterações a este passo afetam 8 passos a jusante em 2 fluxos de trabalho. | Oito passos leem o que este passo escreve, direta ou indiretamente através de outros passos, e entre eles encontram-se em dois fluxos de trabalho. Um passo que está em dois fluxos de trabalho é um só passo, em ambos. |
| As alterações a este passo afetam 3 passos a jusante: 2 em 1 fluxo de trabalho e 1 em nenhum fluxo de trabalho. | Um passo a jusante que não está colocado em nenhum fluxo de trabalho é contado e listado em **Not in any workflow**. |
| As alterações a este passo afetam 3 passos a jusante, nenhum deles num fluxo de trabalho. | Todos os passos afetados estão por colocar. Com um só passo: "afetam 1 passo a jusante, que não está em nenhum fluxo de trabalho." |
| As alterações a este passo afetam pelo menos 8 passos a jusante em pelo menos 2 fluxos de trabalho. O Weave parou de procurar 10 passos a jusante. | A cadeia de leitores tem mais de dez passos. As contagens são um mínimo, não um total, e a frase não as discrimina por colocação. |
| … Não pode abrir 2 deles. | Dois dos passos afetados estão ocultos para a sua função. São contados, para que a frase continue correta, mas não são nomeados. Quando todos os passos afetados estão ocultos, a frase termina com "Não pode abrir nenhum deles." ou, para um só, "Não o pode abrir." |
| Nenhum outro passo lista uma tabela escrita por este passo como origem. | Nenhum passo indica uma destas tabelas como origem. Um passo que chega a uma tabela através de uma consulta SQL ou de uma expressão não é contado, e **Como o Weave sabe** di-lo. |
| Este passo não escreve uma tabela, pelo que o Weave não tem nada a jusante para seguir. | O passo produz algo que não é uma tabela do projeto, como um ficheiro, um e-mail ou um lançamento ERP, e o Weave não consegue seguir quem o usa. |
| O Weave não conseguiu verificar o que as alterações a este passo afetam. | Não foi possível ler a pré-visualização. Seguir a cadeia exige acesso de leitura a passos, fluxos de trabalho e tabelas, por isso uma função a que falte qualquer um deles vê esta mensagem. Guardar funciona como habitualmente. |

## Ver os passos

**Mostrar os passos** lista os passos afetados por fluxo de trabalho. Os fluxos de trabalho que pode abrir
vêm primeiro, por nome; os fluxos de trabalho que não pode abrir seguem-se como um só grupo; os passos em
nenhum fluxo de trabalho vêm no fim. Dentro de um fluxo de trabalho, os leitores mais próximos são listados primeiro,
e os passos que não pode abrir são contados no fim da lista em vez de nomeados. Um
passo que está em mais de um fluxo de trabalho é listado em cada um deles, e **Como
o Weave sabe** di-lo. Uma lista longa desloca-se.

## Como o Weave sabe

**Como o Weave sabe**, por baixo da frase, mostra o que o Weave fez e o que deixou
de fora:

- **O que o Weave fez** — seguiu cada tabela que este passo escreve até aos passos que
  a leem, e depois através do que esses escrevem, até dez passos a jusante.
- **De onde provém** — as tabelas que este passo escreve e as definições guardadas
  de todos os passos do projeto. Uma tabela que a sua função oculta é listada como uma que não
  pode abrir, e uma tabela indicada nas definições do passo que ainda não existe é
  listada pelo respetivo nome.
- **O que o Weave não verificou** — passos que chegam a estas tabelas através de uma consulta
  SQL ou de uma expressão em vez de as listarem como origem; painéis de controlo,
  vistas, exportações e tudo o que esteja fora deste projeto e leia estas tabelas;
  se os passos afetados falhariam ou apenas seriam executados com dados diferentes;
  e as edições a este passo que ainda não guardou.

## Quando aparece

- Apenas para um passo guardado. Um passo novo, ou um duplicado que ainda não guardou, não tem
  leitores para contar.
- Atualiza-se depois de **Guardar** enquanto o passo permanece aberto, uma vez que uma gravação pode
  alterar a tabela que o passo escreve.
- Lê as definições guardadas do projeto, pelo que nunca custa uma chamada de IA e continua
  a funcionar quando nenhum fornecedor de IA está disponível.
