## Descrição

Quando prime **Guardar** num passo, o PlaidCloud verifica as respetivas definições e recusa
as que não consegue executar, como uma expressão que não compila ou uma coluna usada
de uma forma que o seu tipo não permite. Enquanto edita um passo, o Weave executa agora a maioria
dessas verificações à medida que avança e mostra o que o Guardar recusaria numa faixa mesmo acima
dos botões **Guardar**:

> 1 problema que o Guardar vai recusar.

Cada problema é listado por baixo dessa linha. Quando indica uma linha do separador **Seleção de dados da
tabela**, **Ir para** abre esse separador com a linha selecionada.

As verificações leem apenas as definições do passo e as variáveis do projeto, pelo que
são rápidas e não envolvem IA. Nunca impedem a gravação: o Guardar continua
disponível e executa todas as verificações por si quando o prime.

<Aside type="note">
O Guardar também verifica algumas coisas que esta faixa não verifica, como se as tabelas de origem
e de destino têm as colunas que o passo usa e se os campos obrigatórios
estão preenchidos. Por isso, "Nenhum problema encontrado" significa que nenhuma das verificações executadas durante
a edição encontrou um problema, não que o Guardar aceite o passo.
</Aside>

## O que a faixa diz

| O Weave diz | O que significa |
| --- | --- |
| A verificar se este passo tem problemas… | O Weave está a executar as verificações sobre a sua última alteração. |
| 1 problema que o Guardar vai recusar. | O Guardar recusaria o passo tal como está. Cada problema é listado por baixo. |
| Nenhum problema encontrado. O Guardar verifica mais algumas coisas, como as tabelas de origem e de destino. | As verificações executadas durante a edição não encontraram nada. O Guardar continua a executar as suas próprias verificações, incluindo algumas que esta faixa não faz. |
| O Weave não conseguiu verificar as expressões deste passo. … | Não foi possível verificar uma parte do passo; segue-se o motivo. Isto nunca é uma aprovação. |
| O Weave não conseguiu verificar este passo agora. O Guardar continua a verificá-lo. | A verificação não foi executada, por exemplo porque o servidor estava ocupado. A sua alteração seguinte volta a pedi-la. |

### Porque não foi possível verificar as expressões

| Motivo | O que significa |
| --- | --- |
| Este passo não está num fluxo de trabalho, pelo que as suas expressões não podem ser verificadas. O Guardar também não as verifica. | As expressões podem usar variáveis do fluxo de trabalho, por isso são verificadas no fluxo de trabalho do passo. Um passo aberto fora de qualquer fluxo de trabalho não é verificado, nem aqui nem pelo Guardar. |
| Algumas das suas expressões estão em definições que o Weave ainda não consegue verificar. | O passo guarda algumas expressões em definições que estas verificações não leem, como o filtro de uma segunda origem. As restantes continuam a ser verificadas. |
| A configuração das suas colunas é uma que o Weave ainda não consegue verificar. | O passo lista as suas colunas de uma forma que a verificação não consegue compilar, como acontece com uma Junção de várias tabelas. |

Uma expressão que usa uma variável que nem o fluxo de trabalho nem o projeto definem
é um problema, não um motivo: "Uma expressão usa a variável rate, que não está
definida neste fluxo de trabalho nem neste projeto." O mesmo acontece com uma chaveta que não inicia nem termina
o nome de uma variável, como sucede com uma variável escrita pela metade: "Uma expressão tem uma chaveta que
não faz parte do nome de uma variável." O Guardar recusa ambas com as mesmas frases.

## No Editor de expressões

Abra o **Editor de expressões** a partir de uma célula **Expressão** do separador **Seleção de dados da
tabela**, ou a partir de **Selecionar subconjunto de dados** ou **Aplicar filtro secundário aos dados do
resultado** no separador **Filtros de dados**, e uma linha por baixo do editor verifica
a expressão à medida que escreve:

| O editor diz | O que significa |
| --- | --- |
| A verificar… | O Weave está a verificar o que acabou de escrever. |
| Nenhum erro encontrado. | A expressão compila da forma como o Guardar a compila. Aponte para a linha para ler o que isto deixa de fora: o Weave verifica a sintaxe e os nomes das colunas; alguns erros só surgem quando o passo é executado. |
| Erro: … | O Guardar recusaria a expressão, pelo motivo indicado. Um erro de sintaxe também é assinalado na respetiva linha, junto ao número da linha. |
| Não foi possível verificar. … | Não foi possível verificar a expressão, por um dos motivos acima. |
| Não foi possível verificar agora. Guardar o passo continua a verificá-la. | A verificação não foi executada. Premir **Guardar** no passo continua a verificar a expressão. |

O editor verifica com base nas definições do passo tal como estavam quando o Weave verificou o passo pela última vez, com a sua expressão incluída. Se for aberto a partir de qualquer outro local,
como o Explorador de tabelas, não mostra nenhuma linha.

## Quando aparece

- Enquanto edita um passo que pode alterar. Um passo que abre só de leitura para a
  sua função não é verificado durante a edição.
- Após cada alteração, quando faz uma pausa. Uma alteração que deixa as definições
  como estavam não é verificada de novo.
- Lê as definições do passo e as variáveis do projeto, pelo que nunca custa
  uma chamada de IA e nunca consulta o seu armazém.
