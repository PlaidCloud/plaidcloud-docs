Manter documentação detalhada para apoiar requisitos estatutários e de gestão é difícil quando os projetos e os fluxos de trabalho podem ser dinâmicos. Para ajudar a resolver este problema, o PlaidCloud disponibiliza um relatório ao nível do fluxo de trabalho que fornece documentação detalhada dos fluxos de trabalho, dos passos dos fluxos de trabalho, das funções definidas pelo utilizador e das variáveis.



O relatório é gerado a pedido e reflete o estado atual do fluxo de trabalho. Para transferir o relatório, clique no ícone Relatório na hierarquia **Fluxos de trabalho**.
