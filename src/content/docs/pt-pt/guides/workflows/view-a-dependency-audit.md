A **Workflow Dependency Audit** é uma ferramenta muito útil para compreender as dependências de dados e de fluxos de trabalho em fluxos de trabalho complexos e interligados. Com o tempo, à medida que os processos dos fluxos de trabalho se tornam mais complexos, pode tornar-se difícil garantir que todas as dependências estão pela ordem correta. Quando os dados já existem nas tabelas, os passos são executados e parecem corretos em muitos casos, mas podem ter, na realidade, um problema de dependência se os dados forem preenchidos fora de ordem.



Esta ferramenta fornece uma auditoria de dependências e identifica problemas nas relações de dependência dos dados.
