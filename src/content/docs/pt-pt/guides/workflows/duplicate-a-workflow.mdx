Copiar um fluxo de trabalho é útil ao planear alterações importantes ou ao replicar um processo com opções diferentes. As cópias são completamente independentes — modificar uma cópia não afeta o original.

Estão disponíveis duas ações a partir da tabela **Fluxos de trabalho**:

* **Duplicate Selected Workflows** — cópia rápida no próprio local, no mesmo projeto
* **Clonar fluxo(s) de trabalho** — copia para um projeto de destino à sua escolha (por predefinição, o projeto atual)


## Duplicar Fluxos de Trabalho Selecionados

1. Abra a tabela **Fluxos de trabalho** do projeto
2. Selecione um ou mais fluxos de trabalho
3. Clique em `Duplicate Selected Workflows` na barra de ferramentas

Cada clone fica no mesmo projeto, com « copy» acrescentado ao nome do original.


## Clonar Fluxo(s) de Trabalho

Utilize esta opção quando pretender copiar fluxos de trabalho para outro projeto — por exemplo, para promover de um projeto de desenvolvimento para um projeto irmão.

1. Abra a tabela **Fluxos de trabalho** do projeto de origem
2. Selecione um ou mais fluxos de trabalho
3. Abra o menu **Ações** e clique em `Clone Workflow(s)`
4. Na caixa de diálogo, escolha o **Projeto de destino** (por predefinição, o projeto atual)
5. Clique em `Clone Workflow(s)`

É aberta uma caixa de diálogo de progresso enquanto a clonagem decorre, com uma barra global (fluxo de trabalho N de M) e uma barra por passo para o fluxo de trabalho que está a ser copiado. Pode clicar em `Run in Background` para fechar a caixa de diálogo e continuar a trabalhar — a clonagem continua a decorrer e é apresentada uma notificação quando termina.

Os fluxos de trabalho clonados têm « copy» acrescentado aos nomes, para não colidirem com nada que já exista no projeto de destino.

<Aside>A clonagem copia a definição do fluxo de trabalho e a configuração dos passos. Os recursos com âmbito de projeto referenciados pelo fluxo de trabalho (tabelas, dimensões, ligações) têm de existir já no projeto de destino, ou tem de os clonar separadamente.</Aside>
