Durante o desenvolvimento inicial, o teste ou a resolução de problemas de um fluxo de trabalho, é muitas vezes útil executar os passos individualmente. Para executar um único passo isoladamente, clique com o botão direito do rato no passo e selecione **Executar passo** no menu de contexto.
