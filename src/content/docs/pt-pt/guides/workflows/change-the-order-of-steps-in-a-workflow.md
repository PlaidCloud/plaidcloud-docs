Existem duas formas de atualizar a ordem dos passos no fluxo de trabalho. A primeira é utilizar as setas para cima e para baixo presentes na tabela **Fluxos de trabalho** para mover o passo para cima ou para baixo. A segunda é utilizar a opção **Mover passo**, que permite mover o passo com muito mais facilidade quando são necessárias grandes alterações. A opção de mover passo permite mover o passo para o topo, para o fim ou para depois de um passo específico numa única operação.

A estrutura de um fluxo de trabalho só pode conter cada passo uma vez. Se um fluxo de trabalho já tiver, por algum motivo, o mesmo passo listado duas vezes, a sua reordenação — incluindo arrastar um passo para uma nova posição — é recusada com um erro a indicar que o fluxo de trabalho contém um duplicado. Elimine o passo duplicado para reparar o fluxo de trabalho; a remoção de passos não é restringida, e a reordenação volta a funcionar normalmente depois de o duplicado desaparecer.
