[Tryb agenta](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) GitHub Copilot w VSCode obsługuje serwery MCP za pomocą pliku `.vscode/mcp.json` o zakresie obszaru roboczego lub użytkownika (obszar roboczy) albo globalnego pliku `mcp.json` VSCode (użytkownik).

<Aside type="note">Szukasz **Microsoft 365 Copilot** — asystenta w Teams i aplikacji Microsoft 365 — zamiast GitHub Copilot w IDE? Zobacz [Microsoft 365 Copilot](/pl/integrations/microsoft-365-copilot/).</Aside>

Do tych kroków można też przejść z własnego okna PlaidCloud **Połącz swoją AI** (w menu awatara) — GitHub Copilot znajdziesz na karcie **Inne**, obok Gemini CLI i Codex CLI.

<Aside>Obsługa MCP w Copilot zależy od poziomu planu Copilot i ustawienia `chat.mcp.enabled` w VSCode. Przed konfiguracją serwerów upewnij się, że oba są włączone.</Aside>

## Konfiguracja

1. Pobierz token okaziciela, otwierając `https://<your-workspace>.plaid.cloud/mcp/setup/token` w przeglądarce, w której logujesz się do PlaidCloud.

2. W VSCode otwórz paletę poleceń i uruchom **MCP: Add Server** albo utwórz plik `.vscode/mcp.json` bezpośrednio:

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Załaduj ponownie VSCode. Otwórz panel czatu Copilot, przełącz listę trybów na **Agent** i sprawdź, czy narzędzia PlaidCloud pojawiają się na liście narzędzi (zwykle wyświetlane jako `plaidcloud_*`).

## Użycie

Poproś Copilot o wykonanie operacji PlaidCloud bezpośrednio:

- „Znajdź wszystkie przepływy pracy w projekcie `Q4 Forecast`, których ostatnie uruchomienie zakończyło się niepowodzeniem.”
- „Pokaż mi schemat tabeli `customers` i zaproponuj indeksy.”
- „Uruchom przepływ pracy `daily-load` i podaj stan uruchomienia.”

Copilot wybiera odpowiednie narzędzie, wykonuje je i cytuje wyniki w odpowiedzi. W przypadku operacji destrukcyjnych (usuwanie, organizowanie, upsert bez `dry_run`) zwykle prosi o potwierdzenie — przed zatwierdzeniem sprawdź zaplanowaną czynność.

## Odświeżanie tokenu

VSCode odczytuje `.vscode/mcp.json` przy uruchomieniu i po zmianie pliku. Gdy token wygaśnie, ponownie otwórz `https://<your-workspace>.plaid.cloud/mcp/setup/token` i zastąp wartość `Authorization` — VSCode automatycznie ponownie załaduje serwer.

## Ograniczanie do wybranych narzędzi

Aby ograniczyć, które narzędzia PlaidCloud może wywoływać Copilot, użyj listy dozwolonych narzędzi VSCode dla poszczególnych serwerów (Settings → Copilot → MCP → wybór narzędzi dla serwera). Jest to przydatne w sesjach tylko do odczytu lub gdy narzędzia modyfikujące (`*_upsert`, `*_run`) mają pozostać zablokowane do czasu jawnego ponownego włączenia.
