[Tryb agenta](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) GitHub Copilot w VSCode obsługuje serwery MCP przez `.vscode/mcp.json` o zakresie obszaru roboczego lub użytkownika (obszar roboczy) albo globalny `mcp.json` VSCode (użytkownik).

<Aside type="note">Szukasz **Microsoft 365 Copilot** — asystenta w Teams i aplikacji Microsoft 365 — a nie GitHub Copilot w IDE? Zobacz [Microsoft 365 Copilot](/pl/integrations/microsoft-365-copilot/).</Aside>

Do tych kroków możesz też przejść z własnego okna PlaidCloud **Połącz swoją AI** — GitHub Copilot znajdziesz na karcie **Inne**, obok Gemini CLI i Codex CLI.

<Aside>Obsługa MCP w Copilot zależy od planu Copilot i ustawienia `chat.mcp.enabled` w VSCode. Przed konfiguracją serwerów upewnij się, że oba są włączone.</Aside>

## Konfiguracja

1. Uzyskaj token okaziciela, odwiedzając `https://<your-workspace>.plaid.cloud/mcp/setup/token` w przeglądarce, w której jesteś zalogowany do PlaidCloud.

2. W VSCode otwórz paletę poleceń i uruchom **MCP: Add Server** albo utwórz bezpośrednio `.vscode/mcp.json`:

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Załaduj ponownie VSCode. Otwórz panel czatu Copilot, przełącz listę rozwijaną trybu na **Agent** i upewnij się, że narzędzia PlaidCloud pojawiają się na liście narzędzi (zwykle jako `plaidcloud_*`).

## Użycie

Poproś Copilot o wykonanie operacji PlaidCloud bezpośrednio:

- „Znajdź wszystkie przepływy pracy w projekcie `Q4 Forecast`, których ostatnie uruchomienie się nie powiodło."
- „Pokaż mi schemat tabeli `customers` i zaproponuj indeksy."
- „Uruchom przepływ pracy `daily-load` i podaj status uruchomienia."

Copilot wybiera odpowiednie narzędzie, wykonuje je i cytuje wyniki w odpowiedzi. W przypadku operacji destrukcyjnych (usuwanie, organize, upsert bez `dry_run`) zwykle prosi o potwierdzenie — przejrzyj planowaną akcję przed zatwierdzeniem.

## Odświeżanie tokenu

VSCode odczytuje `.vscode/mcp.json` przy uruchomieniu i po zmianie pliku. Gdy token wygaśnie, załaduj ponownie `https://<your-workspace>.plaid.cloud/mcp/setup/token` i nadpisz wartość `Authorization` — VSCode automatycznie przeładuje serwer.

## Ograniczanie do wybranych narzędzi

Jeśli chcesz ograniczyć, które narzędzia PlaidCloud może wywoływać Copilot, użyj listy dozwolonych narzędzi VSCode dla każdego serwera (Settings → Copilot → MCP → server-specific tool selection). Jest to pomocne w sesjach tylko do odczytu lub aby narzędzia modyfikujące (`*_upsert`, `*_run`) pozostawały zablokowane do czasu jawnego ponownego włączenia.
