PlaidCloud łączy się z hostami Git, aby przepływy pracy i aplikacje Panel mogły odczytywać dane z repozytoriów objętych kontrolą wersji. Jest to przydatne do pobierania konfiguracji, skryptów lub plików opartych na szablonach, które znajdują się w systemie kontroli wersji, a nie w bazie danych ani na koncie dokumentów.

## Dostawcy

- [PlaidCloud Git](/pl/reference/connectors/git/plaidcloud-git/) — zarządzana usługa Git wbudowana w obszar roboczy; nie trzeba konfigurować adresu URL serwera ani danych uwierzytelniających
- [GitHub](/pl/reference/connectors/git/github/)
- [GitLab](/pl/reference/connectors/git/gitlab/)
- [Bitbucket](/pl/reference/connectors/git/bitbucket/)
- [Azure Repos](/pl/reference/connectors/git/azure-repos/)
- [AWS CodeCommit](/pl/reference/connectors/git/codecommit/)
