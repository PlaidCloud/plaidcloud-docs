PlaidCloud łączy się z zespołowymi platformami czatu, dzięki czemu przepływy pracy mogą wysyłać powiadomienia, alerty lub aktualizacje stanu bezpośrednio na kanały, które zespół już obserwuje. Najczęściej używane razem z krokami przepływu pracy [Notify via Slack](/pl/reference/workflow-steps/notifications/notify-via-slack/) i [Notify via Microsoft Teams](/pl/reference/workflow-steps/notifications/notify-via-microsoft-teams/).
