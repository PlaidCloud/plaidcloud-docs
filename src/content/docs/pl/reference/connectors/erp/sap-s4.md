S/4HANA nie ma własnego konektora. Współdzieli jeden typ połączenia z SAP ECC, ponieważ PlaidCloud łączy się z oboma systemami przez ten sam interfejs Remote Function Call. Na ekranie **Połączenia** wybierz **Nowy → Instancja SAP ECC / S/4HANA**.

**[Konektor SAP ECC i S/4HANA →](/pl/reference/connectors/erp/sap-ecc/)** — wszystkie pola konfiguracji, dla obu generacji.

## Dokumentacja producenta

Zobacz [dokumentację SAP S/4HANA](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE).
