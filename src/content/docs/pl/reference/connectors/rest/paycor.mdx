## Konfiguracja Paycor
Proces rejestracji i inicjowania aplikacji API Paycor jest nieco bardziej złożony niż u innych dostawców REST.  Przejdź dokładnie przez kroki opisane na ich [stronie Quick Start](https://developers.paycor.com/guides#quickStartLabel)

Kluczowe wartości, które musisz zapisać:
 - Identyfikator klienta OAuth aplikacji
 - Klucz tajny klienta OAuth aplikacji
 - Klucz subskrypcji APIm
 - Klucz zakresu (scope) wersji `current` aplikacji

<Aside type="caution">Nie zapomnij „aktywować” aplikacji, aby umożliwić jej użycie</Aside>

Aktywuj ją tutaj, wybierając środowisko Production lub Sandbox w zależności od potrzeb:

| Środowisko | Adres URL formularza aktywacji |
|-------------|---------------------|
| Sandbox	  | https://hcm-demo.paycor.com/AppActivation/ClientActivation |
| Production  | https://hcm.paycor.com/AppActivation/ClientActivation |

<Aside type="danger">Jeśli masz w Paycor wiele organizacji, potrzebujesz osobnych loginów dla każdej z nich. NIE łącz ich. Portal deweloperski wymaga dedykowanego, unikatowego loginu dla każdej organizacji, aby utworzyć aplikację specyficzną dla organizacji z dostępem REST.</Aside>

## Konfiguracja

Te pola są widoczne podczas tworzenia lub edytowania tego połączenia.

### Identyfikacja

| Pole | Typ | Opis |
|---|---|---|
| Nazwa | Tekst | Wyświetlana nazwa tego połączenia. |
| Alias | Tekst (wielowierszowy) | Opcjonalny alias lub uwagi dotyczące połączenia. |
| Aktywne | Przełącznik | Określa, czy połączenie jest włączone. Wyłącz, aby wstrzymać je bez usuwania. |
| Baza danych tylko do odczytu | Przełącznik | Ogranicza połączenie do operacji tylko do odczytu. |
| Typ dostępu | Lista wyboru | Poziom dostępu dla tego połączenia: tylko odczyt, tylko zapis lub odczyt i zapis. |

### Dane uwierzytelniające

Wprowadź trzy wartości zapisane podczas [konfiguracji Paycor](#konfiguracja-paycor). Nie podajesz hosta ani adresu URL tokenu — PlaidCloud udostępnia host API Paycor i punkt końcowy tokenu OAuth2 za Ciebie.

| Pole | Typ | Opis |
|---|---|---|
| Identyfikator klienta OAuth2 | Tekst | Identyfikator klienta OAuth aplikacji z rejestracji aplikacji Paycor. |
| Klucz tajny klienta OAuth2 | Hasło | Klucz tajny klienta OAuth aplikacji. Przechowywany w postaci zaszyfrowanej. |
| Klucz subskrypcji Paycor | Tekst | Klucz subskrypcji APIm dla Twojej aplikacji Paycor. |

## Uwierzytelnianie

Paycor używa OAuth2 z przyznaniem kodu autoryzacji, więc wprowadzenie danych uwierzytelniających to dopiero pierwsza połowa — musisz też jednorazowo zalogować się w Paycor, aby autoryzować PlaidCloud do pobierania Twoich danych.

1. **Wprowadź dane uwierzytelniające i zapisz.** Wypełnij trzy powyższe wartości i zapisz połączenie.
2. **Połącz.** Kliknij **Połącz z Paycor**. PlaidCloud otworzy **okno autoryzacji Paycor**. Przycisk jest dostępny po zapisaniu połączenia.
3. **Zaloguj się i zatwierdź.** Zaloguj się do Paycor w tym oknie i zatwierdź dostęp. Paycor przekieruje Cię z powrotem do PlaidCloud, który zapisze w połączeniu **token odświeżania** i będzie go odtąd automatycznie używać do uzyskiwania tokenów dostępu.

<Aside type="caution">Zezwól na wyskakujące okna dla PlaidCloud. Jeśli okno autoryzacji zostanie zablokowane, PlaidCloud poinformuje o tym — zezwól na wyskakujące okna i kliknij **Połącz z Paycor** ponownie.</Aside>

Host API (`apis.paycor.com`) i punkt końcowy tokenu (`https://apis.paycor.com/sts/v1/common/token`) są zarządzane przez PlaidCloud. Nie ma pól adresów URL do wypełnienia i nie powinno być potrzeby ich edytowania.

### Ponowna autoryzacja wygasłego połączenia

Dostęp do Paycor może wygasnąć — token odświeżania traci ważność lub zostaje odwołany albo aplikacja Paycor zostaje dezaktywowana. W takiej sytuacji przepływy pracy korzystające z połączenia przestają się uwierzytelniać i kończą się niepowodzeniem. Aby przywrócić działanie:

1. Sprawdź, czy aplikacja Paycor jest nadal **aktywowana** (adresy URL aktywacji znajdziesz w sekcji [Konfiguracja Paycor](#konfiguracja-paycor)).
2. Otwórz połączenie i kliknij **Połącz z Paycor**, aby ponownie uruchomić autoryzację Paycor, a następnie zaloguj się i zatwierdź. Spowoduje to wygenerowanie nowego tokenu odświeżania i połączenie wznowi działanie.

<Aside type="danger">Ustanawiaj i naprawiaj połączenia Paycor za pomocą tego formularza połączenia. Edycja bazowego połączenia w ogólnym edytorze REST lub przez API może nadpisać zarządzany adres URL tokenu i zepsuć uwierzytelnianie.</Aside>
