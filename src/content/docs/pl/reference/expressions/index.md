## Gdzie szukać kanonicznej składni

PlaidCloud Lakehouse korzysta z bibliotek funkcji SQL bazowych silników. Szczegóły dotyczące argumentów funkcji, przypadków brzegowych i najbardziej aktualnego zachowania znajdziesz w dokumentacji silników, obok przykładów dostosowanych do PlaidCloud, które tu zamieszczamy.

- **Lakehouse v1** → [Opis funkcji SQL Databend](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [Opis funkcji SQL StarRocks](https://docs.starrocks.io/docs/sql-reference/sql-functions/) (PlaidCloud Lakehouse v2 śledzi StarRocks 4.1)
