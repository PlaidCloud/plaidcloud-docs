Generuje kod Soundex dla ciągu znaków.

- Kod Soundex składa się z litery, po której następują trzy cyfry. Implementacja w PlaidCloud Lakehouse zwraca więcej niż 4 znaki, ale aby uzyskać standardowy kod Soundex, można zastosować do wyniku funkcję [SUBSTR](../substr).
- Wszystkie znaki niealfabetyczne w ciągu są ignorowane.
- Wszystkie międzynarodowe znaki alfabetyczne spoza zakresu A-Z są ignorowane, chyba że są pierwszą literą.


<Aside>Czym jest Soundex? Soundex konwertuje ciąg alfanumeryczny na czteroznakowy kod oparty na tym, jak ciąg brzmi po wymówieniu w języku angielskim. Więcej informacji znajdziesz na stronie https://en.wikipedia.org/wiki/Soundex</Aside>

Zobacz także: [SOUNDS LIKE](../soundslike)

## Składnia Analyze

```python
func.soundex(<str>)
```

## Przykłady Analyze

```python
func.soundex('PlaidCloud Lakehouse')
┌──────────────────────────────────────┐
│ func.soundex('PlaidCloud Lakehouse') │
├──────────────────────────────────────┤
│ D153                                 │
└──────────────────────────────────────┘
```

## Składnia SQL

```sql
SOUNDEX(<str>)
```

## Argumenty

| Argumenty | Opis         |
|-----------|--------------|
| str  | Ciąg znaków. |

## Typ zwracany

Zwraca kod typu VARCHAR lub wartość NULL.

## Przykłady SQL

```sql
SELECT SOUNDEX('PlaidCloud Lakehouse');

---
D153

-- All non-alphabetic characters in the string are ignored.
SELECT SOUNDEX('PlaidCloud Lakehouse!');

---
D153

-- All international alphabetic characters outside the A-Z range are ignored unless they're the first letter.
SELECT SOUNDEX('PlaidCloud Lakehouse，你好');

---
D153

SELECT SOUNDEX('你好，PlaidCloud Lakehouse');

---
你3153

-- SUBSTR the result to get a standard Soundex code.
SELECT SOUNDEX('databend cloud'),SUBSTR(SOUNDEX('databend cloud'),1,4);

soundex('databend cloud')|substring(soundex('databend cloud') from 1 for 4)|
-------------------------+-------------------------------------------------+
D153243                  |D153                                             |

SELECT SOUNDEX(NULL);
┌─────────────────────────────────────┐
│ `SOUNDEX(NULL)`                     │
├─────────────────────────────────────┤
│ <null>                              │
└─────────────────────────────────────┘
```
