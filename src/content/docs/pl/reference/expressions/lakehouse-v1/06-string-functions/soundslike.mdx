Porównuje wymowę dwóch ciągów znaków na podstawie ich kodów Soundex. Soundex to algorytm fonetyczny, który tworzy kod reprezentujący wymowę ciągu znaków, co umożliwia przybliżone dopasowywanie ciągów na podstawie wymowy, a nie pisowni. PlaidCloud Lakehouse udostępnia funkcję [SOUNDEX](../soundex), która pozwala uzyskać kod Soundex z ciągu znaków.

SOUNDS LIKE jest często używane w klauzuli WHERE zapytań SQL do zawężania wierszy za pomocą rozmytego dopasowywania ciągów, na przykład dla nazwisk i adresów; zobacz [Filtrowanie wierszy](#filtrowanie-wierszy) w sekcji [Przykłady](#przykłady-sql).

<Aside>Choć ta funkcja może być przydatna do przybliżonego dopasowywania ciągów, warto pamiętać, że nie zawsze jest dokładna. Algorytm Soundex opiera się na regułach wymowy angielskiej i może nie działać dobrze dla ciągów z innych języków lub dialektów.</Aside>

## Składnia Analyze

```python
func.sounds_like(<str1>, <str2>)
```

## Przykłady Analyze

```python
func..sounds_like('Monday', 'Sunday')
┌───────────────────────────────────────┐
│ func..sounds_like('Monday', 'Sunday') │
├───────────────────────────────────────┤
│                                     0 │
└───────────────────────────────────────┘
```

## Składnia SQL

```sql
<str1> SOUNDS LIKE <str2>
```

## Argumenty

| Argumenty | Opis                          |
|-----------|-------------------------------|
| str1, 2   | Porównywane ciągi znaków.     |

## Typ zwracany

Zwraca wartość logiczną 1, jeśli kody Soundex obu ciągów są takie same (co oznacza, że brzmią podobnie), a w przeciwnym razie 0.

## Przykłady SQL

### Porównywanie ciągów znaków

```sql
SELECT 'two' SOUNDS LIKE 'too'
----
1

SELECT CONCAT('A', 'B') SOUNDS LIKE 'AB';
----
1

SELECT 'Monday' SOUNDS LIKE 'Sunday';
----
0
```

### Filtrowanie wierszy

SELECT * FROM  employees;
