Zwraca tablicę zawierającą indeksy [H3](https://eng.uber.com/h3/) heksagonów k-pierścienia otaczających wejściowy indeks H3. Każdy element tej tablicy jest indeksem H3.

## Składnia Analyze

```python
func.h3_k_ring(h3, k)
```

## Przykłady Analyze

```python
func.h3_k_ring(644325524701193974, 1)

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                                  func.h3_k_ring(644325524701193974, 1)                                                 │
├────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ [644325524701193974,644325524701193899,644325524701193869,644325524701193970,644325524701193968,644325524701193972,644325524701193897] │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## Składnia SQL

```sql
H3_K_RING(h3, k)
```

## Przykłady SQL

