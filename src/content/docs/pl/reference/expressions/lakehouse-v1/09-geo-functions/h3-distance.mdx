Zwraca odległość siatkową między dwoma podanymi indeksami [H3](https://eng.uber.com/h3/).

<Aside>Obliczenia odległości H3 umożliwiają wyznaczanie odległości wyłącznie między sąsiadującymi heksagonami. Próba użycia tej funkcji dla heksagonów niesąsiadujących zakończy się błędem.</Aside>

### Składnia Analyze

```python
func.h3_distance(h3, a_h3)
```

## Przykłady Analyze

```python
func.h3_distance(599119489002373119, 599119491149856767)

┌──────────────────────────────────────────────────────────┐
│ func.h3_distance(599119489002373119, 599119491149856767) │
├──────────────────────────────────────────────────────────┤
│                                                        1 │
└──────────────────────────────────────────────────────────┘
```

## Składnia SQL

```sql
H3_DISTANCE(h3, a_h3)
```

## Przykłady SQL

```sql
SELECT H3_DISTANCE(599119489002373119, 599119491149856767);

┌─────────────────────────────────────────────────────┐
│ h3_distance(599119489002373119, 599119491149856767) │
├─────────────────────────────────────────────────────┤
│                                                   1 │
└─────────────────────────────────────────────────────┘
```
