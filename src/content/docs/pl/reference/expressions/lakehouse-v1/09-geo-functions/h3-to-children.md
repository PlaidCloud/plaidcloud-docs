Zwraca indeksy zawarte w `h3` w rozdzielczości `child_res`.

## Składnia Analyze

```python
func.h3_to_children(h3, child_res)
```

## Przykłady Analyze


## Składnia SQL

```sql
H3_TO_CHILDREN(h3, child_res)
```
