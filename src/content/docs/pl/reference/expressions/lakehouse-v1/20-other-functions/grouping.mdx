Zwraca maskę bitową wskazującą, które wyrażenia `GROUP BY` nie są uwzględnione w bieżącym zestawie grupowania. Bity są przypisywane tak, że skrajny prawy argument odpowiada najmniej znaczącemu bitowi; każdy bit ma wartość 0, jeśli odpowiadające mu wyrażenie jest uwzględnione w kryteriach grupowania zestawu grupowania generującego bieżący wiersz wyniku, i 1, jeśli nie jest uwzględnione.

## Składnia SQL

```sql
GROUPING ( expr [, expr, ...] )
```

<Aside>`GROUPING` można używać wyłącznie z `GROUPING SETS`, `ROLLUP` lub `CUBE`, a jego argumenty muszą znajdować się na liście zestawów grupowania.</Aside>

## Argumenty

Elementy zestawów grupowania.

## Zwracany typ

UInt32.

## Przykłady SQL

```sql
select a, b, grouping(a), grouping(b), grouping(a,b), grouping(b,a) from t group by grouping sets ((a,b),(a),(b), ()) ;
┌──────┬──────┬─────────────┬─────────────┬────────────────┬────────────────┐
│ a    │ b    │ grouping(a) │ grouping(b) │ grouping(a, b) │ grouping(b, a) │
├──────┼──────┼─────────────┼─────────────┼────────────────┼────────────────┤
│ NULL │ A    │           1 │           0 │              2 │              1 │
│ a    │ NULL │           0 │           1 │              1 │              2 │
│ b    │ A    │           0 │           0 │              0 │              0 │
│ NULL │ NULL │           1 │           1 │              3 │              3 │
│ a    │ A    │           0 │           0 │              0 │              0 │
│ b    │ B    │           0 │           0 │              0 │              0 │
│ b    │ NULL │           0 │           1 │              1 │              2 │
│ a    │ B    │           0 │           0 │              0 │              0 │
│ NULL │ B    │           1 │           0 │              2 │              1 │
└──────┴──────┴─────────────┴─────────────┴────────────────┴────────────────┘
```
