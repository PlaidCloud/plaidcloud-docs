Ten dokument przedstawia funkcję ai_embedding_vector w PlaidCloud Lakehouse i pokazuje, jak za jej pomocą tworzyć osadzenia dokumentów.

Zobacz [implementację źródłową](https://github.com/datafuselabs/databend/blob/1e93c5b562bd159ecb0f336bb88fd1b7f9dc4a62/src/common/openai/src/embedding.rs).

Domyślnie PlaidCloud Lakehouse używa do generowania osadzeń modelu [text-embedding-ada](https://platform.openai.com/docs/models/embeddings).

<Aside>Od wersji PlaidCloud Lakehouse v1.1.47 PlaidCloud Lakehouse obsługuje [usługę Azure OpenAI](https://azure.microsoft.com/en-au/products/cognitive-services/openai-service). Ta integracja zapewnia lepszą prywatność danych. Aby używać Azure OpenAI, dodaj następujące ustawienia do sekcji `[query]`: ```sql # Azure OpenAI openai_api_chat_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_embedding_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_version = "2023-03-15-preview" ```</Aside>


<Aside type="caution">PlaidCloud Lakehouse korzysta z (Azure) OpenAI dla funkcji `AI_EMBEDDING_VECTOR` i wysyła dane kolumny osadzenia do (Azure) OpenAI. Funkcje te działają tylko wtedy, gdy konfiguracja PlaidCloud Lakehouse zawiera `openai_api_key`; w przeciwnym razie są nieaktywne. Ta funkcja jest domyślnie dostępna w PlaidCloud Lakehouse z użyciem klucza Azure OpenAI. Korzystając z nich, potwierdzasz, że Twoje dane zostaną przez nas wysłane do Azure OpenAI.</Aside>

## Przegląd funkcji Ai_embedding_vector

Funkcja `ai_embedding_vector` w PlaidCloud Lakehouse jest wbudowaną funkcją generującą osadzenia wektorowe dla danych tekstowych. Przydaje się w zadaniach przetwarzania języka naturalnego, takich jak podobieństwo dokumentów, klasteryzacja i systemy rekomendacji.

Funkcja przyjmuje tekst jako dane wejściowe i zwraca wielowymiarowy wektor reprezentujący znaczenie semantyczne i kontekst tego tekstu. Osadzenia są tworzone przy użyciu modeli wstępnie wytrenowanych na dużych korpusach tekstów, które uchwytują relacje między słowami i frazami w przestrzeni ciągłej.

## Tworzenie osadzeń za pomocą Ai_embedding_vector

Aby utworzyć osadzenia dla dokumentu tekstowego za pomocą funkcji `ai_embedding_vector`, skorzystaj z poniższego przykładu.
1. Utwórz tabelę do przechowywania dokumentów:
```sql
CREATE TABLE documents (
                           id INT,
                           title VARCHAR,
                           content VARCHAR,
                           embedding ARRAY(FLOAT32)
);
```

2. Wstaw do tabeli przykładowe dokumenty:
```sql
INSERT INTO documents(id, title, content)
VALUES
    (1, 'A Brief History of AI', 'Artificial intelligence (AI) has been a fascinating concept of science fiction for decades...'),
    (2, 'Machine Learning vs. Deep Learning', 'Machine learning and deep learning are two subsets of artificial intelligence...'),
    (3, 'Neural Networks Explained', 'A neural network is a series of algorithms that endeavors to recognize underlying relationships...'),
```

3. Wygeneruj osadzenia:
```sql
UPDATE documents SET embedding = ai_embedding_vector(content) WHERE length(embedding) = 0;
```
Po uruchomieniu zapytania kolumna osadzenia w tabeli będzie zawierać wygenerowane osadzenia.

Osadzenia są przechowywane jako tablica wartości `FLOAT32` w kolumnie osadzenia, której typem jest `ARRAY(FLOAT32)`.

Możesz teraz używać tych osadzeń w różnych zadaniach przetwarzania języka naturalnego, na przykład do wyszukiwania podobnych dokumentów lub grupowania dokumentów na podstawie ich treści.

4. Sprawdź osadzenia:

```sql
SELECT length(embedding) FROM documents;
┌───────────────────┐
│ length(embedding) │
├───────────────────┤
│              1536 │
│              1536 │
│              1536 │
└───────────────────┘
```
Powyższe zapytanie pokazuje, że wygenerowane osadzenia mają długość 1536 (wymiarów) dla każdego dokumentu.
