Oblicza medianę ciągu danych liczbowych za pomocą algorytmu [t-digest](https://github.com/tdunning/t-digest/blob/master/docs/t-digest-paper/histo.pdf).

<Aside type="caution">Wartości NULL nie są uwzględniane w obliczeniach.</Aside>

## Składnia Analyze

```python
func.median_tdigest(<expr>)
```

## Przykłady Analyze

```python
func.median_tdigest(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## Składnia SQL

```sql
MEDIAN_TDIGEST(<expr>)
```

## Argumenty

| Argumenty | Opis                       |
|-----------|----------------------------|
| `<expr>`  | Dowolne wyrażenie liczbowe |

## Typ zwracany

Zwraca wartość tego samego typu danych co wartości wejściowe.

## Przykłady SQL

```sql
-- Create a table and insert sample data
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);

-- Calculate median exam score
SELECT MEDIAN_TDIGEST(score) AS median_score
FROM exam_scores;

|  median_score  |
|----------------|
|      85.0      |
```
