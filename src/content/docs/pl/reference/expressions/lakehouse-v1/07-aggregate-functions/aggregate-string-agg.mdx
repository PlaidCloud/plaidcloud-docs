Funkcja agregująca.

Funkcja STRING_AGG() konwertuje wszystkie wartości kolumny różne od NULL na ciąg znaków, rozdzielając je separatorem.

## Składnia Analyze

```python
func.string_agg(<expr> [, delimiter])
```

## Przykłady Analyze

```python
func.string_agg(table.language_name).alias('concatenated_languages')

|          concatenated_languages         |
|-----------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```

## Składnia SQL

```sql
STRING_AGG(<expr>)
STRING_AGG(<expr> [, delimiter])
```

<Aside>Jeśli `<expr>` nie jest wyrażeniem tekstowym, użyj `::VARCHAR` do konwersji. Na przykład: ```sql SELECT string_agg(number::VARCHAR, '|') AS s FROM numbers(5); ┌───────────┐ │ s │ ├───────────┤ │ 0│1│2│3│4 │ └───────────┘ ```</Aside>

## Argumenty

| Argumenty   | Opis                                                                           |
|-------------|--------------------------------------------------------------------------------|
| `<expr>`    | Dowolne wyrażenie tekstowe (jeśli nie jest tekstowe, użyj `::VARCHAR` do konwersji) |
| `delimiter` | Opcjonalny stały ciąg znaków; jeśli nie został podany, używany jest pusty ciąg |

## Typ zwracany

typ tekstowy

## Przykłady SQL

**Tworzenie tabeli i wstawianie przykładowych danych**

```sql
CREATE TABLE programming_languages (
  id INT,
  language_name VARCHAR
);

INSERT INTO programming_languages (id, language_name)
VALUES (1, 'Python'),
       (2, 'JavaScript'),
       (3, 'Java'),
       (4, 'C#'),
       (5, 'Ruby');
```

**Przykład zapytania: połączenie nazw języków programowania z separatorem**
```sql
SELECT STRING_AGG(language_name, ', ') AS concatenated_languages
FROM programming_languages;
```

**Wynik**
```sql
|          concatenated_languages         |
|------------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```
