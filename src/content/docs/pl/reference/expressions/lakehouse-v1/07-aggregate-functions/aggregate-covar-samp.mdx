Funkcja agregująca.

Funkcja covar_samp() zwraca kowariancję z próby (Σ((x - x̅)(y - y̅)) / (n - 1)) dla dwóch kolumn danych.

<Aside type="caution">Wartości NULL nie są liczone.</Aside>

## Składnia Analyze

```python
func.covar_samp(<expr1>, <expr2>)
```

## Przykłady Analyze

```python
func.covar_samp(table.items_sold, table.profit).alias('covar_samp_items_profit')

| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```

## Składnia SQL

```sql
COVAR_SAMP(<expr1>, <expr2>)
```

## Argumenty

| Argumenty |          Opis            |
|-----------| ------------------------ |
| `<expr1>` | Dowolne wyrażenie liczbowe |
| `<expr2>` | Dowolne wyrażenie liczbowe |

## Typ zwracany

float64; gdy n &lt;= 1, zwraca +∞.

## Przykłady SQL

**Tworzenie tabeli i wstawianie przykładowych danych**

```sql
CREATE TABLE store_sales (
  id INT,
  store_id INT,
  items_sold INT,
  profit FLOAT
);

INSERT INTO store_sales (id, store_id, items_sold, profit)
VALUES (1, 1, 100, 1000),
       (2, 2, 200, 2000),
       (3, 3, 300, 3000),
       (4, 4, 400, 4000),
       (5, 5, 500, 5000);
```

**Przykład zapytania: obliczenie kowariancji z próby między sprzedaną liczbą sztuk a zyskiem**

```sql
SELECT COVAR_SAMP(items_sold, profit) AS covar_samp_items_profit
FROM store_sales;
```

**Wynik**

```sql
| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```
