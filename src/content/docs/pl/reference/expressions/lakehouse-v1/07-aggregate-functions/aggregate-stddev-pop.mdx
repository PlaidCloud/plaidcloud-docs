Funkcja agregująca.

Funkcja STDDEV_POP() zwraca odchylenie standardowe z populacji (pierwiastek kwadratowy z VAR_POP()) dla wyrażenia.

<Aside>Można również użyć STD() lub STDDEV() — są równoważne, ale nie należą do standardu SQL.</Aside>

<Aside type="caution">Wartości NULL nie są liczone.</Aside>

## Składnia Analyze

```python
func.stddev_pop(<expr>)
```

## Przykłady Analyze

```python
func.stddev_pop(table.score).alias('test_score_stddev_pop')

| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```

## Składnia SQL

```sql
STDDEV_POP(<expr>)
STDDEV(<expr>)
STD(<expr>)
```

## Argumenty

| Argumenty | Opis                       |
|-----------|----------------------------|
| `<expr>`  | Dowolne wyrażenie liczbowe |

## Typ zwracany

double

## Przykłady SQL

**Tworzenie tabeli i wstawianie przykładowych danych**
```sql
CREATE TABLE test_scores (
  id INT,
  student_id INT,
  score FLOAT
);

INSERT INTO test_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 85),
       (3, 3, 90),
       (4, 4, 95),
       (5, 5, 100);
```

**Przykład zapytania: obliczenie odchylenia standardowego z populacji dla wyników testu**
```sql
SELECT STDDEV_POP(score) AS test_score_stddev_pop
FROM test_scores;
```

**Wynik**
```sql
| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```
