Funkcja agregująca.

Funkcja STDDEV_SAMP() zwraca odchylenie standardowe z próby (pierwiastek kwadratowy z VAR_SAMP()) dla wyrażenia.

<Aside type="caution">Wartości NULL nie są liczone.</Aside>

## Składnia Analyze

```python
func.stddev_samp(<expr>)
```

## Przykłady Analyze

```python
func.stddev_samp(table.height).alias('height_stddev_samp')

| height_stddev_samp |
|--------------------|
|      0.240         |
```

## Składnia SQL

```sql
STDDEV_SAMP(<expr>)
```

## Argumenty

| Argumenty | Opis                       |
|-----------|----------------------------|
| `<expr>`  | Dowolne wyrażenie liczbowe |

## Typ zwracany

double

## Przykłady SQL

**Tworzenie tabeli i wstawianie przykładowych danych**
```sql
CREATE TABLE height_data (
  id INT,
  person_id INT,
  height FLOAT
);

INSERT INTO height_data (id, person_id, height)
VALUES (1, 1, 5.8),
       (2, 2, 6.1),
       (3, 3, 5.9),
       (4, 4, 5.7),
       (5, 5, 6.3);
```

**Przykład zapytania: obliczenie odchylenia standardowego z próby dla wzrostu**
```sql
SELECT STDDEV_SAMP(height) AS height_stddev_samp
FROM height_data;
```

**Wynik**
```sql
| height_stddev_samp |
|--------------------|
|      0.240         |
```
