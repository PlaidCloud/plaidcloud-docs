Oblicza przybliżony kwantyl ciągu danych liczbowych za pomocą algorytmu [t-digest](https://github.com/tdunning/t-digest/blob/master/docs/t-digest-paper/histo.pdf).

<Aside type="caution">Wartości NULL nie są uwzględniane w obliczeniach.</Aside>

## Składnia Analyze

```python
func.quantile_tdigest(<levels>, <expr>)
```

## Przykłady Analyze

```python
func.quantile_tdigest([0.5, 0.8], table.sales_amount).alias('sales_amounts')

| sales_amounts         |
|-----------------------+
| [6000.0,7000.0]       |
```

## Składnia SQL

```sql
QUANTILE_TDIGEST(<level1>[, <level2>, ...])(<expr>)
```

## Argumenty

| Argumenty   | Opis                                                                                                                                            |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `<level n>` | Poziom kwantyla to stała liczba zmiennoprzecinkowa z zakresu od 0 do 1. Zaleca się używanie wartości poziomu z zakresu [0.01, 0.99].            |
| `<expr>`    | Dowolne wyrażenie liczbowe                                                                                                                      |

## Typ zwracany

Zwraca wartość Float64 albo tablicę wartości Float64, zależnie od liczby podanych poziomów kwantyla.

## Przykłady SQL

```sql
-- Create a table and insert sample data
CREATE TABLE sales_data (
  id INT,
  sales_person_id INT,
  sales_amount FLOAT
);

INSERT INTO sales_data (id, sales_person_id, sales_amount)
VALUES (1, 1, 5000),
       (2, 2, 5500),
       (3, 3, 6000),
       (4, 4, 6500),
       (5, 5, 7000);

SELECT QUANTILE_TDIGEST(0.5)(sales_amount) AS median_sales_amount
FROM sales_data;

median_sales_amount|
-------------------+
             6000.0|

SELECT QUANTILE_TDIGEST(0.5, 0.8)(sales_amount)
FROM sales_data;

quantile_tdigest(0.5, 0.8)(sales_amount)|
----------------------------------------+
[6000.0,7000.0]                         |
```
