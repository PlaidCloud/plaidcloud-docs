Funkcja agregująca.

Funkcja count(distinct ...) oblicza liczbę unikatowych wartości w zbiorze wartości.

Aby uzyskać szacunkowy wynik z dużych zbiorów danych przy niewielkim zużyciu pamięci i czasu, rozważ użycie funkcji [APPROX_COUNT_DISTINCT](../aggregate-approx-count-distinct).

<Aside type="caution">Wartości NULL nie są liczone.</Aside>

## Składnia Analyze

```python
func.count_distinct(<column>)
```

## Przykłady Analyze

```python
func.count_distinct(table.category).alias('unique_categories')

| unique_categories |
|-------------------|
|         2         |
```

## Składnia SQL

```sql
COUNT(distinct <expr> ...)
UNIQ(<expr>)
```

## Argumenty

| Argumenty | Opis                                                    |
|-----------|---------------------------------------------------------|
| `<expr>`  | Dowolne wyrażenie, liczba argumentów mieści się w zakresie [1, 32] |

## Typ zwracany

UInt64

## Przykłady SQL

**Tworzenie tabeli i wstawianie przykładowych danych**
```sql
CREATE TABLE products (
  id INT,
  name VARCHAR,
  category VARCHAR,
  price FLOAT
);

INSERT INTO products (id, name, category, price)
VALUES (1, 'Laptop', 'Electronics', 1000),
       (2, 'Smartphone', 'Electronics', 800),
       (3, 'Tablet', 'Electronics', 600),
       (4, 'Chair', 'Furniture', 150),
       (5, 'Table', 'Furniture', 300);
```

**Przykład zapytania: zliczenie unikatowych kategorii**

```sql
SELECT COUNT(DISTINCT category) AS unique_categories
FROM products;
```

**Wynik**
```sql
| unique_categories |
|-------------------|
|         2         |
```
