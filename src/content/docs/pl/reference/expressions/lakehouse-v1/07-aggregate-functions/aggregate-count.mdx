Funkcja COUNT() zwraca liczbę rekordów zwróconych przez zapytanie SELECT.

<Aside type="caution">Wartości NULL nie są liczone.</Aside>

## Składnia Analyze

```python
func.count(<column>)
```

## Przykłady Analyze

```python
func.count(table.grade).alias('count_valid_grades')

| count_valid_grades |
|--------------------|
|          4         |
```

## Składnia SQL

```sql
COUNT(<expr>)
```

## Argumenty

| Argumenty | Opis                                                                                                                                                            |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<expr>`  | Dowolne wyrażenie. <br /> Może to być nazwa kolumny, wynik innej funkcji lub operacja matematyczna.<br />Dozwolony jest także znak `*`, oznaczający zwykłe zliczanie wierszy. |

## Typ zwracany

Liczba całkowita.

## Przykłady SQL

**Tworzenie tabeli i wstawianie przykładowych danych**
```sql
CREATE TABLE students (
  id INT,
  name VARCHAR,
  age INT,
  grade FLOAT NULL
);

INSERT INTO students (id, name, age, grade)
VALUES (1, 'John', 21, 85),
       (2, 'Emma', 22, NULL),
       (3, 'Alice', 23, 90),
       (4, 'Michael', 21, 88),
       (5, 'Sophie', 22, 92);

```

**Przykład zapytania: zliczenie uczniów z prawidłowymi ocenami**
```sql
SELECT COUNT(grade) AS count_valid_grades
FROM students;
```

**Wynik**
```sql
| count_valid_grades |
|--------------------|
|          4         |
```
