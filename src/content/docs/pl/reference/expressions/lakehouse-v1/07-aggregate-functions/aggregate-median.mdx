Funkcja agregująca.

Funkcja MEDIAN() oblicza medianę ciągu danych liczbowych.

<Aside type="caution">Wartości NULL nie są liczone.</Aside>

## Składnia Analyze

```python
func.median(<expr>)
```

## Przykłady Analyze

```python
func.median(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## Składnia SQL

```sql
MEDIAN(<expr>)
```

## Argumenty

| Argumenty | Opis                       |
|-----------|----------------------------|
| `<expr>`  | Dowolne wyrażenie liczbowe |

## Typ zwracany

Typ wartości.

## Przykłady SQL

**Tworzenie tabeli i wstawianie przykładowych danych**
```sql
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);
```

**Przykład zapytania: obliczenie mediany wyników egzaminu**
```sql
SELECT MEDIAN(score) AS median_score
FROM exam_scores;
```

**Wynik**
```sql
|  median_score  |
|----------------|
|      85.0      |
```
