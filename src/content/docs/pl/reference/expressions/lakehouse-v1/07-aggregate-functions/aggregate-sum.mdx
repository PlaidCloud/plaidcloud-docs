Funkcja agregująca.

Funkcja SUM() oblicza sumę zbioru wartości.

<Aside type="caution">Wartości NULL nie są liczone.</Aside>


## Składnia Analyze

```python
func.sum(<column>)
```

## Przykłady Analyze

```python
func.sum(table.quantity).alias('total_quantity_sold')

| total_quantity_sold |
|---------------------|
|         41          |
```

## Składnia SQL

```sql
SUM(<expr>)
```

## Argumenty

| Argumenty | Opis                       |
|-----------|----------------------------|
| `<expr>`  | Dowolne wyrażenie liczbowe |

## Typ zwracany

Wartość double, jeśli typ wejściowy to double; w przeciwnym razie liczba całkowita.

## Przykłady SQL

**Tworzenie tabeli i wstawianie przykładowych danych**
```sql
CREATE TABLE sales_data (
  id INT,
  product_id INT,
  quantity INT
);

INSERT INTO sales_data (id, product_id, quantity)
VALUES (1, 1, 10),
       (2, 2, 5),
       (3, 3, 8),
       (4, 4, 3),
       (5, 5, 15);
```

**Przykład zapytania: obliczenie łącznej liczby sprzedanych produktów**
```sql
SELECT SUM(quantity) AS total_quantity_sold
FROM sales_data;
```

**Wynik**
```sql
| total_quantity_sold |
|---------------------|
|         41          |
```
