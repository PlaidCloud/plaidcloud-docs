Sprawdza, czy wejściowa wartość JSON jest ciągiem znaków.

## Składnia Analyze

```python
func.is_string(<expr>)
```

## Przykłady Analyze

```python

func.is_string(func.parse_json('"abc"')), func.is_string(func.parse_json('123'))
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ func.is_string(func.parse_json('"abc"'))      │ func.is_string(func.parse_json('123'))           │
├───────────────────────────────────────────────┼──────────────────────────────────────────────────┤
│ true                                          │ false                                            │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## Składnia SQL

```sql
IS_STRING( <expr> )
```

## Typ zwracany

Zwraca `true`, jeśli wejściowa wartość JSON jest ciągiem znaków, a w przeciwnym razie `false`.

## Przykłady SQL

```sql
SELECT
  IS_STRING(PARSE_JSON('"abc"')),
  IS_STRING(PARSE_JSON('123'));

┌───────────────────────────────────────────────────────────────┐
│ is_string(parse_json('"abc"')) │ is_string(parse_json('123')) │
├────────────────────────────────┼──────────────────────────────┤
│ true                           │ false                        │
└───────────────────────────────────────────────────────────────┘
```
