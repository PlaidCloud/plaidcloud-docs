Sprawdza, czy wejściowa wartość JSON jest wartością logiczną.

## Składnia Analyze

```python
func.is_boolean(<expr>)
```

## Przykłady Analyze

```python

func.is_boolean(func.parse_json('true')), func.is_boolean(func.parse_json('[1,2,3]'))
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ func.is_boolean(func.parse_json('true')) │ func.is_boolean(func.parse_json('[1,2,3]')) │
├──────────────────────────────────────────┼─────────────────────────────────────────────┤
│ true                                     │ false                                       │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## Składnia SQL

```sql
IS_BOOLEAN( <expr> )
```

## Typ zwracany

Zwraca `true`, jeśli wejściowa wartość JSON jest wartością logiczną, a w przeciwnym razie `false`.

## Przykłady SQL

```sql
SELECT
  IS_BOOLEAN(PARSE_JSON('true')),
  IS_BOOLEAN(PARSE_JSON('[1,2,3]'));

┌────────────────────────────────────────────────────────────────────┐
│ is_boolean(parse_json('true')) │ is_boolean(parse_json('[1,2,3]')) │
├────────────────────────────────┼───────────────────────────────────┤
│ true                           │ false                             │
└────────────────────────────────────────────────────────────────────┘
```
