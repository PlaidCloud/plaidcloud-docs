Wyodrębnia elementy tablicy JSON i zwraca je jako osobne wiersze zbioru wyników. JSON_ARRAY_ELEMENTS nie rozwija rekurencyjnie zagnieżdżonych tablic; traktuje je jako pojedyncze elementy.


## Składnia Analyze

```python
func.json_array_elements(<json_string>)
```

## Przykłady Analyze

```python

func.json_array_elements(func.parse_json('[ \n  {"product": "laptop", "brand": "apple", "price": 1500},\n  {"product": "smartphone", "brand": "samsung", "price": 800},\n  {"product": "headphones", "brand": "sony", "price": 150}\n]'))
┌───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐

├───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
```

## Składnia SQL

```sql
JSON_ARRAY_ELEMENTS(<json_string>)
```

## Typ zwracany

JSON_ARRAY_ELEMENTS zwraca zbiór wartości VARIANT, z których każda reprezentuje element wyodrębniony z wejściowej tablicy JSON.

## Przykłady SQL

```sql
    )
  );
```
