Sprawdza, czy wejściowa wartość JSON jest liczbą całkowitą.


## Składnia Analyze

```python
func.is_integer(<expr>)
```

## Przykłady Analyze

```python

func.is_integer(func.parse_json('123')), func.is_integer(func.parse_json('[1,2,3]'))
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ func.is_integer(func.parse_json('123'))  │ func.is_integer(func.parse_json('[1,2,3]')) │
├──────────────────────────────────────────┼─────────────────────────────────────────────┤
│ true                                     │ false                                       │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## Składnia SQL

```sql
IS_INTEGER( <expr> )
```

## Typ zwracany

Zwraca `true`, jeśli wejściowa wartość JSON jest liczbą całkowitą, a w przeciwnym razie `false`.

## Przykłady SQL

```sql
SELECT
  IS_INTEGER(PARSE_JSON('123')),
  IS_INTEGER(PARSE_JSON('[1,2,3]'));

┌───────────────────────────────────────────────────────────────────┐
│ is_integer(parse_json('123')) │ is_integer(parse_json('[1,2,3]')) │
├───────────────────────────────┼───────────────────────────────────┤
│ true                          │ false                             │
└───────────────────────────────────────────────────────────────────┘
```
