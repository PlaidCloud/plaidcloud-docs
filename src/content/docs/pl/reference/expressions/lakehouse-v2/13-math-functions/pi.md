Zwraca stałą matematyczną pi.

## Składnia Analyze

```python
func.pi()
```

## Przykłady Analyze

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## Składnia SQL

```sql
PI()
```

## Przykłady SQL

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
