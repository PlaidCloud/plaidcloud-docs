Zwraca stałą matematyczną e (liczbę Eulera).

## Składnia Analyze

```python
func.e()
```

## Przykłady Analyze

```python
func.e()

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## Składnia SQL

```sql
E()
```

## Przykłady SQL

```sql
SELECT E();

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
