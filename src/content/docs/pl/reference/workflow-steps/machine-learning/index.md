Wytrenuj model na dowolnej tabeli, przenoś go przez przepływ pracy jako tabelę modelu i oceniaj nim tabele danych.

## Kroki

- [ML: trenuj model](/pl/reference/workflow-steps/machine-learning/ml-train/) — dopasuj model scikit-learn (klasyfikacji lub regresji) do tabeli źródłowej i zapisz tabelę modelu, którą można odpytywać, z dopasowanym modelem, parametrami, listą cech i metrykami uczenia.
- [ML: oceniaj](/pl/reference/workflow-steps/machine-learning/ml-score/) — oceń tabelę danych za pomocą wytrenowanej tabeli modelu i dołącz kolumnę predykcji.

Zobacz [Migracja przepływów pracy Alteryx](/pl/guides/workflows/migrate-alteryx-workflows/#konwersje-uczenia-maszynowego-assisted-modeling), aby dowiedzieć się, jak potoki Alteryx Assisted Modeling są konwertowane na te kroki.
