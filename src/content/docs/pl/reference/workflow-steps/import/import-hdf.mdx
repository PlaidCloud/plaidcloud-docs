## Opis


Importuje pliki HDF5 (Hierarchical Data Format w wersji 5) do tabel projektu PlaidCloud. HDF5 jest powszechny w obliczeniach naukowych, wymianie danych uczenia maszynowego i wszędzie tam, gdzie typowane dane kolumnowe muszą przechodzić tam i z powrotem między narzędziami Python/R/MATLAB.

Specyfikację formatu znajdziesz w [dokumentacji HDF Group](http://www.hdfgroup.org/HDF5/).

### Nazwa klucza

Pliki HDF przechowują dane w strukturze ścieżek. Klucz (ścieżka) jest potrzebny jako miejsce docelowe tabeli w pliku HDF. W większości sytuacji będzie to *table*.
