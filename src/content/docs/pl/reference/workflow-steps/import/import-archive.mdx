## Opis


Importuje natywny plik archiwum PlaidCloud z powrotem do tabeli projektu. Format archiwum zachowuje typy kolumn, metadane i indeksy, które nie przetrwałyby konwersji przez CSV.

Tworzony przez krok [Export to Table Archive](/pl/reference/workflow-steps/export/export-to-table-archive/). Używany do kopii zapasowych projektów, migracji między obszarami roboczymi lub środowiskami oraz niezawodnego przenoszenia danych z typami.
