## Opis

Importuje pliki Alteryx YXDB z PlaidCloud Document. YXDB to natywny format pliku binarnego używany przez Alteryx Designer do przechowywania zestawów danych wraz z metadanymi pól.

Import YXDB odbywa się strumieniowo przez pamięć tymczasową, bez wczytywania całego pliku do pamięci, dlatego bardzo duże pliki importują się bez wyczerpania pamięci. Typy danych pliku — liczby dziesiętne, daty i znaczniki czasu — są zachowywane w tabeli docelowej.

Jeśli skonfigurowany plik `.yxdb` nie istnieje, ale w tym samym folderze znajduje się plik `.parquet` o tej samej nazwie, krok odczytuje plik `.parquet` i wyświetla o tym ostrzeżenie. Skonwertowane przepływy pracy Alteryx zapisują swoje wyniki `.yxdb` jako pliki `.parquet` o tej samej nazwie, więc krok odczytujący jeden z takich plików `.yxdb` automatycznie pobiera dane. Importy, które wyszukują pliki, nie korzystają z tego zastępowania.
