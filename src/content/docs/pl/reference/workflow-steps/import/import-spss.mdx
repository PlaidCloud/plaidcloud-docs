## Opis



Importuje pliki danych SPSS (formaty .sav i .zsav) do tabel projektu PlaidCloud. Przydatne dla danych ankietowych, danych z badań nauk społecznych i każdego potoku współpracującego z narzędziami opartymi na SPSS.

Etykiety zmiennych i etykiety wartości są zachowywane, o ile format je obsługuje.
