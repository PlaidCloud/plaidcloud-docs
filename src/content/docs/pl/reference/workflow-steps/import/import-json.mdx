## Opis

Importuje pliki tekstowe JSON z PlaidCloud Document.

Więcej informacji o plikach JSON znajdziesz na oficjalnej stronie JSON: http://json.org/.

Pliki JSON *nie* zachowują kolejności kolumn. Kolejność kolumn w pliku źródłowym niekoniecznie odzwierciedla kolejność kolumn w zaimportowanej tabeli danych.

Import JSON odbywa się strumieniowo przez pamięć tymczasową, bez wczytywania całego dokumentu do pamięci, dlatego bardzo duże pliki importują się bez wyczerpania pamięci. Kolumny, które pojawiają się dopiero późno w dużym dokumencie, są uwzględniane w zaimportowanej tabeli. Zagnieżdżone obiekty i tablice są importowane jako standardowy zwarty tekst JSON, dzięki czemu kolejne kroki mogą je analizować dowolnym narzędziem JSON.

## Unikatowe elementy konfiguracji

### Orientacja danych JSON

Rozważ następujący zestaw danych:

| ID | Name | Gender | State |
| 1 | Jack | M | MO |
| 2 | Jill | F | MO |
| 3 | George | M | VA |
| 4 | Abe | M | KY |

Pliki JSON można importować z jednego z trzech formatów danych:

* Records: dane są przechowywane w słownikach Python, a każdy wiersz w formacie \{Column -> Value, …}. Na przykład:


```json
[{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" }]
```

* Index: dane są przechowywane w zagnieżdżonych słownikach Python, a każdy wiersz w formacie \{Index -> \{Column -> Value, …},…}. Na przykład:


```json
{ "0": { "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, "1": { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, "2": { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, "3": { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" } }
```

* Split: dane są przechowywane w jednym słowniku Python, a wartości w listach. Na przykład:


```json
{ "columns": ["ID", "Name", "Gender", "State"], "index": [0, 1, 2, 3], "data": [ [1, "Jack", "M", "MO"], [2, "Jill", "F", "MO"], [3, "George", "M", "VA"], [4, "Abe", "M", "KY"] ] }
```

Oprócz powyższych formatów akceptowany jest JSON rozdzielany znakami nowego wiersza (NDJSON): jeden samodzielny obiekt JSON w każdym wierszu, bez otaczającej tablicy. Na przykład:

```json
{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }
{ "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }
```


### Cały dokument

Aby zachować nienaruszony JSON każdego pliku, wybierz **Importuj każdy plik jako jeden wiersz z całym dokumentem JSON** (`whole_document`) w sekcji **Więcej opcji JSON**. Każdy plik jest wtedy importowany jako jeden wiersz zawierający cały dokument JSON, z liczbami zachowanymi tak, jak zapisano.
