## Opis

Krok **Import dBASE** importuje plik dBASE (`.dbf`) (zawiera on własny schemat). Działa w silniku przepływu pracy; wyniki makr pakietowych są przybliżeniem makra Alteryx.

Import dBASE odbywa się strumieniowo przez pamięć tymczasową, bez wczytywania całego pliku do pamięci, dlatego bardzo duże pliki importują się bez wyczerpania pamięci. Typy danych pliku — liczby dziesiętne, daty i znaczniki czasu — są zachowywane w tabeli docelowej.

## Parametry

- **Źródło** — plik `.dbf`.
- **Tabela docelowa** — tabela wyjściowa.
- **Pomiń ponowny import, jeśli pliki źródłowe nie uległy zmianie** — uruchomienie przepływu pracy pomija import, jeśli plik źródłowy i ustawienia kroku nie zmieniły się od ostatniego udanego uruchomienia. Domyślnie włączone; odznacz, aby zawsze importować ponownie.
