## Opis

Importuje pliki Apache Parquet z PlaidCloud Document. Parquet to kolumnowy format przechowywania szeroko stosowany w ekosystemie Hadoop i chmurowych platformach danych, oferujący wydajną kompresję i kodowanie dużych zestawów danych.

Import Parquet odbywa się strumieniowo przez pamięć tymczasową, bez wczytywania całego pliku do pamięci, dlatego bardzo duże pliki importują się bez wyczerpania pamięci. Typy danych pliku — liczby dziesiętne, daty i znaczniki czasu — są zachowywane w tabeli docelowej, a kolumny znaczników czasu zachowują pełną precyzję daty i pory dnia.
