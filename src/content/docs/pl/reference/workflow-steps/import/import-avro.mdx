## Unikatowe elementy konfiguracji

### Czas modyfikacji pliku

Odczytaj tylko pliki zmienione w danym przedziale czasu. **Zmodyfikowano po** odczytuje tylko pliki ostatnio zmodyfikowane po wpisanym czasie, a **Zmodyfikowano przed** tylko pliki ostatnio zmodyfikowane przed nim; ustaw jedno z pól lub oba. Wpisz czas w formacie `YYYY-MM-DDTHH:MM:SS`, na przykład `2026-10-01T00:00:00`. Czas jest w UTC, o ile nie podano strefy, na przykład `2026-10-01T00:00:00-05:00`. Czas może zawierać zmienną przepływu pracy, która jest odczytywana podczas uruchomienia kroku.
