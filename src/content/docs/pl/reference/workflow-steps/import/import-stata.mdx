## Opis


Importuje pliki danych Stata (.dta) do tabel projektu PlaidCloud. Przydatne dla organizacji używających Stata do analiz ekonometrycznych lub statystycznych, które przenoszą swoje robocze zestawy danych do PlaidCloud w celu dalszego przetwarzania.

Etykiety zmiennych są zachowywane, o ile format Stata je zawiera.
