## Opis



Krok **Notify Agent** uruchamia powiadomienie przez agenta PlaidLink — przydatne, gdy powiadomienia muszą być dostarczane przez systemy lokalne (wewnętrzne alarmowanie, własne webhooki, starszy SMTP), do których PlaidCloud nie ma bezpośredniego dostępu.

Agent odbiera ładunek powiadomienia i wysyła je lokalnie zgodnie ze swoją konfiguracją.
