## Opis



Krok **Notify Via Web Hook** wysyła powiadomienie, wykonując żądanie POST na adres URL webhooka — przydatne do uruchamiania niestandardowych działań w dalszej części procesu, alarmowania platform integracyjnych (Zapier, n8n, Make) lub sterowania botami Slack/Teams/Discord, które nie korzystają z natywnych konektorów.

Format ładunku i dowolne nagłówki niestandardowe są konfigurowalne. Za dalszy przebieg odpowiada usługa odbierająca.
