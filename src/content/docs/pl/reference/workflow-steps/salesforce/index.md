Kroki przepływu pracy, które odczytują dane Salesforce przez [połączenie Salesforce](/pl/guides/connections/salesforce/). Lista obiektów, lista pól i typ każdej kolumny pochodzą z metadanych samej organizacji, więc nie trzeba pisać zapytania ani zgadywać typów.

## Kroki

- [Salesforce: zapytanie o obiekt](/pl/reference/workflow-steps/salesforce/query-salesforce-object/) — wyodrębnij jeden standardowy lub niestandardowy obiekt do tabeli projektu przez Bulk API 2.0, z filtrowaniem w Salesforce.
