## Opis

Krok **DateTime Now (makro)** odtwarza makro pakietowe Alteryx *DateTime Now*. Działa w silniku przepływu pracy; wyniki makr pakietowych są przybliżeniem makra Alteryx.

## Parametry

- **Tabela wyjściowa** i ciąg **Format wyjściowy**.

## Format wyjściowy

Ciąg formatu używa tokenów narzędzia DateTime z Alteryx, a konwersja przenosi je bez zmian. Jeśli pozostawisz go pustym, używany jest domyślny format narzędzia, `day, dd Month, yyyy` — na przykład `Tuesday, 04 August, 2026`.

| Token | Wynik |
| --- | --- |
| `yyyy` / `yy` | Rok czterocyfrowy lub dwucyfrowy |
| `Month` / `Mon` | Pełna lub skrócona nazwa miesiąca |
| `MM` / `M` | Numer miesiąca, z zerem wiodącym lub bez |
| `day` / `dy` | Pełna lub skrócona nazwa dnia tygodnia |
| `dd` / `d` | Dzień miesiąca, z zerem wiodącym lub bez |
| `HH` / `H` | Godzina w zegarze 24-godzinnym, z zerem wiodącym lub bez |
| `hh` / `h` | Godzina w zegarze 12-godzinnym, z zerem wiodącym lub bez |
| `mm` | Minuty |
| `ss` | Sekundy |
| `tt` | AM lub PM |

W tokenach rozróżniana jest wielkość liter: `MM` oznacza miesiąc, a `mm` — minuty.
