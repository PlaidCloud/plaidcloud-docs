## Opis

Kończy przepływ pracy niepowodzeniem, gdy dwie tabele mają różną liczbę wierszy. Użyj go jako bramki jakości danych — na przykład aby potwierdzić, że przekształcona tabela zachowała każdy wiersz tabeli źródłowej lub że uzgodnienie nie pominęło ani nie zduplikowało rekordów. Gdy liczby wierszy są zgodne, przepływ pracy jest kontynuowany; gdy się różnią, krok zatrzymuje przepływ pracy i zapisuje komunikat o niepowodzeniu w dzienniku przepływu pracy.

## Konfiguracja

- **Tabela lewa** — pierwsza tabela, której wiersze są liczone.
- **Tabela prawa** — druga tabela, której wiersze są liczone.
- **Komunikat o niepowodzeniu** — komunikat wyświetlany, gdy liczby wierszy się różnią. Domyślnie „Liczby wierszy nie są zgodne”.

Użyj kroku [Zgłoś błąd przepływu pracy](/pl/reference/workflow-steps/workflow-control/raise-workflow-error/), gdy przepływ pracy ma zakończyć się niepowodzeniem przy dowolnym warunku, a nie tylko przy niezgodności liczby wierszy.
