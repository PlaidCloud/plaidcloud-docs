## Opis



Uruchamia SQL w zdalnej bazie danych przez agenta PlaidLink i sprowadza zbiór wyników z powrotem do PlaidCloud jako tabelę projektu. Używany, gdy baza źródłowa nie jest dostępna bezpośrednio z PlaidCloud (zapora, tylko VPN, lokalna), a mimo to chcesz z niej pobrać dane.

Agent uruchamia zapytanie lokalnie i przesyła wynik strumieniowo do PlaidCloud, dzięki czemu zarówno poświadczenia, jak i dane pozostają w Twojej sieci do momentu, gdy wynik jest potrzebny.
