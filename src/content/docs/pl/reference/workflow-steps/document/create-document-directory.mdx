## Opis


Tworzy nowy katalog w PlaidCloud Document.



## Gdzie utworzyć nowy folder


Najpierw wybierz odpowiednie konto z listy rozwijanej.



Następnie naciśnij przycisk **Przeglądaj**, aby wybrać katalog nadrzędny.



## Nazwa nowego folderu


Wpisz nazwę nowego katalogu.


<Aside>Jeśli katalog już istnieje, nie jest podejmowane żadne działanie.</Aside>
