## Opis


Zmienia nazwę istniejącego katalogu w PlaidCloud Document.



## Folder do zmiany nazwy


Najpierw wybierz odpowiednie konto z menu rozwijanego.



Następnie naciśnij przycisk **Przeglądaj**, aby wybrać katalog, którego nazwa ma zostać zmieniona.



## Nowa nazwa


Wpisz nową nazwę katalogu.


<Aside>Jeśli katalog o nowej nazwie już istnieje, nie jest podejmowane żadne działanie.</Aside>
