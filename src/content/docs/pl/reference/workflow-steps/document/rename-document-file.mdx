## Opis


Zmienia nazwę istniejącego pliku w PlaidCloud Document.



## Plik do zmiany nazwy


Najpierw wybierz odpowiednie konto z menu rozwijanego.



Następnie naciśnij przycisk **Przeglądaj**, aby wybrać plik, którego nazwa ma zostać zmieniona.

<Aside>Jeśli plik o nowej nazwie już istnieje, nie jest podejmowane żadne działanie.</Aside>


## Nowa nazwa


Wpisz nową nazwę pliku.
