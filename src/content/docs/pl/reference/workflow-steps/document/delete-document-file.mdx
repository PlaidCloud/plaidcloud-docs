## Opis


Usuwa istniejący plik z poziomu PlaidCloud Document.



## Plik do usunięcia


Najpierw wybierz odpowiednie konto z menu rozwijanego.


Następnie naciśnij przycisk **Przeglądaj**, aby wybrać plik do usunięcia.

<Aside>Jeśli plik nie istnieje (został już usunięty), nie jest podejmowane żadne działanie.</Aside>
