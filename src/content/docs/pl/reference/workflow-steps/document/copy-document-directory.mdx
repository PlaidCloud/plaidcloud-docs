## Opis


Kopiuje cały katalog w PlaidCloud Document.



## Kopiowany katalog


Najpierw wybierz odpowiednie konto z listy rozwijanej.



Następnie naciśnij przycisk **Przeglądaj**, aby wybrać katalog do skopiowania.



## Wybór miejsca docelowego


Najpierw wybierz odpowiednie konto z listy rozwijanej.



Następnie naciśnij przycisk **Przeglądaj**, aby wybrać miejsce docelowe skopiowanego katalogu. 



W razie potrzeby skopiowany katalog może otrzymać nową nazwę. Aby to zrobić, zaznacz pole **Rename the Copied Folder to:** i wpisz nową nazwę.


<Aside>Domyślnie wszystko, co już istnieje, jest nadpisywane. Uważaj, aby nie nadpisać czegoś przypadkowo.</Aside>
