## Opis

Importuje jedną jednostkę Oracle Fusion Cloud przez [połączenie Oracle Fusion](/pl/guides/connections/oracle-fusion/) do tabeli projektu, wywołując bezpośrednio punkty końcowe OData lub BI Publisher (BIP) w Fusion. Wybierz połączenie, typ jednostki i ewentualne filtry; krok pobiera pasujące rekordy i zapisuje je, bez konieczności tworzenia zapytania OData.

Przy pobieraniu zbyt dużym na wywołanie bezpośrednie użyj zamiast tego kroku [Import Fusion Bulk Extract](/pl/reference/workflow-steps/oracle-fusion/import-fusion-bulk-extract/).

## Konfiguracja

| Pole | Wymagane | Uwagi |
|---|---|---|
| Fusion Connection | Tak | Połączenie Oracle Fusion, przez które odbywa się odczyt. |
| Tabela docelowa | Tak | Tabela projektu, do której zapisywane są wyniki. Przy każdym uruchomieniu jest w całości nadpisywana. |
| Typ jednostki | Tak | Która jednostka ma zostać pobrana. Domyślnie `gl_balances`. Jedna z wartości: `gl_balances`, `journal_batches`. |
| Filters | Nie | Filtry zakresu (`ge`/`le`) dla pól daty, okresu księgowego i wartości liczbowych salda/kwoty oraz filtry równości dla pól dyskretnych (księga, waluta). Każda jednostka ogranicza filtry do pól, które Oracle Fusion potrafi faktycznie ocenić po stronie serwera — nieobsługiwane pole jest odrzucane, a nie po cichu pomijane. |

### Jednostki i pola filtrowalne

| Typ jednostki | Co pobiera | Pola filtrowalne |
|---|---|---|
| `gl_balances` | Salda kont księgi głównej | zakres okresów księgowych (`ge`/`le`), zakres kont, zakres kwoty salda (`ge`/`le`) |
| `journal_batches` | Nagłówki i status partii zapisów dziennika | zakres dat (`ge`/`le`), zakres okresów księgowych (`ge`/`le`) |

<Aside type="note">
Filtr zakresu jest przydatny nawet z jedną granicą — `accounting_date ge 2026-01-01` bez górnej granicy pobiera wszystko od tej daty wzwyż. Podaj obie granice, aby precyzyjnie zawęzić pobieranie.
</Aside>
