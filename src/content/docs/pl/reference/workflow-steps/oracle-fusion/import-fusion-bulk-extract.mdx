## Opis

Krok **Import Fusion Bulk Extract** importuje jednostkę Oracle Fusion Cloud przez [połączenie Oracle Fusion](/pl/guides/connections/oracle-fusion/) ścieżką zbiorczego wyodrębniania FBDI/BI Publisher od Oracle: PlaidCloud przesyła zadanie eksportu, odpytuje je do zakończenia, pobiera powstały plik i zapisuje go do tabeli projektu. Użyj tego kroku zamiast kroku [Import Fusion Entity](/pl/reference/workflow-steps/oracle-fusion/import-fusion-entity/), gdy pobranie jest zbyt duże lub zbyt wolne dla bezpośredniego wywołania OData/BIP.

## Konfiguracja

| Pole | Wymagane | Uwagi |
|---|---|---|
| Połączenie Fusion | Tak | Połączenie Oracle Fusion, przez które odbywa się odczyt. |
| Tabela docelowa | Tak | Tabela projektu, do której zapisywane są wyniki. Przy każdym uruchomieniu jest w całości nadpisywana. |
| Typ jednostki | Tak | Którą jednostkę wyodrębnić. Domyślnie `gl_balances`. Jedna z wartości: `gl_balances`, `journal_batches`. |
| Filtry | Nie | Ten sam zestaw filtrów co w kroku [Import Fusion Entity](/pl/reference/workflow-steps/oracle-fusion/import-fusion-entity/): filtry zakresów (`ge`/`le`) dla pól daty, okresu rozliczeniowego i numerycznych sald/kwot oraz filtry równości dla pól dyskretnych. Stosowane na poziomie zadania wyodrębniania. |

<Aside type="caution">
Ten krok czeka na asynchroniczne zadanie eksportu — spodziewaj się, że dla tej samej liczby wierszy potrwa znacznie dłużej niż [Import Fusion Entity](/pl/reference/workflow-steps/oracle-fusion/import-fusion-entity/). Używaj go tylko wtedy, gdy pobranie jest naprawdę zbyt duże dla bezpośredniego wywołania OData/BIP.
</Aside>
