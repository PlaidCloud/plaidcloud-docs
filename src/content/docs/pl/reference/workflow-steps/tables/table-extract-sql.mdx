## Opis

Wypełnia tabelę docelową na podstawie napisanego przez Ciebie zapytania SQL `SELECT`. O ile krok [Table Extract (krok)](/pl/reference/workflow-steps/tables/table-extract/) buduje zapytanie z zamapowanych kolumn i wyrażeń, ten krok przekazuje zapytanie bezpośrednio do hurtowni danych — w przypadkach, gdy SQL łatwiej wyrazić wprost niż składać w mapperze.

Sięgnij po niego, gdy potrzebujesz konstrukcji, której mapper nie obsługuje: rekurencyjnego CTE, funkcji okna nad partycją, której mapper nie potrafi opisać, lub zapytania do kilku tabel, które krok złączenia uczyniłby bardziej zawiłym.

## Unikatowe elementy konfiguracji

### Zapytanie SQL SELECT

Tekst zapytania. Sformatuj go jako czytelny, wielowierszowy SQL z wcięciami — jedna kolumna lub klauzula w wierszu — zamiast jednego długiego wiersza; krok zachowuje to, co napiszesz, a kolejna osoba otwierająca krok musi to przeczytać.

Zapytanie jest uruchamiane w lakehouse projektu, więc dostępne funkcje to zestaw [Lakehouse v1](/pl/reference/expressions/lakehouse-v1/) lub [v2](/pl/reference/expressions/lakehouse-v2/), zależnie od obszaru roboczego.
