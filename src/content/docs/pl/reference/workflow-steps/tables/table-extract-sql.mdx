## Opis

Wypełnia tabelę docelową na podstawie zapytania SQL `SELECT`, które piszesz samodzielnie. Podczas gdy [Table Extract](/pl/reference/workflow-steps/tables/table-extract/) buduje zapytanie z zmapowanych kolumn i wyrażeń, ten krok przekazuje zapytanie prosto do magazynu danych — w przypadkach, gdy SQL łatwiej wyrazić bezpośrednio niż składać w maperze.

Sięgnij po niego, gdy potrzebujesz konstrukcji, której maper nie obejmuje: rekurencyjnego CTE, funkcji okna po partycji, której maper nie potrafi opisać, lub zapytania do kilku tabel, które krok złączenia uczyniłby bardziej zawiłym.

## Unikatowe elementy konfiguracji

### Zapytanie SQL SELECT

Tekst zapytania. Sformatuj go jako czytelny, wielowierszowy SQL z wcięciami — jedna kolumna lub klauzula na wiersz — zamiast jednego długiego wiersza; krok zachowuje to, co napiszesz, a następna osoba, która go otworzy, będzie musiała to przeczytać.

Zapytanie jest wykonywane w lakehouse projektu, więc dostępne funkcje to zestaw [Lakehouse v1](/pl/reference/expressions/lakehouse-v1/) lub [v2](/pl/reference/expressions/lakehouse-v2/), zależnie od obszaru roboczego.

<SnippetCommonStepPreview />

W odróżnieniu od innych kroków SQL ten krok nie podstawia zmiennych, więc jego Podgląd również tego nie robi.
