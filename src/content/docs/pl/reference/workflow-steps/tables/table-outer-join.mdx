## Opis


Ten krok wykonuje złączenie zewnętrzne dwóch tabel danych i łączy je w jedną tabelę danych na podstawie podanych kluczy złączenia. Kontrolka **Typ złączenia** wybiera, które niedopasowane wiersze zachować — złączenie **Left join**, **Right join** lub **Full outer join**. Domyślnie jest to złączenie left (każdy wiersz z tabeli A, z kolumnami tabeli B uzupełnionymi tam, gdzie klucze pasują).


Więcej informacji o metodyce złączenia zewnętrznego znajdziesz tutaj: [Wikipedia SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## Kolumny nazwane w czasie wykonania

Zaznacz **Przenieś także kolumny nazwane w czasie wykonania**, aby przekazać bez zmian każdą kolumnę źródłową, której krok nie wymienia, w takiej postaci, w jakiej tabela ją ma w chwili uruchomienia kroku. Użyj tej opcji, gdy wcześniejszy krok tworzy kolumny, których nazwy zależą od danych (na przykład przestawienie), więc nie można ich wymienić podczas budowania kroku. Pozostaw ją wyłączoną, aby zapisać tylko wymienione kolumny.

### Typ złączenia

Wybierz, w jaki sposób zachowywane są niedopasowane wiersze:

- **Left join** — zachowaj każdy wiersz z tabeli A; kolumny tabeli B są uzupełniane tylko tam, gdzie klucze złączenia pasują. To ustawienie domyślne.
- **Right join** — zachowaj każdy wiersz z tabeli B; kolumny tabeli A są uzupełniane tylko tam, gdzie klucze złączenia pasują.
- **Full outer join** — zachowaj każdy wiersz z obu tabel, niezależnie od tego, czy ma dopasowanie po drugiej stronie.

## Przykłady


### Złączenie producentów samochodów z modelami


W tym przykładzie rozważ następujące źródłowe tabele danych. Pierwsza to lista producentów samochodów.




| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


Druga to lista modeli samochodów z identyfikatorem producenta. Zwróć uwagę, że kilka modeli nie ma producenta.




| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

Aby uzyskać listę modeli według producenta, warto wykonać złączenie po *Mfg_ID*. Dzięki wykorzystaniu koncepcji złączenia zewnętrznego wynik pokaże również te pozycje, które nie mają żadnych dopasowań.



Najpierw określ parametry **Table 1 Data Selection**. Wybrana jest źródłowa tabela danych i wyświetlone są wszystkie kolumny.



Następnie określ parametry **Table 2 Data Selection.** Ponownie wybrana jest źródłowa tabela danych i wyświetlone są wszystkie kolumny.



Na koniec warunki złączenia ustawia się na karcie **Table Output**. Dzięki przyciskowi **Zgadnij** Analyze poprawnie rozpoznaje kolumnę *Mfg_ID* jako **Join Key**. Ponieważ w tym przykładzie zachowywane są niedopasowane wiersze z obu tabel, ustaw **Typ złączenia** na **Full outer join**. Na końcu 


**Docelowe kolumny wyjściowe** są określane automatycznie za pomocą przycisku **Propaguj**. W efekcie uwzględniane są wszystkie kolumny ze wszystkich tabel, przy czym kolumny złączenia są oczywiście uwzględniane tylko raz. Zwróć uwagę, że kolumny są posortowane alfabetycznie, najpierw według *Manufacturer*, a następnie według *ModelName*.



Zgodnie z oczekiwaniami wynik końcowy zawiera wszystkie wiersze z obu tabel, niezależnie od tego, czy miały dopasowanie w obu tabelach. Dlatego tym razem *Porsche* rzeczywiście się pojawia, mimo że nie ma żadnych modeli. Dodatkowo w wynikach znalazły się *Batmobile*, *Lightning McQueen* i *Optimus Prime*, choć żaden z nich nie ma producenta. Poza tym, kto mógłby im odmówić?
