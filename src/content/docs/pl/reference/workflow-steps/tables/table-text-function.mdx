## Opis

Krok **Tabela: funkcja tekstowa** stosuje funkcję tekstową do kolumn każdego wiersza, które ta funkcja odczytuje, i zapisuje wynik w nowej kolumnie kopii tabeli źródłowej. NULL w dowolnej kolumnie odczytywanej przez funkcję daje NULL.

## Źródło i opcje

- **Tabela źródłowa** i **Tabela wyjściowa** — tabela do odczytu i tabela do zapisu.
- **Funkcja** — funkcja do zastosowania. Formularz oferuje funkcje z dwóch poniższych tabel i pokazuje jedno pole kolumny, opisane zgodnie z jego rolą, dla każdego argumentu odczytywanego przez wybraną funkcję.
- **Kolumny argumentów** — kolumny odczytywane przez funkcję, w kolejności podanej w tabeli. Każda jest wymagana.
- **Kolumna wyjściowa** — nazwa kolumny dodawanej do kopii tabeli źródłowej.

| Funkcja | Argumenty | Wynik |
| --- | --- | --- |
| `levenshtein` | Pierwsza kolumna, Druga kolumna | Odległość edycyjna z uwzględnieniem wielkości liter, jako liczba całkowita |
| `soundex` | Tekst | Tekst |
| `json_format` | JSON | Tekst JSON z wcięciami |
| `json_field` | JSON, Ścieżka | Tekst |
| `json_set_text`, `json_set_number`, `json_set_boolean` | JSON, Ścieżka, Wartość | Tekst JSON z ustawioną wartością |
| `regex_match` | Tekst, Wzorzec, Uwzględnij wielkość liter | Prawda lub fałsz |
| `regex_search` | Tekst, Wzorzec, Wystąpienie, Uwzględnij wielkość liter | Pozycja, jako liczba całkowita |
| `regex_extract` | Tekst, Wzorzec, Wystąpienie, Uwzględnij wielkość liter | Tekst |
| `regex_replace` | Tekst, Wzorzec, Zamiennik, Uwzględnij wielkość liter | Tekst |
| `to_text_number` | Liczba, Wzorzec | Tekst: liczba zapisana wzorcem w stylu DecimalFormat |
| `to_text_datetime` | Data/godzina, Wzorzec | Tekst: data zapisana wzorcem daty i godziny |
| `parse_date` | Tekst, Wzorzec | Tekst odczytany jako data |
| `parse_datetime` | Tekst, Wzorzec | Tekst odczytany jako data i godzina |

Przekonwertowana analiza Savant może zawierać dowolną z tych funkcji i działają one tak samo. Funkcja, której formularz nie oferuje, pokazuje zapisane kolumny i jest zachowywana dokładnie tak, jak zapisano.

### Więcej funkcji

Lista **Funkcja** oferuje także poniższe funkcje. Korzystają z nich również przekonwertowane przepływy pracy KNIME.

| Funkcja | Argumenty | Wynik |
| --- | --- | --- |
| `damerau_levenshtein`, `hamming`, `lcs` | Pierwsza kolumna, Druga kolumna | Odpowiadająca odległość edycyjna, jako liczba całkowita |
| `jaro`, `jaro_winkler` | Pierwsza kolumna, Druga kolumna | 1 minus podobieństwo, 0 dla identycznych tekstów |
| `ngram_distance` | Pierwsza kolumna, Druga kolumna | 1 minus współczynnik Dice'a dla bigramów znaków |
| `jaccard_tokens`, `dice_tokens`, `cosine_tokens` | Pierwsza kolumna, Druga kolumna | 1 minus podobieństwo zbiorów słów obu tekstów, 1, gdy któryś z nich nie ma słów |
| `java_compare` | Pierwsza kolumna, Druga kolumna | Różnica pierwszych różniących się znaków, tak jak daje ją `compareTo` w Javie, jako liczba całkowita |
| `java_regex` | Tekst, Wzorzec, Zamiennik *(tylko w trybie replace)* | Wyrażenie regularne Javy odczytane z kolumny: prawda lub fałsz w trybach `matches` i `find`, tekst w trybach `extract` i `replace` |
| `knime_count` | Tekst, Szukany tekst | Ile razy występuje szukany tekst, jako liczba całkowita |
| `knime_binomial`, `long_pow` | Dwie liczby | Współczynnik dwumianowy lub potęga całkowita, w 64-bitowej arytmetyce z zawijaniem |
| `encode`, `decode` | Tekst | Tekst jako bajty base64 w danym zestawie znaków i z powrotem |
| `url_encode` | Tekst | Tekst zakodowany procentowo jako wartość formularza, spacja zapisana jako `+` |
| `list_sort_numeric` | Tekst | Lista przechowywana jako tekst rozdzielany separatorem, posortowana według wartości liczbowej |
| `geojson_to_wkt` | JSON, Ścieżka | Geometria GeoJSON pod ścieżką, taką jak `$.a[0]`, lub `$` dla samego tekstu, jako WKT |
| `json_patch_apply` | JSON | Dokument z zastosowaną łatką JSON Patch lub Merge Patch |
| `json_diff` | Pierwszy JSON, Drugi JSON | Łatka JSON Patch, która zamienia pierwszy dokument w drugi |
| `json_schema_check` | JSON | Błędy dokumentu względem schematu JSON, jako JSON; NULL, gdy ich nie ma |
| `json_normalize` | JSON | Dokument jako znormalizowany tekst JSON |
| `json_to_xml`, `xml_to_json` | Dokument | Dokument przekonwertowany na XML lub na JSON |
| `xml_well_formed` | XML | Tekst, gdy jest poprawnie sformułowanym XML, w przeciwnym razie NULL |
| `xslt` | XML, Arkusz stylów | Dokument przekształcony arkuszem stylów XSLT |
| `message_text`, `message_tool_calls` | JSON | Tekst komunikatu AI lub jego wywołania narzędzi jako JSON |

Opcje funkcji ustaw w `function_options`:

- `java_regex` — `mode`: `matches` (domyślnie, cały tekst), `find` (gdziekolwiek), `extract` (grupa `group` pierwszego dopasowania, domyślnie 0) lub `replace` (każde dopasowanie); `flags` `i` ignoruje wielkość liter.
- `knime_count` — `modifiers`: `i` ignoruje wielkość liter, `w` liczy całe słowa między białymi znakami.
- `encode` i `decode` — `charset`, nazwa zestawu znaków Javy; domyślnie UTF-8.
- `json_patch_apply` — `patch`, tablica JSON Patch lub obiekt Merge Patch; `merge` ma wartość true dla Merge Patch; `keep` zachowuje dokument, gdy test łatki się nie powiedzie.
- `json_schema_check` — `schema`; `fail` zatrzymuje krok przy pierwszym błędzie zamiast go zwracać.
- `json_normalize` — `comments` zezwala na komentarze `/* */` i `//`; `fail` (domyślnie true) zatrzymuje krok przy tekście, który nie jest JSON-em, a false daje NULL.
- `json_to_xml` — `root`, `item`, `typed`, `parent_keys`, `namespace`, `text_key` i `text_key_enabled`. `xml_to_json` — `text_key`, `comments` i `pis`.
- `list_sort_numeric` — `separator`; `empty`, tekst zapisywany dla listy bez elementów; oraz `missing`, tekst brakującego elementu, sortowanego na końcu.

Domyślnie krok odczytuje wszystkie kolumny źródła i zapisuje wszystkie kolumny źródła, a po nich kolumnę wyjściową. Ustaw `source_columns`, aby odczytać tylko wybrane kolumny, oraz `target_columns` (każda jako `{source, target, dtype}`), aby wybrać i uporządkować zapisywane kolumny. Kolumna docelowa o nazwie takiej jak kolumna wyjściowa zajmuje jej miejsce, z podanym typem danych.
