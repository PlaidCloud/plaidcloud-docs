## Opis


Wyczyść zawartość istniejącej tabeli danych bez usuwania samej tabeli danych. Efektem końcowym jest tabela danych z 0 wierszy.



<SnippetCommonTableSelectionDynamic />

Z opcją **Tabele pasujące do wyszukiwania** krok nie zostanie zapisany z pustym polem **Szukany tekst**, gdy **Ścieżka wyszukiwania** wskazuje najwyższy poziom projektu (`/`), ponieważ wyczyściłoby to każdą tabelę w projekcie. Wpisz tekst do dopasowania lub wybierz folder.
