## Opis


Ten krok wykonuje złączenie wewnętrzne dwóch tabel danych i łączy je w jedną tabelę danych na podstawie podanych kluczy złączenia.


Więcej informacji o metodyce złączenia wewnętrznego znajdziesz tutaj: [Wikipedia SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## Kolumny nazwane w czasie wykonania

Zaznacz **Przenieś także kolumny nazwane w czasie wykonania**, aby przekazać bez zmian każdą kolumnę źródłową, której krok nie wymienia, w takiej postaci, w jakiej tabela ją ma w chwili uruchomienia kroku. Użyj tej opcji, gdy wcześniejszy krok tworzy kolumny, których nazwy zależą od danych (na przykład przestawienie), więc nie można ich wymienić podczas budowania kroku. Pozostaw ją wyłączoną, aby zapisać tylko wymienione kolumny.

## Przykłady


### Złączenie producentów samochodów z modelami


W tym przykładzie rozważ następujące źródłowe tabele danych. Pierwsza to lista producentów samochodów.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

Druga to lista modeli samochodów z identyfikatorem producenta. Zwróć uwagę, że kilka modeli nie ma producenta.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

Aby uzyskać listę modeli według producenta, warto wykonać złączenie po *Mfg_ID*.


Najpierw określ parametry **Table 1 Data Selection**. Wybrana jest źródłowa tabela danych i wyświetlone są wszystkie kolumny.



Następnie określ parametry **Table 2 Data Selection**. Ponownie wybrana jest źródłowa tabela danych i wyświetlone są wszystkie kolumny.



Na koniec warunki złączenia ustawia się na karcie **Table Output**. Dzięki przyciskowi **Zgadnij** Analyze poprawnie rozpoznaje kolumnę *Mfg_ID* jako **Join Key**. Na końcu 


**Docelowe kolumny wyjściowe** są określane automatycznie za pomocą przycisku **Propaguj**. W efekcie uwzględniane są wszystkie kolumny ze wszystkich tabel, a każda kolumna złączenia występuje tylko raz. Zwróć uwagę, że kolumny są posortowane alfabetycznie, najpierw według *Manufacturer*, a następnie według *ModelName*.



Zgodnie z oczekiwaniami wynik końcowy zawiera tylko wartości, które miały dopasowanie w obu tabelach. Dlatego *Porsche* się nie pojawia, ponieważ nie miał żadnych modeli. Podobnie *Batmobile* nie miał producenta (był to egzemplarz wykonany na zamówienie), więc nie został uwzględniony.
