## Opis


Służy, jak można się było spodziewać, do wykonania złączenia wewnętrznego dwóch tabel danych i połączenia ich w jedną tabelę danych na podstawie określonych kluczy złączenia.


Więcej szczegółów o metodyce złączenia wewnętrznego znajdziesz tutaj: [Wikipedia — złączenie wewnętrzne w SQL](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## Kolumny nazwane w czasie wykonania

Zaznacz **Przenieś także kolumny nazwane w czasie wykonania**, aby przepuścić bez zmian każdą kolumnę źródłową, której krok nie wymienia, w takiej postaci, jaką ma tabela w chwili uruchomienia kroku. Użyj tego, gdy wcześniejszy krok tworzy kolumny, których nazwy zależą od danych, na przykład przestawienie, więc nie można ich wymienić przy budowaniu kroku. Pozostaw wyłączone, aby zapisywać tylko wymienione kolumny.

## Przykłady


### Złączenie producentów samochodów z modelami


W tym przykładzie rozważ poniższe źródłowe tabele danych. Pierwsza to lista producentów samochodów.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

Następna to lista modeli samochodów z identyfikatorem producenta. Zwróć uwagę, że kilka modeli nie ma producenta.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

Aby uzyskać listę modeli według producenta, sensowne jest złączenie po *Mfg_ID*.


Najpierw określ parametry dla **Table 1 Data Selection**. Wybrana jest źródłowa tabela danych i wymienione są wszystkie kolumny.



Następnie określ parametry dla **Table 2 Data Selection**. Ponownie wybrana jest źródłowa tabela danych i wymienione są wszystkie kolumny.



Na koniec warunki złączenia ustawia się na karcie **Dane wyjściowe**. Za pomocą przycisku **Zgadnij** Analyze poprawnie rozpoznaje kolumnę *Mfg_ID* do użycia jako **Join Key**. Następnie


**Docelowe kolumny wyjściowe** są określane automatycznie za pomocą przycisku **Propaguj**. Obejmuje to w praktyce wszystkie kolumny ze wszystkich tabel, przy czym wszystkie kolumny złączenia są uwzględnione tylko raz. Zwróć uwagę, że kolumny są posortowane alfabetycznie, najpierw według *Manufacturer*, a następnie według *ModelName*.



Zgodnie z oczekiwaniami wynik końcowy zawiera tylko wartości, które miały dopasowanie w obu tabelach. Dlatego *Porsche* się nie pojawia, ponieważ nie miał żadnych modeli. Podobnie


*Batmobile* nie miał producenta (był to egzemplarz wykonany na zamówienie), więc nie został uwzględniony.
