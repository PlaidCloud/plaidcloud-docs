## Opis

Usuwa tabelę z projektu w całości — zarówno definicję tabeli, jak i wszystkie jej dane. Operacja jest destrukcyjna i nieodwracalna: po uruchomieniu przepływu pracy tabeli już nie ma.

Użyj tego kroku, gdy tabele pośrednie w przepływie pracy nie są już potrzebne w dalszych krokach (na przykład w ramach porządkowania po wieloetapowej transformacji). Aby tylko tymczasowo opróżnić tabelę bez jej usuwania, użyj zamiast tego kroku [Table Clear (krok)](/pl/reference/workflow-steps/tables/table-clear/).
