## Opis


Utwórz kopię tabeli danych.




<SnippetCommonTableSourceAndTarget />



Podczas kopiowania Analyze najpierw sprawdza, czy tabela docelowa już istnieje. Jeśli istnieje, nie zostanie wykonana żadna akcja, chyba że zaznaczono pole wyboru **Allow Overwriting Existing Table**. W takim przypadku tabela docelowa zostanie nadpisana.
