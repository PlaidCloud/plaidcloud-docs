Kroki przepływu pracy odczytujące dane z **Anaplan** przez [połączenie Anaplan](/pl/guides/connections/anaplan/): zapisany widok ścieżką żądań odczytu dużych wolumenów, istniejącą akcję eksportu przez Bulk API lub jedną albo więcej list ładowanych do wymiaru PlaidCloud. Anaplan jest obsługiwany **bezpośrednio z chmury** przez jego Integration API — dla tych kroków nie istnieje ścieżka przez agenta lokalnego, a żaden z nich nigdy nie zapisuje danych z powrotem do Anaplan.

## Kroki

- [Anaplan: odczytaj widok](/pl/reference/workflow-steps/anaplan/anaplan-read-view/) — odczytaj zapisany widok dokładnie tak, jak został zapisany. Bezpośrednio z chmury.
- [Anaplan: odczytaj eksport](/pl/reference/workflow-steps/anaplan/anaplan-read-export/) — uruchom istniejącą akcję eksportu i zapisz jej plik. Bezpośrednio z chmury.
- [Anaplan: odczytaj listę](/pl/reference/workflow-steps/anaplan/anaplan-read-list/) — odczytaj jedną lub więcej list do wymiaru PlaidCloud. Bezpośrednio z chmury.
