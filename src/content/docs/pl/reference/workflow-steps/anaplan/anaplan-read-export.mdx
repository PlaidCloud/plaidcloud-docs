## Opis

Uruchamia **istniejącą** akcję eksportu Anaplan przez [Połączenie Anaplan](/pl/guides/connections/anaplan/) i zapisuje wytworzony przez nią plik jako tabelę. Akcja eksportu musi już istnieć w modelu — API nie może jej utworzyć — a ten krok nie może zawęzić tego, co ona emituje: dokładnie to, co akcja ma skonfigurowane do eksportu w Anaplan, trafia do tabeli.

Ten krok jest widoczny w menu kroków w sekcji **Anaplan**.

Krok łączy się z Anaplan **bezpośrednio z chmury** przez jego Bulk API — nie ma ścieżki przez agenta lokalnego.

<Aside type="tip">
Ten konektor jest tylko do odczytu i uwierzytelnia się za pomocą poświadczeń Basic (nazwa użytkownika i hasło) lub certyfikatu CA — zobacz [Uwierzytelnianie](/pl/guides/connections/anaplan/#uwierzytelnianie). Budżet żądań Anaplan jest współdzielony w całej dzierżawie, więc rozłóż w czasie harmonogram tego kroku względem innych przepływów pracy Anaplan — zobacz [Uwagi o harmonogramie](/pl/guides/connections/anaplan/#kwestie-związane-z-harmonogramem).
</Aside>

## Konfiguracja

### Źródło i cel

| Pole | Wymagane | Uwagi |
|---|---|---|
| Połączenie Anaplan | Tak | [Połączenie Anaplan](/pl/guides/connections/anaplan/), przez które odbywa się odczyt. |
| Środowisko | Tak | Środowisko połączenia. |
| Obszar roboczy | Nie | Zastępuje identyfikator obszaru roboczego zapisany w połączeniu. Wykrywany na żywo z połączenia lub wpisywany ręcznie. |
| Model | Nie | Zastępuje identyfikator modelu zapisany w połączeniu. Wykrywany na żywo po wybraniu obszaru roboczego lub wpisywany ręcznie. |
| Eksport | Tak | Akcja eksportu Anaplan do uruchomienia. Wykrywana na żywo po wybraniu obszaru roboczego i modelu lub wpisywana ręcznie. Jej wyboru nie można tutaj zastąpić — działa dokładnie tak, jak skonfigurowano ją w Anaplan. |
| Liczba prób sprawdzania | Tak | Domyślnie 120. Ile razy sprawdzać zadanie eksportu pod kątem ukończenia, zanim krok odmówi wykonania, podając identyfikator zadania. Nigdy nie wysyła ponownie po cichu — Anaplan nie dokumentuje, jak odróżnić dwa pliki wytworzone przez tę samą akcję eksportu, więc ponowne wysłanie grozi powiązaniem niewłaściwego pliku z tym uruchomieniem. |
| Interwał sprawdzania (sekundy) | Tak | Domyślnie 5. Liczba sekund oczekiwania między kolejnymi sprawdzeniami. |
| Tabela docelowa | Tak | Tabela, do której trafia eksport. Każda kolumna trafia jako tekst. |

## Czego ten krok nie może odwzorować

| Ograniczenie | Co oznacza |
|---|---|
| Wymaga istniejącej akcji eksportu | API nie może utworzyć akcji eksportu, a żądanie wysyłane przez ten krok nie zawiera żadnego punktu widzenia, wyboru elementów ani parametru wycinka — dokładnie to, co akcja ma skonfigurowane do emitowania w Anaplan, trafia do tabeli. Aby zmienić to, co wytwarza, utwórz lub edytuj akcję eksportu w Anaplan. |
| Każda kolumna trafia jako tekst | Pole, które Anaplan publikuje, aby zadeklarować typy kolumn eksportu, jest wewnętrznie niespójne w opublikowanej dokumentacji samego Anaplan, więc nie można mu ufać przy poprawnym typowaniu kolumny — żadna kolumna nie jest typowana na jego podstawie, celowo i na stałe. Rzutuj potrzebne kolumny w kolejnym kroku. |
| Liczby żądane w formacie amerykańskim; kolumna nadal z separatorami grup jest oflagowana, a nie naprawiana | Zadanie eksportu jest wysyłane z żądaniem amerykańskiego formatowania liczb. Kolumna, która nadal wraca z separatorami tysięcy, oznacza, że eksport nie jest renderowany w tym formacie — krok zapisuje wartość bez zmian, jako tekst, i ostrzega, podając nazwę kolumny i przykładową wartość, zamiast zgadywać, który znak jest separatorem dziesiętnym. Sprawdź taką kolumnę przed rzutowaniem w kolejnym kroku: europejskie `1.234.567` odczytane jako `1.234` jest tysiąc razy za małe. |
| Odmowa zamiast zapisu niewiarygodnego wyciągu | Krok niczego nie zapisuje, zamiast zapisać tabelę, która wygląda na kompletną, a nie jest, gdy: zadanie eksportu kończy się niepowodzeniem lub nie zgłasza sukcesu w Anaplan; zadanie zostało anulowane; zadanie nadal trwa po wyczerpaniu budżetu sprawdzeń kroku; wytworzony plik w ogóle nie zawiera danych; wytworzonego pliku nie można powiązać z eksportem, który go wytworzył; lub liczba odczytanych wierszy nie zgadza się z liczbą wierszy zgłaszaną przez sam Anaplan dla eksportu. |
| Tylko do odczytu | Nic nigdy nie jest zapisywane z powrotem do Anaplan. |
