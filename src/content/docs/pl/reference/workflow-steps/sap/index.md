## Kroki doraźnego wyodrębniania

Trzy kroki przeszukują SAP, wyświetlają podgląd i planują wyodrębnienie, a następnie zapisują wynik w tabeli. Jeden odczytuje tabelę, drugi uruchamia transakcję lub raport, a trzeci uruchamia zapisane zapytanie SAP Query. Zobacz [Doraźne wyodrębnianie z SAP ECC / S/4HANA](/pl/guides/connections/sap-adhoc-extract/).
