## Opis


Usuwa modele SAP Profitability and Cost Management (PCM) pasujące do kryteriów wyszukiwania. Usuwanie modeli za pomocą tej transformacji pozwala usunąć wiele modeli bez konieczności monitorowania procesu.



## Nasze kwalifikacje


PlaidCloud jest oficjalnym partnerem SAP i preferowanym dostawcą usług związanych z projektowaniem i wdrażaniem modeli SAP PCM.







## Przykłady


Wybierz „Agent do użycia” z listy rozwijanej. Wybierz żądaną „Model Search Method”. W tym przykładzie wybrano „Exact Match”. Wpisz „Model Search Text” (czego szukasz) w sekcji „Model Name Information” i zdecyduj, czy wyszukiwanie uwzględnia wielkość liter (jeśli tak, zaznacz pole wyboru). Na koniec zaznacz „Wait for Deletion to Complete” i kliknij „Save and Run Step”.
