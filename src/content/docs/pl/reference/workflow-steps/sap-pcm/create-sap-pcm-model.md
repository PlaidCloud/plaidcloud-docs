## Opis



Tworzy nowy, pusty model SAP Profitability and Cost Management (PCM) na serwerze PCM. Przydatne do programowego udostępniania modeli — na przykład gdy nowa jednostka biznesowa lub scenariusz potrzebuje własnego modelu, a przepływ pracy może go utworzyć zamiast czekać na ręczną konfigurację.

Większość użytkowników kopiuje istniejący szablon modelu za pomocą [Copy SAP PCM Model](/pl/reference/workflow-steps/sap-pcm/copy-sap-pcm-model/), zamiast zaczynać od pustego.


## Nasze kwalifikacje


PlaidCloud jest oficjalnym partnerem SAP i preferowanym dostawcą usług związanych z projektowaniem i wdrażaniem modeli SAP PCM.








## Przykłady


Wybierz z listy rozwijanej Agent do użycia. Wpisz „Model Name” i wybierz z listy rozwijanej „Model type” (oba znajdują się w sekcji „Informacje o modelu”). Zaznacz pole wyboru „Wait for Copy to Complete”, a następnie kliknij „Save and Run Step”.
