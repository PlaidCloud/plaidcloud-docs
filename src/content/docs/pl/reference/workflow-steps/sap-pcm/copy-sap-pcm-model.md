### Opis


Kopiuje model SAP Profitability and Cost Management (PCM).


### Nasze kwalifikacje


PlaidCloud jest oficjalnym partnerem SAP i preferowanym dostawcą usług związanych z projektowaniem i wdrażaniem modeli SAP PCM.


### Przykład


Wybierz z listy rozwijanej Agent do użycia, wpisz „From Model Name” i „To Model Name” w polu „Informacje o modelu”, zaznacz pole wyboru „Wait for Copy to Complete”, a następnie kliknij „Save and Run Step”.
