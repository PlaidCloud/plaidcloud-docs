### Opis


Kopiuje wersję modelu SAP Profitability and Cost Management (PCM) w obrębie tego samego modelu.


### Nasze kwalifikacje


PlaidCloud jest oficjalnym partnerem SAP i preferowanym dostawcą usług związanych z projektowaniem i wdrażaniem modeli SAP PCM.


### Przykłady


Wybierz z listy rozwijanej Agent do użycia, wpisz „Model Name”, „Origin Period Name” i „Destination Period Name” w polu „Informacje o modelu”. Zaznacz pole wyboru „Wait for Copy to Complete”, a następnie kliknij „Save and Run Step”.
