## Opis



Uruchamia zadanie w konsoli SAP PCM na zdalnym serwerze PCM — zwykle używane do zadań administracyjnych lub wsadowych, które PCM udostępnia przez interfejs konsoli, a nie przez API obliczeń modelu.

Przykładowe zastosowania to operacje archiwizacji, uruchomienia hyperloadera lub procedury konserwacyjne specyficzne dla dostawcy. Dokładne zadanie i parametry zależą od wdrożenia PCM.


## Nasze kwalifikacje


PlaidCloud jest oficjalnym partnerem SAP i preferowanym dostawcą usług związanych z projektowaniem i wdrażaniem modeli SAP PCM.








## Przykłady


Wybierz z listy rozwijanej Agent do użycia, wpisz ścieżkę pliku konsoli w polu „Console File Path”, zaznacz pole wyboru „Wait for Console Job to Complete” (jeśli chcesz), a następnie kliknij „Save and Run Step”.
