## Opis

**Render** składa elementy raportu w dokument PDF. Jest odpowiednikiem właściwego narzędzia Alteryx *Reporting* / *Portfolio Composer* i działa w silniku przepływów pracy (reportlab / matplotlib); renderer jest przybliżeniem wyniku Alteryx.

## Źródło i opcje

- **Tabela źródłowa** — dane zasilające ten element raportu.
- **Tabela wyjściowa** — tabela, do której zapisywany jest wyrenderowany fragment.
- **Kolejność raportów** — kolejność tego elementu w złożonym raporcie.
- **Width / Height** — rozmiar osadzonego obrazu w pikselach.
- **Plik wyjściowy** — ścieżka w magazynie dokumentów dla wyrenderowanego pliku.

- **Format wyjściowy** (`output_format`) — **PDF** (`pdf`, domyślnie) lub **Strona HTML (samodzielna)** (`html`), aby zapisać raport jako jedną samodzielną stronę HTML. Nadaj nazwie pliku rozszerzenie `.html`.
- **Druga tabela źródłowa** (`source_b`) — druga tabela wejściowa, dzięki której render składa elementy z obu wejść.

## Kolumny

Karta **Kolumny** mapuje kolumny źródłowe dostępne dla elementu raportu.
