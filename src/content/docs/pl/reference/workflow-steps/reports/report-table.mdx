## Opis

**Tabela** danych źródłowych dla złożonego raportu. Jest odpowiednikiem właściwego narzędzia Alteryx *Reporting* / *Portfolio Composer* i działa w silniku przepływów pracy (reportlab / matplotlib); renderer jest przybliżeniem wyniku Alteryx.

## Źródło i opcje

- **Tabela źródłowa** — dane zasilające ten element raportu.
- **Tabela wyjściowa** — tabela, do której zapisywany jest wyrenderowany fragment.
- **Kolejność raportów** — kolejność tego elementu w złożonym raporcie.
- **Kolumny** — które kolumny źródłowe uwzględnić (puste = wszystkie).

## Kolumny

Karta **Kolumny** mapuje kolumny źródłowe dostępne dla elementu raportu.
