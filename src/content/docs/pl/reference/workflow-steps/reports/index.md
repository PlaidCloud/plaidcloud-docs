## Elementy składowe raportu

Skonwertowane przepływy pracy raportowania Alteryx składają dokument z tych kroków. Chart,
Image, Map, Table i Text renderują po jednym elemencie; Layout, Visual Layout i
Overlay rozmieszczają elementy; Render zapisuje złożony wynik do pliku PDF.
