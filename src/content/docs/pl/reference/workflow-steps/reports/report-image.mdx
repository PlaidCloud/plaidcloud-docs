## Opis

**Obraz** umieszczony w złożonym raporcie. Jest odpowiednikiem właściwego narzędzia Alteryx *Reporting* / *Portfolio Composer* i działa w silniku przepływów pracy (reportlab / matplotlib); renderer jest przybliżeniem wyniku Alteryx.

## Źródło i opcje

- **Tabela źródłowa** — dane zasilające ten element raportu.
- **Tabela wyjściowa** — tabela, do której zapisywany jest wyrenderowany fragment.
- **Kolejność raportów** — kolejność tego elementu w złożonym raporcie.
- **Tryb obrazu** — Static (obraz base64 osadzony w treści) lub Field (ścieżka pliku dla każdego wiersza).
- **Base64 image** — osadzone dane obrazu dla trybu Static.

## Kolumny

Karta **Kolumny** mapuje kolumny źródłowe dostępne dla elementu raportu.
