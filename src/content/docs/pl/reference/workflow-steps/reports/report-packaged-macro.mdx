## Opis

**Makro pakietowe** renderuje pakiet raportu zaimportowany z *pakietowego makra raportu* Alteryx. Jest to pełnoprawny krok raportu: dołączona definicja makra jest automatycznie przenoszona razem z krokiem, a element jest renderowany tą samą ścieżką artefaktów raportu co pozostałe kroki raportów.

## Źródło i opcje

- **Tabela źródłowa** — dane zasilające ten element raportu.
- **Tabela docelowa** — tabela, do której zapisywany jest wyrenderowany wynik.
- **Kolejność raportów** — pozycja tego elementu w złożonym raporcie.
