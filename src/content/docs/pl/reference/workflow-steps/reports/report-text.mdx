## Opis

Blok **tekstu** dla złożonego raportu. Jest odpowiednikiem właściwego narzędzia Alteryx *Reporting* / *Portfolio Composer* i działa w silniku przepływów pracy (reportlab / matplotlib); renderer jest przybliżeniem wyniku Alteryx.

## Źródło i opcje

- **Tabela źródłowa** — dane zasilające ten element raportu.
- **Tabela wyjściowa** — tabela, do której zapisywany jest wyrenderowany fragment.
- **Kolejność raportów** — kolejność tego elementu w złożonym raporcie.
- **Treść tekstowa** — tekst do wyrenderowania.

## Odwoływanie się do kolumny w tekście

Treść tekstowa może zawierać nazwę kolumny w nawiasach kwadratowych, a w jej miejsce
zostanie wydrukowana wartość — `[Year] Results` drukuje `2026 Results`. Skonwertowany
Report Text z Alteryx zachowuje wszelkie odwołania do pól, które jego tekst już zawierał,
w tym sformatowaną postać, którą Alteryx zapisuje jako `[Year:A]`.

Jeden fragment tekstu jest składany dla całej tabeli źródłowej, więc wskazana kolumna
musi zawierać tę samą wartość w każdym odczytywanym wierszu. Jeśli kolumna zawiera
więcej niż jedną wartość, podsumuj ją wcześniej w przepływie — blok tekstu nie może
wydrukować kilku wartości naraz.

`[CurrentYear]` drukuje rok, w którym raport jest renderowany, i nie wymaga kolumny.

Kilka reguł sprawia, że zwykły tekst można pisać bezpiecznie:

- Nazwa pasująca do kolumny jest zawsze zastępowana.
- Nazwa niepasująca do żadnej kolumny zatrzymuje krok i informuje o tym, ale tylko
  tam, gdzie nie mogłaby być niczym innym niż odwołaniem — format zapisany
  tuż przy dwukropku, jak w `[Quarter:A]`.
- Tekst w nawiasach jest drukowany tak, jak go napisano. `[12:30]` pozostaje godziną,
  a `[Note: continued]` pozostaje dopowiedzeniem, ponieważ sama liczba nie jest nazwą
  kolumny, a w zwykłym tekście po dwukropku stawia się spację.

Sam format nie jest stosowany — wartość jest drukowana tak, jak ją przechowuje kolumna,
więc jeśli potrzebuje separatorów tysięcy lub układu daty, sformatuj kolumnę wcześniej w przepływie.

## Kolumny

Karta **Kolumny** mapuje kolumny źródłowe dostępne dla elementu raportu.
