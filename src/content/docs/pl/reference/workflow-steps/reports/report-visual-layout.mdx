## Opis

**Układ wizualny**, który rozmieszcza elementy raportu. Jest odpowiednikiem właściwego narzędzia Alteryx *Reporting* / *Portfolio Composer* i działa w silniku przepływów pracy (reportlab / matplotlib); renderer jest przybliżeniem wyniku Alteryx.

## Źródło i opcje

- **Tabela źródłowa** — dane zasilające ten element raportu.
- **Tabela wyjściowa** — tabela, do której zapisywany jest wyrenderowany fragment.
- **Kolejność raportów** — kolejność tego elementu w złożonym raporcie.
- **Układ** — pionowo (jeden pod drugim) lub poziomo (obok siebie).

## Kolumny

Karta **Kolumny** mapuje kolumny źródłowe dostępne dla elementu raportu.
