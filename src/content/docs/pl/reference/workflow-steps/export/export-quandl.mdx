## Opis



Wysyła tabelę PlaidCloud do bazy danych Quandl (NASDAQ Data Link). Przeznaczone głównie dla organizacji, które utrzymują opublikowane zbiory danych w Quandl i chcą je odświeżać z przepływu pracy PlaidCloud.

Wymaga danych uwierzytelniających API Quandl oraz docelowej bazy danych skonfigurowanej z dostępem do zapisu po stronie Quandl.


## Źródło i cel


Określ następujące parametry:


* **Tabela źródłowa**: tabela danych Analyze do wyeksportowania
* **Quandl Connection**: Dostęp do zbiorów danych Quandl wymaga konta użytkownika lub konta gościa z ograniczonym dostępem. Wymaga to konfiguracji w Narzędziach. Szczegóły konfigurowania połączenia z kontem Quandl znajdziesz tutaj: [Narzędzia PlaidCloud – Połączenie](/pl/reference/connectors/)
* **Quandl Code**: Użyj przycisku **Szukaj**, aby wyszukać zbiory danych. Zbiory danych można też wprowadzić ręcznie. Wymaga to wpisania części adresu URL po „[http://www.quandl.com](http://www.quandl.com/)”. Na przykład, aby zaimportować zbiór danych dla akcji Microsoft, który znajduje się tutaj (http://www.quandl.com/GOOG/NASDAQ_MSFT), wpisz *GOOG/NASDAQ_MSFT* w polu Quandl Code
* **Dataset Name**: Nazwa zbioru danych do wyeksportowania do Quandl
* **Dataset Description**: Opis zbioru danych do wyeksportowania do Quandl
