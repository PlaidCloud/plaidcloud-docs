## Opis


Eksportuje tabelę danych Analyze do PlaidCloud Document jako plik HDF5.


Więcej informacji o plikach HDF5 znajdziesz na oficjalnej stronie HDF Group: http://www.hdfgroup.org/HDF5/.

<SnippetCommonExportFileSelection />



### Typ pliku wyjściowego


Wszystkie eksportowane pliki są nieskompresowane, ale dostępne są następujące opcje kompresji:


* Zip
* GZip
* BZip2
