Integracja PlaidCloud z Jupyter umożliwia specjalistom ds. danych pracę z tabelami projektów, uruchamianie zapytań i używanie PlaidCloud jako magazynu danych w środowiskach notebooków. Uwierzytelnianie wykorzystuje tokeny OAuth, dzięki czemu te same poświadczenia działają w CLI, notebookach i REST API.

## Tematy

- [Wiersz poleceń](/pl/reference/cli/jupyter/command-line/) — samodzielne CLI do skryptowych interakcji
- [Notebook Jupyter](/pl/reference/cli/jupyter/jupyter-notebook/) — korzystanie z PlaidCloud w komórkach notebooka
- [Konfiguracja OAuth](/pl/reference/cli/jupyter/oauth-setup/) — konfigurowanie uwierzytelniania
