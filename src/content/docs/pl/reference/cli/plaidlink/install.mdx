## Pobieranie agenta

Sprawdź wydania **PlaidLink** na stronie [PlaidCloud.com](https://plaidcloud.com/).

## Rozpakowanie agenta

Rozpakuj pobrany plik zip w wybranej lokalizacji instalacji. Zazwyczaj jest to:

```bash
C:\Users\<Username here>\src\plaidlink
```

## Utworzenie pliku konfiguracyjnego

<Aside>Jeśli uaktualniasz starszą wersję agenta, istniejący plik konfiguracyjny nadal jest prawidłowy i ten krok można pominąć.</Aside>

Skopiuj plik `config-dist.yaml` z katalogu agenta do `%ProgramData\plaidcloud\`, a następnie zmień nazwę tej kopii na `config.yaml`.

*(Zmodyfikuj tę konfigurację, wpisując wartości pobrane z PlaidCloud.)*

## Instalacja usługi agenta

Uruchom plik `install_windows_service.bat` w katalogu instalacyjnym agenta LUB

w wierszu polecenia uruchomionym jako administrator przejdź do katalogu instalacyjnego agenta i uruchom:

```bash
.\PlaidLink.exe install
```

## Uruchamianie agenta

<Aside>Zainstalowanie usługi systemu Windows wymaga uprawnień administratora.</Aside>

Wpisz **`Services`** w polu wyszukiwania systemu Windows i otwórz menedżera usług. Na liście usług znajdź **`PlaidCloud Agent`**.

Kliknij usługę prawym przyciskiem myszy i wybierz **„Start"**, aby uruchomić agenta.

## Wstrzymanie aktualizacji

Jeśli w dowolnym momencie chcesz wyłączyć funkcję automatycznych aktualizacji agenta, otwórz plik konfiguracyjny **„yaml"** agenta, 
dodaj na najwyższym poziomie pliku wiersz `freeze_updates: true` i uruchom ponownie usługę agenta. 

<Aside type="caution">Wyłączanie automatycznych aktualizacji na dłuższy czas nie jest zalecane.</Aside>
