## Opis

Dane w pulpitach można rozszerzać o metryki.  Każdy zbiór danych zawiera sekcję Metryki.  Metryki można pisać i modyfikować za pomocą SQL w dialekcie PostgreSQL.

<SnippetDashboardsCommonNavigateToDataset />

## Przykłady
Kolumny obliczeniowe to zazwyczaj dodatkowe kolumny tworzone przez połączenie logiki i istniejących kolumn.

### Konwersja daty na tekst
```sql
to_char("week_ending_sol_del_req", 'YYYY-mm-dd')
```

### Różne przykłady SUM
```sql
SUM(Value)

SUM(-1*"value_usd_mkp") / (0.0001+SUM(-1*"value_usd_base"))

(SUM("Value_USD_VAT")/SUM("Value_USD_HEADER"))*100

sum(delivery_cases) where Material_Type = Gloves

sum("total_cost") / sum("delivery_count")
```


### Różne przykłady CASE
```sql
CASE WHEN
SUM("distance_dc_xd") = 0 THEN 0
ELSE
sum("XD")/sum("distance_dc_xd")
END

sum(CASE
WHEN "FUNCTION" = 'OM' THEN "VALUE__FC"
ELSE 0.0
END)
```


### Count
```sql
count(*)
```


### First i Cast
```sql
public.first(cast("PRETAX_SEQ" AS NUMERIC))
```


### Round
```sql
round(Sum("GROSS PROFIT"),0)
```


### Concat
```sql
concat("GCOA","CC Code")
```
