## Opis

Dane w pulpitach można rozszerzać o kolumny obliczeniowe.  Każdy zbiór danych zawiera sekcję kolumn obliczeniowych.  Kolumny obliczeniowe można pisać i modyfikować za pomocą SQL w dialekcie PostgreSQL.

<SnippetDashboardsCommonNavigateToDataset />

## Przykłady
### Count
```sql
COUNT(*)
```

### Min
```sql
min("MyColumnName")
```

### Max
```sql
max("MyColumnName")
```

### Coalesce (przydatne na przykład do zamiany wartości null na 0.0)
```sql
coalesce("BaselineCost",0.0)
```

### Substring
```sql
substring("PERIOD",6,2)
```

### Cast
```sql
CAST("YEAR" AS integer)-1
```

### Concat
```sql
concat("Biller Entity" , ' ', "Country_biller")
```

### To_char
```sql
to_char("date_created", 'YYYY-mm-dd')
```

### Left
```sql
left("period",4)
```

### Divide
dzielenie, z obejściem unikającym błędów DIV/0
```sql
sum("so_infull")/(count(*)+0.00001)
```
<Aside>Lepszym sposobem byłoby sprawdzenie, czy mianownik ma wartość null lub zero, a następnie użycie coalesce do zera, zamiast próbować wykonać dzielenie.</Aside>


### Instrukcja warunkowa
```sql
CASE WHEN "Field_A"= 'Foo' THEN max(coalesce("Value_A",0.0)) - max(coalesce("Value_B",0.0)) END
```
```sql
CASE WHEN "sol_otif_pod_missing" = 1 THEN
'POD is missing.'
ELSE
'POD exists.'
END
```
```sql
case when "Customer DC" = "origin_dc" or "order_reason_type" = 'Off Schedule' or "mot_type" = 'UPS' then
    'Yes'
else
    'No'
end
```
```sql
CASE WHEN "module_type" is NULL THEN '---' ELSE "module_type" END
```
```sql
CASE WHEN "NODE_TYPE" = 'External' THEN '3rd Party' ELSE "ENTITY_LOCATION_DESCRIPTION" END
```

### Concatenate
```sql
concat("Class",' > ',"Product Family",' > ',"Meta Series")
```
