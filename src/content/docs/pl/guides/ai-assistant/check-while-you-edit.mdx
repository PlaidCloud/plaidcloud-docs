## Opis

Gdy naciskasz **Zapisz** w kroku, PlaidCloud sprawdza jego ustawienia i odrzuca
te, których nie może uruchomić, takie jak wyrażenie, które się nie kompiluje,
lub kolumna użyta w sposób niedozwolony dla jej typu. Podczas edycji kroku Weave
uruchamia teraz większość tych sprawdzeń na bieżąco i pokazuje, co odrzuciłby
zapis, w pasku tuż nad przyciskami **Zapisz**:

> 1 problem that Save will refuse.

Każdy problem jest wymieniony pod tym wierszem. Gdy wskazuje wiersz na karcie
**Wybór danych tabeli**, **Przejdź do** otwiera tę kartę z zaznaczonym wierszem.

Sprawdzenia odczytują wyłącznie ustawienia kroku i zmienne projektu, dlatego są
szybkie i nie wykorzystują AI. Nigdy nie blokują zapisu: Zapisz pozostaje
dostępny i po naciśnięciu sam uruchamia każde sprawdzenie.

<Aside type="note">
Zapis sprawdza też kilka rzeczy, których ten pasek nie obejmuje, na przykład
czy tabele źródłowa i docelowa mają kolumny używane przez krok oraz czy
wymagane pola są wypełnione. Dlatego „No problems found” oznacza, że żadne
z sprawdzeń uruchamianych podczas edycji nie wykryło problemu — a nie że zapis
zaakceptuje krok.
</Aside>

## Co mówi pasek

| Weave mówi | Co to oznacza |
| --- | --- |
| Sprawdzanie, czy w tym kroku są problemy… | Weave uruchamia sprawdzenia dla Twojej ostatniej zmiany. |
| 1 problem that Save will refuse. | Zapis odrzuciłby krok w obecnym stanie. Każdy problem jest wymieniony poniżej. |
| No problems found. Save checks a few more things, such as the source and target tables. | Sprawdzenia uruchamiane podczas edycji niczego nie wykryły. Zapis nadal uruchamia własne sprawdzenia, w tym te, które pomija ten pasek. |
| Weave couldn't check this step's expressions. … | Nie można było sprawdzić części kroku; po tym następuje przyczyna. To nigdy nie jest wynik pozytywny. |
| Weave nie mógł tego sprawdzić. Zapis nadal go sprawdza. | Sprawdzenie nie zostało uruchomione, na przykład dlatego, że serwer był zajęty. Twoja następna zmiana ponowi zapytanie. |

### Dlaczego nie można było sprawdzić wyrażeń

| Przyczyna | Co to oznacza |
| --- | --- |
| This step isn't in a workflow, so its expressions can't be checked. Save doesn't check them either. | Wyrażenia mogą używać zmiennych przepływu pracy, więc są sprawdzane w przepływie pracy kroku. Krok otwarty poza jakimkolwiek przepływem pracy nie jest sprawdzany — ani tutaj, ani przez Zapisz. |
| Some of its expressions are in settings Weave can't check yet. | Krok przechowuje część wyrażeń w ustawieniach, których te sprawdzenia nie odczytują, takich jak filtr drugiego źródła. Pozostałe są nadal sprawdzane. |
| Its column setup is one Weave can't check yet. | Krok wymienia swoje kolumny w sposób, którego sprawdzenie nie potrafi skompilować, jak w przypadku Złączenia wielu tabel. |

Wyrażenie używające zmiennej, której nie definiuje ani przepływ pracy, ani
projekt, jest problemem, a nie przyczyną niemożności sprawdzenia: „An expression
uses the variable rate, which isn't defined in this workflow or project.”
Podobnie jest z nawiasem klamrowym, który nie rozpoczyna ani nie kończy żadnej
nazwy zmiennej, jak w przypadku zmiennej wpisanej do połowy: „An expression has
a brace that isn't part of a variable name.” Zapis odrzuca oba przypadki tymi
samymi komunikatami.

## W Edytorze wyrażeń

Otwórz **Edytor wyrażeń** z komórki **Wyrażenie** na karcie **Wybór danych
tabeli** albo z opcji **Wybierz podzbiór danych** lub **Zastosuj filtr dodatkowy
do danych wynikowych** na karcie **Filtry danych**, a wiersz pod edytorem
sprawdzi wyrażenie w trakcie pisania:

| Edytor mówi | Co to oznacza |
| --- | --- |
| Checking… | Weave sprawdza to, co właśnie wpisano. |
| No errors found. | Wyrażenie kompiluje się tak, jak kompiluje je Zapisz. Wskaż ten wiersz, aby przeczytać, czego to nie obejmuje: Weave sprawdza składnię i nazwy kolumn; niektóre błędy ujawniają się dopiero po uruchomieniu kroku. |
| Error: … | Zapis odrzuciłby wyrażenie z podanej przyczyny. Błąd składni jest dodatkowo oznaczony w jego wierszu, obok numeru wiersza. |
| Nie można sprawdzić. … | Nie można było sprawdzić wyrażenia z jednej z przyczyn podanych powyżej. |
| Couldn't check just now. Saving the step still checks it. | Sprawdzenie nie zostało uruchomione. Naciśnięcie **Zapisz** w kroku nadal sprawdza wyrażenie. |

Edytor sprawdza wyrażenie względem ustawień kroku z chwili, gdy Weave ostatnio
sprawdzał krok, z wstawionym Twoim wyrażeniem. Otwarty z jakiegokolwiek innego
miejsca, na przykład z Eksploratora tabel, nie pokazuje żadnego wiersza.

## Kiedy się pojawia

- Podczas edycji kroku, który możesz zmieniać. Krok otwierany tylko do odczytu
  dla Twojej roli nie jest sprawdzany podczas edycji.
- Po każdej zmianie, gdy zrobisz pauzę. Zmiana, która pozostawia ustawienia
  bez zmian, nie jest sprawdzana ponownie.
- Odczytuje ustawienia kroku i zmienne projektu, więc nigdy nie wiąże się
  z wywołaniem AI i nigdy nie odpytuje Twojej hurtowni.
