PlaidCloud Git zawiera wbudowany rejestr pakietów dla dystrybuowanych artefaktów oraz Git Large File Storage (LFS) dla dużych plików binarnych w repozytoriach.

## Informacje o rejestrze pakietów

Rejestr pakietów jest przypisany do właściciela i obsługuje szeroki zakres formatów ekosystemów — npm, PyPI, Maven, NuGet, RubyGems, obrazy kontenerów i inne. Pakiety są prywatne w Twoim obszarze roboczym i dostępne tylko dla uwierzytelnionych członków.

Każdy typ pakietu ma własny punkt końcowy pod adresem:

```
https://git.example.plaidcloud.com/api/packages/you/<type>
```

gdzie `<type>` to identyfikator ekosystemu (na przykład `npm`, `pypi` lub `maven`).

## Uwierzytelnianie w rejestrze

Operacje menedżera pakietów używają nazwy użytkownika PlaidCloud Git oraz osobistego tokenu dostępu jako hasła. Informacje o tworzeniu tokenu znajdziesz w [Repozytoria](/pl/guides/git/repositories/).

## Publikowanie pakietu

Kroki różnią się w zależności od ekosystemu, ale schemat jest ten sam: wskaż menedżerowi pakietów adres URL rejestru i uruchom jego standardowe polecenie publikacji.

W przypadku npm dodaj do projektu plik `.npmrc`, aby powiązać pakiety z rejestrem:

```ini
@you:registry=https://git.example.plaidcloud.com/api/packages/you/npm/
//git.example.plaidcloud.com/api/packages/you/npm/:_authToken=YOUR_TOKEN
```

Następnie opublikuj jak zwykle:

```bash
npm publish
```

W przypadku PyPI, Maven, NuGet i innych ekosystemów ustaw w konfiguracji narzędzia repozytorium lub źródło na odpowiedni adres URL rejestru i użyj standardowego polecenia publikacji tego narzędzia (na przykład `twine upload`, `mvn deploy` lub `dotnet nuget push`).

## Instalowanie pakietu

Wskaż menedżerowi pakietów ten sam adres URL rejestru i zainstaluj jak zwykle. Po skonfigurowaniu powyższego pliku `.npmrc`:

```bash
npm install @you/my-package
```

W przypadku innych ekosystemów dodaj rejestr jako dodatkowe źródło w konfiguracji narzędzia i użyj jego standardowego polecenia instalacji.

## Duże pliki w Git LFS

Git LFS zapewnia szybkość działania repozytorium, zastępując w historii duże lub binarne pliki lekkimi wskaźnikami i przechowując dane plików osobno. LFS jest włączony w każdym repozytorium PlaidCloud Git.

1. Zainstaluj klienta LFS raz na swoim komputerze:

   ```bash
   git lfs install
   ```

2. Wskaż LFS, które wzorce plików ma śledzić, z poziomu repozytorium:

   ```bash
   git lfs track "*.parquet"
   ```

   Spowoduje to utworzenie lub zaktualizowanie `.gitattributes`. Zatwierdź ten plik:

   ```bash
   git add .gitattributes
   git commit -m "Track Parquet files with LFS"
   ```

3. Dodawaj i wypychaj jak zwykle — pasujące pliki są automatycznie przesyłane do LFS:

   ```bash
   git add data/large-dataset.parquet
   git commit -m "Add dataset"
   git push origin main
   ```

<Aside type="tip">Git LFS służy do dużych plików, które znajdują się w historii repozytorium i są pobierane za pomocą `git clone` lub `git pull`. Rejestr pakietów służy do wersjonowanych, dystrybuowanych artefaktów, które odbiorcy instalują za pomocą menedżera pakietów. Jeśli współpracownicy mają je instalować przez `npm install` lub `pip install`, użyj rejestru; jeśli potrzebują ich jako części kopii roboczej, użyj LFS.</Aside>
