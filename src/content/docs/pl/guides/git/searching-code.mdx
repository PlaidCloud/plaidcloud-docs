PlaidCloud Git umożliwia przeszukiwanie kodu, plików, zgłoszeń i pull requestów we wszystkich repozytoriach, do których dostęp daje Ci członkostwo w obszarze roboczym.

## Wyszukiwanie kodu

1. Wybierz pole wyszukiwania u góry dowolnej strony i wpisz zapytanie.
2. Naciśnij **Enter**, aby zobaczyć wyniki ze wszystkich repozytoriów, do których masz dostęp.
3. Wybierz wynik, aby przejść bezpośrednio do pliku w pasującym wierszu.
4. Zawęź wyniki za pomocą filtrów **Repozytorium** i **Język** na stronie wyników.

<Aside>Wyszukiwanie kodu indeksuje gałąź domyślną. Aby przeszukać inną gałąź, przejdź do niej i użyj opisanego poniżej wyszukiwania w repozytorium.</Aside>

## Wyszukiwanie w repozytorium

1. Otwórz repozytorium i wybierz kartę **Kod**.
2. Naciśnij **T** (lub wybierz pole wyszukiwania plików), aby otworzyć wyszukiwarkę plików.
3. Wpisz część nazwy pliku lub ścieżki — lista filtruje się podczas pisania.
4. Wybierz plik, aby go otworzyć, a następnie użyj wyszukiwania na stronie w przeglądarce (**⌘F** / **Ctrl+F**), aby znaleźć konkretny wiersz.

<Aside type="tip">Wyszukiwarka plików dopasowuje segmenty ścieżki, więc wpisanie `util/auth` pokaże `src/util/auth.py`, `lib/util/auth_helper.go` i podobne ścieżki.</Aside>

## Filtrowanie zgłoszeń i pull requestów

Na liście **Issues** lub **Pull Requests** łącz wyszukiwanie słów kluczowych z filtrami `key:value`:

| Filtr | Przykład |
|---|---|
| Stan otwarty lub zamknięty | `is:open`, `is:closed` |
| Etykieta | `label:bug`, `label:"needs review"` |
| Osoba przypisana | `assignee:you` |
| Autor | `author:you` |
| Kamień milowy | `milestone:"v1.2"` |

Wpisuj filtry bezpośrednio w polu wyszukiwania, łącz je dowolnie i użyj menu **Sortuj**, aby uporządkować według **Ostatnio zaktualizowane**, **Najczęściej komentowane**, **Najnowszy** lub **Najstarszy**.

<Aside>Ujmij nazwę etykiety w cudzysłów, gdy zawiera spacje: `label:"needs review"`.</Aside>

## Wskazówki, jak szybciej znajdować

- **Dokładne frazy** — ujmij wielowyrazowe terminy w cudzysłów (`"connection pool"`), aby uniknąć zaszumionych dopasowań częściowych.
- **Zawężenie do repozytorium** — otwórz repozytorium przed wyszukiwaniem, aby wyniki pozostały skoncentrowane.
- **Opisowe nazwy się opłacają** — repozytoria i zgłoszenia o jasnych, konkretnych nazwach pojawiają się w wyszukiwaniu znacznie pewniej niż te o ogólnych nazwach, takich jak `misc`.
- **Etykiety to przeszukiwalne metadane** — dobrze oznaczone zgłoszenie łatwiej przefiltrować niż to ukryte w tekście, więc stosuj etykiety konsekwentnie.
