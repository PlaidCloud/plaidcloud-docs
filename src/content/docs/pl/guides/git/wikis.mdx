Każde repozytorium może hostować wiki — osobny zbiór stron Markdown z dokumentacją, która znajduje się obok kodu, nie mieszając się z nim.

## Włączanie wiki

1. Otwórz repozytorium i wybierz **Ustawienia**.
2. W sekcji **Cechy** włącz **Wiki**.
3. W nawigacji repozytorium pojawi się karta **Wiki**.

## Tworzenie i edytowanie stron

1. Wybierz kartę **Wiki**.
2. Jeśli wiki nie ma jeszcze stron, wybierz **Create the First Page**. W przeciwnym razie wybierz **New Page**.
3. Wpisz tytuł strony. Tytuł staje się adresem URL strony, więc wybierz coś jasnego i stałego.
4. Napisz treść w Markdown, a następnie wybierz **Save Page**.

Pierwsza utworzona strona staje się **Stroną główną** wiki — stroną, na którą odwiedzający trafiają domyślnie. Aby zaktualizować istniejącą stronę, otwórz ją i wybierz **Edytuj**. Każdy zapis dodaje nowy wpis do historii wersji strony.

<Aside>Wiki jest wersjonowane tak samo jak kod. Otwórz widok **Revisions** na dowolnej stronie, aby przeglądać jej historię lub przywrócić wcześniejszą wersję.</Aside>

## Organizowanie wiki

Dwie strony o specjalnych nazwach sterują nawigacją w całym wiki:

- **\_Sidebar** — niestandardowy pasek boczny wyświetlany na każdej stronie. Dodaj tutaj łącza do najważniejszych stron.
- **\_Footer** — stopka wyświetlana na dole każdej strony.

Utwórz dowolną z nich za pomocą **New Page**, używając dokładnie podanej powyżej nazwy. Łącz strony wiki za pomocą standardowego Markdown, odwołując się do identyfikatora strony:

```md
See the [Setup Guide](setup-guide) for installation steps.
```

Od początku używaj opisowych tytułów stron: tytuł staje się adresem URL, a późniejsza zmiana nazwy strony zrywa wszystkie istniejące do niej łącza.

## Edytowanie wiki lokalnie

Wiki samo jest repozytorium Git, dostępnym pod adresem URL `.wiki.git` Twojego repozytorium. Sklonuj je, edytuj pliki Markdown w swoim edytorze i wypchnij zmiany z powrotem.

```bash
git clone https://git.example.plaidcloud.com/you/my-repo.wiki.git
cd my-repo.wiki
# edit or add .md files
git add .
git commit -m "Expand the setup guide"
git push
```

Działa tu ten sam osobisty token dostępu, którego używasz dla głównego repozytorium. Każdy plik Markdown staje się stroną wiki; nazwa pliku (bez rozszerzenia `.md`) jest identyfikatorem strony.
