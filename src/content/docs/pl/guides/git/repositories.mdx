Repozytorium przechowuje pliki, gałęzie i historię jednego projektu. Ta instrukcja opisuje tworzenie repozytorium i łączenie się z nim z Twojego komputera.

## Tworzenie repozytorium

1. Otwórz **Git** w swoim obszarze roboczym.
2. Wybierz menu **+** w prawym górnym rogu, a następnie **New Repository**.
3. Wpisz nazwę i opcjonalnie krótki opis.
4. Wybierz widoczność. Nowe repozytoria są domyślnie **Prywatne** — widzą je tylko członkowie, którym przyznasz dostęp.
5. Opcjonalnie wybierz **Initialize Repository**, aby dodać plik README, plik `.gitignore` i licencję.
6. Wybierz **Create Repository**.

## Generowanie osobistego tokenu dostępu

Ponieważ logujesz się przez PlaidCloud, Twoje konto nie ma osobnego hasła Git. Aby klonować lub wypychać przez HTTPS z wiersza poleceń, utwórz osobisty token dostępu i używaj go zamiast hasła.

1. Wybierz swój awatar w prawym górnym rogu, a następnie **Settings**. Karta konfiguracji na karcie **Git** również prowadzi bezpośrednio do tej strony.
2. Otwórz kartę **Applications**.
3. W sekcji **Manage Access Tokens** wpisz nazwę opisującą, gdzie będziesz używać tokenu (na przykład `laptop`).
4. Wybierz uprawnienie **write:repository**, aby token mógł klonować i wypychać zmiany.
5. Wybierz **Generate Token**.
6. Skopiuj token i zapisz go w bezpiecznym miejscu. Nie będzie można go ponownie wyświetlić.

<Aside type="caution">Traktuj token jak hasło — każdy, kto go ma, może działać w Git jako Ty. Generuj osobny token dla każdego komputera, aby móc unieważnić jeden bez zakłócania pozostałych.</Aside>

## Klonowanie repozytorium

1. Otwórz **Git** w swoim obszarze roboczym i wybierz przycisk kopiowania obok adresu klonowania repozytorium (wybierz **How to clone**, aby zobaczyć kroki konfiguracji). Możesz też wybrać **Kod** w repozytorium i skopiować adres URL **HTTPS**.
2. W terminalu uruchom `git clone` z tym adresem URL:

   ```bash
   git clone <clone URL>
   ```

3. Gdy Git poprosi o hasło, wklej **token dostępu**. Użyj nazwy użytkownika, która już znajduje się w adresie URL.
4. Ustaw imię i nazwisko oraz adres e-mail, które Git zapisuje w Twoich zatwierdzeniach, używając wartości pokazanych na karcie konfiguracji:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Aby wypychać zmiany, potrzebujesz dostępu Contributor lub Administrator; jako Przeglądający możesz czytać, ale nie wypychać. Zobacz [Poziomy dostępu](/pl/guides/git/#poziomy-dostępu).

<Aside>Aby nie wpisywać tokenu przy każdym wypchnięciu, możesz pozwolić pomocnikowi poświadczeń Git systemu operacyjnego go zapisać, na przykład `git config --global credential.helper osxkeychain` w systemie macOS.</Aside>

## Zatwierdzanie i wypychanie zmian

Wewnątrz sklonowanego repozytorium:

1. Przygotuj zmiany do zatwierdzenia: `git add .`
2. Zapisz je z komunikatem: `git commit -m "Describe what changed"`
3. Wyślij je do PlaidCloud Git: `git push`

Twoje zatwierdzenia pojawiają się w widokach **Commits** i **Aktywność** repozytorium oraz w każdej gałęzi lub pull requeście, które je zawierają.

## Zarządzanie dostępem i widocznością

Otwórz kartę **Ustawienia** repozytorium, aby zmienić jego nazwę, widoczność lub przenieść własność. Aby umożliwić innym członkom współtworzenie, użyj **Ustawienia → Collaborators** i dodaj ich według nazwy użytkownika z rolą **Odczyt**, **Zapis** lub **Administrator**.

<Aside>Dostęp do repozytorium zależy także od członkostwa w obszarze roboczym i grup zabezpieczeń. Zobacz [Zarządzanie dostępem](/pl/administration/access/), aby dowiedzieć się, jak przekładają się one na to, kto może przeglądać i edytować repozytorium.</Aside>
