Repozytorium zawiera pliki, gałęzie i historię jednego projektu. Ten przewodnik pokazuje, jak utworzyć repozytorium i połączyć się z nim z komputera.

## Tworzenie repozytorium

1. Otwórz **Git** w obszarze roboczym.
2. Wybierz menu **+** w prawym górnym rogu, a następnie **New Repository**.
3. Wpisz nazwę i opcjonalnie krótki opis.
4. Wybierz widoczność. Nowe repozytoria są domyślnie **Prywatne** – widzą je tylko członkowie, którym przyznano dostęp.
5. Opcjonalnie wybierz **Initialize Repository**, aby dodać plik README, plik `.gitignore` i licencję.
6. Wybierz **Create Repository**.

Współautorzy nie mogą tworzyć repozytoriów bezpośrednio w organizacji Git obszaru roboczego; repozytoria tworzy się za pośrednictwem PlaidCloud.

## Generowanie osobistego tokenu dostępu

Ponieważ logujesz się przez PlaidCloud, Twoje konto nie ma osobnego hasła Git. Aby klonować lub wypychać zmiany przez HTTPS z wiersza polecenia, utwórz osobisty token dostępu i używaj go zamiast hasła.

1. Wybierz swój awatar w prawym górnym rogu, a następnie **Ustawienia**. Karta konfiguracji na karcie **Git** również prowadzi bezpośrednio do tej strony.
2. Otwórz kartę **Aplikacje**.
3. W sekcji **Zarządzaj tokenami dostępu** wpisz nazwę opisującą, gdzie będziesz używać tokenu (na przykład `laptop`).
4. Wybierz uprawnienie **write:repository**, aby token mógł klonować i wypychać zmiany.
5. Wybierz **Generate Token**.
6. Skopiuj token i zachowaj go w bezpiecznym miejscu. Nie będzie można go ponownie wyświetlić.

<Aside type="caution">Traktuj token jak hasło – każdy, kto go ma, może działać w Git w Twoim imieniu. Wygeneruj osobny token dla każdego komputera, aby móc unieważnić jeden bez zakłócania pozostałych.</Aside>

## Klonowanie repozytorium

1. Otwórz **Git** w obszarze roboczym i wybierz przycisk kopiowania obok adresu klonowania repozytorium (wybierz **How to clone**, aby zobaczyć kroki konfiguracji). Możesz też wybrać **Kod** w repozytorium i skopiować adres URL **HTTPS**.
2. W terminalu uruchom `git clone` z tym adresem URL:

   ```bash
   git clone <clone URL>
   ```

3. Gdy Git poprosi o hasło, wklej **token dostępu**. Użyj nazwy użytkownika, która już znajduje się w adresie URL.
4. Ustaw imię i nazwisko oraz adres e-mail, które Git zapisuje w zatwierdzeniach, używając wartości wyświetlonych na karcie konfiguracji:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Do wypychania zmian potrzebujesz dostępu Współautora lub Administratora; jako Przeglądający możesz odczytywać, ale nie wypychać. Zobacz [Poziomy dostępu](/pl/guides/git/#poziomy-dostępu).

<Aside>Aby nie wpisywać tokenu przy każdym wypchnięciu, możesz pozwolić, aby przechowywał go pomocnik poświadczeń Git systemu operacyjnego, na przykład `git config --global credential.helper osxkeychain` w systemie macOS.</Aside>

## Zatwierdzanie i wypychanie zmian

Wewnątrz sklonowanego repozytorium:

1. Dodaj zmiany do poczekalni: `git add .`
2. Zapisz je z komunikatem: `git commit -m "Describe what changed"`
3. Wyślij je do PlaidCloud Git: `git push`

Zatwierdzenia pojawiają się w widokach **Commits** i **Aktywność** repozytorium oraz na każdej gałęzi lub w każdym pull requeście, który je zawiera.

## Zarządzanie dostępem i widocznością

Otwórz kartę **Ustawienia** repozytorium, aby zmienić jego nazwę, widoczność lub przenieść własność. Aby umożliwić współpracę innym członkom, użyj **Ustawienia → Collaborators** i dodaj ich według nazwy użytkownika z rolą **Odczyt**, **Zapis** lub **Administrator**.

<Aside>Dostęp do repozytorium podąża również za członkostwem w obszarze roboczym i grupami zabezpieczeń. Zobacz [Zarządzanie dostępem](/pl/administration/access/), aby dowiedzieć się, jak decydują one o tym, kto może wyświetlać i edytować repozytorium.</Aside>
