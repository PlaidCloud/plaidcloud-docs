Repozytorium zawiera pliki, gałęzie i historię jednego projektu. W tym przewodniku opisano tworzenie repozytorium i łączenie się z nim z komputera.

## Tworzenie repozytorium

1. Otwórz **Git** ze swojego obszaru roboczego.
2. Wybierz menu **+** w prawym górnym rogu, a następnie **New Repository**.
3. Wpisz nazwę i opcjonalnie krótki opis.
4. Wybierz widoczność. Nowe repozytoria są domyślnie **Prywatne** — widzą je tylko członkowie, którym przyznasz dostęp.
5. Opcjonalnie wybierz **Initialize Repository**, aby dodać plik README, `.gitignore` i licencję.
6. Wybierz **Create Repository**.

## Generowanie osobistego tokenu dostępu

Ponieważ logujesz się przez PlaidCloud, Twoje konto nie ma osobnego hasła do Git. Aby klonować lub wypychać przez HTTPS z wiersza poleceń, utwórz osobisty token dostępu i użyj go zamiast hasła.

1. Wybierz swój awatar w prawym górnym rogu, a następnie **Ustawienia**.
2. Otwórz kartę **Aplikacje**.
3. W sekcji **Manage Access Tokens** wpisz nazwę opisującą, gdzie użyjesz tokenu (na przykład `laptop`).
4. Wybierz zakresy **odczytu** i **zapisu** repozytorium, aby token mógł klonować i wypychać.
5. Wybierz **Generate Token**.
6. Skopiuj token i zapisz go w bezpiecznym miejscu. Nie będzie można go wyświetlić ponownie.

<Aside type="caution">Traktuj token jak hasło — każdy, kto go ma, może działać w Git w Twoim imieniu. Generuj osobny token dla każdego komputera, aby móc unieważnić jeden bez zakłócania pozostałych.</Aside>

## Klonowanie repozytorium

1. Otwórz repozytorium w PlaidCloud Git.
2. Wybierz **Kod**, a następnie skopiuj adres URL klonowania **HTTPS**.
3. W terminalu uruchom `git clone` z tym adresem URL:

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. Gdy Git poprosi o poświadczenia, wpisz swoją **nazwę użytkownika PlaidCloud** i wklej **token dostępu** jako hasło.

<Aside>Aby uniknąć ponownego wpisywania tokenu przy każdym wypchnięciu, pozwól pomocnikowi poświadczeń Git systemu operacyjnego go zapisać: uruchom `git config --global credential.helper store` (lub `osxkeychain` w macOS) przed pierwszym wypchnięciem.</Aside>

## Zatwierdzanie i wypychanie zmian

Z poziomu sklonowanego repozytorium:

1. Dodaj zmiany do poczekalni: `git add .`
2. Zapisz je z komunikatem: `git commit -m "Describe what changed"`
3. Wyślij je do PlaidCloud Git: `git push`

Twoje commity pojawiają się w widokach **Commits** i **Aktywność** repozytorium oraz w każdej gałęzi lub pull requeście, który je zawiera.

## Zarządzanie dostępem i widocznością

Otwórz kartę **Ustawienia** repozytorium, aby zmienić jego nazwę, widoczność lub przenieść własność. Aby umożliwić innym członkom współtworzenie, użyj **Ustawienia → Collaborators** i dodaj ich według nazwy użytkownika z rolą **Odczyt**, **Zapis** lub **Administrator**.

<Aside>Dostęp do repozytorium zależy także od członkostwa w obszarze roboczym i grup zabezpieczeń. Informacje o tym, jak przekładają się one na to, kto może przeglądać i edytować repozytorium, znajdziesz w [Zarządzanie dostępem](/pl/administration/access/).</Aside>
