[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jednym Common Finance Model, a Oracle E-Business Suite to jeden z systemów ERP, które odczytuje bezpośrednio. PlaidCloud łączy się z EBS przez agenta [PlaidLink](/pl/reference/cli/plaidlink/) zainstalowanego wewnątrz Twojej sieci, nigdy bezpośrednio. Ta strona jest przeznaczona dla administratora EBS, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła hasła e-mailem.

## Wyślij prośbę o dostęp

Na karcie **Foundation** projektu wybierz **Utwórz nowe połączenie** w sekcji **Połączenie Oracle E-Business Suite**. Formularz pokazuje pełną prośbę oraz link **How to set up PlaidLink**. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Read-only Oracle E-Business Suite access for PlaidCloud (through PlaidLink)”.

## Co konfiguruje administrator EBS

<Steps>

1. **Zainstaluj PlaidLink** na serwerze, który ma dostęp do bazy danych EBS, i zarejestruj go w PlaidCloud.

2. **Nadaj SELECT** użytkownikowi schematu APPS dla PlaidLink (lub użytkownikowi schematu tylko do odczytu z synonimami do obiektów APPS) na:

   | Obszar | Obiekty |
   |---|---|
   | Księga główna | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES` |
   | Flexfieldy | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | Sprzedaż (opcjonalnie) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |

3. **Wskaż użytkownika aplikacji** (`FND_USER`) oraz odpowiedzialność, która widzi wszystkie księgi i wartości segmentu bilansującego, które chcesz raportować.

4. **Opisz plan kont.** Podaj, które segmenty są segmentem bilansującym, kontem naturalnym, centrum kosztów i segmentem wewnątrzgrupowym (ich kwalifikatory segmentów). PlaidCloud typuje konto kosztowe jako koszt własny sprzedanych towarów, gdy ono samo lub wartość nadrzędna nad nim jest opisana jako koszt własny sprzedanych towarów (cost of goods sold), koszt sprzedaży (cost of sales) lub koszt przychodów (cost of revenue). Typuje konto jako nieoperacyjne, gdy jedno z nich wymienia przychody lub koszty odsetkowe, przychody lub koszty finansowe, różnice kursowe, podatek dochodowy lub pozostałe przychody i koszty. Poinformuj PlaidCloud, jeśli Twoje wartości nadrzędne używają do tego innych słów.

5. **Potwierdź typy kursów.** Każda księga podstawowa wskazuje typy kursów średnich okresowych i kursów na koniec okresu w opcjach przeliczania księgi. PlaidCloud przelicza, używając kursów dziennych tych dwóch typów.

</Steps>

<Aside type="caution">
Niewłaściwa odpowiedzialność zwraca wiersze innej księgi bez żadnego błędu. Potwierdź ją z właścicielem księgi głównej.
</Aside>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Host bazy danych | **Database host** |
| Port bazy danych | **Port bazy danych** (1521, chyba że go zmienisz) |
| Nazwa usługi | **Nazwa usługi** |
| Użytkownik schematu APPS | **APPS schema user** |
| Hasło schematu APPS, przez bezpieczny formularz połączenia | **APPS schema password**, które Twój zespół wkleja samodzielnie |
| `FND_USER` | **Application user (FND_USER)** |
| Klucz odpowiedzialności | **Responsibility key** |
| Wartości segmentu bilansującego, które PlaidCloud może odczytywać | W polu **Balancing segment values** (system nie może ich wylistować przed ładowaniem): wpisz jedną wartość w polu **Nazwa** lub pozostaw puste, aby załadować wszystkie jednostki księgi podstawowej |

Agent PlaidLink, który łączy się z instancją, jest wybierany w sekcji System settings jako `agent`.

<Aside type="caution">
Nigdy nie wysyłaj hasła e-mailem. **APPS schema password** jest sekretem: jest przechowywane w połączeniu i nigdy więcej nie jest pokazywane.
</Aside>

## Sprawdź dostęp

Po powrocie do PlaidCloud wprowadź wartości i kliknij **Testuj połączenie**. Każdy zbiór danych jest oznaczony jako **Dostępne do odczytu**, **Brak uprawnienia** lub **Błąd**:

| Zbiór danych | Obiekty, które odczytuje |
|---|---|
| Jednostki | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| Kalendarz fiskalny | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| Plan kont | `GL_CODE_COMBINATIONS`, tabele flexfieldów |
| Działy | `GL_CODE_COMBINATIONS`, tabele flexfieldów |
| Kursy walut | `GL_DAILY_RATES` |
| Księga główna | `GL_JE_HEADERS`, `GL_JE_LINES` |
| Bilans próbny | `GL_BALANCES` |
| Klienci | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES` (opcjonalne) |
| Produkty | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` (opcjonalne) |
| Pozycje sprzedaży | Tabele `RA_CUSTOMER_TRX` (opcjonalne) |

Gdy zbiór danych ma status **Brak uprawnienia**, poproś administratora o nadanie SELECT na obiektach i przetestuj ponownie. Klienci, produkty i pozycje sprzedaży są opcjonalne: instancja, która ich nie używa, nadal ładuje wszystko inne.
