[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jednym Common Finance Model, a Oracle E-Business Suite to jeden z systemów ERP, które odczytuje bezpośrednio. PlaidCloud łączy się z EBS przez agenta [PlaidLink](/pl/reference/cli/plaidlink/) zainstalowanego wewnątrz Twojej sieci, nigdy bezpośrednio. Ta strona jest przeznaczona dla administratora EBS, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła hasła e-mailem.

## Wyślij prośbę o dostęp

Na stronie projektu **Systemy**, w sekcji **Data Foundation** w obszarze **Strona główna**, wybierz swój system w polu **System** w sekcji **Dodaj system** i kliknij **Brak jeszcze dostępu?**. System czeka na dostęp, a wyświetlana jest jedna prośba obejmująca systemy projektu. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Dostęp do PlaidCloud”.

## Co konfiguruje administrator EBS

<Steps>

1. **Zainstaluj PlaidLink** na serwerze, który ma dostęp do bazy danych EBS, i zarejestruj go w PlaidCloud.

2. **Utwórz użytkownika bazy danych tylko do odczytu** dla PlaidLink — nigdy APPS ani żadnego innego użytkownika schematu, który może zmieniać dane. Nadaj mu poniższe uprawnienia, każde z synonimem o tej samej nazwie do obiektu APPS; jest to SELECT, o ile tabela nie podaje inaczej:

   | Obszar | Obiekty |
   |---|---|
   | Sesja (wymagane) | EXECUTE na `FND_GLOBAL` i `MO_GLOBAL`; `FND_RESPONSIBILITY_VL`; oraz `FND_USER` lub widok o tej nazwie zawierający tylko `USER_ID`, `USER_NAME`, `EMPLOYEE_ID` i `DESCRIPTION`. Bez nich każdy odczyt kończy się niepowodzeniem |
   | Księga główna | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES`. `GL_BALANCES` musi zawierać wszystkie okresy, a nie tylko najnowszy: jest to saldo na koniec miesiąca, z którym porównywana jest księga |
   | Flexfieldy | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | Sprzedaż (opcjonalnie) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |
   | Zatwierdzający zapisy (opcjonalnie) | `GL_JE_BATCHES` |
   | Kraj jednostki (opcjonalnie) | `XLE_REGISTRATIONS`, `HZ_LOCATIONS` |
   | Należności, zobowiązania, salda bankowe i faktury dostawców (opcjonalnie) | `AR_PAYMENT_SCHEDULES_ALL`, `AR_CASH_RECEIPTS_ALL`, `AR_RECEIVABLE_APPLICATIONS_ALL`, `AR_ADJUSTMENTS_ALL`, `AR_RECEIPT_METHODS`, `RA_TERMS_TL`, `CE_BANK_ACCOUNTS`, `AP_INVOICES_ALL`, `AP_INVOICE_LINES_ALL`, `AP_INVOICE_DISTRIBUTIONS_ALL`, `AP_PAYMENT_SCHEDULES_ALL`, `AP_INVOICE_PAYMENTS_ALL`, `AP_CHECKS_ALL`, `AP_SUPPLIERS`, `AP_SUPPLIER_SITES_ALL`, `AP_TERMS_TL`, `PO_HEADERS_ALL`, `PO_LINES_ALL`, `MTL_ITEM_CATEGORIES`, `MTL_CATEGORIES_B` |
   | Zakupy, zapasy, budżety, koszty standardowe i środki trwałe (opcjonalnie) | `PO_LINE_LOCATIONS_ALL`, `PO_DISTRIBUTIONS_ALL`, `RCV_TRANSACTIONS`, `ORG_ORGANIZATION_DEFINITIONS`, `MTL_MATERIAL_TRANSACTIONS`, `MTL_SECONDARY_INVENTORIES`, `CST_STANDARD_COSTS`, `GL_BUDGETS`, `GL_BUDGET_VERSIONS`, `FA_ADDITIONS_B`, `FA_ADDITIONS_TL`, `FA_CATEGORIES_B`, `FA_BOOK_CONTROLS`, `FA_BOOKS`, `FA_CATEGORY_BOOKS`, `FA_DISTRIBUTION_HISTORY`, `FA_DEPRN_PERIODS`, `FA_DEPRN_SUMMARY`, `FA_RETIREMENTS`, `FA_TRANSACTION_HEADERS` |

   Zapasy są odczytywane z transakcji materiałowych, więc ich historia wymaga zachowania tych transakcji. Budżety to salda budżetowe w `GL_BALANCES`.

3. **Wskaż użytkownika aplikacji** (`FND_USER`) oraz odpowiedzialność do zapytań, która może tylko wyświetlać dane i która widzi wszystkie księgi i wartości segmentu bilansującego, które chcesz raportować.

4. **Opisz plan kont.** Podaj, które segmenty są segmentem bilansującym, kontem naturalnym, centrum kosztów i segmentem wewnątrzgrupowym (ich kwalifikatory segmentów). PlaidCloud typuje konto kosztowe jako koszt własny sprzedanych towarów, gdy ono samo lub wartość nadrzędna nad nim jest opisana jako koszt własny sprzedanych towarów (cost of goods sold), koszt sprzedaży (cost of sales) lub koszt przychodów (cost of revenue). Typuje konto jako nieoperacyjne, gdy jedno z nich wymienia przychody lub koszty odsetkowe, przychody lub koszty finansowe, różnice kursowe, podatek dochodowy lub pozostałe przychody i koszty. Poinformuj PlaidCloud, jeśli Twoje wartości nadrzędne używają do tego innych słów.

5. **Wskaż segmenty lokalizacji i centrum zysku**, jeśli przechowujesz lokalizacje lub centra zysku w segmencie planu kont (od `SEGMENT1` do `SEGMENT30`). EBS nie ma kwalifikatora dla żadnego z nich. PlaidCloud odczytuje wartości zestawu wartości każdego segmentu jako listy lokalizacji i centrów zysku.

6. **Potwierdź typy kursów.** Każda księga podstawowa wskazuje typy kursów średnich okresowych i kursów na koniec okresu w opcjach przeliczania księgi. PlaidCloud przelicza, używając kursów dziennych tych dwóch typów.

</Steps>

<Aside type="caution">
Niewłaściwa odpowiedzialność zwraca wiersze innej księgi bez żadnego błędu. Potwierdź ją z właścicielem księgi głównej.
</Aside>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Host bazy danych | **Host lub adres IP** |
| Port bazy danych | **Port** (1521, chyba że go zmienisz) |
| Nazwa usługi | **Nazwa usługi** |
| Użytkownik bazy danych tylko do odczytu | **Użytkownik bazy danych (schemat APPS)** |
| Jego hasło, przez bezpieczny formularz połączenia | **Hasło**, które Twój zespół wprowadza samodzielnie |
| `FND_USER` | **Użytkownik aplikacji (FND_USER.USER_NAME)** |
| Klucz odpowiedzialności | **Klucz odpowiedzialności (FND_RESPONSIBILITY.RESPONSIBILITY_KEY)** |
| Wartości segmentu bilansującego, które PlaidCloud może odczytywać | W sekcji **Opcje**, w polu **Spółki**, ponieważ EBS nie może ich wylistować: wpisz wartości oddzielone przecinkami lub pozostaw pole puste, aby załadować wszystkie jednostki każdej księgi podstawowej |

Agent PlaidLink, który łączy się z instancją, jest wskazywany w ustawieniu systemowym **PlaidLink agent**. Segmenty lokalizacji i centrum zysku trafiają do ustawień systemowych **Site segment** i **Profit centre segment**.

<Aside type="caution">
Nigdy nie wysyłaj hasła e-mailem. **Hasło** jest sekretem: jest przechowywane w połączeniu i nigdy więcej nie jest pokazywane.
</Aside>

## Sprawdź dostęp

Po powrocie do PlaidCloud, gdy system zostanie już dodany, kliknij **Testuj połączenie** w jego wierszu na stronie **Systemy**. Ponieważ z EBS łączy się agent PlaidLink, test sprawdza, czy połączenie podaje wszystko, czym agent się loguje. Same tabele są odczytywane przy pierwszym ładowaniu i wtedy wskazywana jest tabela, której agent nie może odczytać. Każdy zbiór danych odczytuje:

| Zbiór danych | Obiekty, które odczytuje |
|---|---|
| Jednostki | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| Kalendarz fiskalny | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| Plan kont | `GL_CODE_COMBINATIONS`, tabele flexfieldów |
| Działy | `GL_CODE_COMBINATIONS`, tabele flexfieldów |
| Kursy walut | `GL_DAILY_RATES` |
| Księga główna | `GL_JE_HEADERS`, `GL_JE_LINES` |
| Bilans próbny | `GL_BALANCES` |
| Klienci | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES` (opcjonalne) |
| Produkty | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` (opcjonalne) |
| Pozycje sprzedaży | Tabele `RA_CUSTOMER_TRX` (opcjonalne) |
| Saldo na koniec miesiąca | `GL_BALANCES`, wszystkie okresy (opcjonalne) |
| Salda bankowe | `CE_BANK_ACCOUNTS` z saldem na koniec miesiąca konta środków pieniężnych każdego banku (opcjonalne) |
| Lokalizacje, Centra zysku | Wartości segmentu wskazanego dla każdego z nich (opcjonalne) |
| Dostawcy | `AP_SUPPLIERS`, `AP_SUPPLIER_SITES_ALL`, `AP_TERMS_TL` (opcjonalne) |
| Pozycje otwarte, Płatności | Tabele należności, zobowiązań i banków (opcjonalne) |
| Pozycje faktur dostawców | `AP_INVOICE_LINES_ALL` z dokumentami zobowiązań (opcjonalne) |
| Zamówienia zakupu | Tabele `PO_`, `RCV_TRANSACTIONS` i pozycje faktur (opcjonalne) |
| Stany magazynowe | `MTL_MATERIAL_TRANSACTIONS`, `MTL_SECONDARY_INVENTORIES` (opcjonalne) |
| Koszty standardowe | `CST_STANDARD_COSTS` (opcjonalne) |
| Budżet | Salda budżetowe `GL_BALANCES`, `GL_BUDGETS`, `GL_BUDGET_VERSIONS` (opcjonalne) |
| Środki trwałe, Ruchy środków trwałych | Tabele `FA_` (opcjonalne) |

Gdy ładowanie wskaże tabelę, której agent nie może odczytać, poproś administratora o nadanie na niej SELECT i załaduj ponownie. Nienadanie uprawnień do tabeli opcjonalnej skutkuje ostrzeżeniem wskazującym tę tabelę, a wszystko inne jest ładowane. Pozycje otwarte, płatności, faktury dostawców, zamówienia zakupu, koszty standardowe, zapasy, budżety, środki trwałe oraz saldo na koniec miesiąca i salda bankowe zachowują wiersze, które już miały, dopóki tabeli nie będzie można odczytać.
