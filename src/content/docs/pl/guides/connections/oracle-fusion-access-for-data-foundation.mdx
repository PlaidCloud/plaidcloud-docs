[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jednym Common Finance Model, a Oracle Fusion Cloud ERP to jeden z systemów ERP, które odczytuje bezpośrednio. Połączenie z Oracle Fusion korzysta z poświadczeń klienta OAuth 2.0, użytkownika integracji tylko do odczytu oraz niewielkiego zestawu raportów BI Publisher. Ta strona jest przeznaczona dla administratora Oracle Fusion, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła hasła ani klucza tajnego klienta e-mailem.

## Wyślij prośbę o dostęp

Na karcie **Foundation** projektu wybierz **Utwórz nowe połączenie** w sekcji **Połączenie Oracle Fusion**. Formularz pokazuje pełną prośbę. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Read-only Oracle Fusion Cloud ERP access for PlaidCloud (OAuth 2.0 client credentials)”.

## Co konfiguruje administrator Oracle Fusion

<Steps>

1. **Utwórz użytkownika integracji** i nadaj mu rolę zawodową, która może wyświetlać następujące dane dla każdej księgi, dla której raportujesz:

   - Księga główna: księgi, kalendarze księgowe i statusy okresów, partie dziennika, dzienniki i salda kont (na przykład „General Accountant” z dostępem do danych tych ksiąg)
   - Kursy przeliczania walut (kursy dzienne)
   - Etykiety segmentów key flexfield, zbiory wartości i ich hierarchia kont (drzewa)
   - Należności: faktury i ich rozksięgowania oraz konta klientów
   - Pozycje zapasów
   - Prawo uruchamiania raportów BI Publisher z kroku 3 oraz ERP Integration Service (zadania ESS)

2. **Zarejestruj aplikację poufną** w domenie tożsamości (IAM) z przepływem client credentials i zakresem interfejsu REST API Fusion Applications. Skopiuj jej identyfikator klienta i klucz tajny.

3. **Wdróż dziewięć raportów BI Publisher** w `/Custom/PlaidCloud/DataFoundation`. Każdy z nich działa jako zadanie ESS, z nazwą raportu jako definicją zadania, i zwraca plik CSV z kolumnami wymienionymi w prośbie:

   | Raport | Co zwraca |
   |---|---|
   | `PlaidCloudKeyFlexLabels` | Jeden wiersz na segment każdego planu kont Księgi głównej: jego pozycję, etykietę i zbiór wartości |
   | `PlaidCloudSegmentValues` | Każdą wartość tych zbiorów wartości, z typem konta naturalnego i hierarchią wartości |
   | `PlaidCloudCalendar` | Okresy księgowe każdej księgi, z typami kursów średnich okresowych i na koniec okresu |
   | `PlaidCloudCodeCombinations` | Kombinacje kodów i ich segmenty |
   | `PlaidCloudBalances` | Salda otwarcia każdej księgi |
   | `PlaidCloudJournalLines` | Pozycje dziennika, odczytywane po jednej księdze, okresie i wartości segmentu bilansującego |
   | `PlaidCloudCustomers` | Konta klientów i nazwy ich stron |
   | `PlaidCloudItems` | Pozycje głównej organizacji zapasów |
   | `PlaidCloudSalesLines` | Jeden wiersz na pozycję faktury Należności |

   Dokładne kolumny każdego raportu znajdują się w treści prośby na karcie **Foundation**. Podaj nazwy raportów dokładnie tak, jak pokazano.

</Steps>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Host Twojego adresu URL Fusion Applications, bez `https://` | **Host poda** |
| Adres URL tokenu domeny tożsamości | **Token URL** |
| Zakres aplikacji REST API | **Zakres** |
| Identyfikator klienta z kroku 2 | **Identyfikator klienta** |
| Klucz tajny klienta z kroku 2 | **Klucz tajny klienta** |
| Wartości segmentu bilansującego, które PlaidCloud może odczytywać | W polu **Balancing segment values** (Fusion nie może ich wylistować): wpisz jedną wartość w polu **Nazwa** lub pozostaw puste, aby załadować wszystkie |

Zamykająca lista prośby wymaga podania tych wartości razem. Przekaż klucz tajny klienta przez menedżera haseł, a nie e-mailem. Zespół użytkownika PlaidCloud sam wkleja go do PlaidCloud.

## Sprawdź dostęp

Po powrocie do PlaidCloud wprowadź wartości i kliknij **Testuj połączenie**. Każdy zbiór danych jest oznaczony jako **Dostępne do odczytu**, **Brak uprawnienia** lub **Błąd**:

| Zbiór danych | Skąd jest odczytywany |
|---|---|
| Jednostki, Kalendarz fiskalny, Plan kont, Działy | Księgi oraz raporty etykiet key flexfield, wartości segmentów i kalendarza |
| Kursy walut | Dzienne kursy przeliczania |
| Księga główna | Partie dziennika i raport pozycji dziennika |
| Bilans próbny | Raporty sald i kombinacji kodów |
| Klienci, Produkty, Pozycje sprzedaży | Raporty klientów, pozycji i pozycji sprzedaży (opcjonalne) |

Gdy brakuje zbioru danych, test wskazuje, które uprawnienie dodać. Poproś administratora o dodanie go do roli zawodowej i przetestuj ponownie. Klienci, Produkty i Pozycje sprzedaży są opcjonalne: pod Fusion, który ich nie zawiera, nadal ładuje wszystko inne.
