[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jednym Common Finance Model, a SAP S/4HANA to jeden z systemów ERP, które odczytuje bezpośrednio. PlaidCloud łączy się z systemem przez agenta [PlaidLink](/pl/reference/cli/plaidlink/) zainstalowanego w Twojej sieci, przez RFC. Ta strona jest przeznaczona dla administratora SAP, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła hasła e-mailem.

## Wyślij prośbę o dostęp

Na karcie **Foundation** projektu wybierz **Utwórz nowe połączenie** w sekcji **SAP S/4HANA connection**. Formularz pokazuje pełną prośbę oraz link **How to set up PlaidLink**. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Read-only SAP S/4HANA access for PlaidCloud (through PlaidLink)”.

## Co konfiguruje administrator SAP

<Steps>

1. **Zainstaluj pakiet ABAP PlaidCloud** (grupa funkcji `Z_PLAIDCL_B5_READ_TABLE`) w kliencie, z którego raportujesz, i zainstaluj agenta PlaidLink, który ma dostęp do systemu przez RFC.

2. **Utwórz użytkownika komunikacyjnego**, na przykład `PLAIDCLOUD_RFC`, z rolą zawierającą te autoryzacje:

   - `S_RFC`: wykonywanie grupy funkcji `Z_PLAIDCL_B5_READ_TABLE`.
   - `S_TABU_NAM` (wyświetlanie, `ACTVT` 03) dla poniższych tabel.

   | Tabele | Co zawierają |
   |---|---|
   | `T001` | Kody firm |
   | `T009`, `T009B`, `T001B` | Warianty roku obrotowego i okresy księgowania |
   | `SKA1`, `SKAT` | Konta księgi głównej |
   | `FAGL_011PC`, `FAGL_011ZC` | Wersja sprawozdania finansowego |
   | `CSKS`, `CSKT` | Centra kosztów |
   | `SETHEADER`, `SETNODE` | Grupy centrów kosztów i centrów zysku |
   | `CEPC`, `CEPCT` | Centra zysku (opcjonalne) |
   | `KNA1`, `KNVV`, `KNVH` | Klienci i ich hierarchia |
   | `MARA`, `MAKT`, `T006A` | Materiały i jednostki miary |
   | `TCURR`, `TCURF`, `TCURX` | Kursy wymiany i miejsca dziesiętne walut |
   | `ACDOCA` | Zapisy dziennika księgi wiodącej i jej przeniesienie sald |
   | `VBRK`, `VBRP`, `PRCD_ELEMENTS` | Dokumenty fakturowania i ich warunki |
   | `ACDOCP` | Dane planu |
   | `COSR` | Statystyczne wskaźniki |
   | `T001K`, `MBEW`, `MBEWH` | Obszary wyceny i wartości zapasów materiałów |

3. **Odpowiedz na pytania księgowe** (zobacz poniżej).

</Steps>

### Pytania, na które odpowiada administrator

| Administrator informuje Cię o | Wprowadzasz w PlaidCloud w sekcji System settings |
|---|---|
| Typie kursu wymiany, który zawiera kurs średni. PlaidCloud uśrednia kursy tego typu z każdego miesiąca. Często jest to `M`. | `average_rate_type` |
| Typie kursu wymiany, który zawiera kurs zamknięcia, czyli kurs na koniec miesiąca. Jeśli nie wskażesz żadnego, kursem zamknięcia jest kurs `M`. | `closing_rate_type` |
| Wersji sprawozdania finansowego, która raportuje zarządczy rachunek zysków i strat oraz bilans | `fsv` |
| Tym, które z jej węzłów to przychody, koszt własny sprzedanych towarów, koszty operacyjne, pozycje nieoperacyjne, aktywa, zobowiązania, kapitał własny i pozycje wewnątrzgrupowe | `intercompany_nodes` dla węzłów wewnątrzgrupowych. Formularz nie ma pola dla pozostałych typów węzłów. |
| Tym, że przeniesienie sald (`FAGLGVTR`) zostało uruchomione dla każdego raportowanego roku obrotowego | Nic do wprowadzenia. Salda otwarcia są z niego odczytywane. |

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Identyfikator systemu i serwer aplikacji (lub serwer komunikatów i grupa logowania) | **Application server** oraz **Numer systemu** |
| Klient (client) | **Klient** |
| Nazwa użytkownika komunikacyjnego | **Użytkownik** |
| Hasło użytkownika komunikacyjnego, przez menedżera haseł | **Hasło**, które Twój zespół wkleja samodzielnie |
| Nazwa agenta PlaidLink, który łączy się z systemem | `agent` w sekcji System settings |
| Kody firm, które PlaidCloud może odczytywać | W polu **Company codes** (system nie może ich wylistować przed ładowaniem): wpisz jeden kod firmy w polu **Nazwa** lub pozostaw puste, aby załadować wszystkie kody firm |

<Aside type="caution">
Nigdy nie wysyłaj hasła e-mailem. **Hasło** jest sekretem: jest przechowywane w połączeniu i nigdy więcej nie jest pokazywane.
</Aside>

## Sprawdź dostęp

Po powrocie do PlaidCloud wprowadź wartości i kliknij **Testuj połączenie**. Każdy zbiór danych jest oznaczony jako **Dostępne do odczytu**, **Brak uprawnienia** lub **Błąd**:

| Zbiór danych | Tabele, które odczytuje |
|---|---|
| Jednostki | `T001` |
| Kalendarz fiskalny | `T001`, `T009`, `T009B`, `T001B` |
| Kursy walut | `TCURR`, `TCURF` |
| Plan kont | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC` |
| Działy | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| Centra zysku | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| Klienci | `KNA1`, `KNVV`, `KNVH` |
| Produkty | `MARA`, `MAKT`, `T006A` |
| Księga główna | `ACDOCA` |
| Bilans próbny | Przeniesienie sald z `ACDOCA` |
| Pozycje sprzedaży | `VBRK`, `VBRP`, `PRCD_ELEMENTS` |
| Budżet | `ACDOCP` |
| Klucze alokacji | `COSR` |
| Stany magazynowe | `T001K`, `MBEW`, `MBEWH` |

Gdy zbiór danych ma status **Brak uprawnienia**, poproś administratora o dodanie tabeli do roli i przetestuj ponownie. Centra zysku, pozycje sprzedaży, budżet, klucze alokacji i stany magazynowe są opcjonalne: system, który któregoś z nich nie zawiera, nadal ładuje wszystko inne.
