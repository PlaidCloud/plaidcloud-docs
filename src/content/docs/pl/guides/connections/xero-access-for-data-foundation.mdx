[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i księgowych, w tylu instancjach, ile masz, w jednym Common Finance Model. Xero to jeden z systemów, które odczytuje bezpośrednio, jedna organizacja Xero na połączenie. Ta strona jest przeznaczona dla administratora Xero, który konfiguruje dostęp, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła hasła e-mailem.

## Wyślij prośbę o dostęp

Na karcie **Foundation** projektu wybierz **Utwórz nowe połączenie** i wybierz **Xero**. Formularz pokazuje pełną prośbę. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Read-only Xero access for PlaidCloud”.

## Co konfiguruje administrator Xero

<Steps>

1. **Autoryzuj aplikację Xero PlaidCloud** dla każdej organizacji, dla której raportujesz, logując się jako użytkownik z rolą Standard lub Advanced. Aplikacja prosi wyłącznie o dostęp do odczytu:

   | Zakres | Co obejmuje |
   |---|---|
   | `accounting.settings.read` | Organizację, plan kont, kategorie śledzenia, pozycje |
   | `accounting.contacts.read` | Klientów |
   | `accounting.transactions.read` | Faktury sprzedaży i noty kredytowe |
   | `accounting.journals.read` | Księgę główną: każdy zaksięgowany dziennik |
   | `accounting.reports.read` | Zestawienie obrotów i sald, dla sald otwarcia |

   Bez `accounting.journals.read` księga główna nie może zostać załadowana. Plan kont, działy, klienci i produkty nadal się ładują.

2. **Skonfiguruj kategorie śledzenia, które odczytuje PlaidCloud**, pod tymi nazwami:

   - **Department:** jedna opcja na dział, nazwana tak, jak ma się pojawiać jego kod.
   - **Intercompany:** jedna opcja na spółkę grupy, nazwana kodem jednostki tej spółki, na pozycjach zapisów wewnątrzgrupowych. Nazywaj konta wewnątrzgrupowe tak, aby „Intercompany” było częścią nazwy konta.

</Steps>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Identyfikator tenanta organizacji (Xero wyświetla go przy połączeniu lub pod `GET /connections`) | **Organisation (tenant) ID** |
| Potwierdzenie, że koniec roku finansowego organizacji i data blokady okresu są ustawione | Nic do wprowadzenia: PlaidCloud odczytuje oba z Xero |

Użytkownik PlaidCloud sam wkleja **Refresh token**; jest to sekret i nigdy nie jest wysyłane e-mailem. Wybiera też wartość w polu **Organizacja**, pod którą połączenie jest ładowane.

W sekcji **System settings** pole **Retained earnings account** wskazuje konto kapitału własnego (Equity), do którego przechodzi otwierający rachunek zysków i strat, gdy nazwy kont tego jeszcze nie określają. Jest opcjonalne.

## Sprawdź dostęp

Po powrocie do PlaidCloud kliknij **Testuj połączenie**. Każdy zbiór danych jest oznaczony jako **Dostępne do odczytu**, **Brak uprawnienia** lub **Błąd**:

| Zbiór danych | Wymagany zakres |
|---|---|
| Jednostki | `accounting.settings.read` |
| Plan kont | `accounting.settings.read` |
| Działy | `accounting.settings.read` (kategoria śledzenia Department) |
| Produkty | `accounting.settings.read` |
| Kalendarz fiskalny | `accounting.settings.read` |
| Klienci | `accounting.contacts.read` |
| Księga główna | `accounting.journals.read` |
| Bilans próbny | `accounting.reports.read` |
| Pozycje sprzedaży (opcjonalne) | `accounting.transactions.read` |
| Budżet (opcjonalne) | `accounting.reports.read` |

Gdy zbiór danych ma status **Brak uprawnienia**, test wskazuje zakres do nadania. Autoryzuj aplikację ponownie z tym zakresem i przetestuj ponownie. Organizacja Xero bez faktur sprzedaży lub budżetów nadal ładuje wszystko inne.

Kursy walut nie są częścią tego dostępu: Xero ich nie publikuje. Zamiast tego dostarcz je w pliku **Kursy walut**.
