[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jednym Common Finance Model, a SAP S/4HANA Cloud to jeden z systemów ERP, które odczytuje bezpośrednio. Połączenie odczytuje wydane usługi OData tenanta za pomocą poświadczeń klienta OAuth 2.0; nie uczestniczy w tym żaden agent. Ta strona jest przeznaczona dla administratora S/4HANA Cloud, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła hasła ani klucza tajnego klienta e-mailem.

## Wyślij prośbę o dostęp

Na karcie **Foundation** projektu wybierz **Utwórz nowe połączenie** w sekcji **Połączenie SAP S/4HANA Cloud**. Formularz pokazuje pełną prośbę. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Read-only SAP S/4HANA Cloud access for PlaidCloud (OAuth 2.0 client credentials)”.

## Co konfiguruje administrator S/4HANA Cloud

<Steps>

1. **Utwórz użytkownika komunikacyjnego** dla PlaidCloud w aplikacji **Maintain Communication Users**. Jego metoda uwierzytelniania to OAuth 2.0 albo nazwa użytkownika i hasło, zależnie od wymagań Twojego środowiska.

2. **Utwórz system komunikacyjny** dla PlaidCloud w aplikacji **Communication Systems**, z tym użytkownikiem dla komunikacji przychodzącej i z poświadczeniami klienta OAuth 2.0.

3. **Utwórz ustalenie komunikacyjne** dla każdego poniższego scenariusza w aplikacji **Communication Arrangements**, wszystkie dla systemu z kroku 2. Razem udostępniają usługi OData, które odczytuje PlaidCloud:

   | Scenariusz | Usługa |
   |---|---|
   | Company Code | `API_COMPANYCODE_SRV` |
   | G/L Account in Chart of Accounts | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | Cost Center | `API_COSTCENTER_SRV` |
   | Business Partner and Customer | `API_BUSINESS_PARTNER` |
   | Product | `API_PRODUCT_SRV` |
   | Fiscal Year Variant Periods | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | Exchange Rates | `API_EXCHANGERATE_SRV` |
   | Journal Entry Item | `API_JOURNALENTRYITEMBASIC_SRV` (dziennik i przeniesione saldo) |
   | Billing Document | `API_BILLING_DOCUMENT_SRV` (opcjonalne: dodaje fakturowaną sprzedaż, dokumenty i pozycje) |

   Nadaj użytkownikowi komunikacyjnemu dostęp do każdego kodu firmy, dla którego raportujesz.

</Steps>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Host API tenanta, na przykład `my300000-api.s4hana.cloud.sap` | **Host** |
| Identyfikator klienta | **Identyfikator klienta** |
| Klucz tajny klienta, przez bezpieczny formularz połączenia | **Klucz tajny klienta**, który Twój zespół wkleja samodzielnie |
| Adres URL tokenu, tylko jeśli Twoje środowisko używa serwera autoryzacji XSUAA zamiast własnego serwera tenanta (`/sap/bc/sec/oauth2/token`) | **Token URL (optional)** |
| Zakres, tylko przy serwerze autoryzacji XSUAA | **Scope (optional)** |
| Czy **Carry Forward Balances** zostało uruchomione dla każdego ładowanego roku obrotowego | Nic do wprowadzenia. Salda otwarcia są z niego odczytywane. |

<Aside type="caution">
Nigdy nie wysyłaj klucza tajnego klienta e-mailem. **Klucz tajny klienta** jest sekretem: jest przechowywany w połączeniu i nigdy więcej nie jest pokazywany.
</Aside>

## Sprawdź dostęp

Po powrocie do PlaidCloud wprowadź wartości i kliknij **Testuj połączenie**. Każdy zbiór danych jest oznaczony jako **Dostępne do odczytu**, **Brak uprawnienia** lub **Błąd**:

| Zbiór danych | Wymagana usługa |
|---|---|
| Jednostki | `API_COMPANYCODE_SRV` |
| Plan kont | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| Działy | `API_COSTCENTER_SRV` |
| Klienci | `API_BUSINESS_PARTNER` |
| Produkty | `API_PRODUCT_SRV` |
| Kursy walut | `API_EXCHANGERATE_SRV` |
| Kalendarz fiskalny | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| Księga główna | `API_JOURNALENTRYITEMBASIC_SRV` |
| Bilans próbny | `API_JOURNALENTRYITEMBASIC_SRV` |
| Pozycje sprzedaży | `API_BILLING_DOCUMENT_SRV` (opcjonalne) |

Gdy zbiór danych ma status **Brak uprawnienia**, poproś administratora o dodanie ustalenia komunikacyjnego dla jego usługi i przetestuj ponownie. Pozycje sprzedaży, budżet i stany magazynowe są opcjonalne: tenant, który któregoś z nich nie zawiera, nadal ładuje wszystko inne.
