[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jednym Common Finance Model, a Dynamics 365 Finance and Operations to jeden z systemów ERP, które odczytuje bezpośrednio. Połączenie korzysta z aplikacji Microsoft Entra ID z kluczem tajnym klienta dla danych głównych oraz z punktu końcowego SQL Fabric (Synapse) Link dla dziennika głównego. Ta strona jest przeznaczona dla administratora Dynamics 365, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła klucza tajnego klienta ani hasła SQL e-mailem.

## Wyślij prośbę o dostęp

Na karcie **Foundation** projektu wybierz **Utwórz nowe połączenie** w sekcji **Dynamics 365 Finance and Operations connection**. Formularz pokazuje pełną prośbę. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Read-only Dynamics 365 Finance and Operations access for PlaidCloud”.

## Co konfiguruje administrator Dynamics 365

<Steps>

1. **Zarejestruj aplikację w Microsoft Entra ID** dla PlaidCloud, z kluczem tajnym klienta. Zanotuj jej Application (client) ID, Directory (tenant) ID oraz klucz tajny.

2. **Przypisz aplikację do użytkownika.** W Dynamics 365, w sekcji **System administration > Setup > Microsoft Entra ID applications**, dodaj identyfikator klienta i przypisz go do użytkownika z rolą, która może wyświetlać następujące dane dla każdej jednostki prawnej, którą chcesz załadować:

   - Księga główna: jednostki prawne, kalendarze fiskalne, konta główne, wartości wymiarów finansowych, kursy wymiany
   - Należności: klienci i pozycje faktur klientów
   - Zarządzanie informacjami o produktach: zwolnione produkty
   - Zarządzanie zapasami: stany bieżące i transakcje magazynowe (opcjonalne)
   - Budżetowanie: wpisy rejestru budżetu (opcjonalne)

3. **Skonfiguruj Fabric Link dla dziennika głównego.** Pozycje dziennika głównego są odczytywane z punktu końcowego SQL Fabric (Synapse) Link, a nie z usługi OData. Potwierdź, że Fabric Link jest włączony dla tych tabel, i utwórz na tym punkcie końcowym login SQL tylko do odczytu dla PlaidCloud:

   - `generaljournalaccountentry`
   - `generaljournalentry`
   - `fiscalcalendarperiod`
   - `dimensionattributelevelvalue`, z jednym wierszem na wartość wymiaru dla każdej kombinacji wymiarów finansowych i z nazwą jej wymiaru

</Steps>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Adres URL środowiska, `https://<name>.operations.dynamics.com` | **Adres URL środowiska** |
| Directory (tenant) ID | **Directory (tenant) ID** |
| Application (client) ID | **Application (client) ID** |
| Punkt końcowy SQL Fabric Link, baza danych i login | Osobne połączenie SQL w PlaidCloud, wybierane w ustawieniu systemowym `fabric_connection_id` |
| Kategorie kont głównych dla Twoich kont kosztu własnego sprzedanych towarów (PlaidCloud zakłada `COGS`) | Ustawienie systemowe `cogs_categories` |
| Kategorie kont głównych dla kont nieoperacyjnych: odsetki, podatek dochodowy, zyski i straty z różnic kursowych, pozostałe przychody | Ustawienie systemowe `non_operating_categories` |
| Wymiar finansowy, który nazywa partnera wewnątrzgrupowego pozycji (PlaidCloud zakłada `IntercompanyPartner`) | Ustawienie systemowe `ic_partner_dimension` |
| Jednostki prawne, które PlaidCloud może odczytywać | Wybierane w polu **Legal entities** w PlaidCloud |

Klucz tajny klienta i hasło loginu SQL nigdy nie są wysyłane e-mailem. Zespół użytkownika PlaidCloud sam wkleja **Klucz tajny klienta** do PlaidCloud, a połączenie SQL przechowuje login SQL. Jednostki prawne będące jednostkami konsolidacyjnymi trafiają do ustawienia systemowego `consolidation_companies`, aby ich księgowania nie były liczone jako aktywność firmy.

## Sprawdź dostęp

Po powrocie do PlaidCloud wprowadź wartości i kliknij **Testuj połączenie**. Każdy zbiór danych jest oznaczony jako **Dostępne do odczytu**, **Brak uprawnienia** lub **Błąd**:

| Zbiór danych | Wymagane uprawnienie |
|---|---|
| Jednostki | Księga główna: wyświetlanie jednostek prawnych |
| Kalendarz fiskalny | Księga główna: wyświetlanie kalendarzy fiskalnych |
| Plan kont | Księga główna: wyświetlanie kont głównych |
| Działy | Księga główna: wyświetlanie wartości wymiarów finansowych |
| Klienci | Należności: wyświetlanie klientów |
| Produkty | Zarządzanie informacjami o produktach: wyświetlanie zwolnionych produktów |
| Kursy walut | Księga główna: wyświetlanie kursów wymiany |
| Bilans próbny, Księga główna | Wyświetlanie księgi głównej (dziennik, przez Fabric Link) |
| Pozycje sprzedaży, Stany magazynowe, Budżet | Opcjonalne |

Gdy brakuje zbioru danych, test wskazuje uprawnienie do dodania. Poproś administratora o dodanie go do roli i przetestuj ponownie. Pozycje sprzedaży, Stany magazynowe i Budżet są opcjonalne: środowisko, które ich nie zawiera, nadal ładuje wszystko inne.
