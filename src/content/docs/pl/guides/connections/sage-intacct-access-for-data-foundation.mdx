[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jednym Common Finance Model, a Sage Intacct to jeden z systemów ERP, które odczytuje bezpośrednio. Połączenie korzysta z Intacct Web Services: autoryzacji nadawcy dla PlaidCloud i użytkownika Web Services tylko do odczytu. Ta strona jest przeznaczona dla administratora Sage Intacct, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła hasła e-mailem.

## Wyślij prośbę o dostęp

Na karcie **Foundation** projektu wybierz **Utwórz nowe połączenie** w sekcji **Połączenie Sage Intacct**. Formularz pokazuje pełną prośbę. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Read-only Sage Intacct access for PlaidCloud (Web Services)”.

## Co konfiguruje administrator Sage Intacct

<Steps>

1. **Autoryzuj PlaidCloud jako nadawcę Web Services.** W sekcji **Company > Admin > Web Services authorizations** dodaj Sender ID podany przez PlaidCloud. Odeślij Sender ID oraz hasło nadawcy (Sender password) wydane przez Sage.

2. **Utwórz użytkownika Web Services.** W sekcji **Company > Admin > Users** utwórz użytkownika typu „Business” z opcją „Web services only” oraz rolę z uprawnieniem **View** do:

   | Obszar | Obiekty |
   |---|---|
   | Księga główna | Konta, zapisy dziennika (wszystkie dzienniki, w tym dzienniki korekt), salda kont, okresy raportowania, kursy wymiany, budżety |
   | Firma | Jednostki (lokalizacje), działy, klasy, projekty |
   | Należności | Klienci |
   | Kontrola zapasów | Pozycje |
   | Wprowadzanie zamówień | Transakcje (faktury sprzedaży oraz noty kredytowe i zwroty, które je cofają), jeśli chcesz uwzględnić sprzedaż |

   Nadaj użytkownikowi dostęp do najwyższego poziomu firmy i do każdej jednostki, dla której raportuje PlaidCloud. Jeśli definicje transakcji not kredytowych i zwrotów nie nazywają się Sales Credit Memo i Sales Return, przekaż użytkownikowi PlaidCloud ich nazwy.

3. **Zezwól na adres IP użytkownika**, jeśli Twoja firma ogranicza Web Services według adresu IP.

</Steps>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Identyfikator firmy | **ID firmy** |
| Identyfikator użytkownika Web Services | **Web services user ID** |
| Hasło użytkownika Web Services | **Web services password** |
| Sender ID | **Sender ID** |
| Hasło nadawcy | **Sender password** |
| Nazwy Twoich definicji transakcji not kredytowych i zwrotów, jeśli nie są domyślne | Ustawienie systemowe `credit_documents` (domyślnie: Sales Credit Memo, Sales Return) |
| Jednostki, które PlaidCloud może odczytywać | Wybierane w polu **Jednostki** w PlaidCloud |

Hasła przekazuj przez menedżera haseł, nigdy e-mailem. Zespół użytkownika PlaidCloud sam wkleja **Web services password** i **Sender password** do PlaidCloud. Jednostki będące własnymi eliminacjami Twojej firmy trafiają do ustawienia systemowego `elimination_entities`.

## Sprawdź dostęp

Po powrocie do PlaidCloud wprowadź wartości i kliknij **Testuj połączenie**. Każdy zbiór danych jest oznaczony jako **Dostępne do odczytu**, **Brak uprawnienia** lub **Błąd**:

| Zbiór danych | Wymagane uprawnienie |
|---|---|
| Jednostki | Firma: jednostki (wyświetlanie) |
| Plan kont | Księga główna: konta i konta statystyczne (wyświetlanie) |
| Działy | Firma: działy (wyświetlanie) |
| Klienci | Należności: klienci (wyświetlanie) |
| Produkty | Kontrola zapasów: pozycje (wyświetlanie) |
| Kursy walut | Księga główna: kursy wymiany (wyświetlanie) |
| Kalendarz fiskalny | Księga główna: okresy raportowania (wyświetlanie) |
| Bilans próbny | Księga główna: salda kont (wyświetlanie) |
| Księga główna | Księga główna: zapisy dziennika (wyświetlanie) |
| Pozycje sprzedaży | Wprowadzanie zamówień: transakcje (wyświetlanie) |
| Budżet | Księga główna: budżety (wyświetlanie) |
| Klucze alokacji | Księga główna: salda kont (wyświetlanie) |

Gdy brakuje zbioru danych, test wskazuje uprawnienie do dodania. Poproś administratora o dodanie go do roli i przetestuj ponownie. Pozycje sprzedaży, Budżet i Klucze alokacji są opcjonalne: firma, która ich nie używa, nadal ładuje wszystko inne.
