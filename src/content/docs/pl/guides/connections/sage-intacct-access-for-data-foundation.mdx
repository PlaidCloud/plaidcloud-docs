[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jednym Common Finance Model, a Sage Intacct to jeden z systemów ERP, które odczytuje bezpośrednio. Połączenie korzysta z Intacct Web Services: autoryzacji nadawcy dla PlaidCloud i użytkownika Web Services tylko do odczytu. Ta strona jest przeznaczona dla administratora Sage Intacct, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Nikt nie wysyła hasła e-mailem.

## Wyślij prośbę o dostęp

Na stronie projektu **Systemy**, w sekcji **Data Foundation** w obszarze **Strona główna**, wybierz swój system w polu **System** w sekcji **Dodaj system** i kliknij **Brak jeszcze dostępu?**. System czeka na dostęp, a wyświetlana jest jedna prośba obejmująca systemy projektu. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem „Dostęp do PlaidCloud”.

## Co konfiguruje administrator Sage Intacct

<Steps>

1. **Autoryzuj PlaidCloud jako nadawcę Web Services.** W sekcji **Company > Admin > Web Services authorizations** dodaj Sender ID podany przez PlaidCloud. Odeślij Sender ID oraz hasło nadawcy (Sender password) wydane przez Sage.

2. **Utwórz użytkownika Web Services.** W sekcji **Company > Admin > Users** utwórz użytkownika typu „Business” z opcją „Web services only” oraz rolę z uprawnieniem **View** do:

   | Obszar | Obiekty |
   |---|---|
   | Księga główna | Konta, konta statystyczne, zapisy dziennika (wszystkie dzienniki, w tym dzienniki korekt), salda kont, okresy raportowania, kursy wymiany, budżety |
   | Firma | Jednostki (lokalizacje), działy, klasy, projekty |
   | Należności | Klienci, faktury, korekty, płatności |
   | Zobowiązania | Dostawcy, rachunki, korekty, płatności |
   | Cash Management | Rachunki bieżące |
   | Kontrola zapasów | Pozycje |
   | Wprowadzanie zamówień | Transakcje (faktury sprzedaży oraz noty kredytowe i zwroty, które je cofają), jeśli chcesz uwzględnić sprzedaż |

   Nadaj użytkownikowi dostęp do najwyższego poziomu firmy i do każdej jednostki, dla której raportuje PlaidCloud. Jeśli definicje transakcji not kredytowych i zwrotów nie nazywają się Sales Credit Memo i Sales Return, przekaż użytkownikowi PlaidCloud ich nazwy.

3. **Zezwól na adres IP użytkownika**, jeśli Twoja firma ogranicza Web Services według adresu IP.

</Steps>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Identyfikator firmy | **ID firmy** |
| Identyfikator użytkownika Web Services | **Nazwa użytkownika usługi internetowej** |
| Sender ID | **Identyfikator klienta** |
| Hasło nadawcy | **Klucz tajny klienta** |
| Nazwy Twoich definicji transakcji not kredytowych i zwrotów, jeśli nie są domyślne | Ustawienie systemowe **Credit memo and return document types** (domyślnie: Sales Credit Memo, Sales Return) |
| Jednostki, które PlaidCloud może odczytywać | W sekcji **Opcje**, w polu **Spółki**: zaznacz je lub nie zaznaczaj żadnej, aby odczytywać wszystkie |

Hasła przekazuj przez menedżera haseł, nigdy e-mailem. Zespół użytkownika PlaidCloud sam wprowadza hasło nadawcy jako **Klucz tajny klienta**. Jednostki będące własnymi eliminacjami Twojej firmy trafiają do ustawienia systemowego **Elimination entities**.

## Sprawdź dostęp

Po powrocie do PlaidCloud, gdy system zostanie już dodany, kliknij **Testuj połączenie** w jego wierszu na stronie **Systemy**. Test odczytuje wymagane zbiory danych i oznacza każdy z nich jako **Czytelne**, **Brak uprawnienia** lub **Błąd**. Opcjonalne zbiory danych, oznaczone poniżej, nie są objęte testem: jeśli Sage Intacct odmówi odczytu któregoś z nich, po następnym ładowaniu sprawdzenia gotowości na pulpicie **CFM-Accounting - Close and assurance** wskażą obiekt, do którego należy nadać uprawnienie.

| Zbiór danych | Wymagane uprawnienie |
|---|---|
| Jednostki | Firma: jednostki (wyświetlanie) |
| Plan kont | Księga główna: konta i konta statystyczne (wyświetlanie) |
| Działy | Firma: działy (wyświetlanie) |
| Klienci | Należności: klienci (wyświetlanie) |
| Produkty | Kontrola zapasów: pozycje (wyświetlanie) |
| Kursy walut | Księga główna: kursy wymiany (wyświetlanie) |
| Kalendarz fiskalny | Księga główna: okresy raportowania (wyświetlanie) |
| Bilans próbny | Księga główna: salda kont (wyświetlanie) |
| Księga główna | Księga główna: zapisy dziennika (wyświetlanie) |
| Saldo na koniec miesiąca (opcjonalne) | Księga główna: salda kont (wyświetlanie) |
| Salda bankowe (opcjonalne) | Cash Management: rachunki bieżące (wyświetlanie), z saldem na koniec miesiąca |
| Lokalizacje (opcjonalne) | Firma: jednostki (lokalizacje) (wyświetlanie) |
| Centra zysku (opcjonalne) | Firma: klasy (wyświetlanie) |
| Projekty (opcjonalne) | Firma: projekty (wyświetlanie) |
| Dostawcy (opcjonalne) | Zobowiązania: dostawcy (wyświetlanie) |
| Pozycje sprzedaży (opcjonalne) | Wprowadzanie zamówień: transakcje (wyświetlanie) |
| Pozycje faktur dostawców (opcjonalne) | Zobowiązania: rachunki i korekty (wyświetlanie) |
| Pozycje otwarte i Płatności (opcjonalne) | Należności: faktury, korekty i płatności oraz Zobowiązania: rachunki, korekty i płatności (wyświetlanie) |
| Budżet (opcjonalne) | Księga główna: budżety (wyświetlanie) |
| Klucze alokacji (opcjonalne) | Księga główna: salda kont (wyświetlanie) |

Gdy brakuje zbioru danych, test wskazuje uprawnienie do dodania. Poproś administratora o dodanie go do roli i przetestuj ponownie. Firma, która nie używa opcjonalnego zbioru danych, nadal ładuje wszystko inne. Gdy Sage Intacct odmawia odczytu, na podstawie którego za dany miesiąc budowane są faktury dostawców, pozycje otwarte lub płatności, ten miesiąc zachowuje wiersze, które już miał, i jest odczytywany ponownie przy następnym ładowaniu.

Informacje o tym, kto i kiedy wprowadził dziennik, kto go zatwierdził i co stornuje, są odczytywane z partii dziennika. Rola, która nie może odczytać partii, pozostawia je puste.
