[Data Foundation](/pl/guides/projects/data-foundation/) łączy dane ze wszystkich podłączonych systemów ERP i ich instancji w jeden Common Finance Model, a Microsoft Dynamics 365 Business Central to jeden z systemów ERP, które odczytuje bezpośrednio. Połączenie wykorzystuje aplikację Microsoft Entra ID z poświadczeniami klienta, zestaw uprawnień tylko do odczytu oraz kilka obiektów stron opublikowanych jako usługi sieci Web. Ta strona jest przeznaczona dla administratora Business Central, który to konfiguruje, oraz dla użytkownika PlaidCloud, który go o to prosi.

PlaidCloud tylko odczytuje dane. Klucza tajnego klienta nigdy nie wysyła się e-mailem.

## Wysyłanie żądania dostępu

Na karcie **Foundation** projektu wybierz **Utwórz nowe połączenie** w sekcji **Połączenie Business Central**. Formularz pokazuje pełną treść żądania. Kliknij **Kopiuj żądanie**, aby wkleić ją do własnej wiadomości, lub **Wyślij żądanie e-mailem**, aby otworzyć ją w programie pocztowym z tematem "Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials)."

## Co konfiguruje administrator Business Central

<Steps>

1. **Zarejestruj aplikację w Microsoft Entra ID.** W sekcji **App registrations > New registration** dodaj klucz tajny klienta i zapisz identyfikator katalogu (dzierżawy), identyfikator aplikacji (klienta) oraz klucz tajny.

2. **Dodaj aplikację w Business Central.** Otwórz **Microsoft Entra Applications**, dodaj aplikację, ustaw jej stan na **Włączone** i nadaj jej zestawy uprawnień **D365 READ** oraz **D365 BASIC** dla każdej firmy, dla której tworzysz raporty. Nie nadawaj jej zestawu uprawnień do zapisu.

3. **Opublikuj obiekty stron jako usługi sieci Web.** W sekcji **Search > Web Services > New** opublikuj te obiekty stron dokładnie z podanymi wartościami **Nazwa usługi** i zaznaczonym polem **Published**. Standardowy interfejs API nie zawiera ich pól:

   | Strona | Nazwa usługi | Uwagi |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | Koszt sprzedanych towarów; opcjonalne |
   | 120 G/L Budget Entries | `GLBudgetEntries` | Budżety; opcjonalne |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | Klucze statystyczne; opcjonalne |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | Wymiary skrótów od 3 do 8; opcjonalne |
   | 479 Dimension Set Entries | `DimensionSetEntries` | Wymiary skrótów od 3 do 8; opcjonalne |

4. **Przekaż użytkownikowi PlaidCloud dwie decyzje:** kod źródłowy, pod którym księgowane są korekty audytowe (PlaidCloud zakłada `ADJUSTMENT`), oraz wymiar odpowiadający działowi (PlaidCloud zakłada Global Dimension 1 o nazwie `DEPARTMENT`).

</Steps>

## Co odesłać

| Administrator przesyła | Wprowadzane w PlaidCloud jako |
|---|---|
| Identyfikator katalogu (dzierżawy) | **Directory (tenant) ID** |
| Nazwę środowiska, na przykład `production` | **Nazwa środowiska** |
| Identyfikator aplikacji (klienta) | **Application (client) ID** |
| Klucz tajny klienta | **Klucz tajny klienta**, wprowadzany przez formularz, nie e-mailem |
| Nazwę wymiaru odpowiadającego działowi | Ustawienie systemowe `department_dimension` |
| Firmy, które PlaidCloud może odczytywać | Wybierane w sekcji **Companies** w PlaidCloud (co najmniej jedna) |

Firmy będące firmami konsolidacyjnymi trafiają do ustawienia systemowego `consolidation_companies`, dzięki czemu ich zapisy nie są liczone jako aktywność żadnej firmy. Kursy walutowe pochodzą z jednej firmy: wskaż ją w ustawieniu systemowym `rate_company`, w przeciwnym razie PlaidCloud użyje pierwszej firmy.

## Sprawdzanie dostępu

Po powrocie do PlaidCloud wprowadź wartości i kliknij **Testuj połączenie**. Każdy zbiór danych jest oznaczony jako **Dostępne do odczytu**, **Brak uprawnienia** lub **Błąd**:

| Zbiór danych | Czego wymaga |
|---|---|
| Jednostki, Plan kont, Klienci, Produkty, Kursy walut, Bilans próbny | Dostępu do interfejsu API (zestaw uprawnień D365 READ) |
| Kalendarz fiskalny | Usługi sieci Web `AccountingPeriods` |
| Działy | Usługi sieci Web `DimensionValues` |
| Księga główna | Usługi sieci Web `GLEntries` |
| Pozycje sprzedaży, Budżet, Klucze alokacji | Opcjonalne |

Gdy brakuje zbioru danych, test wskazuje, które uprawnienie lub którą usługę sieci Web należy dodać. Poproś administratora o jej dodanie i przetestuj ponownie. Pozycje sprzedaży, Budżet i Klucze alokacji są opcjonalne: środowisko, które ich nie używa, nadal ładuje wszystko pozostałe.
