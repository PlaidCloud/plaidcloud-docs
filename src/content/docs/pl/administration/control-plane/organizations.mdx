Organizacja jest administracyjną granicą powiązanych obszarów roboczych PlaidCloud. Ustawienia organizacji określają nazwę wyświetlaną w płaszczyźnie sterowania, metadane rozliczeniowe, działanie SSO oraz osoby, które mogą administrować organizacją.

## Lista organizacji

Strona **Organizations** pokazuje organizacje, do których masz dostęp. W tabeli możesz:

1. Wyszukiwać organizacje według widocznych pól tabeli.
2. Odświeżać listę organizacji.
3. Wyświetlać szczegóły organizacji.
4. Edytować ustawienia organizacji, jeśli masz dostęp administratora.
5. Otwierać zarządzanie dostępem do organizacji, jeśli masz dostęp do zabezpieczeń.
6. Otwierać rekordy rozliczeniowe (**Otwórz rozliczenia**), jeśli masz dostęp do rozliczeń.

## Ustawienia organizacji

| Ustawienie | Opis |
| --- | --- |
| Nazwa | Nazwa wyświetlana organizacji. |
| Identyfikator | Stały identyfikator organizacji. Jest ustawiany podczas tworzenia organizacji. |
| Notatka | Wewnętrzna notatka lub opis wyświetlany w płaszczyźnie sterowania. |
| Plan | Plan handlowy: Enterprise, Zespół lub Free. |
| Numer podatkowy | Identyfikator podatkowy używany w rekordach rozliczeniowych. |
| Aktywna | Określa, czy organizacja jest aktywna. |
| Zablokowana | Po włączeniu uniemożliwia zwykłe zmiany organizacji. |
| Wymagaj SSO | Wymaga, aby członkowie logowali się przez konfigurację logowania jednokrotnego organizacji. |

## Metadane rozliczeniowe

Pola rozliczeniowe opisują sposób rozliczania organizacji. Same w sobie nie przyznają dostępu do produktu.

| Ustawienie | Opcje |
| --- | --- |
| Cykl rozliczeniowy | Miesięczny, kwartalny, półroczny, roczny |
| Cena rozliczeniowa | Kwota liczbowa rozliczenia dla wybranego cyklu. |
| Typ płatności | Faktura na podstawie zamówienia, wersja próbna, bezpłatnie, płatność zaplanowana |

## Działanie SSO

| Ustawienie | Opis |
| --- | --- |
| Dynamiczne przypisywanie grup | Pozwala, aby informacje o grupach SSO sterowały przypisywaniem ról w organizacji. |
| Dynamiczne tworzenie użytkowników | Pozwala, aby logowanie SSO automatycznie tworzyło użytkowników, gdy dostawca tożsamości wyśle zaakceptowanego użytkownika. |
| Nazwa grupy SSO do dynamicznego przypisywania | Nazwa grupy SSO używana do dynamicznego przypisywania. |

<Aside type="note">
	Skonfiguruj dostawcę tożsamości dla obszaru roboczego w jego [oknie dialogowym Single sign-on](/pl/administration/control-plane/workspace-configuration/#logowanie-jednokrotne); konfiguracja SAML jest opisana w przewodnikach po zarządzaniu dostępem. Te ustawienia płaszczyzny sterowania określają, jak organizacja korzysta z konfiguracji SSO po jej utworzeniu.
</Aside>

## Zarządzanie dostępem

Użyj opcji **Manage Access**, aby zapraszać osoby do organizacji i przypisywać role w organizacji.

1. Otwórz **Organizations**.
2. Wybierz organizację.
3. Otwórz **Manage Access**.
4. Kliknij **Invite User**, aby zaprosić jeden lub więcej adresów e-mail.
5. Wybierz role, które każda osoba ma otrzymać.
6. Dodaj opcjonalną wiadomość niestandardową.
7. Wyślij zaproszenie.

Możesz edytować role zaakceptowanych użytkowników, usuwać zaakceptowanych użytkowników lub anulować oczekujące zaproszenia. Oczekujących użytkowników nie można edytować, dopóki nie zaakceptują zaproszenia.

## Role w organizacji

| Rola | Do czego służy |
| --- | --- |
| Administrator | Ustawienia organizacji i zmiany na poziomie administratora. |
| Obszar roboczy | Tworzenie obszarów roboczych, konfiguracja, wydania oraz wstrzymywanie i wznawianie. |
| Zabezpieczenia | Zaproszenia i zarządzanie rolami w organizacji. |
| Rozliczenia | Dostęp do rekordów rozliczeniowych. |
