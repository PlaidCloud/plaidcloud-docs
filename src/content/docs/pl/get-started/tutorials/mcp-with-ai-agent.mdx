Ten samouczek pokazuje, jak skonfigurować agenta kodowania AI do pracy z Twoim obszarem roboczym PlaidCloud za pomocą **Model Context Protocol** (MCP). Po skonfigurowaniu możesz prosić agenta o odczyt tabel, uruchamianie przepływów pracy, budowanie alokacji i odpowiadanie na pytania o dane — bezpośrednio z edytora.

Zajmuje około 20 minut. Działa z Claude Code, Cursor, Claude Desktop, ChatGPT, GitHub Copilot i dowolnym klientem zgodnym z MCP.

## Co zbudujesz

Działające połączenie między agentem kodowania AI a Twoim obszarem roboczym PlaidCloud, dzięki któremu agent może:

- wyświetlać projekty, tabele, przepływy pracy i wymiary,
- odczytywać zawartość tabel,
- przeglądać definicje przepływów pracy,
- wyzwalać uruchomienia przepływów pracy,
- odpowiadać na pytania o Twoje dane bez przełączania kontekstu.

## Wymagania wstępne

- Obszar roboczy PlaidCloud ([rozpocznij bezpłatny okres próbny](https://app.plaidcloud.com), jeśli go nie masz)
- Agent kodowania AI, którego już używasz — Claude Code, Cursor, Claude Desktop, ChatGPT, Copilot lub Gemini
- Agent musi obsługiwać MCP (większość obecnych narzędzi AI to robi)

## Krok 1: znajdź adres URL MCP swojego obszaru roboczego

Każdy obszar roboczy PlaidCloud udostępnia punkt końcowy MCP pod adresem:

```text
https://<your-workspace>.plaid.cloud/mcp
```

Zastąp `<your-workspace>` poddomeną swojego obszaru roboczego — tą samą, której używasz do logowania się w interfejsie PlaidCloud.

## Krok 2: uzyskaj token uwierzytelniania

<Steps>

1. Po zalogowaniu się do PlaidCloud w przeglądarce odwiedź:
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. Skopiuj token okaziciela wyświetlony na stronie. Przechowuj go bezpiecznie — daje taki sam dostęp, jaki ma Twoje konto.

</Steps>

<Aside type="caution">
Traktuj token jak hasło. Omija interaktywne uwierzytelnianie i działa w Twoim imieniu. Jeśli wycieknie, unieważnij go w tym samym punkcie końcowym.
</Aside>

## Krok 3: skonfiguruj agenta

<Tabs>

<TabItem label="Claude Code">

Uruchom w terminalu:

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

Aby użyć uwierzytelniania statycznym tokenem (bez przepływu OAuth, prostsze przy długich sesjach), otwórz w przeglądarce adres URL z kroku 2, skopiuj wyświetlony fragment konfiguracji i wklej go do pliku `.mcp.json`.

Zobacz [konfigurację Claude Code](/pl/integrations/ai-coding-agents/claude-code/), aby poznać wszystkie opcje.

</TabItem>

<TabItem label="Cursor">

Pobierz token okaziciela z `https://<your-workspace>.plaid.cloud/mcp/setup/token` i dodaj poniższy fragment do konfiguracji MCP w Cursorze:

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

Zobacz [konfigurację Cursor](/pl/integrations/ai-coding-agents/cursor/), aby poznać wszystkie opcje.

</TabItem>

<TabItem label="Claude Desktop">

Otwórz Settings → Developer → MCP Servers i dodaj:

- **Adres URL serwera**: `https://<your-workspace>.plaid.cloud/mcp`
- Po wyświetleniu monitu użyj logowania OAuth

Zobacz [konfigurację Claude Desktop](/pl/integrations/ai-coding-agents/claude-desktop/), aby poznać wszystkie opcje.

</TabItem>

<TabItem label="ChatGPT">

1. Settings → Connectors → Add custom connector
2. Wprowadź:
   - **Nazwa**: `PlaidCloud`
   - **Adres URL serwera MCP**: `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT przekieruje Cię do PlaidCloud w celu zalogowania przez OAuth. Zatwierdź połączenie.
4. Włącz konektor w każdej rozmowie, w której ma być używany.

Zobacz [konfigurację ChatGPT](/pl/integrations/ai-coding-agents/chatgpt/), aby poznać wszystkie opcje.

</TabItem>

<TabItem label="Copilot">

Pobierz token okaziciela i dodaj go do `.vscode/mcp.json`:

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

VSCode odczytuje ten plik przy uruchomieniu i przy każdej jego zmianie.

Zobacz [konfigurację Copilot](/pl/integrations/ai-coding-agents/copilot/), aby poznać wszystkie opcje.

</TabItem>

</Tabs>

## Krok 4: zweryfikuj połączenie

Zadaj agentowi proste pytanie:

> „Wyświetl projekty w moim obszarze roboczym PlaidCloud."

Agent powinien odpowiedzieć listą Twoich projektów. Jeśli tak się nie stanie, skorzystaj z poniższych wskazówek dotyczących rozwiązywania problemów.

## Krok 5: wypróbuj prawdziwe zadania

Po połączeniu spróbuj:

- **Poznaj swoje dane**: „Jakie kolumny ma tabela `sales` w moim projekcie Quickstart?"
- **Uruchom przepływ pracy**: „Uruchom przepływ pracy `monthly_close` w projekcie Financials i daj mi znać, kiedy się zakończy."
- **Zbuduj coś**: „Utwórz krok Table Lookup w moim przepływie pracy Test, który filtruje zamówienia z ostatnich 30 dni."

Odpowiedzi agenta będą oparte na rzeczywistym stanie Twojego obszaru roboczego, a nie na ogólnikach.

## Rozwiązywanie problemów

Jeśli agent nie może połączyć się z PlaidCloud lub zwraca błędy uwierzytelniania:

- **Token wygasł** — odśwież go pod adresem `https://<your-workspace>.plaid.cloud/mcp/setup/token`
- **Nieprawidłowe zakresy** — niektóre narzędzia wymagają określonych zakresów PlaidCloud (np. `analyze.workflow.write`). Uruchom w agencie `mcp_introspect(name='<tool>')`, aby zobaczyć wymagane zakresy
- **Nieprawidłowa poddomena obszaru roboczego** — potwierdź ją, logując się do interfejsu PlaidCloud; poddomena to część przed `.plaid.cloud`

Więcej informacji znajdziesz w [rozwiązywaniu problemów z agentami kodowania AI](/pl/integrations/ai-coding-agents/troubleshooting/).
