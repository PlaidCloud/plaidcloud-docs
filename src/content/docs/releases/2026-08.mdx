## Fixed

- **Exporting a project no longer fails because of one unreadable table.** If a table listed in the project has no data behind it, the export used to abandon the whole archive and leave no file at all. It now archives everything else, leaves that table's data out, and finishes with a message naming the tables it skipped. The archive records those tables, and importing it names them again — so a table that came back empty is reported rather than presented as complete. The export window also names the project it is archiving. See [Archive a Project](/guides/projects/archive-a-project/).
