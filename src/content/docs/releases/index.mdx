## How These Notes Are Produced

Each monthly summary aggregates the substantive changes that shipped to tenants during that calendar month. Pure infrastructure work (image bumps, internal refactors, RC cuts, secret rotation, observability tuning) is grouped into theme labels rather than listed line-by-line. If a month had customer-visible features, they're called out explicitly with an Added / Changed / Fixed / Security structure.

For specifics on any particular release, contact your account team.

Looking ahead, every new monthly summary lands here as it's published.
