[Data Foundation](/guides/projects/data-foundation/) brings data from every ERP system and instance you connect into one Common Finance Model, and SAP ECC is one of the ERPs it reads directly. PlaidCloud reaches the system through a [PlaidLink](/reference/cli/plaidlink/) agent installed on your own network, over RFC. This page is for the SAP administrator who sets that up, and for the PlaidCloud user who asks them to.

PlaidCloud only reads data. Nobody sends a password by email.

## Send the Access Request

On the project's **Systems** page, under **Data Foundation** in **Home**, choose your system in **System** under **Add a system** and click **Don't have access yet?**. The system waits for access, and one request covering the project's systems is shown. Click **Copy request** to paste it into your own message, or **Email request** to open it in your mail program with the subject "Access for PlaidCloud."

## What the SAP Administrator Sets Up

<Steps>

1. **Install the PlaidCloud ABAP package** (function group of `Z_PLAIDCL_B5_READ_TABLE`) in the client you report from, and install a PlaidLink agent that can reach the system over RFC.

2. **Create a communication user**, for example `PLAIDCLOUD_RFC`, with a role holding these authorizations:

   - `S_RFC`: execute the function group of `Z_PLAIDCL_B5_READ_TABLE`.
   - `S_TABU_NAM` (display, `ACTVT` 03) for the tables below.

   | Tables | What they hold |
   |---|---|
   | `T001` | Company codes |
   | `T009`, `T009B`, `T001B` | Fiscal year variants and posting periods |
   | `SKA1`, `SKAT` | G/L accounts |
   | `FAGL_011PC`, `FAGL_011ZC` | Financial statement version |
   | `CSKS`, `CSKT` | Cost centers |
   | `SETHEADER`, `SETNODE` | Cost center and profit center groups |
   | `CEPC`, `CEPCT` | Profit centers (optional) |
   | `KNA1`, `KNVV`, `KNVH` | Customers and their hierarchy |
   | `MARA`, `MAKT`, `T006A` | Materials and units |
   | `TCURR`, `TCURF`, `TCURX` | Exchange rates and currency decimals |
   | `BKPF`, `BSEG` | Accounting documents and their line items |
   | `FAGLFLEXT`, or on the classic general ledger `GLT0` | General ledger totals |
   | `CSKB`, `CSKU`, `COEP` | Cost elements and controlling line items: assessments and allocations |
   | `COSP`, `COSS`, `COSR` | Cost center plan and statistical key figures (optional) |
   | `VBRK`, `VBRP`, `KONV` | Billing documents and their pricing conditions (optional) |
   | `T001K`, `MBEW`, `MBEWH` | Valuation areas, material stock values and standard prices (optional) |
   | `T001W`, `TKA02` | Plants, read as sites, and the controlling area of each company code (optional) |
   | `T016T`, `TKUKT`, `KNVP`, `TSPAT`, `T052U` | Industry and customer classification names, each customer's sales employee, division and payment term names (optional) |
   | `T012K`, `T012T` | House bank accounts, for bank balances (optional) |
   | `LFA1`, `LFB1` | Suppliers (optional) |
   | `RBKP`, `RSEG` | Supplier invoices (optional) |
   | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` | Purchase orders and their receipts and invoices (optional) |
   | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095`, `ANLC`, `ANEP`, `ANEA`, `ANLP` | The fixed asset register and its movements (optional) |
   | The operating concern's line item table (`CE1` followed by its name) | CO-PA by valuation (optional) |

   Open items and payments are read from the customer and vendor line items of `BSEG`, with their `BKPF` headers.

3. **Answer the accounting questions** (see below).

</Steps>

### Questions the Administrator Answers

| The administrator tells you | You enter it in PlaidCloud under **System settings** |
|---|---|
| The exchange rate type that holds the average rate. PlaidCloud averages that type's rates of each month. It is often `M`. | **Average rate type** |
| The exchange rate type that holds the closing rate, its rate at month end. If you name none, the closing rate is the `M` rate. | **Closing rate type** |
| Whether the system runs the new general ledger (`FAGLFLEXT`) or the classic one (`GLT0`) | **General ledger totals table** |
| The financial statement version that reports management P&L and balance sheet | **Financial statement version** |
| Which of its nodes are revenue, cost of goods sold, operating expense, non-operating, asset, liability, equity and intercompany | **Account type of each statement node**: one line per node, as `node = type`, with a type the box lists, such as `Revenue` or `Asset`. **Intercompany statement nodes** names the intercompany nodes. Both apply only when **Financial statement version** is set. |
| That the balance carryforward has run for each fiscal year you report (`FAGLGVTR`, or `F.16` on the classic general ledger) | Nothing to enter. The opening balances are read from the totals table. |
| The depreciation area of each asset book, accounting or tax. The first is the register's. PlaidCloud assumes area `01` is the accounting book. | **Depreciation area of each book** |
| The movement type of each asset transaction type, by its first digit. PlaidCloud assumes `1` addition, `2` disposal, `3` transfer, `6` depreciation and `9` opening. | **Movement type of each transaction type** |
| The operating concern's line item table, if you want CO-PA by valuation. With none named, no CO-PA is read. | **Operating concern line item table** |
| The CO-PA value field of each account, and which of them are costs | **Value field of each CO-PA account**, **CO-PA cost value fields** |

## What to Send Back

| The administrator sends | Entered in PlaidCloud as |
|---|---|
| The system ID and the application server (or message server and logon group) | **Host** and **System Number**, or, with **Use Load Balanced Multi-System Connection**, **MS Host**, **MS Server**, **System ID** and **Group** |
| The client | **Client** |
| The communication user's name | **User** |
| The communication user's password, through your password manager | **Password**, which your team enters itself |
| The name of the PlaidLink agent that reaches the system | The **PlaidLink agent** system setting |
| The company codes PlaidCloud may read | Under **Options**, **Companies**, which SAP can't list: enter the company codes, separated by commas, or leave it empty to load every company code |

<Aside type="caution">
Never email the password. **Password** is a secret: it is stored on the connection and never shown again.
</Aside>

## Check the Access

SAP is read through a PlaidLink agent, so **Test connection** doesn't read it: the first load does, and names a table the user may not read. Each dataset reads:

| Dataset | Tables it reads |
|---|---|
| Entities | `T001` |
| Fiscal calendar | `T001`, `T009`, `T009B`, `T001B` |
| Currency rates | `TCURR`, `TCURF` |
| Chart of accounts | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC`, `CSKB`, `CSKU` |
| Departments | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| Profit centers | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| Customers | `KNA1`, `KNVV`, `KNVH` |
| Products | `MARA`, `MAKT`, `T006A` |
| General ledger | `BKPF`, `BSEG`, `COEP` |
| Trial balance | `FAGLFLEXT` or `GLT0` |
| Sales lines | `VBRK`, `VBRP`, `KONV` |
| Budget | `COSP`, `COSS` |
| Allocation drivers | `COSR` |
| Inventory balances | `MBEW`, `MBEWH`, `T001K` |
| Month-end balance | `FAGLFLEXT` or `GLT0`, the balance at each month end |
| Bank balances | `T012K`, `T012T`, with the month-end balance of each house bank's G/L account |
| Sites | `T001W`, `T001K` |
| Suppliers | `LFA1`, `LFB1` |
| Supplier invoice lines | `RBKP`, `RSEG`, `BKPF` |
| Purchase orders | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` |
| Open items, Payments | `BSEG` customer and vendor line items, `BKPF` |
| Fixed assets | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095` |
| Asset movements | `ANLC`, `ANEP`, `ANEA`, `ANLP` |
| Standard costs | `T001K`, `MBEW`, `MBEWH` |
| CO-PA by valuation | The table named in **Operating concern line item table** |

When a load names a table the user may not read, ask the administrator to add it to the role and load again. Profit centers, sales lines, budget, allocation drivers, inventory balances and every dataset from month-end balance down are optional: a system that doesn't hold one still loads everything else. A month's bank balances, open items or payments that SAP refuses keep the rows they already had.

House bank accounts that share a G/L account have one balance row between them, as the G/L account has one balance.
