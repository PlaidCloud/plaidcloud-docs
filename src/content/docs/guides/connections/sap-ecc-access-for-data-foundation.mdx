[Data Foundation](/guides/projects/data-foundation/) brings data from every ERP system and instance you connect into one Common Finance Model, and SAP ECC is one of the ERPs it reads directly. PlaidCloud reaches the system through a [PlaidLink](/reference/cli/plaidlink/) agent installed on your own network, over RFC. This page is for the SAP administrator who sets that up, and for the PlaidCloud user who asks them to.

PlaidCloud only reads data. Nobody sends a password by email.

## Send the Access Request

On the project's **Foundation** tab, choose **Create a new connection** under **SAP ECC connection**. The form shows the full request and a **How to set up PlaidLink** link. Click **Copy request** to paste it into your own message, or **Email request** to open it in your mail program with the subject "Read-only SAP ECC access for PlaidCloud (through PlaidLink)."

## What the SAP Administrator Sets Up

<Steps>

1. **Install the PlaidCloud ABAP package** (function group of `Z_PLAIDCL_B5_READ_TABLE`) in the client you report from, and install a PlaidLink agent that can reach the system over RFC.

2. **Create a communication user**, for example `PLAIDCLOUD_RFC`, with a role holding these authorizations:

   - `S_RFC`: execute the function group of `Z_PLAIDCL_B5_READ_TABLE`.
   - `S_TABU_NAM` (display, `ACTVT` 03) for the tables below.

   | Tables | What they hold |
   |---|---|
   | `T001` | Company codes |
   | `T009`, `T009B`, `T001B` | Fiscal year variants and posting periods |
   | `SKA1`, `SKAT` | G/L accounts |
   | `FAGL_011PC`, `FAGL_011ZC` | Financial statement version |
   | `CSKS`, `CSKT` | Cost centers |
   | `SETHEADER`, `SETNODE` | Cost center and profit center groups |
   | `CEPC`, `CEPCT` | Profit centers (optional) |
   | `KNA1`, `KNVV`, `KNVH` | Customers and their hierarchy |
   | `MARA`, `MAKT`, `T006A` | Materials and units |
   | `TCURR`, `TCURF`, `TCURX` | Exchange rates and currency decimals |
   | `BKPF`, `BSEG` | Accounting documents and their line items |
   | `FAGLFLEXT`, or on the classic general ledger `GLT0` | General ledger totals |
   | `CSKB`, `CSKU`, `COEP` | Cost elements and controlling line items: assessments and allocations |
   | `COSP`, `COSS`, `COSR` | Cost center plan and statistical key figures (optional) |
   | `VBRK`, `VBRP`, `KONV` | Billing documents and their pricing conditions (optional) |

3. **Answer the accounting questions** (see below).

</Steps>

### Questions the Administrator Answers

| The administrator tells you | You enter it in PlaidCloud under System settings |
|---|---|
| The exchange rate type that holds the average rate. PlaidCloud averages that type's rates of each month. It is often `M`. | `average_rate_type` |
| The exchange rate type that holds the closing rate, its rate at month end. If you name none, the closing rate is the `M` rate. | `closing_rate_type` |
| Whether the system runs the new general ledger (`FAGLFLEXT`) or the classic one (`GLT0`) | `totals` |
| The financial statement version that reports management P&L and balance sheet | `fsv` |
| Which of its nodes are revenue, cost of goods sold, operating expense, non-operating, asset, liability, equity and intercompany | `intercompany_nodes` for the intercompany nodes. The form has no field for the other node types. |
| That the balance carryforward has run for each fiscal year you report (`FAGLGVTR`, or `F.16` on the classic general ledger) | Nothing to enter. The opening balances are read from the totals table. |

## What to Send Back

| The administrator sends | Entered in PlaidCloud as |
|---|---|
| The system ID and the application server (or message server and logon group) | **Application server**, and **System number** |
| The client | **Client** |
| The communication user's name | **User** |
| The communication user's password, through your password manager | **Password**, which your team pastes in itself |
| The name of the PlaidLink agent that reaches the system | `agent` under System settings |
| The company codes PlaidCloud may read | Under **Company codes**, which the system can't list before a load: enter one company code under **Name**, or leave it blank to load every company code |

<Aside type="caution">
Never email the password. **Password** is a secret: it is stored on the connection and never shown again.
</Aside>

## Check the Access

Back in PlaidCloud, enter the values and click **Test connection**. Each dataset shows as **Readable**, **Missing permission** or **Error**:

| Dataset | Tables it reads |
|---|---|
| Entities | `T001` |
| Fiscal calendar | `T001`, `T009`, `T009B`, `T001B` |
| Currency rates | `TCURR`, `TCURF` |
| Chart of accounts | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC`, `CSKB`, `CSKU` |
| Departments | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| Profit centers | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| Customers | `KNA1`, `KNVV`, `KNVH` |
| Products | `MARA`, `MAKT`, `T006A` |
| General ledger | `BKPF`, `BSEG`, `COEP` |
| Trial balance | `FAGLFLEXT` or `GLT0` |
| Sales lines | `VBRK`, `VBRP`, `KONV` |
| Budget | `COSP`, `COSS` |
| Allocation drivers | `COSR` |
| Inventory balances | `MBEW`, `MBEWH`, `T001K` |

When a dataset shows **Missing permission**, ask the administrator to add the table to the role and test again. Profit centers, sales lines, budget, allocation drivers and inventory balances are optional: a system that doesn't hold one still loads everything else.
