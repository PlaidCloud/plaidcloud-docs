[Data Foundation](/guides/projects/data-foundation/) brings data from every ERP system and instance you connect into one Common Finance Model. Workday is one of the systems it reads directly. Workday has no web service for journal lines or balances, so this page is for the Workday administrator who builds the reports it reads, and for the PlaidCloud user who asks them to.

PlaidCloud only reads data. Nobody sends a password by email.

## Send the Access Request

On the project's **Systems** page, under **Data Foundation** in **Home**, choose your system in **System** under **Add a system** and click **Don't have access yet?**. The system waits for access, and one request covering the project's systems is shown, with the report specification for Workday. Click **Copy request** to paste it into your own message, or **Email request** to open it in your mail program.

## What the Workday Administrator Sets Up

<Steps>

1. **Build eighteen custom reports (RaaS)**, thirteen of them optional, and share them with the integration system user. Use the column names exactly: Data Foundation maps by name, so a renamed column can't be read. Every code column is the object's Reference ID, not a descriptor such as "C100 Acme US". Every report's output format is JSON.

2. **Grant the Financial_Management web services** `Get_Workday_Companies` and `Get_Currency_Conversion_Rates` to the same user.

3. **Send the report URLs** and the integration system user's details.

</Steps>

| Report | Required | Contents |
|---|---|---|
| Journal Lines | Yes | One row per posted journal line. Prompts: Company (the line's company, as a Reference ID) and Period (the fiscal period's Reference ID). Includes the worktags Region, Fund, Program and Project, the Intercompany affiliate, amounts in transaction and ledger currency, and the book, plus the site (location), the journal source, the document date, who created and approved it and when it was created, the journal it reverses, and its tax code and amount |
| Beginning Balances | Yes | One row per company, fiscal period and ledger account, for every period: the balance at the start of the period and, in Ending_Balance, at its end. The ending balance is the month-end balance the ledger is compared with; without it, the ledger is compared with its own opening balance |
| Ledger Accounts | Yes | Account, name, type, intercompany flag, optional category and parent account |
| Cost Centers | Yes | Cost center, name and parent |
| Fiscal Periods | Yes | One row per company and fiscal period, adjustment periods too, with start, end and status |
| Headcount | Optional | Active staff at each period end, by cost center, with FTE |
| Worktag Values | Optional | One row per Region, Fund, Program and Project value, with parent |
| Customers | Optional | Customer, name, parent, category, region, country, industry, segment and first invoice date |
| Sales Items | Optional | Item, name, parent, group, unit of measure and family |
| Sales Invoice Lines | Optional | One row per customer invoice line, with quantity, gross, discount, net and cost amounts, site, due date, terms, tax and the amount in the invoice's currency |
| Statistical Drivers | Optional | Units produced, square feet and the like, by company, period end and driver |
| Suppliers | Optional | Supplier, name, parent, category, country, payment terms and tax ID |
| Customer Invoices | Optional | Every customer invoice and credit memo over the history, for open receivables at each month end |
| Supplier Invoices | Optional | The same for supplier invoices, for open payables |
| Supplier Invoice Lines | Optional | One row per supplier invoice line, with account, cost center, site, project, item, quantity, price and tax |
| Payments | Optional | One row for each document a payment settles, and one for what it left on account |
| Bank Balances | Optional | Each bank account's own balance at each period end |
| Budgets | Optional | Budgets and forecasts by scenario, version, company, period end, account and cost center |

The full column list of each report is in the access request. A few rules apply to what the reports return:

- Only Posted journal lines load, and only the Actuals ledger. Commitment and Obligation ledgers don't.
- A blank Book_Code is the primary book. A blank line counts in every book of its company and period, and a line with a Book_Code belongs to that book alone.
- The line's company wins over the journal's.
- Ledger_Account_Type_ID is Revenue, COGS, Opex, NonOperating, Asset, Liability or Equity. Workday has one Expense type, which loads as Opex. To separate cost of goods sold or non-operating expense, print a calculated field that returns COGS or NonOperating. An account with no type isn't loaded into the profit and loss.
- Draft, In Progress, Canceled and Denied invoices and payments don't load.
- In the Payments report, a credit memo or adjustment applied to a document, an adjustment or a write-off moves no money: print it as rows with Payment_Type_ID `Applied Credit`, `Adjustment` or `Write-off`. They settle open items and aren't payments.
- An optional report you don't build leaves what depends on it empty. Without Customer Invoices, Supplier Invoices, Supplier Invoice Lines, Payments or Bank Balances, the months they feed aren't loaded and the load warns.
- Adaptive Planning is not connected.

## What to Send Back

| The administrator sends | Saved on the Workday connection as |
|---|---|
| The Workday host | **Workday host** |
| The tenant name | **Tenant** |
| The integration system user's name | **Integration system user** |
| The URL of each required report | **Journal Lines report URL**, **Beginning Balances report URL**, **Ledger Accounts report URL**, **Cost Centers report URL**, **Fiscal Periods report URL** |
| The URL of each optional report you built | **Headcount report URL (optional)**, **Worktag Values report URL (optional)**, **Customers report URL (optional)**, **Sales Items report URL (optional)**, **Sales Invoice Lines report URL (optional)**, **Statistical Drivers report URL (optional)**, **Suppliers report URL (optional)**, **Customer Invoices report URL (optional)**, **Supplier Invoices report URL (optional)**, **Supplier Invoice Lines report URL (optional)**, **Payments report URL (optional)**, **Bank Balances report URL (optional)**, **Budgets report URL (optional)** |
| The Reference IDs of the companies PlaidCloud may read | Under **Options**, **Companies** when you add the system: tick them, or none for every company |

The PlaidCloud user enters the integration system user's password on the connection themselves; it's a secret and is never emailed. The report URLs are settings of the connection, not **System settings**.

Under **System settings**, **Retained earnings account** names the Equity account the opening profit and loss rolls into, when the account names don't already say. It's optional.

<Aside type="note">
Workday's one Expense type loads as Opex, and Data Foundation's readiness check flags it. If your cost of goods sold or non-operating accounts need to be told apart, use the calculated field described above.
</Aside>

## Check the Access

Back in PlaidCloud, once the system is added, click **Test connection** on its row on the **Systems** page. It reads the required datasets and shows each as **Readable**, **Missing permission** or **Error**. The optional ones aren't part of the test:

| Dataset | Comes from |
|---|---|
| Entities | `Get_Workday_Companies` |
| Chart of accounts | The Ledger Accounts report |
| Departments | The Cost Centers report |
| Fiscal calendar | The Fiscal Periods report |
| Currency rates | `Get_Currency_Conversion_Rates` |
| Trial balance | The Beginning Balances report |
| General ledger | The Journal Lines report |
| Allocation drivers (optional) | The Headcount and Statistical Drivers reports |
| Segment values (optional) | The Worktag Values report |
| Customers (optional) | The Customers report |
| Products (optional) | The Sales Items report |
| Sales lines (optional) | The Sales Invoice Lines report |
| Suppliers (optional) | The Suppliers report |
| Month-end balance (optional) | The Beginning Balances report's Ending_Balance |
| Bank balances (optional) | The Bank Balances report |
| Supplier invoice lines (optional) | The Supplier Invoice Lines and Supplier Invoices reports |
| Open items (optional) | The Customer Invoices, Supplier Invoices and Payments reports |
| Payments (optional) | The Payments report |
| Budget (optional) | The Budgets report |

When a dataset shows **Missing permission**, the test names the report or web service. Ask the administrator to share it with the integration system user and test again. A tenant without the optional reports still loads everything else.
