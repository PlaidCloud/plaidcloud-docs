[Data Foundation](/guides/projects/data-foundation/) brings data from every ERP system and instance you connect into one Common Finance Model, and Oracle E-Business Suite is one of the ERPs it reads directly. PlaidCloud reaches EBS through a [PlaidLink](/reference/cli/plaidlink/) agent installed inside your network, never directly. This page is for the EBS administrator who sets that up, and for the PlaidCloud user who asks them to.

PlaidCloud only reads data. Nobody sends a password by email.

## Send the Access Request

On the project's **Foundation** tab, choose **Create a new connection** under **Oracle E-Business Suite connection**. The form shows the full request and a **How to set up PlaidLink** link. Click **Copy request** to paste it into your own message, or **Email request** to open it in your mail program with the subject "Read-only Oracle E-Business Suite access for PlaidCloud (through PlaidLink)."

## What the EBS Administrator Sets Up

<Steps>

1. **Install PlaidLink** on a server that can reach the EBS database, and register it in PlaidCloud.

2. **Grant SELECT** to the PlaidLink APPS-schema user (or a read-only schema user with synonyms to the APPS objects) on:

   | Area | Objects |
   |---|---|
   | General Ledger | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES` |
   | Flexfields | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | Sales (optional) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |

3. **Name an application user** (`FND_USER`) and a responsibility that can see every ledger and balancing segment value you want reported.

4. **Describe the chart of accounts.** Say which segments are the balancing segment, the natural account, the cost centre and the intercompany segment (their segment qualifiers). PlaidCloud types an expense account as cost of goods sold when it or a parent value above it is described as cost of goods sold, cost of sales or cost of revenue. It types an account as non-operating when one of them names interest income or expense, finance income or cost, foreign exchange, income tax expense, or other income and expense. Tell PlaidCloud if your parent values use other words for these.

5. **Confirm the rate types.** Each primary ledger names its period-average and period-end rate types, in the ledger's translation options. PlaidCloud translates with the daily rates of those two types.

</Steps>

<Aside type="caution">
The wrong responsibility returns another ledger's rows without an error. Confirm it with your general ledger owner.
</Aside>

## What to Send Back

| The administrator sends | Entered in PlaidCloud as |
|---|---|
| The database host | **Database host** |
| The database port | **Database port** (1521 unless you change it) |
| The service name | **Service name** |
| The APPS schema user | **APPS schema user** |
| The APPS schema password, through the secure connection form | **APPS schema password**, which your team pastes in itself |
| The `FND_USER` | **Application user (FND_USER)** |
| The responsibility key | **Responsibility key** |
| The balancing segment values PlaidCloud may read | Under **Balancing segment values**, which the system can't list before a load: enter one value under **Name**, or leave it blank to load every entity of the primary ledger |

The PlaidLink agent that reaches the instance is chosen under System settings as `agent`.

<Aside type="caution">
Never email the password. **APPS schema password** is a secret: it is stored on the connection and never shown again.
</Aside>

## Check the Access

Back in PlaidCloud, enter the values and click **Test connection**. Each dataset shows as **Readable**, **Missing permission** or **Error**:

| Dataset | Objects it reads |
|---|---|
| Entities | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| Fiscal calendar | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| Chart of accounts | `GL_CODE_COMBINATIONS`, the flexfield tables |
| Departments | `GL_CODE_COMBINATIONS`, the flexfield tables |
| Currency rates | `GL_DAILY_RATES` |
| General ledger | `GL_JE_HEADERS`, `GL_JE_LINES` |
| Trial balance | `GL_BALANCES` |
| Customers | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES` (optional) |
| Products | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` (optional) |
| Sales lines | The `RA_CUSTOMER_TRX` tables (optional) |

When a dataset shows **Missing permission**, ask the administrator to grant SELECT on the objects and test again. Customers, products and sales lines are optional: an instance that doesn't use them still loads everything else.
