Connect PlaidCloud to **OneStream** so Data Foundation can read your consolidated results and reconcile its management group profit and loss to them. OneStream is supported through its connector: PlaidCloud signs in with OAuth 2.0 client credentials and reads a data adapter that your OneStream administrator builds. It only reads. If you name a Data Management sequence, PlaidCloud runs that sequence first to refresh what the adapter reads, and runs nothing else.

OneStream is a source of results to reconcile to, not of ledger lines: its rows land as the `Consolidated` scenario of the model's budget table, version `OneStream`. See [Reconcile to Your Consolidation System](/guides/projects/data-foundation/#reconcile-to-your-consolidation-system).

<Aside type="note">
The adapter's columns are a contract you and your OneStream administrator agree. When the adapter is built to this page, its rows land as described below. Compare the first load's results with a OneStream report you trust.
</Aside>

## What Your OneStream Administrator Sets Up

The **Foundation** tab writes an access request for you to send. It asks for the following.

1. A client for PlaidCloud in OneStream's identity service that uses the **client credentials** grant, with a service user who can run the adapter and, if you want PlaidCloud to refresh results first, the Data Management sequence.

2. In the application and workspace you report on, a data adapter named **Foundation_Results** that returns one table of the consolidated results with exactly these columns:

   | Column | Holds |
   |---|---|
   | `entity` | The consolidation member: an entity, an elimination member or the group total. |
   | `account` | The account code. Base accounts only. |
   | `time` | The month, as `YYYY-MM`. |
   | `scenario` | The scenario. |
   | `view` | `YTD` or `Periodic`. PlaidCloud reads only the rows of the view you choose. |
   | `amount` | A number, in the sign and scale your reports show. |
   | `currency` | The currency the amount is stated in: your group's reporting currency. |
   | `flow`, `ud1`, `ud2`, `ud3`, `ud4` | Flow and user-defined dimensions. Base members only. |

   Serve base members of the account, flow and user-defined dimensions. A parent member's row would count its children twice. The adapter reads the consolidation member from the substitution variable `Member` and the view from `View`.

3. The members to read: the entities, the elimination members and the group total.

## Create the Connection

<Steps>

1. Open **Tools > Connections** and click `New Connection`, then choose **OneStream**. Or create it from the **Foundation** tab when you add the source.

2. Fill in the fields:

   | Field | Value |
   |---|---|
   | Host | The OneStream base URL, starting with `https://`. |
   | Client ID | The client ID of the PlaidCloud client. |
   | Client Secret | Its secret. Stored encrypted and never shown again. |
   | Token URL | Leave blank to use the Host followed by `/identity/connect/token`. |
   | Default Application | Used by a read that leaves its application blank. |
   | Default Workspace | Used by a read that leaves its workspace blank. |
   | Timeout (seconds) | Defaults to 120. |

3. Click `Create`.

</Steps>

## Add It to a Data Foundation Project

On the **Foundation** tab, add the connection as a source, as you would any other (see [Connect Your ERP](/guides/projects/data-foundation/#connect-your-erp)), and choose the consolidation members to read. Then answer what describes the adapter's amounts:

| Setting | What it means |
|---|---|
| Members | The consolidation members to read, one call to the adapter for each. |
| View | Whether the adapter's amounts are year to date (the default) or periodic. Year-to-date rows land as periodic amounts. |
| Sign | **Natural**: each account in its own sign, as OneStream reports it (the default). **Debit positive**: debits positive. |
| Scale | The multiplier to whole currency units: `1000` when OneStream serves thousands. |
| Fiscal year start month | The month your fiscal year starts, for converting year to date to periodic. |
| Application, Workspace | Override the connection's. |
| Substitution variables | Extra variables the adapter reads, for example `Time=2026M1`. |
| Data Management sequence | A sequence run before the read to refresh what the adapter reads. |

Map the OneStream members to your entities with a code-map file that applies to this source. See [Entity Crosswalk](/guides/projects/data-foundation/#entity-crosswalk). The source reads no history window: the adapter's own substitution variables bound it.

A load that returns no rows from the adapter finishes with a warning, not an error, and the table is empty.
