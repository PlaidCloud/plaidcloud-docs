[Data Foundation](/guides/projects/data-foundation/) brings data from every ERP system and instance you connect into one Common Finance Model, and Microsoft Dynamics 365 Business Central is one of the ERPs it reads directly. The connection uses a Microsoft Entra ID application with client credentials, a read-only permission set, and a few page objects published as web services. This page is for the Business Central administrator who sets that up, and for the PlaidCloud user who asks them to.

PlaidCloud only reads data. Nobody sends a client secret by email.

## Send the Access Request

On the project's **Systems** page, under **Data Foundation** in **Home**, choose your system in **System** under **Add a system** and click **Don't have access yet?**. The system waits for access, and one request covering the project's systems is shown. Click **Copy request** to paste it into your own message, or **Email request** to open it in your mail program with the subject "Access for PlaidCloud."

## What the Business Central Administrator Sets Up

<Steps>

1. **Register an app in Microsoft Entra ID.** Under **App registrations > New registration**, add a client secret, and note the Directory (tenant) ID, the Application (client) ID and the secret.

2. **Add the app in Business Central.** Open **Microsoft Entra Applications**, add the application, set its state to **Enabled**, and give it the permission set **D365 READ** only, for every company you report on. It reads every page below. Don't give it **D365 BASIC** or any other permission set that can write.

3. **Publish page objects as web services.** Under **Search > Web Services > New**, publish these page objects with exactly these Service Names and **Published** ticked. The standard API doesn't carry their fields:

   | Page | Service Name | Notes |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | Cost of goods sold and inventory balances; optional |
   | 120 G/L Budget Entries | `GLBudgetEntries` | Budgets; optional |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | Statistical drivers; optional |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | Shortcut Dimensions 3 to 8; optional |
   | 479 Dimension Set Entries | `DimensionSetEntries` | Shortcut Dimensions 3 to 8; optional |
   | 573 Detailed Cust. Ledg. Entries | `DetailedCustLedgEntries` | Open items and payments; optional |
   | 574 Detailed Vendor Ledg. Entries | `DetailedVendorLedgEntries` | Open items and payments; optional |
   | 371 Bank Account List | `BankAccounts` | Bank balances; optional |
   | 277 Bank Account Posting Groups | `BankAccountPostingGroups` | Bank balances; optional |
   | Inventory Posting Setup (search for its page) | `InventoryPostingSetup` | The account of an item's purchase lines; optional |

4. **Tell the PlaidCloud user three choices:** the source code your audit adjustments post under (PlaidCloud assumes `ADJUSTMENT`), which dimension is your department (PlaidCloud assumes Global Dimension 1, named `DEPARTMENT`), and which is your profit center (PlaidCloud assumes Global Dimension 2, named `PROFITCENTER`). A site is a Business Central location.

</Steps>

## What to Send Back

| The administrator sends | Entered in PlaidCloud as |
|---|---|
| The Directory (tenant) ID | **Azure AD Tenant ID** |
| The Application (client) ID | **Client ID** |
| The client secret | **Client Secret**, entered in the connection editor, not by email |
| The environment name, for example `production` | **Environment** |
| The ID of one company | **Company ID**: the connection needs one, and Data Foundation reads the companies chosen under **Companies** |
| The name of the dimension that is your department | The **Department dimension** system setting |
| The name of the dimension that is your profit center | The **Profit centre dimension** system setting |
| The source code your audit adjustments post under | The **Audit adjustment source code** system setting |
| The companies PlaidCloud may read | Under **Options**, **Companies**: tick them, or none for every company |

Companies that are consolidation companies go under the **Consolidation companies** system setting, so their entries aren't counted as a company's activity. Exchange rates come from one company: name it in the **Exchange rate company** system setting, or PlaidCloud uses the first company.

## Check the Access

Back in PlaidCloud, once the system is added, click **Test connection** on its row on the **Systems** page. Each dataset shows as **Readable**, **Missing permission** or **Error**:

| Dataset | What it needs |
|---|---|
| Entities, Chart of accounts, Customers, Products, Currency rates, Trial balance | API access (permission set D365 READ) |
| Fiscal calendar | The `AccountingPeriods` web service |
| Departments | The `DimensionValues` web service |
| General ledger | The `GLEntries` web service |
| Every other dataset | Optional, not part of the test |

When a dataset is missing, the test says which permission or web service to add. Ask the administrator to add it and test again.

The optional datasets are sites, profit centers, suppliers, the month-end balance, bank balances, inventory balances, sales lines, supplier invoice lines, open items, payments, budgets and allocation drivers. An environment that doesn't use one still loads everything else, and after the next load the readiness checks, on the **CFM-Accounting - Close and assurance** dashboard, name any page Business Central refuses. The month-end balance is the trial balance at each month end; bank balances are that balance for the accounts your bank accounts post to. When Business Central refuses a read that a month's month-end balance, bank balances, inventory, sales lines, supplier invoice lines, open items or payments are built from, that month keeps the rows it already had and is read again at the next load.
