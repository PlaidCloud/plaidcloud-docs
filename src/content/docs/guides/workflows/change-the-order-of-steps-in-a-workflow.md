---
title: Change the order of steps in a workflow
description: Reorder steps within a PlaidCloud workflow using drag-and-drop or manual ordering to control the data processing sequence.
sidebar:
  order: 5
---

There are two ways to update the order of steps in the workflow. The first way is to use the up and down arrows present in the **Workflows** table to move the step up or down. The second way is to use the **Step Move** option which allows you to move the step much easier if large changes are necessary. The step move option allows you to move the step to the top, bottom, or after a specific step in one operation.

A workflow's structure can hold each step only once. If a workflow somehow already has the same step listed twice, reordering it — including dragging a step to a new position — is refused with an error saying the workflow contains a duplicate. Delete the duplicate step to repair the workflow; removing steps isn't restricted, and reordering works normally again once it's gone.
