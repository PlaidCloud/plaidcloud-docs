## Description

**Project home** is where you start in a project. A rail on the left lists six pages: **Overview**, **Variables**, **Schedules & sensors**, **Access & sharing**, **Data & connections** and **Apps & branding**. Overview summarizes the project. The other five pages are where you change the project's settings.

The **Variables** badge on the rail shows how many variables the project has. The **Schedules & sensors** badge shows how many schedules and sensors are active.

A locked project is read only. Its pages show a banner that says "This project is locked, so it is read only. Unlock it on Overview to make changes." and their controls are disabled.

## Overview

![Overview page of Project home showing the project name, six tiles, Coming up and Project defaults](/images/projects/project-home-overview.png)

The top of the page shows the project name and whether it is **Editable** or **Read only**.

- **Description.** Click the pencil to edit the description in place. Press Enter to save, or Escape to cancel.
- **Labels.** Type a label in **Add a label...** and click **Add**. See [Organizing Work with Labels](/guides/projects/organizing-with-labels/).
- **Lock** and **Unlock** switch the project between editable and read only.

The tiles count what the project holds:

| Tile | Shows |
|---|---|
| **Tables** | Tables in the project. |
| **Workflows** | Workflows in the project. |
| **Steps** | Steps across all workflows. |
| **Variables** | Project variables. |
| **Published tables** | Tables you have published. |
| **Data size** | What the project's tables store. Click it to open **Storage**. See [Managing Storage](/guides/projects/managing-storage/). |

If some of the project's rows are filtered for you, **Data size** shows a dash because the total would not be accurate.

**Coming up** lists the next three scheduled runs with their workflow names, and the number of active sensors. **View schedules ›** opens **Schedules & sensors**.

**Project defaults** shows the **Environment**, **Table storage**, **Access** and **ERP posting** values that workflows and steps use unless they set their own. **Change settings ›** opens the page where you change them.

The header buttons are:

- **Project report** builds a report of the project as a **PDF Document** or **Interactive HTML**.
- **Export archive** saves the project as an archive.
- **Refresh** reloads the tiles and the lists on the page.

## Variables

The **Variables** page lists the project's variables in a grid. A workflow or step refers to a variable by name as `{name}`, and a workflow's own variable overrides a project variable of the same name.

The grid shows **Name**, **Value**, **Memo**, **Last updated** and **By**. Use **Filter** to narrow the list, **New variable** to add one, and **Edit** or **Delete** for the selected row.

## Schedules & Sensors

![Schedules and sensors page with a summary strip and two grids](/images/projects/project-home-schedules.png)

This page shows what starts the project's workflows automatically. A summary strip shows the next run, the number of active and paused schedules, and the number of active sensors.

- **Schedules** run a workflow on a timetable. The grid shows **Name**, **Workflow**, **Runs** (the timetable and its time zone), **Next run** and **Status**.
- **Sensors** run a workflow when new data arrives. The grid shows **Name**, **Watches**, **Starts** (the workflow), **Last triggered** and **Status**.

**Status** is **Active**, **Paused** or, for a sensor that has a problem, **Failing**. Each grid has **New schedule** or **New sensor**, **Edit**, **Delete** and **Filter**. Open **Actions** to **Activate** or **Deactivate** the selected row.

**Calendar view** shows upcoming runs on a calendar, so you can spot scheduling conflicts.

## Access & Sharing

This page sets who can reach the project and its data.

- **Project access** sets **Who can open this project**: **All Workspace Members**, **Specific Security Groups Only** or **Specific Members Only**. **Edit groups ›** and **Edit members ›** open the lists to choose from.
- **Dashboard audience** sets the **Default audience for new dashboards**: everyone in the project, or specific groups. Each dashboard can change its own audience. See [Control Who Can See a Dashboard](/guides/dashboards/control-who-can-see-a-dashboard/).
- **Data shares** lists the projects that can read tables from this one. See [Sharing Data Between Projects](/guides/projects/managing-projects/#sharing-data-between-projects).

## Data & Connections

![Data and connections page with connections, table storage and ERP posting](/images/projects/project-home-data.png)

These settings apply to every workflow and step in the project unless a workflow or step sets its own.

- **Connection environment** chooses the credentials a step uses when it doesn't choose one. The page warns you when a connection in the project has no configuration for the selected environment.
- **Default document account** chooses where steps read and write files.
- **Default table storage** chooses where new tables are created.
- **Time travel retention** sets how many days earlier versions of table data are kept. Tables that inherit this setting keep longer history too. History that has already expired can't be recovered.
- **Posting mode** sets how the project sends journal entries to connected ERPs. It is a ceiling for the project: a workflow run can't post more permissively than this setting. **Live** posts normally. **Simulate** builds and validates but never posts or contacts the ERP. **Off** skips posting steps.
- **Write authorizations** shows how many ERP connections are authorized for posting. Administrators can click **Manage authorizations ›**.

## Apps & Branding

This page covers the apps built on the project's data.

- **Panel apps** shows how many apps are built on the project. **Open Panel apps ›** opens them, and **New studio app** starts one.
- **Branding** sets the logo and colors the project's apps use. **Edit branding ›** opens the settings.
- **Home tile image** is the picture shown on the project's tile on the Home page. Click **Choose…** to pick an image, or **Clear** to remove it.
