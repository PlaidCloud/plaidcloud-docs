Home is the first page you see after signing in to a workspace. It brings the
things you work with most — projects, workflows, tables, dashboards, panel apps,
and documents — into one place, so you can pick up where you left off without
hunting through each app tab.

## Lanes

The page is organized into three lanes, top to bottom. A lane only appears when
it has something to show.

- **Needs attention** — workflows whose most recent run failed, so problems
  surface the moment you land. Each card links straight to the failed run, and
  you can **Dismiss** one you've already dealt with.
- **Pinned** — everything you've marked as a favorite, in the order you pinned
  it. Any item type can be pinned here (see [Favorites](#favorites-pinning)).
- **Recent** — projects, dashboards, and panel apps you've opened or edited
  recently, so your latest work is one click away.

<Aside type="note">
Only projects, dashboards, and panel apps appear by recency — there are usually
far too many workflows, tables, and documents to list that way. Surface the ones
you return to by pinning them, and they'll wait for you in the **Pinned** lane.
</Aside>

## Opening Things

Every card and list row has a primary action and, where it makes sense, extra
actions:

| Item | Opens with | Also available |
|---|---|---|
| Project | Open project | |
| Workflow | Open workflow | Run, Open latest run, live **Running** status |
| Table | Open table | Open in Table Explorer |
| Dashboard | Open dashboard | Open in new tab |
| Panel app | Open app | Open in new tab |
| Document | Open document (a file) or Open folder (a directory) | |

A running workflow shows a live status indicator that updates on its own as the
run progresses — no need to refresh.

## Favorites (Pinning)

Click the **star** on any Home card or list row to pin it. Pinned items always
appear in the **Pinned** lane, regardless of how recently you used them, so the
things you care about never scroll out of reach.

You can also pin items from where you already work, without opening Home first:

- **Projects, workflows, and tables** — click the star in the tree that lists
  them.
- **Dashboards** — click the star in the dashboards list.
- **Documents** — right-click a file *or* a folder in the document browser and
  choose **Favorite**.

Click a lit star anywhere to unpin. Changes are reflected on Home immediately.

<Aside type="note">
Folder favorites resolve for most storage accounts. Folders in some object
stores (for example S3 and Wasabi) can't be resolved back to a pin and won't
appear — favorite a file within the folder instead.
</Aside>

## Tiles or List

Use the **Tiles / List** toggle in the toolbar to switch between the roomy card
view and a dense, single-line list. Your choice is remembered and switching is
instant — it redraws what's already loaded without fetching again.

## Filtering by Type

The chip row below the toolbar has one chip per browse type — **Projects**,
**Dashboards**, **Panel apps**, **Workflows**, **Tables**, and **Documents**. A
pressed chip means that type is shown; click it to hide that type from the
**Recent** and **Pinned** lanes. Your filter is remembered between visits.

The **Needs attention** lane is never filtered — a failing workflow always
surfaces, even when its type's chip is off.

## Search (Command Palette)

Press **Ctrl/Cmd-K** — or click **Search** in the toolbar — to open the command
palette and search across projects, workflows, tables, dashboards, and panel
apps at once. Start typing (two characters or more) and results appear grouped
by type, each with the same open actions and favorite star as on the board.

- **Up / Down** move the selection.
- **Enter** opens the selected result.
- **Escape** closes the palette.

## Refreshing

Home refreshes on its own when you return to the tab and its data has gone
stale. To pull the latest immediately, click **Refresh** in the toolbar.
