Document does not back up an account's files on its own. To keep a second copy of them — in an account on another cloud provider, for example — copy them with a workflow and run it on a schedule:

1. Create a workflow with a [Copy Document Directory](/reference/workflow-steps/document/copy-document-directory/) step.
2. Under **Copy Directory**, choose the account and the folder to back up.
3. Under **Select Destination**, choose the account to copy into and the folder to place the copy in.
4. Schedule the workflow to run, for example nightly. See [Schedule a Workflow](/get-started/tutorials/schedule-a-workflow/).

Several accounts can share one backup account: give each copy its own name by ticking **Rename the Copied Folder to:** and naming it after the account it came from, so their folders never collide.

<Aside type="caution">Copy Document Directory overwrites anything at the destination that has the same name, so each run replaces the previous copy rather than keeping a history of copies.</Aside>
