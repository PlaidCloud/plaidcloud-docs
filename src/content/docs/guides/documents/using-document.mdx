The Document browser is a two-pane split view: the folder tree on the left, the file list on the right. The toolbars are labelled, each row has a **⋯** menu, and most operations are also available from a right-click menu in either pane. The right-click menu shows different options depending on whether a folder, a file, or empty space is selected.

The root of an account is itself a viewable folder. Dropping files on empty space in the folder tree uploads them straight into it.


**To open the file explorer:**

1. Go to **Document > Browse**. It opens your favorite account, or the workspace's default account if you have no favorite. Choose another account from the list in the page header. Or go to **Document > Your accounts** and double-click the account's row, or use its **Browse files** icon
2. To start from a file you pinned, select it in **Pinned** on the **Overview**. **Browse** opens at its folder with the file selected

### Pop Out

**Pop out** in the page header opens the current account and folder in a new browser tab, so you can keep a browser open while you work in other pages. Each tab keeps its own selection, so nothing is carried across.

The various file and folder operations are detailed below.


## Upload a File

**Drag-and-drop:**

1. Browse to the desired directory
2. Drag one or more files from your desktop and drop them:
   - on the file list on the right, to upload into the folder shown there
   - on a folder in the tree on the left, to upload into that folder
   - on empty space in the tree on the left, to upload to the root of the account

**From the right-click menu:**

1. Browse to the desired directory
2. Right-click in the file list and select `Upload Here`
3. Pick the files in the OS file picker

**From the toolbar:**

1. Browse to the desired directory
2. Click the `Upload` button on the right pane

<Aside>Multiple files can be uploaded at once. If a target name already exists, you will be prompted to confirm overwrite or cancel.</Aside>

The label **Drag multiple files here to upload** reminds you that you can drop several files at once.

### Uploads and Imports Panel

The **Uploads and imports** panel appears under the browser while files are moving, and hides itself when there is nothing to show. It has one row per upload and one per import to a table, each with its name, status and the actions that fit:

- A running upload shows a progress bar and **Cancel**. **Cancel all** stops every running upload.
- A failed upload has **Retry** and **Dismiss**. It stays until you dismiss it so you can read why.
- A finished upload dismisses itself after a few seconds.
- An import to a table stays until you dismiss it. When it finishes you can go on with **Preview ›**, **Create step ›** or **Open step ›**. **Stop watching** stops tracking an import that is still running; the import itself isn't cancelled.


## Download a File

1. Browse to the desired directory
2. Left-click to select the desired file
3. Right-click and select `Download`


## Rename a File

1. Browse to the desired directory
2. Left-click to select the desired file
3. Right-click and select `Rename`


## Move a File

1. Browse to the desired directory
2. Left-click to select the desired file
3. Drag into the destination folder
4. Select `Move File`


## Copy a File

1. Browse to the desired directory
2. Left-click to select the desired file
3. Right-click and select `Copy`


## Delete a File

1. Browse to the desired directory
2. Left-click to select the desired file
3. Right-click and select `Delete`


## Create a Folder

1. Open the account
2. Click `New Top Level Folder` (or right-click an existing folder and select `New Folder`)
3. Enter a folder name
4. Click `Create`


## Rename a Folder

1. Browse to the desired directory
2. Left-click to select the desired folder
3. Right-click and select `Rename`


## Move or Copy a Folder

1. Browse to the desired directory
2. Left-click to select the desired folder
3. Drag into the destination folder
4. Select `Move Folder` to relocate it, or `Copy Folder` to leave the original where it is

A folder and everything inside it come across either way.


## Delete a Folder

1. Browse to the desired directory
2. Left-click to select the desired folder
3. Right-click and select `Delete`


## Download Folder Contents (zip File)

The `Download as Zip` option compresses every file under the selected folder into a single `.zip` and downloads it. The archive preserves the folder structure shown in the explorer.

1. Browse to the desired directory
2. Left-click to select the desired folder
3. Right-click and select `Download as ZIP`


## Read-Only Accounts

If an account is marked read-only, upload affordances (drag-prompts, the toolbar `Upload` button, and the `Upload Here` context menu) are hidden automatically. Browse, download, and search still work.
