La prise en charge des serveurs MCP ajoutés par l'utilisateur dans ChatGPT est encore en cours de déploiement et varie selon le palier de l'offre et la surface. Cette page décrit ce qui fonctionne aujourd'hui.

## ChatGPT Pro / Plus / Team : connecteurs

Si votre offre ChatGPT propose l'interface **Connectors** (Settings → Connectors), vous pouvez ajouter PlaidCloud comme connecteur MCP personnalisé :

1. Accédez à **Settings → Connectors → Add custom connector**.
2. Saisissez :
   - **Nom** : `PlaidCloud`
   - **URL du serveur MCP** : `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT vous redirige vers PlaidCloud pour la connexion OAuth. Une fois connecté, PlaidCloud affiche une page **Application Access Request** qui nomme l'application demandeuse et l'URI de redirection vers laquelle elle enverra les identifiants ; vérifiez qu'elles correspondent à ChatGPT avant d'approuver.
4. Activez le connecteur dans toute conversation qui doit pouvoir l'utiliser.

<Aside>L'interface Connectors peut ne pas être visible sur tous les comptes ni dans toutes les régions. Si vous ne voyez pas « Add custom connector », votre offre ou la politique de votre espace de travail n'autorise actuellement pas les serveurs MCP ajoutés par l'utilisateur : utilisez la solution de contournement ci-dessous.</Aside>

## ChatGPT Enterprise

Les administrateurs Enterprise peuvent épingler des connecteurs MCP au niveau de l'espace de travail via la console d'administration. Suivez la même configuration OAuth que ci-dessus, mais attendez-vous à une étape d'approbation de l'espace de travail par votre administrateur avant que le connecteur ne soit utilisable.

## Solution de contournement : GPT personnalisés avec actions REST

Si votre compte ne prend pas en charge les connecteurs MCP personnalisés, vous pouvez tout de même piloter PlaidCloud depuis ChatGPT au moyen d'un **GPT personnalisé** qui appelle l'API REST de PlaidCloud comme une action OpenAPI :

1. La surface REST de PlaidCloud est décrite par le document OpenAPI disponible à l'adresse `https://<your-tenant>.plaidcloud.org/openapi_rest.json`.
2. Dans ChatGPT, créez un GPT personnalisé (Explore GPTs → Create) et, sous **Actions**, importez cette URL (ou collez le JSON).
3. Configurez l'authentification sur **OAuth** et pointez vers les points de terminaison Keycloak de PlaidCloud. Votre administrateur PlaidCloud peut vous fournir les URL du realm et l'ID client.

Cela échange les conventions de nommage des outils de MCP contre des points de terminaison REST directs : un peu plus verbeux à parcourir pour le modèle, mais fonctionnellement équivalent pour les opérations de lecture et d'écriture qu'expose PlaidCloud.

## Pourquoi MCP n'est pas toujours disponible

La prise en charge de MCP par OpenAI continue d'évoluer et les surfaces disponibles (interface Connectors, schéma Actions, etc.) changent selon les paliers d'offre et au fil du temps. Si la voie officielle **Connectors** est ouverte sur votre compte, privilégiez-la : elle offre l'actualisation OAuth intégrée et une expérience d'appel d'outils conforme au reste de cette section. Le repli sur les actions de GPT personnalisé n'est nécessaire que lorsque MCP n'est pas encore exposé pour votre compte.
