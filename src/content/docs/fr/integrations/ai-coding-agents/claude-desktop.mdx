L'application Claude grand public, à la fois l'interface web sur [claude.ai](https://claude.ai) et l'application de bureau, prend en charge les serveurs MCP via sa fonctionnalité **Custom Connectors**. La configuration est une procédure OAuth à effectuer une seule fois, après quoi la connexion est associée à votre compte Claude et vous suit d'un appareil à l'autre.

<Aside>Les Custom Connectors sont disponibles avec les offres Claude Pro, Max, Team et Enterprise. Les administrateurs Team et Enterprise peuvent épingler des connecteurs pour tous les membres de l'espace de travail.</Aside>

## Configuration

1. Dans Claude (web ou bureau), ouvrez **Settings → Connectors**.
2. Cliquez sur **Add custom connector**.
3. Renseignez :
   - **Nom** : `PlaidCloud` (ou `PlaidCloud (prod)`, `PlaidCloud (dev)` si vous avez plusieurs tenants).
   - **URL du serveur** : `https://<your-workspace>.plaid.cloud/mcp`
4. Cliquez sur **Ajouter**. Claude ouvre un onglet de navigateur vers la page de connexion Keycloak de PlaidCloud.
5. Connectez-vous, puis approuvez la page **Application Access Request** qui suit : elle nomme l'application demandeuse et l'URI de redirection vers laquelle elle enverra les identifiants, vérifiez donc que les deux correspondent à Claude avant d'approuver. Vous serez redirigé vers Claude avec la connexion enregistrée.

Le connecteur est désormais disponible dans toute conversation. Activez-le (ou désactivez-le) à l'aide du sélecteur de connecteurs dans la zone de saisie de la conversation.

## Utilisation

Une fois activé, vous pouvez demander à Claude des choses comme :

- « Liste les workflows du projet `Q4 Forecast`. »
- « Montre-moi les 10 dernières exécutions en échec du workflow `daily-load`. »
- « Exécute `mcp_recipes` et choisis la bonne recette pour remplir rétroactivement une étape. »

Claude choisit l'outil MCP approprié, l'appelle et intègre la réponse dans sa réplique. Pour les opérations de modification, il décrit généralement ce qu'il s'apprête à faire : examinez-le attentivement avant d'approuver.

## Plusieurs tenants

Ajoutez un connecteur distinct pour chaque tenant. Donnez-leur des noms distincts pour que Claude puisse les différencier dans la conversation. Seuls les connecteurs que vous activez pour une conversation donnée sont disponibles ; laisser la production désactivée par défaut et ne l'activer que lorsque vous êtes sûr est une habitude de sécurité judicieuse.

## Actualiser l'accès

Les connecteurs personnalisés stockent un jeton d'actualisation OAuth ; une nouvelle authentification est donc rare. Si vous changez votre mot de passe PlaidCloud, utilisez un nouvel appareil ou si votre session est invalidée côté serveur, le connecteur peut afficher « needs authentication ». Cliquez sur **Reconnect** dans les paramètres des connecteurs pour refaire la procédure OAuth.

## Déconnexion

Settings → Connectors → cliquez sur le connecteur → **Supprimer**. Cela supprime les jetons OAuth stockés avec votre compte Claude. La session côté PlaidCloud est indépendante : déconnectez-vous séparément de PlaidCloud si vous voulez invalider la session Keycloak sous-jacente.
