Le [mode agent](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) de GitHub Copilot dans VSCode prend en charge les serveurs MCP via un fichier `.vscode/mcp.json` propre à l’espace de travail ou à l’utilisateur (espace de travail), ou via le fichier `mcp.json` global de VSCode (utilisateur).

<Aside type="note">Vous cherchez **Microsoft 365 Copilot**, l’assistant de Teams et de l’application Microsoft 365, plutôt que GitHub Copilot dans votre IDE ? Consultez [Microsoft 365 Copilot](/fr/integrations/microsoft-365-copilot/).</Aside>

Vous pouvez aussi accéder à ces étapes depuis la fenêtre **Connecter votre IA** de PlaidCloud (dans le menu de l’avatar) : GitHub Copilot se trouve sous l’onglet **Autre**, à côté de Gemini CLI et de Codex CLI.

<Aside>La prise en charge de MCP par Copilot dépend du palier de votre formule Copilot et du paramètre `chat.mcp.enabled` de VSCode. Assurez-vous que les deux sont activés avant de configurer des serveurs.</Aside>

## Configuration

1. Obtenez un jeton porteur en visitant `https://<your-workspace>.plaid.cloud/mcp/setup/token` dans un navigateur où vous êtes connecté à PlaidCloud.

2. Dans VSCode, ouvrez la palette de commandes et exécutez **MCP: Add Server**, ou créez directement `.vscode/mcp.json` :

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Rechargez VSCode. Ouvrez le panneau de discussion Copilot, passez la liste déroulante des modes sur **Agent**, puis vérifiez que les outils PlaidCloud apparaissent dans la liste des outils (généralement affichés sous la forme `plaidcloud_*`).

## Utilisation

Demandez à Copilot d’effectuer directement des opérations PlaidCloud :

- « Trouve tous les workflows du projet `Q4 Forecast` dont la dernière exécution a échoué. »
- « Montre-moi le schéma de la table `customers` et suggère des index. »
- « Exécute le workflow `daily-load` et indique l’état de l’exécution. »

Copilot choisit l’outil approprié, l’exécute et cite les résultats dans sa réponse. Pour les opérations destructrices (suppression, organisation, upsert sans `dry_run`), il demande généralement une confirmation : examinez l’action prévue avant de l’approuver.

## Actualiser le jeton

VSCode lit `.vscode/mcp.json` au démarrage et à chaque modification du fichier. Lorsque le jeton expire, rechargez `https://<your-workspace>.plaid.cloud/mcp/setup/token` et remplacez la valeur de `Authorization` : VSCode recharge automatiquement le serveur.

## Limiter à des outils spécifiques

Si vous souhaitez limiter les outils PlaidCloud que Copilot peut appeler, utilisez la liste d’autorisation d’outils par serveur de VSCode (Settings → Copilot → MCP → sélection d’outils propre au serveur). C’est utile pour les sessions en lecture seule ou pour garder les outils qui modifient des données (`*_upsert`, `*_run`) derrière une réactivation explicite.
