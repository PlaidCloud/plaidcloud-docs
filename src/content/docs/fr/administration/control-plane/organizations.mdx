Une organisation est la limite administrative d'un ensemble d'espaces de travail PlaidCloud liés. Les paramètres de l'organisation contrôlent le nom affiché dans le plan de contrôle, les métadonnées de facturation, le comportement de l'authentification unique et les personnes autorisées à administrer l'organisation.

## Liste des organisations

La page **Organizations** affiche les organisations auxquelles vous avez accès. Depuis la table, vous pouvez :

1. Rechercher des organisations selon les champs visibles de la table.
2. Actualiser la liste des organisations.
3. Afficher les détails d'une organisation.
4. Modifier les paramètres d'une organisation si vous disposez de l'accès administrateur.
5. Ouvrir la gestion des accès à l'organisation si vous disposez de l'accès à la sécurité.
6. Ouvrir les enregistrements de facturation si vous disposez de l'accès à la facturation.

## Paramètres de l'organisation

| Paramètre | Description |
| --- | --- |
| Nom | Nom d'affichage de l'organisation. |
| ID | Identifiant stable de l'organisation. Il est défini lors de la création de l'organisation. |
| Mémo | Note interne ou description affichée dans le plan de contrôle. |
| Plan | Plan commercial : Enterprise, Team ou Free. |
| Numéro d'identification fiscale | Identifiant fiscal utilisé pour les enregistrements de facturation. |
| Actif | Indique si l'organisation est active. |
| Verrouillée | Empêche les modifications normales de l'organisation lorsque cette option est activée. |
| Authentification unique obligatoire | Oblige les membres à se connecter via la configuration d'authentification unique de l'organisation. |

## Métadonnées de facturation

Les champs de facturation décrivent la façon dont l'organisation est facturée. Ils ne donnent pas, à eux seuls, accès au produit.

| Paramètre | Options |
| --- | --- |
| Cycle de facturation | Mensuel, Trimestriel, Semestriel, Annuel |
| Prix de facturation | Montant numérique de la facturation pour le cycle sélectionné. |
| Type de paiement | Facturation sur bon de commande, Essai gratuit, Gratuit, Paiement planifié |

## Comportement de l'authentification unique

| Paramètre | Description |
| --- | --- |
| Attribution dynamique des groupes | Permet aux informations de groupe de l'authentification unique de piloter l'attribution des rôles de l'organisation. |
| Création dynamique des utilisateurs | Permet à la connexion par authentification unique de créer automatiquement des utilisateurs lorsque le fournisseur d'identité envoie un utilisateur accepté. |
| Nom du groupe d'attribution dynamique de l'authentification unique | Nom du groupe d'authentification unique utilisé pour l'attribution dynamique. |

<Aside type="note">
	Configurez un fournisseur d'identité pour un espace de travail dans sa [boîte de dialogue Single sign-on](/fr/administration/control-plane/workspace-configuration/#authentification-unique) ; la configuration SAML est documentée dans les guides de gestion des accès. Ces paramètres du plan de contrôle déterminent la façon dont l'organisation utilise la configuration d'authentification unique une fois qu'elle existe.
</Aside>

## Gérer l'accès

Utilisez **Manage Access** pour inviter des personnes dans l'organisation et leur attribuer des rôles d'organisation.

1. Ouvrez **Organizations**.
2. Sélectionnez l'organisation.
3. Ouvrez **Manage Access**.
4. Cliquez sur **Invite User** pour inviter une ou plusieurs adresses e-mail.
5. Sélectionnez les rôles que chaque personne doit recevoir.
6. Ajoutez un message personnalisé facultatif.
7. Envoyez l'invitation.

Vous pouvez modifier les rôles des utilisateurs qui ont accepté l'invitation, les retirer ou annuler les invitations en attente. Les utilisateurs en attente ne peuvent pas être modifiés tant qu'ils n'ont pas accepté l'invitation.

## Rôles de l'organisation

| Rôle | À utiliser pour |
| --- | --- |
| Admin | Les paramètres de l'organisation et les modifications de niveau administrateur. |
| Espace de travail | La création, la configuration, la publication, la suspension et le rétablissement des espaces de travail. |
| Sécurité | Les invitations et la gestion des rôles de l'organisation. |
| Facturation | L'accès aux enregistrements de facturation. |
