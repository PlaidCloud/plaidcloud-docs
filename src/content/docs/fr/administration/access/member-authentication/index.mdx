L'onglet Identity regroupe les fonctionnalités de sécurité et d'authentification sur lesquelles PlaidCloud s'appuie pour garantir une plateforme sûre pour les membres. PlaidCloud propose trois types d'authentification :


* Mot de passe uniquement
* Authentification à deux facteurs
* Authentification unique (SSO)

Le type d'authentification par défaut est le mot de passe uniquement. Vous pouvez toutefois activer l'authentification à deux facteurs. Si un fournisseur d'authentification unique SAML est disponible, vous pouvez configurer votre organisation PlaidCloud pour utiliser l'authentification unique.

Si vous créez un compte personnel, le type d'authentification par défaut est le mot de passe uniquement. Pour passer à l'authentification à deux facteurs, reportez-vous aux étapes de la section Authentification à deux facteurs.

<Aside>Les membres peuvent avoir accès à l'onglet Identity pour des raisons de sécurité ou pour gérer les membres de l'espace de travail. Les détails sur la gestion de la sécurité et de l'authentification des nouveaux membres ou des membres sans accès figurent sur la page principale « Identity ».</Aside>


## Modifier les mots de passe

Pour les membres qui utilisent l'authentification à deux facteurs ou par mot de passe uniquement, la modification du mot de passe est simple et s'effectue depuis le menu « Member » (icône gravatar) dans le coin supérieur droit.


**Pour modifier votre mot de passe :**

1. Sélectionnez l'icône (gravatar) en haut à droite


	* L'icône du menu « Member » est différente pour chaque utilisateur
2. Cliquez sur « Change Password » dans le menu déroulant
3. Saisissez votre mot de passe actuel à l'endroit indiqué
4. Saisissez votre nouveau mot de passe à l'endroit indiqué
5. Saisissez de nouveau votre mot de passe (confirmation)
6. Cliquez sur le bouton « Update » pour enregistrer

<Aside>Seuls les mots de passe robustes sont acceptés, et le nouveau mot de passe doit être différent de l'actuel.</Aside>


## Se déconnecter


Pour vous déconnecter, sélectionnez l'icône (gravatar) en haut à droite, puis cliquez sur « Sign Out » dans le menu déroulant.

La déconnexion met fin à votre session PlaidCloud et vous renvoie vers une page de déconnexion. Pour revenir dans PlaidCloud, connectez-vous de nouveau.

<Aside>Vous devrez vous reconnecter la prochaine fois que vous reviendrez dans PlaidCloud.</Aside>

Votre administrateur peut éventuellement configurer PlaidCloud pour qu'il mette aussi fin à votre session d'authentification unique auprès de votre fournisseur d'identité lorsque vous vous déconnectez.


## Authentification par mot de passe uniquement

L'authentification par mot de passe uniquement est l'option la plus simple et la moins sûre, même avec de longs mots de passe cryptiques. Elle peut convenir à ceux qui recherchent un accès rapide et pratique sans trop se soucier des risques de sécurité. Elle reste une pratique courante, mais nous vous recommandons vivement d'utiliser plutôt l'authentification à deux facteurs.


## Authentification à deux facteurs


L'authentification à deux facteurs, ou multifacteur, renforce considérablement la sécurité par rapport au mot de passe seul, car elle exige à la fois quelque chose que « vous connaissez » (le mot de passe) et quelque chose que « vous possédez » (la clé d'accès). Autrement dit, le mot de passe seul ne permet pas d'accéder au compte.

Les mots de passe sont vulnérables aux menaces de sécurité, car ils représentent une *seule* information dont une personne malveillante a besoin pour accéder au compte ; l'authentification à deux facteurs renforce la sécurité en exigeant des *informations supplémentaires* pour se connecter. C'est pourquoi nous vous encourageons **vivement** à l'utiliser pour la sécurité de votre compte, non seulement sur PlaidCloud, mais aussi sur les autres sites qui la prennent en charge.


### Activer l'authentification à deux facteurs


**Pour activer l'authentification à deux facteurs et définir vos préférences de code d'authentification :**


1. Sélectionnez l'icône (gravatar) en haut à droite
2. Cliquez sur « Manage Multi-Factor Authentication » dans le menu déroulant
3. Sélectionnez le mode de réception du code d'authentification à deux facteurs que vous préférez.

### Types d'authentification à deux facteurs

PlaidCloud propose trois options pour recevoir ces informations supplémentaires :

* Via une application pour smartphone (par exemple Google Authenticator, Authy, Okta, FreeOTP, etc.)
* Via un SMS
* Via une YubiKey de Yubico http://yubico.com

### Authentification par smartphone


Pour obtenir votre code via une application pour smartphone, vous devez télécharger une application d'authentification, comme Google Authenticator, pour votre appareil [iOS](https://itunes.apple.com/us/app/google-authenticator/id388497605?mt=8) ou [Android](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2). Notez que d'autres applications d'authentification compatibles peuvent être utilisées, mais cet article suppose que vous utilisez l'application Google Authenticator.

Une fois l'application téléchargée, ouvrez-la et suivez les instructions de configuration affichées.


**Une fois l'authentificateur configuré :**


1. Appuyez sur le bouton « + »
2. Sélectionnez « Scan barcode »
3. Ouvrez « Manage Multi-Factor Authentication » sous l'icône gravatar dans PlaidCloud
4. Sélectionnez « Configure Authenticator » dans PlaidCloud
5. Lorsque vous y êtes invité, utilisez votre téléphone pour scanner le code QR affiché dans PlaidCloud
6. Après avoir scanné le code QR, votre application d'authentification doit afficher un code d'authentification à six chiffres qui change toutes les 30 secondes
7. Saisissez ce code dans la zone de texte située au bas de l'écran « Configure SmartPhone Authentication » de PlaidCloud, qui doit toujours être affiché depuis les étapes précédentes
8. Sélectionnez « Verify ».
9. Si le code est valide, l'authentification à deux facteurs est activée pour votre compte et une liste de codes de secours s'affiche.
10. Une fois l'authentification activée, vous pouvez de nouveau sélectionner « Manage Multi-Factor Authentication » pour afficher vos codes de secours ou désactiver l'authentification à deux facteurs.

### Authentification par SMS


**Pour utiliser l'authentification par SMS :**


1. Ouvrez « Manage Multi-Factor Authentication » sous l'icône gravatar dans PlaidCloud
2. Sélectionnez « Configure SMS » dans PlaidCloud
3. Saisissez votre numéro de téléphone mobile et votre opérateur
4. Cliquez sur « Submit »
5. Vous recevez alors un SMS contenant un code d'authentification
6. Saisissez ce code dans la fenêtre qui s'affiche dans PlaidCloud
7. Si le code est valide, l'authentification à deux facteurs est activée pour votre compte et un SMS vous envoie un code différent à saisir à chaque connexion
8. Une fois l'authentification activée, vous pouvez de nouveau sélectionner « Manage Multi-Factor Authentication » pour mettre à jour vos coordonnées ou désactiver l'authentification à deux facteurs.

### Authentification par YubiKey


Avec les YubiKey, des dispositifs d'authentification matériels fabriqués par Yubico, les membres peuvent enregistrer jusqu'à cinq YubiKey pour leur compte. Nous proposons à la fois un parc géré de YubiKey PlaidCloud, qui peut être administré par la personne responsable de la sécurité des accès à votre espace de travail, et la possibilité pour les membres d'utiliser n'importe quelle YubiKey standard.

<Aside>Les clés du parc de YubiKey PlaidCloud (les YubiKey émises spécifiquement par PlaidCloud) comptent dans la limite de cinq clés.</Aside>

Pour activer l'authentification par YubiKey, vous devez d'abord enregistrer au moins une YubiKey.



**Pour enregistrer une YubiKey :**


1. Sélectionnez l'icône (gravatar) en haut à droite
2. Cliquez sur « Change Registered YubiKeys » dans le menu déroulant
3. Placez le curseur dans un emplacement libre du formulaire « My Registered YubiKeys »
4. Insérez la YubiKey dans votre ordinateur
5. Appuyez sur le bouton de mot de passe à usage unique (OTP) de la YubiKey
6. Lorsque l'OTP est renseigné, cliquez sur le bouton « Update » du formulaire pour enregistrer

Après avoir enregistré au moins une YubiKey, vous pouvez la configurer pour votre compte.


**Pour configurer une YubiKey :**


1. Sélectionnez l'icône gravatar
2. Cliquez sur « Manage Multi-Factor Authentication »
3. Sélectionnez « Configure YubiKey »
4. Saisissez l'un de vos OTP YubiKey dans le formulaire prévu à cet effet.

Si l'OTP est valide, l'authentification à deux facteurs est activée pour votre compte et vous devrez saisir un OTP YubiKey à chaque connexion.



### Parc de YubiKey PlaidCloud


Le parc de YubiKey géré offre un moyen simple de gérer l'authentification à deux facteurs des membres de l'espace de travail. Les clés gérées portent le logo PlaidCloud et peuvent être expédiées directement aux membres ou en nombre à un administrateur.



Le parc géré présente les avantages suivants par rapport aux YubiKey individuelles :


* Les clés perdues sont facilement remplacées, sans que le membre ait besoin de conserver des codes de récupération
* L'attribution des clés se fait d'un simple clic. Les membres n'ont pas à enregistrer la clé.
* Vous pouvez consulter les attributions de YubiKey et révoquer des clés depuis une interface en pointer-cliquer
* Vous pouvez commander des clés neuves et les expédier directement aux membres
* Les YubiKey gérées sont entièrement compatibles avec les autres services qui acceptent les OTP YubiKey
* Les YubiKey peuvent être réattribuées à d'autres membres sans compromettre la sécurité lors des départs et arrivées de membres

**Pour commander de nouvelles clés :**


1. Ouvrez Identity
2. Sélectionnez l'onglet « Security »
3. Cliquez sur « PlaidCloud Security Keys » dans le menu déroulant
4. Cliquez sur le bouton « Order More Keys » du formulaire

Si des clés gérées ont été commandées, elles apparaissent dans la table des clés gérées.



Depuis le formulaire d'attribution des clés, vous pouvez attribuer des clés, les marquer comme non attribuées ou les marquer comme perdues. Vous pouvez en outre joindre un mémo à chaque clé pour conserver des notes relatives à sa remise. Pour cela, cliquez simplement sur l'icône de modification et effectuez les ajustements souhaités.



Les clés gérées représentent un coût unique. Leur utilisation n'entraîne aucun frais récurrent supplémentaires. Les YubiKey gérées coûtent 30 $ l'unité, frais d'expédition en sus.



## À quoi servent les codes de récupération


Pour des raisons de sécurité, le support PlaidCloud ne peut pas rétablir immédiatement l'accès aux comptes pour lesquels l'authentification à deux facteurs est activée si vous perdez votre téléphone ou votre YubiKey. Les codes de récupération vous permettent d'accéder tout de même à votre compte avec un téléphone ou une YubiKey perdu(e), puis de le reconfigurer à partir de là.



Après avoir configuré avec succès votre authentification à deux facteurs, vous recevez un ensemble de codes de récupération générés aléatoirement, que vous devez consulter et enregistrer. Nous vous recommandons vivement de les enregistrer immédiatement. Vous pouvez toutefois les télécharger à tout moment après l'activation de l'authentification à deux facteurs. Pour plus d'informations, consultez [Téléchargement des codes de récupération de l'authentification à deux facteurs](https://plaidcloud.com/docs/identity/downloading-your-two-factor-authentication-recovery-codes).


<Aside>Si vous n'avez ni code de secours ni clé de secours enregistré, un processus beaucoup plus strict est appliqué, qui peut nécessiter plusieurs jours pour valider l'authenticité de la demande d'accès et préserver la sécurité de PlaidCloud.</Aside>



### YubiKey perdue


Vous pouvez indiquer un numéro de SMS dans votre profil. Si vous perdez à la fois l'accès à votre ensemble de YubiKey enregistrées et à vos codes de récupération, un numéro de SMS de secours peut vous permettre de retrouver l'accès à votre compte.


<Aside>Ce processus n'est pas automatisé : le rétablissement de l'accès peut donc prendre un certain temps.</Aside>


Si le membre utilise une clé du parc géré et la perd, l'administrateur du parc de l'espace de travail peut marquer la clé comme perdue et en délivrer une nouvelle. Cela réduit le risque d'être exclu d'un compte ou de devoir conserver des codes de récupération.



Pour marquer une clé comme perdue :


1. Ouvrez Identity
2. Sélectionnez « Security »
3. Cliquez sur « PlaidCloud Security Keys »
4. Cliquez sur l'icône de modification
5. Sélectionnez « Lost » dans la section Key Usage Information
6. Cliquez sur « Update »

La clé est alors marquée comme perdue et vous pouvez en délivrer une nouvelle.



## Authentification unique


L'authentification unique nécessite un service externe pour effectuer le processus d'authentification proprement dit ; PlaidCloud reçoit simplement une réponse positive ou négative. L'utilisation de l'authentification unique peut réduire les tâches d'administration liées à la gestion des mots de passe entre plusieurs applications et garantir de bonnes pratiques de gestion des membres lors des départs de collaborateurs ou de l'application de restrictions d'accès.



L'authentification unique est l'option la plus simple pour les membres. Elle est aussi sûre que le processus d'authentification utilisé par le tiers externe. Elle contribue à garantir que les mots de passe sont à jour et synchronisés avec les autres services avec lesquels le membre interagit.



Bien que l'authentification unique exige un processus d'authentification plus élaboré en arrière-plan, et nécessite généralement une coordination technique avec l'informatique et/ou la sécurité réseau, elle peut être utilisée par tous, même si elle est généralement adoptée par les grandes entreprises et les établissements universitaires.



Pour plus d'informations sur la configuration et la gestion de l'authentification unique, consultez la [section Gestion des organisations et des espaces de travail.](/fr/administration/access/advanced/managing-single-sign-on-for-organization)
