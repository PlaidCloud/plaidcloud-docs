Si vous ne souhaitez pas conserver les membres inactifs dans PlaidCloud, vous pouvez configurer leur suppression automatique de l'organisation après une période d'inactivité donnée, grâce aux capacités d'expiration de PlaidCloud. Cette suppression automatique des membres dormants peut être fixée à un jour seulement, si vous le souhaitez.

<Aside>Si vous définissez cette option sur zéro (0), aucune suppression automatique n'a lieu pour l'organisation.</Aside>


**Pour définir l'expiration des membres :**

1. Sélectionnez le menu « Organization Settings » en haut à droite de l'écran.
2. Cliquez sur « Organization and User Settings ».
3. Définissez le nombre de jours avant expiration.
4. Cliquez sur Update.
