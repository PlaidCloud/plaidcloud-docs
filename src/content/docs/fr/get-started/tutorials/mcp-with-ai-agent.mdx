Ce tutoriel configure un agent de codage IA pour qu'il interagisse avec votre espace de travail PlaidCloud grâce au **Model Context Protocol** (MCP). Une fois la configuration terminée, vous pouvez demander à l'agent de lire des tables, d'exécuter des workflows, de créer des allocations et de répondre à des questions sur vos données, directement depuis votre éditeur.

Compter environ 20 minutes. Fonctionne avec Claude Code, Cursor, Claude Desktop, ChatGPT, GitHub Copilot et tout client compatible MCP.

## Ce que vous allez créer

Une connexion opérationnelle entre votre agent de codage IA et votre espace de travail PlaidCloud, grâce à laquelle l'agent peut :

- Lister les projets, tables, workflows et dimensions
- Lire le contenu des tables
- Inspecter les définitions de workflow
- Déclencher des exécutions de workflow
- Répondre à des questions sur vos données sans que vous changiez de contexte

## Prérequis

- Un espace de travail PlaidCloud ([démarrez un essai gratuit](https://app.plaidcloud.com) si vous n'en avez pas)
- Un agent de codage IA que vous utilisez déjà : Claude Code, Cursor, Claude Desktop, ChatGPT, Copilot ou Gemini
- L'agent doit prendre en charge MCP (c'est le cas de la plupart des outils d'IA actuels)

## Étape 1 : trouver l'URL MCP de votre espace de travail

Chaque espace de travail PlaidCloud expose un point de terminaison MCP à l'adresse suivante :

```text
https://<your-workspace>.plaid.cloud/mcp
```

Remplacez `<your-workspace>` par le sous-domaine de votre espace de travail, celui que vous utilisez pour vous connecter à l'interface PlaidCloud.

## Étape 2 : obtenir un jeton d'authentification

<Steps>

1. Pendant que vous êtes connecté à PlaidCloud dans un navigateur, accédez à l'adresse suivante :
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. Copiez le jeton porteur affiché sur la page. Conservez-le en lieu sûr : il donne les mêmes accès que votre compte.

</Steps>

<Aside type="caution">
Traitez le jeton comme un mot de passe. Il contourne l'authentification interactive et agit en votre nom. S'il est divulgué, révoquez-le depuis le même point de terminaison.
</Aside>

## Étape 3 : configurer votre agent

<Tabs>

<TabItem label="Claude Code">

Exécutez la commande suivante dans votre terminal :

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

Pour une authentification par jeton statique (sans flux OAuth, plus simple pour les longues sessions), ouvrez dans un navigateur l'URL de l'étape 2, copiez l'extrait de configuration affiché et collez-le dans votre fichier `.mcp.json`.

Consultez la [configuration de Claude Code](/fr/integrations/ai-coding-agents/claude-code/) pour toutes les options.

</TabItem>

<TabItem label="Cursor">

Obtenez un jeton porteur depuis `https://<your-workspace>.plaid.cloud/mcp/setup/token` et ajoutez ceci à votre configuration MCP de Cursor :

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

Consultez la [configuration de Cursor](/fr/integrations/ai-coding-agents/cursor/) pour toutes les options.

</TabItem>

<TabItem label="Claude Desktop">

Ouvrez Settings → Developer → MCP Servers et ajoutez :

- **URL du serveur** : `https://<your-workspace>.plaid.cloud/mcp`
- Utilisez la connexion OAuth lorsque vous y êtes invité

Consultez la [configuration de Claude Desktop](/fr/integrations/ai-coding-agents/claude-desktop/) pour toutes les options.

</TabItem>

<TabItem label="ChatGPT">

1. Settings → Connectors → Add custom connector
2. Saisissez :
   - **Nom** : `PlaidCloud`
   - **URL du serveur MCP** : `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT vous redirige vers PlaidCloud pour la connexion OAuth. Approuvez la connexion.
4. Activez le connecteur dans chaque conversation qui doit l'utiliser.

Consultez la [configuration de ChatGPT](/fr/integrations/ai-coding-agents/chatgpt/) pour toutes les options.

</TabItem>

<TabItem label="Copilot">

Obtenez un jeton porteur et ajoutez-le à `.vscode/mcp.json` :

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

VSCode lit ce fichier au démarrage et à chaque modification.

Consultez la [configuration de Copilot](/fr/integrations/ai-coding-agents/copilot/) pour toutes les options.

</TabItem>

</Tabs>

## Étape 4 : vérifier la connexion

Posez une question simple à l'agent :

> « Liste les projets de mon espace de travail PlaidCloud. »

L'agent doit répondre avec la liste de vos projets. Dans le cas contraire, consultez les conseils de dépannage ci-dessous.

## Étape 5 : essayer des tâches réelles

Une fois la connexion établie, essayez par exemple :

- **Explorer vos données** : « Quelles colonnes contient la table `sales` de mon projet Quickstart ? »
- **Exécuter un workflow** : « Déclenche le workflow `monthly_close` dans le projet Financials et préviens-moi quand il se termine. »
- **Créer quelque chose** : « Crée une étape Table Lookup dans mon workflow Test qui filtre les commandes des 30 derniers jours. »

Les réponses de l'agent s'appuient sur l'état réel de votre espace de travail, et non sur des réponses génériques.

## Dépannage

Si l'agent ne parvient pas à joindre PlaidCloud ou renvoie des erreurs d'authentification :

- **Jeton expiré** : actualisez-le à l'adresse `https://<your-workspace>.plaid.cloud/mcp/setup/token`
- **Mauvaises portées** : certains outils exigent des portées PlaidCloud précises (par exemple `analyze.workflow.write`). Exécutez `mcp_introspect(name='<tool>')` dans l'agent pour voir les portées requises
- **Sous-domaine de l'espace de travail incorrect** : vérifiez-le en vous connectant à l'interface PlaidCloud ; le sous-domaine est la partie qui précède `.plaid.cloud`

Consultez le [dépannage des agents de codage IA](/fr/integrations/ai-coding-agents/troubleshooting/) pour en savoir plus.
