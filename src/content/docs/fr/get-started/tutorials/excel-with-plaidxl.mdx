*~20 minutes · installer le complément, se connecter, récupérer une table, écrire une formule en direct*

Si vos journées reposent déjà sur des tableurs, vous n'avez pas besoin de quitter Excel pour travailler avec PlaidCloud. **PlaidXL** est le complément PlaidCloud pour Excel : il récupère des tables de projet dans des feuilles de calcul, les actualise à la demande et ajoute des formules qui calculent des valeurs consolidées directement à partir des données PlaidCloud. À la fin de ce tutoriel, vos données d'entrée proviennent de tables de projet faisant autorité, et non d'un copier-coller qui devient périmé dès que quelqu'un relance un workflow.

## Ce que vous allez faire

1. Installer le complément PlaidXL.
2. Vous connecter et choisir un projet.
3. Récupérer une table dans une feuille de calcul, puis l'actualiser.
4. Écrire des formules qui listent les tables du projet et calculent un total.

## Prérequis

- Excel pour Microsoft 365, ou Excel 2021 ou version ultérieure, sous Windows ou Mac.
- Un compte PlaidCloud. Si vous utilisez l'authentification unique pour PlaidCloud, continuez à l'utiliser ici — PlaidXL se connecte via la même identité.
- Un projet que vous pouvez ouvrir, avec au moins une table contenant des données et une colonne numérique. N'importe quel projet auquel vous avez déjà accès convient. Si vous n'en avez pas encore, [Du CSV à la réponse](/fr/get-started/tutorials/csv-to-answer/) vous permet de charger une table dans PlaidCloud.

<Aside>PlaidXL lit avec vos autorisations. Vous voyez les projets et les tables que votre compte peut déjà voir dans PlaidCloud — rien de plus — et PlaidXL ne les modifie jamais.</Aside>

## Étape 1 : installer le complément

1. Dans Excel, ouvrez **Insert → Add-ins**. (Dans les anciennes versions de Mac, **Insert → Store**.)
2. Saisissez `PlaidCloud` dans la zone de recherche.
3. Sélectionnez le complément **PlaidCloud** et cliquez sur **Ajouter**.

Un onglet **PlaidCloud** apparaît dans le ruban. Vous l'installez une fois par ordinateur, pas par classeur.

<Aside type="tip">Vous ne voyez pas l'onglet **PlaidCloud** ? Fermez toutes les fenêtres Excel et rouvrez Excel. Si votre organisation gère les compléments, votre administrateur Microsoft 365 devra peut-être le déployer pour vous. Consultez [Installer PlaidXL](/fr/reference/cli/plaidxl/install/).</Aside>

## Étape 2 : se connecter et choisir un projet

1. Ouvrez un nouveau classeur et cliquez sur **PlaidCloud → Show Taskpane**.
2. Saisissez l'adresse e-mail que vous utilisez pour PlaidCloud et cliquez sur **Sign In**.
3. Si vous appartenez à plusieurs espaces de travail, choisissez-en un dans **Select a tenant** et cliquez sur **Sign In**.
4. Autorisez la fenêtre contextuelle lorsqu'Excel vous le demande, puis connectez-vous comme d'habitude — mot de passe et code à deux facteurs, ou authentification unique.

Le volet de tâches affiche **Connected to** l'ID de votre espace de travail **as** votre nom d'utilisateur, avec vos projets en dessous. Cliquez sur votre projet. Ses tables apparaissent dans l'onglet **Tables**.

## Étape 3 : récupérer une table

1. Dans l'onglet **Tables**, cliquez sur une table. **Lignes** et **Colonnes** indiquent sa taille.
2. Sous **Colonne**, décochez les colonnes dont vous n'avez pas besoin. Moins de colonnes se chargent plus vite.
3. Laissez **Matching Worksheet** sélectionné et cliquez sur **Retrieve Table**.

La table arrive dans une nouvelle feuille de calcul portant son nom, prête à l'emploi : une ligne d'en-tête en gras qui reste visible pendant le défilement, des filtres sur chaque colonne et une plage nommée sur les données. Une table nommée **Sample data** arrive dans la feuille `Sample_data` avec la plage nommée `_Sample_data`, de sorte que les formules qui utilisent cette plage suivent les données lorsqu'elles s'allongent.

Créez des formules, des tableaux croisés dynamiques et des graphiques à partir de cette table comme sur n'importe quelle feuille.

## Étape 4 : l'actualiser

Lorsque la table change dans PlaidCloud — un workflow est relancé, de nouvelles données sont chargées — cliquez sur **Refresh All Tables** dans le volet de tâches ou dans le ruban. L'onglet de la feuille devient jaune pendant l'actualisation, puis vert lorsqu'elle est à jour. Toutes les tables récupérées dans le classeur sont actualisées, avec les colonnes et le filtre que vous avez choisis.

## Étape 5 : écrire une formule en direct

Le volet de tâches copie des tables. Les formules PlaidXL vont plus loin : elles calculent à partir des données PlaidCloud dans n'importe quelle cellule.

1. Sur une nouvelle feuille, listez les tables du projet en `A1` :

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   Les noms se déversent vers le bas de la colonne A.

2. Listez les colonnes de votre table en `C1`, en remplaçant `Sample data` par le nom de votre table :

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. Choisissez une colonne numérique dans cette liste, ainsi qu'une colonne de texte contenant une valeur que vous savez présente. Totalisez la colonne numérique pour cette valeur, en remplaçant les noms par les vôtres :

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` affiche le total de **amount** pour les lignes où **Region** vaut **EMEA** — calculé dans PlaidCloud, en direct dans votre feuille. Modifiez la valeur en `E3` et le total suit.

Lorsque la colonne est liée à une [dimension](/fr/guides/dimensions/dimensions/), la valeur peut être n'importe quel nœud de celle-ci, et le total consolide tout ce qui se trouve sous ce nœud. C'est ainsi qu'un rapport PlaidXL totalise une région, un département ou une année à partir des lignes de détail.
