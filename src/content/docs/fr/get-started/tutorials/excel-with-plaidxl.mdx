*~20 minutes · installer le complément, se connecter, récupérer une table, écrire une formule dynamique*

Si votre travail quotidien repose déjà sur des feuilles de calcul, vous n'avez pas à quitter Excel pour utiliser PlaidCloud. **PlaidXL** est le complément PlaidCloud pour Excel : il charge les tables de projet dans des feuilles de calcul, les actualise à la demande et ajoute des formules qui calculent des valeurs consolidées directement à partir des données PlaidCloud. À la fin de ce tutoriel, vos données d'entrée proviennent de tables de projet de référence, et non d'un copier-coller qui devient obsolète dès que quelqu'un réexécute un workflow.

## Ce que vous allez faire

1. Installer le complément PlaidXL.
2. Vous connecter et choisir un projet.
3. Récupérer une table dans une feuille de calcul, puis l'actualiser.
4. Écrire des formules qui listent les tables du projet et calculent un total.

## Prérequis

- Excel pour Microsoft 365, ou Excel 2021 ou version ultérieure, sous Windows ou Mac.
- Un compte PlaidCloud. Si vous utilisez l'authentification unique pour PlaidCloud, continuez à l'utiliser ici : PlaidXL se connecte via la même identité.
- Un projet que vous pouvez ouvrir, contenant au moins une table avec des données et une colonne numérique. Tout projet auquel vous avez déjà accès convient. Si vous n'en avez pas encore, [From CSV to Answer](/fr/get-started/tutorials/csv-to-answer/) explique comment charger une table dans PlaidCloud.

<Aside>PlaidXL lit les données avec vos autorisations. Vous voyez les projets et les tables que votre compte peut déjà voir dans PlaidCloud, et rien de plus. PlaidXL ne modifie une table que lorsque vous y écrivez vous-même.</Aside>

## Étape 1 : installer le complément

1. Dans Excel, ouvrez **Insert → Add-ins**. (Dans les anciennes versions de Mac, **Insert → Store**.)
2. Saisissez `PlaidCloud` dans la zone de recherche.
3. Sélectionnez le complément **PlaidCloud** et cliquez sur **Ajouter**.

Un onglet **PlaidCloud** apparaît dans le ruban. Vous l'installez une seule fois par ordinateur, et non par classeur.

<Aside type="tip">Vous ne voyez pas l'onglet **PlaidCloud** ? Fermez toutes les fenêtres Excel et rouvrez Excel. Si votre organisation gère les compléments, votre administrateur Microsoft 365 devra peut-être le déployer pour vous. Consultez [Install PlaidXL](/fr/reference/cli/plaidxl/install/).</Aside>

## Étape 2 : se connecter et choisir un projet

1. Ouvrez un nouveau classeur et cliquez sur **PlaidCloud → Open PlaidXL**.
2. Saisissez l'adresse e-mail que vous utilisez pour PlaidCloud et cliquez sur **Sign In**. Si vous êtes connecté à Office avec votre compte professionnel, PlaidXL peut trouver votre espace de travail à votre place ; consultez [Sign In With Your Office Account](/fr/reference/cli/plaidxl/connect/#se-connecter-avec-votre-compte-office).
3. Si vous appartenez à plusieurs espaces de travail, choisissez-en un dans **Select a workspace** et cliquez sur **Sign In**.
4. Autorisez la fenêtre contextuelle lorsque Excel vous le demande, puis connectez-vous comme d'habitude : mot de passe et code à deux facteurs, ou authentification unique.

L'en-tête du volet des tâches affiche votre espace de travail. Cliquez sur le nom du projet dans l'en-tête pour ouvrir vos projets, puis cliquez sur votre projet ; si vous ne pouvez ouvrir qu'un seul projet, PlaidXL le lie pour vous. Le classeur s'en souvient. Ses tables apparaissent dans l'onglet **Tables**.

## Étape 3 : récupérer une table

1. Dans l'onglet **Tables**, cliquez sur une table. **Lignes** et **Colonnes** indiquent sa taille.
2. Sous **Colonne**, décochez les colonnes dont vous n'avez pas besoin. Moins il y a de colonnes, plus le chargement est rapide.
3. Laissez **Matching Worksheet** sélectionné et cliquez sur **Retrieve Table**.

La table arrive dans une nouvelle feuille de calcul portant son nom, sous forme de tableau Excel : une table nommée **Sample data** arrive dans la feuille `Sample_data`. La ligne d'en-tête reste visible pendant le défilement, chaque colonne dispose d'un filtre, et les formules qui font référence au tableau Excel suivent les données à mesure qu'elles augmentent.

Créez des formules, des tableaux croisés dynamiques et des graphiques à partir de cette table comme sur n'importe quelle feuille.

## Étape 4 : l'actualiser

Lorsque la table change dans PlaidCloud (un workflow est réexécuté, de nouvelles données sont chargées), cliquez sur **Refresh All Tables** dans le volet des tâches, ou sur **Refresh → Refresh all tables** dans le ruban. Le volet des tâches affiche la progression de chaque table, avec **Annuler**, et indique les lignes actualisées une fois l'opération terminée. Toutes les tables que vous avez récupérées dans le classeur sont actualisées, avec les colonnes et le filtre que vous avez choisis.

## Étape 5 : écrire une formule dynamique

Le volet des tâches copie les tables dans le classeur. Les formules PlaidXL vont plus loin : elles calculent à partir des données PlaidCloud dans n'importe quelle cellule.

1. Dans une nouvelle feuille, listez les tables du projet en `A1` :

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   Les noms se déversent vers le bas dans la colonne A.

2. Listez les colonnes de votre table en `C1`, en remplaçant `Sample data` par le nom de votre table :

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. Choisissez une colonne numérique dans cette liste, ainsi qu'une colonne de texte contenant une valeur que vous savez présente. Totalisez la colonne numérique pour cette valeur, en remplaçant les noms par les vôtres :

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` affiche le total de **amount** pour les lignes où **Région** vaut **EMEA**, calculé dans PlaidCloud et dynamique dans votre feuille. Modifiez la valeur en `E3` et le total suit.

Lorsque la colonne est liée à une [dimension](/fr/guides/dimensions/dimensions/), la valeur peut être n'importe quel nœud de cette dimension, et le total consolide tout ce qui se trouve sous ce nœud. C'est ainsi qu'un rapport PlaidXL totalise une région, un service ou une année à partir des lignes de détail.
