PlaidCloud s'exécute dans votre navigateur web, sans rien à installer. Il nécessite l'un de ces navigateurs, dans cette version ou une version ultérieure.

## Versions minimales

| Navigateur | Version minimale |
| --- | --- |
| Google Chrome | 94 |
| Microsoft Edge | 94 |
| Mozilla Firefox | 93 |
| Safari sur Mac | 16.4 |
| Tout navigateur sur iPad ou iPhone | iPadOS ou iOS 16.4 |

La plupart des navigateurs se mettent à jour d'eux-mêmes ; un navigateur tenu à jour dépasse donc déjà largement ces versions.

## iPad et iPhone

Les applications de navigation sur iPad ou iPhone, y compris Chrome et Firefox, reposent sur le moteur de Safari. Ce qui compte alors, c'est la version d'iPadOS ou d'iOS de l'appareil, et non l'application de navigation que vous utilisez. Pour la mettre à jour, ouvrez **Réglages** > **Général** > **Mise à jour logicielle**.

<Aside type="caution">
L'iPad Air 2 et l'iPad mini 4 ne peuvent pas être mis à jour au-delà d'iPadOS 15 ; PlaidCloud ne fonctionne donc pas sur ces appareils. Utilisez plutôt un ordinateur ou un iPad plus récent.
</Aside>

## Ce qu'affiche un navigateur plus ancien

Un navigateur plus ancien ne charge pas PlaidCloud. Il affiche une page **PlaidCloud nécessite un navigateur plus récent** qui indique les versions ci-dessus. Mettez à jour le navigateur, ou ouvrez PlaidCloud dans l'un des navigateurs listés ici.
