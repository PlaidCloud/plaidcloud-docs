Le lanceur est la première chose que vous voyez après vous être connecté à un
espace de travail. Il rassemble ce que vous utilisez le plus (projets,
workflows, tables, tableaux de bord, applications Panel, dimensions, éditeurs
de données et documents) sur une seule page de vignettes, afin que vous puissiez
reprendre là où vous en étiez sans fouiller dans chaque application.

## Zones

La page est organisée en trois zones, de haut en bas. Une zone n'apparaît que
si elle a quelque chose à afficher.

- **Nécessite une attention** : les workflows dont l'exécution la plus récente
  a échoué, afin que les problèmes apparaissent dès votre arrivée. Chaque carte
  mène directement à l'exécution en échec, et vous pouvez **Ignorer** celle que
  vous avez déjà traitée.
- **Épinglés** : tout ce que vous avez marqué comme favori, dans l'ordre où vous
  l'avez épinglé. N'importe quel type d'élément peut être épinglé ici (voir
  [Épinglage](#épinglage-favoris)).
- **Récents** : les projets, tableaux de bord et applications Panel que vous
  avez ouverts ou modifiés récemment.

<Aside type="note">
Seuls les projets, les tableaux de bord et les applications Panel apparaissent
selon leur récence : il y a généralement beaucoup trop de workflows, de tables,
de dimensions, d'éditeurs de données et de documents pour les lister de cette
façon. Faites ressortir ceux auxquels vous revenez en les épinglant, et ils vous
attendront dans la zone **Épinglés**.
</Aside>

## Vignettes de projet

Une vignette de projet résume le projet en un coup d'œil :

| Statistique | Signification |
|---|---|
| **Exécutions de workflow** | Exécutions de workflow terminées sur la période récente |
| **Dernière exécution** | Moment où l'exécution la plus récente s'est terminée |
| **Workflows** | Workflows que contient le projet |
| **Tables** | Tables que contient le projet |
| **Enregistrements** | Nombre total de lignes dans ces tables (un `~` indique une estimation) |

Un projet sans historique d'exécution affiche **Dernière modification** à la
place des chiffres d'exécution, et les compteurs sont entièrement omis lorsqu'ils
valent zéro.

### Images de vignette

Chaque vignette de projet porte une image d'arrière-plan estompée. Par défaut,
il s'agit de l'éventail PlaidCloud, mais vous pouvez donner à un projet sa propre
image (le logo d'un client, par exemple, ou tout élément qui identifie le travail
d'un coup d'œil) afin qu'il se démarque dans un lanceur chargé.

Pour en définir une :

1. Ouvrez le projet et accédez à son onglet **Accueil**.
2. Faites défiler jusqu'à **Image de la vignette du lanceur**, au bas de la
   colonne de gauche.
3. Choisissez le compte de documents qui contient l'image, puis **Parcourir**
   pour sélectionner le fichier image.
4. Utilisez **Effacer** pour revenir à l'image par défaut.

L'image est estompée derrière les statistiques pour qu'elles restent lisibles ;
choisissez donc quelque chose qui reste agréable à l'œil une fois atténué. Les
images larges conviennent mieux à la forme de la vignette que les images hautes.
Vous avez besoin de l'autorisation de modifier le projet pour la définir ; un
lecteur en lecture seule voit le sélecteur désactivé.

<Aside type="note">
Toute personne pouvant voir le projet voit l'image de sa vignette, mais l'image
n'est servie qu'aux personnes qui peuvent aussi lire le compte de documents où
elle se trouve. Un lecteur sans cet accès voit simplement l'éventail par défaut.
</Aside>

Les vignettes de tableau de bord fonctionnent différemment : elles affichent une
miniature générée automatiquement du tableau de bord lui-même, il n'y a donc
rien à choisir.

## Ouvrir des éléments

Chaque carte et chaque ligne de liste a une action principale et, lorsque c'est
pertinent, des actions supplémentaires :

| Élément | Ouvre | Également disponible |
|---|---|---|
| Projet | Le projet | |
| Workflow | Le workflow | Exécuter, Ouvrir la dernière exécution, statut en direct **En cours d'exécution** |
| Table | La table | Ouvrir dans l'explorateur de tables |
| Dimension | Son éditeur de hiérarchie | |
| Éditeur de données | Son projet | |
| Tableau de bord | Le tableau de bord | Ouvrir dans un nouvel onglet |
| Application Panel | L'application | Ouvrir dans un nouvel onglet |
| Application Dash | L'application | Ouvrir dans un nouvel onglet |
| Document | Le fichier ou le dossier | |

Un workflow en cours d'exécution affiche un indicateur de statut en direct qui
se met à jour tout seul, sans avoir besoin d'actualiser.

## Épinglage (favoris)

Cliquez sur l'**étoile** de n'importe quelle carte ou ligne de liste du lanceur
pour l'épingler. Les éléments épinglés apparaissent toujours dans la zone
**Épinglés**, quelle que soit la date de votre dernière utilisation, de sorte
que ce qui compte pour vous ne sort jamais de votre portée.

Vous pouvez aussi épingler depuis l'endroit où vous travaillez déjà, sans ouvrir
d'abord le lanceur : repérez la colonne des étoiles :

- **Projets, workflows, tables, dimensions et éditeurs de données** : la colonne
  des étoiles dans la liste de chacun, à l'intérieur du projet.
- **Tableaux de bord**, **applications Panel** et **applications Dash** : la
  colonne des étoiles dans Mes tableaux de bord et Mes applications Panel.
- **Documents** : faites un clic droit sur un fichier *ou* un dossier dans le
  navigateur de documents et choisissez **Épingler au lanceur**.

Cliquez sur une étoile allumée, où que ce soit, pour désépingler. Les
épinglages effectués n'importe où sont reflétés immédiatement dans le lanceur.

## Vignettes ou liste

Utilisez la bascule **Vignettes / Liste** de la barre d'outils pour passer de la
vue en cartes spacieuses à une liste dense sur une seule ligne. Votre choix est
mémorisé et le basculement est instantané : il redessine ce qui est déjà chargé
sans effectuer de nouvelle récupération.

## Filtrer par type

La rangée de pastilles à gauche de la barre d'outils comporte une pastille par
type, chacune avec sa propre icône : **Projets**, **Tableaux de bord**,
**Applications Panel**, **Workflows**, **Tables**, **Dimensions**, **Éditeurs de
données** et **Documents**. Une pastille enfoncée signifie que ce type est
affiché ; cliquez dessus pour masquer ce type dans les zones **Récents** et
**Épinglés**. Votre filtre est mémorisé d'une visite à l'autre.

La zone **Nécessite une attention** n'est jamais filtrée : un workflow en échec
apparaît toujours, même lorsque la pastille de son type est désactivée.

## Recherche et commandes

Appuyez sur **Ctrl/Cmd-K** sur n'importe quel écran, ou cliquez sur
**Rechercher** dans la barre d'outils du lanceur, pour ouvrir la palette de
commandes. La seule exception est le Registre des écritures, qui réserve
**Ctrl/Cmd-K** à sa propre palette.

Avant que vous ne saisissiez quoi que ce soit, elle liste deux choses :

- **Actions** : les commandes que vous pouvez exécuter d'ici : aller à Accueil,
  Projets, Tableaux de bord ou Documents, basculer entre l'apparence claire et
  sombre, connecter votre IA et obtenir de l'aide. Les actions **Aller à**
  n'apparaissent que pour les applications dont dispose votre espace de travail.
- **Récents** : les huit dernières choses que vous avez ouvertes, de la plus
  récente à la plus ancienne : projets, workflows, tables, dimensions, éditeurs
  de données, tableaux de bord, applications Panel et documents ouverts depuis le
  lanceur ou la palette, ainsi que chaque projet que vous ouvrez où que ce soit.
  Un élément ouvert depuis l'intérieur d'un projet (un workflow, par exemple, ou
  une dimension) n'est pas ajouté. Cette liste est conservée dans votre
  navigateur ; elle n'est donc pas partagée entre les appareils, et elle est
  distincte de la zone **Récents** du lanceur (voir [Zones](#zones)).

Commencez à saisir et les deux listes se réduisent en même temps : les
caractères saisis doivent seulement apparaître dans l'ordre, si bien que `proj`
trouve **Aller à Projets**, la correspondance la plus proche en premier. À partir
de deux caractères, la palette effectue aussi une recherche dans les projets,
workflows, tables, tableaux de bord et applications Panel, et ajoute ces
résultats en dessous, regroupés par type, chacun avec les mêmes actions
d'ouverture et la même étoile d'épinglage que sur le tableau. Un résultat déjà
affiché sous **Récents** n'est pas répété.

- **Haut / Bas** déplacent la sélection.
- **Entrée** exécute l'action sélectionnée ou ouvre l'élément sélectionné.
- **Échap** ferme la palette.

Les dimensions, les éditeurs de données et les documents ne sont pas
recherchables : accédez-y en les épinglant, depuis **Récents** une fois que vous
les avez ouverts depuis le lanceur, ou depuis le projet auquel ils appartiennent.

Cliquer sur un résultat l'ouvre ; cliquer sur son **étoile** l'épingle et laisse
la palette ouverte, ce qui vous permet d'épingler plusieurs éléments en une seule
passe.

## Actualisation

Le lanceur s'actualise tout seul lorsque vous y revenez et que ses données sont
devenues obsolètes. Pour obtenir immédiatement les dernières données, cliquez sur
**Actualiser** dans la barre d'outils.

## Démarrer ailleurs

Le lanceur est l'endroit où PlaidCloud s'ouvre par défaut. Pour démarrer plutôt
sur une autre application, désactivez **Démarrer sur le lanceur** dans le menu
Options.

## Apparence (clair, sombre, auto)

Le bouton **Apparence** de la barre d'outils supérieure (l'icône de contraste à
côté du menu du compte) bascule PlaidCloud entre une apparence claire et une
apparence sombre. Il s'applique partout : le lanceur, chaque application, ainsi
que chaque fenêtre et boîte de dialogue qu'elles contiennent.

| Choix | Effet |
| --- | --- |
| **Clair** | Utilise toujours l'apparence claire, quel que soit le réglage de votre appareil. |
| **Sombre** | Utilise toujours l'apparence sombre, quel que soit le réglage de votre appareil. |
| **Auto (système)** | Suit le réglage d'apparence de votre système d'exploitation. |

**Auto (système)** est la valeur par défaut, et il suit votre système en direct :
si votre ordinateur est réglé pour passer en sombre le soir, PlaidCloud suit au
même moment, sans rechargement. Choisir **Clair** ou **Sombre** fige l'apparence
et ignore dès lors le réglage du système.

<Aside type="note">
Votre choix est mémorisé dans le navigateur où vous l'avez effectué ; il n'est
donc pas reporté sur un autre navigateur ou un autre ordinateur : définissez-le
une fois dans chacun. Effacer les données de site de votre navigateur le
réinitialise sur **Auto**. Si votre navigateur bloque le stockage local (certains
modes de navigation privée le font), le sélecteur fonctionne toujours pour la
session mais repart sur **Auto** la fois suivante.
</Aside>

Le contenu intégré conserve ses propres couleurs : les tableaux de bord et les
applications Panel ne sont pas restylisés par ce réglage.
