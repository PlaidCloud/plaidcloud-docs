Un dépôt contient les fichiers, les branches et l'historique d'un projet. Ce guide explique comment créer un dépôt et vous y connecter depuis votre ordinateur.

## Créer un dépôt

1. Ouvrez **Git** depuis votre espace de travail.
2. Sélectionnez le menu **+** en haut à droite, puis **New Repository**.
3. Saisissez un nom et, éventuellement, une courte description.
4. Choisissez la visibilité. Les nouveaux dépôts sont **Privé** par défaut : seuls les membres auxquels vous accordez l'accès peuvent les voir.
5. Si vous le souhaitez, sélectionnez **Initialize Repository** pour ajouter un README, un `.gitignore` et une licence.
6. Sélectionnez **Create Repository**.

## Générer un jeton d'accès personnel

Comme vous vous connectez via PlaidCloud, votre compte n'a pas de mot de passe Git distinct. Pour cloner ou pousser en HTTPS depuis la ligne de commande, créez un jeton d'accès personnel et utilisez-le à la place d'un mot de passe.

1. Sélectionnez votre avatar en haut à droite, puis **Paramètres**. La carte de configuration de l'onglet **Git** renvoie aussi directement vers cette page.
2. Ouvrez l'onglet **Applications**.
3. Sous **Manage Access Tokens**, saisissez un nom qui indique où vous utiliserez le jeton (par exemple, `laptop`).
4. Sélectionnez l'autorisation **write:repository** pour que le jeton puisse cloner et pousser.
5. Sélectionnez **Generate Token**.
6. Copiez le jeton et conservez-le en lieu sûr. Vous ne pourrez plus l'afficher ensuite.

<Aside type="caution">Traitez le jeton comme un mot de passe : toute personne qui le possède peut agir en votre nom dans Git. Générez un jeton distinct par machine afin de pouvoir en révoquer un sans perturber les autres.</Aside>

## Cloner un dépôt

1. Ouvrez **Git** dans votre espace de travail et sélectionnez le bouton de copie à côté de l'adresse de clonage du dépôt (sélectionnez **How to clone** pour voir les étapes de configuration). Vous pouvez aussi sélectionner **Code** dans le dépôt et copier l'URL **HTTPS**.
2. Dans un terminal, exécutez `git clone` avec cette URL :

   ```bash
   git clone <clone URL>
   ```

3. Lorsque Git demande un mot de passe, collez le **jeton d'accès**. Utilisez le nom d'utilisateur déjà présent dans l'URL.
4. Définissez le nom et l'adresse e-mail que Git enregistre dans vos commits, avec les valeurs affichées par la carte de configuration :

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Vous avez besoin de l'accès Contributeur ou Administrateur pour pousser ; en tant que Lecteur, vous pouvez lire mais pas pousser. Consultez [Niveaux d'accès](/fr/guides/git/#niveaux-daccès).

<Aside>Pour éviter de ressaisir le jeton à chaque push, vous pouvez laisser l'assistant d'identifiants Git de votre système d'exploitation le mémoriser, par exemple `git config --global credential.helper osxkeychain` sur macOS.</Aside>

## Valider et pousser des modifications

Depuis un dépôt cloné :

1. Indexez vos modifications : `git add .`
2. Enregistrez-les avec un message : `git commit -m "Describe what changed"`
3. Envoyez-les à PlaidCloud Git : `git push`

Vos commits apparaissent dans les vues **Commits** et **Activité** du dépôt, ainsi que sur toute branche ou pull request qui les inclut.

## Gérer l'accès et la visibilité

Ouvrez l'onglet **Paramètres** d'un dépôt pour le renommer, modifier sa visibilité ou transférer sa propriété. Pour permettre à d'autres membres de contribuer, utilisez **Paramètres → Collaborators** et ajoutez-les par nom d'utilisateur avec un rôle **Lecture**, **Écriture** ou **Administrateur**.

<Aside>L'accès aux dépôts suit aussi l'appartenance à votre espace de travail et vos groupes de sécurité. Consultez [Gestion des accès](/fr/administration/access/) pour savoir comment ils déterminent qui peut voir et modifier un dépôt.</Aside>
