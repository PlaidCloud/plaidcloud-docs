Un dépôt contient les fichiers, les branches et l'historique d'un projet. Ce guide explique comment créer un dépôt et vous y connecter depuis votre ordinateur.

## Créer un dépôt

1. Ouvrez **Git** depuis votre espace de travail.
2. Sélectionnez le menu **+** dans le coin supérieur droit, puis **New Repository**.
3. Saisissez un nom et, éventuellement, une brève description.
4. Choisissez la visibilité. Les nouveaux dépôts sont **Privé** par défaut — seuls les membres auxquels vous accordez l'accès peuvent les voir.
5. Sélectionnez éventuellement **Initialize Repository** pour ajouter un fichier README, un fichier `.gitignore` et une licence.
6. Sélectionnez **Create Repository**.

## Générer un jeton d'accès personnel

Comme vous vous connectez via PlaidCloud, votre compte n'a pas de mot de passe Git distinct. Pour cloner ou envoyer du code en HTTPS depuis la ligne de commande, créez un jeton d'accès personnel et utilisez-le à la place d'un mot de passe.

1. Sélectionnez votre avatar dans le coin supérieur droit, puis **Paramètres**. L'astuce de l'onglet **Git** renvoie aussi directement vers cette page.
2. Ouvrez l'onglet **Applications**.
3. Sous **Manage Access Tokens**, saisissez un nom qui décrit l'endroit où vous utiliserez le jeton (par exemple, `laptop`).
4. Sélectionnez l'autorisation **write:repository** afin que le jeton puisse cloner et envoyer du code.
5. Sélectionnez **Generate Token**.
6. Copiez le jeton et conservez-le en lieu sûr. Vous ne pourrez plus l'afficher par la suite.

<Aside type="caution">Traitez le jeton comme un mot de passe — toute personne qui le possède peut agir en votre nom dans Git. Générez un jeton distinct par machine afin de pouvoir en révoquer un sans perturber les autres.</Aside>

## Cloner un dépôt

1. Ouvrez **Git** dans votre espace de travail et sélectionnez **Copy clone URL** sur la ligne du dépôt. Vous pouvez aussi sélectionner **Code** dans le dépôt et copier l'URL **HTTPS**.
2. Dans un terminal, exécutez `git clone` avec cette URL :

   ```bash
   git clone <clone URL>
   ```

3. Lorsque Git demande un mot de passe, collez le **jeton d'accès**. Utilisez le nom d'utilisateur déjà présent dans l'URL.
4. Définissez le nom et l'adresse e-mail que Git enregistre dans vos commits, avec les valeurs que l'astuce affiche :

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Vous avez besoin de l'accès Contributeur ou Administrateur pour envoyer du code ; avec l'accès Lecture, vous pouvez cloner mais pas envoyer. Consultez [Niveaux d'accès](/fr/guides/git/#niveaux-daccès).

<Aside>Pour éviter de ressaisir le jeton à chaque envoi, vous pouvez laisser l'assistant d'identifiants Git de votre système d'exploitation le stocker, par exemple `git config --global credential.helper osxkeychain` sous macOS.</Aside>

## Valider et envoyer des modifications

Depuis l'intérieur d'un dépôt cloné :

1. Indexez vos modifications : `git add .`
2. Enregistrez-les avec un message : `git commit -m "Describe what changed"`
3. Envoyez-les vers PlaidCloud Git : `git push`

Vos commits apparaissent dans les vues **Commits** et **Activité** du dépôt, ainsi que sur toute branche ou demande de fusion qui les inclut.

## Gérer l'accès et la visibilité

Ouvrez l'onglet **Paramètres** d'un dépôt pour le renommer, modifier sa visibilité ou en transférer la propriété. Pour permettre à d'autres membres de contribuer, utilisez **Paramètres → Collaborators** et ajoutez-les par nom d'utilisateur avec un rôle **Lecture**, **Écriture** ou **Administrateur**.

<Aside>L'accès à un dépôt suit aussi l'appartenance à votre espace de travail et vos groupes de sécurité. Consultez [Gestion des accès](/fr/administration/access/) pour voir comment ils déterminent qui peut voir et modifier un dépôt.</Aside>
