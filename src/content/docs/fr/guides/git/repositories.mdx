Un dépôt contient les fichiers, les branches et l'historique d'un projet. Ce guide explique comment créer un dépôt et vous y connecter depuis votre ordinateur.

## Créer un dépôt

1. Ouvrez **Git** depuis votre espace de travail.
2. Sélectionnez le menu **+** dans le coin supérieur droit, puis **New Repository**.
3. Saisissez un nom et, éventuellement, une courte description.
4. Choisissez la visibilité. Les nouveaux dépôts sont **Privé** par défaut : seuls les membres auxquels vous accordez l'accès peuvent les voir.
5. Sélectionnez éventuellement **Initialize Repository** pour ajouter un fichier README, un fichier `.gitignore` et une licence.
6. Sélectionnez **Create Repository**.

## Générer un jeton d'accès personnel

Comme vous vous connectez via PlaidCloud, votre compte n'a pas de mot de passe Git distinct. Pour cloner ou pousser via HTTPS depuis la ligne de commande, créez un jeton d'accès personnel et utilisez-le à la place d'un mot de passe.

1. Sélectionnez votre avatar dans le coin supérieur droit, puis **Paramètres**.
2. Ouvrez l'onglet **Applications**.
3. Sous **Manage Access Tokens**, saisissez un nom qui décrit l'endroit où vous utiliserez le jeton (par exemple `laptop`).
4. Sélectionnez les portées du dépôt **lecture** et **écriture** afin que le jeton puisse cloner et pousser.
5. Sélectionnez **Generate Token**.
6. Copiez le jeton et conservez-le en lieu sûr. Vous ne pourrez plus l'afficher.

<Aside type="caution">Traitez le jeton comme un mot de passe : toute personne qui le possède peut agir en votre nom dans Git. Générez un jeton distinct par machine afin de pouvoir en révoquer un sans perturber les autres.</Aside>

## Cloner un dépôt

1. Ouvrez le dépôt dans PlaidCloud Git.
2. Sélectionnez **Code**, puis copiez l'URL de clonage **HTTPS**.
3. Dans un terminal, exécutez `git clone` avec cette URL :

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. Lorsque Git demande des identifiants, saisissez votre **nom d'utilisateur PlaidCloud** et collez le **jeton d'accès** comme mot de passe.

<Aside>Pour éviter de saisir de nouveau le jeton à chaque push, laissez l'assistant d'identifiants Git de votre système d'exploitation le mémoriser : exécutez `git config --global credential.helper store` (ou `osxkeychain` sur macOS) avant votre premier push.</Aside>

## Valider et pousser des modifications

Depuis l'intérieur d'un dépôt cloné :

1. Indexez vos modifications : `git add .`
2. Enregistrez-les avec un message : `git commit -m "Describe what changed"`
3. Envoyez-les vers PlaidCloud Git : `git push`

Vos commits apparaissent dans les vues **Commits** et **Activité** du dépôt, ainsi que sur toute branche ou pull request qui les inclut.

## Gérer l'accès et la visibilité

Ouvrez l'onglet **Paramètres** d'un dépôt pour le renommer, modifier sa visibilité ou transférer sa propriété. Pour permettre à d'autres membres de contribuer, utilisez **Paramètres → Collaborators** et ajoutez-les par nom d'utilisateur avec un rôle **Lecture**, **Écriture** ou **Administrateur**.

<Aside>L'accès au dépôt suit également l'appartenance à votre espace de travail et vos groupes de sécurité. Consultez [Gestion des accès](/fr/administration/access/) pour voir comment ils déterminent qui peut voir et modifier un dépôt.</Aside>
