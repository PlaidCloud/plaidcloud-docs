PlaidCloud Git vous permet de rechercher du code, des fichiers, des tickets et des pull requests dans tous les dépôts auxquels votre appartenance à l'espace de travail vous donne accès.

## Rechercher du code

1. Sélectionnez la zone de recherche en haut de n'importe quelle page et saisissez votre requête.
2. Appuyez sur **Entrée** pour voir les résultats dans tous les dépôts auxquels vous avez accès.
3. Sélectionnez un résultat pour accéder directement au fichier, à la ligne correspondante.
4. Affinez les résultats avec les filtres **Dépôt** et **Langue** de la page de résultats.

<Aside>La recherche de code indexe la branche par défaut. Pour rechercher dans une autre branche, accédez à cette branche et utilisez la recherche au sein du dépôt décrite ci-dessous.</Aside>

## Rechercher dans un dépôt

1. Ouvrez un dépôt et sélectionnez l'onglet **Code**.
2. Appuyez sur **T** (ou sélectionnez la zone de recherche de fichiers) pour ouvrir le sélecteur de fichiers.
3. Saisissez une partie d'un nom de fichier ou d'un chemin : la liste se filtre au fur et à mesure de la saisie.
4. Sélectionnez un fichier pour l'ouvrir, puis utilisez la recherche dans la page de votre navigateur (**⌘F** / **Ctrl+F**) pour repérer une ligne précise.

<Aside type="tip">Le sélecteur de fichiers recherche sur les segments de chemin ; saisir `util/auth` fait donc apparaître `src/util/auth.py`, `lib/util/auth_helper.go` et des chemins similaires.</Aside>

## Filtrer les tickets et les pull requests

Dans la liste **Issues** ou **Pull Requests**, combinez la recherche par mots-clés avec des filtres `key:value` :

| Filtre | Exemple |
|---|---|
| État ouvert ou fermé | `is:open`, `is:closed` |
| Libellé | `label:bug`, `label:"needs review"` |
| Personne assignée | `assignee:you` |
| Auteur | `author:you` |
| Jalon | `milestone:"v1.2"` |

Saisissez les filtres directement dans la zone de recherche, combinez-les librement et utilisez le menu **Trier** pour ordonner par **Récemment mis à jour**, **Les plus commentés**, **Le plus récent** ou **Le plus ancien**.

<Aside>Placez un nom de libellé entre guillemets lorsqu'il contient des espaces : `label:"needs review"`.</Aside>

## Conseils pour trouver plus vite

- **Expressions exactes** : placez les termes de plusieurs mots entre guillemets (`"connection pool"`) pour éviter les correspondances partielles parasites.
- **Limiter à un dépôt** : ouvrez le dépôt avant de rechercher afin que les résultats restent ciblés.
- **Les noms descriptifs sont payants** : les dépôts et les tickets dotés de noms clairs et précis ressortent dans la recherche bien plus souvent que ceux portant des noms génériques comme `misc`.
- **Les libellés sont des métadonnées consultables** : un ticket bien libellé est plus facile à filtrer qu'un ticket noyé dans la prose ; appliquez donc les libellés de manière cohérente.
