Un tableau de projet répartit les tickets et les pull requests en colonnes qui représentent les étapes de votre workflow, offrant à toute l'équipe une vue partagée de ce qui est en cours, de ce qui est bloqué et de ce qui est terminé.

## Créer un tableau

1. Ouvrez le dépôt et sélectionnez l'onglet **Projets**.
2. Sélectionnez **Nouveau projet**.
3. Saisissez un nom pour le tableau.
4. Choisissez un modèle de départ (une disposition de base **To Do / In Progress / Done** est un bon choix par défaut) ou sélectionnez un tableau vide pour construire la disposition de zéro.
5. Sélectionnez **Create Project** pour ouvrir le tableau.

<Aside>Un tableau créé depuis l'onglet **Projets** d'un dépôt appartient à ce dépôt. Les tableaux qui couvrent plusieurs dépôts de votre espace de travail sont créés par un administrateur depuis la zone Projets au niveau de l'organisation.</Aside>

## Configurer les colonnes

1. Pour ajouter une colonne, sélectionnez **Ajouter une colonne**, saisissez un libellé et enregistrez.
2. Pour renommer une colonne, ouvrez ses paramètres et choisissez **Modifier**.
3. Faites glisser les en-têtes de colonne vers la gauche ou la droite pour les réordonner.
4. Définissez une colonne comme colonne par défaut depuis ses paramètres : toute carte ajoutée sans cible précise y atterrit.

## Ajouter et déplacer des cartes

- Pour ajouter un ticket ou une pull request existant, ouvrez le menu d'une colonne et sélectionnez **Add an item**, puis recherchez-le par titre ou par numéro.
- Pour créer directement un ticket sur le tableau, sélectionnez **+** dans une colonne. Le ticket est enregistré dans le dépôt et apparaît immédiatement sous forme de carte.
- Faites glisser une carte vers une autre colonne à mesure que le travail avance. La position de la carte reflète son statut actuel ; elle ne modifie pas à elle seule les libellés ou les personnes assignées du ticket.

## Suivre le travail

Le tableau donne un aperçu immédiat de la charge de travail de votre équipe sans ouvrir chaque ticket. Gardez-le à jour en :

- Fermant un ticket ou en fusionnant une pull request : la carte passe dans une colonne terminée ou quitte le tableau, selon les paramètres d'automatisation de votre tableau.
- Associant le tableau aux **Jalons** lorsque vous voulez un objectif limité dans le temps en plus de la vue Kanban. Les jalons suivent une échéance et un pourcentage d'avancement ; le tableau suit le flux.
