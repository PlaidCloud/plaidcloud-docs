## Description

Ouvrez la zone depuis **Outils > E-mail**. La page est divisée en deux panneaux : **E-mail envoyé** et **Rebonds**. Le sélecteur de flux en haut permet de choisir le flux Postmark à afficher ; par défaut, il s'agit du premier flux transactionnel configuré pour votre espace de travail.


## E-mail envoyé

Le panneau **E-mail envoyé** affiche les messages que PlaidCloud a envoyés au nom de votre espace de travail. Les colonnes comprennent `Sent At`, `Recipient`, `Subject`, `Status`, `Stream`, `Tag`, `Opens` et `Clicks`.

**Pour filtrer les e-mails envoyés :**

1. Ouvrez **Outils > E-mail > E-mail envoyé**.
2. Saisissez une valeur dans **Destinataire** pour rechercher par adresse du destinataire (correspondance partielle).
3. Choisissez un **Statut** pour affiner par statut de livraison de l'e-mail (livré, ouvert, etc.).
4. Choisissez une **Étiquette** pour vous limiter à une étiquette de message précise.
5. Cliquez sur `Apply`.

Cliquez sur `Clear` pour effacer les filtres. Cliquez sur une ligne pour ouvrir une fenêtre **Détails du message** contenant toutes les métadonnées du message renvoyées par Postmark.


## Rebonds

Le panneau **Rebonds** affiche les échecs de livraison renvoyés par Postmark. Les colonnes comprennent `Bounced At`, `Recipient`, `Type`, `Inactive`, `Description` et `Stream`.

**Pour filtrer les rebonds :**

1. Ouvrez **Outils > E-mail > Rebonds**.
2. Saisissez une valeur dans **Destinataire** pour rechercher par adresse du destinataire (correspondance partielle).
3. Choisissez un **Type** pour affiner par type de rebond (HardBounce, SoftBounce, Transient, etc.).
4. Choisissez une **Étiquette** pour vous limiter à une étiquette de message précise.
5. Cochez **Inactifs uniquement** pour n'afficher que les destinataires que Postmark a marqués comme inactifs.
6. Cliquez sur `Apply`.

Cliquez sur `Clear` pour effacer les filtres. Cliquez sur une ligne pour ouvrir les détails du rebond.


## Réactiver un destinataire en rebond

Lorsque Postmark marque un destinataire comme inactif (généralement après un rebond définitif), plus aucun e-mail n'est envoyé à cette adresse tant que le destinataire n'est pas réactivé.

1. Filtrez sur **Inactifs uniquement**.
2. Sélectionnez la ligne du destinataire.
3. Cliquez sur `Reactivate`.

Après la réactivation, les futurs e-mails générés par PlaidCloud à destination de cette adresse seront de nouveau tentés.


## Pagination

Les deux panneaux parcourent l'historique page par page plutôt que de charger tous les messages d'un coup. Utilisez `Prev` et `Next` pour naviguer entre les pages ; l'étiquette située entre les deux indique votre position (`1–25 of 837`).

<Aside>La zone E-mail sert uniquement à l'inspection et à la réactivation des destinataires. La réponse aux messages, la configuration des serveurs et la gestion des modèles restent à effectuer dans le tableau de bord Postmark.</Aside>
