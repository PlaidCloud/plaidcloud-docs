## Description

Ouvrez une étape enregistrée et, au-dessus de ses boutons **Enregistrer**, Weave indique ce qu'une modification
de cette étape atteindrait :

> Les modifications de cette étape affectent 8 étapes en aval dans 2 workflows.

La phrase compte les étapes qui lisent une table écrite par cette étape, les étapes
qui lisent ce que celles-ci écrivent, et ainsi de suite, jusqu'à dix étapes en aval. Elle est
établie à partir des paramètres enregistrés des étapes du projet ; elle est donc instantanée, c'est
un décompte exact des étapes qui listent ces tables comme source, et aucune IA n'intervient. Elle sert à éclairer l'enregistrement, pas à le conditionner : vous pouvez
toujours enregistrer.

<Aside type="note">
La phrase décrit l'étape telle qu'elle a été enregistrée en dernier. Si vous changez la table
que l'étape écrit, les étapes qui lisent l'ancienne table sont celles qui sont listées jusqu'à
l'enregistrement, et elles sont affectées : elles cessent de recevoir ce que cette étape
écrivait.
</Aside>

## Ce que dit la phrase

| Message de Weave | Signification |
| --- | --- |
| Les modifications de cette étape affectent 8 étapes en aval dans 2 workflows. | Huit étapes lisent ce que cette étape écrit, directement ou par l'intermédiaire d'autres étapes, et elles se répartissent entre deux workflows. Une étape présente dans deux workflows compte pour une seule étape, dans les deux. |
| Les modifications de cette étape affectent 3 étapes en aval : 2 dans 1 workflow et 1 dans aucun workflow. | Une étape en aval qui n'est placée dans aucun workflow est comptée et listée sous **Dans aucun workflow**. |
| Les modifications de cette étape affectent 3 étapes en aval, dont aucune dans un workflow. | Toutes les étapes affectées ne sont placées nulle part. Avec une seule étape : « affectent 1 étape en aval, qui n'est dans aucun workflow. » |
| Les modifications de cette étape affectent au moins 8 étapes en aval dans au moins 2 workflows. Weave a cessé de chercher à 10 étapes en aval. | La chaîne de lecteurs dépasse dix étapes. Les nombres sont un minimum, pas un total, et la phrase ne les ventile pas selon le placement. |
| … Vous ne pouvez pas en ouvrir 2. | Deux des étapes affectées sont masquées pour votre rôle. Elles sont comptées, pour que la phrase reste exacte, mais pas nommées. Lorsque toutes les étapes affectées sont masquées, la phrase se termine par « Vous ne pouvez en ouvrir aucune. », ou « Vous ne pouvez pas l'ouvrir. » pour une seule. |
| Aucune autre étape ne liste une table écrite par cette étape comme source. | Aucune étape ne nomme l'une de ces tables comme source. Une étape qui atteint une table par une requête SQL ou une expression n'est pas comptée, et **Comment Weave le sait** le précise. |
| Cette étape n'écrit pas de table ; Weave n'a donc rien à suivre en aval. | L'étape produit autre chose qu'une table de projet, comme un fichier, un e-mail ou une écriture ERP, et Weave ne peut pas suivre qui l'utilise. |
| Weave n'a pas pu vérifier ce que les modifications de cette étape affectent. | L'aperçu n'a pas pu être lu. Suivre la chaîne exige un accès en lecture aux étapes, aux workflows et aux tables ; un rôle auquel il manque l'un d'eux voit donc ce message. L'enregistrement fonctionne comme d'habitude. |

## Voir les étapes

**Afficher les étapes** liste les étapes affectées par workflow. Les workflows que vous pouvez ouvrir
viennent en premier, par nom ; les workflows que vous ne pouvez pas ouvrir suivent en un seul groupe ; les étapes sans
workflow viennent en dernier. Au sein d'un workflow, les lecteurs les plus proches sont listés en premier,
et les étapes que vous ne pouvez pas ouvrir sont comptées à la fin de la liste plutôt que nommées. Une
étape présente dans plusieurs workflows est listée sous chacun d'eux, et **Comment
Weave le sait** le précise. Une longue liste défile.

## Comment Weave le sait

**Comment Weave le sait**, sous la phrase, montre ce que Weave a fait et ce qu'il a
laissé de côté :

- **Ce que Weave a fait** — suivi chaque table écrite par cette étape jusqu'aux étapes qui
  la lisent, puis jusqu'à ce que celles-ci écrivent, sur dix étapes en aval au maximum.
- **D'où cela provient** — les tables écrites par cette étape et les paramètres enregistrés
  de toutes les étapes du projet. Une table que votre rôle masque est listée comme une table que vous
  ne pouvez pas ouvrir, et une table citée dans les paramètres de l'étape qui n'existe pas encore est
  listée sous ce nom.
- **Ce que Weave n'a pas vérifié** — les étapes qui atteignent ces tables par une requête
  SQL ou une expression plutôt qu'en les listant comme source ; les tableaux de bord,
  vues, exports et tout ce qui, hors de ce projet, lit ces tables ;
  si les étapes affectées échoueraient ou s'exécuteraient simplement sur des données différentes ; et
  les modifications de cette étape que vous n'avez pas enregistrées.

## Quand elle apparaît

- Pour une étape enregistrée uniquement. Une nouvelle étape, ou un doublon que vous n'avez pas encore enregistré, n'a
  aucun lecteur à compter.
- Elle s'actualise après **Enregistrer** tant que l'étape reste ouverte, puisqu'un enregistrement peut
  changer la table que l'étape écrit.
- Elle lit les paramètres enregistrés du projet ; elle ne coûte donc jamais d'appel à l'IA et continue
  de fonctionner lorsqu'aucun fournisseur d'IA n'est disponible.
