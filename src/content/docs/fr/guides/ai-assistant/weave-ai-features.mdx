## Description

Les administrateurs de l'espace de travail décident quelles fonctionnalités IA de Weave l'espace de travail utilise.
Chaque fonctionnalité peut être désactivée séparément, pour tous les membres de l'espace de travail. Chaque
fonctionnalité est activée tant qu'un administrateur ne la désactive pas.

Les contrôles et les constats de Weave n'utilisent aucune IA ; ils restent donc activés quel que soit votre choix ici.

## Activer ou désactiver une fonctionnalité

1. Cliquez sur le bouton **Weave** dans l'en-tête.
2. Choisissez **Fonctionnalités IA…** à la fin de son menu.
3. Décochez la case de chaque fonctionnalité à désactiver, ou cochez-la pour la réactiver.
4. Cliquez sur **Enregistrer**.

La modification s'applique à la prochaine requête IA effectuée par n'importe quel membre de l'espace de travail. Personne
n'a besoin de se déconnecter.

**Fonctionnalités IA…** n'apparaît que pour les administrateurs de l'espace de travail. Toute autre personne qui tente
de modifier les fonctionnalités via l'API reçoit le message *Seuls les administrateurs de l'espace de travail
peuvent activer ou désactiver les fonctionnalités IA.*

## Les fonctionnalités

| Fonctionnalité | Ce qu'elle couvre | Lorsqu'elle est désactivée |
|---|---|---|
| **Chat Weave** | Le chat de l'onglet **Weave** d'un projet, **Demander à l'assistant** dans **Aide et support**, et Weave dans l'[application mobile PlaidCloud](/fr/guides/mobile-app/weave-on-mobile/). | Le **Chat** de l'onglet **Weave** indique que l'administrateur l'a désactivé, **Aide et support** n'a pas d'onglet **Demander à l'assistant**, et une question posée dans l'application mobile est refusée. |
| **Assistant de correction** | **Corriger** sur les constats de Weave, et l'onglet **Weave AI** d'une entrée de journal. | Les constats ne proposent pas de **Corriger**, sauf pour un connecteur manquant dans **Steps that can run before the table they read is written**, dont **Corriger** ouvre [Synchroniser les dépendances](/fr/guides/workflows/sync-dependencies/) plutôt que l'assistant. L'onglet **Weave AI** est indisponible. |
| **Assistants d'import et d'export** | Le chat Weave qui configure pour vous un import de fichier, une étape d'importation ou une étape d'exportation. | Le chat Weave ne peut pas les configurer. |
| **Assistant d'expressions** | L'assistant de l'éditeur d'expressions. | L'éditeur d'expressions n'a pas d'assistant. |
| **SQL à partir d'une description** | [Generate SQL with AI](/fr/guides/ai-assistant/generate-sql-extract/) dans l'étape **Extraire SQL**. | L'étape n'a pas de section **Generate SQL with AI**. Vous pouvez toujours écrire le SQL vous-même. |
| **Résumé de la vérification du workflow** | Le résumé rédigé par l'IA au-dessus du bouton **Vérifier** d'un workflow. | **Vérifier** affiche ses constats sans le résumé. |
| **Graphique de départ** | L'IA qui choisit le premier graphique pour un fichier que vous déposez. | Une règle choisit le graphique à la place. |

Une personne déjà connectée lorsque vous avez effectué la modification voit encore la
fonctionnalité jusqu'à ce qu'elle recharge PlaidCloud, mais Weave n'utilise plus l'IA pour celle-ci. Le
chat, les assistants de correction et d'expressions, et le SQL à partir d'une description l'indiquent, par
exemple *Votre administrateur d'espace de travail a désactivé l'assistant de correction.*

<Aside type="note">
Ces commutateurs concernent l'IA fournie par PlaidCloud. Les étapes IA de vos workflows
utilisent votre propre connexion IA, et les outils IA que vous connectez via
[MCP](/fr/integrations/ai-coding-agents/) utilisent leur propre modèle ; ni les unes ni les autres ne sont donc
affectés.
</Aside>

## Historique des modifications

Chaque fonctionnalité activée ou désactivée est consignée dans le **Journal de sécurité** de l'espace de travail, avec la personne qui l'a
modifiée et le moment, par exemple *Assistant de correction désactivé.*

## Via l'API

`GET /rest/v1/analyze/ai/features` renvoie chaque fonctionnalité et son état d'activation, sous la forme
`{"features": [{"feature": "chat", "on": true}, …]}`. Les noms de fonctionnalités sont
`chat`, `fix`, `import_export`, `expression`, `sql_extract`, `review_summary` et
`starter_chart`.

`PUT /rest/v1/analyze/ai/features` avec `{"off": ["fix"], "on": ["chat"]}` désactive
les fonctionnalités de `off` et active celles de `on`. Une fonctionnalité absente des deux listes reste telle
quelle, de sorte que deux administrateurs qui modifient des fonctionnalités différentes ne s'annulent pas mutuellement.
Il répond comme le `GET`. Seul un administrateur de l'espace de travail peut l'appeler, et un
nom qui n'est pas une fonctionnalité, ou présent dans les deux listes, est refusé.
