## Ce que demande le lab

Le lab s'intitule *Fondamentaux : ventes par région*.

Les commandes et les clients sont déjà chargés dans le projet du lab. Dans son workflow, vous construisez une étape qui ne conserve que les commandes terminées, les joint aux clients, puis écrit une ligne par région avec le montant total et le nombre de commandes. Vous exécutez ensuite le workflow et publiez la table de résultat.

Le lab vérifie que le workflow s'exécute et que la table de résultat contient les bons totaux.
