## Description

Les données des tableaux de bord peuvent être enrichies par des métriques.  Chaque jeu de données contient une section pour les métriques.  Les métriques peuvent être écrites et modifiées en SQL de type PostgreSQL.

<SnippetDashboardsCommonNavigateToDataset />

## Exemples
Les colonnes calculées sont généralement des colonnes supplémentaires créées en combinant une logique et des colonnes existantes.

### Convertir une date en texte
```sql
to_char("week_ending_sol_del_req", 'YYYY-mm-dd')
```

### Divers exemples de SUM
```sql
SUM(Value)

SUM(-1*"value_usd_mkp") / (0.0001+SUM(-1*"value_usd_base"))

(SUM("Value_USD_VAT")/SUM("Value_USD_HEADER"))*100

sum(delivery_cases) where Material_Type = Gloves

sum("total_cost") / sum("delivery_count")
```


### Divers exemples de CASE
```sql
CASE WHEN
SUM("distance_dc_xd") = 0 THEN 0
ELSE
sum("XD")/sum("distance_dc_xd")
END

sum(CASE
WHEN "FUNCTION" = 'OM' THEN "VALUE__FC"
ELSE 0.0
END)
```


### Count
```sql
count(*)
```


### First et Cast
```sql
public.first(cast("PRETAX_SEQ" AS NUMERIC))
```


### Round
```sql
round(Sum("GROSS PROFIT"),0)
```


### Concat
```sql
concat("GCOA","CC Code")
```
