Vous pouvez publier un tableau de bord, une application Panel ou Dash, ou un notebook JupyterLite depuis **Analyses** dans le menu des applications, à gauche. Les personnes que vous choisissez l'ouvrent ensuite depuis le menu en un clic, sous les applications du produit.

<Aside>Publier dans le menu des applications place une entrée dans le menu. Cela n'accorde jamais l'accès à l'élément à qui que ce soit. Une personne ne voit l'entrée que si elle fait partie de son audience **et** peut déjà ouvrir l'élément.</Aside>

## Qui peut publier

Vous devez pouvoir ouvrir l'élément vous-même, et le gérer :

| Élément | Qui peut le publier |
|---|---|
| Tableau de bord | Ses propriétaires et les administrateurs de l'espace de travail, c'est-à-dire les personnes qui choisissent son audience (voir [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/)), avec un accès en écriture aux tableaux de bord. |
| Application Panel ou Dash | Les membres ayant un accès en écriture aux applications et un rôle supérieur à Explorateur sur le projet de l'application. Un projet verrouillé ne vous arrête pas. Une application sans projet peut être publiée par la personne qui l'a créée ou par un administrateur de l'espace de travail. |
| Notebook JupyterLite | La personne qui a ajouté le déploiement, ou un administrateur de l'espace de travail, avec un accès en écriture aux notebooks. |

Le groupe de sécurité **Dashboard Read and Write** donne un accès en écriture aux tableaux de bord, aux applications et aux notebooks.

## Publier un élément

1. Dans **Analyses**, ouvrez **Tableaux de bord**, **Applications** ou **Notebooks**.
2. Choisissez **Publier dans le menu des applications…** dans le menu de ligne de l'élément, ou sélectionnez la ligne et choisissez **Publier dans le menu des applications…** dans la barre d'outils. Cette action est proposée lorsque vous avez un accès en écriture à ce type d'élément, et dans **Tableaux de bord** uniquement pour les tableaux de bord que vous gérez.
3. Dans la boîte de dialogue **Publier dans le menu des applications**, définissez l'entrée :
   - **Entrée de menu** est le libellé affiché dans le menu. Il commence par le nom de l'élément, et un aperçu en dessous montre l'entrée telle qu'elle apparaîtra. Le libellé ne peut pas être plus large que le nom de l'application du produit la plus large du menu ; un libellé trop large l'indique.
   - **Icône** propose un monogramme formé des initiales du libellé ou l'un des 15 symboles, ainsi qu'une couleur. Le premier choix de couleur en sélectionne une à partir du libellé. Un petit badge sur l'icône indique si l'entrée est un tableau de bord, une application, un notebook ou Jupyter Hub.
   - **Qui le voit dans le menu** est **Tous les membres de l'espace de travail**, **Groupes** ou **Personnes**, un seul type à la fois. Pour **Groupes** ou **Personnes**, cochez au moins un élément. **Groupes** nécessite l'accès en lecture aux groupes de sécurité, et **Personnes** l'accès en lecture aux membres ; sans cet accès, ce choix est grisé.
4. Sélectionnez **Publier**.

La ligne de l'élément affiche alors une pastille **Publié**. Pour modifier l'entrée plus tard, rouvrez **Publier dans le menu des applications…** : la boîte de dialogue affiche ce qui est enregistré, son bouton indique **Enregistrer**, et **Annuler la publication** retire l'entrée du menu.

### Qui ne peut pas l'ouvrir

Sous l'audience, la boîte de dialogue vérifie qui, dans l'audience, ne peut pas ouvrir l'élément aujourd'hui :

- *Ne peuvent pas ouvrir cet élément : 3 sur 40* signifie que trois des quarante personnes de l'audience ne verront pas l'entrée tant qu'elles ne pourront pas ouvrir l'élément.
- *Tous les membres de cette audience peuvent ouvrir cet élément* signifie que personne n'est exclu.
- *2 personnes dans des projets que vous ne pouvez pas voir* compte les personnes dont l'accès dépend de projets que vous ne pouvez pas ouvrir ; la boîte de dialogue ne peut donc pas trancher.

Pour un tableau de bord, **Corriger l'accès** ouvre sa boîte de dialogue **Qui peut voir ce tableau de bord ?**, et la vérification s'exécute à nouveau une fois que vous y avez enregistré. Les décomptes ne s'affichent que si vous pouvez voir les membres de l'espace de travail.

## Où l'entrée apparaît

Les entrées publiées viennent après les applications du produit dans le menu des applications, sous un séparateur, dans l'ordre défini par un administrateur de l'espace de travail dans [Applications publiées](#gérer-les-applications-publiées). Chacune a son libellé et son icône. Vous voyez immédiatement une modification que vous faites vous-même ; les autres personnes la voient au prochain chargement de PlaidCloud.

| Élément | S'ouvre |
|---|---|
| Tableau de bord | Sous forme d'onglet dans PlaidCloud |
| Application Panel **Navigateur uniquement** | Sous forme d'onglet dans PlaidCloud |
| Notebook JupyterLite | Sous forme d'onglet dans PlaidCloud |
| Application Panel **Sur serveur** ou application Dash | Dans une nouvelle fenêtre |
| Jupyter Hub | Dans une nouvelle fenêtre |

Un onglet ouvert depuis le menu a un en-tête avec le nom de l'entrée, **Recharger** et **Ouvrir dans une nouvelle fenêtre**. Si l'élément ne vous connecte pas automatiquement dans l'onglet, utilisez **Ouvrir dans une nouvelle fenêtre**.

L'adresse d'un onglet est un lien vers celui-ci que vous pouvez partager : voir [Liens de partage](/fr/guides/projects/sharing-links/#entrées-de-menu-publiées). Si votre menu des applications ne contient que **Accueil** et des entrées publiées, **Accueil** les liste en premier, dans une ligne **Applications**.

### Qui voit une entrée

Un membre voit une entrée lorsque ces deux conditions sont remplies :

- **Il fait partie de son audience :** tous les membres de l'espace de travail, un membre de l'un de ses groupes, ou l'une de ses personnes.
- **Il peut ouvrir l'élément :** un tableau de bord qu'il peut voir dans Analyses ; une application sur un projet auquel il a accès ; et, pour une application **Navigateur uniquement** ou un notebook JupyterLite, l'accès au compte de documents depuis lequel il est servi.

Toute autre personne ne voit pas l'entrée, quelle que soit son audience.

## Masquer une entrée de votre menu

Faites un clic droit sur une entrée publiée dans le menu des applications et choisissez **Masquer de mon menu**. Elle quitte uniquement votre menu, et **Défaire** dans le message qui s'affiche la rétablit. Le masquage est proposé aux membres qui ont Analyses.

Pour l'afficher à nouveau, ouvrez **Applications masquées** dans le rail d'Analyses et sélectionnez **Restaurer** sur sa ligne. Une entrée qui n'est plus dans votre menu indique **N'est plus dans votre menu** ; **Supprimer** la retire de la liste. Les entrées que vous masquez sont enregistrées avec votre compte, elles restent donc masquées dans tous les navigateurs.

## Gérer les applications publiées

Les administrateurs de l'espace de travail ouvrent **Applications publiées** sous **Administrateur** dans le rail d'Analyses. Cette page liste chaque entrée dans l'ordre du menu, avec son **Nom**, son **Genre**, son **Audience** (**Tout le monde**, ou un nombre de groupes ou de personnes) et son **Statut**. **Ouvertures (30 jours)** indique combien de fois chaque tableau de bord a été ouvert, pour les membres qui ont accès aux statistiques d'utilisation.

- **Monter** et **Descendre** définissent l'ordre des entrées dans le menu de tout le monde.
- **Modifier l'audience…** ouvre la boîte de dialogue **Publier dans le menu des applications** pour une entrée que vous pouvez gérer.
- **Annuler la publication** retire une entrée du menu pour toutes les personnes à qui elle est publiée, après confirmation de votre part. Les administrateurs de l'espace de travail peuvent annuler la publication de n'importe quelle entrée.

Lorsqu'un élément publié est supprimé, son entrée quitte le menu. Supprimer une application Panel ou un déploiement JupyterLite de sa liste supprime son entrée en même temps. Pour un tableau de bord supprimé, **Applications publiées** peut afficher l'entrée une fois avec **Élément supprimé, retiré**.

## Publier via l'assistant IA ou MCP

`publication_manage` fait la même chose via MCP. Son `kind` vaut `dashboard`, `panelApp`, `jupyterLite` ou `jupyterHub`, et ses actions sont :

- `get`, `set`, `delete` et `preview` prennent un `kind` et un `item_id`. `set` remplace toute l'entrée par un `spec` composé de `label`, d'un `icon` et d'un `color` facultatifs, et d'un `audience` de `type` `public`, `acl-group` ou `acl-user` avec ses `ids`. `preview` prend un `spec` avec un `audience` et renvoie les mêmes décomptes que la boîte de dialogue.
- `list` renvoie les entrées que vous gérez, ou toutes les entrées pour un administrateur de l'espace de travail, dans l'ordre du menu, pour les types que vous pouvez lire.
- `reorder` prend des `keys` dans le nouvel ordre, chacune de la forme `<kind>:<item_id>`, et s'adresse aux administrateurs de l'espace de travail.

Le lien Jupyter Hub n'est publié que via MCP ou l'API REST, par un administrateur de l'espace de travail, avec `kind` valant `jupyterHub` et `item_id` valant `hub`. `publication_manage` n'est pas disponible pour Weave ni pour d'autres agents IA agissant en votre nom.
