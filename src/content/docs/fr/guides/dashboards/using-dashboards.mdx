## Vue d'ensemble

Les tableaux de bord vous permettent de créer des vues interactives sur les données de tout projet ou espace de travail auquel vous avez accès. Un même tableau de bord peut combiner des tables de plusieurs projets, mêler visualisations et exploration brute, et servir à la fois des rapports permanents et des analyses ponctuelles. Les tableaux de bord passent de petites tables de référence à des jeux de données de plusieurs milliards de lignes sans changement de configuration.

## Comptes de tableaux de bord

Votre compte de tableaux de bord est configuré pour vous la première fois que vous ouvrez un tableau de bord depuis PlaidCloud ; il n'y a donc rien à créer à la main. Ce que vous pouvez voir découle de votre appartenance à l'espace de travail PlaidCloud et de vos groupes de sécurité.

<Aside>Ajoutez, modifiez et retirez des personnes dans PlaidCloud plutôt que dans le service de tableaux de bord : voir [Gérer les membres de l'espace de travail](/fr/administration/access/overview/managing-workspace-members/). Créer un compte utilisateur directement dans le service de tableaux de bord est une action réservée aux administrateurs, et un compte créé de cette manière n'est pas lié à votre appartenance à l'espace de travail.</Aside>

## Quels tableaux de bord vous voyez

La page **Tableaux de bord** de PlaidCloud affiche les tableaux de bord publiés qui appartiennent aux projets auxquels vous avez accès. C'est le cas habituel, qui couvre presque tous les tableaux de bord.

Les propriétaires d'un tableau de bord et les administrateurs de l'espace de travail peuvent le limiter à certains groupes de sécurité. Un tableau de bord restreint n'est listé que pour les membres de ces groupes, ainsi que pour ses propriétaires et les administrateurs de l'espace de travail, qui voient tous les tableaux de bord. Un tableau de bord sans restriction est listé pour toutes les personnes qui ont accès à ses projets ; restreindre un tableau de bord ne change donc jamais qui voit les autres.

Deux points méritent d'être connus si un tableau de bord manque dans votre liste :

- **Un tableau de bord restreint est masqué de la liste, et pas seulement de l'ouverture.** Si vous avez accès au projet du tableau de bord et ouvrez son lien, vous verrez une page **Request access** ; sinon, adressez-vous au propriétaire plutôt que de supposer qu'il a été supprimé.
- **Votre compte de tableaux de bord doit exister pour qu'un tableau de bord restreint vous parvienne.** Il est créé pour vous la première fois que vous ouvrez un tableau de bord depuis PlaidCloud, et vos groupes sont alors appliqués.

<Aside>Définissez qui peut voir un tableau de bord dans PlaidCloud avec **Qui peut voir ceci ?** : voir [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/). L'accès au projet s'applique toujours en plus : voir un tableau de bord ne vous donne jamais les données d'un projet auquel vous n'avez pas accès.</Aside>

## L'espace Tableaux de bord

**Tableaux de bord** s'ouvre avec un rail à gauche et la page que vous choisissez à côté. Les membres qui ne peuvent pas ouvrir une page ne voient pas son élément. Les pages ont un titre en haut, souvent accompagné d'un court sous-titre, et leurs actions se trouvent dans l'en-tête, à côté.

| Élément du rail | Ce qu'il affiche |
|---|---|
| **Vue d'ensemble** | Des vignettes pour **Tableaux de bord**, **Visibles par tous**, **Restreint**, **Vous gérez**, **Applications prêtes** et **Applications en échec**. Sélectionnez une vignette pour ouvrir sa liste, déjà filtrée. **Ouverts récemment et favoris** liste ce que vous avez ouvert ou marqué d'une étoile récemment sur cet appareil. **Nécessite une attention** liste les applications en échec et les demandes d'accès qui vous attendent, avec **À examiner**, qui ouvre les tableaux de bord que vous gérez. **Les plus ouverts au cours des 30 derniers jours** s'affiche pour les membres qui ont accès aux statistiques d'utilisation. |
| **Tableaux de bord** | Les tableaux de bord que vous pouvez voir. Choisissez **Tous**, **Vous gérez** ou **Favoris** au-dessus de la liste. Les colonnes comprennent **Audience**, **Propriétaire** et **Ouvertures (30 jours)**. **Importer une archive de tableau de bord…** et **Définir l'audience…** se trouvent dans la barre d'outils. |
| **Applications** | Les applications Panel, Dash et de navigateur créées sur vos projets, avec **Genre**, **Statut** et **Projet**. Le statut se met à jour en direct. Le menu **Nouvelle application** comporte un en-tête **Application Panel** au-dessus de **Studio**, **Navigateur uniquement** et **Côté serveur**, puis **Application Dash** et **Depuis la galerie…**. La colonne **Type** utilise les mêmes noms. |
| **Notebooks** | Vos déploiements JupyterLite. |
| **Révision des accès** | Sous **Administrateur**, pour les administrateurs de l'espace de travail. Voir [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/#révision-des-accès-aux-tableaux-de-bord). |
| **Ouvrir le navigateur ↗** | En bas du rail. La flèche le signale comme le seul élément qui ouvre sa propre fenêtre : le service de tableaux de bord, dans un nouvel onglet. |

Les compteurs à côté de **Tableaux de bord** et **Applications** indiquent combien vous pouvez en voir.

## Ouvrir un tableau de bord depuis la page Tableaux de bord

Sur la page **Tableaux de bord**, cliquez sur l'icône **Ouvrir** au début de la ligne d'un tableau de bord pour l'ouvrir dans un nouvel onglet. Un double-clic sur la ligne l'ouvre également.

### Le menu d'actions de ligne

Chaque liste de PlaidCloud qui propose des actions par ligne, y compris la page **Tableaux de bord**, possède un menu d'actions de ligne. Ouvrez-le avec le bouton **⋯** au début d'une ligne, par un clic droit sur la ligne, ou depuis le menu **Actions** de la barre d'outils. Le menu a toujours la même disposition :

1. **Ouvrir**, **Détails** et **Modifier**, dans cet ordre.
2. Les actions propres à la liste, telles que **Accès**, **Groupes**, **Réinitialiser le mot de passe** ou **Cloner**.
3. **Supprimer**, en dernier.

Un séparateur divise les groupes. Une action qui ne s'applique pas à la ligne sélectionnée reste à sa place mais est grisée, de sorte que les éléments ne se déplacent jamais d'une ligne à l'autre.

Deux éléments affichent un raccourci. L'élément que la touche **Entrée** exécute, qui ouvre la ligne, affiche **Entrée**. L'élément que la touche **Suppr** exécute affiche **Suppr** (**Retour arrière** sur un Mac).

Une liste dont les lignes n'ont qu'une seule action affiche l'icône de cette action au début de la ligne à la place de **⋯**. Cliquez sur l'icône pour exécuter l'action ; une action destructrice demande tout de même confirmation. Les lignes qui ne peuvent pas recevoir l'action n'affichent aucune icône.

### Vues Standard, Aérée et Cartes

Les listes des applications de l'espace de travail de PlaidCloud, telles que **Tableaux de bord**, **Applications**, le **Registre** ERP et les **Membres** d'Identity, ont dans la barre d'outils un menu **Vue** qui propose trois choix :

- **Lignes standard** : la liste compacte, une ligne par ligne.
- **Lignes aérées** : la même liste avec plus d'espace autour de chaque ligne.
- **Cartes** : une carte par ligne. Les cartes de **Tableaux de bord** montrent une miniature du tableau de bord, et les cartes du registre ERP montrent le montant, la date, l'entité, la connexion et le document.

Les cartes se comportent comme la liste : sélectionnez une carte, étendez la sélection avec Maj, triez et choisissez les colonnes depuis le menu **Vue**, faites un clic droit pour **Copier** et accéder aux actions de la ligne et, dans les listes qui ont des favoris, comme **Tableaux de bord** et **Applications**, cliquez sur l'étoile pour la mettre en favori.

## Demander pourquoi un chiffre vaut ce qu'il vaut

Dans un tableau de bord, faites un clic droit sur un point d'un graphique, ou sur une cellule d'un graphique en table, et choisissez
**Why this number**. PlaidCloud s'ouvre dans un nouvel onglet, et Weave indique quelle étape écrit le
chiffre, d'où il provient et comment il a évolué depuis l'exécution précédente. Voir
[Pourquoi un chiffre vaut ce qu'il vaut](/fr/guides/ai-assistant/weave-numbers/#pourquoi-ce-nombre).

## Ouvrir un lien de tableau de bord après l'expiration de votre session

Si votre session a expiré lorsque vous ouvrez un lien vers un tableau de bord, vous êtes invité à vous connecter, puis dirigé vers ce tableau de bord, et non vers la page d'accueil des tableaux de bord.

## Contrôles d'affichage

Un contrôle d'affichage est un contrôle de la barre de filtres qui permet à toute personne qui consulte un tableau de bord de modifier le regroupement d'un graphique (par exemple en remplaçant « Region » par « Product Line ») sans ouvrir le graphique pour le modifier. Un éditeur de tableau de bord ajoute et configure les contrôles d'affichage depuis le menu des paramètres de la barre de filtres : choisissez **Add or edit filters and controls**, puis **Add display control** dans le menu **Nouveau**.

### Limiter les colonnes proposées

Par défaut, la liste déroulante d'un contrôle d'affichage énumère chaque colonne du jeu de données sous-jacent marquée **Is filterable**. Sur un jeu de données large, cela peut représenter des centaines de colonnes à faire défiler pour trouver celle que vous voulez.

Chaque contrôle d'affichage dispose désormais de son propre champ **Available columns** dans son panneau de configuration. Définissez-le sur une liste précise de colonnes et la liste déroulante du contrôle ne propose que ces colonnes. Laissez-le vide et le contrôle se comporte exactement comme avant, en proposant chaque colonne filtrable ; aucun tableau de bord n'a besoin de modification pour continuer à fonctionner comme toujours.

Pour limiter un contrôle d'affichage :

1. Ouvrez **Add or edit filters and controls** depuis le menu des paramètres de la barre de filtres.
2. Sélectionnez le contrôle d'affichage que vous voulez limiter, ou ajoutez-en un nouveau.
3. Dans **Available columns**, recherchez et sélectionnez les colonnes que vous voulez que les lecteurs voient.
4. Enregistrez.

### Interaction avec « Is Filterable »

**Available columns** ne propose que des colonnes déjà marquées **Is filterable** dans le jeu de données : il restreint encore cette liste, sans la contourner. Décocher **Is filterable** sur une colonne la retire toujours partout : de **Available columns**, des filtres ad hoc, des filtres natifs et du sélecteur **Simple Metric** de chaque graphique créé sur ce jeu de données.

Cette portée étendue est précisément la raison d'être de **Available columns**. Auparavant, le seul moyen de raccourcir la liste déroulante d'un contrôle d'affichage était de décocher **Is filterable** sur les colonnes que vous ne vouliez pas y proposer, ce qui masquait aussi ces mêmes colonnes du sélecteur de métriques de chaque graphique de ce jeu de données. Laissez **Is filterable** coché sur chaque colonne dont un graphique peut avoir besoin comme métrique ou comme filtre ad hoc, et utilisez le champ **Available columns** propre à chaque contrôle d'affichage pour décider de ce que ce contrôle affiche dans sa liste déroulante Group By.

<Aside type="caution">Renommer ou supprimer une colonne qui figure dans la liste **Available columns** d'un contrôle d'affichage n'est pas détecté automatiquement : le contrôle propose simplement moins de colonnes à sa prochaine ouverture, sans avertissement. Revoyez **Available columns** sur vos contrôles d'affichage après avoir renommé ou supprimé des colonnes du jeu de données.</Aside>

### Où c'est enregistré

**Available columns** est enregistré pour chaque contrôle d'affichage, avec le reste des paramètres de ce contrôle. Il suit le tableau de bord lors de l'export et de l'import, et n'a aucun effet sur un autre contrôle, que ce soit dans le même tableau de bord ou dans un autre tableau de bord créé à partir du même jeu de données.

## Modifier une table


Le message que vous recevez après avoir créé une nouvelle table vous invite également à modifier la configuration de la table. Bien qu'il existe des fonctionnalités plus avancées pour modifier la configuration, nous commencerons par une partie limitée et plus simple. Pour modifier la configuration d'une table :


1. Cliquez sur l'icône de modification de la table souhaitée
2. Cliquez sur l'onglet « List Columns »
3. Organisez les colonnes comme vous le souhaitez
4. Cliquez sur « Enregistrer »

Cela vous permet de définir la manière dont vous voulez utiliser des colonnes précises de votre table lorsque vous explorez vos données.


* **Groupable :** si vous voulez que les utilisateurs regroupent des métriques selon un champ précis
* **Filterable :** si vous devez filtrer sur un champ précis
* **Count Distinct :** si vous voulez obtenir le nombre de valeurs distinctes de ce champ
* **Somme :** s'il s'agit d'une métrique que vous voulez additionner
* **Min :** s'il s'agit d'une métrique pour laquelle vous voulez obtenir des statistiques de synthèse de base
* **Max :** s'il s'agit d'une métrique pour laquelle vous voulez obtenir des statistiques de synthèse de base
* **Is temporal :** à cocher pour tout champ de date ou d'heure

## Explorer vos données


Pour commencer à explorer vos données, cliquez simplement sur la table souhaitée. Par défaut, une vue Table s'affiche.



### Obtenir un décompte de données


Pour obtenir le nombre de tous les enregistrements de la table :


1. Remplacez le filtre par « Since »
2. Saisissez le filtre « since » souhaité


	* Vous pouvez utiliser des expressions simples comme « 3 years ago »
3. Saisissez le filtre « until » souhaité


	* La limite supérieure pour les valeurs par défaut de l'heure est « now »
4. Sélectionnez l'en-tête « Group By »
5. Saisissez « Count » dans la section des métriques
6. Sélectionnez « COUNT(*) »
7. Cliquez sur le bouton « Query »

Vous devriez alors voir vos résultats dans la table.

**Si vous voulez obtenir le nombre pour un champ ou une restriction précis :**

1. Saisissez la ou les restrictions souhaitées dans le champ « Group By »
2. Exécutez la requête

<Aside>Lorsque vous utilisez « measurement » dans une restriction, elle fait référence à la valeur de la mesure effectuée, qui dépend du type de mesure. Vous devez donc vous assurer que les types de mesure sont identiques dans la « section filter (par exemple weather_description et Maximum temperature.) »</Aside>

### Limiter le nombre de résultats

Si vous n'avez besoin que d'un certain nombre de résultats, par exemple les 10 premiers :

1. Sélectionnez « Options »
2. Saisissez le nombre maximal de résultats souhaité dans la section « Row Limit »
3. Cliquez sur « Query »

### Outils de visualisation supplémentaires

Pour développer des valeurs abrégées à leur longueur complète :

1. Sélectionnez « Edit Table Config »
2. Cliquez sur « List Sql Metric »
3. Cliquez sur « Edit Metric »
4. Cliquez sur « D3Format »

Pour modifier l'unité de mesure :


1. Sélectionnez « Edit Table Config »
2. Cliquez sur « List Sql Metric »
3. Cliquez sur « Edit Metric »
4. Cliquez sur « SQL Expression »

Pour changer le type de graphique :


1. Faites défiler jusqu'à « Chart Options »
2. Renseignez les champs obligatoires
3. Cliquez sur « Query »

À partir de là, vous pouvez définir les étiquettes d'axe, les marges, les graduations, etc.
