## Vue d'ensemble

Les tableaux de bord vous permettent de créer des vues interactives sur les données de tout projet ou espace de travail auquel vous avez accès. Un même tableau de bord peut combiner des tables de plusieurs projets, associer des visualisations à une exploration des données brutes et servir aussi bien à des rapports récurrents qu'à des analyses ponctuelles. Les tableaux de bord s'adaptent aussi bien à de petites tables de référence qu'à des jeux de données d'un milliard de lignes, sans modification de configuration.

## Comptes de tableaux de bord

Votre compte de tableaux de bord est configuré pour vous la première fois que vous ouvrez un tableau de bord depuis PlaidCloud, vous n'avez donc rien à créer manuellement. Ce que vous pouvez voir dépend de votre appartenance à l'espace de travail PlaidCloud et de vos groupes de sécurité.

<Aside>Ajoutez, modifiez et retirez des personnes dans PlaidCloud plutôt que dans le service de tableaux de bord : voir [Gérer les membres de l'espace de travail](/fr/administration/access/overview/managing-workspace-members/). La création d'un compte utilisateur directement dans le service de tableaux de bord est réservée aux administrateurs, et un compte créé de cette façon n'est pas lié à votre appartenance à l'espace de travail.</Aside>

## Les tableaux de bord que vous voyez

La page **Tableaux de bord** de PlaidCloud affiche les tableaux de bord publiés appartenant aux projets auxquels vous avez accès. C'est le cas habituel, qui couvre presque tous les tableaux de bord.

Les propriétaires d'un tableau de bord et les administrateurs de l'espace de travail peuvent le limiter à certains groupes de sécurité. Un tableau de bord restreint n'est listé que pour les membres de ces groupes, ainsi que pour ses propriétaires et les administrateurs de l'espace de travail, qui voient tous les tableaux de bord. Un tableau de bord sans restriction est listé pour toutes les personnes ayant accès à ses projets, de sorte que restreindre un tableau de bord ne change jamais qui voit les autres.

Deux points sont utiles à connaître si un tableau de bord manque dans votre liste :

- **Un tableau de bord restreint est masqué dans la liste, et pas seulement à l'ouverture.** Si vous avez accès au projet du tableau de bord et ouvrez son lien, vous verrez une page **Request access** ; sinon, demandez au propriétaire plutôt que de supposer qu'il a été supprimé.
- **Votre compte de tableaux de bord doit exister pour qu'un tableau de bord restreint vous parvienne.** Il est créé pour vous la première fois que vous ouvrez un tableau de bord depuis PlaidCloud, et vos groupes sont alors appliqués.

<Aside>Définissez qui peut voir un tableau de bord dans PlaidCloud avec **Qui peut voir ceci ?** : voir [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/). L'accès aux projets s'applique toujours en plus : voir un tableau de bord ne vous donne jamais accès aux données d'un projet auquel vous n'avez pas accès.</Aside>

## L'espace Tableaux de bord

**Tableaux de bord** s'ouvre avec un rail à gauche et, à côté, la page que vous choisissez. Les membres qui ne peuvent pas ouvrir une page ne voient pas l'élément correspondant.

| Élément du rail | Contenu |
|---|---|
| **Vue d'ensemble** | Des vignettes **Tableaux de bord**, **Visibles par tous**, **Restreint**, **Que vous gérez**, **Applications prêtes** et **Applications en échec**. Sélectionnez une vignette pour ouvrir sa liste, déjà filtrée. **Récemment ouverts et favoris** liste ce que vous avez ouvert ou mis en favori récemment sur cet appareil. **Nécessite une attention** liste les applications en échec et les demandes d'accès qui attendent votre action, avec **À examiner**, qui ouvre les tableaux de bord que vous gérez. **Les plus ouverts sur les 30 derniers jours** s'affiche pour les membres ayant accès aux données d'utilisation. |
| **Tableaux de bord** | Les tableaux de bord que vous pouvez voir. Choisissez **Tous**, **Que vous gérez** ou **Favoris** au-dessus de la liste. Les colonnes comprennent **Audience**, **Propriétaire** et **Ouvertures (30 jours)**. **Importer une archive de tableau de bord…** et **Définir l'audience…** se trouvent dans la barre d'outils. |
| **Applications** | Les applications Panel, Dash et navigateur construites sur vos projets, avec **Genre**, **Statut** et **Projet**. Le statut se met à jour en direct. **Nouvelle application** propose **Serveur** et d'autres types d'applications, et **Galerie** part d'un modèle. |
| **Notebooks** | Vos déploiements JupyterLite. |
| **Révision des accès** | Sous **Administrateur**, pour les administrateurs de l'espace de travail. Voir [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/#révision-des-accès-aux-tableaux-de-bord). |
| **Ouvrir le navigateur** | En bas du rail. Ouvre le service de tableaux de bord dans un nouvel onglet. |

Les compteurs à côté de **Tableaux de bord** et **Applications** indiquent combien d'éléments vous pouvez voir.

## Ouvrir un tableau de bord depuis la page Tableaux de bord

Sur la page **Tableaux de bord**, cliquez sur l'icône **Ouvrir** au début de la ligne d'un tableau de bord pour l'ouvrir dans un nouvel onglet. Un double-clic sur la ligne l'ouvre également.

### Le menu des actions de ligne

Chaque liste de PlaidCloud qui propose des actions par ligne, y compris la page **Tableaux de bord**, dispose d'un menu des actions de ligne. Ouvrez-le avec le bouton **⋯** au début d'une ligne, par un clic droit sur la ligne ou depuis le menu **Actions** de la barre d'outils. Le menu a toujours la même disposition :

1. **Ouvrir**, **Détails** et **Modifier**, dans cet ordre.
2. Les actions propres à la liste, comme **Accès**, **Groupes**, **Réinitialiser le mot de passe** ou **Cloner**.
3. **Supprimer** ou **Supprimer** (retrait), en dernier.

Un séparateur divise les groupes. Une action qui ne s'applique pas à la ligne sélectionnée reste à sa place mais est grisée, de sorte que les éléments ne changent jamais de position d'une ligne à l'autre.

Deux éléments affichent un raccourci. L'élément exécuté par la touche **Enter**, qui ouvre la ligne, affiche **Enter**. L'élément exécuté par la touche **Delete** affiche **Del** (**Backspace** sur Mac).

Une liste dont les lignes n'ont qu'une seule action affiche l'icône de cette action au début de la ligne à la place de **⋯**. Cliquez sur l'icône pour exécuter l'action ; une action destructive demande toujours confirmation. Les lignes qui ne peuvent pas recevoir l'action n'affichent aucune icône.

## Ouvrir un lien de tableau de bord après l'expiration de votre session

Si votre session a expiré lorsque vous ouvrez un lien vers un tableau de bord, vous êtes invité à vous connecter, puis redirigé vers ce tableau de bord plutôt que vers la page d'accueil des tableaux de bord.

## Contrôles d'affichage

Un contrôle d'affichage est un contrôle de la barre de filtres qui permet à toute personne consultant un tableau de bord de changer le critère de regroupement d'un graphique, par exemple remplacer « Région » par « Gamme de produits », sans ouvrir le graphique pour le modifier. Un éditeur de tableau de bord ajoute et configure les contrôles d'affichage depuis le menu des paramètres de la barre de filtres : choisissez **Add or edit filters and controls**, puis **Add display control** dans le menu **Nouveau**.

### Limiter les colonnes proposées

Par défaut, la liste déroulante d'un contrôle d'affichage propose toutes les colonnes du jeu de données sous-jacent marquées **Is filterable**. Sur un jeu de données large, cela peut représenter des centaines de colonnes à parcourir pour trouver celle que vous cherchez.

Chaque contrôle d'affichage dispose désormais de son propre champ **Available columns** dans son panneau de configuration. Définissez-le sur une liste précise de colonnes et la liste déroulante du contrôle ne proposera que ces colonnes. Laissez-le vide et le contrôle se comporte exactement comme avant, en proposant toutes les colonnes filtrables : aucun tableau de bord n'a besoin de modification pour continuer à fonctionner comme il l'a toujours fait.

Pour limiter un contrôle d'affichage :

1. Ouvrez **Add or edit filters and controls** depuis le menu des paramètres de la barre de filtres.
2. Sélectionnez le contrôle d'affichage à limiter, ou ajoutez-en un nouveau.
3. Dans **Available columns**, recherchez et sélectionnez les colonnes que les lecteurs doivent voir.
4. Enregistrez.

### Interaction avec « Is Filterable »

**Available columns** ne propose jamais que des colonnes déjà marquées **Is filterable** dans le jeu de données : il restreint encore cette liste, il ne la contourne pas. Décocher **Is filterable** sur une colonne la retire toujours partout : de **Available columns**, des filtres ad hoc, des filtres natifs et du sélecteur **Simple Metric** de chaque graphique construit sur ce jeu de données.

C'est justement cette large portée qui justifie **Available columns**. Auparavant, le seul moyen de raccourcir la liste déroulante d'un contrôle d'affichage était de décocher **Is filterable** sur les colonnes à ne pas y proposer, ce qui masquait aussi ces mêmes colonnes dans le sélecteur de métriques de chaque graphique sur ce jeu de données. Laissez **Is filterable** coché sur chaque colonne dont un graphique pourrait avoir besoin comme métrique ou filtre ad hoc, et utilisez le champ **Available columns** de chaque contrôle d'affichage pour décider de ce que ce contrôle affiche dans sa liste déroulante Regrouper par.

<Aside type="caution">Le renommage ou la suppression d'une colonne figurant dans la liste **Available columns** d'un contrôle d'affichage n'est pas détecté automatiquement : le contrôle propose simplement moins de colonnes à sa prochaine ouverture, sans avertissement. Revérifiez **Available columns** sur vos contrôles d'affichage après avoir renommé ou supprimé des colonnes de jeux de données.</Aside>

### Où le paramètre est enregistré

**Available columns** est enregistré par contrôle d'affichage, avec le reste des paramètres de ce contrôle. Il accompagne le tableau de bord lors de l'export et de l'import, et n'a aucun effet sur les autres contrôles, que ce soit sur le même tableau de bord ou sur tout autre tableau de bord construit à partir du même jeu de données.

## Modifier une table


Le message que vous recevez après avoir créé une table vous invite également à modifier la configuration de la table. Bien qu'il existe des fonctionnalités plus avancées pour modifier la configuration, nous commencerons par une partie limitée et plus simple. Pour modifier la configuration d'une table :


1. Cliquez sur l'icône de modification de la table souhaitée
2. Cliquez sur l'onglet « List Columns »
3. Disposez les colonnes comme vous le souhaitez
4. Cliquez sur « Save »

Vous définissez ainsi la façon dont vous souhaitez utiliser certaines colonnes de votre table lorsque vous explorez vos données.


* **Regroupable :** si vous voulez que les utilisateurs regroupent des métriques selon un champ donné
* **Filtrable :** si vous devez filtrer sur un champ donné
* **Nombre distinct :** si vous voulez obtenir le nombre de valeurs distinctes de ce champ
* **Somme :** s'il s'agit d'une métrique que vous voulez additionner
* **Min :** s'il s'agit d'une métrique pour laquelle vous voulez obtenir des statistiques récapitulatives de base
* **Max :** s'il s'agit d'une métrique pour laquelle vous voulez obtenir des statistiques récapitulatives de base
* **Est temporel :** à cocher pour tout champ de date ou d'heure

## Explorer vos données


Pour commencer à explorer vos données, cliquez simplement sur la table souhaitée. Par défaut, une vue tableau s'affiche.



### Obtenir un nombre d'enregistrements


Pour obtenir le nombre total d'enregistrements de la table :


1. Définissez le filtre sur « Since »
2. Saisissez le filtre de début souhaité


	* Vous pouvez utiliser des expressions simples comme « 3 years ago »
3. Saisissez le filtre de fin souhaité


	* La limite supérieure par défaut est « now »
4. Sélectionnez l'en-tête « Regrouper par »
5. Saisissez « Count » dans la section des métriques
6. Sélectionnez « COUNT(*) »
7. Cliquez sur le bouton « Query »

Vos résultats s'affichent alors dans le tableau.

**Si vous voulez obtenir le nombre pour un champ ou une restriction spécifique :**

1. Saisissez la ou les restrictions souhaitées dans le champ « Regrouper par »
2. Exécutez la requête

<Aside>Lorsque vous utilisez « measurement » dans une restriction, il fait référence à la valeur de la mesure effectuée, qui dépend du type de mesure. Vous devez donc vous assurer que les types de mesure sont identiques dans la « section des filtres (par exemple weather_description et Maximum temperature.) »</Aside>

### Limiter le nombre de résultats

Si vous n'avez besoin que d'un certain nombre de résultats, par exemple les 10 premiers :

1. Sélectionnez « Options »
2. Saisissez le nombre maximal de résultats souhaité dans la section « Row Limit »
3. Cliquez sur « Query »

### Outils de visualisation supplémentaires

Pour afficher les valeurs abrégées en entier :

1. Sélectionnez « Edit Table Config »
2. Cliquez sur « List Sql Metric »
3. Cliquez sur « Edit Metric »
4. Cliquez sur « D3Format »

Pour modifier l'unité de mesure :


1. Sélectionnez « Edit Table Config »
2. Cliquez sur « List Sql Metric »
3. Cliquez sur « Edit Metric »
4. Cliquez sur « SQL Expression »

Pour changer le type de graphique :


1. Faites défiler jusqu'à « Chart Options »
2. Remplissez les champs obligatoires
3. Cliquez sur « Query »

Vous pouvez alors définir les libellés des axes, les marges, les graduations, etc.
