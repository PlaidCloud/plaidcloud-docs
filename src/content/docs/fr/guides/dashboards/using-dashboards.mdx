## Vue d'ensemble

Les tableaux de bord vous permettent de créer des vues interactives sur les données de n'importe quel projet ou espace de travail auquel vous avez accès. Un même tableau de bord peut combiner des tables issues de plusieurs projets, mêler visualisations et exploration brute, et servir à la fois des rapports permanents et des analyses ponctuelles. Les tableaux de bord passent de petites tables de référence à des jeux de données de plusieurs milliards de lignes sans modification de configuration.

## Comptes de tableau de bord

Votre compte de tableau de bord est créé pour vous la première fois que vous ouvrez un tableau de bord depuis PlaidCloud : il n'y a donc rien à créer manuellement. Ce que vous pouvez voir découle de votre appartenance à l'espace de travail PlaidCloud et de vos groupes de sécurité.

<Aside>Ajoutez, modifiez et supprimez des personnes dans PlaidCloud plutôt que dans le service de tableaux de bord : voir [Gestion des membres de l'espace de travail](/fr/administration/access/overview/managing-workspace-members/). La création d'un compte utilisateur directement dans le service de tableaux de bord est une action réservée aux administrateurs, et un compte créé de cette façon n'est pas relié à votre appartenance à l'espace de travail.</Aside>

## Les tableaux de bord que vous voyez

La page **Tableaux de bord** de PlaidCloud affiche les tableaux de bord publiés qui appartiennent aux projets auxquels vous avez accès. C'est le cas habituel, et il couvre presque tous les tableaux de bord.

Les propriétaires d'un tableau de bord et les administrateurs de l'espace de travail peuvent le limiter à certains groupes de sécurité. Un tableau de bord restreint n'est listé que pour les membres de ces groupes, ainsi que pour ses propriétaires et les administrateurs de l'espace de travail, qui voient tous les tableaux de bord. Un tableau de bord sans restriction est listé pour toutes les personnes ayant accès à ses projets : restreindre un tableau de bord ne change donc jamais qui voit les autres.

Deux points sont utiles à connaître si un tableau de bord manque dans votre liste :

- **Un tableau de bord restreint est masqué de la liste, et pas seulement à l'ouverture.** Si vous avez accès au projet du tableau de bord et ouvrez son lien, vous verrez une page **Request access** ; sinon, demandez au propriétaire plutôt que de supposer qu'il a été supprimé.
- **Votre compte de tableau de bord doit exister pour qu'un tableau de bord restreint vous parvienne.** Il est créé pour vous la première fois que vous ouvrez un tableau de bord depuis PlaidCloud, et vos groupes y sont appliqués à ce moment-là.

<Aside>Définissez qui peut voir un tableau de bord dans PlaidCloud avec **Qui peut voir ceci ?** : voir [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/). L'accès au projet s'applique toujours en plus : voir un tableau de bord ne vous donne jamais les données d'un projet auquel vous n'avez pas accès.</Aside>

## L'espace Tableaux de bord

**Tableaux de bord** s'ouvre avec un rail à gauche et la page que vous choisissez à côté. Les membres qui ne peuvent pas ouvrir une page n'en voient pas l'élément. Chaque page comporte en haut un titre et un court sous-titre, avec ses actions dans l'en-tête, à côté.

| Élément du rail | Ce qu'il affiche |
|---|---|
| **Vue d'ensemble** | Des vignettes pour **Tableaux de bord**, **Visible to everyone**, **Restreint**, **You manage**, **Apps ready** et **Apps failed**. Sélectionnez une vignette pour ouvrir sa liste, déjà filtrée. **Recently opened and favorites** liste ce que vous avez ouvert ou ajouté aux favoris récemment sur cet appareil. **Nécessite une attention** liste les applications en échec et les demandes d'accès qui vous attendent, avec **À examiner**, qui ouvre les tableaux de bord que vous gérez. **Most opened in the last 30 days** s'affiche pour les membres ayant accès à l'utilisation. |
| **Tableaux de bord** | Les tableaux de bord que vous pouvez voir. Choisissez **Tous**, **You manage** ou **Favoris** au-dessus de la liste. Les colonnes incluent **Audience**, **Propriétaire** et **Opens (30 days)**. **Import dashboard archive…** et **Définir l'audience…** se trouvent dans la barre d'outils. |
| **Applications** | Les applications Panel, Dash et de navigateur créées sur vos projets, avec **Genre**, **Statut** et **Projet**. Le statut se met à jour en direct. **New app** propose **Serveur** et d'autres types d'applications, et **Galerie** démarre à partir d'un modèle. |
| **Notebooks** | Vos déploiements JupyterLite. |
| **Révision des accès** | Sous **Administrateur**, pour les administrateurs de l'espace de travail. Voir [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/#révision-des-accès-aux-tableaux-de-bord). |
| **Open navigator ↗** | En bas du rail. La flèche indique que c'est le seul élément qui ouvre sa propre fenêtre : le service de tableaux de bord, dans un nouvel onglet. |

Les compteurs à côté de **Tableaux de bord** et **Applications** indiquent combien vous pouvez en voir.

## Ouvrir un tableau de bord depuis la page Tableaux de bord

Sur la page **Tableaux de bord**, cliquez sur l'icône **Ouvrir** au début de la ligne d'un tableau de bord pour l'ouvrir dans un nouvel onglet. Un double-clic sur la ligne l'ouvre aussi.

### Le menu d'actions de ligne

Chaque liste de PlaidCloud qui propose des actions par ligne, y compris la page **Tableaux de bord**, possède un menu d'actions de ligne. Ouvrez-le depuis le bouton **⋯** au début d'une ligne, par un clic droit sur la ligne, ou depuis le menu **Actions** de la barre d'outils. Le menu a toujours la même structure :

1. **Ouvrir**, **Détails** et **Modifier**, dans cet ordre.
2. Les actions propres à la liste, telles que **Accès**, **Groupes**, **Réinitialiser le mot de passe** ou **Cloner**.
3. **Supprimer**, en dernier.

Un séparateur divise les groupes. Une action qui ne s'applique pas à la ligne sélectionnée reste à sa place mais est grisée, de sorte que les éléments ne se déplacent jamais d'une ligne à l'autre.

Deux éléments affichent un raccourci. L'élément qu'exécute la touche **Entrée**, qui ouvre la ligne, affiche **Enter**. L'élément qu'exécute la touche **Suppr** affiche **Del** (**Retour arrière** sur un Mac).

Une liste dont les lignes n'ont qu'une seule action affiche l'icône de cette action au début de la ligne à la place de **⋯**. Cliquez sur l'icône pour exécuter l'action ; une action destructrice demande toujours une confirmation. Les lignes qui ne peuvent pas recevoir l'action n'affichent aucune icône.

### Vues standard, aérée et cartes

Les listes des applications de l'espace de travail de PlaidCloud, telles que **Tableaux de bord**, **Applications**, le **Registre** ERP et les **Membres** d'Identity, ont dans la barre d'outils un menu **Vue** avec trois choix :

- **Standard rows** : la liste compacte, une ligne par élément.
- **Roomy rows** : la même liste avec plus d'espace autour de chaque ligne.
- **Cards** : une carte par élément. Les cartes de **Tableaux de bord** montrent une miniature du tableau de bord, et les cartes du registre ERP montrent le montant, la date, l'entité, la connexion et le document.

Les cartes se comportent comme la liste : sélectionnez une carte, étendez la sélection avec Maj, triez et choisissez les colonnes depuis le menu **Vue**, faites un clic droit pour **Copier** et pour les actions de la ligne, et cliquez sur l'étoile pour l'ajouter aux favoris.

## Ouvrir un lien de tableau de bord après l'expiration de votre session

Si votre session a expiré lorsque vous ouvrez un lien vers un tableau de bord, il vous est demandé de vous connecter, puis vous êtes dirigé vers ce tableau de bord, plutôt que vers la page d'accueil des tableaux de bord.

## Contrôles d'affichage

Un contrôle d'affichage est un contrôle de la barre de filtres qui permet à toute personne consultant un tableau de bord de modifier le regroupement d'un graphique, par exemple en remplaçant « Région » par « Gamme de produits », sans ouvrir le graphique pour le modifier. Un éditeur de tableau de bord ajoute et configure les contrôles d'affichage depuis le menu des paramètres de la barre de filtres : choisissez **Add or edit filters and controls**, puis **Add display control** dans le menu **Nouveau**.

### Limiter les colonnes proposées

Par défaut, la liste déroulante d'un contrôle d'affichage énumère toutes les colonnes du jeu de données sous-jacent marquées **Is filterable**. Sur un jeu de données large, cela peut représenter des centaines de colonnes à parcourir pour trouver celle que vous voulez.

Chaque contrôle d'affichage possède désormais son propre champ **Available columns** dans son panneau de configuration. Définissez-le sur une liste précise de colonnes, et la liste déroulante du contrôle ne propose que ces colonnes. Laissez-le vide et le contrôle se comporte exactement comme avant, en proposant toutes les colonnes filtrables : aucun tableau de bord n'a besoin de modification pour continuer à fonctionner comme toujours.

Pour limiter un contrôle d'affichage :

1. Ouvrez **Add or edit filters and controls** depuis le menu des paramètres de la barre de filtres.
2. Sélectionnez le contrôle d'affichage que vous voulez limiter, ou ajoutez-en un nouveau.
3. Dans **Available columns**, recherchez et sélectionnez les colonnes que vous voulez montrer aux lecteurs.
4. Enregistrez.

### Interaction avec « Is Filterable »

**Available columns** ne propose que des colonnes déjà marquées **Is filterable** dans le jeu de données : il restreint encore cette liste, sans la contourner. Décocher **Is filterable** pour une colonne la retire toujours partout : de **Available columns**, des filtres ad hoc, des filtres natifs et du sélecteur **Simple Metric** de chaque graphique construit sur ce jeu de données.

Cette portée étendue est précisément la raison d'être de **Available columns**. Auparavant, le seul moyen de raccourcir la liste déroulante d'un contrôle d'affichage était de décocher **Is filterable** pour les colonnes que vous ne vouliez pas y voir, ce qui masquait aussi ces mêmes colonnes dans le sélecteur de métriques de chaque graphique de ce jeu de données. Laissez **Is filterable** coché pour chaque colonne dont un graphique peut avoir besoin comme métrique ou comme filtre ad hoc, et utilisez le champ **Available columns** de chaque contrôle d'affichage pour décider de ce que ce contrôle montre dans sa liste déroulante Group By.

<Aside type="caution">Le renommage ou la suppression d'une colonne figurant dans la liste **Available columns** d'un contrôle d'affichage n'est pas détecté automatiquement : le contrôle propose simplement moins de colonnes à sa prochaine ouverture, sans avertissement. Revoyez **Available columns** sur vos contrôles d'affichage après avoir renommé ou supprimé des colonnes du jeu de données.</Aside>

### Où c'est enregistré

**Available columns** est enregistré par contrôle d'affichage, avec le reste des paramètres de ce contrôle. Il suit le tableau de bord lors de l'exportation et de l'importation, et n'a aucun effet sur les autres contrôles, que ce soit sur le même tableau de bord ou sur tout autre tableau de bord construit à partir du même jeu de données.

## Modifier une table


Le message que vous recevez après la création d'une nouvelle table vous invite également à modifier la configuration de la table. Bien qu'il existe des fonctionnalités plus avancées pour modifier la configuration, nous commencerons par une partie limitée et plus simple. Pour modifier la configuration de la table :


1. Cliquez sur l'icône de modification de la table souhaitée.
2. Cliquez sur l'onglet « List Columns ».
3. Organisez les colonnes comme vous le souhaitez.
4. Cliquez sur « Save ».

Cela vous permet de définir la manière dont vous voulez utiliser des colonnes précises de votre table lors de l'exploration de vos données.


* **Groupable :** si vous voulez que les utilisateurs regroupent les métriques selon un champ précis
* **Filterable :** si vous devez filtrer sur un champ précis
* **Count Distinct :** si vous voulez obtenir le nombre de valeurs distinctes de ce champ
* **Somme :** s'il s'agit d'une métrique que vous voulez additionner
* **Min :** s'il s'agit d'une métrique pour laquelle vous voulez recueillir des statistiques récapitulatives de base
* **Max :** s'il s'agit d'une métrique pour laquelle vous voulez recueillir des statistiques récapitulatives de base
* **Is temporal :** à cocher pour tout champ de date ou d'heure

## Explorer vos données


Pour commencer à explorer vos données, cliquez simplement sur la table souhaitée. Par défaut, une Vue Table vous est présentée.



### Obtenir un décompte des données


Pour obtenir le nombre de tous les enregistrements de la table :


1. Remplacez le filtre par « Since ».
2. Saisissez le filtre « since » souhaité.


	* Vous pouvez utiliser des expressions simples telles que « 3 years ago ».
3. Saisissez le filtre « until » souhaité.


	* La limite supérieure du temps est par défaut « now ».
4. Sélectionnez l'en-tête « Regrouper par ».
5. Saisissez « Count » dans la section des métriques.
6. Sélectionnez « COUNT(*) ».
7. Cliquez sur le bouton « Query ».

Vous devriez alors voir vos résultats dans la table.

**Si vous voulez obtenir le nombre pour un champ ou une restriction précis :**

1. Saisissez la ou les restrictions souhaitées dans le champ « Regrouper par ».
2. Exécutez la requête.

<Aside>Lorsque vous utilisez « measurement » dans une restriction, cela fait référence à la valeur de la mesure effectuée, qui dépend du type de mesure. Vous devez donc vous assurer que les types de mesure sont identiques dans la « section de filtre (par exemple weather_description et Maximum temperature) ».</Aside>

### Limiter le nombre de résultats

Si vous n'avez besoin que d'un certain nombre de résultats, par exemple les 10 premiers :

1. Sélectionnez « Options ».
2. Saisissez le nombre maximal de résultats souhaité dans la section « Row Limit ».
3. Cliquez sur « Query ».

### Outils de visualisation supplémentaires

Pour développer les valeurs abrégées à leur longueur complète :

1. Sélectionnez « Edit Table Config ».
2. Cliquez sur « List Sql Metric ».
3. Cliquez sur « Edit Metric ».
4. Cliquez sur « D3Format ».

Pour modifier l'unité de mesure :


1. Sélectionnez « Edit Table Config ».
2. Cliquez sur « List Sql Metric ».
3. Cliquez sur « Edit Metric ».
4. Cliquez sur « SQL Expression ».

Pour changer le type de graphique :


1. Faites défiler jusqu'à « Chart Options ».
2. Renseignez les champs obligatoires.
3. Cliquez sur « Query ».

À partir de là, vous pouvez définir les libellés des axes, les marges, les graduations, etc.
