## Vue d'ensemble

Les tableaux de bord vous permettent de créer des vues interactives sur les données de n'importe quel projet ou espace de travail auquel vous avez accès. Un même tableau de bord peut combiner des tables issues de plusieurs projets, associer des visualisations à une exploration des données brutes, et servir aussi bien des rapports récurrents que des analyses ponctuelles. Les tableaux de bord passent de petites tables de référence à des jeux de données de plusieurs milliards de lignes sans modification de configuration.

## Comptes de tableau de bord

Votre compte de tableau de bord est créé pour vous la première fois que vous ouvrez un tableau de bord depuis PlaidCloud : il n'y a donc rien à créer manuellement. Ce que vous pouvez voir dépend de votre appartenance à l'espace de travail PlaidCloud et de vos groupes de sécurité.

<Aside>Ajoutez, modifiez et supprimez des personnes dans PlaidCloud plutôt que dans le service de tableaux de bord — consultez [Gérer les membres de l'espace de travail](/fr/administration/access/overview/managing-workspace-members/). La création d'un compte utilisateur directement dans le service de tableaux de bord est une action réservée aux administrateurs, et un compte créé de cette manière n'est pas lié à votre appartenance à l'espace de travail.</Aside>

## Les tableaux de bord que vous voyez

La liste des tableaux de bord dans PlaidCloud affiche les tableaux de bord publiés qui appartiennent aux projets auxquels vous avez accès. C'est le cas habituel, qui couvre presque tous les tableaux de bord.

Les propriétaires d'un tableau de bord et les administrateurs de l'espace de travail peuvent le limiter à certains groupes de sécurité. Un tableau de bord restreint n'apparaît que pour les membres de ces groupes, ainsi que pour ses propriétaires et les administrateurs de l'espace de travail, qui voient tous les tableaux de bord. Un tableau de bord sans restriction apparaît pour toute personne ayant accès à ses projets : restreindre un tableau de bord ne modifie donc jamais qui voit les autres.

Deux points sont utiles à connaître si un tableau de bord manque dans votre liste :

- **Un tableau de bord restreint est masqué de la liste, pas seulement de l'ouverture.** Si vous avez accès au projet du tableau de bord et que vous ouvrez son lien, une page **Request access** s'affiche ; sinon, demandez au propriétaire plutôt que de supposer qu'il a été supprimé.
- **Votre compte de tableau de bord doit exister pour qu'un tableau de bord restreint vous parvienne.** Il est créé pour vous la première fois que vous ouvrez un tableau de bord depuis PlaidCloud, et vos groupes sont appliqués à ce moment-là.

<Aside>Définissez qui peut voir un tableau de bord dans PlaidCloud avec **Qui peut voir ceci ?** — consultez [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/). L'accès au projet s'applique toujours en plus : voir un tableau de bord ne vous donne jamais accès aux données d'un projet que vous ne pouvez pas atteindre.</Aside>

## Ouvrir un lien de tableau de bord après l'expiration de votre session

Si votre session a expiré lorsque vous ouvrez un lien vers un tableau de bord, vous êtes invité à vous connecter, puis dirigé vers ce tableau de bord, et non vers la page d'accueil des tableaux de bord.

## Contrôles d'affichage

Un contrôle d'affichage est un contrôle de la barre de filtres qui permet à toute personne consultant un tableau de bord de modifier le regroupement d'un graphique — par exemple remplacer « Région » par « Gamme de produits » — sans ouvrir le graphique pour le modifier. Un éditeur de tableau de bord ajoute et configure les contrôles d'affichage depuis le menu des paramètres de la barre de filtres : choisissez **Add or edit filters and controls**, puis **Add display control** dans le menu **Nouveau**.

### Limiter les colonnes proposées

Par défaut, la liste déroulante d'un contrôle d'affichage répertorie toutes les colonnes du jeu de données sous-jacent marquées **Is filterable**. Sur un jeu de données large, cela peut représenter des centaines de colonnes à parcourir pour trouver celle que vous voulez.

Chaque contrôle d'affichage dispose désormais de son propre champ **Available columns** dans son panneau de configuration. Définissez-le avec une liste précise de colonnes et la liste déroulante du contrôle ne proposera que ces colonnes. Laissez-le vide et le contrôle se comporte exactement comme avant, en proposant toutes les colonnes filtrables — aucun tableau de bord n'a besoin d'être modifié pour continuer à fonctionner comme auparavant.

Pour limiter un contrôle d'affichage :

1. Ouvrez **Add or edit filters and controls** depuis le menu des paramètres de la barre de filtres.
2. Sélectionnez le contrôle d'affichage à limiter, ou ajoutez-en un nouveau.
3. Dans **Available columns**, recherchez et sélectionnez les colonnes que vous voulez montrer aux utilisateurs.
4. Enregistrez.

### Interaction avec « Is Filterable »

**Available columns** ne propose que des colonnes déjà marquées **Is filterable** dans le jeu de données — il restreint encore cette liste, sans la contourner. Décocher **Is filterable** sur une colonne la retire toujours partout : de **Available columns**, des filtres ad hoc, des filtres natifs et du sélecteur **Simple Metric** de chaque graphique créé sur ce jeu de données.

Cette portée étendue est précisément la raison d'être de **Available columns**. Auparavant, la seule façon de raccourcir la liste déroulante d'un contrôle d'affichage était de décocher **Is filterable** sur les colonnes que vous ne vouliez pas proposer — ce qui masquait aussi ces mêmes colonnes dans le sélecteur de métriques de chaque graphique de ce jeu de données. Laissez **Is filterable** coché sur chaque colonne dont un graphique peut avoir besoin comme métrique ou comme filtre ad hoc, et utilisez le champ **Available columns** de chaque contrôle d'affichage pour décider de ce que ce contrôle affiche dans sa liste déroulante **Regrouper par**.

<Aside type="caution">Le renommage ou la suppression d'une colonne figurant dans la liste **Available columns** d'un contrôle d'affichage n'est pas détecté automatiquement — le contrôle propose simplement moins de colonnes à sa prochaine ouverture, sans avertissement. Revoyez **Available columns** sur vos contrôles d'affichage après avoir renommé ou supprimé des colonnes du jeu de données.</Aside>

### Où c'est enregistré

**Available columns** est enregistré pour chaque contrôle d'affichage, avec le reste des paramètres de ce contrôle. Il suit le tableau de bord lors de l'export et de l'import, et n'a aucun effet sur les autres contrôles — que ce soit sur le même tableau de bord ou sur tout autre tableau de bord créé à partir du même jeu de données.

## Modifier une table


Le message que vous recevez après la création d'une nouvelle table vous invite également à modifier la configuration de la table. Même si des fonctionnalités plus avancées permettent de modifier la configuration, nous commencerons par une partie limitée et plus simple. Pour modifier la configuration d'une table :


1. Cliquez sur l'icône de modification de la table souhaitée
2. Cliquez sur l'onglet « List Columns »
3. Organisez les colonnes comme vous le souhaitez
4. Cliquez sur « Save »

Cela vous permet de définir la façon dont vous voulez utiliser certaines colonnes de votre table lors de l'exploration de vos données.


* **Groupable :** si vous voulez que les utilisateurs puissent regrouper des métriques selon un champ précis
* **Filterable :** si vous avez besoin de filtrer sur un champ précis
* **Count Distinct :** si vous voulez obtenir le nombre de valeurs distinctes de ce champ
* **Somme :** s'il s'agit d'une métrique que vous voulez additionner
* **Min :** s'il s'agit d'une métrique pour laquelle vous voulez obtenir des statistiques récapitulatives de base
* **Max :** s'il s'agit d'une métrique pour laquelle vous voulez obtenir des statistiques récapitulatives de base
* **Is temporal :** à cocher pour tout champ de date ou d'heure

## Explorer vos données


Pour commencer à explorer vos données, cliquez simplement sur la table souhaitée. Par défaut, une vue Table s'affiche.



### Obtenir un nombre d'enregistrements


Pour obtenir le nombre de tous les enregistrements de la table :


1. Remplacez le filtre par « Since »
2. Saisissez le filtre « since » souhaité


	* Vous pouvez utiliser des expressions simples telles que « 3 years ago »
3. Saisissez le filtre « until » souhaité


	* La limite supérieure de la période est « now » par défaut
4. Sélectionnez l'en-tête « Regrouper par »
5. Saisissez « Count » dans la section des métriques
6. Sélectionnez « COUNT(*) »
7. Cliquez sur le bouton « Query »

Vous devriez alors voir vos résultats dans la table.

**Si vous voulez obtenir le nombre d'enregistrements pour un champ ou une restriction précis :**

1. Saisissez la ou les restrictions souhaitées dans le champ « Regrouper par »
2. Exécutez la requête

<Aside>Lorsque vous utilisez « measurement » dans une restriction, cela renvoie à la valeur de la mesure effectuée, qui dépend du type de mesure. Vous devez donc vous assurer que les types de mesure sont identiques dans la « section des filtres » (par exemple weather_description et Maximum temperature).</Aside>

### Restreindre le nombre de résultats

Si vous n'avez besoin que d'un certain nombre de résultats, par exemple les 10 premiers :

1. Sélectionnez « Options »
2. Saisissez le nombre maximal de résultats souhaité dans la section « Row Limit »
3. Cliquez sur « Query »

### Outils de visualisation supplémentaires

Pour développer des valeurs abrégées et afficher leur longueur complète :

1. Sélectionnez « Edit Table Config »
2. Cliquez sur « List Sql Metric »
3. Cliquez sur « Edit Metric »
4. Cliquez sur « D3Format »

Pour modifier l'unité de mesure :


1. Sélectionnez « Edit Table Config »
2. Cliquez sur « List Sql Metric »
3. Cliquez sur « Edit Metric »
4. Cliquez sur « SQL Expression »

Pour changer le type de graphique :


1. Faites défiler jusqu'à « Chart Options »
2. Renseignez les champs obligatoires
3. Cliquez sur « Query »

À partir de là, vous pouvez définir les libellés des axes, les marges, les graduations, etc.
