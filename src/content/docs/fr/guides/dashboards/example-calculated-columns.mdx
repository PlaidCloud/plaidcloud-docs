## Description

Les données des tableaux de bord peuvent être enrichies par des colonnes calculées.  Chaque jeu de données contient une section pour les colonnes calculées.  Les colonnes calculées peuvent être écrites et modifiées en SQL de type PostgreSQL.

<SnippetDashboardsCommonNavigateToDataset />

## Exemples
### Count
```sql
COUNT(*)
```

### Min
```sql
min("MyColumnName")
```

### Max
```sql
max("MyColumnName")
```

### Coalesce (utile pour convertir des valeurs nulles en 0.0, par exemple)
```sql
coalesce("BaselineCost",0.0)
```

### Substring
```sql
substring("PERIOD",6,2)
```

### Cast
```sql
CAST("YEAR" AS integer)-1
```

### Concat
```sql
concat("Biller Entity" , ' ', "Country_biller")
```

### To_char
```sql
to_char("date_created", 'YYYY-mm-dd')
```

### Left
```sql
left("period",4)
```

### Divide
division, avec une astuce pour éviter les erreurs de division par zéro
```sql
sum("so_infull")/(count(*)+0.00001)
```
<Aside>Une meilleure approche consisterait à vérifier si le dénominateur est nul ou égal à zéro, puis à utiliser coalesce pour retourner zéro, plutôt que de tenter la division.</Aside>


### Instruction conditionnelle
```sql
CASE WHEN "Field_A"= 'Foo' THEN max(coalesce("Value_A",0.0)) - max(coalesce("Value_B",0.0)) END
```
```sql
CASE WHEN "sol_otif_pod_missing" = 1 THEN
'POD is missing.'
ELSE
'POD exists.'
END
```
```sql
case when "Customer DC" = "origin_dc" or "order_reason_type" = 'Off Schedule' or "mot_type" = 'UPS' then
    'Yes'
else
    'No'
end
```
```sql
CASE WHEN "module_type" is NULL THEN '---' ELSE "module_type" END
```
```sql
CASE WHEN "NODE_TYPE" = 'External' THEN '3rd Party' ELSE "ENTITY_LOCATION_DESCRIPTION" END
```

### Concaténation
```sql
concat("Class",' > ',"Product Family",' > ',"Meta Series")
```
