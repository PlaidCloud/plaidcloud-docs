Document ne sauvegarde pas de lui-même les fichiers d'un compte. Pour en conserver une seconde copie — par exemple dans un compte chez un autre fournisseur cloud — copiez-les avec un workflow et exécutez-le selon une planification :

1. Créer un workflow avec une étape [Copy Document Directory](/fr/reference/workflow-steps/document/copy-document-directory/).
2. Sous **Copy Directory**, choisissez le compte et le dossier à sauvegarder.
3. Sous **Select Destination**, choisissez le compte dans lequel copier et le dossier où placer la copie.
4. Planifiez l'exécution du workflow, par exemple chaque nuit. Consultez [Planifier un workflow](/fr/get-started/tutorials/schedule-a-workflow/).

Plusieurs comptes peuvent partager un même compte de sauvegarde : donnez à chaque copie son propre nom en cochant **Rename the Copied Folder to:** et en la nommant d'après le compte d'origine, afin que leurs dossiers n'entrent jamais en collision.

<Aside type="caution">Copy Document Directory écrase tout ce qui porte le même nom à la destination ; chaque exécution remplace donc la copie précédente au lieu de conserver un historique de copies.</Aside>
