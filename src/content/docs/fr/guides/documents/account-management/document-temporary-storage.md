Le stockage temporaire peut sembler contre-intuitif, mais l'usage réel a montré qu'il est précieux. En général, le stockage permanent sert à déplacer de gros fichiers entre membres ou entre d'autres systèmes, et le nettoyage des fichiers dans ces emplacements se fait souvent de manière désordonnée, au mieux. Le stockage se remplit alors de fichiers qui n'ont rien à y faire, ce qui finit par exiger un nettoyage manuel.



Le stockage temporaire est idéal pour partager ou transférer ce type de gros fichiers, car les fichiers sont supprimés automatiquement après 24 heures.



## Afficher les options de stockage temporaire


1. Aller à `Document > Temp Share` dans PlaidCloud

## Stockage temporaire partagé


Le stockage temporaire partagé est visible par tous les membres de l'espace de travail, mais pas d'un espace de travail à l'autre. Pour accéder à la zone de stockage temporaire partagé, sélectionnez le menu `Temp Share` et cliquez sur `Workspace Temp Share` pour afficher un tableau des fichiers actuellement présents dans la zone Temp Share de l'espace de travail.



### Ajouter de nouveaux fichiers à un emplacement de stockage temporaire partagé


1. Sélectionnez le menu `Temp Share` en haut de la page principale Document
2. Cliquez sur `Workspace Temp Share`
3. Cliquez sur `Browse` pour parcourir les éléments stockés localement
4. Sélectionnez le fichier souhaité et cliquez sur `Open`
5. Cliquez sur `Upload` pour téléverser le fichier vers l'emplacement de stockage temporaire

### Télécharger des fichiers existants depuis le stockage temporaire


1. Cliquez sur l'icône située le plus à gauche, qui représente le type de fichier

### Supprimer manuellement un fichier


1. Cliquez sur l'icône rouge de suppression à gauche du nom du fichier.

Vous trouverez plus de détails sur la gestion des fichiers plus bas, sous « File Explorer ».



## Stockage temporaire personnel


Le stockage temporaire personnel n'est visible que par le membre auquel appartient le Temp Share. Cette option de stockage est avantageuse car elle est accessible d'un espace de travail à l'autre. Cette fonctionnalité facilite le déplacement ou l'utilisation de fichiers entre espaces de travail lorsque le membre travaille simultanément dans plusieurs espaces de travail.



Tous les membres de l'espace de travail peuvent téléverser des fichiers vers l'espace personnel d'un membre, à la manière d'une boîte de dépôt.



### Téléverser un fichier vers l'espace personnel d'un autre membre :


1. Sélectionnez le menu `Temp Share` en haut de la page principale Document
2. Sélectionnez `Drop File to Member Temp.` Une liste de membres s'affiche.
3. Cliquez sur l'icône située le plus à gauche associée au membre de votre choix
4. Cliquez sur `Browse` pour parcourir les éléments stockés localement
5. Sélectionnez le fichier souhaité, puis cliquez sur `Open`
6. Cliquez sur `Upload` pour téléverser le fichier vers le stockage personnel du membre

Vous trouverez plus de détails sur le téléversement de fichiers plus bas, sous « File Explorer ».
