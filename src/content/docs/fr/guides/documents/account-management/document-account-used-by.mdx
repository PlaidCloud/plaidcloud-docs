Avant de retirer, de remplacer ou de reconstruire un compte de documents, repérez tout ce qui l'utilise, puis déplacez ces usages vers un autre compte.

## Voir où un compte est utilisé

1. Sélectionnez `Document > Manage Accounts`.
2. Sélectionnez l'icône **Utilisé par** sur la ligne du compte.

**Où utilisé** liste chaque usage avec son projet, son type, son nom et la manière dont le compte est utilisé :

| Colonne | Valeurs |
| --- | --- |
| Type | Étape, workflow ou valeur par défaut de projet |
| Utilisé | Directement ; condition de conteneur ; valeur par défaut de projet ; ou variable (peut être utilisé) |

Les étapes et les workflows que votre rôle ne peut pas voir sont comptés mais pas nommés. La liste est constituée projet par projet et indique si elle peut être incomplète ou quels projets n'ont jamais été analysés.

Les manifestes App Runner et les images de tuiles de projet ne sont pas analysés. Un usage provenant d'une variable est listé, et vous mettez à jour cette variable manuellement.

## Réaffecter un compte

1. Dans **Où utilisé**, sélectionnez **Réaffecter...**.
2. Choisissez le compte vers lequel basculer, puis sélectionnez **Aperçu**.
3. Passez en revue les usages. Rien n'a encore changé. Décochez ceux que vous souhaitez laisser tels quels.
4. Sélectionnez **Réaffecter** et confirmez.

Chaque usage affiche alors son résultat : **Modifié**, **Modifié depuis l'aperçu**, **Non autorisé**, **Le projet est verrouillé**, **N'existe plus** ou **Refusé**. Un usage en échec n'arrête pas les autres. La modification d'une valeur par défaut de projet nécessite un Architecte ou un administrateur de l'espace de travail.

Les usages par variable ne sont jamais modifiés. L'aperçu nomme chaque variable et l'étape à mettre à jour manuellement.

<Aside type="caution">Si vous réaffectez vers un Personal Temp Drive, les workflows s'exécutent en tant que projet, qui ne peut pas ouvrir ce lecteur, et les étapes réaffectées échouent à l'exécution. PlaidCloud vous avertit pour chaque projet concerné.</Aside>

## Utiliser un assistant IA

* L'assistant IA d'un projet peut proposer une réaffectation. Il présente les modifications sur une carte d'approbation et ne les applique qu'après votre approbation.
* Via MCP, `document_account_describe(include=['used_by'])` liste les usages, et `document_account_repoint` affiche l'aperçu d'une réaffectation et l'applique.
