## Configuration du serveur SFTP

Assurez-vous que l'administrateur de votre serveur SFTP vous a fourni les éléments suivants :

1. Le **nom d'hôte ou l'adresse IP** du serveur SFTP
2. Le **port SSH** (`22` par défaut)
3. Un **nom d'utilisateur** ayant accès au répertoire cible
4. Un **mot de passe** ou une **clé privée SSH** pour l'authentification
5. Facultativement, l'**empreinte de la clé d'hôte SSH du serveur** pour une vérification stricte de l'hôte

Vous disposez maintenant de tout le nécessaire pour ajouter votre compte SFTP à PlaidCloud Document.


## Configuration de PlaidCloud Document

1. Connectez-vous à PlaidCloud
2. Sélectionnez l'espace de travail dans lequel le nouveau compte de documents sera créé
3. Accédez à `Document > Manage`
4. Sélectionnez le bouton **Nouveau compte**
5. Sélectionnez `Secure File Transfer (SFTP)` comme Type de service
6. Saisissez un nom et une description
7. Saisissez le chemin du répertoire distant dans le champ **Chemin de départ** (par ex. `/data/uploads`)
8. Sélectionnez le **Modèle de sécurité** adapté à votre cas d'usage. En cas de doute, conservez `Private`.
9. Saisissez le **nom d'utilisateur** dans le champ Public Key/User, sous Identifiants d'authentification
10. Saisissez le **mot de passe** dans le champ Private Key/Password, sous Identifiants d'authentification
11. Accédez à l'onglet **Configuration SSH**
12. Saisissez l'**Hôte ou adresse IP** du serveur SFTP
13. Saisissez le **Port de connexion SSH** (`22` par défaut)
14. Si vous utilisez une authentification par clé plutôt qu'un mot de passe, collez la **RSA Private Key** dans le champ RSA Private Key. Lorsqu'une clé privée est fournie, elle prévaut sur le mot de passe. La clé enregistrée n'est plus jamais affichée ; pour revenir à l'authentification par mot de passe, sélectionnez **Effacer la clé enregistrée (utiliser le mot de passe)**.
15. Collez éventuellement la **Remote Server RSA Fingerprint** pour une vérification stricte de la clé d'hôte. Laissez ce champ vide pour qu'il soit renseigné automatiquement lors de la première connexion.
16. Sélectionnez le bouton Enregistrer : votre nouveau compte de documents est opérationnel

<Aside>Vous pouvez tester la connexion SSH avant d'enregistrer, à l'aide du bouton **Tester la connexion SSH** de l'onglet Configuration SSH.</Aside>
