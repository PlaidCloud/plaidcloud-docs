## Configuration du serveur FTP

Assurez-vous que votre administrateur de serveur FTP vous a fourni les éléments suivants :

1. L'**URL du serveur FTP** (p. ex. `ftp://ftp.yourcompany.com` ou `ftp://192.168.1.100`)
2. Un **nom d'utilisateur** ayant accès au répertoire cible
3. Un **mot de passe** pour l'authentification

<Aside>FTP transmet les identifiants et les données en clair. Pour un usage en production, envisagez plutôt SFTP, qui chiffre tout le trafic via SSH. N'utilisez FTP que pour vous connecter à des systèmes hérités qui ne prennent pas en charge SFTP.</Aside>

Vous devriez maintenant disposer de tout ce qu'il faut pour ajouter votre compte FTP à PlaidCloud Document.


## Configuration de PlaidCloud Document

1. Connectez-vous à PlaidCloud
2. Sélectionnez l'espace de travail dans lequel le nouveau compte de documents résidera
3. Accédez à `Document > Manage Accounts`
4. Cliquez sur le bouton `+ New Account`
5. Sélectionnez `FTP` comme Type de service
6. Renseignez un nom et une description
7. Saisissez l'**URL du serveur FTP** dans le champ **Chemin de départ** (p. ex. `ftp://ftp.yourcompany.com`)
8. Sélectionnez un **Modèle de sécurité** adapté à votre cas d'usage. En cas de doute, laissez `Private`.
9. Saisissez le **nom d'utilisateur** dans le champ Nom d'utilisateur sous Identifiants d'authentification
10. Saisissez le **mot de passe** dans le champ Mot de passe sous Identifiants d'authentification
11. Cliquez sur le bouton Enregistrer et votre nouveau compte de documents est actif
