## Configuration du serveur WebDAV

Assurez-vous que l'administrateur de votre serveur WebDAV vous a fourni les éléments suivants :

1. L'**URL du point de terminaison WebDAV** (par ex. `https://nextcloud.yourcompany.com/remote.php/dav/files/username/`)
2. Un **nom d'utilisateur** ayant accès au répertoire cible
3. Un **mot de passe** ou un mot de passe propre à l'application pour l'authentification

<Aside>De nombreux services cloud exposent une interface WebDAV. Par exemple, Nextcloud utilise `https://your-server/remote.php/dav/files/{username}/` et ownCloud utilise `https://your-server/remote.php/webdav/`. Consultez la documentation de votre fournisseur pour connaître l'URL correcte.</Aside>

Vous disposez maintenant de tout le nécessaire pour ajouter votre compte WebDAV à PlaidCloud Document.


## Configuration de PlaidCloud Document

1. Connectez-vous à PlaidCloud
2. Sélectionnez l'espace de travail dans lequel le nouveau compte de documents sera créé
3. Accédez à `Document > Manage`
4. Sélectionnez le bouton **Nouveau compte**
5. Sélectionnez `WebDAV` comme Type de service
6. Saisissez un nom et une description
7. Saisissez l'**URL du point de terminaison WebDAV** complète dans le champ **Chemin de départ** (par ex. `https://nextcloud.yourcompany.com/remote.php/dav/files/username/`)
8. Sélectionnez le **Modèle de sécurité** adapté à votre cas d'usage. En cas de doute, conservez `Private`.
9. Saisissez le **nom d'utilisateur** dans le champ Nom d'utilisateur, sous Identifiants d'authentification
10. Saisissez le **mot de passe** dans le champ Mot de passe, sous Identifiants d'authentification
11. Sélectionnez le bouton Enregistrer : votre nouveau compte de documents est opérationnel
