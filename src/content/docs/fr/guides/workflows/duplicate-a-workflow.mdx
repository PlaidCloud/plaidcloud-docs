Copier un workflow est utile pour préparer des modifications importantes ou reproduire un processus avec d'autres options. Les copies sont totalement indépendantes — modifier une copie n'affecte pas l'original.

Deux actions sont disponibles depuis la table **Workflows** :

* **Duplicate Selected Workflows** — copie rapide sur place, dans le même projet
* **Cloner le ou les workflows** — copie dans un projet cible de votre choix (le projet actuel par défaut)


## Duplicate Selected Workflows

1. Ouvrez la table **Workflows** du projet
2. Sélectionnez un ou plusieurs workflows
3. Cliquez sur `Duplicate Selected Workflows` dans la barre d'outils

Chaque clone est créé dans le même projet, avec « copy » ajouté à la fin du nom d'origine.


## Cloner le ou les workflows

Utilisez cette action lorsque vous voulez copier des workflows dans un autre projet — par exemple pour passer d'un projet de développement à un projet voisin.

1. Ouvrez la table **Workflows** du projet source
2. Sélectionnez un ou plusieurs workflows
3. Ouvrez le menu **Actions** et cliquez sur `Clone Workflow(s)`
4. Dans la boîte de dialogue, choisissez le **Projet cible** (le projet actuel par défaut)
5. Cliquez sur `Clone Workflow(s)`

Une boîte de dialogue de progression s'ouvre pendant le clonage, avec une barre globale (workflow N sur M) et une barre par étape pour le workflow en cours de copie. Vous pouvez cliquer sur `Run in Background` pour fermer la boîte de dialogue et continuer à travailler — le clonage se poursuit et une notification s'affiche à la fin.

Les workflows clonés ont « copy » ajouté à la fin de leur nom pour ne pas entrer en conflit avec ce qui existe déjà dans le projet cible.

<Aside>Le clonage copie la définition du workflow et la configuration de ses étapes. Les ressources propres au projet référencées par le workflow (tables, dimensions, connexions) doivent déjà exister dans le projet cible, sinon vous devez les cloner séparément.</Aside>
