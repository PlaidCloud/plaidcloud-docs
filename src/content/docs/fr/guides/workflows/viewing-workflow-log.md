## Afficher le journal du workflow


Lorsque des événements surviennent dans un workflow, par exemple l'exécution d'étapes ou l'apparition d'avertissements, ils sont consignés dans le journal du workflow. Ce journal est consultable depuis la zone **Projet**, sous l'onglet **Journal**. Le journal du workflow figure aussi dans le journal du projet si vous souhaitez une vue plus complète des journaux de plusieurs workflows.

Si vous travaillez dans le [Concepteur visuel de workflow](/fr/guides/workflows/advanced-workflows/), le bouton **Afficher les journaux** de la barre d'outils ouvre cette même vue Journal déjà filtrée sur le workflow que vous avez ouvert.



Le visualiseur de journal permet de trier et de filtrer le journal ainsi que d'afficher les détails d'une entrée de journal particulière.



## Effacer le journal du workflow


Il peut être souhaitable d'effacer le journal du workflow de temps à autre. Depuis le visualiseur de journal, sélectionnez le bouton **Effacer le journal**. Cela efface le journal en fonction du workflow sélectionné, ce qui supprime aussi les entrées correspondantes du journal au niveau du projet.
