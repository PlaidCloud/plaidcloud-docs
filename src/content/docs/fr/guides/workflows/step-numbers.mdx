Chaque étape d'un workflow porte un numéro automatique : le badge situé dans
le coin supérieur gauche de chaque étape sur le canevas visuel, la première colonne
de la grille des étapes, et le « étape 7 » que vous voyez dans les journaux d'exécution, les rapports
de documentation de workflow et les réponses de l'assistant IA. Ce numéro offre un moyen court et
sans ambiguïté de désigner une étape : « la jointure de l'étape 7 perd des lignes » fonctionne dans un message
de discussion, un ticket de support ou une instruction adressée à un agent IA.

## Comment l'ordre est déterminé

Les étapes sont numérotées selon **le flux d'abord, la position ensuite** :

1. **Le flux l'emporte toujours.** Une étape est toujours numérotée après toutes les étapes dont
   elle dépend. Si l'étape A alimente l'étape B, le numéro de A est inférieur, sans exception.
2. **La position départage les égalités.** Les étapes qui s'exécutent en parallèle (sans dépendance
   entre elles) sont ordonnées selon leur emplacement sur le canevas : de gauche à droite,
   puis de haut en bas.

Sur un canevas bien rangé, les numéros augmentent simplement à mesure que vous lisez le diagramme
de gauche à droite : utilisez le bouton de disposition automatique pour démêler un workflow importé,
et la numérotation suivra l'image.

Les workflows standard (en série) sont numérotés selon l'ordre de leurs étapes, le même
ordre que celui que la grille des étapes a toujours affiché.

## Les numéros se mettent à jour lorsque le workflow change

Les numéros d'étape sont dérivés du workflow actuel, et non stockés. Insérez une
étape, supprimez-en une, redessinez une dépendance ou faites glisser une étape parallèle de l'autre
côté du canevas, et les numéros s'ajustent, pour toute personne qui consulte le
workflow, immédiatement. Une brève surbrillance sur le badge du canevas vous montre quelles
étapes viennent de recevoir un nouveau numéro.

<Aside type="caution" title="Utilisez des noms ou des ID pour les références durables">
Comme les numéros suivent le flux, ils peuvent changer lorsque le workflow est modifié.
Ils sont parfaits pour parler du workflow tel qu'il est à l'instant, lors d'un
appel, dans un journal d'exécution que vous êtes en train de déboguer, dans une conversation avec une IA à propos du graphe
actuel. Pour les références qui doivent survivre aux modifications futures (documentation,
favoris, automatisation), utilisez le nom de l'étape ou son ID unique.
</Aside>

Les journaux d'exécution enregistrent les numéros tels qu'ils étaient au démarrage de l'exécution ; le
journal d'une exécution correspond donc toujours à ce que le canevas affichait à ce moment-là, même si le workflow
a été modifié ensuite.

## Copier la référence d'une étape

Faites un clic droit sur une étape du canevas et choisissez **Copier la référence de l'étape** (ou cliquez sur
le badge de numéro lui-même) pour copier une référence prête à coller, comme
`Step 7 — Clean Customer Names`. Coller le numéro *et* le nom garantit que la
référence identifie toujours l'étape même si la numérotation change par la suite.

## Numéros d'étape et agents IA

Les assistants IA connectés via MCP voient les mêmes numéros que vous :
`workflow_describe` liste les étapes d'un workflow avec leur `step_number` dans
l'ordre numérique, de sorte que vous pouvez dire à un agent « regarde l'étape 7 » et il retrouvera
la même étape que celle que vous consultez. Les numéros sont purement informatifs : aucun outil
n'accepte un numéro d'étape en entrée, un agent agit donc toujours sur l'ID stable de l'étape après avoir résolu le numéro.

## Où le même numéro apparaît

- Le badge sur chaque étape du canevas (survolez-le pour voir la règle d'ordre).
- La première colonne de la grille des étapes du workflow.
- L'en-tête de l'Inspecteur ancré et l'historique d'exécution par étape.
- Les journaux d'exécution : `Step 7 — Clean Customer Names: started`. Les étapes désactivées sont
  consignées comme ignorées avec leur numéro, de sorte que la séquence n'a jamais de trous silencieux.
- Le rapport de documentation du workflow : table récapitulative, sections par étape et
  diagrammes.
- La colonne Numéro d'étape de l'aperçu des dépendances de tables.
- Les listes d'étapes de l'assistant IA / MCP.

<Aside type="note">
Dans les workflows avancés (visuels), la grille des étapes liste les lignes dans l'ordre des
numéros d'étape, et les boutons Monter / Descendre / Déplacer de la grille sont désactivés :
organisez plutôt le flux sur le canevas ; les numéros suivent votre disposition.
</Aside>
