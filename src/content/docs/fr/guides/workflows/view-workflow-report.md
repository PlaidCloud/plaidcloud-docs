Maintenir une documentation détaillée pour répondre aux exigences statutaires comme de gestion est difficile lorsque les projets et les workflows sont dynamiques. Pour résoudre ce problème, PlaidCloud fournit un rapport au niveau du workflow qui documente en détail les workflows, les étapes de workflow, les fonctions définies par l'utilisateur et les variables.



Le rapport est généré à la demande et reflète l'état actuel du workflow. Pour télécharger le rapport, cliquez sur l'icône Rapport dans la hiérarchie **Workflows**.
