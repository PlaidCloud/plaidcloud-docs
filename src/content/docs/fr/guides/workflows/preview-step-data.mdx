## Description

Le **tiroir d'aperçu des données** affiche la table d'entrée ou de sortie d'une étape directement dans le [Concepteur visuel de workflow](/fr/guides/workflows/advanced-workflows/) : une grille en lecture seule des **100 premières lignes**, avec des colonnes typées et triables, ancrée en bas du canevas. Il est conçu pour les coups d'œil rapides entre deux modifications : cliquez sur n'importe quelle table d'entrée ou de sortie pour la consulter, vérifiez qu'une jointure a produit les colonnes attendues, confirmez qu'un filtre a bien filtré, puis continuez à construire, sans ouvrir une fenêtre complète de l'explorateur de tables à chaque fois.

<Aside type="note">Le tiroir prévisualise des données qui existent déjà. Si l'étape n'a pas encore produit sa table de sortie, le tiroir affiche *« Aucune donnée pour l'instant : exécutez l'étape pour générer cette table »*. Exécutez l'étape et l'aperçu se remplit.</Aside>

## Ouvrir l'aperçu

Il existe quatre accès, qui mènent tous au même tiroir :

- **Survolez la vignette de l'étape** : un petit pictogramme de navigation (table) apparaît en fondu dans le coin inférieur droit de la vignette. Cliquez dessus.
- **Faites un clic droit sur l'étape** et choisissez **Prévisualiser les données de sortie**.
- **Dans l'inspecteur**, cliquez sur l'**icône en forme d'œil** de n'importe quelle carte de la section **Entrées** ou **Sorties** de l'étape pour prévisualiser cette table.
- **Sur la vignette de l'étape**, cliquez sur une icône de table dans la bande **Entrées** ou **Sorties** de la vignette. (Les icônes de dimension ouvrent toujours la dimension, et les icônes de fichier téléchargent toujours le fichier.)

Le tiroir s'ancre sous le canevas. Si vous avez cliqué sur une table précise, il affiche cette table ; sinon, il charge la première table de sortie de l'étape.

## Passer d'une étape à l'autre

Tant que le tiroir est ouvert, **un clic sur une autre étape redirige l'aperçu** vers la sortie de cette étape, en un seul clic par étape. Parcourez une chaîne d'étapes en cliquant sur chacune à tour de rôle et observez la forme des données évoluer à chaque stade.

Pour fermer le tiroir, cliquez sur **✕** dans son en-tête ou appuyez sur **Échap**. (Si une étape est sélectionnée, le premier appui sur Échap ferme le tiroir et le suivant efface la sélection.)

## L'en-tête du tiroir

L'en-tête précise ce que vous êtes en train de voir :

- **Nom de la table** et **Affichage des N premières lignes sur ~M** : le tilde apparaît lorsque le moteur indique le total de façon approximative.
- **Nombre de colonnes**.
- **Sélecteur de table** : choisissez la table à prévisualiser. Une étape qui écrit plusieurs tables liste chaque sortie, la première étant présélectionnée. Lorsque vous avez prévisualisé une entrée, elle apparaît en tête de liste, avant les sorties, et est présélectionnée ; passez de là à n'importe quelle sortie.
- **Actualiser** : recharge l'aperçu à la demande.
- **Ouvrir dans l'explorateur de tables** : bascule en un clic vers l'explorateur complet pour la table affichée dans le tiroir (voir ci-dessous).
- **✕** : ferme le tiroir.

## À jour après chaque exécution

Si l'étape que vous prévisualisez s'exécute alors que le tiroir est ouvert, l'aperçu **s'actualise automatiquement une fois à la fin de l'exécution** : après un Exécuter cette étape, le tiroir affiche donc déjà les nouvelles données, sur la même table que celle que vous consultiez, y compris une entrée. Revenir à une étape dont la sortie n'a pas changé rouvre son aperçu sans nouveau chargement.

## Pour aller plus loin : l'explorateur de tables

L'aperçu est volontairement un simple coup d'œil, pas un établi : ni modification, ni filtrage, ni téléchargement. Quand vous en avez besoin, cliquez sur **Ouvrir dans l'explorateur de tables** dans l'en-tête du tiroir pour ouvrir la même table dans l'[explorateur de tables](/fr/guides/data/table-explorer/) complet, avec toutes ses fonctionnalités.

Deux cas où ce bouton vous sera utile :

- **Tables larges** : le tiroir affiche les **150 premières colonnes** et indique que le reste est disponible dans l'explorateur de tables.
- **Analyses approfondies** : tout ce qui dépasse les 100 premières lignes, ou tout découpage et filtrage.

## Ce qu'affiche le tiroir quand il n'y a rien à montrer

- **Cette étape n'a aucune table de sortie** : l'étape écrit des fichiers ou des dimensions plutôt que des tables, et vous avez ouvert l'aperçu sans cliquer sur une table. Un clic sur une table d'entrée continue de la prévisualiser.
- **Aucune donnée pour l'instant : exécutez l'étape pour générer cette table** : la table de sortie n'a pas encore été créée. Exécutez l'étape.
- **La table est vide** : la table existe mais ne contient aucune ligne.
