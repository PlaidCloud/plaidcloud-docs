Pendant le développement initial d'un workflow, les tests ou le dépannage, il est souvent utile d'exécuter les étapes individuellement. Pour exécuter une seule étape de façon isolée, faites un clic droit sur l'étape et sélectionnez **Exécuter l'étape** dans le menu contextuel.
