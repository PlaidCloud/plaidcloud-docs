PlaidCloud permet d'organiser et de gérer les hiérarchies, y compris leurs étiquettes. Les hiérarchies sont disponibles pour tous les workflows d'un projet.

PlaidCloud utilise un système basé sur des chemins pour organiser les hiérarchies, comme vous le feriez pour naviguer dans une série de dossiers, ce qui permet une organisation plus souple et plus logique (hiérarchie de contrôle) des hiérarchies. Avec ce système, les hiérarchies peuvent être déplacées dans une hiérarchie de contrôle, ou il est possible de créer plusieurs références vers une même hiérarchie depuis différents emplacements de la hiérarchie de contrôle (hiérarchies alternatives). La gestion des hiérarchies selon cette méthode permet à la structure de refléter les besoins opérationnels, le reporting et le contrôle.

## Recherche

Pour rechercher des hiérarchies :

1. Utilisez la zone de filtre en bas à gauche de la hiérarchie de contrôle
2. Le filtre de recherche recherche des correspondances dans les noms et les étiquettes des hiérarchies et affiche les résultats dans la hiérarchie de contrôle au-dessus

## Déplacer

Pour déplacer une hiérarchie dans la hiérarchie de contrôle :

1. Faites-la glisser dans le dossier où vous souhaitez la placer

## Renommer

Pour renommer une hiérarchie :

1. Faites un clic droit sur la hiérarchie
2. Sélectionnez l'option de renommage
3. Saisissez le nouveau nom et enregistrez
4. La hiérarchie est alors renommée, mais elle conserve son identifiant unique d'origine

## Effacer

Vous pouvez effacer une seule hiérarchie ou plusieurs.

Pour effacer une hiérarchie :

1. Sélectionnez les hiérarchies dans la hiérarchie de contrôle
2. Cliquez sur le bouton d'effacement dans la barre d'outils supérieure

## Supprimer

### Vous pouvez supprimer une seule hiérarchie ou plusieurs

Pour supprimer une hiérarchie :

1. Sélectionnez les hiérarchies dans la hiérarchie de contrôle
2. Cliquez sur le bouton de suppression dans la barre d'outils supérieure

L'opération de suppression vérifie si la hiérarchie est utilisée par des étapes de workflow, des tables ou des vues. Si c'est le cas, il vous est demandé de supprimer ces associations.

<Aside>Vous pouvez aussi forcer la suppression de la ou des hiérarchies. La suppression forcée laisse des références rompues ; elle doit donc être utilisée avec parcimonie.</Aside>

## Créer une nouvelle structure de répertoires

Pour créer un nouveau dossier :

1. Cliquez sur le bouton Nouveau dossier de la barre d'outils

Pour ajouter un dossier à un dossier existant :

1. Faites un clic droit sur le dossier
2. Sélectionnez Nouveau dossier.

## Marquer la hiérarchie pour les rôles de consultation

Pour consulter les hiérarchies par rôle :

1. Cliquez dans les cases à cocher Explorateur ou Gestionnaire

Pour consulter les hiérarchies qui doivent être mises à jour :

1. Sélectionnez les hiérarchies dans la hiérarchie de contrôle
2. Sélectionnez le rôle de consultation souhaité dans le menu Actions de la barre d'outils supérieure

## Mémos pour décrire le contenu des tables

Pour ajouter un mémo à une hiérarchie :

1. Sélectionnez la hiérarchie
2. Mettez à jour le mémo dans le formulaire de contexte à droite

## Afficher les attributs supplémentaires de la hiérarchie

Pour afficher et modifier les attributs supplémentaires d'une hiérarchie :

1. Sélectionnez une hiérarchie
2. Consultez le formulaire de contexte de la hiérarchie à droite

## Dupliquer une hiérarchie

Pour dupliquer une hiérarchie :

1. Sélectionnez la hiérarchie

2. Cliquez sur le bouton de duplication dans la barre d'outils supérieure
