Les tables d'un projet partagent souvent des noms de colonnes : `Period`, `Org`, `Account`. Un **élément de projet** décrit l'un de ces noms une seule fois, pour l'ensemble du projet. Chaque table qui comporte une colonne de ce nom affiche alors la même description, le même masque et la même dimension, ce qui vous évite de ressaisir le même mémo sur des dizaines de tables.

La page **Modèle de données** de l'[accueil du projet](/fr/guides/projects/project-home/) liste les éléments d'un projet, indique quelles tables partagent chacun d'eux et signale les écarts entre les tables.

## Contenu d'un élément

| Paramètre | Rôle |
|---|---|
| **Nom** | Le nom de colonne que l'élément décrit, écrit exactement comme dans les colonnes. |
| **Description** | Ce que contient la colonne. Les colonnes qui n'ont pas de mémo propre affichent celle-ci. |
| **Type** | Le type de données attendu par le projet pour cette colonne. Il est contrôlé, pas appliqué. Consultez [Conflits de type](#conflits-de-type). |
| **Masque** | Un masque numérique. Les colonnes qui n'ont pas de masque propre utilisent celui-ci. |
| **Dimension** | Une dimension dont proviennent les valeurs de la colonne. Les colonnes qui n'ont pas de dimension propre utilisent celle-ci. |
| **Alias** | Les autres noms de colonne qui ont le même sens. |

## Comment une colonne obtient un élément

Une colonne est liée à un élément lorsque son ID de colonne est identique au nom de l'élément ou à l'un de ses alias. La correspondance est exacte : `period` et `Period` sont deux noms différents ; ajoutez donc `period` comme alias de `Period` si vous voulez les deux.

Ajoutez ou supprimez un élément, et chaque colonne correspondante suit.

## Ce qu'une colonne reprend de son élément

Une colonne liée reprend la **Description**, le **Masque** et la **Dimension** de l'élément partout où sa propre valeur est vide. Une valeur que vous définissez sur la colonne elle-même l'emporte toujours. L'élément ne modifie jamais ce qui est stocké sur une table : supprimez-le et chaque colonne retrouve exactement ce qu'elle avait.

Le **Type** n'est pas repris de l'élément.

## Ouvrir la page Modèle de données

Ouvrez le projet, puis choisissez **Modèle de données** dans le rail de l'[accueil du projet](/fr/guides/projects/project-home/). La pastille du rail indique le nombre d'éléments du projet. Vous pouvez aussi ouvrir la page depuis une colonne :

- Dans l'Explorateur de tables, activez **Propriétés de la colonne** et sélectionnez une colonne. La ligne **Élément** indique l'élément de la colonne, ou, si elle n'en a pas et que vous pouvez modifier le projet, **En faire un élément**. Cliquez dessus pour ouvrir la page Modèle de données sur cet élément, ou sur un nouvel élément qui reprend la description, le masque et la dimension propres à la colonne.
- Dans la liste de ce qui utilise une dimension, une ligne nommée **Élément de projet** ouvre la page Modèle de données.

Toute personne qui peut ouvrir le projet peut voir la page. Pour créer, modifier ou supprimer des éléments, vous avez besoin d'un accès en écriture au projet, et le projet ne doit pas être verrouillé. Sinon, la page affiche « Vous pouvez consulter le modèle de données ici, mais pas le modifier. »

## Créer un élément

1. Sur la page **Modèle de données**, cliquez sur **Nouvel élément**.
2. Saisissez un **Nom**. Renseignez **Description**, **Type**, **Masque** et **Dimension** selon vos besoins. Laissez **Type** sur **N'importe quel type** pour accepter n'importe quel type.
3. Dans **Alias**, saisissez les autres noms de colonne qui ont le même sens, un par ligne.
4. Cliquez sur **Enregistrer**.

Un élément ne peut pas prendre un nom ou un alias déjà utilisé par un autre élément. Pour modifier un élément, cliquez sur le crayon (**Modifier l'élément**) à côté de celui-ci. Si vous le renommez, l'ancien nom reste comme alias, de sorte que ses colonnes gardent l'élément.

Pour en supprimer un, ouvrez-le et cliquez sur **Supprimer**, puis confirmez avec **Supprimer l'élément**. La confirmation indique combien de tables y sont liées. Rien de ce qui est stocké sur ces tables ne change.

### Éléments suggérés

Sous **Suggéré**, la page liste les noms de colonnes qui méritent de devenir des éléments :

- Un nom qui n'est pas encore un élément ni un alias et qui figure dans au moins deux tables, lorsque le type de la colonne peut servir de clé de jointure (un type inconnu compte), affiché sous la forme « *name* est dans *n* tables ». Cliquez sur **Créer un élément** pour le créer.
- Un nom qui correspond au nom ou à un alias d'un élément, sans tenir compte de la casse ni des tirets bas, même s'il ne figure que dans une table, affiché sous la forme « *name* ressemble à *element* (*n* tables) ». Cliquez sur **Ajouter un alias** pour lier ses colonnes à cet élément.

## Lire le modèle de données

Le commutateur **Graphe** et **Matrice** au-dessus du canevas présente les mêmes tables et éléments de deux façons.

- **Graphe.** Chaque élément est un pivot, et chaque table est une carte reliée aux éléments pour lesquels elle a une colonne. Un **1** sur une ligne marque une colonne qui est l'unique clé de la table. Une table dont la clé combine plusieurs colonnes n'est pas marquée. La page s'ouvre sur un élément et ses tables. Cliquez sur un élément pour vous concentrer sur lui, cliquez sur une table pour vous concentrer sur cette table, ou double-cliquez sur une table pour l'ouvrir. Les pastilles à côté de **Masquer les éléments** masquent ou affichent les éléments que vous ne voulez pas dans le dessin.
- **Matrice.** Une ligne par table et une colonne par élément. Utilisez **Filtrer par nom de table** pour réduire les lignes.

### Conflits de type

Une table dont une colonne a un type différent de celui des autres est signalée sous l'élément : « *column* est *type* dans *table*, ce qui diffère des autres tables. » Les types sont comparés par famille : un entier et un décimal ne sont donc pas en conflit. Si l'élément a un **Type**, les autres sont comparés à sa famille. Sinon, ils sont comparés à la famille que la plupart des colonnes utilisent, et lorsque deux familles sont à égalité, celle qui vient en premier par ordre alphabétique est retenue. Un conflit n'est qu'un avertissement ; il ne change rien.

Une table qui ne peut pas être lue est exclue et comptabilisée sur la page, au lieu de l'interrompre.

## Où voir les éléments

Les éléments s'affichent sous forme de pastille portant le nom de l'élément :

- **Explorateur de tables.** La liste des colonnes comporte une colonne **Repères** avec la pastille, à côté des pastilles **Dimension** et **Accès aux lignes**. Survolez la pastille pour voir l'élément, sa description et sa dimension.
- **Propriétés de la colonne.** La ligne **Élément** ouvre l'élément. Lorsque **Description**, **Masque** ou **Dimension** est vide, le champ affiche « De l'élément *name* : *value* » comme indication. L'indication n'est pas enregistrée avec la colonne.
- **Onglet Data Mapping d'une étape.** Les colonnes source et cible qui appartiennent à un élément affichent sa pastille après le nom de la colonne.

## Utiliser les éléments depuis l'API REST et MCP

L'API REST lit et modifie les éléments à l'adresse `/rest/v1/analyze/projects/{project_id}/elements` :

| Requête | Effet |
|---|---|
| `GET` | Renvoie `elements`, et `index`, qui associe le nom de chaque colonne liée au nom de son élément. |
| `PUT` | Crée ou remplace un élément à partir de `name`, `memo`, `dtype`, `mask`, `dimension` et `aliases`. Ajoutez `rename_from` pour en renommer un. |
| `DELETE` avec `?name=` | Supprime l'élément nommé. |
| `GET` `/graph` | Renvoie ce qu'affiche la page Modèle de données : chaque élément avec son nombre de tables et ses conflits de type, les colonnes liées de chaque table, et les suggestions. |

Les métadonnées d'une table renvoient les valeurs stockées sur chaque colonne, et non celles qu'elle reprend d'un élément. Pour savoir de quel élément une colonne reprend ses valeurs, recherchez son nom dans l'`index` renvoyé par `GET` elements.

Un assistant connecté via [MCP](/fr/integrations/ai-coding-agents/getting-started/) utilise `element_find`, `element_upsert` et `element_delete`. Ses descriptions de table affichent le mémo de chaque colonne, complété par la valeur de l'élément lorsque la colonne n'en a pas.
