Les fenêtres Analyze s'ouvrent les unes par-dessus les autres — un workflow dans un projet, une étape dans ce workflow, une table ouverte pour vérifier un résultat. Deux fonctionnalités facilitent le repérage et le retour en arrière : un **fil d'Ariane** dans le titre de chaque fenêtre, et une **URL qui suit ce que vous consultez**, de sorte que n'importe quelle vue peut être mise en favori ou transmise à un collègue.

## Le fil d'Ariane

Les fenêtres qui appartiennent à un projet affichent leur ascendance comme titre, dans la barre de titre de la fenêtre :

```
My Project › Workflow › Nightly Load
```

Chaque partie est appelée un segment, et ils se lisent de gauche à droite, du conteneur le plus externe vers l'intérieur :

1. **Le projet** — le projet qui contient ce que vous consultez.
2. **Le type d'objet** — Workflow, Table, Étape, Dimension ou Éditeur de données.
3. **L'objet lui-même** — le workflow, la table, l'étape, etc. en cours. Ce dernier segment est l'endroit où vous vous trouvez déjà ; il n'est donc pas cliquable.

### Naviguer avec le fil d'Ariane

Sélectionnez l'un des deux premiers segments pour remonter :

| Segment | Info-bulle | Action |
|---|---|---|
| Le nom du projet | Ouvrir le projet | Ouvre ce projet, ou le place au premier plan s'il est déjà ouvert |
| Workflow | Afficher tous les workflows | Ouvre le projet sur sa liste de workflows |
| Table | Afficher toutes les tables | Ouvre le projet sur sa liste de tables |
| Étape | Afficher toutes les étapes | Ouvre le projet sur sa liste d'étapes |
| Dimension | Afficher toutes les dimensions | Ouvre le projet sur sa liste de dimensions |
| Éditeur de données | Afficher tous les éditeurs de données | Ouvre le projet sur sa liste d'éditeurs de données |

Le segment de type est le moyen rapide d'atteindre un élément du même niveau : depuis un workflow, un clic vous place sur la liste complète des workflows du même projet, prête à en ouvrir un autre.

<Aside type="note">
La fenêtre d'où vous venez reste ouverte. Naviguer avec un fil d'Ariane place le projet au premier plan — cela ne ferme pas ce que vous consultiez, et vous pouvez y revenir depuis la barre d'onglets en bas de l'écran.
</Aside>

### Où apparaissent les fils d'Ariane

- Fenêtres **Workflow** — la grille d'étapes d'un workflow standard
- **Concepteur visuel de workflow** — la vue canevas d'un workflow avancé
- **Explorateur de tables**
- Fenêtres **Étape** ouvertes seules
- Fenêtres de hiérarchie de **Dimension**
- Fenêtres **Éditeur de données**

Une étape peut appartenir à plusieurs workflows ; le fil d'Ariane d'une étape affiche donc `Project › Step › name` plutôt que de nommer un seul workflow propriétaire.

### Accès au clavier et aux lecteurs d'écran

Les segments cliquables sont des contrôles ordinaires : **Tabulation** s'y déplace et **Entrée** ou **Espace** active celui qui a le focus, de sorte que vous n'avez jamais besoin de la souris pour remonter dans la hiérarchie. Chacun est annoncé comme un bouton, le dernier segment est annoncé comme la page courante, et les séparateurs `›` sont ignorés au lieu d'être lus à voix haute.

### Quitter un éditeur de données avec des modifications non enregistrées

L'éditeur de données est la seule fenêtre qui demande confirmation avant qu'un fil d'Ariane vous en éloigne. Si des modifications sont en cours, la sélection d'un segment affiche l'invite **Modifications non enregistrées** — *Fermer l'éditeur de données sans enregistrer les modifications ?* — avec **Fermer l'éditeur** pour quitter malgré tout. Annulez l'invite et vous restez dans l'éditeur avec vos modifications intactes.

C'est la même invite que celle du bouton **Fermer** de l'éditeur ; il n'existe donc aucun moyen de quitter un éditeur de données en abandonnant le travail sans demander confirmation.

## Liens partageables

La barre d'adresse nomme toujours la fenêtre au premier plan. Ouvrez un workflow et l'URL devient le lien de ce workflow ; ouvrez une table et elle devient celui de la table. Ce lien est l'unité que vous partagez.

**Pour partager ce que vous consultez**, copiez l'URL depuis la barre d'adresse du navigateur et envoyez-la. Toute personne ayant accès à ce projet ouvre la même vue. Mettez-la en favori et elle fonctionnera encore plus tard.

### Ce qui se passe quand quelqu'un ouvre le lien

L'ouverture ou l'actualisation d'un lien restaure le **contexte parent**, pas seulement la fenêtre concernée. Un lien vers un workflow rouvre aussi son projet, de sorte que vous arrivez avec le projet disponible dans la barre d'onglets plutôt qu'avec une seule fenêtre isolée — au même endroit que si vous y aviez navigué vous-même.

### Formats de lien

Les liens commencent par le projet : le projet vient en premier, puis l'objet qu'il contient, séparés par `~`.

```
#p~my-project                        a project
#p~my-project~w~<workflow>           a standard workflow
#p~my-project~c~<workflow>           a workflow in the Visual Workflow Designer
#p~my-project~w~<workflow>~s~<step>  a step within a workflow
#p~my-project~t~<table>              a table in the Table Explorer
#p~my-project~d~<dimension>          a dimension hierarchy
#p~my-project~e~<editor>             a Data Editor
#home                                the Home landing page
```

Lorsqu'un projet a un nom de schéma, le lien l'utilise (`my-project` ci-dessus), ce qui rend le lien lisible et stable. Sinon, l'identifiant du projet est utilisé. Les deux formes ouvrent le même projet.

<Aside type="note">
Les liens créés avant le format commençant par le projet fonctionnent toujours. Les anciens liens de style `?p=…&t=…` continuent d'ouvrir la bonne vue, et la barre d'adresse se met à jour vers le format actuel à votre première navigation.
</Aside>

### Quand un lien ne peut pas être ouvert

Si l'objet d'un lien a été supprimé depuis, ou si vous n'avez pas accès à son projet, le lien ouvre l'application sans cette vue au lieu d'échouer. La fermeture d'une fenêtre dont le lien se trouve dans la barre d'adresse ramène l'URL au projet propriétaire, de sorte que la barre d'adresse ne pointe jamais vers quelque chose qui n'est plus ouvert.
