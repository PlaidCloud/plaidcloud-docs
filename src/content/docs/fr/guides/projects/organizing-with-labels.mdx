## Description

Les **libellés** sont des étiquettes libres que vous associez aux objets d'un projet : le projet lui-même, ses workflows, étapes, tables, dimensions, éditeurs de données et fonctions définies par l'utilisateur. Utilisez-les pour regrouper des éléments liés selon ce qui compte pour vous (une phase de travail, un système source, un responsable, une version), puis retrouver rapidement ces éléments.

Les libellés sont stockés en minuscules et affichés sous forme de petites pastilles partout où l'objet apparaît ; un jeu de libellés cohérent devient ainsi un moyen léger de segmenter un projet volumineux.

## Où gérer les libellés

Chaque objet pouvant être étiqueté dispose d'une zone **Libellés** dans son panneau de détails :

- **Étiquettes du projet** : dans l'accueil du projet
- **Étiquettes du workflow**, **Étiquettes de l'étape**, **Étiquettes de la table**, **Étiquettes de la dimension**, **Étiquettes de l'éditeur de données** et **Étiquettes de l'UDF** : dans le panneau de détails de l'élément correspondant
- **Libellés** : dans l'onglet **Général** du formulaire d'une étape de workflow

La zone liste les libellés actuels de l'objet sous forme de pastilles et fournit un champ pour en ajouter d'autres, avec un bouton **Ajouter** à côté du champ.

## Ajout d'un libellé

1. Cliquez n'importe où dans la zone **Libellés** pour placer le curseur dans le champ de saisie.
2. Saisissez le texte du libellé.
3. Cliquez sur **Ajouter**, ou appuyez sur **Entrée** (ou saisissez une virgule), pour l'ajouter.

Le nouveau libellé apparaît sous forme de pastille et le champ de saisie se vide pour que vous puissiez en ajouter un autre. Les pastilles passent sur plusieurs lignes à mesure que vous ajoutez des libellés, de sorte que rien n'est masqué.

<Aside type="note">
Les libellés sont automatiquement convertis en minuscules. Si le libellé que vous saisissez est déjà associé à cet objet, PlaidCloud vous le signale et n'ajoute pas de doublon.
</Aside>

<Aside type="note">
Sur une étape de workflow que vous créez pour la première fois, les libellés que vous saisissez sont conservés jusqu'à l'enregistrement de l'étape, puis lui sont associés. Chacune des autres zones **Libellés** enregistre chaque libellé dès que vous l'ajoutez.
</Aside>

## Suppression d'un libellé

- Cliquez sur le **×** d'une pastille pour supprimer ce libellé, ou
- Le champ de saisie étant vide, appuyez sur **Retour arrière** pour supprimer la dernière pastille.

## Recherche d'éléments par libellé

Les libellés apparaissent sous forme de pastilles dans la colonne **Libellés** des listes du projet : workflows, étapes, tables, etc. Pour restreindre une liste aux éléments portant un libellé donné, saisissez ce libellé dans la zone de filtre de la liste ; la recherche porte sur le texte des libellés ainsi que sur le nom de l'élément. Survolez une pastille trop longue pour sa colonne afin d'afficher le libellé complet.
