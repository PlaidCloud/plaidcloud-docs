## Description

**Accueil du projet** est votre point de départ dans un projet. Un rail à gauche liste six pages : **Vue d'ensemble**, **Variables**, **Planifications et capteurs**, **Accès et partage**, **Données et connexions** et **Applications et image de marque**. Vue d'ensemble résume le projet. Les cinq autres pages servent à modifier les paramètres du projet.

Le badge **Variables** du rail indique le nombre de variables du projet. Le badge **Planifications et capteurs** indique le nombre de planifications et de capteurs actifs.

Un projet verrouillé est en lecture seule. Ses pages affichent une bannière qui indique « Ce projet est verrouillé et donc en lecture seule. Déverrouillez-le dans Vue d'ensemble pour apporter des modifications. » et leurs commandes sont désactivées.

## Vue d'ensemble

![Page Vue d'ensemble de l'accueil du projet montrant le nom du projet, six tuiles, Coming up et les paramètres par défaut du projet](/images/projects/project-home-overview.png)

Le haut de la page affiche le nom du projet et indique s'il est **Modifiable** ou en **Lecture seule**.

- **Description.** Cliquez sur le crayon pour modifier la description directement. Appuyez sur Entrée pour enregistrer, ou sur Échap pour annuler.
- **Libellés.** Saisissez un libellé dans **Ajouter une étiquette…** et cliquez sur **Ajouter**. Voir [Organiser le travail avec des libellés](/fr/guides/projects/organizing-with-labels/).
- **Verrouiller** et **Déverrouiller** font passer le projet de modifiable à lecture seule.

Les tuiles comptent ce que contient le projet :

| Tuile | Affiche |
|---|---|
| **Tables** | Les tables du projet. |
| **Workflows** | Les workflows du projet. |
| **Étapes** | Les étapes de tous les workflows. |
| **Variables** | Les variables du projet. |
| **Tables publiées** | Les tables que vous avez publiées. |
| **Taille des données** | Ce que stockent les tables du projet. Cliquez dessus pour ouvrir **Stockage**. Voir [Gérer le stockage](/fr/guides/projects/managing-storage/). |

Si certaines lignes du projet sont filtrées pour vous, **Taille des données** affiche un tiret, car le total ne serait pas exact.

**Coming up** liste les trois prochaines exécutions planifiées avec le nom de leur workflow, ainsi que le nombre de capteurs actifs. **View schedules ›** ouvre **Planifications et capteurs**.

**Project defaults** affiche les valeurs **Environnement**, **Stockage des tables**, **Accès** et **Écriture ERP** que les workflows et les étapes utilisent, sauf s'ils définissent les leurs. **Change settings ›** ouvre la page où vous les modifiez.

Les boutons de l'en-tête sont les suivants :

- **Rapport du projet** produit un rapport du projet sous forme de **Document PDF** ou de **HTML interactif**.
- **Exporter l'archive** enregistre le projet sous forme d'archive.
- **Actualiser** recharge les tuiles et les listes de la page.

## Variables

La page **Variables** liste les variables du projet dans une grille. Un workflow ou une étape fait référence à une variable par son nom sous la forme `{name}`, et la variable propre à un workflow remplace une variable de projet du même nom.

La grille affiche **Nom**, **Valeur**, **Mémo**, **Dernière mise à jour** et **Par**. Utilisez **Filtre** pour restreindre la liste, **Nouvelle variable** pour en ajouter une, et **Modifier** ou **Supprimer** pour la ligne sélectionnée.

## Planifications et capteurs

![Page Planifications et capteurs avec une bande récapitulative et deux grilles](/images/projects/project-home-schedules.png)

Cette page montre ce qui démarre automatiquement les workflows du projet. Une bande récapitulative indique la prochaine exécution, le nombre de planifications actives et suspendues, et le nombre de capteurs actifs.

- Les **Schedules** exécutent un workflow selon un calendrier. La grille affiche **Nom**, **Workflow**, **Exécutions** (le calendrier et son fuseau horaire), **Prochaine exécution** et **Statut**.
- Les **Capteurs** exécutent un workflow à l'arrivée de nouvelles données. La grille affiche **Nom**, **Watches**, **Début** (le workflow), **Last triggered** et **Statut**.

**Statut** vaut **Actif**, **Paused** ou, pour un capteur qui rencontre un problème, **Failing**. Chaque grille propose **New schedule** ou **Nouveau capteur**, **Modifier**, **Supprimer** et **Filtre**. Ouvrez **Actions** pour **Activate** ou **Deactivate** la ligne sélectionnée.

**Calendar view** affiche les prochaines exécutions dans un calendrier, ce qui vous permet de repérer les conflits de planification.

## Accès et partage

Cette page définit qui peut accéder au projet et à ses données.

- **Project access** définit **Who can open this project** : **Tous les membres de l'espace de travail**, **Groupes de sécurité spécifiques uniquement** ou **Membres spécifiques uniquement**. **Edit groups ›** et **Edit members ›** ouvrent les listes dans lesquelles choisir.
- **Dashboard audience** définit le **Default audience for new dashboards** : tous les membres du projet, ou des groupes spécifiques. Chaque tableau de bord peut modifier son propre public. Voir [Contrôler qui peut voir un tableau de bord](/fr/guides/dashboards/control-who-can-see-a-dashboard/).
- **Partages de données** liste les projets qui peuvent lire des tables de celui-ci. Voir [Partager des données entre projets](/fr/guides/projects/managing-projects/#partager-des-données-entre-projets).

## Données et connexions

![Page Données et connexions avec les connexions, le stockage des tables et l'écriture ERP](/images/projects/project-home-data.png)

Ces paramètres s'appliquent à chaque workflow et à chaque étape du projet, sauf si un workflow ou une étape définit les siens.

- **Environnement de connexion** choisit les identifiants qu'une étape utilise lorsqu'elle n'en choisit pas. La page vous avertit lorsqu'une connexion du projet n'a aucune configuration pour l'environnement sélectionné.
- **Compte de documents par défaut** choisit où les étapes lisent et écrivent les fichiers.
- **Stockage de table par défaut** choisit où les nouvelles tables sont créées.
- **Time travel retention** définit pendant combien de jours les versions antérieures des données de table sont conservées. Les tables qui héritent de ce paramètre conservent aussi un historique plus long. Un historique déjà expiré ne peut pas être récupéré.
- **Mode de comptabilisation** définit comment le projet envoie les écritures de journal aux ERP connectés. C'est un plafond pour le projet : l'exécution d'un workflow ne peut pas comptabiliser de façon plus permissive que ce paramètre. **Réel** comptabilise normalement. **Simuler** construit et valide, mais ne comptabilise jamais et ne contacte jamais l'ERP. **Désactivé** ignore les étapes de comptabilisation.
- **Write authorizations** indique combien de connexions ERP sont autorisées pour la comptabilisation. Les administrateurs peuvent cliquer sur **Manage authorizations ›**.

## Applications et image de marque

Cette page couvre les applications créées à partir des données du projet.

- **Applications Panel** indique combien d'applications sont créées sur le projet. **Open Panel apps ›** les ouvre, et **Nouvelle application Studio** en démarre une.
- **Branding** définit le logo et les couleurs que les applications du projet utilisent. **Edit branding ›** ouvre les paramètres.
- **Home tile image** est l'image affichée sur la tuile du projet dans la page d'accueil. Cliquez sur **Choisir…** pour sélectionner une image, ou sur **Effacer** pour la supprimer.
