## Description

La console **Support** est l'endroit où les agents du support traitent les tickets des clients. Le personnel PlaidCloud voit les tickets de tous les tenants ; un agent partenaire ne voit que les espaces de travail qui lui ont été attribués (consultez [Gérer le support](/fr/guides/support/managing-support/)). Si vous avez un accès au support, un élément **Support** apparaît dans la navigation de gauche.

## Traiter la file

La console s'ouvre sur une liste de tickets triée et filtrable. Des onglets de vues enregistrées en haut de la liste permettent de la restreindre :

- **Actif** — tout ce qui nécessite encore de l'attention
- **Non attribué** — les tickets que personne n'a pris en charge
- **Mes tickets** — les tickets que vous avez pris en charge
- **Needs response** — un client attend une réponse
- **Awaiting customer** — vous avez répondu ; vous attendez le client
- **Urgent** — les tickets à haute priorité
- **Snoozed**
- **Resolved**

La liste est triée par priorité, puis par durée d'attente du client, afin que le travail le plus pressant figure en haut. Utilisez la zone de recherche pour filtrer par texte ; le personnel PlaidCloud peut aussi se limiter à un seul espace de travail.

## Ouvrir et lire un ticket

Cliquez sur une ligne pour ouvrir le fil du ticket. L'en-tête indique l'espace de travail, le statut et la personne qui l'a pris en charge, le cas échéant. Le fil affiche chaque message avec son expéditeur ; les **notes internes** sont visibles des agents (en surbrillance) mais jamais du client. Les pièces jointes s'affichent directement pour les images, avec un lien de téléchargement pour les autres fichiers.

## Prendre un ticket en charge

La prise en charge signale que vous traitez un ticket et le place dans votre vue **Mes tickets**.

1. Ouvrez le ticket
2. Cliquez sur `Claim` (cliquez sur `Unclaim` pour le libérer)

La prise en charge est distincte de l'attribution propre à Chatwoot — c'est un simple « je m'en occupe » pour votre équipe. Un ticket est libéré automatiquement lorsqu'il est résolu.

## Répondre à un client

1. Ouvrez le ticket
2. Saisissez votre réponse dans la zone en bas
3. (Facultatif) Cliquez sur `Attach` pour ajouter une capture d'écran ou un fichier (jusqu'à 10 fichiers de 10 Mo chacun), ou sur `Insert saved reply…` pour insérer une réponse type
4. Cliquez sur `Send`

Le client reçoit votre réponse par e-mail, et le ticket passe à **Awaiting customer**.

## Ajouter une note interne

Pour laisser aux autres agents une note que le client ne voit jamais :

1. Saisissez votre note dans la zone de réponse
2. Cochez `Internal note`
3. Cliquez sur `Send`

Les notes internes apparaissent en surbrillance dans le fil et sont réservées aux agents. Le commutateur revient à une réponse publique après chaque envoi.

## Définir la priorité, résoudre, rouvrir

- **Priorité** — choisissez un niveau (Urgent / High / Medium / Low / None) dans le sélecteur de priorité ; la file est retriée en conséquence.
- **Resolve** — cliquez sur `Resolve` lorsque le problème est traité ; le client reçoit un e-mail. Cliquez sur `Reopen` s'il réapparaît.

## Escalader vers PlaidCloud

Un agent partenaire qui a besoin que PlaidCloud reprenne un ticket peut le lui transmettre :

1. Ouvrez le ticket
2. Cliquez sur `Escalate`

Le ticket est acheminé vers l'équipe de support de PlaidCloud. L'escalade se produit aussi automatiquement pour les tickets laissés sans prise en charge ni réponse au-delà du délai configuré pour votre organisation — consultez [Gérer le support](/fr/guides/support/managing-support/#configurer-les-notifications-et-lescalade).
