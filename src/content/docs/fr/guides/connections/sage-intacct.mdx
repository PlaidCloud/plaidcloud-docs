Connectez PlaidCloud à Sage Intacct et extrayez des données financières et comptables. Ce guide vous mène des informations d'identification Web Services jusqu'à une extraction fonctionnelle. Pour la référence des champs, consultez le [connecteur REST Sage Intacct](/fr/reference/connectors/rest/sage-intacct/).

## Prérequis

Dans Sage Intacct, vous avez besoin des éléments suivants :

- **Web Services** activé pour votre société : le support Sage fournit votre **Sender ID** et votre **mot de passe expéditeur**, qui deviennent l'**ID client** et le **Secret client** de la connexion.
- Un **utilisateur Web Services** pour PlaidCloud, disposant des autorisations sur **chaque** objet que vos requêtes liront.
- Votre **ID de la société**.

Notez l'ID de la société, le nom d'utilisateur du service web, l'ID client (Sender ID) et le secret client (mot de passe expéditeur) avant de commencer.

<Aside type="caution">L'ID client/le secret client et le nom d'utilisateur du service web sont distincts. L'ID client/le secret client authentifient l'application auprès de Sage ; le nom d'utilisateur du service web, combiné à l'ID de la société, authentifie la connexion au sein de votre société. Les trois sont requis, et l'ID client/le secret client sont des secrets.</Aside>

## Créer la connexion

Intacct est une connexion de la **famille REST**. PlaidCloud fournit une variante **Intacct** dédiée (affichée sous le nom **REST - Intacct**) qui préremplit le point de terminaison du jeton OAuth2 et ne demande que les quatre champs d'identification ci-dessous. En interne, il s'agit d'une connexion REST qui s'authentifie avec les informations d'identification client OAuth2 auprès de l'API REST Intacct.

<Steps>

1. Ouvrez **Tools > Connections** et cliquez sur `New Connection`.

2. Sous **REST**, choisissez **Intacct** (affiché dans le menu sous le nom **REST - Intacct**).

3. Renseignez les champs :

   | Champ | Valeur |
   |---|---|
   | Nom | Un nom explicite, par exemple `Intacct Prod`. |
   | ID client | Votre **Sender ID** Intacct. |
   | Secret client | Votre **mot de passe expéditeur** Intacct. |
   | Nom d'utilisateur du service web | L'identifiant de l'utilisateur Web Services. |
   | ID de la société | La société Intacct à laquelle vous vous connectez. |

4. Cliquez sur `Create`.

</Steps>

## Tester rapidement la connexion

Vérifiez que les informations d'identification fonctionnent avant de construire dessus.

<Steps>

1. Ajoutez une [étape Requête REST](/fr/guides/workflows/rest-request-step/) à un workflow et définissez **Connexion** sur votre connexion Sage Intacct.

2. Dirigez-la vers une lecture réduite et bornée d'un objet que votre utilisateur peut voir.

3. Cliquez sur **Envoyer une requête de test**.

</Steps>

<Aside type="caution">
Utilisez **Envoyer une requête de test**, et non l'onglet Aperçu. Un résultat vert signifie que l'ID client/le secret client et le nom d'utilisateur du service web se sont tous deux authentifiés. En cas d'erreur, le message contient le détail fourni par Sage, le plus souvent une autorisation manquante pour l'utilisateur Web Services ou un ID client/secret client incorrect.
</Aside>

<Aside type="note">
Les requêtes Sage Intacct sont des **requêtes uniques : il n'y a aucune pagination** à configurer. Ne touchez pas aux contrôles de pagination.
</Aside>

## Extraire des données

Pour les extractions courantes, Sage Intacct dispose d'étapes d'importation dédiées qui correspondent directement aux objets Intacct :

- [Import Sage AP](/fr/reference/workflow-steps/sage-intacct/import-sage-ap/) : en-têtes de factures fournisseurs
- [Import Sage AP Lines](/fr/reference/workflow-steps/sage-intacct/import-sage-ap-lines/) : détail des lignes de factures fournisseurs
- [Import Sage Intacct Query](/fr/reference/workflow-steps/sage-intacct/import-intacct-query/) : une requête sur n'importe quel objet Intacct
- [Import Intacct Entity](/fr/reference/workflow-steps/sage-intacct/import-intacct-entity/) : détail du grand livre, soldes de comptes, écritures de journal, référentiels de dimensions (site, service, classe) et documents de commandes clients, avec pagination `readMore` automatique pour les jeux de résultats volumineux et filtres de plage `ge`/`le`

Choisissez l'étape, sélectionnez votre connexion Sage Intacct, définissez l'objet ou la requête, puis exécutez-la. Comme pour toute importation, définissez les colonnes de montants et de dates avec leurs vrais types afin qu'elles arrivent typées plutôt que sous forme de texte.

## Vérifier et planifier

<Steps>

1. Exécutez l'étape et vérifiez la table cible : nombre de lignes et types de colonnes.

2. Pour un flux continu, [planifiez le workflow](/fr/get-started/tutorials/schedule-a-workflow/).

</Steps>

## Dépannage

| Symptôme | Cause probable |
|---|---|
| Échec d'authentification | Un ID client/secret client incorrect (fourni par Sage) ou un nom d'utilisateur du service web incorrect. |
| Erreur d'autorisation / objet introuvable | L'utilisateur Web Services n'a pas l'autorisation sur l'objet lu. |
| Résultat vide ou inattendu | Un **ID de la société** incorrect. |
