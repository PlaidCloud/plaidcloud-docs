[Data Foundation](/fr/guides/projects/data-foundation/) rassemble dans un seul Common Finance Model les données de chaque système ERP et comptable que vous connectez, dans autant d'instances que vous en avez. Xero fait partie des systèmes qu'il lit directement, à raison d'une organisation Xero par connexion. Cette page s'adresse à l'administrateur Xero qui configure l'accès, et à l'utilisateur PlaidCloud qui le lui demande.

PlaidCloud ne fait que lire les données. Personne n'envoie de mot de passe par e-mail.

## Envoyer la demande d'accès

Dans l'onglet **Foundation** du projet, choisissez **Créer une nouvelle connexion** et sélectionnez **Xero**. Le formulaire affiche la demande complète. Cliquez sur **Copier la demande** pour la coller dans votre propre message, ou sur **Envoyer la demande par e-mail** pour l'ouvrir dans votre messagerie avec l'objet « Read-only Xero access for PlaidCloud ».

## Ce que l'administrateur Xero configure

<Steps>

1. **Autorisez l'application Xero de PlaidCloud** pour chaque organisation sur laquelle vous produisez des rapports, en vous connectant avec un utilisateur disposant du rôle Standard ou Advanced. L'application ne demande qu'un accès en lecture :

   | Portée | Ce qu'elle couvre |
   |---|---|
   | `accounting.settings.read` | Organisation, plan comptable, catégories de suivi, articles |
   | `accounting.contacts.read` | Clients |
   | `accounting.transactions.read` | Factures de vente et avoirs |
   | `accounting.journals.read` | Le grand livre : chaque écriture de journal comptabilisée |
   | `accounting.reports.read` | La balance de vérification, pour les soldes d'ouverture |

   Sans `accounting.journals.read`, le grand livre ne peut pas être chargé. Le plan comptable, les départements, les clients et les produits le sont toujours.

2. **Configurez les catégories de suivi que PlaidCloud lit**, sous ces noms :

   - **Département :** une option par département, nommée comme vous voulez que son code apparaisse.
   - **Intersociétés :** une option par société du groupe, nommée par le code d'entité de cette société, sur les lignes des écritures intersociétés. Nommez les comptes intersociétés de sorte que « Intercompany » fasse partie du nom du compte.

</Steps>

## Ce qu'il faut renvoyer

| L'administrateur envoie | Saisi dans PlaidCloud comme |
|---|---|
| L'ID de locataire de l'organisation (Xero le liste sous la connexion, ou à `GET /connections`) | **Organisation (tenant) ID** |
| La confirmation que la fin d'exercice et la date de verrouillage de période de l'organisation sont définies | Rien à saisir : PlaidCloud lit les deux dans Xero |

L'utilisateur PlaidCloud colle lui-même le **Refresh token** ; c'est un secret qui n'est jamais envoyé par e-mail. Il choisit aussi l'**Organisation** sous laquelle la connexion est chargée.

Sous **Paramètres système**, **Retained earnings account** nomme le compte de capitaux propres dans lequel le compte de résultat d'ouverture est reporté, lorsque les noms de comptes ne l'indiquent pas déjà. Il est facultatif.

## Vérifier l'accès

De retour dans PlaidCloud, cliquez sur **Tester la connexion**. Chaque jeu de données s'affiche comme **Lisible**, **Autorisation manquante** ou **Erreur** :

| Jeu de données | Portée requise |
|---|---|
| Entités | `accounting.settings.read` |
| Plan comptable | `accounting.settings.read` |
| Départements | `accounting.settings.read` (la catégorie de suivi Department) |
| Produits | `accounting.settings.read` |
| Calendrier fiscal | `accounting.settings.read` |
| Clients | `accounting.contacts.read` |
| Grand livre | `accounting.journals.read` |
| Balance de vérification | `accounting.reports.read` |
| Lignes de vente (facultatif) | `accounting.transactions.read` |
| Budget (facultatif) | `accounting.reports.read` |

Lorsqu'un jeu de données affiche **Autorisation manquante**, le test nomme la portée à accorder. Autorisez à nouveau l'application avec celle-ci, puis testez à nouveau. Une organisation Xero sans factures de vente ni budgets charge tout le reste.

Les taux de change ne font pas partie de cet accès : Xero ne les publie pas. Fournissez-les plutôt dans un fichier **Taux de change**.
