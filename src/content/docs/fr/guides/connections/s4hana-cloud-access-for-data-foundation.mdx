[Data Foundation](/fr/guides/projects/data-foundation/) rassemble dans un seul Common Finance Model les données de chaque système ERP et de chaque instance que vous connectez, et SAP S/4HANA Cloud fait partie des ERP qu'il lit directement. La connexion lit les services OData publiés du locataire avec les identifiants client OAuth 2.0 ; aucun agent n'intervient. Cette page s'adresse à l'administrateur S/4HANA Cloud qui effectue cette configuration, et à l'utilisateur PlaidCloud qui la lui demande.

PlaidCloud ne fait que lire les données. Personne n'envoie de mot de passe ni de secret client par e-mail.

## Envoyer la demande d'accès

Dans l'onglet **Foundation** du projet, choisissez **Créer une nouvelle connexion** sous **Connexion SAP S/4HANA Cloud**. Le formulaire affiche la demande complète. Cliquez sur **Copier la demande** pour la coller dans votre propre message, ou sur **Envoyer la demande par e-mail** pour l'ouvrir dans votre messagerie avec l'objet « Read-only SAP S/4HANA Cloud access for PlaidCloud (OAuth 2.0 client credentials) ».

## Ce que l'administrateur S/4HANA Cloud configure

<Steps>

1. **Créez un utilisateur de communication** pour PlaidCloud, dans l'application **Maintain Communication Users**. Sa méthode d'authentification est OAuth 2.0 ou nom d'utilisateur et mot de passe, selon ce que votre paysage exige.

2. **Créez un système de communication** pour PlaidCloud, dans l'application **Communication Systems**, avec cet utilisateur pour la communication entrante et les identifiants client OAuth 2.0.

3. **Créez un arrangement de communication** pour chacun des scénarios ci-dessous, dans l'application **Communication Arrangements**, tous pour le système de l'étape 2. Ensemble, ils exposent les services OData que PlaidCloud lit :

   | Scénario | Service |
   |---|---|
   | Company Code | `API_COMPANYCODE_SRV` |
   | G/L Account in Chart of Accounts | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | Cost Center | `API_COSTCENTER_SRV` |
   | Business Partner and Customer | `API_BUSINESS_PARTNER` |
   | Product | `API_PRODUCT_SRV` |
   | Fiscal Year Variant Periods | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | Exchange Rates | `API_EXCHANGERATE_SRV` |
   | Journal Entry Item | `API_JOURNALENTRYITEMBASIC_SRV` (le journal et le solde reporté) |
   | Billing Document | `API_BILLING_DOCUMENT_SRV` (facultatif : il ajoute les ventes facturées, les documents et les postes) |

   Donnez à l'utilisateur de communication l'accès à chaque code société sur lequel vous produisez des rapports.

</Steps>

## Ce qu'il faut renvoyer

| L'administrateur envoie | Saisi dans PlaidCloud comme |
|---|---|
| L'hôte de l'API du locataire, par exemple `my300000-api.s4hana.cloud.sap` | **Hôte** |
| L'ID client | **ID client** |
| Le secret client, via le formulaire de connexion sécurisé | **Secret client**, que votre équipe colle elle-même |
| L'URL du jeton, uniquement si votre paysage utilise un serveur d'autorisation XSUAA plutôt que celui du locataire (`/sap/bc/sec/oauth2/token`) | **Token URL (optional)** |
| La portée, uniquement avec un serveur d'autorisation XSUAA | **Portée (facultatif)** |
| Si **Carry Forward Balances** a été exécuté pour chaque exercice que vous chargez | Rien à saisir. Les soldes d'ouverture y sont lus. |

<Aside type="caution">
N'envoyez jamais le secret client par e-mail. **Secret client** est un secret : il est stocké dans la connexion et jamais affiché de nouveau.
</Aside>

## Vérifier l'accès

De retour dans PlaidCloud, saisissez les valeurs et cliquez sur **Tester la connexion**. Chaque jeu de données s'affiche comme **Lisible**, **Autorisation manquante** ou **Erreur** :

| Jeu de données | Service requis |
|---|---|
| Entités | `API_COMPANYCODE_SRV` |
| Plan comptable | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| Départements | `API_COSTCENTER_SRV` |
| Clients | `API_BUSINESS_PARTNER` |
| Produits | `API_PRODUCT_SRV` |
| Taux de change | `API_EXCHANGERATE_SRV` |
| Calendrier fiscal | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| Grand livre | `API_JOURNALENTRYITEMBASIC_SRV` |
| Balance de vérification | `API_JOURNALENTRYITEMBASIC_SRV` |
| Lignes de vente | `API_BILLING_DOCUMENT_SRV` (facultatif) |

Lorsqu'un jeu de données affiche **Autorisation manquante**, demandez à l'administrateur d'ajouter l'arrangement de communication de son service, puis testez à nouveau. Les lignes de vente, le budget et les soldes de stock sont facultatifs : un locataire qui n'en contient pas charge tout le reste.
