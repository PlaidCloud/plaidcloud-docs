## Description

Le clonage duplique la configuration d'une connexion existante (hôte, port, options, référence des identifiants) afin que vous puissiez modifier quelques champs et l'enregistrer comme nouvelle connexion, sans ressaisir chaque paramètre.

Le clonage fonctionne pour tous les types de connexions de données externes : base de données, ERP, REST, service cloud, Git et documents.


## Cloner une connexion

1. Ouvrez **Tools > Connections**
2. Sélectionnez la connexion à copier
3. Cliquez sur `Clone` dans la barre d'outils (ou cliquez avec le bouton droit sur la ligne et sélectionnez `Clone`)
4. Modifiez le nom de la nouvelle connexion et les champs qui doivent différer
5. Cliquez sur `Save`


## Actions réservées au propriétaire

`Edit`, `Clone` et `Delete` ne sont disponibles que sur les connexions dont vous êtes propriétaire. Si ces boutons de la barre d'outils sont grisés pour la ligne sélectionnée, vous n'êtes pas le propriétaire : demandez-lui de cloner la connexion pour vous, ou faites-vous ajouter comme propriétaire supplémentaire via `Edit Owners`.

<Aside>Le clonage copie la configuration, mais ni les résultats de test ni l'historique d'exécution. Testez la connexion clonée avant de vous y fier dans un workflow.</Aside>
