[Data Foundation](/fr/guides/projects/data-foundation/) rassemble dans un seul Common Finance Model les données de chaque système ERP et comptable que vous connectez, dans autant d'instances que vous en avez. QuickBooks Online fait partie des systèmes qu'il lit directement. Cette page s'adresse à l'administrateur QuickBooks qui configure l'accès, et à l'utilisateur PlaidCloud qui le lui demande.

PlaidCloud ne fait que lire les données. Personne n'envoie de mot de passe ni de jeton par e-mail.

## Envoyer la demande d'accès

Dans la page **Systèmes** du projet, sous **Data Foundation** dans **Accueil**, choisissez votre système dans **Système** sous **Ajouter un système**, puis cliquez sur **Vous n’avez pas encore accès ?**. Le système attend l'accès, et une demande unique couvrant les systèmes du projet s'affiche. Cliquez sur **Copier la demande** pour la coller dans votre propre message, ou sur **Envoyer la demande par e-mail** pour l'ouvrir dans votre messagerie avec l'objet « Accès à PlaidCloud. »

## Ce que l'administrateur QuickBooks configure

<Steps>

1. **Choisissez l'utilisateur QuickBooks au nom duquel PlaidCloud agira.** Dans QuickBooks même, cet utilisateur doit pouvoir voir :

   - le plan comptable (Chart of Accounts), les clients, les fournisseurs, les produits et services, les emplacements et les classes
   - les rapports Grand livre, Balance de vérification et Compte de résultat (un utilisateur qui peut les exécuter sous Rapports)
   - les transactions de vente : factures, reçus de vente, avoirs et reçus de remboursement
   - les achats et les paiements, si vous voulez inclure les fournisseurs, les postes ouverts et les paiements dans le modèle : factures fournisseurs, avoirs fournisseurs, dépenses, paiements clients et paiements de factures
   - les budgets et le récapitulatif de valorisation des stocks, si vous voulez les inclure dans le modèle (QuickBooks Plus ou Advanced)

   Un administrateur de la société dispose déjà de ces accès. Un utilisateur limité doit se voir activer ces autorisations.

2. **Autorisez PlaidCloud une seule fois.** Cet utilisateur se connecte sur l'écran de consentement d'Intuit, depuis la connexion que l'utilisateur PlaidCloud lui envoie. La portée est limitée à Accounting (`com.intuit.quickbooks.accounting`).

3. **Une société par connexion.** Si vous gérez plusieurs sociétés QuickBooks, autorisez chacune sur sa propre connexion.

</Steps>

## Ce qu'il faut renvoyer

| L'administrateur envoie | Saisi dans PlaidCloud comme |
|---|---|
| Le nom de la société, tel qu'il doit apparaître dans le modèle | Rien à saisir : la connexion lit la société unique que l'utilisateur QuickBooks approuve |
| Si les comptes sont clôturés jusqu'à une date (**Settings > Account and Settings > Advanced > Accounting**) | Rien à saisir : PlaidCloud lit la date de clôture des comptes dans QuickBooks |

Dans la page **Systèmes** du projet, l'utilisateur PlaidCloud choisit QuickBooks Online dans **Système** sous **Ajouter un système**, puis clique sur **Se connecter à** suivi du nom du système. PlaidCloud crée la connexion pour l'environnement du projet et ouvre la fenêtre d'approbation d'Intuit. Une fois que l'utilisateur QuickBooks a approuvé, le système est ajouté et commence à charger. Consultez [Connecter votre ERP](/fr/guides/projects/data-foundation/#connecter-votre-erp).

Sous **Paramètres système**, **Retained earnings account** nomme le compte de capitaux propres dans lequel le compte de résultat d'ouverture est reporté, lorsque les noms de comptes ne l'indiquent pas déjà. Il est facultatif.

## Vérifier l'accès

De retour dans PlaidCloud, une fois le système ajouté, cliquez sur **Tester la connexion** sur sa ligne dans la page **Systèmes**. Il lit les jeux de données obligatoires (entités, plan comptable, calendrier fiscal, balance de vérification et grand livre) et affiche chacun comme **Lisible**, **Autorisation manquante** ou **Erreur**. Les jeux de données facultatifs ne font pas partie du test : si QuickBooks en refuse un, les contrôles de préparation le nomment après le chargement suivant. Ce que lit chaque jeu de données :

| Jeu de données | Ce qu'il lit dans QuickBooks |
|---|---|
| Entités | Les informations sur la société |
| Plan comptable | Le plan comptable (Chart of Accounts) |
| Calendrier fiscal | Les préférences de la société : premier mois de l'exercice et date de clôture des comptes |
| Balance de vérification | Le rapport Balance de vérification, pour les soldes d'ouverture |
| Grand livre | Le rapport Grand livre |
| Sites | Les emplacements (facultatif) |
| Centres de profit | Les classes (facultatif) |
| Clients | Les clients (facultatif) |
| Produits | Les produits et services (facultatif) |
| Fournisseurs | Les fournisseurs et leurs conditions de paiement (facultatif) |
| Solde de fin de mois | Le rapport Balance de vérification à chaque fin de mois (facultatif) |
| Soldes bancaires | Les soldes des comptes bancaires dans cette balance de vérification de fin de mois (facultatif) |
| Lignes de vente | Les factures, reçus de vente, avoirs et reçus de remboursement (facultatif) |
| Lignes de factures fournisseurs | Les factures fournisseurs, avoirs fournisseurs et dépenses (facultatif) |
| Postes ouverts | Les factures, avoirs, factures fournisseurs et avoirs fournisseurs, diminués des paiements qui leur sont imputés, à chaque fin de mois (facultatif) |
| Paiements | Les paiements clients et paiements de factures (facultatif) |
| Budget | Les budgets (facultatif) |
| Soldes de stock | Le récapitulatif de valorisation des stocks à chaque fin de mois, lorsque la société suit les quantités disponibles (facultatif) |
| Taux de change | Les taux de change (facultatif) |

Lorsqu'un jeu de données affiche **Autorisation manquante**, le test nomme l'accès à ajouter. Demandez à l'administrateur de l'activer pour l'utilisateur, puis testez à nouveau. Une société sans les données facultatives, comme les budgets, charge tout le reste. Lorsque QuickBooks refuse une lecture à partir de laquelle sont construits les soldes, les stocks, les ventes, les achats, les postes ouverts ou les paiements d'un mois, ce mois conserve les lignes qu'il avait déjà et est relu au chargement suivant.

QuickBooks n'a ni partenaire commercial, ni compte intersociétés, ni registre ; les lignes d'une société QuickBooks n'en portent donc aucun. Il n'a pas non plus de départements : ses emplacements sont des sites et ses classes des centres de profit.
