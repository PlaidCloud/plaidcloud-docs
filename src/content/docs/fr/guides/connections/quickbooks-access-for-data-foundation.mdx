[Data Foundation](/fr/guides/projects/data-foundation/) rassemble dans un seul Common Finance Model les données de chaque système ERP et comptable que vous connectez, dans autant d'instances que vous en avez. QuickBooks Online fait partie des systèmes qu'il lit directement. Cette page s'adresse à l'administrateur QuickBooks qui configure l'accès, et à l'utilisateur PlaidCloud qui le lui demande.

PlaidCloud ne fait que lire les données. Personne n'envoie de mot de passe ni de jeton par e-mail.

## Envoyer la demande d'accès

Dans l'onglet **Foundation** du projet, choisissez **Créer une nouvelle connexion** et sélectionnez **QuickBooks Online**. Le formulaire affiche la demande complète. Cliquez sur **Copier la demande** pour la coller dans votre propre message, ou sur **Envoyer la demande par e-mail** pour l'ouvrir dans votre messagerie avec l'objet « Read-only QuickBooks Online access for PlaidCloud ».

## Ce que l'administrateur QuickBooks configure

<Steps>

1. **Choisissez l'utilisateur QuickBooks au nom duquel PlaidCloud agira.** Dans QuickBooks même, cet utilisateur doit pouvoir voir :

   - le plan comptable (Chart of Accounts), les clients, les produits et services, et les emplacements
   - les rapports Grand livre, Balance de vérification et Compte de résultat (un utilisateur qui peut les exécuter sous Rapports)
   - les transactions de vente : factures, reçus de vente, avoirs et reçus de remboursement
   - les budgets et le récapitulatif de valorisation des stocks, si vous voulez les inclure dans le modèle (QuickBooks Plus ou Advanced)

   Un administrateur de la société dispose déjà de ces accès. Un utilisateur limité doit se voir activer ces autorisations.

2. **Autorisez PlaidCloud une seule fois.** Cet utilisateur se connecte sur l'écran de consentement d'Intuit, depuis la connexion que l'utilisateur PlaidCloud lui envoie. La portée est limitée à Accounting (`com.intuit.quickbooks.accounting`).

3. **Une société par connexion.** Si vous gérez plusieurs sociétés QuickBooks, autorisez chacune sur sa propre connexion.

</Steps>

## Ce qu'il faut renvoyer

| L'administrateur envoie | Saisi dans PlaidCloud comme |
|---|---|
| Le nom de la société, tel qu'il doit apparaître dans le modèle | La **Société** que vous choisissez pour la connexion |
| Si les comptes sont clôturés jusqu'à une date (**Settings > Account and Settings > Advanced > Accounting**) | Rien à saisir : PlaidCloud lit la date de clôture des comptes dans QuickBooks |

Dans l'onglet **Foundation**, l'utilisateur PlaidCloud renseigne la nouvelle connexion :

- **ID de la société (realm ID)**
- **Refresh token**, un secret que l'utilisateur PlaidCloud colle lui-même
- **Environnement**, soit `production`, soit `sandbox`

Sous **Paramètres système**, **Retained earnings account** nomme le compte de capitaux propres dans lequel le compte de résultat d'ouverture est reporté, lorsque les noms de comptes ne l'indiquent pas déjà. Il est facultatif.

## Vérifier l'accès

De retour dans PlaidCloud, cliquez sur **Tester la connexion**. Chaque jeu de données s'affiche comme **Lisible**, **Autorisation manquante** ou **Erreur** :

| Jeu de données | Ce qu'il lit dans QuickBooks |
|---|---|
| Entités | Les informations sur la société |
| Plan comptable | Le plan comptable (Chart of Accounts) |
| Calendrier fiscal | Les préférences de la société : premier mois de l'exercice et date de clôture des comptes |
| Balance de vérification | Le rapport Balance de vérification, pour les soldes d'ouverture |
| Grand livre | Le rapport Grand livre |
| Départements | Les emplacements (facultatif) |
| Clients | Les clients (facultatif) |
| Produits | Les produits et services (facultatif) |
| Lignes de vente | Les factures, reçus de vente, avoirs et reçus de remboursement (facultatif) |
| Budget | Les budgets (facultatif) |
| Soldes de stock | Le récapitulatif de valorisation des stocks (facultatif) |
| Taux de change | Les taux de change (facultatif) |

Lorsqu'un jeu de données affiche **Autorisation manquante**, le test nomme l'accès à ajouter. Demandez à l'administrateur de l'activer pour l'utilisateur, puis testez à nouveau. Une société sans les données facultatives, comme les budgets, charge tout le reste.

QuickBooks n'a ni partenaire commercial, ni compte intersociétés, ni registre ; les lignes d'une société QuickBooks n'en portent donc aucun.
