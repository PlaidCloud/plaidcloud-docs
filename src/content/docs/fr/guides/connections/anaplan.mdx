Connectez PlaidCloud à **Anaplan** pour qu'un workflow puisse lire une vue enregistrée par le chemin de requête de lecture à gros volume d'Anaplan, exécuter une action d'export existante, ou lire une ou plusieurs listes Anaplan dans une dimension PlaidCloud. La connexion atteint l'API d'intégration propre à Anaplan en **accès direct au cloud**. Ces étapes n'ont aucun chemin passant par un agent local. Ce guide présente la connexion, l'authentification, une brève introduction à chacune des trois étapes de lecture, et les points à considérer pour la planification.

<Aside type="note">
Ce connecteur est en lecture seule. Rien n'est jamais réécrit dans Anaplan : il n'existe aucune étape de réécriture ni de mode d'application partielle.
</Aside>

## Prérequis

Vous avez besoin, de la part de votre administrateur d'espace de travail Anaplan :

- Soit d'un **nom d'utilisateur et d'un mot de passe** Anaplan, soit d'un **certificat d'AC et de sa clé privée** associés à un utilisateur Anaplan par votre administrateur d'espace de travail, avec un accès en lecture à l'espace de travail et aux modèles que vos workflows liront. Consultez [Authentification](#authentification) ci-dessous.
- De l'**ID de l'espace de travail** et de l'**ID du modèle** des modèles que vous lirez, visibles dans les paramètres de modèle d'Anaplan. Les deux peuvent aussi être détectés en direct depuis la connexion une fois celle-ci créée.
- Pour **Anaplan : lire une vue**, d'une **vue enregistrée**, construite avec exactement la tranche de lignes, de colonnes et de filtres souhaitée. Consultez [Anaplan : lire une vue](#anaplan--lire-une-vue) ci-dessous.
- Pour **Anaplan : lire un export**, d'une **action d'export qui existe déjà** dans le modèle.
- Pour **Anaplan : lire une liste**, des **listes** Anaplan qui constituent la hiérarchie à lire.

## Authentification

La connexion possède un **Mode d'authentification** : **Basique** (par défaut) ou **Certificat**. Une connexion existante continue de fonctionner sans changement en mode Basique.

- **Basique** se connecte avec un nom d'utilisateur et un mot de passe Anaplan.
- **Certificat** se connecte avec un certificat émis par une AC et sa clé privée, tous deux collés sous forme de texte PEM. La clé privée doit être **RSA et non chiffrée**, et le certificat doit être celui que votre administrateur d'espace de travail Anaplan a associé à votre utilisateur Anaplan, émis par une AC à laquelle Anaplan fait confiance pour votre locataire. PlaidCloud signe un défi aléatoire avec la clé et l'échange contre un jeton Anaplan, selon le flux d'authentification par certificat d'Anaplan ; il n'y a rien d'autre à faire une fois le certificat et la clé collés, et l'actualisation du jeton fonctionne comme en mode Basique. Les deux champs masquent ce que vous collez, et les deux secrets sont stockés chiffrés, comme un mot de passe en mode Basique. Changer de mode n'envoie jamais les identifiants de l'autre mode : si vous faites passer une connexion existante de Basique à Certificat, vous devez coller le certificat et la clé, car ils ne sont pas repris.

L'authentification multifacteur d'Anaplan s'applique aux utilisateurs qui se connectent avec une adresse e-mail et un mot de passe. L'authentification par certificat est l'option sans mot de passe pour une connexion automatisée et planifiée.

Le mode Certificat refuse la connexion avant de contacter Anaplan si la clé ou le certificat collé est illisible, si la clé est chiffrée ou n'est pas RSA, ou si la clé ne correspond pas au certificat. Si Anaplan rejette lui-même le certificat, l'erreur indique s'il a expiré ; les causes habituelles sont un certificat qui n'est pas associé à un utilisateur Anaplan, ou une AC à laquelle votre locataire ne fait pas confiance.

## Créer la connexion

<Steps>

1. Ouvrez **Tools > Connections** et cliquez sur `New Connection`.

2. Choisissez **Anaplan** dans le menu.

3. Renseignez les champs :

   | Champ | Valeur |
   |---|---|
   | Nom | Un nom convivial, par exemple `Anaplan Prod`. |
   | Hôte de l'API | Facultatif. Laissez vide pour utiliser l'adresse standard d'Anaplan, `https://api.anaplan.com`. |
   | Hôte d'authentification | Facultatif. Laissez vide pour utiliser l'adresse standard d'Anaplan, `https://auth.anaplan.com`. |
   | Mode d'authentification | **Basique** (par défaut) ou **Certificat**. Consultez [Authentification](#authentification) ci-dessus. |
   | Nom d'utilisateur | Le nom d'utilisateur du compte Anaplan. Mode Basique uniquement. |
   | Mot de passe | Le mot de passe du compte Anaplan. Mode Basique uniquement. |
   | Certificat d'AC | Texte PEM du certificat X.509 enregistré dans Anaplan. Mode Certificat uniquement. |
   | Clé privée | Texte PEM de la clé privée RSA du certificat, non chiffrée. Mode Certificat uniquement. |
   | ID de l'espace de travail par défaut | Facultatif. Un pré-remplissage pratique pour le champ Espace de travail d'une étape de lecture. |
   | ID du modèle par défaut | Facultatif. Un pré-remplissage pratique pour le champ Modèle d'une étape de lecture. |
   | Délai d'expiration (secondes) | 30 par défaut. |

4. Cliquez sur `Test Connection`. Un test réussi indique l'adresse e-mail du compte Anaplan à laquelle correspondent les identifiants.

5. Cliquez sur `Create`.

</Steps>

## Anaplan : lire une vue

Ajoutez une étape **Anaplan : lire une vue** pour lire une vue enregistrée par le chemin de requête de lecture à gros volume d'Anaplan. **La vue est lue exactement comme elle a été enregistrée dans Anaplan : cette étape n'offre aucune sélection de lignes, de colonnes ou de pages.** Pour lire une autre tranche, construisez une autre vue enregistrée dans Anaplan ; un élément de ligne booléen associé à une vue enregistrée est la méthode habituelle pour y filtrer. Une colonne de données n'arrive avec son type Anaplan déclaré que lorsque la vue place les **éléments de ligne sur l'axe des colonnes** ; si les éléments de ligne sont sur les lignes (une présentation de compte de résultat classique) ou absents de la vue, toutes les colonnes arrivent en texte, et l'étape le signale. Une vue dont le filtre ne correspond à rien charge une table vide avec un avertissement. Une valeur numérique que l'étape ne peut pas lire sans ambiguïté, le plus souvent parce qu'elle pourrait aussi bien être un nombre décimal simple qu'une écriture à l'européenne, est refusée plutôt que devinée, sauf si une autre valeur de la même colonne tranche sur la lecture correcte ; une valeur qui s'interprète correctement est chargée avec toute sa précision, sans erreur d'arrondi. Consultez [Anaplan : lire une vue](/fr/reference/workflow-steps/anaplan/anaplan-read-view/) pour la référence complète des champs et du comportement.

## Anaplan : lire un export

Ajoutez une étape **Anaplan : lire un export** pour exécuter une action d'export Anaplan **existante** et charger le fichier qu'elle produit. L'API ne peut pas créer d'action d'export : construisez-la ou modifiez-la d'abord dans Anaplan. L'étape ne peut pas restreindre ce qui est émis : ce que l'action est configurée pour exporter dans Anaplan est exactement ce qui est chargé. **Toutes les colonnes arrivent en texte.** Les nombres sont demandés au format américain ; une colonne qui revient quand même avec des séparateurs de milliers est chargée telle quelle, en texte, avec un avertissement explicite plutôt qu'un échec de l'exécution. L'étape s'arrête au lieu de charger une table lorsque l'export échoue, est annulé, ne produit aucune donnée, est toujours en cours une fois le délai d'interrogation de l'étape épuisé, ou produit un fichier impossible à rattacher à l'export ou dont le nombre de lignes diffère de celui qu'Anaplan indique lui-même. Consultez [Anaplan : lire un export](/fr/reference/workflow-steps/anaplan/anaplan-read-export/) pour la référence complète.

## Anaplan : lire une liste

Ajoutez une étape **Anaplan : lire une liste** pour lire une ou plusieurs listes Anaplan dans une dimension PlaidCloud. **Une seule étape lit toute une hiérarchie composite** : nommez toutes les listes qu'elle couvre, en commençant par la racine (par exemple Région, puis Pays, puis Magasin), plutôt que de la répartir entre plusieurs étapes ; la table de préparation est remplacée à chaque exécution, donc plusieurs étapes pointant vers une même table de préparation effaceraient chacune les lignes de la précédente. Chaque arête se consolide avec un simple `+`, car les hiérarchies de listes Anaplan ne portent ni pondération ni signe par arête à lire. Les contrôles d'accès aux listes et l'appartenance aux sous-ensembles d'Anaplan ne sont pas importés : ce sont des métadonnées, pas des données de dimension. Les ID de nœud en double, une référence de parent introuvable, des références de parent contradictoires et un nom de propriété qui entre en collision avec des métadonnées importées sont tous refusés avant tout chargement. Consultez [Anaplan : lire une liste](/fr/reference/workflow-steps/anaplan/anaplan-read-list/) pour la référence complète.

## Anaplan comme source pour Data Foundation

[Data Foundation](/fr/guides/projects/data-foundation/) peut lire le plan que détient Anaplan (un budget, une prévision ou les résultats d'un modèle de consolidation) dans son Common Finance Model. Il importe le plan, jamais le grand livre, et ne fait que lire.

Data Foundation exécute une action d'export du modèle telle qu'elle est enregistrée ; votre administrateur Anaplan construit donc cet export au préalable. L'onglet **Foundation** rédige la demande à sa place. L'export doit être une grille à plat comportant une ligne par entité, période, compte et département, avec exactement ces en-têtes de colonne :

| Colonne | Contenu |
|---|---|
| `Entity` | Le code de l'entité. |
| `Period` | Le mois, au format `YYYY-MM`. |
| `Account` | Le code du compte. |
| `Department` | Le code du département, vide lorsque le plan n'en a pas. |
| `Currency` | La devise du montant. |
| `Amount` | Un nombre simple sans séparateur de milliers, avec le signe dans lequel le plan est tenu (revenus positifs). |

Ajoutez ensuite la connexion comme source dans l'onglet **Foundation**, comme pour toute autre (consultez [Connecter votre ERP](/fr/guides/projects/data-foundation/#connecter-votre-erp)). Une nouvelle connexion demande le **Nom d'utilisateur**, le **Mot de passe**, l'**ID de l'espace de travail** et l'**ID du modèle**. Anaplan ne liste aucune entité à cocher ; le formulaire en demande donc une : saisissez sous **Nom** l'entité de l'export à conserver, ou laissez vide pour conserver toutes les entités. Renseignez ensuite les **paramètres système**, qui s'affichent sous ces noms :

| Paramètre | Signification |
|---|---|
| `export` | L'ID de l'action d'export à exécuter. |
| `scenario` | `Budget` (par défaut), `Forecast` ou `Consolidated`, pour les résultats d'un modèle de consolidation auxquels le compte de résultat du groupe est rapproché. |
| `version` | Une étiquette apposée sur chaque ligne. `Anaplan` par défaut. |

Les montants sont lus tels quels, avec leur signe naturel. Une colonne qui revient encore groupée avec des séparateurs de milliers est signalée, et non devinée, comme pour [Anaplan : lire un export](/fr/reference/workflow-steps/anaplan/anaplan-read-export/).

## Considérations sur la planification

Le budget de débit de requêtes d'Anaplan est **partagé à l'échelle du locataire**, entre toutes les intégrations que votre organisation exécute sur ce locataire Anaplan, et pas seulement celles de PlaidCloud ; PlaidCloud ne coordonne pas les planifications entre exécutions concurrentes. Plusieurs étapes Anaplan démarrant à la même minute cron peuvent épuiser ce budget avant qu'aucune ne se termine. **Échelonnez les planifications de vos workflows Anaplan** plutôt que de les lancer toutes en même temps.
