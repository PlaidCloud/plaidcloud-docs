[Data Foundation](/fr/guides/projects/data-foundation/) rassemble dans un seul Common Finance Model les données de chaque système ERP et de chaque instance que vous connectez, et Sage Intacct fait partie des ERP qu'il lit directement. La connexion utilise Intacct Web Services : une autorisation d'expéditeur pour PlaidCloud et un utilisateur Web Services en lecture seule. Cette page s'adresse à l'administrateur Sage Intacct qui effectue cette configuration, et à l'utilisateur PlaidCloud qui la lui demande.

PlaidCloud ne fait que lire les données. Personne n'envoie de mot de passe par e-mail.

## Envoyer la demande d'accès

Dans l'onglet **Foundation** du projet, choisissez **Créer une nouvelle connexion** sous **Connexion Sage Intacct**. Le formulaire affiche la demande complète. Cliquez sur **Copier la demande** pour la coller dans votre propre message, ou sur **Envoyer la demande par e-mail** pour l'ouvrir dans votre messagerie avec l'objet « Read-only Sage Intacct access for PlaidCloud (Web Services) ».

## Ce que l'administrateur Sage Intacct configure

<Steps>

1. **Autorisez PlaidCloud comme expéditeur Web Services.** Sous **Company > Admin > Web Services authorizations**, ajoutez l'ID d'expéditeur que PlaidCloud vous a fourni. Renvoyez l'ID d'expéditeur et le mot de passe d'expéditeur que Sage a émis pour lui.

2. **Créez un utilisateur Web Services.** Sous **Company > Admin > Users**, créez un utilisateur de type « Business » avec l'option « Web services only », et un rôle disposant de l'autorisation **View** sur :

   | Domaine | Objets |
   |---|---|
   | General Ledger | Comptes, écritures de journal (tous les journaux, y compris les journaux d'ajustement), soldes de comptes, périodes de reporting, taux de change, budgets |
   | Company | Entités (emplacements), départements, classes, projets |
   | Accounts Receivable | Clients |
   | Inventory Control | Articles |
   | Order Entry | Transactions (factures de vente, ainsi que les avoirs et retours qui les annulent), si vous voulez les ventes |

   Donnez à l'utilisateur l'accès au niveau supérieur de la société et à chaque entité sur laquelle PlaidCloud produit des rapports. Si les définitions de vos transactions d'avoir et de retour ne s'appellent pas Sales Credit Memo et Sales Return, indiquez leurs noms à l'utilisateur PlaidCloud.

3. **Autorisez l'adresse IP de l'utilisateur** si votre société restreint Web Services par IP.

</Steps>

## Ce qu'il faut renvoyer

| L'administrateur envoie | Saisi dans PlaidCloud comme |
|---|---|
| L'ID de la société | **ID de la société** |
| L'ID de l'utilisateur Web Services | **Web services user ID** |
| Le mot de passe de l'utilisateur Web Services | **Web services password** |
| L'ID d'expéditeur | **Sender ID** |
| Le mot de passe d'expéditeur | **Sender password** |
| Les noms de vos définitions de transactions d'avoir et de retour, s'ils ne sont pas ceux par défaut | Le paramètre système `credit_documents` (par défaut : Sales Credit Memo, Sales Return) |
| Les entités que PlaidCloud peut lire | Choisies sous **Entités** dans PlaidCloud |

Les mots de passe passent par votre gestionnaire de mots de passe, jamais par e-mail. L'équipe de l'utilisateur PlaidCloud colle elle-même le **Web services password** et le **Sender password** dans PlaidCloud. Les entités qui sont les éliminations propres à votre société sont à renseigner dans le paramètre système `elimination_entities`.

## Vérifier l'accès

De retour dans PlaidCloud, saisissez les valeurs et cliquez sur **Tester la connexion**. Chaque jeu de données s'affiche comme **Lisible**, **Autorisation manquante** ou **Erreur** :

| Jeu de données | Autorisation requise |
|---|---|
| Entités | Company : Entities (View) |
| Plan comptable | General Ledger : Accounts et Statistical accounts (View) |
| Départements | Company : Departments (View) |
| Clients | Accounts Receivable : Customers (View) |
| Produits | Inventory Control : Items (View) |
| Taux de change | General Ledger : Exchange rates (View) |
| Calendrier fiscal | General Ledger : Reporting periods (View) |
| Balance de vérification | General Ledger : Account balances (View) |
| Grand livre | General Ledger : Journal entries (View) |
| Lignes de vente | Order Entry : Transactions (View) |
| Budget | General Ledger : Budgets (View) |
| Inducteurs d'allocation | General Ledger : Account balances (View) |

Lorsqu'un jeu de données est manquant, le test nomme l'autorisation à ajouter. Demandez à l'administrateur de l'ajouter au rôle, puis testez à nouveau. Les lignes de vente, le budget et les inducteurs d'allocation sont facultatifs : une société qui ne les utilise pas charge tout le reste.
