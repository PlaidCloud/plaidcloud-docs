PlaidXL ajoute à Excel des fonctions qui lisent les données PlaidCloud directement dans les cellules. Saisissez `=PLAIDXL.` dans une cellule et la saisie semi-automatique d'Excel les répertorie, avec une courte description de chaque argument. L'onglet **Formulas** du volet des tâches peut aussi en écrire une pour vous ; consultez [Insérer une formule depuis le volet des tâches](#insérer-une-formule-depuis-le-volet-des-tâches).

| Groupe | Fonctions | À utiliser pour |
|---|---|---|
| Listes | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Voir ce qui est disponible pour construire vos rapports |
| Tables | [`TABLE.GET_TABLE`](#get_table) | Lire une table entière dans une plage |
| Hiérarchies | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Disposer les nœuds d'une dimension en lignes de rapport |
| Valeurs | [`CELL`](#cell), [`CELLS`](#cells) | Calculer une valeur agrégée pour n'importe quelle combinaison de nœuds |
| Métriques | [`METRIC`](#metric), [`METRIC_BREAKDOWN`](#metric_breakdown) | Lire une métrique métier gouvernée, telle que les tableaux de bord l'affichent |
| Blocs de construction | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Décrire la table, la mesure, l'agrégation, les nœuds et la profondeur de drill utilisés par `CELL`, `CELLS` et `DRILL` |

[Créer un rapport](/fr/reference/cli/plaidxl/build-a-report/) montre ces fonctions à l'œuvre ensemble.

## Fonctionnement des fonctions

- **Connectez-vous d'abord.** Les fonctions lisent les données avec votre connexion PlaidCloud et vos autorisations ; [connectez-vous](/fr/reference/cli/plaidxl/connect/) donc depuis le volet des tâches avant de les utiliser.
- **Elles lisent les données du projet du classeur.** Chaque fonction lit les données du projet associé au classeur dans le volet des tâches. `GET_TABLE`, `TBL_LIST` et `DIM_LIST` acceptent aussi un identifiant de projet facultatif, pour lire un autre projet sans modifier l'association. Chaque classeur a son propre projet : deux classeurs ouverts peuvent donc lire des projets différents.
- **Les résultats se répandent.** Une fonction qui renvoie une liste ou une table remplit les cellules situées en dessous (ou à droite). Laissez de la place pour les résultats ; si quelque chose gêne, Excel affiche une erreur `#SPILL!`.
- **Recalculez pour prendre en compte les modifications.** Une formule PlaidXL récupère de nouveau les données lorsqu'un de ses arguments change. Pour prendre en compte de nouvelles données dans PlaidCloud, ou un autre projet associé dans le volet des tâches, utilisez le menu **Actualiser** du ruban : **Recalculate PlaidXL formulas** recalcule toutes les formules PlaidXL du classeur, et **Refresh this sheet** et **Refresh selection** recalculent les formules qu'elles couvrent. **Refresh all tables** actualise les tables récupérées, et non les formules. Consultez [Actualiser](/fr/reference/cli/plaidxl/ribbon/#actualiser).
- **Utilisez les noms exacts.** Saisissez les noms de tables, de colonnes, de dimensions et de nœuds exactement tels qu'ils apparaissent dans PlaidCloud.

Les arguments entre crochets sont facultatifs.

## Listes

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Répertorie les noms des projets que vous pouvez ouvrir, triés par nom.

- `horizontal` : `TRUE` pour répertorier dans une ligne. La valeur par défaut est `FALSE`, une colonne.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Répertorie les noms des tables d'un projet, triés par nom.

- `project_id` : le projet à lire. Par défaut, le projet du classeur.
- `horizontal` : `TRUE` pour répertorier dans une ligne. La valeur par défaut est `FALSE`, une colonne.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Répertorie les noms des colonnes d'une table du projet sélectionné.

- `table_name` : le nom de la table dans PlaidCloud.
- `column_filter` : un type de données, tel que `"text"`, pour ne répertorier que les colonnes de ce type. Omettez-le pour répertorier toutes les colonnes.
- `orientation` : `"vertical"` (valeur par défaut) pour une colonne, ou `"horizontal"` pour une ligne.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Répertorie les noms des dimensions d'un projet.

- `project_id` : le projet à lire. Par défaut, le projet du classeur.
- `horizontal` : `TRUE` pour répertorier dans une ligne. La valeur par défaut est `FALSE`, une colonne.

## Tables

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Renvoie les lignes d'une table avec une ligne d'en-tête, répandues à partir de la cellule de la formule. Les valeurs vides sont renvoyées sous forme de cellules vides.

- `table_name` : le nom de la table dans PlaidCloud.
- `project_id` : le projet à lire. Par défaut, le projet du classeur.
- `limit` : le nombre maximal de lignes à renvoyer. La valeur par défaut est 1,048,575, le maximum qu'une feuille de calcul peut contenir sous une ligne d'en-tête.

`GET_TABLE` renvoie toutes les colonnes. Pour choisir des colonnes ou filtrer des lignes, [récupérez plutôt la table depuis le volet des tâches](/fr/reference/cli/plaidxl/retrieve/#récupérer-une-table).

## Hiérarchies

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Dispose les nœuds d'une dimension, à partir de `start_node` et en descendant dans ses descendants. Chaque génération est indentée de quatre espaces de plus que son parent, et les groupes de plan d'Excel vous permettent de réduire et de développer chaque niveau.

- `dimension_name` : le nom de la dimension, ou son chemin dans le projet.
- `start_node` : le nœud de départ, par exemple la racine de la dimension.
- `hierarchy` : la [hiérarchie alternative](/fr/guides/dimensions/dimensions/#hiérarchies-alternatives-dattributs) à suivre. Par défaut, `"main"`.
- `orientation` : `"vertical"` (valeur par défaut) pour répertorier les nœuds dans une colonne, ou `"horizontal"` pour les répertorier dans une ligne.
- `generation_limit` : le nombre de générations à renvoyer, en comptant `start_node` comme la première : `2` renvoie le nœud de départ et ses enfants. Omettez-le pour renvoyer toutes les générations.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy], [exclude], [expand], [orientation])`

Renvoie `start_node` et les nœuds situés en dessous que `drill_key` demande, indentés par génération et regroupés dans un plan Excel.

- `dimension_name` : le nom de la dimension, ou son chemin dans le projet.
- `start_node` : le nœud à partir duquel faire le drill. Laissez-le vide (`""`) pour partir des nœuds de plus haut niveau de la dimension. La dimension elle-même compte comme la génération 0 de la clé de drill et n'est pas répertoriée ; les nœuds de plus haut niveau sont donc la génération 1 : `>[1]` ne répertorie que les nœuds de plus haut niveau, et `>[0]` ne répertorie rien.
- `drill_key` : jusqu'où descendre, à partir de [`DRILL_KEY`](#drill_key) : tous les descendants, uniquement les feuilles, un nombre de niveaux ou une plage de générations.
- `hierarchy` : la hiérarchie alternative à suivre. Par défaut, `"main"`.
- `exclude` : les nœuds à exclure, avec tout ce qui se trouve en dessous : un nœud, une liste ou une plage de cellules. Le nœud de départ n'est jamais exclu.
- `expand` : les nœuds dont il faut aussi afficher les enfants, même en dessous de la profondeur demandée par `drill_key` : un nœud, une liste ou une plage de cellules. Seuls les nœuds affichés par le drill sont ouverts ; pour ouvrir un petit-enfant, indiquez aussi son parent.
- `orientation` : `"vertical"` (valeur par défaut) pour répertorier les nœuds dans une colonne, ou `"horizontal"` pour les répertorier dans une ligne, sans indentation et regroupés par colonne. Toute autre valeur provoque une erreur.

`exclude` et `expand` acceptent des identifiants de nœuds sous forme de texte ou de nombres ; les cellules vides et les erreurs d'une plage sont ignorées. Laissez un argument vide (`""`) pour l'ignorer, comme dans `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`.

Par exemple, `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` répertorie **Total** suivi de chaque région feuille située en dessous.

Les [commandes de drill](/fr/reference/cli/plaidxl/drill/) écrivent et modifient les formules `DRILL` pour vous : sélectionnez un nœud puis descendez, remontez, conservez ou supprimez des nœuds.

## Valeurs

`CELL` et `CELLS` calculent une mesure — une colonne numérique d'une table — agrégée jusqu'aux nœuds que vous choisissez dans une ou plusieurs dimensions. Considérez chaque appel comme une intersection d'un rapport : le **Chiffre d'affaires** pour **EMEA** en **FY2026**.

Vous décrivez l'intersection avec les fonctions de blocs de construction ci-dessous, généralement dans leurs propres cellules, puis vous passez ces cellules à `CELL` ou `CELLS` dans n'importe quel ordre :

| Argument | Construit avec | Obligatoire |
|---|---|---|
| La table à lire | [`TABLE_REPR`](#table_repr) | Exactement une |
| La colonne à agréger | [`MEASURE`](#measure) pour `CELL`, [`MEASURES`](#measures) ou plusieurs cellules `MEASURE` pour `CELLS` | Oui |
| Comment l'agréger | [`MEASURE_TYPE`](#measure_type) | Non — `sum` par défaut |
| Un filtre sur une colonne | [`DIMENSION_REPR`](#dimension_repr) | Au moins un, un par colonne |

Chaque filtre nomme une **colonne de la table** et une valeur. Lorsque cette colonne est liée à une dimension dans PlaidCloud, la valeur est un nœud, et le filtre inclut tout ce qui s'agrège jusqu'à ce nœud dans la hiérarchie principale de la dimension, ou dans la hiérarchie que vous nommez — sur une colonne **Region** liée à une dimension géographique, le nœud **EMEA** couvre tous les pays qui se trouvent en dessous. Sur une colonne qui n'est pas liée à une dimension, le filtre recherche la valeur exacte.

Les exemples de cette page utilisent une table dont les colonnes **Region** et **Period** sont liées à des dimensions. Utilisez les noms de colonnes de votre propre table.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Renvoie un nombre : la mesure, agrégée sur les lignes qui se trouvent sous chaque nœud que vous passez.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` affiche le chiffre d'affaires total pour EMEA en FY2026.

Saisissez un nombre par-dessus une formule `CELL` pour l'écrire dans PlaidCloud. Consultez [Saisir des valeurs dans PlaidCloud](/fr/reference/cli/plaidxl/write-values/).

Une feuille remplie de formules `CELL` se calcule rapidement : les formules `CELL` qui se calculent ensemble sont envoyées à PlaidCloud en une seule requête, jusqu'à 10,000 à la fois, et PlaidXL réutilise pendant 30 secondes les détails des colonnes d'une table au lieu de les récupérer pour chaque cellule. Si une valeur ne peut pas être calculée, la cellule affiche `#VALUE!` et le survol de la cellule indique la raison telle que PlaidCloud l'a signalée, par exemple une colonne de filtre absente de la table ou un nœud sans membres. `CELLS` affiche la première raison pour l'ensemble du résultat.

Lorsqu'aucune ligne ne correspond, une `sum` vaut `0`. Tout autre mode de combinaison (`mean`, `median`, `min`, `max`, `std` ou `var`) n'a aucune valeur à fournir : une formule `CELL` affiche `#VALUE!` avec **No value for** l'agrégation, les membres et la mesure au survol, et un élément de `CELLS` reste vide. Les fonctions Excel telles que `AVERAGE` ignorent un élément vide de `CELLS`, et **Expliquer** donne la même raison.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Comme `CELL`, mais pour plusieurs mesures à la fois. Renvoie un nombre par mesure, dans une colonne, dans l'ordre où vous les avez listées.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` passe tout le résultat répandu de `MEASURES`. `B2:B4` affichent le chiffre d'affaires, le coût et les unités pour EMEA en FY2026.

## Métriques

`METRIC` et `METRIC_BREAKDOWN` lisent une [définition de métrique](/fr/integrations/ai-coding-agents/metric-definitions/) du projet du classeur : un chiffre métier tel que *Net Revenue* dont le calcul est convenu et consigné dans PlaidCloud. La valeur est celle que les tableaux de bord affichent, calculée avec votre propre accès aux lignes. **Metric...** dans le ruban répertorie les métriques du projet avec leurs valeurs actuelles et écrit la formule pour vous ; consultez [Insérer une métrique](#insérer-une-métrique).

Les filtres sont des valeurs [`DIMENSION_REPR`](#dimension_repr), comme pour `CELL`, sauf que le premier argument nomme une colonne selon laquelle la métrique peut être ventilée. Un nœud inclut tout ce qui se trouve en dessous. Passez un seul filtre, ou une plage ou une liste de filtres ; les filtres vides sont ignorés. Une formule peut utiliser des filtres issus de plusieurs hiérarchies alternatives, et peut combiner un membre d'une hiérarchie alternative avec des membres d'autres dimensions.

### METRIC

`=PLAIDXL.METRIC(name, [filter], ...)`

Renvoie un nombre : la métrique, pour les lignes qui se trouvent sous chaque filtre que vous passez.

- `name` : le nom de la métrique, l'un de ses synonymes ou son identifiant. La casse n'a pas d'importance.
- `filter` : un filtre `DIMENSION_REPR`. Passez-en autant que nécessaire.

```text
=PLAIDXL.METRIC("Net Revenue", PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA"))
```

Lorsqu'aucune ligne ne correspond, `METRIC` renvoie `0` ; lorsque la métrique n'a pas de valeur, la cellule est vide.

### METRIC_BREAKDOWN

`=PLAIDXL.METRIC_BREAKDOWN(name, breakdown, [filter], ...)`

Renvoie la métrique ventilée selon une colonne : deux colonnes, chaque membre de `breakdown` à côté de sa valeur, de la plus grande valeur à la plus petite, sans ligne d'en-tête.

- `name` : le nom de la métrique, l'un de ses synonymes ou son identifiant.
- `breakdown` : la colonne selon laquelle ventiler la métrique, parmi celles que la métrique permet.
- `filter` : un filtre `DIMENSION_REPR`. Passez-en autant que nécessaire.

```text
=PLAIDXL.METRIC_BREAKDOWN("Net Revenue", "Region")
```

Les membres sans valeur arrivent en dernier, avec une valeur vide. Lorsqu'aucune ligne ne correspond, elle renvoie une seule ligne : un membre vide et `0`.

### Erreurs de métrique

Une métrique qui ne peut pas être calculée affiche `#VALUE!` ; survolez la cellule pour en connaître la raison :

| Message | Que faire |
|---|---|
| Métrique inconnue, ou colonne inconnue | Vérifiez le nom. Lorsqu'il existe des correspondances proches, le message les répertorie après **Did you mean**. |
| Le nom correspond à plusieurs métriques | Utilisez le nom complet de la métrique ou son identifiant. |
| **Your PlaidCloud role doesn't allow reading metrics in this project.** | Demandez l'accès à un propriétaire du projet. |
| **This PlaidCloud workspace doesn't serve metrics to Excel yet.** | Demandez à votre administrateur de mettre à jour l'espace de travail. |
| **PlaidCloud is busy; try again in** un nombre de secondes | PlaidXL a déjà réessayé. Recalculez après le délai indiqué. |
| **Choose a project in the PlaidXL pane first.** | Associez le classeur à un projet. |
| **This PlaidCloud workspace can't combine an alternate hierarchy with other members yet. Ask your administrator to update the workspace.** | Demandez à votre administrateur de mettre à jour l'espace de travail. Les autres cellules du même recalcul répondent quand même. |

## Blocs de construction

Ces fonctions ne lisent pas elles-mêmes de données. Chacune renvoie un court texte qui décrit une partie d'un calcul, prêt à être passé à `CELL`, `CELLS` ou `DRILL`. Placez-les dans des cellules que vous référencez, afin qu'une seule modification — une autre période, par exemple — mette à jour toutes les formules qui les utilisent.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

La table lue par `CELL` et `CELLS`, désignée par son nom dans le projet sélectionné.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

La colonne numérique que `CELL` agrège.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Plusieurs colonnes de mesures pour `CELLS`, à partir d'une plage de cellules contenant des noms de colonnes. Le résultat se répand en une cellule par colonne ; passez-le à `CELLS` avec l'opérateur de déversement, tel que `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Comment agréger la mesure. `agg_function` est l'une des valeurs suivantes, en minuscules :

| Valeur | Renvoie |
|---|---|
| `sum` | Le total (la valeur par défaut lorsque vous ne passez pas de type de mesure) |
| `mean` | La moyenne |
| `median` | La valeur médiane |
| `min` | La plus petite valeur |
| `max` | La plus grande valeur |
| `std` | L'écart type |
| `var` | La variance |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node, [hierarchy])`

Un filtre pour `CELL`, `CELLS`, `METRIC` et `METRIC_BREAKDOWN`. Passez-en un pour chaque colonne selon laquelle vous voulez filtrer.

- `dimension_name` : le nom d'une **colonne de la table** — la colonne qui contient les valeurs de la dimension, par exemple `"Region"`. Il doit correspondre exactement au nom de la colonne ; une colonne absente de la table provoque une erreur.
- `start_node` : le nœud jusqu'auquel agréger, par exemple `"EMEA"`. Sur une colonne qui n'est pas liée à une dimension, la valeur à rechercher.
- `hierarchy` : la hiérarchie alternative par laquelle agréger le nœud. Par défaut, `"main"`.

Référencez une cellule pour le nœud afin de construire une grille : `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Les espaces de début et de fin sont ignorés ; vous pouvez donc le faire pointer vers les noms de nœuds indentés que `DRILL` dispose.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Jusqu'où [`DRILL`](#drill) descend sous son nœud de départ. `d_key` est un texte brut, soit une forme en toutes lettres, soit une clé de drill écrite explicitement :

| `d_key` | Descend jusqu'à |
|---|---|
| `"all"` | Tous les descendants |
| `"leaves"` | Uniquement les feuilles, c'est-à-dire les nœuds sans rien en dessous |
| `"1 level"`, `"2 levels"`, … | Ce nombre de générations vers le bas |
| `">[...]"` | La clé de drill écrite explicitement, comme dans le tableau suivant |

Écrivez le nombre en chiffres : `"2 levels"`, et non `"two levels"`. Un `drill` initial est ignoré ; `"drill 2 levels"` fonctionne donc aussi.

Une clé écrite explicitement compte les générations en descendant depuis le nœud de départ, qui est la génération 0 et toujours inclus. Les nombres négatifs comptent en remontant depuis les feuilles de chaque branche, de sorte qu'une hiérarchie irrégulière fonctionne comme vous vous y attendez.

| Clé | Inclut |
|---|---|
| `>[*]` ou `>[:]` | Tous les nœuds |
| `>[]` ou `>[-1]` | Uniquement les feuilles |
| `>[n]` | Le nœud de départ et `n` générations en dessous. `>[0]` est le nœud de départ seul. |
| `>[a:]` | Le nœud de départ, puis la génération `a` et tout ce qui se trouve en dessous |
| `>[a:b]` | Le nœud de départ, puis les générations `a` jusqu'à `b - 1` |
| `>[0:-k]` | Le nœud de départ et chaque nœud qui a au moins `k` générations en dessous, de sorte que les `k` dernières générations de chaque branche sont écartées. `>[0:-1]` correspond à tous les nœuds sauf les feuilles. |
| `>[a:-k]` | Identique, en partant de la génération `a` |

Pour la hiérarchie `A`, avec les enfants `B`, `C` et `D`, où `B` a `B1` et `B2` et `C` a `C1` :

| Clé | Résultat |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Les nœuds sont répertoriés dans l'ordre de la hiérarchie, chacun sous son propre parent, et les groupes du plan Excel suivent le même ordre. Les espaces à l'intérieur d'une clé sont ignorés. Une clé qui ne correspond à aucune de ces formes renvoie une erreur qui répertorie les formes valides.

<Aside type="caution">
`>[-1]` et `>[0:-1]` ont un sens différent de celui des versions antérieures de PlaidXL, où ils étaient inversés. `>[-1]` renvoie désormais uniquement les feuilles, et `>[0:-1]` tout sauf les feuilles. Vérifiez tout classeur dans lequel une clé de drill a été écrite à la main. Les formes en toutes lettres `"all"`, `"leaves"` et `"2 levels"` n'ont pas changé.
</Aside>

<Aside type="note">
`CELL`, `CELLS` et `DRILL` attendent le résultat de ces fonctions de blocs de construction. Construisez chaque argument avec sa fonction plutôt que de saisir vous-même le texte.
</Aside>

## Insérer une formule depuis le volet des tâches

L'onglet **Formulas** du volet des tâches écrit une formule pour vous. Ouvrez-le depuis le volet des tâches, avec **Formula...** dans le ruban, ou avec **Insert formula here...** dans le menu contextuel **PlaidXL**. Sous **What do you want in the cell?**, choisissez l'une des options suivantes :

- **A whole table** (`GET_TABLE`) : choisissez ou saisissez la table, et éventuellement un nombre maximal de lignes.
- **One number** (`CELL`) : choisissez ou saisissez la table, puis choisissez **Column to total** et **How to combine the values**.
- **A list of dimension nodes** (`DRILL`) : choisissez ou saisissez la dimension et le nœud de départ, choisissez jusqu'où descendre, et éventuellement une **Hiérarchie alternative**, des nœuds à exclure et des nœuds à ouvrir. **Lignes** affiche un aperçu des nœuds que le drill répertorie. Consultez [Drill personnalisé](/fr/reference/cli/plaidxl/drill/#custom-drill).
- **A business metric** (`METRIC`) : consultez [Insérer une métrique](#insérer-une-métrique).

L'aperçu **Formula** affiche le résultat au fur et à mesure que vous remplissez les champs. Cliquez sur **Insert in active cell** (ou appuyez sur **Ctrl+Enter**) pour la placer dans la cellule sélectionnée, ou sur **Copier** pour la coller vous-même. Le choix d'une table dans l'onglet **Tables** ou d'une dimension dans l'onglet **Dimensions** renseigne le champ correspondant.

### Insérer une métrique

Cliquez sur **Metric...** dans le groupe **Insérer** du ruban, ou choisissez **A business metric** dans l'onglet **Formulas**.

1. Dans **Metric**, saisissez une partie du nom ou d'un synonyme d'une métrique, par exemple `revenue`. Chaque correspondance affiche sa valeur actuelle et sa description.
2. Utilisez les touches fléchées ou cliquez pour choisir une métrique.
3. Si vous le souhaitez, ajoutez des filtres : choisissez une **Dimension**, saisissez un **Nœud** et cliquez sur **Ajouter un filtre**.
4. Si vous le souhaitez, choisissez une colonne sous **Breakdown by (optional)** pour écrire `METRIC_BREAKDOWN` au lieu d'un seul nombre.
5. Cliquez sur **Insert in active cell**, ou sur **Copier**.
