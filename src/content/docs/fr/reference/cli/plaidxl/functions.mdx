PlaidXL ajoute à Excel des fonctions qui lisent les données PlaidCloud directement dans les cellules. Saisissez `=PLAIDXL.` dans une cellule et la saisie semi-automatique d'Excel les liste, avec une courte description de chaque argument. L'onglet **Formulas** du volet des tâches peut aussi en écrire une à votre place ; consultez [Insérer une formule depuis le volet des tâches](#insérer-une-formule-depuis-le-volet-des-tâches).

| Groupe | Fonctions | À utiliser pour |
|---|---|---|
| Listes | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Voir ce qui est disponible pour construire un rapport |
| Tables | [`TABLE.GET_TABLE`](#get_table) | Lire une table entière dans une plage |
| Hiérarchies | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Mettre en page les nœuds d'une dimension comme lignes de rapport |
| Valeurs | [`CELL`](#cell), [`CELLS`](#cells) | Calculer une valeur consolidée pour n'importe quelle combinaison de nœuds |
| Métriques | [`METRIC`](#metric), [`METRIC_BREAKDOWN`](#metric_breakdown) | Lire une métrique métier gouvernée, telle que l'affichent les tableaux de bord |
| Éléments de base | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Décrire la table, la mesure, l'agrégation, les nœuds et la profondeur d'exploration qu'utilisent `CELL`, `CELLS` et `DRILL` |

[Build a Report](/fr/reference/cli/plaidxl/build-a-report/) montre ces fonctions à l'œuvre ensemble.

## Fonctionnement des fonctions

- **Connectez-vous d'abord.** Les fonctions lisent les données avec votre connexion PlaidCloud et vos autorisations ; [connectez-vous](/fr/reference/cli/plaidxl/connect/) donc depuis le volet des tâches avant de les utiliser.
- **Elles lisent le projet du classeur.** Chaque fonction lit le projet lié au classeur dans le volet des tâches. `GET_TABLE`, `TBL_LIST` et `DIM_LIST` acceptent aussi un identifiant de projet facultatif, pour lire un autre projet sans modifier le lien. Chaque classeur a son propre projet : deux classeurs ouverts peuvent donc lire des projets différents.
- **Les résultats se déversent.** Une fonction qui renvoie une liste ou une table remplit les cellules situées en dessous (ou à sa droite). Laissez de la place pour les résultats ; si quelque chose gêne, Excel affiche une erreur `#SPILL!`.
- **Recalculez pour prendre en compte les changements.** Une formule PlaidXL récupère à nouveau les données lorsque l'un de ses arguments change. Pour prendre en compte de nouvelles données dans PlaidCloud, ou un autre projet lié dans le volet des tâches, utilisez le menu **Actualiser** du ruban : **Recalculate PlaidXL formulas** recalcule toutes les formules PlaidXL du classeur, et **Refresh this sheet** et **Refresh selection** recalculent les formules qu'ils couvrent. **Refresh all tables** actualise les tables récupérées, pas les formules. Consultez [Refresh](/fr/reference/cli/plaidxl/ribbon/#actualiser).
- **Utilisez les noms exacts.** Saisissez les noms de tables, de colonnes, de dimensions et de nœuds exactement tels qu'ils apparaissent dans PlaidCloud.

Les arguments entre crochets sont facultatifs.

## Listes

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Liste les noms des projets que vous pouvez ouvrir, triés par nom.

- `horizontal` : `TRUE` pour lister sur une ligne. La valeur par défaut est `FALSE`, une colonne.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Liste les noms des tables d'un projet, triés par nom.

- `project_id` : le projet à lire. Par défaut, le projet du classeur.
- `horizontal` : `TRUE` pour lister sur une ligne. La valeur par défaut est `FALSE`, une colonne.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Liste les noms des colonnes d'une table du projet sélectionné.

- `table_name` : le nom de la table dans PlaidCloud.
- `column_filter` : un type de données, comme `"text"`, pour ne lister que les colonnes de ce type. Omettez-le pour lister toutes les colonnes.
- `orientation` : `"vertical"` (par défaut) pour une colonne, ou `"horizontal"` pour une ligne.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Liste les noms des dimensions d'un projet.

- `project_id` : le projet à lire. Par défaut, le projet du classeur.
- `horizontal` : `TRUE` pour lister sur une ligne. La valeur par défaut est `FALSE`, une colonne.

## Tables

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Renvoie les lignes d'une table avec une ligne d'en-tête, déversées à partir de la cellule de la formule. Les valeurs vides sont renvoyées sous forme de cellules vides.

- `table_name` : le nom de la table dans PlaidCloud.
- `project_id` : le projet à lire. Par défaut, le projet du classeur.
- `limit` : le nombre maximal de lignes à renvoyer. La valeur par défaut est 1 048 575, le maximum qu'une feuille de calcul peut contenir sous une ligne d'en-tête.

`GET_TABLE` renvoie toutes les colonnes. Pour choisir des colonnes ou filtrer des lignes, [récupérez plutôt la table depuis le volet des tâches](/fr/reference/cli/plaidxl/retrieve/#récupérer-une-table).

## Hiérarchies

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Met en page les nœuds d'une dimension, en partant de `start_node` et en descendant dans ses descendants. Chaque génération est décalée de quatre espaces de plus que son parent, et des groupes de plan Excel permettent de réduire et de développer chaque niveau.

- `dimension_name` : le nom de la dimension, ou son chemin dans le projet.
- `start_node` : le nœud de départ, par exemple la racine de la dimension.
- `hierarchy` : la [hiérarchie alternative](/fr/guides/dimensions/dimensions/#hiérarchies-alternatives-dattributs) à suivre. Par défaut, `"main"`.
- `orientation` : `"vertical"` (par défaut) pour lister les nœuds dans une colonne, ou `"horizontal"` pour les lister sur une ligne.
- `generation_limit` : le nombre de générations à renvoyer, `start_node` comptant pour la première : `2` renvoie le nœud de départ et ses enfants. Omettez-le pour renvoyer toutes les générations.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy], [exclude], [expand], [orientation])`

Renvoie `start_node` et les nœuds situés en dessous que demande `drill_key`, en retrait selon la génération et regroupés dans un plan Excel.

- `dimension_name` : le nom de la dimension, ou son chemin dans le projet.
- `start_node` : le nœud à partir duquel explorer. Laissez-le vide (`""`) pour partir des nœuds supérieurs de la dimension.
- `drill_key` : la profondeur d'exploration, fournie par [`DRILL_KEY`](#drill_key) : tous les descendants, uniquement les feuilles, un nombre de niveaux ou une plage de générations.
- `hierarchy` : la hiérarchie alternative à suivre. Par défaut, `"main"`.
- `exclude` : les nœuds à laisser de côté, avec tout ce qui se trouve en dessous : un nœud, une liste ou une plage de cellules. Le nœud de départ n'est jamais exclu.
- `expand` : les nœuds dont il faut aussi afficher les enfants, même en dessous de la profondeur demandée par `drill_key` : un nœud, une liste ou une plage de cellules. Seuls les nœuds que l'exploration affiche sont ouverts ; pour ouvrir un petit-enfant, indiquez donc aussi son parent.
- `orientation` : `"vertical"` (par défaut) pour lister les nœuds dans une colonne, ou `"horizontal"` pour les lister sur une ligne, sans retrait et regroupés par colonne.

`exclude` et `expand` acceptent des identifiants de nœuds sous forme de texte ou de nombres ; les cellules vides et les erreurs d'une plage sont ignorées. Laissez un argument vide (`""`) pour l'ignorer, comme dans `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`.

Par exemple, `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` liste **Total** suivi de chaque région feuille située en dessous.

Les [commandes d'exploration](/fr/reference/cli/plaidxl/drill/) écrivent et modifient les formules `DRILL` à votre place : sélectionnez un nœud et explorez vers le bas ou vers le haut, conservez ou supprimez des nœuds.

## Valeurs

`CELL` et `CELLS` calculent une mesure (une colonne numérique d'une table) consolidée jusqu'aux nœuds que vous choisissez dans une ou plusieurs dimensions. Considérez chaque appel comme une intersection d'un rapport : le **Chiffre d'affaires** pour **EMEA** en **FY2026**.

Vous décrivez l'intersection avec les fonctions d'éléments de base ci-dessous, généralement dans leurs propres cellules, puis vous transmettez ces cellules à `CELL` ou `CELLS` dans n'importe quel ordre :

| Argument | Construit avec | Obligatoire |
|---|---|---|
| La table à lire | [`TABLE_REPR`](#table_repr) | Exactement un |
| La colonne à agréger | [`MEASURE`](#measure) pour `CELL`, [`MEASURES`](#measures) ou plusieurs cellules `MEASURE` pour `CELLS` | Oui |
| Comment l'agréger | [`MEASURE_TYPE`](#measure_type) | Non : `sum` par défaut |
| Un filtre sur une colonne | [`DIMENSION_REPR`](#dimension_repr) | Au moins un, un par colonne |

Chaque filtre désigne une **colonne de la table** et une valeur. Lorsque cette colonne est liée à une dimension dans PlaidCloud, la valeur est un nœud, et le filtre inclut tout ce qui se consolide jusqu'à ce nœud dans la hiérarchie principale de la dimension, ou dans la hiérarchie que vous indiquez : sur une colonne **Region** liée à une dimension géographique, le nœud **EMEA** couvre chaque pays situé en dessous. Sur une colonne qui n'est pas liée à une dimension, le filtre recherche une correspondance exacte avec la valeur.

Les exemples de cette page utilisent une table dont les colonnes **Region** et **Period** sont liées à des dimensions. Utilisez les noms de colonnes de votre propre table.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Renvoie un seul nombre : la mesure, agrégée sur les lignes qui se trouvent sous chaque nœud transmis.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` affiche le chiffre d'affaires total pour EMEA en FY2026.

Saisissez un nombre par-dessus une formule `CELL` pour l'écrire dans PlaidCloud. Consultez [Type Values Into PlaidCloud](/fr/reference/cli/plaidxl/write-values/).

Une feuille remplie de formules `CELL` se calcule rapidement : les formules `CELL` qui se calculent ensemble sont envoyées à PlaidCloud en une seule requête, par lots de 10 000 au maximum, et PlaidXL réutilise pendant 30 secondes les détails des colonnes d'une table au lieu de les récupérer pour chaque cellule. Si une valeur ne peut pas être calculée, la cellule affiche `#VALUE!` et le survol indique la raison telle que PlaidCloud l'a signalée, par exemple une colonne de filtre absente de la table ou un nœud sans membres. `CELLS` affiche la première raison pour l'ensemble du résultat.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Comme `CELL`, mais pour plusieurs mesures à la fois. Renvoie un nombre par mesure, dans une colonne, dans l'ordre où vous les avez listées.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` transmet l'intégralité du résultat déversé de `MEASURES`. `B2:B4` affichent revenue, cost et units pour EMEA en FY2026.

## Métriques

`METRIC` et `METRIC_BREAKDOWN` lisent une [définition de métrique](/fr/integrations/ai-coding-agents/metric-definitions/) du projet du classeur : un chiffre métier comme *Net Revenue* dont le calcul est convenu et consigné dans PlaidCloud. La valeur est celle qu'affichent les tableaux de bord et Weave, calculée selon votre propre accès aux lignes. **Metric...** dans le ruban liste les métriques du projet avec leurs valeurs actuelles et écrit la formule à votre place ; consultez [Insérer une métrique](#insérer-une-métrique).

Les filtres sont des valeurs [`DIMENSION_REPR`](#dimension_repr), comme pour `CELL`, sauf que le premier argument peut désigner soit une colonne selon laquelle la métrique peut être ventilée, soit la dimension qui lui est liée. Un nœud inclut tout ce qui se trouve en dessous. Transmettez un seul filtre, ou une plage ou une liste de filtres ; les filtres vides sont ignorés. Une même formule peut utiliser une seule hiérarchie alternative.

### METRIC

`=PLAIDXL.METRIC(name, [filter], ...)`

Renvoie un seul nombre : la métrique, pour les lignes situées sous chaque filtre transmis.

- `name` : le nom de la métrique, l'un de ses synonymes ou son identifiant. La casse n'a pas d'importance.
- `filter` : un filtre `DIMENSION_REPR`. Transmettez-en autant que nécessaire.

```text
=PLAIDXL.METRIC("Net Revenue", PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA"))
```

Lorsqu'aucune ligne ne correspond, `METRIC` renvoie `0` ; lorsque la métrique n'a pas de valeur, la cellule est vide.

### METRIC_BREAKDOWN

`=PLAIDXL.METRIC_BREAKDOWN(name, breakdown, [filter], ...)`

Renvoie la métrique ventilée selon une colonne : deux colonnes, chaque membre de `breakdown` à côté de sa valeur, la valeur la plus élevée en premier. Tous les membres sont listés, sans ligne d'en-tête.

- `name` : le nom de la métrique, l'un de ses synonymes ou son identifiant.
- `breakdown` : la colonne selon laquelle ventiler la métrique, parmi celles qu'elle accepte.
- `filter` : un filtre `DIMENSION_REPR`. Transmettez-en autant que nécessaire.

```text
=PLAIDXL.METRIC_BREAKDOWN("Net Revenue", "Region")
```

Les membres sans valeur arrivent en dernier, avec une valeur vide. Lorsqu'aucune ligne ne correspond, elle renvoie une seule ligne : un membre vide et `0`.

### Erreurs de métrique

Une métrique qui ne peut pas être calculée affiche `#VALUE!` ; survolez la cellule pour en connaître la raison :

| Message | Que faire |
|---|---|
| Métrique inconnue, ou colonne inconnue | Vérifiez le nom. Lorsqu'il existe des correspondances proches, le message les liste après **Did you mean**. |
| Le nom correspond à plusieurs métriques | Utilisez le nom complet de la métrique ou son identifiant. |
| **Your PlaidCloud role doesn't allow reading metrics in this project.** | Demandez l'accès à un propriétaire du projet. |
| **This PlaidCloud workspace doesn't serve metrics to Excel yet.** | Demandez à votre administrateur de mettre à jour l'espace de travail. |
| **PlaidCloud is busy; try again in** un nombre de secondes | PlaidXL a déjà réessayé. Recalculez après le délai indiqué. |
| **Choose a project in the PlaidXL pane first.** | Liez le classeur à un projet. |

## Éléments de base

Ces fonctions ne lisent pas elles-mêmes de données. Chacune renvoie un court texte qui décrit une partie d'un calcul, prêt à être transmis à `CELL`, `CELLS` ou `DRILL`. Placez-les dans des cellules que vous référencez, de sorte qu'un seul changement (une autre période, par exemple) mette à jour toutes les formules qui les utilisent.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

La table que lisent `CELL` et `CELLS`, désignée par son nom dans le projet sélectionné.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

La colonne numérique que `CELL` agrège.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Plusieurs colonnes de mesure pour `CELLS`, à partir d'une plage de cellules contenant des noms de colonnes. Le résultat se déverse dans une cellule par colonne ; transmettez-le à `CELLS` avec l'opérateur de déversement, comme `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

La manière d'agréger la mesure. `agg_function` est l'une des valeurs suivantes, en minuscules :

| Valeur | Renvoie |
|---|---|
| `sum` | Le total (valeur par défaut lorsque vous ne transmettez pas de type de mesure) |
| `mean` | La moyenne |
| `median` | La valeur médiane |
| `min` | La plus petite valeur |
| `max` | La plus grande valeur |
| `std` | L'écart type |
| `var` | La variance |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node, [hierarchy])`

Un filtre pour `CELL`, `CELLS`, `METRIC` et `METRIC_BREAKDOWN`. Transmettez-en un pour chaque colonne selon laquelle vous voulez filtrer.

- `dimension_name` : le nom d'une **colonne de la table**, celle qui contient les valeurs de la dimension, comme `"Region"`. Il doit correspondre exactement au nom de la colonne ; une colonne absente de la table renvoie une erreur.
- `start_node` : le nœud jusqu'auquel consolider, comme `"EMEA"`. Sur une colonne qui n'est pas liée à une dimension, la valeur à faire correspondre.
- `hierarchy` : la hiérarchie alternative à travers laquelle consolider le nœud. Par défaut, `"main"`.

Référencez une cellule pour le nœud afin de construire une grille : `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Les espaces de début et de fin sont ignorés : vous pouvez donc la faire pointer vers les noms de nœuds en retrait que met en page `DRILL`.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

La profondeur jusqu'à laquelle [`DRILL`](#drill) descend sous son nœud de départ. `d_key` est du texte brut, soit une forme en toutes lettres, soit une clé d'exploration écrite explicitement :

| `d_key` | Explore jusqu'à |
|---|---|
| `"all"` | Tous les descendants |
| `"leaves"` | Uniquement les feuilles, c'est-à-dire les nœuds sans rien en dessous |
| `"1 level"`, `"2 levels"`, … | Ce nombre de générations vers le bas |
| `">[...]"` | La clé d'exploration écrite explicitement, comme dans le tableau suivant |

Écrivez le nombre en chiffres : `"2 levels"`, et non `"two levels"`. Un `drill` en tête est ignoré : `"drill 2 levels"` fonctionne donc aussi.

Une clé écrite explicitement compte les générations en descendant à partir du nœud de départ, qui est la génération 0 et toujours inclus. Les nombres négatifs comptent en remontant depuis les feuilles de chaque branche, de sorte qu'une hiérarchie irrégulière fonctionne comme on s'y attend.

| Clé | Inclut |
|---|---|
| `>[*]` ou `>[:]` | Tous les nœuds |
| `>[]` ou `>[-1]` | Uniquement les feuilles |
| `>[n]` | Le nœud de départ et `n` générations en dessous. `>[0]` est le nœud de départ seul. |
| `>[a:]` | Le nœud de départ, puis la génération `a` et tout ce qui se trouve en dessous |
| `>[a:b]` | Le nœud de départ, puis les générations de `a` jusqu'à `b - 1` |
| `>[0:-k]` | Le nœud de départ et tous les nœuds qui ont au moins `k` générations en dessous, de sorte que les `k` dernières générations de chaque branche sont écartées. `>[0:-1]` correspond à tous les nœuds sauf les feuilles. |
| `>[a:-k]` | Idem, en commençant à la génération `a` |

Pour la hiérarchie `A`, avec les enfants `B`, `C` et `D`, où `B` a `B1` et `B2` et `C` a `C1` :

| Clé | Résultat |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Les nœuds sont listés dans l'ordre de la hiérarchie, chacun sous son propre parent, et les groupes du plan Excel suivent le même ordre. Les espaces à l'intérieur d'une clé sont ignorés. Une clé qui ne correspond à aucune de ces formes renvoie une erreur qui liste les formes valides.

<Aside type="caution">
`>[-1]` et `>[0:-1]` ont un sens différent de celui des versions précédentes de PlaidXL, où ils étaient inversés. `>[-1]` renvoie désormais uniquement les feuilles, et `>[0:-1]` tout sauf les feuilles. Vérifiez tout classeur dans lequel une clé d'exploration a été écrite à la main. Les formes en toutes lettres `"all"`, `"leaves"` et `"2 levels"` n'ont pas changé.
</Aside>

<Aside type="note">
`CELL`, `CELLS` et `DRILL` attendent le résultat de ces fonctions d'éléments de base. Construisez chaque argument avec sa fonction plutôt que de saisir vous-même le texte.
</Aside>

## Insérer une formule depuis le volet des tâches

L'onglet **Formulas** du volet des tâches écrit une formule à votre place. Ouvrez-le depuis le volet des tâches, avec **Formula...** dans le ruban, ou avec **Insert formula here...** dans le menu contextuel **PlaidXL**. Sous **What do you want in the cell?**, faites un choix :

- **A whole table** (`GET_TABLE`) : choisissez ou saisissez la table, et éventuellement un nombre maximal de lignes.
- **One number** (`CELL`) : choisissez ou saisissez la table, puis choisissez la **Column to total** et **How to combine the values**.
- **A list of dimension nodes** (`DRILL`) : choisissez ou saisissez la dimension et le nœud de départ, choisissez la profondeur d'exploration, et éventuellement une **Hiérarchie alternative**, des nœuds à exclure et des nœuds à ouvrir. **Lignes** affiche un aperçu des nœuds que liste l'exploration. Consultez [Custom Drill](/fr/reference/cli/plaidxl/drill/#exploration-personnalisée).
- **A business metric** (`METRIC`) : consultez [Insérer une métrique](#insérer-une-métrique).

L'aperçu **Formula** affiche le résultat à mesure que vous renseignez les champs. Cliquez sur **Insert in active cell** (ou appuyez sur **Ctrl+Entrée**) pour le placer dans la cellule sélectionnée, ou sur **Copier** pour le coller vous-même. Choisir une table dans l'onglet **Tables** ou une dimension dans l'onglet **Dimensions** renseigne le champ correspondant.

### Insérer une métrique

Cliquez sur **Metric...** dans le groupe **Insérer** du ruban, ou choisissez **A business metric** dans l'onglet **Formulas**.

1. Dans **Metric**, saisissez une partie du nom ou d'un synonyme d'une métrique, par exemple `revenue`. Chaque résultat affiche sa valeur actuelle et sa description.
2. Utilisez les touches fléchées ou cliquez pour choisir une métrique.
3. Si vous le souhaitez, ajoutez des filtres : choisissez une **Dimension**, saisissez un **Nœud** et cliquez sur **Ajouter un filtre**.
4. Si vous le souhaitez, choisissez une colonne sous **Breakdown by (optional)** pour écrire `METRIC_BREAKDOWN` à la place d'un nombre unique.
5. Cliquez sur **Insert in active cell**, ou sur **Copier**.
