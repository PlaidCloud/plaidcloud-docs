Un rapport PlaidXL est une grille Excel ordinaire§N: les nœuds d'une dimension sur le côté, les nœuds d'une autre dimension en haut, et une formule `PLAIDXL.CELL` à chaque intersection qui consolide une mesure à partir d'une table PlaidCloud. Comme les chiffres sont des formules, le rapport se recalcule à partir des données actuelles au lieu d'être reconstruit chaque mois.

## Avant de commencer

- [Connectez-vous](/fr/reference/cli/plaidxl/connect/) et sélectionnez le projet qui contient vos données. Le classeur le mémorise.
- Vous avez besoin d'une table avec une colonne numérique sur laquelle établir le rapport, par exemple **revenue**, et d'une colonne pour chaque dimension selon laquelle vous établirez le rapport, par exemple **Region** et **Period**, liée à cette dimension dans PlaidCloud. `CELL` filtre par nom de colonne et ne consolide un nœud à travers sa dimension que sur une colonne liée. Consultez [Valeurs](/fr/reference/cli/plaidxl/functions/#valeurs).
- Vous ne connaissez pas les noms exacts§N? `=PLAIDXL.TABLE.TBL_LIST()`, `=PLAIDXL.TABLE.GET_COLUMNS("Sales")` et `=PLAIDXL.DIMENSION.DIM_LIST()` les listent dans une feuille de travail.

## Créer le rapport

Les étapes utilisent une table nommée **Sales** avec la colonne de mesure **revenue** et les colonnes de dimension **Region** (lignes) et **Period** (colonnes), liées à des dimensions du même nom. Remplacez ces noms par les vôtres — dans `DRILL`, utilisez le nom de la dimension, et dans `DIMENSION_REPR`, le nom de colonne de la table.

<Steps>

1. **Décrivez ce que vous mesurez.** Dans trois cellules en haut de la feuille, saisissez§N:

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   Chaque valeur du rapport fait référence à ces cellules§T; en modifier une — `"mean"` au lieu de `"sum"`, par exemple — modifie donc l'ensemble du rapport.

2. **Disposez les lignes.** Dans `A6`, explorez la dimension des lignes à partir de son nœud supérieur§N:

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **Total** et ses enfants se répartissent vers le bas dans la colonne A, en retrait sous leur parent et regroupés pour que vous puissiez les réduire. Utilisez `"all"` pour tous les niveaux, ou `"leaves"` pour le niveau le plus bas uniquement. Pour un contrôle plus fin, par exemple tous les niveaux sauf les feuilles, écrivez la clé en toutes lettres§N: `>[0:-1]`. Consultez [`DRILL_KEY`](/fr/reference/cli/plaidxl/functions/#drill_key). Pour saisir vous-même les nœuds des lignes, placez un nom de nœud dans chaque cellule.

3. **Disposez les colonnes.** Saisissez les nœuds des colonnes sur la ligne 5, à partir de `B5` — par exemple `FY2025` et `FY2026`.

4. **Remplissez la première valeur.** Dans `B6`, saisissez§N:

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   Les signes `$` fixent la table, la mesure et le type, le nœud de ligne dans la colonne A et le nœud de colonne dans la ligne 5. Le retrait que `DRILL` ajoute aux noms de nœuds est ignoré.

5. **Remplissez la grille.** Copiez `B6` vers la droite jusqu'à votre dernière période et vers le bas jusqu'à votre dernière ligne. Chaque cellule affiche le chiffre d'affaires de la région de sa ligne pour la période de sa colonne.

</Steps>

Pour ajouter un filtre qui s'applique à l'ensemble du rapport — une seule gamme de produits, par exemple — ajoutez un autre `DIMENSION_REPR` dans une cellule en haut, comme `B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`, et transmettez `$B$4` à chaque `CELL`.

Pour afficher plusieurs mesures pour chaque ligne, utilisez [`PLAIDXL.CELLS`](/fr/reference/cli/plaidxl/functions/#cells) avec [`PLAIDXL.REPR.MEASURES`](/fr/reference/cli/plaidxl/functions/#measures).

## Garder le rapport à jour

- **Forcez un recalcul complet** pour récupérer les valeurs actuelles dans chaque formule PlaidXL — sous Windows, appuyez sur **Ctrl+Alt+F9**. Un recalcul ordinaire ne récupère pas les données de nouveau, sauf si les arguments d'une formule ont changé.
- **Modifiez le périmètre** en changeant une cellule de base§N: une autre table, une autre mesure ou une autre agrégation, ou un autre nœud de filtre de niveau supérieur. Les formules qui utilisent la cellule se mettent à jour immédiatement.
- **Établissez le rapport sur un autre projet** en le sélectionnant dans le volet des tâches, puis en forçant un recalcul complet. Les formules lisent les données du projet du classeur§T; le même classeur peut donc servir de rapport pour chaque projet qui partage les mêmes noms de table, de colonne et de dimension.

## Partager une copie contenant uniquement des valeurs

Les personnes qui n'ont pas PlaidXL, ou qui n'ont pas accès au projet, voient des erreurs à la place des formules PlaidXL. Pour leur envoyer les chiffres, remplacez d'abord les formules par leurs valeurs§N:

1. Enregistrez votre rapport, puis enregistrez une copie sous un nouveau nom pour l'envoi.
2. Dans la copie, cliquez sur **PlaidCloud → Convert to values (for sharing)** et confirmez.
3. Envoyez la copie.

**Convert to values (for sharing)** remplace chaque formule PlaidXL du classeur par sa valeur actuelle et laisse les autres formules telles quelles. **Restore PlaidXL formulas** remet en place les formules PlaidXL, mais il ne restaure pas correctement les formules dont les résultats se répartissent sur plusieurs cellules, comme `DRILL`, et il écrase tout ce que vous avez modifié après la conversion. Conservez votre original — c'est le moyen fiable de retrouver votre rapport dynamique. Consultez [Share](/fr/reference/cli/plaidxl/ribbon/#partager).

<Aside type="caution">Convertissez la copie que vous envoyez, jamais votre unique rapport de travail.</Aside>
