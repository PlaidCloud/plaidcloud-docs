L'installation de PlaidXL ajoute un onglet **PlaidCloud** au ruban Excel, avec six groupes de commandes : **Connecter**, **Insérer**, **Actualiser**, **Drill**, **Écriture** et **Partager**. Les plus courantes figurent aussi dans le menu contextuel **PlaidXL** et dans l'onglet **PlaidXL Cell**, et chaque commande dotée d'un raccourci clavier l'affiche dans son info-bulle.

Aucune commande n'est jamais grisée. Une commande agit sur la formule, la table ou le nœud PlaidXL le plus proche de la cellule sélectionnée et, lorsqu'il n'y a rien sur quoi elle puisse agir, elle ouvre la partie du volet des tâches qui vous aide à la place.

Si vous exécutez une commande alors que vous êtes déconnecté, ou avant que le classeur soit associé à un projet, PlaidXL ouvre le volet des tâches et indique **Sign in to run** la commande, ou **Pick a project to run** la commande. Une fois que vous êtes connecté, la commande s'exécute sur la cellule à partir de laquelle vous avez commencé. Si vous êtes passé à une autre feuille ou avez choisi un autre projet entre-temps, elle ne s'exécute pas et PlaidXL vous le signale.

## Connecter

| Commande | Fonction |
|---|---|
| **Open PlaidXL** | Ouvre le volet des tâches PlaidXL. |
| **Compte** | Ouvre le volet des tâches pour vous connecter, ou pour choisir votre espace de travail et votre projet. |
| **Shortcuts** | Répertorie les raccourcis clavier de PlaidXL afin que vous puissiez les modifier. Consultez [Raccourcis clavier](#raccourcis-clavier). |
| **Help** | Ouvre cette documentation. |

## Insérer

| Commande | Fonction |
|---|---|
| **Table...** | Ouvre l'onglet **Tables** pour [récupérer une table](/fr/reference/cli/plaidxl/retrieve/#récupérer-une-table). |
| **Dimension...** | Ouvre l'onglet **Dimensions** pour récupérer une dimension ou choisir ses membres. |
| **Formula...** | Ouvre l'onglet **Formulas** pour [créer une formule PlaidXL](/fr/reference/cli/plaidxl/functions/#insérer-une-formule-depuis-le-volet-des-tâches) pour la cellule sélectionnée. |
| **Pick member...** | Ouvre le sélecteur de membres sur la dimension de la cellule sélectionnée. Consultez [Choisir un membre](/fr/reference/cli/plaidxl/drill/#choisir-un-membre). |
| **Metric...** | Ouvre une liste de recherche des métriques de votre projet, avec leurs valeurs actuelles. Consultez [Insérer une métrique](/fr/reference/cli/plaidxl/functions/#insérer-une-métrique). |
| **Build report...** | Ouvre l'onglet **Rapport** pour concevoir un rapport dynamique. Consultez [Créer un rapport](/fr/reference/cli/plaidxl/build-a-report/). |
| **Demander à Weave...** | Ouvre l'onglet **Weave** avec la cellule sélectionnée comme contexte. Consultez [Demander à Weave dans Excel](/fr/reference/cli/plaidxl/weave/). |

## Actualiser

Le menu **Actualiser** contient quatre commandes :

| Commande | Fonction |
|---|---|
| **Refresh this sheet** | Recalcule les formules PlaidXL de la feuille active et récupère de nouveau ses tables. |
| **Refresh selection** | Recalcule les formules PlaidXL de la sélection et récupère de nouveau toute table touchée par la sélection. Si aucun élément PlaidXL n'est sélectionné, elle actualise la feuille. |
| **Refresh all tables** | Récupère de nouveau toutes les tables et toutes les dimensions du classeur, avec les colonnes et le filtre que vous avez choisis pour chacune. |
| **Recalculate PlaidXL formulas** | Recalcule toutes les formules PlaidXL du classeur. |

Consultez [Actualiser les tables](/fr/reference/cli/plaidxl/retrieve/#actualiser-toutes-les-tables) pour savoir ce que vous voyez pendant une actualisation.

**Recalculate PlaidXL formulas** recalcule uniquement les formules PlaidXL, sans recalcul complet d'Excel. Lorsqu'elle est terminée, elle répertorie les feuilles qu'elle a recalculées et efface l'historique d'annulation d'Excel. PlaidXL conserve les détails des colonnes d'une table pendant 30 secondes ; une colonne ou une dimension que vous avez renommée au cours des 30 dernières secondes peut donc mettre un peu plus de temps à apparaître.

## Drill

| Commande | Fonction |
|---|---|
| **Drill down** | Un menu : **One level**, **To lowest level**, **All levels** et **Custom drill...** disposent les nœuds situés sous le nœud sélectionné. |
| **Drill up** | Replie le nœud sélectionné sur son parent. |
| **Keep only** | Conserve uniquement les nœuds sélectionnés dans le drill. |
| **Remove only** | Supprime du drill les nœuds sélectionnés, ainsi que tout ce qui se trouve en dessous. |
| **Show detail rows** | Place les lignes de la table qui sous-tendent la valeur sélectionnée dans une feuille distincte. |
| **Explain this number** | Indique d'où provient la valeur sélectionnée. |

Sélectionnez une seule cellule pour faire un drill : les commandes de drill la transforment en formule `PLAIDXL.DRILL` dynamique. Consultez [Drill, choix de membres et explication des nombres](/fr/reference/cli/plaidxl/drill/).

## Écriture

| Commande | Fonction |
|---|---|
| **Save sheet to PlaidCloud...** | Réécrit immédiatement dans PlaidCloud les tables récupérées dans cette feuille. Consultez [Enregistrer une table dans PlaidCloud](/fr/reference/cli/plaidxl/retrieve/#enregistrer-une-table-dans-plaidcloud). |
| **Undo last write** | Annule la dernière valeur que vous avez saisie dans PlaidCloud ou le dernier enregistrement, en commençant par le plus récent. Consultez [Annuler une écriture](/fr/reference/cli/plaidxl/write-values/#annuler-une-écriture). |

## Partager

| Commande | Fonction |
|---|---|
| **Convert to values** | Un menu : **Whole workbook** ou **This sheet** remplace les formules PlaidXL par leurs valeurs actuelles et mémorise les formules. **Values only (no restore)** les remplace sans conserver de moyen de revenir en arrière. |
| **Restore PlaidXL formulas** | Remet en place, dans toutes les feuilles du classeur, les formules que **Convert to values** a remplacées. |

Utilisez **Convert to values** pour envoyer un rapport à une personne qui n'a pas PlaidXL ou qui n'a pas accès au projet — elle verrait sinon des erreurs à la place des formules PlaidXL. Cette commande convertit chaque formule qui appelle une fonction PlaidXL, y compris celle qui se trouve dans une autre formule comme `IFERROR`, ainsi que les cellules dans lesquelles elle se répand. Tout le reste du classeur est laissé tel quel. **Values only (no restore)** appliquée à tout le classeur demande d'abord confirmation : **Convert every PlaidXL formula in the workbook to values only? Restore can't bring them back.** Les autres choix s'exécutent immédiatement. Le message indique combien de formules ont été converties. Une formule encore en cours de calcul (`#BUSY!`) n'est pas convertie ; le message les compte, donc convertissez de nouveau lorsqu'elles ont terminé.

Les formules sont conservées avec chaque feuille : **Restore PlaidXL formulas** les retrouve donc même après que vous avez renommé ou déplacé une feuille. Il n'est pas nécessaire d'être connecté. Consultez [Partager une copie contenant uniquement les valeurs](/fr/reference/cli/plaidxl/build-a-report/#partager-une-copie-en-valeurs-seules).

<Aside type="caution">
Convertissez une copie enregistrée sous un nouveau nom et conservez votre rapport de travail tel quel. **Values only (no restore)** ne peut pas être annulée avec **Restore PlaidXL formulas**.
</Aside>

## Le menu contextuel

Faites un clic droit sur une cellule et choisissez **PlaidXL** pour accéder à ces commandes, chacune identique à son bouton du ruban :

- **Drill down one level**, **Drill down to lowest level**, **Drill down all levels**, **Custom drill...**, **Drill up**, **Keep only** et **Remove only**
- **Pick member...**
- **Explain this number** et **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...**, qui ouvre l'onglet **Formulas** pour la cellule

## L'onglet PlaidXL Cell

Lorsque la cellule sélectionnée contient une formule PlaidXL, fait partie des résultats d'une formule PlaidXL ou se trouve dans une table récupérée, Excel affiche un onglet **PlaidXL Cell** à côté de l'onglet **PlaidCloud**. Il regroupe les commandes pour cette cellule :

- **Drill** : **Drill down** (**One level**, **Lowest level**, **All levels**), **Drill up**, **Keep only** et **Supprimer**
- **Inspecter** : **Expliquer**, **Detail rows** et **Demander à Weave**
- **Données** : **Pick member**, **Refresh selection** et **Save sheet**

L'onglet se masque de nouveau lorsque vous sélectionnez une autre cellule. Les versions d'Excel qui ne prennent pas en charge les onglets contextuels des compléments ne l'affichent pas ; toutes les commandes restent disponibles dans l'onglet **PlaidCloud**.

## Raccourcis clavier

Chaque raccourci est **Ctrl+Alt+Maj** et une touche sous Windows, ou **⌘⌥⇧** et la même touche sur Mac. Les raccourcis ne se déclenchent pas pendant que vous saisissez du texte dans un champ ou que vous maintenez la touche AltGr. Si une commande du ruban échoue, un message indique quelle commande a échoué et pourquoi, et le volet des tâches s'ouvre s'il était masqué.

| Touche | Commande |
|---|---|
| **Bas** | Drill down d'un niveau |
| **Haut** | Drill up |
| **L** | Drill down jusqu'au niveau le plus bas |
| **8** | Drill down de tous les niveaux |
| **D** | Drill personnalisé |
| **K** | Conserver uniquement |
| **X** | Supprimer uniquement |
| **M** | Choisir un membre |
| **E** | Expliquer ce nombre |
| **T** | Afficher les lignes de détail |
| **R** | Actualiser cette feuille |
| **F** | Actualiser la sélection |
| **A** | Actualiser toutes les tables |
| **C** | Recalculer les formules PlaidXL |
| **W** | Enregistrer la feuille dans PlaidCloud |
| **Z** | Annuler la dernière écriture |
| **P** | Ouvrir PlaidXL |
| **N** | Insérer une formule |
| **B** | Créer un rapport |
| **I** | Insérer une métrique |
| **Q** | Demander à Weave |

Pour en modifier un, cliquez sur **Shortcuts** dans le groupe **Connecter**, ou choisissez **Keyboard shortcuts** dans le menu du compte du volet des tâches. Cliquez sur **Set key** à côté d'une commande, appuyez sur la nouvelle combinaison, puis cliquez sur **Enregistrer** ; **Réinitialiser** rétablit la combinaison d'origine. Une combinaison déjà utilisée par une autre commande est signalée, et l'enregistrer malgré tout prend effet. Certaines versions d'Office ne permettent pas aux compléments de modifier les raccourcis et affichent la liste sans **Set key**.
