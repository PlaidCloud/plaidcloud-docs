Une fois que vous êtes [connecté](/fr/reference/cli/plaidxl/connect/), le volet des tâches liste vos projets. Vous choisissez un projet, puis vous récupérez ses tables et ses dimensions dans le classeur.

## Choisir un projet

L'en-tête du volet des tâches affiche votre espace de travail et le projet auquel ce classeur est associé. Cliquez sur le nom du projet pour ouvrir la liste des projets, qui affiche tous les projets que vous pouvez ouvrir, dans les mêmes dossiers que ceux que vous voyez dans PlaidCloud. Les dossiers sont réduits au départ§T; cliquez sur l'un d'eux pour l'ouvrir, ou saisissez du texte dans **Filter projects by name** pour réduire la liste.

Cliquez sur un projet pour le sélectionner. Ses tables apparaissent dans l'onglet **Tables** et ses dimensions dans l'onglet **Dimensions**.

### Le projet appartient au classeur

Le projet sélectionné est enregistré dans le classeur§T; chaque classeur a donc son propre projet. C'est le projet que les [fonctions personnalisées](/fr/reference/cli/plaidxl/functions/) et les commandes d'exploration PlaidXL lisent dans ce classeur. Si vous ouvrez deux classeurs, chacun lit les données de son propre projet, et lorsque vous rouvrez un classeur, le volet des tâches revient à son projet. Le projet accompagne le fichier chez toute personne qui l'ouvre et se connecte avec un accès à ce projet.

Un projet appartient à un seul espace de travail. Si vous [changez d'espace de travail](/fr/reference/cli/plaidxl/connect/#se-déconnecter-ou-changer-despace-de-travail), un classeur lié à un projet de l'ancien espace de travail n'a pas de projet tant que vous n'en choisissez pas un. Les tables que vous avez récupérées depuis l'ancien espace de travail restent dans le classeur, mais **Refresh All Tables** les ignore, et le volet des tâches vous indique leur nombre. Récupérez-les de nouveau dans le nouvel espace de travail pour les lier.

## Récupérer une table

1. Dans l'onglet **Tables**, cliquez sur une table. Utilisez **Filter tables by name** pour la trouver dans une longue liste. Les valeurs **Lignes** et **Colonnes** à côté de chaque table indiquent sa taille.
2. Sous **Colonne**, décochez la case de chaque colonne dont vous n'avez pas besoin. Toutes les colonnes sont sélectionnées au départ.
3. Pour ne récupérer que certaines lignes, sélectionnez **Avancé** et créez un filtre. Consultez [Filtrer les lignes](#filtrer-les-lignes).
4. Sous **Select where to place this table**, choisissez§N:
   - **Matching Worksheet** — une feuille de calcul portant le nom de la table. PlaidXL crée la feuille si elle n'existe pas, et écrit la table à partir de la cellule A1 si elle existe.
   - **Current Selection** — à partir de la cellule que vous avez sélectionnée dans la feuille active.
5. Cliquez sur **Retrieve Table**.

Les données arrivent avec une ligne d'en-tête, prêtes à l'emploi. La ligne d'en-tête est en gras et ombrée, les colonnes sont dimensionnées pour s'ajuster au contenu et les filtres sont activés. Une table récupérée dans **Matching Worksheet** reçoit également§N:

- Une ligne d'en-tête figée, qui reste visible pendant le défilement.
- Une plage nommée sur les données, afin que les formules qui l'utilisent suivent les données à mesure qu'elles augmentent lors de l'actualisation. Son nom est celui de la feuille de calcul précédé d'un trait de soulignement§N: une table nommée **Sample data** arrive dans la feuille `Sample_data`, avec la plage nommée `_Sample_data`.

Pour nommer la feuille de calcul, PlaidXL tronque le nom de la table à la limite d'Excel de 31 caractères, ne conserve que les lettres simples (A–Z), les chiffres et les espaces, et transforme les espaces en traits de soulignement. Une table nommée **Q3 Revenue (EMEA)** est récupérée dans la feuille `Q3_Revenue_EMEA`. Les traits de soulignement et les lettres accentuées sont également supprimés§T; ainsi, **sales_2024** est récupérée dans la feuille `sales2024`.

<Aside type="tip">Les tables larges sont lentes à charger dans Excel. Décocher les colonnes dont vous n'avez pas besoin est le moyen le plus rapide d'accélérer une récupération volumineuse.</Aside>

### Tables affichées en rouge

Une table s'affiche en rouge lorsqu'elle est trop grande pour une feuille de calcul — plus de 1 048 576 lignes ou 16 384 colonnes — ou lorsque PlaidCloud ne peut pas indiquer sa taille, comme pour une table qui n'a jamais été chargée. Filtrez les lignes avec **Avancé** et décochez des colonnes jusqu'à ce qu'elle tienne. PlaidXL récupère au maximum 1 048 575 lignes plus la ligne d'en-tête, et s'arrête là sans avertissement.

## Filtrer les lignes

Sélectionnez **Avancé** pour ouvrir le générateur de filtres. Chaque règle choisit une colonne, une comparaison telle que **Égal à**, **dans**, **contient**, **Commence par** ou **est vide**, et une valeur. Utilisez des groupes **AND**, des groupes **OR**, ou les deux pour combiner les règles.

Le filtre compare les valeurs sous forme de texte§T; il correspond donc à des valeurs exactes et à des motifs de texte. Les plages de nombres ou de dates ne sont pas disponibles§T; pour récupérer une plage, filtrez sur les valeurs dont vous avez besoin avec **dans**, ou récupérez la table et filtrez-la dans Excel.

- Saisissez les valeurs sans guillemets§N: `EMEA`, et non `"EMEA"`.
- Pour une comparaison qui accepte plusieurs valeurs, comme **dans**, séparez les valeurs par une virgule et une espace§N: `EMEA, APAC, NA`.

Le filtre ne s'applique que lorsque **Avancé** est sélectionné. PlaidXL mémorise le filtre et les colonnes que vous avez choisis avec chaque table récupérée, et les réutilise lorsque vous actualisez.

## Refresh All Tables

**Refresh All Tables** — dans le volet des tâches, ou dans le ruban sous **PlaidCloud → Données** — récupère les données actuelles de PlaidCloud pour chaque table que vous avez récupérée dans le classeur, avec les colonnes et le filtre que vous avez choisis pour chacune.

Pendant l'exécution, l'onglet de la feuille de calcul de chaque table devient jaune. Il devient vert lorsque cette table est à jour. Les formules qui utilisent les données se recalculent normalement§T; actualisez les tableaux croisés dynamiques créés à partir de ces données avec **Data → Refresh All** d'Excel.

PlaidXL enregistre la liste des tables récupérées dans le classeur, de sorte que **Refresh All Tables** fonctionne pour toute personne qui ouvre le fichier et se connecte avec un accès aux mêmes projets.

Chaque **Retrieve Table** ajoute la table à la liste d'actualisation, et il n'est pas possible d'en retirer une. Récupérez chaque table une seule fois, puis utilisez **Refresh All Tables** pour la mettre à jour — récupérer plusieurs fois la même table fait que chaque actualisation la récupère deux fois.

<Aside type="caution">
Une table récupérée dans **Current Selection** est actualisée dans les mêmes cellules de **la feuille active au moment où** vous cliquez sur **Refresh All Tables**, ce qui écrase ce qui s'y trouve. Récupérez les tables que vous prévoyez d'actualiser dans **Matching Worksheet**§T; elles s'actualisent toujours dans leur propre feuille.

Une actualisation écrit par-dessus les anciennes données sans les effacer au préalable. Si une table compte maintenant moins de lignes ou de colonnes qu'avant, les lignes ou colonnes en trop de la récupération précédente restent dans la feuille. Videz le contenu de la feuille avant d'actualiser une table susceptible d'avoir diminué.
</Aside>

## Récupérer une dimension

L'onglet **Dimensions** liste les [dimensions](/fr/guides/dimensions/dimensions/) du projet.

1. Cliquez sur une dimension. Utilisez **Filter dimensions by name** pour la trouver.
2. Sous **Select where to place this dimension**, choisissez **Matching Worksheet** ou **Current Selection**.
3. Cliquez sur **Retrieve Dimension**.

PlaidXL écrit les nœuds de la dimension dans une seule colonne, dans l'ordre de la hiérarchie. Les dimensions n'ont pas de filtres de colonnes ou de lignes, et **Refresh All Tables** ne les actualise pas — récupérez de nouveau la dimension pour prendre en compte les modifications.

Pour disposer une hiérarchie avec des retraits et un regroupement en plan Excel, ou pour partir d'un nœud ou d'une hiérarchie alternative particuliers, utilisez plutôt [`PLAIDXL.DIMENSION.GET_DIMENSION`](/fr/reference/cli/plaidxl/functions/#get_dimension) ou les [commandes d'exploration](/fr/reference/cli/plaidxl/ribbon/#drill-functions).

## Enregistrer une table dans PlaidCloud

Une table que vous avez récupérée dans le classeur peut être réenregistrée, ce qui remplace la table PlaidCloud par le contenu de la feuille.

1. Accédez à la feuille de calcul qui contient la table récupérée. Sous **Save this sheet to PlaidCloud**, le volet des tâches liste chaque table associée à la feuille active, avec son nombre de lignes. Si la feuille n'en a aucune, le volet vous invite à y récupérer d'abord une table.
2. Cliquez sur **Save to PlaidCloud…** à côté de la table.
3. Lisez la confirmation, qui indique la table, le nombre de lignes à écrire et les colonnes, puis cliquez sur **Replace table**.

PlaidXL lit la ligne d'en-tête et les lignes situées en dessous à l'emplacement où la table a été récupérée. L'en-tête doit toujours correspondre aux colonnes que vous avez récupérées, et les valeurs sont converties dans le type de données de chaque colonne. Si une valeur ne peut pas être convertie, rien n'est écrit et les lignes en échec sont listées. Les définitions des colonnes dans PlaidCloud restent inchangées.

### Ce qui est enregistré

- Les cellules vides et les cellules qui affichent une erreur sont enregistrées comme vides.
- Les lignes ajoutées directement sous la table sont incluses, jusqu'à la première ligne vide.
- Une ligne vide à l'intérieur des lignes récupérées est conservée. Deux lignes vides consécutives ou plus, avec des données en dessous, interrompent l'enregistrement et vous indiquent les lignes à supprimer ou à remplir.

### Avant de remplacer une table

- **Une table filtrée.** Si vous avez récupéré la table avec un filtre, chaque ligne que le filtre a exclue est supprimée de PlaidCloud. La confirmation l'indique et vous demande de cocher une case avant que **Replace table** ne s'active.
- **Des colonnes que vous n'avez pas récupérées.** Si vous n'avez récupéré que certaines colonnes, PlaidXL demande **Empty columns that were not retrieved?** et les nomme. Cliquez sur **Write anyway** pour vider ces colonnes dans PlaidCloud, ou annulez pour ne rien écrire.
- **Quelqu'un d'autre a modifié la table.** L'enregistrement est refusé si la table a changé dans PlaidCloud après que vous l'avez récupérée. Récupérez-la de nouveau et réappliquez vos modifications.
- **Un point de restauration.** PlaidXL crée un point de restauration avant d'écrire et le conserve pendant 7 jours. Si l'écriture échoue, la table est remise dans son état d'origine. Une table qui ne peut pas recevoir de point de restauration demande **Write back without a restore point?**, et **Write anyway** poursuit sans point de restauration.

Après un enregistrement réussi, le message de confirmation inclut **Restore previous version**. Il ouvre la table dans PlaidCloud, où vous choisissez la version située juste avant cet enregistrement dans le menu **As of**.
