Une fois que vous êtes [connecté](/fr/reference/cli/plaidxl/connect/), le volet des tâches répertorie vos projets. Vous choisissez un projet, puis vous récupérez ses tables et ses dimensions dans le classeur.

## Choisir un projet

L'en-tête du volet des tâches affiche votre espace de travail et le projet auquel ce classeur est lié. Cliquez sur le nom du projet pour ouvrir la liste des projets, qui affiche tous les projets que vous pouvez ouvrir, dans les mêmes dossiers que ceux de PlaidCloud. Les dossiers sont réduits au départ ; cliquez sur l'un d'eux pour l'ouvrir, ou saisissez du texte dans **Filter projects by name** pour restreindre la liste. Si votre espace de travail ne contient qu'un seul projet que vous pouvez ouvrir, PlaidXL y lie le classeur pour vous, et l'en-tête indique **Linked to** suivi du projet, avec **change** à côté.

Cliquez sur un projet pour le sélectionner. Ses tables apparaissent dans l'onglet **Tables** et ses dimensions dans l'onglet **Dimensions**.

### Le projet appartient au classeur

Le projet sélectionné est enregistré dans le classeur : chaque classeur a donc son propre projet. C'est le projet que les [fonctions personnalisées](/fr/reference/cli/plaidxl/functions/) et les commandes d'analyse détaillée de PlaidXL lisent dans ce classeur. Si vous ouvrez deux classeurs, chacun lit son propre projet, et lorsque vous rouvrez un classeur, le volet des tâches revient à son projet. Le projet accompagne le fichier chez toute personne qui l'ouvre et se connecte avec un accès à ce projet.

Un projet appartient à un seul espace de travail. Si vous [changez d'espace de travail](/fr/reference/cli/plaidxl/connect/#se-déconnecter-ou-changer-despace-de-travail), un classeur lié à un projet de l'ancien espace de travail n'a plus de projet tant que vous n'en choisissez pas un. Les tables et les dimensions que vous avez récupérées depuis l'ancien espace de travail restent dans le classeur, mais ne sont ni actualisées ni enregistrées : **Refresh All Tables** indique que des tables ou des dimensions d'un autre espace de travail n'ont pas été actualisées. Récupérez-les à nouveau dans le nouvel espace de travail pour les lier.

## Récupérer une table

1. Dans l'onglet **Tables**, cliquez sur une table. Utilisez **Filter tables by name** pour la trouver dans une longue liste. Les compteurs **Lignes** et **Colonnes** à côté de chaque table indiquent sa taille.
2. Sous **Colonne**, décochez la case de chaque colonne dont vous n'avez pas besoin. Toutes les colonnes sont sélectionnées au départ.
3. Pour ne récupérer qu'une partie des lignes, sélectionnez **Avancé** et créez un filtre. Consultez [Filtrer les lignes](#filtrer-les-lignes).
4. Sous **Select where to place this table**, choisissez :
   - **Matching Worksheet** — une feuille de calcul portant le nom de la table, à partir de la cellule A1. PlaidXL crée la feuille si elle n'existe pas.
   - **Current Selection** — à partir de la cellule que vous avez sélectionnée dans la feuille active.
5. Cliquez sur **Retrieve Table**.

Les données arrivent sous forme de tableau Excel, portant le nom de la table PlaidCloud, de sorte que les formules, les tableaux croisés dynamiques et les graphiques qui y font référence suivent les données lorsqu'elles augmentent ou diminuent. Les nombres, les dates et les heures reçoivent un format adapté à leur type de données, ou le format numérique défini sur la colonne dans PlaidCloud. Les colonnes de texte sont mises en forme comme du texte, de sorte qu'un code tel que `0012` conserve ses zéros initiaux. La première fois que vous récupérez une table, sa ligne d'en-tête est figée et ses colonnes sont ajustées à leur contenu.

Si les cellules dans lesquelles la table serait placée contiennent déjà autre chose qu'une table PlaidXL, PlaidXL place la table dans une nouvelle feuille et vous indique où. Si la table empiétait sur une partie d'un tableau Excel que PlaidXL ne gère pas, rien ne change et le message indique **Move that Table or convert it to a range, then try again.**

Récupérer une table déjà présente dans la feuille l'actualise sur place : vos propres colonnes restent, et une colonne source que vous décochez conserve son en-tête, avec les cellules situées dessous vidées.

Les identifiants entiers trop grands pour qu'Excel les conserve exactement (supérieurs à 9 007 199 254 740 991) et les dates antérieures au 1er mars 1900 arrivent sous forme de texte, afin de s'afficher et de se réenregistrer exactement.

Pour nommer la feuille de calcul, PlaidXL ne conserve que les lettres simples (A–Z), les chiffres, les traits de soulignement et les espaces, remplace les espaces par des traits de soulignement et limite le nom à 31 caractères, la limite d'Excel. Une table nommée **Q3 Revenue (EMEA)** est récupérée dans la feuille `Q3_Revenue_EMEA`, et **sales_2024** dans `sales_2024`. Les lettres accentuées sont supprimées.

Les grandes tables sont récupérées beaucoup plus rapidement dans Excel sur le web et dans les versions récentes d'Excel pour ordinateur. Une table de 70 000 lignes et 17 colonnes prend environ 15 à 20 secondes sur le web, et une table de 143 000 lignes et 77 colonnes prend environ une minute là où il fallait autrefois plus de dix minutes. Les versions plus anciennes d'Excel fonctionnent toujours, simplement sans cette accélération. Les colonnes sont ajustées à l'en-tête et aux premières lignes.

<Aside type="tip">Les tables larges sont les plus lentes à charger dans Excel. Décocher les colonnes dont vous n'avez pas besoin est le moyen le plus rapide d'accélérer une grande récupération.</Aside>

### Texte plus long qu'une cellule Excel

Une cellule Excel contient au plus 32 767 caractères, de sorte qu'un texte plus long s'affiche tronqué. Lorsqu'une table contient un tel texte, le volet des tâches indique quelles colonnes de quelle table contiennent un texte dépassant les 32 767 caractères d'une cellule Excel, et qu'Excel l'affiche tronqué, si bien que l'enregistrement est désactivé pour cette table. L'enregistrer tronquerait aussi le texte dans PlaidCloud, donc **Save to PlaidCloud** refuse cette table.

### Tables affichées en rouge

Une table s'affiche en rouge, avec l'info-bulle **Too large for an Excel worksheet**, lorsqu'elle compte plus de 1 048 575 lignes ou 16 384 colonnes, ou lorsque PlaidCloud ne peut pas indiquer sa taille, comme pour une table qui n'a jamais été chargée. Vous pouvez tout de même la récupérer : les lignes qui ne tiennent pas dans une seule feuille de calcul se poursuivent dans la suivante, nommée d'après la première avec ` (2)`, ` (3)` et ainsi de suite. Une table répartie sur plusieurs feuilles ne peut pas être réenregistrée dans PlaidCloud ; si vous prévoyez de la modifier, filtrez donc les lignes avec **Avancé** et décochez des colonnes jusqu'à ce qu'elle tienne.

## Filtrer les lignes

Sélectionnez **Avancé** pour ouvrir le générateur de filtres. Chaque règle choisit une colonne, une comparaison telle que **Égal à**, **in**, **contient**, **Commence par** ou **est vide**, et une valeur. Utilisez des groupes **AND**, des groupes **OR**, ou les deux pour combiner les règles.

Le filtre compare les valeurs sous forme de texte, de sorte qu'il correspond à des valeurs exactes et à des motifs de texte. Les plages de nombres ou de dates ne sont pas disponibles ; pour récupérer une plage, filtrez sur les valeurs dont vous avez besoin avec **in**, ou récupérez la table et filtrez-la dans Excel.

- Saisissez les valeurs sans guillemets : `EMEA`, et non `"EMEA"`.
- Pour une comparaison qui accepte plusieurs valeurs, telle que **in**, séparez les valeurs par une virgule suivie d'une espace : `EMEA, APAC, NA`.

Le filtre ne s'applique que lorsque **Avancé** est sélectionné. PlaidXL mémorise le filtre et les colonnes que vous avez choisies pour chaque table récupérée, et les réutilise lorsque vous actualisez. Un filtre composé uniquement de règles **Égal à** et **in** reliées par **AND** détermine aussi quelles lignes sont remplacées par un [enregistrement](#enregistrer-une-table-dans-plaidcloud).

## Actualiser toutes les tables

PlaidXL tient une liste des tables et des dimensions que vous avez récupérées dans le classeur, et les actualise avec les colonnes et le filtre que vous avez choisis pour chacune. La liste est enregistrée dans le classeur, de sorte que l'actualisation fonctionne pour toute personne qui ouvre le fichier et se connecte avec un accès aux mêmes projets.

- **Refresh This Sheet**, dans le volet des tâches, actualise les tables de la feuille active.
- **Refresh All Tables**, dans le volet des tâches, actualise toutes les tables et toutes les dimensions du classeur.
- Le menu **Actualiser** du ruban actualise aussi une feuille, la sélection ou toutes les tables, et recalcule les formules PlaidXL. Consultez [Actualiser](/fr/reference/cli/plaidxl/ribbon/#actualiser).

Pendant une actualisation, le volet des tâches affiche sa progression pour chaque table — interrogation de PlaidCloud, puis proportion de lignes écrites — avec un bouton **Annuler**. Trois tables sont actualisées à la fois, et le lancement d'une autre actualisation s'ajoute à celle déjà en cours. Lorsqu'elle se termine, le volet répertorie chaque table avec son nombre de lignes, ou la raison de son échec. Cliquez sur une table de la liste pour la sélectionner. L'échec d'une table n'arrête pas les autres.

Pendant **Refresh All Tables**, que l'action vienne du volet, du ruban ou de l'actualisation de toutes les tables par Weave, l'onglet de chaque feuille est jaune tant que cette feuille est actualisée. Il reprend sa couleur précédente, aucune ou la vôtre, lorsque la feuille termine, échoue ou est annulée. Si vous enregistrez et fermez le classeur en cours de route, PlaidXL remet les onglets en état au prochain démarrage dans ce classeur. L'actualisation d'une seule feuille ou d'une sélection ne colore pas les onglets.

**Annuler** laisse le classeur dans l'état où il était avant l'actualisation : les données d'une table ne sont remplacées qu'une fois toutes ses lignes arrivées. Cela arrête la requête dans PlaidCloud pour les tables StarRocks ; sur d'autres moteurs, tels que Databend et Snowflake, PlaidXL cesse d'attendre mais la requête n'est pas arrêtée dans PlaidCloud. Le calcul d'Excel est suspendu pendant l'écriture des données et s'exécute une fois à la fin.

### Ce que conserve une actualisation

Une table est actualisée dans le même tableau Excel, où qu'il se trouve désormais — une table récupérée dans **Current Selection** est actualisée dans ses propres cellules, sur sa propre feuille, même si vous déplacez ou renommez le tableau Excel. Le tableau s'agrandit ou se réduit pour s'adapter aux nouvelles données, et les lignes et colonnes restantes d'une extraction précédente plus volumineuse sont effacées.

- **Vos propres colonnes** — les colonnes que vous avez ajoutées à côté des données dans le tableau Excel restent en place. Une formule identique dans chaque ligne est recopiée vers le bas jusqu'aux nouvelles lignes. Les autres valeurs, telles que les notes, suivent leur ligne lorsque la table possède des colonnes clés dans PlaidCloud ; les notes des lignes qui ont disparu sont conservées sous la table. Sans colonnes clés, les notes restent à leur place selon leur position.
- **Votre mise en forme** — un format numérique que vous avez défini sur une colonne est conservé.

Une actualisation qui empiéterait sur d'autres cellules, ou sur un tableau Excel qui n'est pas celui de la table, ne change rien et indique **Move what is there, then try again.** Si le tableau Excel a changé pendant l'arrivée des lignes, le message demande de réessayer.

Si la feuille de calcul d'une table a été supprimée, la table est ignorée et PlaidXL propose **Recreate sheet** ou **Stop refreshing**.

Si Excel refuse une partie de l'écriture finale, le volet indique que la table n'a été écrite que partiellement, avec la raison, et qu'il faut l'actualiser avant de l'enregistrer. **Save to PlaidCloud** refuse cette table tant qu'une actualisation n'a pas réussi.

### Retirer une table de la liste d'actualisation

Sous **On this sheet**, le volet des tâches répertorie chaque table et chaque dimension récupérée dans la feuille active, avec son nombre de lignes et la date de sa dernière actualisation. Cliquez sur **Stop refreshing** pour en retirer une de la liste d'actualisation. Les données restent dans la feuille, et le message propose **Défaire**.

Récupérer une table par-dessus une table déjà présente dans la liste la remplace dans la liste, de sorte qu'une table n'est actualisée qu'une fois, quel que soit le nombre de fois où vous la récupérez. À côté de chaque table, **Copier** copie le nom de son tableau Excel pour l'utiliser dans des formules.

## Récupérer une dimension

L'onglet **Dimensions** répertorie les [dimensions](/fr/guides/dimensions/dimensions/) du projet.

1. Cliquez sur une dimension. Utilisez **Filter dimensions by name** pour la trouver.
2. Sous **Select where to place this dimension**, choisissez **Matching Worksheet** ou **Current Selection**.
3. Cliquez sur **Retrieve Dimension**.

PlaidXL écrit les nœuds de la dimension dans une seule colonne, dans l'ordre de la hiérarchie. Les dimensions n'ont pas de filtres de colonnes ni de lignes. **Refresh All Tables** les actualise avec vos tables.

Pour présenter une hiérarchie avec une indentation et un regroupement en plan Excel, ou pour partir d'un nœud ou d'une hiérarchie alternative particulière, utilisez plutôt les [commandes d'analyse détaillée](/fr/reference/cli/plaidxl/drill/) ou [`PLAIDXL.DRILL`](/fr/reference/cli/plaidxl/functions/#drill). Pour placer un seul membre dans une cellule, cliquez sur **Pick member...** dans l'onglet **Dimensions** ; consultez [Choisir un membre](/fr/reference/cli/plaidxl/drill/#choisir-un-membre).

## Enregistrer une table dans PlaidCloud

Une table que vous avez récupérée dans le classeur peut être réenregistrée, ce qui remplace les lignes de la table PlaidCloud par le contenu de la feuille.

1. Accédez à la feuille de calcul qui contient la table récupérée. Sous **On this sheet**, le volet des tâches répertorie chaque table qui y a été récupérée. S'il n'y en a aucune, le volet indique qu'il faut d'abord y récupérer une table.
2. Cliquez sur **Save to PlaidCloud** à côté de la table, ou cliquez sur **Save sheet to PlaidCloud...** dans le groupe **Écriture** du ruban (**Ctrl+Alt+Maj+W**, ou **⌘⌥⇧W** sur Mac) pour enregistrer toutes les tables de la feuille.

L'enregistrement s'effectue immédiatement, sans confirmation. Le message indique combien de lignes ont été enregistrées, signale tout ce que vous devez savoir et propose **Défaire**.

PlaidXL lit la ligne d'en-tête de la table et les lignes situées dessous. L'en-tête doit toujours correspondre aux colonnes que vous avez récupérées, et les valeurs sont converties selon le type de données de chaque colonne. Si une valeur ne peut pas être convertie, rien n'est écrit et les lignes en échec sont répertoriées. Les définitions de colonnes dans PlaidCloud restent inchangées.

### Ce qui est enregistré

- Les cellules vides sont enregistrées comme vides.
- Un nombre écrit avec une virgule, tel que `1,5`, n'est pas lu comme 15. Un nombre entier trop grand pour la colonne est signalé avec sa ligne, et la date du 29 février 1900, qu'Excel invente, est refusée.
- Les lignes vides situées à l'intérieur des lignes récupérées sont ignorées. Au-delà, la table se termine à la première ligne vide ; les lignes situées plus bas ne sont pas enregistrées, et le message les nomme.
- Les colonnes que vous n'avez pas récupérées sont vidées dans PlaidCloud, et le message les nomme.
- Si la table a changé dans PlaidCloud après que vous l'avez récupérée, votre enregistrement la remplace et le message l'indique. Le point de restauration conserve ce qui s'y trouvait.
- Si vous avez enregistré une feuille d'analyse détaillée et que les membres situés sous ses nœuds ont changé depuis que vous l'avez récupérée, rien n'est écrit : le message indique **Retrieve again before saving.** La récupération ou l'actualisation remplace la feuille, donc copiez d'abord les modifications que vous n'avez pas enregistrées.

### Enregistrements qui ne remplacent qu'une partie des lignes

Un enregistrement ne remplace que ses propres lignes, et conserve le reste de la table, lorsque :

- **La table a été récupérée avec un filtre** composé de règles **Égal à** et **in** reliées par **AND**. Seules les lignes couvertes par le filtre sont remplacées ; les lignes que vous avez ajoutées en dehors du filtre sont tout de même enregistrées, et le message indique combien. Une table récupérée avec tout autre filtre ne peut pas être enregistrée ; récupérez-la à nouveau avec un tel filtre, ou sans filtre.
- **La feuille affiche des lignes de détail** issues de [Show detail rows](/fr/reference/cli/plaidxl/drill/#afficher-les-lignes-de-détail). Seules les lignes situées derrière cette valeur sont remplacées.
- **Votre accès à la table est limité à certaines lignes.** Seules les lignes que vous pouvez voir sont remplacées, de sorte que les lignes des autres personnes sont conservées. Si la feuille contient des lignes en dehors de votre accès, rien n'est enregistré et le message les répertorie ; supprimez ces lignes et enregistrez à nouveau.

### Annuler un enregistrement

PlaidXL crée un point de restauration avant d'écrire. Chaque enregistrement conserve son propre point de restauration pendant 7 jours, de sorte que **Défaire** fonctionne jusqu'à 7 jours après chaque enregistrement, même si vous avez enregistré à nouveau depuis. Cela s'applique aux tables Lakehouse. Si l'écriture échoue, la table est remise comme elle était et vos modifications restent dans la feuille, sauf si quelqu'un d'autre a modifié la table après le début de l'écriture ; elle est alors laissée telle quelle et le message l'indique.

Pour annuler un enregistrement, cliquez sur **Défaire** dans le message, ou sur **Undo last write** dans le groupe **Écriture** du ruban. La table revient à son état d'avant votre enregistrement — pour un enregistrement qui n'a remplacé qu'une partie des lignes, uniquement ces lignes. Actualisez la feuille pour le constater. Consultez [Annuler une écriture](/fr/reference/cli/plaidxl/write-values/#annuler-une-écriture). Si un enregistrement ne peut ni se terminer ni être annulé, le message nomme le point de restauration afin que la table puisse être restaurée ; **Défaire** écrase alors aussi les modifications apportées à la table depuis. Une table qui ne peut pas recevoir de point de restauration est tout de même enregistrée, et le message indique que l'enregistrement ne peut pas être annulé.

Seules la personne et l'espace de travail qui ont effectué une écriture peuvent l'annuler.
