Une fois [connecté](/fr/reference/cli/plaidxl/connect/), vous voyez la liste de vos projets dans le volet des tâches. Vous choisissez un projet, puis récupérez ses tables et ses dimensions dans le classeur.

## Choisir un projet

L'en-tête du volet des tâches affiche votre espace de travail et le projet auquel ce classeur est lié. Cliquez sur le nom du projet pour ouvrir la liste des projets, qui présente tous les projets que vous pouvez ouvrir, dans les mêmes dossiers que dans PlaidCloud. Les dossiers sont réduits au départ ; cliquez sur l'un d'eux pour l'ouvrir, ou saisissez du texte dans **Filter projects by name** pour réduire la liste. Si votre espace de travail ne comporte qu'un seul projet que vous pouvez ouvrir, PlaidXL y lie le classeur pour vous, et l'en-tête indique **Linked to** suivi du projet, avec **change** à côté.

Cliquez sur un projet pour le sélectionner. Ses tables apparaissent dans l'onglet **Tables** et ses dimensions dans l'onglet **Dimensions**.

### Le projet appartient au classeur

Le projet sélectionné est enregistré dans le classeur : chaque classeur a donc son propre projet. C'est le projet que lisent, dans ce classeur, les [fonctions personnalisées](/fr/reference/cli/plaidxl/functions/) PlaidXL et les commandes d'exploration. Si vous ouvrez deux classeurs, chacun lit son propre projet, et lorsque vous rouvrez un classeur, le volet des tâches revient à son projet. Le projet accompagne le fichier chez toute personne qui l'ouvre et se connecte avec un accès à ce projet.

Un projet appartient à un seul espace de travail. Si vous [changez d'espace de travail](/fr/reference/cli/plaidxl/connect/#se-déconnecter-ou-changer-despace-de-travail), un classeur lié à un projet de l'ancien espace de travail n'a plus de projet tant que vous n'en choisissez pas un. Les tables et les dimensions que vous avez récupérées depuis l'ancien espace de travail restent dans le classeur, mais ne sont ni actualisées ni enregistrées : **Refresh All Tables** indique que des tables ou des dimensions d'un autre espace de travail n'ont pas été actualisées. Récupérez-les à nouveau dans le nouvel espace de travail pour les lier.

## Récupérer une table

1. Dans l'onglet **Tables**, cliquez sur une table. Utilisez **Filter tables by name** pour la trouver dans une longue liste. Les valeurs **Lignes** et **Colonnes** à côté de chaque table indiquent sa taille.
2. Sous **Colonne**, décochez la case de chaque colonne dont vous n'avez pas besoin. Toutes les colonnes sont sélectionnées au départ.
3. Pour ne récupérer que certaines lignes, sélectionnez **Avancé** et créez un filtre. Consultez [Filtrer les lignes](#filtrer-les-lignes).
4. Sous **Select where to place this table**, choisissez :
   - **Matching Worksheet** : une feuille de calcul portant le nom de la table, à partir de la cellule A1. PlaidXL crée la feuille si elle n'existe pas.
   - **Current Selection** : à partir de la cellule que vous avez sélectionnée dans la feuille active.
5. Cliquez sur **Retrieve Table**.

Les données arrivent sous forme de tableau Excel, nommé d'après la table PlaidCloud : les formules, les tableaux croisés dynamiques et les graphiques qui y font référence suivent donc les données lorsqu'elles augmentent ou diminuent. Les nombres, les dates et les heures reçoivent un format adapté à leur type de données, ou le format numérique défini sur la colonne dans PlaidCloud. Les colonnes de texte sont mises en forme comme du texte : un code tel que `0012` conserve donc ses zéros de tête. La première fois que vous récupérez une table, sa ligne d'en-tête est figée et ses colonnes sont ajustées à leur contenu.

Si les cellules qui accueilleraient la table contiennent déjà autre chose qu'un tableau PlaidXL, PlaidXL place la table dans une nouvelle feuille et vous indique où.

Pour nommer la feuille de calcul, PlaidXL ne conserve que les lettres simples (A–Z), les chiffres, les traits de soulignement et les espaces, remplace les espaces par des traits de soulignement et tronque le nom à la limite d'Excel de 31 caractères. Une table nommée **Q3 Revenue (EMEA)** est récupérée dans la feuille `Q3_Revenue_EMEA`, et **sales_2024** dans `sales_2024`. Les lettres accentuées sont supprimées.

<Aside type="tip">Les tables larges sont lentes à charger dans Excel. Décocher les colonnes dont vous n'avez pas besoin est le moyen le plus rapide d'accélérer une grosse récupération.</Aside>

### Tables affichées en rouge

Une table s'affiche en rouge, avec l'info-bulle **Too large for an Excel worksheet**, lorsqu'elle compte plus de 1 048 575 lignes ou 16 384 colonnes, ou lorsque PlaidCloud ne peut pas indiquer sa taille, comme pour une table qui n'a jamais été chargée. Vous pouvez quand même la récupérer : les lignes qui ne tiennent pas dans une feuille de calcul continuent dans la suivante, nommée d'après la première avec ` (2)`, ` (3)`, etc. Une table répartie sur plusieurs feuilles ne peut pas être réenregistrée dans PlaidCloud : si vous prévoyez de la modifier, filtrez donc les lignes avec **Avancé** et décochez des colonnes jusqu'à ce qu'elle tienne.

## Filtrer les lignes

Sélectionnez **Avancé** pour ouvrir le générateur de filtres. Chaque règle choisit une colonne, une comparaison comme **égal à**, **in**, **contient**, **commence par** ou **est vide**, et une valeur. Utilisez des groupes **AND**, des groupes **OR**, ou les deux pour combiner les règles.

Le filtre compare les valeurs sous forme de texte : il correspond donc à des valeurs exactes et à des motifs de texte. Les plages de nombres ou de dates ne sont pas disponibles ; pour récupérer une plage, filtrez sur les valeurs dont vous avez besoin avec **in**, ou récupérez la table et filtrez-la dans Excel.

- Saisissez les valeurs sans guillemets : `EMEA`, et non `"EMEA"`.
- Pour une comparaison qui accepte plusieurs valeurs, comme **in**, séparez les valeurs par une virgule et une espace : `EMEA, APAC, NA`.

Le filtre ne s'applique que lorsque **Avancé** est sélectionné. PlaidXL mémorise le filtre et les colonnes que vous avez choisis pour chaque table récupérée, et les réutilise lorsque vous actualisez. Un filtre composé uniquement de règles **égal à** et **in** reliées par **AND** détermine aussi les lignes qu'un [enregistrement](#enregistrer-une-table-dans-plaidcloud) remplace.

## Refresh All Tables

PlaidXL tient une liste des tables et des dimensions que vous avez récupérées dans le classeur, et les actualise avec les colonnes et le filtre que vous avez choisis pour chacune. La liste est enregistrée dans le classeur : l'actualisation fonctionne donc pour toute personne qui ouvre le fichier et se connecte avec un accès aux mêmes projets.

- **Refresh This Sheet**, dans le volet des tâches, actualise les tables de la feuille active.
- **Refresh All Tables**, dans le volet des tâches, actualise toutes les tables et toutes les dimensions du classeur.
- Le menu **Actualiser** du ruban actualise aussi une feuille, la sélection ou toutes les tables, et recalcule les formules PlaidXL. Consultez [Refresh](/fr/reference/cli/plaidxl/ribbon/#actualiser).

Pendant une actualisation, le volet des tâches affiche sa progression pour chaque table (interrogation de PlaidCloud, puis proportion de lignes écrites), avec un bouton **Annuler**. Trois tables sont actualisées à la fois, et le lancement d'une autre actualisation s'ajoute à celle déjà en cours. Une fois l'opération terminée, le volet liste chaque table avec son nombre de lignes, ou la raison de l'échec. Cliquez sur une table de la liste pour la sélectionner. Une table en échec n'empêche pas les autres.

**Annuler** arrête la requête PlaidCloud et laisse le classeur dans l'état où il était avant l'actualisation : les données d'une table ne sont remplacées qu'une fois toutes ses lignes arrivées. Le calcul d'Excel est suspendu pendant l'écriture des données, puis s'exécute une fois à la fin.

### Ce qu'une actualisation conserve

Une table s'actualise dans le même tableau Excel, où qu'il se trouve désormais : une table récupérée dans **Current Selection** s'actualise dans ses propres cellules de sa propre feuille, même si vous déplacez ou renommez le tableau Excel. Le tableau s'agrandit ou se réduit pour s'adapter aux nouvelles données, et les lignes et colonnes restantes d'une extraction précédente plus volumineuse sont effacées.

- **Vos propres colonnes** : les colonnes que vous avez ajoutées à côté des données dans le tableau Excel sont conservées. Une formule identique sur toutes les lignes est recopiée vers le bas sur les nouvelles lignes. Les autres valeurs, comme les notes, suivent leur ligne lorsque la table comporte des colonnes clés dans PlaidCloud ; les notes des lignes disparues sont conservées sous la table. Sans colonnes clés, les notes restent à leur place, selon leur position.
- **Votre mise en forme** : un format numérique que vous avez défini sur une colonne est conservé.

Si la feuille de calcul d'une table a été supprimée, la table est ignorée et PlaidXL propose **Recreate sheet** ou **Stop refreshing**.

### Retirer une table de la liste d'actualisation

Sous **On this sheet**, le volet des tâches liste chaque table et chaque dimension récupérée dans la feuille active, avec son nombre de lignes et la date de sa dernière actualisation. Cliquez sur **Stop refreshing** pour en retirer une de la liste d'actualisation. Les données restent dans la feuille, et le message propose **Défaire**.

Récupérer une table par-dessus une table déjà présente dans la liste la remplace dans la liste : une table n'est donc actualisée qu'une fois, quel que soit le nombre de fois où vous la récupérez. À côté de chaque table, **Copier** copie le nom de son tableau Excel pour l'utiliser dans des formules.

## Récupérer une dimension

L'onglet **Dimensions** liste les [dimensions](/fr/guides/dimensions/dimensions/) du projet.

1. Cliquez sur une dimension. Utilisez **Filter dimensions by name** pour la trouver.
2. Sous **Select where to place this dimension**, choisissez **Matching Worksheet** ou **Current Selection**.
3. Cliquez sur **Retrieve Dimension**.

PlaidXL écrit les nœuds de la dimension dans une seule colonne, dans l'ordre de la hiérarchie. Les dimensions n'ont pas de filtres de colonnes ni de lignes. **Refresh All Tables** les actualise en même temps que vos tables.

Pour mettre en page une hiérarchie avec retrait et regroupement en plan Excel, ou pour partir d'un nœud particulier ou d'une hiérarchie alternative, utilisez plutôt les [commandes d'exploration](/fr/reference/cli/plaidxl/drill/) ou [`PLAIDXL.DRILL`](/fr/reference/cli/plaidxl/functions/#drill). Pour placer un seul membre dans une cellule, cliquez sur **Pick member...** dans l'onglet **Dimensions** ; consultez [Pick a Member](/fr/reference/cli/plaidxl/drill/#choisir-un-membre).

## Enregistrer une table dans PlaidCloud

Une table que vous avez récupérée dans le classeur peut être réenregistrée, ce qui remplace les lignes de la table PlaidCloud par le contenu de la feuille.

1. Accédez à la feuille de calcul qui contient la table récupérée. Sous **On this sheet**, le volet des tâches liste chaque table qui y a été récupérée. S'il n'y en a aucune, le volet vous invite à y récupérer d'abord une table.
2. Cliquez sur **Save to PlaidCloud** à côté de la table, ou sur **Save sheet to PlaidCloud...** dans le groupe **Écriture** du ruban (**Ctrl+Alt+Maj+W**, ou **⌘⌥⇧W** sur Mac) pour enregistrer toutes les tables de la feuille.

L'enregistrement est immédiat, sans confirmation. Le message indique combien de lignes ont été enregistrées, signale tout ce qu'il vous faut savoir et propose **Défaire**.

PlaidXL lit la ligne d'en-tête de la table et les lignes situées en dessous. L'en-tête doit toujours correspondre aux colonnes que vous avez récupérées, et les valeurs sont converties dans le type de données de chaque colonne. Si une valeur ne peut pas être convertie, rien n'est écrit et les lignes en échec sont listées. Les définitions de colonnes dans PlaidCloud restent inchangées.

### Ce qui est enregistré

- Les cellules vides sont enregistrées comme vides.
- Les lignes vides à l'intérieur des lignes récupérées sont ignorées. En dessous, la table se termine à la première ligne vide ; les lignes plus bas ne sont pas enregistrées, et le message les nomme.
- Les colonnes que vous n'avez pas récupérées sont vidées dans PlaidCloud, et le message les nomme.
- Si la table a changé dans PlaidCloud après que vous l'avez récupérée, votre enregistrement la remplace et le message l'indique. Le point de restauration conserve ce qui s'y trouvait.

### Enregistrements qui ne remplacent que certaines lignes

Un enregistrement ne remplace que ses propres lignes, et conserve le reste de la table, lorsque :

- **La table a été récupérée avec un filtre** composé de règles **égal à** et **in** reliées par **AND**. Seules les lignes couvertes par le filtre sont remplacées ; les lignes que vous avez ajoutées en dehors du filtre sont tout de même enregistrées, et le message indique combien. Une table récupérée avec tout autre filtre ne peut pas être enregistrée ; récupérez-la à nouveau avec un tel filtre, ou sans filtre.
- **La feuille affiche des lignes de détail** issues de [Show detail rows](/fr/reference/cli/plaidxl/drill/#afficher-les-lignes-de-détail). Seules les lignes qui sous-tendent cette valeur sont remplacées.
- **Votre accès à la table est limité à certaines lignes.** Seules les lignes que vous pouvez voir sont remplacées, et les lignes des autres personnes sont donc conservées. Si la feuille contient des lignes en dehors de votre accès, rien n'est enregistré et le message les liste ; supprimez ces lignes, ou demandez à un Architecte du projet de les enregistrer.

### Annuler un enregistrement

PlaidXL crée un point de restauration avant d'écrire et le conserve pendant 7 jours. Si l'écriture échoue, la table est remise dans son état d'origine, et vos modifications restent dans la feuille.

Pour annuler un enregistrement, cliquez sur **Défaire** dans le message, ou sur **Undo last write** dans le groupe **Écriture** du ruban. La table revient à son état d'avant votre enregistrement (pour un enregistrement qui n'a remplacé que certaines lignes, seulement ces lignes). Actualisez la feuille pour le voir. Consultez [Undo a Write](/fr/reference/cli/plaidxl/write-values/#annuler-une-écriture). Une table qui ne peut pas recevoir de point de restauration est tout de même enregistrée, et le message indique que l'enregistrement ne peut pas être annulé.
