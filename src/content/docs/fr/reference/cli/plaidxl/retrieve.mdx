Une fois que vous êtes [connecté](/fr/reference/cli/plaidxl/connect/), le volet des tâches liste vos projets. Vous choisissez un projet, puis vous récupérez ses tables et ses dimensions dans le classeur.

## Choisir un projet

La section **Projet** liste tous les projets que vous pouvez ouvrir, dans les mêmes dossiers que dans PlaidCloud. Les dossiers sont réduits au départ : cliquez sur l'un d'eux pour l'ouvrir, ou saisissez du texte dans **Filter projects by name** pour restreindre la liste.

Cliquez sur un projet pour le sélectionner. Ses tables apparaissent dans l'onglet **Tables** et ses dimensions dans l'onglet **Dimensions**.

Le projet sélectionné est aussi celui que les [fonctions personnalisées](/fr/reference/cli/plaidxl/functions/) et les commandes d'exploration de PlaidXL lisent. La sélection s'applique à tous les classeurs que vous avez ouverts, et pas seulement à celui-ci.

### Définir un projet par défaut

Pour qu'un classeur sélectionne le même projet chaque fois que vous ouvrez son volet des tâches, sélectionnez le projet et cliquez sur **Définir par défaut**. Le projet par défaut est enregistré dans le classeur : il suit donc le fichier chez toute personne qui l'ouvre. **Clear Default** le supprime.

## Récupérer une table

1. Dans l'onglet **Tables**, cliquez sur une table. Utilisez **Filter tables by name** pour la trouver dans une longue liste. Les valeurs **Lignes** et **Colonnes** à côté de chaque table indiquent sa taille.
2. Sous **Colonne**, décochez la case de chaque colonne dont vous n'avez pas besoin. Toutes les colonnes sont sélectionnées au départ.
3. Pour ne récupérer que certaines lignes, sélectionnez **Avancé** et créez un filtre. Consultez [Filtrer les lignes](#filtrer-les-lignes).
4. Sous **Select where to place this table**, choisissez :
   - **Matching Worksheet** — une feuille de calcul portant le nom de la table. PlaidXL crée la feuille si elle n'existe pas, et écrit la table à partir de la cellule A1 si elle existe.
   - **Current Selection** — à partir de la cellule que vous avez sélectionnée dans la feuille active.
5. Cliquez sur **Retrieve Table**.

Les données arrivent avec une ligne d'en-tête, prêtes à être exploitées. La ligne d'en-tête est en gras et grisée, la largeur des colonnes est ajustée et les filtres sont activés. Une table récupérée dans **Matching Worksheet** reçoit également :

- Une ligne d'en-tête figée, qui reste visible pendant que vous faites défiler la feuille.
- Une plage nommée couvrant les données, de sorte que les formules qui l'utilisent suivent les données lorsqu'elles s'agrandissent à l'actualisation. Son nom est celui de la feuille de calcul précédé d'un trait de soulignement : une table nommée **Sample data** arrive dans la feuille `Sample_data`, avec la plage nommée `_Sample_data`.

Pour nommer la feuille de calcul, PlaidXL tronque le nom de la table à la limite d'Excel de 31 caractères, ne conserve que les lettres simples (A–Z), les chiffres et les espaces, et transforme les espaces en traits de soulignement. Une table nommée **Q3 Revenue (EMEA)** est récupérée dans la feuille `Q3_Revenue_EMEA`. Les traits de soulignement et les lettres accentuées sont également supprimés : **sales_2024** est donc récupérée dans la feuille `sales2024`.

<Aside type="tip">Les tables larges sont lentes à charger dans Excel. Décocher les colonnes dont vous n'avez pas besoin est le moyen le plus rapide d'accélérer une grosse récupération.</Aside>

### Tables affichées en rouge

Une table s'affiche en rouge lorsqu'elle est trop grande pour une feuille de calcul (plus de 1 048 576 lignes ou 16 384 colonnes) ou lorsque PlaidCloud ne peut pas indiquer sa taille, comme pour une table qui n'a jamais été chargée. Filtrez les lignes avec **Avancé** et décochez des colonnes jusqu'à ce qu'elle tienne. PlaidXL récupère au maximum 1 048 575 lignes plus la ligne d'en-tête, et s'arrête là sans avertissement.

## Filtrer les lignes

Sélectionnez **Avancé** pour ouvrir le générateur de filtres. Chaque règle choisit une colonne, une comparaison telle que **égal à**, **dans**, **contient**, **commence par** ou **est vide**, et une valeur. Utilisez des groupes **AND**, des groupes **OR**, ou les deux pour combiner les règles.

Le filtre compare les valeurs comme du texte : il correspond donc à des valeurs exactes et à des motifs de texte. Les plages de nombres ou de dates ne sont pas disponibles ; pour récupérer une plage, filtrez sur les valeurs dont vous avez besoin avec **dans**, ou récupérez la table et filtrez-la dans Excel.

- Saisissez les valeurs sans guillemets : `EMEA`, et non `"EMEA"`.
- Pour une comparaison qui accepte plusieurs valeurs, comme **dans**, séparez les valeurs par une virgule et un espace : `EMEA, APAC, NA`.

Le filtre ne s'applique que tant que **Avancé** est sélectionné. PlaidXL mémorise le filtre et les colonnes que vous avez choisis avec chaque table récupérée, et les réutilise lorsque vous actualisez.

## Refresh All Tables

**Refresh All Tables**, dans le volet des tâches ou dans le ruban sous **PlaidCloud → PlaidXL Controls**, récupère les données actuelles de PlaidCloud pour chaque table que vous avez importée dans le classeur, avec les colonnes et le filtre que vous avez choisis pour chacune.

Pendant l'exécution, l'onglet de la feuille de chaque table devient jaune. Il devient vert lorsque cette table est à jour. Les formules qui utilisent les données se recalculent comme d'habitude ; actualisez les tableaux croisés dynamiques construits dessus avec **Data → Refresh All** d'Excel.

PlaidXL enregistre la liste des tables récupérées dans le classeur : **Refresh All Tables** fonctionne donc pour toute personne qui ouvre le fichier et se connecte avec un accès aux mêmes projets.

Chaque **Retrieve Table** ajoute la table à la liste d'actualisation, et il n'existe aucun moyen d'en retirer une. Récupérez chaque table une seule fois, puis utilisez **Refresh All Tables** pour la mettre à jour : récupérer de nouveau la même table fait que chaque actualisation la récupère deux fois.

<Aside type="caution">
Une table récupérée dans **Current Selection** est actualisée dans les mêmes cellules de **la feuille active** au moment où vous cliquez sur **Refresh All Tables**, ce qui écrase leur contenu. Récupérez les tables que vous prévoyez d'actualiser dans **Matching Worksheet** ; elles s'actualisent toujours dans leur propre feuille.

Une actualisation écrit par-dessus les anciennes données sans les effacer au préalable. Si une table compte désormais moins de lignes ou de colonnes qu'auparavant, les lignes ou colonnes supplémentaires de la récupération précédente restent dans la feuille. Effacez le contenu de la feuille avant d'actualiser une table qui a pu rétrécir.
</Aside>

## Récupérer une dimension

L'onglet **Dimensions** liste les [dimensions](/fr/guides/dimensions/dimensions/) du projet.

1. Cliquez sur une dimension. Utilisez **Filter dimensions by name** pour la trouver.
2. Sous **Select where to place this dimension**, choisissez **Matching Worksheet** ou **Current Selection**.
3. Cliquez sur **Retrieve Dimension**.

PlaidXL écrit les nœuds de la dimension dans une seule colonne, dans l'ordre de la hiérarchie. Les dimensions n'ont pas de filtres de colonnes ou de lignes, et **Refresh All Tables** ne les actualise pas : récupérez de nouveau la dimension pour prendre en compte les changements.

Pour afficher une hiérarchie avec retrait et regroupement en plan Excel, ou pour partir d'un nœud ou d'une hiérarchie alternative particuliers, utilisez plutôt [`PLAIDXL.DIMENSION.GET_DIMENSION`](/fr/reference/cli/plaidxl/functions/#get_dimension) ou les [commandes d'exploration](/fr/reference/cli/plaidxl/ribbon/#drill-functions).

## Modifier les données

PlaidXL lit les données depuis PlaidCloud et n'écrit jamais en retour. Vous pouvez librement modifier, trier et ajouter des formules dans une feuille récupérée, sans que rien ne change dans le projet. Une actualisation écrit les données PlaidCloud actuelles par-dessus la plage de la table : conservez donc vos propres calculs dans une feuille distincte.

Pour modifier les données elles-mêmes, mettez-les à jour dans PlaidCloud, par exemple avec un [workflow](/fr/guides/workflows/) ou l'[Éditeur de données](/fr/guides/projects/managing-data-editors/).
