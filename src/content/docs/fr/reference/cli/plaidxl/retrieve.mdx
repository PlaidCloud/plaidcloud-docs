Une fois que vous êtes [connecté](/fr/reference/cli/plaidxl/connect/), le volet des tâches répertorie vos projets. Vous choisissez un projet, puis vous extrayez ses tables et ses dimensions dans le classeur.

## Choisir un projet

L'en-tête du volet des tâches affiche votre espace de travail et le projet auquel ce classeur est lié. Cliquez sur le nom du projet pour ouvrir la liste des projets, qui présente tous les projets que vous pouvez ouvrir, dans les mêmes dossiers que dans PlaidCloud. Les dossiers sont repliés au départ : cliquez sur l'un d'eux pour l'ouvrir, ou saisissez du texte dans **Filter projects by name** pour réduire la liste. Si votre espace de travail ne contient qu'un seul projet que vous pouvez ouvrir, PlaidXL y lie le classeur pour vous, et l'en-tête indique **Linked to** suivi du projet, avec **change** à côté.

Cliquez sur un projet pour le sélectionner. Ses tables apparaissent dans l'onglet **Tables** et ses dimensions dans l'onglet **Dimensions**.

### Le projet appartient au classeur

Le projet sélectionné est enregistré dans le classeur : chaque classeur a donc son propre projet. C'est le projet que les [fonctions personnalisées](/fr/reference/cli/plaidxl/functions/) et les commandes de drill de PlaidXL lisent dans ce classeur. Si vous ouvrez deux classeurs, chacun lit son propre projet, et lorsque vous rouvrez un classeur, le volet des tâches revient à son projet. Le projet accompagne le fichier chez toute personne qui l'ouvre et se connecte avec un accès à ce projet.

Un projet appartient à un seul espace de travail. Si vous [changez d'espace de travail](/fr/reference/cli/plaidxl/connect/#se-déconnecter-ou-changer-despace-de-travail), un classeur lié à un projet de l'ancien espace de travail n'a plus de projet tant que vous n'en choisissez pas un. Les tables et dimensions que vous avez extraites de l'ancien espace de travail restent dans le classeur, mais elles ne sont ni actualisées ni enregistrées : **Refresh All Tables** indique que des tables ou des dimensions d'un autre espace de travail n'ont pas été actualisées. Extrayez-les de nouveau dans le nouvel espace de travail pour les lier.

## Récupérer une table

1. Dans l'onglet **Tables**, cliquez sur une table. Utilisez **Filter tables by name** pour la trouver dans une longue liste. Les valeurs **Lignes** et **Colonnes** à côté de chaque table indiquent sa taille.
2. Sous **Colonne**, décochez la case de chaque colonne dont vous n'avez pas besoin. Toutes les colonnes sont sélectionnées au départ.
3. Pour n'extraire qu'une partie des lignes, sélectionnez **Avancé** et créez un filtre. Consultez [Filtrer les lignes](#filtrer-les-lignes).
4. Sous **Select where to place this table**, choisissez :
   - **Matching Worksheet** : une feuille de calcul portant le nom de la table, à partir de la cellule A1. PlaidXL crée la feuille si elle n'existe pas.
   - **Current Selection** : à partir de la cellule que vous avez sélectionnée dans la feuille active.
5. Cliquez sur **Retrieve Table**.

Les données arrivent sous forme de tableau Excel portant le nom de la table PlaidCloud : les formules, les tableaux croisés dynamiques et les graphiques qui y font référence suivent donc les données lorsqu'elles augmentent ou diminuent. Les nombres, les dates et les heures reçoivent un format adapté à leur type de données, ou le format numérique défini sur la colonne dans PlaidCloud. Les colonnes de texte sont mises en forme comme du texte : un code tel que `0012` conserve donc ses zéros de tête. La première fois que vous extrayez une table, sa ligne d'en-tête est figée et ses colonnes sont dimensionnées pour s'ajuster au contenu.

Si les cellules où la table doit aller contiennent déjà autre chose qu'une table PlaidXL, PlaidXL place la table dans une nouvelle feuille et vous indique où. Si la table devait recouvrir une partie d'un tableau Excel que PlaidXL ne gère pas, rien ne change et le message indique **Move that Table or convert it to a range, then try again.**

Extraire une table déjà présente dans la feuille l'actualise sur place : vos propres colonnes restent, et une colonne source que vous décochez conserve son en-tête, avec les cellules situées en dessous vidées.

Les identifiants entiers trop grands pour qu'Excel les conserve exactement (supérieurs à 9 007 199 254 740 991) et les dates antérieures au 1er mars 1900 arrivent sous forme de texte, de sorte qu'ils s'affichent et s'enregistrent exactement.

Pour nommer la feuille de calcul, PlaidXL ne conserve que les lettres simples (A–Z), les chiffres, les traits de soulignement et les espaces, remplace les espaces par des traits de soulignement et tronque le nom à la limite d'Excel de 31 caractères. Une table nommée **Q3 Revenue (EMEA)** s'extrait dans la feuille `Q3_Revenue_EMEA`, et **sales_2024** dans `sales_2024`. Les lettres accentuées sont supprimées.

Les grandes tables s'extraient beaucoup plus vite dans Excel sur le web et dans les versions récentes d'Excel de bureau. Une table de 70 000 lignes et 17 colonnes prend environ 15 à 20 secondes sur le web, et une table de 143 000 lignes et 77 colonnes environ une minute, là où il fallait autrefois plus de dix minutes. Les versions plus anciennes d'Excel fonctionnent toujours, simplement sans cette accélération. Les colonnes sont dimensionnées d'après l'en-tête et les premières lignes.

<Aside type="tip">Les tables larges sont les plus lentes à charger dans Excel. Décocher les colonnes dont vous n'avez pas besoin est le moyen le plus rapide d'accélérer une grande extraction.</Aside>

### Texte plus long qu'une cellule Excel

Une cellule Excel contient au maximum 32 767 caractères : un texte plus long s'affiche donc tronqué. Lorsqu'une table contient un tel texte, le volet des tâches indique quelles colonnes de quelle table contiennent du texte de plus de 32 767 caractères, la limite d'une cellule Excel, et qu'Excel l'affiche tronqué : l'enregistrement est donc désactivé pour cette table. Enregistrer tronquerait aussi le texte dans PlaidCloud : **Save to PlaidCloud** refuse donc cette table.

### Tables affichées en rouge

Une table s'affiche en rouge, avec l'info-bulle **Too large for an Excel worksheet**, lorsqu'elle compte plus de 1 048 575 lignes ou 16 384 colonnes, ou lorsque PlaidCloud ne peut pas en indiquer la taille, comme pour une table qui n'a jamais été chargée. Vous pouvez quand même l'extraire : les lignes qui ne tiennent pas sur une feuille de calcul continuent sur la suivante, nommée d'après la première avec ` (2)`, ` (3)`, et ainsi de suite. Une table répartie sur plusieurs feuilles ne peut pas être réenregistrée dans PlaidCloud : filtrez donc les lignes avec **Avancé** et décochez des colonnes jusqu'à ce qu'elle tienne, si vous prévoyez de la modifier.

## Filtrer les lignes

Sélectionnez **Avancé** pour ouvrir le générateur de filtres. Chaque règle choisit une colonne, une comparaison telle que **Égal à**, **dans**, **contient**, **Commence par** ou **est vide**, et une valeur. Utilisez des groupes **AND**, des groupes **OR**, ou les deux pour combiner les règles.

Le filtre compare les valeurs comme du texte : il correspond donc à des valeurs exactes et à des motifs de texte. Les plages de nombres ou de dates ne sont pas disponibles ; pour extraire une plage, filtrez sur les valeurs voulues avec **dans**, ou extrayez la table et filtrez-la dans Excel.

- Saisissez les valeurs sans guillemets : `EMEA`, et non `"EMEA"`.
- Pour une comparaison qui accepte plusieurs valeurs, comme **dans**, séparez les valeurs par une virgule et une espace : `EMEA, APAC, NA`.

Le filtre ne s'applique que lorsque **Avancé** est sélectionné. PlaidXL mémorise le filtre et les colonnes que vous avez choisies pour chaque table extraite, et les réutilise lors de l'actualisation. Un filtre composé uniquement de règles **Égal à** et **dans** reliées par **AND** détermine aussi les lignes qu'un [enregistrement](#enregistrer-une-table-dans-plaidcloud) remplace.

## Actualiser toutes les tables

PlaidXL tient une liste des tables et des dimensions que vous avez extraites dans le classeur, et les actualise avec les colonnes et le filtre que vous avez choisis pour chacune. La liste est enregistrée dans le classeur : l'actualisation fonctionne donc pour toute personne qui ouvre le fichier et se connecte avec un accès aux mêmes projets.

- **Refresh This Sheet**, dans le volet des tâches, actualise les tables de la feuille active.
- **Refresh All Tables**, dans le volet des tâches, actualise toutes les tables et dimensions du classeur.
- Le menu **Actualiser** du ruban actualise aussi une feuille, la sélection ou toutes les tables, et recalcule les formules PlaidXL. Consultez [Actualiser](/fr/reference/cli/plaidxl/ribbon/#actualiser).

Pendant une actualisation, le volet des tâches affiche sa progression pour chaque table (interrogation de PlaidCloud, puis part des lignes écrites) avec un bouton **Annuler**. Trois tables sont actualisées à la fois, et le lancement d'une autre actualisation s'ajoute à celle qui est déjà en cours. Une fois l'actualisation terminée, le volet répertorie chaque table avec son nombre de lignes, ou la raison de l'échec. Cliquez sur une table de la liste pour la sélectionner. L'échec d'une table n'arrête pas les autres.

**Annuler** laisse le classeur tel qu'il était avant l'actualisation : les données d'une table ne sont remplacées qu'une fois toutes ses lignes arrivées. Pour les tables StarRocks, cela arrête la requête dans PlaidCloud ; sur d'autres moteurs, comme Databend et Snowflake, PlaidXL cesse d'attendre mais la requête n'est pas arrêtée dans PlaidCloud. Le calcul d'Excel est suspendu pendant l'écriture des données et s'exécute une fois à la fin.

### Ce qu'une actualisation conserve

Une table est actualisée dans le même tableau Excel, où qu'il se trouve désormais : une table extraite dans **Current Selection** est actualisée dans ses propres cellules, dans sa propre feuille, même si vous déplacez ou renommez le tableau Excel. Le tableau s'agrandit ou se réduit pour s'ajuster aux nouvelles données, et les lignes et colonnes restantes d'une extraction précédente plus volumineuse sont effacées.

- **Vos propres colonnes** : les colonnes que vous avez ajoutées à côté des données dans le tableau Excel sont conservées. Une formule identique dans chaque ligne est recopiée vers le bas sur les nouvelles lignes. Les autres valeurs, comme les notes, suivent leur ligne lorsque la table a des colonnes clés dans PlaidCloud ; les notes des lignes qui n'existent plus sont conservées sous la table. Sans colonnes clés, les notes restent à leur place, selon leur position.
- **Votre mise en forme** : un format numérique que vous avez défini sur une colonne est conservé.

Une actualisation qui déborderait sur d'autres cellules, ou sur un tableau Excel qui n'est pas celui de la table, ne change rien et indique **Move what is there, then try again.** Si le tableau Excel a changé pendant l'arrivée des lignes, le message demande de réessayer.

Si la feuille de calcul d'une table a été supprimée, la table est ignorée et PlaidXL propose **Recreate sheet** ou **Stop refreshing**.

Si Excel refuse une partie de l'écriture finale, le volet indique que la table n'a été écrite qu'en partie, avec la raison, et demande de l'actualiser avant de l'enregistrer. **Save to PlaidCloud** refuse cette table tant qu'une actualisation n'a pas réussi.

### Retirer une table de la liste d'actualisation

Sous **On this sheet**, le volet des tâches répertorie chaque table et dimension extraite dans la feuille active, avec son nombre de lignes et la date de sa dernière actualisation. Cliquez sur **Stop refreshing** pour en retirer une de la liste d'actualisation. Les données restent dans la feuille, et le message propose **Défaire**.

Extraire une table par-dessus une table déjà présente dans la liste la remplace dans la liste : une table n'est donc actualisée qu'une seule fois, quel que soit le nombre de fois où vous l'extrayez. À côté de chaque table, **Copier** copie le nom de son tableau Excel pour l'utiliser dans des formules.

## Récupérer une dimension

L'onglet **Dimensions** répertorie les [dimensions](/fr/guides/dimensions/dimensions/) du projet.

1. Cliquez sur une dimension. Utilisez **Filter dimensions by name** pour la trouver.
2. Sous **Select where to place this dimension**, choisissez **Matching Worksheet** ou **Current Selection**.
3. Cliquez sur **Retrieve Dimension**.

PlaidXL écrit les nœuds de la dimension dans une seule colonne, selon l'ordre de la hiérarchie. Les dimensions n'ont pas de filtres de colonnes ni de lignes. **Refresh All Tables** les actualise avec vos tables.

Pour présenter une hiérarchie avec une indentation et un regroupement en plan Excel, ou pour partir d'un nœud ou d'une hiérarchie alternative particulier, utilisez plutôt les [commandes de drill](/fr/reference/cli/plaidxl/drill/) ou [`PLAIDXL.DRILL`](/fr/reference/cli/plaidxl/functions/#drill). Pour placer un seul membre dans une cellule, cliquez sur **Pick member...** dans l'onglet **Dimensions** ; consultez [Choisir un membre](/fr/reference/cli/plaidxl/drill/#choisir-un-membre).

## Enregistrer une table dans PlaidCloud

Une table que vous avez extraite dans le classeur peut être réenregistrée, ce qui remplace les lignes de la table PlaidCloud par le contenu de la feuille.

1. Accédez à la feuille de calcul qui contient la table extraite. Sous **On this sheet**, le volet des tâches répertorie chaque table qui y a été extraite. S'il n'y en a aucune, le volet indique d'y extraire d'abord une table.
2. Cliquez sur **Save to PlaidCloud** à côté de la table, ou cliquez sur **Save sheet to PlaidCloud...** dans le groupe **Écriture** du ruban (**Ctrl+Alt+Maj+W**, ou **⌘⌥⇧W** sur Mac) pour enregistrer toutes les tables de la feuille.

L'enregistrement a lieu immédiatement, sans confirmation. Le message indique combien de lignes ont été enregistrées, signale tout ce que vous devez savoir et propose **Défaire**.

PlaidXL lit la ligne d'en-tête de la table et les lignes situées en dessous. L'en-tête doit toujours correspondre aux colonnes que vous avez extraites, et les valeurs sont converties selon le type de données de chaque colonne. Si une valeur ne peut pas être convertie, rien n'est écrit et les lignes en échec sont listées. Les définitions de colonnes dans PlaidCloud restent inchangées.

### Ce qui est enregistré

- Les cellules vides sont enregistrées comme vides.
- Un nombre écrit avec une virgule, comme `1,5`, n'est pas lu comme 15. Un entier trop grand pour la colonne est signalé pour sa ligne, et la date du 29 février 1900, qu'Excel invente, est refusée.
- Les lignes vides situées à l'intérieur des lignes extraites sont ignorées. Au-delà, la table se termine à la première ligne vide ; les lignes situées plus bas ne sont pas enregistrées, et le message les nomme.
- Les colonnes que vous n'avez pas extraites sont vidées dans PlaidCloud, et le message les nomme.
- Si la table a changé dans PlaidCloud après son extraction, votre enregistrement la remplace et le message l'indique. Le point de restauration conserve ce qui s'y trouvait.
- Si vous avez enregistré une feuille d'exploration et que les membres sous ses nœuds ont changé depuis son extraction, rien n'est écrit : le message indique **Retrieve again before saving.** L'extraction ou l'actualisation remplace la feuille : copiez donc d'abord toute modification que vous n'avez pas enregistrée.

### Enregistrements qui ne remplacent qu'une partie des lignes

Un enregistrement ne remplace que ses propres lignes et conserve le reste de la table dans les cas suivants :

- **La table a été extraite avec un filtre** composé de règles **Égal à** et **dans** reliées par **AND**. Seules les lignes couvertes par le filtre sont remplacées ; les lignes que vous avez ajoutées en dehors du filtre sont tout de même enregistrées, et le message indique combien. Une table extraite avec tout autre filtre ne peut pas être enregistrée ; extrayez-la de nouveau avec un tel filtre, ou sans filtre.
- **La feuille affiche des lignes de détail** issues de [Show detail rows](/fr/reference/cli/plaidxl/drill/#afficher-les-lignes-de-détail). Seules les lignes qui se trouvent derrière cette valeur sont remplacées.
- **Votre accès à la table est limité à certaines lignes.** Seules les lignes que vous pouvez voir sont remplacées : les lignes des autres personnes sont donc conservées. Si la feuille contient des lignes en dehors de votre accès, rien n'est enregistré et le message les liste ; supprimez ces lignes et enregistrez de nouveau.

### Annuler un enregistrement

PlaidXL crée un point de restauration avant d'écrire. Chaque enregistrement conserve son propre point de restauration pendant 7 jours : **Défaire** fonctionne donc jusqu'à 7 jours après chaque enregistrement, même si vous avez enregistré de nouveau depuis. Cela s'applique aux tables Lakehouse. Si l'écriture échoue, la table est remise dans son état d'origine et vos modifications restent dans la feuille, sauf si quelqu'un d'autre a modifié la table après le début de l'écriture ; elle est alors laissée telle quelle et le message l'indique.

Pour annuler un enregistrement, cliquez sur **Défaire** dans le message, ou sur **Undo last write** dans le groupe **Écriture** du ruban. La table revient à son état d'avant votre enregistrement (pour un enregistrement qui n'a remplacé qu'une partie des lignes, seulement ces lignes). Actualisez la feuille pour le voir. Consultez [Annuler une écriture](/fr/reference/cli/plaidxl/write-values/#annuler-une-écriture). Si un enregistrement ne peut ni se terminer ni être annulé, le message nomme le point de restauration afin que la table puisse être restaurée ; **Défaire** écrase alors aussi toute modification apportée à la table depuis. Une table qui ne peut pas recevoir de point de restauration est tout de même enregistrée, et le message indique que l'enregistrement ne peut pas être annulé.

Seule la personne et l'espace de travail à l'origine d'une écriture peuvent l'annuler.
