Une fois [connecté](/fr/reference/cli/plaidxl/connect/), le volet des tâches liste vos projets. Vous choisissez un projet, puis vous récupérez ses tables et ses dimensions dans le classeur.

## Choisir un projet

L'en-tête du volet des tâches affiche votre espace de travail et le projet auquel ce classeur est lié. Cliquez sur le nom du projet pour ouvrir la liste des projets, qui affiche tous les projets que vous pouvez ouvrir, dans les mêmes dossiers que ceux que vous voyez dans PlaidCloud. Les dossiers sont réduits au départ ; cliquez sur l'un d'eux pour l'ouvrir, ou saisissez du texte dans **Filter projects by name** pour restreindre la liste.

Cliquez sur un projet pour le sélectionner. Ses tables apparaissent dans l'onglet **Tables** et ses dimensions dans l'onglet **Dimensions**.

### Le projet appartient au classeur

Le projet sélectionné est enregistré dans le classeur : chaque classeur a donc son propre projet. C'est le projet que les [fonctions personnalisées](/fr/reference/cli/plaidxl/functions/) PlaidXL et les commandes d'exploration lisent dans ce classeur. Si vous ouvrez deux classeurs, chacun lit son propre projet, et lorsque vous rouvrez un classeur, le volet des tâches revient à son projet. Le projet accompagne le fichier auprès de toute personne qui l'ouvre et se connecte avec un accès à ce projet.

Un projet appartient à un seul espace de travail. Si vous [changez d'espace de travail](/fr/reference/cli/plaidxl/connect/#se-déconnecter-ou-changer-despace-de-travail), un classeur lié à un projet de l'ancien espace de travail n'a plus de projet tant que vous n'en choisissez pas un. Les tables que vous avez récupérées depuis l'ancien espace de travail restent dans le classeur, mais **Refresh All Tables** les ignore, et le volet des tâches vous indique leur nombre. Récupérez-les de nouveau dans le nouvel espace de travail pour les lier.

## Récupérer une table

1. Dans l'onglet **Tables**, cliquez sur une table. Utilisez **Filter tables by name** pour la trouver dans une longue liste. Les **Rows** et **Columns** à côté de chaque table indiquent sa taille.
2. Sous **Column**, décochez la case de toute colonne dont vous n'avez pas besoin. Toutes les colonnes sont sélectionnées au départ.
3. Pour ne récupérer que certaines lignes, sélectionnez **Advanced** et construisez un filtre. Consultez [Filtrer les lignes](#filtrer-les-lignes).
4. Sous **Select where to place this table**, choisissez :
   - **Matching Worksheet** — une feuille de calcul portant le nom de la table. PlaidXL crée la feuille si elle n'existe pas, et écrit la table à partir de la cellule A1 si elle existe.
   - **Current Selection** — à partir de la cellule que vous avez sélectionnée dans la feuille active.
5. Cliquez sur **Retrieve Table**.

Les données arrivent avec une ligne d'en-tête, prêtes à être utilisées. La ligne d'en-tête est en gras et ombrée, la largeur des colonnes est ajustée et les filtres sont activés. Une table récupérée vers **Matching Worksheet** obtient en plus :

- Une ligne d'en-tête figée, qui reste visible pendant le défilement.
- Une plage nommée sur les données, de sorte que les formules qui l'utilisent suivent les données lorsqu'elles s'étendent à l'actualisation. Son nom est le nom de la feuille précédé d'un trait de soulignement : une table nommée **Sample data** arrive dans la feuille `Sample_data`, avec la plage nommée `_Sample_data`.

Pour nommer la feuille, PlaidXL tronque le nom de la table à la limite d'Excel de 31 caractères, ne conserve que les lettres simples (A–Z), les chiffres et les espaces, et transforme les espaces en traits de soulignement. Une table nommée **Q3 Revenue (EMEA)** est récupérée dans la feuille `Q3_Revenue_EMEA`. Les traits de soulignement et les lettres accentuées sont aussi supprimés : **sales_2024** est donc récupérée dans la feuille `sales2024`.

<Aside type="tip">Les tables larges sont lentes à charger dans Excel. Décocher les colonnes dont vous n'avez pas besoin est le moyen le plus rapide d'accélérer une récupération volumineuse.</Aside>

### Tables affichées en rouge

Une table s'affiche en rouge lorsqu'elle est trop grande pour une feuille de calcul — plus de 1 048 576 lignes ou 16 384 colonnes — ou lorsque PlaidCloud ne peut pas indiquer sa taille, comme pour une table qui n'a jamais été chargée. Filtrez les lignes avec **Advanced** et décochez des colonnes jusqu'à ce qu'elle tienne. PlaidXL récupère au maximum 1 048 575 lignes plus la ligne d'en-tête, et s'arrête là sans avertissement.

## Filtrer les lignes

Sélectionnez **Advanced** pour ouvrir le générateur de filtres. Chaque règle choisit une colonne, une comparaison telle que **égal à**, **dans**, **contient**, **commence par** ou **est vide**, et une valeur. Utilisez des groupes **AND**, des groupes **OR**, ou les deux pour combiner les règles.

Le filtre compare les valeurs en tant que texte ; il correspond donc à des valeurs exactes et à des motifs de texte. Les plages de nombres ou de dates ne sont pas disponibles ; pour récupérer une plage, filtrez sur les valeurs dont vous avez besoin avec **dans**, ou récupérez la table et filtrez-la dans Excel.

- Saisissez les valeurs sans guillemets : `EMEA`, et non `"EMEA"`.
- Pour une comparaison qui accepte plusieurs valeurs, comme **dans**, séparez les valeurs par une virgule et une espace : `EMEA, APAC, NA`.

Le filtre ne s'applique que tant que **Advanced** est sélectionné. PlaidXL mémorise le filtre et les colonnes que vous avez choisies pour chaque table récupérée, et les réutilise lors de l'actualisation.

## Refresh All Tables

**Refresh All Tables** — dans le volet des tâches, ou dans le ruban sous **PlaidCloud → Data** — extrait les données actuelles de PlaidCloud pour chaque table que vous avez récupérée dans le classeur, avec les colonnes et le filtre que vous avez choisis pour chacune.

Pendant l'exécution, l'onglet de la feuille de chaque table devient jaune. Il devient vert lorsque cette table est à jour. Les formules qui utilisent les données se recalculent normalement ; actualisez les tableaux croisés dynamiques qui s'appuient dessus avec **Données → Actualiser tout** d'Excel.

PlaidXL enregistre la liste des tables récupérées dans le classeur : **Refresh All Tables** fonctionne donc pour toute personne qui ouvre le fichier et se connecte avec un accès aux mêmes projets.

Chaque **Retrieve Table** ajoute la table à la liste d'actualisation, et il n'existe aucun moyen d'en retirer une. Récupérez chaque table une seule fois, puis utilisez **Refresh All Tables** pour la mettre à jour — récupérer plusieurs fois la même table fait que chaque actualisation l'extrait deux fois.

<Aside type="caution">
Une table récupérée vers **Current Selection** s'actualise dans les mêmes cellules de **la feuille active au moment où** vous cliquez sur **Refresh All Tables**, en écrasant ce qui s'y trouve. Récupérez les tables que vous prévoyez d'actualiser vers **Matching Worksheet** ; elles s'actualisent toujours dans leur propre feuille.

Une actualisation écrit par-dessus les anciennes données sans les effacer au préalable. Si une table a désormais moins de lignes ou de colonnes qu'avant, les lignes ou colonnes en trop de l'extraction précédente restent dans la feuille. Effacez le contenu de la feuille avant d'actualiser une table qui a pu rétrécir.
</Aside>

## Récupérer une dimension

L'onglet **Dimensions** liste les [dimensions](/fr/guides/dimensions/dimensions/) du projet.

1. Cliquez sur une dimension. Utilisez **Filter dimensions by name** pour la trouver.
2. Sous **Select where to place this dimension**, choisissez **Matching Worksheet** ou **Current Selection**.
3. Cliquez sur **Retrieve Dimension**.

PlaidXL écrit les nœuds de la dimension dans une seule colonne, dans l'ordre de la hiérarchie. Les dimensions n'ont pas de filtres de colonnes ou de lignes, et **Refresh All Tables** ne les actualise pas — récupérez de nouveau la dimension pour prendre en compte les changements.

Pour présenter une hiérarchie avec des retraits et un regroupement en plan Excel, ou pour partir d'un nœud ou d'une hiérarchie alternative particuliers, utilisez plutôt [`PLAIDXL.DIMENSION.GET_DIMENSION`](/fr/reference/cli/plaidxl/functions/#get_dimension) ou les [commandes d'exploration](/fr/reference/cli/plaidxl/ribbon/#drill-functions).

## Enregistrer une table dans PlaidCloud

Une table que vous avez récupérée dans le classeur peut être réenregistrée, ce qui remplace la table PlaidCloud par le contenu de la feuille.

1. Accédez à la feuille de calcul qui contient la table récupérée. Sous **Save this sheet to PlaidCloud**, le volet des tâches liste chaque table liée à la feuille active, avec son nombre de lignes. Si la feuille n'en a aucune, le volet indique de d'abord y récupérer une table.
2. Cliquez sur **Save to PlaidCloud…** en regard de la table.
3. Lisez la confirmation, qui indique la table, le nombre de lignes à écrire et les colonnes, puis cliquez sur **Replace table**.

PlaidXL lit la ligne d'en-tête et les lignes situées en dessous à l'emplacement où la table a été récupérée. L'en-tête doit toujours correspondre aux colonnes que vous avez récupérées, et les valeurs sont converties dans le type de données de chaque colonne. Si une valeur ne peut pas être convertie, rien n'est écrit et les lignes en échec sont listées. Les définitions de colonnes dans PlaidCloud restent inchangées.

### Ce qui est enregistré

- Les cellules vides et les cellules affichant une erreur sont enregistrées comme vides.
- Les lignes ajoutées directement sous la table sont incluses, jusqu'à la première ligne vide.
- Une seule ligne vide parmi les lignes récupérées est ignorée ; les lignes qui l'entourent sont tout de même enregistrées. Deux lignes vides consécutives ou plus, avec des données en dessous, interrompent l'enregistrement et vous indiquent les lignes à supprimer ou à remplir.

### Avant de remplacer une table

- **Une table filtrée.** Si vous avez récupéré la table avec un filtre, toutes les lignes que le filtre a exclues sont supprimées de PlaidCloud. La confirmation le signale et vous demande de cocher une case avant d'activer **Replace table**.
- **Des colonnes que vous n'avez pas récupérées.** Si vous n'avez récupéré que certaines colonnes, PlaidXL demande **Empty columns that were not retrieved?** et les nomme. Cliquez sur **Write anyway** pour vider ces colonnes dans PlaidCloud, ou annulez pour ne rien écrire.
- **Quelqu'un d'autre a modifié la table.** Lorsque PlaidCloud peut le déterminer, l'enregistrement est refusé si la table a changé après que vous l'avez récupérée ; récupérez-la de nouveau et réappliquez vos modifications. Lorsqu'il ne peut pas le déterminer, la confirmation le signale, et tout ce que d'autres ont enregistré depuis que vous avez récupéré la table est écrasé.
- **Un point de restauration.** PlaidXL crée un point de restauration avant d'écrire et le conserve pendant 7 jours. Si l'écriture échoue, la table est remise dans son état d'origine. Une table qui ne peut pas recevoir de point de restauration demande **Write back without a restore point?**, et **Write anyway** poursuit sans point de restauration.

Après un enregistrement réussi, le message de confirmation inclut **Restore previous version**. Il ouvre la table dans PlaidCloud, où vous choisissez la version précédant juste cet enregistrement dans le menu **As of**.
