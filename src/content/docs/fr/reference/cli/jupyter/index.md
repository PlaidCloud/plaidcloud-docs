L'intégration Jupyter de PlaidCloud permet aux data scientists de travailler avec les tables de projet, d'exécuter des requêtes et d'utiliser PlaidCloud comme stockage de référence depuis des environnements de notebooks. L'authentification repose sur des jetons OAuth : les mêmes identifiants fonctionnent donc avec la CLI, les notebooks et l'API REST.

## Sujets

- [Ligne de commande](/fr/reference/cli/jupyter/command-line/) : la CLI autonome pour les interactions scriptées
- [Notebook Jupyter](/fr/reference/cli/jupyter/jupyter-notebook/) : utiliser PlaidCloud depuis les cellules d'un notebook
- [Configuration d'OAuth](/fr/reference/cli/jupyter/oauth-setup/) : mettre en place l'authentification
