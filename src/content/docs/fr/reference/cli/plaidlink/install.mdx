## Télécharger l'agent

Consultez les versions publiées sur [PlaidCloud.com](https://plaidcloud.com/) pour **PlaidLink**.

## Extraire l'agent

Extrayez le fichier zip téléchargé dans l'emplacement d'installation de votre choix. En général, cet emplacement est le suivant :

```bash
C:\Users\<Username here>\src\plaidlink
```

## Créer un fichier de configuration

<Aside>Si vous effectuez une mise à niveau depuis une version antérieure de l'agent, le fichier de configuration reste valide et vous pouvez ignorer cette étape.</Aside>

Copiez le fichier `config-dist.yaml` du répertoire de l'agent dans `%ProgramData\plaidcloud\`, puis renommez cette copie en `config.yaml`.

*(Modifiez cette configuration avec les valeurs récupérées depuis PlaidCloud.)*

## Installer le service de l'agent

Exécutez le fichier `install_windows_service.bat` dans le répertoire d'installation de l'agent OU

depuis une invite de commandes d'administrateur, accédez au répertoire d'installation de l'agent et exécutez :

```bash
.\PlaidLink.exe install
```

## Exécuter l'agent

<Aside>Pour installer un service Windows, il faut disposer des privilèges d'administrateur.</Aside>

Saisissez **`Services`** dans la barre de recherche de Windows et ouvrez le gestionnaire de services. Dans la liste des services, repérez **`PlaidCloud Agent`**.

Effectuez un clic droit sur le service et sélectionnez **« Start »** pour démarrer l'agent.

## Suspendre les mises à jour

Si, à un moment donné, vous souhaitez désactiver la mise à jour automatique de l'agent, ouvrez le fichier de configuration **'yaml'** de l'agent, 
ajoutez à la racine du fichier une ligne `freeze_updates: true`, puis redémarrez le service de l'agent. 

<Aside type="caution">Il n'est pas recommandé de désactiver les mises à jour automatiques à long terme.</Aside>
