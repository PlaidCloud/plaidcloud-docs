L'agent PlaidLink fonctionne conjointement avec le service PlaidCloud. Il fournit la connexion nécessaire 
pour interagir avec des systèmes non accessibles directement, tels que des bases de données et des systèmes de fichiers. L'agent réalise plusieurs actions essentielles, notamment :

* Lire et écrire dans des bases de données
* Lire et écrire des fichiers sur des lecteurs et des serveurs réseau
* Vérifier des conditions de capteur
* Interagir avec SAP ECC et SAP S/4HANA via des appels de fonction distants (RFC)
* Interagir avec SAP Profitability and Cost Management (PCM)
* Envoyer des messages et des notifications à des systèmes distants

## Créer un agent sur PlaidCloud

La gestion des agents PlaidLink s'effectue dans l'onglet Analyze de PlaidCloud. La première étape consiste à créer une nouvelle instance d'agent PlaidLink sur PlaidCloud.

### Pour créer un nouvel agent PlaidLink

1. Sélectionnez l'onglet Analyze
2. Sélectionnez le menu des outils en haut
3. Cliquez sur Agents PlaidLink
4. Créez un agent avec un nom adapté à l'environnement ou au serveur sur lequel il sera installé pour les opérations distantes

### Pour afficher les clés publique et privée de l'agent

1. Cliquez sur l'icône de modification pour afficher le formulaire
2. En bas du formulaire, vous trouverez les clés publique et privée générées aléatoirement lors de la création de l'agent

La clé privée n'apparaît qu'aux membres autorisés à modifier les agents.

<Aside>Conservez ces clés : elles seront utilisées dans la configuration de l'agent sur le serveur distant.</Aside>

### Pour générer de nouvelles clés aléatoires

1. Cliquez sur l'icône Régénérer de l'enregistrement de l'agent
2. Une fois les clés régénérées, n'oubliez pas de mettre à jour le fichier de configuration de l'agent avec les nouvelles clés sur le serveur distant.

<Aside>Conservez les clés publique et privée pour configurer l'agent distant à l'étape suivante.</Aside>

## Accès au compte de documents

Si l'agent doit avoir accès à un compte de documents pour téléverser ou télécharger des fichiers, il doit disposer de l'autorisation d'accéder à ce compte de documents.

### Pour accorder l'accès à un compte

1. Dans Documents, sélectionnez **Gérer** dans le rail
2. Lorsque la table des comptes apparaît, cliquez sur l'icône d'agent du compte pour lequel le nouvel agent doit disposer des droits de téléversement et de téléchargement
3. Faites glisser le nouvel agent dans la colonne Agents affectés
4. Enregistrez le formulaire de contrôle d'accès.

<Aside>Les agents ne peuvent téléverser et télécharger des fichiers que s'ils ont reçu l'accès à un ou plusieurs comptes de documents.</Aside>

## Accès à la connexion de données

Si l'agent doit avoir accès à une connexion de données, par exemple une base de données, il doit disposer de l'autorisation d'accéder aux informations de la connexion de données externe.


### Pour accorder l'accès à une connexion


1. Dans l'onglet Analyze, sélectionnez le menu Tools
2. Cliquez sur Connexions de données externes
3. Lorsque la table des connexions de données apparaît, cliquez sur l'icône d'agent de la connexion pour laquelle le nouvel agent doit disposer des droits d'utilisation
4. Faites glisser le nouvel agent dans la colonne Agents affectés et enregistrez le formulaire de contrôle d'accès.

<Aside>Les identifiants de connexion de données des agents sont gérés dans Connexions de données externes.</Aside>
