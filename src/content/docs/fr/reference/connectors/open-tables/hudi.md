## Documentation du catalogue
[Documentation de Apache Hudi](https://hudi.apache.org/docs/overview/).

## Configuration

Ce connecteur utilise un flux d'authentification propre au fournisseur et se configure directement depuis l'écran **Connexions** de votre espace de travail. Les champs de configuration affichés dépendent des identifiants que l'administrateur de votre locataire a provisionnés pour l'intégration.

Consultez la [documentation hudi](https://hudi.apache.org/docs/overview/) en amont pour connaître les derniers détails de configuration.

Si vous avez besoin d'aide pour configurer ce connecteur pour votre locataire, contactez votre équipe de compte : les identifiants propres au connecteur, les URL d'environnement et tout provisionnement préalable requis doivent généralement être coordonnés avec le support PlaidCloud.
