PlaidCloud Lakehouse peut fédérer des requêtes directement sur des formats de table ouverts, ce qui vous permet d'interroger les données sur place sans d'abord les déplacer dans PlaidCloud. C'est utile pour joindre les données du Lakehouse à des lacs de données externes déjà gérés dans Iceberg, Delta Lake ou Hudi.

## Formats

- [Apache Iceberg](/fr/reference/connectors/open-tables/iceberg/)
- [Delta Lake](/fr/reference/connectors/open-tables/delta-lake/)
- [Apache Hudi](/fr/reference/connectors/open-tables/hudi/)
- [Apache Hive](/fr/reference/connectors/open-tables/hive/) — format de table ouvert Hive (à ne pas confondre avec le [connecteur du moteur de requêtes Hive](/fr/reference/connectors/databases/hive/))
