S/4HANA n'a pas de connecteur propre. Il partage un type de connexion avec SAP ECC, car PlaidCloud atteint les deux par la même interface d'appels de fonction distants (Remote Function Call). Dans l'écran **Connexions**, choisissez **Nouveau → Instance SAP ECC / S/4HANA**.

**[Connecteur SAP ECC et S/4HANA →](/fr/reference/connectors/erp/sap-ecc/)** — tous les champs de configuration, pour les deux générations.

## Documentation officielle

Consultez la [documentation de SAP S/4HANA](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE).
