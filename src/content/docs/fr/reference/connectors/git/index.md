PlaidCloud se connecte à des hôtes Git afin que les workflows et les applications Panel puissent lire des dépôts versionnés. C'est utile pour récupérer de la configuration, des scripts ou des fichiers modélisés qui résident dans le contrôle de source plutôt que dans une base de données ou un compte de documents.

## Fournisseurs

- [PlaidCloud Git](/fr/reference/connectors/git/plaidcloud-git/) — le service Git géré intégré à votre espace de travail ; aucune URL de serveur ni aucun identifiant à configurer
- [GitHub](/fr/reference/connectors/git/github/)
- [GitLab](/fr/reference/connectors/git/gitlab/)
- [Bitbucket](/fr/reference/connectors/git/bitbucket/)
- [Azure Repos](/fr/reference/connectors/git/azure-repos/)
- [AWS CodeCommit](/fr/reference/connectors/git/codecommit/)
