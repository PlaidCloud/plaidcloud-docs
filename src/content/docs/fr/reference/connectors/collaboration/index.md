PlaidCloud se connecte aux plateformes de messagerie d'équipe afin que les workflows puissent envoyer des notifications, des alertes ou des mises à jour d'état directement dans les canaux que votre équipe surveille déjà. Elles sont le plus souvent utilisées avec les étapes de workflow [Notify via Slack](/fr/reference/workflow-steps/notifications/notify-via-slack/) et [Notify via Microsoft Teams](/fr/reference/workflow-steps/notifications/notify-via-microsoft-teams/).

## Fournisseurs

- [Microsoft Teams](/fr/reference/connectors/collaboration/teams/)
