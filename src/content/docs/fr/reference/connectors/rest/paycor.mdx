## Documentation de l'API
La [référence de l'API du fournisseur](https://developers.paycor.com/explore) couvre les points de terminaison de ce connecteur.

## Configuration de Paycor
Le processus de création et d'initialisation d'une application d'API Paycor est un peu plus long que chez les autres fournisseurs REST. Veillez à suivre les étapes décrites dans leur [page de démarrage rapide](https://developers.paycor.com/guides#quickStartLabel).

Les valeurs clés à noter sont les suivantes :
 - l'ID client OAuth de l'application
 - le secret client OAuth de l'application
 - la clé d'abonnement APIm
 - la clé de portée (Scope Key) de la version `current` de l'application

<Aside type="caution">N'oubliez pas d'« activer » l'application pour autoriser son utilisation</Aside>

Activez-la ici, en choisissant Production ou Bac à sable selon vos besoins :

| Environnement | URL du formulaire d'activation |
|-------------|---------------------|
| Bac à sable	  | https://hcm-demo.paycor.com/AppActivation/ClientActivation |
| Production  | https://hcm.paycor.com/AppActivation/ClientActivation |

<Aside type="danger">Si vous avez plusieurs organisations dans Paycor, vous aurez besoin d'identifiants de connexion distincts pour chacune. NE LES FUSIONNEZ PAS. Le portail des développeurs nécessite un identifiant unique et dédié pour chaque organisation afin de créer une application propre à l'organisation pour l'accès REST.</Aside>

## Configuration

Ces champs s'affichent lors de la création ou de la modification de cette connexion.

### Identification

| Champ | Type | Description |
|---|---|---|
| Nom | Texte | Nom d'affichage de cette connexion. |
| Alias | Texte (multiligne) | Alias ou remarques facultatifs sur la connexion. |
| Est active | Interrupteur | Indique si la connexion est activée. Désactivez-la pour la mettre en pause sans la supprimer. |
| Base en lecture seule | Interrupteur | Limite la connexion aux opérations en lecture seule. |
| Type d'accès | Sélection | Niveau d'accès de cette connexion : lecture seule, écriture seule ou lecture-écriture. |

### Identifiants

Saisissez les trois valeurs que vous avez notées pendant la [configuration de Paycor](#configuration-de-paycor). Vous n'avez à saisir ni hôte ni URL de jeton : PlaidCloud fournit l'hôte de l'API Paycor et le point de terminaison de jeton OAuth2.

| Champ | Type | Description |
|---|---|---|
| ID client OAuth2 | Texte | L'ID client OAuth de l'application issu de l'enregistrement de votre application Paycor. |
| Secret client OAuth2 | Mot de passe | Le secret client OAuth de l'application. Stocké chiffré. |
| Clé d'abonnement Paycor | Texte | La clé d'abonnement APIm de votre application Paycor. |

## Authentification

Paycor utilise OAuth2 avec un octroi par code d'autorisation ; la saisie des identifiants n'est donc que la première moitié du processus : vous devez aussi effectuer une connexion unique auprès de Paycor qui autorise PlaidCloud à extraire vos données.

1. **Saisissez les identifiants et enregistrez.** Renseignez les trois valeurs ci-dessus et enregistrez la connexion.
2. **Connectez-vous.** Cliquez sur **Se connecter à Paycor**. PlaidCloud ouvre une **fenêtre d'autorisation Paycor**. Le bouton est disponible une fois la connexion enregistrée.
3. **Connectez-vous et approuvez.** Connectez-vous à Paycor dans cette fenêtre et approuvez l'accès. Paycor vous renvoie vers PlaidCloud, qui stocke un **jeton d'actualisation** sur la connexion et l'utilise ensuite pour obtenir automatiquement des jetons d'accès.

<Aside type="caution">Autorisez les fenêtres contextuelles pour PlaidCloud. Si la fenêtre d'autorisation est bloquée, PlaidCloud vous en informe : autorisez les fenêtres contextuelles et cliquez de nouveau sur **Se connecter à Paycor**.</Aside>

L'hôte de l'API (`apis.paycor.com`) et le point de terminaison de jeton (`https://apis.paycor.com/sts/v1/common/token`) sont gérés par PlaidCloud. Aucun champ d'URL n'est à renseigner, et vous ne devriez pas avoir à les modifier.

### Réautoriser une connexion expirée

L'accès à Paycor peut expirer : le jeton d'actualisation expire ou est révoqué, ou l'application Paycor est désactivée. Dans ce cas, les workflows qui utilisent la connexion cessent de s'authentifier et échouent. Pour la rétablir :

1. Vérifiez que l'application Paycor est toujours **activée** (consultez les URL d'activation sous [Configuration de Paycor](#configuration-de-paycor)).
2. Ouvrez la connexion et cliquez sur **Se connecter à Paycor** pour relancer l'autorisation Paycor, puis connectez-vous et approuvez. Cela génère un nouveau jeton d'actualisation et la connexion reprend.

<Aside type="danger">Établissez et réparez les connexions Paycor via ce formulaire de connexion. Modifier la connexion sous-jacente avec un éditeur REST générique ou l'API peut écraser l'URL de jeton gérée et casser l'authentification.</Aside>
