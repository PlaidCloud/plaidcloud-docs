## Description

L'étape **DateTime Now (macro)** reproduit la macro empaquetée Alteryx *DateTime Now*. Elle s'exécute dans le moteur de workflow ; les résultats des macros empaquetées sont une approximation de la macro Alteryx.

## Paramètres

- **Table de sortie** et la chaîne **Format de sortie**.

## Format de sortie

La chaîne de format utilise les jetons de l'outil DateTime d'Alteryx, et la conversion les reprend tels quels. Si elle est laissée vide, elle utilise la valeur par défaut de l'outil, `day, dd Month, yyyy`, par exemple `Tuesday, 04 August, 2026`.

| Jeton | Rendu |
| --- | --- |
| `yyyy` / `yy` | Année sur quatre ou deux chiffres |
| `Month` / `Mon` | Nom du mois en toutes lettres ou abrégé |
| `MM` / `M` | Numéro du mois, avec ou sans zéro initial |
| `day` / `dy` | Nom du jour de la semaine en toutes lettres ou abrégé |
| `dd` / `d` | Jour du mois, avec ou sans zéro initial |
| `HH` / `H` | Heure sur 24 heures, avec ou sans zéro initial |
| `hh` / `h` | Heure sur 12 heures, avec ou sans zéro initial |
| `mm` | Minutes |
| `ss` | Secondes |
| `tt` | AM ou PM |

Les jetons sont sensibles à la casse : `MM` désigne le mois, `mm` les minutes.
