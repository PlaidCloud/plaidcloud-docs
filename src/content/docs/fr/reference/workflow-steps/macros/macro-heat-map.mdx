## Description

L'étape **Heat Map (macro)** reproduit la macro empaquetée Alteryx *Heat Map*. Elle s'exécute dans le moteur de workflow ; les résultats des macros empaquetées sont une approximation de la macro Alteryx.

## Paramètres

- **Source / Tables de sortie** et la **Distance maximale**.
