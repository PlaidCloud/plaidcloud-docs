## Description

L'étape **Pie Wedge Trade Area (macro)** reproduit la macro empaquetée Alteryx *Pie Wedge Trade Area*. Elle s'exécute dans le moteur de workflow ; les résultats des macros empaquetées sont une approximation de la macro Alteryx.

## Paramètres

- **Clients / Table des magasins**, la **Table de sortie** et la **Taille du tampon**.
