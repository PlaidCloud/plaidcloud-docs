## Description

L'étape **Create Samples (macro)** reproduit la macro empaquetée Alteryx *Create Samples*. Elle s'exécute dans le moteur de workflow ; les résultats des macros empaquetées sont une approximation de la macro Alteryx.

## Paramètres

- **Source / Tables de sortie**.
- **Estimation %** et **Graine aléatoire**.
