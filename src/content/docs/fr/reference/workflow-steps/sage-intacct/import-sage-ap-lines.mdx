## Description

Importez le détail au niveau des lignes des factures fournisseurs (Accounts Payable) depuis Sage Intacct via l'API REST Sage Intacct. Chaque ligne de résultat correspond à une ligne de facture, avec le compte du grand livre, les dimensions, le montant de la ligne et la clé de facture qui la relie à l'en-tête parent.

Associez cette étape à [Import Sage AP](../import-sage-ap/) (étape) pour charger les deux niveaux de granularité en vue d'une allocation, d'un reporting ou d'un rapprochement en aval.

## Éléments de configuration propres à l'étape

* **Connexion Sage** : la connexion REST Sage Intacct à utiliser pour la lecture. Les connexions Sage se gèrent dans **Tools > Connections**.
* **ID de la société** : la société Intacct à interroger. Obligatoire si vos identifiants d'expéditeur couvrent plusieurs sociétés.
* **ID d'entité (séparés par des virgules)** : limite l'importation à une ou plusieurs entités Intacct. Laissez vide pour importer toutes les entités auxquelles l'utilisateur a accès.
