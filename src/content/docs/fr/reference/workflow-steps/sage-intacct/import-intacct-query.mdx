## Description

Exécutez une requête ponctuelle sur n'importe quel type d'objet Sage Intacct et importez les résultats. Contrairement aux étapes dédiées [Sage AP](../import-sage-ap/) et [Sage AP Lines](../import-sage-ap-lines/), cette étape vous permet de cibler n'importe quel objet Intacct (grand livre, projets, clients, fournisseurs, objets personnalisés, etc.) et de choisir les champs et les filtres dont vous avez besoin.

La pagination est gérée automatiquement : l'étape fonctionne donc pour des jeux de résultats plus volumineux qu'une seule page de l'API Intacct.

## Éléments de configuration propres à l'étape

* **Connexion Sage** : la connexion REST Sage Intacct à utiliser pour la lecture. Les connexions Sage se gèrent dans **Tools > Connections**.
* **ID de la société** : la société Intacct à interroger.
* **ID d'entité (séparés par des virgules)** : limite la requête à une ou plusieurs entités Intacct. Laissez vide pour interroger toutes les entités.
* **Nom de l'objet** : l'objet Intacct à interroger, par exemple `GLACCOUNT`, `CUSTOMER`, `PROJECT` ou le nom de n'importe quel objet personnalisé.
* **Champs à importer** : tableau des noms de champs Intacct avec une case Enabled. Cliquez sur `Lookup Object Fields` pour remplir la liste à partir du schéma Intacct, puis utilisez `Select All` ou `Select None` pour tout cocher ou tout décocher d'un coup.
* **Filtres** : tableau de lignes de filtre. Chaque ligne se compose de `Field`, `Filter Type` et `Value`. Les types de filtre comprennent `Equal To`, `Not Equal To`, `Less Than`, `Less Than or Equal To`, `Greater Than`, `Greater Than or Equal To`, `Is Null` et `Is Not Null`. Les filtres s'appliquent côté serveur, avant la pagination.
