## Description

Importe les **soldes de comptes par dimension** de Sage Intacct via une connexion Sage (`get_accountbalancesbydimensions` d'Intacct), délimités par une plage de dates et une plage de comptes, les dimensions sélectionnées étant reportées sur chaque ligne. Le résultat est une balance générale : une ligne par compte et par combinaison de dimensions, avec un solde d'ouverture (`startbalance`), un solde de période (`periodbalance`) et un solde de clôture (`endbalance`).

Utilisez-la pour une balance générale ou un compte de résultat fondé sur les soldes. Le contrôle **Statistique** (ci-dessous) donne aussi accès aux comptes statistiques non monétaires d'Intacct (effectifs, surface, unités) : une seule étape peut donc récupérer les soldes financiers, les soldes statistiques ou les deux, ce qui vous permet de construire des métriques par unité sans exportation distincte. Pour le détail des transactions du grand livre, utilisez [Import Sage Intacct Query](/fr/reference/workflow-steps/sage-intacct/import-intacct-query/) (étape) sur `GLDETAIL` ; pour une requête ponctuelle sur n'importe quel objet Intacct, utilisez cette même étape avec le nom de votre objet.

## Éléments de configuration propres à l'étape

### Source et cible

- **Connexion** : la connexion Sage à utiliser pour la lecture.
- **Société** : la société Sage à lire.

### Sélection des données

- **Date de début** / **Date de fin** : la période sur laquelle les soldes sont reportés (les deux sont obligatoires ; une date de début ou de fin seule est ignorée).
- **Compte de début** / **Compte de fin** : la plage de codes de compte à inclure. Utilisez `0000` et `9999` pour couvrir tous les comptes quel que soit leur numéro, ce qui est le choix habituel lorsque **Statistique** ci-dessous est réglé pour récupérer les comptes statistiques, car les comptes statistiques d'Intacct ne sont pas forcément compris dans la numérotation de votre plan comptable financier.
- **Statistique** : le type de soldes de comptes que renvoie l'extraction :
  - **Financier uniquement (hors statistique)** : ne renvoie que les soldes de comptes financiers (l'extraction normale d'une balance générale). C'est la valeur par défaut.
  - **Financier + statistique** : renvoie ensemble, dans le même résultat, les soldes de comptes financiers et statistiques.
  - **Statistique uniquement** : ne renvoie que les soldes de comptes statistiques : effectifs, surface, unités et tout autre compte non monétaire que votre plan comptable Intacct suit en parallèle du plan financier.
- **Entités** : les entités Sage à inclure.
- **Dimensions** : activez les dimensions que vous souhaitez obtenir sous forme de colonnes : classe, contact, type de coût, client, département, employé, article, site, groupe de projets, tâche et fournisseur.
- **Dimensions personnalisées** : toutes les dimensions supplémentaires définies par l'utilisateur à reporter.

:::caution[La case Entrepôt de données n'a aucun effet]
La configuration de l'étape propose une dimension **Entrepôt de données**, mais l'exécuteur
de workflow ne la lit pas : la dimension est absente de l'ensemble qu'il construit, donc l'activer
n'ajoute aucune colonne. Utilisez **Dimensions personnalisées** si vous avez besoin de l'entrepôt de données
dans la sortie.
:::
