## Description



Importe des fichiers de données SPSS (formats .sav et .zsav) dans des tables de projet PlaidCloud. Utile pour les données d'enquête, les données de recherche en sciences sociales, ou tout pipeline qui interagit avec des outils basés sur SPSS.

Les libellés de variables et de valeurs sont conservés lorsque le format les prend en charge.
