## Description


Importe une ou plusieurs tables d'une base de données externe (configurée via un connecteur de base de données) dans des tables de projet. Prend en charge les **chargements delta** (récupération des seules lignes modifiées depuis la dernière importation) et le **remappage des noms de table** (enregistrement de la table source sous un autre nom dans PlaidCloud).

Utilisez cette étape pour garder les tables PlaidCloud synchronisées avec les systèmes sources opérationnels selon une planification, sans réimporter toutes les lignes à chaque fois.

<Aside title="Inspecter la source lit la base de données externe">
Pour une table ajoutée à cette étape, le bouton **Inspecter la source** lit les colonnes actuelles de cette table directement dans la base de données connectée et actualise sur place le mappage de cette seule table. Utilisez-le lorsque les colonnes d'une table source ont changé depuis la configuration de l'étape, sans relancer la détection sur toute la connexion.
</Aside>

<Aside title="Types de colonnes PostgreSQL">
Sur une source PostgreSQL, les colonnes `uuid` sont importées en texte, et les colonnes `json`/`jsonb` sont importées sous leur représentation textuelle JSON.
</Aside>

<Aside title="Les colonnes numériques sont importées en décimaux exacts">
Une colonne source `numeric`/`decimal` est importée sous forme de valeur décimale exacte, pouvant contenir jusqu'à 28 chiffres à gauche de la virgule et 10 à droite. Une valeur comptant plus de 10 décimales est arrondie pour tenir ; une valeur comptant plus de 28 chiffres entiers arrête l'importation en nommant la colonne.
</Aside>

<Aside type="caution" title="Une valeur qui ne tient pas dans sa colonne arrête l'importation">
Si une valeur source ne peut pas tenir dans sa colonne cible sans perte de données (une fraction arrivant dans une colonne entière, un nombre trop grand pour sa colonne, ou `NaN`/`Infinity` arrivant dans une colonne numérique), l'importation s'arrête avec une erreur nommant la colonne et son type de données, au lieu de tronquer ou d'arrondir silencieusement. Dans le Data Mapper de l'étape, définissez le **Type** de cette colonne sur un type pouvant contenir la valeur, puis relancez l'importation.
</Aside>
