## Description

Importe les éléments d'un ou de plusieurs tableaux [monday.com](https://monday.com/) dans des tables de projet via une connexion monday.com. Utilisez-la pour intégrer dans un workflow, à côté des données financières, des données de suivi de projet, de files de demandes ou de tâches opérationnelles.

## Éléments de configuration propres à l'étape

### Configuration de la connexion

La connexion monday.com à utiliser pour la lecture.

### Table cible

Une ligne par tableau : l'**ID du tableau** à lire et la table de projet dans laquelle il est écrit. Une même étape peut importer plusieurs tableaux à la fois. Chaque cible doit être une table, pas une vue.
