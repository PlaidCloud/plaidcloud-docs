## Description


Importe un fichier d'archive natif PlaidCloud dans une table de projet. Le format d'archive conserve les types de colonnes, les métadonnées et les index, qui ne survivent pas à un aller-retour par CSV.

Créée par [Export to Table Archive](/fr/reference/workflow-steps/export/export-to-table-archive/). Utilisée pour les sauvegardes de projet, les migrations entre espaces de travail ou environnements, et le transfert fiable de données typées.
