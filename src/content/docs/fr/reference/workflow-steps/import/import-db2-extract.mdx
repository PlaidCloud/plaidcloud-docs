## Description

Importe un fichier d'extraction IBM DB2 depuis le stockage PlaidCloud Document. C'est utile lorsque le serveur DB2 n'est accessible que depuis une infrastructure locale : un processus externe dépose l'extraction dans le stockage PlaidCloud Document, et cette étape la lit à partir de là dans une table de projet.

Pour un accès DB2 en direct (sans fichier d'extraction), connectez-vous via la connexion standard [IBM DB2](../../../connectors/databases/ibm-db2/) et utilisez [Importer les tables de base de données externe](../import-external-database-tables/).
