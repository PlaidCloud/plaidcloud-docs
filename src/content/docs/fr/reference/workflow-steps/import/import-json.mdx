## Description

Importe des fichiers texte JSON depuis PlaidCloud Document.

Pour plus de détails sur les fichiers JSON, consultez le site officiel de JSON : http://json.org/.

Les fichiers JSON ne conservent *pas* l'ordre des colonnes. L'ordre des colonnes du fichier source ne reflète pas nécessairement celui de la table de données importée.

Les importations JSON transitent par un stockage temporaire au lieu de charger tout le document en mémoire, de sorte que les très gros fichiers s'importent sans manquer de mémoire. Les colonnes qui n'apparaissent que tardivement dans un gros document sont incluses dans la table importée. Les objets et tableaux imbriqués sont importés sous forme de texte JSON compact standard, de sorte que les étapes en aval peuvent les analyser avec n'importe quel outil JSON.

## Éléments de configuration propres à l'étape

### Orientation des données JSON

Considérez le jeu de données suivant :

| ID | Name | Gender | State |
| 1 | Jack | M | MO |
| 2 | Jill | F | MO |
| 3 | George | M | VA |
| 4 | Abe | M | KY |

Les fichiers JSON peuvent être importés dans l'un des trois formats de données suivants :

* Records : les données sont stockées dans des dictionnaires Python, chaque ligne étant stockée au format \{Column -> Value, …}. Par exemple :


```json
[{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" }]
```

* Index : les données sont stockées dans des dictionnaires Python imbriqués, chaque ligne étant stockée au format \{Index -> \{Column -> Value, …},…}. Par exemple :


```json
{ "0": { "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, "1": { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, "2": { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, "3": { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" } }
```

* Split : les données sont stockées dans un seul dictionnaire Python, avec les valeurs stockées dans des listes. Par exemple :


```json
{ "columns": ["ID", "Name", "Gender", "State"], "index": [0, 1, 2, 3], "data": [ [1, "Jack", "M", "MO"], [2, "Jill", "F", "MO"], [3, "George", "M", "VA"], [4, "Abe", "M", "KY"] ] }
```

Outre les formats ci-dessus, le JSON délimité par des sauts de ligne (NDJSON) est accepté : un objet JSON autonome par ligne, sans tableau englobant. Par exemple :

```json
{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }
{ "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }
```


### Document entier

Pour conserver intact le JSON de chaque fichier, sélectionnez **Importer chaque fichier comme une ligne contenant tout son document JSON** (`whole_document`) dans **Autres options JSON**. Chaque fichier est alors importé comme une ligne contenant tout son document JSON, avec les nombres conservés tels qu'écrits.
