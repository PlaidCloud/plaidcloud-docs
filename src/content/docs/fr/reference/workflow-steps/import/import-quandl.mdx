## Description

Importe des jeux de données depuis le référentiel de millions de jeux de données de Quandl.

Pour plus de détails sur les jeux de données Quandl, consultez le site officiel de Quandl : http://www.quandl.com/.

## Éléments de configuration propres à l'étape

### Spécification des données source

L'accès aux jeux de données Quandl nécessite un compte utilisateur ou un compte invité à accès limité, à configurer dans Tools. Pour plus de détails sur la configuration d'une connexion de compte Quandl, consultez : [PlaidCloud Tools – Connexion](/fr/reference/connectors/).

Une fois tous les comptes nécessaires configurés, sélectionnez le compte approprié dans la liste déroulante.

Saisissez ensuite les critères du code Quandl voulu. Vous pouvez utiliser la fonction **Rechercher** pour trouver des jeux de données. Vous pouvez aussi saisir les jeux de données manuellement, en indiquant la partie de l'URL qui suit « [http://www.quandl.com](http://www.quandl.com/) ». 

Par exemple, pour importer le jeu de données de l'action Microsoft, disponible ici (http://www.quandl.com/GOOG/NASDAQ_MSFT), saisissez *GOOG/NASDAQ_MSFT* dans le champ Quandl Code.


### Sélection des données


Il est possible de découper les jeux de données Quandl lors de l'importation. Les options disponibles sont les suivantes :


* Date de début : utilisez le sélecteur de date pour choisir la date voulue.
* Date de fin : utilisez le sélecteur de date pour choisir la date voulue.
* Collapse : agrège les résultats par jour, semaine, mois, trimestre ou année. Il n'y a aucune agrégation par défaut.
* Transformation : calculs de synthèse.
* Limit Rows : la valeur par défaut 0 renvoie toutes les lignes. Toute autre valeur entière positive indique le nombre maximal de lignes à renvoyer depuis le jeu de données.
