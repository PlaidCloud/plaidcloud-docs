## Description

Importe des fichiers Apache ORC depuis PlaidCloud Document. ORC est un format de stockage en colonnes écrit par Hive et Spark, dont le schéma est porté par le fichier.

Le formulaire de l'étape comporte trois onglets :

- **Paramètres d'importation** : le **Fichier source** (un compte de documents et le chemin du fichier ou du dossier) et la **Table cible**, avec **Supprimer les caractères non ASCII** (`ascii_only`), **Supprimer le ou les fichiers après l'importation** (`delete_file`) et **Ignorer la réimportation si les fichiers sources sont inchangés** (`skip_if_unchanged`).
- **Sélection des données de la table** : mappe les colonnes sources sur les colonnes cibles, avec **Résumer** et **Distinct**. **Renseigner** lit les colonnes et leurs types depuis le schéma porté par le fichier ORC.
- **Filtres de données** : filtre les lignes avant et après le résumé.

Lorsque le fichier est absent ou vide, **Renseigner** répond *Rien à remplir* avec un avertissement qui nomme le chemin, et conserve le mappage existant.

Les [projets Prophecy migrés](/fr/guides/workflows/migrate-prophecy-projects/) utilisent cette étape pour les jeux de données ORC.
