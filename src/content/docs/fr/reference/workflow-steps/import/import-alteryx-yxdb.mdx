## Description

Importe des fichiers Alteryx YXDB depuis PlaidCloud Document. YXDB est le format de fichier binaire natif d'Alteryx Designer, qui stocke les jeux de données avec les métadonnées de leurs champs.

Les importations YXDB transitent par un stockage temporaire au lieu de charger tout le fichier en mémoire, de sorte que les très gros fichiers s'importent sans manquer de mémoire. Les types de données du fichier (décimaux, dates et horodatages) sont conservés dans la table cible.

Si le fichier `.yxdb` configuré n'existe pas mais qu'un fichier `.parquet` du même nom se trouve dans le même dossier, l'étape lit le fichier `.parquet` à la place et affiche un avertissement en ce sens. Les workflows Alteryx convertis écrivent leurs sorties `.yxdb` sous forme de fichiers `.parquet` de même nom, de sorte qu'une étape qui lit l'un de ces fichiers `.yxdb` récupère automatiquement les données. Les importations qui recherchent des fichiers n'utilisent pas ce repli.
