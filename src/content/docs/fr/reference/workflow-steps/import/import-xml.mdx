## Description


Importe des données tabulaires d'un fichier XML dans une table de projet PlaidCloud. Configurez le chemin d'élément qui identifie chaque « ligne » et mappez les éléments enfants ou les attributs sur les colonnes de la table.

Courant avec les anciennes intégrations d'entreprise, l'échange de données B2B (RosettaNet, ebXML) et les formats de déclarations administratives.


## Lire les enregistrements comme

**Lire les enregistrements comme** détermine comment le fichier devient des tables :

* **Une table par balise d'enregistrement** (par défaut) : l'onglet **Balises d'enregistrement** liste chaque balise à lire, et chaque balise est chargée dans sa propre table, nommée à partir du **Préfixe des tables cibles**.
* **Une ligne par élément** : un élément répété est chargé dans une seule table, avec une ligne pour chaque occurrence. L'onglet **Balises d'enregistrement** et le **Préfixe des tables cibles** sont désactivés.

Avec **Une ligne par élément**, définissez :

* **Élément XML** : l'élément qui constitue une ligne. Laissé vide, il s'agit de l'élément de la première colonne, affiché dans le champ.
* **Table cible** : la table à charger.
* **Colonnes** : chaque **Élément enfant ou attribut** et la **Colonne** dans laquelle il est chargé. Toutes les colonnes sont importées en texte.
* **Supprimer les espaces autour des valeurs** : supprime les espaces au début et à la fin de chaque valeur.
* **Faire correspondre les noms avec leur préfixe d'espace de noms** : fait correspondre les noms d'éléments et d'attributs tels qu'ils sont écrits dans le fichier, préfixe compris.

Le Fichier source, la Table cible, ainsi qu'un Élément XML ou au moins une colonne sont obligatoires. Changer de mode conserve dans le formulaire les paramètres de l'autre mode, de sorte que revenir en arrière les restaure, mais l'enregistrement supprime les paramètres du mode que vous avez quitté ; une remarque à côté du contrôle l'indique.

Les étapes enregistrées depuis le formulaire lisent leurs balises d'enregistrement telles que définies dans l'onglet **Balises d'enregistrement**.
