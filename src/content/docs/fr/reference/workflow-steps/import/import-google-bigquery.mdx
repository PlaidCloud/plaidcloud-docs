## Description


Importe des données de Google BigQuery dans une table de projet PlaidCloud. Utile pour les organisations qui utilisent BigQuery comme entrepôt d'analyse principal et récupèrent des jeux de données précis dans PlaidCloud pour des travaux de modélisation ou d'allocation.

L'authentification utilise un compte de service Google Cloud ; le jeu de données et la table source sont configurés au niveau de l'étape.
