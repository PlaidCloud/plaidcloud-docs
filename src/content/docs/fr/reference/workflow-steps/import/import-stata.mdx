## Description


Importe des fichiers de données Stata (.dta) dans des tables de projet PlaidCloud. Utile pour les organisations qui utilisent Stata pour l'analyse économétrique ou statistique et qui amènent leurs jeux de données de travail dans PlaidCloud pour un traitement ultérieur.

Les libellés de variables sont conservés lorsque le format Stata les inclut.
