## Description


Copie les données d'une table d'un autre projet dans le projet courant. L'inverse de [Export Project Table](/fr/reference/workflow-steps/export/export-project-table/) : elle récupère au lieu de pousser.

Utile lorsqu'un projet de consolidation s'alimente à partir de nombreux projets opérationnels, ou lorsque des données de référence sont centralisées dans un projet et lues par d'autres. Le projet source doit accorder à ce projet un partage de données en **Lecture**.


## Gestion du partage de données

![Gestion du partage de données](/images/import_external_project_table_1.png)

Avant de pouvoir importer une table d'un autre projet, ce projet doit autoriser celui-ci à la lire. Ouvrez l'onglet **Accueil** du projet **source**, puis, sous **Gestion du partage de données**, cliquez sur **Nouveau partage de données**, sélectionnez ce projet, cochez **Lecture** sous **Opérations autorisées**, et cliquez sur **Ajouter un partage de données**. Consultez [Partager des données entre projets](/fr/guides/projects/managing-projects/#partage-de-données-entre-projets).

L'étape s'exécute avec l'identité propre de ce projet, de sorte qu'une exécution fonctionne via le partage quel que soit l'utilisateur qui la lance.

## Importer la table de projet externe

![Importer la source et la cible](/images/import_external_project_table_2.png)

### Lire depuis
Sélectionnez le **Projet source** et la **Table source** dans les listes déroulantes.

<Aside type="note" title="Table source vide">
Si la table source ne contient aucune ligne à l'exécution de l'étape, l'importation se termine avec un avertissement indiquant que la source était vide, au lieu d'un succès silencieux, ce qui permet de repérer facilement une cible vide de façon inattendue. Le plus souvent, cela signifie que le workflow du projet source n'avait pas encore construit cette table ; assurez-vous que la source est alimentée (et, pour les exécutions planifiées, qu'elle s'exécute en premier) avant l'importation.
</Aside>

<Aside type="note" title="Suppression d'une table source">
La table source que vous lisez est considérée comme utilisée par cette étape. Si vous essayez de la supprimer, PlaidCloud affiche la référence et vous demande de confirmer une suppression forcée (en cochant **Forcer la suppression de la table ?** et en choisissant **Forcer la suppression**) plutôt qu'une simple suppression, même lorsque l'étape d'importation se trouve dans un autre projet qui partage les données. Dans ce cas inter-projets, l'avertissement liste la référence sans nommer l'étape de l'autre projet, car vous pouvez ne pas y avoir accès.
</Aside>
