## Description



Importe des fichiers texte dont les colonnes sont définies par des positions de caractères plutôt que par des délimiteurs, le format de sortie classique des mainframes et de COBOL. Configurez les limites de colonnes (position de début, longueur) pour chaque champ.

Courant avec les exports d'ERP hérités, les déclarations administratives et les formats de relevés bancaires, où les données ont été disposées pour un affichage en colonnes fixes plutôt que pour une analyse par délimiteurs.

Les importations à largeur fixe transitent par un stockage temporaire au lieu de charger tout le fichier en mémoire, de sorte que les très gros fichiers s'importent sans manquer de mémoire.

### En-tête

Comme les fichiers Excel peuvent contenir ou non des en-têtes, PlaidCloud permet soit d'utiliser les en-têtes, soit de les ignorer, soit de se fonder sur l'ordre des colonnes pour déterminer leur alignement.
* **Sans en-tête** : le fichier ne contient aucun en-tête. Utilisez la liste source du *Data Mapper* pour déterminer l'alignement des colonnes.
* **Avec en-tête : utiliser l'en-tête et remplacer la liste des champs** : le fichier a un en-tête. Utilisez les noms d'en-tête indiqués et ignorez la liste source du *Data Mapper*.
* **Avec en-tête : ignorer l'en-tête et utiliser la liste des champs** : le fichier a un en-tête, mais il doit être ignoré. Utilisez les noms d'en-tête indiqués par la liste source du *Data Mapper*.

### Sélection des lignes

Pour les fichiers d'entrée contenant des enregistrements superflus, vous pouvez indiquer un nombre de lignes à ignorer avant de traiter les données. C'est utile si les fichiers contiennent des blocs d'en-tête qu'il faut sauter avant d'arriver aux données tabulaires.

### Largeurs de colonne

Saisissez les largeurs des colonnes séparées par des virgules ou des espaces.

### Disposition

| Paramètre | Fonction |
| --- | --- |
| Encodage | Le jeu de caractères du fichier : **UTF-8** (par défaut), **EBCDIC (États-Unis, cp037)**, **EBCDIC (international, cp500)** ou **Latin-1**. Choisissez une page de codes EBCDIC pour un fichier de mainframe. |
| Enregistrements à ignorer | Le nombre d'enregistrements à ignorer au début du fichier, avant l'en-tête ou les données. |
| Enregistrements à ignorer à la fin | Le nombre d'enregistrements à supprimer à la fin du fichier, par exemple un enregistrement de fin. |
| Un enregistrement par ligne | Activé (par défaut), chaque ligne est un enregistrement. Désactivez-le pour un fichier dont les enregistrements sont placés bout à bout sans saut de ligne ; chaque enregistrement a alors la longueur totale des largeurs de colonne. |
| Caractères entre les enregistrements | Lorsque les enregistrements ne sont pas un par ligne, le nombre de caractères à ignorer après chaque enregistrement, par exemple un séparateur. |
| Supprimer les espaces | Les espaces supprimés de chaque valeur : **Au début et à la fin** (par défaut), **À la fin uniquement** ou **Aucun**. |
