## Description

Restaure des tables de projet à partir d'une archive créée par [Archiver les tables](/fr/reference/workflow-steps/export/archive-tables/). Utilisez-la pour déplacer des données de tables entre projets ou espaces de travail, ou pour revenir à une copie mise de côté.

## Éléments de configuration propres à l'étape

### Source

Le fichier d'archive situé dans un compte de documents. Le sélecteur permet aussi une correspondance par recherche (exacte, commence par, se termine par, contient ou glob) plutôt qu'un chemin exact.

### Écraser

Désactivé par défaut. Lorsqu'il est désactivé, une table qui existe déjà dans le projet est laissée telle quelle. Activez-le pour remplacer les tables existantes par les copies archivées.
