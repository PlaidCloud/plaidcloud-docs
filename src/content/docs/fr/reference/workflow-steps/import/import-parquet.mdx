## Description

Importe des fichiers Apache Parquet depuis PlaidCloud Document. Parquet est un format de stockage en colonnes très répandu dans l'écosystème Hadoop et les plateformes de données cloud, qui offre une compression et un encodage efficaces pour les grands jeux de données.

Les importations Parquet transitent par un stockage temporaire au lieu de charger tout le fichier en mémoire, de sorte que les très gros fichiers s'importent sans manquer de mémoire. Les types de données du fichier (décimaux, dates et horodatages) sont conservés dans la table cible, et les colonnes d'horodatage conservent leur précision complète de date et d'heure.
