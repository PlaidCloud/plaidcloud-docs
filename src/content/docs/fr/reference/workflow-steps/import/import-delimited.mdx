## Description

L'étape **Importation : délimité (par position)** lit toutes les colonnes d'un document délimité par position, sous forme de colonnes de texte nommées `Column_1` à `Column_N`, et ignore la ligne d'en-tête. Utilisez-la lorsque l'en-tête ne peut pas nommer les colonnes, par exemple lorsqu'une étape ultérieure promeut une ligne de données en en-tête.

## Paramètres

- **Document** : le compte de documents et le chemin du fichier. Un chemin se terminant par `.gz` est décompressé.
- **Délimiteur** : le délimiteur de champs. La valeur par défaut est une virgule.
- **Caractère de citation** : la valeur par défaut est un guillemet double.
- **Colonne du numéro d'enregistrement** *(facultatif)* : une colonne qui numérote les enregistrements dans l'ordre du fichier. Laissez vide pour n'en écrire aucune.
- **Table de sortie** : l'emplacement où les lignes sont écrites.

Un document manquant n'est pas une erreur. L'étape se termine avec un avertissement qui nomme le chemin et écrit une table vide.
