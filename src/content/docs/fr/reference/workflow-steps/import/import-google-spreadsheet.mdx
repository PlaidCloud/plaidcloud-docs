## Description


Importe des feuilles de calcul précises d'une feuille de calcul Google Sheets dans des tables de projet PlaidCloud. Utile pour les données ponctuelles qui vivent dans des feuilles de calcul : tables d'inducteurs maintenues par les utilisateurs métier, mappages de correspondance, ajustements manuels.

L'authentification passe par une connexion Google ; plusieurs feuilles de calcul d'une même feuille de calcul peuvent être importées en une seule étape.

## Paramètres d'importation


![Importer depuis Google Sheets](/images/import_file_google_target.png)
### Source et cible
#### Compte Google

L'accès aux données Google Sheets nécessite un compte utilisateur Google valide, à configurer dans Tools. Pour plus de détails sur la configuration d'une connexion de compte Google, consultez : [PlaidCloud Tools – Connexion](/fr/reference/connectors/).

Une fois tous les comptes nécessaires configurés, sélectionnez le **Compte Google** approprié dans la liste déroulante.
#### Feuille de calcul

Ensuite, indiquez la **Feuille de calcul** à importer dans le menu déroulant qui contient tous les fichiers disponibles associés au **Compte Google** indiqué.

<Aside>Vérifiez que le compte utilisateur fourni a accès au fichier indiqué, surtout si le fichier appartient à un autre utilisateur.</Aside>

### Type d'en-tête

Comme les feuilles de calcul Google peuvent contenir ou non des en-têtes, PlaidCloud permet soit d'utiliser les en-têtes, soit de les ignorer, soit de se fonder sur l'ordre des colonnes pour déterminer leur alignement.
* **Sans en-tête** : le fichier ne contient aucun en-tête. Utilisez la liste source du *Data Mapper* pour déterminer l'alignement des colonnes.
* **Avec en-tête : utiliser l'en-tête et remplacer la liste des champs** : le fichier a un en-tête. Utilisez les noms d'en-tête indiqués et ignorez la liste source du *Data Mapper*.
* **Avec en-tête : ignorer l'en-tête et utiliser la liste des champs** : le fichier a un en-tête, mais il doit être ignoré. Utilisez les noms d'en-tête indiqués par la liste source du *Data Mapper*.

### Feuilles de calcul à importer

Comme les classeurs peuvent contenir de nombreuses feuilles de calcul avec des données différentes, il est possible de sélectionner les feuilles à importer dans le traitement d'importation en cours. Les options sont :

* Toutes les feuilles de calcul
* Feuilles de calcul correspondant à la recherche
* Feuilles de calcul sélectionnées

#### Utiliser la recherche de feuilles de calcul

La recherche de feuilles de calcul permet d'inclure les feuilles qui correspondent aux critères de recherche. Les critères disponibles sont :
* **Commence par** : le nom de la feuille de calcul commence par le texte recherché
* **Contient** : le nom de la feuille de calcul contient le texte recherché
* **Se termine par** : le nom de la feuille de calcul se termine par le texte recherché

#### Rechercher les feuilles dans le fichier sélectionné

Le bouton de recherche des feuilles ouvre le fichier Excel et liste les feuilles de calcul disponibles dans la table. Cochez les cases de la table pour les feuilles de calcul à inclure dans l'importation.

<Aside>Lors du renseignement du *Data Mapper*, la première feuille de calcul trouvée dans la liste est utilisée. Assurez-vous que toutes les feuilles de calcul incluses dans l'étape d'importation ont un format similaire.</Aside>
### En-têtes de colonne

<Aside>En raison de limitations techniques, toutes les colonnes de Google Sheets sont importées avec le type de données String. Les types de données Boolean, Numerical et/ou Date/Time doivent être indiqués explicitement dans le mappeur.</Aside>
