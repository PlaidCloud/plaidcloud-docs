## Description

Importe des fichiers Apache Avro depuis PlaidCloud Document. Avro est un format de sérialisation de données orienté lignes issu du projet Apache Hadoop, qui stocke les données avec leur schéma, ce qui le rend bien adapté aux pipelines de données et aux systèmes de streaming.

## Éléments de configuration propres à l'étape

### Date de modification du fichier

Lisez uniquement les fichiers modifiés dans une fenêtre de temps. **Modifié après** lit uniquement les fichiers modifiés pour la dernière fois après l'heure saisie, et **Modifié avant** uniquement ceux modifiés avant celle-ci ; définissez l'un ou l'autre, ou les deux. Saisissez une heure au format `YYYY-MM-DDTHH:MM:SS`, par exemple `2026-10-01T00:00:00`. Une heure est en UTC, sauf si elle précise un fuseau, par exemple `2026-10-01T00:00:00-05:00`. Une heure peut contenir une variable de workflow, lue à l'exécution de l'étape.
