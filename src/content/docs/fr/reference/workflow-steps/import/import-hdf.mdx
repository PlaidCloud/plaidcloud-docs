## Description


Importe des fichiers HDF5 (Hierarchical Data Format version 5) dans des tables de projet PlaidCloud. HDF5 est courant en calcul scientifique, pour l'échange de données de machine learning, et dans tout contexte où des données typées en colonnes doivent faire l'aller-retour entre des outils Python, R ou MATLAB.

Consultez la [documentation du HDF Group](http://www.hdfgroup.org/HDF5/) pour la spécification du format.

## Éléments de configuration propres à l'étape


### Nom de la clé

Les fichiers HDF stockent les données dans une structure de chemins. Une clé (chemin) est nécessaire comme destination de la table dans le fichier HDF. Dans la plupart des cas, il s'agira de *table*.
