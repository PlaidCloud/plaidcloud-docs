## Description

L'étape **Import dBASE** importe un fichier dBASE (`.dbf`), qui porte son propre schéma. Elle s'exécute dans le moteur de workflow ; les résultats des macros empaquetées sont une approximation de la macro Alteryx.

Les importations dBASE transitent par un stockage temporaire au lieu de charger tout le fichier en mémoire, de sorte que les très gros fichiers s'importent sans manquer de mémoire. Les types de données du fichier (décimaux, dates et horodatages) sont conservés dans la table cible.

## Paramètres

- **Source** : le fichier `.dbf`.
- **Table cible** : la table de sortie.
- **Ignorer la réimportation si les fichiers sources sont inchangés** : une exécution de workflow ignore l'importation si le fichier source et les paramètres de l'étape sont inchangés depuis la dernière exécution réussie. Activé par défaut ; décochez pour toujours réimporter.
