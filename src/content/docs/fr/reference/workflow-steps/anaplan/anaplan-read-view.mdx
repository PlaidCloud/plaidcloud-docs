## Description

Lit les données d'une vue **Anaplan** enregistrée via votre [connexion Anaplan](/fr/guides/connections/anaplan/), par le chemin de requête de lecture à gros volume d'Anaplan. La vue est lue **exactement telle qu'elle a été enregistrée** : cette étape ne permet aucune sélection ad hoc de lignes, de colonnes ni de pages. Pour lire une autre portion, enregistrez une autre vue dans Anaplan.

Cette étape apparaît dans le menu des étapes sous **Anaplan**.

L'étape atteint Anaplan en **direct depuis le cloud** via son API d'intégration ; il n'existe aucun chemin passant par un agent sur site.

<Aside type="tip">
Ce connecteur est en lecture seule et s'authentifie avec des identifiants Basic (nom d'utilisateur et mot de passe) ou un certificat d'AC ; consultez [Authentification](/fr/guides/connections/anaplan/#authentification). Le budget de requêtes d'Anaplan est partagé à l'échelle du locataire ; échelonnez donc la planification de cette étape par rapport à vos autres workflows Anaplan ; consultez [Points à considérer pour la planification](/fr/guides/connections/anaplan/#considérations-sur-la-planification).
</Aside>

## Configuration

### Source et cible

| Champ | Obligatoire | Remarques |
|---|---|---|
| Connexion Anaplan | Oui | La [connexion Anaplan](/fr/guides/connections/anaplan/) à utiliser pour la lecture. |
| Environnement | Oui | L'environnement de la connexion. |
| Espace de travail | Non | Remplace l'ID d'espace de travail enregistré sur la connexion. Détecté en direct depuis la connexion, ou saisi à la main. |
| Modèle | Non | Remplace l'ID de modèle enregistré sur la connexion. Détecté en direct une fois un espace de travail choisi, ou saisi à la main. |
| Vue | Oui | La vue Anaplan enregistrée à lire. Détectée en direct une fois un modèle choisi, ou saisie à la main. |
| Nombre de tentatives d'interrogation | Oui | 120 par défaut. Nombre de fois où interroger la requête de lecture pour savoir si elle est terminée avant que l'étape ne refuse, en nommant l'ID de la requête. Elle ne soumet jamais silencieusement une seconde requête. |
| Intervalle d'interrogation (secondes) | Oui | 5 par défaut. Secondes d'attente entre deux interrogations. |
| Table cible | Oui | La table dans laquelle est chargée la vue renvoyée. |

## Aperçu

**Aperçu** dans l'onglet **Source** affiche les colonnes et les types de données que produirait cette lecture de vue, sans exécuter l'étape. Il n'est pas disponible sur un projet verrouillé.

## Ce que cette étape ne peut pas représenter

| Limite | Signification |
|---|---|
| Aucun contrôle de la portion lue | La vue est lue exactement telle qu'enregistrée, sans sélection de lignes, de colonnes ni de pages. Le sélecteur de pages d'Anaplan n'est documenté que sur son point de terminaison d'aperçu synchrone ; le corps de la requête de lecture à gros volume que cette étape envoie ne prend qu'un type d'export et rien d'autre. Construisez une autre vue enregistrée, généralement un élément de ligne booléen plus un filtre, pour lire une autre portion. |
| Les types déclarés ne sont chargés que lorsque les éléments de ligne sont sur les colonnes | Lorsque les éléments de ligne se trouvent sur l'axe des colonnes de la vue, chaque colonne de données est chargée avec le type issu du format Anaplan déclaré de son élément de ligne (nombre, texte, booléen, date, période ou liste). Lorsque les éléments de ligne sont sur les lignes (une disposition ordinaire de compte de résultat) ou absents de la vue, chaque colonne de données est chargée sous forme de texte, avec un avertissement nommé : une colonne de données couvrirait sinon de nombreux éléments de ligne, donc de nombreux formats, alors qu'une colonne de table ne contient qu'un seul type. |
| Les valeurs du sélecteur de pages ne sont pas chargées en colonnes | Les membres du sélecteur de pages enregistrés d'une vue voyagent dans l'en-tête du CSV et y sont consommés ; ils n'apparaissent pas comme colonnes dans la table cible. |
| Les nombres ambigus sont refusés plutôt que devinés | Une valeur déclarée numérique qui comporte des séparateurs de milliers, ou qui se lit aussi bien comme un décimal simple que dans une présentation à l'européenne (par exemple `1.234`), est refusée nommément plutôt qu'analysée, sauf si une autre valeur de la même colonne détermine quelle lecture est la bonne. Ce chemin de lecture n'a aucun champ de paramètres régionaux permettant de lever l'ambiguïté. Une valeur qui s'analyse correctement est chargée en pleine précision, sans erreur d'arrondi, et une cellule vide est toujours chargée comme valeur vide. |
| Une vue vide est chargée vide, avec un avertissement | Une vue enregistrée dont le filtre ne correspond à rien remplace la table cible par une table vide et avertit : c'est un résultat ordinaire, pas un échec. L'exception est une vue sans dimension sur l'axe des lignes : il n'y a pas de coin d'étiquette de ligne par rapport auquel vérifier un résultat vide, donc l'étape refuse plutôt que de risquer de vider la table à cause d'un en-tête mal lu. |
| Lecture seule | Rien n'est jamais réécrit dans Anaplan. |
