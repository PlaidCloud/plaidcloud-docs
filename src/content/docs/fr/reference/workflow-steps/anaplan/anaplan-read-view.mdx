## Description

Lit les données d'une vue **Anaplan** enregistrée via votre [connexion Anaplan](/fr/guides/connections/anaplan/), en passant par le chemin de requête de lecture grand volume d'Anaplan. La vue est lue **exactement telle qu'elle a été enregistrée** : cette étape ne permet aucune sélection ad hoc de lignes, de colonnes ni de page. Pour lire une autre tranche, enregistrez une autre vue dans Anaplan.

Cette étape apparaît dans le menu des étapes sous **Anaplan**.

L'étape accède à Anaplan en **direct depuis le cloud** via son API d'intégration : il n'existe pas de chemin passant par un agent sur site.

<Aside type="tip">
Ce connecteur est en lecture seule et s'authentifie avec des identifiants de base (nom d'utilisateur et mot de passe) ou un certificat d'AC ; consultez [Authentification](/fr/guides/connections/anaplan/#authentification). Le quota de requêtes d'Anaplan est partagé à l'échelle du tenant : échelonnez donc la planification de cette étape par rapport à vos autres workflows Anaplan ; consultez [Considérations sur la planification](/fr/guides/connections/anaplan/#considérations-de-planification).
</Aside>

## Configuration

### Source et cible

| Champ | Obligatoire | Remarques |
|---|---|---|
| Connexion Anaplan | Oui | La [connexion Anaplan](/fr/guides/connections/anaplan/) à utiliser pour la lecture. |
| Environnement | Oui | L'environnement de la connexion. |
| Espace de travail | Non | Remplace l'ID d'espace de travail enregistré dans la connexion. Découvert en direct à partir de la connexion, ou saisi à la main. |
| Modèle | Non | Remplace l'ID de modèle enregistré dans la connexion. Découvert en direct une fois un espace de travail choisi, ou saisi à la main. |
| Vue | Oui | La vue Anaplan enregistrée à lire. Découverte en direct une fois un modèle choisi, ou saisie à la main. |
| Nombre de tentatives d'interrogation | Oui | 120 par défaut. Nombre de fois où la requête de lecture est interrogée pour savoir si elle est terminée avant que l'étape ne refuse, en nommant l'ID de la requête. Elle ne soumet jamais silencieusement une seconde requête. |
| Intervalle d'interrogation (secondes) | Oui | 5 par défaut. Nombre de secondes d'attente entre deux interrogations. |
| Table cible | Oui | La table dans laquelle la vue renvoyée est déposée. |

## Ce que cette étape ne peut pas représenter

| Limitation | Signification |
|---|---|
| Aucun contrôle de la tranche | La vue est lue exactement telle qu'elle a été enregistrée, sans sélection de lignes, de colonnes ni de page. Le sélecteur de page d'Anaplan n'est documenté que pour son point de terminaison d'aperçu synchrone ; le corps de la requête de lecture grand volume que cette étape envoie ne prend qu'un type d'export, rien d'autre. Créez une autre vue enregistrée (souvent un élément de ligne booléen associé à un filtre) pour lire une autre tranche. |
| Les types déclarés ne sont appliqués que si Line Items est sur les colonnes | Lorsque Line Items se trouve sur l'axe des colonnes de la vue, chaque colonne de données est déposée avec le type issu du format Anaplan déclaré de son élément de ligne (Number, Text, Boolean, Date, Time Period ou List). Lorsque Line Items est sur les lignes (une disposition classique de compte de résultat) ou absent de la vue, toutes les colonnes de données sont déposées en texte, avec un avertissement nommé : une colonne de données couvrirait sinon de nombreux éléments de ligne, donc de nombreux formats, alors qu'une colonne de table ne contient qu'un seul type. |
| Les valeurs du sélecteur de page ne sont pas déposées comme colonnes | Les membres du sélecteur de page enregistrés dans une vue figurent dans l'en-tête du CSV et y sont consommés : ils n'apparaissent pas comme colonnes de la table cible. |
| Les nombres ambigus sont refusés au lieu d'être devinés | Une valeur déclarée Number qui contient des séparateurs de milliers, ou qui se lit aussi bien comme un nombre décimal simple que comme un nombre au format européen (par exemple `1.234`), est refusée nommément au lieu d'être analysée, sauf si une autre valeur de la même colonne tranche sur la lecture correcte. Ce chemin de lecture n'a pas de champ de paramètres régionaux permettant de lever l'ambiguïté. Une valeur analysée avec succès est déposée à pleine précision, sans erreur d'arrondi, et une cellule vide est toujours déposée comme valeur vide. |
| Une vue vide est déposée vide, avec un avertissement | Une vue enregistrée dont le filtre ne correspond à rien remplace la table cible par une table vide et émet un avertissement : c'est un résultat ordinaire, pas un échec. L'exception est une vue sans dimension sur l'axe des lignes : il n'y a pas de coin d'étiquette de ligne permettant de vérifier un résultat vide, donc l'étape refuse plutôt que de risquer de vider la table à cause d'un en-tête mal lu. |
| Lecture seule | Rien n'est jamais réécrit dans Anaplan. |
