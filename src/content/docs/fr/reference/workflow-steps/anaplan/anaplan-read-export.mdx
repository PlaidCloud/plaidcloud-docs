## Description

Exécute une action d'export Anaplan **existante** via votre [connexion Anaplan](/fr/guides/connections/anaplan/) et enregistre le fichier qu'elle produit sous forme de table. L'action d'export doit déjà exister dans le modèle (l'API ne peut pas en créer une) et cette étape ne peut pas restreindre ce qu'elle émet : ce que l'action est configurée pour exporter dans Anaplan est exactement ce qui est enregistré.

Cette étape apparaît dans le menu des étapes sous **Anaplan**.

L'étape accède à Anaplan en **cloud direct** via son API Bulk : il n'existe pas de chemin par agent sur site.

<Aside type="tip">
Ce connecteur est en lecture seule et s'authentifie avec des identifiants Basic (nom d'utilisateur et mot de passe) ou par certificat d'AC : consultez [Authentification](/fr/guides/connections/anaplan/#authentification). Le budget de requêtes d'Anaplan est partagé à l'échelle de l'environnement ; échelonnez donc la planification de cette étape par rapport à vos autres workflows Anaplan : consultez [Considérations sur la planification](/fr/guides/connections/anaplan/#considérations-de-planification).
</Aside>

## Configuration

### Source et cible

| Champ | Obligatoire | Remarques |
|---|---|---|
| Connexion Anaplan | Oui | La [connexion Anaplan](/fr/guides/connections/anaplan/) à utiliser pour la lecture. |
| Environnement | Oui | L'environnement de la connexion. |
| Espace de travail | Non | Remplace l'identifiant d'espace de travail enregistré dans la connexion. Découvert en direct à partir de la connexion, ou saisi manuellement. |
| Modèle | Non | Remplace l'identifiant de modèle enregistré dans la connexion. Découvert en direct une fois un espace de travail choisi, ou saisi manuellement. |
| Export | Oui | L'action d'export Anaplan à exécuter. Découverte en direct une fois l'espace de travail et le modèle choisis, ou saisie manuellement. Sa sélection ne peut pas être modifiée ici : elle s'exécute exactement comme configurée dans Anaplan. |
| Nombre de tentatives d'interrogation | Oui | 120 par défaut. Nombre de fois où la tâche d'export est interrogée pour savoir si elle est terminée avant que l'étape refuse, en nommant l'identifiant de la tâche. Elle ne soumet jamais à nouveau en silence : Anaplan ne documente pas comment distinguer deux fichiers produits par la même action d'export, et une nouvelle soumission risque donc d'associer le mauvais fichier à cette exécution. |
| Intervalle d'interrogation (secondes) | Oui | 5 par défaut. Nombre de secondes d'attente entre deux interrogations. |
| Table cible | Oui | La table dans laquelle l'export est enregistré. Chaque colonne est enregistrée en texte. |

## Ce que cette étape ne peut pas représenter

| Limite | Signification |
|---|---|
| Exige une action d'export existante | L'API ne peut pas créer d'action d'export, et la requête envoyée par cette étape ne comporte aucun paramètre de point de vue, de sélection de membres ou de tranche : ce que l'action est configurée pour émettre dans Anaplan est exactement ce qui est enregistré. Créez ou modifiez l'action d'export dans Anaplan pour changer ce qu'elle produit. |
| Chaque colonne est enregistrée en texte | Le champ qu'Anaplan publie pour déclarer les types de colonnes d'un export est incohérent dans la documentation publiée par Anaplan elle-même ; on ne peut donc pas lui faire confiance pour typer correctement une colonne, et aucune colonne n'est typée à partir de lui, de façon délibérée et définitive. Convertissez les colonnes dont vous avez besoin dans une étape en aval. |
| Nombres demandés au format américain ; une colonne encore groupée est signalée, non corrigée | La tâche d'export est soumise en demandant le format numérique américain. Une colonne qui revient encore avec des séparateurs de milliers signifie que l'export ne s'affiche pas sous ce format : l'étape enregistre la valeur telle quelle, en texte, et émet un avertissement nommant la colonne et une valeur d'exemple, plutôt que de deviner quel caractère est la virgule décimale. Vérifiez une telle colonne avant de la convertir en aval : un `1.234.567` de style européen lu comme `1.234` est mille fois trop petit. |
| Refuse plutôt que d'enregistrer une extraction peu fiable | L'étape n'enregistre rien, plutôt qu'une table qui paraît complète et ne l'est pas, lorsque : la tâche d'export échoue ou ne signale aucun succès dans Anaplan ; la tâche est annulée ; la tâche est toujours en cours une fois le budget d'interrogation de l'étape épuisé ; le fichier produit ne contient aucune donnée ; le fichier produit ne peut pas être relié à l'export qui l'a créé ; ou le nombre de lignes lues diffère du nombre de lignes qu'Anaplan indique lui-même pour l'export. |
| Lecture seule | Rien n'est jamais réécrit dans Anaplan. |
