Étapes de workflow qui lisent des données d'**Anaplan** via votre [connexion Anaplan](/fr/guides/connections/anaplan/) : une vue enregistrée via le chemin de requête de lecture grand volume, une action d'export existante via l'API Bulk, ou une ou plusieurs listes chargées dans une dimension PlaidCloud. Anaplan est joint **en direct depuis le cloud** via son API d'intégration ; ces étapes n'ont pas de chemin passant par un agent sur site, et aucune d'elles n'écrit jamais dans Anaplan.

## Étapes

- [Anaplan : lire une vue](/fr/reference/workflow-steps/anaplan/anaplan-read-view/) : lire une vue enregistrée telle qu'elle a été enregistrée. En direct depuis le cloud.
- [Anaplan : lire un export](/fr/reference/workflow-steps/anaplan/anaplan-read-export/) : exécuter une action d'export existante et déposer son fichier. En direct depuis le cloud.
- [Anaplan : lire une liste](/fr/reference/workflow-steps/anaplan/anaplan-read-list/) : lire une ou plusieurs listes dans une dimension PlaidCloud. En direct depuis le cloud.
