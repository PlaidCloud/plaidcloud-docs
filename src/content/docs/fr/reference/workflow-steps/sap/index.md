## Étapes d'extraction ad hoc

Trois étapes recherchent dans SAP, prévisualisent et planifient l'extraction, puis enregistrent le résultat dans une table. L'une lit une table, une autre exécute une transaction ou un rapport, et la troisième exécute une requête SAP Query enregistrée. Consultez [Extractions ad hoc depuis SAP ECC / S/4HANA](/fr/guides/connections/sap-adhoc-extract/).
