## Description

Importe une entité REST par contrat d'Acumatica dans une table de projet, via votre [connexion Acumatica](/fr/guides/connections/acumatica/). Choisissez la connexion, le type d'entité et les éventuels filtres ; l'étape récupère les enregistrements correspondants et les écrit, sans requête OData à rédiger.

Il s'agit d'une étape générique prédéfinie : un seul type d'étape couvre 18 entités, des données de base et de référence (comptes, sous-comptes, clients, fournisseurs, articles en stock) aux enregistrements transactionnels (factures de vente, factures fournisseur, commandes client, expéditions).

## Configuration

| Champ | Obligatoire | Remarques |
|---|---|---|
| Connexion Acumatica | Oui | La connexion Acumatica à utiliser pour la lecture. |
| Table cible | Oui | La table de projet dans laquelle les résultats sont écrits. Elle est entièrement écrasée à chaque exécution. |
| Type d'entité | Oui | L'entité à récupérer. Par défaut `account`. L'une des valeurs `account`, `ledger`, `financial_period`, `branch`, `currency`, `currency_rate`, `subaccount`, `customer`, `vendor`, `stock_item`, `warehouse`, `employee`, `tax_category`, `sales_invoice`, `bill`, `sales_order`, `shipment`, `project`. |
| Actifs uniquement | Non | Activé par défaut. Filtre sur `Active = true` pour les entités qui portent un indicateur Active. |
| Mis à jour après | Non | Date ou date et heure ISO. Seules les lignes modifiées après cette valeur sont renvoyées. C'est un filtre côté requête, sans curseur conservé : indiquez vous-même la date limite à chaque exécution. Laissé vide, il récupère tout. |
| Filtres | Non | Un tableau de clauses `{field, operator, value}` (`eq`, `ne`, `gt`, `ge`, `lt`, `le`, `contains`) ou de plages `{field, from, to}`. Chaque entité limite les filtres aux champs qu'Acumatica peut réellement évaluer côté serveur : un champ non pris en charge est rejeté, et non ignoré en silence. |

<Aside type="note">
La balance de vérification, le détail des transactions du grand livre, les stocks disponibles, les budgets et les données intersociétés se trouvent derrière les Generic Inquiries d'Acumatica, et non dans ces 18 entités par contrat. Créez la Generic Inquiry dans Acumatica et récupérez-la plutôt avec une [connexion REST générique](/fr/reference/connectors/rest/generic-rest/).
</Aside>

<Aside type="caution">
Le filtrage n'atteint que les champs au niveau de l'entité et de l'en-tête : les dimensions des lignes d'un document (par exemple un centre de coûts sur les lignes d'une facture fournisseur) ne peuvent pas être interrogées côté serveur. Récupérez l'entité, puis limitez le détail au niveau des lignes dans votre workflow après l'importation.
</Aside>
