## Description

Le bloc de **texte** d'un rapport composé. Il équivaut à l'outil Alteryx *Reporting* / *Portfolio Composer* correspondant et s'exécute dans le moteur de workflow (reportlab / matplotlib) ; le moteur de rendu produit une approximation de la sortie Alteryx.

## Source et options

- **Table source** : les données qui alimentent cet élément de rapport.
- **Table de sortie** : la table dans laquelle l'extrait généré est écrit.
- **Ordre des rapports** : la position de cet élément dans un rapport composé.
- **Contenu texte** : le texte à générer.

## Faire référence à une colonne dans le texte

Le contenu texte peut nommer une colonne entre crochets, et la valeur est imprimée à sa place :
`[Year] Results` imprime `2026 Results`. Un Report
Text Alteryx converti reprend toutes les références de champ que son texte contenait déjà, y compris
la forme mise en forme qu'Alteryx écrit sous la forme `[Year:A]`.

Un seul texte est composé pour toute la table source ; une colonne que vous nommez doit donc
contenir la même valeur sur chaque ligne lue. Synthétisez la colonne en amont si
elle en contient plusieurs : un bloc de texte ne peut pas imprimer plusieurs valeurs à la fois.

`[CurrentYear]` imprime l'année de génération du rapport et ne nécessite aucune colonne.

Quelques règles permettent d'écrire sans risque de la prose ordinaire :

- Un nom qui correspond à une colonne est toujours remplacé.
- Un nom qui ne correspond à aucune colonne arrête l'étape et le signale, mais seulement lorsqu'il
  ne pourrait être qu'une référence : un format écrit collé au
  deux-points, comme dans `[Quarter:A]`.
- Le texte entre crochets est imprimé tel que vous l'avez écrit. `[12:30]` reste une heure
  et `[Note: continued]` reste une incise, car un nombre seul n'est pas un nom de colonne
  et c'est la prose qui place une espace après les deux-points.

Le format lui-même n'est pas appliqué : la valeur est imprimée telle que la colonne la contient ;
mettez donc la colonne en forme en amont si elle a besoin de séparateurs de milliers ou d'une présentation de date.

## Colonnes

L'onglet **Colonnes** associe les colonnes source disponibles à l'élément de rapport.
