## Blocs de construction de rapport

Les workflows de reporting Alteryx convertis assemblent un document à partir de ces étapes. Chart,
Image, Map, Table et Text produisent chacune un élément ; Layout, Visual Layout et
Overlay organisent les éléments ; Render écrit le résultat composé dans un PDF.
