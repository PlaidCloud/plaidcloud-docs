## Description

La **carte** générée à partir de la géométrie source d'un rapport composé. Elle équivaut à l'outil Alteryx *Reporting* / *Portfolio Composer* correspondant et s'exécute dans le moteur de workflow (reportlab / matplotlib) ; le moteur de rendu produit une approximation de la sortie Alteryx.

## Source et options

- **Table source** : les données qui alimentent cet élément de rapport.
- **Table de sortie** : la table dans laquelle l'extrait généré est écrit.
- **Ordre des rapports** : la position de cet élément dans un rapport composé.
- **Largeur / Hauteur** : la taille de la carte générée, en pixels.

## La légende du thème

Lorsqu'une couche est nuancée selon une valeur, la carte trace une seule légende qui nomme chaque tranche.

Un Report Map Alteryx converti reprend les noms de tranches utilisés par la carte d'origine
(*Élevé*, *Supérieur à la moyenne*, *Moyen*, *Inférieur à la moyenne*, *Faible* sur une carte
thématique type) et la légende affiche ces noms. Une carte qui ne nomme aucune tranche
étiquette à la place chacune d'elles avec la plage de valeurs qu'elle couvre.

Comme une seule légende est tracée, les noms doivent appartenir aux tranches d'une seule couche.
Plutôt que d'afficher une légende d'apparence correcte mais qui nommerait les mauvaises tranches,
l'étape s'arrête et le signale dans les cas suivants :

- les valeurs nuancées n'atteignent pas toutes les tranches que la carte nomme, de sorte que les noms
  ne peuvent pas être associés aux tranches réellement tracées ;
- seules certaines des tranches sont nommées ;
- les tranches appartiennent à plusieurs couches, ou plusieurs couches sont nuancées.

Lorsque le nuançage se fait par valeur individuelle, chaque tranche continue de porter le nom de sa propre valeur,
puisque c'est ce qu'est la tranche.

## Colonnes

L'onglet **Colonnes** associe les colonnes source disponibles à l'élément de rapport.
