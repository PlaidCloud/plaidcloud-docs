## Description

La **table** des données source d'un rapport composé. Elle équivaut à l'outil Alteryx *Reporting* / *Portfolio Composer* correspondant et s'exécute dans le moteur de workflow (reportlab / matplotlib) ; le moteur de rendu produit une approximation de la sortie Alteryx.

## Source et options

- **Table source** : les données qui alimentent cet élément de rapport.
- **Table de sortie** : la table dans laquelle l'extrait généré est écrit.
- **Ordre des rapports** : la position de cet élément dans un rapport composé.
- **Colonnes** : les colonnes source à inclure (vide = toutes).

## Colonnes

L'onglet **Colonnes** associe les colonnes source disponibles à l'élément de rapport.
