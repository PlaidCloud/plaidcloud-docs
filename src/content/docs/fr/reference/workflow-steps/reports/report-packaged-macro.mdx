## Description

La **macro empaquetée** génère un bundle de rapport importé depuis une *macro de rapport empaquetée* Alteryx. C'est une étape Report à part entière : la définition de la macro incluse est transportée automatiquement avec l'étape, et l'élément est généré par le même chemin d'artefacts de rapport que les autres étapes Report.

## Source et options

- **Table source** : les données qui alimentent cet élément de rapport.
- **Table cible** : la table dans laquelle la sortie générée est écrite.
- **Ordre des rapports** : la position de cet élément dans un rapport composé.
