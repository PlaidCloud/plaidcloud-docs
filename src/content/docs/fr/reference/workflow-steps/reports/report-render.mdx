## Description

Le **rendu** des éléments de rapport composés en un document PDF. Il équivaut à l'outil Alteryx *Reporting* / *Portfolio Composer* correspondant et s'exécute dans le moteur de workflow (reportlab / matplotlib) ; le moteur de rendu produit une approximation de la sortie Alteryx.

## Source et options

- **Table source** : les données qui alimentent cet élément de rapport.
- **Table de sortie** : la table dans laquelle l'extrait généré est écrit.
- **Ordre des rapports** : la position de cet élément dans un rapport composé.
- **Largeur / Hauteur** : la taille des images intégrées, en pixels.
- **Fichier de sortie** : le chemin, dans le magasin de documents, du fichier généré.

- **Format de sortie** (`output_format`) : **PDF** (`pdf`, valeur par défaut) ou **Page HTML (autonome)** (`html`) pour écrire le rapport sous la forme d'une seule page HTML autonome. Donnez au nom du fichier l'extension `.html`.
- **Deuxième table source** (`source_b`) : une seconde table d'entrée, afin que le rendu compose les éléments des deux entrées.

## Colonnes

L'onglet **Colonnes** associe les colonnes source disponibles à l'élément de rapport.
