## Description


Supprime les modèles SAP Profitability and Cost Management (PCM) correspondant aux critères de recherche. Supprimer des modèles avec cette transformation permet d'en supprimer un grand nombre sans avoir à surveiller le processus.



## Nos références


PlaidCloud est un partenaire officiel de SAP et un fournisseur privilégié de services liés à la conception et à la mise en œuvre de modèles SAP PCM.







## Exemples


Sélectionnez « Agent à utiliser » dans la liste déroulante. Sélectionnez la « Model Search Method » de votre choix. Dans cet exemple, nous avons sélectionné « Exact Match ». Saisissez le « Model Search Text » (ce que vous recherchez) sous « Model Name Information » et indiquez si la recherche est sensible à la casse (si oui, cochez la case). Enfin, cochez « Wait for Deletion to Complete » et cliquez sur « Save and Run Step ».
