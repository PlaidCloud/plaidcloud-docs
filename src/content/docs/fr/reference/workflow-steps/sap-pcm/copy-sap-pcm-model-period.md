### Description


Copie une période d'un modèle SAP Profitability and Cost Management (PCM) au sein du même modèle.


### Nos références


PlaidCloud est un partenaire officiel de SAP et un fournisseur privilégié de services liés à la conception et à la mise en œuvre de modèles SAP PCM.


### Exemples


Sélectionnez Agent à utiliser dans la liste déroulante, puis saisissez « Nom du modèle », « From Period Name » et « To Period Name » dans le champ « Informations sur le modèle ». Cochez la case « Wait for Copy to Complete », puis cliquez sur « Save and Run Step ».
