## Description



Renomme un modèle SAP Profitability and Cost Management (PCM) existant. Utile pour la tenue des modèles lors des rotations de scénarios (par exemple, faire passer « Forecast Q3 » à « Actuals Q3 » après la clôture de la période) ou lors d'une réorganisation.

Le nouveau nom doit être unique sur le serveur PCM.


## Nos références


PlaidCloud est un partenaire officiel de SAP et un fournisseur privilégié de services liés à la conception et à la mise en œuvre de modèles SAP PCM.








## Exemples


Sélectionnez Agent à utiliser dans la liste déroulante, saisissez « From Model Name » et « To Model Name » dans le champ « Informations sur le modèle », cochez la case « Wait for Copy to Complete », puis cliquez sur « Save and Run Step ».
