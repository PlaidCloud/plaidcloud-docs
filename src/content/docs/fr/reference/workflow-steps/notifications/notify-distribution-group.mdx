## Description



Envoie une notification par e-mail à un groupe de distribution PlaidCloud, c'est-à-dire une liste nommée de destinataires gérée dans les paramètres de l'espace de travail. Utile pour les mises à jour d'état, les notifications de fin d'exécution ou les alertes d'erreur qui doivent atteindre un public défini.

Les messages sont envoyés depuis le service de notification de PlaidCloud. Les groupes de distribution sont gérés de façon centralisée afin que les auteurs de workflows n'intègrent pas d'adresses e-mail dans les définitions de workflow.


## Sélectionner une liste de distribution PlaidCloud


Sélectionnez une seule liste de distribution dans le menu déroulant. Les listes de distribution peuvent être créées à l'aide de Tools. Pour plus de détails sur la création d'une liste de distribution, consultez : [Outils PlaidCloud – Distro](/fr/administration/access/member-management/#gérer-les-listes-de-distribution-distro).



## Message


Indiquez l'**Objet** et le **Corps** de votre choix.



À noter : les variables du projet et les variables du workflow sont toutes deux disponibles pour cette transformation, dans la ligne d'objet comme dans le corps du message.



De plus, le code HTML standard est autorisé dans le corps pour personnaliser davantage l'apparence des messages e-mail.


## Exemples


Dans cet exemple, toutes les variables système sont utilisées. De plus, un peu de HTML met en forme la première ligne du corps. L'exécution de cette transformation envoie l'e-mail suivant à tous les membres du groupe de distribution :


* De : [info@tartansolutions.com](mailto:info%40tartansolutions.com) (n'oubliez pas que tous les messages proviennent de cette adresse)
* Objet : DEMO Analyze Demo Running


<Aside>Les destinataires individuels du message e-mail ne pourront **pas** voir les noms des autres membres de la liste de distribution.</Aside>
