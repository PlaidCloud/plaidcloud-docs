## Description



Déclenche une notification via un agent PlaidLink, utile lorsque les notifications doivent être acheminées par des systèmes sur site (alertes internes, webhooks internes, SMTP hérité) qui ne sont pas directement accessibles depuis PlaidCloud.

L'agent reçoit la charge utile de la notification et la distribue localement selon sa configuration.
