## Description



Envoie une notification en effectuant un POST vers une URL de webhook, utile pour déclencher des actions personnalisées en aval, alerter des plateformes d'intégration (Zapier, n8n, Make) ou piloter des bots Slack/Teams/Discord qui n'utilisent pas de connecteurs natifs.

Le format de la charge utile et les éventuels en-têtes personnalisés sont configurables. Le service destinataire est responsable de la suite.
