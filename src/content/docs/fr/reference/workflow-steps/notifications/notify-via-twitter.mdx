## Description


Envoie un message privé (DM) Twitter depuis [@plaidcloud](https://twitter.com/plaidcloud).



### Compte Twitter


Indiquez le compte Twitter qui doit recevoir le DM de @plaidcloud. Cet utilisateur doit suivre @plaidcloud pour recevoir le message. Il est permis, sans être obligatoire, de faire précéder le nom d'utilisateur du symbole arobase (@).



### Message


Saisissez le message de votre choix. Analyze n'autorise pas de valeur de plus de 140 caractères.


À noter : les variables du projet et les variables du workflow sont toutes deux disponibles pour cette transformation.


<Aside type="danger">Lorsque vous utilisez des variables, il est possible de générer des messages qui dépassent la limite de 140 caractères. Dans ce cas, le message ne sera PAS envoyé. L'erreur suivante sera écrite dans le journal à la place : *Twitter API returned a 403 (Forbidden), There was an error sending your message: The text of your direct message is over 140 characters.</Aside>

## Exemples

Dans cet exemple, un DM est envoyé de [@PlaidCloud](https://twitter.com/plaidcloud) à [@tartansolutions](https://twitter.com/tartansolutions). Des variables système sont utilisées dans le message. Le message final est : *Analyze Demo is running on #PlaidCloud*.
