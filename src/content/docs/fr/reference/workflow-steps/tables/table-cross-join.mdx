## Description


Permet d'effectuer une jointure croisée sur deux tables de données, en les combinant en une seule table de données sans clé(s) de jointure.


Un filtre source sur l'une ou l'autre table est appliqué avant le dimensionnement de la jointure : une jointure croisée filtrée sur de grandes tables s'exécute donc lorsque le nombre de lignes filtrées est suffisamment faible.

Pour en savoir plus sur la méthodologie de la jointure croisée, consultez : [Wikipédia SQL Cross Join](https://en.wikipedia.org/wiki/Join_%28SQL%29#Cross_join)

## Colonnes nommées à l'exécution

Sélectionnez **Reporter aussi les colonnes nommées à l'exécution** pour transmettre telles quelles toutes les colonnes source que l'étape ne répertorie pas, dans l'état où la table les contient à l'exécution de l'étape. Utilisez cette option lorsqu'une étape précédente crée des colonnes dont les noms dépendent des données, comme un pivot, et que vous ne pouvez donc pas les répertorier en créant l'étape. Laissez-la désactivée pour n'écrire que les colonnes que vous répertoriez.
