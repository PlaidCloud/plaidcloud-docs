## Description

Ajoute les lignes d'une table source à la fin d'une table cible existante. Les lignes existantes de la cible sont conservées ; seules les nouvelles lignes sont insérées. Utilisez-la lorsque des données arrivent de façon incrémentale (par exemple des extractions quotidiennes ou des fichiers de chargement mensuels) et que vous voulez faire croître la cible au fil du temps plutôt que la remplacer.

Si vous devez dédoublonner à l'ajout, faites suivre d'une étape [Table Union Distinct](/fr/reference/workflow-steps/tables/table-union-distinct/), ou utilisez [Table Upsert](/fr/reference/workflow-steps/tables/table-upsert/) si certaines lignes mettent à jour des enregistrements existants selon une clé.

## Paramètres de chargement

### Source et cible

![Source et cible](/images/table_source_and_target_EN.png)

Pour définir les tables source et cible, sélectionnez d'abord la table de données à extraire dans le menu déroulant **Table source**. Sélectionnez ensuite une table existante comme table cible dans la liste déroulante **Table cible**.

## Contrôles effectués à l'enregistrement

- **Le mappage correspond à une table cible existante.** Lorsque la table cible existe déjà, l'étape ne peut pas mapper une colonne que la table n'a pas, ni donner à une colonne un type différent de celui de la table. Les types numérique et monétaire comptent comme un même type. Une colonne de la table que le mappage omet est autorisée, et reste vide dans les lignes ajoutées. Le refus nomme chaque différence, par exemple *The target columns must match the existing target table 'sales'. Types differ: amount (table: numeric, step: text).* Une table cible qui n'existe pas encore, ou nommée à l'aide d'une variable, est vérifiée lors de l'exécution de l'étape.
- **Un mappage vide est rempli pour vous.** Si vous enregistrez avec une table source choisie mais sans colonnes source ou cible, le côté vide est rempli à partir de la source, comme le ferait **Renseigner les deux tables de mappage**.
