## Description

Alimente une table cible à partir d'une requête SQL `SELECT` que vous écrivez vous-même. Là où [Table Extract](/fr/reference/workflow-steps/tables/table-extract/) construit la requête à partir de colonnes et d'expressions mappées, cette étape transmet la requête telle quelle à l'entrepôt, pour les cas où le SQL est plus simple à exprimer directement qu'à assembler dans le mappeur.

Utilisez-la lorsque vous avez besoin d'une construction que le mappeur ne couvre pas : une CTE récursive, une fonction de fenêtrage sur une partition que le mappeur ne peut pas décrire, ou une requête sur plusieurs tables qu'une étape de jointure rendrait plus compliquée.

## Éléments de configuration propres à l'étape

### Requête SQL SELECT

Le texte de la requête. Mettez-le en forme sous la forme d'un SQL lisible, sur plusieurs lignes et indenté (une colonne ou une clause par ligne), plutôt que sur une seule longue ligne : l'étape conserve ce que vous écrivez et la prochaine personne qui l'ouvrira devra le lire.

La requête s'exécute sur le lakehouse du projet ; les fonctions disponibles sont donc celles du jeu [Lakehouse v1](/fr/reference/expressions/lakehouse-v1/) ou [v2](/fr/reference/expressions/lakehouse-v2/), selon l'espace de travail.
