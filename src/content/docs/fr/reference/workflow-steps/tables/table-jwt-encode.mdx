## Description

L'étape **Table : encoder en JWT** signe le JSON d'une colonne de charge utile et écrit le jeton dans une nouvelle colonne de texte, un jeton par ligne. La table de sortie est une copie de la source à laquelle cette colonne est ajoutée.

## Source et options

- **Table source** et **Table de sortie** : la table à lire et la table à écrire.
- **Algorithme** : `HS256`, `HS384`, `HS512`, `RS256`, `RS384` ou `RS512`.
- **Colonne de charge utile** : la colonne contenant la charge utile JSON à signer.
- **Colonne d'en-tête** *(facultatif)* : une colonne contenant un en-tête JSON. Il est fusionné par-dessus l'en-tête par défaut `{"alg": …, "typ": "JWT"}`.
- **Colonne de clé** *(facultatif)* : une colonne contenant la clé de signature. Sans elle, l'étape signe avec la clé détenue par sa connexion.
- **Colonne de sortie** : le nom de la colonne de texte qui reçoit le jeton.

Une analyse Savant convertie signe avec une clé détenue dans une connexion dédiée liée à l'étape, de sorte que la clé n'apparaît jamais dans la configuration de l'étape. Consultez [Migrer les analyses Savant](/fr/guides/workflows/migrate-savant-analyses/#jwt_encode).
