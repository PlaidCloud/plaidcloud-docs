## Description

L'étape Définir l'accès aux lignes recalcule à partir d'une table source les droits d'accès aux lignes d'une colonne gouvernée, puis les applique. Pointez la colonne vers une table dont chaque ligne associe un groupe de sécurité à une valeur que ce groupe peut voir : l'étape lit ces lignes et écrit les droits qui en résultent. L'accès aux lignes reste ainsi à jour à mesure que les données sources changent, sans que personne ait à modifier la grille à la main.

La colonne doit déjà restreindre les lignes. Configurez-la d'abord dans la grille Accès aux lignes. À sa première exécution, l'étape lie la colonne à la table source : les droits définis manuellement pour la colonne sont supprimés et remplacés par les lignes de la table. Ensuite, la colonne apparaît verrouillée dans la grille Accès aux lignes, avec un badge de source, et sa modification manuelle y est refusée tant que quelqu'un n'a pas cliqué sur **Supprimer la liaison**. Consultez [Lier des droits à une table source](/fr/administration/access/managing-security-groups-and-assignments/#lier-les-droits-à-une-table-source) dans le guide Accès aux lignes.

<Aside type="note" title="À utiliser pour synchroniser les droits avec des données qui changent">
Un usage typique consiste à planifier cette étape après le workflow qui charge ou actualise la table source. Un nouveau groupe, une valeur supprimée ou un territoire réaffecté parvient alors automatiquement à l'accès aux lignes à l'exécution suivante, au lieu de dépendre de quelqu'un qui penserait à mettre la grille à jour à la main.
</Aside>

## Paramètres

- **Projet** — le projet dont cette étape met à jour la colonne gouvernée.
- **Colonne** — la colonne gouvernée, choisie parmi les colonnes réelles du projet.
- **Table source** — la table qui fournit les lignes (groupe, valeur). Si vous nommez une autre table que celle à laquelle la colonne est liée, la colonne est reliée à la nouvelle table.
- **Colonne de groupe** — la colonne de la table source qui nomme le groupe de sécurité.
- **Colonne de valeur** — la colonne de la table source qui nomme la valeur que ce groupe peut voir.

## Comportement

À chaque exécution, l'étape lit toutes les lignes (groupe, valeur) présentes dans la table source et remplace les droits de la colonne par exactement cet ensemble. Un groupe qui n'apparaît plus dans la table source perd tous les droits que cette étape lui avait accordés. Les lignes qui nomment un groupe de sécurité inexistant sont ignorées, sans faire échouer l'étape. La mise à jour atteint de la même façon les requêtes de PlaidCloud et les tableaux de bord Superset qu'un enregistrement manuel, généralement en une minute environ.

Comme la table source détermine qui voit quoi, seuls un Architecte du projet, un administrateur du tenant ou les workflows du projet lui-même peuvent modifier ses lignes ou la supprimer une fois qu'elle est liée.

<Aside type="caution">
Cette étape remplace l'*ensemble* des droits qu'elle gère. Si vous gérez certains droits d'une colonne à la main et d'autres à partir d'une table source, utilisez deux colonnes distinctes : les droits modifiés manuellement sur une colonne liée à une source ne sont pas conservés d'une exécution à l'autre.
</Aside>
