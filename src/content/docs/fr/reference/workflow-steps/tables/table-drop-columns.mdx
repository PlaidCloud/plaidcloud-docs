## Description

L'étape **Table : supprimer des colonnes** écrit une copie de la table source dans la table de sortie, en omettant les colonnes que vous choisissez. Toutes les autres colonnes conservent leur nom, leur type et leur position.

## Source et options

- **Table source** et **Table de sortie** : la table à lire et la table à écrire.
- **Colonnes à supprimer** : les colonnes à omettre. Choisissez-en au moins une. Une colonne absente de la source est ignorée, de sorte que l'étape s'exécute toujours lorsqu'une étape précédente cesse de la produire.
- **Préfixe d'ordre numérique** *(facultatif)* : place dans l'ordre numérique, aux positions qu'elles occupent, les colonnes conservées qui commencent par ce texte. Avec le préfixe `Tags_`, `Tags_2` vient avant `Tags_10` au lieu de venir après.
- **Table des noms de colonnes** (`drop_from`) et **Colonne contenant les noms** (`drop_from_column`, `drop` par défaut), dans la section **Colonnes nommées par une table** *(facultatif)* : une table dont les cellules de cette colonne, chacune étant une liste JSON de noms de colonnes, désignent d'autres colonnes à omettre. La table est lue à l'exécution de l'étape.
