## Description


Table Anti Join fournit l'ensemble des éléments sans correspondance entre deux tables. Elle renvoie la liste des éléments de la première table qui n'ont pas de correspondance dans la seconde. C'est très utile pour déterminer quels enregistrements sont présents dans une table mais absents d'une autre.



Cette opération pourrait être réalisée avec des jointures externes et un filtrage sur les valeurs nulles de la jointure ; l'étape Anti Join le fait toutefois de manière plus efficace et plus explicite.

<Aside type="note" title="Il s'agit d'une jointure gauche excluante, pas d'une jointure gauche">
Table Anti Join conserve les lignes de la source A qui n'ont **aucune** correspondance dans la source B. Son comportement est fixé par le type d'étape ; il n'y a donc pas de sélecteur de type de jointure. Si vous voulez une **jointure gauche** — toutes les lignes de la source A, avec les colonnes de la source B renseignées là où les clés correspondent — utilisez l'étape [Table Outer Join](/fr/reference/workflow-steps/tables/table-outer-join/) et réglez son **Type de jointure** sur **Gauche**. Comme une anti-jointure ne renvoie que les lignes de la source A sans correspondance, sa sortie provient **uniquement de la source A** ; la source B fournit les clés de jointure mais aucune colonne de sortie.
</Aside>

## Colonnes nommées à l'exécution

Sélectionnez **Reporter aussi les colonnes nommées à l'exécution** pour transmettre inchangée toute colonne source que l'étape ne liste pas, telle que la table la contient lors de l'exécution de l'étape. Utilisez cette option lorsqu'une étape précédente crée des colonnes dont les noms dépendent des données, comme un pivot, et que vous ne pouvez donc pas les lister lors de la création de l'étape. Laissez-la désactivée pour n'écrire que les colonnes que vous listez.
