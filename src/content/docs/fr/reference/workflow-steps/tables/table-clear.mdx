## Description


Vide le contenu d'une table de données existante sans supprimer la table elle-même. Le résultat est une table de données de 0 ligne.



<SnippetCommonTableSelectionDynamic />

Avec **Tables correspondant à la recherche**, l'étape ne s'enregistre pas si **Texte de recherche** est vide alors que **Chemin de recherche** est le niveau supérieur du projet (`/`), car cela viderait toutes les tables du projet. Saisissez un texte à rechercher, ou choisissez un dossier.
