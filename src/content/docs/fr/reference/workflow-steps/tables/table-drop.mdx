## Description

Supprime entièrement une table du projet, à la fois sa définition et toutes ses données. Cette opération est destructive et irréversible : une fois le workflow exécuté, la table n'existe plus.

Utilisez cette étape lorsque des tables intermédiaires d'un workflow ne sont plus nécessaires en aval (par exemple pour nettoyer après une transformation en plusieurs étapes). Pour vider temporairement une table sans la supprimer, utilisez plutôt [Table Clear](/fr/reference/workflow-steps/tables/table-clear/).
