## Description


Crée une copie d'une table de données.




<SnippetCommonTableSourceAndTarget />



Lors de la copie, Analyze vérifie d'abord si la table de données cible existe déjà. Si c'est le cas, aucune action n'est effectuée, sauf si la case **Allow Overwriting Existing Table** est cochée. Dans ce cas, la table cible est écrasée.
