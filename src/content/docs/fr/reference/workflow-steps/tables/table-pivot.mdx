## Description


Sert à convertir des tables de données longues et étroites en tables de données courtes et larges. Les colonnes sélectionnées sont transposées, les noms de colonnes étant convertis en valeurs réparties sur plusieurs colonnes.


L'exemple le plus facile à comprendre consiste peut-être à imaginer une table de données dont les mois sont listés en lignes :





Pivoter cette table de données convertirait toutes les lignes de mois en colonnes.

En précisant quelles colonnes transposer et lesquelles laisser telles quelles, cela devient un outil puissant. Réaliser cette conversion dans d'autres outils ETL pourrait nécessiter une douzaine d'étapes de plus.

Pour établir la source et la cible, sélectionnez d'abord la table de données à extraire à l'aide du menu déroulant.

### Sélection des colonnes de pivot

La **Colonne de catégorie à transformer en en-têtes de colonne** est l'endroit où vous indiquez la colonne de la table source qui sera pivotée en lignes.
La **Colonne de valeur à pivoter en valeurs de colonne** est la colonne qui contient les valeurs dans la table source.
L'**Option d'agrégation des valeurs** est l'endroit où vous indiquez comment agréger les données.

Les deux colonnes doivent figurer parmi les colonnes de sortie de l'étape dans l'onglet **Colonnes**. Sinon, l'enregistrement est refusé, par exemple avec le message *The category column 'month' isn't one of the step's output columns.*


Le formulaire comporte aussi les champs suivants :

* **Colonne contenant la position de chaque catégorie** (`column_order`) : une colonne source contenant la position de chaque catégorie. Les colonnes pivotées arrivent dans l'ordre croissant de cette colonne plutôt que triées par nom. Elle n'est ni regroupée ni écrite.
* **Modèle de nom des colonnes pivotées** (`column_name_template`) : nomme chaque colonne pivotée d'après ce texte, `{value}` étant remplacé par la valeur de la catégorie, par exemple `{value}+Sum`.

## Sélection des données de la table

![Table Pivot Data Selection](/images/table_pivot_2.png)


L'onglet Sélection des données de la table sert à mapper les colonnes de la table de données source vers la table de données cible. Toutes les colonnes source situées à gauche de la fenêtre sont automatiquement mappées vers la table de données cible représentée à droite de la fenêtre. Avec le bouton de menu **Inspecter la source**, il existe quelques autres façons de mapper les colonnes de la source vers la cible :


* Renseigner les deux tables de mappage : propage toutes les valeurs de la table de données source dans la table de données cible. C'est le comportement par défaut.
* Renseigner uniquement la table de mappage source : mappe uniquement toutes les valeurs de la table de données source. Utile pour modifier un workflow existant lorsque la structure des colonnes source a changé.
* Renseigner uniquement la table de mappage cible : propage toutes les valeurs dans la table de données cible uniquement.

En plus de chacune de ces options, chaque choix permet d'afficher un aperçu des données source.

Enregistrer avec une table source choisie mais sans colonnes source ou sans colonnes cibles remplit le côté vide à partir de la source, comme le ferait **Renseigner les deux tables de mappage**.



Si les options de colonnes source et cible ne suffisent pas, d'autres colonnes peuvent être ajoutées à la table de données cible de plusieurs manières :


* **Tout propager** insère toutes les colonnes source dans la table de données cible, qu'elles existent déjà ou non.
* **Propager la sélection** insère uniquement les colonnes source sélectionnées.
* Faites un clic droit côté cible et sélectionnez **Insérer une ligne** pour insérer une ligne immédiatement au-dessus de la ligne actuellement sélectionnée.
* Faites un clic droit côté cible et sélectionnez **Ajouter une ligne** pour insérer une ligne en bas (tout à droite) de la table de données cible.


<Aside type="danger">Sélectionner **Tout propager** peut effectivement créer un doublon de chaque colonne. Analyze ne vérifie pas si les colonnes sont déjà mappées. Assurez-vous qu'il n'existe pas de noms de colonnes en double.</Aside>




Pour supprimer des colonnes de la table de données cible, sélectionnez la ou les colonnes voulues, puis faites un clic droit et sélectionnez **Supprimer**.



Pour réorganiser les colonnes de la table de données cible, sélectionnez la ou les colonnes voulues, puis faites un clic droit et sélectionnez **Déplacer en haut**, **Monter**, **Descendre** ou **Déplacer en bas**.



Pour ne renvoyer que des options distinctes, sélectionnez l'option de menu **Distinct**. Cela active un ensemble de cases à cocher pour chaque colonne de la source. Cochez simplement la case en regard de la colonne correspondante pour ne renvoyer que des résultats distincts.

<Aside type="danger">Lorsque la table de données cible ne contient qu'un sous-ensemble de la table de données source, cochez la case uniquement pour les colonnes qui **doivent** figurer dans la table de données cible. Cocher toutes les cases pourrait produire une sortie qui ne semble pas distincte.</Aside>




Pour agréger les résultats, sélectionnez l'option de menu **Résumer**. Cela active un ensemble de listes déroulantes pour chaque colonne de la table de données cible. Les options de synthèse suivantes sont disponibles :


* Regrouper par (valeur par défaut)
* Somme
* Min
* Max
* Premier
* Dernier
* Nombre
* Moyenne
* Médiane
* Mode
* Écart type
* Variance
* Produit
* Valeur absolue
* Quantile
* Asymétrie
* Aplatissement
* Écart absolu moyen
* Somme cumulée
* Min cumulé
* Max cumulé
* Produit cumulé




## Filtres de données


Pour offrir une flexibilité maximale, des filtres de données sont disponibles sur les données source et sur les données cible. Pour les jeux de données plus volumineux, il peut être particulièrement avantageux de filtrer des lignes à la source afin que les opérations restantes portent sur un jeu de données plus petit.



### Sélectionner un sous-ensemble de données


N'importe quelle expression Python valide est acceptable pour créer un sous-ensemble des données. Consultez [Expressions](/fr/reference/expressions/)


pour plus de détails et d'exemples.






### Appliquer un filtre secondaire aux données de résultat


N'importe quelle expression Python valide est acceptable pour créer un sous-ensemble des données. Consultez [Expressions](/fr/reference/expressions/) pour plus de détails et d'exemples.



### Découpage final de la table de données (limite)


Pour limiter les données, cochez simplement la case **Appliquer le découpeur de lignes**, puis indiquez ce qui suit :


* **Lignes initiales à ignorer :** lignes de données à ignorer (la ligne d'en-tête des colonnes n'est pas comptée)
* **Terminer à la ligne :** dernière ligne de données à inclure. Cela diffère du simple décompte de lignes à supprimer à la fin
