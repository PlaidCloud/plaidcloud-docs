## Description


Permet de combiner plusieurs tables de données ayant la même structure de colonnes en une seule table. Les données de séries temporelles, par exemple, s'y prêtent particulièrement bien. Le résultat contient tous les enregistrements des tables combinées.

<Aside>**Union All** ne supprime pas les doublons. Pour supprimer les enregistrements en double, utilisez plutôt **Union Distinct**.</Aside>

## Sources


La section **Sources** regroupe toutes les tables de données à ajouter les unes aux autres. En général, toutes les tables de données ont la même structure de colonnes (ou une structure similaire). Deux boutons permettent d'ajouter une table de données à la liste :


* **Insérer une ligne**
* **Ajouter une ligne**

Vous pouvez aussi faire un clic droit dans la fenêtre **Sélectionner la source à modifier** pour afficher les mêmes options. Un clic droit sur une table déjà ajoutée affiche également l'option **Supprimer**.


Pour que la transformation s'exécute correctement, la section **Sources** doit contenir une entrée pour chaque table de données source à ajouter. Ces entrées sont listées dans l'ordre où elles seront ajoutées. Pour modifier l'ordre, faites un clic droit sur une table afin d'afficher les options suivantes :


* **Descendre** (le cas échéant)
* **Déplacer en bas** (le cas échéant)
* **Monter** (le cas échéant)
* **Déplacer en haut** (le cas échéant)

Par défaut, chaque source se nomme *New Frame*, mais nous encourageons le modélisateur à lui donner un nom descriptif, en double-cliquant sur le nom pour le renommer.


<Aside>N'oubliez pas que le texte affiché n'a **aucun** rapport avec le nom de la table de données source. Nous recommandons au modélisateur de choisir un nom descriptif, souvent identique à celui de la table de données source, mais gardez à l'esprit qu'aucun lien n'existe entre ces noms.</Aside>


## Table cible


Par défaut, la **Table cible** est laissée vide. Avant de la nommer, notez que les noms des tables de données doivent respecter les conventions de nommage de Linux. Nous recommandons donc de n'utiliser que des caractères alphanumériques. Analyze supprime automatiquement les caractères non valides du nom. Il limite également la longueur à 256 caractères : soyez donc concis.

## Correspondance des colonnes

**Faire correspondre les colonnes par**, sous **Table cible**, détermine comment les sources s'alignent :

* **Nom** (par défaut) — les colonnes de chaque source sont mises en correspondance par nom avec celles de la première source.
* **Position** — les sources sont empilées dans l'ordre, comme le fait `union` de Spark. Le résultat reprend les noms de colonnes de la première source, et chaque source doit avoir le même nombre de colonnes. Le mappage des colonnes de chaque source n'est pas utilisé, et son onglet **Sélection des données de la table** est donc désactivé.

Avec **Position**, chaque colonne prend un type qui convient à toutes les sources : deux types numériques deviennent le plus large des deux, une date et un horodatage deviennent un horodatage, et les autres mélanges deviennent du texte. Une colonne booléenne ou binaire mélangée à un autre type n'a pas de type commun et fait échouer l'étape, de même que des sources comptant un nombre de colonnes différent.

Si toutes les tables sources sont absentes, l'étape se termine avec un avertissement au lieu d'échouer, quel que soit le mode.

## Contrôles effectués à l'enregistrement

Chaque source doit produire les mêmes colonnes que la première source : les mêmes noms de colonnes et, lorsque les deux en déclarent un, le même type. La table cible est construite à partir des colonnes de la première source. Une source peut lister ses colonnes dans un ordre différent, car elles sont mises en correspondance par nom. L'enregistrement d'une étape dont les sources diffèrent est refusé, avec le détail de chaque différence : *La source « east » doit produire les mêmes colonnes que « west » : region manquante ; absente de « west » : area.*

L'enregistrement renseigne aussi, à partir de sa table, le mappage de chaque source qui a une table source mais aucune colonne source ou cible, comme le ferait **Renseigner les deux tables de mappage**.
