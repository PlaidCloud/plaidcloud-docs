## Description


Sert à combiner plusieurs tables de données ayant la même structure de colonnes en une seule table de données. Par exemple, les données de séries chronologiques sont d'excellentes candidates pour cette transformation. Le résultat contient tous les enregistrements des tables combinées.

<Aside>**Union All** ne supprime pas les doublons. Si vous souhaitez supprimer les enregistrements en double, utilisez plutôt **Union Distinct**.</Aside>

## Sources


La section **Sources** regroupe toutes les tables de données à ajouter les unes à la suite des autres. En règle générale, toutes les tables de données ont la même structure de colonnes (ou une structure similaire). Deux boutons permettent d'ajouter une table de données à la liste :


* **Insérer une ligne**
* **Ajouter une ligne**

De plus, un clic droit dans la fenêtre **Sélectionner la source à modifier** affiche les mêmes options. Un clic droit sur une table déjà ajoutée affiche aussi l'option **Supprimer**.


Pour que la transformation s'exécute correctement, la section **Sources** doit comporter une entrée pour chaque table de données source à ajouter. Ces entrées sont listées dans l'ordre dans lequel elles seront ajoutées. Pour modifier l'ordre, un clic droit sur une table affiche les options suivantes :


* **Descendre** (le cas échéant)
* **Déplacer en bas** (le cas échéant)
* **Monter** (le cas échéant)
* **Déplacer en haut** (le cas échéant)

Par défaut, chaque source est nommée *New Frame*, mais le modélisateur est encouragé à fournir des noms descriptifs en double-cliquant sur le nom et en le renommant en conséquence.


<Aside>Il est important de se rappeler que le texte affiché n'a **aucun** rapport avec le nom de la table de données source. Nous recommandons que le modélisateur fournisse un nom descriptif, souvent le même que celui de la table de données source, mais gardez à l'esprit qu'il n'existe aucun lien entre les noms.</Aside>


## Table cible


Par défaut, la **Table cible** est laissée vide. Avant de la nommer, notez que les tables de données doivent respecter les conventions de nommage de Linux. Nous recommandons donc que les noms ne comportent que des caractères alphanumériques. Analyze supprime automatiquement du nom les caractères non valides. De plus, il limite la longueur à 256 caractères ; soyez donc concis.

## Correspondance des colonnes

**Faire correspondre les colonnes par** sous **Table cible** choisit la façon dont les sources s'alignent :

* **Nom** (par défaut) : les colonnes de chaque source sont mises en correspondance par nom avec celles de la première source.
* **Position** : les sources sont empilées dans l'ordre, comme le fait `union` de Spark. Le résultat reprend les noms de colonnes de la première source, et chaque source doit avoir le même nombre de colonnes. Le mappage des colonnes de chaque source n'est pas utilisé ; son onglet **Colonnes** est donc désactivé.

Avec **Position**, chaque colonne prend un type que toutes les sources acceptent : deux types numériques deviennent le plus large, une date et un horodatage deviennent un horodatage, et les autres mélanges deviennent du texte. Une colonne booléenne ou binaire mélangée à un autre type n'a aucun type commun et fait échouer l'étape, de même que des sources comportant un nombre de colonnes différent.

Si toutes les tables source sont absentes, l'étape se termine avec un avertissement au lieu d'échouer, dans les deux modes.

## Ce qui est contrôlé à l'enregistrement

Chaque source doit produire les mêmes colonnes que la première source : les mêmes noms de colonnes et, lorsque les deux en déclarent un, le même type. La table cible est construite à partir des colonnes de la première source. Une source peut lister ses colonnes dans un ordre différent, car elles sont mises en correspondance par nom. L'enregistrement d'une étape dont les sources diffèrent est refusé, en nommant chaque différence : *Source 'east' must produce the same columns as 'west': missing region; not in 'west': area.*

L'enregistrement remplit aussi, à partir de sa table, le mappage de chaque source qui a une table source mais pas de colonnes source ou pas de colonnes cibles, comme le ferait **Renseigner les deux tables de mappage**.
