## Description


Permet d'effectuer une jointure externe sur deux tables de données, en les combinant en une seule table de données à partir de la ou des clés de jointure indiquées. Le contrôle **Type de jointure** sélectionne les lignes sans correspondance à conserver : une **Jointure gauche**, une **Jointure droite** ou une **Jointure externe complète**. La valeur par défaut est une jointure gauche (chaque ligne de la table A, avec les colonnes de la table B renseignées là où les clés correspondent).


Pour en savoir plus sur la méthodologie de la jointure externe, consultez : [Wikipédia SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## Colonnes nommées à l'exécution

Sélectionnez **Reporter aussi les colonnes nommées à l'exécution** pour transmettre telles quelles toutes les colonnes source que l'étape ne répertorie pas, dans l'état où la table les contient à l'exécution de l'étape. Utilisez cette option lorsqu'une étape précédente crée des colonnes dont les noms dépendent des données, comme un pivot, et que vous ne pouvez donc pas les répertorier en créant l'étape. Laissez-la désactivée pour n'écrire que les colonnes que vous répertoriez.

### Type de jointure

Choisissez comment conserver les lignes sans correspondance :

- **Jointure gauche** : conserve chaque ligne de la table A ; les colonnes de la table B ne sont renseignées que là où les clés de jointure correspondent. C'est la valeur par défaut.
- **Jointure droite** : conserve chaque ligne de la table B ; les colonnes de la table A ne sont renseignées que là où les clés de jointure correspondent.
- **Jointure externe complète** : conserve chaque ligne des deux tables, qu'elle ait ou non une correspondance de l'autre côté.

## Exemples


### Joindre des constructeurs automobiles à des modèles


Dans cet exemple, considérez les tables de données source suivantes. La première est une liste de constructeurs automobiles.




| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


La suivante est une liste de modèles automobiles avec un identifiant de constructeur. Notez que plusieurs modèles n'ont aucun constructeur.




| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

Pour obtenir une liste de modèles par constructeur, il est logique de joindre sur *Mfg_ID*. En s'appuyant sur les concepts de la jointure externe, la sortie pourra aussi montrer les éléments qui n'ont aucune correspondance.



Commencez par définir les paramètres de **Sélection des données de la table 1**. La table de données source est sélectionnée et toutes les colonnes sont répertoriées.



Définissez ensuite les paramètres de **Sélection des données de la table 2.** Là encore, la table de données source est sélectionnée et toutes les colonnes sont répertoriées.



Enfin, les conditions de jointure sont définies dans l'onglet **Sortie de la table**. Grâce au bouton **Deviner**, Analyze identifie correctement la colonne *Mfg_ID* à utiliser comme **Join Key**. Comme cet exemple conserve les lignes sans correspondance des deux tables, définissez le **Type de jointure** sur **Jointure externe complète**. Pour finir, les 


**Colonnes de sortie cibles** sont spécifiées automatiquement à l'aide du bouton **Propager**. Cela inclut de fait toutes les colonnes de toutes les tables, les colonnes de jointure n'étant bien sûr incluses qu'une seule fois. Notez que les colonnes sont triées par ordre alphabétique, d'abord par *Manufacturer*, puis par *ModelName*.



Comme prévu, la sortie finale inclut toutes les lignes des deux tables, qu'elles aient ou non une correspondance dans les deux. Ainsi, cette fois, *Porsche* apparaît bel et bien malgré l'absence de modèles. De plus, *Batmobile*, *Lightning McQueen* et *Optimus Prime* figurent dans les résultats même si aucun n'a de constructeur. Et puis, qui pourrait leur dire non ?
