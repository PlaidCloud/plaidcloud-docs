## Description


Sert à effectuer une jointure externe sur 2 tables de données, en les combinant en une seule table de données selon la ou les clés de jointure spécifiées. Le contrôle **Type de jointure** sélectionne les lignes sans correspondance à conserver : une jointure **gauche**, **droite** ou **externe complète**. Par défaut, il s'agit d'une jointure gauche (toutes les lignes de la Table A, avec les colonnes de la Table B renseignées là où les clés correspondent).


Pour plus de détails sur la méthodologie de la jointure externe, consultez : [Wikipédia, SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## Colonnes nommées à l'exécution

Sélectionnez **Reporter aussi les colonnes nommées à l'exécution** pour transmettre, sans modification, chaque colonne source que l'étape ne liste pas, telle que la table les contient lorsque l'étape s'exécute. Utilisez cette option lorsqu'une étape antérieure crée des colonnes dont les noms dépendent des données, comme un pivot, de sorte que vous ne pouvez pas les lister lorsque vous construisez l'étape. Laissez-la désactivée pour n'écrire que les colonnes que vous listez.

### Type de jointure

Choisissez comment les lignes sans correspondance sont conservées :

- **Jointure gauche** : conserve toutes les lignes de la Table A ; les colonnes de la Table B ne sont renseignées que là où les clés de jointure correspondent. C'est la valeur par défaut.
- **Jointure droite** : conserve toutes les lignes de la Table B ; les colonnes de la Table A ne sont renseignées que là où les clés de jointure correspondent.
- **Jointure externe complète** : conserve toutes les lignes des deux tables, qu'elles aient ou non une correspondance de l'autre côté.

## Exemples


### Joindre des constructeurs automobiles à leurs modèles


Dans cet exemple, considérez les tables de données source suivantes. La première est une liste de constructeurs automobiles.




| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


La suivante est une liste de modèles automobiles avec un identifiant de constructeur. Notez que plusieurs modèles n'ont aucun constructeur.




| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

Pour obtenir une liste de modèles par constructeur, il est logique de joindre sur *Mfg_ID*. En s'appuyant sur les concepts de jointure externe, la sortie pourra aussi afficher les éléments qui n'ont aucune correspondance.



Commencez par spécifier les paramètres de **Table 1 Data Selection**. La table de données source est sélectionnée et toutes les colonnes sont listées.



Spécifiez ensuite les paramètres de **Table 2 Data Selection.** Là encore, la table de données source est sélectionnée et toutes les colonnes sont listées.



Enfin, les conditions de jointure sont définies dans l'onglet **Sortie**. Grâce au bouton **Deviner**, Analyze identifie correctement la colonne *Mfg_ID* à utiliser comme **Clé de jointure**. Comme cet exemple conserve les lignes sans correspondance des deux tables, définissez le **Type de jointure** sur **Jointure externe complète**. Enfin, les 


**Colonnes de sortie cibles** sont spécifiées automatiquement avec le bouton **Propager**. Cela inclut effectivement toutes les colonnes de toutes les tables, les colonnes de jointure n'étant évidemment incluses qu'une seule fois. Notez que les colonnes sont triées par ordre alphabétique, d'abord par *Manufacturer*, puis par *ModelName*.



Comme prévu, la sortie finale inclut toutes les lignes des deux tables, qu'elles aient eu une correspondance dans les deux tables ou non. Ainsi, cette fois, *Porsche* apparaît bel et bien malgré l'absence de modèles. De plus, *Batmobile*, *Lightning McQueen* et *Optimus Prime* figurent dans les résultats alors qu'aucun n'a de constructeur. Après tout, qui peut leur dire « non » ?
