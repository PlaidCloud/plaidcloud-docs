## Description


Si vous utilisez régulièrement la fonction RECHERCHEV (vlookup) de Microsoft Excel, la transformation Table Lookup vous semblera très familière : elle remplit essentiellement la même fonction. Contrairement à la version de Microsoft Excel, la transformation Table Lookup de PlaidCloud Analyze offre une plus grande souplesse, en permettant notamment de faire correspondre et de renvoyer plusieurs colonnes.

## Exemples


### Rechercher les informations de la dimension produit


Dans cet exemple, le modélisateur a besoin d'informations de la table de dimension produit pour donner du sens à la table de faits des commandes. La table *Import Order Fact* est donc sélectionnée comme **Table source**. La table *Import Product Dim* contient les informations de recherche souhaitées ; elle est donc sélectionnée comme **Lookup Table Source**. Bien que ce soit possible, aucun filtre n'est appliqué à la table de données de recherche (ni à aucune autre table de données, d'ailleurs).



Dans la section **Sélection des données de la table**, toutes les colonnes sont mappées de la table de données source vers la table de données cible. 



Aucun des **Filtres de données** n'est appliqué aux données source ni aux données cible. 



Enfin, la table de données source est mise en correspondance avec la table de données de recherche à l'aide du champ *Product_ID* présent dans chaque table. Seules les colonnes *Product_Description* et *Unit_Cost* sont ajoutées à la table de données cible, *Unit_Cost* étant renommée en *Retail_Unit_Cost* au passage. 



Dans la table de données cible obtenue, les colonnes *Product_Description* et *Retail_Unit_Cost* ont été ajoutées, d'après les valeurs correspondantes de la colonne *Product_ID*.
