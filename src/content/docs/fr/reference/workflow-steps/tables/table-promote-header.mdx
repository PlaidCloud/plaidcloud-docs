## Description

L'étape **Table : promouvoir l'en-tête** prend une ligne de l'entrée et fait de ses valeurs les noms de colonnes, puis supprime cette ligne. Utilisez-la pour un fichier dont le véritable en-tête n'est pas la première ligne. L'étape s'exécute lors de l'exécution du workflow : les noms proviennent donc des données.

## Source et options

- **Table source** et **Table de sortie** : la table à lire et la table à écrire.
- **Ligne d'en-tête** : la ligne, comptée à partir de 1, dont les valeurs nomment les colonnes. Elle est retirée des données. Laissez vide pour ne promouvoir aucun en-tête et appliquer les étapes de mise en forme aux noms stockés.
- **Colonne d'ordre des enregistrements** *(facultatif)* : la colonne qui met les lignes en ordre. Sans elle, les lignes sont lues telles qu'elles sont stockées, de sorte que la ligne qui nomme les colonnes peut changer d'une exécution à l'autre.
- **Colonnes si l'entrée est vide** *(facultatif)* : noms, séparés par des virgules, des colonnes de texte à écrire lorsque l'entrée ne contient aucune ligne.

## Étapes de mise en forme

Chaque ligne de la grille **Étapes de mise en forme** modifie les noms promus.

| Paramètre | Choix |
| --- | --- |
| Action | **Renommer**, **Changer le type**, **Masquer**, **Remplir les vides** |
| Critère | **Contient**, **Commence par**, **Se termine par** ou **Est vide** |
| Texte correspondant | Le texte à rechercher dans le nom de la colonne. Inutile pour **Est vide**. |
| Renommer par | **Remplacement du texte**, **Ajout avant** ou **Ajout après**, pour un renommage |
| Remplacer par | Le nouveau texte pour un renommage ou un remplissage |
| Valeur | Le type pour **Changer le type** |

Chaque étape nécessite une action et un critère, et un renommage nécessite une méthode de renommage et son texte.
