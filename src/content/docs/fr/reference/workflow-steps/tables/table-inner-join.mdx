## Description


Sert, comme son nom l'indique, à effectuer une jointure interne sur 2 tables de données, en les combinant en une seule table de données selon la ou les clés de jointure spécifiées.


Pour plus de détails sur la méthodologie de la jointure interne, consultez : [Wikipédia, SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## Colonnes nommées à l'exécution

Sélectionnez **Reporter aussi les colonnes nommées à l'exécution** pour transmettre, sans modification, chaque colonne source que l'étape ne liste pas, telle que la table les contient lorsque l'étape s'exécute. Utilisez cette option lorsqu'une étape antérieure crée des colonnes dont les noms dépendent des données, comme un pivot, de sorte que vous ne pouvez pas les lister lorsque vous construisez l'étape. Laissez-la désactivée pour n'écrire que les colonnes que vous listez.

## Exemples


### Joindre des constructeurs automobiles à leurs modèles


Dans cet exemple, considérez les tables de données source suivantes. La première est une liste de constructeurs automobiles.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

La suivante est une liste de modèles automobiles avec un identifiant de constructeur. Notez que plusieurs modèles n'ont aucun constructeur.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

Pour obtenir une liste de modèles par constructeur, il est logique de joindre sur *Mfg_ID*.


Commencez par spécifier les paramètres de **Table 1 Data Selection**. La table de données source est sélectionnée et toutes les colonnes sont listées.



Spécifiez ensuite les paramètres de **Table 2 Data Selection**. Là encore, la table de données source est sélectionnée et toutes les colonnes sont listées.



Enfin, les conditions de jointure sont définies dans l'onglet **Sortie**. Grâce au bouton **Deviner**, Analyze identifie correctement la colonne *Mfg_ID* à utiliser comme **Clé de jointure**. Enfin, les 


**Colonnes de sortie cibles** sont spécifiées automatiquement avec le bouton **Propager**. Cela inclut effectivement toutes les colonnes de toutes les tables, les colonnes de jointure n'étant incluses qu'une seule fois. Notez que les colonnes sont triées par ordre alphabétique, d'abord par *Manufacturer*, puis par *ModelName*.



Comme prévu, la sortie finale n'inclut que les valeurs qui avaient une correspondance dans les deux tables. Ainsi, *Porsche* n'apparaît pas, car elle n'avait aucun modèle. De même, la 


*Batmobile* n'avait aucun constructeur (c'était une réalisation sur mesure) ; elle n'est donc pas incluse.
