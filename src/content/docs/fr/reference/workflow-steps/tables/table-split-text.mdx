## Description

L'étape **Table : fractionner le texte** (Table Split Text) fractionne le texte d'une colonne selon un séparateur et écrit les morceaux sous forme de nouvelles colonnes ou de nouvelles lignes. Le nombre de colonnes est déterminé à l'exécution de l'étape, d'après la valeur qui compte le plus de morceaux. Vous n'avez donc pas besoin de le connaître à l'avance.

## Source et options

- **Table source** et **Table de sortie** — la table à lire et la table à écrire.
- **Colonne à fractionner** — la colonne à fractionner. Un nombre est fractionné comme son texte.
- **Séparateur** — le texte littéral placé entre les morceaux. Il peut avoir n'importe quelle longueur et n'est pas un motif. Les espaces sont conservés tels que vous les saisissez.
- **Fractionner en** — **Colonnes** ou **Lignes**.
  - **Colonnes** écrit `<column>_1`, `<column>_2`, et ainsi de suite, autant que la valeur qui compte le plus de morceaux. Une valeur qui compte moins de morceaux reçoit NULL dans les colonnes restantes.
  - **Lignes** écrit une ligne par morceau, le morceau remplaçant la colonne. Les morceaux vides restent des lignes.
- **Supprimer les espaces autour de chaque morceau** — activé par défaut.
- **Conserver la colonne d'origine** — activé par défaut. En mode colonnes, elle conserve la colonne fractionnée. En mode lignes, elle écrit aussi la valeur non fractionnée dans `<column>_original`.

Un résultat vide remplace la table de sortie. L'étape ne laisse jamais de lignes d'une exécution antérieure.

### Paramètres supplémentaires pour les colonnes

**Autres options de coupure** propose aussi ces paramètres lors d'un fractionnement en colonnes :

- **Préfixe du nom des morceaux** (`prefix`) — nomme les morceaux `<prefix><n>` au lieu de `<column>_<n>`. **Numéro du premier élément** (`start`, 1 par défaut) est le numéro du premier morceau.
- **Noms des colonnes de morceaux** (`names`) — les noms des colonnes de morceaux, dans l'ordre. Exactement ce nombre de colonnes est écrit, sauf si vous activez **Écrire uniquement autant de colonnes nommées que la plus longue valeur en a** (`fit`) : dans ce cas, seulement autant que la valeur qui compte le plus de morceaux.
- **Type des morceaux** (`dtype`) — le type des morceaux : `text` (par défaut), `integer`, `bigint`, `double`, `boolean`, `date` ou `timestamp`. Un morceau qui ne se lit pas comme ce type vaut NULL.
- **Caractères à retirer** (`strip`) — les caractères retirés aux deux extrémités de chaque morceau, à la place des espaces que supprime **Supprimer les espaces autour de chaque morceau**.
- **La colonne contient une collection KNIME** (`collection`) — la colonne contient une valeur de liste issue d'un workflow KNIME converti. Ses éléments sont les morceaux et le séparateur n'est pas utilisé : un élément manquant vaut NULL, et une liste vide n'a aucun morceau.

**Nœud KNIME** (`knime_config`) exécute avec cette étape l'un des nœuds KNIME Line Chopper, Expand Vector ou Sample and Expand Vector : `chopper` écrit les premiers jetons séparés par des espaces d'une colonne, `expand_vector` écrit les éléments d'une colonne de vecteurs sous forme de colonnes, les positions à conserver étant listées dans la table **Table des positions d'éléments** (`source_b`), et `sample_expand_vector` développe un échantillon aléatoire des éléments, en écrivant les noms des colonnes échantillonnées dans la table indiquée dans **Table des noms de colonnes échantillonnées** (`targets`).
