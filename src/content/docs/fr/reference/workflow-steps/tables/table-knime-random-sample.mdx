## Description

L'étape **Table : KNIME Random Sample** effectue le tirage aléatoire d'un nœud KNIME avec le générateur de nombres aléatoires que KNIME utilise ; un nœud doté d'une graine tire donc les mêmes lignes ou valeurs dans PlaidCloud que dans KNIME. Les [workflows KNIME migrés](/fr/guides/workflows/migrate-knime-workflows/) utilisent cette étape pour Row Sampler, Table Partitioner, Equal Size Sampling, Bootstrap Sampling, Shuffle, X-Partitioner et les nœuds de génération aléatoire de données.

Le tirage lit la table source dans le workflow : la table ne peut donc pas dépasser 10 000 000 de lignes ; une table plus grande fait échouer l'étape.

Le formulaire de l'étape comprend une section **Tables** pour les tables source et de sortie, une section **Tirage** pour la **Méthode**, la **Graine** et la taille de l'échantillon, et une section **Colonnes** pour les colonnes lues et écrites.

## Configuration

- `source` et `target_frame` : la table à lire et la table à écrire.
- `position_column` : la colonne contenant la position (à partir de 0) de chaque ligne. La valeur par défaut est `_knime_pos`.
- `method` : le tirage :
  - `random`, `stratified`, `equal_exact` et `equal_approximate` conservent les positions des lignes qu'un tirage Row Sampler, Table Partitioner ou Equal Size Sampling sélectionne. `class_column` et `class_dtype` désignent la colonne de classe d'un tirage stratifié ou de taille égale.
  - Toutes les autres méthodes écrivent leur tirage à côté des positions de lignes : `uniform`, `gaussian`, `gamma`, `beta`, `label`, `label_dependent`, `label_from_table`, `boolean`, `mersenne_twister`, `sobol` et `halton` (génération aléatoire de données), `shuffle`, `bootstrap`, `match` (Random Matcher), `item_insert` (Random Item Inserter), `stress` (Stresser), `sample_data` (Sample Data Generator, sans table source), `kfold` (plis du X-Partitioner), `p_square` (estimations de percentiles P² par groupe), `set_bits` (vecteurs de bits), `equal_count_edges` (bornes à effectifs égaux du Binner) et `border_texts` (textes de bornes de l'Auto-Binner).
- `seed` : la graine du flux aléatoire. Vide, elle est tirée de l'horloge, comme le fait KNIME sans graine ; les lignes diffèrent donc d'une exécution à l'autre.
- `count`, `percentage` et `relative` : le nombre de lignes à tirer, soit un nombre, soit, avec `relative`, un pourcentage. `count_column` prend plutôt le nombre dans une colonne source, pour un nombre connu seulement à l'exécution du workflow.
- `parameters` : les paramètres du nœud que lisent les méthodes de tirage, comme la distribution d'un tirage `gaussian` ou le nombre de plis d'un tirage `kfold`.
- `source_columns` et `target_columns` : pour les méthodes de tirage, les colonnes lues et les colonnes écrites, la colonne de position en premier.
- `source_b` et `source_columns_b` : une seconde entrée, comme la table de catégories de `label_from_table` ou la table dans laquelle `match` tire. `target_frame_b` et `target_columns_b` reçoivent les centres de clusters de `sample_data`.
