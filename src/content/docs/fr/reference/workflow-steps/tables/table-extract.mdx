## Description


Sert à extraire des données d'une table de données Analyze existante vers une autre table de données. Voici quelques exemples, sans s'y limiter :


* Tri
* Regroupement
* Synthèse
* Filtrage/sous-ensemble de lignes
* Suppression des colonnes superflues
* Opérations mathématiques
* Opérations sur les chaînes

<Aside>Cette transformation n'a aucune fonction exclusive. Tout tri, regroupement, filtrage, etc. peut être effectué dans n'importe quelle autre transformation avec les onglets **Colonnes** et **Filtres**.</Aside>

## Colonnes nommées à l'exécution

Sélectionnez **Reporter aussi les colonnes nommées à l'exécution** pour transmettre, sans modification, chaque colonne source que l'étape ne liste pas, telle que la table les contient lorsque l'étape s'exécute. Utilisez cette option lorsqu'une étape antérieure crée des colonnes dont les noms dépendent des données, comme un pivot, de sorte que vous ne pouvez pas les lister lorsque vous construisez l'étape. Laissez-la désactivée pour n'écrire que les colonnes que vous listez.

Lorsqu'elle est activée, une section **Colonnes reportées** apparaît, et une section **Colonnes nommées par les données** est toujours disponible. Elles comportent les champs suivants :

* **Reporter comme** (`carry_expression`) : écrit chaque colonne reportée sous la forme de cette expression plutôt que sans modification, `__column__` représentant la colonne reportée. C'est ainsi qu'une étape qui regroupe intègre des colonnes que seule l'exécution nomme ; une étape qui agrège ne reporte rien sans cela. **Type des colonnes reportées** (`carry_dtype`) définit le type de données de chaque colonne reportée (par défaut le sien), et **Agrégation des colonnes reportées** (`carry_agg`) définit comment une étape d'agrégation la traite (`dont_group` lorsque l'expression agrège).
* **Renommer les colonnes reportées** (`carry_rename`) : renomme chaque colonne reportée dont le nom correspond à l'expression régulière `pattern` et ne correspond pas à `keep`, en plaçant `replacement` à la place de chaque correspondance (`\1` pour un groupe ; les `max` premières correspondances, lorsqu'il est défini). `__index__` dans `replacement` est la position de la colonne parmi les colonnes renommées, comptée à partir de `start`. Un nom déjà pris reçoit ` (#n)` en suffixe.
* **Colonnes dynamiques** (`dynamic_columns`) : des colonnes cibles nommées par les données, un jeu pour chaque valeur distincte que l'étape lit dans sa source, écrites lorsque l'étape s'exécute. Chaque entrée fournit `rows` (des expressions `key`, `label`, `where` et `order` sur la source), une colonne `target` ou une liste de colonnes qui utilise `__key__`, `__label__` et `__index__`, et `after`, la colonne cible que les nouvelles suivent (par défaut la fin). Les valeurs doivent être du texte, des entiers, des booléens ou NULL, l'étape écrit au plus 1 000 colonnes, et la sortie doit être une table.
