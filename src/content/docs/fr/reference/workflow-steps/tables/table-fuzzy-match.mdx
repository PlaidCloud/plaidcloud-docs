## Description

L'étape **Fuzzy Match** associe les lignes de deux tables (ou dédoublonne une table) selon des correspondances approximatives de champs. Elle s'exécute dans le moteur de workflow ; les résultats des macros empaquetées sont une approximation de la macro Alteryx.

## Paramètres

- **Left / Right Tables** et la **Table de sortie**.
- **Colonne d'identifiant d'enregistrement**, **Seuil** (0-100) et **Émettre aussi les lignes sans correspondance**.
- **Champs de correspondance** : les champs à comparer et la fonction de correspondance de chacun (exact / jaro / levenshtein / bestof / jaro_tfidf / bestof_tfidf).
