Étapes de workflow qui lisent les données Salesforce via votre [connexion Salesforce](/fr/guides/connections/salesforce/). La liste des objets, la liste des champs et le type de chaque colonne proviennent des métadonnées de l'organisation elle-même : il n'y a donc aucune requête à rédiger et aucun type à deviner.

## Étapes

- [Salesforce : interroger un objet](/fr/reference/workflow-steps/salesforce/query-salesforce-object/) : extrait un objet standard ou personnalisé dans une table de projet via Bulk API 2.0, avec un filtrage appliqué dans Salesforce.
