## Description

Importe une liste de données de base NetSuite, via votre [connexion NetSuite](/fr/guides/connections/netsuite/), dans une table de projet. Choisissez un type d'enregistrement (comptes, filiales, départements, classes, emplacements, fournisseurs ou clients) ; l'étape récupère la liste et l'écrit, sans SuiteQL à rédiger ni à maintenir.

Les données de base sont les données de référence vers lesquelles pointent les extractions de soldes et de détail : les comptes, les filiales et les dimensions que vos lignes de grand livre portent sous forme d'ID internes. Importez la liste dont vous avez besoin pour résoudre ces ID internes en noms, ou pour alimenter des recherches et des jointures en aval. Cette étape fait partie des [étapes d'importation NetSuite](/fr/reference/workflow-steps/netsuite/) prédéfinies, qui s'appuient sur une couche de lecture partagée qui actualise le jeton OAuth, parcourt les résultats volumineux page par page et relance automatiquement les erreurs transitoires.

## Configuration

| Champ | Obligatoire | Remarques |
|---|---|---|
| Connexion NetSuite | Oui | La connexion NetSuite à utiliser pour la lecture, filtrée sur les connexions de type NetSuite. |
| Table cible | Oui | La table de projet dans laquelle la liste est écrite. Elle est entièrement écrasée à chaque exécution. |
| Type d'enregistrement | Oui | La liste de données de base à extraire : **compte** (valeur par défaut), **filiale**, **département**, **classe**, **emplacement**, **fournisseur** ou **client**. |
| Inclure les inactifs | Non | Désactivé par défaut : seuls les enregistrements actifs sont renvoyés. Activez cette option pour inclure les enregistrements marqués comme inactifs dans NetSuite. |

<Aside type="note">
Utilisez cette étape pour construire les petites tables de référence dont se servent les autres étapes NetSuite. Par exemple, extrayez une fois les **filiales** pour associer l'ID interne d'une filiale à son nom avant de limiter une extraction [NetSuite : importer les soldes](/fr/reference/workflow-steps/netsuite/import-balances/) ou [NetSuite : importer le détail du grand livre](/fr/reference/workflow-steps/netsuite/import-gl-detail/) à une seule filiale.
</Aside>
