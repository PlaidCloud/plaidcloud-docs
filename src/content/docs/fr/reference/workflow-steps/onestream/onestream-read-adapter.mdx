## Description

Lit un adaptateur de données d'un espace de travail OneStream par votre [connexion OneStream](/fr/guides/connections/onestream-for-data-foundation/) et charge ses lignes dans une table. Elle effectue un appel à l'adaptateur pour chaque membre de consolidation que vous listez, et remplace la table cible par les lignes de tous ces appels. Utilisez-la pour faire entrer des résultats consolidés dans un projet, par exemple pour y rapprocher un modèle.

Cette étape apparaît dans le menu des étapes sous **OneStream**. Data Foundation l'utilise lorsque vous ajoutez OneStream comme source.

<Aside type="note">
L'adaptateur et ses colonnes sont construits par votre administrateur OneStream. Voir [Ce que configure votre administrateur OneStream](/fr/guides/connections/onestream-for-data-foundation/#ce-que-configure-votre-administrateur-onestream).
</Aside>

## Configuration

### Source

| Champ | Obligatoire | Remarques |
|---|---|---|
| Connexion OneStream | Oui | La [connexion OneStream](/fr/guides/connections/onestream-for-data-foundation/) par laquelle lire. |
| Environnement | Non | L'environnement de la connexion. `default` par défaut. |
| Application | Non | Laissez vide pour utiliser l'application enregistrée sur la connexion. Une étape doit avoir l'une ou l'autre. |
| Espace de travail | Non | Laissez vide pour utiliser l'espace de travail enregistré sur la connexion. |
| Adaptateur | Oui | L'adaptateur de données à lire. `Foundation_Results` est l'adaptateur décrit sur la page de la connexion. |
| Table de l'adaptateur | Non | Le nom de la table dans le jeu de données de l'adaptateur. |
| Exécuter d'abord la séquence | Non | Une séquence Data Management à exécuter avant la lecture, pour actualiser ce que lit l'adaptateur. |

### Tranche de données

| Champ | Remarques |
|---|---|
| Membres | Un membre de consolidation par ligne. L'étape appelle l'adaptateur une fois pour chacun, avec le membre dans la variable de substitution `Member`. Vide, elle effectue un seul appel sur le membre par défaut de l'adaptateur. |
| Variables de substitution | Un `Name=Value` par ligne, par exemple `Time=2026M1`. |
| Vue | **Cumul depuis le début de l'exercice** (par défaut) ou **Périodique**. Transmise à l'adaptateur dans la variable de substitution `View`. |
| Signe | **Tel que stocké** (par défaut) ou **Inverser le signe**, qui inverse chaque montant. |
| Échelle des montants | Un multiplicateur appliqué à chaque montant. 1 par défaut. Utilisez 1000 lorsque OneStream sert des valeurs en milliers. |

Les variables de l'application, de l'espace de travail, de la table, de la séquence, des membres et des valeurs de substitution sont renseignées pendant l'exécution du workflow.

### Cible

| Champ | Obligatoire | Remarques |
|---|---|---|
| Table cible | Oui | La table dans laquelle les lignes sont chargées. Elle est remplacée à chaque exécution et doit être une table, pas une vue. |

## Sortie

La table cible reprend les colonnes de l'adaptateur : `entity`, `account`, `time`, `scenario`, `view`, `amount`, `currency`, `flow`, `ud1`, `ud2`, `ud3` et `ud4`. Toutes les colonnes sont chargées en texte, sauf `amount`, qui est numérique après application de l'échelle et du signe.

Si l'adaptateur ne renvoie aucune ligne, la table cible est remplacée par une table vide et l'étape se termine par un avertissement qui nomme l'adaptateur, et non par une erreur.
