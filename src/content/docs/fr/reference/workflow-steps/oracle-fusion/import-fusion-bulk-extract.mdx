## Description

Importe une entité Oracle Fusion Cloud via votre [connexion Oracle Fusion](/fr/guides/connections/oracle-fusion/), en passant par le chemin d'extraction en masse FBDI/BI Publisher d'Oracle : PlaidCloud soumet un job d'export, le sonde jusqu'à son achèvement, télécharge le fichier obtenu et l'écrit dans une table de projet. Utilisez cette étape plutôt que [Import Fusion Entity](/fr/reference/workflow-steps/oracle-fusion/import-fusion-entity/) pour une extraction trop volumineuse ou trop lente pour un appel direct OData/BIP.

## Configuration

| Champ | Obligatoire | Remarques |
|---|---|---|
| Connexion Fusion | Oui | La connexion Oracle Fusion à utiliser pour la lecture. |
| Table cible | Oui | La table de projet dans laquelle les résultats sont écrits. Elle est entièrement écrasée à chaque exécution. |
| Type d'entité | Oui | L'entité à extraire. Valeur par défaut : `gl_balances`. Au choix : `gl_balances`, `journal_batches`. |
| Filtres | Non | Même ensemble de filtres que [Import Fusion Entity](/fr/reference/workflow-steps/oracle-fusion/import-fusion-entity/) : filtres de plage (`ge`/`le`) sur les champs de date, de période comptable et de solde/montant numérique, ainsi que filtres d'égalité sur les champs discrets. Appliqués au niveau du job d'extraction. |

<Aside type="caution">
Cette étape attend un job d'export asynchrone : prévoyez une durée sensiblement plus longue que [Import Fusion Entity](/fr/reference/workflow-steps/oracle-fusion/import-fusion-entity/) pour le même nombre de lignes. Ne l'utilisez que lorsque l'extraction est réellement trop volumineuse pour un appel direct OData/BIP.
</Aside>
