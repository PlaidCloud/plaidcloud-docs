## Description

Importe une entité Oracle Fusion Cloud dans une table de projet, via votre [connexion Oracle Fusion](/fr/guides/connections/oracle-fusion/), en appelant directement les points de terminaison OData ou BI Publisher (BIP) de Fusion. Choisissez la connexion, le type d'entité et les filtres éventuels. L'étape récupère les enregistrements correspondants et les écrit, sans requête OData à rédiger.

Pour une extraction trop volumineuse pour un appel direct, utilisez plutôt l'étape [Import Fusion Bulk Extract](/fr/reference/workflow-steps/oracle-fusion/import-fusion-bulk-extract/).

## Configuration

| Champ | Obligatoire | Remarques |
|---|---|---|
| Connexion Fusion | Oui | Connexion Oracle Fusion à utiliser pour la lecture. |
| Table cible | Oui | Table de projet dans laquelle les résultats sont écrits. Elle est entièrement écrasée à chaque exécution. |
| Type d'entité | Oui | Entité à importer. Valeur par défaut : `gl_balances`. Valeurs possibles : `gl_balances`, `journal_batches`. |
| Filtres | Non | Filtres de plage (`ge`/`le`) sur les champs de date, de période comptable et de solde ou montant numérique, ainsi que filtres d'égalité sur les champs discrets (grand livre, devise). Chaque entité limite les filtres aux champs qu'Oracle Fusion peut réellement évaluer côté serveur : un champ non pris en charge est rejeté, et non ignoré silencieusement. |

### Entités et champs filtrables

| Type d'entité | Données importées | Champs filtrables |
|---|---|---|
| `gl_balances` | Soldes des comptes du grand livre | plage de périodes comptables (`ge`/`le`), plage de comptes, plage de montants de solde (`ge`/`le`) |
| `journal_batches` | En-têtes et statut des lots d'écritures | plage de dates (`ge`/`le`), plage de périodes comptables (`ge`/`le`) |

<Aside type="note">
Une seule borne suffit pour qu'un filtre de plage soit utile : `accounting_date ge 2026-01-01` sans borne supérieure importe tout ce qui date de ce jour ou d'une date ultérieure. Indiquez les deux bornes pour délimiter précisément l'extraction.
</Aside>
