## Description

L'étape **Tableau Hyper Export** exporte une table vers un fichier Tableau Hyper. Elle s'exécute dans le moteur de workflow ; les résultats de macros empaquetées sont une approximation de la macro Alteryx.

## Paramètres

- **Table source** et chemin du **Fichier de sortie**.

Lorsque la table source n'existe pas, ou n'a aucune colonne lorsqu'aucune n'est mappée, l'étape réussit, n'écrit rien et consigne un avertissement qui nomme la source et le fichier de sortie. Une source sans ligne écrit une extraction vide et consigne un avertissement qui l'indique.
