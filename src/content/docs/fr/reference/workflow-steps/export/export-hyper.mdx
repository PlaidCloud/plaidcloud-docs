## Description

L'étape **Tableau Hyper Export** exporte une table vers un fichier Tableau Hyper. Elle s'exécute dans le moteur de workflow ; les résultats de macros empaquetées sont une approximation de la macro Alteryx.

## Paramètres

- **Table source** et chemin du **Fichier de sortie**.

Le programme d'écriture Tableau Hyper n'est pas disponible dans le moteur de workflow ; un CSV est donc écrit à la place (une dégradation fonctionnelle).
