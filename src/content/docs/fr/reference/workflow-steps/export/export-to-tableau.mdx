## Description

L'étape **Publish to Tableau** publie un extrait `.hyper` sur Tableau Server ou Tableau Cloud comme source de données. Écrivez d'abord l'extrait avec [Tableau Hyper Export](/fr/reference/workflow-steps/export/export-hyper/), puis publiez-le avec cette étape. L'étape se connecte avec le jeton d'accès personnel d'une [connexion Tableau](/fr/reference/connectors/collaboration/tableau/), téléverse le fichier par blocs, de sorte que la taille du fichier n'est pas limitée par une seule requête, puis se déconnecte.

Un fichier d'extrait manquant n'est pas une erreur. L'étape avertit que rien n'a été publié et le workflow se poursuit.

## Paramètres

- **Extrait Hyper** — le fichier `.hyper` d'un compte de documents à publier.
- **Connexion Tableau** — la connexion Tableau à utiliser pour la publication.
- **Nom de la source de données** — le nom de la source de données dans Tableau. Laissez vide pour utiliser le nom de fichier de l'extrait sans son extension.
- **Projet** — le projet Tableau dans lequel publier. Laissez vide pour utiliser le projet Default du site. Un nom de projet que Tableau ne connaît pas sur le site fait échouer l'étape.
- **Si la source de données existe** — le mode de publication. Consultez [Modes](#modes).
- **Clés de correspondance** — les colonnes qui servent à faire correspondre les lignes, sous forme de liste séparée par des virgules. Obligatoire pour **Upsert**, **Mettre à jour** et **Replace Matching Rows**.

## Modes

| Mode | Si la source de données existe | Si elle n'existe pas |
| --- | --- | --- |
| **CreateNew** | L'étape échoue. | La crée. |
| **Overwrite** | La remplace. | La crée. |
| **Ajouter à la fin** | Y ajoute les lignes de l'extrait. | La crée. |
| **Upsert** | Met à jour les lignes dont les clés de correspondance concordent et ajoute les autres. | La crée. |
| **Mettre à jour** | Met à jour les lignes dont les clés de correspondance concordent et n'en ajoute aucune. | Avertit et ne modifie rien. |
| **GroupReplace** | Supprime les lignes dont les clés de correspondance concordent, puis insère les lignes de l'extrait. | La crée. |

**Ajouter à la fin**, **Upsert**, **Mettre à jour** et **GroupReplace** recherchent la source de données par son nom dans le projet que vous avez choisi, ou dans le projet Default du site si vous n'en avez choisi aucun, et publient dans le projet où ils ont cherché. Les modes à clés modifient les lignes de la source de données sur place, au moyen des actions de mise à jour de données de Tableau.

## Prérequis

- L'adresse du serveur de la connexion doit utiliser `https`. Un serveur indiqué avec `http` fait échouer l'étape, car le jeton d'accès personnel circulerait en clair sur le réseau. Un nom d'hôte seul est interprété comme `https`.
- Le serveur doit être accessible depuis Internet. PlaidCloud ne publie pas vers un serveur Tableau situé sur un réseau privé.
- Le propriétaire du jeton d'accès personnel doit disposer de l'autorisation de publier dans le projet.
