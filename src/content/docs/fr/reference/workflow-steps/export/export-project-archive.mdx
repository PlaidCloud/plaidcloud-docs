## Description

Écrit une archive complète du projet (workflows, définitions de tables, dimensions, variables et paramètres) dans un compte de documents sous forme d'un seul fichier. Utilisez-la pour une sauvegarde à un instant donné avant une modification importante, ou pour transmettre un projet à un autre espace de travail.

Elle archive le *projet*, pas seulement ses données. Pour les seules données de table, utilisez l'étape [Export to Table Archive](/fr/reference/workflow-steps/export/export-to-table-archive/).

## Éléments de configuration spécifiques

### Répertoire et nom de fichier d'exportation

- **Répertoire d'exportation** — le compte de documents et le dossier dans lesquels l'archive est écrite.
- **Fichier cible** — le nom de fichier de l'archive.
