## Description


Exporte une table de données Analyze vers Google Drive sous la forme d'une feuille de calcul Google. Un compte Google valide est requis pour utiliser cette transformation. Les identifiants de l'utilisateur doivent être configurés dans PlaidCloud Tools avant d'utiliser la transformation.



## Paramètres d'exportation


### Source et cible


Sélectionnez la **Table source** dans PlaidCloud Document à l'aide de la liste déroulante.



Indiquez ensuite les informations de **Connexion cible**. Pour savoir comment configurer une connexion à un compte Google Docs, consultez : [PlaidCloud Tools – Connexion](/fr/reference/connectors/). Une fois tous les comptes nécessaires configurés, sélectionnez le compte approprié dans la liste déroulante.



Enfin, renseignez le **Nom de la feuille de calcul cible** et le **Nom de la feuille cible**. Si vous le souhaitez, cochez la case **Ajouter les données aux données existantes de la feuille** pour ajouter les données à une feuille existante. Si la feuille cible n'existe pas encore, elle est créée.



Une feuille de calcul qui n'existe pas encore est créée, tout comme une feuille manquante. Un **Nom de la feuille de calcul cible** que porte plus d'une feuille de calcul du compte est refusé ; renommez les doublons pour que le nom soit unique. Les valeurs sont écrites telles qu'elles ont été saisies : une cellule de texte qui commence par `=` reste du texte et ne devient pas une formule. Lorsque **Ajouter les données aux données existantes de la feuille** est décochée, la feuille est vidée et redimensionnée à la taille de la table avant l'écriture des lignes.
