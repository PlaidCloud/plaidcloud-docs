## Description

Écrit des tables de projet dans une base de données externe via une [connexion](/fr/reference/connectors/), plutôt que dans un fichier. Utilisez-la pour renvoyer des résultats modélisés vers une base de données de reporting, un entrepôt de données ou un système opérationnel.

C'est le pendant de [Importer les tables de base de données externe](/fr/reference/workflow-steps/import/import-external-database-tables/) : plusieurs tables sont déplacées en une seule étape, et les tables cibles peuvent être sélectionnées explicitement ou trouvées par un motif de recherche.

## Éléments de configuration spécifiques

### Connexion

La connexion de données qui identifie la base de données cible.

### Type d'exportation

La façon dont chaque table cible est préparée avant l'écriture des lignes :

- **Ajouter uniquement** — ajoute des lignes à la table existante ; échoue si elle n'existe pas.
- **Tronquer puis ajouter** — vide la table, conserve sa structure, puis écrit.
- **Créer puis ajouter** — crée la table si elle est absente, puis écrit.
- **Supprimer, créer, puis ajouter** — supprime et recrée la table, puis écrit. À utiliser lorsque le schéma source a changé.

### Nom du cadre

Le nom du cadre sous lequel l'étape s'exécute.

### Ajout de cibles

Utilisez le bouton d'ajout et de suppression de cible pour construire la liste des tables cibles. Sélectionnez une cible pour la configurer dans le volet de droite, et utilisez **Basculer la sélection** pour activer ou désactiver l'exportation des cibles sélectionnées. L'exportation n'analyse pas la base de données cible à la recherche de tables ; ajoutez chaque cible vous-même. [Importer les tables de base de données externe](/fr/reference/workflow-steps/import/import-external-database-tables/) est l'étape qui permet de découvrir les tables d'une base de données externe.

### Onglets de la cible

Une cible sélectionnée comporte trois onglets.

#### Source et cible

Choisissez les tables de projet à exporter et leur destination.

- **Source** — **Table spécifique** désigne une table de projet, avec une option **Dynamique** pour un nom qui change à l'exécution. **Tables correspondant à la recherche** exporte chaque table de projet trouvée par un **Chemin de recherche** et un **Texte de recherche**, mis en correspondance selon **Exact**, **Commence par**, **Contient** ou **Se termine par**.
- **Table externe cible** — **Activer pour l'exportation** active ou désactive la cible. **Schéma cible** et **Table cible** désignent la table de destination. **Utiliser le même nom que la table source** réutilise le nom de chaque table source.

#### Sélection des données de la table

Le mappeur de colonnes de la cible, dans son propre onglet pleine hauteur. **Inspecter la source** lit les colonnes de la table source du projet dans le mappeur.

#### Filtres de données

Filtrez les lignes écrites dans la cible.
