## Description



Écrit une table PlaidCloud dans un compte de documents sous la forme d'un fichier d'archive natif PlaidCloud. L'archive conserve tous les types de colonnes, les index et les métadonnées connus de PlaidCloud, avec une meilleure fidélité que CSV pour les allers-retours entre projets ou environnements PlaidCloud.

Associez-la à [Importer l'archive](/fr/reference/workflow-steps/import/import-archive/) pour réintégrer l'archive dans un projet. Utile pour les sauvegardes, les migrations de projet à projet et les transferts de données entre environnements.
