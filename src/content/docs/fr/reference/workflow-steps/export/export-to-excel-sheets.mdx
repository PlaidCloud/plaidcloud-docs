## Description

Écrit plusieurs tables de projet dans différentes feuilles d'un même classeur
Microsoft Excel, en préservant la mise en forme d'un modèle stylé. Chaque table
remplit une feuille nommée ; le classeur entier est initialisé une seule fois à
partir du modèle et généré en une seule passe, de sorte que les feuilles ne
s'écrasent plus les unes les autres, comme le feraient des exportations
distinctes d'une seule feuille partageant un même fichier de sortie.

Utilisez cette étape lorsqu'un classeur doit porter plus d'une feuille de
résultats, par exemple un modèle de reporting mis en forme avec une feuille de
données, une feuille de synthèse et une feuille de paramètres. Pour une seule
feuille, ou pour un classeur simple sans mise en forme, utilisez plutôt
l'[étape Export to Excel](/fr/reference/workflow-steps/export/export-to-excel/).

La mise en forme du modèle est reportée sur chaque feuille écrite : valeurs,
formats de nombre, polices, remplissages, bordures, cellules fusionnées et
largeurs de colonnes. Un modèle qui contient des tableaux croisés dynamiques ou
des graphiques perd ces objets lors de l'écriture de ses feuilles : l'écriture
ne les reproduit pas.

## Paramètres d'exportation

### Fichier de sortie

Le compte de documents et le dossier dans lesquels le classeur est écrit, avec
le **Nom du fichier** du classeur.

### Fichier modèle

Le modèle mis en forme à partir duquel le classeur est initialisé : un compte de
documents et un chemin vers un fichier `.xlsx` existant dont la mise en forme
est héritée par chaque feuille écrite. Lorsqu'aucun modèle n'est indiqué,
l'étape part du fichier de sortie existant s'il est déjà présent.

### Compression

Le classeur est écrit sans compression par défaut. La compression Zip, GZip ou
BZip2 est disponible.

## Feuilles

Chaque entrée de la table **Feuilles** remplit une feuille de calcul du classeur :

| Champ | Rôle |
| --- | --- |
| Source | La table de projet qui fournit les lignes de la feuille. |
| Feuille cible | La feuille du modèle à remplir. |
| Plage | Une plage facultative de style A1 (par exemple `A1:S1000000`) dont les valeurs existantes sont effacées avant l'écriture de la table, les cellules voisines du modèle restant intactes. |
| Écrire l'en-tête | Indique s'il faut écrire la ligne d'en-tête des noms de colonnes. Activé par défaut. |
| Colonnes | Les colonnes à écrire, dans l'ordre, lorsque vous ne voulez pas toutes les colonnes de la table source. |

Le formulaire comporte aussi ces champs :

* **Un classeur existant** (`if_exists`) — **Faire échouer l'étape sans rien écrire** (`fail`) arrête l'étape lorsque le classeur existe déjà. La valeur par défaut, **Y écrire les feuilles** (`replace`), l'écrit.
* Sur une entrée de feuille, **Trier les lignes par** (`sort_columns`) ordonne les lignes écrites selon ces colonnes source, la première clé en premier, chacune avec un paramètre **Colonne**, **Croissant** et **Valeurs nulles** ; **Cellules manquantes en** (`null_as`) est le texte écrit dans chaque cellule manquante de la feuille, colonnes numériques comprises ; et **Une feuille existante** (`if_sheet_exists`) détermine ce qui se passe lorsque le classeur contient déjà la feuille : **Faire échouer l'étape** (`fail`) arrête l'étape et **Le laisser tel quel** (`skip`) laisse cette feuille telle quelle.

## Limites de taille

Chaque feuille est soumise aux mêmes limites Excel qu'une exportation d'une
seule feuille : au plus 1 048 576 lignes (la ligne d'en-tête comptant) et
16 384 colonnes. Une feuille qui les dépasserait arrête l'étape plutôt que de
produire un fichier qu'Excel refuse d'ouvrir. Pour des données au-delà de ces
tailles, exportez plutôt en CSV ou en Parquet.
