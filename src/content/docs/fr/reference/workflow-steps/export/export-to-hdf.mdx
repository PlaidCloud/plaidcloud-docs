## Description


Exporte une table de données Analyze vers PlaidCloud Document sous la forme d'un fichier HDF5.


Pour en savoir plus sur les fichiers HDF5, consultez le site officiel du HDF Group : http://www.hdfgroup.org/HDF5/.



## Paramètres d'exportation


<SnippetCommonExportFileSelection />



### Type de fichier de sortie


Tous les fichiers exportés sont non compressés, mais les options de compression suivantes sont disponibles :


* Zip
* GZip
* BZip2
