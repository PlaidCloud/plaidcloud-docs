## Description

Écrit les tables de projet que vous sélectionnez dans un compte de documents sous forme de Parquet compressé. Associée à [Restaurer les tables](/fr/reference/workflow-steps/import/restore-tables/), elle déplace des données de table entre des projets ou des espaces de travail, ou met de côté une copie saine avant une modification destructrice.

## Éléments de configuration spécifiques

### Tables

Les tables de projet à archiver.

### Cible

Le compte de documents et le chemin dans lesquels l'archive est écrite.

### Compression

- **Snappy** — le plus rapide, taille d'archive modérée
- **Zstandard** — archives plus petites, nécessite un lecteur compatible Zstandard 0.8 ou ultérieur
