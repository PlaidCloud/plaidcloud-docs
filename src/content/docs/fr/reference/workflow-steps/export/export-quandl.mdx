## Description



Envoie une table PlaidCloud vers une base de données Quandl (NASDAQ Data Link). Principalement destinée aux organisations qui maintiennent des jeux de données publiés sur Quandl et souhaitent les actualiser depuis un workflow PlaidCloud.

Nécessite des identifiants d'API Quandl et une base de données cible configurée avec un accès en écriture côté Quandl.


## Source et cible


Indiquez les paramètres suivants :


* **Table source** : table de données Analyze à exporter
* **Connexion Quandl** : l'accès aux jeux de données Quandl nécessite un compte utilisateur ou un compte invité à accès limité. Cela doit être configuré dans Outils. Pour plus de détails sur la configuration d'une connexion à un compte Quandl, voir ici : [PlaidCloud Tools – Connexion](/fr/reference/connectors/)
* **Code Quandl** : utilisez le bouton **Rechercher** pour rechercher des jeux de données. Les jeux de données peuvent aussi être saisis manuellement. Pour cela, saisissez la partie de l'URL qui suit « [http://www.quandl.com](http://www.quandl.com/) ». Par exemple, pour importer le jeu de données de l'action Microsoft, disponible ici (http://www.quandl.com/GOOG/NASDAQ_MSFT), saisissez *GOOG/NASDAQ_MSFT* dans le champ Code Quandl
* **Nom du jeu de données** : nom du jeu de données à exporter vers Quandl
* **Description du jeu de données** : description du jeu de données à exporter vers Quandl
