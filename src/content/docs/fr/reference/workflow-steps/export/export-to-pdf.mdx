## Description

L'étape **Export to PDF** écrit une table sous forme de document PDF dans un compte de documents. Elle lit elle-même les lignes, si bien qu'aucun worker d'exportation n'intervient entre les deux.

## Paramètres

- **Table source** — la table à exporter.
- **Dossier de sortie** — le compte de documents et le dossier dans lesquels le PDF est écrit.
- **Nom du fichier** — le nom du PDF. `.pdf` est ajouté lorsque le nom ne le contient pas.
- **Écrire les noms de colonnes comme ligne d'en-tête** — activé par défaut. L'en-tête est répété sur chaque page.
- **Sélection des données de la table** — choisissez et ordonnez les colonnes écrites. L'étape peut aussi écrire, à la place d'une liste, toutes les colonnes de la source au moment de l'exécution du workflow.

## Mise en page

- La page est au format lettre en portrait et passe en paysage lorsque la table compte plus de six colonnes.
- Les lignes sont écrites par blocs de 1 000, chaque bloc répétant l'en-tête.
- Une valeur nulle donne une cellule vide.
- Une cellule trop longue pour une page est tronquée par des points de suspension, et l'étape émet un avertissement indiquant les noms des colonnes tronquées.
- Le PDF utilise une police Unicode lorsque le moteur de workflow en dispose. Sans elle, le PDF est composé en Helvetica, qui n'affiche que les caractères Latin-1, et l'étape émet un avertissement.
