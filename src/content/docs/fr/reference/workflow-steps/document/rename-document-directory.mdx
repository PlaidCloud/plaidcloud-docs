## Description


Renomme un répertoire existant dans PlaidCloud Document.



## Dossier à renommer


Sélectionnez d'abord le compte approprié dans le menu déroulant.



Appuyez ensuite sur le bouton **Parcourir** pour sélectionner le répertoire à renommer.



## Renommer en


Saisissez le nouveau nom du répertoire.


<Aside>Si le répertoire renommé existe déjà, aucune action n'est effectuée.</Aside>
