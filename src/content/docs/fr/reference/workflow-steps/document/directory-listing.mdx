## Description

Écrit une table listant les fichiers d'un répertoire de documents. Utilisez-la pour piloter des étapes en aval à partir des fichiers présents, par exemple pour parcourir chaque fichier d'un dossier ou vérifier ce qu'un processus en amont a livré.

## Répertoire

Sélectionnez un compte de documents, puis appuyez sur le bouton **Parcourir** pour choisir le dossier à lister.

## Options

- **Modèle de fichier** *(facultatif)* — un motif glob tel que `*.csv` pour ne lister que les fichiers correspondants. Laissez vide pour tout lister.
- **Inclure les sous-répertoires** — si cette case est cochée, les fichiers des dossiers imbriqués sont également listés.
- **Table cible** — la table qui reçoit la liste.

## Paramètres supplémentaires

Les options **Quels fichiers** limitent la liste :

- **Lister aussi les dossiers, avec une colonne IsFolder** (`include_folders`) — liste aussi les dossiers, sous forme de lignes. Chaque ligne comporte alors une dernière colonne `IsFolder`, vraie pour un dossier.
- **Lister d'abord le répertoire lui-même** (`include_root_folder`) — avec `include_folders`, liste aussi le répertoire lui-même, en premier.
- **Modèle de nom de fichier** (`file_name_filter`) — uniquement les fichiers dont le nom correspond. Le **Type de modèle** est **Caractère générique** ou **Expression régulière** (`type`), et **Respecter la casse** définit `case_sensitive`.
- **Modèle de nom de dossier** (`folder_name_filter`) — uniquement les entrées situées dans des dossiers dont le nom correspond, sous la même forme ; chaque dossier traversé doit correspondre.
- **Extensions** (`extensions`) — uniquement les fichiers ayant l'une de ces extensions, sans le point. **Respecter la casse de l'extension** (`extensions_case_sensitive`) les fait correspondre en tenant compte de la casse.
- **Inclure les fichiers cachés (nom commençant par un point)** (`include_hidden_files`) et **Inclure les dossiers cachés et leur contenu** (`include_hidden_folders`) — décochez l'une ou l'autre pour exclure les fichiers ou dossiers dont le nom commence par un point.
