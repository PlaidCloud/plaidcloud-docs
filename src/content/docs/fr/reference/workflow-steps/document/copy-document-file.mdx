## Description


Copie un fichier unique dans PlaidCloud Document.



## Fichier à copier


Sélectionnez d'abord le compte approprié dans la liste déroulante.



Cliquez ensuite sur le bouton **Parcourir** pour sélectionner le fichier à copier.

Au lieu d'un seul fichier, vous pouvez choisir **Copier les fichiers correspondant à la recherche**, qui copie les fichiers dont le nom correspond à votre texte de recherche (**Exact**, **Commence par**, **Contient** ou **Se termine par**), ou **Copier tous les fichiers du répertoire**. Lorsque vous copiez un dossier entier :

* **Conserver les sous-dossiers** place chaque fichier sous son chemin à l'intérieur du dossier, de sorte que la copie conserve la structure du dossier. Sans cette option, chaque fichier est placé directement dans le dossier de destination, sous son nom.
* **Ignorer les sous-dossiers** copie uniquement les fichiers propres au dossier, aucun de ses sous-dossiers.

**Copier uniquement les fichiers dont le nom correspond (expression régulière) :** restreint l'un quelconque de ces choix aux fichiers dont le nom correspond, depuis son début, à une expression régulière, par exemple `sales_\d{4}\.csv`. La correspondance respecte la casse. Laissez ce champ vide pour copier tous les fichiers choisis. Un modèle qui n'est pas une expression régulière valide, ou qui répète une partie elle-même répétée, comme `(a+)+`, est refusé lorsque vous enregistrez l'étape.

Un fichier ou dossier source manquant ou vide termine l'étape avec un avertissement qui nomme le chemin, et rien n'est copié.



## Sélectionner la destination


Sélectionnez d'abord le compte approprié dans la liste déroulante.



Cliquez ensuite sur le bouton **Parcourir** pour sélectionner la destination du fichier copié.



Par défaut, Analyze n'autorise pas l'écrasement de fichiers. Un suffixe numérique est à la place ajouté à chaque copie suivante. 



Pour écraser le fichier existant, cochez simplement la case **Allow Overwriting Existing File**.



Pour renommer le fichier, cochez la case **Rename the copied file to** et saisissez un nouveau nom.

<Aside>Veillez à indiquer une extension de fichier lorsque vous changez le nom du fichier. Le fichier sera créé sans problème sans extension, mais les systèmes d'exploitation n'en connaîtront pas le type.</Aside>


## Paramètres supplémentaires

Sous **Si le fichier existe**, **Un fichier qui existe déjà** (`overwrite_policy`) définit ce qui se passe lorsqu'un fichier se trouve déjà à la destination : **Copier par-dessus** (`overwrite`, la valeur par défaut), **Copier par-dessus si la source est plus récente** (`overwrite_if_newer`), **Le laisser tel quel** (`skip`) ou **Faire échouer l'étape sans rien copier** (`fail`).

Avec **Copier tous les fichiers du répertoire**, les options **Quels fichiers** restreignent ce qui est copié :

* **Fichiers des sous-dossiers** (`include_subdirs`) : **Non** copie uniquement les fichiers propres au dossier et **Oui** copie tous les fichiers situés en dessous, en conservant leurs dossiers. Laissez-le non défini pour copier chaque fichier dans le dossier de destination sous son nom, comme l'indiquent **Conserver les sous-dossiers** et **Ignorer les sous-dossiers**.
* **Modèle de nom de fichier** (`file_name_filter`) : uniquement les fichiers dont le nom correspond. **Type de modèle** vaut **Caractère générique** ou **Expression régulière** (`type`), et **Respecter la casse** définit `case_sensitive`.
* **Modèle de nom de dossier** (`folder_name_filter`) : uniquement les fichiers situés dans des dossiers dont le nom correspond, sous la même forme ; chaque dossier traversé en descendant doit correspondre.
* **Extensions** (`extensions`) : uniquement les fichiers ayant l'une de ces extensions, sans le point. **Respecter la casse de l'extension** (`extensions_case_sensitive`) les fait correspondre en tenant compte de la casse.
* **Inclure les fichiers cachés (nom commençant par un point)** (`include_hidden_files`) et **Inclure les dossiers cachés et leur contenu** (`include_hidden_folders`) : décochez l'un ou l'autre pour exclure les fichiers ou dossiers dont le nom commence par un point.
