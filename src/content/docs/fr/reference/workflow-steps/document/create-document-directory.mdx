## Description


Crée un nouveau répertoire dans PlaidCloud Document.



## Emplacement de création du nouveau dossier


Sélectionnez d'abord le compte approprié dans la liste déroulante.



Cliquez ensuite sur le bouton **Parcourir** pour sélectionner le répertoire parent.



## Nom du nouveau dossier


Saisissez le nom du nouveau répertoire.


<Aside>Si le répertoire existe déjà, aucune action n'est effectuée.</Aside>
