## Description


Supprime un fichier existant dans PlaidCloud Document.



## Fichier à supprimer


Sélectionnez d'abord le compte approprié dans le menu déroulant.


Appuyez ensuite sur le bouton **Parcourir** pour sélectionner le fichier à supprimer.

<Aside>Si le fichier n'existe pas (déjà supprimé), aucune action n'est effectuée.</Aside>
