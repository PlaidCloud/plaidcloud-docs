## Description


Copie un répertoire entier dans PlaidCloud Document.



## Copier le répertoire


Sélectionnez d'abord le compte approprié dans la liste déroulante.



Cliquez ensuite sur le bouton **Parcourir** pour sélectionner le répertoire à copier.



## Sélectionner la destination


Sélectionnez d'abord le compte approprié dans la liste déroulante.



Cliquez ensuite sur le bouton **Parcourir** pour sélectionner la destination du répertoire copié. 



Si vous le souhaitez, le répertoire copié peut recevoir un nouveau nom. Pour cela, cochez simplement la case **Rename the Copied Folder to:** et saisissez un nouveau nom.


<Aside>Le comportement par défaut consiste à écraser tout ce qui existe déjà. Faites attention à ne pas écraser des éléments par mégarde.</Aside>
