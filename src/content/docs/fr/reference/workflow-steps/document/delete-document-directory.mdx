## Description


Supprime un répertoire existant dans PlaidCloud Document.



## Dossier à supprimer


Sélectionnez d'abord le compte approprié dans le menu déroulant.


Appuyez ensuite sur le bouton **Parcourir** pour sélectionner le répertoire à supprimer.


<Aside>Un dossier absent n'est jamais une erreur. L'étape ne fait rien et se termine par un avertissement indiquant le chemin lorsque le stockage signale que le dossier est introuvable.</Aside>


## Supprimer uniquement les fichiers

Pour vider un dossier tout en le conservant, cochez **Supprimer uniquement les fichiers qu'il contient, en conservant ses dossiers** (`files_only`). Les options **Quels fichiers** limitent alors ce qui est supprimé.

* **Supprimer uniquement les fichiers qu'il contient, en conservant ses dossiers** (`files_only`) — supprime les fichiers du dossier et laisse en place le dossier et ses sous-dossiers.
* **Aussi les fichiers de ses sous-dossiers** (`include_subdirs`) — avec `files_only`, supprime aussi les fichiers de chaque sous-dossier situé en dessous.
* **Modèle de nom de fichier** (`file_name_filter`) — uniquement les fichiers dont le nom correspond. Le **Type de modèle** est **Caractère générique** ou **Expression régulière** (`type`), et **Respecter la casse** définit `case_sensitive`.
* **Modèle de nom de dossier** (`folder_name_filter`) — uniquement les fichiers situés dans des dossiers dont le nom correspond, sous la même forme ; chaque dossier traversé doit correspondre.
* **Extensions** (`extensions`) — uniquement les fichiers ayant l'une de ces extensions, sans le point. **Respecter la casse de l'extension** (`extensions_case_sensitive`) les fait correspondre en tenant compte de la casse.
* **Inclure les fichiers cachés (nom commençant par un point)** (`include_hidden_files`) et **Inclure les dossiers cachés et leur contenu** (`include_hidden_folders`) — décochez l'une ou l'autre pour exclure les fichiers ou dossiers dont le nom commence par un point.

Lorsqu'aucun fichier n'est trouvé, y compris si le dossier est absent, l'étape ne fait rien et se termine par un avertissement indiquant le chemin.
