## Description


Renomme un fichier existant dans PlaidCloud Document.



## Fichier à renommer


Sélectionnez d'abord le compte approprié dans le menu déroulant.



Appuyez ensuite sur le bouton **Parcourir** pour sélectionner le fichier à renommer.

<Aside>Si le fichier renommé existe déjà, aucune action n'est effectuée.</Aside>


## Renommer en


Saisissez le nouveau nom du fichier.
