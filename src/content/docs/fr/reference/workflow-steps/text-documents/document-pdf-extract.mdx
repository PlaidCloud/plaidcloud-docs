## Description

L'étape **PDF Text Extract** extrait le texte de documents PDF. Elle est l'équivalent de l'outil Alteryx correspondant et s'exécute dans le moteur de workflow (les bibliothèques de ML, de NLP et de traitement de documents s'exécutent dans le job d'exécution).

## Source et options

- **Source / Tables de sortie** — les données d'entrée et l'endroit où le résultat est écrit.
- **Colonne de chemin PDF** (ou un **répertoire** de PDF).

## Colonnes

L'onglet **Colonnes** mappe les colonnes d'entrée transmises à la sortie.
