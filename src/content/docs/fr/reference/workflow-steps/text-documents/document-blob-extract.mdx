## Description

L'étape **Document : lire un blob** (Document Read Blob) lit des documents entiers dans une colonne de texte base64 nommée `Blob`, avec une ligne par document. Lisez un document que vous choisissez, ou un document pour chaque ligne d'une table de chemins. Les étapes suivantes, comme [Image OCR](/fr/reference/workflow-steps/text-documents/image-ocr/) et [Text NLP AI](/fr/reference/workflow-steps/text-documents/nlp-ai/), en lisent le contenu.

## Source et options

- **Table des chemins de documents** *(facultatif)* — renseignez ce champ pour lire un document par ligne. Laissez-le vide pour lire le seul document que vous choisissez.
- **Colonne de chemin** — la colonne de cette table qui contient le chemin de chaque document.
- **Document** — le compte de documents et le chemin à lire lorsqu'il n'y a pas de table.
- **Échouer si un document est manquant** — désactivé par défaut. Désactivé, un document manquant est ignoré avec un avertissement qui nomme son chemin, et un document unique manquant produit une table vide. Activé, l'étape échoue.
- **Taille max. du document (octets)** *(facultatif)* — un document plus volumineux fait échouer l'étape au lieu d'être découpé.
- **Table de sortie** — l'endroit où les lignes sont écrites.

Les colonnes de la table de chemins sont transmises à la sortie.

Le groupe **Autres options** définit ces clés :

- **Conserver la ligne d'un document manquant, avec un blob vide** (`keep_missing`) — conserve la ligne d'un document manquant, avec un `Blob` vide, au lieu de l'ignorer.
- **Lire le document comme une archive, une ligne par entrée** (`unpack_enabled`) — avec un seul document choisi et sans table de chemins, lit le document comme une archive (zip, jar, tar, tar.gz, tar.bz2, cpio, ar, ou un fichier `gz` ou `bz2` unique) et écrit une ligne par entrée : `Path` (sous le **Dossier des entrées**, `unpack_destination`), `Directory`, `Status` (`Extracted` ou `Folder`) et `Blob` (aucun pour un dossier). **Encodage des noms d'entrée** (`unpack_charset`, `cp437` par défaut) est l'encodage des noms d'entrée zip qui ne sont pas en UTF-8. Un document manquant ne produit aucune ligne.

Pour réécrire des blobs dans des documents, utilisez [Document : écrire un Blob](/fr/reference/workflow-steps/text-documents/document-blob-write/).
