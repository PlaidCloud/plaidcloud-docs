## Description

L'étape **Image OCR** extrait le texte d'images par OCR. Elle est l'équivalent de l'outil Alteryx correspondant et s'exécute dans le moteur de workflow (les bibliothèques de ML, de NLP et de traitement de documents s'exécutent dans le job d'exécution).

## Source et options

- **Source / Tables de sortie** — les données d'entrée et l'endroit où le résultat est écrit.
- **Colonne du chemin d'image**.

## Colonnes

L'onglet **Colonnes** mappe les colonnes d'entrée transmises à la sortie.
