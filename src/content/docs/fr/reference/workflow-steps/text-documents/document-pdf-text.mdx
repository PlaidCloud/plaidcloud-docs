## Description

Extrait le contenu textuel d'un PDF dans une table. Elle est l'équivalent de l'outil Alteryx *PDF to Text* et s'exécute dans le moteur de workflow, là où se trouvent les bibliothèques de traitement de documents.

Utilisez-la pour mettre le contenu des PDF sous une forme que le reste d'un workflow peut filtrer, analyser et joindre. Pour une extraction par page tenant compte de la mise en page, utilisez plutôt [PDF Text Extract](/fr/reference/workflow-steps/text-documents/document-pdf-extract/).

## Source et options

- **Table source** / **Table de sortie** — la table qui nomme les PDF et l'endroit où le texte extrait est écrit.
- **Colonnes** — les colonnes sources à transmettre à la sortie.
