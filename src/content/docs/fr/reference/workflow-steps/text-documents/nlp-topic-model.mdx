## Description

L'étape **Text Topic Model** découvre les sujets d'une colonne de texte. Elle est l'équivalent de l'outil Alteryx correspondant et s'exécute dans le moteur de workflow (les bibliothèques de ML, de NLP et de traitement de documents s'exécutent dans le job d'exécution).

## Source et options

- **Source / Tables de sortie** — les données d'entrée et l'endroit où le résultat est écrit.
- **Colonne de texte**, nombre de sujets et taille du vocabulaire.

## Colonnes

L'onglet **Colonnes** mappe les colonnes d'entrée transmises à la sortie.

## Nœuds de traitement de texte KNIME

Dans le groupe **Nœud de traitement de texte KNIME**, choisissez un **Nœud de texte KNIME** (`node`) pour exécuter avec cette étape l'un des nœuds Text Processing de KNIME, par exemple `preprocess`, `tagger`, `bag_of_words`, `frequency`, `document_vector`, `keywords`, `topics`, `language` ou les nœuds de plongement. Les paramètres propres au nœud, comme **Colonne de document** (`document_column`) et **Colonne de sortie** (`output_column`), apparaissent à côté de lui dans `knime_config`. Laissez le nœud sur **(aucun)** pour exécuter les paramètres propres de l'étape. Un workflow KNIME converti définit les mêmes clés.

Dans le groupe **Tables du nœud KNIME**, un nœud qui lit une deuxième table, comme un dictionnaire, une liste d'entités ou un vocabulaire, lit la **Deuxième table d'entrée** (`source_b`) avec les colonnes de **Colonnes de la deuxième table** (`source_b_columns`). Un nœud qui a d'autres sorties les écrit, dans l'ordre, dans les tables listées dans **Autres tables de sortie** (`targets`).
