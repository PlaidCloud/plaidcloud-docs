## Description

L'étape **Text Word Cloud** génère une image de nuage de mots à partir d'une colonne de texte. Elle est l'équivalent de l'outil Alteryx correspondant et s'exécute dans le moteur de workflow (les bibliothèques de ML, de NLP et de traitement de documents s'exécutent dans le job d'exécution).

## Source et options

- **Source / Tables de sortie** — les données d'entrée et l'endroit où le résultat est écrit.
- **Colonne de texte**, nombre maximal de mots, taille de l'image et couleur d'arrière-plan.

## Colonnes

L'onglet **Colonnes** mappe les colonnes d'entrée transmises à la sortie.
