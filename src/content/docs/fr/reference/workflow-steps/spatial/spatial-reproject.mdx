## Description

L'étape **Spatial : reprojeter** transforme la géométrie WKT de chaque ligne d'un système de coordonnées de référence à un autre et écrit le résultat dans une table de sortie, les autres colonnes étant reportées.

Le formulaire de l'étape comporte une section **Tables** pour les tables source et de sortie et leurs colonnes, et une section **Projection** pour la colonne de géométrie, les deux systèmes de coordonnées et la colonne de sortie. Les [workflows KNIME migrés](/fr/guides/workflows/migrate-knime-workflows/) utilisent cette étape pour leurs nœuds de projection.

## Configuration

- **Table source** (`source`) et **Table de sortie** (`target_frame`) — la table à lire et la table à écrire.
- **Colonne de géométrie** (`geometry_column`) — la colonne contenant chaque géométrie en WKT. La valeur par défaut est `SpatialObj`.
- **Système de coordonnées source** (`source_crs`) — le système de coordonnées de référence des géométries, par exemple `EPSG:4326`.
- **Système de coordonnées cible** (`target_crs`) — le système de coordonnées de référence vers lequel les projeter, par exemple `EPSG:3857`.
- **Colonne de géométrie projetée** (`output_column`) — la colonne qui reçoit la géométrie projetée. Laissez-la vide pour remplacer la colonne de géométrie elle-même.
- **Colonnes source** (`source_columns`) et **Colonnes de sortie** (`target_columns`) — les colonnes lues et les colonnes reportées, avec leurs types de données.

Une ligne sans géométrie conserve une géométrie projetée vide.
