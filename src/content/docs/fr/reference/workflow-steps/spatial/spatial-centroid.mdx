## Description

L'étape **Spatial : centroïde** ajoute le centre géométrique de chaque géométrie à chaque ligne d'entrée, sous forme de point WKT dans une colonne nommée `Centroid`. Toutes les colonnes d'entrée sont conservées.

## Source et options

- **Table source** et **Table de sortie** — la table à lire et la table à écrire.
- **Colonne de géométrie** — la colonne de géométrie WKT à mesurer.
