## Description

L'étape **Spatial Poly-Build** construit un polygone (ou une enveloppe convexe) par
groupe à partir de géométries de points. C'est l'équivalent de l'outil *Poly-Build*
d'Alteryx, et elle s'exécute dans le moteur de workflow.

## Source et options

- **Table source** / **Table de sortie** — les points d'entrée et la destination du résultat.
- **Géométrie de points** — la colonne de géométrie de points WKT à partir de laquelle construire.
- **Regrouper par** — une colonne facultative qui répartit les points en polygones de sortie
  distincts ; laissez vide pour construire un seul polygone à partir de tous les points.
- **Type de construction** — **Séquence** fusionne les points regroupés en un polygone ;
  **Enveloppe convexe** construit l'enveloppe convexe des points.
- **Colonne de sortie** — le nom de la colonne de géométrie en sortie.

## Colonnes

L'onglet **Colonnes** mappe les colonnes d'entrée à reporter sur la sortie.
