## Description

L'étape **Spatial File Import** lit un fichier spatial — MapInfo `.TAB`,
ESRI `.shp`, `.kml`, `.geojson` ou SRC `.geo` — et ses fichiers associés dans une
table, avec une ligne par entité et une colonne de géométrie WKT. C'est l'équivalent de
l'outil *Input Data* d'Alteryx pointé sur un fichier spatial, et elle s'exécute dans le moteur
de workflow (GDAL).

## Paramètres d'importation

- **Source** — le fichier spatial dans le magasin de documents. Ses fichiers associés
  (par exemple `.dat`/`.map`/`.id`/`.dbf` pour un `.TAB`, ou `.shx`/`.dbf`/`.prj` pour un shapefile)
  sont lus automatiquement depuis le même emplacement.
- **Table cible** — la table dans laquelle les entités sont écrites.

## Remarques

Le schéma de sortie est tiré du fichier ; il n'y a donc aucun mappage de colonnes. La
géométrie propriétaire d'un fichier SRC `.geo` ne peut pas être lue ; ses attributs `.dbf` sont
importés avec des valeurs de géométrie vides.
