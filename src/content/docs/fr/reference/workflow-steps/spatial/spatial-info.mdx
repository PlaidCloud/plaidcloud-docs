## Description

L'étape **Spatial Info** mesure chaque géométrie et ajoute les mesures sous forme de
colonnes. C'est l'équivalent de l'outil *Spatial Info* d'Alteryx, et elle s'exécute dans le
moteur de workflow.

Les mesures sont **géodésiques WGS84**, et non planaires. Cela compte : la forme SQL de
ces mesures est une valeur planaire en degrés² multipliée par une constante équatoriale, et
comme cette constante ne diminue pas avec la longitude lorsque la latitude augmente, elle
**surestime** la surface et la longueur — d'environ un quart aux latitudes des États-Unis.
Les calculer de façon géodésique donne un résultat unique, identique à celui d'Alteryx sur chaque
entrepôt.

## Source et options

- **Table source** / **Table de sortie** — les géométries d'entrée et la destination
  des lignes mesurées.
- **Colonne de géométrie** — la colonne de géométrie WKT à mesurer.
- **Mesures** — les mesures à ajouter. Chaque sélection ajoute les colonnes
  ci-dessous.
- **Rayon de la sphère (km)** *(facultatif)* — mesure sur une sphère de ce rayon.
  Laissez vide pour mesurer sur l'ellipsoïde WGS84.

## Colonnes de sortie

| Mesure | Colonnes ajoutées | Type |
|---|---|---|
| Surface (miles) | `AreaSqMi` | nombre |
| Surface (km) | `AreaSqKm` | nombre |
| Longueur (miles) | `LengthMi` | nombre |
| Longueur (km) | `LengthKm` | nombre |
| Coordonnées du centroïde | `CentroidX`, `CentroidY` | nombre |
| Coordonnées du rectangle englobant | `BR_Left`, `BR_Top`, `BR_Right`, `BR_Bottom` | nombre |
| Objet centroïde | `Centroid` | géométrie WKT |
| Objet rectangle englobant | `BoundingRect` | géométrie WKT |
| Polygone du rectangle englobant | `BoundingRectPolygon` | géométrie WKT |
| Est valide | `IsValid` | booléen |
| Type d'objet | `SpatialObjType` | texte |
| Nombre de parties | `NumParts` | nombre |
| Nombre de points | `NumPoints` | nombre |
| Coordonnées du point d'extrémité | `EndPointX`, `EndPointY` | nombre |
| Objet point d'extrémité | `EndPoint` | géométrie WKT |

`IsValid` indique si la géométrie fournie est une forme valide, avant toute réparation.

L'objet rectangle englobant et le polygone du rectangle englobant sont sérialisés en WKT
sous la même boucle de cinq sommets ; les deux colonnes portent donc la même valeur.

## Remarques

Le type d'objet, le nombre de parties, le nombre de points et les points d'extrémité sont ajoutés sous des
noms de colonnes provisoires — Alteryx documente les mesures mais ne nomme aucune colonne de sortie ;
les noms exacts seront donc vérifiés ultérieurement sur un workflow réel.
Le seul type d'information non converti est la **clé de Peano**, un index
spatial Alteryx propriétaire sans spécification publique : elle est ignorée, et la conversion émet
une note qui la nomme afin que l'omission soit visible dans le workflow converti.
