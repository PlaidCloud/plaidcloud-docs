## Description

L'étape **Spatial : points vers ligne** relie des points en une ligne, écrite dans une colonne nommée `SequenceLine`. Elle écrit une ligne par groupe, ou une seule ligne pour tous les points si vous n'indiquez aucun groupe.

## Source et options

- **Table source** et **Table de sortie** — la table à lire et la table à écrire.
- **Colonne de points** — la colonne contenant les points WKT.
- **Regrouper par** *(facultatif)* — une ligne pour chaque valeur de cette colonne. Laissez vide pour réunir tous les points en une seule ligne.
- **Trier par** *(facultatif)* — la colonne qui ordonne les points dans une ligne. Les nombres sont triés comme des nombres et les autres valeurs comme du texte. Sans elle, les points gardent leur ordre d'entrée.
