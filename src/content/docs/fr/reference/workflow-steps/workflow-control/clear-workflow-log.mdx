## Description


Efface le journal d'un workflow PlaidCloud Analyze existant.



## Journal du workflow à effacer


Sélectionnez d'abord le projet qui contient le journal du workflow à effacer dans la liste déroulante **Projet**.



Sélectionnez ensuite le journal du workflow à effacer dans la liste déroulante **Workflow**.


<Aside type="danger">Aucune boîte de dialogue de confirmation n'apparaît avant la suppression. Veillez à sélectionner le bon journal de workflow.</Aside>
