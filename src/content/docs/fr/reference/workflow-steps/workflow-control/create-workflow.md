## Description


Crée un nouveau workflow PlaidCloud Analyze.



## Workflow à créer


Sélectionnez d'abord, dans la liste déroulante, le projet dans lequel le nouveau workflow doit être créé.



Saisissez ensuite un nom de workflow. Le nom doit être unique dans le projet.
