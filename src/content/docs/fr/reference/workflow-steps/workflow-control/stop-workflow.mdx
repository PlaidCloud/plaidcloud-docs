## Description


L'étape « Arrêter le workflow » arrête un workflow existant en cours d'exécution.


<Aside>Si le workflow n'est pas en cours d'exécution lorsque cette étape s'exécute, un avertissement est écrit dans le journal indiquant que *Workflow is already stopped.</Aside>


## Workflow à arrêter


Sélectionnez d'abord le projet qui contient le workflow à arrêter dans la liste déroulante **Projet**.



Sélectionnez ensuite le workflow à arrêter dans la liste déroulante **Workflow**.
