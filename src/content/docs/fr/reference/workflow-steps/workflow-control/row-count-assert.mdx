## Description

Fait échouer le workflow lorsque deux tables ont un nombre de lignes différent. Utilisez-la comme point de contrôle de la qualité des données — par exemple pour confirmer qu'une table transformée a conservé toutes les lignes de sa source, ou qu'une réconciliation n'a ni supprimé ni dupliqué d'enregistrements. Lorsque les nombres correspondent, le workflow continue ; lorsqu'ils diffèrent, l'étape arrête le workflow et écrit le message d'échec dans le journal du workflow.

## Configuration

- **Table de gauche** — la première table dont les lignes sont comptées.
- **Table de droite** — la seconde table dont les lignes sont comptées.
- **Message d'échec** — le message affiché lorsque les nombres diffèrent. Par défaut : « Les nombres de lignes ne correspondent pas ».

Comparez avec [Déclencher une erreur de workflow](/fr/reference/workflow-steps/workflow-control/raise-workflow-error/) lorsque vous devez faire échouer le workflow sur une condition arbitraire plutôt que sur une différence de nombre de lignes.
