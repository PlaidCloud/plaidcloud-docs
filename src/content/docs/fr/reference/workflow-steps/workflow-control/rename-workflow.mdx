## Description


Renomme un workflow PlaidCloud Analyze existant.

<Aside>Si le workflow renommé existe déjà, une erreur est écrite dans le journal indiquant que *Workflow \{workflow} in project \{project} already exists.* Aucune action n'est effectuée. Cela limite de fait la transformation **Renommer le workflow** à une seule utilisation.</Aside>


## Workflow à renommer


Sélectionnez d'abord le projet qui contient le workflow à renommer dans la liste déroulante **Projet**.



Sélectionnez ensuite le workflow à renommer dans la liste déroulante **Workflow**.



Enfin, saisissez le nouveau nom du workflow dans le champ **Renommer en**. N'oubliez pas que le nom doit être unique dans le projet.
