## Description


Supprime un workflow PlaidCloud Analyze existant.



## Workflow à supprimer


Sélectionnez d'abord le projet qui contient le workflow à supprimer dans la liste déroulante **Projet**.



Sélectionnez ensuite le workflow à supprimer dans la liste déroulante **Workflow**.


<Aside type="danger">Aucune boîte de dialogue de confirmation n'apparaît avant la suppression. Veillez à sélectionner le bon workflow !</Aside>
