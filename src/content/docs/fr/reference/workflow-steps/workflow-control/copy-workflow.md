## Description


Crée une copie d'un workflow PlaidCloud Analyze existant.



## Workflow à copier


Sélectionnez d'abord le projet qui contient le workflow à copier dans la liste déroulante **Projet**.



Sélectionnez ensuite le workflow à copier dans la liste déroulante **Workflow**.



Saisissez enfin le nom du nouveau workflow dans le champ **Nouveau workflow**. N'oubliez pas : le nom doit être unique dans le projet.
