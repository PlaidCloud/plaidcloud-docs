PlaidCloud convertit les workflows KNIME (`.knwf`) et les groupes de workflows (`.knar`)
en workflows avancés natifs. L'importeur fait correspondre chaque nœud KNIME à une
étape de workflow, une variable de projet ou un objet du canevas, et aplatit les métanœuds et
les composants, de sorte qu'un workflow converti s'exécute en mode cloud natif.

98,5 % des configurations de nœuds KNIME sont converties intégralement, et 205 des 207 types
de nœuds principaux sont au statut Complet. Pour lancer une conversion, consultez
[Migrer des workflows KNIME](/fr/guides/workflows/migrate-knime-workflows/).

Chaque nœud a un statut :

- **Complet** : le nœud dispose d'une correspondance valide avec des étapes PlaidCloud.
- **Partiel** : le nœud est converti pour son usage courant, tandis qu'un *mode de capacité*
  distinct n'est pas reproduit ; ce mode est nommé.
- **Non pris en charge** : aucune conversion ; le nœud reste sur le canevas comme espace
  réservé nommé et la capacité est reconstruite nativement.

Les variantes anciennes et obsolètes d'un nœud sont répertoriées sous le nœud qui
les remplace.

Les quelques comportements qu'un workflow converti ne reproduit pas sont répertoriés dans
[Cas limites connus](#cas-limites-connus).

Un nœud de connecteur devient la connexion PlaidCloud sur laquelle ses étapes s'exécutent ; consultez
[Connexion aux systèmes externes](#connexion-aux-systèmes-externes).

## Prise en charge des nœuds

Sur les 207 nœuds principaux : 205 Complet, 2 Partiel, 0 Non pris en charge.

## Familles de nœuds d'extension

Les nœuds des familles d'extensions de KNIME sont eux aussi convertis en étapes
PlaidCloud standard : base de données, REST et services web, scripts Python, R et Java,
apprentissage automatique, JSON et XML, traitement de texte, notification et reporting, séries

et la longue traîne des nœuds utilitaires principaux. Un nœud sans chemin de conversion
est conservé comme espace réservé nommé ; consultez [Non converti](#non-converti).

## Non converti

Un nœud sans chemin de conversion est conservé sur le canevas comme espace réservé nommé.
L'espace réservé transmet ses données, ajoute un avertissement qui nomme le nœud KNIME
et ne fait jamais échouer la conversion : une entrée manquante ou non liée est un
avertissement, pas une erreur. Toute étape située en aval d'un espace réservé est signalée afin qu'un
résultat manquant ne passe jamais inaperçu.

## Connexion aux systèmes externes

Un nœud de connecteur KNIME devient la connexion sur laquelle ses étapes s'exécutent. Les identifiants
ne sont jamais importés ; chaque connexion est donc une connexion que vous choisissez dans l'espace de travail
cible, et l'avertissement de l'étape indique ce qu'il faut définir.

| KNIME | Ce que vous définissez dans PlaidCloud |
| --- | --- |
| Database connectors | Une connexion de base de données, liée lors de la conversion ou choisie sur l'étape. |
| REST and web service nodes that sign in | Une [connexion REST](/fr/reference/connectors/rest/generic-rest/), liée lors de la conversion ou choisie sur l'étape. |
| Speech Recognizer (IBM Watson) | Une connexion REST à l'URL du service Watson dont la connexion Basic utilise l'utilisateur `apikey` avec votre clé d'API comme mot de passe. |
| Email Connector, Email Reader, Email Mover | Le mot de passe du serveur de messagerie, dans la variable de projet que nomme l'avertissement de l'étape. L'hôte et l'utilisateur proviennent du nœud Email Connector. |
| Password-protected Excel workbooks | Le mot de passe du classeur, dans la variable de projet que nomme l'avertissement de l'étape. |
| LLM connectors and authenticators | Une connexion LLM sur l'étape IA. |
| Views, charts and reporting layout | Rien ; ces nœuds n'ont aucun effet sur les données et sont répertoriés dans le rapport de conversion. |

La conversion ne contacte jamais un système source ou de destination.

## Vérifier un workflow converti

L'ordre des lignes et le RowID sont conservés à travers les nœuds qui les lisent ; un
workflow qui dépend de l'ordre des lignes le conserve donc à travers ces nœuds. Comparez la
sortie du workflow converti avec celle de votre workflow KNIME : schéma, nombre
de lignes et valeurs des lignes.
