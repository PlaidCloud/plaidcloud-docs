## Où trouver la syntaxe de référence

PlaidCloud Lakehouse utilise les bibliothèques de fonctions SQL des moteurs sous-jacents. Pour les détails sur les arguments d'une fonction, ses cas limites et son comportement le plus récent, consultez la documentation amont en complément des exemples adaptés à PlaidCloud présentés ici.

- **Lakehouse v1** → [Référence des fonctions SQL de Databend](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [Référence des fonctions SQL de StarRocks](https://docs.starrocks.io/docs/sql-reference/sql-functions/) (PlaidCloud Lakehouse v2 suit StarRocks 4.1)
