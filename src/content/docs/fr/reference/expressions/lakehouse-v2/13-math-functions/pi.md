Renvoie la constante mathématique pi.

## Syntaxe Analyze

```python
func.pi()
```

## Exemples Analyze

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## Syntaxe SQL

```sql
PI()
```

## Exemples SQL

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
