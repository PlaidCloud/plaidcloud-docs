Renvoie la constante mathématique e (nombre d'Euler).

## Syntaxe Analyze

```python
func.e()
```

## Exemples Analyze

```python
func.e()

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## Syntaxe SQL

```sql
E()
```

## Exemples SQL

```sql
SELECT E();

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
