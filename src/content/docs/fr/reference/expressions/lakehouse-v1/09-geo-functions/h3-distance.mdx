Renvoie la distance de grille entre les deux index [H3](https://eng.uber.com/h3/) donnés.

<Aside>Le calcul de distance H3 ne fonctionne qu'entre des hexagones voisins. Son utilisation avec des hexagones non voisins génère une erreur.</Aside>

### Syntaxe Analyze

```python
func.h3_distance(h3, a_h3)
```

## Exemples Analyze

```python
func.h3_distance(599119489002373119, 599119491149856767)

┌──────────────────────────────────────────────────────────┐
│ func.h3_distance(599119489002373119, 599119491149856767) │
├──────────────────────────────────────────────────────────┤
│                                                        1 │
└──────────────────────────────────────────────────────────┘
```

## Syntaxe SQL

```sql
H3_DISTANCE(h3, a_h3)
```

## Exemples SQL

```sql
SELECT H3_DISTANCE(599119489002373119, 599119491149856767);

┌─────────────────────────────────────────────────────┐
│ h3_distance(599119489002373119, 599119491149856767) │
├─────────────────────────────────────────────────────┤
│                                                   1 │
└─────────────────────────────────────────────────────┘
```
