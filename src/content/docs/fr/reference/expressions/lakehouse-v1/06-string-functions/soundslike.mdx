Compare la prononciation de deux chaînes d'après leurs codes Soundex. Soundex est un algorithme phonétique qui produit un code représentant la prononciation d'une chaîne, ce qui permet une correspondance approximative des chaînes selon leur prononciation plutôt que leur orthographe. PlaidCloud Lakehouse propose la fonction [SOUNDEX](../soundex), qui permet d'obtenir le code Soundex d'une chaîne.

SOUNDS LIKE s'utilise fréquemment dans la clause WHERE des requêtes SQL pour restreindre les lignes par correspondance approximative de chaînes, par exemple pour des noms et des adresses ; consultez [Filtrage des lignes](#filtrage-des-lignes) dans [Exemples](#exemples-sql).

<Aside>Bien que cette fonction soit utile pour la correspondance approximative de chaînes, elle n'est pas toujours exacte. L'algorithme Soundex repose sur les règles de prononciation de l'anglais et peut mal fonctionner avec des chaînes d'autres langues ou dialectes.</Aside>

## Syntaxe Analyze

```python
func.sounds_like(<str1>, <str2>)
```

## Exemples Analyze

```python
func..sounds_like('Monday', 'Sunday')
┌───────────────────────────────────────┐
│ func..sounds_like('Monday', 'Sunday') │
├───────────────────────────────────────┤
│                                     0 │
└───────────────────────────────────────┘
```

## Syntaxe SQL

```sql
<str1> SOUNDS LIKE <str2>
```

## Arguments

| Arguments | Description |
|-----------|-------------|
| str1, 2   | Les chaînes à comparer. |

## Type de retour

Renvoie la valeur booléenne 1 si les codes Soundex des deux chaînes sont identiques (c'est-à-dire qu'elles se prononcent de la même façon), sinon 0.

## Exemples SQL

### Comparaison de chaînes

```sql
SELECT 'two' SOUNDS LIKE 'too'
----
1

SELECT CONCAT('A', 'B') SOUNDS LIKE 'AB';
----
1

SELECT 'Monday' SOUNDS LIKE 'Sunday';
----
0
```

### Filtrage des lignes

```sql
SELECT * FROM  employees;

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Mark      |Smythe   | 28|
 0|Johann    |Schmidt  | 51|
 0|Eric      |Doe      | 30|
 0|Sue       |Johnson  | 45|


SELECT * FROM  employees
WHERE  first_name SOUNDS LIKE 'John';

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Johann    |Schmidt  | 51|
```
