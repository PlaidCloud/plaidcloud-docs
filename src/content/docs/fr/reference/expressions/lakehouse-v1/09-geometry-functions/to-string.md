Convertit un objet GEOMETRY en représentation sous forme de chaîne. Le format d'affichage des données en sortie est contrôlé par le paramètre `geometry_output_format`, qui accepte les types suivants :

| Paramètre         | Description                                                         |
|-------------------|---------------------------------------------------------------------|
| GeoJSON (par défaut) | Le résultat GEOMETRY est rendu sous la forme d'un objet JSON au format GeoJSON. |
| WKT               | Le résultat GEOMETRY est rendu sous la forme d'une chaîne au format WKT. |
| WKB               | Le résultat GEOMETRY est rendu sous la forme d'un binaire au format WKB. |
| EWKT              | Le résultat GEOMETRY est rendu sous la forme d'une chaîne au format EWKT. |
| EWKB              | Le résultat GEOMETRY est rendu sous la forme d'un binaire au format EWKB. |

## Syntaxe SQL

```sql
TO_STRING(<geometry>)
```

## Arguments

| Arguments    | Description                                          |
|--------------|------------------------------------------------------|
| `<geometry>` | L'argument doit être une expression de type GEOMETRY. |

## Type de retour

String.

## Exemples SQL

```sql
SET geometry_output_format='GeoJSON';

SELECT
  TO_GEOMETRY(
    ST_GEOMETRYFROMWKT(
      'SRID=4326;LINESTRING(400000 6000000, 401000 6010000)'
    )
  ) AS pipeline_geometry;
```
