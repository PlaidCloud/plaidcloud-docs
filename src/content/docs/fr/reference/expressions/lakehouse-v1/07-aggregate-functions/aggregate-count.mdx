La fonction COUNT() renvoie le nombre d'enregistrements renvoyés par une requête SELECT.

<Aside type="caution">Les valeurs NULL ne sont pas comptées.</Aside>

## Syntaxe Analyze

```python
func.count(<column>)
```

## Exemples Analyze

```python
func.count(table.grade).alias('count_valid_grades')

| count_valid_grades |
|--------------------|
|          4         |
```

## Syntaxe SQL

```sql
COUNT(<expr>)
```

## Arguments

| Arguments | Description                                                                                                                                                     |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<expr>`  | Toute expression. <br /> Il peut s'agir d'un nom de colonne, du résultat d'une autre fonction ou d'une opération mathématique.<br />`*` est également autorisé, pour indiquer un simple comptage de lignes. |

## Type de retour

Un entier.

## Exemples SQL

**Créer une table et insérer des données d'exemple**
```sql
CREATE TABLE students (
  id INT,
  name VARCHAR,
  age INT,
  grade FLOAT NULL
);

INSERT INTO students (id, name, age, grade)
VALUES (1, 'John', 21, 85),
       (2, 'Emma', 22, NULL),
       (3, 'Alice', 23, 90),
       (4, 'Michael', 21, 88),
       (5, 'Sophie', 22, 92);

```

**Exemple de requête : compter les étudiants ayant une note valide**
```sql
SELECT COUNT(grade) AS count_valid_grades
FROM students;
```

**Résultat**
```sql
| count_valid_grades |
|--------------------|
|          4         |
```
