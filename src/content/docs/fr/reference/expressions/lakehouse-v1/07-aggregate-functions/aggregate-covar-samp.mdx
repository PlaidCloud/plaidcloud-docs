Fonction d'agrégation.

La fonction covar_samp() renvoie la covariance d'échantillon (Σ((x - x̅)(y - y̅)) / (n - 1)) de deux colonnes de données.

<Aside type="caution">Les valeurs NULL ne sont pas comptées.</Aside>

## Syntaxe Analyze

```python
func.covar_samp(<expr1>, <expr2>)
```

## Exemples Analyze

```python
func.covar_samp(table.items_sold, table.profit).alias('covar_samp_items_profit')

| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```

## Syntaxe SQL

```sql
COVAR_SAMP(<expr1>, <expr2>)
```

## Arguments

| Arguments |        Description       |
|-----------| ------------------------ |
| `<expr1>` | Toute expression numérique |
| `<expr2>` | Toute expression numérique |

## Type de retour

float64 ; lorsque n &lt;= 1, renvoie +∞.

## Exemples SQL

**Créer une table et insérer des données d'exemple**

```sql
CREATE TABLE store_sales (
  id INT,
  store_id INT,
  items_sold INT,
  profit FLOAT
);

INSERT INTO store_sales (id, store_id, items_sold, profit)
VALUES (1, 1, 100, 1000),
       (2, 2, 200, 2000),
       (3, 3, 300, 3000),
       (4, 4, 400, 4000),
       (5, 5, 500, 5000);
```

**Exemple de requête : calculer la covariance d'échantillon entre les articles vendus et le bénéfice**

```sql
SELECT COVAR_SAMP(items_sold, profit) AS covar_samp_items_profit
FROM store_sales;
```

**Résultat**

```sql
| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```
