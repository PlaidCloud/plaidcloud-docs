Fonction d'agrégation.

La fonction STRING_AGG() convertit toutes les valeurs non NULL d'une colonne en chaîne (String), séparées par le délimiteur.

## Syntaxe Analyze

```python
func.string_agg(<expr> [, delimiter])
```

## Exemples Analyze

```python
func.string_agg(table.language_name).alias('concatenated_languages')

|          concatenated_languages         |
|-----------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```

## Syntaxe SQL

```sql
STRING_AGG(<expr>)
STRING_AGG(<expr> [, delimiter])
```

<Aside>Si `<expr>` n'est pas une expression de type chaîne, utilisez `::VARCHAR` pour la convertir. Par exemple : ```sql SELECT string_agg(number::VARCHAR, '|') AS s FROM numbers(5); ┌───────────┐ │ s │ ├───────────┤ │ 0│1│2│3│4 │ └───────────┘ ```</Aside>

## Arguments

| Arguments   | Description                                                         |
|-------------|---------------------------------------------------------------------|
| `<expr>`    | Toute expression de type chaîne (sinon, utilisez `::VARCHAR` pour la convertir) |
| `delimiter` | Chaîne constante facultative ; si elle n'est pas spécifiée, une chaîne vide est utilisée |

## Type de retour

Le type String

## Exemples SQL

**Créer une table et insérer des données d'exemple**

```sql
CREATE TABLE programming_languages (
  id INT,
  language_name VARCHAR
);

INSERT INTO programming_languages (id, language_name)
VALUES (1, 'Python'),
       (2, 'JavaScript'),
       (3, 'Java'),
       (4, 'C#'),
       (5, 'Ruby');
```

**Exemple de requête : concaténer des noms de langages de programmation avec un délimiteur**
```sql
SELECT STRING_AGG(language_name, ', ') AS concatenated_languages
FROM programming_languages;
```

**Résultat**
```sql
|          concatenated_languages         |
|------------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```
