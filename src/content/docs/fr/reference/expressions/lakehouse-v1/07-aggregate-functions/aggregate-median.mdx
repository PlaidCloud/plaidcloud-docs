Fonction d'agrégation.

La fonction MEDIAN() calcule la médiane d'une séquence de données numériques.

<Aside type="caution">Les valeurs NULL ne sont pas comptées.</Aside>

## Syntaxe Analyze

```python
func.median(<expr>)
```

## Exemples Analyze

```python
func.median(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## Syntaxe SQL

```sql
MEDIAN(<expr>)
```

## Arguments

| Arguments | Description              |
|-----------|--------------------------|
| `<expr>`  | Toute expression numérique |

## Type de retour

Le type de la valeur.

## Exemples SQL

**Créer une table et insérer des données d'exemple**
```sql
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);
```

**Exemple de requête : calculer la note médiane à l'examen**
```sql
SELECT MEDIAN(score) AS median_score
FROM exam_scores;
```

**Résultat**
```sql
|  median_score  |
|----------------|
|      85.0      |
```
