Fonction d'agrégation.

La fonction STDDEV_SAMP() renvoie l'écart type d'échantillon (la racine carrée de VAR_SAMP()) d'une expression.

<Aside type="caution">Les valeurs NULL ne sont pas comptées.</Aside>

## Syntaxe Analyze

```python
func.stddev_samp(<expr>)
```

## Exemples Analyze

```python
func.stddev_samp(table.height).alias('height_stddev_samp')

| height_stddev_samp |
|--------------------|
|      0.240         |
```

## Syntaxe SQL

```sql
STDDEV_SAMP(<expr>)
```

## Arguments

| Arguments | Description              |
|-----------|--------------------------|
| `<expr>`  | Toute expression numérique |

## Type de retour

double

## Exemples SQL

**Créer une table et insérer des données d'exemple**
```sql
CREATE TABLE height_data (
  id INT,
  person_id INT,
  height FLOAT
);

INSERT INTO height_data (id, person_id, height)
VALUES (1, 1, 5.8),
       (2, 2, 6.1),
       (3, 3, 5.9),
       (4, 4, 5.7),
       (5, 5, 6.3);
```

**Exemple de requête : calculer l'écart type d'échantillon des tailles**
```sql
SELECT STDDEV_SAMP(height) AS height_stddev_samp
FROM height_data;
```

**Résultat**
```sql
| height_stddev_samp |
|--------------------|
|      0.240         |
```
