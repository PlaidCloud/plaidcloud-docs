Calcule la médiane d'une séquence de données numériques avec l'algorithme [t-digest](https://github.com/tdunning/t-digest/blob/master/docs/t-digest-paper/histo.pdf).

<Aside type="caution">Les valeurs NULL ne sont pas incluses dans le calcul.</Aside>

## Syntaxe Analyze

```python
func.median_tdigest(<expr>)
```

## Exemples Analyze

```python
func.median_tdigest(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## Syntaxe SQL

```sql
MEDIAN_TDIGEST(<expr>)
```

## Arguments

| Arguments | Description              |
|-----------|--------------------------|
| `<expr>`  | Toute expression numérique |

## Type de retour

Renvoie une valeur du même type de données que les valeurs d'entrée.

## Exemples SQL

```sql
-- Create a table and insert sample data
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);

-- Calculate median exam score
SELECT MEDIAN_TDIGEST(score) AS median_score
FROM exam_scores;

|  median_score  |
|----------------|
|      85.0      |
```
