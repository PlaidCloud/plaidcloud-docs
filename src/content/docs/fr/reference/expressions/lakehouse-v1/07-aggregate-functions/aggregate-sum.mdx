Fonction d'agrégation.

La fonction SUM() calcule la somme d'un ensemble de valeurs.

<Aside type="caution">Les valeurs NULL ne sont pas comptées.</Aside>


## Syntaxe Analyze

```python
func.sum(<column>)
```

## Exemples Analyze

```python
func.sum(table.quantity).alias('total_quantity_sold')

| total_quantity_sold |
|---------------------|
|         41          |
```

## Syntaxe SQL

```sql
SUM(<expr>)
```

## Arguments

| Arguments | Description              |
|-----------|--------------------------|
| `<expr>`  | Toute expression numérique |

## Type de retour

Un double si le type d'entrée est double, sinon un entier.

## Exemples SQL

**Créer une table et insérer des données d'exemple**
```sql
CREATE TABLE sales_data (
  id INT,
  product_id INT,
  quantity INT
);

INSERT INTO sales_data (id, product_id, quantity)
VALUES (1, 1, 10),
       (2, 2, 5),
       (3, 3, 8),
       (4, 4, 3),
       (5, 5, 15);
```

**Exemple de requête : calculer la quantité totale de produits vendus**
```sql
SELECT SUM(quantity) AS total_quantity_sold
FROM sales_data;
```

**Résultat**
```sql
| total_quantity_sold |
|---------------------|
|         41          |
```
