Fonction d'agrégation.

La fonction STDDEV_POP() renvoie l'écart type de population (la racine carrée de VAR_POP()) d'une expression.

<Aside>STD() ou STDDEV() peuvent également être utilisées ; elles sont équivalentes mais ne font pas partie du SQL standard.</Aside>

<Aside type="caution">Les valeurs NULL ne sont pas comptées.</Aside>

## Syntaxe Analyze

```python
func.stddev_pop(<expr>)
```

## Exemples Analyze

```python
func.stddev_pop(table.score).alias('test_score_stddev_pop')

| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```

## Syntaxe SQL

```sql
STDDEV_POP(<expr>)
STDDEV(<expr>)
STD(<expr>)
```

## Arguments

| Arguments | Description              |
|-----------|--------------------------|
| `<expr>`  | Toute expression numérique |

## Type de retour

double

## Exemples SQL

**Créer une table et insérer des données d'exemple**
```sql
CREATE TABLE test_scores (
  id INT,
  student_id INT,
  score FLOAT
);

INSERT INTO test_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 85),
       (3, 3, 90),
       (4, 4, 95),
       (5, 5, 100);
```

**Exemple de requête : calculer l'écart type de population des notes de test**
```sql
SELECT STDDEV_POP(score) AS test_score_stddev_pop
FROM test_scores;
```

**Résultat**
```sql
| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```
