Ce document présente la fonction `ai_text_completion` de PlaidCloud Lakehouse et montre comment générer des complétions de texte avec cette fonction.

Consultez l'[implémentation en amont](https://github.com/datafuselabs/databend/blob/1e93c5b562bd159ecb0f336bb88fd1b7f9dc4a62/src/common/openai/src/completion.rs).

<Aside>À partir de PlaidCloud Lakehouse v1.1.47, PlaidCloud Lakehouse prend en charge le [service Azure OpenAI](https://azure.microsoft.com/en-au/products/cognitive-services/openai-service). Cette intégration offre une meilleure confidentialité des données. Pour utiliser Azure OpenAI, ajoutez les configurations suivantes à la section `[query]` : ```sql # Azure OpenAI openai_api_chat_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_embedding_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_version = "2023-03-15-preview" ```</Aside>

<Aside type="caution">PlaidCloud Lakehouse s'appuie sur (Azure) OpenAI pour `AI_TEXT_COMPLETION` et envoie à (Azure) OpenAI les données du prompt de complétion. Cette fonction ne s'active que si la configuration de PlaidCloud Lakehouse inclut `openai_api_key` ; sinon, elle reste inactive. Elle est disponible par défaut sur PlaidCloud Lakehouse avec une clé Azure OpenAI. Si vous l'utilisez, vous reconnaissez que vos données seront envoyées à Azure OpenAI par nos soins.</Aside>


## Présentation de Ai_text_completion

La fonction `ai_text_completion` de PlaidCloud Lakehouse est une fonction intégrée qui génère des complétions de texte à partir d'un prompt donné. Elle est utile pour les tâches de traitement du langage naturel, comme les questions-réponses, la génération de texte et les systèmes de saisie semi-automatique.

La fonction prend un prompt textuel en entrée et renvoie une complétion générée pour ce prompt. Les complétions sont créées à l'aide de modèles préentraînés sur de vastes corpus de textes, qui capturent les relations entre les mots et les expressions dans un espace continu.

## Génération de complétions de texte avec Ai_text_completion

Voici un exemple simple d'utilisation de la fonction `ai_text_completion` dans PlaidCloud Lakehouse pour générer une complétion de texte :
```sql
SELECT ai_text_completion('What is artificial intelligence?') AS completion;
```

Résultat :
```sql
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ completion                                                                                                          │
├────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ Artificial intelligence (AI) is the field of study focused on creating machines and software capable of thinking, learning, and solving problems in a way that mimics human intelligence. This includes areas such as machine learning, natural language processing, computer vision, and robotics. │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

Dans cet exemple, nous fournissons le prompt « What is artificial intelligence? » à la fonction `ai_text_completion`, qui renvoie une complétion générée décrivant brièvement l'intelligence artificielle.
