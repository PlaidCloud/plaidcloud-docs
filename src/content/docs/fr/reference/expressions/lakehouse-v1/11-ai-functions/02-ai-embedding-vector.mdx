Ce document présente la fonction ai_embedding_vector de PlaidCloud Lakehouse et montre comment créer des embeddings de documents avec cette fonction.

Consultez l'[implémentation en amont](https://github.com/datafuselabs/databend/blob/1e93c5b562bd159ecb0f336bb88fd1b7f9dc4a62/src/common/openai/src/embedding.rs).

Par défaut, PlaidCloud Lakehouse utilise le modèle [text-embedding-ada](https://platform.openai.com/docs/models/embeddings) pour générer les embeddings.

<Aside>À partir de PlaidCloud Lakehouse v1.1.47, PlaidCloud Lakehouse prend en charge le [service Azure OpenAI](https://azure.microsoft.com/en-au/products/cognitive-services/openai-service). Cette intégration offre une meilleure confidentialité des données. Pour utiliser Azure OpenAI, ajoutez les configurations suivantes à la section `[query]` : ```sql # Azure OpenAI openai_api_chat_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_embedding_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_version = "2023-03-15-preview" ```</Aside>


<Aside type="caution">PlaidCloud Lakehouse s'appuie sur (Azure) OpenAI pour `AI_EMBEDDING_VECTOR` et envoie à (Azure) OpenAI les données de la colonne d'embedding. Cette fonction ne s'active que si la configuration de PlaidCloud Lakehouse inclut `openai_api_key` ; sinon, elle reste inactive. Elle est disponible par défaut sur PlaidCloud Lakehouse avec une clé Azure OpenAI. Si vous l'utilisez, vous reconnaissez que vos données seront envoyées à Azure OpenAI par nos soins.</Aside>

## Présentation de Ai_embedding_vector

La fonction `ai_embedding_vector` de PlaidCloud Lakehouse est une fonction intégrée qui génère des vecteurs d'embedding pour des données textuelles. Elle est utile pour les tâches de traitement du langage naturel, comme la similarité de documents, le clustering et les systèmes de recommandation.

La fonction prend un texte en entrée et renvoie un vecteur de grande dimension qui représente le sens sémantique et le contexte de ce texte. Les embeddings sont créés à l'aide de modèles préentraînés sur de vastes corpus de textes, qui capturent les relations entre les mots et les expressions dans un espace continu.

## Création d'embeddings avec Ai_embedding_vector

Pour créer des embeddings pour un document texte avec la fonction `ai_embedding_vector`, suivez l'exemple ci-dessous.
1. Créez une table pour stocker les documents :
```sql
CREATE TABLE documents (
                           id INT,
                           title VARCHAR,
                           content VARCHAR,
                           embedding ARRAY(FLOAT32)
);
```

2. Insérez des documents d'exemple dans la table :
```sql
INSERT INTO documents(id, title, content)
VALUES
    (1, 'A Brief History of AI', 'Artificial intelligence (AI) has been a fascinating concept of science fiction for decades...'),
    (2, 'Machine Learning vs. Deep Learning', 'Machine learning and deep learning are two subsets of artificial intelligence...'),
    (3, 'Neural Networks Explained', 'A neural network is a series of algorithms that endeavors to recognize underlying relationships...'),
```

3. Générez les embeddings :
```sql
UPDATE documents SET embedding = ai_embedding_vector(content) WHERE length(embedding) = 0;
```
Une fois la requête exécutée, la colonne embedding de la table contient les embeddings générés.

Les embeddings sont stockés sous forme de tableau de valeurs `FLOAT32` dans la colonne embedding, dont le type est `ARRAY(FLOAT32)`.

Vous pouvez désormais utiliser ces embeddings pour diverses tâches de traitement du langage naturel, comme trouver des documents similaires ou regrouper des documents selon leur contenu.

4. Inspectez les embeddings :

```sql
SELECT length(embedding) FROM documents;
┌───────────────────┐
│ length(embedding) │
├───────────────────┤
│              1536 │
│              1536 │
│              1536 │
└───────────────────┘
```
La requête ci-dessus montre que les embeddings générés ont une longueur de 1536 (dimensions) pour chaque document.
