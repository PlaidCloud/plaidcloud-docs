Renvoie le quotient de la division du premier nombre par le second. Renvoie NULL si le second nombre est 0 ou NULL.

Voir aussi :

- [DIV](../div)
- [DIV0](../div0)

## Syntaxe Analyze

```python
func.divnull(<numerator>, <denominator>)
```

## Exemples Analyze

```python
func.divnull(20, 6), func.divnull(20, 0), func.divnull(20, null)

┌───────────────────────────────────────────────────────────────────┐
│ func.divnull(20, 6)│ func.divnull(20, 0) │ func.divnull(20, null) │
├────────────────────┼─────────────────────┼────────────────────────┤
│ 3.3333333333333335 │ NULL                │ NULL                   │
└───────────────────────────────────────────────────────────────────┘
```

## Syntaxe SQL

```sql
DIVNULL(<number1>, <number2>)
```

## Exemples SQL

```sql
SELECT
  DIVNULL(20, 6),
  DIVNULL(20, 0),
  DIVNULL(20, NULL);

┌─────────────────────────────────────────────────────────┐
│   divnull(20, 6)   │ divnull(20, 0) │ divnull(20, null) │
├────────────────────┼────────────────┼───────────────────┤
│ 3.3333333333333335 │ NULL           │ NULL              │
└─────────────────────────────────────────────────────────┘
```
