Obtient la valeur maximale du bitmap.

## Syntaxe Analyze

```python
func.bitmap_max( <bitmap> )
```

## Exemples Analyze

```python
func.bitmap_max(func.build_bitmap([1, 4, 5]))

┌───────────────────────────────────────────────┐
│ func.bitmap_max(func.build_bitmap([1, 4, 5])) │
├───────────────────────────────────────────────┤
│                                             5 │
└───────────────────────────────────────────────┘
```

## Syntaxe SQL

```sql
BITMAP_MAX( <bitmap> )
```

## Exemples SQL

```sql
SELECT BITMAP_MAX(BUILD_BITMAP([1,4,5]));

┌─────────────────────────────────────┐
│ bitmap_max(build_bitmap([1, 4, 5])) │
├─────────────────────────────────────┤
│                                   5 │
└─────────────────────────────────────┘
```
