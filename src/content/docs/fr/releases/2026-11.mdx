## Ajouts

- **Aperçu dans les formulaires d'étape.** Import: SQL, Execute: SQL, Extract: SQL, Export: SQL et Salesforce Query affichent jusqu'à 100 lignes sans exécuter l'étape, et les lectures de vues et de listes Anaplan affichent les colonnes et les types qu'elles produiraient. Cliquez sur **Aperçu** dans l'onglet **Source**. Les variables sont renseignées comme lors de l'exécution, mais les formats de variable tels que `{x:>9}` ne sont pas pris en charge. L'aperçu n'exécute que les fonctions SQL standard ; sinon, il vous invite à exécuter l'étape. Il n'est pas disponible sur les projets verrouillés, ni pour l'étape Execute SQL basée sur un agent. Consultez [Importer depuis SQL](/fr/reference/workflow-steps/import/import-sql/) et [Extraire SQL](/fr/reference/workflow-steps/tables/table-extract-sql/).
- **Les assistants IA peuvent dépublier une table et définir l'audience par défaut des tableaux de bord d'un projet.** `publish_manage` dépublie une table avec sa vue publiée et tout jeu de données de tableau de bord qu'aucun graphique n'utilise ; un jeu de données encore utilisé par un graphique est conservé, tout comme la vue et le jeu de données lorsqu'une vue de rapport est construite sur la vue publiée, et la table est tout de même dépubliée. `project_upsert` définit `dashboard_default_audience`, les groupes avec lesquels les nouveaux tableaux de bord du projet sont partagés, et `[]` l'efface. Consultez [Dépublier](/fr/guides/data/publish/#annuler-la-publication-par-lassistant-ia-ou-mcp) et [Définir l'audience par défaut via l'assistant IA ou MCP](/fr/guides/dashboards/control-who-can-see-a-dashboard/#définir-laudience-par-défaut-par-lassistant-ia-ou-mcp).

- **La voix dans Weave sur mobile ne demande qu'un seul appui.** Touchez le microphone, posez votre question, et Weave l'envoie dès que vous cessez de parler. Touchez de nouveau le microphone pour arrêter plus tôt ; il se désactive de lui-même si rien n'est entendu. Si vous quittez l'onglet **Weave** ou mettez l'application en arrière-plan en pleine phrase, vos mots restent dans la zone de question sans être envoyés, afin que vous puissiez les relire. Exécuter, Suspendre, Arrêter et Reprendre ignorent un double appui accidentel sur leur confirmation. Nécessite la version 1.3.0 ou ultérieure de l'application. Consultez [Utiliser la voix](/fr/guides/mobile-app/weave-on-mobile/#utiliser-la-voix).

## Modifications

- **Les formulaires d'étape suivent une même disposition.** Les onglets portent des noms standard dans un ordre standard : Général, Paramètres, Source, Colonnes, Filtres, Sortie et Avancé, avec Colonnes d'en-tête et Colonnes de ligne dans les formulaires de comptabilisation ERP. Les champs obligatoires sont repérés par *, et un formulaire n'empêche l'enregistrement que pour ce dont l'étape a besoin.
- **Le menu d'actions de ligne (⋯) se trouve au bord gauche de chaque ligne de grille.**
- **Les étapes d'écriture ERP enregistrées sans paramètre de validation s'ouvrent en mode validation seule.** Cela concerne SAP Post, SAP Attach, NetSuite Post, Oracle EBS GL et AP Post, ainsi que l'exportation Xero. Les étapes explicitement configurées pour s'exécuter en réel restent en réel.
- **Les tâches de longue durée affichent leur progression de la même manière partout.**
- **Les étapes REST, Import REST et Import Postman sont converties en Requête REST lors de la mise à niveau de votre espace de travail.** Une étape qui ne peut pas être convertie proprement reste telle quelle. Consultez [Étape Requête REST](/fr/guides/workflows/rest-request-step/).
- **Les Architectes de projet voient toutes les lignes des tables à accès restreint dans les tableaux de bord**, comme ce qu'ils voient dans Analyze. Le retrait de l'accès Architecte prend effet immédiatement dans les tableaux de bord, que vous changiez le rôle d'une personne, que vous la retiriez du projet, elle ou son groupe, que vous changiez le type d'accès du projet, que vous restauriez une version antérieure du projet ou que vous supprimiez un groupe de sécurité. Un ancien Architecte ne voit plus toutes les lignes des données à accès restreint. Consultez [Gérer l'accès aux lignes](/fr/administration/access/managing-security-groups-and-assignments/#gestion-de-laccès-aux-lignes).
- **Un lien de tableau de bord ouvert après l'expiration de votre session vous amène à ce tableau de bord une fois connecté.** Consultez [Utiliser les tableaux de bord](/fr/guides/dashboards/using-dashboards/).
- **Les outils MCP refusent un champ qu'ils ne reconnaissent pas** et le nomment dans l'erreur, au lieu de l'ignorer. `workflow_upsert` accepte `memo` et accepte `description` comme autre nom pour ce champ. Consultez [Les champs inconnus sont refusés](/fr/integrations/ai-coding-agents/getting-started/#les-champs-inconnus-sont-refusés).

## Corrections

- **Les paramètres de projet non valides sont signalés par un message clair.** Un environnement ou un compte de documents inconnu, un slug déjà pris ou réservé, ou un type de stockage ou un mode de comptabilisation non valide renvoie désormais un message qui nomme le problème, au lieu d'une erreur serveur générique. Via l'API REST, il s'agit d'une erreur 400 plutôt que 500 ; via l'assistant IA ou MCP, il s'agit d'une erreur d'argument non valide.
