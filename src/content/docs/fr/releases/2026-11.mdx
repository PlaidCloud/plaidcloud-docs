## Ajouts

- **Aperçu dans les formulaires d'étape.** Importation : SQL, Execute: SQL, Extraire SQL, Exportation : SQL et Salesforce : interroger un objet affichent jusqu'à 100 lignes sans exécuter l'étape, et les lectures de vues et de listes Anaplan affichent les colonnes et les types qu'elles produiraient. Cliquez sur **Aperçu** dans l'onglet **Source**. Les variables sont renseignées comme le ferait l'exécution, mais les formats de variable tels que `{x:>9}` ne sont pas pris en charge. L'aperçu n'exécute que les fonctions SQL standard ; sinon, il vous invite à exécuter l'étape. Il n'est pas disponible sur les projets verrouillés, ni pour l'étape Execute SQL basée sur un agent. Consultez [Importer depuis SQL](/fr/reference/workflow-steps/import/import-sql/) et [Extraire SQL](/fr/reference/workflow-steps/tables/table-extract-sql/).
- **Les assistants IA peuvent dépublier une table et définir l'audience par défaut des tableaux de bord d'un projet.** `publish_manage` dépublie une table ainsi que sa vue publiée et tout jeu de données de tableau de bord qu'aucun graphique n'utilise ; un jeu de données encore utilisé par un graphique est conservé, tout comme la vue et le jeu de données lorsqu'une vue de rapport repose sur la vue publiée, et la table est tout de même dépubliée. `project_upsert` définit `dashboard_default_audience`, les groupes avec lesquels les nouveaux tableaux de bord du projet sont partagés, et `[]` l'efface. Consultez [Dépublier](/fr/guides/data/publish/#annuler-la-publication-par-lassistant-ia-ou-mcp) et [Définir l'audience par défaut via l'assistant IA ou MCP](/fr/guides/dashboards/control-who-can-see-a-dashboard/#définir-laudience-par-défaut-par-lassistant-ia-ou-mcp).

## Modifications

- **Les formulaires d'étape suivent une même disposition.** Les onglets portent des noms standard dans un ordre standard : Général, Paramètres, Source, Colonnes, Filtres, Sortie et Avancé, avec Colonnes d'en-tête et Colonnes de ligne sur les formulaires de comptabilisation ERP. Les champs obligatoires sont marqués d'un *, et un formulaire n'empêche l'enregistrement que pour ce dont l'étape a besoin.
- **Le menu d'actions de ligne (⋯) se trouve au bord gauche de chaque ligne de grille.**
- **Les étapes d'écriture ERP enregistrées sans paramètre de validation s'ouvrent en validation seule.** Cela concerne SAP Post, SAP Attach, NetSuite Post, Oracle EBS GL et AP Post, et l'exportation Xero. Les étapes explicitement configurées pour s'exécuter en réel restent en réel.
- **Les tâches de longue durée affichent leur progression de la même manière partout.**
- **Les étapes REST, Import REST et Import Postman sont converties en Requête REST lors de la mise à niveau de votre espace de travail.** Une étape qui ne peut pas être convertie proprement reste telle quelle. Consultez [Étape Requête REST](/fr/guides/workflows/rest-request-step/).
- **Les Architectes de projet voient toutes les lignes des tables à accès restreint dans les tableaux de bord**, comme dans Analyze. Le retrait de l'accès Architecte prend effet immédiatement dans les tableaux de bord, que vous changiez le rôle d'une personne, que vous la retiriez du projet ou son groupe, que vous changiez le type d'accès du projet, que vous restauriez une version antérieure du projet ou que vous supprimiez un groupe de sécurité. Un ancien Architecte ne voit plus toutes les lignes des données à accès restreint. Consultez [Gestion de l'accès aux lignes](/fr/administration/access/managing-security-groups-and-assignments/#gestion-de-laccès-aux-lignes).
- **Un lien de tableau de bord ouvert après l'expiration de votre session vous mène à ce tableau de bord une fois connecté.** Consultez [Utilisation des tableaux de bord](/fr/guides/dashboards/using-dashboards/).
- **Les outils MCP refusent un champ qu'ils ne reconnaissent pas** et le nomment dans l'erreur, au lieu de l'ignorer. `workflow_upsert` accepte `memo` et admet `description` comme autre nom. Consultez [Les champs inconnus sont refusés](/fr/integrations/ai-coding-agents/getting-started/#les-champs-inconnus-sont-refusés).

## Corrections

- **Les paramètres de projet non valides sont signalés par un message clair.** Un environnement ou un compte de documents inconnu, un slug déjà pris ou réservé, ou un type de stockage ou un mode de comptabilisation non valide renvoie désormais un message qui nomme le problème, au lieu d'une erreur serveur générique. Via l'API REST, il s'agit d'une erreur 400 plutôt que 500 ; via l'assistant IA ou MCP, d'une erreur d'argument non valide.
