Este tutorial configura un agente de codificación con IA para que interactúe con su espacio de trabajo de PlaidCloud mediante el **Model Context Protocol** (MCP). Una vez configurado, puede pedirle al agente que lea tablas, ejecute flujos de trabajo, cree asignaciones y responda preguntas sobre sus datos, directamente desde su editor.

Toma unos 20 minutos. Funciona con Claude Code, Cursor, Claude Desktop, ChatGPT, GitHub Copilot y cualquier cliente compatible con MCP.

## Qué creará

Una conexión funcional entre su agente de codificación con IA y su espacio de trabajo de PlaidCloud, en la que el agente puede:

- Listar proyectos, tablas, flujos de trabajo y dimensiones
- Leer el contenido de las tablas
- Inspeccionar las definiciones de los flujos de trabajo
- Iniciar ejecuciones de flujos de trabajo
- Responder preguntas sobre sus datos sin que usted tenga que cambiar de contexto

## Requisitos previos

- Un espacio de trabajo de PlaidCloud ([inicie una prueba gratuita](https://app.plaidcloud.com) si no tiene uno)
- Un agente de codificación con IA que ya utilice: Claude Code, Cursor, Claude Desktop, ChatGPT, Copilot o Gemini
- El agente debe ser compatible con MCP (la mayoría de las herramientas de IA actuales lo son)

## Paso 1: Busque la URL de MCP de su espacio de trabajo

Cada espacio de trabajo de PlaidCloud expone un punto de conexión MCP en:

```text
https://<your-workspace>.plaid.cloud/mcp
```

Reemplace `<your-workspace>` por el subdominio de su espacio de trabajo, el mismo que utiliza para iniciar sesión en la interfaz de PlaidCloud.

## Paso 2: Obtenga un token de autenticación

<Steps>

1. Con la sesión iniciada en PlaidCloud en un navegador, visite:
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. Copie el token de portador que aparece en la página. Manténgalo a salvo: otorga el mismo acceso que tiene su cuenta.

</Steps>

<Aside type="caution">
Trate el token como una contraseña. Omite la autenticación interactiva y actúa en su nombre. Si se filtra, revóquelo desde el mismo punto de conexión.
</Aside>

## Paso 3: Configure su agente

<Tabs>

<TabItem label="Claude Code">

Ejecute en su terminal:

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

Para la autenticación con token estático (sin flujo de OAuth, más sencilla para sesiones largas), abra en un navegador la URL del Paso 2, copie el fragmento de configuración que se muestra y péguelo en su archivo `.mcp.json`.

Consulte la [configuración de Claude Code](/es/integrations/ai-coding-agents/claude-code/) para ver todas las opciones.

</TabItem>

<TabItem label="Cursor">

Obtenga un token de portador en `https://<your-workspace>.plaid.cloud/mcp/setup/token` y agréguelo a la configuración de MCP de Cursor:

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

Consulte la [configuración de Cursor](/es/integrations/ai-coding-agents/cursor/) para ver todas las opciones.

</TabItem>

<TabItem label="Claude Desktop">

Abra Configuración → Developer → MCP Servers y agregue:

- **URL del servidor**: `https://<your-workspace>.plaid.cloud/mcp`
- Use el inicio de sesión con OAuth cuando se le solicite

Consulte la [configuración de Claude Desktop](/es/integrations/ai-coding-agents/claude-desktop/) para ver todas las opciones.

</TabItem>

<TabItem label="ChatGPT">

1. Configuración → Conectores → Agregar conector personalizado
2. Introduzca:
   - **Nombre**: `PlaidCloud`
   - **URL del servidor MCP**: `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT lo redirige a PlaidCloud para iniciar sesión con OAuth. Apruebe la conexión.
4. Active el conector en cualquier conversación que deba utilizarlo.

Consulte la [configuración de ChatGPT](/es/integrations/ai-coding-agents/chatgpt/) para ver todas las opciones.

</TabItem>

<TabItem label="Copilot">

Obtenga un token de portador y agréguelo a `.vscode/mcp.json`:

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

VSCode lee este archivo al iniciarse y cada vez que cambia.

Consulte la [configuración de Copilot](/es/integrations/ai-coding-agents/copilot/) para ver todas las opciones.

</TabItem>

</Tabs>

## Paso 4: Verifique la conexión

Pídale al agente algo sencillo:

> "Lista los proyectos de mi espacio de trabajo de PlaidCloud."

El agente debería responder con su lista de proyectos. Si no lo hace, revise los pasos de solución de problemas que aparecen a continuación.

## Paso 5: Pruebe tareas reales

Una vez conectado, pruebe lo siguiente:

- **Explorar sus datos**: "¿Qué columnas tiene la tabla `sales` de mi proyecto Quickstart?"
- **Ejecutar un flujo de trabajo**: "Inicia el flujo de trabajo `monthly_close` del proyecto Financials y avísame cuando termine."
- **Crear algo**: "Crea un paso Table Lookup en mi flujo de trabajo Test que filtre los pedidos de los últimos 30 días."

Las respuestas del agente se basarán en el estado real de su espacio de trabajo, no en respuestas genéricas.

## Solución de problemas

Si el agente no puede comunicarse con PlaidCloud o devuelve errores de autenticación:

- **Token vencido**: actualícelo en `https://<your-workspace>.plaid.cloud/mcp/setup/token`
- **Permisos incorrectos**: algunas herramientas requieren permisos específicos de PlaidCloud (por ejemplo, `analyze.workflow.write`). Ejecute `mcp_introspect(name='<tool>')` en el agente para ver los permisos necesarios
- **Subdominio del espacio de trabajo incorrecto**: confírmelo iniciando sesión en la interfaz de PlaidCloud; el subdominio es la parte anterior a `.plaid.cloud`

Consulte la [solución de problemas de los agentes de codificación con IA](/es/integrations/ai-coding-agents/troubleshooting/) para obtener más información.
