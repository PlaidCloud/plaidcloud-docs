La integración de Jupyter de PlaidCloud permite a los científicos de datos trabajar con tablas de proyecto, ejecutar consultas y usar PlaidCloud como almacén de respaldo desde entornos de cuadernos. La autenticación usa tokens OAuth, de modo que las mismas credenciales funcionan en la CLI, en los cuadernos y en la API REST.

## Temas

- [Línea de comandos](/es/reference/cli/jupyter/command-line/): la CLI independiente para interacciones con scripts
- [Cuaderno de Jupyter](/es/reference/cli/jupyter/jupyter-notebook/): uso de PlaidCloud desde las celdas de un cuaderno
- [Configuración de OAuth](/es/reference/cli/jupyter/oauth-setup/): configuración de la autenticación
