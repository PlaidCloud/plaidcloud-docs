PlaidXL agrega a Excel funciones que leen datos de PlaidCloud directamente en las celdas. Escriba `=PLAIDXL.` en una celda y el autocompletado de Excel las lista, con una breve descripción de cada argumento.

| Grupo | Funciones | Úselas para |
|---|---|---|
| Listas | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Ver qué hay disponible para empezar a trabajar |
| Tablas | [`TABLE.GET_TABLE`](#get_table) | Leer una tabla completa en un rango |
| Jerarquías | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Distribuir los nodos de una dimensión como filas de un informe |
| Valores | [`CELL`](#cell), [`CELLS`](#cells) | Calcular un valor acumulado para cualquier combinación de nodos |
| Bloques de construcción | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Describir la tabla, la medida, la agregación, los nodos y la profundidad de despliegue que usan `CELL`, `CELLS` y `DRILL` |

[Crear un informe con funciones personalizadas](/es/reference/cli/plaidxl/build-a-report/) muestra estas funciones trabajando juntas.

## Cómo funcionan las funciones

- **Inicie sesión primero.** Las funciones leen con su inicio de sesión de PlaidCloud, así que [inicie sesión](/es/reference/cli/plaidxl/connect/) desde el panel de tareas antes de usarlas.
- **Leen del proyecto seleccionado.** Cada función lee del proyecto seleccionado en el panel de tareas. `GET_TABLE`, `TBL_LIST` y `DIM_LIST` también aceptan un ID de proyecto opcional, para leer otro proyecto sin cambiar la selección. La selección es compartida por todos los libros que tenga abiertos.
- **Los resultados se desbordan.** Una función que devuelve una lista o una tabla rellena las celdas situadas debajo (o a la derecha). Deje espacio para los resultados; si algo lo impide, Excel muestra un error `#SPILL!`.
- **Recalcule para obtener los cambios.** Una fórmula de PlaidXL vuelve a obtener los datos cuando cambia uno de sus argumentos. Para obtener datos nuevos de PlaidCloud, o un proyecto distinto seleccionado en el panel de tareas, fuerce un recálculo completo; en Windows, presione **Ctrl+Alt+F9**. **Refresh All Tables** actualiza las tablas recuperadas, no las fórmulas.
- **Use los nombres exactos.** Escriba los nombres de tablas, columnas, dimensiones y nodos exactamente como aparecen en PlaidCloud.

Los argumentos entre corchetes son opcionales.

## Listas

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Lista los nombres de los proyectos que puede abrir, ordenados por nombre.

- `horizontal`: `TRUE` para listarlos en una fila. El valor predeterminado es `FALSE`, una columna.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Lista los nombres de las tablas de un proyecto, ordenados por nombre.

- `project_id`: el proyecto que se va a leer. De forma predeterminada, el proyecto seleccionado en el panel de tareas.
- `horizontal`: `TRUE` para listarlas en una fila. El valor predeterminado es `FALSE`, una columna.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Lista los nombres de las columnas de una tabla del proyecto seleccionado.

- `table_name`: el nombre de la tabla en PlaidCloud.
- `column_filter`: un tipo de datos, como `"text"`, para listar solo las columnas de ese tipo. Omítalo para listar todas las columnas.
- `orientation`: `"vertical"` (el valor predeterminado) para una columna, o `"horizontal"` para una fila.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Lista los nombres de las dimensiones de un proyecto.

- `project_id`: el proyecto que se va a leer. De forma predeterminada, el proyecto seleccionado en el panel de tareas.
- `horizontal`: `TRUE` para listarlas en una fila. El valor predeterminado es `FALSE`, una columna.

## Tablas

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Devuelve las filas de una tabla con una fila de encabezado, desbordadas desde la celda de la fórmula. Los valores vacíos se devuelven como celdas en blanco.

- `table_name`: el nombre de la tabla en PlaidCloud.
- `project_id`: el proyecto que se va a leer. De forma predeterminada, el proyecto seleccionado en el panel de tareas.
- `limit`: el máximo de filas que se devuelven. El valor predeterminado es 1,048,575, el máximo que cabe en una hoja de cálculo debajo de una fila de encabezado.

`GET_TABLE` devuelve todas las columnas. Para elegir columnas o filtrar filas, [recupere la tabla desde el panel de tareas](/es/reference/cli/plaidxl/retrieve/#recuperar-una-tabla).

## Jerarquías

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Distribuye los nodos de una dimensión, empezando en `start_node` y descendiendo por sus descendientes. Cada generación tiene una sangría de cuatro espacios más que su elemento principal, y los grupos de esquema de Excel le permiten contraer y expandir cada nivel.

- `dimension_name`: el nombre de la dimensión, o su ruta en el proyecto.
- `start_node`: el nodo desde el que empezar, como la raíz de la dimensión.
- `hierarchy`: la [jerarquía alternativa](/es/guides/dimensions/dimensions/#jerarquías-alternativas-de-atributos) que se sigue. El valor predeterminado es `"main"`.
- `orientation`: `"vertical"` (el valor predeterminado) para listar los nodos hacia abajo en una columna, o `"horizontal"` para listarlos en una fila.
- `generation_limit`: cuántas generaciones se devuelven, contando `start_node` como la primera: `2` devuelve el nodo inicial y sus elementos secundarios. Omítalo para devolver todas las generaciones.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

Devuelve `start_node` y los nodos situados debajo que solicita `drill_key`, hacia abajo en una columna, con sangría por generación y agrupados en un esquema de Excel.

- `dimension_name`: el nombre de la dimensión, o su ruta en el proyecto.
- `start_node`: el nodo desde el que se despliega.
- `drill_key`: hasta dónde se despliega, según [`DRILL_KEY`](#drill_key): todos los descendientes, solo las hojas o un número de niveles.
- `hierarchy`: la jerarquía alternativa que se sigue. El valor predeterminado es `"main"`.

Por ejemplo, `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` lista **Total** seguido de todas las regiones hoja que hay debajo.

Los [comandos de despliegue de la cinta de opciones](/es/reference/cli/plaidxl/ribbon/#drill-functions) hacen lo mismo con una dimensión y un nodo que haya escrito en dos celdas, sin escribir una fórmula.

## Valores

`CELL` y `CELLS` calculan una medida (una columna numérica de una tabla) acumulada hasta los nodos que elija en una o más dimensiones. Piense en cada llamada como una intersección de un informe: **Ingresos** de **EMEA** en **FY2026**.

Usted describe la intersección con las funciones de bloque de construcción que aparecen a continuación, normalmente en celdas propias, y luego pasa esas celdas a `CELL` o `CELLS` en cualquier orden:

| Argumento | Se crea con | Obligatorio |
|---|---|---|
| La tabla que se lee | [`TABLE_REPR`](#table_repr) | Exactamente uno |
| La columna que se agrega | [`MEASURE`](#measure) para `CELL`, [`MEASURES`](#measures) o varias celdas `MEASURE` para `CELLS` | Sí |
| Cómo se agrega | [`MEASURE_TYPE`](#measure_type) | No; el valor predeterminado es `sum` |
| Un filtro sobre una columna | [`DIMENSION_REPR`](#dimension_repr) | Al menos uno, uno por columna |

Cada filtro nombra una **columna de la tabla** y un valor. Cuando esa columna está vinculada a una dimensión en PlaidCloud, el valor es un nodo, y el filtro incluye todo lo que se acumula hasta ese nodo en la jerarquía principal de la dimensión: en una columna **Region** vinculada a una dimensión de geografía, el nodo **EMEA** abarca todos los países que hay debajo. En una columna que no está vinculada a una dimensión, el filtro coincide exactamente con el valor.

Los ejemplos de esta página usan una tabla cuyas columnas **Region** y **Period** están vinculadas a dimensiones. Use los nombres de columna de su propia tabla.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Devuelve un número: la medida, agregada en las filas que quedan bajo todos los nodos que pase.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` muestra los ingresos totales de EMEA en FY2026.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Igual que `CELL`, pero para varias medidas a la vez. Devuelve un número por medida, hacia abajo en una columna, en el orden en que las indicó.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` pasa todo el resultado desbordado de `MEASURES`. `B2:B4` muestran los ingresos, el costo y las unidades de EMEA en FY2026.

## Bloques de construcción

Estas funciones no leen datos por sí mismas. Cada una devuelve un breve fragmento de texto que describe una parte de un cálculo, listo para pasarlo a `CELL`, `CELLS` o `DRILL`. Colóquelas en celdas a las que haga referencia, de modo que un solo cambio (por ejemplo, un período distinto) actualice todas las fórmulas que las usan.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

La tabla de la que leen `CELL` y `CELLS`, por su nombre en el proyecto seleccionado.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

La columna numérica que agrega `CELL`.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Varias columnas de medida para `CELLS`, a partir de un rango de celdas que contienen nombres de columna. El resultado se desborda en una celda por columna; páselo a `CELLS` con el operador de desbordamiento, como `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Cómo se agrega la medida. `agg_function` es uno de los siguientes valores, en minúsculas:

| Valor | Devuelve |
|---|---|
| `sum` | El total (el valor predeterminado cuando no se pasa un tipo de medida) |
| `mean` | El promedio |
| `median` | El valor central |
| `min` | El valor más pequeño |
| `max` | El valor más grande |
| `std` | La desviación estándar |
| `var` | La varianza |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

Un filtro para `CELL` y `CELLS`. Pase uno por cada columna por la que desee filtrar.

- `dimension_name`: el nombre de una **columna de la tabla**, la columna que contiene los valores de la dimensión, como `"Region"`. Debe coincidir exactamente con el nombre de la columna; una columna que no está en la tabla devuelve un error.
- `start_node`: el nodo hasta el que se acumula, como `"EMEA"`. En una columna que no está vinculada a una dimensión, el valor con el que debe coincidir.

Haga referencia a una celda para el nodo a fin de crear una cuadrícula: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Los espacios iniciales y finales se ignoran, por lo que puede apuntar a los nombres de nodo con sangría que distribuye `DRILL`.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Hasta dónde llega [`DRILL`](#drill) por debajo de su nodo inicial. `d_key` es texto sin formato:

| `d_key` | Se despliega hasta |
|---|---|
| `"all"` | Todos los descendientes |
| `"leaves"` | Solo las hojas: nodos sin nada debajo |
| `"1 level"`, `"2 levels"`, … | Esa cantidad de generaciones hacia abajo |

Escriba el número con dígitos: `"2 levels"`, no `"two levels"`. Un `drill` inicial se ignora, de modo que `"drill 2 levels"` también funciona.

Con dos o más niveles, `DRILL` lista una generación cada vez (todos los elementos secundarios, luego todos los nietos) en lugar de cada nodo directamente bajo su elemento principal. Para un diseño anidado, use `"all"` o [`GET_DIMENSION`](#get_dimension) con un `generation_limit`.

<Aside type="note">
`CELL`, `CELLS` y `DRILL` esperan la salida de estas funciones de bloque de construcción. Cree cada argumento con su función en lugar de escribir el texto usted mismo.
</Aside>
