PlaidXL agrega a Excel funciones que leen datos de PlaidCloud directamente en las celdas. Escriba `=PLAIDXL.` en una celda y el autocompletado de Excel las enumera, con una breve descripción de cada argumento. La pestaña **Formulas** del panel de tareas también puede escribir una por usted; consulte [Insertar una fórmula desde el panel de tareas](#insertar-una-fórmula-desde-el-panel-de-tareas).

| Grupo | Funciones | Úselas para |
|---|---|---|
| Listas | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Ver qué hay disponible para crear informes |
| Tablas | [`TABLE.GET_TABLE`](#get_table) | Leer una tabla completa en un rango |
| Jerarquías | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Distribuir los nodos de una dimensión como filas de un informe |
| Valores | [`CELL`](#cell), [`CELLS`](#cells) | Calcular un valor acumulado para cualquier combinación de nodos |
| Componentes básicos | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Describir la tabla, la medida, la agregación, los nodos y la profundidad de despliegue que usan `CELL`, `CELLS` y `DRILL` |

[Crear un informe con funciones personalizadas](/es/reference/cli/plaidxl/build-a-report/) muestra cómo funcionan en conjunto.

## Cómo funcionan las funciones

- **Inicie sesión primero.** Las funciones leen con su inicio de sesión de PlaidCloud, así que [inicie sesión](/es/reference/cli/plaidxl/connect/) desde el panel de tareas antes de usarlas.
- **Leen del proyecto del libro.** Cada función lee del proyecto vinculado al libro en el panel de tareas. `GET_TABLE`, `TBL_LIST` y `DIM_LIST` también aceptan un ID de proyecto opcional, para leer otro proyecto sin cambiar el vínculo. Cada libro tiene su propio proyecto, de modo que dos libros abiertos pueden leer de proyectos distintos.
- **Los resultados se derraman.** Una función que devuelve una lista o una tabla rellena las celdas situadas debajo (o a su derecha). Deje espacio para los resultados; si hay algo en el camino, Excel muestra un error `#SPILL!`.
- **Recalcule para recoger los cambios.** Una fórmula de PlaidXL vuelve a obtener los datos cuando cambia uno de sus argumentos. Para recoger datos nuevos de PlaidCloud, o un proyecto distinto vinculado en el panel de tareas, fuerce un recálculo completo; en Windows, presione **Ctrl+Alt+F9**. **Refresh All Tables** actualiza las tablas recuperadas, no las fórmulas.
- **Use nombres exactos.** Escriba los nombres de tablas, columnas, dimensiones y nodos exactamente como aparecen en PlaidCloud.

Los argumentos entre corchetes son opcionales.

## Listas

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Enumera los nombres de los proyectos que puede abrir, ordenados por nombre.

- `horizontal`: `TRUE` para enumerar a lo largo de una fila. De forma predeterminada es `FALSE`, una columna.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Enumera los nombres de las tablas de un proyecto, ordenados por nombre.

- `project_id`: el proyecto que se va a leer. De forma predeterminada es el proyecto del libro.
- `horizontal`: `TRUE` para enumerar a lo largo de una fila. De forma predeterminada es `FALSE`, una columna.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Enumera los nombres de las columnas de una tabla del proyecto seleccionado.

- `table_name`: el nombre de la tabla en PlaidCloud.
- `column_filter`: un tipo de datos, como `"text"`, para enumerar solo las columnas de ese tipo. Omítalo para enumerar todas las columnas.
- `orientation`: `"vertical"` (el valor predeterminado) para una columna, o `"horizontal"` para una fila.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Enumera los nombres de las dimensiones de un proyecto.

- `project_id`: el proyecto que se va a leer. De forma predeterminada es el proyecto del libro.
- `horizontal`: `TRUE` para enumerar a lo largo de una fila. De forma predeterminada es `FALSE`, una columna.

## Tablas

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Devuelve las filas de una tabla con una fila de encabezado, derramadas desde la celda de la fórmula. Los valores vacíos se devuelven como celdas en blanco.

- `table_name`: el nombre de la tabla en PlaidCloud.
- `project_id`: el proyecto que se va a leer. De forma predeterminada es el proyecto del libro.
- `limit`: el máximo de filas que se devuelven. De forma predeterminada es 1.048.575, el máximo que cabe en una hoja de cálculo debajo de una fila de encabezado.

`GET_TABLE` devuelve todas las columnas. Para elegir columnas o filtrar filas, [recupere la tabla desde el panel de tareas](/es/reference/cli/plaidxl/retrieve/#recuperar-una-tabla).

## Jerarquías

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Distribuye los nodos de una dimensión, empezando en `start_node` y descendiendo por sus descendientes. Cada generación tiene una sangría de cuatro espacios más que su elemento principal, y los grupos de esquema de Excel permiten contraer y expandir cada nivel.

- `dimension_name`: el nombre de la dimensión o su ruta en el proyecto.
- `start_node`: el nodo desde el que se empieza, como la raíz de la dimensión.
- `hierarchy`: la [jerarquía alternativa](/es/guides/dimensions/dimensions/#jerarquías-alternativas-de-atributos) que se sigue. De forma predeterminada es `"main"`.
- `orientation`: `"vertical"` (el valor predeterminado) para enumerar los nodos hacia abajo por una columna, o `"horizontal"` para enumerarlos a lo largo de una fila.
- `generation_limit`: cuántas generaciones se devuelven, contando `start_node` como la primera: `2` devuelve el nodo inicial y sus elementos secundarios. Omítalo para devolver todas las generaciones.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

Devuelve `start_node` y los nodos situados debajo que solicita `drill_key`, hacia abajo por una columna, con sangría por generación y agrupados en un esquema de Excel.

- `dimension_name`: el nombre de la dimensión o su ruta en el proyecto.
- `start_node`: el nodo desde el que se despliega.
- `drill_key`: hasta dónde se despliega, de [`DRILL_KEY`](#drill_key): todos los descendientes, solo las hojas, un número de niveles o un rango de generaciones.
- `hierarchy`: la jerarquía alternativa que se sigue. De forma predeterminada es `"main"`.

Por ejemplo, `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` enumera **Total** seguido de cada región hoja situada debajo.

Los [comandos de expansión de la cinta de opciones](/es/reference/cli/plaidxl/ribbon/#funciones-de-despliegue) hacen lo mismo para una dimensión y un nodo que haya escrito en dos celdas, sin escribir una fórmula.

## Valores

`CELL` y `CELLS` calculan una medida (una columna numérica de una tabla) acumulada hasta los nodos que elija en una o más dimensiones. Piense en cada llamada como una intersección de un informe: **Ingresos** de **EMEA** en **FY2026**.

Usted describe la intersección con las funciones de componentes básicos que aparecen a continuación, normalmente en sus propias celdas, y luego pasa esas celdas a `CELL` o `CELLS` en cualquier orden:

| Argumento | Se crea con | Obligatorio |
|---|---|---|
| La tabla que se lee | [`TABLE_REPR`](#table_repr) | Exactamente uno |
| La columna que se agrega | [`MEASURE`](#measure) para `CELL`, [`MEASURES`](#measures) o varias celdas `MEASURE` para `CELLS` | Sí |
| Cómo se agrega | [`MEASURE_TYPE`](#measure_type) | No: de forma predeterminada es `sum` |
| Un filtro sobre una columna | [`DIMENSION_REPR`](#dimension_repr) | Al menos uno, uno por columna |

Cada filtro nombra una **columna de la tabla** y un valor. Cuando esa columna está vinculada a una dimensión en PlaidCloud, el valor es un nodo y el filtro incluye todo lo que se acumula en ese nodo en la jerarquía principal de la dimensión: en una columna **Region** vinculada a una dimensión de geografía, el nodo **EMEA** abarca todos los países situados debajo. En una columna que no está vinculada a una dimensión, el filtro coincide exactamente con el valor.

Los ejemplos de esta página utilizan una tabla cuyas columnas **Region** y **Period** están vinculadas a dimensiones. Utilice los nombres de columna de su propia tabla.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Devuelve un número: la medida, agregada sobre las filas que quedan bajo cada nodo que pase.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` muestra los ingresos totales de EMEA en FY2026.

Una hoja llena de fórmulas `CELL` se recalcula rápidamente: cuando un recálculo solicita muchos valores de la misma tabla, PlaidXL los envía juntos a PlaidCloud en lugar de hacer una solicitud por celda. Si no se puede calcular un valor, la celda muestra `#VALUE!` y, al pasar el puntero sobre ella, se muestra el motivo tal como lo informó PlaidCloud, por ejemplo una columna de filtro que no está en la tabla o un nodo sin miembros. `CELLS` muestra el primer motivo para todo el resultado.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Como `CELL`, pero para varias medidas a la vez. Devuelve un número por medida, hacia abajo por una columna, en el orden en que las enumeró.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` pasa todo el resultado derramado de `MEASURES`. `B2:B4` muestran ingresos, costo y unidades de EMEA en FY2026.

## Componentes básicos

Estas funciones no leen datos por sí mismas. Cada una devuelve un breve fragmento de texto que describe una parte de un cálculo, listo para pasarlo a `CELL`, `CELLS` o `DRILL`. Colóquelas en celdas a las que haga referencia, de modo que un solo cambio (un período distinto, por ejemplo) actualice todas las fórmulas que las usan.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

La tabla de la que leen `CELL` y `CELLS`, por su nombre en el proyecto seleccionado.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

La columna numérica que agrega `CELL`.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Varias columnas de medida para `CELLS`, a partir de un rango de celdas que contienen nombres de columna. El resultado se derrama una celda por columna; páselo a `CELLS` con el operador de derrame, como `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Cómo se agrega la medida. `agg_function` es uno de los siguientes valores, en minúsculas:

| Valor | Devuelve |
|---|---|
| `sum` | El total (el valor predeterminado cuando no se pasa un tipo de medida) |
| `mean` | El promedio |
| `median` | El valor central |
| `min` | El valor más pequeño |
| `max` | El valor más grande |
| `std` | La desviación estándar |
| `var` | La varianza |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

Un filtro para `CELL` y `CELLS`. Pase uno por cada columna por la que quiera filtrar.

- `dimension_name`: el nombre de una **columna de la tabla**, la columna que contiene los valores de la dimensión, como `"Region"`. Debe coincidir exactamente con el nombre de la columna; una columna que no está en la tabla devuelve un error.
- `start_node`: el nodo hasta el que se acumula, como `"EMEA"`. En una columna que no está vinculada a una dimensión, el valor con el que se debe coincidir.

Haga referencia a una celda para el nodo para crear una cuadrícula: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Los espacios iniciales y finales se ignoran, de modo que puede apuntar a los nombres de nodo con sangría que distribuye `DRILL`.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Hasta dónde llega [`DRILL`](#drill) por debajo de su nodo inicial. `d_key` es texto sin formato, ya sea una forma con palabras o una clave de despliegue escrita completa:

| `d_key` | Despliega hasta |
|---|---|
| `"all"` | Todos los descendientes |
| `"leaves"` | Solo las hojas, que son los nodos sin nada debajo |
| `"1 level"`, `"2 levels"`, … | Esa cantidad de generaciones hacia abajo |
| `">[...]"` | La clave de despliegue escrita completa, como en la tabla siguiente |

Escriba el número con dígitos: `"2 levels"`, no `"two levels"`. Un `drill` inicial se ignora, de modo que `"drill 2 levels"` también funciona.

Una clave escrita completa cuenta las generaciones hacia abajo desde el nodo inicial, que es la generación 0 y siempre se incluye. Los números negativos cuentan hacia arriba desde las hojas de cada rama, de modo que una jerarquía irregular funciona como cabría esperar.

| Clave | Incluye |
|---|---|
| `>[*]` o `>[:]` | Todos los nodos |
| `>[]` o `>[-1]` | Solo las hojas |
| `>[n]` | El nodo inicial y `n` generaciones por debajo. `>[0]` es solo el nodo inicial. |
| `>[a:]` | El nodo inicial, luego la generación `a` y todo lo que está por debajo |
| `>[a:b]` | El nodo inicial, luego las generaciones desde `a` hasta `b - 1` |
| `>[0:-k]` | El nodo inicial y todos los nodos que tienen al menos `k` generaciones por debajo, de modo que se omiten las últimas `k` generaciones de cada rama. `>[0:-1]` es todos los nodos excepto las hojas. |
| `>[a:-k]` | Lo mismo, empezando en la generación `a` |

Para la jerarquía `A`, con los elementos secundarios `B`, `C` y `D`, donde `B` tiene `B1` y `B2` y `C` tiene `C1`:

| Clave | Resultado |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Los nodos se enumeran en el orden de la jerarquía, cada uno bajo su propio elemento principal, y los grupos de esquema de Excel siguen el mismo orden. Los espacios dentro de una clave se ignoran. Una clave que no coincide con ninguna de estas formas devuelve un error que enumera las formas válidas.

<Aside type="caution">
`>[-1]` y `>[0:-1]` significan algo distinto que en versiones anteriores de PlaidXL, donde estaban invertidos. `>[-1]` ahora devuelve solo las hojas, y `>[0:-1]` todo excepto las hojas. Revise cualquier libro que haya escrito a mano una clave de despliegue. Las formas con palabras `"all"`, `"leaves"` y `"2 levels"` no han cambiado.
</Aside>

<Aside type="note">
`CELL`, `CELLS` y `DRILL` esperan el resultado de estas funciones de componentes básicos. Cree cada argumento con su función en lugar de escribir usted mismo el texto.
</Aside>

## Insertar una fórmula desde el panel de tareas

La pestaña **Formulas** del panel de tareas escribe una fórmula por usted. En **What do you want in the cell?**, elija una:

- **A whole table** (`GET_TABLE`): elija o escriba la tabla y, opcionalmente, un número máximo de filas.
- **One number** (`CELL`): elija o escriba la tabla, y elija **Column to total** y **How to combine the values**.
- **A list of dimension nodes** (`DRILL`): elija o escriba la dimensión y el nodo inicial, elija **All levels**, **Lowest level only** o **Down** un número de **levels**, y opcionalmente una **Alternate hierarchy**.

La vista previa de **Formula** muestra el resultado a medida que completa los campos. Haga clic en **Insert in active cell** para colocarla en la celda seleccionada, o en **Copiar** para pegarla usted mismo. Al elegir una tabla en la pestaña **Tablas** o una dimensión en la pestaña **Dimensiones**, se completa el campo correspondiente.
