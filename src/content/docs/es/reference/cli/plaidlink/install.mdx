## Descargar el agente

Consulte las versiones publicadas en [PlaidCloud.com](https://plaidcloud.com/) para **PlaidLink**

## Extraer el agente

Extraiga el archivo zip descargado en la ubicación de instalación que prefiera. Por lo general, esta ubicación será:

```bash
C:\Users\<Username here>\src\plaidlink
```

## Crear un archivo de configuración

<Aside>Si está actualizando desde una versión anterior del agente, el archivo de configuración sigue siendo válido y puede omitir este paso</Aside>

Copie el archivo `config-dist.yaml` del directorio del agente en `%ProgramData\plaidcloud\` y cambie el nombre de esta copia a `config.yaml`

*(Edite esta configuración con los valores obtenidos de PlaidCloud)*

## Instalar el servicio del agente

Ejecute el archivo `install_windows_service.bat` en el directorio de instalación del agente O BIEN

Desde un símbolo del sistema con privilegios de administrador, vaya al directorio de instalación del agente y ejecute:

```bash
.\PlaidLink.exe install
```

## Ejecutar el agente

<Aside>Para instalar un servicio de Windows se necesitan privilegios de administrador</Aside>

Escriba **`Services`** en la barra de búsqueda de Windows y abra el administrador de servicios. En la lista de servicios, busque **`PlaidCloud Agent`**.

Haga clic con el botón derecho en el servicio y seleccione **"Start"** para iniciar el agente.

## Congelar las actualizaciones

Si en algún momento desea deshabilitar la función de actualización automática del agente, abra el archivo de configuración **'yaml'** del agente,
y en el nivel raíz del archivo agregue una línea con el texto `freeze_updates: true` y reinicie el servicio del agente.

<Aside type="caution">No se recomienda deshabilitar las actualizaciones automáticas a largo plazo</Aside>
