El agente PlaidLink funciona en conjunto con el servicio de PlaidCloud. El agente PlaidLink proporciona la conexión necesaria 
para operar con sistemas a los que no se puede acceder directamente, como bases de datos y sistemas de archivos. El agente realiza una serie de acciones esenciales, entre ellas:

* Leer y escribir en bases de datos
* Leer y escribir archivos en unidades de red y servidores
* Comprobar condiciones de sensores
* Interactuar con SAP ECC y SAP S/4HANA mediante llamadas a funciones remotas (RFC)
* Interactuar con SAP Profitability and Cost Management (PCM)
* Enviar mensajes y notificaciones a sistemas remotos

## Crear un agente en PlaidCloud

La administración de agentes PlaidLink se realiza en la pestaña Analyze de PlaidCloud. El primer paso es crear una nueva instancia de agente PlaidLink en PlaidCloud.

### Para crear un nuevo agente PlaidLink

1. Seleccione la pestaña Analyze
2. Seleccione el menú de herramientas en la parte superior
3. Haga clic en Agentes de PlaidLink
4. Cree un nuevo agente con un nombre adecuado para el entorno o el servidor en el que se instalará para las operaciones remotas

### Para ver las claves pública y privada del agente

1. Haga clic en el ícono de edición para ver el formulario
2. En la parte inferior del formulario encontrará las claves pública y privada que se generaron de forma aleatoria durante el proceso de creación del agente

<Aside>Recuerde estas claves, ya que se usarán en la configuración del agente en el servidor remoto.</Aside>

### Para generar nuevas claves de forma aleatoria

1. Haga clic en el ícono de regenerar del registro del agente
2. Una vez regeneradas las claves, no olvide actualizar el archivo de configuración del agente con las nuevas claves en el servidor remoto.

<Aside>Conserve las claves pública y privada para configurar el agente remoto en el siguiente paso.</Aside>

## Acceso a la cuenta de documentos

Si el agente necesita acceso a una cuenta de documentos para cargar o descargar archivos, se le debe conceder permiso para acceder a ella.

### Para conceder acceso a la cuenta

1. En la pestaña Documentos, seleccione Administrar cuentas
2. Cuando aparezca la tabla de cuentas, haga clic en el ícono de agente de la cuenta a la que el nuevo agente debe tener derechos de carga y descarga
3. Arrastre el nuevo agente a la columna Agentes asignados
4. Guarde el formulario de control de acceso.

<Aside>Los agentes solo pueden cargar y descargar archivos si se les ha concedido acceso a una o más cuentas de documentos.</Aside>

## Acceso a la conexión de datos

Si el agente necesita acceso a una conexión de datos, como una base de datos, se le debe conceder permiso para acceder a la información de la conexión de datos externa.


### Para conceder acceso a la conexión


1. En la pestaña Analyze, seleccione el menú Tools
2. Haga clic en Conexiones de datos externas
3. Cuando aparezca la tabla de conexiones de datos, haga clic en el ícono de agente de la conexión a la que el nuevo agente debe tener derechos de uso
4. Arrastre el nuevo agente a la columna Agentes asignados y guarde el formulario de control de acceso.

<Aside>Las credenciales de conexión de datos del agente se administran en Conexiones de datos externas.</Aside>
