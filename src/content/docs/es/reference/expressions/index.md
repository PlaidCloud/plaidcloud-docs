## Dónde consultar la sintaxis canónica

PlaidCloud Lakehouse utiliza las bibliotecas de funciones SQL de los motores subyacentes. Para conocer los detalles de los argumentos de una función, sus casos límite y su comportamiento más reciente, consulte la documentación del motor junto con los ejemplos adaptados a PlaidCloud que se incluyen aquí.

- **Lakehouse v1** → [Referencia de funciones SQL de Databend](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [Referencia de funciones SQL de StarRocks](https://docs.starrocks.io/docs/sql-reference/sql-functions/) (PlaidCloud Lakehouse v2 sigue StarRocks 4.1)
