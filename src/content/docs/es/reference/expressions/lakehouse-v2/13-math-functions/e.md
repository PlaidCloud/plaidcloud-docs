Devuelve la constante matemática e (número de Euler).

## Sintaxis de Analyze

```python
func.e()
```

## Ejemplos de Analyze

```python
func.e()

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## Sintaxis de SQL

```sql
E()
```

## Ejemplos de SQL

```sql
SELECT E();

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
