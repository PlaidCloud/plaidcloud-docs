Devuelve la constante matemática pi.

## Sintaxis de Analyze

```python
func.pi()
```

## Ejemplos de Analyze

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## Sintaxis de SQL

```sql
PI()
```

## Ejemplos de SQL

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
