Devuelve la distancia de cuadrícula entre los dos índices [H3](https://eng.uber.com/h3/) dados.

<Aside>Los cálculos de distancia H3 solo pueden calcular distancias entre hexágonos vecinos. Si se usa con hexágonos que no son vecinos, se produce un error.</Aside>

### Sintaxis de Analyze

```python
func.h3_distance(h3, a_h3)
```

## Ejemplos de Analyze

```python
func.h3_distance(599119489002373119, 599119491149856767)

┌──────────────────────────────────────────────────────────┐
│ func.h3_distance(599119489002373119, 599119491149856767) │
├──────────────────────────────────────────────────────────┤
│                                                        1 │
└──────────────────────────────────────────────────────────┘
```

## Sintaxis de SQL

```sql
H3_DISTANCE(h3, a_h3)
```

## Ejemplos de SQL

```sql
SELECT H3_DISTANCE(599119489002373119, 599119491149856767);

│ h3_distance(599119489002373119, 599119491149856767) │
```
