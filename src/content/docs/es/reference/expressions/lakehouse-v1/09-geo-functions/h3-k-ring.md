Devuelve una matriz con los índices [H3](https://eng.uber.com/h3/) de los hexágonos del anillo k que rodean el índice H3 de entrada. Cada elemento de esta matriz es un índice H3.

## Sintaxis de Analyze

```python
func.h3_k_ring(h3, k)
```

## Ejemplos de Analyze

```python
func.h3_k_ring(644325524701193974, 1)

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                                  func.h3_k_ring(644325524701193974, 1)                                                 │
├────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ [644325524701193974,644325524701193899,644325524701193869,644325524701193970,644325524701193968,644325524701193972,644325524701193897] │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## Sintaxis de SQL

```sql
H3_K_RING(h3, k)
```

## Ejemplos de SQL
