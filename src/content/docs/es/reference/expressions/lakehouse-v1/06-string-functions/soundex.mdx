Genera el código Soundex de una cadena.

- Un código Soundex consta de una letra seguida de tres dígitos numéricos. La implementación de PlaidCloud Lakehouse devuelve más de 4 dígitos, pero puede aplicar [SUBSTR](../substr) al resultado para obtener un código Soundex estándar.
- Todos los caracteres no alfabéticos de la cadena se ignoran.
- Todos los caracteres alfabéticos internacionales fuera del rango A-Z se ignoran, a menos que sean la primera letra.


<Aside>¿Qué es Soundex? Soundex convierte una cadena alfanumérica en un código de cuatro caracteres basado en cómo suena la cadena cuando se pronuncia en inglés. Para obtener más información, consulte https://en.wikipedia.org/wiki/Soundex</Aside>

Consulte también: [SOUNDS LIKE](../soundslike)

## Sintaxis de Analyze

```python
func.soundex(<str>)
```

## Ejemplos de Analyze

```python
func.soundex('PlaidCloud Lakehouse')
┌──────────────────────────────────────┐
│ func.soundex('PlaidCloud Lakehouse') │
├──────────────────────────────────────┤
│ D153                                 │
└──────────────────────────────────────┘
```

## Sintaxis SQL

```sql
SOUNDEX(<str>)
```

## Argumentos

| Argumentos | Descripción |
|-----------|-------------|
| str  | La cadena. |

## Tipo de retorno

Devuelve un código de tipo VARCHAR o un valor NULL.

## Ejemplos de SQL

```sql
SELECT SOUNDEX('PlaidCloud Lakehouse');

---
D153

-- All non-alphabetic characters in the string are ignored.
SELECT SOUNDEX('PlaidCloud Lakehouse!');

---
D153

-- All international alphabetic characters outside the A-Z range are ignored unless they're the first letter.
SELECT SOUNDEX('PlaidCloud Lakehouse，你好');

---
D153

SELECT SOUNDEX('你好，PlaidCloud Lakehouse');

---
你3153

-- SUBSTR the result to get a standard Soundex code.
SELECT SOUNDEX('databend cloud'),SUBSTR(SOUNDEX('databend cloud'),1,4);

soundex('databend cloud')|substring(soundex('databend cloud') from 1 for 4)|
-------------------------+-------------------------------------------------+
D153243                  |D153                                             |

SELECT SOUNDEX(NULL);
┌─────────────────────────────────────┐
│ `SOUNDEX(NULL)`                     │
├─────────────────────────────────────┤
│ <null>                              │
└─────────────────────────────────────┘
```
