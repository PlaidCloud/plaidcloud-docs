Compara la pronunciación de dos cadenas mediante sus códigos Soundex. Soundex es un algoritmo fonético que produce un código que representa la pronunciación de una cadena, lo que permite una coincidencia aproximada de cadenas según su pronunciación en lugar de su ortografía. PlaidCloud Lakehouse ofrece la función [SOUNDEX](../soundex), que le permite obtener el código Soundex de una cadena.

SOUNDS LIKE se emplea con frecuencia en la cláusula WHERE de las consultas SQL para acotar filas mediante coincidencia difusa de cadenas, por ejemplo con nombres y direcciones; consulte [Filtrado de filas](#filtrado-de-filas) en [Ejemplos](#ejemplos-de-sql).

<Aside>Aunque la función puede ser útil para la coincidencia aproximada de cadenas, es importante tener en cuenta que no siempre es precisa. El algoritmo Soundex se basa en las reglas de pronunciación del inglés y puede no funcionar bien con cadenas de otros idiomas o dialectos.</Aside>

## Sintaxis de Analyze

```python
func.sounds_like(<str1>, <str2>)
```

## Ejemplos de Analyze

```python
func..sounds_like('Monday', 'Sunday')
┌───────────────────────────────────────┐
│ func..sounds_like('Monday', 'Sunday') │
├───────────────────────────────────────┤
│                                     0 │
└───────────────────────────────────────┘
```

## Sintaxis SQL

```sql
<str1> SOUNDS LIKE <str2>
```

## Argumentos

| Argumentos | Descripción |
|-----------|-------------|
| str1, 2   | Las cadenas que se comparan. |

## Tipo de retorno

Devuelve un valor booleano de 1 si los códigos Soundex de las dos cadenas son iguales (es decir, suenan parecido) y 0 en caso contrario.

## Ejemplos de SQL

### Comparación de cadenas

```sql
SELECT 'two' SOUNDS LIKE 'too'
----
1

SELECT CONCAT('A', 'B') SOUNDS LIKE 'AB';
----
1

SELECT 'Monday' SOUNDS LIKE 'Sunday';
----
0
```

### Filtrado de filas

```sql
SELECT * FROM  employees;

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Mark      |Smythe   | 28|
 0|Johann    |Schmidt  | 51|
 0|Eric      |Doe      | 30|
 0|Sue       |Johnson  | 45|


SELECT * FROM  employees
WHERE  first_name SOUNDS LIKE 'John';

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Johann    |Schmidt  | 51|
```
