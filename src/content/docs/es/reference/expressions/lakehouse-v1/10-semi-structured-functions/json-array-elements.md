Extrae los elementos de un arreglo JSON y los devuelve como filas individuales en el conjunto de resultados. JSON_ARRAY_ELEMENTS no expande de forma recursiva los arreglos anidados; los trata como elementos únicos.


## Sintaxis de Analyze

```python
func.json_array_elements(<json_string>)
```

## Ejemplos de Analyze

```python

func.json_array_elements(func.parse_json('[ \n  {"product": "laptop", "brand": "apple", "price": 1500},\n  {"product": "smartphone", "brand": "samsung", "price": 800},\n  {"product": "headphones", "brand": "sony", "price": 150}\n]'))
```

## Sintaxis SQL

```sql
JSON_ARRAY_ELEMENTS(<json_string>)
```

## Tipo de retorno

JSON_ARRAY_ELEMENTS devuelve un conjunto de valores VARIANT, cada uno de los cuales representa un elemento extraído del arreglo JSON de entrada.

## Ejemplos de SQL
