Función de agregado.

La función count(distinct ...) calcula el número de valores únicos de un conjunto de valores.

Para obtener un resultado estimado a partir de conjuntos de datos grandes con poca memoria y poco tiempo, considere usar [APPROX_COUNT_DISTINCT](../aggregate-approx-count-distinct).

<Aside type="caution">Los valores NULL no se cuentan.</Aside>

## Sintaxis de Analyze

```python
func.count_distinct(<column>)
```

## Ejemplos de Analyze

```python
func.count_distinct(table.category).alias('unique_categories')

| unique_categories |
|-------------------|
|         2         |
```

## Sintaxis de SQL

```sql
COUNT(distinct <expr> ...)
UNIQ(<expr>)
```

## Argumentos

| Argumentos | Descripción                                      |
|-----------|--------------------------------------------------|
| `<expr>`  | Cualquier expresión; el número de argumentos está entre 1 y 32 |

## Tipo de valor devuelto

UInt64

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**
```sql
CREATE TABLE products (
  id INT,
  name VARCHAR,
  category VARCHAR,
  price FLOAT
);

INSERT INTO products (id, name, category, price)
VALUES (1, 'Laptop', 'Electronics', 1000),
       (2, 'Smartphone', 'Electronics', 800),
       (3, 'Tablet', 'Electronics', 600),
       (4, 'Chair', 'Furniture', 150),
       (5, 'Table', 'Furniture', 300);
```

**Consulta de demostración: contar las categorías distintas**

```sql
SELECT COUNT(DISTINCT category) AS unique_categories
FROM products;
```

**Resultado**
```sql
| unique_categories |
|-------------------|
|         2         |
```
