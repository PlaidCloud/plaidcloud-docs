La función COUNT() devuelve el número de registros devueltos por una consulta SELECT.

<Aside type="caution">Los valores NULL no se cuentan.</Aside>

## Sintaxis de Analyze

```python
func.count(<column>)
```

## Ejemplos de Analyze

```python
func.count(table.grade).alias('count_valid_grades')

| count_valid_grades |
|--------------------|
|          4         |
```

## Sintaxis de SQL

```sql
COUNT(<expr>)
```

## Argumentos

| Argumentos | Descripción                                                                                                                                                     |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<expr>`  | Cualquier expresión. <br /> Puede ser el nombre de una columna, el resultado de otra función o una operación matemática.<br />También se admite `*`, para indicar un recuento puro de filas. |

## Tipo de valor devuelto

Un entero.

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**
```sql
CREATE TABLE students (
  id INT,
  name VARCHAR,
  age INT,
  grade FLOAT NULL
);

INSERT INTO students (id, name, age, grade)
VALUES (1, 'John', 21, 85),
       (2, 'Emma', 22, NULL),
       (3, 'Alice', 23, 90),
       (4, 'Michael', 21, 88),
       (5, 'Sophie', 22, 92);

```

**Consulta de demostración: contar los estudiantes con calificaciones válidas**
```sql
SELECT COUNT(grade) AS count_valid_grades
FROM students;
```

**Resultado**
```sql
| count_valid_grades |
|--------------------|
|          4         |
```
