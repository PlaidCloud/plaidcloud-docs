Función de agregado.

La función STRING_AGG() convierte a String todos los valores no NULL de una columna, separados por el delimitador.

## Sintaxis de Analyze

```python
func.string_agg(<expr> [, delimiter])
```

## Ejemplos de Analyze

```python
func.string_agg(table.language_name).alias('concatenated_languages')

|          concatenated_languages         |
|-----------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```

## Sintaxis de SQL

```sql
STRING_AGG(<expr>)
STRING_AGG(<expr> [, delimiter])
```

<Aside>Si `<expr>` no es una expresión de tipo String, debe usar `::VARCHAR` para convertirla. Por ejemplo: ```sql SELECT string_agg(number::VARCHAR, '|') AS s FROM numbers(5); ┌───────────┐ │ s │ ├───────────┤ │ 0│1│2│3│4 │ └───────────┘ ```</Aside>

## Argumentos

| Argumentos   | Descripción                                                         |
|-------------|---------------------------------------------------------------------|
| `<expr>`    | Cualquier expresión de cadena (si no es una cadena, use `::VARCHAR` para convertirla) |
| `delimiter` | String constante opcional; si no se especifica, se usa una cadena vacía        |

## Tipo de valor devuelto

El tipo String

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**

```sql
CREATE TABLE programming_languages (
  id INT,
  language_name VARCHAR
);

INSERT INTO programming_languages (id, language_name)
VALUES (1, 'Python'),
       (2, 'JavaScript'),
       (3, 'Java'),
       (4, 'C#'),
       (5, 'Ruby');
```

**Consulta de demostración: concatenar nombres de lenguajes de programación con un delimitador**
```sql
SELECT STRING_AGG(language_name, ', ') AS concatenated_languages
FROM programming_languages;
```

**Resultado**
```sql
|          concatenated_languages         |
|------------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```
