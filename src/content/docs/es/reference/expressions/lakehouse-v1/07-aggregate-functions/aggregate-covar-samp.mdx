Función de agregado.

La función covar_samp() devuelve la covarianza muestral (Σ((x - x̅)(y - y̅)) / (n - 1)) de dos columnas de datos.

<Aside type="caution">Los valores NULL no se cuentan.</Aside>

## Sintaxis de Analyze

```python
func.covar_samp(<expr1>, <expr2>)
```

## Ejemplos de Analyze

```python
func.covar_samp(table.items_sold, table.profit).alias('covar_samp_items_profit')

| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```

## Sintaxis de SQL

```sql
COVAR_SAMP(<expr1>, <expr2>)
```

## Argumentos

| Argumentos |        Descripción       |
|-----------| ------------------------ |
| `<expr1>` | Cualquier expresión numérica |
| `<expr2>` | Cualquier expresión numérica |

## Tipo de valor devuelto

float64; cuando n &lt;= 1, devuelve +∞.

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**

```sql
CREATE TABLE store_sales (
  id INT,
  store_id INT,
  items_sold INT,
  profit FLOAT
);

INSERT INTO store_sales (id, store_id, items_sold, profit)
VALUES (1, 1, 100, 1000),
       (2, 2, 200, 2000),
       (3, 3, 300, 3000),
       (4, 4, 400, 4000),
       (5, 5, 500, 5000);
```

**Consulta de demostración: calcular la covarianza muestral entre artículos vendidos y beneficio**

```sql
SELECT COVAR_SAMP(items_sold, profit) AS covar_samp_items_profit
FROM store_sales;
```

**Resultado**

```sql
| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```
