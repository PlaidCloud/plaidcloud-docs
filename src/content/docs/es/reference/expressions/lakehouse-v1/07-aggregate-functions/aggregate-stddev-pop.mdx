Función de agregado.

La función STDDEV_POP() devuelve la desviación estándar poblacional (la raíz cuadrada de VAR_POP()) de una expresión.

<Aside>También se pueden usar STD() o STDDEV(), que son equivalentes pero no son SQL estándar.</Aside>

<Aside type="caution">Los valores NULL no se cuentan.</Aside>

## Sintaxis de Analyze

```python
func.stddev_pop(<expr>)
```

## Ejemplos de Analyze

```python
func.stddev_pop(table.score).alias('test_score_stddev_pop')

| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```

## Sintaxis de SQL

```sql
STDDEV_POP(<expr>)
STDDEV(<expr>)
STD(<expr>)
```

## Argumentos

| Argumentos | Descripción              |
|-----------|--------------------------|
| `<expr>`  | Cualquier expresión numérica |

## Tipo de valor devuelto

double

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**
```sql
CREATE TABLE test_scores (
  id INT,
  student_id INT,
  score FLOAT
);

INSERT INTO test_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 85),
       (3, 3, 90),
       (4, 4, 95),
       (5, 5, 100);
```

**Consulta de demostración: calcular la desviación estándar poblacional de las calificaciones de un examen**
```sql
SELECT STDDEV_POP(score) AS test_score_stddev_pop
FROM test_scores;
```

**Resultado**
```sql
| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```
