Función de agregado.

La función QUANTILE_CONT() calcula el cuantil interpolado de una secuencia de datos numéricos.

<Aside type="caution">Los valores NULL no se cuentan.</Aside>

## Sintaxis de Analyze

```python
func.quantile_cont(<levels>, <expr>)
```

## Ejemplos de Analyze

```python
func.quantile_cont(0.5, table.sales_amount).alias('median_sales_amount')

|  median_sales_amount  |
|-----------------------|
|        6000.0         |
```

## Sintaxis de SQL

```sql
QUANTILE_CONT(<levels>)(<expr>)
    
QUANTILE_CONT(level1, level2, ...)(<expr>)
```

## Argumentos

| Argumentos   | Descripción                                                                                                                                     |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `<level(s)` | Nivel o niveles del cuantil. Cada nivel es un número de punto flotante constante de 0 a 1. Recomendamos usar un valor de nivel dentro del intervalo [0.01, 0.99]   |
| `<expr>`    | Cualquier expresión numérica                                                                                                                        |

## Tipo de valor devuelto

Float64 o matriz de float64, según el número de niveles.

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**
```sql
CREATE TABLE sales_data (
  id INT,
  sales_person_id INT,
  sales_amount FLOAT
);

INSERT INTO sales_data (id, sales_person_id, sales_amount)
VALUES (1, 1, 5000),
       (2, 2, 5500),
       (3, 3, 6000),
       (4, 4, 6500),
       (5, 5, 7000);
```

**Consulta de demostración: calcular el percentil 50 (mediana) del importe de ventas mediante interpolación**
```sql
SELECT QUANTILE_CONT(0.5)(sales_amount) AS median_sales_amount
FROM sales_data;
```

**Resultado**
```sql
|  median_sales_amount  |
|-----------------------|
|        6000.0         |
```
