Función de agregado.

La función SUM() calcula la suma de un conjunto de valores.

<Aside type="caution">Los valores NULL no se cuentan.</Aside>


## Sintaxis de Analyze

```python
func.sum(<column>)
```

## Ejemplos de Analyze

```python
func.sum(table.quantity).alias('total_quantity_sold')

| total_quantity_sold |
|---------------------|
|         41          |
```

## Sintaxis de SQL

```sql
SUM(<expr>)
```

## Argumentos

| Argumentos | Descripción              |
|-----------|--------------------------|
| `<expr>`  | Cualquier expresión numérica |

## Tipo de valor devuelto

Un double si el tipo de entrada es double; en caso contrario, un entero.

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**
```sql
CREATE TABLE sales_data (
  id INT,
  product_id INT,
  quantity INT
);

INSERT INTO sales_data (id, product_id, quantity)
VALUES (1, 1, 10),
       (2, 2, 5),
       (3, 3, 8),
       (4, 4, 3),
       (5, 5, 15);
```

**Consulta de demostración: calcular la cantidad total de productos vendidos**
```sql
SELECT SUM(quantity) AS total_quantity_sold
FROM sales_data;
```

**Resultado**
```sql
| total_quantity_sold |
|---------------------|
|         41          |
```
