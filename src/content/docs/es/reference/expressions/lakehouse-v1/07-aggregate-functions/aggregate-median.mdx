Función de agregado.

La función MEDIAN() calcula la mediana de una secuencia de datos numéricos.

<Aside type="caution">Los valores NULL no se cuentan.</Aside>

## Sintaxis de Analyze

```python
func.median(<expr>)
```

## Ejemplos de Analyze

```python
func.median(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## Sintaxis de SQL

```sql
MEDIAN(<expr>)
```

## Argumentos

| Argumentos | Descripción              |
|-----------|--------------------------|
| `<expr>`  | Cualquier expresión numérica |

## Tipo de valor devuelto

El tipo del valor.

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**
```sql
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);
```

**Consulta de demostración: calcular la mediana de las calificaciones de un examen**
```sql
SELECT MEDIAN(score) AS median_score
FROM exam_scores;
```

**Resultado**
```sql
|  median_score  |
|----------------|
|      85.0      |
```
