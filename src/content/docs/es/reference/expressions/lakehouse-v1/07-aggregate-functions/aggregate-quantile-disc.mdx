Función de agregado.

La función `QUANTILE_DISC()` calcula el cuantil exacto de una secuencia de datos numéricos.
`QUANTILE` es un alias de `QUANTILE_DISC`.

<Aside type="caution">Los valores NULL no se cuentan.</Aside>

## Sintaxis de Analyze

```python
func.quantile_disc(<levels>, <expr>)
```

## Ejemplos de Analyze

```python
func.quantile_disc([0.25, 0.75], table.salary).alias('salary_quantiles')

|  salary_quantiles   |
|---------------------|
| [55000.0, 65000.0]  |
```

## Sintaxis de SQL

```sql
QUANTILE_DISC(<levels>)(<expr>)
    
QUANTILE_DISC(level1, level2, ...)(<expr>)
```

## Argumentos

| Argumentos  | Descripción                                                                                                                                   |
|------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| `level(s)` | Nivel o niveles del cuantil. Cada nivel es un número de punto flotante constante de 0 a 1. Recomendamos usar un valor de nivel dentro del intervalo [0.01, 0.99] |
| `<expr>`   | Cualquier expresión numérica                                                                                                                      |

## Tipo de valor devuelto

InputType o matriz de InputType, según el número de niveles.

## Ejemplos de SQL

**Cree una tabla e inserte datos de ejemplo**
```sql
CREATE TABLE salary_data (
  id INT,
  employee_id INT,
  salary FLOAT
);

INSERT INTO salary_data (id, employee_id, salary)
VALUES (1, 1, 50000),
       (2, 2, 55000),
       (3, 3, 60000),
       (4, 4, 65000),
       (5, 5, 70000);
```

**Consulta de demostración: calcular los percentiles 25 y 75 de los salarios**
```sql
SELECT QUANTILE_DISC(0.25, 0.75)(salary) AS salary_quantiles
FROM salary_data;
```

**Resultado**
```sql
|  salary_quantiles   |
|---------------------|
| [55000.0, 65000.0]  |
```
