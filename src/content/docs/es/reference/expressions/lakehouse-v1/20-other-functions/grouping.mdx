Devuelve una máscara de bits que indica qué expresiones de `GROUP BY` no están incluidas en el conjunto de agrupación actual. Los bits se asignan de modo que el argumento situado más a la derecha corresponde al bit menos significativo; cada bit es 0 si la expresión correspondiente está incluida en los criterios de agrupación del conjunto de agrupación que genera la fila de resultado actual, y 1 si no lo está.

## Sintaxis de SQL

```sql
GROUPING ( expr [, expr, ...] )
```

<Aside>`GROUPING` solo se puede usar con `GROUPING SETS`, `ROLLUP` o `CUBE`, y sus argumentos deben estar en la lista de conjuntos de agrupación.</Aside>

## Argumentos

Elementos de los conjuntos de agrupación.

## Tipo de retorno

UInt32.

## Ejemplos de SQL

```sql
select a, b, grouping(a), grouping(b), grouping(a,b), grouping(b,a) from t group by grouping sets ((a,b),(a),(b), ()) ;
┌──────┬──────┬─────────────┬─────────────┬────────────────┬────────────────┐
│ a    │ b    │ grouping(a) │ grouping(b) │ grouping(a, b) │ grouping(b, a) │
├──────┼──────┼─────────────┼─────────────┼────────────────┼────────────────┤
│ NULL │ A    │           1 │           0 │              2 │              1 │
│ a    │ NULL │           0 │           1 │              1 │              2 │
│ b    │ A    │           0 │           0 │              0 │              0 │
│ NULL │ NULL │           1 │           1 │              3 │              3 │
│ a    │ A    │           0 │           0 │              0 │              0 │
│ b    │ B    │           0 │           0 │              0 │              0 │
│ b    │ NULL │           0 │           1 │              1 │              2 │
│ a    │ B    │           0 │           0 │              0 │              0 │
│ NULL │ B    │           1 │           0 │              2 │              1 │
└──────┴──────┴─────────────┴─────────────┴────────────────┴────────────────┘
```
