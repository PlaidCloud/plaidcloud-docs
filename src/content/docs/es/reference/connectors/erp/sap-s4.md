S/4HANA no tiene un conector propio. Comparte un tipo de conexión con SAP ECC, porque PlaidCloud accede a ambos mediante la misma interfaz de llamadas a funciones remotas. En la pantalla **Conexiones**, elija **Nuevo → Instancia de SAP ECC / S/4HANA**.

**[Conector de SAP ECC y S/4HANA →](/es/reference/connectors/erp/sap-ecc/)**: todos los campos de configuración, para ambas generaciones.

## Documentación del proveedor

Consulte la [documentación de SAP S/4HANA](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE).
