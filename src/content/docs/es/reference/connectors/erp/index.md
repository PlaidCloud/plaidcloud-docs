PlaidCloud ofrece conectores dedicados para los principales sistemas ERP empresariales. Cada ERP expone los datos mediante su propia combinación de protocolos (RFC, SOAP, REST o acceso directo a la base de datos), por lo que cada conector encapsula el patrón adecuado para ese proveedor.

## SAP

- [SAP ECC / S/4HANA](/es/reference/connectors/erp/sap-ecc/) — un único tipo de conexión sirve para ambos
- [SAP S/4HANA](/es/reference/connectors/erp/sap-s4/)
- [SAP Analytics Cloud (SAC)](/es/reference/connectors/erp/sap-sac/)
- [SAP Profitability and Performance Management (PaPM)](/es/reference/connectors/erp/sap-papm/)
- [SAP Profitability and Cost Management (PCM)](/es/reference/connectors/erp/sap-pcm/)
