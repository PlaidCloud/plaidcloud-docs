PlaidCloud Lakehouse puede federar consultas directamente contra formatos de tabla abierta, lo que le permite consultar los datos donde están sin tener que moverlos primero a PlaidCloud. Es útil para combinar datos del lakehouse con lagos de datos externos que ya se administran en Iceberg, Delta Lake o Hudi.

## Formatos

- [Apache Iceberg](/es/reference/connectors/open-tables/iceberg/)
- [Delta Lake](/es/reference/connectors/open-tables/delta-lake/)
- [Apache Hudi](/es/reference/connectors/open-tables/hudi/)
- [Apache Hive](/es/reference/connectors/open-tables/hive/) — formato de tabla abierta de Hive (distinto del [conector del motor de consultas de Hive](/es/reference/connectors/databases/hive/))
