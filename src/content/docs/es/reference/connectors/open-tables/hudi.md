## Documentación del catálogo
[Documentación de Apache Hudi](https://hudi.apache.org/docs/overview/).

## Configuración inicial

Este conector utiliza un flujo de autenticación específico del proveedor y se configura directamente desde la pantalla **Conexiones** de su espacio de trabajo. Los campos de configuración que se muestran dependen de las credenciales que el administrador de su inquilino haya aprovisionado para la integración.

Consulte la [documentación de hudi](https://hudi.apache.org/docs/overview/) del proveedor para conocer los detalles de configuración más recientes.

Si necesita ayuda para configurar este conector en su inquilino, comuníquese con su equipo de cuenta: las credenciales específicas del conector, las URL de los entornos y cualquier aprovisionamiento previo necesario suelen requerir coordinación con el soporte de PlaidCloud.
