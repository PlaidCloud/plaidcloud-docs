## Documentación de la API
La [referencia de la API del proveedor](https://developers.paycor.com/explore) cubre los puntos de conexión de este conector.

## Configuración de Paycor
El proceso de solicitud e inicio de la aplicación de API de Paycor es algo más complejo que el de otros proveedores REST. Asegúrese de seguir los pasos descritos en su [página de inicio rápido](https://developers.paycor.com/guides#quickStartLabel).

Los valores clave que debe anotar son:
 - ID de cliente de OAuth de la aplicación
 - Secreto de cliente de OAuth de la aplicación
 - Clave de suscripción de APIm
 - Clave de ámbito de la versión `current` de la aplicación

<Aside type="caution">No olvide “activar” la aplicación para permitir su uso</Aside>

Actívela aquí, eligiendo Producción o Sandbox según lo que necesite:

| Entorno | URL del formulario de activación |
|-------------|---------------------|
| Sandbox	  | https://hcm-demo.paycor.com/AppActivation/ClientActivation |
| Producción  | https://hcm.paycor.com/AppActivation/ClientActivation |

<Aside type="danger">Si tiene varias organizaciones en Paycor, necesitará inicios de sesión distintos para cada una. NO los combine. El portal para desarrolladores necesita un inicio de sesión único y dedicado para cada organización con el fin de crear una aplicación específica de la organización para el acceso REST.</Aside>

## Configuración

Estos campos aparecen al crear o editar esta conexión.

### Identificación

| Campo | Tipo | Descripción |
|---|---|---|
| Nombre | Texto | Nombre para mostrar de esta conexión. |
| Alias | Texto (varias líneas) | Alias o notas opcionales sobre la conexión. |
| Está activa | Interruptor | Indica si la conexión está habilitada. Deshabilítela para pausarla sin eliminarla. |
| Solo lectura de BD | Interruptor | Restringe la conexión a operaciones de solo lectura. |
| Tipo de acceso | Selección | Nivel de acceso de solo lectura, solo escritura o lectura y escritura para esta conexión. |

### Credenciales

Introduzca los tres valores que anotó durante la [configuración de Paycor](#configuración-de-paycor). No necesita introducir un host ni una URL de token: PlaidCloud proporciona el host de la API de Paycor y el punto de conexión de token de OAuth2.

| Campo | Tipo | Descripción |
|---|---|---|
| ID de cliente de OAuth2 | Texto | El ID de cliente de OAuth de la aplicación de su registro de aplicación de Paycor. |
| Secreto de cliente de OAuth2 | Contraseña | El secreto de cliente de OAuth de la aplicación. Se almacena cifrado. |
| Clave de suscripción de Paycor | Texto | La clave de suscripción de APIm de su aplicación de Paycor. |

## Autenticación

Paycor usa OAuth2 con una concesión de código de autorización, por lo que introducir las credenciales es solo la primera mitad: también debe completar un inicio de sesión único con Paycor que autorice a PlaidCloud a extraer sus datos.

1. **Introduzca las credenciales y guarde.** Complete los tres valores anteriores y guarde la conexión.
2. **Conecte.** Haga clic en **Conectar con Paycor**. PlaidCloud abre una **ventana de autorización de Paycor**. El botón está disponible una vez guardada la conexión.
3. **Inicie sesión y apruebe.** Inicie sesión en Paycor en esa ventana y apruebe el acceso. Paycor lo devuelve a PlaidCloud, que almacena un **token de actualización** en la conexión y lo usa para obtener tokens de acceso automáticamente a partir de ese momento.

<Aside type="caution">Permita las ventanas emergentes para PlaidCloud. Si se bloquea la ventana de autorización, PlaidCloud se lo indica: permita las ventanas emergentes y haga clic de nuevo en **Conectar con Paycor**.</Aside>

PlaidCloud administra el host de la API (`apis.paycor.com`) y el punto de conexión de token (`https://apis.paycor.com/sts/v1/common/token`). No hay campos de URL que completar y no debería necesitar editarlos.

### Volver a autorizar una conexión caducada

El acceso a Paycor puede caducar: el token de actualización expira o se revoca, o la aplicación de Paycor se desactiva. Cuando eso ocurre, los flujos de trabajo que usan la conexión dejan de autenticarse y fallan. Para restaurarla:

1. Confirme que la aplicación de Paycor sigue **activada** (consulte las URL de activación en [Configuración de Paycor](#configuración-de-paycor)).
2. Abra la conexión y haga clic en **Conectar con Paycor** para ejecutar de nuevo la autorización de Paycor, luego inicie sesión y apruebe. Esto genera un nuevo token de actualización y la conexión se reanuda.

<Aside type="danger">Establezca y repare las conexiones de Paycor mediante este formulario de conexión. Editar la conexión subyacente mediante un editor REST genérico o la API puede sobrescribir la URL de token administrada y romper la autenticación.</Aside>
