PlaidCloud se conecta a los servicios de Google mediante cuentas de servicio de Google Cloud (BigQuery) y OAuth (Google Sheets). Cada conector se dirige a una familia de productos de Google específica.

## Proveedores

- [BigQuery](/es/reference/connectors/google/big-query/) — el almacén de datos en la nube de Google
- [Google Sheets](/es/reference/connectors/google/gspread/) — leer y escribir datos de hojas de cálculo
