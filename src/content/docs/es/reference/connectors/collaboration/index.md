PlaidCloud se conecta a plataformas de chat de equipo para que los flujos de trabajo puedan enviar notificaciones, alertas o actualizaciones de estado directamente a los canales que su equipo ya está siguiendo. Se usa con mayor frecuencia junto con los pasos de flujo de trabajo [Notify via Slack](/es/reference/workflow-steps/notifications/notify-via-slack/) y [Notify via Microsoft Teams](/es/reference/workflow-steps/notifications/notify-via-microsoft-teams/).
