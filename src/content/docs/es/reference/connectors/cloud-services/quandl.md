## Documentación de la conexión
[Quandl es ahora Nasdaq Data Link. La documentación](https://docs.data.nasdaq.com/).

## Configuración

Este conector usa un flujo de autenticación específico del proveedor y se configura directamente desde la pantalla **Conexiones** de su espacio de trabajo. Los campos de configuración que se muestran dependen de las credenciales que el administrador de su tenant haya aprovisionado para la integración.

Consulte la [documentación de quandl](https://docs.data.nasdaq.com/) del proveedor para conocer los detalles de configuración más recientes.

Si necesita ayuda para configurar este conector para su tenant, comuníquese con su equipo de cuenta: las credenciales específicas del conector, las URL de entorno y cualquier aprovisionamiento previo necesario normalmente deben coordinarse con el soporte de PlaidCloud.
