**Apache Doris** es la base de datos analítica MPP de alto rendimiento de la que se bifurcó StarRocks. Use este conector para consultar implementaciones de Doris desde los flujos de trabajo de PlaidCloud. La conexión usa el protocolo de red de MySQL con autenticación estándar de usuario y contraseña.

## Documentación del proveedor
[Documentación de Apache Doris](https://doris.apache.org/docs/4.x/gettingStarted/what-is-apache-doris).

La [página principal del proyecto Apache Doris](https://doris.apache.org/).

## Configuración

Este conector usa un flujo de autenticación específico del proveedor y se configura directamente desde la pantalla **Conexiones** de su espacio de trabajo. Los campos de configuración que se muestran dependen de las credenciales que el administrador de su tenant haya aprovisionado para la integración.

Consulte la [documentación de doris](https://doris.apache.org/docs/) del proveedor para conocer los detalles de configuración más recientes.

Si necesita ayuda para configurar este conector para su tenant, comuníquese con su equipo de cuenta: las credenciales específicas del conector, las URL de entorno y cualquier aprovisionamiento previo necesario normalmente deben coordinarse con el soporte de PlaidCloud.
