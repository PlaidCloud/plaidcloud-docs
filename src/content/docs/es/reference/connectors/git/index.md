PlaidCloud se conecta a hosts de Git para que los flujos de trabajo y las aplicaciones de Panel puedan leer de repositorios con control de versiones. Es útil para obtener configuración, scripts o archivos con plantillas que residen en el control de código fuente en lugar de en una base de datos o una cuenta de documentos.

## Proveedores

- [PlaidCloud Git](/es/reference/connectors/git/plaidcloud-git/) — el servicio de Git administrado integrado en su espacio de trabajo; no hay URL de servidor ni credenciales que configurar
- [GitHub](/es/reference/connectors/git/github/)
- [GitLab](/es/reference/connectors/git/gitlab/)
- [Bitbucket](/es/reference/connectors/git/bitbucket/)
- [Azure Repos](/es/reference/connectors/git/azure-repos/)
- [AWS CodeCommit](/es/reference/connectors/git/codecommit/)
