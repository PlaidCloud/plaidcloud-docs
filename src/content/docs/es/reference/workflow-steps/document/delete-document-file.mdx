## Descripción


Elimina un archivo existente de PlaidCloud Document.



## Archivo que eliminar


Primero, seleccione la cuenta correspondiente en el menú desplegable.


Después, pulse el botón **Examinar** para seleccionar el archivo que desea eliminar.

<Aside>Si el archivo no existe (porque ya se eliminó), no se realiza ninguna acción.</Aside>
