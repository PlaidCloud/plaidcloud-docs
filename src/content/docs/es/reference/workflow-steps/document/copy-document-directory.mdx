## Descripción


Copia un directorio completo dentro de PlaidCloud Document.



## Copiar directorio


Primero, seleccione la cuenta correspondiente en el menú desplegable.



A continuación, pulse el botón **Examinar** para seleccionar el directorio que desea copiar.



## Seleccionar destino


Primero, seleccione la cuenta correspondiente en el menú desplegable.



A continuación, pulse el botón **Examinar** para seleccionar el destino del directorio copiado.



Si lo desea, puede asignar un nombre nuevo al directorio copiado. Para ello, marque la casilla **Rename the Copied Folder to:** y escriba un nombre nuevo.


<Aside>El comportamiento predeterminado es sobrescribir cualquier elemento que ya exista. Tenga cuidado de no sobrescribir por accidente.</Aside>
