## Descripción


Cambia el nombre de un directorio existente de PlaidCloud Document.



## Carpeta a la que cambiar el nombre


Primero, seleccione la cuenta correspondiente en el menú desplegable.



Después, pulse el botón **Examinar** para seleccionar el directorio cuyo nombre se va a cambiar.



## Cambiar nombre a


Escriba el nuevo nombre del directorio.


<Aside>Si el directorio con el nuevo nombre ya existe, no se realiza ninguna acción.</Aside>
