## Descripción


Cambia el nombre de un archivo existente de PlaidCloud Document.



## Archivo al que cambiar el nombre


Primero, seleccione la cuenta correspondiente en el menú desplegable.



Después, pulse el botón **Examinar** para seleccionar el archivo cuyo nombre se va a cambiar.

<Aside>Si el archivo con el nuevo nombre ya existe, no se realiza ninguna acción.</Aside>


## Cambiar nombre a


Escriba el nuevo nombre del archivo.
