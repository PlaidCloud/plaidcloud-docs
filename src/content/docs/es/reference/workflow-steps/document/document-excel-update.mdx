## Descripción

El paso **Document: Update Excel Cells** escribe valores en celdas individuales de un libro `.xlsx` de una cuenta de documentos y deja el resto del libro como está. Cada fila de la tabla de entrada indica una celda y el valor que se escribirá en ella. El paso también puede aplicar formato al libro, a partir de una tabla de instrucciones de formato.

El formulario del paso tiene tres grupos de opciones: **Libro**, **Celdas** y **Formato**. Los flujos de trabajo migrados desde KNIME usan este paso para sus nodos de actualización y formato de celdas de Excel.

Que falte un libro nunca es un error: el paso lo deja sin tocar y termina con una advertencia que indica la ruta.

## Establecer valores de celda

- **Tabla de origen** (`source`): la tabla de direcciones de celda y sus nuevos valores. **Columnas de origen** (`source_columns`) enumera la columna de dirección y las columnas de valores.
- **Columna de dirección** (`address_column`): la columna que contiene la dirección de cada celda, como `A5`, o `column:row` como números a partir de 1.
- **Libro** (`file`): el libro que se va a actualizar, `{account, path}`.
- **Hoja** (`sheet_name`): la hoja que se va a actualizar. Si el libro no tiene una hoja con ese nombre, se agrega.
- **Se escribe para un valor ausente** (`replace_missing`): se escribe en una celda cuya fila no contiene ningún valor. Déjelo vacío para dejar la celda en blanco.

## Aplicar formato al libro

Establezca **Tabla de instrucciones de formato** (`source_b`) con una tabla de instrucciones de formato, con una fila por cada instrucción. **Columnas de instrucciones** (`source_b_columns`) indica sus columnas Kind, Tag y Params. Kind es `font`, `background`, `cell`, `border`, `merge`, `conditional`, `size`, `comment`, `hyperlink`, `sheet_properties` o `sheet`, y Params contiene la configuración de la instrucción como JSON. **Tabla de origen** pasa entonces a ser una tabla de control superpuesta a la hoja: cada una de sus celdas contiene las etiquetas, separadas por comas, de las instrucciones que se aplican a esa celda. **Columna de dirección** y **Hoja** no se usan.

## Escribir una copia

- **Escribir el libro actualizado en** (`output_file`): escribe el libro actualizado en este `{account, path}` en lugar de sobre el original.
- **Un archivo que ya existe** (`if_exists`): con **Escribir el libro actualizado en**, **Sobrescribirlo** (`overwrite`, el valor predeterminado) reemplaza un archivo que ya existe y **Hacer que el paso falle** (`fail`) detiene el paso.
