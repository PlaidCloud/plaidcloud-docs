## Descripción


Crea un directorio nuevo dentro de PlaidCloud Document.



## Dónde crear la carpeta nueva


Primero, seleccione la cuenta correspondiente en el menú desplegable.



A continuación, pulse el botón **Examinar** para seleccionar el directorio principal.



## Nuevo nombre de carpeta


Escriba el nombre del directorio nuevo.


<Aside>Si el directorio ya existe, no se realiza ninguna acción.</Aside>
