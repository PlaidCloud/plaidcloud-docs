## Descripción

Escribe una tabla con los archivos de un directorio de documentos. Úsela para controlar pasos posteriores según los archivos presentes, por ejemplo, para recorrer cada archivo de una carpeta o para comprobar lo que entregó un proceso anterior.

## Directorio

Seleccione una cuenta de documentos y pulse el botón **Examinar** para elegir la carpeta que desea listar.

## Opciones

- **Patrón de archivo** *(opcional)*: un glob como `*.csv` para listar solo los archivos que coinciden. Déjelo en blanco para listar todo.
- **Incluir subdirectorios**: si está marcada, también se listan los archivos de las carpetas anidadas.
- **Tabla de destino**: la tabla que recibe el listado.

## Configuración adicional

Las opciones de **Qué archivos** limitan el listado:

- **Listar también las carpetas, con una columna IsFolder** (`include_folders`): lista también las carpetas, como filas. Cada fila lleva entonces una columna final `IsFolder`, verdadera para una carpeta.
- **Listar primero el propio directorio** (`include_root_folder`): con `include_folders`, lista además el propio directorio, en primer lugar.
- **Patrón de nombre de archivo** (`file_name_filter`): solo los archivos cuyo nombre coincide. **Tipo de patrón** es **Comodín** o **Expresión regular** (`type`), y **Coincidir mayúsculas y minúsculas** establece `case_sensitive`.
- **Patrón de nombre de carpeta** (`folder_name_filter`): solo las entradas de carpetas cuyos nombres coinciden, con la misma forma; todas las carpetas del recorrido hacia abajo deben coincidir.
- **Extensiones** (`extensions`): solo los archivos con una de estas extensiones, sin el punto. **Coincidir mayúsculas y minúsculas de la extensión** (`extensions_case_sensitive`) las compara distinguiendo mayúsculas y minúsculas.
- **Incluir archivos ocultos (nombre que empieza por punto)** (`include_hidden_files`) e **Incluir carpetas ocultas y su contenido** (`include_hidden_folders`): desmarque cualquiera de ellas para excluir los archivos o las carpetas cuyo nombre empieza por punto.
