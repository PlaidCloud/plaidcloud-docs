## Descripción

Ejecute una consulta ad hoc sobre cualquier tipo de objeto de Sage Intacct e importe los resultados. A diferencia de los pasos específicos [Sage AP](../import-sage-ap/) y [Sage AP Lines](../import-sage-ap-lines/), este paso le permite dirigirse a cualquier objeto de Intacct (libro mayor, proyectos, clientes, proveedores, objetos personalizados, etc.) y elegir los campos y filtros que necesite.

La paginación se gestiona automáticamente, por lo que el paso funciona con conjuntos de resultados mayores que una sola página de la API de Intacct.

## Elementos de configuración propios

* **Conexión de Sage**: la conexión REST de Sage Intacct de la que se lee. Las conexiones de Sage se administran en **Tools > Connections**.
* **ID de empresa**: la empresa de Intacct que se consulta.
* **ID de entidad (separados por comas)**: restringe la consulta a una o más entidades de Intacct. Déjelo en blanco para todas las entidades.
* **Nombre del objeto**: el objeto de Intacct que se consulta, por ejemplo `GLACCOUNT`, `CUSTOMER`, `PROJECT` o el nombre de cualquier objeto personalizado.
* **Campos que se importarán**: tabla de nombres de campo de Intacct con una casilla Enabled. Haga clic en `Lookup Object Fields` para rellenar la lista a partir del esquema de Intacct y use `Select All` o `Select None` para activar o desactivar todos a la vez.
* **Filtros**: tabla de filas de filtro. Cada fila es `Field`, `Filter Type`, `Value`. Los tipos de filtro incluyen `Equal To`, `Not Equal To`, `Less Than`, `Less Than or Equal To`, `Greater Than`, `Greater Than or Equal To`, `Is Null` y `Is Not Null`. Los filtros se aplican en el servidor, antes de paginar.
