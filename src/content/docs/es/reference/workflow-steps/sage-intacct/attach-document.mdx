## Descripción

Adjunta documentos justificativos a registros de Sage Intacct a través de su [conexión de Sage Intacct](/es/guides/connections/sage-intacct/), mediante la canalización de escritura de ERP compartida de PlaidCloud. Cada fila de la tabla de origen es un archivo (sus bytes, su nombre y la clave del registro de Intacct al que se adjunta), que el paso crea como documento justificativo de Sage Intacct (`supdoc`) y vincula a ese registro. **Validate Only** comprueba cada fila sin crear nada en Intacct; la tabla de resultados registra el resultado de cada archivo adjunto.

Úselo para enviar los archivos que un flujo de trabajo ya tiene a mano (un PDF de factura generado, un recibo escaneado, un informe exportado) a las transacciones o registros de Intacct a los que corresponden, en la misma ejecución que los produce o los contabiliza. Se combina de forma natural con [Intacct: contabilizar asiento de diario](/es/reference/workflow-steps/sage-intacct/export-to-sage/): contabilice los asientos y, después, adjunte su respaldo con la clave de Intacct que devolvió cada contabilización.

## Contrato de la estructura de datos

Cree la tabla de archivos adjuntos en un paso anterior con pasos estándar, de modo que cada fila sea un archivo completo vinculado a un registro:

- **`parent_key`**: el registro de Sage Intacct al que se adjunta el archivo. Un archivo, un registro principal por fila; para adjuntar el mismo archivo a varios registros, repítalo en varias filas.
- **`file_name`**: el nombre de archivo del documento justificativo, con la extensión (`invoice-1043.pdf`).
- **`mime_type`**: el tipo de contenido del archivo (`application/pdf`, `image/png`), para que Intacct lo almacene y lo sirva correctamente.
- **`content_base64`**: los bytes del archivo, codificados en base64, en la fila.

## Configuración

### Conexión

- **Conexión de Sage Intacct**: la conexión de Sage Intacct a través de la cual se adjunta. Solo se ofrecen conexiones de Sage Intacct; la misma conexión lee de Intacct y escribe en él.
- **Entorno**: el entorno de la conexión.

### Datos

- **Tabla de archivos adjuntos**: la tabla de origen descrita arriba: una fila por archivo, con `parent_key`, `file_name`, `mime_type` y `content_base64`.
- **Tabla de resultados**: id de la tabla de salida: una fila por archivo adjunto con `parent_key`, `file_name`, `supdoc_id`, `status`, `message`.
- **Validate Only**: marcada de forma predeterminada. Solo comprobación previa; comprueba cada fila y escribe la tabla de resultados, pero no crea ningún documento justificativo en Intacct. Una configuración de paso que omita este campo por completo, por ejemplo una creada mediante la API REST, MCP o la importación de un paquete de flujo de trabajo, también adopta Validate Only de forma predeterminada en lugar de un adjunto real.
- **Continue On Error**: marcada de forma predeterminada. Sigue adjuntando los archivos restantes después de que uno falle; si se desmarca, se detiene en el primer fallo.

## Tabla de resultados

Cada ejecución, ya sea Validate Only o real, escribe en la tabla de resultados una fila por cada fila de origen:

| Columna | Descripción |
|---|---|
| `parent_key` | El registro de Intacct al que se dirige este archivo adjunto. |
| `file_name` | El nombre de archivo de la fila de origen. |
| `supdoc_id` | El id del documento justificativo de Sage Intacct creado para el archivo, cuando el adjunto se realizó correctamente. |
| `status` | El resultado de esta fila: validada, adjuntada o con error. |
| `message` | Una descripción breve y depurada de lo que falló, cuando la fila falló. |
