## Descripción

Importe desde Sage Intacct, mediante la API REST de Sage Intacct, los encabezados de facturas de cuentas por pagar. Cada fila es una factura de cuentas por pagar, con el proveedor, la fecha del libro mayor, la fecha de vencimiento, los totales y los campos de estado necesarios para los informes posteriores.

Use como origen un [Sage Intacct REST Connector](../../../connectors/rest/sage-intacct/) configurado. Para extraer al mismo tiempo el detalle por líneas, combine este paso con [Import Sage AP Lines](../import-sage-ap-lines/).

## Elementos de configuración propios

* **Conexión de Sage**: la conexión REST de Sage Intacct de la que se lee. Las conexiones de Sage se administran en **Tools > Connections**.
* **ID de empresa**: la empresa de Intacct que se consulta. Obligatorio si sus credenciales de remitente cubren más de una empresa.
* **ID de entidad (separados por comas)**: restringe la importación a una o más entidades de Intacct. Déjelo en blanco para extraer todas las entidades a las que tiene acceso el usuario.
