## Descripción

Lee un adaptador de datos en un espacio de trabajo de OneStream mediante su [conexión de OneStream](/es/guides/connections/onestream-for-data-foundation/) y carga sus filas en una tabla. Realiza una llamada al adaptador por cada miembro de consolidación que indique, y reemplaza la tabla de destino con las filas de todos ellos. Úselo para incorporar resultados consolidados a un proyecto, por ejemplo para conciliar un modelo con ellos.

Este paso aparece en el menú de pasos en **OneStream**. Data Foundation lo usa cuando agrega OneStream como origen.

<Aside type="note">
El adaptador y sus columnas los crea su administrador de OneStream. Consulte [Qué configura su administrador de OneStream](/es/guides/connections/onestream-for-data-foundation/#qué-configura-su-administrador-de-onestream).
</Aside>

## Configuración

### Origen

| Campo | Obligatorio | Notas |
|---|---|---|
| Conexión de OneStream | Sí | La [conexión de OneStream](/es/guides/connections/onestream-for-data-foundation/) mediante la cual se lee. |
| Entorno | No | **Entorno del proyecto** (el valor predeterminado) usa el entorno de la conexión del proyecto. **Entorno fijo** usa siempre el que usted elija. Consulte [Fijar un paso a un entorno](/es/guides/projects/managing-projects/#fijar-un-paso-a-un-solo-entorno). |
| Aplicación | No | Déjelo en blanco para usar la aplicación guardada en la conexión. Un paso debe tener una u otra. |
| Espacio de trabajo | No | Déjelo en blanco para usar el espacio de trabajo guardado en la conexión. |
| Adaptador | Sí | El adaptador de datos que se leerá. `Foundation_Results` es el adaptador descrito en la página de la conexión. |
| Tabla del adaptador | No | El nombre de la tabla dentro del conjunto de datos del adaptador. |
| Ejecutar secuencia primero | No | Una secuencia de Data Management que se ejecuta antes de leer, para actualizar lo que lee el adaptador. |

### Segmento de datos

| Campo | Notas |
|---|---|
| Miembros | Un miembro de consolidación por línea. El paso llama al adaptador una vez por cada uno, con el miembro en la variable de sustitución `Member`. Si se deja en blanco, realiza una llamada con el miembro predeterminado del adaptador. |
| Variables de sustitución | Un `Name=Value` por línea, por ejemplo `Time=2026M1`. |
| Vista | **Year to date** (el valor predeterminado) o **Periodic**. Se pasa al adaptador en la variable de sustitución `View`. |
| Signo | **As stored** (el valor predeterminado) o **Flip sign**, que invierte el signo de cada importe. |
| Escala de importes | Un multiplicador que se aplica a cada importe. El valor predeterminado es 1. Use 1000 cuando OneStream sirva valores en miles. |

Las variables de la aplicación, el espacio de trabajo, la tabla, la secuencia, los miembros y los valores de sustitución se completan a medida que se ejecuta el flujo de trabajo.

### Destino

| Campo | Obligatorio | Notas |
|---|---|---|
| Tabla de destino | Sí | La tabla en la que se cargan las filas. Se reemplaza en cada ejecución y debe ser una tabla, no una vista. |

## Salida

La tabla de destino tiene las columnas del adaptador: `entity`, `account`, `time`, `scenario`, `view`, `amount`, `currency`, `flow`, `ud1`, `ud2`, `ud3` y `ud4`. Todas las columnas se cargan como texto excepto `amount`, que es numérica una vez aplicados la escala y el signo.

Si el adaptador no devuelve filas, la tabla de destino se reemplaza por una vacía y el paso termina con una advertencia que nombra al adaptador, no con un error.
