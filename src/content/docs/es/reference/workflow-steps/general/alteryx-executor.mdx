## Descripción

Ejecuta una operación versionada con paridad de Alteryx como trabajo administrado. Es el vehículo de uso general para las [conversiones de Alteryx](/es/guides/workflows/migrate-alteryx-workflows/) cuyo trabajo necesita bibliotecas de Python (Shapely, scikit-learn, NLTK, Tesseract, reportlab) en lugar de SQL de base de datos.

La mayoría de las operaciones convertidas tienen ahora su propio tipo de paso de primera clase, que es más fácil de leer y editar. Este paso se conserva para las operaciones que no lo tienen, y es lo que esos tipos de paso inician por debajo.

<Aside type="note" title="Normalmente no se crea a mano">
  La conversión genera este paso donde hace falta. Solo lo agregaría a mano
  para ejecutar una operación de paridad que no tiene su propio tipo de paso, por ejemplo
  [Spatial Info](/es/reference/workflow-steps/spatial/spatial-info/).
</Aside>

## Configuración

### Ejecutor

- **Operación**: la operación de paridad que se ejecutará.
- **Versión del contrato**: el contrato del ejecutor con el que se ejecuta la operación. El valor predeterminado es `v1`.

### Entradas y salidas

- **Origen** / **Tabla de destino**: las tablas principales de entrada y de salida.
- **Tablas de entrada** / **Tablas de salida**: tablas adicionales para las operaciones que reciben o producen más de una.
- **Artefactos de entrada** / **Artefactos de salida**: entradas y salidas que no son tablas, como las imágenes renderizadas.

### Recursos

Desactivado de forma predeterminada; en ese caso el trabajo recibe los recursos estándar. Active la administración avanzada de recursos para establecer explícitamente la **CPU** y la **memoria**; conviene hacerlo cuando una operación maneja geometría muy grande o entrenamiento de modelos y la asignación predeterminada no es suficiente.
