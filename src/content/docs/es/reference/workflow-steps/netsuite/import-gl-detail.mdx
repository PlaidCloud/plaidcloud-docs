## Descripción

Importa el detalle de las líneas de transacciones del libro mayor de NetSuite a una tabla del proyecto a través de su [conexión de NetSuite](/es/guides/connections/netsuite/): las líneas de contabilización detrás de sus saldos, para conciliación, análisis detallado o un estado de pérdidas y ganancias detallado. Elija la conexión, asigne un nombre a una tabla de destino y defina el período y la subsidiaria; el paso obtiene las líneas y las escribe, sin SuiteQL que crear ni mantener.

Este es uno de los [pasos de importación de NetSuite](/es/reference/workflow-steps/netsuite/) predefinidos. Cada uno se ejecuta sobre una capa de lectura compartida que renueva el token de OAuth, recorre por páginas los resultados grandes y reintenta los errores transitorios por usted, de modo que una extracción de un período completo se devuelve completa sin ajustes manuales. Para saldos por período en lugar de líneas, use [NetSuite: importar saldos](/es/reference/workflow-steps/netsuite/import-balances/).

## Configuración

| Campo | Obligatorio | Notas |
|---|---|---|
| Conexión de NetSuite | Sí | La conexión de NetSuite por la que se lee, filtrada a las conexiones de tipo NetSuite. |
| Tabla de destino | Sí | La tabla del proyecto en la que se escriben las líneas de transacciones. Se sobrescribe por completo en cada ejecución. |
| Fecha de inicio | No | La fecha de transacción más temprana que se incluye, `YYYY-MM-DD`, inclusive. Déjela en blanco para no tener límite inferior. Si se indica junto con Fecha de fin, la extracción se divide automáticamente en bloques de fechas para mantenerse por debajo del límite de filas de SuiteQL de NetSuite; consulte la precaución más abajo. |
| Fecha de fin | No | La fecha de transacción más tardía que se incluye, `YYYY-MM-DD`, inclusive. Déjela en blanco para no tener límite superior. |
| Subsidiaria | No | El ID interno de una subsidiaria de NetSuite para limitar la extracción a una sola subsidiaria. Déjelo en blanco para incluir todas las subsidiarias. |
| Libro contable | No | El ID interno de un libro contable de NetSuite. Déjelo en blanco para extraer **solo el libro principal (ID interno 1)**, o escriba `all` para sumar todos los libros. |
| Número de cuenta | No | Un número exacto de cuenta del libro mayor para limitar la extracción a una sola cuenta. Déjelo en blanco para incluir todas las cuentas. |
| Período contable | No | El ID interno de un período contable de NetSuite. Déjelo en blanco para incluir todos los períodos. |

<Aside type="caution">
**Cuentas con varios libros:** una cuenta de NetSuite que usa Multi-Book Accounting registra una fila por libro y por línea de transacción, de modo que extraer todos los libros sin filtrar multiplica por N un total. Si deja Libro contable en blanco, se extrae **solo el libro principal**. Defínalo como `all` solo si desea deliberadamente un total entre libros, o como el ID interno de un libro específico para obtener únicamente ese libro.
</Aside>

<Aside type="note">
Limite el período a la porción que necesita. Cada ejecución reemplaza toda la tabla de destino, por lo que una extracción programada vuelve a extraer el resultado completo cada vez; una ventana de fechas móvil mantiene rápida una extracción periódica del libro mayor en lugar de releer todo el historial.
</Aside>

<Aside type="note">
La API SuiteQL de NetSuite limita una sola consulta a unas 100,000 filas sin SuiteAnalytics Connect. Si indica tanto Fecha de inicio como Fecha de fin, PlaidCloud divide de forma proactiva la extracción en bloques que se mantienen por debajo de ese límite; el detalle del libro mayor es la extracción con más probabilidad de acercarse a él, por lo que aquí importa más que en Import Balances. Una extracción **sin límites** que resulte superar el límite falla con un mensaje que le pide agregar un intervalo de fechas, en lugar de devolver en silencio un resultado truncado.
</Aside>
