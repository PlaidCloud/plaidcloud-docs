## Descripción

Importa los saldos de cuentas de NetSuite a una tabla del proyecto a través de su [conexión de NetSuite](/es/guides/connections/netsuite/): un balance de comprobación sobre el que puede crear informes. Elija la conexión, asigne un nombre a una tabla de destino y defina el período y la subsidiaria; el paso obtiene los saldos y los escribe, sin SuiteQL que crear ni mantener.

Este es uno de los [pasos de importación de NetSuite](/es/reference/workflow-steps/netsuite/) predefinidos. Cada uno se ejecuta sobre una capa de lectura compartida que renueva el token de OAuth, recorre por páginas los resultados grandes y reintenta los errores transitorios por usted, de modo que una extracción de un año completo o de todas las subsidiarias se devuelve completa sin ajustes manuales. Para una extracción a nivel de transacción, use [NetSuite: importar detalle del libro mayor](/es/reference/workflow-steps/netsuite/import-gl-detail/); para cuentas, subsidiarias y otras listas, use [NetSuite: importar datos maestros](/es/reference/workflow-steps/netsuite/import-master-data/).

## Configuración

| Campo | Obligatorio | Notas |
|---|---|---|
| Conexión de NetSuite | Sí | La conexión de NetSuite por la que se lee, filtrada a las conexiones de tipo NetSuite. |
| Tabla de destino | Sí | La tabla del proyecto en la que se escriben los saldos. Se sobrescribe por completo en cada ejecución. |
| Fecha de inicio | No | La fecha más temprana que se incluye, `YYYY-MM-DD`, inclusive. Déjela en blanco para no tener límite inferior. Si se indica junto con Fecha de fin, la extracción se divide automáticamente en bloques de fechas para mantenerse por debajo del límite de filas de SuiteQL de NetSuite; consulte la precaución más abajo. |
| Fecha de fin | No | La fecha más tardía que se incluye, `YYYY-MM-DD`, inclusive. Déjela en blanco para no tener límite superior. |
| Subsidiaria | No | El ID interno de una subsidiaria de NetSuite para limitar la extracción a una sola subsidiaria. Déjelo en blanco para incluir todas las subsidiarias. |
| Libro contable | No | El ID interno de un libro contable de NetSuite. Déjelo en blanco para extraer **solo el libro principal (ID interno 1)**, o escriba `all` para sumar todos los libros. |
| Número de cuenta | No | Un número exacto de cuenta del libro mayor para limitar la extracción a una sola cuenta. Déjelo en blanco para incluir todas las cuentas. |
| Período contable | No | El ID interno de un período contable de NetSuite. Déjelo en blanco para incluir todos los períodos. |

<Aside type="caution">
**Cuentas con varios libros:** una cuenta de NetSuite que usa Multi-Book Accounting registra una fila por libro y por línea de transacción. Si deja Libro contable en blanco, se extrae **solo el libro principal**, que es la opción correcta para un balance de comprobación estándar. Defínalo como `all` solo si desea deliberadamente un total entre libros (que suma los libros en lugar de conciliarlos), o como el ID interno de un libro específico para obtener únicamente ese libro.
</Aside>

<Aside type="note">
Subsidiaria y Libro contable reciben el ID interno de NetSuite, no un nombre. Obtenga los ID internos una sola vez con [NetSuite: importar datos maestros](/es/reference/workflow-steps/netsuite/import-master-data/) (tipo de registro **subsidiary**) y consérvelos en una pequeña tabla de referencia.
</Aside>

<Aside type="note">
La API SuiteQL de NetSuite limita una sola consulta a unas 100,000 filas sin SuiteAnalytics Connect. Si indica tanto Fecha de inicio como Fecha de fin, PlaidCloud divide de forma proactiva la extracción en bloques que se mantienen por debajo de ese límite, de modo que una extracción de un año completo se devuelve completa sin que usted haga nada. Una extracción **sin límites** (con Fecha de inicio o Fecha de fin en blanco) que resulte superar el límite falla con un mensaje que le pide agregar un intervalo de fechas, en lugar de devolver en silencio un resultado truncado.
</Aside>
