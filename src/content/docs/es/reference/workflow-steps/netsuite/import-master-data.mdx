## Descripción

Importa una lista de datos maestros de NetSuite a una tabla del proyecto a través de su [conexión de NetSuite](/es/guides/connections/netsuite/). Elija un tipo de registro (cuentas, subsidiarias, departamentos, clases, ubicaciones, proveedores o clientes) y el paso obtiene la lista y la escribe, sin SuiteQL que crear ni mantener.

Los datos maestros son los datos de referencia a los que apuntan las extracciones de saldos y de detalle: las cuentas, las subsidiarias y las dimensiones que sus filas del libro mayor incluyen como ID internos. Importe la lista que necesite para resolver esos ID internos en nombres, o para impulsar búsquedas y combinaciones en pasos posteriores. Este es uno de los [pasos de importación de NetSuite](/es/reference/workflow-steps/netsuite/) predefinidos, que se ejecutan sobre una capa de lectura compartida que renueva el token de OAuth, recorre por páginas los resultados grandes y reintenta los errores transitorios por usted.

## Configuración

| Campo | Obligatorio | Notas |
|---|---|---|
| Conexión de NetSuite | Sí | La conexión de NetSuite por la que se lee, filtrada a las conexiones de tipo NetSuite. |
| Tabla de destino | Sí | La tabla del proyecto en la que se escribe la lista. Se sobrescribe por completo en cada ejecución. |
| Tipo de registro | Sí | Qué lista maestra se extrae: **account** (el valor predeterminado), **subsidiary**, **department**, **class**, **location**, **vendor** o **customer**. |
| Incluir inactivos | No | Desactivado de forma predeterminada, de modo que solo se devuelven los registros activos. Actívelo para incluir los registros marcados como inactivos en NetSuite. |

<Aside type="note">
Use este paso para crear las pequeñas tablas de referencia en las que se apoyan los demás pasos de NetSuite; por ejemplo, extraiga **subsidiary** una vez para asignar el ID interno de una subsidiaria a su nombre antes de limitar una extracción de [NetSuite: importar saldos](/es/reference/workflow-steps/netsuite/import-balances/) o de [NetSuite: importar detalle del libro mayor](/es/reference/workflow-steps/netsuite/import-gl-detail/) a una sola subsidiaria.
</Aside>
