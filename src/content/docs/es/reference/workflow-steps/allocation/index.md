Pasos de flujo de trabajo para la asignación de costos, la repercusión de costos, los precios de transferencia y otros problemas similares de distribución de valores. Cada paso reparte los valores de un conjunto de filas de origen entre un conjunto de filas de destino mediante datos de inductores y un método.

## Pasos

- [Allocation Rules](/es/reference/workflow-steps/allocation/allocation-rules/): define y aplica reglas de asignación con condiciones explícitas.
- [Allocation Split](/es/reference/workflow-steps/allocation/allocation-split/): divide los valores de origen entre los destinos mediante una tabla de inductores.
- [Etiquetado basado en reglas](/es/reference/workflow-steps/allocation/rule-based-tagging/): etiqueta las filas con atributos de una dimensión antes de asignar.

## Relacionado

- [Asignaciones (guía)](/es/guides/allocations/): conceptos y flujos de trabajo de principio a fin para problemas de asignación.
- [Dimensiones (guía)](/es/guides/dimensions/): configure las jerarquías en las que las asignaciones reparten los valores.
