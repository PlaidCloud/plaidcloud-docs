## Descripción


“Detener flujo de trabajo” detiene un flujo de trabajo existente que está en ejecución.


<Aside>Si el flujo de trabajo no está en ejecución cuando se ejecuta este paso, se escribirá una advertencia en el registro indicando que *Workflow is already stopped.</Aside>


## Flujo de trabajo que se va a detener


Primero, seleccione el proyecto que contiene el flujo de trabajo que se detendrá en el menú desplegable **Proyecto**.



A continuación, seleccione el flujo de trabajo concreto que se detendrá en el menú desplegable **Flujo de trabajo**.
