## Descripción

Hace fallar el flujo de trabajo cuando dos tablas tienen recuentos de filas distintos. Úselo como puerta de calidad de datos; por ejemplo, para confirmar que una tabla transformada conservó todas las filas de su origen o que una conciliación no omitió ni duplicó registros. Cuando los recuentos coinciden, el flujo de trabajo continúa; cuando difieren, el paso detiene el flujo de trabajo y escribe el mensaje de error en el registro del flujo de trabajo.

## Configuración

- **Tabla izquierda**: la primera tabla cuyas filas se cuentan.
- **Tabla derecha**: la segunda tabla cuyas filas se cuentan.
- **Mensaje de error**: el mensaje que se muestra cuando los recuentos difieren. El valor predeterminado es “Los recuentos de filas no coinciden”.

Compárelo con [Generar error de flujo de trabajo](/es/reference/workflow-steps/workflow-control/raise-workflow-error/) cuando necesite hacer fallar el flujo de trabajo ante una condición arbitraria y no ante una diferencia en el recuento de filas.
