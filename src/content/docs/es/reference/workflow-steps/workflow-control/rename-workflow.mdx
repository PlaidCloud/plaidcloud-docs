## Descripción


Cambia el nombre de un flujo de trabajo existente de PlaidCloud Analyze.

<Aside>Si el flujo de trabajo con el nuevo nombre ya existe, se escribirá un error en el registro indicando que *Workflow \{workflow} in project \{project} already exists.* No se realizará ninguna acción. Esto limita en la práctica el paso **Cambiar nombre del flujo de trabajo** a un solo uso.</Aside>


## Flujo de trabajo que se va a cambiar de nombre


Primero, seleccione el proyecto que contiene el flujo de trabajo cuyo nombre se cambiará en el menú desplegable **Proyecto**.



A continuación, seleccione el flujo de trabajo concreto en el menú desplegable **Flujo de trabajo**.



Por último, escriba el nuevo nombre del flujo de trabajo en el campo **Cambiar nombre a**. Recuerde que el nombre debe ser único dentro del proyecto.
