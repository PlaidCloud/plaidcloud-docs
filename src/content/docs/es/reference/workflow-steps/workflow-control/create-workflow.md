## Descripción


Crea un flujo de trabajo nuevo de PlaidCloud Analyze.



## Flujo de trabajo que se va a crear


Primero, seleccione en el menú desplegable el proyecto en el que se creará el flujo de trabajo nuevo.



A continuación, escriba un nombre para el flujo de trabajo. El nombre debe ser único en el proyecto.
