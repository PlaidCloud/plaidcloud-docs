## Descripción



Ejecuta SQL en una base de datos remota mediante un agente de PlaidLink y devuelve el conjunto de resultados a PlaidCloud como una tabla de proyecto. Se utiliza cuando PlaidCloud no puede acceder directamente a la base de datos de origen (cortafuegos, solo VPN, local) pero aun así desea extraer datos de ella.

El agente ejecuta la consulta en las instalaciones y transmite el resultado a PlaidCloud, de modo que tanto las credenciales como los datos permanecen en su red hasta que se necesita el resultado.
