## Descripción

Lee una o más listas de Anaplan a través de su [conexión de Anaplan](/es/guides/connections/anaplan/) y las carga en una dimensión de PlaidCloud. **Un solo paso lee una jerarquía compuesta completa**: nombre todas las listas que abarca, empezando por la raíz (por ejemplo Region, luego Country y luego Store), en lugar de dividirla en varios pasos: la tabla de ensayo se reemplaza por completo en cada ejecución, por lo que varios pasos dirigidos a una misma tabla de ensayo borrarían cada uno las filas del anterior.

Este paso aparece en el menú de pasos en **Anaplan**, con la etiqueta **Lectura de lista**.

El paso llega a Anaplan **directamente desde la nube** mediante su API de integración; no existe una ruta mediante un agente local.

<Aside type="tip">
Este conector es de solo lectura y se autentica con credenciales básicas (nombre de usuario y contraseña) o con certificado de CA; consulte [Autenticación](/es/guides/connections/anaplan/#autenticación). El presupuesto de solicitudes de Anaplan se comparte en todo el inquilino, así que escalone la programación de este paso respecto de sus demás flujos de trabajo de Anaplan; consulte [Consideraciones de programación](/es/guides/connections/anaplan/#consideraciones-sobre-la-programación).
</Aside>

## Configuración

### Origen de Anaplan

| Campo | Obligatorio | Notas |
|---|---|---|
| Conexión de Anaplan | Sí | La [conexión de Anaplan](/es/guides/connections/anaplan/) a través de la cual leer. |
| Entorno | No | **Entorno del proyecto** (el valor predeterminado) usa el entorno de la conexión del proyecto. **Entorno fijo** usa siempre el que usted elija. Consulte [Fijar un paso a un entorno](/es/guides/projects/managing-projects/#fijar-un-paso-a-un-solo-entorno). |
| Modelo | No | Reemplaza el ID de modelo guardado en la conexión. Se detecta en vivo desde la conexión o se escribe a mano. |
| Listas | Sí | Todas las listas de Anaplan que abarca la jerarquía, como una lista ordenada. Agregue listas detectadas en el modelo elegido o escriba un ID a mano y luego reordénelas con Subir / Bajar. Enumerarlas empezando por la raíz se lee bien, pero el orden no cambia lo que se carga: todas las listas se leen antes de resolver cualquier elemento principal. |
| Tabla de ensayo | Sí | Las filas sin procesar de elemento principal/secundario/consolidación/nombre y de propiedades se cargan aquí antes de crear a partir de ellas la dimensión de PlaidCloud. |

### Dimensión de PlaidCloud de destino

| Campo | Obligatorio | Notas |
|---|---|---|
| Especificar la dimensión de forma dinámica | Una de las dos | Nombre de la dimensión de destino, que puede contener tokens `{variable}` que se resuelven en tiempo de ejecución. Seleccionada de forma predeterminada. |
| Usar una dimensión específica | Una de las dos | Elija en su lugar una dimensión de PlaidCloud que ya exista. |

## Vista previa

**Vista previa** en la pestaña **Origen** muestra las columnas y los tipos de datos que produciría esta lectura de lista, sin ejecutar el paso. No está disponible en un proyecto bloqueado.

## Lo que este paso no puede representar

| Limitación | Qué significa |
|---|---|
| Cada arista se consolida con un `+` simple | Las jerarquías de listas de Anaplan no llevan un peso ni un signo por arista: no hay nada que leer, por lo que no se pierde nada en la traducción, pero tampoco se puede representar nada más. Si un modelo expresa exclusiones o consolidaciones negativas mediante un elemento de línea o una propiedad, esa lógica no se traslada a la dimensión y debe reconstruirse en pasos posteriores. |
| Los indicadores de control de acceso y la pertenencia a subconjuntos no se importan | Los indicadores de lectura/escritura de acceso selectivo y la pertenencia de cada elemento a subconjuntos de la lista son metadatos de Anaplan, no datos de la dimensión: importar cada subconjunto como su propia columna chocaría con propiedades reales en un espacio de nombres compartido que no deja de crecer. Una propiedad de lista genuina cuyo nombre coincida con alguno de los dos se rechaza en lugar de cargarse en silencio con el nombre del otro. |
| Los subconjuntos de elementos de línea no se pueden leer como dimensiones | Anaplan los expone solo a través de un punto de conexión genérico de elementos de dimensión, no como una lista que este paso pueda leer. |
| No se puede leer una lista de más de 1 000 000 de registros por esta ruta | El punto de conexión de elementos del que lee este paso rechaza de plano lo que supera ese límite documentado en lugar de devolver un resultado parcial, y no ofrece forma de paginar para sortearlo, por lo que el paso se rechaza y nombra el límite en lugar de cargar una dimensión parcial. Mientras tanto, divida la lista en Anaplan o lea un subconjunto de ella. |
| Un nodo cuelga de exactamente un elemento principal | Un elemento cuyo nombre y cuyo ID de elemento principal no coinciden, cuyo elemento principal está en una lista que este paso no lee, o cuyo elemento principal nombrado no existe en absoluto, se rechaza por su nombre en lugar de reasignarse en silencio a la raíz de la dimensión. |
| El elemento de nivel superior de una lista no se importa | El elemento de nivel superior de Anaplan es un nodo de consolidación que está por encima de todos los elementos de la lista en lugar de ser un elemento de la propia lista, por lo que nunca lo devuelven los elementos que lee este paso. La dimensión termina con un nivel menos de profundidad que la lista de Anaplan, y las raíces propias de la lista pasan a ser las raíces de la dimensión. El paso avisa cuando una lista que usted lee declara uno. |
| Los ID de nodo deben ser únicos en todas las listas leídas juntas | El ID de un nodo es el código de Anaplan del elemento o, si no tiene, su nombre; y un código de Anaplan solo tiene garantizada la unicidad dentro de una lista. Dos listas que reutilizan los mismos códigos cortos se rechazan por su nombre en lugar de fusionarse en silencio en un solo nodo. |
| No se admiten jerarquías alternativas | Todas las listas se cargan en la jerarquía principal de la dimensión. |
| Solo lectura | Nunca se escribe nada de vuelta en Anaplan. |
