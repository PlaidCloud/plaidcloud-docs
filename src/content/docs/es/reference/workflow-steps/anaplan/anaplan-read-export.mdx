## Descripción

Ejecuta una acción de exportación de Anaplan **ya existente** a través de su [conexión de Anaplan](/es/guides/connections/anaplan/) y almacena el archivo que genera como una tabla. La acción de exportación ya debe existir en el modelo, porque la API no puede crearla, y este paso no puede restringir lo que emite: lo que la acción esté configurada para exportar en Anaplan es exactamente lo que se almacena.

Este paso aparece en el menú de pasos, en **Anaplan**.

El paso accede a Anaplan **directamente desde la nube** mediante su API Bulk; no existe una ruta mediante un agente local.

<Aside type="tip">
Este conector es de solo lectura y se autentica con credenciales Basic (nombre de usuario y contraseña) o con certificado de CA; consulte [Autenticación](/es/guides/connections/anaplan/#autenticación). El presupuesto de solicitudes de Anaplan se comparte en todo el inquilino, así que escalone la programación de este paso respecto de sus otros flujos de trabajo de Anaplan; consulte [Consideraciones sobre la programación](/es/guides/connections/anaplan/#consideraciones-sobre-la-programación).
</Aside>

## Configuración

### Origen y destino

| Campo | Obligatorio | Notas |
|---|---|---|
| Conexión de Anaplan | Sí | La [conexión de Anaplan](/es/guides/connections/anaplan/) a través de la cual se lee. |
| Entorno | Sí | El entorno de la conexión. |
| Workspace | No | Reemplaza el ID del espacio de trabajo guardado en la conexión. Se detecta en directo a partir de la conexión o se escribe a mano. |
| Model | No | Reemplaza el ID del modelo guardado en la conexión. Se detecta en directo una vez elegido un espacio de trabajo, o se escribe a mano. |
| Export | Sí | La acción de exportación de Anaplan que se ejecuta. Se detecta en directo una vez elegidos el espacio de trabajo y el modelo, o se escribe a mano. Su selección no se puede reemplazar desde aquí: se ejecuta exactamente como está configurada en Anaplan. |
| Intentos de sondeo | Sí | El valor predeterminado es 120. Cuántas veces se sondea la tarea de exportación para comprobar si ha finalizado antes de que el paso se niegue a continuar, indicando el ID de la tarea. Nunca vuelve a enviarla en silencio: Anaplan no documenta cómo distinguir dos archivos generados por la misma acción de exportación, por lo que un reenvío corre el riesgo de vincular el archivo equivocado a esta ejecución. |
| Poll Interval (seconds) | Sí | El valor predeterminado es 5. Segundos de espera entre sondeos. |
| Tabla de destino | Sí | La tabla en la que se almacena la exportación. Todas las columnas se almacenan como texto. |

## Lo que este paso no puede representar

| Limitación | Qué significa |
|---|---|
| Requiere una acción de exportación existente | La API no puede crear una acción de exportación, y la solicitud que envía este paso no lleva ningún parámetro de punto de vista, de selección de miembros ni de segmento: lo que la acción esté configurada para emitir en Anaplan es exactamente lo que se almacena. Cree o edite la acción de exportación en Anaplan para cambiar lo que genera. |
| Todas las columnas se almacenan como texto | El campo que Anaplan publica para declarar los tipos de columna de una exportación es internamente incoherente en la propia documentación publicada de Anaplan, por lo que no se puede confiar en él para asignar el tipo correcto a una columna: ninguna columna recibe su tipo de ahí, de forma deliberada y permanente. Convierta las columnas que necesite en un paso posterior. |
| Números solicitados en formato de EE. UU.; una columna que sigue agrupada se señala, no se corrige | La tarea de exportación se envía solicitando el formato numérico de EE. UU. Una columna que aún llega con separadores de miles significa que la exportación no se está generando con ese formato: el paso almacena el valor sin cambios, como texto, y muestra una advertencia con el nombre de la columna y un valor de ejemplo, en lugar de adivinar cuál es el carácter decimal. Compruebe una columna así antes de convertirla en un paso posterior: un `1.234.567` de estilo europeo leído como `1.234` es mil veces menor. |
| Se niega a almacenar una extracción poco fiable | El paso no almacena nada, en lugar de una tabla que parece completa y no lo es, cuando: la tarea de exportación falla o no informa de ningún éxito en Anaplan; la tarea se cancela; la tarea sigue ejecutándose cuando se agota el presupuesto de sondeo del paso; el archivo generado no tiene ningún dato; el archivo generado no se puede vincular con la exportación que lo creó; o el número de filas leídas no coincide con el recuento de filas que informa el propio Anaplan para la exportación. |
| Solo lectura | Nunca se escribe nada de vuelta en Anaplan. |
