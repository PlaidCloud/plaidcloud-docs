## Descripción


Se usa para convertir tablas de datos largas y estrechas en tablas de datos cortas y anchas. Las columnas seleccionadas se transponen y los nombres de columna se convierten en valores en varias columnas.


Quizá el ejemplo más fácil de entender sea pensar en una tabla de datos con los meses como filas:





Al pivotar esta tabla de datos, todas las filas de meses se convertirían en columnas.

Al especificar qué columnas transponer y cuáles dejar sin cambios, se convierte en una herramienta potente. Realizar esta conversión en otras herramientas ETL podría requerir una docena de pasos más.

### Selección de columnas de pivote

En **Columna de categoría que se transformará en encabezados de columna** se especifica la columna de la tabla de origen que se pivotará a filas.
**Columna de valor que se pivotará a valores de columna** es la columna que contiene los valores de la tabla de origen.
En **Opción de agregación de valores** se especifica cómo desea agregar los datos.

Ambas columnas deben estar entre las columnas de salida del paso en la pestaña **Selección de datos de la tabla**. De lo contrario, se rechaza el guardado, por ejemplo con *The category column 'month' isn't one of the step's output columns.*


El formulario también tiene estos campos:

* **Columna con la posición de cada categoría** (`column_order`): una columna de origen que contiene la posición de cada categoría. Las columnas pivotadas aparecen en el orden ascendente de esta columna, en lugar de ordenarse por nombre. No se agrupa por ella ni se escribe.
* **Plantilla del nombre de columna dinámica** (`column_name_template`): nombra cada columna pivotada con este texto, en el que `{value}` se reemplaza por el valor de la categoría, como `{value}+Sum`.

## Selección de datos de la tabla

![Selección de datos de Table Pivot](/images/table_pivot_2.png)


La pestaña Selección de datos de la tabla sirve para asignar columnas de la tabla de datos de origen a la tabla de datos de destino. Todas las columnas de origen del lado izquierdo de la ventana se asignan automáticamente a la tabla de datos de destino representada en el lado derecho de la ventana. Con el botón de menú **Inspeccionar origen**, hay algunas formas adicionales de asignar columnas del origen al destino:


* Rellenar ambas tablas de asignación: propaga todos los valores de la tabla de datos de origen a la tabla de datos de destino. Es el valor predeterminado.
* Rellenar solo la tabla de asignación de origen: asigna únicamente todos los valores de la tabla de datos de origen. Es útil al modificar un flujo de trabajo existente cuando la estructura de las columnas de origen ha cambiado.
* Rellenar solo la tabla de asignación de destino: propaga todos los valores únicamente a la tabla de datos de destino.

Además de cada una de estas opciones, cada elección ofrece la posibilidad de obtener una vista previa de los datos de origen.

Si se guarda con una tabla de origen elegida pero sin columnas de origen o sin columnas de destino, el lado vacío se rellena desde el origen, igual que lo haría **Rellenar ambas tablas de asignación**.



Si las opciones de columnas de origen y de destino no son suficientes, se pueden agregar otras columnas a la tabla de datos de destino de varias maneras:


* **Propagar todo** insertará todas las columnas de origen en la tabla de datos de destino, existieran ya o no.
* **Propagar seleccionadas** insertará únicamente las columnas de origen seleccionadas.
* Haga clic con el botón derecho en el lado de destino y seleccione **Insertar fila** para insertar una fila inmediatamente encima de la fila seleccionada.
* Haga clic con el botón derecho en el lado de destino y seleccione **Anexar fila** para insertar una fila al final (en el extremo derecho) de la tabla de datos de destino.


<Aside type="danger">Seleccionar **Propagar todo** puede crear de forma efectiva un duplicado de cada columna. Analyze no comprueba si las columnas ya están asignadas. Asegúrese de que no existan nombres de columna duplicados.</Aside>




Para eliminar columnas de la tabla de datos de destino, seleccione las columnas deseadas, haga clic con el botón derecho y seleccione **Eliminar**.



Para reorganizar las columnas de la tabla de datos de destino, seleccione las columnas deseadas, haga clic con el botón derecho y seleccione **Mover al principio**, **Subir**, **Bajar** o **Mover al final**.



Para devolver solo opciones distintas, seleccione la opción de menú **Distinto**. Esto activará un conjunto de casillas para cada columna del origen. Basta con marcar la casilla junto a la columna correspondiente para obtener únicamente resultados distintos.

<Aside type="danger">Cuando la tabla de datos de destino contiene solo un subconjunto de la tabla de datos de origen, marque la casilla únicamente junto a las columnas que **sí** deben incluirse en la tabla de datos de destino. Si se marcan todas las casillas, la salida podría no parecer distinta.</Aside>




Para agregar resultados, seleccione la opción de menú **Resumir**. Esto activará un conjunto de cuadros desplegables para cada columna de la tabla de datos de destino. Están disponibles las siguientes opciones de resumen:


* Agrupar por (valor predeterminado)
* Suma
* Mínimo
* Máximo
* Primero
* Último
* Recuento
* Media
* Mediana
* Moda

* Varianza

* Asimetría

## Filtros de datos


Para ofrecer la máxima flexibilidad, hay filtros de datos disponibles tanto para los datos de origen como para los de destino. En conjuntos de datos más grandes, puede resultar especialmente útil filtrar filas en el origen para que las operaciones restantes se realicen sobre un conjunto de datos más pequeño.



### Seleccionar subconjunto de datos


Cualquier expresión de Python válida sirve para obtener un subconjunto de los datos. Consulte [Expresiones](/es/reference/expressions/)


para obtener más detalles y ejemplos.






### Aplicar filtro secundario a los datos de resultado


Cualquier expresión de Python válida sirve para obtener un subconjunto de los datos. Consulte [Expresiones](/es/reference/expressions/) para obtener más detalles y ejemplos



### Segmentación final de la tabla de datos (límite)


Para limitar los datos, simplemente marque la casilla **Aplicar segmentador de filas** y especifique lo siguiente:


* **Filas iniciales que omitir:** filas de datos que se omiten (la fila de encabezado de columna no se incluye en el recuento)
* **Terminar en la fila:** última fila de datos que se incluirá. Esto es distinto de contar filas al final para descartarlas
