## Descripción


Se usa para convertir tablas de datos cortas y anchas en tablas de datos largas y estrechas. Las columnas seleccionadas se transponen y los nombres de columna se convierten en valores en varias filas.


Quizá el ejemplo más fácil de entender sea pensar en una tabla de datos con los meses como encabezados de columna:





Al despivotar esta tabla de datos, todas las columnas de meses se convertirían en filas.

Al especificar qué columnas transponer y cuáles dejar sin cambios, se convierte en una herramienta potente. Realizar esta conversión en otras herramientas ETL podría requerir una docena de pasos más.

### Origen y destino


Para establecer el origen y el destino, seleccione primero la tabla de datos de la que se extraerá en el menú desplegable **Tabla de origen**.

## Selección de datos de tabla previa a despivotar

![Table Pre-Melt](/images/table_melt_2.png)

Esta sección es un poco distinta de la selección de datos de tabla estándar. Básicamente sirve para especificar qué columnas se usarán en la operación de despivotado. Esto incluye las columnas de ID y las columnas de variable y valor.


<Aside>El diseño de columnas de la selección de datos de tabla previa a despivotar **NO** refleja el diseño de columnas de la tabla de datos de salida. El diseño de la tabla de datos de destino se especifica en la sección Diseño de despivotado.</Aside>

Si se guarda con una tabla de origen elegida pero sin columnas de origen o sin columnas de destino, el lado vacío se rellena desde el origen, igual que lo haría **Rellenar ambas tablas de asignación**.







## Filtros de datos


Para ofrecer la máxima flexibilidad, hay filtros de datos disponibles tanto para los datos de origen como para los de destino. En conjuntos de datos más grandes, puede resultar especialmente útil filtrar filas en el origen para que las operaciones restantes se realicen sobre un conjunto de datos más pequeño.



### Seleccionar subconjunto de datos de origen


Cualquier expresión de Python válida sirve para obtener un subconjunto de los datos. Consulte [Expresiones](/es/reference/expressions/)


para obtener más detalles y ejemplos.



### Aplicar filtro secundario a los datos de resultado


Cualquier expresión de Python válida sirve para obtener un subconjunto de los datos. Consulte [Expresiones](/es/reference/expressions/) para obtener más detalles y ejemplos



### Segmentación final de la tabla de datos (límite)


Para limitar los datos, simplemente marque la casilla **Aplicar segmentador de filas** y especifique lo siguiente:


* **Filas iniciales que omitir:** filas de datos que se omiten (la fila de encabezado de columna no se incluye en el recuento)
* **Terminar en la fila:** última fila de datos que se incluirá. Esto es distinto de contar filas al final para descartarlas



## Diseño de despivotado

![Diseño de Table Melt](/images/table_melt_3.png)

Hay un botón **Guess Layout** para que Analyze haga un primer intento de especificar las columnas de ID. De forma predeterminada, todas las columnas de texto (tipo de datos **Cadena**) se colocan en la sección **Keys**. Las columnas numéricas no se colocan en **Keys** de forma predeterminada, pero se permite que estén ahí según las necesidades del modelo.


<Aside>La estructura de la tabla de datos de destino constará de todas las **Columnas de ID** más los nombres especificados en **Nombre de la columna de variable** y **Nombre de la columna de valor**.</Aside>




### Columnas que se usarán como ID (claves)


Las columnas de ID son las columnas que permanecen intactas. Estas columnas se repiten de forma efectiva para cada instancia de una combinación de variable y valor. En una tabla mensual, esto daría lugar a 12 repeticiones de las columnas de ID.



Las columnas de ID se pueden agregar de forma automática o manual. Para agregarlas automáticamente, use el botón **Guess Layout** mencionado anteriormente. Para agregar columnas adicionales manualmente, haga clic con el botón derecho en cualquier punto de la sección y seleccione **Insertar fila** o **Anexar fila**, para agregar una fila antes de la fila seleccionada o al final, respectivamente. Después, escriba el nombre de la columna que se usará como ID.



Para quitar un campo de **IDs**, simplemente haga clic con el botón derecho y seleccione **Eliminar**.



### Nomenclatura de las columnas del resultado del despivotado


Hay 2 valores que especificar. Ambos se convertirán en nombres de columna de la tabla de datos de destino.


* **Nombre de la columna de variable:** como se indica en la transformación, *los nombres de variable se derivan de los nombres actuales de las columnas de origen*. Básicamente, especifique un nombre de columna que represente los datos que originalmente representaban las columnas de la tabla de datos de origen.
* **Nombre de la columna de valor:** especifique un nombre de columna para representar los datos que contiene la tabla de datos de origen. Normalmente será una unidad numérica: dólares, libras, grados, porcentaje, etc.





### Configuración adicional

**Más opciones de despivotado** tiene estos campos:

* **Despivotar también todas las demás columnas que tenga la tabla al ejecutarse el paso** (`melt_all_columns`): despivota también todas las columnas que tenga la tabla de origen cuando se ejecuta el paso, que el paso no enumere y que no sean columnas de ID, en el orden en que las tiene la tabla.
* **Nombre de la columna de posición** (`position_name`): escribe además una columna con este nombre que contiene la posición, basada en 0, de la columna de valor de cada fila entre las columnas de valor.
* **Nombre de la columna de tipo** (`type_name`): escribe además una columna con este nombre que contiene el tipo de datos de la columna de valor de cada fila, como `integer`, `numeric`, `text`, `boolean`, `date` o `timestamp`.
