## Descripción

Rellena una tabla de destino a partir de un `SELECT` de SQL que usted mismo escribe. Mientras que [Table Extract](/es/reference/workflow-steps/tables/table-extract/) crea la consulta a partir de columnas asignadas y expresiones, este paso entrega la consulta directamente al almacén de datos, para los casos en que el SQL es más fácil de expresar directamente que de armar en el asignador.

Recurra a él cuando necesite una construcción que el asignador no cubre: una CTE recursiva, una función de ventana sobre una partición que el asignador no puede describir, o una consulta contra varias tablas que un paso de combinación volvería más enrevesada.

## Elementos de configuración exclusivos

### Consulta SQL SELECT

El texto de la consulta. Dele formato de SQL legible, de varias líneas y con sangría (una columna o cláusula por línea) en lugar de una sola línea larga; el paso conserva lo que usted escribe y la siguiente persona que lo abra tendrá que leerlo.

La consulta se ejecuta en el Lakehouse del proyecto, así que las funciones disponibles son el conjunto de [Lakehouse v1](/es/reference/expressions/lakehouse-v1/) o de [v2](/es/reference/expressions/lakehouse-v2/), según el espacio de trabajo.

A diferencia de los demás pasos SQL, este paso no rellena las variables, por lo que su vista previa tampoco lo hace.
