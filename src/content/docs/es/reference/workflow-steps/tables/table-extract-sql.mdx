## Descripción

Rellena una tabla de destino a partir de una instrucción SQL `SELECT` que usted mismo escribe. Mientras que el paso [Table Extract](/es/reference/workflow-steps/tables/table-extract/) genera la consulta a partir de columnas y expresiones asignadas, este paso entrega la consulta directamente al almacén, para los casos en que es más fácil expresar el SQL de forma directa que armarlo en el asignador.

Recurra a él cuando necesite una construcción que el asignador no cubre: una CTE recursiva, una función de ventana sobre una partición que el asignador no puede describir, o una consulta sobre varias tablas que un paso de combinación volvería más enrevesada.

## Elementos de configuración exclusivos

### Consulta SQL SELECT

El texto de la consulta. Déle un formato legible, de varias líneas y con sangría (una columna o cláusula por línea), en lugar de una sola línea larga; el paso conserva lo que usted escribe y la siguiente persona que lo abra tendrá que leerlo.

La consulta se ejecuta en el lakehouse del proyecto, por lo que las funciones disponibles son las del conjunto [Lakehouse v1](/es/reference/expressions/lakehouse-v1/) o [v2](/es/reference/expressions/lakehouse-v2/), según el espacio de trabajo.
