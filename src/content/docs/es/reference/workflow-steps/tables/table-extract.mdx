## Descripción


Se usa para extraer datos de una tabla de datos de Analyze existente a otra tabla de datos. Algunos ejemplos son, entre otros, los siguientes:


* Ordenación
* Agrupación
* Resumen
* Filtrado o subconjunto de filas
* Eliminación de columnas sobrantes
* Operaciones matemáticas
* Operaciones con cadenas

<Aside>Esta transformación no tiene funciones exclusivas. Toda la ordenación, agrupación, filtrado, etc. puede realizarse en cualquier otra transformación con las pestañas **Selección de datos de la tabla** y **Filtros de datos**.</Aside>

## Columnas nombradas en tiempo de ejecución

Seleccione **Incluir también columnas nombradas en tiempo de ejecución** para pasar sin cambios todas las columnas de origen que el paso no enumera, tal como las tiene la tabla cuando el paso se ejecuta. Úselo cuando un paso anterior cree columnas cuyos nombres dependen de los datos, como una tabla dinámica, de modo que no pueda enumerarlas al crear el paso. Déjelo desactivado para escribir solo las columnas que enumere.

Cuando está activado, aparece una sección **Columnas arrastradas**, y una sección **Columnas nombradas por los datos** está siempre disponible. Tienen estos campos:

* **Arrastrar como** (`carry_expression`): escribe cada columna arrastrada como esta expresión en lugar de sin cambios, donde `__column__` representa la columna arrastrada. Así es como un paso que agrupa incorpora columnas que solo conoce la ejecución; un paso que agrega no arrastra nada sin ella. **Tipo de las columnas arrastradas** (`carry_dtype`) define el tipo de datos de cada columna arrastrada (de forma predeterminada, el suyo propio), y **Agregación de las columnas arrastradas** (`carry_agg`) define cómo la trata un paso que agrega (`dont_group` cuando la expresión agrega).
* **Renombrar columnas arrastradas** (`carry_rename`): renombra cada columna arrastrada cuyo nombre coincide con la expresión regular `pattern` y no con `keep`, colocando `replacement` en lugar de cada coincidencia (`\1` para un grupo; las primeras `max` coincidencias, si se define). `__index__` en `replacement` es la posición de la columna entre las columnas renombradas, contada desde `start`. Si un nombre ya está en uso, se le agrega ` (#n)`.
* **Columnas dinámicas** (`dynamic_columns`): columnas de destino nombradas por los datos, un conjunto por cada valor distinto que el paso lee de su origen, escritas cuando el paso se ejecuta. Cada entrada indica `rows` (expresiones `key`, `label`, `where` y `order` sobre el origen), una columna `target` o una lista de columnas que usa `__key__`, `__label__` y `__index__`, y `after`, la columna de destino a la que siguen las nuevas (de forma predeterminada, el final). Los valores deben ser texto, entero, booleano o NULL, el paso escribe como máximo 1000 columnas y la salida debe ser una tabla.
