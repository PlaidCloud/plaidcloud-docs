## Descripción


Se utiliza para extraer datos de una tabla de datos existente de Analyze a otra tabla de datos. Algunos ejemplos, entre otros, son los siguientes:


* Ordenar
* Agrupar
* Resumen
* Filtrar o seleccionar un subconjunto de filas
* Quitar columnas sobrantes
* Operaciones matemáticas
* Operaciones con cadenas

<Aside>Esta transformación no tiene funciones exclusivas. Todas las operaciones de ordenación, agrupación, filtrado, etc. se pueden realizar en cualquier otra transformación con las pestañas **Columnas** y **Filtros**.</Aside>

## Columnas nombradas en tiempo de ejecución

Seleccione **Incluir también columnas nombradas en tiempo de ejecución** para pasar sin cambios todas las columnas de origen que el paso no enumera, tal como las tiene la tabla cuando se ejecuta el paso. Úselo cuando un paso anterior crea columnas cuyos nombres dependen de los datos, como un pivote, de modo que no pueda enumerarlas al crear el paso. Déjelo desactivado para escribir solo las columnas que usted enumera.

Cuando está activado, aparece una sección **Columnas arrastradas**, y siempre hay disponible una sección **Columnas nombradas por los datos**. Tienen estos campos:

* **Arrastrar como** (`carry_expression`): escribe cada columna arrastrada como esta expresión en lugar de sin cambios, donde `__column__` representa la columna arrastrada. Así es como un paso que agrupa incorpora columnas que solo conoce la ejecución; un paso que agrega no arrastra nada sin ella. **Tipo de las columnas arrastradas** (`carry_dtype`) establece el tipo de datos de cada columna arrastrada (de forma predeterminada, el suyo propio), y **Agregación de las columnas arrastradas** (`carry_agg`) establece cómo la trata un paso que agrega (`dont_group` cuando la expresión agrega).
* **Renombrar columnas arrastradas** (`carry_rename`): cambia el nombre de cada columna arrastrada cuyo nombre coincide con la expresión regular `pattern`, y no con `keep`, colocando `replacement` en lugar de cada coincidencia (`\1` para un grupo; las primeras `max` coincidencias, cuando se establece). `__index__` en `replacement` es la posición de la columna entre las columnas renombradas, contada desde `start`. A un nombre que ya está en uso se le agrega ` (#n)`.
* **Columnas dinámicas** (`dynamic_columns`): columnas de destino nombradas por los datos, un conjunto por cada valor distinto que el paso lee de su origen, escritas cuando se ejecuta el paso. Cada entrada indica `rows` (expresiones `key`, `label`, `where` y `order` sobre el origen), una columna `target` o lista de columnas que usa `__key__`, `__label__` y `__index__`, y `after`, la columna de destino a la que siguen las nuevas (de forma predeterminada, el final). Los valores deben ser texto, entero, booleano o NULL, el paso escribe como máximo 1000 columnas y la salida debe ser una tabla.
