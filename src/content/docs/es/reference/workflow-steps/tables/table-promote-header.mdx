## Descripción

El paso **Tabla: promover encabezado** toma una fila de la entrada y convierte sus valores en los nombres de columna, y luego elimina esa fila. Úselo para un archivo cuyo encabezado real no es la primera línea. El paso se ejecuta cuando se ejecuta el flujo de trabajo, por lo que los nombres proceden de los datos.

## Origen y opciones

- **Tabla de origen** y **Tabla de salida**: la tabla que se lee y la tabla en la que se escribe.
- **Fila de encabezado**: la fila, contada desde 1, cuyos valores dan nombre a las columnas. Se elimina de los datos. Déjela vacía para no promover ningún encabezado y aplicar los pasos de formato a los nombres almacenados.
- **Columna de orden de registro** *(opcional)*: la columna que ordena las filas. Sin ella, las filas se leen tal como están almacenadas, por lo que la fila que da nombre a las columnas puede cambiar de una ejecución a otra.
- **Columnas cuando la entrada está vacía** *(opcional)*: nombres, separados por comas, de las columnas de texto que se escriben cuando la entrada no tiene filas.

## Pasos de formato

Cada fila de la cuadrícula **Pasos de formato** cambia los nombres promovidos.

| Configuración | Opciones |
| --- | --- |
| Acción | **Cambiar nombre**, **Cambiar tipo**, **Ocultar**, **Rellenar vacíos** |
| Criterio | **Contiene**, **Empieza por**, **Termina en** o **Está vacío** |
| Texto coincidente | El texto que debe coincidir en el nombre de la columna. No es necesario para **Está vacío**. |
| Cambiar nombre por | **Reemplazar texto**, **Agregar antes** o **Agregar después**, para un cambio de nombre |
| Reemplazar por | El texto nuevo para un cambio de nombre o un relleno |
| Valor | El tipo para **Cambiar tipo** |

Cada paso necesita una acción y un criterio, y un cambio de nombre necesita un método de cambio de nombre y su texto.
