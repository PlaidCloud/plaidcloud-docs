## Descripción

El paso **Fuzzy Match** empareja las filas de dos tablas (o elimina duplicados de una) según coincidencias aproximadas de campos. Se ejecuta en el motor de flujos de trabajo; los resultados de las macros empaquetadas son una aproximación de la macro de Alteryx.

## Parámetros

- **Tablas izquierda y derecha** y la **Tabla de salida**.
- **Columna de ID de registro**, **Umbral** (0-100) y **Emitir también las filas sin coincidencia**.
- **Campos de coincidencia**: los campos que se comparan y la función de coincidencia de cada uno (exact / jaro / levenshtein / bestof / jaro_tfidf / bestof_tfidf).
