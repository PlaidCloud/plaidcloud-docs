## Descripción


Si usa con regularidad la función vlookup de Microsoft Excel, la transformación Table Lookup le resultará muy familiar. Se usa para realizar básicamente la misma función. A diferencia de la versión de Microsoft Excel, la transformación Table Lookup de PlaidCloud Analyze ofrece mayor flexibilidad, ya que permite, sobre todo, buscar coincidencias y devolver varias columnas.

## Ejemplos


### Buscar información de la dimensión de producto


En este ejemplo, el modelador necesita información de la tabla de la dimensión de producto para dar sentido a la tabla de hechos de pedidos. Por ello, la tabla *Import Order Fact* se selecciona como **Tabla de origen**. La tabla *Import Product Dim* contiene la información de búsqueda deseada, por lo que se selecciona como **Lookup Table Source**. Aunque están disponibles, no se aplica ningún filtro a la tabla de datos de búsqueda (ni a ninguna otra tabla de datos, en realidad).



En la sección **Selección de datos de la tabla**, todas las columnas se asignan de la tabla de datos de origen a la tabla de datos de destino. 



No se aplica ningún filtro en **Filtros de datos** ni a los datos de origen ni a los de destino. 



Por último, la tabla de datos de origen se compara con la tabla de datos de búsqueda mediante el campo *Product_ID* que se encuentra en cada tabla. Solo las columnas *Product_Description* y *Unit_Cost* se agregan a la tabla de datos de destino, y *Unit_Cost* cambia de nombre a *Retail_Unit_Cost* en el proceso. 



En la tabla de datos de destino resultante, se han agregado las columnas *Product_Description* y *Retail_Unit_Cost*, según los valores coincidentes de la columna *Product_ID*.
