## Descripción

Copia una tabla de un proyecto a otro. Úselo para trasladar entre proyectos una tabla de referencia compartida, un conjunto de resultados publicado o una búsqueda basada en dimensiones, sin exportar a un archivo y volver a importarlo.

Ambos lados se nombran de forma explícita: un proyecto y una tabla de origen, y un proyecto y una tabla de destino. El proyecto de destino empieza siendo el proyecto actual, pero puede ser cualquier proyecto, de modo que un paso puede copiar hacia este proyecto, desde él o entre otros dos. La tabla de destino se crea si no existe, y debe ser una tabla y no una vista.

## Administración del uso compartido de datos

Una copia necesita hasta dos recursos compartidos de datos:

- **Lectura, del proyecto de origen al proyecto de destino**, de modo que los datos del origen lleguen solo adonde el origen los comparte. Abra la pestaña **Inicio** del proyecto de **origen**, haga clic en **Nuevo recurso compartido de datos** en **Administración del uso compartido de datos**, seleccione el proyecto de destino, marque **Leer** en **Operaciones permitidas** y haga clic en **Agregar recurso compartido de datos**.
- **Escritura, del proyecto de destino a este proyecto**, es decir, el proyecto en el que está el flujo de trabajo, que es el que escribe, cuando el destino es otro proyecto. Abra la pestaña **Inicio** del proyecto de **destino**, haga clic en **Nuevo recurso compartido de datos** en **Administración del uso compartido de datos**, seleccione este proyecto, marque **Escribir** en **Operaciones permitidas** y haga clic en **Agregar recurso compartido de datos**.

Así, una copia hacia este proyecto solo necesita el recurso compartido de lectura, y una copia dentro de un mismo proyecto no necesita ninguno. Consulte [Uso compartido de datos entre proyectos](/es/guides/projects/managing-projects/#uso-compartido-de-datos-entre-proyectos).

Sin un recurso compartido que necesite, se rechaza el guardado del paso y falla la ejecución, con un mensaje que nombra cada recurso compartido que debe agregarse; por ejemplo, *El proyecto 'Sales' no puede escribir en el proyecto 'Finance': en el proyecto 'Finance', en Administración del uso compartido de datos, agregue un recurso compartido de datos para 'Sales' que permita Escribir.* Una ejecución rechazada deja el proyecto de destino como estaba, sin crear la tabla de destino. Un proyecto indicado mediante una variable se comprueba cuando se ejecuta el paso.

El paso se ejecuta con la identidad propia de este proyecto, por lo que una ejecución funciona a través de los recursos compartidos sin importar quién la inicie.

## Parámetros de copia

### Leer desde

- **Proyecto de origen**: el proyecto desde el que se copia.
- **Tabla de origen**: la tabla que se copia, elegida del proyecto de origen.

### Escribir en

- **Proyecto de destino**: el proyecto en el que se copia. Empieza siendo el proyecto actual.
- **Tabla de destino**: la tabla que se escribe, elegida del proyecto de destino. Al elegir un **Proyecto de destino** distinto se borra la tabla que había elegido del anterior; una tabla indicada por nombre o ruta se conserva y se busca en el nuevo proyecto.
- **Anexar a los datos existentes**: márquela para agregar las filas copiadas a lo que ya contenga la tabla de destino. Déjela sin marcar para reemplazar las filas de la tabla por las del origen.

Un proyecto guardado que usted no puede ver, o que se ha eliminado, se muestra marcado como **(faltante)** en lugar de sustituirse por otro proyecto.
