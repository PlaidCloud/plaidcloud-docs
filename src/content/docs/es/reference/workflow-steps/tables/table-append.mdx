## Descripción

Agrega filas de una tabla de origen al final de una tabla de destino existente. Las filas existentes en el destino se conservan; solo se insertan filas nuevas. Úselo cuando los datos lleguen de forma incremental (p. ej., extracciones diarias, archivos de carga mensuales) y desee que el destino crezca con el tiempo en lugar de reemplazarlo.

Si necesita eliminar duplicados al anexar, haga seguir este paso de un paso [Table Union Distinct (paso)](/es/reference/workflow-steps/tables/table-union-distinct/), o use [Table Upsert (paso)](/es/reference/workflow-steps/tables/table-upsert/) si algunas filas actualizan registros existentes por clave.

## Qué se comprueba al guardar

- **La asignación se ajusta a una tabla de destino existente.** Cuando la tabla de destino ya existe, el paso no puede asignar una columna que la tabla no tiene, ni dar a una columna un tipo distinto del de la tabla. Numérico y moneda cuentan como el mismo tipo. Se permite que una columna de la tabla quede fuera de la asignación, y se deja vacía en las filas anexadas. El rechazo nombra cada diferencia, por ejemplo *Las columnas de destino deben coincidir con la tabla de destino existente 'sales'. Los tipos difieren: amount (tabla: numeric, paso: text).* Una tabla de destino que aún no existe, o una nombrada con una variable, se comprueba cuando se ejecuta el paso.
- **Una asignación vacía se rellena por usted.** Si se guarda con una tabla de origen elegida pero sin columnas de origen o de destino, el lado vacío se rellena a partir del origen, como lo haría **Rellenar ambas tablas de asignación**.
