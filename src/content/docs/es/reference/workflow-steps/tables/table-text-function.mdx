## Descripción

El paso **Tabla: función de texto** aplica una función de texto a las columnas de cada fila que la función lee y escribe el resultado en una columna nueva de una copia de la tabla de origen. Un NULL en cualquier columna que lee la función da NULL.

## Origen y opciones

- **Tabla de origen** y **Tabla de salida**: la tabla que se lee y la tabla que se escribe.
- **Función**: la función que se aplica. El formulario ofrece las funciones de las dos tablas siguientes y muestra un campo de columna, con una etiqueta según su función, para cada argumento que lee la función seleccionada.
- **Columnas de argumentos**: las columnas que lee la función, en el orden en que las enumera la tabla. Todas son obligatorias.
- **Columna de salida**: el nombre de la columna que se agrega a la copia del origen.

| Función | Argumentos | Resultado |
| --- | --- | --- |
| `levenshtein` | Primera columna, Segunda columna | Distancia de edición que distingue mayúsculas de minúsculas, como número entero |
| `soundex` | Texto | Texto |
| `json_format` | JSON | Texto JSON con formato legible |
| `json_field` | JSON, Ruta | Texto |
| `json_set_text`, `json_set_number`, `json_set_boolean` | JSON, Ruta, Valor | Texto JSON con el valor establecido |
| `regex_match` | Texto, Patrón, Coincidir mayúsculas y minúsculas | Verdadero o falso |
| `regex_search` | Texto, Patrón, Aparición, Coincidir mayúsculas y minúsculas | Posición, como número entero |
| `regex_extract` | Texto, Patrón, Aparición, Coincidir mayúsculas y minúsculas | Texto |
| `regex_replace` | Texto, Patrón, Reemplazo, Coincidir mayúsculas y minúsculas | Texto |
| `to_text_number` | Número, Patrón | Texto: el número escrito con un patrón de estilo DecimalFormat |
| `to_text_datetime` | Fecha y hora, Patrón | Texto: la fecha escrita con un patrón de fecha y hora |
| `parse_date` | Texto, Patrón | El texto leído como fecha |
| `parse_datetime` | Texto, Patrón | El texto leído como fecha y hora |

Un análisis de Savant convertido puede contener cualquiera de estas funciones, y se ejecutan de la misma manera. Una función que el formulario no ofrece muestra sus columnas almacenadas y se conserva exactamente como se guardó.

### Más funciones

La lista **Función** también ofrece estas funciones. Los flujos de trabajo de KNIME convertidos también las usan.

| Función | Argumentos | Resultado |
| --- | --- | --- |
| `damerau_levenshtein`, `hamming`, `lcs` | Primera columna, Segunda columna | La distancia de edición correspondiente, como número entero |
| `jaro`, `jaro_winkler` | Primera columna, Segunda columna | 1 menos la similitud, 0 para textos iguales |
| `ngram_distance` | Primera columna, Segunda columna | 1 menos el coeficiente de Dice de los bigramas de caracteres |
| `jaccard_tokens`, `dice_tokens`, `cosine_tokens` | Primera columna, Segunda columna | 1 menos la similitud de conjuntos de las palabras de los dos textos, 1 cuando alguno no tiene ninguna |
| `java_compare` | Primera columna, Segunda columna | La diferencia de los primeros caracteres distintos, tal como la da `compareTo` de Java, como número entero |
| `java_regex` | Texto, Patrón, Reemplazo *(solo en el modo replace)* | Una expresión regular de Java leída de una columna: verdadero o falso en los modos `matches` y `find`, texto en `extract` y `replace` |
| `knime_count` | Texto, Texto de búsqueda | Cuántas veces aparece el texto de búsqueda, como número entero |
| `knime_binomial`, `long_pow` | Dos números | El coeficiente binomial, o la potencia entera, en aritmética de 64 bits con desbordamiento cíclico |
| `encode`, `decode` | Texto | El texto como bytes en base64 en un juego de caracteres, y a la inversa |
| `url_encode` | Texto | El texto con codificación porcentual como valor de formulario, con el espacio escrito como `+` |
| `list_sort_numeric` | Texto | Una lista guardada como texto separado, ordenada por valor numérico |
| `geojson_to_wkt` | JSON, Ruta | La geometría GeoJSON en una ruta como `$.a[0]`, o `$` para el propio texto, como WKT |
| `json_patch_apply` | JSON | El documento con un JSON Patch o un Merge Patch aplicado |
| `json_diff` | Primer JSON, Segundo JSON | El JSON Patch que convierte el primer documento en el segundo |
| `json_schema_check` | JSON | Los errores que tiene el documento frente a un esquema JSON, como JSON; NULL cuando no tiene ninguno |
| `json_normalize` | JSON | El documento como texto JSON normalizado |
| `json_to_xml`, `xml_to_json` | Documento | El documento convertido a XML, o a JSON |
| `xml_well_formed` | XML | El texto cuando es XML bien formado; de lo contrario, NULL |
| `xslt` | XML, Hoja de estilos | El documento transformado por la hoja de estilos XSLT |
| `message_text`, `message_tool_calls` | JSON | El texto de un mensaje de IA, o sus llamadas a herramientas como JSON |

Defina las opciones de una función en `function_options`:

- `java_regex`: `mode`: `matches` (predeterminado, el texto completo), `find` (en cualquier parte), `extract` (el grupo `group` de la primera coincidencia, 0 de forma predeterminada) o `replace` (todas las coincidencias); `flags` `i` ignora mayúsculas y minúsculas.
- `knime_count`: `modifiers`: `i` ignora mayúsculas y minúsculas, `w` cuenta palabras completas entre espacios en blanco.
- `encode` y `decode`: `charset`, un nombre de juego de caracteres de Java; el valor predeterminado es UTF-8.
- `json_patch_apply`: `patch`, la matriz de JSON Patch o el objeto de Merge Patch; `merge` es verdadero para un Merge Patch; `keep` conserva el documento cuando falla una prueba del parche.
- `json_schema_check`: `schema`; `fail` detiene el paso en el primer error en lugar de devolverlo.
- `json_normalize`: `comments` permite comentarios `/* */` y `//`; `fail` (verdadero de forma predeterminada) detiene el paso con texto que no es JSON, y falso da NULL.
- `json_to_xml`: `root`, `item`, `typed`, `parent_keys`, `namespace`, `text_key` y `text_key_enabled`. `xml_to_json`: `text_key`, `comments` y `pis`.
- `list_sort_numeric`: `separator`; `empty`, el texto que se escribe para una lista sin elementos; y `missing`, el texto de un elemento ausente, que se ordena al final.

De forma predeterminada, el paso lee todas las columnas del origen y escribe todas las columnas del origen seguidas de la columna de salida. Defina `source_columns` para leer solo algunas columnas, y `target_columns` (cada una `{source, target, dtype}`) para elegir y ordenar las columnas escritas. Una columna de destino con el mismo nombre que la columna de salida ocupa su lugar, con el tipo de datos indicado.
