## Descripción


Se usa para realizar una combinación externa de 2 tablas de datos y unirlas en una sola tabla de datos según las claves de combinación especificadas. El control **Tipo de combinación** selecciona qué filas sin coincidencia se conservan: una combinación **Combinación izquierda**, **Combinación derecha** o **Combinación externa completa**. El valor predeterminado es una combinación izquierda (todas las filas de la tabla A, con las columnas de la tabla B completadas donde coinciden las claves).


Para obtener más detalles sobre la metodología de la combinación externa, consulte: [Wikipedia SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## Columnas nombradas en tiempo de ejecución

Seleccione **Incluir también columnas nombradas en tiempo de ejecución** para pasar sin cambios todas las columnas de origen que el paso no enumera, tal como las tiene la tabla cuando se ejecuta el paso. Úselo cuando un paso anterior cree columnas cuyos nombres dependan de los datos, como un pivote, de modo que no pueda enumerarlas al crear el paso. Déjelo desactivado para escribir solo las columnas que enumere.

### Tipo de combinación

Elija cómo se conservan las filas sin coincidencia:

- **Combinación izquierda**: conserva todas las filas de la tabla A; las columnas de la tabla B se completan solo donde coinciden las claves de combinación. Es el valor predeterminado.
- **Combinación derecha**: conserva todas las filas de la tabla B; las columnas de la tabla A se completan solo donde coinciden las claves de combinación.
- **Combinación externa completa**: conserva todas las filas de ambas tablas, tengan o no coincidencia en el otro lado.

## Ejemplos


### Combinar fabricantes de automóviles con modelos


En este ejemplo, considere las siguientes tablas de datos de origen. La primera es una lista de fabricantes de automóviles.




| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


A continuación hay una lista de modelos de automóviles con un ID de fabricante. Observe que hay varios modelos sin fabricante.




| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

Para obtener una lista de modelos por fabricante, lo lógico es combinar por *Mfg_ID*. Al aprovechar los conceptos de combinación externa, la salida también podrá mostrar los elementos que no tienen ninguna coincidencia.



Primero, especifique los parámetros de **Table 1 Data Selection**. Se selecciona la tabla de datos de origen y se enumeran todas las columnas.



A continuación, especifique los parámetros de **Table 2 Data Selection.** De nuevo, se selecciona la tabla de datos de origen y se enumeran todas las columnas.



Por último, las condiciones de combinación se establecen en la pestaña **Table Output**. Con el botón **Detectar**, Analyze identifica correctamente la columna *Mfg_ID* que se usará como **Join Key**. Como este ejemplo conserva las filas sin coincidencia de ambas tablas, establezca el **Tipo de combinación** en **Combinación externa completa**. Por último, las 


**Columnas de salida de destino** se especifican automáticamente con el botón **Propagar**. Esto incluye de forma efectiva todas las columnas de todas las tablas, y las columnas de combinación, obviamente, se incluyen una sola vez. Observe que las columnas se ordenan alfabéticamente, primero por *Manufacturer* y después por *ModelName*.



Como era de esperar, la salida final incluye todas las filas de ambas tablas, tengan o no coincidencia en las dos. Por eso, esta vez *Porsche* sí aparece a pesar de no tener modelos. Además, *Batmobile*, *Lightning McQueen* y *Optimus Prime* se incluyen en los resultados aunque ninguno tenga fabricante. Además, ¿quién puede decirles que no?
