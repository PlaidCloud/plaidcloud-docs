## Descripción

Quita una tabla del proyecto por completo: tanto la definición de la tabla como todos sus datos. Esta acción es destructiva e irreversible; una vez que se ejecuta el flujo de trabajo, la tabla desaparece.

Utilícelo cuando las tablas intermedias de un flujo de trabajo ya no se necesiten en pasos posteriores (por ejemplo, para la limpieza tras una transformación de varios pasos). Para vaciar una tabla temporalmente sin quitarla, use en su lugar [Table Clear](/es/reference/workflow-steps/tables/table-clear/).
