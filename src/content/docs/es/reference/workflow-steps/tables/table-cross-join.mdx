## Descripción


Se usa, como cabría esperar, para realizar una combinación cruzada de 2 tablas de datos y unirlas en una sola tabla de datos sin claves de combinación.


Un filtro de origen en cualquiera de las tablas se aplica antes de calcular el tamaño de la combinación, de modo que una combinación cruzada filtrada sobre tablas grandes se ejecuta cuando las filas filtradas son lo bastante pocas.

Para obtener más detalles sobre la metodología de la combinación cruzada, consulte: [Wikipedia SQL Cross Join](https://en.wikipedia.org/wiki/Join_%28SQL%29#Cross_join)

## Columnas nombradas en tiempo de ejecución

Seleccione **Incluir también columnas nombradas en tiempo de ejecución** para pasar sin cambios todas las columnas de origen que el paso no enumera, tal como las tiene la tabla cuando se ejecuta el paso. Úselo cuando un paso anterior cree columnas cuyos nombres dependan de los datos, como un pivote, de modo que no pueda enumerarlas al crear el paso. Déjelo desactivado para escribir solo las columnas que enumere.
