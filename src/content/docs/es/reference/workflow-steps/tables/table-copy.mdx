## Descripción


Crea una copia de una tabla de datos.




<SnippetCommonTableSourceAndTarget />



Al realizar la copia, Analyze comprobará primero si la tabla de destino ya existe. Si existe, no se realizará ninguna acción a menos que esté seleccionada la casilla **Allow Overwriting Existing Table**. En ese caso, la tabla de destino se sobrescribirá.
