## Descripción

El paso **Tabla: cierre de jerarquía** recorre cada fila hacia arriba por su cadena de elementos padre y escribe una fila de salida por cada fila y cada uno de sus ancestros. No hay límite de profundidad. La columna de distancia es 0 para la propia fila, 1 para su elemento padre, y así sucesivamente.

Un recorrido se detiene en una raíz, en un elemento padre que la tabla de nodos no contiene o en un nodo que ya ha encontrado, de modo que un bucle en los ID de elemento padre no puede ejecutarse indefinidamente. Un bucle conserva todos los ancestros hasta el nodo repetido. Un bucle al que no llega ninguna raíz termina en su ID más pequeño.

## Origen y opciones

- **Filas de inicio del recorrido**: la tabla cuyas filas inician los recorridos.
- **Columna de id** y **Columna de elemento padre**: el ID de cada fila y el ID de su elemento padre. NULL, o el propio ID de la fila, indica una raíz.
- **Tabla de nodos** *(opcional)*: la tabla de nodos por la que asciende el recorrido. Déjela en blanco para usar la tabla de origen.
- **Columna de id de nodos** y **Columna de elemento padre de nodos** *(opcional)*: de forma predeterminada son las columnas de id y de elemento padre. Un ID con varias filas sigue una fila raíz o, si no la hay, su elemento padre más pequeño.
- **Columna de ancestro**: la columna de salida que contiene el ID del ancestro. El valor predeterminado es `Ancestor`.
- **Columna de distancia**: los pasos desde la fila de inicio. El valor predeterminado es `Distance`.
- **Cadenas creadas a lo largo de la ruta** *(opcional)*: una fila por cada columna de texto que se va acumulando a medida que el recorrido asciende. Cada fila tiene:
  - **Columna de salida**: la columna nueva.
  - **Columna de origen**: la columna que se lee como texto, y **Columna de nodos** para leer de la tabla de nodos cuando es distinta.
  - **Delimitador**: el texto entre valores.
  - **Distinto**: omite un valor que el texto ya contiene.
  - **Raíz primero**: coloca cada ancestro antes del texto acumulado hasta el momento.
- **Tabla de salida**: donde se escribe el resultado.

La salida contiene las columnas de id y de elemento padre, las columnas de ancestro y de distancia, y una columna de texto por cada cadena que cree.
