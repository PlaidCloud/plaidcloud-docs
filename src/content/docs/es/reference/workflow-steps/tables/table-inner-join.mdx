## Descripción


Se usa, como cabría esperar, para realizar una combinación interna de 2 tablas de datos y unirlas en una sola tabla de datos según las claves de combinación especificadas.


Para obtener más detalles sobre la metodología de la combinación interna, consulte: [Wikipedia SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## Columnas nombradas en tiempo de ejecución

Seleccione **Incluir también columnas nombradas en tiempo de ejecución** para pasar sin cambios todas las columnas de origen que el paso no enumera, tal como las tiene la tabla cuando se ejecuta el paso. Úselo cuando un paso anterior cree columnas cuyos nombres dependan de los datos, como un pivote, de modo que no pueda enumerarlas al crear el paso. Déjelo desactivado para escribir solo las columnas que enumere.

## Ejemplos


### Combinar fabricantes de automóviles con modelos


En este ejemplo, considere las siguientes tablas de datos de origen. La primera es una lista de fabricantes de automóviles.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

A continuación hay una lista de modelos de automóviles con un ID de fabricante. Observe que hay varios modelos sin fabricante.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

Para obtener una lista de modelos por fabricante, lo lógico es combinar por *Mfg_ID*.


Primero, especifique los parámetros de **Table 1 Data Selection**. Se selecciona la tabla de datos de origen y se enumeran todas las columnas.



A continuación, especifique los parámetros de **Table 2 Data Selection**. De nuevo, se selecciona la tabla de datos de origen y se enumeran todas las columnas.



Por último, las condiciones de combinación se establecen en la pestaña **Table Output**. Con el botón **Detectar**, Analyze identifica correctamente la columna *Mfg_ID* que se usará como **Join Key**. Por último, las 


**Columnas de salida de destino** se especifican automáticamente con el botón **Propagar**. Esto incluye de forma efectiva todas las columnas de todas las tablas, con todas las columnas de combinación incluidas una sola vez. Observe que las columnas se ordenan alfabéticamente, primero por *Manufacturer* y después por *ModelName*.



Como era de esperar, la salida final solo incluye los valores que tenían coincidencia en ambas tablas. Por eso *Porsche* no aparece, ya que no tenía modelos. Del mismo modo, el 


*Batmobile* no tenía fabricante (era un trabajo a medida), por lo que no se incluye.
