## Descripción

El paso **Tabla: dividir texto** divide el texto de una columna en un separador y escribe las partes como columnas nuevas o como filas nuevas. El número de columnas se decide cuando se ejecuta el paso, a partir del valor con más partes, por lo que no necesita conocerlo de antemano.

## Origen y opciones

- **Tabla de origen** y **Tabla de salida**: la tabla que se lee y la tabla que se escribe.
- **Columna que se dividirá**: la columna que se divide. Un número se divide como su texto.
- **Separador**: el texto literal entre las partes. Puede tener cualquier longitud y no es un patrón. Los espacios se conservan tal como se escriben.
- **Dividir en**: **Columnas** o **Filas**.
  - **Columnas** escribe `<column>_1`, `<column>_2`, etc., tantas como partes tenga el valor con más partes. Un valor con menos partes recibe NULL en las restantes.
  - **Filas** escribe una fila por parte, con la parte en lugar de la columna. Las partes vacías se conservan como filas.
- **Recortar los espacios alrededor de cada fragmento**: activada de forma predeterminada.
- **Conservar la columna original**: activada de forma predeterminada. En el modo de columnas conserva la columna dividida. En el modo de filas, además escribe el valor sin dividir en `<column>_original`.

Un resultado vacío reemplaza la tabla de salida. Nunca deja filas de una ejecución anterior.

### Configuración adicional para columnas

**Más opciones de división** también incluye estos ajustes al dividir en columnas:

- **Prefijo del nombre de las partes** (`prefix`): nombra las partes `<prefix><n>` en lugar de `<column>_<n>`. **Número de la primera parte** (`start`, 1 de forma predeterminada) es el número de la primera parte.
- **Nombres de las columnas de partes** (`names`): los nombres de las columnas de partes, en orden. Se escriben exactamente esas columnas, a menos que active **Escribir solo tantas columnas con nombre como tenga el valor más largo** (`fit`): entonces solo se escriben tantas como tenga el valor con más partes.
- **Tipo de las partes** (`dtype`): el tipo de las partes: `text` (predeterminado), `integer`, `bigint`, `double`, `boolean`, `date` o `timestamp`. Una parte que no se pueda leer como ese tipo es NULL.
- **Caracteres que quitar** (`strip`): los caracteres que se quitan de ambos extremos de cada parte, en lugar de los espacios que quita **Recortar los espacios alrededor de cada fragmento**.
- **La columna contiene una colección de KNIME** (`collection`): la columna contiene un valor de lista de un flujo de trabajo de KNIME convertido. Sus elementos son las partes y no se usa el separador: un elemento ausente es NULL y una lista vacía no tiene partes.

**Nodo de KNIME** (`knime_config`) ejecuta con este paso uno de los nodos Line Chopper, Expand Vector o Sample and Expand Vector de KNIME: `chopper` escribe los primeros tokens separados por espacios en blanco de una columna, `expand_vector` escribe los elementos de una columna de vector como columnas, con las posiciones que se conservan indicadas en la tabla **Tabla de posiciones de elementos** (`source_b`), y `sample_expand_vector` expande una muestra aleatoria de los elementos y escribe los nombres de las columnas muestreadas en la tabla indicada en **Tabla de nombres de columnas muestreadas** (`targets`).
