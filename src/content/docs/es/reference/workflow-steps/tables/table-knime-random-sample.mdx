## Descripción

El paso **Tabla: Muestra aleatoria de KNIME** realiza la extracción aleatoria de un nodo de KNIME con el generador de números aleatorios que usa KNIME, de modo que un nodo con semilla extrae las mismas filas o valores en PlaidCloud que en KNIME. Los [flujos de trabajo de KNIME migrados](/es/guides/workflows/migrate-knime-workflows/) usan este paso para Row Sampler, Table Partitioner, Equal Size Sampling, Bootstrap Sampling, Shuffle, X-Partitioner y los nodos de generación aleatoria de datos.

La extracción lee la tabla de origen en el flujo de trabajo, por lo que admite una tabla de 10,000,000 de filas como máximo; una tabla mayor hace que el paso falle.

El formulario del paso tiene una sección **Tablas** para las tablas de origen y de salida, una sección **Extracción** para el **Método**, la **Semilla** y el tamaño de la muestra, y una sección **Columnas** para las columnas que se leen y se escriben.

## Configuración

- `source` y `target_frame`: la tabla que se lee y la tabla en la que se escribe.
- `position_column`: la columna que contiene la posición de cada fila, basada en 0. El valor predeterminado es `_knime_pos`.
- `method`: la extracción:
  - `random`, `stratified`, `equal_exact` y `equal_approximate` conservan las posiciones de las filas que selecciona una extracción de Row Sampler, Table Partitioner o Equal Size Sampling. `class_column` y `class_dtype` indican la columna de clase de una extracción estratificada o de igual tamaño.
  - Cualquier otro método escribe su extracción junto a las posiciones de fila: `uniform`, `gaussian`, `gamma`, `beta`, `label`, `label_dependent`, `label_from_table`, `boolean`, `mersenne_twister`, `sobol` y `halton` (generación aleatoria de datos), `shuffle`, `bootstrap`, `match` (Random Matcher), `item_insert` (Random Item Inserter), `stress` (Stresser), `sample_data` (Sample Data Generator, sin tabla de origen), `kfold` (particiones de X-Partitioner), `p_square` (estimaciones de percentiles P² por grupo), `set_bits` (vectores de bits), `equal_count_edges` (los bordes de recuento igual del Binner) y `border_texts` (los textos de borde del Auto-Binner).
- `seed`: la semilla del flujo aleatorio. Si está vacía, se toma del reloj, como hace KNIME sin semilla, por lo que las filas difieren de una ejecución a otra.
- `count`, `percentage` y `relative`: cuántas filas se extraen: un recuento o, con `relative`, un porcentaje. `count_column` toma el recuento de una columna de origen, para un recuento que solo se conoce cuando se ejecuta el flujo de trabajo.
- `parameters`: la configuración del nodo que leen los métodos de extracción, como la distribución de una extracción `gaussian` o el número de particiones de una extracción `kfold`.
- `source_columns` y `target_columns`: para los métodos de extracción, las columnas que se leen y las que se escriben, con la columna de posición primero.
- `source_b` y `source_columns_b`: una segunda entrada, como la tabla de categorías de `label_from_table` o la tabla de la que extrae `match`. `target_frame_b` y `target_columns_b` reciben los centros de los clústeres de `sample_data`.
