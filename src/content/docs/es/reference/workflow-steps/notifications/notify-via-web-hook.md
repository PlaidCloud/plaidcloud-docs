## Descripción



Envía una notificación mediante una solicitud POST a una URL de webhook: es útil para activar acciones personalizadas posteriores, alertar a plataformas de integración (Zapier, n8n, Make) o dirigir bots de Slack/Teams/Discord que no usan conectores nativos.

El formato de la carga y los encabezados personalizados son configurables. El servicio receptor es responsable de lo que ocurra después.
