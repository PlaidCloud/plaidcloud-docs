## Descripción



Envía una notificación por correo electrónico a una lista de distribución de PlaidCloud: una lista con nombre de destinatarios que se administra en la configuración del espacio de trabajo. Es útil para actualizaciones de estado, notificaciones de finalización o alertas de error que deben llegar a un público definido.

Los mensajes se envían desde el servicio de notificaciones de PlaidCloud. Las listas de distribución se administran de forma centralizada para que los autores de flujos de trabajo no incrusten direcciones de correo electrónico en las definiciones de los flujos de trabajo.


## Seleccionar la lista de distribución de PlaidCloud


Seleccione una única lista de distribución en el menú desplegable. Las listas de distribución se pueden crear con Herramientas. Para obtener más información sobre cómo crear una lista de distribución, consulte: [Herramientas de PlaidCloud: Distro](/es/administration/access/member-management/#administración-de-listas-de-distribución-distro).



## Mensaje


Especifique el **Asunto** y el **Cuerpo** como desee.



Tenga en cuenta que tanto las variables del proyecto como las variables del flujo de trabajo están disponibles para usarse con esta transformación, tanto en la línea de asunto como en el cuerpo del mensaje.



Además, se permite código HTML estándar en el cuerpo para personalizar aún más el aspecto de los mensajes de correo electrónico.


## Ejemplos


En este ejemplo se usan todas las variables del sistema. Además, se usa un poco de HTML para dar formato a la primera línea del cuerpo. Al ejecutar esta transformación, se enviará el siguiente correo electrónico a todos los miembros especificados en la lista de distribución:


* DE: [info@tartansolutions.com](mailto:info%40tartansolutions.com) (recuerde que todos los mensajes provienen de esta dirección)
* Asunto: DEMO Analyze Demo Running


<Aside>Los destinatarios individuales del mensaje de correo electrónico **no** podrán ver los nombres de los demás miembros de la lista de distribución.</Aside>
