## Descripción



Activa una notificación a través de un agente de PlaidLink: es útil cuando las notificaciones deben entregarse mediante sistemas locales (alertas internas, webhooks propios, SMTP heredado) a los que PlaidCloud no puede llegar directamente.

El agente recibe la carga de la notificación y la envía localmente según su configuración.
