## Descripción


Envía un mensaje directo (DM) de Twitter desde [@plaidcloud](https://twitter.com/plaidcloud).



### Cuenta de Twitter


Especifique la cuenta de Twitter que recibirá el DM de @plaidcloud. Este usuario debe seguir a @plaidcloud para recibir el mensaje. Se permite, aunque no es obligatorio, anteponer el signo de arroba (@) al nombre de usuario.



### Mensaje


Escriba el mensaje deseado. Analyze no permite un valor de más de 140 caracteres.


Tenga en cuenta que tanto las variables del proyecto como las variables del flujo de trabajo están disponibles para usarse con esta transformación.


<Aside type="danger">Al usar variables, es posible generar mensajes que superen el límite de 140 caracteres. En ese caso, el mensaje NO se enviará. En su lugar, se escribirá en el registro el siguiente error: *Twitter API returned a 403 (Forbidden), There was an error sending your message: The text of your direct message is over 140 characters.</Aside>

## Ejemplos

En este ejemplo, se envía un DM desde [@PlaidCloud](https://twitter.com/plaidcloud) a [@tartansolutions](https://twitter.com/tartansolutions). Se usan variables del sistema en el mensaje. El mensaje final dice *Analyze Demo is running on #PlaidCloud*.
