## Descripción

El paso **Importación de archivo espacial** lee un archivo espacial (MapInfo `.TAB`,
ESRI `.shp`, `.kml`, `.geojson` o SRC `.geo`) y sus archivos complementarios en una
tabla, con una fila por elemento y una columna de geometría WKT. Es el equivalente de
la herramienta *Input Data* de Alteryx apuntada a un archivo espacial y se ejecuta en el motor
de flujos de trabajo (GDAL).

## Parámetros de importación

- **Origen**: el archivo espacial en el almacén de documentos. Sus archivos
  complementarios (por ejemplo, los `.dat`/`.map`/`.id`/`.dbf` de un `.TAB`, o los `.shx`/`.dbf`/`.prj` de un shapefile)
  se leen automáticamente desde la misma ubicación.
- **Tabla de destino**: la tabla en la que se escriben los elementos.

## Notas

El esquema de salida se toma del archivo, por lo que no hay asignación de columnas. La geometría
propietaria de un archivo SRC `.geo` no se puede leer; sus atributos `.dbf` se
importan con valores de geometría vacíos.
