## Descripción

El paso **Spatial Match (Intersect / Unmatched)** empareja cada geometría de destino
con las geometrías del universo con las que se relaciona y puede emitir la
**geometría de intersección** de cada par coincidente (*IntersectPoly*) o las
filas de destino **sin coincidencia**. Complementa el paso SQL
[Coincidencia espacial](/es/reference/workflow-steps/spatial/spatial-match/), que
cubre el caso simple de pares coincidentes; este paso respaldado por un ejecutor cubre las dos
salidas que no se pueden expresar en SQL de base de datos.

## Orígenes y opciones

- **Tabla de destino** / **Tabla universo**: las geometrías que se van a comparar y los
  candidatos con los que se comparan.
- **Tabla de salida**: el lugar donde se escribe el resultado.
- **Geometría de destino / Geometría del universo**: la columna de geometría WKT de cada lado.
- **Relación**: intersects, within, contains, touches, crosses, overlaps, equals o disjoint. *Equals* solo hace coincidir geometrías topológicamente iguales, y *disjoint* hace coincidir pares que no comparten ningún punto; una geometría nula nunca coincide con *disjoint*.
- **Multiple Rules**: una coincidencia puede relacionar varias columnas de geometría de destino y de universo a la vez, cada regla con su propia relación. El valor de `joiner` indica si un par debe cumplir todas las reglas (*and*, el valor predeterminado) o cualquiera de ellas (*or*). La conversión de Savant produce coincidencias de varias reglas. Una relación o un valor de joiner desconocidos hacen que el paso falle indicando el nombre, en lugar de ejecutarse como intersects.
- **Emitir también la geometría de intersección (IntersectPoly)**: agrega como columna la geometría
  de solapamiento de cada par coincidente.
- **Salida**: *Pares coincidentes* o *Filas de destino sin coincidencia*.

## Asignación del destino y del universo

Cada entrada tiene una pestaña de asignación que enumera sus columnas, que se usa para alimentar
los selectores de geometría y para transferir columnas a la salida.
