## Descripción

El paso **Spatial Info** mide cada geometría y agrega las medidas como
columnas. Es el equivalente de la herramienta *Spatial Info* de Alteryx y se ejecuta en el
motor de flujos de trabajo.

Las medidas son **geodésicas WGS84**, no planares. Esto es importante: la forma SQL de
estas medidas es un valor planar en grados² escalado por una constante ecuatorial y,
como esa constante no se reduce con la longitud a medida que aumenta la latitud,
**sobrestima** el área y la longitud, aproximadamente una cuarta parte de más en las latitudes de EE. UU.
Calcularlas de forma geodésica da una única respuesta que coincide con Alteryx en cada
almacén de datos.

## Origen y opciones

- **Tabla de origen** / **Tabla de salida**: las geometrías de entrada y el lugar
  donde se escriben las filas medidas.
- **Columna de geometría**: la columna de geometría WKT que se mide.
- **Medidas**: qué medidas se agregan. Cada selección agrega las columnas
  que se indican a continuación.
- **Radio de la esfera (km)** *(opcional)*: mide sobre una esfera de este radio.
  Déjelo en blanco para medir sobre el elipsoide WGS84.

## Columnas de salida

| Medida | Columnas agregadas | Tipo |
|---|---|---|
| Área (millas) | `AreaSqMi` | número |
| Área (km) | `AreaSqKm` | número |
| Longitud (millas) | `LengthMi` | número |
| Longitud (km) | `LengthKm` | número |
| Coordenadas del centroide | `CentroidX`, `CentroidY` | número |
| Coordenadas del rectángulo delimitador | `BR_Left`, `BR_Top`, `BR_Right`, `BR_Bottom` | número |
| Objeto centroide | `Centroid` | geometría WKT |
| Objeto rectángulo delimitador | `BoundingRect` | geometría WKT |
| Polígono del rectángulo delimitador | `BoundingRectPolygon` | geometría WKT |
| Es válida | `IsValid` | booleano |
| Tipo de objeto | `SpatialObjType` | texto |
| Número de partes | `NumParts` | número |
| Número de puntos | `NumPoints` | número |
| Coordenadas del punto final | `EndPointX`, `EndPointY` | número |
| Objeto punto final | `EndPoint` | geometría WKT |

`IsValid` indica si la geometría tal como se suministró es una forma válida, antes de cualquier reparación.

El objeto rectángulo delimitador y el polígono del rectángulo delimitador se serializan en el
mismo anillo de cinco vértices en WKT, por lo que ambas columnas contienen el mismo valor.

## Notas

El tipo de objeto, el número de partes, el número de puntos y los puntos finales se agregan con nombres de
columna provisionales: Alteryx documenta las medidas pero no da nombre a ninguna columna
de salida, por lo que los nombres exactos se verificarán después con un flujo de trabajo real.
El único tipo de información que no se convierte es la **clave de Peano**, un índice
espacial propietario de Alteryx sin especificación pública: se omite, y la conversión emite
una nota que la nombra para que la omisión sea visible en el flujo de trabajo convertido.
