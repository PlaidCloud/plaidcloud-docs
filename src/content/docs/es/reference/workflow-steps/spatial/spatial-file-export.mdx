## Descripción

El paso **Espacial: exportación de archivo** escribe una tabla en un archivo espacial de una cuenta de documentos, con un elemento por fila: la geometría de una columna WKT y las demás columnas como atributos del elemento. Combínelo con [Importación de archivo espacial](/es/reference/workflow-steps/spatial/spatial-file-import/).

El formulario del paso tiene una sección **Origen y archivo** para la tabla de origen, sus columnas, el archivo de salida y lo que ocurre cuando el archivo ya existe, y una sección **Geometría** para la columna de geometría y el sistema de coordenadas. Los [flujos de trabajo de KNIME migrados](/es/guides/workflows/migrate-knime-workflows/) usan este paso para sus escritores de archivos geoespaciales.

## Configuración

- **Tabla de origen** (`source`): la tabla que se exporta. **Columnas de origen** (`source_columns`) enumera las columnas que se escriben.
- **Archivo de salida** (`output_file`): la cuenta de documentos y la ruta del archivo. La extensión determina el formato: `.shp` (shapefile de ESRI), `.geojson` o `.json` (GeoJSON), `.gpkg` (GeoPackage), `.kml`, `.gml`, o `.tab` y `.mif` (MapInfo). Un formato compuesto por varios archivos, como un shapefile, se escribe con sus archivos complementarios al lado.
- **Columna de geometría** (`geometry_column`): la columna que contiene la geometría de cada elemento como WKT. El valor predeterminado es `SpatialObj`.
- **Sistema de coordenadas** (`crs`): el sistema de referencia de coordenadas en el que están las geometrías, como `EPSG:4326`, que se escribe con el archivo.
- **Un archivo que ya existe** (`if_exists`): **Sobrescribirlo** (`overwrite`, predeterminado) reemplaza un archivo que ya está allí; **Hacer fallar el paso sin escribir nada** (`fail`) detiene el paso antes de escribir nada.
