## Descripción

El paso **Espacial: reproyectar** transforma la geometría WKT de cada fila de un sistema de referencia de coordenadas a otro y escribe el resultado en una tabla de salida, con las demás columnas transferidas.

El formulario del paso tiene una sección **Tablas** para las tablas de origen y de salida y sus columnas, y una sección **Proyección** para la columna de geometría, los dos sistemas de coordenadas y la columna de salida. Los [flujos de trabajo de KNIME migrados](/es/guides/workflows/migrate-knime-workflows/) usan este paso para sus nodos de proyección.

## Configuración

- **Tabla de origen** (`source`) y **Tabla de salida** (`target_frame`): la tabla que se lee y la tabla que se escribe.
- **Columna de geometría** (`geometry_column`): la columna que contiene cada geometría como WKT. El valor predeterminado es `SpatialObj`.
- **Sistema de coordenadas de origen** (`source_crs`): el sistema de referencia de coordenadas en el que están las geometrías, como `EPSG:4326`.
- **Sistema de coordenadas de destino** (`target_crs`): el sistema de referencia de coordenadas al que se proyectan, como `EPSG:3857`.
- **Columna de geometría proyectada** (`output_column`): la columna que recibe la geometría proyectada. Déjela vacía para reemplazar la propia columna de geometría.
- **Columnas de origen** (`source_columns`) y **Columnas de salida** (`target_columns`): las columnas que se leen y las columnas que se transfieren, con sus tipos de datos.

Una fila sin geometría conserva una geometría proyectada vacía.
