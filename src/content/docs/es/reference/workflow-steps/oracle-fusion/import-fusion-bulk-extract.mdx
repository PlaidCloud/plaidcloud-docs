## Descripción

Importa una entidad de Oracle Fusion Cloud a través de su [conexión de Oracle Fusion](/es/guides/connections/oracle-fusion/) por la vía de extracción masiva FBDI/BI Publisher de Oracle: PlaidCloud envía un trabajo de exportación, lo sondea hasta que termina, descarga el archivo resultante y lo escribe en una tabla del proyecto. Use este paso en lugar de [Import Fusion Entity](/es/reference/workflow-steps/oracle-fusion/import-fusion-entity/) para una extracción demasiado grande o lenta para una llamada directa a OData/BIP.

## Configuración

| Campo | Obligatorio | Notas |
|---|---|---|
| Conexión de Fusion | Sí | La conexión de Oracle Fusion por la que se lee. |
| Tabla de destino | Sí | La tabla del proyecto en la que se escriben los resultados. Se sobrescribe por completo en cada ejecución. |
| Tipo de entidad | Sí | Qué entidad se extrae. Valor predeterminado `gl_balances`. Una de `gl_balances`, `journal_batches`. |
| Filtros | No | El mismo conjunto de filtros que [Import Fusion Entity](/es/reference/workflow-steps/oracle-fusion/import-fusion-entity/): filtros de intervalo (`ge`/`le`) sobre campos de fecha, de período contable y de saldo/importe numérico, además de filtros de igualdad sobre campos discretos. Se aplican a nivel del trabajo de extracción. |

<Aside type="caution">
Este paso espera un trabajo de exportación asíncrono: cabe esperar que tarde bastante más que [Import Fusion Entity](/es/reference/workflow-steps/oracle-fusion/import-fusion-entity/) para la misma cantidad de filas. Úselo solo cuando la extracción sea realmente demasiado grande para una llamada directa a OData/BIP.
</Aside>
