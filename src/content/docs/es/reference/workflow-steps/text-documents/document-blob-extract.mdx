## Descripción

El paso **Documento: leer blob** lee documentos completos en una columna de texto base64 llamada `Blob`, con una fila por documento. Lea un documento que usted elija, o un documento por cada fila de una tabla de rutas. Los pasos posteriores, como [Image OCR](/es/reference/workflow-steps/text-documents/image-ocr/) (paso) y [Text NLP AI](/es/reference/workflow-steps/text-documents/nlp-ai/) (paso), leen el contenido.

## Origen y opciones

- **Tabla de rutas de documentos** *(opcional)*: defínala para leer un documento por cada fila. Déjela en blanco para leer el único documento que elija.
- **Columna de ruta**: la columna de esa tabla que contiene la ruta de cada documento.
- **Documento**: la cuenta de documentos y la ruta que se leerán cuando no hay tabla.
- **Generar error si falta un documento**: desactivada de forma predeterminada. Desactivada, un documento ausente se omite con una advertencia que nombra su ruta, y un único documento ausente escribe una tabla vacía. Activada, el paso falla.
- **Documento más grande (bytes)** *(opcional)*: un documento mayor falla en lugar de dividirse.
- **Tabla de salida**: dónde se escriben las filas.

Las columnas de la tabla de rutas pasan a la salida.

El grupo **Más opciones** define estas claves:

- **Conservar la fila de un documento ausente, con un blob vacío** (`keep_missing`): conserva la fila de un documento ausente, con un `Blob` vacío, en lugar de omitirla.
- **Leer el documento como un archivo, una fila por entrada** (`unpack_enabled`): con un único documento elegido y sin tabla de rutas, lee el documento como un archivo comprimido (zip, jar, tar, tar.gz, tar.bz2, cpio, ar, o un único archivo `gz` o `bz2`) y escribe una fila por entrada: `Path` (dentro de la **Carpeta de entradas**, `unpack_destination`), `Directory`, `Status` (`Extracted` o `Folder`) y `Blob` (ninguno para una carpeta). **Codificación de los nombres de entrada** (`unpack_charset`, `cp437` de forma predeterminada) es la codificación de los nombres de entrada zip que no son UTF-8. Un documento ausente no da ninguna fila.

Para volver a escribir blobs en documentos, use [Document: Write Blob](/es/reference/workflow-steps/text-documents/document-blob-write/) (paso).
