## Pasos de extracción ad hoc

Tres pasos buscan en SAP, previsualizan y planifican la extracción, y guardan el resultado en una tabla. Uno lee una tabla, otro ejecuta una transacción o un informe, y otro ejecuta una consulta de SAP Query guardada. Consulte [Extracciones ad hoc de SAP ECC / S/4HANA](/es/guides/connections/sap-adhoc-extract/).
