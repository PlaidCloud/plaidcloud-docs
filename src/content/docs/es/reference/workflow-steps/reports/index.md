## Bloques de construcción de informes

Los flujos de trabajo de informes de Alteryx convertidos componen un documento a partir de estos pasos. Chart,
Image, Map, Table y Text generan cada uno una pieza; Layout, Visual Layout y
Overlay organizan las piezas; Render escribe el resultado compuesto en un PDF.
