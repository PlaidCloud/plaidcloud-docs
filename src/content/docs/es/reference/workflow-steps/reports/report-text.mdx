## Descripción

El bloque de **texto** de un informe compuesto. Equivale a la herramienta correspondiente de *Reporting* / *Portfolio Composer* de Alteryx y se ejecuta en el motor de flujos de trabajo (reportlab / matplotlib); el generador es una aproximación de la salida de Alteryx.

## Origen y opciones

- **Tabla de origen**: los datos que alimentan esta pieza del informe.
- **Tabla de salida**: la tabla en la que se escribe el fragmento generado.
- **Orden del informe**: el orden de esta pieza dentro de un informe compuesto.
- **Contenido de texto**: el texto que se genera.

## Referencia a una columna en el texto

El contenido de texto puede nombrar una columna entre corchetes, y el valor se imprime
en su lugar: `[Year] Results` imprime `2026 Results`. Un Report
Text de Alteryx convertido conserva las referencias a campos que ya tuviera su texto, incluida la
forma con formato que Alteryx escribe como `[Year:A]`.

Se compone un único texto para toda la tabla de origen, por lo que la columna que nombre debe
tener el mismo valor en todas las filas que lea. Resuma la columna en un paso anterior si
contiene más de un valor: un bloque de texto no puede imprimir varios valores a la vez.

`[CurrentYear]` imprime el año en que se genera el informe y no necesita ninguna columna.

Unas pocas reglas mantienen a salvo la prosa ordinaria:

- Un nombre que coincide con una columna siempre se reemplaza.
- Un nombre que no coincide con ninguna columna detiene el paso e informa de ello, pero solo cuando
  no podría ser otra cosa que una referencia: un formato escrito pegado a los
  dos puntos, como en `[Quarter:A]`.
- El texto entre corchetes se imprime tal como lo escribió. `[12:30]` sigue siendo una hora
  y `[Note: continued]` sigue siendo un inciso, porque un número solo no es un nombre de columna
  y la prosa es lo que deja un espacio después de los dos puntos.

El formato en sí no se aplica: el valor se imprime tal como lo contiene la columna, así que
dé formato a la columna en un paso anterior si necesita separadores de millares o un formato de fecha.

## Columnas

La pestaña **Columnas** asigna las columnas de origen disponibles para la pieza del informe.
