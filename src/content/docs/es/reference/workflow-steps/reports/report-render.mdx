## Descripción

El **render** de las piezas del informe compuesto en un documento PDF. Equivale a la herramienta correspondiente de *Reporting* / *Portfolio Composer* de Alteryx y se ejecuta en el motor de flujos de trabajo (reportlab / matplotlib); el generador es una aproximación de la salida de Alteryx.

## Origen y opciones

- **Tabla de origen**: los datos que alimentan esta pieza del informe.
- **Tabla de salida**: la tabla en la que se escribe el fragmento generado.
- **Orden del informe**: el orden de esta pieza dentro de un informe compuesto.
- **Width / Height**: el tamaño de la imagen incrustada, en píxeles.
- **Archivo de salida**: la ruta del almacén de documentos para el archivo generado.

- **Formato de salida** (`output_format`): **PDF** (`pdf`, el valor predeterminado) o **Página HTML (autónoma)** (`html`) para escribir el informe como una única página HTML autónoma. Asigne al archivo la extensión `.html`.
- **Segunda tabla de origen** (`source_b`): una segunda tabla de entrada, de modo que el render componga las piezas de ambas entradas.

## Columnas

La pestaña **Columnas** asigna las columnas de origen disponibles para la pieza del informe.
