## Descripción

La **tabla** de los datos de origen de un informe compuesto. Equivale a la herramienta correspondiente de *Reporting* / *Portfolio Composer* de Alteryx y se ejecuta en el motor de flujos de trabajo (reportlab / matplotlib); el generador es una aproximación de la salida de Alteryx.

## Origen y opciones

- **Tabla de origen**: los datos que alimentan esta pieza del informe.
- **Tabla de salida**: la tabla en la que se escribe el fragmento generado.
- **Orden del informe**: el orden de esta pieza dentro de un informe compuesto.
- **Columnas**: las columnas de origen que se incluyen (en blanco = todas).

## Columnas

La pestaña **Columnas** asigna las columnas de origen disponibles para la pieza del informe.
