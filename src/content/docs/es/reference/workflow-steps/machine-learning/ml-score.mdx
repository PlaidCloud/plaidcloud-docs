## Descripción

El paso **ML: puntuar** puntúa una tabla de datos con un modelo entrenado por [ML: entrenar modelo](/es/reference/workflow-steps/machine-learning/ml-train/) y escribe los datos con una columna de predicción anexada. Como el modelo llega como una tabla normal, puede entrenar una vez y puntuar muchas tablas, o volver a puntuar cada vez que lleguen datos nuevos. El paso se ejecuta como un trabajo administrado de PlaidCloud (como el paso LLM).

## Pestaña de puntuación

- **Tabla de datos**: la tabla que se puntúa. Debe contener todas las columnas de características con las que se entrenó el modelo.
- **Tabla del modelo**: una tabla de modelo escrita por un paso ML: entrenar modelo. El paso falla si la tabla está vacía o si falta alguna parte del modelo almacenado.
- **Tabla de salida**: dónde se escriben los datos puntuados.
- **Columna de predicción**: el nombre de la columna anexada. Déjelo en blanco para usar `prediction`. El paso falla si el nombre ya existe en la tabla de datos.

## Salida

La tabla de salida contiene todas las columnas de la tabla de datos más la columna de predicción: etiquetas de clase de texto para los clasificadores y valores numéricos para los regresores. Los valores de las características se preparan exactamente como en el momento del entrenamiento, y los valores categóricos que el modelo nunca vio durante el entrenamiento se ignoran en lugar de causar un error.

La tabla del modelo debe tener la forma que escribe un paso ML: entrenar modelo: el conjunto completo de columnas del modelo, un algoritmo conocido y todas las partes del modelo almacenado presentes. El propio modelo se carga con una restricción que rechaza cualquier cosa ajena a la pila científica estándar, de modo que una fila de modelo creada a mano no puede ejecutar código arbitrario.

### Más columnas de salida

La sección **Opciones de puntuación** tiene estos campos. Los flujos de trabajo de KNIME convertidos también los usan.

- **Columnas de probabilidad de clase** (`probability_column_template`): para un clasificador, anexa una columna de probabilidad por clase, con el nombre dado por esta plantilla en la que se reemplaza `{class}`. **Probabilidades antes de la predicción** (`probabilities_first`) las coloca antes de la columna de predicción, y **Ordenar las clases según su primera aparición en el entrenamiento** (`classes_in_domain_order`) las ordena según el orden en que las clases aparecen por primera vez en los datos de entrenamiento en lugar de alfabéticamente.
- **Columna de confianza** (`confidence_column`): para un clasificador, anexa la probabilidad de la clase ganadora con este nombre.
- **Columna de varianza** (`variance_column`): para un regresor de bosque, anexa la varianza de las predicciones de los árboles con este nombre.
- **Columna de recuento de modelos** (`model_count_column`): para un modelo de árboles, anexa el número de árboles con este nombre.
- **Orden de las columnas añadidas** (`column_order`): el orden de las columnas anexadas. En blanco: predicción, probabilidades, confianza, varianza y, por último, recuento de modelos.
- **Escribir en su lugar** (`report`): escribe una de las propias tablas del modelo en lugar de los datos puntuados, como `variable_importance`, `coefficients`, `statistics`, `pmml` (el modelo como documento PMML), `centers`, `cluster_counts` o `association_rules`.
- **Formato del modelo** (`model_format`): `pmml` puntúa con un documento PMML: la tabla del modelo contiene el documento, o el modelo de un aprendiz que tiene una forma PMML.
- **Configuración del algoritmo** (`algorithm_settings`): configuración de la puntuación o del informe específica del algoritmo del modelo, como el número de componentes a los que proyecta un modelo `pca`.
- **Tercera tabla** (`source_c`): una tercera tabla que leen algunos algoritmos, como el bosque aleatorio que usa un modelo `knn_distance`.

Un asistente de IA o la API REST también pueden establecer `report` en `shap_values`.

## Límites y advertencias

- **Conjunto de trabajo en memoria**: la tabla de datos se lee en memoria, por lo que el paso está pensado para aproximadamente un millón de filas por ejecución.
- **Flujos de trabajo de Alteryx convertidos**: una herramienta Predict convertida fija la columna de predicción al nombre de la variable de destino con el sufijo `_predicted`.
