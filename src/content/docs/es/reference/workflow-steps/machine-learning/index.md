Entrene un modelo con cualquier tabla, llévelo a lo largo del flujo de trabajo como una tabla de modelo y puntúe tablas de datos con él.

## Pasos

- [ML: entrenar modelo](/es/reference/workflow-steps/machine-learning/ml-train/): ajuste un modelo de scikit-learn (clasificación o regresión) sobre una tabla de origen y escriba una tabla de modelo consultable con el modelo ajustado, los parámetros, la lista de características y las métricas de entrenamiento.
- [ML: puntuar](/es/reference/workflow-steps/machine-learning/ml-score/): puntúe una tabla de datos con una tabla de modelo entrenado y anexe una columna de predicción.

Consulte [Migrar flujos de trabajo de Alteryx](/es/guides/workflows/migrate-alteryx-workflows/#conversiones-de-aprendizaje-automático-assisted-modeling) para saber cómo se convierten las canalizaciones de Assisted Modeling de Alteryx en estos pasos.
