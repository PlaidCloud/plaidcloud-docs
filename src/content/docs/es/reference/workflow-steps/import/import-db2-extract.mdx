## Descripción

Importe un archivo de extracto de IBM DB2 desde el almacenamiento de PlaidCloud Document. Es útil cuando el servidor DB2 solo es accesible desde la infraestructura local: un proceso externo envía el extracto al almacenamiento de PlaidCloud Document y este paso lo lee desde allí a una tabla de proyecto.

Para el acceso en vivo a DB2 (sin archivo de extracto), conéctese mediante la conexión estándar de [IBM DB2](../../../connectors/databases/ibm-db2/) y use [Importar tablas de bases de datos externas](../import-external-database-tables/).
