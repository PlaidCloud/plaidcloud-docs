## Descripción



Importa archivos de datos de SPSS (formatos .sav y .zsav) a tablas de proyecto de PlaidCloud. Resulta útil para datos de encuestas, datos de investigación en ciencias sociales o cualquier canalización que interopere con herramientas basadas en SPSS.

Las etiquetas de variable y las etiquetas de valor se conservan cuando el formato las admite.
