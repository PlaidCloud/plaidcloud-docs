## Descripción

Importe archivos Alteryx YXDB desde PlaidCloud Document. YXDB es el formato de archivo binario nativo que usa Alteryx Designer para almacenar conjuntos de datos junto con los metadatos de sus campos.

Las importaciones de YXDB se transmiten a través de almacenamiento temporal en lugar de cargar todo el archivo en memoria, por lo que los archivos muy grandes se importan sin agotar la memoria. Los tipos de datos del archivo (decimales, fechas y marcas de tiempo) se conservan en la tabla de destino.

Si el archivo `.yxdb` configurado no existe pero hay un archivo `.parquet` con el mismo nombre en la misma carpeta, el paso lee el archivo `.parquet` en su lugar y muestra una advertencia que lo indica. Los flujos de trabajo de Alteryx convertidos escriben sus salidas `.yxdb` como archivos `.parquet` con el mismo nombre, de modo que un paso que lee uno de esos archivos `.yxdb` obtiene los datos automáticamente. Las importaciones que buscan archivos no usan esta alternativa.
