## Descripción



Importa archivos de texto en los que las columnas se definen por posiciones de caracteres en lugar de por delimitadores, el clásico formato de salida de mainframe / COBOL. Configure los límites de las columnas (posición inicial, longitud) para cada campo.

Es habitual en exportaciones de ERP heredados, declaraciones gubernamentales y formatos de extractos bancarios, donde los datos se han dispuesto para mostrarse en columnas fijas y no para analizarse con delimitadores.

Las importaciones de ancho fijo se transmiten a través de almacenamiento temporal en lugar de cargar todo el archivo en memoria, por lo que los archivos muy grandes se importan sin agotar la memoria.

### Encabezado

Como los archivos de Excel pueden contener encabezados o no, PlaidCloud ofrece una forma de usar los encabezados, ignorarlos o usar el orden de las columnas para determinar su alineación.
* **Sin encabezado**: el archivo no contiene encabezado. Use la lista de origen del *asignador de datos* para determinar la alineación de las columnas.
* **Con encabezado: usar el encabezado y reemplazar la lista de campos**: el archivo tiene un encabezado. Use los nombres de encabezado especificados e ignore la lista de origen del *asignador de datos*.
* **Con encabezado: omitir el encabezado y usar la lista de campos**: el archivo tiene un encabezado, pero debe ignorarse. Use los nombres de encabezado especificados por la lista de origen del *asignador de datos*.

### Selección de filas

Para los archivos de entrada con registros ajenos a los datos, puede especificar un número de filas que omitir antes de procesar los datos. Esto es útil si los archivos contienen bloques de encabezado que deben omitirse antes de llegar a los datos tabulares.

### Anchos de columna

Introduzca los anchos de las columnas separados por comas o espacios.

### Diseño

| Configuración | Qué hace |
| --- | --- |
| Codificación | El juego de caracteres del archivo: **UTF-8** (el valor predeterminado), **EBCDIC (EE. UU., cp037)**, **EBCDIC (internacional, cp500)** o **Latin-1**. Elija una página de códigos EBCDIC para un archivo de mainframe. |
| Registros que omitir | Cuántos registros se omiten al inicio del archivo, antes del encabezado o de los datos. |
| Registros que descartar al final | Cuántos registros se descartan del final del archivo, como un registro de cierre. |
| Un registro por línea | Activado (el valor predeterminado), cada línea es un registro. Desmárquelo para un archivo cuyos registros están dispuestos uno tras otro sin saltos de línea; cada registro tiene entonces la longitud de todos los anchos de columna juntos. |
| Caracteres entre registros | Cuando los registros no están uno por línea, cuántos caracteres se omiten después de cada registro, como un separador. |
| Quitar espacios | Los espacios que se eliminan de cada valor: **Iniciales y finales** (el valor predeterminado), **Solo finales** o **Ninguno**. |
