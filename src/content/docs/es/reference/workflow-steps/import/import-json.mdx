## Descripción

Importe archivos de texto JSON desde PlaidCloud Document.

Para obtener más detalles sobre los archivos JSON, consulte el sitio web oficial de JSON: http://json.org/.

Los archivos JSON *no* conservan el orden de las columnas. El orden de las columnas del archivo de origen no refleja necesariamente el orden de las columnas de la tabla de datos importada.

Las importaciones de JSON se transmiten a través de almacenamiento temporal en lugar de cargar todo el documento en memoria, por lo que los archivos muy grandes se importan sin agotar la memoria. Las columnas que aparecen por primera vez al final de un documento grande se incluyen en la tabla importada. Los objetos y las matrices anidados se importan como texto JSON compacto estándar, de modo que los pasos posteriores pueden analizarlos con cualquier herramienta de JSON.

## Elementos de configuración exclusivos

### Orientación de los datos JSON

Considere el siguiente conjunto de datos:

| ID | Name | Gender | State |
| 1 | Jack | M | MO |
| 2 | Jill | F | MO |
| 3 | George | M | VA |
| 4 | Abe | M | KY |

Los archivos JSON se pueden importar desde uno de tres formatos de datos:

* Records: los datos se almacenan en conjuntos de diccionarios de Python, con cada fila almacenada en el formato \{Column -> Value, …}. Por ejemplo:


```json
[{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" }]
```

* Index: los datos se almacenan en conjuntos anidados de diccionarios de Python, con cada fila almacenada en el formato \{Index -> \{Column -> Value, …},…}. Por ejemplo:


```json
{ "0": { "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, "1": { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, "2": { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, "3": { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" } }
```

* Split: los datos se almacenan en un único conjunto de diccionario de Python, con los valores almacenados en listas. Por ejemplo:


```json
{ "columns": ["ID", "Name", "Gender", "State"], "index": [0, 1, 2, 3], "data": [ [1, "Jack", "M", "MO"], [2, "Jill", "F", "MO"], [3, "George", "M", "VA"], [4, "Abe", "M", "KY"] ] }
```

Además de los formatos anteriores, se acepta JSON delimitado por saltos de línea (NDJSON): un objeto JSON independiente por línea, sin matriz envolvente. Por ejemplo:

```json
{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }
{ "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }
```


### Documento completo

Para mantener intacto el JSON de cada archivo, seleccione **Importar cada archivo como una fila con todo su documento JSON** (`whole_document`) en **Más opciones de JSON**. Cada archivo se importa entonces como una fila que contiene todo su documento JSON, con los números tal como están escritos.
