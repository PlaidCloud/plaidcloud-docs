## Descripción


Importa un archivo de archivo nativo de PlaidCloud de vuelta a una tabla de proyecto. El formato de archivo conserva los tipos de columna, los metadatos y los índices que no sobreviven a un viaje de ida y vuelta por CSV.

Lo crea [Export to Table Archive](/es/reference/workflow-steps/export/export-to-table-archive/). Se usa para copias de seguridad de proyectos, migraciones entre espacios de trabajo o entornos y transferencia fiable de datos con tipos.
