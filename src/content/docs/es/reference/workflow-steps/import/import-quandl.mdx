## Descripción

Importa conjuntos de datos del repositorio de Quandl, que contiene millones de ellos.

Para obtener más detalles sobre los conjuntos de datos de Quandl, consulte el sitio web oficial de Quandl: http://www.quandl.com/.

## Elementos de configuración exclusivos

### Especificación de los datos de origen

Acceder a los conjuntos de datos de Quandl requiere una cuenta de usuario o una cuenta de invitado con acceso limitado. Esto requiere una configuración en Herramientas. Para obtener detalles sobre cómo configurar una conexión de cuenta de Quandl, consulte aquí: [Herramientas de PlaidCloud – Conexión](/es/reference/connectors/).

Una vez configuradas todas las cuentas necesarias, seleccione la cuenta adecuada en la lista desplegable.

A continuación, introduzca los criterios del código de Quandl deseado. Los usuarios pueden usar la función **Buscar** para buscar conjuntos de datos. También pueden introducirse manualmente. Esto requiere que el usuario introduzca la parte de la URL posterior a “[http://www.quandl.com](http://www.quandl.com/)”. 

Por ejemplo, para importar el conjunto de datos de las acciones de Microsoft, que se encuentra aquí (http://www.quandl.com/GOOG/NASDAQ_MSFT), introduzca *GOOG/NASDAQ_MSFT* en el campo del código de Quandl.


### Selección de datos


Es posible segmentar los conjuntos de datos de Quandl al importarlos. Las opciones disponibles incluyen las siguientes:


* Fecha de inicio: use el selector de fecha para elegir la fecha deseada.
* Fecha de fin: use el selector de fecha para elegir la fecha deseada.
* Collapse: agrega los resultados por día, semana, mes, trimestre o año. De forma predeterminada no hay agregación.
* Transformation: cálculos de resumen.
* Limit Rows: el valor predeterminado 0 devuelve todas las filas. Cualquier otro valor entero positivo especifica el límite de filas que se devuelven del conjunto de datos.
