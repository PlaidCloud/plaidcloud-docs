## Descripción

Importe archivos de Apache Avro desde PlaidCloud Document. Avro es un formato de serialización de datos basado en filas del proyecto Apache Hadoop que almacena los datos junto con su esquema, lo que lo hace muy adecuado para canalizaciones de datos y sistemas de transmisión.

## Elementos de configuración exclusivos

### Hora de modificación del archivo

Lea solo los archivos modificados dentro de un intervalo de tiempo. **Modificado después de** lee solo los archivos modificados por última vez después de la hora que introduzca, y **Modificado antes de** solo los modificados por última vez antes de ella; defina uno o ambos. Introduzca la hora con el formato `YYYY-MM-DDTHH:MM:SS`, por ejemplo `2026-10-01T00:00:00`. Una hora se interpreta en UTC, salvo que indique una zona, como `2026-10-01T00:00:00-05:00`. Una hora puede contener una variable de flujo de trabajo, que se lee cuando se ejecuta el paso.
