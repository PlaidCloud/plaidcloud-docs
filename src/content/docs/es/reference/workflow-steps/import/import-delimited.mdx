## Descripción

El paso **Importar: delimitado (por posición)** lee todas las columnas de un documento delimitado por posición, como columnas de texto con los nombres `Column_1` a `Column_N`, y omite la línea de encabezado. Úselo cuando el encabezado no pueda dar nombre a las columnas, por ejemplo cuando un paso posterior promueve una fila de datos a encabezado.

## Parámetros

- **Documento**: la cuenta de documentos y la ruta del archivo. Una ruta que termina en `.gz` se descomprime.
- **Delimitador**: el delimitador de campos. El valor predeterminado es una coma.
- **Carácter de comillas**: el valor predeterminado es unas comillas dobles.
- **Columna de número de registro** *(opcional)*: una columna que numera los registros en el orden del archivo. Déjela en blanco para no escribir ninguna.
- **Tabla de salida**: dónde se escriben las filas.

Un documento ausente no es un error. El paso termina con una advertencia que indica la ruta y escribe una tabla vacía.
