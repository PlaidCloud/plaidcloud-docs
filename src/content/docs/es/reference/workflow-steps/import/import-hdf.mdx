## Descripción


Importa archivos HDF5 (Hierarchical Data Format versión 5) a tablas de proyecto de PlaidCloud. HDF5 es habitual en la computación científica, en el intercambio de datos de aprendizaje automático y en cualquier entorno donde los datos columnares con tipos deban circular de ida y vuelta entre herramientas de Python, R o MATLAB.

Consulte la [documentación del HDF Group](http://www.hdfgroup.org/HDF5/) para ver la especificación del formato.

## Elementos de configuración exclusivos


### Nombre de clave

Los archivos HDF almacenan los datos en una estructura de rutas. Se necesita una clave (ruta) como destino de la tabla dentro del archivo HDF. En la mayoría de las situaciones, será *table*.
