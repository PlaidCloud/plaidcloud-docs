## Descripción

Importa archivos de texto delimitado desde PlaidCloud Document. Esto incluye, entre otros, los siguientes tipos de delimitador:
* coma (, )
* barra vertical (|)
* punto y coma (; )
* tabulación
* espacio ( )
* arroba (@)
* virgulilla (~)
* dos puntos (:)

### Inspeccionar el archivo de origen seleccionado

Al pulsar el botón *Detectar la configuración a partir del archivo de origen*, PlaidCloud abre el archivo y lo inspecciona para intentar determinar el formato de los datos. Compruebe siempre
que la configuración detectada sea correcta.

<Aside>Si se selecciona un directorio de archivos para importar o se usa la búsqueda, se usará el primer archivo encontrado para la detección</Aside>

No se puede guardar un paso cuyo archivo no produce columnas: el guardado se detiene con **No se detectaron columnas**. Cuando PlaidCloud no pudo leer el archivo, el mensaje indica el motivo; por ejemplo, una extensión poco habitual para un archivo delimitado o una ruta de archivo que usa una variable de flujo de trabajo no definida. En caso contrario, compruebe que el delimitador y los caracteres de comillas y de escape coinciden con el archivo, que se trata de un archivo de texto delimitado y que no está vacío.

### Formato de datos

#### Delimitador
Como se mencionó antes, **Inspeccionar el archivo de origen seleccionado** intentará determinar el delimitador del archivo de origen. Si desea otro delimitador, use esta
sección para especificarlo. Los usuarios pueden elegir de una lista de delimitadores estándar. Un paso sin delimitador definido usa una coma.
* coma (, )
* barra vertical (|)
* punto y coma (; )
* tabulación
* espacio ( )
* arroba (@)
* virgulilla (~)
* dos puntos (:)

#### Tipo de encabezado

Dado que los archivos CSV pueden contener encabezados o no, PlaidCloud ofrece una forma de usar los encabezados, ignorarlos o usar el orden de las columnas para determinar su alineación.
* **Sin encabezado**: el archivo CSV no contiene encabezado. Use la lista de origen del *asignador de datos* para determinar la alineación de las columnas.
* **Con encabezado: usar el encabezado y reemplazar la lista de campos**: el archivo CSV tiene un encabezado. Use los nombres de encabezado especificados e ignore la lista de origen del *asignador de datos*.
* **Con encabezado: omitir el encabezado y usar la lista de campos**: el archivo CSV tiene un encabezado, pero debe ignorarse. Use los nombres de encabezado especificados por la lista de origen del *asignador de datos*.

**Tipo de encabezado** se almacena en `header_treatment` como `use` o `skip` para las dos opciones con encabezado. Importar Excel también acepta `dynamic`.

#### Formato de fecha

Este ajuste es útil si las fechas contenidas en el archivo CSV no se reconocen fácilmente como fechas y horas. El proceso de importación intenta convertir las fechas, pero contar con algo más de información
puede ayudar durante la importación.

Un valor que el almacén no puede leer con el formato indicado se almacena como vacío en lugar de detener la importación, por lo que un formato que no coincide con el archivo
produce una columna de fechas vacías y una importación que aun así informa de éxito. Después de cambiar este ajuste, compruebe la columna importada antes de confiar en el resultado.

<Aside type="caution" title="Columnas de hora en Lakehouse v2">
Una columna cuyo tipo de datos es **Hora** se importa vacía en Lakehouse v2, sea cual sea el formato de fecha que indique. La función del almacén que se usa para analizarla no puede
producir un valor de hora del día por sí solo. Importe la columna como **Marca de tiempo** y lea la hora a partir de ella, o impórtela como **Texto**. Las columnas **Fecha** y **Marca de tiempo**
no se ven afectadas.
</Aside>

### Caracteres especiales

Las entradas de caracteres especiales controlan cómo PlaidCloud trata la presencia de ciertos caracteres y qué significan en el contexto del procesamiento del CSV.
 * **Carácter de comillas**: el carácter que se usa para indicar un conjunto de texto delimitado que debe procesarse como un único campo. Si no se define, son las comillas dobles (`"`).
 * **Carácter de escape**: el carácter que se usa para indicar que el carácter siguiente debe procesarse tal cual y no interpretarse como un carácter especial. Resulta útil cuando un campo puede contener el delimitador. Si no se define, es la barra invertida (`\`).
 * **Carácter nulo**: como los archivos CSV no tienen tipos de datos, este carácter permite indicar que el valor debe ser NULL en lugar de una cadena vacía o 0.
 * **Campos vacíos**: un campo vacío se carga como NULL en cada lakehouse, tanto en columnas de texto como numéricas, de modo que un número en blanco es NULL en lugar de 0. Una celda que contiene solo espacios se carga tal cual.
 * **Negativos finales**: algunos sistemas de origen generan números negativos con el símbolo negativo al final en lugar de al principio. Este ajuste los procesa como números negativos.

### Selección de filas

Para archivos de entrada con registros ajenos a los datos, establezca **Omitir filas** en el número de líneas que se omitirán antes de procesar los datos. Esto es útil si los archivos contienen bloques de encabezado que deben omitirse antes de llegar a los datos tabulares.

Las líneas omitidas incluyen las líneas en blanco. Con un **Tipo de encabezado** de **Con encabezado: usar el encabezado y reemplazar la lista de campos**, el encabezado se lee de la primera línea posterior a las líneas omitidas, de modo que los datos se asignan a las columnas de destino por el nombre del encabezado. Un archivo que contiene solo las líneas omitidas y un encabezado, sin filas de datos, no importa nada y el paso aun así se completa.

#### Ejemplo: exportación de lista de SAP

Una exportación de lista de SAP como KE24, KSB1 o FAGLL03 comienza con un bloque de selección, a menudo con líneas en blanco, antes del encabezado de columnas:

```text
Line Item Journal Entries
Company Code: 1000
Posting Date: 2026-09-01 to 2026-09-30

Company Code|Document Number|Posting Date|Amount
1000|100004512|2026-09-03|1,500.00
```

El encabezado está en la línea 5, por lo que hay cuatro líneas antes de él. Establezca **Omitir filas** en `4` y **Tipo de encabezado** en **Con encabezado: usar el encabezado y reemplazar la lista de campos**. La importación lee `Company Code`, `Document Number`, `Posting Date` y `Amount` como los nombres de las columnas, y la primera fila de datos es la línea posterior al encabezado.

Seleccione **Keep Quoted Empty Fields ("") As Empty String** para cargar un campo vacío entre comillas como una cadena vacía en lugar de NULL.

### Configuración adicional

**Más opciones de CSV** contiene estos campos:

* **Codificación** (`encoding`): el códec de Python con el que se lee el archivo, en lugar de detectarlo. Los bytes que no se pueden decodificar se leen como U+FFFD.
* **Delimitadores** (`delimiters`): una matriz JSON con todos los textos que separan columnas, en lugar de un único delimitador. Cada uno puede tener varios caracteres. Seleccione **Varios delimitadores seguidos cuentan como uno** (`combine_delimiters`) para contar varios delimitadores seguidos como uno solo.
* **Delimitador de fila** (`row_delimiter`): el texto que termina una fila cuando está fuera de unas comillas; un salto de línea en cualquier otro lugar forma entonces parte del valor. Si se deja en blanco, cualquier salto de línea termina una fila.
* **Prefijo de línea de comentario** (`comment`): las líneas que comienzan con este texto no se importan. **Comentarios** (`comments`) enumera los comentarios como pares **Empieza por** y **Termina en** que se recortan dondequiera que estén fuera de unas comillas; sin **Termina en**, un comentario se extiende hasta el final de la línea.
* **Continuación de línea** (`line_continuation`): este texto antes de un salto de línea une la línea con la siguiente.
* **Comilla de cierre** (`quote_end`): la comilla que termina un valor entre comillas, cuando difiere del **Carácter de comillas**. Seleccione **Un valor entre comillas conserva sus comillas** (`keep_quotes`) para conservar las comillas de un valor entre comillas.
* **Importar una línea vacía como una fila de valores vacíos** (`keep_blank_lines`): una línea vacía se importa como una fila de valores vacíos en lugar de omitirse.
