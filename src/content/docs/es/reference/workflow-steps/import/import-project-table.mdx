## Descripción


Copia datos de una tabla de un proyecto distinto al proyecto actual. Es el inverso de [Export Project Table](/es/reference/workflow-steps/export/export-project-table/): extrae en lugar de enviar.

Resulta útil cuando un proyecto de consolidación obtiene datos de muchos proyectos operativos, o cuando los datos de referencia están centralizados en un proyecto y los leen otros. El proyecto de origen debe conceder a este proyecto un recurso compartido de datos de **Leer**.


## Administración del uso compartido de datos

![Administración del uso compartido de datos](/images/import_external_project_table_1.png)

Antes de poder importar una tabla de otro proyecto, ese proyecto tiene que permitir que este la lea. Abra la pestaña **Inicio** del proyecto de **origen**, y en **Administración del uso compartido de datos** haga clic en **Nuevo recurso compartido de datos**, seleccione este proyecto, marque **Leer** en **Operaciones permitidas** y haga clic en **Agregar recurso compartido de datos**. Consulte [Uso compartido de datos entre proyectos](/es/guides/projects/managing-projects/#uso-compartido-de-datos-entre-proyectos).

El paso se ejecuta con la identidad propia de este proyecto, por lo que una ejecución funciona a través del recurso compartido sea quien sea quien la inicie.

## Importar tabla externa del proyecto

![Importar origen y destino](/images/import_external_project_table_2.png)

### Leer desde
Seleccione el **Proyecto de origen** y la **Tabla de origen** en las listas desplegables.

<Aside type="note" title="Tabla de origen vacía">
Si la tabla de origen no tiene filas cuando se ejecuta el paso, la importación termina con una advertencia de que el origen estaba vacío en lugar de un éxito silencioso, de modo que es fácil detectar un destino inesperadamente vacío. Lo más habitual es que el flujo de trabajo del proyecto de origen todavía no haya generado esa tabla; asegúrese de que el origen esté poblado (y, en las ejecuciones programadas, de que se ejecute primero) antes de la importación.
</Aside>

<Aside type="note" title="Eliminación de una tabla de origen">
La tabla de origen que lee se considera en uso por este paso. Si intenta eliminarla, PlaidCloud muestra la referencia y le pide que confirme una eliminación forzada (marcando **¿Forzar la eliminación de la tabla?** y eligiendo **Forzar eliminación**) en lugar de una eliminación simple, incluso cuando el paso de importación se encuentra en un proyecto distinto que comparte los datos. En ese caso entre proyectos, la advertencia enumera la referencia sin nombrar el paso del otro proyecto, ya que es posible que usted no tenga acceso a él.
</Aside>
