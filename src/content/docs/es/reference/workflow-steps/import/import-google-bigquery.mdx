## Descripción


Importa datos de Google BigQuery a una tabla de proyecto de PlaidCloud. Resulta útil para las organizaciones que usan BigQuery como almacén analítico principal y llevan conjuntos de datos específicos a PlaidCloud para continuar con el modelado o el trabajo de asignación.

La autenticación usa una cuenta de servicio de Google Cloud; el conjunto de datos y la tabla de origen se configuran a nivel del paso.
