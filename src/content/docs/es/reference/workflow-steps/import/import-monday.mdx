## Descripción

Importa los elementos de uno o más tableros de [monday.com](https://monday.com/) a tablas de proyecto mediante una conexión de monday.com. Úselo para llevar el seguimiento de proyectos, las colas de entrada o los datos de tareas operativas a un flujo de trabajo junto con los datos financieros.

## Elementos de configuración exclusivos

### Configuración de la conexión

La conexión de monday.com a través de la cual se lee.

### Tabla de destino

Una fila por tablero: el **ID del tablero** que se lee y la tabla de proyecto en la que se escribe. Un solo paso puede importar varios tableros a la vez. Cada destino debe ser una tabla, no una vista.
