## Descripción


Importa archivos de datos de Stata (.dta) a tablas de proyecto de PlaidCloud. Resulta útil para las organizaciones que usan Stata para análisis econométricos o estadísticos y llevan sus conjuntos de datos de trabajo a PlaidCloud para seguir procesándolos.

Las etiquetas de variable se conservan cuando el formato de Stata las incluye.
