## Descripción

Restaura tablas de proyecto desde un archivo creado por [Archivar tablas](/es/reference/workflow-steps/export/archive-tables/). Úselo para mover datos de tablas entre proyectos o espacios de trabajo, o para volver a una copia reservada.

## Elementos de configuración exclusivos

### Origen

El archivo en una cuenta de documentos. El selector también admite la coincidencia por búsqueda (exacta, comienza por, termina en, contiene o patrón glob) en lugar de una ruta exacta.

### Sobrescribir

Desactivado de forma predeterminada. Cuando está desactivado, una tabla que ya existe en el proyecto se deja intacta. Actívelo para reemplazar las tablas existentes con las copias archivadas.
