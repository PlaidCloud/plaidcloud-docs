## Descripción

Escribe un archivo completo del proyecto (flujos de trabajo, definiciones de tablas, dimensiones, variables y configuración) en una cuenta de documentos como un único archivo. Úselo para una copia de seguridad en un momento dado antes de un cambio importante, o para entregar un proyecto a otro espacio de trabajo.

Esto archiva el *proyecto*, no solo sus datos. Para los datos de tablas únicamente, utilice [Export to Table Archive](/es/reference/workflow-steps/export/export-to-table-archive/).

## Elementos de configuración únicos

### Directorio y nombre de archivo de exportación

- **Directorio de exportación**: la cuenta de documentos y la carpeta en las que se escribe el archivo.
- **Archivo de destino**: el nombre de archivo del archivo del proyecto.
