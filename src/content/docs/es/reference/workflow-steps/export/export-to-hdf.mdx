## Descripción


Exporte una tabla de datos de Analyze a PlaidCloud Document como un archivo HDF5.


Para obtener más información sobre los archivos HDF5, consulte el sitio web oficial de HDF Group aquí: http://www.hdfgroup.org/HDF5/.

<SnippetCommonExportFileSelection />



### Tipo de archivo de salida


Todos los archivos exportados se generan sin comprimir, pero están disponibles las siguientes opciones de compresión:


* Zip
* GZip
* BZip2
