## Descripción

Escribe las tablas de proyecto que seleccione en una cuenta de documentos como Parquet comprimido. Junto con [Restaurar tablas](/es/reference/workflow-steps/import/restore-tables/), traslada datos de tablas entre proyectos o espacios de trabajo, o conserva una copia en buen estado antes de un cambio destructivo.

## Elementos de configuración únicos

### Tablas

Las tablas de proyecto que se archivan.

### Destino

La cuenta de documentos y la ruta en las que se escribe el archivo.

### Compresión

- **Snappy**: la más rápida, con un tamaño de archivo moderado
- **Zstandard**: archivos más pequeños; requiere un lector con Zstandard 0.8 o posterior
