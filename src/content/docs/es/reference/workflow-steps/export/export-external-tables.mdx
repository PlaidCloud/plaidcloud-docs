## Descripción

Escribe tablas de proyecto en una base de datos externa mediante una [conexión](/es/reference/connectors/), en lugar de en un archivo. Úselo para devolver resultados modelados a una base de datos de informes, a un almacén de datos o a un sistema operativo.

Es el reflejo de [Importar tablas de bases de datos externas](/es/reference/workflow-steps/import/import-external-database-tables/): se mueven varias tablas en un solo paso, y las tablas de destino se pueden seleccionar de forma explícita o encontrarse mediante un patrón de búsqueda.

## Elementos de configuración únicos

### Conexión

La conexión de datos que identifica la base de datos de destino.

### Tipo de exportación

Cómo se prepara cada tabla de destino antes de escribir las filas:

- **Solo anexar**: agrega filas a la tabla existente; falla si no existe.
- **Truncar y anexar**: vacía la tabla, conserva su estructura y después escribe.
- **Crear y anexar**: crea la tabla si falta y después escribe.
- **Descartar, crear y anexar**: descarta y vuelve a crear la tabla, y después escribe. Úselo cuando el esquema de origen haya cambiado.

### Nombre del marco

El nombre del marco bajo el que se ejecuta el paso.

### Agregar destinos

Utilice el botón de agregar y quitar destino para crear la lista de tablas de destino. Seleccione un destino para configurarlo en el panel derecho y use **Alternar selección** para habilitar o deshabilitar para exportación los destinos seleccionados. La exportación no analiza la base de datos de destino en busca de tablas; agregue usted mismo cada destino. [Importar tablas de bases de datos externas](/es/reference/workflow-steps/import/import-external-database-tables/) es el paso para descubrir tablas en una base de datos externa.

### Pestañas de destino

Un destino seleccionado tiene tres pestañas.

#### Origen y destino

Elija las tablas de proyecto que se exportan y dónde se depositan.

- **Origen**: **Tabla específica** indica una tabla de proyecto, con una opción **Dinámico** para un nombre que cambia en tiempo de ejecución. **Tablas que coinciden con la búsqueda** exporta todas las tablas de proyecto que se encuentran con una **Ruta de búsqueda** y un **Texto de búsqueda**, comparados como **Exacto**, **Comienza por**, **Contiene** o **Termina en**.
- **Tabla externa de destino**: **Habilitar para exportación** activa o desactiva el destino. **Esquema de destino** y **Tabla de destino** indican la tabla de destino. **Usar el mismo nombre que la tabla de origen** reutiliza el nombre de cada tabla de origen.

#### Selección de datos de la tabla

El asignador de columnas del destino, en su propia pestaña de altura completa. **Inspeccionar origen** lee las columnas de la tabla de origen del proyecto en el asignador.

#### Filtros de datos

Filtre las filas que se escriben en el destino.
