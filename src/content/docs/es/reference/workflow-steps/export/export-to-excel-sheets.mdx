## Descripción

Escribe varias tablas de proyecto en distintas hojas de un único libro de Microsoft Excel,
conservando el formato de una plantilla con estilo. Cada tabla rellena una hoja
con nombre; todo el libro se inicializa a partir de la plantilla una sola vez y se renderiza en
una única pasada, por lo que las hojas ya no se sobrescriben entre sí como lo harían
exportaciones separadas de una sola hoja cuando comparten un archivo de salida.

Utilice este paso cuando un libro tenga que contener más de una hoja de resultados,
por ejemplo, una plantilla de informes con formato que incluya una hoja de datos, una hoja de resumen
y una hoja de parámetros. Para una sola hoja, o para un libro simple sin estilo,
utilice en su lugar [Export to Excel](/es/reference/workflow-steps/export/export-to-excel/).

El formato de la plantilla se traslada a cada hoja escrita: valores, formatos
numéricos, fuentes, rellenos, bordes, celdas combinadas y anchos de columna. Una plantilla que
contenga tablas dinámicas o gráficos pierde esos objetos cuando se escriben sus hojas:
la escritura no los reproduce.

## Parámetros de exportación

### Archivo de salida

La cuenta de documentos y la carpeta en las que se escribe el libro, junto con el
**Nombre de archivo** del libro.

### Archivo de plantilla

La plantilla con estilo a partir de la cual se inicializa el libro: una cuenta de documentos y la ruta de
un archivo `.xlsx` existente cuyo formato heredan todas las hojas escritas. Si no se indica ninguna
plantilla, el paso se inicializa a partir del archivo de salida existente, si ya hay uno.

### Compresión

De forma predeterminada, el libro se escribe sin comprimir. Está disponible la compresión Zip, GZip
o BZip2.

## Hojas

Cada entrada de la tabla **Hojas** rellena una hoja de cálculo del libro:

| Campo | Finalidad |
| --- | --- |
| Origen | La tabla de proyecto que proporciona las filas de la hoja. |
| Hoja de destino | La hoja de la plantilla que se rellena. |
| Rango | Un rango opcional de estilo A1 (por ejemplo, `A1:S1000000`) cuyos valores existentes se borran antes de escribir la tabla, sin tocar las celdas de plantilla circundantes. |
| Escribir encabezado | Si se escribe la fila de encabezado con los nombres de columna. Activado de forma predeterminada. |
| Columnas | Las columnas que se escriben, en orden, cuando no se desean todas las columnas de la tabla de origen. |

Estos campos también figuran en el formulario:

* **Un libro existente** (`if_exists`): **Hacer fallar el paso sin escribir nada** (`fail`) detiene el paso cuando el libro ya existe. El valor predeterminado, **Escribir las hojas en él** (`replace`), lo escribe.
* En una entrada de hoja, **Ordenar filas por** (`sort_columns`) ordena las filas escritas según estas columnas de origen, empezando por la primera clave, cada una con una configuración de **Columna**, **Ascendente** y **Nulos**; **Celdas vacías como** (`null_as`) es el texto que se escribe en cada celda ausente de la hoja, incluidas las columnas numéricas; y **Una hoja existente** (`if_sheet_exists`) decide qué ocurre cuando el libro ya tiene la hoja: **Hacer que el paso falle** (`fail`) detiene el paso y **Dejarlo como está** (`skip`) deja esa hoja como está.

## Límites de tamaño

Cada hoja está sujeta a los mismos límites de Excel que una exportación de una sola hoja: como máximo
1,048,576 filas (la fila de encabezado cuenta) y 16,384 columnas. Una hoja que
los supere detiene el paso en lugar de producir un archivo que Excel se niega a abrir.
Para datos que superen estos tamaños, exporte en su lugar a CSV o Parquet.
