## Descripción

El paso **Publish to Tableau** publica un extracto `.hyper` en Tableau Server o Tableau Cloud como origen de datos. Primero escriba el extracto con [Tableau Hyper Export](/es/reference/workflow-steps/export/export-hyper/) y después publíquelo con este paso. El paso inicia sesión con el token de acceso personal de una [conexión de Tableau](/es/reference/connectors/collaboration/tableau/), carga el archivo en fragmentos, de modo que el tamaño del archivo no queda limitado por una sola solicitud, y cierra la sesión.

Un archivo de extracto que falta no es un error. El paso advierte de que no se publicó nada y el flujo de trabajo continúa.

## Parámetros

- **Extracto Hyper**: el archivo `.hyper` de una cuenta de documentos que se publicará.
- **Conexión de Tableau**: la conexión de Tableau mediante la cual se publica.
- **Nombre del origen de datos**: el nombre del origen de datos en Tableau. Déjelo en blanco para usar el nombre de archivo del extracto sin su extensión.
- **Proyecto**: el proyecto de Tableau en el que se publica. Déjelo en blanco para usar el proyecto Default del sitio. Si el sitio no tiene un proyecto con el nombre indicado en Tableau, el paso falla.
- **Si el origen de datos existe**: el modo de publicación. Consulte [Modos](#modos).
- **Claves de coincidencia**: las columnas que hacen coincidir las filas, como lista separada por comas. Obligatorio para **Upsert**, **Actualizar** y **Replace Matching Rows**.

## Modos

| Modo | Cuando el origen de datos existe | Cuando no existe |
| --- | --- | --- |
| **CreateNew** | El paso falla. | Lo crea. |
| **Overwrite** | Lo reemplaza. | Lo crea. |
| **Anexar** | Le agrega las filas del extracto. | Lo crea. |
| **Upsert** | Actualiza las filas cuyas claves de coincidencia coinciden y agrega el resto. | Lo crea. |
| **Actualizar** | Actualiza las filas cuyas claves de coincidencia coinciden y no agrega ninguna. | Advierte y no cambia nada. |
| **GroupReplace** | Elimina las filas cuyas claves de coincidencia coinciden y después inserta las filas del extracto. | Lo crea. |

**Anexar**, **Upsert**, **Actualizar** y **GroupReplace** buscan el origen de datos por nombre en el proyecto que eligió, o en el proyecto Default del sitio si no eligió ninguno, y publican en el proyecto en el que lo buscaron. Los modos con clave modifican las filas del origen de datos en su lugar, mediante las acciones de actualización de datos de Tableau.

## Requisitos

- La dirección del servidor de la conexión debe usar `https`. Un servidor indicado con `http` hace que el paso falle, porque el token de acceso personal viajaría por la red sin cifrar. Un nombre de host sin esquema se interpreta como `https`.
- El servidor debe ser accesible desde Internet. PlaidCloud no publica en un servidor de Tableau de una red privada.
- El propietario del token de acceso personal necesita permiso para publicar en el proyecto.
