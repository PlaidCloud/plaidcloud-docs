## Descripción



Escribe una tabla de PlaidCloud en una cuenta de documentos como un archivo comprimido nativo de PlaidCloud. El archivo conserva todos los tipos de columna, los índices y los metadatos que PlaidCloud conoce, con mayor fidelidad que CSV para los traslados de ida y vuelta entre proyectos o entornos de PlaidCloud.

Combínelo con el paso [Importar archivo comprimido](/es/reference/workflow-steps/import/import-archive/) para volver a traer el archivo a un proyecto. Resulta útil para copias de seguridad, migraciones entre proyectos y transferencias de datos entre entornos.
