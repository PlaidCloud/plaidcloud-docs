## Descripción



Envía una tabla de PlaidCloud a una base de datos de Quandl (NASDAQ Data Link). Está pensado sobre todo para organizaciones que mantienen conjuntos de datos publicados en Quandl y quieren actualizarlos desde un flujo de trabajo de PlaidCloud.

Requiere credenciales de la API de Quandl y una base de datos de destino configurada con acceso de escritura en Quandl.


## Origen y destino


Especifique los siguientes parámetros:


* **Tabla de origen**: tabla de datos de Analyze que se exporta
* **Conexión de Quandl**: para acceder a los conjuntos de datos de Quandl se necesita una cuenta de usuario o una cuenta de invitado con acceso limitado. Esto requiere una configuración en Herramientas. Para obtener más información sobre cómo configurar una conexión de cuenta de Quandl, consulte aquí: [Herramientas de PlaidCloud – Conexión](/es/reference/connectors/)
* **Código de Quandl**: use el botón **Buscar** para buscar conjuntos de datos. También se pueden introducir los conjuntos de datos manualmente. Para ello, el usuario debe introducir la parte de la URL posterior a “[http://www.quandl.com](http://www.quandl.com/)”. Por ejemplo, para importar el conjunto de datos de las acciones de Microsoft, que se encuentra aquí (http://www.quandl.com/GOOG/NASDAQ_MSFT), introduzca *GOOG/NASDAQ_MSFT* en el campo Código de Quandl
* **Nombre del conjunto de datos**: nombre del conjunto de datos que se exporta a Quandl
* **Descripción del conjunto de datos**: descripción del conjunto de datos que se exporta a Quandl
