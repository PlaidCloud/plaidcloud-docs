## Descripción

El paso **Export to PDF** escribe una tabla como documento PDF en una cuenta de documentos. Lee las filas por sí mismo, de modo que no interviene ningún trabajador de exportación.

## Parámetros

- **Tabla de origen**: la tabla que se exportará.
- **Carpeta de salida**: la cuenta de documentos y la carpeta en las que se escribe el PDF.
- **Nombre de archivo**: el nombre del PDF. Se agrega `.pdf` cuando el nombre no lo incluye.
- **Escribir los nombres de columna como fila de encabezado**: activada de forma predeterminada. El encabezado se repite en cada página.
- **Selección de datos de la tabla**: elija y ordene las columnas que se escriben. El paso también puede escribir todas las columnas que tenga el origen cuando se ejecute el flujo de trabajo, en lugar de una lista.

## Diseño

- La página tiene tamaño carta en orientación vertical y pasa a horizontal cuando la tabla tiene más de seis columnas.
- Las filas se escriben en bloques de 1000, y cada bloque repite el encabezado.
- Un valor nulo es una celda vacía.
- Una celda demasiado larga para una página se recorta con puntos suspensivos, y el paso advierte con los nombres de las columnas que recortó.
- El PDF usa una fuente Unicode cuando el motor de flujos de trabajo dispone de una. Sin ella, el PDF se compone en Helvetica, que solo muestra caracteres Latin-1, y el paso lo advierte.
