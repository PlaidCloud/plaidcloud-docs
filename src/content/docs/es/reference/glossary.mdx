Un lugar único y de referencia para los términos del producto. Si una guía o una página de referencia usa alguna de las palabras que aparecen aquí, este es su significado.

## Cuenta

Un inicio de sesión de PlaidCloud. Una cuenta pertenece a una o más organizaciones y recibe acceso a espacios de trabajo específicos dentro de esas organizaciones.

## Asistente de IA

Una interfaz de chat con alcance de proyecto dentro de PlaidCloud para hacer preguntas sobre los datos, generar expresiones y operar sobre proyectos en lenguaje natural. Consulte la [guía del Asistente de IA](/es/guides/ai-assistant/).

## Asignación

Una operación de flujo de trabajo que distribuye valores de un conjunto de filas (“origen”) a otro (“destino”) según datos de inductores y reglas. Se utiliza para precios de transferencia, costeo basado en actividades, redistribución de costos de TI, análisis de rentabilidad y problemas similares de distribución de costos. Consulte [Asignaciones](/es/guides/allocations/).

## Conexión

Una configuración guardada que permite a PlaidCloud acceder a un sistema externo: una base de datos, una cuenta de almacenamiento en la nube, un ERP o una API REST. Los pasos de flujo de trabajo reutilizan las conexiones, de modo que las credenciales se mantienen en un solo lugar. Consulte [Conexiones (guía)](/es/guides/connections/) · [Conectores (referencia)](/es/reference/connectors/).

## Aplicación de Dash

Una aplicación interactiva personalizada creada sobre los datos de PlaidCloud con el framework Plotly Dash, publicada desde un repositorio de Git y alojada en igualdad de condiciones con una aplicación Panel de servidor. Consulte [Aplicaciones de Dash](/es/guides/dash-apps/).

## Panel de control

Una vista interactiva y publicada de los datos de un proyecto, creada a partir de tablas y vistas. Consulte [Paneles de control](/es/guides/dashboards/).

## Dimensión

Una jerarquía que se usa para segmentar y agregar datos. Los centros de costo, los productos, la geografía y los períodos son dimensiones habituales. Las asignaciones usan dimensiones para decidir qué se asigna a qué. Consulte [Dimensiones](/es/guides/dimensions/).

## Inductor

En una asignación, los datos que determinan *cómo* se distribuyen los valores entre los destinos. Ejemplo: si asigna el costo de TI a las unidades de negocio según el número de empleados, la tabla de número de empleados es el inductor.

## Lakehouse

El almacén de datos analíticos subyacente de PlaidCloud. La biblioteca de expresiones se versiona según el motor de Lakehouse: **Lakehouse v1** (basado en Databend) y **Lakehouse v2** (basado en StarRocks). Consulte [Referencia de expresiones](/es/reference/expressions/).

## MCP

Model Context Protocol: el estándar que PlaidCloud utiliza para integrarse con agentes de codificación con IA (Claude Code, Cursor, Copilot, etc.). Consulte [Agentes de codificación con IA](/es/integrations/ai-coding-agents/).

## Miembro

Una cuenta de usuario con acceso a un espacio de trabajo. Los miembros se asignan a grupos de seguridad dentro del espacio de trabajo, que controlan lo que pueden hacer. Consulte [Administración de acceso](/es/administration/access/).

## Organización

El límite de facturación e identidad de nivel superior en PlaidCloud. Una organización contiene uno o más espacios de trabajo y una o más cuentas de miembros.

## Aplicación Panel

Una aplicación interactiva personalizada creada sobre los datos de PlaidCloud, normalmente con el framework Panel. Consulte [Aplicaciones de Panel](/es/guides/panel-apps/).

## PlaidLink

El daemon de conexión local de PlaidCloud: se ejecuta como servicio de Windows, daemon de Unix/Linux/Mac o servicio en contenedor para conectar los flujos de trabajo de PlaidCloud con orígenes de datos locales. Consulte la [referencia de PlaidLink](/es/reference/cli/plaidlink/).

## PlaidXL

El complemento de PlaidCloud para Excel. Recupera y actualiza tablas y dimensiones de proyecto en las hojas de cálculo, y agrega fórmulas `PLAIDXL` que calculan valores acumulados a partir de los datos de PlaidCloud. Consulte la [referencia de PlaidXL](/es/reference/cli/plaidxl/).

## Proyecto

Una unidad de trabajo dentro de un espacio de trabajo. Cada proyecto tiene sus propias tablas, flujos de trabajo, dimensiones e historial de auditoría. Los proyectos están aislados entre sí: no comparten estado. Consulte [Proyectos](/es/guides/projects/).

## Publicar

Poner una tabla de proyecto a disposición para su consumo externo (paneles de control, herramientas de BI, sistemas posteriores). Consulte [Publicación de datos](/es/guides/data/publish/).

## Grupo de seguridad

Un conjunto de permisos dentro de un espacio de trabajo. Los miembros se asignan a grupos de seguridad para concederles capacidades específicas (leer tablas, editar flujos de trabajo, administrar miembros, etc.). Consulte [Grupos de seguridad](/es/administration/access/managing-security-groups-and-assignments/).

## Paso

Una operación individual dentro de un flujo de trabajo: importar un CSV, combinar dos tablas, enviar una notificación, ejecutar una asignación. Los pasos se agrupan en categorías (importación, exportación, tablas, asignación, dimensión, documento, notificaciones, etc.). Consulte la [referencia de pasos de flujo de trabajo](/es/reference/workflow-steps/).

## Tabla

Datos estructurados en filas y columnas dentro de un proyecto. Las tablas provienen de importaciones, transformaciones u orígenes externos.

## Vista

El resultado guardado de una consulta, definido sobre una o más tablas. Se comporta como una tabla para los consumidores posteriores, pero los datos subyacentes se vuelven a evaluar en cada lectura.

## Flujo de trabajo

Una secuencia de pasos que opera sobre tablas. La unidad de automatización en PlaidCloud. Los flujos de trabajo se pueden ejecutar de forma secuencial, en paralelo, de forma condicional o en bucles. Consulte [Flujos de trabajo (guía)](/es/guides/workflows/) · [Pasos de flujo de trabajo (referencia)](/es/reference/workflow-steps/).

## Espacio de trabajo

Un entorno aislado dentro de una organización donde se realiza el trabajo real. Los equipos suelen usar un espacio de trabajo por entorno (dev, staging, prod) o por unidad de negocio. Los miembros reciben acceso a nivel de espacio de trabajo. Consulte [Administración de acceso](/es/administration/access/).
