## Descripción

Los datos de los paneles de control se pueden enriquecer con columnas calculadas.  Cada conjunto de datos contiene una sección para columnas calculadas.  Las columnas calculadas se pueden escribir y modificar con SQL de estilo PostgreSQL.

<SnippetDashboardsCommonNavigateToDataset />

## Ejemplos
### Count
```sql
COUNT(*)
```

### Min
```sql
min("MyColumnName")
```

### Max
```sql
max("MyColumnName")
```

### Coalesce (útil para convertir valores nulos en 0.0, por ejemplo)
```sql
coalesce("BaselineCost",0.0)
```

### Substring
```sql
substring("PERIOD",6,2)
```

### Cast
```sql
CAST("YEAR" AS integer)-1
```

### Concat
```sql
concat("Biller Entity" , ' ', "Country_biller")
```

### To_char
```sql
to_char("date_created", 'YYYY-mm-dd')
```

### Left
```sql
left("period",4)
```

### Divide
división, con un truco para evitar errores de división por cero (DIV/0)
```sql
sum("so_infull")/(count(*)+0.00001)
```
<Aside>Una forma mejor de hacerlo sería comprobar si el denominador es nulo o cero y luego aplicar coalesce a cero, en lugar de intentar la división.</Aside>


### Instrucción condicional
```sql
CASE WHEN "Field_A"= 'Foo' THEN max(coalesce("Value_A",0.0)) - max(coalesce("Value_B",0.0)) END
```
```sql
CASE WHEN "sol_otif_pod_missing" = 1 THEN
'POD is missing.'
ELSE
'POD exists.'
END
```
```sql
case when "Customer DC" = "origin_dc" or "order_reason_type" = 'Off Schedule' or "mot_type" = 'UPS' then
    'Yes'
else
    'No'
end
```
```sql
CASE WHEN "module_type" is NULL THEN '---' ELSE "module_type" END
```
```sql
CASE WHEN "NODE_TYPE" = 'External' THEN '3rd Party' ELSE "ENTITY_LOCATION_DESCRIPTION" END
```

### Concatenar
```sql
concat("Class",' > ',"Product Family",' > ',"Meta Series")
```
