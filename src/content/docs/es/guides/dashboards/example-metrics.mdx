## Descripción

Los datos de los paneles de control se pueden enriquecer con métricas.  Cada conjunto de datos contiene una sección para Métricas.  Las métricas se pueden escribir y modificar con SQL de estilo PostgreSQL.

<SnippetDashboardsCommonNavigateToDataset />

## Ejemplos
Las columnas calculadas suelen ser columnas adicionales creadas al combinar lógica y columnas existentes.

### Convertir una fecha en texto
```sql
to_char("week_ending_sol_del_req", 'YYYY-mm-dd')
```

### Varios ejemplos de SUM
```sql
SUM(Value)

SUM(-1*"value_usd_mkp") / (0.0001+SUM(-1*"value_usd_base"))

(SUM("Value_USD_VAT")/SUM("Value_USD_HEADER"))*100

sum(delivery_cases) where Material_Type = Gloves

sum("total_cost") / sum("delivery_count")
```


### Varios ejemplos de CASE
```sql
CASE WHEN
SUM("distance_dc_xd") = 0 THEN 0
ELSE
sum("XD")/sum("distance_dc_xd")
END

sum(CASE
WHEN "FUNCTION" = 'OM' THEN "VALUE__FC"
ELSE 0.0
END)
```


### Count
```sql
count(*)
```


### First y Cast
```sql
public.first(cast("PRETAX_SEQ" AS NUMERIC))
```


### Round
```sql
round(Sum("GROSS PROFIT"),0)
```


### Concat
```sql
concat("GCOA","CC Code")
```
