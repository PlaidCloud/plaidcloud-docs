Hay dos formas de actualizar el orden de los pasos del flujo de trabajo. La primera es usar las flechas hacia arriba y hacia abajo de la tabla **Flujos de trabajo** para mover el paso. La segunda es usar la opción **Step Move**, que permite mover el paso con mucha más facilidad cuando se necesitan cambios grandes. La opción de mover paso permite colocarlo al principio, al final o después de un paso específico en una sola operación.

La estructura de un flujo de trabajo solo puede contener cada paso una vez. Si un flujo de trabajo ya tiene el mismo paso en la lista dos veces, reordenarlo (incluido arrastrar un paso a una nueva posición) se rechaza con un error que indica que el flujo de trabajo contiene un duplicado. Elimine el paso duplicado para reparar el flujo de trabajo; eliminar pasos no está restringido, y el reordenamiento vuelve a funcionar con normalidad una vez que desaparece.
