Use esta lista de verificación antes de importar flujos de trabajo de Alteryx a PlaidCloud. Un paquete completo ayuda a PlaidCloud a crear flujos de trabajo avanzados, flujos de trabajo de macro, dependencias respaldadas por documentos y entradas de ejecución controladas con un seguimiento mínimo.

<Aside type="note">
  Para portafolios grandes, ejecute esta lista de verificación una vez para todo el portafolio y de nuevo para cada familia de flujos de trabajo de alta prioridad.
</Aside>

## Recopile los archivos de flujo de trabajo

Recopile todos los archivos de flujo de trabajo que forman parte de la migración:

1. Flujos de trabajo estándar: `.yxmd`.
2. Aplicaciones analíticas: `.yxwz`.
3. Macros: `.yxmc`.
4. Macros anidadas o compartidas a las que hacen referencia otros flujos de trabajo.
5. Versiones de flujos de trabajo que todavía se usan en producción.

Mantenga juntos los flujos de trabajo y las macros relacionados cuando se llamen entre sí. PlaidCloud usa esas relaciones para generar flujos de trabajo de macro y conectar los puertos de entrada y salida de las macros.

## Recopile las dependencias de datos

Empaquete los archivos que los flujos de trabajo leen, escriben o inspeccionan:

- Archivos CSV, TSV, de ancho fijo, JSON, XML, Excel, Access, YXDB y de extracto de bases de datos.
- Carpetas que usan las herramientas Directory o Dynamic Input.
- Archivos de salida esperados para la validación.
- Recursos de informes, como imágenes, PDF, plantillas y capas de mapas.
- Tablas de búsqueda y tablas de reglas que se usan en combinaciones, fórmulas, reemplazos y coincidencias.

Si un flujo de trabajo hace referencia a una ruta local del escritorio, incluya ese archivo o carpeta en el paquete de importación y elija la ruta de documentos donde PlaidCloud debe almacenarlo.

## Recopile los archivos auxiliares espaciales

Los formatos de archivo espaciales suelen requerir que varios archivos se mantengan juntos. Incluya todos los archivos auxiliares en la misma carpeta:

- Grupos de shapefile, como `.shp`, `.shx`, `.dbf` y `.prj`.
- Grupos de MapInfo, como `.tab`, `.map`, `.id` y `.dat`.
- KML, GeoJSON y otros archivos espaciales independientes.
- Archivos de proyección o de sistema de referencia de coordenadas que use el flujo de trabajo.

Los archivos auxiliares que faltan son una causa frecuente de diferencias en la validación espacial.

## Registre las entradas de ejecución

Para las aplicaciones analíticas, registre los valores que los usuarios suelen proporcionar:

1. Entradas de texto, numéricas, de fecha, de archivo y de carpeta.
2. Selecciones de listas desplegables, botones de opción, casillas de verificación, listas y árboles.
3. Valores predeterminados que se usan en ejecuciones programadas o repetibles.
4. Valores que activan condiciones, advertencias o errores.

PlaidCloud convierte estas entradas en variables de flujo de trabajo controladas.

## Elija la ubicación de destino

Antes de importar, decida lo siguiente:

1. El proyecto de PlaidCloud de destino.
2. La cuenta de documentos de destino.
3. La carpeta de documentos de destino para los archivos importados.
4. La convención de nombres para los flujos de trabajo y las macros convertidos.
5. Si la primera importación es una importación de preproducción o de producción.

En las migraciones de portafolios, use una carpeta de migración dedicada en Document para que las dependencias sean fáciles de auditar.

## Elija la evidencia de validación

Para cada flujo de trabajo, elija el nivel de validación:

- La validación estructural confirma que el flujo de trabajo se convierte en un DAG de PlaidCloud ejecutable.
- La validación de paridad de salida compara el esquema, el recuento de filas y los valores de las filas con salidas confiables de Alteryx.
- La validación de artefactos revisa informes, PDF, imágenes, gráficos, mapas o salidas de modelos.

Almacene las salidas esperadas junto con el paquete de migración siempre que se requiera paridad de salida.

## Lista de verificación de preparación para la importación

Antes de importar, confirme lo siguiente:

- Los archivos de flujos de trabajo, aplicaciones y macros están presentes.
- Las macros a las que se hace referencia están presentes.
- Los archivos y carpetas de entrada están presentes.
- Los archivos auxiliares espaciales están agrupados.
- Las salidas esperadas están disponibles cuando la validación de paridad forma parte del plan de migración.
- Los valores de entrada de ejecución se conocen para las aplicaciones analíticas.
- Se han seleccionado el proyecto de destino y la ruta de documentos.
- Las credenciales o conexiones externas que necesita el flujo de trabajo están disponibles en PlaidCloud.
