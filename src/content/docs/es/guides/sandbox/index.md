Los entornos sandbox le permiten probar los cambios de forma segura antes de promoverlos. Use un proyecto o un espacio de trabajo sandbox para validar las ediciones de flujos de trabajo, la lógica de asignación y los cambios de dimensiones sin tocar producción.
