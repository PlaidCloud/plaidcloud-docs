## Descripción

**Inicio del proyecto** es donde comienza en un proyecto. Un riel a la izquierda enumera seis páginas: **Resumen**, **Variables**, **Programaciones y sensores**, **Acceso y uso compartido**, **Datos y conexiones** y **Aplicaciones y marca**. Resumen sintetiza el proyecto. Las otras cinco páginas son donde se cambia la configuración del proyecto.

La insignia de **Variables** en el riel muestra cuántas variables tiene el proyecto. La insignia de **Programaciones y sensores** muestra cuántas programaciones y sensores están activos.

Un proyecto bloqueado es de solo lectura. Sus páginas muestran un aviso que dice “Este proyecto está bloqueado, por lo que es de solo lectura. Desbloquéelo en Resumen para hacer cambios.” y sus controles están desactivados.

## Resumen

![Página Resumen de Inicio del proyecto con el nombre del proyecto, seis mosaicos, Coming up y Project defaults](/images/projects/project-home-overview.png)

La parte superior de la página muestra el nombre del proyecto y si es **Editable** o **Solo lectura**.

- **Descripción.** Haga clic en el lápiz para editar la descripción en el mismo lugar. Presione Intro para guardar o Esc para cancelar.
- **Etiquetas.** Escriba una etiqueta en **Agregar una etiqueta…** y haga clic en **Agregar**. Consulte [Organizar el trabajo con etiquetas](/es/guides/projects/organizing-with-labels/).
- **Bloquear** y **Desbloquear** cambian el proyecto entre editable y de solo lectura.

Los mosaicos cuentan lo que contiene el proyecto:

| Mosaico | Muestra |
|---|---|
| **Tablas** | Tablas del proyecto. |
| **Flujos de trabajo** | Flujos de trabajo del proyecto. |
| **Pasos** | Pasos de todos los flujos de trabajo. |
| **Variables** | Variables del proyecto. |
| **Tablas publicadas** | Tablas que ha publicado. |
| **Tamaño de los datos** | Lo que almacenan las tablas del proyecto. Haga clic para abrir **Almacenamiento**. Consulte [Administrar el almacenamiento](/es/guides/projects/managing-storage/). |

Si algunas filas del proyecto están filtradas para usted, **Tamaño de los datos** muestra un guion porque el total no sería exacto.

**Coming up** enumera las tres próximas ejecuciones programadas con los nombres de sus flujos de trabajo y el número de sensores activos. **View schedules ›** abre **Programaciones y sensores**.

**Project defaults** muestra los valores de **Entorno**, **Almacenamiento de tablas**, **Acceso** y **Contabilización en ERP** que usan los flujos de trabajo y los pasos, a menos que establezcan los suyos. **Change settings ›** abre la página donde puede cambiarlos.

Los botones del encabezado son:

- **Informe del proyecto** genera un informe del proyecto como **Documento PDF** o **HTML interactivo**.
- **Exportar archivo comprimido** guarda el proyecto como un archivo.
- **Actualizar** vuelve a cargar los mosaicos y las listas de la página.

## Variables

La página **Variables** enumera las variables del proyecto en una cuadrícula. Un flujo de trabajo o un paso se refiere a una variable por su nombre como `{name}`, y la variable propia de un flujo de trabajo reemplaza a una variable del proyecto con el mismo nombre.

La cuadrícula muestra **Nombre**, **Valor**, **Nota**, **Última actualización** y **Por**. Use **Filtro** para acotar la lista, **Nueva variable** para agregar una y **Editar** o **Eliminar** para la fila seleccionada.

## Programaciones y sensores

![Página Programaciones y sensores con una franja de resumen y dos cuadrículas](/images/projects/project-home-schedules.png)

Esta página muestra qué inicia automáticamente los flujos de trabajo del proyecto. Una franja de resumen muestra la próxima ejecución, el número de programaciones activas y en pausa, y el número de sensores activos.

- Las **programaciones** ejecutan un flujo de trabajo según un calendario. La cuadrícula muestra **Nombre**, **Flujo de trabajo**, **Ejecuciones** (el calendario y su zona horaria), **Próxima ejecución** y **Estado**.
- Los **Sensores** ejecutan un flujo de trabajo cuando llegan datos nuevos. La cuadrícula muestra **Nombre**, **Watches**, **Inicio** (el flujo de trabajo), **Last triggered** y **Estado**.

**Estado** es **Activo**, **Paused** o, para un sensor que tiene un problema, **Failing**. Cada cuadrícula tiene **New schedule** o **Nuevo sensor**, **Editar**, **Eliminar** y **Filtro**. Abra **Acciones** para **Activate** o **Deactivate** la fila seleccionada.

**Calendar view** muestra las próximas ejecuciones en un calendario, para que pueda detectar conflictos de programación.

## Acceso y uso compartido

Esta página establece quién puede acceder al proyecto y a sus datos.

- **Project access** establece **Who can open this project**: **Todos los miembros del espacio de trabajo**, **Solo grupos de seguridad específicos** o **Solo miembros específicos**. **Edit groups ›** y **Edit members ›** abren las listas entre las que elegir.
- **Dashboard audience** establece **Default audience for new dashboards**: todos los miembros del proyecto o grupos específicos. Cada panel de control puede cambiar su propia audiencia. Consulte [Controlar quién puede ver un panel de control](/es/guides/dashboards/control-who-can-see-a-dashboard/).
- **Recursos compartidos de datos** enumera los proyectos que pueden leer tablas de este. Consulte [Compartir datos entre proyectos](/es/guides/projects/managing-projects/#uso-compartido-de-datos-entre-proyectos).

## Datos y conexiones

![Página Datos y conexiones con conexiones, almacenamiento de tablas y contabilización en ERP](/images/projects/project-home-data.png)

Estos valores se aplican a todos los flujos de trabajo y pasos del proyecto, a menos que un flujo de trabajo o un paso establezca los suyos.

- **Entorno de la conexión** elige cuál de las configuraciones de cada conexión usan los pasos del proyecto, de modo que un mismo proyecto puede pasar de QA a Producción. Todos los pasos lo siguen, salvo que el paso tenga un [entorno fijo](/es/guides/projects/managing-projects/#fijar-un-paso-a-un-entorno). Cuando lo cambia, la página le avisa si una conexión del proyecto no tiene configuración para el nuevo entorno y nombra los pasos cuyo entorno fijo no lo seguirá.
- **Cuenta de documentos predeterminada** elige dónde los pasos leen y escriben archivos.
- **Almacenamiento predeterminado de tablas** elige dónde se crean las tablas nuevas.
- **Time travel retention** establece cuántos días se conservan las versiones anteriores de los datos de las tablas. Las tablas que heredan este valor también conservan un historial más largo. El historial que ya ha caducado no se puede recuperar.
- **Modo de contabilización** establece cómo envía el proyecto los asientos de diario a los ERP conectados. Es un límite máximo para el proyecto: una ejecución de flujo de trabajo no puede contabilizar de forma más permisiva que este valor. **En vivo** contabiliza con normalidad. **Simular** genera y valida, pero nunca contabiliza ni contacta con el ERP. **Desactivado** omite los pasos de contabilización.
- **Write authorizations** muestra cuántas conexiones de ERP están autorizadas para contabilizar. Los administradores pueden hacer clic en **Manage authorizations ›**.

## Aplicaciones y marca

Esta página abarca las aplicaciones creadas a partir de los datos del proyecto.

- **Aplicaciones de Panel** muestra cuántas aplicaciones se han creado a partir del proyecto. **Open Panel apps ›** las abre y **Nueva aplicación Studio** inicia una.
- **Branding** establece el logotipo y los colores que usan las aplicaciones del proyecto. **Edit branding ›** abre la configuración.
- **Home tile image** es la imagen que se muestra en el mosaico del proyecto en la página de inicio. Haga clic en **Elegir...** para seleccionar una imagen o en **Borrar** para quitarla.
