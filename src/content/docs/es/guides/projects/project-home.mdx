## Descripción

El **inicio del proyecto** es donde usted comienza en un proyecto. Un riel a la izquierda enumera seis páginas: **Resumen**, **Variables**, **Programaciones y sensores**, **Acceso y uso compartido**, **Datos y conexiones** y **Aplicaciones y marca**. Resumen presenta una visión general del proyecto. Las otras cinco páginas son donde se cambia la configuración del proyecto.

La insignia de **Variables** en el riel muestra cuántas variables tiene el proyecto. La insignia de **Programaciones y sensores** muestra cuántas programaciones y sensores están activos.

Un proyecto bloqueado es de solo lectura. Sus páginas muestran un banner que dice "This project is locked, so it is read only. Unlock it on Overview to make changes." y sus controles están inhabilitados.

## Resumen

![Página Resumen del inicio del proyecto con el nombre del proyecto, seis mosaicos, Próximamente y Valores predeterminados del proyecto](/images/projects/project-home-overview.png)

La parte superior de la página muestra el nombre del proyecto y si es **Editable** o **Solo lectura**.

- **Descripción.** Haga clic en el lápiz para editar la descripción en su lugar. Presione Intro para guardar o Esc para cancelar.
- **Etiquetas.** Escriba una etiqueta en **Agregar una etiqueta…** y haga clic en **Agregar**. Consulte [Organizar el trabajo con etiquetas](/es/guides/projects/organizing-with-labels/).
- **Bloquear** y **Desbloquear** cambian el proyecto entre editable y de solo lectura.

Los mosaicos cuentan lo que contiene el proyecto:

| Mosaico | Muestra |
|---|---|
| **Tablas** | Las tablas del proyecto. |
| **Flujos de trabajo** | Los flujos de trabajo del proyecto. |
| **Pasos** | Los pasos de todos los flujos de trabajo. |
| **Variables** | Las variables del proyecto. |
| **Tablas publicadas** | Las tablas que usted ha publicado. |
| **Tamaño de los datos** | Lo que almacenan las tablas del proyecto. Haga clic en él para abrir **Almacenamiento**. Consulte [Administrar el almacenamiento](/es/guides/projects/managing-storage/). |

Si algunas de las filas del proyecto están filtradas para usted, **Tamaño de los datos** muestra un guion porque el total no sería exacto.

**Próximamente** enumera las tres próximas ejecuciones programadas con los nombres de sus flujos de trabajo y el número de sensores activos. **Ver programaciones ›** abre **Programaciones y sensores**.

**Valores predeterminados del proyecto** muestra los valores de **Entorno**, **Almacenamiento de tablas**, **Acceso** y **Contabilización en ERP** que usan los flujos de trabajo y los pasos a menos que definan los suyos. **Cambiar configuración ›** abre la página donde se cambian.

Los botones del encabezado son:

- **Informe del proyecto** genera un informe del proyecto como **Documento PDF** o **HTML interactivo**.
- **Exportar archivo comprimido** guarda el proyecto como un archivo comprimido.
- **Actualizar** vuelve a cargar los mosaicos y las listas de la página.

## Variables

La página **Variables** enumera las variables del proyecto en una cuadrícula. Un flujo de trabajo o un paso hace referencia a una variable por su nombre como `{name}`, y la variable propia de un flujo de trabajo anula una variable de proyecto del mismo nombre.

La cuadrícula muestra **Nombre**, **Valor**, **Nota**, **Última actualización** y **Por**. Use **Filtro** para acotar la lista, **Nueva variable** para agregar una, y **Editar** o **Eliminar** para la fila seleccionada.

## Programaciones y sensores

![Página de programaciones y sensores con una franja de resumen y dos cuadrículas](/images/projects/project-home-schedules.png)

Esta página muestra qué inicia automáticamente los flujos de trabajo del proyecto. Una franja de resumen muestra la próxima ejecución, el número de programaciones activas y en pausa, y el número de sensores activos.

- Las **Programaciones** ejecutan un flujo de trabajo según un calendario. La cuadrícula muestra **Nombre**, **Flujo de trabajo**, **Ejecuciones** (el calendario y su zona horaria), **Próxima ejecución** y **Estado**.
- Los **Sensores** ejecutan un flujo de trabajo cuando llegan datos nuevos. La cuadrícula muestra **Nombre**, **Observa**, **Inicio** (el flujo de trabajo), **Último disparo** y **Estado**.

**Estado** es **Activo**, **En pausa** o, para un sensor que tiene un problema, **Con errores**. Cada cuadrícula tiene **Nueva programación** o **Nuevo sensor**, **Editar**, **Eliminar** y **Filtro**. Abra **Acciones** para **Activar** o **Desactivar** la fila seleccionada.

**Vista de calendario** muestra las próximas ejecuciones en un calendario, para que pueda detectar conflictos de programación.

## Acceso y uso compartido

Esta página define quién puede acceder al proyecto y a sus datos.

- **Acceso al proyecto** define **Quién puede abrir este proyecto**: **Todos los miembros del espacio de trabajo**, **Solo grupos de seguridad específicos** o **Solo miembros específicos**. **Editar grupos ›** y **Editar miembros ›** abren las listas para elegir.
- **Audiencia de los paneles de control** define la **Audiencia predeterminada de los paneles de control nuevos**: todos los del proyecto o grupos específicos. Cada panel de control puede cambiar su propia audiencia. Consulte [Controlar quién puede ver un panel de control](/es/guides/dashboards/control-who-can-see-a-dashboard/).
- **Recursos compartidos de datos** enumera los proyectos que pueden leer tablas de este. Consulte [Uso compartido de datos entre proyectos](/es/guides/projects/managing-projects/#uso-compartido-de-datos-entre-proyectos).

## Datos y conexiones

![Página de datos y conexiones con conexiones, almacenamiento de tablas y contabilización en ERP](/images/projects/project-home-data.png)

Estos ajustes se aplican a todos los flujos de trabajo y pasos del proyecto a menos que un flujo de trabajo o un paso defina los suyos.

- **Entorno de la conexión** elige las credenciales que usa un paso cuando no elige ninguna. La página le avisa cuando una conexión del proyecto no tiene configuración para el entorno seleccionado.
- **Cuenta de documentos predeterminada** elige dónde leen y escriben archivos los pasos.
- **Almacenamiento predeterminado de tablas** elige dónde se crean las tablas nuevas.
- **Retención de Time travel** define cuántos días se conservan las versiones anteriores de los datos de las tablas. Las tablas que heredan este ajuste también conservan un historial más largo. El historial que ya ha caducado no se puede recuperar.
- **Modo de contabilización** define cómo envía el proyecto los asientos de diario a los ERP conectados. Es un techo para el proyecto: una ejecución de flujo de trabajo no puede contabilizar de forma más permisiva que este ajuste. **En vivo** contabiliza con normalidad. **Simular** construye y valida, pero nunca contabiliza ni contacta con el ERP. **Desactivado** omite los pasos de contabilización.
- **Autorizaciones de escritura** muestra cuántas conexiones de ERP están autorizadas para contabilizar. Los administradores pueden hacer clic en **Administrar autorizaciones ›**.

## Aplicaciones y marca

Esta página abarca las aplicaciones creadas sobre los datos del proyecto.

- **Aplicaciones de Panel** muestra cuántas aplicaciones están creadas sobre el proyecto. **Abrir aplicaciones de Panel ›** las abre, y **Nueva aplicación Studio** inicia una.
- **Marca** define el logotipo y los colores que usan las aplicaciones del proyecto. **Editar marca ›** abre la configuración.
- **Imagen del mosaico de inicio** es la imagen que se muestra en el mosaico del proyecto en la página Inicio. Haga clic en **Elegir...** para seleccionar una imagen o en **Borrar** para quitarla.
