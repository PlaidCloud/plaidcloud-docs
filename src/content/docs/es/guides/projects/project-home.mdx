## Descripción

El **Inicio del proyecto** es el punto de partida dentro de un proyecto. Un panel a la izquierda enumera siete páginas, como texto y sin iconos: **Resumen**, **Variables**, **Programaciones y sensores**, **Acceso y uso compartido**, **Datos y conexiones**, **Modelo de datos** y **Aplicaciones y marca**. Resumen ofrece una síntesis del proyecto. En otras cinco páginas se cambia la configuración del proyecto y, en **Modelo de datos**, se ve qué columnas comparten sus tablas.

El distintivo de **Variables** en el panel muestra cuántas variables tiene el proyecto. El distintivo de **Programaciones y sensores** muestra cuántas programaciones y sensores están activos. El distintivo de **Modelo de datos** muestra cuántos elementos de proyecto hay.

Un proyecto bloqueado es de solo lectura. Sus páginas muestran un aviso que dice “Este proyecto está bloqueado, por lo que es de solo lectura. Desbloquéelo en Resumen para hacer cambios.” y sus controles están deshabilitados.

## Resumen

![Página Resumen del Inicio del proyecto con el nombre del proyecto, seis mosaicos, Próximamente y los valores predeterminados del proyecto](/images/projects/project-home-overview.png)

La parte superior de la página muestra el nombre del proyecto y si es **Editable** o de **Solo lectura**.

- **Descripción.** Haga clic en el lápiz para editar la descripción en el mismo lugar. Pulse Intro para guardar o Escape para cancelar.
- **Etiquetas.** Escriba una etiqueta en **Agregar una etiqueta…** y haga clic en **Agregar**. Consulte [Organizar el trabajo con etiquetas](/es/guides/projects/organizing-with-labels/).
- **Bloquear** y **Desbloquear** cambian el proyecto entre editable y de solo lectura.

Los mosaicos cuentan lo que contiene el proyecto:

| Mosaico | Muestra |
|---|---|
| **Tablas** | Las tablas del proyecto. |
| **Flujos de trabajo** | Los flujos de trabajo del proyecto. |
| **Pasos** | Los pasos de todos los flujos de trabajo. |
| **Variables** | Las variables del proyecto. |
| **Tablas publicadas** | Las tablas que ha publicado. |
| **Tamaño de los datos** | Todo lo que almacena el proyecto, incluidas las versiones anteriores que se conservan para poder restaurar los datos. Es la misma cifra que el **Tamaño** del proyecto en la pantalla **Proyectos**. Pase el puntero sobre él para ver por separado los datos actuales y las versiones anteriores que se conservan para restauraciones. Haga clic en él para abrir **Almacenamiento**. Consulte [Administración del almacenamiento](/es/guides/projects/managing-storage/). |

Si algunas de las filas del proyecto están filtradas para usted, **Tamaño de los datos** muestra un guion, porque el total no sería exacto.

**Próximamente** enumera las tres próximas ejecuciones programadas con los nombres de sus flujos de trabajo, y el número de sensores activos. **Ver programaciones ›** abre **Programaciones y sensores**.

**Valores predeterminados del proyecto** muestra los valores de **Entorno**, **Almacenamiento de tablas**, **Acceso** y **Contabilización en ERP** que usan los flujos de trabajo y los pasos, a menos que definan los suyos propios. **Cambiar la configuración ›** abre la página donde se cambian.

Los botones del encabezado son:

- **Informe del proyecto** genera un informe del proyecto como **Documento PDF** o **HTML interactivo**.
- **Exportar archivo comprimido** guarda el proyecto como un archivo comprimido.
- **Actualizar** vuelve a cargar los mosaicos y las listas de la página.

## Variables

La página **Variables** enumera las variables del proyecto en una cuadrícula. Un flujo de trabajo o un paso hace referencia a una variable por su nombre como `{name}`, y una variable propia de un flujo de trabajo anula una variable del proyecto con el mismo nombre.

La cuadrícula muestra **Nombre**, **Valor**, **Nota**, **Última actualización** y **Por**. Use **Filtro** para acotar la lista, **Nueva variable** para agregar una, y **Editar** o **Eliminar** para la fila seleccionada.

## Programaciones y sensores

![Página Programaciones y sensores con una franja de resumen y dos cuadrículas](/images/projects/project-home-schedules.png)

Esta página muestra lo que inicia automáticamente los flujos de trabajo del proyecto. Una franja de resumen muestra la próxima ejecución, el número de programaciones activas y en pausa, y el número de sensores activos.

- **Programaciones** ejecutan un flujo de trabajo según un calendario. La cuadrícula muestra **Nombre**, **Flujo de trabajo**, **Ejecuciones** (el calendario y su zona horaria), **Próxima ejecución** y **Estado**.
- **Sensores** ejecutan un flujo de trabajo cuando llegan datos nuevos. La cuadrícula muestra **Nombre**, **Observa**, **Inicio** (el flujo de trabajo), **Último activador** y **Estado**.

**Estado** es **Activo**, **En pausa** o, en el caso de un sensor que tiene un problema, **Con errores**. Cada cuadrícula tiene **Nueva programación** o **Nuevo sensor**, **Editar**, **Eliminar** y **Filtro**. Abra **Acciones** para **Activar** o **Desactivar** la fila seleccionada.

**Vista de calendario** muestra las próximas ejecuciones en un calendario, para que pueda detectar conflictos de programación.

## Acceso y uso compartido

Esta página define quién puede acceder al proyecto y a sus datos.

- **Acceso al proyecto** define **Quién puede abrir este proyecto**: **Todos los miembros del espacio de trabajo**, **Solo grupos de seguridad específicos** o **Solo miembros específicos**. **Editar grupos ›** y **Editar miembros ›** abren las listas entre las que elegir.
- **Audiencia del panel de control** define la **Audiencia predeterminada de los paneles de control nuevos**: todas las personas del proyecto o grupos específicos. Cada panel de control puede cambiar su propia audiencia. Consulte [Controlar quién puede ver un panel de control](/es/guides/dashboards/control-who-can-see-a-dashboard/).
- **Recursos compartidos de datos** enumera los proyectos que pueden leer tablas de este. Consulte [Compartir datos entre proyectos](/es/guides/projects/managing-projects/#uso-compartido-de-datos-entre-proyectos).

## Datos y conexiones

![Página Datos y conexiones con las conexiones, el almacenamiento de tablas y la contabilización en ERP](/images/projects/project-home-data.png)

Esta configuración se aplica a todos los flujos de trabajo y pasos del proyecto, a menos que un flujo de trabajo o un paso defina la suya propia.

- **Entorno de la conexión** elige cuál de las configuraciones de cada conexión usan los pasos del proyecto, de modo que un mismo proyecto pueda pasar de QA a Production. Todos los pasos lo siguen, a menos que el paso tenga un [entorno fijo](/es/guides/projects/managing-projects/#fijar-un-paso-a-un-entorno). Cuando lo cambia, la página le avisa si una conexión del proyecto no tiene configuración para el nuevo entorno, e indica los pasos cuyo entorno fijo no lo seguirá.
- **Cuenta de documentos predeterminada** elige dónde leen y escriben archivos los pasos.
- **Almacenamiento de tablas predeterminado** elige dónde se crean las tablas nuevas.
- **Retención de time travel** define durante cuántos días se conservan las versiones anteriores de los datos de las tablas. Las tablas que heredan esta configuración también conservan un historial más largo. El historial que ya ha caducado no se puede recuperar.
- **Modo de contabilización** define cómo envía el proyecto los asientos de diario a los ERP conectados. Es un límite máximo para el proyecto: una ejecución de flujo de trabajo no puede contabilizar de forma más permisiva que esta configuración. **En vivo** contabiliza con normalidad. **Simular** genera y valida, pero nunca contabiliza ni se comunica con el ERP. **Desactivado** omite los pasos de contabilización.
- **Autorizaciones de escritura** muestra cuántas conexiones de ERP están autorizadas para contabilizar. Los administradores pueden hacer clic en **Administrar autorizaciones ›**.

## Modelo de datos

Esta página enumera los elementos del proyecto: nombres de columna que comparten sus tablas, descritos una sola vez. Muestra qué tablas comparten cada elemento y permite crear, cambiar y eliminar elementos. Consulte [Modelo de datos y elementos de proyecto](/es/guides/projects/data-model/).

## Aplicaciones y marca

Esta página abarca las aplicaciones creadas con los datos del proyecto.

- **Aplicaciones de Panel** muestra cuántas aplicaciones se han creado con el proyecto. **Abrir aplicaciones Panel ›** las abre, y **Nueva aplicación Studio** crea una.
- **Marca** define el logotipo y los colores que usan las aplicaciones del proyecto. **Editar la marca ›** abre la configuración.
- **Imagen del mosaico de inicio** es la imagen que se muestra en el mosaico del proyecto en la página de inicio. Haga clic en **Elegir...** para seleccionar una imagen, o en **Borrar** para quitarla.
