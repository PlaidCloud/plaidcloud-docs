Las tablas de un proyecto suelen compartir nombres de columna: `Period`, `Org`, `Account`. Un **elemento de proyecto** describe uno de esos nombres una sola vez, para todo el proyecto. Toda tabla con una columna de ese nombre muestra entonces la misma descripción, máscara y dimensión, de modo que ya no tiene que reescribir la misma nota en decenas de tablas.

La página **Modelo de datos** del [inicio del proyecto](/es/guides/projects/project-home/) enumera los elementos de un proyecto, muestra qué tablas comparten cada uno e indica dónde las tablas no coinciden.

## Qué contiene un elemento

| Configuración | Qué hace |
|---|---|
| **Nombre** | El nombre de columna que describe el elemento, escrito exactamente como lo tienen las columnas. |
| **Descripción** | Lo que contiene la columna. Las columnas que no tienen una nota propia muestran esta. |
| **Tipo** | El tipo de datos que el proyecto espera para esta columna. Se comprueba, no se aplica. Consulte [Conflictos de tipo](#conflictos-de-tipo). |
| **Máscara** | Una máscara numérica. Las columnas que no tienen una máscara propia usan esta. |
| **Dimensión** | Una dimensión de la que provienen los valores de la columna. Las columnas que no tienen una dimensión propia usan esta. |
| **Alias** | Otros nombres de columna que significan lo mismo. |

## Cómo obtiene una columna un elemento

Una columna se vincula a un elemento cuando su ID de columna es igual al nombre del elemento o a uno de sus alias. La coincidencia es exacta: `period` y `Period` son nombres distintos, así que agregue `period` como alias de `Period` si quiere ambos.

Agregue o elimine un elemento y todas las columnas coincidentes lo siguen.

## Qué toma una columna de su elemento

Una columna vinculada toma la **Descripción**, la **Máscara** y la **Dimensión** del elemento allí donde su propio valor esté en blanco. Un valor que usted define en la propia columna siempre prevalece. El elemento nunca cambia lo que está almacenado en una tabla: si lo elimina, cada columna vuelve exactamente a lo que tenía.

El **Tipo** no se toma del elemento.

## Abrir la página Modelo de datos

Abra el proyecto y elija **Modelo de datos** en el riel del [inicio del proyecto](/es/guides/projects/project-home/). La insignia del riel muestra cuántos elementos tiene el proyecto. También puede abrir la página desde una columna:

- En el Explorador de tablas, active **Propiedades de la columna** y seleccione una columna. La fila **Elemento** muestra el elemento de la columna o, si no tiene ninguno y usted puede editar el proyecto, **Convertir en elemento**. Haga clic en ella para abrir la página Modelo de datos en ese elemento, o en un elemento nuevo que parte de la descripción, la máscara y la dimensión de la propia columna.
- En la lista de lo que usa una dimensión, una fila llamada **Elemento del proyecto** abre la página Modelo de datos.

Todos los que pueden abrir el proyecto pueden ver la página. Para crear, cambiar o eliminar elementos necesita acceso de escritura al proyecto, y el proyecto no puede estar bloqueado. De lo contrario, la página muestra "Aquí puede ver el modelo de datos, pero no modificarlo."

## Crear un elemento

1. En la página **Modelo de datos**, haga clic en **Nuevo elemento**.
2. Escriba un **Nombre**. Complete **Descripción**, **Tipo**, **Máscara** y **Dimensión** según sea necesario. Deje **Tipo** en **Cualquier tipo** para aceptar cualquier tipo.
3. En **Alias**, escriba otros nombres de columna que signifiquen lo mismo, uno por línea.
4. Haga clic en **Guardar**.

Un elemento no puede tomar un nombre o alias que ya tenga otro elemento. Para cambiar un elemento, haga clic en el lápiz (**Editar elemento**) junto a él. Si lo cambia de nombre, el nombre anterior se conserva como alias para que sus columnas mantengan el elemento.

Para quitar uno, ábralo y haga clic en **Eliminar**, y luego confirme con **Eliminar elemento**. La confirmación indica a cuántas tablas está vinculado. No cambia nada de lo almacenado en esas tablas.

### Elementos sugeridos

Bajo **Sugerido**, la página enumera nombres de columna que conviene convertir en elementos:

- Un nombre que todavía no es un elemento ni un alias y que está en dos o más tablas, donde el tipo de la columna puede ser una clave de combinación (un tipo desconocido cuenta), que se muestra como "*name* está en *n* tablas". Haga clic en **Crear elemento** para crearlo.
- Un nombre que coincide con el nombre o un alias de un elemento si se ignoran las mayúsculas y los guiones bajos, aunque esté en una sola tabla, que se muestra como "*name* parece *element* (*n* tablas)". Haga clic en **Añadir alias** para vincular sus columnas a ese elemento.

## Leer el modelo de datos

El conmutador **Gráfico** y **Matriz** sobre el lienzo muestra las mismas tablas y elementos de dos maneras.

- **Gráfico.** Cada elemento es un centro, y cada tabla es una tarjeta unida a los elementos para los que tiene una columna. Un **1** en una línea marca una columna que es la única clave de la tabla. Una tabla con una clave combinada de varias columnas no se marca. La página se abre en un elemento y sus tablas. Haga clic en un elemento para centrarse en él, haga clic en una tabla para centrarse en ella, o haga doble clic en una tabla para abrirla. Las fichas junto a **Ocultar elementos** ocultan o muestran los elementos que no quiere en el dibujo.
- **Matriz.** Una fila por tabla y una columna por elemento. Use **Filtrar por nombre de tabla** para reducir las filas.

### Conflictos de tipo

Una tabla cuya columna tiene un tipo distinto del de las demás se señala bajo el elemento: "*column* es *type* en *table*, lo que difiere de las demás tablas." Los tipos se comparan por familia, de modo que un entero y un decimal no entran en conflicto. Si el elemento tiene un **Tipo**, las demás se comparan con su familia. Si no, se comparan con la familia que usan la mayoría de las columnas y, cuando dos familias empatan, se usa la que va primero alfabéticamente. Un conflicto es solo una advertencia; no cambia nada.

Una tabla que no se puede leer se deja fuera y se contabiliza en la página en lugar de detenerla.

## Dónde se ven los elementos

Los elementos se muestran como una etiqueta con el nombre del elemento:

- **Explorador de tablas.** La lista de columnas tiene una columna **Marcas** con la etiqueta, junto a las etiquetas **Dimensión** y **Acceso a filas**. Pase el cursor sobre la etiqueta para ver el elemento, su descripción y su dimensión.
- **Propiedades de la columna.** La fila **Elemento** abre el elemento. Cuando **Descripción**, **Máscara** o **Dimensión** está en blanco, el campo muestra "Del elemento *name*: *value*" como sugerencia. La sugerencia no se guarda con la columna.
- **Pestaña Asignación de datos de un paso.** Las columnas de origen y de destino que pertenecen a un elemento muestran su etiqueta después del nombre de la columna.

## Usar elementos desde la API REST y MCP

La API REST lee y cambia elementos en `/rest/v1/analyze/projects/{project_id}/elements`:

| Solicitud | Qué hace |
|---|---|
| `GET` | Devuelve `elements` e `index`, que asigna el nombre de cada columna vinculada al nombre de su elemento. |
| `PUT` | Crea o reemplaza un elemento a partir de `name`, `memo`, `dtype`, `mask`, `dimension` y `aliases`. Agregue `rename_from` para cambiar el nombre de uno. |
| `DELETE` con `?name=` | Elimina el elemento indicado. |
| `GET` `/graph` | Devuelve lo que muestra la página Modelo de datos: cada elemento con su número de tablas y sus conflictos de tipo, las columnas vinculadas de cada tabla y las sugerencias. |

Los metadatos de la tabla devuelven los valores almacenados en cada columna, no los valores que toma de un elemento. Para saber de qué elemento toma valores una columna, busque su nombre en el `index` de `GET` elements.

Un asistente conectado mediante [MCP](/es/integrations/ai-coding-agents/getting-started/) usa `element_find`, `element_upsert` y `element_delete`. Sus descripciones de tablas muestran la nota de cada columna con el valor del elemento completado donde la columna no tiene ninguno.
