PlaidCloud mantiene la barra de direcciones sincronizada con lo que tiene abierto. Abra un flujo de trabajo, una tabla, una dimensión o una pantalla en Paneles de control, Documentos o Identidad, y la URL se convierte en un **enlace directo** a ella: copie esa URL, péguela en un mensaje o en un ticket, y quien la abra llegará a la misma pantalla.

## Copiar un enlace

1. Abra la pantalla que desea compartir: un proyecto, flujo de trabajo, tabla, dimensión, editor de datos o una pantalla de una de las otras aplicaciones.
2. Copie la URL completa de la barra de direcciones del navegador.
3. Envíela.

No hay un botón “compartir” independiente: la barra de direcciones *es* el enlace. La función de marcadores del navegador también funciona con estas URL, de modo que una pantalla a la que regresa con frecuencia se puede guardar como marcador como cualquier otra página web.

<Aside type="note">
Un enlace solo contiene la *ubicación*, no el permiso para verla. Quien abra el enlace sigue necesitando acceso al proyecto. Alguien que no lo tenga no verá el objeto.

Un enlace a una aplicación que la persona no tiene (porque su espacio de trabajo no la incluye o no se le ha concedido) la lleva a Inicio con una nota que indica que el enlace no estaba disponible, en lugar de parecer que no ocurre nada.
</Aside>

## A qué se puede enlazar

### Analyze

| Pantalla | El enlace termina con |
|---|---|
| Proyecto | `#p~<project>` |
| Flujo de trabajo (cuadrícula de pasos) | `#p~<project>~w~<workflow>` |
| Flujo de trabajo (lienzo del Diseñador visual de flujos de trabajo) | `#p~<project>~c~<workflow>` |
| Un paso dentro de un flujo de trabajo | `…~w~<workflow>~s~<step>` o `…~c~<workflow>~s~<step>` |
| Un paso por sí solo | `#p~<project>~s~<step>` |
| Explorador de tablas | `#p~<project>~t~<table>` |
| Jerarquía de dimensiones | `#p~<project>~d~<dimension>` |
| Editor de datos | `#p~<project>~e~<editor>` |
| Inicio | `#home` |

La parte del proyecto en el enlace es el **esquema** de su proyecto cuando tiene uno personalizado, de modo que los enlaces se leen como `#p~acme_budget~w~…` en lugar de como una cadena hexadecimal. Los proyectos que se dejan en el esquema predeterminado usan en su lugar el identificador propio del proyecto. Ambas formas abren el mismo proyecto, por lo que un enlace anterior sigue funcionando después de definir un esquema.

### Paneles de control, Documentos e Identidad

Las pantallas de las otras aplicaciones se nombran directamente, de modo que sus enlaces se leen como la propia pantalla:

| Aplicación | Pantalla | Enlace |
|---|---|---|
| Paneles de control | Paneles de control | `#dashboard.dashboards` |
| Paneles de control | Aplicaciones | `#dashboard.panel_apps` |
| Paneles de control | Cuadernos | `#dashboard.jupyterlite_deployments` |
| Documentos | Administrar | `#document.accounts` |
| Documentos | Sus cuentas | `#document.your_accounts` |
| Documentos | Examinar los archivos de una cuenta | `#document.browser~…` |
| Identidad | Miembros | `#identity.members` |
| Identidad | Directorio | `#identity.member_directory` |
| Identidad | Listas de distribución | `#identity.distro.lists` |
| Identidad | Grupos de seguridad | `#identity.security_groups` |
| Identidad | Auditoría de grupos | `#identity.security_group_audit` |
| Identidad | Todos los ámbitos | `#identity.scopes` |
| Identidad | Sesiones | `#identity.sessions` |
| Identidad | Clientes de API | `#identity.api_client_list` |
| Identidad | Registro de seguridad | `#identity.security_log` |

Algunas pantallas recuerdan una configuración en el enlace (las listas Miembros y Directorio de miembros conservan cada una si estaba viendo **Todos**, **Solo activos** o **Solo inactivos**, y examinar una cuenta conserva qué cuenta), que su navegador muestra como un sufijo codificado después del nombre de la pantalla. Copie y pegue la URL completa y se abrirá la pantalla en la que estaba; al abrirla cuando esa pantalla ya está abierta, se trae esa ventana al frente en lugar de apilar una segunda.

<Aside type="note">
Estos enlaces nombran la pantalla, no un registro dentro de ella. Un enlace a Miembros abre la lista de Miembros; no abre el formulario de un miembro.
</Aside>

## Qué ocurre cuando alguien abre un enlace

- **El proyecto propietario también se abre.** Un enlace a un flujo de trabajo, tabla, paso, dimensión o editor de datos también abre su proyecto como una pestaña en la parte inferior de la pantalla, de modo que el destinatario llega con el contexto circundante en lugar de una sola ventana flotando por su cuenta.
- **Un enlace a un paso selecciona el paso.** Un enlace a un paso dentro de un flujo de trabajo abre el flujo de trabajo y resalta ese paso; en el lienzo del Diseñador visual de flujos de trabajo, se selecciona el nodo del paso.
- **Una dimensión se abre lista para editar** cuando el proyecto está desbloqueado, y de solo lectura cuando está bloqueado: la misma regla que se aplica cuando la abre desde el proyecto.
- **Actualizar la página lo mantiene donde está.** Al recargar la página se vuelve a abrir lo que nombra el enlace, en lugar de devolverlo al inicio.

## Moverse entre pantallas

La URL sigue lo que está viendo:

- Al abrir una pantalla se actualiza la barra de direcciones, y el botón **Atrás** del navegador lo devuelve a la anterior.
- **Sin importar cómo llegó allí.** Abrir un flujo de trabajo desde el flujo de actividad, una tarjeta de Inicio, una acción **Profundizar en el flujo de trabajo**, un listado de “dónde se usa” o el registro actualiza el enlace igual que abrirlo desde la lista de Flujos de trabajo del proyecto, y lo mismo ocurre al volver a abrir la pantalla en la que ya está.
- Al seleccionar la pestaña de una ventana en la parte inferior de la pantalla, el enlace de esa ventana vuelve a la barra de direcciones, de modo que al cambiar entre pantallas abiertas la URL se mantiene fiel.
- Al cambiar a una aplicación en la que no hay nada enlazable abierto, el enlace se **borra** en lugar de dejarlo apuntando a la aplicación que acaba de abandonar.
- Al cerrar una ventana, la URL vuelve al lugar desde donde la abrió. Cierre una tabla que abrió desde un lienzo de flujo de trabajo y la URL vuelve a ese lienzo; cierre una que abrió desde un proyecto y vuelve al proyecto.
- Al cerrar la última ventana de un proyecto, se borra el enlace.

## Enlaces guardados antes de este cambio

Los enlaces con el estilo antiguo `#te?p=…&t=…` siguen funcionando. Al abrir uno, se le lleva al mismo lugar y se reescribe discretamente la barra de direcciones con la forma actual, de modo que al volver a copiarlo desde allí obtiene el enlace más nuevo y legible.
