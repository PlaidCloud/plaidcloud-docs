PlaidCloud mantiene la barra de direcciones sincronizada con lo que tiene abierto. Abra un flujo de trabajo, una tabla, una dimensión o una pantalla de Paneles de control, Documentos o Identidad, y la URL se convierte en un **vínculo directo** a ella: copie esa URL, péguela en un mensaje o en un ticket, y quien la abra llegará a la misma pantalla.

## Cómo copiar un vínculo

1. Abra la pantalla que desea compartir: un proyecto, un flujo de trabajo, una tabla, una dimensión, un editor de datos o una pantalla de una de las otras aplicaciones.
2. Copie la URL completa de la barra de direcciones del navegador.
3. Envíela.

No hay un botón independiente de “compartir”: la barra de direcciones *es* el vínculo. La función de marcadores del navegador también funciona con estas URL, por lo que una pantalla a la que vuelve con frecuencia se puede guardar como marcador como cualquier otra página web.

<Aside type="note">
Un vínculo solo contiene la *ubicación*, no el permiso para verla. Quien abra el vínculo sigue necesitando acceso al proyecto. Quien no lo tenga no verá el objeto.

Un vínculo a una aplicación que la persona no tiene (porque su espacio de trabajo no la incluye o no se le ha concedido) la lleva a Inicio con una nota que indica que el vínculo no estaba disponible, en lugar de parecer que no ocurre nada.
</Aside>

## A qué se puede vincular

### Analyze

| Pantalla | El vínculo termina en |
|---|---|
| Proyecto | `#p~<project>` |
| Flujo de trabajo (cuadrícula de pasos) | `#p~<project>~w~<workflow>` |
| Flujo de trabajo (lienzo del Diseñador visual de flujos de trabajo) | `#p~<project>~c~<workflow>` |
| Un paso dentro de un flujo de trabajo | `…~w~<workflow>~s~<step>` o `…~c~<workflow>~s~<step>` |
| Un paso por sí solo | `#p~<project>~s~<step>` |
| Explorador de tablas | `#p~<project>~t~<table>` |
| Jerarquía de dimensión | `#p~<project>~d~<dimension>` |
| Editor de datos | `#p~<project>~e~<editor>` |
| Inicio | `#home` |

La parte del proyecto en el vínculo es el **esquema** de su proyecto cuando tiene uno personalizado, de modo que los vínculos se leen como `#p~acme_budget~w~…` en lugar de como una cadena hexadecimal. Los proyectos que se dejan con el esquema predeterminado usan en su lugar el identificador propio del proyecto. Ambas formas abren el mismo proyecto, por lo que un vínculo antiguo sigue funcionando después de establecer un esquema.

### Paneles de control, Documentos e Identidad

Las pantallas de las otras aplicaciones se nombran directamente, por lo que sus vínculos se leen como la propia pantalla:

| Aplicación | Pantalla | Vínculo |
|---|---|---|
| Paneles de control | Mis paneles de control | `#dashboard.dashboards` |
| Paneles de control | Aplicaciones | `#dashboard.panel_apps` |
| Paneles de control | Jupyter Lite | `#dashboard.jupyterlite_deployments` |
| Documentos | Todas las cuentas | `#document.accounts` |
| Documentos | Cuentas compartidas | `#document.shared_accounts` |
| Documentos | Cuentas privadas | `#document.private_accounts` |
| Documentos | Exploración de los archivos de una cuenta | `#document.browser~…` |
| Identidad | Miembros | `#identity.members` |
| Identidad | Directorio de miembros | `#identity.member_directory` |
| Identidad | Listas de distribución | `#identity.distro.lists` |
| Identidad | Grupos de seguridad | `#identity.security_groups` |
| Identidad | Auditoría de grupos de seguridad | `#identity.security_group_audit` |
| Identidad | Ámbitos | `#identity.scopes` |
| Identidad | Sesiones | `#identity.sessions` |
| Identidad | Clientes de API | `#identity.api_client_list` |
| Identidad | Registro de seguridad | `#identity.security_log` |

Algunas pantallas recuerdan una configuración en el vínculo (las listas Miembros y Directorio de miembros conservan cada una si estaba viendo **Todos**, **Solo activos** o **Solo inactivos**, y al explorar una cuenta se conserva cuál), que el navegador muestra como un sufijo codificado después del nombre de la pantalla. Copie y pegue la URL completa y se abrirá la pantalla en la que estaba; si la abre cuando esa pantalla ya está abierta, esa ventana pasa al primer plano en lugar de apilar una segunda.

<Aside type="note">
Estos vínculos nombran la pantalla, no un registro dentro de ella. Un vínculo a Miembros abre la lista de miembros; no abre el formulario de un miembro concreto.
</Aside>

## Qué ocurre cuando alguien abre un vínculo

- **También se abre el proyecto propietario.** Un vínculo a un flujo de trabajo, una tabla, un paso, una dimensión o un editor de datos abre además su proyecto como una pestaña en la parte inferior de la pantalla, de modo que el destinatario llega con el contexto que lo rodea en lugar de una sola ventana flotando por su cuenta.
- **Un vínculo a un paso selecciona el paso.** Un vínculo a un paso dentro de un flujo de trabajo abre el flujo de trabajo y resalta ese paso; en el lienzo del Diseñador visual de flujos de trabajo, se selecciona el nodo del paso.
- **Una dimensión se abre lista para editar** cuando el proyecto está desbloqueado, y en modo de solo lectura cuando está bloqueado: la misma regla que se aplica cuando la abre desde el proyecto.
- **Actualizar la página le mantiene donde está.** Volver a cargar la página reabre lo que nombra el vínculo, en lugar de devolverle al principio.

## Desplazamiento entre pantallas

La URL sigue lo que está viendo:

- Abrir una pantalla actualiza la barra de direcciones, y el botón **Atrás** del navegador le devuelve a la anterior.
- **Da igual cómo haya llegado.** Abrir un flujo de trabajo desde el flujo de actividad, una tarjeta de Inicio, una acción **Profundizar en el flujo de trabajo**, un listado de “dónde se usa” o el registro actualiza el vínculo igual que abrirlo desde la lista de flujos de trabajo del proyecto, y lo mismo ocurre al volver a abrir la pantalla en la que ya está.
- Al seleccionar la pestaña de una ventana en la parte inferior de la pantalla, el vínculo de esa ventana vuelve a la barra de direcciones, de modo que al cambiar entre pantallas abiertas la URL sigue siendo fiel.
- Cambiar a una aplicación en la que no hay nada vinculable abierto **borra** el vínculo en lugar de dejarlo apuntando a la aplicación que acaba de dejar.
- Al cerrar una ventana, la URL vuelve al lugar desde el que la abrió. Cierre una tabla que abrió desde el lienzo de un flujo de trabajo y la URL vuelve a ese lienzo; cierre una que abrió desde un proyecto y vuelve al proyecto.
- Al cerrar la última ventana de un proyecto se borra el vínculo.

## Vínculos guardados antes de este cambio

Los vínculos del estilo anterior `#te?p=…&t=…` siguen funcionando. Al abrir uno, llega al mismo lugar y la barra de direcciones se reescribe discretamente en la forma actual, de modo que si lo vuelve a copiar desde ahí obtiene el vínculo más reciente y legible.
