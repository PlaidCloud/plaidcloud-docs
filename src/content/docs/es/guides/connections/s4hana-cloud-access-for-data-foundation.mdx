[Data Foundation](/es/guides/projects/data-foundation/) reúne los datos de cada sistema ERP e instancia que usted conecta en un único Common Finance Model, y SAP S/4HANA Cloud es uno de los ERP que lee directamente. La conexión lee los servicios OData liberados del inquilino con credenciales de cliente de OAuth 2.0; no interviene ningún agente. Esta página está dirigida al administrador de S/4HANA Cloud que lo configura y al usuario de PlaidCloud que se lo solicita.

PlaidCloud solo lee datos. Nadie envía por correo electrónico una contraseña ni un secreto de cliente.

## Enviar la solicitud de acceso

En la pestaña **Foundation** del proyecto, elija **Crear una conexión nueva** en **Conexión de SAP S/4HANA Cloud**. El formulario muestra la solicitud completa. Haga clic en **Copiar solicitud** para pegarla en su propio mensaje, o en **Enviar solicitud por correo** para abrirla en su programa de correo con el asunto "Read-only SAP S/4HANA Cloud access for PlaidCloud (OAuth 2.0 client credentials)."

## Qué configura el administrador de S/4HANA Cloud

<Steps>

1. **Cree un usuario de comunicación** para PlaidCloud, en la aplicación **Maintain Communication Users**. Su método de autenticación es OAuth 2.0 o nombre de usuario y contraseña, según requiera su entorno.

2. **Cree un sistema de comunicación** para PlaidCloud, en la aplicación **Communication Systems**, con ese usuario para la comunicación entrante y credenciales de cliente de OAuth 2.0.

3. **Cree un acuerdo de comunicación** para cada escenario siguiente, en la aplicación **Communication Arrangements**, todos para el sistema del paso 2. En conjunto exponen los servicios OData que lee PlaidCloud:

   | Escenario | Servicio |
   |---|---|
   | Company Code | `API_COMPANYCODE_SRV` |
   | G/L Account in Chart of Accounts | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | Cost Center | `API_COSTCENTER_SRV` |
   | Business Partner and Customer | `API_BUSINESS_PARTNER` |
   | Product | `API_PRODUCT_SRV` |
   | Fiscal Year Variant Periods | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | Exchange Rates | `API_EXCHANGERATE_SRV` |
   | Journal Entry Item | `API_JOURNALENTRYITEMBASIC_SRV` (el diario y el saldo arrastrado) |
   | Billing Document | `API_BILLING_DOCUMENT_SRV` (opcional: agrega ventas facturadas, documentos y partidas) |

   Dé al usuario de comunicación acceso a cada código de empresa sobre el que informe.

</Steps>

## Qué debe enviar de vuelta

| El administrador envía | Se introduce en PlaidCloud como |
|---|---|
| El host de la API del inquilino, por ejemplo `my300000-api.s4hana.cloud.sap` | **Host** |
| El ID de cliente | **ID de cliente** |
| El secreto de cliente, mediante el formulario de conexión seguro | **Secreto de cliente**, que su equipo pega por sí mismo |
| La URL del token, solo si su entorno usa un servidor de autorización XSUAA en lugar del propio del inquilino (`/sap/bc/sec/oauth2/token`) | **URL del token (opcional)** |
| El ámbito, solo con un servidor de autorización XSUAA | **Ámbito (opcional)** |
| Si se ha ejecutado **Carry Forward Balances** para cada ejercicio fiscal que carga | No hay nada que introducir. Los saldos iniciales se leen de ahí. |

<Aside type="caution">
No envíe nunca el secreto de cliente por correo electrónico. **Secreto de cliente** es un secreto: se almacena en la conexión y no se vuelve a mostrar.
</Aside>

## Comprobar el acceso

De vuelta en PlaidCloud, introduzca los valores y haga clic en **Probar conexión**. Cada conjunto de datos se muestra como **Legible**, **Falta un permiso** o **Error**:

| Conjunto de datos | Servicio que necesita |
|---|---|
| Entidades | `API_COMPANYCODE_SRV` |
| Plan de cuentas | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| Departamentos | `API_COSTCENTER_SRV` |
| Clientes | `API_BUSINESS_PARTNER` |
| Productos | `API_PRODUCT_SRV` |
| Tipos de cambio | `API_EXCHANGERATE_SRV` |
| Calendario fiscal | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| Libro mayor | `API_JOURNALENTRYITEMBASIC_SRV` |
| Balance de comprobación | `API_JOURNALENTRYITEMBASIC_SRV` |
| Líneas de ventas | `API_BILLING_DOCUMENT_SRV` (opcional) |

Cuando un conjunto de datos muestra **Falta un permiso**, pida al administrador que agregue el acuerdo de comunicación de su servicio y vuelva a probar. Las líneas de ventas, el presupuesto y los saldos de inventario son opcionales: un inquilino que no contiene alguno de ellos carga igualmente todo lo demás.
