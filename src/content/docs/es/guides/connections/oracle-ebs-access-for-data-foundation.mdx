[Data Foundation](/es/guides/projects/data-foundation/) reúne los datos de cada sistema ERP e instancia que usted conecta en un único Common Finance Model, y Oracle E-Business Suite es uno de los ERP que lee directamente. PlaidCloud llega a EBS mediante un agente de [PlaidLink](/es/reference/cli/plaidlink/) instalado dentro de su red, nunca de forma directa. Esta página está dirigida al administrador de EBS que lo configura y al usuario de PlaidCloud que se lo solicita.

PlaidCloud solo lee datos. Nadie envía una contraseña por correo electrónico.

## Enviar la solicitud de acceso

En la pestaña **Foundation** del proyecto, elija **Crear una conexión nueva** en **Conexión de Oracle E-Business Suite**. El formulario muestra la solicitud completa y un enlace **How to set up PlaidLink**. Haga clic en **Copiar solicitud** para pegarla en su propio mensaje, o en **Enviar solicitud por correo** para abrirla en su programa de correo con el asunto "Read-only Oracle E-Business Suite access for PlaidCloud (through PlaidLink)."

## Qué configura el administrador de EBS

<Steps>

1. **Instale PlaidLink** en un servidor que pueda llegar a la base de datos de EBS y regístrelo en PlaidCloud.

2. **Conceda SELECT** al usuario del esquema APPS de PlaidLink (o a un usuario de esquema de solo lectura con sinónimos de los objetos de APPS) sobre:

   | Área | Objetos |
   |---|---|
   | General Ledger | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES` |
   | Flexfields | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | Ventas (opcional) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |

3. **Indique un usuario de aplicación** (`FND_USER`) y una responsabilidad que pueda ver todos los libros y valores del segmento de equilibrio que desee informar.

4. **Describa el plan de cuentas.** Indique qué segmentos son el segmento de equilibrio, la cuenta natural, el centro de costos y el segmento intercompañía (sus calificadores de segmento). PlaidCloud clasifica una cuenta de gastos como costo de los productos vendidos cuando ella o un valor padre por encima de ella se describe como costo de los productos vendidos, costo de ventas o costo de ingresos. Clasifica una cuenta como no operativa cuando alguno de ellos nombra ingresos o gastos por intereses, ingresos o costos financieros, moneda extranjera, gasto por impuesto sobre la renta, u otros ingresos y gastos. Avise a PlaidCloud si sus valores padre usan otras palabras para esto.

5. **Confirme los tipos de tipo de cambio.** Cada libro principal nombra sus tipos de cambio de promedio del período y de cierre del período en las opciones de conversión del libro. PlaidCloud convierte con los tipos de cambio diarios de esos dos tipos.

</Steps>

<Aside type="caution">
Una responsabilidad incorrecta devuelve las filas de otro libro sin ningún error. Confírmela con el propietario de su libro mayor.
</Aside>

## Qué debe enviar de vuelta

| El administrador envía | Se introduce en PlaidCloud como |
|---|---|
| El host de la base de datos | **Database host** |
| El puerto de la base de datos | **Puerto de la base de datos** (1521, salvo que lo cambie) |
| El nombre del servicio | **Nombre del servicio** |
| El usuario del esquema APPS | **APPS schema user** |
| La contraseña del esquema APPS, mediante el formulario de conexión seguro | **APPS schema password**, que su equipo pega por sí mismo |
| El `FND_USER` | **Application user (FND_USER)** |
| La clave de responsabilidad | **Responsibility key** |
| Los valores del segmento de equilibrio que PlaidCloud puede leer | En **Balancing segment values**, que el sistema no puede listar antes de una carga: introduzca un valor en **Nombre**, o déjelo en blanco para cargar todas las entidades del libro principal |

El agente de PlaidLink que llega a la instancia se elige en la configuración del sistema como `agent`.

<Aside type="caution">
No envíe nunca la contraseña por correo electrónico. **APPS schema password** es un secreto: se almacena en la conexión y no se vuelve a mostrar.
</Aside>

## Comprobar el acceso

De vuelta en PlaidCloud, introduzca los valores y haga clic en **Probar conexión**. Cada conjunto de datos se muestra como **Legible**, **Falta un permiso** o **Error**:

| Conjunto de datos | Objetos que lee |
|---|---|
| Entidades | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| Calendario fiscal | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| Plan de cuentas | `GL_CODE_COMBINATIONS`, las tablas de flexfields |
| Departamentos | `GL_CODE_COMBINATIONS`, las tablas de flexfields |
| Tipos de cambio | `GL_DAILY_RATES` |
| Libro mayor | `GL_JE_HEADERS`, `GL_JE_LINES` |
| Balance de comprobación | `GL_BALANCES` |
| Clientes | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES` (opcional) |
| Productos | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` (opcional) |
| Líneas de ventas | Las tablas `RA_CUSTOMER_TRX` (opcional) |

Cuando un conjunto de datos muestra **Falta un permiso**, pida al administrador que conceda SELECT sobre los objetos y vuelva a probar. Los clientes, los productos y las líneas de ventas son opcionales: una instancia que no los usa carga igualmente todo lo demás.
