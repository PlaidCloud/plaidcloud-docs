[Data Foundation](/es/guides/projects/data-foundation/) reúne los datos de cada sistema ERP e instancia que usted conecta en un único Common Finance Model, y Sage Intacct es uno de los ERP que lee directamente. La conexión usa Intacct Web Services: una autorización de remitente para PlaidCloud y un usuario de Web Services de solo lectura. Esta página está dirigida al administrador de Sage Intacct que lo configura y al usuario de PlaidCloud que se lo solicita.

PlaidCloud solo lee datos. Nadie envía una contraseña por correo electrónico.

## Enviar la solicitud de acceso

En la pestaña **Foundation** del proyecto, elija **Crear una conexión nueva** en **Conexión de Sage Intacct**. El formulario muestra la solicitud completa. Haga clic en **Copiar solicitud** para pegarla en su propio mensaje, o en **Enviar solicitud por correo** para abrirla en su programa de correo con el asunto "Read-only Sage Intacct access for PlaidCloud (Web Services)."

## Qué configura el administrador de Sage Intacct

<Steps>

1. **Autorice a PlaidCloud como remitente de Web Services.** En **Company > Admin > Web Services authorizations**, agregue el Sender ID que le dio PlaidCloud. Envíe de vuelta el Sender ID y la contraseña de remitente (Sender password) que Sage emitió para él.

2. **Cree un usuario de Web Services.** En **Company > Admin > Users**, cree un usuario de tipo "Business" con la opción "Web services only", y un rol con permiso **View** sobre:

   | Área | Objetos |
   |---|---|
   | General Ledger | Accounts, Journal entries (todos los diarios, incluidos los diarios de ajuste), Account balances, Reporting periods, Exchange rates, Budgets |
   | Company | Entities (locations), Departments, Classes, Projects |
   | Accounts Receivable | Customers |
   | Inventory Control | Items |
   | Order Entry | Transactions (facturas de venta, y las notas de crédito y devoluciones que las revierten), si desea ventas |

   Dé al usuario acceso al nivel superior de la empresa y a cada entidad sobre la que informe PlaidCloud. Si las definiciones de transacción de sus notas de crédito y devoluciones no se llaman Sales Credit Memo y Sales Return, comunique sus nombres al usuario de PlaidCloud.

3. **Permita la dirección IP del usuario** si su empresa restringe Web Services por IP.

</Steps>

## Qué debe enviar de vuelta

| El administrador envía | Se introduce en PlaidCloud como |
|---|---|
| El ID de la empresa | **ID de empresa** |
| El ID del usuario de Web Services | **Web services user ID** |
| La contraseña del usuario de Web Services | **Web services password** |
| El Sender ID | **Sender ID** |
| La contraseña de remitente | **Sender password** |
| Los nombres de las definiciones de transacción de sus notas de crédito y devoluciones, si no son los predeterminados | La configuración del sistema `credit_documents` (valores predeterminados: Sales Credit Memo, Sales Return) |
| Las entidades que PlaidCloud puede leer | Se eligen en **Entidades** en PlaidCloud |

Las contraseñas pasan por su administrador de contraseñas, nunca por correo electrónico. El equipo del usuario de PlaidCloud pega la **Web services password** y la **Sender password** en PlaidCloud por sí mismo. Las entidades que son las eliminaciones propias de su empresa se indican en la configuración del sistema `elimination_entities`.

## Comprobar el acceso

De vuelta en PlaidCloud, introduzca los valores y haga clic en **Probar conexión**. Cada conjunto de datos se muestra como **Legible**, **Falta un permiso** o **Error**:

| Conjunto de datos | Permiso que necesita |
|---|---|
| Entidades | Company: Entities (View) |
| Plan de cuentas | General Ledger: Accounts y Statistical accounts (View) |
| Departamentos | Company: Departments (View) |
| Clientes | Accounts Receivable: Customers (View) |
| Productos | Inventory Control: Items (View) |
| Tipos de cambio | General Ledger: Exchange rates (View) |
| Calendario fiscal | General Ledger: Reporting periods (View) |
| Balance de comprobación | General Ledger: Account balances (View) |
| Libro mayor | General Ledger: Journal entries (View) |
| Líneas de ventas | Order Entry: Transactions (View) |
| Presupuesto | General Ledger: Budgets (View) |
| Inductores de asignación | General Ledger: Account balances (View) |

Cuando falta un conjunto de datos, la prueba indica el permiso que debe agregarse. Pida al administrador que lo agregue al rol y vuelva a probar. Las líneas de ventas, el presupuesto y los inductores de asignación son opcionales: una empresa que no los usa carga igualmente todo lo demás.
