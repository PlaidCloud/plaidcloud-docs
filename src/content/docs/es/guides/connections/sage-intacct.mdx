Conecte PlaidCloud con Sage Intacct y extraiga datos financieros y contables. Esta guía le lleva desde las credenciales de Web Services hasta una extracción funcional. Para la referencia de campos, consulte el [conector REST de Sage Intacct](/es/reference/connectors/rest/sage-intacct/).

## Requisitos previos

En Sage Intacct necesita lo siguiente:

- **Web Services** habilitado para su empresa: el soporte de Sage aprovisiona su **Sender ID** y su **Sender password**, que pasan a ser el **ID de cliente** y el **Secreto de cliente** de la conexión.
- Un **usuario de Web Services** para PlaidCloud, con permisos sobre **todos** los objetos que leerán sus consultas.
- Su **ID de empresa**.

Anote el ID de empresa, el nombre de usuario del servicio web, el ID de cliente (Sender ID) y el secreto de cliente (Sender password) antes de comenzar.

<Aside type="caution">El ID de cliente y el secreto de cliente son distintos del nombre de usuario del servicio web. El ID de cliente y el secreto de cliente autentican la aplicación ante Sage; el nombre de usuario del servicio web, combinado con el ID de empresa, autentica el inicio de sesión dentro de su empresa. Los tres son obligatorios, y el ID de cliente y el secreto de cliente son secretos.</Aside>

## Crear la conexión

Intacct es una conexión de la **familia REST**. PlaidCloud ofrece una variante dedicada de **Intacct** (que aparece como **REST - Intacct**) que rellena de antemano el punto de conexión del token OAuth2 y solicita solo los cuatro campos de credenciales que se indican más abajo; internamente es una conexión REST que se autentica con credenciales de cliente OAuth2 en la API REST de Intacct.

<Steps>

1. Abra **Tools > Connections** y haga clic en `New Connection`.

2. En **REST**, elija **Intacct** (aparece en el menú como **REST - Intacct**).

3. Complete los campos:

   | Campo | Valor |
   |---|---|
   | Nombre | Un nombre descriptivo, por ejemplo, `Intacct Prod`. |
   | ID de cliente | Su **Sender ID** de Intacct. |
   | Secreto de cliente | Su **Sender password** de Intacct. |
   | Nombre de usuario del servicio web | El inicio de sesión del usuario de Web Services. |
   | ID de empresa | La empresa de Intacct a la que se conecta. |

4. Haga clic en `Create`.

</Steps>

## Probar la conexión

Confirme que las credenciales funcionan antes de construir sobre ellas.

<Steps>

1. Agregue un [paso Solicitud REST](/es/guides/workflows/rest-request-step/) a un flujo de trabajo y establezca **Conexión** en su conexión de Sage Intacct.

2. Apúntelo a una lectura pequeña y acotada de un objeto que su usuario pueda ver.

3. Haga clic en **Enviar solicitud de prueba**.

</Steps>

<Aside type="caution">
Use **Enviar solicitud de prueba**, no la pestaña Vista previa. Un resultado verde significa que tanto el ID de cliente y el secreto de cliente como el nombre de usuario del servicio web se autenticaron. Si hay un error, el mensaje incluye el detalle propio de Sage, normalmente una falta de permisos del usuario de Web Services o un ID de cliente o secreto de cliente incorrectos.
</Aside>

<Aside type="note">
Las solicitudes de Sage Intacct son de **una sola solicitud: no hay paginación** que configurar. No modifique los controles de paginación.
</Aside>

## Extraer datos

Para las extracciones habituales, Sage Intacct cuenta con pasos de importación dedicados que se asignan directamente a objetos de Intacct:

- [Import Sage AP](/es/reference/workflow-steps/sage-intacct/import-sage-ap/) (paso): encabezados de facturas de cuentas por pagar
- [Import Sage AP Lines](/es/reference/workflow-steps/sage-intacct/import-sage-ap-lines/) (paso): detalle de líneas de facturas de cuentas por pagar
- [Import Sage Intacct Query](/es/reference/workflow-steps/sage-intacct/import-intacct-query/) (paso): una consulta sobre cualquier objeto de Intacct
- [Import Intacct Entity](/es/reference/workflow-steps/sage-intacct/import-intacct-entity/) (paso): detalle del libro mayor, saldos de cuentas, asientos de diario, maestros de dimensiones (ubicación, departamento, clase) y documentos de pedidos de venta, con paginación automática `readMore` para conjuntos de resultados grandes y filtros de rango `ge`/`le`

Elija el paso, seleccione su conexión de Sage Intacct, establezca el objeto o la consulta y ejecútelo. Como en cualquier importación, defina las columnas de importes y fechas con sus tipos reales para que lleguen con tipo y no como texto.

## Verificar y programar

<Steps>

1. Ejecute el paso y revise la tabla de destino: recuento de filas y tipos de columna.

2. Para una carga continua, [programe el flujo de trabajo](/es/get-started/tutorials/schedule-a-workflow/).

</Steps>

## Solución de problemas

| Síntoma | Causa probable |
|---|---|
| Error de autenticación | Un ID de cliente o secreto de cliente incorrecto (aprovisionado por Sage) o un nombre de usuario del servicio web incorrecto. |
| Error de permisos o de objeto no encontrado | El usuario de Web Services no tiene permiso sobre el objeto que se lee. |
| Resultado vacío o inesperado | Un **ID de empresa** incorrecto. |
