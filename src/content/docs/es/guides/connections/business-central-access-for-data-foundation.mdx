[Data Foundation](/es/guides/projects/data-foundation/) reúne los datos de cada sistema ERP e instancia que usted conecta en un único Common Finance Model, y Microsoft Dynamics 365 Business Central es uno de los ERP que lee directamente. La conexión usa una aplicación de Microsoft Entra ID con credenciales de cliente, un conjunto de permisos de solo lectura y algunas páginas publicadas como servicios web. Esta página está dirigida al administrador de Business Central que lo configura y al usuario de PlaidCloud que se lo solicita.

PlaidCloud solo lee datos. Nadie envía un secreto de cliente por correo electrónico.

## Enviar la solicitud de acceso

En la pestaña **Foundation** del proyecto, elija **Crear una conexión nueva** en **Conexión de Business Central**. El formulario muestra la solicitud completa. Haga clic en **Copiar solicitud** para pegarla en su propio mensaje, o en **Enviar solicitud por correo** para abrirla en su programa de correo con el asunto "Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials)."

## Qué configura el administrador de Business Central

<Steps>

1. **Registre una aplicación en Microsoft Entra ID.** En **App registrations > New registration**, agregue un secreto de cliente y anote el ID de directorio (inquilino), el ID de aplicación (cliente) y el secreto.

2. **Agregue la aplicación en Business Central.** Abra **Microsoft Entra Applications**, agregue la aplicación, establezca su estado en **Habilitado** y asígnele los conjuntos de permisos **D365 READ** y **D365 BASIC** para cada empresa sobre la que informe. No le asigne ningún conjunto de permisos de escritura.

3. **Publique páginas como servicios web.** En **Search > Web Services > New**, publique estas páginas con exactamente estos valores de **Nombre del servicio** y con **Published** marcado. La API estándar no incluye sus campos:

   | Página | Nombre del servicio | Notas |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Unidades de negocio | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | Costo de los productos vendidos; opcional |
   | 120 G/L Budget Entries | `GLBudgetEntries` | Presupuestos; opcional |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | Inductores estadísticos; opcional |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | Dimensiones de acceso directo 3 a 8; opcional |
   | 479 Dimension Set Entries | `DimensionSetEntries` | Dimensiones de acceso directo 3 a 8; opcional |

4. **Comunique al usuario de PlaidCloud dos decisiones:** el código de origen con el que se contabilizan sus ajustes de auditoría (PlaidCloud supone `ADJUSTMENT`) y qué dimensión es su departamento (PlaidCloud supone la dimensión global 1, llamada `DEPARTMENT`).

</Steps>

## Qué debe enviar de vuelta

| El administrador envía | Se introduce en PlaidCloud como |
|---|---|
| El ID de directorio (inquilino) | **Directory (tenant) ID** |
| El nombre del entorno, por ejemplo `production` | **Nombre del entorno** |
| El ID de aplicación (cliente) | **Application (client) ID** |
| El secreto de cliente | **Secreto de cliente**, introducido mediante el formulario, no por correo electrónico |
| El nombre de la dimensión que es su departamento | La configuración del sistema `department_dimension` |
| Las empresas que PlaidCloud puede leer | Se eligen en **Companies** en PlaidCloud (al menos una) |

Las empresas que son empresas de consolidación se indican en la configuración del sistema `consolidation_companies`, para que sus asientos no se cuenten como actividad de una empresa. Los tipos de cambio provienen de una sola empresa: indíquela en la configuración del sistema `rate_company`, o PlaidCloud usa la primera empresa.

## Comprobar el acceso

De vuelta en PlaidCloud, introduzca los valores y haga clic en **Probar conexión**. Cada conjunto de datos se muestra como **Legible**, **Falta un permiso** o **Error**:

| Conjunto de datos | Qué necesita |
|---|---|
| Entidades, plan de cuentas, clientes, productos, tipos de cambio, balance de comprobación | Acceso a la API (conjunto de permisos D365 READ) |
| Calendario fiscal | El servicio web `AccountingPeriods` |
| Departamentos | El servicio web `DimensionValues` |
| Libro mayor | El servicio web `GLEntries` |
| Líneas de ventas, presupuesto, inductores de asignación | Opcional |

Cuando falta un conjunto de datos, la prueba indica qué permiso o servicio web agregar. Pida al administrador que lo agregue y vuelva a probar. Las líneas de ventas, el presupuesto y los inductores de asignación son opcionales: un entorno que no los usa carga igualmente todo lo demás.
