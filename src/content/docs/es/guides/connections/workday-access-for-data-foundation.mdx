[Data Foundation](/es/guides/projects/data-foundation/) reúne los datos de cada sistema ERP e instancia que usted conecta en un único Common Finance Model. Workday es uno de los sistemas que lee directamente. Workday no tiene un servicio web para las líneas de diario ni para los saldos, así que esta página está dirigida al administrador de Workday que crea los informes que se leen y al usuario de PlaidCloud que se lo solicita.

PlaidCloud solo lee datos. Nadie envía una contraseña por correo electrónico.

## Enviar la solicitud de acceso

En la pestaña **Foundation** del proyecto, elija **Crear una conexión nueva** y seleccione **Workday**. El formulario muestra la especificación de los informes. Haga clic en **Copiar solicitud** para pegarla en su propio mensaje, o en **Enviar solicitud por correo** para abrirla en su programa de correo.

## Qué configura el administrador de Workday

<Steps>

1. **Cree diez informes personalizados (RaaS)**, cuatro de ellos opcionales, y compártalos con el usuario del sistema de integración. Use los nombres de columna exactamente: Data Foundation asigna por nombre, así que una columna con otro nombre no se puede leer. Cada columna de código es el Reference ID del objeto, no un descriptor como "C100 Acme US". El formato de salida de cada informe es JSON.

2. **Conceda los servicios web de Financial_Management** `Get_Workday_Companies` y `Get_Currency_Conversion_Rates` al mismo usuario.

3. **Envíe las URL de los informes** y los datos del usuario del sistema de integración.

</Steps>

| Informe | Obligatorio | Contenido |
|---|---|---|
| Journal Lines | Sí | Una fila por cada línea de diario contabilizada. Solicitudes: Company (la empresa de la línea, como Reference ID) y Period (el Reference ID del período fiscal). Incluye las worktags Region, Fund, Program y Project, la afiliada intercompañía, los importes en la moneda de la transacción y del libro, y el libro contable |
| Beginning Balances | Sí | Una fila por cada empresa, período fiscal y cuenta del libro mayor: el saldo al inicio del período. Solo se cargan las cuentas de Asset, Liability y Equity |
| Ledger Accounts | Sí | Cuenta, nombre, tipo, indicador intercompañía, categoría opcional y cuenta padre |
| Cost Centers | Sí | Centro de costos, nombre y padre |
| Fiscal Periods | Sí | Una fila por cada empresa y período fiscal, también los períodos de ajuste, con inicio, fin y estado |
| Headcount | Opcional | Trabajadores activos al cierre de cada período, por centro de costos, con FTE |
| Worktag Values | Opcional | Una fila por cada valor de Region, Fund, Program y Project, con su padre |
| Customers | Opcional | Cliente, nombre, padre, categoría, región y país |
| Sales Items | Opcional | Artículo, nombre, padre, grupo y unidad de medida |
| Sales Invoice Lines | Opcional | Una fila por cada línea de factura de cliente, con cantidad e importes bruto, de descuento, neto y de costo |

La lista completa de columnas de cada informe está en la especificación de la pestaña Foundation. Se aplican algunas reglas a lo que devuelven los informes:

- Solo se cargan las líneas de diario Posted, y solo el libro Actuals. Los libros Commitment y Obligation no se cargan.
- Un Book_Code en blanco es el libro principal. Una línea en blanco cuenta en todos los libros de su empresa y período, y una línea con un Book_Code pertenece únicamente a ese libro.
- La empresa de la línea prevalece sobre la del diario.
- Ledger_Account_Type_ID es Revenue, COGS, Opex, NonOperating, Asset, Liability o Equity. Workday tiene un solo tipo Expense, que se carga como Opex. Para separar el costo de los productos vendidos o el gasto no operativo, imprima un campo calculado que devuelva COGS o NonOperating. Una cuenta sin tipo no se carga en las pérdidas y ganancias.
- Las facturas en estado Draft, In Progress, Canceled y Denied no se cargan.
- Los presupuestos se cargan desde archivos. Adaptive Planning no está conectado.

## Qué debe enviar de vuelta

| El administrador envía | Se introduce en PlaidCloud como |
|---|---|
| El host de Workday | **Host de Workday** |
| El nombre del inquilino | **Inquilino** |
| El nombre del usuario del sistema de integración | **Usuario del sistema de integración** |
| La URL de cada informe obligatorio | **Journal Lines report URL**, **Beginning Balances report URL**, **Ledger Accounts report URL**, **Cost Centers report URL**, **Fiscal Periods report URL** |
| La URL de cada informe opcional que haya creado | **Headcount report URL (optional)**, **Worktag Values report URL (optional)**, **Customers report URL (optional)**, **Sales Items report URL (optional)**, **Sales Invoice Lines report URL (optional)** |
| Los Reference ID de las empresas que PlaidCloud puede leer | Se eligen en **Companies**. Déjelo en blanco para cargar todas las empresas |

El usuario de PlaidCloud pega por sí mismo la **Contraseña** del usuario del sistema de integración; es un secreto y nunca se envía por correo electrónico.

En **Configuración del sistema**, **Retained earnings account** indica la cuenta de patrimonio en la que se consolidan las pérdidas y ganancias iniciales, cuando los nombres de las cuentas no lo indican ya. Es opcional.

<Aside type="note">
El único tipo Expense de Workday se carga como Opex, y la comprobación de preparación de Data Foundation lo señala. Si necesita distinguir sus cuentas de costo de los productos vendidos o no operativas, use el campo calculado descrito anteriormente.
</Aside>

## Comprobar el acceso

De vuelta en PlaidCloud, haga clic en **Probar conexión**. Cada conjunto de datos se muestra como **Legible**, **Falta un permiso** o **Error**:

| Conjunto de datos | Procede de |
|---|---|
| Entidades | `Get_Workday_Companies` |
| Plan de cuentas | El informe Ledger Accounts |
| Departamentos | El informe Cost Centers |
| Calendario fiscal | El informe Fiscal Periods |
| Tipos de cambio | `Get_Currency_Conversion_Rates` |
| Balance de comprobación | El informe Beginning Balances |
| Libro mayor | El informe Journal Lines |
| Inductores de asignación (opcional) | El informe Headcount |
| Valores de segmento (opcional) | El informe Worktag Values |
| Clientes (opcional) | El informe Customers |
| Productos (opcional) | El informe Sales Items |
| Líneas de ventas (opcional) | El informe Sales Invoice Lines |

Cuando un conjunto de datos muestra **Falta un permiso**, la prueba indica el informe o servicio web. Pida al administrador que lo comparta con el usuario del sistema de integración y vuelva a probar. Un inquilino sin los informes opcionales carga igualmente todo lo demás.
