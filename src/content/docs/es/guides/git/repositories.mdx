Un repositorio contiene los archivos, las ramas y el historial de un proyecto. Esta guía explica cómo crear un repositorio y conectarse a él desde su equipo.

## Crear un repositorio

1. Abra **Git** desde su espacio de trabajo.
2. Seleccione el menú **+** en la esquina superior derecha y luego **New Repository**.
3. Escriba un nombre y, opcionalmente, una descripción breve.
4. Elija la visibilidad. Los repositorios nuevos son **Privado** de forma predeterminada: solo pueden verlos los miembros a quienes usted conceda acceso.
5. Opcionalmente, seleccione **Initialize Repository** para agregar un README, un archivo `.gitignore` y una licencia.
6. Seleccione **Create Repository**.

Los colaboradores no pueden crear repositorios directamente en la organización de Git del espacio de trabajo; los repositorios se crean a través de PlaidCloud.

## Generar un token de acceso personal

Como inicia sesión a través de PlaidCloud, su cuenta no tiene una contraseña de Git aparte. Para clonar o enviar cambios por HTTPS desde la línea de comandos, cree un token de acceso personal y úselo en lugar de una contraseña.

1. Seleccione su avatar en la esquina superior derecha y luego **Configuración**. La tarjeta de configuración de la pestaña **Git** también enlaza directamente a esta página.
2. Abra la pestaña **Aplicaciones**.
3. En **Administrar tokens de acceso**, escriba un nombre que describa dónde usará el token (por ejemplo, `laptop`).
4. Seleccione el permiso **write:repository** para que el token pueda clonar y enviar cambios.
5. Seleccione **Generate Token**.
6. Copie el token y guárdelo en un lugar seguro. No podrá volver a verlo.

<Aside type="caution">Trate el token como una contraseña: cualquiera que lo tenga puede actuar como usted en Git. Genere un token distinto para cada equipo para poder revocar uno sin afectar a los demás.</Aside>

## Clonar un repositorio

1. Abra **Git** en su espacio de trabajo y seleccione el botón de copiar junto a la dirección de clonación del repositorio (seleccione **How to clone** para ver los pasos de configuración). También puede seleccionar **Código** en el repositorio y copiar la URL **HTTPS**.
2. En una terminal, ejecute `git clone` con esa URL:

   ```bash
   git clone <clone URL>
   ```

3. Cuando Git solicite una contraseña, pegue el **token de acceso**. Use el nombre de usuario que ya figura en la URL.
4. Establezca el nombre y el correo electrónico que Git registra en sus confirmaciones, con los valores que muestra la tarjeta de configuración:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Necesita acceso de Colaborador o Administrador para enviar cambios; como Visualizador puede leer, pero no enviar. Consulte [Niveles de acceso](/es/guides/git/#niveles-de-acceso).

<Aside>Para no tener que volver a escribir el token en cada envío, puede dejar que el asistente de credenciales de Git de su sistema operativo lo almacene, por ejemplo con `git config --global credential.helper osxkeychain` en macOS.</Aside>

## Confirmar y enviar cambios

Desde dentro de un repositorio clonado:

1. Prepare sus cambios: `git add .`
2. Regístrelos con un mensaje: `git commit -m "Describe what changed"`
3. Envíelos a PlaidCloud Git: `git push`

Sus confirmaciones aparecen en las vistas **Commits** y **Actividad** del repositorio, y en cualquier rama o solicitud de incorporación de cambios que las incluya.

## Administrar el acceso y la visibilidad

Abra la pestaña **Configuración** de un repositorio para cambiarle el nombre, modificar su visibilidad o transferir su propiedad. Para que otros miembros puedan contribuir, use **Configuración → Collaborators** y agréguelos por nombre de usuario con el rol **Leer**, **Escribir** o **Administrador**.

<Aside>El acceso a los repositorios también sigue su pertenencia al espacio de trabajo y sus grupos de seguridad. Consulte [Administración de acceso](/es/administration/access/) para saber cómo se relacionan con quién puede ver y editar un repositorio.</Aside>
