Un repositorio contiene los archivos, las ramas y el historial de un proyecto. Esta guía explica cómo crear un repositorio y conectarse a él desde su computadora.

## Crear un repositorio

1. Abra **Git** desde su espacio de trabajo.
2. Seleccione el menú **+** en la esquina superior derecha y luego **New Repository**.
3. Escriba un nombre y, opcionalmente, una descripción breve.
4. Elija la visibilidad. Los repositorios nuevos son **Privado** de forma predeterminada: solo pueden verlos los miembros a quienes usted otorgue acceso.
5. Opcionalmente, seleccione **Initialize Repository** para agregar un README, un `.gitignore` y una licencia.
6. Seleccione **Create Repository**.

## Generar un token de acceso personal

Como inicia sesión a través de PlaidCloud, su cuenta no tiene una contraseña de Git aparte. Para clonar o enviar por HTTPS desde la línea de comandos, cree un token de acceso personal y utilícelo en lugar de una contraseña.

1. Seleccione su avatar en la esquina superior derecha y luego **Configuración**.
2. Abra la pestaña **Aplicaciones**.
3. En **Manage Access Tokens**, escriba un nombre que describa dónde usará el token (por ejemplo, `laptop`).
4. Seleccione los ámbitos de **lectura** y **escritura** del repositorio para que el token pueda clonar y enviar.
5. Seleccione **Generate Token**.
6. Copie el token y guárdelo en un lugar seguro. No podrá volver a verlo.

<Aside type="caution">Trate el token como una contraseña: cualquiera que lo tenga puede actuar como usted en Git. Genere un token distinto por equipo para poder revocar uno sin afectar a los demás.</Aside>

## Clonar un repositorio

1. Abra el repositorio en PlaidCloud Git.
2. Seleccione **Código** y luego copie la URL de clonación **HTTPS**.
3. En una terminal, ejecute `git clone` con esa URL:

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. Cuando Git solicite credenciales, escriba su **nombre de usuario de PlaidCloud** y pegue el **token de acceso** como contraseña.

<Aside>Para evitar volver a escribir el token en cada envío, deje que el asistente de credenciales de Git de su sistema operativo lo almacene: ejecute `git config --global credential.helper store` (o `osxkeychain` en macOS) antes de su primer envío.</Aside>

## Confirmar y enviar cambios

Desde dentro de un repositorio clonado:

1. Prepare sus cambios: `git add .`
2. Regístrelos con un mensaje: `git commit -m "Describe what changed"`
3. Envíelos a PlaidCloud Git: `git push`

Sus commits aparecen en las vistas **Commits** y **Actividad** del repositorio, y en cualquier rama o solicitud de incorporación de cambios que los incluya.

## Administrar el acceso y la visibilidad

Abra la pestaña **Configuración** de un repositorio para cambiarle el nombre, modificar su visibilidad o transferir su propiedad. Para que otros miembros puedan contribuir, use **Configuración → Collaborators** y agréguelos por nombre de usuario con un rol de **Leer**, **Escribir** o **Administrador**.

<Aside>El acceso a un repositorio también sigue la pertenencia a su espacio de trabajo y sus grupos de seguridad. Consulte [Administración de acceso](/es/administration/access/) para ver cómo se relacionan con quién puede ver y editar un repositorio.</Aside>
