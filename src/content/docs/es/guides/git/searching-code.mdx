PlaidCloud Git le permite buscar código, archivos, incidencias y solicitudes de incorporación de cambios en todos los repositorios a los que le da acceso su pertenencia al espacio de trabajo.

## Buscar código

1. Seleccione el cuadro de búsqueda en la parte superior de cualquier página y escriba su consulta.
2. Presione **Enter** para ver los resultados de todos los repositorios a los que tiene acceso.
3. Seleccione un resultado para ir directamente al archivo en la línea coincidente.
4. Acote los resultados con los filtros **Repositorio** e **Idioma** de la página de resultados.

<Aside>La búsqueda de código indexa la rama predeterminada. Para buscar en otra rama, vaya a esa rama y use la búsqueda dentro del repositorio que se describe a continuación.</Aside>

## Buscar dentro de un repositorio

1. Abra un repositorio y seleccione la pestaña **Código**.
2. Presione **T** (o seleccione el cuadro del buscador de archivos) para abrir el buscador de archivos.
3. Escriba parte de un nombre de archivo o de una ruta: la lista se filtra a medida que escribe.
4. Seleccione un archivo para abrirlo y luego use la búsqueda en la página de su navegador (**⌘F** / **Ctrl+F**) para localizar una línea específica.

<Aside type="tip">El buscador de archivos coincide con segmentos de ruta, por lo que al escribir `util/auth` aparecen `src/util/auth.py`, `lib/util/auth_helper.go` y rutas similares.</Aside>

## Filtrar incidencias y solicitudes de incorporación de cambios

En la lista **Issues** o **Pull Requests**, combine la búsqueda por palabras clave con filtros `key:value`:

| Filtro | Ejemplo |
|---|---|
| Estado abierto o cerrado | `is:open`, `is:closed` |
| Etiqueta | `label:bug`, `label:"needs review"` |
| Responsable | `assignee:you` |
| Autor | `author:you` |
| Hito | `milestone:"v1.2"` |

Escriba los filtros directamente en el cuadro de búsqueda, combínelos libremente y use el menú **Ordenar** para ordenar por **Actualización reciente**, **Más comentados**, **Más reciente** o **El más antiguo**.

<Aside>Escriba entre comillas el nombre de una etiqueta cuando contenga espacios: `label:"needs review"`.</Aside>

## Consejos para encontrar las cosas más rápido

- **Frases exactas** — escriba entre comillas los términos de varias palabras (`"connection pool"`) para evitar coincidencias parciales ruidosas.
- **Limite la búsqueda a un repositorio** — abra el repositorio antes de buscar para que los resultados se mantengan enfocados.
- **Los nombres descriptivos valen la pena** — los repositorios y las incidencias con nombres claros y específicos aparecen en la búsqueda con mucha más fiabilidad que los genéricos como `misc`.
- **Las etiquetas son metadatos que se pueden buscar** — una incidencia bien etiquetada es más fácil de filtrar que una enterrada en prosa, así que aplique las etiquetas de manera uniforme.
