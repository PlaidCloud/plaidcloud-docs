Las dimensiones son las jerarquías de PlaidCloud: los árboles que se usan para organizar centros de costo, productos, cuentas, geografía, períodos de tiempo o cualquier otra estructura consolidada. Son la base sobre la que se construyen las asignaciones, los paneles de control y los informes.

## Cuándo usar una dimensión

Recurra a una dimensión cuando necesite:

- Consolidar valores desde las hojas hasta los elementos padre (sumar el costo por departamento, luego por región y luego por empresa)
- Asignar de un conjunto de filas a otro según una jerarquía compartida (distribuir el costo de TI entre las unidades de negocio)
- Segmentar un panel de control por una estructura más profunda que una lista plana (profundizar de continente → país → ciudad)
- Aplicar la misma lógica de agrupación en varios lugares: defina el árbol una vez y haga referencia a él en todas partes

Si sus datos ya son planos y unidimensionales, no necesita una dimensión. Una tabla normal es suficiente.

## Cómo se estructuran las dimensiones

Toda dimensión tiene una **jerarquía principal**: el árbol canónico donde cada hoja se registra exactamente una vez. Sobre ella puede superponer **jerarquías alternativas** que vuelven a consolidar las mismas hojas bajo elementos padre diferentes (por ejemplo, el árbol principal agrupa los centros de costo por departamento y uno alternativo los agrupa por región).

Cada nodo del árbol puede tener propiedades, alias y valores, de modo que una jerarquía es más que un árbol de nombres: es una estructura con metadatos a los que las asignaciones y los informes pueden hacer referencia.

Para conocer los detalles de cómo crear, copiar, ordenar y administrar dimensiones, consulte [Uso de dimensiones (jerarquías)](/es/guides/dimensions/dimensions/).

## Cómo se cargan las dimensiones

Las dimensiones suelen rellenarse desde una tabla de origen mediante un flujo de trabajo:

- **Formato elemento padre-elemento hijo**: dos columnas (elemento padre, elemento hijo), una arista por fila
- **Formato de niveles**: una columna por nivel de la jerarquía, una ruta completa por fila

Consulte [Carga y descarga de dimensiones](/es/guides/dimensions/loading-unloading/) para conocer el proceso de carga, y el paso de flujo de trabajo [Dimension Load](/es/reference/workflow-steps/dimensions/dimension-load/) para ver el conjunto completo de opciones.
