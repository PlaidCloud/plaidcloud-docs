## Descripción

Cuando pulsa **Guardar** en un paso, PlaidCloud comprueba su configuración y rechaza
todo lo que no puede ejecutar, como una expresión que no se compila o una columna usada
de una manera que su tipo no permite. Mientras edita un paso, Weave ejecuta ahora la mayoría de
esas comprobaciones sobre la marcha y muestra lo que Guardar rechazaría en una franja justo encima
de los botones **Guardar**:

> 1 problema que Guardar rechazará.

Cada problema se enumera bajo esa línea. Cuando nombra una fila de la pestaña **Columnas**, **Ir a** abre esa pestaña con la fila seleccionada.

Las comprobaciones leen solo la configuración del paso y las variables de su proyecto, por lo que
son rápidas y no interviene ninguna IA. Nunca bloquean el guardado: Guardar sigue
disponible y ejecuta él mismo todas las comprobaciones cuando lo pulsa.

<Aside type="note">
Guardar también comprueba algunas cosas que esta franja no comprueba, como si las tablas
de origen y de destino tienen las columnas que usa el paso y si los campos obligatorios
están completos. Por lo tanto, “No se encontraron problemas” significa que ninguna de las comprobaciones que se ejecutan mientras
edita encontró alguno, no que Guardar vaya a aceptar el paso.
</Aside>

## Qué dice la franja

| Weave dice | Qué significa |
| --- | --- |
| Comprobando si este paso tiene problemas… | Weave está ejecutando las comprobaciones sobre su último cambio. |
| 1 problema que Guardar rechazará. | Guardar rechazaría el paso tal como está. Cada problema se enumera debajo. |
| No se encontraron problemas. Guardar comprueba algunas cosas más, como las tablas de origen y de destino. | Las comprobaciones que se ejecutan mientras edita no encontraron nada. Guardar sigue ejecutando sus propias comprobaciones, incluidas algunas que esta franja omite. |
| Weave no pudo verificar las expresiones de este paso. … | No se pudo comprobar una parte del paso; a continuación se indica el motivo. Esto nunca es una aprobación. |
| Weave no pudo verificar esto en este momento. Guardar sí lo comprueba. | La comprobación no se ejecutó, por ejemplo porque el servidor estaba ocupado. Su siguiente cambio vuelve a solicitarla. |

### Por qué no se pudieron comprobar las expresiones

| Motivo | Qué significa |
| --- | --- |
| Este paso no está en un flujo de trabajo, por lo que sus expresiones no se pueden comprobar. Guardar tampoco las comprueba. | Las expresiones pueden usar variables del flujo de trabajo, por lo que se comprueban en el flujo de trabajo del paso. Un paso que abrió fuera de cualquier flujo de trabajo no se comprueba, ni aquí ni con Guardar. |
| Algunas de sus expresiones están en configuraciones que Weave aún no puede comprobar. | El paso guarda algunas expresiones en configuraciones que estas comprobaciones no leen, como el filtro de un segundo origen. Las demás se siguen comprobando. |
| La configuración de sus columnas es una que Weave aún no puede comprobar. | El paso enumera sus columnas de una manera que la comprobación no puede compilar, como lo hace una Combinación de varias tablas. |

Una expresión que usa una variable que no está definida ni en el flujo de trabajo ni en el proyecto
es un problema, no un motivo: “Una expresión usa la variable rate, que no está
definida en este flujo de trabajo ni en el proyecto”. También lo es una llave que no inicia ni termina
ningún nombre de variable, como ocurre con una variable a medio escribir: “Una expresión tiene una llave que
no forma parte de un nombre de variable”. Guardar rechaza ambos casos con las mismas frases.

## En el editor de expresiones

Abra el **Editor de expresiones** desde una celda **Expresión** de la pestaña **Columnas**, o desde **Seleccionar subconjunto de datos** o **Aplicar filtro secundario a los datos de resultado** en la pestaña **Filtros**, y una línea bajo el editor comprueba
la expresión a medida que escribe:

| El editor dice | Qué significa |
| --- | --- |
| Comprobando… | Weave está comprobando lo que acaba de escribir. |
| No se encontraron errores. | La expresión se compila de la misma manera que la compila Guardar. Señale la línea para leer lo que esto deja fuera: Weave comprueba la sintaxis y los nombres de las columnas; algunos errores solo aparecen cuando se ejecuta el paso. |
| Error: … | Guardar rechazaría la expresión, por el motivo indicado. Un error de sintaxis también se marca en su línea, junto al número de línea. |
| No se pudo verificar. … | No se pudo comprobar la expresión, por uno de los motivos anteriores. |
| No se pudo verificar en este momento. Al guardar el paso se comprueba de todos modos. | La comprobación no se ejecutó. Al pulsar **Guardar** en el paso, la expresión se sigue comprobando. |

El editor comprueba según la configuración del paso tal como estaba cuando Weave comprobó el paso por última vez,
con su expresión incluida. Si se abre desde cualquier otro lugar,
como el Explorador de tablas, no muestra ninguna línea.

## Cuándo aparece

- Mientras edita un paso que puede cambiar. Un paso que se abre en modo de solo lectura para su
  rol no se comprueba mientras lo edita.
- Después de cada cambio, cuando hace una pausa. Un cambio que deja la configuración
  como estaba no se vuelve a comprobar.
- Lee la configuración del paso y las variables del proyecto, por lo que nunca cuesta
  una llamada a la IA y nunca consulta su almacén de datos.
