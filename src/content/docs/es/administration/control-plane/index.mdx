El plano de control de PlaidCloud está dirigido a los administradores de socios y de clientes que administran organizaciones y espacios de trabajo. Utilícelo para crear espacios de trabajo, asignar la propiedad de los espacios de trabajo, elegir el comportamiento de las versiones, habilitar servicios del espacio de trabajo, configurar la imagen de marca y administrar el acceso a nivel de organización.

<Aside type="note">
	El área PlaidAdmin es para el personal de operaciones de PlaidCloud. Esta guía cubre únicamente las áreas de administración de socios y de clientes.
</Aside>

## Navegación

Después de iniciar sesión, utilice la navegación de la izquierda:

1. Abra **Organizations** para ver o editar las organizaciones que administra.
2. Abra **Trust Center** para descargar los documentos de seguridad de PlaidCloud de una organización que administra.
3. Abra **Espacios de trabajo** para ver, crear, editar, pausar, reanudar o actualizar en bloque los espacios de trabajo que puede administrar.
4. Utilice el menú de su perfil para actualizar el perfil de su cuenta o cerrar sesión.

Las acciones que ve dependen de sus roles en la organización. Por ejemplo, un usuario con acceso a espacios de trabajo puede administrar los espacios de trabajo de una organización, mientras que un usuario con acceso de seguridad puede administrar invitaciones y roles.

## Roles

El acceso a la organización se controla mediante estos roles:

| Rol | Qué permite |
| --- | --- |
| Administrador | Editar la configuración de la organización y administrar la administración a nivel de organización. |
| Espacio de trabajo | Crear, editar, pausar, reanudar, eliminar y versionar espacios de trabajo en la organización. |
| Seguridad | Invitar usuarios, quitar usuarios y editar los roles de la organización. |
| Facturación | Ver la información de facturación cuando el acceso a la facturación está habilitado. |

Los roles se asignan desde el cuadro de diálogo de acceso a la organización. Una invitación pendiente se activa cuando la persona invitada la acepta.
