## Cambios

- **La documentación interactiva de la API ahora reside en cada inquilino**: Swagger UI, que antes se servía desde una ruta central de la documentación, ahora está integrado en la instancia de cada inquilino. Acceda a él desde su espacio de trabajo en lugar de usar una URL independiente.
- **PlaidLink actualizado**: se distribuyó una nueva compilación de PlaidLink; las instalaciones existentes siguen funcionando, así que actualice cuando le resulte conveniente.

## Novedades

- **Base para la compatibilidad con agentes de codificación de IA**: este mes se incorporó la conexión inicial de ingreso para las rutas `/mcp` y `/.well-known/oauth-*`, que habilita las integraciones de MCP que pasaron a estar disponibles para los usuarios en mayo.
- **Pruebas de StarRocks 4.1 (Lakehouse v2)**: el motor de Lakehouse de próxima generación se está validando con cargas de trabajo reales. Aún no hay cambios visibles para los clientes; las migraciones voluntarias llegarán más adelante.
