El [modo agente](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) de GitHub Copilot en VSCode admite servidores MCP mediante un `.vscode/mcp.json` de ámbito de espacio de trabajo o de usuario (espacio de trabajo) o el `mcp.json` global de VSCode (usuario).

<Aside type="note">¿Busca **Microsoft 365 Copilot** (el asistente de Teams y de la aplicación de Microsoft 365) en lugar de GitHub Copilot en su IDE? Consulte [Microsoft 365 Copilot](/es/integrations/microsoft-365-copilot/).</Aside>

También puede llegar a estos pasos desde la propia ventana **Conecte su IA** de PlaidCloud: encontrará GitHub Copilot en la pestaña **Otros**, junto con Gemini CLI y Codex CLI.

<Aside>La compatibilidad de Copilot con MCP depende del nivel del plan de Copilot y del ajuste `chat.mcp.enabled` de VSCode. Asegúrese de que ambos estén habilitados antes de configurar servidores.</Aside>

## Configuración

1. Obtenga un token de portador visitando `https://<your-workspace>.plaid.cloud/mcp/setup/token` en un navegador donde haya iniciado sesión en PlaidCloud.

2. En VSCode, abra la paleta de comandos y ejecute **MCP: Add Server**, o cree `.vscode/mcp.json` directamente:

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Vuelva a cargar VSCode. Abra el panel de chat de Copilot, cambie la lista desplegable de modo a **Agent** y confirme que las herramientas de PlaidCloud aparecen en la lista de herramientas (normalmente mostradas como `plaidcloud_*`).

## Uso

Pida a Copilot que realice operaciones de PlaidCloud directamente:

- “Encuentra todos los flujos de trabajo del proyecto `Q4 Forecast` cuya última ejecución falló.”
- “Muéstrame el esquema de la tabla `customers` y sugiere índices.”
- “Ejecuta el flujo de trabajo `daily-load` e informa del estado de la ejecución.”

Copilot elige la herramienta adecuada, la ejecuta y cita los resultados en su respuesta. En las operaciones destructivas (eliminar, organizar, upsert sin `dry_run`), normalmente pedirá confirmación: revise la acción prevista antes de aprobar.

## Actualización del token

VSCode lee `.vscode/mcp.json` al iniciarse y cuando el archivo cambia. Cuando el token caduque, vuelva a cargar `https://<your-workspace>.plaid.cloud/mcp/setup/token` y sobrescriba el valor de `Authorization`; VSCode recarga el servidor automáticamente.

## Restricción a herramientas específicas

Si desea limitar qué herramientas de PlaidCloud puede llamar Copilot, use la lista de herramientas permitidas por servidor de VSCode (Settings → Copilot → MCP → selección de herramientas específica del servidor). Esto resulta útil para sesiones de solo lectura o para mantener las herramientas que modifican datos (`*_upsert`, `*_run`) tras una reactivación explícita.
