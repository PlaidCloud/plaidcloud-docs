El [modo agente](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) de GitHub Copilot en VSCode admite servidores MCP mediante un `.vscode/mcp.json` del espacio de trabajo o del usuario (espacio de trabajo), o el `mcp.json` global de VSCode (usuario).

<Aside type="note">¿Busca **Microsoft 365 Copilot**, el asistente de Teams y de la aplicación Microsoft 365, en lugar de GitHub Copilot en su IDE? Consulte [Microsoft 365 Copilot](/es/integrations/microsoft-365-copilot/).</Aside>

También puede llegar a estos pasos desde la propia ventana **Conecte su IA** de PlaidCloud (en el menú del avatar); encuentre GitHub Copilot en la pestaña **Otros**, junto a Gemini CLI y Codex CLI.

<Aside>La compatibilidad de Copilot con MCP depende del nivel del plan de Copilot y del ajuste `chat.mcp.enabled` de VSCode. Asegúrese de que ambos estén habilitados antes de configurar los servidores.</Aside>

## Configuración

1. Obtenga un token de portador visitando `https://<your-workspace>.plaid.cloud/mcp/setup/token` en un navegador donde haya iniciado sesión en PlaidCloud.

2. En VSCode, abra la paleta de comandos y ejecute **MCP: Add Server**, o cree `.vscode/mcp.json` directamente:

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Vuelva a cargar VSCode. Abra el panel de chat de Copilot, cambie el menú desplegable de modo a **Agente** y confirme que las herramientas de PlaidCloud aparecen en la lista de herramientas (normalmente se muestran como `plaidcloud_*`).

## Uso

Pida a Copilot que realice operaciones de PlaidCloud directamente:

- "Find all workflows in project `Q4 Forecast` whose last run failed."
- "Show me the schema of table `customers` and suggest indexes."
- "Run the `daily-load` workflow and report the run status."

Copilot elige la herramienta adecuada, la ejecuta y cita los resultados en su respuesta. En las operaciones destructivas (eliminar, organizar, upsert sin `dry_run`), normalmente le pedirá confirmación; revise la acción planificada antes de aprobarla.

## Actualización del token

VSCode lee `.vscode/mcp.json` al iniciarse y cuando el archivo cambia. Cuando el token caduque, vuelva a cargar `https://<your-workspace>.plaid.cloud/mcp/setup/token` y sobrescriba el valor de `Authorization`; VSCode vuelve a cargar el servidor automáticamente.

## Restricción a herramientas específicas

Si desea limitar qué herramientas de PlaidCloud puede llamar Copilot, use la lista de herramientas permitidas por servidor de VSCode (Settings → Copilot → MCP → selección de herramientas específica del servidor). Esto resulta útil para sesiones de solo lectura o para mantener las herramientas que modifican datos (`*_upsert`, `*_run`) protegidas hasta que se vuelvan a habilitar de forma explícita.
