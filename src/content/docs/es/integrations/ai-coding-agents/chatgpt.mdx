La compatibilidad de ChatGPT con servidores MCP agregados por el usuario todavía se está desplegando y varía según el nivel del plan y la superficie. Esta página describe lo que funciona hoy.

## ChatGPT Pro / Plus / Team: conectores

Si su plan de ChatGPT muestra la interfaz de **Connectors** (Settings → Connectors), puede agregar PlaidCloud como un conector MCP personalizado:

1. Vaya a **Settings → Connectors → Add custom connector**.
2. Introduzca:
   - **Nombre**: `PlaidCloud`
   - **URL del servidor MCP**: `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT le redirigirá a PlaidCloud para iniciar sesión mediante OAuth. Después de iniciar sesión, PlaidCloud muestra una página de **Application Access Request** que indica la aplicación solicitante y el URI de redirección al que enviará las credenciales; compruebe que coinciden con ChatGPT antes de aprobar.
4. Active el conector en cualquier conversación que deba poder usarlo.

<Aside>Es posible que la interfaz de Connectors no sea visible en todas las cuentas ni en todas las regiones. Si no ve “Add custom connector”, su plan o la política de su espacio de trabajo no permite actualmente servidores MCP agregados por el usuario; use la alternativa que se describe a continuación.</Aside>

## ChatGPT Enterprise

Los administradores de Enterprise pueden fijar conectores MCP en el nivel del espacio de trabajo mediante la consola de administración. Siga la misma configuración de OAuth descrita arriba, pero espere un paso de aprobación del espacio de trabajo por parte de su administrador antes de que el conector pueda usarse.

## Alternativa: GPT personalizados con acciones REST

Si su cuenta no admite conectores MCP personalizados, aún puede manejar PlaidCloud desde ChatGPT mediante un **GPT personalizado** que llame a la API REST de PlaidCloud como una acción de OpenAPI:

1. La superficie REST de PlaidCloud se describe en el documento OpenAPI en `https://<your-tenant>.plaidcloud.org/openapi_rest.json`.
2. En ChatGPT, cree un GPT personalizado (Explore GPTs → Create) y, en **Actions**, importe esa URL (o pegue el JSON).
3. Configure la autenticación como **OAuth** y apunte a los puntos de conexión de Keycloak de PlaidCloud. Su administrador de PlaidCloud puede facilitarle las URL del realm y el ID de cliente.

Esto cambia las convenciones de nombres de herramientas de MCP por puntos de conexión REST directos: algo más extenso para que el modelo navegue, pero funcionalmente equivalente para las operaciones de lectura y escritura que expone PlaidCloud.

## Por qué MCP no siempre está disponible

La compatibilidad de OpenAI con MCP sigue evolucionando y las superficies disponibles (interfaz de Connectors, esquema de Actions, etc.) cambian entre niveles de plan y con el tiempo. Si la ruta oficial de **Connectors** está abierta en su cuenta, prefiérala: tiene actualización de OAuth integrada y una experiencia de llamadas a herramientas acorde con el resto de esta sección. Recurrir a las acciones de GPT personalizados solo es necesario cuando MCP aún no está disponible para su cuenta.
