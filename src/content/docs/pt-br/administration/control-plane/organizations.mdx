Uma organização é o limite administrativo de espaços de trabalho relacionados do PlaidCloud. As configurações da organização controlam o nome exibido no plano de controle, os metadados de faturamento, o comportamento de SSO e quem pode administrar a organização.

## Lista de organizações

A página **Organizações** mostra as organizações às quais você tem acesso. Na tabela, você pode:

1. Pesquisar organizações pelos campos visíveis da tabela.
2. Atualizar a lista de organizações.
3. Ver os detalhes da organização.
4. Editar as configurações da organização quando você tem acesso de administrador.
5. Abrir o gerenciamento de acesso da organização quando você tem acesso de segurança.
6. Abrir os registros de faturamento quando você tem acesso ao faturamento.

## Configurações da organização

| Configuração | Descrição |
| --- | --- |
| Nome | Nome de exibição da organização. |
| ID | Identificador estável da organização. É definido quando a organização é criada. |
| Memorando | Observação ou descrição interna exibida no plano de controle. |
| Plano | Plano comercial: Enterprise, Team ou Free. |
| ID fiscal | Identificador fiscal usado nos registros de faturamento. |
| Ativa | Indica se a organização está ativa. |
| Bloqueada | Impede alterações normais na organização enquanto estiver ativada. |
| Exigir SSO | Exige que os membros entrem por meio da configuração de logon único da organização. |

## Metadados de faturamento

Os campos de faturamento descrevem como a organização é cobrada. Eles não concedem acesso ao produto por si só.

| Configuração | Opções |
| --- | --- |
| Ciclo de faturamento | Mensal, Trimestral, Semestral, Anual |
| Preço de faturamento | Valor numérico de faturamento para o ciclo selecionado. |
| Tipo de pagamento | Faturado por pedido de compra, Avaliação gratuita, Gratuito, Pagamento agendado |

## Comportamento do SSO

| Configuração | Descrição |
| --- | --- |
| Atribuição dinâmica de grupo | Permite que as informações de grupo do SSO determinem a atribuição de funções da organização. |
| Criação dinâmica de usuário | Permite que o login por SSO crie usuários automaticamente quando o provedor de identidade envia um usuário aceito. |
| Nome de atribuição dinâmica de grupo do SSO | O nome do grupo de SSO usado na atribuição dinâmica. |

<Aside type="note">
	Configure um provedor de identidade para um espaço de trabalho na [caixa de diálogo de logon único](/pt-br/administration/control-plane/workspace-configuration/#logon-único); a configuração do SAML está documentada nos guias de gerenciamento de acesso. Essas configurações do plano de controle determinam como a organização usa a configuração de SSO depois que ela existe.
</Aside>

## Gerenciar acesso

Use **Gerenciar acesso** para convidar pessoas para a organização e atribuir funções da organização.

1. Abra **Organizações**.
2. Selecione a organização.
3. Abra **Gerenciar acesso**.
4. Clique em **Convidar usuário** para convidar um ou mais endereços de e-mail.
5. Selecione as funções que cada pessoa deve receber.
6. Adicione uma mensagem personalizada, se quiser.
7. Envie o convite.

Você pode editar as funções de usuários que já aceitaram, remover usuários que já aceitaram ou cancelar convites pendentes. Usuários pendentes não podem ser editados até aceitarem o convite.

## Funções da organização

| Função | Use para |
| --- | --- |
| Admin | Configurações da organização e alterações em nível de administrador. |
| Espaço de trabalho | Criação, configuração, liberação, pausa e retomada de espaços de trabalho. |
| Segurança | Convites e gerenciamento de funções da organização. |
| Faturamento | Acesso aos registros de faturamento. |
