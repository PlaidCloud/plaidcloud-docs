Cada organização pode ter uma URL personalizada ([https://plaidcloud.com/sso](https://plaidcloud.com)/`<custom_name_here>`) para que os membros acessem a página de logon único que você especificou na configuração.

<Aside>O logon único usa os protocolos SAML 2.0 e é configurado pela interface do usuário.</Aside>

<Aside type="tip">Para permitir que as pessoas de um espaço de trabalho entrem com o Microsoft Entra ID, o Okta ou outro provedor OpenID Connect, use a caixa de diálogo guiada **Single sign-on** (o logon único corporativo está incluído nos planos pagos; senha com MFA e login social estão disponíveis em todos os planos) na página **Workspaces**. Consulte [Logon único](/pt-br/administration/control-plane/workspace-configuration/#logon-único).</Aside>

Para criar uma URL personalizada:

1. Selecione o menu “Organization Settings” no canto superior direito da tela
2. Clique em “Single Sign-On Security Credentials”
3. Ajuste a URL de logon único conforme desejado
4. Clique em “Update Organization SSO Settings”

## Permitir a criação automática de usuários

Se o logon único estiver ativado, você pode optar por criar membros automaticamente com base em uma autenticação de logon único bem-sucedida. Os novos membros receberão o espaço de trabalho padrão e as funções de segurança especificados nas configurações da organização. Para criar membros automaticamente:

1. Selecione o menu “Organization Settings” no canto superior direito da tela
2. Clique em “Organization and User Settings”
3. Marque a caixa “Create Users Automatically from Single Sign-On”
4. Escolha o espaço de trabalho padrão desejado

O uso desse recurso simplifica bastante o gerenciamento de membros, porque os novos membros terão acesso automaticamente, sem nenhuma configuração adicional no PlaidCloud. Da mesma forma, se os membros forem removidos do serviço de logon único, eles deixarão de ter acesso ao PlaidCloud.


## Permitir atribuições de grupos de segurança a partir do logon único

Se o logon único estiver ativado, você pode optar por enviar uma lista de associações a grupos junto com a mensagem de autenticação positiva. Os itens da lista serão usados para atribuir um membro aos grupos especificados e removê-lo de qualquer grupo não especificado. Essa é uma forma eficaz de gerenciar as atribuições de grupos de segurança usando um serviço central de gerenciamento de usuários, como o Active Directory ou outro serviço LDAP.


<Aside>Se um membro estiver marcado como administrador em um espaço de trabalho, ele continuará tendo acesso total a esse espaço de trabalho, independentemente da função específica que lhe for atribuída por esse processo automatizado.</Aside>


Se essa opção estiver ativada, as funções de segurança serão atribuídas com base na lista fornecida na próxima vez que o membro entrar. Se a opção estiver desativada, os membros existentes manterão as funções de segurança atuais até que sejam atualizadas manualmente no PlaidCloud.
