O [modo agente](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) do GitHub Copilot no VSCode oferece suporte a servidores MCP por meio de um `.vscode/mcp.json` no escopo do espaço de trabalho (workspace) ou do usuário, ou do `mcp.json` global do VSCode (usuário).

<Aside type="note">Procurando o **Microsoft 365 Copilot** — o assistente no Teams e no aplicativo Microsoft 365 — em vez do GitHub Copilot na sua IDE? Veja [Microsoft 365 Copilot](/pt-br/integrations/microsoft-365-copilot/).</Aside>

Você também pode chegar a estas etapas pela própria janela **Conecte sua IA** do PlaidCloud — encontre o GitHub Copilot na guia **Outro**, ao lado do Gemini CLI e do Codex CLI.

<Aside>O suporte a MCP do Copilot depende do nível do plano do Copilot e da configuração `chat.mcp.enabled` no VSCode. Certifique-se de que ambos estejam ativados antes de configurar os servidores.</Aside>

## Configuração

1. Obtenha um token de portador acessando `https://<your-workspace>.plaid.cloud/mcp/setup/token` em um navegador em que você esteja conectado ao PlaidCloud.

2. No VSCode, abra a paleta de comandos e execute **MCP: Add Server**, ou crie o `.vscode/mcp.json` diretamente:

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Recarregue o VSCode. Abra o painel de chat do Copilot, mude a lista suspensa de modo para **Agente** e confirme que as ferramentas do PlaidCloud aparecem na lista de ferramentas (normalmente exibidas como `plaidcloud_*`).

## Uso

Peça ao Copilot que execute operações do PlaidCloud diretamente:

- "Encontre todos os fluxos de trabalho do projeto `Q4 Forecast` cuja última execução falhou."
- "Mostre o esquema da tabela `customers` e sugira índices."
- "Executar o fluxo de trabalho `daily-load` e informar o status da execução."

O Copilot escolhe a ferramenta apropriada, a executa e cita os resultados na resposta. Para operações destrutivas (excluir, organizar, fazer upsert sem `dry_run`), ele normalmente pede confirmação — revise a ação planejada antes de aprovar.

## Atualização do token

O VSCode lê o `.vscode/mcp.json` na inicialização e quando o arquivo muda. Quando o token expirar, recarregue `https://<your-workspace>.plaid.cloud/mcp/setup/token` e sobrescreva o valor de `Authorization` — o VSCode recarrega o servidor automaticamente.

## Restrição a ferramentas específicas

Se quiser limitar quais ferramentas do PlaidCloud o Copilot pode chamar, use a lista de permissões de ferramentas por servidor do VSCode (Configurações → Copilot → MCP → seleção de ferramentas específica do servidor). Isso é útil para sessões somente leitura ou para manter as ferramentas que alteram dados (`*_upsert`, `*_run`) protegidas por uma reativação explícita.
