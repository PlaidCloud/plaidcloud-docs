O suporte do ChatGPT a servidores MCP adicionados pelo usuário ainda está sendo liberado gradualmente e varia conforme o nível do plano e a superfície. Esta página descreve o que funciona hoje.

## ChatGPT Pro / Plus / Team — Conectores

Se o seu plano do ChatGPT expõe a interface de **Conectores** (Configurações → Conectores), você pode adicionar o PlaidCloud como um conector MCP personalizado:

1. Acesse **Configurações → Conectores → Adicionar conector personalizado**.
2. Informe:
   - **Nome**: `PlaidCloud`
   - **URL do servidor MCP**: `https://<your-workspace>.plaid.cloud/mcp`
3. O ChatGPT redireciona você ao PlaidCloud para o login OAuth. Depois que você entrar, o PlaidCloud exibe uma página de **Solicitação de acesso do aplicativo** que informa o aplicativo solicitante e o URI de redirecionamento para o qual enviará as credenciais — confira se eles correspondem ao ChatGPT antes de aprovar.
4. Ative o conector em qualquer conversa que deva poder usá-lo.

<Aside>A interface de Conectores pode não estar visível em todas as contas ou regiões. Se você não vir "Adicionar conector personalizado", seu plano ou a política do seu espaço de trabalho não permite, no momento, servidores MCP adicionados pelo usuário — use a alternativa abaixo.</Aside>

## ChatGPT Enterprise

Os administradores do Enterprise podem fixar conectores MCP no nível do espaço de trabalho por meio do console de administração. Siga a mesma configuração de OAuth descrita acima, mas espere uma etapa de aprovação do espaço de trabalho por parte do seu administrador antes que o conector se torne utilizável.

## Alternativa — GPTs personalizados com ações REST

Se a sua conta não oferece suporte a conectores MCP personalizados, você ainda pode controlar o PlaidCloud a partir do ChatGPT por meio de um **GPT personalizado** que chama a API REST do PlaidCloud como uma Ação OpenAPI:

1. A superfície REST do PlaidCloud é descrita pelo documento OpenAPI em `https://<your-tenant>.plaidcloud.org/openapi_rest.json`.
2. No ChatGPT, crie um GPT personalizado (Explorar GPTs → Criar) e, em **Ações**, importe essa URL (ou cole o JSON).
3. Configure a autenticação como **OAuth** e aponte para os endpoints do Keycloak do PlaidCloud. O administrador do seu PlaidCloud pode fornecer as URLs do realm e o ID do cliente.

Isso troca as convenções de nomes de ferramentas do MCP por endpoints REST diretos — um pouco mais verboso para o modelo navegar, mas funcionalmente equivalente para as operações de leitura e gravação que o PlaidCloud expõe.

## Por que o MCP nem sempre está disponível

O suporte da OpenAI ao MCP continua evoluindo, e as superfícies disponíveis (interface de Conectores, esquema de Ações etc.) mudam entre os níveis de plano e ao longo do tempo. Se o caminho oficial de **Conectores** estiver aberto na sua conta, prefira-o — ele tem atualização de OAuth integrada e uma experiência de chamada de ferramentas compatível com o restante desta seção. Recorrer às Ações do GPT personalizado só é necessário quando o MCP ainda não está exposto para a sua conta.
