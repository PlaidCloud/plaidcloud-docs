O aplicativo Claude para o consumidor — tanto a interface web em [claude.ai](https://claude.ai) quanto o aplicativo de desktop — oferece suporte a servidores MCP por meio do recurso de **Conectores personalizados**. A configuração é um processo único de OAuth, depois do qual a conexão fica associada à sua conta do Claude e acompanha você entre dispositivos.

<Aside>Os Conectores personalizados estão disponíveis nos planos Claude Pro, Max, Team e Enterprise. Os administradores dos planos Team e Enterprise podem fixar conectores para todos no espaço de trabalho.</Aside>

## Configuração

1. No Claude (web ou desktop), abra **Configurações → Conectores**.
2. Clique em **Adicionar conector personalizado**.
3. Preencha:
   - **Nome**: `PlaidCloud` (ou `PlaidCloud (prod)`, `PlaidCloud (dev)` se você tiver vários tenants).
   - **URL do servidor**: `https://<your-workspace>.plaid.cloud/mcp`
4. Clique em **Adicionar**. O Claude abre uma guia do navegador para o login do Keycloak do PlaidCloud.
5. Entre e, em seguida, aprove a página de **Solicitação de acesso do aplicativo** que aparece — ela informa o aplicativo solicitante e o URI de redirecionamento para o qual enviará as credenciais, então confira se ambos correspondem ao Claude antes de aprovar. Você será redirecionado de volta ao Claude com a conexão salva.

O conector agora está disponível em qualquer conversa. Ative-o (ou desative-o) usando o seletor de conectores no campo de composição do chat.

## Uso

Depois de ativado, você pode pedir ao Claude coisas como:

- "Liste os fluxos de trabalho do projeto `Q4 Forecast`."
- "Mostre as últimas 10 execuções com falha do fluxo de trabalho `daily-load`."
- "Execute `mcp_recipes` e escolha a receita certa para fazer o backfill de uma etapa."

O Claude escolherá a ferramenta MCP apropriada, a chamará e incorporará a resposta à sua. Para operações que alteram dados, ele normalmente descreve o que está prestes a fazer — revise com atenção antes de aprovar.

## Vários tenants

Adicione um conector separado para cada tenant. Dê a eles nomes distintos para que o Claude consiga diferenciá-los na conversa. Somente os conectores que você ativar em um determinado chat ficam disponíveis — deixar a produção desativada por padrão e só ativá-la quando tiver certeza é um hábito de segurança sensato.

## Atualização do acesso

Os conectores personalizados armazenam um token de atualização do OAuth, então a reautenticação é rara. Se você alterar sua senha do PlaidCloud, usar um novo dispositivo ou se sua sessão for invalidada no servidor, o conector pode mostrar "precisa de autenticação". Clique em **Reconectar** nas configurações de conectores para refazer o fluxo OAuth.

## Desconexão

Configurações → Conectores → clique no conector → **Remover**. Isso exclui os tokens OAuth armazenados com a sua conta do Claude. A sessão do lado do PlaidCloud é independente — saia do PlaidCloud separadamente se quiser invalidar a sessão subjacente do Keycloak.
