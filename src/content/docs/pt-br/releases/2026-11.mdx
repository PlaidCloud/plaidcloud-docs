## Adicionado

- **Os assistentes de IA podem cancelar a publicação de uma tabela e definir o público padrão dos painéis de um projeto.** `publish_manage` cancela a publicação de uma tabela junto com a visão publicada dela e qualquer conjunto de dados de painel que nenhum gráfico use; um conjunto de dados que um gráfico ainda usa permanece, assim como a visão e o conjunto de dados quando uma visão de relatório é construída sobre a visão publicada, e a publicação da tabela é cancelada mesmo assim. `project_upsert` define `dashboard_default_audience`, os grupos com quem os novos painéis do projeto são compartilhados, e `[]` o limpa. Consulte [Cancelar publicação](/pt-br/guides/data/publish/#cancelar-a-publicação-por-meio-do-assistente-de-ia-ou-do-mcp) e [Definir o público padrão pelo assistente de IA ou MCP](/pt-br/guides/dashboards/control-who-can-see-a-dashboard/#definir-o-público-padrão-por-meio-do-assistente-de-ia-ou-do-mcp).

## Alterado

- **Os Arquitetos do projeto veem todas as linhas das tabelas com restrição de linhas nos painéis**, em linha com o que veem no Analyze. Retirar o acesso de Arquiteto tem efeito imediato nos painéis — seja alterando a função de alguém, removendo essa pessoa ou o grupo dela do projeto, alterando o tipo de acesso do projeto, restaurando uma versão anterior do projeto ou excluindo um grupo de segurança. Um ex-Arquiteto deixa de ver todas as linhas dos dados com restrição de linhas. Consulte [Gerenciando o acesso a linhas](/pt-br/administration/access/managing-security-groups-and-assignments/#gerenciando-o-acesso-a-linhas).
- **Um link de painel aberto depois que a sua sessão expirou leva você a esse painel assim que você faz login.** Consulte [Usando painéis](/pt-br/guides/dashboards/using-dashboards/).
- **As ferramentas de MCP recusam um campo que não reconhecem** e o nomeiam no erro, em vez de ignorá-lo. `workflow_upsert` aceita `memo` e aceita `description` como outro nome para ele. Consulte [Campos desconhecidos são recusados](/pt-br/integrations/ai-coding-agents/getting-started/#campos-desconhecidos-são-recusados).

## Corrigido

- **Configurações de projeto inválidas são informadas com uma mensagem clara.** Um ambiente ou uma conta de documentos desconhecidos, um slug já usado ou reservado, ou um tipo de armazenamento ou modo de lançamento inválidos agora retornam uma mensagem que nomeia o problema, em vez de um erro genérico do servidor. Pela API REST, isso é um 400 em vez de um 500, e pelo assistente de IA ou MCP é um erro de argumento inválido.
