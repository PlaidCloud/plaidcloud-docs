## Adicionado

- **Pré-visualização nos formulários de etapa.** Importar: SQL, Executar: SQL, Extrair: SQL, Exportar: SQL e Salesforce Query mostram até 100 linhas sem executar a etapa, e as leituras de visão e de lista do Anaplan mostram as colunas e os tipos que produziriam. Clique em **Pré-visualização** na guia **Origem**. As variáveis são preenchidas como a execução as preencheria, mas formatos de variável como `{x:>9}` não são compatíveis. A pré-visualização executa apenas funções SQL padrão; caso contrário, ela orienta você a executar a etapa. Ela não está disponível em projetos bloqueados nem para a etapa Executar SQL baseada em agente. Consulte [Importar SQL](/pt-br/reference/workflow-steps/import/import-sql/) e [Extrair SQL](/pt-br/reference/workflow-steps/tables/table-extract-sql/).
- **Os assistentes de IA podem cancelar a publicação de uma tabela e definir o público padrão de painéis de um projeto.** `publish_manage` cancela a publicação de uma tabela junto com sua visão publicada e qualquer conjunto de dados de painel que nenhum gráfico use; um conjunto de dados que um gráfico ainda usa permanece, assim como a visão e o conjunto de dados quando uma visão de relatório é criada sobre a visão publicada, enquanto a publicação da tabela é cancelada mesmo assim. `project_upsert` define `dashboard_default_audience`, os grupos com os quais os novos painéis do projeto são compartilhados, e `[]` o limpa. Consulte [Cancelar a publicação](/pt-br/guides/data/publish/#cancelar-a-publicação-por-meio-do-assistente-de-ia-ou-do-mcp) e [Definir o público padrão pelo assistente de IA ou MCP](/pt-br/guides/dashboards/control-who-can-see-a-dashboard/#definir-o-público-padrão-por-meio-do-assistente-de-ia-ou-do-mcp).

- **A voz no Weave no celular exige apenas um toque.** Toque no microfone, faça sua pergunta, e o Weave a envia quando você para de falar. Toque no microfone novamente para parar antes; ele se desliga sozinho se nada for ouvido. Se você sair da guia **Weave** ou enviar o aplicativo para segundo plano no meio da frase, suas palavras permanecem na caixa de pergunta sem serem enviadas, para que você possa revisá-las. Executar, Pausar, Parar e Retomar ignoram um toque duplo acidental na confirmação. Requer a versão 1.3.0 ou posterior do aplicativo. Consulte [Usar a voz](/pt-br/guides/mobile-app/weave-on-mobile/#usar-a-voz).

## Alterado

- **Os formulários de etapa seguem um único layout.** As guias têm nomes padrão em uma ordem padrão: Geral, Configurações, Origem, Colunas, Filtros, Saída e Avançado, com Colunas de cabeçalho e Colunas de linha nos formulários de lançamento em ERP. Os campos obrigatórios são marcados com *, e um formulário só impede o salvamento pelo que a etapa exige.
- **O menu de ações da linha (⋯) fica na borda esquerda de cada linha da grade.**
- **As etapas de gravação em ERP salvas sem a configuração de validação abrem como somente validação.** Isso abrange SAP Post, SAP Attach, NetSuite Post, Oracle EBS GL e AP Post e a exportação para o Xero. As etapas definidas explicitamente para execução real continuam reais.
- **Os trabalhos de longa duração mostram o progresso da mesma forma em todos os lugares.**
- **As etapas REST, Import REST e Import Postman são convertidas em Solicitação REST quando seu espaço de trabalho é atualizado.** Uma etapa que não pode ser convertida de forma limpa permanece como estava. Consulte [Etapa Solicitação REST](/pt-br/guides/workflows/rest-request-step/).
- **Os Arquitetos de projeto veem todas as linhas de tabelas com restrição de linhas nos painéis**, de acordo com o que veem no Analyze. A remoção do acesso de Arquiteto tem efeito imediato nos painéis — seja ao alterar a função de alguém, remover essa pessoa ou o grupo dela do projeto, alterar o tipo de acesso do projeto, restaurar uma versão anterior do projeto ou excluir um grupo de segurança. Um ex-Arquiteto deixa de ver todas as linhas de dados com restrição de linhas. Consulte [Gerenciar o acesso a linhas](/pt-br/administration/access/managing-security-groups-and-assignments/#gerenciando-o-acesso-a-linhas).
- **Um link de painel aberto depois que sua sessão expirou leva você a esse painel assim que você entra.** Consulte [Usar painéis](/pt-br/guides/dashboards/using-dashboards/).
- **As ferramentas MCP recusam um campo que não reconhecem** e o nomeiam no erro, em vez de ignorá-lo. `workflow_upsert` aceita `memo` e aceita `description` como outro nome para ele. Consulte [Campos desconhecidos são recusados](/pt-br/integrations/ai-coding-agents/getting-started/#campos-desconhecidos-são-recusados).

## Corrigido

- **As configurações de projeto inválidas são informadas com uma mensagem clara.** Um ambiente ou uma conta de documentos desconhecidos, um slug já em uso ou reservado, ou um tipo de armazenamento ou modo de lançamento inválidos agora retornam uma mensagem que nomeia o problema, em vez de um erro genérico do servidor. Pela API REST, isso é um 400 em vez de um 500, e pelo assistente de IA ou MCP é um erro de argumento inválido.
- **A solicitação de valores de dimensão da API REST funciona.** `POST /rest/v1/analyze/query/retrieve-dimension-values` era tratada como uma solicitação de grade e recusada como inválida. Agora ela retorna um valor agregado para cada coluna em `value_columns`, e uma grade, com um valor para cada par formado por um filtro de linha e um filtro de coluna, tem sua própria solicitação, `POST /rest/v1/analyze/query/retrieve-dimension-cells`.
- **Leituras lentas de tabelas e o processamento de arquivos não atrasam mais outras solicitações.** Ler as colunas de uma tabela no data warehouse, registrar um arquivo do Data Foundation, exportar para o Excel, ler a resposta de uma importação REST ou SOAP, descobrir onde uma conta de documentos é usada e verificar o código ou o logotipo de um aplicativo Panel eram operações que podiam, cada uma, pausar todas as outras solicitações atendidas pelo mesmo servidor até serem concluídas. Agora elas são executadas em paralelo a essas solicitações.
- **As caixas de diálogo de variáveis de projeto e de fluxo de trabalho rolam.** Em uma tela pequena ou de baixa resolução, a caixa de diálogo de adição e edição ficava mais alta que a janela, de modo que os botões **Criar** e **Atualizar** podiam ficar fora de alcance. Agora o formulário rola e os botões permanecem na parte inferior.

## Segurança

- **Somente os proprietários de uma conta podem restaurar suas versões anteriores.** Restaurar uma conta de documentos para uma versão anterior, reter ou liberar uma versão e fazer um backup agora exigem que você seja um dos proprietários da conta, e nenhuma dessas ações está disponível em uma conta gerenciada pelo sistema. Ver o histórico de versões de uma conta exige acesso à conta.
