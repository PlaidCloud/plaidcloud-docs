## Como estas notas são produzidas

Cada resumo mensal reúne as mudanças relevantes lançadas nos tenants durante aquele mês do calendário. O trabalho puramente de infraestrutura (atualizações de imagens, refatorações internas, cortes de RC, rotação de segredos, ajustes de observabilidade) é agrupado em rótulos de tema, em vez de listado linha a linha. Se um mês teve recursos visíveis para o cliente, eles são destacados explicitamente em uma estrutura Adicionado / Alterado / Corrigido / Segurança.

Para detalhes de uma versão específica, entre em contato com a sua equipe de conta.

Daqui em diante, cada novo resumo mensal será publicado aqui assim que estiver disponível.
