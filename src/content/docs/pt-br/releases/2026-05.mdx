## Adicionado

- **Personal Temp Drive** — todo membro do espaço de trabalho agora recebe um espaço temporário privado, por usuário, com suporte de armazenamento em nuvem gerenciado. Ativado por padrão no nível do chart; nenhuma ação do administrador é necessária para começar a usá-lo.
- **Cadastro self-service via Stripe** — novas contas agora podem se cadastrar diretamente pelo plaidcloud.com, sem contato com vendas. O fluxo de cadastro está integrado ao plano de controle para o provisionamento de tenants.
- **Endpoints de integração com o MCP** — as rotas `/mcp` e `/.well-known/oauth-*` agora direcionam para o servidor RPC do PlaidCloud, permitindo que agentes de codificação com IA (Claude Code, Cursor, Copilot, ChatGPT, Gemini) se conectem por meio do Model Context Protocol. Consulte [Agentes de codificação com IA](/pt-br/integrations/ai-coding-agents/).
- **Ferramentas de migração para o Lakehouse v2** — o serviço migrador que move espaços de trabalho do Lakehouse v1 (Databend) para o Lakehouse v2 (StarRocks) agora está implantado em toda a frota, em preparação para migrações escalonadas de tenants.

## Alterado

- **Interface do aplicativo consolidada no qooxdoo** — `app.<your-domain>` agora serve diretamente o cliente qooxdoo. O cp-frontend legado foi descontinuado; usuários com favoritos apontando para caminhos antigos serão redirecionados de forma transparente.
- **URLs legadas são redirecionadas automaticamente** — visitas a `/signin` e a caminhos legados relacionados agora recebem um 301 para a nova interface `/client/`. Atualize seus favoritos quando for conveniente, mas os links antigos continuam funcionando.
- **Histórico de execuções de fluxos de trabalho** — metadados adicionais do histórico de execuções agora são capturados por tenant, exibindo mais detalhes nos logs dos fluxos de trabalho.

## Segurança

- **WAF substituído** — o firewall de aplicativos web de perímetro foi substituído por uma alternativa com manutenção mais ativa, sem alteração no tráfego admitido.
