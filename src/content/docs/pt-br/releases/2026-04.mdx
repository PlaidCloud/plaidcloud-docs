## Alterado

- **A documentação interativa da API agora fica em cada tenant** — o Swagger UI, antes servido a partir de um caminho central de documentação, agora está incorporado dentro da instância de cada tenant. Acesse-o pelo seu espaço de trabalho, e não por uma URL separada.
- **PlaidLink atualizado** — uma nova versão do PlaidLink foi distribuída; as instalações existentes continuam funcionando, e você pode atualizar quando for conveniente.

## Adicionado

- **Base para o suporte a agentes de codificação com IA** — a configuração inicial de ingress para os caminhos `/mcp` e `/.well-known/oauth-*` foi concluída neste mês, viabilizando as integrações do MCP que se tornaram visíveis aos usuários em maio.
- **Testes do StarRocks 4.1 (Lakehouse v2)** — o mecanismo de Lakehouse de nova geração está sendo validado com cargas de trabalho reais. Ainda sem alterações visíveis para o cliente; as migrações opcionais (opt-in) virão mais tarde.
