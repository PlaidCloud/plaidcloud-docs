Um repositório contém os arquivos, os branches e o histórico de um projeto. Este guia mostra como criar um repositório e conectar-se a ele a partir do seu computador.

## Criar um repositório

1. Abra **Git** no seu espaço de trabalho.
2. Selecione o menu **+** no canto superior direito e depois **New Repository**.
3. Informe um nome e, opcionalmente, uma breve descrição.
4. Escolha a visibilidade. Os novos repositórios são **Privado** por padrão: somente os membros aos quais você concede acesso podem vê-los.
5. Opcionalmente, selecione **Initialize Repository** para adicionar um README, um `.gitignore` e uma licença.
6. Selecione **Create Repository**.

## Gerar um token de acesso pessoal

Como você entra pelo PlaidCloud, sua conta não tem uma senha separada do Git. Para clonar ou enviar por HTTPS pela linha de comando, crie um token de acesso pessoal e use-o no lugar de uma senha.

1. Selecione seu avatar no canto superior direito e depois **Configurações**. A dica na guia **Git** também leva direto a essa página.
2. Abra a guia **Applications**.
3. Em **Manage Access Tokens**, informe um nome que descreva onde você usará o token (por exemplo, `laptop`).
4. Selecione a permissão **write:repository** para que o token possa clonar e enviar.
5. Selecione **Generate Token**.
6. Copie o token e guarde-o em um local seguro. Você não poderá vê-lo novamente.

<Aside type="caution">Trate o token como uma senha: qualquer pessoa que o tenha pode agir como você no Git. Gere um token separado para cada máquina, para poder revogar um sem afetar os demais.</Aside>

## Clonar um repositório

1. Abra **Git** no seu espaço de trabalho e selecione **Copy clone URL** na linha do repositório. Você também pode selecionar **Código** no repositório e copiar a URL **HTTPS**.
2. Em um terminal, execute `git clone` com essa URL:

   ```bash
   git clone <clone URL>
   ```

3. Quando o Git pedir uma senha, cole o **token de acesso**. Use o nome de usuário que já está na URL.
4. Defina o nome e o e-mail que o Git registra nos seus commits, usando os valores que a dica mostra:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Para enviar alterações, você precisa de acesso de Contributor ou de Administrador; com acesso de Leitura, você pode clonar, mas não enviar. Consulte [Níveis de acesso](/pt-br/guides/git/#níveis-de-acesso).

<Aside>Para não precisar informar o token novamente a cada envio, você pode deixar o auxiliar de credenciais do Git do seu sistema operacional armazená-lo, por exemplo `git config --global credential.helper osxkeychain` no macOS.</Aside>

## Fazer commit e enviar alterações

De dentro de um repositório clonado:

1. Prepare suas alterações: `git add .`
2. Registre-as com uma mensagem: `git commit -m "Describe what changed"`
3. Envie-as ao PlaidCloud Git: `git push`

Seus commits aparecem nas visões **Commits** e **Atividade** do repositório, e em qualquer branch ou pull request que os inclua.

## Gerenciar acesso e visibilidade

Abra a guia **Configurações** de um repositório para renomeá-lo, alterar a visibilidade dele ou transferir a propriedade. Para permitir que outros membros contribuam, use **Configurações → Collaborators** e adicione-os pelo nome de usuário com a função **Leitura**, **Gravação** ou **Administrator**.

<Aside>O acesso ao repositório também segue a sua participação no espaço de trabalho e os seus grupos de segurança. Consulte [Gerenciamento de acesso](/pt-br/administration/access/) para saber como eles determinam quem pode ver e editar um repositório.</Aside>
