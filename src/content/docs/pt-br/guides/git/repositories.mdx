Um repositório contém os arquivos, branches e o histórico de um projeto. Este guia explica como criar um repositório e se conectar a ele a partir do seu computador.

## Criar um repositório

1. Abra o **Git** a partir do seu espaço de trabalho.
2. Selecione o menu **+** no canto superior direito e depois **New Repository**.
3. Digite um nome e, opcionalmente, uma descrição curta.
4. Escolha a visibilidade. Os novos repositórios são **Privado** por padrão – somente os membros a quem você conceder acesso podem vê-los.
5. Opcionalmente, selecione **Initialize Repository** para adicionar um README, um arquivo `.gitignore` e uma licença.
6. Selecione **Create Repository**.

Os colaboradores não podem criar repositórios diretamente na organização Git do espaço de trabalho; os repositórios são criados pelo PlaidCloud.

## Gerar um token de acesso pessoal

Como você entra pelo PlaidCloud, sua conta não tem uma senha Git separada. Para clonar ou fazer push por HTTPS na linha de comando, crie um token de acesso pessoal e use-o no lugar da senha.

1. Selecione seu avatar no canto superior direito e depois **Configurações**. O cartão de configuração na guia **Git** também tem um link direto para esta página.
2. Abra a guia **Aplicativos**.
3. Em **Gerenciar tokens de acesso**, digite um nome que descreva onde você usará o token (por exemplo, `laptop`).
4. Selecione a permissão **write:repository** para que o token possa clonar e fazer push.
5. Selecione **Generate Token**.
6. Copie o token e guarde-o em um lugar seguro. Você não poderá vê-lo novamente.

<Aside type="caution">Trate o token como uma senha – qualquer pessoa que o tenha pode agir como você no Git. Gere um token separado para cada máquina, para poder revogar um sem afetar os demais.</Aside>

## Clonar um repositório

1. Abra o **Git** no seu espaço de trabalho e selecione o botão de copiar ao lado do endereço de clone do repositório (selecione **How to clone** para ver as etapas de configuração). Você também pode selecionar **Código** no repositório e copiar a URL **HTTPS**.
2. Em um terminal, execute `git clone` com essa URL:

   ```bash
   git clone <clone URL>
   ```

3. Quando o Git pedir uma senha, cole o **token de acesso**. Use o nome de usuário que já está na URL.
4. Defina o nome e o e-mail que o Git registra nos seus commits, usando os valores que o cartão de configuração mostra:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Você precisa de acesso de Colaborador ou Administrador para fazer push; como Visualizador, você pode ler, mas não fazer push. Consulte [Níveis de acesso](/pt-br/guides/git/#níveis-de-acesso).

<Aside>Para evitar digitar o token novamente a cada push, você pode deixar que o auxiliar de credenciais do Git do seu sistema operacional o armazene, por exemplo com `git config --global credential.helper osxkeychain` no macOS.</Aside>

## Fazer commit e push das alterações

A partir de dentro de um repositório clonado:

1. Adicione suas alterações à área de stage: `git add .`
2. Registre-as com uma mensagem: `git commit -m "Describe what changed"`
3. Envie-as ao PlaidCloud Git: `git push`

Seus commits aparecem nas visualizações **Commits** e **Atividade** do repositório, e em qualquer branch ou pull request que os inclua.

## Gerenciar acesso e visibilidade

Abra a guia **Configurações** de um repositório para renomeá-lo, alterar a visibilidade ou transferir a propriedade. Para permitir que outros membros contribuam, use **Configurações → Collaborators** e adicione-os por nome de usuário com a função **Leitura**, **Gravação** ou **Administrador**.

<Aside>O acesso ao repositório também acompanha a sua participação no espaço de trabalho e os grupos de segurança. Consulte [Gerenciamento de acesso](/pt-br/administration/access/) para saber como eles definem quem pode ver e editar um repositório.</Aside>
