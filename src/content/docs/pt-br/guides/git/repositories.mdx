Um repositório contém os arquivos, os branches e o histórico de um projeto. Este guia mostra como criar um repositório e conectar-se a ele a partir do seu computador.

## Criar um repositório

1. Abra o **Git** no seu espaço de trabalho.
2. Selecione o menu **+** no canto superior direito e depois **New Repository**.
3. Informe um nome e, opcionalmente, uma breve descrição.
4. Escolha a visibilidade. Os novos repositórios são **Privado** por padrão: somente os membros aos quais você concede acesso podem vê-los.
5. Opcionalmente, selecione **Initialize Repository** para adicionar um README, um `.gitignore` e uma licença.
6. Selecione **Create Repository**.

## Gerar um token de acesso pessoal

Como você entra pelo PlaidCloud, sua conta não tem uma senha separada do Git. Para clonar ou enviar por HTTPS pela linha de comando, crie um token de acesso pessoal e use-o no lugar de uma senha.

1. Selecione seu avatar no canto superior direito e depois **Configurações**.
2. Abra a guia **Aplicativos**.
3. Em **Manage Access Tokens**, informe um nome que descreva onde você usará o token (por exemplo, `laptop`).
4. Selecione os escopos de **leitura** e **gravação** do repositório para que o token possa clonar e enviar.
5. Selecione **Generate Token**.
6. Copie o token e guarde-o em um local seguro. Não será possível visualizá-lo novamente.

<Aside type="caution">Trate o token como uma senha: qualquer pessoa que o tenha pode agir como você no Git. Gere um token separado para cada máquina, para poder revogar um sem afetar os demais.</Aside>

## Clonar um repositório

1. Abra o repositório no PlaidCloud Git.
2. Selecione **Código** e depois copie a URL de clone **HTTPS**.
3. Em um terminal, execute `git clone` com essa URL:

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. Quando o Git solicitar credenciais, informe seu **nome de usuário do PlaidCloud** e cole o **token de acesso** como senha.

<Aside>Para evitar informar o token novamente a cada push, deixe o auxiliar de credenciais do Git do seu sistema operacional armazená-lo: execute `git config --global credential.helper store` (ou `osxkeychain` no macOS) antes do primeiro push.</Aside>

## Fazer commit e enviar alterações

De dentro de um repositório clonado:

1. Adicione suas alterações à área de preparação: `git add .`
2. Registre-as com uma mensagem: `git commit -m "Describe what changed"`
3. Envie-as ao PlaidCloud Git: `git push`

Seus commits aparecem nas visões **Commits** e **Atividade** do repositório, e em qualquer branch ou pull request que os inclua.

## Gerenciar acesso e visibilidade

Abra a guia **Configurações** de um repositório para renomeá-lo, alterar a visibilidade ou transferir a propriedade. Para permitir que outros membros contribuam, use **Configurações → Collaborators** e adicione-os pelo nome de usuário com a função **Leitura**, **Gravação** ou **Administrator**.

<Aside>O acesso ao repositório também segue a participação no seu espaço de trabalho e os grupos de segurança. Consulte [Gerenciamento de acesso](/pt-br/administration/access/) para ver como eles determinam quem pode ver e editar um repositório.</Aside>
