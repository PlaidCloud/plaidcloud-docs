O PlaidCloud Git permite pesquisar código, arquivos, issues e pull requests em todos os repositórios aos quais a sua participação no espaço de trabalho dá acesso.

## Pesquisar código

1. Selecione a caixa de pesquisa na parte superior de qualquer página e digite sua consulta.
2. Pressione **Enter** para ver os resultados em todos os repositórios aos quais você tem acesso.
3. Selecione um resultado para ir diretamente ao arquivo, na linha correspondente.
4. Restrinja os resultados com os filtros **Repositório** e **Idioma** na página de resultados.

<Aside>A pesquisa de código indexa o branch padrão. Para pesquisar em outro branch, navegue até ele e use a pesquisa dentro do repositório descrita abaixo.</Aside>

## Pesquisar dentro de um repositório

1. Abra um repositório e selecione a guia **Código**.
2. Pressione **T** (ou selecione a caixa do localizador de arquivos) para abrir o localizador de arquivos.
3. Digite parte de um nome de arquivo ou caminho; a lista é filtrada à medida que você digita.
4. Selecione um arquivo para abri-lo e depois use a busca na página do navegador (**⌘F** / **Ctrl+F**) para localizar uma linha específica.

<Aside type="tip">O localizador de arquivos faz a correspondência por segmentos de caminho, então digitar `util/auth` exibe `src/util/auth.py`, `lib/util/auth_helper.go` e caminhos semelhantes.</Aside>

## Filtrar issues e pull requests

Na lista de **Issues** ou de **Pull Requests**, combine a pesquisa por palavra-chave com filtros `key:value`:

| Filtro | Exemplo |
|---|---|
| Estado aberto ou fechado | `is:open`, `is:closed` |
| Rótulo | `label:bug`, `label:"needs review"` |
| Responsável | `assignee:you` |
| Autor | `author:you` |
| Marco | `milestone:"v1.2"` |

Digite os filtros diretamente na caixa de pesquisa, combine-os livremente e use o menu **Classificar** para ordenar por **Atualizados recentemente**, **Mais comentados**, **Mais recentes** ou **Mais antigo**.

<Aside>Coloque o nome de um rótulo entre aspas quando ele contiver espaços: `label:"needs review"`.</Aside>

## Dicas para encontrar as coisas mais rápido

- **Frases exatas:** coloque termos com várias palavras entre aspas (`"connection pool"`) para evitar correspondências parciais irrelevantes.
- **Restringir a um repositório:** abra o repositório antes de pesquisar para que os resultados fiquem mais focados.
- **Nomes descritivos compensam:** repositórios e issues com nomes claros e específicos aparecem na pesquisa de forma muito mais confiável do que os genéricos, como `misc`.
- **Rótulos são metadados pesquisáveis:** uma issue bem rotulada é mais fácil de filtrar do que uma enterrada em texto corrido, então aplique rótulos de forma consistente.
