Um quadro de projeto organiza issues e pull requests em colunas que representam as etapas do seu fluxo de trabalho, dando a toda a equipe uma visão compartilhada do que está em andamento, do que está bloqueado e do que está concluído.

## Criar um quadro

1. Abra o repositório e selecione a guia **Projetos**.
2. Selecione **Novo projeto**.
3. Informe um nome para o quadro.
4. Escolha um modelo inicial (um layout básico **To Do / In Progress / Done** é um bom padrão) ou selecione um quadro vazio para montar o layout do zero.
5. Selecione **Create Project** para abrir o quadro.

<Aside>Um quadro criado na guia **Projetos** de um repositório pertence a esse repositório. Os quadros que abrangem vários repositórios do seu espaço de trabalho são criados por um administrador na área Projetos em nível de organização.</Aside>

## Configurar colunas

1. Para adicionar uma coluna, selecione **Adicionar coluna**, informe um rótulo e salve.
2. Para renomear uma coluna, abra as configurações dela e escolha **Editar**.
3. Arraste os cabeçalhos das colunas para a esquerda ou para a direita para reordená-las.
4. Marque uma coluna como padrão nas configurações dela: qualquer cartão adicionado sem um destino específico vai para lá.

## Adicionar e mover cartões

- Para adicionar uma issue ou um pull request existente, abra o menu de uma coluna e selecione **Add an item**; depois, pesquise por título ou número.
- Para criar uma nova issue diretamente no quadro, selecione **+** dentro de uma coluna. A issue é salva no repositório e aparece imediatamente como um cartão.
- Arraste um cartão para outra coluna conforme o trabalho avança. A posição do cartão reflete o status atual dele; por si só, ela não altera os rótulos nem os responsáveis da issue.

## Acompanhar o trabalho

O quadro dá uma visão rápida da carga de trabalho da sua equipe sem abrir cada issue. Mantenha-o atualizado:

- Fechando uma issue ou mesclando um pull request: o cartão vai para uma coluna de concluído ou sai do quadro, conforme as configurações de automação do seu quadro.
- Combinando o quadro com **Marcos** quando você quiser uma meta com prazo definido ao lado da visão Kanban. Os marcos acompanham uma data de vencimento e o percentual de conclusão; o quadro acompanha o fluxo.
