## Descrição

Os dados nos painéis podem ser enriquecidos com métricas.  Cada conjunto de dados contém uma seção para Métricas.  As métricas podem ser escritas e modificadas com SQL no dialeto do PostgreSQL.

<SnippetDashboardsCommonNavigateToDataset />

## Exemplos
Colunas calculadas são, em geral, colunas adicionais criadas combinando lógica e colunas existentes.

### Converter uma data em texto
```sql
to_char("week_ending_sol_del_req", 'YYYY-mm-dd')
```

### Vários exemplos de SUM
```sql
SUM(Value)

SUM(-1*"value_usd_mkp") / (0.0001+SUM(-1*"value_usd_base"))

(SUM("Value_USD_VAT")/SUM("Value_USD_HEADER"))*100

sum(delivery_cases) where Material_Type = Gloves

sum("total_cost") / sum("delivery_count")
```


### Vários exemplos de CASE
```sql
CASE WHEN
SUM("distance_dc_xd") = 0 THEN 0
ELSE
sum("XD")/sum("distance_dc_xd")
END

sum(CASE
WHEN "FUNCTION" = 'OM' THEN "VALUE__FC"
ELSE 0.0
END)
```


### Count
```sql
count(*)
```


### First e Cast
```sql
public.first(cast("PRETAX_SEQ" AS NUMERIC))
```


### Round
```sql
round(Sum("GROSS PROFIT"),0)
```


### Concat
```sql
concat("GCOA","CC Code")
```
