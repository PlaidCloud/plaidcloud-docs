O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas e instâncias de ERP que você conecta em um único Common Finance Model, e o Sage Intacct é um dos ERPs que ele lê diretamente. A conexão usa o Intacct Web Services: uma autorização de remetente para o PlaidCloud e um usuário do Web Services somente leitura. Esta página é para o administrador do Sage Intacct que faz essa configuração e para o usuário do PlaidCloud que a solicita a ele.

O PlaidCloud apenas lê dados. Ninguém envia uma senha por e-mail.

## Enviar a solicitação de acesso

Na guia **Foundation** do projeto, escolha **Criar uma nova conexão** em **Conexão Sage Intacct**. O formulário mostra a solicitação completa. Clique em **Copiar solicitação** para colá-la na sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la no seu programa de e-mail com o assunto "Read-only Sage Intacct access for PlaidCloud (Web Services)."

## O que o administrador do Sage Intacct configura

<Steps>

1. **Autorizar o PlaidCloud como remetente do Web Services.** Em **Company > Admin > Web Services authorizations**, adicione o ID do remetente que o PlaidCloud forneceu a você. Devolva o ID do remetente e a senha do remetente que a Sage emitiu para ele.

2. **Criar um usuário do Web Services.** Em **Company > Admin > Users**, crie um usuário do tipo "Business" com a opção "Web services only" e uma função com permissão **Visualizar** em:

   | Área | Objetos |
   |---|---|
   | Razão geral | Contas, lançamentos contábeis (todos os diários, inclusive os de ajuste), saldos de contas, períodos de relatório, taxas de câmbio, orçamentos |
   | Empresa | Entidades (localizações), departamentos, classes, projetos |
   | Contas a receber | Clientes |
   | Controle de estoque | Itens |
   | Entrada de pedidos | Transações (faturas de venda e as notas de crédito e devoluções que as cancelam), se você quiser vendas |

   Dê ao usuário acesso ao nível superior da empresa e a todas as entidades sobre as quais o PlaidCloud gera relatórios. Se as definições de transação de nota de crédito e de devolução não se chamarem Sales Credit Memo e Sales Return, informe os nomes ao usuário do PlaidCloud.

3. **Permitir o endereço IP do usuário** se a sua empresa restringe o Web Services por IP.

</Steps>

## O que devolver

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O ID da empresa | **ID da empresa** |
| O ID do usuário do Web Services | **ID do usuário do Web Services** |
| A senha do usuário do Web Services | **Senha do Web Services** |
| O ID do remetente | **ID do remetente** |
| A senha do remetente | **Senha do remetente** |
| Os nomes das suas definições de transação de nota de crédito e de devolução, se não forem os padrões | A configuração de sistema `credit_documents` (padrões: Sales Credit Memo, Sales Return) |
| As entidades que o PlaidCloud pode ler | Escolhidas em **Entidades** no PlaidCloud |

As senhas passam pelo seu gerenciador de senhas, nunca por e-mail. A equipe do usuário do PlaidCloud cola a **Senha do Web Services** e a **Senha do remetente** no PlaidCloud por conta própria. As entidades que são as eliminações da própria empresa vão na configuração de sistema `elimination_entities`.

## Verificar o acesso

De volta ao PlaidCloud, informe os valores e clique em **Testar conexão**. Cada conjunto de dados aparece como **Legível**, **Permissão ausente** ou **Erro**:

| Conjunto de dados | Permissão que ele exige |
|---|---|
| Entidades | Empresa: Entidades (Visualizar) |
| Plano de contas | Razão geral: Contas e Contas estatísticas (Visualizar) |
| Departamentos | Empresa: Departamentos (Visualizar) |
| Clientes | Contas a receber: Clientes (Visualizar) |
| Produtos | Controle de estoque: Itens (Visualizar) |
| Taxas de câmbio | Razão geral: Taxas de câmbio (Visualizar) |
| Calendário fiscal | Razão geral: Períodos de relatório (Visualizar) |
| Balancete | Razão geral: Saldos de contas (Visualizar) |
| Razão geral | Razão geral: Lançamentos contábeis (Visualizar) |
| Linhas de vendas | Entrada de pedidos: Transações (Visualizar) |
| Orçamento | Razão geral: Orçamentos (Visualizar) |
| Direcionadores de alocação | Razão geral: Saldos de contas (Visualizar) |

Quando falta um conjunto de dados, o teste informa a permissão a adicionar. Peça ao administrador que a adicione à função e teste novamente. Linhas de vendas, Orçamento e Direcionadores de alocação são opcionais: uma empresa que não os usa ainda carrega todo o resto.
