O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas e instâncias de ERP que você conecta em um único Common Finance Model, e o Sage Intacct é um dos ERPs que ele lê diretamente. A conexão usa o Intacct Web Services: uma autorização de remetente para o PlaidCloud e um usuário do Web Services somente leitura. Esta página é para o administrador do Sage Intacct que faz essa configuração e para o usuário do PlaidCloud que a solicita a ele.

O PlaidCloud apenas lê dados. Ninguém envia uma senha por e-mail.

## Enviar a solicitação de acesso

Na página **Sistemas** do projeto, em **Data Foundation**, no **Início**, escolha seu sistema em **Sistema**, em **Adicionar um sistema**, e clique em **Ainda não tem acesso?**. O sistema fica aguardando acesso, e é exibida uma única solicitação que abrange os sistemas do projeto. Clique em **Copiar solicitação** para colá-la na sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la no seu programa de e-mail com o assunto "Acesso ao PlaidCloud."

## O que o administrador do Sage Intacct configura

<Steps>

1. **Autorizar o PlaidCloud como remetente do Web Services.** Em **Company > Admin > Web Services authorizations**, adicione o ID do remetente que o PlaidCloud forneceu a você. Devolva o ID do remetente e a senha do remetente que a Sage emitiu para ele.

2. **Criar um usuário do Web Services.** Em **Company > Admin > Users**, crie um usuário do tipo "Business" com a opção "Web services only" e uma função com permissão **Visualizar** em:

   | Área | Objetos |
   |---|---|
   | Razão geral | Contas, contas estatísticas, lançamentos contábeis (todos os diários, inclusive os de ajuste), saldos de contas, períodos de relatório, taxas de câmbio, orçamentos |
   | Empresa | Entidades (localizações), departamentos, classes, projetos |
   | Contas a receber | Clientes, faturas, ajustes, pagamentos |
   | Contas a pagar | Fornecedores, contas a pagar, ajustes, pagamentos |
   | Gestão de caixa | Contas correntes |
   | Controle de estoque | Itens |
   | Entrada de pedidos | Transações (faturas de venda e as notas de crédito e devoluções que as cancelam), se você quiser vendas |

   Dê ao usuário acesso ao nível superior da empresa e a todas as entidades sobre as quais o PlaidCloud gera relatórios. Se as definições de transação de nota de crédito e de devolução não se chamarem Sales Credit Memo e Sales Return, informe os nomes ao usuário do PlaidCloud.

3. **Permitir o endereço IP do usuário** se a sua empresa restringe o Web Services por IP.

</Steps>

## O que devolver

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O ID da empresa | **ID da empresa** |
| O ID do usuário do Web Services | **Nome de usuário do usuário de serviço web** |
| O ID do remetente | **ID do cliente** |
| A senha do remetente | **Segredo do cliente** |
| Os nomes das suas definições de transação de nota de crédito e de devolução, se não forem os padrões | A configuração de sistema **Credit memo and return document types** (padrões: Sales Credit Memo, Sales Return) |
| As entidades que o PlaidCloud pode ler | Em **Opções**, **Empresas**: marque-as, ou nenhuma para todas elas |

As senhas passam pelo seu gerenciador de senhas, nunca por e-mail. A equipe do usuário do PlaidCloud informa por conta própria a senha do remetente como o **Segredo do cliente**. As entidades que são as eliminações da própria empresa vão na configuração de sistema **Elimination entities**.

## Verificar o acesso

De volta ao PlaidCloud, depois de adicionar o sistema, clique em **Testar conexão** na linha dele na página **Sistemas**. Ele lê os conjuntos de dados obrigatórios e mostra cada um como **Legível**, **Permissão ausente** ou **Erro**. Os opcionais, marcados abaixo, não fazem parte do teste: se o Sage Intacct recusar algum, após a próxima carga as verificações de prontidão, no painel **CFM-Accounting - Close and assurance**, indicam o objeto a conceder.

| Conjunto de dados | Permissão que ele exige |
|---|---|
| Entidades | Empresa: Entidades (Visualizar) |
| Plano de contas | Razão geral: Contas e Contas estatísticas (Visualizar) |
| Departamentos | Empresa: Departamentos (Visualizar) |
| Clientes | Contas a receber: Clientes (Visualizar) |
| Produtos | Controle de estoque: Itens (Visualizar) |
| Taxas de câmbio | Razão geral: Taxas de câmbio (Visualizar) |
| Calendário fiscal | Razão geral: Períodos de relatório (Visualizar) |
| Balancete | Razão geral: Saldos de contas (Visualizar) |
| Razão geral | Razão geral: Lançamentos contábeis (Visualizar) |
| Saldo de fim de mês (opcional) | Razão geral: Saldos de contas (Visualizar) |
| Saldos bancários (opcional) | Gestão de caixa: Contas correntes (Visualizar), com o saldo de fim de mês |
| Sites (opcional) | Empresa: Entidades (localizações) (Visualizar) |
| Centros de lucro (opcional) | Empresa: Classes (Visualizar) |
| Projetos (opcional) | Empresa: Projetos (Visualizar) |
| Fornecedores (opcional) | Contas a pagar: Fornecedores (Visualizar) |
| Linhas de vendas (opcional) | Entrada de pedidos: Transações (Visualizar) |
| Linhas de faturas de fornecedor (opcional) | Contas a pagar: Contas a pagar e Ajustes (Visualizar) |
| Itens em aberto e Pagamentos (opcional) | Contas a receber: Faturas, Ajustes e Pagamentos, e Contas a pagar: Contas a pagar, Ajustes e Pagamentos (Visualizar) |
| Orçamento (opcional) | Razão geral: Orçamentos (Visualizar) |
| Direcionadores de alocação (opcional) | Razão geral: Saldos de contas (Visualizar) |

Quando falta um conjunto de dados, o teste informa a permissão a adicionar. Peça ao administrador que a adicione à função e teste novamente. Uma empresa que não usa um conjunto de dados opcional ainda carrega todo o resto. Quando o Sage Intacct recusa uma leitura a partir da qual são montados as faturas de fornecedor, os itens em aberto ou os pagamentos de um mês, esse mês mantém as linhas que já tinha e é lido novamente na próxima carga.

Quem inseriu um lançamento, quando, quem o aprovou e o que ele estorna são lidos do lote do lançamento. Uma função que não consegue ler o lote os deixa vazios.
