Conecte o PlaidCloud ao **OneStream** para que o Data Foundation possa ler seus resultados consolidados e conciliar com eles a demonstração do resultado (DRE) gerencial do grupo. O OneStream é compatível por meio do conector dele: o PlaidCloud entra com credenciais de cliente OAuth 2.0 e lê um adaptador de dados que o administrador do OneStream cria. Ele apenas lê. Se você indicar uma sequência do Data Management, o PlaidCloud executa essa sequência primeiro para atualizar o que o adaptador lê, e não executa mais nada.

O OneStream é uma fonte de resultados com os quais conciliar, não de linhas do razão: as linhas dele chegam como o cenário `Consolidated` da tabela de orçamento do modelo, versão `OneStream`. Consulte [Concilie com seu sistema de consolidação](/pt-br/guides/projects/data-foundation/#reconcilie-com-seu-sistema-de-consolidação).

<Aside type="note">
As colunas do adaptador são um contrato que você e o administrador do OneStream combinam. Quando o adaptador é criado conforme esta página, as linhas dele chegam como descrito abaixo. Compare os resultados da primeira carga com um relatório do OneStream em que você confie.
</Aside>

## O que o administrador do OneStream configura

A guia **Foundation** redige uma solicitação de acesso para você enviar. Ela pede o seguinte.

1. Um cliente para o PlaidCloud no serviço de identidade do OneStream que use a concessão de **credenciais de cliente**, com um usuário de serviço que possa executar o adaptador e, se você quiser que o PlaidCloud atualize os resultados antes, a sequência do Data Management.

2. No aplicativo e no espaço de trabalho sobre os quais você gera relatórios, um adaptador de dados chamado **Foundation_Results** que retorne uma tabela dos resultados consolidados com exatamente estas colunas:

   | Coluna | Contém |
   |---|---|
   | `entity` | O membro de consolidação: uma entidade, um membro de eliminação ou o total do grupo. |
   | `account` | O código da conta. Somente contas-base. |
   | `time` | O mês, no formato `YYYY-MM`. |
   | `scenario` | O cenário. |
   | `view` | `YTD` ou `Periodic`. O PlaidCloud lê apenas as linhas da visão que você escolher. |
   | `amount` | Um número, no sinal e na escala que seus relatórios mostram. |
   | `currency` | A moeda em que o valor é expresso: a moeda de relatório do seu grupo. |
   | `flow`, `ud1`, `ud2`, `ud3`, `ud4` | Dimensões de fluxo e definidas pelo usuário. Somente membros-base. |

   Forneça membros-base das dimensões de conta, de fluxo e definidas pelo usuário. A linha de um membro pai contaria os filhos duas vezes. O adaptador lê o membro de consolidação da variável de substituição `Member` e a visão de `View`.

3. Os membros a ler: as entidades, os membros de eliminação e o total do grupo.

## Criar a conexão

<Steps>

1. Abra **Tools > Connections**, clique em `New Connection` e escolha **REST - OneStream**.

2. Preencha os campos:

   | Campo | Valor |
   |---|---|
   | Host | O URL base do OneStream, começando com `https://`. |
   | ID do cliente | O ID do cliente do PlaidCloud. |
   | Segredo do cliente | O segredo dele. Armazenado criptografado e nunca mais exibido. |
   | URL do token | Deixe em branco para usar o Host seguido de `/identity/connect/token`. |
   | Aplicativo padrão | Usado por uma leitura que deixa o aplicativo em branco. |
   | Espaço de trabalho padrão | Usado por uma leitura que deixa o espaço de trabalho em branco. |
   | Tempo limite (segundos) | O padrão é 120. |

3. Clique em `Create`.

</Steps>

Você também pode criar a conexão na guia **Foundation** ao adicionar a fonte: escolha **Criar uma nova conexão** e preencha **URL do host da API**, **ID do cliente**, **Segredo do cliente**, **URL do token**, **Aplicativo** e **Espaço de trabalho**, que têm o mesmo significado dos campos acima.

## Adicionar ao projeto do Data Foundation

Na guia **Foundation**, adicione a conexão como fonte, como faria com qualquer outra (consulte [Conecte seu ERP](/pt-br/guides/projects/data-foundation/#conecte-seu-erp)). O OneStream não lista membros para marcar, então o formulário pede o membro de consolidação a ler: informe-o em **Nome**. Depois, em **Configurações do sistema**, descreva os valores do adaptador. As configurações aparecem com estes nomes:

| Configuração | O que significa |
|---|---|
| `view` | `ytd` (o padrão) quando os valores do adaptador são acumulados no ano, ou `periodic`. As linhas acumuladas no ano chegam como valores do período. |
| `sign` | `natural` (o padrão): cada conta no próprio sinal, como o OneStream a reporta. `debit_positive`: débitos positivos. |
| `scale` | O multiplicador para unidades monetárias inteiras: `1000` quando o OneStream fornece milhares. O padrão é `1`. |
| `fy_start_month` | O mês em que o seu ano fiscal começa, de `1` a `12`, para converter acumulado no ano em valores do período. O padrão é `1`. |
| `application`, `workspace` | Substituem os da conexão. Deixe em branco para usar os da conexão. |
| `table` | O nome da tabela dentro do conjunto de dados do adaptador. O padrão é `Results`. |
| `sequence` | Uma sequência do Data Management executada antes da leitura para atualizar o que o adaptador lê. |

Mapeie os membros do OneStream para as suas entidades com um arquivo de mapa de códigos que se aplique a esta fonte. Consulte [Correspondência de entidades](/pt-br/guides/projects/data-foundation/#mapeamento-de-entidades). A fonte não lê nenhuma janela de histórico: as próprias variáveis de substituição do adaptador a delimitam.

Uma carga em que o adaptador não retorna nenhuma linha termina com um aviso, não com um erro, e a tabela fica vazia.
