Conecte o PlaidCloud ao **OneStream** para que o Data Foundation leia seus resultados consolidados e concilie com eles a demonstração do resultado (DRE) gerencial do grupo. O OneStream é compatível por meio do seu conector: o PlaidCloud faz login com as credenciais de cliente do OAuth 2.0 e lê um adaptador de dados que o administrador do OneStream cria. Ele apenas lê. Se você informar uma sequência do Data Management, o PlaidCloud executa essa sequência primeiro para atualizar o que o adaptador lê, e não executa mais nada.

O OneStream é uma origem de resultados com os quais conciliar, não de linhas do razão: suas linhas chegam como o cenário `Consolidated` da tabela de orçamento do modelo, na versão `OneStream`. Consulte [Concilie com seu sistema de consolidação](/pt-br/guides/projects/data-foundation/#concilie-com-seu-sistema-de-consolidação).

<Aside type="note">
As colunas do adaptador são um contrato que você e o administrador do OneStream combinam. Quando o adaptador é criado conforme esta página, suas linhas chegam como descrito abaixo. Compare os resultados da primeira carga com um relatório do OneStream em que você confie.
</Aside>

## O que o administrador do OneStream configura

A guia **Foundation** redige uma solicitação de acesso para você enviar. Ela pede o seguinte.

1. Um cliente para o PlaidCloud no serviço de identidade do OneStream que use a concessão de **credenciais de cliente**, com um usuário de serviço que possa executar o adaptador e, se você quiser que o PlaidCloud atualize os resultados antes, a sequência do Data Management.

2. No aplicativo e no espaço de trabalho sobre os quais você reporta, um adaptador de dados chamado **Foundation_Results** que retorne uma tabela de resultados consolidados com exatamente estas colunas:

   | Coluna | Contém |
   |---|---|
   | `entity` | O membro de consolidação: uma entidade, um membro de eliminação ou o total do grupo. |
   | `account` | O código da conta. Somente contas-base. |
   | `time` | O mês, como `YYYY-MM`. |
   | `scenario` | O cenário. |
   | `view` | `YTD` ou `Periodic`. O PlaidCloud lê apenas as linhas da visão que você escolher. |
   | `amount` | Um número, no sinal e na escala que seus relatórios mostram. |
   | `currency` | A moeda em que o valor está expresso: a moeda de relatório do seu grupo. |
   | `flow`, `ud1`, `ud2`, `ud3`, `ud4` | Dimensões de fluxo e definidas pelo usuário. Somente membros-base. |

   Forneça membros-base das dimensões de conta, fluxo e definidas pelo usuário. A linha de um membro pai contaria seus filhos duas vezes. O adaptador lê o membro de consolidação da variável de substituição `Member` e a visão de `View`.

3. Os membros a serem lidos: as entidades, os membros de eliminação e o total do grupo.

## Criar a conexão

<Steps>

1. Abra **Tools > Connections** e clique em `New Connection`, depois escolha **OneStream**. Ou crie-a pela guia **Foundation** ao adicionar a origem.

2. Preencha os campos:

   | Campo | Valor |
   |---|---|
   | Host | A URL base do OneStream, começando com `https://`. |
   | ID do cliente | O ID de cliente do cliente do PlaidCloud. |
   | Segredo do cliente | Seu segredo. Armazenado criptografado e nunca mais exibido. |
   | URL do token | Deixe em branco para usar o Host seguido de `/identity/connect/token`. |
   | Aplicativo padrão | Usado por uma leitura que deixa o aplicativo em branco. |
   | Espaço de trabalho padrão | Usado por uma leitura que deixa o espaço de trabalho em branco. |
   | Tempo limite (segundos) | O padrão é 120. |

3. Clique em `Create`.

</Steps>

## Adicionar a um projeto do Data Foundation

Na guia **Foundation**, adicione a conexão como origem, como faria com qualquer outra (consulte [Conecte seu ERP](/pt-br/guides/projects/data-foundation/#conecte-seu-erp)), e escolha os membros de consolidação a serem lidos. Depois, responda o que descreve os valores do adaptador:

| Configuração | O que significa |
|---|---|
| Membros | Os membros de consolidação a serem lidos, com uma chamada ao adaptador para cada um. |
| Visão | Se os valores do adaptador são acumulados no ano (o padrão) ou periódicos. As linhas acumuladas no ano chegam como valores periódicos. |
| Sinal | **Natural**: cada conta no seu próprio sinal, como o OneStream a reporta (o padrão). **Debit positive**: débitos positivos. |
| Escala | O multiplicador para unidades inteiras da moeda: `1000` quando o OneStream fornece milhares. |
| Mês de início do ano fiscal | O mês em que seu ano fiscal começa, para converter acumulado no ano em periódico. |
| Aplicativo, espaço de trabalho | Substituem os da conexão. |
| Variáveis de substituição | Variáveis extras que o adaptador lê, por exemplo `Time=2026M1`. |
| Sequência do Data Management | Uma sequência executada antes da leitura para atualizar o que o adaptador lê. |

Mapeie os membros do OneStream para as suas entidades com um arquivo de mapa de códigos que se aplique a esta origem. Consulte [Mapeamento de entidades](/pt-br/guides/projects/data-foundation/#mapeamento-de-entidades). A origem não lê nenhuma janela de histórico: as próprias variáveis de substituição do adaptador a delimitam.

Uma carga que não retorna linhas do adaptador termina com um aviso, não com um erro, e a tabela fica vazia.
