Conecte o PlaidCloud ao **OneStream** para que o Data Foundation possa ler seus resultados consolidados e conciliar com eles a demonstração do resultado (DRE) gerencial do grupo. O OneStream é compatível por meio do conector dele: o PlaidCloud entra com credenciais de cliente OAuth 2.0 e lê um adaptador de dados que o administrador do OneStream cria. Ele apenas lê.

O OneStream é uma fonte de resultados com os quais conciliar, não de linhas do razão: as linhas dele chegam como o cenário `Consolidated` da tabela de orçamento do modelo, versão `OneStream`. Consulte [Concilie com seu sistema de consolidação](/pt-br/guides/projects/data-foundation/#reconciliar-com-o-seu-sistema-de-consolidação).

<Aside type="note">
As colunas do adaptador são um contrato que você e o administrador do OneStream combinam. Quando o adaptador é criado conforme esta página, as linhas dele chegam como descrito abaixo. Compare os resultados da primeira carga com um relatório do OneStream em que você confie.
</Aside>

## O que o administrador do OneStream configura

A página **Sistemas** do projeto redige uma solicitação de acesso para você enviar; consulte [Conecte seu ERP](/pt-br/guides/projects/data-foundation/#conectar-seu-erp). Ela pede o seguinte.

1. Um cliente para o PlaidCloud no serviço de identidade do OneStream que use a concessão de **credenciais de cliente**, com um usuário de serviço que possa apenas executar os adaptadores abaixo: sem direitos de Data Management, de carga ou de consolidação. O PlaidCloud não executa nenhuma sequência do Data Management, então mantenha atualizados, no seu próprio agendamento, os resultados que os adaptadores leem.

2. No aplicativo e no espaço de trabalho sobre os quais você gera relatórios, um adaptador de dados chamado **Foundation_Results** que retorne uma tabela dos resultados consolidados com exatamente estas colunas:

   | Coluna | Contém |
   |---|---|
   | `entity` | O membro de consolidação: uma entidade, um membro de eliminação ou o total do grupo. |
   | `account` | O código da conta. Somente contas-base. |
   | `time` | O mês, no formato `YYYY-MM`. |
   | `scenario` | `Actual` para os resultados consolidados. `Budget` ou `Forecast` para um plano, lido como o plano. |
   | `view` | `YTD` ou `Periodic`. O PlaidCloud lê apenas as linhas da visão que você escolher. |
   | `amount` | Um número, no sinal e na escala que seus relatórios mostram. |
   | `currency` | A moeda em que o valor é expresso: a moeda de relatório do seu grupo. |
   | `flow` | O membro de fluxo. Somente membros-base. |
   | `ud1` a `ud5` | Os membros de departamento, produto, site, representante de vendas e projeto, `None` quando a linha não tem nenhum. Somente membros-base. |
   | `version` | A versão de um plano. Deixe `None` ou em branco para `Actual`. |
   | `version_as_of` | O mês, no formato `YYYY-MM`, em que a versão de um plano foi feita. Deixe `None` ou em branco para `Actual`. |
   | `quantity` | As unidades para as quais a linha de um plano é planejada, por mês, qualquer que seja a visão. Deixe `None` ou em branco para `Actual`. |

   Forneça membros-base das dimensões de conta, de fluxo e definidas pelo usuário. A linha de um membro pai contaria os filhos duas vezes. O adaptador lê o membro de consolidação da variável de substituição `Member` e a visão de `View`.

   Se o seu plano contém o quadro de pessoal ou as unidades produzidas, crie também um adaptador chamado **Foundation_Drivers** com as colunas `entity`, `time`, `scenario`, `driver` (por exemplo `headcount` ou `units_produced`), `value`, `unit` (`FTE`, `EA` e assim por diante), `ud1` (departamento), `ud2` (produto), `ud3` (site), `version` e `version_as_of`. Ele lê `Member` da mesma forma e é opcional: sem ele, ou sem acesso a ele, nenhum direcionador planejado é carregado, e as verificações de prontidão informam isso.

3. Os membros a ler: as entidades, os membros de eliminação e o total do grupo.

## Criar a conexão

<Steps>

1. Abra **Tools > Connections**, clique em `New Connection` e escolha **REST - OneStream**.

2. Preencha os campos:

   | Campo | Valor |
   |---|---|
   | Host | O URL base do OneStream, começando com `https://`. |
   | ID do cliente | O ID do cliente do PlaidCloud. |
   | Segredo do cliente | O segredo dele. Armazenado criptografado e nunca mais exibido. |
   | URL do token | Deixe em branco para usar o Host seguido de `/identity/connect/token`. |
   | Aplicativo padrão | Usado por uma leitura que deixa o aplicativo em branco. |
   | Espaço de trabalho padrão | Usado por uma leitura que deixa o espaço de trabalho em branco. |
   | Tempo limite (segundos) | O padrão é 120. |

3. Clique em `Create`.

</Steps>

Você também pode criar a conexão ao adicionar o sistema na página **Sistemas**: escolha **Nova conexão** em **Conexão**, e o mesmo editor de conexões é aberto.

## Adicionar ao projeto do Data Foundation

Na página **Sistemas** do projeto, adicione o OneStream com a conexão dele, como faria com qualquer outro sistema (consulte [Conecte seu ERP](/pt-br/guides/projects/data-foundation/#conectar-seu-erp)). O OneStream não lista membros para marcar, então em **Opções**, **Empresas**, informe os membros de consolidação a ler, separados por vírgulas: pelo menos um. Depois, em **Configurações do sistema**, descreva os valores do adaptador:

| Configuração | O que significa |
|---|---|
| **View member** | `ytd` (o padrão) quando os valores do adaptador são acumulados no ano, ou `periodic`. As linhas acumuladas no ano chegam como valores do período. |
| **Sign convention** | `natural` (o padrão): cada conta no próprio sinal, como o OneStream a reporta. `debit_positive`: débitos positivos. |
| **Amount scale** | O multiplicador para unidades monetárias inteiras: `1000` quando o OneStream fornece milhares. O padrão é `1`. |
| **First month of the fiscal year** | O mês em que o seu ano fiscal começa, de `1` a `12`, para converter acumulado no ano em valores do período. O padrão é `1`. |
| **Application**, **Workspace** | Substituem os da conexão. Deixe em branco para usar os da conexão. |
| **Adapter results table** | O nome da tabela dentro do conjunto de dados do adaptador. O padrão é `Results`. |
| **Substitution variables** | As variáveis de substituição definidas para o adaptador, uma por linha no formato `name = value`, por exemplo `Time = 2026M1`. |

Mapeie os membros do OneStream para as suas entidades com um arquivo de mapa de códigos que se aplique a esta fonte. Consulte [Correspondência de entidades](/pt-br/guides/projects/data-foundation/#mapeamento-de-entidades). A fonte não lê nenhuma janela de histórico: as próprias variáveis de substituição do adaptador a delimitam.

Uma carga em que o adaptador não retorna nenhuma linha termina com um aviso, não com um erro, e a tabela fica vazia.
