O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas de ERP e de contabilidade que você conecta, em quantas instâncias você tiver, em um único Common Finance Model. O Xero é um dos sistemas que ele lê diretamente, com uma organização do Xero por conexão. Esta página é para o administrador do Xero que configura o acesso e para o usuário do PlaidCloud que o solicita a ele.

O PlaidCloud apenas lê dados. Ninguém envia uma senha por e-mail.

## Enviar a solicitação de acesso

Na guia **Foundation** do projeto, escolha **Criar uma nova conexão** e selecione **Xero**. O formulário mostra a solicitação completa. Clique em **Copiar solicitação** para colá-la na sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la no seu programa de e-mail com o assunto "Read-only Xero access for PlaidCloud."

## O que o administrador do Xero configura

<Steps>

1. **Autorizar o aplicativo do PlaidCloud no Xero** para cada organização sobre a qual você gera relatórios, conectado como um usuário com a função Standard ou Advanced. O aplicativo pede somente acesso de leitura:

   | Escopo | O que ele abrange |
   |---|---|
   | `accounting.settings.read` | Organização, plano de contas, categorias de acompanhamento, itens |
   | `accounting.contacts.read` | Clientes |
   | `accounting.transactions.read` | Faturas de venda e notas de crédito |
   | `accounting.journals.read` | O razão geral: todos os lançamentos contábeis registrados |
   | `accounting.reports.read` | O balancete, para os saldos de abertura |

   Sem `accounting.journals.read`, o razão geral não pode ser carregado. O plano de contas, os departamentos, os clientes e os produtos ainda são.

2. **Configurar as categorias de acompanhamento que o PlaidCloud lê**, com estes nomes:

   - **Department:** uma opção por departamento, nomeada como você quer que o código dele apareça.
   - **Intercompany:** uma opção por empresa do grupo, nomeada pelo código de entidade dessa empresa, nas linhas dos lançamentos intercompanhia. Nomeie as contas intercompanhia de modo que "Intercompany" faça parte do nome da conta.

</Steps>

## O que devolver

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O ID do tenant da organização (o Xero o lista na conexão, ou em `GET /connections`) | **ID da organização (tenant)** |
| A confirmação de que o fim do exercício financeiro e a data de bloqueio de períodos da organização estão definidos | Nada a informar: o PlaidCloud lê ambos do Xero |

O usuário do PlaidCloud cola por conta própria o **Token de atualização**; ele é um segredo e nunca é enviado por e-mail. Ele também escolhe a **Organização** com a qual a conexão é carregada.

Em **Configurações do sistema**, **Conta de lucros acumulados** indica a conta de Patrimônio líquido para a qual a demonstração do resultado de abertura é transferida, quando os nomes das contas ainda não deixam isso claro. É opcional.

## Verificar o acesso

De volta ao PlaidCloud, clique em **Testar conexão**. Cada conjunto de dados aparece como **Legível**, **Permissão ausente** ou **Erro**:

| Conjunto de dados | Escopo que ele exige |
|---|---|
| Entidades | `accounting.settings.read` |
| Plano de contas | `accounting.settings.read` |
| Departamentos | `accounting.settings.read` (a categoria de acompanhamento Department) |
| Produtos | `accounting.settings.read` |
| Calendário fiscal | `accounting.settings.read` |
| Clientes | `accounting.contacts.read` |
| Razão geral | `accounting.journals.read` |
| Balancete | `accounting.reports.read` |
| Linhas de vendas (opcional) | `accounting.transactions.read` |
| Orçamento (opcional) | `accounting.reports.read` |

Quando um conjunto de dados mostra **Permissão ausente**, o teste informa o escopo a conceder. Autorize o aplicativo novamente com ele e teste de novo. Uma organização do Xero sem faturas de venda ou orçamentos ainda carrega todo o resto.

As taxas de câmbio não fazem parte deste acesso: o Xero não as publica. Forneça-as em um arquivo de **Taxas de câmbio**.
