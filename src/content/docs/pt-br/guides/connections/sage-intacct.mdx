Conecte o PlaidCloud ao Sage Intacct e extraia dados financeiros e contábeis. Este guia leva você das credenciais de Web Services até uma extração em funcionamento. Para a referência de campos, consulte o [Conector REST do Sage Intacct](/pt-br/reference/connectors/rest/sage-intacct/).

## Pré-requisitos

No Sage Intacct, você precisa de:

- **Web Services** habilitado para a sua empresa: o suporte da Sage provisiona o seu **Sender ID** e a **Sender password**, que se tornam o **ID do cliente** e o **Segredo do cliente** da conexão.
- Um **usuário de serviço web** para o PlaidCloud, com permissões em **todos** os objetos que as suas consultas vão ler.
- O seu **ID da empresa**.

Anote o ID da empresa, o Nome de usuário do usuário de serviço web, o ID do cliente (Sender ID) e o Segredo do cliente (Sender password) antes de começar.

<Aside type="caution">O ID do cliente/Segredo do cliente e o Nome de usuário do usuário de serviço web são distintos. O ID do cliente/Segredo do cliente autenticam o aplicativo na Sage; o Nome de usuário do usuário de serviço web, combinado com o ID da empresa, autentica o login dentro da sua empresa. Os três são obrigatórios, e o ID do cliente/Segredo do cliente são segredos.</Aside>

## Criar a conexão

O Intacct é uma conexão da família **REST**. O PlaidCloud oferece uma variante dedicada **Intacct** (listada como **REST - Intacct**) que preenche previamente o endpoint de token OAuth2 e coleta apenas os quatro campos de credencial abaixo; por baixo dos panos, é uma conexão REST que se autentica com credenciais de cliente OAuth2 na API REST do Intacct.

<Steps>

1. Abra **Tools > Connections** e clique em `New Connection`.

2. Em **REST**, escolha **Intacct** (exibido no menu como **REST - Intacct**).

3. Preencha os campos:

   | Campo | Valor |
   |---|---|
   | Nome | Um nome amigável, por exemplo, `Intacct Prod`. |
   | ID do cliente | O **Sender ID** do seu Intacct. |
   | Segredo do cliente | A **Sender password** do seu Intacct. |
   | Nome de usuário do usuário de serviço web | O login do usuário de Web Services. |
   | ID da empresa | A empresa do Intacct à qual você está se conectando. |

4. Clique em `Create`.

</Steps>

## Testar a conexão

Confirme que as credenciais funcionam antes de construir sobre elas.

<Steps>

1. Adicione uma [etapa Solicitação REST](/pt-br/guides/workflows/rest-request-step/) a um fluxo de trabalho e defina **Conexão** como a sua conexão do Sage Intacct.

2. Aponte-a para uma leitura pequena e limitada de um objeto que o seu usuário possa ver.

3. Clique em **Enviar solicitação de teste**.

</Steps>

<Aside type="caution">
Use **Enviar solicitação de teste**, não a guia Preview. Um resultado verde significa que o ID do cliente/Segredo do cliente e o Nome de usuário do usuário de serviço web foram autenticados. Se ocorrer um erro, a mensagem traz o detalhe da própria Sage, geralmente uma falta de permissão do usuário de Web Services ou um ID do cliente/Segredo do cliente incorreto.
</Aside>

<Aside type="note">
As solicitações do Sage Intacct são de **solicitação única: não há paginação** para configurar. Deixe os controles de paginação como estão.
</Aside>

## Extrair dados

Para extrações de rotina, o Sage Intacct tem etapas de importação dedicadas que mapeiam diretamente para objetos do Intacct:

- [Import Sage AP](/pt-br/reference/workflow-steps/sage-intacct/import-sage-ap/): cabeçalhos de faturas de contas a pagar
- [Import Sage AP Lines](/pt-br/reference/workflow-steps/sage-intacct/import-sage-ap-lines/): detalhe das linhas de faturas de contas a pagar
- [Import Sage Intacct Query](/pt-br/reference/workflow-steps/sage-intacct/import-intacct-query/): uma consulta a qualquer objeto do Intacct
- [Import Intacct Entity](/pt-br/reference/workflow-steps/sage-intacct/import-intacct-entity/): detalhe do razão geral, saldos de contas, lançamentos contábeis, mestres de dimensões (localização, departamento, classe) e documentos de pedidos de venda, com paginação `readMore` automática para grandes conjuntos de resultados e filtros de intervalo `ge`/`le`

Escolha a etapa, selecione a sua conexão do Sage Intacct, defina o objeto ou a consulta e execute. Como em qualquer importação, defina as colunas de valores e datas com seus tipos reais para que cheguem tipadas, e não como texto.

## Verificar e agendar

<Steps>

1. Execute a etapa e verifique a tabela de destino: contagem de linhas e tipos de coluna.

2. Para um feed contínuo, [agende o fluxo de trabalho](/pt-br/get-started/tutorials/schedule-a-workflow/).

</Steps>

## Solução de problemas

| Sintoma | Causa provável |
|---|---|
| Falha de autenticação | Um ID do cliente/Segredo do cliente incorreto (provisionado pela Sage) ou um Nome de usuário do usuário de serviço web incorreto. |
| Erro de permissão / objeto não encontrado | O usuário de Web Services não tem permissão no objeto que está sendo lido. |
| Resultado vazio ou inesperado | Um **ID da empresa** incorreto. |
