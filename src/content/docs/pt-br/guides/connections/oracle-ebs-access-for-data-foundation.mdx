O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas e instâncias de ERP que você conecta em um único Common Finance Model, e o Oracle E-Business Suite é um dos ERPs que ele lê diretamente. O PlaidCloud acessa o EBS por meio de um agente [PlaidLink](/pt-br/reference/cli/plaidlink/) instalado dentro da sua rede, nunca diretamente. Esta página é para o administrador do EBS que faz essa configuração e para o usuário do PlaidCloud que a solicita a ele.

O PlaidCloud apenas lê dados. Ninguém envia uma senha por e-mail.

## Enviar a solicitação de acesso

Na página **Sistemas** do projeto, em **Data Foundation**, no **Início**, escolha seu sistema em **Sistema**, em **Adicionar um sistema**, e clique em **Ainda não tem acesso?**. O sistema fica aguardando acesso, e é exibida uma única solicitação que abrange os sistemas do projeto. Clique em **Copiar solicitação** para colá-la na sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la no seu programa de e-mail com o assunto "Acesso ao PlaidCloud."

## O que o administrador do EBS configura

<Steps>

1. **Instalar o PlaidLink** em um servidor que consiga acessar o banco de dados do EBS e registrá-lo no PlaidCloud.

2. **Criar um usuário de banco de dados somente leitura** para o PlaidLink, nunca o APPS nem qualquer outro usuário de esquema que possa alterar dados. Conceda a ele estes privilégios, cada um com um sinônimo de mesmo nome para o objeto do APPS, SELECT, a menos que a tabela indique o contrário:

   | Área | Objetos |
   |---|---|
   | Sessão (obrigatório) | EXECUTE em `FND_GLOBAL` e `MO_GLOBAL`; `FND_RESPONSIBILITY_VL`; e `FND_USER`, ou uma visão dela com esse nome contendo apenas `USER_ID`, `USER_NAME`, `EMPLOYEE_ID` e `DESCRIPTION`. Sem eles, todas as leituras falham |
   | Razão geral | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES`. `GL_BALANCES` deve conter todos os períodos, não apenas o mais recente: é o saldo de fim de mês com o qual o razão é comparado |
   | Flexfields | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | Vendas (opcional) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |
   | Aprovador de lançamentos (opcional) | `GL_JE_BATCHES` |
   | País da entidade (opcional) | `XLE_REGISTRATIONS`, `HZ_LOCATIONS` |
   | Contas a receber, contas a pagar, saldos bancários e faturas de fornecedor (opcional) | `AR_PAYMENT_SCHEDULES_ALL`, `AR_CASH_RECEIPTS_ALL`, `AR_RECEIVABLE_APPLICATIONS_ALL`, `AR_ADJUSTMENTS_ALL`, `AR_RECEIPT_METHODS`, `RA_TERMS_TL`, `CE_BANK_ACCOUNTS`, `AP_INVOICES_ALL`, `AP_INVOICE_LINES_ALL`, `AP_INVOICE_DISTRIBUTIONS_ALL`, `AP_PAYMENT_SCHEDULES_ALL`, `AP_INVOICE_PAYMENTS_ALL`, `AP_CHECKS_ALL`, `AP_SUPPLIERS`, `AP_SUPPLIER_SITES_ALL`, `AP_TERMS_TL`, `PO_HEADERS_ALL`, `PO_LINES_ALL`, `MTL_ITEM_CATEGORIES`, `MTL_CATEGORIES_B` |
   | Compras, estoque, orçamentos, custos padrão e ativos imobilizados (opcional) | `PO_LINE_LOCATIONS_ALL`, `PO_DISTRIBUTIONS_ALL`, `RCV_TRANSACTIONS`, `ORG_ORGANIZATION_DEFINITIONS`, `MTL_MATERIAL_TRANSACTIONS`, `MTL_SECONDARY_INVENTORIES`, `CST_STANDARD_COSTS`, `GL_BUDGETS`, `GL_BUDGET_VERSIONS`, `FA_ADDITIONS_B`, `FA_ADDITIONS_TL`, `FA_CATEGORIES_B`, `FA_BOOK_CONTROLS`, `FA_BOOKS`, `FA_CATEGORY_BOOKS`, `FA_DISTRIBUTION_HISTORY`, `FA_DEPRN_PERIODS`, `FA_DEPRN_SUMMARY`, `FA_RETIREMENTS`, `FA_TRANSACTION_HEADERS` |

   O estoque é lido das transações de material, então o histórico dele exige que elas sejam mantidas. Os orçamentos são os saldos de orçamento em `GL_BALANCES`.

3. **Indicar um usuário do aplicativo** (`FND_USER`) e uma responsabilidade de consulta, que possa apenas visualizar, e que enxergue todos os razões e todos os valores de segmento de balanceamento que você quer reportar.

4. **Descrever o plano de contas.** Diga quais segmentos são o segmento de balanceamento, a conta natural, o centro de custo e o segmento intercompanhia (os qualificadores de segmento deles). O PlaidCloud classifica uma conta de despesa como custo das mercadorias vendidas quando ela, ou um valor pai acima dela, é descrita como custo das mercadorias vendidas, custo de vendas ou custo da receita. Ele classifica uma conta como não operacional quando uma delas cita receita ou despesa de juros, receita ou custo financeiro, câmbio, despesa de imposto de renda, ou outras receitas e despesas. Informe ao PlaidCloud se os seus valores pai usam outras palavras para isso.

5. **Indicar os segmentos de site e de centro de lucro**, se você mantém sites ou centros de lucro em um segmento do plano de contas (`SEGMENT1` a `SEGMENT30`). O EBS não tem qualificador para nenhum deles. O PlaidCloud lê os valores do conjunto de valores de cada segmento como as listas de sites e de centros de lucro.

6. **Confirmar os tipos de taxa.** Cada razão primário nomeia os tipos de taxa de média do período e de fim do período, nas opções de conversão do razão. O PlaidCloud converte com as taxas diárias desses dois tipos.

</Steps>

<Aside type="caution">
A responsabilidade errada retorna as linhas de outro razão sem nenhum erro. Confirme-a com o responsável pelo seu razão geral.
</Aside>

## O que devolver

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O host do banco de dados | **Host ou endereço IP** |
| A porta do banco de dados | **Porta** (1521, a menos que você a altere) |
| O nome do serviço | **Nome do serviço** |
| O usuário de banco de dados somente leitura | **Usuário do banco de dados (esquema APPS)** |
| A senha dele, pelo formulário de conexão seguro | **Senha**, que a sua equipe informa por conta própria |
| O `FND_USER` | **Usuário do aplicativo (FND_USER.USER_NAME)** |
| A chave da responsabilidade | **Chave de responsabilidade (FND_RESPONSIBILITY.RESPONSIBILITY_KEY)** |
| Os valores de segmento de balanceamento que o PlaidCloud pode ler | Em **Opções**, **Empresas**, que o EBS não consegue listar: informe os valores, separados por vírgulas, ou deixe vazio para carregar todas as entidades de cada razão primário |

O agente PlaidLink que acessa a instância é indicado na configuração do sistema **PlaidLink agent**. Os segmentos de site e de centro de lucro vão nas configurações do sistema **Site segment** e **Profit centre segment**.

<Aside type="caution">
Nunca envie a senha por e-mail. A **Senha** é um segredo: ela é armazenada na conexão e nunca mais exibida.
</Aside>

## Verificar o acesso

De volta ao PlaidCloud, depois de adicionar o sistema, clique em **Testar conexão** na linha dele na página **Sistemas**. Como o EBS é acessado pelo agente PlaidLink, o teste verifica se a conexão indica tudo aquilo com que o agente entra. As próprias tabelas são lidas na primeira carga, e uma tabela que o agente não pode ler é indicada nesse momento. Cada conjunto de dados lê:

| Conjunto de dados | Objetos que ele lê |
|---|---|
| Entidades | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| Calendário fiscal | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| Plano de contas | `GL_CODE_COMBINATIONS`, as tabelas de flexfield |
| Departamentos | `GL_CODE_COMBINATIONS`, as tabelas de flexfield |
| Taxas de câmbio | `GL_DAILY_RATES` |
| Razão geral | `GL_JE_HEADERS`, `GL_JE_LINES` |
| Balancete | `GL_BALANCES` |
| Clientes | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES` (opcional) |
| Produtos | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` (opcional) |
| Linhas de vendas | As tabelas `RA_CUSTOMER_TRX` (opcional) |
| Saldo de fim de mês | `GL_BALANCES`, todos os períodos (opcional) |
| Saldos bancários | `CE_BANK_ACCOUNTS`, com o saldo de fim de mês da conta de caixa de cada banco (opcional) |
| Sites, Centros de lucro | Os valores do segmento que você indicar para cada um (opcional) |
| Fornecedores | `AP_SUPPLIERS`, `AP_SUPPLIER_SITES_ALL`, `AP_TERMS_TL` (opcional) |
| Itens em aberto, Pagamentos | As tabelas de contas a receber, de contas a pagar e de bancos (opcional) |
| Linhas de faturas de fornecedor | `AP_INVOICE_LINES_ALL`, com os documentos de contas a pagar (opcional) |
| Pedidos de compra | As tabelas `PO_`, `RCV_TRANSACTIONS` e as linhas de fatura (opcional) |
| Saldos de estoque | `MTL_MATERIAL_TRANSACTIONS`, `MTL_SECONDARY_INVENTORIES` (opcional) |
| Custos padrão | `CST_STANDARD_COSTS` (opcional) |
| Orçamento | Saldos de orçamento em `GL_BALANCES`, `GL_BUDGETS`, `GL_BUDGET_VERSIONS` (opcional) |
| Ativos imobilizados, Movimentações de ativos | As tabelas `FA_` (opcional) |

Quando uma carga indicar uma tabela que o agente não pode ler, peça ao administrador que conceda SELECT nela e carregue novamente. Uma tabela opcional que você não concede gera um aviso que a indica, e todo o resto é carregado. Itens em aberto, pagamentos, faturas de fornecedor, pedidos de compra, custos padrão, estoque, orçamentos, ativos e os saldos de fim de mês e bancários mantêm as linhas que já tinham até que a tabela possa ser lida.
