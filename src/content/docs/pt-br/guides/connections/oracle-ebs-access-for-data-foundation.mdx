O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas e instâncias de ERP que você conecta em um único Common Finance Model, e o Oracle E-Business Suite é um dos ERPs que ele lê diretamente. O PlaidCloud acessa o EBS por meio de um agente [PlaidLink](/pt-br/reference/cli/plaidlink/) instalado dentro da sua rede, nunca diretamente. Esta página é para o administrador do EBS que faz essa configuração e para o usuário do PlaidCloud que a solicita a ele.

O PlaidCloud apenas lê dados. Ninguém envia uma senha por e-mail.

## Enviar a solicitação de acesso

Na guia **Foundation** do projeto, escolha **Criar uma nova conexão** em **Conexão do Oracle E-Business Suite**. O formulário mostra a solicitação completa e um link **How to set up PlaidLink**. Clique em **Copiar solicitação** para colá-la na sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la no seu programa de e-mail com o assunto "Read-only Oracle E-Business Suite access for PlaidCloud (through PlaidLink)."

## O que o administrador do EBS configura

<Steps>

1. **Instalar o PlaidLink** em um servidor que consiga acessar o banco de dados do EBS e registrá-lo no PlaidCloud.

2. **Conceder SELECT** ao usuário do esquema APPS do PlaidLink (ou a um usuário de esquema somente leitura com sinônimos para os objetos do APPS) em:

   | Área | Objetos |
   |---|---|
   | Razão geral | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES` |
   | Flexfields | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | Vendas (opcional) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |

3. **Indicar um usuário do aplicativo** (`FND_USER`) e uma responsabilidade que enxergue todos os razões e todos os valores de segmento de balanceamento que você quer reportar.

4. **Descrever o plano de contas.** Diga quais segmentos são o segmento de balanceamento, a conta natural, o centro de custo e o segmento intercompanhia (os qualificadores de segmento deles). O PlaidCloud classifica uma conta de despesa como custo das mercadorias vendidas quando ela, ou um valor pai acima dela, é descrita como custo das mercadorias vendidas, custo de vendas ou custo da receita. Ele classifica uma conta como não operacional quando uma delas cita receita ou despesa de juros, receita ou custo financeiro, câmbio, despesa de imposto de renda, ou outras receitas e despesas. Informe ao PlaidCloud se os seus valores pai usam outras palavras para isso.

5. **Confirmar os tipos de taxa.** Cada razão primário nomeia os tipos de taxa de média do período e de fim do período, nas opções de conversão do razão. O PlaidCloud converte com as taxas diárias desses dois tipos.

</Steps>

<Aside type="caution">
A responsabilidade errada retorna as linhas de outro razão sem nenhum erro. Confirme-a com o responsável pelo seu razão geral.
</Aside>

## O que devolver

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O host do banco de dados | **Host do banco de dados** |
| A porta do banco de dados | **Porta do banco de dados** (1521, a menos que você a altere) |
| O nome do serviço | **Nome do serviço** |
| O usuário do esquema APPS | **Usuário do esquema APPS** |
| A senha do esquema APPS, pelo formulário de conexão seguro | **Senha do esquema APPS**, que a sua equipe cola por conta própria |
| O `FND_USER` | **Usuário do aplicativo (FND_USER)** |
| A chave da responsabilidade | **Chave da responsabilidade** |
| Os valores de segmento de balanceamento que o PlaidCloud pode ler | Em **Valores de segmento de balanceamento**, que o sistema não consegue listar antes de uma carga: informe um valor em **Nome** ou deixe em branco para carregar todas as entidades do razão primário |

O agente PlaidLink que acessa a instância é escolhido nas configurações do sistema como `agent`.

<Aside type="caution">
Nunca envie a senha por e-mail. A **Senha do esquema APPS** é um segredo: ela é armazenada na conexão e nunca mais exibida.
</Aside>

## Verificar o acesso

De volta ao PlaidCloud, informe os valores e clique em **Testar conexão**. Cada conjunto de dados aparece como **Legível**, **Permissão ausente** ou **Erro**:

| Conjunto de dados | Objetos que ele lê |
|---|---|
| Entidades | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| Calendário fiscal | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| Plano de contas | `GL_CODE_COMBINATIONS`, as tabelas de flexfield |
| Departamentos | `GL_CODE_COMBINATIONS`, as tabelas de flexfield |
| Taxas de câmbio | `GL_DAILY_RATES` |
| Razão geral | `GL_JE_HEADERS`, `GL_JE_LINES` |
| Balancete | `GL_BALANCES` |
| Clientes | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES` (opcional) |
| Produtos | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` (opcional) |
| Linhas de vendas | As tabelas `RA_CUSTOMER_TRX` (opcional) |

Quando um conjunto de dados mostra **Permissão ausente**, peça ao administrador que conceda SELECT nos objetos e teste novamente. Clientes, produtos e linhas de vendas são opcionais: uma instância que não os usa ainda carrega todo o resto.
