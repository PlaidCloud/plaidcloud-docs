O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas e instâncias de ERP que você conecta em um único Common Finance Model, e o SAP S/4HANA Cloud é um dos ERPs que ele lê diretamente. A conexão lê os serviços OData liberados do tenant com credenciais de cliente OAuth 2.0; nenhum agente está envolvido. Esta página é para o administrador do S/4HANA Cloud que faz essa configuração e para o usuário do PlaidCloud que a solicita a ele.

O PlaidCloud apenas lê dados. Ninguém envia uma senha ou um segredo do cliente por e-mail.

## Enviar a solicitação de acesso

Na guia **Foundation** do projeto, escolha **Criar uma nova conexão** em **Conexão do SAP S/4HANA Cloud**. O formulário mostra a solicitação completa. Clique em **Copiar solicitação** para colá-la na sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la no seu programa de e-mail com o assunto "Read-only SAP S/4HANA Cloud access for PlaidCloud (OAuth 2.0 client credentials)."

## O que o administrador do S/4HANA Cloud configura

<Steps>

1. **Criar um usuário de comunicação** para o PlaidCloud, no aplicativo **Maintain Communication Users**. O método de autenticação dele é OAuth 2.0 ou nome de usuário e senha, conforme o seu ambiente exigir.

2. **Criar um sistema de comunicação** para o PlaidCloud, no aplicativo **Communication Systems**, com esse usuário para comunicação de entrada e com credenciais de cliente OAuth 2.0.

3. **Criar um acordo de comunicação** para cada cenário abaixo, no aplicativo **Communication Arrangements**, todos para o sistema da etapa 2. Juntos, eles expõem os serviços OData que o PlaidCloud lê:

   | Cenário | Serviço |
   |---|---|
   | Código da empresa | `API_COMPANYCODE_SRV` |
   | Conta do razão no plano de contas | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | Centro de custo | `API_COSTCENTER_SRV` |
   | Parceiro de negócios e cliente | `API_BUSINESS_PARTNER` |
   | Produto | `API_PRODUCT_SRV` |
   | Períodos da variante de ano fiscal | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | Taxas de câmbio | `API_EXCHANGERATE_SRV` |
   | Item de lançamento contábil | `API_JOURNALENTRYITEMBASIC_SRV` (o diário e o saldo transportado) |
   | Documento de faturamento | `API_BILLING_DOCUMENT_SRV` (opcional: acrescenta vendas faturadas, documentos e itens) |

   Dê ao usuário de comunicação acesso a todos os códigos de empresa sobre os quais você gera relatórios.

</Steps>

## O que devolver

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O host da API do tenant, por exemplo `my300000-api.s4hana.cloud.sap` | **Host** |
| O ID do cliente | **ID do cliente** |
| O segredo do cliente, pelo formulário de conexão seguro | **Segredo do cliente**, que a sua equipe cola por conta própria |
| O URL do token, somente se o seu ambiente usar um servidor de autorização XSUAA em vez do próprio do tenant (`/sap/bc/sec/oauth2/token`) | **URL do token (opcional)** |
| O escopo, somente com um servidor de autorização XSUAA | **Escopo (opcional)** |
| Se o **Carry Forward Balances** foi executado para cada ano fiscal que você carrega | Nada a informar. Os saldos de abertura são lidos dele. |

<Aside type="caution">
Nunca envie o segredo do cliente por e-mail. O **Segredo do cliente** é um segredo: ele é armazenado na conexão e nunca mais exibido.
</Aside>

## Verificar o acesso

De volta ao PlaidCloud, informe os valores e clique em **Testar conexão**. Cada conjunto de dados aparece como **Legível**, **Permissão ausente** ou **Erro**:

| Conjunto de dados | Serviço que ele exige |
|---|---|
| Entidades | `API_COMPANYCODE_SRV` |
| Plano de contas | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| Departamentos | `API_COSTCENTER_SRV` |
| Clientes | `API_BUSINESS_PARTNER` |
| Produtos | `API_PRODUCT_SRV` |
| Taxas de câmbio | `API_EXCHANGERATE_SRV` |
| Calendário fiscal | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| Razão geral | `API_JOURNALENTRYITEMBASIC_SRV` |
| Balancete | `API_JOURNALENTRYITEMBASIC_SRV` |
| Linhas de vendas | `API_BILLING_DOCUMENT_SRV` (opcional) |

Quando um conjunto de dados mostra **Permissão ausente**, peça ao administrador que adicione o acordo de comunicação do serviço correspondente e teste novamente. Linhas de vendas, orçamento e saldos de estoque são opcionais: um tenant que não contém algum deles ainda carrega todo o resto.
