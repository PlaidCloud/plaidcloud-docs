O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas e instâncias de ERP que você conecta em um único Common Finance Model, e o Microsoft Dynamics 365 Business Central é um dos ERPs que ele lê diretamente. A conexão usa um aplicativo do Microsoft Entra ID com credenciais de cliente, um conjunto de permissões somente leitura e algumas páginas publicadas como web services. Esta página é para o administrador do Business Central que faz essa configuração e para o usuário do PlaidCloud que a solicita a ele.

O PlaidCloud apenas lê dados. Ninguém envia um segredo do cliente por e-mail.

## Enviar a solicitação de acesso

Na guia **Foundation** do projeto, escolha **Criar uma nova conexão** em **Conexão do Business Central**. O formulário mostra a solicitação completa. Clique em **Copiar solicitação** para colá-la na sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la no seu programa de e-mail com o assunto "Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials)."

## O que o administrador do Business Central configura

<Steps>

1. **Registrar um aplicativo no Microsoft Entra ID.** Em **App registrations > New registration**, adicione um segredo do cliente e anote o ID do diretório (tenant), o ID do aplicativo (cliente) e o segredo.

2. **Adicionar o aplicativo no Business Central.** Abra **Microsoft Entra Applications**, adicione o aplicativo, defina o estado dele como **Ativado** e atribua a ele os conjuntos de permissões **D365 READ** e **D365 BASIC** para cada empresa sobre a qual você gera relatórios. Não atribua um conjunto de permissões de gravação.

3. **Publicar páginas como web services.** Em **Search > Web Services > New**, publique estas páginas com exatamente estes nomes de serviço e com **Published** marcado. A API padrão não traz os campos delas:

   | Página | Nome do serviço | Observações |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | Custo das mercadorias vendidas; opcional |
   | 120 G/L Budget Entries | `GLBudgetEntries` | Orçamentos; opcional |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | Direcionadores estatísticos; opcional |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | Dimensões de atalho 3 a 8; opcional |
   | 479 Dimension Set Entries | `DimensionSetEntries` | Dimensões de atalho 3 a 8; opcional |

4. **Informar ao usuário do PlaidCloud duas escolhas:** o código de origem sob o qual seus ajustes de auditoria são lançados (o PlaidCloud presume `ADJUSTMENT`) e qual dimensão é o seu departamento (o PlaidCloud presume a Global Dimension 1, chamada `DEPARTMENT`).

</Steps>

## O que devolver

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O ID do diretório (tenant) | **ID do diretório (tenant)** |
| O nome do ambiente, por exemplo `production` | **Nome do ambiente** |
| O ID do aplicativo (cliente) | **ID do aplicativo (cliente)** |
| O segredo do cliente | **Segredo do cliente**, informado pelo formulário, não por e-mail |
| O nome da dimensão que é o seu departamento | A configuração de sistema `department_dimension` |
| As empresas que o PlaidCloud pode ler | Escolhidas em **Empresas** no PlaidCloud (pelo menos uma) |

As empresas que são empresas de consolidação vão na configuração de sistema `consolidation_companies`, para que os lançamentos delas não sejam contados como atividade de uma empresa. As taxas de câmbio vêm de uma única empresa: indique-a na configuração de sistema `rate_company`, ou o PlaidCloud usa a primeira empresa.

## Verificar o acesso

De volta ao PlaidCloud, informe os valores e clique em **Testar conexão**. Cada conjunto de dados aparece como **Legível**, **Permissão ausente** ou **Erro**:

| Conjunto de dados | O que ele exige |
|---|---|
| Entidades, Plano de contas, Clientes, Produtos, Taxas de câmbio, Balancete | Acesso à API (conjunto de permissões D365 READ) |
| Calendário fiscal | O web service `AccountingPeriods` |
| Departamentos | O web service `DimensionValues` |
| Razão geral | O web service `GLEntries` |
| Linhas de vendas, Orçamento, Direcionadores de alocação | Opcional |

Quando falta um conjunto de dados, o teste informa qual permissão ou web service adicionar. Peça ao administrador que o adicione e teste novamente. Linhas de vendas, Orçamento e Direcionadores de alocação são opcionais: um ambiente que não os usa ainda carrega todo o resto.
