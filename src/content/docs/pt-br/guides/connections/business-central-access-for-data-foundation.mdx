O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas ERP e instâncias que você conecta em um único Common Finance Model, e o Microsoft Dynamics 365 Business Central é um dos ERPs que ele lê diretamente. A conexão usa um aplicativo do Microsoft Entra ID com credenciais de cliente, um conjunto de permissões somente leitura e alguns objetos de página publicados como serviços web. Esta página é destinada ao administrador do Business Central que faz essa configuração e ao usuário do PlaidCloud que solicita isso a ele.

O PlaidCloud apenas lê dados. Ninguém envia um segredo do cliente por e-mail.

## Enviar a solicitação de acesso

Na guia **Foundation** do projeto, escolha **Criar uma nova conexão** em **Conexão do Business Central**. O formulário mostra a solicitação completa. Clique em **Copiar solicitação** para colá-la em sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la em seu programa de e-mail, com o assunto "Acesso somente leitura ao Business Central para o PlaidCloud (Microsoft Entra ID, credenciais de cliente)."

## O que o administrador do Business Central configura

<Steps>

1. **Registre um aplicativo no Microsoft Entra ID.** Em **App registrations > New registration**, adicione um segredo do cliente e anote o ID do diretório (tenant), o ID do aplicativo (cliente) e o segredo.

2. **Adicione o aplicativo no Business Central.** Abra **Microsoft Entra Applications**, adicione o aplicativo, defina seu estado como **Ativado** e atribua a ele os conjuntos de permissões **D365 READ** e **D365 BASIC** para cada empresa sobre a qual você gera relatórios. Não atribua a ele um conjunto de permissões de gravação.

3. **Publique objetos de página como serviços web.** Em **Search > Web Services > New**, publique estes objetos de página exatamente com estes nomes de serviço e com **Published** marcado. A API padrão não inclui os campos deles:

   | Página | Nome do serviço | Observações |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | Custo dos produtos vendidos; opcional |
   | 120 G/L Budget Entries | `GLBudgetEntries` | Orçamentos; opcional |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | Direcionadores estatísticos; opcional |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | Dimensões de atalho 3 a 8; opcional |
   | 479 Dimension Set Entries | `DimensionSetEntries` | Dimensões de atalho 3 a 8; opcional |

4. **Informe ao usuário do PlaidCloud duas escolhas:** o código de origem sob o qual seus ajustes de auditoria são lançados (o PlaidCloud presume `ADJUSTMENT`) e qual dimensão representa seu departamento (o PlaidCloud presume a Global Dimension 1, chamada `DEPARTMENT`).

</Steps>

## O que enviar de volta

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O ID do diretório (tenant) | **Directory (tenant) ID** |
| O nome do ambiente, por exemplo `production` | **Nome do ambiente** |
| O ID do aplicativo (cliente) | **Application (client) ID** |
| O segredo do cliente | **Segredo do cliente**, informado pelo formulário, não por e-mail |
| O nome da dimensão que representa seu departamento | A configuração de sistema `department_dimension` |
| As empresas que o PlaidCloud pode ler | Escolhidas em **Companies** no PlaidCloud (pelo menos uma) |

As empresas de consolidação entram na configuração de sistema `consolidation_companies`, para que seus lançamentos não sejam contados como atividade de uma empresa. As taxas de câmbio vêm de uma única empresa. Indique-a na configuração de sistema `rate_company`; caso contrário, o PlaidCloud usa a primeira empresa.

## Verificar o acesso

De volta ao PlaidCloud, informe os valores e clique em **Testar conexão**. Cada conjunto de dados aparece como **Legível**, **Permissão ausente** ou **Erro**:

| Conjunto de dados | O que ele exige |
|---|---|
| Entidades, Plano de contas, Clientes, Produtos, Taxas de câmbio, Balancete | Acesso à API (conjunto de permissões D365 READ) |
| Calendário fiscal | O serviço web `AccountingPeriods` |
| Departamentos | O serviço web `DimensionValues` |
| Razão geral | O serviço web `GLEntries` |
| Linhas de vendas, Orçamento, Direcionadores de alocação | Opcional |

Quando falta um conjunto de dados, o teste informa qual permissão ou serviço web adicionar. Peça ao administrador que o adicione e teste novamente. Linhas de vendas, Orçamento e Direcionadores de alocação são opcionais: um ambiente que não os usa ainda carrega todo o restante.
