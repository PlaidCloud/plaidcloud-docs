O [Data Foundation](/pt-br/guides/projects/data-foundation/) reúne os dados de todos os sistemas e instâncias de ERP que você conecta em um único Common Finance Model, e o SAP ECC é um dos ERPs que ele lê diretamente. O PlaidCloud acessa o sistema por meio de um agente [PlaidLink](/pt-br/reference/cli/plaidlink/) instalado na sua própria rede, via RFC. Esta página é para o administrador do SAP que faz essa configuração e para o usuário do PlaidCloud que a solicita a ele.

O PlaidCloud apenas lê dados. Ninguém envia uma senha por e-mail.

## Enviar a solicitação de acesso

Na página **Sistemas** do projeto, em **Data Foundation**, no **Início**, escolha seu sistema em **Sistema**, em **Adicionar um sistema**, e clique em **Ainda não tem acesso?**. O sistema fica aguardando acesso, e é exibida uma única solicitação que abrange os sistemas do projeto. Clique em **Copiar solicitação** para colá-la na sua própria mensagem ou em **Enviar solicitação por e-mail** para abri-la no seu programa de e-mail com o assunto "Acesso ao PlaidCloud."

## O que o administrador do SAP configura

<Steps>

1. **Instalar o pacote ABAP do PlaidCloud** (grupo de funções de `Z_PLAIDCL_B5_READ_TABLE`) no mandante a partir do qual você gera relatórios e instalar um agente PlaidLink que consiga acessar o sistema via RFC.

2. **Criar um usuário de comunicação**, por exemplo `PLAIDCLOUD_RFC`, com uma função que contenha estas autorizações:

   - `S_RFC`: executar o grupo de funções de `Z_PLAIDCL_B5_READ_TABLE`.
   - `S_TABU_NAM` (exibir, `ACTVT` 03) para as tabelas abaixo.

   | Tabelas | O que elas contêm |
   |---|---|
   | `T001` | Códigos da empresa |
   | `T009`, `T009B`, `T001B` | Variantes de ano fiscal e períodos de lançamento |
   | `SKA1`, `SKAT` | Contas do razão |
   | `FAGL_011PC`, `FAGL_011ZC` | Versão de demonstrações financeiras |
   | `CSKS`, `CSKT` | Centros de custo |
   | `SETHEADER`, `SETNODE` | Grupos de centros de custo e de centros de lucro |
   | `CEPC`, `CEPCT` | Centros de lucro (opcional) |
   | `KNA1`, `KNVV`, `KNVH` | Clientes e sua hierarquia |
   | `MARA`, `MAKT`, `T006A` | Materiais e unidades |
   | `TCURR`, `TCURF`, `TCURX` | Taxas de câmbio e casas decimais das moedas |
   | `BKPF`, `BSEG` | Documentos contábeis e seus itens de linha |
   | `FAGLFLEXT`, ou, no razão geral clássico, `GLT0` | Totais do razão geral |
   | `CSKB`, `CSKU`, `COEP` | Elementos de custo e itens de linha de controladoria: rateios e alocações |
   | `COSP`, `COSS`, `COSR` | Planejamento de centros de custo e indicadores estatísticos (opcional) |
   | `VBRK`, `VBRP`, `KONV` | Documentos de faturamento e suas condições de preço (opcional) |
   | `T001K`, `MBEW`, `MBEWH` | Áreas de avaliação, valores de estoque de materiais e preços padrão (opcional) |
   | `T001W`, `TKA02` | Centros, lidos como sites, e a área de contabilidade de custos de cada código da empresa (opcional) |
   | `T016T`, `TKUKT`, `KNVP`, `TSPAT`, `T052U` | Nomes de ramos de atividade e de classificações de clientes, o funcionário de vendas de cada cliente e nomes de setores de atividade e de condições de pagamento (opcional) |
   | `T012K`, `T012T` | Contas de bancos da empresa, para saldos bancários (opcional) |
   | `LFA1`, `LFB1` | Fornecedores (opcional) |
   | `RBKP`, `RSEG` | Faturas de fornecedor (opcional) |
   | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` | Pedidos de compra e seus recebimentos e faturas (opcional) |
   | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095`, `ANLC`, `ANEP`, `ANEA`, `ANLP` | O registro de ativos imobilizados e suas movimentações (opcional) |
   | A tabela de itens de linha da área de resultado (`CE1` seguido do nome dela) | CO-PA por avaliação (opcional) |

   Os itens em aberto e os pagamentos são lidos dos itens de linha de clientes e de fornecedores do `BSEG`, com os cabeçalhos `BKPF` deles.

3. **Responder às perguntas contábeis** (veja abaixo).

</Steps>

### Perguntas que o administrador responde

| O administrador informa a você | Você informa no PlaidCloud em **Configurações do sistema** |
|---|---|
| O tipo de taxa de câmbio que contém a taxa média. O PlaidCloud calcula a média das taxas desse tipo em cada mês. Costuma ser `M`. | **Average rate type** |
| O tipo de taxa de câmbio que contém a taxa de fechamento, a taxa no fim do mês. Se você não indicar nenhum, a taxa de fechamento é a taxa `M`. | **Closing rate type** |
| Se o sistema executa o novo razão geral (`FAGLFLEXT`) ou o clássico (`GLT0`) | **General ledger totals table** |
| A versão de demonstrações financeiras que reporta a DRE gerencial e o balanço patrimonial | **Financial statement version** |
| Quais dos nós dela são receita, custo das mercadorias vendidas, despesa operacional, não operacional, ativo, passivo, patrimônio líquido e intercompanhia | **Account type of each statement node**: uma linha por nó, no formato `node = type`, com um tipo que a caixa lista, como `Revenue` ou `Asset`. **Intercompany statement nodes** indica os nós intercompanhia. Ambos só se aplicam quando **Financial statement version** está definido. |
| Que a transferência de saldos para o novo exercício foi executada para cada ano fiscal sobre o qual você gera relatórios (`FAGLGVTR`, ou `F.16` no razão geral clássico) | Nada a informar. Os saldos de abertura são lidos da tabela de totais. |
| A área de depreciação de cada livro de ativos, contábil ou fiscal. A primeira é a do registro. O PlaidCloud presume que a área `01` é o livro contábil. | **Depreciation area of each book** |
| O tipo de movimento de cada tipo de transação de ativo, pelo primeiro dígito. O PlaidCloud presume `1` aquisição, `2` baixa, `3` transferência, `6` depreciação e `9` abertura. | **Movement type of each transaction type** |
| A tabela de itens de linha da área de resultado, se você quiser CO-PA por avaliação. Sem nenhuma indicada, nenhum CO-PA é lido. | **Operating concern line item table** |
| O campo de valor CO-PA de cada conta e quais deles são custos | **Value field of each CO-PA account**, **CO-PA cost value fields** |

## O que devolver

| O administrador envia | Informado no PlaidCloud como |
|---|---|
| O ID do sistema e o servidor de aplicação (ou servidor de mensagens e grupo de logon) | **Host** e **Número do sistema** ou, com **Usar conexão de vários sistemas com balanceamento de carga**, **Host MS**, **Servidor MS**, **ID do sistema** e **Grupo** |
| O mandante | **Cliente** |
| O nome do usuário de comunicação | **Usuário** |
| A senha do usuário de comunicação, pelo seu gerenciador de senhas | **Senha**, que a sua equipe informa por conta própria |
| O nome do agente PlaidLink que acessa o sistema | A configuração do sistema **PlaidLink agent** |
| Os códigos da empresa que o PlaidCloud pode ler | Em **Opções**, **Empresas**, que o SAP não consegue listar: informe os códigos da empresa, separados por vírgulas, ou deixe vazio para carregar todos os códigos da empresa |

<Aside type="caution">
Nunca envie a senha por e-mail. A **Senha** é um segredo: ela é armazenada na conexão e nunca mais exibida.
</Aside>

## Verificar o acesso

O SAP é lido por um agente PlaidLink, então o **Testar conexão** não o lê: a primeira carga lê e indica uma tabela que o usuário não pode ler. Cada conjunto de dados lê:

| Conjunto de dados | Tabelas que ele lê |
|---|---|
| Entidades | `T001` |
| Calendário fiscal | `T001`, `T009`, `T009B`, `T001B` |
| Taxas de câmbio | `TCURR`, `TCURF` |
| Plano de contas | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC`, `CSKB`, `CSKU` |
| Departamentos | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| Centros de lucro | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| Clientes | `KNA1`, `KNVV`, `KNVH` |
| Produtos | `MARA`, `MAKT`, `T006A` |
| Razão geral | `BKPF`, `BSEG`, `COEP` |
| Balancete | `FAGLFLEXT` ou `GLT0` |
| Linhas de vendas | `VBRK`, `VBRP`, `KONV` |
| Orçamento | `COSP`, `COSS` |
| Direcionadores de alocação | `COSR` |
| Saldos de estoque | `MBEW`, `MBEWH`, `T001K` |
| Saldo de fim de mês | `FAGLFLEXT` ou `GLT0`, o saldo em cada fim de mês |
| Saldos bancários | `T012K`, `T012T`, com o saldo de fim de mês da conta do razão de cada banco da empresa |
| Sites | `T001W`, `T001K` |
| Fornecedores | `LFA1`, `LFB1` |
| Linhas de faturas de fornecedor | `RBKP`, `RSEG`, `BKPF` |
| Pedidos de compra | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` |
| Itens em aberto, Pagamentos | Itens de linha de clientes e de fornecedores do `BSEG`, `BKPF` |
| Ativos imobilizados | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095` |
| Movimentações de ativos | `ANLC`, `ANEP`, `ANEA`, `ANLP` |
| Custos padrão | `T001K`, `MBEW`, `MBEWH` |
| CO-PA por avaliação | A tabela indicada em **Operating concern line item table** |

Quando uma carga indicar uma tabela que o usuário não pode ler, peça ao administrador que a adicione à função e carregue novamente. Centros de lucro, linhas de vendas, orçamento, direcionadores de alocação, saldos de estoque e todos os conjuntos de dados a partir de saldo de fim de mês são opcionais: um sistema que não contém algum deles ainda carrega todo o resto. Os saldos bancários, os itens em aberto ou os pagamentos de um mês que o SAP recusar mantêm as linhas que já tinham.

As contas de bancos da empresa que compartilham uma conta do razão têm uma única linha de saldo entre elas, pois a conta do razão tem um único saldo.
