## Descrição

O navegador de documentos inclui uma barra de pesquisa na parte superior da lista de arquivos. As pesquisas são executadas em tempo real no back-end conectado (S3, Azure Blob, Google Drive, OneDrive etc.), de modo que os resultados refletem o estado atual da conta, e não um índice desatualizado.


## Executar uma pesquisa

1. Abra uma conta de documentos
2. Clique no campo **Pesquisar arquivos…** na parte superior da lista de arquivos
3. Digite um padrão de nome
4. Acompanhe os resultados chegando à lista de arquivos

Pressione `Esc` ou clique no ícone de limpar no final do campo para sair do modo de pesquisa e voltar à lista de arquivos normal. A linha de status abaixo do campo mostra quantas pastas foram verificadas e quantas correspondências foram encontradas.


## Filtros avançados

Clique em `Advanced` ao lado do campo de pesquisa para exibir a linha de filtros. Combine qualquer um destes filtros com o padrão de nome:

* **Ext.:** extensões separadas por vírgula, por exemplo `pdf,xlsx`. Sem espaços.
* **Tipo:** `Files & folders` (padrão), `Files only` ou `Folders only`.
* **Tamanho (bytes):** tamanho mínimo e/ou máximo.
* **Modificado:** a partir de uma data e/ou até uma data, ambas no formato `YYYY-MM-DD`.

Os filtros se aplicam sobre o padrão de nome. Clique em `Clear` para apagar a consulta e todos os filtros.


## Destaque e exibição na pasta

* Enquanto a pesquisa está em execução, os resultados chegam em ordem de chegada, para que você possa agir sobre as primeiras correspondências sem esperar.
* Quando o fluxo termina, a lista de arquivos é reordenada por nome e o trecho correspondente é destacado em cada linha.
* Clique com o botão direito em qualquer resultado e selecione `Reveal in folder` para ir até o arquivo no diretório que o contém e sair do modo de pesquisa.


## Pesquisar em vários back-ends

A pesquisa usa a API de pesquisa do próprio back-end de armazenamento quando houver uma, de modo que os resultados correspondem ao que você veria na interface nativa do back-end:

* **Google Drive:** usa a API do Drive.
* **OneDrive / SharePoint:** usa o Microsoft Graph.

Para armazenamentos de objetos (S3 e compatíveis com S3, Azure Blob, GCS etc.), o PlaidCloud percorre os caminhos configurados em paralelo.


<Aside>Cada usuário tem um limite de taxa de poucas pesquisas simultâneas por conta, para que uma pesquisa pesada não prejudique os outros usuários. Se você atingir o limite, a barra de pesquisa informa um erro: aguarde uma das suas outras pesquisas terminar e tente novamente.</Aside>
