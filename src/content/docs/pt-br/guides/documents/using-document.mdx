O navegador de documentos é uma visão dividida em dois painéis: a árvore de pastas à esquerda e a lista de arquivos à direita. As barras de ferramentas têm rótulos, cada linha tem um menu **⋯**, e a maioria das operações também está disponível no menu de clique com o botão direito em qualquer um dos painéis. Esse menu mostra opções diferentes conforme uma pasta, um arquivo ou um espaço vazio esteja selecionado.

A raiz de uma conta é, por si só, uma pasta que pode ser visualizada e na qual é possível soltar arquivos: ao clicar nela, você vê tudo o que está no nível superior, e ela aceita uploads por arrastar e soltar.


**Para abrir o explorador de arquivos:**

1. Acesse **Documento > Procurar** e escolha a conta na lista do cabeçalho da página. Ou acesse **Documento > Compartilhadas** (ou **Minhas privadas**) e clique duas vezes na linha da conta, ou use o ícone **Procurar arquivos** dela
2. Para começar por um arquivo que você fixou, selecione-o em **Fixados** na **Visão geral**. **Procurar** abre na pasta dele, com o arquivo selecionado

### Desacoplar e encaixar

**Pop out** no cabeçalho da página abre a conta e a pasta atuais em uma janela própria, para que você mantenha um navegador aberto enquanto trabalha em outras páginas. **Dock** nessa janela a fecha e abre **Procurar** na página, na mesma conta e pasta. Cada navegador mantém a própria seleção, então nada é transferido de um para o outro. Se ainda houver uploads ou importações em andamento quando você fechar uma janela desacoplada, o PlaidCloud pede que você confirme.

As várias operações com arquivos e pastas são detalhadas abaixo.


## Carregar um arquivo

**Arrastar e soltar:**

1. Navegue até o diretório desejado
2. Arraste um ou mais arquivos da área de trabalho para a lista de arquivos

**Pelo menu de clique com o botão direito:**

1. Navegue até o diretório desejado
2. Clique com o botão direito na lista de arquivos e selecione `Upload Here`
3. Escolha os arquivos no seletor de arquivos do sistema operacional

**Pela barra de ferramentas:**

1. Navegue até o diretório desejado
2. Clique no botão `Upload` no painel direito

<Aside>É possível carregar vários arquivos de uma só vez. Se já existir um arquivo com o nome de destino, você será solicitado a confirmar a substituição ou a cancelar.</Aside>

Uma zona tracejada para soltar arquivos, abaixo da lista de arquivos, informa a pasta para a qual o que você soltar será carregado.

### Painel de uploads e importações

O painel **Uploads and imports** aparece abaixo do navegador enquanto há arquivos em trânsito e se oculta quando não há nada para mostrar. Ele tem uma linha por upload e uma por importação para uma tabela, cada uma com o nome, o status e as ações cabíveis:

- Um upload em andamento mostra uma barra de progresso e **Cancelar**. **Cancel all** interrompe todos os uploads em andamento.
- Um upload com falha tem **Tentar novamente** e **Dispensar**. Ele permanece até você dispensá-lo, para que você possa ler o motivo.
- Um upload concluído se dispensa sozinho após alguns segundos.
- Uma importação para uma tabela permanece até você dispensá-la. Quando ela termina, você pode continuar com **Preview ›**, **Create step ›** ou **Open step ›**. **Parar de monitorar** deixa de acompanhar uma importação que ainda está em andamento; a importação em si não é cancelada.


## Baixar um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Download`


## Renomear um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Rename`


## Mover um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Arraste-o para a pasta de destino
4. Selecione `Move File`


## Copiar um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Copy`


## Excluir um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Delete`


## Criar uma pasta

1. Abra a conta
2. Clique em `New Top Level Folder` (ou clique com o botão direito em uma pasta existente e selecione `New Folder`)
3. Informe um nome para a pasta
4. Clique em `Create`


## Renomear uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Rename`


## Mover ou copiar uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Arraste-a para a pasta de destino
4. Selecione `Move Folder` para realocá-la ou `Copy Folder` para deixar o original onde está

A pasta e tudo o que há dentro dela são levados nos dois casos.


## Excluir uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Delete`


## Baixar o conteúdo de uma pasta (arquivo zip)

A opção `Download as Zip` compacta todos os arquivos da pasta selecionada em um único `.zip` e o baixa. O arquivo preserva a estrutura de pastas mostrada no explorador.

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Download as ZIP`


## Contas somente leitura

Se uma conta estiver marcada como somente leitura, os recursos de upload (indicações de arrastar, o botão `Upload` da barra de ferramentas e o item `Upload Here` do menu de contexto) são ocultados automaticamente. Navegar, baixar e pesquisar continuam funcionando.


## Pesquisar

Para encontrar arquivos em uma conta, inclusive em muitas subpastas ou em várias contas conectadas, consulte [Pesquisar documentos](../searching-documents/).
