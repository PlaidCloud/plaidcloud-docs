O navegador do Documento é uma visão dividida em dois painéis: a árvore de pastas à esquerda e a lista de arquivos à direita. As barras de ferramentas têm rótulos, cada linha tem um menu **⋯** e a maioria das operações também está disponível em um menu de clique com o botão direito em qualquer um dos painéis. O menu de clique com o botão direito mostra opções diferentes dependendo de o item selecionado ser uma pasta, um arquivo ou um espaço vazio.

A raiz de uma conta é, por si só, uma pasta que pode ser visualizada, e a zona de soltura da esquerda envia diretamente para ela.


**Para abrir o explorador de arquivos:**

1. Acesse **Documento > Procurar**. Ele abre a sua conta favorita ou, se você não tiver uma favorita, a conta padrão do espaço de trabalho. Escolha outra conta na lista do cabeçalho da página. Ou acesse **Documento > Suas contas** e clique duas vezes na linha da conta, ou use o ícone **Abrir** dela
2. Para começar a partir de um arquivo que você fixou, selecione-o em **Fixados** na **Visão geral**. **Procurar** abre na pasta dele, com o arquivo selecionado

### Pop out

**Pop out** no cabeçalho da página abre a conta e a pasta atuais em uma nova guia do navegador, para que você possa manter um navegador aberto enquanto trabalha em outras páginas. Cada guia mantém sua própria seleção, portanto nada é transferido entre elas. Se envios ou importações ainda estiverem em execução quando você fechar a guia, o navegador pede que você confirme.

As diversas operações com arquivos e pastas são detalhadas abaixo.


## Enviar um arquivo

**Arrastar e soltar:**

1. Navegue até o diretório desejado
2. Arraste um ou mais arquivos da sua área de trabalho para uma zona de soltura: a da esquerda envia para a raiz da conta e a da direita envia para a pasta que você selecionou

**No menu de clique com o botão direito:**

1. Navegue até o diretório desejado
2. Clique com o botão direito na lista de arquivos e selecione `Upload Here`
3. Escolha os arquivos no seletor de arquivos do sistema operacional

**Na barra de ferramentas:**

1. Navegue até o diretório desejado
2. Clique no botão `Upload` no painel direito

<Aside>Vários arquivos podem ser enviados de uma vez. Se o nome de destino já existir, você será solicitado a confirmar a substituição ou cancelar.</Aside>

As duas zonas de soltura tracejadas abaixo da lista de arquivos indicam a pasta para a qual um arquivo solto é enviado: a raiz da conta à esquerda e a pasta selecionada à direita.

### Painel de envios e importações

O painel **Envios e importações** aparece abaixo do navegador enquanto os arquivos estão sendo movidos e se oculta quando não há nada a mostrar. Ele tem uma linha para cada envio e uma para cada importação para uma tabela, cada uma com seu nome, status e as ações adequadas:

- Um envio em andamento mostra uma barra de progresso e **Cancelar**. **Cancelar tudo** interrompe todos os envios em andamento.
- Um envio com falha tem **Tentar novamente** e **Dispensar**. Ele permanece até você dispensá-lo, para que você possa ler o motivo.
- Um envio concluído é dispensado sozinho após alguns segundos.
- Uma importação para uma tabela permanece até você dispensá-la. Quando ela termina, você pode continuar com **Visualizar prévia ›**, **Criar etapa ›** ou **Abrir etapa ›**. **Parar de monitorar** interrompe o acompanhamento de uma importação que ainda está em andamento; a importação em si não é cancelada.


## Baixar um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Download`


## Renomear um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Rename`


## Mover um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Arraste para a pasta de destino
4. Selecione `Move File`


## Copiar um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Copy`


## Excluir um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Delete`


## Criar uma pasta

1. Abra a conta
2. Clique em `New Top Level Folder` (ou clique com o botão direito em uma pasta existente e selecione `New Folder`)
3. Informe um nome de pasta
4. Clique em `Create`


## Renomear uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Rename`


## Mover ou copiar uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Arraste para a pasta de destino
4. Selecione `Move Folder` para realocá-la ou `Copy Folder` para deixar o original onde está

Uma pasta e tudo o que há dentro dela são transferidos nos dois casos.


## Excluir uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Delete`


## Baixar o conteúdo de uma pasta (arquivo zip)

A opção `Download as Zip` compacta todos os arquivos da pasta selecionada em um único `.zip` e o baixa. O arquivo compactado preserva a estrutura de pastas exibida no explorador.

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Download as ZIP`


## Contas somente leitura

Se uma conta estiver marcada como somente leitura, os recursos de envio (avisos de arrastar, o botão `Upload` da barra de ferramentas e o menu de contexto `Upload Here`) ficam ocultos automaticamente. Procurar, baixar e pesquisar continuam funcionando.


## Pesquisa

Para encontrar arquivos em uma conta, inclusive em muitas subpastas ou em várias contas conectadas, consulte [Pesquisar documentos](../searching-documents/).
