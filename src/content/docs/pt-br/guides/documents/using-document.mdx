O navegador de documentos é uma visão dividida em dois painéis: a árvore de pastas à esquerda e a lista de arquivos à direita. A maioria das operações está disponível no menu de clique com o botão direito em qualquer um dos painéis. Esse menu mostra opções diferentes conforme uma pasta, um arquivo ou um espaço vazio esteja selecionado.

A raiz de uma conta é, por si só, uma pasta que pode ser visualizada e na qual é possível soltar arquivos: ao clicar nela, você vê tudo o que está no nível superior, e ela aceita uploads por arrastar e soltar.


**Para abrir o explorador de arquivos:**

1. Acesse **Document > Contas compartilhadas** (ou **Private Accounts**)
2. Clique no ícone de pasta (extrema esquerda) da conta que você quer explorar ou clique duas vezes na linha da conta

As várias operações com arquivos e pastas são detalhadas abaixo.


## Carregar um arquivo

**Arrastar e soltar:**

1. Navegue até o diretório desejado
2. Arraste um ou mais arquivos da área de trabalho para a lista de arquivos

**Pelo menu de clique com o botão direito:**

1. Navegue até o diretório desejado
2. Clique com o botão direito na lista de arquivos e selecione `Upload Here`
3. Escolha os arquivos no seletor de arquivos do sistema operacional

**Pela barra de ferramentas:**

1. Navegue até o diretório desejado
2. Clique no botão `Upload` no painel direito

<Aside>É possível carregar vários arquivos de uma só vez. Se já existir um arquivo com o nome de destino, você será solicitado a confirmar a substituição ou a cancelar.</Aside>


## Baixar um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Download`


## Renomear um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Rename`


## Mover um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Arraste-o para a pasta de destino
4. Selecione `Move File`


## Copiar um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Copy`


## Excluir um arquivo

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar o arquivo desejado
3. Clique com o botão direito e selecione `Delete`


## Criar uma pasta

1. Abra a conta
2. Clique em `New Top Level Folder` (ou clique com o botão direito em uma pasta existente e selecione `New Folder`)
3. Informe um nome para a pasta
4. Clique em `Create`


## Renomear uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Rename`


## Mover ou copiar uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Arraste-a para a pasta de destino
4. Selecione `Move Folder` para realocá-la ou `Copy Folder` para deixar o original onde está

A pasta e tudo o que há dentro dela são levados nos dois casos.


## Excluir uma pasta

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Delete`


## Baixar o conteúdo de uma pasta (arquivo zip)

A opção `Download as Zip` compacta todos os arquivos da pasta selecionada em um único `.zip` e o baixa. O arquivo preserva a estrutura de pastas mostrada no explorador.

1. Navegue até o diretório desejado
2. Clique com o botão esquerdo para selecionar a pasta desejada
3. Clique com o botão direito e selecione `Download as ZIP`


## Contas somente leitura

Se uma conta estiver marcada como somente leitura, os recursos de upload (indicações de arrastar, o botão `Upload` da barra de ferramentas e o item `Upload Here` do menu de contexto) são ocultados automaticamente. Navegar, baixar e pesquisar continuam funcionando.


## Pesquisar

Para encontrar arquivos em uma conta, inclusive em muitas subpastas ou em várias contas conectadas, consulte [Pesquisar documentos](../searching-documents/).
