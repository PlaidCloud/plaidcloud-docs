## Configuração do servidor SFTP

Confirme que o administrador do servidor SFTP forneceu as seguintes informações:

1. O **nome do host ou endereço IP** do servidor SFTP
2. A **porta SSH** (o padrão é `22`)
3. Um **nome de usuário** com acesso ao diretório de destino
4. Uma **senha** ou uma **chave privada SSH** para autenticação
5. Opcionalmente, a **impressão digital da chave de host SSH do servidor** para verificação rigorosa do host

Agora você tem tudo de que precisa para adicionar sua conta SFTP ao PlaidCloud Document.


## Configuração do PlaidCloud Document

1. Entre no PlaidCloud
2. Selecione o espaço de trabalho em que a nova conta de documentos ficará
3. Acesse `Document > Manage Accounts`
4. Selecione o botão `+ New Account`
5. Selecione `Secure File Transfer (SFTP)` como **Tipo de serviço**
6. Preencha um nome e uma descrição
7. Informe o caminho do diretório remoto no campo **Caminho inicial** (por exemplo, `/data/uploads`)
8. Selecione um **Modelo de segurança** adequado ao seu caso de uso. Deixe `Private` se tiver dúvida.
9. Informe o **nome de usuário** no campo Public Key/User em Credenciais de autenticação
10. Informe a **senha** no campo Private Key/Password em Credenciais de autenticação
11. Acesse a guia **Configuração de SSH**
12. Informe o **Host ou endereço IP** do servidor SFTP
13. Informe a **Porta da conexão SSH** (padrão `22`)
14. Se usar autenticação por chave em vez de senha, cole a **chave privada RSA** no campo RSA Private Key. Quando uma chave privada é fornecida, ela tem precedência sobre a senha. A chave salva nunca é exibida novamente; para voltar à autenticação por senha, selecione **Limpar a chave salva (usar a senha)**.
15. Opcionalmente, cole a **Remote Server RSA Fingerprint** para verificação rigorosa da chave de host. Deixe em branco para preencher automaticamente na primeira conexão.
16. Selecione o botão Salvar e sua nova conta de documentos estará ativa

<Aside>Você pode testar a conexão SSH usando o botão **Testar conexão SSH** na guia Configuração de SSH antes de salvar.</Aside>
