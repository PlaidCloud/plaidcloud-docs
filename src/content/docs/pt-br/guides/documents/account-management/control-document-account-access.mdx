Estão disponíveis quatro tipos de restrição de acesso para uma conta: Privado, Espaço de trabalho, Somente membros e Grupo de segurança. O tipo de restrição definido para um usuário pode ser editado a qualquer momento no formulário da conta.

<Aside>Nenhum dos níveis de acesso à conta revela as credenciais usadas para acessar os documentos. Somente os proprietários da conta podem ver as credenciais.</Aside>

## Atualizando o acesso à conta


1. Selecione `Document > Manage Accounts` no PlaidCloud
2. Entre no modo de edição da conta que você deseja alterar
3. Selecione a restrição de nível de acesso desejada em `Security Model`
4. Clique no botão Salvar

<Aside>Dependendo do Modelo de segurança selecionado, haverá opções diferentes para atribuir quais membros ou grupos de segurança têm permissão de acesso na lista de contas em Gerenciar contas.</Aside>


## Opções de restrição


### Todos os membros do espaço de trabalho


Este é o acesso mais simples, pois concede acesso a todos os membros do espaço de trabalho e não exige nenhuma atribuição adicional de membros.



### Somente membros específicos


Esta configuração de acesso exige a atribuição de cada membro a uma conta. Essa opção é particularmente útil quando combinada com a opção de logon único de atribuir membros com base em uma lista de grupos enviada com a autenticação. No entanto, em espaços de trabalho com muitos membros, essa abordagem muitas vezes exige mais esforço do que o desejado, e é aí que os grupos de segurança se tornam úteis. Para escolher somente membros específicos:


1. Selecione o ícone de membros na lista Gerenciar contas
2. Arraste os membros desejados da coluna `Unassigned Members`, à esquerda, para a coluna `Assigned Members`, à direita
3. Para remover membros, faça o contrário
4. Clique no botão Salvar

### Somente grupos de segurança específicos


Com esta opção, a permissão para acessar uma conta é concedida a grupos de segurança específicos, e não apenas a pessoas individuais. Com restrições de acesso baseadas na associação a um ou mais grupos de segurança, a administração de contas com um número muito maior de usuários fica muito mais simples. Para editar os grupos atribuídos:


1. Selecione o ícone de grupos na lista Gerenciar contas
2. Arraste os grupos desejados da coluna `Unassigned Groups`, à esquerda, para a coluna `Assigned Groups`, à direita
3. Para remover grupos, faça o contrário
4. Clique no botão Salvar

### Agentes remotos


Os agentes do PlaidLink costumam usar contas de documentos para armazenar arquivos ou movê-los entre sistemas. Para permitir que agentes remotos acessem contas de documentos, é OBRIGATÓRIO conceder permissão aos agentes. Este é um recurso de segurança para limitar acessos indesejados a informações potencialmente sensíveis. Para adicionar agentes:


1. Selecione o ícone de agente na lista Gerenciar contas
2. Arraste os agentes desejados da coluna `Unassigned Agents`, à esquerda, para a coluna `Assigned Agents`, à direita
3. Para remover agentes, faça o contrário
4. Clique no botão Salvar
