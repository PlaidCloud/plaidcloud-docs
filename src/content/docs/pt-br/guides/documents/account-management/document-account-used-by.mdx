Antes de desativar, substituir ou reconstruir uma conta de documentos, encontre tudo o que a usa e, em seguida, mova esses usos para outra conta.

## Veja onde uma conta é usada

1. Selecione `Document > Manage Accounts`.
2. Selecione o ícone **Used By** na linha da conta.

**Onde é usado** lista cada uso com seu projeto, tipo, nome e a forma como a conta é usada:

| Coluna | Valores |
| --- | --- |
| Tipo | Etapa, fluxo de trabalho ou padrão do projeto |
| Uso | Diretamente; condição do contêiner; padrão do projeto; ou variável (pode ser usada) |

As etapas e os fluxos de trabalho que a sua função não pode ver são contados, mas não nomeados. A lista é reunida um projeto por vez e informa quando pode estar incompleta ou quais projetos nunca foram verificados.

Os manifestos do App Runner e as imagens de blocos de projeto não são verificados. Um uso proveniente de uma variável é listado, e você atualiza essa variável manualmente.

## Reaponte uma conta

1. Em **Onde é usado**, selecione **Re-point...**.
2. Escolha a conta para a qual deseja migrar e selecione **Pré-visualização**.
3. Revise os usos. Nada foi alterado ainda. Desmarque os que você quiser deixar como estão.
4. Selecione **Re-point** e confirme.

Cada uso então mostra seu resultado: **Changed**, **Changed since the preview**, **Not allowed**, **Project is locked**, **No longer exists** ou **Refused**. Um uso que falha não impede os demais. Alterar um padrão de projeto exige um Arquiteto ou administrador do espaço de trabalho.

Os usos por variável nunca são alterados. A pré-visualização nomeia cada variável e a etapa a ser atualizada manualmente.

<Aside type="caution">Se você reapontar para um Personal Temp Drive, os fluxos de trabalho são executados como o projeto, que não consegue abrir esse drive, e as etapas reapontadas falham quando são executadas. O PlaidCloud avisa você sobre cada projeto afetado.</Aside>

## Usando um assistente de IA

* O assistente de IA em um projeto pode propor um reapontamento. Ele mostra as alterações em um cartão de aprovação e só as aplica depois que você aprova.
* Via MCP, `document_account_describe(include=['used_by'])` lista os usos e `document_account_repoint` faz a pré-visualização e aplica um reapontamento.
