## Descrição

Quando você pressiona **Salvar** em uma etapa, o PlaidCloud verifica as configurações dela e recusa
as que não consegue executar, como uma expressão que não compila ou uma coluna usada
de um modo que o tipo dela não permite. Enquanto você edita uma etapa, o Weave agora executa a maior parte
dessas verificações à medida que você trabalha e mostra o que o Salvar recusaria em uma faixa logo acima
dos botões **Salvar**:

> 1 problema que o Salvar vai recusar.

Cada problema é listado abaixo dessa linha. Quando ele aponta uma linha da guia **Seleção de dados da tabela**, **Ir para** abre essa guia com a linha selecionada.

As verificações leem apenas as configurações da etapa e as variáveis do seu projeto, portanto são
rápidas e não envolvem IA. Elas nunca bloqueiam o salvamento: o Salvar continua
disponível e executa todas as verificações por conta própria quando você o pressiona.

<Aside type="note">
O Salvar também verifica algumas coisas que esta faixa não verifica, como se as tabelas
de origem e de destino têm as colunas que a etapa usa e se os campos obrigatórios
estão preenchidos. Assim, "Nenhum problema encontrado" significa que nenhuma das verificações executadas durante a edição
encontrou um problema, não que o Salvar vai aceitar a etapa.
</Aside>

## O que a faixa diz

| O Weave diz | O que significa |
| --- | --- |
| Verificando se esta etapa tem problemas… | O Weave está executando as verificações na sua alteração mais recente. |
| 1 problema que o Salvar vai recusar. | O Salvar recusaria a etapa como ela está. Cada problema é listado abaixo. |
| Nenhum problema encontrado. O Salvar verifica mais algumas coisas, como as tabelas de origem e de destino. | As verificações executadas durante a edição não encontraram nada. O Salvar ainda executa as próprias verificações, incluindo algumas que esta faixa ignora. |
| O Weave não conseguiu verificar as expressões desta etapa. … | Parte da etapa não pôde ser verificada; o motivo vem a seguir. Isso nunca é uma aprovação. |
| O Weave não conseguiu verificar esta etapa agora. O Salvar ainda a verifica. | A verificação não foi executada, por exemplo porque o servidor estava ocupado. Sua próxima alteração pede novamente. |

### Por que as expressões não puderam ser verificadas

| Motivo | O que significa |
| --- | --- |
| Esta etapa não está em um fluxo de trabalho, então suas expressões não podem ser verificadas. O Salvar também não as verifica. | As expressões podem usar variáveis do fluxo de trabalho, então são verificadas no fluxo de trabalho da etapa. Uma etapa que você abriu fora de qualquer fluxo de trabalho não é verificada, nem aqui nem pelo Salvar. |
| Algumas das expressões estão em configurações que o Weave ainda não consegue verificar. | A etapa mantém algumas expressões em configurações que essas verificações não leem, como o filtro de uma segunda origem. As demais continuam sendo verificadas. |
| A configuração de colunas dela é de um tipo que o Weave ainda não consegue verificar. | A etapa lista suas colunas de um modo que a verificação não consegue compilar, como faz uma Junção de várias tabelas. |

Uma expressão que usa uma variável que nem o fluxo de trabalho nem o projeto definem
é um problema, não um motivo: "Uma expressão usa a variável rate, que não está
definida neste fluxo de trabalho ou projeto." O mesmo vale para uma chave que não inicia nem encerra
nenhum nome de variável, como acontece com uma variável digitada pela metade: "Uma expressão tem uma chave que
não faz parte de um nome de variável." O Salvar recusa ambas com as mesmas frases.

## No Editor de expressões

Abra o **Editor de expressões** a partir de uma célula **Expressão** na guia **Seleção de dados da
tabela**, ou a partir de **Selecionar subconjunto de dados** ou **Aplicar filtro secundário aos dados do
resultado** na guia **Filtros de dados**, e uma linha sob o editor verifica
a expressão conforme você digita:

| O editor diz | O que significa |
| --- | --- |
| Verificando… | O Weave está verificando o que você acabou de digitar. |
| Nenhum erro encontrado. | A expressão compila do mesmo modo que o Salvar a compila. Aponte para a linha para ler o que isso deixa de fora: o Weave verifica a sintaxe e os nomes de coluna; alguns erros só aparecem quando a etapa é executada. |
| Erro: … | O Salvar recusaria a expressão, pelo motivo indicado. Um erro de sintaxe também é marcado na linha dele, ao lado do número da linha. |
| Não foi possível verificar. … | A expressão não pôde ser verificada, por um dos motivos acima. |
| Não foi possível verificar agora. Salvar a etapa ainda a verifica. | A verificação não foi executada. Pressionar **Salvar** na etapa ainda verifica a expressão. |

O editor verifica com base nas configurações da etapa como estavam quando o Weave verificou
a etapa pela última vez, com a sua expressão no lugar. Aberto de qualquer outro lugar,
como o Explorador de tabelas, ele não mostra a linha.

## Quando ela aparece

- Enquanto você edita uma etapa que pode alterar. Uma etapa que abre somente para leitura no seu
  perfil não é verificada durante a edição.
- Depois de cada alteração, assim que você faz uma pausa. Uma alteração que deixa as configurações
  como estavam não é verificada de novo.
- Ela lê as configurações da etapa e as variáveis do projeto, portanto nunca custa
  uma chamada de IA e nunca consulta o seu warehouse.
