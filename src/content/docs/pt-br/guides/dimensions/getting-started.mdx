As dimensões são as hierarquias do PlaidCloud — as árvores que você usa para organizar centros de custo, produtos, contas, geografia, períodos ou qualquer outra estrutura consolidada. Elas são a base sobre a qual alocações, painéis e relatórios são construídos.

## Quando usar uma dimensão

Recorra a uma dimensão quando precisar:

- Consolidar valores das folhas até os pais (somar o custo por departamento, depois por região, depois por empresa)
- Alocar de um conjunto de linhas para outro com base em uma hierarquia compartilhada (distribuir o custo de TI entre unidades de negócios)
- Segmentar um painel por uma estrutura mais profunda do que uma lista plana (detalhar de continente → país → cidade)
- Aplicar a mesma lógica de agrupamento em vários lugares — defina a árvore uma vez e faça referência a ela em todos os lugares

Se os seus dados já são planos e unidimensionais, você não precisa de uma dimensão. Uma tabela comum basta.

## Como as dimensões são estruturadas

Toda dimensão tem uma **hierarquia principal** — a árvore canônica em que cada folha é registrada exatamente uma vez. Sobre ela, você pode sobrepor **hierarquias alternativas** que consolidam novamente as mesmas folhas sob pais diferentes (por exemplo, a árvore principal agrupa os centros de custo por departamento, e uma alternativa os agrupa por região).

Cada nó da árvore pode conter propriedades, aliases e valores; portanto, uma hierarquia é mais do que uma árvore de nomes — é uma estrutura com metadados que alocações e relatórios podem referenciar.

Para conhecer a mecânica de criar, copiar, ordenar e gerenciar dimensões, consulte [Usando dimensões (hierarquias)](/pt-br/guides/dimensions/dimensions/).

## Como as dimensões são carregadas

As dimensões normalmente são populadas a partir de uma tabela de origem por meio de um fluxo de trabalho:

- **Formato pai-filho** — duas colunas (pai, filho), uma aresta por linha
- **Formato de níveis** — uma coluna por nível da hierarquia, um caminho completo por linha

Consulte [Carregando e descarregando dimensões](/pt-br/guides/dimensions/loading-unloading/) para ver o processo de carga e a etapa de fluxo de trabalho [Dimension Load](/pt-br/reference/workflow-steps/dimensions/dimension-load/) para ver o conjunto completo de opções.
