O Iniciador é a primeira coisa que você vê depois de entrar em um espaço de trabalho.
Ele reúne o que você mais usa (projetos, fluxos de trabalho, tabelas, painéis,
aplicativos Panel, dimensões, editores de dados e documentos) em uma única página de blocos,
para que você retome de onde parou sem precisar procurar em cada aplicativo.

## Faixas

A página é organizada em três faixas, de cima para baixo. Uma faixa só aparece quando
tem algo a mostrar.

- **Requer atenção:** fluxos de trabalho cuja execução mais recente falhou, para que os problemas
  apareçam assim que você chega. Cada cartão leva direto à execução com falha, e
  você pode **Dispensar** um que já tenha tratado.
- **Fixados:** tudo o que você marcou como favorito, na ordem em que o fixou.
  Qualquer tipo de item pode ser fixado aqui (consulte [Fixação](#fixação-favoritos)).
- **Recentes:** projetos, painéis e aplicativos Panel que você abriu ou editou
  recentemente.

<Aside type="note">
Apenas projetos, painéis e aplicativos Panel aparecem por recência, pois normalmente há
fluxos de trabalho, tabelas, dimensões, editores de dados e documentos demais para listar
dessa forma. Deixe à mão aqueles aos quais você volta fixando-os, e eles ficarão
esperando por você na faixa **Fixados**.
</Aside>

## Blocos de projeto

Um bloco de projeto resume o projeto de relance:

| Estatística | Significado |
|---|---|
| **Execuções de fluxos de trabalho** | Execuções de fluxo de trabalho concluídas na janela recente |
| **Última execução** | Quando a execução mais recente terminou |
| **Fluxos de trabalho** | Fluxos de trabalho que o projeto contém |
| **Tabelas** | Tabelas que o projeto contém |
| **Registros** | Total de linhas nessas tabelas (um `~` indica uma estimativa) |

Um projeto sem histórico de execuções mostra **Última edição** em vez dos números de execução, e
as contagens são omitidas por completo quando são zero.

### Imagens de bloco

Cada bloco de projeto traz uma imagem de fundo esmaecida. Por padrão, é o
ventilador do PlaidCloud, mas você pode dar ao projeto uma imagem própria (um logotipo de cliente,
por exemplo, ou algo que identifique o trabalho de relance) para que ele se destaque em um
Iniciador cheio.

Para definir uma:

1. Abra o projeto e acesse a guia **Início** dele.
2. Role até **Imagem do bloco do iniciador**, na parte inferior da coluna esquerda.
3. Escolha a conta de documentos que contém a imagem e depois use **Procurar** para localizar o
   arquivo de imagem.
4. Use **Limpar** para voltar ao padrão.

A imagem é esmaecida atrás das estatísticas para que elas continuem legíveis, então escolha
algo que fique bem quando desbotado. Imagens largas combinam melhor com o formato do bloco
do que imagens altas. Você precisa de permissão para editar o projeto para definir isso; um
visualizador somente leitura vê o seletor desativado.

<Aside type="note">
Qualquer pessoa que possa ver o projeto vê a imagem do bloco dele, mas a imagem é entregue
apenas a quem também pode ler a conta de documentos em que ela está. Um visualizador
sem esse acesso simplesmente vê o ventilador padrão.
</Aside>

Os blocos de painel funcionam de outra forma: eles mostram uma miniatura gerada automaticamente
do próprio painel, então não há nada para escolher.

## Abrir itens

Cada cartão e cada linha de lista tem uma ação principal e, onde faz sentido, ações
extras:

| Item | Abre | Também disponível |
|---|---|---|
| Projeto | O projeto | |
| Fluxo de trabalho | O fluxo de trabalho | Executar, Abrir a última execução, status ao vivo **Em execução** |
| Tabela | A tabela | Abrir no Explorador de tabelas |
| Dimensão | Seu editor de hierarquia | |
| Editor de dados | Seu projeto | |
| Painel | O painel | Abrir em nova guia |
| Aplicativo Panel | O aplicativo | Abrir em nova guia |
| Aplicativo Dash | O aplicativo | Abrir em nova guia |
| Documento | O arquivo ou a pasta | |

Um fluxo de trabalho em execução mostra um indicador de status ao vivo que se atualiza sozinho,
sem precisar atualizar a página.

## Fixação (favoritos)

Clique na **estrela** em qualquer cartão ou linha de lista do Iniciador para fixá-lo. Os itens fixados
sempre aparecem na faixa **Fixados**, independentemente de há quanto tempo você os usou,
para que o que importa para você nunca saia do alcance.

Você também pode fixar de onde já está trabalhando, sem abrir o Iniciador
primeiro; procure a coluna de estrela:

- **Projetos, fluxos de trabalho, tabelas, dimensões e editores de dados:** a coluna de
  estrela na lista de cada um, dentro do projeto.
- **Painéis**, **aplicativos Panel** e **aplicativos Dash:** a coluna de estrela em Meus
  painéis e Meus aplicativos Panel.
- **Documentos:** clique com o botão direito em um arquivo *ou* em uma pasta no navegador de documentos
  e escolha **Fixar no iniciador**.

Clique em uma estrela acesa em qualquer lugar para desafixar. Os itens fixados em qualquer lugar aparecem
no Iniciador imediatamente.

## Blocos ou lista

Use o alternador **Blocos / Lista** na barra de ferramentas para alternar entre a visão ampla
de cartões e uma lista densa de uma linha. Sua escolha é lembrada, e a troca é
instantânea: ela redesenha o que já foi carregado sem buscar novamente.

## Filtrar por tipo

A linha de chips à esquerda da barra de ferramentas tem um chip por tipo, cada um com seu próprio
ícone: **Projetos**, **Painéis**, **Aplicativos Panel**, **Fluxos de trabalho**, **Tabelas**,
**Dimensões**, **Editores de dados** e **Documentos**. Um chip pressionado significa que
esse tipo é mostrado; clique nele para ocultar esse tipo das faixas **Recentes** e **Fixados**.
Seu filtro é lembrado entre as visitas.

A faixa **Requer atenção** nunca é filtrada: um fluxo de trabalho com falha sempre
aparece, mesmo quando o chip do tipo dele está desligado.

## Pesquisa e comandos

Pressione **Ctrl/Cmd-K** em qualquer tela, ou clique em **Pesquisar** na barra de ferramentas
do Iniciador, para abrir a paleta de comandos. A única exceção é o Registro de lançamentos,
que mantém o **Ctrl/Cmd-K** para a própria paleta.

Antes de você digitar, ela lista duas coisas:

- **Ações:** comandos que você pode executar daqui: ir para Início, Projetos,
  Painéis ou Documentos, alternar entre a aparência clara e a escura,
  conectar sua IA e obter ajuda. As ações **Ir para** aparecem apenas para os aplicativos
  que o seu espaço de trabalho tem.
- **Recentes:** as últimas oito coisas que você abriu, da mais recente para a mais antiga: projetos,
  fluxos de trabalho, tabelas, dimensões, editores de dados, painéis, aplicativos Panel e
  documentos abertos pelo Iniciador ou pela paleta, e todos os projetos que você abre
  em qualquer lugar. Algo aberto de dentro de um projeto, como um fluxo de trabalho
  ou uma dimensão, não é adicionado. Esta lista é mantida no seu navegador, portanto não é
  compartilhada entre dispositivos e é separada da faixa **Recentes** do Iniciador
  (consulte [Faixas](#faixas)).

Comece a digitar e as duas listas são reduzidas ao mesmo tempo: os caracteres digitados só precisam
aparecer em ordem, então `proj` encontra **Ir para Projetos**, com a correspondência mais próxima
primeiro. A partir de dois caracteres, a paleta também pesquisa em projetos,
fluxos de trabalho, tabelas, painéis e aplicativos Panel e adiciona esses resultados abaixo,
agrupados por tipo, cada um com as mesmas ações de abertura e a mesma estrela de fixação do quadro.
Um resultado que já é mostrado em **Recentes** não é repetido.

- **Seta para cima / Seta para baixo** movem a seleção.
- **Enter** executa a ação selecionada ou abre o item selecionado.
- **Escape** fecha a paleta.

Dimensões, editores de dados e documentos não são pesquisáveis: chegue a eles
fixando-os, por **Recentes** depois de abri-los pelo Iniciador ou pelo
projeto ao qual pertencem.

Clicar em um resultado o abre; clicar na **estrela** dele o fixa e mantém a paleta
aberta, para que você possa fixar várias coisas de uma só vez.

## Atualização

O Iniciador se atualiza sozinho quando você volta a ele e seus dados estão
desatualizados. Para obter o mais recente imediatamente, clique em **Atualizar** na barra de ferramentas.

## Começar em outro lugar

O Iniciador é onde o PlaidCloud abre por padrão. Para começar em outro aplicativo,
desative **Iniciar no Iniciador** no menu Opções.

## Aparência (claro, escuro, automático)

O botão **Aparência** na barra de ferramentas superior (o ícone de contraste ao lado
do menu da conta) alterna o PlaidCloud entre uma aparência clara e uma escura. Ele
se aplica em todo lugar: no Iniciador, em todos os aplicativos e em todas as janelas e caixas de diálogo
dentro deles.

| Opção | O que faz |
| --- | --- |
| **Claro** | Usa sempre a aparência clara, qualquer que seja a configuração do seu dispositivo. |
| **Escuro** | Usa sempre a aparência escura, qualquer que seja a configuração do seu dispositivo. |
| **Automático (sistema)** | Segue a configuração de aparência do seu sistema operacional. |

**Automático (sistema)** é o padrão e acompanha o sistema em tempo real: se o seu
computador estiver configurado para mudar para o escuro à noite, o PlaidCloud acompanha no mesmo
momento, sem recarregar. Escolher **Claro** ou **Escuro** fixa a aparência e
ignora a configuração do sistema a partir de então.

<Aside type="note">
Sua escolha é lembrada no navegador em que você a fez, portanto não é levada
para outro navegador nem para outro computador: defina-a uma vez em cada um.
Limpar os dados de site do navegador a redefine para **Automático**. Se o seu navegador bloquear o
armazenamento local (alguns modos de navegação privada fazem isso), o alternador ainda funciona durante a
sessão, mas volta a **Automático** na próxima vez.
</Aside>

O conteúdo incorporado mantém as próprias cores: painéis e aplicativos Panel não são
reestilizados por esta configuração.
