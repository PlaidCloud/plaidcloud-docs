Copiar um fluxo de trabalho é útil ao planejar grandes alterações ou replicar um processo com opções diferentes. As cópias são totalmente independentes: modificar uma cópia não afeta o original.

Duas ações estão disponíveis na tabela **Fluxos de trabalho**:

* **Duplicate Selected Workflows**: cópia rápida no mesmo projeto
* **Clone Workflow(s)**: copia para um projeto de destino à sua escolha (o padrão é o projeto atual)


## Duplicar fluxos de trabalho selecionados

1. Abra a tabela **Fluxos de trabalho** do projeto
2. Selecione um ou mais fluxos de trabalho
3. Clique em `Duplicate Selected Workflows` na barra de ferramentas

Cada clone fica no mesmo projeto, com " copy" acrescentado ao nome original.


## Clonar fluxo(s) de trabalho

Use esta opção quando quiser copiar fluxos de trabalho para outro projeto, por exemplo, ao promover de um projeto de desenvolvimento para um projeto irmão.

1. Abra a tabela **Fluxos de trabalho** do projeto de origem
2. Selecione um ou mais fluxos de trabalho
3. Abra o menu **Ações** e clique em `Clone Workflow(s)`
4. Na caixa de diálogo, escolha o **Projeto de destino** (o padrão é o projeto atual)
5. Clique em `Clone Workflow(s)`

Uma caixa de diálogo de progresso é aberta enquanto a clonagem é executada, mostrando uma barra geral (fluxo de trabalho N de M) e uma barra por etapa para o fluxo de trabalho que está sendo copiado. Você pode clicar em `Run in Background` para fechar a caixa de diálogo e continuar trabalhando: a clonagem continua em execução e uma notificação aparece quando ela termina.

Os fluxos de trabalho clonados têm " copy" acrescentado aos nomes para que não colidam com nada que já exista no projeto de destino.

<Aside>A clonagem copia a definição do fluxo de trabalho e a configuração das etapas. Os recursos com escopo de projeto referenciados pelo fluxo de trabalho (tabelas, dimensões, conexões) devem já existir no projeto de destino, ou você deve cloná-los separadamente.</Aside>
