## Ver o log do fluxo de trabalho


Conforme as coisas acontecem em um fluxo de trabalho, como etapas sendo executadas ou avisos ocorrendo, esses eventos são registrados no log do fluxo de trabalho. Esse log pode ser visualizado na área **Projeto**, na guia **Log**. O log do fluxo de trabalho também está presente no log do projeto, caso você queira uma visão mais abrangente dos logs de vários fluxos de trabalho.

Se você estiver trabalhando no [Designer visual de fluxo de trabalho](/pt-br/guides/workflows/advanced-workflows/), o botão **Ver logs** da barra de ferramentas abre essa mesma visão de Log já filtrada para o fluxo de trabalho que você tem aberto.



O visualizador de log permite ordenar e filtrar o log, além de ver os detalhes de uma entrada de log específica.



## Limpar o log do fluxo de trabalho


Limpar o log do fluxo de trabalho pode ser desejável de tempos em tempos. No visualizador de log, selecione o botão **Limpar log**. Isso limpa o log com base no fluxo de trabalho selecionado, o que também remove as entradas de log do log em nível de projeto.
