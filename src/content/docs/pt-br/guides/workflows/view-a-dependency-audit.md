A **Workflow Dependency Audit** é uma ferramenta muito útil para entender as dependências de dados e de fluxo de trabalho em fluxos de trabalho complexos e interconectados. Com o tempo, à medida que os processos de fluxo de trabalho se tornam mais complexos, pode ser difícil garantir que todas as dependências estejam na ordem correta. Quando os dados já existem nas tabelas, as etapas serão executadas e parecerão corretas em muitos casos, mas podem de fato ter um problema de dependência se os dados forem preenchidos fora de ordem.



Essa ferramenta fornece uma auditoria de dependências e identifica problemas nas relações de dependência de dados.
