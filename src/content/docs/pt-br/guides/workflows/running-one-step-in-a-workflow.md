Durante o desenvolvimento inicial do fluxo de trabalho, o teste ou a solução de problemas, muitas vezes é útil executar as etapas individualmente. Para executar uma única etapa isoladamente, clique com o botão direito na etapa e selecione **Executar etapa** no menu de contexto.
