Há duas maneiras de atualizar a ordem das etapas no fluxo de trabalho. A primeira é usar as setas para cima e para baixo da tabela **Fluxos de trabalho** para mover a etapa. A segunda é usar a opção **Step Move**, que facilita mover a etapa quando são necessárias mudanças grandes. A opção de mover etapa permite levar a etapa para o início, para o fim ou para depois de uma etapa específica em uma única operação.

A estrutura de um fluxo de trabalho só pode conter cada etapa uma vez. Se um fluxo de trabalho já tiver, de alguma forma, a mesma etapa listada duas vezes, reordená-lo — inclusive arrastar uma etapa para uma nova posição — é recusado com um erro informando que o fluxo de trabalho contém uma duplicata. Exclua a etapa duplicada para reparar o fluxo de trabalho; a remoção de etapas não é restrita, e a reordenação volta a funcionar normalmente assim que ela for removida.
