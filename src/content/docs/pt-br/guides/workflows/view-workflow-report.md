Manter uma documentação detalhada que dê suporte a requisitos estatutários e gerenciais é difícil quando os projetos e fluxos de trabalho podem ser dinâmicos. Para ajudar a resolver esse problema, o PlaidCloud oferece um relatório em nível de fluxo de trabalho que fornece documentação detalhada de fluxos de trabalho, etapas de fluxo de trabalho, funções definidas pelo usuário e variáveis.



O relatório é gerado sob demanda e reflete o estado atual do fluxo de trabalho. Para baixar o relatório, clique no ícone Relatório na hierarquia de **Fluxos de trabalho**.
