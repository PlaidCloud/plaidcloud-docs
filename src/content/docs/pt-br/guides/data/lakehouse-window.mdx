A janela **Lakehouse** no Analyze mostra o que está em execução no seu lakehouse e como ele está configurado. Uma barra no lado esquerdo lista as páginas da janela.

| Página | O que mostra |
|---|---|
| **Consultas** | O que está em execução agora e o que foi executado recentemente. |
| **Perfil** | O plano e o custo de uma consulta. |
| **Carga** | O quanto o lakehouse está ocupado. |
| **Catálogo** | Os namespaces e as tabelas de um catálogo do lakehouse, com os detalhes de cada tabela. |

Em **Administration**, a barra lista **Lakehouse catalogs**, **Database users** e **Compute**. **Database users** e **Compute** são exibidas apenas para membros que têm a função de administrador do Lakehouse ou a função de cluster do Lakehouse; sem a função, a página não é listada.

## Consultas

**Running now** lista as consultas em execução no lakehouse. **Atualizar a cada** define com que frequência a lista é lida novamente enquanto a janela está aberta. Selecione uma consulta em execução e clique em **Stop query** para encerrá-la.

**Histórico** lista as últimas consultas, da mais recente para a mais antiga. Restrinja a lista com **Search SQL**, **Any user**, **Any kind** e **Any duration**. Clique em **Copy SQL** para copiar a instrução de uma consulta.

Para ver como uma consulta foi executada, clique duas vezes nela ou selecione-a e escolha **Profile this query**. A janela abre **Perfil** no plano dessa consulta.

## Catálogo

**Catálogo** tem, no cabeçalho, um seletor para o catálogo do lakehouse. Escolha um namespace para listar as tabelas dele e, em seguida, selecione uma tabela para abrir os detalhes:

- **Colunas**, com o tipo de cada coluna e se ela é obrigatória.
- As linhas, o tamanho e os arquivos de dados do instantâneo atual.
- **Particionamento**, **Local** e **Propriedades**.
- **Histórico**, uma linha por instantâneo com o horário, a operação e as **Rows added** e **Rows removed**.

Um valor que os metadados da tabela não contêm é exibido como —.

### Copiar uma consulta de viagem no tempo

Em um instantâneo em **Histórico**, clique em **Copy query as of this snapshot**. Isso copia uma consulta que lê a tabela como ela estava naquele instantâneo, usando `FOR VERSION AS OF`, que você pode colar em uma tela de consulta. A cópia é oferecida apenas para o catálogo padrão do lakehouse. Para navegar pelos instantâneos de uma tabela ou revertê-los no Explorador de tabelas, consulte [Instantâneos de tabela](/pt-br/guides/data/table-snapshots/).

## Catálogos do lakehouse, usuários de banco de dados e computação

**Lakehouse catalogs** lista os catálogos registrados para o seu espaço de trabalho. **Procurar** em um catálogo abre o catálogo em **Catálogo**.

**Database users** lista os usuários de banco de dados que podem se conectar ao lakehouse e permite adicioná-los, alterá-los e removê-los. **Compute** mostra a integridade dos nós de computação do lakehouse e oferece **Reiniciar computação**, uma reinicialização gradual para quando as consultas estiverem travadas. Ela substitui os nós de computação um de cada vez; assim, as consultas em execução em um nó que está sendo substituído falham, enquanto os outros nós continuam atendendo novas consultas. Há um intervalo de espera entre as reinicializações.
