Um **projeto** é a unidade de trabalho do PlaidCloud. Cada projeto tem seus próprios dados, fluxos de trabalho, dimensões e histórico de auditoria. Os projetos não compartilham estado entre si: são isolados, o que os torna o limite natural para separar análises distintas, processos de negócio ou produtos de dados.

A maioria das equipes começa com um projeto por área de análise: um projeto para alocação de custos de pessoal, outro para análise de receita, outro para o fechamento mensal, ou o que corresponder à forma como a equipe pensa o próprio trabalho.
