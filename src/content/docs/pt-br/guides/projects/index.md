Um **projeto** é a unidade de trabalho no PlaidCloud. Cada projeto tem seus próprios dados, fluxos de trabalho, dimensões e histórico de auditoria. Os projetos não compartilham estado entre si — eles são isolados, o que os torna o limite natural para separar análises, processos de negócio ou produtos de dados distintos.

A maioria das equipes começa com um projeto por área analítica: um projeto para alocação de custos de pessoal, outro para análise de receita, outro para o fechamento mensal — o que corresponder à forma como sua equipe pensa o próprio trabalho.
