## Visualizar e Classificar o Log do Projeto

À medida que ações ocorrem em um projeto, como atribuir novos membros ou executar fluxos de trabalho, o log do projeto armazena os eventos. O log do projeto consolida a visualização
de todos os logs individuais dos fluxos de trabalho para oferecer uma visão mais completa das atividades do projeto. O PlaidCloud também permite classificar e
filtrar o log do projeto e ver os detalhes de uma entrada de log específica.


**Para visualizar o log do projeto:**
1. Abra o Analyze
2. Selecione "Projetos"
3. Clique no ícone de log

**Para classificar e filtrar o log do projeto:**
1. Clique no pequeno ícone à direita do log e à esquerda da "mensagem de log"
2. Selecione as diretrizes desejadas

**Para ver os detalhes de uma entrada de log específica:**
1. Clique com o botão direito na entrada de log desejada
2. Veja os detalhes na caixa "Mensagem de log"

## Limpar o Log do Projeto

Pode ser conveniente limpar o log do projeto de tempos em tempos

<Aside>Limpar o log do projeto inclui excluir todos os sublogs de cada fluxo de trabalho</Aside>

**Para limpar o log do projeto:**
1. Abra o Analyze
2. Selecione "Projetos"
3. Clique no ícone de log
4. Clique no botão "Limpar log"
