O PlaidCloud oferece a capacidade de organizar e gerenciar hierarquias, incluindo rótulos. As hierarquias ficam disponíveis para todos os fluxos de trabalho de um projeto.

O PlaidCloud usa um sistema baseado em caminhos para organizar as hierarquias, como o que você usaria para navegar por uma série de pastas, permitindo uma organização mais flexível e lógica (hierarquia de controle) das hierarquias. Com esse sistema, as hierarquias podem ser movidas dentro de uma hierarquia de controle, ou é possível criar várias referências a uma hierarquia a partir de locais diferentes da hierarquia de controle (hierarquias alternativas). A capacidade de gerenciar hierarquias por esse método permite que a estrutura reflita necessidades operacionais, de relatórios e de controle.

## Pesquisar

Para pesquisar hierarquias:

1. Use a caixa de filtro no canto inferior esquerdo da hierarquia de controle
2. O filtro de pesquisa procura correspondências nos nomes e rótulos das hierarquias e mostra os resultados na hierarquia de controle acima

## Mover

Para mover uma hierarquia dentro da hierarquia de controle:

1. Arraste-a para a pasta em que deseja colocá-la

## Renomear

Para renomear uma hierarquia:

1. Clique com o botão direito na hierarquia
2. Selecione a opção de renomear
3. Digite o novo nome e salve
4. A hierarquia agora está renomeada, mas manterá seu identificador exclusivo original

## Limpar

Você pode limpar uma única hierarquia ou várias hierarquias.

Para limpar uma hierarquia:

1. Selecione as hierarquias na hierarquia de controle
2. Clique no botão de limpar na barra de ferramentas superior

## Excluir

### Você pode excluir uma única hierarquia ou várias hierarquias

Para excluir uma hierarquia:

1. Selecione as hierarquias na hierarquia de controle
2. Clique no botão de excluir na barra de ferramentas superior

A operação de exclusão verifica se a hierarquia está em uso por etapas de fluxo de trabalho, tabelas ou visões. Em caso afirmativo, você será solicitado a remover essas associações.

<Aside>Você também pode forçar a exclusão da(s) hierarquia(s). A exclusão forçada da(s) hierarquia(s) deixa as referências quebradas, portanto deve ser usada com moderação.</Aside>

## Criar uma nova estrutura de diretórios

Para criar uma nova pasta:

1. Clique no botão Nova pasta na barra de ferramentas

Para adicionar uma pasta a uma pasta existente:

1. Clique com o botão direito na pasta
2. Selecione Nova pasta.

## Marcar a hierarquia para papéis de visualização

Para ver hierarquias por papéis:

1. Clique nas caixas de seleção Explorador ou Gerente

Para ver hierarquias que precisam ser atualizadas:

1. Selecione as hierarquias na hierarquia de controle
2. Selecione o papel de visualização desejado no menu Ações da barra de ferramentas superior

## Memorandos para descrever o conteúdo da tabela

Para adicionar um memorando a uma hierarquia:

1. Selecione a hierarquia
2. Atualize o memorando no formulário de contexto à direita

## Ver atributos adicionais da hierarquia

Para ver e editar atributos adicionais da hierarquia:

1. Selecione uma hierarquia
2. Veja o formulário de contexto da hierarquia à direita

## Duplicar uma hierarquia

Para duplicar uma hierarquia:

1. Selecione a hierarquia

2. Clique no botão de duplicar na barra de ferramentas superior
