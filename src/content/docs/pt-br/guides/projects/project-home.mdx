## Descrição

A **Project home** é onde você começa em um projeto. Uma barra lateral à esquerda lista seis páginas: **Visão geral**, **Variáveis**, **Schedules & sensors**, **Access & sharing**, **Data & connections** e **Apps & branding**. A Visão geral resume o projeto. As outras cinco páginas são onde você altera as configurações do projeto.

O indicador de **Variáveis** na barra lateral mostra quantas variáveis o projeto tem. O indicador de **Schedules & sensors** mostra quantos agendamentos e sensores estão ativos.

Um projeto bloqueado é somente leitura. Suas páginas exibem um banner que diz "This project is locked, so it is read only. Unlock it on Overview to make changes." e seus controles ficam desativados.

## Visão geral

![Página Visão geral da Project home mostrando o nome do projeto, seis blocos, Coming up e Project defaults](/images/projects/project-home-overview.png)

A parte superior da página mostra o nome do projeto e se ele é **Editável** ou **Somente leitura**.

- **Descrição.** Clique no lápis para editar a descrição no próprio local. Pressione Enter para salvar ou Escape para cancelar.
- **Rótulos.** Digite um rótulo em **Adicionar um rótulo…** e clique em **Adicionar**. Consulte [Organizar o trabalho com rótulos](/pt-br/guides/projects/organizing-with-labels/).
- **Bloquear** e **Unlock** alternam o projeto entre editável e somente leitura.

Os blocos contam o que o projeto contém:

| Bloco | Mostra |
|---|---|
| **Tabelas** | Tabelas no projeto. |
| **Fluxos de trabalho** | Fluxos de trabalho no projeto. |
| **Etapas** | Etapas em todos os fluxos de trabalho. |
| **Variáveis** | Variáveis do projeto. |
| **Tabelas publicadas** | Tabelas que você publicou. |
| **Tamanho dos dados** | O que as tabelas do projeto armazenam. Clique para abrir **Armazenamento**. Consulte [Gerenciar o armazenamento](/pt-br/guides/projects/managing-storage/). |

Se algumas das linhas do projeto estiverem filtradas para você, **Tamanho dos dados** mostra um traço, porque o total não seria preciso.

**Coming up** lista as próximas três execuções agendadas com os nomes de seus fluxos de trabalho e o número de sensores ativos. **View schedules ›** abre **Schedules & sensors**.

**Project defaults** mostra os valores de **Ambiente**, **Armazenamento de tabelas**, **Acesso** e **Lançamento no ERP** que os fluxos de trabalho e as etapas usam, a menos que definam os seus próprios. **Change settings ›** abre a página em que você os altera.

Os botões do cabeçalho são:

- **Relatório do projeto** gera um relatório do projeto como **Documento PDF** ou **HTML interativo**.
- **Exportar arquivo compactado** salva o projeto como um arquivo compactado.
- **Atualizar** recarrega os blocos e as listas da página.

## Variáveis

A página **Variáveis** lista as variáveis do projeto em uma grade. Um fluxo de trabalho ou uma etapa se refere a uma variável pelo nome como `{name}`, e a variável do próprio fluxo de trabalho substitui uma variável de projeto de mesmo nome.

A grade mostra **Nome**, **Valor**, **Memorando**, **Última atualização** e **Por**. Use **Filtro** para restringir a lista, **Nova variável** para adicionar uma e **Editar** ou **Excluir** para a linha selecionada.

## Schedules & sensors

![Página Schedules and sensors com uma faixa de resumo e duas grades](/images/projects/project-home-schedules.png)

Esta página mostra o que inicia os fluxos de trabalho do projeto automaticamente. Uma faixa de resumo mostra a próxima execução, o número de agendamentos ativos e pausados e o número de sensores ativos.

- **Schedules** executam um fluxo de trabalho em um cronograma. A grade mostra **Nome**, **Fluxo de trabalho**, **Execuções** (o cronograma e seu fuso horário), **Próxima execução** e **Status**.
- **Sensores** executam um fluxo de trabalho quando chegam novos dados. A grade mostra **Nome**, **Watches**, **Início** (o fluxo de trabalho), **Last triggered** e **Status**.

**Status** é **Ativo**, **Paused** ou, para um sensor com problema, **Failing**. Cada grade tem **New schedule** ou **Novo sensor**, **Editar**, **Excluir** e **Filtro**. Abra **Ações** para **Activate** ou **Deactivate** a linha selecionada.

**Calendar view** mostra as próximas execuções em um calendário, para que você identifique conflitos de agendamento.

## Access & sharing

Esta página define quem pode acessar o projeto e seus dados.

- **Project access** define **Who can open this project**: **Todos os membros do espaço de trabalho**, **Somente grupos de segurança específicos** ou **Somente membros específicos**. **Edit groups ›** e **Edit members ›** abrem as listas para escolher.
- **Dashboard audience** define o **Default audience for new dashboards**: todos no projeto ou grupos específicos. Cada painel pode alterar o próprio público. Consulte [Controlar quem pode ver um painel](/pt-br/guides/dashboards/control-who-can-see-a-dashboard/).
- **Compartilhamentos de dados** lista os projetos que podem ler tabelas deste. Consulte [Compartilhar dados entre projetos](/pt-br/guides/projects/managing-projects/#compartilhar-dados-entre-projetos).

## Data & connections

![Página Data and connections com conexões, armazenamento de tabelas e lançamento no ERP](/images/projects/project-home-data.png)

Estas configurações se aplicam a todos os fluxos de trabalho e etapas do projeto, a menos que um fluxo de trabalho ou uma etapa defina as suas próprias.

- **Ambiente da conexão** escolhe as credenciais que uma etapa usa quando não escolhe uma. A página avisa quando uma conexão do projeto não tem configuração para o ambiente selecionado.
- **Conta de documentos padrão** escolhe onde as etapas leem e gravam arquivos.
- **Armazenamento padrão de tabelas** escolhe onde as novas tabelas são criadas.
- **Time travel retention** define por quantos dias as versões anteriores dos dados da tabela são mantidas. As tabelas que herdam essa configuração também mantêm um histórico mais longo. O histórico que já expirou não pode ser recuperado.
- **Modo de lançamento** define como o projeto envia lançamentos contábeis aos ERPs conectados. É um teto para o projeto: uma execução de fluxo de trabalho não pode lançar de forma mais permissiva do que esta configuração. **Ao vivo** lança normalmente. **Simular** monta e valida, mas nunca lança nem contata o ERP. **Desativado** ignora as etapas de lançamento.
- **Write authorizations** mostra quantas conexões de ERP estão autorizadas a lançar. Os administradores podem clicar em **Manage authorizations ›**.

## Apps & branding

Esta página abrange os aplicativos criados sobre os dados do projeto.

- **Aplicativos Panel** mostra quantos aplicativos foram criados sobre o projeto. **Open Panel apps ›** os abre, e **Novo aplicativo Studio** inicia um.
- **Branding** define o logotipo e as cores que os aplicativos do projeto usam. **Edit branding ›** abre as configurações.
- **Home tile image** é a imagem exibida no bloco do projeto na página inicial. Clique em **Escolher...** para selecionar uma imagem ou em **Limpar** para removê-la.
