O PlaidCloud mantém a barra de endereço em sincronia com o que você tem aberto. Abra um fluxo de trabalho, uma tabela, uma dimensão ou uma tela em Painéis, Documentos ou Identidade, e a URL se torna um **link direto** para ela: copie essa URL, cole em uma mensagem ou em um ticket, e quem abri-la chega à mesma tela.

## Copiar um link

1. Abra a tela que você quer compartilhar: um projeto, fluxo de trabalho, tabela, dimensão, editor de dados ou uma tela de um dos outros aplicativos.
2. Copie a URL inteira da barra de endereço do navegador.
3. Envie-a.

Não há um botão "compartilhar" separado: a barra de endereço *é* o link. O recurso de favoritos do navegador também funciona com essas URLs, então uma tela a que você volta com frequência pode ser salva como favorito como qualquer outra página da web.

<Aside type="note">
Um link carrega apenas a *localização*, não a permissão para vê-la. Quem abrir o link ainda precisa de acesso ao projeto. Quem não tiver acesso não verá o objeto.

Um link para um aplicativo que a pessoa não tem, porque o espaço de trabalho dela não o inclui ou porque ela não recebeu acesso, leva-a para Início com um aviso de que o link não estava disponível, em vez de parecer que nada aconteceu.
</Aside>

## Para o que você pode criar links

### Analyze

| Tela | O link termina com |
|---|---|
| Projeto | `#p~<project>` |
| Fluxo de trabalho (grade de etapas) | `#p~<project>~w~<workflow>` |
| Fluxo de trabalho (tela do Designer visual de fluxo de trabalho) | `#p~<project>~c~<workflow>` |
| Uma etapa dentro de um fluxo de trabalho | `…~w~<workflow>~s~<step>` ou `…~c~<workflow>~s~<step>` |
| Uma etapa isolada | `#p~<project>~s~<step>` |
| Explorador de tabelas | `#p~<project>~t~<table>` |
| Hierarquia de dimensão | `#p~<project>~d~<dimension>` |
| Editor de dados | `#p~<project>~e~<editor>` |
| Início | `#home` |

A parte do projeto no link é o **esquema** do seu projeto quando ele tem um personalizado, de modo que os links aparecem como `#p~acme_budget~w~…` em vez de uma sequência hexadecimal. Os projetos que continuam no esquema padrão usam o próprio identificador do projeto. As duas formas abrem o mesmo projeto, então um link mais antigo continua funcionando depois que um esquema é definido.

### Painéis, documentos e identidade

As telas dos outros aplicativos são nomeadas diretamente, então seus links mostram a própria tela:

| Aplicativo | Tela | Link |
|---|---|---|
| Painéis | Meus painéis | `#dashboard.dashboards` |
| Painéis | Aplicativos | `#dashboard.panel_apps` |
| Painéis | Jupyter Lite | `#dashboard.jupyterlite_deployments` |
| Documentos | Todas as contas | `#document.accounts` |
| Documentos | Contas compartilhadas | `#document.shared_accounts` |
| Documentos | Contas privadas | `#document.private_accounts` |
| Documentos | Navegação pelos arquivos de uma conta | `#document.browser~…` |
| Identidade | Membros | `#identity.members` |
| Identidade | Diretório de membros | `#identity.member_directory` |
| Identidade | Listas de distribuição | `#identity.distro.lists` |
| Identidade | Grupos de segurança | `#identity.security_groups` |
| Identidade | Auditoria de grupos de segurança | `#identity.security_group_audit` |
| Identidade | Escopos | `#identity.scopes` |
| Identidade | Sessões | `#identity.sessions` |
| Identidade | Clientes de API | `#identity.api_client_list` |
| Identidade | Log de segurança | `#identity.security_log` |

Algumas telas lembram uma configuração no link (as listas Membros e Diretório de membros mantêm cada uma se você estava vendo **Todos**, **Somente ativos** ou **Somente inativos**, e a navegação em uma conta mantém qual conta), o que o navegador mostra como um sufixo codificado após o nome da tela. Copie e cole a URL inteira e ela abre a tela em que você estava; abri-la quando essa tela já está aberta traz essa janela para a frente em vez de empilhar uma segunda.

<Aside type="note">
Esses links nomeiam a tela, não um registro dentro dela. Um link para Membros abre a lista de membros; ele não abre o formulário de um membro.
</Aside>

## O que acontece quando alguém abre um link

- **O projeto proprietário também é aberto.** Um link para um fluxo de trabalho, tabela, etapa, dimensão ou editor de dados também abre o projeto dele como uma guia na parte inferior da tela, de modo que o destinatário chega com o contexto ao redor, e não com uma única janela solta.
- **O link de uma etapa seleciona a etapa.** Um link para uma etapa dentro de um fluxo de trabalho abre o fluxo de trabalho e destaca essa etapa; na tela do Designer visual de fluxo de trabalho, o nó da etapa fica selecionado.
- **Uma dimensão abre pronta para edição** quando o projeto está desbloqueado e somente leitura quando está bloqueado, a mesma regra que vale quando você a abre a partir do projeto.
- **Atualizar a página mantém você onde está.** Recarregar a página reabre o que o link nomeia, em vez de levá-lo de volta ao início.

## Alternar entre telas

A URL acompanha o que você está vendo:

- Abrir uma tela atualiza a barra de endereço, e o botão **Voltar** do navegador leva você à anterior.
- **Qualquer que seja o caminho.** Abrir um fluxo de trabalho pelo fluxo de atividades, por um cartão de Início, por uma ação **Detalhar até o fluxo de trabalho**, por uma lista de "onde é usado" ou pelo log atualiza o link da mesma forma que abri-lo pela lista de fluxos de trabalho do projeto, e o mesmo vale para reabrir a tela em que você já está.
- Selecionar a guia de uma janela na parte inferior da tela coloca o link dessa janela de volta na barra de endereço, de modo que alternar entre telas abertas mantém a URL correta.
- Mudar para um aplicativo em que nada que possa receber link está aberto **limpa** o link, em vez de deixá-lo apontando para o aplicativo que você acabou de deixar.
- Fechar uma janela devolve a URL ao ponto de onde você a abriu. Feche uma tabela que você abriu a partir da tela de um fluxo de trabalho e a URL volta para essa tela; feche uma que você abriu a partir de um projeto e ela volta para o projeto.
- Fechar a última janela de um projeto limpa o link.

## Links salvos antes desta alteração

Os links no estilo antigo `#te?p=…&t=…` continuam funcionando. Abrir um deles leva você ao mesmo lugar e reescreve discretamente a barra de endereço no formato atual, então copiá-lo de novo a partir dali dá a você o link mais novo e mais legível.
