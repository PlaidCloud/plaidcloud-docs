O PlaidCloud mantém a barra de endereços em sintonia com o que você tem aberto. Abra um fluxo de trabalho, uma tabela, uma dimensão ou uma tela em Painéis, Documentos ou Identidade, e a URL se torna um **link direto** para ela — copie essa URL, cole em uma mensagem ou em um chamado, e quem a abrir chega à mesma tela.

## Copiar um link

1. Abra a tela que você quer compartilhar — um projeto, fluxo de trabalho, tabela, dimensão, editor de dados ou uma tela de um dos outros aplicativos.
2. Copie a URL inteira da barra de endereços do navegador.
3. Envie-a.

Não há um botão de "compartilhar" separado: a barra de endereços *é* o link. O recurso de favoritos do navegador também funciona com essas URLs, portanto uma tela à qual você volta com frequência pode ser adicionada aos favoritos como qualquer outra página da web.

<Aside type="note">
Um link carrega apenas a *localização*, não a permissão para vê-la. Quem abrir o link ainda precisa ter acesso ao projeto. Quem não tiver não verá o objeto.

Um link para um aplicativo que a pessoa não tem — porque o espaço de trabalho dela não o inclui ou porque ela não recebeu acesso a ele — leva-a ao Início com uma observação dizendo que o link não estava disponível, em vez de parecer que nada aconteceu.
</Aside>

## Para o que você pode criar links

### Analyze

| Tela | O link termina com |
|---|---|
| Projeto | `#p~<project>` |
| Fluxo de trabalho (grade de etapas) | `#p~<project>~w~<workflow>` |
| Fluxo de trabalho (tela do Designer visual de fluxo de trabalho) | `#p~<project>~c~<workflow>` |
| Uma etapa dentro de um fluxo de trabalho | `…~w~<workflow>~s~<step>` ou `…~c~<workflow>~s~<step>` |
| Uma etapa isolada | `#p~<project>~s~<step>` |
| Explorador de tabelas | `#p~<project>~t~<table>` |
| Hierarquia de dimensão | `#p~<project>~d~<dimension>` |
| Editor de dados | `#p~<project>~e~<editor>` |
| Início | `#home` |

A parte do projeto no link é o **esquema** do seu projeto quando ele tem um personalizado, de modo que os links aparecem como `#p~acme_budget~w~…` em vez de uma sequência hexadecimal. Os projetos que permanecem no esquema padrão usam o identificador do próprio projeto. As duas formas abrem o mesmo projeto, portanto um link mais antigo continua funcionando depois que um esquema é definido.

### Painéis, Documentos e Identidade

As telas dos outros aplicativos são nomeadas diretamente, portanto seus links aparecem como a própria tela:

| Aplicativo | Tela | Link |
|---|---|---|
| Painéis | Painéis | `#dashboard.dashboards` |
| Painéis | Aplicativos | `#dashboard.panel_apps` |
| Painéis | Notebooks | `#dashboard.jupyterlite_deployments` |
| Documentos | Gerenciar | `#document.accounts` |
| Documentos | Suas contas | `#document.your_accounts` |
| Documentos | Navegação pelos arquivos de uma conta | `#document.browser~…` |
| Identidade | Membros | `#identity.members` |
| Identidade | Diretório | `#identity.member_directory` |
| Identidade | Listas de distribuição | `#identity.distro.lists` |
| Identidade | Grupos de segurança | `#identity.security_groups` |
| Identidade | Auditoria de grupos | `#identity.security_group_audit` |
| Identidade | Todos os escopos | `#identity.scopes` |
| Identidade | Sessões | `#identity.sessions` |
| Identidade | Clientes de API | `#identity.api_client_list` |
| Identidade | Log de segurança | `#identity.security_log` |

Algumas telas lembram uma configuração no link — as listas Membros e Diretório de membros mantêm, cada uma, se você estava vendo **Todos**, **Somente ativos** ou **Somente inativos**, e navegar por uma conta mantém qual conta — o que o navegador mostra como um sufixo codificado após o nome da tela. Copie e cole a URL inteira e ela abre a tela em que você estava; abri-la quando essa tela já está aberta traz essa janela para a frente em vez de empilhar uma segunda.

<Aside type="note">
Esses links nomeiam a tela, não um registro dentro dela. Um link para Membros abre a lista de Membros; ele não abre o formulário de um membro específico.
</Aside>

## O que acontece quando alguém abre um link

- **O projeto proprietário também é aberto.** Um link para um fluxo de trabalho, tabela, etapa, dimensão ou editor de dados também abre o projeto dele como uma guia na parte inferior da tela, de modo que o destinatário chega com o contexto ao redor, em vez de uma única janela solta.
- **O link de uma etapa seleciona a etapa.** Um link para uma etapa dentro de um fluxo de trabalho abre o fluxo de trabalho e destaca essa etapa — na tela do Designer visual de fluxo de trabalho, o nó da etapa é selecionado.
- **Uma dimensão abre pronta para edição** quando o projeto está desbloqueado e somente para leitura quando está bloqueado — a mesma regra que se aplica quando você a abre a partir do projeto.
- **Atualizar a página mantém você onde está.** Recarregar a página reabre o que o link nomeia, em vez de levar você de volta ao início.

## Navegar entre telas

A URL acompanha o que você está vendo:

- Abrir uma tela atualiza a barra de endereços, e o botão **Voltar** do navegador leva você à tela anterior.
- **Não importa como você chegou lá.** Abrir um fluxo de trabalho a partir do fluxo de atividades, de um cartão do Início, de uma ação **Detalhar até o fluxo de trabalho**, de uma listagem de "onde é usado" ou do log atualiza o link da mesma forma que abri-lo a partir da lista de Fluxos de trabalho do projeto — e o mesmo vale para reabrir a tela em que você já está.
- Selecionar a guia de uma janela na parte inferior da tela coloca o link dessa janela de volta na barra de endereços, de modo que alternar entre telas abertas mantém a URL fiel.
- Alternar para um aplicativo em que nada que possa receber link está aberto **limpa** o link, em vez de deixá-lo apontando para o aplicativo que você acabou de deixar.
- Fechar uma janela devolve a URL ao ponto de onde você a abriu. Feche uma tabela que você abriu a partir da tela de um fluxo de trabalho e a URL volta para essa tela; feche uma que você abriu a partir de um projeto e ela volta para o projeto.
- Fechar a última janela de um projeto limpa o link.

## Links salvos antes desta mudança

Os links no estilo mais antigo `#te?p=…&t=…` ainda funcionam. Abrir um deles leva você ao mesmo lugar e reescreve discretamente a barra de endereços na forma atual, de modo que copiá-lo novamente a partir dali dá a você o link mais novo e mais legível.
