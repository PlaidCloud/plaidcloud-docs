## Organização, espaço de trabalho, membro

Sua conta começa no nível da **organização**, que é o limite de cobrança e de identidade. Dentro de uma organização há um ou mais **espaços de trabalho**, que são ambientes isolados onde o trabalho de fato acontece. Os **membros** são usuários que pertencem a uma organização e recebem acesso a espaços de trabalho específicos, com funções específicas.

- A maioria das equipes começa com um espaço de trabalho por ambiente (desenvolvimento, homologação, produção) ou um por unidade de negócios.
- Os grupos de segurança dentro de um espaço de trabalho controlam o que cada membro pode fazer.

Mais informações: [Gerenciamento de acesso](/pt-br/administration/access/)

## Projeto

Um **projeto** é a unidade de trabalho dentro de um espaço de trabalho. Cada projeto possui seus próprios dados, fluxos de trabalho, dimensões e histórico de auditoria. Os projetos não compartilham estado entre si; eles são isolados.

Use projetos para separar análises, processos de negócios ou produtos de dados distintos uns dos outros.

Mais informações: [Projetos](/pt-br/guides/projects/)

## Conexão

Uma **conexão** é uma configuração salva que permite ao PlaidCloud acessar um sistema externo: um banco de dados, uma conta de armazenamento em nuvem, um ERP, uma API REST. As conexões são reutilizadas pelas etapas do fluxo de trabalho, de modo que as credenciais não sejam duplicadas entre as etapas.

Mais informações: [Conexões (tarefas)](/pt-br/guides/connections/) · [Conectores (referência)](/pt-br/reference/connectors/)

## Tabela e visão

Uma **tabela** é um conjunto de dados estruturados dentro de um projeto: linhas e colunas, como uma tabela SQL. As tabelas vêm de importações, transformações ou origens externas. As **visões** são resultados de consultas salvos, construídos sobre as tabelas.

Mais informações: [Tabelas e visões](/pt-br/guides/data/)

## Fluxo de trabalho e etapa

Um **fluxo de trabalho** é um pipeline que opera sobre tabelas. Cada fluxo de trabalho é uma sequência de **etapas**: importar um CSV, juntar duas tabelas, filtrar linhas, exportar para JSON, enviar uma notificação. As etapas podem ser executadas em sequência, em paralelo, de forma condicional ou em loops.

As etapas se dividem em categorias:

- **Importar** — traz dados para dentro (CSV, Excel, SQL, Parquet, JSON etc.)
- **Tabelas** — transforma tabelas (junção, filtro, melt, pivô, anexação, upsert)
- **Exportar** — envia dados para fora
- **Documento** — trata PDFs, imagens e arquivos em geral
- **Notificações** — envia mensagens por e-mail, Slack, Teams, SMS e webhook
- **Alocação** — executa modelos de alocação de custos
- **Dimensão** — cria e modifica hierarquias
- **SAP / SAP-PCM** — chama operações específicas do SAP
- **Controle de fluxo de trabalho** — variáveis, loops, subfluxos de trabalho

Mais informações: [Fluxos de trabalho (tarefas)](/pt-br/guides/workflows/) · [Etapas de fluxo de trabalho (referência)](/pt-br/reference/workflow-steps/)

## Dimensão

Uma **dimensão** é uma hierarquia, normalmente usada para segmentar ou agregar dados. Centros de custo, produtos, geografia, tempo. As dimensões podem ser criadas a partir de tabelas, carregadas de origens externas ou modificadas de forma incremental.

As alocações usam dimensões para decidir *o que alocar a quê*.

Mais informações: [Dimensões](/pt-br/guides/dimensions/)

## Alocação

Uma **alocação** distribui valores de um conjunto de linhas para outro com base em dados de direcionadores e em regras. Pense em preço de transferência, custeio baseado em atividades, rateio de TI, rentabilidade: qualquer situação em que há um conjunto de custos que precisa ser distribuído entre consumidores.

As alocações combinam tabelas (valores, direcionadores, resultados), dimensões (as regras) e etapas de fluxo de trabalho (para executar o modelo).

Mais informações: [Alocações](/pt-br/guides/allocations/)

## Painel

Um **painel** é uma visão publicada e interativa dos dados de um projeto. Crie-o a partir de tabelas e visões publicadas.

Mais informações: [Painéis](/pt-br/guides/dashboards/)

## Assistente de IA

Um chat com escopo de projeto para fazer perguntas sobre seus dados e fluxos de trabalho. As conversas são mantidas e isoladas por projeto.

Mais informações: [Assistente de IA](/pt-br/guides/ai-assistant/)

## Como tudo se encaixa

Um fluxo completo típico:

1. **Configure uma conexão** com o seu sistema de origem.
2. Dentro de um **projeto**, crie um **fluxo de trabalho** que:
   - **Importa** dados pela conexão (cria tabelas)
   - **Transforma** com etapas de tabela
   - **Junta** com **dimensões** para dar contexto
   - **Aloca**, se você estiver distribuindo custos
   - **Publica** o resultado
3. Um **painel** lê as tabelas publicadas.
4. Os **membros do espaço de trabalho** navegam pelo painel ou consultam os resultados pelo Assistente de IA.
