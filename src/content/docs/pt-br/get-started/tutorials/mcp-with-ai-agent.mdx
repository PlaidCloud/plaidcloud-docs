Este tutorial configura um agente de programação com IA para interagir com seu espaço de trabalho do PlaidCloud usando o **Model Context Protocol** (MCP). Depois de configurado, você pode pedir ao agente que leia tabelas, execute fluxos de trabalho, crie alocações e responda a perguntas sobre seus dados, diretamente do seu editor.

Leva cerca de 20 minutos. Funciona com Claude Code, Cursor, Claude Desktop, ChatGPT, GitHub Copilot e qualquer cliente compatível com MCP.

## O que você vai criar

Uma conexão funcional entre seu agente de programação com IA e seu espaço de trabalho do PlaidCloud, na qual o agente pode:

- Listar projetos, tabelas, fluxos de trabalho e dimensões
- Ler o conteúdo de tabelas
- Inspecionar definições de fluxos de trabalho
- Disparar execuções de fluxos de trabalho
- Responder a perguntas sobre seus dados sem que você precise trocar de contexto

## Pré-requisitos

- Um espaço de trabalho do PlaidCloud ([inicie um teste gratuito](https://app.plaidcloud.com) se você não tiver um)
- Um agente de programação com IA que você já use: Claude Code, Cursor, Claude Desktop, ChatGPT, Copilot ou Gemini
- O agente deve ser compatível com MCP (a maioria das ferramentas de IA atuais é)

## Etapa 1: encontre a URL do MCP do seu espaço de trabalho

Todo espaço de trabalho do PlaidCloud expõe um endpoint MCP em:

```text
https://<your-workspace>.plaid.cloud/mcp
```

Substitua `<your-workspace>` pelo subdomínio do seu espaço de trabalho, o mesmo que você usa para entrar na interface do PlaidCloud.

## Etapa 2: obtenha um token de autenticação

<Steps>

1. Com a sessão do PlaidCloud iniciada em um navegador, acesse:
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. Copie o token de portador exibido na página. Guarde-o em segurança: ele concede o mesmo acesso que sua conta tem.

</Steps>

<Aside type="caution">
Trate o token como uma senha. Ele ignora a autenticação interativa e age em seu nome. Se ele vazar, revogue-o no mesmo endpoint.
</Aside>

## Etapa 3: configure seu agente

<Tabs>

<TabItem label="Claude Code">

Execute no seu terminal:

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

Para autenticação com token estático (sem fluxo OAuth, mais simples para sessões longas), abra a URL da Etapa 2 em um navegador, copie o trecho de configuração exibido e cole-o no seu arquivo `.mcp.json`.

Consulte a [configuração do Claude Code](/pt-br/integrations/ai-coding-agents/claude-code/) para ver todas as opções.

</TabItem>

<TabItem label="Cursor">

Obtenha um token de portador em `https://<your-workspace>.plaid.cloud/mcp/setup/token` e adicione isto à configuração de MCP do Cursor:

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

Consulte a [configuração do Cursor](/pt-br/integrations/ai-coding-agents/cursor/) para ver todas as opções.

</TabItem>

<TabItem label="Claude Desktop">

Abra Configurações → Developer → MCP Servers e adicione:

- **URL do servidor**: `https://<your-workspace>.plaid.cloud/mcp`
- Use o login OAuth quando solicitado

Consulte a [configuração do Claude Desktop](/pt-br/integrations/ai-coding-agents/claude-desktop/) para ver todas as opções.

</TabItem>

<TabItem label="ChatGPT">

1. Configurações → Connectors → Add custom connector
2. Informe:
   - **Nome**: `PlaidCloud`
   - **URL do servidor MCP**: `https://<your-workspace>.plaid.cloud/mcp`
3. O ChatGPT redireciona você ao PlaidCloud para o login OAuth. Aprove a conexão.
4. Ative o conector em qualquer conversa que deva usá-lo.

Consulte a [configuração do ChatGPT](/pt-br/integrations/ai-coding-agents/chatgpt/) para ver todas as opções.

</TabItem>

<TabItem label="Copilot">

Obtenha um token de portador e adicione-o a `.vscode/mcp.json`:

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

O VSCode lê esse arquivo ao iniciar e sempre que ele muda.

Consulte a [configuração do Copilot](/pt-br/integrations/ai-coding-agents/copilot/) para ver todas as opções.

</TabItem>

</Tabs>

## Etapa 4: verifique a conexão

Peça ao agente algo simples:

> "Liste os projetos no meu espaço de trabalho do PlaidCloud."

O agente deve responder com a lista dos seus projetos. Se não responder, consulte as etapas de solução de problemas abaixo.

## Etapa 5: experimente tarefas reais

Depois de conectado, experimente:

- **Explorar seus dados**: "Quais colunas a tabela `sales` do meu projeto Quickstart tem?"
- **Executar um fluxo de trabalho**: "Dispare o fluxo de trabalho `monthly_close` no projeto Financials e me avise quando terminar."
- **Criar algo**: "Crie uma etapa Table Lookup no meu fluxo de trabalho Test que filtre os pedidos dos últimos 30 dias."

As respostas do agente se baseiam no estado real do seu espaço de trabalho, e não em respostas genéricas.

## Solução de problemas

Se o agente não conseguir acessar o PlaidCloud ou retornar erros de autenticação:

- **Token expirado**: atualize-o em `https://<your-workspace>.plaid.cloud/mcp/setup/token`
- **Escopos incorretos**: algumas ferramentas exigem escopos específicos do PlaidCloud (por exemplo, `analyze.workflow.write`). Execute `mcp_introspect(name='<tool>')` no agente para ver os escopos necessários
- **Subdomínio do espaço de trabalho incorreto**: confirme entrando na interface do PlaidCloud; o subdomínio é a parte antes de `.plaid.cloud`

Consulte a [solução de problemas de agentes de programação com IA](/pt-br/integrations/ai-coding-agents/troubleshooting/) para saber mais.
