## O que é o PlaidCloud?

O PlaidCloud é uma plataforma unificada de análise financeira. Conecte fontes de dados, crie fluxos de trabalho que transformam e combinam os dados, defina dimensões e hierarquias que correspondam à forma como sua empresa está organizada, execute alocações de custos e publique os resultados em painéis ou sistemas downstream — tudo em uma única plataforma.

## Quem usa o PlaidCloud?

Principalmente equipes de finanças, FP&A e análise em organizações de médio e grande porte que realizam trabalhos como:

- **Alocação de custos** — custeio baseado em atividades, rateio de TI, distribuição de serviços compartilhados, preço de transferência
- **Análise de rentabilidade** — margem por cliente / produto / canal em escala
- **Consolidação financeira** — combinação de dados entre entidades e moedas
- **Relatórios operacionais** — painéis sobre dados corporativos com métricas limpas e governadas
- **Data warehousing** — criação de uma camada analítica unificada sobre sistemas operacionais

### Preciso de uma formação técnica específica?

A maioria dos usuários do PlaidCloud são analistas de negócios que dominam o básico de Excel e SQL. Você não precisa ser desenvolvedor. A plataforma expõe fluxos de trabalho e operações de dados por meio de uma interface visual, com expressões SQL disponíveis quando você precisar.

## Planos e preços

### Quais planos estão disponíveis?

O PlaidCloud oferece espaços de trabalho de avaliação self-service, planos para equipes e planos enterprise. Os limites dos planos, os preços e a disponibilidade de recursos variam entre os níveis.

Para preços e detalhes de planos atuais, consulte [plaidcloud.com](https://plaidcloud.com/) ou entre em contato com sua equipe de conta.

### Preciso de cartão de crédito para me cadastrar?

Não — o plano **Free** exige apenas a verificação do e-mail. Não há cartão de crédito nem etapa de pagamento; basta verificar seu e-mail e seu espaço de trabalho é criado. (Os planos pagos **Inicial** e **Equipe** oferecem uma avaliação opcional de 7 dias que coleta um cartão para que possa ser convertida automaticamente; o plano **Free** é permanente e nunca pede um.)

### Há limites no plano Free?

O plano **Free** é permanente (sem limite de tempo), com limites de uso adequados para avaliar a plataforma. As **avaliações Inicial/Equipe** de 7 dias, separadas, dão acesso total a esses níveis por uma semana. Os detalhes são mostrados durante o cadastro.

### Posso trocar de plano depois?

Sim — os espaços de trabalho podem ser atualizados para um plano superior sem perder dados nem quebrar integrações. Converse com sua equipe de conta sobre o melhor caminho para a sua situação.

## Recursos e limites

### Qual o tamanho máximo dos dados?

O mecanismo Lakehouse do PlaidCloud trata desde pequenas tabelas de referência (centenas de linhas) até conjuntos de dados analíticos com bilhões de linhas. Para cargas de trabalho muito grandes, converse com sua equipe de conta sobre o dimensionamento — os recursos de computação são configuráveis.

### O PlaidCloud substitui meu data warehouse?

Pode substituir. O PlaidCloud Lakehouse é um repositório analítico completo que pode servir como seu data warehouse principal ou ficar ao lado de um já existente (Snowflake, BigQuery, Redshift etc.) e extrair dados dele por meio de [conectores](/pt-br/reference/connectors/).

### Posso executar o PlaidCloud no local (on-premises)?

O PlaidCloud é uma plataforma SaaS. Para acessar fontes de dados locais, o [PlaidLink Agent](/pt-br/reference/cli/plaidlink/) é instalado dentro da sua rede e conecta o PlaidCloud a bancos de dados e sistemas de arquivos protegidos por firewall.

### O PlaidCloud tem uma API?

Sim. A API é exposta por locatário dentro de cada espaço de trabalho, portanto a documentação interativa da API fica no seu espaço de trabalho, e não centralizada neste site de documentação. Para integração programática, os padrões de acesso por Jupyter / CLI em [Jupyter CLI](/pt-br/reference/cli/jupyter/) e [PlaidLink](/pt-br/reference/cli/plaidlink/) são bons pontos de partida.

## Trabalhando com o produto

### Posso usar o Excel com o PlaidCloud?

Sim — o [PlaidXL](/pt-br/reference/cli/plaidxl/) é o suplemento do PlaidCloud para Excel. Ele traz tabelas e dimensões do projeto para as planilhas, atualiza-as sob demanda e adiciona fórmulas que calculam valores consolidados a partir dos dados do PlaidCloud. É útil para analistas cujo ambiente principal de modelagem é o Excel. [Trabalhe no Excel com o PlaidXL](/pt-br/get-started/tutorials/excel-with-plaidxl/) ajuda você a começar em cerca de 20 minutos.

### Posso usar ferramentas de IA como Claude Code ou Cursor?

Sim — o PlaidCloud expõe um servidor MCP (Model Context Protocol) por espaço de trabalho. Consulte [Agentes de codificação de IA](/pt-br/integrations/ai-coding-agents/) para a configuração.

### Posso usar notebooks Jupyter?

Sim — consulte [Jupyter CLI](/pt-br/reference/cli/jupyter/). A autenticação usa tokens OAuth, portanto as mesmas credenciais funcionam na CLI, nos notebooks e na API REST.

### Posso usar SQL diretamente?

Sim — os fluxos de trabalho aceitam expressões SQL para cálculos de colunas, filtros e junções. A [referência de expressões](/pt-br/reference/expressions/) cobre todas as funções SQL disponíveis, divididas por versão do mecanismo Lakehouse.

### Como agendo fluxos de trabalho?

O PlaidCloud tem agendamento integrado. Consulte [Eventos agendados](/pt-br/administration/scheduled-events/).

### Como sou notificado quando um fluxo de trabalho termina (ou falha)?

Use uma etapa de notificação — [e-mail](/pt-br/reference/workflow-steps/notifications/notify-via-email/), [Slack](/pt-br/reference/workflow-steps/notifications/notify-via-slack/), [Teams](/pt-br/reference/workflow-steps/notifications/notify-via-microsoft-teams/), [SMS](/pt-br/reference/workflow-steps/notifications/notify-via-sms/) ou [webhook](/pt-br/reference/workflow-steps/notifications/notify-via-web-hook/). Você também pode configurar um fluxo de trabalho de correção que é executado automaticamente em caso de falha.

## Segurança e acesso

### Como as permissões são gerenciadas?

O PlaidCloud usa **grupos de segurança** no nível do espaço de trabalho. Os membros são atribuídos a grupos; os grupos concedem recursos específicos. Consulte [Gerenciamento de acesso](/pt-br/administration/access/).

### Posso usar logon único (SSO)?

Sim — o PlaidCloud oferece suporte ao SAML 2.0. Consulte os guias de configuração para [Okta](/pt-br/administration/access/advanced/okta-saml-setup/), [Auth0](/pt-br/administration/access/advanced/auth0-saml-setup/), [Microsoft Entra](/pt-br/administration/access/advanced/entra-saml-setup/), [Google](/pt-br/administration/access/advanced/google-saml-setup/) e [AWS](/pt-br/administration/access/advanced/aws-saml-setup/).

### Onde meus dados são armazenados?

Os dados do PlaidCloud são armazenados na região de nuvem configurada para o seu locatário. Converse com sua equipe de conta sobre implantações específicas por região se você tiver requisitos de residência de dados.

### Como os dados são criptografados?

Em trânsito e em repouso. As chaves de criptografia são gerenciadas pela plataforma; opções de gerenciamento de chaves para setores regulamentados estão disponíveis nos planos enterprise.

## Armadilhas comuns

### Minha etapa de fluxo de trabalho falha com "No Rows Returned"

Geralmente significa que o filtro ou a junção não correspondeu ao que você esperava. Abra as tabelas de origem no Explorador de tabelas e verifique:

- As colunas de chave da junção têm a mesma grafia nas duas tabelas (inclusive maiúsculas e minúsculas)?
- Há espaços no início/fim ou caracteres ocultos nos valores da chave?
- A condição do filtro é mais restritiva do que você pretendia?

### Os resultados da minha alocação não conciliam

A soma dos valores alocados deve ser igual à soma dos valores de origem. Se não for:

- **Linhas de origem órfãs** — uma linha de origem sem dados de direcionador correspondentes não será alocada. Verifique se toda linha de origem tem um valor de direcionador.
- **Membros de destino ausentes** — um membro da dimensão sem entrada de direcionador não receberá alocação. Confirme que a dimensão e a tabela de direcionadores estão sincronizadas.
- **Direcionadores negativos** — produzem comportamento inesperado. Filtre-os ou trate-os explicitamente.

Consulte [Solução de problemas de alocações](/pt-br/guides/allocations/results/troubleshooting-allocations/).

### Minha carga de dimensão criou membros duplicados

Geralmente é um problema de maiúsculas/minúsculas ou de espaços nos dados de origem. As dimensões tratam "ACME Corp" e "Acme Corp" como membros diferentes. Normalize a origem antes de carregar ou use uma etapa de transformação anterior para limpá-la.

### Não consigo ver um projeto mencionado por um colega

A visibilidade dos projetos é controlada pelos grupos de segurança do espaço de trabalho. Peça a um administrador do espaço de trabalho que adicione você ao grupo que concede acesso ao projeto.

## Como obter ajuda

### Como entro em contato com o suporte?

- Para usuários de avaliação e self-service: envie um e-mail para [support@plaidcloud.com](mailto:support@plaidcloud.com)
- Para clientes enterprise: seu canal de suporte dedicado, normalmente Slack ou um portal do cliente — pergunte à sua equipe de conta

### Onde registro um bug ou uma solicitação de recurso?

Pelos mesmos canais do suporte. Bugs que afetam especificamente a documentação também podem ser sinalizados pelo link **Edit Page** no topo de qualquer página da documentação.

### Existe uma comunidade de usuários?

Os fóruns de usuários do PlaidCloud e a base de conhecimento compartilhada podem ser acessados pelo menu de ajuda do produto assim que você tiver um espaço de trabalho. O site de documentação é o recurso voltado ao público.
