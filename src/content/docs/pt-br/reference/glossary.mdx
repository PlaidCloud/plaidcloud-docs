Um único lugar de referência para os termos do produto. Se um guia ou uma página de referência usar uma palavra daqui, é este o significado dela.

## Conta

Um login do PlaidCloud. Uma conta pertence a uma ou mais organizações e recebe acesso a espaços de trabalho específicos dentro dessas organizações.

## Assistente de IA

Uma interface de chat no escopo do projeto, dentro do PlaidCloud, para fazer perguntas sobre os dados, gerar expressões e operar sobre projetos em linguagem natural. Veja o [guia do Assistente de IA](/pt-br/guides/ai-assistant/).

## Alocação

Uma operação de fluxo de trabalho que distribui valores de um conjunto de linhas ("origem") para outro ("destino") com base em dados de direcionadores e em regras. Usada para preço de transferência, custeio baseado em atividades, rateio de custos de TI, análise de rentabilidade e problemas semelhantes de distribuição de custos. Veja [Alocações](/pt-br/guides/allocations/).

## Conexão

Uma configuração salva que permite ao PlaidCloud acessar um sistema externo — um banco de dados, uma conta de armazenamento em nuvem, um ERP, uma API REST. As conexões são reutilizadas pelas etapas do fluxo de trabalho, de modo que as credenciais ficam em um único lugar. Veja [Conexões (guia)](/pt-br/guides/connections/) · [Conectores (referência)](/pt-br/reference/connectors/).

## Aplicativo Dash

Um aplicativo interativo personalizado criado sobre os dados do PlaidCloud com o framework Plotly Dash, publicado a partir de um repositório Git e hospedado em paridade com um aplicativo Panel de servidor. Veja [Aplicativos Dash](/pt-br/guides/dash-apps/).

## Painel

Uma visão interativa e publicada dos dados do projeto, criada a partir de tabelas e visões. Veja [Painéis](/pt-br/guides/dashboards/).

## Dimensão

Uma hierarquia, usada para segmentar e agregar dados. Centros de custo, produtos, geografia e períodos de tempo são dimensões comuns. As alocações usam dimensões para decidir o que alocar para o quê. Veja [Dimensões](/pt-br/guides/dimensions/).

## Direcionador

Em uma alocação, os dados que determinam *como* os valores são distribuídos entre os destinos. Exemplo: se você está alocando o custo de TI para unidades de negócio com base no número de funcionários, a tabela de número de funcionários é o direcionador.

## Lakehouse

O armazenamento analítico de dados subjacente do PlaidCloud. A biblioteca de expressões é versionada pelo mecanismo do Lakehouse: **Lakehouse v1** (baseado em Databend) e **Lakehouse v2** (baseado em StarRocks). Veja a [referência de expressões](/pt-br/reference/expressions/).

## MCP

Model Context Protocol — o padrão que o PlaidCloud usa para se integrar a agentes de programação com IA (Claude Code, Cursor, Copilot etc.). Veja [Agentes de programação com IA](/pt-br/integrations/ai-coding-agents/).

## Membro

Uma conta de usuário com acesso a um espaço de trabalho. Os membros são atribuídos a grupos de segurança dentro do espaço de trabalho, que controlam o que eles podem fazer. Veja [Gerenciamento de acesso](/pt-br/administration/access/).

## Organização

O limite superior de cobrança e identidade no PlaidCloud. Uma organização contém um ou mais espaços de trabalho e uma ou mais contas de membros.

## Aplicativo Panel

Um aplicativo interativo personalizado criado sobre os dados do PlaidCloud, normalmente com o framework Panel. Veja [Aplicativos Panel](/pt-br/guides/panel-apps/).

## PlaidLink

O daemon de conector local do PlaidCloud — executado como serviço do Windows, daemon Unix/Linux/Mac ou serviço em contêiner para conectar os fluxos de trabalho do PlaidCloud a fontes de dados locais. Veja a [referência do PlaidLink](/pt-br/reference/cli/plaidlink/).

## PlaidXL

O suplemento do PlaidCloud para Excel. Ele recupera e atualiza tabelas e dimensões do projeto nas planilhas e adiciona fórmulas `PLAIDXL` que calculam valores consolidados a partir dos dados do PlaidCloud. Veja a [referência do PlaidXL](/pt-br/reference/cli/plaidxl/).

## Projeto

Uma unidade de trabalho dentro de um espaço de trabalho. Cada projeto tem as suas próprias tabelas, fluxos de trabalho, dimensões e histórico de auditoria. Os projetos são isolados entre si — não compartilham estado. Veja [Projetos](/pt-br/guides/projects/).

## Publicar

Disponibilizar uma tabela do projeto para consumo externo (painéis, ferramentas de BI, sistemas downstream). Veja [Publicação de dados](/pt-br/guides/data/publish/).

## Grupo de segurança

Um conjunto de permissões dentro de um espaço de trabalho. Os membros são atribuídos a grupos de segurança para receber capacidades específicas (ler tabelas, editar fluxos de trabalho, gerenciar membros etc.). Veja [Grupos de segurança](/pt-br/administration/access/managing-security-groups-and-assignments/).

## Etapa

Uma única operação dentro de um fluxo de trabalho — importar um CSV, juntar duas tabelas, enviar uma notificação, executar uma alocação. As etapas se dividem em categorias (importação, exportação, tabelas, alocação, dimensão, documento, notificações etc.). Veja a [referência de etapas de fluxo de trabalho](/pt-br/reference/workflow-steps/).

## Tabela

Dados estruturados em linhas e colunas dentro de um projeto. As tabelas vêm de importações, transformações ou fontes externas.

## Visão

O resultado de uma consulta salva, em camada sobre uma ou mais tabelas. Comporta-se como uma tabela para os consumidores downstream, mas os dados subjacentes são reavaliados a cada leitura.

## Fluxo de trabalho

Uma sequência de etapas que opera sobre tabelas. A unidade de automação do PlaidCloud. Os fluxos de trabalho podem ser executados em sequência, em paralelo, de forma condicional ou em loops. Veja [Fluxos de trabalho (guia)](/pt-br/guides/workflows/) · [Etapas de fluxo de trabalho (referência)](/pt-br/reference/workflow-steps/).

## Espaço de trabalho

Um ambiente isolado dentro de uma organização, onde o trabalho de fato acontece. As equipes costumam usar um espaço de trabalho por ambiente (desenvolvimento, homologação, produção) ou por unidade de negócio. Os membros recebem acesso no nível do espaço de trabalho. Veja [Gerenciamento de acesso](/pt-br/administration/access/).
