## Documentação da API
A [referência da API do fornecedor](https://developers.paycor.com/explore) cobre os endpoints deste conector.

## Configuração do Paycor
O processo de criação e inicialização do aplicativo de API do Paycor é um pouco mais trabalhoso do que o de outros provedores REST. Siga todas as etapas descritas na [página Quick Start](https://developers.paycor.com/guides#quickStartLabel) deles.

Os valores principais que você precisa anotar são:
 - ID do cliente OAuth do aplicativo
 - Segredo do cliente OAuth do aplicativo
 - Chave de assinatura do APIm
 - Chave de escopo da versão `current` do aplicativo

<Aside type="caution">Não se esqueça de "ativar" o aplicativo para permitir o uso</Aside>

Ative-o aqui, escolhendo Produção ou Sandbox conforme a sua necessidade:

| Ambiente | URL do formulário de ativação |
|-------------|---------------------|
| Sandbox	  | https://hcm-demo.paycor.com/AppActivation/ClientActivation |
| Produção  | https://hcm.paycor.com/AppActivation/ClientActivation |

<Aside type="danger">Se você tiver várias organizações no Paycor, precisará de logins separados para cada uma. NÃO os una. O portal do desenvolvedor exige um login exclusivo e dedicado para cada organização, para criar um aplicativo específico da organização para acesso REST.</Aside>

## Configuração

Estes campos aparecem ao criar ou editar esta conexão.

### Identificação

| Campo | Tipo | Descrição |
|---|---|---|
| Nome | Texto | Nome de exibição desta conexão. |
| Alias | Texto (várias linhas) | Alias ou observações opcionais sobre a conexão. |
| Está ativa | Alternância | Indica se a conexão está ativada. Desative para pausá-la sem excluí-la. |
| Banco somente leitura | Alternância | Restringe a conexão a operações somente leitura. |
| Tipo de acesso | Seleção | Nível de acesso desta conexão: somente leitura, somente gravação ou leitura e gravação. |

### Credenciais

Informe os três valores que você anotou em [Configuração do Paycor](#configuração-do-paycor). Você não informa um host nem uma URL de token: o PlaidCloud fornece o host da API do Paycor e o endpoint de token OAuth2 para você.

| Campo | Tipo | Descrição |
|---|---|---|
| ID do cliente OAuth2 | Texto | O ID do cliente OAuth do aplicativo, do registro do seu aplicativo no Paycor. |
| Segredo do cliente OAuth2 | Senha | O segredo do cliente OAuth do aplicativo. Armazenado de forma criptografada. |
| Chave de assinatura do Paycor | Texto | A chave de assinatura do APIm do seu aplicativo no Paycor. |

## Autenticação

O Paycor usa OAuth2 com concessão por código de autorização, então informar as credenciais é só a primeira metade: você também conclui um login único no Paycor que autoriza o PlaidCloud a extrair os seus dados.

1. **Informe as credenciais e salve.** Preencha os três valores acima e salve a conexão.
2. **Conecte.** Clique em **Conectar ao Paycor**. O PlaidCloud abre uma **janela de autorização do Paycor**. O botão fica disponível depois que a conexão é salva.
3. **Faça login e aprove.** Entre no Paycor nessa janela e aprove o acesso. O Paycor redireciona você de volta ao PlaidCloud, que armazena um **token de atualização** na conexão e o usa para obter tokens de acesso automaticamente a partir daí.

<Aside type="caution">Permita pop-ups para o PlaidCloud. Se a janela de autorização for bloqueada, o PlaidCloud avisa: permita os pop-ups e clique em **Conectar ao Paycor** novamente.</Aside>

O host da API (`apis.paycor.com`) e o endpoint de token (`https://apis.paycor.com/sts/v1/common/token`) são gerenciados pelo PlaidCloud. Não há campos de URL para preencher, e você não deve precisar editá-los.

### Reautorizar uma conexão expirada

O acesso ao Paycor pode expirar: o token de atualização expira ou é revogado, ou o aplicativo do Paycor é desativado. Quando isso acontece, os fluxos de trabalho que usam a conexão deixam de se autenticar e falham. Para restaurá-la:

1. Confirme que o aplicativo do Paycor ainda está **ativado** (consulte as URLs de ativação em [Configuração do Paycor](#configuração-do-paycor)).
2. Abra a conexão e clique em **Conectar ao Paycor** para executar novamente a autorização do Paycor, depois faça login e aprove. Isso gera um novo token de atualização e a conexão volta a funcionar.

<Aside type="danger">Crie e repare as conexões do Paycor por este formulário de conexão. Editar a conexão subjacente por um editor REST genérico ou pela API pode sobrescrever a URL de token gerenciada e quebrar a autenticação.</Aside>
