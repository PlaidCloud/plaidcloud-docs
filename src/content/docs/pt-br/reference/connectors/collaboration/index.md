O PlaidCloud se conecta a plataformas de chat de equipe para que os fluxos de trabalho possam enviar notificações, alertas ou atualizações de status diretamente para os canais que a sua equipe já acompanha. É usado com mais frequência junto com as etapas de fluxo de trabalho [Notify via Slack](/pt-br/reference/workflow-steps/notifications/notify-via-slack/) e [Notify via Microsoft Teams](/pt-br/reference/workflow-steps/notifications/notify-via-microsoft-teams/).
