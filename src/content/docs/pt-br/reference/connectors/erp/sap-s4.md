O S/4HANA não tem um conector próprio. Ele compartilha um único tipo de conexão com o SAP ECC, porque o PlaidCloud acessa os dois pela mesma interface de Remote Function Call. Na tela **Conexões**, escolha **Novo → Instância SAP ECC / S/4HANA**.

**[Conector SAP ECC e S/4HANA →](/pt-br/reference/connectors/erp/sap-ecc/)** — todos os campos de configuração, para as duas gerações.

## Documentação do Fornecedor

Consulte a [documentação do SAP S/4HANA](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE).
