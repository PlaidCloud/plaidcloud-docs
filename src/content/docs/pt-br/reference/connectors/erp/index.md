O PlaidCloud oferece conectores dedicados para os principais sistemas ERP corporativos. Cada ERP expõe os dados por uma combinação própria de protocolos — RFCs, SOAP, REST ou acesso direto ao banco de dados — por isso cada conector encapsula o padrão adequado ao fornecedor.

## SAP

- [SAP ECC / S/4HANA](/pt-br/reference/connectors/erp/sap-ecc/) — um único tipo de conexão atende aos dois
- [SAP S/4HANA](/pt-br/reference/connectors/erp/sap-s4/)
- [SAP Analytics Cloud (SAC)](/pt-br/reference/connectors/erp/sap-sac/)
- [SAP Profitability and Performance Management (PaPM)](/pt-br/reference/connectors/erp/sap-papm/)
- [SAP Profitability and Cost Management (PCM)](/pt-br/reference/connectors/erp/sap-pcm/)
