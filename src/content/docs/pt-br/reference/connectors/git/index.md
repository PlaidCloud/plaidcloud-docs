O PlaidCloud se conecta a hosts Git para que fluxos de trabalho e aplicativos Panel possam ler de repositórios versionados. É útil para obter configurações, scripts ou arquivos de modelo que ficam no controle de versão, e não em um banco de dados ou em uma conta de documentos.

## Provedores

- [PlaidCloud Git](/pt-br/reference/connectors/git/plaidcloud-git/) — o serviço Git gerenciado integrado ao seu espaço de trabalho; sem URL de servidor nem credenciais para configurar
- [GitHub](/pt-br/reference/connectors/git/github/)
- [GitLab](/pt-br/reference/connectors/git/gitlab/)
- [Bitbucket](/pt-br/reference/connectors/git/bitbucket/)
- [Azure Repos](/pt-br/reference/connectors/git/azure-repos/)
- [AWS CodeCommit](/pt-br/reference/connectors/git/codecommit/)
