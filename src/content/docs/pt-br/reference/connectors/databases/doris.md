O **Apache Doris** é o banco de dados analítico MPP de alto desempenho do qual o StarRocks foi derivado. Use este conector para consultar implantações do Doris a partir de fluxos de trabalho do PlaidCloud. A conexão usa o protocolo de comunicação do MySQL com autenticação padrão por usuário e senha.

## Documentação de origem
[Documentação do Apache Doris](https://doris.apache.org/docs/4.x/gettingStarted/what-is-apache-doris).

A [página inicial do projeto Apache Doris](https://doris.apache.org/).

## Configuração

Este conector usa um fluxo de autenticação específico do fornecedor e é configurado diretamente na tela **Conexões** do seu espaço de trabalho. Os campos de configuração exibidos dependem das credenciais que o administrador do seu tenant provisionou para a integração.

Consulte a [documentação do doris](https://doris.apache.org/docs/) para obter os detalhes de configuração mais recentes.

Se precisar de ajuda para configurar este conector para o seu tenant, entre em contato com a sua equipe de conta — credenciais específicas do conector, URLs de ambiente e qualquer pré-provisionamento necessário normalmente precisam ser coordenados com o suporte do PlaidCloud.
