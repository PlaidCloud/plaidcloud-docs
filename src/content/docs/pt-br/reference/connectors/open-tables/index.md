O PlaidCloud Lakehouse pode federar consultas diretamente em formatos de tabela aberta, permitindo consultar os dados no local, sem movê-los antes para o PlaidCloud. É útil para combinar dados do lakehouse com data lakes externos já gerenciados em Iceberg, Delta Lake ou Hudi.

## Formatos

- [Apache Iceberg](/pt-br/reference/connectors/open-tables/iceberg/)
- [Delta Lake](/pt-br/reference/connectors/open-tables/delta-lake/)
- [Apache Hudi](/pt-br/reference/connectors/open-tables/hudi/)
- [Apache Hive](/pt-br/reference/connectors/open-tables/hive/) — formato de tabela aberta Hive (distinto do [conector do mecanismo de consulta Hive](/pt-br/reference/connectors/databases/hive/))
