## Onde Consultar a Sintaxe Canônica

O PlaidCloud Lakehouse usa as bibliotecas de funções SQL dos mecanismos subjacentes. Para detalhes sobre os argumentos de uma função, casos extremos e o comportamento mais atual, consulte a documentação original junto com os exemplos no estilo do PlaidCloud apresentados aqui.

- **Lakehouse v1** → [Referência de funções SQL do Databend](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [Referência de funções SQL do StarRocks](https://docs.starrocks.io/docs/sql-reference/sql-functions/) (o PlaidCloud Lakehouse v2 acompanha o StarRocks 4.1)
