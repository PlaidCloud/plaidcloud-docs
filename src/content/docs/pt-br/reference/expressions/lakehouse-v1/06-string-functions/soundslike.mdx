Compara a pronúncia de duas strings por meio de seus códigos Soundex. Soundex é um algoritmo fonético que produz um código representando a pronúncia de uma string, permitindo a correspondência aproximada de strings com base na pronúncia, e não na grafia. O PlaidCloud Lakehouse oferece a função [SOUNDEX](../soundex), que permite obter o código Soundex de uma string.

SOUNDS LIKE é frequentemente usada na cláusula WHERE de consultas SQL para restringir linhas por correspondência aproximada de strings, como em nomes e endereços; veja [Filtrar linhas](#filtrar-linhas) em [Exemplos](#exemplos-de-sql).

<Aside>Embora a função possa ser útil para a correspondência aproximada de strings, é importante observar que nem sempre ela é precisa. O algoritmo Soundex se baseia nas regras de pronúncia do inglês e pode não funcionar bem com strings de outros idiomas ou dialetos.</Aside>

## Sintaxe do Analyze

```python
func.sounds_like(<str1>, <str2>)
```

## Exemplos do Analyze

```python
func..sounds_like('Monday', 'Sunday')
┌───────────────────────────────────────┐
│ func..sounds_like('Monday', 'Sunday') │
├───────────────────────────────────────┤
│                                     0 │
└───────────────────────────────────────┘
```

## Sintaxe SQL

```sql
<str1> SOUNDS LIKE <str2>
```

## Argumentos

| Argumentos | Descrição                |
|-----------|--------------------------|
| str1, 2   | As strings a comparar.   |

## Tipo de retorno

Retorna o valor booleano 1 se os códigos Soundex das duas strings forem iguais (ou seja, elas têm pronúncia parecida) e 0 caso contrário.

## Exemplos de SQL

### Comparar strings

```sql
SELECT 'two' SOUNDS LIKE 'too'
----
1

SELECT CONCAT('A', 'B') SOUNDS LIKE 'AB';
----
1

SELECT 'Monday' SOUNDS LIKE 'Sunday';
----
0
```

### Filtrar linhas

```sql
SELECT * FROM  employees;

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Mark      |Smythe   | 28|
 0|Johann    |Schmidt  | 51|
 0|Eric      |Doe      | 30|
 0|Sue       |Johnson  | 45|


SELECT * FROM  employees
WHERE  first_name SOUNDS LIKE 'John';

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Johann    |Schmidt  | 51|
```
