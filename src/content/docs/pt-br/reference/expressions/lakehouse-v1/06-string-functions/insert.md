Retorna a string str, com a substring que começa na posição pos e tem len caracteres de comprimento substituída pela string newstr. Retorna a string original se pos não estiver dentro do comprimento da string. Substitui o restante da string a partir da posição pos se len não estiver dentro do comprimento do restante da string. Retorna NULL se algum argumento for NULL.

## Sintaxe do Analyze

```python
func.insert(<str>, <pos>, <len>, <newstr>)
```

## Exemplos do Analyze

```python
func.insert('Quadratic', 3, 4, 'What')
┌────────────────────────────────────────┐
│ func.insert('Quadratic', 3, 4, 'What') │
├────────────────────────────────────────┤
│ QuWhattic                              │
└────────────────────────────────────────┘
```

## Sintaxe SQL

```sql
INSERT(<str>, <pos>, <len>, <newstr>)
```

## Argumentos

| Argumentos | Descrição         |
|------------|-------------------|
| `<str>`    | A string.         |
| `<pos>`    | A posição.        |
| `<len>`    | O comprimento.    |
| `<newstr>` | A nova string.    |

## Tipo de retorno

`VARCHAR`
