Gera o código Soundex de uma string.

- Um código Soundex consiste em uma letra seguida por três dígitos numéricos. A implementação do PlaidCloud Lakehouse retorna mais de 4 dígitos, mas você pode aplicar [SUBSTR](../substr) ao resultado para obter um código Soundex padrão.
- Todos os caracteres não alfabéticos da string são ignorados.
- Todos os caracteres alfabéticos internacionais fora do intervalo A-Z são ignorados, a menos que sejam a primeira letra.


<Aside>O que é Soundex? O Soundex converte uma string alfanumérica em um código de quatro caracteres baseado em como a string soa quando pronunciada em inglês. Para mais informações, consulte https://en.wikipedia.org/wiki/Soundex</Aside>

Veja também: [SOUNDS LIKE](../soundslike)

## Sintaxe do Analyze

```python
func.soundex(<str>)
```

## Exemplos do Analyze

```python
func.soundex('PlaidCloud Lakehouse')
┌──────────────────────────────────────┐
│ func.soundex('PlaidCloud Lakehouse') │
├──────────────────────────────────────┤
│ D153                                 │
└──────────────────────────────────────┘
```

## Sintaxe SQL

```sql
SOUNDEX(<str>)
```

## Argumentos

| Argumentos | Descrição  |
|-----------|-------------|
| str  | A string. |

## Tipo de retorno

Retorna um código do tipo VARCHAR ou um valor NULL.

## Exemplos de SQL

```sql
SELECT SOUNDEX('PlaidCloud Lakehouse');

---
D153

-- All non-alphabetic characters in the string are ignored.
SELECT SOUNDEX('PlaidCloud Lakehouse!');

---
D153

-- All international alphabetic characters outside the A-Z range are ignored unless they're the first letter.
SELECT SOUNDEX('PlaidCloud Lakehouse，你好');

---
D153

SELECT SOUNDEX('你好，PlaidCloud Lakehouse');

---
你3153

-- SUBSTR the result to get a standard Soundex code.
SELECT SOUNDEX('databend cloud'),SUBSTR(SOUNDEX('databend cloud'),1,4);

soundex('databend cloud')|substring(soundex('databend cloud') from 1 for 4)|
-------------------------+-------------------------------------------------+
D153243                  |D153                                             |

SELECT SOUNDEX(NULL);
┌─────────────────────────────────────┐
│ `SOUNDEX(NULL)`                     │
├─────────────────────────────────────┤
│ <null>                              │
└─────────────────────────────────────┘
```
