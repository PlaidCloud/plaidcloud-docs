Concatena dois arrays.

## Sintaxe do Analyze

```python
func.array_concat( <array1>, <array2> )
```

## Exemplos do Analyze

```python
func.array_concat([1, 2], [3, 4])

┌────────────────────────────────────┐
│ func.array_concat([1, 2], [3, 4])  │
├────────────────────────────────────┤
│ [1,2,3,4]                          │
└────────────────────────────────────┘
```

## Sintaxe SQL

```sql
ARRAY_CONCAT( <array1>, <array2> )
```

## Exemplos de SQL

```sql
SELECT ARRAY_CONCAT([1, 2], [3, 4]);

┌──────────────────────────────┐
│ array_concat([1, 2], [3, 4]) │
├──────────────────────────────┤
│ [1,2,3,4]                    │
└──────────────────────────────┘
```
