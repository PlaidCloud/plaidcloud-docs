Função de agregação.

A função STDDEV_POP() retorna o desvio padrão populacional (a raiz quadrada de VAR_POP()) de uma expressão.

<Aside>STD() ou STDDEV() também podem ser usadas; são equivalentes, mas não fazem parte do SQL padrão.</Aside>

<Aside type="caution">Valores NULL não são contados.</Aside>

## Sintaxe do Analyze

```python
func.stddev_pop(<expr>)
```

## Exemplos do Analyze

```python
func.stddev_pop(table.score).alias('test_score_stddev_pop')

| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```

## Sintaxe SQL

```sql
STDDEV_POP(<expr>)
STDDEV(<expr>)
STD(<expr>)
```

## Argumentos

| Argumentos | Descrição                  |
|-----------|----------------------------|
| `<expr>`  | Qualquer expressão numérica |

## Tipo de retorno

double

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**
```sql
CREATE TABLE test_scores (
  id INT,
  student_id INT,
  score FLOAT
);

INSERT INTO test_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 85),
       (3, 3, 90),
       (4, 4, 95),
       (5, 5, 100);
```

**Demonstração de consulta: calcular o desvio padrão populacional das notas dos testes**
```sql
SELECT STDDEV_POP(score) AS test_score_stddev_pop
FROM test_scores;
```

**Resultado**
```sql
| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```
