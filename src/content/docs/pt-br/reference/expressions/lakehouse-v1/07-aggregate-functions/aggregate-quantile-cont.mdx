Função de agregação.

A função QUANTILE_CONT() calcula o quantil interpolado de uma sequência de dados numéricos.

<Aside type="caution">Valores NULL não são contados.</Aside>

## Sintaxe do Analyze

```python
func.quantile_cont(<levels>, <expr>)
```

## Exemplos do Analyze

```python
func.quantile_cont(0.5, table.sales_amount).alias('median_sales_amount')

|  median_sales_amount  |
|-----------------------|
|        6000.0         |
```

## Sintaxe SQL

```sql
QUANTILE_CONT(<levels>)(<expr>)
    
QUANTILE_CONT(level1, level2, ...)(<expr>)
```

## Argumentos

| Argumentos  | Descrição                                                                                                                                                     |
|-------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<level(s)` | Nível(is) do quantil. Cada nível é um número de ponto flutuante constante de 0 a 1. Recomendamos usar um valor de nível no intervalo [0.01, 0.99]            |
| `<expr>`    | Qualquer expressão numérica                                                                                                                                   |

## Tipo de retorno

Float64 ou array de float64, de acordo com o número de níveis.

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**
```sql
CREATE TABLE sales_data (
  id INT,
  sales_person_id INT,
  sales_amount FLOAT
);

INSERT INTO sales_data (id, sales_person_id, sales_amount)
VALUES (1, 1, 5000),
       (2, 2, 5500),
       (3, 3, 6000),
       (4, 4, 6500),
       (5, 5, 7000);
```

**Demonstração de consulta: calcular o percentil 50 (mediana) do valor de vendas usando interpolação**
```sql
SELECT QUANTILE_CONT(0.5)(sales_amount) AS median_sales_amount
FROM sales_data;
```

**Resultado**
```sql
|  median_sales_amount  |
|-----------------------|
|        6000.0         |
```
