Função de agregação.

A função count(distinct ...) calcula o número de valores exclusivos de um conjunto de valores.

Para obter um resultado estimado de grandes conjuntos de dados com pouca memória e pouco tempo, considere usar [APPROX_COUNT_DISTINCT](../aggregate-approx-count-distinct).

<Aside type="caution">Valores NULL não são contados.</Aside>

## Sintaxe do Analyze

```python
func.count_distinct(<column>)
```

## Exemplos do Analyze

```python
func.count_distinct(table.category).alias('unique_categories')

| unique_categories |
|-------------------|
|         2         |
```

## Sintaxe SQL

```sql
COUNT(distinct <expr> ...)
UNIQ(<expr>)
```

## Argumentos

| Argumentos | Descrição                                                    |
|-----------|--------------------------------------------------------------|
| `<expr>`  | Qualquer expressão; o número de argumentos está entre [1, 32] |

## Tipo de retorno

UInt64

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**
```sql
CREATE TABLE products (
  id INT,
  name VARCHAR,
  category VARCHAR,
  price FLOAT
);

INSERT INTO products (id, name, category, price)
VALUES (1, 'Laptop', 'Electronics', 1000),
       (2, 'Smartphone', 'Electronics', 800),
       (3, 'Tablet', 'Electronics', 600),
       (4, 'Chair', 'Furniture', 150),
       (5, 'Table', 'Furniture', 300);
```

**Demonstração de consulta: contar categorias distintas**

```sql
SELECT COUNT(DISTINCT category) AS unique_categories
FROM products;
```

**Resultado**
```sql
| unique_categories |
|-------------------|
|         2         |
```
