Função de agregação.

A função STRING_AGG() converte todos os valores não NULL de uma coluna em String, separados pelo delimitador.

## Sintaxe do Analyze

```python
func.string_agg(<expr> [, delimiter])
```

## Exemplos do Analyze

```python
func.string_agg(table.language_name).alias('concatenated_languages')

|          concatenated_languages         |
|-----------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```

## Sintaxe SQL

```sql
STRING_AGG(<expr>)
STRING_AGG(<expr> [, delimiter])
```

<Aside>Se `<expr>` não for uma expressão de String, use `::VARCHAR` para converter. Por exemplo: ```sql SELECT string_agg(number::VARCHAR, '|') AS s FROM numbers(5); ┌───────────┐ │ s │ ├───────────┤ │ 0│1│2│3│4 │ └───────────┘ ```</Aside>

## Argumentos

| Argumentos  | Descrição                                                                    |
|-------------|------------------------------------------------------------------------------|
| `<expr>`    | Qualquer expressão de string (se não for uma string, use `::VARCHAR` para converter) |
| `delimiter` | String constante opcional; se não for especificada, usa uma String vazia     |

## Tipo de retorno

O tipo String

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**

```sql
CREATE TABLE programming_languages (
  id INT,
  language_name VARCHAR
);

INSERT INTO programming_languages (id, language_name)
VALUES (1, 'Python'),
       (2, 'JavaScript'),
       (3, 'Java'),
       (4, 'C#'),
       (5, 'Ruby');
```

**Demonstração de consulta: concatenar nomes de linguagens de programação com um delimitador**
```sql
SELECT STRING_AGG(language_name, ', ') AS concatenated_languages
FROM programming_languages;
```

**Resultado**
```sql
|          concatenated_languages         |
|------------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```
