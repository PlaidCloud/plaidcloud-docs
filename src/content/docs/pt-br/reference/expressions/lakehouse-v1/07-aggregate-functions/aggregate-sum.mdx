Função de agregação.

A função SUM() calcula a soma de um conjunto de valores.

<Aside type="caution">Valores NULL não são contados.</Aside>


## Sintaxe do Analyze

```python
func.sum(<column>)
```

## Exemplos do Analyze

```python
func.sum(table.quantity).alias('total_quantity_sold')

| total_quantity_sold |
|---------------------|
|         41          |
```

## Sintaxe SQL

```sql
SUM(<expr>)
```

## Argumentos

| Argumentos | Descrição                  |
|-----------|----------------------------|
| `<expr>`  | Qualquer expressão numérica |

## Tipo de retorno

Um double se o tipo de entrada for double; caso contrário, inteiro.

## Exemplos de SQL

**Criar uma tabela e inserir dados de exemplo**
```sql
CREATE TABLE sales_data (
  id INT,
  product_id INT,
  quantity INT
);

INSERT INTO sales_data (id, product_id, quantity)
VALUES (1, 1, 10),
       (2, 2, 5),
       (3, 3, 8),
       (4, 4, 3),
       (5, 5, 15);
```

**Demonstração de consulta: calcular a quantidade total de produtos vendidos**
```sql
SELECT SUM(quantity) AS total_quantity_sold
FROM sales_data;
```

**Resultado**
```sql
| total_quantity_sold |
|---------------------|
|         41          |
```
