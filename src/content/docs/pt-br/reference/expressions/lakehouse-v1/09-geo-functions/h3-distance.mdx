Retorna a distância na grade entre os dois índices [H3](https://eng.uber.com/h3/) informados.

<Aside>Os cálculos de distância H3 só conseguem calcular distâncias entre hexágonos vizinhos. Tentar usá-los com hexágonos que não são vizinhos gera um erro.</Aside>

### Sintaxe do Analyze

```python
func.h3_distance(h3, a_h3)
```

## Exemplos do Analyze

```python
func.h3_distance(599119489002373119, 599119491149856767)

┌──────────────────────────────────────────────────────────┐
│ func.h3_distance(599119489002373119, 599119491149856767) │
├──────────────────────────────────────────────────────────┤
│                                                        1 │
└──────────────────────────────────────────────────────────┘
```

## Sintaxe SQL

```sql
H3_DISTANCE(h3, a_h3)
```

## Exemplos de SQL

```sql
SELECT H3_DISTANCE(599119489002373119, 599119491149856767);

┌─────────────────────────────────────────────────────┐
│ h3_distance(599119489002373119, 599119491149856767) │
├─────────────────────────────────────────────────────┤
│                                                   1 │
└─────────────────────────────────────────────────────┘
```
