Retorna um array com os índices [H3](https://eng.uber.com/h3/) dos hexágonos do anel k ao redor do índice H3 de entrada. Cada elemento desse array é um índice H3.

## Sintaxe do Analyze

```python
func.h3_k_ring(h3, k)
```

## Exemplos do Analyze

```python
func.h3_k_ring(644325524701193974, 1)

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                                  func.h3_k_ring(644325524701193974, 1)                                                 │
├────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ [644325524701193974,644325524701193899,644325524701193869,644325524701193970,644325524701193968,644325524701193972,644325524701193897] │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## Sintaxe SQL

```sql
H3_K_RING(h3, k)
```
