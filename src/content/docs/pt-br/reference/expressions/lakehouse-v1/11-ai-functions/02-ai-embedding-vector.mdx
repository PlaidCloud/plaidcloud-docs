Este documento apresenta uma visão geral da função ai_embedding_vector no PlaidCloud Lakehouse e demonstra como criar embeddings de documentos com ela.

Consulte a [implementação upstream](https://github.com/datafuselabs/databend/blob/1e93c5b562bd159ecb0f336bb88fd1b7f9dc4a62/src/common/openai/src/embedding.rs).

Por padrão, o PlaidCloud Lakehouse usa o modelo [text-embedding-ada](https://platform.openai.com/docs/models/embeddings) para gerar embeddings.

<Aside>A partir do PlaidCloud Lakehouse v1.1.47, o PlaidCloud Lakehouse oferece suporte ao [serviço Azure OpenAI](https://azure.microsoft.com/en-au/products/cognitive-services/openai-service). Essa integração oferece maior privacidade de dados. Para usar o Azure OpenAI, adicione as seguintes configurações à seção `[query]`: ```sql # Azure OpenAI openai_api_chat_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_embedding_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_version = "2023-03-15-preview" ```</Aside>


<Aside type="caution">O PlaidCloud Lakehouse depende do (Azure) OpenAI para `AI_EMBEDDING_VECTOR` e envia os dados da coluna de embedding ao (Azure) OpenAI. Essas funções só funcionam quando a configuração do PlaidCloud Lakehouse inclui o `openai_api_key`; caso contrário, ficam inativas. Esta função está disponível por padrão no PlaidCloud Lakehouse usando uma chave do Azure OpenAI. Ao usá-las, você reconhece que seus dados serão enviados por nós ao Azure OpenAI.</Aside>

## Visão geral de Ai_embedding_vector

A função `ai_embedding_vector` do PlaidCloud Lakehouse é uma função integrada que gera embeddings vetoriais para dados de texto. Ela é útil em tarefas de processamento de linguagem natural, como similaridade de documentos, clusterização e sistemas de recomendação.

A função recebe um texto como entrada e retorna um vetor de alta dimensionalidade que representa o significado semântico e o contexto do texto. Os embeddings são criados com modelos pré-treinados em grandes corpora de texto, capturando as relações entre palavras e frases em um espaço contínuo.

## Criação de embeddings com Ai_embedding_vector

Para criar embeddings de um documento de texto com a função `ai_embedding_vector`, siga o exemplo abaixo.
1. Crie uma tabela para armazenar os documentos:
```sql
CREATE TABLE documents (
                           id INT,
                           title VARCHAR,
                           content VARCHAR,
                           embedding ARRAY(FLOAT32)
);
```

2. Insira documentos de exemplo na tabela:
```sql
INSERT INTO documents(id, title, content)
VALUES
    (1, 'A Brief History of AI', 'Artificial intelligence (AI) has been a fascinating concept of science fiction for decades...'),
    (2, 'Machine Learning vs. Deep Learning', 'Machine learning and deep learning are two subsets of artificial intelligence...'),
    (3, 'Neural Networks Explained', 'A neural network is a series of algorithms that endeavors to recognize underlying relationships...'),
```

3. Gere os embeddings:
```sql
UPDATE documents SET embedding = ai_embedding_vector(content) WHERE length(embedding) = 0;
```
Depois de executar a consulta, a coluna embedding da tabela conterá os embeddings gerados.

Os embeddings são armazenados como uma matriz de valores `FLOAT32` na coluna embedding, que tem o tipo de coluna `ARRAY(FLOAT32)`.

Agora você pode usar esses embeddings em diversas tarefas de processamento de linguagem natural, como encontrar documentos semelhantes ou agrupar documentos com base no conteúdo.

4. Inspecione os embeddings:

```sql
SELECT length(embedding) FROM documents;
┌───────────────────┐
│ length(embedding) │
├───────────────────┤
│              1536 │
│              1536 │
│              1536 │
└───────────────────┘
```
A consulta acima mostra que os embeddings gerados têm comprimento de 1536 (dimensões) para cada documento.
