<Aside>A partir do PlaidCloud Lakehouse v1.1.47, o PlaidCloud Lakehouse oferece suporte ao [serviço Azure OpenAI](https://azure.microsoft.com/en-au/products/cognitive-services/openai-service). Essa integração oferece maior privacidade de dados. Para usar o Azure OpenAI, adicione as seguintes configurações à seção `[query]`: ```sql # Azure OpenAI openai_api_chat_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_embedding_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_version = "2023-03-15-preview" ```</Aside>

Esta função está disponível por padrão no PlaidCloud Lakehouse usando uma chave do Azure OpenAI. Ao usá-las, você reconhece que seus dados serão enviados por nós ao Azure OpenAI.</Aside>


## Visão geral de Ai_text_completion

A função `ai_text_completion` do PlaidCloud Lakehouse é uma função integrada que gera complementos de texto a partir de um prompt. Ela é útil em tarefas de processamento de linguagem natural, como respostas a perguntas, geração de texto e sistemas de preenchimento automático.

A função recebe um prompt de texto como entrada e retorna um complemento gerado para ele. Os complementos são criados com modelos pré-treinados em grandes corpora de texto, capturando as relações entre palavras e frases em um espaço contínuo.

## Geração de complementos de texto com Ai_text_completion

Veja um exemplo simples que usa a função `ai_text_completion` no PlaidCloud Lakehouse para gerar um complemento de texto:
```sql
SELECT ai_text_completion('What is artificial intelligence?') AS completion;
```

Resultado:
```sql
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ completion                                                                                                          │
├────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ Artificial intelligence (AI) is the field of study focused on creating machines and software capable of thinking, learning, and solving problems in a way that mimics human intelligence. This includes areas such as machine learning, natural language processing, computer vision, and robotics. │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

Neste exemplo, fornecemos o prompt "What is artificial intelligence?" à função `ai_text_completion`, e ela retorna um complemento gerado que descreve brevemente a inteligência artificial.
