A integração do PlaidCloud com o Jupyter permite que cientistas de dados trabalhem com tabelas de projeto, executem consultas e usem o PlaidCloud como repositório de apoio a partir de ambientes de notebook. A autenticação usa tokens OAuth, de modo que as mesmas credenciais funcionam na CLI, nos notebooks e na API REST.

## Tópicos

- [Linha de comando](/pt-br/reference/cli/jupyter/command-line/): a CLI autônoma para interações com script
- [Notebook Jupyter](/pt-br/reference/cli/jupyter/jupyter-notebook/): uso do PlaidCloud a partir de células de notebook
- [Configuração do OAuth](/pt-br/reference/cli/jupyter/oauth-setup/): configuração da autenticação
