Depois de [fazer login](/pt-br/reference/cli/plaidxl/connect/), o painel de tarefas lista os seus projetos. Você escolhe um projeto e depois recupera suas tabelas e dimensões para a pasta de trabalho.

## Escolher um projeto

A seção **Projeto** lista todos os projetos que você pode abrir, nas mesmas pastas que você vê no PlaidCloud. As pastas começam recolhidas; clique em uma para abri-la ou digite em **Filter projects by name** para restringir a lista.

Clique em um projeto para selecioná-lo. Suas tabelas aparecem na guia **Tabelas** e suas dimensões na guia **Dimensões**.

O projeto selecionado também é o projeto do qual as [funções personalizadas](/pt-br/reference/cli/plaidxl/functions/) e os comandos de detalhamento do PlaidXL leem. A seleção se aplica a todas as pastas de trabalho que você tiver abertas, não apenas a esta.

### Definir um projeto padrão

Para que uma pasta de trabalho selecione o mesmo projeto toda vez que você abrir o painel de tarefas, selecione o projeto e clique em **Definir como padrão**. O padrão é salvo na pasta de trabalho, então acompanha o arquivo para qualquer pessoa que o abrir. **Clear Default** o remove.

## Recuperar uma tabela

1. Na guia **Tabelas**, clique em uma tabela. Use **Filter tables by name** para encontrá-la em uma lista longa. Os valores de **Linhas** e **Colunas** ao lado de cada tabela mostram o seu tamanho.
2. Em **Coluna**, desmarque a caixa de seleção de qualquer coluna de que você não precise. Todas as colunas começam selecionadas.
3. Para recuperar apenas algumas linhas, selecione **Avançado** e crie um filtro. Consulte [Filtrar linhas](#filtrar-linhas).
4. Em **Select where to place this table**, escolha:
   - **Matching Worksheet** — uma planilha com o nome da tabela. O PlaidXL cria a planilha se ela não existir e, se existir, grava a tabela a partir da célula A1.
   - **Current Selection** — a partir da célula que você selecionou na planilha ativa.
5. Clique em **Retrieve Table**.

Os dados chegam com uma linha de cabeçalho, prontos para uso. A linha de cabeçalho fica em negrito e sombreada, as colunas são ajustadas ao conteúdo e os filtros são ativados. Uma tabela recuperada em **Matching Worksheet** também recebe:

- Uma linha de cabeçalho congelada, que permanece visível ao rolar a planilha.
- Um intervalo nomeado sobre os dados, para que as fórmulas que o usam acompanhem o crescimento dos dados na atualização. Seu nome é o nome da planilha com um sublinhado na frente: uma tabela chamada **Sample data** vai para a planilha `Sample_data`, com o intervalo nomeado `_Sample_data`.

Para nomear a planilha, o PlaidXL corta o nome da tabela no limite de 31 caracteres do Excel, mantém apenas letras simples (A–Z), números e espaços, e transforma os espaços em sublinhados. Uma tabela chamada **Q3 Revenue (EMEA)** é recuperada na planilha `Q3_Revenue_EMEA`. Sublinhados e letras acentuadas também são descartados, então **sales_2024** é recuperada na planilha `sales2024`.

<Aside type="tip">Tabelas largas demoram a carregar no Excel. Desmarcar as colunas de que você não precisa é a maneira mais rápida de acelerar uma recuperação grande.</Aside>

### Tabelas exibidas em vermelho

Uma tabela aparece em vermelho quando é grande demais para uma planilha — mais de 1.048.576 linhas ou 16.384 colunas — ou quando o PlaidCloud não consegue informar o seu tamanho, como no caso de uma tabela que nunca foi carregada. Filtre as linhas com **Avançado** e desmarque colunas até que ela caiba. O PlaidXL recupera no máximo 1.048.575 linhas mais a linha de cabeçalho e para por aí, sem aviso.

## Filtrar linhas

Selecione **Avançado** para abrir o construtor de filtros. Cada regra escolhe uma coluna, uma comparação como **igual a**, **in**, **contém**, **começa com** ou **está vazio**, e um valor. Use grupos **AND**, grupos **OR** ou ambos para combinar regras.

O filtro compara os valores como texto, portanto corresponde a valores exatos e a padrões de texto. Intervalos de números ou datas não estão disponíveis; para recuperar um intervalo, filtre pelos valores de que você precisa com **in** ou recupere a tabela e filtre-a no Excel.

- Digite os valores sem aspas: `EMEA`, não `"EMEA"`.
- Para uma comparação que aceita vários valores, como **in**, separe os valores com uma vírgula e um espaço: `EMEA, APAC, NA`.

O filtro só se aplica enquanto **Avançado** estiver selecionado. O PlaidXL lembra o filtro e as colunas que você escolheu para cada tabela recuperada e os usa novamente quando você atualiza.

## Refresh All Tables

**Refresh All Tables** — no painel de tarefas ou na faixa de opções em **PlaidCloud → PlaidXL Controls** — traz os dados atuais do PlaidCloud para todas as tabelas que você recuperou na pasta de trabalho, com as colunas e o filtro que você escolheu para cada uma.

Enquanto é executado, a guia da planilha de cada tabela fica amarela. Ela fica verde quando essa tabela está atualizada. As fórmulas que usam os dados são recalculadas normalmente; atualize as tabelas dinâmicas criadas a partir deles com **Data → Refresh All** do Excel.

O PlaidXL salva a lista de tabelas recuperadas na pasta de trabalho, portanto **Refresh All Tables** funciona para qualquer pessoa que abrir o arquivo e fizer login com acesso aos mesmos projetos.

Cada **Retrieve Table** adiciona a tabela à lista de atualização, e não há como remover uma. Recupere cada tabela uma vez e depois use **Refresh All Tables** para atualizá-la — recuperar a mesma tabela novamente faz com que cada atualização a busque duas vezes.

<Aside type="caution">
Uma tabela recuperada em **Current Selection** é atualizada nas mesmas células da **planilha que estiver ativa** quando você clica em **Refresh All Tables**, sobrescrevendo o que estiver lá. Recupere em **Matching Worksheet** as tabelas que você pretende atualizar; elas sempre são atualizadas na sua própria planilha.

Uma atualização grava sobre os dados antigos sem limpá-los antes. Se uma tabela agora tem menos linhas ou colunas do que antes, as linhas ou colunas extras da recuperação anterior permanecem na planilha. Limpe o conteúdo da planilha antes de atualizar uma tabela que possa ter diminuído.
</Aside>

## Recuperar uma dimensão

A guia **Dimensões** lista as [dimensões](/pt-br/guides/dimensions/dimensions/) do projeto.

1. Clique em uma dimensão. Use **Filter dimensions by name** para encontrá-la.
2. Em **Select where to place this dimension**, escolha **Matching Worksheet** ou **Current Selection**.
3. Clique em **Retrieve Dimension**.

O PlaidXL grava os nós da dimensão em uma única coluna, na ordem da hierarquia. As dimensões não têm filtros de coluna ou de linha, e **Refresh All Tables** não as atualiza — recupere a dimensão novamente para obter as alterações.

Para montar uma hierarquia com recuo e agrupamento em estrutura de tópicos do Excel, ou para começar a partir de um nó específico ou de uma hierarquia alternativa, use [`PLAIDXL.DIMENSION.GET_DIMENSION`](/pt-br/reference/cli/plaidxl/functions/#get_dimension) ou os [comandos de detalhamento](/pt-br/reference/cli/plaidxl/ribbon/#drill-functions).

## Alterar dados

O PlaidXL lê do PlaidCloud e nunca grava de volta. Você pode editar, classificar e adicionar fórmulas livremente a uma planilha recuperada, e nada no projeto muda. Uma atualização grava os dados atuais do PlaidCloud sobre o intervalo da tabela, portanto mantenha seus próprios cálculos em uma planilha separada.

Para alterar os dados em si, atualize-os no PlaidCloud — por exemplo, com um [fluxo de trabalho](/pt-br/guides/workflows/) ou o [Editor de dados](/pt-br/guides/projects/managing-data-editors/).
