Depois que você [fizer login](/pt-br/reference/cli/plaidxl/connect/), o painel de tarefas lista os seus projetos. Você escolhe um projeto e, em seguida, recupera as tabelas e dimensões dele para a pasta de trabalho.

## Escolha um projeto

O cabeçalho do painel de tarefas mostra o seu espaço de trabalho e o projeto ao qual esta pasta de trabalho está vinculada. Clique no nome do projeto para abrir a lista de projetos, que mostra todos os projetos que você pode abrir, nas mesmas pastas que você vê no PlaidCloud. As pastas começam recolhidas; clique em uma para abri-la ou digite em **Filter projects by name** para restringir a lista.

Clique em um projeto para selecioná-lo. As tabelas dele aparecem na guia **Tabelas** e as dimensões dele na guia **Dimensões**.

### O projeto pertence à pasta de trabalho

O projeto selecionado é salvo na pasta de trabalho; assim, cada pasta de trabalho tem o seu próprio projeto. É o projeto do qual as [funções personalizadas](/pt-br/reference/cli/plaidxl/functions/) e os comandos de detalhamento do PlaidXL leem nessa pasta de trabalho. Se você abrir duas pastas de trabalho, cada uma lê do seu próprio projeto, e, quando você reabre uma pasta de trabalho, o painel de tarefas volta para o projeto dela. O projeto acompanha o arquivo para qualquer pessoa que o abra e faça login com acesso a ele.

Um projeto pertence a um único espaço de trabalho. Se você [trocar de espaço de trabalho](/pt-br/reference/cli/plaidxl/connect/#saia-ou-troque-de-espaço-de-trabalho), uma pasta de trabalho vinculada a um projeto do espaço de trabalho anterior fica sem projeto até você escolher um. As tabelas que você recuperou do espaço de trabalho anterior permanecem na pasta de trabalho, mas são ignoradas por **Refresh All Tables**, e o painel de tarefas informa quantas são. Recupere-as novamente no novo espaço de trabalho para vinculá-las.

## Recupere uma tabela

1. Na guia **Tabelas**, clique em uma tabela. Use **Filter tables by name** para encontrá-la em uma lista longa. As **Linhas** e as **Colunas** ao lado de cada tabela informam o tamanho dela.
2. Em **Coluna**, desmarque a caixa de seleção de qualquer coluna de que você não precise. Todas as colunas começam selecionadas.
3. Para recuperar apenas algumas linhas, selecione **Avançado** e crie um filtro. Consulte [Filtre linhas](#filtre-linhas).
4. Em **Select where to place this table**, escolha:
   - **Matching Worksheet**: uma planilha com o nome da tabela. O PlaidXL cria a planilha se ela não existir e, se existir, grava a tabela a partir da célula A1.
   - **Current Selection**: a partir da célula que você selecionou na planilha ativa.
5. Clique em **Retrieve Table**.

Os dados chegam com uma linha de cabeçalho, prontos para uso. A linha de cabeçalho fica em negrito e sombreada, as colunas são dimensionadas para caber e os filtros são ativados. Uma tabela recuperada para **Matching Worksheet** também recebe:

- Uma linha de cabeçalho congelada, para que permaneça visível ao rolar.
- Um intervalo nomeado sobre os dados, para que as fórmulas que o usam acompanhem os dados à medida que eles crescem na atualização. O nome dele é o nome da planilha com um sublinhado na frente: uma tabela chamada **Sample data** vai para a planilha `Sample_data`, com o intervalo nomeado `_Sample_data`.

Para nomear a planilha, o PlaidXL corta o nome da tabela no limite de 31 caracteres do Excel, mantém apenas letras simples (A–Z), números e espaços e transforma os espaços em sublinhados. Uma tabela chamada **Q3 Revenue (EMEA)** é recuperada para a planilha `Q3_Revenue_EMEA`. Sublinhados e letras acentuadas também são descartados; assim, **sales_2024** é recuperada para a planilha `sales2024`.

<Aside type="tip">Tabelas largas demoram para carregar no Excel. Desmarcar as colunas de que você não precisa é a forma mais rápida de acelerar uma recuperação grande.</Aside>

### Tabelas exibidas em vermelho

Uma tabela aparece em vermelho quando é grande demais para uma planilha (mais de 1.048.576 linhas ou 16.384 colunas) ou quando o PlaidCloud não consegue informar o tamanho dela, como no caso de uma tabela que nunca foi carregada. Filtre as linhas com **Avançado** e desmarque colunas até que ela caiba. O PlaidXL recupera no máximo 1.048.575 linhas mais a linha de cabeçalho e para por aí, sem aviso.

## Filtre linhas

Selecione **Avançado** para abrir o construtor de filtros. Cada regra escolhe uma coluna, uma comparação como **igual a**, **está em**, **contém**, **começa com** ou **está vazio**, e um valor. Use grupos **AND**, grupos **OR** ou ambos para combinar regras.

O filtro compara valores como texto; por isso, ele corresponde a valores exatos e a padrões de texto. Intervalos de números ou de datas não estão disponíveis; para recuperar um intervalo, filtre pelos valores de que você precisa com **está em** ou recupere a tabela e filtre-a no Excel.

- Digite os valores sem aspas: `EMEA`, não `"EMEA"`.
- Para uma comparação que aceita vários valores, como **está em**, separe os valores com uma vírgula e um espaço: `EMEA, APAC, NA`.

O filtro só é aplicado enquanto **Avançado** estiver selecionado. O PlaidXL se lembra do filtro e das colunas que você escolheu com cada tabela recuperada e os usa novamente quando você atualiza.

## Refresh All Tables

**Refresh All Tables**, no painel de tarefas ou na faixa de opções em **PlaidCloud → Dados**, traz os dados atuais do PlaidCloud para todas as tabelas que você recuperou na pasta de trabalho, com as colunas e o filtro que você escolheu para cada uma.

Enquanto ele é executado, a guia da planilha de cada tabela fica amarela. Ela fica verde quando essa tabela está atualizada. As fórmulas que usam os dados são recalculadas normalmente; atualize as tabelas dinâmicas criadas a partir deles com **Data → Refresh All** do Excel.

O PlaidXL salva a lista de tabelas recuperadas na pasta de trabalho; assim, **Refresh All Tables** funciona para qualquer pessoa que abra o arquivo e faça login com acesso aos mesmos projetos.

Cada **Retrieve Table** adiciona a tabela à lista de atualização, e não há como remover uma. Recupere cada tabela uma vez e depois use **Refresh All Tables** para atualizá-la; recuperar a mesma tabela novamente faz com que cada atualização a traga duas vezes.

<Aside type="caution">
Uma tabela recuperada para **Current Selection** é atualizada nas mesmas células da **planilha que estiver ativa** quando você clicar em **Refresh All Tables**, sobrescrevendo o que estiver lá. Recupere para **Matching Worksheet** as tabelas que você pretende atualizar; elas sempre são atualizadas na própria planilha.

Uma atualização grava sobre os dados antigos sem limpá-los antes. Se uma tabela agora tem menos linhas ou colunas do que antes, as linhas ou colunas extras da recuperação anterior permanecem na planilha. Limpe o conteúdo da planilha antes de atualizar uma tabela que possa ter diminuído.
</Aside>

## Recupere uma dimensão

A guia **Dimensões** lista as [dimensões](/pt-br/guides/dimensions/dimensions/) do projeto.

1. Clique em uma dimensão. Use **Filter dimensions by name** para encontrá-la.
2. Em **Select where to place this dimension**, escolha **Matching Worksheet** ou **Current Selection**.
3. Clique em **Retrieve Dimension**.

O PlaidXL grava os nós da dimensão como uma única coluna, na ordem da hierarquia. As dimensões não têm filtros de coluna nem de linha, e **Refresh All Tables** não as atualiza; recupere a dimensão novamente para obter as alterações.

Para dispor uma hierarquia com recuo e agrupamento em estrutura de tópicos do Excel, ou para começar de um nó específico ou de uma hierarquia alternativa, use [`PLAIDXL.DIMENSION.GET_DIMENSION`](/pt-br/reference/cli/plaidxl/functions/#get_dimension) ou os [comandos de detalhamento](/pt-br/reference/cli/plaidxl/ribbon/#funções-de-detalhamento).

## Salve uma tabela no PlaidCloud

Uma tabela que você recuperou na pasta de trabalho pode ser salva de volta, substituindo a tabela do PlaidCloud pelo que está na planilha.

1. Vá para a planilha que contém a tabela recuperada. Em **Save this sheet to PlaidCloud**, o painel de tarefas lista cada tabela vinculada à planilha ativa, com a contagem de linhas dela. Se a planilha não tiver nenhuma, o painel diz para recuperar uma tabela ali primeiro.
2. Clique em **Save to PlaidCloud…** ao lado da tabela.
3. Leia a confirmação, que mostra a tabela, o número de linhas a gravar e as colunas, e depois clique em **Replace table**.

O PlaidXL lê a linha de cabeçalho e as linhas abaixo dela a partir do local para o qual a tabela foi recuperada. O cabeçalho ainda deve corresponder às colunas que você recuperou, e os valores são convertidos para o tipo de dados de cada coluna. Se um valor não puder ser convertido, nada é gravado e as linhas que falharam são listadas. As definições de coluna no PlaidCloud permanecem como estão.

### O que é salvo

- Células vazias e células que mostram um erro são salvas como vazias.
- As linhas adicionadas diretamente abaixo da tabela são incluídas, até a primeira linha vazia.
- Uma linha vazia no meio das linhas recuperadas é mantida. Duas ou mais linhas vazias seguidas, com dados abaixo delas, interrompem o salvamento e informam quais linhas excluir ou preencher.

### Antes de substituir uma tabela

- **Uma tabela filtrada.** Se você recuperou a tabela com um filtro, todas as linhas que o filtro deixou de fora são excluídas do PlaidCloud. A confirmação informa isso e pede que você marque uma caixa antes de **Replace table** ser ativado.
- **Colunas que você não recuperou.** Se você recuperou apenas algumas colunas, o PlaidXL pergunta **Empty columns that were not retrieved?** e as nomeia. Clique em **Write anyway** para esvaziar essas colunas no PlaidCloud ou cancele para não gravar nada.
- **Outra pessoa alterou a tabela.** O salvamento é recusado se a tabela mudou no PlaidCloud depois que você a recuperou. Recupere-a novamente e reaplique as suas edições.
- **Um ponto de restauração.** O PlaidXL cria um ponto de restauração antes de gravar e o mantém por 7 dias. Se a gravação falhar, a tabela volta ao que era. Uma tabela que não pode receber um ponto de restauração pergunta **Write back without a restore point?**, e **Write anyway** continua sem ele.

Depois de um salvamento bem-sucedido, a mensagem de confirmação inclui **Restore previous version**. Ela abre a tabela no PlaidCloud, onde você escolhe no menu **As of** a versão imediatamente anterior a este salvamento.
