O PlaidXL adiciona ao Excel funções que leem os dados do PlaidCloud diretamente para as células. Digite `=PLAIDXL.` em uma célula e o preenchimento automático do Excel as lista, com uma breve descrição de cada argumento. A guia **Formulas** do painel de tarefas também pode escrever uma para você; consulte [Insira uma fórmula pelo painel de tarefas](#insira-uma-fórmula-pelo-painel-de-tarefas).

| Grupo | Funções | Use-as para |
|---|---|---|
| Listas | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Ver o que está disponível para construir |
| Tabelas | [`TABLE.GET_TABLE`](#get_table) | Ler uma tabela inteira em um intervalo |
| Hierarquias | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Dispor os nós de uma dimensão como linhas de relatório |
| Valores | [`CELL`](#cell), [`CELLS`](#cells) | Calcular um valor consolidado para qualquer combinação de nós |
| Blocos de construção | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Descrever a tabela, a medida, a agregação, os nós e a profundidade do detalhamento que `CELL`, `CELLS` e `DRILL` usam |

[Crie um relatório com funções personalizadas](/pt-br/reference/cli/plaidxl/build-a-report/) mostra essas funções trabalhando juntas.

## Como as funções funcionam

- **Faça login primeiro.** As funções leem com o seu login do PlaidCloud; por isso, [faça login](/pt-br/reference/cli/plaidxl/connect/) pelo painel de tarefas antes de usá-las.
- **Elas leem do projeto da pasta de trabalho.** Cada função lê do projeto vinculado à pasta de trabalho no painel de tarefas. `GET_TABLE`, `TBL_LIST` e `DIM_LIST` também aceitam um ID de projeto opcional, para ler outro projeto sem alterar o vínculo. Cada pasta de trabalho tem o seu próprio projeto; assim, duas pastas de trabalho abertas podem ler de projetos diferentes.
- **Os resultados se espalham.** Uma função que retorna uma lista ou uma tabela preenche as células abaixo dela (ou à sua direita). Deixe espaço para os resultados; se algo estiver no caminho, o Excel mostra um erro `#SPILL!`.
- **Recalcule para obter as alterações.** Uma fórmula do PlaidXL busca os dados novamente quando um dos seus argumentos muda. Para obter novos dados no PlaidCloud, ou um projeto diferente vinculado no painel de tarefas, force um recálculo completo; no Windows, pressione **Ctrl+Alt+F9**. **Refresh All Tables** atualiza as tabelas recuperadas, não as fórmulas.
- **Use os nomes exatos.** Digite os nomes de tabelas, colunas, dimensões e nós exatamente como aparecem no PlaidCloud.

Os argumentos entre colchetes são opcionais.

## Listas

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Lista os nomes dos projetos que você pode abrir, em ordem alfabética.

- `horizontal`: `TRUE` para listar em uma linha. O padrão é `FALSE`, uma coluna.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Lista os nomes das tabelas de um projeto, em ordem alfabética.

- `project_id`: o projeto a ser lido. O padrão é o projeto da pasta de trabalho.
- `horizontal`: `TRUE` para listar em uma linha. O padrão é `FALSE`, uma coluna.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Lista os nomes das colunas de uma tabela do projeto selecionado.

- `table_name`: o nome da tabela no PlaidCloud.
- `column_filter`: um tipo de dados, como `"text"`, para listar apenas as colunas desse tipo. Omita-o para listar todas as colunas.
- `orientation`: `"vertical"` (o padrão) para uma coluna ou `"horizontal"` para uma linha.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Lista os nomes das dimensões de um projeto.

- `project_id`: o projeto a ser lido. O padrão é o projeto da pasta de trabalho.
- `horizontal`: `TRUE` para listar em uma linha. O padrão é `FALSE`, uma coluna.

## Tabelas

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Retorna as linhas de uma tabela com uma linha de cabeçalho, espalhadas a partir da célula da fórmula. Valores vazios voltam como células em branco.

- `table_name`: o nome da tabela no PlaidCloud.
- `project_id`: o projeto a ser lido. O padrão é o projeto da pasta de trabalho.
- `limit`: o máximo de linhas a retornar. O padrão é 1.048.575, o máximo que uma planilha comporta abaixo de uma linha de cabeçalho.

`GET_TABLE` retorna todas as colunas. Para escolher colunas ou filtrar linhas, [recupere a tabela pelo painel de tarefas](/pt-br/reference/cli/plaidxl/retrieve/#recupere-uma-tabela).

## Hierarquias

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Dispõe os nós de uma dimensão, começando em `start_node` e descendo por seus descendentes. Cada geração é recuada quatro espaços a mais do que a do seu nó pai, e os grupos de estrutura de tópicos do Excel permitem recolher e expandir cada nível.

- `dimension_name`: o nome da dimensão ou o caminho dela no projeto.
- `start_node`: o nó de partida, como a raiz da dimensão.
- `hierarchy`: a [hierarquia alternativa](/pt-br/guides/dimensions/dimensions/#hierarquias-alternativas-de-atributo) a seguir. O padrão é `"main"`.
- `orientation`: `"vertical"` (o padrão) para listar os nós em uma coluna ou `"horizontal"` para listá-los em uma linha.
- `generation_limit`: quantas gerações retornar, contando `start_node` como a primeira: `2` retorna o nó de partida e seus filhos. Omita-o para retornar todas as gerações.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

Retorna `start_node` e os nós abaixo dele que `drill_key` pede, em uma coluna, recuados por geração e agrupados em uma estrutura de tópicos do Excel.

- `dimension_name`: o nome da dimensão ou o caminho dela no projeto.
- `start_node`: o nó a partir do qual detalhar.
- `drill_key`: até onde detalhar, a partir de [`DRILL_KEY`](#drill_key): todos os descendentes, apenas as folhas, um número de níveis ou um intervalo de gerações.
- `hierarchy`: a hierarquia alternativa a seguir. O padrão é `"main"`.

Por exemplo, `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` lista **Total** seguido de todas as regiões-folha abaixo dele.

Os [comandos de expansão da faixa de opções](/pt-br/reference/cli/plaidxl/ribbon/#funções-de-detalhamento) fazem o mesmo para uma dimensão e um nó que você digitou em duas células, sem escrever uma fórmula.

## Valores

`CELL` e `CELLS` calculam uma medida (uma coluna numérica de uma tabela) consolidada nos nós que você escolher em uma ou mais dimensões. Pense em cada chamada como uma interseção de um relatório: **Receita** de **EMEA** em **FY2026**.

Você descreve a interseção com as funções de blocos de construção abaixo, geralmente em células próprias, e depois passa essas células para `CELL` ou `CELLS` em qualquer ordem:

| Argumento | Criado com | Obrigatório |
|---|---|---|
| A tabela a ser lida | [`TABLE_REPR`](#table_repr) | Exatamente uma |
| A coluna a ser agregada | [`MEASURE`](#measure) para `CELL`, [`MEASURES`](#measures) ou várias células `MEASURE` para `CELLS` | Sim |
| Como agregá-la | [`MEASURE_TYPE`](#measure_type) | Não: o padrão é `sum` |
| Um filtro em uma coluna | [`DIMENSION_REPR`](#dimension_repr) | Pelo menos um, um por coluna |

Cada filtro nomeia uma **coluna da tabela** e um valor. Quando essa coluna está vinculada a uma dimensão no PlaidCloud, o valor é um nó, e o filtro inclui tudo o que se consolida nesse nó na hierarquia principal da dimensão: em uma coluna **Region** vinculada a uma dimensão de geografia, o nó **EMEA** abrange todos os países abaixo dele. Em uma coluna que não está vinculada a uma dimensão, o filtro corresponde exatamente ao valor.

Os exemplos desta página usam uma tabela cujas colunas **Region** e **Period** estão vinculadas a dimensões. Use os nomes das colunas da sua própria tabela.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Retorna um número: a medida, agregada nas linhas que ficam sob todos os nós que você passar.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` mostra a receita total de EMEA em FY2026.

Uma planilha cheia de fórmulas `CELL` é recalculada rapidamente: quando um recálculo pede muitos valores da mesma tabela, o PlaidXL os envia ao PlaidCloud juntos, em vez de uma solicitação por célula. Se não for possível calcular um valor, a célula mostra `#VALUE!` e, ao passar o mouse sobre ela, o motivo aparece como o PlaidCloud o informou, como uma coluna de filtro que não está na tabela ou um nó sem membros. `CELLS` mostra o primeiro motivo para o resultado inteiro.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Como `CELL`, mas para várias medidas de uma só vez. Retorna um número por medida, em uma coluna, na ordem em que você as listou.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` passa o resultado espalhado inteiro de `MEASURES`. `B2:B4` mostram receita, custo e unidades de EMEA em FY2026.

## Blocos de construção

Essas funções não leem dados por conta própria. Cada uma retorna um pequeno trecho de texto que descreve uma parte de um cálculo, pronto para ser passado para `CELL`, `CELLS` ou `DRILL`. Coloque-as em células que você referencia, de modo que uma única alteração, como um período diferente, atualize todas as fórmulas que as usam.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

A tabela da qual `CELL` e `CELLS` leem, pelo nome dela no projeto selecionado.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

A coluna numérica que `CELL` agrega.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Várias colunas de medida para `CELLS`, a partir de um intervalo de células que contêm nomes de colunas. O resultado se espalha em uma célula por coluna; passe-o para `CELLS` com o operador de derramamento, como `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Como agregar a medida. `agg_function` é um destes valores, em minúsculas:

| Valor | Retorna |
|---|---|
| `sum` | O total (o padrão quando você não passa um tipo de medida) |
| `mean` | A média |
| `median` | O valor central |
| `min` | O menor valor |
| `max` | O maior valor |
| `std` | O desvio padrão |
| `var` | A variância |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

Um filtro para `CELL` e `CELLS`. Passe um para cada coluna pela qual você quer filtrar.

- `dimension_name`: o nome de uma **coluna da tabela**, a coluna que contém os valores da dimensão, como `"Region"`. Ele deve corresponder exatamente ao nome da coluna; uma coluna que não está na tabela retorna um erro.
- `start_node`: o nó para o qual consolidar, como `"EMEA"`. Em uma coluna que não está vinculada a uma dimensão, o valor a ser correspondido.

Referencie uma célula para o nó a fim de montar uma grade: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Espaços no início e no fim são ignorados, de modo que você pode apontá-lo para os nomes de nós recuados que `DRILL` dispõe.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Até onde [`DRILL`](#drill) vai abaixo do nó de partida. `d_key` é texto simples, seja uma forma em palavras ou uma chave de detalhamento escrita por extenso:

| `d_key` | Detalha até |
|---|---|
| `"all"` | Todos os descendentes |
| `"leaves"` | Apenas as folhas, que são os nós sem nada abaixo deles |
| `"1 level"`, `"2 levels"`, … | Essa quantidade de gerações para baixo |
| `">[...]"` | A chave de detalhamento escrita por extenso, como na tabela seguinte |

Escreva o número com algarismos: `"2 levels"`, não `"two levels"`. Um `drill` no início é ignorado; assim, `"drill 2 levels"` também funciona.

Uma chave escrita por extenso conta as gerações para baixo a partir do nó de partida, que é a geração 0 e está sempre incluído. Números negativos contam para cima a partir das folhas de cada ramo, de modo que uma hierarquia irregular funciona como você esperaria.

| Chave | Inclui |
|---|---|
| `>[*]` ou `>[:]` | Todos os nós |
| `>[]` ou `>[-1]` | Apenas as folhas |
| `>[n]` | O nó de partida e `n` gerações abaixo dele. `>[0]` é somente o nó de partida. |
| `>[a:]` | O nó de partida, depois a geração `a` e tudo abaixo dela |
| `>[a:b]` | O nó de partida, depois as gerações de `a` até `b - 1` |
| `>[0:-k]` | O nó de partida e todos os nós que têm pelo menos `k` gerações abaixo deles, de modo que as últimas `k` gerações de cada ramo ficam de fora. `>[0:-1]` é todos os nós, exceto as folhas. |
| `>[a:-k]` | O mesmo, começando na geração `a` |

Para a hierarquia `A`, com os filhos `B`, `C` e `D`, em que `B` tem `B1` e `B2` e `C` tem `C1`:

| Chave | Resultado |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Os nós são listados na ordem da hierarquia, cada um sob o seu próprio nó pai, e os grupos da estrutura de tópicos do Excel seguem a mesma ordem. Os espaços dentro de uma chave são ignorados. Uma chave que não corresponde a nenhuma dessas formas retorna um erro que lista as formas válidas.

<Aside type="caution">
`>[-1]` e `>[0:-1]` significam algo diferente do que em versões anteriores do PlaidXL, em que eram invertidos. `>[-1]` agora retorna apenas as folhas, e `>[0:-1]` tudo, exceto as folhas. Revise qualquer pasta de trabalho que tenha escrito uma chave de detalhamento à mão. As formas em palavras `"all"`, `"leaves"` e `"2 levels"` não mudaram.
</Aside>

<Aside type="note">
`CELL`, `CELLS` e `DRILL` esperam a saída dessas funções de blocos de construção. Crie cada argumento com a sua função, em vez de digitar o texto você mesmo.
</Aside>

## Insira uma fórmula pelo painel de tarefas

A guia **Formulas** do painel de tarefas escreve uma fórmula para você. Em **What do you want in the cell?**, escolha uma opção:

- **A whole table** (`GET_TABLE`): escolha ou digite a tabela e, opcionalmente, um número máximo de linhas.
- **One number** (`CELL`): escolha ou digite a tabela e escolha **Column to total** e **How to combine the values**.
- **A list of dimension nodes** (`DRILL`): escolha ou digite a dimensão e o nó de partida, escolha **All levels**, **Lowest level only** ou **Down** um número de **levels** e, opcionalmente, uma Hierarquia alternativa.

A pré-visualização de **Formula** mostra o resultado à medida que você preenche os campos. Clique em **Insert in active cell** para colocá-la na célula selecionada ou em **Copiar** para colá-la você mesmo. Escolher uma tabela na guia **Tabelas** ou uma dimensão na guia **Dimensions** preenche o campo correspondente.
