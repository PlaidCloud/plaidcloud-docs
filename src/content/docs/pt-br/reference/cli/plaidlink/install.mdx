## Baixar o Agente

Consulte as versões disponíveis em [PlaidCloud.com](https://plaidcloud.com/) para o **PlaidLink**.

## Extrair o Agente

Extraia o arquivo zip baixado em um local de instalação de sua escolha. Em geral, esse local será:

```bash
C:\Users\<Username here>\src\plaidlink
```

## Criar um Arquivo de Configuração

<Aside>Se você está atualizando de uma versão anterior do agente, o arquivo de configuração continua válido e você pode ignorar esta etapa</Aside>

Copie o arquivo `config-dist.yaml` do diretório do agente para `%ProgramData\plaidcloud\` e renomeie essa cópia para `config.yaml`.

*(Edite esta configuração com os valores obtidos no PlaidCloud)*

## Instalar o Serviço do Agente

Execute o arquivo `install_windows_service.bat` no diretório de instalação do agente OU

Em um prompt de comando como administrador, navegue até o diretório de instalação do agente e execute:

```bash
.\PlaidLink.exe install
```

## Executar o Agente

<Aside>Para instalar um serviço do Windows, é necessário ter privilégios de administrador</Aside>

Digite **`Services`** na barra de pesquisa do Windows e abra o gerenciador de serviços. Na lista de serviços, localize **`PlaidCloud Agent`**.

Clique com o botão direito do mouse no serviço e selecione **"Start"** para iniciar o agente.

## Congelar Atualizações

Se em algum momento você quiser desabilitar o recurso de atualização automática do agente, abra o arquivo de configuração **'yaml'** do agente,
e no nível raiz do arquivo, adicione uma linha com `freeze_updates: true` e reinicie o serviço do agente.

<Aside type="caution">Não é recomendado desabilitar as atualizações automáticas por longos períodos</Aside>
