O agente PlaidLink funciona em conjunto com o serviço PlaidCloud. Ele fornece a conexão necessária 
para operar com sistemas que não são acessíveis diretamente, como bancos de dados e sistemas de arquivos. O agente executa diversas ações essenciais, incluindo:

* Ler e gravar em bancos de dados
* Ler e gravar arquivos em unidades de rede e servidores
* Verificar condições de sensores
* Interagir com o SAP ECC e o SAP S/4HANA por meio de chamadas de função remota (RFCs)
* Interagir com o SAP Profitability and Cost Management (PCM)
* Enviar mensagens e notificações a sistemas remotos

## Criar um agente no PlaidCloud

O gerenciamento de agentes PlaidLink é feito na guia Analyze do PlaidCloud. O primeiro passo é criar uma nova instância de agente PlaidLink no PlaidCloud.

### Para criar um novo agente PlaidLink

1. Selecione a guia Analyze
2. Selecione o menu Tools no topo
3. Clique em Agentes PlaidLink
4. Crie um novo agente com um nome adequado ao ambiente ou ao servidor em que ele será instalado para operações remotas

### Para ver as chaves pública e privada do agente

1. Clique no ícone de edição para ver o formulário
2. Na parte inferior do formulário, você encontrará as chaves pública e privada geradas aleatoriamente durante o processo de criação do agente

<Aside>Guarde essas chaves, pois elas serão usadas na configuração do agente no servidor remoto.</Aside>

### Para gerar novas chaves aleatoriamente

1. Clique no ícone de regenerar no registro do agente
2. Depois que as chaves forem regeneradas, não se esqueça de atualizar o arquivo de configuração do agente com as novas chaves no servidor remoto.

<Aside>Guarde as chaves pública e privada para configurar o agente remoto na próxima etapa.</Aside>

## Acesso à conta de documentos

Se o agente precisar de acesso a uma conta de documentos para carregar ou baixar arquivos, é necessário conceder a ele permissão para acessá-la.

### Para conceder acesso à conta

1. Na guia Document, selecione Gerenciar contas
2. Quando a tabela de contas for exibida, clique no ícone de agente da conta à qual o novo agente deve ter direitos de carregamento e download
3. Arraste o novo agente para a coluna Agentes atribuídos
4. Salve o formulário de controle de acesso.

<Aside>Os agentes só podem carregar e baixar arquivos se tiverem recebido acesso a uma ou mais contas de documentos.</Aside>

## Acesso à conexão de dados

Se o agente precisar de acesso a uma conexão de dados, como um banco de dados, é necessário conceder a ele permissão para acessar as informações da conexão de dados externa.


### Para conceder acesso à conexão


1. Na guia Analyze, selecione o menu Tools
2. Clique em Conexões de dados externas
3. Quando a tabela de conexões de dados for exibida, clique no ícone de agente da conexão à qual o novo agente deve ter direitos de uso
4. Arraste o novo agente para a coluna Agentes atribuídos e salve o formulário de controle de acesso.

<Aside>As credenciais de conexão de dados do agente são gerenciadas em Conexões de dados externas.</Aside>
