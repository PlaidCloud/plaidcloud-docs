## Descrição

Importa dados do Workday Financials, pela sua [conexão com o Workday Financials](/pt-br/guides/connections/workday-financials/), para uma tabela de projeto. Diferentemente do NetSuite, do Acumatica ou do Business Central, o PlaidCloud não tem um conjunto fixo de entidades prontas do Workday Financials: em vez disso, você cria um **relatório Report-as-a-Service (RaaS)** no Workday, o publica com acesso a Web Service e informa à etapa a URL do relatório como origem da extração.

## Configuração

| Campo | Obrigatório | Observações |
|---|---|---|
| Conexão do Workday | Sim | A conexão do Workday Financials pela qual ler. |
| URL do relatório RaaS | Sim | A URL do Web Service do relatório RaaS que você criou e publicou no Workday. |
| Tabela de destino | Sim | A tabela de projeto em que os resultados são gravados. Ela é totalmente sobrescrita a cada execução. |
| Filtros | Não | `company`, `ledger`, `period`, `accounting_date` (intervalo), `ledger_account` (intervalo), `cost_center`. Cada um é repassado como parâmetro do relatório — um filtro só tem efeito se o seu relatório RaaS definir um prompt correspondente. |

<Aside type="caution">
Definir um filtro sem um prompt correspondente no relatório é rejeitado, não ignorado em silêncio. Adicione primeiro o prompt ao relatório RaaS no Workday e depois defina o filtro aqui.
</Aside>

<Aside type="note">
Como o próprio relatório define os campos retornados, o formato da sua importação — nomes de colunas, granularidade, dimensões incluídas — é o que o seu relatório RaaS produzir. Projete o relatório com o formato esperado da tabela de destino em mente.
</Aside>
