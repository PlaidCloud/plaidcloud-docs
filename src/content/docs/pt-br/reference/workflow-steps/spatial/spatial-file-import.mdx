## Descrição

A etapa **Importar arquivo espacial** lê um arquivo espacial — MapInfo `.TAB`,
ESRI `.shp`, `.kml`, `.geojson` ou SRC `.geo` — e seus arquivos auxiliares para uma
tabela, com uma linha por recurso e uma coluna de geometria WKT. Ela é o equivalente da
ferramenta *Input Data* do Alteryx apontada para um arquivo espacial e é executada no mecanismo de
fluxo de trabalho (GDAL).

## Parâmetros de importação

- **Origem** — o arquivo espacial no armazenamento de documentos. Os arquivos
  auxiliares dele (por exemplo, `.dat`/`.map`/`.id`/`.dbf` de um `.TAB`, ou `.shx`/`.dbf`/`.prj` de um shapefile)
  são lidos automaticamente do mesmo local.
- **Tabela de destino** — a tabela em que os recursos são gravados.

## Observações

O esquema de saída é obtido do arquivo, portanto não há mapeamento de colunas. A
geometria proprietária de um arquivo SRC `.geo` não pode ser lida; seus atributos `.dbf` são
importados com valores de geometria vazios.
