## Descrição

A etapa **Espacial: Ponto para linha** une pontos em uma linha, gravada em uma coluna chamada `SequenceLine`. Ela grava uma linha para cada grupo ou uma linha para todos os pontos quando você não informa um grupo.

## Origem e opções

- **Tabela de origem** e **Tabela de saída** — a tabela a ser lida e a tabela a ser gravada.
- **Coluna de ponto** — a coluna que contém os pontos WKT.
- **Agrupar por** *(opcional)* — uma linha para cada valor dessa coluna. Deixe em branco para fazer de todos os pontos uma única linha.
- **Ordenar por** *(opcional)* — a coluna que ordena os pontos em uma linha. Números são ordenados como números e os demais valores como texto. Sem ela, os pontos mantêm a ordem de entrada.
