## Descrição



Executa SQL em um banco de dados remoto por meio de um agente PlaidLink e traz o conjunto de resultados de volta ao PlaidCloud como uma tabela de projeto. É usada quando o banco de dados de origem não pode ser acessado diretamente pelo PlaidCloud (firewall, somente VPN, local) mas você ainda quer extrair dados dele.

O agente executa a consulta no ambiente local e transmite o resultado ao PlaidCloud, de modo que as credenciais e os dados permanecem na sua rede até que o resultado seja necessário.
