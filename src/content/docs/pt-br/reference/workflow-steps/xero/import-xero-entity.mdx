## Descrição

Importa uma entidade da API Accounting do Xero, restrita à organização da conexão, por meio da sua [conexão do Xero](/pt-br/guides/connections/xero/) para uma tabela do projeto. Escolha a conexão, o tipo de entidade e os filtros desejados; a etapa busca os registros correspondentes e os grava, sem nenhuma consulta para escrever.

Um único tipo de etapa cobre onze entidades, de dados de referência (plano de contas, contatos, itens, alíquotas de imposto, moedas) a registros transacionais (faturas, notas de crédito, pagamentos, lançamentos manuais, transações bancárias).

## Configuração

| Campo | Obrigatório | Observações |
|---|---|---|
| Conexão do Xero | Sim | A conexão do Xero pela qual os dados serão lidos. |
| Tabela de destino | Sim | A tabela do projeto na qual os resultados são gravados. |
| Tipo de entidade | Sim | Qual entidade importar. O padrão é **Faturas**. |
| Status | Não | Restringe a um único valor de `Status` do Xero, por exemplo `AUTHORISED` ou `PAID`. |
| Data inicial | Não | Limite inferior, no formato `YYYY-MM-DD`, para o `Date` da entidade. |
| Data final | Não | Limite superior, no formato `YYYY-MM-DD`, para o `Date` da entidade. |
| Atualizado após | Não | Enviado como data limite de modificação, de modo que somente as linhas alteradas depois dela são retornadas. Em branco, importa tudo. |

<Aside type="note">
**Atualizado após** é um filtro do lado da solicitação, sem marca d'água salva — o PlaidCloud não lembra onde a última execução parou; portanto, informe você mesmo a data limite a cada execução para obter um comportamento incremental.
</Aside>

## Tipos de entidade

| Tipo de entidade | O que contém |
|---|---|
| Plano de contas | Código da conta, nome, tipo, classe, tipo de imposto, status, código de relatório. |
| Contatos | Clientes e fornecedores, com status, número fiscal e moeda padrão. |
| Faturas | Faturas de venda e de compra, com contato, datas, status, totais e valor devido. |
| Notas de crédito | Notas de crédito de vendas ou compras, com contato, data, status e total. |
| Pagamentos | Pagamentos com data, valor, status e conta bancária. |
| Lançamentos manuais | Descrição do lançamento, data e status. |
| Transações bancárias | Transações de pagamento e de recebimento, com data, status, total e indicador de conciliação. |
| Itens | Itens de estoque e de serviço, com indicador de rastreamento e quantidade em estoque. |
| Categorias de rastreamento | Nomes e status das categorias de rastreamento. |
| Alíquotas de imposto | Nomes, tipos, status e alíquota efetiva das alíquotas de imposto. |
| Moedas | Códigos e descrições de moedas. |

<Aside type="note">
Nem toda entidade documenta todos os filtros — Itens e Moedas não aceitam nenhum deles, e Plano de contas e Contatos aceitam um status, mas não um intervalo de datas. Os campos de filtro permanecem habilitados para todas as entidades; o Xero rejeita um filtro que a entidade não suporta, portanto a etapa informa o erro em vez de retornar um conjunto de resultados incorreto.
</Aside>

<Aside type="caution">
**A organização vem da conexão, não desta etapa.** Toda solicitação ao Xero nomeia uma organização, e a conexão a carrega — por isso não há campo de organização na etapa. Para importar a mesma entidade de uma segunda organização, crie uma segunda conexão do Xero que aponte para ela.
</Aside>
