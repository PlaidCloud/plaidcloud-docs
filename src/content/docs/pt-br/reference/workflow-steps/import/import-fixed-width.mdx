## Descrição



Importa arquivos de texto em que as colunas são definidas por posições de caracteres em vez de delimitadores — o clássico formato de saída de mainframe / COBOL. Configure os limites das colunas (posição inicial, comprimento) para cada campo.

É comum em exportações de ERPs legados, declarações governamentais e formatos de extratos bancários, em que os dados foram dispostos para exibição em colunas fixas, e não para análise delimitada.

As importações de largura fixa são transmitidas por armazenamento temporário em vez de carregar o arquivo inteiro na memória, de modo que arquivos muito grandes são importados sem esgotar a memória.

### Cabeçalho

Como os arquivos Excel podem ou não conter cabeçalhos, o PlaidCloud oferece uma forma de usar os cabeçalhos, ignorá-los ou usar a ordem das colunas para determinar o alinhamento delas.
* **Sem cabeçalho**: o arquivo não contém cabeçalho. Use a lista de origem no *Data Mapper* para determinar o alinhamento das colunas
* **Com cabeçalho - usar cabeçalho e substituir lista de campos**: o arquivo tem cabeçalho. Use os nomes de cabeçalho especificados e ignore a lista de origem no *Data Mapper*.
* **Com cabeçalho - ignorar cabeçalho e usar a lista de campos**: o arquivo tem cabeçalho, mas ele deve ser ignorado. Use os nomes de cabeçalho especificados pela lista de origem no *Data Mapper*.

### Seleção de linhas

Para arquivos de entrada com registros estranhos, você pode especificar um número de linhas a ignorar antes de processar os dados. Isso é útil se os arquivos contêm blocos de cabeçalho que precisam ser ignorados antes de chegar aos dados tabulares.

### Larguras das colunas

Informe as larguras das colunas separadas por vírgulas ou espaços.

### Layout

| Configuração | O que faz |
| --- | --- |
| Codificação | O conjunto de caracteres do arquivo: **UTF-8** (o padrão), **EBCDIC (EUA, cp037)**, **EBCDIC (internacional, cp500)** ou **Latin-1**. Escolha uma página de código EBCDIC para um arquivo de mainframe. |
| Registros a ignorar | Quantos registros ignorar no início do arquivo, antes do cabeçalho ou dos dados. |
| Registros a descartar no final | Quantos registros descartar do final do arquivo, como um registro de rodapé. |
| Um registro por linha | Ativado (o padrão), cada linha é um registro. Desmarque para um arquivo cujos registros estão dispostos um após o outro, sem quebras de linha; cada registro tem então o comprimento total das larguras das colunas. |
| Caracteres entre registros | Quando os registros não são um por linha, quantos caracteres ignorar após cada registro, como um separador. |
| Remover espaços | Os espaços em branco removidos de cada valor: **Iniciais e finais** (o padrão), **Somente finais** ou **Nenhum**. |
