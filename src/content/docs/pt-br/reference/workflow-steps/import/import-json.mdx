## Descrição

Importe arquivos de texto JSON do PlaidCloud Document.

Para mais detalhes sobre arquivos JSON, consulte o site oficial do JSON: http://json.org/.

Os arquivos JSON *não* mantêm a ordem das colunas. A ordem das colunas no arquivo de origem não reflete necessariamente a ordem das colunas na tabela de dados importada.

As importações de JSON são transmitidas por armazenamento temporário em vez de carregar o documento inteiro na memória, de modo que arquivos muito grandes são importados sem esgotar a memória. As colunas que aparecem pela primeira vez no fim de um documento grande são incluídas na tabela importada. Objetos e arrays aninhados são importados como texto JSON compacto padrão, de modo que as etapas seguintes possam analisá-los com qualquer ferramenta JSON.

## Itens de configuração exclusivos

### Orientação dos dados JSON

Considere o seguinte conjunto de dados:

| ID | Name | Gender | State |
| 1 | Jack | M | MO |
| 2 | Jill | F | MO |
| 3 | George | M | VA |
| 4 | Abe | M | KY |

Os arquivos JSON podem ser importados em um de três formatos de dados:

* Records: os dados são armazenados em conjuntos de dicionários Python, com cada linha armazenada no formato \{Column -> Value, …}. Por exemplo:


```json
[{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" }]
```

* Index: os dados são armazenados em conjuntos de dicionários Python aninhados, com cada linha armazenada no formato \{Index -> \{Column -> Value, …},…}. Por exemplo:


```json
{ "0": { "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, "1": { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, "2": { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, "3": { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" } }
```

* Split: os dados são armazenados em um único conjunto de dicionário Python, com os valores armazenados em listas. Por exemplo:


```json
{ "columns": ["ID", "Name", "Gender", "State"], "index": [0, 1, 2, 3], "data": [ [1, "Jack", "M", "MO"], [2, "Jill", "F", "MO"], [3, "George", "M", "VA"], [4, "Abe", "M", "KY"] ] }
```

Além dos formatos acima, o JSON delimitado por nova linha (NDJSON) é aceito: um objeto JSON independente por linha, sem array envolvente. Por exemplo:

```json
{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }
{ "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }
```


### Documento inteiro

Para manter o JSON de cada arquivo intacto, selecione **Importar cada arquivo como uma linha com todo o documento JSON** (`whole_document`) em **Mais opções de JSON**. Cada arquivo é então importado como uma linha que contém todo o seu documento JSON, com os números mantidos como foram escritos.
