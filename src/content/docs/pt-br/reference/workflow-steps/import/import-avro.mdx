## Descrição

Importe arquivos Apache Avro do PlaidCloud Document. Avro é um formato de serialização de dados baseado em linhas, do projeto Apache Hadoop, que armazena os dados junto com seu esquema, o que o torna adequado para pipelines de dados e sistemas de streaming.

## Itens de configuração exclusivos

### Hora de modificação do arquivo

Leia apenas os arquivos alterados em um intervalo de tempo. **Modificado depois de** lê apenas os arquivos modificados pela última vez depois do horário informado, e **Modificado antes de** apenas os modificados antes dele; defina um dos dois ou ambos. Informe o horário como `YYYY-MM-DDTHH:MM:SS`, como `2026-10-01T00:00:00`. O horário é UTC, a menos que indique um fuso, como `2026-10-01T00:00:00-05:00`. O horário pode conter uma variável de fluxo de trabalho, que é lida quando a etapa é executada.
