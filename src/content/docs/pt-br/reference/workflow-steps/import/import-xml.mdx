## Descrição


Importa dados tabulares de um arquivo XML para uma tabela de projeto do PlaidCloud. Configure o caminho do elemento que identifica cada "linha" e mapeie os elementos filhos ou atributos para colunas da tabela.

É comum em integrações corporativas mais antigas, na troca de dados B2B (RosettaNet, ebXML) e em formatos de declarações governamentais.


## Ler registros como

**Ler registros como** define como o arquivo se torna tabelas:

* **Uma tabela por tag de registro** (padrão) — a guia **Tags de registro** lista cada tag a ser lida, e cada tag é carregada em sua própria tabela, nomeada a partir do **Prefixo das tabelas de destino**.
* **Uma linha por elemento** — um elemento repetido é carregado em uma tabela, com uma linha para cada ocorrência. A guia **Tags de registro** e o **Prefixo das tabelas de destino** ficam desativados.

Com **Uma linha por elemento**, defina:

* **Elemento XML** — o elemento que forma uma linha. Se deixado em branco, é o elemento da primeira coluna, exibido no campo.
* **Tabela de destino** — a tabela a ser carregada.
* **Colunas** — cada **Elemento filho ou atributo** e a **Coluna** em que ele é carregado. Todas as colunas são importadas como texto.
* **Remover espaços ao redor dos valores** — remove os espaços em branco iniciais e finais de cada valor.
* **Corresponder nomes com o respectivo prefixo de namespace** — corresponde os nomes de elementos e atributos como estão escritos no arquivo, incluindo o prefixo.

Arquivo de origem, Tabela de destino e um Elemento XML ou pelo menos uma coluna são obrigatórios. Alternar entre os modos mantém no formulário as configurações do outro modo, de modo que voltar as restaura, mas salvar remove as configurações do modo do qual você saiu; uma observação ao lado do controle explica isso.

As etapas salvas pelo formulário leem suas tags de registro conforme definido na guia **Tags de registro**.
