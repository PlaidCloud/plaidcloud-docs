## Descrição

A etapa **Import dBASE** importa um arquivo dBASE (`.dbf`), que traz seu próprio esquema. Ela é executada no mecanismo de fluxo de trabalho; os resultados de macros empacotadas são uma aproximação da macro do Alteryx.

As importações de dBASE são transmitidas por armazenamento temporário em vez de carregar o arquivo inteiro na memória, de modo que arquivos muito grandes são importados sem esgotar a memória. Os tipos de dados do arquivo — decimais, datas e timestamps — são preservados na tabela de destino.

## Parâmetros

- **Origem** — o arquivo `.dbf`.
- **Tabela de destino** — a tabela de saída.
- **Ignorar nova importação se os arquivos de origem não mudaram** — uma execução de fluxo de trabalho ignora a importação se o arquivo de origem e as configurações da etapa não mudaram desde a última execução bem-sucedida. Ativado por padrão; desmarque para sempre importar novamente.
