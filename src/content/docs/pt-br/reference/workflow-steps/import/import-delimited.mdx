## Descrição

A etapa **Importar: Delimitado (por posição)** lê todas as colunas de um documento delimitado por posição, como colunas de texto chamadas `Column_1` a `Column_N`, e ignora a linha de cabeçalho. Use-a quando o cabeçalho não puder nomear as colunas, por exemplo quando uma etapa posterior promove uma linha de dados a cabeçalho.

## Parâmetros

- **Documento** — a conta de documentos e o caminho do arquivo. Um caminho terminado em `.gz` é descompactado.
- **Delimitador** — o delimitador de campos. O padrão é a vírgula.
- **Caractere de aspas** — o padrão é aspas duplas.
- **Coluna de número do registro** *(opcional)* — uma coluna que numera os registros na ordem do arquivo. Deixe em branco para não gravar nenhuma.
- **Tabela de saída** — onde as linhas são gravadas.

Um documento ausente não é um erro. A etapa termina com um aviso que informa o caminho e grava uma tabela vazia.
