## Descrição

Importe arquivos Apache Parquet do PlaidCloud Document. Parquet é um formato de armazenamento colunar amplamente usado no ecossistema Hadoop e em plataformas de dados na nuvem, que oferece compactação e codificação eficientes para grandes conjuntos de dados.

As importações de Parquet são transmitidas por armazenamento temporário em vez de carregar o arquivo inteiro na memória, de modo que arquivos muito grandes são importados sem esgotar a memória. Os tipos de dados do arquivo — decimais, datas e timestamps — são preservados na tabela de destino, e as colunas de timestamp mantêm a precisão completa de data e hora do dia.
