## Descrição

Restaura tabelas de projeto a partir de um arquivo compactado criado por [Arquivar tabelas](/pt-br/reference/workflow-steps/export/archive-tables/). Use-a para mover dados de tabelas entre projetos ou espaços de trabalho, ou para voltar a uma cópia guardada.

## Itens de configuração exclusivos

### Origem

O arquivo compactado em uma conta de documentos. O seletor também permite correspondência por pesquisa — exata, começa com, termina com, contém ou glob — em vez de um caminho exato.

### Sobrescrever

Desativado por padrão. Quando desativado, uma tabela que já existe no projeto é deixada como está. Ative para substituir as tabelas existentes pelas cópias arquivadas.
