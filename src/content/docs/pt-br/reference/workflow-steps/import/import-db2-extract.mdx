## Descrição

Importe um arquivo de extração do IBM DB2 do armazenamento do PlaidCloud Document. Isso é útil quando o servidor DB2 só é acessível a partir da infraestrutura local: um processo externo envia a extração para o armazenamento do PlaidCloud Document, e esta etapa a lê de lá para uma tabela de projeto.

Para acesso ao vivo ao DB2 (sem arquivo de extração), conecte-se pela conexão padrão do [IBM DB2](../../../connectors/databases/ibm-db2/) e use [Importar tabelas de banco de dados externo](../import-external-database-tables/).
