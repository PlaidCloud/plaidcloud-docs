## Descrição

Importe arquivos Apache ORC do PlaidCloud Document. ORC é um formato de armazenamento colunar gravado pelo Hive e pelo Spark, com o esquema contido no arquivo.

O formulário da etapa tem três guias:

- **Parâmetros de importação** — o **Arquivo de origem** (uma conta de documentos e o caminho do arquivo ou da pasta) e a **Tabela de destino**, com **Remover caracteres não ASCII** (`ascii_only`), **Excluir arquivo(s) após a importação** (`delete_file`) e **Ignorar nova importação se os arquivos de origem não mudaram** (`skip_if_unchanged`).
- **Seleção de dados da tabela** — mapeia as colunas de origem para as colunas de destino, com **Resumir** e **Distintos**. **Preencher** lê as colunas e seus tipos a partir do esquema contido no arquivo ORC.
- **Filtros de dados** — filtra as linhas antes e depois de resumir.

Quando o arquivo não existe ou está vazio, **Preencher** responde *Nada para preencher* com um aviso que informa o caminho e mantém o mapeamento que você já tem.

Os [projetos Prophecy migrados](/pt-br/guides/workflows/migrate-prophecy-projects/) usam esta etapa para conjuntos de dados ORC.
