## Descrição


Importa arquivos de dados Stata (.dta) para tabelas de projeto do PlaidCloud. Útil para organizações que usam o Stata em análises econométricas ou estatísticas e trazem seus conjuntos de dados de trabalho para o PlaidCloud para processamento adicional.

Os rótulos de variáveis são preservados quando o formato Stata os inclui.
