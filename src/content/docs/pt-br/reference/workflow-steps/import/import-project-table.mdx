## Descrição


Copia dados de uma tabela de um projeto diferente para o projeto atual. O inverso da etapa [Export Project Table](/pt-br/reference/workflow-steps/export/export-project-table/) — puxa em vez de enviar.

Útil quando um projeto de consolidação obtém dados de vários projetos operacionais, ou quando os dados de referência são centralizados em um projeto e lidos por outros. O projeto de origem deve conceder a este projeto um compartilhamento de dados de **Leitura**.


## Gerenciamento de compartilhamento de dados

![Gerenciamento de compartilhamento de dados](/images/import_external_project_table_1.png)

Antes de importar uma tabela de outro projeto, esse projeto precisa permitir que este a leia. Abra a guia **Início** do projeto de **origem** e, em **Gerenciamento de compartilhamento de dados**, clique em **Novo compartilhamento de dados**, selecione este projeto, marque **Leitura** em **Operações permitidas** e clique em **Adicionar compartilhamento de dados**. Veja [Compartilhando dados entre projetos](/pt-br/guides/projects/managing-projects/#compartilhar-dados-entre-projetos).

A etapa é executada com a identidade do próprio projeto, de modo que uma execução funciona por meio do compartilhamento, independentemente de quem a inicie.

## Importar tabela de projeto externa

![Importar origem e destino](/images/import_external_project_table_2.png)

### Ler de
Selecione o **Projeto de origem** e a **Tabela de origem** nos menus suspensos.

<Aside type="note" title="Tabela de origem vazia">
Se a tabela de origem não tiver linhas quando a etapa for executada, a importação termina com um aviso de que a origem estava vazia, em vez de um sucesso silencioso — assim, uma tabela de destino inesperadamente vazia é fácil de notar. Na maioria das vezes, isso significa que o fluxo de trabalho do projeto de origem ainda não havia criado essa tabela; garanta que a origem esteja preenchida (e, em execuções agendadas, programada para ser executada antes) antes da importação.
</Aside>

<Aside type="note" title="Excluindo uma tabela de origem">
A tabela de origem que você lê é tratada como em uso por esta etapa. Se você tentar excluí-la, o PlaidCloud mostra a referência e exige que você confirme uma exclusão forçada — marcando **Forçar a exclusão da tabela?** e escolhendo **Forçar exclusão** — em vez de uma exclusão simples, mesmo quando a etapa de importação está em um projeto diferente que compartilha os dados. Nesse caso entre projetos, o aviso lista a referência sem nomear a etapa do outro projeto, já que você pode não ter acesso a ela.
</Aside>
