## Descrição


Importa um arquivo compactado nativo do PlaidCloud de volta para uma tabela de projeto. O formato preserva os tipos de coluna, os metadados e os índices que não sobrevivem a uma ida e volta por CSV.

Criado por [Export to Table Archive](/pt-br/reference/workflow-steps/export/export-to-table-archive/). Usado para backups de projetos, migrações entre espaços de trabalho ou ambientes e transferência confiável de dados tipados.
