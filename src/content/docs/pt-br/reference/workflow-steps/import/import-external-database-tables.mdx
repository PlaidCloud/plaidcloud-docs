## Descrição


Importa uma ou mais tabelas de um banco de dados externo (configurado por meio de um conector de banco de dados) para tabelas de projeto. Oferece suporte a **cargas delta** — trazendo apenas as linhas que mudaram desde a última importação — e ao **remapeamento de nomes de tabela** — gravando a tabela de origem no PlaidCloud com outro nome.

Use-a para manter as tabelas do PlaidCloud sincronizadas com os sistemas de origem operacionais de forma agendada, sem importar novamente todas as linhas a cada vez.

<Aside title="Inspecionar origem lê o banco de dados externo">
Para uma tabela adicionada a esta etapa, o botão **Inspecionar origem** lê as colunas atuais dessa tabela diretamente do banco de dados conectado e atualiza no próprio local apenas o mapeamento dessa tabela. Use-o quando as colunas de uma tabela de origem mudaram desde que você configurou a etapa, sem executar novamente a descoberta em toda a conexão.
</Aside>

<Aside title="Tipos de coluna do PostgreSQL">
Em uma origem PostgreSQL, as colunas `uuid` são importadas como texto, e as colunas `json`/`jsonb` são importadas como sua representação em texto JSON.
</Aside>

<Aside title="Colunas numéricas são importadas como decimais exatos">
Uma coluna `numeric`/`decimal` de origem é importada como um valor decimal exato, com até 28 dígitos à esquerda da vírgula decimal e 10 dígitos à direita. Um valor com mais de 10 casas decimais é arredondado para caber; um valor com mais de 28 dígitos inteiros interrompe a importação, informando a coluna.
</Aside>

<Aside type="caution" title="Um valor que não cabe na coluna interrompe a importação">
Se um valor de origem não cabe na coluna de destino sem perda de dados — uma fração em uma coluna de inteiros, um número grande demais para a coluna ou `NaN`/`Infinity` em uma coluna numérica —, a importação é interrompida com um erro que informa a coluna e seu tipo de dados, em vez de truncar ou arredondar silenciosamente. No Data Mapper da etapa, defina o **Tipo** dessa coluna como um que comporte o valor e execute a importação novamente.
</Aside>
