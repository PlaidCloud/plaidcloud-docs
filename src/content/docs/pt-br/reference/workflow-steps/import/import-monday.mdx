## Descrição

Importa os itens de um ou mais quadros do [monday.com](https://monday.com/) para tabelas de projeto por meio de uma conexão com o monday.com. Use-a para trazer dados de acompanhamento de projetos, filas de entrada ou tarefas operacionais para um fluxo de trabalho, junto com os dados financeiros.

## Itens de configuração exclusivos

### Configuração da conexão

A conexão com o monday.com usada para a leitura.

### Tabela de destino

Uma linha por quadro: o **ID do quadro** a ser lido e a tabela de projeto em que ele é gravado. Uma única etapa pode importar vários quadros ao mesmo tempo. Cada destino deve ser uma tabela, não uma visão.
