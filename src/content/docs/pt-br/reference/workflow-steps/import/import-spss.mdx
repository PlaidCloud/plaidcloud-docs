## Descrição



Importa arquivos de dados SPSS (formatos .sav e .zsav) para tabelas de projeto do PlaidCloud. Útil para dados de pesquisas, dados de pesquisa em ciências sociais ou qualquer pipeline que interopere com ferramentas baseadas em SPSS.

Os rótulos de variáveis e de valores são preservados quando o formato os oferece.
