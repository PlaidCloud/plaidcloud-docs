## Descrição


Importa dados do Google BigQuery para uma tabela de projeto do PlaidCloud. Útil para organizações que usam o BigQuery como principal data warehouse analítico e trazem conjuntos de dados específicos para o PlaidCloud para modelagem ou alocação adicionais.

A autenticação usa uma conta de serviço do Google Cloud; o conjunto de dados e a tabela de origem são configurados no nível da etapa.
