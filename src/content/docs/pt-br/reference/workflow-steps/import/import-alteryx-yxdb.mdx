## Descrição

Importe arquivos Alteryx YXDB do PlaidCloud Document. YXDB é o formato de arquivo binário nativo usado pelo Alteryx Designer para armazenar conjuntos de dados junto com os metadados dos campos.

As importações de YXDB são transmitidas por armazenamento temporário em vez de carregar o arquivo inteiro na memória, de modo que arquivos muito grandes são importados sem esgotar a memória. Os tipos de dados do arquivo — decimais, datas e timestamps — são preservados na tabela de destino.

Se o arquivo `.yxdb` configurado não existir, mas houver um arquivo `.parquet` com o mesmo nome na mesma pasta, a etapa lê o arquivo `.parquet` e exibe um aviso informando isso. Os fluxos de trabalho do Alteryx convertidos gravam suas saídas `.yxdb` como arquivos `.parquet` de mesmo nome, de modo que uma etapa que lê um desses arquivos `.yxdb` obtém os dados automaticamente. As importações que procuram arquivos por pesquisa não usam esse recurso alternativo.
