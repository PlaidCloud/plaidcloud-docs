Para mais detalhes sobre os conjuntos de dados do Quandl, consulte o site oficial do Quandl: http://www.quandl.com/.

## Itens de configuração exclusivos

### Especificação dos dados de origem

Acessar os conjuntos de dados do Quandl exige uma conta de usuário ou uma conta de convidado com acesso limitado. Isso requer configuração em Ferramentas. Para detalhes sobre como configurar uma conexão de conta do Quandl, veja aqui: [PlaidCloud Tools – Conexão](/pt-br/reference/connectors/).

Depois que todas as contas necessárias estiverem configuradas, selecione a conta apropriada na lista suspensa.

Em seguida, informe os critérios do código Quandl desejado. Os usuários podem usar a funcionalidade **Pesquisar** para procurar conjuntos de dados. Como alternativa, os conjuntos de dados podem ser informados manualmente. Isso exige que o usuário informe a parte da URL após “[http://www.quandl.com](http://www.quandl.com/)”. 

Por exemplo, para importar o conjunto de dados das ações da Microsoft, que pode ser encontrado aqui (http://www.quandl.com/GOOG/NASDAQ_MSFT), informe *GOOG/NASDAQ_MSFT* no campo de código do Quandl.


### Seleção de dados


É possível fatiar os conjuntos de dados do Quandl na importação. As opções disponíveis incluem:


* Data inicial: use o seletor de data para escolher a data desejada.
* Data final: use o seletor de data para escolher a data desejada.
* Collapse: agrega os resultados em base diária, semanal, mensal, trimestral ou anual. Por padrão, não há agregação.
* Transformation: cálculos de resumo.
* Limit Rows: o valor padrão 0 retorna todas as linhas. Qualquer outro valor inteiro positivo especifica o limite de linhas a retornar do conjunto de dados.
