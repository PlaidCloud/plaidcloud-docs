## Descrição


Importa planilhas específicas de uma planilha do Planilhas Google para tabelas de projeto do PlaidCloud. Útil para dados ad hoc que ficam em planilhas — tabelas de direcionadores mantidas por usuários de negócio, mapeamentos de consulta, ajustes manuais.

A autenticação é feita por uma conexão Google; várias planilhas de uma mesma planilha do Google podem ser importadas em uma única etapa.

## Parâmetros de importação


![Importar Planilha Google](/images/import_file_google_target.png)
### Origem e destino
#### Conta Google

Acessar dados do Planilhas Google exige uma conta de usuário Google válida. Isso requer configuração em Ferramentas. Para detalhes sobre como configurar uma conexão de conta Google, veja aqui: [PlaidCloud Tools – Conexão](/pt-br/reference/connectors/).

Depois que todas as contas necessárias estiverem configuradas, selecione a **Conta Google** apropriada na lista suspensa.
#### Planilha

Em seguida, especifique a **Planilha** a ser importada no menu suspenso que contém todos os arquivos disponíveis associados à **Conta Google** especificada.

<Aside>Verifique se a conta de usuário informada tem acesso ao arquivo especificado, especialmente se o arquivo pertencer a outro usuário.</Aside>

### Tipo de cabeçalho

Como as Planilhas Google podem ou não conter cabeçalhos, o PlaidCloud oferece uma forma de usar os cabeçalhos, ignorá-los ou usar a ordem das colunas para determinar o alinhamento delas.
* **Sem cabeçalho**: o arquivo não contém cabeçalho. Use a lista de origem no *Data Mapper* para determinar o alinhamento das colunas
* **Com cabeçalho - usar cabeçalho e substituir lista de campos**: o arquivo tem cabeçalho. Use os nomes de cabeçalho especificados e ignore a lista de origem no *Data Mapper*.
* **Com cabeçalho - ignorar cabeçalho e usar a lista de campos**: o arquivo tem cabeçalho, mas ele deve ser ignorado. Use os nomes de cabeçalho especificados pela lista de origem no *Data Mapper*.

### Planilhas a importar

Como as pastas de trabalho podem conter muitas planilhas com dados diferentes, é possível selecionar quais planilhas devem ser importadas no processo de importação atual. As opções são:

* Todas as planilhas
* Planilhas correspondentes à pesquisa
* Planilhas selecionadas

#### Usando a pesquisa de planilhas

A funcionalidade de pesquisa de planilhas permite incluir as planilhas que correspondem aos critérios de pesquisa. Os critérios de pesquisa permitem:
* **Começa com**: o nome da planilha começa com o texto pesquisado
* **Contém**: o nome da planilha contém o texto pesquisado
* **Termina com**: o nome da planilha termina com o texto pesquisado

#### Localizar abas no arquivo selecionado

O botão de localizar abas abre o arquivo Excel e lista as planilhas disponíveis na tabela. Marque as caixas de seleção na tabela das planilhas a serem incluídas na importação.

<Aside>Ao preencher o *Data Mapper*, é usada a primeira planilha encontrada na lista. Garanta que todas as planilhas incluídas na etapa de importação tenham um formato semelhante.</Aside>
### Cabeçalhos das colunas

<Aside>Devido a limitações técnicas, todas as colunas do Planilhas Google são importadas com o tipo de dados String. Os tipos de dados Boolean, numéricos e/ou de data/hora precisam ser especificados explicitamente no mapeador.</Aside>
