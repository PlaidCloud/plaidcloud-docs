## Descrição


Importa arquivos HDF5 (Hierarchical Data Format versão 5) para tabelas de projeto do PlaidCloud. O HDF5 é comum em computação científica, na troca de dados de aprendizado de máquina e em qualquer cenário em que dados tipados e colunares precisem circular entre ferramentas Python/R/MATLAB.

Consulte a [documentação do HDF Group](http://www.hdfgroup.org/HDF5/) para ver a especificação do formato.

## Itens de configuração exclusivos


### Nome da chave

Os arquivos HDF armazenam dados em uma estrutura de caminhos. É necessária uma chave (caminho) como destino da tabela dentro do arquivo HDF. Na maioria das situações, será *table*.
