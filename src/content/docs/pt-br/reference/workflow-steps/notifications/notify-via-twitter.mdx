## Descrição


Envie uma mensagem direta (DM) do Twitter a partir de [@plaidcloud](https://twitter.com/plaidcloud).



### Conta do Twitter


Especifique a conta do Twitter que receberá a DM de @plaidcloud. Esse usuário precisa estar seguindo @plaidcloud para receber a mensagem. É permitido, embora não obrigatório, prefixar o nome de usuário com o arroba (@).



### Mensagem


Digite a mensagem desejada. O Analyze não aceita um valor com mais de 140 caracteres.


Observação: as variáveis do projeto e as variáveis do fluxo de trabalho estão disponíveis para uso nesta transformação.


<Aside type="danger">Ao usar variáveis, é possível gerar mensagens que excedam o limite de 140 caracteres. Nesse caso, a mensagem NÃO será enviada. Em vez disso, o seguinte erro será gravado no log: *Twitter API returned a 403 (Forbidden), There was an error sending your message: The text of your direct message is over 140 characters.</Aside>

## Exemplos

Neste exemplo, uma DM é enviada de [@PlaidCloud](https://twitter.com/plaidcloud) para [@tartansolutions](https://twitter.com/tartansolutions). Variáveis do sistema são usadas na mensagem. A mensagem final diz *Analyze Demo is running on #PlaidCloud*.
