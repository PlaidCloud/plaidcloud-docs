## Descrição



Envia uma notificação por meio de um POST para a URL de um webhook, o que é útil para acionar ações personalizadas posteriores, alertar plataformas de integração (Zapier, n8n, Make) ou controlar bots do Slack/Teams/Discord que não usam conectores nativos.

O formato da carga e quaisquer cabeçalhos personalizados são configuráveis. O serviço receptor é responsável pelo que acontece em seguida.
