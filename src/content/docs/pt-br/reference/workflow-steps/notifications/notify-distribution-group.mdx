## Descrição



Envia uma notificação por e-mail a um grupo de distribuição do PlaidCloud: uma lista nomeada de destinatários gerenciada nas configurações do espaço de trabalho. É útil para atualizações de status, notificações de conclusão ou alertas de erro que precisam chegar a um público definido.

As mensagens são enviadas pelo serviço de notificações do PlaidCloud. Os grupos de distribuição são gerenciados de forma centralizada, para que os autores de fluxos de trabalho não incluam endereços de e-mail nas definições de fluxo de trabalho.


## Selecionar a lista de distribuição do PlaidCloud


Selecione uma única lista de distribuição no menu suspenso. As listas de distribuição podem ser criadas usando Ferramentas. Para ver detalhes sobre como criar uma lista de distribuição, consulte aqui: [Ferramentas do PlaidCloud – Distro](/pt-br/administration/access/member-management/#gerenciamento-de-listas-de-distribuição-distro).



## Mensagem


Especifique o **Assunto** e o **Corpo** como desejar.



Observação: as variáveis do projeto e as variáveis do fluxo de trabalho estão disponíveis para uso nesta transformação, tanto na linha de assunto quanto no corpo da mensagem.



Além disso, é permitido usar código HTML padrão no corpo para personalizar ainda mais a aparência das mensagens de e-mail.


## Exemplos


Neste exemplo, todas as variáveis do sistema são usadas. Além disso, um pequeno trecho de HTML é usado para formatar a primeira linha do corpo. A execução desta transformação envia o seguinte e-mail a todos os membros especificados no grupo de distribuição:


* DE: [info@tartansolutions.com](mailto:info%40tartansolutions.com) (lembre-se de que todas as mensagens vêm deste endereço)
* Assunto: DEMO Analyze Demo Running


<Aside>Os destinatários individuais da mensagem de e-mail **não** poderão ver os nomes dos outros membros da lista de distribuição.</Aside>
