## Descrição

A etapa **Publish to Tableau** publica um extrato `.hyper` no Tableau Server ou no Tableau Cloud como uma origem de dados. Grave primeiro o extrato com [Tableau Hyper Export (etapa)](/pt-br/reference/workflow-steps/export/export-hyper/) e depois publique-o com esta etapa. A etapa faz login com o token de acesso pessoal de uma [conexão do Tableau](/pt-br/reference/connectors/collaboration/tableau/), envia o arquivo em partes, de modo que o tamanho do arquivo não fica limitado a uma única solicitação, e faz logout.

Um arquivo de extrato ausente não é um erro. A etapa avisa que nada foi publicado e o fluxo de trabalho continua.

## Parâmetros

- **Extrato Hyper** — o arquivo `.hyper` em uma conta de documentos a publicar.
- **Conexão do Tableau** — a conexão do Tableau pela qual publicar.
- **Nome da origem de dados** — o nome da origem de dados no Tableau. Deixe em branco para usar o nome do arquivo do extrato sem a extensão.
- **Projeto** — o projeto do Tableau no qual publicar. Deixe em branco para usar o projeto Default do site. Um nome de projeto que o Tableau não tem no site faz a etapa falhar.
- **Se a origem de dados existir** — o modo de publicação. Consulte [Modos](#modos).
- **Chaves de correspondência** — as colunas que correspondem às linhas, como uma lista separada por vírgulas. Obrigatórias para **Upsert**, **Update** e **Replace Matching Rows**.

## Modos

| Modo | Quando a origem de dados existe | Quando não existe |
| --- | --- | --- |
| **CreateNew** | A etapa falha. | Cria a origem de dados. |
| **Overwrite** | Substitui a origem de dados. | Cria a origem de dados. |
| **Append** | Adiciona a ela as linhas do extrato. | Cria a origem de dados. |
| **Upsert** | Atualiza as linhas cujas chaves de correspondência coincidem e adiciona as demais. | Cria a origem de dados. |
| **Update** | Atualiza as linhas cujas chaves de correspondência coincidem e não adiciona nenhuma. | Emite um aviso e não altera nada. |
| **GroupReplace** | Exclui as linhas cujas chaves de correspondência coincidem e depois insere as linhas do extrato. | Cria a origem de dados. |

**Append**, **Upsert**, **Update** e **GroupReplace** procuram a origem de dados pelo nome no projeto que você escolheu, ou no projeto Default do site quando você não escolheu nenhum, e publicam no projeto em que procuraram. Os modos com chave alteram as linhas da origem de dados no local, por meio das ações de atualização de dados do Tableau.

## Requisitos

- O endereço do servidor da conexão deve usar `https`. Um servidor informado com `http` faz a etapa falhar, porque o token de acesso pessoal trafegaria na rede em texto claro. Um nome de host simples é lido como `https`.
- O servidor deve estar acessível pela internet. O PlaidCloud não publica em um servidor Tableau em uma rede privada.
- O proprietário do token de acesso pessoal precisa de permissão para publicar no projeto.
