## Descrição

Grava as tabelas de projeto selecionadas em uma conta de documentos como Parquet compactado. Em conjunto com [Restaurar tabelas](/pt-br/reference/workflow-steps/import/restore-tables/), move dados de tabelas entre projetos ou espaços de trabalho, ou guarda uma cópia íntegra antes de uma alteração destrutiva.

## Itens de configuração exclusivos

### Tabelas

As tabelas de projeto a arquivar.

### Destino

A conta de documentos e o caminho em que o arquivo é gravado.

### Compactação

- **Snappy** — o mais rápido, com tamanho de arquivo moderado
- **Zstandard** — arquivos menores; exige um leitor com Zstandard 0.8 ou posterior
