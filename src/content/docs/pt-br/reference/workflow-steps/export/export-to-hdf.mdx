## Descrição


Exporte uma tabela de dados do Analyze para o PlaidCloud Document como um arquivo HDF5.


Para saber mais sobre arquivos HDF5, consulte o site oficial do HDF Group: http://www.hdfgroup.org/HDF5/.

<SnippetCommonExportFileSelection />



### Tipo de arquivo de saída


Todos os arquivos exportados não são compactados, mas as seguintes opções de compactação estão disponíveis:


* Zip
* GZip
* BZip2
