## Descrição


Exporte uma tabela de dados do Analyze para o Google Drive como uma planilha Google. É necessária uma conta Google válida para usar esta transformação. As credenciais do usuário devem ser configuradas no PlaidCloud Tools antes de usar a transformação.



## Parâmetros de exportação


### Origem e destino


Selecione a **Tabela de origem** do PlaidCloud Document usando o menu suspenso.



Em seguida, especifique as informações da **Conexão de destino**. Para saber como configurar uma conexão de conta do Google Docs, consulte: [PlaidCloud Tools – Conexão](/pt-br/reference/connectors/). Depois de configurar todas as contas necessárias, selecione a conta apropriada na lista suspensa.



Por fim, informe o **Nome da planilha de destino** e o **Nome da aba de destino**. Se quiser, marque a caixa de seleção **Anexar dados aos dados existentes da aba** para anexar dados a uma aba existente. Se a aba de destino ainda não existir, ela será criada.



Uma planilha que ainda não existe é criada, assim como uma aba ausente. Um **Nome da planilha de destino** que mais de uma planilha da conta possui é recusado; renomeie as duplicatas para que o nome seja exclusivo. Os valores são gravados como digitados, de modo que uma célula de texto que começa com `=` continua sendo texto e não vira uma fórmula. Com **Anexar dados aos dados existentes da aba** desmarcado, a aba é limpa e redimensionada para a tabela antes de as linhas serem gravadas.
