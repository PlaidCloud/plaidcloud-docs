## Descrição

Grava várias tabelas de projeto em planilhas diferentes de uma única pasta de trabalho do Microsoft Excel,
preservando a formatação de um modelo estilizado. Cada tabela preenche uma
planilha nomeada; a pasta de trabalho inteira é criada a partir do modelo uma única vez e renderizada em
uma só passagem, de modo que as planilhas não se sobrescrevem mais, como aconteceria com exportações
separadas de uma só planilha que compartilhassem um arquivo de saída.

Use esta etapa quando uma pasta de trabalho precisar conter mais de uma planilha de resultados,
por exemplo um modelo de relatório formatado com uma planilha de dados, uma de resumo
e uma de parâmetros. Para uma única planilha, ou para uma pasta de trabalho simples sem formatação,
use [Export to Excel](/pt-br/reference/workflow-steps/export/export-to-excel/).

A formatação do modelo é mantida em cada planilha gravada: valores, formatos de número,
fontes, preenchimentos, bordas, células mescladas e larguras de coluna. Um modelo que
contenha tabelas dinâmicas ou gráficos perde esses objetos quando suas planilhas são gravadas;
eles não são reproduzidos pela gravação.

## Parâmetros de exportação

### Arquivo de saída

A conta de documentos e a pasta em que a pasta de trabalho é gravada, junto com o
**Nome do arquivo** da pasta de trabalho.

### Arquivo de modelo

O modelo estilizado a partir do qual a pasta de trabalho é criada: uma conta de documentos e um caminho para
um arquivo `.xlsx` existente cuja formatação cada planilha gravada herda. Quando nenhum
modelo é informado, a etapa parte do arquivo de saída existente, se já houver um.

### Compactação

A pasta de trabalho é gravada sem compactação por padrão. Estão disponíveis as compactações Zip, GZip
ou BZip2.

## Planilhas

Cada entrada da tabela **Planilhas** preenche uma planilha da pasta de trabalho:

| Campo | Finalidade |
| --- | --- |
| Origem | A tabela de projeto que fornece as linhas da planilha. |
| Planilha de destino | A planilha do modelo a preencher. |
| Intervalo | Um intervalo opcional no estilo A1 (por exemplo `A1:S1000000`) cujos valores existentes são apagados antes de a tabela ser gravada, deixando intactas as células do modelo ao redor. |
| Gravar cabeçalho | Se a linha de cabeçalho com os nomes das colunas deve ser gravada. Ativado por padrão. |
| Colunas | As colunas a gravar, em ordem, quando você não quer todas as colunas da tabela de origem. |

Estes campos também estão no formulário:

* **Uma pasta de trabalho existente** (`if_exists`) — **Fazer a etapa falhar sem gravar nada** (`fail`) interrompe a etapa quando a pasta de trabalho já existe. O padrão, **Gravar as planilhas nela** (`replace`), grava nela.
* Em uma entrada de planilha, **Ordenar linhas por** (`sort_columns`) ordena as linhas gravadas por estas colunas de origem, a primeira chave primeiro, cada uma com uma configuração de **Coluna**, **Crescente** e **Nulos**; **Células ausentes como** (`null_as`) é o texto gravado em toda célula ausente da planilha, inclusive nas colunas numéricas; e **Uma planilha existente** (`if_sheet_exists`) decide o que acontece quando a pasta de trabalho já tem a planilha: **Falhar a etapa** (`fail`) interrompe a etapa e **Deixar como está** (`skip`) mantém essa planilha como está.

## Limites de tamanho

Cada planilha está sujeita aos mesmos limites do Excel de uma exportação de planilha única: no máximo
1.048.576 linhas (a linha de cabeçalho conta) e 16.384 colunas. Uma planilha que
ultrapassasse esses limites interrompe a etapa, em vez de produzir um arquivo que o Excel se recusa a abrir.
Para dados além desses tamanhos, exporte para CSV ou Parquet.
