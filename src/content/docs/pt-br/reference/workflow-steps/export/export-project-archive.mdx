## Descrição

Grava um arquivo completo do projeto (fluxos de trabalho, definições de tabelas, dimensões, variáveis e configurações) em uma conta de documentos, como um único arquivo. Use-o para um backup em um ponto no tempo antes de uma grande alteração, ou para entregar um projeto a outro espaço de trabalho.

Isto arquiva o *projeto*, não apenas seus dados. Para os dados de tabelas somente, use [Export to Table Archive](/pt-br/reference/workflow-steps/export/export-to-table-archive/).

## Itens de configuração exclusivos

### Diretório e nome do arquivo de exportação

- **Diretório de exportação** — a conta de documentos e a pasta em que o arquivo é gravado.
- **Arquivo de destino** — o nome do arquivo.
