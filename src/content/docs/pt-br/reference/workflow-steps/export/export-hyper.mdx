## Descrição

A etapa **Tableau Hyper Export** exporta uma tabela para um arquivo Tableau Hyper. Ela é executada no mecanismo de fluxo de trabalho; os resultados de macros empacotadas são uma aproximação da macro do Alteryx.

## Parâmetros

- **Tabela de origem** e o **Arquivo de saída**.

O gravador Tableau Hyper não está disponível no mecanismo de fluxo de trabalho, portanto um CSV é gravado no lugar (uma degradação funcional).
