## Descrição



Grava uma tabela do PlaidCloud em uma conta de documentos como um arquivo compactado nativo do PlaidCloud. O arquivo preserva todos os tipos de coluna, índices e metadados que o PlaidCloud conhece — com fidelidade maior que o CSV para idas e vindas entre projetos ou ambientes do PlaidCloud.

Use-a em conjunto com [Importar arquivo compactado](/pt-br/reference/workflow-steps/import/import-archive/) para trazer o arquivo de volta a um projeto. É útil para backups, migrações de projeto para projeto e transferência de dados entre ambientes.
