## Descrição

Grava tabelas de projeto em um banco de dados externo por meio de uma [conexão](/pt-br/reference/connectors/), em vez de em um arquivo. Use-a para enviar de volta resultados modelados a um banco de dados de relatórios, a um data warehouse ou a um sistema operacional.

É o espelho de [Importar tabelas de banco de dados externo](/pt-br/reference/workflow-steps/import/import-external-database-tables/): várias tabelas são movidas em uma única etapa, e as tabelas de destino podem ser selecionadas explicitamente ou encontradas por um padrão de pesquisa.

## Itens de configuração exclusivos

### Conexão

A conexão de dados que identifica o banco de dados de destino.

### Tipo de exportação

Como cada tabela de destino é preparada antes de as linhas serem gravadas:

- **Somente anexar** — adiciona linhas à tabela existente; falha se ela não existir.
- **Truncar e anexar** — esvazia a tabela, mantém sua estrutura e depois grava.
- **Criar e anexar** — cria a tabela se ela não existir e depois grava.
- **Descartar, criar e anexar** — descarta e recria a tabela e depois grava. Use quando o esquema de origem mudou.

### Nome do frame

O nome do frame sob o qual a etapa é executada.

### Adicionando destinos

Use o botão de adicionar e remover destino para montar a lista de tabelas de destino. Selecione um destino para configurá-lo no painel direito e use **Alternar selecionados** para ativar ou desativar a exportação dos destinos selecionados. A exportação não varre o banco de dados de destino em busca de tabelas; adicione cada destino você mesmo. [Importar tabelas de banco de dados externo](/pt-br/reference/workflow-steps/import/import-external-database-tables/) é a etapa para descobrir tabelas em um banco de dados externo.

### Guias do destino

Um destino selecionado tem três guias.

#### Origem e destino

Escolha as tabelas de projeto a exportar e onde elas são gravadas.

- **Origem** — **Tabela específica** indica uma tabela de projeto, com uma opção **Dinâmico** para um nome que muda em tempo de execução. **Tabelas correspondentes à pesquisa** exporta todas as tabelas de projeto encontradas por um **Caminho de pesquisa** e um **Texto da pesquisa**, com correspondência **Exata**, **Começa com**, **Contém** ou **Termina com**.
- **Tabela externa de destino** — **Ativar para exportação** liga ou desliga o destino. **Esquema de destino** e **Tabela de destino** indicam a tabela de destino. **Usar o mesmo nome da tabela de origem** reutiliza o nome de cada tabela de origem.

#### Seleção de dados da tabela

O mapeador de colunas do destino, em uma guia própria de altura total. **Inspecionar origem** lê as colunas da tabela de origem do projeto para o mapeador.

#### Filtros de dados

Filtre as linhas gravadas no destino.
