## Descrição



Envia uma tabela do PlaidCloud para um banco de dados do Quandl (NASDAQ Data Link). Destina-se principalmente a organizações que mantêm conjuntos de dados publicados no Quandl e querem atualizá-los a partir de um fluxo de trabalho do PlaidCloud.

Exige credenciais da API do Quandl e um banco de dados de destino configurado com acesso de gravação no lado do Quandl.


## Origem e destino


Especifique os seguintes parâmetros:


* **Tabela de origem**: tabela de dados do Analyze a exportar
* **Conexão do Quandl**: acessar conjuntos de dados do Quandl exige uma conta de usuário ou uma conta de convidado com acesso limitado. Isso requer configuração em Ferramentas. Para detalhes sobre como configurar uma conexão de conta do Quandl, consulte: [Ferramentas do PlaidCloud – Conexão](/pt-br/reference/connectors/)
* **Código do Quandl**: use o botão **Pesquisar** para procurar conjuntos de dados. Como alternativa, os conjuntos de dados podem ser informados manualmente. Isso exige que o usuário informe a parte do URL que vem depois de “[http://www.quandl.com](http://www.quandl.com/)”. Por exemplo, para importar o conjunto de dados das ações da Microsoft, encontrado em (http://www.quandl.com/GOOG/NASDAQ_MSFT), informe *GOOG/NASDAQ_MSFT* no campo Código do Quandl
* **Nome do conjunto de dados**: nome do conjunto de dados a exportar para o Quandl
* **Descrição do conjunto de dados**: descrição do conjunto de dados a exportar para o Quandl
