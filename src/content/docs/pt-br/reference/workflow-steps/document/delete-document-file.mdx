## Descrição


Exclui um arquivo existente no PlaidCloud Document.



## Arquivo a excluir


Primeiro, selecione a conta apropriada no menu suspenso.


Em seguida, clique no botão **Procurar** para selecionar o arquivo a ser excluído.

<Aside>Se o arquivo não existir (já foi excluído), nenhuma ação é executada.</Aside>
