## Descrição

Grava uma tabela com a lista dos arquivos de um diretório de documentos. Use-a para conduzir etapas seguintes com base nos arquivos presentes, por exemplo, para percorrer todos os arquivos de uma pasta ou verificar o que um processo anterior entregou.

## Diretório

Selecione uma conta de documentos e clique no botão **Procurar** para escolher a pasta a ser listada.

## Opções

- **Padrão de arquivo** *(opcional)* — um glob, como `*.csv`, para listar somente os arquivos correspondentes. Deixe em branco para listar tudo.
- **Incluir subdiretórios** — quando marcado, os arquivos de pastas aninhadas também são listados.
- **Tabela de destino** — a tabela que recebe a listagem.

## Configurações adicionais

As opções de **Quais arquivos** restringem a listagem:

- **Listar também as pastas, com uma coluna IsFolder** (`include_folders`) — lista também as pastas, como linhas. Cada linha passa a ter uma coluna final `IsFolder`, verdadeira para uma pasta.
- **Listar primeiro o próprio diretório** (`include_root_folder`) — com `include_folders`, lista também o próprio diretório, em primeiro lugar.
- **Padrão do nome de arquivo** (`file_name_filter`) — somente arquivos cujo nome corresponda. O **Tipo de padrão** é **Curinga** ou **Expressão regular** (`type`), e **Diferenciar maiúsculas e minúsculas** define `case_sensitive`.
- **Padrão do nome de pasta** (`folder_name_filter`) — somente entradas em pastas cujos nomes correspondam, no mesmo formato; todas as pastas no caminho até a entrada devem corresponder.
- **Extensões** (`extensions`) — somente arquivos com uma destas extensões, sem o ponto. **Diferenciar maiúsculas e minúsculas da extensão** (`extensions_case_sensitive`) faz a correspondência respeitando maiúsculas e minúsculas.
- **Incluir arquivos ocultos (nome que começa com ponto)** (`include_hidden_files`) e **Incluir pastas ocultas e o que estiver abaixo delas** (`include_hidden_folders`) — desmarque qualquer uma para deixar de fora arquivos ou pastas cujo nome comece com ponto.
