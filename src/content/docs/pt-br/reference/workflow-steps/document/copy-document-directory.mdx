## Descrição


Copia um diretório inteiro dentro do PlaidCloud Document.



## Copiar diretório


Primeiro, selecione a conta apropriada no menu suspenso.



Em seguida, pressione o botão **Procurar** para selecionar o diretório que você quer copiar.



## Selecionar destino


Primeiro, selecione a conta apropriada no menu suspenso.



Em seguida, pressione o botão **Procurar** para selecionar o destino do diretório copiado.



Se desejar, o diretório copiado pode receber um novo nome. Para isso, basta marcar a caixa **Rename the Copied Folder to:** e digitar um novo nome.


<Aside>O comportamento padrão é sobrescrever qualquer item que já exista. Tome cuidado para não sobrescrever por engano.</Aside>
