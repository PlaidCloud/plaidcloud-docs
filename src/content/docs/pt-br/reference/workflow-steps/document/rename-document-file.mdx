## Descrição


Renomeia um arquivo existente no PlaidCloud Document.



## Arquivo a renomear


Primeiro, selecione a conta apropriada no menu suspenso.



Em seguida, clique no botão **Procurar** para selecionar o arquivo a ser renomeado.

<Aside>Se o arquivo renomeado já existir, nenhuma ação é executada.</Aside>


## Renomear para


Digite o novo nome do arquivo.
