## Descrição


Renomeia um diretório existente no PlaidCloud Document.



## Pasta a renomear


Primeiro, selecione a conta apropriada no menu suspenso.



Em seguida, clique no botão **Procurar** para selecionar o diretório a ser renomeado.



## Renomear para


Digite o novo nome do diretório.


<Aside>Se o diretório renomeado já existir, nenhuma ação é executada.</Aside>
