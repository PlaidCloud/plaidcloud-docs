## Descrição


Cria um novo diretório dentro do PlaidCloud Document.



## Onde criar a nova pasta


Primeiro, selecione a conta apropriada no menu suspenso.



Em seguida, pressione o botão **Procurar** para selecionar o diretório pai.



## Nome da nova pasta


Digite o nome do novo diretório.


<Aside>Se o diretório já existir, nenhuma ação é tomada.</Aside>
