Treine um modelo em qualquer tabela, leve-o pelo fluxo de trabalho como uma tabela de modelo e pontue tabelas de dados com ele.

## Etapas

- [ML: Treinar modelo](/pt-br/reference/workflow-steps/machine-learning/ml-train/) — ajuste um modelo scikit-learn (classificação ou regressão) em uma tabela de origem e grave uma tabela de modelo consultável com o modelo ajustado, os parâmetros, a lista de features e as métricas de treinamento.
- [ML: Pontuar](/pt-br/reference/workflow-steps/machine-learning/ml-score/) — pontue uma tabela de dados com uma tabela de modelo treinado e acrescente uma coluna de previsão.

Veja [Migrar fluxos de trabalho do Alteryx](/pt-br/guides/workflows/migrate-alteryx-workflows/#conversões-de-aprendizado-de-máquina-assisted-modeling) para saber como os pipelines de Assisted Modeling do Alteryx são convertidos nestas etapas.
