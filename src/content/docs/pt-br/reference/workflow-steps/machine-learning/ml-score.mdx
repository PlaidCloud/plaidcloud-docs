## Descrição

A etapa **ML: Pontuar** pontua uma tabela de dados com um modelo treinado por [ML: Treinar modelo](/pt-br/reference/workflow-steps/machine-learning/ml-train/) e grava os dados com uma coluna de previsão acrescentada. Como o modelo chega como uma tabela comum, você pode treinar uma vez e pontuar várias tabelas, ou pontuar novamente sempre que novos dados chegarem. A etapa é executada como um job gerenciado do PlaidCloud (como a etapa de LLM).

## Guia de pontuação

- **Tabela de dados** — a tabela a ser pontuada. Ela deve conter todas as colunas de features com as quais o modelo foi treinado.
- **Tabela de modelo** — uma tabela de modelo gravada por uma etapa ML: Treinar modelo. A etapa falha se a tabela estiver vazia ou se qualquer parte do modelo armazenado estiver ausente.
- **Tabela de saída** — onde os dados pontuados são gravados.
- **Coluna de previsão** — o nome da coluna acrescentada. Deixe em branco para usar `prediction`. A etapa falha se o nome já existir na tabela de dados.

## Saída

A tabela de saída contém todas as colunas da tabela de dados mais a coluna de previsão: rótulos de classe em texto para classificadores, valores numéricos para regressores. Os valores das features são preparados exatamente como no momento do treinamento, e os valores categóricos que o modelo nunca viu durante o treinamento são ignorados em vez de causar um erro.

A tabela de modelo deve ter a estrutura que uma etapa ML: Treinar modelo grava — o conjunto completo de colunas do modelo, um algoritmo conhecido e todas as partes do modelo armazenado presentes. O próprio modelo é carregado sob uma restrição que rejeita qualquer coisa fora da pilha científica padrão, de modo que uma linha de modelo criada manualmente não pode executar código arbitrário.

### Mais colunas de saída

A seção **Opções de pontuação** tem estes campos. Os fluxos de trabalho do KNIME convertidos também os usam.

- **Colunas de probabilidade de classe** (`probability_column_template`) — para um classificador, acrescenta uma coluna de probabilidade por classe, nomeada por este modelo com `{class}` substituído. **Probabilidades antes da previsão** (`probabilities_first`) as coloca antes da coluna de previsão, e **Ordenar as classes conforme aparecem pela primeira vez no treinamento** (`classes_in_domain_order`) as ordena pela ordem em que as classes aparecem pela primeira vez nos dados de treinamento, em vez de em ordem alfabética.
- **Coluna de confiança** (`confidence_column`) — para um classificador, acrescenta a probabilidade da classe vencedora com este nome.
- **Coluna de variância** (`variance_column`) — para um regressor de floresta, acrescenta a variância das previsões das árvores com este nome.
- **Coluna de contagem de modelos** (`model_count_column`) — para um modelo de árvore, acrescenta o número de árvores com este nome.
- **Ordem das colunas acrescentadas** (`column_order`) — a ordem das colunas acrescentadas. Em branco: previsão, probabilidades, confiança, variância e, por fim, contagem de modelos.
- **Gravar em vez disso** (`report`) — grava uma das próprias tabelas do modelo em vez dos dados pontuados, como `variable_importance`, `coefficients`, `statistics`, `pmml` (o modelo como um documento PMML), `centers`, `cluster_counts` ou `association_rules`.
- **Formato do modelo** (`model_format`) — `pmml` pontua com um documento PMML: a tabela de modelo contém o documento, ou o modelo de um learner que tem uma forma PMML.
- **Configurações do algoritmo** (`algorithm_settings`) — configurações da pontuação ou do relatório específicas do algoritmo do modelo, como o número de componentes para os quais um modelo `pca` projeta.
- **Terceira tabela** (`source_c`) — uma terceira tabela que alguns algoritmos leem, como a floresta aleatória que um modelo `knn_distance` usa.

Um assistente de IA ou a API REST também pode definir `report` como `shap_values`.

## Limites e ressalvas

- **Conjunto de trabalho em memória** — a tabela de dados é lida para a memória, portanto a etapa visa a cerca de um milhão de linhas por execução.
- **Fluxos de trabalho do Alteryx convertidos** — uma ferramenta Predict convertida fixa a coluna de previsão ao nome da variável de destino com o sufixo `_predicted`.
