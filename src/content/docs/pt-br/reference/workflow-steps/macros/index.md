Etapas de fluxo de trabalho que reproduzem as *macros empacotadas* do Alteryx, ou seja, as macros que acompanham o Alteryx, e não aquelas que você mesmo cria. Cada uma é executada no mecanismo de fluxos de trabalho, e seu resultado é uma aproximação da macro do Alteryx.

Elas são diferentes das [macros do PlaidCloud](/pt-br/reference/workflow-steps/workflow-control/run-macro/), que são sequências reutilizáveis de etapas que você mesmo cria.
