## Descrição

A etapa **Create Samples (macro)** reproduz a macro empacotada *Create Samples* do Alteryx. Ela é executada no mecanismo de fluxos de trabalho; os resultados das macros empacotadas são uma aproximação da macro do Alteryx.

## Parâmetros

- **Origem / Tabelas de saída**.
- **Estimation %** e **Semente aleatória**.
