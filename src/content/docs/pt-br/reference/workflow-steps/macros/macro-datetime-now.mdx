## Descrição

A etapa **DateTime Now (macro)** reproduz a macro empacotada *DateTime Now* do Alteryx. Ela é executada no mecanismo de fluxos de trabalho; os resultados das macros empacotadas são uma aproximação da macro do Alteryx.

## Parâmetros

- **Tabela de saída** e a string de **Formato de saída**.

## Formato de saída

A string de formato usa os tokens da ferramenta DateTime do Alteryx, e a conversão os mantém como foram escritos. Se ficar em branco, usa o padrão da própria ferramenta, `day, dd Month, yyyy`, por exemplo `Tuesday, 04 August, 2026`.

| Token | Resultado |
| --- | --- |
| `yyyy` / `yy` | Ano com quatro ou dois dígitos |
| `Month` / `Mon` | Nome do mês por extenso ou abreviado |
| `MM` / `M` | Número do mês, com ou sem zero à esquerda |
| `day` / `dy` | Nome do dia da semana por extenso ou abreviado |
| `dd` / `d` | Dia do mês, com ou sem zero à esquerda |
| `HH` / `H` | Hora em formato de 24 horas, com ou sem zero à esquerda |
| `hh` / `h` | Hora em formato de 12 horas, com ou sem zero à esquerda |
| `mm` | Minutos |
| `ss` | Segundos |
| `tt` | AM ou PM |

Os tokens diferenciam maiúsculas de minúsculas: `MM` é o mês, `mm` é o minuto.
