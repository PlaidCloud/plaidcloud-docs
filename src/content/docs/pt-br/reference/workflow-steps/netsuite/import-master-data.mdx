## Descrição

Importa uma lista de dados mestres do NetSuite, por meio da sua [conexão do NetSuite](/pt-br/guides/connections/netsuite/), para uma tabela de projeto. Escolha um tipo de registro (contas, subsidiárias, departamentos, classes, locais, fornecedores ou clientes) e a etapa busca a lista e a grava, sem SuiteQL para escrever ou manter.

Os dados mestres são os dados de referência para os quais as extrações de saldos e de detalhes apontam: as contas, subsidiárias e dimensões que suas linhas do razão geral trazem como IDs internos. Importe a lista de que você precisa para resolver esses IDs internos em nomes ou para alimentar pesquisas e junções posteriores. Esta é uma das [etapas de importação do NetSuite](/pt-br/reference/workflow-steps/netsuite/) prontas, que são executadas sobre uma camada de leitura compartilhada que renova o token OAuth, percorre resultados grandes página por página e tenta novamente em caso de erros transitórios.

## Configuração

| Campo | Obrigatório | Observações |
|---|---|---|
| Conexão do NetSuite | Sim | A conexão do NetSuite pela qual ler, filtrada para conexões do tipo NetSuite. |
| Tabela de destino | Sim | A tabela de projeto na qual a lista é gravada. Ela é totalmente sobrescrita a cada execução. |
| Tipo de registro | Sim | Qual lista mestra extrair: **conta** (o padrão), **subsidiária**, **departamento**, **classe**, **local**, **fornecedor** ou **cliente**. |
| Incluir inativos | Não | Desativado por padrão, retornando apenas registros ativos. Ative para incluir registros marcados como inativos no NetSuite. |

<Aside type="note">
Use esta etapa para criar as pequenas tabelas de referência de que as outras etapas do NetSuite dependem. Por exemplo, extraia **subsidiária** uma vez para mapear o ID interno de uma subsidiária ao seu nome antes de restringir uma extração de [Importar saldos](/pt-br/reference/workflow-steps/netsuite/import-balances/) ou [Importar detalhes do razão geral](/pt-br/reference/workflow-steps/netsuite/import-gl-detail/) a uma única subsidiária.
</Aside>
