## Descrição

Importa o detalhe das linhas de transação do razão geral do NetSuite, por meio da sua [conexão do NetSuite](/pt-br/guides/connections/netsuite/), para uma tabela de projeto: as linhas de lançamento por trás dos seus saldos, para conciliação, detalhamento ou uma DRE detalhada. Escolha a conexão, dê um nome à tabela de destino e defina o período e a subsidiária; a etapa busca as linhas e as grava, sem SuiteQL para escrever ou manter.

Esta é uma das [etapas de importação do NetSuite](/pt-br/reference/workflow-steps/netsuite/) prontas. Todas são executadas sobre uma camada de leitura compartilhada que renova o token OAuth, percorre resultados grandes página por página e tenta novamente em caso de erros transitórios, de modo que uma extração de um período inteiro volta completa, sem ajustes manuais. Para saldos por período em vez de linhas, use [NetSuite: Importar saldos](/pt-br/reference/workflow-steps/netsuite/import-balances/).

## Configuração

| Campo | Obrigatório | Observações |
|---|---|---|
| Conexão do NetSuite | Sim | A conexão do NetSuite pela qual ler, filtrada para conexões do tipo NetSuite. |
| Tabela de destino | Sim | A tabela de projeto na qual as linhas de transação são gravadas. Ela é totalmente sobrescrita a cada execução. |
| Data inicial | Não | A primeira data de transação a incluir, `YYYY-MM-DD`, inclusive. Deixe em branco para não ter limite inferior. Quando informada junto com a Data final, a extração é dividida automaticamente em janelas de datas para ficar abaixo do limite de linhas do SuiteQL do NetSuite; veja o aviso abaixo. |
| Data final | Não | A última data de transação a incluir, `YYYY-MM-DD`, inclusive. Deixe em branco para não ter limite superior. |
| Subsidiária | Não | O ID interno de uma subsidiária do NetSuite para restringir a extração a uma única subsidiária. Deixe em branco para incluir todas as subsidiárias. |
| Livro contábil | Não | O ID interno de um livro contábil do NetSuite. Deixe em branco para extrair **somente o livro principal (ID interno 1)**, ou digite `all` para somar todos os livros. |
| Número da conta | Não | Um número exato de conta do razão geral para restringir a extração a uma única conta. Deixe em branco para incluir todas as contas. |
| Período de lançamento | Não | O ID interno de um período contábil/de lançamento do NetSuite. Deixe em branco para incluir todos os períodos. |

<Aside type="caution">
**Contas com vários livros:** uma conta do NetSuite que usa o Multi-Book Accounting lança uma linha por livro para cada linha de transação; por isso, extrair todos os livros sem filtro conta o total N vezes. Deixar o Livro contábil em branco extrai **somente o livro principal**. Defina como `all` somente se quiser deliberadamente um total entre livros, ou como o ID interno de um livro específico para obter apenas esse livro.
</Aside>

<Aside type="note">
Limite o período à fatia de que você precisa. Cada execução substitui toda a tabela de destino, então uma extração agendada reextrai o resultado completo a cada vez; uma janela de datas móvel mantém rápida uma extração recorrente do razão geral, em vez de reler todo o histórico.
</Aside>

<Aside type="note">
A API SuiteQL do NetSuite limita uma única consulta a cerca de 100.000 linhas sem o SuiteAnalytics Connect. Informar a Data inicial e a Data final permite que o PlaidCloud divida a extração de forma proativa em janelas que ficam abaixo desse limite. O detalhe do razão geral é a extração com maior probabilidade de se aproximar dele, então isso importa mais aqui do que em Importar saldos. Uma extração **sem intervalo definido** que acabe ultrapassando o limite falha com uma mensagem pedindo que você adicione um intervalo de datas, em vez de retornar silenciosamente um resultado truncado.
</Aside>
