## Descrição

A etapa **PDF Text Extract** extrai texto de documentos PDF. É o equivalente da ferramenta correspondente do Alteryx e é executada no mecanismo do fluxo de trabalho (as bibliotecas de ML, PLN e documentos são executadas no job executor).

## Origem e opções

- **Origem / Tabelas de saída** — os dados de entrada e o local onde o resultado é gravado.
- **PDF path column** (ou um **diretório** de PDFs).

## Colunas

A guia **Colunas** mapeia as colunas de entrada repassadas para a saída.
