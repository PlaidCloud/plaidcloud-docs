## Descrição

A etapa **Documento: Ler blob** lê documentos inteiros em uma coluna de texto base64 chamada `Blob`, com uma linha por documento. Leia um documento de sua escolha ou um documento para cada linha de uma tabela de caminhos. Etapas posteriores, como [Image OCR](/pt-br/reference/workflow-steps/text-documents/image-ocr/) e [Text NLP AI](/pt-br/reference/workflow-steps/text-documents/nlp-ai/), leem o conteúdo.

## Origem e opções

- **Tabela de caminhos de documentos** *(opcional)* — defina-a para ler um documento para cada linha. Deixe em branco para ler o único documento que você escolher.
- **Coluna de caminho** — a coluna dessa tabela que contém o caminho de cada documento.
- **Documento** — a conta de documentos e o caminho a ler quando não há tabela.
- **Falhar quando um documento estiver ausente** — desativado por padrão. Desativado, um documento ausente é ignorado com um aviso que indica seu caminho, e um único documento ausente grava uma tabela vazia. Ativado, a etapa falha.
- **Maior documento (bytes)** *(opcional)* — um documento maior falha em vez de ser dividido.
- **Tabela de saída** — onde as linhas são gravadas.

As colunas da tabela de caminhos passam para a saída.

O grupo **Mais opções** define estas chaves:

- **Manter a linha de um documento ausente, com um blob vazio** (`keep_missing`) — mantém a linha de um documento ausente, com um `Blob` vazio, em vez de ignorá-la.
- **Ler o documento como um arquivo, uma linha por entrada** (`unpack_enabled`) — com um único documento escolhido e sem tabela de caminhos, lê o documento como um arquivo compactado (zip, jar, tar, tar.gz, tar.bz2, cpio, ar, ou um único arquivo `gz` ou `bz2`) e grava uma linha por entrada: `Path` (abaixo da **Pasta das entradas**, `unpack_destination`), `Directory`, `Status` (`Extracted` ou `Folder`) e `Blob` (nenhum para uma pasta). **Codificação dos nomes de entrada** (`unpack_charset`, padrão `cp437`) é a codificação dos nomes de entrada zip que não estão em UTF-8. Um documento ausente não gera linhas.

Para gravar blobs de volta em documentos, use [Documento: gravar Blob](/pt-br/reference/workflow-steps/text-documents/document-blob-write/).
