## Descrição

Extrai o conteúdo de texto de um PDF para uma tabela. É o equivalente da ferramenta *PDF to Text* do Alteryx e é executada no mecanismo do fluxo de trabalho, onde ficam as bibliotecas de documentos.

Use-a para colocar o conteúdo dos PDFs em uma forma que o restante de um fluxo de trabalho possa filtrar, analisar e juntar. Para extração por página e com reconhecimento de layout, use [PDF Text Extract](/pt-br/reference/workflow-steps/text-documents/document-pdf-extract/).

## Origem e opções

- **Tabela de origem** / **Tabela de saída** — a tabela que nomeia os PDFs e o local onde o texto extraído é gravado.
- **Colunas** — as colunas de origem a repassar para a saída.
