Etapas de fluxo de trabalho que leem dados do Salesforce por meio da sua [conexão do Salesforce](/pt-br/guides/connections/salesforce/). A lista de objetos, a lista de campos e o tipo de cada coluna vêm dos metadados da própria organização, portanto não há consulta a escrever nem tipo a adivinhar.

## Etapas

- [Salesforce: Consultar objeto](/pt-br/reference/workflow-steps/salesforce/query-salesforce-object/) — extrai um objeto padrão ou personalizado para uma tabela de projeto pela Bulk API 2.0, filtrado no Salesforce.
