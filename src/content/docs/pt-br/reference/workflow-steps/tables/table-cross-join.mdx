## Descrição


Use esta etapa para executar uma junção cruzada em 2 tabelas de dados, combinando-as em uma única tabela de dados sem chaves de junção.


Um filtro de origem em qualquer uma das tabelas é aplicado antes de o tamanho da junção ser calculado, de modo que uma junção cruzada filtrada sobre tabelas grandes é executada quando as linhas filtradas são poucas o suficiente.

Para mais detalhes sobre a metodologia da junção cruzada, consulte: [Wikipedia SQL Cross Join](https://en.wikipedia.org/wiki/Join_%28SQL%29#Cross_join)

## Colunas nomeadas durante a execução

Marque **Levar também colunas nomeadas durante a execução** para passar sem alteração todas as colunas de origem que a etapa não lista, como a tabela as tem quando a etapa é executada. Use essa opção quando uma etapa anterior cria colunas cujos nomes dependem dos dados, como em um pivô, e por isso você não pode listá-las ao criar a etapa. Deixe-a desmarcada para gravar somente as colunas que você listar.
