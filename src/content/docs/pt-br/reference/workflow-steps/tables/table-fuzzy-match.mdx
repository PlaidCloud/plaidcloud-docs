## Descrição

A etapa **Fuzzy Match** emparelha linhas de duas tabelas (ou remove duplicatas de uma) por correspondências aproximadas de campos. Ela é executada no mecanismo de fluxos de trabalho; os resultados da macro empacotada são uma aproximação da macro do Alteryx.

## Parâmetros

- **Left / Right Tables** e a **Tabela de saída**.
- **Coluna de ID do registro**, **Limite** (0-100) e **Emitir também as linhas sem correspondência**.
- **Campos de correspondência** — os campos a comparar e a função de correspondência de cada um (exact / jaro / levenshtein / bestof / jaro_tfidf / bestof_tfidf).
