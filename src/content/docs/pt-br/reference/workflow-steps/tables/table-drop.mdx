## Descrição

Remove uma tabela do projeto por completo — tanto a definição da tabela quanto todos os seus dados. Essa ação é destrutiva e irreversível; depois que o fluxo de trabalho é executado, a tabela deixa de existir.

Use esta etapa quando as tabelas intermediárias de um fluxo de trabalho não forem mais necessárias adiante (por exemplo, na limpeza após uma transformação em várias etapas). Para esvaziar temporariamente uma tabela sem removê-la, use [Table Clear (etapa)](/pt-br/reference/workflow-steps/tables/table-clear/).
