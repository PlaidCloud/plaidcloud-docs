## Descrição


Usada para converter tabelas de dados longas e estreitas em tabelas de dados curtas e largas. As colunas selecionadas são transpostas, com os nomes das colunas convertidos em valores em várias colunas.


Talvez o exemplo mais fácil de entender seja pensar em uma tabela de dados com meses listados como linhas:





Fazer o pivô dessa tabela de dados converteria todas as linhas de meses em colunas.

### Seleção de colunas do pivô

A **Coluna de categoria a transformar em cabeçalhos de coluna** é onde você especifica a coluna da Tabela de origem que será pivotada em linhas.
A **Coluna de valor a pivotar em valores de coluna** é a coluna que contém os valores na Tabela de origem.
A **Opção de agregação de valores** é onde você especifica como deseja agregar os dados.

As duas colunas devem estar entre as colunas de saída da etapa na guia **Seleção de dados da tabela**. Caso contrário, o salvamento é recusado, por exemplo com *The category column 'month' isn't one of the step's output columns.*


O formulário também tem estes campos:

* **Coluna com a posição de cada categoria** (`column_order`) — uma coluna de origem com a posição de cada categoria. As colunas pivotadas vêm em ordem crescente dela, em vez de ordenadas por nome. Ela não é usada para agrupar nem é gravada.
* **Modelo de nome das colunas dinâmicas** (`column_name_template`) — nomeia cada coluna pivotada por este texto, com `{value}` substituído pelo valor da categoria, como `{value}+Sum`.

## Seleção de dados da tabela

![Table Pivot Data Selection](/images/table_pivot_2.png)


A guia Seleção de dados da tabela é usada para mapear colunas da tabela de dados de origem para a tabela de dados de destino. Todas as colunas de origem no lado esquerdo da janela são mapeadas automaticamente para a tabela de dados de destino exibida no lado direito da janela. Usando o botão de menu **Inspecionar origem**, há algumas outras formas de mapear colunas da origem para o destino:


* Preencher ambas as tabelas de mapeamento: propaga todos os valores da tabela de dados de origem para a tabela de dados de destino. Este é o padrão.
* Preencher somente a tabela de mapeamento de origem: mapeia somente todos os valores da tabela de dados de origem. Isso é útil ao modificar um fluxo de trabalho existente quando a estrutura de colunas de origem mudou.
* Preencher somente a tabela de mapeamento de destino: propaga todos os valores somente para a tabela de dados de destino.

Além de cada uma dessas opções, cada escolha oferece a possibilidade de visualizar os dados de origem.

Salvar com uma tabela de origem escolhida, mas sem colunas de origem ou sem colunas de destino, preenche o lado vazio a partir da origem, como **Preencher ambas as tabelas de mapeamento** faria.



Se as opções de colunas de origem e de destino não forem suficientes, outras colunas podem ser adicionadas à tabela de dados de destino de várias maneiras:


* **Propagar tudo** insere todas as colunas de origem na tabela de dados de destino, quer já existissem ou não.
* **Propagar selecionadas** insere somente as colunas de origem selecionadas.
* Clique com o botão direito no lado do destino e selecione **Inserir linha** para inserir uma linha imediatamente acima da linha selecionada.
* Clique com o botão direito no lado do destino e selecione **Anexar linha** para inserir uma linha na parte inferior (extrema direita) da tabela de dados de destino.


<Aside type="danger">Selecionar **Propagar tudo** pode criar, na prática, uma duplicata de cada coluna. O Analyze não verifica se as colunas já estão mapeadas. Certifique-se de que não existam nomes de colunas duplicados.</Aside>




Para excluir colunas da tabela de dados de destino, selecione as colunas desejadas, clique com o botão direito e selecione **Excluir**.



Para reorganizar as colunas na tabela de dados de destino, selecione as colunas desejadas, clique com o botão direito e selecione **Mover para o início**, **Mover para cima**, **Mover para baixo** ou **Mover para o final**.



Para retornar somente opções distintas, selecione a opção de menu **Distintos**. Isso exibe um conjunto de caixas de seleção para cada coluna da origem. Basta marcar a caixa ao lado da coluna correspondente para retornar somente resultados distintos.

<Aside type="danger">Quando a tabela de dados de destino contém somente um subconjunto da tabela de dados de origem, marque a caixa de seleção somente ao lado das colunas que **devem** ser incluídas na tabela de dados de destino. Marcar todas as caixas de seleção pode produzir uma saída que não parece ser distinta.</Aside>




Para agregar resultados, selecione a opção de menu **Resumir**. Isso exibe um conjunto de listas suspensas para cada coluna da tabela de dados de destino. As seguintes opções de resumo estão disponíveis:


* Agrupar por (definido como padrão)
* Soma
* Mínimo
* Máximo
* Primeiro
* Último
* Contagem

* Mediana
* Moda

## Filtros de dados


Para dar o máximo de flexibilidade, há filtros de dados disponíveis para os dados de origem e de destino. Para conjuntos de dados maiores, pode ser especialmente vantajoso filtrar linhas na origem para que as demais operações sejam executadas em um conjunto de dados menor.



### Selecionar subconjunto de dados


Qualquer expressão Python válida é aceita para criar o subconjunto dos dados. Consulte [Expressões](/pt-br/reference/expressions/)


para mais detalhes e exemplos.






### Aplicar filtro secundário aos dados do resultado


Qualquer expressão Python válida é aceita para criar o subconjunto dos dados. Consulte [Expressões](/pt-br/reference/expressions/) para mais detalhes e exemplos



### Fatiamento final da tabela de dados (limite)


Para limitar os dados, basta marcar a caixa **Aplicar fatiador de linhas** e especificar o seguinte:


* **Linhas iniciais a ignorar:** linhas de dados a ignorar (a linha de cabeçalho das colunas não entra na contagem)
* **Terminar na linha:** última linha de dados a incluir. Isso é diferente de simplesmente contar linhas no final para descartá-las
