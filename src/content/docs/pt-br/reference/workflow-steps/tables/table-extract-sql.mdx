## Descrição

Preenche uma tabela de destino a partir de um `SELECT` SQL que você mesmo escreve. Enquanto [Table Extract (etapa)](/pt-br/reference/workflow-steps/tables/table-extract/) monta a consulta a partir de colunas e expressões mapeadas, esta etapa entrega a consulta diretamente ao data warehouse — para os casos em que o SQL é mais fácil de expressar diretamente do que de montar no mapeador.

Recorra a ela quando precisar de uma construção que o mapeador não cobre: uma CTE recursiva, uma função de janela sobre uma partição que o mapeador não consegue descrever ou uma consulta sobre várias tabelas que uma etapa de junção tornaria mais complicada.

## Itens de configuração exclusivos

### Consulta SQL SELECT

O texto da consulta. Formate-o como SQL legível, em várias linhas e com indentação — uma coluna ou cláusula por linha — em vez de uma única linha longa; a etapa preserva o que você escreve, e a próxima pessoa que abrir a etapa precisará lê-lo.

A consulta é executada no lakehouse do projeto, então as funções disponíveis são as do conjunto [Lakehouse v1](/pt-br/reference/expressions/lakehouse-v1/) ou [v2](/pt-br/reference/expressions/lakehouse-v2/), dependendo do espaço de trabalho.
