## Descrição

Preenche uma tabela de destino a partir de um `SELECT` SQL que você mesmo escreve. Enquanto a [etapa Table Extract](/pt-br/reference/workflow-steps/tables/table-extract/) monta a consulta a partir de colunas e expressões mapeadas, esta etapa entrega a consulta diretamente ao data warehouse, para os casos em que o SQL é mais fácil de expressar diretamente do que de montar no mapeador.

Recorra a ela quando precisar de uma construção que o mapeador não cobre: uma CTE recursiva, uma função de janela sobre uma partição que o mapeador não consegue descrever ou uma consulta em várias tabelas que uma etapa de junção tornaria mais complicada.

## Itens de configuração exclusivos

### Consulta SQL SELECT

O texto da consulta. Formate-o como SQL legível, em várias linhas e com recuo, uma coluna ou cláusula por linha, em vez de uma única linha longa; a etapa preserva o que você escreve e a próxima pessoa que a abrir terá de lê-lo.

A consulta é executada no Lakehouse do projeto, então as funções disponíveis são o conjunto do [Lakehouse v1](/pt-br/reference/expressions/lakehouse-v1/) ou do [v2](/pt-br/reference/expressions/lakehouse-v2/), dependendo do espaço de trabalho.

<SnippetCommonStepPreview />

Ao contrário das outras etapas SQL, esta etapa não preenche variáveis, então a pré-visualização dela também não.
