## Descrição


Se você usa regularmente a função PROCV (vlookup) do Microsoft Excel, a transformação Table Lookup vai parecer bem familiar. Ela é usada para executar essencialmente a mesma função. Ao contrário da versão do Microsoft Excel, a transformação Table Lookup do PlaidCloud Analyze oferece maior flexibilidade, permitindo especialmente corresponder e retornar várias colunas.

## Exemplos


### Consulta de informações da dimensão de produto


Neste exemplo, o modelador precisa de informações da tabela da dimensão de produto para dar sentido à tabela fato de pedidos. Por isso, a tabela *Import Order Fact* é selecionada como **Tabela de origem**. A tabela *Import Product Dim* contém as informações de consulta desejadas, então ela é selecionada como **Lookup Table Source**. Embora estejam disponíveis, nenhum filtro é aplicado à tabela de dados de consulta (nem a nenhuma outra tabela de dados, aliás).



Na seção **Seleção de dados da tabela**, todas as colunas são mapeadas da tabela de dados de origem para a tabela de dados de destino. 



Nenhum dos **Filtros de dados** é aplicado aos dados de origem ou de destino. 



Por fim, a tabela de dados de origem é correspondida à tabela de dados de consulta usando o campo *Product_ID* presente em cada tabela. Somente as colunas *Product_Description* e *Unit_Cost* são anexadas à tabela de dados de destino, e *Unit_Cost* é renomeada para *Retail_Unit_Cost* no processo. 



Na tabela de dados de destino resultante, as colunas *Product_Description* e *Retail_Unit_Cost* foram adicionadas, com base nos valores correspondentes na coluna *Product_ID*.
