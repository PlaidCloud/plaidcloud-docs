## Descrição


Cria uma cópia de uma tabela de dados.




<SnippetCommonTableSourceAndTarget />



Ao fazer a cópia, o Analyze verifica primeiro se a tabela de dados de destino já existe. Se existir, nenhuma ação é executada, a menos que a caixa de seleção **Allow Overwriting Existing Table** esteja marcada. Nesse caso, a tabela de destino é sobrescrita.
