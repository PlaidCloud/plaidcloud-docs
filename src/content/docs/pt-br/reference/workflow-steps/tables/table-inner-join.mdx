## Descrição


Use, como você poderia esperar, para executar uma operação de junção interna em 2 tabelas de dados, combinando-as em uma única tabela de dados com base nas chaves de junção especificadas.


Para mais detalhes sobre a metodologia da junção interna, veja aqui: [Wikipedia SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## Colunas nomeadas durante a execução

Selecione **Levar também colunas nomeadas durante a execução** para passar adiante, sem alteração, todas as colunas de origem que a etapa não lista, como a tabela as tem quando a etapa é executada. Use-o quando uma etapa anterior cria colunas cujos nomes dependem dos dados, como um pivô, de modo que você não pode listá-las ao construir a etapa. Deixe desativado para gravar apenas as colunas que você lista.

## Exemplos


### Unir fabricantes de automóveis com modelos


Neste exemplo, considere as seguintes tabelas de dados de origem. A primeira é uma lista de fabricantes de automóveis.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

A seguir, uma lista de modelos de automóveis com um ID de fabricante. Observe que vários modelos não têm fabricante.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

Para obter uma lista de modelos por fabricante, faz sentido unir por *Mfg_ID*.


Primeiro, especifique os parâmetros da **Seleção de dados da Tabela 1**. A tabela de dados de origem é selecionada e todas as colunas são listadas.



Em seguida, especifique os parâmetros da **Seleção de dados da Tabela 2**. Mais uma vez, a tabela de dados de origem é selecionada e todas as colunas são listadas.



Por fim, as condições de junção são definidas na guia **Saída**. Usando o botão **Detectar**, o Analyze identifica corretamente a coluna *Mfg_ID* a ser usada como **Chave de junção**. Por último, as 


**Colunas de saída de destino** são especificadas automaticamente com o botão **Propagar**. Isso inclui efetivamente todas as colunas de todas as tabelas, com todas as colunas de junção incluídas uma única vez. Observe que as colunas são ordenadas alfabeticamente, primeiro por *Manufacturer* e depois por *ModelName*.



Como esperado, a saída final inclui apenas os valores que tiveram correspondência em ambas as tabelas. Assim, a *Porsche* não aparece porque não tinha modelos. Da mesma forma, o 


*Batmobile* não tinha fabricante (era um trabalho personalizado), então não está incluído.
