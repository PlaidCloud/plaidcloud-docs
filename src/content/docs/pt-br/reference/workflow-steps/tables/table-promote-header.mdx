## Descrição

A etapa **Tabela: Promover cabeçalho** pega uma linha da entrada, transforma os valores dela nos nomes das colunas e depois remove essa linha. Use-a para um arquivo cujo cabeçalho real não é a primeira linha. A etapa é executada quando o fluxo de trabalho é executado, então os nomes vêm dos dados.

## Origem e opções

- **Tabela de origem** e **Tabela de saída** — a tabela a ser lida e a tabela a ser gravada.
- **Linha de cabeçalho** — a linha, contada a partir de 1, cujos valores dão nome às colunas. Ela é removida dos dados. Deixe vazio para não promover nenhum cabeçalho e aplicar as etapas de formatação aos nomes armazenados.
- **Coluna de ordem dos registros** *(opcional)* — a coluna que coloca as linhas em ordem. Sem ela, as linhas são lidas como estão armazenadas, então a linha que dá nome às colunas pode mudar de uma execução para outra.
- **Colunas quando a entrada está vazia** *(opcional)* — nomes, separados por vírgulas, das colunas de texto a gravar quando a entrada não tem linhas.

## Etapas de formatação

Cada linha da grade **Etapas de formatação** altera os nomes promovidos.

| Configuração | Opções |
| --- | --- |
| Ação | **Renomear**, **Alterar tipo**, **Ocultar**, **Preencher vazios** |
| Condição | **Contém**, **Começa com**, **Termina com** ou **Está vazio** |
| Texto correspondente | O texto a procurar no nome da coluna. Não é necessário para **Está vazio**. |
| Renomear por | **Substituindo texto**, **Adicionando antes** ou **Adicionando depois**, para uma renomeação |
| Substituir por | O novo texto para uma renomeação ou um preenchimento |
| Valor | O tipo para **Alterar tipo** |

Cada etapa precisa de uma ação e de uma condição, e uma renomeação precisa de um método de renomeação e do texto dele.
