## Descrição

A etapa **Table: KNIME Random Sample** faz o sorteio aleatório de um nó do KNIME com o gerador de números aleatórios que o KNIME usa, de modo que um nó com semente sorteia as mesmas linhas ou os mesmos valores no PlaidCloud e no KNIME. Os [fluxos de trabalho do KNIME migrados](/pt-br/guides/workflows/migrate-knime-workflows/) usam esta etapa para Row Sampler, Table Partitioner, Equal Size Sampling, Bootstrap Sampling, Shuffle, X-Partitioner e os nós de geração de dados aleatórios.

O sorteio lê a tabela de origem para o fluxo de trabalho, então aceita uma tabela de no máximo 10.000.000 de linhas; uma tabela maior faz a etapa falhar.

O formulário da etapa tem uma seção **Tabelas** para as tabelas de origem e de saída, uma seção **Sorteio** para o **Método**, a **Semente** e o tamanho da amostra, e uma seção **Colunas** para as colunas lidas e gravadas.

## Configuração

- `source` e `target_frame` — a tabela a ser lida e a tabela a ser gravada.
- `position_column` — a coluna com a posição de cada linha, começando em 0. O padrão é `_knime_pos`.
- `method` — o sorteio:
  - `random`, `stratified`, `equal_exact` e `equal_approximate` mantêm as posições das linhas que um sorteio de Row Sampler, Table Partitioner ou Equal Size Sampling seleciona. `class_column` e `class_dtype` nomeiam a coluna de classe de um sorteio estratificado ou de tamanho igual.
  - Todos os outros métodos gravam o sorteio ao lado das posições das linhas: `uniform`, `gaussian`, `gamma`, `beta`, `label`, `label_dependent`, `label_from_table`, `boolean`, `mersenne_twister`, `sobol` e `halton` (geração de dados aleatórios), `shuffle`, `bootstrap`, `match` (Random Matcher), `item_insert` (Random Item Inserter), `stress` (Stresser), `sample_data` (Sample Data Generator, sem tabela de origem), `kfold` (partições do X-Partitioner), `p_square` (estimativas de percentil P² por grupo), `set_bits` (vetores de bits), `equal_count_edges` (os limites de contagem igual do Binner) e `border_texts` (os textos de limite do Auto-Binner).
- `seed` — a semente do fluxo aleatório. Vazia, sorteia a partir do relógio, como o KNIME faz sem semente, de modo que as linhas mudam a cada execução.
- `count`, `percentage` e `relative` — quantas linhas sortear: uma contagem ou, com `relative`, uma porcentagem. `count_column` toma a contagem de uma coluna de origem, para uma contagem conhecida somente quando o fluxo de trabalho é executado.
- `parameters` — as configurações do nó que os métodos de sorteio leem, como a distribuição de um sorteio `gaussian` ou o número de partições de um sorteio `kfold`.
- `source_columns` e `target_columns` — para os métodos de sorteio, as colunas lidas e as colunas gravadas, com a coluna de posição primeiro.
- `source_b` e `source_columns_b` — uma segunda entrada, como a tabela de categorias de `label_from_table` ou a tabela da qual `match` sorteia. `target_frame_b` e `target_columns_b` recebem os centros dos clusters de `sample_data`.
