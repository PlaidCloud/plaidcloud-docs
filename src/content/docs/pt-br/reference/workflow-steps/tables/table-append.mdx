## Descrição

Adiciona linhas de uma tabela de origem ao final de uma tabela de destino existente. As linhas existentes no destino são preservadas; apenas as linhas novas são inseridas. Use-a quando os dados chegam de forma incremental (por exemplo, extrações diárias, arquivos de carga mensais) e você quer que o destino cresça ao longo do tempo, em vez de ser substituído.

Se precisar remover duplicatas ao anexar, use em seguida uma etapa [Table Union Distinct](/pt-br/reference/workflow-steps/tables/table-union-distinct/) ou use [Table Upsert](/pt-br/reference/workflow-steps/tables/table-upsert/) se algumas linhas atualizarem registros existentes por chave.

## O que é verificado ao salvar

- **O mapeamento se ajusta a uma tabela de destino existente.** Quando a tabela de destino já existe, a etapa não pode mapear uma coluna que a tabela não tem nem dar a uma coluna um tipo diferente do da tabela. Numérico e moeda contam como o mesmo tipo. Uma coluna da tabela que o mapeamento deixa de fora é permitida e fica vazia nas linhas anexadas. A recusa cita cada diferença, por exemplo, *The target columns must match the existing target table 'sales'. Types differ: amount (table: numeric, step: text).* Uma tabela de destino que ainda não existe, ou nomeada com uma variável, é verificada quando a etapa é executada.
- **Um mapeamento vazio é preenchido para você.** Ao salvar com uma tabela de origem escolhida, mas sem colunas de origem ou de destino, o lado vazio é preenchido a partir da origem, como faria **Preencher ambas as tabelas de mapeamento**.
