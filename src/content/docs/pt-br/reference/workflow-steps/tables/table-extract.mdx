## Descrição


Usada para extrair dados de uma tabela de dados do Analyze existente para outra tabela de dados. Os exemplos incluem, entre outros, os seguintes:


* Ordenação
* Agrupamento
* Resumo
* Filtrar/subconjunto de linhas
* Remover colunas extras
* Operações matemáticas
* Operações com strings

<Aside>Não há funções exclusivas desta transformação. Toda ordenação, agrupamento, filtragem etc. pode ser realizada em qualquer outra transformação com as guias **Colunas** e **Filtros**.</Aside>

## Colunas nomeadas durante a execução

Selecione **Levar também colunas nomeadas durante a execução** para passar adiante, sem alteração, todas as colunas de origem que a etapa não lista, como a tabela as tem quando a etapa é executada. Use-o quando uma etapa anterior cria colunas cujos nomes dependem dos dados, como um pivô, de modo que você não pode listá-las ao construir a etapa. Deixe desativado para gravar apenas as colunas que você lista.

Quando está ativado, uma seção **Colunas carregadas** aparece, e uma seção **Colunas nomeadas pelos dados** está sempre disponível. Elas têm estes campos:

* **Carregar como** (`carry_expression`): grava cada coluna carregada como esta expressão, em vez de sem alteração, com `__column__` representando a coluna carregada. É assim que uma etapa que agrupa incorpora colunas que só a execução nomeia; uma etapa que agrega não carrega nada sem isso. **Tipo das colunas carregadas** (`carry_dtype`) define o tipo de dados de cada coluna carregada (padrão: o próprio dela), e **Agregação das colunas carregadas** (`carry_agg`) define como uma etapa de agregação a trata (`dont_group` quando a expressão agrega).
* **Renomear colunas transportadas** (`carry_rename`): renomeia cada coluna carregada cujo nome a expressão regular `pattern` corresponde, e `keep` não, colocando `replacement` no lugar de cada correspondência (`\1` para um grupo; as primeiras `max` correspondências, quando definido). `__index__` em `replacement` é a posição da coluna entre as colunas renomeadas, contada a partir de `start`. Um nome já ocupado recebe ` (#n)` acrescentado.
* **Colunas dinâmicas** (`dynamic_columns`): colunas de destino nomeadas pelos dados, um conjunto para cada valor distinto que a etapa lê da origem, gravadas quando a etapa é executada. Cada entrada informa `rows` (expressões `key`, `label`, `where` e `order` sobre a origem), uma coluna `target` ou lista de colunas que usa `__key__`, `__label__` e `__index__`, e `after`, a coluna de destino após a qual as novas ficam (padrão: o final). Os valores devem ser texto, inteiro, booleano ou NULL, a etapa grava no máximo 1.000 colunas, e a saída deve ser uma tabela.
