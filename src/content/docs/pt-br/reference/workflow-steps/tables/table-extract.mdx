## Descrição


Usada para extrair dados de uma tabela de dados do Analyze existente para outra tabela de dados. Os exemplos incluem, entre outros, os seguintes:


* Ordenação
* Agrupamento
* Sumarização
* Filtro/subconjunto de linhas
* Remoção de colunas extras
* Operações matemáticas
* Operações com strings

<Aside>Não há funções exclusivas desta transformação. Toda ordenação, agrupamento, filtragem etc. pode ser feita em qualquer outra transformação com as guias **Seleção de dados da tabela** e **Filtros de dados**.</Aside>

## Colunas nomeadas durante a execução

Selecione **Levar também colunas nomeadas durante a execução** para repassar, sem alterações, todas as colunas de origem que a etapa não lista, do jeito que a tabela as tem quando a etapa é executada. Use essa opção quando uma etapa anterior cria colunas cujos nomes dependem dos dados, como uma tabela dinâmica (pivot), e você não pode listá-las ao montar a etapa. Deixe-a desativada para gravar somente as colunas que você listar.

Quando ela está ativada, aparece a seção **Colunas carregadas**, e a seção **Colunas nomeadas pelos dados** está sempre disponível. Elas têm estes campos:

* **Carregar como** (`carry_expression`) — grava cada coluna carregada como esta expressão, em vez de sem alterações, com `__column__` representando a coluna carregada. É assim que uma etapa que agrupa incorpora colunas que só a execução nomeia; uma etapa que agrega não carrega nada sem isso. **Tipo das colunas carregadas** (`carry_dtype`) define o tipo de dados de cada coluna carregada (por padrão, o próprio tipo dela), e **Agregação das colunas carregadas** (`carry_agg`) define como uma etapa de agregação trata essa coluna (`dont_group` quando a expressão agrega).
* **Renomear colunas transportadas** (`carry_rename`) — renomeia cada coluna carregada cujo nome corresponde à expressão regular `pattern` e não corresponde a `keep`, colocando `replacement` no lugar de cada correspondência (`\1` para um grupo; as primeiras `max` correspondências, quando definido). `__index__` em `replacement` é a posição da coluna entre as colunas renomeadas, contada a partir de `start`. Um nome já em uso recebe ` (#n)` no final.
* **Colunas dinâmicas** (`dynamic_columns`) — colunas de destino nomeadas pelos dados, um conjunto para cada valor distinto que a etapa lê de sua origem, gravadas quando a etapa é executada. Cada entrada informa `rows` (expressões `key`, `label`, `where` e `order` sobre a origem), uma coluna `target` ou lista de colunas que usa `__key__`, `__label__` e `__index__`, e `after`, a coluna de destino após a qual as novas são inseridas (por padrão, o final). Os valores devem ser texto, inteiro, booleano ou NULL, a etapa grava no máximo 1.000 colunas e a saída deve ser uma tabela.
