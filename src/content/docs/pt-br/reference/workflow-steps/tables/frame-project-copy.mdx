## Descrição

Copia uma tabela de um projeto para outro. Use-a para trazer uma tabela de referência compartilhada, um conjunto de resultados publicado ou uma consulta baseada em dimensão entre projetos, sem exportar para um arquivo e importá-lo de volta.

Os dois lados são nomeados explicitamente — um projeto e uma tabela de origem, e um projeto e uma tabela de destino. O projeto de destino começa como o projeto atual, mas pode ser qualquer projeto, então uma etapa pode copiar para este projeto, a partir dele ou entre outros dois. A tabela de destino é criada se não existir e deve ser uma tabela, e não uma visão.

## Gerenciamento de compartilhamento de dados

Uma cópia precisa de até dois compartilhamentos de dados:

- **Leitura, do projeto de origem para o projeto de destino**, para que os dados da origem cheguem apenas aonde a origem os compartilha. Abra a guia **Início** do projeto de **origem** e, em **Gerenciamento de compartilhamento de dados**, clique em **Novo compartilhamento de dados**, selecione o projeto de destino, marque **Leitura** em **Operações permitidas** e clique em **Adicionar compartilhamento de dados**.
- **Gravação, do projeto de destino para este projeto** — o projeto em que o fluxo de trabalho está, que faz a gravação — quando o destino é outro projeto. Abra a guia **Início** do projeto de **destino** e, em **Gerenciamento de compartilhamento de dados**, clique em **Novo compartilhamento de dados**, selecione este projeto, marque **Gravação** em **Operações permitidas** e clique em **Adicionar compartilhamento de dados**.

Assim, uma cópia para este projeto precisa apenas do compartilhamento de Leitura, e uma cópia dentro de um único projeto não precisa de nenhum. Consulte [Compartilhando dados entre projetos](/pt-br/guides/projects/managing-projects/#compartilhar-dados-entre-projetos).

Sem um compartilhamento de que precisa, o salvamento da etapa é recusado e uma execução falha, com uma mensagem que cita cada compartilhamento a adicionar — por exemplo, *Project 'Sales' can't write to project 'Finance': in project 'Finance', under Data Sharing Management, add a data share for 'Sales' that allows Write.* Uma execução recusada deixa o projeto de destino como estava, sem criar a tabela de destino. Um projeto informado como variável é verificado quando a etapa é executada.

A etapa é executada com a identidade do próprio projeto, então uma execução funciona pelos compartilhamentos, não importa quem a inicie.

## Parâmetros de cópia

### Ler de

- **Projeto de origem** — o projeto do qual copiar.
- **Tabela de origem** — a tabela a copiar, escolhida no projeto de origem.

### Gravar em

- **Projeto de destino** — o projeto para o qual copiar. Ele começa como o projeto atual.
- **Tabela de destino** — a tabela a gravar, escolhida no projeto de destino. Escolher um **Projeto de destino** diferente limpa uma tabela escolhida no projeto anterior; uma tabela informada por nome ou caminho é mantida e procurada no novo projeto.
- **Anexar aos dados existentes** — marque para adicionar as linhas copiadas ao que a tabela de destino já contém. Deixe desmarcada para substituir as linhas da tabela pelas da origem.

Um projeto salvo que você não consegue ver, ou que foi excluído, é exibido marcado como **(missing)**, em vez de ser trocado por outro projeto.
