## Descrição

Lê dados de uma visão salva do **Anaplan** por meio da sua [conexão do Anaplan](/pt-br/guides/connections/anaplan/), usando o caminho de solicitação de leitura de grande volume do Anaplan. A visão é lida **exatamente como foi salva** — esta etapa não tem seleção ad hoc de linhas, colunas ou páginas. Para ler um recorte diferente, salve outra visão no Anaplan.

Esta etapa aparece no menu de etapas em **Anaplan**.

A etapa acessa o Anaplan **diretamente na nuvem** por meio da Integration API — não há caminho por agente local.

<Aside type="tip">
Este conector é somente leitura e se autentica com credenciais Basic (usuário e senha) ou com Certificado de CA — consulte [Autenticação](/pt-br/guides/connections/anaplan/#autenticação). O orçamento de solicitações do Anaplan é compartilhado por todo o tenant, portanto escalone o agendamento desta etapa em relação aos seus outros fluxos de trabalho do Anaplan — consulte [Considerações sobre agendamento](/pt-br/guides/connections/anaplan/#considerações-sobre-agendamento).
</Aside>

## Configuração

### Origem e destino

| Campo | Obrigatório | Observações |
|---|---|---|
| Conexão do Anaplan | Sim | A [conexão do Anaplan](/pt-br/guides/connections/anaplan/) usada para a leitura. |
| Ambiente | Sim | O ambiente da conexão. |
| Espaço de trabalho | Não | Substitui o ID do espaço de trabalho salvo na conexão. Descoberto ao vivo a partir da conexão ou digitado manualmente. |
| Modelo | Não | Substitui o ID do modelo salvo na conexão. Descoberto ao vivo depois que um espaço de trabalho é escolhido ou digitado manualmente. |
| Visão | Sim | A visão salva do Anaplan a ser lida. Descoberta ao vivo depois que um modelo é escolhido ou digitada manualmente. |
| Tentativas de consulta | Sim | Padrão 120. Quantas vezes a solicitação de leitura é consultada para verificar a conclusão antes de a etapa recusar, informando o ID da solicitação. Ela nunca envia silenciosamente uma segunda solicitação. |
| Intervalo de consulta (segundos) | Sim | Padrão 5. Segundos de espera entre as consultas. |
| Tabela de destino | Sim | A tabela em que a visão retornada é gravada. |

## O que esta etapa não consegue representar

| Limitação | O que significa |
|---|---|
| Sem controle de recorte | A visão é lida exatamente como foi salva — sem seleção de linhas, colunas ou páginas. O seletor de página do Anaplan está documentado apenas no endpoint síncrono de pré-visualização; o corpo da solicitação de leitura de grande volume que esta etapa envia aceita um tipo de exportação e nada mais. Crie outra visão salva — normalmente um item de linha booleano mais um filtro — para ler um recorte diferente. |
| Os tipos declarados só são aplicados quando Line Items está em Columns | Com Line Items no eixo de colunas da visão, cada coluna de dados é gravada com o tipo do formato declarado no Anaplan para o respectivo item de linha (Number, Text, Boolean, Date, Time Period ou List). Com Line Items nas linhas (um layout comum de DRE) ou totalmente ausente da visão, toda coluna de dados é gravada como texto, com um aviso identificado — caso contrário, uma coluna de dados abrangeria muitos itens de linha e, portanto, muitos formatos, enquanto uma coluna de tabela comporta exatamente um tipo. |
| Os valores do seletor de página não são gravados como colunas | Os membros do seletor de página salvos em uma visão acompanham o cabeçalho do CSV e são consumidos ali — não aparecem como colunas na tabela de destino. |
| Números ambíguos são recusados em vez de adivinhados | Um valor declarado como Number que tenha separadores de milhar, ou que possa ser lido igualmente como decimal simples ou como notação europeia (por exemplo, `1.234`), é recusado pelo nome em vez de analisado — a menos que outro valor da mesma coluna indique qual leitura está correta. Este caminho de leitura não tem um campo de localidade para resolver a ambiguidade. Um valor que seja analisado com sucesso é gravado com precisão total, sem erro de arredondamento, e uma célula em branco sempre é gravada como valor vazio. |
| Visão vazia é gravada vazia, com um aviso | Uma visão salva cujo filtro não corresponde a nada substitui a tabela de destino por uma tabela vazia e emite um aviso — isso é um resultado comum, não uma falha. A exceção é uma visão sem nenhuma dimensão no eixo de linhas: não há canto com rótulos de linha para verificar um resultado vazio, então a etapa recusa em vez de arriscar esvaziar a tabela por causa de um cabeçalho lido incorretamente. |
| Somente leitura | Nada é gravado de volta no Anaplan. |
