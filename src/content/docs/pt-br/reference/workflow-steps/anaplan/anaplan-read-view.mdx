## Descrição

Lê dados de uma visão salva do **Anaplan** por meio da sua [conexão do Anaplan](/pt-br/guides/connections/anaplan/), pelo caminho de solicitação de leitura de grande volume do Anaplan. A visão é lida **exatamente como foi salva**; não há seleção ad hoc de linhas, colunas ou páginas nesta etapa. Para ler uma fatia diferente, salve uma visão diferente no Anaplan.

Esta etapa aparece no menu de etapas em **Anaplan**.

A etapa alcança o Anaplan **diretamente na nuvem** pela API de integração dele; não há caminho por agente local.

<Aside type="tip">
Este conector é somente leitura e autentica com credenciais Basic (nome de usuário e senha) ou de certificado de CA; consulte [Autenticação](/pt-br/guides/connections/anaplan/#autenticação). O orçamento de solicitações do Anaplan é compartilhado em todo o tenant, então escalone o agendamento desta etapa em relação aos seus outros fluxos de trabalho do Anaplan; consulte [Considerações sobre agendamento](/pt-br/guides/connections/anaplan/#considerações-sobre-agendamento).
</Aside>

## Configuração

### Origem e destino

| Campo | Obrigatório | Observações |
|---|---|---|
| Conexão do Anaplan | Sim | A [conexão do Anaplan](/pt-br/guides/connections/anaplan/) pela qual ler. |
| Ambiente | Não | **Ambiente do projeto** (o padrão) usa o ambiente da conexão do projeto. **Ambiente fixo** sempre usa o que você escolher. Consulte [Fixar uma etapa em um ambiente](/pt-br/guides/projects/managing-projects/#fixar-uma-etapa-em-um-ambiente). |
| Espaço de trabalho | Não | Substitui o ID do espaço de trabalho salvo na conexão. Descoberto ao vivo a partir da conexão ou digitado manualmente. |
| Modelo | Não | Substitui o ID do modelo salvo na conexão. Descoberto ao vivo depois que um espaço de trabalho é escolhido ou digitado manualmente. |
| Visão | Sim | A visão salva do Anaplan a ser lida. Descoberta ao vivo depois que um modelo é escolhido ou digitada manualmente. |
| Tentativas de consulta | Sim | Padrão 120. Quantas vezes consultar a solicitação de leitura até a conclusão antes de a etapa recusar, informando o ID da solicitação. Ela nunca envia silenciosamente uma segunda solicitação. |
| Intervalo de consulta (segundos) | Sim | Padrão 5. Segundos de espera entre as consultas. |
| Tabela de destino | Sim | A tabela em que a visão retornada é gravada. |

## Pré-visualização

**Pré-visualização** na guia **Origem** mostra as colunas e os tipos de dados que esta leitura de visão produziria, sem executar a etapa. Ela não está disponível em um projeto bloqueado.

## O que esta etapa não consegue representar

| Limitação | O que significa |
|---|---|
| Sem controle de fatia | A visão é lida exatamente como foi salva, sem seleção de linhas, colunas ou páginas. O seletor de páginas do Anaplan está documentado apenas no endpoint de pré-visualização síncrono dele; o corpo da solicitação de leitura de grande volume que esta etapa envia aceita um tipo de exportação e nada mais. Crie uma visão salva diferente, em geral um item de linha booleano mais um filtro, para ler uma fatia diferente. |
| Os tipos declarados só são gravados quando Line Items está em Colunas | Com Line Items no eixo de colunas da visão, cada coluna de dados é gravada com o tipo vindo do formato declarado do item de linha no Anaplan (Número, Texto, Booleano, Data, Período de tempo ou Lista). Com Line Items nas linhas (um layout comum de DRE) ou ausente da visão, toda coluna de dados é gravada como texto, com um aviso nomeado: uma coluna de dados abrangeria muitos itens de linha, e portanto muitos formatos, enquanto uma coluna de tabela contém exatamente um tipo. |
| Os valores do seletor de páginas não são gravados como colunas | Os membros salvos do seletor de páginas de uma visão acompanham o cabeçalho do CSV e são consumidos ali; eles não aparecem como colunas na tabela de destino. |
| Números ambíguos são recusados em vez de adivinhados | Um valor declarado como Número que contém separadores de milhar, ou que pode ser lido tanto como decimal simples quanto no estilo europeu (por exemplo `1.234`), é recusado pelo nome em vez de analisado, a menos que outro valor na mesma coluna defina qual leitura está correta. Este caminho de leitura não tem campo de localidade para resolver a ambiguidade. Um valor que é analisado é gravado com precisão total, sem erro de arredondamento, e uma célula em branco é sempre gravada como valor vazio. |
| Uma visão vazia é gravada vazia, com um aviso | Uma visão salva cujo filtro não corresponde a nada substitui a tabela de destino por uma vazia e emite um aviso; isso é um resultado comum, não uma falha. A exceção é uma visão sem nenhuma dimensão no eixo de linhas: não há canto de rótulo de linha com o qual verificar um resultado vazio, então a etapa recusa em vez de arriscar esvaziar a tabela por causa de um cabeçalho mal interpretado. |
| Somente leitura | Nada é gravado de volta no Anaplan. |
