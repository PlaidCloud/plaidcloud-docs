## Descrição

Executa uma ação de exportação **já existente** do Anaplan pela sua [Conexão do Anaplan](/pt-br/guides/connections/anaplan/) e grava o arquivo que ela produz como uma tabela. A ação de exportação já deve existir no modelo — a API não consegue criar uma — e esta etapa não consegue restringir o que ela emite: o que a ação estiver configurada para exportar no Anaplan é exatamente o que é gravado.

Esta etapa aparece no menu de etapas em **Anaplan**.

A etapa acessa o Anaplan **diretamente pela nuvem**, por meio da Bulk API — não há caminho por agente local.

<Aside type="tip">
Este conector é somente leitura e autentica com credenciais Basic (usuário e senha) ou de certificado de CA — consulte [Autenticação](/pt-br/guides/connections/anaplan/#autenticação). O orçamento de solicitações do Anaplan é compartilhado em todo o tenant, portanto escalone o agendamento desta etapa em relação aos seus outros fluxos de trabalho do Anaplan — consulte [Considerações sobre agendamento](/pt-br/guides/connections/anaplan/#considerações-sobre-agendamento).
</Aside>

## Configuração

### Origem e destino

| Campo | Obrigatório | Observações |
|---|---|---|
| Conexão do Anaplan | Sim | A [conexão do Anaplan](/pt-br/guides/connections/anaplan/) pela qual ler. |
| Ambiente | Sim | O ambiente da conexão. |
| Espaço de trabalho | Não | Substitui o ID do espaço de trabalho salvo na conexão. Descoberto ao vivo a partir da conexão ou digitado manualmente. |
| Modelo | Não | Substitui o ID do modelo salvo na conexão. Descoberto ao vivo depois que um espaço de trabalho é escolhido, ou digitado manualmente. |
| Exportação | Sim | A ação de exportação do Anaplan a executar. Descoberta ao vivo depois que o espaço de trabalho e o modelo são escolhidos, ou digitada manualmente. Sua seleção não pode ser substituída aqui — ela é executada exatamente como configurada no Anaplan. |
| Tentativas de consulta | Sim | Padrão: 120. Quantas vezes consultar a tarefa de exportação para verificar a conclusão antes que a etapa recuse a execução, informando o ID da tarefa. Ela nunca reenvia em silêncio — o Anaplan não documenta como distinguir dois arquivos produzidos pela mesma ação de exportação, portanto um reenvio corre o risco de associar o arquivo errado a esta execução. |
| Intervalo de consulta (segundos) | Sim | Padrão: 5. Segundos de espera entre as consultas. |
| Tabela de destino | Sim | A tabela em que a exportação é gravada. Todas as colunas são gravadas como texto. |

## O que esta etapa não consegue representar

| Limitação | O que significa |
|---|---|
| Exige uma ação de exportação já existente | A API não consegue criar uma ação de exportação, e a solicitação que esta etapa envia não carrega nenhum parâmetro de ponto de vista, seleção de membros ou fatia de qualquer tipo — o que a ação estiver configurada para emitir no Anaplan é exatamente o que é gravado. Crie ou edite a ação de exportação no Anaplan para alterar o que ela produz. |
| Todas as colunas são gravadas como texto | O campo que o Anaplan publica para declarar os tipos das colunas de uma exportação é internamente inconsistente na própria documentação publicada do Anaplan, portanto não é possível confiar nele para tipar uma coluna corretamente — nenhuma coluna é tipada a partir dele, de forma deliberada e permanente. Converta as colunas de que precisar em uma etapa seguinte. |
| Números solicitados no formato dos EUA; uma coluna ainda agrupada é sinalizada, não corrigida | A tarefa de exportação é enviada solicitando a formatação numérica dos EUA. Uma coluna que ainda volta com separadores de milhar significa que a exportação não está sendo renderizada nesse formato — a etapa grava o valor inalterado, como texto, e emite um aviso, informando a coluna e um valor de exemplo, em vez de adivinhar qual caractere é a vírgula decimal. Verifique essa coluna antes de convertê-la em uma etapa seguinte: um `1.234.567` no estilo europeu lido como `1.234` fica mil vezes menor. |
| Recusa a execução em vez de gravar uma extração não confiável | A etapa não grava nada, em vez de uma tabela que parece completa e não é, quando: a tarefa de exportação falha ou não informa sucesso no Anaplan; a tarefa é cancelada; a tarefa ainda está em execução quando o orçamento de consultas da etapa se esgota; o arquivo produzido não tem nenhum dado; o arquivo produzido não pode ser associado à exportação que o gerou; ou o número de linhas lidas diverge da contagem de linhas que o próprio Anaplan informa para a exportação. |
| Somente leitura | Nada é gravado de volta no Anaplan. |
