## Descrição


“Parar fluxo de trabalho” interrompe um fluxo de trabalho existente que está em execução.


<Aside>Se o fluxo de trabalho não estiver em execução quando esta etapa for executada, um aviso será gravado no log informando que *Workflow is already stopped.</Aside>


## Fluxo de trabalho a parar


Primeiro, selecione o projeto que contém o fluxo de trabalho a ser interrompido no menu suspenso **Projeto**.



Em seguida, selecione o fluxo de trabalho específico a ser interrompido no menu suspenso **Fluxo de trabalho**.
