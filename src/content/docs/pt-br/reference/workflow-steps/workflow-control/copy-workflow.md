## Descrição


Faça uma cópia de um fluxo de trabalho existente do PlaidCloud Analyze.



## Fluxo de trabalho a copiar


Primeiro, selecione no menu suspenso **Projeto** o projeto que contém o fluxo de trabalho a ser copiado.



Em seguida, selecione no menu suspenso **Fluxo de trabalho** o fluxo de trabalho específico a ser copiado.



Em seguida, insira o nome do novo fluxo de trabalho no campo **Novo fluxo de trabalho**. Lembre-se: o nome deve ser exclusivo no projeto.
