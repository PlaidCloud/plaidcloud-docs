## Descrição


Crie um novo fluxo de trabalho do PlaidCloud Analyze.



## Fluxo de trabalho a criar


Primeiro, selecione no menu suspenso o projeto em que o novo fluxo de trabalho deve ser criado.



Em seguida, digite o nome do fluxo de trabalho. O nome deve ser exclusivo no projeto.
