## Descrição


Renomeia um fluxo de trabalho existente do PlaidCloud Analyze.

<Aside>Se o fluxo de trabalho renomeado já existir, um erro será gravado no log informando que *Workflow \{workflow} in project \{project} already exists.* Nenhuma ação será executada. Na prática, isso limita a transformação **Renomear fluxo de trabalho** a um único uso.</Aside>


## Fluxo de trabalho a renomear


Primeiro, selecione o projeto que contém o fluxo de trabalho a ser renomeado no menu suspenso **Projeto**.



Em seguida, selecione o fluxo de trabalho específico a ser renomeado no menu suspenso **Fluxo de trabalho**.



Por fim, digite o novo nome do fluxo de trabalho no campo **Renomear para**. Lembre-se de que o nome deve ser exclusivo no projeto.
