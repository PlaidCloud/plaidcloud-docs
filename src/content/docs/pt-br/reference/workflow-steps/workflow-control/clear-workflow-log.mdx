## Descrição


Limpe o log de um fluxo de trabalho existente do PlaidCloud Analyze.



## Log do fluxo de trabalho a limpar


Primeiro, selecione no menu suspenso **Projeto** o projeto que contém o log do fluxo de trabalho a ser limpo.



Em seguida, selecione no menu suspenso **Fluxo de trabalho** o log específico do fluxo de trabalho a ser limpo.


<Aside type="danger">Não há caixa de diálogo para confirmar a exclusão. Certifique-se de selecionar o log do fluxo de trabalho correto.</Aside>
