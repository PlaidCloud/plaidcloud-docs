## Descrição


Exclua um fluxo de trabalho existente do PlaidCloud Analyze.



## Fluxo de trabalho a excluir


Primeiro, selecione no menu suspenso **Projeto** o projeto que contém o fluxo de trabalho a ser excluído.



Em seguida, selecione no menu suspenso **Fluxo de trabalho** o fluxo de trabalho específico a ser excluído.


<Aside type="danger">Não há caixa de diálogo para confirmar a exclusão. Certifique-se de estar selecionando o fluxo de trabalho correto!</Aside>
