## Descrição

Importe os cabeçalhos de faturas do Contas a Pagar do Sage Intacct por meio da API REST do Sage Intacct. Cada linha é uma fatura do Contas a Pagar, com o fornecedor, a data do razão geral, a data de vencimento, os totais e os campos de status necessários para relatórios posteriores.

Use um [Conector REST do Sage Intacct](../../../connectors/rest/sage-intacct/) configurado como origem. Para importar também o detalhe em nível de linha, combine esta etapa com [Import Sage AP Lines](../import-sage-ap-lines/).

## Itens de Configuração Exclusivos

* **Conexão Sage** — a conexão REST do Sage Intacct da qual ler. As conexões Sage são gerenciadas em **Ferramentas > Conexões**.
* **ID da empresa** — a empresa do Intacct a consultar. Obrigatório se as suas credenciais de remetente cobrirem mais de uma empresa.
* **ID(s) da entidade (separados por vírgula)** — restringe a importação a uma ou mais entidades do Intacct. Deixe em branco para importar todas as entidades a que o usuário tem acesso.
