## Descrição

Anexa documentos de suporte a registros do Sage Intacct por meio da sua [conexão Sage Intacct](/pt-br/guides/connections/sage-intacct/), usando o pipeline de gravação ERP compartilhado do PlaidCloud. Cada linha da tabela de origem é um arquivo — seus bytes, seu nome e a chave do registro do Intacct ao qual ele é anexado — que a etapa cria como um documento de suporte do Sage Intacct (`supdoc`) e vincula a esse registro. **Validate Only** verifica todas as linhas sem criar nada no Intacct; a tabela de resultado registra o desfecho de cada anexo.

Use-a para enviar arquivos que um fluxo de trabalho já tem em mãos — um PDF de fatura renderizado, um recibo digitalizado, um relatório exportado — para as transações ou os registros do Intacct a que pertencem, na mesma execução que os produz ou lança. Ela combina naturalmente com [Intacct: Lançar lançamento contábil](/pt-br/reference/workflow-steps/sage-intacct/export-to-sage/): lance os lançamentos e depois anexe o respectivo comprovante usando a chave do Intacct que cada lançamento retornou.

## Contrato do Formato dos Dados

Monte a tabela de anexos em uma etapa anterior com etapas padrão, de modo que cada linha seja um arquivo completo vinculado a um registro:

- **`parent_key`** — o registro do Sage Intacct ao qual o arquivo é anexado. Um arquivo, um pai por linha; para anexar o mesmo arquivo a vários registros, repita-o em várias linhas.
- **`file_name`** — o nome do arquivo do documento de suporte, incluindo a extensão (`invoice-1043.pdf`).
- **`mime_type`** — o tipo de conteúdo do arquivo (`application/pdf`, `image/png`), para que o Intacct o armazene e o sirva corretamente.
- **`content_base64`** — os bytes do arquivo, codificados em base64, na linha.

## Configuração

### Conexão

- **Conexão Sage Intacct** — a conexão Sage Intacct pela qual anexar. Apenas conexões Sage Intacct são oferecidas; a mesma conexão lê e grava no Intacct.
- **Ambiente** — o ambiente da conexão.

### Dados

- **Tabela de anexos** — a tabela de origem descrita acima: uma linha por arquivo, com `parent_key`, `file_name`, `mime_type` e `content_base64`.
- **Tabela de resultado** — id da tabela de saída: uma linha por anexo com `parent_key`, `file_name`, `supdoc_id`, `status`, `message`.
- **Validate Only** — marcado por padrão. Apenas verificação prévia; verifica cada linha e grava a tabela de resultado, mas não cria nenhum documento de suporte no Intacct. Uma configuração de etapa que omita totalmente este campo — por exemplo, uma criada pela API REST, pelo MCP ou por uma importação de pacote de fluxo de trabalho — também assume Validate Only como padrão, em vez de um anexo real.
- **Continue On Error** — marcado por padrão. Continua anexando os arquivos restantes depois que um falha; desmarcado, interrompe na primeira falha.

## Tabela de Resultado

Toda execução — Validate Only ou real — grava uma linha por linha de origem na tabela de resultado:

| Coluna | Descrição |
|---|---|
| `parent_key` | O registro do Intacct que este anexo tem como destino. |
| `file_name` | O nome do arquivo da linha de origem. |
| `supdoc_id` | O id do documento de suporte do Sage Intacct criado para o arquivo, quando o anexo foi bem-sucedido. |
| `status` | O desfecho desta linha — validado, anexado ou com falha. |
| `message` | Uma descrição curta e higienizada do que deu errado, quando a linha falhou. |
