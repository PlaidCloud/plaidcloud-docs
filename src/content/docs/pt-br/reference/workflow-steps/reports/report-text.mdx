## Descrição

O bloco de **Texto** de um relatório composto. É o equivalente da ferramenta correspondente do Alteryx *Reporting* / *Portfolio Composer* e é executado no mecanismo de fluxo de trabalho (reportlab / matplotlib); o renderizador é uma aproximação da saída do Alteryx.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de saída** — a tabela em que o trecho renderizado é gravado.
- **Ordem do relatório** — a ordem desta parte dentro de um relatório composto.
- **Conteúdo de texto** — o texto a renderizar.

## Referenciando uma Coluna no Texto

O conteúdo de texto pode nomear uma coluna entre colchetes, e o valor é impresso no
lugar — `[Year] Results` imprime `2026 Results`. Um Report
Text do Alteryx convertido traz as referências de campo que o texto já tinha, incluindo
a forma formatada que o Alteryx grava como `[Year:A]`.

Um único texto é composto para toda a tabela de origem, portanto a coluna que você nomear
deve ter o mesmo valor em todas as linhas lidas. Resuma a coluna em uma etapa anterior se
ela tiver mais de um valor — um bloco de texto não consegue imprimir vários valores ao mesmo tempo.

`[CurrentYear]` imprime o ano em que o relatório é renderizado e não precisa de coluna.

Algumas regras mantêm seguro o texto corrido comum:

- Um nome que corresponde a uma coluna é sempre substituído.
- Um nome que não corresponde a nenhuma coluna interrompe a etapa e informa o problema, mas somente quando
  ele só poderia ser uma referência — um formato escrito colado aos dois-pontos, como em
  `[Quarter:A]`.
- O texto entre colchetes é impresso como você o escreveu. `[12:30]` continua sendo um horário
  e `[Note: continued]` continua sendo um comentário à parte, porque um número isolado não é um nome de coluna
  e é o texto corrido que coloca um espaço depois dos dois-pontos.

O formato em si não é aplicado — o valor é impresso como a coluna o contém, portanto
formate a coluna em uma etapa anterior se ela precisar de separadores de milhar ou de um formato de data.

## Colunas

A guia **Colunas** mapeia as colunas de origem disponíveis para a parte do relatório.
