## Descrição

O **Chart** (gráfico de barras) dos dados de origem de um relatório composto. É o equivalente da ferramenta correspondente do Alteryx *Reporting* / *Portfolio Composer* e é executado no mecanismo de fluxo de trabalho (reportlab / matplotlib); o renderizador é uma aproximação da saída do Alteryx.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de saída** — a tabela em que o trecho renderizado é gravado.
- **Ordem do relatório** — a ordem desta parte dentro de um relatório composto.
- **Título do gráfico** — o título exibido acima do gráfico.

## Colunas

A guia **Colunas** mapeia as colunas de origem disponíveis para a parte do relatório.
