## Descrição

A **Macro empacotada** renderiza um pacote de relatório importado de uma *macro de relatório empacotada* do Alteryx. É uma etapa Report de primeira classe: a definição da macro incluída no pacote acompanha a etapa automaticamente, e a parte é renderizada pelo mesmo caminho de artefatos de relatório das demais etapas Report.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de destino** — a tabela em que a saída renderizada é gravada.
- **Ordem do relatório** — a posição desta parte dentro de um relatório composto.
