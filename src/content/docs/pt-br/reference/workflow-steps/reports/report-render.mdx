## Descrição

O **Render** das partes do relatório composto em um documento PDF. É o equivalente da ferramenta correspondente do Alteryx *Reporting* / *Portfolio Composer* e é executado no mecanismo de fluxo de trabalho (reportlab / matplotlib); o renderizador é uma aproximação da saída do Alteryx.

## Origem e opções

- **Tabela de origem** — os dados que alimentam esta parte do relatório.
- **Tabela de saída** — a tabela em que o trecho renderizado é gravado.
- **Ordem do relatório** — a ordem desta parte dentro de um relatório composto.
- **Width / Height** — o tamanho da imagem incorporada, em pixels.
- **Arquivo de saída** — o caminho no repositório de documentos do arquivo renderizado.

- **Formato de saída** (`output_format`) — **PDF** (`pdf`, o padrão) ou **Página HTML (autocontida)** (`html`) para gravar o relatório como uma única página HTML autocontida. Dê ao nome do arquivo a extensão `.html`.
- **Segunda tabela de origem** (`source_b`) — uma segunda tabela de entrada, para que a renderização componha as partes das duas entradas.

## Colunas

A guia **Colunas** mapeia as colunas de origem disponíveis para a parte do relatório.
