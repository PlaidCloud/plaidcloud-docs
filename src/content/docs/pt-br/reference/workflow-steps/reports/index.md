## Blocos de Construção de Relatórios

Os fluxos de trabalho de relatórios do Alteryx convertidos montam um documento a partir destas etapas. Chart,
Image, Map, Table e Text geram cada um uma parte; Layout, Visual Layout e
Overlay organizam as partes; Render grava o resultado composto em um PDF.
