Etapas de fluxo de trabalho para alocação de custos, repasse interno, preços de transferência e problemas semelhantes de distribuição de valores. Cada etapa distribui valores de um conjunto de linhas de origem para um conjunto de destino usando dados do direcionador e um método.

## Etapas

- [Etapa Allocation Rules](/pt-br/reference/workflow-steps/allocation/allocation-rules/) — define e aplica regras de alocação com condições explícitas.
- [Etapa Allocation Split](/pt-br/reference/workflow-steps/allocation/allocation-split/) — divide valores de origem entre destinos usando uma tabela de direcionadores.
- [Marcação baseada em regras](/pt-br/reference/workflow-steps/allocation/rule-based-tagging/) — marca linhas com atributos de uma dimensão antes de alocar.

## Relacionados

- [Alocações (guia)](/pt-br/guides/allocations/) — conceitos e fluxos de trabalho completos para problemas de alocação.
- [Dimensões (guia)](/pt-br/guides/dimensions/) — configure as hierarquias para as quais as alocações distribuem valores.
