## Descrição



Divide o valor de uma linha de origem em partes e direciona cada parte para um destino diferente, com proporções determinadas pelos dados do direcionador. Mais simples que a [etapa Allocation Rules](/pt-br/reference/workflow-steps/allocation/allocation-rules/) — use-a quando você só precisa distribuir valores sem uma dimensão de atribuição.

Padrão comum: pegar um valor total, dividi-lo entre vários destinatários com base em percentuais ou pesos de uma tabela de direcionadores e produzir uma linha de saída por destinatário.

## Configurações da tabela de dados

A **Tabela de valores a alocar**, a **Tabela de dados do direcionador** e a **Tabela de resultado da alocação** podem ser selecionadas de forma dinâmica ou estática.

### Seleção dinâmica de tabela
A opção de tabela dinâmica permite especificar uma tabela usando texto e variáveis.  Isso é útil ao empregar
fluxos de trabalho orientados por variáveis, em que as referências a tabelas ou visões são relativas às variáveis especificadas.

Um exemplo que usa a variável `current_month` para apontar dinamicamente para uma tabela:

```text
legal_entity/inputs/{current_month}/ledger_values
```

### Seleção estática de tabela
Quando uma tabela específica é desejada como origem, deixe a caixa *Dynamic* desmarcada e selecione a tabela de origem no menu suspenso.


O Explorador de tabelas está sempre disponível em qualquer seleção de tabela.  Clique no botão Explorador de tabelas à direita da seleção de tabela e uma janela do Explorador de tabelas será aberta.

<Aside>A **Tabela de resultado da alocação** deve ser uma tabela e não uma visão.</Aside>

### Tabela de valores a alocar

Esta é a tabela que contém os valores a serem alocados. Normalmente são valores de custo ou de receita.  


### Tabela de dados do direcionador

A tabela de dados do direcionador contém os valores que a etapa de alocação usará para alocar os custos. 


Exemplos:

- Para uma cadeia de suprimentos atribuir custos a clientes, você poderia usar dados de entregas, com o número de entregas ou o peso das entregas como direcionador.
- Para um help desk de TI atribuir seus custos aos departamentos que ele atende, os dados do direcionador seriam o número de chamados por centro de custo. 

#### Driver Data Sign Rule
Os dados do direcionador podem conter valores positivos e negativos. A opção **Driver Data Sign Rule** permite decidir como os sinais conflitantes serão tratados.
- **Error on conficting signs** - A etapa de alocação gerará um erro e será interrompida se forem encontrados sinais conflitantes.
- **Proceed with warning on conflicting signs** - A etapa de alocação usará valores de direcionador negativos e positivos, mas exibirá um aviso.
- **Use only positive driver values** - A etapa de alocação usará apenas valores de direcionador positivos e ignorará os negativos.
- **Use only negative driver values** - A etapa de alocação usará apenas valores de direcionador negativos e ignorará os positivos.
- **Use absolute values of driver data** - A etapa de alocação usará os valores absolutos dos dados do direcionador.


### Tabela de resultado da alocação



#### Anexar resultados à tabela de destino
Se esta caixa estiver marcada, os resultados da alocação serão anexados à tabela de resultado da alocação. 
Se esta caixa não estiver marcada, a tabela de resultado da alocação será sobrescrita toda vez que a etapa de alocação for executada.

#### Colunas separadas para resultados alocados

Se esta caixa estiver marcada, a tabela de resultado mostrará o valor de cada registro alocado, bem como o valor efetivamente alocado a cada registro do direcionador.
