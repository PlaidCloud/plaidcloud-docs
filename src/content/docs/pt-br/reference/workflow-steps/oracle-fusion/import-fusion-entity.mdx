## Descrição

Importa uma entidade do Oracle Fusion Cloud para uma tabela de projeto por meio da sua [conexão do Oracle Fusion](/pt-br/guides/connections/oracle-fusion/), chamando diretamente os endpoints OData ou BI Publisher (BIP) do Fusion. Escolha a conexão, o tipo de entidade e os filtros desejados; a etapa busca os registros correspondentes e os grava, sem precisar escrever consultas OData.

Para uma carga grande demais para uma chamada direta, use a etapa [Import Fusion Bulk Extract](/pt-br/reference/workflow-steps/oracle-fusion/import-fusion-bulk-extract/).

## Configuração

| Campo | Obrigatório | Observações |
|---|---|---|
| Fusion Connection | Sim | A conexão do Oracle Fusion usada para a leitura. |
| Tabela de destino | Sim | A tabela do projeto em que os resultados são gravados. Ela é totalmente sobrescrita a cada execução. |
| Tipo de entidade | Sim | Qual entidade importar. O padrão é `gl_balances`. Uma entre `gl_balances` e `journal_batches`. |
| Filtros | Não | Filtros de intervalo (`ge`/`le`) em campos de data, período contábil e valores numéricos de saldo/montante, além de filtros de igualdade em campos discretos (razão, moeda). Cada entidade restringe os filtros aos campos que o Oracle Fusion consegue avaliar no servidor — um campo sem suporte é rejeitado, não descartado silenciosamente. |

### Entidades e Campos Filtráveis

| Tipo de entidade | O que importa | Campos filtráveis |
|---|---|---|
| `gl_balances` | Saldos de contas do razão geral | intervalo de período contábil (`ge`/`le`), intervalo de contas, intervalo de valor do saldo (`ge`/`le`) |
| `journal_batches` | Cabeçalhos e status de lotes de lançamentos | intervalo de datas (`ge`/`le`), intervalo de período contábil (`ge`/`le`) |

<Aside type="note">
Um filtro de intervalo precisa de apenas um limite para ser útil — `accounting_date ge 2026-01-01` sem limite superior importa tudo a partir dessa data. Informe os dois limites para restringir bem a carga.
</Aside>
