O PlaidCloud converte fluxos de trabalho do KNIME (`.knwf`) e grupos de fluxos de trabalho (`.knar`)
em fluxos de trabalho avançados nativos. O importador mapeia cada nó do KNIME para uma
etapa do fluxo de trabalho, uma variável de projeto ou um objeto da tela, e nivela metanós e
componentes, de modo que um fluxo de trabalho convertido seja executado nativamente na nuvem.

98,5% das configurações de nós do KNIME são convertidas por completo, e 205 dos 207 tipos
de nós principais têm status Completo. Para executar uma conversão, consulte
[Migrar fluxos de trabalho do KNIME](/pt-br/guides/workflows/migrate-knime-workflows/).

Cada nó tem um status:

- **Completo** — o nó tem um mapeamento válido para etapas do PlaidCloud.
- **Parcial** — o nó é convertido para o uso comum, mas um *modo de recurso*
  distinto não é reproduzido; o modo é nomeado.
- **Não compatível** — sem conversão; o nó permanece na tela como um
  marcador de posição nomeado e o recurso é reconstruído de forma nativa.

As variantes antigas e obsoletas de um nó são listadas sob o nó que as
substitui.

Os poucos comportamentos que um fluxo de trabalho convertido não reproduz estão listados em
[Casos limite conhecidos](#casos-limite-conhecidos).

Um nó conector se torna a conexão do PlaidCloud na qual suas etapas são executadas — consulte
[Conexão com sistemas externos](#conexão-com-sistemas-externos).

Entre os 207 nós principais: 205 Completos, 2 Parciais, 0 Não compatíveis.

## Não convertidos

Um nó sem caminho de conversão é mantido na tela como um marcador de posição nomeado.
O marcador de posição repassa seus dados, adiciona um aviso que nomeia o nó do
KNIME e nunca faz a conversão falhar — uma entrada ausente ou não vinculada é um
aviso, não um erro. Qualquer etapa posterior a um marcador de posição é sinalizada para que
um resultado ausente nunca passe despercebido.

## Conexão com sistemas externos

Um nó conector do KNIME se torna a conexão na qual suas etapas são executadas. As credenciais
nunca são importadas, portanto cada conexão é uma que você escolhe no espaço de trabalho
de destino, e o aviso na etapa indica o que definir.

| KNIME | O que você define no PlaidCloud |
| --- | --- |
| Database connectors | Uma conexão de banco de dados, vinculada na conversão ou escolhida na etapa. |
| REST and web service nodes that sign in | Uma [conexão REST](/pt-br/reference/connectors/rest/generic-rest/), vinculada na conversão ou escolhida na etapa. |
| Speech Recognizer (IBM Watson) | Uma conexão REST com a URL do serviço Watson cujo login Basic é o usuário `apikey` com sua chave de API como senha. |
| Email Connector, Email Reader, Email Mover | A senha do servidor de e-mail, na variável de projeto indicada pelo aviso da etapa. O host e o usuário vêm do Email Connector. |
| Password-protected Excel workbooks | A senha da pasta de trabalho, na variável de projeto indicada pelo aviso da etapa. |
| LLM connectors and authenticators | Uma conexão de LLM na etapa de IA. |
| Views, charts and reporting layout | Nada; esses nós não afetam os dados e são listados no relatório de conversão. |

A conversão nunca entra em contato com um sistema de origem ou de destino.

## Verificação de um fluxo de trabalho convertido

A ordem das linhas e o RowID são mantidos pelos nós que os leem, de modo que um
fluxo de trabalho que depende da ordem das linhas a preserva ao passar por esses nós. Compare a saída do
fluxo de trabalho convertido com a saída do seu fluxo de trabalho do KNIME: esquema, contagem
de linhas e valores das linhas.
