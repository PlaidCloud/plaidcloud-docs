PlaidCloud는 KNIME 워크플로(`.knwf`)와 워크플로 그룹(`.knar`)을
네이티브 고급 워크플로로 변환합니다. 가져오기 도구는 각 KNIME 노드를
워크플로 단계, 프로젝트 변수 또는 캔버스 개체에 매핑하고 메타노드와
컴포넌트를 평탄화하므로, 변환된 워크플로는 클라우드 네이티브로 실행됩니다.

KNIME 노드 구성의 98.5%가 완전히 변환되며, 207개의 핵심
노드 유형 중 205개가 전체 지원입니다. 변환을 실행하려면
[KNIME 워크플로 마이그레이션](/ko/guides/workflows/migrate-knime-workflows/)을 참조하십시오.

각 노드에는 다음 중 하나의 상태가 있습니다.

- **전체** — 노드에 PlaidCloud 단계로의 유효한 매핑이 있습니다.
- **부분** — 노드의 일반적인 용도는 변환되지만, 하나의 별개
  *기능 모드*는 재현되지 않습니다. 해당 모드는 명시되어 있습니다.
- **지원 안 함** — 변환되지 않습니다. 노드는 이름이 표시된
  자리 표시자로 캔버스에 남으며, 해당 기능은 네이티브로 새로 구축해야 합니다.

노드의 이전 버전 및 사용 중단된 변형은 해당 노드를 대체하는
노드 아래에 나열됩니다.

변환된 워크플로가 재현하지 않는 몇 가지 동작은
[알려진 예외 사례](#알려진-예외-사례)에 나열되어 있습니다.

커넥터 노드는 해당 단계가 실행되는 PlaidCloud 연결이 됩니다.
[외부 시스템 연결](#외부-시스템-연결)을 참조하십시오.

## 확장 노드 제품군

KNIME 확장 제품군의 노드도 표준 PlaidCloud 단계로 변환됩니다.
데이터베이스, REST 및 웹 서비스, Python, R, Java 스크립팅, 머신 러닝,
JSON 및 XML, 텍스트 처리, 알림 및 보고, 시계열, 지리 공간, 빅데이터,
이미지 처리, 화학, 워크플로 서비스, 그리고 다수의 핵심 유틸리티 노드가
이에 해당합니다. 변환 경로가 없는 노드는 이름이 표시된 자리 표시자로
유지됩니다. [변환되지 않는 항목](#변환되지-않는-항목)을 참조하십시오.

## 변환되지 않는 항목

변환 경로가 없는 노드는 이름이 표시된 자리 표시자로 캔버스에 유지됩니다.
자리 표시자는 데이터를 그대로 전달하고, KNIME 노드의 이름을 알리는 경고를
추가하며, 변환을 실패시키지 않습니다. 누락되었거나 바인딩되지 않은 입력은
오류가 아니라 경고입니다. 자리 표시자 다음에 오는 모든 단계에는 표시가
붙으므로 누락된 결과가 조용히 넘어가는 일은 없습니다.

## 외부 시스템 연결

KNIME 커넥터 노드는 해당 단계가 실행되는 연결이 됩니다. 자격 증명은
가져오지 않으므로 각 연결은 대상 워크스페이스에서 직접 선택해야 하며,
단계의 경고에 설정할 항목이 표시됩니다.

| KNIME | PlaidCloud에서 설정할 항목 |
| --- | --- |
| Database connectors | 변환할 때 바인딩하거나 단계에서 선택하는 데이터베이스 연결. |
| REST and web service nodes that sign in | 변환할 때 바인딩하거나 단계에서 선택하는 [REST 연결](/ko/reference/connectors/rest/generic-rest/). |
| Speech Recognizer (IBM Watson) | Watson 서비스 URL에 대한 REST 연결. 기본 로그인은 사용자 `apikey`이며 비밀번호는 사용자의 API 키입니다. |
| Email Connector, Email Reader, Email Mover | 단계의 경고에 표시된 프로젝트 변수에 입력하는 메일 서버 비밀번호. 호스트와 사용자는 Email Connector에서 가져옵니다. |
| Password-protected Excel workbooks | 단계의 경고에 표시된 프로젝트 변수에 입력하는 통합 문서 비밀번호. |
| LLM connectors and authenticators | AI 단계의 LLM 연결. |
| Views, charts and reporting layout | 없음. 이 노드들은 데이터에 영향이 없으며 변환 보고서에 나열됩니다. |

변환은 소스 또는 대상 시스템에 접속하지 않습니다.

| Loop End (Column Append) | [테이블: 내부 조인](/ko/reference/workflow-steps/tables/table-inner-join/)으로 변환됩니다. 아직 재현되지 않는 항목: KNIME과 결과가 다른 몇 가지 설정 조합. |
| Row Sampler, Table Partitioner, Equal Size Sampling | 시드가 지정된 무작위 추출은 [Table: KNIME Random Sample](/ko/reference/workflow-steps/tables/table-knime-random-sample/)을 사용하여 KNIME과 동일한 행을 선택합니다. 이 추출은 최대 10,000,000행의 테이블을 대상으로 합니다. |

## 변환된 워크플로 확인

행 순서와 RowID는 이를 읽는 노드를 거치면서 그대로 유지되므로, 행 순서에
의존하는 워크플로는 해당 노드를 거쳐도 순서가 유지됩니다. 변환된 워크플로의
출력을 KNIME 워크플로의 출력과 비교하십시오. 스키마, 행 수, 행 값을
비교합니다.
