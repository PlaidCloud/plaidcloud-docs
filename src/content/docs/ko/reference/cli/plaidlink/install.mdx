## 에이전트 다운로드

[PlaidCloud.com](https://plaidcloud.com/)의 릴리스에서 **PlaidLink**를 확인합니다.

## 에이전트 압축 풀기

다운로드한 zip 파일의 압축을 원하는 설치 위치에 풉니다. 일반적으로 다음 위치를 사용합니다.

```bash
C:\Users\<Username here>\src\plaidlink
```

## 구성 파일 만들기

<Aside>이전 버전의 에이전트에서 업그레이드하는 경우 기존 구성 파일을 그대로 사용할 수 있으므로 이 단계를 건너뛰어도 됩니다</Aside>

에이전트 디렉터리에 있는 `config-dist.yaml` 파일을 `%ProgramData\plaidcloud\`로 복사하고 복사본의 이름을 `config.yaml`로 바꿉니다.

*(PlaidCloud에서 가져온 값으로 이 구성을 편집합니다)*

## 에이전트 서비스 설치

에이전트 설치 디렉터리에서 `install_windows_service.bat` 파일을 실행하거나

관리자 권한 명령 프롬프트에서 에이전트 설치 디렉터리로 이동한 다음 다음 명령을 실행합니다.

```bash
.\PlaidLink.exe install
```

## 에이전트 실행

<Aside>Windows 서비스를 설치하려면 관리자 권한이 있어야 합니다</Aside>

Windows 검색 창에 **`Services`** 를 입력하고 서비스 관리자를 엽니다. 서비스 목록에서 **`PlaidCloud Agent`** 를 찾습니다.

서비스를 마우스 오른쪽 단추로 클릭하고 **"시작"** 을 선택하여 에이전트를 시작합니다.

## 업데이트 고정

에이전트의 자동 업데이트 기능을 비활성화하려면 에이전트의 **'yaml'** 구성 파일을 열고 
파일 최상위 수준에 `freeze_updates: true` 줄을 추가한 다음 에이전트 서비스를 다시 시작합니다. 

<Aside type="caution">자동 업데이트를 장기간 비활성화하는 것은 권장하지 않습니다</Aside>
