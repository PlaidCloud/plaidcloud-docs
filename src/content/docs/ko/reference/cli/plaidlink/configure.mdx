PlaidLink 에이전트는 PlaidCloud 서비스와 함께 작동합니다. PlaidLink 에이전트는 데이터베이스와 파일 시스템처럼 직접 접근할 수 없는 시스템과 연동하는 데 필요한 연결을 제공합니다. 에이전트는 다음과 같은 여러 핵심 작업을 수행합니다.

* 데이터베이스 읽기 및 쓰기
* 네트워크 드라이브와 서버에 파일 읽기 및 쓰기
* 센서 조건 확인
* 원격 함수 호출(RFC)을 통한 SAP ECC 및 SAP S/4HANA와의 연동
* SAP Profitability and Cost Management(PCM)와의 연동
* 원격 시스템에 메시지와 알림 전송

## PlaidCloud에서 에이전트 만들기

PlaidLink 에이전트 관리는 PlaidCloud의 Analyze 탭에서 이루어집니다. 첫 단계는 PlaidCloud에서 새 PlaidLink 에이전트 인스턴스를 만드는 것입니다.

### 새 PlaidLink 에이전트를 만들려면

1. Analyze 탭을 선택합니다
2. 상단의 도구 메뉴를 선택합니다
3. PlaidLink Agents를 클릭합니다
4. 원격 작업을 위해 에이전트를 설치할 환경이나 서버에 맞는 이름으로 새 에이전트를 만듭니다

### 에이전트의 공개 키와 개인 키를 보려면

1. 편집 아이콘을 클릭하여 양식을 엽니다
2. 양식 맨 아래에서 에이전트를 만드는 과정에서 무작위로 생성된 공개 키와 개인 키를 확인할 수 있습니다

<Aside>이 키는 원격 서버의 에이전트 구성에 사용되므로 잘 기록해 두십시오.</Aside>

### 새 키를 무작위로 생성하려면

1. 에이전트 레코드의 다시 생성 아이콘을 클릭합니다
2. 키가 다시 생성되면 원격 서버의 에이전트 구성 파일을 새 키로 업데이트하는 것을 잊지 마십시오.

<Aside>다음 단계에서 원격 에이전트를 구성할 때 사용하므로 공개 키와 개인 키를 보관해 두십시오.</Aside>

## 문서 계정 접근

에이전트가 파일을 업로드하거나 다운로드하기 위해 문서 계정에 접근해야 하는 경우, 해당 문서 계정에 접근할 권한을 부여해야 합니다.

### 계정 접근 권한을 부여하려면

1. Document 탭에서 Manage Accounts를 선택합니다
2. 계정 테이블이 나타나면 새 에이전트에 업로드/다운로드 권한을 부여할 계정의 에이전트 아이콘을 클릭합니다
3. 새 에이전트를 Assigned Agents 열로 끌어다 놓습니다
4. 접근 제어 양식을 저장합니다.

<Aside>에이전트는 하나 이상의 문서 계정에 대한 접근 권한이 부여된 경우에만 파일을 업로드하고 다운로드할 수 있습니다.</Aside>

## 데이터 연결 접근

에이전트가 데이터베이스와 같은 데이터 연결에 접근해야 하는 경우, 외부 데이터 연결 정보에 접근할 권한을 부여해야 합니다.


### 연결 접근 권한을 부여하려면


1. Analyze 탭에서 Tools 메뉴를 선택합니다
2. External Data Connections를 클릭합니다
3. 데이터 연결 테이블이 나타나면 새 에이전트에 사용 권한을 부여할 연결의 에이전트 아이콘을 클릭합니다
4. 새 에이전트를 Assigned Agents 열로 끌어다 놓고 접근 제어 양식을 저장합니다.

<Aside>에이전트 데이터 연결 자격 증명은 External Data Connections에서 관리합니다.</Aside>
