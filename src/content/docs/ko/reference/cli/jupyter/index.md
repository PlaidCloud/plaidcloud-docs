PlaidCloud의 Jupyter 연동을 사용하면 데이터 과학자가 노트북 환경에서 프로젝트 테이블을 다루고, 쿼리를 실행하고, PlaidCloud를 백업 저장소로 사용할 수 있습니다. 인증에는 OAuth 토큰을 사용하므로 CLI, 노트북, REST API에서 같은 자격 증명을 사용할 수 있습니다.

## 주제

- [명령줄](/ko/reference/cli/jupyter/command-line/) — 스크립트 방식 상호작용을 위한 독립 실행형 CLI
- [Jupyter 노트북](/ko/reference/cli/jupyter/jupyter-notebook/) — 노트북 셀에서 PlaidCloud 사용
- [OAuth 설정](/ko/reference/cli/jupyter/oauth-setup/) — 인증 구성
