[로그인](/ko/reference/cli/plaidxl/connect/)하면 작업 창에 프로젝트가 나열됩니다. 프로젝트를 선택한 다음 해당 프로젝트의 테이블과 차원을 통합 문서로 가져옵니다.

## 프로젝트 선택

**프로젝트** 섹션에는 PlaidCloud에서 보는 것과 같은 폴더 구조로 열 수 있는 모든 프로젝트가 나열됩니다. 폴더는 접힌 상태로 시작하며, 클릭하여 열거나 **Filter projects by name**에 입력하여 목록을 좁힐 수 있습니다.

프로젝트를 클릭하여 선택합니다. 해당 프로젝트의 테이블은 **테이블** 탭에, 차원은 **차원** 탭에 표시됩니다.

선택한 프로젝트는 PlaidXL [사용자 지정 함수](/ko/reference/cli/plaidxl/functions/)와 드릴 명령이 데이터를 읽는 프로젝트이기도 합니다. 이 선택은 현재 통합 문서뿐 아니라 열려 있는 모든 통합 문서에 적용됩니다.

### 기본 프로젝트 설정

통합 문서의 작업 창을 열 때마다 같은 프로젝트가 선택되도록 하려면 프로젝트를 선택하고 **기본값으로 설정**을 클릭합니다. 기본값은 통합 문서에 저장되므로 파일을 여는 모든 사용자에게 함께 전달됩니다. **Clear Default**를 클릭하면 제거됩니다.

## 테이블 가져오기

1. **테이블** 탭에서 테이블을 클릭합니다. 긴 목록에서 테이블을 찾으려면 **Filter tables by name**을 사용합니다. 각 테이블 옆의 **행**과 **열**은 테이블의 크기를 알려 줍니다.
2. **열** 아래에서 필요하지 않은 열의 확인란을 선택 해제합니다. 처음에는 모든 열이 선택되어 있습니다.
3. 일부 행만 가져오려면 **고급**을 선택하고 필터를 작성합니다. [행 필터링](#행-필터링)을 참조하십시오.
4. **Select where to place this table**에서 다음 중 하나를 선택합니다.
   - **Matching Worksheet** — 테이블 이름을 딴 워크시트입니다. 시트가 없으면 PlaidXL이 만들고, 있으면 A1 셀부터 테이블을 씁니다.
   - **Current Selection** — 활성 시트에서 선택한 셀부터 시작합니다.
5. **Retrieve Table**을 클릭합니다.

데이터는 머리글 행과 함께 바로 사용할 수 있는 상태로 도착합니다. 머리글 행은 굵게 표시되고 음영이 적용되며, 열 너비는 내용에 맞게 조정되고 필터가 켜집니다. **Matching Worksheet**로 가져온 테이블에는 다음도 추가됩니다.

- 스크롤해도 계속 보이도록 고정된 머리글 행.
- 데이터 위의 이름이 지정된 범위. 이를 사용하는 수식은 새로 고칠 때 데이터가 늘어나는 대로 따라갑니다. 이름은 워크시트 이름 앞에 밑줄을 붙인 것입니다. **Sample data**라는 테이블은 `Sample_data` 시트에 놓이며 이름이 지정된 범위는 `_Sample_data`입니다.

워크시트 이름을 정할 때 PlaidXL은 테이블 이름을 Excel의 한도인 31자로 자르고, 일반 영문자(A–Z), 숫자, 공백만 남기며, 공백을 밑줄로 바꿉니다. **Q3 Revenue (EMEA)** 라는 테이블은 `Q3_Revenue_EMEA` 시트로 가져옵니다. 밑줄과 악센트가 있는 문자도 제거되므로 **sales_2024**는 `sales2024` 시트로 가져옵니다.

<Aside type="tip">열이 많은 테이블은 Excel로 로드하는 속도가 느립니다. 필요하지 않은 열을 선택 해제하는 것이 대용량 가져오기를 빠르게 하는 가장 쉬운 방법입니다.</Aside>

### 빨간색으로 표시되는 테이블

테이블이 워크시트에 비해 너무 크거나(행이 1,048,576개를 초과하거나 열이 16,384개를 초과), 한 번도 로드된 적이 없는 테이블처럼 PlaidCloud가 크기를 보고할 수 없으면 테이블이 빨간색으로 표시됩니다. 크기가 맞을 때까지 **고급**으로 행을 필터링하고 열을 선택 해제하십시오. PlaidXL은 머리글 행 외에 최대 1,048,575개의 행을 가져오며, 경고 없이 거기에서 중단합니다.

## 행 필터링

**고급**을 선택하면 필터 작성기가 열립니다. 각 규칙은 열, **같음**, **in**, **포함**, **시작 문자**, **비어 있음** 같은 비교 방식, 값을 선택합니다. **AND** 그룹, **OR** 그룹 또는 둘 다를 사용하여 규칙을 결합합니다.

필터는 값을 텍스트로 비교하므로 정확한 값과 텍스트 패턴에 일치합니다. 숫자나 날짜 범위는 사용할 수 없습니다. 범위를 가져오려면 **in**으로 필요한 값을 필터링하거나 테이블을 가져온 다음 Excel에서 필터링하십시오.

- 값은 따옴표 없이 입력합니다. `"EMEA"`가 아니라 `EMEA`입니다.
- **in**처럼 여러 값을 받는 비교에서는 값을 쉼표와 공백으로 구분합니다. `EMEA, APAC, NA`
 
필터는 **고급**을 선택한 동안에만 적용됩니다. PlaidXL은 가져온 각 테이블에 대해 선택한 필터와 열을 기억하고 새로 고칠 때 다시 사용합니다.

## 모든 테이블 새로 고침

작업 창 또는 리본의 **PlaidCloud → PlaidXL Controls**에 있는 **Refresh All Tables**는 통합 문서로 가져온 모든 테이블에 대해 각각 선택한 열과 필터를 적용하여 PlaidCloud의 최신 데이터를 가져옵니다.

실행되는 동안 각 테이블의 워크시트 탭이 노란색으로 바뀌고, 해당 테이블이 최신 상태가 되면 녹색으로 바뀝니다. 데이터를 사용하는 수식은 평소처럼 다시 계산되며, 그 데이터로 만든 피벗 테이블은 Excel의 **데이터 → 모두 새로 고침**으로 새로 고칩니다.

PlaidXL은 가져온 테이블 목록을 통합 문서에 저장하므로, 같은 프로젝트에 액세스할 수 있는 상태로 로그인한 사용자라면 누구나 파일을 열어 **Refresh All Tables**를 사용할 수 있습니다.

**Retrieve Table**을 실행할 때마다 해당 테이블이 새로 고침 목록에 추가되며 목록에서 하나를 제거할 방법은 없습니다. 각 테이블은 한 번만 가져온 다음 **Refresh All Tables**로 업데이트하십시오. 같은 테이블을 다시 가져오면 새로 고칠 때마다 두 번 가져오게 됩니다.

<Aside type="caution">
**Current Selection**으로 가져온 테이블은 **Refresh All Tables**를 클릭할 때 **활성 상태인 시트**의 같은 셀로 새로 고쳐지며 그 위치에 있던 내용을 덮어씁니다. 새로 고칠 계획인 테이블은 **Matching Worksheet**로 가져오십시오. 이 테이블은 항상 자신의 시트로 새로 고쳐집니다.

새로 고침은 이전 데이터를 먼저 지우지 않고 그 위에 씁니다. 테이블의 행이나 열이 이전보다 줄어들었다면 이전에 가져온 추가 행이나 열이 시트에 그대로 남습니다. 줄어들었을 수 있는 테이블을 새로 고치기 전에 시트의 내용을 지우십시오.
</Aside>

## 차원 가져오기

**차원** 탭에는 프로젝트의 [차원](/ko/guides/dimensions/dimensions/)이 나열됩니다.

1. 차원을 클릭합니다. **Filter dimensions by name**을 사용하여 차원을 찾습니다.
2. **Select where to place this dimension**에서 **Matching Worksheet** 또는 **Current Selection**을 선택합니다.
3. **Retrieve Dimension**을 클릭합니다.

PlaidXL은 차원의 노드를 계층 순서대로 하나의 열로 씁니다. 차원에는 열 또는 행 필터가 없으며 **Refresh All Tables**로 새로 고쳐지지 않습니다. 변경 사항을 반영하려면 차원을 다시 가져오십시오.

들여쓰기와 Excel 윤곽 그룹화로 계층을 배치하거나 특정 노드 또는 대체 계층에서 시작하려면 대신 [`PLAIDXL.DIMENSION.GET_DIMENSION`](/ko/reference/cli/plaidxl/functions/#get_dimension) 또는 [드릴 명령](/ko/reference/cli/plaidxl/ribbon/#drill-functions)을 사용하십시오.

## 데이터 변경

PlaidXL은 PlaidCloud에서 데이터를 읽기만 하고 다시 쓰지 않습니다. 가져온 시트를 자유롭게 편집하고 정렬하고 수식을 추가해도 프로젝트에는 아무 변화가 없습니다. 새로 고침은 테이블 범위 위에 PlaidCloud의 현재 데이터를 덮어쓰므로 자체 계산은 별도의 시트에 두십시오.

데이터 자체를 변경하려면 PlaidCloud에서 업데이트하십시오. 예를 들어 [워크플로](/ko/guides/workflows/) 또는 [데이터 편집기](/ko/guides/projects/managing-data-editors/)를 사용합니다.
