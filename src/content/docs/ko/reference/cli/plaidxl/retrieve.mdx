[로그인](/ko/reference/cli/plaidxl/connect/)하면 작업 창에 프로젝트 목록이 표시됩니다. 프로젝트를 선택한 다음 해당 프로젝트의 테이블과 차원을 통합 문서로 가져옵니다.

## 프로젝트 선택

작업 창 머리글에는 워크스페이스와 이 통합 문서에 연결된 프로젝트가 표시됩니다. 프로젝트 이름을 클릭하면 열 수 있는 모든 프로젝트가 PlaidCloud와 같은 폴더 구성으로 표시되는 프로젝트 목록이 열립니다. 폴더는 접힌 상태로 시작하며, 폴더를 클릭하여 열거나 **Filter projects by name**에 입력하여 목록을 좁힐 수 있습니다.

프로젝트를 클릭하면 선택됩니다. 해당 프로젝트의 테이블은 **Tables** 탭에, 차원은 **Dimensions** 탭에 표시됩니다.

### 프로젝트는 통합 문서에 속합니다

선택한 프로젝트는 통합 문서에 저장되므로 통합 문서마다 고유한 프로젝트가 있습니다. 해당 통합 문서에서 PlaidXL [사용자 지정 함수](/ko/reference/cli/plaidxl/functions/)와 드릴 명령이 읽는 프로젝트입니다. 통합 문서 두 개를 열면 각각 자신의 프로젝트에서 읽으며, 통합 문서를 다시 열면 작업 창이 해당 프로젝트로 돌아갑니다. 프로젝트는 파일과 함께 이동하므로, 파일을 열고 해당 프로젝트에 대한 액세스 권한으로 로그인하는 모든 사용자에게 적용됩니다.

프로젝트는 하나의 워크스페이스에 속합니다. [워크스페이스를 전환](/ko/reference/cli/plaidxl/connect/#로그아웃-또는-워크스페이스-전환)하면, 이전 워크스페이스의 프로젝트에 연결된 통합 문서는 다른 프로젝트를 선택할 때까지 프로젝트가 없는 상태가 됩니다. 이전 워크스페이스에서 가져온 테이블은 통합 문서에 남아 있지만 **Refresh All Tables**에서 건너뛰며, 작업 창에 건너뛴 개수가 표시됩니다. 새 워크스페이스에서 다시 가져오면 연결됩니다.

## 테이블 가져오기

1. **Tables** 탭에서 테이블을 클릭합니다. 목록이 긴 경우 **Filter tables by name**을 사용하여 찾습니다. 각 테이블 옆의 **Rows**와 **Columns**는 테이블의 크기를 알려 줍니다.
2. **Column**에서 필요하지 않은 열의 확인란을 선택 해제합니다. 처음에는 모든 열이 선택되어 있습니다.
3. 일부 행만 가져오려면 **Advanced**를 선택하고 필터를 만듭니다. [행 필터링](#행-필터링)을 참조하십시오.
4. **Select where to place this table**에서 다음 중 하나를 선택합니다.
   - **Matching Worksheet** — 테이블 이름을 딴 워크시트입니다. 시트가 없으면 PlaidXL이 만들고, 있으면 셀 A1부터 테이블을 씁니다.
   - **Current Selection** — 활성 시트에서 선택한 셀부터 시작합니다.
5. **Retrieve Table**을 클릭합니다.

데이터는 머리글 행과 함께 도착하여 바로 작업할 수 있습니다. 머리글 행은 굵게 표시되고 음영이 적용되며, 열 너비는 내용에 맞게 조정되고 필터가 켜집니다. **Matching Worksheet**로 가져온 테이블에는 다음도 추가됩니다.

- 고정된 머리글 행. 스크롤해도 계속 표시됩니다.
- 데이터에 대한 이름 있는 범위. 이를 사용하는 수식이 새로 고칠 때 데이터가 늘어나는 대로 따라갑니다. 이름은 워크시트 이름 앞에 밑줄을 붙인 것입니다. **Sample data**라는 테이블은 시트 `Sample_data`에 놓이고 이름 있는 범위는 `_Sample_data`가 됩니다.

워크시트 이름을 정하기 위해 PlaidXL은 테이블 이름을 Excel 한도인 31자로 자르고, 일반 영문자(A–Z), 숫자, 공백만 남기고, 공백을 밑줄로 바꿉니다. **Q3 Revenue (EMEA)** 라는 테이블은 시트 `Q3_Revenue_EMEA`로 가져옵니다. 밑줄과 악센트 문자도 제거되므로 **sales_2024**는 시트 `sales2024`로 가져옵니다.

<Aside type="tip">열이 많은 테이블은 Excel로 로드하는 속도가 느립니다. 필요하지 않은 열을 선택 해제하는 것이 대규모 가져오기를 가장 빠르게 만드는 방법입니다.</Aside>

### 빨간색으로 표시된 테이블

테이블이 워크시트에 비해 너무 크거나(1,048,576행 또는 16,384열 초과), 한 번도 로드된 적 없는 테이블처럼 PlaidCloud가 크기를 보고할 수 없으면 테이블이 빨간색으로 표시됩니다. 크기가 맞을 때까지 **Advanced**로 행을 필터링하고 열을 선택 해제하십시오. PlaidXL은 최대 1,048,575행과 머리글 행을 가져오며, 경고 없이 거기서 멈춥니다.

## 행 필터링

**Advanced**를 선택하여 필터 작성기를 엽니다. 각 규칙은 열, **equal**, **in**, **contains**, **begins with**, **is empty** 같은 비교 방식, 값을 선택합니다. **AND** 그룹, **OR** 그룹 또는 둘 다를 사용하여 규칙을 결합합니다.

필터는 값을 텍스트로 비교하므로 정확한 값과 텍스트 패턴과 일치합니다. 숫자나 날짜 범위는 사용할 수 없습니다. 범위를 가져오려면 **in**으로 필요한 값을 필터링하거나, 테이블을 가져온 뒤 Excel에서 필터링하십시오.

- 값은 따옴표 없이 입력합니다. `"EMEA"`가 아니라 `EMEA`입니다.
- **in**처럼 여러 값을 받는 비교에서는 쉼표와 공백으로 값을 구분합니다. `EMEA, APAC, NA`처럼 입력합니다.

필터는 **Advanced**가 선택된 동안에만 적용됩니다. PlaidXL은 가져온 각 테이블에 대해 필터와 선택한 열을 기억하고 새로 고칠 때 다시 사용합니다.

## Refresh All Tables

**Refresh All Tables**는 작업 창 또는 리본의 **PlaidCloud → Data**에 있으며, 통합 문서로 가져온 모든 테이블에 대해 각 테이블에 선택한 열과 필터로 PlaidCloud에서 최신 데이터를 가져옵니다.

실행되는 동안 각 테이블의 워크시트 탭이 노란색으로 바뀝니다. 해당 테이블이 최신 상태가 되면 녹색으로 바뀝니다. 데이터를 사용하는 수식은 평소처럼 다시 계산됩니다. 이 데이터로 만든 피벗 테이블은 Excel의 **Data → Refresh All**로 새로 고치십시오.

PlaidXL은 가져온 테이블 목록을 통합 문서에 저장하므로, 파일을 열고 같은 프로젝트에 대한 액세스 권한으로 로그인하는 모든 사용자가 **Refresh All Tables**를 사용할 수 있습니다.

**Retrieve Table**을 실행할 때마다 테이블이 새로 고침 목록에 추가되며, 목록에서 제거하는 방법은 없습니다. 각 테이블은 한 번만 가져온 다음 **Refresh All Tables**로 업데이트하십시오. 같은 테이블을 다시 가져오면 새로 고칠 때마다 두 번 가져옵니다.

<Aside type="caution">
**Current Selection**으로 가져온 테이블은 **Refresh All Tables**를 클릭할 때 **활성 상태인 시트**의 같은 셀로 새로 고쳐지며, 그 자리에 있는 내용을 덮어씁니다. 새로 고칠 테이블은 **Matching Worksheet**로 가져오십시오. 이러한 테이블은 항상 자신의 시트에서 새로 고쳐집니다.

새로 고침은 이전 데이터를 지우지 않고 그 위에 덮어씁니다. 테이블의 행이나 열이 이전보다 줄었다면 이전에 가져온 추가 행이나 열이 시트에 남습니다. 줄어들었을 수 있는 테이블을 새로 고치기 전에 시트의 내용을 지우십시오.
</Aside>

## 차원 가져오기

**Dimensions** 탭에는 프로젝트의 [차원](/ko/guides/dimensions/dimensions/)이 나열됩니다.

1. 차원을 클릭합니다. **Filter dimensions by name**을 사용하여 찾습니다.
2. **Select where to place this dimension**에서 **Matching Worksheet** 또는 **Current Selection**을 선택합니다.
3. **Retrieve Dimension**을 클릭합니다.

PlaidXL은 차원의 노드를 계층 순서대로 열 하나에 씁니다. 차원에는 열 또는 행 필터가 없으며 **Refresh All Tables**도 차원을 새로 고치지 않습니다. 변경 사항을 반영하려면 차원을 다시 가져오십시오.

들여쓰기와 Excel 윤곽 그룹으로 계층을 배치하거나 특정 노드 또는 대체 계층에서 시작하려면 대신 [`PLAIDXL.DIMENSION.GET_DIMENSION`](/ko/reference/cli/plaidxl/functions/#get_dimension) 또는 [드릴 명령](/ko/reference/cli/plaidxl/ribbon/#drill-functions)을 사용하십시오.

## 테이블을 PlaidCloud에 저장

통합 문서로 가져온 테이블은 PlaidCloud 테이블을 시트에 있는 내용으로 바꾸는 방식으로 다시 저장할 수 있습니다.

1. 가져온 테이블이 있는 워크시트로 이동합니다. 작업 창의 **Save this sheet to PlaidCloud** 아래에 활성 시트에 연결된 각 테이블이 행 수와 함께 나열됩니다. 시트에 테이블이 없으면 먼저 그곳에 테이블을 가져오라는 메시지가 표시됩니다.
2. 테이블 옆의 **Save to PlaidCloud…** 버튼을 클릭합니다.
3. 테이블, 쓸 행 수, 열을 보여 주는 확인 메시지를 읽은 다음 **Replace table**을 클릭합니다.

PlaidXL은 테이블을 가져온 위치에서 머리글 행과 그 아래 행을 읽습니다. 머리글은 가져온 열과 여전히 일치해야 하며, 값은 각 열의 데이터 유형으로 변환됩니다. 값을 변환할 수 없으면 아무것도 쓰지 않고 실패한 행을 나열합니다. PlaidCloud의 열 정의는 그대로 유지됩니다.

### 저장되는 내용

- 빈 셀과 오류가 표시된 셀은 빈 값으로 저장됩니다.
- 테이블 바로 아래에 추가한 행은 첫 번째 빈 행까지 포함됩니다.
- 가져온 행 안에 있는 단일 빈 행은 건너뛰며, 그 주변 행은 그대로 저장됩니다. 아래에 데이터가 있는 상태에서 빈 행이 연속으로 둘 이상이면 저장이 중단되고 삭제하거나 채워야 할 행을 알려 줍니다.

### 테이블을 바꾸기 전에

- **필터링된 테이블.** 필터를 사용하여 테이블을 가져온 경우, 필터에서 제외된 모든 행이 PlaidCloud에서 삭제됩니다. 확인 메시지가 이를 알려 주며, **Replace table**이 활성화되기 전에 확인란을 선택하도록 요청합니다.
- **가져오지 않은 열.** 일부 열만 가져온 경우 PlaidXL이 **Empty columns that were not retrieved?** 라고 묻고 해당 열의 이름을 알려 줍니다. PlaidCloud에서 해당 열을 비우려면 **Write anyway**를 클릭하고, 아무것도 쓰지 않으려면 취소합니다.
- **다른 사람이 테이블을 변경한 경우.** PlaidCloud가 확인할 수 있는 경우, 테이블을 가져온 후 변경되었다면 저장이 거부됩니다. 테이블을 다시 가져와 편집 내용을 다시 적용하십시오. 확인할 수 없는 경우 확인 메시지가 그렇다고 알려 주며, 테이블을 가져온 이후 다른 사람이 저장한 내용은 덮어씁니다.
- **복원 지점.** PlaidXL은 쓰기 전에 복원 지점을 만들고 7일 동안 보관합니다. 쓰기가 실패하면 테이블이 원래 상태로 복구됩니다. 복원 지점을 만들 수 없는 테이블은 **Write back without a restore point?** 라고 묻고, **Write anyway**를 클릭하면 복원 지점 없이 진행합니다.

저장에 성공하면 확인 메시지에 **Restore previous version**이 포함됩니다. 이를 클릭하면 PlaidCloud에서 테이블이 열리며, **As of** 메뉴에서 이번 저장 직전의 버전을 선택합니다.
