PlaidXL을 설치하면 Excel 리본에 **PlaidCloud** 탭이 추가되며, 여기에는 **연결**, **삽입**, **새로 고침**, **Drill**, **쓰기**, **공유**의 여섯 가지 명령 그룹이 있습니다. 자주 사용하는 명령은 **PlaidXL** 마우스 오른쪽 클릭 메뉴와 **PlaidXL Cell** 탭에도 있으며, 키보드 단축키가 있는 모든 명령은 툴팁에 단축키가 표시됩니다.

비활성화되는 명령은 없습니다. 명령은 선택한 셀에서 가장 가까운 PlaidXL 수식, 테이블, 노드에 대해 작동하며, 작업할 대상이 없으면 대신 도움이 되는 작업 창 부분을 엽니다.

로그아웃된 상태이거나 통합 문서가 프로젝트에 연결되기 전에 명령을 실행하면 PlaidXL이 작업 창을 열고 명령을 실행하려면 **Sign in to run** 또는 **Pick a project to run**이라고 안내합니다. 로그인하거나 프로젝트를 선택하면 시작한 셀에서 명령이 실행됩니다. 그 사이에 다른 시트로 이동했거나 다른 프로젝트를 선택했다면 명령이 실행되지 않으며 PlaidXL이 그 사실을 알려 줍니다.

## 연결

| 명령 | 기능 |
|---|---|
| **Open PlaidXL** | PlaidXL 작업 창을 엽니다. |
| **계정** | 작업 창을 열어 로그인하거나 워크스페이스와 프로젝트를 선택합니다. |
| **Shortcuts** | PlaidXL 키보드 단축키를 나열하며 변경할 수 있습니다. [키보드 단축키](#키보드-단축키)를 참조하십시오. |
| **Help** | 이 문서를 엽니다. |

## 삽입

| 명령 | 기능 |
|---|---|
| **테이블...** | **테이블** 탭을 열어 [테이블을 가져옵니다](/ko/reference/cli/plaidxl/retrieve/#테이블-가져오기). |
| **차원...** | **차원** 탭을 열어 차원을 가져오거나 구성원을 선택합니다. |
| **Formula...** | **Formulas** 탭을 열어 선택한 셀에 사용할 [PlaidXL 수식을 작성합니다](/ko/reference/cli/plaidxl/functions/#작업-창에서-수식-삽입). |
| **Pick member...** | 선택한 셀의 차원에 대해 구성원 선택기를 엽니다. [구성원 선택](/ko/reference/cli/plaidxl/drill/#멤버-선택)을 참조하십시오. |
| **Metric...** | 프로젝트의 지표를 현재 값과 함께 검색 가능한 목록으로 엽니다. [지표 삽입](/ko/reference/cli/plaidxl/functions/#지표-삽입)을 참조하십시오. |
| **Build report...** | **보고서** 탭을 열어 라이브 보고서를 배치합니다. [보고서 작성](/ko/reference/cli/plaidxl/build-a-report/)을 참조하십시오. |
| **Weave에 문의...** | 선택한 셀을 컨텍스트로 하여 **Weave** 탭을 엽니다. [Excel에서 Weave에 문의](/ko/reference/cli/plaidxl/weave/)를 참조하십시오. |

## 새로 고침

**새로 고침** 메뉴에는 명령이 네 개 있습니다.

| 명령 | 기능 |
|---|---|
| **Refresh this sheet** | 활성 시트의 PlaidXL 수식을 다시 계산하고 해당 시트의 테이블을 다시 가져옵니다. |
| **Refresh selection** | 선택 영역의 PlaidXL 수식을 다시 계산하고 선택 영역이 닿는 테이블을 다시 가져옵니다. PlaidXL 항목이 선택되어 있지 않으면 시트를 새로 고칩니다. |
| **Refresh all tables** | 통합 문서의 모든 테이블과 차원을, 각각에 대해 선택한 열과 필터로 다시 가져옵니다. |
| **Recalculate PlaidXL formulas** | 통합 문서의 모든 PlaidXL 수식을 다시 계산합니다. |

새로 고침이 실행되는 동안 표시되는 내용은 [테이블 새로 고침](/ko/reference/cli/plaidxl/retrieve/#refresh-all-tables)을 참조하십시오.

**Recalculate PlaidXL formulas**는 Excel 전체 재계산 없이 PlaidXL 수식만 다시 계산합니다. 완료되면 다시 계산한 시트를 나열하고 Excel의 실행 취소 기록을 지웁니다. PlaidXL은 테이블의 열 세부 정보를 30초 동안 유지하므로, 최근 30초 이내에 이름을 바꾼 열이나 차원은 표시되는 데 시간이 조금 더 걸릴 수 있습니다.

## Drill

| 명령 | 기능 |
|---|---|
| **Drill down** | 메뉴입니다. **One level**, **To lowest level**, **All levels**, **Custom drill...** 이 선택한 노드 아래의 노드를 배치합니다. |
| **Drill up** | 선택한 노드를 부모로 접습니다. |
| **Keep only** | 드릴에서 선택한 노드만 유지합니다. |
| **Remove only** | 선택한 노드와 그 아래의 모든 항목을 드릴에서 제거합니다. |
| **Show detail rows** | 선택한 값 뒤의 테이블 행을 별도의 시트에 표시합니다. |
| **Explain this number** | 선택한 값이 어디에서 나왔는지 보여 줍니다. |

셀 하나를 선택하여 드릴합니다. 드릴 명령은 해당 셀을 라이브 `PLAIDXL.DRILL` 수식으로 바꿉니다. [드릴, 구성원 선택, 숫자 설명](/ko/reference/cli/plaidxl/drill/)을 참조하십시오.

## 쓰기

| 명령 | 기능 |
|---|---|
| **Save sheet to PlaidCloud...** | 이 시트로 가져온 테이블을 즉시 PlaidCloud에 다시 씁니다. [테이블을 PlaidCloud에 저장](/ko/reference/cli/plaidxl/retrieve/#테이블을-plaidcloud에-저장)을 참조하십시오. |
| **Undo last write** | PlaidCloud에 마지막으로 입력한 값 또는 마지막 저장을 최신순으로 실행 취소합니다. [쓰기 실행 취소](/ko/reference/cli/plaidxl/write-values/#쓰기-실행-취소)를 참조하십시오. |

## 공유

| 명령 | 기능 |
|---|---|
| **Convert to values** | 메뉴입니다. **Whole workbook** 또는 **This sheet**는 PlaidXL 수식을 현재 값으로 바꾸고 수식을 기억합니다. **Values only (no restore)** 는 되돌릴 방법을 유지하지 않고 바꿉니다. |
| **Restore PlaidXL formulas** | **Convert to values**가 바꾼 수식을 통합 문서의 모든 시트에서 복원합니다. |

PlaidXL이 없거나 프로젝트에 액세스할 수 없는 사용자에게 보고서를 보내려면 **Convert to values**를 사용하십시오. 그렇지 않으면 PlaidXL 수식이 있던 곳에 오류가 표시됩니다. PlaidXL 함수를 호출하는 모든 수식을 변환하며, `IFERROR` 같은 다른 수식 안에 있는 경우와 수식이 확장된 셀도 포함됩니다. 통합 문서의 나머지는 그대로 유지됩니다. 통합 문서 전체에 **Values only (no restore)** 를 사용하면 먼저 **Convert every PlaidXL formula in the workbook to values only? Restore can't bring them back.** 라고 묻습니다. 다른 선택은 즉시 실행됩니다. 메시지에는 변환된 수식의 수가 표시됩니다. 아직 계산 중인(`#BUSY!`) 수식은 변환되지 않으며 메시지에 그 수가 표시되므로, 계산이 끝난 후 다시 변환하십시오.

수식은 각 시트와 함께 보관되므로, 시트 이름을 바꾸거나 이동한 후에도 **Restore PlaidXL formulas**가 수식을 찾을 수 있습니다. 로그인하지 않아도 됩니다. [값만 있는 사본 공유](/ko/reference/cli/plaidxl/build-a-report/#값-전용-사본-공유)를 참조하십시오.

<Aside type="caution">
새 이름으로 저장한 사본을 변환하고, 작업 중인 보고서는 그대로 두십시오. **Values only (no restore)** 는 **Restore PlaidXL formulas**로 실행 취소할 수 없습니다.
</Aside>

## 마우스 오른쪽 클릭 메뉴

셀을 마우스 오른쪽 버튼으로 클릭하고 **PlaidXL**을 선택하면 다음 명령을 사용할 수 있으며, 각각 해당 리본 버튼과 동일합니다.

- **Drill down one level**, **Drill down to lowest level**, **Drill down all levels**, **Custom drill...**, **Drill up**, **Keep only**, **Remove only**
- **Pick member...**
- **Explain this number** 및 **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...** — 해당 셀에 대해 **Formulas** 탭을 엽니다

## PlaidXL Cell 탭

선택한 셀에 PlaidXL 수식이 있거나, PlaidXL 수식 결과의 일부이거나, 가져온 테이블 안에 있으면 Excel은 **PlaidCloud** 탭 옆에 **PlaidXL Cell** 탭을 표시합니다. 이 탭에는 해당 셀에 대한 명령이 모여 있습니다.

- **Drill** — **Drill down**(**One level**, **Lowest level**, **All levels**), **Drill up**, **Keep only**, **제거**
- **검사** — **설명**, **Detail rows**, **Weave에 문의**
- **데이터** — **Pick member**, **Refresh selection**, **Save sheet**

다른 셀을 선택하면 탭이 다시 숨겨집니다. 추가 기능의 상황별 탭을 지원하지 않는 Excel 버전에서는 이 탭이 표시되지 않으며, 모든 명령은 **PlaidCloud** 탭에서 계속 사용할 수 있습니다.

## 키보드 단축키

모든 단축키는 Windows에서는 **Ctrl+Alt+Shift**와 키 하나, Mac에서는 **⌘⌥⇧** 와 같은 키입니다. 필드에 입력하는 중이거나 AltGr 키를 누르고 있는 동안에는 단축키가 작동하지 않습니다. 리본 명령이 실패하면 어떤 명령이 왜 실패했는지 알려 주는 메시지가 표시되며, 작업 창이 숨겨져 있었다면 열립니다.

| 키 | 명령 |
|---|---|
| **Down** | 한 수준 아래로 드릴 |
| **Up** | 위로 드릴 |
| **L** | 가장 낮은 수준까지 드릴 |
| **8** | 모든 수준으로 드릴 |
| **D** | 사용자 지정 드릴 |
| **K** | Keep only |
| **X** | Remove only |
| **M** | 구성원 선택 |
| **E** | 이 숫자 설명 |
| **T** | 상세 행 표시 |
| **R** | 이 시트 새로 고침 |
| **F** | 선택 영역 새로 고침 |
| **A** | 모든 테이블 새로 고침 |
| **C** | PlaidXL 수식 다시 계산 |
| **W** | 시트를 PlaidCloud에 저장 |
| **Z** | 마지막 쓰기 실행 취소 |
| **P** | PlaidXL 열기 |
| **N** | 수식 삽입 |
| **B** | 보고서 작성 |
| **I** | 지표 삽입 |
| **Q** | Weave에 문의 |

단축키를 변경하려면 **연결** 그룹에서 **Shortcuts**를 클릭하거나, 작업 창의 계정 메뉴에서 **Keyboard shortcuts**를 선택합니다. 명령 옆의 **Set key**를 클릭하고 새 조합을 누른 다음 **저장**을 클릭합니다. **재설정**을 클릭하면 원래 조합으로 돌아갑니다. 다른 명령이 이미 사용 중인 조합은 표시되며, 그래도 저장하면 적용됩니다. 일부 Office 버전에서는 추가 기능이 단축키를 변경할 수 없으며, **Set key** 없이 목록만 표시됩니다.
