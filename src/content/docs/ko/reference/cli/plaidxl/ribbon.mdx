PlaidXL을 설치하면 Excel 리본에 세 개의 명령 그룹이 있는 **PlaidCloud** 탭이 추가됩니다. 명령을 사용하기 전에 작업 창에서 [로그인](/ko/reference/cli/plaidxl/connect/)하십시오. 드릴 명령은 작업 창에서 선택한 프로젝트에서 데이터를 읽습니다.

## PlaidXL Controls

| 명령 | 기능 |
|---|---|
| **Show Taskpane** | PlaidXL 작업 창을 엽니다. |
| **Refresh All Tables** | 통합 문서로 가져온 모든 테이블의 최신 데이터를 가져옵니다. 작업 창의 단추와 동일합니다. [Refresh All Tables](/ko/reference/cli/plaidxl/retrieve/#모든-테이블-새로-고침)를 참조하십시오. |

## Drill Functions

드릴 명령은 수식을 작성하지 않고도 선택한 노드 아래에 차원의 노드를 배치합니다.

1. 나란히 있는 두 셀에 차원 이름과 해당 차원의 노드를 입력합니다. 예를 들어 `A1`에 `Region`, `B1`에 `EMEA`를 입력합니다. 순서는 상관없습니다.
2. 두 셀을 모두 선택합니다.
3. 드릴 명령을 클릭합니다.

| 명령 | 선택 영역 아래에 쓰는 내용 |
|---|---|
| **Drill All** | 해당 노드와 그 아래의 모든 노드 |
| **Drill Leaves** | 해당 노드와 그 아래의 리프 노드만 |
| **Drill One** | 해당 노드와 그 하위 노드 |

노드는 선택 영역 아래에 세대별로 들여쓰기되어 기록되며 Excel 윤곽으로 그룹화되므로 각 수준을 접을 수 있습니다. 드릴 명령은 차원의 기본 계층을 따릅니다. 대체 계층을 드릴하거나 차원이 변경될 때 레이아웃이 업데이트되도록 하려면 [`PLAIDXL.DRILL`](/ko/reference/cli/plaidxl/functions/#drill) 함수를 대신 사용하십시오.

PlaidXL이 차원이나 노드를 찾지 못하면 PlaidCloud의 이름과 철자를 비교하고 정확히 두 개의 셀이 선택되어 있는지 확인하십시오.

## Control Functions

| 명령 | 기능 |
|---|---|
| **Sanitize Workbook** | 통합 문서의 모든 수식을 현재 값으로 바꾸고 수식을 기억해 둡니다. |
| **Restore Workbook** | **Sanitize Workbook**이 바꾼 수식을 되돌려 놓습니다. |

PlaidXL이 없거나 프로젝트에 액세스할 수 없는 사람에게 보고서를 보낼 때 **Sanitize Workbook**을 사용하십시오. 그렇지 않으면 PlaidXL 수식이 있는 위치에 오류가 표시됩니다. [값만 있는 사본 공유](/ko/reference/cli/plaidxl/build-a-report/#값만-있는-사본-공유)를 참조하십시오.

<Aside type="caution">
**Sanitize Workbook**은 PlaidXL 함수뿐 아니라 통합 문서의 *모든* 수식을 바꿉니다. 새 이름으로 저장한 사본을 정리하고 작업용 보고서는 그대로 두십시오. 같은 통합 문서를 두 번째로 정리하기 전에 **Restore Workbook**을 실행하십시오.
</Aside>
