PlaidXL 작업 창의 **Weave** 탭에서는 "2026년 월별 리전별 revenue", "headcount가 있는 테이블은 무엇입니까?", "이 #VALUE!는 왜 나오죠?"처럼 원하는 것을 일상적인 말로 [Weave](/ko/guides/ai-assistant/)에 요청하면, Weave가 통합 문서에서 작업을 수행합니다. Weave는 사용자의 권한으로 사용자 본인처럼 PlaidCloud를 읽으며 PlaidCloud에서는 아무것도 변경하지 않습니다. 통합 문서에서 변경한 내용은 되돌릴 수 있습니다.

## 질문하기

1. 작업 창을 열고 **Weave** 탭을 클릭하거나, 리본의 **삽입** 그룹에서 **Weave에 문의...** 버튼을 클릭합니다.
2. **Weave에 문의**에 질문을 입력하고 **Enter** 키를 누르거나 **질문**을 클릭합니다. **Shift+Enter**는 줄을 바꾸고, 빈 입력란에서 **Up** 키를 누르면 마지막 질문이 다시 나타납니다.

Weave는 테이블을 기반으로 답하므로 통합 문서가 프로젝트에 연결되어 있어야 합니다. Weave는 선택한 영역과 활성 셀을 볼 수 있으므로 "이것을 분기별로 합산해 줘" 같은 질문도 눈앞의 셀에 대해 작동합니다. **취소**는 아직 진행 중인 답변을 중지합니다.

## Weave가 할 수 있는 일

- **보고서 작성** — 차원을 드릴하는 행과 열, 모든 셀의 `PLAIDXL.CELL` 값으로, [보고서 작성](/ko/reference/cli/plaidxl/build-a-report/)과 같습니다.
- 질문한 셀에 **수식 작성**.
- **드릴** — [드릴 명령](/ko/reference/cli/plaidxl/drill/)처럼 드릴에서 노드를 열고, 닫고, 유지하거나 제거합니다.
- 요청한 행으로 필터링하여 통합 문서로 **테이블 가져오기**. 직접 가져온 테이블과 마찬가지로 새로 고침 목록에 추가되므로 **Refresh all tables**로 최신 상태를 유지합니다.
- **테이블 찾기** — 무언가를 담고 있는 테이블을 물으면, 각 답변에 해당 테이블을 가져오는 **Pull** 버튼이 함께 표시됩니다.
- 설명 중인 범위를 **선택**하거나 새로 고침을 제안합니다.

Weave는 PlaidXL 함수와, 수학, 텍스트, 논리, 조회, 날짜, 동적 배열을 위한 일반적인 Excel 함수를 사용하는 수식을 작성합니다. `WEBSERVICE`, `HYPERLINK`, `INDIRECT`, `IMAGE`처럼 통합 문서 밖에 접근하거나 텍스트로 참조를 만드는 수식, 또는 다른 파일을 참조하는 수식은 작성하지 않습니다.

Weave는 PlaidCloud에 데이터를 기록하지 않습니다. 값을 다시 기록하려면 직접 [`CELL` 위에 입력](/ko/reference/cli/plaidxl/write-values/)하거나 [시트를 저장](/ko/reference/cli/plaidxl/retrieve/#테이블을-plaidcloud에-저장)하십시오.

### Weave가 먼저 확인하는 경우

Weave는 변경이 빈 셀, PlaidXL 셀, 오류가 표시된 셀, 또는 질문한 셀에 들어갈 때는 즉시 작업합니다. 사용자가 입력한 내용을 교체하게 되는 경우에는 변경 내용을 설명하고 기다립니다.

- 다른 내용이 있는 셀 위에 수식을 쓰려면 **적용**을 기다립니다.
- 값이 들어 있는 셀을 교체하는 드릴은 **적용**을 기다립니다.
- 이미 새로 고친 테이블이 있는 시트에 테이블을 가져오려면 **Retrieve**를 기다립니다.
- 새로 고침은 **새로 고침**을 기다립니다.

## 변경 되돌리기

Weave가 수행한 각 변경에는 **되돌리기** 버튼이 있으며, 여러 변경을 수행한 답변에는 **모두 되돌리기**가 있습니다. 되돌리기는 각 셀을 원래대로 복원하되, 이후에 사용자가 변경한 셀은 그대로 두고 그 사실을 알려 줍니다. Weave가 새 시트에 만든 보고서나 테이블은 시트를 삭제하여 되돌리며, 이 삭제는 Excel에서 실행 취소할 수 없습니다. 사용 중인 Excel 버전이 지원하는 경우 **Ctrl+Z**로도 Weave 변경을 한 번에 실행 취소할 수 있습니다.

## 문제가 생겼을 때

Weave가 작성한 수식이나 작업이 오류로 끝나면 Weave가 한 번 수정을 시도합니다. 수정이 되지 않으면 원본을 되돌려 놓고 시도한 내용을 알려 줍니다.

## 셀에 대해 질문

셀을 선택한 다음 **PlaidXL** 마우스 오른쪽 클릭 메뉴에서 **Ask Weave about this cell**을 선택하거나, **PlaidXL Cell** 탭에서 **Weave에 문의**를 클릭하거나, **Ctrl+Alt+Shift+Q**(Mac에서는 **⌘⌥⇧Q**)를 누릅니다. 질문할 준비가 된 상태로 **Weave** 탭이 열립니다. 셀에 오류가 표시되어 있으면 질문이 자동으로 채워지며(예: **Why is this #VALUE!?**), 준비되면 전송합니다. PlaidXL 셀의 경우 Weave는 수식이 읽는 대상도 알고 있습니다.

## 제한

| 제한 | 값 |
|---|---|
| 질문 길이 | 4,000자 |
| 사용자당 질문 수 | 시간당 30개 |
| 답변 하나에서 가져오는 테이블 수 | 3개 |

대화는 이 컴퓨터에서 통합 문서와 프로젝트별로 최근 40개 항목까지 보관되므로 창을 다시 열어도 그대로 남아 있습니다. 다시 로드하면 **되돌리기**와 **적용** 버튼은 사라집니다. 로그아웃하거나 워크스페이스를 전환하면 대화가 지워집니다.

<Aside>
Weave는 통합 문서에 연결된 프로젝트를 기반으로 답합니다. 다른 프로젝트에 대해 질문하려면 먼저 작업 창 머리글에서 해당 프로젝트를 선택하십시오.
</Aside>
