PlaidXL 작업 창의 **Weave** 탭에서는 "2026년 월별 리전별 수익", "인원수가 있는 테이블은 무엇인가?", "이 #VALUE!는 왜 나오는가?"처럼 원하는 내용을 일상적인 표현으로 [Weave](/ko/guides/ai-assistant/)에 요청하면 Weave가 통합 문서에서 작업을 수행합니다. Weave는 사용자의 권한으로 PlaidCloud를 읽으며 PlaidCloud에서는 아무것도 변경하지 않습니다. 통합 문서에서 변경한 내용은 되돌릴 수 있습니다.

## 질문하기

1. 작업 창을 열고 **Weave** 탭을 클릭하거나, 리본의 **삽입** 그룹에서 **Weave에 문의...** 를 클릭합니다.
2. **Weave에 문의**에 질문을 입력하고 **Enter**를 누르거나 **질문**을 클릭합니다. **Shift+Enter**는 줄을 바꾸며, 빈 입력란에서 **Up**을 누르면 마지막 질문이 다시 나타납니다.

Weave는 프로젝트의 테이블을 바탕으로 답하므로 통합 문서가 프로젝트에 연결되어 있어야 합니다. Weave는 선택한 영역과 활성 셀을 볼 수 있으므로 "분기별로 합산해 줘" 같은 질문도 눈앞의 셀에 대해 작동합니다. 아직 진행 중인 답변은 **취소**로 중지할 수 있습니다.

## Weave가 할 수 있는 작업

- **보고서 작성** — 차원을 드릴하는 행과 열에 모든 셀마다 `PLAIDXL.CELL` 값을 넣으며, [보고서 작성](/ko/reference/cli/plaidxl/build-a-report/)과 같습니다.
- 질문한 셀에 **수식 작성**.
- **드릴** — [드릴 명령](/ko/reference/cli/plaidxl/drill/)처럼 드릴에서 노드를 열고, 닫고, 유지하거나 제거합니다.
- 요청한 행으로 필터링하여 **테이블을 통합 문서로 가져오기**. 직접 가져오는 테이블처럼 새로 고침 목록에 추가되므로 **Refresh all tables**로 최신 상태를 유지할 수 있습니다.
- **테이블 찾기** — 어떤 테이블에 특정 내용이 있는지 물으면 각 답변에 해당 테이블을 가져오는 **Pull** 버튼이 함께 표시됩니다.
- Weave가 설명하는 범위를 **선택**하거나 새로 고침을 제안합니다.

Weave는 PlaidXL 함수와 수학, 텍스트, 논리, 조회, 날짜, 동적 배열용 일반 Excel 함수를 사용하는 수식을 작성합니다. `WEBSERVICE`, `HYPERLINK`, `INDIRECT`, `IMAGE`처럼 통합 문서 밖에 접근하거나 텍스트에서 참조를 만들거나 다른 파일을 참조하는 수식은 작성하지 않습니다. 통합 문서에 없는 시트나 테이블, 경로나 URL, `[Book2]` 같은 열려 있는 다른 파일을 가리키는 수식은 작성되지 않으며, 답변에 **Not run**으로 이유와 함께 나열되고 **formulas that reach outside the workbook are not written**으로 끝납니다.

Weave는 PlaidCloud에 데이터를 쓰지 않습니다. 값을 다시 쓰려면 [`CELL` 위에 값을 입력](/ko/reference/cli/plaidxl/write-values/)하거나 [시트를 저장](/ko/reference/cli/plaidxl/retrieve/#테이블을-plaidcloud에-저장)하는 작업을 직접 수행하십시오.

### Weave가 먼저 확인하는 경우

보고서와 선택은 항상 즉시 수행됩니다. 수식은 질문한 셀, 빈 셀, PlaidXL 셀, 오류가 표시된 셀에 들어가는 경우 바로 입력됩니다. 드릴이나 테이블 가져오기는 빈 셀과 PlaidXL 셀만 건드리는 경우에만 즉시 수행됩니다. 사용자가 입력한 내용을 대체하는 작업은 먼저 설명한 후 대기합니다.

- 다른 내용이 들어 있는 셀 위의 수식은 **적용**을 기다립니다.
- 값이 들어 있는 셀을 대체하는 드릴은 **적용**을 기다립니다.
- 이미 새로 고친 테이블이 있는 시트에 테이블을 가져오는 작업은 **Retrieve**를 기다립니다.
- 새로 고침은 항상 **새로 고침**을 기다립니다.

## 변경 내용 되돌리기

Weave가 수행한 각 변경에는 **되돌리기** 버튼이 있으며, 여러 변경을 수행한 답변에는 **Revert all**이 있습니다. 되돌리기는 각 셀을 이전 상태로 돌려놓지만, 그 이후 사용자가 변경한 셀은 그대로 두고 알려 줍니다. Weave가 새 시트에 넣은 보고서나 테이블은 해당 시트를 삭제하는 방식으로 되돌리며, 이는 Excel에서 실행 취소할 수 없습니다. 사용 중인 Excel 버전이 지원하면 **Ctrl+Z**로도 Weave의 변경을 한 번에 실행 취소할 수 있습니다.

## 문제가 생겼을 때

Weave가 작성한 수식이나 작업이 오류로 끝나면 Weave가 한 번 수정을 시도합니다. 수정이 작동하지 않으면 원래 상태로 되돌리고 시도한 내용을 알려 줍니다.

## 셀에 대해 질문

셀을 선택한 후 **PlaidXL** 마우스 오른쪽 클릭 메뉴에서 **Ask Weave about this cell**을 선택하거나, **PlaidXL Cell** 탭에서 **Weave에 문의**를 클릭하거나, **Ctrl+Alt+Shift+Q**(Mac에서는 **⌘⌥⇧Q**)를 누릅니다. 질문을 입력할 수 있는 상태로 **Weave** 탭이 열립니다. 셀에 오류가 표시되어 있으면 **Why is this #VALUE!?** 처럼 질문이 자동으로 채워지며, 준비되면 전송하면 됩니다. PlaidXL 셀의 경우 Weave는 수식이 읽는 대상도 파악합니다.

## 제한

| 제한 | 값 |
|---|---|
| 질문 길이 | 4,000자 |
| 사용자당 질문 수 | 시간당 30개 |
| 한 번의 답변에서 가져오는 테이블 수 | 3개 |

대화는 이 컴퓨터에서 통합 문서와 프로젝트별로 최근 항목 40개까지 보관되므로 작업 창을 다시 열어도 그대로 남아 있습니다. 새로 불러온 후에는 **되돌리기** 및 **적용** 버튼이 사라집니다. 로그아웃하거나 워크스페이스를 전환하면 대화가 지워집니다.

<Aside>
Weave는 통합 문서에 연결된 프로젝트를 바탕으로 답합니다. 다른 프로젝트에 대해 질문하려면 먼저 작업 창 머리글에서 해당 프로젝트를 선택하십시오.
</Aside>
