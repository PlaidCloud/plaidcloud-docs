## 리본에 PlaidCloud 탭이 없음

- 모든 Excel 창을 닫고 Excel을 다시 시작합니다. 새로 설치한 추가 기능은 다시 시작한 후에야 나타나는 경우가 많습니다.
- **Insert → My Add-ins**를 열고 **PlaidCloud**를 선택합니다.
- Microsoft 365용 데스크톱 Excel 또는 Excel 2021 이상을 사용하고 있는지 확인합니다. [PlaidXL 설치](/ko/reference/cli/plaidxl/install/)를 참조하십시오.
- 조직에서 추가 기능을 관리하는 경우 Microsoft 365 관리자에게 **PlaidCloud** 추가 기능이 사용자에게 배포되어 있는지 문의하십시오.

## 로그인 팝업이 열리지 않음

**로그인**을 클릭하면 Excel이 팝업 창을 표시할지 묻습니다. 허용하십시오. 안내를 닫았다면 **로그인**을 다시 클릭합니다.

팝업은 열리는데 로그인을 완료할 수 없다면 같은 이메일로 브라우저에서 PlaidCloud에 로그인해 보십시오. 만료된 비밀번호나 더 이상 가지고 있지 않은 2단계 인증 장치처럼 그곳에 문제가 있다면 먼저 PlaidCloud에서 해결해야 합니다. [멤버 인증](/ko/administration/access/member-authentication/)을 참조하십시오.

## 워크스페이스가 목록에 없음

**Select a workspace**에는 이메일 주소가 속한 워크스페이스가 나열됩니다. 하나가 없다면 해당 워크스페이스에 사용하는 이메일과 같은 이메일을 입력했는지 확인한 다음, 워크스페이스 관리자에게 멤버인지 확인해 달라고 요청하십시오. [워크스페이스 멤버 관리](/ko/administration/access/overview/managing-workspace-members/)를 참조하십시오.

속해 있는 다른 워크스페이스로 이동하려면 계정 메뉴를 열고 **Switch workspace**를 선택합니다.

## 프로젝트, 테이블 또는 차원이 보이지 않음

PlaidXL에는 PlaidCloud에서 계정이 볼 수 있는 항목이 표시됩니다. 프로젝트가 보이지 않으면 소유자에게 액세스를 요청하십시오. 테이블이 보이지 않으면 선택한 프로젝트에 존재하고 데이터가 로드되었는지 확인하십시오. 한 번도 기록된 적 없는 테이블은 선택할 때 **Unable to get table metadata**가 표시됩니다.

프로젝트, 테이블, 차원 목록의 폴더는 접힌 상태로 시작합니다. 폴더 안의 항목을 찾으려면 목록 맨 위의 필터 상자에 이름의 일부를 입력하십시오.

## 테이블이 빨간색으로 표시됨

테이블의 행이나 열이 Excel 워크시트가 담을 수 있는 수보다 많거나 PlaidCloud가 크기를 보고할 수 없는 경우입니다. 가져올 수는 있으며 들어가지 않는 행은 다음 시트로 이어지지만, 여러 시트로 나뉜 테이블은 저장할 수 없습니다. **고급**을 선택하여 행을 필터링하고 필요하지 않은 열을 선택 해제하여 한 시트에 들어가도록 하십시오. [빨간색으로 표시되는 테이블](/ko/reference/cli/plaidxl/retrieve/#빨간색으로-표시되는-테이블)을 참조하십시오.

## 가져오기가 느림

Excel은 열이 많은 테이블에서 가장 느립니다. 필요하지 않은 열의 확인란을 선택 해제하고 **고급**으로 행을 필터링하십시오. 작업하는 데이터만 가져오면 더 빠르고 통합 문서도 작아집니다.

## 수식에 오류가 표시됨

| 표시되는 내용 | 확인 사항 |
|---|---|
| `#SPILL!` | 결과에 필요한 셀에 무언가 있습니다. 수식 아래나 옆의 셀을 지우십시오. |
| `#NAME?` | Excel이 함수를 인식하지 못합니다. PlaidXL이 설치되어 있는지(리본에 **PlaidCloud** 탭이 있는지) 확인하고, [함수 목록](/ko/reference/cli/plaidxl/functions/)에서 철자를 확인하십시오. |
| `PLAIDXL` 함수의 오류 | 로그인되어 있고 올바른 프로젝트가 선택되어 있는지 확인한 다음, 모든 테이블, 열, 차원, 노드 이름을 PlaidCloud와 대조하십시오. 이름은 정확히 일치해야 합니다. |
| `CELL`이 필터 열을 찾을 수 없다고 보고함 | `DIMENSION_REPR`의 첫 번째 인수는 차원이 아니라 테이블의 열입니다. 테이블의 열 이름을 정확히 사용하십시오. [값](/ko/reference/cli/plaidxl/functions/#값)을 참조하십시오. |
| `METRIC` 또는 `METRIC_BREAKDOWN`의 `#VALUE!` | 셀에 마우스를 올려 이유를 확인하십시오. [지표 오류](/ko/reference/cli/plaidxl/functions/#지표-오류)를 참조하십시오. |
| `CELL` 또는 `CELLS`의 `#VALUE!` | 셀에 마우스를 올려 PlaidCloud가 알려 준 이유를 확인하십시오. 알 수 없는 열, 존재하지 않거나 멤버가 없는 노드, 값 계산 중 문제 등이 있을 수 있습니다. 이름을 PlaidCloud와 대조하십시오. |
| `CELL`이 예상과 다른 합계를 반환함 | 노드는 해당 차원에 연결된 열에서만 집계되며, 다른 열에서는 값과 정확히 일치해야 합니다. 각 필터의 열과 노드를 확인하십시오. |
| 데이터나 프로젝트가 바뀌어도 값이 변하지 않음 | 리본의 **새로 고침** 메뉴에서 **Recalculate PlaidXL formulas**를 클릭하십시오. |
| `MEASURE_TYPE`이 오류를 반환함 | `sum`, `mean`, `median`, `min`, `max`, `std`, `var` 중 하나를 소문자로 사용하십시오. |

## 수식이 다른 프로젝트의 데이터를 반환함

PlaidXL 함수는 통합 문서에 연결된 프로젝트에서 읽습니다. 해당 통합 문서에서 작업 창을 열고 보고서를 만든 대상 프로젝트를 선택한 다음, 리본의 **새로 고침** 메뉴에서 **Recalculate PlaidXL formulas**를 클릭하십시오. 통합 문서마다 자체 프로젝트가 있으므로, 다른 통합 문서에서 프로젝트를 선택해도 이 통합 문서는 바뀌지 않습니다. [프로젝트는 통합 문서에 속합니다](/ko/reference/cli/plaidxl/retrieve/#프로젝트는-통합-문서에-속합니다)를 참조하십시오.

## 다른 워크스페이스의 테이블은 건너뜀

워크스페이스를 전환한 후 **Refresh All Tables**는 이 통합 문서에서 다른 워크스페이스의 테이블이나 차원이 새로 고쳐지지 않았다고 알려 주며, 해당 항목은 **On this sheet** 아래에 나열되지 않습니다. 현재 워크스페이스에서 각 테이블을 다시 가져와 연결하십시오.

## 입력한 값이 기록되지 않음

`CELL` 위에 입력하면 작업 창이 기록한 내용과, 기록하지 않은 항목 및 그 이유를 나열합니다. [PlaidCloud에 값 입력](/ko/reference/cli/plaidxl/write-values/)을 참조하십시오.

| 표시되는 내용 | 조치 사항 |
|---|---|
| `PLAIDXL.CELL` 하나만 들어 있는 셀만 입력한 값을 받음 | 수식이 단일 `CELL`인 셀(선택적으로 곱하기, 나누기 또는 부호 반전 가능) 위에 입력하십시오. |
| 여기서는 인수를 읽을 수 없음 | `CELL`의 인수는 다른 계산이 아니라 셀이나 텍스트여야 합니다. |
| 분산 방법, 형태 또는 고정은 합계에만 적용됨 | `E1200`, `1200 like FY2025`, `H` 같은 코드는 **sum** 셀에서만 작동합니다. 다른 셀에는 일반 숫자를 입력하십시오. |
| 모든 멤버가 고정됨 | `H`로 고정을 해제한 다음 값을 다시 입력하십시오. |
| 워크스페이스가 아직 Excel에서 입력한 값을 받지 않음 | 관리자에게 워크스페이스 업데이트를 요청하십시오. |

## 저장이 거부되거나 중단됨

저장은 즉시 기록되며 중단되는 일은 드뭅니다. 다음의 경우에는 중단됩니다.

| 표시되는 내용 | 조치 사항 |
|---|---|
| 머리글 행이 더 이상 가져온 열과 일치하지 않음 | 머리글을 가져온 상태로 되돌리거나 테이블을 다시 가져오십시오. |
| 값을 변환할 수 없음 | 아무것도 기록되지 않고 행이 나열됩니다. 열의 데이터 유형에 맞게 값을 수정하십시오. |
| 테이블이 다른 시트로 이어짐 | 여러 시트로 나뉜 테이블은 저장할 수 없습니다. 한 시트에 들어가도록 필터를 사용하여 가져오십시오. |
| 저장이 유지할 수 없는 필터로 테이블을 가져옴 | **AND**로 결합된 **같음** 및 **목록에 포함** 규칙의 필터로 다시 가져오거나, 필터 없이 가져오십시오. |
| 행이 행 액세스 범위 밖에 있음 | 아무것도 저장되지 않습니다. 해당 행을 제거하거나 프로젝트 아키텍트에게 저장을 요청하십시오. |
| 시트가 테이블에 연결되어 있지 않음 | 먼저 시트로 테이블을 가져오십시오. 활성 시트로 가져온 테이블만 **On this sheet** 아래에 나열됩니다. |

저장을 실행 취소하려면 메시지의 **실행 취소**를 클릭하거나 리본의 **Undo last write**를 클릭하십시오. 복원 지점은 7일 동안 보관됩니다. [테이블을 PlaidCloud에 저장](/ko/reference/cli/plaidxl/retrieve/#테이블을-plaidcloud에-저장)을 참조하십시오.
