## 리본에 PlaidCloud 탭이 없음

- 모든 Excel 창을 닫고 Excel을 다시 시작합니다. 새로 설치한 추가 기능은 다시 시작해야만 나타나는 경우가 많습니다.
- **삽입 → 내 추가 기능**을 열고 **PlaidCloud**를 선택합니다.
- Microsoft 365용 데스크톱 Excel 또는 Excel 2021 이상을 사용하고 있는지 확인합니다. [PlaidXL 설치](/ko/reference/cli/plaidxl/install/)를 참조하십시오.
- 조직에서 추가 기능을 관리하는 경우 Microsoft 365 관리자에게 **PlaidCloud** 추가 기능이 사용자에게 배포되었는지 문의하십시오.

## 로그인 팝업이 열리지 않음

**Sign In**을 클릭하면 Excel이 팝업 창을 표시할지 묻습니다. 허용하십시오. 메시지를 닫았다면 **Sign In**을 다시 클릭합니다.

팝업은 열렸지만 로그인을 완료할 수 없으면 같은 이메일로 브라우저에서 PlaidCloud에 로그인해 보십시오. 만료된 비밀번호나 더 이상 가지고 있지 않은 2단계 인증 장치와 같은 문제가 있으면 먼저 PlaidCloud에서 해결해야 합니다. [멤버 인증](/ko/administration/access/member-authentication/)을 참조하십시오.

## 워크스페이스가 목록에 없음

**Select a workspace**에는 사용자의 이메일 주소가 속한 워크스페이스가 나열됩니다. 하나가 없으면 해당 워크스페이스에 사용하는 이메일과 같은 이메일을 입력했는지 확인한 다음 워크스페이스 관리자에게 멤버로 등록되어 있는지 확인해 달라고 요청하십시오. [워크스페이스 멤버 관리](/ko/administration/access/overview/managing-workspace-members/)를 참조하십시오.

소속된 다른 워크스페이스로 이동하려면 계정 메뉴를 열고 **Switch workspace**를 선택합니다.

## 프로젝트, 테이블 또는 차원이 없음

PlaidXL은 사용자 계정이 PlaidCloud에서 볼 수 있는 항목을 표시합니다. 프로젝트가 없으면 소유자에게 액세스 권한을 부여해 달라고 요청하십시오. 테이블이 없으면 선택한 프로젝트에 테이블이 있고 데이터가 로드되었는지 확인하십시오. 한 번도 쓰이지 않은 테이블은 선택할 때 **Unable to get table metadata**가 표시됩니다.

프로젝트, 테이블, 차원 목록의 폴더는 접힌 상태로 시작합니다. 목록 상단의 필터 상자에 이름의 일부를 입력하면 폴더 안에 있는 항목을 찾을 수 있습니다.

## 테이블이 빨간색으로 표시됨

테이블의 행 또는 열이 Excel 워크시트가 담을 수 있는 수보다 많습니다. 크기가 맞을 때까지 **Advanced**를 선택하여 행을 필터링하고 필요하지 않은 열을 선택 해제하십시오. [빨간색으로 표시된 테이블](/ko/reference/cli/plaidxl/retrieve/#빨간색으로-표시된-테이블)을 참조하십시오.

## 가져오기가 느림

Excel은 열이 많은 테이블에서 가장 느립니다. 필요하지 않은 열의 확인란을 선택 해제하고 **Advanced**로 행을 필터링하십시오. 작업하는 데이터만 가져오면 더 빠르고 통합 문서도 더 작아집니다.

## 수식에 오류가 표시됨

| 표시되는 내용 | 확인할 사항 |
|---|---|
| `#SPILL!` | 결과에 필요한 셀에 다른 내용이 있습니다. 수식 아래 또는 옆의 셀을 비우십시오. |
| `#NAME?` | Excel이 함수를 인식하지 못합니다. PlaidXL이 설치되어 있는지(리본에 **PlaidCloud** 탭이 있는지) 확인하고, [함수 목록](/ko/reference/cli/plaidxl/functions/)과 철자를 비교하십시오. |
| `PLAIDXL` 함수의 오류 | 로그인되어 있고 올바른 프로젝트가 선택되었는지 확인한 다음, 모든 테이블, 열, 차원, 노드 이름을 PlaidCloud와 대조하십시오. 이름은 정확히 일치해야 합니다. |
| `CELL`이 필터 열을 찾을 수 없다고 보고함 | `DIMENSION_REPR`의 첫 번째 인수는 차원이 아니라 테이블의 열입니다. 테이블의 열 이름을 정확히 사용하십시오. [값](/ko/reference/cli/plaidxl/functions/#값)을 참조하십시오. |
| `CELL` 또는 `CELLS`의 `#VALUE!` | 셀 위에 마우스를 올려 PlaidCloud가 제공한 이유를 읽으십시오. 알 수 없는 열, 존재하지 않거나 멤버가 없는 노드, 값 계산 중 발생한 문제 등이 있습니다. 이름을 PlaidCloud와 대조하십시오. |
| `CELL`이 예상과 다른 합계를 반환함 | 노드는 차원에 연결된 열에서만 롤업되며, 다른 열에서는 값과 정확히 일치해야 합니다. 각 필터의 열과 노드를 확인하십시오. |
| 데이터나 프로젝트를 변경해도 값이 바뀌지 않음 | 전체 다시 계산을 강제로 실행합니다. Windows에서는 **Ctrl+Alt+F9**입니다. |
| `MEASURE_TYPE`이 오류를 반환함 | `sum`, `mean`, `median`, `min`, `max`, `std`, `var` 중 하나를 소문자로 사용하십시오. |

## 수식이 다른 프로젝트의 데이터를 반환함

PlaidXL 함수는 통합 문서에 연결된 프로젝트에서 읽습니다. 해당 통합 문서에서 작업 창을 열고 보고서를 만든 프로젝트를 선택한 다음 전체 다시 계산을 강제로 실행하십시오. 통합 문서마다 고유한 프로젝트가 있으므로 다른 통합 문서에서 프로젝트를 선택해도 이 통합 문서는 바뀌지 않습니다. [프로젝트는 통합 문서에 속합니다](/ko/reference/cli/plaidxl/retrieve/#프로젝트는-통합-문서에-속합니다)를 참조하십시오.

## 다른 워크스페이스의 테이블이 건너뛰어짐

워크스페이스를 전환한 후 작업 창에 다른 워크스페이스에 속하여 **Refresh All Tables**에서 건너뛰는 추적 테이블의 수가 표시됩니다. 현재 워크스페이스에서 각 테이블을 다시 가져와 연결하십시오.

## 저장이 거부되거나 중단됨

| 표시되는 내용 | 조치 사항 |
|---|---|
| 테이블 안에 빈 행이 있음 | 단일 빈 행은 건너뜁니다. 아래에 데이터가 있는 상태에서 빈 행이 연속으로 둘 이상이면 저장이 중단됩니다. 빈 행을 삭제하거나 채운 다음 다시 저장하십시오. |
| 테이블을 가져온 후 변경됨 | 다른 사용자가 PlaidCloud에서 테이블을 저장했습니다. 테이블을 다시 가져와 편집 내용을 다시 적용하십시오. (PlaidCloud는 일부 테이블 유형에서만 이를 확인할 수 있으며, 확인할 수 없는 경우 확인 메시지가 다른 사용자의 변경 사항을 덮어쓴다고 경고합니다.) |
| 값을 변환할 수 없음 | 아무것도 쓰지 않고 해당 행을 나열합니다. 열의 데이터 유형에 맞게 값을 수정하십시오. |
| 시트가 테이블에 연결되어 있지 않음 | 먼저 시트로 테이블을 가져오십시오. **Save to PlaidCloud…** 는 활성 시트로 가져온 테이블에만 표시됩니다. |

저장을 취소하려면 확인 메시지에서 **Restore previous version**을 클릭하거나, PlaidCloud에서 테이블을 열고 **As of** 메뉴에서 저장 이전의 버전을 선택하십시오. 복원 지점은 7일 동안 보관됩니다. [테이블을 PlaidCloud에 저장](/ko/reference/cli/plaidxl/retrieve/#테이블을-plaidcloud에-저장)을 참조하십시오.
