PlaidXL은 PlaidCloud 데이터를 셀로 직접 읽어 오는 함수를 Excel에 추가합니다. 셀에 `=PLAIDXL.`을 입력하면 Excel 자동 완성 기능이 각 인수에 대한 간단한 설명과 함께 함수를 나열합니다. 작업 창의 **Formulas** 탭에서 수식을 대신 작성할 수도 있습니다. [작업 창에서 수식 삽입](#작업-창에서-수식-삽입)을 참조하십시오.

| 그룹 | 함수 | 용도 |
|---|---|---|
| 목록 | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | 사용할 수 있는 항목 확인 |
| 테이블 | [`TABLE.GET_TABLE`](#get_table) | 테이블 전체를 범위로 읽기 |
| 계층 | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | 차원의 노드를 보고서 행으로 배치 |
| 값 | [`CELL`](#cell), [`CELLS`](#cells) | 노드의 모든 조합에 대한 롤업 값 계산 |
| 지표 | [`METRIC`](#metric), [`METRIC_BREAKDOWN`](#metric_breakdown) | 대시보드에 표시되는 그대로 관리되는 비즈니스 지표 읽기 |
| 구성 요소 | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | `CELL`, `CELLS`, `DRILL`이 사용하는 테이블, 측정값, 집계, 노드, 드릴 깊이 설명 |

[보고서 작성](/ko/reference/cli/plaidxl/build-a-report/)에서 이 함수들이 함께 작동하는 모습을 볼 수 있습니다.

## 함수 작동 방식

- **먼저 로그인합니다.** 함수는 사용자의 PlaidCloud 로그인과 권한으로 데이터를 읽으므로, 함수를 사용하기 전에 작업 창에서 [로그인](/ko/reference/cli/plaidxl/connect/)하십시오.
- **통합 문서의 프로젝트에서 읽습니다.** 모든 함수는 작업 창에서 통합 문서에 연결된 프로젝트에서 데이터를 읽습니다. `GET_TABLE`, `TBL_LIST`, `DIM_LIST`는 연결을 변경하지 않고 다른 프로젝트를 읽을 수 있도록 선택적 프로젝트 ID도 받습니다. 각 통합 문서는 자체 프로젝트를 가지므로, 열려 있는 두 통합 문서가 서로 다른 프로젝트에서 읽을 수 있습니다.
- **결과가 인접 셀로 확장됩니다.** 목록이나 테이블을 반환하는 함수는 아래쪽(또는 오른쪽) 셀을 채웁니다. 결과를 위한 공간을 비워 두십시오. 방해가 되는 내용이 있으면 Excel에 `#SPILL!` 오류가 표시됩니다.
- **변경 사항을 반영하려면 다시 계산합니다.** PlaidXL 수식은 인수가 변경되면 데이터를 다시 가져옵니다. PlaidCloud의 새 데이터나 작업 창에서 연결한 다른 프로젝트를 반영하려면 리본의 **새로 고침** 메뉴를 사용합니다. **Recalculate PlaidXL formulas**는 통합 문서의 모든 PlaidXL 수식을 다시 계산하고, **Refresh this sheet**와 **Refresh selection**은 해당 범위에 포함된 수식을 다시 계산합니다. **Refresh all tables**는 수식이 아니라 가져온 테이블을 새로 고칩니다. [새로 고침](/ko/reference/cli/plaidxl/ribbon/#새로-고침)을 참조하십시오.
- **정확한 이름을 사용합니다.** 테이블, 열, 차원, 노드 이름은 PlaidCloud에 표시된 그대로 입력하십시오.

대괄호로 묶인 인수는 선택 사항입니다.

## 목록

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

열 수 있는 프로젝트의 이름을 이름순으로 나열합니다.

- `horizontal` — `TRUE`이면 행 방향으로 나열합니다. 기본값은 열 방향인 `FALSE`입니다.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

프로젝트에 있는 테이블의 이름을 이름순으로 나열합니다.

- `project_id` — 읽을 프로젝트입니다. 기본값은 통합 문서의 프로젝트입니다.
- `horizontal` — `TRUE`이면 행 방향으로 나열합니다. 기본값은 열 방향인 `FALSE`입니다.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

선택한 프로젝트에 있는 테이블의 열 이름을 나열합니다.

- `table_name` — PlaidCloud의 테이블 이름입니다.
- `column_filter` — `"text"`와 같은 데이터 유형으로, 해당 유형의 열만 나열합니다. 생략하면 모든 열을 나열합니다.
- `orientation` — `"vertical"`(기본값)은 열 방향, `"horizontal"`은 행 방향입니다.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

프로젝트에 있는 차원의 이름을 나열합니다.

- `project_id` — 읽을 프로젝트입니다. 기본값은 통합 문서의 프로젝트입니다.
- `horizontal` — `TRUE`이면 행 방향으로 나열합니다. 기본값은 열 방향인 `FALSE`입니다.

## 테이블

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

테이블의 행을 머리글 행과 함께 반환하며, 수식이 있는 셀에서부터 확장됩니다. 빈 값은 빈 셀로 반환됩니다.

- `table_name` — PlaidCloud의 테이블 이름입니다.
- `project_id` — 읽을 프로젝트입니다. 기본값은 통합 문서의 프로젝트입니다.
- `limit` — 반환할 최대 행 수입니다. 기본값은 1,048,575로, 워크시트에서 머리글 행 아래에 담을 수 있는 최대 행 수입니다.

`GET_TABLE`은 모든 열을 반환합니다. 열을 선택하거나 행을 필터링하려면 대신 [작업 창에서 테이블을 가져오십시오](/ko/reference/cli/plaidxl/retrieve/#테이블-가져오기).

## 계층

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

`start_node`에서 시작하여 하위 노드로 내려가며 차원의 노드를 배치합니다. 각 세대는 부모보다 공백 네 칸 더 들여쓰며, Excel 윤곽선 그룹으로 각 수준을 접거나 펼칠 수 있습니다.

- `dimension_name` — 차원의 이름 또는 프로젝트 내 경로입니다.
- `start_node` — 시작할 노드로, 차원의 루트 등입니다.
- `hierarchy` — 따라갈 [대체 계층](/ko/guides/dimensions/dimensions/#대체특성-계층)입니다. 기본값은 `"main"`입니다.
- `orientation` — `"vertical"`(기본값)은 노드를 열 아래로, `"horizontal"`은 행을 따라 나열합니다.
- `generation_limit` — `start_node`를 첫 번째 세대로 세어 반환할 세대 수입니다. `2`는 시작 노드와 그 자식을 반환합니다. 생략하면 모든 세대를 반환합니다.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy], [exclude], [expand], [orientation])`

`start_node`와 `drill_key`가 요청하는 그 아래 노드를 반환하며, 세대별로 들여쓰고 Excel 윤곽선으로 그룹화합니다.

- `dimension_name` — 차원의 이름 또는 프로젝트 내 경로입니다.
- `start_node` — 드릴을 시작할 노드입니다. 비워 두면(`""`) 차원의 최상위 노드에서 시작합니다. 차원 자체는 드릴 키의 세대 0으로 계산되며 나열되지 않으므로, 최상위 노드는 세대 1입니다. `>[1]`은 최상위 노드만 나열하고, `>[0]`은 아무것도 나열하지 않습니다.
- `drill_key` — [`DRILL_KEY`](#drill_key)로 지정하는 드릴 범위입니다. 모든 하위 노드, 리프만, 지정한 수준 수, 세대 범위 중에서 선택합니다.
- `hierarchy` — 따라갈 대체 계층입니다. 기본값은 `"main"`입니다.
- `exclude` — 그 아래의 모든 노드와 함께 제외할 노드입니다. 노드 하나, 목록, 셀 범위를 지정할 수 있습니다. 시작 노드는 제외되지 않습니다.
- `expand` — `drill_key`가 요청한 깊이보다 아래에 있더라도 자식을 함께 표시할 노드입니다. 노드 하나, 목록, 셀 범위를 지정할 수 있습니다. 드릴에 표시된 노드만 펼쳐지므로, 손자 노드를 펼치려면 그 부모도 나열하십시오.
- `orientation` — `"vertical"`(기본값)은 노드를 열 아래로 나열하고, `"horizontal"`은 들여쓰기 없이 행을 따라 열별로 그룹화하여 나열합니다. 그 외의 값은 오류입니다.

`exclude`와 `expand`는 텍스트 또는 숫자로 된 노드 ID를 받으며, 범위에 포함된 빈 셀과 오류는 무시됩니다. 인수를 건너뛰려면 `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`처럼 비워 두십시오(`""`).

예를 들어 `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))`는 **Total**과 그 아래의 모든 리프 리전을 나열합니다.

[드릴 명령](/ko/reference/cli/plaidxl/drill/)은 `DRILL` 수식을 대신 작성하고 편집합니다. 노드를 선택하여 아래로 드릴하거나, 위로 드릴하거나, 노드를 유지하거나 제거할 수 있습니다.

## 값

`CELL`과 `CELLS`는 하나 이상의 차원에서 선택한 노드까지 롤업된 측정값(테이블의 숫자 열)을 계산합니다. 각 호출을 보고서의 교차점 하나로 생각하십시오. 예를 들어 **FY2026**의 **EMEA**에 대한 **수익**입니다.

아래의 구성 요소 함수로 교차점을 설명한 뒤(보통 각각 별도 셀에 둡니다), 해당 셀을 순서에 관계없이 `CELL` 또는 `CELLS`에 전달합니다.

| 인수 | 작성 방법 | 필수 여부 |
|---|---|---|
| 읽을 테이블 | [`TABLE_REPR`](#table_repr) | 정확히 하나 |
| 집계할 열 | `CELL`은 [`MEASURE`](#measure), `CELLS`는 [`MEASURES`](#measures) 또는 여러 `MEASURE` 셀 | 예 |
| 집계 방법 | [`MEASURE_TYPE`](#measure_type) | 아니요 — 기본값은 `sum` |
| 열에 대한 필터 | [`DIMENSION_REPR`](#dimension_repr) | 열마다 하나씩, 최소 하나 |

각 필터는 **테이블의 열**과 값을 지정합니다. 해당 열이 PlaidCloud에서 차원에 연결되어 있으면 값은 노드이며, 필터에는 차원의 기본 계층 또는 지정한 계층에서 해당 노드로 롤업되는 모든 항목이 포함됩니다. 지리 차원에 연결된 **Region** 열에서 노드 **EMEA**는 그 아래의 모든 국가를 포함합니다. 차원에 연결되지 않은 열에서는 필터가 값과 정확히 일치하는 항목을 찾습니다.

이 페이지의 예제는 **Region**과 **Period** 열이 차원에 연결된 테이블을 사용합니다. 사용자의 테이블 열 이름을 사용하십시오.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

숫자 하나를 반환합니다. 전달한 모든 노드에 해당하는 행에 걸쳐 집계한 측정값입니다.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1`에는 FY2026 EMEA의 총 수익이 표시됩니다.

`CELL` 위에 숫자를 입력하면 PlaidCloud에 기록됩니다. [PlaidCloud에 값 입력](/ko/reference/cli/plaidxl/write-values/)을 참조하십시오.

`CELL` 수식이 가득한 시트도 빠르게 계산됩니다. 함께 계산되는 `CELL` 수식은 한 번에 최대 10,000개씩 하나의 요청으로 PlaidCloud에 전송되며, PlaidXL은 셀마다 가져오지 않고 테이블의 열 세부 정보를 30초 동안 재사용합니다. 값을 계산할 수 없으면 셀에 `#VALUE!`가 표시되고, 마우스를 올리면 테이블에 없는 필터 열이나 구성원이 없는 노드처럼 PlaidCloud가 보고한 이유가 표시됩니다. `CELLS`는 전체 결과에 대해 첫 번째 이유를 표시합니다.

일치하는 행이 없으면 `sum`은 `0`입니다. 그 외의 집계 방식(`mean`, `median`, `min`, `max`, `std`, `var`)은 반환할 값이 없습니다. `CELL`은 `#VALUE!`를 표시하며 마우스를 올리면 집계, 구성원, 측정값과 함께 **No value for**가 표시되고, `CELLS` 요소는 비어 있게 됩니다. `AVERAGE` 같은 Excel 함수는 비어 있는 `CELLS` 요소를 건너뛰며, **설명**에서도 같은 이유를 확인할 수 있습니다.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

`CELL`과 같지만 여러 측정값을 한 번에 처리합니다. 나열한 순서대로 측정값마다 숫자 하나를 열 아래로 반환합니다.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#`은 `MEASURES`의 전체 확장 결과를 전달합니다. `B2:B4`에는 FY2026 EMEA의 수익, 비용, 수량이 표시됩니다.

## 지표

`METRIC`과 `METRIC_BREAKDOWN`은 통합 문서의 프로젝트에서 [지표 정의](/ko/integrations/ai-coding-agents/metric-definitions/)를 읽습니다. 지표 정의는 *순매출*처럼 계산 방식이 합의되어 PlaidCloud에 기록된 비즈니스 수치입니다. 값은 대시보드에 표시되는 값과 같으며, 사용자의 행 액세스 권한에 따라 계산됩니다. 리본의 **Metric...** 은 프로젝트의 지표를 현재 값과 함께 나열하고 수식을 대신 작성합니다. [지표 삽입](#지표-삽입)을 참조하십시오.

필터는 `CELL`과 마찬가지로 [`DIMENSION_REPR`](#dimension_repr) 값이지만, 첫 번째 인수가 지표를 세분화할 수 있는 열의 이름이라는 점이 다릅니다. 노드에는 그 아래의 모든 항목이 포함됩니다. 필터를 하나 전달하거나 범위 또는 목록으로 전달할 수 있으며, 빈 필터는 무시됩니다. 수식에서 둘 이상의 대체 계층의 필터를 사용할 수 있으며, 대체 계층의 멤버를 다른 차원의 멤버와 함께 사용할 수도 있습니다.

### METRIC

`=PLAIDXL.METRIC(name, [filter], ...)`

숫자 하나를 반환합니다. 전달한 모든 필터에 해당하는 행에 대한 지표입니다.

- `name` — 지표의 이름, 동의어 중 하나 또는 ID입니다. 대소문자는 구분하지 않습니다.
- `filter` — `DIMENSION_REPR` 필터입니다. 필요한 만큼 전달할 수 있습니다.

```text
=PLAIDXL.METRIC("Net Revenue", PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA"))
```

일치하는 행이 없으면 `METRIC`은 `0`을 반환하고, 지표에 값이 없으면 셀이 비어 있게 됩니다.

### METRIC_BREAKDOWN

`=PLAIDXL.METRIC_BREAKDOWN(name, breakdown, [filter], ...)`

열 하나로 나눈 지표를 반환합니다. 머리글 행 없이 두 개의 열로 구성되며, `breakdown`의 각 구성원과 그 값이 값이 큰 순서대로 나란히 표시됩니다.

- `name` — 지표의 이름, 동의어 중 하나 또는 ID입니다.
- `breakdown` — 지표를 세분화할 열로, 지표를 세분화할 수 있는 열이어야 합니다.
- `filter` — `DIMENSION_REPR` 필터입니다. 필요한 만큼 전달할 수 있습니다.

```text
=PLAIDXL.METRIC_BREAKDOWN("Net Revenue", "Region")
```

값이 없는 구성원은 값을 비워 둔 채 마지막에 표시됩니다. 일치하는 행이 없으면 빈 구성원과 `0`으로 이루어진 행 하나를 반환합니다.

### 지표 오류

계산할 수 없는 지표는 `#VALUE!`를 표시합니다. 셀에 마우스를 올리면 이유를 확인할 수 있습니다.

| 메시지 | 조치 사항 |
|---|---|
| 알 수 없는 지표 또는 알 수 없는 열 | 이름을 확인하십시오. 비슷한 항목이 있으면 메시지의 **Did you mean** 뒤에 나열됩니다. |
| 이름이 둘 이상의 지표와 일치함 | 지표의 전체 이름 또는 ID를 사용하십시오. |
| **Your PlaidCloud role doesn't allow reading metrics in this project.** | 프로젝트 소유자에게 액세스를 요청하십시오. |
| **This PlaidCloud workspace doesn't serve metrics to Excel yet.** | 관리자에게 워크스페이스를 업데이트하도록 요청하십시오. |
| **PlaidCloud is busy; try again in** 뒤에 초 단위 숫자 | PlaidXL이 이미 재시도했습니다. 안내된 시간이 지난 후 다시 계산하십시오. |
| **Choose a project in the PlaidXL pane first.** | 통합 문서를 프로젝트에 연결하십시오. |
| **This PlaidCloud workspace can't combine an alternate hierarchy with other members yet. Ask your administrator to update the workspace.** | 관리자에게 워크스페이스를 업데이트하도록 요청하십시오. 같은 재계산의 다른 셀은 계속 응답합니다. |

## 구성 요소

이 함수들은 데이터를 직접 읽지 않습니다. 각각 계산의 한 부분을 설명하는 짧은 텍스트를 반환하며, 이를 `CELL`, `CELLS`, `DRILL`에 전달합니다. 참조할 셀에 이 함수들을 두면 다른 기간 같은 변경 사항 하나가 해당 셀을 사용하는 모든 수식에 반영됩니다.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

`CELL`과 `CELLS`가 읽을 테이블로, 선택한 프로젝트에서의 이름으로 지정합니다.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

`CELL`이 집계하는 숫자 열입니다.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

`CELLS`에 사용할 여러 측정값 열로, 열 이름이 들어 있는 셀 범위에서 가져옵니다. 결과는 열마다 셀 하나씩 확장되며, `D2#`처럼 확장 연산자를 사용하여 `CELLS`에 전달합니다.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

측정값을 집계하는 방법입니다. `agg_function`은 다음 중 하나이며 소문자로 입력합니다.

| 값 | 반환 값 |
|---|---|
| `sum` | 합계(측정값 유형을 전달하지 않았을 때의 기본값) |
| `mean` | 평균 |
| `median` | 중앙값 |
| `min` | 최솟값 |
| `max` | 최댓값 |
| `std` | 표준 편차 |
| `var` | 분산 |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node, [hierarchy])`

`CELL`, `CELLS`, `METRIC`, `METRIC_BREAKDOWN`에 사용하는 필터입니다. 필터링할 열마다 하나씩 전달합니다.

- `dimension_name` — **테이블에 있는 열**의 이름으로, `"Region"`처럼 차원의 값을 담은 열입니다. 열 이름과 정확히 일치해야 하며, 테이블에 없는 열은 오류를 반환합니다.
- `start_node` — 롤업할 노드로, `"EMEA"` 등입니다. 차원에 연결되지 않은 열에서는 일치시킬 값입니다.
- `hierarchy` — 노드를 롤업할 대체 계층입니다. 기본값은 `"main"`입니다.

그리드를 만들려면 노드에 셀을 참조하십시오. `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`처럼 사용합니다. 앞뒤 공백은 무시되므로 `DRILL`이 배치한 들여쓴 노드 이름을 가리켜도 됩니다.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

[`DRILL`](#drill)이 시작 노드 아래로 얼마나 내려갈지를 지정합니다. `d_key`는 단어 형식이거나 직접 작성한 드릴 키인 일반 텍스트입니다.

| `d_key` | 드릴 범위 |
|---|---|
| `"all"` | 모든 하위 노드 |
| `"leaves"` | 리프만, 즉 아래에 아무것도 없는 노드 |
| `"1 level"`, `"2 levels"`, … | 지정한 세대 수만큼 아래로 |
| `">[...]"` | 다음 표와 같이 직접 작성한 드릴 키 |

숫자는 `"two levels"`가 아니라 `"2 levels"`처럼 숫자로 작성하십시오. 앞의 `drill`은 무시되므로 `"drill 2 levels"`도 작동합니다.

직접 작성한 키는 세대 0이며 항상 포함되는 시작 노드에서부터 아래로 세대를 셉니다. 음수는 각 가지의 리프에서부터 위로 세므로, 들쭉날쭉한 계층도 예상대로 작동합니다.

| 키 | 포함 범위 |
|---|---|
| `>[*]` 또는 `>[:]` | 모든 노드 |
| `>[]` 또는 `>[-1]` | 리프만 |
| `>[n]` | 시작 노드와 그 아래 `n`개 세대. `>[0]`은 시작 노드만입니다. |
| `>[a:]` | 시작 노드, 그리고 세대 `a`와 그 아래 모든 항목 |
| `>[a:b]` | 시작 노드, 그리고 세대 `a`부터 `b - 1`까지 |
| `>[0:-k]` | 시작 노드와 그 아래에 세대가 `k`개 이상 있는 모든 노드. 즉 각 가지의 마지막 `k`개 세대는 제외됩니다. `>[0:-1]`은 리프를 제외한 모든 노드입니다. |
| `>[a:-k]` | 동일하지만 세대 `a`에서 시작합니다 |

계층 `A`에 자식 `B`, `C`, `D`가 있고, `B`에 `B1`과 `B2`가, `C`에 `C1`이 있는 경우는 다음과 같습니다.

| 키 | 결과 |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

노드는 계층 순서대로 각각 자신의 부모 아래에 나열되며, Excel 윤곽선 그룹도 같은 순서를 따릅니다. 키 안의 공백은 무시됩니다. 이 형식 중 어느 것과도 일치하지 않는 키는 올바른 형식을 나열한 오류를 반환합니다.

<Aside type="caution">
`>[-1]`과 `>[0:-1]`은 이전 버전의 PlaidXL과 의미가 다릅니다. 이전에는 반대로 작동했습니다. 이제 `>[-1]`은 리프만, `>[0:-1]`은 리프를 제외한 모든 항목을 반환합니다. 드릴 키를 직접 작성한 통합 문서는 검토하십시오. 단어 형식 `"all"`, `"leaves"`, `"2 levels"`는 변경되지 않았습니다.
</Aside>

<Aside type="note">
`CELL`, `CELLS`, `DRILL`은 이러한 구성 요소 함수의 출력을 필요로 합니다. 텍스트를 직접 입력하지 말고 각 인수를 해당 함수로 작성하십시오.
</Aside>

## 작업 창에서 수식 삽입

작업 창의 **Formulas** 탭에서 수식을 대신 작성합니다. 작업 창에서, 리본의 **Formula...** 로, 또는 **PlaidXL** 마우스 오른쪽 클릭 메뉴의 **Insert formula here...** 로 엽니다. **What do you want in the cell?** 아래에서 하나를 선택합니다.

- **A whole table**(`GET_TABLE`) — 테이블을 선택하거나 입력하고, 선택적으로 최대 행 수를 지정합니다.
- **One number**(`CELL`) — 테이블을 선택하거나 입력하고, **Column to total**과 **How to combine the values**를 선택합니다.
- **A list of dimension nodes**(`DRILL`) — 차원과 시작 노드를 선택하거나 입력하고, 드릴 범위를 선택하며, 선택적으로 **대체 계층**, 제외할 노드, 펼칠 노드를 지정합니다. **행**에서 드릴이 나열하는 노드를 미리 볼 수 있습니다. [사용자 지정 드릴](/ko/reference/cli/plaidxl/drill/#custom-drill)을 참조하십시오.
- **A business metric**(`METRIC`) — [지표 삽입](#지표-삽입)을 참조하십시오.

**Formula** 미리 보기에는 필드를 채우는 동안 결과가 표시됩니다. **Insert in active cell**을 클릭하거나 **Ctrl+Enter**를 누르면 선택한 셀에 수식이 입력되고, **복사**를 클릭하면 직접 붙여넣을 수 있습니다. **테이블** 탭에서 테이블을 선택하거나 **차원** 탭에서 차원을 선택하면 해당 필드가 채워집니다.

### 지표 삽입

리본의 **삽입** 그룹에서 **Metric...** 을 클릭하거나, **Formulas** 탭에서 **A business metric**을 선택합니다.

1. **Metric**에 `revenue`처럼 지표 이름이나 동의어의 일부를 입력합니다. 일치하는 항목마다 현재 값과 설명이 표시됩니다.
2. 화살표 키를 사용하거나 클릭하여 지표를 선택합니다.
3. 선택적으로 필터를 추가합니다. **차원**을 선택하고 **노드**를 입력한 후 **필터 추가**를 클릭합니다.
4. 선택적으로 **Breakdown by (optional)** 에서 열을 선택하면 숫자 하나 대신 `METRIC_BREAKDOWN`이 작성됩니다.
5. **Insert in active cell**을 클릭하거나 **복사**를 클릭합니다.
