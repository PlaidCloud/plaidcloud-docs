[`PLAIDXL.CELL`](/ko/reference/cli/plaidxl/functions/#cell) 값은 읽기 전용이 아닙니다. 값 위에 숫자를 입력하면 PlaidXL이 그 바탕이 되는 PlaidCloud 테이블에 기록하고, 수식을 원래대로 되돌리고, 시트를 다시 계산하므로 보고서에 새 수치와 그로부터 집계되는 모든 값이 반영됩니다. 이렇게 예산, 예측 또는 조정 값을 보고서에 직접 입력합니다.

## 값 입력

1. `PLAIDXL.CELL` 수식이 들어 있는 셀을 선택합니다.
2. 숫자 또는 아래의 [코드](#분산-조정-형태) 중 하나를 입력하고 **Enter** 키를 누릅니다.

값은 즉시 PlaidCloud에 기록되며, 작업 창에 `Jan·East·Revenue 80 → 100 · 14 rows`와 같이 무엇이 바뀌었는지가 **실행 취소** 버튼과 함께 표시됩니다. 값 범위를 붙여넣거나 채우면 함께 기록됩니다.

셀에 `CELL` 수식 하나가 있거나, `CELL`에 숫자·셀·이름을 곱하거나 나누거나 부호를 바꾼 수식(예: `=-PLAIDXL.CELL(...)*$B$1/1000`)이 있으면 입력한 값을 받습니다. PlaidXL은 기록하기 전에 입력한 값에서 `CELL`이 가져야 할 값을 역산합니다. PlaidXL이 어느 교차점에 기록할지 알 수 있도록 `CELL`의 인수는 셀이나 텍스트여야 합니다.

그 외에는 입력한 그대로 남습니다.

- 숫자나 코드가 아닌 텍스트는 셀에 그대로 남으며, 메시지에 숫자와 조정 값만 기록된다고 표시됩니다.
- 다른 수식 위에 입력한 값은 기록되지 않습니다.
- `CELL`에서 **Delete** 키를 누르면 수식이 원래대로 돌아옵니다.
- `10%`와 같은 양의 백분율은 기록되지 않습니다. 값을 10% 올리려면 `+10%`를, 값을 설정하려면 `0.1`을 입력하십시오.

### 테이블이 바뀌는 방식

- **sum** — 이전 값과 새 값의 차이가 새 행으로 추가됩니다. 이 행들은 해당 교차점에 이미 있는 행을 복사하며, 각 행은 크기에 비례하여 몫을 가져갑니다. 빈 교차점에서는 PlaidXL이 셀 노드 아래의 말단 멤버 조합마다 한 행을 추가합니다.
- **mean**, **median**, **min**, **max** — 교차점의 모든 행이 차이만큼 이동합니다.
- **std**와 **var** — 교차점의 행이 평균을 중심으로 퍼지거나 모이며, 평균은 그대로 유지됩니다.

한 번의 쓰기로 최대 100,000행까지 추가됩니다.

## 분산, 조정, 형태

**sum** 셀에서는 코드를 입력하여 그 아래의 말단 멤버에게 값을 어떻게 나눌지 선택할 수 있습니다. 문자는 대문자나 소문자 모두 사용할 수 있습니다.

| 입력 | 동작 |
|---|---|
| `1200` | 셀을 1,200으로 설정하고, 각 말단 멤버가 현재 보유한 값에 비례하여 나눕니다. |
| `P1200` | 위와 같으며 명시적으로 쓴 형태입니다. 비례 분산입니다. |
| `E1200` | 셀을 1,200으로 설정하고 말단 멤버에게 균등하게 나눕니다. |
| `R1200` | 각 말단 멤버를 1,200으로 설정하므로 셀에는 멤버 수의 1,200배가 표시됩니다. |
| `1200 like FY2025` | 셀을 1,200으로 설정하고 **FY2025** 셀과 같은 형태로 나눕니다. |
| `+50` 또는 `-50%` | 금액이나 비율만큼 값을 올리거나 내립니다. |
| `-50` | 셀을 -50으로 설정합니다. 빼기 부호만 있으면 음수 값을 설정하며, 조정하려면 `%`를 추가합니다. |
| `H` | 셀을 고정하거나, 고정되어 있으면 해제합니다. |

숫자는 Excel의 소수점 및 천 단위 구분 기호를 사용합니다. `like`의 경우 멤버는 셀의 차원 중 하나에만 속해야 하며, 둘에 속하면 이미 해당 멤버가 있는 셀을 사용하십시오. 내용이 없는 형태는 균등하게 나눕니다.

### 값 고정

`CELL` 위에 `H`를 입력하면 고정됩니다. 고정된 셀에는 점선 테두리가 표시되며, 같은 테이블과 측정값의 다른 셀에 이후 쓰기를 해도 그대로 유지됩니다. 부모의 새 값은 고정되지 않은 멤버에게 나뉩니다. 해제하려면 `H`를 다시 입력하십시오. 고정 상태는 통합 문서와 함께 저장됩니다. 셀 아래의 모든 멤버가 고정되어 있으면 해당 셀에 대한 쓰기는 거부됩니다.

코드, 형태, 고정은 **sum** 셀에서만 작동합니다.

## 쓰기 실행 취소

Excel의 **Ctrl+Z**는 PlaidCloud에 대한 쓰기를 되돌리지 않습니다. 쓰기를 실행 취소하려면 메시지의 **실행 취소**를 클릭하거나 리본의 **쓰기** 그룹에서 **Undo last write**를 클릭합니다(**Ctrl+Alt+Shift+Z**, Mac에서는 **⌘⌥⇧Z**).

**Undo last write**는 이 통합 문서에서 수행한 가장 최근 쓰기(입력한 값이든 [저장](/ko/reference/cli/plaidxl/retrieve/#테이블을-plaidcloud에-저장)이든)를 실행 취소합니다. 다시 클릭하면 그 이전 쓰기가 실행 취소됩니다. 목록은 통합 문서에 보관되므로 파일을 닫았다 다시 열어도 유지되며 최근 100개의 쓰기를 담습니다.

- **입력한 값**은 해당 행을 되돌려 실행 취소하며, 시트가 다시 계산됩니다. 쓰기는 한 번만 실행 취소할 수 있습니다. 테이블의 열이 바뀐 후에는 실행 취소할 수 없습니다.
- **저장**은 그 이전에 만든 복원 지점으로 테이블을 되돌립니다. 시트를 새로 고치면 복원된 행을 볼 수 있습니다.

## 동시에 쓰는 다른 사용자

마지막 쓰기가 우선합니다. 마지막으로 새로 고친 후 다른 사용자가 값을 변경했더라도 쓰기는 그대로 진행되며, 메시지에 `was 80, not 75`처럼 추가로 표시됩니다. 입력 시점에 PlaidCloud에는 시트에 표시된 75가 아니라 80이 있었다는 뜻입니다.

## 행 액세스

테이블에 대한 액세스가 일부 행으로 제한되어 있으면 그 범위 안에서만 쓸 수 있습니다. 입력한 값은 볼 수 있는 멤버에게 나뉘며, 액세스 범위 밖의 행을 변경하게 되는 실행 취소는 거부됩니다.

<Aside>
값을 입력하려면 이를 허용하는 PlaidCloud 워크스페이스가 필요합니다. 워크스페이스가 아직 Excel에서 입력한 값을 받지 않는다고 PlaidXL이 알려 주면 관리자에게 업데이트를 요청하십시오.
</Aside>
