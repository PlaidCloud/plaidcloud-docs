[`PLAIDXL.CELL`](/ko/reference/cli/plaidxl/functions/#cell) 값은 읽기 전용이 아닙니다. 그 위에 숫자를 입력하면 PlaidXL이 그 뒤에 있는 PlaidCloud 테이블에 값을 쓰고, 수식을 다시 복원하고, 시트를 다시 계산하므로 보고서에 새 수치와 그로부터 롤업되는 모든 항목이 표시됩니다. 이렇게 예산, 예측, 조정 항목을 보고서에 바로 입력합니다.

## 값 입력

1. `PLAIDXL.CELL` 수식이 있는 셀을 선택합니다.
2. 숫자 또는 아래의 [코드](#분배-조정-형태) 중 하나를 입력하고 **Enter**를 누릅니다.

값은 즉시 PlaidCloud에 기록되며 작업 창에 변경 내용이 표시됩니다. 예를 들어 `Jan·East·Revenue 80 → 100 · 14 rows`와 같이 표시되고 **실행 취소** 버튼이 함께 나타납니다. 값 범위를 붙여넣거나 채우면 한꺼번에 기록됩니다.

셀에 `CELL` 수식 하나가 있거나, `CELL`에 숫자·셀·이름을 곱하거나 나누거나 음수로 바꾼 수식(예: `=-PLAIDXL.CELL(...)*$B$1/1000`)이 있으면 입력한 값을 받을 수 있습니다. PlaidXL은 기록하기 전에 입력한 값을 `CELL`이 가져야 할 값으로 환산합니다. PlaidXL이 어떤 교차점에 기록할지 알 수 있도록 `CELL`의 인수는 셀 또는 텍스트여야 합니다.

그 외의 경우에는 입력한 그대로 유지됩니다.

- 숫자나 코드가 아닌 텍스트는 셀에 그대로 남으며, 메시지에 숫자와 조정 값만 기록된다고 표시됩니다.
- 다른 수식 위에 입력한 값은 기록되지 않습니다.
- `CELL`에서 **Delete**를 누르면 수식이 복원됩니다.
- `10%` 같은 양의 백분율은 기록되지 않습니다. 값을 10% 늘리려면 `+10%`를, 값을 설정하려면 `0.1`을 입력하십시오.

PlaidCloud의 응답이 너무 오래 걸리거나 셀에 대한 응답이 없으면, 메시지에 변경이 적용되었을 수 있다고 표시됩니다. 다시 쓰기 전에 값을 확인하십시오. 전송하지 못한 셀은 아무것도 기록되지 않았다고 표시됩니다.

행이나 열을 삽입하거나 삭제하기 직전에 입력한 값은 Excel이 이동시킨 셀에 기록됩니다. 이후 삭제된 행이나 열에 입력한 값은 기록되지 않으며, 메시지에 삭제되었거나 이동된 셀에 입력된 값의 수가 표시됩니다.

### 테이블이 변경되는 방식

- **합계** — 이전 값과 새 값의 차이가 새 행으로 추가됩니다. 이 행은 해당 교차점에 이미 있는 행을 복사하며, 각 행이 크기에 비례하여 일정 몫을 가져갑니다. 비어 있는 교차점에서는 셀의 노드 아래에 있는 리프 구성원의 모든 조합마다 PlaidXL이 행을 하나씩 추가합니다.
- **평균**, **중앙값**, **최소**, **최대** — 교차점의 모든 행이 차이만큼 이동합니다.
- **표준 편차(std)** 및 **분산(var)** — 교차점의 행이 평균을 중심으로 퍼지거나 모이며, 평균은 그대로 유지됩니다.

한 번의 쓰기로 최대 100,000개의 행을 추가합니다.

## 분배, 조정, 형태

**합계** 셀에서는 코드를 입력하여 그 아래 리프 구성원 사이에 값을 어떻게 나눌지 선택할 수 있습니다. 문자는 대문자와 소문자 모두 사용할 수 있습니다.

| 입력 | 결과 |
|---|---|
| `1200` | 셀을 1,200으로 설정하고 각 리프 구성원이 현재 가진 값에 비례하여 나눕니다. |
| `P1200` | 위와 같으며 명시적으로 쓴 것입니다. 비례 분배입니다. |
| `E1200` | 셀을 1,200으로 설정하고 리프 구성원에게 균등하게 나눕니다. |
| `R1200` | 각 리프 구성원을 1,200으로 설정하므로 셀에는 구성원 수의 1,200배가 표시됩니다. |
| `1200 like FY2025` | 셀을 1,200으로 설정하고 **FY2025** 셀과 같은 형태로 나눕니다. |
| `+50` 또는 `-50%` | 금액 또는 백분율만큼 값을 늘리거나 줄입니다. |
| `-50` | 셀을 -50으로 설정합니다. 빼기 기호만 있으면 음수 값이 설정되며, 조정하려면 `%`를 추가합니다. |
| `H` | 셀을 고정하거나, 고정되어 있으면 해제합니다. |

숫자는 Excel의 소수점 및 천 단위 구분 기호를 따릅니다. `like`를 사용할 때 구성원은 셀의 차원 중 하나에만 속해야 합니다. 두 개에 속하면 이미 해당 구성원이 있는 셀을 사용하십시오. 값이 없는 형태는 균등하게 나눕니다.

### 값 고정

`CELL` 위에 `H`를 입력하면 해당 셀이 고정됩니다. 고정된 셀에는 점선 테두리가 표시되며, 같은 테이블과 측정값의 다른 셀에 이후 쓰기를 하더라도 그대로 유지됩니다. 부모의 새 값은 고정되지 않은 구성원에게 나뉩니다. 다시 `H`를 입력하면 해제됩니다. 고정하려면 `CELL`의 인수가 셀 또는 텍스트여야 합니다. 인수가 수식인 셀은 인수가 셀 또는 텍스트인 셀을 고정하라는 메시지가 표시됩니다. 고정 상태는 통합 문서와 함께 저장됩니다. 셀 아래의 모든 구성원이 고정되어 있으면 해당 셀에 대한 쓰기가 거부됩니다.

코드, 형태, 고정은 **합계** 셀에서만 작동합니다.

## 쓰기 실행 취소

Excel의 **Ctrl+Z**는 PlaidCloud에 대한 쓰기를 되돌리지 못합니다. 실행 취소하려면 메시지에서 **실행 취소**를 클릭하거나 리본의 **쓰기** 그룹에서 **Undo last write**를 클릭합니다(**Ctrl+Alt+Shift+Z**, Mac에서는 **⌘⌥⇧Z**).

**Undo last write**는 이 통합 문서에서 수행한 가장 최근의 쓰기를 실행 취소합니다. 입력한 값이든 [저장](/ko/reference/cli/plaidxl/retrieve/#테이블을-plaidcloud에-저장)이든 상관없으며, 다시 클릭하면 그 이전 쓰기가 실행 취소됩니다. 이 목록은 통합 문서에 보관되므로 파일을 닫았다가 다시 열어도 유지되며 최근 100개의 쓰기를 담습니다.

- **입력한 값**은 해당 행을 되돌리는 방식으로 실행 취소되며 시트가 다시 계산됩니다. 쓰기는 한 번만 실행 취소할 수 있습니다. 테이블의 열이 변경된 후에는 실행 취소할 수 없습니다.
- **저장**은 저장 이전에 만든 복원 지점으로 테이블을 되돌립니다. 복원된 행을 보려면 시트를 새로 고치십시오.

쓰기를 수행한 사용자와 워크스페이스만 해당 쓰기를 실행 취소할 수 있습니다. 다른 사용자의 항목은 목록에 남으며 **This write was made by another user or workspace**라고 표시됩니다. 이미 실행 취소된 항목에는 **Already undone or no longer available**이라고 표시됩니다. 통합 문서에 본인의 쓰기가 없으면 **Nothing to undo: the writes in this workbook were made by other users or workspaces.** 라는 메시지가 표시됩니다. PlaidCloud가 실행 취소에 너무 오래 걸리면 적용되었을 수 있다는 메시지가 표시됩니다. **실행 취소**를 다시 시도하십시오.

## 동시에 쓰는 다른 사용자

마지막 쓰기가 우선합니다. 마지막으로 새로 고친 후 다른 사용자가 값을 변경했더라도 사용자의 쓰기는 그대로 진행되며, 메시지에 `was 80, not 75`와 같은 내용이 추가됩니다. 입력할 때 PlaidCloud에는 시트에 표시된 75가 아니라 80이 있었다는 뜻입니다.

## 행 액세스

테이블에 대한 액세스가 일부 행으로 제한되어 있으면 그 범위 안에만 쓸 수 있습니다. 입력한 값은 볼 수 있는 구성원에게 나뉘며, 액세스 권한 밖의 행을 변경하게 되는 실행 취소는 거부됩니다.

<Aside>
값을 입력하려면 이를 받아들이는 PlaidCloud 워크스페이스가 필요합니다. PlaidXL에서 워크스페이스가 Excel에서 입력한 값을 아직 지원하지 않는다고 표시되면 관리자에게 업데이트를 요청하십시오.
</Aside>
