보고서를 작성하는 방법은 세 가지입니다. 자신의 데이터로 샘플을 만드는 **Build my first report**, 직접 선택하여 보고서를 만드는 **보고서** 탭, 그리고 수식을 직접 작성하는 방법입니다. 일상적인 말로 [Weave에 요청](/ko/reference/cli/plaidxl/weave/)하여 만들 수도 있습니다.

## 시작하기

통합 문서에 PlaidCloud의 데이터가 아직 없으면 작업 창에 **Get started**가 표시됩니다.

- **Build my first report**는 연결된 프로젝트에서 숫자 열과 보고 기준이 될 차원이 있는 테이블을 선택하여, 그 테이블로 **PlaidXL sample**이라는 새 시트에 보고서를 만들고, 옆의 **PlaidXL sample data** 시트에 테이블의 행을 최대 1,000개까지 가져옵니다. 필터 셀을 변경하면 보고서가 다시 계산됩니다.
- **Insert a table**은 **테이블** 탭을 엽니다.
- **Build a report...** 버튼은 **보고서** 탭을 엽니다.

## 보고서 작성

**보고서** 탭이 보고서 전체 레이아웃을 만들어 줍니다. 작업 창에서 열거나 리본의 **삽입** 그룹에서 **Build report...** 버튼을 클릭합니다(**Ctrl+Alt+Shift+B**, Mac에서는 **⌘⌥⇧B**).

1. **테이블** — 보고 대상 테이블을 선택합니다.
2. **값** — **Column to total**을 선택하고 **Combine by**를 선택합니다. 선택 가능한 값은 sum, mean, median, std, var, min, max입니다.
3. **행** — **차원**을 선택하고 **시작 기준**(맨 위부터 시작하려면 비워 둠)과 **Depth**를 선택합니다. Depth는 **Levels down**의 수, **All levels**, **Lowest level only**, **Drill key** 중에서 고릅니다.
4. **열** — **Drill a dimension across the columns**를 선택하고 열에도 같은 방식으로 지정하거나, 선택하지 않고 두면 값이 하나의 열로 표시됩니다.
5. **필터(선택 사항)** — 보고서 전체를 필터링할 차원과 노드마다 **필터 추가**를 클릭합니다.

탭은 테이블과 차원이 이미 선택된 상태로 열리며, 값을 변경할 때마다 각 축의 처음 10개 노드와 `12 × 4 = 48 values`와 같은 값의 수를 미리 보여 줍니다. 차원에 없는 시작 노드를 입력하면 가장 가까운 항목이 표시되어 선택할 수 있습니다.

보고서가 시작될 셀을 선택하고 **Build report** 버튼을 클릭합니다(또는 **Ctrl+Enter** 키를 누릅니다). 값이 채워지는 동안 **취소**를 클릭하면 중지되고 보고서가 제거됩니다. 완료되면 메시지에 **실행 취소**가 표시됩니다. 보고서에 필요한 셀에 이미 내용이 있으면, 보고서는 번호가 붙은 새 **Report** 시트에 만들어집니다.

보고서는 직접 작성할 수 있는 것과 동일한 수식으로 구성됩니다.

- 맨 위에는 **테이블**, **측정값**, **집계**를 위한 셀과 필터마다 하나씩의 셀이 있습니다.
- 행을 위해 왼쪽에 [`DRILL`](/ko/reference/cli/plaidxl/functions/#drill), 열을 위해 위쪽에 또 하나가 있습니다.
- 모든 교차점에는 [`CELL`](/ko/reference/cli/plaidxl/functions/#cell)이 있으며, 여기에 직접 입력하여 [PlaidCloud에 값을 쓸](/ko/reference/cli/plaidxl/write-values/) 수 있습니다.

부모 행은 굵게 표시되고 머리글은 고정됩니다. 보고서를 변경하려면 보고서 안의 셀을 선택하십시오. **보고서** 탭에 해당 보고서가 로드되고, **Rebuild report**를 클릭하면 제자리에서 교체됩니다. 별도의 보고서를 시작하려면 **Build a new one instead** 버튼을 클릭합니다.

### 보고서는 드릴을 따라갑니다

보고서의 행이나 열이 변경되면(행을 아래나 위로 드릴하거나, 노드를 유지하거나 제거하거나, 차원이 바뀌는 경우) 보고서는 그에 맞춰 행과 열 전체를 삽입하거나 삭제하고, `Report updated: +3 rows, -1 column`과 같이 무엇이 바뀌었는지 알려 주는 메시지를 **실행 취소**와 함께 표시합니다. 직접 입력한 값, 메모, 서식, 보고서 옆의 수식은 해당 노드와 함께 유지됩니다.

## 수식으로 작성

보고서를 직접 만들려면 수식을 직접 작성합니다.

### 시작하기 전에

- [로그인](/ko/reference/cli/plaidxl/connect/)하고 데이터가 있는 프로젝트를 선택합니다. 통합 문서가 이 선택을 기억합니다.
- 보고 대상인 숫자 열(예: **revenue**)이 있는 테이블과, 보고 기준으로 사용할 각 차원에 해당하는 열(예: **Region**과 **Period**)이 필요하며, 이 열들은 PlaidCloud에서 해당 차원에 연결되어 있어야 합니다. `CELL`은 열 이름으로 필터링하며, 연결된 열에서만 차원을 통해 노드를 집계합니다. [값](/ko/reference/cli/plaidxl/functions/#값)을 참조하십시오.
- 정확한 이름이 확실하지 않습니까? 임시 시트에서 `=PLAIDXL.TABLE.TBL_LIST()`, `=PLAIDXL.TABLE.GET_COLUMNS("Sales")`, `=PLAIDXL.DIMENSION.DIM_LIST()`를 사용하면 이름을 나열할 수 있습니다.

### 수식 작성

단계에서는 측정값 열 **revenue**와 차원 열 **Region**(행), **Period**(열)이 있는 **Sales** 테이블을 사용하며, 열은 같은 이름의 차원에 연결되어 있습니다. 이름은 사용자의 것으로 바꾸십시오. `DRILL`에는 차원의 이름을, `DIMENSION_REPR`에는 테이블의 열 이름을 사용합니다.

<Steps>

1. **측정 대상을 설명합니다.** 시트 맨 위의 셀 세 개에 다음을 입력합니다.

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   보고서의 모든 값이 이 셀들을 참조하므로, 예를 들어 `"sum"` 대신 `"mean"`으로 바꾸면 보고서 전체가 바뀝니다.

2. **행을 배치합니다.** `A6`에서 행 차원을 최상위 노드부터 드릴합니다.

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **Total**과 그 하위 항목이 A열 아래로 채워지며, 부모 아래에 들여쓰기되고 접을 수 있도록 그룹화됩니다. 모든 수준을 표시하려면 `"all"`을, 맨 아래 수준만 표시하려면 `"leaves"`를 사용하십시오. 말단을 제외한 모든 수준처럼 더 세밀하게 제어하려면 키를 직접 작성합니다(`>[0:-1]`). [`DRILL_KEY`](/ko/reference/cli/plaidxl/functions/#drill_key)를 참조하십시오. 행 노드를 직접 입력하려면 각 셀에 노드 이름을 하나씩 입력합니다.

3. **열을 배치합니다.** 5행에 `B5`부터 열 노드를 가로로 입력합니다(예: `FY2025`, `FY2026`). 또는 행을 따라 드릴할 수 있습니다. `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`.

4. **첫 번째 값을 채웁니다.** `B6`에 다음을 입력합니다.

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   `$` 기호는 테이블, 측정값, 유형을 고정하고, 행 노드는 A열에, 열 노드는 5행에 고정합니다. `DRILL`이 노드 이름에 추가하는 들여쓰기는 무시됩니다.

5. **그리드를 채웁니다.** `B6`을 마지막 기간까지 오른쪽으로, 마지막 행까지 아래로 복사합니다. 각 셀에는 해당 행의 리전에 대한 해당 열 기간의 revenue가 표시됩니다.

</Steps>

보고서 전체에 적용되는 필터(예: 특정 제품군 하나)를 추가하려면 맨 위의 셀에 `B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`와 같이 `DIMENSION_REPR`를 하나 더 추가하고, 모든 `CELL`에 `$B$4`를 전달합니다.

각 행에 여러 측정값을 표시하려면 [`PLAIDXL.CELLS`](/ko/reference/cli/plaidxl/functions/#cells)를 [`PLAIDXL.REPR.MEASURES`](/ko/reference/cli/plaidxl/functions/#measures)와 함께 사용합니다.

## 보고서를 최신 상태로 유지

- 리본의 **새로 고침** 메뉴에서 **Recalculate PlaidXL formulas**를 사용하면 모든 PlaidXL 수식에 현재 값을 가져오고, **Refresh this sheet**를 사용하면 한 시트만 가져옵니다. 일반적인 Excel 다시 계산은 수식의 인수가 바뀌지 않는 한 값을 다시 가져오지 않습니다.
- 구성 요소 셀을 편집하여 **범위를 변경**합니다. 다른 테이블, 측정값 또는 집계, 혹은 다른 최상위 필터 노드를 지정할 수 있습니다. 해당 셀을 사용하는 수식이 즉시 업데이트됩니다.
- 모든 값이나 행 머리글에서 [드릴 명령](/ko/reference/cli/plaidxl/drill/)으로 **행을 드릴**하면 보고서가 [그에 따라 변경](#보고서는-드릴을-따라갑니다)됩니다.
- 작업 창에서 다른 프로젝트를 선택한 다음 PlaidXL 수식을 다시 계산하여 **다른 프로젝트를 보고**합니다. 수식은 통합 문서의 프로젝트에서 읽으므로, 테이블, 열, 차원 이름이 같은 각 프로젝트에 대해 동일한 통합 문서로 보고할 수 있습니다.

## 값 전용 사본 공유

PlaidXL이 없는 사용자나 프로젝트에 액세스할 수 없는 사용자에게는 PlaidXL 수식 대신 오류가 표시됩니다. 숫자를 보내려면 먼저 수식을 값으로 바꿉니다.

1. 보고서를 저장한 다음, 전송용으로 새 이름의 사본을 저장합니다.
2. 사본에서 **PlaidCloud → Convert to values → Whole workbook**을 클릭하거나, 한 시트만 변환하려면 **This sheet**를 클릭합니다.
3. 사본을 전송합니다.

**Convert to values**는 모든 PlaidXL 수식을 현재 값으로 바꾸고 다른 수식은 그대로 둡니다. **Restore PlaidXL formulas**는 시트 이름을 바꾼 후에도 PlaidXL 수식을 원래 셀에 다시 넣으며, 그 셀에 있던 내용은 교체됩니다. **Values only (no restore)** 는 되돌릴 방법을 남기지 않습니다. 원본을 보관하십시오. 원본이 라이브 보고서를 되찾는 확실한 방법입니다. [공유](/ko/reference/cli/plaidxl/ribbon/#공유)를 참조하십시오.

<Aside type="caution">유일한 작업 중 보고서가 아니라, 전송할 사본을 변환하십시오.</Aside>
