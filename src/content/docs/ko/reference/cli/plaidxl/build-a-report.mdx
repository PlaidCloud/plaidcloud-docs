## 시작하기 전에

- [로그인](/ko/reference/cli/plaidxl/connect/)하고 데이터가 있는 프로젝트를 선택합니다.
- 보고 대상이 되는 숫자 열(예: **revenue**)이 있는 테이블과, 보고 기준으로 사용할 각 차원(예: **Region**과 **Period**)에 대한 열이 필요하며, 이 열은 PlaidCloud에서 해당 차원에 연결되어 있어야 합니다. `CELL`은 열 이름으로 필터링하며, 연결된 열에서만 차원을 통해 노드를 롤업합니다. [값](/ko/reference/cli/plaidxl/functions/#값)을 참조하십시오.
- 정확한 이름을 모르십니까? `=PLAIDXL.TABLE.TBL_LIST()`, `=PLAIDXL.TABLE.GET_COLUMNS("Sales")`, `=PLAIDXL.DIMENSION.DIM_LIST()`로 임시 시트에 이름을 나열할 수 있습니다.

## 보고서 작성

다음 단계에서는 측정값 열 **revenue**와 차원 열 **Region**(행) 및 **Period**(열)이 있는 **Sales** 테이블을 사용하며, 이 열은 이름이 같은 차원에 연결되어 있습니다. 자신의 이름으로 바꾸어 사용하십시오. `DRILL`에는 차원 이름을, `DIMENSION_REPR`에는 테이블의 열 이름을 사용합니다.

<Steps>

1. **측정 대상을 설명합니다.** 시트 맨 위의 세 셀에 다음을 입력합니다.

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   보고서의 모든 값이 이 셀을 참조하므로, 예를 들어 `"sum"` 대신 `"mean"`을 사용하는 것처럼 하나를 바꾸면 보고서 전체가 바뀝니다.

2. **행을 배치합니다.** `A6`에서 최상위 노드부터 행 차원을 드릴합니다.

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **Total**과 그 하위 노드가 A열 아래로 펼쳐지며, 부모 아래에 들여쓰기되고 접을 수 있도록 그룹화됩니다. 모든 수준을 표시하려면 `"all"`을, 최하위 수준만 표시하려면 `"leaves"`를 사용합니다. 행 노드를 직접 입력하려면 각 셀에 노드 이름을 하나씩 입력합니다.

3. **열을 배치합니다.** `B5`부터 5행에 열 노드를 입력합니다. 예를 들어 `FY2025`와 `FY2026`입니다.

4. **첫 번째 값을 채웁니다.** `B6`에 다음을 입력합니다.

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   `$` 기호는 테이블, 측정값, 유형, A열의 행 노드, 5행의 열 노드를 고정합니다. `DRILL`이 노드 이름에 추가하는 들여쓰기는 무시됩니다.

5. **그리드를 채웁니다.** `B6`을 마지막 기간까지 오른쪽으로, 마지막 행까지 아래로 복사합니다. 각 셀에는 해당 행의 리전에 대한 해당 열의 기간 수익이 표시됩니다.

</Steps>

보고서 전체에 적용되는 필터(예: 하나의 제품 라인)를 추가하려면 맨 위의 셀에 `B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`와 같이 `DIMENSION_REPR`을 하나 더 추가하고 모든 `CELL`에 `$B$4`를 전달합니다.

각 행에 여러 측정값을 표시하려면 [`PLAIDXL.REPR.MEASURES`](/ko/reference/cli/plaidxl/functions/#cells)와 함께 [`PLAIDXL.CELLS`](/ko/reference/cli/plaidxl/functions/#measures)를 사용합니다.

## 보고서를 최신 상태로 유지

- **전체 다시 계산을 강제로 실행**하여 최신 값을 모든 PlaidXL 수식으로 가져옵니다. Windows에서는 **Ctrl+Alt+F9**를 누릅니다. 일반적인 다시 계산은 수식의 인수가 바뀌지 않으면 데이터를 다시 가져오지 않습니다.
- **범위 변경**은 구성 요소 셀을 편집하여 수행합니다. 다른 테이블, 측정값, 집계 또는 다른 최상위 필터 노드를 지정할 수 있습니다. 해당 셀을 사용하는 수식이 즉시 업데이트됩니다.
- **다른 프로젝트에 대한 보고**는 작업 창에서 해당 프로젝트를 선택한 다음 전체 다시 계산을 강제로 실행합니다. 수식은 선택된 프로젝트에서 데이터를 읽으므로, 테이블, 열, 차원 이름을 공유하는 각 프로젝트에 대해 같은 통합 문서로 보고할 수 있습니다.

## 값만 있는 사본 공유

PlaidXL이 없거나 프로젝트에 액세스할 수 없는 사람에게는 PlaidXL 수식 대신 오류가 표시됩니다. 숫자를 보내려면 먼저 수식을 값으로 바꿉니다.

1. 보고서를 저장한 다음 전송용으로 새 이름의 사본을 저장합니다.
2. 사본에서 **PlaidCloud → Sanitize Workbook**을 클릭합니다.
3. 사본을 보냅니다.

**Sanitize Workbook**은 통합 문서의 모든 수식을 현재 값으로 바꿉니다. **Restore Workbook**은 수식을 되돌리지만 `DRILL`처럼 결과가 펼쳐지는 수식은 깔끔하게 복원하지 못하며, 정리한 후에 변경한 내용은 덮어씁니다. 원본을 보관하십시오. 실시간 보고서를 확실하게 되찾는 방법입니다. [정리 및 복원](/ko/reference/cli/plaidxl/ribbon/#control-functions)을 참조하십시오.

<Aside type="caution">보내려는 사본을 정리해야 하며, 하나뿐인 작업용 보고서를 정리해서는 안 됩니다. 정리는 PlaidXL 함수가 아닌 수식을 포함하여 통합 문서의 모든 수식에 영향을 줍니다.</Aside>
