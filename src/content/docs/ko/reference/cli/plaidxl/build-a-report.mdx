## 시작하기 전에

- [로그인](/ko/reference/cli/plaidxl/connect/)하고 데이터가 있는 프로젝트를 선택합니다. 통합 문서가 이 프로젝트를 기억합니다.
- 보고할 숫자 열(예: **revenue**)이 있는 테이블이 필요하며, 보고 기준으로 사용할 각 차원(예: **Region**과 **Period**)에 대한 열이 PlaidCloud에서 해당 차원에 연결되어 있어야 합니다. `CELL`은 열 이름으로 필터링하며, 연결된 열에 대해서만 노드를 해당 차원을 통해 롤업합니다. [값](/ko/reference/cli/plaidxl/functions/#값)을 참조하십시오.
- 정확한 이름이 확실하지 않나요? `=PLAIDXL.TABLE.TBL_LIST()`, `=PLAIDXL.TABLE.GET_COLUMNS("Sales")`, `=PLAIDXL.DIMENSION.DIM_LIST()`로 임시 시트에 이름을 나열할 수 있습니다.

## 보고서 만들기

다음 단계에서는 측정값 열 **revenue**와 차원 열 **Region**(행), **Period**(열)이 있는 **Sales** 테이블을 사용하며, 이 열들은 같은 이름의 차원에 연결되어 있습니다. 이름은 사용하는 이름으로 바꾸십시오. `DRILL`에는 차원 이름을, `DIMENSION_REPR`에는 테이블의 열 이름을 사용합니다.

<Steps>

1. **측정 대상을 설명합니다.** 시트 맨 위의 세 셀에 다음을 입력합니다.

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   보고서의 모든 값은 이 셀들을 참조하므로, 예를 들어 `"sum"` 대신 `"mean"`으로 바꾸는 식으로 하나만 변경해도 보고서 전체가 바뀝니다.

2. **행을 배치합니다.** `A6`에서 최상위 노드부터 행 차원을 드릴합니다.

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **Total**과 그 하위 노드가 A열 아래로 펼쳐지며, 상위 노드 아래에 들여쓰기되고 그룹화되어 접을 수 있습니다. 모든 레벨을 표시하려면 `"all"`을, 가장 아래 레벨만 표시하려면 `"leaves"`를 사용하십시오. 리프를 제외한 모든 레벨처럼 더 세밀하게 제어하려면 키를 직접 작성합니다(`>[0:-1]`). [`DRILL_KEY`](/ko/reference/cli/plaidxl/functions/#drill_key)를 참조하십시오. 행 노드를 직접 입력하려면 각 셀에 노드 이름을 하나씩 입력합니다.

3. **열을 배치합니다.** `B5`부터 5행에 걸쳐 열 노드를 입력합니다. 예를 들어 `FY2025`와 `FY2026`입니다.

4. **첫 번째 값을 채웁니다.** `B6`에 다음을 입력합니다.

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   `$` 기호는 테이블, 측정값, 유형을 고정하고, 행 노드는 A열에, 열 노드는 5행에 고정합니다. `DRILL`이 노드 이름에 추가하는 들여쓰기는 무시됩니다.

5. **그리드를 채웁니다.** `B6`을 마지막 기간까지 오른쪽으로, 마지막 행까지 아래쪽으로 복사합니다. 각 셀에는 해당 행의 리전에 대한 해당 열 기간의 revenue가 표시됩니다.

</Steps>

예를 들어 제품 라인 하나처럼 보고서 전체에 적용되는 필터를 추가하려면, 맨 위의 셀에 `B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`와 같이 `DIMENSION_REPR`를 하나 더 추가하고 모든 `CELL`에 `$B$4`를 전달합니다.

각 행에 여러 측정값을 표시하려면 [`PLAIDXL.CELLS`](/ko/reference/cli/plaidxl/functions/#cells)를 [`PLAIDXL.REPR.MEASURES`](/ko/reference/cli/plaidxl/functions/#measures)와 함께 사용하십시오.

## 보고서를 최신 상태로 유지

- **전체 다시 계산을 강제로 실행**하면 모든 PlaidXL 수식에 최신 값을 가져옵니다. Windows에서는 **Ctrl+Alt+F9**를 누릅니다. 일반 다시 계산은 수식의 인수가 변경되지 않으면 값을 다시 가져오지 않습니다.
- **범위를 변경**하려면 구성 요소 셀을 편집합니다. 다른 테이블, 측정값 또는 집계를 지정하거나 최상위 필터 노드를 변경할 수 있습니다. 해당 셀을 사용하는 수식은 즉시 업데이트됩니다.
- **다른 프로젝트에 대해 보고**하려면 작업 창에서 해당 프로젝트를 선택한 다음 전체 다시 계산을 강제로 실행합니다. 수식은 통합 문서의 프로젝트에서 읽으므로, 테이블, 열, 차원 이름이 같은 각 프로젝트에 대해 동일한 통합 문서로 보고할 수 있습니다.

## 값만 담긴 사본 공유

PlaidXL이 없거나 프로젝트에 액세스할 수 없는 사용자에게는 PlaidXL 수식 대신 오류가 표시됩니다. 숫자를 보내려면 먼저 수식을 값으로 바꿉니다.

1. 보고서를 저장한 다음, 전송용으로 새 이름으로 사본을 저장합니다.
2. 사본에서 **PlaidCloud → Convert to values (for sharing)** 명령을 클릭하고 확인합니다.
3. 사본을 보냅니다.

**Convert to values (for sharing)** 명령은 통합 문서의 모든 PlaidXL 수식을 현재 값으로 바꾸고 다른 수식은 그대로 둡니다. **Restore PlaidXL formulas**는 PlaidXL 수식을 되돌리지만, `DRILL`처럼 결과가 펼쳐지는 수식은 깔끔하게 복원하지 못하며 변환 후 변경한 내용은 덮어씁니다. 원본을 보관하십시오. 실시간 보고서를 안정적으로 되돌리는 방법은 이것뿐입니다. [Share](/ko/reference/cli/plaidxl/ribbon/#share)를 참조하십시오.

<Aside type="caution">유일한 작업용 보고서가 아니라 보낼 사본을 변환하십시오.</Aside>
