**Drill** 명령은 하나의 셀에서 작동합니다. 노드를 실시간 [`PLAIDXL.DRILL`](/ko/reference/cli/plaidxl/functions/#drill) 수식으로 바꾼 다음 그 수식을 대신 편집하므로, 레이아웃이 차원과 계속 연결되어 있고 차원이 바뀌면 함께 업데이트됩니다. 각 명령은 **PlaidCloud** 리본 탭, **PlaidXL** 오른쪽 클릭 메뉴, **PlaidXL Cell** 탭, [키보드 단축키](/ko/reference/cli/plaidxl/ribbon/#키보드-단축키)에 있습니다.

## 셀에서 아래로 드릴

1. 셀에 차원의 노드를 입력하고(`4000` 같은 ID 또는 `Revenue` 같은 별칭) 선택합니다.
2. **Drill down**을 클릭한 다음 **One level**, **To lowest level** 또는 **All levels**를 클릭합니다.

셀이 `PLAIDXL.DRILL` 수식으로 바뀌며, 해당 노드와 그 아래 노드가 열 아래로 나열됩니다. 노드는 세대별로 들여쓰기되고 Excel 개요로 그룹화되어 각 수준을 접을 수 있습니다.

PlaidXL은 셀 위에서 가장 가까운 차원 이름으로 차원을 판단합니다. 차원 이름이 없으면 해당 시트에서 마지막으로 드릴한 차원을 사용합니다. 차원 이름과 노드처럼 나란히 있는 두 셀을 선택할 수도 있으며, 이 경우 드릴은 노드가 있는 셀에 들어갑니다.

차원의 맨 위에서 시작하려면 차원 이름이 들어 있는 셀 또는 그 아래의 빈 셀을 선택하십시오. 드릴은 이름 아래에 만들어지며 차원의 최상위 노드에서 시작합니다.

### 드릴 안에서 드릴

기존 드릴의 행에서 같은 명령을 사용합니다.

- **One level**은 해당 행의 하위 항목을 제자리에서 열며 나머지 목록은 그대로 둡니다.
- **To lowest level**과 **All levels**는 해당 행의 노드에서 드릴을 다시 시작합니다.
- **Drill up**은 행 위에서 가장 가까운 열린 노드를 닫습니다. 닫을 노드가 없으면 드릴의 시작 노드를 상위 노드로 올립니다.

노드는 있지만 드릴이 없는 셀에서 **Drill up**을 사용하면 노드가 상위 노드로 바뀝니다.

### 보고서 값에서 드릴

보고서의 값(`CELL` 또는 `CELLS` 수식)을 선택하고 **Drill down one level**을 사용하면 해당 값의 행에 있는 행 머리글이 제자리에서 열려, 그 아래에 다음 수준의 상세 정보가 보고서에 추가됩니다. **Drill up**은 이를 다시 닫습니다. 행 제목이 드릴의 일부가 아니거나, **All levels**처럼 제자리 드릴을 하면 보고서의 행이 사라지는 경우에는 PlaidXL이 대신 내용이 채워진 **Custom drill**을 엽니다.

### 덮어쓰기와 실행 취소

드릴은 쓰기 전에 확인하지 않습니다. 새 행에 필요한 셀에 내용이 있으면 PlaidXL이 해당 셀을 지우고 메시지에 몇 개를 지웠는지 알려 줍니다. 사용하는 Excel 버전에서 편집을 그룹화할 수 있으면 드릴은 하나의 실행 취소 단계이며 **Ctrl+Z**로 모든 것이 원래대로 돌아갑니다. 이전 버전에서는 여러 단계가 될 수 있습니다. 작업 창이 열려 있으면 메시지에 **실행 취소**도 표시되며, 이 기능은 드릴이 쓴 내용이 그대로 남아 있는 셀만 복원하고 그 후에 편집한 내용은 유지합니다.

Drill 명령은 열 아래로 이어지는 드릴을 편집합니다. 보고서의 열 머리글처럼 행을 따라 가로로 이어지는 `DRILL`은 수식에서 직접 변경합니다.

## Keep Only와 Remove Only

여러 드릴에 걸쳐서라도 드릴의 행을 하나 이상 선택한 다음 다음을 사용합니다.

- **Remove only**는 선택한 노드와 그 아래의 모든 항목을 드릴에서 제거합니다. 드릴의 첫 번째 행을 제거하면 드릴이 지워집니다.
- **Keep only**는 선택한 노드만 유지합니다. 노드 하나를 선택하면 그 노드만 있는 드릴이 되고, 여러 노드를 선택하면 가장 가까운 공통 상위 노드 아래에서 원래 위치가 유지됩니다.

**Remove only**는 노드를 드릴의 `exclude` 인수에 추가합니다. **Keep only**는 드릴의 시작 노드, 키, `exclude`를 다시 씁니다. 어느 쪽이든 결과는 실시간으로 유지됩니다. PlaidXL은 선택한 셀을 최대 5,000개까지 읽습니다. 제거된 노드 목록이 매우 길면 수식이 참조하는 **PlaidXL Lists**라는 숨겨진 시트로 이동합니다.

## Custom Drill

**Custom drill...** 은 선택한 셀을 바탕으로 내용이 채워진 상태로 **A list of dimension nodes**의 **Formulas** 탭을 엽니다.

- **Start from node** — 비워 두면 차원의 맨 위에서 시작합니다.
- **How far to drill** — **All levels**, **Lowest level only**, 지정한 수준 수만큼 **Down**, 한 수준에서 다른 수준까지 **From level**, 마지막 몇 수준을 제외한 **All but the last**, 또는 `[1:3]` 같은 **Advanced (type the drill key)** 입니다.
- **Alternate hierarchy (optional)**.
- **Exclude nodes (optional, one id per line)** 및 **Open nodes (optional, one id per line)** — 제외할 노드와 하위 항목도 함께 표시할 노드입니다.

필드 옆의 **Use selected cell**은 선택한 셀이나 범위를 가리키게 하므로 드릴이 그 셀을 따라갑니다. **행**에서는 처음 10개 노드와 전체 개수를 미리 볼 수 있으며, **모두 표시**를 클릭하면 더 볼 수 있습니다. **Insert in active cell**을 클릭하면 시작한 드릴을 변경하거나 활성 셀에 새 드릴을 넣고, **복사**를 클릭하면 수식을 직접 붙여 넣을 수 있습니다.

## 멤버 선택

**Pick member...** 는 선택한 셀의 차원에 대한 멤버 선택기를 열며, 이미 셀의 텍스트를 검색한 상태입니다. **차원** 탭에서 열 수도 있습니다.

- **Search id or alias**는 차원의 모든 계층을 검색하고 일치하는 항목마다 경로를 표시합니다.
- 차원에 계층이 둘 이상이면 목록에서 계층을 선택합니다.
- 화살표 키로 트리를 탐색하고, **공백**으로 노드를 선택하고, **Enter**를 눌러 삽입합니다.

**삽입**은 노드의 ID를 활성 셀에 쓰고 한 행 아래로 이동합니다. 노드를 선택해 둔 경우에는 활성 셀부터 아래로 채웁니다. **Fill down**과 **Fill right**는 선택한 노드를 아래로 또는 오른쪽으로 씁니다. 노드를 두 번 클릭하면 삽입됩니다. 활성 셀에 드릴이 있으면 삽입한 노드가 드릴의 시작 노드가 됩니다.

삽입하면 기존 내용 위에 쓰며, 값이 있던 셀을 몇 개 바꿨는지 알려 줍니다. 메시지에 **실행 취소**가 표시되며, 사용하는 Excel 버전에서 편집을 그룹화할 수 있으면 **Ctrl+Z**로 한 번에 취소됩니다.

### 멤버 드롭다운 추가

선택 항목을 제공해야 하는 셀(예: 기간 열)을 선택한 다음, 멤버 선택기에서 노드를 가리키고 **Add dropdown**을 클릭합니다. 선택한 각 셀에 해당 노드의 하위 항목 드롭다운이 생깁니다. 목록은 숨겨진 **PlaidXL Lists** 시트의 드릴이므로 차원이 바뀌면 업데이트됩니다. 셀은 값을 그대로 유지하며, 목록에 없는 값도 계속 허용됩니다.

실시간 목록을 따르는 드롭다운에는 Microsoft 365용 Excel 또는 Excel 2024가 필요합니다. 사용하는 Excel 버전에서 편집을 그룹화할 수 있으면 **Ctrl+Z**로 드롭다운이 한 번에 제거됩니다.

## 숫자 설명

**Explain this number**는 선택한 각 PlaidXL 셀의 카드가 있는 **설명** 탭을 엽니다. `CELL`, `CELLS`, `DRILL`, `TABLE.GET_TABLE`, `METRIC`, `METRIC_BREAKDOWN`을 설명하며, `IFERROR` 같은 다른 수식 안에 있는 경우도 설명합니다. PlaidXL 수식이 아닌 셀을 선택하면 그 셀이 계산되는 근거가 된 PlaidXL 셀을 설명합니다.

각 카드에는 다음이 표시됩니다.

- 셀이 계산하는 내용 — 예를 들어 테이블에서 열의 합계를 각 노드로 필터링한 값과, 각 노드 아래의 리프 멤버 수입니다.
- 지금 계산한 값과 셀과의 일치 여부입니다. 일치하지 않으면 **Recalculate**로 셀을 최신 상태로 만듭니다.
- **Where this comes from** — 테이블 데이터가 마지막으로 업데이트된 시점, 행 수, 테이블을 만든 워크플로 단계이며 각각 PlaidCloud로 연결됩니다.
- **Open table in PlaidCloud**, **Drill through to rows**, **Copy explanation**.

필터 노드는 PlaidCloud의 해당 노드로 연결되며, 해당 노드의 **Drill** 버튼은 그 노드의 하위 항목을 행으로 추가합니다. 셀에 오류가 표시되면 카드에 이유가 나오고, 가능한 경우 해결 방법도 제공합니다. **프로젝트 선택… 버튼** 또는 가장 가까운 일치 항목이 있는 **Pick a member**가 그 예입니다.

여러 셀을 한 번에 설명하면 카드가 20개씩 로드되며, 끝에 나머지를 표시하는 버튼이 있습니다.

## 상세 행 표시

**Show detail rows**는 `CELL` 또는 `CELLS` 값의 근거가 되는 테이블 행을, 노드와 테이블 이름을 딴 새 시트에 넣습니다. PlaidXL 값으로 계산되는 셀을 선택하면 PlaidXL이 그 값을 사용합니다.

- 1행은 값을 설명하며 그 값으로 다시 연결됩니다.
- 2행은 행의 합이 값과 일치하는지 확인합니다. **ties**를 표시하거나 차이가 얼마인지 표시합니다.
- 행은 3행부터 Excel 표로 시작합니다.

행을 로드하는 동안 작업 창에 진행률과 **취소**가 표시됩니다. 같은 값에서 **Show detail rows**를 다시 실행하면 해당 시트가 새로 고쳐지고, **Refresh all tables**를 사용하면 최신 상태로 유지됩니다. 상세 시트는 [PlaidCloud에 다시 저장](/ko/reference/cli/plaidxl/retrieve/#테이블을-plaidcloud에-저장)할 수 있으며, 저장하면 해당 값의 근거가 되는 행만 바뀝니다.

<Aside type="tip">
셀이 무엇을 하는지 잘 모르겠습니까? 셀을 선택하고 **Ctrl+Alt+Shift+E**(Mac에서는 **⌘⌥⇧E**)를 눌러 설명을 확인하거나, **Ctrl+Alt+Shift+Q**를 눌러 그 셀에 대해 [Weave에 문의](/ko/reference/cli/plaidxl/weave/)하십시오.
</Aside>
