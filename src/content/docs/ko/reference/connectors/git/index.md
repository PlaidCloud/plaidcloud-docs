PlaidCloud는 Git 호스트에 연결하여 워크플로와 패널 앱이 버전 관리되는 리포지토리에서 읽을 수 있도록 합니다. 데이터베이스나 문서 계정이 아니라 소스 제어에 있는 구성, 스크립트 또는 템플릿 파일을 소스로 사용할 때 유용합니다.

## 제공자

- [PlaidCloud Git](/ko/reference/connectors/git/plaidcloud-git/) — 워크스페이스에 기본 제공되는 관리형 Git 서비스이며, 서버 URL이나 자격 증명을 구성할 필요가 없습니다
- [GitHub](/ko/reference/connectors/git/github/)
- [GitLab](/ko/reference/connectors/git/gitlab/)
- [Bitbucket](/ko/reference/connectors/git/bitbucket/)
- [Azure Repos](/ko/reference/connectors/git/azure-repos/)
- [AWS CodeCommit](/ko/reference/connectors/git/codecommit/)
