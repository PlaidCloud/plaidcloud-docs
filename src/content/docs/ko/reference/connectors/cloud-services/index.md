독자적이거나 REST가 아닌 프로토콜을 사용하는 클라우드 기반 데이터 서비스용 커넥터입니다. 데이터베이스 또는 REST 범주에 깔끔하게 맞지 않는 서비스입니다.

## 제공업체

- [Quandl](/ko/reference/connectors/cloud-services/quandl/) — 금융 및 경제 데이터(NASDAQ Data Link)
