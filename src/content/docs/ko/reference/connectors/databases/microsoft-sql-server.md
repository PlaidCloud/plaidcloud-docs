**Microsoft SQL Server**는 온프레미스 Microsoft 엔터프라이즈 스택에 흔히 포함되는 관계형 데이터베이스입니다. 이 커넥터를 사용하여 SQL Server 테이블을 읽고 쓸 수 있습니다. SQL Server 인증(사용자 이름/비밀번호)과 통합 인증을 모두 지원하며, 단순하지 않은 네트워크 배포에서는 SSL과 SSH 터널링을 사용할 수 있습니다.

## 업스트림 문서
[Microsoft SQL Server 문서](https://learn.microsoft.com/en-us/sql/sql-server/).

## 구성

이 필드는 연결을 만들거나 편집할 때 나타납니다. 필수 여부는 사용하도록 설정한 인증 옵션에 따라 달라집니다.

### 식별

| 필드 | 유형 | 설명 |
|---|---|---|
| 이름 | 텍스트 | 이 연결의 표시 이름입니다. |
| 별칭 | 텍스트(여러 줄) | 연결에 대한 선택적 별칭 또는 메모입니다. |
| 활성 여부 | 토글 | 연결의 사용 여부입니다. 삭제하지 않고 일시 중지하려면 비활성화합니다. |
| DB 읽기 전용 | 토글 | 연결을 읽기 전용 작업으로 제한합니다. |
| 액세스 유형 | 선택 | 이 연결의 읽기 전용, 쓰기 전용 또는 읽기/쓰기 액세스 수준입니다. |

### 연결

| 필드 | 유형 | 설명 |
|---|---|---|
| DB 호스트 | 텍스트 | 데이터베이스 서버의 호스트 이름 또는 IP 주소입니다. |
| DB 포트 | 숫자 | 데이터베이스 연결에 사용하는 포트 번호입니다. |
| DB 카탈로그 | 텍스트 | 연결할 데이터베이스, 카탈로그 또는 스키마입니다. |

### 인증

| 필드 | 유형 | 설명 |
|---|---|---|
| DB 사용자 | 텍스트 | 데이터베이스 인증에 사용하는 사용자 이름입니다. |
| DB 비밀번호 | 비밀번호 | 데이터베이스 인증에 사용하는 비밀번호입니다. |

### SSL / TLS

| 필드 | 유형 | 설명 |
|---|---|---|
| SSL 사용 | 토글 | SSL/TLS로 연결을 암호화합니다. |
| SSL 모드 | 선택 | SSL 검증 모드입니다(예: disable, require, verify-ca, verify-full). |
| SSL 인증 클라이언트 인증서 | 텍스트(여러 줄) | 상호 TLS 인증을 위한 클라이언트 인증서(PEM)입니다. |
| SSL 인증 클라이언트 키 | 텍스트(여러 줄) | 상호 TLS 인증을 위한 클라이언트 개인 키(PEM)입니다. |
| SSL 인증 루트 인증서 | 텍스트(여러 줄) | 서버 인증서를 검증하기 위한 루트 CA 인증서(PEM)입니다. |
| SSL 인증 인증서 해지 | 텍스트(여러 줄) | 사용 환경에서 인증서 해지 목록을 사용하는 경우 해당 목록입니다. |

### SSH 터널

| 필드 | 유형 | 설명 |
|---|---|---|
| SSH 사용 | 토글 | SSH 배스천을 통해 연결을 터널링합니다. |
| SSH 호스트 | 텍스트 | SSH 배스천 호스트 이름입니다. |
| SSH 포트 | 숫자 | SSH 배스천 포트입니다(기본값 22). |
| SSH 사용자 | 텍스트 | SSH 배스천 사용자 이름입니다. |
| SSH 비밀번호 | 비밀번호 | SSH 배스천 비밀번호입니다(비밀번호 인증을 사용하는 경우). |
| SSH 인증서 사용 | 토글 | 비밀번호 대신 개인 키로 SSH 배스천에 인증합니다. |
| SSH 개인 키 | 텍스트(여러 줄) | 배스천 인증을 위한 SSH 개인 키(PEM)입니다. |
| SSH 호스트 키 | 텍스트(여러 줄) | 배스천 지문을 검증하기 위한 예상 SSH 호스트 키입니다. |

|---|---|---|

| 드라이버 유형 | 선택 | — |
| 사용자 인증 | 토글 | — |
