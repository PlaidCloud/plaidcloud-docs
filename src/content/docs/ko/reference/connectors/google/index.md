PlaidCloud는 Google Cloud 서비스 계정(BigQuery)과 OAuth(Google 스프레드시트)를 통해 Google 서비스에 연결합니다. 각 커넥터는 특정 Google 제품군을 대상으로 합니다.

## 제공자

- [BigQuery](/ko/reference/connectors/google/big-query/) — Google의 클라우드 데이터 웨어하우스
- [Google 스프레드시트](/ko/reference/connectors/google/gspread/) — 스프레드시트 데이터 읽기 및 쓰기
