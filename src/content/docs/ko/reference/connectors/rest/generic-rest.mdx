**범용 REST 연결**은 전용 커넥터가 없는 모든 HTTP/REST 서비스에 PlaidCloud를 연결합니다. 일반적인 인증 방식(None, Basic, API 키, Bearer 토큰, OAuth 2.0), 기본 요청 헤더, 세부적인 리디렉션 및 전송 처리, 양식 내 요청 테스터를 지원합니다.

Savant 가져오기 도구와 같은 변환기는 암호화된 시크릿 값을 보유한 REST 연결을 만들 수 있습니다. 변환된 단계는 실행할 때 이 값을 사용합니다.

## 구성

양식에는 탭이 네 개 있습니다.

### 연결 세부 정보

| 필드 | 유형 | 설명 |
|---|---|---|
| 연결 이름 | 텍스트 | 이 연결의 표시 이름입니다. |
| 메모 | 텍스트(여러 줄) | 연결에 대한 선택적 메모입니다. |
| 호스트 또는 IP 주소 | 텍스트 | 요청이 대상으로 하는 기본 호스트입니다. |
| 활성(액세스 허용) | 토글 | 연결의 사용 여부입니다. 삭제하지 않고 일시 중지하려면 비활성화합니다. |
| 인증 유형 | 선택 | `None`, `Basic`, `API Key`, `Bearer Token`, `OAuth 2.0`, `Azure Cosmos DB (Master Key)` 또는 `Azure Cosmos DB (Microsoft Entra ID)`입니다. 유형을 선택하면 **인증** 탭에서 해당하는 그룹이 활성화됩니다. |
| 보안 모델 | 선택 | 연결을 사용할 수 있는 대상으로, 비공개, 특정 멤버, 특정 보안 그룹 또는 모든 작업 영역 멤버입니다. |

#### 연결 설정

| 설정 | 기본값 | 설명 |
|---|---|---|
| SSL 인증서 확인 사용 | 끔 | 요청을 보낼 때 SSL 인증서를 확인합니다. 확인에 실패하면 요청이 중단됩니다. |
| 리디렉션 자동 따르기 | 켬 | HTTP 3xx 응답을 리디렉션으로 따릅니다. |
| 원래 HTTP 메서드 따르기 | 끔 | 기본값인 GET으로 리디렉션하는 대신 원래 HTTP 메서드로 리디렉션합니다. |
| Authorization 헤더 따르기 | 끔 | 리디렉션이 발생할 때 authorization 헤더를 유지합니다. |
| 리디렉션 시 referer 헤더 제거 | 끔 | 리디렉션이 발생할 때 referer 헤더를 제거합니다. |
| 엄격한 HTTP 파서 사용 | 끔 | 잘못된 HTTP 헤더가 있는 응답을 거부합니다. |
| URL 자동 인코딩 | 켬 | URL의 경로, 쿼리 매개변수, 인증 필드를 인코딩합니다. |
| 쿠키 저장소 사용 안 함 | 끔 | 이 요청의 쿠키를 쿠키 저장소에 저장하지 않으며, 저장된 쿠키를 헤더로 보내지 않습니다. |
| 핸드셰이크 중 서버 암호 모음 사용 | 끔 | 핸드셰이크 중에 클라이언트의 순서 대신 서버의 암호 모음 순서를 사용합니다. |
| 최대 리디렉션 횟수 | 10 | 따라갈 리디렉션 횟수의 상한입니다. |

#### API 정의

선택 사항입니다. API의 OpenAPI 3.x 또는 Swagger 2.0 정의를 연결에 첨부하면, 이 연결을 사용하는 모든 [REST Request 단계](/ko/guides/workflows/rest-request-step/)에서 각 단계에 정의를 다시 입력하지 않고도 메서드, 매개변수, 요청 본문이 채워진 API의 엔드포인트를 나열할 수 있습니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| 정의 | 선택 | `None`, `OpenAPI / Swagger URL` 또는 `OpenAPI / Swagger file`입니다. |
| 정의 URL | 텍스트 | 명세가 게시된 주소입니다(예: `https://api.example.com/openapi.json`). URL을 선택하면 표시됩니다. |
| 정의 파일 | 파일 | Document에 저장된 `.json` 또는 `.yaml` 명세입니다. 파일을 선택하면 표시됩니다. |

REST Request 단계에서 이 연결을 선택하고 **엔드포인트 소스**를 **연결의 API 정의에서**로 설정한 다음 **카탈로그 로드**를 선택합니다.

<Aside type="note">정의 URL은 인터넷에서 접근할 수 있어야 합니다. 명세가 사용자 네트워크 내부에서만 게시되는 경우에는 Document에 업로드하고 파일로 선택하십시오.</Aside>

### 인증

선택한 `Authentication Type`에 해당하는 그룹만 표시됩니다. `None`이면 탭이 비활성화됩니다.

**Basic**

| 필드 | 유형 | 설명 |
|---|---|---|
| 사용자 | 텍스트 | Basic 인증 사용자 이름입니다. |
| 비밀번호 | 비밀번호 | Basic 인증 비밀번호입니다(쓰기 전용). |

**API Key**

| 필드 | 유형 | 설명 |
|---|---|---|
| 키 | 텍스트 | API 키 필드 이름입니다. |
| 값 | 텍스트 | API 키 값입니다. |

**Bearer Token**

| 필드 | 유형 | 설명 |
|---|---|---|
| 토큰 | 비밀번호 | Bearer 토큰입니다(쓰기 전용). |

**OAuth 2.0**

| 필드 | 유형 | 설명 |
|---|---|---|
| 인증 데이터 추가 위치 | 선택 | 인증 데이터를 `Request Headers` 또는 `Request URL`에 담아 보냅니다. |
| 헤더 접두사 | 텍스트 | authorization 헤더 값의 접두사입니다(기본값은 `Bearer`). |
| 인증 URL | 텍스트 | 권한 부여 엔드포인트입니다. |
| 액세스 토큰 URL | 텍스트 | 토큰 엔드포인트입니다. |
| 클라이언트 ID | 텍스트 | OAuth 클라이언트 식별자입니다. |
| 클라이언트 시크릿 | 텍스트 | OAuth 클라이언트 시크릿입니다. |
| 새로 고침 토큰 URL | 텍스트 | 토큰을 새로 고치는 데 사용하는 엔드포인트입니다. |
| 초기 새로 고침 토큰 | 텍스트 | 첫 교환에 사용하는 시드 새로 고침 토큰입니다. |
| 추가 토큰 요청 매개변수 | 테이블 | 토큰 요청에 함께 보내는 추가 본문 매개변수입니다(사용, 이름, 값, 설명). |
| 추가 토큰 요청 헤더 | 테이블 | 토큰 요청에 함께 보내는 추가 헤더입니다(사용, 이름, 값, 설명). |

**Azure Cosmos DB (Master Key)**

| 필드 | 유형 | 설명 |
|---|---|---|
| 마스터 키 | 비밀번호 | Cosmos DB 계정의 마스터 키입니다(쓰기 전용). Cosmos DB REST API의 요구에 따라 모든 요청이 이 키로 서명됩니다. |

**Azure Cosmos DB (Microsoft Entra ID)**

| 필드 | 유형 | 설명 |
|---|---|---|
| 액세스 토큰 URL | 텍스트 | 테넌트의 토큰 엔드포인트입니다(예: `https://login.microsoftonline.com/<tenant>/oauth2/v2.0/token`). |
| 클라이언트 ID | 텍스트 | Entra 애플리케이션의 클라이언트 ID입니다. |
| 클라이언트 시크릿 | 비밀번호 | Entra 애플리케이션의 클라이언트 시크릿입니다(쓰기 전용). |

컨테이너의 문서를 쿼리하고 쓰려면 Cosmos DB 연결을 [REST Request](/ko/reference/workflow-steps/general/rest-request/) 단계와 함께 사용하십시오. 연결의 기본 URL은 Cosmos DB 계정 엔드포인트로 설정하십시오.

### 기본 헤더

이 연결을 통한 모든 요청과 함께 보내는 헤더의 테이블입니다. 각 행에는 `Enabled`, `Header Name`, `Value`, `Description`이 있습니다. 행 버튼으로 헤더를 추가, 삽입, 삭제합니다. 이 헤더는 페이지를 나눈 읽기의 각 페이지와 행별 팬아웃의 각 요청을 포함해 연결이 보내는 모든 요청과 함께 전송되며, 개별 단계에 설정된 헤더는 같은 이름의 여기 헤더보다 우선합니다.

### 테스트

저장된 연결을 통해 임시 요청을 보내 연결이 동작하는지 확인합니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| 테스트 엔드포인트 | 텍스트 | 호출할 전체 URL입니다(예: `https://example.com/rest/test/validate`). |
| 메서드 | 선택 | `GET`, `PUT`, `POST`, `DELETE`, `HEAD` 또는 `OPTIONS`입니다. |
| 페이로드 | 코드 | 요청 본문입니다. Django/Jinja 스타일 템플릿 토큰을 지원합니다. |
| 테스트 요청 보내기 | 버튼 | 요청을 보내고 응답(또는 오류)을 표시합니다. |

<Aside type="caution">테스트 요청을 보내기 전에 연결을 저장하십시오. 테스트는 저장된 구성을 대상으로 실행되므로 저장하지 않은 연결은 거부됩니다.</Aside>

<Aside type="note">비밀번호와 토큰 필드는 쓰기 전용입니다. 저장된 연결을 다시 열면 비어 있는 것으로 표시되며, 저장할 때 비워 두면 저장된 시크릿이 유지됩니다. 값을 변경하려는 경우에만 다시 입력하십시오.</Aside>
