## API 문서
[공급업체 API 참조](https://developers.paycor.com/explore)에서 이 커넥터의 엔드포인트를 다룹니다.

## Paycor 설정
Paycor API 애플리케이션 등록 및 시작 절차는 다른 REST 제공자보다 다소 복잡합니다. [빠른 시작 페이지](https://developers.paycor.com/guides#quickStartLabel)에 설명된 단계를 반드시 따르십시오.

반드시 확보해야 하는 주요 값은 다음과 같습니다.
 - 애플리케이션 OAuth 클라이언트 ID
 - 애플리케이션 OAuth 클라이언트 시크릿
 - APIm 구독 키
 - `current` 애플리케이션 버전의 범위 키

<Aside type="caution">애플리케이션을 사용할 수 있도록 "활성화"하는 것을 잊지 마십시오</Aside>

필요에 따라 운영 또는 샌드박스를 선택하여 여기에서 활성화하십시오.

| 환경 | 활성화 양식 URL |
|-------------|---------------------|
| 샌드박스	  | https://hcm-demo.paycor.com/AppActivation/ClientActivation |
| 운영  | https://hcm.paycor.com/AppActivation/ClientActivation |

<Aside type="danger">Paycor에 조직이 여러 개 있는 경우 조직마다 별도의 로그인이 필요합니다. 병합하지 마십시오. REST 액세스용 조직별 애플리케이션을 만들려면 개발자 포털에 조직마다 고유한 전용 로그인이 필요합니다.</Aside>

## 구성

이 필드는 연결을 만들거나 편집할 때 나타납니다.

### 식별 정보

| 필드 | 유형 | 설명 |
|---|---|---|
| 이름 | 텍스트 | 이 연결의 표시 이름입니다. |
| 별칭 | 텍스트(여러 줄) | 연결에 대한 선택적 별칭 또는 메모입니다. |
| 활성 여부 | 토글 | 연결의 사용 여부입니다. 삭제하지 않고 일시 중지하려면 비활성화합니다. |
| DB 읽기 전용 | 토글 | 연결을 읽기 전용 작업으로 제한합니다. |
| 액세스 유형 | 선택 | 이 연결의 읽기 전용, 쓰기 전용 또는 읽기/쓰기 액세스 수준입니다. |

### 자격 증명

[Paycor 설정](#paycor-설정) 중에 확보한 세 가지 값을 입력하십시오. 호스트나 토큰 URL은 입력하지 않습니다. PlaidCloud가 Paycor API 호스트와 OAuth2 토큰 엔드포인트를 제공합니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| OAuth2 클라이언트 ID | 텍스트 | Paycor 앱 등록의 애플리케이션 OAuth 클라이언트 ID입니다. |
| OAuth2 클라이언트 시크릿 | 비밀번호 | 애플리케이션 OAuth 클라이언트 시크릿입니다. 암호화되어 저장됩니다. |
| Paycor 구독 키 | 텍스트 | Paycor 애플리케이션의 APIm 구독 키입니다. |

## 인증

Paycor는 권한 부여 코드 방식의 OAuth2를 사용하므로 자격 증명 입력은 전반부일 뿐이며, PlaidCloud가 데이터를 가져오도록 승인하는 일회성 Paycor 로그인도 완료해야 합니다.

1. **자격 증명을 입력하고 저장합니다.** 위의 세 값을 입력하고 연결을 저장합니다.
2. **연결합니다.** **Paycor에 연결**을 클릭합니다. PlaidCloud가 **Paycor 인증 창**을 엽니다. 이 버튼은 연결을 저장한 후에 사용할 수 있습니다.
3. **로그인하고 승인합니다.** 해당 창에서 Paycor에 로그인하고 액세스를 승인합니다. Paycor가 PlaidCloud로 되돌려 보내며, PlaidCloud는 연결에 **새로 고침 토큰**을 저장하고 이후에는 이를 사용하여 액세스 토큰을 자동으로 얻습니다.

<Aside type="caution">PlaidCloud에 대해 팝업을 허용하십시오. 인증 창이 차단되면 PlaidCloud가 알려 줍니다. 팝업을 허용한 다음 **Paycor에 연결**을 다시 클릭하십시오.</Aside>

API 호스트(`apis.paycor.com`)와 토큰 엔드포인트(`https://apis.paycor.com/sts/v1/common/token`)는 PlaidCloud가 관리합니다. 입력할 URL 필드가 없으며 편집할 필요도 없습니다.

### 만료된 연결 다시 승인

Paycor 액세스는 만료될 수 있습니다. 새로 고침 토큰이 만료되거나 취소되거나 Paycor 애플리케이션이 비활성화되는 경우입니다. 이런 일이 발생하면 연결을 사용하는 워크플로가 인증되지 않아 실패합니다. 복구하려면 다음과 같이 합니다.

1. Paycor 애플리케이션이 아직 **활성화**되어 있는지 확인합니다([Paycor 설정](#paycor-설정)의 활성화 URL 참조).
2. 연결을 열고 **Paycor에 연결**을 클릭하여 Paycor 승인을 다시 실행한 다음 로그인하고 승인합니다. 새 새로 고침 토큰이 발급되고 연결이 다시 동작합니다.

<Aside type="danger">Paycor 연결은 이 연결 양식을 통해 설정하고 복구하십시오. 범용 REST 편집기나 API로 기본 연결을 편집하면 관리되는 토큰 URL을 덮어써서 인증이 깨질 수 있습니다.</Aside>
