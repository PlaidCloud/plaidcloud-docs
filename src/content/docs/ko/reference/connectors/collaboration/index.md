PlaidCloud는 팀 채팅 플랫폼에 연결되므로 워크플로가 팀이 이미 확인하고 있는 채널로 알림, 경고 또는 상태 업데이트를 직접 보낼 수 있습니다. 주로 [Notify via Slack](/ko/reference/workflow-steps/notifications/notify-via-slack/) 및 [Notify via Microsoft Teams](/ko/reference/workflow-steps/notifications/notify-via-microsoft-teams/) 워크플로 단계와 함께 사용합니다.

## 제공업체

- [Slack](/ko/reference/connectors/collaboration/slack/)
- [Microsoft Teams](/ko/reference/connectors/collaboration/teams/)
- [Tableau](/ko/reference/connectors/collaboration/tableau/)
