PlaidCloud Lakehouse는 오픈 테이블 형식에 대해 직접 연합 쿼리를 실행할 수 있으므로, 데이터를 먼저 PlaidCloud로 옮기지 않고 제자리에서 쿼리할 수 있습니다. Iceberg, Delta Lake 또는 Hudi로 이미 관리되고 있는 외부 데이터 레이크와 레이크하우스 데이터를 조인할 때 유용합니다.

## 형식

- [Apache Iceberg](/ko/reference/connectors/open-tables/iceberg/)
- [Delta Lake](/ko/reference/connectors/open-tables/delta-lake/)
- [Apache Hudi](/ko/reference/connectors/open-tables/hudi/)
- [Apache Hive](/ko/reference/connectors/open-tables/hive/) — Hive 오픈 테이블 형식([Hive 쿼리 엔진 커넥터](/ko/reference/connectors/databases/hive/)와는 다릅니다)
