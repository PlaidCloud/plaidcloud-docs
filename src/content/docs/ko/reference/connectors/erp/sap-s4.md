S/4HANA에는 별도의 커넥터가 없습니다. PlaidCloud는 동일한 Remote Function Call 인터페이스로 두 시스템에 접근하므로 SAP ECC와 하나의 연결 유형을 공유합니다. **연결** 화면에서 **New → SAP ECC / S/4HANA 인스턴스**를 선택합니다.

**[SAP ECC 및 S/4HANA 커넥터 →](/ko/reference/connectors/erp/sap-ecc/)** — 두 세대에 해당하는 모든 구성 필드입니다.

## 업스트림 문서

[SAP S/4HANA 문서](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE)를 참조하십시오.

## 관련 항목

- [SAP 워크플로 단계](/ko/reference/workflow-steps/sap/) — 이 연결을 사용해 실행되는 단계입니다.
- [SAP Analytics Cloud(SAC)](/ko/reference/connectors/erp/sap-sac/), [SAP PaPM](/ko/reference/connectors/erp/sap-papm/), [SAP PCM](/ko/reference/connectors/erp/sap-pcm/)은 각자의 구성을 가진 별도의 커넥터입니다.
