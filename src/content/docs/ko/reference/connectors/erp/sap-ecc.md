하나의 연결 유형으로 SAP ECC와 SAP S/4HANA를 모두 지원합니다. 두 시스템 모두 애플리케이션 서버에 대한 Remote Function Call로 접근하므로, PlaidCloud는 어느 세대를 사용하는지 묻지 않습니다. **연결** 화면에서 **New → SAP ECC / S/4HANA 인스턴스**를 선택합니다.

[SAP 워크플로 단계](/ko/reference/workflow-steps/sap/)는 모두 이 유형의 연결을 사용해 실행됩니다. SAP를 검색하고 테이블, 트랜잭션, 보고서, 저장된 SAP Query를 추출하려면 [SAP ECC / S/4HANA에서 임시 추출](/ko/guides/connections/sap-adhoc-extract/)을 참조하십시오.

## 업스트림 문서

SAP는 ECC 문서를 모두 삭제했으며 현재는 [S/4HANA](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE) 문서만 제공합니다. PlaidCloud가 사용하는 RFC 인터페이스는 두 시스템에 공통입니다.

## 구성

이 필드는 연결을 만들거나 편집할 때 나타납니다.

### 계정 설명

| 필드 | 유형 | 설명 |
|---|---|---|
| 계정 이름 | 텍스트 | 단계에서 연결을 선택할 때마다 표시되는 이 연결의 표시 이름입니다. 필수입니다. |
| 메모 | 텍스트(여러 줄) | 연결에 대한 선택적 메모입니다. 예를 들어 어떤 시스템을 가리키는지, 누가 소유자인지 적습니다. |

### SAP 환경

| 필드 | 유형 | 설명 |
|---|---|---|
| 클라이언트 | 텍스트 | SAP 클라이언트 번호입니다. 예: `100`. 필수입니다. |
| 언어 | 선택 | 두 글자 SAP 코드로 된 로그온 언어입니다. 기본값은 `EN`입니다. 필수입니다. |
| 추적 수준 | 선택 | RFC 추적의 상세도로, 끔, 간략, 상세, 전체 중에서 선택합니다. 연결 문제를 진단하는 경우가 아니면 끔으로 두십시오. 필수입니다. |
| 연결 유형 | 라디오 | **단일 직접 연결 사용**은 애플리케이션 서버 하나에 접속하고, **부하 분산 다중 시스템 연결 사용**은 메시지 서버를 거칩니다. 아래 필드는 이 선택에 따라 활성화됩니다. |

**단일 직접 연결 사용**을 선택하면 다음 필드가 활성화됩니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| 호스트 | 텍스트 | 애플리케이션 서버의 호스트 이름 또는 IP 주소입니다. |
| 시스템 번호 | 텍스트 | 두 자리 SAP 시스템 번호입니다. 예: `00`. |

**부하 분산 다중 시스템 연결 사용**을 선택하면 다음 필드가 활성화됩니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| MS 호스트 | 텍스트 | 메시지 서버의 호스트 이름 또는 IP 주소입니다. |
| MS 서버 | 텍스트 | 메시지 서버 포트 또는 서비스 이름입니다. |
| 시스템 ID | 텍스트 | 세 글자 SAP 시스템 ID입니다. 예: `PRD`. |
| 그룹 | 텍스트 | 부하를 분산할 로그온 그룹입니다. 예: `PUBLIC`. |

### 인증 자격 증명

| 필드 | 유형 | 설명 |
|---|---|---|
| 사용자 | 텍스트 | RFC 호출에 사용하는 SAP 로그온 사용자입니다. 필수입니다. |
| 비밀번호 | 비밀번호 | 해당 사용자의 비밀번호입니다. 쓰기 전용이며, 편집할 때 비워 두면 저장된 비밀번호가 유지됩니다. |

### 사용

| 필드 | 유형 | 설명 |
|---|---|---|
| 활성(액세스 허용) | 토글 | 연결을 사용할 수 있는지 여부입니다. 삭제하지 않고 연결을 일시 중지하려면 선택을 해제합니다. |
| 읽기 전용 | 토글 | 연결을 읽기 작업으로 제한합니다. |

### 보안 모델

| 필드 | 유형 | 설명 |
|---|---|---|
| 보안 모델 | 선택 | 이 연결을 사용할 수 있는 대상으로, 비공개(소유자만), 특정 멤버만, 특정 보안 그룹만, 모든 작업 영역 멤버 중에서 선택합니다. |

## 연결 테스트

연결 창의 **연결 테스트**는 위의 정보로 로그온한 뒤 결과를 알려 줍니다. 기존 연결을 편집하여 설정을 변경한 경우 테스트하기 전에 비밀번호를 다시 입력하십시오. 저장된 비밀번호는 편집한 값과 함께 전송되지 않습니다.
