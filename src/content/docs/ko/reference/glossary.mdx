제품 용어를 한곳에 모은 기준 문서입니다. 가이드나 참조 페이지에서 여기에 있는 용어가 나오면 이 문서의 설명이 그 의미입니다.

## 계정

PlaidCloud 로그인입니다. 계정은 하나 이상의 조직에 속하며, 해당 조직 내의 특정 워크스페이스에 대한 액세스 권한을 부여받습니다.

## AI 어시스턴트

PlaidCloud 안에서 데이터에 대해 질문하고, 식을 생성하고, 자연어로 프로젝트를 조작할 수 있는 프로젝트 범위의 채팅 인터페이스입니다. [AI 어시스턴트 가이드](/ko/guides/ai-assistant/)를 참조하십시오.

## 배부

드라이버 데이터와 규칙을 기반으로 한 행 집합("소스")의 값을 다른 행 집합("대상")으로 분배하는 워크플로 작업입니다. 이전 가격 책정, 활동 기반 원가 계산, IT 비용 청구, 수익성 분석 등 비용 분배 문제에 사용됩니다. [배부](/ko/guides/allocations/)를 참조하십시오.

## 연결

PlaidCloud가 데이터베이스, 클라우드 스토리지 계정, ERP, REST API 같은 외부 시스템에 접근할 수 있게 해 주는 저장된 구성입니다. 연결은 워크플로 단계에서 재사용되므로 자격 증명을 한곳에서 관리할 수 있습니다. [연결(가이드)](/ko/guides/connections/) · [커넥터(참조)](/ko/reference/connectors/)를 참조하십시오.

## Dash 앱

Plotly Dash 프레임워크를 사용하여 PlaidCloud 데이터 위에 구축한 맞춤형 대화형 애플리케이션입니다. Git 리포지토리에서 게시되며 서버 Panel 앱과 동등하게 호스팅됩니다. [Dash 앱](/ko/guides/dash-apps/)을 참조하십시오.

## 대시보드

테이블과 뷰로 구축한, 게시된 대화형 프로젝트 데이터 뷰입니다. [대시보드](/ko/guides/dashboards/)를 참조하십시오.

## 차원

데이터를 분할하고 집계하는 데 사용하는 계층입니다. 비용 센터, 제품, 지역, 기간이 대표적인 차원입니다. 배부는 차원을 사용하여 무엇을 무엇에 배부할지 결정합니다. [차원](/ko/guides/dimensions/)을 참조하십시오.

## 배부 동인

배부에서 값을 대상 전체에 *어떻게* 분배할지 결정하는 데이터입니다. 예를 들어 IT 비용을 인원 수에 따라 사업부에 배부한다면 인원 수 테이블이 동인입니다.

## Lakehouse

PlaidCloud의 기반 분석 데이터 저장소입니다. 식 라이브러리는 Lakehouse 엔진별로 버전이 구분됩니다. **Lakehouse v1**(Databend 기반)과 **Lakehouse v2**(StarRocks 기반)가 있습니다. [식 참조](/ko/reference/expressions/)를 참조하십시오.

## MCP

Model Context Protocol — PlaidCloud가 AI 코딩 에이전트(Claude Code, Cursor, Copilot 등)와 통합할 때 사용하는 표준입니다. [AI 코딩 에이전트](/ko/integrations/ai-coding-agents/)를 참조하십시오.

## 멤버

워크스페이스에 대한 액세스 권한을 부여받은 사용자 계정입니다. 멤버는 워크스페이스 내의 보안 그룹에 할당되며, 보안 그룹이 멤버가 수행할 수 있는 작업을 제어합니다. [액세스 관리](/ko/administration/access/)를 참조하십시오.

## 조직

PlaidCloud의 최상위 청구 및 ID 경계입니다. 조직에는 하나 이상의 워크스페이스와 하나 이상의 멤버 계정이 포함됩니다.

## Panel 앱

주로 Panel 프레임워크를 사용하여 PlaidCloud 데이터 위에 구축한 맞춤형 대화형 애플리케이션입니다. [패널 앱](/ko/guides/panel-apps/)을 참조하십시오.

## PlaidLink

PlaidCloud의 온프레미스 커넥터 데몬입니다. Windows 서비스, Unix/Linux/Mac 데몬 또는 컨테이너 서비스로 실행되어 PlaidCloud 워크플로를 로컬 데이터 소스와 연결합니다. [PlaidLink 참조](/ko/reference/cli/plaidlink/)를 참조하십시오.

## PlaidXL

Excel용 PlaidCloud 추가 기능입니다. 워크시트에서 프로젝트 테이블과 차원을 가져와 새로 고치고, PlaidCloud 데이터에서 롤업된 값을 계산하는 `PLAIDXL` 수식을 추가합니다. [PlaidXL 참조](/ko/reference/cli/plaidxl/)를 참조하십시오.

## 프로젝트

워크스페이스 내부의 작업 단위입니다. 각 프로젝트는 자체 테이블, 워크플로, 차원, 감사 기록을 소유합니다. 프로젝트는 서로 격리되어 있어 상태를 공유하지 않습니다. [프로젝트](/ko/guides/projects/)를 참조하십시오.

## 게시

프로젝트 테이블을 외부(대시보드, BI 도구, 다운스트림 시스템)에서 사용할 수 있도록 제공합니다. [데이터 게시](/ko/guides/data/publish/)를 참조하십시오.

## 보안 그룹

워크스페이스 내부의 권한 모음입니다. 멤버를 보안 그룹에 할당하여 특정 기능(테이블 읽기, 워크플로 편집, 멤버 관리 등)을 부여합니다. [보안 그룹](/ko/administration/access/managing-security-groups-and-assignments/)을 참조하십시오.

## 단계

워크플로 내부의 단일 작업입니다. CSV 가져오기, 두 테이블 조인, 알림 전송, 배부 실행 등이 해당합니다. 단계는 범주(가져오기, 내보내기, 테이블, 배부, 차원, 문서, 알림 등)로 구분됩니다. [워크플로 단계 참조](/ko/reference/workflow-steps/)를 참조하십시오.

## 테이블

프로젝트 내부의 행과 열로 구성된 구조화된 데이터입니다. 테이블은 가져오기, 변환 또는 외부 소스에서 만들어집니다.

## 뷰

하나 이상의 테이블 위에 계층화된 저장된 쿼리 결과입니다. 다운스트림 소비자에게는 테이블처럼 동작하지만, 기본 데이터는 읽을 때마다 다시 평가됩니다.

## 워크플로

테이블에 작용하는 단계의 시퀀스입니다. PlaidCloud의 자동화 단위입니다. 워크플로는 순차적으로, 병렬로, 조건부로 또는 반복문으로 실행할 수 있습니다. [워크플로(가이드)](/ko/guides/workflows/) · [워크플로 단계(참조)](/ko/reference/workflow-steps/)를 참조하십시오.

## 워크스페이스

조직 내부에서 실제 작업이 이루어지는 격리된 환경입니다. 팀은 보통 환경(개발, 스테이징, 운영)별 또는 사업부별로 워크스페이스를 하나씩 사용합니다. 멤버는 워크스페이스 수준에서 액세스 권한을 부여받습니다. [액세스 관리](/ko/administration/access/)를 참조하십시오.
