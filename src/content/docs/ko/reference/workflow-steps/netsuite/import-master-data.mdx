## 설명

[NetSuite 연결](/ko/guides/connections/netsuite/)을 통해 NetSuite 마스터 데이터 목록을 프로젝트 테이블로 가져옵니다. 계정, 자회사, 부서, 클래스, 위치, 공급업체, 고객 중 레코드 유형 하나를 선택하면 단계가 목록을 가져와 기록합니다. SuiteQL을 작성하거나 유지 관리할 필요가 없습니다.

마스터 데이터는 잔액 및 상세 가져오기가 참조하는 기준 데이터로, 총계정원장 행이 내부 ID로 가지고 있는 계정, 자회사, 차원입니다. 이러한 내부 ID를 이름으로 변환하거나 다운스트림 조회와 조인에 활용하려면 필요한 목록을 가져오십시오. 이 단계는 미리 만들어진 [NetSuite 가져오기 단계](/ko/reference/workflow-steps/netsuite/) 중 하나이며, OAuth 토큰을 갱신하고, 큰 결과를 페이지 단위로 가져오며, 일시적인 오류를 자동으로 재시도하는 공용 읽기 계층에서 실행됩니다.

## 구성

| 필드 | 필수 | 참고 |
|---|---|---|
| NetSuite 연결 | 예 | 읽기에 사용할 NetSuite 연결로, 유형이 NetSuite인 연결만 표시됩니다. |
| 대상 테이블 | 예 | 목록을 기록할 프로젝트 테이블입니다. 실행할 때마다 전체가 덮어쓰기됩니다. |
| 레코드 유형 | 예 | 가져올 마스터 목록입니다. **계정**(기본값), **자회사**, **부서**, **클래스**, **위치**, **공급업체**, **고객** 중에서 선택합니다. |
| 비활성 포함 | 아니요 | 기본적으로 꺼져 있으며 활성 레코드만 반환합니다. 켜면 NetSuite에서 비활성으로 표시된 레코드도 포함합니다. |

<Aside type="note">
이 단계를 사용하여 다른 NetSuite 단계가 의존하는 작은 참조 테이블을 만드십시오. 예를 들어 [잔액 가져오기](/ko/reference/workflow-steps/netsuite/import-balances/) 또는 [총계정원장 상세 가져오기](/ko/reference/workflow-steps/netsuite/import-gl-detail/)를 한 자회사로 제한하기 전에, **자회사**를 한 번 가져와 자회사 내부 ID를 이름에 매핑할 수 있습니다.
</Aside>
