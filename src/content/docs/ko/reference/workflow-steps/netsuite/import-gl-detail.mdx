## 설명

[NetSuite 연결](/ko/guides/connections/netsuite/)을 통해 NetSuite의 총계정원장 거래 라인 상세를 프로젝트 테이블로 가져옵니다. 잔액의 근거가 되는 전기 수준의 라인으로, 대사, 드릴다운 또는 상세 손익계산서에 사용할 수 있습니다. 연결을 선택하고 대상 테이블 이름을 지정한 다음 기간과 자회사를 설정하면, 단계가 라인을 가져와 기록합니다. SuiteQL을 작성하거나 유지 관리할 필요가 없습니다.

이 단계는 미리 만들어진 [NetSuite 가져오기 단계](/ko/reference/workflow-steps/netsuite/) 중 하나입니다. 각 단계는 OAuth 토큰을 갱신하고, 큰 결과를 페이지 단위로 가져오며, 일시적인 오류를 자동으로 재시도하는 공용 읽기 계층에서 실행되므로, 전체 기간에 대한 가져오기도 별도 조정 없이 완전하게 반환됩니다. 라인이 아닌 기간별 잔액이 필요하면 [NetSuite: 잔액 가져오기](/ko/reference/workflow-steps/netsuite/import-balances/)를 사용하십시오.

## 구성

| 필드 | 필수 | 참고 |
|---|---|---|
| NetSuite 연결 | 예 | 읽기에 사용할 NetSuite 연결로, 유형이 NetSuite인 연결만 표시됩니다. |
| 대상 테이블 | 예 | 거래 라인을 기록할 프로젝트 테이블입니다. 실행할 때마다 전체가 덮어쓰기됩니다. |
| 시작 날짜 | 아니요 | 포함할 가장 이른 거래 날짜이며 `YYYY-MM-DD` 형식으로 해당 날짜를 포함합니다. 비워 두면 하한이 없습니다. 종료 날짜와 함께 지정하면 NetSuite의 SuiteQL 행 한도를 넘지 않도록 가져오기가 날짜 구간으로 자동 분할됩니다. 아래 주의 사항을 참조하십시오. |
| 종료 날짜 | 아니요 | 포함할 가장 늦은 거래 날짜이며 `YYYY-MM-DD` 형식으로 해당 날짜를 포함합니다. 비워 두면 상한이 없습니다. |
| 자회사 | 아니요 | 가져오기를 한 자회사로 제한하기 위한 NetSuite 자회사 내부 ID입니다. 모든 자회사를 가져오려면 비워 두십시오. |
| 회계 장부 | 아니요 | NetSuite 회계 장부 내부 ID입니다. 비워 두면 **기본 장부(내부 ID 1)만** 가져오며, `all`을 입력하면 모든 장부를 합산합니다. |
| 계정 번호 | 아니요 | 가져오기를 하나의 계정으로 제한하기 위한 정확한 총계정원장 계정 번호입니다. 모든 계정을 가져오려면 비워 두십시오. |
| 전기 기간 | 아니요 | NetSuite 전기/회계 기간 내부 ID입니다. 모든 기간을 가져오려면 비워 두십시오. |

<Aside type="caution">
**다중 장부 계정:** 다중 장부 회계를 사용하는 NetSuite 계정은 거래 라인마다 장부별로 한 행씩 전기하므로, 필터 없이 모든 장부를 가져오면 합계가 장부 수만큼 중복 계산됩니다. 회계 장부를 비워 두면 **기본 장부만** 가져옵니다. 장부 간 합계가 의도적으로 필요한 경우에만 `all`로 설정하고, 특정 장부만 가져오려면 해당 장부의 내부 ID로 설정하십시오.
</Aside>

<Aside type="note">
기간은 필요한 범위로 제한하십시오. 실행할 때마다 대상 테이블 전체가 교체되므로 예약된 가져오기는 매번 전체 결과를 다시 추출합니다. 롤링 날짜 구간을 사용하면 전체 이력을 다시 읽지 않고도 반복 실행되는 총계정원장 가져오기를 빠르게 유지할 수 있습니다.
</Aside>

<Aside type="note">
NetSuite의 SuiteQL API는 SuiteAnalytics Connect 없이 단일 쿼리를 약 100,000개 행으로 제한합니다. 시작 날짜와 종료 날짜를 모두 지정하면 PlaidCloud가 이 한도를 넘지 않도록 가져오기를 미리 구간으로 분할합니다. 총계정원장 상세는 이 한도에 가장 가까워지기 쉬운 가져오기이므로 잔액 가져오기보다 더 중요합니다. 범위가 열려 있는 가져오기가 한도를 넘는 것으로 확인되면, 잘린 결과를 조용히 반환하는 대신 날짜 범위를 추가하라는 메시지와 함께 실패합니다.
</Aside>
