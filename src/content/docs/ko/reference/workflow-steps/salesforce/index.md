[Salesforce 연결](/ko/guides/connections/salesforce/)을 통해 Salesforce 데이터를 읽는 워크플로 단계입니다. 개체 목록, 필드 목록, 모든 열의 유형은 조직 자체의 메타데이터에서 가져오므로 작성할 쿼리도, 추측할 유형도 없습니다.

## 단계

- [Salesforce: 개체 쿼리](/ko/reference/workflow-steps/salesforce/query-salesforce-object/) — Salesforce에서 필터링한 표준 또는 사용자 지정 개체 하나를 Bulk API 2.0으로 프로젝트 테이블에 추출합니다.
