## 설명

[Anaplan 연결](/ko/guides/connections/anaplan/)을 통해 Anaplan의 대용량 읽기 요청 경로로 저장된 **Anaplan** 뷰의 데이터를 읽습니다. 뷰는 **저장된 그대로** 읽으며, 이 단계에서는 행, 열, 페이지를 임의로 선택할 수 없습니다. 다른 부분을 읽으려면 Anaplan에서 다른 뷰를 저장하십시오.

이 단계는 단계 메뉴의 **Anaplan** 아래에 표시됩니다.

이 단계는 Anaplan의 Integration API를 통해 Anaplan에 **클라우드 직접** 연결합니다. 온프레미스 에이전트 경로는 없습니다.

<Aside type="tip">
이 커넥터는 읽기 전용이며, 기본(사용자 이름과 비밀번호) 자격 증명 또는 CA 인증서 자격 증명으로 인증합니다. [인증](/ko/guides/connections/anaplan/#인증)을 참조하십시오. Anaplan의 요청 한도는 테넌트 전체에서 공유되므로, 이 단계의 일정을 다른 Anaplan 워크플로와 겹치지 않게 분산하십시오. [일정 관련 고려 사항](/ko/guides/connections/anaplan/#일정-관련-고려-사항)을 참조하십시오.
</Aside>

## 구성

### 소스 및 대상

| 필드 | 필수 | 참고 |
|---|---|---|
| Anaplan 연결 | 예 | 데이터를 읽을 [Anaplan 연결](/ko/guides/connections/anaplan/)입니다. |
| 환경 | 예 | 연결의 환경입니다. |
| 워크스페이스 | 아니요 | 연결에 저장된 워크스페이스 ID를 재정의합니다. 연결에서 실시간으로 검색하거나 직접 입력합니다. |
| 모델 | 아니요 | 연결에 저장된 모델 ID를 재정의합니다. 워크스페이스를 선택한 후 실시간으로 검색하거나 직접 입력합니다. |
| 뷰 | 예 | 읽을 저장된 Anaplan 뷰입니다. 모델을 선택한 후 실시간으로 검색하거나 직접 입력합니다. |
| 폴링 시도 횟수 | 예 | 기본값은 120입니다. 단계가 거부되기 전에 읽기 요청의 완료 여부를 폴링하는 횟수입니다. 이때 요청 ID를 함께 알려 줍니다. 두 번째 요청을 조용히 제출하는 일은 없습니다. |
| 폴링 간격(초) | 예 | 기본값은 5입니다. 폴링 사이에 대기하는 시간(초)입니다. |
| 대상 테이블 | 예 | 반환된 뷰를 저장할 테이블입니다. |

## 이 단계에서 표현할 수 없는 항목

| 제한 사항 | 의미 |
|---|---|
| 슬라이스 제어 없음 | 뷰는 저장된 그대로 읽으며 행, 열, 페이지 선택을 지원하지 않습니다. Anaplan의 페이지 선택기는 동기식 미리 보기 엔드포인트에서만 문서화되어 있으며, 이 단계가 게시하는 대용량 읽기 요청 본문에는 내보내기 유형 외에 다른 항목이 없습니다. 다른 부분을 읽으려면 다른 저장된 뷰를 만드십시오. 보통 Boolean 라인 항목과 필터를 함께 사용합니다. |
| 선언된 형식은 라인 항목이 열에 있을 때만 적용됨 | 라인 항목이 뷰의 열 축에 있으면 각 데이터 열은 해당 라인 항목에 선언된 Anaplan 형식(숫자, 텍스트, Boolean, 날짜, 시간 기간 또는 목록)에 맞는 형식으로 저장됩니다. 라인 항목이 행에 있거나(일반적인 손익계산서 레이아웃) 뷰에 아예 없으면 모든 데이터 열이 텍스트로 저장되고 이름이 지정된 경고가 표시됩니다. 데이터 열 하나가 여러 라인 항목, 즉 여러 형식에 걸쳐 있을 수 있는 반면 테이블 열은 정확히 하나의 형식만 가질 수 있기 때문입니다. |
| 페이지 선택기 값은 열로 저장되지 않음 | 뷰에 저장된 페이지 선택기 멤버는 CSV 헤더에 포함되어 전달되며 그곳에서 소비됩니다. 대상 테이블에는 열로 나타나지 않습니다. |
| 모호한 숫자는 추측하지 않고 거부됨 | 숫자로 선언된 값에 천 단위 구분 기호가 있거나 일반 소수와 유럽식 표기 모두로 읽힐 수 있는 값(예: `1.234`)은 같은 열의 다른 값으로 어느 쪽이 맞는지 확인할 수 없는 한 구문 분석하지 않고 이름과 함께 거부됩니다. 이 읽기 경로에는 모호성을 해소할 로캘 필드가 없습니다. 구문 분석되는 값은 반올림 오류 없이 전체 정밀도로 저장되며, 빈 셀은 항상 빈 값으로 저장됩니다. |
| 빈 뷰는 경고와 함께 빈 상태로 저장됨 | 필터와 일치하는 항목이 없는 저장된 뷰는 대상 테이블을 빈 테이블로 교체하고 경고합니다. 이는 실패가 아니라 정상적인 결과입니다. 단, 행 축에 차원이 없는 뷰는 예외입니다. 빈 결과를 검증할 행 레이블 모서리가 없으므로, 헤더를 잘못 해석하여 테이블을 비우는 위험을 감수하지 않고 단계가 거부됩니다. |
| 읽기 전용 | Anaplan에는 아무것도 다시 쓰지 않습니다. |
