## 설명

[Anaplan 연결](/ko/guides/connections/anaplan/)을 통해 Anaplan의 대용량 읽기 요청 경로로 저장된 **Anaplan** 뷰의 데이터를 읽습니다. 뷰는 **저장된 그대로** 읽으며, 이 단계에서는 임시 행, 열, 페이지 선택이 없습니다. 다른 조각을 읽으려면 Anaplan에서 다른 뷰를 저장하십시오.

이 단계는 단계 메뉴의 **Anaplan** 아래에 표시됩니다.

이 단계는 Anaplan의 Integration API를 통해 Anaplan에 **클라우드에서 직접** 접근하며, 온프레미스 에이전트 경로는 없습니다.

<Aside type="tip">
이 커넥터는 읽기 전용이며 기본(사용자 이름과 비밀번호) 또는 CA 인증서 자격 증명으로 인증합니다. [인증](/ko/guides/connections/anaplan/#인증)을 참조하십시오. Anaplan의 요청 한도는 테넌트 전체에서 공유되므로, 이 단계의 일정을 다른 Anaplan 워크플로와 엇갈리게 설정하십시오. [일정 고려 사항](/ko/guides/connections/anaplan/#일정-관련-고려-사항)을 참조하십시오.
</Aside>

## 구성

### 소스 및 대상

| 필드 | 필수 | 참고 |
|---|---|---|
| Anaplan 연결 | 예 | 읽을 때 사용할 [Anaplan 연결](/ko/guides/connections/anaplan/)입니다. |
| 환경 | 예 | 연결의 환경입니다. |
| 워크스페이스 | 아니요 | 연결에 저장된 워크스페이스 ID를 재정의합니다. 연결에서 실시간으로 검색하거나 직접 입력합니다. |
| 모델 | 아니요 | 연결에 저장된 모델 ID를 재정의합니다. 워크스페이스를 선택하면 실시간으로 검색되며, 직접 입력할 수도 있습니다. |
| 뷰 | 예 | 읽을 저장된 Anaplan 뷰입니다. 모델을 선택하면 실시간으로 검색되며, 직접 입력할 수도 있습니다. |
| 폴링 시도 횟수 | 예 | 기본값은 120입니다. 단계가 거부하기 전에 읽기 요청의 완료 여부를 폴링하는 횟수이며, 거부할 때 요청 ID를 명시합니다. 두 번째 요청을 조용히 제출하지는 않습니다. |
| 폴링 간격(초) | 예 | 기본값은 5입니다. 폴링 사이에 기다리는 시간(초)입니다. |
| 대상 테이블 | 예 | 반환된 뷰가 적재되는 테이블입니다. |

## 미리 보기

**소스** 탭의 **미리 보기**는 단계를 실행하지 않고 이 뷰 읽기가 생성할 열과 데이터 유형을 보여 줍니다. 잠긴 프로젝트에서는 사용할 수 없습니다.

## 이 단계에서 표현할 수 없는 항목

| 제한 사항 | 의미 |
|---|---|
| 조각 제어 없음 | 뷰는 저장된 그대로 읽으며 행, 열, 페이지 선택이 없습니다. Anaplan의 페이지 선택기는 동기식 미리 보기 엔드포인트에서만 문서화되어 있으며, 이 단계가 게시하는 대용량 읽기 요청 본문은 내보내기 유형만 받습니다. 다른 조각을 읽으려면 다른 저장된 뷰(보통 부울 라인 항목과 필터)를 만드십시오. |
| 선언된 유형은 Line Items가 열에 있을 때만 적재됨 | Line Items가 뷰의 열 축에 있으면 각 데이터 열이 라인 항목에 선언된 Anaplan 형식(Number, Text, Boolean, Date, Time Period 또는 List)에 따라 유형이 지정되어 적재됩니다. Line Items가 행에 있거나(일반적인 손익계산서 레이아웃) 뷰에 아예 없으면 명명된 경고와 함께 모든 데이터 열이 텍스트로 적재됩니다. 그렇지 않으면 데이터 열 하나가 여러 라인 항목, 즉 여러 형식에 걸치게 되는데 테이블 열은 정확히 하나의 유형만 가지기 때문입니다. |
| 페이지 선택기 값은 열로 적재되지 않음 | 뷰에 저장된 페이지 선택기 멤버는 CSV 헤더에 포함되어 그곳에서 소비되며, 대상 테이블의 열로 나타나지 않습니다. |
| 모호한 숫자는 추측하지 않고 거부됨 | 천 단위 구분 기호가 있는 Number 선언 값이나 일반 소수와 유럽식 표기로 똑같이 읽히는 값(예: `1.234`)은 다른 값이 같은 열에서 올바른 해석을 결정해 주지 않는 한 파싱되지 않고 이름과 함께 거부됩니다. 이 읽기 경로에는 모호성을 해결할 로캘 필드가 없습니다. 파싱되는 값은 반올림 오류 없이 전체 정밀도로 적재되며, 빈 셀은 항상 빈 값으로 적재됩니다. |
| 빈 뷰는 경고와 함께 빈 상태로 적재됨 | 필터와 일치하는 항목이 없는 저장된 뷰는 대상 테이블을 빈 테이블로 교체하고 경고합니다. 이는 실패가 아니라 일반적인 결과입니다. 단, 행 축에 차원이 없는 뷰는 예외입니다. 빈 결과를 검증할 행 레이블 모서리가 없으므로, 헤더를 잘못 읽어 테이블을 비우는 위험을 감수하는 대신 단계가 거부합니다. |
| 읽기 전용 | Anaplan에는 아무것도 다시 쓰지 않습니다. |
