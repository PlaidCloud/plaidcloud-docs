[Anaplan 연결](/ko/guides/connections/anaplan/)을 통해 **Anaplan**에서 데이터를 읽는 워크플로 단계입니다. 대용량 읽기 요청 경로로 저장된 뷰를 읽거나, Bulk API로 이미 있는 내보내기 작업을 실행하거나, 하나 이상의 목록을 PlaidCloud 차원으로 로드합니다. Anaplan에는 Integration API를 통해 **클라우드 직접**으로 연결하며, 이 단계들에는 온프레미스 에이전트 경로가 없고 Anaplan에 다시 쓰는 단계도 없습니다.

## 단계

- [Anaplan: 뷰 읽기](/ko/reference/workflow-steps/anaplan/anaplan-read-view/) — 저장된 뷰를 저장된 그대로 읽습니다. 클라우드 직접.
- [Anaplan: 내보내기 읽기](/ko/reference/workflow-steps/anaplan/anaplan-read-export/) — 이미 있는 내보내기 작업을 실행하고 해당 파일을 저장합니다. 클라우드 직접.
- [Anaplan: 목록 읽기](/ko/reference/workflow-steps/anaplan/anaplan-read-list/) — 하나 이상의 목록을 PlaidCloud 차원으로 읽습니다. 클라우드 직접.
