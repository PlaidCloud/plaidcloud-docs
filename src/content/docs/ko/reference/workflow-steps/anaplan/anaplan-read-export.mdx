## 설명

[Anaplan 연결](/ko/guides/connections/anaplan/)을 통해 **기존** Anaplan 내보내기 작업을 실행하고, 생성된 파일을 테이블로 가져옵니다. 내보내기 작업은 모델에 이미 존재해야 합니다. API로는 만들 수 없으며, 이 단계는 내보내기 내용을 좁힐 수 없습니다. Anaplan에서 작업이 내보내도록 구성된 내용이 그대로 가져와집니다.

이 단계는 단계 메뉴의 **Anaplan** 아래에 나타납니다.

이 단계는 Bulk API를 통해 Anaplan에 **클라우드에서 직접** 접근하며, 온프레미스 에이전트 경로는 없습니다.

<Aside type="tip">
이 커넥터는 읽기 전용이며 기본(사용자 이름 및 비밀번호) 또는 CA 인증서 자격 증명으로 인증합니다. [인증](/ko/guides/connections/anaplan/#인증)을 참고하십시오. Anaplan의 요청 한도는 테넌트 전체에서 공유되므로, 이 단계의 일정을 다른 Anaplan 워크플로와 겹치지 않게 분산하십시오. [일정 고려 사항](/ko/guides/connections/anaplan/#일정-관련-고려-사항)을 참고하십시오.
</Aside>

## 구성

### 소스 및 대상

| 필드 | 필수 | 참고 |
|---|---|---|
| Anaplan 연결 | 예 | 읽기에 사용할 [Anaplan 연결](/ko/guides/connections/anaplan/)입니다. |
| 환경 | 예 | 연결의 환경입니다. |
| 워크스페이스 | 아니요 | 연결에 저장된 워크스페이스 ID를 재정의합니다. 연결에서 실시간으로 검색하거나 직접 입력합니다. |
| 모델 | 아니요 | 연결에 저장된 모델 ID를 재정의합니다. 워크스페이스를 선택하면 실시간으로 검색하거나 직접 입력합니다. |
| 내보내기 | 예 | 실행할 Anaplan 내보내기 작업입니다. 워크스페이스와 모델을 선택하면 실시간으로 검색하거나 직접 입력합니다. 여기서는 선택 항목을 재정의할 수 없으며, Anaplan에 구성된 그대로 실행됩니다. |
| 폴링 시도 횟수 | 예 | 기본값은 120입니다. 단계가 거부하기 전에 내보내기 작업의 완료 여부를 폴링하는 횟수이며, 거부 시 작업 ID를 알려 줍니다. 조용히 다시 제출하지 않습니다. Anaplan은 같은 내보내기 작업이 생성한 두 파일을 구별하는 방법을 문서화하지 않았으므로, 다시 제출하면 이번 실행에 잘못된 파일을 연결할 위험이 있습니다. |
| 폴링 간격(초) | 예 | 기본값은 5입니다. 폴링 사이에 대기하는 초 수입니다. |
| 대상 테이블 | 예 | 내보내기를 가져올 테이블입니다. 모든 열은 텍스트로 가져옵니다. |

## 이 단계에서 표현할 수 없는 항목

| 제한 사항 | 의미 |
|---|---|
| 기존 내보내기 작업 필요 | API로는 내보내기 작업을 만들 수 없으며, 이 단계가 보내는 요청에는 POV, 멤버 선택, 슬라이스 매개변수가 전혀 없습니다. Anaplan에서 작업이 내보내도록 구성된 내용이 그대로 가져와집니다. 생성되는 내용을 바꾸려면 Anaplan에서 내보내기 작업을 만들거나 편집하십시오. |
| 모든 열이 텍스트로 가져와짐 | Anaplan이 내보내기의 열 유형을 선언하려고 게시하는 필드는 Anaplan이 직접 게시한 문서 내에서도 일관성이 없으므로 열 유형을 올바르게 지정하는 데 신뢰할 수 없습니다. 이 필드로는 어떤 열에도 유형을 지정하지 않으며, 이는 의도적이고 영구적입니다. 필요한 열은 후속 단계에서 변환하십시오. |
| 숫자를 미국 형식으로 요청하며, 여전히 그룹화된 열은 수정하지 않고 표시만 함 | 내보내기 작업은 미국 숫자 형식을 요청하여 제출됩니다. 천 단위 구분 기호가 여전히 포함되어 돌아오는 열은 내보내기가 해당 형식으로 렌더링되지 않는다는 뜻입니다. 이 단계는 어느 문자가 소수점인지 추측하지 않고 값을 텍스트로 그대로 가져오며, 열 이름과 값의 예를 알려 주는 경고를 표시합니다. 이런 열은 후속 단계에서 변환하기 전에 확인하십시오. 유럽식 `1.234.567`을 `1.234`로 읽으면 값이 천 배 작아집니다. |
| 신뢰할 수 없는 추출 결과는 가져오지 않고 거부 | 다음의 경우 단계는 완전해 보이지만 그렇지 않은 테이블을 가져오는 대신 아무것도 가져오지 않습니다. 내보내기 작업이 실패하거나 Anaplan에서 성공을 보고하지 않는 경우, 작업이 취소된 경우, 단계의 폴링 한도가 소진된 후에도 작업이 계속 실행 중인 경우, 생성된 파일에 데이터가 전혀 없는 경우, 생성된 파일을 그것을 만든 내보내기와 연결할 수 없는 경우, 읽은 행 수가 Anaplan이 해당 내보내기에 대해 보고하는 행 수와 일치하지 않는 경우입니다. |
| 읽기 전용 | Anaplan에는 아무것도 다시 기록되지 않습니다. |
