## 설명

[OneStream 연결](/ko/guides/connections/onestream-for-data-foundation/)을 통해 OneStream 워크스페이스의 데이터 어댑터를 읽고 그 행을 테이블에 적재합니다. 나열한 통합 멤버마다 어댑터를 한 번씩 호출하며, 대상 테이블을 모든 멤버의 행으로 교체합니다. 통합 결과를 프로젝트로 가져올 때 사용하며, 예를 들어 모델을 그 결과에 대사하는 경우에 사용합니다.

이 단계는 단계 메뉴의 **OneStream** 아래에 나타납니다. OneStream을 소스로 추가하면 Data Foundation이 이 단계를 사용합니다.

<Aside type="note">
어댑터와 그 열은 OneStream 관리자가 만듭니다. [OneStream 관리자가 설정하는 내용](/ko/guides/connections/onestream-for-data-foundation/#onestream-관리자가-설정하는-항목)을 참조하십시오.
</Aside>

## 구성

### 소스

| 필드 | 필수 | 참고 |
|---|---|---|
| OneStream 연결 | 예 | 읽을 때 사용할 [OneStream 연결](/ko/guides/connections/onestream-for-data-foundation/)입니다. |
| 환경 | 아니요 | 연결의 환경입니다. 기본값은 `default`입니다. |
| 애플리케이션 | 아니요 | 연결에 저장된 애플리케이션을 사용하려면 비워 둡니다. 단계 또는 연결 중 하나에는 반드시 있어야 합니다. |
| 워크스페이스 | 아니요 | 연결에 저장된 워크스페이스를 사용하려면 비워 둡니다. |
| 어댑터 | 예 | 읽을 데이터 어댑터입니다. `Foundation_Results`는 연결 페이지에 설명된 어댑터입니다. |
| 어댑터 테이블 | 아니요 | 어댑터의 데이터 세트 내 테이블 이름입니다. |
| 시퀀스 먼저 실행 | 아니요 | 읽기 전에 실행하여 어댑터가 읽는 내용을 새로 고치는 Data Management 시퀀스입니다. |

### 데이터 조각

| 필드 | 참고 |
|---|---|
| 멤버 | 한 줄에 통합 멤버 하나입니다. 단계는 멤버마다 어댑터를 한 번씩 호출하며, 멤버를 대체 변수 `Member`에 전달합니다. 비워 두면 어댑터의 기본 멤버로 한 번 호출합니다. |
| 대체 변수 | 한 줄에 `Name=Value` 하나입니다. 예: `Time=2026M1`. |
| 뷰 | **누계**(기본값) 또는 **기간별**입니다. 대체 변수 `View`로 어댑터에 전달됩니다. |
| 부호 | **저장된 그대로**(기본값) 또는 모든 금액의 부호를 반전하는 **부호 반전**입니다. |
| 금액 단위 | 모든 금액에 적용되는 배수입니다. 기본값은 1입니다. OneStream이 값을 천 단위로 제공하면 1000을 사용합니다. |

애플리케이션, 워크스페이스, 테이블, 시퀀스, 멤버, 대체 값의 변수는 워크플로가 실행될 때 채워집니다.

### 대상

| 필드 | 필수 | 참고 |
|---|---|---|
| 대상 테이블 | 예 | 행이 적재되는 테이블입니다. 실행할 때마다 교체되며 뷰가 아닌 테이블이어야 합니다. |

## 출력

대상 테이블에는 어댑터의 열인 `entity`, `account`, `time`, `scenario`, `view`, `amount`, `currency`, `flow`, `ud1`, `ud2`, `ud3`, `ud4`가 있습니다. 모든 열은 텍스트로 적재되며, 단위와 부호가 적용된 후 숫자가 되는 `amount`만 예외입니다.

어댑터에서 행이 반환되지 않으면 대상 테이블이 빈 테이블로 교체되고, 단계는 오류가 아니라 어댑터 이름을 포함한 경고와 함께 완료됩니다.
