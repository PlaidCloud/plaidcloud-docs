### 설명


동일한 모델 내에서 SAP Profitability and Cost Management(PCM) 모델 버전을 복사합니다.


### 당사의 자격


PlaidCloud는 공식 SAP 파트너이며 SAP PCM 모델 설계 및 구현과 관련된 서비스의 우선 공급업체입니다.


### 예제


드롭다운에서 사용할 에이전트를 선택하고, “모델 정보” 필드에 “Model Name”, “Origin Period Name”, “Destination Period Name”을 입력합니다. “Wait for Copy to Complete” 체크박스를 선택한 다음 “Save and Run Step”을 클릭합니다.
