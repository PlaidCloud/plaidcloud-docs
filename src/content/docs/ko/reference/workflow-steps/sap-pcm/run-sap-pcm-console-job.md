## 설명



원격 PCM 서버의 SAP PCM 콘솔에서 작업을 시작합니다. 일반적으로 PCM이 모델 계산 API가 아닌 콘솔 인터페이스를 통해 제공하는 관리 작업이나 배치 작업에 사용합니다.

사용 사례로는 아카이브 작업, 하이퍼로더 실행 또는 공급업체별 유지 관리 루틴이 있습니다. 정확한 작업과 매개변수는 PCM 배포 환경에 따라 다릅니다.


## 당사의 자격


PlaidCloud는 공식 SAP 파트너이며 SAP PCM 모델 설계 및 구현과 관련된 서비스의 우선 공급업체입니다.








## 예제


드롭다운에서 사용할 에이전트를 선택하고, “Console File Path” 필드에 콘솔 파일 경로를 입력하고, (필요한 경우) “Wait for Console Job to Complete” 체크박스를 선택한 다음 “Save and Run Step”을 클릭합니다.
