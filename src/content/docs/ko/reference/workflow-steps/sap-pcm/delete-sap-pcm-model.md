## 설명


검색 조건과 일치하는 SAP Profitability and Cost Management(PCM) 모델을 삭제합니다. 이 변환으로 모델을 삭제하면 진행 상황을 지켜보지 않고도 많은 모델을 삭제할 수 있습니다.



## 당사의 자격


PlaidCloud는 공식 SAP 파트너이며 SAP PCM 모델 설계 및 구현과 관련된 서비스의 우선 공급업체입니다.







## 예제


드롭다운에서 “Agent to Use”를 선택합니다. 원하는 “Model Search Method”를 선택합니다. 이 예제에서는 “Exact Match”를 선택했습니다. “Model Name Information” 아래의 “Model Search Text”(찾으려는 내용)를 입력하고 검색 시 대소문자를 구분할지 결정합니다(구분하려면 체크박스를 선택). 마지막으로 “Wait for Deletion to Complete”를 선택하고 “Save and Run Step”을 클릭합니다.
