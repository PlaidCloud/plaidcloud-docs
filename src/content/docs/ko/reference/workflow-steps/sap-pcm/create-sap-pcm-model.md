## 설명



PCM 서버에 비어 있는 새 SAP Profitability and Cost Management(PCM) 모델을 생성합니다. 모델을 프로그램 방식으로 프로비저닝할 때 유용합니다. 예를 들어 새 사업부나 시나리오에 자체 모델이 필요할 때 수동 설정을 기다리지 않고 워크플로가 모델을 바로 만들 수 있습니다.

대부분의 사용자는 빈 모델로 시작하지 않고 [Copy SAP PCM Model](/ko/reference/workflow-steps/sap-pcm/copy-sap-pcm-model/) 단계로 기존 모델 템플릿에서 복사합니다.


## 당사의 자격


PlaidCloud는 공식 SAP 파트너이며 SAP PCM 모델 설계 및 구현과 관련된 서비스의 우선 공급업체입니다.








## 예제


드롭다운에서 사용할 에이전트를 선택합니다. “모델 이름”을 입력하고 드롭다운에서 “Model type”을 선택합니다(둘 다 “모델 정보” 섹션에 있습니다). “Wait for Copy to Complete” 체크박스를 선택한 다음 “Save and Run Step”을 클릭합니다.
