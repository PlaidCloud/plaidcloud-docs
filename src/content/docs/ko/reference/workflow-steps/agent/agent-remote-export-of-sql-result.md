## 설명



PlaidLink 에이전트를 통해 원격 데이터베이스에서 SQL을 실행하고, 결과 집합을 프로젝트 테이블로 PlaidCloud에 가져옵니다. PlaidCloud에서 원본 데이터베이스에 직접 접근할 수 없지만(방화벽, VPN 전용, 온프레미스) 데이터를 가져오고 싶을 때 사용합니다.

에이전트가 쿼리를 온프레미스에서 실행하고 결과를 PlaidCloud로 스트리밍하므로, 결과가 필요해지기 전까지 자격 증명과 데이터는 모두 사용자의 네트워크 안에 머뭅니다.
