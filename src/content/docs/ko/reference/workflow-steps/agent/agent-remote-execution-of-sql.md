## 설명

PlaidLink 에이전트를 통해서만 PlaidCloud가 접근할 수 있는 데이터베이스에서 SQL을 실행합니다. 일반적으로 데이터베이스가 방화벽 뒤, 사설 네트워크 또는 온프레미스 데이터 센터에 있는 경우입니다. 에이전트가 SQL을 로컬에서 실행하고 성공 또는 실패를 PlaidCloud에 보고합니다.

원본 데이터베이스를 공용 인터넷에 노출하지 않고 PlaidCloud 워크플로의 일부로 원격 저장 프로시저, 새로 고침 루틴 또는 유지 관리 작업을 트리거할 때 사용합니다.

## 쿼리 미리 보기

**원격 실행: SQL** 단계의 **소스** 탭에서 **미리 보기**를 사용하면 문을 실행하지 않고 최대 100개 행을 볼 수 있으므로, `SELECT`를 실행하기 전에 확인할 수 있습니다. 미리 보기는 실행과 같은 방식으로 변수를 채우지만 `{x:>9}` 같은 변수 형식은 지원하지 않습니다. 데이터만 읽으며, 쓰기를 수행하는 문이나 미리 보기가 읽기 전용임을 확인할 수 없는 함수는 다음 메시지와 함께 거부됩니다. *미리 보기는 표준 SQL 함수만 지원합니다. 단계를 실행하여 결과를 확인하십시오.* 잠긴 프로젝트에서는 미리 보기를 사용할 수 없으며, 드라이버 테이블과 함께 `:name` 자리 표시자를 사용하는 문에서도 사용할 수 없습니다. 이 페이지에서 설명하는 에이전트 기반 단계에서도 사용할 수 없습니다. 해당 데이터베이스에는 에이전트만 접근할 수 있기 때문입니다.

## 행마다 문 한 번 실행

에이전트를 거치지 않고 데이터베이스에 직접 연결하는 **원격 실행: SQL** 단계는 테이블의 각 행에 대해 문을 한 번씩 실행할 수 있습니다. 예를 들어 입력 행마다 저장 프로시저를 호출할 수 있습니다. **SQL 실행**을 **행마다 한 번**으로 설정하고 **드라이버 테이블**을 선택한 다음 **매개변수**를 채웁니다. 문의 각 값을 `CALL load_region(:region, :period)`처럼 `:name` 자리 표시자로 작성하고, **매개변수**에서 각 자리 표시자를 이를 제공하는 **드라이버 열**에 매핑합니다. 각 값은 문 텍스트에 붙여 넣어지지 않고 항상 바인딩된 매개변수로 데이터베이스에 전송됩니다.

모든 매개변수에는 이름과 드라이버 열이 모두 필요하며, 매개변수를 두 번 나열할 수 없습니다. 문의 `:name`에 매핑이 없거나 매핑이 문에 없으면 양식이 경고합니다. 드라이버 테이블은 뷰가 아니라 테이블이어야 합니다. 행이 없는 드라이버 테이블은 경고와 함께 완료되며 아무것도 실행하지 않고, 행이 100,000개를 넘는 드라이버 테이블은 어느 행도 실행하지 않고 단계를 실패시키므로 먼저 필터링하십시오.

## 스크립트를 한 트랜잭션으로 실행

**원격 실행: SQL** 단계에서 **SQL을 한 트랜잭션의 문 스크립트로 실행(모두 적용되거나 전혀 적용되지 않음)**(`transaction`)을 선택하면 SQL이 문 스크립트로 하나씩 순서대로 단일 트랜잭션에서 실행되므로, 모든 문이 적용되거나 하나도 적용되지 않습니다.
