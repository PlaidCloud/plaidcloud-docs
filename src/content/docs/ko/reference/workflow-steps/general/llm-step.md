## 설명

**LLM 단계**는 대규모 언어 모델에 프롬프트를 보냅니다. Anthropic LLM 연결을 사용하면 모델이 사용자가 바인딩한 프로젝트 테이블, 차원, 문서에 범위가 지정된 액세스 권한을 얻으며(객체마다 **읽기**, **쓰기** 또는 둘 다), 쓰기가 사용된 바인딩에 결과를 직접 기록합니다. 쓰기 바인딩이 곧 단계의 출력이며, 별도의 출력 형식은 없습니다.

전체 안내는 [LLM 단계 가이드](/ko/guides/workflows/llm-step/)를 참조하십시오.

## 구성

* **LLM 연결** *(필수)* — LLM 종류의 연결입니다(예: Anthropic). 쓰기 바인딩이 있으려면 연결의 **에이전트 액세스**가 **읽기 및 쓰기**여야 합니다. **전체**도 2027년 1월 15일에 제거될 때까지는 쓰기를 허용하며, 이를 사용하는 단계는 완료될 때 경고를 기록합니다. **읽기 및 쓰기**에서는 단계가 쓰기를 선택한 바인딩에만 기록하며, 쓰기를 수행하는 SQL을 실행하거나 테이블을 만들 수 없습니다.
* **모델** *(선택)* — 기본값은 연결의 기본 모델입니다. Anthropic 연결에서는 Claude Sonnet 4.5 같은 이전 모델을 포함해 모든 Claude 모델을 사용할 수 있습니다.
* **프롬프트** *(필수)* — 바인딩된 객체를 가리키는 `{{tables.NAME}}`, `{{dimensions.NAME}}`, `{{documents.NAME}}` 참조를 지원합니다.
* **결과 스키마** *(Anthropic은 선택, 다른 제공업체는 필수)* — 캡처된 구조화 요약에 대한 JSON 스키마(루트 `"type": "object"`)입니다. Anthropic에서는 모델의 작업이 MCP 쓰기인 경우 비워 둡니다. Anthropic이 아닌 제공업체는 MCP 액세스가 없으므로 스키마가 필요합니다.
* **바인딩** — 모델이 액세스할 수 있는 테이블, 차원, 문서이며, 각각 선택기로 고르고 **읽기** 및/또는 **쓰기**를 부여합니다. 쓰기 테이블은 삽입된 행을, 쓰기 차원은 노드를, 쓰기 문서는 업로드된 파일을 받습니다.
* **한도** — 최대 출력 토큰(1,024~128,000)과 자격 증명 TTL(60~3,600초)입니다.

## 동작

* 모델 호출은 자체 작업에서 실행됩니다. 실행을 위해 수명이 짧고 범위가 지정된 자격 증명이 발급되며, 실행이 끝나면 취소됩니다.
* 액세스는 객체별, 확인란별로 제어됩니다. 모델은 읽기로 바인딩된 객체만 읽고 쓰기로 바인딩된 객체에만 기록하며, 바인딩하지 않은 객체에는 절대 액세스하지 않습니다. 쓰려면 이미 존재하는 대상 객체가 필요하며, 단계가 대상 객체를 만들지는 않습니다.
* 실행할 때마다 요금이 부과되는 제공업체 호출이 발생하며 바인딩된 객체에 기록합니다.

## 저장할 때 검사하는 항목

* **결과 스키마** — 스키마를 제공하면 유효한 JSON이고 JSON 객체여야 하며 루트에 `"type": "object"`를 선언해야 합니다. 그렇지 않으면 저장이 거부되며, 예를 들어 *결과 스키마는 루트에 "type": "object"를 선언해야 합니다.*라는 메시지가 표시됩니다.
* **바인딩과 연결** — Anthropic 연결만 모델에 바인딩에 대한 액세스를 제공합니다. 다른 제공업체의 연결에서 바인딩이 있는 단계를 저장하면 제공업체 이름과 함께 *바인딩을 제거하거나 Anthropic 연결을 선택하십시오.*라는 메시지가 표시되며 거부됩니다. **쓰기**를 선택한 바인딩에는 **에이전트 액세스**가 쓰기를 허용하는 연결이 필요합니다. 읽기 전용 연결에서는 *선택한 LLM 연결의 에이전트 액세스가 읽기 전용이므로 쓰기를 선택한 바인딩이 기록할 수 없습니다. 연결을 '읽기 및 쓰기'로 설정하거나 바인딩의 쓰기를 선택 해제하십시오.*라는 메시지와 함께 저장이 거부됩니다. 연결 없이 API를 통해 저장한 단계는 워크스페이스의 기본 LLM 연결을 기준으로 검사하며, 단계도 그 연결에서 실행됩니다. 이 연결은 관리자가 기본값으로 표시한 연결이고, 없으면 가장 최근에 업데이트된 연결입니다. 관리자가 기본값으로 표시한 연결이 없을 때 다른 LLM 연결을 편집하면 그 연결이 기본값이 되며, 단계의 다음 저장이 거부될 수 있습니다.
