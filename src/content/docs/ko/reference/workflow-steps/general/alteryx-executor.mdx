## 설명

버전이 지정된 Alteryx 동등 작업을 관리형 작업으로 실행합니다. 데이터베이스 SQL이 아니라 Shapely, scikit-learn, NLTK, Tesseract, reportlab 같은 Python 라이브러리가 필요한 [Alteryx 변환](/ko/guides/workflows/migrate-alteryx-workflows/)을 위한 범용 전달 수단입니다.

변환된 작업은 대부분 이제 읽고 편집하기 쉬운 전용 단계 유형을 갖고 있습니다. 이 단계는 그렇지 않은 작업을 위해 남아 있으며, 해당 단계 유형이 내부적으로 실행하는 대상이기도 합니다.

<Aside type="note" title="대개 직접 작성하지 않습니다">
  변환 시 필요한 곳에 이 단계가 생성됩니다. 직접 추가하는 경우는 
  [Spatial Info 단계](/ko/reference/workflow-steps/spatial/spatial-info/)처럼
  자체 단계 유형이 없는 동등 작업을 실행할 때뿐입니다.
</Aside>

## 구성

### 실행기

- **작업** — 실행할 동등 작업입니다.
- **계약 버전** — 작업이 실행되는 실행기 계약입니다. 기본값은 `v1`입니다.

### 입력 및 출력

- **소스** / **대상 테이블** — 기본 입력 테이블과 출력 테이블입니다.
- **입력 테이블** / **출력 테이블** — 둘 이상을 받거나 생성하는 작업을 위한 추가 테이블입니다.
- **입력 아티팩트** / **출력 아티팩트** — 렌더링된 이미지 같은 테이블이 아닌 입력과 출력입니다.

### 리소스

기본적으로 꺼져 있으며, 이 경우 작업에는 표준 리소스가 할당됩니다. 고급 리소스 관리를 켜면 **CPU**와 **메모리**를 직접 설정할 수 있습니다. 작업이 매우 큰 지오메트리나 모델 학습을 처리하여 기본 할당량으로는 부족할 때 설정하는 것이 좋습니다.
