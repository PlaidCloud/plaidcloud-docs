## 설명


이 변환은 PlaidLink를 사용하여 Python 파일을 실행합니다. Python 파일은 원격 시스템에서 실행됩니다.



원격 시스템의 스크립트 실행에서 전역 변수 집합을 전달할 수 있습니다.
