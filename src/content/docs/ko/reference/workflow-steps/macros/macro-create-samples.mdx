## 설명

**Create Samples (매크로)** 단계는 Alteryx *Create Samples* 패키지 매크로를 재현합니다. 워크플로 엔진에서 실행되며, 패키지 매크로의 결과는 Alteryx 매크로의 근사치입니다.

## 매개변수

- **소스/출력 테이블**.
- **추정 비율(%)** 과 **난수 시드**.
