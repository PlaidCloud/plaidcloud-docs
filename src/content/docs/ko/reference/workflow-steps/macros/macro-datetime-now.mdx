## 설명

**DateTime Now (매크로)** 단계는 Alteryx *DateTime Now* 패키지 매크로를 재현합니다. 워크플로 엔진에서 실행되며, 패키지 매크로의 결과는 Alteryx 매크로의 근사치입니다.

## 매개변수

- **출력 테이블**과 **출력 형식** 문자열.

## 출력 형식

형식 문자열은 Alteryx DateTime 도구의 토큰을 사용하며, 변환 시 작성된 그대로 유지됩니다. 비워 두면 도구 자체의 기본값인 `day, dd Month, yyyy`가 사용됩니다. 예: `Tuesday, 04 August, 2026`.

| 토큰 | 표시 내용 |
| --- | --- |
| `yyyy` / `yy` | 4자리 또는 2자리 연도 |
| `Month` / `Mon` | 전체 또는 약식 월 이름 |
| `MM` / `M` | 월 숫자(앞자리 0 포함 또는 제외) |
| `day` / `dy` | 전체 또는 약식 요일 이름 |
| `dd` / `d` | 일(앞자리 0 포함 또는 제외) |
| `HH` / `H` | 24시간제 시(앞자리 0 포함 또는 제외) |
| `hh` / `h` | 12시간제 시(앞자리 0 포함 또는 제외) |
| `mm` | 분 |
| `ss` | 초 |
| `tt` | AM 또는 PM |

토큰은 대소문자를 구분합니다. `MM`은 월이고 `mm`은 분입니다.
