Alteryx *패키지 매크로*, 즉 사용자가 직접 작성한 매크로가 아니라 Alteryx에 기본 포함된 매크로를 재현하는 워크플로 단계입니다. 각 단계는 워크플로 엔진에서 실행되며, 그 결과는 Alteryx 매크로의 근사치입니다.

이 단계들은 직접 만드는 재사용 가능한 단계 시퀀스인 [PlaidCloud 매크로](/ko/reference/workflow-steps/workflow-control/run-macro/)와 다릅니다.
