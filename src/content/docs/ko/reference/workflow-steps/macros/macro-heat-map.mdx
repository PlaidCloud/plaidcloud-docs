## 설명

**Heat Map (매크로)** 단계는 Alteryx *Heat Map* 패키지 매크로를 재현합니다. 워크플로 엔진에서 실행되며, 패키지 매크로의 결과는 Alteryx 매크로의 근사치입니다.

## 매개변수

- **소스/출력 테이블**과 **최대 거리**.
