## 설명


데이터 테이블의 사본을 만듭니다.




<SnippetCommonTableSourceAndTarget />



복사를 수행할 때 Analyze는 먼저 대상 데이터 테이블이 이미 있는지 확인합니다. 이미 있으면 **Allow Overwriting Existing Table** 확인란을 선택하지 않은 한 아무 작업도 수행하지 않습니다. 이 확인란을 선택한 경우에는 대상 테이블을 덮어씁니다.
