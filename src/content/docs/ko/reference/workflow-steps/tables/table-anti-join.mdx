## 설명


Table Anti Join은 두 테이블 간에 일치하지 않는 항목 집합을 제공합니다. 첫 번째 테이블의 항목 중 두 번째 테이블에 일치하는 항목이 없는 것의 목록을 반환합니다. 한 테이블에는 있지만 다른 테이블에는 없는 레코드를 파악할 때 매우 유용합니다.



이 작업은 외부 조인을 사용하고 조인 결과의 null 값을 필터링하여 수행할 수도 있지만, Anti Join 변환은 이를 더 효율적이고 명확한 방식으로 수행합니다.

<Aside type="note" title="이 단계는 왼쪽 조인이 아니라 왼쪽 제외 조인입니다">
Table Anti Join은 소스 B에 일치하는 항목이 **없는** 소스 A의 행을 유지합니다. 동작은 단계 유형으로 고정되어 있으므로 조인 유형 선택기는 없습니다. **왼쪽 조인**, 즉 키가 일치하는 곳에는 소스 B의 열을 채워 넣고 소스 A의 모든 행을 유지하려면 [Table Outer Join 단계](/ko/reference/workflow-steps/tables/table-outer-join/)를 사용하고 **조인 유형**을 **왼쪽 조인**으로 설정하십시오. 안티 조인은 일치하지 않는 소스 A의 행만 반환하므로 출력은 **소스 A에서만** 가져옵니다. 소스 B는 조인 키를 제공하지만 출력 열은 제공하지 않습니다.
</Aside>

## 실행 시점에 지정된 열

**실행 시점에 지정된 열도 함께 전달**을 선택하면 단계가 실행될 때 테이블에 있는 대로, 단계에 나열하지 않은 모든 소스 열을 변경 없이 그대로 전달합니다. 피벗처럼 이전 단계에서 데이터에 따라 이름이 달라지는 열을 만들어 단계를 구성할 때 그 열을 나열할 수 없는 경우에 사용합니다. 선택하지 않으면 나열한 열만 기록합니다.
