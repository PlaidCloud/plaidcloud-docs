## 설명

**테이블: 헤더 승격** 단계는 입력의 한 행을 가져와 그 값을 열 이름으로 만들고 해당 행을 제거합니다. 실제 헤더가 첫 번째 줄이 아닌 파일에 사용합니다. 이 단계는 워크플로가 실행될 때 실행되므로 이름이 데이터에서 결정됩니다.

## 소스 및 옵션

- **소스 테이블**과 **출력 테이블** — 읽을 테이블과 기록할 테이블입니다.
- **헤더 행** — 값이 열 이름이 되는 행이며, 1부터 센 번호입니다. 이 행은 데이터에서 제거됩니다. 비워 두면 헤더를 승격하지 않고 저장된 이름에 서식 단계를 적용합니다.
- **레코드 순서 열** *(선택 사항)* — 행의 순서를 정하는 열입니다. 지정하지 않으면 행을 저장된 대로 읽으므로, 어느 행이 열 이름이 되는지가 실행할 때마다 달라질 수 있습니다.
- **입력이 비어 있을 때의 열** *(선택 사항)* — 입력에 행이 없을 때 기록할 텍스트 열의 이름을 쉼표로 구분해 나열합니다.

## 서식 단계

**서식 단계** 그리드의 각 행은 승격된 이름을 변경합니다.

| 설정 | 선택 항목 |
| --- | --- |
| 동작 | **이름 바꾸기**, **유형 변경**, **숨기기**, **빈 값 채우기** |
| 일치 방식 | **포함**, **다음으로 시작**, **다음으로 끝남**, **비어 있음** |
| 일치 텍스트 | 열 이름에서 일치시킬 텍스트입니다. **비어 있음**에는 필요하지 않습니다. |
| 이름 변경 방식 | 이름 바꾸기에 사용하며 **텍스트 바꾸기**, **앞에 추가**, **뒤에 추가** 중 하나입니다 |
| 바꿀 내용 | 이름 바꾸기나 채우기에 사용할 새 텍스트 |
| 값 | **유형 변경**에 사용할 유형 |

각 단계에는 동작과 일치 방식이 필요하며, 이름 바꾸기에는 이름 변경 방식과 해당 텍스트가 필요합니다.
