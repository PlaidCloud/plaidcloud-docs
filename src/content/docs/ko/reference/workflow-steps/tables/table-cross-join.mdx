## 설명


조인 키 없이 두 데이터 테이블을 하나의 데이터 테이블로 결합하는 교차 조인 작업을 수행할 때 사용합니다.


어느 한쪽 테이블에 소스 필터를 지정하면 조인 크기를 계산하기 전에 필터가 적용됩니다. 따라서 큰 테이블에 대한 교차 조인이라도 필터링된 행이 충분히 적으면 실행됩니다.

교차 조인 방식에 대한 자세한 내용은 [Wikipedia SQL Cross Join](https://en.wikipedia.org/wiki/Join_%28SQL%29#Cross_join)을 참조하십시오.

## 실행 시점에 지정된 열

**실행 시점에 지정된 열도 함께 전달**을 선택하면 단계에 나열하지 않은 모든 소스 열이 단계 실행 시점의 테이블 상태 그대로 변경 없이 전달됩니다. 피벗처럼 이전 단계에서 데이터에 따라 열 이름이 결정되는 열을 만들어 단계를 구성할 때 열을 미리 나열할 수 없는 경우에 사용합니다. 선택하지 않으면 나열한 열만 기록됩니다.
