## 설명

**테이블: 열 삭제** 단계는 소스 테이블의 사본을 출력 테이블에 기록하되 선택한 열은 제외합니다. 나머지 열은 이름, 유형, 위치를 그대로 유지합니다.

## 소스 및 옵션

- **소스 테이블**과 **출력 테이블** — 읽을 테이블과 기록할 테이블입니다.
- **삭제할 열** — 제외할 열입니다. 하나 이상 선택해야 합니다. 소스에 없는 열은 무시되므로 이전 단계에서 해당 열을 더 이상 만들지 않아도 단계는 계속 실행됩니다.
- **숫자 순서 접두사** *(선택 사항)* — 유지되는 열 중 이 텍스트로 시작하는 열을 원래 차지하던 위치 안에서 숫자 순서로 정렬합니다. 접두사가 `Tags_`이면 `Tags_2`가 `Tags_10` 뒤가 아니라 앞에 옵니다.
- **열 이름 테이블**(`drop_from`)과 **이름이 들어 있는 열**(`drop_from_column`, 기본값 `drop`)은 **테이블로 지정된 열** 섹션에 있으며 *(선택 사항)*, 해당 열의 셀이 각각 열 이름의 JSON 목록인 테이블로서 제외할 열을 추가로 지정합니다. 이 테이블은 단계가 실행될 때 읽습니다.
