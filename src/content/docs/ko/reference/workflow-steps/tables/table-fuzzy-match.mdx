## 설명

**Fuzzy Match** 단계는 근사 필드 일치를 기준으로 두 테이블의 행을 짝짓거나 한 테이블의 중복을 제거합니다. 이 단계는 워크플로 엔진에서 실행되며, 패키지 매크로의 결과는 Alteryx 매크로의 근사치입니다.

## 매개변수

- **Left / Right Tables**와 **출력 테이블**.
- **레코드 ID 열**, **임계값**(0-100), **일치하지 않는 행도 내보내기**.
- **매치 필드** — 일치시킬 필드와 각 필드의 일치 함수(exact / jaro / levenshtein / bestof / jaro_tfidf / bestof_tfidf)입니다.
