## 설명

**테이블: JWT 인코딩** 단계는 페이로드 열의 JSON에 서명하고 토큰을 새 텍스트 열에 행마다 하나씩 기록합니다. 출력 테이블은 해당 열이 추가된 소스의 사본입니다.

## 소스 및 옵션

- **소스 테이블**과 **출력 테이블** — 읽을 테이블과 기록할 테이블입니다.
- **알고리즘** — `HS256`, `HS384`, `HS512`, `RS256`, `RS384`, `RS512` 중 하나입니다.
- **페이로드 열** — 서명할 JSON 페이로드가 들어 있는 열입니다.
- **헤더 열** *(선택 사항)* — JSON 헤더가 들어 있는 열입니다. 기본 헤더 `{"alg": …, "typ": "JWT"}`에 병합됩니다.
- **키 열** *(선택 사항)* — 서명 키가 들어 있는 열입니다. 지정하지 않으면 단계는 연결에 보관된 키로 서명합니다.
- **출력 열** — 토큰을 받을 텍스트 열의 이름입니다.

변환된 Savant 분석은 단계에 바인딩된 전용 연결에 보관된 키로 서명하므로 키가 단계 구성에 나타나지 않습니다. [Savant 분석 마이그레이션](/ko/guides/workflows/migrate-savant-analyses/#jwt_encode)을 참조하십시오.
