## 설명


지정한 조인 키를 기준으로 두 데이터 테이블을 하나의 데이터 테이블로 결합하는 내부 조인 작업을 수행할 때 사용합니다.


내부 조인 방식에 대한 자세한 내용은 [Wikipedia SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)을 참조하십시오.

## 실행 시점에 지정된 열

**실행 시점에 지정된 열도 함께 전달**을 선택하면 단계에 나열하지 않은 모든 소스 열이 단계 실행 시점의 테이블 상태 그대로 변경 없이 전달됩니다. 피벗처럼 이전 단계에서 데이터에 따라 열 이름이 결정되는 열을 만들어 단계를 구성할 때 열을 미리 나열할 수 없는 경우에 사용합니다. 선택하지 않으면 나열한 열만 기록됩니다.

## 예시


### 자동차 제조사와 모델 조인


이 예시에서는 다음 소스 데이터 테이블을 가정합니다. 먼저 자동차 제조사 목록입니다.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

다음은 제조사 ID가 있는 자동차 모델 목록입니다. 제조사가 없는 모델이 여러 개 있다는 점에 유의하십시오.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

제조사별 모델 목록을 얻으려면 *Mfg_ID*를 기준으로 조인하는 것이 합리적입니다.


먼저 **테이블 1 데이터 선택**의 매개변수를 지정합니다. 소스 데이터 테이블을 선택하면 모든 열이 나열됩니다.



다음으로 **테이블 2 데이터 선택**의 매개변수를 지정합니다. 마찬가지로 소스 데이터 테이블을 선택하면 모든 열이 나열됩니다.



마지막으로 **테이블 출력** 탭에서 조인 조건을 설정합니다. **추측** 버튼을 사용하면 Analyze가 *Mfg_ID* 열을 **조인 키**로 사용할 열로 올바르게 식별합니다. 그런 다음 


**대상 출력 열**은 **전파** 버튼으로 자동 지정됩니다. 이렇게 하면 모든 조인 열은 한 번만 포함하고 모든 테이블의 모든 열이 포함됩니다. 열은 먼저 *Manufacturer*, 다음으로 *ModelName* 순으로 알파벳순 정렬됩니다.



예상대로 최종 출력에는 두 테이블에서 모두 일치한 값만 포함됩니다. 따라서 *Porsche*는 모델이 없으므로 나타나지 않습니다. 마찬가지로 


*Batmobile*은 제조사가 없으므로(맞춤 제작품이었습니다) 포함되지 않았습니다.
