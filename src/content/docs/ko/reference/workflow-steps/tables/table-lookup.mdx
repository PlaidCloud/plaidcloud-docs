## 설명


Microsoft Excel의 vlookup 함수를 자주 사용하신다면 Table Lookup 변환이 매우 익숙하게 느껴질 것입니다. 기본적으로 같은 기능을 수행하는 변환입니다. Microsoft Excel 버전과 달리 PlaidCloud Analyze의 Table Lookup 변환은 더 유연하여, 특히 여러 열을 기준으로 일치시키고 여러 열을 반환할 수 있습니다.

## 예시


### 제품 차원 정보 조회


이 예시에서는 모델러가 주문 팩트 테이블을 이해하기 위해 제품 차원 테이블의 정보가 필요합니다. 그래서 *Import Order Fact* 테이블을 **소스 테이블**로 선택합니다. *Import Product Dim* 테이블에 원하는 조회 정보가 있으므로 이를 **Lookup Table Source**로 선택합니다. 필터를 사용할 수 있지만, 조회 데이터 테이블(그리고 다른 어떤 데이터 테이블)에도 필터를 적용하지 않았습니다.



**테이블 데이터 선택** 섹션에서는 소스 데이터 테이블의 모든 열을 대상 데이터 테이블에 매핑합니다. 



소스 데이터나 대상 데이터 어디에도 **데이터 필터**는 적용하지 않았습니다. 



마지막으로 각 테이블에 있는 *Product_ID* 필드를 사용해 소스 데이터 테이블을 조회 데이터 테이블과 일치시킵니다. *Product_Description*과 *Unit_Cost* 열만 대상 데이터 테이블에 추가되며, 이 과정에서 *Unit_Cost*의 이름은 *Retail_Unit_Cost*로 바뀝니다. 



결과 대상 데이터 테이블에는 *Product_ID* 열의 일치하는 값을 기준으로 *Product_Description*과 *Retail_Unit_Cost* 열이 추가되었습니다.
