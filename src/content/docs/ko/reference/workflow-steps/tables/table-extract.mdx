## 설명


기존 Analyze 데이터 테이블의 데이터를 다른 데이터 테이블로 추출하는 데 사용합니다. 예를 들면 다음과 같으며, 이에 국한되지 않습니다.


* 정렬
* 그룹화
* 요약
* 행 필터링/하위 집합
* 불필요한 열 삭제
* 수학 연산
* 문자열 연산

<Aside>이 변환에만 해당하는 함수는 없습니다. 모든 정렬, 그룹화, 필터링 등은 **테이블 데이터 선택** 및 **데이터 필터** 탭을 통해 다른 모든 변환에서 수행할 수 있습니다.</Aside>

## 실행 시점에 이름이 정해지는 열

**실행 시점에 지정된 열도 함께 전달**을 선택하면, 단계가 실행될 때 테이블에 있는 그대로, 단계에 나열하지 않은 모든 소스 열을 변경 없이 통과시킵니다. 피벗처럼 이전 단계가 데이터에 따라 이름이 달라지는 열을 만들어서 단계를 구성할 때 해당 열을 나열할 수 없는 경우에 사용하십시오. 끄면 나열한 열만 기록합니다.

이 옵션을 켜면 **이월 열** 섹션이 나타나며, **데이터로 이름이 정해지는 열** 섹션은 항상 사용할 수 있습니다. 필드는 다음과 같습니다.

* **이월 방식**(`carry_expression`) — 이월된 각 열을 변경 없이 쓰는 대신 이 식으로 씁니다. `__column__`은 이월된 열을 나타냅니다. 그룹화하는 단계가 실행 시점에만 알려지는 열을 포함시키는 방법이며, 집계하는 단계는 이 값이 없으면 아무것도 이월하지 않습니다. **이월 열의 형식**(`carry_dtype`)은 이월된 각 열의 데이터 형식을 설정하며(기본값은 열 자체의 형식), **이월 열의 집계**(`carry_agg`)는 집계하는 단계가 이를 처리하는 방식을 설정합니다(식이 집계할 때는 `dont_group`).
* **전달된 열 이름 바꾸기**(`carry_rename`) — 정규식 `pattern`과 일치하고 `keep`과 일치하지 않는 이름의 이월된 각 열을, 일치한 각 부분을 `replacement`로 대체하여 이름을 바꿉니다(그룹은 `\1`, 설정한 경우 처음 `max`개 일치 항목). `replacement`의 `__index__`는 `start`부터 센, 이름이 바뀐 열 중에서 해당 열의 위치입니다. 이미 사용 중인 이름에는 ` (#n)`이 추가됩니다.
* **동적 열**(`dynamic_columns`) — 데이터로 이름이 정해지는 대상 열이며, 단계가 소스에서 읽는 고유한 값마다 한 세트씩 단계 실행 시 기록됩니다. 각 항목은 `rows`(소스에 대한 식 `key`, `label`, `where`, `order`), `__key__`, `__label__`, `__index__`를 사용하는 `target` 열 또는 열 목록, 새 열이 뒤따르는 대상 열인 `after`(기본값은 끝)를 지정합니다. 값은 텍스트, 정수, 부울 또는 NULL이어야 하고, 단계는 최대 1,000개의 열을 기록하며, 출력은 테이블이어야 합니다.
