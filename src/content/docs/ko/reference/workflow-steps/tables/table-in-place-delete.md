## 설명


지정한 필터 조건을 사용해 테이블에서 삭제를 수행합니다. 이 작업은 지정한 테이블에서 직접 수행되므로 추가 테이블이 만들어지지 않습니다. 필터 조건에 맞는 행만 삭제됩니다. 데이터 크기와 관련된 문제가 있을 때 효과적인 방법일 수 있습니다.



## 삭제 매개변수


드롭다운 목록에서 삭제할 **소스** 테이블을 선택합니다. 이 목록에는 모든 *프로젝트* 및 *워크플로* 데이터 테이블이 포함됩니다.
