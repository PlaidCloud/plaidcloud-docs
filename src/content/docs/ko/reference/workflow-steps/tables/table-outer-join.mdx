## 설명


지정한 조인 키를 기준으로 두 데이터 테이블을 하나의 데이터 테이블로 결합하는 외부 조인 작업을 수행할 때 사용합니다. **조인 유형** 컨트롤은 일치하지 않는 행 중 어느 쪽을 유지할지 선택하며, **왼쪽 조인**, **오른쪽 조인**, **전체 외부 조인** 중에서 고를 수 있습니다. 기본값은 왼쪽 조인으로, 테이블 A의 모든 행을 유지하고 키가 일치하는 곳에는 테이블 B의 열을 채웁니다.


외부 조인 방식에 대한 자세한 내용은 [Wikipedia SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)을 참조하십시오.

## 실행 시점에 지정된 열

**실행 시점에 지정된 열도 함께 전달**을 선택하면 단계에 나열하지 않은 모든 소스 열이 단계 실행 시점의 테이블 상태 그대로 변경 없이 전달됩니다. 피벗처럼 이전 단계에서 데이터에 따라 열 이름이 결정되는 열을 만들어 단계를 구성할 때 열을 미리 나열할 수 없는 경우에 사용합니다. 선택하지 않으면 나열한 열만 기록됩니다.

### 조인 유형

일치하지 않는 행을 어떻게 유지할지 선택합니다.

- **왼쪽 조인** — 테이블 A의 모든 행을 유지하며, 테이블 B의 열은 조인 키가 일치하는 곳에만 채워집니다. 기본값입니다.
- **오른쪽 조인** — 테이블 B의 모든 행을 유지하며, 테이블 A의 열은 조인 키가 일치하는 곳에만 채워집니다.
- **전체 외부 조인** — 반대쪽에 일치하는 행이 있든 없든 두 테이블의 모든 행을 유지합니다.

## 예시


### 자동차 제조사와 모델 조인


이 예시에서는 다음 소스 데이터 테이블을 가정합니다. 먼저 자동차 제조사 목록입니다.




| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


다음은 제조사 ID가 있는 자동차 모델 목록입니다. 제조사가 없는 모델이 여러 개 있다는 점에 유의하십시오.




| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

제조사별 모델 목록을 얻으려면 *Mfg_ID*를 기준으로 조인하는 것이 합리적입니다. 외부 조인 개념을 활용하면 일치하는 항목이 없는 행도 출력에 표시할 수 있습니다.



먼저 **테이블 1 데이터 선택**의 매개변수를 지정합니다. 소스 데이터 테이블을 선택하면 모든 열이 나열됩니다.



다음으로 **테이블 2 데이터 선택**의 매개변수를 지정합니다. 마찬가지로 소스 데이터 테이블을 선택하면 모든 열이 나열됩니다.



마지막으로 **테이블 출력** 탭에서 조인 조건을 설정합니다. **추측** 버튼을 사용하면 Analyze가 *Mfg_ID* 열을 **조인 키**로 사용할 열로 올바르게 식별합니다. 이 예시는 두 테이블에서 일치하지 않는 행을 모두 유지하므로 **조인 유형**을 **전체 외부 조인**으로 설정합니다. 그런 다음 


**대상 출력 열**은 **전파** 버튼으로 자동 지정됩니다. 이렇게 하면 모든 테이블의 모든 열이 포함되며, 조인 열은 당연히 한 번만 포함됩니다. 열은 먼저 *Manufacturer*, 다음으로 *ModelName* 순으로 알파벳순 정렬됩니다.



예상대로 최종 출력에는 두 테이블에서 일치 여부와 관계없이 모든 행이 포함됩니다. 따라서 이번에는 모델이 없는 *Porsche*도 표시됩니다. 또한 *Batmobile*, *Lightning McQueen*, *Optimus Prime*은 제조사가 없는데도 결과에 포함됩니다. 게다가 누가 이들에게 ‘안 돼’라고 말할 수 있겠습니까?
