## 설명


실제 데이터 테이블을 삭제하지 않고 기존 데이터 테이블의 내용을 지웁니다. 결과는 행이 0개인 데이터 테이블입니다.



<SnippetCommonTableSelectionDynamic />

**검색과 일치하는 테이블**을 사용하면 **검색 경로**가 프로젝트의 최상위(`/`)일 때 **검색 텍스트**가 비어 있는 상태로는 단계가 저장되지 않습니다. 프로젝트의 모든 테이블이 비워지기 때문입니다. 일치시킬 텍스트를 입력하거나 폴더를 선택하십시오.
