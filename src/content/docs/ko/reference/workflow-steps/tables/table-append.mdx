## 설명

소스 테이블의 행을 기존 대상 테이블의 끝에 추가합니다. 대상의 기존 행은 유지되며 새 행만 삽입됩니다. 일별 추출이나 월별 로드 파일처럼 데이터가 점진적으로 도착하고, 대상을 교체하지 않고 시간이 지남에 따라 늘려 가려는 경우에 사용합니다.

추가하면서 중복을 제거해야 하면 뒤에 [Table Union Distinct 단계](/ko/reference/workflow-steps/tables/table-union-distinct/)를 이어서 사용하거나, 일부 행이 키를 기준으로 기존 레코드를 업데이트한다면 [Table Upsert 단계](/ko/reference/workflow-steps/tables/table-upsert/)를 사용하십시오.

## 로드 매개변수

### 소스 및 대상

![소스 및 대상](/images/table_source_and_target_EN.png)

소스 테이블과 대상 테이블을 설정하려면 먼저 **소스 테이블** 드롭다운 메뉴에서 추출할 데이터 테이블을 선택합니다. 그다음 **대상 테이블** 드롭다운에서 기존 테이블을 대상 테이블로 선택합니다.


## 테이블 데이터 선택

데이터 매퍼를 구성할 때는 소스 테이블의 열을 대상 테이블의 열에 매핑해야 합니다.

## 저장 시 검사 항목

- **매핑이 기존 대상 테이블에 맞습니다.** 대상 테이블이 이미 있으면 단계는 테이블에 없는 열을 매핑하거나 열에 테이블과 다른 유형을 지정할 수 없습니다. 숫자와 통화는 같은 유형으로 취급합니다. 매핑에서 생략한 테이블 열은 허용되며, 추가된 행에서 비어 있는 상태로 남습니다. 거부 메시지에는 각 차이가 명시됩니다. 예: *The target columns must match the existing target table 'sales'. Types differ: amount (table: numeric, step: text).* 아직 존재하지 않는 대상 테이블이나 변수로 지정한 테이블은 단계가 실행될 때 검사됩니다.
- **비어 있는 매핑은 자동으로 채워집니다.** 소스 테이블을 선택했지만 소스 열이나 대상 열이 없는 상태로 저장하면, **두 매핑 테이블 모두 채우기**를 선택한 것처럼 비어 있는 쪽이 소스에서 채워집니다.
