## 설명

테이블 정의와 모든 데이터를 포함해 테이블을 프로젝트에서 완전히 제거합니다. 이 작업은 되돌릴 수 없는 파괴적 작업이며, 워크플로를 실행하면 테이블이 사라집니다.

워크플로의 중간 테이블이 이후 단계에서 더 이상 필요하지 않을 때(예: 여러 단계의 변환을 마친 뒤 정리할 때) 사용합니다. 테이블을 제거하지 않고 일시적으로 비우려면 [Table Clear](/ko/reference/workflow-steps/tables/table-clear/) 단계를 대신 사용하십시오.
