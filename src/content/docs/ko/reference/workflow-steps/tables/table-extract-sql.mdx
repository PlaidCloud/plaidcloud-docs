## 설명

직접 작성한 SQL `SELECT`로 대상 테이블을 채웁니다. [Table Extract](/ko/reference/workflow-steps/tables/table-extract/) 단계는 매핑된 열과 식으로 쿼리를 만들지만, 이 단계는 쿼리를 웨어하우스에 그대로 전달합니다. 매퍼에서 조립하는 것보다 SQL로 직접 표현하는 편이 쉬운 경우에 적합합니다.

재귀 CTE, 매퍼로 기술할 수 없는 파티션에 대한 윈도 함수, 조인 단계를 쓰면 오히려 복잡해지는 여러 테이블 대상 쿼리처럼 매퍼가 지원하지 않는 구문이 필요할 때 사용하십시오.

## 고유 구성 항목

### SQL Select 쿼리

쿼리 텍스트입니다. 한 줄로 길게 쓰지 말고 열이나 절마다 한 줄씩, 들여쓰기를 적용한 읽기 쉬운 여러 줄 SQL로 작성하십시오. 단계는 작성한 내용을 그대로 보존하며, 나중에 이 단계를 여는 사람이 읽어야 하기 때문입니다.

쿼리는 프로젝트의 Lakehouse에서 실행되므로 사용할 수 있는 함수는 워크스페이스에 따라 [Lakehouse v1](/ko/reference/expressions/lakehouse-v1/) 또는 [v2](/ko/reference/expressions/lakehouse-v2/) 집합입니다.
