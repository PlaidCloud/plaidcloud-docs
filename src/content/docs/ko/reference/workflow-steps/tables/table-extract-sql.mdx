## 설명

직접 작성한 SQL `SELECT`로 대상 테이블을 채웁니다. [Table Extract 단계](/ko/reference/workflow-steps/tables/table-extract/)가 매핑된 열과 식으로 쿼리를 만드는 반면, 이 단계는 쿼리를 웨어하우스에 그대로 전달합니다. 매퍼에서 조립하는 것보다 SQL로 직접 표현하는 편이 쉬운 경우에 적합합니다.

재귀 CTE, 매퍼로 설명할 수 없는 파티션에 대한 윈도 함수, 조인 단계를 사용하면 더 복잡해지는 여러 테이블에 대한 쿼리처럼 매퍼가 지원하지 않는 구문이 필요할 때 사용하십시오.

## 고유 구성 항목

### SQL Select 쿼리

쿼리 텍스트입니다. 한 줄로 길게 쓰지 말고, 열이나 절마다 한 줄씩 읽기 쉬운 여러 줄의 들여쓰기된 SQL 형식으로 작성하십시오. 단계는 작성한 내용을 그대로 유지하며, 나중에 여는 사람이 읽어야 하기 때문입니다.

쿼리는 프로젝트의 Lakehouse에서 실행되므로 사용할 수 있는 함수는 워크스페이스에 따라 [Lakehouse v1](/ko/reference/expressions/lakehouse-v1/) 또는 [v2](/ko/reference/expressions/lakehouse-v2/) 집합입니다.

<SnippetCommonStepPreview />

다른 SQL 단계와 달리 이 단계는 변수를 채우지 않으므로 미리 보기도 변수를 채우지 않습니다.
