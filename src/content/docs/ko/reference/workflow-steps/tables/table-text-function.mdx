## 설명

**테이블: 텍스트 함수** 단계는 각 행에서 함수가 읽는 열에 텍스트 함수를 적용하고, 그 결과를 소스 테이블의 복사본에 있는 새 열에 기록합니다. 함수가 읽는 열 중 어느 하나라도 NULL이면 결과는 NULL입니다.

## 소스 및 옵션

- **소스 테이블** 및 **출력 테이블** — 읽을 테이블과 기록할 테이블입니다.
- **함수** — 적용할 함수입니다. 양식에는 아래 두 표의 함수가 제공되며, 선택한 함수가 읽는 인수마다 역할에 맞는 이름이 붙은 열 필드가 하나씩 표시됩니다.
- **인수 열** — 함수가 읽는 열이며, 표에 나열된 순서대로 지정합니다. 모두 필수입니다.
- **출력 열** — 소스 복사본에 추가되는 열의 이름입니다.

| 함수 | 인수 | 결과 |
| --- | --- | --- |
| `levenshtein` | 첫 번째 열, 두 번째 열 | 대/소문자를 구분하는 편집 거리(정수) |
| `soundex` | 텍스트 | 텍스트 |
| `json_format` | JSON | 보기 좋게 정리된 JSON 텍스트 |
| `json_field` | JSON, 경로 | 텍스트 |
| `json_set_text`, `json_set_number`, `json_set_boolean` | JSON, 경로, 값 | 값이 설정된 JSON 텍스트 |
| `regex_match` | 텍스트, 패턴, 대/소문자 구분 | 참 또는 거짓 |
| `regex_search` | 텍스트, 패턴, 발생 횟수, 대/소문자 구분 | 위치(정수) |
| `regex_extract` | 텍스트, 패턴, 발생 횟수, 대/소문자 구분 | 텍스트 |
| `regex_replace` | 텍스트, 패턴, 바꿀 텍스트, 대/소문자 구분 | 텍스트 |
| `to_text_number` | 숫자, 패턴 | 텍스트: DecimalFormat 방식의 패턴으로 쓴 숫자 |
| `to_text_datetime` | 날짜/시간, 패턴 | 텍스트: 날짜-시간 패턴으로 쓴 날짜 |
| `parse_date` | 텍스트, 패턴 | 날짜로 읽은 텍스트 |
| `parse_datetime` | 텍스트, 패턴 | 날짜-시간으로 읽은 텍스트 |

변환된 Savant 분석에는 이러한 함수가 포함될 수 있으며, 동일한 방식으로 실행됩니다. 양식에서 제공하지 않는 함수는 저장된 열을 표시하고 저장된 그대로 유지됩니다.

### 추가 함수

**함수** 목록에는 다음 함수도 제공됩니다. 변환된 KNIME 워크플로에서도 이러한 함수를 사용합니다.

| 함수 | 인수 | 결과 |
| --- | --- | --- |
| `damerau_levenshtein`, `hamming`, `lcs` | 첫 번째 열, 두 번째 열 | 해당하는 편집 거리(정수) |
| `jaro`, `jaro_winkler` | 첫 번째 열, 두 번째 열 | 1에서 유사도를 뺀 값이며, 텍스트가 같으면 0 |
| `ngram_distance` | 첫 번째 열, 두 번째 열 | 1에서 문자 바이그램의 Dice 계수를 뺀 값 |
| `jaccard_tokens`, `dice_tokens`, `cosine_tokens` | 첫 번째 열, 두 번째 열 | 1에서 두 텍스트의 단어 집합 유사도를 뺀 값이며, 어느 한쪽에 단어가 없으면 1 |
| `java_compare` | 첫 번째 열, 두 번째 열 | Java의 `compareTo`가 반환하는 것과 같은, 처음으로 다른 문자들의 차이(정수) |
| `java_regex` | 텍스트, 패턴, 바꿀 텍스트 *(바꾸기 모드에서만)* | 열에서 읽은 Java 정규식: `matches` 및 `find` 모드에서는 참 또는 거짓, `extract` 및 `replace` 모드에서는 텍스트 |
| `knime_count` | 텍스트, 검색 텍스트 | 검색 텍스트가 나타나는 횟수(정수) |
| `knime_binomial`, `long_pow` | 숫자 두 개 | 이항 계수 또는 정수 거듭제곱이며, 오버플로가 순환하는 64비트 연산으로 계산 |
| `encode`, `decode` | 텍스트 | 문자 집합으로 변환한 Base64 바이트로 나타낸 텍스트, 그리고 그 역변환 |
| `url_encode` | 텍스트 | 폼 값으로 퍼센트 인코딩한 텍스트이며, 공백은 `+`로 기록 |
| `list_sort_numeric` | 텍스트 | 구분된 텍스트로 저장된 목록을 숫자 값 기준으로 정렬한 결과 |
| `geojson_to_wkt` | JSON, 경로 | `$.a[0]` 같은 경로에 있는 GeoJSON 도형이며, 텍스트 자체인 경우 `$`, WKT로 반환 |
| `json_patch_apply` | JSON | JSON Patch 또는 Merge Patch를 적용한 문서 |
| `json_diff` | 첫 번째 JSON, 두 번째 JSON | 첫 번째 문서를 두 번째 문서로 바꾸는 JSON Patch |
| `json_schema_check` | JSON | 문서가 JSON 스키마에 대해 가진 오류를 JSON으로 반환하며, 오류가 없으면 NULL |
| `json_normalize` | JSON | 정규화된 JSON 텍스트로 나타낸 문서 |
| `json_to_xml`, `xml_to_json` | 문서 | XML 또는 JSON으로 변환한 문서 |
| `xml_well_formed` | XML | 올바른 형식의 XML이면 해당 텍스트, 아니면 NULL |
| `xslt` | XML, 스타일시트 | XSLT 스타일시트로 변환한 문서 |
| `message_text`, `message_tool_calls` | JSON | AI 메시지의 텍스트 또는 해당 도구 호출을 JSON으로 반환 |

함수의 옵션은 `function_options`에서 설정합니다.

- `java_regex` — `mode`: `matches`(기본값, 전체 텍스트), `find`(어디서든), `extract`(첫 번째 일치 항목의 `group` 그룹, 기본값 0) 또는 `replace`(일치하는 모든 항목). `flags`의 `i`는 대/소문자를 무시합니다.
- `knime_count` — `modifiers`: `i`는 대/소문자를 무시하고, `w`는 공백 사이의 전체 단어를 셉니다.
- `encode` 및 `decode` — `charset`은 Java 문자 집합 이름이며 기본값은 UTF-8입니다.
- `json_patch_apply` — `patch`는 JSON Patch 배열 또는 Merge Patch 객체이고, `merge`는 Merge Patch이면 true이며, `keep`은 패치 테스트가 실패할 때 문서를 유지합니다.
- `json_schema_check` — `schema`. `fail`은 오류를 반환하는 대신 첫 번째 오류에서 단계를 중지합니다.
- `json_normalize` — `comments`는 `/* */` 및 `//` 주석을 허용합니다. `fail`(기본값 true)은 JSON이 아닌 텍스트에서 단계를 중지하며, false이면 NULL을 반환합니다.
- `json_to_xml` — `root`, `item`, `typed`, `parent_keys`, `namespace`, `text_key`, `text_key_enabled`. `xml_to_json` — `text_key`, `comments`, `pis`.
- `list_sort_numeric` — `separator`. `empty`는 요소가 없는 목록에 기록할 텍스트이고, `missing`은 누락된 요소의 텍스트이며 맨 뒤로 정렬됩니다.

기본적으로 이 단계는 소스의 모든 열을 읽고, 모든 소스 열 다음에 출력 열을 기록합니다. 일부 열만 읽으려면 `source_columns`를 설정하고, 기록할 열을 선택하고 순서를 정하려면 `target_columns`(각 항목은 `{source, target, dtype}`)를 설정합니다. 출력 열과 이름이 같은 대상 열은 그 자리를 대신하며, 지정한 데이터 형식을 가집니다.
