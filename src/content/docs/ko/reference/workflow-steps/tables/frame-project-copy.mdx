## 설명

한 프로젝트의 테이블을 다른 프로젝트로 복사합니다. 파일로 내보냈다가 다시 가져오지 않고도 공유 참조 테이블, 게시된 결과 집합 또는 차원 기반 조회 테이블을 프로젝트 간에 가져올 때 사용합니다.

양쪽 모두 명시적으로 지정합니다. 소스 프로젝트와 테이블, 대상 프로젝트와 테이블입니다. 대상 프로젝트는 처음에는 현재 프로젝트이지만 어떤 프로젝트든 될 수 있으므로, 이 프로젝트로 복사하거나, 이 프로젝트에서 복사해 내거나, 다른 두 프로젝트 사이에서 복사할 수 있습니다. 대상 테이블은 없으면 생성되며, 뷰가 아니라 테이블이어야 합니다.

## 데이터 공유 관리

복사에는 최대 두 개의 데이터 공유가 필요합니다.

- **소스 프로젝트에서 대상 프로젝트로의 읽기**: 소스의 데이터가 소스에서 공유한 곳에만 도착하도록 합니다. **소스** 프로젝트의 **홈** 탭을 열고 **데이터 공유 관리**에서 **새 데이터 공유**를 클릭한 다음 대상 프로젝트를 선택하고 **허용된 작업**에서 **읽기**를 선택한 후 **데이터 공유 추가**를 클릭합니다.
- **대상 프로젝트에서 이 프로젝트로의 쓰기**: 대상이 다른 프로젝트인 경우 쓰기를 수행하는 워크플로가 있는 프로젝트가 대상이 됩니다. **대상** 프로젝트의 **홈** 탭을 열고 **데이터 공유 관리**에서 **새 데이터 공유**를 클릭한 다음 이 프로젝트를 선택하고 **허용된 작업**에서 **쓰기**를 선택한 후 **데이터 공유 추가**를 클릭합니다.

따라서 이 프로젝트로 복사할 때는 읽기 공유만 필요하고, 한 프로젝트 안에서 복사할 때는 어느 쪽도 필요하지 않습니다. [프로젝트 간 데이터 공유](/ko/guides/projects/managing-projects/#프로젝트-간-데이터-공유)를 참조하십시오.

필요한 공유가 없으면 단계 저장이 거부되고 실행이 실패하며, 추가해야 하는 각 공유를 명시한 메시지가 표시됩니다. 예: *Project 'Sales' can't write to project 'Finance': in project 'Finance', under Data Sharing Management, add a data share for 'Sales' that allows Write.* 거부된 실행은 대상 테이블을 만들지 않고 대상 프로젝트를 그대로 둡니다. 변수로 지정한 프로젝트는 단계가 실행될 때 검사됩니다.

이 단계는 이 프로젝트 자체의 ID로 실행되므로, 누가 시작하든 공유를 통해 실행됩니다.

## 복사 매개변수

### 읽기 원본

- **소스 프로젝트** — 복사할 원본 프로젝트입니다.
- **소스 테이블** — 복사할 테이블이며, 소스 프로젝트에서 선택합니다.

### 쓰기 대상

- **대상 프로젝트** — 복사해 넣을 프로젝트입니다. 처음에는 현재 프로젝트입니다.
- **대상 테이블** — 기록할 테이블이며, 대상 프로젝트에서 선택합니다. 다른 **대상 프로젝트**를 선택하면 이전 프로젝트에서 선택한 테이블이 지워지며, 이름이나 경로로 지정한 테이블은 유지되고 새 프로젝트에서 찾습니다.
- **기존 데이터에 추가** — 선택하면 복사한 행을 대상 테이블에 이미 있는 데이터에 추가합니다. 선택하지 않으면 테이블의 행을 소스의 행으로 바꿉니다.

볼 수 없거나 삭제된 저장된 프로젝트는 다른 프로젝트로 대체되지 않고 **(missing)** 으로 표시됩니다.
