## 설명

[Oracle Fusion 연결](/ko/guides/connections/oracle-fusion/)을 통해 Oracle Fusion Cloud 엔터티 하나를 프로젝트 테이블로 가져오며, Fusion의 OData 또는 BI Publisher(BIP) 엔드포인트를 직접 호출합니다. 연결, 엔터티 유형, 필터를 선택하면 이 단계가 일치하는 레코드를 가져와 기록하므로 OData 쿼리를 직접 작성할 필요가 없습니다.

직접 호출로 처리하기에 너무 큰 데이터를 가져와야 한다면 [Import Fusion Bulk Extract](/ko/reference/workflow-steps/oracle-fusion/import-fusion-bulk-extract/) 단계를 대신 사용하십시오.

## 구성

| 필드 | 필수 | 참고 |
|---|---|---|
| Fusion 연결 | 예 | 데이터를 읽을 Oracle Fusion 연결입니다. |
| 대상 테이블 | 예 | 결과를 기록할 프로젝트 테이블입니다. 실행할 때마다 전체 내용을 덮어씁니다. |
| 엔터티 유형 | 예 | 가져올 엔터티입니다. 기본값은 `gl_balances`입니다. `gl_balances`, `journal_batches` 중 하나입니다. |
| 필터 | 아니요 | 날짜, 회계 기간, 숫자 잔액/금액 필드에 대한 범위 필터(`ge`/`le`)와 개별 필드(원장, 통화)에 대한 동등 필터입니다. 각 엔터티는 Oracle Fusion이 서버 측에서 실제로 평가할 수 있는 필드로만 필터를 제한합니다. 지원되지 않는 필드는 조용히 무시되지 않고 거부됩니다. |

### 엔터티와 필터링 가능한 필드

| 엔터티 유형 | 가져오는 내용 | 필터링 가능한 필드 |
|---|---|---|
| `gl_balances` | 총계정원장 계정 잔액 | 회계 기간 범위(`ge`/`le`), 계정 범위, 잔액 금액 범위(`ge`/`le`) |
| `journal_batches` | 분개 배치 헤더 및 상태 | 날짜 범위(`ge`/`le`), 회계 기간 범위(`ge`/`le`) |

<Aside type="note">
범위 필터는 한쪽 경계만 있어도 유용합니다. 예를 들어 상한 없이 `accounting_date ge 2026-01-01`만 지정하면 해당 날짜 이후의 모든 데이터를 가져옵니다. 가져올 범위를 좁히려면 양쪽 경계를 모두 지정하십시오.
</Aside>
