## 설명

Oracle의 FBDI/BI Publisher 대량 추출 경로를 통해 [Oracle Fusion 연결](/ko/guides/connections/oracle-fusion/)으로 Oracle Fusion Cloud 엔터티를 가져옵니다. PlaidCloud가 내보내기 작업을 제출하고, 완료될 때까지 폴링하고, 생성된 파일을 다운로드하여 프로젝트 테이블에 기록합니다. 직접 OData/BIP 호출로 가져오기에는 너무 크거나 느린 경우 [Import Fusion Entity 단계](/ko/reference/workflow-steps/oracle-fusion/import-fusion-entity/) 대신 이 단계를 사용하십시오.

## 구성

| 필드 | 필수 | 참고 |
|---|---|---|
| Fusion 연결 | 예 | 읽기에 사용할 Oracle Fusion 연결입니다. |
| 대상 테이블 | 예 | 결과를 기록할 프로젝트 테이블입니다. 실행할 때마다 전체가 덮어쓰기됩니다. |
| 엔터티 유형 | 예 | 추출할 엔터티입니다. 기본값은 `gl_balances`입니다. `gl_balances`, `journal_batches` 중 하나입니다. |
| 필터 | 아니요 | [Import Fusion Entity 단계](/ko/reference/workflow-steps/oracle-fusion/import-fusion-entity/)와 동일한 필터 집합입니다. 날짜, 회계 기간, 숫자 잔액/금액 필드의 범위 필터(`ge`/`le`)와 개별 값 필드의 동등 필터입니다. 추출 작업 수준에서 적용됩니다. |

<Aside type="caution">
이 단계는 비동기 내보내기 작업을 기다리므로 같은 행 수에서 [Import Fusion Entity 단계](/ko/reference/workflow-steps/oracle-fusion/import-fusion-entity/)보다 상당히 오래 걸릴 수 있습니다. 직접 OData/BIP 호출로 가져오기에는 정말로 너무 큰 경우에만 사용하십시오.
</Aside>
