## 설명

[D365 F&O 연결](/ko/guides/connections/dynamics-365-fo/)을 통해 Dynamics 365 Finance & Operations 엔터티 하나를 프로젝트 테이블로 가져옵니다. 연결, 엔터티 유형, 동기화 모드 및 필터를 선택하면 단계가 일치하는 레코드를 가져와 기록하며, OData 쿼리를 직접 작성할 필요가 없습니다.

이 단계는 범용 기본 제공 단계로, 하나의 단계 유형으로 마스터/참조 데이터(주 계정, 통화, 고객, 공급업체, 출시 제품)부터 트랜잭션 레코드(원장 분개 헤더)까지 여섯 가지 엔터티를 다루며, 직접 OData 호출 또는 비동기 DMF 대량 추출 중 하나를 사용할 수 있습니다.

## 구성

| 필드 | 필수 | 참고 |
|---|---|---|
| D365 F&O 연결 | 예 | 읽을 때 사용할 D365 F&O 연결입니다. |
| 대상 테이블 | 예 | 결과를 기록할 프로젝트 테이블입니다. 실행할 때마다 전체가 덮어써집니다. |
| 엔터티 유형 | 예 | 가져올 엔터티입니다. 기본값은 `main_accounts`입니다. `main_accounts`, `currencies`, `customers`, `vendors`, `released_products`, `ledger_journal_headers` 중 하나입니다. |
| 동기화 모드 | 예 | 기본값은 `odata`입니다. `odata`는 엔터티의 표준 OData 엔드포인트를 직접 호출합니다. `dmf`는 비동기 Data Management Framework 내보내기 작업을 제출하고 완료되면 결과를 다운로드하며, 일반 OData 페이징으로는 너무 크거나 느린 가져오기에 사용합니다. |
| 필터 | 아니요 | 요청의 OData `$filter`로 변환되는 범위 및 동등 필터입니다. 각 엔터티는 D365 F&O가 서버 측에서 실제로 평가할 수 있는 필드로만 필터를 제한하며, 지원되지 않는 필드는 조용히 무시되지 않고 거부됩니다. |

### 엔터티와 필터링 가능한 필드

| 엔터티 유형 | 가져오는 항목 | 필터링 가능한 필드 |
|---|---|---|
| `main_accounts` | 계정과목표 | 계정 범위, 차원 |
| `currencies` | 통화 마스터 | — |
| `customers` | 고객 마스터 | 계정 범위 |
| `vendors` | 공급업체 마스터 | 계정 범위 |
| `released_products` | 출시 제품 마스터 | — |
| `ledger_journal_headers` | 전기된 분개 헤더와 전기되지 않은 분개 헤더 | 날짜 범위, 계정 범위, 차원 |

<Aside type="note">
날짜, 계정 및 차원 **범위** 필터(`ge`/`le` 방식의 경계)는 `ledger_journal_headers` 가져오기를 제한하는 주된 방법입니다. 제한 없이 트랜잭션 내역을 가져오면 매우 클 수 있습니다. 운영 데이터에 대해 실행하기 전에 큰 엔터티에는 경계를 하나 이상 설정하십시오.
</Aside>

<Aside type="caution">
`dmf`(대량) 모드는 비동기 내보내기 작업을 기다리므로 같은 엔터티와 필터 집합에서 `odata` 모드보다 훨씬 느립니다. 직접 OData로 가져오기에는 너무 큰 추출에만 사용하십시오.
</Aside>
