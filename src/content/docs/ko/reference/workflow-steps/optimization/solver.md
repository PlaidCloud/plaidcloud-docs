솔버 단계는 PlaidCloud 테이블에서 선형 계획법과 혼합 정수 계획법 문제를 해결합니다. 워크플로가 선형 제약 조건을 만족하면서 목적 함수를 최소화하거나 최대화하는 값을 선택해야 할 때 사용하십시오.

솔버는 워크플로 작업 파드에서 실행되며 결과를 프로젝트 테이블에 다시 기록합니다.

## 입력

입력 테이블 네 개를 구성합니다. 각 입력에는 소스 테이블, 데이터 매핑, 필터가 있습니다. PlaidCloud는 이러한 설정을 각 입력을 읽는 데 사용되는 데이터베이스 쿼리로 변환하므로, 선택은 솔버가 행을 받기 전에 이루어집니다.

### 변수

의사 결정 변수마다 한 행입니다.

| 열 | 설명 |
| --- | --- |
| `variable_id` | 다른 입력 테이블에서 사용하는 고유한 변수 이름입니다. |
| `lower_bound` | 최솟값입니다. 하한이 없으면 비워 두십시오. |
| `upper_bound` | 최댓값입니다. 상한이 없으면 비워 두십시오. |
| `type` | `continuous`, `integer` 또는 `binary`입니다. 이진 변수는 경계 `0`과 `1`을 사용합니다. |

### 목적 함수

0이 아닌 목적 함수 계수를 가진 변수마다 한 행입니다.

| 열 | 설명 |
| --- | --- |
| `variable_id` | 변수 입력의 변수입니다. |
| `coefficient` | 해당 변수의 목적 함수 계수입니다. |

이 테이블에 없는 변수는 계수 `0`을 사용합니다.

### 제약 조건

선형 제약 조건마다 한 행입니다.

| 열 | 설명 |
| --- | --- |
| `constraint_id` | 계수 입력에서 사용하는 고유한 제약 조건 이름입니다. |
| `lower_bound` | 허용되는 최소 활동값입니다. 하한이 없으면 비워 두십시오. |
| `upper_bound` | 허용되는 최대 활동값입니다. 상한이 없으면 비워 두십시오. |

등식 제약 조건에는 하한과 상한을 같게 설정합니다.

### 계수

제약 조건 계수의 희소 행렬입니다.

| 열 | 설명 |
| --- | --- |
| `constraint_id` | 제약 조건 입력의 제약 조건입니다. |
| `variable_id` | 변수 입력의 변수입니다. |
| `coefficient` | 해당 제약 조건에서 그 변수의 계수입니다. |

## 솔버 옵션

| 옵션 | 설명 |
| --- | --- |
| 목적 함수 방향 | 최소화 또는 최대화를 선택합니다. |
| 시간 제한 | 초 단위의 선택적 실행 시간 제한입니다. |
| MIP 갭 | 혼합 정수 문제를 위한 선택적 상대 MIP 갭입니다. |
| 프리솔브 사용 | 솔버가 풀기 전에 모델을 단순화하도록 합니다. |
| 사용자 지정 리소스 사용 | 작업 파드의 CPU 코어와 메모리를 설정합니다. |

## 출력

솔버는 세 개의 출력 테이블을 기록합니다.

### 해 테이블

변수마다 한 행이며, 풀이된 값, 경계, 변수 유형, 목적 함수 계수, 그리고 가능한 경우 환원 비용이 포함됩니다.

### 제약 조건 결과 테이블

제약 조건마다 한 행이며, 활동값, 경계, 여유값, 그리고 가능한 경우 쌍대값이 포함됩니다.

### 요약 테이블

솔버 상태, 목적 함수 값, 실행 시간, MIP 갭, MIP 쌍대 경계, 노드 수, 반복 횟수, 변수 수, 제약 조건 수가 담긴 한 행입니다.

## 상태 동작

최적해를 구하면 단계가 성공적으로 완료됩니다. 솔버가 최적이 아닌 상태로 사용 가능한 해를 반환하면 단계는 경고와 함께 완료되며 출력 테이블은 그대로 기록됩니다. 사용 가능한 해가 없으면 단계는 솔버 상태 메시지와 함께 실패합니다.
