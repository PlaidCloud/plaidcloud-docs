위치 최적화 단계는 후보 위치 테이블에서 수요 지점 테이블까지의 총 거리 또는 가중 거리를 최소화하는 **K**개 사이트를 선택합니다. PlaidCloud의 HiGHS 솔버에서 혼합 정수 프로그램으로 풀리는 p-median 시설 입지 모델입니다.

위치 최적화는 [솔버](/ko/reference/workflow-steps/optimization/solver/)가 사용하는 것과 동일한 작업 이미지인 워크플로 작업 파드에서 실행되며, 결과를 프로젝트 테이블에 다시 기록합니다.

## 입력

### 후보 사이트

가능한 사이트 위치의 테이블로, 테이블에 매핑되는 모든 입력이 사용하는 것과 동일한 소스/대상 열 매핑, 필터, 집계로 매핑됩니다.

### 수요 지점

가장 가까운 선택된 사이트까지의 거리를 최소화할 지점의 테이블로, 같은 방식으로 매핑됩니다.

### 거리 테이블(선택 사항)

후보에서 수요 지점까지 미리 계산된 거리의 테이블입니다. 설정하지 않으면 단계가 직접 거리를 계산합니다.

### K

후보 사이트에서 선택할 사이트 수입니다.

## 솔버 옵션

| 옵션 | 설명 |
| --- | --- |
| 시간 제한 | 초 단위의 선택적 실행 시간 제한입니다. |
| MIP 갭 | 선택적 상대 MIP 갭입니다. |
| 프리솔브 사용 | 솔버가 풀기 전에 모델을 단순화하도록 합니다. 기본적으로 사용 설정되어 있습니다. |
| 사용자 지정 리소스 사용 | 작업 파드의 CPU 코어와 메모리를 설정합니다. |

**시간 제한** 또는 **MIP 갭**으로 중단하면 진정한 최적해가 아니라 해당 제한 내에서 찾은 최선의 해를 반환합니다. 이는 [솔버](/ko/reference/workflow-steps/optimization/solver/#상태-동작)가 최적이 아닌 상태에서 취하는 절충과 같습니다. 완전한 최적해까지 풀려면 둘 다 설정하지 마십시오.

## 출력

위치 최적화는 세 개의 출력 테이블을 기록하며, 이름이 모두 서로 달라야 합니다.

### 선택된 사이트 출력 테이블

선택된 사이트마다 한 행입니다.

### 할당 출력 테이블

수요 지점마다 한 행이며, 할당된 선택 사이트가 지정됩니다.

### 요약 출력 테이블

솔버 상태, 목적 함수 값, 실행 세부 정보가 담긴 한 행입니다.

## 제한 사항 및 주의 사항

이 단계는 **p-median** 모델입니다. 항상 수요 지점에서 가장 가까운 선택된 사이트까지의 총(선택적으로 가중된) 거리를 최소화합니다. 중력 방식 점수, 사용자 지정 점수 공식, 또는 거리가 낮을수록이 아니라 점수가 높을수록 좋은 목적 함수는 표현할 수 없습니다. 이러한 요구가 있는 사이트 선택 문제는 대신 직접 구성한 [솔버](/ko/reference/workflow-steps/optimization/solver/) 모델로 해결해야 합니다.

## 관련 항목

- [솔버](/ko/reference/workflow-steps/optimization/solver/) — 이 단계의 고정된 p-median 모델이 다루지 않는 사이트 선택 목적 함수를 위한 일반 선형 및 혼합 정수 최적화입니다.
- [Alteryx 변환 매트릭스](/ko/reference/alteryx-conversion-matrix/) — Alteryx Location Optimizer 도구는 선형 거리 최소화 사례에 한해서만 이 단계로 변환되며, 중력 커널이나 사용자 지정 점수 매크로는 여전히 거부됩니다.
