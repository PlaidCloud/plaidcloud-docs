## 설명


PlaidCloud Document 내에서 파일 하나를 복사합니다.



## 복사할 파일


먼저 드롭다운 메뉴에서 해당 계정을 선택합니다.



다음으로 **찾아보기** 버튼을 눌러 복사할 파일을 선택합니다.

파일 하나 대신 **검색과 일치하는 파일 복사**를 선택하면 이름이 검색 텍스트와 일치하는 파일(**정확히 일치**, **시작 문자열**, **포함** 또는 **끝 문자열**)을 복사하며, **디렉터리의 모든 파일 복사**를 선택할 수도 있습니다. 폴더 전체를 복사하는 경우:

* **하위 폴더 유지**는 각 파일을 폴더 아래의 경로 그대로 복사하므로 복사본이 폴더 구조를 유지합니다. 이 옵션을 사용하지 않으면 모든 파일이 이름만으로 대상 폴더 바로 아래에 복사됩니다.
* **하위 폴더 건너뛰기**는 폴더 자체의 파일만 복사하고 하위 폴더의 파일은 복사하지 않습니다.

**이름이 일치하는 파일만 복사 (정규식)** 옵션은 이러한 선택 항목 모두를, 이름이 처음부터 정규식과 일치하는 파일로 좁힙니다(예: `sales_\d{4}\.csv`). 대/소문자를 구분합니다. 비워 두면 선택한 모든 파일을 복사합니다. 유효한 정규식이 아니거나 `(a+)+`처럼 그 자체가 반복되는 부분을 반복하는 패턴은 단계를 저장할 때 거부됩니다.

소스 파일이나 폴더가 없거나 비어 있으면 단계는 해당 경로를 알려 주는 경고와 함께 완료되며 아무것도 복사되지 않습니다.



## 대상 위치 선택


먼저 드롭다운 메뉴에서 해당 계정을 선택합니다.



다음으로 **찾아보기** 버튼을 눌러 복사한 파일을 둘 대상 위치를 선택합니다.



기본적으로 Analyze는 파일을 덮어쓰지 않습니다. 대신 이후의 복사본마다 숫자 접미사가 추가됩니다. 



기존 파일을 덮어쓰려면 **Allow Overwriting Existing File** 상자를 선택하기만 하면 됩니다.



파일 이름을 바꾸려면 **Rename the copied file to** 상자를 선택하고 새 이름을 입력합니다.

<Aside>파일 이름을 변경할 때는 반드시 파일 확장자를 지정하십시오. 확장자가 없어도 파일은 정상적으로 생성되지만 운영 체제에서 파일 형식을 알 수 없습니다.</Aside>


## 추가 설정

**파일이 있는 경우** 아래의 **이미 있는 파일**(`overwrite_policy`)은 대상 위치에 이미 파일이 있을 때의 동작을 설정합니다. **덮어쓰기**(`overwrite`, 기본값), **원본이 더 최신이면 덮어쓰기**(`overwrite_if_newer`), **그대로 두기**(`skip`), **아무것도 복사하지 않고 단계 실패**(`fail`) 중에서 선택합니다.

**디렉터리의 모든 파일 복사**를 사용하면 **대상 파일** 옵션으로 복사 대상을 좁힐 수 있습니다.

* **하위 폴더 아래 파일**(`include_subdirs`) — **아니요**는 폴더 자체의 파일만 복사하고 **예**는 그 아래의 모든 파일을 폴더와 함께 복사합니다. 설정하지 않으면 **하위 폴더 유지**와 **하위 폴더 건너뛰기**에서 설명한 대로 모든 파일을 이름만으로 대상 폴더에 복사합니다.
* **파일 이름 패턴**(`file_name_filter`) — 이름이 일치하는 파일만 복사합니다. **패턴 유형**은 **와일드카드** 또는 **정규식**(`type`)이며, **대/소문자 구분**은 `case_sensitive`를 설정합니다.
* **폴더 이름 패턴**(`folder_name_filter`) — 이름이 일치하는 폴더 안의 파일만 같은 형식으로 복사합니다. 경로상의 모든 폴더가 일치해야 합니다.
* **확장자**(`extensions`) — 이 확장자(점 제외) 중 하나를 가진 파일만 복사합니다. **확장자의 대/소문자 구분**(`extensions_case_sensitive`)을 선택하면 대/소문자를 구분하여 일치시킵니다.
* **숨김 파일 포함(점으로 시작하는 이름)** 옵션(`include_hidden_files`)과 **숨김 폴더와 그 아래 항목 포함** 옵션(`include_hidden_folders`) — 선택을 해제하면 이름이 점으로 시작하는 파일 또는 폴더가 제외됩니다.
