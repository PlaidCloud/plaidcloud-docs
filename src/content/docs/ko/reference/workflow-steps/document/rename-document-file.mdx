## 설명


PlaidCloud 문서 안에 있는 기존 파일의 이름을 바꿉니다.



## 이름을 바꿀 파일


먼저 드롭다운 메뉴에서 해당 계정을 선택합니다.



다음으로 **찾아보기** 버튼을 눌러 이름을 바꿀 파일을 선택합니다.

<Aside>이름을 바꾼 파일이 이미 있으면 아무 작업도 하지 않습니다.</Aside>


## 새 이름


파일의 새 이름을 입력합니다.
