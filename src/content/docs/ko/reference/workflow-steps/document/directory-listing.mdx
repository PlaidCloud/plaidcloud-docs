## 설명

문서 디렉터리의 파일을 나열하는 테이블을 작성합니다. 폴더에 있는 모든 파일을 반복 처리하거나 상위 프로세스가 전달한 파일을 확인하는 등, 현재 존재하는 파일을 기준으로 후속 단계를 구동할 때 사용합니다.

## 디렉터리

문서 계정을 선택한 다음 **찾아보기** 버튼을 눌러 나열할 폴더를 선택합니다.

## 옵션

- **파일 패턴** *(선택 사항)* — `*.csv`와 같은 glob으로, 일치하는 파일만 나열합니다. 비워 두면 모두 나열합니다.
- **하위 디렉터리 포함** — 선택하면 중첩된 폴더의 파일도 나열합니다.
- **대상 테이블** — 목록을 받을 테이블입니다.

## 추가 설정

**대상 파일** 옵션으로 목록을 좁힙니다.

- **IsFolder 열과 함께 폴더도 나열**(`include_folders`) — 폴더도 행으로 나열합니다. 이 경우 모든 행의 끝에 `IsFolder` 열이 추가되며, 폴더이면 true입니다.
- **디렉터리 자체를 먼저 나열**(`include_root_folder`) — `include_folders`와 함께 사용하면 디렉터리 자체도 맨 먼저 나열합니다.
- **파일 이름 패턴**(`file_name_filter`) — 이름이 일치하는 파일만 대상으로 합니다. **패턴 유형**은 **와일드카드** 또는 **정규식**(`type`)이며, **대/소문자 구분**은 `case_sensitive`를 설정합니다.
- **폴더 이름 패턴**(`folder_name_filter`) — 이름이 일치하는 폴더 안의 항목만 같은 형식으로 대상으로 합니다. 아래로 내려가는 경로의 모든 폴더가 일치해야 합니다.
- **확장자**(`extensions`) — 이 확장자 중 하나를 가진 파일만 대상으로 하며, 점은 쓰지 않습니다. **확장자의 대/소문자 구분**(`extensions_case_sensitive`)을 선택하면 대/소문자를 구분하여 일치시킵니다.
- **숨김 파일 포함(점으로 시작하는 이름)**(`include_hidden_files`)과 **숨김 폴더와 그 아래 항목 포함**(`include_hidden_folders`) — 둘 중 하나를 해제하면 이름이 점으로 시작하는 파일 또는 폴더를 제외합니다.
