## 설명


PlaidCloud Document 내에서 디렉터리 전체를 복사합니다.



## 디렉터리 복사


먼저 드롭다운 메뉴에서 해당 계정을 선택합니다.



다음으로 **찾아보기** 버튼을 눌러 복사할 디렉터리를 선택합니다.



## 대상 위치 선택


먼저 드롭다운 메뉴에서 해당 계정을 선택합니다.



다음으로 **찾아보기** 버튼을 눌러 복사한 디렉터리를 둘 대상 위치를 선택합니다. 



원하는 경우 복사한 디렉터리에 새 이름을 지정할 수 있습니다. 이렇게 하려면 **Rename the Copied Folder to:** 상자를 선택하고 새 이름을 입력하기만 하면 됩니다.


<Aside>기본 동작은 이미 있는 항목을 덮어쓰는 것입니다. 실수로 덮어쓰지 않도록 주의하십시오.</Aside>
