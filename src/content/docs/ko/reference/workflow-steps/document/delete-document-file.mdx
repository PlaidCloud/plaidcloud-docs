## 설명


PlaidCloud 문서 안에 있는 기존 파일을 삭제합니다.



## 삭제할 파일


먼저 드롭다운 메뉴에서 해당 계정을 선택합니다.


다음으로 **찾아보기** 버튼을 눌러 삭제할 파일을 선택합니다.

<Aside>파일이 없는 경우(이미 삭제된 경우) 아무 작업도 하지 않습니다.</Aside>
