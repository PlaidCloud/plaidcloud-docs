## 설명

대시보드를 PDF로 렌더링하여 문서 계정에 기록합니다. 대시보드를 일정에 따라 배포하려는 경우, 예를 들어 월말 보고 자료, 로그인하지 않는 사람들에게 보내는 배포본, 특정 날짜의 수치를 보관하는 스냅샷 용도로 사용합니다.

이 단계는 필터 데이터 세트의 행마다 한 번씩 렌더링하며 해당 행의 값을 대시보드 필터로 적용하므로, 한 번의 실행으로 지역별 또는 엔터티별 PDF 세트를 만들 수 있습니다.

## 구성

### 대시보드

렌더링할 대시보드입니다.

### 필터 데이터 세트

렌더링을 구동하는 테이블로, 행마다 PDF 하나가 만들어집니다.

### 출력 경로

PDF를 기록할 문서 계정과 폴더입니다.

### 옵션

- **동시 PDF 생성** — 동시에 실행할 렌더링 수입니다. 기본값은 8이며, 대시보드가 무거워 병렬 렌더링 시 시간 초과가 발생하면 이 값을 낮추십시오.
- **렌더링 대기 시간 (초)** — 단계 구성에는 있지만 워크플로 실행기에서 **현재 적용되지 않습니다**. 지금은 설정해도 아무 효과가 없습니다.

### 대시보드 필터

대시보드 자체의 필터이며 각각 **대시보드 필터 ID**를 가집니다. 매핑을 채울 때 대시보드에서 읽어 옵니다.

### 소스 열 매핑

필터 데이터 세트의 열과 각 열의 사용 방식입니다. **소스 검사 › 매핑 테이블 채우기**를 사용하여 열과 대시보드의 필터를 읽어 오며, 대시보드 필터와 이름이 같은 열은 해당 필터에 대한 필터로 지정됩니다. 다시 채워도 열에 이미 설정한 **종류**와 **매핑된 필터 열**은 유지됩니다.

각 열의 **종류**를 설정합니다.

- **열 필터** — 열의 값이 **매핑된 필터 열**에 지정한 대시보드 필터의 값으로 설정됩니다. 지정한 필터는 대시보드의 필터 중 하나여야 합니다.
- **파일 이름** — 열이 각 PDF의 파일 이름을 제공합니다. 파일 이름 열은 하나만 지정할 수 있습니다. 지정하지 않으면 단계가 경고를 표시하고 이름을 자동으로 생성합니다.
- **필터 없음** — 열을 사용하지 않습니다.

**열 필터**가 하나 이상 있어야 합니다.

## 저장할 때 확인하는 항목

다음 경우에는 열 이름을 알려 주며 단계 저장이 거부됩니다.

- 매핑된 필터 열이 있는 열 필터가 하나도 없는 경우 — *소스 열을 하나 이상 열 필터로 지정하고, 해당 열이 설정할 매핑된 필터 열을 지정하십시오.*
- 열 필터에 매핑된 필터 열이 없거나 대시보드의 필터에 없는 열을 지정한 경우 — *소스 열 'region'의 매핑된 필터 열 'Region'은 대시보드의 필터가 아닙니다.*
- 둘 이상의 열이 파일 이름인 경우 — *소스 열은 하나만 파일 이름으로 지정할 수 있습니다. region, entity 모두 지정되어 있습니다.*
- 열 필터 또는 파일 이름 열에 데이터 형식이 없는 경우 — *소스 열 'region'에 데이터 형식이 없습니다. 소스를 다시 검사하여 새로 고치십시오.* 단계 양식에서 저장된 일부 단계는 열의 형식이 누락되어 있어, 형식을 복원할 때까지 실행할 때마다 실패합니다. **소스 검사 › 매핑 테이블 채우기**를 실행하여 복원하십시오. 열 필터와 파일 이름 지정은 유지됩니다.
