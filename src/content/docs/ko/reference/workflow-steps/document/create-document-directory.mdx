## 설명


PlaidCloud Document 내에 새 디렉터리를 만듭니다.



## 새 폴더를 만들 위치


먼저 드롭다운 메뉴에서 해당 계정을 선택합니다.



다음으로 **찾아보기** 버튼을 눌러 상위 디렉터리를 선택합니다.



## 새 폴더 이름


새 디렉터리의 이름을 입력합니다.


<Aside>디렉터리가 이미 있으면 아무 작업도 수행하지 않습니다.</Aside>
