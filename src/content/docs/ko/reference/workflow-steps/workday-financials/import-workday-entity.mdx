## 설명

[Workday Financials 연결](/ko/guides/connections/workday-financials/)을 통해 Workday Financials의 데이터를 프로젝트 테이블로 가져옵니다. NetSuite, Acumatica, Business Central과 달리 PlaidCloud에는 미리 정의된 Workday Financials 엔터티 집합이 없습니다. 대신 Workday에서 **Report-as-a-Service(RaaS) 보고서**를 만들어 웹 서비스 액세스와 함께 게시하고, 이 단계에 보고서의 URL을 추출 소스로 지정합니다.

## 구성

| 필드 | 필수 | 참고 |
|---|---|---|
| Workday 연결 | 예 | 읽을 때 사용할 Workday Financials 연결입니다. |
| RaaS 보고서 URL | 예 | Workday에서 만들어 게시한 RaaS 보고서의 웹 서비스 URL입니다. |
| 대상 테이블 | 예 | 결과를 기록할 프로젝트 테이블입니다. 실행할 때마다 전체가 덮어쓰입니다. |
| 필터 | 아니요 | `company`, `ledger`, `period`, `accounting_date`(범위), `ledger_account`(범위), `cost_center`입니다. 각각 보고서 매개변수로 전달되며, RaaS 보고서에 일치하는 프롬프트가 정의되어 있어야 필터가 적용됩니다. |

<Aside type="caution">
보고서에 일치하는 프롬프트가 없는 필터를 설정하면 조용히 무시되지 않고 거부됩니다. 먼저 Workday의 RaaS 보고서에 프롬프트를 추가한 다음 여기서 필터를 설정하십시오.
</Aside>

<Aside type="note">
반환되는 필드는 보고서 자체가 정의하므로, 가져오는 데이터의 형태(열 이름, 단위, 포함된 차원)는 RaaS 보고서가 생성하는 그대로입니다. 대상 테이블에 기대하는 형태를 염두에 두고 보고서를 설계하십시오.
</Aside>
