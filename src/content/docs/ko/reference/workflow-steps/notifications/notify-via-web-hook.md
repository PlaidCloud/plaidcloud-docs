## 설명



웹훅 URL로 POST 요청을 보내 알림을 전송합니다. 사용자 지정 다운스트림 작업을 트리거하거나, 통합 플랫폼(Zapier, n8n, Make)에 경고하거나, 기본 커넥터를 사용하지 않는 Slack/Teams/Discord 봇을 구동하는 데 유용합니다.

페이로드 형식과 사용자 지정 헤더는 구성할 수 있습니다. 이후에 일어나는 일은 수신 서비스가 담당합니다.
