## 설명

워크플로에서 주의가 필요할 때 워크스페이스 멤버에게 문자를 보냅니다. 문자는 사용자 메뉴의 **문자 알림**에서 직접 수신에 동의하고 확인을 마친 미국 휴대폰 번호가 있는 멤버에게만 전송됩니다. 멤버 또는 배포 목록을 선택하며, 단계에 전화번호를 직접 입력하지는 않습니다. 수신 동의 방법은 [문자 알림](/ko/guides/workflows/text-alerts/)을 참조하십시오.

문자는 미국 번호로만 보낼 수 있습니다. 문자에 건강 정보나 금융 관련 개인 데이터를 포함하지 마십시오.

문자는 하나의 PlaidCloud 알림 번호로 발송되며, `PlaidCloud [your workspace name]: ` 다음에 메시지가 이어지는 형태로 표시됩니다. [SMS 약관](https://plaidcloud.com/sms-terms/)과 [SMS 개인정보 처리방침](https://plaidcloud.com/sms-privacy/)을 참조하십시오.

## 수신자

**멤버** 또는 **배포 목록**을 선택합니다.

- **멤버**에는 워크스페이스 멤버가 나열됩니다. 각 멤버에는 **수신 동의함**, **수신 동의 안 함** 또는 **수신 거부됨 - 알림 번호로 START 문자 보내기**가 표시됩니다.
- **배포 목록**은 목록에서 수신에 동의한 모든 멤버에게 문자를 보냅니다.

수신에 동의하지 않은 멤버에게는 문자가 전송되지 않습니다. 이러한 멤버는 단계에서 문제로 처리되며(**문자를 전달할 수 없는 경우** 참조), 기본적으로 해당 메시지를 이메일로 받습니다.

## 메시지

**메시지**를 작성합니다. 프로젝트 변수와 워크플로 변수를 사용할 수 있으며, **변수 삽입**으로 다음 항목을 추가할 수 있습니다.

| 변수 | 값 |
|---|---|
| `{workflow_name}` | 실행 중인 워크플로의 이름 |
| `{project_name}` | 프로젝트의 이름 |
| `{run_url}` | PlaidCloud의 해당 실행에 대한 링크 |
| `{project}`, `{model}`, `{cloud}`, `{date}` | 기존 변수 |

메시지 아래의 카운터는 `PlaidCloud [workspace]:` 접두사와 실행 링크를 포함하여 문자가 차지하는 대략적인 글자 수와 세그먼트 수를 보여 줍니다. 3세그먼트를 넘으면 문자가 잘립니다. 공개 링크 단축 서비스의 링크는 거부됩니다.

## 전달

| 설정 | 기능 |
|---|---|
| **문자를 전달할 수 없는 경우** | **단계 실패 처리**(기본값) 또는 **경고 후 계속**. 전달되지 않은 문자는 조용히 넘어가지 않으며 항상 단계에 보고됩니다. |
| **문자를 전달할 수 없는 수신자에게 이메일 보내기** | 기본적으로 켜져 있습니다. 문자 전송에 실패했거나, 수신에 동의하지 않았거나, 수신을 거부한 멤버는 메시지를 이메일로 받습니다. |
| **반복 알림 묶기(분)** | 기본값은 60입니다. 이 시간 안에 같은 멤버에게 같은 메시지를 반복해서 보내면 전송되지 않으며, 이후 발송되는 다음 문자 끝에 `(+N similar since HH:MM)`이 붙습니다. |
| **방해 금지 시간 동안 문자 보류** | **시작** 시간과 **~** 시간, 그리고 시간대를 선택합니다. 해당 시간대 안에 발송될 문자는 그 시간이 끝날 때까지 보류됩니다. |

각 멤버는 하루에 최대 20건의 문자를 받으며, 워크스페이스는 하루에 문자와 대체 이메일을 합쳐 최대 500건을 발송하고, 하나의 단계는 한 번에 최대 50명의 멤버에게 문자를 보냅니다.

## 나에게 테스트 보내기

**나에게 테스트 보내기**는 본인 번호로 테스트 문자를 보내고 버튼 옆에 결과를 표시합니다. 수신에 동의하지 않았다면 **문자 알림** 창이 열리므로 그곳에서 동의할 수 있습니다.

## 수신자에게 표시되는 내용

모든 문자는 알림 번호에서 발송됩니다. **STOP**으로 답장하면 PlaidCloud에서 해당 번호로 보내는 모든 문자가 중단되고, **HELP**로 답장하면 연락처 정보가 반환됩니다. STOP 이후 멤버가 다시 받으려면 알림 번호로 **START** 문자를 보낸 다음 **문자 알림**에서 문자 알림을 다시 켜야 합니다. 그때까지 단계 양식에는 해당 멤버 옆에 **수신 거부됨 - 알림 번호로 START 문자 보내기**가 표시됩니다.

워크스페이스 관리자는 멤버 창의 **멤버 정보** 탭에서 번호가 가려진 상태로 각 멤버의 문자 알림 상태를 확인할 수 있습니다. 멤버가 직접 수신 동의 및 거부를 설정하며, 관리자가 대신 설정할 수는 없습니다.

## 번호를 직접 입력한 단계

이 단계의 이전 버전은 모바일 통신사와 직접 입력한 전화번호를 사용했습니다. 여전히 그 방식으로 저장된 단계는 워크플로를 실패시키지 않으며, 입력된 번호로 문자를 보내지도 않습니다.

- **선택한 수신자가 없는 경우:** 단계가 경고와 함께 완료되며, 경고 메시지는 *No text was sent: this step still uses the retired mobile provider and number. Open the step, choose members who've opted in to text alerts, and save it.*입니다. 아무것도 전송되지 않습니다.
- **멤버 또는 배포 목록을 선택한 경우:** 단계가 해당 수신자에게 문자를 보내고, 남아 있는 통신사와 번호는 무시합니다.

단계를 수정하려면 단계를 열고 멤버 또는 배포 목록을 선택한 다음 저장합니다.
