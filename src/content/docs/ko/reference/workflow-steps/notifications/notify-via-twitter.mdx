## 설명


[@plaidcloud](https://twitter.com/plaidcloud)에서 Twitter 다이렉트 메시지(DM)를 보냅니다.



### Twitter 계정


@plaidcloud의 DM을 받을 Twitter 계정을 지정합니다. 메시지를 받으려면 해당 사용자가 @plaidcloud를 팔로우하고 있어야 합니다. 사용자 이름 앞에 앳 기호(@)를 붙여도 되지만 필수는 아닙니다.



### 메시지


원하는 메시지를 입력합니다. Analyze는 140자를 초과하는 값을 허용하지 않습니다.


참고: 이 변환에는 프로젝트 변수와 워크플로 변수를 모두 사용할 수 있습니다.


<Aside type="danger">변수를 사용하면 140자 제한을 초과하는 메시지가 생성될 수 있습니다. 이 경우 메시지는 전송되지 않으며, 대신 다음 오류가 로그에 기록됩니다. *Twitter API returned a 403 (Forbidden), There was an error sending your message: The text of your direct message is over 140 characters.</Aside>

## 예제

이 예제에서는 [@PlaidCloud](https://twitter.com/plaidcloud)에서 [@tartansolutions](https://twitter.com/tartansolutions)로 DM을 보냅니다. 메시지에는 시스템 변수가 사용됩니다. 최종 메시지는 *Analyze Demo is running on #PlaidCloud*입니다.
