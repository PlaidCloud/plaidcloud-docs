## 설명



PlaidLink 에이전트를 통해 알림을 트리거합니다. PlaidCloud에서 직접 접근할 수 없는 온프레미스 시스템(내부 경고 시스템, 자체 웹후크, 레거시 SMTP)을 통해 알림을 전달해야 할 때 유용합니다.

에이전트가 알림 페이로드를 받아 구성에 따라 로컬에서 전달합니다.
