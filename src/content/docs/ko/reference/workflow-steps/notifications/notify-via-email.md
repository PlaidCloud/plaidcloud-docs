## 설명


이메일 알림을 보냅니다. 메시지는 *[info@tartansolutions.com](mailto:info@tartansolutions.com)* 이메일 계정에서 발송됩니다. 별도의 발신 설정은 필요하지 않습니다.



### 이메일 주소


수신자 이메일을 원하는 만큼 지정할 수 있습니다. 구분자로는 세미콜론(;)과 쉼표(,)를 사용할 수 있습니다.



### 참조, 숨은 참조, 회신 주소

**참조**(`cc_address`), **숨은 참조**(`bcc_address`), **회신 주소**(`reply_to`)에는 수신자와 같은 형식의 주소를 입력하며, 프로젝트 변수와 워크플로 변수를 사용할 수 있습니다. 참조 및 숨은 참조 수신자는 동일한 메시지를 받고, 회신은 회신 주소로 전송됩니다. 일반 본문과 Jinja 템플릿 본문 모두에 적용됩니다. **메시지** 탭의 **추가 이메일 옵션**에서 설정합니다.

### 행마다 이메일 하나

**추가 이메일 옵션**에서 **보내기**(`request_source`)를 **테이블 행마다 이메일 한 통**(`table`)로 설정하고 **드라이버 테이블**(`driver_table`)을 선택하면, 이메일 한 통 대신 테이블의 각 행마다 이메일을 하나씩 보냅니다. **이메일로 보낼 최대 행 수**(`row_limit`)는 사용할 행 수의 상한이며 기본값은 10,000입니다. 드라이버는 뷰가 아닌 테이블이어야 합니다.

주소, 제목, 메시지, 첨부 파일 경로에서 `{{row.column}}`을 사용하여 각 행의 값을 채울 수 있습니다. 드라이버 테이블에 없는 열을 사용하면 단계가 실패합니다. 받는 사람 주소가 없는 행은 아무것도 보내지 않으며, 단계는 해당 행을 알리는 경고와 함께 완료됩니다.

행의 값으로 채워지는 첨부 파일 경로(`{{row.column}}`)는 폴더가 아닌 존재하는 단일 파일이어야 하므로, 경로가 잘못 만들어진 행이 다른 사람의 파일을 보낼 수 없습니다. 해당 경로의 값이 비어 있거나, 경로가 `..`로 폴더 밖으로 벗어나거나, 파일이 없는 행은 첨부 파일 없이 전송되며 해당 행을 알리는 경고가 표시됩니다. 행별 보내기는 일반 본문이 필요하며 Jinja 템플릿 본문에서는 사용할 수 없습니다.

### 메시지


원하는 대로 **제목**과 **본문**을 지정합니다.



참고: 이 변환에서는 프로젝트 변수와 워크플로 변수를 모두 제목 줄과 메시지 본문에서 사용할 수 있습니다.



또한 본문에는 표준 HTML 코드를 사용하여 이메일 메시지의 모양을 더 세부적으로 조정할 수 있습니다.


### 첨부 파일


이메일에 파일을 첨부하는 것은 매우 간단합니다. 문서에서 첨부할 파일 또는 폴더를 선택합니다. 폴더를 선택하면 폴더의 내용이 개별 파일로 첨부됩니다. 경로에서 변수 대체가 작동하므로, 개인화된 이메일을 보낼 때 파일 첨부를 더 세밀하게 제어할 수 있습니다.



여러 문서를 첨부하려면 **이메일에 첨부 파일 추가**를 선택하고 **추가 이메일 옵션**의 **추가 첨부 파일**(`attachments`)에 각 문서의 **계정 ID**와 **문서 경로**를 나열합니다. 이 문서들은 선택한 첨부 파일과 함께 전송되며, 경로에는 변수와 행 토큰을 같은 방식으로 사용할 수 있습니다.

### 우선순위 및 일반 텍스트

**추가 이메일 옵션**에서 **우선순위**(`priority`)는 메시지를 **낮음**, **보통** 또는 **높음**(`low`, `normal`, `high`)으로 표시하며, **보내기 형식**(`content_type`)을 **일반 텍스트**(`text`)로 설정하면 본문을 **HTML**(`html`, 기본값) 대신 일반 텍스트로 보냅니다.

### 본문(Jinja 템플릿)


단계의 본문은 하나 이상의 **프레임**에 대해 렌더링되는 **Jinja 템플릿**으로 작성되어 풍부한 HTML 이메일을 생성합니다. 각 프레임은 이름이 지정된 단일 테이블 선택으로, 프레임 이름, 워크플로 테이블 하나, 그리고 선택 사항인 열 선택, where 필터, 집계로 구성됩니다(조인 없음). 편집기는 프레임 목록, 템플릿 본문, 실시간 미리 보기, **나에게 테스트 보내기** 버튼이 있는 이 템플릿으로 바로 열리며 일반 텍스트와 템플릿 간 전환은 없습니다. **코드 정리** 버튼과 삽입 팔레트(프레임용 `render_table(...)`, `{{ cloud }}`, for 루프, 통화/천 단위/백분율/날짜 필터)가 템플릿 작성을 돕습니다.

템플릿에서 각 프레임은 `frames['<Frame Name>'].rows`와 `frames['<Frame Name>'].columns`로 참조합니다. 프레임이 하나인 템플릿은 첫 번째 프레임에 바인딩된 최상위 `rows` / `columns`를 사용할 수 있습니다. 템플릿은 별도의 샌드박스 렌더링 엔진이므로 `cloud`만 워크스페이스 값으로 확인되며, 레거시 `{project}` / `{model}` / `{date}` 토큰은 그 안에서 확인되지 않습니다. Jinja 작성 방식이 도입되기 전에 만든 단계는 기존 본문이 자동 변환된 상태로 열리며, 안전하게 변환할 수 없는 본문은 일반 텍스트 대체 상태로 유지되어 레거시 `{token}` 대체 방식으로 계속 전송됩니다. 사용 가능한 템플릿 변수, `render_table` 도우미, 이메일 새니타이저를 통과하는 HTML 태그와 속성, 기존 본문의 마이그레이션 방법은 [템플릿 HTML 이메일 알림 보내기](/ko/guides/workflows/notify-email-templates/)를 참조하십시오.
