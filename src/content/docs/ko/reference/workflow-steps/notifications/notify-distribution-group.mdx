## 설명



워크스페이스 설정에서 관리하는 이름이 지정된 수신자 목록인 PlaidCloud 배포 그룹에 이메일 알림을 보냅니다. 정해진 대상에게 전달해야 하는 상태 업데이트, 완료 알림 또는 오류 경고에 유용합니다.

메시지는 PlaidCloud의 알림 서비스에서 발송됩니다. 배포 그룹은 중앙에서 관리되므로 워크플로 작성자가 워크플로 정의에 이메일 주소를 직접 넣을 필요가 없습니다.


## PlaidCloud 배포 목록 선택


드롭다운 메뉴에서 배포 목록 하나를 선택합니다. 배포 목록은 도구를 사용하여 만들 수 있습니다. 배포 목록을 만드는 방법은 [PlaidCloud 도구 – 배포 목록](/ko/administration/access/member-management/#배포-목록distro-list-관리)을 참조하십시오.



## 메시지


원하는 대로 **제목**과 **본문**을 지정합니다.



참고: 이 변환에서는 프로젝트 변수와 워크플로 변수를 모두 제목 줄과 메시지 본문에서 사용할 수 있습니다.



또한 본문에는 표준 HTML 코드를 사용하여 이메일 메시지의 모양을 더 세부적으로 조정할 수 있습니다.


## 예제


이 예제에서는 모든 시스템 변수를 사용했습니다. 또한 본문의 첫 줄을 서식 지정하는 데 약간의 HTML을 사용했습니다. 이 변환을 실행하면 배포 그룹에 지정된 모든 멤버에게 다음 이메일이 전송됩니다.


* FROM: [info@tartansolutions.com](mailto:info%40tartansolutions.com) (모든 메시지는 이 주소에서 발송됩니다)
* 제목: DEMO Analyze Demo Running


<Aside>이메일 메시지의 개별 수신자는 배포 목록에 있는 다른 멤버의 이름을 볼 수 **없습니다**.</Aside>
