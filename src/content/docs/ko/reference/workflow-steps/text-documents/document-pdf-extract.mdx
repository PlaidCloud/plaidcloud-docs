## 설명

**PDF Text Extract** 단계는 PDF 문서에서 텍스트를 추출합니다. 해당하는 Alteryx 도구에 대응하며 워크플로 엔진에서 실행됩니다(ML / NLP / 문서 라이브러리는 실행기 작업에서 실행됩니다).

## 소스 및 옵션

- **소스 / 출력 테이블** — 입력 데이터와 결과를 기록할 위치입니다.
- **PDF 경로 열**(또는 PDF **디렉터리**).

## 열

**열** 탭은 출력으로 전달되는 입력 열을 매핑합니다.
