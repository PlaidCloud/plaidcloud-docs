## 설명

PDF의 텍스트 콘텐츠를 테이블로 추출합니다. Alteryx의 *PDF to Text* 도구에 대응하며, 문서 라이브러리가 있는 워크플로 엔진에서 실행됩니다.

PDF의 내용을 워크플로의 나머지 부분에서 필터링, 구문 분석, 조인할 수 있는 형태로 가져올 때 사용하십시오. 페이지 수준 및 레이아웃 인식 추출에는 [PDF Text Extract 단계](/ko/reference/workflow-steps/text-documents/document-pdf-extract/)를 대신 사용하십시오.

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — PDF를 지정하는 테이블과 추출된 텍스트를 기록할 테이블입니다.
- **열** — 출력으로 전달할 소스 열입니다.
