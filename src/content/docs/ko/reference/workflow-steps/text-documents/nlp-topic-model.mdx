## 설명

**Text Topic Model** 단계는 텍스트 열 전반의 토픽을 발견합니다. 해당하는 Alteryx 도구에 대응하며 워크플로 엔진에서 실행됩니다(ML / NLP / 문서 라이브러리는 실행기 작업에서 실행됩니다).

## 소스 및 옵션

- **소스 / 출력 테이블** — 입력 데이터와 결과를 기록할 위치입니다.
- **텍스트 열**, 토픽 수, 어휘 크기.

## 열

**열** 탭은 출력으로 전달되는 입력 열을 매핑합니다.

## KNIME 텍스트 처리 노드

**KNIME 텍스트 처리 노드** 그룹에서 **KNIME 텍스트 노드**(`node`)를 선택하면 이 단계로 KNIME의 텍스트 처리 노드 중 하나를 실행합니다. 예를 들어 `preprocess`, `tagger`, `bag_of_words`, `frequency`, `document_vector`, `keywords`, `topics`, `language` 또는 임베딩 노드가 있습니다. **문서 열**(`document_column`) 및 **출력 열**(`output_column`) 같은 노드 자체 설정은 `knime_config`에서 노드 옆에 표시됩니다. 단계 자체 설정을 실행하려면 노드를 **(없음)** 으로 두십시오. 변환된 KNIME 워크플로도 같은 키를 설정합니다.

**KNIME 노드 테이블** 그룹에서 사전, 엔터티 목록, 어휘처럼 두 번째 테이블을 읽는 노드는 **두 번째 테이블 열**(`source_b_columns`)의 열이 있는 **두 번째 입력 테이블**(`source_b`)을 읽습니다. 추가 출력이 있는 노드는 **추가 출력 테이블**(`targets`)에 나열된 테이블에 순서대로 기록합니다.
