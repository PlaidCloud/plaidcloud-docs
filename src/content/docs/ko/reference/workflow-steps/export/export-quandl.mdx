## 설명



PlaidCloud 테이블을 Quandl(NASDAQ Data Link) 데이터베이스로 푸시합니다. 주로 Quandl에 게시된 데이터 세트를 유지 관리하며 PlaidCloud 워크플로에서 이를 새로 고치려는 조직을 위한 단계입니다.

Quandl API 자격 증명과 Quandl 측에서 쓰기 액세스용으로 구성된 대상 데이터베이스가 필요합니다.


## 소스 및 대상


다음 매개변수를 지정합니다.


* **소스 테이블**: 내보낼 Analyze 데이터 테이블
* **Quandl 연결**: Quandl 데이터 세트에 접근하려면 사용자 계정 또는 액세스가 제한된 게스트 계정이 필요합니다. 이를 위해 도구에서 설정해야 합니다. Quandl 계정 연결 설정에 대한 자세한 내용은 여기를 참조하십시오: [PlaidCloud 도구 – 연결](/ko/reference/connectors/)
* **Quandl 코드**: **검색** 버튼을 사용하여 데이터 세트를 검색합니다. 또는 데이터 세트를 직접 입력할 수도 있으며, 이 경우 “[http://www.quandl.com](http://www.quandl.com/)” 뒤에 오는 URL 부분을 입력해야 합니다. 예를 들어 Microsoft 주식 데이터 세트(http://www.quandl.com/GOOG/NASDAQ_MSFT 에서 찾을 수 있음)를 가져오려면 Quandl 코드 필드에 *GOOG/NASDAQ_MSFT*를 입력합니다
* **데이터 세트 이름**: Quandl로 내보낼 데이터 세트의 이름
* **데이터 세트 설명**: Quandl로 내보낼 데이터 세트의 설명
