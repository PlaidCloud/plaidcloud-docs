## 설명

파일이 아니라 [연결](/ko/reference/connectors/)을 통해 프로젝트 테이블을 외부 데이터베이스에 기록합니다. 모델링한 결과를 보고용 데이터베이스, 데이터 웨어하우스 또는 운영 시스템으로 되돌려 보낼 때 사용합니다.

[외부 데이터베이스 테이블 가져오기](/ko/reference/workflow-steps/import/import-external-database-tables/)의 반대 단계입니다. 한 단계에서 여러 테이블을 이동하며, 대상 테이블은 명시적으로 선택하거나 검색 패턴으로 일치시킬 수 있습니다.

## 고유 구성 항목

### 연결

대상 데이터베이스를 식별하는 데이터 연결입니다.

### 내보내기 유형

행을 기록하기 전에 각 대상 테이블을 준비하는 방식입니다.

- **추가만** — 기존 테이블에 행을 추가하며, 테이블이 없으면 실패합니다.
- **비우고 추가** — 테이블을 비우고 구조는 유지한 채 기록합니다.
- **만들고 추가** — 테이블이 없으면 만든 다음 기록합니다.
- **삭제, 만들기 후 추가** — 테이블을 삭제하고 다시 만든 다음 기록합니다. 소스 스키마가 변경된 경우에 사용합니다.

### 프레임 이름

단계가 실행되는 프레임의 이름입니다.

### 대상 추가

대상 추가 및 제거 버튼을 사용하여 대상 테이블 목록을 만듭니다. 대상을 선택하면 오른쪽 창에서 구성할 수 있으며, **선택 항목 전환**을 사용하여 선택한 대상의 내보내기를 사용하거나 사용하지 않도록 설정합니다. 내보내기는 대상 데이터베이스에서 테이블을 검색하지 않으므로 각 대상을 직접 추가하십시오. 외부 데이터베이스의 테이블을 찾으려면 [외부 데이터베이스 테이블 가져오기](/ko/reference/workflow-steps/import/import-external-database-tables/) 단계를 사용합니다.

### 대상 탭

선택한 대상에는 세 개의 탭이 있습니다.

#### 소스 및 대상

내보낼 프로젝트 테이블과 저장될 위치를 선택합니다.

- **소스** — **특정 테이블**은 프로젝트 테이블 하나를 지정하며, 실행 시점에 이름이 바뀌는 경우를 위한 **동적** 옵션이 있습니다. **검색과 일치하는 테이블**은 **검색 경로**와 **검색 텍스트**로 찾은 모든 프로젝트 테이블을 내보내며, **정확히 일치**, **시작 문자열**, **포함** 또는 **끝 문자열** 방식으로 일치시킵니다.
- **대상 외부 테이블** — **내보내기 사용**은 대상을 켜거나 끕니다. **대상 스키마**와 **대상 테이블**은 대상 테이블의 이름을 지정합니다. **원본 테이블과 같은 이름 사용**은 각 소스 테이블의 이름을 그대로 사용합니다.

#### 테이블 데이터 선택

대상의 열 매퍼이며 전체 높이를 차지하는 별도의 탭입니다. **소스 검사**는 프로젝트 소스 테이블의 열을 매퍼로 읽어 옵니다.

#### 데이터 필터

대상에 기록되는 행을 필터링합니다.
