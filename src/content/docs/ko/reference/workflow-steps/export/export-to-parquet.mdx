## 설명

프로젝트 테이블을 [Apache Parquet](https://parquet.apache.org/) 파일로 문서 계정에 기록합니다. Parquet은 데이터를 행이 아닌 열 단위로 저장하므로 열이 많은 테이블에서 CSV보다 훨씬 효율적으로 압축되며, 다운스트림 판독기가 필요한 열만 불러올 수 있습니다.

대규모 테이블을 클라우드 데이터 플랫폼이나 데이터 과학 워크플로에 전달할 때 대체로 가장 적합한 선택입니다. 정수, 소수, 날짜, 타임스탬프 같은 유형이 보존되며, 일부 값이 비어 있어도 정수로 이루어진 열은 정수 열로 유지됩니다. [Parquet 가져오기](/ko/reference/workflow-steps/import/import-parquet/) 단계와 함께 사용하십시오.

## 고유 구성 항목

### 압축

Parquet은 열 청크마다 압축합니다.

* **Snappy** — 읽기 속도가 가장 빠르고 파일 크기는 보통입니다.
* **Zstandard** — 파일이 더 작으며, Zstandard 0.8 이상의 판독기가 필요합니다.

### 대상 파일 접두사

단계가 테이블 하나를 파일 하나로 내보내고 값이 이미 `.parquet`으로 끝나는 경우(예: `Loadfile1.parquet`) 파일은 정확히 그 이름으로 기록됩니다. 그렇지 않으면 값은 접두사로 사용되어 각 테이블이 `<prefix><table name>.parquet`로 기록됩니다.

### 테이블당 파일 하나

Parquet 내보내기는 테이블마다 파일 하나를 기록합니다. 여러 파일을 기록하도록 선택하면 그 사실을 알리는 메시지와 함께 거부되므로, 내보내기를 실행하려면 해당 선택을 해제하십시오.

### 파일이 있는 경우

**파일 매개변수** 페이지의 **파일이 있는 경우** 아래에 있는 **이미 있는 파일**(`if_exists`):

* **덮어쓰기**(`overwrite`, 기본값)는 이미 있는 파일을 대체합니다.
* **아무것도 기록하지 않고 단계 실패**(`fail`)는 기록하려는 파일이 이미 있으면 아무것도 기록하지 않고 단계를 중단합니다.
