## 설명

다른 내보내기 단계가 기록하는 원시 열 덤프 대신, 템플릿을 통해 프로젝트 테이블을 렌더링하여 구조화된 문서를 만듭니다. 받는 시스템이 테이블이 아니라 특정 XML 구조나 다른 텍스트 형식을 요구할 때 사용합니다.

## 고유 구성 항목

### 소스 템플릿

출력을 렌더링하는 데 사용하는 Jinja 템플릿입니다. [템플릿에서 사용할 수 있는 항목](#템플릿에서-사용할-수-있는-항목)을 참조하십시오.

### 대상 출력

렌더링된 결과의 문서 계정, 폴더 및 파일 이름입니다. 파일에 담기는 내용은 템플릿이 결정하며, 확장자가 없는 파일 이름에는 `.xml`이 붙습니다.

**테이블 데이터에 Pandas 데이터프레임 사용**은 각 소스의 행이 템플릿에 전달되는 방식을 바꿉니다. [테이블로서의 소스 행](#테이블로서의-소스-행)을 참조하십시오.

### 소스 테이블

테이블을 명시적으로 지정하거나, 경로와 검색 규칙(정확히 일치, 시작 문자열, 끝 문자열, 포함 또는 glob)으로 일치시킵니다.

## 템플릿에서 사용할 수 있는 항목

템플릿은 샌드박스에서 렌더링되며 단계가 제공하는 데이터만 읽을 수 있습니다.

- **각 소스는 해당 이름(Name)으로.** 나열한 모든 소스 테이블은 지정한 **이름**으로 템플릿에서 사용할 수 있으므로 `invoices`처럼 변수로 쓸 수 있는 이름을 사용하십시오.
- **워크플로의 변수**는 `variable`로 사용합니다. 예: `{{ variable.region }}`.

```jinja
<Invoices>
{% for row in invoices %}
  <Invoice id="{{ row.invoice_id }}" amount="{{ row.amount }}" />
{% endfor %}
</Invoices>
```

### 목록으로서의 소스 행

**테이블 데이터에 Pandas 데이터프레임 사용**을 끄면 소스는 읽기 전용 행 목록입니다. 목록을 반복하거나 `|length`, `keys()`, `first()`, `one()`, `all()`, `scalar()`, `scalars()`, `mappings()`, `fetchmany(n)`, `columns('a', 'b')`를 사용합니다. 행의 값은 `row.amount`, `row['amount']` 또는 `row[0]`으로 읽으며, `row._mapping`, `row._asdict()`, `row._fields`도 작동합니다. `columns('a', 'b')`의 행은 `row.amount` 또는 `row[0]`을 사용하며 `row['amount']`는 사용할 수 없습니다.

### 테이블로서의 소스 행

**테이블 데이터에 Pandas 데이터프레임 사용**을 켜면 소스는 읽기 전용 테이블입니다. 반복하면 각 행이 사전으로 제공되므로 `row.amount`와 `row['amount']`가 모두 작동합니다. 다음도 사용할 수 있습니다.

- `columns`, `empty`, `shape`, `values`, `index`
- `head(n)`과 `tail(n)`
- `itertuples()`는 행 위치를 `Index`로 맨 앞에 두므로 `r[1]`이 첫 번째 열이며, `itertuples(index=False)`는 이를 제외합니다
- `iterrows()`는 행 위치와 행을 제공합니다
- `invoices['amount']`는 한 열의 값이며 `sum()`, `min()`, `max()`, `mean()`, `unique()`, `tolist()`를 사용할 수 있고, `sum`, `min`, `max`, `mean`은 null을 건너뜁니다

`loc`와 `groupby` 같은 다른 pandas 메서드는 사용할 수 없습니다. 이전 단계에서 데이터를 가공하고 그 결과를 내보내십시오.

### 템플릿이 할 수 없는 작업

- 어떤 값에 대해서든 이름이 `to_`로 시작하는 메서드를 호출하는 것 — `to_csv`와 `to_json`뿐 아니라 `to_pydatetime`처럼 무해한 메서드도 해당됩니다.
- 행의 `_mapping`, `_asdict`, `_fields`를 제외하고 이름이 밑줄로 시작하는 속성을 읽는 것.
- 파일을 쓰거나 여는 것.

`to_` 호출이나 파일 작업은 단계를 실패시킵니다. 위 세 가지를 제외한 밑줄 속성은 아무것도 렌더링되지 않습니다.
