## 설명

**Tableau Hyper Export** 단계는 테이블을 Tableau Hyper 파일로 내보냅니다. 워크플로 엔진에서 실행되며, 패키지 매크로 결과는 Alteryx 매크로의 근사치입니다.

## 매개변수

- **소스 테이블**과 **출력 파일** 경로입니다.

워크플로 엔진에서는 Tableau Hyper 라이터를 사용할 수 없으므로 대신 CSV가 기록됩니다(기능상 다운그레이드).
