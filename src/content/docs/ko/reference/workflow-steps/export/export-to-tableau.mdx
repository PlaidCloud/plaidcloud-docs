## 설명

**Publish to Tableau** 단계는 `.hyper` 추출을 데이터 소스로 Tableau Server 또는 Tableau Cloud에 게시합니다. 먼저 [Tableau Hyper Export 단계](/ko/reference/workflow-steps/export/export-hyper/)로 추출을 기록한 다음 이 단계로 게시하십시오. 이 단계는 [Tableau 연결](/ko/reference/connectors/collaboration/tableau/)의 개인 액세스 토큰으로 로그인하고, 파일을 청크 단위로 업로드하므로 파일 크기가 단일 요청에 의해 제한되지 않으며, 완료되면 로그아웃합니다.

추출 파일이 없는 것은 오류가 아닙니다. 단계는 아무것도 게시되지 않았다고 경고하고 워크플로는 계속됩니다.

## 매개변수

- **Hyper 추출** — 게시할 문서 계정의 `.hyper` 파일입니다.
- **Tableau 연결** — 게시에 사용할 Tableau 연결입니다.
- **데이터 소스 이름** — Tableau에서 사용할 데이터 소스의 이름입니다. 비워 두면 확장명을 제외한 추출 파일 이름을 사용합니다.
- **프로젝트** — 게시할 대상 Tableau 프로젝트입니다. 비워 두면 사이트의 Default 프로젝트를 사용합니다. 사이트에 없는 Tableau 프로젝트 이름을 지정하면 단계가 실패합니다.
- **데이터 소스가 있는 경우** — 게시 모드입니다. [모드](#모드)를 참조하십시오.
- **일치 키** — 행을 일치시키는 열이며, 쉼표로 구분한 목록으로 입력합니다. **업서트**, **업데이트**, **일치하는 행 바꾸기**에 필요합니다.

## 모드

| 모드 | 데이터 소스가 있을 때 | 없을 때 |
| --- | --- | --- |
| **새로 만들기** | 단계가 실패합니다. | 새로 만듭니다. |
| **덮어쓰기** | 대체합니다. | 새로 만듭니다. |
| **추가** | 추출의 행을 추가합니다. | 새로 만듭니다. |
| **업서트** | 일치 키가 일치하는 행은 업데이트하고 나머지는 추가합니다. | 새로 만듭니다. |
| **업데이트** | 일치 키가 일치하는 행을 업데이트하며 추가하지는 않습니다. | 경고하고 아무것도 변경하지 않습니다. |
| **일치하는 행 바꾸기** | 일치 키가 일치하는 행을 삭제한 다음 추출의 행을 삽입합니다. | 새로 만듭니다. |

**추가**, **업서트**, **업데이트**, **일치하는 행 바꾸기**는 선택한 프로젝트에서, 선택하지 않았다면 사이트의 Default 프로젝트에서 이름으로 데이터 소스를 찾고, 찾은 프로젝트에 게시합니다. 키를 사용하는 모드는 Tableau의 데이터 업데이트 작업을 통해 데이터 소스의 행을 제자리에서 변경합니다.

## 요구 사항

- 연결의 서버 주소는 `https`를 사용해야 합니다. `http`로 지정된 서버는 개인 액세스 토큰이 암호화되지 않은 채 네트워크를 지나가게 되므로 단계가 실패합니다. 호스트 이름만 입력하면 `https`로 간주합니다.
- 서버는 인터넷에서 접근할 수 있어야 합니다. PlaidCloud는 사설 네트워크에 있는 Tableau 서버에는 게시하지 않습니다.
- 개인 액세스 토큰의 소유자에게 해당 프로젝트에 게시할 권한이 있어야 합니다.
