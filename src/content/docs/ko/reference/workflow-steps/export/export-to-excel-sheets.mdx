## 설명

여러 프로젝트 테이블을 하나의 Microsoft Excel 통합 문서의 서로 다른 시트에 기록하며,
서식이 지정된 템플릿의 서식을 유지합니다. 각 테이블은 이름이 지정된 시트 하나를 채우며,
전체 통합 문서는 템플릿에서 한 번 시드된 후 한 번에 렌더링됩니다. 따라서 같은 출력
파일을 공유하는 별도의 단일 시트 내보내기처럼 시트가 서로를 덮어쓰지 않습니다.

하나의 통합 문서에 결과 시트가 둘 이상 필요한 경우, 예를 들어 데이터 시트, 요약 시트,
매개변수 시트가 있는 서식 지정된 보고용 템플릿에 이 단계를 사용합니다. 시트가 하나이거나
서식이 없는 일반 통합 문서에는 [Export to Excel 단계](/ko/reference/workflow-steps/export/export-to-excel/)를
대신 사용하십시오.

템플릿의 서식은 기록되는 각 시트에 그대로 적용됩니다. 값, 숫자 형식, 글꼴, 채우기, 테두리,
병합된 셀, 열 너비가 해당됩니다. 피벗 테이블이나 차트가 있는 템플릿은 시트를 기록할 때
해당 개체가 제거되며, 기록 시 다시 만들어지지 않습니다.

## 내보내기 매개변수

### 출력 파일

통합 문서를 기록할 문서 계정과 폴더이며, 통합 문서 **파일 이름**과 함께 지정합니다.

### 템플릿 파일

통합 문서를 시드하는 서식 지정된 템플릿으로, 기록되는 모든 시트가 서식을 물려받는 기존
`.xlsx` 파일의 문서 계정과 경로입니다. 템플릿을 지정하지 않으면 단계는 기존 출력 파일이
이미 있는 경우 그 파일에서 시드합니다.

### 압축

통합 문서는 기본적으로 압축하지 않고 기록됩니다. Zip, GZip 또는 BZip2 압축을 사용할 수 있습니다.

## 시트

**시트** 테이블의 각 항목은 통합 문서의 워크시트 하나를 채웁니다.

| 필드 | 용도 |
| --- | --- |
| 소스 | 시트의 행을 제공하는 프로젝트 테이블입니다. |
| 대상 시트 | 채울 템플릿의 시트입니다. |
| 범위 | 선택 사항인 A1 방식 범위(예: `A1:S1000000`)로, 테이블을 기록하기 전에 기존 값을 지우며 주변 템플릿 셀은 그대로 둡니다. |
| 머리글 쓰기 | 열 이름 머리글 행을 기록할지 여부입니다. 기본적으로 켜져 있습니다. |
| 열 | 소스 테이블의 모든 열을 원하지 않을 때 기록할 열을 순서대로 지정합니다. |

양식에는 다음 필드도 있습니다.

* **이미 있는 통합 문서**(`if_exists`) — **아무것도 기록하지 않고 단계 실패**(`fail`)는 통합 문서가 이미 있으면 단계를 중지합니다. 기본값인 **시트 기록**(`replace`)은 통합 문서에 기록합니다.
* 시트 항목에서 **행 정렬 기준**(`sort_columns`)은 기록되는 행을 이 소스 열로 정렬하며 첫 번째 키부터 적용하고, 각 키마다 **열**, **오름차순**, **NULL 값** 설정이 있습니다. **누락된 셀 값**(`null_as`)은 숫자 열을 포함하여 시트의 누락된 모든 셀에 기록되는 텍스트이며, **이미 있는 시트**(`if_sheet_exists`)는 통합 문서에 이미 해당 시트가 있을 때의 동작을 결정합니다. **단계 실패 처리**(`fail`)는 단계를 중지하고 **그대로 두기**(`skip`)는 해당 시트를 그대로 둡니다.

## 크기 제한

각 시트에는 단일 시트 내보내기와 동일한 Excel 제한이 적용됩니다. 최대
1,048,576행(머리글 행 포함)과 16,384열입니다. 이를 초과하는 시트는 Excel이 열지 못하는
파일을 만드는 대신 단계를 중지합니다. 이보다 큰 데이터는 CSV나 Parquet로 내보내십시오.
