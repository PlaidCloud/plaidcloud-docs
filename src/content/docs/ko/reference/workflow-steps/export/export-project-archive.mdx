## 설명

워크플로, 테이블 정의, 차원, 변수 및 설정을 포함한 프로젝트 전체의 아카이브를 단일 파일로 문서 계정에 기록합니다. 큰 변경 전의 특정 시점 백업이나 다른 워크스페이스로 프로젝트를 넘길 때 사용합니다.

이 단계는 데이터뿐 아니라 *프로젝트*를 아카이브합니다. 테이블 데이터만 필요하면 [Export to Table Archive 단계](/ko/reference/workflow-steps/export/export-to-table-archive/)를 사용하십시오.

## 고유 구성 항목

### 내보내기 디렉터리 및 파일 이름

- **내보내기 디렉터리** — 아카이브를 기록할 문서 계정과 폴더입니다.
- **대상 파일** — 아카이브의 파일 이름입니다.
