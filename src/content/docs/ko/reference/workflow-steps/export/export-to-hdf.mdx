## 설명


Analyze 데이터 테이블을 HDF5 파일로 PlaidCloud Document에 내보냅니다.


HDF5 파일에 대한 자세한 내용은 HDF Group 공식 웹사이트(http://www.hdfgroup.org/HDF5/)를 참조하십시오.

### 출력 파일 유형


내보낸 모든 파일은 기본적으로 압축되지 않지만, 다음 압축 옵션을 사용할 수 있습니다.


* Zip
* GZip
* BZip2
