## 설명


Analyze 데이터 테이블을 Google 스프레드시트로 Google Drive에 내보냅니다. 이 변환을 사용하려면 유효한 Google 계정이 필요합니다. 변환을 사용하기 전에 PlaidCloud Tools에서 사용자 자격 증명을 설정해야 합니다.



## 내보내기 매개변수


### 소스 및 대상


드롭다운 메뉴에서 PlaidCloud Document의 **소스 테이블**을 선택합니다.



다음으로 **대상 연결** 정보를 지정합니다. Google Docs 계정 연결 설정에 대한 자세한 내용은 [PlaidCloud Tools – 연결](/ko/reference/connectors/)을 참조하십시오. 필요한 계정을 모두 설정했으면 드롭다운 목록에서 해당 계정을 선택합니다.



마지막으로 **대상 스프레드시트 이름**과 **대상 워크시트 이름**을 입력합니다. 필요한 경우 **기존 워크시트 데이터에 데이터 추가** 확인란을 선택하여 기존 워크시트에 데이터를 추가합니다. 대상 워크시트가 아직 없으면 새로 만들어집니다.



아직 없는 스프레드시트는 새로 만들어지며, 없는 워크시트도 마찬가지입니다. 계정에서 둘 이상의 스프레드시트가 같은 **대상 스프레드시트 이름**을 사용하는 경우에는 거부되므로, 이름이 고유해지도록 중복된 스프레드시트의 이름을 바꾸십시오. 값은 입력한 그대로 기록되므로 `=`로 시작하는 텍스트 셀은 수식이 되지 않고 텍스트로 유지됩니다. **기존 워크시트 데이터에 데이터 추가**를 선택 해제하면 행을 기록하기 전에 워크시트를 비우고 테이블 크기에 맞게 조정합니다.
