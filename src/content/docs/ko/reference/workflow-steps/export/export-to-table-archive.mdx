## 설명



PlaidCloud 테이블을 PlaidCloud 고유의 아카이브 파일로 문서 계정에 기록합니다. 아카이브에는 PlaidCloud가 아는 모든 열 유형, 인덱스, 메타데이터가 보존되므로, PlaidCloud 프로젝트 또는 환경 간에 주고받을 때 CSV보다 충실도가 높습니다.

[아카이브 가져오기](/ko/reference/workflow-steps/import/import-archive/) 단계와 함께 사용하면 아카이브를 프로젝트로 다시 가져올 수 있습니다. 백업, 프로젝트 간 마이그레이션, 환경 간 데이터 전송에 유용합니다.
