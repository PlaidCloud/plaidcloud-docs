## 설명

**Export to PDF** 단계는 테이블 하나를 문서 계정에 PDF 문서로 기록합니다. 단계가 직접 행을 읽으므로 중간에 내보내기 작업자가 실행되지 않습니다.

## 매개변수

- **소스 테이블** — 내보낼 테이블입니다.
- **출력 폴더** — PDF를 기록할 문서 계정과 폴더입니다.
- **파일 이름** — PDF의 이름입니다. 이름에 `.pdf`가 없으면 추가됩니다.
- **열 이름을 헤더 행으로 작성** — 기본적으로 켜져 있습니다. 헤더는 모든 페이지에 반복됩니다.
- **테이블 데이터 선택** — 기록할 열을 선택하고 순서를 정합니다. 목록 대신, 워크플로가 실행될 때 소스에 있는 모든 열을 기록하도록 설정할 수도 있습니다.

## 레이아웃

- 페이지는 세로 방향 Letter 크기이며, 테이블의 열이 6개를 초과하면 가로 방향이 됩니다.
- 행은 1,000개 단위의 블록으로 기록되며, 각 블록마다 헤더가 반복됩니다.
- null 값은 빈 셀이 됩니다.
- 한 페이지에 들어가지 않을 만큼 긴 셀은 말줄임표와 함께 잘리며, 단계는 잘린 열의 이름을 경고로 알려 줍니다.
- 워크플로 엔진에 Unicode 글꼴이 있으면 PDF에 그 글꼴이 사용됩니다. 없으면 PDF는 Latin-1 문자만 표시하는 Helvetica로 구성되며, 단계가 경고합니다.
