## 설명

프로젝트 테이블을 [Apache Avro](https://avro.apache.org/) 파일로 문서 계정에 기록합니다. Avro는 스키마를 파일 안에 담고 있으므로 별도의 스키마 정의 없이도 열 이름과 형식이 그대로 유지되며, 따라서 Kafka, Spark 또는 Hadoop 소비자에게 데이터를 넘기는 데 적합합니다.

[Avro 가져오기](/ko/reference/workflow-steps/import/import-avro/)와 함께 사용하면 형식을 잃지 않고 프로젝트 간에 테이블을 이동할 수 있습니다.

## 고유 구성 항목

### 압축

기록되는 파일은 내보내는 과정에서 압축할 수 있습니다.

* 압축 안 함
* Zip
* GZip
* BZip2

### 파일 이름

파일 이름은 내보내기의 **파일 이름**을 따르며, 이름에 확장자가 없으면 `.avro` 확장자가 붙습니다. `customers`라는 내보내기는 `customers.avro`를 기록합니다. 내보내기가 여러 테이블을 기록하면 각 파일은 내보내기 이름 뒤에 테이블의 별칭이 붙으며 `customers_orders.avro`와 같습니다. **Many Files**를 켜면 내보내기가 그 이름의 폴더를 만들어 `data1.avro`, `data2.avro` 등을 담으며, 각 파일에는 최대 배치 크기만큼의 행이 들어갑니다.

### 파일이 있는 경우

**파일 매개변수** 페이지의 **파일이 있는 경우** 아래에 있는 **이미 있는 파일**(`if_exists`)입니다.

* **덮어쓰기**(`overwrite`, 기본값)는 이미 있는 파일을 교체합니다.
* **아무것도 기록하지 않고 단계 실패**(`fail`)는 기록하려는 파일이 이미 있으면 아무것도 기록하지 않고 단계를 중지합니다.
