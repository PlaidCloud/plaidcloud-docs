## 설명

[S/4HANA Cloud 연결](/ko/guides/connections/s4hana-cloud/)을 통해 SAP S/4HANA Cloud 엔터티 하나를 프로젝트 테이블로 가져옵니다. 연결, 엔터티 유형, 필터를 선택하면 이 단계가 일치하는 레코드를 가져와 기록하므로 OData 쿼리를 직접 작성할 필요가 없습니다.

이 단계는 범용 기성 단계로, 하나의 단계 유형이 두 가지 엔터티를 다룹니다. 하나는 기말 보고를 위한 집계된 `trial_balance` 큐브이고, 다른 하나는 전기된 거래 상세를 라인 항목 수준으로 제공하는 `journal_entry_items`입니다.

## 구성

| 필드 | 필수 | 참고 |
|---|---|---|
| S/4HANA 연결 | 예 | 데이터를 읽을 S/4HANA Cloud 연결입니다. |
| 대상 테이블 | 예 | 결과를 기록할 프로젝트 테이블입니다. 실행할 때마다 전체 내용을 덮어씁니다. |
| 엔터티 유형 | 예 | 가져올 엔터티입니다. 기본값은 `trial_balance`입니다. `trial_balance`, `journal_entry_items` 중 하나입니다. |
| 필터 | 아니요 | 요청의 OData `$filter`로 변환되는 범위 및 동등 필터입니다. 각 엔터티는 S/4HANA가 서버 측에서 실제로 평가할 수 있는 필드로만 필터를 제한합니다. 지원되지 않는 필드는 조용히 무시되지 않고 거부됩니다. |

### 엔터티와 필터링 가능한 필드

| 엔터티 유형 | 가져오는 내용 | OData 서비스 | 필터링 가능한 필드 |
|---|---|---|---|
| `trial_balance` | 집계된 기말 총계정원장 계정 잔액 | `API_OPLACCTGDOCITEMCUBE_SRV` | `CompanyCode`, `GLAccount`, `CostCenter`, `ProfitCenter`, `FiscalYear`(범위), `FiscalPeriod`(범위), `Ledger` |
| `journal_entry_items` | 전기된 분개 전표 라인 항목 | `API_JOURNALENTRYITEMBASIC_SRV` | `CompanyCode`, `GLAccount`, `CostCenter`, `ProfitCenter`, `PostingDate`(범위), `FiscalYear`(범위), `FiscalPeriod`(범위), `Ledger` |

<Aside type="note">
`PostingDate`, `FiscalYear`, `FiscalPeriod`는 **범위** 필터(`ge`/`le` 방식의 경계)를 지원하며, 라인 항목 상세를 제한 없이 가져오면 데이터가 매우 커질 수 있으므로 `journal_entry_items` 가져오기의 범위를 제한하는 주된 방법입니다. 운영 데이터에 대해 실행하기 전에 대용량 엔터티에는 경계를 하나 이상 설정하십시오.
</Aside>

<Aside type="caution">
`CostCenter`와 `ProfitCenter`는 Communication Scenario가 해당 필드를 노출하는 경우에만 필터링할 수 있습니다. 해당 시나리오에 포함되지 않은 차원은 조용히 무시되지 않고 지원되지 않는 필터로 거부됩니다.
</Aside>
