## 설명

**패키지 매크로**는 Alteryx *패키지 보고서 매크로*에서 가져온 보고서 번들을 렌더링합니다. 일급 Report 단계이므로 번들된 매크로 정의가 단계와 함께 자동으로 전달되며, 다른 Report 단계와 동일한 보고서 아티팩트 경로로 렌더링됩니다.

## 소스 및 옵션

- **소스 테이블** — 이 보고서 부분에 데이터를 제공하는 테이블입니다.
- **대상 테이블** — 렌더링된 출력을 기록할 테이블입니다.
- **보고서 순서** — 구성된 보고서 안에서 이 부분의 위치입니다.
