## 설명

구성된 보고서에 들어가는 소스 데이터의 **테이블**입니다. 해당하는 Alteryx *Reporting* / *Portfolio Composer* 도구에 대응하며 워크플로 엔진(reportlab / matplotlib)에서 실행됩니다. 렌더러는 Alteryx 출력을 근사한 것입니다.

## 소스 및 옵션

- **소스 테이블** — 이 보고서 부분에 데이터를 제공하는 테이블입니다.
- **출력 테이블** — 렌더링된 스니펫을 기록할 테이블입니다.
- **보고서 순서** — 구성된 보고서 안에서 이 부분의 순서입니다.
- **열** — 포함할 소스 열입니다(비워 두면 모두 포함).

## 열

**열** 탭은 보고서 부분에서 사용할 수 있는 소스 열을 매핑합니다.
