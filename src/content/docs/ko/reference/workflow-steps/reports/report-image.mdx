## 설명

구성된 보고서에 배치되는 **이미지**입니다. 해당하는 Alteryx *Reporting* / *Portfolio Composer* 도구에 대응하며 워크플로 엔진(reportlab / matplotlib)에서 실행됩니다. 렌더러는 Alteryx 출력을 근사한 것입니다.

## 소스 및 옵션

- **소스 테이블** — 이 보고서 부분에 데이터를 제공하는 테이블입니다.
- **출력 테이블** — 렌더링된 스니펫을 기록할 테이블입니다.
- **보고서 순서** — 구성된 보고서 안에서 이 부분의 순서입니다.
- **이미지 모드** — Static(인라인 base64 이미지) 또는 Field(행별 파일 경로)입니다.
- **Base64 이미지** — Static 모드에서 사용하는 인라인 이미지 데이터입니다.

## 열

**열** 탭은 보고서 부분에서 사용할 수 있는 소스 열을 매핑합니다.
