## 보고서 구성 요소

변환된 Alteryx 보고 워크플로는 다음 단계로 문서를 조립합니다. Chart, Image, Map, Table, Text 단계는 각각 보고서의 한 부분을 렌더링하고, Layout, Visual Layout, Overlay 단계는 각 부분을 배치하며, Render 단계는 구성된 결과를 PDF로 기록합니다.
