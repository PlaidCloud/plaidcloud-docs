## 설명

구성된 보고서 부분을 PDF 문서로 **렌더링**합니다. 해당하는 Alteryx *Reporting* / *Portfolio Composer* 도구에 대응하며 워크플로 엔진(reportlab / matplotlib)에서 실행됩니다. 렌더러는 Alteryx 출력을 근사한 것입니다.

## 소스 및 옵션

- **소스 테이블** — 이 보고서 부분에 데이터를 제공하는 테이블입니다.
- **출력 테이블** — 렌더링된 스니펫을 기록할 테이블입니다.
- **보고서 순서** — 구성된 보고서 안에서 이 부분의 순서입니다.
- **너비 / 높이** — 포함되는 이미지의 크기(픽셀)입니다.
- **출력 파일** — 렌더링된 파일의 문서 저장소 경로입니다.

- **출력 형식**(`output_format`) — **PDF**(`pdf`, 기본값) 또는 보고서를 독립형 HTML 페이지 하나로 기록하는 **HTML 페이지(독립형)**(`html`)입니다. 이 경우 파일 이름에 `.html` 확장자를 지정하십시오.
- **두 번째 원본 테이블**(`source_b`) — 두 번째 입력 테이블로, 렌더링이 두 입력의 보고서 부분을 함께 구성하게 합니다.

## 열

**열** 탭은 보고서 부분에서 사용할 수 있는 소스 열을 매핑합니다.
