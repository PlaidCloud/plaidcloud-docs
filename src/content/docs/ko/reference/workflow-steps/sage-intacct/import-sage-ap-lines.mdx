## 설명

Sage Intacct REST API를 통해 Sage Intacct의 매입채무 청구서 라인 수준 상세를 가져옵니다. 각 행은 청구서 라인 하나이며, 총계정원장 계정, 차원, 라인 금액, 그리고 상위 헤더로 연결되는 청구서 키를 포함합니다.

이 단계를 [Import Sage AP](../import-sage-ap/) 단계와 함께 사용하면 두 수준의 데이터를 모두 불러와 후속 배부, 보고 또는 대조에 활용할 수 있습니다.

## 고유 구성 항목

* **Sage 연결** — 데이터를 읽을 Sage Intacct REST 연결입니다. Sage 연결은 **도구 > 연결**에서 관리합니다.
* **회사 ID** — 쿼리할 Intacct 회사입니다. 발신자 자격 증명이 둘 이상의 회사를 포함하는 경우에 필요합니다.
* **엔터티 ID(쉼표로 구분)** — 가져오기를 하나 이상의 Intacct 엔터티로 제한합니다. 사용자가 액세스할 수 있는 모든 엔터티를 가져오려면 비워 두십시오.
