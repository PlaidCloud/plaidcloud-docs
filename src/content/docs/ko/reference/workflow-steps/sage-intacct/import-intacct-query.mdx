## 설명

모든 Sage Intacct 개체 유형에 대해 임시 쿼리를 실행하고 결과를 가져옵니다. 전용 [Sage AP](../import-sage-ap/) 단계 및 [Sage AP Lines](../import-sage-ap-lines/) 단계와 달리, 이 단계에서는 총계정원장, 프로젝트, 고객, 공급업체, 사용자 지정 개체 등 모든 Intacct 개체를 대상으로 지정하고 필요한 필드와 필터를 선택할 수 있습니다.

페이지 매김은 자동으로 처리되므로, 이 단계는 Intacct API 한 페이지보다 큰 결과 집합에도 사용할 수 있습니다.

## 고유 구성 항목

* **Sage 연결** — 데이터를 읽을 Sage Intacct REST 연결입니다. Sage 연결은 **도구 > 연결**에서 관리합니다.
* **회사 ID** — 쿼리할 Intacct 회사입니다.
* **엔터티 ID(쉼표로 구분)** — 쿼리를 하나 이상의 Intacct 엔터티로 제한합니다. 모든 엔터티를 대상으로 하려면 비워 두십시오.
* **개체 이름** — 쿼리할 Intacct 개체입니다(예: `GLACCOUNT`, `CUSTOMER`, `PROJECT` 또는 모든 사용자 지정 개체 이름).
* **가져올 필드** — 사용 체크박스가 있는 Intacct 필드 이름 테이블입니다. `Lookup Object Fields`를 클릭하여 Intacct 스키마에서 목록을 채운 다음, `Select All` 또는 `Select None`으로 일괄 전환하십시오.
* **필터** — 필터 행 테이블입니다. 각 행은 `Field`, `Filter Type`, `Value`로 구성됩니다. 필터 유형에는 `Equal To`, `Not Equal To`, `Less Than`, `Less Than or Equal To`, `Greater Than`, `Greater Than or Equal To`, `Is Null`, `Is Not Null`이 있습니다. 필터는 페이지 매김 전에 서버 측에서 적용됩니다.
