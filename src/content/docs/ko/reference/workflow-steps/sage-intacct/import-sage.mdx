## 설명

Sage 연결을 통해 Sage Intacct의 **차원별 계정 잔액**(Intacct의 `get_accountbalancesbydimensions`)을 가져오며, 날짜 범위와 계정 범위로 한정하고 선택한 차원이 각 행에 포함됩니다. 결과는 시산표입니다. 계정과 차원 조합당 한 행이며 기초(`startbalance`), 기간(`periodbalance`), 기말(`endbalance`) 잔액을 포함합니다.

시산표 또는 잔액 기반 손익계산서에 사용하십시오. 아래의 **통계** 컨트롤은 인원 수, 면적, 단위 수와 같은 Intacct의 비화폐성 통계 계정에도 접근하므로, 별도의 내보내기 없이 한 단계에서 재무 잔액, 통계 잔액 또는 둘 다 가져와 단위당 지표를 만들 수 있습니다. 거래 수준의 총계정원장 상세에는 `GLDETAIL`에 대해 [Import Sage Intacct Query](/ko/reference/workflow-steps/sage-intacct/import-intacct-query/) 단계를 사용하십시오. 모든 Intacct 개체에 대한 임시 쿼리에는 개체 이름을 지정하여 같은 단계를 사용하십시오.

## 고유 구성 항목

### 소스 및 대상

- **연결** — 데이터를 읽을 Sage 연결입니다.
- **회사** — 데이터를 읽을 Sage 회사입니다.

### 데이터 선택

- **시작 날짜** / **종료 날짜** — 잔액을 보고하는 기간입니다(둘 다 필수이며, 시작 날짜나 종료 날짜 하나만 지정하면 무시됩니다).
- **시작 계정** / **종료 계정** — 포함할 계정 코드 범위입니다. 번호와 관계없이 모든 계정을 포함하려면 `0000`과 `9999`를 사용하십시오. Intacct의 통계 계정이 재무 계정과목표의 번호 체계 안에 있다는 보장이 없으므로, 아래 **통계**를 통계 계정을 가져오도록 설정한 경우 보통 이렇게 지정합니다.
- **통계** — 가져오기가 반환하는 계정 잔액의 종류입니다.
  - **재무만(통계 제외)** — 재무 계정 잔액만 반환합니다(일반적인 시산표 가져오기). 기본값입니다.
  - **재무 + 통계** — 재무 계정 잔액과 통계 계정 잔액을 같은 결과에 함께 반환합니다.
  - **통계만** — 통계 계정 잔액만 반환합니다. 인원 수, 면적, 단위 수, 그리고 Intacct 계정과목표가 재무 계정과 함께 관리하는 기타 비화폐성 계정이 해당합니다.
- **엔터티** — 포함할 Sage 엔터티입니다.
- **차원** — 열로 사용할 차원을 켭니다. 클래스, 연락처, 원가 유형, 고객, 부서, 직원, 품목, 위치, 프로젝트 그룹, 작업, 공급업체가 있습니다.
- **사용자 지정 차원** — 함께 가져올 추가 사용자 정의 차원입니다.

:::caution[웨어하우스 체크박스는 아무 동작도 하지 않습니다]
단계 구성에는 **웨어하우스** 차원이 있지만 워크플로 실행기는 이를 읽지 않습니다. 이 차원은 실행기가 만드는 집합에 포함되지 않으므로 켜도 열이 추가되지 않습니다. 출력에 웨어하우스가 필요하면 **사용자 지정 차원**을 사용하십시오.
:::
