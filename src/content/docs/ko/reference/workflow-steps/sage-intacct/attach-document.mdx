## 설명

[Sage Intacct 연결](/ko/guides/connections/sage-intacct/)을 통해 증빙 문서를 Sage Intacct 레코드에 첨부하며, PlaidCloud의 공유 ERP 쓰기 파이프라인을 거칩니다. 소스 테이블의 각 행은 파일 하나를 나타내며(파일의 바이트, 이름, 첨부 대상 Intacct 레코드의 키), 이 단계는 이를 Sage Intacct 증빙 문서(`supdoc`)로 생성하여 해당 레코드에 연결합니다. **Validate Only**는 Intacct에 아무것도 생성하지 않고 모든 행을 검사하며, 결과 테이블에는 첨부 파일별 결과가 기록됩니다.

렌더링된 청구서 PDF, 스캔한 영수증, 내보낸 보고서처럼 워크플로가 이미 가지고 있는 파일을, 이를 생성하거나 전기하는 동일한 실행 안에서 해당 파일이 속한 Intacct 거래 또는 레코드에 올릴 때 사용하십시오. [Intacct: 분개 전표 전기](/ko/reference/workflow-steps/sage-intacct/export-to-sage/) 단계와 함께 쓰기에 알맞습니다. 전표를 전기한 다음, 각 전기에서 반환된 Intacct 키로 증빙 자료를 첨부하십시오.

## 데이터 형태 규약

각 행이 하나의 레코드에 연결된 완전한 파일 하나가 되도록 표준 단계로 업스트림에서 첨부 파일 테이블을 구성하십시오.

- **`parent_key`** — 파일을 첨부할 Sage Intacct 레코드입니다. 행당 파일 하나, 부모 하나입니다. 같은 파일을 여러 레코드에 첨부하려면 여러 행에 반복해서 지정하십시오.
- **`file_name`** — 확장자를 포함한 증빙 문서의 파일 이름입니다(`invoice-1043.pdf`).
- **`mime_type`** — Intacct가 파일을 올바르게 저장하고 제공하도록 하는 파일의 콘텐츠 유형입니다(`application/pdf`, `image/png`).
- **`content_base64`** — 행에 포함된, base64로 인코딩된 파일의 바이트입니다.

## 구성

### 연결

- **Sage Intacct 연결** — 첨부에 사용할 Sage Intacct 연결입니다. Sage Intacct 연결만 표시되며, 같은 연결로 Intacct에서 읽고 Intacct에 씁니다.
- **환경** — 연결의 환경입니다.

### 데이터

- **첨부 파일 테이블** — 위에서 설명한 소스 테이블입니다. 파일당 한 행이며 `parent_key`, `file_name`, `mime_type`, `content_base64`를 포함합니다.
- **결과 테이블** — 출력 테이블 ID: 첨부 파일당 한 행이며 `parent_key`, `file_name`, `supdoc_id`, `status`, `message`를 포함합니다.
- **Validate Only** — 기본적으로 선택되어 있습니다. 사전 점검만 수행하며, 각 행을 검사하고 결과 테이블을 기록하지만 Intacct에 증빙 문서를 생성하지 않습니다. 이 필드를 완전히 생략한 단계 구성(예: REST API, MCP 또는 워크플로 번들 가져오기로 작성한 구성)도 실제 첨부가 아니라 Validate Only로 기본 설정됩니다.
- **Continue On Error** — 기본적으로 선택되어 있습니다. 한 파일이 실패한 후에도 나머지 파일을 계속 첨부하며, 선택 해제하면 첫 번째 실패에서 중지합니다.

## 결과 테이블

Validate Only든 실제 실행이든 모든 실행은 소스 행마다 결과 테이블에 한 행을 기록합니다.

| 열 | 설명 |
|---|---|
| `parent_key` | 이 첨부 파일이 대상으로 하는 Intacct 레코드입니다. |
| `file_name` | 소스 행의 파일 이름입니다. |
| `supdoc_id` | 첨부에 성공한 경우, 해당 파일에 대해 생성된 Sage Intacct 증빙 문서 ID입니다. |
| `status` | 이 행의 결과(검증됨, 첨부됨 또는 실패)입니다. |
| `message` | 행이 실패한 경우 무엇이 잘못되었는지에 대한 간단하고 정제된 설명입니다. |
