## 설명

Sage Intacct REST API를 통해 Sage Intacct의 매입채무 청구서 헤더를 가져옵니다. 각 행은 매입채무 청구서 하나이며, 후속 보고에 필요한 공급업체, 총계정원장 날짜, 만기일, 합계, 상태 필드를 포함합니다.

구성된 [Sage Intacct REST 커넥터](../../../connectors/rest/sage-intacct/)를 소스로 사용하십시오. 라인 수준 상세를 동시에 가져오려면 이 단계를 [Import Sage AP Lines](../import-sage-ap-lines/) 단계와 함께 사용하십시오.

## 고유 구성 항목

* **Sage 연결** — 데이터를 읽을 Sage Intacct REST 연결입니다. Sage 연결은 **도구 > 연결**에서 관리합니다.
* **회사 ID** — 쿼리할 Intacct 회사입니다. 발신자 자격 증명이 둘 이상의 회사를 포함하는 경우에 필요합니다.
* **엔터티 ID(쉼표로 구분)** — 가져오기를 하나 이상의 Intacct 엔터티로 제한합니다. 사용자가 액세스할 수 있는 모든 엔터티를 가져오려면 비워 두십시오.
