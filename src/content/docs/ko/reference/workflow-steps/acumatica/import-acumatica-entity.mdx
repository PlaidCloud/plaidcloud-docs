## 설명

[Acumatica 연결](/ko/guides/connections/acumatica/)을 통해 Acumatica 계약 기반 REST 엔터티 하나를 프로젝트 테이블로 가져옵니다. 연결, 엔터티 유형, 필터를 선택하면 단계가 일치하는 레코드를 가져와 기록하므로 OData 쿼리를 작성할 필요가 없습니다.

이 단계는 범용 기본 제공 단계로, 하나의 단계 유형이 계정, 하위 계정, 고객, 공급업체, 재고 품목 같은 마스터/참조 데이터부터 판매 인보이스, 청구서, 판매 주문, 배송 같은 트랜잭션 레코드까지 18개 엔터티를 처리합니다.

## 구성

| 필드 | 필수 | 참고 |
|---|---|---|
| Acumatica 연결 | 예 | 읽기에 사용할 Acumatica 연결입니다. |
| 대상 테이블 | 예 | 결과를 기록할 프로젝트 테이블입니다. 실행할 때마다 전체가 덮어쓰기됩니다. |
| 엔터티 유형 | 예 | 가져올 엔터티입니다. 기본값은 `account`입니다. `account`, `ledger`, `financial_period`, `branch`, `currency`, `currency_rate`, `subaccount`, `customer`, `vendor`, `stock_item`, `warehouse`, `employee`, `tax_category`, `sales_invoice`, `bill`, `sales_order`, `shipment`, `project` 중 하나입니다. |
| 활성만 | 아니요 | 기본적으로 켜져 있습니다. Active 플래그가 있는 엔터티에 대해 `Active = true`로 필터링합니다. |
| 업데이트 기준일 | 아니요 | ISO 날짜 또는 날짜/시간입니다. 이 시점 이후에 변경된 행만 반환됩니다. 요청 측 필터이며 저장되는 커서가 없으므로, 실행할 때마다 기준 시점을 직접 지정해야 합니다. 비워 두면 모든 항목을 가져옵니다. |
| 필터 | 아니요 | `{field, operator, value}` 절(`eq`, `ne`, `gt`, `ge`, `lt`, `le`, `contains`)의 배열 또는 `{field, from, to}` 범위입니다. 엔터티마다 Acumatica가 서버 측에서 실제로 평가할 수 있는 필드로만 필터가 제한되며, 지원되지 않는 필드는 조용히 무시되지 않고 거부됩니다. |

<Aside type="note">
시산표, 총계정원장 거래 상세, 재고 현황, 예산, 회사 간 데이터는 이 18개 계약 기반 엔터티가 아니라 Acumatica Generic Inquiry에 있습니다. Acumatica에서 GI를 만들고 [Generic REST 연결](/ko/reference/connectors/rest/generic-rest/)로 가져오십시오.
</Aside>

<Aside type="caution">
필터링은 엔터티 수준과 헤더 수준 필드에만 적용됩니다. 문서의 라인 항목 차원(예: 청구서 라인의 원가 센터)은 서버 측에서 쿼리할 수 없습니다. 엔터티를 가져온 다음 가져오기 이후 워크플로에서 라인 수준 상세를 지정하십시오.
</Aside>
