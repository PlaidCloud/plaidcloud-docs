## 설명


기존 PlaidCloud Analyze 워크플로의 로그를 지웁니다.



## 지울 워크플로 로그


먼저 **프로젝트** 드롭다운 메뉴에서 지울 워크플로 로그가 들어 있는 프로젝트를 선택합니다.



다음으로 **워크플로** 드롭다운 메뉴에서 지울 특정 워크플로 로그를 선택합니다.


<Aside type="danger">삭제를 확인하는 팝업 대화상자가 없습니다. 올바른 워크플로 로그를 선택했는지 확인하십시오.</Aside>
