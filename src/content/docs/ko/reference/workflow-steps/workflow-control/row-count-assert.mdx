## 설명

두 테이블의 행 수가 다르면 워크플로를 실패시킵니다. 데이터 품질 게이트로 사용합니다. 예를 들어 변환된 테이블이 소스의 모든 행을 유지했는지, 또는 대사 과정에서 레코드가 누락되거나 중복되지 않았는지 확인할 수 있습니다. 행 수가 일치하면 워크플로가 계속 진행되고, 다르면 단계가 워크플로를 중지하고 실패 메시지를 워크플로 로그에 기록합니다.

## 구성

- **왼쪽 테이블** — 행 수를 셀 첫 번째 테이블입니다.
- **오른쪽 테이블** — 행 수를 셀 두 번째 테이블입니다.
- **실패 메시지** — 행 수가 다를 때 표시되는 메시지입니다. 기본값은 "행 수가 일치하지 않습니다"입니다.

행 수 불일치가 아닌 임의의 조건에서 실패시켜야 한다면 [워크플로 오류 발생](/ko/reference/workflow-steps/workflow-control/raise-workflow-error/)과 비교해 보십시오.
