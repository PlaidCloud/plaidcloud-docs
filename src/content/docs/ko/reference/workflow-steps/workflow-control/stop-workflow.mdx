## 설명


"워크플로 중지"는 실행 중인 기존 워크플로를 중지합니다.


<Aside>이 단계가 실행될 때 워크플로가 실행 중이 아니면 *워크플로가 이미 중지되었습니다.라는 경고가 로그에 기록됩니다.</Aside>


## 중지할 워크플로


먼저 **프로젝트** 드롭다운 메뉴에서 중지할 워크플로가 들어 있는 프로젝트를 선택합니다.



다음으로 **워크플로** 드롭다운 메뉴에서 중지할 워크플로를 선택합니다.
