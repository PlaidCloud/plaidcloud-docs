## 설명


기존 PlaidCloud Analyze 워크플로의 이름을 바꿉니다.

<Aside>이름을 바꾼 워크플로가 이미 존재하면 *프로젝트 \{project}에 워크플로 \{workflow}이(가) 이미 있습니다.*라는 오류가 로그에 기록되며 아무 작업도 수행되지 않습니다. 따라서 **워크플로 이름 바꾸기** 변환은 사실상 한 번만 사용할 수 있습니다.</Aside>


## 이름을 바꿀 워크플로


먼저 **프로젝트** 드롭다운 메뉴에서 이름을 바꿀 워크플로가 들어 있는 프로젝트를 선택합니다.



다음으로 **워크플로** 드롭다운 메뉴에서 이름을 바꿀 워크플로를 선택합니다.



마지막으로 **새 이름** 필드에 새 워크플로 이름을 입력합니다. 이름은 프로젝트 내에서 고유해야 합니다.
