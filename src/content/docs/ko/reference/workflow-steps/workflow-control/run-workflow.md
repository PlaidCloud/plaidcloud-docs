## 설명

현재 워크플로를 실행하는 과정에서 다른 워크플로를 트리거합니다. 하나의 프로세스가 논리적으로 다른 프로세스에 의존할 때 워크플로를 서로 연결하는 데 사용합니다. 예를 들어 "실적 로드" 워크플로를 호출한 다음 "배부 실행" 워크플로, 그다음 "대시보드 게시" 워크플로를 호출하는 "월 마감" 워크플로를 만들 수 있습니다.

호출된 워크플로는 독립적으로 실행되며, 같은 프로젝트에 있어도 되고 다른 프로젝트에 있어도 됩니다. 기본적으로 호출한 워크플로는 기다리지 않고 계속 진행합니다. 호출자의 다음 단계가 호출된 워크플로의 완료에 의존한다면 **Wait until processing completes** 옵션을 설정하십시오.



## 실행할 워크플로


먼저 **프로젝트** 드롭다운 메뉴에서 실행할 워크플로가 들어 있는 프로젝트를 선택합니다.



다음으로 **워크플로** 드롭다운 메뉴에서 실행할 워크플로를 선택합니다.



또한 **Wait until processing completes before continuing.** 옵션이 있습니다. 이 확인란을 선택하면 호출된 워크플로의 실행이 완료될 때까지 현재 워크플로의 실행이 보류됩니다. 기본적으로 이 옵션은 비활성화되어 있으며, 이 경우 이 변환이 포함된 현재 워크플로는 호출된 워크플로와 병렬로 계속 처리됩니다.
