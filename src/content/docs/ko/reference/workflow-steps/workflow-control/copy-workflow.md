## 설명


기존 PlaidCloud Analyze 워크플로의 사본을 만듭니다.



## 복사할 워크플로


먼저 **프로젝트** 드롭다운 메뉴에서 복사할 워크플로가 들어 있는 프로젝트를 선택합니다.



다음으로 **워크플로** 드롭다운 메뉴에서 복사할 특정 워크플로를 선택합니다.



다음으로 **새 워크플로** 필드에 새 워크플로 이름을 입력합니다. 이름은 프로젝트 내에서 고유해야 합니다.
