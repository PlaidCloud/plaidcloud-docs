## 설명


새 PlaidCloud Analyze 워크플로를 만듭니다.



## 만들 워크플로


먼저 드롭다운 메뉴에서 새 워크플로를 만들 프로젝트를 선택합니다.



다음으로 워크플로 이름을 입력합니다. 이름은 프로젝트 내에서 고유해야 합니다.
