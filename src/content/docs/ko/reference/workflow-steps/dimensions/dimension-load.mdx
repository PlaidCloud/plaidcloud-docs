## 설명

PlaidCloud 테이블의 데이터로 차원을 로드하거나 업데이트합니다. 초기 로드(계층을 처음부터 생성)와 증분 업데이트(처음부터 다시 만들지 않고 멤버 추가, 상위 항목 변경, 속성 업데이트)를 모두 처리합니다.

두 가지 소스 데이터 형태를 지원합니다. **상위-하위**(트리의 에지당 한 행)와 **레벨**(계층 레벨당 한 열, 행당 전체 경로 하나)입니다. 구조 데이터와 함께 값, 별칭, 속성을 로드할 수 있습니다.


## 차원 선택
### 차원을 동적으로 지정
차원을 동적으로 지정하려면 이름에 **프로젝트** 변수 또는 **로컬** 변수를 포함합니다.


차원을 주기적으로 업데이트하면서 과거 보기를 유지하려는 경우에 변수가 유용합니다.

`current_month` 변수를 사용하여 차원을 동적으로 로드하는 예:

```text
dimension_name_{current_month}
```
### 특정 차원 사용

특정 차원을 사용하려면 드롭다운 메뉴에서 **차원**을 선택합니다.


### 대체 계층에 로드

대체 계층을 로드하려면 먼저 차원을 동적으로 또는 특정하게 선택하고, 대체 계층에 로드 확인란을 선택한 다음 로드할 대체 계층의 이름을 입력합니다.

<Aside>주 차원의 대체 보기나 롤업이 있으면 유용한 경우가 많습니다. 예를 들어 코스트 센터에는 대개 회계 롤업이 있지만 조직 구조에 기반한 대체 보기가 필요할 수도 있습니다.</Aside>

주 계층에 없는 멤버는 하나의 대체 계층에만 속할 수 있습니다. 해당 멤버를 두 번째 대체 계층에도 배치하는 로드는 실패하며, 해당 멤버와 이미 그 멤버를 가지고 있는 대체 계층의 이름을 알려 줍니다. 리프를 여러 대체 계층에서 사용하려면 먼저 주 계층에 추가하십시오. 대체 계층은 주 계층 멤버 아래에 멤버를 추가할 수 없으므로, 상위 항목은 각 대체 계층에 자신의 이름이 필요합니다.

## 소스 테이블

### 동적 
소스 테이블을 동적으로 지정하려면 **동적 확인란**을 선택하고 이름에 **프로젝트** 변수 또는 **로컬** 변수를 포함한 테이블 이름을 입력합니다.

### 정적

특정 **소스 테이블**을 사용하려면 드롭다운 메뉴에서 테이블을 선택합니다.

## 차원 속성 및 테이블 레이아웃

### 기본 통합 유형

통합 유형에는 세 가지 옵션이 있습니다.
* **"+"**: 차원의 값을 집계합니다.
* **"-"**: 차원의 값을 뺍니다.
* **"~"**: 차원에서 집계를 수행하지 않습니다.

<Aside>소스 데이터 테이블에 **통합 유형**을 열로 포함하면 하나의 차원 안에서 여러 통합 유형을 사용할 수 있습니다. 그러면 아래 **열 매핑** 섹션에서 **통합 유형** 열이 사용됩니다.</Aside>

### 테이블 열 형식
차원을 로드할 때 **소스 테이블**의 형식을 지정하는 방법은 두 가지입니다. 
#### 상위-하위
상위-하위 테이블에는 차원 구조를 나타내는 **상위**와 **하위**라는 두 개의 열이 있습니다.

**상위-하위 예시**

| 상위    | 하위    | 통합 유형 |
|-----------|----------|--------------------|
|전체 상위 | 상위 1 |        ~           |
|전체 상위 | 상위 2 | ~                  |
| 상위 1  | 하위 1  | +                  |
| 상위 2  | 하위 2  | +                  |
| 하위 1   | 하위 3  | +                  |
| 하위 1   | 하위 4  | +                  |
| 하위 2   | 하위 5  | +                  |

<Aside>상위-하위 테이블 형식에도 **통합 유형** 열을 포함할 수 있습니다. **통합 유형**은 하위 항목에 연결됩니다.</Aside>

상위 항목이 비어 있는 행은 하위 항목을 루트 바로 아래의 최상위 멤버로 로드합니다. 하위 항목이 비어 있는 행은 건너뜁니다.

#### 평면화된 레벨
평면화된 레벨 테이블에는 차원의 각 레벨을 나타내는 열이 제한 없이 있습니다.

**평면화된 레벨 예시**

|레벨 1   |레벨 2 |레벨 3|레벨 4|
|----------|--------|-------|-------|
|전체 상위|상위 1|하위 1|하위 3|
|전체 상위|상위 1|하위 1|하위 4|
|전체 상위|상위 2|하위 2|하위 5|

## 열 매핑

**소스 검사** 메뉴 버튼을 사용하면 데이터 매퍼의 **소스 열**이 채워집니다.
**소스 열**이 채워지면 **종류** 드롭다운 메뉴를 사용하여 **소스 열**을 적절한 열 유형에 매핑합니다.
