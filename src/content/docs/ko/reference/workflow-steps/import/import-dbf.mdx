## 설명

**Import dBASE** 단계는 dBASE(`.dbf`) 파일을 가져옵니다(파일에 자체 스키마가 포함되어 있습니다). 이 단계는 워크플로 엔진에서 실행되며, 패키지 매크로 결과는 Alteryx 매크로의 근사치입니다.

dBASE 가져오기는 파일 전체를 메모리에 로드하지 않고 임시 저장소를 통해 스트리밍하므로, 매우 큰 파일도 메모리 부족 없이 가져올 수 있습니다. 파일의 데이터 유형(소수, 날짜, 타임스탬프)은 대상 테이블에 그대로 보존됩니다.

## 매개변수

- **소스** — `.dbf` 파일입니다.
- **대상 테이블** — 출력 테이블입니다.
- **소스 파일이 변경되지 않았으면 다시 가져오기 건너뛰기** — 소스 파일과 단계 설정이 마지막으로 성공한 실행 이후 변경되지 않았으면 워크플로 실행이 가져오기를 건너뜁니다. 기본적으로 켜져 있으며, 항상 다시 가져오려면 선택을 해제하십시오.
