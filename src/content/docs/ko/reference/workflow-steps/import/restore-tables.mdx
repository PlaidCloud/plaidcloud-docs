## 설명

[테이블 보관](/ko/reference/workflow-steps/export/archive-tables/)으로 만든 아카이브에서 프로젝트 테이블을 복원합니다. 프로젝트 또는 워크스페이스 간에 테이블 데이터를 옮기거나, 보관해 둔 사본으로 롤백할 때 사용합니다.

## 고유 구성 항목

### 소스

문서 계정에 있는 아카이브 파일입니다. 선택기는 정확한 경로 대신 검색 일치(정확히 일치, 시작 문자열, 끝 문자열, 포함, 글로브)도 지원합니다.

### 덮어쓰기

기본적으로 꺼져 있습니다. 꺼져 있으면 프로젝트에 이미 있는 테이블은 그대로 둡니다. 켜면 기존 테이블을 아카이브된 사본으로 바꿉니다.
