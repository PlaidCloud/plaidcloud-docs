## 설명

PlaidCloud Document에서 Apache Parquet 파일을 가져옵니다. Parquet는 Hadoop 생태계와 클라우드 데이터 플랫폼에서 널리 사용되는 열 기반 저장 형식으로, 대용량 데이터 세트에 대해 효율적인 압축과 인코딩을 제공합니다.

Parquet 가져오기는 파일 전체를 메모리에 로드하지 않고 임시 저장소를 통해 스트리밍하므로, 매우 큰 파일도 메모리 부족 없이 가져올 수 있습니다. 파일의 데이터 유형(소수, 날짜, 타임스탬프)은 대상 테이블에 그대로 보존되며, 타임스탬프 열은 날짜와 시각의 전체 정밀도를 유지합니다.
