## 설명

PlaidCloud Document의 Microsoft Excel 파일에서 특정 워크시트를 가져옵니다. Analyze는 레거시 Excel 형식(XP/2003)과 새 형식(2007/2010/2013)을 모두 지원합니다. 지원하는 파일 형식은 다음을 포함하며 이에 국한되지 않습니다.

* XLS
* XLSX
* XLSB
* XLSM

바이너리 통합 문서(XLSB), 레거시 XLS, ODS 파일도 XLSX와 같은 방식으로 워크시트와 셀 범위를 가져옵니다.

Excel 가져오기는 통합 문서 전체를 메모리에 로드하지 않고 임시 저장소를 통해 스트리밍하므로, 매우 큰 파일도 메모리 부족 없이 가져올 수 있습니다. 소스 데이터 유형(소수, 날짜, 타임스탬프)은 텍스트를 거치지 않고 대상 테이블에 그대로 보존됩니다.

### 헤더

Excel 파일에는 헤더가 있을 수도 있고 없을 수도 있으므로, PlaidCloud는 헤더를 사용하거나, 헤더를 무시하거나, 열 순서로 열 정렬을 결정하는 방법을 제공합니다.
* **헤더 없음**: 파일에 헤더가 없습니다.  *데이터 매퍼*의 소스 목록을 사용하여 열 정렬을 결정합니다.
* **헤더 있음 - 헤더를 사용하고 필드 목록 재정의**: 파일에 헤더가 있습니다.  지정된 헤더 이름을 사용하고 *데이터 매퍼*의 소스 목록은 무시합니다.
* **헤더 있음 - 헤더를 건너뛰고 대신 필드 목록 사용**: 파일에 헤더가 있지만 무시해야 합니다.  *데이터 매퍼*의 소스 목록에 지정된 헤더 이름을 사용합니다.

헤더 셀의 앞뒤 공백과 줄 바꿈은 열 이름에서 제거됩니다.

### 행 선택

불필요한 레코드가 있는 입력 파일의 경우, 데이터를 처리하기 전에 건너뛸 행 수를 지정할 수 있습니다.  파일에 표 형식 데이터에 도달하기 전에 건너뛰어야 하는 헤더 블록이 있을 때 유용합니다.

**Keep Empty Text Cells As Empty String**을 선택하면 비어 있는 텍스트 셀을 NULL 대신 빈 문자열로 로드합니다.

**추가 Excel 옵션**에는 다음 필드가 있습니다.

* **워크시트가 숨긴 행 제외**(`skip_hidden_rows`) — 워크시트가 숨긴 행은 가져오지 않습니다.
* **수식 오류 셀을 빈 값이 아닌 오류 텍스트(#DIV/0!)로 가져오기**(`keep_error_cells`) — 수식 오류 셀을 빈 값 대신 `#DIV/0!` 같은 오류 텍스트로 가져옵니다.
* **유효 자릿수**(`significant_digits`) — 각 소수를 이 유효 자릿수로 반올림합니다. Excel은 15자리를 유지합니다.
* **워크시트 위치**(`sheet_index`) — 이름으로 선택한 워크시트 대신, 통합 문서에서 0부터 시작하는 이 위치의 워크시트를 가져옵니다.

**가져올 워크시트**에서 **데이터가 있는 첫 번째 시트 가져오기**(`sheet_first_with_data`)를 선택하면 데이터가 있는 첫 번째 워크시트를 가져오며, 그 앞의 빈 워크시트는 건너뜁니다. 데이터가 있는 워크시트가 없으면 통합 문서의 첫 번째 워크시트를 읽습니다.

### 통합 문서

**통합 문서 암호 변수**는 암호로 보호된 통합 문서를 엽니다. 암호 자체가 아니라 암호를 담고 있는 워크플로 또는 프로젝트 변수를 `{xlsx_password}`와 같이 입력하십시오. 암호 필드에 변수 참조가 아닌 값이 들어 있는 단계는 저장할 때 거부되므로, 암호가 단계, 단계의 버전, 단계의 복사본에 나타나지 않습니다. 이 규칙이 생기기 전에 암호를 직접 입력해 둔 단계는 암호가 새 프로젝트 변수로 자동으로 옮겨졌으며, 이 변수는 아키텍트에게만 표시되고 단계는 이제 해당 변수를 참조합니다.

### 읽을 대상

가져오기의 각 항목은 워크시트, 통합 문서에서 정의한 이름이 지정된 범위, 특정 셀 범위 중 하나를 선택합니다. 세 가지는 대등하며, 가져오기 하나에서 여러 항목에 걸쳐 섞어 쓸 수 있습니다.

* **워크시트**: 이름으로 선택한 시트 전체를 읽습니다.
* **이름이 지정된 범위**: 통합 문서 자체가 이름을 정의한 범위를 읽습니다. 이름이 지정된 범위는 선택기에서 워크시트와 함께 나열되므로(아래 *선택한 파일에서 시트 찾기* 참조) 시트를 선택하는 것과 같은 방식으로 선택합니다.
* **셀 범위**: 워크시트나 통합 문서 이름으로 뒷받침되지 않는 특정 직사각형 범위를 읽습니다. 범위가 있는 시트를 선택한 다음 `$` 뒤에 범위를 입력합니다. 세 가지 형식을 지원합니다.
  * `Sheet1$A1:J100` — 경계가 있는 범위입니다.
  * `Sheet1$A1:J` — 끝이 열려 있는 범위입니다. `A1`부터 A~J 열의 마지막 행까지 읽습니다.
  * `Sheet1$A:BJ` — 전체 열입니다. 시트의 A~BJ 열을 읽으며, Alteryx가 Excel 입력에 기록하는 형식입니다.

이름이 지정된 범위는 XLSX 및 XLSM 통합 문서에서 읽습니다. XLSB, XLS, ODS 통합 문서는 워크시트와 셀 범위를 제공합니다.

<Aside type="caution">서로 분리된 영역을 둘 이상 가리키는 이름이 지정된 범위, 또는 시트 경계를 벗어나거나 뒤집힌 셀 범위(예: 끝 셀이 시작 셀보다 위쪽이나 왼쪽에 있는 경우)는 가져오지 않고 오류와 함께 거부되므로, 가져오기가 엉뚱한 셀을 조용히 읽는 일이 없습니다.</Aside>

#### 가져올 워크시트

통합 문서에는 서로 다른 데이터가 담긴 워크시트가 많을 수 있으므로, 현재 가져오기 프로세스에서 가져올 워크시트를 선택할 수 있습니다.  옵션은 다음과 같습니다.

* 모든 워크시트
* 검색과 일치하는 워크시트
* 선택한 워크시트

#### 워크시트 검색 사용

워크시트 검색 기능을 사용하면 검색 조건과 일치하는 워크시트를 포함할 수 있습니다.  검색 조건은 다음을 지원합니다.
* **시작 문자열**: 워크시트 이름이 검색 텍스트로 시작합니다.
* **포함**: 워크시트 이름에 검색 텍스트가 포함됩니다.
* **끝 문자열**: 워크시트 이름이 검색 텍스트로 끝납니다.

#### 선택한 파일에서 시트 찾기

시트 찾기 버튼은 Excel 파일을 열어 테이블에서 사용할 수 있는 워크시트와 이름이 지정된 범위를 나열합니다.  가져오기에 포함할 워크시트 및/또는 이름이 지정된 범위의 확인란을 테이블에서 선택하십시오. `.zip` 파일 안의 통합 문서도 사용할 수 있으며, 해당 워크시트와 이름이 지정된 범위가 나열됩니다.

<Aside>*데이터 매퍼*를 채울 때는 목록에서 처음 발견된 워크시트, 이름이 지정된 범위 또는 셀 범위를 사용합니다. 가져오기 단계에 포함된 모든 항목의 형식이 비슷한지 확인하십시오.</Aside>

#### 시트 매핑

**시트 매핑**은 통합 문서마다 서로 다른 워크시트 집합을 읽습니다. 읽을 워크시트마다 한 행씩 있는 **시트 매핑 테이블**을 선택하고, **통합 문서 열**에는 통합 문서의 경로 또는 파일 이름을, **시트 열**에는 워크시트를 담습니다. 시트 매핑을 설정하면 테이블에 이름이 있는 통합 문서만 읽으며, 각 통합 문서에서 나열된 워크시트를 테이블의 행 순서대로 읽습니다. 워크시트가 비어 있으면 통합 문서의 첫 번째 워크시트를 읽습니다.

#### 선택한 워크시트가 없는 파일

가져오기에서 여러 파일을 읽을 때, 선택한 워크시트가 없거나 워크시트 검색과 일치하는 워크시트가 없는 파일은 건너뜁니다. 단계는 건너뛴 파일의 이름과 해당 파일에 있는 워크시트 목록을 담은 경고와 함께 완료되며, 다른 파일은 계속 가져옵니다. 모든 파일을 건너뛰어도 단계는 성공하며, 대상 테이블은 비어 있고 그 이유를 설명하는 경고가 표시됩니다. 워크시트 이름은 대소문자를 포함해 정확히 일치해야 합니다.

건너뛴 파일은 *가져온 후 파일 삭제*를 켜 두어도 폴더에 남아 있으며, 파일을 제거하거나 수정할 때까지 실행할 때마다 다시 경고합니다. 여러 파일 가져오기의 경고는 단계에 표시되며, 최대 다섯 개까지 나열되고 나머지는 개수로 표시됩니다.

<Aside>여러 워크시트를 가져올 때 비어 있는 워크시트는 해당 워크시트에서 행을 0개 로드하며, 가져오기가 실패하지는 않습니다.</Aside>

### 하나의 소스 열을 여러 대상 열에 사용

하나의 소스 열이 둘 이상의 대상 열에 값을 공급할 수 있습니다. 같은 소스 열을 둘 이상의 대상 행에 매핑하고, 각각 고유한 이름, 유형 또는 식을 지정하십시오. 예를 들어 `Amount`를 텍스트 열로 한 번, 숫자 열로 한 번 읽거나, 같은 셀에서 텍스트 열 두 개를 만들 수 있습니다. 숫자 대상은 더 이상 식이 실행되기 전에 소스를 변환하지 않으므로, 식에서 `1,500` 같은 값을 먼저 정리할 수 있습니다.

데이터 매퍼를 사용하는 CSV 가져오기 외의 모든 파일 가져오기, 즉 Excel 가져오기, 고정 너비, JSON, Avro, Parquet, DBF, XML, YXDB에서 동일하게 동작합니다.
