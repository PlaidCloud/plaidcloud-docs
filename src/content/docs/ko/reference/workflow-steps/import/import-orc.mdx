## 설명

PlaidCloud Document에서 Apache ORC 파일을 가져옵니다. ORC는 Hive와 Spark가 기록하는 열 기반 저장 형식이며, 스키마가 파일에 포함되어 있습니다.

단계 양식에는 세 개의 탭이 있습니다.

- **가져오기 매개변수** — **소스 파일**(문서 계정과 파일 또는 폴더 경로)과 **대상 테이블**을 지정하며, **ASCII가 아닌 문자 제거**(`ascii_only`), **가져온 후 파일 삭제**(`delete_file`), **소스 파일이 변경되지 않았으면 다시 가져오기 건너뛰기**(`skip_if_unchanged`) 옵션이 있습니다.
- **테이블 데이터 선택** — 소스 열을 대상 열에 매핑하며, **요약**과 **고유** 옵션이 있습니다. **채우기**는 ORC 파일에 포함된 스키마에서 열과 해당 유형을 읽습니다.
- **데이터 필터** — 요약 전후에 행을 필터링합니다.

파일이 없거나 비어 있으면 **채우기**는 경로를 명시한 경고와 함께 *채울 항목이 없습니다*라고 응답하고 기존 매핑을 유지합니다.

[마이그레이션된 Prophecy 프로젝트](/ko/guides/workflows/migrate-prophecy-projects/)는 ORC 데이터 세트에 이 단계를 사용합니다.
