## 설명


외부 데이터베이스(데이터베이스 커넥터로 구성)의 테이블을 하나 이상 프로젝트 테이블로 가져옵니다. **델타 로드**(마지막 가져오기 이후 변경된 행만 가져오기)와 **테이블 이름 재매핑**(소스 테이블을 PlaidCloud에서 다른 이름으로 저장하기)을 지원합니다.

매번 모든 행을 다시 가져오지 않고, 일정에 따라 PlaidCloud 테이블을 운영 소스 시스템과 동기화된 상태로 유지할 때 사용합니다.

<Aside title="소스 검사는 외부 데이터베이스를 읽습니다">
이 단계에 추가한 테이블의 경우, **소스 검사** 버튼은 연결된 데이터베이스에서 해당 테이블의 현재 열을 직접 읽어 그 테이블의 매핑만 제자리에서 새로 고칩니다. 단계를 설정한 이후 소스 테이블의 열이 변경되었을 때, 연결 전체에 대해 검색을 다시 실행하지 않고 사용합니다.
</Aside>

<Aside title="PostgreSQL 열 유형">
PostgreSQL 소스에서 `uuid` 열은 텍스트로, `json`/`jsonb` 열은 JSON 텍스트 표현으로 가져옵니다.
</Aside>

<Aside title="숫자 열은 정확한 소수로 가져옵니다">
소스의 `numeric`/`decimal` 열은 정확한 소수 값으로 가져오며, 소수점 왼쪽 최대 28자리와 오른쪽 최대 10자리를 유지합니다. 소수 자릿수가 10자리를 넘는 값은 맞도록 반올림되며, 정수 자릿수가 28자리를 넘는 값은 열 이름을 명시하며 가져오기를 중지합니다.
</Aside>

<Aside type="caution" title="열에 맞지 않는 값은 가져오기를 중지합니다">
소스 값이 데이터 손실 없이 대상 열에 들어갈 수 없는 경우, 예를 들어 정수 열에 소수가 들어가거나, 열에 비해 숫자가 너무 크거나, 숫자 열에 `NaN`/`Infinity`가 들어가는 경우에는, 값을 조용히 자르거나 반올림하지 않고 열 이름과 데이터 유형을 명시한 오류와 함께 가져오기를 중지합니다. 단계의 데이터 매퍼에서 해당 열의 **유형**을 값을 담을 수 있는 유형으로 설정한 다음 가져오기를 다시 실행하십시오.
</Aside>
