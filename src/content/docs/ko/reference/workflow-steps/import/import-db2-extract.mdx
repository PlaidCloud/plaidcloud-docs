## 설명

PlaidCloud Document 저장소에서 IBM DB2 추출 파일을 가져옵니다. DB2 서버에 온프레미스 인프라에서만 접근할 수 있는 경우에 유용합니다. 외부 프로세스가 추출 파일을 PlaidCloud Document 저장소로 푸시하면, 이 단계가 그곳에서 파일을 읽어 프로젝트 테이블에 저장합니다.

추출 파일 없이 DB2에 실시간으로 접근하려면 표준 [IBM DB2](../../../connectors/databases/ibm-db2/) 연결로 연결하고 [외부 데이터베이스 테이블 가져오기](../import-external-database-tables/)를 사용하십시오.
