## 설명



구분 기호가 아니라 문자 위치로 열을 정의하는 텍스트 파일을 가져옵니다. 전형적인 메인프레임 / COBOL 출력 형식입니다. 필드마다 열 경계(시작 위치, 길이)를 구성합니다.

레거시 ERP 내보내기, 정부 제출 서류, 구분 기호 구문 분석이 아니라 고정 열 표시를 위해 데이터를 배치한 은행 명세서 형식에서 흔히 사용합니다.

고정 너비 가져오기는 파일 전체를 메모리에 로드하지 않고 임시 저장소를 통해 스트리밍하므로, 매우 큰 파일도 메모리 부족 없이 가져올 수 있습니다.

### 헤더

Excel 파일에는 헤더가 있을 수도 있고 없을 수도 있으므로, PlaidCloud는 헤더를 사용하거나, 헤더를 무시하거나, 열 순서로 열 정렬을 결정하는 방법을 제공합니다.
* **헤더 없음**: 파일에 헤더가 없습니다.  *데이터 매퍼*의 소스 목록을 사용하여 열 정렬을 결정합니다.
* **헤더 있음 - 헤더를 사용하고 필드 목록 재정의**: 파일에 헤더가 있습니다.  지정된 헤더 이름을 사용하고 *데이터 매퍼*의 소스 목록은 무시합니다.
* **헤더 있음 - 헤더를 건너뛰고 대신 필드 목록 사용**: 파일에 헤더가 있지만 무시해야 합니다.  *데이터 매퍼*의 소스 목록에 지정된 헤더 이름을 사용합니다.

### 행 선택

불필요한 레코드가 있는 입력 파일의 경우, 데이터를 처리하기 전에 건너뛸 행 수를 지정할 수 있습니다.  파일에 표 형식 데이터에 도달하기 전에 건너뛰어야 하는 헤더 블록이 있을 때 유용합니다.

### 열 너비

열 너비를 쉼표 또는 공백으로 구분하여 입력합니다.

### 레이아웃

| 설정 | 기능 |
| --- | --- |
| 인코딩 | 파일의 문자 집합입니다. **UTF-8**(기본값), **EBCDIC(미국, cp037)**, **EBCDIC(국제, cp500)**, **라틴-1(Latin-1)** 중에서 선택합니다. 메인프레임 파일에는 EBCDIC 코드 페이지를 선택하십시오. |
| 건너뛸 레코드 수 | 헤더 또는 데이터 앞에서 파일 시작 부분의 몇 개 레코드를 건너뛸지 지정합니다. |
| 끝에서 제외할 레코드 수 | 트레일러 레코드와 같이 파일 끝에서 몇 개 레코드를 제외할지 지정합니다. |
| 한 줄에 레코드 하나 | 켜져 있으면(기본값) 각 줄이 하나의 레코드입니다. 줄 바꿈 없이 레코드가 끝에서 끝으로 이어진 파일에는 선택을 해제하십시오. 이 경우 각 레코드의 길이는 열 너비의 합과 같습니다. |
| 레코드 사이 문자 수 | 레코드가 한 줄에 하나가 아닐 때, 구분 문자와 같이 각 레코드 뒤에서 건너뛸 문자 수입니다. |
| 공백 제거 | 각 값에서 제거할 공백입니다. **앞뒤 모두**(기본값), **뒤쪽만**, **없음** 중에서 선택합니다. |
