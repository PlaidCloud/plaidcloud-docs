## 설명

PlaidCloud 문서에서 구분 기호로 구분된 텍스트 파일을 가져옵니다. 다음과 같은 구분 기호 유형을 지원하며, 이에 국한되지 않습니다.
* 쉼표(, )
* 파이프(|)
* 세미콜론(; )
* 탭
* 공백( )
* 앳 기호(@)
* 물결표(~)
* 콜론(:)

### 선택한 소스 파일 검사

*소스 파일에서 설정 추측* 버튼을 누르면 PlaidCloud가 파일을 열어 검사하고 데이터 형식을 판단하려고 시도합니다. 추측된 설정이 올바른지 항상 확인하십시오.

<Aside>파일 디렉터리를 가져오도록 선택했거나 검색을 사용하는 경우, 처음 발견된 파일을 추측에 사용합니다</Aside>

파일에서 열을 찾을 수 없는 단계는 저장할 수 없으며, 저장이 **감지된 열 없음** 메시지와 함께 중지됩니다. PlaidCloud가 파일을 읽을 수 없었던 경우 메시지에 그 이유가 표시됩니다. 예를 들어 구분 기호로 구분된 파일에 일반적이지 않은 확장명이거나, 정의되지 않은 워크플로 변수를 사용하는 파일 경로일 수 있습니다. 그렇지 않은 경우 구분 기호, 따옴표 문자, 이스케이프 문자가 파일과 일치하는지, 구분 기호로 구분된 텍스트 파일인지, 비어 있지 않은지 확인하십시오.

### 데이터 형식

#### 구분 기호
위에서 설명한 것처럼 **소스 검사**는 소스 파일의 구분 기호를 판단하려고 시도합니다. 다른 구분 기호를 사용하려면 이 섹션에서 구분 기호를 지정하십시오. 사용자는 표준 구분 기호 목록에서 선택할 수 있습니다. 구분 기호를 설정하지 않은 단계는 쉼표를 사용합니다.
* 쉼표(, )
* 파이프(|)
* 세미콜론(; )
* 탭
* 공백( )
* 앳 기호(@)
* 물결표(~)
* 콜론(:)

#### 헤더 유형

CSV에는 헤더가 있을 수도 있고 없을 수도 있으므로, PlaidCloud는 헤더를 사용하거나, 헤더를 무시하거나, 열 순서를 사용하여 열 정렬을 결정하는 방법을 제공합니다.
* **헤더 없음**: CSV 파일에 헤더가 없습니다. *데이터 매퍼*의 소스 목록을 사용하여 열 정렬을 결정합니다.
* **헤더 있음 - 헤더를 사용하고 필드 목록 재정의**: CSV 파일에 헤더가 있습니다. 지정된 헤더 이름을 사용하고 *데이터 매퍼*의 소스 목록은 무시합니다.
* **헤더 있음 - 헤더를 건너뛰고 대신 필드 목록 사용**: CSV 파일에 헤더가 있지만 무시해야 합니다. *데이터 매퍼*의 소스 목록에 지정된 헤더 이름을 사용합니다.

**헤더 유형**은 두 헤더 옵션에 대해 `header_treatment`에 `use` 또는 `skip`으로 저장됩니다. Excel 가져오기에서는 `dynamic`도 허용됩니다.

#### 날짜 형식

이 설정은 CSV 파일의 날짜가 날짜와 시간으로 쉽게 인식되지 않을 때 유용합니다. 가져오기 프로세스는 날짜 변환을 시도하지만, 약간의 추가 정보가 있으면 가져오기에 도움이 됩니다.

웨어하우스가 주어진 형식에 따라 읽을 수 없는 값은 가져오기를 중지하지 않고 빈 값으로 저장됩니다. 따라서 파일과 일치하지 않는 형식을 지정하면 빈 날짜 열이 만들어지고 가져오기는 여전히 성공으로 보고됩니다. 이 설정을 변경한 후에는 결과를 사용하기 전에 가져온 열을 확인하십시오.

<Aside type="caution" title="Lakehouse v2의 시간 열">
데이터 형식이 **시간**인 열은 지정한 날짜 형식과 관계없이 Lakehouse v2에서 빈 값으로 가져와집니다. 이를 구문 분석하는 데 사용하는 웨어하우스 함수는 시각만 있는 값을 생성할 수 없습니다. 해당 열을 **타임스탬프**로 가져와서 거기에서 시간을 읽거나 **텍스트**로 가져오십시오. **날짜** 및 **타임스탬프** 열은 영향을 받지 않습니다.
</Aside>

### 특수 문자

특수 문자 입력은 PlaidCloud가 특정 문자의 존재를 처리하는 방식과 CSV 처리 과정에서 그 문자가 의미하는 바를 제어합니다.
 * **따옴표 문자**: 하나의 필드로 처리해야 하는 텍스트 묶음을 나타내는 데 사용하는 문자입니다. 설정하지 않으면 큰따옴표(`"`)입니다.
 * **이스케이프 문자**: 다음 문자를 특수 문자로 해석하지 않고 있는 그대로 처리해야 함을 나타내는 데 사용하는 문자입니다. 필드에 구분 기호가 포함될 수 있을 때 유용합니다. 설정하지 않으면 백슬래시(`\`)입니다.
 * **Null 문자**: CSV에는 데이터 형식이 없으므로, 이 문자는 값을 빈 문자열이나 0이 아니라 NULL로 처리해야 함을 나타내는 방법을 제공합니다.
 * **빈 필드**: 빈 필드는 모든 레이크하우스에서 텍스트 열과 숫자 열 모두 NULL로 로드되므로, 비어 있는 숫자는 0이 아니라 NULL이 됩니다. 공백만 있는 셀은 있는 그대로 로드됩니다.
 * **후행 음수**: 일부 소스 시스템은 음수를 앞에 붙이지 않고 뒤에 음수 기호를 붙여 생성합니다. 이 설정은 이러한 값을 음수로 처리합니다.

### 행 선택

불필요한 레코드가 있는 입력 파일의 경우, 데이터를 처리하기 전에 건너뛸 줄 수를 **건너뛸 행**에 설정하십시오. 표 형식 데이터에 도달하기 전에 건너뛰어야 하는 헤더 블록이 파일에 있을 때 유용합니다.

건너뛰는 줄에는 빈 줄이 포함됩니다. **헤더 유형**이 **헤더 있음 - 헤더를 사용하고 필드 목록 재정의**이면 건너뛴 줄 다음의 첫 번째 줄에서 헤더를 읽으므로, 데이터가 헤더 이름을 기준으로 대상 열에 매핑됩니다. 건너뛴 줄과 헤더만 있고 데이터 행이 없는 파일은 아무것도 가져오지 않으며 단계는 그대로 완료됩니다.

#### 예제: SAP 목록 내보내기

KE24, KSB1, FAGLL03과 같은 SAP 목록 내보내기는 열 헤더 앞에, 빈 줄이 포함되는 경우가 많은 선택 블록으로 시작합니다.

```text
Line Item Journal Entries
Company Code: 1000
Posting Date: 2026-09-01 to 2026-09-30

Company Code|Document Number|Posting Date|Amount
1000|100004512|2026-09-03|1,500.00
```

헤더는 5번째 줄에 있으므로 그 앞에 네 줄이 있습니다. **건너뛸 행**을 `4`로, **헤더 유형**을 **헤더 있음 - 헤더를 사용하고 필드 목록 재정의**로 설정하십시오. 가져오기는 `Company Code`, `Document Number`, `Posting Date`, `Amount`를 열 이름으로 읽으며, 첫 번째 데이터 행은 헤더 다음 줄입니다.

따옴표로 묶인 빈 필드를 NULL 대신 빈 문자열로 로드하려면 **Keep Quoted Empty Fields ("") As Empty String**을 선택하십시오.

### 추가 설정

**추가 CSV 옵션**에는 다음 필드가 있습니다.

* **인코딩**(`encoding`) — 파일을 감지하는 대신 파일을 읽는 데 사용하는 Python 코덱입니다. 디코딩되지 않는 바이트는 U+FFFD로 읽힙니다.
* **구분 기호**(`delimiters`) — 단일 구분 기호 대신 열을 구분하는 모든 텍스트의 JSON 배열입니다. 각 항목은 여러 문자일 수 있습니다. 연속된 여러 구분 기호를 하나로 취급하려면 **연속된 구분 기호를 하나로 취급**(`combine_delimiters`)을 선택하십시오.
* **행 구분 기호**(`row_delimiter`) — 따옴표 밖에 있을 때 행을 끝내는 텍스트이며, 그 외의 위치에 있는 줄 바꿈은 값의 일부가 됩니다. 비워 두면 모든 줄 바꿈이 행을 끝냅니다.
* **주석 줄 접두사**(`comment`) — 이 텍스트로 시작하는 줄은 가져오지 않습니다. **댓글**(`comments`)은 **시작 문자**와 **끝 문자열** 쌍으로 주석을 나열하며, 따옴표 밖에 있는 주석은 어디에 있든 잘라냅니다. **끝 문자열**이 없으면 주석은 줄 끝까지 이어집니다.
* **줄 연결**(`line_continuation`) — 줄 바꿈 앞에 이 텍스트가 있으면 해당 줄을 다음 줄과 연결합니다.
* **닫는 따옴표**(`quote_end`) — **따옴표 문자**와 다를 때 따옴표로 묶인 값을 끝내는 따옴표입니다. 따옴표로 묶인 값의 따옴표 문자를 유지하려면 **따옴표로 묶인 값은 따옴표를 유지합니다**(`keep_quotes`)를 선택하십시오.
* **빈 줄을 빈 값의 행으로 가져오기**(`keep_blank_lines`) — 빈 줄을 제외하지 않고 빈 값의 행으로 가져옵니다.
