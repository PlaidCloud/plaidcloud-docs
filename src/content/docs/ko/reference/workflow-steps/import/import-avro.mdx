## 설명

PlaidCloud Document에서 Apache Avro 파일을 가져옵니다. Avro는 Apache Hadoop 프로젝트의 행 기반 데이터 직렬화 형식으로, 데이터를 스키마와 함께 저장하므로 데이터 파이프라인과 스트리밍 시스템에서 사용하기에 적합합니다.

## 고유 구성 항목

### 파일 수정 시간

특정 시간 범위 내에 변경된 파일만 읽습니다. **이후 수정됨**은 입력한 시간 이후에 마지막으로 수정된 파일만 읽고, **이전 수정됨**은 입력한 시간 이전에 마지막으로 수정된 파일만 읽습니다. 둘 중 하나 또는 둘 다 설정할 수 있습니다. 시간은 `YYYY-MM-DDTHH:MM:SS` 형식으로 입력하며, 예를 들면 `2026-10-01T00:00:00`입니다. 시간대를 지정하지 않으면 UTC로 간주하며, 시간대는 `2026-10-01T00:00:00-05:00`처럼 지정합니다. 시간에는 워크플로 변수를 넣을 수 있으며, 이 값은 단계가 실행될 때 읽습니다.
