## 설명


PlaidCloud 고유 아카이브 파일을 프로젝트 테이블로 다시 가져옵니다. 아카이브 형식은 CSV로 왕복하면 유지되지 않는 열 유형, 메타데이터, 인덱스를 보존합니다.

[Export to Table Archive 단계](/ko/reference/workflow-steps/export/export-to-table-archive/)로 생성됩니다. 프로젝트 백업, 워크스페이스 또는 환경 간 마이그레이션, 유형이 지정된 데이터의 안정적인 전송에 사용됩니다.
