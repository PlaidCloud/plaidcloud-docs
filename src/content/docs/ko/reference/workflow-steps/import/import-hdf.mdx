## 설명


HDF5(Hierarchical Data Format version 5) 파일을 PlaidCloud 프로젝트 테이블로 가져옵니다. HDF5는 과학 컴퓨팅, 머신러닝 데이터 교환, 그리고 유형이 지정된 열 기반 데이터를 Python/R/MATLAB 도구 간에 왕복해야 하는 모든 환경에서 흔히 사용됩니다.

형식 사양은 [HDF Group 문서](http://www.hdfgroup.org/HDF5/)를 참조하십시오.

## 고유 구성 항목


### 키 이름

HDF 파일은 경로 구조로 데이터를 저장합니다. HDF 파일 안에서 테이블의 대상 위치로 사용할 키(경로)가 필요합니다. 대부분의 경우 *table*입니다.
