## 설명



SPSS 데이터 파일(.sav 및 .zsav 형식)을 PlaidCloud 프로젝트 테이블로 가져옵니다. 설문 조사 데이터, 사회과학 연구 데이터, 또는 SPSS 기반 도구와 상호 운용되는 모든 파이프라인에 유용합니다.

변수 레이블과 값 레이블은 형식이 지원하는 경우 보존됩니다.
