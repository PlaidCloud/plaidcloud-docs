## 설명


XML 파일의 표 형식 데이터를 PlaidCloud 프로젝트 테이블로 가져옵니다. 각 '행'을 식별하는 요소 경로를 구성하고, 자식 요소 또는 속성을 테이블 열에 매핑합니다.

오래된 기업 통합, B2B 데이터 교환(RosettaNet, ebXML), 정부 제출 형식에서 흔히 사용합니다.


## 레코드 읽기 방식

**레코드 읽기 방식**은 파일을 테이블로 만드는 방법을 선택합니다.

* **레코드 태그당 테이블 1개**(기본값) — **레코드 태그** 탭에 읽을 각 태그가 나열되며, 각 태그는 **대상 테이블 접두사**에서 이름을 딴 자체 테이블로 로드됩니다.
* **요소당 1행** — 반복되는 요소 하나가 테이블 하나로 로드되며, 요소가 나타날 때마다 한 행이 됩니다. **레코드 태그** 탭과 **대상 테이블 접두사**는 비활성화됩니다.

**요소당 1행**에서는 다음을 설정합니다.

* **XML 요소** — 행을 만드는 요소입니다. 비워 두면 첫 번째 열의 요소가 되며 필드에 표시됩니다.
* **대상 테이블** — 로드할 테이블입니다.
* **열** — 각 **자식 요소 또는 속성**과 그것이 로드될 **열**입니다. 모든 열은 텍스트로 가져옵니다.
* **값 앞뒤 공백 제거** — 각 값의 앞뒤 공백을 제거합니다.
* **이름을 네임스페이스 접두사와 함께 일치** — 요소와 속성 이름을 접두사를 포함하여 파일에 쓰인 그대로 일치시킵니다.

소스 파일, 대상 테이블, 그리고 XML 요소 또는 하나 이상의 열이 필요합니다. 모드를 전환하면 다른 모드의 설정이 양식에 유지되어 다시 전환할 때 복원되지만, 저장하면 전환해 나온 모드의 설정은 제거됩니다. 컨트롤 옆의 안내에 이 내용이 표시됩니다.

양식에서 저장한 단계는 **레코드 태그** 탭에 설정된 대로 레코드 태그를 읽습니다.
