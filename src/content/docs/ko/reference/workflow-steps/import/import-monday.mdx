## 설명

monday.com 연결을 통해 하나 이상의 [monday.com](https://monday.com/) 보드의 항목을 프로젝트 테이블로 가져옵니다. 프로젝트 추적, 접수 대기열, 운영 작업 데이터를 재무 데이터와 함께 워크플로로 가져올 때 사용합니다.

## 고유 구성 항목

### 연결 구성

데이터를 읽을 monday.com 연결입니다.

### 대상 테이블

보드마다 한 행입니다. 읽을 **보드 ID**와 이를 기록할 프로젝트 테이블을 지정합니다. 하나의 단계에서 여러 보드를 한꺼번에 가져올 수 있습니다. 각 대상은 뷰가 아니라 테이블이어야 합니다.
