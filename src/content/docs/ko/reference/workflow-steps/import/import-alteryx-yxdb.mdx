## 설명

PlaidCloud Document에서 Alteryx YXDB 파일을 가져옵니다. YXDB는 Alteryx Designer가 필드 메타데이터와 함께 데이터 세트를 저장하는 데 사용하는 고유 바이너리 파일 형식입니다.

YXDB 가져오기는 파일 전체를 메모리에 로드하지 않고 임시 저장소를 통해 스트리밍하므로, 매우 큰 파일도 메모리 부족 없이 가져올 수 있습니다. 파일의 데이터 유형(소수, 날짜, 타임스탬프)은 대상 테이블에 그대로 보존됩니다.

구성된 `.yxdb` 파일이 없지만 같은 폴더에 이름이 같은 `.parquet` 파일이 있으면, 이 단계는 대신 `.parquet` 파일을 읽고 그 사실을 알리는 경고를 표시합니다. 변환된 Alteryx 워크플로는 `.yxdb` 출력을 이름이 같은 `.parquet` 파일로 기록하므로, 해당 `.yxdb` 파일 중 하나를 읽는 단계는 데이터를 자동으로 가져옵니다. 파일을 검색하는 가져오기에서는 이 대체 동작을 사용하지 않습니다.
