## 설명


Google BigQuery의 데이터를 PlaidCloud 프로젝트 테이블로 가져옵니다. BigQuery를 기본 분석 웨어하우스로 사용하며 특정 데이터 세트를 PlaidCloud로 가져와 추가 모델링이나 배부 작업에 활용하는 조직에 유용합니다.

인증에는 Google Cloud 서비스 계정을 사용하며, 소스 데이터 세트와 테이블은 단계 수준에서 구성합니다.
