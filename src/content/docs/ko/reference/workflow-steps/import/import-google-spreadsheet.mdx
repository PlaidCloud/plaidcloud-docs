## 설명


Google 스프레드시트의 특정 워크시트를 PlaidCloud 프로젝트 테이블로 가져옵니다. 비즈니스 사용자가 관리하는 드라이버 테이블, 조회 매핑, 수동 재정의처럼 스프레드시트에 있는 임시 데이터에 유용합니다.

Google 연결을 통해 인증하며, 하나의 스프레드시트에 있는 여러 워크시트를 한 단계에서 가져올 수 있습니다.

### 소스 및 대상
#### Google 계정

Google 스프레드시트 데이터에 접근하려면 유효한 Google 사용자 계정이 필요합니다. 이 계정은 도구에서 설정해야 합니다. Google 계정 연결 설정에 대한 자세한 내용은 [PlaidCloud 도구 – 연결](/ko/reference/connectors/)을 참조하십시오.

필요한 계정을 모두 설정한 후 드롭다운 목록에서 해당 **Google 계정**을 선택합니다.
#### 스프레드시트

그런 다음 지정한 **Google 계정**과 연결된 사용 가능한 모든 파일이 들어 있는 드롭다운 메뉴에서 가져올 **스프레드시트**를 지정합니다.

<Aside>제공한 사용자 계정이 지정한 파일에 접근할 수 있는지 확인하십시오. 특히 파일을 다른 사용자가 소유한 경우에 중요합니다.</Aside>

### 헤더 유형

Google 스프레드시트에는 헤더가 있을 수도 있고 없을 수도 있으므로, PlaidCloud는 헤더를 사용하거나, 헤더를 무시하거나, 열 순서로 열 정렬을 결정하는 방법을 제공합니다.
* **헤더 없음**: 파일에 헤더가 없습니다.  *데이터 매퍼*의 소스 목록을 사용하여 열 정렬을 결정합니다.
* **헤더 있음 - 헤더를 사용하고 필드 목록 재정의**: 파일에 헤더가 있습니다.  지정된 헤더 이름을 사용하고 *데이터 매퍼*의 소스 목록은 무시합니다.
* **헤더 있음 - 헤더를 건너뛰고 대신 필드 목록 사용**: 파일에 헤더가 있지만 무시해야 합니다.  *데이터 매퍼*의 소스 목록에 지정된 헤더 이름을 사용합니다.

### 가져올 워크시트

통합 문서에는 서로 다른 데이터가 담긴 워크시트가 많을 수 있으므로, 현재 가져오기 프로세스에서 가져올 워크시트를 선택할 수 있습니다.  옵션은 다음과 같습니다.

* 모든 워크시트
* 검색과 일치하는 워크시트
* 선택한 워크시트

#### 워크시트 검색 사용

워크시트 검색 기능을 사용하면 검색 조건과 일치하는 워크시트를 포함할 수 있습니다.  검색 조건은 다음을 지원합니다.
* **시작 문자열**: 워크시트 이름이 검색 텍스트로 시작합니다.
* **포함**: 워크시트 이름에 검색 텍스트가 포함됩니다.
* **끝 문자열**: 워크시트 이름이 검색 텍스트로 끝납니다.

#### 선택한 파일에서 시트 찾기

시트 찾기 버튼은 Excel 파일을 열어 테이블에서 사용할 수 있는 워크시트를 나열합니다.  가져오기에 포함할 워크시트의 확인란을 테이블에서 선택하십시오.

<Aside>*데이터 매퍼*를 채울 때는 목록에서 처음 발견된 워크시트를 사용합니다. 가져오기 단계에 포함된 모든 워크시트의 형식이 비슷한지 확인하십시오.</Aside>
### 열 헤더

<Aside>기술적 제한으로 인해 Google 스프레드시트의 모든 열은 문자열 데이터 유형으로 가져옵니다. 부울, 숫자 및/또는 날짜/시간 데이터 유형은 매퍼에서 명시적으로 지정해야 합니다.</Aside>
