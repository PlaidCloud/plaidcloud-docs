## 설명

**가져오기: 구분 문서(위치 기준)** 단계는 구분 문서의 모든 열을 위치 기준으로 읽어 `Column_1`부터 `Column_N`까지 이름이 지정된 텍스트 열로 가져오며, 헤더 줄은 건너뜁니다. 헤더로 열 이름을 지정할 수 없을 때, 예를 들어 이후 단계에서 데이터 행을 헤더로 승격하는 경우에 사용합니다.

## 매개변수

- **문서** — 파일의 문서 계정과 경로입니다. `.gz`로 끝나는 경로는 압축을 풉니다.
- **구분 기호** — 필드 구분 기호입니다. 기본값은 쉼표입니다.
- **따옴표 문자** — 기본값은 큰따옴표입니다.
- **레코드 번호 열** *(선택 사항)* — 파일 순서대로 레코드에 번호를 매기는 열입니다. 비워 두면 만들지 않습니다.
- **출력 테이블** — 행을 기록할 위치입니다.

문서가 없는 것은 오류가 아닙니다. 이 단계는 경로를 명시한 경고와 함께 완료되며 빈 테이블을 기록합니다.
