## 설명

수백만 개의 데이터 세트가 있는 Quandl 저장소에서 데이터 세트를 가져옵니다.

Quandl 데이터 세트에 대한 자세한 내용은 Quandl 공식 웹 사이트(http://www.quandl.com/)를 참조하십시오.

## 고유 구성 항목

### 소스 데이터 사양

Quandl 데이터 세트에 접근하려면 사용자 계정 또는 접근이 제한된 게스트 계정이 필요합니다. 이 계정은 도구에서 설정해야 합니다. Quandl 계정 연결 설정에 대한 자세한 내용은 [PlaidCloud 도구 – 연결](/ko/reference/connectors/)을 참조하십시오.

필요한 계정을 모두 설정한 후 드롭다운 목록에서 해당 계정을 선택합니다.

다음으로 원하는 Quandl 코드의 조건을 입력합니다. 사용자는 **검색** 기능으로 데이터 세트를 검색할 수 있으며, 데이터 세트를 직접 입력할 수도 있습니다. 직접 입력하려면 “[http://www.quandl.com](http://www.quandl.com/)” 뒤에 오는 URL 부분을 입력해야 합니다. 

예를 들어 Microsoft 주식의 데이터 세트(http://www.quandl.com/GOOG/NASDAQ_MSFT)를 가져오려면 Quandl 코드 필드에 *GOOG/NASDAQ_MSFT*를 입력합니다.


### 데이터 선택


가져올 때 Quandl 데이터 세트를 분할할 수 있습니다. 사용 가능한 옵션은 다음과 같습니다.


* 시작 날짜: 날짜 선택기를 사용하여 원하는 날짜를 선택합니다.
* 종료 날짜: 날짜 선택기를 사용하여 원하는 날짜를 선택합니다.
* Collapse: 일별, 주별, 월별, 분기별 또는 연도별로 결과를 집계합니다. 기본적으로 집계하지 않습니다.
* Transformation: 요약 계산입니다.
* Limit Rows: 기본값 0은 모든 행을 반환합니다. 0보다 큰 다른 정수 값은 데이터 세트에서 반환할 행 수의 상한을 지정합니다.
