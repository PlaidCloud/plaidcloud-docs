## 설명


Stata 데이터 파일(.dta)을 PlaidCloud 프로젝트 테이블로 가져옵니다. 계량경제학 또는 통계 분석에 Stata를 사용하며 작업 데이터 세트를 PlaidCloud로 가져와 추가로 처리하려는 조직에 유용합니다.

변수 레이블은 Stata 형식에 포함된 경우 보존됩니다.
