## 설명

**공간 파일 가져오기** 단계는 공간 파일(MapInfo `.TAB`,
ESRI `.shp`, `.kml`, `.geojson` 또는 SRC `.geo`)과 그 보조 파일을
테이블로 읽어 들이며, 피처마다 한 행과 WKT 지오메트리 열을 만듭니다. 공간 파일을 가리키는
Alteryx *Input Data* 도구에 해당하며 워크플로
엔진(GDAL)에서 실행됩니다.

## 가져오기 매개변수

- **소스** — 문서 저장소에 있는 공간 파일입니다. 보조 파일
  (예: `.TAB`의 `.dat`/`.map`/`.id`/`.dbf` 또는 shapefile의 `.shx`/`.dbf`/`.prj`)은
  같은 위치에서 자동으로 읽습니다.
- **대상 테이블** — 피처를 기록할 테이블입니다.

## 참고

출력 스키마는 파일에서 가져오므로 열 매핑이 없습니다. SRC
`.geo` 파일의 독점 지오메트리는 읽을 수 없으며, 해당 `.dbf` 속성은
빈 지오메트리 값으로 가져옵니다.
