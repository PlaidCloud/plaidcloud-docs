## 설명

**Spatial Smooth** 단계는 각 지오메트리를 지정한 횟수의
패스로 평활화합니다. Alteryx *Smooth* 도구에 해당하며
워크플로 엔진에서 실행됩니다.

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — 입력 지오메트리와 결과를
  기록할 위치입니다.
- **도형 열** — 평활화할 WKT 지오메트리 열입니다.
- **패스** — 적용할 평활화 패스의 수입니다.

## 열

**열** 탭에서는 출력으로 전달할 입력 열을 매핑합니다.
