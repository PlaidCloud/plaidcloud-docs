## 설명

**Spatial Generalize** 단계는 각 지오메트리를 허용 오차에 맞게 단순화하여
꼭짓점 수를 줄입니다. Alteryx *Generalize* 도구에 해당하며
워크플로 엔진에서 실행됩니다.

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — 입력 지오메트리와 결과를
  기록할 위치입니다.
- **도형 열** — 단순화할 WKT 지오메트리 열입니다.
- **허용 오차** — 단순화 허용 오차이며, 값이 클수록 더 거친
  지오메트리가 만들어집니다. 토폴로지는 유지됩니다.

## 열

**열** 탭에서는 출력으로 전달할 입력 열을 매핑합니다.
