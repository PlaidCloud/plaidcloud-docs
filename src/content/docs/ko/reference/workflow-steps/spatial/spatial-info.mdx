## 설명

**Spatial Info** 단계는 각 지오메트리를 측정하고 측정값을
열로 추가합니다. Alteryx *Spatial Info* 도구에 해당하며
워크플로 엔진에서 실행됩니다.

측정값은 평면이 아니라 **WGS84 측지** 방식입니다. 이 점이 중요합니다. 이러한 측정값의 SQL 형식은
적도 상수로 환산한 평면 도² 값인데, 위도가 높아져도 이 상수는 경도에 따라
줄어들지 않으므로 면적과 길이를 **과대 평가**합니다. 미국 위도에서는 약 4분의 1 정도 높게 나옵니다.
측지 방식으로 계산하면 모든 웨어하우스에서 Alteryx와 일치하는 하나의 결과를 얻을 수 있습니다.

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — 입력 지오메트리와 측정된 행을
  기록할 위치입니다.
- **도형 열** — 측정할 WKT 지오메트리 열입니다.
- **측정값** — 추가할 측정값입니다. 선택 항목마다 아래의
  열이 추가됩니다.
- **구 반지름(km)** *(선택 사항)* — 이 반지름의 구에서 측정합니다.
  WGS84 타원체에서 측정하려면 비워 둡니다.

## 출력 열

| 측정값 | 추가되는 열 | 유형 |
|---|---|---|
| 면적(마일) | `AreaSqMi` | 숫자 |
| 면적(km) | `AreaSqKm` | 숫자 |
| 길이(마일) | `LengthMi` | 숫자 |
| 길이(km) | `LengthKm` | 숫자 |
| 중심점 좌표 | `CentroidX`, `CentroidY` | 숫자 |
| 경계 사각형 좌표 | `BR_Left`, `BR_Top`, `BR_Right`, `BR_Bottom` | 숫자 |
| 중심점 개체 | `Centroid` | WKT 지오메트리 |
| 경계 사각형 개체 | `BoundingRect` | WKT 지오메트리 |
| 경계 사각형 폴리곤 | `BoundingRectPolygon` | WKT 지오메트리 |
| 유효 여부 | `IsValid` | 불리언 |
| 개체 유형 | `SpatialObjType` | 텍스트 |
| 부분 수 | `NumParts` | 숫자 |
| 점 수 | `NumPoints` | 숫자 |
| 끝점 좌표 | `EndPointX`, `EndPointY` | 숫자 |
| 끝점 개체 | `EndPoint` | WKT 지오메트리 |

`IsValid`는 제공된 지오메트리가 수정 전에 유효한 도형인지를 나타냅니다.

경계 사각형 개체와 경계 사각형 폴리곤은 WKT에서
동일한 5개 꼭짓점 링으로 직렬화되므로 두 열은 같은 값을 가집니다.

## 참고

개체 유형, 부분 수, 점 수, 끝점은 최선의 추정으로 정한 열 이름으로 추가됩니다.
Alteryx는 측정값을 문서화하지만 출력 열 이름은 명시하지 않으므로,
정확한 이름은 후속 작업에서 실제 워크플로로 검증합니다.
변환되지 않는 유일한 정보 유형은 **Peano key**입니다. 이는 공개 사양이 없는 Alteryx 독점
공간 인덱스이며, 건너뛰고 변환 시 해당 항목을 명시한 참고가 출력되어
변환된 워크플로에서 누락 사실을 확인할 수 있습니다.
