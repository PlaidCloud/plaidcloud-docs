## 설명

**Spatial Buffer** 단계는 열의 각 지오메트리를 고정 거리만큼 확장하고
버퍼링된 지오메트리를 출력 열에 기록합니다. Alteryx *Buffer* 도구에 해당하며,
워크플로 엔진에서 실행됩니다(지오메트리 작업은 SQL로 표현할 수 없습니다).

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — 입력 지오메트리와 결과를 기록할 위치입니다.
- **도형 열** — 버퍼를 적용할 WKT 지오메트리 열입니다.
- **버퍼 거리** — 각 지오메트리를 확장할 거리이며, 지오메트리 자체의
  좌표 단위로 지정합니다.

## 열

**열** 탭에서는 출력으로 전달할 입력 열을 매핑합니다. 버퍼링된
지오메트리 열은 자동으로 추가됩니다.
