## 설명

**공간 결합** 단계는 각 그룹 내의 지오메트리를 하나의 지오메트리(합집합)로
디졸브하며, 그룹당 하나의 출력 행을 만듭니다. Alteryx *Summarize* 도구의
*SpatialObjCombine* 동작에 해당하며 워크플로 엔진에서
실행됩니다.

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — 입력 지오메트리와 디졸브된 결과를
  기록할 위치입니다.
- **도형 열** — 디졸브할 WKT 지오메트리 열입니다.
- **그룹화 기준** — 고유한 조합이 각 그룹을 정의하는 열이며, 각
  그룹의 지오메트리가 하나로 합쳐집니다. 아무것도 선택하지 않으면 모든 항목을
  하나의 지오메트리로 결합합니다.
- **출력 열** — 출력 지오메트리 열의 이름입니다.
- **작업** — `spatialobjcombine`은 그룹을 합집합으로 디졸브하고, `spatialobjconvexhull`은 그룹을 둘러싸는 가장 작은 볼록 폴리곤을 반환하며, `intersection`은 모든 구성원이 공유하는 영역만 유지하고(구성원이 서로 떨어져 있으면 비어 있음), `envelope`는 그룹의 경계 상자를 반환합니다.

## 열

**열** 탭에서는 출력으로 전달할 입력 열을 매핑합니다.
