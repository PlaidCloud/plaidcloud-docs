## 설명

**Spatial Make Grid** 단계는 직사각형 범위를 고정된 지상 크기의 정사각형 셀로
나누고 셀마다 한 행을 기록합니다. Alteryx *Make Grid* 도구에
해당하며 워크플로 엔진에서 실행됩니다.

데이터에서 범위를 읽고 나면 셀 수는 단순 산술로 정해지므로
(`ceil(extent ÷ cell size)`를 가로세로 각각 적용) 팬아웃이 제한적이고 예측 가능합니다.

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — 입력 지오메트리와 셀을
  기록할 위치입니다.
- **도형 열** — 범위를 나눌 WKT 지오메트리 열입니다.
- **격자 크기** 및 **단위** — 정사각형 셀 하나의 지상 크기이며, 마일,
  킬로미터, 미터 또는 피트로 지정합니다.
- **개체당 격자 하나** — 설정하면 각 입력 지오메트리 위에 별도의 격자가 그려지고,
  설정하지 않으면 전체 레이어의 범위를 격자 하나가 덮습니다.
- **Clip cells to polygon** — 개체별 모드에서 각 셀을 해당 셀이 속한 폴리곤에 맞게
  잘라 냅니다. 기본적으로 켜져 있습니다.
- **격자 이름 열** — 출력 셀 레이블 열의 이름입니다
  (기본값은 `GridName`).
- **출력 열** — 출력 지오메트리 열의 이름입니다
  (기본값은 `SpatialObj`).

## 출력 열

모든 행에는 셀 레이블과 셀 지오메트리가 포함됩니다. 개체별 모드에서는
소스 열이 함께 전달되며, 전체 레이어 모드에서는 셀이 단일 입력 행에 속하지 않으므로
출력이 두 격자 열뿐입니다.

## 참고

격자 크기가 0 또는 음수이면 빈 격자를 만드는 대신 단계가 실패합니다.

셀 크기는 선택한 지상 단위에서 대략적인 도 단위 크기로 변환되므로,
적도에서 멀어질수록 셀이 약간 직사각형으로 보입니다. 이는 실제 단위를 사용하는
다른 공간 단계와 같은 평면 근사입니다.
