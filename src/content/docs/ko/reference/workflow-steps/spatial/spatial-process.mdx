## 설명

**공간 처리** 단계는 각 행의 두 지오메트리 열을 결합하여
하나의 결과 지오메트리를 만듭니다. Alteryx *Spatial
Process* 도구에 해당하며 워크플로 엔진에서 실행됩니다.

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — 입력 지오메트리와 결과를
  기록할 위치입니다.
- **첫 번째 도형** / **두 번째 도형** — 결합할 두 개의 WKT 지오메트리
  열입니다.
- **작업** — 결합 방식입니다.
  - **교집합** — 두 지오메트리의 겹치는 부분.
  - **합집합** — 두 지오메트리를 합친 결과.
  - **첫 번째에서 두 번째 제거** — 첫 번째를 지운 두 번째 지오메트리.
  - **두 번째에서 첫 번째 제거** — 두 번째를 지운 첫 번째 지오메트리.
- **빈 결과 도형 삭제** — 결과가 비어 있는 행을 건너뜁니다.
- **출력 열** — 출력 지오메트리 열의 이름입니다.

## 열

**열** 탭에서는 출력으로 전달할 입력 열을 매핑합니다.
