## 설명

만듭니다. Alteryx *Poly-Build*
도구에 해당하며 워크플로 엔진에서 실행됩니다.

## 소스 및 옵션

- **소스 테이블** / **출력 테이블** — 입력 점과 결과를
  기록할 위치입니다.
- **점 도형** — 구성에 사용할 WKT 점 지오메트리 열입니다.
- **그룹화 기준** — 점을 별도의 출력 폴리곤으로 묶는 선택 열입니다.
  모든 점으로 폴리곤 하나를 만들려면 비워 둡니다.
- **빌드 유형** — **시퀀스**는 그룹화된 점을 폴리곤으로 디졸브하고,
  **볼록 껍질**은 점의 볼록 껍질을 만듭니다.
- **출력 열** — 출력 지오메트리 열의 이름입니다.

## 열

**열** 탭에서는 출력으로 전달할 입력 열을 매핑합니다.
