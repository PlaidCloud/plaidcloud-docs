## 설명

**Spatial Match (Intersect / Unmatched)** 단계는 각 대상
지오메트리를 관계가 있는 유니버스 지오메트리와 짝짓고, 일치한 각 쌍의
**교차 지오메트리**(*IntersectPoly*) 또는
**불일치** 대상 행을 출력할 수 있습니다. 일치한 쌍만 다루는 일반적인 경우는 SQL 기반
[공간 매치](/ko/reference/workflow-steps/spatial/spatial-match/) 단계가 담당하고,
이 실행기 기반 단계는 데이터베이스 SQL로 표현할 수 없는 두 가지
출력을 담당합니다.

## 소스 및 옵션

- **대상 테이블** / **유니버스 테이블** — 매치할 지오메트리와
  매치 대상이 되는 후보입니다.
- **출력 테이블** — 결과를 기록할 위치입니다.
- **대상 지오메트리 / 유니버스 지오메트리** — 양쪽의 WKT 지오메트리 열입니다.
- **관계** — 교차(intersects), 내부(within), 포함(contains), 접함(touches), 가로지름(crosses), 겹침(overlaps), 동일(equals), 분리(disjoint) 중에서 선택합니다. *동일*은 토폴로지상 같은 지오메트리만 매치하고, *분리*는 공유하는 점이 없는 쌍을 매치하며, null 지오메트리는 *분리*와 매치되지 않습니다.
- **Multiple Rules** — 하나의 매치에서 여러 대상 및 유니버스 지오메트리 열을 동시에 연관시킬 수 있으며, 규칙마다 관계를 따로 지정합니다. `joiner` 설정은 쌍이 모든 규칙을 만족해야 하는지(*and*, 기본값) 아니면 하나라도 만족하면 되는지(*or*)를 정합니다. Savant 변환은 다중 규칙 매치를 생성합니다. 알 수 없는 관계나 joiner는 교차로 실행되는 대신 이름을 명시하며 단계를 실패시킵니다.
- **교차 도형도 출력(IntersectPoly)** — 일치한 각 쌍의 겹치는 영역
  지오메트리를 열로 추가합니다.
- **출력** — *일치한 쌍* 또는 *일치하지 않은 대상 행*.

## 대상 및 유니버스 매핑

각 입력에는 해당 열을 나열하는 매핑 탭이 있으며, 지오메트리
선택기를 채우고 열을 출력으로 전달하는 데 쓰입니다.
