## 설명

**ML: 점수 산출** 단계는 [ML: 모델 학습](/ko/reference/workflow-steps/machine-learning/ml-train/)으로 학습시킨 모델로 데이터 테이블을 채점하고, 예측 열 하나를 추가한 데이터를 기록합니다. 모델이 일반 테이블로 전달되므로 한 번 학습시켜 여러 테이블을 채점하거나 새 데이터가 들어올 때마다 다시 채점할 수 있습니다. 이 단계는 PlaidCloud 관리형 작업으로 실행됩니다(LLM 단계와 같습니다).

## 채점 탭

- **데이터 테이블** — 채점할 테이블입니다. 모델이 학습된 모든 특성 열이 포함되어 있어야 합니다.
- **모델 테이블** — ML: 모델 학습 단계가 기록한 모델 테이블입니다. 테이블이 비어 있거나 저장된 모델의 일부가 없으면 단계가 실패합니다.
- **출력 테이블** — 채점된 데이터를 기록할 위치입니다.
- **예측 열** — 추가되는 열의 이름입니다. 비워 두면 `prediction`을 사용합니다. 데이터 테이블에 이미 같은 이름이 있으면 단계가 실패합니다.

## 출력

출력 테이블에는 데이터 테이블의 모든 열과 예측 열이 포함됩니다. 분류기는 텍스트 클래스 레이블을, 회귀기는 숫자 값을 반환합니다. 특성 값은 학습 시점과 똑같이 준비되며, 모델이 학습 중에 본 적이 없는 범주형 값은 오류를 일으키지 않고 무시됩니다.

모델 테이블은 ML: 모델 학습 단계가 기록하는 형태여야 합니다. 즉 모든 모델 열이 있고, 알려진 알고리즘이며, 저장된 모델의 모든 부분이 있어야 합니다. 모델 자체는 표준 과학 스택 외의 모든 것을 거부하는 제한 하에 로드되므로, 임의로 만든 모델 행으로는 임의의 코드를 실행할 수 없습니다.

### 추가 출력 열

**채점 옵션** 섹션에는 다음 필드가 있습니다. 변환된 KNIME 워크플로도 이 필드를 사용합니다.

- **클래스 확률 열**(`probability_column_template`) — 분류기에서 클래스마다 확률 열을 하나씩 추가하며, 이 템플릿에서 `{class}`를 치환한 이름을 붙입니다. **예측 앞에 확률 배치**(`probabilities_first`)는 확률 열을 예측 열 앞에 놓고, **학습에서 처음 나타난 순서대로 클래스 정렬**(`classes_in_domain_order`)은 클래스를 정렬하는 대신 학습 데이터에 처음 나타난 순서대로 배치합니다.
- **신뢰도 열**(`confidence_column`) — 분류기에서 이 이름으로 선택된 클래스의 확률을 추가합니다.
- **분산 열**(`variance_column`) — 포레스트 회귀기에서 이 이름으로 트리 예측값의 분산을 추가합니다.
- **모델 수 열**(`model_count_column`) — 트리 모델에서 이 이름으로 트리 개수를 추가합니다.
- **추가되는 열의 순서**(`column_order`) — 추가되는 열의 순서입니다. 비워 두면 예측, 확률, 신뢰도, 분산, 모델 수 순입니다.
- **대신 기록**(`report`) — 채점된 데이터 대신 모델 자체 테이블 중 하나를 기록합니다. 예를 들어 `variable_importance`, `coefficients`, `statistics`, `pmml`(PMML 문서로 된 모델), `centers`, `cluster_counts`, `association_rules`가 있습니다.
- **모델 형식**(`model_format`) — `pmml`은 PMML 문서로 채점합니다. 모델 테이블에 문서가 있거나, PMML 형식을 가진 학습기의 모델이 있어야 합니다.
- **알고리즘 설정**(`algorithm_settings`) — `pca` 모델이 투영하는 구성 요소 수처럼, 모델 알고리즘에 고유한 채점 또는 보고서 설정입니다.
- **세 번째 테이블**(`source_c`) — `knn_distance` 모델이 사용하는 랜덤 포레스트처럼 일부 알고리즘이 읽는 세 번째 테이블입니다.

AI 어시스턴트 또는 REST API로 `report`를 `shap_values`로 설정할 수도 있습니다.

## 제한 사항 및 주의 사항

- **메모리 내 작업 집합** — 데이터 테이블을 메모리로 읽으므로, 이 단계는 실행당 약 100만 행을 대상으로 합니다.
- **변환된 Alteryx 워크플로** — 변환된 Predict 도구는 예측 열 이름을 대상 변수 이름에 `_predicted` 접미사를 붙인 이름으로 고정합니다.
