`VARIANT`에서 `path_name`으로 값을 추출합니다.
값은 `Variant`로 반환되며, 인수 중 하나라도 `NULL`이면 `NULL`이 반환됩니다.

`GET_PATH`는 `GET` 함수를 연쇄 호출한 것과 같으며, `path_name`은 마침표(.), 콜론(:) 또는 인덱스 연산자(`[index]`)가 앞에 붙은 필드 이름을 이어 붙인 것입니다. 첫 번째 필드 이름에는 앞에 붙는 식별자를 지정하지 않아도 됩니다.

## Analyze Syntax

```python
func.get_path(<variant>, <path_name>)
```

## Analyze Examples

```python
func.get_path(func.parse_json('{"k1":[0,1,2], "k2":{"k3":3,"k4":4}}'), 'k2.k4')
┌─────────────────────────────────────────────────────────────────────────────────┐
│ func.get_path(func.parse_json('{"k1":[0,1,2], "k2":{"k3":3,"k4":4}}'), 'k2.k4') │
├─────────────────────────────────────────────────────────────────────────────────┤
│ 4                                                                               │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## SQL Syntax

```sql
GET_PATH( <variant>, <path_name> )
```

## 인수

| 인수     | 설명                                                      |
|---------------|------------------------------------------------------------------|
| `<variant>`   | ARRAY 또는 OBJECT를 포함하는 VARIANT 값     |
| `<path_name>` | 필드 이름을 이어 붙인 문자열 값 |

## 반환 타입

VARIANT
