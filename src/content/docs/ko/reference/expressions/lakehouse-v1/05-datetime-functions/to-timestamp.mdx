TO_TIMESTAMP는 식을 시간이 포함된 날짜(timestamp/datetime)로 변환합니다.

이 함수는 하나 또는 두 개의 인수를 받을 수 있습니다. 인수가 하나이면 문자열에서 날짜를 추출합니다. 인수가 정수이면 Unix 에포크(1970년 1월 1일 자정) 이전(음수) 또는 이후(양수)의 초, 밀리초 또는 마이크로초 수로 해석합니다.

- 정수가 31,536,000,000보다 작으면 초로 처리합니다.
- 정수가 31,536,000,000 이상이고 31,536,000,000,000보다 작으면 밀리초로 처리합니다.
- 정수가 31,536,000,000,000 이상이면 마이크로초로 처리합니다.

인수가 두 개이면 두 번째 문자열에 지정된 형식에 따라 첫 번째 문자열을 타임스탬프로 변환합니다. PlaidCloud Lakehouse에서 날짜와 시간의 형식을 사용자 지정하려면 지정자를 사용할 수 있습니다. 지정자를 사용하면 날짜 및 시간 값에 원하는 형식을 정의할 수 있습니다. 지원되는 지정자의 전체 목록은 Formatting Date and Time을 참조하십시오.

- 출력 타임스탬프에는 PlaidCloud Lakehouse 시간대가 반영됩니다.
- 변환할 문자열에 시간대 정보가 포함되어 있어야 하며, 그렇지 않으면 NULL이 반환됩니다.

날짜 형식은 `strftime` 사양으로 표현합니다. [빠른 참조](https://devhints.io/strftime)를 참조하십시오.

참고: [TO_DATE](../to-date)

## Analyze 구문

```python
func.to_timestamp(<expr>)
```

## Analyze 예제

```python
func.to_timestamp('2022-01-02T03:25:02.868894-07:00')

┌────────────────────────────────────────────────────────────────┐
│ func.to_timestamp('2022-01-02T03:25:02.868894-07:00')          │
│                          Timestamp                             │
├────────────────────────────────────────────────────────────────┤
│ 2022-01-02 10:25:02.868894                                     │
└────────────────────────────────────────────────────────────────┘
```

## SQL 구문

```sql
-- Convert a string or integer to a timestamp
TO_TIMESTAMP(<expr>)

-- Convert a string to a timestamp using the given pattern
TO_TIMESTAMP(<expr, expr>)
```

## 반환 형식

"YYYY-MM-DD hh:mm:ss.ffffff" 형식의 타임스탬프를 반환합니다. 지정한 문자열이 이 형식과 일치하지만 시간 부분이 없으면 자동으로 이 패턴으로 확장됩니다. 채움 값은 0입니다.

## SQL 예제

### 문자열 인수를 지정한 경우

```sql
SELECT TO_TIMESTAMP('2022-01-02T03:25:02.868894-07:00');

---
2022-01-02 10:25:02.868894

SELECT TO_TIMESTAMP('2022-01-02 02:00:11');

---
2022-01-02 02:00:11.000000

SELECT TO_TIMESTAMP('2022-01-02T02:00:22');

---
2022-01-02 02:00:22.000000

SELECT TO_TIMESTAMP('2022-01-02T01:12:00-07:00');

---
2022-01-02 08:12:00.000000

SELECT TO_TIMESTAMP('2022-01-02T01');

---
2022-01-02 01:00:00.000000
```

### 정수 인수를 지정한 경우

```sql
SELECT TO_TIMESTAMP(1);

---
1970-01-01 00:00:01.000000

SELECT TO_TIMESTAMP(-1);

---
1969-12-31 23:59:59.000000
```

<Aside>참고: Timestamp 값의 범위는 1000-01-01 00:00:00.000000부터 9999-12-31 23:59:59.999999까지입니다. 다음 문을 실행하면 PlaidCloud Lakehouse에서 오류가 반환됩니다. ```sql SELECT TO_TIMESTAMP(9999999999999999999); ```</Aside>

### 인수를 두 개 지정한 경우

```sql
SET GLOBAL timezone ='Japan';
SELECT TO_TIMESTAMP('2022 年 2 月 4 日、8 時 58 分 59 秒、タイムゾーン：+0900', '%Y年%m月%d日、%H時%M分%S秒、タイムゾーン：%z');

---
2022-02-04 08:58:59.000000

SET GLOBAL timezone ='America/Toronto';
SELECT TO_TIMESTAMP('2022 年 2 月 4 日、8 時 58 分 59 秒、タイムゾーン：+0900', '%Y年%m月%d日、%H時%M分%S秒、タイムゾーン：%z');

---
2022-02-03 18:58:59.000000
```
