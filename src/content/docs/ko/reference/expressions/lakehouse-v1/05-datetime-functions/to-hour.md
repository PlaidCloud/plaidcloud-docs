날짜/시간(타임스탬프/datetime)을 24시간제 시각의 시(0-23)를 담은 UInt8 숫자로 변환합니다.
이 함수는 시계를 앞당기는 경우 1시간 단위로 오전 2시에 이루어지고, 시계를 되돌리는 경우 1시간 단위로 오전 3시에 이루어진다고 가정합니다(항상 그런 것은 아니며, 모스크바에서도 시계가 서로 다른 시점에 두 번 변경된 적이 있습니다).


## Analyze 구문

```python
func.to_hour(<expr>)
```

## Analyze 예시

```python
func.to_hour('2023-11-12 09:38:18.165575')

┌────────────────────────────────────────────────────┐
│ func.to_hour('2023-11-12 09:38:18.165575')         │
│                     UInt8                          │
├────────────────────────────────────────────────────┤
│                                                  9 │
└────────────────────────────────────────────────────┘
```

## SQL 구문

```sql
TO_HOUR(<expr>)
```

## 인수

| 인수 | 설명 |
|-----------|-------------|
| `<expr>`  | 타임스탬프   |

## 반환 형식

`TINYINT`

## SQL 예시

```sql
SELECT
    to_hour('2023-11-12 09:38:18.165575')

│                                     9 │
└───────────────────────────────────────┘
```
