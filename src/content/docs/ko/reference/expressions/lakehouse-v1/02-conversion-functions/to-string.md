값을 String 데이터 형식으로 변환하거나 Date 값을 특정 문자열 형식으로 변환합니다. PlaidCloud Lakehouse에서 날짜와 시간의 형식을 사용자 지정하려면 지정자를 사용할 수 있습니다. 이러한 지정자로 날짜 및 시간 값에 원하는 형식을 정의할 수 있습니다. 지원되는 지정자의 전체 목록은 날짜 및 시간 서식 지정을 참조하십시오.

## Analyze 구문

```python
func.to_string( '<expr>' )
```

## Analyze 예제

```python
func.date_format('1.23'), func.to_string('1.23'), func.to_text('1.23'), func.to_varchar('1.23'), func.json_to_string('1.23')

┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ func.date_format('1.23') │ func.to_string('1.23') │ func.to_text('1.23') │ func.to_varchar('1.23') │ func.json_to_string('1.23') │
├──────────────────────────┼────────────────────────┼──────────────────────┼─────────────────────────┼─────────────────────────────┤
│ 1.23                     │ 1.23                   │ 1.23                 │ 1.23                    │ 1.23                        │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘ 
```

## SQL 구문

```sql
TO_STRING( '<expr>' )

TO_STRING( '<date>', '<format>' )
```
