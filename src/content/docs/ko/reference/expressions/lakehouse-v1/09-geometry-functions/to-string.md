GEOMETRY 객체를 문자열 표현으로 변환합니다. 출력 데이터의 표시 형식은 `geometry_output_format` 설정으로 제어하며, 사용할 수 있는 유형은 다음과 같습니다.

| 매개변수         | 설명                                                         |
|-------------------|---------------------------------------------------------------------|
| GeoJSON (기본값) | GEOMETRY 결과를 GeoJSON 형식의 JSON 객체로 렌더링합니다. |
| WKT               | GEOMETRY 결과를 WKT 형식의 문자열로 렌더링합니다.          |
| WKB               | GEOMETRY 결과를 WKB 형식의 이진 값으로 렌더링합니다.          |
| EWKT              | GEOMETRY 결과를 EWKT 형식의 문자열로 렌더링합니다.         |
| EWKB              | GEOMETRY 결과를 EWKB 형식의 이진 값으로 렌더링합니다.         |

## SQL 구문

```sql
TO_STRING(<geometry>)
```

## 인수

| 인수    | 설명                                          |
|--------------|------------------------------------------------------|
| `<geometry>` | 인수는 GEOMETRY 형식의 식이어야 합니다. |

## 반환 형식

String.

## SQL 예제

```sql
SET geometry_output_format='GeoJSON';

SELECT
  TO_GEOMETRY(
    ST_GEOMETRYFROMWKT(
      'SRID=4326;LINESTRING(400000 6000000, 401000 6010000)'
    )
  ) AS pipeline_geometry;
```
