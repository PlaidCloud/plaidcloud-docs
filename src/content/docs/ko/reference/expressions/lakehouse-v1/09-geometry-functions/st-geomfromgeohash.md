[geohash](https://en.wikipedia.org/wiki/Geohash)의 경계를 나타내는 다각형의 GEOMETRY 객체를 반환합니다.

## SQL 구문

```sql
ST_GEOMFROMGEOHASH(<geohash>)
```

## 인수

| 인수   | 설명                     |
|-------------|---------------------------------|
| `<geohash>` | 인수는 geohash여야 합니다. |

## 반환 형식

Geometry.

## SQL 예제

```sql
SELECT
  ST_GEOMFROMGEOHASH(
    '9q60y60rhs'
  ) AS pipeline_geometry;
```
