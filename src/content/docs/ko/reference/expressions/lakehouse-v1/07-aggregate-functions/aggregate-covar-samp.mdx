집계 함수입니다.

covar_samp() 함수는 두 데이터 열의 표본 공분산(Σ((x - x̅)(y - y̅)) / (n - 1))을 반환합니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.covar_samp(<expr1>, <expr2>)
```

## Analyze 예제

```python
func.covar_samp(table.items_sold, table.profit).alias('covar_samp_items_profit')

| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```

## SQL 구문

```sql
COVAR_SAMP(<expr1>, <expr2>)
```

## 인수

| 인수 |        설명       |
|-----------| ------------------------ |
| `<expr1>` | 모든 숫자 식 |
| `<expr2>` | 모든 숫자 식 |

## 반환 형식

float64이며, n &lt;= 1이면 +∞를 반환합니다.

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**

```sql
CREATE TABLE store_sales (
  id INT,
  store_id INT,
  items_sold INT,
  profit FLOAT
);

INSERT INTO store_sales (id, store_id, items_sold, profit)
VALUES (1, 1, 100, 1000),
       (2, 2, 200, 2000),
       (3, 3, 300, 3000),
       (4, 4, 400, 4000),
       (5, 5, 500, 5000);
```

**쿼리 데모: 판매 품목 수와 이익 간의 표본 공분산 계산**

```sql
SELECT COVAR_SAMP(items_sold, profit) AS covar_samp_items_profit
FROM store_sales;
```

**결과**

```sql
| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```
