집계 함수입니다.

STDDEV_POP() 함수는 식의 모집단 표준 편차(VAR_POP()의 제곱근)를 반환합니다.

<Aside>STD() 또는 STDDEV()도 사용할 수 있으며, 동일하게 동작하지만 표준 SQL은 아닙니다.</Aside>

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.stddev_pop(<expr>)
```

## Analyze 예제

```python
func.stddev_pop(table.score).alias('test_score_stddev_pop')

| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```

## SQL 구문

```sql
STDDEV_POP(<expr>)
STDDEV(<expr>)
STD(<expr>)
```

## 인수

| 인수 | 설명              |
|-----------|--------------------------|
| `<expr>`  | 모든 숫자 식 |

## 반환 형식

double

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**
```sql
CREATE TABLE test_scores (
  id INT,
  student_id INT,
  score FLOAT
);

INSERT INTO test_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 85),
       (3, 3, 90),
       (4, 4, 95),
       (5, 5, 100);
```

**쿼리 데모: 시험 점수의 모집단 표준 편차 계산**
```sql
SELECT STDDEV_POP(score) AS test_score_stddev_pop
FROM test_scores;
```

**결과**
```sql
| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```
