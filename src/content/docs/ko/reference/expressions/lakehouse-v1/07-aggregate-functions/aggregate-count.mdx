COUNT() 함수는 SELECT 쿼리가 반환하는 레코드 수를 반환합니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.count(<column>)
```

## Analyze 예제

```python
func.count(table.grade).alias('count_valid_grades')

| count_valid_grades |
|--------------------|
|          4         |
```

## SQL 구문

```sql
COUNT(<expr>)
```

## 인수

| 인수 | 설명 |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<expr>`  | 모든 식입니다. <br /> 열 이름, 다른 함수의 결과 또는 수학 연산일 수 있습니다.<br />`*`도 사용할 수 있으며, 순수한 행 개수 세기를 나타냅니다. |

## 반환 형식

정수입니다.

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**
```sql
CREATE TABLE students (
  id INT,
  name VARCHAR,
  age INT,
  grade FLOAT NULL
);

INSERT INTO students (id, name, age, grade)
VALUES (1, 'John', 21, 85),
       (2, 'Emma', 22, NULL),
       (3, 'Alice', 23, 90),
       (4, 'Michael', 21, 88),
       (5, 'Sophie', 22, 92);

```

**쿼리 데모: 유효한 성적이 있는 학생 수 세기**
```sql
SELECT COUNT(grade) AS count_valid_grades
FROM students;
```

**결과**
```sql
| count_valid_grades |
|--------------------|
|          4         |
```
