[t-digest](https://github.com/tdunning/t-digest/blob/master/docs/t-digest-paper/histo.pdf) 알고리즘을 사용하여 숫자 데이터 시퀀스의 중앙값을 계산합니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.median_tdigest(<expr>)
```

## Analyze 예제

```python
func.median_tdigest(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## SQL 구문

```sql
MEDIAN_TDIGEST(<expr>)
```

## 인수

| 인수 | 설명              |
|-----------|--------------------------|
| `<expr>`  | 모든 숫자 식 |

## 반환 형식

입력 값과 같은 데이터 형식의 값을 반환합니다.

## SQL 예제

```sql
-- Create a table and insert sample data
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);

-- Calculate median exam score
SELECT MEDIAN_TDIGEST(score) AS median_score
FROM exam_scores;

|  median_score  |
|----------------|
|      85.0      |
```
