집계 함수입니다.

count(distinct ...) 함수는 값 집합에서 고유한 값의 개수를 계산합니다.

적은 메모리와 시간으로 대규모 데이터 집합에서 추정 결과를 얻으려면 [APPROX_COUNT_DISTINCT](../aggregate-approx-count-distinct)를 사용해 보십시오.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.count_distinct(<column>)
```

## Analyze 예제

```python
func.count_distinct(table.category).alias('unique_categories')

| unique_categories |
|-------------------|
|         2         |
```

## SQL 구문

```sql
COUNT(distinct <expr> ...)
UNIQ(<expr>)
```

## 인수

| 인수 | 설명 |
|-----------|--------------------------------------------------|
| `<expr>`  | 모든 식이며, 인수의 개수는 [1, 32]입니다 |

## 반환 형식

UInt64

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**
```sql
CREATE TABLE products (
  id INT,
  name VARCHAR,
  category VARCHAR,
  price FLOAT
);

INSERT INTO products (id, name, category, price)
VALUES (1, 'Laptop', 'Electronics', 1000),
       (2, 'Smartphone', 'Electronics', 800),
       (3, 'Tablet', 'Electronics', 600),
       (4, 'Chair', 'Furniture', 150),
       (5, 'Table', 'Furniture', 300);
```

**쿼리 데모: 고유 카테고리 개수 세기**

```sql
SELECT COUNT(DISTINCT category) AS unique_categories
FROM products;
```

**결과**
```sql
| unique_categories |
|-------------------|
|         2         |
```
