[t-digest](https://github.com/tdunning/t-digest/blob/master/docs/t-digest-paper/histo.pdf) 알고리즘을 사용하여 숫자 데이터 시퀀스의 근사 분위수를 계산합니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.quantile_tdigest(<levels>, <expr>)
```

## Analyze 예제

```python
func.quantile_tdigest([0.5, 0.8], table.sales_amount).alias('sales_amounts')

| sales_amounts         |
|-----------------------+
| [6000.0,7000.0]       |
```

## SQL 구문

```sql
QUANTILE_TDIGEST(<level1>[, <level2>, ...])(<expr>)
```

## 인수

| 인수   | 설명                                                                                                                                     |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `<level n>` | 분위수의 수준은 0에서 1 사이의 부동 소수점 상수를 나타냅니다. [0.01, 0.99] 범위의 수준 값을 사용하는 것이 좋습니다.   |
| `<expr>`    | 모든 숫자 식                                                                                                                        |

## 반환 형식

지정한 분위수 수준의 개수에 따라 Float64 값 또는 Float64 값의 배열을 반환합니다.

## SQL 예제

```sql
-- Create a table and insert sample data
CREATE TABLE sales_data (
  id INT,
  sales_person_id INT,
  sales_amount FLOAT
);

INSERT INTO sales_data (id, sales_person_id, sales_amount)
VALUES (1, 1, 5000),
       (2, 2, 5500),
       (3, 3, 6000),
       (4, 4, 6500),
       (5, 5, 7000);

SELECT QUANTILE_TDIGEST(0.5)(sales_amount) AS median_sales_amount
FROM sales_data;

median_sales_amount|
-------------------+
             6000.0|

SELECT QUANTILE_TDIGEST(0.5, 0.8)(sales_amount)
FROM sales_data;

quantile_tdigest(0.5, 0.8)(sales_amount)|
----------------------------------------+
[6000.0,7000.0]                         |
```
