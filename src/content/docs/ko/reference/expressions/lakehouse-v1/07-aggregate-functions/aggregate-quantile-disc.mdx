집계 함수입니다.

`QUANTILE_DISC()` 함수는 숫자 데이터 시퀀스의 정확한 분위수를 계산합니다.
`QUANTILE`은 `QUANTILE_DISC`의 별칭입니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.quantile_disc(<levels>, <expr>)
```

## Analyze 예제

```python
func.quantile_disc([0.25, 0.75], table.salary).alias('salary_quantiles')

|  salary_quantiles   |
|---------------------|
| [55000.0, 65000.0]  |
```

## SQL 구문

```sql
QUANTILE_DISC(<levels>)(<expr>)
    
QUANTILE_DISC(level1, level2, ...)(<expr>)
```

## 인수

| 인수  | 설명                                                                                                                                   |
|------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| `level(s)` | 분위수의 수준입니다. 각 수준은 0에서 1 사이의 부동 소수점 상수입니다. [0.01, 0.99] 범위의 수준 값을 사용하는 것이 좋습니다. |
| `<expr>`   | 모든 숫자 식                                                                                                                      |

## 반환 형식

수준 개수에 따라 InputType 또는 InputType의 배열입니다.

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**
```sql
CREATE TABLE salary_data (
  id INT,
  employee_id INT,
  salary FLOAT
);

INSERT INTO salary_data (id, employee_id, salary)
VALUES (1, 1, 50000),
       (2, 2, 55000),
       (3, 3, 60000),
       (4, 4, 65000),
       (5, 5, 70000);
```

**쿼리 데모: 급여의 25번째 및 75번째 백분위수 계산**
```sql
SELECT QUANTILE_DISC(0.25, 0.75)(salary) AS salary_quantiles
FROM salary_data;
```

**결과**
```sql
|  salary_quantiles   |
|---------------------|
| [55000.0, 65000.0]  |
```
