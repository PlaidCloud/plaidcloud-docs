집계 함수입니다.

STRING_AGG() 함수는 열에서 NULL이 아닌 모든 값을 문자열로 변환하여 구분자로 구분해 연결합니다.

## Analyze 구문

```python
func.string_agg(<expr> [, delimiter])
```

## Analyze 예제

```python
func.string_agg(table.language_name).alias('concatenated_languages')

|          concatenated_languages         |
|-----------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```

## SQL 구문

```sql
STRING_AGG(<expr>)
STRING_AGG(<expr> [, delimiter])
```

<Aside>`<expr>`이 문자열 식이 아니면 `::VARCHAR`를 사용하여 변환해야 합니다. 예: ```sql SELECT string_agg(number::VARCHAR, '|') AS s FROM numbers(5); ┌───────────┐ │ s │ ├───────────┤ │ 0│1│2│3│4 │ └───────────┘ ```</Aside>

## 인수

| 인수   | 설명                                                         |
|-------------|---------------------------------------------------------------------|
| `<expr>`    | 모든 문자열 식(문자열이 아니면 `::VARCHAR`를 사용하여 변환) |
| `delimiter` | 선택적 문자열 상수이며, 지정하지 않으면 빈 문자열을 사용합니다.        |

## 반환 형식

문자열 형식입니다.

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**

```sql
CREATE TABLE programming_languages (
  id INT,
  language_name VARCHAR
);

INSERT INTO programming_languages (id, language_name)
VALUES (1, 'Python'),
       (2, 'JavaScript'),
       (3, 'Java'),
       (4, 'C#'),
       (5, 'Ruby');
```

**쿼리 데모: 구분자로 프로그래밍 언어 이름 연결**
```sql
SELECT STRING_AGG(language_name, ', ') AS concatenated_languages
FROM programming_languages;
```

**결과**
```sql
|          concatenated_languages         |
|------------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```
