집계 함수입니다.

MEDIAN() 함수는 숫자 데이터 시퀀스의 중앙값을 계산합니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.median(<expr>)
```

## Analyze 예제

```python
func.median(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## SQL 구문

```sql
MEDIAN(<expr>)
```

## 인수

| 인수 | 설명              |
|-----------|--------------------------|
| `<expr>`  | 모든 숫자 식 |

## 반환 형식

값의 형식입니다.

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**
```sql
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);
```

**쿼리 데모: 시험 점수 중앙값 계산**
```sql
SELECT MEDIAN(score) AS median_score
FROM exam_scores;
```

**결과**
```sql
|  median_score  |
|----------------|
|      85.0      |
```
