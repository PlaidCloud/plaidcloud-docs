집계 함수입니다.

STDDEV_SAMP() 함수는 식의 표본 표준 편차(VAR_SAMP()의 제곱근)를 반환합니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.stddev_samp(<expr>)
```

## Analyze 예제

```python
func.stddev_samp(table.height).alias('height_stddev_samp')

| height_stddev_samp |
|--------------------|
|      0.240         |
```

## SQL 구문

```sql
STDDEV_SAMP(<expr>)
```

## 인수

| 인수 | 설명              |
|-----------|--------------------------|
| `<expr>`  | 모든 숫자 식 |

## 반환 형식

double

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**
```sql
CREATE TABLE height_data (
  id INT,
  person_id INT,
  height FLOAT
);

INSERT INTO height_data (id, person_id, height)
VALUES (1, 1, 5.8),
       (2, 2, 6.1),
       (3, 3, 5.9),
       (4, 4, 5.7),
       (5, 5, 6.3);
```

**쿼리 데모: 키의 표본 표준 편차 계산**
```sql
SELECT STDDEV_SAMP(height) AS height_stddev_samp
FROM height_data;
```

**결과**
```sql
| height_stddev_samp |
|--------------------|
|      0.240         |
```
