집계 함수입니다.

SUM() 함수는 값 집합의 합계를 계산합니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>


## Analyze 구문

```python
func.sum(<column>)
```

## Analyze 예제

```python
func.sum(table.quantity).alias('total_quantity_sold')

| total_quantity_sold |
|---------------------|
|         41          |
```

## SQL 구문

```sql
SUM(<expr>)
```

## 인수

| 인수 | 설명              |
|-----------|--------------------------|
| `<expr>`  | 모든 숫자 식 |

## 반환 형식

입력 형식이 double이면 double이고, 그렇지 않으면 정수입니다.

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**
```sql
CREATE TABLE sales_data (
  id INT,
  product_id INT,
  quantity INT
);

INSERT INTO sales_data (id, product_id, quantity)
VALUES (1, 1, 10),
       (2, 2, 5),
       (3, 3, 8),
       (4, 4, 3),
       (5, 5, 15);
```

**쿼리 데모: 판매된 제품의 총 수량 계산**
```sql
SELECT SUM(quantity) AS total_quantity_sold
FROM sales_data;
```

**결과**
```sql
| total_quantity_sold |
|---------------------|
|         41          |
```
