집계 함수입니다.

QUANTILE_CONT() 함수는 숫자 데이터 시퀀스의 보간된 분위수를 계산합니다.

<Aside type="caution">NULL 값은 계산에 포함되지 않습니다.</Aside>

## Analyze 구문

```python
func.quantile_cont(<levels>, <expr>)
```

## Analyze 예제

```python
func.quantile_cont(0.5, table.sales_amount).alias('median_sales_amount')

|  median_sales_amount  |
|-----------------------|
|        6000.0         |
```

## SQL 구문

```sql
QUANTILE_CONT(<levels>)(<expr>)
    
QUANTILE_CONT(level1, level2, ...)(<expr>)
```

## 인수

| 인수   | 설명                                                                                                                                     |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `<level(s)` | 분위수의 수준입니다. 각 수준은 0에서 1 사이의 부동 소수점 상수입니다. [0.01, 0.99] 범위의 수준 값을 사용하는 것이 좋습니다.   |
| `<expr>`    | 모든 숫자 식                                                                                                                        |

## 반환 형식

수준 개수에 따라 Float64 또는 float64 배열입니다.

## SQL 예제

**테이블을 만들고 샘플 데이터 삽입**
```sql
CREATE TABLE sales_data (
  id INT,
  sales_person_id INT,
  sales_amount FLOAT
);

INSERT INTO sales_data (id, sales_person_id, sales_amount)
VALUES (1, 1, 5000),
       (2, 2, 5500),
       (3, 3, 6000),
       (4, 4, 6500),
       (5, 5, 7000);
```

**쿼리 데모: 보간을 사용하여 판매 금액의 50번째 백분위수(중앙값) 계산**
```sql
SELECT QUANTILE_CONT(0.5)(sales_amount) AS median_sales_amount
FROM sales_data;
```

**결과**
```sql
|  median_sales_amount  |
|-----------------------|
|        6000.0         |
```
