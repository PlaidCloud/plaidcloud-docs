RFC 3174(보안 해시 알고리즘)에 설명된 대로 문자열의 SHA-1 160비트 체크섬을 계산합니다. 값은 16진수 40자리 문자열로 반환되며, 인수가 NULL이면 NULL을 반환합니다.

## Analyze 구문

```python
func.sha(<expr>)
```

## Analyze 예제

```python
func.sha('1234567890')

┌──────────────────────────────────────────┐
│ func.sha('1234567890')                   │
├──────────────────────────────────────────┤
│ 01b307acba4f54f55aafc33bb06bbbf6ca803e9a │
└──────────────────────────────────────────┘
```

## SQL 구문

```sql
SHA(<expr>)
```

```sql
└─────────────────────────────────────────────────────────────────────────────────────┘
```
