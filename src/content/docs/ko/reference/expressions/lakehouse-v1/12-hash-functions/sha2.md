SHA-2 계열 해시 함수(SHA-224, SHA-256, SHA-384, SHA-512)를 계산합니다. 해시 길이가 허용되는 값이 아니면 반환값은 NULL입니다. 그렇지 않으면 함수 결과는 원하는 비트 수를 가진 해시 값을 16진수 문자열로 나타낸 것입니다.

## Analyze 구문

```python
func.sha2(<expr>, <expr>)
```

## Analyze 예제

```python
func.sha2('1234567890', 0)

┌──────────────────────────────────────────────────────────────────┐
│ func.sha2('1234567890', 0))                                      │
├──────────────────────────────────────────────────────────────────┤
│ c775e7b757ede630cd0aa1113bd102661ab38829ca52a6422ab782862f268646 │
└──────────────────────────────────────────────────────────────────┘
```

## SQL 구문

```sql
SHA2(<expr>, <expr>)
```

## SQL 예제

```sql
SELECT SHA2('1234567890', 0);

┌──────────────────────────────────────────────────────────────────┐
│                       sha2('1234567890', 0)                      │
├──────────────────────────────────────────────────────────────────┤
│ c775e7b757ede630cd0aa1113bd102661ab38829ca52a6422ab782862f268646 │
└──────────────────────────────────────────────────────────────────┘
```
