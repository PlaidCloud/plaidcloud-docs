문자열의 BLAKE3 256비트 체크섬을 계산합니다. 값은 16진수 64자리 문자열로 반환되며, 인수가 NULL이면 NULL을 반환합니다.

## Analyze 구문

```python
func.blake3(<expr>)
```

## Analyze 예제

```python
func.blake3('1234567890')

┌──────────────────────────────────────────────────────────────────┐
│ func.blake3('1234567890')                                        │
├──────────────────────────────────────────────────────────────────┤
│ d12e417e04494572b561ba2c12c3d7f9e5107c4747e27b9a8a54f8480c63e841 │
└──────────────────────────────────────────────────────────────────┘
```

## SQL 구문

```sql
BLAKE3(<expr>)
```

## SQL 예제

```sql
SELECT BLAKE3('1234567890');

┌──────────────────────────────────────────────────────────────────┐
│                       blake3('1234567890')                       │
├──────────────────────────────────────────────────────────────────┤
│ d12e417e04494572b561ba2c12c3d7f9e5107c4747e27b9a8a54f8480c63e841 │
└──────────────────────────────────────────────────────────────────┘
```
