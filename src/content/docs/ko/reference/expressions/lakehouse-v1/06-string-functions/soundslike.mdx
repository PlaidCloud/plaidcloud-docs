두 문자열의 Soundex 코드로 발음을 비교합니다. Soundex는 문자열의 발음을 나타내는 코드를 생성하는 음성 알고리즘으로, 철자가 아닌 발음을 기준으로 문자열을 근사 일치시킬 수 있습니다. PlaidCloud Lakehouse는 문자열에서 Soundex 코드를 얻을 수 있는 [SOUNDEX](../soundex) 함수를 제공합니다.

SOUNDS LIKE는 이름이나 주소처럼 퍼지 문자열 일치로 행을 좁히기 위해 SQL 쿼리의 WHERE 절에서 자주 사용됩니다. [예제](#행-필터링)의 [행 필터링](#sql-예제)을 참조하십시오.

<Aside>이 함수는 근사 문자열 일치에 유용할 수 있지만 항상 정확한 것은 아니라는 점에 유의해야 합니다. Soundex 알고리즘은 영어 발음 규칙을 기반으로 하므로 다른 언어나 방언의 문자열에는 잘 작동하지 않을 수 있습니다.</Aside>

## Analyze 구문

```python
func.sounds_like(<str1>, <str2>)
```

## Analyze 예제

```python
func..sounds_like('Monday', 'Sunday')
┌───────────────────────────────────────┐
│ func..sounds_like('Monday', 'Sunday') │
├───────────────────────────────────────┤
│                                     0 │
└───────────────────────────────────────┘
```

## SQL 구문

```sql
<str1> SOUNDS LIKE <str2>
```

## 인수

| 인수 | 설명 |
|-----------|-------------|
| str1, 2   | 비교할 문자열입니다. |

## 반환 형식

두 문자열의 Soundex 코드가 같으면(즉, 발음이 비슷하면) Boolean 값 1을, 그렇지 않으면 0을 반환합니다.

## SQL 예제

### 문자열 비교

```sql
SELECT 'two' SOUNDS LIKE 'too'
----
1

SELECT CONCAT('A', 'B') SOUNDS LIKE 'AB';
----
1

SELECT 'Monday' SOUNDS LIKE 'Sunday';
----
0
```

### 행 필터링

```sql
SELECT * FROM  employees;

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Mark      |Smythe   | 28|
 0|Johann    |Schmidt  | 51|
 0|Eric      |Doe      | 30|
 0|Sue       |Johnson  | 45|


SELECT * FROM  employees
WHERE  first_name SOUNDS LIKE 'John';

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Johann    |Schmidt  | 51|
```
