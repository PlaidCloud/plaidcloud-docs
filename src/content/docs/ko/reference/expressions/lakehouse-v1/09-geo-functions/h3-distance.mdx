지정한 두 [H3](https://eng.uber.com/h3/) 인덱스 사이의 그리드 거리를 반환합니다.

<Aside>H3 거리 계산은 이웃한 육각형 사이의 거리만 계산할 수 있습니다. 이웃하지 않은 육각형에 사용하면 오류가 발생합니다.</Aside>

### Analyze 구문

```python
func.h3_distance(h3, a_h3)
```

## Analyze 예제

```python
func.h3_distance(599119489002373119, 599119491149856767)

┌──────────────────────────────────────────────────────────┐
│ func.h3_distance(599119489002373119, 599119491149856767) │
├──────────────────────────────────────────────────────────┤
│                                                        1 │
└──────────────────────────────────────────────────────────┘
```

## SQL 구문

```sql
H3_DISTANCE(h3, a_h3)
```

## SQL 예제

```sql
SELECT H3_DISTANCE(599119489002373119, 599119491149856767);

┌─────────────────────────────────────────────────────┐
│ h3_distance(599119489002373119, 599119491149856767) │

```
