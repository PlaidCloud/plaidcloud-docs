현재 그룹화 집합에 포함되지 않은 `GROUP BY` 식을 나타내는 비트 마스크를 반환합니다. 가장 오른쪽 인수가 최하위 비트에 해당하도록 비트가 할당되며, 각 비트는 해당 식이 현재 결과 행을 생성하는 그룹화 집합의 그룹화 기준에 포함되어 있으면 0, 포함되어 있지 않으면 1입니다.

## SQL 구문

```sql
GROUPING ( expr [, expr, ...] )
```

<Aside>`GROUPING`은 `GROUPING SETS`, `ROLLUP` 또는 `CUBE`와 함께만 사용할 수 있으며, 인수는 그룹화 집합 목록에 있어야 합니다.</Aside>

## 인수

그룹화 집합 항목.

## 반환 유형

UInt32.

## SQL 예제

```sql
select a, b, grouping(a), grouping(b), grouping(a,b), grouping(b,a) from t group by grouping sets ((a,b),(a),(b), ()) ;
┌──────┬──────┬─────────────┬─────────────┬────────────────┬────────────────┐
│ a    │ b    │ grouping(a) │ grouping(b) │ grouping(a, b) │ grouping(b, a) │
├──────┼──────┼─────────────┼─────────────┼────────────────┼────────────────┤
│ NULL │ A    │           1 │           0 │              2 │              1 │
│ a    │ NULL │           0 │           1 │              1 │              2 │
│ b    │ A    │           0 │           0 │              0 │              0 │
│ NULL │ NULL │           1 │           1 │              3 │              3 │
│ a    │ A    │           0 │           0 │              0 │              0 │
│ b    │ B    │           0 │           0 │              0 │              0 │
│ b    │ NULL │           0 │           1 │              1 │              2 │
│ a    │ B    │           0 │           0 │              0 │              0 │
│ NULL │ B    │           1 │           0 │              2 │              1 │
└──────┴──────┴─────────────┴─────────────┴────────────────┴────────────────┘
```
