수학 상수 파이를 반환합니다.

## Analyze 구문

```python
func.pi()
```

## Analyze 예제

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## SQL 구문

```sql
PI()
```

## SQL 예제

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
