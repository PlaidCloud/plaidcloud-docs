수학 상수 e(오일러 수)를 반환합니다.

## Analyze 구문

```python
func.e()
```

## Analyze 예제

```python
func.e()

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## SQL 구문

```sql
E()
```

## SQL 예제

```sql
SELECT E();

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
