## 설명

**Lakehouse** 영역에서는 PlaidCloud를 벗어나지 않고도 워크스페이스의 Lakehouse 컴퓨팅과 Iceberg 카탈로그를 클릭만으로 관리할 수 있습니다. 메인 도구 모음의 **Lakehouse** 버튼에서 엽니다.

창 상단의 창고 선택기는 모든 탭에 적용됩니다. 이 영역은 **쿼리**, **프로필**, **카탈로그**, **창고**, **사용자**, **로드**, **관리자**의 일곱 개 탭으로 구성됩니다.


## 쿼리

실행 중인 쿼리를 모니터링하고 기록을 탐색합니다. 이 탭은 이동할 수 있는 구분선으로 위아래로 나뉩니다.

* **실행 중** — 현재 실행 중인 쿼리입니다. 도구 모음에서 선택한 간격으로 자동 폴링합니다.
* **기록** — 최근에 완료된 쿼리입니다.

**쿼리 계획을 보려면:**

1. 행 시작 부분의 `Profile` 아이콘을 클릭합니다.
2. 쿼리 SQL이 **프로필** 탭에 로드되며, 여기서 EXPLAIN 또는 EXPLAIN ANALYZE를 실행할 수 있습니다.

**실행 중인 쿼리를 종료하려면:**

1. **실행 중** 테이블에서 행을 하나 이상 선택합니다.
2. 도구 모음에서 `Kill selected`를 클릭합니다.
3. 대화 상자에서 확인합니다.


## 프로필

SQL 문에 `EXPLAIN` 또는 `EXPLAIN ANALYZE`를 실행하고, 결과 계획을 히트맵 트리로 시각화합니다.

1. **Lakehouse > 프로필**을 엽니다.
2. SQL 문을 붙여넣거나 입력합니다.
3. `EXPLAIN`(계획만) 또는 `EXPLAIN ANALYZE`(계획 + 실제 행 수와 소요 시간)를 클릭합니다.

계획 트리에서 비용이 가장 큰 노드가 강조 표시되므로 느린 쿼리의 병목 지점을 한눈에 확인할 수 있습니다.


## 카탈로그

선택한 창고의 Iceberg 카탈로그를 탐색합니다. 이 창에는 왼쪽에 네임스페이스가, 오른쪽에 테이블이 나열되며, 생성/삭제 작업을 위한 작업 표시줄이 있습니다.

**네임스페이스를 생성하려면:**

1. **Lakehouse > 카탈로그**를 엽니다.
2. `New namespace`를 클릭합니다.
3. 네임스페이스 이름을 입력하고 확인합니다.

**테이블을 삭제하려면:**

1. 네임스페이스를 선택한 다음 테이블을 선택합니다.
2. `Drop table`을 클릭합니다.
3. 대화 상자에서 확인합니다.

탭 하단의 삭제된 테이블 목록에서는 복구할 수 있는 동안 최근에 삭제된 테이블을 `UNDROP`할 수 있습니다.

<Aside>선택한 창고가 워크스페이스 기본값이면 파괴적인 작업(네임스페이스 삭제, 테이블 삭제)은 비활성화됩니다.</Aside>


## 창고

Lakehouse를 뒷받침하는 Iceberg 창고를 생성, 조회, 삭제합니다.

**창고를 생성하려면:**

1. **Lakehouse > 창고**를 엽니다.
2. `Add warehouse`를 클릭합니다.
3. 창고 이름과 스토리지 구성을 입력합니다.
4. `Add`를 클릭합니다.

**창고를 삭제하려면:**

1. 창고 행을 선택합니다.
2. `Delete`를 클릭합니다.
3. 대화 상자에서 확인합니다.

<Aside>기본 창고는 보호되므로 삭제할 수 없습니다.</Aside>

<Aside title="유휴 창고는 자동으로 축소됩니다">창고의 쿼리 실행 용량은 일정 시간 유휴 상태가 되면 작은 최소 수준으로 축소되고, 쿼리가 다시 들어오면 자동으로 확장됩니다. 따라서 사용하지 않는 유휴 용량은 하루 종일 과금되지 않고 해제됩니다. 한 가지 알아 둘 점은 한동안 유휴 상태였던 창고에 대한 첫 번째 쿼리는 용량이 다시 온라인 상태가 되는 동안 시간이 조금 더 걸릴 수 있다는 것입니다. 꾸준히 또는 많이 사용되는 창고는 영향을 받지 않으며, 창고에는 계속 접속할 수 있습니다. 이 기능으로 창고가 오프라인 상태가 되는 일은 없습니다.</Aside>


## 사용자

DBeaver 등의 외부 SQL 클라이언트에서 Lakehouse에 연결하는 데이터베이스 사용자를 관리합니다. 비밀번호 기반 사용자와 SSO로 프로비저닝된 사용자가 모두 나열됩니다.

**사용자를 추가하려면:**

1. **Lakehouse > 사용자**를 엽니다.
2. `Add user`를 클릭합니다.
3. 사용자 이름과 비밀번호를 입력합니다.
4. `Add`를 클릭합니다.
5. 비밀번호를 저장하십시오. 비밀번호는 한 번만 표시되며 나중에 다시 확인할 수 없습니다.

**비밀번호를 재설정하려면:**

1. 사용자 행을 선택합니다.
2. `Reset password`를 클릭합니다.
3. 대화 상자에 표시된 새 비밀번호를 저장합니다.

**사용자를 제거하려면:**

1. 사용자 행을 선택합니다.
2. `Drop user`를 클릭합니다.
3. 대화 상자에서 확인합니다.


## 로드

클러스터 활동을 한눈에 확인합니다. 이 탭에는 카운터 행(활성 쿼리, 최근 처리량)이 표시되고, 그 아래에 **쿼리** 탭과 동일한 폴링 간격으로 샘플링한 스파크라인이 표시됩니다.


## 관리자

컴퓨팅 워크로드 상태를 검사하고, 필요할 때 창고 컴퓨팅을 다시 시작합니다.

워크로드 테이블에는 각 구성 요소와 현재 상태가 나열됩니다. **순차 재시작** 섹션에서는 선택한 창고의 컴퓨팅 포드를 순환 재시작할 수 있습니다.

**컴퓨팅을 다시 시작하려면:**

1. **Lakehouse > 관리자**를 엽니다.
2. 중단 경고를 읽습니다.
3. 확인 필드에 창고 ID를 입력합니다.
4. `Restart compute`를 클릭합니다.

재시작 사이의 대기 시간은 실수로 연속 재시작하는 것을 방지합니다. 남은 대기 시간은 버튼 옆에 표시됩니다.

<Aside>순차 재시작은 활성 세션을 잠시 중단시킵니다. 확인하기 전에 사용자와 조율하십시오.</Aside>

<Aside title="유휴 축소와 실행 중인 쿼리">자동 유휴 축소(위의 **창고** 참조)는 쿼리 활동이 없는 상태가 오래 지속된 후에만 작동하므로 진행 중인 쿼리를 중단시키지 않습니다. 특정 워크스페이스의 창고를 항상 최대 용량으로 유지하려면 PlaidCloud 지원팀에 문의하여 해당 워크스페이스에서 이 기능을 끄도록 요청하십시오.</Aside>
