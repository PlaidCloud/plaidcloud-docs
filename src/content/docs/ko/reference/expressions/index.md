- [Lakehouse v1 식](./lakehouse-v1/) — Databend SQL 함수를 기반으로 한 PlaidCloud Lakehouse의 1세대입니다.
- [Lakehouse v2 식](./lakehouse-v2/) — StarRocks 4.1 SQL 함수를 기반으로 하며 Apache Iceberg 오픈 테이블 형식을 사용하는 PlaidCloud Lakehouse의 2세대입니다.

## 정식 구문을 찾아볼 곳

PlaidCloud Lakehouse는 기반 엔진의 SQL 함수 라이브러리를 사용합니다. 함수의 인수, 예외 상황, 최신 동작에 대한 자세한 내용은 여기에 있는 PlaidCloud 방식의 예제와 함께 업스트림 문서를 참조하십시오.

- **Lakehouse v1** → [Databend SQL 함수 레퍼런스](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [StarRocks SQL 함수 레퍼런스](https://docs.starrocks.io/docs/sql-reference/sql-functions/) (PlaidCloud Lakehouse v2는 StarRocks 4.1을 따릅니다)
