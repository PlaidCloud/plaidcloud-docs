## 추가됨

- **단계 양식의 미리 보기.** 가져오기: SQL, 실행: SQL, 추출: SQL, 내보내기: SQL 및 Salesforce 쿼리 단계는 단계를 실행하지 않고도 최대 100개 행을 표시하며, Anaplan 뷰 및 목록 읽기 단계는 생성될 열과 유형을 표시합니다. **소스** 탭에서 **미리 보기**를 클릭하십시오. 변수는 실행 시와 동일하게 채워지지만 `{x:>9}`와 같은 변수 형식은 지원되지 않습니다. 미리 보기는 표준 SQL 함수만 실행하며, 그 외의 경우에는 단계를 실행하라고 안내합니다. 잠긴 프로젝트나 에이전트 기반 SQL 실행 단계에서는 사용할 수 없습니다. [SQL 가져오기](/ko/reference/workflow-steps/import/import-sql/) 및 [SQL 추출](/ko/reference/workflow-steps/tables/table-extract-sql/)을 참조하십시오.
- **AI 어시스턴트가 테이블 게시를 취소하고 프로젝트의 기본 대시보드 대상을 설정할 수 있습니다.** `publish_manage`는 테이블의 게시를 취소하면서 게시된 뷰와 어떤 차트에서도 사용하지 않는 대시보드 데이터 세트도 함께 게시 취소합니다. 차트에서 아직 사용 중인 데이터 세트는 유지되며, 게시된 뷰를 기반으로 보고서 뷰가 만들어진 경우에도 뷰와 데이터 세트는 유지되지만 테이블의 게시는 취소됩니다. `project_upsert`는 프로젝트의 새 대시보드를 공유할 그룹인 `dashboard_default_audience`를 설정하며, `[]`로 지정하면 이 값이 지워집니다. [게시 취소](/ko/guides/data/publish/#ai-어시스턴트-또는-mcp로-게시-취소) 및 [AI 어시스턴트 또는 MCP를 통해 기본 대상 설정](/ko/guides/dashboards/control-who-can-see-a-dashboard/#ai-어시스턴트-또는-mcp로-기본-대상-설정)을 참조하십시오.

- **모바일 Weave의 음성 입력을 한 번의 탭으로 사용할 수 있습니다.** 마이크를 탭하고 질문하면, 말을 멈추는 즉시 Weave가 질문을 보냅니다. 일찍 중지하려면 마이크를 다시 탭하십시오. 아무 소리도 들리지 않으면 자동으로 꺼집니다. 말하는 도중에 **Weave** 탭을 벗어나거나 앱을 백그라운드로 전환하면, 입력한 내용은 보내지 않은 상태로 질문 상자에 남아 있어 검토할 수 있습니다. 실행, 일시 중지, 중지 및 다시 시작은 확인 단계에서 실수로 두 번 탭한 것을 무시합니다. 앱 버전 1.3.0 이상이 필요합니다. [음성 사용](/ko/guides/mobile-app/weave-on-mobile/#음성-사용)을 참조하십시오.

## 변경됨

- **단계 양식이 하나의 레이아웃을 따릅니다.** 탭은 일반, 설정, 소스, 열, 필터, 출력, 고급의 표준 이름과 표준 순서를 따르며, ERP 전기 양식에는 헤더 열과 라인 열이 있습니다. 필수 필드는 *로 표시되며, 양식은 단계에 필요한 항목에 대해서만 저장을 막습니다.
- **행 작업 메뉴(⋯)가 모든 그리드 행의 왼쪽 가장자리에 있습니다.**
- **검증 설정이 없는 저장된 ERP 쓰기 단계는 검증 전용으로 열립니다.** 여기에는 SAP 전기, SAP 첨부, NetSuite 전기, Oracle EBS GL 및 AP 전기, Xero 내보내기가 포함됩니다. 실제 실행으로 명시적으로 설정된 단계는 그대로 실제 실행됩니다.
- **장시간 실행되는 작업의 진행률이 모든 곳에서 동일한 방식으로 표시됩니다.**
- **워크스페이스를 업그레이드하면 REST, REST 가져오기 및 Postman 가져오기 단계가 REST 요청 단계로 변환됩니다.** 깔끔하게 변환할 수 없는 단계는 그대로 유지됩니다. [REST 요청 단계](/ko/guides/workflows/rest-request-step/)를 참조하십시오.
- **프로젝트 아키텍트는 대시보드에서 행이 제한된 테이블의 모든 행을 볼 수 있으며**, 이는 Analyze에서 보는 내용과 일치합니다. 아키텍트 액세스 권한을 제거하면 대시보드에 즉시 적용됩니다. 사용자의 역할을 변경하거나, 사용자 또는 그 그룹을 프로젝트에서 제거하거나, 프로젝트의 액세스 유형을 변경하거나, 이전 프로젝트 버전을 복원하거나, 보안 그룹을 삭제하는 경우 모두 해당됩니다. 이전 아키텍트는 더 이상 행이 제한된 데이터의 모든 행을 볼 수 없습니다. [행 액세스 관리](/ko/administration/access/managing-security-groups-and-assignments/#행-액세스-관리)를 참조하십시오.
- **세션이 만료된 후 연 대시보드 링크는 로그인하면 해당 대시보드로 이동합니다.** [대시보드 사용](/ko/guides/dashboards/using-dashboards/)을 참조하십시오.
- **MCP 도구는 인식하지 못하는 필드를 무시하지 않고 거부하며** 오류 메시지에 해당 필드 이름을 표시합니다. `workflow_upsert`는 `memo`를 받으며 `description`도 같은 필드의 다른 이름으로 허용합니다. [알 수 없는 필드는 거부됨](/ko/integrations/ai-coding-agents/getting-started/#알-수-없는-필드는-거부됩니다)을 참조하십시오.

## 수정됨

- **잘못된 프로젝트 설정이 명확한 메시지로 보고됩니다.** 알 수 없는 환경 또는 문서 계정, 이미 사용 중이거나 예약된 슬러그, 잘못된 스토리지 유형 또는 전기 모드에 대해 이제 일반적인 서버 오류 대신 문제를 명시하는 메시지를 반환합니다. REST API를 통해서는 500 대신 400을 반환하며, AI 어시스턴트 또는 MCP를 통해서는 잘못된 인수 오류를 반환합니다.
- **REST API의 차원 값 요청이 작동합니다.** `POST /rest/v1/analyze/query/retrieve-dimension-values`가 그리드 요청으로 처리되어 잘못된 요청으로 거부되었습니다. 이제 `value_columns`의 각 열에 대해 집계된 값 하나를 반환하며, 행 필터와 열 필터의 각 쌍마다 값 하나를 반환하는 그리드에는 별도의 `POST /rest/v1/analyze/query/retrieve-dimension-cells`가 있습니다.
- **느린 테이블 읽기 및 파일 처리가 더 이상 다른 요청을 지연시키지 않습니다.** 웨어하우스에서 테이블의 열을 읽거나, Data Foundation 파일을 등록하거나, Excel로 내보내거나, REST 또는 SOAP 가져오기의 응답을 읽거나, 문서 계정이 사용되는 위치를 찾거나, Panel 앱의 코드 또는 로고를 확인하는 작업은 각각 완료될 때까지 같은 서버가 처리하던 다른 모든 요청을 일시 중지시킬 수 있었습니다. 이제 이러한 작업은 다른 요청과 함께 실행됩니다.
- **프로젝트 및 워크플로 변수 대화 상자를 스크롤할 수 있습니다.** 작은 화면이나 낮은 해상도에서는 추가 및 편집 대화 상자가 창보다 커서 **만들기** 및 **업데이트** 버튼에 접근하지 못할 수 있었습니다. 이제 양식이 스크롤되며 버튼은 하단에 유지됩니다.
