## 추가됨

- **단계 양식의 미리 보기.** Import: SQL, Execute: SQL, Extract: SQL, Export: SQL 및 Salesforce Query는 단계를 실행하지 않고도 최대 100개 행을 표시하며, Anaplan 뷰 및 목록 읽기는 생성될 열과 유형을 표시합니다. **소스** 탭에서 **미리 보기**를 클릭합니다. 변수는 실행 시와 같은 방식으로 채워지지만 `{x:>9}`와 같은 변수 형식은 지원되지 않습니다. 미리 보기는 표준 SQL 함수만 실행하며, 그렇지 않으면 단계를 실행하라는 메시지가 표시됩니다. 잠긴 프로젝트나 에이전트 기반 Execute SQL 단계에서는 사용할 수 없습니다. [SQL 가져오기](/ko/reference/workflow-steps/import/import-sql/)와 [SQL 추출](/ko/reference/workflow-steps/tables/table-extract-sql/)을 참조하십시오.
- **AI 어시스턴트가 테이블 게시를 취소하고 프로젝트의 기본 대시보드 대상을 설정할 수 있습니다.** `publish_manage`는 테이블의 게시를 취소하면서 게시된 뷰와 어떤 차트도 사용하지 않는 대시보드 데이터셋도 함께 제거합니다. 차트가 아직 사용 중인 데이터셋은 유지되고, 보고서 뷰가 게시된 뷰를 기반으로 만들어진 경우 해당 뷰와 데이터셋도 유지되지만 테이블의 게시는 취소됩니다. `project_upsert`는 프로젝트의 새 대시보드를 공유할 그룹인 `dashboard_default_audience`를 설정하며, `[]`는 이를 지웁니다. [게시 취소](/ko/guides/data/publish/#ai-어시스턴트-또는-mcp로-게시-취소)와 [AI 어시스턴트 또는 MCP로 기본 대상 설정](/ko/guides/dashboards/control-who-can-see-a-dashboard/#ai-어시스턴트-또는-mcp로-기본-대상-설정)을 참조하십시오.

- **모바일의 Weave 음성이 한 번의 탭으로 작동합니다.** 마이크를 탭하고 질문을 말하면 말을 멈춘 뒤 Weave가 질문을 전송합니다. 마이크를 다시 탭하면 중간에 끝낼 수 있으며, 아무 소리도 들리지 않으면 자동으로 꺼집니다. 말하는 도중에 **Weave** 탭을 떠나거나 앱을 백그라운드로 보내면, 말한 내용이 전송되지 않은 채 질문 입력란에 남아 검토할 수 있습니다. 실행, 일시 중지, 중지, 재개는 확인 단계에서 실수로 두 번 탭해도 무시합니다. 앱 버전 1.3.0 이상이 필요합니다. [음성 사용](/ko/guides/mobile-app/weave-on-mobile/#음성-사용)을 참조하십시오.

## 변경됨

- **단계 양식이 하나의 레이아웃을 따릅니다.** 탭은 일반, 설정, 소스, 열, 필터, 출력, 고급의 표준 이름과 표준 순서를 사용하며, ERP 전기 양식에는 헤더 열과 라인 열이 추가됩니다. 필수 필드는 *로 표시되고, 양식은 단계에 필요한 항목에 대해서만 저장을 차단합니다.
- **행 작업 메뉴(⋯)가 모든 그리드 행의 왼쪽 가장자리에 있습니다.**
- **검증 설정이 없는 저장된 ERP 쓰기 단계는 검증 전용으로 열립니다.** SAP Post, SAP Attach, NetSuite Post, Oracle EBS GL 및 AP Post, Xero 내보내기가 해당됩니다. 실제 실행으로 명시적으로 설정된 단계는 그대로 실제 실행됩니다.
- **오래 걸리는 작업의 진행률이 모든 곳에서 같은 방식으로 표시됩니다.**
- **워크스페이스를 업그레이드하면 REST, Import REST, Import Postman 단계가 REST 요청으로 변환됩니다.** 깔끔하게 변환할 수 없는 단계는 그대로 유지됩니다. [REST 요청 단계](/ko/guides/workflows/rest-request-step/)를 참조하십시오.
- **프로젝트 아키텍트는 대시보드에서 행이 제한된 테이블의 모든 행을 볼 수 있으며**, 이는 Analyze에서 보는 내용과 일치합니다. 아키텍트 액세스를 제거하면 대시보드에 즉시 반영됩니다. 누군가의 역할을 변경하거나, 사용자 또는 그룹을 프로젝트에서 제거하거나, 프로젝트의 액세스 유형을 변경하거나, 이전 프로젝트 버전을 복원하거나, 보안 그룹을 삭제하는 경우가 모두 해당됩니다. 이전 아키텍트는 더 이상 행이 제한된 데이터의 모든 행을 볼 수 없습니다. [행 액세스 관리](/ko/administration/access/managing-security-groups-and-assignments/#행-액세스-관리)를 참조하십시오.
- **세션이 만료된 후 열린 대시보드 링크는 로그인하면 해당 대시보드로 이동합니다.** [대시보드 사용](/ko/guides/dashboards/using-dashboards/)을 참조하십시오.
- **MCP 도구는 인식하지 못하는 필드를 무시하는 대신 거부하고** 오류에 해당 필드 이름을 표시합니다. `workflow_upsert`는 `memo`를 받으며 `description`도 같은 필드의 다른 이름으로 허용합니다. [알 수 없는 필드는 거부됩니다](/ko/integrations/ai-coding-agents/getting-started/#알-수-없는-필드는-거부됩니다)를 참조하십시오.

## 수정됨

- **잘못된 프로젝트 설정이 명확한 메시지로 보고됩니다.** 알 수 없는 환경 또는 문서 계정, 이미 사용 중이거나 예약된 슬러그, 잘못된 스토리지 유형 또는 전기 모드는 이제 일반적인 서버 오류 대신 문제를 알려 주는 메시지를 반환합니다. REST API에서는 500이 아닌 400이며, AI 어시스턴트나 MCP에서는 잘못된 인수 오류입니다.
- **REST API의 차원 값 요청이 작동합니다.** `POST /rest/v1/analyze/query/retrieve-dimension-values` 요청은 그리드 요청으로 처리되어 유효하지 않은 요청으로 거부되었습니다. 이제 이 요청은 `value_columns`의 각 열에 대해 집계된 값 하나를 반환하며, 행 필터와 열 필터의 각 쌍마다 값 하나를 반환하는 그리드에는 별도의 `POST /rest/v1/analyze/query/retrieve-dimension-cells` 엔드포인트가 있습니다.
- **느린 테이블 읽기와 파일 처리가 더 이상 다른 요청을 지연시키지 않습니다.** 웨어하우스에서 테이블의 열을 읽거나, Data Foundation 파일을 등록하거나, Excel로 내보내거나, REST 또는 SOAP 가져오기의 응답을 읽거나, 문서 계정이 사용되는 위치를 찾거나, Panel 앱의 코드 또는 로고를 확인하는 작업은 각각 완료될 때까지 같은 서버에서 처리 중이던 다른 모든 요청을 멈추게 할 수 있었습니다. 이제 이러한 작업은 다른 요청과 동시에 실행됩니다.
- **프로젝트 및 워크플로 변수 대화 상자가 스크롤됩니다.** 작은 화면이나 낮은 해상도에서는 추가 및 편집 대화 상자가 창보다 길어서 **만들기** 및 **업데이트** 버튼에 닿지 못할 수 있었습니다. 이제 양식이 스크롤되며 버튼은 아래쪽에 그대로 유지됩니다.

## 보안

- **계정 소유자만 이전 버전을 복원할 수 있습니다.** 문서 계정을 이전 버전으로 복원하거나, 버전을 보류하거나 보류 해제하거나, 백업을 만들려면 해당 계정의 소유자여야 하며, 시스템에서 관리하는 계정에서는 이 중 어느 것도 사용할 수 없습니다. 계정의 버전 기록을 보려면 해당 계정에 대한 액세스 권한이 필요합니다.
