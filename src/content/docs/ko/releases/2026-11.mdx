## 추가됨

- **단계 양식의 미리 보기.** 가져오기: SQL, 실행: SQL, SQL 추출, 내보내기: SQL, Salesforce 쿼리 단계는 단계를 실행하지 않고 최대 100개 행을 표시하며, Anaplan 뷰 및 목록 읽기는 생성될 열과 유형을 표시합니다. **소스** 탭에서 **미리 보기**를 클릭하십시오. 변수는 실행 시와 동일하게 채워지지만 `{x:>9}` 같은 변수 형식은 지원되지 않습니다. 쿼리를 받는 단계의 경우 미리 보기는 표준 SQL 함수만 실행하며, 그렇지 않으면 단계를 실행하라고 안내합니다. 잠긴 프로젝트나 에이전트 기반 Execute SQL 단계에서는 사용할 수 없습니다. [SQL 가져오기](/ko/reference/workflow-steps/import/import-sql/) 및 [SQL 추출](/ko/reference/workflow-steps/tables/table-extract-sql/)을 참조하십시오.
- **AI 어시스턴트가 테이블 게시를 취소하고 프로젝트의 기본 대시보드 대상을 설정할 수 있습니다.** `publish_manage`는 테이블의 게시를 취소하면서 게시된 뷰와 차트에서 사용하지 않는 대시보드 데이터 세트도 함께 제거합니다. 차트가 아직 사용하는 데이터 세트는 유지되며, 게시된 뷰를 기반으로 보고서 뷰가 만들어진 경우 해당 뷰와 데이터 세트도 유지되지만 테이블의 게시는 취소됩니다. `project_upsert`는 프로젝트의 새 대시보드를 공유할 그룹인 `dashboard_default_audience`를 설정하며, `[]`는 이 값을 지웁니다. [게시 취소](/ko/guides/data/publish/#ai-어시스턴트-또는-mcp로-게시-취소) 및 [AI 어시스턴트 또는 MCP로 기본 대상 설정](/ko/guides/dashboards/control-who-can-see-a-dashboard/#ai-어시스턴트-또는-mcp로-기본-대상-설정)을 참조하십시오.

## 변경됨

- **단계 양식이 하나의 레이아웃을 따릅니다.** 탭은 일반, 설정, 소스, 열, 필터, 출력, 고급의 표준 이름과 표준 순서를 사용하며, ERP 전기 양식에는 헤더 열과 라인 열이 추가됩니다. 필수 필드는 *로 표시되며, 양식은 단계에 필요한 항목에 대해서만 저장을 막습니다.
- **행 작업 메뉴(⋯)가 모든 그리드 행의 왼쪽 끝에 있습니다.**
- **검증 설정이 없는 저장된 ERP 쓰기 단계는 검증 전용으로 열립니다.** SAP Post, SAP Attach, NetSuite Post, Oracle EBS GL 및 AP Post, Xero 내보내기가 해당합니다. 명시적으로 실제 실행으로 설정된 단계는 그대로 실제 실행됩니다.
- **장기 실행 작업이 모든 곳에서 동일한 방식으로 진행 상황을 표시합니다.**
- **워크스페이스를 업그레이드하면 REST, Import REST, Import Postman 단계가 REST 요청으로 변환됩니다.** 깔끔하게 변환할 수 없는 단계는 그대로 유지됩니다. [REST 요청 단계](/ko/guides/workflows/rest-request-step/)를 참조하십시오.
- **프로젝트 아키텍트는 대시보드에서 행이 제한된 테이블의 모든 행을 봅니다.** Analyze에서 보는 내용과 동일합니다. 누군가의 아키텍트 액세스를 제거하면 약 1분 후, 경우에 따라 최대 15분 후에 적용됩니다. [행 액세스 관리](/ko/administration/access/managing-security-groups-and-assignments/#행-액세스-관리)를 참조하십시오.
- **세션이 만료된 후 대시보드 링크를 열면 로그인 후 해당 대시보드로 이동합니다.** [대시보드 사용](/ko/guides/dashboards/using-dashboards/)을 참조하십시오.
- **MCP 도구는 인식하지 못하는 필드를 무시하는 대신 거부하고** 오류에 해당 필드를 명시합니다. `workflow_upsert`는 `memo`를 받으며 `description`을 같은 필드의 다른 이름으로 허용합니다. [알 수 없는 필드는 거부됩니다](/ko/integrations/ai-coding-agents/getting-started/#알-수-없는-필드는-거부됩니다)를 참조하십시오.
