## 이 노트를 작성하는 방법

각 월별 요약은 해당 달에 테넌트에 배포된 주요 변경 사항을 모아 정리한 것입니다. 이미지 업데이트, 내부 리팩터링, RC 작성, 시크릿 교체, 관측성 조정과 같은 순수 인프라 작업은 항목별로 나열하지 않고 주제 레이블로 묶습니다. 고객에게 보이는 기능이 있었던 달은 추가됨 / 변경됨 / 수정됨 / 보안 구조로 명시적으로 설명합니다.

특정 릴리스에 대한 자세한 내용은 담당 계정 팀에 문의하십시오.

앞으로 새로운 월별 요약은 게시되는 대로 여기에 추가됩니다.
