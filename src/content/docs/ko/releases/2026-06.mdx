## 추가 사항

- **멀티 에이전트 AI 어시스턴트** — 어시스턴트가 이제 하나의 오케스트레이터 뒤에서 전문화된 하위 에이전트를 조율하여, 데이터 질문에 더 정확하고 더 근거 있는 답변을 제공합니다.
- **채팅 내 시각적 설명** — 어시스턴트가 답변을 설명하기 위해 다이어그램과 인라인 차트를 생성할 수 있으므로, 복잡한 결과도 한눈에 이해하기 쉽습니다.
- **LLM 단계** — 여러 제공업체와 액세스 수준을 지원하는 대규모 언어 모델을 워크플로의 단계로 직접 호출합니다.
- **설명으로 SQL 추출 생성** — 원하는 결과를 일상 언어로 설명하면 어시스턴트가 관련 소스 테이블까지 골라 쿼리를 작성해 줍니다. 생성된 SQL과 감지된 열은 저장하기 전에 자유롭게 편집할 수 있습니다.
- **어시스턴트로 테이블 내보내기** — 어시스턴트에게 테이블을 내보내 달라고 요청하면 다시 실행할 수 있는 내보내기 단계를 만들어 주며, 파일 형식은 선택한 확장자(CSV, TSV, Excel, Parquet, JSON, XML)에 따라 결정됩니다.
- **140개 이상의 새 데이터 커넥터** — 지원하는 데이터 소스를 대폭 확장했으며, 안내에 따른 연결 설정과 가져올 수 있는 스트림의 자동 검색을 제공합니다.
- **증분 및 재개 가능한 동기화** — 동기화가 중단된 지점부터 이어지고 새 레코드를 키 기준으로 병합하므로, 변경된 데이터만 옮기면 됩니다.
- **더 빠른 Snowflake 가져오기** — 서버 측 언로드로 Snowflake의 대용량 가져오기 속도가 빨라집니다.
- **REST 요청 단계** — 연결 카탈로그의 모든 엔드포인트를 호출하고, 테스트 요청을 보내고, 응답을 테이블이나 분기에 사용할 워크플로 변수로 캡처합니다.
- **시각적 조인 디자이너를 갖춘 다중 테이블 조인 단계** — 시각적 그래프에서 테이블 열 사이에 조인을 그릴 수 있으며, 실행 취소/다시 실행과 다이어그램 내보내기를 지원합니다.
- **예측 단계** — 예측을 워크플로 단계로 직접 실행합니다.
- **솔버 단계** — 최적화(선형 및 혼합 정수)를 워크플로 단계로 실행하고 해, 제약 조건, 요약 테이블을 기록합니다.
- **동시 매크로 실행** — 매크로 단계가 작업을 병렬로 실행하여 더 빠르게 처리할 수 있습니다.
- **협업형 시각적 워크플로 디자이너** — 단계별 색상 구분, 새로 디자인한 캔버스, 팀원이 함께 워크플로를 작업할 수 있는 실시간 협업을 갖춘 워크플로의 시각적 뷰입니다.
- **워크플로 실행 이력 및 히트맵** — 활동 히트맵이 포함된 새 실행 이력 뷰로, 패턴과 문제가 있는 실행을 한눈에 파악할 수 있습니다.
- **예약 이벤트 캘린더** — 다가오는 예약 실행을 주, 월, 일정 뷰로 확인할 수 있으며, 겹침 감지와 일정, 워크플로, 프로젝트에 걸친 필터를 제공합니다.
- **테이블 스냅샷 및 특정 시점 복원** — 이전에 저장된 시점의 테이블을 보고, 되돌려야 할 때 그 자리에서 복원할 수 있습니다.
- **새로 만든 프로젝트 보고서** — 모든 워크플로 단계를 문서화하고, 각 워크플로를 생성된 흐름 다이어그램으로 시작하며, 요약 보고와 감사 목록(연결, 테이블과 그 계보, 소스 파일, 내보내기)을 포함하도록 완전히 새로 디자인한 보고서입니다. 브랜드가 적용된 세련된 PDF로 만들거나, 접을 수 있는 세부 정보와 클릭 가능한 목차가 있는 대화형 HTML 보조 문서로 만들 수 있으며, 진행 대화 상자가 워크플로별 생성 진행 상황을 보여 줍니다.
- **프로젝트 비교 및 병합** — 두 프로젝트의 차이를 확인하고 변경 사항을 안전하게 병합합니다.
- **"사용 위치" 영향 분석** — 에이전트와 외부 데이터 연결을 변경하기 전에 어디에서 사용되는지 빠르게 확인합니다.
- **배부 근본 원인 추적** — 새로운 계보 및 추적 도구로 배부 결과가 어떻게 만들어졌는지 이해하고 문제를 해결하기가 더 쉬워졌습니다. 결과가 둘 이상의 배부 단계에서 만들어진 경우 어시스턴트가 후보를 나열하고 어느 것을 추적할지 묻거나, 질문이 그중 하나만 만든 행으로 좁혀지면 올바른 것을 자동으로 추적합니다. 추적은 실제 환경의 모델도 처리합니다. 공백, 괄호 또는 `%` 기호가 들어간 열 이름, Databend와 Postgres는 물론 StarRocks 워크스페이스, 친숙한 이름으로 참조되는 테이블, 각 배부에 입력되는 드라이버 및 기준 테이블까지 포함하는 데이터 최신성이 그 예입니다.
- **서버 Panel 앱 로그** — PlaidCloud에서 바로 서버 Panel 앱의 로그를 열 수 있으며, **런타임**과 **빌드** 뷰가 분리되어 있습니다. 실행 중인 앱이 기록하고 출력한 내용(앱이 유휴 상태가 되어 종료된 후에도 유지됨)을 보거나, 빌드 출력을 읽어 빌드가 실패한 이유를 확인할 수 있으며, 수준 필터, 시간 범위, 자동 새로 고침을 제공합니다.
- **보는 사람 권한으로 데이터를 읽는 Panel 앱** — 서버 측 Panel 앱이 이제 각 보는 사람을 Single Sign-On으로 로그인시키고 해당 사용자 본인의 권한으로 PlaidCloud 데이터를 읽으므로, 각자가 볼 수 있도록 허용된 내용만 정확히 보여 줍니다. 공유 서비스 계정이 없으므로 사용자별 대시보드와 행 수준 보안에 이상적입니다.
- **더 읽기 쉬운 Panel 앱 로그** — 로그 뷰어에서 행을 선택하면 측면 창에서 전체 메시지를 읽을 수 있어, 긴 오류와 전체 스택 트레이스가 더 이상 잘리지 않습니다. 여러 줄을 한꺼번에 선택해 복사할 수도 있어, 디버깅하는 동안 AI 어시스턴트나 팀 메시지에 붙여 넣기 편리합니다.
- **누가 발생시켰는지 보여 주는 Panel 앱 로그** — 앱이 보는 사람을 로그인시키는 경우, 각 로그 줄에 해당 세션을 만든 사용자가 표시되므로 어떤 보는 사람이 오류나 경고를 만났는지 알 수 있습니다. (최선의 노력 기준이며, 일부 시작 줄은 보는 사람이 관여하기 전에 실행됩니다.)
- **서버 Panel 앱 사용 지표** — 앱 목록에서 로그 보기 옆에 있는 새 사용 지표 뷰에서 앱이 어떻게 사용되고 있는지 확인할 수 있습니다. 고유 사용자, 세션 수, 평균 및 중앙값 세션 길이, 마지막 사용 시점과 함께 사용자별, 일별 내역을 보여 줍니다. (앱이 방문 사이에 유휴 상태가 되고 축소되므로 지속 시간은 근삿값입니다.)
- **위임된 Git 관리** — 새 **Git Administration** 권한으로 조직 생성을 포함하여 워크스페이스의 Git 서비스를 관리할 수 있는 사람을 제어합니다. 이를 어떤 보안 그룹에든 연결하거나(또는 기본 제공 **Git Administration** 그룹 사용) 자체 사용자가 PlaidCloud의 도움 없이 Git을 관리하도록 할 수 있습니다.

## 변경 사항

- **더 적절한 AI 답변** — 개선된 검색이 어시스턴트가 답변할 때 알맞은 보조 컨텍스트를 가져오며, 식 작성 도움말은 이제 엔진이 실제로 실행하는 내용과 대조하여 검사하므로 실수를 더 일찍 발견합니다.
- **어시스턴트가 실패한 단계를 수정할 수 있습니다** — 워크플로 단계에서 오류가 발생하면 어시스턴트가 수정된 구성을 제안하고, 승인하면 수정을 적용합니다. 무엇이 잘못되었는지 설명만 하는 데 그치지 않습니다.
- **더 명확한 AI 활동 표시** — 어시스턴트가 오래 걸리는 쿼리를 처리하는 동안 아무 반응 없이 기다리게 하는 대신 처리 표시기가 나타나며, 대화는 이제 프로젝트별로 정리됩니다.
- **더 빠른 테이블 미리 보기** — 테이블 탐색기가 항상 첫 행만 보여 주는 대신 빠른 무작위 샘플을 보여 줄 수 있으며, 열 값 프로필은 이제 오래 실행되는 쿼리를 제한("시간 초과" 배지 표시)하여 매우 큰 테이블에서도 탐색기가 응답성을 유지합니다.
- **더 큰 차원도 확장 가능** — 매우 큰 계층을 메모리 내 저장소의 대안으로 프로젝트의 데이터스토어에 저장할 수 있게 되어, 속도 저하 없이 유지되고 확장됩니다.
- **시각적 워크플로 디자이너 개선** — 브라우저 뒤로 및 앞으로가 작동하는 딥 링크 가능한 프로젝트 및 캔버스 URL, 고급 워크플로 노드의 중단점, 하나의 단위로 활성화 또는 비활성화되는 그룹화 가능한 노드 컨테이너를 제공합니다.
- **더 안정적인 파일 가져오기** — 잘못된 형식의 XML과 까다로운 텍스트 인코딩을 포함하여, 문제가 있는 파일에 대한 Parquet 처리와 더 명확하고 신뢰할 수 있는 오류 보고가 개선되었습니다.
- **더 매끄러운 대시보드와 사용자 동기화** — 대시보드 렌더링 수정과 사용자 및 역할의 분석 계층 동기화 강화가 포함됩니다.
- **더 탄력적인 연결** — 캐싱 계층의 자가 복구와 백그라운드 처리 수정으로 정체가 줄고 전반적인 응답성이 향상됩니다.
- **서버 Panel 앱 로딩 화면** — 유휴 상태가 된 서버 측 Panel 앱을 열면 이제 빈 탭 대신 앱이 시작되는 동안 브랜드가 적용된 PlaidCloud 로딩 화면이 표시되며, 앱을 시작할 수 없으면 다시 시도할 수 있는 명확한 “앱이 시작되지 않았습니다” 메시지로 바뀝니다.
- **앱 목록에서 서버 Panel 앱 다시 빌드** — 새 **다시 빌드** 행 작업을 사용하면 게시를 취소했다가 다시 게시하지 않고도 서버 앱을 다시 빌드하고 재배포할 수 있습니다.
- **서버 Panel 앱의 현대적인 모양과 외관 제어** — 서버 Panel 앱은 이제 기본적으로 현대적인 Fast 디자인을 사용하고, 기존 CSS에 필요하면 Panel의 Default 디자인으로 되돌릴 수 있으며, 제공하는 템플릿을 통해 앱의 테마(라이트, 다크, 또는 보는 사람이 전환할 수 있는 라이트/다크 토글)를 설정할 수 있습니다. 밝은 배경을 기준으로 만든 테이블과 사용자 지정 스타일은 라이트 테마를 유지해야 합니다.
- **서버 Panel 앱의 로컬 빌드 제어** — Panel 앱 가이드에 PlaidCloud가 앱을 배포할 때 사용하는 것과 동일한 `PANEL_*` 환경 변수와 `panel serve` 플래그가 나열되어 있어, 고급 사용자가 배포된 런타임을 로컬에서 재현할 수 있습니다.

## 수정 사항

- **더 이상 "새로 고침이 멈추지" 않습니다** — 서버가 현재 버전을 잠시 확인하지 못할 때 앱이 반복해서 스스로 다시 로드될 수 있던 문제를 수정했습니다.
- **조인 유형이 유지됩니다** — 오른쪽 또는 전체 외부 조인을 선택하면 이제 아무 알림 없이 왼쪽 조인으로 되돌아가지 않고 유지됩니다.
- **안정적인 테이블 내보내기** — 일부 프로젝트에서 압축하지 않은 Parquet를 포함하여 실패할 수 있던 Parquet, Avro, XML로의 테이블 내보내기를 수정했습니다.
- **중단된 단계 복구** — 가져오기 및 내보내기 단계를 처리하던 워커가 중단되어도 단계가 영원히 실행되는 것처럼 보이지 않으며, 다른 워커가 작업을 이어받아 마칩니다.
- **CSV 가져오기 기본값** — "null as" 기본값이 없어서 가져온 CSV 단계가 실행되지 않을 수 있던 문제를 수정했습니다.
- **이전 워크스페이스의 Panel 앱 권한** — 기능이 출시되기 전에 만들어진 워크스페이스에서도 Panel 앱 읽기 및 쓰기 권한이 표시되고 할당할 수 있습니다.
- **문서 브라우저** — 처음 열 때 폴더가 비어 있는 것으로 표시되던 문제, 폴더 이동 경로 오류, 방금 이동하거나 삭제한 폴더를 새로 고칠 때 간헐적으로 충돌하던 문제를 수정했습니다.
- **다중 스키마 외부 데이터베이스 가져오기** — 선택한 소스 테이블이 둘 이상의 스키마에서 온 경우 외부 데이터베이스 테이블 가져오기 및 내보내기 단계의 "메타데이터 검색"과 "소스 데이터베이스 검사"가 "예기치 않은 오류"로 실패하던 문제를 수정했습니다. 이제 다중 스키마 선택도 올바르게 새로 고쳐지며, 연결 또는 메타데이터 문제는 일반적인 오류 대신 명확한 메시지로 보고됩니다.

## 보안

- **PlaidCloud 지원 팀을 위한 비밀번호 없는 액세스** — 이제 모든 지원 팀원이 사용자 이름과 비밀번호 없이 로그인하므로, 플랫폼에 대한 지원 액세스에서 비밀번호 기반 자격 증명이라는 공격 경로가 제거됩니다.
- **더 강력한 테넌트별 격리** — 각 테넌트가 이제 세션과 워크플로 단계에 자체 전용 서명 시크릿을 사용합니다.
- **교차 사이트 스크립팅(XSS) 강화** — 대화 상자 콘텐츠와 화면 알림은 기본적으로 안전하게 이스케이프되며, HTML은 명시적으로 의도된 경우에만 허용됩니다.
- **강화된 파일 가져오기** — 잘못된 형식의 업로드를 혼란스러운 오류로 노출하지 않고 안전하게 처리합니다.
- **지속적인 취약점 스캔** — 모든 빌드의 일부로 애플리케이션 이미지에서 알려진 보안 취약점을 자동으로 스캔합니다.
