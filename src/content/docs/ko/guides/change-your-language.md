PlaidCloud 인터페이스는 11개 언어로 제공됩니다.

| 언어 | 메뉴 항목 |
|---|---|
| 영어(미국) | English (US) |
| 영어(영국) | English (UK) |
| 독일어 | Deutsch |
| 스페인어 | Español |
| 프랑스어 | Français |
| 포르투갈어(포르투갈) | Português (Portugal) |
| 포르투갈어(브라질) | Português (Brasil) |
| 폴란드어 | Polski |
| 일본어 | 日本語 |
| 한국어 | 한국어 |
| 중국어(간체) | 简体中文 |

모든 사용자는 English (US)로 시작합니다. 언어를 선택하기 전에는 아무것도 바뀌지 않습니다.

## 언어 변경하기

1. 상단 헤더에서 **모양** 버튼 옆의 **언어** 버튼을 클릭합니다. 메뉴에는 각 언어가 해당 언어의 이름으로 나열되므로 현재 표시 언어와 관계없이 원하는 언어를 찾을 수 있습니다.
2. 언어를 선택합니다.
3. PlaidCloud가 해당 언어로 다시 로드된다는 메시지가 표시됩니다. 저장되지 않은 변경 사항은 사라지므로 먼저 작업을 저장하십시오. 계속하려면 **다시 로드**를 클릭하고, 현재 상태를 유지하려면 취소를 클릭합니다.

PlaidCloud는 선택한 언어를 프로필에 저장하고 새 언어로 다시 로드합니다. 원래대로 되돌리려면 같은 방법으로 **English (US)** 를 선택하십시오.

## 선택이 적용되는 범위

- **다른 기기와 브라우저.** 선택한 언어가 따라옵니다. 다른 기기나 브라우저에서 같은 워크스페이스에 로그인하면 다음 페이지 로드부터 적용됩니다.
- **워크스페이스별.** 선택은 한 워크스페이스에 있는 프로필에 속합니다. 여러 워크스페이스를 사용한다면 각각에서 언어를 설정하십시오.

## 숫자와 날짜

숫자와 날짜는 선택한 언어의 형식으로 표시됩니다. 예를 들어 독일어에서는 1,234.5가 `1.234,5`로 표시됩니다. 폴란드어에서는 1234567.89가 `1 234 567,89`로, 2026년 10월 12일이 `12.10.2026`으로 표시됩니다. 일본어와 중국어에서는 이 날짜가 `2026/10/12`로, 한국어에서는 `26. 10. 12.`로 표시됩니다. English (UK)는 영국식 철자와 영국식 형식을 사용합니다.

표시 방식만 바뀝니다. 저장하거나 내보내거나 연동 서비스로 전송하는 값은 평소 형식을 유지합니다.

## 일본어, 한국어, 중국어 입력

일본어, 한국어, 중국어 입력기는 숫자 필드와 입력 가능한 문자를 제한하는 다른 필드에서도 동작합니다. 전각 숫자는 입력하는 즉시 변환되므로 `１２３`이 `123`이 됩니다.

## 언어를 따르는 기타 항목

PlaidCloud가 서버에서 보내는 텍스트도 PlaidCloud가 제공하는 모든 언어에서 선택한 언어를 따릅니다.

- **이메일.** 초대, 비밀번호 재설정, 워크플로 및 마이그레이션 알림 같은 시스템 이메일과 가입, 청구, 지원 이메일.
- **로그인 화면.** 로그인, 비밀번호 설정, 로그아웃 화면과 이 화면에서 Keycloak이 보내는 이메일.
- **오류 메시지.** 요청이 실패할 때 PlaidCloud가 인터페이스, REST API, JSON-RPC를 통해 표시하는 메시지.
- **프로젝트 문서 PDF.** PlaidCloud가 프로젝트를 문서화하기 위해 생성하는 PDF.

## PlaidCloud가 언어를 선택하는 방법

| 위치 | 사용되는 언어 |
|---|---|
| PlaidCloud 내부 | **언어** 버튼으로 선택한 언어. 로그인 페이지와 이메일도 같은 선택을 따릅니다. |
| 로그인 전의 로그인 및 기타 화면 | 브라우저의 언어. |
| 가입 | 브라우저의 언어. PlaidCloud가 이를 조직에 저장하며, 조직에 보내는 청구 및 계정 이메일에 이 언어가 사용됩니다. |

브라우저나 프로필에서 PlaidCloud가 제공하지 않는 언어를 사용하면 텍스트가 English (US)로 표시됩니다. 번체 중국어(zh-TW 또는 zh-HK)로 설정된 브라우저는 서버 텍스트에 대해 English (US)로 대체됩니다.

## 영어로 유지되는 항목

- 워크플로 및 단계 실행 메시지와 로그, 활동 스트림. 많은 사람이 이를 읽으므로 하나의 언어로 유지하면 검색과 일관성에 도움이 됩니다.
- AI 어시스턴트와 MCP 도구가 출력하는 텍스트.
- 이메일 템플릿과 보고서 단계에서 보내는 이메일을 포함해 직접 작성하는 이메일.
- OpenAPI 문서.
- SQL 및 식 엔진의 오류 텍스트.
- 가입 화면.
- 프로젝트, 테이블, 단계의 이름처럼 직접 만드는 콘텐츠.
