## 설명

워크스페이스 관리자는 워크스페이스에서 사용할 Weave의 AI 기능을 결정합니다. 각 기능은 워크스페이스의 모든 사용자에 대해 개별적으로 끌 수 있습니다. 관리자가 끄기 전까지는 모든 기능이 켜져 있습니다.

Weave의 검사와 결과 항목은 AI를 사용하지 않으므로, 여기서 어떻게 선택하든 계속 켜져 있습니다.

## 기능 켜기 또는 끄기

1. 헤더에서 **Weave** 단추를 클릭합니다.
2. 메뉴 맨 끝에 있는 **AI 기능…** 을 선택합니다.
3. 끄려는 각 기능 옆의 상자를 선택 해제하고, 다시 켜려면 선택합니다.
4. **저장**을 클릭합니다.

변경 사항은 워크스페이스의 누구든 다음 AI 요청을 할 때 적용됩니다. 로그아웃할 필요는 없습니다.

**AI 기능…** 은 워크스페이스 관리자에게만 표시됩니다. 다른 사용자가 API를 통해 기능을 변경하려고 하면 *워크스페이스 관리자만 AI 기능을 켜거나 끌 수 있습니다.*라는 메시지가 표시됩니다.

## 기능

| 기능 | 포함 범위 | 끈 경우 |
|---|---|---|
| **Weave 채팅** | 프로젝트의 **Weave** 탭에 있는 채팅, **도움말 및 지원**의 **어시스턴트에게 질문하기**, [PlaidCloud 모바일 앱](/ko/guides/mobile-app/weave-on-mobile/)의 Weave | **Weave** 탭의 **채팅**에 관리자가 기능을 껐다고 표시되고, **도움말 및 지원**에는 **어시스턴트에게 질문하기** 탭이 없으며, 모바일 앱에서 한 질문은 거부됩니다. |
| **수정 어시스턴트** | Weave의 결과 항목에 있는 **수정**과 로그 항목의 **Weave AI** 탭 | 결과 항목에 **수정**이 제공되지 않습니다. 단, **Steps that can run before the table they read is written**의 누락된 커넥터는 예외이며, 이 경우 **수정**은 어시스턴트가 아니라 [종속성 동기화](/ko/guides/workflows/sync-dependencies/)를 엽니다. **Weave AI** 탭을 사용할 수 없습니다. |
| **가져오기 및 내보내기 어시스턴트** | Weave 채팅이 파일 가져오기, 가져오기 단계 또는 내보내기 단계를 대신 설정하는 기능 | Weave 채팅이 이들을 설정할 수 없습니다. |
| **식 어시스턴트** | 식 편집기의 어시스턴트 | 식 편집기에 어시스턴트가 없습니다. |
| **설명으로 SQL 생성** | **SQL 추출** 단계의 [Generate SQL with AI](/ko/guides/ai-assistant/generate-sql-extract/) | 단계에 **Generate SQL with AI** 섹션이 없습니다. SQL은 직접 작성할 수 있습니다. |
| **워크플로 검토 요약** | 워크플로의 **검사** 위에 AI가 작성하는 요약 | **검사**가 요약 없이 결과 항목만 표시합니다. |
| **시작 차트** | 끌어다 놓은 파일에 대해 AI가 첫 차트를 선택하는 기능 | 규칙에 따라 차트가 선택됩니다. |

변경했을 때 이미 로그인해 있던 사용자는 PlaidCloud를 다시 로드하기 전까지 해당 기능이 계속 표시되지만, Weave는 더 이상 그 기능에 AI를 사용하지 않습니다. 채팅, 수정 어시스턴트와 식 어시스턴트, 설명으로 SQL 생성은 그렇다고 알려 줍니다. 예: *워크스페이스 관리자가 수정 어시스턴트를 껐습니다.*

<Aside type="note">
이 스위치는 PlaidCloud가 제공하는 AI에 적용됩니다. 워크플로의 AI 단계는 사용자 자신의 AI 연결을 사용하고, [MCP](/ko/integrations/ai-coding-agents/)로 연결한 AI 도구는 자체 모델을 사용하므로 둘 다 영향을 받지 않습니다.
</Aside>

## 변경 기록

기능을 켜거나 끌 때마다 워크스페이스의 보안 로그에 변경한 사람과 시점이 기록됩니다. 예: *수정 어시스턴트를 껐습니다.*

## API로 변경하기

`GET /rest/v1/analyze/ai/features`는 각 기능과 켜져 있는지 여부를 `{"features": [{"feature": "chat", "on": true}, …]}` 형태로 반환합니다. 기능 이름은 `chat`, `fix`, `import_export`, `expression`, `sql_extract`, `review_summary`, `starter_chart`입니다.

`{"off": ["fix"], "on": ["chat"]}`를 사용한 `PUT /rest/v1/analyze/ai/features`는 `off`에 있는 기능을 끄고 `on`에 있는 기능을 켭니다. 두 목록 어디에도 없는 기능은 그대로 유지되므로, 관리자 두 명이 서로 다른 기능을 변경해도 서로의 변경을 되돌리지 않습니다. 응답은 `GET`과 같은 형식입니다. 워크스페이스 관리자만 호출할 수 있으며, 기능이 아닌 이름이나 두 목록에 모두 있는 이름은 거부됩니다.
