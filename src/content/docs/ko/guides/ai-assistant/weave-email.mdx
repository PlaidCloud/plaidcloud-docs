## 설명

Weave는 사용자에게 이메일을 보낼 수 있으므로 PlaidCloud를 계속 열어 두지 않아도 문제를 알 수 있습니다. 이메일은 두 가지 종류가 있으며, 각각 본인이 직접 켭니다.

- **알림**은 워크플로 실행이 끝났을 때 Weave가 사용자가 확인해야 할 심각한 문제를 찾으면 전송됩니다. 실행 실패, 또는 작동할 수 없게 설정된 워크플로, 단계 또는 일정이 해당합니다. PlaidCloud에서 Weave가 사용자에게 알려 주었을 문제에 대해 받게 되며, 대개 사용자가 해당 워크플로를 마지막으로 실행했거나 누군가 그 문제를 사용자에게 할당한 경우입니다.
- **일일 요약**은 Weave가 알려 준 문제 중 아직 읽지 않은 문제를 모아 사용자가 선택한 시간에 전송됩니다.

두 가지 모두 켜기 전까지는 꺼져 있습니다.

## Weave 이메일 켜기

1. 헤더에서 **Weave** 버튼을 클릭합니다.
2. **Weave 이메일…** 메뉴를 선택합니다.
3. **내 이메일** 아래에서 둘 중 하나 또는 둘 모두를 선택합니다.
   - **확인해야 할 심각한 문제를 Weave가 찾으면 이메일로 알림 받기**
   - **Weave가 알려 준 문제 중 읽지 않은 문제의 일일 요약을 이메일로 받기**를 선택한 경우 **시간**도 선택합니다.
4. **저장**을 클릭합니다.

시간은 사용자의 시간대, 즉 **저장**을 클릭할 때 브라우저가 사용하는 시간대를 기준으로 합니다. 창에서 **시간** 옆에 해당 시간대가 표시됩니다. 그날 해당 시간이 지난 뒤에 일일 요약을 켜면 첫 요약은 1시간 이내에 전송됩니다.

**저장**을 클릭할 때 PlaidCloud에 연결할 수 없으면 창에 *이메일 선택 사항을 저장하지 못했습니다. 잠시 후 다시 시도하세요.*라고 표시되며 창은 열린 채로 유지됩니다.

이메일 수신을 중지하려면 확인란을 지우고 **저장**을 클릭합니다.

## 이메일 내용

각 이메일에는 프로젝트 이름과 함께 각 문제의 워크플로, 단계, 테이블 또는 지표가 문제 유형과 함께 표시되며, 예를 들면 *"Month End" (workflow) — Last run failed*와 같습니다. 이메일은 프로젝트의 **Weave** 탭으로 연결되는 링크를 포함하며, 그곳에서 전체 결과 항목을 읽을 수 있습니다.

이메일에는 데이터의 수치나 값이 포함되지 않습니다. PlaidCloud에서 Weave가 보여 주는 문장에는 이러한 값이 인용될 수 있으므로 이메일에서는 해당 문장을 제외합니다.

Weave는 이메일을 보내기 전에 사용자가 볼 수 있는 항목을 확인합니다. 각 이메일은 사용자 권한으로 실행한 Weave 검사 결과로 만들어지므로 사용자의 액세스 권한으로 가려진 항목은 이메일에 나타나지 않으며, 더 이상 열 수 없는 프로젝트에 대한 이메일도 받지 않습니다.

일일 요약에는 문제가 **Weave** 탭에서 읽히거나 해결될 때까지 해당 문제가 계속 나열됩니다. 따라서 어제 알림을 받았지만 아직 읽지 않은 문제는 오늘 요약에도 포함됩니다. 읽지 않은 문제가 없으면 요약은 전송되지 않습니다.

## 관리자용

워크스페이스 관리자는 같은 창에서 **워크스페이스** 섹션을 볼 수 있습니다.

- **Weave가 이 워크스페이스의 멤버에게 이메일을 보내도록 허용**은 해제하기 전까지 켜져 있습니다. 이 옵션을 끄면 Weave는 누구에게도 이메일을 보내지 않으며, 각 멤버의 창에는 *워크스페이스 관리자가 Weave 이메일을 껐습니다.*라고 표시됩니다.
- **방해 금지 시간**은 **시작** 시각부터 **종료** 시각까지 알림 전송을 보류합니다. 방해 금지 시간은 각 멤버의 시간대를 기준으로 적용되며, 예를 들어 20:00부터 07:00까지처럼 자정을 넘길 수 있습니다. 방해 금지 시간 중에 발견된 알림은 문제가 아직 남아 있고 멤버가 읽지 않았다면 해당 시간이 끝날 때 전송됩니다. 방해 금지 시간은 각 멤버가 선택한 시간에 전송되는 일일 요약에는 영향을 주지 않습니다.

모든 변경 사항은 변경한 사람과 시각과 함께 워크스페이스의 보안 로그에 기록되며, 예를 들면 *Turned off Weave email.*과 같습니다.

<Aside type="note">
Weave는 각 멤버의 PlaidCloud 계정에 등록된 주소로 이메일을 보냅니다. 계정이 비활성화된 멤버는 이메일을 받지 않습니다.
</Aside>
