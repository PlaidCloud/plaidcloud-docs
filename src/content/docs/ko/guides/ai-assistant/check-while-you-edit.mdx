## 설명

단계에서 **저장**을 누르면 PlaidCloud는 단계의 설정을 검사하고, 컴파일되지 않는 식이나 유형상 허용되지 않는 방식으로 사용된 열처럼 실행할 수 없는 설정을 거부합니다. 단계를 편집하는 동안 Weave는 이러한 검사의 대부분을 편집과 동시에 실행하고, **저장** 버튼 바로 위의 표시줄에 저장이 거부할 항목을 보여 줍니다.

> 저장이 거부할 문제가 1건 있습니다.

각 문제는 이 줄 아래에 나열됩니다. 문제가 **테이블 데이터 선택** 탭의 행을 가리키면 **이동**을 클릭해 해당 행이 선택된 상태로 그 탭을 엽니다.

검사는 단계의 설정과 프로젝트의 변수만 읽으므로 빠르게 실행되며 AI는 사용되지 않습니다. 검사가 저장을 막지는 않습니다. 저장은 항상 가능하며, 저장을 누르면 저장이 모든 검사를 직접 실행합니다.

<Aside type="note">
저장은 이 표시줄에서 확인하지 않는 몇 가지도 검사합니다. 예를 들어 소스 테이블과 대상 테이블에 단계가 사용하는 열이 있는지, 필수 필드가 채워져 있는지 등입니다. 따라서 "문제가 없습니다"는 편집하는 동안 실행되는 검사에서 문제를 찾지 못했다는 뜻이며, 저장이 해당 단계를 수락한다는 뜻은 아닙니다.
</Aside>

## 표시줄에 표시되는 내용

| Weave 표시 내용 | 의미 |
| --- | --- |
| 이 단계에 문제가 있는지 확인하는 중입니다… | Weave가 가장 최근 변경 사항에 대해 검사를 실행하는 중입니다. |
| 저장이 거부할 문제가 1건 있습니다. | 현재 상태 그대로는 저장이 단계를 거부합니다. 각 문제는 아래에 나열됩니다. |
| 문제가 없습니다. 저장은 소스 테이블과 대상 테이블 등 몇 가지를 더 검사합니다. | 편집하는 동안 실행되는 검사에서 아무것도 찾지 못했습니다. 저장은 이 표시줄에서 건너뛰는 항목을 포함해 자체 검사를 여전히 실행합니다. |
| Weave에서 이 단계의 식을 검사할 수 없습니다. … | 단계의 일부를 검사할 수 없었으며, 뒤에 이유가 이어집니다. 이는 통과가 아닙니다. |
| Weave에서 지금은 이 단계를 검사할 수 없습니다. 저장은 여전히 검사합니다. | 서버가 사용 중이었던 경우처럼 검사가 실행되지 않았습니다. 다음 변경 시 다시 요청합니다. |

### 식을 검사할 수 없는 이유

| 이유 | 의미 |
| --- | --- |
| 이 단계는 워크플로에 속해 있지 않아 식을 검사할 수 없습니다. 저장도 식을 검사하지 않습니다. | 식은 워크플로 변수를 사용할 수 있으므로 단계가 속한 워크플로에서 검사합니다. 워크플로 밖에서 연 단계는 여기서도, 저장에서도 검사하지 않습니다. |
| 일부 식은 Weave가 아직 검사할 수 없는 설정에 있습니다. | 단계가 두 번째 소스의 필터처럼 이 검사가 읽지 않는 설정에 일부 식을 보관합니다. 나머지 식은 계속 검사합니다. |
| 열 설정을 Weave가 아직 검사할 수 없습니다. | 다중 테이블 조인처럼 단계가 열을 검사에서 컴파일할 수 없는 방식으로 나열합니다. |

워크플로와 프로젝트 어디에도 정의되지 않은 변수를 사용하는 식은 이유가 아니라 문제입니다. 예: "식에서 변수 rate를 사용하지만 이 워크플로 또는 프로젝트에 정의되어 있지 않습니다." 입력하다 만 변수처럼 어떤 변수 이름도 시작하거나 끝내지 않는 중괄호도 문제입니다. 예: "식에 변수 이름의 일부가 아닌 중괄호가 있습니다." 저장은 두 경우 모두 같은 문장으로 거부합니다.

## 식 편집기에서

**테이블 데이터 선택** 탭의 **식** 셀에서, 또는 **데이터 필터** 탭의 **데이터 하위 집합 선택**이나 **결과 데이터에 보조 필터 적용**에서 **식 편집기**를 열면, 편집기 아래의 한 줄이 입력하는 즉시 식을 검사합니다.

| 편집기 표시 내용 | 의미 |
| --- | --- |
| 확인하는 중… | Weave가 방금 입력한 내용을 검사하는 중입니다. |
| 오류가 없습니다. | 저장이 컴파일하는 방식 그대로 식이 컴파일됩니다. 이 줄에 포인터를 올리면 검사하지 않는 항목을 볼 수 있습니다. Weave는 구문과 열 이름을 검사하며, 일부 오류는 단계를 실행할 때만 나타납니다. |
| 오류: … | 제시된 이유로 저장이 식을 거부합니다. 구문 오류는 해당 줄의 줄 번호 옆에도 표시됩니다. |
| 검사할 수 없음. … | 위에서 설명한 이유 중 하나로 식을 검사할 수 없었습니다. |
| 지금은 검사할 수 없습니다. 단계를 저장할 때 다시 검사합니다. | 검사가 실행되지 않았습니다. 단계에서 **저장**을 누르면 식을 여전히 검사합니다. |

편집기는 Weave가 단계를 마지막으로 검사했을 당시의 단계 설정에 사용자가 입력한 식을 적용해 검사합니다. 테이블 탐색기처럼 다른 곳에서 열면 이 줄이 표시되지 않습니다.

## 표시되는 경우

- 변경할 수 있는 단계를 편집하는 동안 표시됩니다. 역할상 읽기 전용으로 열리는 단계는 편집하는 동안 검사하지 않습니다.
- 변경할 때마다 잠시 멈춘 뒤에 검사합니다. 설정이 이전과 같게 유지되는 변경은 다시 검사하지 않습니다.
- 단계의 설정과 프로젝트의 변수를 읽으므로 AI 호출 비용이 발생하지 않으며 웨어하우스에 쿼리하지도 않습니다.
