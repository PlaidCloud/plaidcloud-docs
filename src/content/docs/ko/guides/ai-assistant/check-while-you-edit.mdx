## 설명

단계에서 **저장**을 누르면 PlaidCloud는 단계의 설정을 검사하여 실행할 수 없는 설정을 거부합니다. 예를 들어 컴파일되지 않는 식이나 열 유형에서 허용하지 않는 방식으로 사용된 열이 해당합니다. 이제 단계를 편집하는 동안 Weave가 이러한 검사 대부분을 계속 실행하고, 저장이 거부할 항목을 **저장** 버튼 바로 위의 표시줄에 보여 줍니다.

> 저장이 거부할 문제가 1개 있습니다.

각 문제는 이 줄 아래에 나열됩니다. 문제가 **열** 탭의 행을 가리키는 경우 **이동**을 누르면 해당 행이 선택된 상태로 그 탭이 열립니다.

이 검사는 단계의 설정과 프로젝트의 변수만 읽으므로 빠릅니다. 검사는 저장을 막지 않습니다. 저장은 항상 사용할 수 있으며, 저장을 누르면 모든 검사를 직접 실행합니다.

<Aside type="note">
저장은 이 표시줄이 검사하지 않는 몇 가지 항목도 검사합니다. 예를 들어 소스 테이블과 대상 테이블에 단계가 사용하는 열이 있는지, 필수 필드가 채워져 있는지 확인합니다. 따라서 "문제가 없습니다"는 편집하는 동안 실행되는 검사에서 문제를 찾지 못했다는 뜻이며, 저장이 단계를 승인한다는 뜻은 아닙니다.
</Aside>

## 표시줄의 메시지

| Weave의 메시지 | 의미 |
| --- | --- |
| 이 단계에 문제가 있는지 확인하는 중입니다… | Weave가 최신 변경 사항에 대해 검사를 실행하고 있습니다. |
| 저장이 거부할 문제가 1개 있습니다. | 현재 상태의 단계는 저장이 거부합니다. 각 문제는 그 아래에 나열됩니다. |
| 문제가 없습니다. 저장은 소스 테이블과 대상 테이블 등 몇 가지를 더 검사합니다. | 편집하는 동안 실행된 검사에서 아무것도 찾지 못했습니다. 저장은 이 표시줄이 건너뛰는 항목을 포함하여 자체 검사를 계속 실행합니다. |
| Weave에서 이 단계의 식을 검사할 수 없습니다. … | 단계의 일부를 검사할 수 없었으며, 이유가 뒤따릅니다. 이는 통과가 아닙니다. |
| Weave에서 지금은 이 단계를 검사할 수 없습니다. 저장이 계속 검사합니다. | 서버가 사용 중인 경우 등으로 검사가 실행되지 않았습니다. 다음 변경 시 다시 요청합니다. |

### 식을 검사할 수 없는 이유

| 이유 | 의미 |
| --- | --- |
| 이 단계는 워크플로에 속해 있지 않으므로 식을 검사할 수 없습니다. 저장도 식을 검사하지 않습니다. | 식은 워크플로 변수를 사용할 수 있으므로 단계가 속한 워크플로에서 검사합니다. 워크플로 밖에서 연 단계는 여기서도, 저장에서도 검사하지 않습니다. |
| 일부 식이 Weave가 아직 검사할 수 없는 설정에 있습니다. | 단계는 일부 식을 이 검사가 읽지 않는 설정에 보관합니다. 예를 들어 두 번째 소스의 필터가 그렇습니다. 나머지 식은 계속 검사합니다. |
| 열 설정을 Weave가 아직 검사할 수 없습니다. | 다중 테이블 조인처럼, 단계가 검사에서 컴파일할 수 없는 방식으로 열을 나열합니다. |

워크플로나 프로젝트 어느 쪽에도 정의되지 않은 변수를 사용하는 식은 이유가 아니라 문제입니다. "식에서 변수 rate를 사용하지만 이 워크플로나 프로젝트에 정의되어 있지 않습니다." 변수 이름을 시작하거나 끝내지 않는 중괄호도 마찬가지입니다. 변수를 입력하다 만 경우가 그렇습니다. "식에 변수 이름에 속하지 않는 중괄호가 있습니다." 저장은 두 경우 모두 같은 문장으로 거부합니다.

## 식 편집기에서

**열** 탭의 **식** 셀이나 **필터** 탭의 **데이터 하위 집합 선택** 또는 **결과 데이터에 보조 필터 적용**에서 **식 편집기**를 열면, 편집기 아래의 한 줄이 입력하는 동안 식을 검사합니다.

| 편집기의 메시지 | 의미 |
| --- | --- |
| 검사 중… | Weave가 방금 입력한 내용을 검사하고 있습니다. |
| 오류가 없습니다. | 저장이 컴파일하는 방식으로 식이 컴파일됩니다. 이 줄에 포인터를 올리면 제외되는 항목을 볼 수 있습니다. Weave는 구문과 열 이름을 검사하며, 일부 오류는 단계를 실행할 때만 나타납니다. |
| 오류: … | 저장이 제시된 이유로 식을 거부합니다. 구문 오류는 해당 줄의 줄 번호 옆에도 표시됩니다. |
| 검사할 수 없음. … | 위에 설명한 이유 중 하나로 식을 검사할 수 없었습니다. |
| 지금은 검사할 수 없습니다. 단계를 저장하면 계속 검사합니다. | 검사가 실행되지 않았습니다. 단계에서 **저장**을 눌러도 식을 계속 검사합니다. |

편집기는 Weave가 단계를 마지막으로 검사한 시점의 단계 설정에 사용자의 식을 적용하여 검사합니다. 테이블 탐색기 등 다른 곳에서 열면 이 줄이 표시되지 않습니다.

## 표시되는 시점

- 변경할 수 있는 단계를 편집하는 동안. 역할상 읽기 전용으로 열리는 단계는 편집하는 동안 검사하지 않습니다.
- 변경할 때마다, 입력을 멈춘 후. 설정이 이전과 같게 유지되는 변경은 다시 검사하지 않습니다.
- 단계의 설정과 프로젝트의 변수를 읽으므로 웨어하우스를 쿼리하지도 않습니다.
