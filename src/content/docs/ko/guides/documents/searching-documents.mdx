## 설명

Document 브라우저에는 파일 목록 상단에 검색 표시줄이 있습니다. 검색은 연결된 백엔드(S3, Azure Blob, Google Drive, OneDrive 등)를 대상으로 실시간으로 실행되므로 오래된 인덱스가 아니라 계정의 현재 상태가 결과에 반영됩니다.


## 검색 실행

1. Document 계정을 엽니다.
2. 파일 목록 상단의 **파일 검색…** 필드를 클릭합니다.
3. 이름 패턴을 입력합니다.
4. 결과가 파일 목록에 순차적으로 표시되는 것을 확인합니다.

`Esc` 키를 누르거나 필드 끝의 지우기 아이콘을 클릭하면 검색 모드가 종료되고 일반 파일 목록으로 돌아갑니다. 필드 아래의 상태 표시줄에는 스캔한 폴더 수와 찾은 일치 항목 수가 표시됩니다.


## 고급 필터

검색 필드 옆의 `Advanced`를 클릭하면 필터 행이 표시됩니다. 다음 필터를 이름 패턴과 자유롭게 조합할 수 있습니다.

* **확장명:** — 쉼표로 구분한 확장명입니다(예: `pdf,xlsx`). 공백은 넣지 않습니다.
* **종류:** — `Files & folders`(기본값), `Files only`, `Folders only` 중에서 선택합니다.
* **크기(바이트):** — 최소 크기 및/또는 최대 크기입니다.
* **수정됨:** — 시작 날짜 이후 및 종료 날짜 이전이며, 둘 다 `YYYY-MM-DD` 형식입니다.

필터는 이름 패턴에 추가로 적용됩니다. `Clear`를 클릭하면 검색어와 모든 필터가 지워집니다.


## 강조 표시와 위치 표시

* 검색이 실행되는 동안 결과가 도착하는 순서대로 표시되므로 기다리지 않고 먼저 찾은 항목에 바로 작업할 수 있습니다.
* 스트림이 완료되면 파일 목록이 이름순으로 다시 정렬되고, 각 행에서 일치한 부분 문자열이 강조 표시됩니다.
* 결과를 마우스 오른쪽 버튼으로 클릭하고 `Reveal in folder`를 선택하면 해당 파일이 있는 디렉터리로 이동하고 검색 모드가 종료됩니다.


## 백엔드 간 검색

검색은 스토리지 백엔드가 자체 검색 API를 제공하는 경우 해당 API를 사용하므로, 백엔드의 기본 UI에서 보는 결과와 일치합니다.

* **Google Drive** — Drive API를 사용합니다.
* **OneDrive / SharePoint** — Microsoft Graph를 사용합니다.

오브젝트 스토어(S3 및 S3 호환 스토리지, Azure Blob, GCS 등)의 경우 PlaidCloud가 구성된 경로를 병렬로 크롤링합니다.


<Aside>사용자마다 계정당 동시 검색 수가 소수로 제한되므로 무거운 검색이 다른 사용자의 검색을 지연시키지 않습니다. 제한에 도달하면 검색 표시줄에 오류가 표시됩니다. 진행 중인 다른 검색이 끝날 때까지 기다린 후 다시 시도하십시오.</Aside>
