Document 브라우저는 왼쪽에 폴더 트리, 오른쪽에 파일 목록이 표시되는 두 개의 창으로 나뉜 보기입니다. 대부분의 작업은 두 창 어느 쪽에서든 마우스 오른쪽 버튼 메뉴로 사용할 수 있습니다. 마우스 오른쪽 버튼 메뉴에는 폴더, 파일, 빈 공간 중 무엇을 선택했는지에 따라 다른 옵션이 표시됩니다.

계정의 루트는 그 자체로 볼 수 있고 파일을 끌어다 놓을 수 있는 폴더입니다. 루트를 클릭하면 최상위 수준의 모든 항목이 표시되며 끌어다 놓은 업로드를 받을 수 있습니다.


**파일 탐색기를 여는 방법:**

1. **Document > 공유 계정**(또는 **Private Accounts**)으로 이동합니다.
2. 탐색할 계정의 폴더 아이콘(맨 왼쪽)을 클릭하거나 계정 행을 두 번 클릭합니다.

다양한 파일 및 폴더 작업은 아래에서 자세히 설명합니다.


## 파일 업로드

**끌어서 놓기:**

1. 원하는 디렉터리로 이동합니다.
2. 바탕 화면에서 파일을 하나 이상 파일 목록으로 끌어다 놓습니다.

**마우스 오른쪽 버튼 메뉴에서:**

1. 원하는 디렉터리로 이동합니다.
2. 파일 목록에서 마우스 오른쪽 버튼으로 클릭하고 `Upload Here`를 선택합니다.
3. 운영 체제의 파일 선택기에서 파일을 선택합니다.

**도구 모음에서:**

1. 원하는 디렉터리로 이동합니다.
2. 오른쪽 창의 `Upload` 버튼을 클릭합니다.

<Aside>여러 파일을 한 번에 업로드할 수 있습니다. 대상 이름이 이미 있으면 덮어쓸지 취소할지 확인하는 메시지가 표시됩니다.</Aside>


## 파일 다운로드

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 파일을 선택합니다.
3. 마우스 오른쪽 버튼으로 클릭하고 `Download`를 선택합니다.


## 파일 이름 바꾸기

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 파일을 선택합니다.
3. 마우스 오른쪽 버튼으로 클릭하고 `Rename`을 선택합니다.


## 파일 이동

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 파일을 선택합니다.
3. 대상 폴더로 끌어다 놓습니다.
4. `Move File`을 선택합니다.


## 파일 복사

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 파일을 선택합니다.
3. 마우스 오른쪽 버튼으로 클릭하고 `Copy`를 선택합니다.


## 파일 삭제

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 파일을 선택합니다.
3. 마우스 오른쪽 버튼으로 클릭하고 `Delete`를 선택합니다.


## 폴더 만들기

1. 계정을 엽니다.
2. `New Top Level Folder`를 클릭합니다(또는 기존 폴더를 마우스 오른쪽 버튼으로 클릭하고 `New Folder`를 선택합니다).
3. 폴더 이름을 입력합니다.
4. `Create`를 클릭합니다.


## 폴더 이름 바꾸기

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 폴더를 선택합니다.
3. 마우스 오른쪽 버튼으로 클릭하고 `Rename`을 선택합니다.


## 폴더 이동 또는 복사

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 폴더를 선택합니다.
3. 대상 폴더로 끌어다 놓습니다.
4. 폴더를 옮기려면 `Move Folder`를, 원본을 그대로 두려면 `Copy Folder`를 선택합니다.

어느 쪽이든 폴더와 그 안의 모든 항목이 함께 이동하거나 복사됩니다.


## 폴더 삭제

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 폴더를 선택합니다.
3. 마우스 오른쪽 버튼으로 클릭하고 `Delete`를 선택합니다.


## 폴더 내용 다운로드(zip 파일)

`Download as Zip` 옵션은 선택한 폴더 아래의 모든 파일을 하나의 `.zip`으로 압축하여 다운로드합니다. 압축 파일에는 탐색기에 표시된 폴더 구조가 그대로 유지됩니다.

1. 원하는 디렉터리로 이동합니다.
2. 왼쪽 클릭으로 원하는 폴더를 선택합니다.
3. 마우스 오른쪽 버튼으로 클릭하고 `Download as ZIP`을 선택합니다.


## 읽기 전용 계정

계정이 읽기 전용으로 표시되어 있으면 업로드 관련 요소(끌어다 놓기 안내, 도구 모음의 `Upload` 버튼, `Upload Here` 상황에 맞는 메뉴)가 자동으로 숨겨집니다. 찾아보기, 다운로드, 검색은 계속 사용할 수 있습니다.


## 검색

여러 하위 폴더 또는 연결된 여러 계정에 걸쳐 계정 전체에서 파일을 찾으려면 [문서 검색](../searching-documents/)을 참조하십시오.
