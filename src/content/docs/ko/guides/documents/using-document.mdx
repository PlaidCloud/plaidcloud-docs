문서 브라우저는 왼쪽에 폴더 트리, 오른쪽에 파일 목록이 있는 2개 창 분할 뷰입니다. 도구 모음에는 레이블이 있고, 각 행에는 **⋯** 메뉴가 있으며, 대부분의 작업은 두 창 어디에서든 마우스 오른쪽 버튼 메뉴로도 사용할 수 있습니다. 마우스 오른쪽 버튼 메뉴에는 폴더, 파일, 빈 공간 중 무엇을 선택했는지에 따라 다른 옵션이 표시됩니다.

계정의 루트는 그 자체로 볼 수 있는 폴더이며, 왼쪽 드롭 영역은 루트로 바로 업로드합니다.


**파일 탐색기를 열려면:**

1. **문서 > 찾아보기**로 이동합니다. 즐겨찾는 계정이 열리며, 즐겨찾는 계정이 없으면 워크스페이스의 기본 계정이 열립니다. 페이지 머리글의 목록에서 다른 계정을 선택하십시오. 또는 **문서 > 내 계정**으로 이동하여 계정의 행을 두 번 클릭하거나 해당 행의 **열기** 아이콘을 사용합니다
2. 고정한 파일에서 시작하려면 **개요**의 **고정됨**에서 해당 파일을 선택합니다. 해당 파일이 선택된 상태로 그 폴더에서 **찾아보기**가 열립니다

### 팝아웃

페이지 머리글의 **Pop out**은 현재 계정과 폴더를 새 브라우저 탭에서 열어, 다른 페이지에서 작업하는 동안에도 브라우저를 열어 둘 수 있게 합니다. 각 탭은 자체 선택 상태를 유지하므로 탭 간에 아무것도 전달되지 않습니다. 탭을 닫을 때 업로드나 가져오기가 아직 실행 중이면 브라우저가 확인을 요청합니다.

다양한 파일 및 폴더 작업은 아래에 자세히 설명되어 있습니다.


## 파일 업로드

**끌어서 놓기:**

1. 원하는 디렉터리로 이동합니다
2. 바탕 화면에서 하나 이상의 파일을 드롭 영역으로 끕니다. 왼쪽 영역은 계정의 루트로 업로드하고, 오른쪽 영역은 선택한 폴더로 업로드합니다

**마우스 오른쪽 버튼 메뉴에서:**

1. 원하는 디렉터리로 이동합니다
2. 파일 목록에서 마우스 오른쪽 버튼으로 클릭하고 `Upload Here`를 선택합니다
3. OS 파일 선택기에서 파일을 선택합니다

**도구 모음에서:**

1. 원하는 디렉터리로 이동합니다
2. 오른쪽 창에서 `Upload` 버튼을 클릭합니다

<Aside>여러 파일을 한 번에 업로드할 수 있습니다. 대상 이름이 이미 있으면 덮어쓸지 취소할지 확인하라는 메시지가 표시됩니다.</Aside>

파일 목록 아래의 점선 드롭 영역 두 개는 드롭한 항목이 업로드될 폴더를 나타냅니다. 왼쪽은 계정 루트이고 오른쪽은 선택한 폴더입니다.

### 업로드 및 가져오기 패널

**Uploads and imports** 패널은 파일이 이동하는 동안 브라우저 아래에 나타나며, 표시할 내용이 없으면 자동으로 숨겨집니다. 업로드마다, 그리고 테이블로의 가져오기마다 한 행이 있으며, 각 행에는 이름, 상태, 그리고 해당 상황에 맞는 작업이 표시됩니다.

- 실행 중인 업로드에는 진행률 표시줄과 **취소**가 표시됩니다. **모두 취소**는 실행 중인 모든 업로드를 중지합니다.
- 실패한 업로드에는 **다시 시도**와 **닫기**가 있습니다. 이유를 읽을 수 있도록 닫을 때까지 유지됩니다.
- 완료된 업로드는 몇 초 후에 저절로 닫힙니다.
- 테이블로의 가져오기는 닫을 때까지 유지됩니다. 완료되면 **미리보기 ›**, **단계 만들기 ›**, **단계 열기 ›** 버튼으로 계속 진행할 수 있습니다. **감시 중지**는 아직 실행 중인 가져오기의 추적을 중지하며, 가져오기 자체는 취소되지 않습니다.


## 파일 다운로드

1. 원하는 디렉터리로 이동합니다
2. 원하는 파일을 왼쪽 클릭하여 선택합니다
3. 마우스 오른쪽 버튼으로 클릭하고 `Download`를 선택합니다


## 파일 이름 바꾸기

1. 원하는 디렉터리로 이동합니다
2. 원하는 파일을 왼쪽 클릭하여 선택합니다
3. 마우스 오른쪽 버튼으로 클릭하고 `Rename`을 선택합니다


## 파일 이동

1. 원하는 디렉터리로 이동합니다
2. 원하는 파일을 왼쪽 클릭하여 선택합니다
3. 대상 폴더로 끌어다 놓습니다
4. `Move File`을 선택합니다


## 파일 복사

1. 원하는 디렉터리로 이동합니다
2. 원하는 파일을 왼쪽 클릭하여 선택합니다
3. 마우스 오른쪽 버튼으로 클릭하고 `Copy`를 선택합니다


## 파일 삭제

1. 원하는 디렉터리로 이동합니다
2. 원하는 파일을 왼쪽 클릭하여 선택합니다
3. 마우스 오른쪽 버튼으로 클릭하고 `Delete`를 선택합니다


## 폴더 만들기

1. 계정을 엽니다
2. `New Top Level Folder`를 클릭합니다(또는 기존 폴더를 마우스 오른쪽 버튼으로 클릭하고 `New Folder`를 선택합니다)
3. 폴더 이름을 입력합니다
4. `Create`를 클릭합니다


## 폴더 이름 바꾸기

1. 원하는 디렉터리로 이동합니다
2. 원하는 폴더를 왼쪽 클릭하여 선택합니다
3. 마우스 오른쪽 버튼으로 클릭하고 `Rename`을 선택합니다


## 폴더 이동 또는 복사

1. 원하는 디렉터리로 이동합니다
2. 원하는 폴더를 왼쪽 클릭하여 선택합니다
3. 대상 폴더로 끌어다 놓습니다
4. 폴더를 다른 위치로 옮기려면 `Move Folder`를, 원래 위치에 그대로 두려면 `Copy Folder`를 선택합니다

어느 쪽이든 폴더와 그 안의 모든 항목이 함께 이동됩니다.


## 폴더 삭제

1. 원하는 디렉터리로 이동합니다
2. 원하는 폴더를 왼쪽 클릭하여 선택합니다
3. 마우스 오른쪽 버튼으로 클릭하고 `Delete`를 선택합니다


## 폴더 내용 다운로드(zip 파일)

`Download as Zip` 옵션은 선택한 폴더 아래의 모든 파일을 하나의 `.zip`으로 압축하여 다운로드합니다. 아카이브는 탐색기에 표시된 폴더 구조를 유지합니다.

1. 원하는 디렉터리로 이동합니다
2. 원하는 폴더를 왼쪽 클릭하여 선택합니다
3. 마우스 오른쪽 버튼으로 클릭하고 `Download as ZIP`을 선택합니다


## 읽기 전용 계정

계정이 읽기 전용으로 표시되어 있으면 업로드 관련 요소(끌어서 놓기 안내, 도구 모음의 `Upload` 버튼, `Upload Here` 상황에 맞는 메뉴)가 자동으로 숨겨집니다. 찾아보기, 다운로드, 검색은 계속 작동합니다.


## 검색

계정 전체(여러 하위 폴더 또는 연결된 여러 계정 포함)에서 파일을 찾으려면 [문서 검색](../searching-documents/)을 참조하십시오.
