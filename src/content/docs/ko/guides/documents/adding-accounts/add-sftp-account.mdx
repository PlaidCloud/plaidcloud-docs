## SFTP 서버 설정

SFTP 서버 관리자에게 다음 항목을 받아 두십시오.

1. SFTP 서버의 **호스트 이름 또는 IP 주소**
2. **SSH 포트**(기본값은 `22`)
3. 대상 디렉터리에 액세스할 수 있는 **사용자 이름**
4. 인증에 사용할 **암호** 또는 **SSH 개인 키**
5. 선택 사항으로, 엄격한 호스트 확인을 위한 **서버의 SSH 호스트 키 핑거프린트**

이제 SFTP 계정을 PlaidCloud Document에 추가하는 데 필요한 모든 정보를 갖추었습니다.


## PlaidCloud Document 설정

1. PlaidCloud에 로그인합니다.
2. 새 Document 계정을 둘 워크스페이스를 선택합니다.
3. `Document > Manage Accounts`로 이동합니다.
4. `+ New Account` 버튼을 선택합니다.
5. **서비스 유형**으로 `Secure File Transfer (SFTP)`를 선택합니다.
6. 이름과 설명을 입력합니다.
7. **시작 경로** 필드에 원격 디렉터리 경로를 입력합니다(예: `/data/uploads`).
8. 용도에 맞는 **보안 모델**을 선택합니다. 잘 모르겠으면 `Private`로 둡니다.
9. **사용자 이름**을 인증 자격 증명 아래의 공개 키/사용자 필드에 입력합니다.
10. **암호**를 인증 자격 증명 아래의 개인 키/암호 필드에 입력합니다.
11. **SSH 구성** 탭으로 이동합니다.
12. SFTP 서버의 **호스트 또는 IP 주소**를 입력합니다.
13. **SSH 연결 포트**를 입력합니다(기본값 `22`).
14. 암호 대신 키 기반 인증을 사용하는 경우 **RSA 개인 키**를 RSA 개인 키 필드에 붙여넣습니다. 개인 키를 입력하면 암호보다 우선합니다. 저장된 키는 다시 표시되지 않으며, 암호 인증으로 되돌리려면 **저장된 키 지우기(암호 사용)** 옵션을 선택합니다.
15. 선택 사항으로, 엄격한 호스트 키 확인을 위해 **원격 서버 RSA 핑거프린트**를 붙여넣습니다. 비워 두면 처음 연결할 때 자동으로 채워집니다.
16. 저장 버튼을 선택하면 새 Document 계정이 활성화됩니다.

<Aside>저장하기 전에 SSH 구성 탭의 **SSH 연결 테스트** 버튼으로 SSH 연결을 테스트할 수 있습니다.</Aside>
