## WebDAV 서버 설정

WebDAV 서버 관리자에게 다음 항목을 받아 두십시오.

1. **WebDAV 엔드포인트 URL**(예: `https://nextcloud.yourcompany.com/remote.php/dav/files/username/`)
2. 대상 디렉터리에 액세스할 수 있는 **사용자 이름**
3. 인증에 사용할 **암호** 또는 앱 전용 암호

<Aside>많은 클라우드 서비스가 WebDAV 인터페이스를 제공합니다. 예를 들어 Nextcloud는 `https://your-server/remote.php/dav/files/{username}/`를, ownCloud는 `https://your-server/remote.php/webdav/`를 사용합니다. 올바른 URL은 사용 중인 제공업체의 설명서를 확인하십시오.</Aside>

이제 WebDAV 계정을 PlaidCloud Document에 추가하는 데 필요한 모든 정보를 갖추었습니다.


## PlaidCloud Document 설정

1. PlaidCloud에 로그인합니다.
2. 새 Document 계정을 둘 워크스페이스를 선택합니다.
3. `Document > Manage Accounts`로 이동합니다.
4. `+ New Account` 버튼을 선택합니다.
5. **서비스 유형**으로 `WebDAV`를 선택합니다.
6. 이름과 설명을 입력합니다.
7. **시작 경로** 필드에 전체 **WebDAV 엔드포인트 URL**을 입력합니다(예: `https://nextcloud.yourcompany.com/remote.php/dav/files/username/`).
8. 용도에 맞는 **보안 모델**을 선택합니다. 잘 모르겠으면 `Private`로 둡니다.
9. **사용자 이름**을 인증 자격 증명 아래의 사용자 이름 필드에 입력합니다.
10. **암호**를 인증 자격 증명 아래의 암호 필드에 입력합니다.
11. 저장 버튼을 선택하면 새 Document 계정이 활성화됩니다.
