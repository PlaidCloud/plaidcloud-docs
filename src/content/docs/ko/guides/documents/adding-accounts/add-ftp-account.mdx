## FTP 서버 설정

FTP 서버 관리자로부터 다음 항목을 받을 수 있는지 확인하십시오.

1. **FTP 서버 URL**(예: `ftp://ftp.yourcompany.com` 또는 `ftp://192.168.1.100`)
2. 대상 디렉터리에 액세스할 수 있는 **사용자 이름**
3. 인증을 위한 **암호**

<Aside>FTP는 자격 증명과 데이터를 일반 텍스트로 전송합니다. 프로덕션 환경에서는 SSH를 통해 모든 트래픽을 암호화하는 SFTP 사용을 고려하십시오. SFTP를 지원하지 않는 레거시 시스템에 연결할 때만 FTP를 사용하십시오.</Aside>

이제 PlaidCloud Document에 FTP 계정을 추가하는 데 필요한 모든 것을 갖추었습니다.


## PlaidCloud Document 설정

1. PlaidCloud에 로그인합니다
2. 새 문서 계정을 둘 워크스페이스를 선택합니다
3. `Document > Manage Accounts`로 이동합니다
4. `+ New Account` 버튼을 선택합니다
5. 서비스 유형으로 `FTP`를 선택합니다
6. 이름과 설명을 입력합니다
7. **FTP 서버 URL**을 **시작 경로** 필드에 입력합니다(예: `ftp://ftp.yourcompany.com`)
8. 사용 목적에 맞는 **보안 모델**을 선택합니다. 잘 모르겠으면 `Private`로 둡니다.
9. **사용자 이름**을 인증 자격 증명 아래의 사용자 이름 필드에 입력합니다
10. **암호**를 인증 자격 증명 아래의 암호 필드에 입력합니다
11. 저장 버튼을 선택하면 새 문서 계정이 활성화됩니다
