계정 관리 양식에서는 스토리지 연결 정보와 시작 경로를 구성할 수 있습니다. 시작 경로를 사용하면 계정 사용자가 디렉터리 트리의 더 아래쪽에서 디렉터리 구조 탐색을 시작할 수 있습니다. 이 옵션은 파일 스토리지를 분리해야 하는 팀이 여러 개 있지만 기반 스토리지 서비스 계정은 하나만 두려는 경우에 유용합니다.



문서 계정의 시작 경로 옵션은 다음과 같은 이유로 유용합니다.


* 특정 팀과 그룹에 대해 하위 디렉터리에 대한 액세스를 제어할 때
* 버킷 하나에만 액세스 권한을 부여할 때

예를 들어 `Team 1` 문서 계정의 시작 경로를 *teams/team_1/*으로, `Team 2` 문서 계정의 시작 경로를 *teams/team_2*로 설정하면 공유 계정에서 서로 다른 시작 지점이 제공됩니다. 멤버가 Team 1 문서 계정을 열면 *team/team_1* 안에서 파일 탐색을 시작합니다. 트리의 위쪽으로 이동하여 *teams/team_1* 위에 있는 항목을 볼 수 없습니다.



Team 2도 Team 1의 영역으로 이동할 수 없다는 비슷한 제한을 받습니다.



이를 통해 추가 버킷이나 특별한 권한 같은 클라우드 스토리지의 복잡성을 더하지 않고도, 특정 팀은 트리의 하위 수준으로 제한하고 다른 팀에는 트리의 상위 수준에 대한 액세스를 허용할 수 있습니다.



## 시작 경로 추가 및 업데이트


1. Document > Manage Accounts로 이동합니다
2. 편집하려는 계정을 선택하고 편집 모드로 들어갑니다
3. 시작 경로 텍스트 필드에 시작 경로를 추가합니다
4. 저장 버튼을 선택합니다

## 시작 경로 형식


경로는 항상 버킷 이름으로 시작하고 그 뒤에 하위 디렉터리가 이어집니다.



```text
<my-bucket>/folder1/folder2/
```
