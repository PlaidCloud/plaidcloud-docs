임시 스토리지라고 하면 직관에 어긋나게 들릴 수 있지만, 실제 사용에서 유용하다는 것이 확인되었습니다. 일반적으로 영구 스토리지는 멤버 간 또는 다른 시스템 간에 큰 파일을 옮기는 데 사용되는데, 이러한 스토리지 위치의 파일 정리는 기껏해야 되는대로 이루어지는 경우가 많습니다. 그 결과 있어서는 안 될 파일로 스토리지가 가득 차고, 결국 수동 정리가 필요해집니다.



임시 스토리지는 파일이 24시간 후에 자동으로 삭제되므로 이러한 유형의 큰 파일을 공유하거나 전송하기에 알맞습니다.



## 임시 스토리지 옵션 보기


1. PlaidCloud에서 `Document > Temp Share`로 이동합니다

## 공유 임시 스토리지


공유 임시 스토리지는 워크스페이스의 모든 멤버가 볼 수 있지만 워크스페이스 간에는 볼 수 없습니다. 공유 임시 스토리지 영역에 액세스하려면 `Temp Share` 메뉴를 선택하고 `Workspace Temp Share`를 클릭하여 워크스페이스의 Temp Share 영역에 현재 있는 파일 표를 표시합니다.



### 공유 임시 스토리지 위치에 새 파일 추가


1. 문서 기본 페이지 위쪽의 `Temp Share` 메뉴를 선택합니다
2. `Workspace Temp Share`를 클릭합니다
3. `Browse`를 클릭하여 로컬에 저장된 항목을 찾아봅니다
4. 원하는 파일을 선택하고 `Open`을 클릭합니다
5. `Upload`를 클릭하여 파일을 임시 스토리지 위치에 업로드합니다

### 임시 스토리지에서 기존 파일 다운로드


1. 파일 유형을 나타내는 맨 왼쪽 아이콘을 클릭합니다

### 파일을 수동으로 삭제


1. 파일 이름 왼쪽에 있는 빨간색 삭제 아이콘을 클릭합니다.

파일 관리에 관한 자세한 내용은 아래 “파일 탐색기”에서 확인할 수 있습니다.



## 개인 임시 스토리지


개인 임시 스토리지는 해당 임시 공유가 속한 멤버만 볼 수 있습니다. 이 스토리지 옵션은 워크스페이스 간에도 액세스할 수 있어 유용합니다. 이 기능 덕분에 멤버가 여러 워크스페이스에서 동시에 작업할 때 워크스페이스 간에 파일을 쉽게 옮기거나 사용할 수 있습니다.



워크스페이스의 모든 멤버는 드롭박스처럼 다른 멤버의 개인 공유에 파일을 업로드할 수 있습니다.



### 다른 멤버의 개인 공유에 파일 업로드:


1. 문서 기본 페이지 위쪽의 `Temp Share` 메뉴를 선택합니다
2. `Drop File to Member Temp.`를 선택합니다. 멤버 목록이 표시됩니다.
3. 선택한 멤버와 연결된 맨 왼쪽 아이콘을 클릭합니다
4. `Browse`를 클릭하여 로컬에 저장된 항목을 찾아봅니다
5. 원하는 파일을 선택한 다음 `Open`을 클릭합니다
6. `Upload`를 클릭하여 파일을 멤버의 개인 스토리지에 업로드합니다

파일 업로드에 관한 자세한 내용은 아래 “파일 탐색기”에서 확인할 수 있습니다.
