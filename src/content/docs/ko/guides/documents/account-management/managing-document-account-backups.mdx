Document는 계정의 파일을 자동으로 백업하지 않습니다. 예를 들어 다른 클라우드 공급자의 계정에 두 번째 사본을 보관하려면 워크플로로 파일을 복사하고 일정에 따라 실행하십시오.

1. [Copy Document Directory](/ko/reference/workflow-steps/document/copy-document-directory/) 단계가 포함된 워크플로를 만듭니다.
2. **Copy Directory**에서 백업할 계정과 폴더를 선택합니다.
3. **Select Destination**에서 복사할 대상 계정과 사본을 둘 폴더를 선택합니다.
4. 워크플로를 예를 들어 매일 밤 실행되도록 예약합니다. [워크플로 예약](/ko/get-started/tutorials/schedule-a-workflow/)을 참조하십시오.

여러 계정이 하나의 백업 계정을 공유할 수 있습니다. **Rename the Copied Folder to:** 를 선택하고 원본 계정의 이름을 따라 이름을 지정하여 각 사본에 고유한 이름을 부여하면 폴더가 서로 충돌하지 않습니다.

<Aside type="caution">Copy Document Directory 단계는 대상에서 이름이 같은 항목을 덮어쓰므로, 실행할 때마다 사본의 기록을 유지하지 않고 이전 사본을 대체합니다.</Aside>
