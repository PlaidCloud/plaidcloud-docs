문서 계정을 폐기, 교체 또는 다시 구축하기 전에 해당 계정을 사용하는 모든 항목을 찾은 다음, 그 사용처를 다른 계정으로 옮기십시오.

## 계정이 사용되는 위치 확인

1. `Document > Manage Accounts`를 선택합니다.
2. 계정 행에서 **Used By** 아이콘을 선택합니다.

**사용 위치**에는 각 사용처가 프로젝트, 유형, 이름, 계정이 사용되는 방식과 함께 나열됩니다.

| 열 | 값 |
| --- | --- |
| 유형 | 단계, 워크플로 또는 프로젝트 기본값 |
| 사용 방식 | 직접, 컨테이너 조건, 프로젝트 기본값 또는 변수(사용될 수 있음) |

역할상 볼 수 없는 단계와 워크플로는 개수만 계산되고 이름은 표시되지 않습니다. 목록은 프로젝트 단위로 수집되며, 불완전할 수 있는 경우나 한 번도 스캔되지 않은 프로젝트가 있는 경우에는 그 사실을 알려 줍니다.

App Runner 매니페스트와 프로젝트 타일 이미지는 스캔되지 않습니다. 변수에서 비롯된 사용처는 목록에 표시되며, 해당 변수는 직접 업데이트해야 합니다.

## 계정 재지정

1. **사용 위치**에서 **Re-point...** 버튼을 선택합니다.
2. 전환할 계정을 선택한 다음 **미리 보기**를 선택합니다.
3. 사용처를 검토합니다. 아직 아무것도 변경되지 않았습니다. 그대로 두려는 항목은 선택을 해제합니다.
4. **Re-point**를 선택하고 확인합니다.

그러면 각 사용처에 결과가 **Changed**, **Changed since the preview**, **Not allowed**, **Project is locked**, **No longer exists**, **Refused** 중 하나로 표시됩니다. 실패한 사용처가 있어도 다른 사용처는 중단되지 않습니다. 프로젝트 기본값을 변경하려면 아키텍트 또는 워크스페이스 관리자여야 합니다.

변수 사용처는 변경되지 않습니다. 미리 보기에는 각 변수의 이름과 직접 업데이트해야 할 단계가 표시됩니다.

<Aside type="caution">개인 임시 드라이브로 재지정하면 워크플로가 프로젝트 권한으로 실행되는데, 프로젝트는 해당 드라이브를 열 수 없으므로 재지정된 단계는 실행될 때 실패합니다. PlaidCloud는 영향을 받는 각 프로젝트에 대해 경고합니다.</Aside>

## AI 어시스턴트 사용

* 프로젝트의 AI 어시스턴트가 재지정을 제안할 수 있습니다. 변경 사항을 승인 카드에 표시하며, 사용자가 승인한 후에만 적용합니다.
* MCP에서는 `document_account_describe(include=['used_by'])`가 사용처를 나열하고, `document_account_repoint`가 재지정을 미리 보고 적용합니다.
