계정에는 비공개, 워크스페이스, 멤버 전용, 보안 그룹의 네 가지 액세스 제한 유형을 사용할 수 있습니다. 사용자에게 설정한 제한 유형은 계정 양식에서 언제든지 편집할 수 있습니다.

<Aside>어떤 계정 액세스 수준에서도 문서에 액세스하는 데 사용하는 계정 자격 증명은 공개되지 않습니다. 계정 소유자만 자격 증명을 볼 수 있습니다.</Aside>

## 계정 액세스 업데이트


1. PlaidCloud에서 `Document > Manage Accounts`를 선택합니다
2. 변경하려는 계정의 편집 모드로 들어갑니다
3. `Security Model` 아래에 있는 원하는 액세스 수준 제한을 선택합니다
4. 저장 버튼을 선택합니다

<Aside>선택한 보안 모델에 따라, 계정 관리의 계정 목록에서 액세스를 허용할 멤버나 보안 그룹을 할당하는 옵션이 달라집니다.</Aside>


## 제한 옵션


### 모든 작업 영역 멤버


이 액세스는 워크스페이스의 모든 멤버에게 액세스를 제공하며 멤버를 추가로 할당할 필요가 없으므로 가장 간단합니다.



### 특정 멤버만


이 액세스 설정에서는 각 멤버를 계정에 할당해야 합니다. 이 옵션은 인증과 함께 전송된 그룹 목록에 따라 멤버를 할당하는 싱글 사인온 옵션과 함께 사용할 때 특히 유용합니다. 그러나 멤버 수가 많은 워크스페이스에서는 이 방식이 원하는 것보다 많은 작업을 요구하는 경우가 많으며, 이때 보안 그룹이 유용합니다. 특정 멤버만 선택하려면 다음과 같이 합니다.


1. 계정 관리 목록에서 멤버 아이콘을 선택합니다
2. 원하는 멤버를 왼쪽의 `Unassigned Members` 열에서 오른쪽의 `Assigned Members` 열로 끕니다
3. 멤버를 제거하려면 반대로 합니다
4. 저장 버튼을 선택합니다

### 특정 보안 그룹만


이 옵션을 사용하면 개별 사용자만이 아니라 특정 보안 그룹에 계정 액세스 권한이 부여됩니다. 액세스 제한이 하나 이상의 보안 그룹과의 연결을 기반으로 하므로, 사용자 수가 훨씬 많은 계정의 관리가 훨씬 간단해집니다. 할당된 그룹을 편집하려면 다음과 같이 합니다.


1. 계정 관리 목록에서 그룹 아이콘을 선택합니다
2. 원하는 그룹을 왼쪽의 `Unassigned Groups` 열에서 오른쪽의 `Assigned Groups` 열로 끕니다
3. 그룹을 제거하려면 반대로 합니다
4. 저장 버튼을 선택합니다

### 원격 에이전트


PlaidLink 에이전트는 파일을 저장하거나 시스템 간에 파일을 이동하기 위해 문서 계정을 사용하는 경우가 많습니다. 원격 에이전트가 문서 계정에 액세스하도록 하려면 에이전트에 반드시 권한이 부여되어야 합니다. 이는 중요한 정보에 대한 원치 않는 액세스를 제한하는 보안 기능입니다. 에이전트를 추가하려면 다음과 같이 합니다.


1. 계정 관리 목록에서 에이전트 아이콘을 선택합니다
2. 원하는 에이전트를 왼쪽의 `Unassigned Agents` 열에서 오른쪽의 `Assigned Agents` 열로 끕니다
3. 에이전트를 제거하려면 반대로 합니다
4. 저장 버튼을 선택합니다
