각 리포지토리는 위키를 호스팅할 수 있습니다. 위키는 코드와 섞이지 않으면서 코드 옆에 존재하는 문서용 Markdown 페이지의 별도 모음입니다.

## 위키 활성화

1. 리포지토리를 열고 **설정**을 선택합니다.
2. **피처** 아래에서 **Wiki**를 켭니다.
3. 리포지토리 탐색에 **Wiki** 탭이 나타납니다.

## 페이지 만들기 및 편집

1. **Wiki** 탭을 선택합니다.
2. 위키에 페이지가 아직 없으면 **Create the First Page**를 선택합니다. 그렇지 않으면 **New Page**를 선택합니다.
3. 페이지 제목을 입력합니다. 제목이 페이지의 URL이 되므로 명확하고 바뀌지 않을 이름을 선택하십시오.
4. Markdown으로 내용을 작성한 다음 **Save Page**를 선택합니다.

처음 만든 페이지는 방문자가 기본으로 이동하는 위키의 **홈**이 됩니다. 기존 페이지를 업데이트하려면 해당 페이지를 열고 **편집**을 선택합니다. 저장할 때마다 페이지의 수정 기록에 새 항목이 기록됩니다.

<Aside>위키는 코드와 마찬가지로 버전이 관리됩니다. 아무 페이지에서나 **Revisions** 보기를 열어 기록을 둘러보거나 이전 버전으로 되돌릴 수 있습니다.</Aside>

## 위키 구성

특별한 이름의 두 페이지가 위키 전체의 탐색을 제어합니다.

- **\_Sidebar** — 모든 페이지에 표시되는 사용자 지정 사이드바입니다. 가장 중요한 페이지로 연결되는 링크를 여기에 추가합니다.
- **\_Footer** — 모든 페이지 하단에 표시되는 바닥글입니다.

**New Page**에서 위에 표시된 정확한 이름으로 둘 중 하나를 만듭니다. 위키 페이지 사이는 페이지 슬러그를 참조하는 표준 Markdown으로 연결합니다.

```md
See the [Setup Guide](setup-guide) for installation steps.
```

처음부터 설명적인 페이지 제목을 사용하십시오. 제목이 URL이 되므로 나중에 페이지 이름을 바꾸면 해당 페이지로 연결된 기존 링크가 끊어집니다.

## 로컬에서 위키 편집

위키 자체가 Git 리포지토리이며 리포지토리의 `.wiki.git` URL에서 사용할 수 있습니다. 위키를 복제하고 편집기에서 Markdown 파일을 편집한 다음 변경 사항을 다시 푸시합니다.

```bash
git clone https://git.example.plaidcloud.com/you/my-repo.wiki.git
cd my-repo.wiki
# edit or add .md files
git add .
git commit -m "Expand the setup guide"
git push
```

기본 리포지토리에 사용하는 것과 같은 개인 액세스 토큰을 여기서도 사용할 수 있습니다. 각 Markdown 파일이 위키 페이지가 되며, 파일 이름(`.md` 확장명 제외)이 페이지 슬러그입니다.
