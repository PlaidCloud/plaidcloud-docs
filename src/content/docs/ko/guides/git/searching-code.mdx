PlaidCloud Git에서는 워크스페이스 멤버십으로 액세스할 수 있는 모든 리포지토리의 코드, 파일, 이슈, 풀 리퀘스트를 검색할 수 있습니다.

## 코드 검색

1. 아무 페이지에서나 상단의 검색 상자를 선택하고 검색어를 입력합니다.
2. **Enter** 키를 누르면 액세스할 수 있는 모든 리포지토리의 결과가 표시됩니다.
3. 결과를 선택하면 일치하는 줄이 있는 파일로 바로 이동합니다.
4. 결과 페이지에서 **리포지토리** 및 **언어** 필터로 결과 범위를 좁힙니다.

<Aside>코드 검색은 기본 브랜치를 인덱싱합니다. 다른 브랜치를 검색하려면 해당 브랜치로 이동하여 아래에 설명된 리포지토리 내 검색을 사용하십시오.</Aside>

## 리포지토리 내 검색

1. 리포지토리를 열고 **코드** 탭을 선택합니다.
2. **T** 키를 누르거나(또는 파일 찾기 상자를 선택하여) 파일 찾기를 엽니다.
3. 파일 이름 또는 경로의 일부를 입력하면 입력하는 동안 목록이 필터링됩니다.
4. 파일을 선택하여 열고, 브라우저의 페이지 내 찾기(**⌘F** / **Ctrl+F**)로 특정 줄을 찾습니다.

<Aside type="tip">파일 찾기는 경로 세그먼트를 기준으로 일치시키므로 `util/auth`를 입력하면 `src/util/auth.py`, `lib/util/auth_helper.go` 등의 경로가 표시됩니다.</Aside>

## 이슈 및 풀 리퀘스트 필터링

**Issues** 또는 **Pull Requests** 목록에서는 키워드 검색과 `key:value` 필터를 조합할 수 있습니다.

| 필터 | 예시 |
|---|---|
| 열림 또는 닫힘 상태 | `is:open`, `is:closed` |
| 레이블 | `label:bug`, `label:"needs review"` |
| 담당자 | `assignee:you` |
| 작성자 | `author:you` |
| 마일스톤 | `milestone:"v1.2"` |

검색 상자에 필터를 직접 입력하여 자유롭게 조합하고, **정렬** 메뉴를 사용하여 **최근 업데이트됨**, **댓글 많은 순**, **최신**, **가장 오래됨** 순으로 정렬합니다.

<Aside>레이블 이름에 공백이 있으면 따옴표로 묶으십시오: `label:"needs review"`.</Aside>

## 더 빨리 찾는 방법

- **정확한 구문** — 여러 단어로 된 검색어는 따옴표로 묶어(`"connection pool"`) 불필요한 부분 일치를 피합니다.
- **리포지토리로 범위 지정** — 검색하기 전에 리포지토리를 열어 두면 결과가 집중됩니다.
- **설명적인 이름의 효과** — 명확하고 구체적인 이름을 가진 리포지토리와 이슈는 `misc` 같은 일반적인 이름보다 검색에서 훨씬 안정적으로 표시됩니다.
- **레이블은 검색 가능한 메타데이터입니다** — 레이블이 잘 지정된 이슈는 본문에 묻혀 있는 이슈보다 필터링하기 쉬우므로 레이블을 일관되게 적용하십시오.
