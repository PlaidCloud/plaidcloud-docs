PlaidCloud Git에는 배포 가능한 아티팩트를 위한 내장 패키지 레지스트리와, 리포지토리 안의 대용량 바이너리 파일을 위한 Git Large File Storage(LFS)가 포함되어 있습니다.

## 패키지 레지스트리 정보

패키지 레지스트리는 소유자별로 제공되며 npm, PyPI, Maven, NuGet, RubyGems, 컨테이너 이미지 등 다양한 에코시스템 형식을 지원합니다. 패키지는 워크스페이스 내부에서만 비공개로 유지되며 인증된 멤버만 액세스할 수 있습니다.

패키지 유형마다 다음 경로 아래에 고유한 엔드포인트가 있습니다.

```
https://git.example.plaidcloud.com/api/packages/you/<type>
```

여기서 `<type>`은 에코시스템 식별자입니다(예: `npm`, `pypi`, `maven`).

## 레지스트리에 인증

패키지 관리자 작업에는 PlaidCloud Git 사용자 이름과 암호 역할을 하는 개인 액세스 토큰을 사용합니다. 토큰을 만드는 방법은 [리포지토리](/ko/guides/git/repositories/)를 참조하십시오.

## 패키지 게시

단계는 에코시스템마다 다르지만 패턴은 같습니다. 패키지 관리자가 레지스트리 URL을 가리키도록 설정하고 표준 게시 명령을 실행합니다.

npm의 경우 프로젝트에 `.npmrc`를 추가하여 패키지 범위를 레지스트리로 지정합니다.

```ini
@you:registry=https://git.example.plaidcloud.com/api/packages/you/npm/
//git.example.plaidcloud.com/api/packages/you/npm/:_authToken=YOUR_TOKEN
```

그런 다음 평소처럼 게시합니다.

```bash
npm publish
```

PyPI, Maven, NuGet 및 기타 에코시스템에서는 도구의 리포지토리 또는 소스 설정을 해당 레지스트리 URL로 지정하고 그 도구의 표준 게시 명령을 사용합니다(예: `twine upload`, `mvn deploy`, `dotnet nuget push`).

## 패키지 설치

패키지 관리자가 같은 레지스트리 URL을 가리키도록 설정하고 평소처럼 설치합니다. 위의 `.npmrc`가 있는 경우:

```bash
npm install @you/my-package
```

다른 에코시스템에서는 도구 구성에서 레지스트리를 추가 소스로 등록하고 표준 설치 명령을 사용합니다.

## Git LFS로 대용량 파일 관리

Git LFS는 기록에 있는 대용량 파일이나 바이너리 파일을 경량 포인터로 대체하고 파일 데이터를 별도로 저장하여 리포지토리를 빠르게 유지합니다. LFS는 모든 PlaidCloud Git 리포지토리에서 사용할 수 있습니다.

1. 컴퓨터에 LFS 클라이언트를 한 번 설치합니다.

   ```bash
   git lfs install
   ```

2. 리포지토리 안에서 LFS가 추적할 파일 패턴을 지정합니다.

   ```bash
   git lfs track "*.parquet"
   ```

   이 명령은 `.gitattributes`를 만들거나 업데이트합니다. 해당 파일을 커밋합니다.

   ```bash
   git add .gitattributes
   git commit -m "Track Parquet files with LFS"
   ```

3. 평소처럼 추가하고 푸시합니다. 일치하는 파일은 LFS에 자동으로 업로드됩니다.

   ```bash
   git add data/large-dataset.parquet
   git commit -m "Add dataset"
   git push origin main
   ```

<Aside type="tip">Git LFS는 리포지토리 기록 안에 있으며 `git clone` 또는 `git pull`로 가져오는 대용량 파일을 위한 기능입니다. 패키지 레지스트리는 사용자가 패키지 관리자로 설치하는, 버전이 지정된 배포 가능한 아티팩트를 위한 기능입니다. 팀원이 `npm install` 또는 `pip install`로 설치할 대상이라면 레지스트리를 사용하고, 체크아웃의 일부로 필요하다면 LFS를 사용하십시오.</Aside>
