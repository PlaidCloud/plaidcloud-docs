리포지토리에는 하나의 프로젝트에 대한 파일, 브랜치, 기록이 들어 있습니다. 이 가이드에서는 리포지토리를 만들고 컴퓨터에서 연결하는 방법을 안내합니다.

## 리포지토리 만들기

1. 워크스페이스에서 **Git**을 엽니다.
2. 오른쪽 위의 **+** 메뉴를 선택한 다음 **New Repository**를 선택합니다.
3. 이름을 입력하고, 필요하면 간단한 설명도 입력합니다.
4. 공개 범위를 선택합니다. 새 리포지토리는 기본적으로 **비공개**이며, 액세스 권한을 부여한 멤버만 볼 수 있습니다.
5. 필요하면 **Initialize Repository**를 선택하여 README, `.gitignore`, 라이선스를 추가합니다.
6. **Create Repository**를 선택합니다.

## 개인 액세스 토큰 생성

PlaidCloud를 통해 로그인하므로 계정에는 별도의 Git 암호가 없습니다. 명령줄에서 HTTPS로 복제하거나 푸시하려면 개인 액세스 토큰을 만들어 암호 대신 사용합니다.

1. 오른쪽 위의 아바타를 선택한 다음 **설정**을 선택합니다.
2. **애플리케이션** 탭을 엽니다.
3. **Manage Access Tokens** 아래에 토큰을 사용할 위치를 설명하는 이름을 입력합니다(예: `laptop`).
4. 토큰이 복제하고 푸시할 수 있도록 리포지토리 **읽기** 및 **쓰기** 범위를 선택합니다.
5. **Generate Token**을 선택합니다.
6. 토큰을 복사하여 안전한 곳에 보관합니다. 나중에 다시 볼 수 없습니다.

<Aside type="caution">토큰은 암호처럼 취급하십시오. 토큰을 가진 사람은 누구나 Git에서 사용자 본인으로 활동할 수 있습니다. 다른 토큰에 영향을 주지 않고 하나만 해지할 수 있도록 컴퓨터마다 별도의 토큰을 생성하십시오.</Aside>

## 리포지토리 복제

1. PlaidCloud Git에서 리포지토리를 엽니다.
2. **코드**를 선택한 다음 **HTTPS** 복제 URL을 복사합니다.
3. 터미널에서 해당 URL로 `git clone`을 실행합니다.

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. Git이 자격 증명을 요청하면 **PlaidCloud 사용자 이름**을 입력하고 **액세스 토큰**을 암호로 붙여넣습니다.

<Aside>푸시할 때마다 토큰을 다시 입력하지 않으려면 운영 체제의 Git 자격 증명 도우미가 토큰을 저장하도록 하십시오. 첫 푸시 전에 `git config --global credential.helper store`(macOS에서는 `osxkeychain`)를 실행합니다.</Aside>

## 변경 사항 커밋 및 푸시

복제한 리포지토리 안에서 다음을 수행합니다.

1. 변경 사항을 스테이징합니다: `git add .`
2. 메시지와 함께 기록합니다: `git commit -m "Describe what changed"`
3. PlaidCloud Git으로 전송합니다: `git push`

커밋은 리포지토리의 **Commits** 및 **활동** 보기와, 해당 커밋이 포함된 모든 브랜치 또는 풀 리퀘스트에 표시됩니다.

## 액세스 및 공개 범위 관리

리포지토리의 **설정** 탭을 열면 이름을 바꾸거나, 공개 범위를 변경하거나, 소유권을 이전할 수 있습니다. 다른 멤버가 기여할 수 있게 하려면 **설정 → Collaborators**를 사용하여 사용자 이름으로 추가하고 **읽기**, **쓰기** 또는 **관리자** 역할을 지정합니다.

<Aside>리포지토리 액세스는 워크스페이스 멤버십과 보안 그룹에도 따릅니다. 이들이 리포지토리를 보고 편집할 수 있는 사용자에 어떻게 대응하는지는 [액세스 관리](/ko/administration/access/)를 참조하십시오.</Aside>
