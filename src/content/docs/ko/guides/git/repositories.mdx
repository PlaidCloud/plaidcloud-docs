리포지토리에는 하나의 프로젝트에 대한 파일, 브랜치, 기록이 들어 있습니다. 이 가이드에서는 리포지토리를 만들고 내 컴퓨터에서 연결하는 방법을 설명합니다.

## 리포지토리 만들기

1. 워크스페이스에서 **Git**을 엽니다.
2. 오른쪽 위의 **+** 메뉴를 선택한 다음 **New Repository**를 선택합니다.
3. 이름을 입력하고, 필요하면 간단한 설명도 입력합니다.
4. 공개 범위를 선택합니다. 새 리포지토리는 기본적으로 **비공개**이며, 액세스 권한을 부여한 멤버만 볼 수 있습니다.
5. 필요하면 **Initialize Repository**를 선택하여 README, `.gitignore`, 라이선스를 추가합니다.
6. **Create Repository**를 선택합니다.

## 개인 액세스 토큰 생성하기

PlaidCloud를 통해 로그인하므로 계정에는 별도의 Git 비밀번호가 없습니다. 명령줄에서 HTTPS로 클론하거나 푸시하려면 개인 액세스 토큰을 만들어 비밀번호 대신 사용하십시오.

1. 오른쪽 위의 아바타를 선택한 다음 **설정**을 선택합니다. **Git** 탭의 설정 카드에도 이 페이지로 바로 가는 링크가 있습니다.
2. **애플리케이션** 탭을 엽니다.
3. **Manage Access Tokens**에서 토큰을 사용할 위치를 나타내는 이름을 입력합니다(예: `laptop`).
4. 토큰으로 클론과 푸시를 할 수 있도록 **write:repository** 권한을 선택합니다.
5. **Generate Token**을 선택합니다.
6. 토큰을 복사하여 안전한 곳에 보관합니다. 나중에 다시 볼 수 없습니다.

<Aside type="caution">토큰은 비밀번호처럼 취급하십시오. 토큰이 있는 사람은 누구나 Git에서 나로 행세할 수 있습니다. 다른 토큰에 영향을 주지 않고 하나만 취소할 수 있도록 컴퓨터마다 별도의 토큰을 생성하십시오.</Aside>

## 리포지토리 클론하기

1. 워크스페이스에서 **Git**을 열고 리포지토리의 클론 주소 옆에 있는 복사 버튼을 선택합니다(설정 단계를 보려면 **How to clone**을 선택합니다). 리포지토리에서 **코드**를 선택하고 **HTTPS** URL을 복사할 수도 있습니다.
2. 터미널에서 해당 URL로 `git clone`을 실행합니다.

   ```bash
   git clone <clone URL>
   ```

3. Git이 비밀번호를 물으면 **액세스 토큰**을 붙여 넣습니다. 사용자 이름은 URL에 이미 포함된 것을 사용합니다.
4. 설정 카드에 표시된 값을 사용하여 Git이 커밋에 기록할 이름과 이메일을 설정합니다.

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

푸시하려면 Contributor 또는 Administrator 액세스가 필요합니다. 뷰어는 읽을 수만 있고 푸시할 수 없습니다. [액세스 수준](/ko/guides/git/#액세스-수준)을 참조하십시오.

<Aside>푸시할 때마다 토큰을 다시 입력하지 않으려면 운영 체제의 Git 자격 증명 도우미가 토큰을 저장하게 할 수 있습니다. 예를 들어 macOS에서는 `git config --global credential.helper osxkeychain`을 사용합니다.</Aside>

## 변경 사항 커밋 및 푸시하기

클론한 리포지토리 안에서 다음을 수행합니다.

1. 변경 사항을 스테이징합니다. `git add .`
2. 메시지와 함께 변경 사항을 기록합니다. `git commit -m "Describe what changed"`
3. PlaidCloud Git으로 보냅니다. `git push`

커밋은 리포지토리의 **Commits** 및 **활동** 보기와, 해당 커밋을 포함하는 모든 브랜치 또는 풀 리퀘스트에 표시됩니다.

## 액세스 및 공개 범위 관리하기

리포지토리의 **설정** 탭을 열면 이름을 바꾸고, 공개 범위를 변경하고, 소유권을 이전할 수 있습니다. 다른 멤버가 기여할 수 있게 하려면 **설정 → Collaborators**를 사용하여 사용자 이름으로 추가하고 **읽기**, **쓰기**, **Administrator** 역할 중 하나를 지정합니다.

<Aside>리포지토리 액세스는 워크스페이스 멤버십과 보안 그룹도 따릅니다. 이들이 리포지토리를 보고 편집할 수 있는 사용자와 어떻게 대응하는지는 [액세스 관리](/ko/administration/access/)를 참조하십시오.</Aside>
