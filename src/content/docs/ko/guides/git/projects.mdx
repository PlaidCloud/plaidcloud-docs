프로젝트 보드는 이슈와 풀 리퀘스트를 워크플로의 각 단계를 나타내는 열로 배치하여, 진행 중인 작업, 막혀 있는 작업, 완료된 작업을 팀 전체가 함께 볼 수 있게 합니다.

## 보드 만들기

1. 리포지토리를 열고 **Projects** 탭을 선택합니다.
2. **새 프로젝트**를 선택합니다.
3. 보드 이름을 입력합니다.
4. 시작 템플릿을 선택합니다. 기본 **To Do / In Progress / Done** 레이아웃을 권장하며, 빈 보드를 선택하여 레이아웃을 처음부터 구성할 수도 있습니다.
5. **Create Project**를 선택하여 보드를 엽니다.

<Aside>리포지토리의 **Projects** 탭에서 만든 보드는 해당 리포지토리에 속합니다. 워크스페이스의 여러 리포지토리에 걸친 보드는 관리자가 조직 수준의 Projects 영역에서 만듭니다.</Aside>

## 열 설정

1. 열을 추가하려면 **열 추가**를 선택하고 레이블을 입력한 후 저장합니다.
2. 열 이름을 바꾸려면 해당 열의 설정을 열고 **편집**을 선택합니다.
3. 열 머리글을 왼쪽이나 오른쪽으로 끌어 순서를 바꿉니다.
4. 열 설정에서 한 열을 기본값으로 지정합니다. 대상을 지정하지 않고 추가한 카드는 이 열에 놓입니다.

## 카드 추가 및 이동

- 기존 이슈나 풀 리퀘스트를 추가하려면 열의 메뉴를 열고 **Add an item**을 선택한 다음 제목이나 번호로 검색합니다.
- 보드에서 바로 새 이슈를 만들려면 열 안에서 **+** 를 선택합니다. 이슈는 리포지토리에 저장되고 즉시 카드로 표시됩니다.
- 작업이 진행되면 카드를 다른 열로 끌어다 놓습니다. 카드의 위치는 현재 상태를 반영하며, 그 자체로 이슈의 레이블이나 담당자를 변경하지는 않습니다.

## 작업 추적

보드를 사용하면 개별 이슈를 열지 않고도 팀의 업무량을 한눈에 파악할 수 있습니다. 다음과 같이 최신 상태를 유지하십시오.

- 이슈를 닫거나 풀 리퀘스트를 병합하면 보드의 자동화 설정에 따라 카드가 완료 열로 이동하거나 보드에서 사라집니다.
- 칸반 보기와 함께 기한이 있는 목표가 필요하면 보드를 **Milestones**와 함께 사용합니다. 마일스톤은 마감일과 완료 비율을 추적하고, 보드는 흐름을 추적합니다.
