PlaidCloud를 **OneStream**에 연결하면 Data Foundation이 통합 결과를 읽고 관리 그룹 손익계산서를 그 결과에 대사할 수 있습니다. OneStream은 해당 커넥터를 통해 지원됩니다. PlaidCloud는 OAuth 2.0 클라이언트 자격 증명으로 로그인하고 OneStream 관리자가 만든 데이터 어댑터를 읽습니다. 읽기만 합니다. Data Management 시퀀스 이름을 지정하면 PlaidCloud가 어댑터가 읽는 내용을 새로 고치기 위해 해당 시퀀스를 먼저 실행하며, 그 외에는 아무것도 실행하지 않습니다.

OneStream은 원장 라인의 소스가 아니라 대사할 대상 결과의 소스입니다. 해당 행은 모델 예산 테이블의 `Consolidated` 시나리오, 버전 `OneStream`으로 적재됩니다. [통합 시스템에 대사](/ko/guides/projects/data-foundation/#통합-시스템과-대사)를 참조하십시오.

<Aside type="note">
어댑터의 열은 사용자와 OneStream 관리자가 합의하는 계약입니다. 어댑터가 이 페이지에 맞게 만들어지면 행이 아래 설명대로 적재됩니다. 첫 로드의 결과를 신뢰할 수 있는 OneStream 보고서와 비교하십시오.
</Aside>

## OneStream 관리자가 설정하는 내용

**Foundation** 탭에서 보낼 액세스 요청서를 작성해 줍니다. 요청서에는 다음이 포함됩니다.

1. OneStream ID 서비스에서 **클라이언트 자격 증명** 부여 방식을 사용하는 PlaidCloud용 클라이언트. 어댑터를 실행할 수 있는 서비스 사용자가 필요하며, PlaidCloud가 먼저 결과를 새로 고치게 하려면 Data Management 시퀀스도 실행할 수 있어야 합니다.

2. 보고 대상 애플리케이션과 워크스페이스에서, 통합 결과를 담은 테이블 하나를 반환하는 **Foundation_Results**라는 데이터 어댑터. 열은 정확히 다음과 같아야 합니다.

   | 열 | 내용 |
   |---|---|
   | `entity` | 통합 멤버: 엔터티, 제거 멤버 또는 그룹 합계입니다. |
   | `account` | 계정 코드입니다. 기본 계정만 해당합니다. |
   | `time` | `YYYY-MM` 형식의 월입니다. |
   | `scenario` | 시나리오입니다. |
   | `view` | `YTD` 또는 `Periodic`입니다. PlaidCloud는 선택한 뷰의 행만 읽습니다. |
   | `amount` | 보고서에 표시되는 부호와 단위의 숫자입니다. |
   | `currency` | 금액이 표시되는 통화입니다. 그룹의 보고 통화입니다. |
   | `flow`, `ud1`, `ud2`, `ud3`, `ud4` | 흐름 및 사용자 정의 차원입니다. 기본 멤버만 해당합니다. |

   계정, 흐름, 사용자 정의 차원의 기본 멤버를 제공하십시오. 상위 멤버의 행은 하위 항목을 두 번 계산하게 됩니다. 어댑터는 통합 멤버를 대체 변수 `Member`에서, 뷰를 `View`에서 읽습니다.

3. 읽을 멤버: 엔터티, 제거 멤버, 그룹 합계.

## 연결 만들기

<Steps>

1. **Tools > Connections**를 열고 `New Connection`을 클릭한 다음 **OneStream**을 선택합니다. 또는 소스를 추가할 때 **Foundation** 탭에서 만들 수 있습니다.

2. 필드를 입력합니다.

   | 필드 | 값 |
   |---|---|
   | 호스트 | `https://`로 시작하는 OneStream 기본 URL입니다. |
   | 클라이언트 ID | PlaidCloud 클라이언트의 클라이언트 ID입니다. |
   | 클라이언트 시크릿 | 해당 시크릿입니다. 암호화되어 저장되며 다시 표시되지 않습니다. |
   | 토큰 URL | 호스트 뒤에 `/identity/connect/token`을 붙인 주소를 사용하려면 비워 둡니다. |
   | 기본 애플리케이션 | 애플리케이션을 비워 둔 읽기에서 사용됩니다. |
   | 기본 워크스페이스 | 워크스페이스를 비워 둔 읽기에서 사용됩니다. |
   | 시간 제한(초) | 기본값은 120입니다. |

3. `Create`를 클릭합니다.

</Steps>

## Data Foundation 프로젝트에 추가

**Foundation** 탭에서 다른 소스와 마찬가지로 이 연결을 소스로 추가하고([ERP 연결](/ko/guides/projects/data-foundation/#erp-연결) 참조) 읽을 통합 멤버를 선택합니다. 그런 다음 어댑터의 금액을 설명하는 항목에 답합니다.

| 설정 | 의미 |
|---|---|
| 멤버 | 읽을 통합 멤버이며, 멤버마다 어댑터를 한 번씩 호출합니다. |
| 뷰 | 어댑터의 금액이 누계(기본값)인지 기간별인지 지정합니다. 누계 행은 기간별 금액으로 적재됩니다. |
| 부호 | **자연**: 각 계정을 OneStream이 보고하는 고유한 부호로 표시합니다(기본값). **차변 양수**: 차변을 양수로 표시합니다. |
| 단위 | 전체 통화 단위로 환산하는 배수입니다. OneStream이 천 단위로 제공하면 `1000`입니다. |
| 회계 연도 시작 월 | 누계를 기간별로 변환하기 위한 회계 연도의 시작 월입니다. |
| 애플리케이션, 워크스페이스 | 연결의 값을 재정의합니다. |
| 대체 변수 | 어댑터가 읽는 추가 변수입니다. 예: `Time=2026M1`. |
| Data Management 시퀀스 | 어댑터가 읽는 내용을 새로 고치기 위해 읽기 전에 실행하는 시퀀스입니다. |

이 소스에 적용되는 코드 매핑 파일로 OneStream 멤버를 엔터티에 매핑합니다. [엔터티 매핑표](/ko/guides/projects/data-foundation/#엔터티-매핑표)를 참조하십시오. 이 소스는 이력 기간을 읽지 않으며, 어댑터 자체의 대체 변수가 범위를 제한합니다.

어댑터에서 행이 반환되지 않는 로드는 오류가 아닌 경고와 함께 완료되며 테이블은 비어 있게 됩니다.
