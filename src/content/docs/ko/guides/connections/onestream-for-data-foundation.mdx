Data Foundation이 연결 결과를 읽고 관리 그룹 손익계산서를 그 결과와 조정할 수 있도록 PlaidCloud를 **OneStream**에 연결합니다. OneStream은 해당 커넥터를 통해 지원됩니다. PlaidCloud는 OAuth 2.0 클라이언트 자격 증명으로 로그인하고 OneStream 관리자가 구축한 데이터 어댑터를 읽습니다. 읽기만 수행합니다. Data Management 시퀀스를 지정하면 PlaidCloud는 어댑터가 읽는 내용을 새로 고치기 위해 해당 시퀀스를 먼저 실행하며, 그 외에는 아무것도 실행하지 않습니다.

OneStream은 원장 라인이 아니라 조정 대상이 되는 결과의 소스입니다. 해당 행은 모델 예산 테이블의 `Consolidated` 시나리오, 버전 `OneStream`으로 저장됩니다. [연결 시스템과 조정](/ko/guides/projects/data-foundation/#통합-시스템과-대사)을 참조하십시오.

<Aside type="note">
어댑터의 열은 사용자와 OneStream 관리자가 합의하는 계약입니다. 어댑터를 이 페이지에 맞게 구축하면 행이 아래 설명대로 저장됩니다. 첫 로드의 결과를 신뢰하는 OneStream 보고서와 비교해 보십시오.
</Aside>

## OneStream 관리자가 설정하는 항목

**Foundation** 탭에서 보낼 액세스 요청서를 작성해 줍니다. 요청서에는 다음 내용이 포함됩니다.

1. OneStream ID 서비스에 있는 PlaidCloud용 클라이언트로, **클라이언트 자격 증명** 권한 부여 방식을 사용하며, 어댑터를 실행할 수 있는 서비스 사용자를 둡니다. PlaidCloud가 결과를 먼저 새로 고치도록 하려면 Data Management 시퀀스도 실행할 수 있어야 합니다.

2. 보고 대상 애플리케이션과 워크스페이스에 **Foundation_Results**라는 데이터 어댑터를 만들어, 연결 결과를 담은 테이블 하나를 정확히 다음 열로 반환하게 합니다.

   | 열 | 내용 |
   |---|---|
   | `entity` | 연결 멤버입니다: 엔터티, 제거 멤버 또는 그룹 합계입니다. |
   | `account` | 계정 코드입니다. 기본 계정만 해당합니다. |
   | `time` | `YYYY-MM` 형식의 월입니다. |
   | `scenario` | 시나리오입니다. |
   | `view` | `YTD` 또는 `Periodic`입니다. PlaidCloud는 선택한 뷰의 행만 읽습니다. |
   | `amount` | 보고서에 표시되는 부호와 단위의 숫자입니다. |
   | `currency` | 금액이 표시되는 통화로, 그룹의 보고 통화입니다. |
   | `flow`, `ud1`, `ud2`, `ud3`, `ud4` | 플로 및 사용자 정의 차원입니다. 기본 멤버만 해당합니다. |

   계정, 플로, 사용자 정의 차원의 기본 멤버를 제공하십시오. 상위 멤버의 행은 하위 멤버를 두 번 계산하게 됩니다. 어댑터는 치환 변수 `Member`에서 연결 멤버를, `View`에서 뷰를 읽습니다.

3. 읽을 멤버: 엔터티, 제거 멤버, 그룹 합계입니다.

## 연결 만들기

<Steps>

1. **Tools > Connections**를 열고 `New Connection`을 클릭한 다음 **REST - OneStream**을 선택합니다.

2. 필드를 입력합니다.

   | 필드 | 값 |
   |---|---|
   | 호스트 | `https://`로 시작하는 OneStream 기본 URL입니다. |
   | 클라이언트 ID | PlaidCloud 클라이언트의 클라이언트 ID입니다. |
   | 클라이언트 시크릿 | 해당 시크릿입니다. 암호화되어 저장되며 다시 표시되지 않습니다. |
   | 토큰 URL | 비워 두면 호스트 뒤에 `/identity/connect/token`을 붙여 사용합니다. |
   | 기본 애플리케이션 | 애플리케이션을 비워 둔 읽기에 사용됩니다. |
   | 기본 워크스페이스 | 워크스페이스를 비워 둔 읽기에 사용됩니다. |
   | 제한 시간(초) | 기본값은 120입니다. |

3. `Create`를 클릭합니다.

</Steps>

소스를 추가할 때 **Foundation** 탭에서 연결을 만들 수도 있습니다. **새 연결 만들기**를 선택하고 **API 호스트 URL**, **클라이언트 ID**, **클라이언트 시크릿**, **Token URL**, **애플리케이션**, **워크스페이스**를 입력합니다. 이 필드는 위의 필드와 의미가 같습니다.

## Data Foundation 프로젝트에 추가

**Foundation** 탭에서 다른 소스와 마찬가지로 이 연결을 소스로 추가합니다([ERP 연결](/ko/guides/projects/data-foundation/#erp-연결) 참조). OneStream은 선택할 멤버 목록을 제공하지 않으므로 양식에서 읽을 연결 멤버를 묻습니다. **이름**에 입력하십시오. 그런 다음 **System settings**에서 어댑터의 금액을 설명합니다. 설정은 다음 이름으로 표시됩니다.

| 설정 | 의미 |
|---|---|
| `view` | 어댑터의 금액이 연초 누계이면 `ytd`(기본값), 기간별이면 `periodic`입니다. 연초 누계 행은 기간별 금액으로 저장됩니다. |
| `sign` | `natural`(기본값)은 OneStream이 보고하는 대로 각 계정이 자체 부호를 따릅니다. `debit_positive`는 차변이 양수입니다. |
| `scale` | 전체 통화 단위로 바꾸는 배수입니다. OneStream이 천 단위로 제공하면 `1000`입니다. 기본값은 `1`입니다. |
| `fy_start_month` | 연초 누계를 기간별로 변환할 때 사용하는 회계 연도 시작 월이며 `1`에서 `12` 사이입니다. 기본값은 `1`입니다. |
| `application`, `workspace` | 연결의 값을 재정의합니다. 연결의 값을 사용하려면 비워 둡니다. |
| `table` | 어댑터 데이터 세트 내의 테이블 이름입니다. 기본값은 `Results`입니다. |
| `sequence` | 어댑터가 읽는 내용을 새로 고치기 위해 읽기 전에 실행하는 Data Management 시퀀스입니다. |

이 소스에 적용되는 코드 매핑 파일로 OneStream 멤버를 엔터티에 매핑합니다. [엔터티 크로스워크](/ko/guides/projects/data-foundation/#엔터티-매핑표)를 참조하십시오. 이 소스에는 이력 범위가 없으며, 어댑터 자체의 치환 변수가 범위를 제한합니다.

어댑터에서 행이 반환되지 않는 로드는 오류가 아니라 경고와 함께 완료되며 테이블은 비어 있습니다.
