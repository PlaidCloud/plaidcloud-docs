[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, SAP S/4HANA Cloud는 Data Foundation이 직접 읽는 ERP 중 하나입니다. 이 연결은 OAuth 2.0 클라이언트 자격 증명으로 테넌트의 릴리스된 OData 서비스를 읽으며, 에이전트는 사용하지 않습니다. 이 페이지는 이를 설정하는 S/4HANA Cloud 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호나 클라이언트 시크릿은 이메일로 보내지 마십시오.

## 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **SAP S/4HANA Cloud 연결** 아래의 **새 연결 만들기**를 선택합니다. 양식에 전체 요청 내용이 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "Read-only SAP S/4HANA Cloud access for PlaidCloud (OAuth 2.0 client credentials)"라는 제목으로 메일 프로그램에서 열립니다.

## S/4HANA Cloud 관리자가 설정하는 항목

<Steps>

1. **Maintain Communication Users** 앱에서 PlaidCloud용 **통신 사용자를 만듭니다.** 인증 방법은 사용 환경에 따라 OAuth 2.0 또는 사용자 이름과 암호 중에서 선택합니다.

2. **Communication Systems** 앱에서 PlaidCloud용 **통신 시스템을 만들고**, 인바운드 통신에 해당 사용자와 OAuth 2.0 클라이언트 자격 증명을 지정합니다.

3. **Communication Arrangements** 앱에서 아래 각 시나리오에 대해 **통신 어레인지먼트를 만들며**, 모두 2단계의 시스템을 대상으로 합니다. 이들이 함께 PlaidCloud가 읽는 OData 서비스를 노출합니다.

   | 시나리오 | 서비스 |
   |---|---|
   | Company Code | `API_COMPANYCODE_SRV` |
   | G/L Account in Chart of Accounts | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | Cost Center | `API_COSTCENTER_SRV` |
   | Business Partner and Customer | `API_BUSINESS_PARTNER` |
   | Product | `API_PRODUCT_SRV` |
   | Fiscal Year Variant Periods | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | Exchange Rates | `API_EXCHANGERATE_SRV` |
   | Journal Entry Item | `API_JOURNALENTRYITEMBASIC_SRV`(분개장과 이월 잔액) |
   | Billing Document | `API_BILLING_DOCUMENT_SRV`(선택 사항: 청구된 판매, 문서, 항목이 추가됨) |

   통신 사용자에게 보고 대상인 모든 회사 코드에 대한 액세스를 부여합니다.

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 테넌트 API의 호스트(예: `my300000-api.s4hana.cloud.sap`) | **호스트** |
| 클라이언트 ID | **클라이언트 ID** |
| 보안 연결 양식을 통해 전달하는 클라이언트 시크릿 | **클라이언트 시크릿**, 팀이 직접 붙여 넣음 |
| 토큰 URL. 사용 환경이 테넌트 자체 서버(`/sap/bc/sec/oauth2/token`) 대신 XSUAA 권한 부여 서버를 사용하는 경우에만 해당 | **Token URL (optional)** |
| 범위. XSUAA 권한 부여 서버를 사용하는 경우에만 해당 | **Scope (optional)** |
| 로드하는 각 회계 연도에 **Carry Forward Balances**를 실행했는지 여부 | 입력할 것 없음. 기초 잔액은 여기에서 읽습니다. |

<Aside type="caution">
클라이언트 시크릿은 이메일로 보내지 마십시오. **클라이언트 시크릿**은 비밀 값으로, 연결에 저장되며 다시 표시되지 않습니다.
</Aside>

## 액세스 확인

PlaidCloud로 돌아가 값을 입력하고 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | 필요한 서비스 |
|---|---|
| 엔터티 | `API_COMPANYCODE_SRV` |
| 계정과목표 | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| 부서 | `API_COSTCENTER_SRV` |
| 고객 | `API_BUSINESS_PARTNER` |
| 제품 | `API_PRODUCT_SRV` |
| 환율 | `API_EXCHANGERATE_SRV` |
| 회계 달력 | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| 총계정원장 | `API_JOURNALENTRYITEMBASIC_SRV` |
| 시산표 | `API_JOURNALENTRYITEMBASIC_SRV` |
| 판매 라인 | `API_BILLING_DOCUMENT_SRV`(선택 사항) |

데이터 세트가 **권한 누락**으로 표시되면 관리자에게 해당 서비스의 통신 어레인지먼트를 추가해 달라고 요청한 후 다시 테스트하십시오. 판매 라인, 예산, 재고 잔액은 선택 사항이므로, 이를 보유하지 않은 테넌트도 나머지는 모두 로드됩니다.
