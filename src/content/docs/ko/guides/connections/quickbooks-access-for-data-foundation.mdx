[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 및 회계 시스템의 데이터를 인스턴스 수에 관계없이 하나의 Common Finance Model로 가져옵니다. QuickBooks Online은 Data Foundation이 직접 읽는 시스템 중 하나입니다. 이 페이지는 액세스를 설정하는 QuickBooks 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호나 토큰은 이메일로 보내지 마십시오.

## 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **새 연결 만들기**를 선택하고 **QuickBooks Online**을 고릅니다. 양식에 전체 요청 내용이 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "Read-only QuickBooks Online access for PlaidCloud"라는 제목으로 메일 프로그램에서 열립니다.

## QuickBooks 관리자가 설정하는 항목

<Steps>

1. **PlaidCloud가 대리할 QuickBooks 사용자를 선택합니다.** QuickBooks에서 해당 사용자는 다음 항목을 볼 수 있어야 합니다.

   - 계정과목표, 고객, 제품 및 서비스, 위치
   - 총계정원장, 시산표, 손익계산서 보고서(Reports에서 이를 실행할 수 있는 사용자)
   - 판매 트랜잭션: 송장, 판매 영수증, 대변 메모, 환불 영수증
   - 모델에 포함하려는 경우 예산과 재고 평가 요약(QuickBooks Plus 또는 Advanced)

   회사 관리자는 이미 이 권한이 있습니다. 제한된 사용자는 해당 권한을 켜야 합니다.

2. **PlaidCloud를 한 번 승인합니다.** 해당 사용자가 PlaidCloud 사용자가 보낸 연결에서 Intuit의 동의 화면에 로그인합니다. 범위는 Accounting(`com.intuit.quickbooks.accounting`)뿐입니다.

3. **연결마다 회사 하나.** QuickBooks 회사가 여러 개이면 각 회사를 별도의 연결에서 승인합니다.

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 모델에 표시될 회사 이름 | 연결에 선택하는 **회사** |
| 특정 날짜까지 장부가 마감되었는지 여부(**Settings > Account and Settings > Advanced > Accounting**) | 입력할 것 없음: PlaidCloud가 QuickBooks에서 장부 마감일을 읽음 |

**Foundation** 탭에서 PlaidCloud 사용자가 새 연결을 입력합니다.

- **회사 ID(realm ID)**
- **Refresh token**: PlaidCloud 사용자가 직접 붙여 넣는 비밀 값
- **환경**: `production` 또는 `sandbox`

**System settings**에서 **Retained earnings account**는 계정 이름만으로 알 수 없는 경우 기초 손익계산서가 이월되는 자본 계정을 지정합니다. 선택 사항입니다.

## 액세스 확인

PlaidCloud로 돌아가 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | QuickBooks에서 읽는 항목 |
|---|---|
| 엔터티 | 회사 정보 |
| 계정과목표 | 계정과목표 |
| 회계 달력 | 회사 기본 설정: 회계 연도의 첫 달과 장부 마감일 |
| 시산표 | 기초 잔액용 시산표 보고서 |
| 총계정원장 | 총계정원장 보고서 |
| 부서 | 위치(선택 사항) |
| 고객 | 고객(선택 사항) |
| 제품 | 제품 및 서비스(선택 사항) |
| 판매 라인 | 송장, 판매 영수증, 대변 메모, 환불 영수증(선택 사항) |
| 예산 | 예산(선택 사항) |
| 재고 잔액 | 재고 평가 요약(선택 사항) |
| 환율 | 환율(선택 사항) |

데이터 세트가 **권한 누락**으로 표시되면 테스트에서 추가해야 할 액세스를 알려 줍니다. 관리자에게 해당 사용자에게 권한을 켜 달라고 요청한 후 다시 테스트하십시오. 예산 같은 선택 데이터가 없는 회사도 나머지는 모두 로드됩니다.

QuickBooks에는 거래 상대방, 회사 간 거래 계정, 원장이 없으므로 QuickBooks 회사의 라인에는 해당 정보가 없습니다.
