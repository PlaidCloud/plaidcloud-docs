PlaidCloud를 IBM **TM1 / Planning Analytics** 서버에 연결하면 워크플로가 저장된 뷰나 MDX 쿼리에서 큐브 데이터를 읽거나, 차원 계층을 PlaidCloud 차원으로 로드할 수 있습니다. 연결은 기본적으로 TM1 자체 REST API에 **클라우드에서 직접** 접속합니다. 사용자 네트워크 내부에서만 접근할 수 있는 TM1 서버는 대신 온프레미스 [PlaidLink 에이전트](/ko/reference/cli/plaidlink/)가 접속합니다. 아래의 [방화벽 뒤의 TM1 읽기](#방화벽-뒤의-tm1-읽기)를 참조하십시오. 이 가이드에서는 연결, 클라우드 직접 쿼리 실행, 한 번에 한 기간씩 가져오는 증분 추출 패턴, 온프레미스 경로를 설명합니다.

<Aside type="note">
이 커넥터는 읽기 전용입니다. TM1에 대한 쓰기 저장이나 TI 프로세스 실행은 지원하지 않습니다.
</Aside>

## 사전 요구 사항

TM1 관리자에게서 다음 정보가 필요합니다.

- **TM1 REST API 호스트**(예: `https://tm1-prod.example.com:8010`) 또는 PAaaS URL.
- 워크플로가 쿼리할 데이터베이스, 큐브, 뷰에 대한 읽기 권한이 있는 **TM1 계정**(사용자 이름과 암호).
- 해당 계정이 **Native**(TM1 사용자/암호)로 인증하는지 **CAM**(Cognos Access Manager SSO)으로 인증하는지, 그리고 CAM인 경우 **네임스페이스**.
- 사용자가 읽을 **데이터베이스(인스턴스) 이름**.

## 연결 만들기

<Steps>

1. **Tools > Connections**를 열고 `New Connection`을 클릭합니다.

2. 메뉴에서 **IBM Planning Analytics (TM1)** 를 선택합니다.

3. 필드를 입력합니다.

   | 필드 | 값 |
   |---|---|
   | 이름 | 알아보기 쉬운 이름(예: `TM1 Prod`). |
   | 호스트 | TM1 REST API 호스트(예: `https://tm1-prod.example.com:8010`). |
   | 기본 데이터베이스 | 선택 사항. 단계의 데이터베이스 필드에 미리 채울 TM1 데이터베이스. |
   | 인증 모드 | `Native` 또는 `CAM`. |
   | 사용자 이름 | TM1 계정 사용자 이름. |
   | 암호 | TM1 계정 암호. |
   | CAM 네임스페이스 | 인증 모드가 CAM인 경우에만 필요합니다. |
   | SSL 인증서 확인 | 기본적으로 켜져 있습니다. 테스트 서버에서 알려진 자체 서명 인증서를 사용하는 경우에만 끄십시오. |
   | 제한 시간(초) | 기본값은 30입니다. |

4. `Test Connection`을 클릭합니다. 테스트에 성공하면 서버의 제품 버전이 보고됩니다.

5. `Create`를 클릭합니다.

</Steps>

## 쿼리 실행

<Steps>

1. 워크플로에 **TM1: 큐브 쿼리** 단계를 추가합니다(단계 메뉴의 **IBM TM1 / Planning Analytics** 아래에 있습니다).

2. **소스 및 대상**에서 **TM1 연결**, **환경**, **데이터베이스**, **큐브**, **대상 테이블**을 설정합니다. 큐브 옵션은 데이터베이스를 선택하면 연결된 데이터베이스에서 실시간으로 검색됩니다. 검색 결과에 나타나지 않으면 이름을 직접 입력하십시오.

3. **슬라이스**에서 **소스 모드**를 선택합니다.

   - **뷰 기준** - 저장된 TM1 뷰를 선택합니다. 뷰 옵션은 큐브를 선택하면 실시간으로 검색됩니다.
   - **MDX 기준** - 큐브에 대한 MDX 쿼리를 작성합니다.

4. 필요하면 **관점**에서 뷰나 MDX가 이미 고정한 것 외의 차원 멤버를 고정합니다. 관점은 `By MDX`에서만 적용할 수 있습니다.

5. **미리 보기**를 클릭하면 현재 슬라이스를 실행하여 저장하기 전에 처음 몇 행과 셀 수를 확인할 수 있습니다.

</Steps>

## 기간별 증분 추출

TM1은 변경 사항을 추적하지 않으므로 변경 이후 데이터를 요청하는 호출이 없습니다. 대신 실행할 때마다 **기간**(또는 버전)으로 슬라이스합니다. 관점에서 `Period`를 리터럴 멤버 이름이 아닌 `{period}` 워크플로 변수로 고정하십시오. 관점 멤버 값은 MDX 필드와 마찬가지로 실행 시점에 워크플로 자체의 변수로 대체되므로, 각 실행은 큐브 전체를 다시 읽는 대신 지정된 기간만 가져옵니다. 실행할 때마다 값이 바뀌는 변수가 있는 [일정이 설정된 워크플로](/ko/administration/scheduled-events/)에 이 단계를 배치하면 한 번에 한 기간씩 이력이 쌓입니다.

## 옵션

- **0/빈 셀 숨기기** - 기본적으로 꺼져 있습니다. 값이 0인 셀을 가져온 **후에야** 제거하므로 대역폭을 절약하지 못하며, 전기된 `0`이 실제 데이터인 계획 큐브에서는 이를 버리게 됩니다. 대신 쿼리 자체에서 0을 숨기는 것이 좋습니다. MDX에서는 `NON EMPTY`를 사용하거나 저장된 뷰의 자체 숨기기 설정을 사용하십시오.
- **행 제한** - 기본값은 250,000입니다. 행 제한을 설정하지 않으면 "무제한"이 아니라 이 상한이 적용됩니다. 유효 제한보다 많은 셀을 반환하는 쿼리는 조용히 잘리는 대신 거부됩니다. 쿼리 범위를 좁히거나, 정당한 대규모 추출이면 행 제한을 직접 높이십시오.

## 차원 계층 로드

[TM1: 차원 읽기](/ko/reference/workflow-steps/ibm-planning-analytics/tm1-dimension-read/) 단계는 TM1 계층 하나의 요소, 부모/자식 간선, 속성을 읽어 PlaidCloud 차원으로 로드하며, 동일한 연결을 통해 클라우드에서 직접 수행됩니다. 이 단계는 TM1: 큐브 쿼리와 별개의 단계이며, 큐브 셀이 아닌 차원 구조를 읽습니다. 한 계층에서 두 개의 통합 아래에 있는 TM1 요소나 일반 `+`/`-`/`~` 부호로 표현할 수 없는 통합 가중치는 잘못 로드되는 대신 거부되거나 표시됩니다. 두 제한에 대한 자세한 내용은 단계 참조를 확인하십시오.

## 방화벽 뒤의 TM1 읽기

TM1 서버에 PlaidCloud가 직접 접근할 수 있는 네트워크 경로(공개 엔드포인트, 허용 목록에 등록된 IP, VPN)가 없다면 대신 설치된 **PlaidLink 에이전트**를 통해 읽습니다. [TM1: 큐브 쿼리(에이전트)](/ko/reference/workflow-steps/ibm-planning-analytics/tm1-query-remote/) 단계는 위에서 설명한 것과 같은 뷰/MDX/관점 쿼리를 실행하지만, 이를 에이전트에 전달하며 에이전트가 사용자 네트워크에서 TM1에 접속합니다.

다음이 필요합니다.

<Steps>

1. **설치된 PlaidLink 에이전트.** TM1 서버에 네트워크로 접근할 수 있어야 합니다. [PlaidLink 설치](/ko/reference/cli/plaidlink/install/)를 참조하십시오.

2. **TM1을 지원하는 에이전트 빌드.** PlaidCloud는 전달하기 전에 에이전트가 알리는 기능을 확인하므로, TM1 지원이 출시되기 전에 설치한 기존 에이전트는 수동으로 다시 빌드하고 다시 설치해야 합니다. PlaidLink는 자동으로 업데이트되지 않습니다. [PlaidLink 업그레이드](/ko/reference/cli/plaidlink/upgrade/)를 참조하십시오.

3. **해당 에이전트와 공유된 TM1 연결.** 연결이 이미 가진 멤버 또는 그룹 액세스에 더하여, 연결의 `Actions > Agents` 목록에서 공유합니다. [보안 모델](/ko/guides/connections/create-connection/#보안-모델)을 참조하십시오.

</Steps>

**TM1: 큐브 쿼리(에이전트)** 단계를 추가하고 에이전트를 선택한 다음, TM1: 큐브 쿼리와 동일한 연결, 데이터베이스, 큐브, 슬라이스 필드를 입력합니다. 이 단계에는 실시간 검색이나 미리 보기가 없습니다. 에이전트는 폼이 열려 있는 동안이 아니라 실행 중에만 접근할 수 있기 때문입니다. 따라서 큐브, 뷰, MDX는 직접 입력하며 단계가 실행될 때 검증됩니다.
