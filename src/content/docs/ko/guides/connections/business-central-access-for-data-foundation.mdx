[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 통합하며, Microsoft Dynamics 365 Business Central은 Data Foundation이 직접 읽는 ERP 중 하나입니다. 이 연결에는 클라이언트 자격 증명을 사용하는 Microsoft Entra ID 애플리케이션, 읽기 전용 권한 집합, 웹 서비스로 게시된 몇 개의 페이지 개체가 사용됩니다. 이 페이지는 이를 설정하는 Business Central 관리자와, 관리자에게 설정을 요청하는 PlaidCloud 사용자를 위한 안내입니다.

PlaidCloud는 데이터를 읽기만 합니다. 클라이언트 시크릿은 이메일로 보내지 마십시오.

## 액세스 요청 보내기

**홈**의 **Data Foundation** 아래에 있는 프로젝트의 **시스템** 페이지에서 **시스템 추가** 아래의 **시스템**에서 사용 중인 시스템을 선택하고 **아직 액세스 권한이 없으십니까?** 버튼을 클릭합니다. 시스템이 액세스 대기 상태가 되고, 프로젝트의 시스템을 모두 다루는 요청 하나가 표시됩니다. **요청 복사**를 클릭하여 직접 작성하는 메시지에 붙여 넣거나, **이메일 요청**을 클릭하여 메일 프로그램에서 여십시오. 제목은 "PlaidCloud 액세스"로 설정됩니다.

## Business Central 관리자가 설정하는 항목

<Steps>

1. **Microsoft Entra ID에 앱을 등록합니다.** **App registrations > New registration**에서 클라이언트 시크릿을 추가하고, Directory(tenant) ID, Application(client) ID, 시크릿을 기록해 둡니다.

2. **Business Central에 앱을 추가합니다.** **Microsoft Entra Applications**를 열고 애플리케이션을 추가한 다음 상태를 **사용**으로 설정하고, 보고 대상인 모든 회사에 대해 권한 집합 **D365 READ**만 부여합니다. 이 권한 집합으로 아래의 모든 페이지를 읽습니다. **D365 BASIC**이나 쓰기가 가능한 다른 권한 집합은 부여하지 마십시오.

3. **페이지 개체를 웹 서비스로 게시합니다.** **Search > Web Services > New**에서 다음 페이지 개체를 아래와 정확히 같은 서비스 이름(Service Name)으로 게시하고 **Published**를 선택합니다. 표준 API에는 이 개체들의 필드가 포함되어 있지 않습니다.

   | 페이지 | 서비스 이름 | 참고 |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | 매출원가 및 재고 잔액용, 선택 사항 |
   | 120 G/L Budget Entries | `GLBudgetEntries` | 예산용, 선택 사항 |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | 통계 드라이버용, 선택 사항 |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | 바로 가기 차원 3~8용, 선택 사항 |
   | 479 Dimension Set Entries | `DimensionSetEntries` | 바로 가기 차원 3~8용, 선택 사항 |
   | 573 Detailed Cust. Ledg. Entries | `DetailedCustLedgEntries` | 미결 항목 및 결제용, 선택 사항 |
   | 574 Detailed Vendor Ledg. Entries | `DetailedVendorLedgEntries` | 미결 항목 및 결제용, 선택 사항 |
   | 371 Bank Account List | `BankAccounts` | 은행 잔액용, 선택 사항 |
   | 277 Bank Account Posting Groups | `BankAccountPostingGroups` | 은행 잔액용, 선택 사항 |
   | Inventory Posting Setup(해당 페이지 검색) | `InventoryPostingSetup` | 품목 구매 라인의 계정용, 선택 사항 |

4. **PlaidCloud 사용자에게 세 가지 선택 사항을 알려 줍니다.** 감사 조정 분개를 전기할 소스 코드(PlaidCloud는 `ADJUSTMENT`로 가정합니다), 부서에 해당하는 차원(PlaidCloud는 `DEPARTMENT`라는 이름의 Global Dimension 1로 가정합니다), 이익 센터에 해당하는 차원(PlaidCloud는 `PROFITCENTER`라는 이름의 Global Dimension 2로 가정합니다)입니다. 사이트는 Business Central 위치(location)입니다.

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| Directory(tenant) ID | **Azure AD 테넌트 ID** |
| Application(client) ID | **클라이언트 ID** |
| 클라이언트 시크릿 | **클라이언트 시크릿**: 이메일이 아니라 연결 편집기에서 입력합니다 |
| 환경 이름(예: `production`) | **환경** |
| 회사 하나의 ID | **회사 ID**: 연결에 하나가 필요하며, Data Foundation은 **회사**에서 선택한 회사를 읽습니다 |
| 부서에 해당하는 차원의 이름 | **Department dimension** 시스템 설정 |
| 이익 센터에 해당하는 차원의 이름 | **Profit centre dimension** 시스템 설정 |
| 감사 조정 분개를 전기할 소스 코드 | **Audit adjustment source code** 시스템 설정 |
| PlaidCloud가 읽을 수 있는 회사 | **옵션**의 **회사**: 회사를 선택하거나, 모든 회사를 읽으려면 선택하지 않습니다 |

연결 회사(consolidation company)인 회사는 **Consolidation companies** 시스템 설정에 지정하여, 해당 항목이 개별 회사의 활동으로 집계되지 않도록 합니다. 환율은 한 회사에서 가져옵니다. **Exchange rate company** 시스템 설정에 해당 회사를 지정하며, 지정하지 않으면 PlaidCloud는 첫 번째 회사를 사용합니다.

## 액세스 확인

PlaidCloud로 돌아가 시스템이 추가되면 **시스템** 페이지에서 해당 시스템 행의 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | 필요한 항목 |
|---|---|
| 엔터티, 계정과목표, 고객, 제품, 환율, 시산표 | API 액세스(권한 집합 D365 READ) |
| 회계 달력 | `AccountingPeriods` 웹 서비스 |
| 부서 | `DimensionValues` 웹 서비스 |
| 총계정원장 | `GLEntries` 웹 서비스 |
| 그 밖의 모든 데이터 세트 | 선택 사항이며 테스트에 포함되지 않습니다 |

데이터 세트가 누락되면 테스트에서 추가해야 할 권한이나 웹 서비스를 알려 줍니다. 관리자에게 해당 항목을 추가하도록 요청한 후 다시 테스트하십시오.

선택 사항인 데이터 세트는 사이트, 이익 센터, 공급업체, 월말 잔액, 은행 잔액, 재고 잔액, 판매 라인, 공급업체 청구서 라인, 미결 항목, 결제, 예산, 배부 동인입니다. 이 중 하나를 사용하지 않는 환경에서도 나머지 데이터는 모두 로드되며, 다음 로드 후 **CFM-Accounting - Close and assurance** 대시보드의 준비 상태 검사에서 Business Central이 거부하는 페이지를 알려 줍니다. 월말 잔액은 각 월말 시점의 시산표이며, 은행 잔액은 은행 계정이 전기되는 계정에 대한 해당 잔액입니다. 특정 월의 월말 잔액, 은행 잔액, 재고, 판매 라인, 공급업체 청구서 라인, 미결 항목 또는 결제를 구성하는 읽기를 Business Central이 거부하면, 해당 월은 이미 있던 행을 유지하고 다음 로드에서 다시 읽습니다.
