[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, Microsoft Dynamics 365 Business Central은 Data Foundation이 직접 읽는 ERP 중 하나입니다. 이 연결에는 클라이언트 자격 증명을 사용하는 Microsoft Entra ID 애플리케이션, 읽기 전용 권한 집합, 웹 서비스로 게시된 몇 개의 페이지가 사용됩니다. 이 페이지는 이를 설정하는 Business Central 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 클라이언트 시크릿은 이메일로 보내지 마십시오.

## 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **Business Central 연결** 아래의 **새 연결 만들기**를 선택합니다. 양식에 전체 요청 내용이 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials)"라는 제목으로 메일 프로그램에서 열립니다.

## Business Central 관리자가 설정하는 항목

<Steps>

1. **Microsoft Entra ID에 앱을 등록합니다.** **App registrations > New registration**에서 클라이언트 시크릿을 추가하고 디렉터리(테넌트) ID, 애플리케이션(클라이언트) ID, 시크릿을 기록해 둡니다.

2. **Business Central에 앱을 추가합니다.** **Microsoft Entra Applications**를 열고 애플리케이션을 추가한 다음 상태를 **사용**으로 설정하고, 보고 대상인 모든 회사에 대해 **D365 READ** 및 **D365 BASIC** 권한 집합을 부여합니다. 쓰기 권한 집합은 부여하지 마십시오.

3. **페이지를 웹 서비스로 게시합니다.** **Search > Web Services > New**에서 다음 페이지를 아래 서비스 이름 그대로 게시하고 **Published**를 선택합니다. 표준 API에는 이 페이지의 필드가 포함되어 있지 않습니다.

   | 페이지 | 서비스 이름 | 참고 |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | 매출원가, 선택 사항 |
   | 120 G/L Budget Entries | `GLBudgetEntries` | 예산, 선택 사항 |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | 통계 드라이버, 선택 사항 |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | 바로 가기 차원 3~8, 선택 사항 |
   | 479 Dimension Set Entries | `DimensionSetEntries` | 바로 가기 차원 3~8, 선택 사항 |

4. **PlaidCloud 사용자에게 두 가지 선택 사항을 알려 줍니다.** 감사 조정 항목을 전기할 소스 코드(PlaidCloud는 `ADJUSTMENT`로 가정함)와 부서에 해당하는 차원(PlaidCloud는 `DEPARTMENT`라는 이름의 글로벌 차원 1로 가정함)입니다.

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 디렉터리(테넌트) ID | **Directory (tenant) ID** |
| 환경 이름(예: `production`) | **환경 이름** |
| 애플리케이션(클라이언트) ID | **Application (client) ID** |
| 클라이언트 시크릿 | **클라이언트 시크릿**, 이메일이 아닌 양식을 통해 입력 |
| 부서에 해당하는 차원의 이름 | `department_dimension` 시스템 설정 |
| PlaidCloud가 읽을 수 있는 회사 | PlaidCloud의 **Companies**에서 선택(하나 이상) |

연결 회사인 회사는 `consolidation_companies` 시스템 설정에 넣어, 해당 항목이 한 회사의 활동으로 집계되지 않도록 합니다. 환율은 한 회사에서 가져옵니다. `rate_company` 시스템 설정에 그 회사를 지정하거나, 지정하지 않으면 PlaidCloud가 첫 번째 회사를 사용합니다.

## 액세스 확인

PlaidCloud로 돌아가 값을 입력하고 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | 필요한 항목 |
|---|---|
| 엔터티, 계정과목표, 고객, 제품, 환율, 시산표 | API 액세스(권한 집합 D365 READ) |
| 회계 달력 | `AccountingPeriods` 웹 서비스 |
| 부서 | `DimensionValues` 웹 서비스 |
| 총계정원장 | `GLEntries` 웹 서비스 |
| 판매 라인, 예산, 배부 동인 | 선택 사항 |

데이터 세트가 누락되면 테스트에서 추가해야 할 권한이나 웹 서비스를 알려 줍니다. 관리자에게 추가를 요청한 후 다시 테스트하십시오. 판매 라인, 예산, 배부 동인은 선택 사항이므로, 이를 사용하지 않는 환경도 나머지는 모두 로드됩니다.
