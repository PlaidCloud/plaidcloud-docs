[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 및 회계 시스템의 데이터를 인스턴스 수에 관계없이 하나의 Common Finance Model로 가져옵니다. Xero는 Data Foundation이 직접 읽는 시스템 중 하나이며, 연결 하나당 Xero 조직 하나를 읽습니다. 이 페이지는 액세스를 설정하는 Xero 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호는 이메일로 보내지 마십시오.

## 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **새 연결 만들기**를 선택하고 **Xero**를 고릅니다. 양식에 전체 요청 내용이 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "Read-only Xero access for PlaidCloud"라는 제목으로 메일 프로그램에서 열립니다.

## Xero 관리자가 설정하는 항목

<Steps>

1. 보고 대상인 각 조직에 대해 Standard 또는 Advanced 역할의 사용자로 로그인하여 **PlaidCloud의 Xero 앱을 승인합니다.** 이 앱은 읽기 권한만 요청합니다.

   | 범위 | 포함 내용 |
   |---|---|
   | `accounting.settings.read` | 조직, 계정과목표, 추적 범주, 품목 |
   | `accounting.contacts.read` | 고객 |
   | `accounting.transactions.read` | 판매 송장 및 대변 메모 |
   | `accounting.journals.read` | 총계정원장: 전기된 모든 분개 |
   | `accounting.reports.read` | 기초 잔액용 시산표 |

   `accounting.journals.read`가 없으면 총계정원장을 로드할 수 없습니다. 계정과목표, 부서, 고객, 제품은 계속 로드됩니다.

2. 다음 이름으로 **PlaidCloud가 읽는 추적 범주를 설정합니다.**

   - **Department:** 부서마다 옵션 하나씩, 코드로 표시하려는 이름으로 지정합니다.
   - **Intercompany:** 그룹 회사마다 옵션 하나씩, 해당 회사의 엔터티 코드로 이름을 지정하며 회사 간 거래 분개의 라인에 사용합니다. 계정 이름에 "Intercompany"가 포함되도록 회사 간 거래 계정의 이름을 지정하십시오.

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 조직의 테넌트 ID(Xero의 연결 아래 또는 `GET /connections`에 표시됨) | **Organisation (tenant) ID** |
| 조직의 회계 연도 종료일과 기간 잠금일이 설정되어 있다는 확인 | 입력할 것 없음: PlaidCloud가 Xero에서 둘 다 읽음 |

PlaidCloud 사용자가 **Refresh token**을 직접 붙여 넣습니다. 이는 비밀 값이므로 이메일로 보내지 않습니다. 또한 연결이 로드되는 **조직**도 선택합니다.

**System settings**에서 **Retained earnings account**는 계정 이름만으로 알 수 없는 경우 기초 손익계산서가 이월되는 자본 계정을 지정합니다. 선택 사항입니다.

## 액세스 확인

PlaidCloud로 돌아가 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | 필요한 범위 |
|---|---|
| 엔터티 | `accounting.settings.read` |
| 계정과목표 | `accounting.settings.read` |
| 부서 | `accounting.settings.read`(Department 추적 범주) |
| 제품 | `accounting.settings.read` |
| 회계 달력 | `accounting.settings.read` |
| 고객 | `accounting.contacts.read` |
| 총계정원장 | `accounting.journals.read` |
| 시산표 | `accounting.reports.read` |
| 판매 라인(선택 사항) | `accounting.transactions.read` |
| 예산(선택 사항) | `accounting.reports.read` |

데이터 세트가 **권한 누락**으로 표시되면 테스트에서 부여해야 할 범위를 알려 줍니다. 해당 범위로 앱을 다시 승인한 후 다시 테스트하십시오. 판매 송장이나 예산이 없는 Xero 조직도 나머지는 모두 로드됩니다.

환율은 이 액세스에 포함되지 않습니다. Xero는 환율을 제공하지 않으므로 대신 **환율** 파일로 제공하십시오.
