PlaidCloud를 Sage Intacct에 연결하여 재무 및 회계 데이터를 가져옵니다. 이 가이드는 Web Services 자격 증명 준비부터 실제 데이터 가져오기까지 안내합니다. 필드 참조는 [Sage Intacct REST 커넥터](/ko/reference/connectors/rest/sage-intacct/)를 참조하십시오.

## 사전 요구 사항

Sage Intacct에서 다음이 필요합니다.

- 회사에 **Web Services**가 활성화되어 있어야 합니다. Sage 지원팀이 **Sender ID**와 **Sender password**를 발급하며, 이는 연결의 **클라이언트 ID**와 **클라이언트 시크릿**이 됩니다.
- PlaidCloud용 **Web Services 사용자**. 쿼리가 읽는 **모든** 개체에 대한 권한이 있어야 합니다.
- **회사 ID**.

시작하기 전에 회사 ID, 웹 서비스 사용자 이름, 클라이언트 ID(Sender ID), 클라이언트 시크릿(Sender password)을 기록해 두십시오.

<Aside type="caution">클라이언트 ID/클라이언트 시크릿과 웹 서비스 사용자 이름은 별개입니다. 클라이언트 ID/클라이언트 시크릿은 Sage에 애플리케이션을 인증하고, 웹 서비스 사용자 이름은 회사 ID와 함께 회사 내 로그인을 인증합니다. 세 가지가 모두 필요하며, 클라이언트 ID/클라이언트 시크릿은 비밀 정보입니다.</Aside>

## 연결 만들기

Intacct는 **REST 계열** 연결입니다. PlaidCloud는 OAuth2 토큰 엔드포인트를 미리 채우고 아래 네 가지 자격 증명 필드만 수집하는 전용 **Intacct** 변형(**REST - Intacct**로 표시됨)을 제공합니다. 내부적으로는 Intacct REST API에 대해 OAuth2 클라이언트 자격 증명으로 인증하는 REST 연결입니다.

<Steps>

1. **Tools > Connections**를 열고 `New Connection`을 클릭합니다.

2. **REST** 아래에서 **Intacct**(메뉴에는 **REST - Intacct**로 표시됨)를 선택합니다.

3. 필드를 입력합니다.

   | 필드 | 값 |
   |---|---|
   | 이름 | 알아보기 쉬운 이름(예: `Intacct Prod`). |
   | 클라이언트 ID | Intacct **Sender ID**. |
   | 클라이언트 시크릿 | Intacct **Sender password**. |
   | 웹 서비스 사용자 이름 | Web Services 사용자 로그인. |
   | 회사 ID | 연결하려는 Intacct 회사. |

4. `Create`를 클릭합니다.

</Steps>

## 연결 스모크 테스트

이 자격 증명을 기반으로 작업하기 전에 올바르게 동작하는지 확인합니다.

<Steps>

1. 워크플로에 [REST 요청 단계](/ko/guides/workflows/rest-request-step/)를 추가하고 **연결**을 Sage Intacct 연결로 설정합니다.

2. 사용자가 볼 수 있는 개체에 대해 범위가 작은 읽기 요청을 지정합니다.

3. **테스트 요청 보내기**를 클릭합니다.

</Steps>

<Aside type="caution">
미리 보기 탭이 아니라 **테스트 요청 보내기**를 사용하십시오. 결과가 녹색이면 클라이언트 ID/클라이언트 시크릿과 웹 서비스 사용자 이름이 모두 인증된 것입니다. 오류가 발생하면 메시지에 Sage의 자세한 내용이 포함됩니다. 대개 Web Services 사용자의 권한 부족이거나 잘못된 클라이언트 ID/클라이언트 시크릿입니다.
</Aside>

<Aside type="note">
Sage Intacct 요청은 **단일 요청이며 구성할 페이지 매김이 없습니다**. 페이지 매김 컨트롤은 그대로 두십시오.
</Aside>

## 데이터 가져오기

일반적인 가져오기에는 Intacct 개체에 바로 매핑되는 Sage Intacct 전용 가져오기 단계가 있습니다.

- [Import Sage AP](/ko/reference/workflow-steps/sage-intacct/import-sage-ap/) 단계 - AP 청구서 헤더
- [Import Sage AP Lines](/ko/reference/workflow-steps/sage-intacct/import-sage-ap-lines/) 단계 - AP 청구서 라인 상세
- [Import Sage Intacct Query](/ko/reference/workflow-steps/sage-intacct/import-intacct-query/) 단계 - 모든 Intacct 개체에 대한 쿼리
- [Import Intacct Entity](/ko/reference/workflow-steps/sage-intacct/import-intacct-entity/) 단계 - 총계정원장 상세, 계정 잔액, 분개, 차원 마스터(위치, 부서, 클래스), 판매 주문 문서를 가져오며, 대용량 결과 집합을 위한 자동 `readMore` 페이지 매김과 `ge`/`le` 범위 필터를 지원합니다

단계를 선택하고, Sage Intacct 연결을 선택한 다음, 개체 또는 쿼리를 설정하고 실행합니다. 다른 가져오기와 마찬가지로, 금액 및 날짜 열은 실제 형식으로 정의해야 텍스트가 아닌 형식이 지정된 값으로 들어옵니다.

## 확인 및 일정 설정

<Steps>

1. 단계를 실행하고 대상 테이블의 행 수와 열 형식을 확인합니다.

2. 지속적인 피드가 필요하면 [워크플로 일정을 설정](/ko/get-started/tutorials/schedule-a-workflow/)합니다.

</Steps>

## 문제 해결

| 증상 | 가능한 원인 |
|---|---|
| 인증 실패 | Sage에서 발급한 클라이언트 ID/클라이언트 시크릿이 잘못되었거나 웹 서비스 사용자 이름이 잘못되었습니다. |
| 권한 / 개체를 찾을 수 없음 오류 | Web Services 사용자에게 읽으려는 개체에 대한 권한이 없습니다. |
| 비어 있거나 예상과 다른 결과 | **회사 ID**가 잘못되었습니다. |
