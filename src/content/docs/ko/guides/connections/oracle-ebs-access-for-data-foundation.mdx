[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, Oracle E-Business Suite는 Data Foundation이 직접 읽는 ERP 중 하나입니다. PlaidCloud는 네트워크 내부에 설치된 [PlaidLink](/ko/reference/cli/plaidlink/) 에이전트를 통해서만 EBS에 접속하며, 직접 접속하지 않습니다. 이 페이지는 이를 설정하는 EBS 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호는 이메일로 보내지 마십시오.

## 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **Oracle E-Business Suite 연결** 아래의 **새 연결 만들기**를 선택합니다. 양식에 전체 요청 내용과 **How to set up PlaidLink** 링크가 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "Read-only Oracle E-Business Suite access for PlaidCloud (through PlaidLink)"라는 제목으로 메일 프로그램에서 열립니다.

## EBS 관리자가 설정하는 항목

<Steps>

1. EBS 데이터베이스에 접속할 수 있는 서버에 **PlaidLink를 설치하고** PlaidCloud에 등록합니다.

2. PlaidLink APPS 스키마 사용자(또는 APPS 객체에 대한 시노님이 있는 읽기 전용 스키마 사용자)에게 다음 항목에 대한 **SELECT 권한을 부여합니다.**

   | 영역 | 객체 |
   |---|---|
   | 총계정원장 | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES` |
   | 플렉스필드 | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | 판매(선택 사항) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |

3. 보고하려는 모든 원장과 밸런싱 세그먼트 값을 볼 수 있는 **애플리케이션 사용자**(`FND_USER`)와 책임을 지정합니다.

4. **계정과목표를 설명합니다.** 어느 세그먼트가 밸런싱 세그먼트, 자연 계정, 원가 센터, 회사 간 거래 세그먼트인지(세그먼트 한정자)를 알려 줍니다. PlaidCloud는 비용 계정 또는 그 위의 상위 값이 매출원가, 판매원가 또는 수익원가로 설명되어 있으면 해당 계정을 매출원가로 분류합니다. 이자 수익 또는 비용, 금융 수익 또는 비용, 외환, 법인세 비용, 기타 수익 및 비용 중 하나가 이름에 있으면 영업 외 계정으로 분류합니다. 상위 값에 이와 다른 표현을 사용한다면 PlaidCloud에 알려 주십시오.

5. **환율 유형을 확인합니다.** 각 기본 원장은 원장의 환산 옵션에 기간 평균 환율 유형과 기간 말 환율 유형을 지정합니다. PlaidCloud는 이 두 유형의 일일 환율로 환산합니다.

</Steps>

<Aside type="caution">
잘못된 책임을 사용하면 오류 없이 다른 원장의 행이 반환됩니다. 총계정원장 담당자와 함께 확인하십시오.
</Aside>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 데이터베이스 호스트 | **Database host** |
| 데이터베이스 포트 | **데이터베이스 포트**(변경하지 않으면 1521) |
| 서비스 이름 | **서비스 이름** |
| APPS 스키마 사용자 | **APPS schema user** |
| 보안 연결 양식을 통해 전달하는 APPS 스키마 암호 | **APPS schema password**, 팀이 직접 붙여 넣음 |
| `FND_USER` | **Application user (FND_USER)** |
| 책임 키 | **Responsibility key** |
| PlaidCloud가 읽을 수 있는 밸런싱 세그먼트 값 | **Balancing segment values** 아래에 입력하며, 시스템이 로드 전에는 목록을 가져올 수 없습니다. **이름**에 값 하나를 입력하거나, 비워 두면 기본 원장의 모든 엔터티를 로드합니다 |

인스턴스에 접속하는 PlaidLink 에이전트는 시스템 설정에서 `agent`로 선택합니다.

<Aside type="caution">
암호는 이메일로 보내지 마십시오. **APPS schema password**는 비밀 값으로, 연결에 저장되며 다시 표시되지 않습니다.
</Aside>

## 액세스 확인

PlaidCloud로 돌아가 값을 입력하고 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | 읽는 객체 |
|---|---|
| 엔터티 | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| 회계 달력 | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| 계정과목표 | `GL_CODE_COMBINATIONS`, 플렉스필드 테이블 |
| 부서 | `GL_CODE_COMBINATIONS`, 플렉스필드 테이블 |
| 환율 | `GL_DAILY_RATES` |
| 총계정원장 | `GL_JE_HEADERS`, `GL_JE_LINES` |
| 시산표 | `GL_BALANCES` |
| 고객 | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`(선택 사항) |
| 제품 | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B`(선택 사항) |
| 판매 라인 | `RA_CUSTOMER_TRX` 테이블(선택 사항) |

데이터 세트가 **권한 누락**으로 표시되면 관리자에게 해당 객체에 대한 SELECT 권한 부여를 요청한 후 다시 테스트하십시오. 고객, 제품, 판매 라인은 선택 사항이므로, 이를 사용하지 않는 인스턴스도 나머지는 모두 로드됩니다.
