[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, Oracle E-Business Suite는 Data Foundation이 직접 읽는 ERP 중 하나입니다. PlaidCloud는 네트워크 내부에 설치된 [PlaidLink](/ko/reference/cli/plaidlink/) 에이전트를 통해서만 EBS에 접속하며, 직접 접속하지 않습니다. 이 페이지는 이를 설정하는 EBS 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호는 이메일로 보내지 마십시오.

## 액세스 요청 보내기

**홈**의 **Data Foundation** 아래에 있는 프로젝트의 **시스템** 페이지에서 **시스템 추가** 아래의 **시스템**에서 사용 중인 시스템을 선택하고 **아직 액세스 권한이 없으십니까?** 버튼을 클릭합니다. 시스템이 액세스 대기 상태가 되고, 프로젝트의 시스템을 모두 다루는 요청 하나가 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "PlaidCloud 액세스"라는 제목으로 메일 프로그램에서 열립니다.

## EBS 관리자가 설정하는 항목

<Steps>

1. EBS 데이터베이스에 접속할 수 있는 서버에 **PlaidLink를 설치하고** PlaidCloud에 등록합니다.

2. PlaidLink용 **읽기 전용 데이터베이스 사용자를 만듭니다.** APPS 또는 데이터를 변경할 수 있는 다른 스키마 사용자는 절대 사용하지 마십시오. 이 사용자에게 다음 권한을 부여하고, 각 항목에는 APPS 객체에 대한 같은 이름의 시노님을 둡니다. 표에 달리 명시되지 않은 한 SELECT 권한입니다.

   | 영역 | 객체 |
   |---|---|
   | 세션(필수) | `FND_GLOBAL` 및 `MO_GLOBAL`에 대한 EXECUTE, `FND_RESPONSIBILITY_VL`, 그리고 `FND_USER` 또는 같은 이름으로 `USER_ID`, `USER_NAME`, `EMPLOYEE_ID`, `DESCRIPTION`만 담은 해당 뷰. 이 항목이 없으면 모든 읽기가 실패합니다 |
   | 총계정원장 | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES`. `GL_BALANCES`에는 최신 기간뿐 아니라 모든 기간이 있어야 합니다. 이 값이 원장과 비교되는 월말 잔액입니다 |
   | 플렉스필드 | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | 판매(선택 사항) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |
   | 분개 승인자(선택 사항) | `GL_JE_BATCHES` |
   | 엔터티 국가(선택 사항) | `XLE_REGISTRATIONS`, `HZ_LOCATIONS` |
   | 매출채권, 매입채무, 은행 잔액, 공급업체 청구서(선택 사항) | `AR_PAYMENT_SCHEDULES_ALL`, `AR_CASH_RECEIPTS_ALL`, `AR_RECEIVABLE_APPLICATIONS_ALL`, `AR_ADJUSTMENTS_ALL`, `AR_RECEIPT_METHODS`, `RA_TERMS_TL`, `CE_BANK_ACCOUNTS`, `AP_INVOICES_ALL`, `AP_INVOICE_LINES_ALL`, `AP_INVOICE_DISTRIBUTIONS_ALL`, `AP_PAYMENT_SCHEDULES_ALL`, `AP_INVOICE_PAYMENTS_ALL`, `AP_CHECKS_ALL`, `AP_SUPPLIERS`, `AP_SUPPLIER_SITES_ALL`, `AP_TERMS_TL`, `PO_HEADERS_ALL`, `PO_LINES_ALL`, `MTL_ITEM_CATEGORIES`, `MTL_CATEGORIES_B` |
   | 구매, 재고, 예산, 표준 원가, 고정 자산(선택 사항) | `PO_LINE_LOCATIONS_ALL`, `PO_DISTRIBUTIONS_ALL`, `RCV_TRANSACTIONS`, `ORG_ORGANIZATION_DEFINITIONS`, `MTL_MATERIAL_TRANSACTIONS`, `MTL_SECONDARY_INVENTORIES`, `CST_STANDARD_COSTS`, `GL_BUDGETS`, `GL_BUDGET_VERSIONS`, `FA_ADDITIONS_B`, `FA_ADDITIONS_TL`, `FA_CATEGORIES_B`, `FA_BOOK_CONTROLS`, `FA_BOOKS`, `FA_CATEGORY_BOOKS`, `FA_DISTRIBUTION_HISTORY`, `FA_DEPRN_PERIODS`, `FA_DEPRN_SUMMARY`, `FA_RETIREMENTS`, `FA_TRANSACTION_HEADERS` |

   재고는 자재 트랜잭션에서 읽으므로, 재고 이력을 위해서는 자재 트랜잭션을 보관해야 합니다. 예산은 `GL_BALANCES`의 예산 잔액입니다.

3. 보고하려는 모든 원장과 밸런싱 세그먼트 값을 볼 수 있는 **애플리케이션 사용자**(`FND_USER`)와 조회 전용 책임(보기만 가능한 책임)을 지정합니다.

4. **계정과목표를 설명합니다.** 어느 세그먼트가 밸런싱 세그먼트, 자연 계정, 원가 센터, 회사 간 거래 세그먼트인지(세그먼트 한정자)를 알려 줍니다. PlaidCloud는 비용 계정 또는 그 위의 상위 값이 매출원가, 판매원가 또는 수익원가로 설명되어 있으면 해당 계정을 매출원가로 분류합니다. 이자 수익 또는 비용, 금융 수익 또는 비용, 외환, 법인세 비용, 기타 수익 및 비용 중 하나가 이름에 있으면 영업 외 계정으로 분류합니다. 상위 값에 이와 다른 표현을 사용한다면 PlaidCloud에 알려 주십시오.

5. 계정과목표의 세그먼트(`SEGMENT1`~`SEGMENT30`)에 사이트나 이익 센터를 관리한다면 **사이트 세그먼트와 이익 센터 세그먼트를 지정합니다.** EBS에는 두 가지 모두에 대한 한정자가 없습니다. PlaidCloud는 각 세그먼트 값 집합의 값을 사이트 목록과 이익 센터 목록으로 읽습니다.

6. **환율 유형을 확인합니다.** 각 기본 원장은 원장의 환산 옵션에 기간 평균 환율 유형과 기간 말 환율 유형을 지정합니다. PlaidCloud는 이 두 유형의 일일 환율로 환산합니다.

</Steps>

<Aside type="caution">
잘못된 책임을 사용하면 오류 없이 다른 원장의 행이 반환됩니다. 총계정원장 담당자와 함께 확인하십시오.
</Aside>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 데이터베이스 호스트 | **호스트 또는 IP 주소** |
| 데이터베이스 포트 | **포트**(변경하지 않으면 1521) |
| 서비스 이름 | **서비스 이름** |
| 읽기 전용 데이터베이스 사용자 | **데이터베이스 사용자(APPS 스키마)** |
| 보안 연결 양식을 통해 전달하는 해당 사용자의 암호 | **암호**, 팀이 직접 입력함 |
| `FND_USER` | **애플리케이션 사용자(FND_USER.USER_NAME)** |
| 책임 키 | **책임 키(FND_RESPONSIBILITY.RESPONSIBILITY_KEY)** |
| PlaidCloud가 읽을 수 있는 밸런싱 세그먼트 값 | **옵션**의 **회사**에 입력하며, EBS는 목록을 제공할 수 없습니다. 값을 쉼표로 구분하여 입력하거나, 비워 두면 모든 기본 원장의 모든 엔터티를 로드합니다 |

인스턴스에 접속하는 PlaidLink 에이전트는 **PlaidLink agent** 시스템 설정에 지정합니다. 사이트 세그먼트와 이익 센터 세그먼트는 **Site segment** 및 **Profit centre segment** 시스템 설정에 지정합니다.

<Aside type="caution">
암호는 이메일로 보내지 마십시오. **암호**는 비밀 값으로, 연결에 저장되며 다시 표시되지 않습니다.
</Aside>

## 액세스 확인

PlaidCloud로 돌아가 시스템이 추가되면 **시스템** 페이지에서 해당 시스템 행의 **연결 테스트**를 클릭합니다. EBS는 PlaidLink 에이전트를 통해 접속하므로, 테스트는 에이전트가 로그인에 사용하는 모든 항목이 연결에 지정되어 있는지 확인합니다. 테이블 자체는 첫 로드 때 읽으며, 에이전트가 읽을 수 없는 테이블은 그때 표시됩니다. 각 데이터 세트가 읽는 객체는 다음과 같습니다.

| 데이터 세트 | 읽는 객체 |
|---|---|
| 엔터티 | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| 회계 달력 | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| 계정과목표 | `GL_CODE_COMBINATIONS`, 플렉스필드 테이블 |
| 부서 | `GL_CODE_COMBINATIONS`, 플렉스필드 테이블 |
| 환율 | `GL_DAILY_RATES` |
| 총계정원장 | `GL_JE_HEADERS`, `GL_JE_LINES` |
| 시산표 | `GL_BALANCES` |
| 고객 | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`(선택 사항) |
| 제품 | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B`(선택 사항) |
| 판매 라인 | `RA_CUSTOMER_TRX` 테이블(선택 사항) |
| 월말 잔액 | `GL_BALANCES`, 모든 기간(선택 사항) |
| 은행 잔액 | `CE_BANK_ACCOUNTS`와 각 은행 현금 계정의 월말 잔액(선택 사항) |
| 사이트, 이익 센터 | 각각에 대해 지정한 세그먼트의 값(선택 사항) |
| 공급업체 | `AP_SUPPLIERS`, `AP_SUPPLIER_SITES_ALL`, `AP_TERMS_TL`(선택 사항) |
| 미결 항목, 결제 | 매출채권, 매입채무, 은행 테이블(선택 사항) |
| 공급업체 청구서 라인 | `AP_INVOICE_LINES_ALL`과 매입채무 전표(선택 사항) |
| 구매 주문 | `PO_` 테이블, `RCV_TRANSACTIONS`, 청구서 라인(선택 사항) |
| 재고 잔액 | `MTL_MATERIAL_TRANSACTIONS`, `MTL_SECONDARY_INVENTORIES`(선택 사항) |
| 표준 원가 | `CST_STANDARD_COSTS`(선택 사항) |
| 예산 | `GL_BALANCES` 예산 잔액, `GL_BUDGETS`, `GL_BUDGET_VERSIONS`(선택 사항) |
| 고정 자산, 자산 변동 | `FA_` 테이블(선택 사항) |

로드에서 에이전트가 읽을 수 없는 테이블이 표시되면 관리자에게 해당 테이블에 대한 SELECT 권한 부여를 요청한 후 다시 로드하십시오. 권한을 부여하지 않은 선택 사항 테이블은 해당 테이블을 지정하는 경고로 표시되며, 나머지는 모두 로드됩니다. 미결 항목, 결제, 공급업체 청구서, 구매 주문, 표준 원가, 재고, 예산, 자산, 월말 잔액 및 은행 잔액은 테이블을 읽을 수 있을 때까지 이미 있던 행을 유지합니다.
