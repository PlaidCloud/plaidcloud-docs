[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, SAP ECC는 Data Foundation이 직접 읽는 ERP 중 하나입니다. PlaidCloud는 사용자 네트워크에 설치된 [PlaidLink](/ko/reference/cli/plaidlink/) 에이전트를 통해 RFC로 시스템에 접속합니다. 이 페이지는 이를 설정하는 SAP 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호는 이메일로 보내지 마십시오.

## 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **SAP ECC 연결** 아래의 **새 연결 만들기**를 선택합니다. 양식에 전체 요청 내용과 **How to set up PlaidLink** 링크가 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "Read-only SAP ECC access for PlaidCloud (through PlaidLink)"라는 제목으로 메일 프로그램에서 열립니다.

## SAP 관리자가 설정하는 항목

<Steps>

1. 보고 대상 클라이언트에 **PlaidCloud ABAP 패키지를 설치하고**(`Z_PLAIDCL_B5_READ_TABLE`의 함수 그룹), RFC로 시스템에 접속할 수 있는 PlaidLink 에이전트를 설치합니다.

2. 다음 권한을 가진 역할로 **통신 사용자를 만듭니다**(예: `PLAIDCLOUD_RFC`).

   - `S_RFC`: `Z_PLAIDCL_B5_READ_TABLE`의 함수 그룹을 실행합니다.
   - 아래 테이블에 대한 `S_TABU_NAM`(조회, `ACTVT` 03).

   | 테이블 | 내용 |
   |---|---|
   | `T001` | 회사 코드 |
   | `T009`, `T009B`, `T001B` | 회계 연도 변형 및 전기 기간 |
   | `SKA1`, `SKAT` | 총계정원장 계정 |
   | `FAGL_011PC`, `FAGL_011ZC` | 재무제표 버전 |
   | `CSKS`, `CSKT` | 원가 센터 |
   | `SETHEADER`, `SETNODE` | 원가 센터 및 이익 센터 그룹 |
   | `CEPC`, `CEPCT` | 이익 센터(선택 사항) |
   | `KNA1`, `KNVV`, `KNVH` | 고객 및 고객 계층 |
   | `MARA`, `MAKT`, `T006A` | 자재 및 단위 |
   | `TCURR`, `TCURF`, `TCURX` | 환율 및 통화 소수 자릿수 |
   | `BKPF`, `BSEG` | 회계 문서 및 해당 라인 항목 |
   | `FAGLFLEXT`, 또는 기존 총계정원장의 `GLT0` | 총계정원장 합계 |
   | `CSKB`, `CSKU`, `COEP` | 원가 요소 및 관리 회계 라인 항목: 평가 및 배부 |
   | `COSP`, `COSS`, `COSR` | 원가 센터 계획 및 통계 핵심 수치(선택 사항) |
   | `VBRK`, `VBRP`, `KONV` | 청구 문서 및 가격 조건(선택 사항) |

3. **회계 관련 질문에 답합니다**(아래 참조).

</Steps>

### 관리자가 답하는 질문

| 관리자가 알려 주는 내용 | PlaidCloud의 시스템 설정에 입력하는 위치 |
|---|---|
| 평균 환율을 보관하는 환율 유형. PlaidCloud는 매월 해당 유형의 환율을 평균합니다. 대개 `M`입니다. | `average_rate_type` |
| 월말 환율인 마감 환율을 보관하는 환율 유형. 지정하지 않으면 마감 환율은 `M` 환율입니다. | `closing_rate_type` |
| 시스템이 새 총계정원장(`FAGLFLEXT`)을 사용하는지 기존 총계정원장(`GLT0`)을 사용하는지 여부 | `totals` |
| 관리 손익계산서와 대차대조표를 보고하는 재무제표 버전 | `fsv` |
| 해당 노드 중 수익, 매출원가, 영업 비용, 영업 외, 자산, 부채, 자본, 회사 간 거래에 해당하는 노드 | 회사 간 거래 노드는 `intercompany_nodes`. 양식에는 다른 노드 유형을 위한 필드가 없습니다. |
| 보고하는 각 회계 연도에 대해 잔액 이월이 실행되었다는 사실(`FAGLGVTR`, 기존 총계정원장에서는 `F.16`) | 입력할 것 없음. 기초 잔액은 합계 테이블에서 읽습니다. |

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 시스템 ID와 애플리케이션 서버(또는 메시지 서버와 로그온 그룹) | **Application server**, **시스템 번호** |
| 클라이언트 | **클라이언트** |
| 통신 사용자의 이름 | **사용자** |
| 암호 관리자를 통해 전달하는 통신 사용자의 암호 | **암호**, 팀이 직접 붙여 넣음 |
| 시스템에 접속하는 PlaidLink 에이전트의 이름 | 시스템 설정의 `agent` |
| PlaidCloud가 읽을 수 있는 회사 코드 | **회사 코드** 아래에 입력하며, 시스템이 로드 전에는 목록을 가져올 수 없습니다. **이름**에 회사 코드 하나를 입력하거나, 비워 두면 모든 회사 코드를 로드합니다 |

<Aside type="caution">
암호는 이메일로 보내지 마십시오. **암호**는 비밀 값으로, 연결에 저장되며 다시 표시되지 않습니다.
</Aside>

## 액세스 확인

PlaidCloud로 돌아가 값을 입력하고 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | 읽는 테이블 |
|---|---|
| 엔터티 | `T001` |
| 회계 달력 | `T001`, `T009`, `T009B`, `T001B` |
| 환율 | `TCURR`, `TCURF` |
| 계정과목표 | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC`, `CSKB`, `CSKU` |
| 부서 | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| 이익 센터 | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| 고객 | `KNA1`, `KNVV`, `KNVH` |
| 제품 | `MARA`, `MAKT`, `T006A` |
| 총계정원장 | `BKPF`, `BSEG`, `COEP` |
| 시산표 | `FAGLFLEXT` 또는 `GLT0` |
| 판매 라인 | `VBRK`, `VBRP`, `KONV` |
| 예산 | `COSP`, `COSS` |
| 배부 동인 | `COSR` |
| 재고 잔액 | `MBEW`, `MBEWH`, `T001K` |

데이터 세트가 **권한 누락**으로 표시되면 관리자에게 역할에 해당 테이블을 추가해 달라고 요청한 후 다시 테스트하십시오. 이익 센터, 판매 라인, 예산, 배부 동인, 재고 잔액은 선택 사항이므로, 이를 보유하지 않은 시스템도 나머지는 모두 로드됩니다.
