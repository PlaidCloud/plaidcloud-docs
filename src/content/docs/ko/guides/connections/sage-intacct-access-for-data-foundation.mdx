[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, Sage Intacct는 Data Foundation이 직접 읽는 ERP 중 하나입니다. 이 연결에는 Intacct Web Services가 사용되며, PlaidCloud용 발신자 승인과 읽기 전용 Web Services 사용자가 필요합니다. 이 페이지는 이를 설정하는 Sage Intacct 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호는 이메일로 보내지 마십시오.

## 액세스 요청 보내기

**홈**의 **Data Foundation** 아래에 있는 프로젝트의 **시스템** 페이지에서 **시스템 추가** 아래의 **시스템**에서 사용 중인 시스템을 선택하고 **아직 액세스 권한이 없으십니까?** 버튼을 클릭합니다. 시스템이 액세스 대기 상태가 되고, 프로젝트의 시스템을 모두 다루는 요청 하나가 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "PlaidCloud 액세스"라는 제목으로 메일 프로그램에서 열립니다.

## Sage Intacct 관리자가 설정하는 항목

<Steps>

1. **PlaidCloud를 Web Services 발신자로 승인합니다.** **Company > Admin > Web Services authorizations**에서 PlaidCloud가 알려 준 Sender ID를 추가합니다. Sender ID와 Sage가 발급한 Sender password를 회신합니다.

2. **Web Services 사용자를 만듭니다.** **Company > Admin > Users**에서 "Business" 유형이며 "Web services only" 옵션이 있는 사용자와, 다음 항목에 대한 **View** 권한이 있는 역할을 만듭니다.

   | 영역 | 객체 |
   |---|---|
   | General Ledger | Accounts, Statistical accounts, Journal entries(조정 분개장 포함 모든 분개장), Account balances, Reporting periods, Exchange rates, Budgets |
   | Company | Entities(위치), Departments, Classes, Projects |
   | Accounts Receivable | Customers, Invoices, Adjustments, Payments |
   | Accounts Payable | Vendors, Bills, Adjustments, Payments |
   | Cash Management | Checking accounts |
   | Inventory Control | Items |
   | Order Entry | Transactions(판매 송장과 이를 취소하는 대변 메모 및 반품). 판매 데이터가 필요한 경우 |

   사용자에게 회사 최상위 수준과 PlaidCloud가 보고하는 모든 엔터티에 대한 액세스를 부여합니다. 대변 메모 및 반품 트랜잭션 정의의 이름이 Sales Credit Memo와 Sales Return이 아니면 PlaidCloud 사용자에게 해당 이름을 알려 주십시오.

3. 회사에서 IP로 Web Services를 제한하는 경우 **사용자의 IP 주소를 허용합니다.**

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 회사 ID | **회사 ID** |
| Web Services 사용자 ID | **웹 서비스 사용자 이름** |
| Sender ID | **클라이언트 ID** |
| Sender password | **클라이언트 시크릿** |
| 기본값이 아닌 경우 대변 메모 및 반품 트랜잭션 정의의 이름 | **Credit memo and return document types** 시스템 설정(기본값: Sales Credit Memo, Sales Return) |
| PlaidCloud가 읽을 수 있는 엔터티 | **옵션**의 **회사**: 엔터티를 선택하거나, 모두 읽으려면 선택하지 않음 |

암호는 이메일이 아닌 암호 관리자를 통해 전달합니다. PlaidCloud 사용자의 팀이 Sender password를 **클라이언트 시크릿**으로 직접 입력합니다. 회사 자체의 제거 엔터티는 **Elimination entities** 시스템 설정에 넣습니다.

## 액세스 확인

PlaidCloud로 돌아가 시스템이 추가되면 **시스템** 페이지에서 해당 시스템 행의 **연결 테스트**를 클릭합니다. 테스트는 필수 데이터 세트를 읽고 각각을 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시합니다. 아래에 표시된 선택 사항 데이터 세트는 테스트에 포함되지 않습니다. Sage Intacct가 그중 하나를 거부하면 다음 로드 후 **CFM-Accounting - Close and assurance** 대시보드의 준비 상태 검사에서 권한을 부여해야 할 객체를 알려 줍니다.

| 데이터 세트 | 필요한 권한 |
|---|---|
| 엔터티 | Company: Entities (View) |
| 계정과목표 | General Ledger: Accounts and Statistical accounts (View) |
| 부서 | Company: Departments (View) |
| 고객 | Accounts Receivable: Customers (View) |
| 제품 | Inventory Control: Items (View) |
| 환율 | General Ledger: Exchange rates (View) |
| 회계 달력 | General Ledger: Reporting periods (View) |
| 시산표 | General Ledger: Account balances (View) |
| 총계정원장 | General Ledger: Journal entries (View) |
| 월말 잔액(선택 사항) | General Ledger: Account balances (View) |
| 은행 잔액(선택 사항) | Cash Management: Checking accounts (View), 월말 잔액 포함 |
| 사이트(선택 사항) | Company: Entities (locations) (View) |
| 이익 센터(선택 사항) | Company: Classes (View) |
| 프로젝트(선택 사항) | Company: Projects (View) |
| 공급업체(선택 사항) | Accounts Payable: Vendors (View) |
| 판매 라인(선택 사항) | Order Entry: Transactions (View) |
| 공급업체 청구서 라인(선택 사항) | Accounts Payable: Bills and Adjustments (View) |
| 미결 항목 및 결제(선택 사항) | Accounts Receivable: Invoices, Adjustments and Payments, and Accounts Payable: Bills, Adjustments and Payments (View) |
| 예산(선택 사항) | General Ledger: Budgets (View) |
| 배부 동인(선택 사항) | General Ledger: Account balances (View) |

데이터 세트가 누락되면 테스트에서 추가해야 할 권한을 알려 줍니다. 관리자에게 역할에 추가해 달라고 요청한 후 다시 테스트하십시오. 선택 사항 데이터 세트를 사용하지 않는 회사도 나머지는 모두 로드됩니다. 특정 월의 공급업체 청구서, 미결 항목 또는 결제를 구성하는 읽기를 Sage Intacct가 거부하면, 해당 월은 이미 있던 행을 유지하고 다음 로드에서 다시 읽습니다.

분개의 입력자, 일시, 승인자, 역분개 대상은 분개의 배치에서 읽습니다. 배치를 읽을 수 없는 역할이면 이 정보는 비어 있습니다.
