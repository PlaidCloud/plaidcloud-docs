[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, SAP S/4HANA는 Data Foundation이 직접 읽는 ERP 중 하나입니다. PlaidCloud는 사용자 네트워크에 설치된 [PlaidLink](/ko/reference/cli/plaidlink/) 에이전트를 통해 RFC로 시스템에 접속합니다. 이 페이지는 이를 설정하는 SAP 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호는 이메일로 보내지 마십시오.

## 액세스 요청 보내기

**홈**의 **Data Foundation** 아래에 있는 프로젝트의 **시스템** 페이지에서 **시스템 추가** 아래의 **시스템**에서 사용 중인 시스템을 선택하고 **아직 액세스 권한이 없으십니까?** 버튼을 클릭합니다. 시스템이 액세스 대기 상태가 되고, 프로젝트의 시스템을 모두 다루는 요청 하나가 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "PlaidCloud 액세스"라는 제목으로 메일 프로그램에서 열립니다.

## SAP 관리자가 설정하는 항목

<Steps>

1. 보고 대상 클라이언트에 **PlaidCloud ABAP 패키지를 설치하고**(`Z_PLAIDCL_B5_READ_TABLE`의 함수 그룹), RFC로 시스템에 접속할 수 있는 PlaidLink 에이전트를 설치합니다.

2. 다음 권한을 가진 역할로 **통신 사용자를 만듭니다**(예: `PLAIDCLOUD_RFC`).

   - `S_RFC`: `Z_PLAIDCL_B5_READ_TABLE`의 함수 그룹을 실행합니다.
   - 아래 테이블에 대한 `S_TABU_NAM`(조회, `ACTVT` 03).

   | 테이블 | 내용 |
   |---|---|
   | `T001` | 회사 코드 |
   | `T009`, `T009B`, `T001B` | 회계 연도 변형 및 전기 기간 |
   | `SKA1`, `SKAT` | 총계정원장 계정 |
   | `FAGL_011PC`, `FAGL_011ZC` | 재무제표 버전 |
   | `CSKS`, `CSKT` | 원가 센터 |
   | `SETHEADER`, `SETNODE` | 원가 센터 및 이익 센터 그룹 |
   | `CEPC`, `CEPCT` | 이익 센터(선택 사항) |
   | `KNA1`, `KNVV`, `KNVH` | 고객 및 고객 계층 |
   | `MARA`, `MAKT`, `T006A` | 자재 및 단위 |
   | `TCURR`, `TCURF`, `TCURX` | 환율 및 통화 소수 자릿수 |
   | `ACDOCA` | 선행 원장의 분개 전표 및 잔액 이월 |
   | `VBRK`, `VBRP`, `PRCD_ELEMENTS` | 청구 문서 및 조건 |
   | `ACDOCP` | 계획 데이터 |
   | `COSR` | 통계 핵심 수치 |
   | `T001K`, `MBEW`, `MBEWH` | 평가 영역, 자재 재고 가치 및 표준 가격 |
   | `T001W`, `TKA02` | 사이트로 읽는 플랜트와 각 회사 코드의 관리 회계 영역(선택 사항) |
   | `T016T`, `TKUKT`, `KNVP`, `TSPAT`, `T052U` | 산업 및 고객 분류 이름, 각 고객의 영업 담당 직원, 제품군 및 지급 조건 이름(선택 사항) |
   | `LFA1`, `LFB1` | 공급업체(선택 사항) |
   | `RBKP`, `RSEG`, `BKPF` | 공급업체 청구서와 해당 회계 문서(선택 사항) |
   | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` | 구매 주문과 해당 입고 및 청구서(선택 사항) |
   | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095` | 고정 자산 대장(선택 사항) |
   | 운영 관심 영역의 라인 항목 테이블(`CE1` 뒤에 해당 이름) | 평가별 CO-PA(선택 사항) |

   미결 항목과 결제는 `ACDOCA`의 고객 및 공급업체 라인에서 읽고, 자산 변동은 같은 원장의 자산 계정 전기에서 읽습니다.

3. **회계 관련 질문에 답합니다**(아래 참조).

</Steps>

### 관리자가 답하는 질문

| 관리자가 알려 주는 내용 | PlaidCloud의 **시스템 설정**에 입력하는 위치 |
|---|---|
| 평균 환율을 보관하는 환율 유형. PlaidCloud는 매월 해당 유형의 환율을 평균합니다. 대개 `M`입니다. | **Average rate type** |
| 월말 환율인 마감 환율을 보관하는 환율 유형. 지정하지 않으면 마감 환율은 `M` 환율입니다. | **Closing rate type** |
| 관리 손익계산서와 대차대조표를 보고하는 재무제표 버전 | **Financial statement version** |
| 해당 노드 중 수익, 매출원가, 영업 비용, 영업 외, 자산, 부채, 자본, 회사 간 거래에 해당하는 노드 | **Account type of each statement node**: 노드마다 한 줄씩 `node = type` 형식으로 입력하며, 유형은 상자에 나열된 유형(예: `Revenue` 또는 `Asset`)을 사용합니다. **Intercompany statement nodes**에는 회사 간 거래 노드를 지정합니다. 두 설정 모두 **Financial statement version**이 설정된 경우에만 적용됩니다. |
| 보고하는 각 회계 연도에 대해 잔액 이월(`FAGLGVTR`)이 실행되었다는 사실 | 입력할 것 없음. 기초 잔액은 여기에서 읽습니다. |
| 각 자산 장부(회계 또는 세무)의 감가상각 영역. 첫 번째가 자산 대장의 영역입니다. PlaidCloud는 영역 `01`을 회계 장부로 가정합니다. | **Depreciation area of each book** |
| 각 자산 거래 유형의 변동 유형(첫 자리 기준). PlaidCloud는 `1` 취득, `2` 처분, `3` 이전, `6` 감가상각, `9` 기초로 가정합니다. | **Movement type of each transaction type** |
| 평가별 CO-PA가 필요한 경우 운영 관심 영역의 라인 항목 테이블. 지정하지 않으면 CO-PA를 읽지 않습니다. | **Operating concern line item table** |
| 각 계정의 CO-PA 값 필드와 그중 비용에 해당하는 필드 | **Value field of each CO-PA account**, **CO-PA cost value fields** |

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| 시스템 ID와 애플리케이션 서버(또는 메시지 서버와 로그온 그룹) | **호스트** 및 **시스템 번호**, 또는 **부하 분산 다중 시스템 연결 사용**을 선택한 경우 **MS 호스트**, **MS 서버**, **시스템 ID**, **그룹** |
| 클라이언트 | **클라이언트** |
| 통신 사용자의 이름 | **사용자** |
| 암호 관리자를 통해 전달하는 통신 사용자의 암호 | **암호**, 팀이 직접 입력함 |
| 시스템에 접속하는 PlaidLink 에이전트의 이름 | **PlaidLink agent** 시스템 설정 |
| PlaidCloud가 읽을 수 있는 회사 코드 | **옵션**의 **회사**에 입력하며, SAP는 목록을 제공할 수 없습니다. 회사 코드를 쉼표로 구분하여 입력하거나, 비워 두면 모든 회사 코드를 로드합니다 |

<Aside type="caution">
암호는 이메일로 보내지 마십시오. **암호**는 비밀 값으로, 연결에 저장되며 다시 표시되지 않습니다.
</Aside>

## 액세스 확인

SAP는 PlaidLink 에이전트를 통해 읽으므로 **연결 테스트**는 SAP를 읽지 않습니다. 첫 로드에서 읽으며, 사용자가 읽을 수 없는 테이블은 그때 표시됩니다. 각 데이터 세트가 읽는 테이블은 다음과 같습니다.

| 데이터 세트 | 읽는 테이블 |
|---|---|
| 엔터티 | `T001` |
| 회계 달력 | `T001`, `T009`, `T009B`, `T001B` |
| 환율 | `TCURR`, `TCURF` |
| 계정과목표 | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC` |
| 부서 | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| 이익 센터 | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| 고객 | `KNA1`, `KNVV`, `KNVH` |
| 제품 | `MARA`, `MAKT`, `T006A` |
| 총계정원장 | `ACDOCA` |
| 시산표 | `ACDOCA` 잔액 이월 |
| 판매 라인 | `VBRK`, `VBRP`, `PRCD_ELEMENTS` |
| 예산 | `ACDOCP` |
| 배부 동인 | `COSR` |
| 재고 잔액 | `T001K`, `MBEW`, `MBEWH` |
| 사이트 | `T001W`, `T001K` |
| 공급업체 | `LFA1`, `LFB1` |
| 공급업체 청구서 라인 | `RBKP`, `RSEG`, `BKPF` |
| 구매 주문 | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` |
| 미결 항목, 결제 | `ACDOCA` 고객 및 공급업체 라인 |
| 고정 자산 | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095` |
| 자산 변동 | `ACDOCA`와 `ANLA`, `ANKA`, `T095` |
| 표준 원가 | `T001K`, `MBEW`, `MBEWH` |
| 평가별 CO-PA | **Operating concern line item table**에 지정한 테이블 |

로드에서 사용자가 읽을 수 없는 테이블이 표시되면 관리자에게 역할에 해당 테이블을 추가해 달라고 요청한 후 다시 로드하십시오. 이익 센터, 사이트, 공급업체, 공급업체 청구서 라인, 구매 주문, 미결 항목, 결제, 고정 자산, 자산 변동, 표준 원가, CO-PA, 판매 라인, 예산, 배부 동인, 재고 잔액은 선택 사항이므로, 이 중 하나를 보유하지 않은 시스템도 나머지는 모두 로드됩니다. SAP가 거부한 특정 월의 미결 항목 또는 결제는 이미 있던 행을 유지합니다.

S/4HANA에는 Data Foundation이 읽는 별도의 월말 잔액이 없으므로, 원장은 자체 시산표와 비교됩니다. 원장에 전기하지 않는 감가상각 영역은 읽지 않으며, 준비 상태 검사에서 해당 영역을 알려 줍니다.
