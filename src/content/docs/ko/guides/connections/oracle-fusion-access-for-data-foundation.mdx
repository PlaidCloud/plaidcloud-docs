[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, Oracle Fusion Cloud ERP는 Data Foundation이 직접 읽는 ERP 중 하나입니다. Oracle Fusion 연결에는 OAuth 2.0 클라이언트 자격 증명, 읽기 전용 통합 사용자, 소수의 BI Publisher 보고서가 사용됩니다. 이 페이지는 이를 설정하는 Oracle Fusion 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호나 클라이언트 시크릿은 이메일로 보내지 마십시오.

## 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **Oracle Fusion 연결** 아래의 **새 연결 만들기**를 선택합니다. 양식에 전체 요청 내용이 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "Read-only Oracle Fusion Cloud ERP access for PlaidCloud (OAuth 2.0 client credentials)"라는 제목으로 메일 프로그램에서 열립니다.

## Oracle Fusion 관리자가 설정하는 항목

<Steps>

1. **통합 사용자를 만들고** 보고 대상인 모든 원장에 대해 다음 항목을 볼 수 있는 직무 역할을 부여합니다.

   - 총계정원장: 원장, 회계 달력과 기간 상태, 분개 배치, 분개 전표, 계정 잔액(예: 해당 원장에 대한 데이터 액세스가 있는 "General Accountant")
   - 통화 환산 환율(일일 환율)
   - 키 플렉스필드 세그먼트 레이블, 값 집합과 해당 계정 계층(트리)
   - 매출채권: 송장과 그 배부 내역, 고객 계정
   - 재고 품목
   - 3단계의 BI Publisher 보고서와 ERP Integration Service(ESS 작업)에 대한 실행 권한

2. 아이덴티티 도메인(IAM)에 클라이언트 자격 증명 권한 부여 방식과 Fusion Applications REST API 범위를 사용하는 **기밀 애플리케이션을 등록합니다.** 클라이언트 ID와 시크릿을 복사합니다.

3. `/Custom/PlaidCloud/DataFoundation` 아래에 **BI Publisher 보고서 9개를 배포합니다.** 각 보고서는 보고서 이름을 작업 정의로 하여 ESS 작업으로 실행되며, 요청에 나열된 열이 있는 CSV를 반환합니다.

   | 보고서 | 반환 내용 |
   |---|---|
   | `PlaidCloudKeyFlexLabels` | 각 총계정원장 계정과목표의 세그먼트마다 한 행: 위치, 레이블, 값 집합 |
   | `PlaidCloudSegmentValues` | 해당 값 집합의 모든 값과 자연 계정 유형, 값 계층 |
   | `PlaidCloudCalendar` | 모든 원장의 회계 기간과 원장의 기간 평균 및 기간 말 환율 유형 |
   | `PlaidCloudCodeCombinations` | 코드 조합과 해당 세그먼트 |
   | `PlaidCloudBalances` | 모든 원장의 기초 잔액 |
   | `PlaidCloudJournalLines` | 원장, 기간, 밸런싱 세그먼트 값 단위로 읽는 분개 라인 |
   | `PlaidCloudCustomers` | 고객 계정과 당사자 이름 |
   | `PlaidCloudItems` | 마스터 재고 조직의 품목 |
   | `PlaidCloudSalesLines` | 매출채권 송장 라인마다 한 행 |

   각 보고서의 정확한 열은 **Foundation** 탭의 요청 텍스트에 있습니다. 보고서 이름은 표시된 그대로 지정하십시오.

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| `https://`를 제외한 Fusion Applications URL의 호스트 | **Pod 호스트** |
| 아이덴티티 도메인의 토큰 URL | **Token URL** |
| REST API 애플리케이션의 범위 | **범위** |
| 2단계의 클라이언트 ID | **클라이언트 ID** |
| 2단계의 클라이언트 시크릿 | **클라이언트 시크릿** |
| PlaidCloud가 읽을 수 있는 밸런싱 세그먼트 값 | **Balancing segment values** 아래에 입력하며, Fusion은 목록을 가져올 수 없습니다. **이름**에 값 하나를 입력하거나, 비워 두면 모든 값을 로드합니다 |

요청서의 마지막 목록에서 이 값들을 함께 요청합니다. 클라이언트 시크릿은 이메일이 아닌 암호 관리자로 공유하십시오. PlaidCloud 사용자의 팀이 직접 PlaidCloud에 붙여 넣습니다.

## 액세스 확인

PlaidCloud로 돌아가 값을 입력하고 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | 읽는 위치 |
|---|---|
| 엔터티, 회계 달력, 계정과목표, 부서 | 원장, 그리고 키 플렉스필드 레이블, 세그먼트 값, 달력 보고서 |
| 환율 | 일일 환산 환율 |
| 총계정원장 | 분개 배치와 분개 라인 보고서 |
| 시산표 | 잔액 및 코드 조합 보고서 |
| 고객, 제품, 판매 라인 | 고객, 품목, 판매 라인 보고서(선택 사항) |

데이터 세트가 누락되면 테스트에서 추가해야 할 권한을 알려 줍니다. 관리자에게 직무 역할에 추가해 달라고 요청한 후 다시 테스트하십시오. 고객, 제품, 판매 라인은 선택 사항이므로, 이를 보유하지 않은 Fusion 포드도 나머지는 모두 로드됩니다.
