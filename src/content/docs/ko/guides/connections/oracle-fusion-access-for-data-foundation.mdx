[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 ERP 시스템과 인스턴스의 데이터를 하나의 Common Finance Model로 가져오며, Oracle Fusion Cloud ERP는 Data Foundation이 직접 읽는 ERP 중 하나입니다. Oracle Fusion 연결에는 OAuth 2.0 클라이언트 자격 증명, 읽기 전용 통합 사용자, 소수의 BI Publisher 보고서가 사용됩니다. 이 페이지는 이를 설정하는 Oracle Fusion 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호나 클라이언트 시크릿은 이메일로 보내지 마십시오.

## 액세스 요청 보내기

**홈**의 **Data Foundation** 아래에 있는 프로젝트의 **시스템** 페이지에서 **시스템 추가** 아래의 **시스템**에서 사용 중인 시스템을 선택하고 **아직 액세스 권한이 없으십니까?** 버튼을 클릭합니다. 시스템이 액세스 대기 상태가 되고, 프로젝트의 시스템을 모두 다루는 요청 하나가 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "PlaidCloud 액세스"라는 제목으로 메일 프로그램에서 열립니다.

## Oracle Fusion 관리자가 설정하는 항목

<Steps>

1. **통합 사용자를 만들고** 보고 대상인 모든 원장에 대해 보기만 가능한 사용자 지정 직무 역할을 부여합니다. General Accountant처럼 입력, 전기 또는 승인이 가능한 역할은 사용하지 마십시오. 역할에는 다음 항목이 필요합니다.

   - 총계정원장: 원장, 회계 달력과 기간 상태, 분개 배치, 분개 전표, 계정 잔액(해당 원장에 대한 데이터 액세스가 있는 조회 권한)
   - 통화 환산 환율(일일 환율)
   - 키 플렉스필드 세그먼트 레이블, 값 집합과 해당 계정 계층(트리)
   - 매출채권 및 매입채무: 송장, 입금, 결제와 그 배부 내역, 고객 계정과 공급업체
   - Cash Management 은행 계정
   - 재고 품목과 현재 재고 수량
   - 배포하는 각 선택 사항 보고서에 해당하는 보기 전용 액세스: 구매(View Purchase Order, `PO_VIEW_PURCHASE_ORDER_PRIV`, 입고 조회, 조달 사업부에 대한 데이터 액세스 포함), 고정 자산(자산 조회, 회사 및 세무 자산 장부에 대한 데이터 액세스 포함), 원가 관리(Review Item Costs, 원가 조직에 대한 데이터 액세스 포함), 예산(총계정원장 예산 잔액 조회)
   - 3단계의 BI Publisher 보고서와 ERP Integration Service(ESS 작업)에 대한 실행 권한

2. 아이덴티티 도메인(IAM)에 클라이언트 자격 증명 권한 부여 방식과 Fusion Applications REST API 범위를 사용하는 **기밀 애플리케이션을 등록합니다.** 클라이언트 ID와 시크릿을 복사합니다.

3. `/Custom/PlaidCloud/DataFoundation` 아래에 **BI Publisher 보고서를 배포합니다.** 각 보고서는 보고서 이름을 작업 정의로 하여 ESS 작업으로 실행되며, 요청에 나열된 열이 있는 CSV를 반환합니다. 처음 여섯 개는 필수이며 원장은 이 보고서로 구성됩니다. 나머지는 선택 사항입니다. 선택 사항 보고서가 없으면 해당 보고서가 담는 데이터만 비어 있고 다른 항목에는 영향이 없습니다.

   | 보고서 | 반환 내용 |
   |---|---|
   | `PlaidCloudKeyFlexLabels` | 각 총계정원장 계정과목표의 세그먼트마다 한 행: 위치, 레이블, 값 집합 |
   | `PlaidCloudSegmentValues` | 해당 값 집합의 모든 값과 자연 계정 유형, 값 계층 |
   | `PlaidCloudCalendar` | 모든 원장의 회계 기간과 원장의 기간 평균 및 기간 말 환율 유형 |
   | `PlaidCloudCodeCombinations` | 코드 조합과 해당 세그먼트 |
   | `PlaidCloudBalances` | 조정 기간을 포함한 모든 기간의 모든 원장 잔액: 기초 잔액과 원장이 비교되는 월말 잔액 |
   | `PlaidCloudJournalLines` | 원장, 기간, 밸런싱 세그먼트 값 단위로 읽는 분개 라인과 각 분개의 입력자 및 승인자, 일시, 역분개 대상 분개 |
   | `PlaidCloudCustomers` | 고객 계정과 당사자 이름(선택 사항) |
   | `PlaidCloudItems` | 마스터 재고 조직의 품목(선택 사항) |
   | `PlaidCloudSalesLines` | 매출채권 송장 라인마다 한 행(선택 사항) |
   | `PlaidCloudSites` | `GL_SITE` 세그먼트의 값(선택 사항) |
   | `PlaidCloudSuppliers` | 공급업체(선택 사항) |
   | `PlaidCloudArDocuments`, `PlaidCloudReceipts` | 미결 항목과 결제를 위한 매출채권 거래와 해당 거래에 적용된 내역(선택 사항) |
   | `PlaidCloudApInvoices`, `PlaidCloudApPayments` | 미결 항목과 결제를 위한 매입채무 송장과 해당 송장에 적용된 내역(선택 사항) |
   | `PlaidCloudApInvoiceLines` | 매입채무 송장 라인마다 한 행(선택 사항) |
   | `PlaidCloudBankBalances` | 각 은행 계정 자체의 매월 말 잔액(선택 사항) |
   | `PlaidCloudInventory` | 매월 말 모든 품목 및 하위 재고의 현재 재고 수량과 금액(선택 사항) |
   | `PlaidCloudBudget` | 월별 승인 예산(선택 사항) |
   | `PlaidCloudPurchaseOrders`, `PlaidCloudPurchaseOrderEvents` | 구매 주문 라인과 해당 입고 및 대응 송장(선택 사항) |
   | `PlaidCloudAssets`, `PlaidCloudAssetMovements` | 회사 장부의 자산 대장과 회사 및 세무 장부에서의 각 자산 변동(선택 사항) |
   | `PlaidCloudStandardCosts` | 각 품목의 월별 표준 원가(선택 사항) |

   각 보고서의 정확한 열은 액세스 요청 텍스트에 있습니다. 보고서 이름은 표시된 그대로 지정하십시오. 이전 버전용으로 `PlaidCloudBalances` 또는 `PlaidCloudApInvoices`를 배포했다면 요청에 설명된 대로 확장하십시오. 이제 `PlaidCloudBalances`는 모든 기간을 해당 기간의 활동과 함께 반환해야 합니다.

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| `https://`를 제외한 Fusion Applications URL의 호스트 | **Pod 호스트** |
| 아이덴티티 도메인의 토큰 URL | **ID 도메인 토큰 URL** |
| REST API 애플리케이션의 범위 | **범위** |
| 2단계의 클라이언트 ID | **클라이언트 ID** |
| 2단계의 클라이언트 시크릿 | **클라이언트 시크릿** |
| PlaidCloud가 읽을 수 있는 밸런싱 세그먼트 값 | **옵션**의 **회사**에 입력하며, Fusion은 목록을 가져올 수 없습니다. 값을 쉼표로 구분하여 입력하거나, 비워 두면 모든 값을 로드합니다 |

요청서의 마지막 목록에서 이 값들을 함께 요청합니다. 클라이언트 시크릿은 이메일이 아닌 암호 관리자로 공유하십시오. PlaidCloud 사용자의 팀이 직접 PlaidCloud에 붙여 넣습니다.

## 액세스 확인

PlaidCloud로 돌아가 시스템이 추가되면 **시스템** 페이지에서 해당 시스템 행의 **연결 테스트**를 클릭합니다. 테스트는 필수 데이터 세트마다 객체 하나를 읽고 각 데이터 세트를 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시합니다. 보고서 자체는 첫 로드 때 실행되며, 선택 사항 보고서는 테스트에 포함되지 않습니다. 선택 사항 보고서가 없거나 사용자가 실행할 수 없으면 다음 로드 때 표시됩니다.

| 데이터 세트 | 테스트가 읽는 항목 |
|---|---|
| 엔터티, 회계 달력, 계정과목표, 부서, 시산표 | 원장 |
| 환율 | 일일 환산 환율 |
| 총계정원장 | 분개 배치 |

데이터 세트가 누락되면 테스트에서 추가해야 할 권한을 알려 줍니다. 관리자에게 직무 역할에 추가해 달라고 요청한 후 다시 테스트하십시오. 선택 사항 보고서가 없는 Fusion 포드도 나머지는 모두 로드됩니다. 고객, 제품, 사이트, 공급업체는 비어 있는 상태로 로드되며, 그 밖의 데이터 세트는 보고서를 다시 읽을 수 있을 때까지 이전 로드에서 가져온 내용을 유지합니다.

Oracle Fusion에는 Data Foundation이 읽는 이익 센터 목록이 없습니다. 분개 라인의 이익 센터는 해당 계정과목표의 관리 세그먼트입니다.
