Sage 100은 사용자의 서버에 설치되며 웹 API가 없으므로, PlaidCloud는 네트워크 안의 Windows 컴퓨터에서 실행되는 [PlaidLink](/ko/reference/cli/plaidlink/) 에이전트를 통해 이 시스템에 접근합니다. [Data Foundation](/ko/guides/projects/data-foundation/)은 연결되는 다른 ERP 시스템과 마찬가지로 이 에이전트를 통해 Sage 100 회사 하나의 계정과목표, 회계 달력, 분개, 기간 잔액을 읽습니다. 워크플로는 총계정원장 분개 전표와 외상매입금 수기 수표를 회사에 다시 전기할 수도 있습니다.

이 페이지에서는 Sage 100 관리자가 설정하는 항목, 회사를 연결하는 방법, Data Foundation이 읽는 항목, 전기가 동작하는 방식을 설명합니다.

## Sage 100 관리자가 설정하는 항목

아래 항목은 모두 PlaidLink 에이전트를 실행하는 컴퓨터 한 대에서 설정합니다.

<Steps>

1. 컴퓨터에 **PlaidLink를 설치하고 등록한** 다음, PlaidLink 1.2.36 이상을 사용하고 에이전트를 시스템 계정(LocalSystem, LocalService 또는 NetworkService)이 아닌 전용 Windows 계정으로 실행합니다. 전용 계정을 사용하면 PlaidLink가 멈춘 Sage 100 세션을 정리할 수 있지만, 시스템 계정에서는 정리할 수 없습니다.

2. **Sage의 64비트 ODBC 드라이버를 설치하고 64비트 시스템 DSN을 만듭니다.** 에이전트는 64비트 프로그램이므로 32비트 드라이버나 데이터 원본을 사용할 수 없습니다. 데이터 원본 이름은 보통 `SOTAMAS90`이며 Sage 100 Standard 및 Advanced에 포함되어 있습니다. Sage 100 Premium은 SQL Server에서 읽으므로 대신 Microsoft ODBC Driver for SQL Server가 필요합니다. Sage 100 라이선스가 ODBC 드라이버와 워크스테이션을 포함하는지 확인하십시오.

3. **PlaidCloud용 Sage 사용자를 만들고** Role Maintenance에서 다음 작업을 부여합니다.

   | 용도 | 작업 |
   |---|---|
   | 읽기 | General Ledger: Chart of Accounts, Account Inquiry, Journal Entry inquiry, Fiscal Year and Period inquiry. Library Master: Company Maintenance inquiry. |
   | 전기, 항목을 보기만 하는 것이 아니라 추가할 수 있는 권한 포함 | General Ledger: Journal Entry. Accounts Payable: Manual Check Entry. |

   Premium의 경우 사용자에게 SQL Server에 있는 Sage 100 데이터베이스에 대한 읽기 권한도 부여합니다.

4. **같은 컴퓨터에 Sage 100을 워크스테이션으로 설치합니다.** 데이터 원본이 회사 파일을 열 때 필요하며, 전기는 워크스테이션 설치에서 제공하는 Sage의 Business Object Interface(BOI)를 통해 이루어집니다. 전기가 실행되는 동안에는 Sage 100 워크스테이션 라이선스 하나를 사용합니다. Sage 100이 설치된 폴더와 회사가 장부를 관리하는 통화를 기록해 두십시오.

5. 먼저 연결할 **테스트 회사**나 회사의 사본을 PlaidCloud에 제공합니다.

6. 첫 설치가 차단되지 않도록 **PlaidLink 에이전트를 바이러스 백신과 Windows SmartScreen에서 허용합니다.**

</Steps>

Standard 또는 Advanced 데이터 원본은 회사 하나에 로그인합니다. Premium 연결은 데이터베이스 하나의 회사 하나를 지정합니다. 각 회사를 별도로 연결하십시오.

<Aside type="caution">
Sage 비밀번호를 이메일로 보내지 마십시오. **Sage password**는 비밀 값이며 연결에 저장되고 다시 표시되지 않습니다.
</Aside>

### 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **시스템 연결** 아래의 **Sage 100 — on-premises**를 선택한 다음 **새 연결 만들기**를 선택합니다. 양식에는 전체 요청 내용, **PlaidLink 설정 방법** 링크, 요청을 직접 작성하는 메시지에 붙여 넣는 **요청 복사**, 제목이 "Sage 100 access for PlaidCloud."인 요청을 메일 프로그램에서 여는 **이메일 요청**이 표시됩니다.

## 회사 연결

**Foundation** 탭에서 **소스**를 열고 **시스템 연결**에서(프로젝트에 소스가 이미 있으면 **다른 시스템 연결**에서) **Sage 100 — on-premises**를 선택한 다음 **새 연결 만들기**를 선택합니다. **연결 이름**을 입력하고 **환경**을 선택한 다음 다음 설정을 채웁니다.

| 설정 | 입력할 내용 |
|---|---|
| **Sage 100 edition** | Premium, Standard 또는 Advanced. |
| **Company code** | Sage 100 회사의 코드이며 영문자와 숫자 1~10자입니다. |
| **Company currency** | `USD`와 같이 회사가 장부를 관리하는 통화의 세 글자 코드입니다. 필수 항목이며 PlaidCloud는 통화를 임의로 가정하지 않습니다. |
| **Sage user** | PlaidCloud용으로 만든 Sage 사용자. |
| **Sage password** | 해당 사용자의 비밀번호. |
| **Sage 100 install folder on the agent machine** | Sage 100이 설치된 폴더입니다. 전기에는 필요하지만 읽기에는 필요하지 않습니다. |
| **Accounts Payable division** | 수기 수표를 전기할 사업부입니다. 기본값은 `00`입니다. |
| **SQL Server (Premium)** 및 **SQL Server database (Premium)** | Premium의 경우: Sage 100이 설치된 SQL Server와 데이터베이스. |
| **ODBC data source (Standard and Advanced)** | Standard 및 Advanced의 경우: 에이전트 컴퓨터의 시스템 DSN입니다. 기본값은 `SOTAMAS90`입니다. |

**시스템 설정** 아래에서 **PlaidLink agent**에서 PlaidLink 에이전트를 선택하고, 그곳의 **Company currency**를 같은 코드로 설정합니다. 행은 해당 통화로 로드되며, 변경하기 전에는 `USD`입니다. **Document account for the agent's reads**는 에이전트가 읽는 동안 기록하는 파일을 보관하며, 기본값은 프로젝트의 문서 계정입니다. **Account mask**는 Sage 100의 계정 형식이며, `#`은 문자 하나이고 그 외는 구분 기호입니다. `####-###`은 네 글자 주 계정, 구분 기호, 세 글자 부서입니다. 변경하기 전에는 `####`입니다.

**연결 테스트**를 클릭합니다. Sage 100의 경우 이 검사는 연결에 필요한 값이 모두 있는지만 확인하며 Sage 100에 로그인하지는 않습니다. 에이전트는 **로드**를 클릭할 때 테이블을 읽습니다. 그런 다음 **이력 개월 수**를 설정하고 [ERP 연결](/ko/guides/projects/data-foundation/#erp-연결)에 설명된 대로 시스템을 추가합니다. 연결이 제공하는 엔터티는 회사 하나뿐입니다.

## Data Foundation이 읽는 항목

| 데이터 세트 | Sage 100에서 읽는 항목 |
|---|---|
| 엔터티 | 회사. |
| 회계 달력 | 회계 연도와 해당 기간으로, 연간 최대 13개입니다. 종료일이 바로 앞 기간과 같은 기간은 조정 기간입니다. |
| 계정과목표 | 계정 마스크에 따라 세그먼트로 나뉜 총계정원장 계정. |
| 부서 | 마스크에 부서 세그먼트가 있을 때 계정의 부서 세그먼트. |
| 총계정원장 | 회계 연도와 기간별 총계정원장 전기 상세. |
| 시산표 | 기간 전기 이력으로, 기간별 각 계정의 차변과 대변이며 처음 읽는 기간에는 기초 잔액이 포함됩니다. |

Sage 100은 제품, 고객, 판매 라인, 환율 및 다른 데이터 세트를 제공하지 않으므로 이러한 항목은 파일로 추가하십시오. 장부를 하나의 통화로 관리하므로 읽을 환율이 없습니다. [Data Foundation 적용 범위 매트릭스](/ko/reference/data-foundation-coverage-matrix/)를 참조하십시오.

에이전트가 읽을 수 없는 테이블이나 행이 없는 테이블은 오류가 아니라 경고입니다. 이전 로드에서 해당 테이블로부터 반영된 내용은 그대로 유지되고, 로드할 수 있는 데이터 세트는 로드되며, **준비 상태**에 해당 테이블이 표시됩니다.

## Sage 100에 전기

**문서 전기** 단계는 Sage 100 연결에 전기하며, 다른 ERP와 같은 문서 테이블과 같은 [전기 모드](/ko/guides/workflows/run-a-workflow/#전기-모드-선택)를 사용합니다. **시뮬레이션**은 Sage 100에 연결하지 않고 각 문서를 작성하고 검사합니다. 시스템은 실행이 Live이고 프로젝트에 해당 시스템의 오늘자 쓰기 승인이 있을 때만 Live로 전기합니다. 전기를 추적하려면 [전기 등록부 검토](/ko/guides/connections/posting-register/)를, 그 기반이 되는 원장은 [ERP 전기 이력 검토](/ko/guides/connections/erp-post-history/)를 참조하십시오.

Sage 100은 두 종류의 문서를 받습니다.

| 문서 | 전기되는 항목 | 필요한 항목 |
|---|---|---|
| `journal` | 총계정원장 분개 전표. | 전기일과 모든 라인의 계정이 필요합니다. 라인은 센트 단위까지 균형이 맞아야 하며, 분개의 설명이 되는 참조는 최대 30자입니다. |
| `payment` | Sage 100 밖에서 이루어진 지급을 공급업체의 미결 송장에 대해 기록하는 외상매입금 수기 수표. | 전기일, 라인 전체에 걸쳐 공급업체 하나, 각 라인의 `invoice_no`와 양수 금액, 은행 코드, 수표 번호가 되는 최대 7자의 참조가 필요합니다. 은행 코드는 `bank_code` 열이거나 Sage 100 시스템에 저장된 필수 값입니다. |

아무것도 전송되기 전에 다음 경우 문서는 사유와 함께 중지됩니다.

- 라인이 연결의 **Company currency**와 다른 통화로 되어 있는 경우
- `company` 열이 연결의 **Company code**와 다른 회사를 지정하는 경우
- 분개의 날짜가 Sage 100에서 마감된 기간이거나, 지급이 해당 금액으로 미결 상태가 아닌 송장에 대한 것인 경우(에이전트가 확인할 수 있을 때이며, 이 두 검사는 Live 전기에서만 실행됩니다)

각 문서는 Sage 100의 배치로 입력되며, PlaidCloud는 전기됨으로 간주하기 전에 이를 다시 읽습니다. 표시되는 상태는 다음과 같습니다.

- **전기됨**: 다시 읽기에서 Sage 100의 전기된 테이블에서 문서를 찾은 경우에만 표시됩니다.
- **대기 중**: 문서가 배치에 있으며 Sage 100의 Update를 기다리는 경우로, "Entered in Sage, batch *n*" 메시지가 함께 표시됩니다. 에이전트가 온라인인 동안 PlaidCloud는 이런 각 문서에 대해 약 매시간 Sage 100에 다시 문의하고, 문서가 나타나면 전기됨으로 기록합니다. 7일이 지나도 입력된 상태인 문서는 미확인이 됩니다.
- **미확인**: Sage 100이 문서를 보유하고 있는지 PlaidCloud가 확인할 수 없는 경우입니다. 추측만으로 다시 전송되지 않으므로, 해결하기 전에 Sage 100을 확인하십시오.
- **전기되지 않음**: Sage 100이 문서를 거부했거나, 에이전트가 오프라인인 경우 등으로 에이전트가 문서를 받지 못한 경우입니다. 거부된 문서는 수정한 후 다시 보낼 수 있습니다.

전기된 문서는 두 번 전기되지 않습니다. 같은 문서를 다시 실행하면 참조로 인식됩니다.

<Aside type="note">
PlaidLink는 에이전트당 한 번에 하나의 Sage 100 세션만 열므로, 한 에이전트의 전기는 차례로 실행됩니다. 전기는 세션을 최대 1분 동안 기다린 후 사용할 수 없음으로 거부됩니다. Sage 100에서는 전기 되돌리기를 사용할 수 없습니다.
</Aside>
