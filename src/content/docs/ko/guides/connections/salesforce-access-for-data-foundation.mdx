[Data Foundation](/ko/guides/projects/data-foundation/)은 연결한 모든 시스템의 데이터를 인스턴스 수에 관계없이 하나의 Common Finance Model로 가져옵니다. Salesforce는 Data Foundation이 직접 읽는 시스템 중 하나입니다. Salesforce는 원장이 아니라 CRM 소스이며, 고객, 제품, 영업 파이프라인을 제공할 뿐 총계정원장 항목은 제공하지 않습니다. 이 페이지는 액세스를 설정하는 Salesforce 관리자와 관리자에게 요청하는 PlaidCloud 사용자를 위한 것입니다.

PlaidCloud는 데이터를 읽기만 합니다. 암호나 보안 토큰은 이메일로 보내지 마십시오.

## 액세스 요청 보내기

프로젝트의 **Foundation** 탭에서 **새 연결 만들기**를 선택하고 **Salesforce**를 고릅니다. 양식에 전체 요청 내용이 표시됩니다. **요청 복사**를 클릭하면 직접 작성하는 메시지에 붙여 넣을 수 있고, **이메일 요청**을 클릭하면 "Read-only Salesforce access for PlaidCloud (OAuth 2.0 client credentials)"라는 제목으로 메일 프로그램에서 열립니다.

## Salesforce 관리자가 설정하는 항목

<Steps>

1. **Setup > Apps > External Client Apps > New**에서 **External Client App을 만듭니다.** 조직에 Connected App이 아직 있다면 그것을 만들어도 됩니다.

   - OAuth 설정을 활성화하고 **Enable Client Credentials Flow**만 선택합니다(인증 코드 흐름이나 암호 흐름은 사용하지 않음).
   - **OAuth scope:** Manage user data via APIs (`api`).
   - **Run As:** 전용 통합 사용자(2단계).

2. 통합 사용자에게 다음 항목이 포함된 **프로필 또는 권한 집합을 부여합니다.**

   - API Enabled
   - Account(Account Number 필드 포함), Product2, Opportunity, OpportunityLineItem, Organization(기본 통화용)에 대한 읽기 권한
   - View All Data, 또는 보고 대상인 모든 영업 기회를 볼 수 있게 해 주는 공유 설정

   Salesforce는 PlaidCloud가 읽을 수 있는 모든 행과 필드를 이 사용자가 볼 수 있는 범위로 제한합니다.

3. 앱에서 **Consumer Key(클라이언트 ID)와 Consumer Secret을 복사하고**, 조직의 My Domain URL(예: `https://yourcompany.my.salesforce.com`)도 복사합니다.

</Steps>

## 회신할 내용

| 관리자가 보내는 내용 | PlaidCloud에 입력하는 위치 |
|---|---|
| My Domain URL | **My Domain URL** |
| 클라이언트 ID(Consumer Key) | **클라이언트 ID** |
| 이메일이 아닌 보안 연결 양식을 통해 전달하는 클라이언트 시크릿(Consumer Secret) | **클라이언트 시크릿** |

**엔터티** 아래의 **이름**에 Salesforce 조직의 파이프라인이 속한 엔터티를 입력합니다. 조직에는 나열할 엔터티가 없기 때문입니다. 조직 하나가 엔터티 하나이므로, 조직이 두 개이면 연결도 두 개입니다.

## 액세스 확인

PlaidCloud로 돌아가 **연결 테스트**를 클릭합니다. 각 데이터 세트는 **읽기 가능**, **권한 누락**, **오류** 중 하나로 표시됩니다.

| 데이터 세트 | Salesforce에서 읽는 항목 |
|---|---|
| 고객 | Account |
| 제품 | Product2 |
| 파이프라인 | 계정 번호가 포함된 Opportunity와 OpportunityLineItem |

세 가지 모두 선택 사항입니다. 하나가 **권한 누락**으로 표시되면 관리자에게 통합 사용자에게 해당 객체에 대한 읽기 권한을 추가해 달라고 요청한 후 다시 테스트하십시오.

파이프라인 금액은 영업 기회의 통화로 표시됩니다. 통화를 하나만 사용하는 조직에는 해당 필드가 없으므로, PlaidCloud는 Organization의 조직 기본 통화를 사용하고 그렇지 않으면 엔터티의 통화를 사용합니다.
