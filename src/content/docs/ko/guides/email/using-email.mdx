## 설명

**도구 > 이메일**에서 이 영역을 엽니다. 페이지는 **보낸 이메일**과 **반송**의 두 패널로 나뉩니다. 상단의 스트림 선택기에서 확인할 Postmark 스트림을 고르며, 기본값은 워크스페이스에 구성된 첫 번째 트랜잭션 스트림입니다.


## 보낸 이메일

**보낸 이메일** 패널에는 PlaidCloud가 워크스페이스를 대신하여 보낸 메시지가 표시됩니다. 열에는 `Sent At`, `Recipient`, `Subject`, `Status`, `Stream`, `Tag`, `Opens`, `Clicks`가 포함됩니다.

**보낸 이메일을 필터링하는 방법:**

1. **도구 > 이메일 > 보낸 이메일**을 엽니다.
2. **수신자**에 입력하여 받는 사람 주소로 검색합니다(부분 문자열 일치).
3. **상태**를 선택하여 이메일 전달 상태(전달됨, 열람됨 등)로 범위를 좁힙니다.
4. **태그**를 선택하여 특정 메시지 태그로 범위를 좁힙니다.
5. `Apply`를 클릭합니다.

`Clear`를 클릭하면 필터가 지워집니다. 행을 클릭하면 Postmark에서 반환한 전체 메시지 메타데이터가 표시되는 **메시지 세부 정보** 창이 열립니다.


## 반송

**반송** 패널에는 Postmark에서 반환한 전달 실패 내역이 표시됩니다. 열에는 `Bounced At`, `Recipient`, `Type`, `Inactive`, `Description`, `Stream`이 포함됩니다.

**반송 내역을 필터링하는 방법:**

1. **도구 > 이메일 > 반송**을 엽니다.
2. **수신자**에 입력하여 받는 사람 주소로 검색합니다(부분 문자열 일치).
3. **유형**을 선택하여 반송 유형(HardBounce, SoftBounce, Transient 등)으로 범위를 좁힙니다.
4. **태그**를 선택하여 특정 메시지 태그로 범위를 좁힙니다.
5. **비활성만**을 선택하면 Postmark에서 비활성으로 표시한 수신자만 표시됩니다.
6. `Apply`를 클릭합니다.

`Clear`를 클릭하면 필터가 지워집니다. 행을 클릭하면 반송 세부 정보가 열립니다.


## 반송된 수신자 다시 활성화

Postmark가 수신자를 비활성으로 표시하면(일반적으로 하드 바운스 이후) 수신자를 다시 활성화할 때까지 해당 주소로 더 이상 메일이 전송되지 않습니다.

1. **비활성만**으로 필터링합니다.
2. 수신자 행을 선택합니다.
3. `Reactivate`를 클릭합니다.

다시 활성화하면 이후 PlaidCloud에서 생성하는 메일을 해당 주소로 다시 전송하려고 시도합니다.


## 페이지 이동

두 패널 모두 모든 메시지를 한 번에 불러오지 않고 기록을 페이지 단위로 넘겨 봅니다. `Prev`와 `Next`로 페이지를 이동하며, 두 버튼 사이의 레이블에 현재 위치(`1–25 of 837`)가 표시됩니다.

<Aside>이메일 영역은 조회와 수신자 다시 활성화 전용입니다. 메시지 회신, 서버 구성, 템플릿 관리는 계속 Postmark 대시보드에서 수행합니다.</Aside>
