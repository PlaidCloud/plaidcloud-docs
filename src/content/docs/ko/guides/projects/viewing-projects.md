## 설명


**Analyze**에서 프로젝트 기능은 액세스 제어와 권한 수정을 훨씬 쉽게 해 주는 구획화 수준을 제공합니다. 프로젝트는 워크스페이스 탭 내에서 데이터를 구분하는 기본 단위입니다.



프로젝트는 Analyze에 속하고 워크플로는 프로젝트에 속하므로, 프로젝트에는 워크플로가 포함됩니다. 워크플로는 간단히 말해 데이터 변환 파이프라인, 데이터 분석, ETL 프로세스까지 폭넓은 작업을 수행합니다. 워크플로에 대한 자세한 내용은 “워크플로” 섹션에서 확인할 수 있습니다.



## 프로젝트 액세스


**프로젝트에 액세스하려면 다음과 같이 합니다.**


1. Analyze를 엽니다.
2. 상단 메뉴 표시줄에서 “프로젝트”를 선택합니다.

그러면 프로젝트 계층 구조가 표시됩니다. 여기에는 액세스 권한이 있는 프로젝트의 계층 구조가 나타납니다. 워크스페이스에 다른 프로젝트가 더 있을 수 있지만, 소유자가 아니거나 해당 프로젝트에 지정되지 않았다면 표시되지 않습니다.


## 활동 패널

프로젝트 창 오른쪽의 **활동** 패널에는 프로젝트에서 무엇이 실행되었는지, 성공했는지, 누가 무엇을 변경했는지가 표시됩니다. 액세스 권한이 있는 모든 프로젝트의 활동이 날짜별 머리글 아래에 최신순으로 나열됩니다. 프로젝트 창이 활성 창이고 브라우저 탭이 표시되어 있는 동안에는 약 15초마다 새 활동을 확인합니다.

각 날짜의 머리글에는 **오늘**, **어제** 또는 날짜가 표시되며, "12회 실행 · 1개 실패 · 3개 변경 사항"과 같이 그날 행의 요약이 함께 표시됩니다. 스크롤 중인 날짜의 머리글은 목록 맨 위에 고정됩니다.

### 실행

워크플로 실행 하나는 행 하나로 표시됩니다. 아이콘은 실행 결과를 나타내며, 아이콘 위에 마우스를 올리면 성공, 실패, 경고, 중지됨 또는 시작됨 중 해당 상태의 이름이 표시됩니다. 실패하거나 경고가 있는 행에는 왼쪽 가장자리를 따라 색상 막대도 표시됩니다.

- **첫 번째 줄**에는 워크플로 이름과 시간이 표시됩니다. 오늘은 "지금", 몇 분 전 또는 몇 시간 전으로, 이전 날짜는 시계 시각으로 표시됩니다. 시간 위에 마우스를 올리면 전체 날짜가 표시됩니다.
- **두 번째 줄**에는 누가 어느 프로젝트에서 실행했는지가 "mike 님이 실행했습니다 · CFO Services", "예약 실행 · CFO Services", "센서 실행 · CFO Services"처럼 표시됩니다. 오른쪽에는 실행에 걸린 시간이 표시되고, **실패** 또는 **중지됨**인 경우 소요 시간과 함께 표시됩니다. 중지된 실행에는 중지한 사람의 이름이 표시됩니다.
- **세 번째 줄**은 있는 경우 문제가 된 내용을 보여 줍니다. 실행 중 단계가 실패하거나 경고가 발생하면 단계 이름과 메시지가 표시되며, 다른 단계에도 문제가 있으면 "외 2개"로 표시됩니다. 이 줄을 클릭하면 해당 단계에서 워크플로가 열립니다.

실행이 진행 중인 동안에는 [현재 실행 중](#현재-실행-중)에 나열됩니다. 실행이 끝나면 해당 행에 결과가 표시됩니다. 워크플로: 실행 단계나 매크로를 통해 다른 워크플로가 실행한 워크플로는 자체 행이 없으며, 그 안의 단계 문제는 이를 호출한 실행의 행에 표시됩니다. 실행이 목록에 없는 단계 문제는 "단계 실패 · CRM Pipeline · CFO Services"처럼 자체 행으로 표시됩니다.

워크플로, 단계, 테이블, 차원, 프로젝트 등의 변경은 각각 행 하나로 표시되며, 예를 들어 단계 이름 아래에 "mike 님이 단계를 수정했습니다 · CFO Services"처럼 나타납니다.

대부분의 행은 클릭하거나 Enter 키를 누르면 해당 항목이 열립니다. 실행이나 생성, 수정, 가져오기, 내보내기된 워크플로는 해당 프로젝트의 **워크플로** 탭을 열고 해당 워크플로를 선택합니다. 단계 문제, 또는 생성, 수정, 삭제, 복사, 이동된 단계는 해당 단계에서 워크플로를 엽니다. 생성, 이름 변경, 게시 또는 게시 취소된 테이블은 테이블 탐색기에서 열리고, 생성 또는 수정된 차원은 편집을 위해 열리며, 생성, 수정, 가져오기, 내보내기, 백업되었거나 보안이 변경된 프로젝트는 해당 프로젝트를 엽니다.

### 반복되는 행

같은 사람이 같은 개체에 연달아 수행한 같은 종류의 편집은 행 하나로 합쳐지며, 같은 사람이나 일정이 같은 방식으로 시작한 같은 워크플로의 연속된 성공 실행도 마찬가지입니다. 행에서 **3개 편집** 또는 **4회 실행**을 클릭하면 각각을 볼 수 있고, 다시 클릭하면 접힙니다.

### 현재 실행 중

현재 실행 중인 워크플로는 목록 위의 **현재 실행 중**에 시작한 사람과 실행 시간과 함께 나열됩니다. 일시 중지된 실행에는 **일시 중지됨**이 표시됩니다. 워크플로 이름을 클릭하면 해당 프로젝트의 **워크플로** 목록에서 선택되고, **중지**를 클릭하면 해당 실행이 중지됩니다.

### 마우스 오버 작업

실행 행 위에 마우스를 올리거나 키보드로 해당 행으로 이동하면 아이콘 버튼 두 개가 표시되며, 툴팁은 **로그 열기**와 **워크플로 실행**입니다.

- **로그 열기**는 해당 워크플로로 필터링된 프로젝트 로그를 엽니다. 단계 문제의 행에도 이 버튼이 있습니다.
- **워크플로 실행**은 워크플로를 다시 실행합니다.

**중지**와 **워크플로 실행**은 워크플로의 자체 화면에서 중지하고 실행할 수 있는 멤버에게 동일하게 허용됩니다. **워크플로 실행**은 행의 실행이 단일 단계, 단계 범위 또는 시뮬레이션이었더라도 전체 워크플로를 기본 설정으로 실행합니다.

### 문제와 필터

로드된 활동에 실패하거나 경고가 있는 실행 또는 단계가 있으면 패널 머리글에 **문제 2개**와 같은 개수가 표시되며, 하나라도 실패했다면 오류로 표시됩니다. 클릭하면 해당 행만 표시됩니다.

패널 하단의 막대에서 목록에 표시할 내용을 선택합니다.

| 선택 | 표시 내용 |
|---|---|
| **모두** | 모든 항목 |
| **실행 횟수** | 워크플로 실행 |
| **변경 사항** | 워크플로, 단계, 테이블, 차원, 프로젝트 등의 변경 |
| **문제** | 실패하거나 경고가 있는 실행과 단계 |
| **내 활동** | 내가 수행한 실행과 변경 |

**필터**에 입력하면 워크플로, 프로젝트, 단계, 테이블, 차원 또는 멤버 이름에 입력한 텍스트가 포함된 행만 표시됩니다. 막대 끝에는 일치하는 이벤트 수가 **12개 이벤트**와 같이 표시됩니다. 패널은 선택한 항목을 이 브라우저에 기억합니다.

### 마지막 방문 이후 새 활동

**마지막 방문 이후 새 활동** 줄은 이전 방문 이후 도착한 활동과 이미 확인한 활동을 구분합니다. **모두**를 선택하고 **필터**에 아무것도 입력하지 않았을 때 표시됩니다. 다른 창으로 전환하거나 프로젝트 창을 닫으면 방문이 끝나며, 이 줄은 다음에 프로젝트 창을 열거나 페이지를 새로 고칠 때 이동합니다.

### 이전 활동 표시

목록은 최근 7일로 시작합니다. 목록 끝에서 **이전 활동 표시**를 클릭하면 로드된 가장 오래된 이벤트 이전 30일 동안의 이벤트를 최대 500개 더 불러오며, 다시 클릭하면 더 이전으로 이동합니다. 30일 동안 활동이 없으면 이 버튼이 사라집니다.

### 키보드

Tab 키로 행으로 이동한 다음 위쪽 및 아래쪽 화살표 키로 행 사이를 이동하고 Enter 키로 현재 행을 엽니다. Tab 키는 행의 마우스 오버 작업으로도 이동합니다.

### 제한 사항

- **마지막 방문은 브라우저별로 기억됩니다.** 다른 브라우저나 기기에서는 **마지막 방문 이후 새 활동** 줄이 해당 브라우저나 기기에서의 마지막 방문을 기준으로 표시됩니다.
- **개수는 패널에 로드된 활동을 기준으로 합니다.** 문제 개수, **문제**, 날짜별 요약은 처음에는 최근 7일 중 최신 이벤트 500개를 대상으로 하며, **이전 활동 표시**를 사용할수록 더 늘어납니다. 프로젝트 전체의 합계가 아닙니다.
- **대기 중인 실행은 시작됨으로 표시되며,** 실제로 시작되면 **현재 실행 중**에 나타납니다. 소요 시간은 대기열에 들어간 시점부터 계산됩니다.
- **매크로 안의 매크로에서 발생한 단계 문제**는 최상위 실행의 행에 표시되지 않습니다.
- **자주 실행되는 워크플로**는 행이 많아집니다. 나란히 있는 성공 실행은 합쳐지지만, 번갈아 실행되는 두 워크플로의 성공 실행은 합쳐지지 않습니다.
- **이 패널이 출시되기 전의 실행**은 결과 없이 시작됨으로 표시되며, 그 이전의 중지 기록은 나타나지 않습니다.
- **늦게 기록된 이벤트**는 이미 더 새로운 이벤트가 표시된 뒤라면 페이지를 다시 로드해야 표시됩니다.
- **30일을 넘게 열어 두고 사용하지 않은 프로젝트 창**은 30일 전부터 이어서 표시합니다.
- **최근 7일 동안 활동이 없으면** 패널에 "최근 7일간 활동이 없습니다."라는 메시지가 표시되고 **이전 활동 표시**는 나타나지 않으므로 이전 활동을 로드할 수 없습니다.
