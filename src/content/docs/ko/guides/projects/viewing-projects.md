## 설명


**Analyze**에서 프로젝트 기능은 액세스 제어와 권한 수정을 훨씬 쉽게 해 주는 구획화 수준을 제공합니다. 프로젝트는 워크스페이스 탭 내에서 데이터를 구분하는 기본 단위입니다.



프로젝트는 Analyze에 속하고 워크플로는 프로젝트에 속하므로, 프로젝트에는 워크플로가 포함됩니다. 워크플로는 간단히 말해 데이터 변환 파이프라인, 데이터 분석, ETL 프로세스까지 폭넓은 작업을 수행합니다. 워크플로에 대한 자세한 내용은 “워크플로” 섹션에서 확인할 수 있습니다.



## 프로젝트 액세스


**프로젝트에 액세스하려면 다음과 같이 합니다.**


1. Analyze를 엽니다.
2. 상단 메뉴 표시줄에서 “프로젝트”를 선택합니다.

그러면 프로젝트 계층 구조가 표시됩니다. 여기에는 액세스 권한이 있는 프로젝트의 계층 구조가 나타납니다. 워크스페이스에 다른 프로젝트가 더 있을 수 있지만, 소유자가 아니거나 해당 프로젝트에 지정되지 않았다면 표시되지 않습니다.
