이 안내서는 새 프로젝트에서 시작하여 보고서, 지표, AI 어시스턴트가 읽는 로드 및 검사가 끝난 모델을 만들고 이를 인계하는 과정을 설명합니다. 프로젝트 **Foundation** 탭의 **설정** 체크리스트에 있는 여덟 개 항목을 따라 진행합니다. 각 단계에는 해당 내용을 자세히 다루는 [Data Foundation: Common Finance Model](/ko/guides/projects/data-foundation/)의 해당 부분으로 연결되는 링크가 있습니다.

## 시작하기 전에

- 프로젝트를 만들 수 있어야 하며, 공유 프로젝트의 경우 아키텍트여야 합니다.
- 연결하려는 각 ERP의 자격 증명을 준비하십시오. 자격 증명이 없으면 **Foundation** 탭이 ERP 관리자에게 보낼 액세스 요청서를 작성해 줍니다. [ERP 연결](/ko/guides/projects/data-foundation/#erp-연결)을 참조하십시오.
- 어떤 템플릿이 적합한지 결정하십시오. **Enterprise Profitability**는 손익계산서와 마진 브리지를 구축합니다. **Cost to Serve**는 고객별 서비스 제공 비용을 추가합니다. **Operational Transfer Pricing**은 각 엔터티의 이익을 정책 범위와 비교하여 테스트합니다. 세 가지 모두 동일한 Common Finance Model을 읽습니다. [템플릿으로 모델 위에 구축](/ko/guides/projects/data-foundation/#템플릿으로-모델-위에-구축)을 참조하십시오.

## 설정 체크리스트 따라가기

<Steps>

1. **프로젝트 만들기.** Analyze에서 **프로젝트**를 열고 **새 프로젝트**를 클릭합니다. **시작 기준**에서 템플릿을 선택합니다. 아무것도 연결하기 전에 모델을 체험해 보려면 **샘플 데이터로 시작**을 선택합니다. 프로젝트가 바로 첫 **로드**를 실행하고 **Foundation** 탭에 완성된 예제가 표시됩니다. 본인이나 동료가 저장한 모델을 재사용하려면 **From a template file...** 옵션을 선택합니다. [내 템플릿으로 저장](/ko/guides/projects/data-foundation/#내-템플릿으로-저장)을 참조하십시오.

2. **데이터 연결.** **Foundation** 탭에서 기존 연결을 선택하거나 새로 만들고, **연결 테스트**를 클릭하고, 로드할 엔터티를 선택하고, **이력 개월 수**를 설정한 다음 **연결**을 클릭합니다. 다른 시스템이나 다른 인스턴스를 추가하려면 이 과정을 반복하고 **Add this as another source instead of replacing the current one**을 선택합니다. ERP 외부의 데이터는 파일로 추가합니다. [ERP 연결](/ko/guides/projects/data-foundation/#erp-연결)과 [소스](/ko/guides/projects/data-foundation/#소스)를 참조하십시오.

3. **데이터 로드.** **로드**를 클릭합니다. 모든 소스를 모델에 맞게 조정하고, 보고 통화로 환산하고, 검사합니다. **What to do next**에는 확인이 필요한 항목이 중요도 순으로 나열됩니다. [데이터 로드](/ko/guides/projects/data-foundation/#데이터-로드)를 참조하십시오.

4. **로드에서 제기된 질문에 답하기.** 여러 소스가 같은 코드를 서로 다른 의미로 사용하는 경우 **Codes waiting for your answer**가 같은 의미인지 묻습니다. 두 소스가 같은 월을 다루는 경우 **Choose which source counts from when**에서 선택합니다. **Apply changes**를 클릭하면 ERP에서 다시 가져오지 않고 다시 구축합니다. 하나씩 답하는 대신 어시스턴트에게 답변을 제안해 달라고 요청할 수도 있습니다. [소스 간 코드 매핑](/ko/guides/projects/data-foundation/#소스-간-코드-매핑)과 [Ask로 미해결 질문 해결](/ko/guides/projects/data-foundation/#ask로-미해결-질문-해결)을 참조하십시오.

5. **합계 일치 여부 확인.** **준비 상태** 그리드에는 엔터티, 기간, 검사마다 한 행이 표시됩니다. 의심스러운 수치는 **Explain this number**로 열 수 있으며, 원장에 있는 금액, 안팎으로 배부된 금액, 그룹에서 제거된 금액으로 나누어 보여 줍니다. [준비 상태 검사](/ko/guides/projects/data-foundation/#준비-상태-검사)와 [수치 설명](/ko/guides/projects/data-foundation/#수치-설명)을 참조하십시오.

6. **계층 구조 검토.** **Open hierarchies**를 클릭하고, 엔터티, 계정, 부서 계층을 확인한 다음 **검토했습니다**를 선택합니다. [계층](/ko/guides/projects/data-foundation/#계층)을 참조하십시오.

7. **비즈니스에서 쓰는 이름으로 부르기.** **Business names**에서 범주, 손익계산서 라인, 지표, 열에 비즈니스에서 사용하는 이름을 지정합니다. 보고서, 지표, 어시스턴트에 그 이름이 표시됩니다. [비즈니스 이름](/ko/guides/projects/data-foundation/#비즈니스-이름)을 참조하십시오. 모델의 비용 배분 방식이 업무 방식과 맞지 않으면 **작업 > Allocations...** 메뉴에서 변경합니다. [배부 규칙](/ko/guides/projects/data-foundation/#배부-규칙)을 참조하십시오.

8. **최신 상태 유지.** 로드가 성공하면 **야간 새로 고침**을 클릭합니다. 필요하면 [이사회 자료](/ko/guides/projects/data-foundation/#이사회-자료)를 설정할 수 있으며, 선택한 폴더에 손익계산서 대시보드의 Excel 통합 문서와 PDF를 씁니다.

9. **공유, 문서화, 인계.** 프로젝트를 팀과 공유하고, **Download evidence pack**을 클릭하여 로드된 내용과 합계가 어떻게 일치하는지에 대한 기록을 받습니다. 고객을 위해 프로젝트를 설정한 경우에는 고객 측 소유자를 아키텍트로 지정한 다음 본인을 제거합니다. [프로젝트 인계](/ko/guides/projects/data-foundation/#프로젝트-인계)를 참조하십시오.

</Steps>

<Aside type="tip">
소스나 매핑을 크게 변경하기 전에 먼저 복사해 둘 필요는 없습니다. 복원 시점이 자동으로 만들어지며, **작업 > Restore...** 메뉴로 프로젝트를 되돌릴 수 있습니다. [복원 시점](/ko/guides/projects/data-foundation/#복원-시점)을 참조하십시오.
</Aside>

## 완료 후 갖추게 되는 것

- 하나의 계정과목표, 하나의 엔터티 집합, 하나의 보고 통화를 갖춘 Common Finance Model과, 내부 거래가 제거된 관리 그룹 손익계산서.
- 팀과 어시스턴트가 질문할 수 있는 모델, 지표, 분석 경로.
- 야간 새로 고침과, 선택 사항인 이사회 자료.
- 증빙 자료 묶음과, 고객 측 소유자가 관리하는 프로젝트.
