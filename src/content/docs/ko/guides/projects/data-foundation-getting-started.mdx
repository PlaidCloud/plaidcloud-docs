이 안내서는 새 프로젝트에서 시작해 보고서, 지표, AI 어시스턴트가 읽는 로드 및 검사 완료 모델을 만든 다음 이를 인계하는 과정을 설명합니다. 각 단계에서 프로젝트의 **홈** 레일에 있는 **Data Foundation** 아래의 **요약** 페이지가 **재무 시스템 추가**, **로드**, **질문 3개에 답변**, **보고서 열기** 같은 버튼으로 다음 단계 하나를 제시합니다. 아래 각 단계에는 해당 내용을 자세히 다루는 [Data Foundation: Common Finance Model](/ko/guides/projects/data-foundation/)의 해당 부분 링크가 있습니다.

## 시작하기 전에

- 프로젝트를 만들 수 있어야 하며, 공유 프로젝트의 경우 해당 프로젝트의 아키텍트여야 합니다.
- 연결하려는 각 시스템의 자격 증명을 준비하십시오. 자격 증명이 없으면 **아직 액세스 권한이 없으십니까?** 링크가 관리자에게 보낼 액세스 요청을 작성해 줍니다. [ERP 연결](/ko/guides/projects/data-foundation/#erp-연결)을 참조하십시오.
- 솔루션이 필요한지 정하십시오. **Data Foundation**만으로도 모델과 보고서를 사용할 수 있습니다. **Enterprise Profitability**는 비용을 제품과 고객에 배부합니다. **Cost to Serve**는 고객별 서비스 제공 비용을 추가합니다. **Operational Transfer Pricing**은 각 엔터티의 이익을 정책 범위와 대조해 검증합니다. 각 솔루션에는 Data Foundation이 포함되며, 모두 동일한 Common Finance Model을 읽습니다. [템플릿으로 모델 확장](/ko/guides/projects/data-foundation/#템플릿으로-모델-확장)을 참조하십시오.

## 모델에 데이터를 제공할 수 있는 시스템

Data Foundation은 아래의 모든 시스템에서 PlaidCloud 연결을 통해 직접 데이터를 읽으며, 한 프로젝트에서 여러 시스템과 각 시스템의 여러 인스턴스를 함께 사용할 수 있습니다. 아래 각 페이지는 액세스 권한을 부여하는 관리자를 위한 것이며, Data Foundation이 작성하는 액세스 요청에서 요구하는 항목과 최신 릴리스에서 추가로 읽는 항목을 나열합니다. [Data Foundation 지원 범위 매트릭스](/ko/reference/data-foundation-coverage-matrix/)에서 각 시스템이 직접 제공하는 데이터 세트를 확인할 수 있습니다.

## 설정 따라가기

<Steps>

1. **프로젝트 만들기.** Analyze에서 **프로젝트**를 열고 **새 프로젝트**를 클릭합니다. **시작 기준**에서 **Data Foundation** 또는 솔루션 중 하나를 선택합니다. 아무것도 연결하기 전에 모델을 체험해 보려면 **샘플 데이터로 시작**을 선택하십시오. 사용자 또는 동료가 저장한 모델을 재사용하려면 **템플릿 파일에서** 옵션을 선택하십시오. [내 템플릿으로 저장](/ko/guides/projects/data-foundation/#내-템플릿으로-저장)을 참조하십시오. 이미 있는 프로젝트에 Data Foundation을 추가하거나, 처음 로그인할 때 **재무 시스템 연결**에서 시작할 수도 있습니다. [Data Foundation 사용 시작](/ko/guides/projects/data-foundation/#data-foundation-사용-시작)을 참조하십시오.

2. **시스템 연결.** **요약**에서 **재무 시스템 추가**를 클릭합니다. **시스템** 페이지의 **시스템 추가**에서 시스템을 선택한 다음 해당 연결을 고르고 **시스템 추가**를 클릭합니다. QuickBooks Online과 Xero의 경우에는 **Connect to**를 클릭하고 액세스를 승인합니다. 다른 시스템이나 다른 인스턴스도 같은 방법으로 추가하며, 모든 시스템이 하나의 통합 모델에 데이터를 제공합니다. 시스템에 없는 데이터는 파일로 추가합니다. [ERP 연결](/ko/guides/projects/data-foundation/#erp-연결)과 [시스템](/ko/guides/projects/data-foundation/#시스템)을 참조하십시오.

3. **데이터 로드.** 연결과 함께 추가한 시스템은 바로 로드를 시작합니다. 그렇지 않으면 **요약**에서 **로드**를 클릭합니다. 모든 소스를 모델에 맞게 정합하고, 보고 통화로 환산하며, 검사합니다. [데이터 로드](/ko/guides/projects/data-foundation/#데이터-로드)를 참조하십시오.

4. **로드 중에 제기된 질문에 답하기.** 답변을 기다리는 질문이 있으면 **요약**의 다음 단계가 **질문**을 엽니다. 예를 들어 두 번째 시스템이 첫 번째 시스템과 같은 계정 코드를 사용하는지, 또는 이전된 엔터티에 대해 어느 달부터 어떤 시스템을 기준으로 할지를 묻습니다. 수익 클래스나 팀 기능에 대한 질문은 아무것도 보류하지 않으므로 다음 단계가 되지 않습니다. 각 질문에는 Weave가 제안하는 답변이 함께 표시되며, **제안된 항목 모두 수락**을 클릭하면 모든 제안을 한 번에 수락합니다. 답변은 다음 **로드** 또는 **변경 사항 적용** 시 반영됩니다. [소스 간 코드 매핑](/ko/guides/projects/data-foundation/#소스-간-코드-매핑), [기간별 기준 소스 선택](/ko/guides/projects/data-foundation/#기간별-기준-소스-선택), [Ask로 미해결 질문 해결](/ko/guides/projects/data-foundation/#ask로-미해결-질문-해결)을 참조하십시오.

5. **합계 일치 여부 확인.** **요약**의 **수치를 신뢰할 수 있습니까?** 패널에는 최대 다섯 가지 보증이 표시되며, 적색 보증에는 **Weave에게 이유 묻기** 버튼이 제공됩니다. 의심스러운 수치는 **이 숫자 설명**으로 열어 볼 수 있으며, 순이익을 라인, 엔터티, 계정별로 나누고 가장 큰 문서를 나열합니다. [Data Foundation: 수치를 신뢰할 수 있습니까?](/ko/guides/projects/data-foundation-proof/)와 [숫자 설명](/ko/guides/projects/data-foundation/#숫자-설명)을 참조하십시오.

6. **계층 구조 검토.** **요약**의 **작업 ▾** 에서 **계층…** 메뉴를 선택하고 엔터티, 계정, 부서 계층을 확인합니다. [계층](/ko/guides/projects/data-foundation/#계층)을 참조하십시오.

7. **비즈니스에서 쓰는 이름 지정.** 범주, 손익계산서 라인, 지표, 열에 비즈니스에서 사용하는 이름을 지정합니다. 보고서, 지표, 어시스턴트에 이 이름이 표시됩니다. [비즈니스 이름](/ko/guides/projects/data-foundation/#비즈니스-이름)을 참조하십시오. 솔루션이 있는 프로젝트에서 모델의 비용 분배 방식이 업무 방식과 맞지 않으면 레일의 **배부**에서 변경하십시오. [배부 규칙](/ko/guides/projects/data-foundation/#배부-규칙)을 참조하십시오.

8. **최신 상태 유지.** 로드에 성공하면 **요약**의 **작업 ▾** 에서 **야간 새로 고침**을 선택합니다. 선택적으로 [이사회 보고 자료](/ko/guides/projects/data-foundation/#이사회-보고-자료)를 설정할 수 있으며, 이 기능은 로드할 때마다 재무제표 Excel 통합 문서와 **CFM-Finance - Statements** 대시보드의 PDF를 사용자가 지정한 폴더에 작성합니다.

9. **공유, 문서화, 인계.** 팀과 프로젝트를 공유하고, **요약**의 **작업 ▾** 에서 **증빙 자료 팩 다운로드**를 선택해 로드된 내용과 합계 일치 방식에 대한 기록을 받습니다. 고객사를 위해 프로젝트를 설정한 경우에는 고객사 소유자를 아키텍트로 지정한 다음 본인을 제거하십시오. [프로젝트 인계](/ko/guides/projects/data-foundation/#프로젝트-인계)를 참조하십시오.

</Steps>

<Aside type="tip">
소스나 매핑을 크게 변경하기 전에 먼저 복사해 둘 필요는 없습니다. 복원 지점이 자동으로 만들어지며, **요약**의 **작업 ▾** 에 있는 **복원…** 메뉴로 프로젝트를 되돌릴 수 있습니다. [복원 지점](/ko/guides/projects/data-foundation/#복원-지점)을 참조하십시오.
</Aside>

## 완료 후 갖추게 되는 것

- 하나의 계정과목표, 하나의 엔터티 집합, 하나의 보고 통화를 갖춘 Common Finance Model과 내부거래가 제거된 관리용 그룹 손익계산서.
- 팀과 어시스턴트가 질문할 수 있는 모델, 지표, 분석 경로.
- 설정한 경우 이사회 보고 자료도 함께 만드는 야간 새로 고침.
- 증빙 자료 팩과 고객사 소유자가 관리하는 프로젝트.
