## 설명

**레이블**은 프로젝트 자체, 워크플로, 단계, 테이블, 차원, 데이터 편집기, 사용자 정의 함수 등 프로젝트의 개체에 붙이는 자유 형식 태그입니다. 작업 단계, 소스 시스템, 소유자, 릴리스 등 중요한 기준으로 관련 항목을 그룹화한 다음 나중에 빠르게 다시 찾는 데 사용하십시오.

레이블은 소문자로 저장되며 개체가 나타나는 모든 곳에 작은 칩으로 표시되므로, 일관된 레이블 집합은 대규모 프로젝트를 나누어 보는 가벼운 방법이 됩니다.

## 레이블을 관리하는 위치

태그를 지정할 수 있는 모든 개체의 세부 정보 패널에는 **레이블** 상자가 있습니다.

- **프로젝트 레이블** — 프로젝트 홈
- **워크플로 레이블**, **단계 레이블**, **테이블 레이블**, **차원 레이블**, **데이터 편집기 레이블**, **UDF 레이블** — 해당 항목의 세부 정보 패널
- **레이블** — 워크플로 단계 양식의 **일반** 탭

이 상자에는 개체의 현재 레이블이 칩으로 나열되고, 레이블을 더 추가할 수 있는 필드가 있으며 필드 옆에 **추가** 버튼이 있습니다.

## 레이블 추가

1. **레이블** 상자의 아무 곳이나 클릭하여 입력 필드에 커서를 놓습니다.
2. 레이블 텍스트를 입력합니다.
3. **추가**를 클릭하거나 **Enter**를 누르거나 쉼표를 입력하여 추가합니다.

새 레이블이 칩으로 나타나고 입력 필드가 비워져 다른 레이블을 추가할 수 있습니다. 레이블을 추가하면 칩이 여러 행으로 줄 바꿈되므로 숨겨지는 항목이 없습니다.

<Aside type="note">
레이블은 자동으로 소문자로 변환됩니다. 입력한 레이블이 해당 개체에 이미 있으면 PlaidCloud가 이를 알려 주며 중복 레이블을 추가하지 않습니다.
</Aside>

<Aside type="note">
처음 만드는 워크플로 단계에서는 입력한 레이블이 단계를 저장할 때까지 보관되었다가 단계에 연결됩니다. 그 밖의 모든 **레이블** 상자는 레이블을 추가하는 즉시 각각 저장합니다.
</Aside>

## 레이블 제거

- 칩의 **×** 를 클릭하여 해당 레이블을 제거하거나,
- 입력 필드가 비어 있을 때 **Backspace**를 눌러 마지막 칩을 제거합니다.

## 레이블로 항목 찾기

레이블은 워크플로, 단계, 테이블 등 프로젝트 목록의 **레이블** 열에 칩으로 표시됩니다. 특정 레이블이 있는 항목으로 목록을 좁히려면 목록의 필터 상자에 레이블을 입력하십시오. 검색은 항목 이름과 함께 레이블 텍스트도 일치시킵니다. 열에 다 들어가지 않는 긴 칩 위에 마우스를 올리면 전체 레이블이 표시됩니다.
