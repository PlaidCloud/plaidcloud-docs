프로젝트의 테이블은 `Period`, `Org`, `Account`처럼 열 이름을 공유하는 경우가 많습니다. **프로젝트 요소**는 이러한 이름 하나를 프로젝트 전체에 대해 한 번만 설명합니다. 그러면 해당 이름의 열이 있는 모든 테이블에 같은 설명, 마스크, 차원이 표시되므로 수십 개의 테이블에 같은 메모를 다시 입력할 필요가 없습니다.

[프로젝트 홈](/ko/guides/projects/project-home/)의 **데이터 모델** 페이지에는 프로젝트의 요소가 나열되고, 각 요소를 공유하는 테이블이 표시되며, 테이블 간에 서로 다른 부분이 플래그로 표시됩니다.

## 요소에 담기는 내용

| 설정 | 기능 |
|---|---|
| **이름** | 요소가 설명하는 열 이름이며, 열에 있는 그대로 정확하게 입력합니다. |
| **설명** | 열에 들어 있는 내용입니다. 자체 메모가 없는 열에는 이 설명이 표시됩니다. |
| **유형** | 프로젝트가 이 열에 기대하는 데이터 유형입니다. 적용되는 것이 아니라 검사됩니다. [유형 충돌](#유형-충돌)을 참조하십시오. |
| **마스크** | 숫자 마스크입니다. 자체 마스크가 없는 열은 이 마스크를 사용합니다. |
| **차원** | 열의 값이 유래하는 차원입니다. 자체 차원이 없는 열은 이 차원을 사용합니다. |
| **별칭** | 같은 의미를 가진 다른 열 이름입니다. |

## 열이 요소를 갖게 되는 방식

열 ID가 요소의 이름 또는 별칭 중 하나와 같으면 열이 해당 요소에 바인딩됩니다. 일치 여부는 정확하게 판단합니다. `period`와 `Period`는 서로 다른 이름이므로 둘 다 사용하려면 `period`를 `Period`의 별칭으로 추가하십시오.

요소를 추가하거나 삭제하면 일치하는 모든 열이 그에 따라 바뀝니다.

## 열이 요소에서 가져오는 값

바인딩된 열은 자체 값이 비어 있는 곳에서 요소의 **설명**, **마스크**, **차원**을 가져옵니다. 열에 직접 설정한 값이 항상 우선합니다. 요소는 테이블에 저장된 내용을 절대 바꾸지 않습니다. 요소를 삭제하면 각 열은 원래 가지고 있던 값으로 정확히 되돌아갑니다.

**유형**은 요소에서 가져오지 않습니다.

## 데이터 모델 페이지 열기

프로젝트를 연 다음 [프로젝트 홈](/ko/guides/projects/project-home/)의 레일에서 **데이터 모델**을 선택합니다. 레일의 배지에는 프로젝트의 요소 수가 표시됩니다. 열에서 이 페이지를 열 수도 있습니다.

- 테이블 탐색기에서 **열 속성**을 켜고 열을 선택합니다. **요소** 행에는 열의 요소가 표시되며, 요소가 없고 프로젝트를 편집할 수 있는 경우에는 **이것을 요소로 만들기**가 표시됩니다. 이를 클릭하면 해당 요소의 데이터 모델 페이지가 열리거나, 열 자체의 설명, 마스크, 차원으로 시작하는 새 요소의 페이지가 열립니다.
- 차원을 사용하는 대상의 목록에서 **프로젝트 요소**라는 행을 클릭하면 데이터 모델 페이지가 열립니다.

프로젝트를 열 수 있는 사람은 누구나 이 페이지를 볼 수 있습니다. 요소를 만들거나 변경하거나 삭제하려면 프로젝트에 대한 쓰기 액세스 권한이 있어야 하고 프로젝트가 잠겨 있지 않아야 합니다. 그렇지 않으면 페이지에 "여기서 데이터 모델을 볼 수는 있지만 변경할 수는 없습니다."라고 표시됩니다.

## 요소 만들기

1. **데이터 모델** 페이지에서 **새 요소**를 클릭합니다.
2. **이름**을 입력합니다. 필요에 따라 **설명**, **유형**, **마스크**, **차원**을 입력합니다. 모든 유형을 허용하려면 **유형**을 **모든 유형**으로 둡니다.
3. **별칭**에 같은 의미를 가진 다른 열 이름을 한 줄에 하나씩 입력합니다.
4. **저장**을 클릭합니다.

요소는 다른 요소가 이미 가지고 있는 이름이나 별칭을 사용할 수 없습니다. 요소를 변경하려면 요소 옆의 연필 아이콘(**요소 편집**)을 클릭합니다. 이름을 바꾸면 이전 이름이 별칭으로 남으므로 해당 열은 계속 요소를 사용합니다.

요소를 제거하려면 요소를 열어 **삭제**를 클릭한 다음 **요소 삭제**로 확인합니다. 확인 대화상자에는 이 요소에 바인딩된 테이블의 수가 표시됩니다. 해당 테이블에 저장된 내용은 변경되지 않습니다.

### 제안된 요소

페이지의 **추천** 아래에는 요소로 만들 만한 열 이름이 나열됩니다.

- 아직 요소나 별칭이 아니면서 둘 이상의 테이블에 있는 이름이며, 열의 유형이 조인 키가 될 수 있는 경우(알 수 없는 유형도 해당)입니다. "*name*은(는) 테이블 *n*개에 있습니다"로 표시됩니다. **요소 만들기**를 클릭하여 요소를 만듭니다.
- 대소문자와 밑줄을 무시하면 요소의 이름이나 별칭과 일치하는 이름이며, 한 테이블에만 있어도 해당됩니다. "*name*은(는) *element*(테이블 *n*개)처럼 보입니다"로 표시됩니다. **별칭 추가**를 클릭하면 해당 열이 그 요소에 바인딩됩니다.

## 데이터 모델 읽기

캔버스 위의 **그래프**와 **매트릭스** 전환 버튼은 같은 테이블과 요소를 두 가지 방식으로 보여 줍니다.

- **그래프.** 각 요소는 허브이며 각 테이블은 해당 요소의 열을 가진 요소에 연결된 카드입니다. 선 위의 **1**은 테이블의 유일한 키인 열을 나타냅니다. 여러 열로 이루어진 복합 키를 가진 테이블에는 표시되지 않습니다. 페이지는 요소 하나와 그 테이블을 표시한 상태로 열립니다. 요소를 클릭하면 해당 요소에 초점이 맞춰지고, 테이블을 클릭하면 해당 테이블에 초점이 맞춰지며, 테이블을 더블 클릭하면 테이블이 열립니다. **요소 숨기기** 옆의 칩으로 그림에서 원하지 않는 요소를 숨기거나 표시합니다.
- **매트릭스.** 테이블마다 한 행, 요소마다 한 열이 있습니다. **테이블 이름으로 필터링**을 사용하여 행을 좁힙니다.

### 유형 충돌

열의 유형이 나머지 테이블과 다른 테이블은 요소 아래에 "*column*은(는) *table*에서 *type*이며, 다른 테이블과 다릅니다."라고 플래그로 표시됩니다. 유형은 계열 단위로 비교하므로 정수와 소수는 충돌하지 않습니다. 요소에 **유형**이 있으면 나머지 열을 그 유형의 계열과 비교합니다. 없으면 대부분의 열이 사용하는 계열과 비교하며, 두 계열의 수가 같으면 알파벳순으로 앞선 계열을 사용합니다. 충돌은 경고일 뿐이며 아무것도 바꾸지 않습니다.

읽을 수 없는 테이블은 제외되고, 페이지가 중단되는 대신 페이지에 그 수가 표시됩니다.

## 요소가 표시되는 곳

요소는 요소 이름이 담긴 필 모양으로 표시됩니다.

- **테이블 탐색기.** 열 목록에는 **차원** 및 **행 액세스** 필 옆에 요소 필이 있는 **표시** 열이 있습니다. 필 위에 마우스를 올리면 요소와 그 설명, 차원이 표시됩니다.
- **열 속성.** **요소** 행에서 요소를 엽니다. **설명**, **마스크** 또는 **차원**이 비어 있으면 필드에 힌트로 "요소 *name*에서: *value*"가 표시됩니다. 이 힌트는 열과 함께 저장되지 않습니다.
- **단계의 데이터 매핑 탭.** 요소에 속한 소스 열과 대상 열에는 열 이름 뒤에 요소 필이 표시됩니다.

## REST API와 MCP에서 요소 사용하기

REST API는 `/rest/v1/analyze/projects/{project_id}/elements`에서 요소를 읽고 변경합니다.

| 요청 | 기능 |
|---|---|
| `GET` | `elements`와 `index`를 반환하며, 후자는 바인딩된 각 열 이름을 해당 요소의 이름에 매핑합니다. |
| `PUT` | `name`, `memo`, `dtype`, `mask`, `dimension`, `aliases`로 요소를 만들거나 바꿉니다. 이름을 바꾸려면 `rename_from`을 추가합니다. |
| `?name=`이 있는 `DELETE` | 지정한 이름의 요소를 삭제합니다. |
| `GET` `/graph` | 데이터 모델 페이지에 표시되는 내용을 반환합니다. 테이블 수와 유형 충돌이 있는 각 요소, 각 테이블의 바인딩된 열, 제안 항목입니다. |

테이블 메타데이터는 열이 요소에서 가져오는 값이 아니라 각 열에 저장된 값을 반환합니다. 열이 값을 가져오는 요소를 찾으려면 `GET` elements의 `index`에서 열 이름을 조회하십시오.

[MCP](/ko/integrations/ai-coding-agents/getting-started/)로 연결된 어시스턴트는 `element_find`, `element_upsert`, `element_delete`를 사용합니다. 어시스턴트의 테이블 설명에는 각 열의 메모가 표시되며, 열에 메모가 없는 곳에는 요소의 값이 채워져 있습니다.
