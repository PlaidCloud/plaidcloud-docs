PlaidCloud에서는 레이블을 포함하여 데이터 편집기를 정리하고 관리할 수 있습니다. 데이터 편집기를 사용하면 사용자 상호작용으로 테이블 데이터를 편집하거나 데이터를 만들 수 있습니다.



PlaidCloud는 일련의 폴더를 탐색하는 것과 같은 경로 기반 시스템으로 데이터 편집기를 정리하므로 더 유연하고 논리적인 데이터 편집기 구성(제어 계층)이 가능합니다. 이 시스템에서는 데이터 편집기를 제어 계층 안에서 이동할 수 있습니다. 제어 계층의 여러 위치에서 하나의 데이터 편집기를 가리키는 여러 참조(대체 계층)를 만들 수도 있습니다. 이러한 방식으로 데이터 편집기를 관리하면 구조에 운영, 보고, 제어의 필요를 반영할 수 있습니다.




## 테이블에서 데이터 편집기 만들기


기존 테이블에서 바로 사용할 수 있는 데이터 편집기를 곧바로 만들 수 있습니다. PlaidCloud는 테이블의 열을 검사하여 편집기를 미리 구성합니다. 각 열에 맞는 입력 컨트롤을 선택하고, 반복되는 값이 적은 수의 집합인 열은 드롭다운 선택 목록으로 바꿉니다.


테이블에서 데이터 편집기를 만들려면 다음과 같이 합니다.


1. 프로젝트의 **테이블** 보기를 열고 테이블을 하나 선택합니다
2. **테이블에서 데이터 편집기 만들기**를 엽니다. 도구 모음의 **새로 만들기** 메뉴를 사용하거나 테이블을 마우스 오른쪽 버튼으로 클릭합니다
3. PlaidCloud가 테이블을 프로파일링하고 모든 항목이 미리 채워진 **데이터 편집기 구성** 창을 엽니다. 소스와 대상을 모두 선택한 테이블로 설정하여 편집 내용이 해당 테이블에 바로 저장되도록 하고, **양식 열** 탭의 각 열에 데이터 유형과 값에 맞는 컨트롤을 지정합니다
4. 열을 검토하고 필요에 따라 컨트롤을 조정합니다
5. **저장** 또는 **저장 후 닫기**를 클릭합니다

저장하면 편집기가 만들어지며, **취소**를 클릭하면 아무것도 추가되지 않습니다.

열이 차원에 매핑되는 경우 저장하기 전에 양식 열 탭에서 해당 열의 계층을 선택하십시오. 차원 열에 계층이 없으면 PlaidCloud가 저장을 차단합니다.


## PlaidCloud가 열을 구성하는 방식


테이블에서 편집기를 만들거나 **소스에서 채우기**를 사용하면 PlaidCloud가 각 열을 자동으로 설정합니다.


- **부울** 열은 확인란이 되며, 열이 빈 값을 허용하는 경우에는 참/거짓 목록이 됩니다
- **날짜** 열은 날짜 선택기가 됩니다
- **Numeric** 열은 숫자 필드가 됩니다
- **차원**에 매핑되는 열은 계층을 선택하는 차원 선택기가 됩니다. 셀을 편집하면 [차원 유형 속성과 멤버 선택기](/ko/guides/dimensions/dimensions/#차원-유형-속성과-멤버-선택기)에 설명된 것과 같은 멤버 선택기 트리가 열리며, **모두 펼치기**, **모두 접기**, **적용**, **지우기**, **취소**를 사용할 수 있습니다
- 값이 적은 수의 집합 안에서 반복되는 열(예: 상태 또는 지역 코드)은 열에서 찾은 값을 나열하는 **드롭다운**이 됩니다
- 그 밖의 **텍스트** 열은 텍스트 필드가 되며, 값이 긴 경우에는 텍스트 영역이 됩니다
- PlaidCloud는 자동 생성된 ID 같은 키 성격의 열을 포함하지만 읽기 전용으로 표시합니다

매우 큰 테이블의 경우 PlaidCloud는 행 샘플로 값 목록을 추정합니다. 이후 열의 컨트롤은 언제든지 변경할 수 있습니다.

**양식 열** 탭에서 열을 선택하면 PlaidCloud가 해당 컨트롤을 선택한 이유에 대한 짧은 설명을 볼 수 있습니다.


## 선택 목록 기준 조정


PlaidCloud는 열의 값이 적은 수의 집합 안에서 반복될 때만 열을 드롭다운으로 바꿉니다. 이 기준을 변경하고 열을 다시 도출할 수 있습니다.


1. **양식 열** 탭에서 **선택 목록 최대 값 수**를 열이 드롭다운이 될 수 있는 고유 값의 최대 개수로 설정합니다
2. **다시 프로파일링**을 클릭합니다

PlaidCloud는 새 설정으로 소스 테이블을 다시 검사하여 열을 다시 빌드합니다. 편집기에 이미 열이 있으면 다시 프로파일링할 때 열이 대체되므로 PlaidCloud가 확인을 요청합니다.


## 테이블에서 기존 편집기 채우기


이미 편집 중인 편집기에도 같은 자동 구성을 적용할 수 있습니다.


1. 데이터 편집기의 구성을 열고 **소스 및 대상** 탭으로 이동합니다
2. 소스를 테이블로 설정합니다
3. **양식 열** 탭에서 **소스에서 채우기**를 클릭합니다

PlaidCloud는 소스 테이블의 각 열에 대해 구성된 열을 추가합니다. 이미 사용자 지정한 열은 유지하며, 더 이상 소스에 없는 열은 제거하도록 안내합니다.


## 검색


데이터 편집기를 검색하려면 다음과 같이 합니다.


1. 제어 계층 왼쪽 아래의 필터 상자를 사용합니다

검색 필터는 데이터 편집기의 이름과 레이블에서 일치하는 항목을 찾아 위쪽 제어 계층에 결과를 표시합니다.




## 이동


제어 계층 안에서 데이터 편집기를 이동하려면 다음과 같이 합니다.


1. 배치하려는 폴더로 끌어다 놓습니다

## 이름 바꾸기


데이터 편집기의 이름을 바꾸려면 다음과 같이 합니다.


1. 데이터 편집기를 마우스 오른쪽 버튼으로 클릭합니다
2. 이름 바꾸기 옵션을 선택합니다
3. 새 이름을 입력하고 저장합니다

이제 데이터 편집기의 이름이 바뀌지만 원래의 고유 식별자는 유지됩니다.




## 삭제


데이터 편집기를 하나 또는 여러 개 삭제할 수 있습니다.


데이터 편집기를 삭제하려면 다음과 같이 합니다.


1. 제어 계층에서 데이터 편집기를 선택합니다
2. 상단 도구 모음의 삭제 버튼을 클릭합니다


## 새 디렉터리 구조 만들기


제어 계층에 새 폴더를 추가하려면 다음과 같이 합니다.


1. 도구 모음의 **새 폴더** 버튼을 클릭합니다

기존 폴더에 폴더를 추가하려면 다음과 같이 합니다.


1. 폴더를 마우스 오른쪽 버튼으로 클릭합니다
2. **새 폴더**를 선택합니다


## 보기 역할에 맞게 계층 표시


여러 역할이 데이터 편집기를 볼 수 있도록 하려면 다음과 같이 합니다.


1. 탐색기 또는 관리자 확인란을 클릭합니다

여러 데이터 편집기를 업데이트하려면 다음과 같이 합니다.


1. 제어 계층에서 데이터 편집기를 선택합니다
2. 상단 도구 모음의 작업 메뉴에서 원하는 보기 역할을 선택합니다


## 테이블 내용을 설명하는 메모


데이터 편집기에 메모를 추가하려면 다음과 같이 합니다.


1. 데이터 편집기를 선택합니다
2. 오른쪽 컨텍스트 양식에서 메모를 업데이트합니다


## 추가 계층 속성 보기


데이터 편집기의 추가 속성을 보고 편집하려면 다음과 같이 합니다.


1. 데이터 편집기를 선택하고 오른쪽의 데이터 편집기 컨텍스트 양식을 확인합니다


## 데이터 편집기 복제


데이터 편집기를 복제하려면 다음과 같이 합니다.


1. 데이터 편집기를 선택합니다
2. 상단 도구 모음의 복제 버튼을 클릭합니다


## AI 어시스턴트 또는 MCP를 통해 쓰기

구성 화면 외에도 `editor_upsert`는 데이터 편집기의 소스, 대상, 컨트롤을 설정하고 행을 직접 쓸 수 있습니다. `data`는 각 컨트롤의 ID를 키로 하는 행 객체의 목록입니다. 잘못된 날짜는 대상 테이블에 영향을 주기 전에 거부되므로, 잘못된 쓰기가 일부만 반영되는 일은 없습니다.
