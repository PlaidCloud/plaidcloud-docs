PlaidCloud에서는 레이블을 포함하여 계층을 정리하고 관리할 수 있습니다. 계층은 프로젝트 내의 모든 워크플로에서 사용할 수 있습니다.



PlaidCloud는 일련의 폴더를 탐색하는 것과 같은 경로 기반 시스템으로 계층을 정리하므로 더 유연하고 논리적인 계층 구성(제어 계층)이 가능합니다. 이 시스템에서는 계층을 제어 계층 안에서 이동하거나, 제어 계층의 여러 위치에서 하나의 계층을 가리키는 여러 참조(대체 계층)를 만들 수 있습니다. 이러한 방식으로 계층을 관리하면 구조에 운영, 보고, 제어의 필요를 반영할 수 있습니다.



## 검색


계층을 검색하려면 다음과 같이 합니다.


1. 제어 계층 왼쪽 아래의 필터 상자를 사용합니다
2. 검색 필터는 계층의 이름과 레이블에서 일치하는 항목을 찾아 위쪽 제어 계층에 결과를 표시합니다


## 이동


제어 계층 안에서 계층을 이동하려면 다음과 같이 합니다.


1. 배치하려는 폴더로 끌어다 놓습니다


## 이름 바꾸기


계층의 이름을 바꾸려면 다음과 같이 합니다.


1. 계층을 마우스 오른쪽 버튼으로 클릭합니다
2. 이름 바꾸기 옵션을 선택합니다
3. 새 이름을 입력하고 저장합니다
4. 이제 계층의 이름이 바뀌지만 원래의 고유 식별자는 유지됩니다


## 지우기


계층을 하나 또는 여러 개 지울 수 있습니다.


계층을 지우려면 다음과 같이 합니다.


1. 제어 계층에서 계층을 선택합니다
2. 상단 도구 모음의 지우기 버튼을 클릭합니다


## 삭제


### 계층을 하나 또는 여러 개 삭제할 수 있습니다


계층을 삭제하려면 다음과 같이 합니다.


1. 제어 계층에서 계층을 선택합니다
2. 상단 도구 모음의 삭제 버튼을 클릭합니다

삭제 작업은 계층이 워크플로 단계, 테이블 또는 뷰에서 사용 중인지 확인합니다. 사용 중이면 해당 연결을 제거하라는 요청이 표시됩니다.

<Aside>계층을 강제로 삭제할 수도 있습니다. 계층을 강제로 삭제하면 참조가 끊어진 채로 남으므로 드물게 사용해야 합니다.</Aside>



## 새 디렉터리 구조 만들기


새 폴더를 만들려면 다음과 같이 합니다.


1. 도구 모음의 **새 폴더** 버튼을 클릭합니다

기존 폴더에 폴더를 추가하려면 다음과 같이 합니다.


1. 폴더를 마우스 오른쪽 버튼으로 클릭합니다
2. **새 폴더**를 선택합니다


## 보기 역할에 맞게 계층 표시


역할별로 계층을 보려면 다음과 같이 합니다.


1. 탐색기 또는 관리자 확인란을 클릭합니다

업데이트해야 하는 계층을 보려면 다음과 같이 합니다.


1. 제어 계층에서 계층을 선택합니다
2. 상단 도구 모음의 작업 메뉴에서 원하는 보기 역할을 선택합니다


## 테이블 내용을 설명하는 메모


계층에 메모를 추가하려면 다음과 같이 합니다.


1. 계층을 선택합니다
2. 오른쪽 컨텍스트 양식에서 메모를 업데이트합니다


## 추가 계층 속성 보기


계층의 추가 속성을 보고 편집하려면 다음과 같이 합니다.


1. 계층을 선택합니다
2. 오른쪽의 계층 컨텍스트 양식을 확인합니다


## 계층 복제


계층을 복제하려면 다음과 같이 합니다.



1. 계층을 선택합니다


2. 상단 도구 모음의 복제 버튼을 클릭합니다
