PlaidCloud에서는 레이블을 포함하여 계층을 정리하고 관리할 수 있습니다. 계층은 프로젝트 내 모든 워크플로에서 사용할 수 있습니다.



PlaidCloud는 폴더 계열을 탐색하듯이 경로 기반 시스템으로 계층을 정리하므로, 계층을 더 유연하고 논리적으로 정리(제어 계층)할 수 있습니다. 이 시스템에서는 계층을 제어 계층 안에서 이동할 수 있으며, 하나의 계층을 제어 계층의 여러 위치에서 참조(대체 계층)하도록 만들 수도 있습니다. 이 방식으로 계층을 관리하면 구조에 운영, 보고, 통제의 요구 사항을 반영할 수 있습니다.



## 검색


계층을 검색하려면 다음과 같이 합니다.


1. 목록 하단의 행 수 옆에 있는 **필터**를 사용합니다(**/** 또는 Ctrl/Cmd+F를 누르면 바로 이동합니다).
2. 검색 필터는 계층 이름과 레이블에서 일치하는 항목을 찾아 계층에 결과를 표시합니다.


## 이동


제어 계층 안에서 계층을 이동하려면 다음과 같이 합니다.


1. 계층을 배치할 폴더로 끌어다 놓습니다.


## 이름 바꾸기


계층의 이름을 바꾸려면 다음과 같이 합니다.


1. 계층을 마우스 오른쪽 버튼으로 클릭합니다.
2. 이름 바꾸기 옵션을 선택합니다.
3. 새 이름을 입력하고 저장합니다.
4. 계층의 이름이 바뀌지만 원래의 고유 식별자는 그대로 유지됩니다.


## 지우기


계층 하나 또는 여러 계층을 지울 수 있습니다.


계층을 지우려면 다음과 같이 합니다.


1. 제어 계층에서 계층을 선택합니다.
2. 상단 도구 모음에서 지우기 버튼을 클릭합니다.


## 삭제


### 계층 하나 또는 여러 계층을 삭제할 수 있습니다


계층을 삭제하려면 다음과 같이 합니다.


1. 제어 계층에서 계층을 선택합니다.
2. 상단 도구 모음에서 삭제 버튼을 클릭합니다.

삭제 작업은 계층이 워크플로 단계, 테이블 또는 뷰에서 사용 중인지 확인합니다. 사용 중이면 해당 연결을 제거하라는 안내가 표시됩니다.

<Aside>계층을 강제로 삭제할 수도 있습니다. 강제 삭제하면 참조가 끊어진 채로 남으므로 꼭 필요한 경우에만 사용하십시오.</Aside>



## 새 디렉터리 구조 만들기


새 폴더를 만들려면 다음과 같이 합니다.


1. 도구 모음에서 **새 폴더** 버튼을 클릭합니다.

기존 폴더 안에 폴더를 추가하려면 다음과 같이 합니다.


1. 폴더를 마우스 오른쪽 버튼으로 클릭합니다.
2. **새 폴더**를 선택합니다.

선택 항목이 폴더 안에 있으면 새 폴더 이름을 입력하는 프롬프트에도 **최상위에 만들기**가 있습니다. 이를 선택하면 새 폴더가 프로젝트의 최상위에 만들어집니다.


## 보기 역할에 맞게 계층 표시


역할별로 계층을 보려면 다음과 같이 합니다.


1. **탐색기** 또는 **관리자** 확인란을 클릭합니다.

업데이트가 필요한 계층을 보려면 다음과 같이 합니다.


1. 제어 계층에서 계층을 선택합니다.
2. 상단 도구 모음의 작업 메뉴에서 원하는 보기 역할을 선택합니다.


## 테이블 내용을 설명하는 메모


계층에 메모를 추가하려면 다음과 같이 합니다.


1. 계층을 선택합니다.
2. 오른쪽 컨텍스트 양식에서 메모를 업데이트합니다.


## 추가 계층 특성 보기


계층의 추가 특성을 보고 편집하려면 다음과 같이 합니다.


1. 계층을 선택합니다.
2. 오른쪽의 계층 컨텍스트 양식을 확인합니다.


## 계층 복제


계층을 복제하려면 다음과 같이 합니다.



1. 계층을 선택합니다.


2. 상단 도구 모음에서 복제 버튼을 클릭합니다.
