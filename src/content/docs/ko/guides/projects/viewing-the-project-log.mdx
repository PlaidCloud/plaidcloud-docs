## 프로젝트 로그 보기 및 정렬

새 멤버 지정이나 워크플로 실행 등 프로젝트 내에서 작업이 발생하면 프로젝트 로그에 이벤트가 저장됩니다. 프로젝트 로그는 개별 워크플로 로그를 모두 통합해 보여 주어 프로젝트 활동을 더 포괄적으로 볼 수 있게 합니다. 또한 PlaidCloud에서는 프로젝트 로그를 정렬하고 필터링하며 특정 로그 항목의 세부 정보를 볼 수 있습니다.


**프로젝트 로그를 보려면 다음과 같이 합니다.**
1. Analyze를 엽니다.
2. “프로젝트”를 선택합니다.
3. 로그 아이콘을 클릭합니다.

**프로젝트 로그를 정렬하고 필터링하려면 다음과 같이 합니다.**
1. 로그 오른쪽, “log message” 왼쪽에 있는 작은 아이콘을 클릭합니다.
2. 원하는 기준을 선택합니다.

**특정 로그 항목의 세부 정보를 보려면 다음과 같이 합니다.**
1. 원하는 로그 항목을 마우스 오른쪽 버튼으로 클릭합니다.
2. “Log Message” 상자에서 세부 정보를 확인합니다.

## 프로젝트 로그 지우기

프로젝트 로그를 가끔 지우는 것이 좋을 수 있습니다.

<Aside>프로젝트 로그를 지우면 각 워크플로*의 모든 하위 로그도 함께 삭제됩니다.</Aside>

**프로젝트 로그를 지우려면 다음과 같이 합니다.**
1. Analyze를 엽니다.
2. “프로젝트”를 선택합니다.
3. 로그 아이콘을 클릭합니다.
4. “Clear Log” 버튼을 클릭합니다.
