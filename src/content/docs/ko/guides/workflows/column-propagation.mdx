## 설명

소스에서 열의 이름을 바꾸거나 유형을 변경하거나 제거하면, 해당 열에 매핑된 모든 하위 단계도 그에 맞게 업데이트해야 합니다. **열 전파**를 사용하면 한 번의 확인으로 이 작업이 처리됩니다.

전파는 **ColumnMapper**가 있는 모든 단계(Project Table, Calculate, Append, Merge 등)에서 사용할 수 있습니다. 매퍼 도구 모음의 두 버튼으로 전파를 실행합니다.

* `Propagate All` - 매퍼의 모든 열을 전파합니다
* `Propagate Selected` - 매퍼 그리드에서 선택한 열만 전파합니다


## 열 변경 전파

1. 변경할 열이 있는 워크플로 단계를 엽니다
2. **ColumnMapper**에서 변경(이름 바꾸기, 유형 변경 등)을 수행합니다
3. 매퍼 도구 모음에서 `Propagate All`을 클릭합니다(또는 행을 선택한 뒤 `Propagate Selected`를 클릭합니다)
4. 소스 단계에 종속된 모든 단계의 트리가 표시된 **하위로 전파** 대화 상자가 열립니다
5. 변경을 적용할 단계를 선택합니다. 하위 단계는 자동으로 함께 선택됩니다
6. 집계 단계의 경우 아래쪽 **집계** 패널에서 새 열에 사용할 집계 함수를 선택합니다
7. `Confirm`을 클릭합니다

**집계** 패널에는 표준 집계 함수가 나열됩니다. 윈도 함수와 함께 사용하는 **고급 비그룹화 기준**은 단계 자체의 매퍼에서 설정하며 여기에서는 제공되지 않습니다. 선택한 집계가 열에 맞지 않으면 대화 상자에 어떤 열이 왜 맞지 않는지 표시되므로 다른 집계를 선택할 수 있습니다.

대화 상자의 기본값은 안전하게 설정되어 있습니다. 하위 행에 해당 열의 명시적 매핑이 없으면 소스 이름이 대상 이름으로 재사용되므로 전달 과정에서 정보가 손실되지 않습니다.


## 전파되는 항목

* 열 이름 바꾸기 - 소스 → 대상 이름 변경
* 유형 변경 - 열이 나타나는 모든 곳에서 dtype이 업데이트됩니다
* 이 단계에서 추가된 새 열 - 하위 매퍼로 전달됩니다
* 소스에 적용된 제거(strip) 작업

해당 열을 참조하지 않는 단계도 트리에는 표시되지만 기본적으로 선택되지 않습니다.


## 오류 및 재시도

대화 상자를 연 이후 다른 사용자가 하위 단계를 편집한 경우 전파는 오래된 버전 오류와 함께 실패합니다. 대화 상자는 종속성 그래프를 자동으로 다시 가져오며, 선택 항목을 잃지 않고 다시 시도할 수 있습니다. 다시 가져오기 자체가 실패하더라도 선택 항목은 유지되므로 근본 원인을 해결한 뒤 다시 시도할 수 있습니다.

<Aside>열 전파는 같은 워크플로 안의 단계만 수정합니다. 다른 워크플로가 해당 테이블을 사용하는 경우 그 매퍼를 별도로 업데이트하거나 [종속성 감사](../view-a-dependency-audit/)를 실행해 영향을 받는 단계를 찾으세요.</Aside>
