초기 워크플로 개발, 테스트 또는 문제 해결 중에는 단계를 개별적으로 실행하는 것이 유용한 경우가 많습니다. 단계 하나만 단독으로 실행하려면 해당 단계를 마우스 오른쪽 버튼으로 클릭하고 컨텍스트 메뉴에서 **단계 실행**을 선택합니다.
