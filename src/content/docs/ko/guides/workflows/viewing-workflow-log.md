## 워크플로 로그 보기


단계 실행이나 경고 발생과 같이 워크플로 안에서 일어나는 일은 워크플로 로그에 기록됩니다. 이 로그는 **프로젝트** 영역의 **로그** 탭에서 볼 수 있습니다. 여러 워크플로에 걸친 로그를 더 종합적으로 보려는 경우를 위해 워크플로 로그는 프로젝트 로그에도 있습니다.

[시각적 워크플로 디자이너](/ko/guides/workflows/advanced-workflows/)에서 작업 중이라면, 도구 모음의 **로그 보기** 버튼이 열려 있는 워크플로로 이미 필터링된 같은 로그 보기를 엽니다.



로그 뷰어에서는 로그를 정렬하고 필터링할 수 있으며, 특정 로그 항목의 세부 정보를 볼 수 있습니다.



## 워크플로 로그 지우기


가끔 워크플로 로그를 지워야 할 수 있습니다. 로그 뷰어에서 **로그 지우기** 버튼을 선택합니다. 선택한 워크플로를 기준으로 로그가 지워지며, 프로젝트 수준 로그에서도 해당 로그 항목이 제거됩니다.
