Alteryx 워크플로를 PlaidCloud로 가져오기 전에 이 체크리스트를 사용하세요. 패키지가 완전하면 PlaidCloud가 고급 워크플로, 매크로 워크플로, 문서 기반 종속 항목, 통제된 런타임 입력을 최소한의 후속 작업으로 생성할 수 있습니다.

<Aside type="note">
  대규모 포트폴리오의 경우 포트폴리오 전체에 대해 이 체크리스트를 한 번 실행하고, 우선순위가 높은 워크플로 계열마다 다시 실행하세요.
</Aside>

## 워크플로 파일 수집

마이그레이션에 포함되는 모든 워크플로 파일을 수집하세요.

1. 표준 워크플로: `.yxmd`.
2. 분석 앱: `.yxwz`.
3. 매크로: `.yxmc`.
4. 다른 워크플로에서 참조하는 중첩 매크로 또는 공유 매크로.
5. 프로덕션에서 여전히 사용 중인 워크플로 버전.

서로 호출하는 워크플로와 매크로는 함께 보관하세요. PlaidCloud는 이러한 관계를 사용해 매크로 워크플로를 생성하고 매크로의 입력 포트와 출력 포트를 연결합니다.

## 데이터 종속 항목 수집

워크플로가 읽거나 쓰거나 검사하는 파일을 패키징하세요.

- CSV, TSV, 고정 너비, JSON, XML, Excel, Access, YXDB 및 데이터베이스 추출 파일.
- Directory 도구 또는 Dynamic Input 도구에서 사용하는 폴더.
- 검증에 사용할 예상 출력 파일.
- 이미지, PDF, 템플릿, 지도 레이어와 같은 보고서 자산.
- 조인, 수식, 바꾸기, 매칭에 사용하는 조회 테이블과 규칙 테이블.

워크플로가 로컬 데스크톱 경로를 참조하는 경우 해당 파일이나 폴더를 가져오기 패키지에 포함하고, PlaidCloud가 이를 저장할 문서 경로를 선택하세요.

## 공간 사이드카 파일 수집

공간 파일 형식은 여러 파일을 함께 유지해야 하는 경우가 많습니다. 모든 사이드카 파일을 같은 폴더에 포함하세요.

- `.shp`, `.shx`, `.dbf`, `.prj`와 같은 셰이프파일 그룹.
- `.tab`, `.map`, `.id`, `.dat`와 같은 MapInfo 그룹.
- KML, GeoJSON 및 기타 독립 공간 파일.
- 워크플로에서 사용하는 투영 또는 좌표 참조 파일.

사이드카 파일이 누락되면 공간 검증 차이가 발생하는 경우가 많습니다.

## 런타임 입력 기록

분석 앱의 경우 사용자가 일반적으로 제공하는 값을 기록하세요.

1. 텍스트, 숫자, 날짜, 파일, 폴더 입력.
2. 드롭다운, 라디오 버튼, 확인란, 목록, 트리 선택.
3. 예약 실행이나 반복 실행에 사용하는 기본값.
4. 조건, 경고 또는 오류를 유발하는 값.

PlaidCloud는 이러한 입력을 통제된 워크플로 변수로 변환합니다.

## 대상 위치 선택

가져오기 전에 다음을 결정하세요.

1. 대상 PlaidCloud 프로젝트.
2. 대상 문서 계정.
3. 가져온 파일을 저장할 대상 문서 폴더.
4. 변환된 워크플로와 매크로의 명명 규칙.
5. 첫 번째 가져오기를 스테이징 가져오기로 할지 프로덕션 가져오기로 할지 여부.

포트폴리오 마이그레이션에서는 종속 항목을 쉽게 감사할 수 있도록 문서에 전용 마이그레이션 폴더를 사용하세요.

## 검증 근거 선택

워크플로마다 검증 수준을 선택하세요.

- 구조 검증은 워크플로가 실행 가능한 PlaidCloud DAG로 변환되는지 확인합니다.
- 출력 동등성 검증은 스키마, 행 수, 행 값을 신뢰할 수 있는 Alteryx 출력과 비교합니다.
- 아티팩트 검증은 보고서, PDF, 이미지, 차트, 지도 또는 모델 출력을 검토합니다.

출력 동등성이 필요한 경우에는 항상 예상 출력을 마이그레이션 패키지와 함께 보관하세요.

## 가져오기 준비 상태 체크리스트

가져오기 전에 다음을 확인하세요.

- 워크플로, 앱, 매크로 파일이 있습니다.
- 참조된 매크로가 있습니다.
- 입력 파일과 폴더가 있습니다.
- 공간 사이드카 파일이 함께 그룹화되어 있습니다.
- 마이그레이션 계획에 동등성 검증이 포함된 경우 예상 출력을 사용할 수 있습니다.
- 분석 앱의 런타임 입력 값을 알고 있습니다.
- 대상 프로젝트와 문서 경로가 선택되어 있습니다.
- 워크플로에 필요한 자격 증명 또는 외부 연결을 PlaidCloud에서 사용할 수 있습니다.
