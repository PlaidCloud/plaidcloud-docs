워크플로를 복사하면 대규모 변경을 계획하거나 다른 옵션으로 프로세스를 복제할 때 유용합니다. 복사본은 완전히 독립적이므로 복사본을 수정해도 원본에는 영향이 없습니다.

**워크플로** 테이블에서 두 가지 작업을 사용할 수 있습니다.

* **Duplicate Selected Workflows** — 같은 프로젝트 안에서 빠르게 제자리 복사
* **워크플로 복제** — 원하는 대상 프로젝트로 복사(기본값은 현재 프로젝트)


## Duplicate Selected Workflows

1. 프로젝트의 **워크플로** 테이블을 엽니다
2. 워크플로를 하나 이상 선택합니다
3. 도구 모음에서 `Duplicate Selected Workflows`를 클릭합니다

각 복제본은 같은 프로젝트에 생성되며, 원래 이름 뒤에 " copy"가 붙습니다.


## 워크플로 복제

워크플로를 다른 프로젝트로 복사하려는 경우(예: 개발 프로젝트에서 형제 프로젝트로 승격)에 사용합니다.

1. 원본 프로젝트의 **워크플로** 테이블을 엽니다
2. 워크플로를 하나 이상 선택합니다
3. **작업** 메뉴를 열고 `Clone Workflow(s)`를 클릭합니다
4. 대화 상자에서 **대상 프로젝트**를 선택합니다(기본값은 현재 프로젝트)
5. `Clone Workflow(s)`를 클릭합니다

클론이 실행되는 동안 진행률 대화 상자가 열리며, 전체 진행 막대(M개 중 N번째 워크플로)와 현재 복사 중인 워크플로의 단계별 진행 막대가 표시됩니다. `Run in Background`를 클릭하면 대화 상자를 닫고 계속 작업할 수 있습니다. 클론은 계속 실행되며 완료되면 알림이 나타납니다.

클론된 워크플로에는 이름 뒤에 " copy"가 붙어 대상 프로젝트에 이미 있는 항목과 충돌하지 않습니다.

<Aside>클론은 워크플로 정의와 단계 구성을 복사합니다. 워크플로가 참조하는 프로젝트 범위 리소스(테이블, 차원, 연결)는 대상 프로젝트에 이미 있어야 하며, 그렇지 않으면 별도로 클론해야 합니다.</Aside>
