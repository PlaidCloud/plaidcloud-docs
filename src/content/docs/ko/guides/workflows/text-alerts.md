워크플로는 [Notify Via SMS](/ko/reference/workflow-steps/notifications/notify-via-sms/) 단계로, 주의가 필요할 때 문자로 알릴 수 있습니다. 워크플로는 사용자가 직접 동의한 후에만 문자를 보낼 수 있습니다.

## 문자 알림 켜기

1. 오른쪽 위의 사용자 메뉴를 열고 **문자 알림**을 선택합니다.
2. **미국 휴대폰 번호**를 입력합니다.
3. **이 번호로 PlaidCloud 워크플로 문자 알림을 받는 데 동의합니다.** 를 선택합니다. 그 위에 있는 고지 사항과 **SMS Terms**, **SMS Privacy Policy** 링크를 읽어 보십시오.
4. **코드 보내기**를 클릭합니다. PlaidCloud가 6자리 코드를 번호로 문자 전송합니다. 문자가 도착하는 데 1~2분 걸릴 수 있습니다.
5. 10분 이내에 **확인 코드**를 입력하고 **확인**을 클릭합니다.

코드를 보내면 버튼에 60초 동안 카운트다운이 표시된 후 **코드 다시 보내기**로 바뀝니다. 코드가 아직 유효한 상태에서 다시 보내면 같은 코드가 문자로 전송되므로, 먼저 도착한 문자든 나중에 도착한 문자든 사용할 수 있습니다. 코드는 전화번호당 하루 3회, 한 사람당 시간당 3회까지 요청할 수 있습니다.

그러면 창에 마스킹된 번호와 함께 **문자 알림이 켜져 있습니다**가 표시됩니다. 미국 휴대폰 번호만 지원됩니다. 메시지 및 데이터 요금이 부과될 수 있으며, 메시지 빈도는 달라질 수 있습니다.

## 문자 알림 끄기

**문자 알림**을 열고 **문자 알림 중지**를 클릭하거나, 받은 문자에 **STOP**으로 회신합니다. 도움이 필요하면 **HELP**로 회신하십시오.

## STOP 이후 다시 켜기

STOP으로 회신하면 번호로 가는 모든 문자가 차단됩니다. 창에 표시된 알림 번호로 **START**를 문자로 보낸 다음 새 코드를 보내 확인하십시오.

## 문제가 발생한 경우

| 메시지 | 조치 사항 |
|---|---|
| 코드가 올바르지 않습니다 | 문자를 확인하고 코드를 다시 입력하십시오. |
| 코드가 만료되었습니다 | **코드 보내기**를 클릭하여 새 코드를 받으십시오. |
| 잘못된 코드를 너무 많이 입력했습니다 | 잘못된 코드를 5회 입력한 후에는 **코드 보내기**를 클릭하여 새 코드를 받으십시오. |
| 올바른 미국 휴대폰 번호를 입력하십시오 | 10자리 미국 휴대폰 번호를 사용하십시오. |
| 요청이 너무 많습니다 | 코드 요청 한도에 도달했습니다. 몇 분 기다린 후 다시 시도하십시오. |
| 현재 이 워크스페이스에서는 문자 알림을 사용할 수 없습니다 | 나중에 다시 시도하십시오. |

건강 정보나 금융 관련 개인 데이터에는 문자 알림을 사용하지 마십시오. 문의: support@plaidcloud.com.
