워크플로의 단계를 워크플로 실행 중에 건너뛰도록 설정할 수 있습니다. 디버깅용 단계나 아직 워크플로에서 완전히 제거할 준비가 되지 않은 이전 단계가 있을 때 유용합니다.

이 옵션을 설정하려면 워크플로 테이블에서 해당 단계의 **사용** 체크박스를 선택 해제합니다. 변경 내용은 클릭하는 즉시 저장되며 별도의 저장 작업은 필요하지 않습니다. 단계는 더 이상 워크플로의 일부로 실행되지 않지만, 단일 단계 실행 방법으로는 계속 실행할 수 있습니다.



사용 안 함으로 설정된 단계는 워크플로 단계 계층 테이블에 사용 안 함 표시가 나타납니다.
