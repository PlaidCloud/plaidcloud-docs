일부 Alteryx 워크플로는 테이블뿐 아니라 파일과 시각적 출력도 생성합니다. PlaidCloud는 이러한 단계를 Document에 저장하고, 워크플로 실행 이력에서 검토하며, 하위 프로세스에서 사용할 수 있는 클라우드 네이티브 아티팩트로 변환합니다.

<Aside type="note">
  아티팩트 검증은 생성된 출력의 비즈니스 내용과 하위 프로세스에서의 사용성에 초점을 맞춥니다. PlaidCloud는 공유, 일정 설정, 반복 가능한 검토를 위해 설계된 클라우드 네이티브 아티팩트를 생성합니다.
</Aside>

## 아티팩트 유형

변환된 워크플로는 다음을 생성하거나 사용할 수 있습니다.

- PDF.
- 이미지.
- 차트.
- 지도.
- HTML 또는 보고서 조각.
- 보고서 테이블 및 레이아웃.
- 대시보드 또는 인사이트 형태의 검토 아티팩트.
- 모델, NLP, OCR 또는 텍스트 분석 출력.

변환된 워크플로가 아티팩트를 기록하면 PlaidCloud는 생성된 파일을 Document에 저장합니다.

## 보고서 내용 검증

보고서와 PDF의 경우 다음을 확인합니다.

1. 파일이 예상한 Document 경로에 생성되었습니다.
2. 보고서에 예상한 테이블, 레이블, 섹션, 값이 포함되어 있습니다.
3. 이미지와 로고가 예상한 위치에 나타납니다.
4. 페이지 수준 레이아웃이 비즈니스 용도에 적합합니다.
5. 하위 프로세스의 사용자가 파일을 열거나 배포할 수 있습니다.

정확한 레이아웃이 중요한 경우, PlaidCloud 아티팩트를 신뢰할 수 있는 Alteryx 출력과 비교하십시오.

## 차트 및 대시보드 검증

차트와 대시보드 형태의 출력의 경우 다음을 확인합니다.

1. 소스 데이터가 예상한 스키마, 행 수, 값과 일치합니다.
2. 측정값, 차원, 레이블이 올바릅니다.
3. 필터 또는 매개변수가 올바르게 적용되었습니다.
4. 생성된 차트 또는 대시보드가 의도한 검토 워크플로를 지원합니다.

PlaidCloud는 Alteryx 데스크톱 전용 렌더러를 재현하는 대신 클라우드 네이티브 시각화를 만들 수 있습니다.

## 지도 검증

지도 출력의 경우 다음을 확인합니다.

1. 공간 입력이 성공적으로 로드되었습니다.
2. 좌표 참조 동작이 허용 가능합니다.
3. 지도 레이어에 예상한 레코드가 포함되어 있습니다.
4. 레이블, 경계, 지오메트리가 비즈니스 용도에 맞게 올바릅니다.
5. 의도적인 클라우드 네이티브 아티팩트 차이가 있으면 문서화되어 있습니다.

데이터가 중요한 지도 워크플로의 경우 아티팩트의 기반이 되는 지오메트리 테이블도 검증하십시오.

## OCR, PDF 및 NLP 출력 검증

추출 및 텍스트 워크플로의 경우 다음을 확인합니다.

1. 예상한 파일이 처리되었습니다.
2. 추출된 텍스트, 테이블, 점수, 주제 또는 분류가 있습니다.
3. 출력 테이블이 예상한 스키마 및 행 수와 일치합니다.
4. 값이 합의된 허용 오차 내에서 예상 출력과 일치합니다.
5. 실행기 참고 사항을 검토했습니다.

## 승인 기록

프로덕션 마이그레이션의 경우 다음을 포함하는 검증 기록을 보관하십시오.

- 워크플로 이름.
- 실행 날짜.
- Document 출력 경로.
- 예상 출력 소스.
- 검증 수준.
- 승인된 클라우드 네이티브 아티팩트 차이.
- 승인자.
