## 설명

**데이터 미리 보기 창**은 [시각적 워크플로 디자이너](/ko/guides/workflows/advanced-workflows/) 안에서 단계의 입력 테이블 또는 출력 테이블을 바로 보여 줍니다. 캔버스 하단에 고정되며, 형식이 지정되고 정렬 가능한 열과 **처음 100개 행**으로 구성된 읽기 전용 그리드입니다. 편집 사이사이에 빠르게 확인하기 위해 만들어졌습니다. 입력 또는 출력 테이블을 클릭해 살펴보고, 조인이 예상한 열을 만들었는지 확인하고, 필터가 실제로 걸러 냈는지 확인한 다음 계속 작업할 수 있습니다. 매번 전체 테이블 탐색기 창을 열 필요가 없습니다.

<Aside type="note">미리 보기 창은 이미 존재하는 데이터를 미리 봅니다. 단계가 아직 출력 테이블을 만들지 않았다면 창에 *"아직 데이터가 없습니다. 단계를 실행하여 이 테이블을 생성하십시오"*라고 표시됩니다. 단계를 실행하면 미리 보기가 채워집니다.</Aside>

## 미리 보기 열기

같은 창으로 연결되는 방법이 네 가지 있습니다.

- **단계 타일 위에 마우스를 올립니다.** 타일의 오른쪽 아래 모서리에 작은 찾아보기(테이블) 아이콘이 나타납니다. 이를 클릭합니다.
- **단계를 마우스 오른쪽 버튼으로 클릭**하고 **출력 데이터 미리 보기**를 선택합니다.
- **인스펙터에서** 단계의 **입력** 또는 **출력** 섹션에 있는 카드의 **눈 아이콘**을 클릭하면 해당 테이블을 미리 봅니다.
- **단계 타일에서** 타일의 **입력** 또는 **출력** 영역에 있는 테이블 아이콘을 클릭합니다. (차원 아이콘은 여전히 차원을 열고, 파일 아이콘은 여전히 파일을 다운로드합니다.)

창은 캔버스 아래에 고정됩니다. 특정 테이블을 클릭한 경우에는 해당 테이블을 표시하고, 그렇지 않으면 단계의 첫 번째 테이블 출력을 로드합니다.

## 단계 간 이동하며 살펴보기

창이 열려 있는 동안 **다른 단계를 클릭하면 미리 보기가 해당 단계의 출력으로 전환됩니다**. 단계마다 한 번의 클릭이면 됩니다. 단계의 연쇄를 따라 차례로 클릭하면서 각 단계에서 데이터의 모양이 어떻게 바뀌는지 확인하십시오.

창을 닫으려면 머리글의 **✕** 를 클릭하거나 **Esc**를 누릅니다. (단계가 선택되어 있으면 첫 번째 Esc는 창을 닫고, 다음 Esc는 선택을 해제합니다.)

## 창 머리글

머리글은 지금 보고 있는 내용을 정확히 알려 줍니다.

- **테이블 이름**과 **전체 약 M개 행 중 처음 N개 표시**: 엔진이 전체 행 수를 근사치로 보고하면 물결표가 나타납니다.
- **열 수**
- **테이블 선택기**: 미리 볼 테이블을 선택합니다. 둘 이상의 테이블을 쓰는 단계는 각 출력을 나열하며 첫 번째가 미리 선택됩니다. 입력을 미리 본 경우에는 출력보다 앞에 목록 맨 위에 나타나고 미리 선택되며, 거기에서 원하는 출력으로 전환할 수 있습니다.
- **새로 고침**: 필요할 때 미리 보기를 다시 가져옵니다.
- **테이블 탐색기에서 열기**: 창이 표시하는 테이블을 전체 탐색기에서 한 번의 클릭으로 엽니다(아래 참조).
- **✕**: 창을 닫습니다.

## 실행할 때마다 최신 상태 유지

미리 보는 단계가 창이 열려 있는 동안 실행되면 미리 보기는 **실행이 완료될 때 자동으로 한 번 새로 고침됩니다**. 따라서 **이 단계 실행** 후에는 보고 있던 같은 테이블(입력 포함)에 새 데이터가 이미 표시됩니다. 출력이 변경되지 않은 단계로 돌아가면 다시 가져오지 않고 미리 보기를 다시 엽니다.

## 더 필요한 경우: 테이블 탐색기

미리 보기는 의도적으로 한눈에 보는 용도이며 작업대가 아닙니다. 편집, 필터링, 다운로드는 지원하지 않습니다. 이러한 기능이 필요하면 창 머리글에서 **테이블 탐색기에서 열기**를 클릭하여 같은 테이블을 모든 기능을 제공하는 전체 [테이블 탐색기](/ko/guides/data/table-explorer/)에서 엽니다.

이 버튼이 필요한 경우는 두 가지입니다.

- **너비가 큰 테이블**: 창은 **처음 150개 열**을 렌더링하고 나머지는 테이블 탐색기에서 볼 수 있다고 안내합니다.
- **심층 분석**: 처음 100개 행을 넘어서는 내용이나 슬라이싱과 필터링이 필요한 경우입니다.

## 표시할 내용이 없을 때 창에 표시되는 내용

- **이 단계에는 테이블 출력이 없습니다**: 단계가 테이블 대신 파일이나 차원을 쓰며, 테이블을 클릭하지 않고 미리 보기를 열었습니다. 입력 테이블을 클릭하면 여전히 미리 볼 수 있습니다.
- **아직 데이터가 없습니다. 단계를 실행하여 이 테이블을 생성하십시오**: 출력 테이블이 아직 만들어지지 않았습니다. 단계를 실행하십시오.
- **테이블이 비어 있습니다**: 테이블은 있지만 행이 없습니다.
