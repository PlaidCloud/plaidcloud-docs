런처는 워크스페이스에 로그인한 후 가장 먼저 보이는 화면입니다. 프로젝트, 워크플로, 테이블, 대시보드,
패널 앱, 차원, 데이터 편집기, 문서 등 가장 자주 사용하는 항목을 타일이 있는 한 페이지에 모아 주므로
각 앱을 일일이 찾아다니지 않고 중단한 곳에서 바로 이어서 작업할 수 있습니다.

## 레인

페이지는 위에서 아래로 세 개의 레인으로 구성됩니다. 레인은 표시할 항목이 있을 때만 나타납니다.

- **조치 필요** — 가장 최근 실행이 실패한 워크플로입니다. 페이지에 들어서자마자
  문제가 눈에 띕니다. 각 카드는 실패한 실행으로 바로 연결되며, 이미 처리한 항목은
  **닫기**로 숨길 수 있습니다.
- **고정됨** — 즐겨찾기로 표시한 모든 항목이며, 고정한 순서대로 표시됩니다.
  모든 항목 유형을 여기에 고정할 수 있습니다([고정](#고정즐겨찾기) 참조).
- **최근 항목** — 최근에 열었거나 편집한 프로젝트, 대시보드, 패널 앱입니다.

<Aside type="note">
프로젝트, 대시보드, 패널 앱만 최근 사용 기준으로 표시됩니다. 워크플로, 테이블, 차원,
데이터 편집기, 문서는 보통 너무 많아서 그런 방식으로 나열할 수 없습니다. 자주 사용하는
항목은 고정해 두면 **고정됨** 레인에서 기다리고 있습니다.
</Aside>

## 프로젝트 타일

프로젝트 타일은 프로젝트를 한눈에 요약해서 보여 줍니다.

| 통계 | 의미 |
|---|---|
| **워크플로 실행** | 최근 기간에 완료된 워크플로 실행 |
| **마지막 실행** | 가장 최근 실행이 끝난 시점 |
| **워크플로** | 프로젝트에 포함된 워크플로 |
| **테이블** | 프로젝트에 포함된 테이블 |
| **레코드** | 해당 테이블 전체의 총 행 수(`~`는 추정치를 나타냄) |

실행 기록이 없는 프로젝트에는 실행 수치 대신 **마지막 편집**이 표시되며,
수치가 0이면 해당 항목은 아예 표시되지 않습니다.

### 타일 이미지

각 프로젝트 타일에는 흐리게 처리된 배경 이미지가 있습니다. 기본값은
PlaidCloud 팬이지만, 고객 로고나 작업을 한눈에 알아볼 수 있는 이미지처럼
프로젝트별 이미지를 지정하면 복잡한 런처에서도 눈에 띕니다.

이미지를 설정하는 방법은 다음과 같습니다.

1. 프로젝트를 열고 **홈** 탭으로 이동합니다.
2. 왼쪽 열 맨 아래의 **런처 타일 이미지**로 스크롤합니다.
3. 이미지가 있는 문서 계정을 선택한 다음 **찾아보기**로 이미지
   파일을 선택합니다.
4. 기본값으로 되돌리려면 **지우기**를 사용합니다.

이미지는 통계 뒤에서 흐리게 표시되어 통계를 읽는 데 지장이 없으므로, 흐리게 처리해도
잘 보이는 이미지를 선택하십시오. 세로로 긴 이미지보다 가로로 넓은 이미지가 타일 모양에
더 잘 맞습니다. 이를 설정하려면 프로젝트를 편집할 권한이 필요하며, 읽기 전용 뷰어에게는
선택기가 비활성화되어 표시됩니다.

<Aside type="note">
프로젝트를 볼 수 있는 사람은 누구나 타일 이미지를 볼 수 있지만, 이미지가 들어 있는
문서 계정을 읽을 수 있는 사람에게만 이미지가 제공됩니다. 해당 액세스 권한이 없는 뷰어에게는
기본 팬 이미지가 표시됩니다.
</Aside>

대시보드 타일은 다르게 동작합니다. 대시보드 자체의 자동 생성 미리보기 이미지를 표시하므로
선택할 항목이 없습니다.

## 항목 열기

모든 카드와 목록 행에는 기본 작업이 있으며, 필요한 경우 추가 작업이 있습니다.

| 항목 | 열리는 대상 | 추가로 사용 가능 |
|---|---|---|
| 프로젝트 | 프로젝트 | |
| 워크플로 | 워크플로 | 실행, 최근 실행 열기, 실시간 **실행 중** 상태 |
| 테이블 | 테이블 | 테이블 탐색기에서 열기 |
| 차원 | 해당 계층 편집기 | |
| 데이터 편집기 | 해당 프로젝트 | |
| 대시보드 | 대시보드 | 새 탭에서 열기 |
| Panel 앱 | 앱 | 새 탭에서 열기 |
| Dash 앱 | 앱 | 새 탭에서 열기 |
| 문서 | 파일 또는 폴더 | |

실행 중인 워크플로에는 자동으로 업데이트되는 실시간 상태 표시기가 나타나므로
새로 고칠 필요가 없습니다.

## 고정(즐겨찾기)

런처의 카드나 목록 행에서 **별표**를 클릭하면 고정됩니다. 고정한 항목은 최근에 사용했는지와
관계없이 항상 **고정됨** 레인에 표시되므로, 중요한 항목이 스크롤 밖으로 밀려나지 않습니다.

런처를 먼저 열지 않고 이미 작업 중인 위치에서도 고정할 수 있습니다. 별표 열을 찾으십시오.

- **프로젝트, 워크플로, 테이블, 차원, 데이터 편집기** — 프로젝트 안에 있는 각 목록의
  별표 열입니다.
- **대시보드**, **패널 앱**, **Dash 앱** — 내 대시보드와 내 Panel 앱의 별표 열입니다.
- **문서** — 문서 브라우저에서 파일 *또는* 폴더를 마우스 오른쪽 버튼으로 클릭하고
  **런처에 고정**을 선택합니다.

켜진 별표를 클릭하면 어디서든 고정이 해제됩니다. 어디서 고정하든 런처에 즉시 반영됩니다.

## 타일 또는 목록

도구 모음의 **타일 / 목록** 토글을 사용하면 여유 있는 카드 보기와 한 줄로 표시되는 촘촘한
목록 보기를 전환할 수 있습니다. 선택 내용은 기억되며, 전환은 즉시 이루어집니다. 이미 불러온
항목을 다시 가져오지 않고 다시 그리기만 합니다.

## 유형별 필터링

도구 모음 왼쪽의 칩 행에는 유형마다 고유한 아이콘이 있는 칩이 하나씩 있습니다. **프로젝트**,
**대시보드**, **패널 앱**, **워크플로**, **테이블**, **차원**, **데이터 편집기**, **문서**입니다.
눌린 칩은 해당 유형이 표시된다는 뜻이며, 칩을 클릭하면 **최근 항목** 및 **고정됨**
레인에서 해당 유형이 숨겨집니다. 필터는 다음에 방문할 때도 유지됩니다.

**조치 필요** 레인은 필터링되지 않습니다. 실패한 워크플로는 해당 유형의 칩이 꺼져 있어도
항상 표시됩니다.

## 검색 및 명령

아무 화면에서나 **Ctrl/Cmd-K**를 누르거나 런처 도구 모음에서 **검색**을 클릭하면
명령 팔레트가 열립니다. 단, 전기 등록부는 자체 팔레트를 위해 **Ctrl/Cmd-K**를 따로 사용합니다.

입력하기 전에는 두 가지 항목이 나열됩니다.

- **작업** — 여기에서 실행할 수 있는 명령입니다. 홈, 프로젝트, 대시보드 또는 문서로 이동,
  밝은 모양과 어두운 모양 간 전환, AI 연결, 도움말 보기가 있습니다. **이동** 작업은 워크스페이스에
  있는 앱에 대해서만 나타납니다.
- **최근 항목** — 가장 최근에 연 항목 여덟 개이며 최신순입니다. 런처나 팔레트에서 연 프로젝트,
  워크플로, 테이블, 차원, 데이터 편집기, 대시보드, 패널 앱, 문서와 다른 어디에서든 연 모든
  프로젝트가 포함됩니다. 프로젝트 안에서 연 항목(예: 워크플로나 차원)은 추가되지 않습니다.
  이 목록은 브라우저에 저장되므로 기기 간에 공유되지 않으며, 런처의 **최근 항목** 레인과는
  별개입니다([레인](#레인) 참조).

입력을 시작하면 두 목록이 동시에 좁혀집니다. 입력한 문자가 순서대로 나타나기만 하면 되므로
`proj`를 입력하면 **프로젝트로 이동**이 검색되며, 가장 가까운 일치 항목이 맨 위에 표시됩니다.
두 글자부터는 팔레트가 프로젝트, 워크플로, 테이블, 대시보드, 패널 앱 전체도 검색하여 그 결과를
유형별로 묶어 아래에 추가하며, 각 결과에는 보드와 동일한 열기 작업과 고정 별표가 있습니다.
이미 **최근 항목**에 표시된 결과는 반복해서 표시되지 않습니다.

- **위쪽/아래쪽 화살표**로 선택 항목을 이동합니다.
- **Enter**로 선택한 작업을 실행하거나 선택한 항목을 엽니다.
- **Escape**로 팔레트를 닫습니다.

차원, 데이터 편집기, 문서는 검색되지 않습니다. 고정하거나, 런처에서 연 후 **최근 항목**에서
찾거나, 해당 항목이 속한 프로젝트에서 접근하십시오.

결과를 클릭하면 열립니다. 결과의 **별표**를 클릭하면 팔레트를 열어 둔 채 고정되므로 한 번에
여러 항목을 고정할 수 있습니다.

## 새로 고침

런처는 다시 돌아왔을 때 데이터가 오래되었으면 자동으로 새로 고쳐집니다. 최신 내용을
즉시 가져오려면 도구 모음에서 **새로 고침**을 클릭합니다.

## 다른 곳에서 시작

PlaidCloud는 기본적으로 런처에서 열립니다. 대신 다른 앱에서 시작하려면 옵션 메뉴에서
**실행기에서 시작**을 끕니다.

## 모양(밝게, 어둡게, 자동)

상단 도구 모음의 **모양** 버튼(계정 메뉴 옆의 대비 아이콘)으로 PlaidCloud의 밝은 모양과 어두운 모양을
전환합니다. 이 설정은 런처, 모든 앱, 앱 안의 모든 창과 대화상자 등 모든 곳에 적용됩니다.

| 선택 | 동작 |
| --- | --- |
| **밝게** | 기기 설정과 관계없이 항상 밝은 모양을 사용합니다. |
| **어둡게** | 기기 설정과 관계없이 항상 어두운 모양을 사용합니다. |
| **자동(시스템)** | 운영 체제의 모양 설정을 따릅니다. |

**자동(시스템)** 옵션이 기본값이며 시스템을 실시간으로 따릅니다. 컴퓨터가 저녁에 어두운 모양으로 전환되도록
설정되어 있으면 PlaidCloud도 같은 시점에 새로 고침 없이 따라갑니다. **밝게** 또는 **어둡게**를 선택하면
모양이 고정되어 이후 시스템 설정을 무시합니다.

<Aside type="note">
선택 내용은 선택한 브라우저에 기억되므로 다른 브라우저나 다른 컴퓨터로는 이어지지 않습니다.
각각에서 한 번씩 설정하십시오. 브라우저의 사이트 데이터를 지우면 **자동**으로 재설정됩니다. 브라우저가
로컬 스토리지를 차단하는 경우(일부 비공개 브라우징 모드)에도 전환기는 해당 세션에서 계속 작동하지만
다음에는 다시 **자동**에서 시작합니다.
</Aside>

포함된 콘텐츠는 자체 색상을 유지합니다. 대시보드와 Panel 앱은 이 설정의 영향을 받지 않습니다.
