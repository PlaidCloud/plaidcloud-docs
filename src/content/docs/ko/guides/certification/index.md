PlaidCloud 인증은 실습 랩으로 여러분이 할 수 있는 일을 증명합니다. 각 랩은 작업할 프로젝트와 과제를 제공하고, 제출하면 작업을 자동으로 채점합니다. 예약해야 하는 시험도, 등록해야 하는 과정도 없습니다. 각 [학습 경로](#학습-경로)가 나열하는 가이드를 순서대로 읽으며 준비하면 됩니다.

## 티어와 트랙

| 티어 | 트랙 | 취득 방법 |
|---|---|---|
| **파운데이션** | 트랙 없음 | 파운데이션 랩 통과 |
| **프랙티셔너** | **데이터 엔지니어링**, **모델링** 또는 **분석** | 해당 트랙의 프랙티셔너 랩 통과 |
| **엑스퍼트** | **데이터 엔지니어링**, **모델링** 또는 **분석** | 시간 제한이 있는 해당 트랙의 엑스퍼트 랩 통과 |
| **마스터** | 트랙 없음 | 엑스퍼트 배지 3개를 보유하고 PlaidCloud의 운영 중인 구현 검토 통과 |

**재무 운영** 및 **관리 및 보안** 트랙은 **출시 예정**으로 표시됩니다. 아직 랩이 없습니다.

각 트랙에서는 엑스퍼트 배지가 프랙티셔너 배지를 대신하여 표시됩니다.

## 인증 열기

오른쪽 위의 사용자 메뉴를 열고 **인증**을 선택합니다. 창이 홈 탭으로 열리며 다음이 표시됩니다.

- 워크스페이스 관리자가 목표를 설정한 경우 내 목표가 담긴 배너. 해당 배지를 아직 보유하지 않았는지 여부도 알려 줍니다.
- **내 배지**: 각 배지를 취득한 날짜와 만료되는 날짜
- **랩**: 각 트랙을 **파운데이션**, **프랙티셔너**, **엑스퍼트**와 대조한 격자. 각 셀에는 **랩 시작**, 보유한 배지에는 **취득함**, 인증 워크스페이스에서는 [대기](#7일-대기) 후 랩을 다시 시작할 수 있는 날짜가 표시됩니다. 내 목표의 행에는 **내 목표**가 표시되며, 파운데이션 또는 마스터 목표는 **모든 트랙**에 표시됩니다.
- **마스터**: 엑스퍼트 배지 3개 중 몇 개를 보유하고 있는지

**홈으로 돌아가기**를 클릭하면 창이 닫힙니다.

## 인증 워크스페이스

랩은 PlaidCloud의 인증 워크스페이스에서만 실행됩니다. 다른 워크스페이스에서 **랩 시작**을 클릭하면 같은 이메일 주소로 빌드할 수 있는 멤버로서 인증 워크스페이스에 추가되고, 새 탭에서 해당 워크스페이스의 **인증** 창이 열립니다. 거기서 **랩 시작**을 다시 선택하면 랩이 시작됩니다.

처음에는 PlaidCloud가 인증 워크스페이스의 암호를 설정하라는 이메일을 보냅니다. 받은 편지함을 확인하십시오.

어떤 PlaidCloud 워크스페이스에도 속해 있지 않다면 PlaidCloud에 문의하십시오. 인증 워크스페이스에 초대해 드립니다.

배지는 이메일 주소에 귀속되므로, 랩을 시작하거나 포기하거나 배지를 취득하려면 확인된 이메일 주소가 필요합니다.

## 랩 진행 방식

1. 인증 워크스페이스에서 **랩 시작**을 선택합니다. PlaidCloud가 랩의 프로젝트를 만들어 주며, 본인만 열 수 있습니다.
2. 창에 랩의 제목, 시작한 시각, **과제**, 그리고 **채점용으로 제출**, **프로젝트 열기**, **포기**가 표시됩니다. 랩이 열려 있는 동안에는 배지와 격자 대신 랩이 표시됩니다.
3. **프로젝트 열기**를 선택하고 과제를 수행합니다.
4. **채점용으로 제출**을 선택합니다. 채점은 랩의 워크플로를 실행한 다음 그 실행이 만든 결과를 검사하므로, 실행 시간만큼 걸릴 수 있습니다.
   - 모든 검사를 통과하면 배지를 취득하고 랩 프로젝트는 삭제됩니다.
   - 검사에 하나라도 실패하면 **최근 결과**에 각 검사가 **통과** 또는 **실패**로 나열됩니다. 실패한 검사는 무엇이 잘못되었는지 알려 주며, 해당 내용을 다루는 가이드로 연결되는 **가이드 ›** 링크가 있습니다. 프로젝트를 수정한 다음 다시 제출하십시오.

랩이 열려 있는 동안에는 횟수에 제한 없이 제출할 수 있습니다. 랩의 워크플로가 이미 실행 중일 때 제출하면 아무것도 채점되지 않습니다. 실행이 끝날 때까지 기다린 후 다시 제출하십시오.

모든 검사를 통과했더라도 이메일 주소가 확인되지 않았다면 배지가 수여되지 않습니다. 이메일 주소를 확인한 다음 다시 제출하십시오.

### 시간 제한

엑스퍼트 랩은 시간 제한이 있습니다. **랩** 격자에 **시간 제한 · 4시간**이 표시되고, 열려 있는 엑스퍼트 랩에는 남은 시간(분)이 표시됩니다. 시계는 랩을 시작할 때 시작되며, 작업 중인지 여부와 관계없이 계속 흐릅니다.

시간이 지나면 랩을 통과할 수 없습니다. 다음에 제출하면 시도가 종료되고, 랩 프로젝트가 삭제되며, 7일의 대기 기간이 시작됩니다.

파운데이션 및 프랙티셔너 랩에는 시간 제한이 없습니다.

### 7일 대기

**포기**는 랩 프로젝트를 삭제하고 시도를 종료합니다. 먼저 확인 절차를 거칩니다. 랩을 포기하거나 엑스퍼트 랩의 시간이 초과되면 해당 랩을 다시 시작할 수 있을 때까지 7일의 대기 기간이 시작됩니다. **랩** 격자에 다시 시작할 수 있는 날짜가 표시됩니다. 일부 검사에 실패한 랩을 제출하는 것은 대기 기간을 시작하지 않습니다.

## 만료

배지는 취득 후 2년이 지나면 만료됩니다. 만료된 배지는 더 이상 **내 배지**나 관리자에게 표시되지 않으며, 해당 랩을 다시 시작할 수 있지만, 같은 트랙에서 더 높은 배지를 아직 보유하고 있으면 그렇지 않습니다.

## 마스터

마스터는 랩에서 취득하지 않는 유일한 배지입니다. 만료되지 않은 엑스퍼트 배지 3개와, PlaidCloud가 검토하는 운영 중인 구현 하나가 필요합니다.

**마스터** 카드의 **마스터 검토 요청**은 엑스퍼트 배지 3개를 보유하면 사용할 수 있게 됩니다. 이를 선택하면 **도움말 및 지원**이 열리며, 보유한 엑스퍼트 배지가 이미 기재된 새 티켓이 만들어집니다. 구현에 대한 세부 정보를 추가하여 보내십시오. 검토에서는 다음을 확인합니다.

- 지정된 고객 또는 파트너에서 운영 중인 구현일 것
- 직접 구축했거나 주도했을 것
- 최소 두 개 트랙의 기능을 사용할 것
- 이를 확인해 줄 지정된 담당자가 있을 것

마스터 배지도 부여된 후 2년이 지나면 만료됩니다.

## 배지 공유

각 배지에는 배지, 이름, 발급 시기, 만료 시기, 그리고 아직 유효한지 여부를 보여 주는 고유한 공개 검증 페이지가 있습니다. 이름은 배지를 공개할 때 인증 워크스페이스의 프로필에 있는 이름이며, 랩을 시작할 때 PlaidCloud가 그곳에 계정을 만들었다면 이메일 주소에서 @ 앞부분입니다. 변경된 이름을 표시하려면 배지를 비공개로 전환한 다음 다시 공개로 전환해야 합니다. 이 페이지에는 전체 이메일 주소가 표시되지 않습니다. 이 페이지는 배지가 공개인 동안에만 존재합니다.

인증 워크스페이스의 **내 배지**에서 각 배지 아래에 다음이 있습니다.

- **공개로 설정**은 배지의 검증 페이지를 게시합니다. 선택을 해제하면 페이지가 내려갑니다.
- **링크 복사**는 페이지의 주소를 복사합니다.
- **LinkedIn에 추가**는 배지의 내용이 채워진 상태로 LinkedIn의 인증 추가 양식을 엽니다.

**링크 복사**와 **LinkedIn에 추가**는 배지가 공개인 동안에만 작동합니다. 다른 워크스페이스에서는 공개 배지에 **링크 복사**와 **LinkedIn에 추가**가 그대로 있고, 공개가 아닌 배지에는 인증 워크스페이스의 **인증** 창을 여는 **인증 작업 영역에서 공유**가 제공됩니다.

공유하려면 확인된 이메일 주소가 필요합니다. 이메일 주소가 확인되기 전에는 **내 배지**에 아무것도 나열되지 않습니다.

## 관리자에게 표시되는 내용

배지는 이메일 주소에 귀속되므로, 해당 주소로 멤버인 모든 워크스페이스에 표시됩니다. 워크스페이스의 **멤버** 목록에서 관리자는 각 멤버의 배지와 목표를 확인하고 목표 트랙을 지정할 수 있습니다. 관리자에게는 배지만 보이며 랩 시도나 결과는 보이지 않습니다. [인증 배지 및 목표](/ko/administration/access/member-management/#인증-배지-및-목표)를 참조하십시오.
