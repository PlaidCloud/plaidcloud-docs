## 개요

대시보드를 사용하면 액세스할 수 있는 모든 프로젝트 또는 워크스페이스의 데이터를 기반으로 대화형 뷰를 빌드할 수 있습니다. 하나의 대시보드에서 여러 프로젝트의 테이블을 결합하고, 시각화와 원시 탐색을 함께 사용하고, 상시 보고서와 임시 분석을 모두 제공할 수 있습니다. 대시보드는 구성을 변경하지 않고도 작은 참조 테이블부터 수십억 행의 데이터셋까지 확장됩니다.

## 대시보드 계정

대시보드 계정은 PlaidCloud에서 처음 대시보드를 열 때 자동으로 설정되므로 직접 만들 필요가 없습니다. 볼 수 있는 항목은 PlaidCloud 워크스페이스 멤버십과 보안 그룹에 따라 결정됩니다.

<Aside>사용자의 추가, 변경, 제거는 대시보드 서비스 안이 아니라 PlaidCloud에서 하십시오. [워크스페이스 멤버 관리](/ko/administration/access/overview/managing-workspace-members/)를 참조하십시오. 대시보드 서비스에서 사용자 계정을 직접 만드는 것은 관리자 전용 작업이며, 이렇게 만든 계정은 워크스페이스 멤버십과 연결되지 않습니다.</Aside>

## 볼 수 있는 대시보드

PlaidCloud의 대시보드 목록에는 액세스할 수 있는 프로젝트에 속한 게시된 대시보드가 표시됩니다. 일반적인 경우이며 거의 모든 대시보드가 여기에 해당합니다.

대시보드의 소유자와 워크스페이스 관리자는 대시보드를 특정 보안 그룹으로 제한할 수 있습니다. 제한된 대시보드는 해당 그룹의 멤버, 그리고 모든 대시보드를 볼 수 있는 소유자와 워크스페이스 관리자에게만 목록에 표시됩니다. 제한이 없는 대시보드는 해당 프로젝트에 액세스할 수 있는 모든 사용자에게 표시되므로, 한 대시보드를 제한해도 다른 대시보드를 볼 수 있는 사용자는 변경되지 않습니다.

목록에 대시보드가 없다면 다음 두 가지를 알아 두십시오.

- **제한된 대시보드는 열기만 막는 것이 아니라 목록에서도 숨겨집니다.** 대시보드의 프로젝트에 액세스할 수 있고 해당 링크를 열 수 있다면 **액세스 요청** 페이지가 표시됩니다. 그렇지 않으면 삭제되었다고 단정하지 말고 소유자에게 문의하십시오.
- **제한된 대시보드가 사용자에게 도달하려면 대시보드 계정이 있어야 합니다.** 계정은 PlaidCloud에서 처음 대시보드를 열 때 만들어지며 그때 그룹이 적용됩니다.

<Aside>PlaidCloud에서 대시보드를 볼 수 있는 사용자는 **누가 볼 수 있습니까?**로 설정합니다. [대시보드를 볼 수 있는 사용자 제어](/ko/guides/dashboards/control-who-can-see-a-dashboard/)를 참조하십시오. 프로젝트 액세스는 그 위에 여전히 적용됩니다. 대시보드를 볼 수 있다고 해서 액세스할 수 없는 프로젝트의 데이터를 볼 수 있는 것은 아닙니다.</Aside>

## 표시 컨트롤

표시 컨트롤은 필터 모음의 컨트롤로, 대시보드를 보는 누구나 차트를 편집하기 위해 열지 않고도 차트의 그룹화 기준을 변경할 수 있게 합니다. 예를 들어 "Region"을 "Product Line"으로 바꿀 수 있습니다. 대시보드 편집자는 필터 모음의 설정 메뉴에서 표시 컨트롤을 추가하고 구성합니다. **Add or edit filters and controls**를 선택한 다음 **새로 만들기** 메뉴에서 **Add display control**을 선택합니다.

### 표시되는 열 제한

기본적으로 표시 컨트롤의 드롭다운에는 기본 데이터셋에서 **필터링 가능**으로 표시된 모든 열이 나열됩니다. 열이 많은 데이터셋에서는 원하는 열을 찾기 위해 수백 개의 열을 스크롤해야 할 수 있습니다.

이제 모든 표시 컨트롤의 구성 패널에 고유한 **Available columns** 필드가 있습니다. 이 필드를 특정 열 목록으로 설정하면 컨트롤의 드롭다운에 해당 열만 제공됩니다. 비워 두면 컨트롤은 이전과 똑같이 동작하여 필터링 가능한 모든 열을 제공하므로, 기존 대시보드를 변경하지 않아도 그대로 작동합니다.

표시 컨트롤을 제한하려면 다음과 같이 합니다.

1. 필터 모음의 설정 메뉴에서 **Add or edit filters and controls**를 엽니다.
2. 제한하려는 표시 컨트롤을 선택하거나 새로 추가합니다.
3. **Available columns**에서 사용자에게 표시하려는 열을 검색하여 선택합니다.
4. 저장합니다.

### "필터링 가능"과의 상호 작용

**Available columns**는 데이터셋에서 이미 **필터링 가능**으로 표시된 열만 제공합니다. 즉 해당 목록을 더 좁힐 뿐 우회하지는 않습니다. 열에서 **필터링 가능**을 선택 취소하면 **Available columns**, 임시 필터, 기본 필터, 해당 데이터셋을 기반으로 만든 모든 차트의 **Simple Metric** 선택기 등 모든 곳에서 여전히 제거됩니다.

이렇게 영향 범위가 넓기 때문에 **Available columns**가 존재합니다. 이 필드가 생기기 전에는 표시 컨트롤의 드롭다운을 줄이는 유일한 방법이 제공하지 않으려는 열에서 **필터링 가능**을 선택 취소하는 것이었으며, 이렇게 하면 해당 데이터셋의 모든 차트 지표 선택기에서도 같은 열이 숨겨졌습니다. 차트가 지표나 임시 필터로 필요로 할 수 있는 모든 열에는 **필터링 가능**을 선택된 상태로 두고, 각 표시 컨트롤이 그룹화 기준 드롭다운에 표시할 항목은 해당 컨트롤의 **Available columns**로 결정하십시오.

<Aside type="caution">표시 컨트롤의 **Available columns** 목록에 있는 열의 이름을 바꾸거나 삭제해도 자동으로 감지되지 않습니다. 컨트롤은 다음에 열릴 때 경고 없이 더 적은 수의 열을 제공할 뿐입니다. 데이터셋 열의 이름을 바꾸거나 제거한 후에는 표시 컨트롤의 **Available columns**를 다시 확인하십시오.</Aside>

### 저장 위치

**Available columns**는 해당 컨트롤의 나머지 설정과 함께 표시 컨트롤별로 저장됩니다. 대시보드와 함께 내보내기 및 가져오기가 되며, 같은 대시보드나 같은 데이터셋으로 만든 다른 대시보드의 다른 컨트롤에는 영향을 주지 않습니다.

## 테이블 편집


새 테이블을 만든 후 받는 메시지는 테이블 구성을 편집하라는 안내도 포함합니다. 구성을 편집하는 더 고급 기능도 있지만, 여기서는 제한적이고 더 간단한 부분부터 시작하겠습니다. 테이블 구성을 편집하려면 다음과 같이 합니다.


1. 원하는 테이블의 편집 아이콘을 클릭합니다
2. “List Columns” 탭을 클릭합니다
3. 열을 원하는 대로 정렬합니다
4. “저장”을 클릭합니다

이렇게 하면 데이터를 탐색할 때 테이블의 특정 열을 어떻게 사용할지 정의할 수 있습니다.


* **그룹화 가능:** 사용자가 특정 필드를 기준으로 지표를 그룹화하게 하려는 경우
* **필터링 가능:** 특정 필드를 기준으로 필터링해야 하는 경우
* **고유 개수:** 이 필드의 고유 개수를 얻으려는 경우
* **합계:** 합산하려는 지표인 경우
* **최솟값:** 기본 요약 통계를 수집하려는 지표인 경우
* **최댓값:** 기본 요약 통계를 수집하려는 지표인 경우
* **시간 열:** 날짜 또는 시간 필드에 대해 선택해야 합니다

## 데이터 탐색


데이터 탐색을 시작하려면 원하는 테이블을 클릭하기만 하면 됩니다. 기본적으로 테이블 뷰가 표시됩니다.



### 데이터 개수 가져오기


테이블에 있는 모든 레코드의 개수를 가져오려면 다음과 같이 합니다.


1. 필터를 “Since”로 변경합니다
2. 원하는 since 필터를 입력합니다


	* “3 years ago”와 같은 간단한 구문을 사용할 수 있습니다
3. 원하는 until 필터를 입력합니다


	* 시간의 상한 기본값은 “now”입니다
4. “그룹화 기준” 헤더를 선택합니다
5. 지표 섹션에 “Count”를 입력합니다
6. “COUNT(*)”를 선택합니다
7. “Query” 버튼을 클릭합니다

그러면 테이블에 결과가 표시됩니다.

**특정 필드 또는 제한 조건의 개수를 찾으려면:**

1. “그룹화 기준” 필드에 원하는 제한 조건을 입력합니다
2. 쿼리를 실행합니다

<Aside>제한 조건에 “measurement”를 사용하면 측정 유형에 따라 달라지는 측정값을 가리킵니다. 따라서 “filter section(예: weather_description 및 Maximum temperature)”에서 측정 유형이 같은지 확인해야 합니다.</Aside>

### 결과 수 제한

상위 10개 등 특정 개수의 결과만 필요한 경우:

1. “Options”를 선택합니다
2. “Row Limit” 섹션에 원하는 최대 결과 수를 입력합니다
3. “Query”를 클릭합니다

### 추가 시각화 도구

축약된 값을 전체 길이로 확장하려면:

1. “Edit Table Config”를 선택합니다
2. “List Sql Metric”을 클릭합니다
3. “Edit Metric”을 클릭합니다
4. “D3Format”을 클릭합니다

측정 단위를 편집하려면:


1. “Edit Table Config”를 선택합니다
2. “List Sql Metric”을 클릭합니다
3. “Edit Metric”을 클릭합니다
4. “SQL Expression”을 클릭합니다

차트 유형을 변경하려면:


1. “Chart Options”로 스크롤합니다
2. 필수 필드를 입력합니다
3. “Query”를 클릭합니다

여기에서 축 레이블, 여백, 눈금 등을 설정할 수 있습니다.
