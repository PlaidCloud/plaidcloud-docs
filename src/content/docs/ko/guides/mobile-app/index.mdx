PlaidCloud 앱을 사용하면 자리를 비운 상태에서도 워크플로를 실행하고 모니터링할 수 있습니다.
프로젝트를 둘러보고, 워크플로를 시작하거나 실행 중인 워크플로를 중지하며, 각 단계의
상태와 실행 기록을 확인할 수 있습니다. 앱에서 Weave를 사용하면 무엇이 실패했는지
물어보고 수정 사항을 승인할 수도 있습니다.
[모바일의 Weave](/ko/guides/mobile-app/weave-on-mobile/)를 참조하십시오.

이 앱은 브라우저에서 사용하는 PlaidCloud를 보완하는 도구이며, 별도의 제품이 아닙니다.
워크플로, 테이블, 대시보드는 웹에서 만들고, 앱은 이를 계속 실행되도록 관리하는 데 사용합니다.

## 시작하기 전에

- **기존 PlaidCloud 워크스페이스와 해당 워크스페이스의 계정.** 앱에는 가입 기능이 없습니다.
  워크스페이스 관리자가 평소처럼 웹에서 사용자를 워크스페이스에 추가합니다.
- **워크스페이스 이름.** 브라우저에서 사용하는 주소의 첫 부분입니다.
  `acme.plaid.cloud`의 경우 워크스페이스 이름은 `acme`입니다.
- **지원되는 기기:**

| 기기 | 최소 버전 |
| --- | --- |
| iPhone 및 iPad | iOS 또는 iPadOS 15.1 |
| Android 휴대폰 또는 태블릿 | Android 7.0 |

## 앱 설치

기기의 앱 스토어에서 **PlaidCloud**를 검색하거나 아래 링크로 바로 이동합니다.

- **iPhone 및 iPad:** [App Store의 PlaidCloud](https://apps.apple.com/app/id6769620647)
- **Android:** [Google Play의 PlaidCloud](https://play.google.com/store/apps/details?id=com.plaidcloud.mobile)

앱은 무료입니다.

## 로그인

1. 앱을 엽니다. 첫 화면에서 **워크스페이스**를 입력하라는 메시지가 표시됩니다.
2. `acme`와 같은 워크스페이스 이름을 입력하고 **계속**을 탭합니다. iPhone과 iPad에서는
   `https://acme.plaid.cloud/`와 같은 워크스페이스 전체 주소를 붙여넣을 수도 있습니다.
   앱은 워크스페이스 이름만 사용합니다.
3. 워크스페이스의 로그인 페이지가 열립니다. 브라우저에서 보던 것과 같은 페이지이므로
   평소처럼 로그인합니다. 비밀번호와 다단계 인증 코드를 사용하거나, 워크스페이스에서
   조직의 싱글 사인온(SSO)을 사용하는 경우 SSO로 로그인합니다.
4. 로그인이 완료되면 앱으로 돌아갑니다.

로그인 상태는 세션 간에 유지되며, 앱이 백그라운드에서 로그인을 갱신합니다.
자격 증명은 워크스페이스의 로그인 페이지에서만 입력하며, 앱 자체에는 입력하지 않습니다.
앱은 워크스페이스에 대해 OpenID Connect와 PKCE로 로그인하고, 발급된 토큰을
기기의 보안 저장소에 보관합니다.

로그인이 시작되지 않거나 해당 이름의 워크스페이스가 없다는 메시지가 표시되면,
워크스페이스 이름의 철자를 브라우저에서 사용하는 주소와 비교해 확인하십시오.

<Aside type="note">
앱은 한 번에 하나의 워크스페이스에만 로그인됩니다. 다른 워크스페이스를 사용하려면
**설정**에서 전환하십시오([워크스페이스 전환 또는 로그아웃](#워크스페이스-전환-또는-로그아웃) 참조).
</Aside>

## 워크플로 찾기

**프로젝트** 탭에는 액세스 권한이 있는 프로젝트가 각 프로젝트의 설명과 함께 표시됩니다.
목록을 아래로 당기면 새로 고침됩니다.

프로젝트를 탭하면 폴더별로 그룹화된 워크플로가 표시됩니다. 각 워크플로에는
**실행 중**, **대기 중**, **일시 중지됨**, **완료**, **오류**, **중지됨** 같은 현재 상태와
설명, 마지막 실행이 끝난 시점이 표시됩니다. 화면 상단의
**Search workflows**를 사용하면 워크플로 이름이나 설명으로 목록을 필터링할 수 있습니다.

iPhone과 iPad에서는 앱이 **홈** 탭에서 열리기도 합니다. **조치 필요**에는 마지막 실행이
실패한 워크플로가 오류 메시지와 함께 표시되고, **최근 항목**에는 가장 최근에 사용한
프로젝트가 표시됩니다. 둘 중 하나를 탭하면 해당 항목으로 바로 이동합니다.

## 워크플로 실행 및 모니터링

워크플로를 탭하여 엽니다. 화면 상단에 워크플로의 상태와 **상태** 패널이 표시됩니다.
이 패널에는 현재 또는 마지막 실행의 **시작됨** 및 **종료됨** 시각, **소요 시간**,
최신 **메시지**가 나옵니다. 워크플로에 오류가 있으면 오류 메시지가 빨간색으로 표시됩니다.
워크플로가 실행 중이거나 대기 중인 동안에는 화면이 상태를 자동으로 최신 상태로 유지합니다.

하단의 컨트롤은 워크플로의 상태에 따라 달라집니다.

| 워크플로 상태 | 컨트롤 |
| --- | --- |
| 실행 중 또는 대기 중 | **일시 중지**, **중지** |
| 그 외 | **실행**, **재개** |

- **실행**은 워크플로를 처음부터 시작합니다.
- **일시 중지**는 실행 중인 워크플로를 멈추고, **재개**는 멈춘 지점부터 계속합니다.
  **재개**는 실패한 단계를 수정한 뒤 워크플로를 이어서 실행할 때도 사용합니다.
- **중지**는 실행을 종료합니다.

각 컨트롤은 동작하기 전에 확인을 요청합니다(예: **Run this workflow?** 메시지).
확인 단계에서 실수로 두 번 탭해도 무시되므로 작업은 한 번만 실행됩니다.

컨트롤 아래의 **구성**에는 워크플로의 사용 여부, 잠금 여부, 오류 처리 방식이 표시되고,
**세부 정보**에는 워크플로가 있는 폴더와 마지막으로 업데이트한 사용자가 표시됩니다.

<Aside type="note">
앱은 웹의 PlaidCloud와 동일한 권한을 사용합니다. 워크플로를 실행하거나 변경할 권한이
없으면 앱에 이유와 함께 **작업 실패**가 표시되고 아무것도 변경되지 않습니다.
</Aside>

## 워크플로의 단계 보기

워크플로에서 **단계**를 탭하면 모든 단계가 상태, 유형, 최신 메시지와 함께 표시됩니다.
실행되지 않는 단계에는 **사용 안 함** 배지가 표시되고, 중첩된 워크플로를 실행하는
단계에는 **하위 워크플로** 배지가 표시됩니다.

목록의 구성 방식은 워크플로의 종류에 따라 다릅니다.

- **그래프로 만든 워크플로**는 단계를 실행 순서대로 표시하며, 왼쪽의 선으로 어떤 단계가
  어떤 단계로 이어지는지 보여 줍니다. 나란히 실행되는 단계도 표시됩니다.
- **단계 목록으로 만든 워크플로**는 단계를 순서대로 표시하며, 각 단계가 속한 폴더도
  함께 보여 줍니다.

## 이전 실행 확인

워크플로에서 **실행 기록**을 탭하면 최근 실행이 표시됩니다. 각 실행에는 시작 시각,
종료 상태, 소요 시간, 실행된 단계 수가 나옵니다.

iPhone과 iPad에서는 실행을 탭하면 해당 실행에서 발생한 단계 오류와 로그의 마지막 200줄을
시간, 수준, 단계와 함께 볼 수 있습니다.

## 이름, 설명, 설정 편집

컴퓨터로 돌아가지 않고도 간단한 변경을 할 수 있습니다.

- 프로젝트나 워크플로에서는 화면 상단의 **편집**을 탭합니다.
- 단계에서는 **단계** 목록에서 해당 단계를 탭합니다.

**편집** 시트에서 **이름**과 **설명**을 변경하고 **사용**과 **Locked**를 켜거나 끌 수 있습니다.
변경 사항을 적용하려면 **저장**을, 취소하려면 **취소**를 탭합니다. 단계 설정 변경, 단계 추가,
워크플로 재배치와 같은 그 밖의 작업은 웹의 PlaidCloud에서 수행합니다.

## 워크스페이스 전환 또는 로그아웃

**설정** 탭을 엽니다. **현재 작업 영역**에는 현재 로그인한 워크스페이스가 표시됩니다.

- **Switch workspace**는 현재 워크스페이스에서 로그아웃한 뒤 **워크스페이스** 화면으로
  돌아가 다른 워크스페이스에 로그인할 수 있게 합니다.
- **로그아웃**은 워크스페이스에서 로그아웃합니다.

두 작업 모두 먼저 확인을 요청합니다.

<Aside type="note">
현재 Android 릴리스에는 **프로젝트** 탭과 **설정** 탭이 있습니다. **홈** 탭과 오류 및
로그 줄이 포함된 실행 상세 정보는 iPhone 및 iPad 앱에서 제공됩니다.
</Aside>
