**통화**는 금액 값을 위해 만들어진 열 데이터 유형입니다. 모든 데이터 유형 목록에서 Numeric, Integer, Text 같은 익숙한 유형과 함께 나타나며, 금액을 정확한 고정 소수점 십진수(정밀도 18자리, 소수 4자리)로 저장합니다. 약 ±100조까지 표현할 수 있고 단위의 1/10,000까지 정확하며 부동 소수점 반올림 오차가 없습니다.

이점은 속도입니다. 통화 열은 Numeric 열의 절반에 해당하는 메모리 폭을 차지하므로, 금액으로 가득한 테이블을 스캔하는 대시보드와 워크플로 단계는 읽는 데이터가 약 절반으로 줄어 더 빨리 완료됩니다. Numeric은 고정밀도 기본값(정밀도 38자리, 소수 10자리)으로 유지되며, 통화는 값이 금액인 곳에 선택적으로 적용하는 더 가벼운 유형입니다.

<Aside>
통화는 현재 플랫폼 릴리스와 함께 출시됩니다. 워크스페이스에 업데이트가 적용되면 데이터 유형 목록에 이 옵션이 나타납니다.
</Aside>


## 통화를 사용해야 하는 경우

비용, 매출, 가격, 마진, 지출, 배부 금액 등 금액을 담는 열에는 통화를 선택하십시오. 이러한 열은 수익성 및 재무 모델에서 큰 비중을 차지하므로, 열의 유형을 다시 지정하는 것이 스캔이 많은 대시보드와 워크플로에서 단일 최대 성능 향상이 되는 경우가 많습니다.

다음과 같은 경우에는 Numeric을 유지하십시오.

* 값이 약 ±100조를 초과할 수 있거나 소수 4자리보다 많은 자릿수가 필요한 경우(환율, 단가, 백분율, 배부 계수 등)
* 열에 금액과 다른 측정값이 섞여 있거나 어떤 값이 담길지 확실하지 않은 경우

<Aside type="note" title="참고">
모든 통화 값은 정밀도 18자리와 소수 4자리에 맞아야 하며, 소수 4자리 기준으로 약 ±100조입니다. 열에 이보다 큰 범위나 더 높은 정밀도가 필요하면 Numeric을 사용하십시오.
</Aside>


## 설정 위치

통화는 열의 데이터 유형을 선택하는 모든 곳에서 사용할 수 있습니다.

### 워크플로 단계의 열 매핑

모든 단계의 출력 열 매핑, 즉 데이터 매퍼 그리드에서 열의 데이터 유형 드롭다운에서 Numeric 또는 Text를 선택할 때와 같은 방법으로 **통화**를 선택합니다. 다음 실행부터 단계가 해당 열을 통화로 기록합니다.

### 테이블의 열 속성

테이블의 **열 속성**을 열고 **데이터 유형** 컨트롤을 사용하여 열을 **Numeric**과 **통화** 사이에서 전환합니다. 변경 사항은 테이블이 다음에 다시 빌드될 때, 예를 들어 테이블을 생성하는 워크플로 단계가 다음에 실행될 때 적용됩니다.

### AI 어시스턴트 또는 MCP 도구 사용

[MCP](/ko/integrations/ai-coding-agents/getting-started/)로 연결된 에이전트도 유형을 설정할 수 있습니다. 열을 만들거나, 테이블을 정의하거나, 단계를 구성하는 등 열 유형을 지정하는 모든 곳에서 데이터 유형 값은 `currency`입니다. 어시스턴트에게 *"금액 열을 통화로 만들어 줘"*라고 요청하는 것이 열이 많은 테이블의 유형을 다시 지정하는 가장 빠른 방법인 경우가 많습니다.


## 통화의 동작 방식

몇 가지 규칙 덕분에 통화는 플랫폼 전반에서 예측 가능하게 동작합니다.

* **통화는 항상 사용자가 명시적으로 선택합니다.** 가져오기, 유형 자동 감지, SQL 결과, 파생 열(합계, 식, 배부 출력)은 항상 기본적으로 Numeric이 됩니다. 결과를 통화로 만들려면 해당 출력 열의 유형을 직접 다시 지정하십시오.
* **한 번 설정하면 기억됩니다.** 통화로 선언한 열은 읽기, 다운스트림 단계, 테이블 다시 빌드 후에도 통화로 유지됩니다. 다운스트림 단계가 테이블에서 열 매핑을 채우면 통화 유형이 단계 구성으로 자동으로 이어집니다.
* **집계는 Numeric을 반환합니다.** 통화 열의 SUM 또는 다른 집계는 Numeric 결과를 생성합니다. 집계 결과도 통화로 저장하려면 출력 열을 다시 통화로 설정하십시오.
* **빈 셀은 0으로 가져옵니다.** 파일 가져오기에서 통화 열의 빈 셀은 Numeric과 똑같이 0으로 로드됩니다.

<Aside type="caution" title="주의">
원시 SQL을 작성하는 단계에서 **채우기** 버튼은 쿼리 결과로부터 출력 열을 추론하며, 쿼리 결과는 항상 Numeric으로 반환됩니다. 채우기를 실행한 후 금액 열을 통화로 설정하고, 다시 실행하면 다시 설정해야 한다는 점에 유의하십시오.
</Aside>
