## 게시

PlaidCloud 프로젝트 구성의 `Tables` 탭에서 대시보드와 PlaidXL에서 사용하도록 게시할 테이블을 찾습니다. 테이블 레코드를 
마우스 오른쪽 버튼으로 클릭하고 메뉴에서 `Set Published Table Reporting Name`을 선택합니다.

그러면 고유한 게시 이름을 지정할 수 있는 대화 상자가 열립니다. 이 이름은 테이블 또는 뷰 이름과 같을 필요가 없습니다. 이름을 다르게 지정할 수 있으면 
대시보드와 PlaidXL에서 데이터 소스를 참조할 때 사용자에게 더 친숙한 이름을 제공할 수 있어 유용한 경우가 많습니다.

테이블 또는 뷰를 게시하면 게시된 이름이 `Tables` 뷰의 `Published As` 열에 표시됩니다.

테이블을 선택하면 **테이블 세부 정보** 패널의 **테이블 ID** 아래에 있는 읽기 전용 **게시 이름** 필드에도 이름이 표시됩니다. 게시되지 않은 테이블에서는 이 필드에 "게시되지 않음"이 표시됩니다. 필드 옆의 복사 버튼을 사용하면 이름을 복사할 수 있으며, 이름이 너무 길어 다 표시되지 않을 때는 필드 위에 마우스를 올려 전체 이름을 볼 수 있습니다.

<Aside>게시된 이름에는 몇 가지 제한이 있습니다. 최대 63자까지 가능하며 특수 문자에도 일부 제한이 있습니다. 이는 PlaidCloud 외부의 시스템, 도구, 프로세스와의 호환성을 최대한 보장하기 위한 것입니다.</Aside>

<Aside type="caution">
**행 액세스.** [행 액세스](/ko/administration/access/managing-security-groups-and-assignments/#행-액세스-관리)로 제한된 열이 있는 테이블을 게시하면 같은 단계에서 해당 테이블의 대시보드 필터도 설정됩니다. 대시보드는 게시된 보고 뷰를 통해 테이블을 읽으므로, PlaidCloud는 게시가 완료되기 전에 각 그룹의 필터를 등록합니다. 등록할 수 없으면 사유와 함께 게시가 거부되고 해당 시도에서 만들어진 모든 항목이 롤백됩니다. 제한된 테이블이 필터 없이 대시보드에 남는 일은 없습니다. 행을 제한하는 프로젝트에서는 *뷰*를 게시할 수 없습니다. 뷰의 쿼리가 제한된 열의 이름을 바꾸거나 그 열에서 값을 파생할 수 있기 때문입니다. 대신 뷰가 읽는 테이블을 게시하십시오. [열 이름 하나, 모든 테이블](/ko/administration/access/managing-security-groups-and-assignments/#하나의-열-이름-모든-테이블)을 참조하십시오.
</Aside>

## 게시된 테이블 성능 검토

게시된 테이블 성능은 PlaidCloud 테이블 성능 오토파일럿의 1단계입니다. 사용자가 게시된 테이블을 어떻게 사용하는지 모니터링하여 권장 사항을 제공하며, 아직은 테이블을 자동으로 변경하지 않습니다. **Table Optimizer**를 열고 게시된 테이블을 선택한 다음 **게시된 테이블 성능**을 선택하면 검토 내용을 볼 수 있습니다.

검토에서는 반복되는 직접 쿼리와 대시보드 사용을 포함하여 PlaidCloud가 안내를 제공할 만큼 현재 활동이 충분한지 보여 줍니다. 유용한 패턴이 있으면 향후 레이아웃 개선에서 고려할 열을 알려 줍니다. 변경이 필요하지 않은 경우나 결론을 내리기 전에 더 많은 최신 활동이 필요한 경우도 분명하게 알려 줍니다.

이 1단계 릴리스는 수동적입니다. 안내만 제공합니다. 개선이 가치 있다고 판단되면 일반 변경 프로세스를 통해 계획하고 적용하십시오. 향후 2단계 릴리스에서는 이 근거와 동일한 안전 검사를 사용하여 지원되는 최적화를 자동으로 적용할 계획입니다.

안내는 데이터 플랫폼과 해당 게시된 테이블에서 확인할 수 있는 현재 활동에 따라 달라집니다. PlaidCloud가 안전하게 평가할 수 없는 경우, 검토에서는 제안을 확실한 것처럼 제시하는 대신 그 한계를 설명합니다.

## 게시 취소

테이블 또는 뷰의 게시를 취소하는 과정은 게시 과정과 비슷합니다. PlaidCloud 프로젝트 구성의 `Tables` 탭에서 대시보드와 PlaidXL에서 사용하도록 게시했던 테이블을 
찾습니다. 테이블 레코드를 마우스 오른쪽 버튼으로 클릭하고 메뉴에서 `Set Published Table Reporting Name`을 선택합니다.

게시 이름을 설정하는 대화 상자가 나타나면 `Unpublish` 버튼을 선택합니다. 그러면 대시보드와 PlaidXL에서 해당 테이블을 사용할 수 없게 됩니다.

게시된 이름은 더 이상 `Published As` 열에 표시되지 않습니다.


## 이름 바꾸기

테이블 또는 뷰의 이름을 바꾸는 과정은 게시 과정과 비슷합니다. PlaidCloud 프로젝트 구성의 `Tables` 탭에서 대시보드와 PlaidXL에서 사용하도록 게시했던 테이블을 
찾습니다. 테이블 레코드를 마우스 오른쪽 버튼으로 클릭하고 메뉴에서 `Set Published Table Reporting Name`을 선택합니다.

대화 상자가 나타나면 게시 이름을 원하는 새 이름으로 변경합니다. `Publish` 버튼을 눌러 이름을 업데이트합니다.

업데이트된 이름이 `Published As` 열과 대시보드 및 PlaidXL에 표시됩니다.
