Analyze의 **Lakehouse** 창에는 Lakehouse에서 실행 중인 항목과 Lakehouse의 설정 방식이 표시됩니다. 창의 왼쪽을 따라 있는 레일에 창의 페이지가 나열됩니다.

| 페이지 | 표시 내용 |
|---|---|
| **쿼리** | 지금 실행 중인 항목과 최근에 실행된 항목. |
| **프로필** | 쿼리의 계획과 비용. |
| **로드** | Lakehouse가 얼마나 사용 중인지. |
| **카탈로그** | Lakehouse 카탈로그의 네임스페이스와 테이블, 그리고 각 테이블의 세부 정보. |

**Administration** 아래의 레일에는 **Lakehouse catalogs**, **Database users**, **Compute**가 나열됩니다. **Database users**와 **Compute**는 Lakehouse 관리자 역할 또는 Lakehouse 클러스터 역할이 있는 멤버에게만 표시되므로, 해당 역할이 없으면 이 페이지가 나열되지 않습니다.

## 쿼리

**Running now**에는 Lakehouse에서 실행 중인 쿼리가 나열됩니다. **새로 고침 주기**는 창이 열려 있는 동안 목록을 다시 읽는 간격을 설정합니다. 실행 중인 쿼리를 선택하고 **Stop query**를 클릭하면 쿼리가 종료됩니다.

**기록**에는 최근 쿼리가 최신 항목부터 나열됩니다. **Search SQL**, **Any user**, **Any kind**, **Any duration**으로 목록 범위를 좁힐 수 있습니다. 쿼리의 문을 복사하려면 **Copy SQL**을 클릭하십시오.

쿼리가 어떻게 실행되었는지 보려면 쿼리를 두 번 클릭하거나, 쿼리를 선택하고 **Profile this query**를 선택하십시오. 창에서 해당 쿼리의 계획에 대한 **프로필**이 열립니다.

## 카탈로그

**카탈로그**의 헤더에는 Lakehouse 카탈로그를 고르는 선택기가 있습니다. 네임스페이스를 선택하여 해당 테이블을 나열한 다음, 테이블을 선택하여 세부 정보를 엽니다.

- 각 열의 유형과 필수 여부가 포함된 **열**.
- 현재 스냅샷의 행, 크기, 데이터 파일.
- **파티셔닝**, **위치**, **속성**.
- **기록**: 스냅샷마다 한 행씩 표시되며 시간, 작업, **추가된 행**과 **제거된 행**이 포함됩니다.

테이블의 메타데이터에 없는 수치는 —로 표시됩니다.

### 타임 트래블 쿼리 복사

**기록**의 스냅샷에서 **Copy query as of this snapshot**을 클릭하십시오. `FOR VERSION AS OF`를 사용하여 해당 스냅샷 시점의 테이블을 읽는 쿼리가 복사되며, 이 쿼리를 쿼리 화면에 붙여 넣을 수 있습니다. 복사는 기본 Lakehouse 카탈로그에서만 제공됩니다. 대신 테이블 탐색기에서 테이블의 스냅샷을 찾아보거나 되돌리려면 [테이블 스냅샷](/ko/guides/data/table-snapshots/)을 참조하십시오.

## Lakehouse 카탈로그, 데이터베이스 사용자 및 컴퓨트

**Lakehouse catalogs**에는 워크스페이스에 등록된 카탈로그가 나열됩니다. 카탈로그에서 **찾아보기**를 클릭하면 **카탈로그**에서 해당 카탈로그가 열립니다.

**Database users**에는 Lakehouse에 연결할 수 있는 데이터베이스 사용자가 나열되며, 사용자를 추가, 변경, 제거할 수 있습니다. **Compute**에는 Lakehouse 컴퓨트 노드의 상태가 표시되며, 쿼리가 멈췄을 때 사용하는 순차 재시작인 **컴퓨트 재시작**이 제공됩니다. 컴퓨트 노드를 한 번에 하나씩 교체하므로, 교체 중인 노드에서 실행 중인 쿼리는 실패하지만 다른 노드는 계속 새 쿼리를 처리합니다. 재시작 사이에는 대기 시간이 적용됩니다.
