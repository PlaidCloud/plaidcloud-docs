PlaidCloud의 차원은 **계층**, 즉 비용 센터, 제품, 계정, 지역, 기간 등을 정리하는 트리 구조입니다. 배부, 대시보드, 보고서가 데이터를 분할하고 집계할 때 기반이 되는 뼈대입니다.

차원은 상위-하위 관계 외에도 더 많은 정보를 담을 수 있습니다. 각 노드는 속성, 별칭, 값을 가질 수 있으므로 비용 센터 계층은 각 센터가 어떤 통화로 보고하는지, 대체 보기에서 어느 사업 부문으로 롤업되는지, 운영 예산이 얼마인지도 알려 줄 수 있습니다.

차원은 각 프로젝트의 **차원** 탭에서 관리합니다.

## 기본 계층

모든 차원에는 **기본** 계층이 있습니다. 기본 계층은 리프 멤버의 전체 집합을 정의하며, 차원 안의 모든 리프 노드는 반드시 여기에 나타나야 합니다.

기본 계층은 단일 진실의 표준 트리라고 생각하면 됩니다. 차원 안의 모든 것은 기본 계층의 멤버이며, 문제는 트리의 *어디에* 위치하느냐뿐입니다.

## 대체(특성) 계층

대체 계층은 기본 계층에 있는 리프를 다른 방식으로 보는 보기입니다. 리프의 일부만 선택하거나, 다르게 그룹화하거나, 완전히 다른 롤업을 사용할 수 있습니다.

일반적인 패턴은 두 가지입니다.

- **부분 집합 보기** — 특정 보고서나 배부를 위해 특정 리프 집합을 집중된 트리로 가져옵니다. 대체 계층은 멤버에 대한 변경 사항을 기본 계층에서 상속합니다.
- **다른 롤업** — 같은 리프에 다른 상위 노드를 사용합니다. 예를 들어 기본 계층은 비용 센터를 부서별로 정리하고, 대체 계층은 같은 비용 센터를 지역별로 정리합니다.

## 차원 관리

<Aside type="caution">
**어떤 사용자가 어떤 행을 볼 수 있는지 결정하는 차원은 프로젝트 아키텍트만 변경할 수 있습니다.** [행 액세스](/ko/administration/access/managing-security-groups-and-assignments/#차원-부여)로 행을 제한하는 프로젝트에서, 제한된 열이 값을 가져오는 차원은 프로젝트 아키텍트, 테넌트 관리자 또는 프로젝트 자체의 워크플로만 변경할 수 있습니다. 여기에는 노드의 추가, 이동, 이름 바꾸기, 복사, 지우기, 로드, 복원과 차원 자체의 생성, 복사, 이름 바꾸기, 삭제가 포함됩니다. 다른 사용자에게는 누구에게 요청해야 하는지 안내가 표시됩니다. 그 밖의 차원과, 행을 제한하지 않는 프로젝트의 모든 차원은 아래에 설명된 대로 작동합니다.
</Aside>

### 만들기

도구 모음의 **새로 만들기** 버튼에서 **새 차원**을 선택합니다. 이름, 디렉터리(폴더 방식 정리용), 설명 메모를 입력합니다.

**만들기**를 클릭하면 차원을 바로 사용할 수 있습니다. 워크플로에서 [Dimension Create](/ko/reference/workflow-steps/dimensions/dimension-create/) 단계로 만들 수도 있습니다.

### 배부 차원 만들기

**배부 차원**(**할당 차원**이라고도 함)은 [배부](/ko/guides/allocations/setup/configure-an-allocation/) 단계가 각 소스 레코드를 대상에 어떻게 분산할지 결정하기 위해 읽는 특수한 차원입니다. 노드를 하나씩 만드는 대신, 가이드 빌더를 사용하면 시작용 차원을 한 번에 만들 수 있습니다.

워크스페이스에서 이 기능을 사용할 수 있고 차원을 만들 권한이 있는 경우, **새로 만들기** 메뉴를 열고 **새 배부 차원**(분할 아이콘으로 표시됨)을 선택합니다. 빌더는 네 단계 중 첫 번째 단계에서 열립니다.

1. **이름 및 테이블** — 차원 이름을 지정한 다음, 규칙이 행을 필터링하는 **소스(값) 테이블**과 금액을 분산할 기준이 되는 **드라이버 테이블**을 선택합니다.
2. **규칙 필터** — 규칙 필터로 작동하는 소스 열을 선택합니다. 이미 차원 관계가 있는 열은 그대로 적용됩니다. 그렇지 않은 열은 값이 멤버로 확인되도록 차원을 연결할 수 있습니다.
3. **드라이버 및 대상** — 드라이버 테이블에서 **드라이버 이름** 열과 **드라이버 값** 열을 지정하고, 금액을 분산할 **대상 열**을 선택합니다.
4. **규칙** — 규칙의 평면 그리드를 채웁니다. 각 규칙은 소스 필터 값 집합과 해당 조합에 사용할 명명된 드라이버로 구성됩니다.

**마침**을 클릭하면 PlaidCloud가 전체 차원을 한 번에 만듭니다. 이 차원은 일반 계층이 아닌 배부 차원임을 나타내는 **분할 아이콘**이 붙은 채 차원 트리에 나타납니다.

이 차원은 어떤 배부와도 독립적으로 작성되므로, 하나의 배부 차원을 여러 단계에서 사용할 수 있습니다. 사용하려면 배부 단계가 이 차원을 가리키도록 설정합니다. 자세한 내용은 [배부 구성](/ko/guides/allocations/setup/configure-an-allocation/)을 참조하십시오.

### 삭제

차원을 선택하고 **작업** 메뉴를 열어 **차원 삭제**를 선택합니다. 그러면 차원과 모든 기반 데이터가 제거됩니다.

워크플로에서 [Dimension Delete](/ko/reference/workflow-steps/dimensions/dimension-delete/) 단계로 삭제할 수도 있습니다.

차원은 유지하면서 내용(모든 구조, 값, 별칭, 속성, 대체 계층)을 초기화하려면 삭제 대신 [Dimension Clear](/ko/reference/workflow-steps/dimensions/dimension-clear/) 단계를 사용하십시오.

### 복사

차원을 선택하고 **작업**을 열어 **차원 복사**를 선택합니다. 복사본의 이름을 지정하고 **복사본 만들기**를 클릭합니다. 복사본에는 값, 별칭, 속성, 모든 대체 계층이 포함됩니다.

### 정렬

차원 관리 영역에서는 멤버를 위아래로 이동하고 상위 노드를 직접 변경할 수 있습니다. 큰 계층에서는 이를 수작업으로 하기 번거로우므로 [Dimension Sort](/ko/reference/workflow-steps/dimensions/dimension-sort/) 워크플로 단계를 사용해 프로그래밍 방식으로 정렬하십시오. 데이터를 로드하거나 대규모 구조 개편을 한 뒤에 시간을 크게 절약할 수 있습니다.

## 차원 로드

차원을 로드한다는 것은 표 형식의 소스 데이터를 계층 구조로 변환하는 것을 의미합니다. PlaidCloud는 로드에 두 가지 데이터 형태를 지원합니다.

- **상위-하위** — 상위용 열 하나와 하위용 열 하나, 이렇게 두 개의 열을 사용합니다. 각 행이 트리의 간선 하나를 정의합니다. 깊이가 임의적이고 불규칙한 계층에도 사용할 수 있습니다.
- **레벨** — 레벨마다 열 하나를 사용합니다. 행마다 각 열이 해당 레벨의 상위 노드를 알려 줍니다. 깊이를 예측할 수 있는 규칙적인 계층(예: 국가 → 지역 → 도시)에 가장 적합합니다.

로드할 때 구조와 함께 값, 별칭, 속성도 포함할 수 있습니다. 전체 옵션은 [Dimension Load](/ko/reference/workflow-steps/dimensions/dimension-load/) 워크플로 단계를 참조하십시오.

## 노드 속성

계층 도구 모음에서 **속성**을 켜면 차원에 정의된 각 속성(비용 센터의 통화, 계정의 사업 부문, 제품의 범주 등)을 보여 주는 열이 표시됩니다.

### 속성 추가 또는 편집

1. 도구 모음에서 **새 속성**을 클릭합니다
2. **속성 구성** 창에서 **속성 이름**을 입력하고, **속성 표시**(**텍스트** 또는 **태그**)를 선택하고, **편집기 유형**을 고릅니다. 편집기 유형은 속성의 데이터 입력에 사용하는 컨트롤이며 **선택(차원)**, **선택(고정)**, **선택(테이블)**, **확인란**, **스피너**, **날짜 선택기**, **Numeric**을 포함합니다
3. 편집기 유형에 추가 설정이 필요하면 **구성** 섹션이 나타나고 **구성 편집** 버튼이 표시됩니다
4. **만들기**(편집 중에는 **업데이트**)를 클릭하여 저장합니다

기존 속성의 설정을 변경하려면 해당 열을 선택하고 도구 모음에서 **속성 구성 편집**을 선택합니다. **속성 삭제**는 속성 전체를 제거하고, **속성 지우기**는 선택한 항목을 지우며, **속성의 모든 항목 지우기**는 모든 노드에서 해당 속성을 지웁니다.

### 차원 유형 속성과 멤버 선택기

속성의 **편집기 유형**을 **선택(차원)** 옵션으로 설정하면 다른 차원(또는 같은 차원)의 계층을 조회하는 속성이 됩니다. 예를 들어 비용 센터의 "지역" 속성이 지리 차원을 가리키도록 할 수 있습니다. **구성 편집**을 클릭하면 **차원 구성** 창이 열립니다.

- **차원** 및 **계층** — 속성이 멤버를 선택해 오는 차원과 계층입니다. 계층에서 **지정되지 않음**을 선택하면 선택기에 차원의 모든 계층이 표시됩니다.
- **시작 노드(선택 사항)** — 선택기를 전체 계층 대신 하위 트리로 제한합니다.
- **여러 항목 선택 허용** — 하나의 속성 값이 둘 이상의 멤버를 담을 수 있게 합니다. 기본적으로 켜져 있으며, 선택을 해제하면 속성을 단일 멤버로 제한합니다.
- **특수 사례** — 계층의 실제 멤버 외에 선택할 수 있는 추가 항목으로 **소스**와 **현재**를 제공합니다.

**저장**을 하려면 차원을 선택해야 합니다. 계층은 **지정되지 않음**으로 둘 수 있으며, 이는 빈 값이 아니라 하나의 선택입니다.

속성을 이렇게 구성한 후에는 그리드에서 해당 셀을 더블 클릭하여 멤버 선택기를 엽니다. 같은 트리 형태의 선택기는 [데이터 편집기](/ko/guides/projects/managing-data-editors/) 그리드에서 차원에 매핑된 열에도 나타납니다. 셀에 이미 값이 있든 없든 첫 번째 더블 클릭에서 열립니다.

- **모두 펼치기** / **모두 접기** — 트리의 모든 분기를 열거나 닫습니다.
- 멤버를 클릭하여(여러 항목 선택 허용이 켜져 있으면 여러 멤버를) 선택합니다.
- **적용**은 속성을 현재 선택 항목으로 설정합니다.
- **지우기**는 속성의 현재 값을 제거합니다.
- **취소**는 아무것도 변경하지 않고 선택기를 닫습니다.

<Aside type="note">선택기를 열 때 그리드에서 여러 행이 선택되어 있으면, **적용**은 더블 클릭한 행만이 아니라 선택한 모든 행에 값을 설정합니다. 이는 여러 행을 한 번에 편집할 수 있도록 의도된 동작입니다.</Aside>

## 차원 속성 상속

차원은 하위 노드가 상위 노드로부터 속성 값을 상속하도록 구성할 수 있습니다. 이를 켜려면 **속성** 옆의 드롭다운을 클릭하고 **상속된 속성**을 선택합니다.

상속 동작에 관한 참고 사항은 다음과 같습니다.

- 상속은 차원의 **모든** 속성에 적용됩니다. 하나의 속성에만 켜고 다른 속성에는 켜지 않을 수 없습니다.
- 하위 노드에 속성을 설정한 뒤 나중에 그 값을 삭제하면 하위 노드는 상위 노드의 값으로 되돌아갑니다. 상위 노드에 값이 있으면 하위 노드의 속성은 null일 수 없습니다.
- 노드에 속성을 설정하면 하위 노드로 전파되어, 명시적으로 설정되기 전까지 상속된 값을 덮어씁니다.
- 상속은 트리를 따라 리프 노드까지 내려갑니다.

## 계층에서 노드 찾기

큰 차원은 수천 개의 멤버로 구성될 수 있으므로, 계층 창에는 그리드에 표시되는 내용을 좁히는 두 가지 방법이 있습니다. 두 방법 모두 일치하지 않는 노드를 강조 표시하는 데 그치지 않고 숨기며, 일치하는 노드의 상위 노드를 화면에 유지하므로 트리에서 해당 노드의 위치를 계속 확인할 수 있습니다.

### 필터 상자

창 아래쪽의 **필터:** 상자는 입력하는 동안 필터링합니다. 대/소문자를 구분하지 않고 텍스트의 일부와 일치하며 다음을 검색합니다.

- 계층에서 노드의 이름
- 현재 표시 중인 모든 **대체 항목**, **별칭**, **속성**, **값** 열

화면에 있는 열만 검색하므로 도구 모음 토글이 검색 범위 역할도 합니다. **속성**을 켜면 속성에 저장된 계정 코드로 노드를 찾을 수 있고, 다시 끄면 이름만 검색합니다. 태그로 표시되는 속성은 개별 태그 하나와도 일치합니다.

상자 옆의 버튼은 필터를 적용할 창을 선택합니다. **둘 다**, **기본 계층**, **대체 계층** 중에서 고를 수 있습니다. 깔때기 버튼은 필터를 지우고 전체 트리를 복원합니다.

<Aside type="note">필터 상자는 각 노드에 저장된 값을 검색합니다. **상속된 속성**을 켠 경우, 상위 노드로부터 상속받은 값을 표시하는 노드는 그 값으로 일치하지 않으며, 값이 실제로 설정된 상위 노드만 일치합니다.</Aside>

### 고급 필터

필터 상자가 표시 중인 모든 열을 한 번에 검색하는 반면, 계층 도구 모음의 **고급**은 열별로 정밀한 조건을 만듭니다. **고급 차원 필터 구성** 창이 열리며, 각 행이 하나의 조건입니다.

1. **행 추가**를 클릭합니다
2. **열**을 선택합니다. 차원의 모든 속성 또는 집계 열을 선택할 수 있습니다
3. **조건**을 선택합니다. 속성은 텍스트를 담으므로 `=`, `!=`, `contains`를 제공하고, 집계는 숫자를 담으므로 `=`, `!=`, `<`, `>`, `<=`, `>=`를 제공합니다
4. 비교할 **값**을 입력하거나, **비교 대상**에서 다른 열을 선택하여 두 열을 서로 비교합니다. 둘 중 하나만 사용할 수 있고 둘 다 사용할 수는 없습니다. 숫자와 텍스트를 비교하면 어느 쪽이든 의미가 없으므로, **비교 대상**에는 같은 종류의 값을 담은 다른 열만 나열됩니다
5. **업데이트**를 클릭하여 적용합니다

**행 삭제**는 선택한 행을 제거하고 **지우기**는 목록 전체를 비웁니다. 행을 여러 개 추가하여 더 좁힐 수 있으며, 노드는 모든 행과 필터 상자의 텍스트까지 충족해야 합니다. **업데이트**는 모든 행이 완성될 때까지 비활성 상태로 유지되므로, 완성되지 않은 조건이 표시 내용을 조용히 바꾸는 일은 없습니다.

고급 조건은 기본 계층에 적용됩니다. 필터 상자는 여전히 옆의 버튼으로 선택한 창에 적용됩니다.

텍스트 조건은 필터 상자와 마찬가지로 대/소문자를 구분하지 않습니다. `=`는 값 전체와 일치하므로, 더 긴 속성 값 안이나 여러 태그를 가진 속성의 태그 하나에 들어 있는 코드를 찾으려면 `contains`를 사용하십시오.
