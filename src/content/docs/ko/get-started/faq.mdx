## PlaidCloud란 무엇입니까?

PlaidCloud는 통합 재무 분석 플랫폼입니다. 데이터 소스를 연결하고, 데이터를 변환하고 결합하는 워크플로를 빌드하고, 비즈니스 조직 방식에 맞는 차원과 계층을 정의하고, 비용 배부를 실행하고, 결과를 대시보드나 다운스트림 시스템에 게시하는 모든 작업을 하나의 플랫폼에서 수행할 수 있습니다.

## PlaidCloud는 누가 사용합니까?

주로 중대형 조직의 재무, FP&A, 분석 팀이 다음과 같은 작업에 사용합니다.

- **비용 배부** — 활동 기준 원가 계산, IT 차지백, 공유 서비스 분배, 이전 가격 책정
- **수익성 분석** — 대규모 고객 / 제품 / 채널별 마진
- **재무 연결** — 여러 엔터티와 통화에 걸친 데이터 결합
- **운영 보고** — 깨끗하고 거버넌스가 적용된 지표를 갖춘 엔터프라이즈 데이터 대시보드
- **데이터 웨어하우징** — 운영 시스템 위에 통합 분석 계층 구축

### 특별한 기술 배경이 필요합니까?

대부분의 PlaidCloud 사용자는 Excel과 SQL 기초에 익숙한 비즈니스 분석가입니다. 개발자일 필요는 없습니다. 이 플랫폼은 워크플로와 데이터 작업을 시각적 인터페이스로 제공하며, 필요할 때는 SQL 식을 사용할 수 있습니다.

## 요금제 및 가격

### 어떤 요금제를 사용할 수 있습니까?

PlaidCloud는 셀프 서비스 체험 워크스페이스, Team 요금제, 엔터프라이즈 요금제를 제공합니다. 요금제 한도, 가격, 기능 제공 여부는 티어마다 다릅니다.

현재 가격과 요금제 세부 정보는 [plaidcloud.com](https://plaidcloud.com/)을 참조하거나 계정 팀에 문의하십시오.

### 가입하려면 신용카드가 필요합니까?

아니요. **Free** 요금제는 이메일 확인만 필요합니다. 신용카드도 결제 단계도 없으며, 이메일을 확인하면 워크스페이스가 만들어집니다. (유료 **Starter** 및 **Team** 요금제는 선택 사항인 7일 체험을 제공하며, 자동으로 전환될 수 있도록 카드를 수집합니다. **Free**는 영구적이며 카드를 요구하지 않습니다.)

### Free 요금제에 제한이 있습니까?

**Free** 요금제는 영구적(기간 제한 없음)이며 플랫폼을 평가하기에 적합한 사용량 제한이 있습니다. 별도의 7일 **Starter/Team 체험**은 해당 티어의 모든 기능을 일주일 동안 사용할 수 있습니다. 구체적인 내용은 가입 중에 표시됩니다.

### 나중에 요금제를 변경할 수 있습니까?

예. 데이터를 잃거나 통합이 중단되지 않으면서 워크스페이스를 업그레이드할 수 있습니다. 상황에 맞는 방법은 계정 팀에 문의하십시오.

## 기능 및 한도

### 데이터는 얼마나 커질 수 있습니까?

PlaidCloud의 기반 Lakehouse 엔진은 수백 행의 작은 참조 테이블부터 수십억 행의 분석 데이터 세트까지 처리합니다. 매우 큰 워크로드는 계정 팀에 규모 산정을 문의하십시오. 컴퓨팅 리소스는 구성할 수 있습니다.

### PlaidCloud가 데이터 웨어하우스를 대체합니까?

대체할 수 있습니다. PlaidCloud Lakehouse는 주 데이터 웨어하우스로 사용할 수 있는 완전한 분석 저장소이며, 기존 데이터 웨어하우스(Snowflake, BigQuery, Redshift 등)와 함께 두고 [커넥터](/ko/reference/connectors/)를 통해 데이터를 가져올 수도 있습니다.

### PlaidCloud를 온프레미스에서 실행할 수 있습니까?

PlaidCloud는 SaaS 플랫폼입니다. 온프레미스 데이터 소스에 액세스하려면 [PlaidLink Agent](/ko/reference/cli/plaidlink/)를 네트워크 내부에 설치하여 PlaidCloud를 방화벽으로 보호되는 데이터베이스 및 파일 시스템과 연결합니다.

### PlaidCloud에 API가 있습니까?

예. API는 각 워크스페이스 안에서 테넌트별로 제공되므로, 대화형 API 문서는 이 문서 사이트가 아니라 워크스페이스 안에 있습니다. 프로그래밍 방식 통합에는 [Jupyter CLI](/ko/reference/cli/jupyter/)와 [PlaidLink](/ko/reference/cli/plaidlink/)의 Jupyter / CLI 액세스 패턴이 좋은 출발점입니다.

## 제품 활용

### PlaidCloud에서 Excel을 사용할 수 있습니까?

예. [PlaidXL](/ko/reference/cli/plaidxl/)은 PlaidCloud용 Excel 추가 기능입니다. 프로젝트 테이블과 차원을 워크시트로 가져오고, 필요할 때 새로 고치고, PlaidCloud 데이터에서 집계 값을 계산하는 수식을 추가합니다. 주 모델링 환경이 Excel인 분석가에게 유용합니다. [PlaidXL로 Excel에서 작업하기](/ko/get-started/tutorials/excel-with-plaidxl/)를 따라 하면 약 20분 만에 시작할 수 있습니다.

### Claude Code나 Cursor 같은 AI 도구를 사용할 수 있습니까?

예. PlaidCloud는 워크스페이스마다 MCP(Model Context Protocol) 서버를 제공합니다. 설정 방법은 [AI 코딩 에이전트](/ko/integrations/ai-coding-agents/)를 참조하십시오.

### Jupyter Notebook을 사용할 수 있습니까?

예. [Jupyter CLI](/ko/reference/cli/jupyter/)를 참조하십시오. 인증에는 OAuth 토큰을 사용하므로 CLI, 노트북, REST API에서 동일한 자격 증명이 작동합니다.

### SQL을 직접 사용할 수 있습니까?

예. 워크플로는 열 계산, 필터, 조인에 SQL 식을 사용할 수 있습니다. [식 참조](/ko/reference/expressions/)에서 Lakehouse 엔진 버전별로 나뉜 사용 가능한 모든 SQL 함수를 확인할 수 있습니다.

### 워크플로는 어떻게 예약합니까?

PlaidCloud에는 예약 기능이 기본으로 제공됩니다. [예약된 이벤트](/ko/administration/scheduled-events/)를 참조하십시오.

### 워크플로가 끝났을 때(또는 실패했을 때) 알림을 받으려면 어떻게 합니까?

알림 단계 — [이메일](/ko/reference/workflow-steps/notifications/notify-via-email/), [Slack](/ko/reference/workflow-steps/notifications/notify-via-slack/), [Teams](/ko/reference/workflow-steps/notifications/notify-via-microsoft-teams/), [SMS](/ko/reference/workflow-steps/notifications/notify-via-sms/), [웹 훅](/ko/reference/workflow-steps/notifications/notify-via-web-hook/) 중 하나를 사용하십시오. 실패 시 자동으로 실행되는 복구 워크플로를 구성할 수도 있습니다.

## 보안 및 액세스

### 권한은 어떻게 관리됩니까?

PlaidCloud는 워크스페이스 수준에서 **보안 그룹**을 사용합니다. 멤버를 그룹에 할당하고, 그룹이 특정 기능을 부여합니다. [액세스 관리](/ko/administration/access/)를 참조하십시오.

### Single Sign-On(SSO)을 사용할 수 있습니까?

예. PlaidCloud는 SAML 2.0을 지원합니다. [Okta](/ko/administration/access/advanced/okta-saml-setup/), [Auth0](/ko/administration/access/advanced/auth0-saml-setup/), [Microsoft Entra](/ko/administration/access/advanced/entra-saml-setup/), [Google](/ko/administration/access/advanced/google-saml-setup/), [AWS](/ko/administration/access/advanced/aws-saml-setup/)의 설정 가이드를 참조하십시오.

### 내 데이터는 어디에 저장됩니까?

PlaidCloud 데이터는 테넌트에 구성된 클라우드 리전에 저장됩니다. 데이터 상주 요구 사항이 있으면 계정 팀에 리전별 배포를 문의하십시오.

### 데이터는 어떻게 암호화됩니까?

전송 중과 저장 시 모두 암호화됩니다. 암호화 키는 플랫폼이 관리하며, 규제 산업을 위한 키 관리 옵션은 엔터프라이즈 요금제에서 사용할 수 있습니다.

## 흔히 겪는 문제

### 워크플로 단계에서 “No Rows Returned” 오류가 발생합니다

대개 필터나 조인이 예상과 다르게 일치했다는 뜻입니다. 테이블 탐색기에서 소스 테이블을 열고 다음을 확인하십시오.

- 조인 키 열의 철자가 두 테이블에서 (대소문자를 포함하여) 동일합니까?
- 키 값에 앞뒤 공백이나 숨겨진 문자가 있습니까?
- 필터 조건이 의도한 것보다 더 제한적입니까?

### 배부 결과가 일치하지 않습니다

배부된 금액의 합계는 소스 금액의 합계와 같아야 합니다. 같지 않다면 다음을 확인하십시오.

- **고아 소스 행** — 일치하는 드라이버 데이터가 없는 소스 행은 배부되지 않습니다. 모든 소스 행에 드라이버 값이 있는지 확인하십시오.
- **누락된 대상 멤버** — 드라이버 항목이 없는 차원 멤버는 배부를 받지 못합니다. 차원과 드라이버 테이블이 동기화되어 있는지 확인하십시오.
- **음수 드라이버** — 예기치 않은 동작을 일으킵니다. 필터링하여 제외하거나 명시적으로 처리하십시오.

[배부 문제 해결](/ko/guides/allocations/results/troubleshooting-allocations/)을 참조하십시오.

### 차원 로드로 중복 멤버가 생성되었습니다

대개 소스 데이터의 대소문자나 공백 문제입니다. 차원은 “ACME Corp”와 “Acme Corp”를 서로 다른 멤버로 취급합니다. 로드하기 전에 소스를 정규화하거나, 업스트림에서 변환 단계를 사용하여 정리하십시오.

### 동료가 말한 프로젝트가 보이지 않습니다

프로젝트 가시성은 워크스페이스 보안 그룹이 제어합니다. 워크스페이스 관리자에게 해당 프로젝트에 대한 액세스 권한을 부여하는 그룹에 추가해 달라고 요청하십시오.

## 도움 받기

### 지원팀에 연락하려면 어떻게 해야 합니까?

- 체험 및 셀프 서비스 사용자: [support@plaidcloud.com](mailto:support@plaidcloud.com)으로 이메일을 보내십시오.
- 엔터프라이즈 고객: 전용 지원 채널(보통 Slack 또는 고객 포털)을 이용하십시오. 계정 팀에 문의하십시오.

### 버그나 기능 요청은 어디에 제출합니까?

지원팀과 같은 채널을 이용하십시오. 문서에 특정된 버그는 모든 문서 페이지 상단의 **Edit Page** 링크로도 신고할 수 있습니다.

### 사용자 커뮤니티가 있습니까?

워크스페이스가 있으면 제품 내 도움말 메뉴에서 PlaidCloud 사용자 포럼과 공유 지식 베이스에 액세스할 수 있습니다. 문서 사이트는 공개용 리소스입니다.
