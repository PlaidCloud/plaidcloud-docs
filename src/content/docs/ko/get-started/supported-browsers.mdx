PlaidCloud는 설치 없이 웹 브라우저에서 실행됩니다. 다음 브라우저 중 하나를 해당 버전 이상으로 사용해야 합니다.

## 최소 버전

| 브라우저 | 최소 버전 |
| --- | --- |
| Google Chrome | 94 |
| Microsoft Edge | 94 |
| Mozilla Firefox | 93 |
| Mac의 Safari | 16.4 |
| iPad 또는 iPhone의 모든 브라우저 | iPadOS 또는 iOS 16.4 |

대부분의 브라우저는 자동으로 업데이트되므로, 최신 상태로 유지되는 브라우저는 이미 이 버전을 훨씬 넘어섰습니다.

## iPad 및 iPhone

iPad나 iPhone의 브라우저 앱은 Chrome과 Firefox를 포함해 모두 Safari 엔진을 기반으로 만들어집니다. 따라서 어떤 브라우저 앱을 사용하는지가 아니라 기기의 iPadOS 또는 iOS 버전이 중요합니다. 업데이트하려면 **설정** > **일반** > **소프트웨어 업데이트**를 엽니다.

<Aside type="caution">
iPad Air 2와 iPad mini 4는 iPadOS 15 이후로 업데이트할 수 없으므로 PlaidCloud를 실행할 수 없습니다. 대신 컴퓨터나 최신 iPad를 사용하십시오.
</Aside>

## 이전 브라우저에서 표시되는 내용

이전 브라우저에서는 PlaidCloud가 로드되지 않습니다. 위의 버전을 안내하는 **PlaidCloud needs a newer browser** 페이지가 표시됩니다. 브라우저를 업데이트하거나, 여기에 나열된 브라우저 중 하나로 PlaidCloud를 여십시오.
