*약 10분 · 내 CSV, 적재된 테이블, 첫 번째 결과*

이 튜토리얼은 빠른 버전입니다. CSV 파일 하나를 준비하면, 끝날 때쯤 그 파일을 가져와 테이블로 적재하고, 변환을 한 번 실행하여 내 데이터에서 실제 결과를 읽어 볼 수 있습니다.

[데이터 로드, 변환, 게시](/ko/get-started/tutorials/load-and-transform-data/)의 빠른 버전이기도 합니다. 해당 튜토리얼은 약 1시간이 걸리며 조인과 게시를 포함한 완전한 다단계 파이프라인을 구축합니다. 먼저 여기서 첫 성과를 확인한 다음, 더 깊이 알고 싶을 때 그쪽으로 넘어가십시오.

## 사전 요구 사항

- PlaidCloud 워크스페이스([워크스페이스가 없다면 무료 체험을 시작](https://app.plaidcloud.com)하십시오).
- 작업할 프로젝트. 아직 없다면 **프로젝트** 탭에서 만드십시오.
- 직접 가져온 CSV 파일 하나. 머리글 행과 숫자 열이 있는 파일이면 무엇이든 됩니다. 매출, 비용, 주문 목록 등이 좋습니다.

## 1단계: 워크플로 만들기

워크플로는 데이터를 가져오고 변환하는 파이프라인입니다.

1. 프로젝트를 열고 **워크플로** 탭으로 전환합니다.
2. 도구 모음에서 **새 워크플로**를 클릭합니다.
3. "CSV Quick Start"와 같은 이름을 지정하고 **워크플로 유형**은 기본값인 **표준 직렬**로 둡니다.
4. **만들기**를 클릭한 다음 새 워크플로를 두 번 클릭하여 [워크플로 탐색기](/ko/guides/workflows/workflow-explorer/)를 엽니다.

## 2단계: CSV 가져오기

1. 새 단계를 추가하고 **Import → CSV** 단계(또는 파일 형식에 맞는 다른 가져오기 단계)를 선택합니다.
2. 단계 구성에서 다음을 설정합니다.
   - **소스 파일** — CSV를 지정합니다. 직접 업로드하거나 연결된 문서 계정에서 선택합니다.
   - **대상 테이블** — 이름을 `my_data`로 지정합니다.
   - **구분 기호, 따옴표 문자, 머리글 행** — 파일이 표준 형식이 아닌 경우에만 조정합니다. 기본값은 머리글 행이 있는 일반적인 쉼표 구분 파일을 처리합니다.
3. 단계를 실행합니다.

이제 CSV가 프로젝트에 [테이블](/ko/guides/data/tables-views/)로 적재되었습니다. 테이블은 물리적인 행과 열 데이터를 담고 있으며, 이후의 모든 작업이 여기에서 데이터를 읽습니다.

> **소스는 절대 변경되지 않습니다.** 각 단계는 소스에서 읽고 대상에 쓰며 원본은 그대로 둡니다. CSV 가져오기는 `my_data`에 썼고, 다음 단계의 변환은 이를 읽어서 새로운 곳에 씁니다.

## 3단계: 적재된 테이블 확인하기

**테이블** 탭으로 전환하여 `my_data`를 클릭합니다. 열 개수, 몇 개의 샘플 행, 데이터 형식이 올바른지 확인하십시오. 숫자 열은 텍스트가 아니라 숫자로 표시되어야 합니다. 형식이 잘못되었다면 가져오기 단계의 열 매퍼로 수정한 뒤 다시 실행할 수 있습니다.

## 4단계: 변환 한 번 실행하기

이제 원시 테이블을 답으로 바꿉니다. 이 예에서는 중요한 행만 필터링하고 필요한 열만 남깁니다. 세부 사항은 내 파일에 맞게 조정하십시오.

1. **테이블 → Table Lookup** 단계(또는 행을 필터링하고 열을 선택할 수 있는 다른 테이블 변환)를 추가합니다.
2. 다음과 같이 구성합니다.
   - **소스 테이블** — `my_data`
   - **대상 테이블** — `my_result`
   - **필터 조건** — 행을 줄이는 조건. 예: `amount > 0`
   - **유지할 열** — 읽고 싶은 열의 부분 집합과 `revenue = quantity * price`와 같은 계산 열
3. 단계를 실행합니다.

계산 열에 사용할 수 있는 전체 함수(문자열 연산, 날짜 계산, 조건 논리)는 [식 참조](/ko/reference/expressions/)를 확인하십시오.

> **이렇게 보여야 합니다.** 단계가 실행된 후 `my_result`에는 `my_data`보다 적은 수의 행이 있어야 하며(필터가 행을 줄였기 때문입니다), 계산 열(예: `revenue`)이 남아 있는 모든 행에 채워져 있어야 합니다. 행 수가 줄지 않았거나 계산 열이 비어 있다면 다음으로 넘어가기 전에 필터 조건과 식을 다시 확인하십시오.

## 5단계: 결과 확인하기

**테이블** 탭을 열고 `my_result`를 클릭합니다. `my_data`보다 적은 행, 남겨 둔 열만, 그리고 채워진 계산 열이 보입니다. 이것이 내 데이터에서 바로 얻은 첫 번째 답입니다.

두 단계를 한 번에 실행할 수도 있습니다. 워크플로로 돌아가 **실행**을 클릭하거나(또는 **작업** 메뉴에서 **Run All**), 전체를 순서대로 실행하십시오. 각 단계는 진행되는 동안 상태 아이콘을 표시하며, **Completed**는 문제없이 끝났다는 뜻입니다. 각 상태의 의미와 중지된 실행을 재개하는 방법은 [워크플로 실행](/ko/guides/workflows/run-a-workflow/)을 참고하십시오.

> **오류가 발생했나요?** 가장 흔한 원인은 숫자여야 하는데 텍스트로 가져와진 데이터 형식, 그리고 테이블에 없는 열 이름을 참조하는 필터 조건입니다. 3단계의 테이블을 확인한 다음 다시 실행하십시오. 나머지 경우는 [단계 오류 관리](/ko/guides/workflows/managing-step-errors/)에서 다룹니다.
