이 튜토리얼에서는 **Model Context Protocol**(MCP)을 사용하여 AI 코딩 에이전트가 PlaidCloud 워크스페이스와 상호 작용하도록 설정합니다. 설정을 마치면 에디터에서 바로 에이전트에게 테이블 읽기, 워크플로 실행, 배부 구성, 데이터 관련 질문 답변을 요청할 수 있습니다.

소요 시간은 약 20분입니다. Claude Code, Cursor, Claude Desktop, ChatGPT, GitHub Copilot 및 MCP를 지원하는 모든 클라이언트에서 사용할 수 있습니다.

## 구축할 내용

AI 코딩 에이전트와 PlaidCloud 워크스페이스 사이의 연결을 구성하며, 에이전트는 다음 작업을 수행할 수 있습니다.

- 프로젝트, 테이블, 워크플로, 차원 목록 보기
- 테이블 내용 읽기
- 워크플로 정의 검사
- 워크플로 실행 트리거
- 화면을 전환하지 않고 데이터에 대한 질문에 답변

## 사전 요구 사항

- PlaidCloud 워크스페이스(없는 경우 [무료 체험을 시작하십시오](https://app.plaidcloud.com))
- 이미 사용 중인 AI 코딩 에이전트 — Claude Code, Cursor, Claude Desktop, ChatGPT, Copilot 또는 Gemini
- 에이전트가 MCP를 지원해야 합니다(최신 AI 도구 대부분이 지원합니다)

## 1단계: 워크스페이스의 MCP URL 확인

모든 PlaidCloud 워크스페이스는 다음 주소에서 MCP 엔드포인트를 제공합니다.

```text
https://<your-workspace>.plaid.cloud/mcp
```

`<your-workspace>`를 워크스페이스 서브도메인으로 바꾸십시오. PlaidCloud UI에 로그인할 때 사용하는 서브도메인과 같습니다.

## 2단계: 인증 토큰 받기

<Steps>

1. 브라우저에서 PlaidCloud에 로그인한 상태로 다음 주소를 방문합니다.
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. 페이지에 표시된 전달자 토큰을 복사합니다. 이 토큰은 사용자 계정과 동일한 액세스 권한을 부여하므로 안전하게 보관하십시오.

</Steps>

<Aside type="caution">
토큰을 비밀번호처럼 취급하십시오. 토큰은 대화형 인증을 우회하며 사용자를 대신하여 동작합니다. 토큰이 유출된 경우 같은 엔드포인트에서 폐기하십시오.
</Aside>

## 3단계: 에이전트 구성

<Tabs>

<TabItem label="Claude Code">

터미널에서 다음을 실행합니다.

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

정적 토큰 인증(OAuth 흐름 없음, 장시간 세션에 더 간편함)을 사용하려면 브라우저에서 2단계의 URL을 열고 표시된 구성 스니펫을 복사하여 `.mcp.json` 파일에 붙여넣으십시오.

전체 옵션은 [Claude Code 설정](/ko/integrations/ai-coding-agents/claude-code/)을 참조하십시오.

</TabItem>

<TabItem label="Cursor">

`https://<your-workspace>.plaid.cloud/mcp/setup/token`에서 전달자 토큰을 받아 Cursor MCP 구성에 다음 내용을 추가합니다.

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

전체 옵션은 [Cursor 설정](/ko/integrations/ai-coding-agents/cursor/)을 참조하십시오.

</TabItem>

<TabItem label="Claude Desktop">

설정 → 개발자 → MCP 서버를 열고 다음을 추가합니다.

- **서버 URL**: `https://<your-workspace>.plaid.cloud/mcp`
- 메시지가 표시되면 OAuth 로그인을 사용합니다

전체 옵션은 [Claude Desktop 설정](/ko/integrations/ai-coding-agents/claude-desktop/)을 참조하십시오.

</TabItem>

<TabItem label="ChatGPT">

1. 설정 → 커넥터 → 사용자 지정 커넥터 추가
2. 다음을 입력합니다.
   - **이름**: `PlaidCloud`
   - **MCP 서버 URL**: `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT가 OAuth 로그인을 위해 PlaidCloud로 리디렉션합니다. 연결을 승인합니다.
4. 커넥터를 사용할 대화에서 해당 커넥터를 켭니다.

전체 옵션은 [ChatGPT 설정](/ko/integrations/ai-coding-agents/chatgpt/)을 참조하십시오.

</TabItem>

<TabItem label="Copilot">

전달자 토큰을 받아 `.vscode/mcp.json`에 추가합니다.

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

VSCode는 시작할 때와 파일이 변경될 때 이 파일을 읽습니다.

전체 옵션은 [Copilot 설정](/ko/integrations/ai-coding-agents/copilot/)을 참조하십시오.

</TabItem>

</Tabs>

## 4단계: 연결 확인

에이전트에게 간단한 질문을 해 보십시오.

> "내 PlaidCloud 워크스페이스의 프로젝트 목록을 보여 줘."

에이전트가 프로젝트 목록을 응답해야 합니다. 응답하지 않으면 아래 문제 해결 항목을 확인하십시오.

## 5단계: 실제 작업 시도

연결되었다면 다음을 시도해 보십시오.

- **데이터 탐색**: "내 Quickstart 프로젝트의 `sales` 테이블에는 어떤 열이 있어?"
- **워크플로 실행**: "Financials 프로젝트의 `monthly_close` 워크플로를 실행하고 완료되면 알려 줘."
- **구성 작업**: "내 Test 워크플로에 최근 30일의 주문만 필터링하는 Table Lookup 단계를 만들어 줘."

에이전트의 응답은 일반적인 답변이 아니라 사용자 워크스페이스의 실제 상태를 기반으로 합니다.

## 문제 해결

에이전트가 PlaidCloud에 연결할 수 없거나 인증 오류가 반환되는 경우:

- **토큰 만료** — `https://<your-workspace>.plaid.cloud/mcp/setup/token`에서 토큰을 갱신하십시오
- **잘못된 범위** — 일부 도구에는 특정 PlaidCloud 범위(예: `analyze.workflow.write`)가 필요합니다. 에이전트에서 `mcp_introspect(name='<tool>')`을 실행하여 필요한 범위를 확인하십시오
- **워크스페이스 서브도메인 오류** — PlaidCloud UI에 로그인하여 확인하십시오. 서브도메인은 `.plaid.cloud` 앞부분입니다

자세한 내용은 [AI 코딩 에이전트 문제 해결](/ko/integrations/ai-coding-agents/troubleshooting/)을 참조하십시오.
