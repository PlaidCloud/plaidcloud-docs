이 튜토리얼에서는 PlaidCloud에서 완전한 비용 배부를 만드는 과정을 안내합니다. 끝까지 진행하면 드라이버 데이터를 사용해 비용 풀을 대상 차원에 분배하는 작동하는 모델이 완성됩니다. 이는 활동 기준 원가 계산, IT 비용 청구, 공유 서비스 분배의 기초입니다.

약 한 시간이 걸립니다. 배부는 PlaidCloud의 가장 독특한 기능이며, 이 모델을 이해하는 가장 좋은 방법입니다.

## 만들 내용

IT 부서 총비용을 각 사업부의 사용자 수에 따라 가중하여 사업부에 분배합니다.

```text
IT cost table  →  ┐
                  ├→  Allocation step  →  results table
User counts    →  ┤      (driver-based)
                  ┘
                  ↑
        Business unit dimension
```

## 사전 요구 사항

- PlaidCloud 워크스페이스(없다면 [무료 체험을 시작하세요](https://app.plaidcloud.com))
- 다음을 포함하고 있거나 가져올 수 있는 프로젝트:
  - **배부할 값**: 월별 IT 비용(총액 또는 하위 범주별)
  - **드라이버 데이터**: 사업부별 사용자 수
  - **차원**: 사업부 계층(사업부 → 본부 → 회사)
- [개념](/ko/get-started/concepts/)에 대한 이해: 워크스페이스, 프로젝트, 워크플로, 차원, 배부

<Aside>
원본 데이터가 아직 없다면 작은 CSV 파일을 준비하고 [데이터 로드, 변환 및 게시](/ko/get-started/tutorials/load-and-transform-data/)를 따라 먼저 가져올 수 있습니다.
</Aside>

## 1단계: 입력 설정하기

프로젝트에 다음 세 가지가 있는지 확인합니다.

| 개체 | 포함하는 내용 |
|---|---|
| `it_cost` 테이블 | IT 총비용(예: 금액이 있는 월별 한 행) |
| `users_by_bu` 테이블 | `user_count` 열이 있는 사업부별 한 행 |
| `business_units` 차원 | 리프 노드가 `users_by_bu`의 사업부 이름과 일치하는 사업부 계층 |

누락된 항목이 있으면 계속하기 전에 워크플로로 불러오십시오.

## 2단계: 배부 워크플로 만들기

<Steps>

1. 프로젝트를 열고 **워크플로** 탭으로 전환합니다.
2. **새 워크플로**를 클릭합니다. 이름을 "IT Cost Allocation"으로 지정합니다.
3. 워크플로 탐색기에서 새 워크플로를 엽니다.

</Steps>

## 3단계: 배부 단계 추가하기

<Steps>

1. **배부** 카테고리에서 새 단계를 추가합니다. 가장 유연한 옵션인 **Allocation Rules**를 선택합니다.
2. 소스를 구성합니다.
   - **소스 테이블**: `it_cost`
   - **소스 금액 열**: 금액이 들어 있는 열
3. 드라이버를 구성합니다.
   - **드라이버 테이블**: `users_by_bu`
   - **드라이버 값 열**: `user_count`
   - **드라이버 일치 열**: 사업부 이름이 들어 있는 열
4. 대상을 구성합니다.
   - **대상 차원**: `business_units`
   - **대상 수준**: 배부할 계층 수준을 선택합니다(보통 리프 수준).
5. 출력을 구성합니다.
   - **결과 테이블**: `it_cost_allocated`

</Steps>

## 4단계: 실행 및 확인

<Steps>

1. 단계를 실행합니다.
2. **테이블** 탭을 열고 `it_cost_allocated`를 클릭합니다.
3. 각 행은 한 사업부로 가는 비용 한 조각을 나타냅니다. 열은 다음과 같습니다.
   - 소스 금액(예: 해당 월의 IT 총비용)
   - 대상 사업부
   - 사용된 드라이버 값(해당 사업부의 사용자 수)
   - 배부율(사용자 수 ÷ 전체 사업부의 총 사용자 수)
   - 배부 금액(소스 × 배부율)

</Steps>

## 5단계: 숫자 검증하기

모든 배부가 통과해야 하는 세 가지 검사입니다.

1. **총액 대조**: 배부된 금액의 합계가 소스 총액과 같습니다(반올림 허용 오차 내).
2. **배부율 합계**: 소스 행마다 배부율의 합계가 1.0(= 100%)입니다.
3. **적용 범위**: 차원에서 몫을 받아야 하는 모든 사업부가 실제로 받았습니다.

[배부 결과](/ko/guides/allocations/results/allocation-results/) 가이드에 검증을 위한 전체 점검표가 있습니다.

문제가 있다면 가장 흔한 원인은 다음과 같습니다.
- **누락된 드라이버 데이터**: 차원에는 있지만 `users_by_bu`에 행이 없는 사업부는 배부를 받지 못합니다.
- **일치하지 않는 이름**: 드라이버 테이블에는 "Sales East"로, 차원에는 "Sales-East"로 되어 있는 경우입니다(띄어쓰기나 대소문자가 다르면 일치하지 않습니다).
- **0 또는 음수 드라이버**: 0 또는 예상하지 못한 배부가 생성됩니다.

## 6단계: 결과 사용하기

결과 테이블은 다른 PlaidCloud 테이블과 동일하며 다음과 같이 사용할 수 있습니다.

- 이후 워크플로 단계에서 다른 테이블과 **조인**(예: 총계정원장에 완전 배부 비용 열 추가)
- 대시보드나 외부 사용자를 위해 **게시**
- 다음 배부 단계의 소스로 **재배부**(연쇄 모델의 경우)

## 시도해 볼 변형

기본 모델이 작동하면 다음과 같이 확장할 수 있습니다.

- **여러 비용 풀**: 단일 `it_cost` 행을 IT 하위 범주(컴퓨팅, 스토리지, 라이선스)별 행으로 바꾸고 각각 다른 드라이버로 독립적으로 배부합니다.
- **다중 기간**: 소스를 월별로 분할하여 기간마다 배부 결과 하나를 생성합니다.
- **계층형 배부**: 본부 간접비를 사업부로, 사업부 비용을 제품으로, 제품 비용을 고객으로 배부합니다. 각 계층이 자체 배부 단계입니다.
- **재귀 배부**: 공유 서비스가 서로를 이용하는 경우(IT가 HR을 지원하고 HR이 IT를 지원)입니다. [재귀 배부](/ko/guides/allocations/setup/recursive-allocations/)를 참조하십시오.
- **규칙 기반 할당**: 분배가 둘 이상의 드라이버에 따라 달라지고 소스마다 다른 경우, 단일 드라이버 테이블을 연결하는 대신 안내형 빌더로 배부 차원을 작성합니다. [배부 차원 만들기](/ko/guides/dimensions/dimensions/#배부-차원-만들기)를 참조하십시오.
