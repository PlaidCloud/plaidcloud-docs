*약 20분 · 추가 기능 설치, 로그인, 테이블 가져오기, 실시간 수식 작성*

이미 스프레드시트로 하루 업무를 처리하고 있다면 PlaidCloud를 사용하기 위해 Excel을 떠날 필요가 없습니다. **PlaidXL**은 Excel용 PlaidCloud 추가 기능입니다. 프로젝트 테이블을 워크시트로 가져오고, 필요할 때 새로 고치며, PlaidCloud 데이터에서 바로 집계된 값을 계산하는 수식을 추가합니다. 이 튜토리얼을 마치면 누군가 워크플로를 다시 실행하는 순간 오래된 데이터가 되는 복사해 붙여넣기 대신, 신뢰할 수 있는 프로젝트 테이블에서 입력 값을 가져오게 됩니다.

## 수행할 작업

1. PlaidXL 추가 기능을 설치합니다.
2. 로그인하고 프로젝트를 선택합니다.
3. 테이블을 워크시트로 가져온 다음 새로 고칩니다.
4. 프로젝트의 테이블을 나열하고 합계를 계산하는 수식을 작성합니다.

## 사전 요구 사항

- Windows 또는 Mac에서 Microsoft 365용 Excel 또는 Excel 2021 이상.
- PlaidCloud 계정. PlaidCloud에서 싱글 사인온을 사용한다면 여기서도 계속 사용하십시오. PlaidXL은 동일한 ID로 로그인합니다.
- 열 수 있는 프로젝트로, 데이터가 있고 숫자 열이 있는 테이블이 하나 이상 있어야 합니다. 이미 액세스 권한이 있는 프로젝트라면 어느 것이든 사용할 수 있습니다. 아직 프로젝트가 없다면 [CSV에서 답까지](/ko/get-started/tutorials/csv-to-answer/)에서 PlaidCloud로 테이블을 가져올 수 있습니다.

<Aside>PlaidXL은 사용자의 권한으로 읽습니다. PlaidCloud에서 계정이 이미 볼 수 있는 프로젝트와 테이블만 표시되며, PlaidXL은 사용자가 테이블을 다시 저장하고 확인한 경우에만 테이블을 변경합니다.</Aside>

## 1단계: 추가 기능 설치

1. Excel에서 **Insert → Add-ins**를 엽니다. (이전 Mac 버전에서는 **Insert → Store**.)
2. 검색 상자에 `PlaidCloud`를 입력합니다.
3. **PlaidCloud** 추가 기능을 선택하고 **추가**를 클릭합니다.

리본에 **PlaidCloud** 탭이 나타납니다. 추가 기능은 통합 문서마다가 아니라 컴퓨터마다 한 번만 설치합니다.

<Aside type="tip">**PlaidCloud** 탭이 보이지 않나요? 모든 Excel 창을 닫고 Excel을 다시 시작하십시오. 조직에서 추가 기능을 관리하는 경우 Microsoft 365 관리자가 대신 배포해야 할 수 있습니다. [PlaidXL 설치](/ko/reference/cli/plaidxl/install/)를 참조하십시오.</Aside>

## 2단계: 로그인하고 프로젝트 선택

1. 새 통합 문서를 열고 **PlaidCloud → Open PlaidXL**을 클릭합니다.
2. PlaidCloud에 사용하는 이메일 주소를 입력하고 **로그인**을 클릭합니다.
3. 둘 이상의 워크스페이스에 속해 있다면 **Select a workspace**에서 하나를 선택하고 **로그인**을 클릭합니다.
4. Excel에서 요청하면 팝업을 허용하고, 평소 사용하는 방식(비밀번호와 2단계 인증 코드 또는 싱글 사인온)으로 로그인합니다.

작업 창 머리글에 워크스페이스가 표시됩니다. 머리글의 프로젝트 이름을 클릭하여 프로젝트 목록을 열고 프로젝트를 클릭합니다. 통합 문서가 이 프로젝트를 기억합니다. 프로젝트의 테이블은 **테이블** 탭에 나타납니다.

## 3단계: 테이블 가져오기

1. **테이블** 탭에서 테이블을 클릭합니다. **행**과 **열**에 테이블의 크기가 표시됩니다.
2. **열** 아래에서 필요하지 않은 열의 선택을 해제합니다. 열이 적을수록 더 빨리 로드됩니다.
3. **Matching Worksheet**를 선택된 상태로 두고 **Retrieve Table**을 클릭합니다.

테이블은 테이블 이름을 딴 새 워크시트에 바로 사용할 수 있는 상태로 나타납니다. 스크롤해도 계속 보이는 굵은 머리글 행, 모든 열의 필터, 데이터 전체를 포함하는 이름 있는 범위가 포함됩니다. **Sample data**라는 테이블은 `Sample_data` 시트에 이름 있는 범위 `_Sample_data`와 함께 나타나므로, 이 범위를 사용하는 수식은 데이터가 늘어나도 따라서 확장됩니다.

다른 시트에서와 마찬가지로 이 데이터를 기반으로 수식, 피벗 테이블, 차트를 만들 수 있습니다.

## 4단계: 새로 고침

PlaidCloud에서 테이블이 변경되면(워크플로가 다시 실행되거나 새 데이터가 로드되는 경우) 작업 창 또는 리본에서 **Refresh All Tables**를 클릭합니다. 새로 고치는 동안 시트 탭이 노란색으로 바뀌고 최신 상태가 되면 녹색으로 바뀝니다. 통합 문서로 가져온 모든 테이블이 선택한 열과 필터 그대로 새로 고쳐집니다.

## 5단계: 실시간 수식 작성

작업 창은 테이블을 복사해 옵니다. PlaidXL 수식은 한 걸음 더 나아가, 어느 셀에서든 PlaidCloud 데이터로 계산합니다.

1. 새 시트의 `A1`에 프로젝트의 테이블을 나열합니다.

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   이름이 A열 아래로 펼쳐집니다.

2. `C1`에 테이블의 열을 나열합니다. `Sample data`는 사용하는 테이블 이름으로 바꾸십시오.

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. 목록에서 숫자 열 하나와, 값이 포함되어 있다고 알고 있는 텍스트 열 하나를 고릅니다. 해당 값에 대해 숫자 열의 합계를 구합니다. 이름은 사용하는 이름으로 바꾸십시오.

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4`에는 **Region**이 **EMEA**인 행의 **amount** 합계가 표시됩니다. 계산은 PlaidCloud에서 이루어지고 값은 시트에 실시간으로 나타납니다. `E3`의 값을 바꾸면 합계도 따라서 바뀝니다.

열이 [차원](/ko/guides/dimensions/dimensions/)에 연결되어 있으면 값은 그 차원의 어느 노드든 될 수 있으며, 합계는 해당 노드 아래의 모든 항목을 롤업합니다. PlaidXL 보고서가 상세 행에서 리전, 부서 또는 연도의 합계를 구하는 방식이 바로 이것입니다.
