*약 20분 · 추가 기능 설치, 로그인, 테이블 가져오기, 실시간 수식 작성*

하루 업무가 이미 스프레드시트 중심으로 돌아간다면 PlaidCloud를 사용하기 위해 Excel을 떠날 필요가 없습니다. **PlaidXL**은 PlaidCloud의 Excel용 추가 기능으로, 프로젝트 테이블을 워크시트로 가져오고, 필요할 때 새로 고치며, PlaidCloud 데이터에서 직접 집계 값을 계산하는 수식을 추가합니다. 이 튜토리얼을 마치면 누군가 워크플로를 다시 실행하는 순간 오래된 데이터가 되어 버리는 복사 붙여넣기 대신, 신뢰할 수 있는 프로젝트 테이블에서 입력을 가져오게 됩니다.

## 진행 내용

1. PlaidXL 추가 기능을 설치합니다.
2. 로그인하고 프로젝트를 선택합니다.
3. 테이블을 워크시트로 가져온 다음 새로 고칩니다.
4. 프로젝트의 테이블을 나열하고 합계를 계산하는 수식을 작성합니다.

## 사전 요구 사항

- Windows 또는 Mac용 Microsoft 365 Excel, 또는 Excel 2021 이상.
- PlaidCloud 계정. PlaidCloud에 싱글 사인온을 사용한다면 여기서도 그대로 사용하십시오. PlaidXL은 동일한 ID로 로그인합니다.
- 열 수 있는 프로젝트와 데이터가 있는 테이블, 그리고 숫자 열 하나. 이미 액세스할 수 있는 프로젝트라면 무엇이든 됩니다. 아직 없다면 [CSV에서 답까지](/ko/get-started/tutorials/csv-to-answer/)에서 테이블을 PlaidCloud에 넣을 수 있습니다.

<Aside>PlaidXL은 사용자의 권한으로 읽습니다. PlaidCloud에서 계정이 이미 볼 수 있는 프로젝트와 테이블만 표시되며 그 이상은 표시되지 않고, PlaidXL은 이를 변경하지 않습니다.</Aside>

## 1단계: 추가 기능 설치하기

1. Excel에서 **Insert → Add-ins**를 엽니다. (이전 Mac 버전에서는 **Insert → Store**입니다.)
2. 검색 상자에 `PlaidCloud`를 입력합니다.
3. **PlaidCloud** 추가 기능을 선택하고 **추가**를 클릭합니다.

리본에 **PlaidCloud** 탭이 나타납니다. 통합 문서마다가 아니라 컴퓨터마다 한 번만 설치하면 됩니다.

<Aside type="tip">**PlaidCloud** 탭이 보이지 않나요? 모든 Excel 창을 닫고 Excel을 다시 여십시오. 조직에서 추가 기능을 관리하는 경우 Microsoft 365 관리자가 대신 배포해야 할 수 있습니다. [PlaidXL 설치](/ko/reference/cli/plaidxl/install/)를 참고하십시오.</Aside>

## 2단계: 로그인하고 프로젝트 선택하기

1. 새 통합 문서를 열고 **PlaidCloud → Show Taskpane**을 클릭합니다.
2. PlaidCloud에 사용하는 이메일 주소를 입력하고 **Sign In**을 클릭합니다.
3. 둘 이상의 워크스페이스에 속해 있다면 **Select a tenant**에서 하나를 선택하고 **Sign In**을 클릭합니다.
4. Excel에서 요청하면 팝업을 허용하고, 평소 방식(비밀번호와 2단계 인증 코드 또는 싱글 사인온)으로 로그인합니다.

작업 창에는 **Connected to** 뒤에 워크스페이스 ID가, **as** 뒤에 사용자 이름이 표시되고 그 아래에 프로젝트가 나열됩니다. 프로젝트를 클릭하면 **테이블** 탭에 해당 프로젝트의 테이블이 나타납니다.

## 3단계: 테이블 가져오기

1. **테이블** 탭에서 테이블을 클릭합니다. **행**과 **열**에 크기가 표시됩니다.
2. **열**에서 필요하지 않은 열의 선택을 해제합니다. 열이 적을수록 더 빨리 로드됩니다.
3. **Matching Worksheet**를 선택된 상태로 두고 **Retrieve Table**을 클릭합니다.

테이블은 이름을 딴 새 워크시트에 바로 작업할 수 있는 상태로 나타납니다. 스크롤해도 계속 보이는 굵은 머리글 행, 모든 열의 필터, 데이터 전체에 대한 이름 있는 범위가 포함됩니다. **Sample data**라는 테이블은 `Sample_data` 시트에 `_Sample_data`라는 이름 있는 범위로 나타나므로, 이 범위를 사용하는 수식은 데이터가 늘어나도 그대로 따라갑니다.

다른 시트에서와 같은 방식으로 이 데이터를 대상으로 수식, 피벗 테이블, 차트를 만들 수 있습니다.

## 4단계: 새로 고치기

워크플로가 다시 실행되거나 새 데이터가 로드되어 PlaidCloud의 테이블이 변경되면 작업 창이나 리본에서 **Refresh All Tables**를 클릭하십시오. 새로 고치는 동안 시트 탭이 노란색으로 바뀌고 최신 상태가 되면 녹색으로 바뀝니다. 통합 문서로 가져온 모든 테이블이 선택한 열과 필터 그대로 새로 고쳐집니다.

## 5단계: 실시간 수식 작성하기

작업 창은 테이블을 복사해 옵니다. PlaidXL 수식은 한 단계 더 나아가 어떤 셀에서든 PlaidCloud 데이터로 계산합니다.

1. 새 시트의 `A1`에 프로젝트의 테이블을 나열합니다.

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   이름이 A열 아래로 펼쳐집니다.

2. `C1`에 테이블의 열을 나열합니다. `Sample data`를 내 테이블 이름으로 바꾸십시오.

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. 해당 목록에서 숫자 열 하나와, 알고 있는 값이 들어 있는 텍스트 열 하나를 고릅니다. 그 값에 해당하는 숫자 열의 합계를 구합니다. 이름은 내 것으로 바꾸십시오.

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4`에는 **Region**이 **EMEA**인 행의 **amount** 합계가 표시됩니다. PlaidCloud에서 계산되어 시트에 실시간으로 나타납니다. `E3`의 값을 바꾸면 합계도 따라 바뀝니다.

열이 [차원](/ko/guides/dimensions/dimensions/)에 연결되어 있으면 값은 그 안의 어떤 노드든 될 수 있으며, 합계는 해당 노드 아래의 모든 항목을 집계합니다. PlaidXL 보고서가 세부 행에서 지역, 부서 또는 연도의 합계를 구하는 방식입니다.
