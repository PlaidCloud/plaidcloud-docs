*약 20분 · 추가 기능 설치, 로그인, 테이블 가져오기, 라이브 수식 작성*

업무가 이미 스프레드시트 중심으로 돌아간다면 PlaidCloud를 사용하기 위해 Excel을 떠날 필요가 없습니다. **PlaidXL**은 Excel용 PlaidCloud 추가 기능으로, 프로젝트 테이블을 워크시트로 가져오고, 필요할 때 새로 고치며, PlaidCloud 데이터에서 바로 집계 값을 계산하는 수식을 제공합니다. 이 튜토리얼을 마치면 누군가 워크플로를 다시 실행하는 순간 오래된 데이터가 되는 복사해 붙여넣기 대신, 신뢰할 수 있는 프로젝트 테이블에서 입력값을 가져오게 됩니다.

## 수행할 작업

1. PlaidXL 추가 기능을 설치합니다.
2. 로그인하고 프로젝트를 선택합니다.
3. 테이블을 워크시트로 가져온 다음 새로 고칩니다.
4. 프로젝트의 테이블을 나열하고 합계를 계산하는 수식을 작성합니다.

## 사전 요구 사항

- Windows 또는 Mac에서 Microsoft 365용 Excel 또는 Excel 2021 이상.
- PlaidCloud 계정. PlaidCloud에 단일 로그인(SSO)을 사용한다면 여기서도 그대로 사용하십시오. PlaidXL은 동일한 ID로 로그인합니다.
- 데이터가 있는 테이블과 숫자 열이 하나 이상 있는, 열 수 있는 프로젝트. 이미 액세스할 수 있는 프로젝트라면 무엇이든 사용할 수 있습니다. 아직 프로젝트가 없다면 [CSV에서 답까지](/ko/get-started/tutorials/csv-to-answer/)에서 PlaidCloud로 테이블을 가져오는 방법을 확인하십시오.

<Aside>PlaidXL은 사용자의 권한으로 읽습니다. PlaidCloud에서 이미 볼 수 있는 프로젝트와 테이블만 표시되며 그 이상은 표시되지 않습니다. 또한 PlaidXL은 사용자가 직접 쓰기 작업을 할 때만 테이블을 변경합니다.</Aside>

## 1단계: 추가 기능 설치

1. Excel에서 **Insert → Add-ins**를 엽니다. (이전 Mac 버전에서는 **Insert → Store**입니다.)
2. 검색 상자에 `PlaidCloud`를 입력합니다.
3. **PlaidCloud** 추가 기능을 선택하고 **추가**를 클릭합니다.

리본에 **PlaidCloud** 탭이 나타납니다. 추가 기능은 통합 문서마다가 아니라 컴퓨터마다 한 번만 설치합니다.

<Aside type="tip">**PlaidCloud** 탭이 보이지 않습니까? 모든 Excel 창을 닫고 Excel을 다시 시작하십시오. 조직에서 추가 기능을 관리하는 경우 Microsoft 365 관리자가 대신 배포해야 할 수 있습니다. [PlaidXL 설치](/ko/reference/cli/plaidxl/install/)를 참조하십시오.</Aside>

## 2단계: 로그인하고 프로젝트 선택

1. 새 통합 문서를 열고 **PlaidCloud → Open PlaidXL**을 클릭합니다.
2. PlaidCloud에 사용하는 이메일 주소를 입력하고 **로그인**을 클릭합니다. 업무용 계정으로 Office에 로그인되어 있다면 PlaidXL이 워크스페이스를 자동으로 찾을 수 있습니다. [Office 계정으로 로그인](/ko/reference/cli/plaidxl/connect/#office-계정으로-로그인)을 참조하십시오.
3. 둘 이상의 워크스페이스에 속해 있다면 **Select a workspace**에서 하나를 선택하고 **로그인**을 클릭합니다.
4. Excel이 요청하면 팝업을 허용하고 평소 방식(비밀번호와 2단계 인증 코드 또는 SSO)으로 로그인합니다.

작업 창 머리글에 워크스페이스가 표시됩니다. 머리글의 프로젝트 이름을 클릭하여 프로젝트 목록을 열고 사용할 프로젝트를 클릭합니다. 열 수 있는 프로젝트가 하나뿐이면 PlaidXL이 자동으로 연결합니다. 통합 문서가 이 선택을 기억하며, 해당 프로젝트의 테이블은 **테이블** 탭에 나타납니다.

## 3단계: 테이블 가져오기

1. **테이블** 탭에서 테이블을 클릭합니다. **행**과 **열**에 테이블 크기가 표시됩니다.
2. **열**에서 필요하지 않은 열의 선택을 해제합니다. 열이 적을수록 더 빨리 로드됩니다.
3. **Matching Worksheet**를 선택한 상태로 두고 **Retrieve Table**을 클릭합니다.

테이블은 이름이 같은 새 워크시트에 Excel 표로 들어옵니다. 예를 들어 **Sample data**라는 테이블은 `Sample_data` 시트에 들어옵니다. 스크롤해도 머리글 행이 계속 보이고, 모든 열에 필터가 있으며, Excel 표를 참조하는 수식은 데이터가 늘어나도 그대로 따라갑니다.

다른 시트에서와 마찬가지로 이 데이터를 기반으로 수식, 피벗 테이블, 차트를 만들 수 있습니다.

## 4단계: 새로 고침

PlaidCloud에서 테이블이 변경되면(워크플로가 다시 실행되거나 새 데이터가 로드될 때) 작업 창에서 **Refresh All Tables**를 클릭하거나 리본에서 **Refresh → Refresh all tables**를 클릭합니다. 작업 창에는 각 테이블의 진행 상황이 **취소**와 함께 표시되고, 완료되면 새로 고친 행 수가 나열됩니다. 통합 문서로 가져온 모든 테이블이 선택한 열과 필터 그대로 새로 고쳐집니다.

## 5단계: 라이브 수식 작성

작업 창은 테이블을 복사해 옵니다. PlaidXL 수식은 한 걸음 더 나아가 어느 셀에서든 PlaidCloud 데이터로 직접 계산합니다.

1. 새 시트의 `A1`에 프로젝트의 테이블을 나열합니다.

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   이름이 A열 아래로 채워집니다.

2. `C1`에 테이블의 열을 나열합니다. `Sample data`를 사용자의 테이블 이름으로 바꾸십시오.

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. 해당 목록에서 숫자 열 하나와, 값을 알고 있는 텍스트 열 하나를 고릅니다. 그 값에 대해 숫자 열의 합계를 구합니다. 이름은 사용자의 것으로 바꾸십시오.

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4`에는 **Region**이 **EMEA**인 행의 **amount** 합계가 표시됩니다. 계산은 PlaidCloud에서 이루어지고 결과는 시트에 라이브로 나타납니다. `E3`의 값을 바꾸면 합계도 따라 바뀝니다.

열이 [차원](/ko/guides/dimensions/dimensions/)에 연결되어 있으면 값에는 해당 차원의 어떤 노드든 사용할 수 있으며, 합계는 그 노드 아래의 모든 항목을 집계합니다. PlaidXL 보고서가 상세 행에서 리전, 부서, 연도 합계를 구하는 방식이 바로 이것입니다.
