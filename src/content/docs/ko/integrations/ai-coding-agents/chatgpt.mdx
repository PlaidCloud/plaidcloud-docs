사용자가 추가하는 MCP 서버에 대한 ChatGPT의 지원은 아직 순차적으로 제공되고 있으며 요금제와 사용 환경에 따라 다릅니다. 이 페이지에서는 현재 작동하는 방법을 설명합니다.

## ChatGPT Pro / Plus / Team — 커넥터

ChatGPT 요금제에서 **Connectors** UI(Settings → Connectors)를 사용할 수 있다면 PlaidCloud를 사용자 지정 MCP 커넥터로 추가할 수 있습니다.

1. **Settings → Connectors → Add custom connector**로 이동합니다.
2. 다음을 입력합니다.
   - **이름**: `PlaidCloud`
   - **MCP 서버 URL**: `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT가 OAuth 로그인을 위해 PlaidCloud로 리디렉션합니다. 로그인하면 PlaidCloud에 요청하는 애플리케이션과 자격 증명을 보낼 리디렉션 URI가 표시되는 **Application Access Request** 페이지가 나타납니다. 승인하기 전에 이 내용이 ChatGPT와 일치하는지 확인하십시오.
4. 커넥터를 사용해야 하는 대화에서 커넥터를 켭니다.

<Aside>Connectors UI는 모든 계정이나 모든 지역에서 표시되지 않을 수 있습니다. "Add custom connector"가 보이지 않으면 요금제나 워크스페이스 정책에서 현재 사용자가 추가하는 MCP 서버를 허용하지 않는 것이므로 아래의 대체 방법을 사용하십시오.</Aside>

## ChatGPT Enterprise

Enterprise 관리자는 관리 콘솔을 통해 워크스페이스 수준에서 MCP 커넥터를 고정할 수 있습니다. 위와 같은 OAuth 설정을 따르되, 커넥터를 사용할 수 있게 되기 전에 관리자의 워크스페이스 승인 단계가 있다는 점에 유의하십시오.

## 대체 방법 — REST 작업을 사용하는 사용자 지정 GPT

계정에서 사용자 지정 MCP 커넥터를 지원하지 않는 경우에도 PlaidCloud의 REST API를 OpenAPI Action으로 호출하는 **Custom GPT**를 통해 ChatGPT에서 PlaidCloud를 사용할 수 있습니다.

1. PlaidCloud의 REST 인터페이스는 `https://<your-tenant>.plaidcloud.org/openapi_rest.json`의 OpenAPI 문서에 설명되어 있습니다.
2. ChatGPT에서 Custom GPT를 만들고(Explore GPTs → Create) **작업** 아래에서 해당 URL을 가져오거나 JSON을 붙여 넣습니다.
3. 인증을 **OAuth**로 구성하고 PlaidCloud의 Keycloak 엔드포인트를 지정합니다. realm URL과 클라이언트 ID는 PlaidCloud 관리자에게 문의하십시오.

이 방식은 MCP의 도구 이름 규칙 대신 REST 엔드포인트를 직접 사용합니다. 모델이 탐색하기에는 약간 더 장황하지만, PlaidCloud가 제공하는 읽기/쓰기 작업에서는 기능적으로 동일합니다.

## MCP를 항상 사용할 수는 없는 이유

OpenAI의 MCP 지원은 계속 발전하고 있으며, 사용 가능한 환경(Connectors UI, Actions 스키마 등)은 요금제와 시기에 따라 달라집니다. 계정에서 공식 **Connectors** 경로를 사용할 수 있다면 그것을 우선 사용하십시오. 내장된 OAuth 새로 고침이 있고 이 섹션의 나머지 부분과 같은 도구 호출 환경을 제공합니다. Custom GPT Actions로의 대체는 계정에 MCP가 아직 제공되지 않을 때에만 필요합니다.
