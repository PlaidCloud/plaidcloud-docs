[claude.ai](https://claude.ai)의 웹 UI와 데스크톱 앱 모두 일반 사용자용 Claude 앱은 **Custom Connectors** 기능을 통해 MCP 서버를 지원합니다. 설정은 한 번의 OAuth 절차로 끝나며, 이후 연결은 Claude 계정과 연결되어 여러 기기에서 따라옵니다.

<Aside>Custom Connectors는 Claude Pro, Max, Team, Enterprise 요금제에서 사용할 수 있습니다. Team 및 Enterprise 관리자는 워크스페이스의 모든 사용자에게 커넥터를 고정할 수 있습니다.</Aside>

## 설정

1. Claude(웹 또는 데스크톱)에서 **Settings → Connectors**를 엽니다.
2. **Add custom connector**를 클릭합니다.
3. 다음을 입력합니다.
   - **이름**: `PlaidCloud` (테넌트가 여러 개이면 `PlaidCloud (prod)`, `PlaidCloud (dev)`).
   - **서버 URL**: `https://<your-workspace>.plaid.cloud/mcp`
4. **추가**를 클릭합니다. Claude가 PlaidCloud의 Keycloak 로그인으로 가는 브라우저 탭을 엽니다.
5. 로그인한 다음 이어서 표시되는 **Application Access Request** 페이지를 승인합니다. 이 페이지에는 요청하는 애플리케이션과 자격 증명을 보낼 리디렉션 URI가 표시되므로, 승인하기 전에 둘 다 Claude와 일치하는지 확인하십시오. 연결이 저장된 상태로 Claude로 돌아옵니다.

이제 커넥터를 모든 대화에서 사용할 수 있습니다. 채팅 입력창의 커넥터 선택기에서 켜거나 끌 수 있습니다.

## 사용법

활성화한 후에는 Claude에게 다음과 같이 요청할 수 있습니다.

- "프로젝트 `Q4 Forecast`의 워크플로를 나열해 줘."
- "`daily-load` 워크플로의 최근 실패한 실행 10건을 보여 줘."
- "`mcp_recipes`를 실행하고 단계를 백필하는 데 맞는 것을 골라 줘."

Claude는 적절한 MCP 도구를 선택해 호출하고 응답을 답변에 반영합니다. 변경 작업의 경우 일반적으로 수행하려는 내용을 설명하므로 승인하기 전에 주의 깊게 검토하십시오.

## 여러 테넌트

테넌트마다 별도의 커넥터를 추가하십시오. 대화에서 Claude가 구별할 수 있도록 서로 다른 이름을 지정합니다. 특정 채팅에서 켠 커넥터만 사용할 수 있습니다. 운영 환경은 기본적으로 꺼 두고 확실할 때만 켜는 것이 합리적인 안전 습관입니다.

## 액세스 새로 고침

Custom connector는 OAuth 새로 고침 토큰을 저장하므로 다시 인증해야 하는 경우는 드뭅니다. PlaidCloud 비밀번호를 변경했거나 새 기기를 사용하거나 서버 측에서 세션이 무효화되면 커넥터에 "needs authentication"이 표시될 수 있습니다. 커넥터 설정에서 **Reconnect**를 클릭하여 OAuth 절차를 다시 진행하십시오.

## 연결 해제

Settings → Connectors → 커넥터 클릭 → **제거**. 이렇게 하면 Claude 계정에 저장된 OAuth 토큰이 삭제됩니다. PlaidCloud 측 세션은 독립적이므로, 기반이 되는 Keycloak 세션을 무효화하려면 PlaidCloud에서 별도로 로그아웃하십시오.
