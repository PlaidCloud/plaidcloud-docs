AI 어시스턴트를 PlaidCloud의 [MCP 서버](../getting-started/)에 연결한 다음, 프로젝트의 테이블이나 뷰를 기반으로 차트 또는 대시보드 전체를 요청하십시오. 필요한 커넥터는 PlaidCloud 커넥터 하나뿐입니다. 어시스턴트는 사용자 본인의 권한으로 작업하므로 이미 열 수 있는 데이터만 차트로 만들 수 있으며, [행 액세스](/ko/guides/dashboards/control-who-can-see-a-dashboard/)는 다른 모든 곳과 마찬가지로 적용됩니다.

> Sales Results 테이블에서 *월별 순매출* 차트를 만든 다음, Sales Overview라는 새 대시보드에 추가해 줘.

## 시작하기 전에

- **먼저 테이블을 게시하십시오.** 차트는 PlaidCloud에 게시된 테이블이나 뷰를 기반으로만 만들 수 있습니다. 게시되지 않은 경우 어시스턴트가 게시하라고 안내하므로, 게시한 후 다시 요청하십시오.
- **대시보드 사이트를 한 번 여십시오.** 대시보드 사이트를 한 번도 열지 않은 멤버는 첫 요청 전에 사이트를 한 번 열어야 합니다. 그 전까지 어시스턴트는 계정이 아직 설정되지 않았다고 보고합니다.
- **로그인한 연결을 사용하십시오.** 차트와 대시보드는 사용자가 직접 연결하고 로그인한 어시스턴트만 만들 수 있습니다. Microsoft 365 Copilot, PlaidCloud 앱 내 어시스턴트, 워크플로 단계 및 서비스 계정으로는 만들 수 없습니다.

## 차트

무엇을 측정하고 어떻게 나눌지 말하여 차트를 요청하십시오. 어시스턴트가 테이블, 차트 유형 및 설정을 선택합니다.

| 설정 | 기능 |
| --- | --- |
| **유형** | `table`, `bar`, `line`, `pie` 또는 `big_number`. |
| **지표** | 열과 그 열을 집계하는 방법: `SUM`, `COUNT`, `AVG`, `MIN`, `MAX` 또는 `COUNT_DISTINCT`. `SUM`과 `AVG`에는 숫자 열이 필요합니다. |
| **X** | 막대 차트나 꺾은선 차트의 범주 열 또는 시간 열입니다. `big_number` 차트에 지정하면 추세선이 추가됩니다. |
| **시간 단위** | 시간 열을 `day`, `week`, `month`, `quarter` 또는 `year` 단위로 그룹화합니다. |
| **그룹화 기준** | 수치를 나눌 기준 열입니다. 원형 차트는 정확히 하나만 사용합니다. |
| **필터** | 열, 비교 연산자(`=`, `!=`, `>`, `<`, `>=`, `<=`, `LIKE`, `ILIKE`, `NOT LIKE`, `IN` 또는 `NOT IN`) 및 값입니다. `IN`과 `NOT IN`에는 목록을 지정합니다. |

어시스턴트는 차트 링크와 차트 데이터 샘플을 받습니다. 차트를 신뢰하기 전에 어시스턴트에게 샘플이 질문과 맞는지 확인하도록 요청하십시오.

### 차트 편집

어시스턴트는 `chart_id`를 전달하여 사용자가 소유한 차트를 편집합니다. 이 값이 없으면 같은 요청을 반복할 때 두 번째 차트가 만들어지므로, 차트를 다시 만들지 말고 방금 만든 차트를 편집하라고 어시스턴트에게 지시하십시오.

### 계산 측정값

차트 빌더는 열을 집계합니다. 마진이나 단위당 매출 같은 계산 측정값이 필요하면 먼저 PlaidCloud [뷰](../getting-started/#레이블과-뷰)에 열로 추가하고 뷰를 게시한 다음, 그 열로 차트를 만드십시오. 어시스턴트에게 뷰를 만들어 달라고 요청할 수도 있습니다.

## 대시보드

직접 만든 차트로 대시보드를 요청하십시오.

- **새 대시보드**는 프로젝트의 **기본 대시보드 대상**으로 게시됩니다. 프로젝트에 대상이 설정되어 있지 않으면 프로젝트의 모든 사용자가 볼 수 있습니다. 볼 수 있는 사용자를 변경하려면 [대시보드를 볼 수 있는 사용자 제어](/ko/guides/dashboards/control-who-can-see-a-dashboard/)를 참조하십시오.
- **기존 대시보드에 추가**는 사용자가 소유한 대시보드에서 작동하며, 이미 있는 차트를 제거하지 않습니다. 일부 차트를 추가하지 못한 경우 어시스턴트에게 나머지 차트에 대해 요청을 다시 실행하도록 요청하십시오.
- **대시보드당 하나의 프로젝트.** 대시보드의 모든 차트는 같은 프로젝트에서 가져와야 합니다. 다른 프로젝트의 차트는 두 번째 대시보드를 만들어 사용하십시오.

<Aside>
  대상 설정은 볼 수 없어야 하는 사람에게 대시보드를 숨깁니다. 각 차트의 데이터에는 여전히 프로젝트 액세스와 행 액세스가 적용됩니다.
</Aside>

## 문제가 발생한 경우

| 메시지 | 조치 사항 |
| --- | --- |
| 테이블이 게시되지 않았습니다 | PlaidCloud에서 테이블이나 뷰를 게시한 다음 다시 요청하십시오. |
| 계정이 아직 존재하지 않습니다 | 대시보드 사이트를 한 번 연 다음 다시 요청하십시오. |
| 해당 차트 또는 대시보드의 소유자가 아닙니다 | 소유한 차트와 대시보드만 편집할 수 있습니다. 대신 새로 만들어 달라고 요청하십시오. |
| 열 또는 집계가 유효하지 않습니다 | 열 이름을 확인하고, `SUM`이나 `AVG`는 숫자 열에만 사용하십시오. |
| 서비스 시간이 초과되었습니다 | 차트나 대시보드가 이미 만들어졌을 수 있습니다. 다시 요청하기 전에 대시보드 사이트를 확인하십시오. |
