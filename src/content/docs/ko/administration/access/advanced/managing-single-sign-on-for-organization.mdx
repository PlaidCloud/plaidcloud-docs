각 조직은 멤버가 구성에서 지정한 싱글 사인온 페이지에 접속할 수 있는 사용자 지정 URL([https://plaidcloud.com/sso](https://plaidcloud.com)/`<custom_name_here>`)을 가질 수 있습니다.

<Aside>싱글 사인온은 SAML 2.0 프로토콜을 사용하며 사용자 인터페이스를 통해 설정합니다.</Aside>

<Aside type="tip">워크스페이스 구성원이 Microsoft Entra ID, Okta 또는 다른 OpenID Connect 공급자로 로그인하도록 하려면 **Workspaces** 페이지의 안내형 **Single sign-on** 대화 상자를 사용하십시오(엔터프라이즈 싱글 사인온은 유료 요금제에 포함되며, MFA 비밀번호와 소셜 로그인은 모든 요금제에서 사용할 수 있습니다). [싱글 사인온](/ko/administration/control-plane/workspace-configuration/#single-sign-on)을 참조하십시오.</Aside>

사용자 지정 URL을 만들려면 다음을 수행합니다.

1. 화면 오른쪽 상단의 “Organization Settings” 메뉴를 선택합니다.
2. “Single Sign-On Security Credentials”를 클릭합니다.
3. 필요에 따라 Single Sign-On URL을 조정합니다.
4. “Update Organization SSO Settings”를 클릭합니다.

## 사용자 자동 생성 허용

싱글 사인온을 사용하는 경우 싱글 사인온 인증에 성공하면 멤버를 자동으로 만들도록 선택할 수 있습니다. 새 멤버에게는 조직 설정에 지정된 기본 워크스페이스와 보안 역할이 부여됩니다. 멤버를 자동으로 만들려면 다음을 수행합니다.

1. 화면 오른쪽 상단의 “Organization Settings” 메뉴를 선택합니다.
2. “Organization and User Settings”를 클릭합니다.
3. “Create Users Automatically from Single Sign-On” 확인란을 선택합니다.
4. 원하는 기본 워크스페이스를 선택합니다.

이 기능을 사용하면 새 멤버가 PlaidCloud에서 별도 설정 없이 자동으로 액세스 권한을 갖게 되므로 멤버 관리가 크게 간소화됩니다. 마찬가지로 멤버가 싱글 사인온 시스템에서 제거되면 더 이상 PlaidCloud에 액세스할 수 없습니다.


## 싱글 사인온에서 보안 그룹 할당 허용

싱글 사인온을 사용하는 경우 인증 성공 메시지와 함께 그룹 연결 목록을 전달하도록 선택할 수 있습니다. 목록의 항목은 멤버를 지정된 그룹에 할당하고 지정되지 않은 그룹에서는 제거하는 데 사용됩니다. 이는 Active Directory 또는 다른 LDAP 서비스와 같은 중앙 사용자 관리 서비스를 사용하여 보안 그룹 할당을 관리하는 효과적인 방법입니다.


<Aside>멤버가 워크스페이스에서 관리자로 표시되어 있으면 이 자동화 과정에서 할당된 역할과 관계없이 해당 워크스페이스에 대한 전체 액세스 권한이 계속 유지됩니다.</Aside>


이 옵션을 사용하면 멤버가 다음에 로그인할 때 제공된 목록을 사용하여 보안 역할이 할당됩니다. 이 옵션을 사용하지 않으면 기존 멤버는 PlaidCloud에서 수동으로 업데이트할 때까지 현재 보안 역할을 유지합니다.
