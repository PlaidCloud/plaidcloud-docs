PlaidCloud에서 비활성 멤버를 유지하고 싶지 않다면 PlaidCloud가 제공하는 만료 기능을 사용하여 지정한 비활성 기간이 지난 후 조직에서 멤버를 자동으로 제거하도록 설정할 수 있습니다. 휴면 멤버의 자동 제거는 필요한 경우 최소 하루로 설정할 수 있습니다.

<Aside>이 옵션을 0으로 설정하면 조직에서 자동 제거가 이루어지지 않습니다.</Aside>


**멤버 만료를 설정하려면 다음을 수행합니다.**

1. 화면 오른쪽 상단의 “Organization Settings” 메뉴를 선택합니다.
2. “Organization and User Settings”를 클릭합니다.
3. 만료까지의 일수를 원하는 값으로 설정합니다.
4. Update를 클릭합니다.
