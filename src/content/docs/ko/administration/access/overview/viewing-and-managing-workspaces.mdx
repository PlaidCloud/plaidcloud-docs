워크스페이스를 사용하면 소규모에서 대규모에 이르는 조직이 자체 클라우드 기반 서비스처럼 운영할 수 있습니다. 예를 들어 소규모 팀은 조직에 워크스페이스를 하나만 둘 수 있고, 대규모 조직은 특화된 워크스페이스를 수백 개 둘 수 있습니다.



워크스페이스는 액세스와 가시성을 관리하며 조직의 멤버가 작업할 수 있는 격리된 영역을 제공합니다. 워크스페이스 액세스 권한은 조직의 비공개 멀티 테넌트 환경에서 멤버에게 할당됩니다. 워크스페이스를 사용하면 일부 워크스페이스에서는 팀이 공개 프로젝트를 협업하고, 다른 워크스페이스에서는 엄격한 기밀성을 유지할 수 있습니다.



워크스페이스는 완전히 격리되어 있으므로 데이터를 워크스페이스 간에 직접 공유하거나 액세스할 수 없습니다. 다만 워크스페이스가 동일한 공유 Document 영역에 액세스할 수 있으므로, 원하는 경우 워크스페이스 간에 파일을 공유할 수 있습니다.



## 워크스페이스 보기 및 관리


조직 내 워크스페이스를 보고 관리하는 일은 간단합니다. 워크스페이스를 관리하려면 조직 소유자여야 합니다. 워크스페이스를 보고 관리하려면:


1. 브라우저 오른쪽 위의 메뉴에서 “Organization Settings”를 선택합니다.
2. “Workspaces”를 클릭합니다.

그러면 조직 내 모든 현재 워크스페이스를 보여 주는 테이블이 표시됩니다. 여기에서 워크스페이스를 만들고, 업데이트하고, 일시 중지하고, 삭제할 수 있으며, 워크스페이스에 앱을 추가하고 각 워크스페이스에 대한 멤버 액세스를 관리할 수 있습니다.



### 워크스페이스 만들기


1. 브라우저 오른쪽 위의 메뉴에서 “Organization Settings”를 선택합니다.
2. “Workspaces”를 클릭합니다.
3. “New Workspace” 버튼을 클릭합니다.
4. 필수 필드를 작성합니다.
5. “Submit”을 클릭합니다.

<Aside>기본적으로 워크스페이스를 만든 멤버는 해당 워크스페이스에 자동으로 할당됩니다.</Aside>


### 워크스페이스 업데이트


1. 브라우저 오른쪽 위의 메뉴에서 “Organization Settings”를 선택합니다.
2. “Workspaces”를 클릭합니다.
3. 원하는 워크스페이스의 편집 아이콘을 클릭합니다.
4. 필요에 따라 필드를 조정합니다.
5. “Submit”을 클릭합니다.

### 워크스페이스 일시 중지


1. 브라우저 오른쪽 위의 메뉴에서 “Organization Settings”를 선택합니다.
2. “Workspaces”를 클릭합니다.
3. 원하는 워크스페이스의 “Active” 체크박스를 선택 해제합니다.
4. “Submit”을 클릭합니다.

### 워크스페이스 삭제


1. 브라우저 오른쪽 위의 메뉴에서 “Organization Settings”를 선택합니다.
2. “Workspaces”를 클릭합니다.
3. 원하는 워크스페이스의 삭제 아이콘을 클릭합니다.
4. “Delete”를 다시 한 번 클릭합니다.

<Aside>삭제는 영구적인 작업입니다. 이 과정에서 워크스페이스와 관련된 모든 데이터가 삭제됩니다. 삭제하기 전에 필요한 모든 항목을 백업했는지 확인하십시오.</Aside>


### 워크스페이스에서 사용할 수 있는 앱 관리


기본적으로 새 워크스페이스에는 Analyze, Document, Identity의 세 가지 앱이 자동으로 추가됩니다. Identity는 워크스페이스 내 액세스와 역할을 관리하는 데 필수적이므로 제거할 수 없지만 Analyze와 Document는 제거할 수 있습니다. 사용자 지정 앱을 포함하여 워크스페이스에서 사용할 수 있는 앱을 관리하려면:


1. 브라우저 오른쪽 위의 메뉴에서 “Organization Settings”를 선택합니다.
2. “Workspaces”를 클릭합니다.
3. 연결된 앱을 수정하려는 워크스페이스의 앱 아이콘을 클릭합니다.
4. 앱을 제거하려면 제거할 앱의 삭제 아이콘을 클릭하고 삭제를 확인합니다.
5. 새 앱을 추가하려면 **Add App to Workspace** 버튼을 클릭하고 추가할 앱을 선택한 다음 **Enable for Use** 체크박스를 선택하고 Create 버튼을 클릭합니다.
