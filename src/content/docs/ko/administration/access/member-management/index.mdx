ID는 워크스페이스 멤버를 추가, 제거 및/또는 일시 중지하는 기능을 제공합니다. PlaidCloud 멤버는 여러 워크스페이스의 멤버가 될 수 있으므로, 워크스페이스에서 멤버를 제거해도 PlaidCloud에서 멤버 계정이 삭제되지는 않습니다.



## 신규 멤버


### 신규 멤버 초대


멤버 추가는 초대 방식으로 이루어집니다. 역할을 선택하고 하나 이상의 이메일 주소를 입력하면, 각 주소마다 해당 역할이 부여된 새 멤버 계정이 생성됩니다.

**멤버를 초대하려면:**


1. ID를 열고 레일에서 **멤버**를 선택합니다(또는 **개요**에서 **Invite member**를 선택합니다)
2. **Invite member**를 클릭합니다
3. **뷰어** 또는 **Builder**를 선택합니다([뷰어와 Builder 비교](#뷰어와-builder-비교) 참조)
4. 이름, 성, 언어를 입력합니다
5. 이메일 주소를 입력합니다. 여러 사람을 한 번에 초대하려면 한 줄에 주소 하나씩 입력합니다
6. **Send invite**를 클릭합니다

초대한 각 주소는 선택한 역할이 부여된 새 멤버가 됩니다. 싱글 사인온을 강제하지 않는 워크스페이스에서는 뷰어든 Builder든 초대된 모든 멤버가 암호 설정 링크가 포함된 동일한 [환영 이메일](#신규-멤버-환영-이메일)을 받습니다. 싱글 사인온을 강제하는 워크스페이스에서는 초대된 멤버가 ID 공급자를 통해 로그인하므로 암호 설정 이메일이 전송되지 않습니다.

선택한 역할은 해당 멤버의 워크스페이스 수준 권한을 즉시 부여합니다. 즉, Builder는 프로젝트 액세스 권한이 있는 모든 곳에서 즉시 콘텐츠를 만들고 편집할 수 있습니다. 다만 초대만으로 새 멤버가 특정 프로젝트에 자동으로 추가되지는 않습니다. 개별 프로젝트에 대한 액세스는 언제든지 각 프로젝트의 멤버 목록에서 별도로 부여하십시오.

### 이미 계정이 있는 사용자 추가

주소가 이미 워크스페이스 멤버의 것인 경우(싱글 사인온으로 처음 로그인할 때 계정이 자동으로 생성된 사용자 포함), **작업 영역 멤버 추가**는 실패하는 대신 해당 사용자를 워크스페이스에 추가합니다. 선택한 역할이나 프로젝트 액세스가 적용되며, 이미 보유한 더 높은 프로젝트 역할은 낮아지지 않습니다. 액세스 권한이 생겼음을 알 수 있도록 환영 이메일이 즉시 전송되고, "&lt;email&gt; is already a member of this workspace. A welcome email was sent so they know they have access."라는 메시지가 표시됩니다.

이 환영 이메일은 평소처럼 또는 싱글 사인온으로 로그인하라고 안내합니다. 암호 설정 링크는 없으며 이미 보유한 암호를 대체하지 않습니다. 전송에 실패하면 알림이 표시되며, 멤버 목록에서 **환영 이메일 다시 보내기**를 사용할 수 있습니다.

일부 계정은 사유와 함께 거부됩니다.

- 비활성화된 멤버. **멤버**에서 활성화한 다음 추가하십시오.
- 시스템 계정.
- 이메일이 확인되지 않은 계정. 지원팀에 문의하십시오.

여러 주소를 입력하면 대소문자나 불필요한 공백과 관계없이 중복된 주소는 무시됩니다.

### 뷰어와 Builder 비교


멤버의 역할은 워크스페이스 수준 권한, 즉 프로젝트에 액세스한 뒤 수행할 수 있는 작업의 종류를 결정합니다.

- **뷰어** — 읽기 전용 액세스입니다. 모든 플랜에서 무료이며 제한이 없으므로 뷰어를 원하는 만큼 초대할 수 있습니다. 새 초대의 기본 역할입니다.
- **Builder** — 콘텐츠를 만들고 편집할 수 있습니다. Builder는 플랜의 빌드 시트 한도에 포함됩니다(Free 플랜에는 1개가 포함됩니다).

초대 양식에는 역할을 전환할 때마다 갱신되는 시트 사용량 안내가 표시되어, 선택한 역할이 무료인지 빌드 시트를 사용하는지, 그리고 플랜에 시트가 몇 개 포함되어 있는지 알려 줍니다. 플랜의 Builder 시트 한도에 도달하면 Builder를 초대하거나 기존 멤버를 Builder로 승격할 수 없습니다. 뷰어는 모든 플랜에서 무료이며 제한이 없으므로 영향을 받지 않습니다. Builder를 더 초대해야 하면 관리자에게 시트 추가를 요청하십시오.

### 신규 멤버 환영 이메일


새 멤버를 추가하면 제공된 이메일 주소로 환영 이메일이 전송됩니다. 단, 워크스페이스가 싱글 사인온을 강제하는 경우에는 설정할 암호가 없으므로 이메일이 전송되지 않으며, 새 멤버는 ID 공급자를 통해 직접 로그인합니다. 이메일에는 **Set your password** 링크가 하나 포함되어 있습니다. 새 멤버가 이 링크를 클릭해 암호를 정하고 로그인하면 되며, 일회용 코드를 먼저 요청하는 별도의 단계는 없습니다. 이 링크는 안전하고, 한 번만 사용할 수 있으며, 24시간 후에 만료됩니다. 사용하기 전에 만료되면 멤버가 로그인 페이지에서 새 링크를 요청할 수 있습니다. 환영 이메일이 전달되지 않으면 PlaidCloud가 자동으로 다시 시도하므로 새 멤버가 조용히 로그인하지 못하는 일은 없습니다. **환영 이메일 다시 보내기**는 멤버 목록에서 새 환영 이메일을 보냅니다. 이미 암호를 설정했거나 로그인한 멤버에게는 사유가 표시되며 거부됩니다. 전송에 실패하면 성공 메시지 대신 실패 알림이 표시됩니다. 환영 이메일은 새 멤버의 PlaidCloud 사용과 관련된 추가 정보를 제공하도록 사용자 지정할 수 있습니다.



**환영 이메일을 업데이트하거나 확인하려면:**


1. ID를 엽니다
2. “멤버” 탭을 선택합니다
3. 드롭다운 메뉴에서 “환영 이메일 메시지”를 클릭합니다
4. 원하는 내용을 추가하거나 변경합니다
5. “업데이트” 버튼을 클릭합니다

## 워크스페이스 관리자 변경

워크스페이스 관리자만 다른 워크스페이스 관리자를 변경하거나 다른 사람을 관리자로 지정할 수 있습니다. 여기에는 관리자의 세부 정보나 이메일 주소 편집, 암호 재설정 또는 설정, 비활성화, 다시 활성화 또는 삭제, 세션 종료, 보안 그룹 변경, 그룹에 추가하거나 그룹에서 제거하는 작업이 포함됩니다. 관리자가 아닌 멤버는 거부되며, 멤버를 관리할 권한이 있더라도 프로젝트 또는 에이전트 서비스 계정(예: 사용자 정의 함수가 실행되는 계정)도 거부됩니다. 이러한 변경은 워크스페이스 관리자만 수행할 수 있다는 메시지와 함께 거부됩니다.

관리자가 아닌 멤버에 대한 변경은 멤버를 관리할 권한이 있는 누구나 이전과 같이 수행할 수 있습니다.

## ID 워크스페이스

**ID**는 왼쪽의 레일과 그 옆에서 선택한 페이지로 구성되어 열립니다. 페이지를 열 수 없는 멤버에게는 해당 항목이 표시되지 않습니다. 각 페이지의 맨 위에는 제목과 짧은 부제가 있으며, 작업은 그 옆의 머리글에 있습니다.

| 레일 섹션 | 항목 |
|---|---|
| **ID** | **개요**, **멤버**, **디렉터리**, **보안 그룹**, **배포 목록** |
| **보안** | **세션**, **보안 로그**, **API 클라이언트**, **Group audit**, **All scopes** |
| **인사이트** | **사용 현황 보고서**, 레일 옆의 페이지로 열립니다 |

**개요**에는 **멤버**, **활성**, **Never signed in**, **Builder seats**, **Signed in now** 타일, **활성 멤버** 차트, **조치 필요**, 지난 7일간의 **Recent security events**가 표시됩니다. **조치 필요**에는 로그인한 적이 없는 멤버가 **환영 이메일 다시 보내기**와 함께, 그리고 다시 살펴볼 만한 액세스가 **검토**와 함께 나열됩니다. **Invite member**는 페이지 머리글에 있습니다. 불러올 수 없는 수치는 그 사실을 알리고 **다시 시도**를 제공합니다.

**멤버**에는 목록 위에 **모두**, **활성**, **비활성** 선택 항목이 있으며, **Seat** 열에 **Builder** 또는 **뷰어**가 표시됩니다. **멤버**와 **보안 그룹** 옆의 레일 개수는 개요에서 이미 읽은 정보를 기준으로 합니다.

## 멤버 페이지

멤버 또는 **Invite member**를 선택하면 해당 멤버가 페이지로 열립니다. 이 페이지에는 다음 카드가 있습니다.

- **프로필**: 이름과 로그인 세부 정보이며, **편집**으로 변경합니다.
- **액세스**: 멤버의 **Seat**(**Builder** 또는 **뷰어**), **작업 영역 관리자** 액세스, 서비스 계정을 위한 **MFA exemption**입니다.
- **Groups and data**: 멤버의 보안 그룹, 행 액세스, Git 액세스입니다.

**세션**과 **작업** 메뉴는 페이지 머리글에 있습니다. **작업**에는 **환영 이메일 다시 보내기**, **암호 재설정**, **로그인 기록**, **삭제**가 있습니다. 저장하지 않은 변경 사항이 있는 상태로 페이지를 벗어나면 PlaidCloud가 변경 사항을 취소할지 묻습니다.

## 멤버 편집 및 삭제

멤버 양식을 저장하거나 삭제하는 동안에는 두 번 클릭해도 중복 제출되지 않도록 버튼이 비활성화됩니다. 멤버를 삭제하면 확인 대화 상자가 표시되고 멤버 목록이 새로 고쳐집니다. 양식을 이미 닫았더라도 마찬가지입니다.

## 멤버 세션 보기 및 관리


**현재 멤버 세션을 보려면:**


1. ID를 엽니다
2. 레일의 **보안** 아래에서 **세션**을 선택합니다. 특정 멤버의 세션을 보려면 해당 멤버의 페이지에서 **세션**을 선택합니다

이 테이블에서 세션 정보(현재 세션과 마지막 활동)를 확인할 수 있으며, 필요한 경우 세션을 종료할 수도 있습니다.



**세션을 종료하려면:**


1. 로그아웃시킬 멤버를 강조 표시합니다
2. **선택한 세션 종료**를 클릭합니다

## 배포(distro) 목록 관리


배포 목록(Distro)은 PlaidCloud 내에서 관리되는 이메일 배포 목록입니다. 보고서, 파일 및/또는 기타 정보를 그룹에 빠르고 쉽게 보낼 수 있습니다. 배포 목록 기능을 사용하면 워크스페이스별로 목록을 관리할 수 있습니다. 따라서 대상 독자를 과도하게 포함하거나 누락할 수 있는 외부 목록에 의존할 필요가 없습니다.



**목록을 관리하려면:**


1. ID를 엽니다
2. 레일에서 **배포 목록**을 선택합니다
3. **New list** 버튼을 클릭하여 새 목록을 만듭니다
4. 배포 목록 양식의 모든 필수 필드를 작성합니다
5. “만들기” 버튼을 클릭합니다

<Aside>배포 목록에는 워크스페이스 멤버와 비멤버를 모두 포함할 수 있습니다</Aside>



**각 목록의 워크스페이스 멤버를 관리하려면:**


1. 테이블에서 워크스페이스 아이콘(구름)을 선택합니다
2. 비멤버를 관리하려면 지구본 아이콘을 클릭합니다.

## 문자 알림 상태

멤버 페이지의 **프로필** 카드에는 **문자 알림** 상태가 표시됩니다. 마스킹된 번호와 함께 표시되는 **수신 동의함**, **수신 동의 안 함**, **수신 거부함** 중 하나입니다. 읽기 전용입니다. 멤버는 사용자 메뉴의 **문자 알림**에서 직접 수신 동의 및 거부를 설정합니다. [문자 알림](/ko/guides/workflows/text-alerts/)을 참조하십시오.
