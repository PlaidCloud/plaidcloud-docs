Identity 탭에는 PlaidCloud가 안전한 멤버 플랫폼을 보장하기 위해 중점을 두는 보안 및 인증 기능이 모여 있습니다. PlaidCloud는 세 가지 인증 유형을 제공합니다. 다음과 같습니다.


* 비밀번호만 사용
* 2단계 인증
* Single Sign-On

기본 인증 유형은 비밀번호만 사용하는 방식입니다. 다만 2단계 인증도 활성화할 수 있습니다. Single Sign-On SAML 인증 공급자를 사용할 수 있다면 PlaidCloud 조직이 Single Sign-On을 사용하도록 구성할 수 있습니다.

개인 계정을 만들면 기본 인증 유형은 비밀번호만 사용하는 방식입니다. 이를 2단계 인증으로 변경하려면 2단계 인증 섹션의 절차를 참조하십시오.

<Aside>보안상의 이유로 또는 워크스페이스의 멤버를 관리하기 위해 일부 멤버에게 Identity 탭에 대한 액세스 권한이 있을 수 있습니다. 신규 멤버나 액세스 권한이 없는 멤버의 보안 및 인증을 관리하는 방법은 기본 “Identity” 페이지에서 확인할 수 있습니다.</Aside>


## 비밀번호 변경

2단계 인증 또는 비밀번호만 사용하는 인증을 쓰는 멤버는 오른쪽 위의 “Member” 메뉴(Gravatar 아이콘)에서 간단하게 비밀번호를 변경할 수 있습니다.


**비밀번호를 변경하려면 다음과 같이 하십시오.**

1. 오른쪽 위의 아이콘(Gravatar)을 선택합니다.


	* “Member” 메뉴 아이콘은 사용자마다 다릅니다.
2. 드롭다운 메뉴에서 “Change Password”를 클릭합니다.
3. 요청하는 위치에 현재 비밀번호를 입력합니다.
4. 요청하는 위치에 새 비밀번호를 입력합니다.
5. 확인을 위해 비밀번호를 다시 입력합니다.
6. “Update” 버튼을 클릭하여 저장합니다.

<Aside>강력한 비밀번호만 허용되며, 새 비밀번호는 현재 비밀번호와 달라야 합니다.</Aside>


## 로그아웃


로그아웃하려면 오른쪽 위의 아이콘(Gravatar)을 선택하고 드롭다운 메뉴에서 “Sign Out”을 클릭합니다.

로그아웃하면 PlaidCloud 세션이 종료되고 로그아웃 페이지로 이동합니다. PlaidCloud로 돌아가려면 다시 로그인하십시오.

<Aside>다음에 PlaidCloud로 돌아오면 다시 로그인하라는 요청이 표시됩니다.</Aside>

관리자는 로그아웃할 때 ID 공급자와의 Single Sign-On 세션도 함께 종료하도록 PlaidCloud를 선택적으로 구성할 수 있습니다.


## 비밀번호만 사용하는 인증

비밀번호만 사용하는 인증은 길고 복잡한 비밀번호를 쓰더라도 가장 단순하고 보안성이 가장 낮은 옵션입니다. 보안 위험에 크게 신경 쓰지 않고 빠르고 편리하게 액세스하려는 경우에 적합할 수 있습니다. 비밀번호만 사용하는 인증은 여전히 널리 쓰이지만, 대신 2단계 인증을 사용할 것을 적극 권장합니다.


## 2단계 인증


2단계 인증(다단계 인증)은 “알고 있는 것”(비밀번호)과 “가지고 있는 것”(액세스 키)을 모두 요구하므로 비밀번호만 사용하는 방식보다 보안이 크게 향상됩니다. 즉, 비밀번호만으로는 액세스할 수 없습니다.

비밀번호는 악의적인 행위자가 액세스 권한을 얻는 데 필요한 정보가 *하나*뿐이므로 보안 위협에 취약합니다. 2단계 인증은 로그인할 때 *추가 정보*를 요구하여 보안을 강화합니다. 이러한 이유로 PlaidCloud뿐만 아니라 2단계 인증을 지원하는 다른 웹사이트에서도 계정의 안전을 위해 2단계 인증을 사용할 것을 **강력히** 권장합니다.


### 2단계 인증 사용 설정


**2단계 인증을 사용 설정하고 인증 코드 환경설정을 지정하려면 다음과 같이 하십시오.**


1. 오른쪽 위의 아이콘(Gravatar)을 선택합니다.
2. 드롭다운 메뉴에서 “Manage Multi-Factor Authentication”을 클릭합니다.
3. 원하는 2단계 인증 코드 전달 방식을 선택합니다.

### 2단계 인증 유형

PlaidCloud는 이 추가 정보를 받는 세 가지 방법을 제공합니다.

* 스마트폰 앱 사용(예: Google Authenticator, Authy, Okta, FreeOTP 등)
* 문자 메시지(SMS) 사용
* Yubico의 YubiKey 사용 http://yubico.com

### 스마트폰 기반 인증


스마트폰 앱으로 코드를 받으려면 [iOS](https://itunes.apple.com/us/app/google-authenticator/id388497605?mt=8) 또는 [Android](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2) 기기에 Google Authenticator 같은 인증 앱을 다운로드해야 합니다. 사용할 수 있는 호환 인증 앱은 이 밖에도 있지만, 이 문서는 Google Authenticator 앱을 사용한다고 가정합니다.

앱을 다운로드한 후 앱을 열고 앱 안의 설정 안내를 따르십시오.


**인증 앱 설정이 끝나면 다음과 같이 하십시오.**


1. “+” 버튼을 탭합니다.
2. “Scan barcode”를 선택합니다.
3. PlaidCloud에서 Gravatar 아이콘 아래의 “Manage Multi-Factor Authentication”을 엽니다.
4. PlaidCloud에서 “Configure Authenticator”를 선택합니다.
5. 메시지가 표시되면 휴대폰으로 PlaidCloud에 표시된 QR 코드를 스캔합니다.
6. QR 코드를 스캔하면 인증 앱에 30초마다 바뀌는 6자리 인증 코드가 표시됩니다.
7. 이전 단계에서 열어 둔 PlaidCloud “Configure SmartPhone Authentication” 화면 하단의 텍스트 상자에 이 코드를 입력합니다.
8. “Verify.”를 선택합니다.
9. 코드가 유효하면 계정에 2단계 인증이 사용 설정되고 백업 코드 목록이 표시됩니다.
10. 사용 설정한 후 “Manage Multi-Factor Authentication”을 다시 선택하면 백업 코드를 확인하거나 2단계 인증을 사용 중지할 수 있습니다.

### SMS 기반 인증


**SMS 기반 인증을 사용하려면 다음과 같이 하십시오.**


1. PlaidCloud에서 Gravatar 아이콘 아래의 “Manage Multi-Factor Authentication”을 엽니다.
2. PlaidCloud에서 “Configure SMS”를 선택합니다.
3. 휴대폰 번호와 통신사를 입력합니다.
4. “Submit”을 클릭합니다.
5. 인증 코드가 담긴 문자 메시지가 전송됩니다.
6. PlaidCloud에 나타나는 창에 이 코드를 입력합니다.
7. 코드가 유효하면 계정에 2단계 인증이 사용 설정되며, 이후 로그인할 때마다 SMS로 다른 코드가 전송되어 입력해야 합니다.
8. 사용 설정한 후 “Manage Multi-Factor Authentication”을 다시 선택하면 연락처 정보를 업데이트하거나 2단계 인증을 사용 중지할 수 있습니다.

### YubiKey 인증


Yubico에서 제조한 하드웨어 인증 장치인 YubiKey를 사용하는 경우, 멤버는 계정에 YubiKey를 최대 5개까지 등록할 수 있습니다. 워크스페이스 액세스 보안을 담당하는 사람이 관리할 수 있는 PlaidCloud YubiKey 관리형 풀이 있으며, 멤버가 일반 YubiKey를 직접 사용할 수도 있습니다.

<Aside>PlaidCloud YubiKey 풀의 키(PlaidCloud에서 특별히 발급한 YubiKey)도 5개 제한에 포함됩니다.</Aside>

YubiKey 인증을 사용 설정하려면 먼저 YubiKey를 하나 이상 등록해야 합니다.



**YubiKey를 등록하려면 다음과 같이 하십시오.**


1. 오른쪽 위의 아이콘(Gravatar)을 선택합니다.
2. 드롭다운 메뉴에서 “Change Registered YubiKeys”를 클릭합니다.
3. “My Registered YubiKeys” 양식의 빈 칸에 커서를 놓습니다.
4. 컴퓨터에 YubiKey를 꽂습니다.
5. YubiKey의 일회용 비밀번호(OTP) 버튼을 누릅니다.
6. OTP가 입력되면 양식의 “Update” 버튼을 클릭하여 저장합니다.

YubiKey를 하나 이상 등록한 후에는 계정에 맞게 구성할 수 있습니다.


**YubiKey를 구성하려면 다음과 같이 하십시오.**


1. Gravatar 아이콘을 선택합니다.
2. “Manage Multi-Factor Authentication”을 클릭합니다.
3. “Configure YubiKey”를 선택합니다.
4. 제공된 양식에 YubiKey OTP 중 하나를 입력합니다.

OTP가 유효하면 계정에 2단계 인증이 사용 설정되며, 이후 로그인할 때마다 YubiKey OTP를 입력해야 합니다.



### PlaidCloud YubiKey 풀


관리형 YubiKey 풀을 사용하면 워크스페이스 멤버의 2단계 인증을 손쉽게 관리할 수 있습니다. 관리형 키에는 PlaidCloud 로고가 새겨져 있으며, 멤버에게 직접 배송하거나 관리자에게 일괄 배송할 수 있습니다.



관리형 풀은 개별 YubiKey에 비해 다음과 같은 장점이 있습니다.


* 분실한 키를 쉽게 교체할 수 있으며 멤버가 복구 코드를 보관할 필요가 없습니다.
* 키 할당은 클릭만으로 할 수 있습니다. 멤버가 키를 등록할 필요가 없습니다.
* 클릭만으로 YubiKey 할당을 확인하고 키를 해제할 수 있습니다.
* 새 키를 주문하여 멤버에게 직접 배송할 수 있습니다.
* 관리형 YubiKey는 YubiKey OTP를 허용하는 다른 서비스와 완벽하게 호환됩니다.
* 멤버가 교체되더라도 보안을 해치지 않고 YubiKey를 다른 멤버에게 다시 할당할 수 있습니다.

**새 키를 주문하려면 다음과 같이 하십시오.**


1. Identity를 엽니다.
2. “Security” 탭을 선택합니다.
3. 드롭다운 메뉴에서 “PlaidCloud Security Keys”를 클릭합니다.
4. 양식에서 “Order More Keys” 버튼을 클릭합니다.

관리형 키를 주문하면 관리형 키 테이블에 표시됩니다.



키 할당 양식에서 키를 할당하거나, 할당 해제로 표시하거나, 분실로 표시할 수 있습니다. 또한 각 키에는 키 발급과 관련된 메모를 기록하기 위한 메모를 첨부할 수 있습니다. 이렇게 하려면 편집 아이콘을 클릭하고 원하는 대로 조정하면 됩니다.



관리형 키는 일회성 비용입니다. 사용에 따른 추가 비용은 없습니다. 관리형 YubiKey는 개당 30달러이며 배송비는 별도입니다.



## 복구 코드의 역할


보안상의 이유로, 휴대폰이나 YubiKey를 분실한 경우 PlaidCloud 지원팀은 2단계 인증이 사용 설정된 계정의 액세스 권한을 즉시 복원할 수 없습니다. 복구 코드를 사용하면 휴대폰이나 YubiKey를 분실하더라도 계정에 액세스한 다음 다시 구성할 수 있습니다.



2단계 인증을 성공적으로 설정하면 무작위로 생성된 복구 코드 세트가 제공되며, 이를 확인하고 저장해야 합니다. 복구 코드는 즉시 저장하는 것이 좋습니다. 다만 이 코드는 2단계 인증을 사용 설정한 후 언제든지 다운로드할 수 있습니다. 자세한 내용은 [2단계 인증 복구 코드 다운로드](https://plaidcloud.com/docs/identity/downloading-your-two-factor-authentication-recovery-codes)를 참조하십시오.


<Aside>백업 코드나 백업 키를 등록하지 않았다면 훨씬 더 엄격한 절차가 진행되며, 액세스 요청의 진위를 확인하고 PlaidCloud 보안을 유지하기 위해 며칠이 걸릴 수 있습니다.</Aside>



### YubiKey 분실


프로필에 SMS 번호를 제공할 수 있습니다. 등록한 YubiKey 세트와 복구 코드에 모두 액세스할 수 없게 되면 백업 SMS 번호로 계정에 다시 들어갈 수 있습니다.


<Aside>이 과정은 자동화되어 있지 않으므로 액세스를 복구하는 데 시간이 걸릴 수 있습니다.</Aside>


멤버가 관리형 풀의 키를 사용하다가 분실한 경우, 워크스페이스 풀 관리자가 해당 키를 분실로 표시하고 새 키를 발급할 수 있습니다. 이렇게 하면 계정에서 잠기거나 복구 코드를 보관해야 할 위험이 줄어듭니다.



키를 분실로 표시하려면:


1. Identity를 엽니다.
2. “Security”를 선택합니다.
3. “PlaidCloud Security Keys”를 클릭합니다.
4. 편집 아이콘을 클릭합니다.
5. Key Usage Information 섹션에서 “Lost”를 선택합니다.
6. “Update”를 클릭합니다.

그러면 키가 분실로 표시되고 새 키를 발급할 수 있습니다.



## Single Sign-On


Single Sign-On은 실제 인증 과정을 외부 서비스가 수행하며, PlaidCloud는 긍정 또는 부정 응답만 받습니다. Single Sign-On을 사용하면 여러 애플리케이션에 걸친 비밀번호 관리 부담을 줄이고, 직원이 퇴사하거나 액세스 제한이 적용될 때 멤버를 올바르게 관리할 수 있습니다.



Single Sign-On은 멤버가 사용하기 가장 쉬운 옵션입니다. 외부 업체가 사용하는 인증 과정만큼 안전합니다. Single Sign-On을 사용하면 비밀번호가 최신 상태로 유지되고 멤버가 사용하는 다른 서비스와 동기화됩니다.



Single Sign-On은 내부적으로 더 광범위한 인증 과정이 필요하고 보통 IT 또는 네트워크 보안 부서와의 기술적 협의가 필요하지만, 누구나 사용할 수 있으며 일반적으로 대기업과 학술 기관에서 주로 사용합니다.



Single Sign-On을 설정하고 관리하는 방법은 [조직 및 워크스페이스 관리 영역](/ko/administration/access/advanced/managing-single-sign-on-for-organization)을 참조하십시오.
