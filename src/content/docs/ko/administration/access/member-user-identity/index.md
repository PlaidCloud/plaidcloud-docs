PlaidCloud에서는 화면 왼쪽에 있는 “Identity” 탭이라는 한곳에서 인증과 역할 기반 보안을 쉽게 제어할 수 있습니다. Identity는 멤버 관리, 보안, 다양한 유형의 인증 과정을 위한 기반을 제공합니다.

멤버 관리에는 현재 멤버 보기, 신규 멤버 추가부터 단체 이메일 발송까지 모든 작업이 포함됩니다.

보안은 PlaidCloud의 우선순위입니다. Identity 탭의 보안 영역에서는 보안 감사를 수행하고, 보안 그룹과 신규 멤버를 위한 기본 보안 그룹을 설정하며, 각 멤버에게 허용된 보안 수준을 제어할 수 있습니다.

인증은 보안의 출발점입니다. PlaidCloud는 대부분의 사용 사례를 지원하도록 여러 인증 옵션을 제공합니다.

* 비밀번호만 사용
* 2단계 인증
* Single Sign-On
