## 설명


특정 워크플로를 예약하면 업무를 체계적으로 관리하는 데 유용하므로 PlaidCloud는 이 기능을 제공합니다. 이벤트 스케줄러를 사용하면 월, 일, 요일, 시, 분을 기준으로 워크플로가 실행되도록 예약할 수 있으며, 일정을 해석할 시간대도 지정할 수 있습니다.



예약된 이벤트는 한 프로젝트의 워크플로 하나와 해당 워크플로가 실행되는 일정으로 구성됩니다. 여러 워크플로를 같은 주기로 실행하려면 워크플로마다 이벤트를 하나씩 추가합니다.



Events Table에는 워크스페이스의 모든 이벤트가 실행하는 프로젝트와 워크플로, UTC 오프셋, 마지막 실행의 상태와 시작 및 종료 시간, 다음 실행 예정 시간과 함께 나열됩니다.



**이벤트를 보려면 다음과 같이 하십시오.**


1. Analyze를 엽니다.
2. “Tools”를 선택합니다.
3. “이벤트 스케줄러”를 클릭합니다.

그러면 워크스페이스에 구성된 모든 현재 이벤트를 보여 주는 **Events Table**이 열립니다.

<Aside>이벤트가 활성 상태이면 “활성” 아이콘이 표시됩니다.</Aside>

## 이벤트 만들기


**이벤트를 만들려면 다음과 같이 하십시오.**


1. Analyze를 엽니다.
2. “Tools”를 선택합니다.
3. “이벤트 스케줄러”를 클릭합니다.
4. “Add Scheduled Event”를 클릭합니다.
5. 아래에 설명된 세부 정보, 시간대, 일정 필드를 작성합니다.
6. “Create”를 클릭합니다.

### 세부 정보


**이름** — 이벤트가 Events Table에 표시되는 방식입니다. 필수 항목입니다.



**메모** — 이벤트의 용도에 대한 선택적 메모입니다.



**작업을 활성화하고 정의된 일정에 따라 실행** — 기본적으로 선택되어 있습니다. 선택을 해제하면 이벤트가 실행되지 않게 하면서 저장할 수 있습니다. [이벤트 일시 중지](#이벤트-일시-중지)를 참조하십시오.



**프로젝트**와 **워크플로** — 이 이벤트가 실행하는 워크플로입니다. 프로젝트를 먼저 선택하십시오. 워크플로 목록은 선택한 프로젝트를 기준으로 채워집니다. 둘 다 필수 항목이며, 이벤트를 만든 후에는 둘 다 변경할 수 없습니다. 이벤트를 다른 워크플로로 옮기려면 이벤트를 삭제하고 새로 추가하십시오.



### 시간대


일정은 이 시간대를 기준으로 해석되며, **UTC -12**부터 **UTC +14**까지의 오프셋으로 선택합니다. 기본값은 **UTC +0**이며, 영국 하계 표준시를 포함한 런던 시간으로 해석됩니다.



대부분의 오프셋은 해당 오프셋에 있는 지역의 현지 시간이며 그 지역의 일광 절약 시간제를 따릅니다. 예를 들어 **UTC -5**에서 09:00으로 설정한 이벤트는 여름과 겨울 모두 뉴욕 시간 09:00에 실행되며, 이는 여름에는 UTC 13:00, 겨울에는 UTC 14:00입니다. **다음 실행** 열과 [예정된 실행 캘린더](/ko/administration/scheduled-events/upcoming-runs-calendar/)에서 이벤트가 실제로 실행되는 시점을 확인할 수 있습니다.

### 일정


일정은 **월**, **시간**, **분**, **일(월 기준)**, **요일**의 다섯 개 필드로 구성되며, 각 필드는 맨 위에 **모두** 상자가 있는 체크박스 목록입니다. 현재 시간이 모든 필드에서 동시에 선택한 값과 일치할 때마다 이벤트가 실행됩니다.



모든 필드에 값이 있어야 합니다. 모든 값과 일치시키려면 **모두**를 선택하고, 그렇지 않으면 원하는 개별 값을 선택하십시오. 필드를 완전히 비워 두면 이벤트가 저장되지 않으며, 메시지에 해당 필드 이름이 표시되므로 쉽게 찾을 수 있습니다.



몇 가지 예시는 다음과 같습니다.


- **매일 06:30** — 월, 일(월 기준), 요일에서 **모두**, 시간에서 **06**, 분에서 **30**.
- **매월 1일 자정** — 월과 요일에서 **모두**, 일(월 기준)에서 **01**, 시간과 분에서 **00**.
- **평일 매일 18:00** — 월과 일(월 기준)에서 **모두**, 요일에서 월요일부터 금요일, 시간에서 **18**, 분에서 **00**.
- **15분마다** — 월, 일(월 기준), 요일, 시간에서 **모두**, 분에서 **00**, **15**, **30**, **45**.

<Aside>새 이벤트는 아무것도 선택되지 않은 상태로 시작하므로 일정을 선택하기 전에는 실행되지 않습니다.</Aside>


### ERP 전기 모드

각 이벤트에는 자체 [ERP 전기 모드](/ko/guides/workflows/run-a-workflow/#전기-모드-선택)(**실거래**, **시뮬레이션**, **끄기**)가 있으며, 이벤트가 시작하는 모든 실행에 이 모드가 사용됩니다. 모드가 설정되지 않은 이벤트는 실거래로 실행되며, 프로젝트 자체의 전기 모드 상한도 그 위에 계속 적용되므로 이벤트가 프로젝트에서 허용하는 것보다 자유롭게 전기할 수는 없습니다.

모드는 API 또는 AI 어시스턴트를 통해 설정합니다. `PUT /rest/v1/analyze/workflow/scheduled-event`의 `erp_write_mode` 필드(`live`, `simulate`, `off`)를 사용하거나 `workflow_schedule` MCP 도구의 업서트에서 설정합니다. 이후에는 이벤트가 이 값을 유지합니다. 이벤트 스케줄러에서 이벤트를 편집하거나 일시 중지하거나 다시 사용 설정해도 모드는 그대로 유지되므로, 시뮬레이션으로 설정된 일정은 모드 자체를 변경하기 전까지 실행될 때마다 시뮬레이션으로 유지됩니다.

## 이벤트 편집


**이벤트를 편집하려면 다음과 같이 하십시오.**


1. Analyze를 엽니다.
2. “Tools”를 선택합니다.
3. “이벤트 스케줄러”를 클릭합니다.
4. 편집 아이콘을 클릭합니다.
5. 원하는 필드를 조정합니다.
6. “업데이트”를 클릭합니다.

편집하는 동안 프로젝트와 워크플로는 읽기 전용으로 표시됩니다. 이벤트는 만들 때 지정한 워크플로에 계속 연결됩니다.

AI 어시스턴트는 새 이름이나 일정처럼 변경할 필드만 보내는 방식으로 `workflow_schedule` MCP 도구를 통해 이벤트를 편집할 수 있습니다. 생략한 모든 필드는 현재 값을 유지합니다.

## 이벤트 삭제


**이벤트를 삭제하려면 다음과 같이 하십시오.**


1. Analyze를 엽니다.
2. “Tools”를 선택합니다.
3. “이벤트 스케줄러”를 클릭합니다.
4. 삭제 아이콘을 클릭합니다.
5. 삭제를 다시 한 번 클릭합니다.

<Aside type="note">
워크플로를 삭제하면 해당 워크플로에 예약된 모든 이벤트도 함께 삭제됩니다. 이벤트를 먼저
제거할 필요가 없으며, 더 이상 존재하지 않는 워크플로를 실행하려고 남아 있는 이벤트도
없습니다. 다른 워크플로에 예약된 이벤트는 영향을 받지 않습니다.
</Aside>

## 이벤트 일시 중지


**이벤트를 하나 이상 일시 중지하려면 다음과 같이 하십시오.**


1. Analyze를 엽니다.
2. “Tools”를 선택합니다.
3. “이벤트 스케줄러”를 클릭합니다.
4. 이벤트를 하나 이상 선택합니다.
5. “Disable Selected”를 클릭합니다.

**선택 항목 사용**을 클릭하면 다시 실행되기 시작합니다. 일시 중지된 이벤트는 일정과 실행 기록을 그대로 유지하며, 다시 사용 설정하기 전까지 실행되지 않을 뿐이고, Events Table에서 **활성** 아이콘이 해제됩니다.



이벤트를 편집하면서 하나만 일시 중지할 수도 있습니다. **작업을 활성화하고 정의된 일정에 따라 실행**의 선택을 해제하고 **업데이트**를 클릭합니다.



## 필요할 때 이벤트 실행


**이벤트를 즉시 실행하려면 다음과 같이 하십시오.**


1. Analyze를 엽니다.
2. “Tools”를 선택합니다.
3. “이벤트 스케줄러”를 클릭합니다.
4. 원하는 이벤트를 하나 이상 선택합니다.
5. “Run Selected Events”를 클릭합니다.

각 이벤트는 자체 [ERP 전기 모드](#erp-전기-모드)로 실행되므로 시뮬레이션 이벤트는 시뮬레이션으로 실행됩니다. 워크플로가 이미 실행 중인 이벤트는 건너뛰며, 실행 후 메시지에는 시작된 이벤트만 집계됩니다.
