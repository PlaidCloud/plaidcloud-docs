## 설명

**예정된 실행** 캘린더는 예약된 워크플로가 다음에 실행되는 시점을 보여 주는 읽기 전용 미리 보기입니다. 실제 실행을 구동하는 것과 동일한 일정을 펼쳐서 보여 주므로, 캘린더에 표시되는 내용이 곧 실행될 내용이며 아무것도 트리거하지 않습니다.

이 캘린더는 Events 테이블만으로는 답할 수 없는 두 가지 질문에 답합니다.

- **모든 작업이 언제 실행되는가?** 사용 설정된 모든 일정의 예정된 실행을 하나의 화면에서 확인합니다.
- **실행이 충돌하는가?** 각 실행은 워크플로의 일반적인 소요 시간에 맞춘 막대로 표시되고 나란히 배치되므로 실행 기간이 겹치는 경우를 쉽게 알 수 있습니다.

<Aside type="note">캘린더는 워크플로를 시작하지 않습니다. 스케줄러에서 예정된 실행 시점을 읽고 과거 실행 기록을 바탕으로 각 실행의 길이를 추정합니다. 막대 길이는 추정값이며 추정값임이 표시됩니다.</Aside>

## 보기

세 가지 보기 중에서 전환합니다.

- **월** — 한 달 동안 예정된 실행을 보여 주는 캘린더 격자입니다.
- **주** — 한 번에 한 주씩 보여 주며, 실행이 시작되는 요일과 시간에 배치됩니다.
- **일정** — 예정된 실행을 시간순으로 나열한 목록입니다.

**이전**, **다음**, **오늘**을 사용하여 시간을 이동하고, **새로 고침**으로 최신 실행 시점을 다시 가져오고, **필터…** 로 특정 일정만 보도록 좁힙니다.

<Aside>시간은 각 일정 자체의 시간대로 표시됩니다. 워크스페이스에 서로 다른 시간대로 구성된 일정이 있을 수 있으므로 캘린더에 이를 알리는 안내가 표시됩니다.</Aside>

## 캘린더 읽기

- **막대**는 예약된 실행을 나타내며, 막대가 길수록 일반적인 실행 소요 시간이 깁니다.
- 같은 시간대에 **나란히 놓인 막대**는 해당 실행이 겹친다는 뜻이며, 같은 리소스나 데이터를 두고 경쟁한다면 일정을 엇갈리게 조정하라는 신호입니다.
- 표시되는 범위에 예약된 항목이 없으면 **No upcoming scheduled runs**가 나타납니다.

센서(이벤트 기반 트리거)는 이벤트에 반응하여 실행되고 정해진 미래 시점이 없으므로 표시되지 **않습니다**.

## 범위

캘린더는 열린 위치에 맞게 달라집니다.

- **워크스페이스 전체 또는 프로젝트 전체** — 사용 설정된 모든 일정의 예정된 실행을 함께 보여 주는 종합적인 충돌 해소 보기입니다.
- **단일 일정** — 해당 일정의 예정된 실행만 보여 주는 집중형 일정 팝오버입니다.
