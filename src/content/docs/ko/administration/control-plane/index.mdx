PlaidCloud 컨트롤 플레인은 조직과 워크스페이스를 관리하는 파트너 관리자와 고객 관리자를 위한 공간입니다. 컨트롤 플레인에서 워크스페이스를 만들고, 워크스페이스 소유권을 지정하고, 릴리스 동작을 선택하고, 워크스페이스 서비스를 사용 설정하고, 브랜딩을 구성하고, 조직 수준의 액세스를 관리할 수 있습니다.

<Aside type="note">
	PlaidAdmin 영역은 PlaidCloud 운영 담당자 전용입니다. 이 가이드는 파트너 및 고객 관리 영역만 다룹니다.
</Aside>

## 탐색

로그인한 후 왼쪽 탐색 메뉴를 사용합니다.

1. **Organizations**를 열어 관리 중인 조직을 확인하거나 편집합니다.
2. **Trust Center**를 열어 관리 중인 조직에 대한 PlaidCloud의 보안 문서를 다운로드합니다.
3. **Workspaces**를 열어 관리할 수 있는 워크스페이스를 확인, 생성, 편집, 일시 중지, 일시 중지 해제하거나 일괄 업데이트합니다.
4. 프로필 메뉴를 사용하여 계정 프로필을 업데이트하거나 로그아웃합니다.

표시되는 작업은 조직 역할에 따라 달라집니다. 예를 들어 워크스페이스 액세스 권한이 있는 사용자는 조직의 워크스페이스를 관리할 수 있고, 보안 액세스 권한이 있는 사용자는 초대와 역할을 관리할 수 있습니다.

## 역할

조직 액세스는 다음 역할로 제어됩니다.

| 역할 | 허용 범위 |
| --- | --- |
| 관리자 | 조직 설정을 편집하고 조직 수준의 관리 작업을 수행합니다. |
| 워크스페이스 | 조직에서 워크스페이스를 만들고, 편집하고, 일시 중지하고, 일시 중지 해제하고, 삭제하고, 버전을 관리합니다. |
| 보안 | 사용자를 초대하고, 사용자를 제거하고, 조직 역할을 편집합니다. |
| 청구 | 청구 액세스가 사용 설정된 경우 청구 정보를 확인합니다. |

역할은 조직 액세스 대화 상자에서 할당합니다. 대기 중인 초대는 초대받은 사람이 수락하면 활성화됩니다.
