조직은 관련된 PlaidCloud 워크스페이스의 관리 경계입니다. 조직 설정은 컨트롤 플레인에 표시되는 이름, 결제 메타데이터, SSO 동작, 조직을 관리할 수 있는 사람을 제어합니다.

## 조직 목록

**Organizations** 페이지에는 액세스할 수 있는 조직이 표시됩니다. 테이블에서 다음 작업을 할 수 있습니다.

1. 표시되는 테이블 필드로 조직을 검색합니다.
2. 조직 목록을 새로 고칩니다.
3. 조직 세부 정보를 봅니다.
4. 관리자 액세스 권한이 있으면 조직 설정을 편집합니다.
5. 보안 액세스 권한이 있으면 조직 액세스 관리를 엽니다.
6. 결제 액세스 권한이 있으면 결제 기록을 엽니다.

## 조직 설정

| 설정 | 설명 |
| --- | --- |
| 이름 | 조직의 표시 이름입니다. |
| ID | 변하지 않는 조직 식별자입니다. 조직을 만들 때 설정됩니다. |
| 메모 | 컨트롤 플레인에 표시되는 내부용 메모 또는 설명입니다. |
| 요금제 | 상용 요금제: Enterprise, Team 또는 Free입니다. |
| 세금 ID | 결제 기록에 사용되는 세금 식별자입니다. |
| 활성 | 조직이 활성 상태인지 여부입니다. |
| 잠금 | 사용 설정된 동안 일반적인 조직 변경을 막습니다. |
| SSO 필수 | 멤버가 조직의 Single Sign-On 구성을 통해 로그인하도록 요구합니다. |

## 결제 메타데이터

결제 필드는 조직에 요금이 청구되는 방식을 설명합니다. 그 자체로 제품 액세스 권한을 부여하지는 않습니다.

| 설정 | 옵션 |
| --- | --- |
| 결제 주기 | 월간, 분기, 반기, 연간 |
| 결제 가격 | 선택한 주기에 대한 숫자 결제 금액입니다. |
| 결제 유형 | PO 청구, 무료 체험, 무료, 예약 결제 |

## SSO 동작

| 설정 | 설명 |
| --- | --- |
| 동적 그룹 할당 | SSO 그룹 정보로 조직 역할을 할당할 수 있게 합니다. |
| 동적 사용자 생성 | ID 공급자가 허용된 사용자를 보낼 때 SSO 로그인으로 사용자를 자동으로 만들 수 있게 합니다. |
| SSO 동적 그룹 할당 이름 | 동적 할당에 사용되는 SSO 그룹 이름입니다. |

<Aside type="note">
	워크스페이스의 ID 공급자는 해당 워크스페이스의 [Single sign-on 대화상자](/ko/administration/control-plane/workspace-configuration/#single-sign-on)에서 설정합니다. SAML 설정은 액세스 관리 가이드에 설명되어 있습니다. 이러한 컨트롤 플레인 설정은 SSO 구성이 만들어진 후 조직이 이를 사용하는 방식을 결정합니다.
</Aside>

## 액세스 관리

**Manage Access**를 사용하여 사람들을 조직에 초대하고 조직 역할을 할당합니다.

1. **Organizations**를 엽니다.
2. 조직을 선택합니다.
3. **Manage Access**를 엽니다.
4. **Invite User**를 클릭하여 하나 이상의 이메일 주소를 초대합니다.
5. 각 사람이 받아야 할 역할을 선택합니다.
6. 필요하면 사용자 지정 메시지를 추가합니다.
7. 초대를 보냅니다.

수락한 사용자의 역할을 편집하거나, 수락한 사용자를 제거하거나, 보류 중인 초대를 취소할 수 있습니다. 보류 중인 사용자는 초대를 수락하기 전에는 편집할 수 없습니다.

## 조직 역할

| 역할 | 사용 용도 |
| --- | --- |
| 관리자 | 조직 설정 및 관리자 수준 변경. |
| 워크스페이스 | 워크스페이스 생성, 구성, 릴리스, 일시 중지, 일시 중지 해제 작업. |
| 보안 | 초대 및 조직 역할 관리. |
| 결제 | 결제 기록 액세스. |
