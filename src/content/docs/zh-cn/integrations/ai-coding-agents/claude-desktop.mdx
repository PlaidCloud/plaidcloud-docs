面向消费者的 Claude 应用（[claude.ai](https://claude.ai) 的网页界面和桌面应用）通过其 **Custom Connectors** 功能支持 MCP 服务器。设置只需进行一次 OAuth 授权，之后该连接会与您的 Claude 账户关联，并跟随您在各设备间使用。

<Aside>Custom Connectors 适用于 Claude Pro、Max、Team 和 Enterprise 套餐。Team 和 Enterprise 管理员可以为工作区中的所有人固定连接器。</Aside>

## 设置

1. 在 Claude（网页版或桌面版）中，打开**设置 → 连接器**。
2. 点击 **Add custom connector**。
3. 填写：
   - **名称**：`PlaidCloud`（如果有多个租户，可使用 `PlaidCloud (prod)`、`PlaidCloud (dev)`）。
   - **服务器 URL**：`https://<your-workspace>.plaid.cloud/mcp`
4. 点击**添加**。Claude 会打开浏览器标签页，转到 PlaidCloud 的 Keycloak 登录页。
5. 登录，然后批准随后出现的 **Application Access Request** 页面。该页面列出发出请求的应用程序以及将向其发送凭据的重定向 URI，批准之前请检查两者是否与 Claude 一致。您将被重定向回 Claude，连接已保存。

该连接器现在可用于任何对话。使用聊天输入框中的连接器选择器开启或关闭它。

## 使用

启用后，您可以向 Claude 提出这样的问题：

- “列出项目 `Q4 Forecast` 中的工作流。”
- “显示 `daily-load` 工作流最近 10 次失败的运行。”
- “运行 `mcp_recipes`，并选出适合回填某个步骤的那一个。”

Claude 会选择合适的 MCP 工具，调用它，并将响应整合到回复中。对于会产生变更的操作，它通常会说明即将执行的内容，批准之前请仔细审阅。

## 多个租户

为每个租户添加单独的连接器。为它们指定不同的名称，使 Claude 在对话中能够区分。对于某个聊天，只有您开启的连接器可用，因此默认关闭生产环境、只在确有把握时才启用，是一个合理的安全习惯。

## 刷新访问权限

自定义连接器会存储 OAuth 刷新令牌，因此很少需要重新验证身份。如果您更改了 PlaidCloud 密码、换了新设备，或您的会话在服务器端失效，连接器可能会显示“needs authentication”。请在连接器设置中点击 **Reconnect** 重新执行 OAuth 流程。

## 断开连接

设置 → 连接器 → 点击该连接器 → **移除**。这会删除随您的 Claude 账户存储的 OAuth 令牌。PlaidCloud 一侧的会话是独立的，如果要使底层的 Keycloak 会话失效，请单独退出 PlaidCloud。
