将 AI 助手连接到 PlaidCloud 的 [MCP 服务器](../getting-started/)，然后请它基于项目中的某个表或视图生成图表，甚至整个仪表板。只需 PlaidCloud 连接器即可，无需其他连接器。助手以您的身份构建，因此只能为您本来就能打开的数据制作图表，[行访问](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)也像在其他地方一样生效。

> 基于 Sales Results 表绘制*按月净收入*图表，然后将其放到名为 Sales Overview 的新仪表板上。

## 开始之前

- **先发布表。** 图表只能基于在 PlaidCloud 中已发布的表或视图构建。如果尚未发布，助手会提示您先发布，然后再重新提问。
- **先打开一次仪表板站点。** 从未打开过仪表板站点的成员，必须在第一次请求之前打开一次。在此之前，助手会报告您的账户尚未设置。
- **使用已登录的连接。** 图表和仪表板必须由您自己连接并登录的助手构建。Microsoft 365 Copilot、PlaidCloud 的应用内助手、工作流步骤和服务账户都无法构建。

## 图表

请求图表时，说明要衡量什么以及如何拆分。助手会自行选择表、图表类型和设置。

| 设置 | 作用 |
| --- | --- |
| **类型** | `table`、`bar`、`line`、`pie` 或 `big_number`。 |
| **指标** | 一个列以及汇总方式：`SUM`、`COUNT`、`AVG`、`MIN`、`MAX` 或 `COUNT_DISTINCT`。`SUM` 和 `AVG` 需要数值列。 |
| **X** | 条形图或折线图的类别列或时间列。为 `big_number` 图表指定该列时，会添加趋势线。 |
| **时间粒度** | 按 `day`、`week`、`month`、`quarter` 或 `year` 对时间列分组。 |
| **分组依据** | 用于拆分数字的列。饼图只接受一列。 |
| **筛选器** | 一个列、一个比较运算符（`=`、`!=`、`>`、`<`、`>=`、`<=`、`LIKE`、`ILIKE`、`NOT LIKE`、`IN` 或 `NOT IN`）和一个值。`IN` 和 `NOT IN` 接受一个列表。 |

助手会返回图表的链接及其数据样本。在依赖该图表之前，请让助手对照您的问题检查样本。

### 编辑图表

助手通过传入 `chart_id` 来编辑您拥有的图表。如果不传入，重复的请求会再创建一个图表，因此请告诉助手编辑它刚刚创建的图表，而不是重新创建。

### 计算度量

图表构建器只对列进行汇总。如需计算度量（例如利润率或单位收入），请先在 PlaidCloud [视图](../getting-started/#标签与视图)中将其添加为列，发布该视图，再为该列制作图表。可以让助手为您创建视图。

## 仪表板

可以请助手用您已构建的图表生成仪表板。

- **新仪表板**会以项目的**默认仪表板受众**发布。如果项目未设置受众，项目中的所有人都能看到它。要更改可查看的人员，请参阅[控制谁可以查看仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)。
- **添加到现有仪表板**仅适用于您拥有的仪表板，且绝不会移除其上已有的图表。如果部分图表未能添加，请让助手针对其余图表再次运行该请求。
- **每个仪表板对应一个项目。** 仪表板上的所有图表必须来自同一个项目。如需使用第二个项目，请构建第二个仪表板。

<Aside>
  受众设置会对不应看到仪表板的人隐藏该仪表板。每个图表中的数据仍遵循项目访问权限和行访问。
</Aside>

## 出现问题时

| 消息 | 操作 |
| --- | --- |
| 表未发布 | 在 PlaidCloud 中发布该表或视图，然后重新提问。 |
| 您的账户尚不存在 | 打开一次仪表板站点，然后重新提问。 |
| 不是该图表或仪表板的所有者 | 您只能编辑自己拥有的图表和仪表板。请改为请求新建一个。 |
| 列或聚合无效 | 检查列名，并且只对数值列使用 `SUM` 或 `AVG`。 |
| 服务超时 | 图表或仪表板可能已经创建。请先查看仪表板站点，再重新提问。 |
