ChatGPT 对用户自行添加 MCP 服务器的支持仍在逐步推出，因套餐层级和使用界面而异。本页介绍目前可行的做法。

## ChatGPT Pro / Plus / Team：连接器

如果您的 ChatGPT 套餐提供了**连接器**界面（设置 → 连接器），您可以将 PlaidCloud 添加为自定义 MCP 连接器：

1. 转到**设置 → 连接器 → Add custom connector**。
2. 输入：
   - **名称**：`PlaidCloud`
   - **MCP 服务器 URL**：`https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT 会将您重定向到 PlaidCloud 进行 OAuth 登录。登录后，PlaidCloud 会显示 **Application Access Request** 页面，列出发出请求的应用程序以及将向其发送凭据的重定向 URI。批准之前，请检查这些信息是否与 ChatGPT 一致。
4. 在任何需要使用该连接器的对话中，将其开启。

<Aside>连接器界面可能并非在每个账户或每个地区都可见。如果您没有看到“Add custom connector”，说明您的套餐或工作区策略目前不允许用户添加 MCP 服务器，请使用下面的变通方法。</Aside>

## ChatGPT Enterprise

Enterprise 管理员可以通过管理控制台在工作区级别固定 MCP 连接器。请按照与上文相同的 OAuth 设置进行操作，但连接器可用之前，需要管理员进行工作区审批。

## 变通方法：使用 REST 操作的自定义 GPT

如果您的账户不支持自定义 MCP 连接器，您仍然可以通过**自定义 GPT**从 ChatGPT 驱动 PlaidCloud，该 GPT 会将 PlaidCloud 的 REST API 作为 OpenAPI 操作来调用：

1. PlaidCloud 的 REST 接口由 `https://<your-tenant>.plaidcloud.org/openapi_rest.json` 处的 OpenAPI 文档描述。
2. 在 ChatGPT 中创建自定义 GPT（Explore GPTs → Create），并在**操作**下导入该 URL（或粘贴 JSON）。
3. 将身份验证配置为 **OAuth**，并指向 PlaidCloud 的 Keycloak 端点。您的 PlaidCloud 管理员可以提供 realm URL 和客户端 ID。

这是用直接的 REST 端点换取 MCP 的工具命名约定：模型浏览起来稍显冗长，但对于 PlaidCloud 提供的读取和写入操作，功能上是等效的。

## 为什么 MCP 并不总是可用

OpenAI 的 MCP 支持仍在不断演进，可用的界面（连接器界面、操作架构等）会因套餐层级而异，也会随时间变化。如果官方的**连接器**路径在您的账户上可用，请优先使用它：它内置 OAuth 刷新，并且工具调用体验与本节其余部分一致。只有在您的账户尚未开放 MCP 时，才需要退而使用自定义 GPT 操作。
