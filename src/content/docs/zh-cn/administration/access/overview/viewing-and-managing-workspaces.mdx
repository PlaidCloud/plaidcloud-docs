工作区使组织能够作为自己的云服务运行，适用于从小型到大型的各类组织。例如，小型团队的组织中可能只有一个工作区，而大型组织则可能拥有数百个专用工作区。



工作区管理访问和可见性，同时为组织的成员提供相互隔离的操作区域。工作区访问权限在组织的私有多租户环境中分配给成员。借助工作区，团队可以在某些工作区中就公开项目开展协作，同时在其他工作区中保持严格的机密性。



由于工作区之间完全隔离，数据无法在工作区之间直接共享或访问。不过，各工作区可以访问同一个共享的“文档”区域，因此如有需要，也可以在工作区之间共享文件。



## 查看和管理工作区


查看和管理组织内的工作区很简单。必须是组织所有者才能管理工作区。查看和管理工作区的步骤：


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”

这将打开一个表，显示组织内当前的所有工作区。在这里可以创建、更新、暂停和删除工作区，向工作区添加应用，以及管理成员对各工作区的访问。



### 创建工作区


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”
3. 单击“New Workspace”按钮
4. 填写必填字段
5. 单击“Submit”

<Aside>默认情况下，创建工作区的成员会被自动分配到该工作区。</Aside>


### 更新工作区


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”
3. 单击所需工作区的编辑图标
4. 根据需要调整字段
5. 单击“Submit”

### 暂停工作区


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”
3. 取消勾选所需工作区的“Active”复选框
4. 单击“Submit”

### 删除工作区


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”
3. 单击所需工作区的删除图标
4. 再次单击“Delete”

<Aside>删除是永久性操作。此过程将删除工作区及其所有关联数据。执行前请确保已备份所需的全部内容。</Aside>


### 管理工作区中可用的应用


默认情况下，新工作区会自动添加三个应用：Analyze、Document 和 Identity。Identity 对于管理工作区内的访问和角色至关重要，因此无法移除，而 Analyze 和 Document 可以移除。管理工作区中可用的应用（包括自定义应用）的步骤：


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”
3. 单击要修改关联应用的工作区的应用图标
4. 如果要移除应用，请单击要移除的应用的删除图标并确认删除
5. 如果要添加新应用，请单击 **Add App to Workspace** 按钮，选择要添加的应用，勾选 **Enable for Use** 复选框，然后单击 create 按钮
