虽然成员可能与组织内的其他工作区相关联，但每个工作区都有自己的访问限制。成员必须获得权限才能查看和访问工作区。



## 添加成员


添加成员的步骤：


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”
3. 单击成员图标
4. 选择所需成员并将其拖到相应的列中
5. 单击“Submit”

<Aside>要将成员添加到工作区，该成员必须属于组织并显示在成员管理表单中。如果要添加未显示在成员管理表单中的成员，必须先邀请该成员加入工作区。</Aside>



发送邀请的步骤：


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”
3. 单击邀请图标

此操作会向该成员发送电子邮件邀请。成员随后需要单击邮件中的链接，并按说明登录；如果是 PlaidCloud 新用户，则需创建账户。成功登录后，该成员将被添加到工作区。



## 移除成员


移除成员的步骤：


1. 从浏览器右上角的菜单中选择“Organization Settings”
2. 单击“Workspaces”
3. 单击成员图标
4. 选择所需成员并将其拖到相应的列中
5. 单击“Submit”
