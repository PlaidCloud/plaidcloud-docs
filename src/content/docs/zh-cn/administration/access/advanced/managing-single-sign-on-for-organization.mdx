每个组织都可以拥有自定义 URL（[https://plaidcloud.com/sso](https://plaidcloud.com)/`<custom_name_here>`），成员通过该地址访问您在配置中指定的单点登录页面。

<Aside>单点登录使用 SAML 2.0 协议，并通过用户界面进行设置。</Aside>

<Aside type="tip">如需让工作区的成员使用 Microsoft Entra ID、Okta 或其他 OpenID Connect 提供商登录，请使用 **Workspaces** 页面上的引导式 **Single sign-on** 对话框（企业单点登录包含在付费方案中；带 MFA 的密码登录和社交登录适用于所有方案）。请参阅[单点登录](/zh-cn/administration/control-plane/workspace-configuration/#单点登录)。</Aside>

创建自定义 URL 的步骤：

1. 从屏幕右上角选择“Organization Settings”菜单
2. 点击“Single Sign-On Security Credentials”
3. 按需调整单点登录 URL
4. 点击“Update Organization SSO Settings”

## 允许自动创建用户

启用单点登录后，可以选择根据成功的单点登录身份验证自动创建成员。新成员将获得组织设置中指定的默认工作区和安全角色。自动创建成员的步骤：

1. 从屏幕右上角选择“Organization Settings”菜单
2. 点击“Organization and User Settings”
3. 勾选“Create Users Automatically from Single Sign-On”复选框
4. 选择所需的默认工作区

使用此功能可大幅简化成员管理，因为新成员无需在 PlaidCloud 中进行任何额外设置即可自动获得访问权限。同样，如果成员从单点登录服务中被移除，他们将无法再访问 PlaidCloud。


## 允许通过单点登录分配安全组

启用单点登录后，可以选择在肯定的身份验证消息中同时传递分组关联列表。列表中的各项将用于把成员分配到指定的分组，并将其从未指定的分组中移除。借助 Active Directory 或其他 LDAP 服务等中央用户管理服务，这是管理安全组分配的有效方式。


<Aside>如果成员在工作区中被标记为管理员，则无论通过此自动化流程为其分配了何种具体角色，他们都将继续拥有该工作区的完全访问权限。</Aside>


如果启用此选项，将在成员下次登录时使用所提供的列表分配安全角色。如果禁用此选项，现有成员将保留其当前的安全角色，直到在 PlaidCloud 中手动更新。
