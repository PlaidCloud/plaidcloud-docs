PlaidCloud 通过位于屏幕左侧的“身份”选项卡，在一个集中的位置轻松控制身份验证和基于角色的安全。“身份”是成员管理、安全以及各类身份验证流程的基础。

成员管理涵盖从查看现有成员、添加新成员到发送群发电子邮件的全部内容。

安全是 PlaidCloud 的重中之重。“身份”选项卡中的“安全”子集可用于执行安全审计、设置安全组和新成员的默认安全组，并控制每位成员获准的安全级别。

身份验证是安全的起点。PlaidCloud 提供多种身份验证选项，以支持大多数使用场景：

* 仅密码
* 双因素身份验证
* 单点登录
