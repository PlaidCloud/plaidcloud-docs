组织是相关 PlaidCloud 工作区的管理边界。组织设置控制控制平面中显示的名称、账单元数据、SSO 行为，以及谁可以管理该组织。

## 组织列表

**组织**页面显示您可以访问的组织。在该表中可以：

1. 按可见的表字段搜索组织。
2. 刷新组织列表。
3. 查看组织详细信息。
4. 拥有管理员访问权限时，编辑组织设置。
5. 拥有安全访问权限时，打开组织访问管理。
6. 拥有账单访问权限时，打开账单记录。

## 组织设置

| 设置 | 说明 |
| --- | --- |
| 名称 | 组织的显示名称。 |
| ID | 稳定的组织标识符，在创建组织时设置。 |
| 备注 | 控制平面中显示的内部备注或说明。 |
| 计划 | 商业计划：Enterprise、Team 或 Free。 |
| 税号 | 用于账单记录的税务标识符。 |
| 活动 | 组织是否处于活动状态。 |
| 已锁定 | 启用后，将阻止对组织进行常规更改。 |
| 要求 SSO | 要求成员通过组织的单点登录配置登录。 |

## 账单元数据

账单字段描述组织的计费方式，其本身不授予产品访问权限。

| 设置 | 选项 |
| --- | --- |
| 计费周期 | 每月、每季度、每半年、每年 |
| 计费价格 | 所选周期的数值计费金额。 |
| 付款类型 | PO 发票、免费试用、免费、计划付款 |

## SSO 行为

| 设置 | 说明 |
| --- | --- |
| 动态分组分配 | 允许由 SSO 分组信息驱动组织角色的分配。 |
| 动态用户创建 | 当身份提供商发送了被接受的用户时，允许 SSO 登录自动创建用户。 |
| SSO 动态分组分配名称 | 用于动态分配的 SSO 分组名称。 |

<Aside type="note">
	在工作区的[单点登录对话框](/zh-cn/administration/control-plane/workspace-configuration/#单点登录)中为工作区设置身份提供商；SAML 设置记录在访问管理指南中。这些控制平面设置决定组织在 SSO 配置建立之后如何使用该配置。
</Aside>

## 管理访问权限

使用**管理访问权限**邀请人员加入组织并分配组织角色。

1. 打开**组织**。
2. 选择该组织。
3. 打开**管理访问权限**。
4. 单击**邀请用户**，邀请一个或多个电子邮件地址。
5. 选择每个人应获得的角色。
6. 添加可选的自定义消息。
7. 发送邀请。

可以编辑已接受邀请的用户的角色、移除已接受邀请的用户，或取消待处理的邀请。待处理的用户在接受邀请之前无法编辑。

## 组织角色

| 角色 | 用途 |
| --- | --- |
| 管理员 | 组织设置和管理员级别的更改。 |
| 工作区 | 创建、配置、发布、暂停和取消暂停工作区的操作。 |
| 安全 | 邀请和组织角色管理。 |
| 账单 | 账单记录访问。 |
