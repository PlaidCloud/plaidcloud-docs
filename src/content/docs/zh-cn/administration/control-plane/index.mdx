PlaidCloud 控制平面面向管理组织和工作区的合作伙伴管理员和客户管理员。可用它创建工作区、指定工作区所有者、选择发布行为、启用工作区服务、配置品牌设置，以及管理组织级别的访问权限。

<Aside type="note">
	PlaidAdmin 区域供 PlaidCloud 运维人员使用。本指南仅涵盖合作伙伴和客户管理区域。
</Aside>

## 导航

登录后，使用左侧导航：

1. 打开**组织**，查看或编辑您管理的组织。
2. 打开**工作区**，查看、创建、编辑、暂停、取消暂停或批量更新您可管理的工作区。
3. 使用个人资料菜单更新账户个人资料或退出登录。

您看到的操作取决于您的组织角色。例如，拥有工作区访问权限的用户可以管理组织的工作区，而拥有安全访问权限的用户可以管理邀请和角色。

## 角色

组织访问权限由以下角色控制：

| 角色 | 允许的操作 |
| --- | --- |
| 管理员 | 编辑组织设置并管理组织级别的管理事务。 |
| 工作区 | 创建、编辑、暂停、取消暂停、删除组织中的工作区并管理其版本。 |
| 安全 | 邀请用户、移除用户以及编辑组织角色。 |
| 账单 | 在启用账单访问权限时查看账单信息。 |

角色通过组织访问对话框分配。待处理的邀请在被邀请人接受后生效。
