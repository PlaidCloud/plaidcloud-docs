PlaidCloud 控制平面面向管理组织和工作区的合作伙伴管理员与客户管理员。可使用它创建工作区、分配工作区所有权、选择发布行为、启用工作区服务、配置品牌，以及管理组织级访问权限。

<Aside type="note">
	PlaidAdmin 区域仅供 PlaidCloud 运营人员使用。本指南只涵盖合作伙伴和客户管理区域。
</Aside>

## 导航

登录后，使用左侧导航：

1. 打开 **Organizations** 查看或编辑您管理的组织。
2. 打开 **Trust Center** 为您管理的组织下载 PlaidCloud 的安全文档。
3. 打开 **Workspaces** 查看、创建、编辑、暂停、恢复或批量更新您可管理的工作区。
4. 使用个人资料菜单更新账户个人资料或退出登录。

可执行的操作取决于您的组织角色。例如，具有工作区访问权限的用户可以管理组织的工作区，而具有安全访问权限的用户可以管理邀请和角色。

## 角色

组织访问权限由以下角色控制：

| 角色 | 允许的操作 |
| --- | --- |
| 管理员 | 编辑组织设置并管理组织级管理事务。 |
| 工作区 | 创建、编辑、暂停、恢复、删除组织中的工作区并管理其版本。 |
| 安全 | 邀请用户、移除用户和编辑组织角色。 |
| 账单 | 启用账单访问后可查看账单信息。 |

角色通过组织访问对话框分配。待处理的邀请在被邀请者接受后生效。
