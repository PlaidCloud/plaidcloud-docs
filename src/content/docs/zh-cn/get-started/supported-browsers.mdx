PlaidCloud 在网页浏览器中运行，无需安装任何软件。需要使用下列浏览器之一，且版本不低于所列版本。

## 最低版本

| 浏览器 | 最低版本 |
| --- | --- |
| Google Chrome | 94 |
| Microsoft Edge | 94 |
| Mozilla Firefox | 93 |
| Mac 上的 Safari | 16.4 |
| iPad 或 iPhone 上的任何浏览器 | iPadOS 或 iOS 16.4 |

大多数浏览器会自动更新，因此保持最新的浏览器版本远高于上述要求。

## iPad 和 iPhone

iPad 或 iPhone 上的浏览器应用（包括 Chrome 和 Firefox）都基于 Safari 的引擎构建。这里起决定作用的是设备的 iPadOS 或 iOS 版本，而不是您使用哪个浏览器应用。要更新系统，请打开**设置** > **通用** > **软件更新**。

<Aside type="caution">
iPad Air 2 和 iPad mini 4 无法更新到 iPadOS 15 以上的版本，因此 PlaidCloud 无法在这些设备上运行。请改用电脑或较新的 iPad。
</Aside>

## 旧版浏览器会显示什么

旧版浏览器无法加载 PlaidCloud，而是显示一个 **PlaidCloud needs a newer browser** 页面，其中列出上述版本。请更新浏览器，或改用此处列出的浏览器之一打开 PlaidCloud。
