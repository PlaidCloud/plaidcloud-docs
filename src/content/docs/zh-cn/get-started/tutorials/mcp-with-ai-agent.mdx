本教程使用 **Model Context Protocol**（MCP）将 AI 编码代理连接到 PlaidCloud 工作区。配置完成后，可以直接在编辑器中让代理读取表、运行工作流、构建分摊，并回答有关数据的问题。

大约需要 20 分钟。适用于 Claude Code、Cursor、Claude Desktop、ChatGPT、GitHub Copilot 以及任何兼容 MCP 的客户端。

## 您将构建的内容

在 AI 编码代理与 PlaidCloud 工作区之间建立可用的连接，代理可以：

- 列出项目、表、工作流和维度
- 读取表内容
- 检查工作流定义
- 触发工作流运行
- 无需切换上下文即可回答有关数据的问题

## 前提条件

- 一个 PlaidCloud 工作区（如果还没有，请[开始免费试用](https://app.plaidcloud.com)）
- 一个已在使用的 AI 编码代理，例如 Claude Code、Cursor、Claude Desktop、ChatGPT、Copilot 或 Gemini
- 代理必须支持 MCP（目前大多数 AI 工具都支持）

## 步骤 1：查找工作区的 MCP URL

每个 PlaidCloud 工作区都在以下位置提供 MCP 端点：

```text
https://<your-workspace>.plaid.cloud/mcp
```

将 `<your-workspace>` 替换为工作区子域名，即登录 PlaidCloud 界面时使用的子域名。

## 步骤 2：获取身份验证令牌

<Steps>

1. 在浏览器中登录 PlaidCloud 后，访问：
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. 复制页面上显示的持有者令牌。请妥善保管，它拥有与您的账户相同的访问权限。

</Steps>

<Aside type="caution">
请像对待密码一样对待该令牌。它会绕过交互式身份验证并代表您执行操作。如果令牌泄露，请在同一端点撤销。
</Aside>

## 步骤 3：配置代理

<Tabs>

<TabItem label="Claude Code">

在终端中运行：

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

如需使用静态令牌身份验证（无需 OAuth 流程，更适合长时间会话），请在浏览器中打开步骤 2 中的 URL，复制显示的配置片段，并粘贴到 `.mcp.json` 文件中。

有关完整选项，请参阅 [Claude Code 设置](/zh-cn/integrations/ai-coding-agents/claude-code/)。

</TabItem>

<TabItem label="Cursor">

从 `https://<your-workspace>.plaid.cloud/mcp/setup/token` 获取持有者令牌，并将以下内容添加到 Cursor 的 MCP 配置：

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

有关完整选项，请参阅 [Cursor 设置](/zh-cn/integrations/ai-coding-agents/cursor/)。

</TabItem>

<TabItem label="Claude Desktop">

打开“设置 → 开发者 → MCP 服务器”并添加：

- **服务器 URL**：`https://<your-workspace>.plaid.cloud/mcp`
- 出现提示时使用 OAuth 登录

有关完整选项，请参阅 [Claude Desktop 设置](/zh-cn/integrations/ai-coding-agents/claude-desktop/)。

</TabItem>

<TabItem label="ChatGPT">

1. 设置 → 连接器 → 添加自定义连接器
2. 输入：
   - **名称**：`PlaidCloud`
   - **MCP 服务器 URL**：`https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT 会将您重定向到 PlaidCloud 进行 OAuth 登录。批准该连接。
4. 在需要使用该连接器的任何对话中启用它。

有关完整选项，请参阅 [ChatGPT 设置](/zh-cn/integrations/ai-coding-agents/chatgpt/)。

</TabItem>

<TabItem label="Copilot">

获取持有者令牌，并添加到 `.vscode/mcp.json`：

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

VSCode 会在启动时和文件更改时读取该文件。

有关完整选项，请参阅 [Copilot 设置](/zh-cn/integrations/ai-coding-agents/copilot/)。

</TabItem>

</Tabs>

## 步骤 4：验证连接

向代理提一个简单的问题：

> “列出我的 PlaidCloud 工作区中的项目。”

代理应返回您的项目列表。如果没有，请查看下面的故障排除步骤。

## 步骤 5：尝试实际任务

连接成功后，可以尝试：

- **探索数据**：“我的 Quickstart 项目中的 `sales` 表有哪些列？”
- **运行工作流**：“触发 Financials 项目中的 `monthly_close` 工作流，完成后告诉我。”
- **构建内容**：“在我的 Test 工作流中创建一个 Table Lookup 步骤，将订单筛选为最近 30 天。”

代理的回答基于工作区的实际状态，而不是泛泛的通用答案。

## 故障排除

如果代理无法访问 PlaidCloud 或返回身份验证错误：

- **令牌已过期**：在 `https://<your-workspace>.plaid.cloud/mcp/setup/token` 刷新令牌
- **作用域不正确**：某些工具需要特定的 PlaidCloud 作用域（例如 `analyze.workflow.write`）。在代理中运行 `mcp_introspect(name='<tool>')` 可查看所需的作用域
- **工作区子域名错误**：登录 PlaidCloud 界面进行确认；子域名是 `.plaid.cloud` 之前的部分

更多信息请参阅 [AI 编码代理故障排除](/zh-cn/integrations/ai-coding-agents/troubleshooting/)。
