*约 20 分钟 · 安装加载项、登录、提取表、编写实时公式*

如果您的日常工作离不开电子表格，就无需离开 Excel 也能使用 PlaidCloud。**PlaidXL** 是适用于 Excel 的 PlaidCloud 加载项：它可以将项目表提取到工作表中，按需刷新，并提供可直接基于 PlaidCloud 数据计算汇总值的公式。完成本教程后，您的输入将来自权威的项目表，而不再是复制粘贴得来的数据——后者在有人重新运行工作流的那一刻就已过时。

## 您将完成的内容

1. 安装 PlaidXL 加载项。
2. 登录并选择项目。
3. 将表检索到工作表中，然后刷新。
4. 编写公式，列出项目的表并计算总计。

## 前提条件

- 适用于 Microsoft 365 的 Excel，或 Windows 或 Mac 上的 Excel 2021 及更高版本。
- 一个 PlaidCloud 账户。如果您的 PlaidCloud 使用单点登录，在此处继续使用即可——PlaidXL 通过同一身份登录。
- 一个可以打开的项目，其中至少有一个含数据且带有数值列的表。您有权访问的任何项目都可以。如果还没有，可参阅[从 CSV 到答案](/zh-cn/get-started/tutorials/csv-to-answer/)，将表导入 PlaidCloud。

<Aside>PlaidXL 以您的权限读取数据。您只能看到您的账户在 PlaidCloud 中已有权查看的项目和表，不会更多；只有在您保存回表并确认后，PlaidXL 才会更改表。</Aside>

## 步骤 1：安装加载项

1. 在 Excel 中，打开**插入 → 加载项**。（在较早的 Mac 版本中，为**插入 → 应用商店**。）
2. 在搜索框中输入 `PlaidCloud`。
3. 选择 **PlaidCloud** 加载项，然后单击**添加**。

功能区上会出现 **PlaidCloud** 选项卡。每台计算机只需安装一次，无需为每个工作簿分别安装。

<Aside type="tip">没有看到 **PlaidCloud** 选项卡？请关闭所有 Excel 窗口，然后重新打开 Excel。如果您的组织管理加载项，可能需要由 Microsoft 365 管理员为您部署。请参阅[安装 PlaidXL](/zh-cn/reference/cli/plaidxl/install/)。</Aside>

## 步骤 2：登录并选择项目

1. 打开一个新工作簿，单击 **PlaidCloud → 打开 PlaidXL**。
2. 输入您用于 PlaidCloud 的电子邮件地址，然后单击**登录**。
3. 如果您属于多个工作区，请从**选择工作区**中选择一个，然后单击**登录**。
4. 在 Excel 提示时允许弹出窗口，并按平时的方式登录——密码加双重验证码，或单点登录。

任务窗格的标题栏会显示您的工作区。单击标题栏中的项目名称以打开项目列表，然后单击您的项目。工作簿会记住该项目。项目的表显示在**表**选项卡上。

## 步骤 3：检索表

1. 在**表**选项卡上，单击一个表。**行**和**列**会显示其大小。
2. 在**列**下，清除不需要的列。列越少，加载越快。
3. 保持选中**匹配的工作表**，然后单击**检索表**。

表会落在以其命名的新工作表上，可以直接使用：粗体标题行在滚动时始终可见，每列都有筛选器，数据上还有一个命名区域。名为 **Sample data** 的表会落在工作表 `Sample_data` 上，命名区域为 `_Sample_data`，因此使用该区域的公式会随数据增长而自动调整。

您可以像在任何工作表上一样，针对它构建公式、数据透视表和图表。

## 步骤 4：刷新

当 PlaidCloud 中的表发生变化时——例如工作流重新运行、加载了新数据——请单击任务窗格或功能区中的**刷新所有表**。刷新期间工作表选项卡会变为黄色，数据最新时变为绿色。您已检索到工作簿中的每个表都会刷新，并保留您所选的列和筛选器。

## 步骤 5：编写实时公式

任务窗格负责将表复制进来。PlaidXL 公式则更进一步：它们可以在任意单元格中基于 PlaidCloud 数据进行计算。

1. 在新工作表的 `A1` 中，列出项目的表：

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   表名会向下溢出到 A 列。

2. 在 `C1` 中列出您的表的列，并将 `Sample data` 替换为您的表名：

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. 从该列表中选择一个数值列，再选择一个文本列，并确保其中包含一个您已知存在的值。针对该值对数值列求和，并将名称替换为您自己的：

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` 显示**区域**为 **EMEA** 的行的**金额**总计——在 PlaidCloud 中计算，在您的工作表中实时显示。更改 `E3` 中的值，总计也会随之变化。

当该列链接到[维度](/zh-cn/guides/dimensions/dimensions/)时，值可以是其中的任意节点，总计会汇总该节点下的所有内容。PlaidXL 报表就是这样从明细行汇总出区域、部门或年度的总计。
