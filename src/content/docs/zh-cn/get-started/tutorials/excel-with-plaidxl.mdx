*约 20 分钟 · 安装加载项、登录、提取表、编写实时公式*

如果您的日常工作已经离不开电子表格，就无需离开 Excel 来使用 PlaidCloud。**PlaidXL** 是 PlaidCloud 的 Excel 加载项：它可将项目表提取到工作表中，按需刷新，并提供直接基于 PlaidCloud 数据计算汇总值的公式。完成本教程后，您的输入将来自权威的项目表，而不再是复制粘贴得来、在有人重新运行工作流的那一刻就过期的数据。

## 您将完成的操作

1. 安装 PlaidXL 加载项。
2. 登录并选择项目。
3. 将表检索到工作表中，然后刷新。
4. 编写公式，列出项目的表并计算总计。

## 前提条件

- 适用于 Microsoft 365 的 Excel，或 Excel 2021 及更高版本，Windows 或 Mac 均可。
- 一个 PlaidCloud 账户。如果您使用单点登录访问 PlaidCloud，在这里也请继续使用，PlaidXL 通过同一身份登录。
- 一个可以打开的项目，其中至少有一张含数据且有数值列的表。您已有权访问的任何项目都可以。如果还没有，[从 CSV 到答案](/zh-cn/get-started/tutorials/csv-to-answer/)可帮助您将表导入 PlaidCloud。

<Aside>PlaidXL 以您的权限读取数据。您只能看到自己的账户在 PlaidCloud 中已能看到的项目和表，不会更多，而且 PlaidXL 绝不会更改它们。</Aside>

## 步骤 1：安装加载项

1. 在 Excel 中，打开 **Insert → Add-ins**。（在较旧的 Mac 版本中为 **Insert → Store**。）
2. 在搜索框中输入 `PlaidCloud`。
3. 选择 **PlaidCloud** 加载项，然后点击 **Add**。

功能区上会出现 **PlaidCloud** 选项卡。每台计算机只需安装一次，而不是每个工作簿都安装。

<Aside type="tip">没有看到 **PlaidCloud** 选项卡？请关闭所有 Excel 窗口，然后重新打开 Excel。如果您的组织管理加载项，可能需要由 Microsoft 365 管理员为您部署。请参阅[安装 PlaidXL](/zh-cn/reference/cli/plaidxl/install/)。</Aside>

## 步骤 2：登录并选择项目

1. 打开一个新工作簿，点击 **PlaidCloud → Show Taskpane**。
2. 输入用于 PlaidCloud 的电子邮件地址，然后点击 **Sign In**。
3. 如果您属于多个工作区，请从 **Select a tenant** 中选择一个，然后点击 **Sign In**。
4. Excel 提示时允许弹出窗口，并按平时的方式登录：密码加双重验证码，或单点登录。

任务窗格会显示 **Connected to** 您的工作区 ID **as** 您的用户名，其下方是您的项目。点击您的项目，其表会显示在 **Tables** 选项卡上。

## 步骤 3：检索表

1. 在 **Tables** 选项卡上，点击一张表。**Rows** 和 **Columns** 显示其大小。
2. 在 **Column** 下，清除不需要的列。列越少，加载越快。
3. 保持选中 **Matching Worksheet**，然后点击 **Retrieve Table**。

表会落在以其命名的新工作表上，可直接使用：有一个滚动时保持可见的粗体标题行、每列都有筛选器，以及覆盖数据的命名区域。名为 **Sample data** 的表会落在工作表 `Sample_data` 上，命名区域为 `_Sample_data`，因此使用该区域的公式会随数据增长而自动延伸。

您可以像在任何工作表上一样，基于它构建公式、数据透视表和图表。

## 步骤 4：刷新

当表在 PlaidCloud 中发生变化时（例如工作流重新运行、加载了新数据），请点击任务窗格或功能区中的 **Refresh All Tables**。刷新时工作表标签变为黄色，数据最新时变为绿色。您检索到工作簿中的每张表都会刷新，并沿用您所选的列和筛选器。

## 步骤 5：编写实时公式

任务窗格负责把表复制进来。PlaidXL 公式则更进一步：可以在任意单元格中基于 PlaidCloud 数据进行计算。

1. 在新工作表上，于 `A1` 中列出项目的表：

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   名称会向下溢出到 A 列。

2. 在 `C1` 中列出您的表的列，将 `Sample data` 替换为您的表名：

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. 从该列表中选择一个数值列，以及一个文本列，并选择该文本列中一个您确定存在的值。对该值汇总数值列的总计，并将名称替换为您自己的：

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` 显示 **Region** 为 **EMEA** 的行的 **amount** 总计，由 PlaidCloud 计算，并实时显示在您的工作表中。更改 `E3` 中的值，总计会随之变化。

当该列关联到[维度](/zh-cn/guides/dimensions/dimensions/)时，该值可以是维度中的任意节点，总计会汇总该节点之下的所有内容。这就是 PlaidXL 报表如何根据明细行汇总出区域、部门或年度总计。
