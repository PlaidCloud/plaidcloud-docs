*约 20 分钟 · 安装加载项、登录、拉取一个表、编写实时公式*

如果您的日常工作离不开电子表格，就不必离开 Excel 来使用 PlaidCloud。**PlaidXL** 是 PlaidCloud 的 Excel 加载项：它可以将项目表拉取到工作表中，按需刷新，并提供可直接基于 PlaidCloud 数据计算汇总值的公式。完成本教程后，您的输入将来自权威的项目表，而不是一份复制粘贴的数据——后者在有人重新运行工作流的那一刻就已过时。

## 您将完成的内容

1. 安装 PlaidXL 加载项。
2. 登录并选择一个项目。
3. 将一个表检索到工作表中，然后刷新它。
4. 编写公式，列出项目中的表并计算总计。

## 前提条件

- 在 Windows 或 Mac 上使用 Microsoft 365 版 Excel，或 Excel 2021 及更高版本。
- 一个 PlaidCloud 账户。如果您使用单点登录访问 PlaidCloud，在这里继续使用即可——PlaidXL 通过同一身份登录。
- 一个您可以打开的项目，其中至少有一个包含数据和一个数值列的表。任何您已有权访问的项目都可以。如果您还没有，可以参阅[从 CSV 到答案](/zh-cn/get-started/tutorials/csv-to-answer/)，将表导入 PlaidCloud。

<Aside>PlaidXL 以您的权限读取数据。您只能看到您的账户在 PlaidCloud 中已经能看到的项目和表，不会更多；只有在您自己向表写入时，PlaidXL 才会更改表。</Aside>

## 步骤 1：安装加载项

1. 在 Excel 中，打开 **插入 → Add-ins**。（在较旧的 Mac 版本中为 **插入 → Store**。）
2. 在搜索框中输入 `PlaidCloud`。
3. 选择 **PlaidCloud** 加载项，然后单击 **添加**。

功能区上会出现 **PlaidCloud** 选项卡。每台计算机只需安装一次，而不是每个工作簿安装一次。

<Aside type="tip">没有看到 **PlaidCloud** 选项卡？关闭所有 Excel 窗口，然后重新打开 Excel。如果您的组织统一管理加载项，可能需要由 Microsoft 365 管理员为您部署。请参阅[安装 PlaidXL](/zh-cn/reference/cli/plaidxl/install/)。</Aside>

## 步骤 2：登录并选择项目

1. 打开一个新工作簿，单击 **PlaidCloud → Open PlaidXL**。
2. 输入您用于 PlaidCloud 的电子邮件地址，然后单击 **Sign In**。如果您已使用工作账户登录 Office，PlaidXL 可能会自动找到您的工作区；请参阅[使用 Office 账户登录](/zh-cn/reference/cli/plaidxl/connect/#使用-office-账户登录)。
3. 如果您属于多个工作区，请从 **Select a workspace** 中选择一个，然后单击 **Sign In**。
4. 当 Excel 询问时允许弹出窗口，并按平时的方式登录——密码加双重验证码，或单点登录。

任务窗格的标题栏会显示您的工作区。单击标题栏中的项目名称以打开项目列表，然后单击您的项目；如果您只能打开一个项目，PlaidXL 会自动为您关联。工作簿会记住该项目。项目中的表显示在 **表** 选项卡上。

## 步骤 3：检索表

1. 在 **表** 选项卡上，单击一个表。**行** 和 **列** 显示其大小。
2. 在 **列** 下，清除不需要的列。列越少，加载越快。
3. 保持选中 **Matching Worksheet**，然后单击 **Retrieve Table**。

该表会以 Excel 表的形式出现在一个以其命名的新工作表上：名为 **Sample data** 的表会出现在工作表 `Sample_data` 上。滚动时标题行始终可见，每一列都有筛选器，引用该 Excel 表的公式会随数据增长而自动扩展。

可以像在任何工作表上一样，基于它构建公式、数据透视表和图表。

## 步骤 4：刷新

当表在 PlaidCloud 中发生变化时——工作流重新运行、加载了新数据——请单击任务窗格中的 **Refresh All Tables**，或功能区上的 **刷新 → Refresh all tables**。任务窗格会显示每个表的进度，并提供 **取消**，完成后列出已刷新的行数。您检索到工作簿中的每个表都会刷新，并沿用您所选的列和筛选器。

## 步骤 5：编写实时公式

任务窗格会将表复制进来。PlaidXL 公式则更进一步：它们可以在任意单元格中基于 PlaidCloud 数据进行计算。

1. 在新工作表的 `A1` 中，列出项目中的表：

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   表名会向下溢出到 A 列。

2. 在 `C1` 中列出您的表的列，将 `Sample data` 替换为您的表名：

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. 从该列表中选择一个数值列，再选择一个文本列，并确保其中包含一个您知道存在的值。针对该值对数值列求和，并将名称替换为您自己的：

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` 显示 **Region** 为 **EMEA** 的行的 **amount** 总计——在 PlaidCloud 中计算，在您的工作表中实时呈现。更改 `E3` 中的值，总计会随之变化。

当该列关联到[维度](/zh-cn/guides/dimensions/dimensions/)时，该值可以是维度中的任意节点，总计会汇总该节点下的所有内容。这就是 PlaidXL 报表根据明细行汇总区域、部门或年份的方式。
