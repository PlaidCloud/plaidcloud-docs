## 什么是 PlaidCloud？

PlaidCloud 是一个统一的财务分析平台。连接数据源，构建转换和合并数据的工作流，定义与业务组织方式相匹配的维度和层次结构，运行成本分摊，并将结果发布到仪表板或下游系统，所有这些都在一个平台中完成。

## 谁在使用 PlaidCloud？

主要是中大型组织的财务、FP&A 和分析团队，从事如下工作：

- **成本分摊**：基于作业的成本核算、IT 费用分摊、共享服务分配、转让定价
- **盈利能力分析**：大规模的客户 / 产品 / 渠道利润分析
- **财务合并**：跨实体和货币合并数据
- **运营报表**：基于企业数据、指标清晰且受治理的仪表板
- **数据仓库**：在运营系统之上构建统一的分析层

### 需要特定的技术背景吗？

大多数 PlaidCloud 用户是熟悉 Excel 和 SQL 基础知识的业务分析师，无需成为开发人员。平台通过可视化界面提供工作流和数据操作，并在需要时支持使用 SQL 表达式。

## 计划与定价

### 有哪些计划可选？

PlaidCloud 提供自助试用工作区、团队计划和企业计划。不同层级的计划限制、定价和功能可用性各不相同。

有关当前定价和计划详情，请访问 [plaidcloud.com](https://plaidcloud.com/) 或联系您的客户团队。

### 注册需要信用卡吗？

不需要：**免费版**计划只需验证电子邮件。没有信用卡，也没有付款步骤，验证电子邮件后即可创建工作区。（付费的**入门版**和**团队**计划提供可选的 7 天试用，会收集信用卡信息以便自动转为付费；**免费版**是永久的，从不要求提供信用卡。）

### 免费版计划有限制吗？

**免费版**计划是永久的（没有时间限制），其使用限制适合评估平台。另外，7 天的**入门版 / 团队试用**可让您在一周内完整使用这些层级。具体信息会在注册时显示。

### 以后可以切换计划吗？

可以：工作区可以升级，且不会丢失数据或破坏集成。请与您的客户团队讨论适合您情况的方案。

## 功能与限制

### 数据量可以有多大？

PlaidCloud 底层的 Lakehouse 引擎可处理从小型参考表（数百行）到数十亿行的分析数据集。对于超大型工作负载，请与您的客户团队讨论规模配置，计算资源是可配置的。

### PlaidCloud 会取代我的数据仓库吗？

可以取代。PlaidCloud Lakehouse 是完整的分析存储，既可以作为您的主数据仓库，也可以与现有数据仓库（Snowflake、BigQuery、Redshift 等）并存，并通过[连接器](/zh-cn/reference/connectors/)从中拉取数据。

### 可以在本地部署 PlaidCloud 吗？

PlaidCloud 是 SaaS 平台。要访问本地数据源，可将 [PlaidLink Agent](/zh-cn/reference/cli/plaidlink/) 安装在您的网络内部，它会把 PlaidCloud 与受防火墙保护的数据库和文件系统连接起来。

### PlaidCloud 有 API 吗？

有。API 按租户在每个工作区内提供，因此交互式 API 文档位于您的工作区中，而不是集中放在本文档站点上。对于编程集成，[Jupyter CLI](/zh-cn/reference/cli/jupyter/) 和 [PlaidLink](/zh-cn/reference/cli/plaidlink/) 中介绍的 Jupyter / CLI 访问模式是很好的起点。

## 使用产品

### 可以在 PlaidCloud 中使用 Excel 吗？

可以：[PlaidXL](/zh-cn/reference/cli/plaidxl/) 是 PlaidCloud 的 Excel 加载项。它可将项目表和维度拉取到工作表中，按需刷新，并添加根据 PlaidCloud 数据计算汇总值的公式。适合以 Excel 作为主要建模环境的分析师。[使用 PlaidXL 在 Excel 中工作](/zh-cn/get-started/tutorials/excel-with-plaidxl/)约用 20 分钟即可带您入门。

### 可以使用 Claude Code 或 Cursor 等 AI 工具吗？

可以：PlaidCloud 为每个工作区提供一个 MCP（模型上下文协议）服务器。设置方法请参阅 [AI 编码代理](/zh-cn/integrations/ai-coding-agents/)。

### 可以使用 Jupyter 笔记本吗？

可以，请参阅 [Jupyter CLI](/zh-cn/reference/cli/jupyter/)。身份验证使用 OAuth 令牌，因此同一套凭据可用于 CLI、笔记本和 REST API。

### 可以直接使用 SQL 吗？

可以：工作流在列计算、筛选器和联接中接受 SQL 表达式。[表达式参考](/zh-cn/reference/expressions/)涵盖所有可用的 SQL 函数，并按 Lakehouse 引擎版本划分。

### 如何计划工作流？

PlaidCloud 内置计划功能。请参阅[计划事件](/zh-cn/administration/scheduled-events/)。

### 工作流完成（或失败）时如何收到通知？

使用通知步骤：[电子邮件](/zh-cn/reference/workflow-steps/notifications/notify-via-email/)、[Slack](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/)、[Teams](/zh-cn/reference/workflow-steps/notifications/notify-via-microsoft-teams/)、[短信](/zh-cn/reference/workflow-steps/notifications/notify-via-sms/)或 [Webhook](/zh-cn/reference/workflow-steps/notifications/notify-via-web-hook/)。还可以配置在失败时自动运行的补救工作流。

## 安全与访问

### 权限如何管理？

PlaidCloud 在工作区级别使用**安全组**。成员被分配到分组，分组授予特定的能力。请参阅[访问管理](/zh-cn/administration/access/)。

### 可以使用单点登录（SSO）吗？

可以：PlaidCloud 支持 SAML 2.0。请参阅 [Okta](/zh-cn/administration/access/advanced/okta-saml-setup/)、[Auth0](/zh-cn/administration/access/advanced/auth0-saml-setup/)、[Microsoft Entra](/zh-cn/administration/access/advanced/entra-saml-setup/)、[Google](/zh-cn/administration/access/advanced/google-saml-setup/) 和 [AWS](/zh-cn/administration/access/advanced/aws-saml-setup/) 的设置指南。

### 我的数据存储在哪里？

PlaidCloud 数据存储在为您的租户配置的云区域中。如果有数据驻留要求，请与您的客户团队讨论特定区域的部署。

### 数据如何加密？

传输中和静态时均加密。加密密钥由平台管理；受监管行业的密钥管理选项在企业计划中提供。

## 常见陷阱

### 我的工作流步骤报错“No Rows Returned”

通常意味着筛选器或联接与预期不符。请在表资源管理器中打开源表并检查：

- 两个表中的联接键列拼写是否相同（包括大小写）？
- 键值中是否有前导/尾随空格或隐藏字符？
- 筛选条件是否比您的预期更严格？

### 我的分摊结果无法对账

分摊金额之和应等于源金额之和。如果不相等：

- **孤立的源行**：没有匹配驱动数据的源行不会被分摊。请检查每个源行是否都有驱动值。
- **缺失的目标成员**：没有驱动条目的维度成员不会获得分摊。请确认维度与驱动因素表保持同步。
- **负驱动值**：会产生意外行为。请将其筛选掉或明确处理。

请参阅[分摊故障排除](/zh-cn/guides/allocations/results/troubleshooting-allocations/)。

### 我的维度加载创建了重复成员

通常是源数据中的大小写或空白问题。维度会将“ACME Corp”和“Acme Corp”视为不同的成员。请在加载前规范化源数据，或在上游使用转换步骤对其进行清理。

### 看不到同事提到的项目

项目可见性由工作区安全组控制。请让工作区管理员将您添加到可访问该项目的分组中。
