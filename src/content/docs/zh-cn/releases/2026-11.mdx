## 新增

- **步骤表单上的预览。** 导入：SQL、执行：SQL、提取：SQL、导出：SQL 和 Salesforce 查询无需运行步骤即可显示最多 100 行，Anaplan 视图和列表读取则显示其将生成的列和类型。在**源**选项卡上点击**预览**。变量会按运行时的方式填入，但不支持 `{x:>9}` 之类的变量格式。预览只运行标准 SQL 函数；否则会提示您运行该步骤。已锁定的项目以及基于代理的执行 SQL 步骤不可使用预览。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **AI 助手可以取消发布表并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表及其已发布的视图，以及没有任何图表使用的仪表板数据集；仍被图表使用的数据集会保留，当报表视图建立在已发布的视图之上时，该视图和数据集也会保留，而表仍会被取消发布。`project_upsert` 可设置 `dashboard_default_audience`，即项目中新仪表板所共享给的分组，传入 `[]` 则清除该设置。请参阅[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

## 变更

- **步骤表单遵循统一布局。** 选项卡采用标准名称和标准顺序：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单另有表头列和行列。必填字段以 * 标记，表单只会因步骤所需的内容而阻止保存。
- **行操作菜单（⋯）位于每个网格行的最左侧。**
- **未设置验证选项的已保存 ERP 写入步骤将以仅验证模式打开。** 涵盖 SAP 过账、SAP 附件、NetSuite 过账、Oracle EBS 总账和应付账款过账以及 Xero 导出。明确设置为实际运行的步骤保持实际运行。
- **长时间运行的作业在各处以相同方式显示进度。**
- **工作区升级时，REST、导入 REST 和导入 Postman 步骤会转换为 REST 请求。** 无法干净转换的步骤保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **项目架构师可在仪表板中查看行受限表的所有行**，与其在 Analyze 中看到的一致。撤销架构师访问权限会立即在仪表板中生效——无论您是更改某人的角色、将其或其所在分组从项目中移除、更改项目的访问类型、还原项目的早期版本，还是删除安全组。前架构师不再能看到行受限数据的所有行。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
- **会话过期后打开的仪表板链接，在您登录后会带您进入该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**，并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为它的另一个名称。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。

## 修复

- **无效的项目设置现在会给出清晰的提示信息。** 未知的环境或文档账户、已被占用或保留的 slug，以及无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 时返回 400 而不是 500，通过 AI 助手或 MCP 时则为无效参数错误。
