## 新增

- **步骤表单中的预览。** Import: SQL、Execute: SQL、Extract: SQL、Export: SQL 和 Salesforce Query 无需运行步骤即可显示最多 100 行，Anaplan 视图和列表读取则会显示它们将生成的列和类型。在 **源** 选项卡上单击 **预览**。变量会按运行时的方式填充，但不支持 `{x:>9}` 这类变量格式。预览只运行标准 SQL 函数；否则会提示您运行该步骤。在已锁定的项目中，或对于基于代理的 Execute SQL 步骤，预览不可用。参见[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **使用情况报告会显示变化、可缩小到某个分组，并可流入工作流。** **概览** 新增了与上一时段对比的趋势箭头，以及指向未激活成员和无人打开的仪表板与应用的 **Highlights** 列表。**分组** 将 **概览**、**内容** 和未激活列表限定为某个安全组的成员；日期范围新增了 **Previous month** 和 **This month**，并由所有选项卡共用，且会随您的账户记住。每个数据现在都有说明，表格使用 **成员** 和 **Area** 这样的通俗名称，按 Enter 可打开行，加载和错误提示更清晰，**漏斗** 的最后一步会显示有多少成员完成了它。新的 **Get Workspace Usage** 步骤会按计划将每日或每月的使用情况合计写入表中，不含成员姓名，并且与 **Get Workspace Members** 一样，每次运行都会记录在安全日志中。参见[使用情况报告](/zh-cn/administration/access/usage-reports/)和[Get Workspace Usage](/zh-cn/reference/workflow-steps/general/get-workspace-usage/)。
- **AI 助手可以取消发布表并设置项目的默认仪表板受众。** `publish_manage` 会取消发布一个表，同时取消发布其已发布的视图以及没有图表使用的仪表板数据集；仍被图表使用的数据集会保留，当报表视图基于已发布视图构建时，该视图和数据集也会保留，但表仍会被取消发布。`project_upsert` 可设置 `dashboard_default_audience`，即项目中新仪表板所共享给的分组，`[]` 表示清除。参见[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

- **移动端 Weave 中的语音只需轻点一次。** 轻点麦克风并提出问题，停止说话后 Weave 会将其发送。再次轻点麦克风可提前停止；如果一段时间没有听到声音，它会自动关闭。如果在说话途中离开 **Weave** 选项卡或将应用切换到后台，您说的话会保留在问题框中而不发送，以便您检查。运行、暂停、停止和恢复会忽略对其确认按钮的误触双击。需要应用版本 1.3.0 或更高版本。参见[使用语音](/zh-cn/guides/mobile-app/weave-on-mobile/#使用语音)。

## 变更

- **步骤表单遵循同一布局。** 选项卡具有标准名称和标准顺序：General、Settings、Source、Columns、Filters、Output 和 Advanced，ERP 过账表单还包含 Header columns 和 Line columns。必填字段以 * 标记，表单仅会因步骤所需内容而阻止保存。
- **复制项目可分别选择表数据和维度成员，复制数据更快，并保留私有副本的 ERP 写入授权。** 在 **Data to copy** 下，选择 **表数据** —— **No table data**（默认）、**完整** 或 **样本** —— 并另外选择 **Copy dimension members**（默认开启），因此不含表行的副本也会带有已填充的维度，并且创建速度很快。**完整** 和 **样本** 复制会同时复制多个表，因此包含许多表的项目完成得更快。**复制结果** 会在列出表的同时列出每个维度的结果，**Retry failed items** 会一并重试失败的表和维度。带数据的新副本仅您自己可见，并保留源项目中您自己即可授予的 ERP 写入授权；如果源项目以 Live 方式过账，副本会以 Simulate 状态到达，因此在您将其切换为 Live 之前，不会有任何内容到达 ERP。REST API 和 `project_copy` MCP 工具也接受 `dimension_members`。参见[选择要复制的数据量](/zh-cn/guides/projects/managing-projects/#选择复制多少数据)和[副本中的 ERP 写入授权](/zh-cn/guides/projects/managing-projects/#副本中的-erp-写入授权)。
- **行操作菜单（⋯）位于每个网格行的最左侧。**
- **未设置验证选项的已保存 ERP 写入步骤将以仅验证方式打开。** 涵盖 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL and AP Post 和 Xero export。明确设置为实时运行的步骤保持实时。
- **长时间运行的作业在所有位置以相同方式显示进度。**
- **停止工作流不再使后续导入停滞，且从未启动的步骤会失败而不是挂起。** 停止会取消仍在排队的导入和维度步骤，因此工作区中后续的导入和维度加载可正常启动。如果约 40 分钟内没有工作进程启动某个步骤的作业，或工作进程启动后消失，该步骤会失败并给出说明消息，指引您使用 **从此处运行**，而不是一直显示“运行中”直到 24 小时超时。参见[运行工作流](/zh-cn/guides/workflows/run-a-workflow/#永远不会启动的步骤)。
- **工作区升级时，REST、Import REST 和 Import Postman 步骤会转换为 REST 请求。** 无法干净转换的步骤保持原样。参见[REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **项目架构师在仪表板中可看到行受限表的所有行**，与其在 Analyze 中看到的一致。撤销架构师访问权限会立即在仪表板中生效——无论是更改某人的角色、将其或其分组从项目中移除、更改项目的访问类型、还原项目的早期版本，还是删除安全组。前任架构师不再能看到行受限数据的所有行。参见[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
- **会话过期后打开的仪表板链接，在您登录后会带您进入该仪表板。** 参见[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为其另一个名称。参见[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。
- **在 Lakehouse v2 上，Lakehouse 自行将 Parquet 导出写入 Google Cloud Storage。** 导出到 Google Cloud Storage 文档账户时，数据直接进入该账户的存储桶，并使用该账户自己的凭据写入，而不是每一行都先经过 PlaidCloud。导出到 Amazon S3 和 Azure Blob Storage 账户的方式与以前相同。参见[Export to Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/) 步骤。
- **Slack、Microsoft Teams 和 Web Hook 步骤会说明消息未发送的原因。** 步骤的错误会指出它尝试访问的服务器，对于 Slack 和 Teams 还会指出连接，并说明出了什么问题：例如 Slack 不再识别该 Webhook、无法向该频道发布消息、找不到服务器或服务器在 60 秒内没有响应，或者连接已被删除。Slack 或 Teams 的 Webhook URL 绝不会显示，因为任何持有它的人都可以冒充您的集成发布消息。参见[Notify via Slack](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/) 步骤。

## 修复

- **无效的项目设置现在会给出清晰的消息。** 未知的环境或文档账户、已被占用或保留的 slug，或无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 时返回 400 而不是 500，通过 AI 助手或 MCP 时则是无效参数错误。
- **REST API 的维度值请求现在可以正常工作。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 曾被当作网格请求处理并被拒绝为无效。现在它会为 `value_columns` 中的每一列返回一个聚合值；而网格（每对行筛选器和列筛选器对应一个值）有自己专用的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻塞其他请求。** 从仓库读取表的列、注册 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，每一项都可能使同一服务器正在处理的其他所有请求暂停，直到它完成。现在它们与这些请求并行运行。
- **项目变量和工作流变量对话框可以滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口还高，因此 **创建** 和 **更新** 按钮可能够不到。现在表单可以滚动，按钮始终保持在底部。
- **Azure Blob Storage 文档账户中超过 256 MiB 的文件可以复制、移动和重命名。** 以前，对这种大小的文件执行这些操作都会失败，移动或重命名包含此类文件的文件夹也会失败。
- **在 Lakehouse v2 上，表的行数反映刚写入的内容。** 写入表的步骤或导入可能记录的是写入之前的行数，因此刚加载的表显示 0 行，导入也可能报告导入了 0 行。现在会在新行对所有位置可见之后再读取行数，因此后续步骤也能读到它们。将表切换到另一个分支，或将分支合并到该表中，也会更新其行数和列数。
- **Weave 的空值检查会将每次运行与之前运行实际留下的结果进行比较。** 步骤的空值经常是在步骤清空其表以重新填充之后才被统计，因此其之前的运行看起来没有空值，而一个始终部分为空的列会被报告为刚刚变空。现在每次运行都按步骤留下的表来统计。之前记录的计数无法与正确的计数区分，因此不予使用：每个步骤的空值检查都会重新开始记录历史，并在统计满五次运行之前报告为未检查。行数和值分布检查也不再把另一个步骤在本步骤完成两秒以上之后对同一个表所做的写入记为本步骤的写入。参见[Weave 检查内容](/zh-cn/guides/ai-assistant/weave-findings/)。
- **向 REST API 请求已删除的连接会返回 404。** 请求已被删除的连接或不存在的 ID 时，曾返回通用服务器错误（500）。现在会返回 404，并附带指明连接 ID 的消息。

## 安全

- **只有账户所有者才能还原其早期版本。** 将文档账户还原到早期版本、保留或释放某个版本，以及进行备份，现在都要求您是该账户的所有者之一，并且这些操作均不适用于系统管理的账户。查看账户的版本历史需要具有该账户的访问权限。
