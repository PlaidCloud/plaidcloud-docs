## 新增

- **PlaidXL 可在 Excel 中构建、钻取、说明和规划。** **PlaidCloud** 功能区选项卡分为 **连接**、**插入**、**刷新**、**Drill**、**写入** 和 **共享** 几组，常用命令也出现在 **PlaidXL** 右键菜单和 **PlaidXL Cell** 选项卡上，每个命令都有可更改的键盘快捷键。登录之前运行的命令会打开登录界面，并在您登录后运行；如果在 Office 中使用 Microsoft Entra 工作账户，PlaidXL 会为您找到您的工作区。请参阅 [PlaidXL 参考](/zh-cn/reference/cli/plaidxl/)。
  - **几次单击即可构建报表。** **报表** 选项卡根据一个表排布实时报表，行上钻取一个维度，列上钻取另一个维度，每个交叉点上都有一个 `CELL` 值。**Build my first report** 基于您自己的数据生成示例。随着您钻取，报表会插入和删除整行整列，您键入的值、备注和格式会跟随其所在行。请参阅[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)。
  - **从任意单元格钻取。** **Drill down**、**Drill up**、**Keep only** 和 **Remove only** 可将节点转换为实时的 `DRILL` 公式，并以一个可撤消的步骤编辑它，支持从节点、维度标题或报表值开始。**Custom drill** 会在插入之前预览行，成员选取器可插入成员，或为单元格添加节点子节点的下拉列表。`DRILL` 可接受要排除或展开的节点，并且可以沿行横向运行。请参阅[钻取、选取成员和说明数字](/zh-cn/reference/cli/plaidxl/drill/)。
  - **说明数字。** **Explain this number** 会显示值的计算内容、它当前是否与 PlaidCloud 一致，以及它所来自的表和工作流步骤。**Show detail rows** 会将值背后的行放到单独的工作表上，并检查它们加总后是否一致。
  - **Excel 中的受管控指标。** `PLAIDXL.METRIC` 和 `PLAIDXL.METRIC_BREAKDOWN` 返回与仪表板所示一致的业务指标，**Metric...** 会列出项目的指标及其当前值。请参阅[指标](/zh-cn/reference/cli/plaidxl/functions/#指标)。
  - **通过在报表中键入来规划。** 在 `CELL` 值上键入数字即可将其写入 PlaidCloud：按比例、平均或参照另一成员的形状分摊，按金额或百分比调整，被保持的单元格保持不变。平均值、中位数、最小值、最大值、标准差和方差单元格也接受键入的值。**Undo last write** 会撤销键入的值和保存，最新的优先。请参阅[向 PlaidCloud 输入值](/zh-cn/reference/cli/plaidxl/write-values/)。
  - **只刷新您需要的内容。** 可刷新一个工作表、所选内容或每个表，任务窗格中显示每个表的进度并提供 **取消**，也可以只重新计算 PlaidXL 公式。检索的表以按数据类型设置格式的 Excel 表形式到达，刷新时保留您自己的列和数字格式，并在原位置刷新。再次检索表不会将其在刷新列表中添加两次，**Stop refreshing** 可将其移出，维度会随您的表一起刷新。请参阅[刷新所有表](/zh-cn/reference/cli/plaidxl/retrieve/#刷新所有表)。
  - **保存立即写入，并且可以撤消。** **Save to PlaidCloud** 无需确认即可写入，说明它做了什么，并提供 **撤消**。使用筛选器检索的工作表、明细行工作表，或访问权限仅涵盖部分行的用户，只会替换这些行，因此其他人的行会保留。请参阅[将表保存到 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)。
  - **在 Excel 中询问 Weave。** 在 **Weave** 选项卡上，用自然语言请求报表、公式、钻取或表，或选择 **Ask Weave about this cell**。Weave 以您的身份读取 PlaidCloud，只更改工作簿，在替换您输入的任何内容之前会先询问，并且每项更改都可以还原。请参阅[在 Excel 中询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。
  - **共享一个工作表或整个工作簿的仅含值副本。** **Convert to values** 可转换整个工作簿、一个工作表，或转换后无法恢复的值，并且在您重命名工作表后，**Restore PlaidXL formulas** 仍然有效。
- **步骤表单上的预览。** 导入：SQL、执行：SQL、提取：SQL、导出：SQL 和 Salesforce 查询无需运行步骤即可显示最多 100 行，Anaplan 视图和列表读取会显示它们将产生的列和类型。在 **源** 选项卡上单击 **预览**。变量会按运行时的方式填充，但不支持 `{x:>9}` 之类的变量格式。预览只运行标准 SQL 函数；否则会提示您运行该步骤。在已锁定的项目上，或对于基于代理的 Execute SQL 步骤，预览不可用。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **AI 助手可以取消发布表并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表及其已发布的视图和任何没有图表使用的仪表板数据集；仍被图表使用的数据集会保留，当报表视图基于已发布的视图构建时，该视图和数据集也会保留，而表仍会被取消发布。`project_upsert` 设置 `dashboard_default_audience`，即项目中新仪表板所共享的分组，`[]` 会清除它。请参阅[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

- **移动端 Weave 中的语音只需轻点一下。** 轻点麦克风，说出您的问题，停止说话后 Weave 会发送它。再次轻点麦克风可提前停止，如果没有检测到声音，它会自动关闭。如果您在说话中途离开 **Weave** 选项卡或将应用切到后台，您的话会留在问题框中而不发送，以便您查看。运行、暂停、停止和恢复会忽略其确认框上的意外双击。需要应用版本 1.3.0 或更高版本。请参阅[使用语音](/zh-cn/guides/mobile-app/weave-on-mobile/#使用语音)。

## 变更

- **步骤表单采用统一的布局。** 选项卡按标准顺序使用标准名称：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单另有表头列和行列。必填字段用 * 标记，表单仅对步骤所需的内容阻止保存。
- **复制项目可分别选择表数据和维度成员，复制数据更快，并保留私有副本的 ERP 写入授权。** 在 **Data to copy** 下，选择 **表数据**——**无表数据**（默认）、**完整** 或 **样本**——并另外选择 **Copy dimension members**（默认开启），因此不含表行的副本仍会带有已填充的维度，并且制作很快。**完整** 和 **样本** 复制会同时复制多个表，因此包含许多表的项目完成得更快。**复制结果** 会将每个维度的结果与表一起列出，**Retry failed items** 会同时重试失败的表和维度。带数据的新副本仅您自己可见，并保留源项目中您自己可以授予的 ERP 写入授权；如果源项目以 Live 过账，副本会处于 Simulate 状态，因此在您将其切换为 Live 之前，不会有任何内容到达 ERP。REST API 和 `project_copy` MCP 工具也接受 `dimension_members`。请参阅[选择复制多少数据](/zh-cn/guides/projects/managing-projects/#选择复制多少数据)和[副本中的 ERP 写入授权](/zh-cn/guides/projects/managing-projects/#副本中的-erp-写入授权)。
- **行操作菜单（⋯）位于每个网格行的最左侧。**
- **未设置验证选项的已保存 ERP 写入步骤以仅验证方式打开。** 这包括 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL 和 AP Post，以及 Xero export。明确设置为实时运行的步骤保持实时。
- **长时间运行的作业在各处以相同方式显示进度。**
- **停止工作流不再使后续导入停滞，从未启动的步骤会失败而不是挂起。** 停止会取消仍在排队的导入和维度步骤，因此工作区中后续的导入和维度加载会正常启动。如果约 40 分钟内没有工作进程启动某个步骤的作业，或者工作进程启动它之后消失了，该步骤会失败，并给出说明消息，指引您使用 **从此处运行**，而不是一直显示正在运行直到 24 小时超时。请参阅[运行工作流](/zh-cn/guides/workflows/run-a-workflow/#永远不会启动的步骤)。
- **REST、Import REST 和 Import Postman 步骤会在您的工作区升级时转换为 REST 请求。** 无法干净转换的步骤保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **项目架构师可在仪表板中看到行受限表的所有行**，与他们在 Analyze 中看到的一致。撤销架构师访问权限会立即在仪表板中生效——无论您是更改某人的角色、将他们或其分组从项目中移除、更改项目的访问类型、恢复项目的早期版本，还是删除安全组。前架构师不再能看到行受限数据的每一行。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
- **会话过期后打开的仪表板链接，在您登录后会带您进入该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝它们无法识别的字段**，并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为它的另一个名称。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。
- **在 Lakehouse v2 上，Lakehouse 自行将 Parquet 导出写入 Google Cloud Storage。** 导出到 Google Cloud Storage 文档账户时，数据会直接进入该账户的存储桶，使用该账户自己的凭据写入，而不是每一行先经过 PlaidCloud。导出到 Amazon S3 和 Azure Blob Storage 账户的方式保持不变。请参阅[导出到 Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/)。
- **Slack、Microsoft Teams 和 Web Hook 步骤会说明消息未发送的原因。** 步骤的错误会指明它尝试访问的服务器，对于 Slack 和 Teams 还会指明连接，并说明出了什么问题：例如，Slack 不再识别该 webhook、无法向该频道发帖、找不到服务器或服务器在 60 秒内没有响应，或者连接已被删除。Slack 或 Teams 的 webhook URL 永远不会显示，因为任何拥有它的人都可以冒充您的集成发帖。请参阅[通过 Slack 通知](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/)。

## 修复

- **无效的项目设置会以清晰的消息报告。** 未知的环境或文档账户、已被占用或保留的 slug，或无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 时这是 400 而不是 500，通过 AI 助手或 MCP 时是无效参数错误。
- **REST API 的维度值请求现在可用。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 曾被当作网格请求处理并被拒绝为无效。它现在为 `value_columns` 中的每一列返回一个聚合值，而网格（每对行筛选器和列筛选器对应一个值）有自己的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻碍其他请求。** 从仓库读取表的列、注册 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，这些操作原先都可能使同一服务器正在处理的所有其他请求暂停，直到其完成。它们现在与那些请求并行运行。
- **项目和工作流变量对话框可以滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口还高，因此 **创建** 和 **更新** 按钮可能够不到。表单现在可以滚动，按钮始终位于底部。
- **Azure Blob Storage 文档账户中超过 256 MiB 的文件可以被复制、移动和重命名。** 这些操作原先对这种大小的文件都会失败，移动或重命名包含这种文件的文件夹也会失败。
- **在 Lakehouse v2 上，表的行数反映刚写入的内容。** 写入表的步骤或导入可能记录的是写入之前的行数，因此刚加载的表显示为 0 行，导入可能报告导入了 0 行。现在会在新行到处可见之后再读取行数，因此其后的步骤也能读取到这些行。将表切换到另一个分支，或将分支合并到表中，同样会更新其行数和列数。
- **Weave 的空值检查会将每次运行与之前运行实际留下的内容进行比较。** 步骤的空值经常在步骤清空其表以重新填充之后才被统计，因此其之前的运行看起来没有空值，而一直部分为空的列会被报告为刚刚才变成这样。现在每次运行按步骤留下的表来统计。之前记录的计数无法与正确的计数区分，因此不予使用：每个步骤的空值检查会重新开始其历史记录，在统计了五次运行之前显示为未检查。行数和值分布检查也不再将另一个步骤在本步骤完成两秒之后对同一个表所做的写入记在本步骤名下。请参阅 [Weave检查内容](/zh-cn/guides/ai-assistant/weave-findings/)。
- **向 REST API 请求已删除的连接会返回 404。** 请求已被删除的连接或不存在的 ID 时，原先返回通用的服务器错误（500）。现在返回 404，并附带指明连接 ID 的消息。

## 安全

- **只有账户的所有者才能恢复其早期版本。** 将文档账户恢复到早期版本、保留或释放某个版本，以及创建备份，现在都要求您是该账户的所有者之一，并且在系统管理的账户上都不可用。查看账户的版本历史记录需要有该账户的访问权限。
