## 新增

- **PlaidXL 在 Excel 中构建、钻取、解释和规划。** **PlaidCloud** 功能区选项卡分为**连接**、**插入**、**刷新**、**Drill**、**写入**和**共享**，常用命令也出现在 **PlaidXL** 右键菜单和 **PlaidXL Cell** 选项卡中，主要命令还提供可自行更改的键盘快捷方式。登录前运行的命令会打开登录界面，并在登录后运行一次；在 Office 中使用 Microsoft Entra 工作账户时，PlaidXL 会自动找到您的工作区。请参阅 [PlaidXL 参考](/zh-cn/reference/cli/plaidxl/)。
  - **几次单击即可构建报表。** **报表**选项卡根据表生成实时报表，一个维度向下钻取到行，另一个维度横跨各列，每个交叉点都有一个 `CELL` 值。**Build my first report** 会用您自己的数据生成示例。钻取时，报表会插入和删除整行整列，您输入的值、备注和格式会跟随所在的行。请参阅[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)。
  - **从任意单元格钻取。** **Drill down**、**Drill up**、**Keep only** 和 **Remove only** 会将节点转换为实时的 `DRILL` 公式并为您编辑，可从节点、维度标题或报表值发起。**Custom drill** 会在插入之前预览行，成员选取器可插入成员，或为单元格添加节点子级的下拉列表。`DRILL` 可接受要排除或展开的节点，并且可以跨行运行。请参阅[钻取、选取成员和解释数字](/zh-cn/reference/cli/plaidxl/drill/)。
  - **解释数字。** **Explain this number** 会显示值的计算方式、它现在是否与 PlaidCloud 一致，以及它来自哪个表和工作流步骤。**Show detail rows** 会将值背后的行放在单独的工作表中，并检查它们是否加总一致。
  - **Excel 中受治理的指标。** `PLAIDXL.METRIC` 和 `PLAIDXL.METRIC_BREAKDOWN` 按仪表板显示的方式返回业务指标，**Metric...** 会列出项目的指标及其当前值。请参阅[指标](/zh-cn/reference/cli/plaidxl/functions/#指标)。
  - **通过在报表中键入进行规划。** 在 `CELL` 值上键入数字，该数字会写入 PlaidCloud：可按比例分摊、平均分摊或按另一成员的形态分摊，可按金额或百分比调整，已锁定的单元格不受影响。平均值、中位数、最小值、最大值、标准差和方差单元格也接受键入的值。**Undo last write** 会按从新到旧的顺序撤销键入的值并保存。请参阅[将值键入 PlaidCloud](/zh-cn/reference/cli/plaidxl/write-values/)。
  - **只刷新所需内容。** 可刷新一张工作表、所选内容或所有表，每张表的进度和**取消**都显示在任务窗格中，也可以只重新计算 PlaidXL 公式。检索到的表会作为按数据类型设置格式的 Excel 表到达，刷新时保留您自己的列和数字格式，并在原位置刷新。再次检索表不会将其重复添加到刷新列表，**Stop refreshing** 可将其移出列表，维度会随表一同刷新。请参阅[刷新所有表](/zh-cn/reference/cli/plaidxl/retrieve/#刷新所有表)。
  - **保存立即写入，并且可以撤消。** **Save to PlaidCloud** 无需确认即可写入，会说明所做的操作，并提供**撤消**。使用筛选器检索的工作表、明细行工作表，或访问权限仅覆盖部分行的用户，只会替换这些行，因此其他人的行会得到保留。请参阅[将表保存到 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)。
  - **在 Excel 中询问 Weave。** 在 **Weave** 选项卡上，可以用日常语言请求报表、公式、钻取或表，或选择 **Ask Weave about this cell**。Weave 以您的身份读取 PlaidCloud，只更改工作簿，在替换您已输入的内容之前会先询问，并且每项更改在您重新加载窗格之前都可以还原。请参阅[在 Excel 中询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。
  - **共享单个工作表或整个工作簿的仅值副本。** **Convert to values** 可转换整个工作簿、单个工作表，或转换为无法还原的值，并且在重命名工作表之后，**Restore PlaidXL formulas** 仍然有效。
- **步骤表单上的预览。** 导入：SQL、Execute: SQL、提取 SQL、导出：SQL 和 Salesforce Query 无需运行步骤即可显示最多 100 行，Anaplan 视图和列表读取会显示它们将生成的列和类型。请在**源**选项卡上单击**预览**。变量会按运行时的方式填充，但不支持 `{x:>9}` 这类变量格式。预览只运行标准 SQL 函数，否则会提示您运行该步骤。锁定的项目以及基于代理的 Execute SQL 步骤不可用。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **AI 助手可以取消发布表并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表，同时取消发布其已发布视图以及没有图表使用的仪表板数据集；仍被图表使用的数据集会保留，当报表视图构建在已发布视图之上时，该视图和数据集也会保留，而表仍会被取消发布。`project_upsert` 用于设置 `dashboard_default_audience`，即项目中新仪表板的共享对象分组，设置为 `[]` 则清除。请参阅[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

- **移动端 Weave 中的语音只需轻点一下。** 轻点麦克风并提出问题，停止说话后 Weave 会发送该问题。再次轻点麦克风可提前停止，如果一直没有检测到声音，它会自动关闭。如果在说话中途离开 **Weave** 选项卡或将应用转入后台，您说的内容会保留在问题框中而不发送，以便您查看。运行、暂停、停止和恢复会忽略对其确认按钮的意外双击。需要应用版本 1.3.0 或更高版本。请参阅[使用语音](/zh-cn/guides/mobile-app/weave-on-mobile/#使用语音)。

## 变更

- **步骤表单遵循同一布局。** 选项卡有标准名称和标准顺序：General、Settings、Source、Columns、Filters、Output 和 Advanced，ERP 过账表单上另有 Header columns 和 Line columns。必填字段以 * 标记，表单只会因步骤所需的内容而阻止保存。
- **复制项目可分别选择表数据和维度成员，复制数据更快，并保留私有副本的 ERP 写入授权。** 在 **Data to copy** 下，选择 **Table data**（**No table data**（默认）、**完整**或**样本**），并另外选择 **Copy dimension members**（默认开启），因此不含表行的副本到达时仍有已填充的维度，且制作速度很快。**完整**和**样本**副本会同时复制多张表，因此包含许多表的项目完成得更快。**复制结果**会在表旁边列出每个维度的结果，**Retry failed items** 会同时重试失败的表和维度。带数据创建的新副本仅您私有，并保留源项目中您自己有权授予的 ERP 写入授权；如果源项目以实时模式过账，则副本以模拟模式到达，因此在您将其切换为实时之前，不会有任何内容到达 ERP。REST API 和 `project_copy` MCP 工具也接受 `dimension_members`。请参阅[选择要复制的数据量](/zh-cn/guides/projects/managing-projects/#选择复制多少数据)和[副本中的 ERP 写入授权](/zh-cn/guides/projects/managing-projects/#副本中的-erp-写入授权)。
- **行操作菜单 (⋯) 位于每个网格行的最左侧。**
- **未设置验证选项的已保存 ERP 写入步骤以仅验证模式打开。** 涵盖 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL and AP Post 以及 Xero export。显式设置为实时运行的步骤保持实时。
- **长时间运行的作业在各处以相同方式显示进度。**
- **停止工作流会停止它启动的所有内容，无法启动的步骤会失败而不是挂起。** 停止会取消仍在排队的导入和维度步骤，因此工作区中后续的导入和维度加载可正常启动，同时也会停止工作流中已排队或正在运行的连接器（Singer）同步。如果步骤的作业无法启动，该步骤会连同原因一起失败，而不是永远等待：大约 40 分钟内没有工作进程启动它、工作进程启动后又消失、其 pod 在大约 20 分钟内一直处于 Pending 状态、其镜像在大约 5 分钟内无法拉取，或大约 20 分钟内没有创建 pod。大约 30 分钟内没有运行器接手的连接器同步会失败，并给出指明该同步的消息。步骤等待工作进程时，其状态消息显示“Waiting for a worker…”及已等待的分钟数，工作开始后即清除。请参阅[运行工作流](/zh-cn/guides/workflows/run-a-workflow/#永远无法启动的步骤)。
- **工作区升级时，REST、Import REST 和 Import Postman 步骤会转换为 REST 请求。** 无法干净转换的步骤保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **项目架构师在仪表板中可看到行受限表的所有行**，与他们在 Analyze 中看到的一致。撤销架构师权限会立即在仪表板中生效——无论是更改某人的角色、将其或其分组从项目中移除、更改项目的访问类型、还原项目的早期版本，还是删除安全组。前架构师不再能看到行受限数据的每一行。请参阅[管理行访问权限](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
- **会话过期后打开的仪表板链接，会在登录后带您进入该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为它的另一个名称。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。
- **在 Lakehouse v2 上，Lakehouse 自行将 Parquet 导出写入 Google Cloud Storage。** 导出到 Google Cloud Storage 文档账户时，数据会使用该账户自己的凭据直接写入账户的存储桶，而不是每一行都先经过 PlaidCloud。导出到 Amazon S3 和 Azure Blob Storage 账户的行为与以前相同。请参阅[导出为 Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/)。
- **Slack、Microsoft Teams 和 Web Hook 步骤会说明消息未发送的原因。** 步骤的错误会指明它尝试连接的服务器，对于 Slack 和 Teams 还会指明连接，并说明出了什么问题，例如：Slack 不再识别该 webhook、无法向该频道发帖、找不到服务器或服务器在 60 秒内没有响应，或连接已被删除。Slack 或 Teams 的 webhook URL 从不显示，因为任何持有它的人都可以冒充您的集成发帖。请参阅 [Notify via Slack](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/)。

## 已修复

- **无效的项目设置会以清晰的消息报告。** 未知的环境或文档账户、已被占用或保留的 slug，或无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 返回的是 400 而非 500，通过 AI 助手或 MCP 则是无效参数错误。
- **REST API 的维度值请求现在可用。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 曾被当作网格请求处理并被拒绝为无效。现在它为 `value_columns` 中的每一列返回一个聚合值，而网格（行筛选器与列筛选器的每一对组合对应一个值）有自己的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻碍其他请求。** 从仓库读取表的列、注册 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，每一项都可能使同一服务器正在处理的所有其他请求暂停，直到它完成。现在它们与这些请求并行运行。
- **项目和工作流变量对话框可以滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口更高，因此**创建**和**更新**按钮可能无法触及。现在表单可以滚动，按钮保持在底部。
- **Azure Blob Storage 文档账户中超过 256 MiB 的文件可以复制、移动和重命名。** 以前这些操作在这种大小的文件上都会失败，移动或重命名包含这种文件的文件夹也会失败。
- **在 Lakehouse v2 上，表的行数反映刚刚写入的内容。** 写入表的步骤或导入可能记录的是写入之前的行数，因此刚加载的表显示 0 行，导入可能报告导入了 0 行。现在会在新行对所有位置可见之后才读取行数，因此其后的步骤也能读到这些行。将表切换到另一个分支或将分支合并到其中，同样会更新其行数和列数。
- **Weave 的空值检查会将每次运行与之前运行实际留下的结果进行比较。** 步骤的空值往往是在步骤清空其表以重新填充之后才被统计的，因此其之前的运行看起来没有空值，而一直部分为空的列会被报告为刚刚变空。现在每次运行都按步骤留下表时的状态统计。之前记录的计数无法与正确的计数区分，因此不予使用：每个步骤的空值检查会重新开始其历史记录，在统计满五次运行之前报告为未检查。行数和值分布检查也不再把另一个步骤在该步骤完成两秒以上之后对同一张表所做的写入记在该步骤名下。请参阅 [Weave检查内容](/zh-cn/guides/ai-assistant/weave-findings/)。
- **向 REST API 请求已删除的连接会返回 404。** 请求已被删除的连接或不存在的 ID 时，以前会返回通用的服务器错误（500）。现在会返回 404 以及指明连接 ID 的消息。

## 安全

- **只有账户的所有者才能还原其早期版本。** 将文档账户还原到早期版本、保留或释放某个版本以及进行备份，现在都要求您是该账户的所有者之一，并且这些操作在系统托管的账户上均不可用。查看账户的版本历史记录需要拥有该账户的访问权限。
