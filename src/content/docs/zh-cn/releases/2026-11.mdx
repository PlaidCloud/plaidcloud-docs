## 新增

- **AI 助手可以取消发布表，并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表及其已发布的视图，以及没有任何图表使用的仪表板数据集；仍有图表使用的数据集会保留，基于已发布视图构建了报表视图时，该视图和数据集也会保留，但表仍会被取消发布。`project_upsert` 用于设置 `dashboard_default_audience`，即项目中新建仪表板默认共享给的分组，传入 `[]` 则清除该设置。参见[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

## 变更

- **项目架构师可在仪表板中查看受行限制的表的所有行**，与其在 Analyze 中看到的一致。撤销架构师权限会在仪表板中立即生效——无论是更改某人的角色、将其或其所在分组从项目中移除、更改项目的访问类型、恢复项目的早期版本，还是删除安全组。前架构师不再能看到受行限制数据的所有行。参见[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
- **会话过期后打开的仪表板链接，在您登录后会直接带您进入该仪表板。** 参见[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**，并在错误信息中指出该字段，而不是将其忽略。`workflow_upsert` 接受 `memo`，也接受 `description` 作为其另一个名称。参见[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。

## 修复

- **无效的项目设置现在会给出清晰的提示信息。** 未知的环境或文档账户、已被占用或保留的 slug，以及无效的存储类型或过账模式，现在都会返回指明问题的信息，而不是笼统的服务器错误。通过 REST API 返回的是 400 而不是 500，通过 AI 助手或 MCP 则返回无效参数错误。
