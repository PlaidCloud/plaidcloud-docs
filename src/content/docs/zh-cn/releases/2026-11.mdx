## 新增

- **控制平面中的 Trust Center 为安全团队提供 PlaidCloud 的安全文档。** Admin 和 Security 用户可为其组织打开 **Trust Center**，立即下载子处理方列表和 DPA 等公开文档，并代表组织签署一次安全文档 NDA，即可解锁 SOC 2 Type II 报告等受限文档。其他 Admin 和 Security 用户可以看到签署人和签署时间。如果组织的合同已包含 NDA，可将其标记为已存档，无需签署即可解锁文档。受限下载会添加水印并被记录，NDA 发布新版本后需要重新接受。Admin 和 Security 用户还可以按组织选择订阅每日电子邮件，汇总新增或更新的文档以及新的 NDA 版本；邮件中从不包含文档本身。请参阅 [Trust Center](/zh-cn/administration/control-plane/trust-center/)。
- **PlaidXL 在 Excel 中完成构建、钻取、解释和计划。** **PlaidCloud** 功能区选项卡分为 **连接**、**插入**、**刷新**、**钻取**、**写入** 和 **共享** 几组，常用命令也出现在 **PlaidXL** 右键菜单和 **PlaidXL Cell** 选项卡上，主要命令带有可自定义的键盘快捷键，在字段中输入时不会触发。命令失败时会说明是哪个命令以及失败原因。登录前运行的命令会打开登录界面，并在登录后运行；一次登录只对一个工作区有效，因此切换工作区时需要登录新工作区（切换回来则不需要）。在 Office 中使用 Microsoft Entra 工作账户时，PlaidXL 会自动找到您的工作区。请参阅 [PlaidXL 参考](/zh-cn/reference/cli/plaidxl/)。
  - **点击几下即可构建报表。** **报表** 选项卡基于表布局一份实时报表：一个维度沿行向下钻取，另一个维度横跨列，每个交叉点都是一个 `CELL` 值。**Build my first report** 会用您自己的数据生成一个示例。钻取时，报表会插入和删除整行整列，您输入的值、批注和格式会随所在行保留。请参阅[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)。
  - **从任意单元格钻取。** **Drill down**、**Drill up**、**Keep only** 和 **Remove only** 会将节点转换为实时 `DRILL` 公式并替您编辑它，可从节点、维度标题或报表值发起。**Custom drill** 会在插入前预览行，成员选择器可以插入成员，或为单元格添加包含节点子项的下拉列表。`DRILL` 可以指定要排除或展开的节点，并可横跨一行运行。请参阅[钻取、选择成员和解释数字](/zh-cn/reference/cli/plaidxl/drill/)。
  - **解释一个数字。** **Explain this number** 会显示某个值的计算内容、它当前是否与 PlaidCloud 一致，以及它来自哪个表和工作流步骤。**Show detail rows** 会把某个值背后的行放到单独的工作表上，并检查它们的合计是否一致。
  - **Excel 中的受治理指标。** `PLAIDXL.METRIC` 和 `PLAIDXL.METRIC_BREAKDOWN` 按仪表板中的显示方式返回业务指标；没有可聚合内容的 `CELL` 或 `CELLS` 对求和显示 `0`，其他情况显示 `#VALUE!` 并附带原因（在 `CELLS` 溢出区域中为空白）；**Metric...** 会列出项目的指标及其当前值。一个指标可以按多个备用层次结构进行筛选，也可以将备用层次结构成员与其他维度的成员混合使用。请参阅[指标](/zh-cn/reference/cli/plaidxl/functions/#指标)。
  - **在报表中直接输入进行计划。** 在 `CELL` 值上输入一个数字，它就会写入 PlaidCloud：可按比例分配、平均分配或按另一个成员的形态分配，可按金额或百分比调整，锁定的单元格保持不变。平均值、中位数、最小值、最大值、标准差和方差单元格同样接受输入值；插入或删除行列时，输入值会跟随其单元格（被删除单元格中的值会被报告）。**Undo last write** 会按从新到旧的顺序撤消输入值和保存，并且只有执行写入的人员和工作区才能撤消。撤消求和，或撤消输入到空单元格中的平均值时，会保留此后写入相同单元格的内容；在完成前被中断的写入无法撤消。请参阅[向 PlaidCloud 输入值](/zh-cn/reference/cli/plaidxl/write-values/)。
  - **只刷新需要的内容。** 可以刷新一个工作表、一个选定区域或所有表，任务窗格中会显示每个表的进度和 **取消**，也可以只重新计算 PlaidXL 公式。检索到的表以 Excel 表格的形式呈现，并按数据类型设置格式；刷新时会保留您自己添加的列和数字格式，并在原位置刷新。检索或刷新绝不会覆盖其他单元格或与其他 Excel 表格重叠，超出 Excel 范围的整数 ID 和 1900 年之前的日期以文本形式呈现。再次检索同一个表不会把它重复加入刷新列表，**Stop refreshing** 可将其移出列表，维度会随表一起刷新。请参阅[刷新所有表](/zh-cn/reference/cli/plaidxl/retrieve/#refresh-all-tables)。
  - **保存立即写入，并且可以撤消。** **Save to PlaidCloud** 无需确认即可写入，会说明执行了什么操作，并提供 **撤消**；对于 Lakehouse 表，每次保存后 7 天内都可以撤消。使用筛选器检索的工作表、明细行工作表，或访问权限只覆盖部分行的人员，只会替换这些行，其他人的行会被保留。自检索以来成员已发生变化的钻取工作表不会被保存；保存失败时会给出还原点名称，以便将表还原。请参阅[将表保存到 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)。
  - **在 Excel 中询问 Weave。** 在 **Weave** 选项卡上，用平实的语言请求报表、公式、钻取或表，或选择 **Ask Weave about this cell**。Weave 以您的身份读取 PlaidCloud，只修改工作簿，在替换您输入的任何内容之前会先询问，绝不会编写引用工作簿之外内容的公式，并且在重新加载窗格之前每项更改都可以还原。请参阅[在 Excel 中询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。
  - **共享单个工作表或整个工作簿的纯值副本。** **Convert to values** 可以转换整个工作簿、单个工作表，或转换为无法还原的值（会先询问），只更改 PlaidXL 公式及其溢出区域，仍在计算的公式会留待再次尝试；重命名工作表后，**Restore PlaidXL formulas** 仍然有效。
- **过账登记簿打开时直接显示需要您处理的内容。** 有内容需要查看时，它会打开 **异常**；有等待您处理的请求时，打开 **审批**；否则打开 **所有过账**。侧边栏将其屏幕分为 **需要我处理**、**登记簿**、**洞察** 和 **设置** 几组，**异常** 和 **审批** 上显示计数，所有屏幕共用同一个标题和范围栏：选择期间（**本月**、**上个月**、**最近 7 天**、**最近 30 天** 或 **自定义**）、连接、项目、环境或实体，以及 **实时**、**模拟** 或 **全部**，然后 **重置** 或保留一个 **Saved scope**。系统会记住您上次使用的范围。
  - **异常屏幕整理需要查看的内容。** **需要查看**、**未确认**、**待处理**、**失败** 和 **待冲销** 标签显示各自的计数，连接健康状况行显示“All N connections posting normally”，每笔过账都有一个通俗易懂的状态，并带有说明下一步操作的工具提示。没有未处理的内容时显示 **All clear**。将分类账 ID 粘贴到 **Find a posting by ledger id** 或命令面板中，即可直接打开该过账。
  - **审批、委托和关注都是收件箱屏幕。** 可在 **Waiting on me** 和 **Submitted by me** 之间切换，填写原因后 **批准** 或 **拒绝**，一次批准多项，并可从通知中 **撤消** 审批。**Delegate approvals** 是一个简短的对话框，**我的关注** 列出您关注的内容。**冲销过账** 以及批量重试和清除对话框使用同一种布局。
  - **过账抽屉说明发生了什么。** 它显示状态及其含义、按名称列出的关键信息，以及 **行项目**、**历史记录** 和 **签核** 选项卡，并提供 **标记为已审核**、**重试**、**冲销…**、**关注连接**、**关注运行** 和 **复制链接**，后者可直接打开该过账。
  - **辅助、导出和保留采用相同的设计。** **辅助** 提供提问框和洞察卡片，建议标记为 **Draft — nothing applied**，**所有过账** 上的异常卡片带有 **显示这些**。**导出和警报** 提供 **New schedule**，**保留** 是一张卡片。
  - **登记簿保持最新。** 过账变化时侧边栏徽章会更新，过账发生变化时打开的列表会提供 **刷新**，打开的抽屉会就地更新。**主页** 在 **需要关注** 下显示一张 **过账登记簿** 卡片。请参阅[查看过账登记簿](/zh-cn/guides/connections/posting-register/)。
- **项目主页有六个页面。** 纯文本侧边栏列出 **概览**、**变量**、**计划和传感器**、**访问和共享**、**数据和连接** 以及 **应用和品牌**，并带有显示变量数量以及活动计划和传感器数量的徽章。**概览** 显示项目的说明和标签、锁定状态，以及表、工作流、步骤、变量、已发布表和 **数据大小** 的磁贴（后者会打开 **存储**）。该总量与 **项目** 屏幕显示的总量相同，包含为还原而保留的早期版本，工具提示会区分当前数据和早期版本；此外还显示接下来三次计划运行和项目的默认设置，并提供 PDF 或交互式 HTML 格式的 **项目报表** 以及 **导出归档**。其他页面用于管理变量、计划和传感器（提供 **Calendar view** 以及 **Activate** 或 **Deactivate**），谁可以打开项目及其仪表板、哪些项目可以读取其表，连接和表存储默认设置及 ERP 过账模式，以及 Panel 应用、品牌和项目磁贴图像。已锁定的项目会显示横幅并禁用其控件。请参阅[项目主页](/zh-cn/guides/projects/project-home/)。
- **文档打开时显示概览，并带有页面侧边栏。** **概览**、**浏览**、**您的账户** 和 **管理** 位于侧边栏中，页面带有标题（通常还有副标题），操作位于标题区域。**概览** 显示您的账户磁贴、**Pinned** 文件（会在其所在文件夹打开 **浏览** 并选中该文件）、按服务分类的账户以及谁可以使用它们。**您的账户** 是一个列表，列出您可以使用的所有账户，每行带有 **共享** 或 **私有** 标记。**管理** 列出您拥有的账户；工作区管理员可以在其中看到所有文档账户，并可管理其在其他情况下也能管理的任何账户（系统管理的账户会被拒绝，托管存储桶账户无法克隆）。行的 **⋯** 菜单包含 **打开**、**编辑**、**克隆…**、**谁可以使用**、**使用位置…**、**版本历史记录**、**启用** 或 **禁用** 以及 **删除**。账户以页面形式打开，包含 **常规**、**访问**、**凭据** 卡片，SFTP 账户还有 **SSH** 卡片；存在未保存的更改时，离开前会先询问。**浏览** 会打开您收藏的账户或工作区的默认账户，提供带标签的工具栏、行菜单、拖放上传（拖放到文件列表或某个文件夹即上传到该处，拖放到树中的空白处则上传到账户根目录），以及 **Uploads and imports** 面板，显示每次上传和导入到表的进度及可用操作。**Pop out** 会在新的浏览器选项卡中打开该文件夹。请参阅[文档](/zh-cn/guides/documents/)和[使用文档账户](/zh-cn/guides/documents/using-document/)。
- **仪表板打开时显示概览，并带有页面侧边栏。** **概览**、**仪表板**、**应用**、**笔记本** 以及（工作区管理员可见的）**访问审核** 位于侧边栏中，底部是 **Open navigator ↗**，带有标记是因为它会打开单独的窗口。页面带有标题（通常还有副标题），操作位于标题区域。**概览** 显示仪表板和应用的磁贴（会打开已筛选好的对应列表）、您最近打开或加星标的内容、失败的应用和等待您处理的访问请求，并向拥有使用情况访问权限的成员显示打开次数最多的仪表板。**仪表板** 可按 **全部**、**由您管理** 和 **收藏** 筛选，**应用** 显示每个应用的 **类型** 和实时状态。请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **身份打开时显示概览，并带有页面侧边栏。** 侧边栏列出 **概览**、**成员**、**目录**、**安全组** 和 **分发列表**，然后是 **会话**、**安全日志**、**API 客户端**、**分组审计** 和 **所有范围**。页面带有标题（通常还有副标题），操作位于标题区域。**概览** 显示成员、活动成员和从未登录成员、构建者席位以及当前登录人员的磁贴，**活动成员** 图表，带有 **重新发送欢迎电子邮件** 和 **审核** 的 **需要关注**，以及最近 7 天的安全事件。成员以页面形式打开，包含 **配置文件**、**访问** 和 **分组和数据** 卡片；**Invite member** 可从概览和主页的首次运行卡片中使用。请参阅[成员管理](/zh-cn/administration/access/member-management/)。
- **列表可以显示为标准行、宽松行或卡片。** **仪表板**、**应用**、ERP 登记簿和身份 **成员** 等列表的工具栏中有 **视图** 菜单，可在这几种方式之间选择。卡片保留列表的全部功能：选择、排序、列、右键 **复制**，以及（列表支持收藏时的）收藏星标。**仪表板** 卡片会显示缩略图。请参阅[标准、宽松和卡片视图](/zh-cn/guides/dashboards/using-dashboards/#标准宽松和卡片视图)。
- **Lakehouse 窗口新增侧边栏、表详细信息和时间旅行。** **查询**、**配置文件**、**加载** 和 **目录** 位于侧边栏中，**管理** 下有 **Lakehouse 目录**、**数据库用户** 和 **计算**。**数据库用户** 和 **计算** 只向拥有 Lakehouse admin 或 Lakehouse cluster 角色的成员显示。**查询** 可按 SQL 文本、用户、类型和持续时间筛选历史记录，用 **Copy SQL** 复制语句，并用 **Profile this query** 在 **配置文件** 中打开查询。**目录** 可打开表的列、当前快照、分区、位置、属性和快照历史记录，**Copy query as of this snapshot** 会复制一个 `FOR VERSION AS OF` 查询，用于读取该表在当时的状态。请参阅 [Lakehouse 窗口](/zh-cn/guides/data/lakehouse-window/)。
- **步骤表单支持预览。** 导入：SQL、Execute: SQL、Extract: SQL、导出：SQL 和 Salesforce 查询可在不运行步骤的情况下显示最多 100 行，Anaplan 视图和列表读取会显示它们将生成的列和类型。在 **源** 选项卡上点击 **预览**。变量会按运行时的方式填充，但不支持 `{x:>9}` 等变量格式。预览只运行标准 SQL 函数；否则会提示您运行步骤。锁定的项目以及基于代理的 Execute SQL 步骤不支持预览。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/) 和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **使用情况报告在身份中打开，显示变化，可缩小到某个分组，并可流入工作流。** 身份侧边栏 **洞察** 下的 **使用情况报告** 会作为侧边栏旁的页面打开，而不是单独的窗口，包含 **概览**、**活动**、**路径**、**成员**、**内容**、**导出** 和 **漏斗** 选项卡。**概览** 新增与上一期间对比的趋势箭头，以及指向不活跃成员和无人打开的仪表板及应用的 **Highlights** 列表。已停用的成员不计入不活跃成员，也不会列为不活跃。**分组** 将 **概览**、**内容** 和不活跃列表限制为某个安全组的成员；日期范围新增 **上一个月** 和 **本月**，由所有选项卡共用，并随您的账户记住。现在每个数字都有说明，表使用 **成员** 和 **区域** 等通俗名称，按 Enter 即可打开行，加载和错误提示更清晰，**漏斗** 的最后一步会显示完成该步骤的成员数。**Get Workspace Usage** 步骤按计划将使用情况写入表，可以是不含成员姓名的每日或每月合计，也可以是可直接用于报告的数据集：**成员**、**每位成员每日**、**内容** 和 **每位成员内容**。成员数据集包含姓名、电子邮件、分组和活动，因此可以按电子邮件将其与您自己的组织表联接，按部门报告活跃分钟数或仪表板打开次数。与 **Get Workspace Members** 一样，每次运行都会记录在安全日志中。请参阅[使用情况报告](/zh-cn/administration/access/usage-reports/)和 [Get Workspace Usage](/zh-cn/reference/workflow-steps/general/get-workspace-usage/)。
- **AI 助手可以分析表的概况。** 通过 MCP，`table_profile` 会返回表资源管理器显示的列统计信息和数据质量雷达检查，以及每列最常见的值，每次最多 50 列，并且只针对您可见的行。请参阅[从 AI 助手读取概况](/zh-cn/guides/data/table-explorer/#从-ai-助手读取分析结果)。
- **AI 助手可以取消发布表，并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表及其已发布视图，以及所有未被图表使用的仪表板数据集；仍被图表使用的数据集会保留，如果有报表视图基于已发布视图构建，该视图和数据集也会保留，但表仍会被取消发布。`project_upsert` 用于设置 `dashboard_default_audience`，即项目中新建仪表板默认共享给的分组，`[]` 会将其清除。请参阅[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

## 变更

- **如果工作区使用 Grok，移动端 Weave 会要求您再次同意其 AI 声明。** 该声明不再表示 xAI 不会使用您的数据训练其模型，而是说明 PlaidCloud 与 xAI 之间没有零数据保留协议，因此 xAI 可能会保留这些数据，并在其标准条款允许的范围内使用。请参阅 [Weave 如何使用您的数据](/zh-cn/guides/ai-assistant/weave-data-use/)。
- **假设分析窗口一次读取一个期间。** 当 Allocation Split 步骤的输出包含期间列时，窗口会打开最新的期间，并可通过 **期间：** 选择其他期间或 **所有期间**。如果某个步骤的动因在每个期间都有一行，数据量过大而无法跨所有期间读取，现在也能打开并针对一个期间给出答案。已保存的方案会保留其保存时对应的期间（如果有），打开它时，只要该期间仍在列表中，窗口就会切换到该期间。请参阅[选择期间](/zh-cn/guides/allocations/results/driver-what-if/#选择期间)。
- **PlaidCloud 的 Web 应用和 Python 客户端库使用 REST API，JSON-RPC 已弃用。** Web 应用将请求发送到 REST API。使用 `plaidcloud-rpc` 1.25.0 或更高版本时，`SimpleRPC` 调用会发送到 REST API，无需更改代码；REST API 尚未覆盖的调用，或仍使用旧版本的工作区，会像以前一样使用 JSON-RPC。JSON-RPC 将在以后的版本中移除，因此请将脚本和笔记本升级到 `plaidcloud-rpc` 1.25.0 或更高版本，并基于 REST API 编写新的集成。请参阅[命令行](/zh-cn/reference/cli/jupyter/command-line/)。
- **除非将步骤固定到其他环境，否则它会跟随项目的连接环境。** 在 QA 和 Production 等环境之间切换项目时，所有步骤都会随之切换。必须保持在某一个环境的步骤可以改为指定 **Fixed environment**：表单会用警告标记它，其日志会记录每次在项目环境以外的环境中运行，切换项目时会列出不会跟随的步骤。ERP 过账步骤始终使用项目的环境。当项目、固定步骤或代理正在使用某个环境时，无法删除该环境；代理表单中的字段现在为 **Environment this agent serves**。请参阅[将步骤固定到一个环境](/zh-cn/guides/projects/managing-projects/#将步骤固定到单一环境)。
- **步骤表单采用统一布局。** 选项卡使用标准名称并按标准顺序排列：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单还有标题列和行列。必填字段用 * 标记，表单只会因步骤必需的内容而阻止保存。
- **复制项目可分别选择表数据和维度成员，复制数据更快，并保留私有副本的 ERP 写入授权。** 在 **Data to copy** 下，选择 **表数据**——**无表数据**（默认）、**完整** 或 **样本**——并另外选择 **Copy dimension members**（默认开启），因此即使副本不含表行，其维度也已填充，且能快速创建。**完整** 和 **样本** 副本会同时复制多个表，因此表较多的项目能更快完成。**复制结果** 会在表旁边列出每个维度的结果，**Retry failed items** 会同时重试失败的表和维度。包含数据的新副本仅对您私有，并保留源项目中您可以自行授予的 ERP 写入授权；如果源项目以实时方式过账，副本会以模拟方式到达，因此在您将其切换为实时之前，不会有任何内容到达 ERP。REST API 和 `project_copy` MCP 工具也支持 `dimension_members`。请参阅[选择要复制的数据量](/zh-cn/guides/projects/managing-projects/#选择复制多少数据)和[副本中的 ERP 写入授权](/zh-cn/guides/projects/managing-projects/#副本中的-erp-写入授权)。
- **表的详细信息面板会更快地显示使用该表的步骤。** 选择另一个表时会立即清除上一个表的步骤，共享此项目数据的其他项目中的步骤会在其余步骤之后稍后添加，而不会拖慢整个面板。请参阅[查看表的使用位置](/zh-cn/guides/projects/managing-tables-and-views/#查看表的使用位置)。
- **行操作在每个列表中的工作方式相同。** 可以通过行首的 **⋯** 按钮、右键单击行，或工具栏的 **操作** 菜单打开行菜单。它始终先列出 **打开**、**详细信息** 和 **编辑**，然后是列表自己的操作，最后是 **删除** 或 **移除**；不适用于某行的操作会在原位置显示为灰色。**Enter** 和 **Del** 会显示在它们所执行的项上。如果列表的行只有一个操作，则显示该操作的图标而不是 **⋯**，仪表板、应用和笔记本重新显示 **打开** 图标。请参阅[行操作菜单](/zh-cn/guides/dashboards/using-dashboards/#行操作菜单)。
- **PlaidCloud 采用焕然一新的蓝色外观，支持浅色和深色模式。** 按钮、复选框、选中的行、选项卡、链接以及列出工作区页面的侧边栏统一使用 PlaidCloud 蓝，并具有在两种主题下都便于阅读的对比度。应用选项卡图标采用统一的一套图标。
- **新的加载屏幕。** PlaidCloud 会打开一个更简洁的加载屏幕，并跟随您的浅色或深色主题。从空闲状态唤醒的 Panel 或 Dash 应用会显示 **正在启动**、**正在准备** 和 **正在加载应用** 的进度；如果无法启动，会说明停在哪一步，并提供 **重试**。请参阅[使用 Panel 应用](/zh-cn/guides/panel-apps/using/)。
- **未设置验证选项的已保存 ERP 写入步骤会以仅验证模式打开。** 这适用于 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL 和 AP Post 以及 Xero 导出。明确设置为实时运行的步骤保持实时运行。
- **长时间运行的作业在各处以相同方式显示进度。**
- **工作流如实地停止、失败和报告。** 停止工作流会停止它启动的所有内容，无法完成的运行或步骤会附带原因失败而不是挂起，运行状态与实际运行的内容一致。
  - **停止工作流会停止它启动的所有内容，无法完成的运行或步骤会失败而不是挂起。** 停止会取消仍在排队的导入和维度步骤，使工作区中后续的导入和维度加载能够正常启动，还会停止该工作流排队中或正在运行的连接器（Singer）同步。如果步骤的作业无法启动，步骤会附带原因失败，而不是无限等待：约 40 分钟内没有工作进程启动它、工作进程启动后又消失、其 pod 停留在 Pending 状态约 20 分钟、其镜像约 5 分钟无法拉取，或约 20 分钟内未创建 pod。约 30 分钟内没有运行器接手的连接器同步会失败，并显示注明该同步的消息。步骤等待工作进程期间，其状态消息显示“Waiting for a worker…”以及已等待的分钟数，工作开始后即清除。停止宏会停止其所有正在运行的副本，而停止某一个副本，或 **Macro Concurrent** 步骤放弃一个已停止响应的副本，都不会影响调用它的工作流继续运行。仅在其他工作流内部运行的宏会在工作流列表中显示为 **正在运行**，并提供 **停止**，以及每个步骤在最近一次运行中的状态、开始时间和结束时间。服务器丢失的运行会以失败结束，运行超过 12 小时仍未结束的运行会失败，并显示“Run failed: still running at the 12-hour limit. Re-run the workflow.”。请参阅[运行工作流](/zh-cn/guides/workflows/run-a-workflow/#永远无法启动的步骤)。
  - **恢复、运行历史记录和运行状态与实际运行的内容一致。** 恢复父工作流会运行子工作流剩余的所有内容，即使您单独重新运行过子工作流的某个步骤也是如此；在一次运行中对子工作流的每次调用都有各自的运行历史记录条目。因服务器停止而重新启动的步骤会在其日志中说明这一点，`workflow_run_status` 和 REST API 的运行结果会在 `continued_step_ids` 和 `continued_step_count` 中列出失败但继续执行的步骤，而不会将运行报告为无错误。请参阅[暂停、停止和恢复](/zh-cn/guides/workflows/run-a-workflow/#暂停停止和恢复)和[出错时继续](/zh-cn/guides/workflows/continue-on-error/)。
  - **步骤错误显示其自身的消息。** PlaidCloud 未预料到的错误显示为“The step stopped on an unexpected error (*type*): *message*”。启动器上的 **需要关注** 卡片用一行显示错误，并且不包括此后已删除的工作流的运行。请参阅[管理步骤错误](/zh-cn/guides/workflows/managing-step-errors/)。
  - **未完成的 ERP 提取会使其步骤失败，恢复后会继续提取。** 当 **SAP：临时提取** 因达到行数或时间限制而暂停，或其代理未及时响应，或者在步骤停止等待时 Salesforce、Oracle Fusion 批量或 HFM/FCCS 导出作业仍在运行，该步骤会失败，以免后续步骤在不完整的表上运行。恢复工作流或重新运行该步骤后，提取会在同一个作业上从停止处继续。请参阅[运行限制](/zh-cn/guides/connections/sap-adhoc-extract/#运行限制)和 [Salesforce：查询对象](/zh-cn/reference/workflow-steps/salesforce/query-salesforce-object/#运行未完成时)。
  - **取消导出会停止其在数据仓库中的查询。** 当导出或下载被取消（包括通过停止其工作流取消）时，在 Lakehouse v2、Snowflake、Databricks、PostgreSQL 和 Greenplum 上读取其数据的查询也会停止，导出到远程数据库的操作也会停止读取其源，而不会一直运行到结束。
- **工作区升级时，REST、Import REST 和 Import Postman 步骤会转换为 REST 请求。** 无法顺利转换的步骤保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **会话过期后打开的仪表板链接会在您登录后转到该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**，并在错误中注明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为它的另一个名称。请参阅[拒绝未知字段](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。
- **在 Lakehouse v2 上，Lakehouse 会自行将 Parquet 导出写入 Google Cloud Storage。** 导出到 Google Cloud Storage 文档账户时，数据会使用该账户自己的凭据直接写入账户的存储桶，而不是让每一行先经过 PlaidCloud。导出到 Amazon S3 和 Azure Blob Storage 账户的方式与以前相同。请参阅 [Export to Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/)。
- **Slack、Microsoft Teams 和 Web Hook 步骤会说明消息未发送的原因。** 步骤的错误会注明它尝试访问的服务器（对于 Slack 和 Teams 还会注明连接），并说明出了什么问题：例如，Slack 不再识别该 webhook、无法向该频道发帖、找不到服务器或服务器 60 秒内没有响应，或者连接已被删除。Slack 或 Teams 的 webhook URL 从不显示，因为任何拥有它的人都可以以您的集成身份发帖。请参阅 [Notify via Slack](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/)。
- **项目服务账户的访问令牌有效期至少为 24 小时。** 以项目身份运行的工作流作业（例如 UDF 步骤）获得的令牌有效期为 24 小时。工作区升级时，较短的有效期会被延长，您设置的较长有效期则会保留。
- **工作区的组织、所有者、发布渠道和版本由 PlaidCloud 设置，数据中心由您选择。** 在控制平面中，您创建的工作区归您所有，并放在 PlaidCloud 设置的发布渠道上，您可以从注册时提供的区域中选择其 **Data Center**。编辑工作区时，组织、所有者、发布渠道和版本均为只读。使用 **Set Version** 更改版本；如需迁移工作区、更改其所有者或渠道，或固定其版本，请联系 PlaidCloud 支持。请参阅[工作区配置](/zh-cn/administration/control-plane/workspace-configuration/#主要设置)。
- **编码转换步骤可以保留文件夹的子文件夹。** **文档：将文件转换为 ASCII 编码**、**文档：将文件转换为 Unicode (UTF-8) 编码** 和 **文档：将文件转换为 Unicode (UTF-16) 编码** 提供 **保留子文件夹** 复选框。勾选后，输入文件夹某个子文件夹中的每个文件都会写入目标中对应的子文件夹；压缩文件的内容会放入它原来所在的子文件夹。不勾选时，所有文件都会像以前一样直接写入目标位置。请参阅 [Convert Document Encoding to UTF-16](/zh-cn/reference/workflow-steps/document/convert-document-encoding-to-utf-16/)。
- **源表与其设置不匹配的步骤会在写入任何内容之前停止，并一次列出所有问题。** Table Extract、Table Lookup、Table Inner Join、Table Cross Join、Table Outer Join、Table Anti Join、多表联接、Table Union Distinct、Table Union All、Table Pivot、Table Melt、Table In-Place Delete、Table Upsert 和 Table Append 步骤会在写入之前检查其源表。如果步骤读取的列在表中不存在、联接键缺失或不在步骤的源列中，或者步骤读取的源表尚未构建，步骤会停止并给出一个错误，列出每个问题及其修复方法，已存在的目标表会保留其原有内容。对于尚未构建的源表，Table Union Distinct 和 Table Union All 是例外：它们会像以前一样不发出警告地跳过该表并合并其余表，如果所有源表都未构建，则以警告结束而不是失败。步骤列出但并不读取、且表中已不存在的列只会产生警告，因此以前能运行的步骤仍能运行。对于目标为视图的步骤，只有在数据仓库本来就会拒绝创建该视图的情况下，才会对照其表检查它列出的列和联接键。这些失败以前来自数据库，使用数据库自己的措辞，且一次只报告一列，而替换目标表的步骤此时已经清空了目标表。如果工作流的错误处理依赖数据库的文本进行匹配，请进行更新。请参阅[步骤运行时](/zh-cn/reference/workflow-steps/tables/table-extract/#步骤运行时)。
- **没有表的导出会停止，而不是完成。** 没有表的 Export to Parquet、Export to ORC 或 Export to Avro 步骤过去会在不写入任何文件的情况下完成，没有表的 Export to XML 步骤则会写入一个不含任何表的文件。现在这些步骤会在写入任何内容之前停止，并显示 *No Tables Specified*。完全没有表列表就被保存的步骤，过去会因一个提及内部设置的意外错误而失败，现在会以同样的消息停止。

## 修复

- **无效的项目设置会以清晰的消息报告。** 未知的环境或文档账户、已被占用或保留的 slug，或无效的存储类型或过账模式，现在会返回注明问题的消息，而不是通用的服务器错误。通过 REST API 返回的是 400 而不是 500，通过 AI 助手或 MCP 返回的是无效参数错误。
- **REST API 的维度值请求现在可以正常工作。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 以前被当作网格请求处理并被拒绝为无效。现在它会为 `value_columns` 中的每一列返回一个聚合值；网格（为每对行筛选器和列筛选器各返回一个值）有其单独的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻塞其他请求。** 从数据仓库读取表的列、注册 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，以前都可能让同一服务器正在处理的其他所有请求暂停，直到其完成。现在它们会与这些请求并行运行。
- **项目和工作流变量对话框可以滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口还高，因此可能无法点到 **创建** 和 **更新** 按钮。现在表单可以滚动，按钮保持在底部。
- **Azure Blob Storage 文档账户中超过 256 MiB 的文件可以复制、移动和重命名。** 以前，对这种大小的文件执行这些操作都会失败，移动或重命名包含此类文件的文件夹也会失败。
- **在 Lakehouse v2 上，表的行数会反映刚写入的内容。** 写入表的步骤或导入可能会记录写入之前的行数，因此刚加载的表显示 0 行，导入也可能报告导入了 0 行。现在会在新行处处可见后再读取行数，因此后续步骤也能读取到它们。将表切换到另一个分支，或将某个分支合并到表中，也会更新其行数和列数。
- **Weave 的空值检查会将每次运行与之前运行实际留下的结果进行比较。** 步骤的空值常常在步骤为重新填充而清空表之后立即被统计，因此其之前的运行看起来没有任何空值，而一直部分为空的列会被报告为刚刚变空。现在每次运行都按步骤留下的表进行统计。之前记录的计数无法与正确的计数区分开，因此不再使用：每个步骤的空值检查会重新开始积累历史记录，在统计满五次运行之前报告为未检查。行数检查和值分布检查也不再把另一个步骤在该步骤完成两秒以后对同一个表的写入算作该步骤的写入。请参阅 [Weave检查内容](/zh-cn/guides/ai-assistant/weave-findings/)。
- **Data Foundation 会保持反转汇率和小数阈值的精度。** 由于您的汇率是从报告货币报价到另一种货币，PlaidCloud 需要将其反转，反转后的汇率可能会被舍入到六位小数，导致汇率较小的货币（例如印尼盾）的金额偏差约 1%。现在反转汇率会保留 12 位小数。带小数的 `group_amber` 或 `group_red` 阈值（例如 `0.5`）以前会被舍入为整数。下一次加载会使用精确值。请参阅[汇率](/zh-cn/guides/projects/data-foundation/#汇率)。
- **已停用成员的警报和摘要会停止。** 所有者已被停用的 Panel 应用警报或摘要以前会继续检查和发送。现在在所有者停用期间会暂停，重新激活后恢复。请参阅[警报和摘要](/zh-cn/guides/panel-apps/alerts-and-digests/)。
- **向 REST API 请求已删除的连接会返回 404。** 请求已删除的连接或不存在的 ID 时，以前会返回通用服务器错误（500）。现在会返回 404，并显示注明该连接 ID 的消息。
- **模板化表导出可通过 AI 助手和 MCP 使用。** `table_data_export` 的 `templated` 格式以前只要指定了表就会失败。现在它会通过您的模板导出该表，并限于您可以读取的行。在模板中，表的行以其表 ID 命名，其中每个 `-` 写作 `_`。
- **Amazon S3 和 S3 兼容文档账户会保留其区域。** 保存此类账户时会丢弃您输入的 **区域**，因此下次打开账户时该字段为空。现在区域会被保存。对于在此修复之前保存的账户，请重新输入区域并保存。请参阅[添加 AWS S3 账户](/zh-cn/guides/documents/adding-accounts/add-aws-s3-account/)。
- **转换文件夹编码时不再用同名文件覆盖另一个文件。** 两个文件要写入目标中的同一位置时（例如来自不同子文件夹的两个同名文件），以前只会留下最后写入的那个。现在步骤会在写入第二个文件之前停止，注明两个文件及其目标位置，并说明勾选 **保留子文件夹** 是否可以将它们分开。
- **在文档：将文件转换为 ASCII 编码中清除替换字符选项现在会生效。** 保存时勾选了 **将目标编码无法表示的字符替换为 ?** 的步骤，在清除该复选框并再次保存后仍保持勾选状态。现在清除后会关闭替换。
- **AI 助手和 JSON-RPC 不再列出使用您的角色所隐藏的表的步骤名称。** 以前询问此类表的使用位置时，它们会列出您的角色可见的、读取或写入该表的每个步骤，以及其设置和工作流。现在它们只说明有步骤使用该表，而不列出名称，与项目的表引用一致。请参阅[您的角色隐藏的内容](/zh-cn/guides/ai-assistant/weave-tab/#您的角色隐藏的内容)。
- **您选择的默认 AI 连接会保持为默认。** 将 AI 连接标记为工作区默认连接看似成功，但实际从未保存，因此依赖默认连接的代理和步骤一直使用最近更新的那个连接。现在您的选择会被保存。请参阅 [LLM 提供商](/zh-cn/integrations/ai-architecture/llm-providers/#连接包含的内容)。
- **在 Weave 历史记录中右键单击对话不再在删除对话线程上方打开重命名。** **重命名** 现在位于聊天的选项卡上：右键单击该选项卡即可，此前右键单击它没有任何选项。请参阅 [Weave 选项卡中的选项卡](/zh-cn/guides/ai-assistant/weave-tab/#weave-选项卡中的选项卡)。
- **备注为空不再阻止保存。** 在 **备注** 框为空的情况下创建或保存项目、维度、表、数据仓库、编辑器、计划工作流事件或分发列表时，会失败并显示“Memo: Input should be a valid string”。现在接受空备注。
- **在需要一个值的位置给出多个值的表达式会被拒绝，Table Extract 或 Table Union All 步骤会保留其目标表的数据。** 常见原因是末尾多了逗号，例如 `table.amount,`，或者与多个值进行比较，例如 `table.region == ('EU', 'US')`。在 Databend 上，步骤会失败，而 Table Extract 或 Table Union All 步骤此时已经清空了其目标表。其他一些数据仓库会运行此类表达式，但不一定按所写的方式执行，因此一直无错误运行的步骤现在可能会被拒绝。保存步骤时，步骤表单会拒绝该表达式，消息会显示需要修改的内容。请参阅[需要一个值时给出了多个值](/zh-cn/reference/workflow-steps/common/advanced-data-mapper-usage/#期望单个值时给出了多个值)。
- **将同一输出列命名两次的步骤会在清空其目标之前停止。** 在 Table Lookup、Table Extract 或联接中，两个同名的 **目标输出列** 会使步骤先清空其目标表，然后以含糊的错误失败。现在步骤会先停止，并显示注明重复列的消息，以便您为每个输出列指定各自的名称。按查询返回顺序写入列的提取 SQL 不受影响。请参阅 [Table Lookup](/zh-cn/reference/workflow-steps/tables/table-lookup/)。
- **保存时没有源列的联合源会说明缺少什么。** 通过 REST API、JSON-RPC，或者 AI 助手或 MCP 保存、且没有源列列表的 Table Union All 或 Table Union Distinct 步骤的源，过去会在步骤运行时因一个提及内部设置的意外错误而失败。现在保存这样的源会被拒绝，并指出该源；读取此前保存的此类源的步骤会在写入任何内容之前停止，并指出该源。从其表中获取所有列、或按位置堆叠表的转换后的 Table Union All 步骤不需要列表，也不会因为没有列表而被拒绝。
- **列的常量可以是数字、`0` 或 `false`。** 输出列的常量为数字的步骤会因意外错误而失败。常量为 `0` 或 `false` 时会被当作没有常量，因此该列改用其表达式或源列，或者因为列没有可读取的内容而导致步骤失败。现在这些常量会写入每一行，并转换为该列的数据类型，AI 助手也可以提议带有此类常量的步骤。

## 安全

- **Weave 不再在每次对话开始时将您的姓名和电子邮件地址发送给其 AI 提供商。** 它从未使用过这些信息。
- **密码登录需要身份验证器应用，并且密码要求更严格。** 使用 PlaidCloud 密码登录的成员会在下次登录时被要求设置身份验证器应用，此后每次登录都需输入其代码。单点登录、Google、Microsoft 和 GitHub 登录、API 令牌和服务账户不受影响。新密码至少需要 12 个字符，不能是您的用户名或最近六次使用过的密码之一；多次登录失败后，账户会被短时间锁定。工作区已有的更严格规则会被保留。请参阅[成员身份验证](/zh-cn/administration/access/member-authentication/)。
- **连接可以指向公共地址和专用网络地址。** 连接不能指向环回地址、链路本地地址或云元数据地址，错误会注明主机及其解析到的地址。专用网络上的地址不受影响。请参阅[连接无法访问的地址](/zh-cn/guides/connections/create-connection/#连接无法访问的地址)。
- **已保存的连接凭据只向可以编辑连接或工作流的成员显示。** 通过 REST API 和 MCP，已保存连接的密码、令牌和密钥会对其他成员屏蔽，但他们仍可以打开和浏览该连接。请参阅[谁可以看到连接的凭据](/zh-cn/guides/connections/create-connection/#谁能看到连接的凭据)。
- **应用构建在无法访问工作区 Git 凭据的情况下运行。**
- **代理的私钥只向可以编辑代理的成员显示。** 通过 REST API 和 MCP，该密钥不再出现在代理列表或详细信息中，代理表单只向可以编辑代理的成员显示 **私钥** 和 **查看 RPC 配置**。服务账户、项目和代理令牌以及 AI 委托令牌都无法检索该密钥或 RPC 配置。正在运行的代理不受影响，公钥仍会显示。请参阅[获取代理凭据](/zh-cn/reference/cli/plaidlink/agents/#获取代理凭据)。
- **代理下载链接的有效期为一小时。** 开启 **Use PlaidCloud Proxy Download** 后，如果链接已过期，请再次打开下载以获取新链接。请参阅[服务](/zh-cn/administration/control-plane/workspace-configuration/#服务)。
- **向安全组添加人员时遵循您所拥有的权限。** 只有当您拥有某个分组授予的全部权限时，才能将成员添加到该安全组、选择成员的分组或邀请架构师。工作区管理员不受此限制。请参阅[管理安全组](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理安全组)。
- **由连接的所有者或工作区管理员更改其设置并将其开启或关闭。** 通过 REST API、JSON-RPC 以及 AI 助手或 MCP 更改连接的设置，需要该连接的某个所有者；对于没有所有者的连接，则需要工作区管理员。启用、禁用、锁定和解锁连接需要所有者或工作区管理员，并且涉及多个连接的请求只有在您可以更改所有这些连接时才会生效。只有工作区管理员可以选择工作区的默认 AI 连接，并且只有在没有由管理员拥有或没有所有者的连接可作为默认时，成员拥有的连接才会成为默认连接。请参阅[编辑连接](/zh-cn/guides/connections/create-connection/#编辑连接)和 [LLM 提供商](/zh-cn/integrations/ai-architecture/llm-providers/#连接包含的内容)。
- **行访问适用于成员对受限表执行的所有操作。** 成员在仪表板中、在自己编写的 SQL 中以及在加载中，只能查看和更改其授权允许的行。
  - **项目架构师可以在仪表板中看到行受限表的所有行**，与他们在 Analyze 中看到的一致。撤销架构师访问权限会立即在仪表板中生效，无论是更改某人的角色、将其本人或其分组从项目中移除、更改项目的访问类型、还原项目的早期版本，还是删除安全组。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
  - **受行访问限制的成员可以运行自己的 SQL 查询并导出结果。** 在启用了行访问的项目中，非架构师成员在查询屏幕上运行自己的查询时，得到的正好是其授权允许的行，并且可以将其导出为 CSV、Excel 或 JSON，同时显示 **行数受您的访问权限限制** 提示；以前这些操作会被拒绝。包含百分号（`%`）的授权值现在可以在查询屏幕上返回其行，以 CSV 格式下载此类查询也可以正常工作。他们在 Snowflake 或 Databricks 上自行编写的自由格式 SQL、从 Postgres 系列数据仓库导出自己编写的 SQL，以及按快照读取受治理的表，仍会被拒绝；视图必须保留受治理列的原始名称才能被筛选。请参阅[行访问与您自己编写的查询](/zh-cn/administration/access/managing-security-groups-and-assignments/#行访问与您自己编写的查询)。
  - **保存行访问时会保留其源中不存在的授权值。** 当表中没有包含某个值的行、维度中没有该成员或列表中没有该值时，授予安全组的该值会保留在网格中并加以标记。**保存** 会询问是保留还是移除每个此类值。请参阅[行访问网格](/zh-cn/administration/access/managing-security-groups-and-assignments/#行访问网格)。
  - **向行受限表写入 DataFrame、保存记录和清除操作只会更改您能看到的行。** 当行访问限制了您的行时，使用 Python 客户端向受限表写入 DataFrame 或清除该表，或通过 REST API 向其保存记录或清除该表，都只会更改您自己的行；如果加载中包含您访问范围以外的行，会在任何更改发生之前被拒绝，并注明找到的值。项目架构师、可以看到所有行的成员以及工作流运行会写入整个表。个人对任何表进行的每次此类写入都会记录在安全日志中。请参阅[将数据加载到受限表](/zh-cn/administration/access/managing-security-groups-and-assignments/#向受限表加载数据)。
  - **对行受限表执行导入、复制、还原和删除需要您能看到所有行。** 当行访问限制了您的行时，将文件导入受限表、从其他项目将表复制到其中、切换或合并其分支、还原它、删除它、在删除后恢复它，或任何替换整个表的其他操作，只有在您能看到表的所有行时才会运行；否则会被拒绝，并且不会发生任何更改。通过 REST API 保存表的行只会更改您自己的行，与其他加载方式一样。项目架构师、可以看到所有行的成员以及工作流运行不受影响，这些操作也会记录在安全日志中。请参阅[将数据加载到受限表](/zh-cn/administration/access/managing-security-groups-and-assignments/#向受限表加载数据)。
- **只有账户的所有者才能还原其早期版本。** 将文档账户还原到早期版本、保留或释放某个版本以及执行备份，都需要该账户的某个所有者，并且系统管理的账户不提供这些操作。查看账户的版本历史记录需要拥有该账户的访问权限。
- **`query_run` 只运行只读语句。** AI 助手和 MCP 客户端使用的 `query_run` 工具只接受一条 SELECT 或 WITH 语句、对其的 EXPLAIN，或 SHOW；其他任何语句都不会运行。要更改数据，请使用 `query_transform`。MCP 表导出中的 SQL 遵循同样的规则。通过 REST 和 JSON-RPC API，对于不能更改项目数据的成员，该规则同样适用于运行查询、构建列分面、以 CSV 格式下载查询、将查询导出到远程数据库以及使用自己的查询导出表数据；被拒绝的查询返回 403。Explain Analyze 会运行查询以进行测量，因此在查询日志和 Lakehouse 中它只接受读取数据的查询，并且在启用了行访问的项目中，只有项目架构师可以从查询日志中运行它。
- **表资源管理器筛选器、发送到 PlaidCloud 的查询以及查找 Table Extract 步骤动态列的查询，不能调用运行 SQL 或读取服务器文件的函数。** 调用此类函数（例如 `query_to_xml`、`dblink` 或 `pg_read_file`）会被拒绝，错误会注明该函数。在这些位置，`.op()` 只接受运算符，`literal_column` 不能使用 Unicode 转义引号。动态列查询包含步骤的筛选器以及从源中读取列名的表达式，因此违反规则的查询会在步骤运行时使其失败。请参阅[被拒绝的函数和运算符](/zh-cn/reference/workflow-steps/common/advanced-data-mapper-usage/#会被拒绝的函数和运算符)。
- **Data Foundation 分摊规则会拒绝包含单引号、反斜杠或换行符的部门或统计名称。** 该名称会写入分摊步骤的筛选器，因此 **保存** 和第 1 阶段的预览会拒绝它，并注明该值。请参阅[分摊规则](/zh-cn/guides/projects/data-foundation/#分摊规则)。
