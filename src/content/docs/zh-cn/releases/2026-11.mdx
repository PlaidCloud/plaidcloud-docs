## 新增

- **步骤表单上的预览。** Import: SQL、Execute: SQL、Extract: SQL、Export: SQL 和 Salesforce Query 可在不运行步骤的情况下显示最多 100 行，Anaplan 视图和列表读取则显示它们将生成的列和类型。请在**源**选项卡上单击**预览**。变量会按运行时的方式填充，但不支持 `{x:>9}` 这样的变量格式。预览仅运行标准 SQL 函数；否则会提示您运行该步骤。锁定的项目以及基于代理的 Execute SQL 步骤不支持预览。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **AI 助手可以取消发布表并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表及其已发布的视图和任何没有图表使用的仪表板数据集；仍被图表使用的数据集会保留，当报表视图构建在已发布视图之上时，该视图和数据集也会保留，而表本身仍会被取消发布。`project_upsert` 设置 `dashboard_default_audience`，即项目中新仪表板所共享的分组，设为 `[]` 则清除。请参阅[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

- **移动端 Weave 中的语音只需轻点一下。** 轻点麦克风并提出问题，停止说话后 Weave 会发送一次。再次轻点麦克风可提前停止，如果没有检测到声音，它会自动关闭。如果在说话中途离开 **Weave** 选项卡或将应用切换到后台，您说的内容会保留在问题框中而不发送，以便您查看。运行、暂停、停止和恢复会忽略对其确认框的误触双击。需要应用 1.3.0 或更高版本。请参阅[使用语音](/zh-cn/guides/mobile-app/weave-on-mobile/#使用语音)。

## 变更

- **步骤表单遵循同一布局。** 选项卡采用标准名称和标准顺序：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单上另有标题列和行列。必填字段以 * 标记，表单只会因步骤所需的内容而阻止保存。
- **复制项目可分别选择表数据和维度成员，复制数据更快，并让私有副本保留 ERP 写入授权。** 在 **Data to copy** 下，选择**表数据**：**无表数据**（默认）、**完整**或**样本**；另外还可单独选择 **Copy dimension members**，该选项默认开启，因此不带表行的副本到达时仍有已填充的维度，而且复制很快。**完整**和**样本**复制会同时复制多个表，因此包含大量表的项目完成得更快。**复制结果**会在表的旁边列出每个维度的结果，**Retry failed items** 会一并重试失败的表和维度。带数据创建的新副本仅对您私有，并保留源项目中您自己可以授予的 ERP 写入授权；如果源项目以 Live 模式过账，副本会以 Simulate 模式到达，因此在您将其切换为 Live 之前，不会有任何内容到达 ERP。REST API 和 `project_copy` MCP 工具同样接受 `dimension_members`。请参阅[选择复制多少数据](/zh-cn/guides/projects/managing-projects/#选择复制多少数据)和[副本中的 ERP 写入授权](/zh-cn/guides/projects/managing-projects/#副本中的-erp-写入授权)。
- **行操作菜单（⋯）位于每个网格行的最左侧。**
- **未设置验证选项的已保存 ERP 写入步骤将以仅验证方式打开。** 涵盖 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL 和 AP Post 以及 Xero 导出。明确设置为实时运行的步骤仍保持实时。
- **长时间运行的作业在各处以相同方式显示进度。**
- **停止工作流不再阻碍后续导入，从不启动的步骤会失败而不是挂起。** 停止会取消仍在排队的导入和维度步骤，因此工作区中后续的导入和维度加载可正常启动。如果约 40 分钟内没有工作器启动某个步骤的作业，或工作器启动后又消失，该步骤会失败并给出相应消息，引导您使用 **Run from here**，而不是一直显示正在运行直到 24 小时超时。请参阅[运行工作流](/zh-cn/guides/workflows/run-a-workflow/#永远不会启动的步骤)。
- **工作区升级时，REST、Import REST 和 Import Postman 步骤会转换为 REST 请求步骤。** 无法干净转换的步骤保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **项目架构师可在仪表板中看到行受限表的所有行**，与其在 Analyze 中看到的一致。撤销架构师权限会在仪表板中立即生效，无论是更改某人的角色、将其或其所在分组从项目中移除、更改项目的访问类型、还原项目的早期版本，还是删除安全组。前架构师不再能看到行受限数据的所有行。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
- **会话过期后打开的仪表板链接，会在您登录后带您进入该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝它们无法识别的字段**，并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为它的另一个名称。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。
- **在 Lakehouse v2 上，Lakehouse 自行将 Parquet 导出写入 Google Cloud Storage。** 导出到 Google Cloud Storage 文档账户时，数据使用该账户自己的凭据直接写入账户的存储桶，而不是让每一行都先经过 PlaidCloud。导出到 Amazon S3 和 Azure Blob Storage 账户的方式不变。请参阅[导出为 Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/)。
- **Slack、Microsoft Teams 和 Web Hook 步骤会说明消息未能发送的原因。** 步骤的错误会指明它尝试访问的服务器（对于 Slack 和 Teams，还会指明连接），并说明出了什么问题：例如 Slack 不再识别该 webhook、无法向该频道发帖、找不到服务器或服务器在 60 秒内没有响应，或者连接已被删除。Slack 或 Teams 的 webhook URL 绝不会显示，因为任何持有它的人都可以冒充您的集成发帖。请参阅 [Notify via Slack 步骤](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/)。

## 修复

- **无效的项目设置会给出明确的报告消息。** 未知的环境或文档账户、已被占用或保留的 slug，或无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 时返回 400 而不是 500，通过 AI 助手或 MCP 时则是无效参数错误。
- **REST API 的维度值请求现已可用。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 曾被当作网格请求处理并被拒绝为无效。现在它会为 `value_columns` 中的每一列返回一个聚合值，而网格（行筛选器与列筛选器的每一对组合各返回一个值）则有自己的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻碍其他请求。** 从仓库读取表的列、注册 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，过去都可能让同一服务器正在处理的所有其他请求暂停，直到其完成。现在它们与这些请求并行运行。
- **项目和工作流变量对话框可以滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口还高，因此**创建**和**更新**按钮可能够不到。现在表单可以滚动，按钮保持在底部。
- **Azure Blob Storage 文档账户中超过 256 MiB 的文件可以复制、移动和重命名。** 以前这些操作在该大小的文件上都会失败，移动或重命名包含此类文件的文件夹也是如此。
- **在 Lakehouse v2 上，表的行数会反映刚写入的内容。** 写入表的步骤或导入可能会记录写入之前的行数，因此刚加载的表显示为 0 行，导入也可能报告导入了 0 行。现在会在新行在所有位置都可见后才读取行数，因此后续步骤也能读取到这些行。将表切换到另一个分支，或将分支合并到表中，也会更新表的行数和列数。
- **Weave 的空值检查会将每次运行与之前的运行实际留下的内容进行比较。** 步骤的空值经常是在步骤为重新填充而清空其表之后立即统计的，因此之前的运行看起来没有空值，而一直部分为空的列会被报告为好像刚刚才变成这样。现在，每次运行都按步骤留下的表进行统计。之前记录的计数无法与正确的计数区分开，因此不再使用：每个步骤的空值检查会重新开始其历史记录，并在统计满五次运行之前被报告为未检查。行数和值分布检查也不再将另一个步骤在该步骤结束两秒多之后写入同一表的内容算作该步骤的写入。请参阅[Weave检查内容](/zh-cn/guides/ai-assistant/weave-findings/)。
- **向 REST API 请求已删除的连接现在会返回 404。** 请求已被删除的连接或不存在的 ID 时，此前会返回通用的服务器错误（500）。现在返回 404，并附带指明该连接 ID 的消息。

## 安全

- **只有账户所有者才能还原其早期版本。** 将文档账户还原到早期版本、保留或释放版本以及进行备份，现在都要求您是该账户的所有者之一，系统托管的账户上则都不可用。查看账户的版本历史需要有该账户的访问权限。
