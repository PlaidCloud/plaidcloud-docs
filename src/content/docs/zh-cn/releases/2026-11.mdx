## 新增

- **步骤表单上的预览。** 导入：SQL、执行：SQL、提取 SQL、导出：SQL 和 Salesforce 查询可在不运行步骤的情况下显示最多 100 行，Anaplan 视图和列表读取则显示它们将生成的列和类型。请单击**源**选项卡上的**预览**。变量的填充方式与运行时相同，但不支持 `{x:>9}` 之类的变量格式。预览只运行标准 SQL 函数；否则会提示您运行步骤。在已锁定的项目中，或对于基于代理的执行 SQL 步骤，预览不可用。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **AI 助手可以取消发布表并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表及其已发布的视图，以及没有图表使用的任何仪表板数据集；仍被图表使用的数据集会保留，当报表视图构建在已发布的视图之上时，该视图和数据集也会保留，而表仍会被取消发布。`project_upsert` 会设置 `dashboard_default_audience`，即与项目中新仪表板共享的分组，`[]` 表示清除。请参阅[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

## 更改

- **步骤表单遵循同一种布局。** 选项卡采用标准名称和标准顺序：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单上另有表头列和行项目列。必填字段以 * 标记，表单只会因步骤所需的内容而阻止保存。
- **行操作菜单（⋯）位于每个网格行的最左侧。**
- **未设置验证选项的已保存 ERP 写入步骤将以仅验证模式打开。** 这涵盖 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL 和 AP Post，以及 Xero 导出。明确设置为实时运行的步骤仍保持实时运行。
- **长时间运行的作业在各处以相同的方式显示进度。**
- **REST、Import REST 和 Import Postman 步骤会在您的工作区升级时转换为 REST 请求步骤。** 无法干净转换的步骤会保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **项目架构师可在仪表板中看到受行限制的表的所有行**，与他们在 Analyze 中看到的一致。移除某人的架构师权限大约一分钟后生效，在某些情况下最多需要 15 分钟。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
- **会话过期后打开的仪表板链接，会在您登录后带您进入该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为它的另一个名称。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。
