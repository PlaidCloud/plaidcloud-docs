## 新增

- **控制平面中的 Trust Center 为安全团队提供 PlaidCloud 的安全文档。** Admin 和 Security 用户可为其组织打开 **Trust Center**，立即下载子处理方清单和 DPA 等公开文档，并由组织签署一次安全文档保密协议（NDA），即可解锁 SOC 2 Type II 报告等受限文档。其他 Admin 和 Security 用户可以看到谁在何时签署。合同中已包含 NDA 的组织可将其标记为已存档，这样无需签署即可解锁文档。受限文档的下载带有水印并会被记录，新版本的 NDA 需要重新接受。Admin 和 Security 用户还可以按组织选择订阅每日电子邮件摘要，内容为新增或更新的文档以及新版本 NDA；邮件中绝不包含文档本身。请参阅 [Trust Center](/zh-cn/administration/control-plane/trust-center/)。
- **PlaidXL 可在 Excel 中构建、钻取、解释和规划。** **PlaidCloud** 功能区选项卡分为 **连接**、**插入**、**刷新**、**Drill**、**写入** 和 **共享**，常用命令还位于 **PlaidXL** 右键菜单和 **PlaidXL Cell** 选项卡上，主要命令带有可更改的键盘快捷键，在字段中输入时不会触发。命令失败时会说明是哪个命令以及原因。在登录前运行的命令会打开登录界面，并在登录后运行一次；登录对一个工作区有效，因此切换工作区时会要求登录新工作区（切换回来则不需要），使用 Office 中的 Microsoft Entra 工作账户时，PlaidXL 会自动找到您的工作区。请参阅 [PlaidXL 参考](/zh-cn/reference/cli/plaidxl/)。
  - **点几下就能构建报表。** **Report** 选项卡根据表排布实时报表，一个维度向下钻取展开于行，另一个维度横跨于列，每个交叉处都有一个 `CELL` 值。**Build my first report** 会基于您自己的数据生成示例。钻取时，报表会插入和删除整行整列，您输入的值、备注和格式会跟随所在行。请参阅[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)。
  - **从任意单元格钻取。** **Drill down**、**Drill up**、**Keep only** 和 **Remove only** 会将节点转换为实时的 `DRILL` 公式并为您编辑，可从节点、维度标题或报表值发起。**Custom drill** 会在插入前预览行，成员选择器可插入成员，或为单元格添加节点子项的下拉列表。`DRILL` 可接受要排除或展开的节点，并可横跨一行运行。请参阅[钻取、选择成员和解释数字](/zh-cn/reference/cli/plaidxl/drill/)。
  - **解释数字。** **Explain this number** 会显示某个值的计算方式、它当前是否与 PlaidCloud 一致，以及其来源的表和工作流步骤。**Show detail rows** 会将值背后的行放到单独的工作表上，并检查它们是否相加一致。
  - **在 Excel 中使用受管控的指标。** `PLAIDXL.METRIC` 和 `PLAIDXL.METRIC_BREAKDOWN` 按仪表板显示的方式返回业务指标；没有可聚合内容的 `CELL` 或 `CELLS` 对求和显示 `0`，否则显示 `#VALUE!` 及原因（在 `CELLS` 溢出区域中为空白），**Metric...** 会列出项目的指标及其当前值。指标可以按多个备用层次结构进行筛选，并可将备用层次结构的成员与其他维度的成员混合使用。请参阅[指标](/zh-cn/reference/cli/plaidxl/functions/#指标)。
  - **在报表中直接输入即可规划。** 在 `CELL` 值上输入数字，即会写入 PlaidCloud：可按比例分摊、平均分摊或按另一个成员的形态分摊，可按金额或百分比调整，已锁定的单元格保持不变。平均值、中位数、最小值、最大值、标准差和方差单元格同样接受输入值；插入或删除行或列时，输入的值会跟随其单元格（已删除单元格中的值会被报告）。**Undo last write** 会按从新到旧的顺序撤消输入的值和保存，只有执行该写入的人员和工作区才能撤消。撤消求和，或撤消在空单元格中输入的平均值时，会保留此后写入同一单元格的内容；在完成前被中断的写入无法撤消。请参阅[向 PlaidCloud 输入值](/zh-cn/reference/cli/plaidxl/write-values/)。
  - **只刷新所需内容。** 可刷新一个工作表、一个选区或所有表，任务窗格中显示每个表的进度和 **取消**，也可以只重新计算 PlaidXL 公式。在网页版 Excel 和当前桌面版 Excel 中，大型表的检索速度大大加快（143,000 行、77 列的表约需一分钟，而不是十分钟以上；较旧的 Excel 版本照常工作），超出 Excel 单元格容量的文本会被标记，并避免被截断保存。检索到的表以按数据类型设置格式的 Excel 表形式到达，刷新时保留您自己的列和数字格式，并在原位置刷新。检索或刷新绝不会覆盖其他单元格或与另一个 Excel 表重叠，超出 Excel 范围的整数 ID 和 1900 年之前的日期会以文本形式到达。再次检索某个表不会将其重复添加到刷新列表，**Stop refreshing** 可将其移出，维度会随表一同刷新。请参阅[刷新所有表](/zh-cn/reference/cli/plaidxl/retrieve/#刷新所有表)。
  - **保存立即写入，并且可以撤消。** **Save to PlaidCloud** 无需确认即写入，说明其所做的操作，并提供 **撤消**，对 Lakehouse 表而言，每次保存后最多 7 天内有效。带筛选器检索的工作表、明细行工作表，或访问权限仅涵盖部分行的用户，只会替换相应的行，因此其他人的行得以保留。自检索以来成员已发生变化的穿透工作表不会被保存，保存失败时会指出还原点，以便恢复该表。请参阅[将表保存到 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)。
  - **在 Excel 中询问 Weave。** 在 **Weave** 选项卡上，用日常语言请求报表、公式、钻取或表，或选择 **Ask Weave about this cell**。Weave 以您的身份读取 PlaidCloud，只更改工作簿，替换您已输入的内容前会先询问，从不写入引用工作簿之外的公式，并且在重新加载窗格之前，每项更改都可以还原。请参阅[在 Excel 中询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。
  - **共享单个工作表或整个工作簿的仅值副本。** **Convert to values** 可转换整个工作簿、单个工作表，或转换为无法恢复的值（会先询问），只更改 PlaidXL 公式及其溢出区域，仍在计算的公式会留待再次尝试，并且在您重命名工作表后，**Restore PlaidXL formulas** 仍然有效。
  - **任务窗格焕然一新。** 它与 PlaidCloud 网页应用保持一致，采用品牌蓝、导轨式选项卡和列表，并将表、维度、项目和列放在有边界的可滚动卡片中。键盘焦点显示清晰的焦点环，窗格跟随您的 Office 浅色或深色主题。在较窄的窗格中，选项卡排成三列两行，宽度达到 560 像素起则排成一行。请参阅[浅色和深色主题](/zh-cn/reference/cli/plaidxl/connect/#浅色和深色主题)。
  - **窗格中的数字遵循 Excel 的显示语言。** 行数和列数，以及刷新、重新计算、Explain、Formulas、Report 和规划消息，均按您的 Excel 的方式显示数字，因此德语版 Excel 显示 4.812.233。写入单元格的值不变。
  - **刷新期间工作表选项卡变为黄色。** 在 **Refresh All Tables** 期间，无论是从窗格、功能区还是 Weave 发起，每个工作表的选项卡在该工作表刷新时为黄色，并在其完成、失败或被取消时恢复为原先的颜色（包括您自己设置的颜色）。如果在中途保存并关闭工作簿，下次在其中启动 PlaidXL 时会恢复选项卡颜色。请参阅[刷新所有表](/zh-cn/reference/cli/plaidxl/retrieve/#刷新所有表)。
- **过账登记簿打开时即显示需要您处理的内容。** 有事项需要查看时打开 **异常**，有请求等待您处理时打开 **审批**，否则打开 **所有过账**。导轨将其屏幕分为 **需要我处理**、**登记簿**、**洞察** 和 **设置**，并在 **异常** 和 **审批** 上显示计数，每个屏幕共用同一个页眉和范围栏：选择期间（**This month**、**上个月**、**最近 7 天**、**最近 30 天** 或 **自定义**）、连接、项目、环境或实体，以及 **实时**、**模拟** 或 **全部**，然后选择 **重置**，或保留 **Saved scope**。系统会记住您上次使用的范围。
  - **“异常”会整理出需要查看的内容。** **Needs a look**、**Unconfirmed**、**Pending**、**Failed** 和 **Reversal outstanding** 的标签显示其计数，连接健康状况行显示“所有 N 个连接过账正常”，每笔过账都有一个通俗易懂的状态，并带有关于下一步该做什么的工具提示。没有未处理事项时会显示 **All clear**。将分类账 ID 粘贴到 **Find a posting by ledger id** 或命令面板中，即可直接打开该笔过账。
  - **审批、委托和关注都是收件箱式屏幕。** 可在 **Waiting on me** 和 **Submitted by me** 之间切换，附上理由 **批准** 或 **拒绝**，一次批准多项，并可从提示消息中 **撤消** 审批。**Delegate approvals** 是一个简短的对话框，**我的关注** 列出您关注的内容。**冲销过账** 以及批量重试和清除对话框共用同一布局。
  - **过账的抽屉会说明发生了什么。** 它显示状态及其含义、按名称列出的关键事实，以及 **Lines**、**历史记录** 和 **签核** 选项卡，并提供 **标记为已审核**、**重试**、**冲销…**、**关注连接**、**关注运行** 和 **Copy link**（会直接打开该笔过账）。
  - **辅助、导出和保留采用相同的设计。** **辅助** 有提问框和洞察卡片，建议标有 **Draft — nothing applied**，**所有过账** 上有异常卡片，带 **显示这些**。**导出和警报** 有 **New schedule**，**保留** 是一张卡片。
  - **登记簿保持最新。** 过账发生变化时，导轨徽章会更新，打开的列表会提供 **刷新**，打开的抽屉会原地更新。**主页** 在 **需要关注** 下显示 **过账登记簿** 卡片。请参阅[查看过账登记簿](/zh-cn/guides/connections/posting-register/)。
- **项目主页有七个页面。** 纯文本导轨列出 **概览**、**变量**、**计划与传感器**、**访问与共享**、**数据与连接**、**数据模型** 和 **应用与品牌设置**，并以徽章显示变量数量、活动的计划和传感器数量，以及元素数量。**概览** 显示项目的说明和标签、锁定状态、表、工作流、步骤、变量、已发布表和 **数据大小**（会打开 **存储**）的磁贴（其总计与 **项目** 屏幕显示的一致，包括为还原而保留的早期版本，工具提示会将当前数据与早期版本分开列出）、接下来的三次计划运行，以及项目的默认设置，并提供 PDF 或交互式 HTML 的 **项目报表** 和 **导出归档**。其他页面管理变量、计划和传感器（带 **Calendar view** 和 **Activate** 或 **Deactivate**）、谁可以打开项目及其仪表板、哪些项目可以读取其表、带 ERP 过账模式的连接和表存储默认设置，以及 Panel 应用、品牌和项目的磁贴图像。锁定的项目会显示横幅并禁用其控件。请参阅[项目主页](/zh-cn/guides/projects/project-home/)。
- **将共享列一次性描述为项目元素，并查看表之间如何关联。** 多张表共享的列名，例如 `Period` 或 `Org`，会成为带有说明、类型、掩码、维度和别名的元素。每张包含该名称的列的表，在该列自身没有对应值时，都会显示元素的说明、掩码和维度，而表上存储的内容不会有任何更改。项目主页上新增的 **数据模型** 页面列出这些元素，以图或矩阵显示共享每个元素的表，标出类型不同的表，并建议值得转为元素的名称。元素的名称会显示在表资源管理器、列属性和步骤的 Data Mapping 选项卡中其列的旁边。Data Foundation 项目自带其共享 Common Finance Model 列的元素。REST API 以及 `element_find`、`element_upsert` 和 `element_delete` MCP 工具可管理元素，AI 助手可看到每列的元素含义。请参阅[数据模型与项目元素](/zh-cn/guides/projects/data-model/)。
- **文档打开时显示概览，并带有页面导轨。** **概览**、**浏览**、**Your accounts** 和 **管理** 位于导轨中，页面有标题，通常带副标题，其操作位于页眉。**概览** 显示您的账户、**Pinned** 文件（会在其文件夹处打开 **浏览** 并选中该文件）、按服务划分的账户以及谁可以使用它们的磁贴。**Your accounts** 是您可使用的所有账户的单一列表，每行带 **Shared** 或 **私有** 标签。**管理** 列出您拥有的账户，工作区管理员在此可以看到每个文档账户，并可管理其他情况下有权管理的任何账户（系统管理的账户会被拒绝，托管存储桶账户无法克隆）。行的 **⋯** 菜单包含 **打开**、**编辑**、**克隆…**、**Who can use it**、**使用位置…**、**Version history**、**启用** 或 **Disable** 以及 **删除**。账户以页面形式打开，带有 **常规**、**访问**、**Credentials** 卡片，对于 SFTP 还带有 **SSH** 卡片，并在您离开且有未保存的更改时询问。**浏览** 会打开您收藏的账户或工作区的默认账户，带有标注的工具栏、行菜单、拖放上传（拖到文件列表或某个文件夹即可上传到该处，拖到树中的空白处则上传到账户根目录），以及 **Uploads and imports** 面板，显示每次上传以及导入到表的进度和操作。**Pop out** 会在新的浏览器选项卡中打开该文件夹。请参阅[文档](/zh-cn/guides/documents/)和[使用文档账户](/zh-cn/guides/documents/using-document/)。
- **仪表板打开时显示概览，并带有页面导轨。** **概览**、**仪表板**、**应用**、**Notebooks** 以及（面向工作区管理员的）**访问审核** 位于导轨中，底部有 **Open navigator ↗**，带有标记，因为它会打开自己的窗口。页面有标题，通常带副标题，其操作位于页眉。**概览** 显示仪表板和应用的磁贴（会打开已筛选的相应列表）、您最近打开或加星标的内容、失败的应用和等待您处理的访问请求，以及对有使用情况访问权限的成员显示打开次数最多的仪表板。**仪表板** 可按 **全部**、**You manage** 和 **收藏** 筛选，**应用** 显示每个应用的 **类型** 和实时状态。请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **“身份”打开时显示概览，并带有页面导轨。** 导轨列出 **概览**、**成员**、**目录**、**安全组** 和 **Distribution lists**，然后是 **会话**、**安全日志**、**API 客户端**、**Group audit** 和 **All scopes**。页面有标题，通常带副标题，其操作位于页眉。**概览** 显示成员、活动成员和从未登录的成员、构建者席位以及当前登录者的磁贴，**活动成员** 图表，带 **重新发送欢迎电子邮件** 和 **审核** 的 **需要关注**，以及最近 7 天的安全事件。成员以页面形式打开，带有 **配置文件**、**访问** 和 **Groups and data** 卡片，**Invite member** 可从概览和主页的首次运行卡片使用。请参阅[成员管理](/zh-cn/administration/access/member-management/)。
- **列表可显示为 Standard rows、Roomy rows 或 Cards。** 在 **仪表板**、**应用**、ERP 登记簿和“身份”的 **成员** 等列表的工具栏中，**视图** 菜单可让您在它们之间选择。卡片保留列表的所有功能：选择、排序、列、右键 **复制**，以及在列表带有收藏的情况下的收藏星标。**仪表板** 卡片显示缩略图。请参阅[Standard、Roomy 和 Cards 视图](/zh-cn/guides/dashboards/using-dashboards/#标准宽松和卡片视图)。
- **Lakehouse 窗口带有侧边导轨、表详细信息和时间旅行。** **查询**、**配置文件**、**加载** 和 **目录** 位于导轨中，**Administration** 下有 **Lakehouse catalogs**、**Database users** 和 **Compute**。**Database users** 和 **Compute** 仅对具有 Lakehouse admin 或 Lakehouse cluster 角色的成员显示。**查询** 可按 SQL 文本、用户、类型和持续时间筛选历史记录，用 **Copy SQL** 复制语句，并用 **Profile this query** 在 **配置文件** 中打开查询。**目录** 会打开表的列、当前快照、分区、位置、属性和快照历史记录，**Copy query as of this snapshot** 会复制一条 `FOR VERSION AS OF` 查询，读取表在当时的状态。请参阅 [Lakehouse 窗口](/zh-cn/guides/data/lakehouse-window/)。
- **步骤表单上的预览。** 导入：SQL、Execute: SQL、提取 SQL、导出：SQL 和 Salesforce Query 无需运行步骤即可显示最多 100 行，Anaplan 视图和列表读取会显示它们将生成的列和类型。请在 **源** 选项卡上单击 **预览**。变量会按运行时的方式填入，但不支持 `{x:>9}` 之类的变量格式。预览只运行标准 SQL 函数，否则会提示您运行该步骤。它在锁定的项目中不可用，对基于代理的 Execute SQL 步骤也不可用。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。

- **Git 应用会列出您的存储库，并告诉您可以执行的操作。** 应用列表中的 **Git** 会显示您的角色（**Administrator**、**Contributor** 或 **查看者**）以及工作区的存储库，每个存储库带有其说明、最后更新日期、带复制按钮的克隆地址和 **打开**。**Set up Git on your computer** 卡片会逐步介绍安装 Git、创建令牌和克隆，**How to clone** 可重新打开它。**View all in Git** 会打开完整的 Git 界面，**Manage who can push** 会打开分组管理。访问级别为 **查看者**、**Contributor**（向 `apps` 推送应用代码）或 **Administrator**（向所有存储库推送，包括 `udfs`），查看者会看到最多三位可以请求的工作区管理员。新增的 **Git Contributors** 分组授予 Contributor 权限，并且可以作为默认分组，因此新成员会自动获得；**Git Administration** 授予 Admin 权限。成员的 **Git** 选项卡显示其 Git 用户名、级别以及授予该级别的分组。成员的 Git 账户跟随其成员身份：停用或移除成员后，其 Git 账户（包括令牌和 SSH 密钥）会在大约一小时内被阻止，重新激活后即解除阻止，其存储库和历史记录均予保留。使用单点登录登录 Git 时，打开的是该成员自己的账户。Contributor 不会直接在工作区的 Git 组织中创建存储库；存储库通过 PlaidCloud 创建。应用窗口显示 **存储库** 部分，UDF 有 **打开**，Git 有 **← Back to** your workspace 链接。平台创建的每个存储库（包括应用存储库以及内置的 `apps` 和 `udfs` 存储库）对工作区中每位已登录的成员均可读取，因此成员无需针对每个存储库进行设置即可打开并重新发布应用。Git 管理员仍可将存储库设为私有，这会将其从存储库选择器中隐藏，并使成员无法从中发布，或运行其中存放的由 Git 支持的 UDF 代码。请参阅 [PlaidCloud Git](/zh-cn/guides/git/#打开-git) 和[谁可以看到存储库](/zh-cn/guides/connections/plaidcloud-git/#谁可以查看存储库)。
- **Cost to Serve 和 Operational Transfer Pricing 模板基于 Common Finance Model 构建。** 从 **Cost to Serve** 启动项目，可按您为每个部门设置的作业和动因，将运营费用分摊到客户，并查看每位客户在扣除服务成本后的利润率，且与总账相互对应。从 **Operational Transfer Pricing** 启动，可对照您的政策区间测试各实体的利润水平（销售回报率、成本加成净额或转售价格减项），并通过调整补足将超出区间的实体拉回目标。销售回报率为 EBIT 除以受测方销售额。请参阅 [Cost to Serve](/zh-cn/guides/projects/cost-to-serve/) 和 [Operational Transfer Pricing](/zh-cn/guides/projects/operational-transfer-pricing/)。

- **告诉 Weave 您想要什么，它就会构建并运行。** 用于创建项目、工作流、步骤、导入或维度的对话框，以及空列表和空画布，都以 **Tell Weave what you want** 开始，旁边有 **Fill in the form instead**。描述一个工作流，Weave 会用一张计划卡片作答；批准后，即可看到步骤出现在画布上，标有 **Built by Weave**，并可使用**停止**结束构建。可以让 Weave 运行一个工作流、一段步骤或单个步骤，为工作流设置计划或更改其计划，或者更改或添加步骤：每项都是一张由您批准的卡片，每次运行都会关闭 ERP 过账，向 ERP 过账或在 PlaidCloud 之外写入数据的步骤由您自己处理。将数据文件拖放到项目的**概览**或画布上即可生成表或导入步骤；拖放或粘贴 SQL 脚本即可将其重建为标准步骤；拖放 Alteryx 工作流或指定一个包含 Alteryx 工作流的文件夹，Weave 会将其转换为新项目、运行它们，并在迁入报告中将结果与它们写出的文件进行比较。导入完成后，**建议的下一步**会提供可构建的第一个图表或清理操作。请参阅[使用 Weave 构建和运行](/zh-cn/guides/ai-assistant/weave-build/)。

- **离开后 Weave 作业仍会继续运行。** 从停靠栏中的 **Weave** 按钮中选择 **Weave jobs…**，即可查看每个作业的状态、跟踪其进度、打开其对话或停止作业。关闭停靠栏或选项卡后作业仍会继续，作业完成或需要您处理时您会收到消息；对于运行超过一分钟且未被停止的作业，如果使用移动应用，还会收到手机通知。请参阅[持续运行的作业](/zh-cn/guides/ai-assistant/weave-dock/#持续运行的作业)。
- **Weave 新增 Monitor。** **Weave**选项卡的**发现项**页面现在是**Monitor**，其侧栏将**发现项**、**团队**、**活动**、**月度摘要**、**预期**和**请求**归为一组，并将结账检查**就绪状态**和**对账**归入**Close checks**下。**发现项**开头是一行 Weave 的结论，例如 *3 个未解决的问题，其中 1 个属于您。*，以及您离开期间发生情况的说明和结账的进展。磁贴显示未解决的问题、未分配的问题和最早的未解决问题。发现项按严重程度分组，并按其影响的其他内容多少排序；失败的运行只占一行，受其影响的工作流和仪表板折叠在其下。每一行显示其所有者、已打开多长时间以及一个操作，**修复**或**打开**排在最前，其余操作位于 **⋯** 下。打开某一行可以阅读 Weave 的描述、证据、Weave 的判断依据和评论，还可以按**所有者**和**工作流**筛选。在**建议**下，有人按某种规律手动运行的工作流会显示 **Automate this**，用于提议相应的计划。**此为预期**可将某个范围标记为今后的正常情况，**预期**还会列出 Weave 已学到的有关项目的术语和约定。请参阅 [Weave 选项卡](/zh-cn/guides/ai-assistant/weave-tab/)。
- **结账在隔夜准备好。** 对于设有截止时间的就绪集，Weave 每天以及在其所依赖的运行之后检查结账，为能够处理的每个问题准备修复或重新运行，并显示一张卡片，例如 *Month-end close is 92% done. Two things need you.*，其中每项决定都有编号，并有各自待批准的卡片。请参阅[隔夜准备好的结账](/zh-cn/guides/ai-assistant/weave-readiness/#隔夜准备好的结账)。
- **保留 Weave 的回答，并请求报表和警报。** 回答下方的 **Keep ▾** 可将其保留为常设请求、指标、假设分析方案、团队配方或固定的回答。用您自己的话请 Weave 按计划或在工作流运行后提供报表或警报，它会在 PlaidCloud 中、手机上以及通过电子邮件（不含数字）通知您。可在 **Monitor → 请求**中使用 **Run now**、**暂停**、**更改**和**移除**管理您的请求。请参阅[保留回答和常设请求](/zh-cn/guides/ai-assistant/weave-requests/)。
- **询问某个数字为何如此。** 在表资源管理器中右键单击单元格，或在仪表板图表上右键单击点或单元格，然后选择 **Why this number**：Weave 会指出写入该数字的步骤及其来源，以及自上一次运行和上一期间以来的变化。在表资源管理器中，**As of** 按写入表的运行列出表的早先版本，**Compare with now** 会说明此后哪些行和列发生了变化。用文字提出有关分摊结果的假设分析问题，即可立即获得估算。对账的上次结果会被保留，例如 *06:02 与 Cost Pool 对平。* 请参阅[某个数字为何如此](/zh-cn/guides/ai-assistant/weave-numbers/)。
- **与团队共享 Weave。** 固定一个回答，项目中的每个人都能看到它，并以各自的访问权限重新运行。将问题保存为配方，任何人都可以在停靠栏中用 `/` 运行它，也可以在触发时运行。两者都列在项目**概览**的 **From your team** 下。步骤、工作流、表和发现项都有评论对话线程，可以在其中提及团队成员或询问 @Weave；Weave 处理某个工作流时，会在画布上显示。请参阅[与团队共享 Weave](/zh-cn/guides/ai-assistant/weave-team/)。
- **了解 Weave 的价值。** 部分发现项会询问是否值得告知您，提供点赞和点踩。**月度摘要**会显示 Weave 的发现项和回答的有用程度、Weave 修复的失败运行以及团队成员重复使用的固定回答，并估算节省的时间，可按项目或仅针对您查看。请参阅 [Weave 月度摘要](/zh-cn/guides/ai-assistant/weave-monthly-summary/)。
- **在移动端使用 Weave 语音只需轻点一下。** 点击麦克风并提出问题，停止说话后 Weave 就会发送。再次点击麦克风可以提前停止，如果没有听到声音，它会自动关闭。如果您在说话中途离开**Weave**选项卡或将应用切换到后台，您说的话会保留在问题框中而不会发送，以便您检查。运行、暂停、停止和恢复会忽略对其确认按钮的意外双击。需要应用版本 1.3.0 或更高版本。请参阅[使用语音](/zh-cn/guides/mobile-app/weave-on-mobile/#使用语音)。
- **Weave 会通过电子邮件通知您出现的问题。** 您可以为自己开启两种电子邮件：工作流运行以需要您查看的严重问题结束时发送的邮件，以及在您选择的时间发送的每日摘要，汇总 Weave 已告知您但您尚未阅读的问题。电子邮件会指明项目，以及每个工作流、步骤、表或指标和问题类型，并链接回**Weave**选项卡，绝不包含您数据中的数字或值。工作区管理员可以为所有人关闭 Weave 电子邮件，并设置静默时段（按每位成员各自的时区计算），在静默时段结束前暂缓发送警报。请参阅 [Weave 电子邮件](/zh-cn/guides/ai-assistant/weave-email/)。
- **Weave 如何使用您的数据。** 一个新面板位于**Weave**菜单中、每个 AI 聊天下方以及**AI 功能**中，说明您的工作区由哪个 AI 提供商在何处回答 Weave 的请求、Weave 会向其发送哪些内容，以及有关训练和数据保留仍在确认中的事项。请参阅 [Weave 如何使用您的数据](/zh-cn/guides/ai-assistant/weave-data-use/)。

## 变更

- **一个可筛选的清单可在所有位置分配人员、分组和工作流。** 安全组成员、成员的分组关联、分发列表成员、文档账户成员、分组、代理和所有者、连接访问权限以及 Weave 就绪状态集的工作流，都使用同一个选择器，而不再是需要在两个列表之间拖动。输入内容即可按姓名或电子邮件筛选（包括 `@example.com` 之类的域名），粘贴电子邮件列表即可精确匹配这些人员，在 **全部**、**已分配** 和 **Not assigned** 之间切换，并使用 **Assign all shown** 或 **Unassign all shown**。您更改的行带有 **Will add** 或 **Will remove** 标签，**Undo changes** 可将其恢复，只有在有更改时保存按钮才可用。在筛选框中按 **Enter** 绝不会保存，按 **空格** 会勾选所选行。在您可以查看但无法更改访问权限的位置，列表为只读。
- **如果您的工作区使用 Grok，移动设备上的 Weave 会再次要求您同意其 AI 声明。** 该声明不再说 xAI 不会使用您的数据训练其模型，而是说明 PlaidCloud 与 xAI 之间没有零数据保留协议，因此 xAI 可能会保留数据，并按其标准条款允许的方式使用。请参阅 [Weave 如何使用您的数据](/zh-cn/guides/ai-assistant/weave-data-use/)。
- **“What if”窗口一次读取一个期间。** 当 Allocation Split 步骤的输出带有期间列时，窗口会在最新期间打开，**期间：** 可让您选择另一个期间或 **All periods**。如果某个步骤的动因在每个期间都有一行，而数据量大到无法跨所有期间读取，现在会针对某一个期间打开并回答。已保存的方案会保留其保存时对应的期间（如有），打开方案时，只要该期间仍在列表中，窗口就会切换到该期间。请参阅[选择期间](/zh-cn/guides/allocations/results/driver-what-if/#选择期间)。
- **PlaidCloud 的网页应用和 Python 客户端库使用 REST API，JSON-RPC 已弃用。** 网页应用将其请求发送到 REST API。使用 `plaidcloud-rpc` 1.25.0 或更高版本时，`SimpleRPC` 调用会转到 REST API，您的代码无需更改；REST API 尚未涵盖的调用，或仍使用较旧版本的工作区，会像以前一样使用 JSON-RPC。JSON-RPC 将在后续版本中移除，因此请将您的脚本和笔记本升级到 `plaidcloud-rpc` 1.25.0 或更高版本，并针对 REST API 编写新的集成。请参阅[命令行](/zh-cn/reference/cli/jupyter/command-line/)。
- **步骤跟随其项目的连接环境，除非您将其固定到另一个环境。** 在 QA 和 Production 等环境之间切换项目时，每个步骤都会随之移动。必须保持在某一环境的步骤可以改为设置 **Fixed environment**：表单会以警告标记该步骤，其日志会记录每次在项目环境之外的环境上运行的情况，切换项目时会列出不会跟随的步骤。ERP 过账步骤始终使用项目的环境。只要有项目、固定的步骤或代理在使用某个环境，该环境就无法删除，代理表单中的字段现在是 **Environment this agent serves**。请参阅[将步骤固定到一个环境](/zh-cn/guides/projects/managing-projects/#将步骤固定到单一环境)。
- **步骤表单遵循统一的布局。** 选项卡采用标准名称和标准顺序：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单上还有页眉列和行列。必填字段以 * 标记，表单只会因步骤所需的内容而阻止保存。
- **Acumatica、Bill.com、Dynamics、Eclipse、HFM/FCCS、NetSuite、Workday 和 Workday Financials 连接可以创建、编辑并在步骤中选取，设置不会丢失。** 它们保存为 REST 连接，**连接** 列表会显示其自身的类型。右键点击连接并选择 **Edit REST settings**，即可打开其标头、身份验证和分页。**测试连接** 适用于已保存的 NetSuite 和 HFM/FCCS 连接。Workday Financials 连接可使用集成系统用户及其密码（须同时提供）登录，也可使用 OAuth 客户端登录，Workday、Bill.com、Dynamics 和 Eclipse 表单中有 **API 主机** 字段。请参阅[创建和管理连接](/zh-cn/guides/connections/create-connection/)。
- **数据输入表单将每个字段放在其标签旁边。** 字段左对齐、宽度一致，不再固定在最右侧，适用于 Data Foundation 的 **连接** 和 **源**、文档账户设置以及成员配置文件。
- **复制项目会分别选择表数据和维度成员，复制数据更快，并保留私有副本的 ERP 写入授权。** 在 **Data to copy** 下，选择 **表数据**（**No table data**（默认）、**完整** 或 **样本**），并单独选择 **Copy dimension members**（默认开启），因此不含表行的副本仍会带有已填充的维度，而且创建速度很快。**完整** 和 **样本** 副本会同时复制多个表，因此包含许多表的项目完成得更快。**复制结果** 会将每个维度的结果与各表一起列出，**Retry failed items** 会一并重试失败的表和维度。包含数据创建的新副本仅您自己可见，并保留您自己有权授予的、来源的 ERP 写入授权；如果来源以实时方式过账，副本会处于模拟状态，因此在您将其切换为实时之前，不会有任何内容到达 ERP。REST API 和 `project_copy` MCP 工具也接受 `dimension_members`。请参阅[选择要复制的数据量](/zh-cn/guides/projects/managing-projects/#选择复制多少数据)和[副本中的 ERP 写入授权](/zh-cn/guides/projects/managing-projects/#副本中的-erp-写入授权)。
- **表的详细信息面板更快地显示使用它的步骤。** 选择另一个表时，会立即清除前一个表的步骤，与本项目共享数据的其他项目中的步骤会在其余内容之后稍等片刻再添加，而不会使整个面板延迟。请参阅[查看表的使用位置](/zh-cn/guides/projects/managing-tables-and-views/#查看表的使用位置)。
- **工时和费用中的发票列表打开更快，并可按需加载更多。** 它显示与您的状态和搜索相匹配的最新 100 张发票，还有更多时，**加载更多**会再添加 100 张。选择**全部**或**已支付**只对该次访问有效，下次访问会打开到**未结**。
- **行操作在每个列表中的工作方式相同。** 可通过行首的 **⋯** 按钮、右键单击该行或工具栏的 **操作** 菜单打开行的菜单。它始终先列出 **打开**、**详细信息** 和 **编辑**，然后是该列表自己的操作，最后是 **删除** 或 **移除**，不适用于某行的操作会以灰色显示在原位。**Enter** 和 **Del** 显示在它们所执行的项目上。行只有一个操作的列表会显示该操作的图标，而不是 **⋯**，仪表板、应用和 Notebooks 再次显示 **打开** 图标。请参阅[行操作菜单](/zh-cn/guides/dashboards/using-dashboards/#行操作菜单)。
- **PlaidCloud 焕然一新，采用蓝色外观，支持浅色和深色。** 按钮、复选框、选中的行、选项卡、链接以及列出工作区页面的导轨使用同一种 PlaidCloud 蓝，并具备在两种主题中阅读所需的对比度。应用选项卡图标为统一的一套。
- **全新的加载画面。** PlaidCloud 会以更简洁的加载画面打开，并跟随您的浅色或深色主题。从空闲状态唤醒的 Panel 或 Dash 应用会显示 **正在启动**、**正在准备…** 和 **Loading app** 的进度，如果未能启动，会说明停在哪一步，并提供 **重试**。请参阅[使用 Panel 应用](/zh-cn/guides/panel-apps/using/)。
- **没有验证设置的已保存 ERP 写入步骤以仅验证方式打开。** 这涵盖 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL 和 AP Post，以及 Xero 导出。明确设置为实时运行的步骤保持实时。
- **长时间运行的作业在所有位置以相同方式显示进度。**
- **工作流如实地停止、失败和报告。** 停止工作流会停止其启动的所有内容，无法完成的运行或步骤会以原因失败而不是挂起，运行状态与实际运行的内容一致。
  - **停止工作流会停止其启动的所有内容，无法完成的运行或步骤会失败而不是挂起。** 停止会取消仍在排队的导入和维度步骤，使工作区中后续的导入和维度加载正常启动，同时也会停止该工作流排队中或运行中的连接器（Singer）同步。如果某个步骤的作业无法启动，该步骤会以原因失败，而不是永远等待：约 40 分钟内没有工作进程启动它、工作进程启动后消失、其 Pod 约 20 分钟一直处于 Pending、其映像约 5 分钟无法拉取，或约 20 分钟没有创建 Pod。约 30 分钟内没有运行器接手的连接器同步会失败，并给出指明该同步的消息。步骤等待工作进程时，其状态消息显示“正在等待工作进程…”及已等待的分钟数，工作开始后消失。停止宏会停止其所有正在运行的副本，而停止某一个副本，或 **Macro Concurrent** 步骤放弃已停止响应的副本，都会使调用它的工作流继续运行。仅在其他工作流内部运行的宏会在工作流列表中显示为 **正在运行**，可使用 **停止**，并显示每个步骤最近一次运行的状态、开始和结束时间。服务器丢失的运行会以失败结束，运行超过 12 小时仍未结束的运行会失败，并显示“Run failed: still running at the 12-hour limit. Re-run the workflow.”。请参阅[运行工作流](/zh-cn/guides/workflows/run-a-workflow/#永远无法启动的步骤)。
  - **继续、运行历史记录和运行状态与实际运行的内容一致。** 继续父工作流会运行子工作流剩余的所有内容，即使您已单独重新运行过子工作流的某个步骤；同一次运行中子工作流的每次调用都有自己的运行历史记录条目。因服务器停止而重新启动的步骤会在其日志中说明，并且 `workflow_run_status` 和 REST API 的运行结果会在 `continued_step_ids` 和 `continued_step_count` 中列出失败但继续运行的步骤，而不是将运行报告为正常。请参阅[暂停、停止和继续](/zh-cn/guides/workflows/run-a-workflow/#暂停停止和恢复)和[出错时继续](/zh-cn/guides/workflows/continue-on-error/)。
  - **步骤错误显示其自身的消息。** PlaidCloud 未预料到的错误显示为“The step stopped on an unexpected error (*type*): *message*”。启动器上的 **需要关注** 卡片以一行显示错误，并省略此后已被删除的工作流的运行。请参阅[管理步骤错误](/zh-cn/guides/workflows/managing-step-errors/)。
  - **未完成的 ERP 提取会使其步骤失败，继续会接着提取。** 当 **SAP：临时提取** 在其行数或时间限制处暂停，或其代理未及时回复，或者 Salesforce、Oracle Fusion 批量或 HFM/FCCS 导出作业在步骤停止等待时仍在运行，该步骤会失败，这样其后的步骤就不会基于不完整的表运行。继续工作流或重新运行该步骤，提取会在同一作业上从停止处继续。请参阅[运行限制](/zh-cn/guides/connections/sap-adhoc-extract/#运行限制)和[Salesforce：查询对象](/zh-cn/reference/workflow-steps/salesforce/query-salesforce-object/#运行未完成时)。
  - **取消导出会停止其在仓库中的查询。** 取消导出或下载时（包括通过停止其工作流），在 Lakehouse v2、Snowflake、Databricks、PostgreSQL 和 Greenplum 上读取其数据的查询也会随之停止，导出到远程数据库的步骤会停止读取其源，而不是一直运行到结束。
- **工作区升级时，REST、Import REST 和 Import Postman 步骤会转换为 REST 请求。** 无法干净转换的步骤保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **会话过期后打开的仪表板链接，会在您登录后带您进入该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**，并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为其另一个名称。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。
- **在 Lakehouse v2 上，Lakehouse 自身将 Parquet 导出写入 Google Cloud Storage。** 导出到 Google Cloud Storage 文档账户时，会使用该账户自己的凭据直接写入账户的存储桶，而不是让每一行都先经过 PlaidCloud。导出到 Amazon S3 和 Azure Blob Storage 账户的方式与以前相同。请参阅[导出到 Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/)。
- **Slack、Microsoft Teams 和 Web Hook 步骤会说明消息未发送的原因。** 步骤的错误会指明其尝试访问的服务器，对于 Slack 和 Teams 还会指明连接，并说明出了什么问题：例如 Slack 不再识别该 Webhook、无法向该频道发帖、找不到服务器或服务器在 60 秒内没有响应，或者连接已被删除。Slack 或 Teams 的 Webhook URL 绝不会显示，因为任何持有它的人都可以冒充您的集成发帖。请参阅 [Notify via Slack](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/)。
- **项目服务账户的访问令牌至少持续 24 小时。** 以项目身份运行的工作流作业（例如 UDF 步骤）获得的令牌持续 24 小时。较短的有效期会在工作区升级时提高，您设置的较长有效期会保留。
- **工作区的组织、所有者、发布和版本由 PlaidCloud 设置，您可以选择其数据中心。** 在控制平面中，您创建的工作区归您所有，并放置在 PlaidCloud 设定的发布渠道上，您可从注册时提供的区域中选择其 **Data Center**。编辑工作区时，组织、所有者、发布和版本为只读。使用 **Set Version** 更改版本，如需移动工作区、更改其所有者或渠道，或将其固定，请联系 PlaidCloud 支持。请参阅[工作区配置](/zh-cn/administration/control-plane/workspace-configuration/#主要设置)。
- **编码转换步骤可以保留文件夹的子文件夹。** **文档：将文件转换为 ASCII 编码**、**文档：将文件转换为 Unicode (UTF-8) 编码** 和 **文档：将文件转换为 Unicode (UTF-16) 编码** 有一个 **保留子文件夹** 复选框。勾选后，会将输入文件夹的子文件夹中的每个文件写入目标的对应子文件夹；压缩文件的内容进入其所在的子文件夹。不勾选时，每个文件都直接写入目标本身，与以前相同。请参阅[将文档编码转换为 UTF-16](/zh-cn/reference/workflow-steps/document/convert-document-encoding-to-utf-16/)。
- **源表与其设置不匹配的步骤会在写入任何内容之前停止，并一次性指出所有问题。** Table Extract、Table Lookup、Table Inner Join、Table Cross Join、Table Outer Join、Table Anti Join、多表联接、Table Union Distinct、Table Union All、Table Pivot、Table Melt、Table In-Place Delete、Table Upsert 和 Table Append 步骤会在写入之前检查其源表。步骤读取的列在表中不存在、联接键缺失或不在步骤的源列中，或者步骤读取的源表尚未构建，都会使步骤停止，并给出一条错误，指明每个问题及修复方法，已存在的目标表会保留其原有内容。Table Union Distinct 和 Table Union All 在源表尚未构建这一点上是例外：与以前一样，它们会不加警告地将其省略并合并其余表，如果一个都未构建，则以警告完成而不是失败。步骤列出但并未读取、且表中已不再存在的列，则只是警告，因此以前能运行的步骤仍可运行。对于目标为视图的步骤，仅在仓库本来就会拒绝创建视图的情况下，才会对照其表检查它所列出的列和联接键。这些失败过去由数据库以其自己的措辞逐列给出，而替换其目标表的步骤此时已将其清空。如果工作流的错误处理匹配数据库的文本，请更新它。请参阅[步骤运行时](/zh-cn/reference/workflow-steps/tables/table-extract/#运行时指定名称的列)。
- **没有表的导出会停止，而不是直接完成。** 没有表的 Export to Parquet、Export to ORC 或 Export to Avro 步骤过去会在未写入文件的情况下完成，没有表的 Export to XML 步骤则会写入一个不含任何内容的文件。这些步骤现在会在写入任何内容之前停止，并显示 *No Tables Specified*。完全没有保存表列表的步骤过去会以指明内部设置的意外错误失败，现在会以相同的消息停止。

## 已修复

- **无效的项目设置会以清晰的消息报告。** 未知的环境或文档账户、已被占用或保留的标识，或无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 时返回 400 而不是 500，通过 AI 助手或 MCP 时则为无效参数错误。
- **REST API 的维度值请求恢复正常。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 过去被当作网格请求处理并被拒绝为无效。它现在为 `value_columns` 中的每一列返回一个聚合值，而网格（每一对行筛选器和列筛选器对应一个值）有自己的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻碍其他请求。** 从仓库读取表的列、登记 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，过去都可能使同一服务器正在处理的其他所有请求暂停，直至其完成。它们现在与这些请求并行运行。
- **项目和工作流变量对话框可以滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口还高，导致 **创建** 和 **更新** 按钮可能够不到。现在表单可以滚动，按钮保持在底部。
- **Azure Blob Storage 文档账户中超过 256 MiB 的文件可以复制、移动和重命名。** 过去对这种大小的文件执行这些操作都会失败，移动或重命名包含此类文件的文件夹同样会失败。
- **在 Lakehouse v2 上，表的行数反映刚写入的内容。** 写入表的步骤或导入可能记录写入之前的行数，因此刚加载的表显示 0 行，导入也可能报告导入了 0 行。现在会在新行对所有位置可见之后再读取行数，因此其后的步骤也能读到这些行。将表切换到另一个分支，或将分支合并到表中，也会更新其行数和列数。
- **Weave 的空值检查会将每次运行与之前的运行实际留下的内容进行比较。** 步骤的空值经常是在步骤清空其表以重新填充之后才被统计，因此其之前的运行看起来没有空值，而始终有部分为空的列被报告为刚刚才变为如此。现在每次运行都按步骤留下表的状态统计。之前记录的计数无法与正确的计数区分，因此不会使用它们：每个步骤的空值检查会重新开始其历史记录，在统计满五次运行之前报告为未检查。行数和值分布检查也不再将另一个步骤在其完成两秒之后对同一个表所做的写入记在该步骤名下。请参阅 [Weave检查内容](/zh-cn/guides/ai-assistant/weave-findings/)。
- **Data Foundation 保留倒转汇率和小数阈值的精度。** 当您的汇率是从报告货币报价到另一种货币时，PlaidCloud 会将其倒转，该汇率可能被四舍五入到六位小数，导致汇率很小的货币（例如印尼盾）的金额偏差约 1%。倒转后的汇率现在保留 12 位小数。带小数的 `group_amber` 或 `group_red` 阈值（例如 `0.5`）过去会被四舍五入为整数。您的下一次加载将使用精确的值。请参阅[汇率](/zh-cn/guides/projects/data-foundation/#汇率)。
- **已停用成员的提醒和摘要会停止。** 所有者已被停用的 Panel 应用提醒或摘要过去仍会持续检查和发送。现在在其被停用期间会暂停，重新激活后会恢复。请参阅[提醒与摘要](/zh-cn/guides/panel-apps/alerts-and-digests/)。
- **向 REST API 请求已删除的连接时返回 404。** 请求已被删除的连接或不存在的 ID，过去会返回通用的服务器错误（500）。现在返回 404 及指明连接 ID 的消息。
- **通过 AI 助手和 MCP 可以使用模板化的表导出。** `table_data_export` 的 `templated` 格式在传入表时总是失败。现在它会通过您的模板导出该表，并限定为您可读取的行。在模板中，表的行以其表 ID 命名，其中每个 `-` 写作 `_`。
- **Amazon S3 和兼容 S3 的文档账户会保留其区域。** 保存这类账户时会丢弃您输入的 **区域**，因此下次打开账户时该字段为空。现在会保存区域。对于在此修复之前保存的账户，请重新输入区域并保存。请参阅[添加 AWS S3 账户](/zh-cn/guides/documents/adding-accounts/add-aws-s3-account/)。
- **转换文件夹的编码时不再用同名文件覆盖文件。** 目标中同一位置的两个文件（例如来自不同子文件夹的两个同名文件）过去只会留下最后写入的那个。现在步骤会在写入第二个之前停止，指出这两个文件及其目标位置，并在勾选 **保留子文件夹** 可使它们互不冲突时予以说明。
- **取消勾选“文档：将文件转换为 ASCII 编码”中的替换字符后会生效。** 勾选了 **将目标编码无法表示的字符替换为 ?** 的步骤，在取消勾选并再次保存步骤后仍保持勾选状态。现在取消勾选会关闭替换。
- **AI 助手和 JSON-RPC 不再指出使用了您的角色所隐藏的表的步骤。** 在询问此类表的使用位置时，过去它们会指出您的角色可见的、读取或写入该表的每个步骤，以及其设置和工作流。现在它们只说明有步骤使用该表而不指出这些步骤，与项目的表引用方式相同。请参阅[您的角色隐藏的内容](/zh-cn/guides/ai-assistant/weave-tab/#您的角色隐藏的内容)。
- **您选择的默认 AI 连接保持为默认。** 将某个 AI 连接标记为工作区默认连接看似成功，但从未被保存，因此依赖默认连接的代理和步骤仍使用最近更新的那个连接。现在您的选择会被保存。请参阅 [LLM 提供商](/zh-cn/integrations/ai-architecture/llm-providers/#连接包含的内容)。
- **在 Weave 历史记录中右键单击对话不再在“删除对话线程”之上打开重命名。** **重命名** 现在位于聊天的选项卡上：右键单击该选项卡，此前它没有提供任何内容。请参阅 [Weave 选项卡中的选项卡](/zh-cn/guides/ai-assistant/weave-tab/#weave-选项卡中的选项卡)。
- **空白的备注不再阻止保存。** 在 **备注** 框留空的情况下创建或保存项目、维度、表、仓库、编辑器、计划的工作流事件或分发列表，过去会失败并显示“Memo: Input should be a valid string”。现在接受空白备注。
- **在应有一个值的位置给出多个值的表达式会被拒绝，并且 Table Extract 或 Table Union All 步骤会保留其目标表的数据。** 常见原因是结尾的逗号（如 `table.amount,`），或与多个值的比较（如 `table.region == ('EU', 'US')`）。在 Databend 上步骤会失败，而此时 Table Extract 或 Table Union All 步骤已经清空了其目标表。其他一些仓库会运行此类表达式，但不一定按所写的方式运行，因此一直无错误运行的步骤现在可能会被拒绝。保存步骤时，步骤表单会拒绝该表达式，消息会显示需要更改的内容。请参阅[在应有一个值的位置给出多个值](/zh-cn/reference/workflow-steps/common/advanced-data-mapper-usage/#期望单个值时给出了多个值)。
- **两次使用同一输出列名的步骤会在清空其目标之前停止。** 在 Table Lookup、Table Extract 或联接中，两个同名的 **目标输出列** 会使步骤先清空其目标表，然后以含义不明的错误失败。现在步骤会先停止，并给出指明重复列的消息，以便您为每个输出列指定各自的名称。提取 SQL 按您的查询返回的顺序写入列，因此保持不变。请参阅 [Table Lookup](/zh-cn/reference/workflow-steps/tables/table-lookup/)。
- **保存时没有源列的联合源会说明缺少什么。** 通过 REST API、JSON-RPC，或 AI 助手或 MCP 保存的、没有源列列表的 Table Union All 或 Table Union Distinct 源，在步骤运行时会失败，并显示指明内部设置的意外错误。现在保存这样的源会被拒绝并指明该源，读取在此之前保存的此类源的步骤会在写入任何内容之前停止，并指明该源。从其表中取全部列、或按位置堆叠它们的已转换 Table Union All 无需列表，也不会因没有列表而被拒绝。
- **列的常量可以是数字、`0` 或 `false`。** 输出列的常量为数字的步骤过去会因意外错误而失败。常量为 `0` 或 `false` 会被视为根本没有常量，因此该列改为采用其表达式或源列，或者因该列没有可读取的内容而使步骤失败。现在这些常量会转换为列的数据类型后写入每一行，AI 助手也可以提议带有此类常量的步骤。
- **转换后的 Alteryx Data Cleansing 工具会删除空值行。** 勾选了 **Remove Null Rows** 的 Data Cleansing 或 Data Cleanse Pro 工具在转换报告中会被标记为需要审核，其转换后的步骤会保留所有行。现在该步骤会像 Alteryx 一样，删除在每一列中都为 null 的行。包含空文本值的行会被保留。Data Cleanse Pro 在处理完其他选项之后才检查每一行，因此其 null 被替换为空文本的行同样会被保留。**Remove Null Columns** 仍会被标记为需要审核。请重新导入工作流以获得此修复。
- **未列出列的电子邮件通知会包含所有列。** 过去，未选择列的 Notify Via Email 框架会导致运行失败。在模板正文中，主题里的 `{variable}` 占位符会在计划发送、预览和 **向我发送测试** 时被填充。
- **表达式验证接受运行时接受的函数。** 过去，调用 `int(...)` 等函数的有效表达式在检查时会被拒绝。

## 安全

- **Weave 不再在每次对话开始时将您的姓名和电子邮件地址发送给其 AI 提供商。** 它从未使用过这些信息。
- **密码登录需要身份验证器应用，密码也更强。** 使用 PlaidCloud 密码登录的成员会在下次登录时被要求设置身份验证器应用，此后每次都要输入其验证码。单点登录、Google、Microsoft 和 GitHub 登录、API 令牌和服务账户保持不变。新密码至少需要 12 个字符，不能是您的用户名或最近六个密码之一，多次登录失败后账户会被锁定一小段时间。工作区已有的更严格规则会保留。请参阅[成员身份验证](/zh-cn/administration/access/member-authentication/)。
- **连接指向公共和专用网络地址。** 连接不能指向环回地址、链路本地地址或云元数据地址，错误会指出主机及其解析到的地址。您专用网络上的地址不受影响。请参阅[连接无法访问的地址](/zh-cn/guides/connections/create-connection/#连接无法访问的地址)。
- **已保存的连接凭据仅向可以编辑连接或工作流的成员显示。** 通过 REST API 和 MCP，已保存连接的密码、令牌和密钥会对其他成员隐藏，他们仍可打开并浏览该连接。请参阅[谁可以看到连接的凭据](/zh-cn/guides/connections/create-connection/#谁能看到连接的凭据)。
- **应用构建在运行时无法访问您工作区的 Git 凭据。**
- **代理的私钥仅向可以编辑代理的成员显示。** 通过 REST API 和 MCP，代理列表或详细信息中不再出现该密钥，代理表单仅向可以编辑代理的成员显示 **私钥** 和 **查看 RPC 配置**。服务账户、项目和代理令牌以及 AI 委托的令牌无法检索密钥或 RPC 配置。正在运行的代理不受影响，公钥仍会显示。请参阅[获取代理凭据](/zh-cn/reference/cli/plaidlink/agents/#获取代理凭据)。
- **代理下载链接的有效期为一小时。** 开启 **Use PlaidCloud Proxy Download** 后，如果链接已过期，请再次打开下载以获取新链接。请参阅[服务](/zh-cn/administration/control-plane/workspace-configuration/#服务)。
- **将人员添加到安全组遵循您所拥有的权限。** 当您拥有某个分组授予的每一项权限时，才可以将成员添加到该安全组、选择成员的分组或邀请架构师。工作区管理员不受限制。请参阅[管理安全组](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理安全组)。
- **连接的所有者或工作区管理员可更改其设置并将其开启或关闭。** 通过 REST API、JSON-RPC 以及 AI 助手或 MCP 更改连接的设置，需要其所有者之一，对没有所有者的连接则需要工作区管理员。启用、停用、锁定和解锁连接需要所有者或工作区管理员，指明多个连接的请求仅在您可以更改所有这些连接时才会应用。只有工作区管理员可以选择工作区的默认 AI 连接，并且仅当没有任何由管理员拥有或无所有者的连接可以成为默认连接时，成员拥有的连接才会成为默认连接。请参阅[编辑连接](/zh-cn/guides/connections/create-connection/#编辑连接)和 [LLM 提供商](/zh-cn/integrations/ai-architecture/llm-providers/#连接包含的内容)。
- **行访问适用于成员对受限表所做的一切操作。** 在仪表板、自己的 SQL 和加载中，成员只能查看和更改其授权所允许的行。
  - **项目架构师在仪表板中可看到行受限表的所有行**，与他们在 Analyze 中看到的一致。撤销架构师访问权限会在仪表板中立即生效，无论是更改某人的角色、将其或其分组从项目中移除、更改项目的访问类型、还原项目的早期版本，还是删除安全组。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
  - **受行访问限制的成员可以运行自己的 SQL 查询并导出结果。** 在设置了行访问的项目中，非架构师成员在查询屏幕上通过自己的查询只能得到其授权所允许的行，并且可以将其导出为 CSV、Excel 或 JSON，同时显示 **行数受您的访问权限限制** 的提示；此前这些操作会被拒绝。包含百分号（`%`）的授权值现在会在查询屏幕上返回其行，将此类查询下载为 CSV 也可正常工作。他们在 Snowflake 或 Databricks 上自己的自由格式 SQL、从 Postgres 系列仓库导出自己的 SQL，以及按快照时间读取受管控的表，仍然会被拒绝，并且视图必须以原始名称保留受管控的列才能被筛选。请参阅[行访问和您自己编写的查询](/zh-cn/administration/access/managing-security-groups-and-assignments/#行访问与您自己编写的查询)。
  - **保存行访问时会保留其源中不存在的已授予值。** 当表中没有包含某个值的行、维度中没有该成员，或列表中没有该值时，安全组被授予的该值会保留在网格中并带有标记。**保存** 会询问是保留还是移除每个这样的值。请参阅[行访问网格](/zh-cn/administration/access/managing-security-groups-and-assignments/#行访问网格)。
  - **DataFrame 写入、记录保存以及对行受限表的清除只更改您可见的行。** 当行访问限制了您的行时，使用 Python 客户端将 DataFrame 写入受限表或将其清除，或通过 REST API 向其保存记录或将其清除，只会更改您自己的行，并且带有您访问范围之外某一行的加载会在任何更改之前被拒绝，并指出所发现的值。项目架构师、可看到所有行的成员以及工作流运行会写入整个表。个人对任何表所做的上述每种写入都会记录在安全日志中。请参阅[向受限表加载数据](/zh-cn/administration/access/managing-security-groups-and-assignments/#向受限表加载数据)。
  - **对行受限表的导入、复制、还原和删除要求每一行对您可见。** 当行访问限制了您的行时，将文件导入受限表、从另一个项目向其中复制表、切换或合并其分支、还原它、删除它、在其被删除后恢复它，或任何其他替换整个表的操作，只有在您可以看到该表的每一行时才会运行；否则会被拒绝，且不会有任何更改。通过 REST API 保存表的行只会更改您自己的行，与其他加载相同。项目架构师、可看到所有行的成员以及工作流运行不受影响，这些操作也会记录在安全日志中。请参阅[向受限表加载数据](/zh-cn/administration/access/managing-security-groups-and-assignments/#向受限表加载数据)。
- **只有账户的所有者才能还原其早期版本。** 将文档账户还原到早期版本、保留或释放某个版本以及创建备份，都需要该账户的所有者之一，并且在系统管理的账户上均不可用。查看账户的版本历史记录需要拥有该账户的访问权限。
- **`query_run` 运行只读语句。** AI 助手和 MCP 客户端使用的 `query_run` 工具接受一条 SELECT 或 WITH 语句、对其的 EXPLAIN，或一条 SHOW；其他任何语句都不会运行。要更改数据，请使用 `query_transform`。MCP 表导出中的 SQL 遵循同样的规则。对于无法更改项目数据的成员，通过 REST 和 JSON-RPC API 时，该规则也适用于运行查询、构建列分面、将查询下载为 CSV、将查询导出到远程数据库，以及使用您自己的查询导出表数据；被拒绝的查询返回 403。Explain Analyze 会运行查询以进行度量，因此在查询日志和 Lakehouse 中，它只接受读取数据的查询，并且在设置了行访问的项目中，只有项目架构师才能从查询日志运行它。
- **表资源管理器筛选器、发送到 PlaidCloud 的查询，以及查找 Table Extract 步骤的动态列的查询，不能调用运行 SQL 或读取服务器文件的函数。** 对此类函数的调用（例如 `query_to_xml`、`dblink` 或 `pg_read_file`）会被拒绝，错误会指出该函数。在同样的位置，`.op()` 只接受运算符，`literal_column` 不能使用 Unicode 转义引用。动态列查询带有步骤的筛选器以及从源中读取列名的表达式，因此违反规则的查询会在步骤运行时使步骤失败。请参阅[被拒绝的函数和运算符](/zh-cn/reference/workflow-steps/common/advanced-data-mapper-usage/#会被拒绝的函数和运算符)。
- **Data Foundation 分摊规则会拒绝包含单引号、反斜杠或换行符的部门或统计名称。** 该名称会写入分摊步骤的筛选器，因此 **保存** 和第 1 阶段的预览会拒绝它并指出该值。请参阅[分摊规则](/zh-cn/guides/projects/data-foundation/#分摊规则)。
