## 新增

- **控制平面中的 Trust Center 为安全团队提供 PlaidCloud 的安全文档。** Admin 和 Security 用户可为其组织打开 **Trust Center**，立即下载子处理方列表和 DPA 等公开文档；为整个组织签署一次安全文档保密协议（NDA），即可解锁 SOC 2 Type II 报告等受限文档。其他 Admin 和 Security 用户可以看到谁在何时签署。合同中已包含 NDA 的组织可将其标记为已存档，这样无需签署即可解锁文档。受限文档的下载带有水印并会被记录，新版本的 NDA 需要重新接受。Admin 和 Security 用户还可以按组织选择接收每日电子邮件摘要，内容为新增或更新的文档以及新版本的 NDA，邮件本身不包含文档。请参阅 [Trust Center](/zh-cn/administration/control-plane/trust-center/)。
- **PlaidXL 可在 Excel 中构建、钻取、解释和规划。** **PlaidCloud** 功能区选项卡分为 **连接**、**插入**、**刷新**、**钻取**、**写入** 和 **共享**；常用命令也在 **PlaidXL** 右键菜单和 **PlaidXL Cell** 选项卡上，主要命令带有可更改的键盘快捷方式，在字段中输入时不会触发。命令失败时会说明是哪条命令以及原因。登录前运行的命令会打开登录窗口，并在登录后运行一次；一次登录对应一个工作区，因此切换工作区时会要求登录新工作区（切换回来则无需重新登录）；在 Office 中使用 Microsoft Entra 工作账户时，PlaidXL 会自动找到您的工作区。请参阅 [PlaidXL 参考](/zh-cn/reference/cli/plaidxl/)。
  - **几次点击即可构建报表。** **报表**选项卡根据表布局出实时报表：一个维度向下钻取到行，另一个维度横跨列，每个交叉点放置一个 `CELL` 值。**Build my first report** 会用您自己的数据生成示例。钻取时，报表会插入和删除整行整列，您键入的值、备注和格式会随所在行保留。请参阅[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)。
  - **从任意单元格钻取。** **Drill down**、**Drill up**、**Keep only** 和 **Remove only** 可将节点转换为实时的 `DRILL` 公式并为您编辑，起点可以是节点、维度标题或报表值。**Custom drill** 会在插入前预览行，成员选择器可插入成员，或为单元格添加节点子级的下拉列表。`DRILL` 可接受要排除或展开的节点，并可跨行运行。请参阅[钻取、选取成员和解释数字](/zh-cn/reference/cli/plaidxl/drill/)。
  - **解释数字。** **Explain this number** 显示值的计算方式、是否与 PlaidCloud 当前一致，以及其来源的表和工作流步骤。**Show detail rows** 会将值背后的行放在单独的工作表中，并检查它们是否相加一致。
  - **Excel 中的受治理指标。** `PLAIDXL.METRIC` 和 `PLAIDXL.METRIC_BREAKDOWN` 按仪表板显示的方式返回业务指标；没有可聚合内容的 `CELL` 或 `CELLS` 对于求和显示 `0`，其他情况显示 `#VALUE!` 并附原因（在 `CELLS` 溢出区域中为空白）；**Metric...** 列出项目的指标及其当前值。指标可以按多个备用层次结构筛选，并可将备用层次结构成员与其他维度的成员混合使用。请参阅[指标](/zh-cn/reference/cli/plaidxl/functions/#指标)。
  - **在报表中直接键入以进行规划。** 在 `CELL` 值上键入数字，即会写入 PlaidCloud：可按比例分摊、平均分摊或按另一成员的形态分摊，可按金额或百分比调整，已锁定的单元格保持不变。平均值、中位数、最小值、最大值、标准差和方差单元格也接受键入的值；插入或删除行或列时，键入的值会跟随其单元格（已删除单元格中的值会被报告）**。Undo last write** 按从新到旧的顺序撤消键入的值和保存，且只有进行写入的人员和工作区才能撤消。撤消求和，或撤消在空单元格中键入的平均值，会保留此后写入相同单元格的内容；写入过程中中断、未完成的操作无法撤消。请参阅[向 PlaidCloud 键入值](/zh-cn/reference/cli/plaidxl/write-values/)。
  - **只刷新所需内容。** 可刷新一个工作表、一个选区或所有表，任务窗格中显示每个表的进度和 **取消**，也可以只重新计算 PlaidXL 公式。在 Excel 网页版和当前桌面版 Excel 中，大表的检索速度大幅提高（143,000 行、77 列的表约需一分钟，而此前需十多分钟；旧版 Excel 的行为不变），超出 Excel 单元格容量的文本会被标记并避免在保存时被截断。检索到的表以按数据类型设置格式的 Excel 表格形式到达，刷新时保留您自己的列和数字格式，并在原位置刷新。检索或刷新绝不会覆盖其他单元格或与其他 Excel 表格重叠，超出 Excel 范围的整数 ID 和 1900 年之前的日期以文本形式到达。再次检索某个表不会将其重复加入刷新列表，**Stop refreshing** 可将某个表移出，维度会随表一起刷新。请参阅[刷新所有表](/zh-cn/reference/cli/plaidxl/retrieve/#刷新所有表)。
  - **保存即时写入并可撤消。** **Save to PlaidCloud** 无需确认即可写入，说明已执行的操作，并提供 **撤消**；对于 Lakehouse 表，每次保存后 7 天内均可撤消。使用筛选器检索的工作表、明细行工作表，或访问权限只涵盖部分行的用户，只会替换相应的行，因此其他人的行会保留。成员在您检索后已发生变化的钻透工作表不会被保存；保存失败时会指出还原点，以便将表恢复原状。请参阅[将表保存到 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)。
  - **在 Excel 中询问 Weave。** 在 **Weave** 选项卡上，用自然语言请求报表、公式、钻取或表，也可选择 **Ask Weave about this cell**。Weave 以您的身份读取 PlaidCloud，只更改工作簿，在替换您已输入的内容前会先询问，绝不写入引用工作簿之外的公式，并且在重新加载窗格之前，每项更改都可以还原。请参阅[在 Excel 中询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。
  - **共享单个工作表或整个工作簿的纯值副本。** **Convert to values** 可转换整个工作簿、单个工作表，或转换为无法恢复的纯值（会先询问），只更改 PlaidXL 公式及其溢出区域，仍在计算的公式会保留以便再次尝试；重命名工作表后，**Restore PlaidXL formulas** 仍然有效。
  - **任务窗格焕然一新。** 它与 PlaidCloud Web 应用保持一致，采用品牌蓝、导轨式选项卡和列表，表、维度、项目和列显示在带边界的可滚动卡片中。键盘焦点显示清晰的焦点环，窗格会跟随 Office 的浅色或深色主题。在窄窗格中，选项卡排成三列两行，宽度达到 560 像素时排成一行。请参阅[浅色和深色主题](/zh-cn/reference/cli/plaidxl/connect/#浅色和深色主题)。
  - **窗格中的数字遵循 Excel 的显示语言。** 行数和列数，以及刷新、重新计算、Explain、公式、报表和规划消息中的数字，均按您的 Excel 方式显示，例如德语 Excel 显示 4.812.233。写入单元格的值不变。
  - **工作表刷新时，其选项卡会变为黄色。** 在 **Refresh All Tables** 期间，无论从窗格、功能区还是 Weave 发起，每个工作表在刷新时其选项卡为黄色，完成、失败或取消后恢复为之前的颜色（包括您自己设置的颜色）。如果在中途保存并关闭工作簿，下次 PlaidXL 在其中启动时会恢复选项卡颜色。请参阅[刷新所有表](/zh-cn/reference/cli/plaidxl/retrieve/#刷新所有表)。
- **过账登记簿打开时即显示需要您处理的内容。** 有事项需要查看时，它打开到 **异常**；有请求等待您处理时，打开到 **审批**；否则打开到 **所有过账**。侧栏将各屏幕分为 **需要我处理**、**登记簿**、**洞察** 和 **设置**，**异常** 和 **审批** 上带有计数；每个屏幕共用同一个页眉和范围栏：选择期间（**本月**、**上个月**、**最近 7 天**、**最近 30 天** 或 **自定义**）、连接、项目、环境或实体，以及 **实时**、**模拟** 或 **全部**，然后 **重置** 或保留 **Saved scope**。系统会记住您上次的范围。
  - **异常会整理出需要查看的内容。** **需要查看**、**未确认**、**待处理**、**失败** 和 **冲销待处理** 标签显示各自的计数，连接健康状况行显示“所有 N 个连接过账正常”，每笔过账都有通俗易懂的英文状态，并通过工具提示说明下一步该做什么。没有未决事项时显示 **All clear**。将分类账 ID 粘贴到 **Find a posting by ledger id** 或命令面板中，即可直接打开该笔过账。
  - **审批、委派和关注均为收件箱式屏幕。** 在 **Waiting on me** 和 **Submitted by me** 之间切换，可 **批准** 或 **拒绝** 并填写原因，可一次批准多项，还可从提示消息中 **撤消** 批准。**Delegate approvals** 是一个简短的对话框，**我的关注** 列出您关注的内容。**冲销过账** 以及批量重试和清除对话框共用同一布局。
  - **过账的抽屉会说明发生了什么。** 它显示状态及其含义、按名称列出的关键事实，以及 **明细行**、**历史记录** 和 **签核** 选项卡，并提供 **标记为已审核**、**重试**、**冲销…**、**关注连接**、**关注运行** 和 **Copy link**（可直接打开该笔过账）。
  - **辅助、导出和保留遵循同一设计。** **辅助** 提供提问框和洞察卡片、标有 **Draft — nothing applied** 的建议，以及 **所有过账** 上带有 **显示这些** 的异常卡片。**导出和警报** 提供 **New schedule**，**保留** 为一张卡片。
  - **登记簿保持最新。** 侧栏徽章会随过账变化而更新，过账发生变化时打开的列表会提供 **刷新**，已打开的抽屉会就地更新。**主页** 在 **需要关注** 下显示 **过账登记簿** 卡片。请参阅[查看过账登记簿](/zh-cn/guides/connections/posting-register/)。
- **项目主页有七个页面。** 纯文本侧栏列出 **概览**、**变量**、**计划和传感器**、**访问和共享**、**数据和连接**、**数据模型** 和 **应用和品牌**，并以徽章显示变量数量、活动计划和传感器数量以及元素数量。**概览** 显示项目的说明和标签、锁定状态，以及表、工作流、步骤、变量、已发布表和 **数据大小**（打开 **存储**）的磁贴，其总量与 **项目** 屏幕所示一致，包含为还原而保留的早期版本，工具提示会拆分当前数据与早期版本；还显示接下来三次计划运行和项目默认设置，并提供 PDF 或交互式 HTML 格式的 **项目报表** 以及 **导出归档**。其他页面用于管理变量、计划和传感器（带有 **Calendar view** 以及 **Activate** 或 **Deactivate**），管理谁可以打开项目及其仪表板、哪些项目可以读取其表、带 ERP 过账模式的连接和表存储默认设置，以及 Panel 应用、品牌和项目的磁贴图像。锁定的项目会显示横幅并禁用其控件。请参阅[项目主页](/zh-cn/guides/projects/project-home/)。
- **将共享列一次性描述为项目元素，并查看表之间的关联。** 多个表共用的列名（如 `Period` 或 `Org`）会成为元素，具有说明、类型、掩码、维度和别名。凡含有该名称列的表，只要该列自身没有这些设置，就会显示元素的说明、掩码和维度，表上存储的内容不会有任何改变。项目主页上新增的 **数据模型** 页面列出这些元素，以图或矩阵显示共用每个元素的表，标出类型不同的表，并建议值得设为元素的名称。元素名称会显示在表资源管理器、列属性以及步骤的“数据映射”选项卡中其列的旁边。Data Foundation 项目附带其共享的 Common Finance Model 列的元素。REST API 以及 `element_find`、`element_upsert` 和 `element_delete` MCP 工具用于管理元素，AI 助手可看到每个列的元素含义。请参阅[数据模型和项目元素](/zh-cn/guides/projects/data-model/)。
- **文档打开到概览，并带有页面侧栏。** **概览**、**浏览**、**您的账户** 和 **管理** 位于侧栏中，页面有标题（通常带副标题），其操作位于页眉。**概览** 显示您的账户磁贴、**Pinned** 文件（打开 **浏览** 并定位到其文件夹和所选文件）、按服务分类的账户以及谁可以使用它们。**您的账户** 是您可使用的所有账户的单一列表，每行带有 **已共享** 或 **私有** 标记。**管理** 列出您拥有的账户，工作区管理员会在此看到所有文档账户，并可管理其本来就可管理的任何账户（系统管理的账户会被拒绝，受管存储桶账户无法克隆）。行的 **⋯** 菜单包含 **打开**、**编辑**、**克隆…**、**谁可以使用**、**使用位置…**、**版本历史记录**、**启用** 或 **禁用** 以及 **删除**。账户会作为页面打开，包含 **常规**、**访问**、**凭据** 卡片，SFTP 账户还有 **SSH** 卡片，存在未保存的更改时离开前会先询问。**浏览** 会打开您收藏的账户或工作区的默认账户，并提供带标签的工具栏、行菜单、拖放上传（拖放到文件列表或文件夹上即可上传到该处，拖放到树中的空白处则上传到账户根目录），以及 **Uploads and imports** 面板，显示每次上传和导入到表的进度和操作。**Pop out** 在新的浏览器选项卡中打开该文件夹。请参阅[文档](/zh-cn/guides/documents/)和[使用文档账户](/zh-cn/guides/documents/using-document/)。
- **仪表板打开到概览，并带有页面侧栏。** **概览**、**仪表板**、**应用**、**笔记本** 以及（面向工作区管理员的）**访问审核** 位于侧栏中，底部的 **Open navigator ↗** 带有标记，因为它会在单独的窗口中打开。页面有标题（通常带副标题），其操作位于页眉。**概览** 显示仪表板和应用的磁贴（打开已筛选的相应列表）、您最近打开或加星标的内容、失败的应用和等待您处理的访问请求，并为有使用情况访问权限的成员显示打开次数最多的仪表板。**仪表板** 可按 **全部**、**您管理的** 和 **收藏** 筛选，**应用** 显示每个应用的 **类型** 和实时状态。请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **Identity 打开到概览，并带有页面侧栏。** 侧栏依次列出 **概览**、**成员**、**目录**、**安全组** 和 **分发列表**，然后是 **会话**、**安全日志**、**API 客户端**、**分组审核** 和 **所有范围**。页面有标题（通常带副标题），其操作位于页眉。**概览** 显示成员、活动成员和从未登录的成员、构建者席位以及当前已登录者的磁贴，**活动成员** 图表，带有 **重新发送欢迎电子邮件** 和 **审核** 的 **需要关注**，以及最近 7 天的安全事件。成员会作为页面打开，包含 **配置文件**、**访问** 和 **分组和数据** 卡片，并且 **Invite member** 可从概览和主页的首次运行卡片使用。请参阅[成员管理](/zh-cn/administration/access/member-management/)。
- **列表可显示为标准行、宽松行或卡片。** **仪表板**、**应用**、ERP 登记簿和 Identity **成员** 等列表的工具栏中的 **视图** 菜单可让您在这些方式之间选择。卡片保留列表的所有功能：选择、排序、列、右键 **复制**，以及（有收藏功能的列表中的）收藏星标。**仪表板** 卡片显示缩略图。请参阅[标准行、宽松行和卡片视图](/zh-cn/guides/dashboards/using-dashboards/#标准宽松和卡片视图)。
- **Lakehouse 窗口具有侧栏、表详细信息和时间旅行。** **查询**、**配置文件**、**加载** 和 **目录** 位于侧栏中，**Lakehouse 目录**、**数据库用户** 和 **计算** 位于 **管理** 下。**数据库用户** 和 **计算** 仅对具有 Lakehouse 管理员或 Lakehouse 集群角色的成员显示。**查询** 可按 SQL 文本、用户、类型和持续时间筛选历史记录，用 **Copy SQL** 复制语句，并用 **Profile this query** 在 **配置文件** 中打开查询。**目录** 会打开表的列、当前快照、分区、位置、属性和快照历史记录，**Copy query as of this snapshot** 会复制一条 `FOR VERSION AS OF` 查询，读取表在当时的状态。请参阅 [Lakehouse 窗口](/zh-cn/guides/data/lakehouse-window/)。
- **步骤表单上的预览。** 导入：SQL、执行：SQL、提取：SQL、导出：SQL 和 Salesforce：查询对象最多可在不运行步骤的情况下显示 100 行，Anaplan 视图和列表读取会显示其将生成的列和类型。请在 **源** 选项卡上单击 **预览**。变量会按运行时的方式填充，但不支持 `{x:>9}` 之类的变量格式。预览只运行标准 SQL 函数；否则会提示您运行该步骤。在锁定的项目中，或对于基于代理的 Execute SQL 步骤，预览不可用。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/) 和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。

- **Git 应用列出您的存储库并告诉您可以做什么。** 应用列表中的 **Git** 显示您的角色（**管理员**、**贡献者** 或 **查看者**）和工作区的存储库，每个存储库带有说明、最近更新日期、带复制按钮的克隆地址以及 **打开**。**Set up Git on your computer** 卡片会引导您完成安装 Git、创建令牌和克隆，**How to clone** 可重新打开它。**View all in Git** 打开完整的 Git 界面，**Manage who can push** 打开分组管理。访问权限分为 **查看者**、**贡献者**（向 `apps` 推送应用代码）或 **管理员**（可推送到任何位置，包括 `udfs`），查看者最多可看到三位工作区管理员以便向其询问。新的 **Git Contributors** 分组授予贡献者权限，并且可设为默认分组，这样新成员会自动获得该权限；**Git Administration** 授予管理员权限。成员的 **Git** 选项卡显示其 Git 用户名、级别以及授予该级别的分组。成员的 Git 账户随其成员资格变化：停用或移除成员后，其 Git 账户（包括令牌和 SSH 密钥）会在约一小时内被阻止，重新激活后则解除阻止，其存储库和历史记录均保留。使用单点登录登录 Git 会打开该成员自己的账户。贡献者不能直接在工作区的 Git 组织中创建存储库；存储库通过 PlaidCloud 创建。应用窗口显示 **存储库** 部分，UDF 带有 **打开**，Git 有指向您工作区的 **← Back to** 链接。平台创建的每个存储库（包括应用存储库以及内置的 `apps` 和 `udfs` 存储库）对工作区中每位已登录的成员都是可读的，因此成员无需逐个存储库设置即可打开和重新发布应用。Git 管理员仍可将存储库设为私有，这会使其从存储库选择器中隐藏，并使成员无法从中发布或运行其中存储的基于 Git 的 UDF 代码。请参阅 [PlaidCloud Git](/zh-cn/guides/git/#打开-git) 和[谁可以看到存储库](/zh-cn/guides/connections/plaidcloud-git/#谁可以查看存储库)。
- **Cost to Serve 和 Operational Transfer Pricing 模板基于 Common Finance Model 构建。** 从 **Cost to Serve** 启动项目，可按您为每个部门设置的作业和动因将运营费用分摊到客户，并查看扣除服务成本后每个客户的利润，且与总账一致。从 **Operational Transfer Pricing** 启动，可对照政策区间测试每个实体的利润水平（销售回报率、净成本加成或转售价格减法），并通过调整补足使超出区间的实体回到目标。销售回报率为 EBIT 除以被测试方的销售额。请参阅 [Cost to Serve](/zh-cn/guides/projects/cost-to-serve/) 和 [Operational Transfer Pricing](/zh-cn/guides/projects/operational-transfer-pricing/)。
- **OneStream 和 Anaplan 为 Data Foundation 提供数据，并且 OneStream 有读取步骤。** Data Foundation 通过 OneStream 管理员构建的数据适配器读取 OneStream 合并结果，并通过导出操作读取 Anaplan 计划，然后将集团损益表与它们进行对账。新的 **OneStream: Read Adapter** 步骤可在任何工作流中将适配器（每个合并成员调用一次）读取到表中。请参阅[适用于 Data Foundation 的 OneStream](/zh-cn/guides/connections/onestream-for-data-foundation/)、[将 Anaplan 用作 Data Foundation 源](/zh-cn/guides/connections/anaplan/#将-anaplan-作为-data-foundation-源)和 [OneStream: Read Adapter](/zh-cn/reference/workflow-steps/onestream/onestream-read-adapter/)。

- **告诉 Weave 您想要什么，它会构建并运行。** 创建项目、工作流、步骤、导入或维度的对话框，以及空列表和画布，都以 **Tell Weave what you want** 开头，旁边是 **Fill in the form instead**。描述一个工作流，Weave 会以一张计划卡片作答；批准后即可看到步骤出现在画布上，并标有 **Built by Weave**，**停止** 可结束构建。可让 Weave 运行工作流、一段步骤范围或单个步骤，为工作流安排计划或更改其计划，或者更改或添加步骤：每项操作都是一张需要您批准的卡片，每次运行都关闭 ERP 过账，对于过账到 ERP 或写入 PlaidCloud 之外的步骤，Weave 会留给您处理。将数据文件拖放到项目的 **概览** 或画布上可得到表或导入步骤，拖放或粘贴 SQL 脚本可将其重建为标准步骤，拖放 Alteryx 工作流或指定一个包含它们的文件夹，Weave 会将其转换为新项目、运行它们，并在迁移报告中将结果与它们所写入的文件进行比较。导入之后，**建议的下一步** 会提供可构建的第一张图表或清理操作。请参阅[使用 Weave 构建和运行](/zh-cn/guides/ai-assistant/weave-build/)。

- **关账在夜间准备就绪。** 对于设有截止时间的就绪集，Weave 每天以及在其依赖的运行之后检查关账，为能处理的每个问题准备修复或重新运行，并显示一张卡片，例如 *月末关账已完成 92%。有两件事需要您处理。*，其中每项决定都有编号，并有各自需要批准的卡片。请参阅[夜间准备的关账](/zh-cn/guides/ai-assistant/weave-readiness/#隔夜准备好的结账)。
- **保留 Weave 的答案，并请求报表和警报。** 答案下方的 **Keep ▾** 可将其保留为常设请求、指标、假设方案、团队配方或固定答案。用您自己的话让 Weave 按计划或在工作流运行之后生成报表或警报，它会在 PlaidCloud 和手机上通知您，并通过电子邮件（不含数字）通知您。在 **Monitor → 请求** 上管理您的请求，可使用 **立即运行**、**暂停**、**更改** 和 **移除**。请参阅[保留答案和常设请求](/zh-cn/guides/ai-assistant/weave-requests/)。
- **询问数字为何如此。** 右键单击表资源管理器中的单元格，或仪表板图表上的点或单元格，然后选择 **Why this number**：Weave 会指出写入它的步骤及其来源，以及它自上次运行和自上一期间以来如何变化。在表资源管理器中，**As of** 按写入的运行列出表的早期版本，**Compare with now** 会说明自那时起哪些行和列发生了变化。用文字提出关于分摊结果的假设问题，即可立即得到估算。对账的最近结果会被保留，例如 *已于 06:02 与 Cost Pool 核对一致。* 请参阅[数字为何如此](/zh-cn/guides/ai-assistant/weave-numbers/)。
- **与团队共享 Weave。** 固定一个答案，项目中的每个人都能看到它，并以各自的访问权限重新运行。将问题保存为配方，任何人都可在停靠栏中用 `/` 运行，或通过触发器运行。两者都列在项目 **概览** 的 **From your team** 下。步骤、工作流、表和发现项都有评论线程，您可以在其中提及同事或向 @Weave 提问，Weave 处理工作流时会在画布上显示。请参阅[与团队共享 Weave](/zh-cn/guides/ai-assistant/weave-team/)。
- **查看 Weave 的价值。** 有些发现项会通过点赞和点踩询问其是否值得告诉您。**月度摘要** 显示 Weave 的发现项和答案有多大用处、Weave 修复的失败运行以及同事复用的固定答案，并估算节省的时间，范围可以是项目或您本人。请参阅 [Weave 月度摘要](/zh-cn/guides/ai-assistant/weave-monthly-summary/)。
- **移动端的 Weave 语音只需点一下。** 点击麦克风，提出问题，您停止说话后 Weave 会发送。再次点击麦克风可提前停止，如果听不到声音，它会自动关闭。如果您在说到一半时离开 **Weave** 选项卡或将应用置于后台，您的话会保留在问题框中而不发送，以便您检查。运行、暂停、停止和继续的确认框会忽略意外的双击。需要应用版本 1.3.0 或更高版本。请参阅[使用语音](/zh-cn/guides/mobile-app/weave-on-mobile/#使用语音)。
- **Weave 通过电子邮件通知您问题。** 您可为自己开启：工作流运行以严重问题结束需要您查看时发送电子邮件，以及在您选择的时间发送每日摘要，列出 Weave 已告知您但您尚未阅读的问题。邮件会指明项目以及每个工作流、步骤、表或指标和问题类型，链接回 **Weave** 选项卡，绝不包含您数据中的数字或值。工作区管理员可为所有人关闭 Weave 电子邮件，并设置静默时段（按每位成员各自的时区），在静默时段结束前暂缓发送警报。请参阅 [Weave 电子邮件](/zh-cn/guides/ai-assistant/weave-email/)。
- **Weave 如何使用您的数据。** 新增的面板位于 **Weave** 菜单、每个 AI 聊天下方以及 **AI 功能** 中，说明为您的工作区回答 Weave 的 AI 提供商是哪一家、位于何处，Weave 向其发送了什么，以及关于训练和保留仍有哪些事项有待确认。请参阅 [Weave 如何使用您的数据](/zh-cn/guides/ai-assistant/weave-data-use/)。

## 变更

- **一个可筛选的清单可在所有位置分配人员、分组和工作流。** 安全组成员、成员的分组关联、分发列表成员、文档账户成员、分组、代理和所有者、连接访问权限以及 Weave 就绪状态集的工作流，都使用同一个选择器，而不再是需要在两个列表之间拖动。输入内容即可按姓名或电子邮件筛选（包括 `@example.com` 之类的域名），粘贴电子邮件列表即可精确匹配这些人员，在 **全部**、**已分配** 和 **Not assigned** 之间切换，并使用 **Assign all shown** 或 **Unassign all shown**。您更改的行带有 **Will add** 或 **Will remove** 标签，**Undo changes** 可将其恢复，只有在有更改时保存按钮才可用。在筛选框中按 **Enter** 绝不会保存，按 **空格** 会勾选所选行。在您可以查看但无法更改访问权限的位置，列表为只读。
- **如果您的工作区使用 Grok，移动设备上的 Weave 会再次要求您同意其 AI 声明。** 该声明不再说 xAI 不会使用您的数据训练其模型，而是说明 PlaidCloud 与 xAI 之间没有零数据保留协议，因此 xAI 可能会保留数据，并按其标准条款允许的方式使用。请参阅 [Weave 如何使用您的数据](/zh-cn/guides/ai-assistant/weave-data-use/)。
- **“What if”窗口一次读取一个期间。** 当 Allocation Split 步骤的输出带有期间列时，窗口会在最新期间打开，**期间：** 可让您选择另一个期间或 **All periods**。如果某个步骤的动因在每个期间都有一行，而数据量大到无法跨所有期间读取，现在会针对某一个期间打开并回答。已保存的方案会保留其保存时对应的期间（如有），打开方案时，只要该期间仍在列表中，窗口就会切换到该期间。请参阅[选择期间](/zh-cn/guides/allocations/results/driver-what-if/#选择期间)。
- **PlaidCloud 的网页应用和 Python 客户端库使用 REST API，JSON-RPC 已弃用。** 网页应用将其请求发送到 REST API。使用 `plaidcloud-rpc` 1.25.0 或更高版本时，`SimpleRPC` 调用会转到 REST API，您的代码无需更改；REST API 尚未涵盖的调用，或仍使用较旧版本的工作区，会像以前一样使用 JSON-RPC。JSON-RPC 将在后续版本中移除，因此请将您的脚本和笔记本升级到 `plaidcloud-rpc` 1.25.0 或更高版本，并针对 REST API 编写新的集成。请参阅[命令行](/zh-cn/reference/cli/jupyter/command-line/)。
- **步骤跟随其项目的连接环境，除非您将其固定到另一个环境。** 在 QA 和 Production 等环境之间切换项目时，每个步骤都会随之移动。必须保持在某一环境的步骤可以改为设置 **Fixed environment**：表单会以警告标记该步骤，其日志会记录每次在项目环境之外的环境上运行的情况，切换项目时会列出不会跟随的步骤。ERP 过账步骤始终使用项目的环境。只要有项目、固定的步骤或代理在使用某个环境，该环境就无法删除，代理表单中的字段现在是 **Environment this agent serves**。请参阅[将步骤固定到一个环境](/zh-cn/guides/projects/managing-projects/#将步骤固定到某一环境)。
- **步骤表单遵循统一的布局。** 选项卡采用标准名称和标准顺序：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单上还有页眉列和行列。必填字段以 * 标记，表单只会因步骤所需的内容而阻止保存。
- **Acumatica、Bill.com、Dynamics、Eclipse、HFM/FCCS、NetSuite、Workday 和 Workday Financials 连接可以创建、编辑并在步骤中选取，设置不会丢失。** 它们保存为 REST 连接，**连接** 列表会显示其自身的类型。右键点击连接并选择 **Edit REST settings**，即可打开其标头、身份验证和分页。**测试连接** 适用于已保存的 NetSuite 和 HFM/FCCS 连接。Workday Financials 连接可使用集成系统用户及其密码（须同时提供）登录，也可使用 OAuth 客户端登录，Workday、Bill.com、Dynamics 和 Eclipse 表单中有 **API 主机** 字段。请参阅[创建和管理连接](/zh-cn/guides/connections/create-connection/)。
- **数据输入表单将每个字段放在其标签旁边。** 字段左对齐、宽度一致，不再固定在最右侧，适用于 Data Foundation 的 **连接** 和 **源**、文档账户设置以及成员配置文件。
- **复制项目会分别选择表数据和维度成员，复制数据更快，并保留私有副本的 ERP 写入授权。** 在 **Data to copy** 下，选择 **表数据**（**No table data**（默认）、**完整** 或 **样本**），并单独选择 **Copy dimension members**（默认开启），因此不含表行的副本仍会带有已填充的维度，而且创建速度很快。**完整** 和 **样本** 副本会同时复制多个表，因此包含许多表的项目完成得更快。**复制结果** 会将每个维度的结果与各表一起列出，**Retry failed items** 会一并重试失败的表和维度。包含数据创建的新副本仅您自己可见，并保留您自己有权授予的、来源的 ERP 写入授权；如果来源以实时方式过账，副本会处于模拟状态，因此在您将其切换为实时之前，不会有任何内容到达 ERP。REST API 和 `project_copy` MCP 工具也接受 `dimension_members`。请参阅[选择要复制的数据量](/zh-cn/guides/projects/managing-projects/#选择复制多少数据)和[副本中的 ERP 写入授权](/zh-cn/guides/projects/managing-projects/#副本中的-erp-写入授权)。
- **表的详细信息面板更快地显示使用它的步骤。** 选择另一个表时，会立即清除前一个表的步骤，与本项目共享数据的其他项目中的步骤会在其余内容之后稍等片刻再添加，而不会使整个面板延迟。请参阅[查看表的使用位置](/zh-cn/guides/projects/managing-tables-and-views/#查看表的使用位置)。
- **工时和费用中的发票列表打开更快，并可按需加载更多。** 它显示与您的状态和搜索相匹配的最新 100 张发票，还有更多时，**加载更多**会再添加 100 张。选择**全部**或**已支付**只对该次访问有效，下次访问会打开到**未结**。
- **每个表都有相同的布局、筛选器和行操作。** 您自己的操作排在左侧最前面，例如 **新建** 和 **打开**，其后是 **操作**、（表有此项时的）**视图**，以及位于最右侧的图标 **刷新**。任何工具栏都没有 **更多** 菜单：不常用的命令位于 **操作** 中，例如“表”上的 **存储** 和 **下载**，“工作流”上的 **全部停止** 和 **清除状态**，以及工作流详细信息窗口上的 **移动所选项**、**诊断模式**、**锁定工作流**、**依赖项** 和 **Flashback**，移动箭头保留在工具栏上。**筛选器** 位于每个表的底部、行数旁边；按 **/** 或 Ctrl/Cmd+F 可跳转到它，在树视图中，一个筛选器同时驱动树和平面列表。“表”列表在筛选器旁有 **All | Published** 开关，维度的层次结构有 **主 | 两者 | 备用** 开关，用于选择筛选器搜索哪棵树，其 **视图** 菜单中有 **显示备用层次结构**、列和布局。已锁定的工作流在其详细信息工具栏上显示 **Locked** 标记；如果您可以编辑该工作流，单击它即可解锁。连接和项目的“安全”列表新增了筛选器。数据共享、计划事件、Flashback、工作流的运行历史记录和成员的 **行访问** 列表现在与其他列表一样可筛选、刷新、显示行菜单并用 **Enter** 键打开，并可用 **F5** 刷新。**删除** 会要求您确认，而数据共享以前不需要。在每个对话框中，**取消** 或 **关闭** 都是最右侧的按钮。
- **行操作在所有位置都一样。** 可从行首的 **⋯** 按钮、右键单击行，或工具栏的 **操作** 菜单打开行菜单。它始终先列出 **打开**、**详细信息** 和 **编辑**，然后是列表自身的操作，最后是 **删除** 或 **移除**，不适用于某行的操作会在原位置变灰。**Enter** 和 **Del** 会显示在其所运行的菜单项上。如果列表的行只有一个操作，会显示该操作的图标而不是 **⋯**，仪表板、应用和笔记本再次显示 **打开** 图标。请参阅[行操作菜单](/zh-cn/guides/dashboards/using-dashboards/#行操作菜单)。
- **“新建应用”菜单会为每种应用命名，您的账户详细信息位于头像菜单中。** **应用** 上的 **New app** 在 **Panel 应用** 标题下列出 **Studio**（在 PlaidCloud 的编辑器中使用标准布局编写和发布；代码由系统为您保存）、**仅浏览器**（您自己的存储库；在查看者的浏览器中运行）和 **基于服务器**（您自己的存储库；在 PlaidCloud 服务器上运行），然后是 **Dash 应用** 和 **From gallery…**，**类型** 列使用相同的名称。您的姓名、电子邮件和 **连接您的 AI** 位于头像菜单中，而不是标题栏中。请参阅[创建 Panel 应用](/zh-cn/guides/panel-apps/creating/)和[连接您的 AI 代理](/zh-cn/integrations/ai-coding-agents/getting-started/)。
- **PlaidCloud 焕然一新，采用蓝色外观，支持浅色和深色。** 按钮、复选框、选中的行、选项卡、链接以及列出工作区页面的导轨使用同一种 PlaidCloud 蓝，并具备在两种主题中阅读所需的对比度。应用选项卡图标为统一的一套。
- **全新的加载画面。** PlaidCloud 会以更简洁的加载画面打开，并跟随您的浅色或深色主题。从空闲状态唤醒的 Panel 或 Dash 应用会显示 **正在启动**、**正在准备…** 和 **Loading app** 的进度，如果未能启动，会说明停在哪一步，并提供 **重试**。请参阅[使用 Panel 应用](/zh-cn/guides/panel-apps/using/)。
- **没有验证设置的已保存 ERP 写入步骤以仅验证方式打开。** 这涵盖 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL 和 AP Post，以及 Xero 导出。明确设置为实时运行的步骤保持实时。
- **长时间运行的作业在所有位置以相同方式显示进度。**
- **工作流如实停止、失败和报告。** 停止工作流会停止它启动的所有内容，无法完成的运行或步骤会带着原因失败而不是挂起，运行状态与实际运行的内容一致。
  - **停止工作流会停止它启动的所有内容，无法完成的运行或步骤会失败而不是挂起。** 停止会取消仍在排队的导入和维度步骤，因此工作区中后续的导入和维度加载可正常启动，同时也会停止该工作流排队中或正在运行的连接器（Singer）同步。如果步骤的作业无法启动，该步骤会带着原因失败，而不是无限等待：约 40 分钟内没有工作进程启动它、工作进程启动后消失、其 Pod 约 20 分钟一直处于 Pending 状态、其映像约 5 分钟内无法拉取，或约 20 分钟内未创建 Pod。约 30 分钟内没有运行器接手的连接器同步会失败，并显示指明该同步的消息。步骤等待工作进程时，其状态消息会显示“正在等待工作进程…”及已等待的分钟数，工作开始后消失。停止宏会停止它的每个正在运行的副本，而停止其中一个副本，或 **Macro Concurrent** 步骤放弃一个不再响应的副本，会让调用它的工作流继续运行。仅在其他工作流内部运行的宏会在工作流列表中显示为 **正在运行**，可使用 **停止**，每个步骤的状态、开始和结束时间来自其最近一次运行。服务器丢失的运行会以失败结束，运行超过 12 小时仍未结束的运行会失败，并显示“运行失败：运行已达到 12 小时上限仍未结束。请重新运行工作流。”请参阅[运行工作流](/zh-cn/guides/workflows/run-a-workflow/#永远无法启动的步骤)。
  - **继续、运行历史记录和运行状态与实际运行的内容一致。** 继续父工作流会运行子工作流剩余的所有内容，即使您已单独重新运行了子工作流的某个步骤，一次运行中对子工作流的每次调用都有自己的运行历史记录条目。因服务器停止而重新启动的步骤会在其日志中说明，`workflow_run_status` 和 REST API 的运行结果会在 `continued_step_ids` 和 `continued_step_count` 中列出失败但继续执行的步骤，而不是将运行报告为干净无误。请参阅[暂停、停止和继续](/zh-cn/guides/workflows/run-a-workflow/#暂停停止和恢复)和[出错时继续](/zh-cn/guides/workflows/continue-on-error/)。
  - **步骤错误显示其自身的消息。** PlaidCloud 未预料到的错误显示为“步骤因意外错误而停止（*类型*）：*消息*”。启动器上的 **需要关注** 卡片以一行显示错误，并省略此后已被删除的工作流的运行。请参阅[管理步骤错误](/zh-cn/guides/workflows/managing-step-errors/)。
  - **未完成的 ERP 提取会使其步骤失败，继续可使其接着运行。** 当 **SAP：临时提取** 在达到行数或时间上限时暂停，或其代理未及时回复，或者 Salesforce、Oracle Fusion 批量或 HFM/FCCS 导出作业在步骤停止等待时仍在运行时，该步骤会失败，这样其后的步骤就不会基于不完整的表运行。继续工作流或重新运行该步骤，提取会在同一作业上从停止处继续。请参阅[运行限制](/zh-cn/guides/connections/sap-adhoc-extract/#运行限制)和 [Salesforce：查询对象](/zh-cn/reference/workflow-steps/salesforce/query-salesforce-object/#运行未完成时)。
  - **取消导出会停止其在仓库中的查询。** 取消导出或下载时（包括通过停止其工作流），在 Lakehouse v2、Snowflake、Databricks、PostgreSQL 和 Greenplum 上，读取其数据的查询也会停止，导出到远程数据库的操作会停止读取其源，而不是一直运行到结束。
- **工作区升级时，REST、Import REST 和 Import Postman 步骤会转换为 REST 请求。** 无法干净转换的步骤保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **会话过期后打开的仪表板链接会在您登录后带您进入该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**，并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为其另一个名称。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#未知字段会被拒绝)。
- **在 Lakehouse v2 上，Lakehouse 自行将 Parquet 导出写入 Google Cloud Storage。** 导出到 Google Cloud Storage 文档账户时，数据会使用该账户自己的凭据直接写入账户的存储桶，而不是让每一行先经过 PlaidCloud。导出到 Amazon S3 和 Azure Blob Storage 账户的行为与以前相同。请参阅[导出为 Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/)。
- **Slack、Microsoft Teams 和 Web Hook 步骤会说明消息为何未发送。** 步骤的错误会指明它尝试访问的服务器，对于 Slack 和 Teams 还会指明连接，并说明出了什么问题：例如 Slack 不再识别该 Webhook、无法向该频道发布消息、找不到服务器或服务器在 60 秒内未应答，或者连接已被删除。绝不会显示 Slack 或 Teams 的 Webhook URL，因为任何拥有它的人都可以冒充您的集成发布消息。请参阅[通过 Slack 通知](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/)。
- **项目服务账户的访问令牌至少持续 24 小时。** 以项目身份运行的工作流作业（例如 UDF 步骤）获得的令牌持续 24 小时。工作区升级时，较短的有效期会被提高到该值，您设置的较长有效期则会保留。
- **工作区的组织、所有者、发布和版本由 PlaidCloud 设置，您可选择其数据中心。** 在控制平面中，您创建的工作区归您所有，并被置于 PlaidCloud 设置的发布渠道上，您可从注册时提供的区域中选择其 **Data Center**。编辑工作区时，组织、所有者、发布和版本为只读。使用 **Set Version** 更改版本，并请联系 PlaidCloud 支持来移动工作区、更改其所有者或渠道，或将其固定。请参阅[工作区配置](/zh-cn/administration/control-plane/workspace-configuration/#主要设置)。
- **编码转换步骤可保留文件夹的子文件夹。** **文档：将文件转换为 ASCII 编码**、**文档：将文件转换为 Unicode (UTF-8) 编码** 和 **文档：将文件转换为 Unicode (UTF-16) 编码** 带有 **保留子文件夹** 复选框。勾选后，输入文件夹的子文件夹中的每个文件会写入目标的对应子文件夹；压缩文件的内容会放入它原来所在的子文件夹。不勾选时，每个文件都像以前一样直接写入目标本身。请参阅[将文档编码转换为 UTF-16](/zh-cn/reference/workflow-steps/document/convert-document-encoding-to-utf-16/)。
- **源表与设置不匹配的步骤会在写入任何内容之前停止，并一次性列出所有问题。** Table Extract、Table Lookup、Table Inner Join、Table Cross Join、Table Outer Join、Table Anti Join、多表联接、Table Union Distinct、Table Union All、Table Pivot、Table Melt、Table In-Place Delete、Table Upsert 和 Table Append 步骤会在写入前检查其源表。步骤读取的列在表中不存在、联接键缺失或不在步骤的源列中，或者步骤读取的源表尚未构建，都会使步骤停止，并给出一个指明每个问题及修复方法的错误，已存在的目标表会保留其原有内容。对于尚未构建的源表，Table Union Distinct 和 Table Union All 是例外：与以前一样，它们会不发警告地省略该表并合并其余的表，如果一个都未构建，则以警告结束而不是失败。步骤列出但并不读取、且表中已不再存在的列，则只是警告，因此以前运行过的步骤仍会运行。对于目标为视图的步骤，只有在仓库本来就会拒绝创建该视图的情况下，才会对照其表检查其列出的列和联接键。这些失败以前来自数据库，使用数据库自己的措辞且每次只报一列，而替换其目标表的步骤此时已将其清空。如果工作流的错误处理匹配数据库的文本，请更新它。请参阅[步骤运行时](/zh-cn/reference/workflow-steps/tables/table-extract/#运行时指定名称的列)。
- **没有表的导出会停止而不是完成。** 没有表的 Export to Parquet、Export to ORC 或 Export to Avro 步骤过去会在不写入文件的情况下完成，没有表的 Export to XML 步骤会写入一个不含任何表的文件。这些步骤现在会在写入任何内容之前停止，并显示 *未指定任何表*。保存时完全没有表列表的步骤，过去会以指明内部设置的意外错误失败，现在会以相同的消息停止。

## 已修复

- **无效的项目设置会以清晰的消息报告。** 未知的环境或文档账户、已被占用或保留的 slug，或无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 返回 400 而不是 500，通过 AI 助手或 MCP 则返回无效参数错误。
- **REST API 的维度值请求现在可用。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 过去被当作网格请求处理并被拒绝为无效。现在它会为 `value_columns` 中的每一列返回一个聚合值，而网格（行筛选器和列筛选器的每一对组合对应一个值）有自己的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻碍其他请求。** 从仓库读取表的列、注册 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，过去都可能使同一服务器正在处理的其他所有请求暂停，直到其完成。现在它们与这些请求并行运行。
- **项目和工作流变量对话框可滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口还高，**创建** 和 **更新** 按钮可能够不到。现在表单可滚动，按钮保持在底部。
- **Azure Blob Storage 文档账户中超过 256 MiB 的文件可以复制、移动和重命名。** 过去这些操作对该大小的文件都会失败，移动或重命名包含此类文件的文件夹也是如此。
- **在 Lakehouse v2 上，表的行数反映刚写入的内容。** 写入表的步骤或导入可能记录写入之前的行数，因此刚加载的表显示 0 行，导入可能报告导入了 0 行。现在会在新行到处可见之后才读取行数，因此其后的步骤也能读到这些行。将表切换到另一个分支，或将分支合并到表中，也会更新其行数和列数。
- **Weave 的空值检查将每次运行与之前的运行实际留下的内容进行比较。** 步骤的空值常常恰好在步骤清空表以重新填充之后被统计，因此其之前的运行看起来没有空值，而一直有部分空值的列会被报告为刚刚变空。现在每次运行都按步骤留下的表来统计。之前记录的计数无法与正确的区分，因此不再使用：每个步骤的空值检查会重新开始其历史记录，在统计满五次运行之前报告为未检查。行数和值分布检查也不再将另一个步骤在其完成两秒之后对同一个表所做的写入记在该步骤名下。请参阅 [Weave检查内容](/zh-cn/guides/ai-assistant/weave-findings/)。
- **Data Foundation 保留倒数汇率和小数阈值的精度。** 当您的汇率是从报告货币折算为另一种货币时，PlaidCloud 将其取倒数，该汇率可能被四舍五入到六位小数，导致汇率较小的货币（例如印尼盾）的金额偏差约 1%。取倒数后的汇率现在保留 12 位小数。带小数的 `group_amber` 或 `group_red` 阈值（例如 `0.5`）过去会被四舍五入为整数。下一次 **加载** 会使用精确的值。请参阅[汇率](/zh-cn/guides/projects/data-foundation/#汇率)。
- **已停用成员的警报和摘要会停止。** 所有者已被停用的 Panel 应用警报或摘要过去仍会继续检查和发送。现在在其被停用期间会暂停，重新激活后恢复。请参阅[警报和摘要](/zh-cn/guides/panel-apps/alerts-and-digests/)。
- **向 REST API 请求已删除的连接时返回 404。** 请求已删除的连接或不存在的 ID 过去会返回通用的服务器错误 (500)。现在返回 404，并附有指明连接 ID 的消息。
- **模板化表导出可通过 AI 助手和 MCP 使用。** `table_data_export` 的 `templated` 格式过去只要给定表就会失败。现在它会通过您的模板导出该表，并限于您可读取的行。在模板中，表的行以其表 ID 命名，其中每个 `-` 写作 `_`。
- **Amazon S3 和与 S3 兼容的文档账户会保留其区域。** 保存这类账户时会丢弃您输入的 **区域**，因此下次打开账户时该字段为空。现在会保存区域。对于在此修复之前保存的账户，请重新输入区域并保存。请参阅[添加 AWS S3 账户](/zh-cn/guides/documents/adding-accounts/add-aws-s3-account/)。
- **转换文件夹的编码时不再用同名的另一个文件覆盖文件。** 两个要写入目标中同一位置的文件（例如来自不同子文件夹的两个同名文件）过去只会留下最后写入的一个。现在步骤会在写入第二个之前停止，指明这两个文件及其写入位置，并在勾选 **保留子文件夹** 可将它们分开时予以说明。
- **清除“文档：将文件转换为 ASCII 编码”中的替换字符选项会生效。** 勾选了 **将目标编码无法表示的字符替换为 ?** 的步骤，在取消勾选并再次保存步骤后仍保持勾选。现在清除该选项会关闭替换。
- **AI 助手和 JSON-RPC 不再指出使用您的角色所隐藏的表的步骤。** 询问此类表的使用位置时，它们过去会列出您的角色可见的、读取或写入该表的每个步骤及其设置和工作流。现在它们会说明有步骤使用该表，但不指明是哪些步骤，与项目的表引用相同。请参阅[您的角色隐藏的内容](/zh-cn/guides/ai-assistant/weave-tab/#您的角色隐藏的内容)。
- **您选择的默认 AI 连接会保持为默认。** 将 AI 连接标记为工作区默认连接看似成功，实际上并未保存，因此依赖默认连接的代理和步骤继续使用最近更新的连接。现在您的选择会被保存。请参阅 [LLM 提供商](/zh-cn/integrations/ai-architecture/llm-providers/#连接包含的内容)。
- **右键单击 Weave 历史记录中的对话时，不再在“删除对话线程”之上打开“重命名”。** **重命名** 现在位于聊天的选项卡上：右键单击该选项卡，此前它没有任何选项。请参阅 [Weave 选项卡中的选项卡](/zh-cn/guides/ai-assistant/weave-tab/#weave-选项卡中的选项卡)。
- **空白的备注不再阻止保存。** 创建或保存项目、维度、表、仓库、编辑器、计划工作流事件或分发列表时，如果 **备注** 框为空，过去会失败并提示“备注：输入应为有效字符串”。现在接受空白备注。
- **在应有单个值的位置给出多个值的表达式会被拒绝，Table Extract 或 Table Union All 步骤会保留其目标表的数据。** 常见原因是末尾的逗号（如 `table.amount,`），或与多个值的比较（如 `table.region == ('EU', 'US')`）。在 Databend 上步骤会失败，而此时 Table Extract 或 Table Union All 步骤已清空其目标表。其他一些仓库会运行此类表达式，但并不总是按所写的方式运行，因此一直无错误运行的步骤现在可能会被拒绝。保存步骤时，步骤表单会拒绝该表达式，并通过消息说明需要更改的内容。请参阅[在应有单个值的位置给出多个值](/zh-cn/reference/workflow-steps/common/advanced-data-mapper-usage/#期望单个值时给出了多个值)。
- **两次命名同一输出列的步骤会在清空其目标之前停止。** 在 Table Lookup、Table Extract 或联接中，两个同名的 **目标输出列** 会使步骤先清空其目标表，然后以不清楚的错误失败。现在步骤会先停止，并通过消息指明重复的列，以便您为每个输出列赋予各自的名称。按查询返回顺序写入列的提取 SQL 保持不变。请参阅 [Table Lookup](/zh-cn/reference/workflow-steps/tables/table-lookup/)。
- **保存时没有源列的联合源会说明缺少什么。** 通过 REST API、JSON-RPC 或 AI 助手或 MCP 保存的、没有源列列表的 Table Union All 或 Table Union Distinct 源，过去会在步骤运行时失败，并显示指明内部设置的意外错误。现在保存此类源会被拒绝并指明该源，读取此前保存的此类源的步骤会在写入任何内容之前停止并指明该源。从其表中取所有列、或按位置堆叠的已转换 Table Union All 不需要列表，也不会因为没有列表而被拒绝。
- **列的常量可以是数字、`0` 或 `false`。** 输出列的常量为数字的步骤过去会以意外错误失败。常量 `0` 或 `false` 被当作根本没有常量，因此该列改用其表达式或源列，或者因为该列无内容可读而使步骤失败。现在这些常量会写入每一行，并转换为该列的数据类型，AI 助手也可以提出带有此类常量的步骤。
- **已转换的 Alteryx Data Cleansing 工具会删除空行。** 勾选了 **Remove Null Rows** 的 Data Cleansing 或 Data Cleanse Pro 工具过去会在转换报告中被标记为需要审核，其转换后的步骤会保留每一行。现在该步骤会像 Alteryx 一样删除每列均为空的每一行。包含空文本值的行会保留。Data Cleanse Pro 在其他选项之后检查每一行，因此其空值被替换为空白的行也会保留。**Remove Null Columns** 仍会被标记为需要审核。请重新导入工作流以获得此更改。
- **未列出任何列的电子邮件通知会包含所有列。** 未选择任何列的 Notify Via Email 框架过去会使运行失败。在模板正文中，主题里的 `{variable}` 占位符会在计划发送、预览和 **向我发送测试** 时被填充。
- **表达式验证接受运行时接受的函数。** 调用 `int(...)` 等函数的有效表达式过去在您检查时会被拒绝。

## 安全

- **Weave 不再在每次对话开始时向其 AI 提供商发送您的姓名和电子邮件地址。** 它从未使用过这些信息。
- **密码登录需要身份验证器应用，并且密码更强。** 使用 PlaidCloud 密码登录的成员会在下次登录时被要求设置身份验证器应用，此后每次都要输入其验证码。单点登录、Google、Microsoft 和 GitHub 登录、API 令牌和服务账户不变。新密码至少需要 12 个字符，不能是您的用户名或您最近六个密码之一，多次登录失败后账户会被短暂锁定。工作区原有的更严格规则会保留。请参阅[成员身份验证](/zh-cn/administration/access/member-authentication/)。
- **连接指向公共和专用网络地址。** 连接不能指向环回地址、链路本地地址或云元数据地址，错误会指明主机及其解析到的地址。您专用网络上的地址不受影响。请参阅[连接无法访问的地址](/zh-cn/guides/connections/create-connection/#连接无法访问的地址)。
- **已保存的连接凭据仅向可编辑连接或工作流的成员显示。** 通过 REST API 和 MCP，已保存连接的密码、令牌和密钥会对其他成员遮盖，他们仍可打开和浏览该连接。请参阅[谁能看到连接的凭据](/zh-cn/guides/connections/create-connection/#谁能看到连接的凭据)。
- **应用构建在运行时无法访问您工作区的 Git 凭据。**
- **代理的私钥仅向可编辑代理的成员显示。** 通过 REST API 和 MCP，该密钥不再出现在代理列表或详细信息中，代理表单仅向可编辑代理的成员显示 **私钥** 和 **查看 RPC 配置**。服务账户、项目和代理令牌以及 AI 委派的令牌无法获取密钥或 RPC 配置。正在运行的代理不受影响，公钥仍会显示。请参阅[获取代理凭据](/zh-cn/reference/cli/plaidlink/agents/#获取代理凭据)。
- **代理下载链接的有效期为一小时。** 开启 **Use PlaidCloud Proxy Download** 后，链接过期时请再次打开下载以获取新链接。请参阅[服务](/zh-cn/administration/control-plane/workspace-configuration/#服务)。
- **将人员添加到安全组遵循您所拥有的权限。** 当您拥有该组授予的所有权限时，才可以将成员添加到安全组、选择成员的分组或邀请架构师。工作区管理员不受限制。请参阅[管理安全组](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理安全组)。
- **连接的所有者或工作区管理员可更改其设置并将其开启或关闭。** 通过 REST API、JSON-RPC 以及 AI 助手或 MCP 更改连接的设置，需要其所有者之一，或者对于没有所有者的连接需要工作区管理员。启用、禁用、锁定和解锁连接需要所有者或工作区管理员，指定多个连接的请求只有在您能更改全部连接时才会生效。只有工作区管理员可以选择工作区的默认 AI 连接，并且仅当不存在由管理员拥有或没有所有者的连接可作为默认时，成员拥有的连接才会成为默认连接。请参阅[编辑连接](/zh-cn/guides/connections/create-connection/#编辑连接)和 [LLM 提供商](/zh-cn/integrations/ai-architecture/llm-providers/#连接包含的内容)。
- **行访问适用于成员对受限表所做的一切操作。** 在仪表板、其自己的 SQL 和加载中，成员只能查看和更改其授权所允许的行。
  - **项目架构师在仪表板中可看到行受限表的所有行**，与其在 Analyze 中看到的一致。取消架构师访问权限会在仪表板中立即生效，无论您是更改某人的角色、将其或其分组从项目中移除、更改项目的访问类型、还原项目的早期版本，还是删除安全组。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
  - **受行访问限制的成员可以运行自己的 SQL 查询并导出结果。** 在设有行访问的项目中，非架构师的成员可通过查询屏幕上自己的查询准确获得其授权所允许的行，并可将其导出为 CSV、Excel 或 JSON，同时显示 **行数受您的访问权限限制** 提示；以前这些操作会被拒绝。包含百分号 (`%`) 的授权值现在会在查询屏幕上返回其行，并且将此类查询下载为 CSV 也可正常工作。成员在 Snowflake 或 Databricks 上自己编写的自由格式 SQL、在 Postgres 系列仓库上对自己 SQL 的导出，以及按快照读取受治理的表，仍会被拒绝，并且视图必须以原名保留受治理的列才能被筛选。请参阅[行访问和您自己编写的查询](/zh-cn/administration/access/managing-security-groups-and-assignments/#行访问和您自己编写的查询)。
  - **保存行访问会保留其源中不存在的已授权值。** 当表中没有包含该值的行、维度中没有该成员或列表中没有该值时，安全组被授予的值会保留在网格中并带有标记。**保存** 会询问是保留还是移除每个这样的值。请参阅[行访问网格](/zh-cn/administration/access/managing-security-groups-and-assignments/#行访问网格)。
  - **DataFrame 写入、记录保存和对行受限表的清除只会更改您可见的行。** 当行访问限制了您的行时，使用 Python 客户端向受限表写入 DataFrame 或将其清除，或者通过 REST API 向其保存记录或将其清除，只会更改您自己的行，包含您访问范围之外的行的加载会在任何更改发生之前被拒绝，并指明所发现的值。项目架构师、可看到每一行的成员以及工作流运行会写入整个表。个人对任何表所做的上述每种写入都会记录在 **安全日志** 中。请参阅[向受限表加载数据](/zh-cn/administration/access/managing-security-groups-and-assignments/#向受限表加载数据)。
  - **对行受限表的导入、复制、还原和删除需要您能看到每一行。** 当行访问限制了您的行时，向受限表导入文件、从另一个项目将表复制到其中、切换或合并其分支、还原它、删除它、在其被删除后恢复它，或任何其他替换整个表的操作，只有在您能看到该表的每一行时才会运行；否则会被拒绝，并且不会有任何更改。通过 REST API 保存表的行只会更改您自己的行，与其他加载相同。项目架构师、可看到每一行的成员以及工作流运行不受影响，这些操作同样会记录在 **安全日志** 中。请参阅[向受限表加载数据](/zh-cn/administration/access/managing-security-groups-and-assignments/#向受限表加载数据)。
- **只有账户的所有者才能还原其早期版本。** 将文档账户还原到早期版本、保留或释放版本以及进行备份，都需要账户的所有者之一，并且系统管理的账户均不可使用这些操作。查看账户的版本历史记录需要拥有该账户的访问权限。
- **`query_run` 运行只读语句。** AI 助手和 MCP 客户端使用的 `query_run` 工具接受一条 SELECT 或 WITH 语句、对其的 EXPLAIN，或 SHOW；任何其他语句都不会运行。要更改数据，请使用 `query_transform`。MCP 表导出中的 SQL 遵循同样的规则。对于无法更改项目数据的成员，通过 REST 和 JSON-RPC API，该规则还适用于运行查询、构建列分面、将查询下载为 CSV、将查询导出到远程数据库，以及使用自己的查询导出表数据；被拒绝的查询返回 403。Explain Analyze 会运行查询来进行测量，因此在查询日志和 Lakehouse 中它只接受读取数据的查询，在设有行访问的项目中只有项目架构师可以从查询日志运行它。
- **表资源管理器的筛选器、发送到 PlaidCloud 的查询，以及查找 Table Extract 步骤的动态列的查询，无法调用运行 SQL 或读取服务器文件的函数。** 对此类函数（如 `query_to_xml`、`dblink` 或 `pg_read_file`）的调用会被拒绝，错误会指明该函数。在相同位置，`.op()` 只接受运算符，`literal_column` 不能使用 Unicode 转义的引号。动态列查询包含步骤的筛选器以及从源读取列名的表达式，因此违反规则的查询会在步骤运行时使步骤失败。请参阅[被拒绝的函数和运算符](/zh-cn/reference/workflow-steps/common/advanced-data-mapper-usage/#会被拒绝的函数和运算符)。
- **Data Foundation 的分摊规则会拒绝包含单引号、反斜杠或换行符的部门或统计名称。** 该名称会写入分摊步骤的筛选器中，因此 **保存** 和第 1 阶段的预览会拒绝它并指明该值。请参阅[分摊规则](/zh-cn/guides/projects/data-foundation/#分摊规则)。
