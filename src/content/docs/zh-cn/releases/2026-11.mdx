## 新增

- **步骤表单支持预览。** 导入：SQL、执行：SQL、提取：SQL、导出：SQL 和 Salesforce 查询无需运行步骤即可显示最多 100 行，Anaplan 视图和列表读取会显示它们将生成的列和类型。在**源**选项卡上单击**预览**。变量会按运行时的方式填充，但不支持 `{x:>9}` 之类的变量格式。预览只运行标准 SQL 函数；否则会提示您运行该步骤。锁定的项目无法使用预览，基于代理的执行 SQL 步骤也不支持预览。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **AI 助手可以取消发布表，并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表，同时取消发布其已发布视图以及未被任何图表使用的仪表板数据集；仍被图表使用的数据集会保留；如果报表视图基于已发布视图构建，该视图和数据集也会保留，而表仍会被取消发布。`project_upsert` 用于设置 `dashboard_default_audience`，即项目中新仪表板默认共享给的分组，传入 `[]` 可将其清除。请参阅[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

- **在移动端 Weave 中使用语音只需轻点一次。** 轻点麦克风，说出问题，停止说话后 Weave 就会发送。再次轻点麦克风可提前停止；如果没有检测到声音，它会自动关闭。如果在说话中途离开**Weave**选项卡或将应用切换到后台，已说的话会保留在问题框中而不发送，便于您检查。运行、暂停、停止和恢复会忽略在其确认上的意外双击。需要应用版本 1.3.0 或更高版本。请参阅[使用语音](/zh-cn/guides/mobile-app/weave-on-mobile/#使用语音)。

## 变更

- **步骤表单采用统一布局。** 选项卡使用标准名称和标准顺序：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单还包含抬头列和行项目列。必填字段以 * 标记，表单仅在缺少步骤所需内容时才阻止保存。
- **行操作菜单（⋯）位于每个网格行的左边缘。**
- **未设置验证选项的已保存 ERP 写入步骤会以仅验证模式打开。** 这包括 SAP 过账、SAP 附件、NetSuite 过账、Oracle EBS 总账和应付账款过账，以及 Xero 导出。明确设置为实时运行的步骤保持实时运行。
- **长时间运行的作业在所有位置以相同方式显示进度。**
- **工作区升级时，REST、Import REST 和 Import Postman 步骤会转换为 REST 请求步骤。** 无法完整转换的步骤保持原样。请参阅[REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **项目架构师在仪表板中可以看到行受限表的所有行**，与他们在 Analyze 中看到的一致。撤销架构师访问权限会立即在仪表板中生效——无论是更改某人的角色、将其或其分组从项目中移除、更改项目的访问类型、还原较早的项目版本，还是删除安全组。前架构师将不再看到行受限数据的所有行。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
- **会话过期后打开的仪表板链接会在您登录后直接打开该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝无法识别的字段**，并在错误中指明该字段，而不是将其忽略。`workflow_upsert` 接受 `memo`，也接受 `description` 作为它的别名。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。

## 修复

- **无效的项目设置会以清晰的消息报告。** 未知的环境或文档账户、已被占用或保留的 slug，或者无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 时返回 400 而不是 500；通过 AI 助手或 MCP 时返回无效参数错误。
- **REST API 的维度值请求可以正常工作。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 曾被当作网格请求处理并因无效而被拒绝。现在它会为 `value_columns` 中的每一列返回一个聚合值；网格请求（为每一对行筛选器和列筛选器各返回一个值）则有自己的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻塞其他请求。** 从仓库读取表的列、注册 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，以前都可能让同一服务器正在处理的所有其他请求暂停，直到其完成。现在它们会与这些请求并行运行。
- **项目和工作流变量对话框可以滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口还高，因此**创建**和**更新**按钮可能无法点到。现在表单可以滚动，按钮始终位于底部。
