## 新增

- **控制平面中的 Trust Center 为您的安全团队提供 PlaidCloud 的安全文档。** 管理员和安全用户可为其组织打开 **Trust Center**，立即下载子处理方清单和 DPA 等公开文档，并由组织一次性签署安全文档 NDA，以解锁 SOC 2 Type II 报告等受限文档。其他管理员和安全用户可以看到谁在何时签署。合同中已包含 NDA 的组织可将其标记为已存档，这样无需签署即可解锁文档。受限下载带有水印并会被记录，新的 NDA 版本需要重新接受。请参阅 [Trust Center](/zh-cn/administration/control-plane/trust-center/)。
- **PlaidXL 可在 Excel 中构建、钻取、解释和规划。** **PlaidCloud** 功能区选项卡分为**连接**、**插入**、**刷新**、**钻取**、**写入**和**共享**，常用命令也出现在 **PlaidXL** 右键菜单和 **PlaidXL Cell** 选项卡上，主要命令带有可更改的键盘快捷键，在字段中输入时这些快捷键不会触发。命令失败时会说明是哪个命令以及原因。在登录之前运行的命令会打开登录界面，并在登录后运行；登录仅对一个工作区有效，因此切换工作区时会要求您登录新工作区（切换回来则无需再次登录）；在 Office 中使用 Microsoft Entra 工作账户时，PlaidXL 会为您找到工作区。请参阅 [PlaidXL 参考](/zh-cn/reference/cli/plaidxl/)。
  - **几次单击即可构建报表。** **报表**选项卡基于表布局实时报表，一个维度逐级钻取显示在行上，另一个显示在列上，每个交叉点都有一个 `CELL` 值。**Build my first report** 会基于您自己的数据生成示例。钻取时，报表会插入和删除整行整列，您输入的值、备注和格式会跟随其所在行。请参阅[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)。
  - **从任意单元格钻取。** **Drill down**、**Drill up**、**Keep only** 和 **Remove only** 会将节点转换为实时 `DRILL` 公式并为您编辑，可从节点、维度标题或报表值发起。**Custom drill** 会在插入之前预览行，成员选取器可插入成员，或向单元格添加某个节点的子节点下拉列表。`DRILL` 可指定要排除或展开的节点，并且可以跨行运行。请参阅[钻取、选取成员和解释数字](/zh-cn/reference/cli/plaidxl/drill/)。
  - **解释数字。** **Explain this number** 会显示某个值的计算方式、它当前是否与 PlaidCloud 一致，以及它来自的表和工作流步骤。**Show detail rows** 会将某个值背后的行放在单独的工作表上，并检查它们是否加总一致。
  - **Excel 中的受管控指标。** `PLAIDXL.METRIC` 和 `PLAIDXL.METRIC_BREAKDOWN` 会按仪表板显示的方式返回业务指标；当 `CELL` 或 `CELLS` 没有可聚合的内容时，求和显示 `0`，否则显示 `#VALUE!` 及原因（在 `CELLS` 溢出中为空白）；**Metric...** 会列出项目的指标及其当前值。指标可以按多个备用层次结构筛选，并将备用层次结构的成员与其他维度的成员混合使用。请参阅[指标](/zh-cn/reference/cli/plaidxl/functions/#指标)。
  - **通过在报表中键入来规划。** 在 `CELL` 值上键入数字，它就会写入 PlaidCloud：可按比例、均分或按另一个成员的形态分摊，可按金额或百分比调整，被锁定的单元格保持不变。平均值、中位数、最小值、最大值、标准差和方差单元格也接受键入的值，插入或删除行或列时，键入的值会跟随其单元格（已删除单元格中的值会被报告）。**Undo last write** 会按从新到旧的顺序撤消键入的值和保存，并且只有执行写入的人员和工作区才能撤消该写入。撤消求和，或撤消在空单元格中键入的平均值时，会保留此后写入同一些单元格的内容；在完成之前被中断的写入无法撤消。请参阅[向 PlaidCloud 键入值](/zh-cn/reference/cli/plaidxl/write-values/)。
  - **只刷新您需要的内容。** 可以刷新一个工作表、一个选区或每个表，每个表的进度和**取消**显示在任务窗格中，也可以只重新计算 PlaidXL 公式。检索到的表以按数据类型格式化的 Excel 表形式到达，刷新时保留您自己的列和数字格式，并在原位置刷新。检索或刷新绝不会覆盖其他单元格，也不会与另一个 Excel 表重叠，超出 Excel 范围的整数 ID 和 1900 年之前的日期会以文本形式到达。再次检索某个表不会将其重复添加到刷新列表中，**Stop refreshing** 可将其移除，维度会随您的表一起刷新。请参阅[刷新所有表](/zh-cn/reference/cli/plaidxl/retrieve/#refresh-all-tables)。
  - **保存立即写入，并且可以撤消。** **Save to PlaidCloud** 无需确认即可写入，会说明所执行的操作，并提供**撤消**，对于 Lakehouse 表，该操作在每次保存后最长 7 天内有效。带筛选器检索的工作表、明细行工作表，或访问权限仅涵盖部分行的人员，只会替换这些行，因此其他人的行会被保留。成员自检索以来发生变化的钻取工作表不会被保存，保存失败时会指明还原点，以便可以恢复该表。请参阅[将表保存到 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)。
  - **在 Excel 中询问 Weave。** 在 **Weave** 选项卡上，可以用日常语言请求报表、公式、钻取或表，也可以选择 **Ask Weave about this cell**。Weave 以您的身份读取 PlaidCloud，只更改工作簿，在替换您已输入的任何内容之前会先询问，绝不会编写引用工作簿之外内容的公式，并且每项更改在您重新加载窗格之前都可以还原。请参阅[在 Excel 中询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。
  - **共享一个工作表或整个工作簿的纯值副本。** **Convert to values** 可转换整个工作簿、一个工作表，或无法恢复的值（会先询问），只更改 PlaidXL 公式及其溢出，仍在计算的公式会留待再次尝试，并且在您重命名工作表之后，**Restore PlaidXL formulas** 仍然有效。
- **过账登记簿会在需要您处理的内容上打开。** 当有内容需要查看时，它会在**异常**上打开；当有请求在等您处理时，在**审批**上打开；否则在**所有过账**上打开。侧栏将其屏幕分组为**需要我处理**、**登记簿**、**洞察**和**设置**，**异常**和**审批**上带有计数，每个屏幕共用一个页眉和范围栏：选择期间（**本月**、**上个月**、**最近 7 天**、**最近 30 天**或**自定义**）、连接、项目、环境或实体，以及**实时**、**模拟**或**全部**，然后**重置**或保留 **Saved scope**。系统会记住您上次的范围。
  - **异常会整理出需要查看的内容。** **需要查看**、**未确认**、**待处理**、**失败**和**冲销未完成**这些标签会显示其计数，连接健康状况行显示“全部 N 个连接均过账正常”，每笔过账都有通俗易懂的状态，并带有说明下一步该做什么的工具提示。没有未处理项时会显示 **All clear**。将分类账 ID 粘贴到 **Find a posting by ledger id** 或命令面板中，可直接打开该笔过账。
  - **审批、委托和关注是收件箱式屏幕。** 在**等待我处理**和**我提交的**之间切换，填写原因后**批准**或**拒绝**，可一次批准多项，还可从提示消息中**撤消**批准。**Delegate approvals** 是一个简短的对话框，**我的关注**列出您关注的内容。**冲销过账**以及批量重试和清除对话框共用同一布局。
  - **过账抽屉会说明发生了什么。** 它显示状态及其含义、按名称列出的关键事实，以及**明细行**、**历史记录**和**签核**选项卡，并提供**标记为已审核**、**重试**、**冲销…**、**关注连接**、**关注运行**和**复制链接**（会直接打开该笔过账）。
  - **辅助、导出和保留遵循相同的设计。** **辅助**带有提问框和洞察卡片、标记为 **Draft — nothing applied** 的建议，以及**所有过账**上的异常卡片和**显示这些**。**导出和警报**带有 **New schedule**，**保留**是一张卡片。
  - **登记簿保持最新。** 过账发生变化时，侧栏徽章会更新，打开的列表在过账变化时会提供**刷新**，打开的抽屉会就地更新。**主页**在**需要关注**下显示**过账登记簿**卡片。请参阅[查看过账登记簿](/zh-cn/guides/connections/posting-register/)。
- **项目主页有六个页面。** 纯文本侧栏列出**概览**、**变量**、**计划与传感器**、**访问和共享**、**数据和连接**以及**应用和品牌**，并带有变量数量以及活动计划和传感器的徽章。**概览**显示项目的说明和标签、锁定状态、表、工作流、步骤、变量、已发布的表和**数据大小**（打开**存储**）的图块（与**项目**屏幕显示的总量相同，包含为还原而保留的早期版本，工具提示会拆分当前数据与早期版本）、接下来的三次计划运行以及项目的默认设置，并提供 PDF 或交互式 HTML 格式的**项目报表**和**导出归档**。其他页面管理变量、计划和传感器（带有**日历视图**和**激活**或**停用**）、谁可以打开项目及其仪表板以及哪些项目可以读取其表、连接和表存储默认设置（含 ERP 过账模式），以及 Panel 应用、品牌和项目的图块图像。已锁定的项目会显示横幅并禁用其控件。请参阅[项目主页](/zh-cn/guides/projects/project-home/)。
- **文档在概览上打开，并带有页面侧栏。** **概览**、**浏览**、**您的账户**和**管理**位于侧栏中，每个页面都有标题和副标题，其操作位于页眉中。**概览**显示您账户的图块、**已固定**文件（会在其文件夹处打开**浏览**并选中该文件）、按服务划分的账户以及谁可以使用它们。**您的账户**是您可以使用的所有账户的单一列表，每行带有**已共享**或**私有**标签。**管理**列出您拥有的账户，工作区管理员可在其中看到每个文档账户，并可管理其在其他情况下有权管理的任何账户（系统管理的账户会被拒绝，托管存储桶账户无法克隆）。某一行的 **⋯** 菜单包含**打开**、**编辑**、**克隆…**、**谁可以使用**、**使用位置…**、**版本历史记录**、**启用**或**禁用**以及**删除**。账户会作为页面打开，带有**常规**、**访问**、**凭据**以及（对于 SFTP）**SSH** 卡片，在您带着未保存的更改离开之前会先询问。**浏览**会打开您收藏的账户或工作区的默认账户，带有带标签的工具栏、行菜单、两个拖放区（左侧上传到账户根目录，右侧上传到所选文件夹）以及 **Uploads and imports** 面板，该面板显示每个上传和每个导入到表的任务及其进度和操作。**Pop out** 会在新的浏览器选项卡中打开该文件夹。请参阅[文档](/zh-cn/guides/documents/)和[使用文档账户](/zh-cn/guides/documents/using-document/)。
- **仪表板在概览上打开，并带有页面侧栏。** **概览**、**仪表板**、**应用**、**笔记本**以及（对于工作区管理员）**访问审核**位于侧栏中，底部是 **Open navigator ↗**，因其会打开自己的窗口而带有标记。每个页面都有标题和副标题，其操作位于页眉中。**概览**显示仪表板和应用的图块（打开已筛选的对应列表）、您最近打开或加星标的内容、失败的应用和等待您处理的访问请求，以及面向有使用情况访问权限的成员的最常打开的仪表板。**仪表板**可按**全部**、**You manage** 和**收藏**筛选，**应用**显示每个应用的**类型**和实时状态。请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **“身份”在概览上打开，并带有页面侧栏。** 侧栏列出**概览**、**成员**、**目录**、**安全组**和**分发列表**，然后是**会话**、**安全日志**、**API 客户端**、**组审核**和**所有范围**，**使用情况报告**会作为侧栏旁边的页面打开，带有**概览**、**活动**、**路径**、**成员**、**内容**、**导出**和**漏斗**选项卡。每个页面都有标题和副标题，其操作位于页眉中。**概览**显示成员、活动成员和从未登录成员、构建者席位以及当前在线人员的图块，一个**活动成员**图表，带有**重新发送欢迎电子邮件**和**审核**的**需要关注**，以及最近 7 天的安全事件。成员会作为页面打开，带有**配置文件**、**访问**和 **Groups and data** 卡片，**Invite member** 可从概览和主页的首次运行卡片中使用。请参阅[成员管理](/zh-cn/administration/access/member-management/)。
- **列表可显示为标准行、宽松行或卡片。** **仪表板**、**应用**、ERP 登记簿和“身份”**成员**等列表工具栏中的**视图**菜单取代了原来的紧凑切换。卡片保留列表的全部功能：选择、排序、列、右键**复制**和收藏星标。**仪表板**卡片显示缩略图。请参阅[标准、宽松和卡片视图](/zh-cn/guides/dashboards/using-dashboards/#标准宽松和卡片视图)。
- **Lakehouse 窗口带有侧栏、表详情和时间旅行。** **查询**、**配置文件**、**加载**和**目录**位于侧栏中，**管理**下有 **Lakehouse 目录**、**数据库用户**和**计算**。**数据库用户**和**计算**仅向拥有 Lakehouse 管理员或 Lakehouse 集群角色的成员显示。**查询**按 SQL 文本、用户、类型和持续时间筛选历史记录，使用 **Copy SQL** 复制语句，并使用 **Profile this query** 在**配置文件**中打开查询。**目录**会打开表的列、当前快照、分区、位置、属性和快照历史记录，**Copy query as of this snapshot** 会复制一个 `FOR VERSION AS OF` 查询，以读取该表当时的状态。请参阅 [Lakehouse 窗口](/zh-cn/guides/data/lakehouse-window/)。
- **步骤表单上的预览。** 导入：SQL、执行：SQL、提取 SQL、导出：SQL 和 Salesforce 查询无需运行步骤即可显示最多 100 行，Anaplan 视图和列表读取会显示它们将生成的列和类型。请在**源**选项卡上单击**预览**。变量会按运行时的填充方式填入，但不支持 `{x:>9}` 这样的变量格式。预览只运行标准 SQL 函数；否则会提示您运行该步骤。它在已锁定的项目上不可用，对基于代理的 Execute SQL 步骤也不可用。请参阅[导入 SQL](/zh-cn/reference/workflow-steps/import/import-sql/)和[提取 SQL](/zh-cn/reference/workflow-steps/tables/table-extract-sql/)。
- **使用情况报告会显示变化、可限定到某个分组，并可流入工作流。** **概览**新增了与上一周期对比的趋势箭头，以及指向未激活成员和无人打开的仪表板与应用的 **Highlights** 列表。已停用的成员不会被统计或列为未激活。**分组**将**概览**、**内容**和未激活列表限定到某个安全组的成员，日期范围新增了**上月**和**本月**，由所有选项卡共用，并会随您的账户一起记住。现在每个数据都有说明，表使用**成员**和**区域**等通俗名称，按 Enter 可打开行，加载和错误提示更清晰，最后一个**漏斗**步骤会显示有多少成员完成了它。**Get Workspace Usage** 步骤会按计划将使用情况写入表中，既可以是不含成员姓名的每日或每月合计，也可以是可直接用于报告的数据集：**成员**、**每位成员的每日数据**、**内容**和**每位成员的内容**。成员数据集包含姓名、电子邮件、分组和活动，因此可以按电子邮件将它们与您自己的组织表联接，并按部门报告活动分钟数或仪表板打开次数。与 **Get Workspace Members** 一样，每次运行都会记录在安全日志中。请参阅[使用情况报告](/zh-cn/administration/access/usage-reports/)和 [Get Workspace Usage](/zh-cn/reference/workflow-steps/general/get-workspace-usage/)。
- **AI 助手可以分析表的概要。** 通过 MCP，`table_profile` 会返回表资源管理器显示的列统计信息和数据质量雷达检查，以及每列最常见的值，一次最多 50 列，并且仅针对您可以看到的行。请参阅[从 AI 助手读取概要分析](/zh-cn/guides/data/table-explorer/#从-ai-助手读取分析结果)。
- **AI 助手可以取消发布表并设置项目的默认仪表板受众。** `publish_manage` 会取消发布表及其已发布的视图，以及没有任何图表使用的仪表板数据集；仍有图表使用的数据集会保留，当报表视图构建在已发布的视图之上时，该视图和数据集也会保留，而表仍会被取消发布。`project_upsert` 会设置 `dashboard_default_audience`，即与项目中新仪表板共享的分组，`[]` 会将其清除。请参阅[取消发布](/zh-cn/guides/data/publish/#通过-ai-助手或-mcp-取消发布)和[通过 AI 助手或 MCP 设置默认受众](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#通过-ai-助手或-mcp-设置默认受众)。

## 变更

- **如果您的工作区使用 Grok，移动端 Weave 会再次要求您同意其 AI 声明。** 该声明不再说明 xAI 不会使用您的数据训练其模型，而是改为说明 PlaidCloud 与 xAI 没有零数据保留协议，因此 xAI 可能会保留数据，并在其标准条款允许的范围内使用。请参阅 [Weave 如何使用您的数据](/zh-cn/guides/ai-assistant/weave-data-use/)。
- **假设分析窗口一次读取一个期间。** 当 Allocation Split 步骤的输出带有期间列时，窗口会在最新期间上打开，**期间：**可让您选择另一个期间或**所有期间**。如果某个步骤的动因在每个期间都有一行，因而过大而无法跨所有期间读取，现在会打开并针对某一个期间作答。已保存的方案会保留其保存时对应的期间（如果有），打开它时，只要该期间仍在列表中，窗口就会切换到该期间。请参阅[选择期间](/zh-cn/guides/allocations/results/driver-what-if/#选择期间)。
- **PlaidCloud 的 Web 应用和 Python 客户端库使用 REST API，JSON-RPC 已弃用。** Web 应用将其请求发送到 REST API。使用 `plaidcloud-rpc` 1.25.0 或更高版本时，`SimpleRPC` 调用会转到 REST API，无需更改您的代码；REST API 尚未涵盖的调用，或仍处于较旧版本的工作区，会像以前一样使用 JSON-RPC。JSON-RPC 将在后续版本中移除，因此请将您的脚本和笔记本升级到 `plaidcloud-rpc` 1.25.0 或更高版本，并针对 REST API 编写新的集成。请参阅[命令行](/zh-cn/reference/cli/jupyter/command-line/)。
- **步骤遵循其项目的连接环境，除非您将其固定到另一个环境。** 在环境之间切换项目（例如 QA 和 Production）会移动每个步骤。必须保持在某个环境的步骤可以改为设置 **Fixed environment**：表单会用警告标记它，其日志会注明每次在项目环境之外的环境上运行，切换项目时会指明不会跟随的步骤。ERP 过账步骤始终使用项目的环境。只要项目、固定步骤或代理仍在使用某个环境，就无法删除它，代理表单中的字段现在是 **Environment this agent serves**。请参阅[将步骤固定到某个环境](/zh-cn/guides/projects/managing-projects/#将步骤固定到单一环境)。
- **步骤表单遵循统一布局。** 选项卡采用标准名称和标准顺序：常规、设置、源、列、筛选器、输出和高级，ERP 过账表单上还有表头列和行列。必填字段用 * 标记，表单仅会因步骤所需的内容而阻止保存。
- **复制项目会分别选择表数据和维度成员，复制数据更快，并保留私有副本的 ERP 写入授权。** 在**要复制的数据**下，选择**表数据**：**无表数据**（默认）、**完整**或**样本**；另外还可单独选择**复制维度成员**（默认开启），因此不含表行的副本仍会带有已填充的维度，并且创建速度很快。**完整**和**样本**副本会同时复制多个表，因此包含许多表的项目完成得更快。**复制结果**会将每个维度的结果与表一起列出，**Retry failed items** 会将失败的表和维度一起重试。带数据创建的新副本仅您自己可见，并保留源中您自己可以授予的 ERP 写入授权；如果源以 Live 模式过账，副本会以 Simulate 模式到达，因此在您将其切换为 Live 之前，不会有任何内容到达 ERP。REST API 和 `project_copy` MCP 工具也接受 `dimension_members`。请参阅[选择复制多少数据](/zh-cn/guides/projects/managing-projects/#选择复制多少数据)和[副本中的 ERP 写入授权](/zh-cn/guides/projects/managing-projects/#副本中的-erp-写入授权)。
- **表的详细信息面板会更快地显示使用它的步骤。** 选择另一个表会立即清除上一个表的步骤，共享此项目数据的其他项目中的步骤会在其余内容之后稍等片刻再添加，而不会拖慢整个面板。请参阅[查看表的使用位置](/zh-cn/guides/projects/managing-tables-and-views/#查看表的使用位置)。
- **每个列表中的行操作工作方式相同。** 可通过行首的 **⋯** 按钮、右键单击该行，或工具栏的**操作**菜单打开行菜单。它始终先列出**打开**、**详细信息**和**编辑**，然后是列表自身的操作，最后是**删除**或**移除**，不适用于某行的操作会在原位置呈灰色。**Enter** 和 **Del** 显示在其所执行的项目上。如果列表的行只有单个操作，则显示该操作的图标而不是 **⋯**，仪表板、应用和笔记本再次显示**打开**图标。请参阅[行操作菜单](/zh-cn/guides/dashboards/using-dashboards/#行操作菜单)。
- **PlaidCloud 采用了全新的蓝色外观，支持浅色和深色。** 按钮、复选框、所选行、选项卡、链接以及列出工作区页面的侧栏使用同一种 PlaidCloud 蓝色，并具有在两种主题下都便于阅读所需的对比度。应用选项卡图标是一套统一的图标。
- **全新的加载屏幕。** PlaidCloud 会在更简洁的加载屏幕上打开，该屏幕跟随您的浅色或深色主题。从空闲状态唤醒的 Panel 或 Dash 应用会显示其**正在启动**、**正在准备**和**正在加载应用**的进度，如果未能启动，会说明停在了哪一步并提供**重试**。请参阅[使用 Panel 应用](/zh-cn/guides/panel-apps/using/)。
- **没有验证设置的已保存 ERP 写入步骤会以仅验证模式打开。** 这涵盖 SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL 和 AP Post，以及 Xero 导出。明确设置为实时运行的步骤仍保持实时。
- **长时间运行的作业在所有位置以相同方式显示进度。**
- **工作流如实地停止、失败和报告。** 停止工作流会停止它启动的所有内容，无法完成的运行或步骤会带着原因失败而不是挂起，运行状态与实际运行的内容一致。
  - **停止工作流会停止它启动的所有内容，无法完成的运行或步骤会失败而不是挂起。** 停止会取消仍在排队的导入和维度步骤，因此工作区中后续的导入和维度加载会正常启动，它还会停止该工作流中排队或正在运行的连接器（Singer）同步。如果某个步骤的作业无法启动，该步骤会带着原因失败，而不是无限期等待：约 40 分钟内没有工作进程启动它、工作进程启动后又消失、其 Pod 约 20 分钟一直处于 Pending 状态、其镜像约 5 分钟无法拉取，或约 20 分钟内没有创建 Pod。如果某个连接器同步在约 30 分钟内没有任何运行器接手，则会失败并给出指明该同步的消息。当步骤等待工作进程时，其状态消息显示“正在等待工作进程…”及已等待的分钟数，工作开始后即清除。停止宏会停止它所有正在运行的副本，而停止某一个副本，或 **Macro Concurrent** 步骤放弃某个停止响应的副本，都会让调用它的工作流继续运行。仅在其他工作流内部运行的宏会在工作流列表中显示为**正在运行**，可使用**停止**，并显示每个步骤最近一次运行的状态、开始时间和结束时间。服务器丢失的运行会以失败结束，运行超过 12 小时仍未结束的运行会失败，并显示“运行失败：运行已达 12 小时上限仍在运行。请重新运行工作流。”请参阅[运行工作流](/zh-cn/guides/workflows/run-a-workflow/#永远无法启动的步骤)。
  - **恢复、运行历史记录和运行状态与实际运行的内容一致。** 恢复父工作流会运行子工作流剩余的所有内容，即使您之前单独重新运行过该子工作流的某个步骤；一次运行中对子工作流的每次调用都有自己的运行历史记录条目。因服务器停止而重新启动的步骤会在其日志中说明，`workflow_run_status` 和 REST API 的运行结果会在 `continued_step_ids` 和 `continued_step_count` 中列出失败但继续运行的步骤，而不是将运行报告为一切正常。请参阅[暂停、停止和恢复](/zh-cn/guides/workflows/run-a-workflow/#暂停停止和恢复)和[出错后继续](/zh-cn/guides/workflows/continue-on-error/)。
  - **步骤错误显示其自身的消息。** PlaidCloud 未预料到的错误显示为“步骤因意外错误（*类型*）而停止：*消息*”。启动器上的**需要关注**卡片会用一行显示错误，并省略此后已被删除的工作流的运行。请参阅[管理步骤错误](/zh-cn/guides/workflows/managing-step-errors/)。
  - **未完成的 ERP 提取会使其步骤失败，并且可通过恢复继续。** 当 **SAP：临时提取**在其行数或时间限制处暂停或其代理未及时回复，或者 Salesforce、Oracle Fusion 批量或 HFM/FCCS 导出作业在步骤停止等待时仍在运行，该步骤会失败，这样其后的步骤就不会基于部分表运行。恢复工作流或重新运行该步骤，提取会在同一作业上从停止的位置继续。请参阅[运行限制](/zh-cn/guides/connections/sap-adhoc-extract/#运行限制)和 [Salesforce：查询对象](/zh-cn/reference/workflow-steps/salesforce/query-salesforce-object/#运行未完成时)。
  - **取消导出会停止其在仓库中的查询。** 取消导出或下载时（包括通过停止其工作流取消），在 Lakehouse v2、Snowflake、Databricks、PostgreSQL 和 Greenplum 上读取其数据的查询也会随之停止，导出到远程数据库会停止读取其源，而不是一直运行到结束。
- **工作区升级时，REST、Import REST 和 Import Postman 步骤会转换为 REST 请求。** 无法干净转换的步骤保持原样。请参阅 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)。
- **会话过期后打开的仪表板链接，会在您登录后带您转到该仪表板。** 请参阅[使用仪表板](/zh-cn/guides/dashboards/using-dashboards/)。
- **MCP 工具会拒绝其无法识别的字段**，并在错误中指明该字段，而不是忽略它。`workflow_upsert` 接受 `memo`，并接受 `description` 作为其别名。请参阅[未知字段会被拒绝](/zh-cn/integrations/ai-coding-agents/getting-started/#无法识别的字段会被拒绝)。
- **在 Lakehouse v2 上，Lakehouse 自行将 Parquet 导出写入 Google Cloud Storage。** 导出到 Google Cloud Storage 文档账户时，数据会使用账户自身的凭据直接写入该账户的存储桶，而不是让每一行都先经过 PlaidCloud。导出到 Amazon S3 和 Azure Blob Storage 账户的方式与以前相同。请参阅[导出为 Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/)。
- **Slack、Microsoft Teams 和 Web Hook 步骤会说明消息未发送的原因。** 步骤的错误会指明其尝试访问的服务器，对于 Slack 和 Teams 还会指明连接，并说明出了什么问题：例如，Slack 不再识别该 webhook、无法向该频道发帖、找不到服务器或服务器在 60 秒内没有应答，或者连接已被删除。Slack 或 Teams 的 webhook URL 绝不会显示，因为任何拥有它的人都可以冒充您的集成发帖。请参阅 [Notify via Slack](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/)。
- **项目服务账户的访问令牌至少持续 24 小时。** 以项目身份运行的工作流作业（例如 UDF 步骤）获得的令牌持续 24 小时。工作区升级时会提高较短的有效期，您设置的较长有效期则会保留。
- **工作区的组织、所有者、发布和版本由 PlaidCloud 设置，您可以选择其数据中心。** 在控制平面中，您创建的工作区归您所有，并放置在 PlaidCloud 设置的发布渠道上，您可从注册时提供的区域中选择其 **Data Center**。编辑工作区时，组织、所有者、发布和版本为只读。使用 **Set Version** 更改版本，并请 PlaidCloud 支持团队移动工作区、更改其所有者或渠道，或将其固定。请参阅[工作区配置](/zh-cn/administration/control-plane/workspace-configuration/#主要设置)。

## 已修复

- **无效的项目设置会以清晰的消息报告。** 未知的环境或文档账户、已被占用或保留的 slug，或无效的存储类型或过账模式，现在会返回指明问题的消息，而不是通用的服务器错误。通过 REST API 时返回 400 而不是 500，通过 AI 助手或 MCP 时则是无效参数错误。
- **REST API 的维度值请求现在可用。** `POST /rest/v1/analyze/query/retrieve-dimension-values` 过去被当作网格请求处理并被拒绝为无效。现在它会为 `value_columns` 中的每一列返回一个聚合值，而网格（即每一对行筛选器和列筛选器对应一个值）则有自己的 `POST /rest/v1/analyze/query/retrieve-dimension-cells`。
- **缓慢的表读取和文件处理不再阻塞其他请求。** 从仓库读取表的列、登记 Data Foundation 文件、导出到 Excel、读取 REST 或 SOAP 导入的响应、查找文档账户的使用位置，以及检查 Panel 应用的代码或徽标，过去都可能使同一服务器正在处理的所有其他请求暂停，直到其完成。现在它们与这些请求并行运行。
- **项目和工作流变量对话框可以滚动。** 在小屏幕或低分辨率下，添加和编辑对话框比窗口更高，因此**创建**和**更新**按钮可能够不到。现在表单可以滚动，按钮保持在底部。
- **Azure Blob Storage 文档账户中超过 256 MiB 的文件可以复制、移动和重命名。** 过去这些操作对该大小的文件都会失败，移动或重命名包含此类文件的文件夹也是如此。
- **在 Lakehouse v2 上，表的行数反映刚写入的内容。** 写入表的步骤或导入可能记录的是写入之前的行数，因此刚加载的表显示 0 行，导入可能报告导入了 0 行。现在会在新行在各处可见之后再读取行数，因此其后的步骤也能读取这些行。将表切换到另一个分支，或将分支合并到其中，也会更新其行数和列数。
- **Weave 的空值检查会将每次运行与之前运行实际留下的内容进行比较。** 步骤的空值经常是在该步骤清空其表以重新填充之后才被统计，因此其之前的运行看起来没有空值，而一直部分为空的列会被报告为刚刚变空。现在每次运行都按步骤留下其表的状态来统计。之前记录的计数无法与正确的计数区分开，因此不会使用：每个步骤的空值检查都会重新开始其历史记录，在统计满五次运行之前报告为未检查。行数和值分布检查也不再将另一个步骤在其完成两秒之后对同一张表所做的写入记在该步骤名下。请参阅 [Weave检查内容](/zh-cn/guides/ai-assistant/weave-findings/)。
- **Data Foundation 保留反向汇率和小数阈值的精度。** PlaidCloud 因您的汇率是从报告货币报价到另一种货币而反转的汇率，可能被舍入到小数点后六位，这会使汇率较小的货币（例如印尼盾）的金额偏差约 1%。现在反向汇率保留 12 位小数。带小数的 `group_amber` 或 `group_red` 阈值（例如 `0.5`）过去会被舍入为整数。您的下一次加载会使用精确值。请参阅[汇率](/zh-cn/guides/projects/data-foundation/#汇率)。
- **已停用成员的警报和摘要会停止。** 所有者已被停用的 Panel 应用警报或摘要过去仍会持续检查和发送。现在它会在其被停用期间暂停，并在其被重新激活后恢复。请参阅[警报和摘要](/zh-cn/guides/panel-apps/alerts-and-digests/)。
- **向 REST API 请求已删除的连接会返回 404。** 请求已被删除的连接或不存在的 ID，过去会返回通用的服务器错误（500）。现在它会返回 404 及指明连接 ID 的消息。
- **模板化表导出可通过 AI 助手和 MCP 使用。** `table_data_export` 的 `templated` 格式在指定表时总会失败。现在它会通过您的模板导出该表，并限于您可以读取的行。在模板中，表的行以其表 ID 命名，其中每个 `-` 写作 `_`。
- **Amazon S3 和兼容 S3 的文档账户会保留其区域。** 保存这类账户时，您输入的**区域**会被丢弃，因此下次打开账户时该字段为空。现在区域会被保存。对于在此修复之前保存的账户，请重新输入区域并保存。请参阅[添加 AWS S3 账户](/zh-cn/guides/documents/adding-accounts/add-aws-s3-account/)。
- **AI 助手和 JSON-RPC 不再指明使用您的角色所隐藏的表的步骤。** 询问此类表在何处使用时，它们过去会指明您的角色可以看到的、读取或写入它的每个步骤，包括其设置和工作流。现在它们只说明有步骤使用该表，而不指明这些步骤，与项目的表引用一致。请参阅[您的角色隐藏的内容](/zh-cn/guides/ai-assistant/weave-tab/#您的角色隐藏的内容)。
- **您选择的默认 AI 连接会保持为默认。** 将某个 AI 连接标记为工作区默认连接看似成功，实际却从未保存，因此依赖默认连接的代理和步骤继续使用最近更新的那个连接。现在您的选择会被保存。请参阅 [LLM 提供商](/zh-cn/integrations/ai-architecture/llm-providers/#连接包含的内容)。
- **在 Weave 历史记录中右键单击对话时，不再在删除对话线程之上打开重命名。** **重命名**现在位于聊天的选项卡上：右键单击选项卡即可，而此前该选项卡不提供任何内容。请参阅 [Weave 选项卡中的选项卡](/zh-cn/guides/ai-assistant/weave-tab/#weave-选项卡中的选项卡)。

## 安全

- **Weave 不再在每次对话开始时向其 AI 提供商发送您的姓名和电子邮件地址。** 它从未使用过这些信息。
- **密码登录需要身份验证器应用，密码也更强。** 使用 PlaidCloud 密码登录的成员会在下次登录时被要求设置身份验证器应用，此后每次都要输入其验证码。单点登录、Google、Microsoft 和 GitHub 登录、API 令牌和服务账户保持不变。新密码至少需要 12 个字符，不能是您的用户名或最近六次使用过的密码之一，多次登录失败后账户会被短暂锁定。工作区已有的更严格规则会被保留。请参阅[成员身份验证](/zh-cn/administration/access/member-authentication/)。
- **连接可指向公共和专用网络地址。** 连接不能指向环回、链路本地或云元数据地址，错误会指明主机及其解析到的地址。您专用网络上的地址不受影响。请参阅[连接无法访问的地址](/zh-cn/guides/connections/create-connection/#连接无法访问的地址)。
- **已保存的连接凭据仅向可以编辑连接或工作流的成员显示。** 通过 REST API 和 MCP，已保存连接的密码、令牌和密钥会对其他成员进行掩码处理，这些成员仍可打开和浏览该连接。请参阅[谁可以看到连接的凭据](/zh-cn/guides/connections/create-connection/#谁能看到连接的凭据)。
- **应用构建在运行时无法访问您工作区的 Git 凭据。**
- **代理的私钥仅向可以编辑代理的成员显示。** 通过 REST API 和 MCP，该密钥不再出现在代理列表或详细信息中，代理表单仅向可以编辑代理的成员显示**私钥**和**查看 RPC 配置**。服务账户、项目和代理令牌以及 AI 委托令牌无法检索该密钥或 RPC 配置。正在运行的代理不受影响，公钥仍会显示。请参阅[获取代理凭据](/zh-cn/reference/cli/plaidlink/agents/#获取代理凭据)。
- **代理下载链接的有效期为一小时。** 开启 **Use PlaidCloud Proxy Download** 后，链接过期时请重新打开下载以获取新链接。请参阅[服务](/zh-cn/administration/control-plane/workspace-configuration/#服务)。
- **将人员添加到安全组遵循您所拥有的权限。** 当您拥有安全组授予的每项权限时，才可以将成员添加到安全组、选择成员的分组或邀请架构师。工作区管理员不受限制。请参阅[管理安全组](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理安全组)。
- **连接的所有者或工作区管理员可更改其设置并将其开启或关闭。** 通过 REST API、JSON-RPC 以及 AI 助手或 MCP 更改连接的设置，需要其所有者之一，对于没有所有者的连接则需要工作区管理员。启用、禁用、锁定和解锁连接需要所有者或工作区管理员，指明多个连接的请求仅在您可以更改所有这些连接时才会生效。只有工作区管理员才能选择工作区的默认 AI 连接，并且只有当不存在由管理员拥有或没有所有者的连接可作为默认连接时，成员拥有的连接才会成为默认连接。请参阅[编辑连接](/zh-cn/guides/connections/create-connection/#编辑连接)和 [LLM 提供商](/zh-cn/integrations/ai-architecture/llm-providers/#连接包含的内容)。
- **行访问适用于成员对受限表执行的所有操作。** 成员在仪表板、在其自己的 SQL 以及在加载中，只能看到和更改其授权允许的行。
  - **项目架构师可在仪表板中看到行受限表的所有行**，与其在 Analyze 中看到的一致。取消架构师访问权限会在仪表板中立即生效，无论您是更改某人的角色、将其或其分组从项目中移除、更改项目的访问类型、还原项目的早期版本，还是删除安全组。请参阅[管理行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。
  - **受行访问限制的成员可以运行自己的 SQL 查询并导出结果。** 在具有行访问的项目中，非架构师成员在查询屏幕上通过自己的查询只会得到其授权允许的行，并且可以将其导出为 CSV、Excel 或 JSON，并带有**行数受您的访问权限限制**提示；此前这些操作会被拒绝。包含百分号（`%`）的授权值现在可以在查询屏幕上返回其行，将此类查询下载为 CSV 也可以正常工作。他们在 Snowflake 或 Databricks 上自己的自由格式 SQL、Postgres 系列仓库中对其自己 SQL 的导出，以及按快照读取受管控的表，仍会被拒绝，并且视图必须以原始名称保留受管控的列才能被筛选。请参阅[行访问和您自己编写的查询](/zh-cn/administration/access/managing-security-groups-and-assignments/#行访问与您自己编写的查询)。
  - **保存行访问会保留其源中没有的已授予值。** 当表中没有包含该值的行、维度中没有该成员或列表中没有该值时，安全组被授予的值会保留在网格中并带有标记。**保存**会询问是保留还是移除每个此类值。请参阅[行访问网格](/zh-cn/administration/access/managing-security-groups-and-assignments/#行访问网格)。
  - **向行受限表写入 DataFrame、保存记录和清除时，只会更改您能看到的行。** 当行访问限制您的行时，使用 Python 客户端向受限表写入 DataFrame 或清除它，或通过 REST API 向其保存记录或清除它，只会更改您自己的行，包含您访问权限之外的行的加载会在任何更改之前被拒绝，并指明其发现的值。项目架构师、可以看到所有行的成员和工作流运行会写入整个表。个人对任何表所做的每次此类写入都会记录在安全日志中。请参阅[向受限表加载数据](/zh-cn/administration/access/managing-security-groups-and-assignments/#向受限表加载数据)。
  - **对行受限表的导入、复制、还原和删除要求您能看到每一行。** 当行访问限制您的行时，将文件导入受限表、从另一个项目将表复制到其中、切换或合并其分支、还原它、删除它、在删除后将其恢复，或任何其他替换整个表的操作，仅在您可以看到该表的每一行时才会运行；否则会被拒绝且不会更改任何内容。通过 REST API 保存表的行只会更改您自己的行，与其他加载相同。项目架构师、可以看到所有行的成员和工作流运行不受影响，这些操作同样会记录在安全日志中。请参阅[向受限表加载数据](/zh-cn/administration/access/managing-security-groups-and-assignments/#向受限表加载数据)。
- **只有账户的所有者才能还原其早期版本。** 将文档账户还原到早期版本、保留或释放某个版本以及进行备份，都需要账户的所有者之一，并且这些操作在系统管理的账户上都不可用。查看账户的版本历史记录需要拥有该账户的访问权限。
- **`query_run` 运行只读语句。** AI 助手和 MCP 客户端使用的 `query_run` 工具接受一条 SELECT 或 WITH 语句、对其的 EXPLAIN，或 SHOW；其他任何语句都不会运行。若要更改数据，请使用 `query_transform`。MCP 表导出中的 SQL 遵循相同的规则。对于无法更改项目数据的成员，通过 REST 和 JSON-RPC API，这一规则同样适用于运行查询、构建列分面、将查询下载为 CSV、将查询导出到远程数据库，以及使用自己的查询导出表数据；被拒绝的查询会返回 403。Explain Analyze 会运行查询以进行测量，因此在查询日志和 Lakehouse 中，它只接受读取型查询，并且在具有行访问的项目上，只有项目架构师才能从查询日志中运行它。
- **表资源管理器筛选器、发送到 PlaidCloud 的查询，以及查找 Table Extract 步骤的动态列的查询，不能调用运行 SQL 或读取服务器文件的函数。** 对此类函数（例如 `query_to_xml`、`dblink` 或 `pg_read_file`）的调用会被拒绝，错误会指明该函数。在相同的位置，`.op()` 只接受运算符，`literal_column` 不能使用 Unicode 转义引用。动态列查询带有步骤的筛选器以及从源读取列名的表达式，因此违反规则的查询会使该步骤在运行时失败。请参阅[被拒绝的函数和运算符](/zh-cn/reference/workflow-steps/common/advanced-data-mapper-usage/#会被拒绝的函数和运算符)。
- **Data Foundation 分摊规则会拒绝包含单引号、反斜杠或换行符的部门或统计名称。** 该名称会被写入分摊步骤的筛选器中，因此**保存**和第 1 阶段的预览会拒绝它并指明该值。请参阅[分摊规则](/zh-cn/guides/projects/data-foundation/#分摊规则)。
