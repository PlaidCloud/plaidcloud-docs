## 新增

- **多代理 AI 助手** — 助手现在通过单一编排器协调多个专业子代理，为您的数据问题提供更准确、推理更充分的答案。
- **聊天中的可视化说明** — 助手可以生成图表和内嵌图形来说明其答案，让复杂的结果一目了然。
- **AI（LLM）工作流步骤** — 在工作流中直接将大型语言模型作为一个步骤调用，支持多个提供商和多种访问级别。
- **根据描述生成 SQL 提取** — 用自然语言描述您想要的结果，助手就会为您编写查询，甚至会选择相关的源表；在保存之前，生成的 SQL 和检测到的列仍可完全编辑。
- **通过助手导出表** — 让助手导出一个表，它会为您构建可重复运行的导出步骤，文件格式取决于您选择的扩展名（CSV、TSV、Excel、Parquet、JSON 或 XML）。
- **140 多个新数据连接器** — 大幅扩展支持的数据源，提供引导式连接设置，并自动发现可导入的数据流。
- **增量、可恢复的同步** — 同步会从中断处继续，并按键合并新记录，因此只需移动发生变化的数据。
- **更快的 Snowflake 导入** — 服务器端卸载加快了从 Snowflake 导入大型数据的速度。
- **REST 请求工作流步骤** — 调用连接目录中的任意端点，发送测试请求，并将响应捕获到表中，或捕获到工作流变量中以便据此分支。
- **带有可视化联接设计器的多表联接步骤** — 在可视化图上绘制表列之间的联接，支持撤销/重做和图表导出。
- **预测工作流步骤** — 直接将预测作为工作流步骤运行。
- **求解器工作流步骤** — 将优化（线性和混合整数）作为工作流步骤运行，并写出解、约束和汇总表。
- **并发宏执行** — 宏步骤可以并行执行工作，加快处理速度。
- **协作式可视化工作流设计器** — 工作流的可视化视图，提供步骤颜色编码、重新设计的画布和实时协作，团队成员可以共同处理同一个工作流。
- **工作流运行历史和热力图** — 全新的运行历史视图，配有活动热力图，让您一眼发现规律和有问题的运行。
- **计划事件日历** — 以周、月和议程视图查看即将进行的计划运行，支持重叠检测，以及按计划、工作流和项目筛选。
- **表快照和时间点还原** — 查看表在较早保存时间点的状态，并在需要回滚时就地还原。
- **重新构建的项目报告** — 经过全面重新设计的报告，记录每个工作流步骤，每个工作流都以生成的流程图开头，并包含执行摘要和审计清单（连接、表及其血缘、源文件和导出）。可生成精美的品牌化 PDF，也可生成带有可折叠详情和可点击目录的交互式 HTML 配套文件；进度对话框会逐个工作流跟踪生成进度。
- **比较和合并项目** — 查看两个项目之间的差异，并在它们之间安全地合并变更。
- **“使用位置”影响分析** — 在更改之前，快速查看代理和外部数据连接在哪些地方被使用。
- **分摊根因追踪** — 全新的血缘和追踪工具让您更容易理解并排查分摊结果是如何产生的。当结果由多个分摊步骤产生时，助手会列出候选项并询问要追踪哪一个；如果您的问题缩小到只有其中一个步骤产生的行，则会自动追踪正确的那个。追踪还能处理真实环境中的模型：包含空格、括号或 `%` 符号的列名；StarRocks 工作区以及 Databend 和 Postgres；以友好名称引用的表；以及同样涵盖为每个分摊提供数据的驱动因素表和基础表的数据新鲜度。
- **服务器 Panel 应用的日志** — 直接在 PlaidCloud 中打开服务器 Panel 应用的日志，提供独立的**运行时**和**构建**视图：查看正在运行的应用记录和打印的内容（即使应用空闲并关闭后也会保留），或阅读构建输出以找出构建失败的原因——支持级别筛选、时间范围和自动刷新。
- **Panel 应用以查看者身份读取数据** — 服务器端 Panel 应用现在通过单点登录让每位查看者登录，并以该用户自己的权限读取 PlaidCloud 数据，因此向每位查看者展示的正是他们有权查看的内容。无需共享服务账户——非常适合按用户定制的仪表板和行级安全。
- **更易阅读的 Panel 应用日志** — 日志查看器现在允许您选择一行，在侧边窗格中阅读其完整消息，因此较长的错误和完整的堆栈跟踪不再被截断。您还可以一次选择多行并复制——在调试时粘贴给 AI 助手或发送给团队的消息中非常方便。
- **Panel 应用日志显示触发者** — 当您的应用让查看者登录时，每条日志行都会标记产生该日志的会话所属的用户，让您可以分辨是哪位查看者遇到了错误或警告。（尽力而为——部分启动行在任何查看者参与之前就已运行。）
- **服务器 Panel 应用的使用指标** — 在应用列表中“查看日志”旁打开的全新 Usage Metrics 视图，展示应用的使用情况：唯一用户数、会话数、平均和中位会话时长、上次使用时间，以及按用户和按天的明细。（时长为近似值，因为应用在两次访问之间会空闲并缩容。）
- **委托式 Git 管理** — 全新的 **Git Administration** 权限控制谁可以管理您工作区的 Git 服务，包括创建组织。可将其附加到任意安全组（或使用内置的 **Git Administration** 分组），让您自己的用户管理 Git，而无需 PlaidCloud 介入。

## 变更

- **更相关的 AI 答案** — 改进的检索会在助手回答时引入合适的支持上下文，表达式编写帮助现在会对照引擎实际运行的内容进行检查，从而更早发现错误。
- **助手可以修复失败的步骤** — 当工作流步骤出错时，助手可以提出修正后的配置，并在您批准后应用该修复——而不仅仅是解释出了什么问题。
- **更清晰的 AI 活动** — 助手处理较长的查询时会显示处理指示器，而不是让您面对无声的空白；对话现在按项目组织。
- **更快的表预览** — 表浏览器可以显示快速的随机样本，而不是始终显示前几行；列值概要现在会限制长时间运行的查询（并显示“已超时”标记），使浏览器在超大表上依然保持响应。
- **更大的维度可进一步扩展** — 超大的层次结构现在可以存储在项目的数据存储中，作为内存存储的替代方案，因此可以持久保存并扩展，而不会拖慢速度。
- **可视化工作流设计器增强** — 可深度链接的项目和画布网址，浏览器后退和前进可正常使用；高级工作流节点上的断点；以及可作为整体启用或禁用的可分组节点容器。
- **更稳健的文件导入** — 改进了 Parquet 处理，并为有问题的文件（包括格式错误的 XML 和棘手的文本编码）提供更清晰、更可靠的错误报告。
- **更流畅的仪表板和用户同步** — 修复了仪表板渲染问题，并加强了用户和角色与分析层的同步。
- **更具弹性的连接** — 缓存层的自我修复和后台处理方面的修复减少了停滞，提升了整体响应速度。
- **服务器 Panel 应用的加载屏幕** — 打开已进入空闲状态的服务器端 Panel 应用时，现在会在其启动期间显示带有品牌标识的 PlaidCloud 加载屏幕，而不是空白标签页；如果无法启动，则会变为清晰的“此应用未能启动”消息，并提供重试。
- **从应用列表重新构建服务器 Panel 应用** — 使用新的**重新构建**行操作，无需取消发布再重新发布，即可重新构建并重新部署服务器应用。
- **服务器 Panel 应用的现代外观和外观控制** — 服务器 Panel 应用现在默认使用现代的 Fast 设计，在现有 CSS 需要时可切换回 Panel 的 Default 设计，并允许通过您提供的模板在应用中设置主题——浅色、深色，或供查看者切换的浅色/深色切换开关。为浅色背景构建的表格和自定义样式应保持使用浅色。
- **服务器 Panel 应用的本地构建控制** — Panel 应用指南现在列出了 PlaidCloud 部署应用时所使用的 `PANEL_*` 环境变量和 `panel serve` 标志，高级用户可以据此在本地重现已部署的运行时。

## 修复

- **不再“卡在刷新”** — 修复了当服务器短暂无法确认当前版本时，应用可能反复自行重新加载的情况。
- **联接类型现在会保留** — 选择右联接或全外联接现在会保留，而不是悄悄恢复为左联接。
- **可靠的表导出** — 修复了导出到 Parquet、Avro 和 XML 时可能失败的问题，包括某些项目上未压缩的 Parquet。
- **中断的步骤可恢复** — 当处理导入和导出步骤的工作进程被中断时，这些步骤不再看似永远运行；工作会由另一个工作进程接手并完成。
- **CSV 导入默认值** — 修复了因缺少“null as”默认值而可能无法运行的已导入 CSV 步骤。
- **旧工作区中的 Panel 应用权限** — 在该功能发布之前创建的工作区中，Panel 应用的读取和写入权限现在会显示，并且可以分配。
- **文档浏览器** — 修复了文件夹首次打开时显示为空、文件夹移动路径错误，以及刷新刚被移动或删除的文件夹时偶尔崩溃的问题。
- **多架构外部数据库导入** — 修复了在导入和导出外部数据库表步骤上，当所选源表来自多个架构时，“检索元数据”和“检查源数据库”因“意外错误”而失败的问题；多架构选择现在可以正确刷新，连接或元数据问题会报告清晰的消息，而不是笼统的错误。

## 安全

- **PlaidCloud 支持团队的无密码访问** — 所有支持团队成员现在无需用户名和密码即可登录，消除了基于密码的凭据作为支持团队访问平台的攻击途径。
- **更强的租户级隔离** — 每个租户现在为会话和工作流步骤使用各自专用的签名密钥。
- **跨站脚本（XSS）加固** — 对话框内容和屏幕通知默认会被安全转义，仅在明确需要的地方才允许使用 HTML。
- **加固的文件导入** — 格式错误的上传会被安全处理，而不是显示令人困惑的错误。
- **持续漏洞扫描** — 每次构建时，都会自动扫描应用镜像中的已知安全漏洞。
