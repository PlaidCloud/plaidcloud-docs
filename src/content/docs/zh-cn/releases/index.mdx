## 这些说明是如何编写的

每份月度摘要汇总了该自然月内发布到租户的实质性变更。纯基础设施工作（镜像升级、内部重构、RC 发布、密钥轮换、可观测性调优）按主题标签归类，而不逐条列出。如果某个月有客户可见的功能，则会按“新增 / 变更 / 修复 / 安全”的结构明确列出。

如需了解任何特定版本的详细信息，请联系您的客户团队。

今后每份新的月度摘要发布后都会列在这里。
