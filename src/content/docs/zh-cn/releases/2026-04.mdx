## 变更

- **交互式 API 文档现在位于各租户内部** — 以前从中央文档路径提供的 Swagger UI，现在嵌入每个租户的实例中。请通过您的工作区访问，而不是单独的网址。
- **PlaidLink 已更新** — 已发布新的 PlaidLink 构建版本；现有安装可继续使用，可在方便时升级。

## 新增

- **AI 编码代理支持的基础** — `/mcp` 和 `/.well-known/oauth-*` 路径的初始入口配置已于本月完成，为 5 月面向用户推出的 MCP 集成奠定了基础。
- **StarRocks 4.1（Lakehouse v2）测试** — 新一代 Lakehouse 引擎正在使用真实工作负载进行验证。目前没有用户可见的变更；可自行选择加入的迁移将于稍后推出。
