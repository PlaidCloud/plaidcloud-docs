## 新增

- **Data Foundation 将您的 ERP 数据汇集到一个 Common Finance Model 中**。Common Finance Model 将来自多个 ERP 系统和实例的 ERP 数据汇集到一个模型中：一套会计科目表、一组实体和一种报告货币。基于它构建的报表、指标和 AI 助手读取的都是同样的数字，无论数据来自哪个 ERP。

  - **直接来自您的 ERP**。总账、试算平衡表、主数据和预算通过 PlaidCloud 的 ERP 直连获取。**实体对照表**会将各来源的公司代码映射到相同的实体，文件则用于补充系统中没有的内容，例如汇率或分摊动因。
  - **一个模型，一种货币**。**加载**会将每个来源整合到 Common Finance Model 中，并换算为您的报告货币：损益表按期间平均汇率，资产负债表按期末汇率，权益按历史汇率。层次结构由您的主数据构建。
  - **检查就绪状态**。针对每个实体和期间运行检查：试算平衡表和销售额与总账相符，每个产品、客户和科目都已知，货币可以换算，每个实体都已映射。
  - **多个来源，一个模型**。添加、排序、编辑和移除来源，每个来源可以是 ERP 系统或实例，也可以是文件。**加载**会整合所有来源，在重叠处只保留一份，并记录被搁置的行及原因；**Apply changes** 会重新运行整合，而无需再次从 ERP 提取数据。
  - **跨来源映射代码**。当多个来源使用相同的代码时，系统会按名称匹配给出建议，询问其含义是否相同；您可以回答单个代码，也可以使用 **Accept all**、**All the same** 或 **All different** 一次回答整组。映射会按来源和维度保存。最多十个额外类别使用您为其指定的名称，覆盖范围视图让您选择从哪个月份起哪个来源生效。
  - **文件选项**。文件可以只应用于一个来源、提出它需要回答的问题、将一列拆分为多个字段、设置报告货币，或被移除。
  - **管理合并**。每次加载都会构建集团损益表（包括本年累计），其中集团内部交易在 **Eliminations** 实体上抵销，另有一个 **Unmapped** 桶，并与您的合并系统的结果进行对账。这是一个遵循项目行访问权限的管理视图，而不是法定合并。
  - **保持最新**。**每晚刷新**会在每晚重新加载模型，缺少文件或文件为空时会以警告而不是错误结束。

  从模板（例如 **Enterprise Profitability**）创建项目后，项目的**基础数据**选项卡会带您完成从已连接的 ERP 到已加载并检查的模型的全过程。请参阅 [Data Foundation：Common Finance Model](/zh-cn/guides/projects/data-foundation/)。

- **在您自己的 Snowflake 或 Databricks 数据仓库上运行 PlaidCloud**。工作区管理员在用户菜单中打开**使用您自己的数据仓库**，并在自己的账户中运行生成的设置脚本。该脚本会创建一个有上限的仓库和一个供 PlaidCloud 使用的服务身份，并且绝不会触碰您现有的仓库。**检查连接**会用通俗的语言解释任何问题及其解决办法。此后新项目会将其表存储在您的仓库中，并在其中运行工作流；移除仓库会撤销 PlaidCloud 在该处的访问权限。请参阅[使用您自己的数据仓库](/zh-cn/guides/connections/external-lakehouse/)。

  - **使用 Snowflake 或 Databricks 登录**。管理员无需粘贴凭据，而是可以通过登录来关联仓库。此后仪表板将使用每个人自己的仓库权限运行，工作流则以仅持有您指定的数据角色的服务身份运行。请参阅[使用 Snowflake 或 Databricks 登录](/zh-cn/guides/connections/external-lakehouse/#使用-snowflake-或-databricks-登录)。
  - **连接多个仓库**。在**管理数据仓库**中选择**设为默认**，可将新项目发送到另一个仓库，而现有项目保持不变。请参阅[管理数据仓库](/zh-cn/guides/connections/external-lakehouse/#管理数据仓库)。
  - **查看每次运行的成本**。运行历史记录会为每次运行显示一个**仓库成本**列，以积分或 DBU 为单位。请参阅[每次运行的仓库成本](/zh-cn/guides/connections/external-lakehouse/#每次运行的仓库成本)。
  - **您的治理策略保持不变**。描述会写入仓库自己的目录，当 PlaidCloud 替换、重新创建或克隆表时，Snowflake 的行访问策略和掩码策略以及 Databricks 的行筛选器和列掩码仍会保持关联。请参阅[您的策略和描述会被保留](/zh-cn/guides/connections/external-lakehouse/#您的策略和说明会延续)。

- **在 PlaidCloud 内构建、发布和定制 Panel 应用的品牌**。

  - **Panel Studio**。**我的 Panel 应用**中的第一个按钮**新建 Studio 应用**可从空白应用、表、视图、另一个 Studio 应用或应用库开始，**表**选项卡上的**创建 Panel 应用**则从您选中的表开始。**在 Studio 中打开**会在编辑器中打开应用的文件。可以保存草稿，用**预览**查看私有构建，并**发布**正式应用。构建错误会指向其所在的文件和行，**历史记录**可恢复任何已发布的版本，**洞察**显示浏览量、加载时间和错误。**询问 Weave** 了解应用的文件和构建状态，并会在保存任何代码之前向您展示完整差异以供批准。请参阅 [Panel Studio](/zh-cn/guides/panel-apps/studio/) 和[使用 Weave 构建 Panel 应用](/zh-cn/guides/panel-apps/build-with-weave/)。
  - **外观与 PlaidCloud 一致的应用工具包**。使用该工具包构建的应用在浅色和深色下都采用 PlaidCloud 的颜色、字体和间距。工具包包括导航、筛选器、关键数字卡片、图表、表单、命令面板、运行工作流的按钮、打印，以及一个在服务器端排序和汇总、按列格式化数字、每次加载一屏行的数据网格，因此可以处理任意大小的表。应用以已登录查看者的身份读取表，并应用行级安全。请参阅 [Panel 应用工具包](/zh-cn/guides/panel-apps/app-kit/)、[DataGrid](/zh-cn/guides/panel-apps/app-kit/#datagrid) 和 [Panel 应用的数据 API](/zh-cn/guides/panel-apps/data-api/)。
  - **提醒和摘要**。当项目表中的某个数字越过限值时，通过推送通知、电子邮件、Slack 或 Microsoft Teams 获得通知，或获取最多包含 10 个数字的每日或每周摘要，始终遵循您自己的行访问权限。请参阅[提醒和摘要](/zh-cn/guides/panel-apps/alerts-and-digests/)。
  - **项目、品牌和共享**。将应用分配给项目，分配前会先审查哪些人可以打开该应用但不在项目中。项目**主页**选项卡上的**编辑品牌设置**会为项目中的每个应用设置八种品牌颜色和一个徽标。**应用库…** 会将属于某个项目的 Studio 应用作为模板列出，供所有能查看其项目的人使用，**从应用库中移除**则将其撤下。请参阅[项目品牌和应用项目](/zh-cn/guides/panel-apps/branding/)和[应用库](/zh-cn/guides/panel-apps/gallery/)。

- **只需约定一次业务数字的计算方式，每个 AI 回答都使用该计算**。项目架构师定义一个**指标**，例如*净收入*或*人数*：它的源表、各行如何累加、始终计入的行、它联接的查找表，以及可用于细分它的列。定义一经保存即生效；如果保存时指定了不存在的表或列，或某个查找表的每个键对应多行，保存会被拒绝。按名称或同义词向 AI 助手询问该指标，数字会按定义并在您自己的行访问权限下计算，而不是由助手自行推算。定义通过 AI 助手或 REST API 管理。请参阅[指标定义](/zh-cn/integrations/ai-coding-agents/metric-definitions/)。

  - **派生指标**。定义两个指标的比率、和或差，例如人均净收入，或某个指标乘以固定系数。请参阅[从其他指标派生指标](/zh-cn/integrations/ai-coding-agents/metric-definitions/#由其他指标派生指标)。
  - **比较、排名和占比**。可以询问相对预算的差异、保留并列项的前 N 名或后 N 名，或每一行占总计的份额。请参阅[比较、排名和占比](/zh-cn/integrations/ai-coding-agents/metric-definitions/#比较排名和占比)。
  - **您的措辞，约定的值**。将细分列绑定到维度后，像 *EMEA* 这样的词就会变成其下的每个区域。如果某个词没有匹配项或匹配多个成员，会作为候选项返回并向您确认，绝不会猜测。请参阅[询问指标](/zh-cn/integrations/ai-coding-agents/metric-definitions/#询问指标)。
  - **财年时间**。告诉指标其各行在您的财年日历中的位置，然后可以询问某个财年期间、本年累计、同比或环比。请参阅[随时间比较](/zh-cn/integrations/ai-coding-agents/metric-definitions/#随时间比较)。

  PlaidCloud 自己的 AI 助手回答业务数字时会优先使用指标，并在单独的卡片中显示这些数字，卡片标有 ✓，该标记绝不会出现在助手自己的文本上。请参阅[业务数字](/zh-cn/guides/ai-assistant/weave-tab/#业务数字)和[来自指标的数字](/zh-cn/guides/ai-assistant/weave-tab/#来自指标的数字)。

- **询问 Weave 是否已准备好结账，并检查两个表是否对平**。两者都不涉及 AI。

  - **结账就绪检查**。在项目的 **Weave** 选项卡上，从**就绪状态**中将结账、预测或任何截止日期所依赖的工作流命名为一个**就绪集**。一份清单即可回答所有这些工作流的状态：“13 个中有 11 个就绪；1 个未就绪；1 个无法检查。”只有当 Weave 能对某个工作流运行的每项检查都通过时，该工作流才算就绪；Weave 无法判断的内容会显示为**无法检查**并附上原因，绝不会显示为就绪。如果最近一次运行的更早历史太少而无法比较（例如新工作流），则按正常情况计算。不写入表的步骤（例如发送电子邮件或导出文件的步骤）没有行或空值需要检查，因此不会使工作流停留在**无法检查**。请参阅[结账前检查就绪状态](/zh-cn/guides/ai-assistant/weave-readiness/)。
  - **对账**。按您配对的关键列，逐行比较两个表，或同一个表的两个期间。Weave 会说明它们是否对平、相差多少以及哪些行不同，对于无法完整读取的数据，绝不会说“对平”。每项对账在使用之前，需要由另一位架构师批准。请参阅[检查两个表是否对平](/zh-cn/guides/ai-assistant/weave-reconciliation/)。

- **Weave 会关注更多可能出错的地方，并在两次运行之间通知您**。Weave 的检查不使用 AI。每个发现项以及 AI 助手的每个回答都有一个 **Weave 如何得知**面板：对于发现项，显示检查及其背后的值；对于回答，显示助手运行的每个查询，并将每个句子标记为**已匹配**、**未匹配**或**未检查**。请参阅 [Weave 目前检查的内容](/zh-cn/guides/ai-assistant/weave-findings/#weave-目前检查的内容)、[Weave 如何得知](/zh-cn/guides/ai-assistant/weave-findings/#weave-如何得知)和 [AI 助手中的 Weave 如何得知](/zh-cn/guides/ai-assistant/weave-tab/#weave-如何得知)。

  - **表按时写入**。Weave 会报告自其计划到期以来一直未写入的表，或超过您在表详细信息中的**时效性**下设置的新鲜度阈值（1 小时到 180 天）仍未写入的表。
  - **过时或损坏的输入**。Weave 会报告读取了另一个工作流此后已写入的表的工作流，以及所有依赖于失败运行的工作流和仪表板，包括图表基于 SQL 数据集构建的仪表板。**同步依赖项**会补上步骤与其所读取的表之间缺少的连接器。请参阅[同步依赖项](/zh-cn/guides/workflows/sync-dependencies/)。
  - **形态发生变化的数据**。Weave 会报告运行后值的分布大幅变化的小数列、开始重复写入行的联接、Extract 步骤因无法转换为列的类型而留空的值，以及未找到任何文件的导入。它还会报告最新期间与通常情况相差很大的指标，并指出导致这一情况的项。Weave 会考虑月末和工作日的规律，因此月末总是较重的加载不会被报告。请参阅[异常的指标总计](/zh-cn/guides/ai-assistant/weave-metric-insights/)。
  - **变慢的运行**。Weave 会指出导致运行变慢的步骤，并报告较新的运行耗时比较早的运行至少长四分之一的工作流，同时指出耗时增长最多的步骤。
  - **在两次运行之间通知**。每小时的检查会通过应用内消息将每个问题通知其所有者一次，页眉中的 **Weave** 按钮会统计您在所有项目中尚未读取的问题数。请参阅[在两次运行之间获得通知](/zh-cn/guides/ai-assistant/weave-findings/#两次运行之间收到通知)和[页眉中的 Weave 按钮](/zh-cn/guides/ai-assistant/weave-tab/#标题栏中的-weave-按钮)。
  - **所有者、评论和预期的警告**。每个发现项都有一个所有者，默认为最后运行其工作流的人。**分配**可将其转交他人，评论用于记录进展，**团队**视图显示谁负责什么。架构师可以将警告标记为**此为预期**，并附上原因和结束日期。请参阅[为发现项指定所有者](/zh-cn/guides/ai-assistant/weave-tab/#为发现项指定负责人)和[将发现项标记为预期](/zh-cn/guides/ai-assistant/weave-tab/#将发现项标记为预期)。

- **修复助手会解释错误，在卡片上提出供您批准的更改，重新运行该步骤，并可撤消修复**。对于最常见的失败，例如表中不存在的列、必填设置为空、数据库无法读取的 SQL 或类型错误的值，第一条回复会解释常见原因和修复方法。提出的更改以卡片形式显示，说明该步骤失败的原因，并逐项显示每个更改的设置：当前值为红色，新值为绿色。**批准**会应用更改，之后助手会提议重新运行该步骤，并诊断新出现的失败。**Weave** 选项卡中发现项上的**修复**会针对该问题打开助手。**撤消**会恢复该步骤此前的设置，**撤消并运行**则会重建其输出。请参阅[使用 AI 修复工作流错误](/zh-cn/guides/ai-assistant/fixing-workflow-errors/)、[使用 AI 助手修复发现项](/zh-cn/guides/ai-assistant/weave-tab/#使用-ai-助手修复发现项)和[撤消修复](/zh-cn/guides/ai-assistant/fixing-workflow-errors/#撤消修复)。

- **查看 Weave 在项目中所做的一切，并导出给审计人员**。项目 **Weave** 选项卡上的**活动**会列出 Weave 发现过并随后不再发现的问题、AI 助手提出的每项更改、谁提出请求、谁批准或拒绝、它具体替换和写入了什么，以及最终结果。Weave 会在进行更改之前记录您的批准，并且不会进行无法记录的更改。**导出 CSV** 或**导出 PDF** 会将某个期间保存为审计证据，条目无法编辑或删除。**摘要**一览显示一个月的情况：发现并解决的问题、已批准的更改以及其中被撤消的数量。工作区管理员可通过**工作区摘要…** 查看所有项目的同样信息。请参阅 [Weave 活动历史记录](/zh-cn/guides/ai-assistant/weave-activity/)和 [Weave 月度摘要](/zh-cn/guides/ai-assistant/weave-monthly-summary/)。

- **在保存之前，了解步骤的作用以及更改它会影响什么**。所有这些都根据您项目已保存的设置构建，不涉及 AI，并且您的角色所隐藏的任何内容只计数，绝不显示名称。

  - **每个步骤和工作流的文档，以及每个表的列**。详细信息面板中的**文档**部分会描述步骤的作用以及工作流中各步骤的顺序，Weave 和 AI 助手还可以获知读取和写入某个表的内容。表的详细信息面板会列出其**列**及其类型和描述。**下载交接包**会将整个项目保存为一份文档，其中包括指标定义和分摊模型。请参阅[表、步骤和工作流的文档](/zh-cn/guides/ai-assistant/weave-documentation/)。
  - **更改会影响什么**。在**保存**上方，Weave 会说明有多少个下游步骤读取该步骤所写入的内容，例如“对此步骤的更改会影响 2 个工作流中的 8 个下游步骤”，**显示步骤**会列出这些步骤。请参阅[更改会影响什么](/zh-cn/guides/ai-assistant/impact-preview/)。
  - **保存会拒绝什么**。在**保存**上方有一个条带，会在您编辑时运行该步骤的检查，每个问题旁有**转到**，表达式编辑器会在您输入时检查表达式。请参阅[保存会拒绝什么](/zh-cn/guides/ai-assistant/check-while-you-edit/)。
  - **审查单个工作流**。工作流画布或**步骤**网格上的**检查**会对其运行 Weave 的检查，以及分摊和行级安全检查。请参阅[审查单个工作流](/zh-cn/guides/ai-assistant/weave-findings/#审核单个工作流)。

- **为您的工作区关闭 Weave 的任何 AI 功能**。工作区管理员在页眉的 **Weave** 按钮上选择 **AI 功能…**，即可分别开启或关闭 Weave 聊天、修复助手、导入和导出助手、表达式助手、根据描述生成 SQL、工作流审查摘要或入门图表。在管理员关闭之前，所有功能均为开启状态；Weave 的检查和发现项始终保持开启，每项更改都会记录在安全日志中。请参阅 [AI 功能](/zh-cn/guides/ai-assistant/weave-ai-features/)。

- **更直接地排列和编辑高级工作流画布**。按住 **Cmd** 或 **Ctrl** 并拖动步骤，即可将其拖入或拖出容器，并可从执行容器的**出口端口**连接其输出。**排列**菜单可整理、对齐、分布和吸附步骤，同时保持您的顺序并让备注随其步骤一起移动，每次操作都可作为一次**撤消**。右键单击空白处，可在您单击的位置复制和粘贴步骤。所选步骤上的**创建步骤**会从其写入的表开始创建联接或提取，有未保存更改的窗口在放弃更改前会先询问。步骤的输入或输出上的眼睛图标会打开恰好是该表的预览。请参阅[容器](/zh-cn/guides/workflows/advanced-workflows/#容器)、[排列画布](/zh-cn/guides/workflows/advanced-workflows/#排列画布)、[在高级画布上复制和粘贴](/zh-cn/guides/workflows/copy-paste-steps/#在高级画布上复制和粘贴)和[创建步骤](/zh-cn/guides/workflows/workflow-explorer/#创建步骤)。

- **优化高级工作流，使其运行更快**。右键单击工作流并选择**优化…**，可在任何更改发生之前先审查更改。**Rebuild dependencies from data lineage** 只将每个步骤连接到其所用表所对应的步骤，因此相互独立的步骤可并行运行，**Merge** 会将一连串 Extract Data 步骤合并为一个，并且只有在两个版本对您当前数据给出完全相同的结果之后才会应用。窗口会显示节省的时间，并列出每个无法优化的步骤及原因，**撤消优化…** 会恢复该工作流。请参阅[优化工作流](/zh-cn/guides/workflows/optimize-a-workflow/)。

- **在运行之前，先确保联接的键正确**。**Join Map** 上的**推测**会先使用联接相同两个表的另一个步骤的键，然后是指标，然后是表的键列，最后是匹配的名称，并说明它使用了哪一种。**检查键**会统计被联接表中重复的键值，这些重复值可能使您的行数成倍增加。当**检查源**填充步骤的列时，诸如 `customer_id` 之类的标识符列最初是**分组依据**而不是**求和**。请参阅[内联接](/zh-cn/reference/workflow-steps/tables/table-inner-join/#检查键)。

- **AI 助手和 Microsoft 365 Copilot 对您的数据了解得更多，也能做更多事**。

  - **每个分析路径和列的指引**。每个分析路径都有**提示指引**（最多 1,000 个字符），用于说明始终适用的筛选条件、财年日历和您的业务术语。列备注会随表的列一起传达给助手和 LLM 步骤，因此代码或标志会按您的本意来理解。请参阅[让路径对 AI 助手有用](/zh-cn/integrations/ai-coding-agents/analysis-paths/#让路径对-ai-助手更有用)。
  - **Copilot 能做更多**。Microsoft 365 Copilot 中的 PlaidCloud 代理可以创建 CSV、Excel、PowerPoint 和 Word 文件，根据您的指标回答业务数字，在整个表上汇总细分，并解释分摊的工作方式。管理员下载更新后的软件包，并在 Teams 管理中心更新。请参阅 [Microsoft 365 Copilot](/zh-cn/integrations/microsoft-365-copilot/)。
  - **一次调用完成更多事**。助手可以在服务器上对表进行分组和汇总（先应用行访问权限），搜索和读取 PlaidCloud 的文档，使用仅可写入的凭据创建完整配置的文档账户（包括 OneDrive 和 SharePoint），除了添加标签也可以移除标签，并处理您在 PlaidCloud 中看到的视图。请参阅[分析路径](/zh-cn/integrations/ai-coding-agents/analysis-paths/#通过-mcp-使用)和 [AI 代理入门](/zh-cn/integrations/ai-coding-agents/getting-started/)。

## 变更

- **Go To Metric 会打开 Weave 发现项所涉及的指标**。它会显示该指标的数字，这些数字在您单击时计算并遵循您自己的行访问权限，同时用 ✓ 标明其所依据的版本。对于异常总计，它是 Weave 所指出的、在其判断的期间内的那一项。对于任何其他指标发现项（包括由其他指标计算得出的指标的发现项），则是该指标的总计。数字下方的**转到行**仍会在表资源管理器中打开变化背后的行。请参阅 [Go To Metric](/zh-cn/guides/ai-assistant/weave-metric-insights/#转到指标)。

- **一个 Weave 选项卡同时容纳您的发现项和 Weave AI 聊天**。聊天是 **Weave** 选项卡中位于**发现项**之后的子选项卡。每个发现项是一张卡片，带有各自的**修复**、**转到**和**标记为已读**按钮，虚线卡片标记 Weave 无法检查的内容，芯片按需要关注的内容筛选列表。关于表达式的发现项会指出错误所在位置，表达式本身位于 **Weave 如何得知**下。运行结束时，Weave 会将每个问题只提及一次，关于同一个项目的消息会合并为一条而不是堆叠。在大型项目中，该选项卡打开很快，因为 Weave 只重新检查已更改的内容。工作流列表中的 Weave 列已移除。请参阅 [Weave 选项卡](/zh-cn/guides/ai-assistant/weave-tab/)和[在运行结束时获得通知](/zh-cn/guides/ai-assistant/weave-findings/#运行结束时收到通知)。

- **Ctrl/Cmd-K 可在任何屏幕上打开命令面板**。在您输入之前，它会列出您最近打开的内容和您可以执行的操作：转到主页、项目、仪表板或文档，在浅色和深色之间切换，连接您的 AI，或获取帮助。输入内容会缩小这两个列表的范围，从输入两个字符起，它还会搜索项目、工作流、表、仪表板和 Panel 应用。请参阅[搜索和命令](/zh-cn/guides/launcher/#搜索和命令)。

- **步骤会在保存时而不是运行时发现问题**。保存其设置会导致运行失败或给出错误结果的步骤时，保存会被拒绝，并附有说明应更改什么的消息。每个步骤的参考页面都列出了它检查的内容。步骤或其源表中已不存在的映射源列会以红色标记，保存时会打开一个对话框，其中有**全部移除并保存**、**仍然保存**或**取消**。联接、查找和空间步骤会保留这样的行，而不是自行删除。使用未定义变量的表达式会指出该变量的名称，运行时被拒绝的步骤会用通俗的语言解释原因。请参阅[不再列出的源列](/zh-cn/reference/workflow-steps/tables/table-extract/#不再列出的源列)、[源表中缺少的列](/zh-cn/reference/workflow-steps/tables/table-extract/#源表中缺少的列)和[管理步骤错误](/zh-cn/guides/workflows/managing-step-errors/)。

- **缺少或为空的来源绝不是错误**。文件缺失或为空的文件导入会以警告结束，警告中指明路径，并将其目标表保留为空且带有其声明的列，因此后续步骤读取到零行。针对缺失或空文件夹的文档步骤会报告“没有可处理的内容”，工作流继续运行。远程文件步骤在路径缺失时发出警告，并拒绝不安全的路径。对缺失文件的检查适用于 OneDrive、SharePoint 和 SFTP。批次表为空的**报表：批量生成**会以警告结束，并且不生成任何报表。请参阅[导入步骤](/zh-cn/reference/workflow-steps/import/)、[文档工作流步骤](/zh-cn/reference/workflow-steps/document/)和[文档路径条件](/zh-cn/guides/workflows/step-conditions/#文档路径条件)。

- **大型工作流运行可靠，且停止可取消导入和导出**。当 PlaidCloud 繁忙时，步骤会等待容量而不是失败，并且会随着步骤排队而增加容量。Import External Database Tables 一次最多运行 10 个表。如果运行某个步骤的服务器丢失，替换其输出的步骤会自动重新运行，无法安全重复的步骤则会失败一次并显示*中断*消息。**停止**会取消正在运行的导入和导出作业，已停止的运行会报告为“已停止”。请参阅[中断的步骤](/zh-cn/guides/workflows/run-a-workflow/#已中断的步骤)和[暂停、停止和恢复](/zh-cn/guides/workflows/run-a-workflow/#暂停停止和恢复)。

- **每个 Lakehouse 的存储和计算方式都相同**。来自导入 CSV、导入 XML 或 Import Table Archive 的空字段会作为 null 加载，因此之后测试 `= ''` 或 `= 0` 的步骤需要改为测试 null。`cast(x, Float)` 在所有地方都是 64 位，因此大额金额会保留其全部数字，PlaidCloud 创建的 Float 列为双精度。JSON 列、**Table: Delete Rows** 和聚合条件在每个 Lakehouse 上都可使用。自行构建结果的步骤（例如求解器、预测，以及在 pandas 中运行的透视和分摊拆分）会将结果作为带类型的数据加载，速度快得多。表资源管理器会显示数值列的最小值、最大值、平均值、总和、标准差和方差。请参阅[转换为 Float](/zh-cn/reference/workflow-steps/common/advanced-data-mapper-usage/#转换为-float)和[列数据和唯一值计数](/zh-cn/guides/data/table-explorer/#列数据和唯一值计数)。

- **文件导出会保留类型**。Parquet 文件会将整数列保持为整数，以微秒存储时间戳，并将时区标记为 UTC。Avro 文件会保持日期、时间戳和布尔值的类型，单表 Avro 导出以该导出命名。为 Parquet 导出选择多个文件时会停止并提示 Parquet 只写入单个文件。非常大的 Parquet、ORC 和 JSON 导出会在读取行的同时写入，因此不再耗尽内存，并且 Parquet 会使用您选择的压缩方式。版本为 1.2.33 或更高的 PlaidLink 代理会以 Parquet 文件接收导出的表。请参阅 [Export to Parquet](/zh-cn/reference/workflow-steps/export/export-to-parquet/)、[Export to Avro](/zh-cn/reference/workflow-steps/export/export-to-avro/) 和[数据如何到达代理](/zh-cn/reference/workflow-steps/agent/agent-remote-import-table-into-sql-database/#数据如何到达代理)。

- **ERP 过账遵循每个计划的模式，不确定的回复会被搁置以供您检查**。计划事件保留其自己的过账模式（**实时**、**模拟**或**关闭**），并受项目设置的上限约束，**运行所选事件**使用每个事件各自的模式。PlaidCloud 无法确认的 ERP 回复（例如超时或服务器错误）会被标为存疑而不是记录为被拒绝，并且过账不能被冲销两次。过账登记簿会列出 **reversal outstanding** 过账，架构师在项目主页上的 **ERP 写入授权**中授权项目过账。请参阅 [ERP过账模式](/zh-cn/administration/scheduled-events/event-scheduler/#erp过账模式)、[冲销](/zh-cn/guides/connections/posting-register/#冲销)和[授权项目过账](/zh-cn/guides/workflows/run-a-workflow/#授权项目过账)。

- **行访问会跟上分组变更，并说明问题所在**。单点登录在某人登录时设置的分组成员资格会在约 15 分钟内传达到仪表板行访问，默认分组的新成员会在约一分钟内获得其行。行访问窗口会在某个限制没有筛掉任何内容时发出警告，能处理包含 `&`、`/` 或 `%` 的列名，并在同步失败时显示**错误**及原因，或显示**正在重试**以及一个**重试**按钮。请参阅[保持仪表板同步](/zh-cn/administration/access/managing-security-groups-and-assignments/#保持仪表板同步)。

- **用户定义函数现在在 Python 3.14 上运行，并使用更新的库**。大多数函数无需更改即可运行。导入 numba 或 Python 已移除的标准库模块（例如 `cgi` 或 `telnetlib`）的函数现在会失败，需要重写。预测的 AutoTheta 边界可能与之前的运行略有不同。请参阅 [User Defined Transform](/zh-cn/reference/workflow-steps/general/user-defined-transform/)。

- **完整代理访问已弃用，将于 2027 年 1 月 15 日移除**。使用**完整**访问的 LLM 步骤会记录警告。请改用**读取和写入**，此时代理通过 PlaidCloud 的写入工具更改数据，LLM 步骤只写入勾选了**写入**的绑定。请参阅[代理访问](/zh-cn/integrations/ai-architecture/llm-providers/#代理访问)。

- **文档账户更易于设置和浏览**。OneDrive 或 SharePoint 账户的文件浏览器会打开其起始路径下的文件夹。Google Cloud Storage 账户需要有效的服务账户密钥，没有该密钥的现有账户在您添加之前将无法工作。被拒绝的设置会自行说明原因，未使用的备份图标已从**管理账户**中移除。请参阅[添加 Google Cloud Storage 账户](/zh-cn/guides/documents/adding-accounts/add-google-cloud-storage-account/)和[备份文档账户](/zh-cn/guides/documents/account-management/managing-document-account-backups/)。

- **Project 应用对发票、行程和补报工时的处理更完整**。新发票从主项目开始，由主项目提供客户和采购订单号。删除草稿发票会使其工时和行程重新变为可计费，**AR 收件人**设置提交发票时向谁发送电子邮件。行程抽屉会显示每一行的供应商、类别和审核状态，**添加补报工时**会为已批准的一周创建工时表。请参阅[使用 Project 应用跟踪工时和费用](/zh-cn/guides/time-expense/track-time-and-expenses/)。

- **已移除会删除所有未被任何步骤引用的表的 API 调用**。请改为按 ID 删除表。

- **应用各处的小幅变更**。在账户、仪表板、成员、分组或设置列表中双击某一行即可将其打开。空的**维度**、**数据编辑器**、**UDF** 和**步骤**选项卡会说明下一步该做什么，没有应用的成员会进入启动器。步骤的表选择器会显示表最后一次更新的时间（[查看源表上次更改的时间](/zh-cn/guides/workflows/create-workflow/#查看源表最后一次更改的时间)）。Export External Database Tables 在自己的选项卡上映射列，**报表：批量生成**不再显示未使用的 **Report Constants** 部分。Convert Encoding 步骤可识别中欧、土耳其和阿拉伯编码。指向已移除屏幕的链接会说明这一点。

## 修复

- **AI 助手在您批准之前不会更改任何内容，并按原样显示名称**。此前将步骤构建到新表中时，会在您批准之前就创建该表；现在表和步骤会在您批准后一起创建，创建项目、工作流或维度、复制表以及更改表属性或标签也都会先征求您的同意。批准仅在您的下一条回复中有效。助手提出的导入或导出会按名称显示其表、文档账户和工作流，并且绝不会与不存在或您无法打开的项一起提供。带下划线的名称会按原样显示，而不会变成斜体，表和代码在深色主题下可读，图表会绘制出来而不是显示为文本，表达式编辑器的 Weave 面板会读取您正在编辑的表达式。即使某个表没有名称，助手也会列出项目的表；即使某个步骤读取或写入多个表，助手也会回答哪些步骤读取或写入某个表，而不会因错误而停止。请参阅[构建工作流步骤](/zh-cn/guides/ai-assistant/weave-tab/#构建工作流步骤)。

- **文件导入会读取您所指向的内容**。导入 Excel 可读取整列范围和 XLSB 工作簿，可在压缩的工作簿中找到工作表，并且不再因带有填充或换行符的标题而失败。导入 CSV 遵循**跳过行数**，因此标题上方有若干行的文件（例如 SAP 列表导出）可按列名导入，并且可使用默认的分隔符、引号和转义字符运行。一个源列可以为多个目标列提供数据，所有列都是固定值的导入会加载每一行，使用大写压缩扩展名命名的文件会被解压，未变化时跳过的导入会重新加载被清空的表。要求 AI 助手从**项目默认值**导入文件时，会读取项目的默认文档账户，并在项目未设置时明确告知您。带有较新列类型的 Parquet 文件可在文档中打开。请参阅[导入 Excel](/zh-cn/reference/workflow-steps/import/import-excel/#读取内容)和[导入 CSV](/zh-cn/reference/workflow-steps/import/import-csv/#行选择)。

- **工作流步骤会按配置保存和运行**。表：Upsert 步骤重新可以保存，其**更新键**列也已恢复。表：项目间复制会指定其目标项目并通过数据共享读取。文档：将仪表板保存为 PDF 会保留其列类型，表：去重合并和表：全部合并按名称匹配列。多表联接可在有多个输入时保存，并接受带空格的列名。Table Lookup 会忽略其查找列上的聚合设置，SCD-2 截至日期联接可将变量作为其日期。LLM 步骤可在早于 4.6 的 Claude 模型上运行，并在 AI 助手编辑它们时保留其模型。REST 请求发送的行值只编码一次，导出到远程数据库会提交其行。请参阅[更新键](/zh-cn/reference/workflow-steps/tables/table-upsert/#更新键)、[数据共享管理](/zh-cn/reference/workflow-steps/tables/frame-project-copy/#数据共享管理)和[多表联接](/zh-cn/reference/workflow-steps/tables/table-multi-table-join/)。选择工作流的步骤（例如 Workflow Delete、Copy、Rename 和 Stop）会保留已不存在的工作流，显示为 *id（缺失）*，而不是切换到列表中的第一个工作流。

- **工作流运行会按预期完成**。Workflow Loop 会在每次迭代时运行循环的工作流，迭代容器和在一次运行中多次运行的工作流也是如此。从某个步骤或并行组内部开始的运行会运行正确的步骤并完成。长时间运行的导入或导出绝不会被启动两次，不会在 PlaidCloud 更新期间停滞，并且以服务器错误结束的操作不会被再次发送。数据库驱动程序崩溃只会使其自己的步骤失败，并附上数据库给出的原因。运行历史记录会统计每个步骤的行数，在工作开始之前就失败的步骤会将原因写入工作流日志。请参阅 [Workflow Loop](/zh-cn/reference/workflow-steps/workflow-control/workflow-loop/) 和[运行历史记录](/zh-cn/guides/workflows/advanced-workflows/#运行历史)。

- **项目的复制、导入和打开不再出现意外**。项目导入会保留它能够还原的所有内容，并在**导入结果**窗口中列出遗漏的内容，显示其进度，说明失败的原因，并且可以重试。当项目有变量时，复制选定对象也能正常工作。打开项目不再更改其设置，**导入您自己的数据**会导入您的 CSV，在 PostgreSQL 仓库上创建表也能正常工作。App Runner 应用会在 PlaidCloud 更新时自行刷新，并对限制行的项目上的查看者正常工作。请参阅[归档的一部分未能导入时](/zh-cn/guides/projects/archive-a-project/#归档的部分内容未能导入时)和[保持应用为最新](/zh-cn/guides/workflows/use-converted-alteryx-apps/#保持应用为最新)。

- **维度和分摊的加载与读取正确**。父子加载会将父级为空的行保留为顶层成员，对于第二个备用层次结构，在每种加载中都会拒绝主层次结构之外的成员。将成员移到其层次结构不包含的父级之下会被拒绝，维度步骤会指出它找不到的维度，粘贴含有空白的列会让每个值保持在其所在行。读取大型维度不再拖慢工作区中的其他所有人。维度属性将**层次结构**保留为**未指定**的分摊规则可以运行。请参阅[加载到备用层次结构](/zh-cn/reference/workflow-steps/dimensions/dimension-load/#加载到备用层次结构)和[维度类型属性和成员选取器](/zh-cn/guides/dimensions/dimensions/#维度类型属性和成员选取器)。

- **工作流画布和各屏幕表现正常**。**钻取到工作流**会在画布上打开高级工作流，画布可以打开每个工作流，并在布局的某一部分无法读取时告知您。放不下的工具栏按钮会移入**更多**菜单，列表在您保存后立即更新。通知会显示其完整消息，警告会在**日志**选项卡中显示警告图标，表资源管理器会在某列的概要分析失败时说明，数据编辑器会让空的日期单元格保持为空。在开启列筛选器的情况下保存数据编辑器，会保留筛选器隐藏的行，包括在您添加、删除或移动行之后。任何有权更改用户定义函数的人，打开其编辑器时均可编辑。请参阅[画布无法打开工作流时](/zh-cn/guides/workflows/advanced-workflows/#画布无法打开工作流时)。从**表**列表中删除表时，会列出仅通过变量路径（例如 `/Periods/{period}/Sales`）访问某个表的所有步骤，并且只有在您强制时才会删除该表。请参阅[删除](/zh-cn/guides/projects/managing-tables-and-views/#删除)。

- **成员和连接按预期工作**。**添加工作区成员**适用于已有账户的人（包括通过单点登录创建的账户），并且绝不会降低其已有的项目角色。ODBC 连接通过 PlaidLink 代理所在机器上的 DSN 或驱动程序进行连接。拒绝您的 OAuth 凭据的提供商会告诉您重新输入或重新授权，Databricks 采样和导出会刷新即将过期的令牌，较旧数据库类型的连接可以删除。**使用位置**包含通知步骤，免费工作区保留每日、每周和每月备份。请参阅[成员管理](/zh-cn/administration/access/member-management/)和 [ODBC](/zh-cn/reference/connectors/databases/odbc/)。

- **REST API 和 AI 助手工具会完全按您的要求执行**。对成员、分组或计划事件的部分更新只会更改您指定的字段，因此暂停的事件会保持暂停。从指定步骤开始运行会从该步骤开始，还原表快照会保留一个安全快照和一条审计记录。AI 工具的动因假设分析只在与您的模型实际所做的拆分一致时才会回答。过去以服务器错误失败的请求现在要么可以正常工作，要么会说明错误所在。请参阅[追踪分摊](/zh-cn/integrations/ai-coding-agents/tracing-allocations/)和[还原或恢复快照](/zh-cn/guides/data/table-snapshots/#回退或还原快照)。

## 安全

- **AI 助手始终在您的权限范围内**。助手的数据查询在运行前会按其结构进行检查，并且只会运行单条读取查询。只读 AI 连接（包括 Microsoft 365 Copilot）无法导出文件、保存仪表板 PDF、将行复制到另一个项目，或通过 REST 连接发送更改。通过 AI 助手进行的导入会以您的身份在您指定的项目中运行，并且对话只能由发起对话的人继续。助手和表引用会省略您的角色所隐藏的表、步骤、工作流和维度，Weave 会统计您无法打开的失败步骤，而不是列出其名称。请参阅[访问级别](/zh-cn/integrations/microsoft-365-copilot/#访问级别)、[您的角色所隐藏的内容](/zh-cn/guides/ai-assistant/weave-tab/#您的角色隐藏的内容)和[管理过往对话](/zh-cn/guides/ai-assistant/weave-tab/#管理过往对话)。

- **ERP 过账无法绕过其控制措施**。启用职责分离后，冲销会经过过账登记簿，并在其中适用审批。复制或导入的项目不再继承过账权限，SAP 和 EBS 过账不能直接发送给代理，测试模式下的 SAP Post 步骤需要与实际过账相同的权限。一个无需这些检查就能向 Sage Intacct 过账的未公开端点已被移除。ERP 和 REST 连接的错误消息不再包含凭据。请参阅[职责分离](/zh-cn/guides/connections/posting-register/#职责分离)。

- **机密仅可写入，只有所有者才能决定谁使用连接**。文档账户的密钥、密码和令牌一经保存便不再显示，更改账户的连接位置需要再次提供该机密。步骤中的密码和密钥只存在于变量中；已输入到步骤中的机密已被移入仅架构师可见的项目变量。多行凭据在您输入时会被屏蔽。只有连接的所有者或工作区管理员才能更改谁有权访问它。请参阅[保存的机密仅可写入](/zh-cn/guides/documents/adding-accounts/#已保存的机密为只写)、[密钥保存在变量中](/zh-cn/reference/workflow-steps/document/encrypt-decrypt-file/#密钥存放在变量中)和[创建和管理连接](/zh-cn/guides/connections/create-connection/#安全模型)。

- **您无法使用的文档账户对您保持关闭**。检查文件是否存在、读取 Parquet、Avro、ORC 或 Delta 文件的列、使用**填充**填充导入步骤的列，以及 AI 助手的文件检查，现在都会拒绝您无权访问的账户，就像浏览该账户时一样。

- **只有工作区管理员才能更改工作区管理员**。编辑、停用或删除管理员、更改其分组，以及将某人设为管理员，都需要工作区管理员。请参阅[更改工作区管理员](/zh-cn/administration/access/member-management/#更改工作区管理员)。

- **数据共享仅代表其被授予的项目的成员**。通过共享读取需要在接收项目中拥有角色，写入则需要**写入**共享以及在该项目中拥有管理者或架构师角色。请参阅[在项目之间共享数据](/zh-cn/guides/projects/managing-projects/#在项目之间共享数据)。

- **还原仅适用于所指定的项**。还原较早的版本会还原该项本身，并且权限检查针对该项。其内容不属于自身标头中所列维度的维度备份文件会被拒绝。请参阅[版本历史记录](/zh-cn/guides/projects/managing-projects/#版本历史)。

- **模板、导入和归档会拒绝不安全的内容**。导出模板和报表模板在沙盒中渲染，只读取提供给它们的数据。导入根据其自身设置构建加载查询，包含 PlaidCloud 归档从不包含的内容的项目归档会被拒绝，会与另一个项目共享报表架构的项目标识符会被拒绝。请参阅[模板可以使用什么](/zh-cn/reference/workflow-steps/export/export-templated/#模板可以使用的内容)和[还原归档](/zh-cn/guides/projects/archive-a-project/#还原归档)。

- **仪表板遵循 PlaidCloud 登录和您的行访问权限**。仪表板的缩略图以您的身份渲染，账户仅来自 PlaidCloud 登录，仪表板只能从导出所生成的 ZIP 文件导入。请参阅[导入现有仪表板](/zh-cn/guides/dashboards/learning-dashboard/#导入现有仪表板)。

- **启动工作流运行不再返回该运行的凭据**。

- **运行用户定义函数的环境不再包含 PySpark 的 Java 库**，这些库存在已知漏洞。PySpark 的 DataFrame 和 SQL API 仍可连接到您的 Spark 计算集群，但导入 `SparkContext` 或 `RDD` 的函数现在会失败。请参阅 [PySpark 入门](/zh-cn/integrations/pyspark/getting-started/)。

- **附件、还原和转换只读取您可以使用的账户**。通过电子邮件发送文件、从文件还原维度或表归档、检查或导入表包、从模板填充 Excel 导出，以及转换 Alteryx 工作流，现在都会拒绝您无权访问的文档账户。将维度备份到文档账户需要对其具有写入权限。工作流步骤不受影响，但通过电子邮件发送文件、还原表或填充 Excel 模板的步骤不能再从 Personal Temp Drive 读取。

- **导出只保存到您可以写入的账户**。以任何格式将表或查询导出为文件、导出表归档、项目归档或表包、从项目创建本地 Python 工作流、将 REST 响应另存为文件，以及转换 Alteryx 或 Prophecy 工作流，现在都需要对其所保存到的文档账户具有写入权限。导出查询时现在还会检查您是否可以使用其所属的项目。表包导入不再将其导入日志写入您只有读取权限的账户。工作流中的导出步骤不受影响，但它们不能再保存到 Personal Temp Drive。
