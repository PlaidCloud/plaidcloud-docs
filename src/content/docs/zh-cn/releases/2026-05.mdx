## 新增

- **个人临时驱动器** — 每位工作区成员现在都拥有由托管云存储支持的私有、按用户划分的临时空间。已在图表级别默认启用；无需管理员操作即可开始使用。
- **通过 Stripe 自助注册** — 新账户现在可以直接通过 plaidcloud.com 注册，无需销售介入。注册流程已接入控制平面，用于租户配置。
- **MCP 集成端点** — `/mcp` 和 `/.well-known/oauth-*` 路由现在会路由到 PlaidCloud RPC 服务器，使 AI 编码代理（Claude Code、Cursor、Copilot、ChatGPT、Gemini）能够通过 Model Context Protocol 连接。请参阅 [AI 编码代理](/zh-cn/integrations/ai-coding-agents/)。
- **Lakehouse v2 迁移工具** — 将工作区从 Lakehouse v1（Databend）迁移到 Lakehouse v2（StarRocks）的迁移器服务，现已部署到整个集群，为分阶段的租户迁移做准备。

## 变更

- **应用界面整合到 qooxdoo** — `app.<your-domain>` 现在直接提供 qooxdoo 客户端。旧版 cp-frontend 已弃用；使用指向旧路径书签的用户将被透明地重定向。
- **旧版网址自动重定向** — 访问 `/signin` 及相关旧版路径时，现在会以 301 重定向到新的 `/client/` 界面。可在方便时更新书签，但旧链接仍可继续使用。
- **工作流运行历史** — 现在会按租户记录更多的运行历史元数据，使工作流日志呈现更多细节。

## 安全

- **WAF 已更换** — 边界 Web 应用防火墙已更换为维护更积极的替代方案，已放行的流量不受影响。
