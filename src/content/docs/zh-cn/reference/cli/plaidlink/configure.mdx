PlaidLink 代理与 PlaidCloud 服务协同工作。PlaidLink 代理提供与无法直接访问的系统（如数据库和文件系统）进行操作所需的连接。
代理会执行多项关键操作，包括：

* 读取和写入数据库
* 读取和写入网络驱动器和服务器上的文件
* 检查传感器条件
* 通过远程函数调用（RFC）与 SAP ECC 和 SAP S/4HANA 交互
* 与 SAP Profitability and Cost Management（PCM）交互
* 向远程系统发送消息和通知

## 在 PlaidCloud 上创建代理

PlaidLink 代理的管理在 PlaidCloud 的 Analyze 选项卡中进行。第一步是在 PlaidCloud 上创建新的 PlaidLink 代理实例。

### 创建新的 PlaidLink 代理

1. 选择 Analyze 选项卡
2. 选择顶部的工具菜单
3. 单击 PlaidLink 代理
4. 创建一个新代理，并使用与将要安装它以进行远程操作的环境或服务器相符的名称

### 查看代理的公钥和私钥

1. 单击编辑图标以查看表单
2. 在表单底部，可以看到创建代理过程中随机生成的公钥和私钥

私钥仅对可编辑代理的成员显示。

<Aside>请记住这些密钥，它们将用于远程服务器上的代理配置。</Aside>

### 随机生成新密钥

1. 单击代理记录的重新生成图标
2. 密钥重新生成后，别忘了在远程服务器上使用新密钥更新代理配置文件。

<Aside>请保留公钥和私钥，以便在下一步配置远程代理时使用。</Aside>

## 文档账户访问

如果代理需要访问文档账户以上传或下载文件，则必须授予其访问该文档账户的权限。

### 授予账户访问权限

1. 在文档中，选择导航栏中的**管理**
2. 出现账户表后，单击新代理应具有上传/下载权限的账户的代理图标
3. 将新代理拖到已分配的代理列中
4. 保存访问控制表单。

<Aside>只有在代理已被授予一个或多个文档账户的访问权限时，代理才能上传和下载文件。</Aside>

## 数据连接访问

如果代理需要访问数据库等数据连接，则必须授予其访问外部数据连接信息的权限。


### 授予连接访问权限


1. 在 Analyze 选项卡中选择工具菜单
2. 单击外部数据连接
3. 出现数据连接表后，单击新代理应具有使用权限的连接的代理图标
4. 将新代理拖到已分配的代理列中，并保存访问控制表单。

<Aside>代理的数据连接凭据在外部数据连接中管理。</Aside>
