## 下载代理

在 [PlaidCloud.com](https://plaidcloud.com/) 的发布页面中查找 **PlaidLink**

## 解压代理

将下载的 zip 文件解压到您选择的安装位置。通常该位置为：

```bash
C:\Users\<Username here>\src\plaidlink
```

## 创建配置文件

<Aside>如果您是从旧版本的代理升级，原有配置文件仍然有效，可以跳过此步骤</Aside>

将代理目录中的 `config-dist.yaml` 文件复制到 `%ProgramData\plaidcloud\`，并将该副本重命名为 `config.yaml`

*（使用从 PlaidCloud 获取的值编辑此配置）*

## 安装代理服务

运行代理安装目录中的 `install_windows_service.bat` 文件，或者

在管理员命令提示符中，进入代理的安装目录并运行：

```bash
.\PlaidLink.exe install
```

## 运行代理

<Aside>安装 Windows 服务需要管理员权限</Aside>

在 Windows 搜索栏中输入 **`Services`**，打开服务管理器。在服务列表中找到 **`PlaidCloud Agent`**。

右键单击该服务并选择 **“启动”** 以启动代理。

## 冻结更新

如果想随时禁用代理的自动更新功能，请打开代理的 **'yaml'** 配置文件，在文件根级别添加一行 `freeze_updates: true`，然后重启代理服务。

<Aside type="caution">不建议长期禁用自动更新</Aside>
