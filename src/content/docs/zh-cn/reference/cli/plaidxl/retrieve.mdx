[登录](/zh-cn/reference/cli/plaidxl/connect/)后，任务窗格会列出您的项目。先选择项目，再将其表和维度检索到工作簿中。

## 选择项目

任务窗格的标题栏显示您的工作区以及此工作簿所关联的项目。单击项目名称可打开项目列表，其中显示您可以打开的所有项目，文件夹结构与您在 PlaidCloud 中看到的相同。文件夹默认折叠；单击可展开，或在 **Filter projects by name** 中输入内容以缩小列表范围。

单击某个项目即可选中。其表显示在 **Tables** 选项卡上，其维度显示在 **Dimensions** 选项卡上。

### 项目属于工作簿

所选项目保存在工作簿中，因此每个工作簿都有自己的项目。它是该工作簿中 PlaidXL [自定义函数](/zh-cn/reference/cli/plaidxl/functions/)和钻取命令所读取的项目。打开两个工作簿，各自读取自己的项目；重新打开工作簿时，任务窗格会回到其项目。该项目会随文件传递给打开文件并以有权访问该项目的身份登录的任何人。

一个项目只属于一个工作区。如果您[切换工作区](/zh-cn/reference/cli/plaidxl/connect/#退出登录或切换工作区)，链接到旧工作区中某个项目的工作簿在您重新选择之前将没有项目。从旧工作区检索的表会保留在工作簿中，但会被 **Refresh All Tables** 跳过，任务窗格会告知您跳过了多少个。请在新工作区中重新检索它们以建立关联。

## 检索表

1. 在 **Tables** 选项卡上，单击某个表。在较长的列表中，可使用 **Filter tables by name** 查找。每个表旁边的 **Rows** 和 **Columns** 显示其大小。
2. 在 **Column** 下，清除不需要的列的复选框。所有列默认处于选中状态。
3. 如果只检索部分行，请选择 **Advanced** 并构建筛选器。参见[筛选行](#筛选行)。
4. 在 **Select where to place this table** 下，选择：
   - **Matching Worksheet** — 以表命名的工作表。如果该工作表不存在，PlaidXL 会创建它；如果已存在，则从单元格 A1 开始写入表。
   - **Current Selection** — 从您在活动工作表上选中的单元格开始。
5. 单击 **Retrieve Table**。

数据会连同标题行一起到达，可立即使用。标题行为粗体并带有底纹，列宽自动适应内容，并且已启用筛选。检索到 **Matching Worksheet** 的表还会获得：

- 冻结的标题行，滚动时始终可见。
- 覆盖数据的命名区域，因此使用它的公式会在刷新时随数据增长而变化。其名称是工作表名称前加一个下划线：名为 **Sample data** 的表位于工作表 `Sample_data` 上，命名区域为 `_Sample_data`。

为工作表命名时，PlaidXL 会将表名截断到 Excel 的 31 个字符上限，仅保留普通字母（A–Z）、数字和空格，并将空格转换为下划线。名为 **Q3 Revenue (EMEA)** 的表会检索到工作表 `Q3_Revenue_EMEA`。下划线和带重音的字母也会被去掉，因此 **sales_2024** 会检索到工作表 `sales2024`。

<Aside type="tip">宽表加载到 Excel 中较慢。清除不需要的列是加快大型检索最快的方法。</Aside>

### 以红色显示的表

当表对工作表来说太大（超过 1,048,576 行或 16,384 列），或者 PlaidCloud 无法报告其大小（例如从未加载过的表）时，该表会以红色显示。请使用 **Advanced** 筛选行并清除列，直到它能放得下为止。PlaidXL 最多检索 1,048,575 行外加标题行，到此为止，且不会发出警告。

## 筛选行

选择 **Advanced** 以打开筛选器生成器。每条规则选取一列、一个比较方式（例如 **equal**、**in**、**contains**、**begins with** 或 **is empty**）和一个值。使用 **AND** 组、**OR** 组或两者来组合规则。

筛选器将值作为文本进行比较，因此可匹配精确值和文本模式。不提供数字或日期范围；若要检索某个范围，请使用 **in** 对所需的值进行筛选，或检索该表后在 Excel 中筛选。

- 输入值时不带引号：`EMEA`，而不是 `"EMEA"`。
- 对于接受多个值的比较（例如 **in**），请用逗号加空格分隔各值：`EMEA, APAC, NA`。

筛选器仅在选中 **Advanced** 时才应用。PlaidXL 会记住每个已检索表所用的筛选器和您选择的列，并在刷新时再次使用。

## Refresh All Tables

**Refresh All Tables**（在任务窗格中，或在功能区的 **PlaidCloud → Data** 下）会按您为每个表所选的列和筛选器，从 PlaidCloud 拉取您已检索到工作簿中的每个表的当前数据。

运行期间，每个表的工作表标签会变为黄色。该表更新完毕后变为绿色。使用这些数据的公式会照常重新计算；基于这些数据构建的数据透视表，请使用 Excel 的**数据 → 全部刷新**来刷新。

PlaidXL 会将已检索表的列表保存在工作簿中，因此任何打开该文件并以有权访问相同项目的身份登录的人，都可以使用 **Refresh All Tables**。

每次 **Retrieve Table** 都会将该表添加到刷新列表，且无法移除其中任何一项。请对每个表只检索一次，然后使用 **Refresh All Tables** 更新它；重复检索同一个表会使每次刷新都拉取它两次。

<Aside type="caution">
检索到 **Current Selection** 的表，在您单击 **Refresh All Tables** 时，会刷新到**当时处于活动状态的任何工作表**的相同单元格中，并覆盖其中的内容。请将计划刷新的表检索到 **Matching Worksheet**；它们总是刷新到自己的工作表上。

刷新会直接覆盖旧数据，而不会先清除。如果表现在的行或列比以前少，上次拉取遗留的多余行或列会保留在工作表上。刷新可能已缩小的表之前，请先清除工作表的内容。
</Aside>

## 检索维度

**Dimensions** 选项卡列出项目的[维度](/zh-cn/guides/dimensions/dimensions/)。

1. 单击某个维度。使用 **Filter dimensions by name** 查找。
2. 在 **Select where to place this dimension** 下，选择 **Matching Worksheet** 或 **Current Selection**。
3. 单击 **Retrieve Dimension**。

PlaidXL 将维度的节点按层次结构顺序写成一列。维度没有列筛选器或行筛选器，并且 **Refresh All Tables** 不会刷新它们；请重新检索维度以获取更改。

若要以缩进和 Excel 分级显示分组的方式布局层次结构，或要从特定节点或备用层次结构开始，请改用 [`PLAIDXL.DIMENSION.GET_DIMENSION`](/zh-cn/reference/cli/plaidxl/functions/#get_dimension) 或[钻取命令](/zh-cn/reference/cli/plaidxl/ribbon/#drill-functions)。

## 将表保存到 PlaidCloud

您检索到工作簿中的表可以保存回去，用工作表上的内容替换 PlaidCloud 中的表。

1. 转到包含已检索表的工作表。在 **Save this sheet to PlaidCloud** 下，任务窗格会列出链接到活动工作表的每个表及其行数。如果工作表没有任何关联的表，窗格会提示先在该处检索一个表。
2. 单击表旁边的 **Save to PlaidCloud…**。
3. 阅读确认信息（其中显示表、要写入的行数和列），然后单击 **Replace table**。

PlaidXL 从该表被检索到的位置读取标题行及其下方的行。标题必须仍与您检索的列相匹配，并且值会转换为每列的数据类型。如果某个值无法转换，则不会写入任何内容，并会列出失败的行。PlaidCloud 中的列定义保持不变。

### 保存的内容

- 空单元格和显示错误的单元格会保存为空。
- 直接添加在表下方的行会被包含，直到第一个空行为止。
- 已检索行内部的单个空行会被跳过；其前后的行仍会保存。连续两个或更多空行且其下方还有数据时，会停止保存，并告知您需要删除或填写哪些行。

### 替换表之前

- **已筛选的表。** 如果您检索表时使用了筛选器，则筛选器排除的每一行都会从 PlaidCloud 中删除。确认信息会说明这一点，并要求您勾选一个复选框，之后 **Replace table** 才会启用。
- **您未检索的列。** 如果您只检索了部分列，PlaidXL 会询问 **Empty columns that were not retrieved?** 并列出这些列的名称。单击 **Write anyway** 可清空 PlaidCloud 中的这些列，或取消以不写入任何内容。
- **其他人更改了表。** 在 PlaidCloud 能够判断的情况下，如果表在您检索之后发生了更改，保存会被拒绝；请重新检索并重新应用您的编辑。在无法判断的情况下，确认信息会说明这一点，并且自您检索表以来其他人保存的任何内容都会被覆盖。
- **还原点。** PlaidXL 会在写入之前创建一个还原点，并保留 7 天。如果写入失败，表会恢复原状。无法创建还原点的表会询问 **Write back without a restore point?**，而 **Write anyway** 会在没有还原点的情况下继续进行。

保存成功后，确认消息中包含 **Restore previous version**。它会在 PlaidCloud 中打开该表，您可在其中通过 **As of** 菜单选择此次保存之前的版本。
