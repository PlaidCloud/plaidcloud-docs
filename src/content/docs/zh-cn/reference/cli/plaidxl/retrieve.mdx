[登录](/zh-cn/reference/cli/plaidxl/connect/)后，任务窗格会列出您的项目。先选择一个项目，然后将其表和维度检索到工作簿中。

## 选择项目

**项目**部分列出您可以打开的所有项目，文件夹结构与 PlaidCloud 中所见相同。文件夹默认折叠；单击可展开，或在 **Filter projects by name** 中输入内容以缩小列表范围。

单击某个项目即可选中它。其表显示在 **表** 选项卡上，其维度显示在 **维度** 选项卡上。

所选项目也是 PlaidXL [自定义函数](/zh-cn/reference/cli/plaidxl/functions/)和钻取命令读取数据的项目。该选择适用于您打开的所有工作簿，而不仅仅是当前工作簿。

### 设置默认项目

若要让工作簿每次打开任务窗格时都选中同一个项目，请选中该项目并单击 **设为默认**。默认设置保存在工作簿中，因此会随文件传递给打开它的任何人。**Clear Default** 可将其移除。

## 检索表

1. 在 **表** 选项卡上，单击某个表。在较长的列表中，可使用 **Filter tables by name** 查找。每个表旁边的 **行** 和 **列** 显示其大小。
2. 在 **列** 下，清除不需要的列的复选框。所有列默认处于选中状态。
3. 若只检索部分行，请选择 **高级** 并构建筛选器。请参阅[筛选行](#筛选行)。
4. 在 **Select where to place this table** 下，选择：
   - **Matching Worksheet** — 以表命名的工作表。如果该工作表不存在，PlaidXL 会创建它；如果已存在，则从单元格 A1 开始写入表。
   - **Current Selection** — 从活动工作表上选中的单元格开始。
5. 单击 **Retrieve Table**。

数据连同标题行一起到达，可直接使用。标题行为粗体并带有底纹，列宽自动适配，并且已开启筛选。检索到 **Matching Worksheet** 的表还会获得：

- 冻结的标题行，滚动时始终可见。
- 覆盖数据的命名区域，因此使用它的公式会在刷新时随数据增长。其名称是在工作表名称前加一个下划线：名为 **Sample data** 的表位于工作表 `Sample_data`，命名区域为 `_Sample_data`。

为工作表命名时，PlaidXL 会将表名截断到 Excel 的 31 个字符上限，仅保留普通字母（A–Z）、数字和空格，并将空格转换为下划线。名为 **Q3 Revenue (EMEA)** 的表会检索到工作表 `Q3_Revenue_EMEA`。下划线和带重音的字母也会被去掉，因此 **sales_2024** 会检索到工作表 `sales2024`。

<Aside type="tip">宽表加载到 Excel 中较慢。清除不需要的列是加快大型检索速度的最快方式。</Aside>

### 以红色显示的表

当表对于工作表来说太大（超过 1,048,576 行或 16,384 列），或者 PlaidCloud 无法报告其大小（例如从未加载过的表）时，该表会以红色显示。请使用 **高级** 筛选行并清除列，直到其能够容纳。PlaidXL 最多检索 1,048,575 行外加标题行，到此为止，不会给出警告。

## 筛选行

选择 **高级** 以打开筛选器构建器。每条规则选择一列、一种比较方式（例如 **等于**、**in**、**包含**、**开头** 或 **为空**）以及一个值。使用 **AND** 组、**OR** 组或两者结合来组合规则。

筛选器将值作为文本进行比较，因此可匹配精确值和文本模式。不支持数字或日期范围；若要检索某个范围，请使用 **in** 对所需的值进行筛选，或先检索该表再在 Excel 中筛选。

- 输入值时不要加引号：写 `EMEA`，而不是 `"EMEA"`。
- 对于接受多个值的比较（例如 **in**），请用逗号加空格分隔各个值：`EMEA, APAC, NA`。

筛选器仅在选中 **高级** 时生效。PlaidXL 会记住每个已检索表所选的筛选器和列，并在刷新时再次使用。

## 刷新所有表

**Refresh All Tables**（位于任务窗格中，或功能区的 **PlaidCloud → PlaidXL Controls** 下）会为您已检索到工作簿中的每个表拉取 PlaidCloud 的当前数据，并使用您为每个表选择的列和筛选器。

运行时，每个表的工作表选项卡会变为黄色；该表更新完成后变为绿色。使用这些数据的公式照常重新计算；基于这些数据构建的数据透视表请使用 Excel 的 **Data → Refresh All** 刷新。

PlaidXL 会将已检索表的列表保存在工作簿中，因此任何打开该文件并以有权访问相同项目的账户登录的人，都可以使用 **Refresh All Tables**。

每次 **Retrieve Table** 都会将该表添加到刷新列表中，且无法移除。请将每个表只检索一次，然后使用 **Refresh All Tables** 进行更新；重复检索同一个表会导致每次刷新都拉取它两次。

<Aside type="caution">
检索到 **Current Selection** 的表，在您单击 **Refresh All Tables** 时，会刷新到**当前活动工作表**上的相同单元格中，并覆盖那里的内容。计划刷新的表请检索到 **Matching Worksheet**；它们始终会刷新到自己的工作表上。

刷新会直接覆盖旧数据，而不会先清除它。如果某个表现在的行数或列数比之前少，之前拉取的多余行或列会保留在工作表上。刷新可能缩小的表之前，请先清除工作表内容。
</Aside>

## 检索维度

**维度** 选项卡列出项目的[维度](/zh-cn/guides/dimensions/dimensions/)。

1. 单击某个维度。可使用 **Filter dimensions by name** 查找。
2. 在 **Select where to place this dimension** 下，选择 **Matching Worksheet** 或 **Current Selection**。
3. 单击 **Retrieve Dimension**。

PlaidXL 按层次结构顺序将维度的节点写成一列。维度没有列筛选器或行筛选器，**Refresh All Tables** 也不会刷新它们；请重新检索维度以获取变更。

若要以缩进和 Excel 分级显示分组的方式排布层次结构，或者从特定节点或备用层次结构开始，请改用 [`PLAIDXL.DIMENSION.GET_DIMENSION`](/zh-cn/reference/cli/plaidxl/functions/#get_dimension) 或[钻取命令](/zh-cn/reference/cli/plaidxl/ribbon/#钻取函数)。

## 更改数据

PlaidXL 从 PlaidCloud 读取数据，绝不会写回。您可以随意编辑已检索的工作表、对其排序以及添加公式，项目中的任何内容都不会改变。刷新会用 PlaidCloud 的当前数据覆盖该表的区域，因此请将自己的计算放在单独的工作表上。

若要更改数据本身，请在 PlaidCloud 中更新，例如使用[工作流](/zh-cn/guides/workflows/)或[数据编辑器](/zh-cn/guides/projects/managing-data-editors/)。
