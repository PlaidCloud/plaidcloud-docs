[登录](/zh-cn/reference/cli/plaidxl/connect/)后，任务窗格会列出您的项目。您选择一个项目，然后将其表和维度检索到工作簿中。

## 选择项目

任务窗格的标题栏显示您的工作区以及此工作簿所关联的项目。单击项目名称可打开项目列表，其中显示您可以打开的每个项目，所在文件夹与您在 PlaidCloud 中看到的相同。文件夹默认折叠；单击可展开，或在 **Filter projects by name** 中键入以缩小列表范围。如果您的工作区只有一个您可以打开的项目，PlaidXL 会自动将工作簿关联到它，标题栏会显示 **Linked to** 该项目，旁边有 **change**。

单击项目即可选择它。其表显示在 **表** 选项卡上，其维度显示在 **维度** 选项卡上。

### 项目属于工作簿

所选项目保存在工作簿中，因此每个工作簿都有自己的项目。这是该工作簿中 PlaidXL [自定义函数](/zh-cn/reference/cli/plaidxl/functions/)和钻取命令所读取的项目。打开两个工作簿，各自读取自己的项目；重新打开工作簿时，任务窗格会回到其项目。该项目会随文件传给任何打开它并以有权访问它的身份登录的人。

一个项目属于一个工作区。如果您[切换工作区](/zh-cn/reference/cli/plaidxl/connect/#退出登录或切换工作区)，关联到旧工作区中项目的工作簿在您重新选择之前没有项目。您从旧工作区检索的表和维度会保留在工作簿中，但不会被刷新或保存：**Refresh All Tables** 会提示来自其他工作区的表或维度未被刷新。请在新工作区中重新检索它们以建立关联。

## 检索表

1. 在 **表** 选项卡上，单击一个表。在较长的列表中使用 **Filter tables by name** 来查找。每个表旁边的 **行** 和 **列** 显示其大小。
2. 在 **列** 下，清除不需要的列的复选框。所有列默认处于选中状态。
3. 若只检索部分行，请选择 **高级** 并构建筛选器。请参阅[筛选行](#筛选行)。
4. 在 **Select where to place this table** 下，选择：
   - **Matching Worksheet**——以表命名的工作表，从单元格 A1 开始。如果该工作表不存在，PlaidXL 会创建它。
   - **Current Selection**——从您在活动工作表上选中的单元格开始。
5. 单击 **Retrieve Table**。

数据以 Excel 表的形式到达，以 PlaidCloud 表命名，因此引用它的公式、数据透视表和图表会随数据的增减而自动调整。数字、日期和时间会采用适合其数据类型的格式，或 PlaidCloud 中为该列设置的数字格式。文本列按文本格式设置，因此像 `0012` 这样的代码会保留前导零。首次检索表时，其标题行会被冻结，列宽会自动调整。

如果该表将要放入的单元格中已有并非 PlaidXL 表的内容，PlaidXL 会改为将表放到新工作表上，并告知您位置。

为工作表命名时，PlaidXL 只保留普通字母（A–Z）、数字、下划线和空格，将空格转换为下划线，并将名称截断至 Excel 的 31 个字符上限。名为 **Q3 Revenue (EMEA)** 的表会检索到工作表 `Q3_Revenue_EMEA`，**sales_2024** 则检索到 `sales_2024`。带重音的字母会被丢弃。

<Aside type="tip">较宽的表加载到 Excel 中很慢。清除不需要的列是加快大型检索的最快方法。</Aside>

### 以红色显示的表

当表的行数超过 1,048,575 或列数超过 16,384，或者 PlaidCloud 无法报告其大小（例如从未加载过的表）时，该表会以红色显示，并带有提示 **Too large for an Excel worksheet**。您仍然可以检索它：放不进一个工作表的行会继续放在下一个工作表上，其名称为第一个工作表的名称加上 ` (2)`、` (3)` 等。拆分到多个工作表的表无法保存回 PlaidCloud，因此如果您打算编辑它，请使用 **高级** 筛选行并清除部分列，直到能放得下。

## 筛选行

选择 **高级** 以打开筛选器构建器。每条规则选择一列、一个比较方式（如 **等于**、**in**、**包含**、**开头** 或 **为空**）以及一个值。使用 **AND** 组、**OR** 组或两者组合规则。

筛选器将值作为文本进行比较，因此匹配的是精确值和文本模式。不提供数字或日期的范围；若要检索某个范围，请使用 **in** 对所需的值进行筛选，或检索整个表后在 Excel 中筛选。

- 键入值时不要加引号：`EMEA`，而不是 `"EMEA"`。
- 对于接受多个值的比较（如 **in**），请用逗号加空格分隔各个值：`EMEA, APAC, NA`。

筛选器仅在选中 **高级** 时生效。PlaidXL 会记住每个已检索表所用的筛选器和您选择的列，并在刷新时再次使用。仅由用 **AND** 连接的 **等于** 和 **in** 规则构建的筛选器，也决定[保存](#将表保存到-plaidcloud)会替换哪些行。

## 刷新所有表

PlaidXL 会保存您已检索到工作簿中的表和维度的列表，并使用您为每个表选择的列和筛选器刷新它们。该列表保存在工作簿中，因此任何打开该文件并以有权访问相同项目的身份登录的人都可以刷新。

- 任务窗格中的 **Refresh This Sheet** 刷新活动工作表上的表。
- 任务窗格中的 **Refresh All Tables** 刷新工作簿中的每个表和维度。
- 功能区上的 **刷新** 菜单同样可以刷新工作表、所选内容或每个表，并重新计算 PlaidXL 公式。请参阅[刷新](/zh-cn/reference/cli/plaidxl/ribbon/#刷新)。

刷新运行期间，任务窗格会显示每个表的进度——先查询 PlaidCloud，然后是已写入行的比例——并带有 **取消** 按钮。同时刷新三个表，启动另一次刷新会加入已在运行的刷新中。完成后，窗格会列出每个表及其行数，或失败的原因。单击列表中的表即可选中它。某个表失败不会阻止其他表。

**取消** 会停止 PlaidCloud 查询，并使工作簿保持刷新前的状态：只有在表的所有行都到达之后，才会替换其数据。写入数据时 Excel 的计算会暂停，并在结束时运行一次。

### 刷新会保留的内容

表会刷新到同一个 Excel 表中，无论它现在在哪里——检索到 **Current Selection** 的表会在其所在工作表上的原有单元格中刷新，即使您移动或重命名了该 Excel 表。该表会根据新数据扩大或缩小，先前较大的拉取遗留的行和列会被清除。

- **您自己的列**——您在 Excel 表内、数据旁边添加的列会保留。每行相同的公式会向下填充到新行。其他值（如备注）在表于 PlaidCloud 中有键列时会跟随其所在行；已不存在的行的备注会保留在表的下方。没有键列时，备注按位置留在原处。
- **您的格式**——您为某一列设置的数字格式会保留。

如果表所在的工作表已被删除，该表会被跳过，PlaidXL 会提供 **Recreate sheet** 或 **Stop refreshing**。

### 从刷新列表中移除表

在 **On this sheet** 下，任务窗格会列出检索到活动工作表上的每个表和维度，以及其行数和上次刷新时间。单击 **Stop refreshing** 可将其从刷新列表中移除。数据保留在工作表上，消息中提供 **撤消**。

将表检索到已在列表中的表之上，会替换列表中的该表，因此无论检索多少次，表只会刷新一次。每个表旁边的 **复制** 会复制其 Excel 表名，以便在公式中使用。

## 检索维度

**维度** 选项卡列出项目的[维度](/zh-cn/guides/dimensions/dimensions/)。

1. 单击一个维度。使用 **Filter dimensions by name** 来查找。
2. 在 **Select where to place this dimension** 下，选择 **Matching Worksheet** 或 **Current Selection**。
3. 单击 **Retrieve Dimension**。

PlaidXL 会按层次结构顺序将维度的节点写为一列。维度没有列筛选器或行筛选器。**Refresh All Tables** 会连同您的表一起刷新它们。

若要排布带缩进和 Excel 大纲分组的层次结构，或从特定节点或备用层次结构开始，请改用[钻取命令](/zh-cn/reference/cli/plaidxl/drill/)或 [`PLAIDXL.DRILL`](/zh-cn/reference/cli/plaidxl/functions/#drill)。若要将单个成员放入单元格，请单击 **维度** 选项卡上的 **Pick member...**；请参阅[选取成员](/zh-cn/reference/cli/plaidxl/drill/#选取成员)。

## 将表保存到 PlaidCloud

您检索到工作簿中的表可以保存回去，用工作表上的内容替换 PlaidCloud 表的行。

1. 转到包含已检索表的工作表。在 **On this sheet** 下，任务窗格会列出检索到该工作表上的每个表。如果没有，窗格会提示先在那里检索一个表。
2. 单击表旁边的 **Save to PlaidCloud**，或单击功能区 **写入** 组中的 **Save sheet to PlaidCloud...**（**Ctrl+Alt+Shift+W**，Mac 上为 **⌘⌥⇧W**）以保存工作表上的每个表。

保存会立即发生，不需要确认。消息会说明保存了多少行，提示您应当了解的事项，并提供 **撤消**。

PlaidXL 读取表的标题行及其下方的各行。标题必须仍与您检索的列相匹配，并且值会转换为每一列的数据类型。如果某个值无法转换，则不会写入任何内容，并列出失败的行。PlaidCloud 中的列定义保持不变。

### 保存的内容

- 空单元格保存为空。
- 已检索行内部的空行会被跳过。在它们之下，表在第一个空行处结束；更靠下的行不会被保存，消息中会指出这些行。
- 您没有检索的列会在 PlaidCloud 中被清空，消息中会指出这些列。
- 如果表在您检索之后在 PlaidCloud 中发生了变化，您的保存会替换它，消息中会说明。还原点会保留原有内容。

### 只替换部分行的保存

在以下情况下，保存只替换它自己的行，并保留表的其余部分：

- **表是使用筛选器检索的**，且该筛选器由用 **AND** 连接的 **等于** 和 **in** 规则构建。只有筛选器涵盖的行会被替换；您添加的、落在筛选器之外的行仍会被保存，消息中会说明数量。使用任何其他筛选器检索的表无法保存；请使用此类筛选器或不使用筛选器重新检索。
- **工作表显示来自 [Show detail rows](/zh-cn/reference/cli/plaidxl/drill/#显示明细行) 的明细行。** 只有该值背后的行会被替换。
- **您对该表的访问权限仅限于部分行。** 只有您可以看到的行会被替换，因此其他人的行会保留。如果工作表中包含您无权访问的行，则不会保存任何内容，消息会列出这些行；请移除这些行，或请项目架构师来保存它们。

### 撤消保存

PlaidXL 在写入之前会创建一个还原点，并保留 7 天。如果写入失败，表会恢复原样，您的更改保留在工作表中。

若要撤消保存，请单击消息中的 **撤消**，或功能区 **写入** 组中的 **Undo last write**。表会恢复到您保存之前的状态——对于只替换部分行的保存，则只恢复那些行。刷新工作表即可查看。请参阅[撤销写入](/zh-cn/reference/cli/plaidxl/write-values/#撤销写入)。无法创建还原点的表仍会被保存，消息会说明该保存无法撤消。
