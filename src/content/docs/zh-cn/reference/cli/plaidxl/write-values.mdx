[`PLAIDXL.CELL`](/zh-cn/reference/cli/plaidxl/functions/#cell) 的值不仅用于读取。在其上键入一个数字，PlaidXL 会将其写入背后的 PlaidCloud 表，放回公式，并重新计算工作表，因此报表会显示新的数字以及由此汇总的所有内容。您就是这样将预算、预测或调整直接输入报表的。

## 键入值

1. 选中包含 `PLAIDXL.CELL` 公式的单元格。
2. 键入一个数字，或下面的[代码](#分摊调整和形状)之一，然后按 **Enter**。

该值会立即写入 PlaidCloud，任务窗格会显示更改内容——例如 `Jan·East·Revenue 80 → 100 · 14 rows`——并带有 **撤消** 按钮。粘贴或填充一个值区域时，这些值会一起写入。

当单元格包含单个 `CELL` 公式，或被数字、单元格或名称乘、除或取负的 `CELL`（例如 `=-PLAIDXL.CELL(...)*$B$1/1000`）时，它接受键入的值。PlaidXL 会在写入之前，将键入的值换算为 `CELL` 应当保存的值。`CELL` 的参数必须是单元格或文本，这样 PlaidXL 才能判断要写入哪个交叉点。

其他任何情况都会保持您键入的原样：

- 不是数字或代码的文本会保留在单元格中，消息会说明只写入数字和调整。
- 在任何其他公式上键入的值不会被写入。
- 在 `CELL` 上按 **删除** 会放回其公式。
- 正百分比（如 `10%`）不会被写入；键入 `+10%` 可将值提高 10%，或键入 `0.1` 来设置该值。

### 表如何变化

- **求和**——新旧值之间的差额作为新行添加。这些行复制该交叉点上已有的行，每行按其大小按比例分得一份。在空的交叉点上，PlaidXL 会为单元格节点下的每种叶子成员组合各添加一行。
- **平均值**、**中位数**、**最小** 和 **最大**——交叉点上的每一行都按差额移动。
- **std** 和 **var**——交叉点上的行围绕其保持不变的平均值向外扩散或向内收拢。

一次写入最多添加 100,000 行。

## 分摊、调整和形状

在 **求和** 单元格上，您可以键入代码来选择如何在其下的叶子成员之间分摊该值。字母可大写或小写。

| 键入 | 结果 |
|---|---|
| `1200` | 将单元格设置为 1,200，按每个叶子成员当前所持有的值按比例分摊。 |
| `P1200` | 同上，写成完整形式：按比例。 |
| `E1200` | 将单元格设置为 1,200，在叶子成员之间平均分摊。 |
| `R1200` | 将每个叶子成员设置为 1,200，因此单元格显示的是成员数量的 1,200 倍。 |
| `1200 like FY2025` | 将单元格设置为 1,200，按与 **FY2025** 单元格相同的形状分摊。 |
| `+50` 或 `-50%` | 按金额或百分比向上或向下调整该值。 |
| `-50` | 将单元格设置为 -50。单独的减号表示设置负值；加上 `%` 才是调整。 |
| `H` | 保持该单元格，如果已被保持则释放。 |

数字使用您的 Excel 小数点和千位分隔符。对于 `like`，成员必须只属于单元格的其中一个维度；如果它属于两个，请使用已包含它的单元格。内容为空的形状会平均分摊。

### 保持值

在 `CELL` 上键入 `H` 即可保持它。被保持的单元格会有虚线边框，之后对同一表和度量的其他单元格的写入会保持其不变：父级的新值会在未被保持的成员之间分摊。再次键入 `H` 即可释放。保持状态会随工作簿一起保存。如果某个单元格下的所有成员都被保持，则对它的写入会被拒绝。

代码、形状和保持仅适用于 **求和** 单元格。

## 撤销写入

Excel 的 **Ctrl+Z** 不会撤销对 PlaidCloud 的写入。若要撤销，请单击消息中的 **撤消**，或单击功能区 **写入** 组中的 **Undo last write**（**Ctrl+Alt+Shift+Z**，Mac 上为 **⌘⌥⇧Z**）。

**Undo last write** 会撤销从此工作簿所做的最新一次写入，无论是键入的值还是[保存](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)；再次单击可撤销更早的一次。该列表保存在工作簿中，因此关闭并重新打开文件后仍然存在，并保留最近 100 次写入。

- **键入的值**通过反向处理其行来撤消，工作表随之重新计算。一次写入只能撤消一次。表的列发生变化后无法撤消。
- **保存**会将表恢复到其之前创建的还原点。刷新工作表即可查看恢复的行。

## 其他人同时写入

最后一次写入生效。如果在您上次刷新之后有人更改了某个值，您的写入仍会进行，消息会补充说明，例如 `was 80, not 75`：您键入时 PlaidCloud 中是 80，而不是您的工作表所显示的 75。

## 行访问

如果您对某个表的访问权限仅限于部分行，则只能在这些行内写入。键入的值会在您能看到的成员之间分摊，会更改您访问权限之外的行的撤消操作会被拒绝。

<Aside>
键入值需要接受此类值的 PlaidCloud 工作区。如果 PlaidXL 提示工作区尚不接受在 Excel 中键入的值，请联系管理员更新。
</Aside>
