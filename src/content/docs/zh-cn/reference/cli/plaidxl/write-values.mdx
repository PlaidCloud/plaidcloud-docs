[`PLAIDXL.CELL`](/zh-cn/reference/cli/plaidxl/functions/#cell) 值不仅用于读取。在其上输入数字，PlaidXL 就会将其写入背后的 PlaidCloud 表，恢复公式，并重新计算工作表，因此报表会显示新的数字以及由此汇总的所有内容。您可以通过这种方式将预算、预测或调整直接输入报表。

## 输入值

1. 选择包含 `PLAIDXL.CELL` 公式的单元格。
2. 输入数字或下面的[代码](#分摊调整和形状)之一，然后按 **Enter**。

该值会立即写入 PlaidCloud，任务窗格会显示更改的内容，例如 `Jan·East·Revenue 80 → 100 · 14 rows`，并带有 **撤消** 按钮。粘贴或填充一个值区域时，这些值会一起写入。

当单元格包含单个 `CELL` 公式，或 `CELL` 与数字、单元格或名称相乘、相除或取负时（例如 `=-PLAIDXL.CELL(...)*$B$1/1000`），可以接受输入的值。PlaidXL 会先将输入的值反推为 `CELL` 应持有的值，然后再写入。`CELL` 的参数必须是单元格或文本，以便 PlaidXL 能判断要写入哪个交叉点。

其他任何内容都保持您输入的样子：

- 不是数字或代码的文本会保留在单元格中，消息会说明只写入数字和调整。
- 在任何其他公式上输入的值不会被写入。
- 在 `CELL` 上按 **Delete** 会恢复其公式。
- 正百分比（如 `10%`）不会被写入；输入 `+10%` 可将值提高 10%，输入 `0.1` 则设置该值。

如果 PlaidCloud 响应时间过长，或没有为某个单元格给出响应，消息会说明更改可能已经应用；再次写入之前请检查该值。无法发送的单元格会提示没有写入任何内容。

在插入或删除行或列之前刚输入的值，会写入 Excel 将其移动到的单元格。在随后被删除的行或列中输入的值不会被写入，消息会说明在已删除或已移动的单元格中有多少个输入值。

### 表如何变化

- **求和**：新旧值之差会作为新行添加。它们复制该交叉点上已有的行，每行按其大小的比例分得一份。在空的交叉点上，PlaidXL 会为该单元格节点之下叶成员的每种组合添加一行。
- **平均值**、**中位数**、**最小** 和 **最大**：交叉点上的每一行都按差值移动。
- **标准差** 和 **方差**：交叉点上的行会围绕其平均值展开或收拢，而平均值保持不变。

单次写入最多添加 100,000 行。

## 分摊、调整和形状

在 **求和** 单元格上，您可以输入代码来选择如何在其下的叶成员之间分摊该值。字母可以大写或小写。

| 输入 | 效果 |
|---|---|
| `1200` | 将单元格设为 1,200，按每个叶成员当前持有的值按比例分摊。 |
| `P1200` | 同上，只是明确写出：按比例。 |
| `E1200` | 将单元格设为 1,200，在叶成员之间平均分摊。 |
| `R1200` | 将每个叶成员设为 1,200，因此该单元格显示的是 1,200 乘以成员数。 |
| `1200 like FY2025` | 将单元格设为 1,200，按与 **FY2025** 对应单元格相同的形状分摊。 |
| `+50` 或 `-50%` | 按金额或百分比上调或下调该值。 |
| `-50` | 将单元格设为 -50。单独的负号表示设置负值；加上 `%` 则表示调整。 |
| `H` | 锁定该单元格，如果已锁定则释放。 |

数字使用您 Excel 的小数点和千位分隔符。对于 `like`，成员必须只属于该单元格的某一个维度；如果它属于两个维度，请使用已包含它的单元格。内容为空的形状会平均分摊。

### 锁定值

在 `CELL` 上输入 `H` 可将其锁定。被锁定的单元格会带有虚线边框，此后对同一表和度量的其他单元格的写入不会改变它：父级的新值会在未被锁定的成员之间分摊。再次输入 `H` 即可释放。锁定要求 `CELL` 的参数是单元格或文本；对于参数为公式的单元格，消息会提示锁定参数为单元格或文本的单元格。锁定信息随工作簿一起保存。如果某个单元格下的所有成员都被锁定，则对它的写入会被拒绝。

代码、形状和锁定仅适用于 **求和** 单元格。

## 撤消写入

Excel 的 **Ctrl+Z** 不会撤销对 PlaidCloud 的写入。要撤消写入，请点击消息中的 **撤消**，或点击功能区 **写入** 组中的 **Undo last write**（**Ctrl+Alt+Shift+Z**，Mac 上为 **⌘⌥⇧Z**）。

**Undo last write** 会撤消从此工作簿发出的最新一次写入，无论是输入的值还是[保存](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)；再次点击可撤消之前的一次。该列表保存在工作簿中，因此关闭并重新打开文件后仍然存在，并保留最近 100 次写入。

- **输入的值** 通过反向处理其行来撤消，工作表随后重新计算。一次写入只能撤消一次。表的列发生变化后无法撤消。
- **保存** 会将表恢复到其之前创建的还原点。刷新工作表即可看到已还原的行。

只有执行写入的人员和工作区才能撤消它。其他人的条目会留在列表中，并显示 **This write was made by another user or workspace**。已经撤消的条目显示 **Already undone or no longer available**。如果工作簿中没有任何属于您的写入，消息会显示 **Nothing to undo: the writes in this workbook were made by other users or workspaces.** 如果 PlaidCloud 响应撤消的时间过长，消息会说明它可能已经应用；请再次尝试 **撤消**。

## 他人同时写入

后写入者生效。如果在您上次刷新之后有其他人更改了某个值，您的写入仍会继续，并且消息会补充说明，例如 `was 80, not 75`：您输入时 PlaidCloud 中的值是 80，而不是您的工作表所显示的 75。

## 行访问

如果您对表的访问权限仅限于部分行，则只能在这些行内写入。输入的值会在您能看到的成员之间分摊，会更改您无权访问的行的撤消操作会被拒绝。

<Aside>
输入值需要接受它们的 PlaidCloud 工作区。如果 PlaidXL 提示工作区尚不接受在 Excel 中输入的值，请让管理员更新该工作区。
</Aside>
