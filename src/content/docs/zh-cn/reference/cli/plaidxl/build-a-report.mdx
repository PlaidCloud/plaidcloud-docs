## 开始之前

- [登录](/zh-cn/reference/cli/plaidxl/connect/)并选择包含数据的项目。工作簿会记住该项目。
- 您需要一个带有数值列（例如 **revenue**）的表，以及您要按其报告的每个维度对应的列（例如 **Region** 和 **Period**），并且这些列已在 PlaidCloud 中链接到相应维度。`CELL` 按列名筛选，并且只有在已链接的列上才会通过其维度汇总节点。请参阅[值](/zh-cn/reference/cli/plaidxl/functions/#值)。
- 不确定确切的名称？可以在临时工作表上使用 `=PLAIDXL.TABLE.TBL_LIST()`、`=PLAIDXL.TABLE.GET_COLUMNS("Sales")` 和 `=PLAIDXL.DIMENSION.DIM_LIST()` 列出它们。

## 构建报表

这些步骤使用名为 **Sales** 的表，其度量列为 **revenue**，维度列为 **Region**（行）和 **Period**（列），并链接到同名维度。请换成您自己的名称——在 `DRILL` 中使用维度的名称，在 `DIMENSION_REPR` 中使用表的列名。

<Steps>

1. **描述要度量的内容。** 在工作表顶部的三个单元格中输入：

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   报表中的每个值都引用这些单元格，因此更改其中一个——例如用 `"mean"` 代替 `"sum"`——就会改变整个报表。

2. **布置行。** 在 `A6` 中，从行维度的顶部节点开始向下钻取：

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **Total** 及其子节点会向下溢出到 A 列，缩进显示在其父节点之下，并进行了分组，便于折叠。使用 `"all"` 可显示所有级别，使用 `"leaves"` 则只显示最底层。如需更精细的控制，例如显示除叶子节点之外的所有级别，请直接写出键：`>[0:-1]`。请参阅 [`DRILL_KEY`](/zh-cn/reference/cli/plaidxl/functions/#drill_key)。如果想自己输入行节点，请在每个单元格中放入一个节点名称。

3. **布置列。** 从 `B5` 开始，在第 5 行中依次输入列节点——例如 `FY2025` 和 `FY2026`。

4. **填充第一个值。** 在 `B6` 中输入：

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   `$` 符号分别固定表、度量和类型，A 列中的行节点，以及第 5 行中的列节点。`DRILL` 为节点名称添加的缩进会被忽略。

5. **填充网格。** 将 `B6` 向右复制到最后一个期间，再向下复制到最后一行。每个单元格显示其所在行的区域在其所在列的期间内的收入。

</Steps>

如果要添加适用于整个报表的筛选器——例如只看某一条产品线——请在顶部的某个单元格中再添加一个 `DIMENSION_REPR`，例如 `B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`，并将 `$B$4` 传给每个 `CELL`。

如需为每一行显示多个度量，请将 [`PLAIDXL.CELLS`](/zh-cn/reference/cli/plaidxl/functions/#cells) 与 [`PLAIDXL.REPR.MEASURES`](/zh-cn/reference/cli/plaidxl/functions/#measures) 配合使用。

## 保持报表为最新

- **强制完全重新计算**，以便将当前值提取到每个 PlaidXL 公式中——在 Windows 上，按 **Ctrl+Alt+F9**。除非公式的参数发生变化，否则普通的重新计算不会再次提取数据。
- **更改范围**：编辑某个构建块单元格，例如换成另一个表、度量或聚合方式，或另一个顶层筛选节点。使用该单元格的公式会立即更新。
- **对另一个项目进行报告**：在任务窗格中选择该项目，然后强制完全重新计算。公式从工作簿的项目中读取，因此同一个工作簿可以对每个具有相同表名、列名和维度名的项目进行报告。

## 共享仅含值的副本

没有 PlaidXL 或无权访问该项目的人会看到错误，而不是 PlaidXL 公式的结果。若要向他们发送数字，请先将公式替换为其值：

1. 保存报表，然后另存一个副本并使用新名称，用于发送。
2. 在副本中，单击 **PlaidCloud → 转换为值（用于共享）** 并确认。
3. 发送该副本。

**转换为值（用于共享）** 会将工作簿中的每个 PlaidXL 公式替换为其当前值，并保留其他公式不变。**还原 PlaidXL 公式**会将 PlaidXL 公式放回原处，但无法完好还原结果会溢出的公式（例如 `DRILL`），并且会覆盖转换后您所做的任何更改。请保留原始文件——这是找回实时报表的可靠方式。请参阅[共享](/zh-cn/reference/cli/plaidxl/ribbon/#共享)。

<Aside type="caution">请转换要发送的副本，切勿转换您唯一的工作报表。</Aside>
