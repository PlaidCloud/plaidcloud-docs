安装 PlaidXL 会在 Excel 功能区中添加一个 **PlaidCloud** 选项卡，其中有六组命令：**连接**、**插入**、**刷新**、**Drill**、**写入** 和 **共享**。最常用的命令也在 **PlaidXL** 右键菜单和 **PlaidXL Cell** 选项卡上，每个有键盘快捷键的命令都会在其工具提示中显示快捷键。

任何命令都不会呈灰色不可用状态。命令会作用于离所选单元格最近的 PlaidXL 公式、表或节点；当没有可作用的对象时，它会打开任务窗格中能提供帮助的部分。

如果在退出登录状态下，或在工作簿关联到项目之前运行命令，PlaidXL 会打开任务窗格，并提示 **Sign in to run** 该命令，或 **Pick a project to run** 该命令。进入之后，命令会在您开始时所在的单元格上运行。如果在此期间您已切换到另一个工作表或选择了另一个项目，则命令不会运行，PlaidXL 会告知您。

## 连接

| 命令 | 作用 |
|---|---|
| **Open PlaidXL** | 打开 PlaidXL 任务窗格。 |
| **账户** | 打开任务窗格以登录，或选择您的工作区和项目。 |
| **Shortcuts** | 列出 PlaidXL 键盘快捷键，以便您更改。请参阅[键盘快捷键](#键盘快捷键)。 |
| **Help** | 打开本文档。 |

## 插入

| 命令 | 作用 |
|---|---|
| **表...** | 打开 **表** 选项卡以[检索表](/zh-cn/reference/cli/plaidxl/retrieve/#检索表)。 |
| **维度...** | 打开 **维度** 选项卡以检索维度或选取其成员。 |
| **Formula...** | 打开 **Formulas** 选项卡，为所选单元格[构建 PlaidXL 公式](/zh-cn/reference/cli/plaidxl/functions/#从任务窗格插入公式)。 |
| **Pick member...** | 针对所选单元格的维度打开成员选取器。请参阅[选取成员](/zh-cn/reference/cli/plaidxl/drill/#选取成员)。 |
| **Metric...** | 打开可搜索的项目指标列表，并显示其当前值。请参阅[插入指标](/zh-cn/reference/cli/plaidxl/functions/#插入指标)。 |
| **Build report...** | 打开 **报表** 选项卡以排布实时报表。请参阅[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)。 |
| **询问 Weave...** | 以所选单元格为上下文打开 **Weave** 选项卡。请参阅[在 Excel 中询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。 |

## 刷新

**刷新** 菜单包含四个命令：

| 命令 | 作用 |
|---|---|
| **Refresh this sheet** | 重新计算活动工作表上的 PlaidXL 公式，并重新检索其表。 |
| **Refresh selection** | 重新计算所选内容中的 PlaidXL 公式，并重新检索所选内容涉及的任何表。如果所选内容中没有来自 PlaidXL 的内容，则刷新工作表。 |
| **Refresh all tables** | 使用您为每个表选择的列和筛选器，重新检索工作簿中的每个表和维度。 |
| **Recalculate PlaidXL formulas** | 重新计算工作簿中的每个 PlaidXL 公式。 |

刷新运行期间您会看到的内容，请参阅[刷新表](/zh-cn/reference/cli/plaidxl/retrieve/#刷新所有表)。

**Recalculate PlaidXL formulas** 只重新计算 PlaidXL 公式，不进行完整的 Excel 重新计算。完成后，它会列出已重新计算的工作表，并清除 Excel 的撤消历史记录。PlaidXL 会将表的列详情保留 30 秒，因此在最近 30 秒内重命名的列或维度可能需要稍长时间才会显示。

## Drill

| 命令 | 作用 |
|---|---|
| **Drill down** | 一个菜单：**One level**、**To lowest level**、**All levels** 和 **Custom drill...** 会排布所选节点之下的节点。 |
| **Drill up** | 将所选节点折叠回其父节点。 |
| **Keep only** | 在钻取中仅保留所选节点。 |
| **Remove only** | 将所选节点及其下方的所有内容从钻取中移除。 |
| **Show detail rows** | 将所选值背后的表行放到单独的工作表上。 |
| **Explain this number** | 显示所选值的来源。 |

选中单个单元格进行钻取：钻取命令会将其转换为实时的 `PLAIDXL.DRILL` 公式。请参阅[钻取、选取成员和说明数字](/zh-cn/reference/cli/plaidxl/drill/)。

## 写入

| 命令 | 作用 |
|---|---|
| **Save sheet to PlaidCloud...** | 立即将检索到此工作表的表写回 PlaidCloud。请参阅[将表保存到 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)。 |
| **Undo last write** | 撤消您最近键入 PlaidCloud 的值或最近一次保存，最新的优先。请参阅[撤销写入](/zh-cn/reference/cli/plaidxl/write-values/#撤销写入)。 |

## 共享

| 命令 | 作用 |
|---|---|
| **Convert to values** | 一个菜单：**Whole workbook** 或 **This sheet** 将 PlaidXL 公式替换为其当前值，并记住这些公式。**Values only (no restore)** 替换公式，但不保留恢复途径。 |
| **Restore PlaidXL formulas** | 在工作簿的每个工作表中，放回被 **Convert to values** 替换的公式。 |

使用 **Convert to values** 向没有 PlaidXL 或无权访问该项目的人发送报表——否则他们会在 PlaidXL 公式所在位置看到错误。它会转换每个调用 PlaidXL 函数的公式，包括嵌套在 `IFERROR` 等其他公式中的公式，其他公式则保持不变。它会立即运行，不会事先询问，并说明转换了多少个公式。

公式随每个工作表保存，因此在您重命名或移动工作表之后，**Restore PlaidXL formulas** 仍然能找到它们。它不需要您已登录。请参阅[分享仅含值的副本](/zh-cn/reference/cli/plaidxl/build-a-report/#分享仅含值的副本)。

<Aside type="caution">
请转换以新名称保存的副本，并保持您的工作报表不变。**Values only (no restore)** 无法通过 **Restore PlaidXL formulas** 撤销。
</Aside>

## 右键菜单

右键单击单元格并选择 **PlaidXL**，即可使用以下命令，每个命令都与其功能区按钮相同：

- **Drill down one level**、**Drill down to lowest level**、**Drill down all levels**、**Custom drill...**、**Drill up**、**Keep only** 和 **Remove only**
- **Pick member...**
- **Explain this number** 和 **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...**，它会针对该单元格打开 **Formulas** 选项卡

## PlaidXL Cell 选项卡

当所选单元格包含 PlaidXL 公式、属于 PlaidXL 公式结果的一部分，或位于已检索的表内时，Excel 会在 **PlaidCloud** 选项卡旁显示 **PlaidXL Cell** 选项卡。它汇集了针对该单元格的命令：

- **Drill**——**Drill down**（**One level**、**Lowest level**、**All levels**）、**Drill up**、**Keep only** 和 **移除**
- **检查**——**说明**、**Detail rows** 和 **询问 Weave**
- **数据**——**Pick member**、**Refresh selection** 和 **Save sheet**

选择其他单元格时，该选项卡会再次隐藏。不支持加载项上下文选项卡的 Excel 版本不会显示它；每个命令仍然都在 **PlaidCloud** 选项卡上。

## 键盘快捷键

每个快捷键在 Windows 上是 **Ctrl+Alt+Shift** 加一个键，在 Mac 上是 **⌘⌥⇧** 加相同的键：

| 键 | 命令 |
|---|---|
| **向下** | 向下钻取一层 |
| **向上** | 向上钻取 |
| **L** | 向下钻取到最低层 |
| **8** | 向下钻取所有层级 |
| **D** | 自定义钻取 |
| **K** | 仅保留 |
| **X** | 仅移除 |
| **M** | 选取成员 |
| **E** | 说明此数字 |
| **T** | 显示明细行 |
| **R** | 刷新此工作表 |
| **F** | 刷新所选内容 |
| **A** | 刷新所有表 |
| **C** | 重新计算 PlaidXL 公式 |
| **W** | 将工作表保存到 PlaidCloud |
| **Z** | 撤消上次写入 |
| **P** | 打开 PlaidXL |
| **N** | 插入公式 |
| **B** | 构建报表 |
| **I** | 插入指标 |
| **Q** | 询问 Weave |

若要更改某个快捷键，请单击 **连接** 组中的 **Shortcuts**，或从任务窗格的账户菜单中选择 **Keyboard shortcuts**。单击命令旁边的 **Set key**，按下新的组合键，然后单击 **保存**；**重置** 会恢复原来的设置。已被其他命令使用的组合键会被标记，仍然保存的话也会生效。某些版本的 Office 不允许加载项更改快捷键，会显示不带 **Set key** 的列表。
