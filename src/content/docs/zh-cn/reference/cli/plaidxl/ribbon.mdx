安装 PlaidXL 会在 Excel 功能区中添加一个 **PlaidCloud** 选项卡，其中有六个命令组：**连接**、**插入**、**刷新**、**Drill**、**写入** 和 **共享**。最常用的命令也出现在 **PlaidXL** 右键菜单和 **PlaidXL Cell** 选项卡上，每个带有键盘快捷键的命令都会在其工具提示中显示该快捷键。

任何命令都不会变灰。命令会作用于距离所选单元格最近的 PlaidXL 公式、表或节点；当没有可作用的对象时，它会改为打开任务窗格中能提供帮助的部分。

如果您在退出登录状态下，或在工作簿尚未关联到项目时运行命令，PlaidXL 会打开任务窗格，并提示 **Sign in to run** 该命令，或 **Pick a project to run** 该命令。进入之后，命令会在您开始操作时所在的单元格上运行。如果在此期间您已转到其他工作表或选择了其他项目，则命令不会运行，PlaidXL 会告知您。

## 连接

| 命令 | 作用 |
|---|---|
| **Open PlaidXL** | 打开 PlaidXL 任务窗格。 |
| **账户** | 打开任务窗格以登录，或选择您的工作区和项目。 |
| **Shortcuts** | 列出 PlaidXL 键盘快捷键，方便您更改。请参阅[键盘快捷键](#键盘快捷键)。 |
| **Help** | 打开本文档。 |

## 插入

| 命令 | 作用 |
|---|---|
| **表...** | 打开 **表** 选项卡以[检索表](/zh-cn/reference/cli/plaidxl/retrieve/#检索表)。 |
| **维度...** | 打开 **维度** 选项卡以检索维度或选取其成员。 |
| **Formula...** | 打开 **Formulas** 选项卡，为所选单元格[构建 PlaidXL 公式](/zh-cn/reference/cli/plaidxl/functions/#从任务窗格插入公式)。 |
| **Pick member...** | 在所选单元格的维度上打开成员选取器。请参阅[选取成员](/zh-cn/reference/cli/plaidxl/drill/#选取成员)。 |
| **Metric...** | 打开一个可搜索的列表，列出项目的指标及其当前值。请参阅[插入指标](/zh-cn/reference/cli/plaidxl/functions/#插入指标)。 |
| **Build report...** | 打开 **报表** 选项卡以布局实时报表。请参阅[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)。 |
| **询问 Weave...** | 以所选单元格为上下文打开 **Weave** 选项卡。请参阅[在 Excel 中询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。 |

## 刷新

**刷新** 菜单包含四个命令：

| 命令 | 作用 |
|---|---|
| **Refresh this sheet** | 重新计算活动工作表上的 PlaidXL 公式，并再次检索其表。 |
| **Refresh selection** | 重新计算所选内容中的 PlaidXL 公式，并检索所选内容涉及的所有表。未选中任何 PlaidXL 内容时，它会刷新工作表。 |
| **Refresh all tables** | 使用您为每个表选择的列和筛选器，再次检索工作簿中的每个表和维度。 |
| **Recalculate PlaidXL formulas** | 重新计算工作簿中的每个 PlaidXL 公式。 |

有关刷新运行时您会看到的内容，请参阅[刷新表](/zh-cn/reference/cli/plaidxl/retrieve/#refresh-all-tables)。

**Recalculate PlaidXL formulas** 仅重新计算 PlaidXL 公式，而不会执行完整的 Excel 重新计算。完成后，它会列出已重新计算的工作表，并清除 Excel 的撤消历史记录。PlaidXL 会将表的列详细信息保留 30 秒，因此您在最近 30 秒内重命名的列或维度可能需要稍等片刻才会显示。

## Drill

| 命令 | 作用 |
|---|---|
| **Drill down** | 一个菜单：**One level**、**To lowest level**、**All levels** 和 **Custom drill...** 会布局所选节点之下的节点。 |
| **Drill up** | 将所选节点折叠回其父节点。 |
| **Keep only** | 在下钻中仅保留所选节点。 |
| **Remove only** | 从下钻中移除所选节点及其下的所有内容。 |
| **Show detail rows** | 将所选值背后的表行放到单独的工作表上。 |
| **Explain this number** | 显示所选值的来源。 |

选择单个单元格即可下钻：下钻命令会将其转换为实时的 `PLAIDXL.DRILL` 公式。请参阅[下钻、选取成员和解释数字](/zh-cn/reference/cli/plaidxl/drill/)。

## 写入

| 命令 | 作用 |
|---|---|
| **Save sheet to PlaidCloud...** | 立即将检索到此工作表中的表写回 PlaidCloud。请参阅[将表保存到 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)。 |
| **Undo last write** | 按从新到旧的顺序，撤消您最近一次输入 PlaidCloud 的值或最近一次保存。请参阅[撤消写入](/zh-cn/reference/cli/plaidxl/write-values/#撤消写入)。 |

## 共享

| 命令 | 作用 |
|---|---|
| **Convert to values** | 一个菜单：**Whole workbook** 或 **This sheet** 会将 PlaidXL 公式替换为其当前值，并记住这些公式。**Values only (no restore)** 会替换公式，且不保留恢复途径。 |
| **Restore PlaidXL formulas** | 在工作簿的每个工作表中，恢复被 **Convert to values** 替换的公式。 |

使用 **Convert to values** 可将报表发送给没有 PlaidXL 或无权访问该项目的人，否则他们会在 PlaidXL 公式处看到错误。它会转换每个调用 PlaidXL 函数的公式，包括嵌套在 `IFERROR` 等其他公式内的公式，以及它溢出到的单元格。工作簿中的其他所有内容保持不变。对整个工作簿使用 **Values only (no restore)** 时会先询问：**Convert every PlaidXL formula in the workbook to values only? Restore can't bring them back.** 其他选项会立即运行。消息会说明已转换多少个公式。仍在计算的公式（`#BUSY!`）不会被转换；消息会统计这些公式，因此请在它们完成后再次转换。

这些公式随每个工作表一起保存，因此在您重命名或移动工作表之后，**Restore PlaidXL formulas** 仍能找到它们。它不要求您已登录。请参阅[共享仅含值的副本](/zh-cn/reference/cli/plaidxl/build-a-report/#分享仅含值的副本)。

<Aside type="caution">
请转换另存为新名称的副本，保持您的工作报表不变。**Values only (no restore)** 无法通过 **Restore PlaidXL formulas** 撤消。
</Aside>

## 右键菜单

右键点击单元格并选择 **PlaidXL**，即可使用以下命令，每个命令都与对应的功能区按钮相同：

- **Drill down one level**、**Drill down to lowest level**、**Drill down all levels**、**Custom drill...**、**Drill up**、**Keep only** 和 **Remove only**
- **Pick member...**
- **Explain this number** 和 **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...**，用于为该单元格打开 **Formulas** 选项卡

## PlaidXL Cell 选项卡

当所选单元格包含 PlaidXL 公式、属于 PlaidXL 公式的结果，或位于已检索的表内时，Excel 会在 **PlaidCloud** 选项卡旁边显示 **PlaidXL Cell** 选项卡。它汇集了针对该单元格的命令：

- **Drill**：**Drill down**（**One level**、**Lowest level**、**All levels**）、**Drill up**、**Keep only** 和 **移除**
- **检查**：**说明**、**Detail rows** 和 **询问 Weave**
- **数据**：**Pick member**、**Refresh selection** 和 **Save sheet**

选择其他单元格时，该选项卡会再次隐藏。不支持加载项上下文选项卡的 Excel 版本不会显示它；所有命令仍然可以在 **PlaidCloud** 选项卡上找到。

## 键盘快捷键

在 Windows 上，每个快捷键都是 **Ctrl+Alt+Shift** 加一个键；在 Mac 上是 **⌘⌥⇧** 加同一个键。在字段中输入或按住 AltGr 时，快捷键不会触发。如果某个功能区命令失败，会有消息说明哪个命令失败及原因，如果任务窗格被隐藏，则会将其打开。

| 键 | 命令 |
|---|---|
| **向下** | 向下钻取一级 |
| **向上** | 向上钻取 |
| **L** | 下钻到最低级 |
| **8** | 下钻所有级别 |
| **D** | 自定义下钻 |
| **K** | 仅保留 |
| **X** | 仅移除 |
| **M** | 选取成员 |
| **E** | 解释此数字 |
| **T** | 显示明细行 |
| **R** | 刷新此工作表 |
| **F** | 刷新所选内容 |
| **A** | 刷新所有表 |
| **C** | 重新计算 PlaidXL 公式 |
| **W** | 将工作表保存到 PlaidCloud |
| **Z** | 撤消上次写入 |
| **P** | 打开 PlaidXL |
| **N** | 插入公式 |
| **B** | 构建报表 |
| **I** | 插入指标 |
| **Q** | 询问 Weave |

要更改某个快捷键，请点击 **连接** 组中的 **Shortcuts**，或在任务窗格的账户菜单中选择 **Keyboard shortcuts**。点击命令旁边的 **Set key**，按下新的组合键，然后点击 **保存**；**重置** 会恢复原来的组合键。如果某个组合键已被其他命令使用，会有标记，仍然保存的话也会生效。某些版本的 Office 不允许加载项更改快捷键，显示的列表中不含 **Set key**。
