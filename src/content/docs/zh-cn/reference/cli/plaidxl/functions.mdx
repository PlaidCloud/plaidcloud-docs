PlaidXL 为 Excel 添加了可将 PlaidCloud 数据直接读入单元格的函数。在单元格中输入 `=PLAIDXL.`，Excel 的自动完成会列出这些函数，并附有每个参数的简短说明。任务窗格的 **Formulas** 选项卡也可以为您编写公式；请参阅[从任务窗格插入公式](#从任务窗格插入公式)。

| 分组 | 函数 | 用途 |
|---|---|---|
| 列表 | [`LIST_PROJECTS`](#list_projects)、[`TABLE.TBL_LIST`](#tbl_list)、[`TABLE.GET_COLUMNS`](#get_columns)、[`DIMENSION.DIM_LIST`](#dim_list) | 查看可用于构建的内容 |
| 表 | [`TABLE.GET_TABLE`](#get_table) | 将整个表读入一个区域 |
| 层次结构 | [`DIMENSION.GET_DIMENSION`](#get_dimension)、[`DRILL`](#drill) | 将维度的节点布局为报表行 |
| 值 | [`CELL`](#cell)、[`CELLS`](#cells) | 为任意节点组合计算汇总值 |
| 指标 | [`METRIC`](#metric)、[`METRIC_BREAKDOWN`](#metric_breakdown) | 读取受治理的业务指标，与仪表板显示的一致 |
| 构建块 | [`REPR.TABLE_REPR`](#table_repr)、[`REPR.MEASURE`](#measure)、[`REPR.MEASURES`](#measures)、[`REPR.MEASURE_TYPE`](#measure_type)、[`REPR.DIMENSION_REPR`](#dimension_repr)、[`REPR.DRILL_KEY`](#drill_key) | 描述 `CELL`、`CELLS` 和 `DRILL` 所用的表、度量、聚合、节点和钻取深度 |

[构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)展示了这些函数如何协同工作。

## 函数的工作方式

- **先登录。** 这些函数使用您的 PlaidCloud 登录信息和权限进行读取，因此使用之前请先从任务窗格[登录](/zh-cn/reference/cli/plaidxl/connect/)。
- **它们从工作簿的项目读取。** 每个函数都从任务窗格中与工作簿关联的项目读取。`GET_TABLE`、`TBL_LIST` 和 `DIM_LIST` 还可接受可选的项目 ID，以便在不更改关联的情况下读取另一个项目。每个工作簿都有自己的项目，因此两个打开的工作簿可以读取不同的项目。
- **结果会溢出。** 返回列表或表的函数会填充其下方（或右侧）的单元格。请为结果留出空间；如果有内容挡住，Excel 会显示 `#SPILL!` 错误。
- **重新计算以获取更改。** PlaidXL 公式会在其某个参数变化时重新获取数据。要获取 PlaidCloud 中的新数据，或任务窗格中关联的其他项目，请使用功能区的**刷新**菜单：**Recalculate PlaidXL formulas** 会重新计算工作簿中的每个 PlaidXL 公式，**Refresh this sheet** 和 **Refresh selection** 会重新计算它们所涵盖的公式。**Refresh all tables** 刷新已检索的表，而不是公式。请参阅[刷新](/zh-cn/reference/cli/plaidxl/ribbon/#刷新)。
- **使用准确的名称。** 输入表、列、维度和节点名称时，请与 PlaidCloud 中显示的完全一致。

方括号中的参数是可选的。

## 列表

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

列出您可以打开的项目的名称，按名称排序。

- `horizontal` — 设为 `TRUE` 则沿行横向列出。默认为 `FALSE`，即沿列列出。

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

列出项目中表的名称，按名称排序。

- `project_id` — 要读取的项目。默认为工作簿的项目。
- `horizontal` — 设为 `TRUE` 则沿行横向列出。默认为 `FALSE`，即沿列列出。

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

列出所选项目中某个表的列名。

- `table_name` — 表在 PlaidCloud 中的名称。
- `column_filter` — 数据类型，例如 `"text"`，只列出该类型的列。省略则列出每一列。
- `orientation` — `"vertical"`（默认）表示沿列，`"horizontal"` 表示沿行。

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

列出项目中维度的名称。

- `project_id` — 要读取的项目。默认为工作簿的项目。
- `horizontal` — 设为 `TRUE` 则沿行横向列出。默认为 `FALSE`，即沿列列出。

## 表

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

返回表的行（含标题行），从公式所在单元格开始溢出。空值以空白单元格返回。

- `table_name` — 表在 PlaidCloud 中的名称。
- `project_id` — 要读取的项目。默认为工作簿的项目。
- `limit` — 最多返回的行数。默认为 1,048,575，即工作表在标题行下方最多能容纳的行数。

`GET_TABLE` 返回每一列。要选择列或筛选行，请改为[从任务窗格检索表](/zh-cn/reference/cli/plaidxl/retrieve/#检索表)。

## 层次结构

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

布局维度的节点，从 `start_node` 开始，向下遍历其后代。每一代比其父级多缩进四个空格，Excel 分级显示组可让您折叠和展开每个层级。

- `dimension_name` — 维度的名称，或其在项目中的路径。
- `start_node` — 起始节点，例如维度的根节点。
- `hierarchy` — 要沿用的[备用层次结构](/zh-cn/guides/dimensions/dimensions/#备用属性层次结构)。默认为 `"main"`。
- `orientation` — `"vertical"`（默认）表示沿列向下列出节点，`"horizontal"` 表示沿行横向列出。
- `generation_limit` — 要返回的代数，`start_node` 算第一代：`2` 返回起始节点及其子节点。省略则返回每一代。

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy], [exclude], [expand], [orientation])`

返回 `start_node` 及 `drill_key` 所要求的其下节点，按代际缩进，并分组到 Excel 分级显示中。

- `dimension_name` — 维度的名称，或其在项目中的路径。
- `start_node` — 钻取的起始节点。留空（`""`）则从维度的顶层节点开始。维度本身算作钻取键的第 0 代且不会列出，因此顶层节点是第 1 代：`>[1]` 只列出顶层节点，`>[0]` 什么也不列出。
- `drill_key` — 钻取深度，来自 [`DRILL_KEY`](#drill_key)：每个后代、仅叶节点、若干层级，或一段代际范围。
- `hierarchy` — 要沿用的备用层次结构。默认为 `"main"`。
- `exclude` — 要排除的节点，连同其下的所有内容：一个节点、一个列表或一个单元格区域。起始节点永远不会被排除。
- `expand` — 要同时显示其子节点的节点，即使超出 `drill_key` 所要求的深度：一个节点、一个列表或一个单元格区域。只有钻取显示出来的节点才会被展开，因此要展开孙节点，也请列出其父节点。
- `orientation` — `"vertical"`（默认）表示沿列向下列出节点，`"horizontal"` 表示沿行横向列出，不缩进，并按列分组。任何其他值都会报错。

`exclude` 和 `expand` 接受文本或数字形式的节点 ID；区域中的空单元格和错误会被忽略。将参数留空（`""`）即可跳过，如 `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`。

例如，`=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` 会列出 **Total**，然后是其下的每个叶区域。

[钻取命令](/zh-cn/reference/cli/plaidxl/drill/)会为您编写和编辑 `DRILL` 公式：选中一个节点，然后向下钻取、向上钻取、保留或移除节点。

## 值

`CELL` 和 `CELLS` 计算一个度量（表中的数值列），汇总到您在一个或多个维度中选择的节点。可以把每次调用看作报表中的一个交叉点：**EMEA** 在 **FY2026** 的**收入**。

您使用下面的构建块函数（通常放在各自的单元格中）来描述交叉点，然后以任意顺序将这些单元格传给 `CELL` 或 `CELLS`：

| 参数 | 构建方式 | 是否必需 |
|---|---|---|
| 要读取的表 | [`TABLE_REPR`](#table_repr) | 恰好一个 |
| 要聚合的列 | `CELL` 用 [`MEASURE`](#measure)，`CELLS` 用 [`MEASURES`](#measures) 或多个 `MEASURE` 单元格 | 是 |
| 如何聚合 | [`MEASURE_TYPE`](#measure_type) | 否 — 默认为 `sum` |
| 对某一列的筛选器 | [`DIMENSION_REPR`](#dimension_repr) | 至少一个，每列一个 |

每个筛选器指定**表的一个列**和一个值。当该列在 PlaidCloud 中与某个维度关联时，该值是一个节点，筛选器包含在维度的主层次结构（或您指定的层次结构）中汇总到该节点的所有内容：在与地理维度关联的**区域**列上，节点 **EMEA** 涵盖其下的每个国家/地区。在未与维度关联的列上，筛选器按值精确匹配。

本页的示例使用的表，其 **Region** 和 **Period** 列与维度关联。请使用您自己表的列名。

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

返回一个数字：对落在您传入的每个节点之下的行聚合得到的度量。

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` 显示 EMEA 在 FY2026 的总收入。

在 `CELL` 上键入数字即可将其写入 PlaidCloud。请参阅[向 PlaidCloud 键入值](/zh-cn/reference/cli/plaidxl/write-values/)。

充满 `CELL` 公式的工作表计算很快：一起计算的 `CELL` 公式会在一个请求中发送到 PlaidCloud，每次最多 10,000 个，并且 PlaidXL 会将表的列详细信息复用 30 秒，而不是为每个单元格都重新获取。如果某个值无法计算，单元格会显示 `#VALUE!`，将鼠标悬停其上会显示 PlaidCloud 报告的原因，例如表中没有的筛选列，或没有成员的节点。`CELLS` 会为整个结果显示第一个原因。

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

与 `CELL` 类似，但一次处理多个度量。每个度量返回一个数字，沿列向下，顺序与您列出的顺序一致。

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` 传入 `MEASURES` 的整个溢出结果。`B2:B4` 显示 EMEA 在 FY2026 的收入、成本和数量。

## 指标

`METRIC` 和 `METRIC_BREAKDOWN` 从工作簿的项目读取[指标定义](/zh-cn/integrations/ai-coding-agents/metric-definitions/)：一个业务数字，例如 *Net Revenue*，其计算方式已在 PlaidCloud 中约定并记录。该值与仪表板显示的一致，并按您自己的行访问权限计算。功能区上的 **Metric...** 会列出项目的指标及其当前值，并为您编写公式；请参阅[插入指标](#插入指标)。

筛选器是 [`DIMENSION_REPR`](#dimension_repr) 值，与 `CELL` 相同，只是第一个参数指定的是指标可以按其拆分的列。节点包含其下的所有内容。可以传入单个筛选器，或它们的区域或列表；空筛选器会被忽略。一个公式可以使用一个备用层次结构。

### METRIC

`=PLAIDXL.METRIC(name, [filter], ...)`

返回一个数字：对满足您传入的每个筛选器的行计算的指标。

- `name` — 指标的名称、其某个同义词或其 ID。不区分大小写。
- `filter` — 一个 `DIMENSION_REPR` 筛选器。可按需传入多个。

```text
=PLAIDXL.METRIC("Net Revenue", PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA"))
```

没有行匹配时，`METRIC` 返回 `0`；指标没有值时，单元格为空白。

### METRIC_BREAKDOWN

`=PLAIDXL.METRIC_BREAKDOWN(name, breakdown, [filter], ...)`

返回按一列拆分的指标：共两列，`breakdown` 的每个成员与其值并排，值最大的在前，没有标题行。

- `name` — 指标的名称、其某个同义词或其 ID。
- `breakdown` — 用于拆分指标的列，必须是指标可以按其拆分的列。
- `filter` — 一个 `DIMENSION_REPR` 筛选器。可按需传入多个。

```text
=PLAIDXL.METRIC_BREAKDOWN("Net Revenue", "Region")
```

没有值的成员排在最后，值为空白。没有行匹配时，它返回一行：空成员和 `0`。

### 指标错误

无法计算的指标会显示 `#VALUE!`；将鼠标悬停在单元格上可查看原因：

| 消息 | 操作 |
|---|---|
| 未知的指标，或未知的列 | 检查名称。有相近的匹配项时，消息会在 **Did you mean** 之后列出它们。 |
| 该名称匹配多个指标 | 使用指标的全名或其 ID。 |
| **Your PlaidCloud role doesn't allow reading metrics in this project.** | 请向项目所有者申请访问权限。 |
| **This PlaidCloud workspace doesn't serve metrics to Excel yet.** | 请让管理员更新该工作区。 |
| **PlaidCloud is busy; try again in** 若干秒 | PlaidXL 已经重试过。请在给出的时间之后重新计算。 |
| **Choose a project in the PlaidXL pane first.** | 将工作簿关联到某个项目。 |

## 构建块

这些函数本身不读取数据。每个函数返回一小段文本，描述计算的某一部分，可直接传给 `CELL`、`CELLS` 或 `DRILL`。请把它们放在被引用的单元格中，这样一处更改（例如换一个期间）就会更新所有使用它们的公式。

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

`CELL` 和 `CELLS` 读取的表，按其在所选项目中的名称指定。

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

`CELL` 聚合的数值列。

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

供 `CELLS` 使用的多个度量列，来自包含列名的单元格区域。结果每列溢出一个单元格；请用溢出运算符（如 `D2#`）将其传给 `CELLS`。

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

如何聚合度量。`agg_function` 是以下之一，使用小写：

| 值 | 返回 |
|---|---|
| `sum` | 总和（未传入度量类型时的默认值） |
| `mean` | 平均值 |
| `median` | 中位数 |
| `min` | 最小值 |
| `max` | 最大值 |
| `std` | 标准差 |
| `var` | 方差 |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node, [hierarchy])`

`CELL`、`CELLS`、`METRIC` 和 `METRIC_BREAKDOWN` 的筛选器。要按哪一列筛选，就为该列传入一个。

- `dimension_name` — **表中某一列**的名称，即保存该维度值的列，例如 `"Region"`。它必须与列名完全一致；表中没有的列会返回错误。
- `start_node` — 要汇总到的节点，例如 `"EMEA"`。在未与维度关联的列上，则为要匹配的值。
- `hierarchy` — 节点汇总时经过的备用层次结构。默认为 `"main"`。

引用某个单元格作为节点即可构建网格：`=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`。前导和尾随空格会被忽略，因此可以指向 `DRILL` 布局出的带缩进的节点名称。

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

[`DRILL`](#drill) 在其起始节点下方深入多远。`d_key` 是纯文本，可以是文字形式，也可以是写出的钻取键：

| `d_key` | 钻取到 |
|---|---|
| `"all"` | 每个后代 |
| `"leaves"` | 仅叶节点，即其下没有任何节点的节点 |
| `"1 level"`、`"2 levels"`、… | 向下那么多代 |
| `">[...]"` | 写出的钻取键，如下表所示 |

数字请用阿拉伯数字：`"2 levels"`，而不是 `"two levels"`。开头的 `drill` 会被忽略，因此 `"drill 2 levels"` 也可使用。

写出的键从起始节点开始向下计算代数，起始节点是第 0 代且始终包含在内。负数从每个分支的叶节点向上计算，因此不规则的层次结构也能按预期工作。

| 键 | 包含 |
|---|---|
| `>[*]` 或 `>[:]` | 每个节点 |
| `>[]` 或 `>[-1]` | 仅叶节点 |
| `>[n]` | 起始节点及其下方 `n` 代。`>[0]` 仅为起始节点。 |
| `>[a:]` | 起始节点，然后是第 `a` 代及其下的所有内容 |
| `>[a:b]` | 起始节点，然后是第 `a` 代到第 `b - 1` 代 |
| `>[0:-k]` | 起始节点和其下至少还有 `k` 代的每个节点，因此每个分支的最后 `k` 代会被去掉。`>[0:-1]` 是除叶节点之外的每个节点。 |
| `>[a:-k]` | 同上，但从第 `a` 代开始 |

对于层次结构 `A`，其子节点为 `B`、`C` 和 `D`，其中 `B` 有 `B1` 和 `B2`，`C` 有 `C1`：

| 键 | 结果 |
|---|---|
| `>[1]` | `A`、`B`、`C`、`D` |
| `>[2]` | `A`、`B`、`B1`、`B2`、`C`、`C1`、`D` |
| `>[]` | `A`、`B1`、`B2`、`C1`、`D` |
| `>[0:-1]` | `A`、`B`、`C` |
| `>[2:]` | `A`、`B1`、`B2`、`C1` |

节点按层次结构顺序列出，每个节点位于其父节点之下，Excel 分级显示组也遵循相同顺序。键内的空格会被忽略。不符合上述形式的键会返回一个列出有效形式的错误。

<Aside type="caution">
`>[-1]` 和 `>[0:-1]` 的含义与早期版本的 PlaidXL 不同，早期版本中它们是相反的。现在 `>[-1]` 只返回叶节点，`>[0:-1]` 返回除叶节点之外的所有节点。请检查所有手写钻取键的工作簿。文字形式 `"all"`、`"leaves"` 和 `"2 levels"` 保持不变。
</Aside>

<Aside type="note">
`CELL`、`CELLS` 和 `DRILL` 需要这些构建块函数的输出。请用相应的函数构建每个参数，而不要自己输入文本。
</Aside>

## 从任务窗格插入公式

任务窗格的 **Formulas** 选项卡可为您编写公式。可从任务窗格打开它，也可使用功能区上的 **Formula...**，或 **PlaidXL** 右键菜单上的 **Insert formula here...**。在 **What do you want in the cell?** 下选择其中一项：

- **A whole table**（`GET_TABLE`） — 选择或输入表，还可选择输入最大行数。
- **One number**（`CELL`） — 选择或输入表，选择 **Column to total** 和 **How to combine the values**。
- **A list of dimension nodes**（`DRILL`） — 选择或输入维度和起始节点，选择钻取深度，还可选择**备用层次结构**、要排除的节点和要展开的节点。**行**会预览钻取列出的节点。请参阅[自定义钻取](/zh-cn/reference/cli/plaidxl/drill/#自定义钻取)。
- **A business metric**（`METRIC`） — 请参阅[插入指标](#插入指标)。

**Formula** 预览会在您填写字段时显示结果。点击 **Insert in active cell**（或按 **Ctrl+Enter**）将其放入所选单元格，或点击**复制**自行粘贴。在**表**选项卡上选择表，或在**维度**选项卡上选择维度，会填入相应的字段。

### 插入指标

点击功能区**插入**组中的 **Metric...**，或在 **Formulas** 选项卡上选择 **A business metric**。

1. 在 **Metric** 中输入指标名称或同义词的一部分，例如 `revenue`。每个匹配项都会显示其当前值和说明。
2. 使用方向键或点击选择一个指标。
3. 可选：添加筛选器：选择**维度**，输入**节点**，然后点击**添加筛选器**。
4. 可选：在 **Breakdown by (optional)** 下选择一列，以编写 `METRIC_BREAKDOWN` 而不是单个数字。
5. 点击 **Insert in active cell** 或**复制**。
