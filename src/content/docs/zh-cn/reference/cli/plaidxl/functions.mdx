PlaidXL 为 Excel 添加了可将 PlaidCloud 数据直接读入单元格的函数。在单元格中输入 `=PLAIDXL.`，Excel 的自动完成会列出这些函数，并附有每个参数的简短说明。任务窗格的 **Formulas** 选项卡也可以为您编写公式；请参阅[从任务窗格插入公式](#从任务窗格插入公式)。

| 分组 | 函数 | 用途 |
|---|---|---|
| 列表 | [`LIST_PROJECTS`](#list_projects)、[`TABLE.TBL_LIST`](#tbl_list)、[`TABLE.GET_COLUMNS`](#get_columns)、[`DIMENSION.DIM_LIST`](#dim_list) | 查看有哪些内容可供构建 |
| 表 | [`TABLE.GET_TABLE`](#get_table) | 将整个表读入一个区域 |
| 层次结构 | [`DIMENSION.GET_DIMENSION`](#get_dimension)、[`DRILL`](#drill) | 将维度的节点布置为报表行 |
| 值 | [`CELL`](#cell)、[`CELLS`](#cells) | 为任意节点组合计算汇总值 |
| 构建块 | [`REPR.TABLE_REPR`](#table_repr)、[`REPR.MEASURE`](#measure)、[`REPR.MEASURES`](#measures)、[`REPR.MEASURE_TYPE`](#measure_type)、[`REPR.DIMENSION_REPR`](#dimension_repr)、[`REPR.DRILL_KEY`](#drill_key) | 描述 `CELL`、`CELLS` 和 `DRILL` 所使用的表、度量、聚合方式、节点和钻取深度 |

[使用自定义函数构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)展示了这些函数如何协同工作。

## 函数的工作方式

- **先登录。** 这些函数使用您的 PlaidCloud 登录状态读取数据，因此在使用之前，请先从任务窗格[登录](/zh-cn/reference/cli/plaidxl/connect/)。
- **它们从工作簿的项目中读取。** 每个函数都从在任务窗格中与工作簿关联的项目读取。`GET_TABLE`、`TBL_LIST` 和 `DIM_LIST` 还接受可选的项目 ID，以便在不更改关联的情况下读取另一个项目。每个工作簿都有自己的项目，因此同时打开的两个工作簿可以读取不同的项目。
- **结果会溢出。** 返回列表或表的函数会填充其下方（或右侧）的单元格。请为结果留出空间；如果有内容挡住，Excel 会显示 `#SPILL!` 错误。
- **重新计算以获取更改。** 当 PlaidXL 公式的某个参数发生变化时，它会重新提取数据。若要获取 PlaidCloud 中的新数据，或在任务窗格中关联的另一个项目，请强制完全重新计算——在 Windows 上，按 **Ctrl+Alt+F9**。**Refresh All Tables** 刷新的是已检索的表，而不是公式。
- **使用准确的名称。** 输入表、列、维度和节点名称时，请与 PlaidCloud 中显示的完全一致。

方括号中的参数是可选的。

## 列表

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

列出您可以打开的项目名称，按名称排序。

- `horizontal`——`TRUE` 表示横向列出，占一行。默认为 `FALSE`，即占一列。

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

列出项目中的表名称，按名称排序。

- `project_id`——要读取的项目。默认为工作簿的项目。
- `horizontal`——`TRUE` 表示横向列出，占一行。默认为 `FALSE`，即占一列。

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

列出所选项目中某个表的列名称。

- `table_name`——表在 PlaidCloud 中的名称。
- `column_filter`——数据类型，例如 `"text"`，只列出该类型的列。省略则列出每一列。
- `orientation`——`"vertical"`（默认）表示占一列，`"horizontal"` 表示占一行。

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

列出项目中的维度名称。

- `project_id`——要读取的项目。默认为工作簿的项目。
- `horizontal`——`TRUE` 表示横向列出，占一行。默认为 `FALSE`，即占一列。

## 表

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

返回表的行及标题行，从公式所在的单元格开始溢出。空值会作为空白单元格返回。

- `table_name`——表在 PlaidCloud 中的名称。
- `project_id`——要读取的项目。默认为工作簿的项目。
- `limit`——最多返回的行数。默认为 1,048,575，即工作表在标题行下方最多可容纳的行数。

`GET_TABLE` 会返回每一列。若要选择列或筛选行，请改为[从任务窗格检索表](/zh-cn/reference/cli/plaidxl/retrieve/#检索表)。

## 层次结构

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

布置维度的节点，从 `start_node` 开始，向下遍历其后代。每一层代比其父节点多缩进四个空格，Excel 大纲分组可让您折叠和展开每个级别。

- `dimension_name`——维度的名称，或其在项目中的路径。
- `start_node`——起始节点，例如维度的根节点。
- `hierarchy`——要遵循的[备用层次结构](/zh-cn/guides/dimensions/dimensions/#备用属性层次结构)。默认为 `"main"`。
- `orientation`——`"vertical"`（默认）表示沿列向下列出节点，`"horizontal"` 表示沿行向右列出。
- `generation_limit`——要返回的层代数，将 `start_node` 计为第一层：`2` 表示返回起始节点及其子节点。省略则返回每一层代。

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

沿一列返回 `start_node` 及 `drill_key` 所要求的其下节点，按层代缩进，并分组到 Excel 大纲中。

- `dimension_name`——维度的名称，或其在项目中的路径。
- `start_node`——要从其开始钻取的节点。
- `drill_key`——钻取的深度，来自 [`DRILL_KEY`](#drill_key)：所有后代、仅叶子节点、若干级别，或一段层代范围。
- `hierarchy`——要遵循的备用层次结构。默认为 `"main"`。

例如，`=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` 会列出 **Total**，后面跟着其下的每个叶子区域。

[功能区上的展开命令](/zh-cn/reference/cli/plaidxl/ribbon/#钻取函数)对您在两个单元格中输入的维度和节点执行相同的操作，无需编写公式。

## 值

`CELL` 和 `CELLS` 计算度量——表的数值列——并汇总到您在一个或多个维度中选择的节点。可以将每次调用看作报表中的一个交叉点：**FY2026** 中 **EMEA** 的**收入**。

您使用下面的构建块函数来描述交叉点，通常放在各自的单元格中，然后以任意顺序将这些单元格传给 `CELL` 或 `CELLS`：

| 参数 | 构建方式 | 是否必需 |
|---|---|---|
| 要读取的表 | [`TABLE_REPR`](#table_repr) | 恰好一个 |
| 要聚合的列 | `CELL` 使用 [`MEASURE`](#measure)，`CELLS` 使用 [`MEASURES`](#measures) 或多个 `MEASURE` 单元格 | 是 |
| 如何聚合 | [`MEASURE_TYPE`](#measure_type) | 否——默认为 `sum` |
| 对某一列的筛选 | [`DIMENSION_REPR`](#dimension_repr) | 至少一个，每列一个 |

每个筛选器都会指定**表中的一列**和一个值。当该列已在 PlaidCloud 中链接到某个维度时，该值是一个节点，筛选器会包含在该维度主层次结构中汇总到该节点的所有内容——在链接到地理维度的**区域**列上，节点 **EMEA** 涵盖其下的每个国家。在未链接到维度的列上，筛选器会精确匹配该值。

本页的示例使用的表，其 **Region** 和 **Period** 列已链接到维度。请使用您自己的表的列名。

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

返回一个数字：对您传入的每个节点之下的行聚合得到的度量值。

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` 显示 FY2026 中 EMEA 的总收入。

满是 `CELL` 公式的工作表重新计算很快：当一次重新计算要求从同一个表获取许多值时，PlaidXL 会将它们一并发送到 PlaidCloud，而不是每个单元格发送一次请求。如果某个值无法计算，该单元格会显示 `#VALUE!`，将鼠标悬停其上会显示 PlaidCloud 报告的原因，例如筛选列不在表中，或节点没有成员。`CELLS` 会为整个结果显示第一个原因。

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

与 `CELL` 类似，但可一次处理多个度量。每个度量返回一个数字，沿列向下排列，顺序与您列出的顺序一致。

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` 传入 `MEASURES` 的整个溢出结果。`B2:B4` 显示 FY2026 中 EMEA 的收入、成本和数量。

## 构建块

这些函数本身不读取数据。每个函数返回一小段文本，用于描述计算的某一部分，可直接传给 `CELL`、`CELLS` 或 `DRILL`。请将它们放在您引用的单元格中，这样一处更改——例如换一个期间——就会更新使用它们的每个公式。

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

`CELL` 和 `CELLS` 所读取的表，按其在所选项目中的名称指定。

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

`CELL` 所聚合的数值列。

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

供 `CELLS` 使用的多个度量列，来自保存列名的单元格区域。结果每列溢出一个单元格；请使用溢出运算符（例如 `D2#`）将其传给 `CELLS`。

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

如何聚合度量。`agg_function` 是以下之一，且为小写：

| 值 | 返回 |
|---|---|
| `sum` | 总和（未传入度量类型时的默认值） |
| `mean` | 平均值 |
| `median` | 中位数 |
| `min` | 最小值 |
| `max` | 最大值 |
| `std` | 标准差 |
| `var` | 方差 |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

`CELL` 和 `CELLS` 的筛选器。对于每个要筛选的列，各传入一个。

- `dimension_name`——**表中某一列**的名称，即保存维度值的列，例如 `"Region"`。它必须与列名完全一致；不在表中的列会返回错误。
- `start_node`——要汇总到的节点，例如 `"EMEA"`。在未链接到维度的列上，则为要匹配的值。

引用某个单元格作为节点即可构建网格：`=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`。前导和尾随空格会被忽略，因此可以指向 `DRILL` 布置出的带缩进的节点名称。

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

[`DRILL`](#drill) 在其起始节点之下走多远。`d_key` 是纯文本，可以是文字形式，也可以是写出的钻取键：

| `d_key` | 钻取到 |
|---|---|
| `"all"` | 每个后代 |
| `"leaves"` | 仅叶子节点，即其下没有任何节点的节点 |
| `"1 level"`、`"2 levels"`…… | 向下这么多层代 |
| `">[...]"` | 写出的钻取键，如下表所示 |

请用数字写出数目：`"2 levels"`，而不是 `"two levels"`。开头的 `drill` 会被忽略，因此 `"drill 2 levels"` 也有效。

写出的键从起始节点向下计算层代，起始节点为第 0 层，始终包含在内。负数则从每个分支的叶子节点向上计数，因此不规则层次结构的行为符合您的预期。

| 键 | 包含 |
|---|---|
| `>[*]` 或 `>[:]` | 每个节点 |
| `>[]` 或 `>[-1]` | 仅叶子节点 |
| `>[n]` | 起始节点及其下 `n` 层代。`>[0]` 仅为起始节点。 |
| `>[a:]` | 起始节点，然后是第 `a` 层代及其以下的所有内容 |
| `>[a:b]` | 起始节点，然后是第 `a` 层代到第 `b - 1` 层代 |
| `>[0:-k]` | 起始节点，以及其下至少还有 `k` 层代的每个节点，因此每个分支的最后 `k` 层代会被排除。`>[0:-1]` 是除叶子节点之外的每个节点。 |
| `>[a:-k]` | 同上，但从第 `a` 层代开始 |

对于层次结构 `A`，其子节点为 `B`、`C` 和 `D`，其中 `B` 有 `B1` 和 `B2`，`C` 有 `C1`：

| 键 | 结果 |
|---|---|
| `>[1]` | `A`、`B`、`C`、`D` |
| `>[2]` | `A`、`B`、`B1`、`B2`、`C`、`C1`、`D` |
| `>[]` | `A`、`B1`、`B2`、`C1`、`D` |
| `>[0:-1]` | `A`、`B`、`C` |
| `>[2:]` | `A`、`B1`、`B2`、`C1` |

节点按层次结构顺序列出，每个节点位于其自己的父节点之下，Excel 大纲分组遵循相同的顺序。键内的空格会被忽略。与这些形式都不匹配的键会返回一个错误，其中列出有效的形式。

<Aside type="caution">
`>[-1]` 和 `>[0:-1]` 的含义与早期版本的 PlaidXL 不同，早期版本中它们是反过来的。现在 `>[-1]` 仅返回叶子节点，`>[0:-1]` 返回除叶子节点之外的所有节点。请检查任何手动写出钻取键的工作簿。文字形式 `"all"`、`"leaves"` 和 `"2 levels"` 保持不变。
</Aside>

<Aside type="note">
`CELL`、`CELLS` 和 `DRILL` 需要这些构建块函数的输出。请用相应的函数来构建每个参数，而不要自己输入文本。
</Aside>

## 从任务窗格插入公式

任务窗格的 **Formulas** 选项卡可以为您编写公式。在 **What do you want in the cell?** 下，选择其中一项：

- **A whole table**（`GET_TABLE`）——选择或输入表，还可以选择输入最大行数。
- **One number**（`CELL`）——选择或输入表，选择 **Column to total** 和 **How to combine the values**。
- **A list of dimension nodes**（`DRILL`）——选择或输入维度和起始节点，选择 **All levels**、**Lowest level only**，或向下若干个 **levels** 的 **Down**，还可以选择 **Alternate hierarchy**。

**Formula** 预览会随着您填写字段显示结果。单击 **Insert in active cell** 可将其放入所选单元格，或单击**复制**自行粘贴。在**表**选项卡上选择表，或在**维度**选项卡上选择维度，会填入相应的字段。
