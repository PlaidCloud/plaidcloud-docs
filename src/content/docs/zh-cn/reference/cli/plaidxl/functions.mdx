PlaidXL 为 Excel 添加了一些函数，可将 PlaidCloud 数据直接读入单元格。在单元格中输入 `=PLAIDXL.`，Excel 的自动完成功能会列出这些函数，并附上每个参数的简短说明。任务窗格的 **Formulas** 选项卡也可以为您编写公式，参见[从任务窗格插入公式](#从任务窗格插入公式)。

| 分组 | 函数 | 用途 |
|---|---|---|
| 列表 | [`LIST_PROJECTS`](#list_projects)、[`TABLE.TBL_LIST`](#tbl_list)、[`TABLE.GET_COLUMNS`](#get_columns)、[`DIMENSION.DIM_LIST`](#dim_list) | 查看可用于构建的内容 |
| 表 | [`TABLE.GET_TABLE`](#get_table) | 将整个表读入一个区域 |
| 层次结构 | [`DIMENSION.GET_DIMENSION`](#get_dimension)、[`DRILL`](#drill) | 将维度的节点布局为报表行 |
| 值 | [`CELL`](#cell)、[`CELLS`](#cells) | 为任意节点组合计算汇总值 |
| 构建块 | [`REPR.TABLE_REPR`](#table_repr)、[`REPR.MEASURE`](#measure)、[`REPR.MEASURES`](#measures)、[`REPR.MEASURE_TYPE`](#measure_type)、[`REPR.DIMENSION_REPR`](#dimension_repr)、[`REPR.DRILL_KEY`](#drill_key) | 描述 `CELL`、`CELLS` 和 `DRILL` 使用的表、度量、聚合方式、节点和钻取深度 |

[使用自定义函数构建报表](/zh-cn/reference/cli/plaidxl/build-a-report/)展示了这些函数如何配合使用。

## 函数的工作方式

- **先登录。** 这些函数使用您的 PlaidCloud 登录信息读取数据，因此使用前请先从任务窗格[登录](/zh-cn/reference/cli/plaidxl/connect/)。
- **从工作簿的项目读取。** 每个函数都从任务窗格中与工作簿关联的项目读取数据。`GET_TABLE`、`TBL_LIST` 和 `DIM_LIST` 还接受可选的项目 ID，可在不更改关联的情况下读取其他项目。每个工作簿都有自己的项目，因此两个同时打开的工作簿可以读取不同的项目。
- **结果会溢出。** 返回列表或表的函数会填充其下方（或右侧）的单元格。请留出足够空间放置结果；如果有内容挡住，Excel 会显示 `#SPILL!` 错误。
- **重新计算以获取更改。** 当某个参数发生变化时，PlaidXL 公式会重新获取数据。若要获取 PlaidCloud 中的新数据，或任务窗格中关联的其他项目，请强制完全重新计算：在 Windows 上，按 **Ctrl+Alt+F9**。**Refresh All Tables** 刷新的是已检索的表，而不是公式。
- **使用准确的名称。** 输入表、列、维度和节点名称时，须与 PlaidCloud 中显示的完全一致。

方括号中的参数为可选参数。

## 列表

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

列出您可以打开的项目的名称，按名称排序。

- `horizontal` — 设为 `TRUE` 则沿一行列出。默认为 `FALSE`，即沿一列列出。

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

列出项目中表的名称，按名称排序。

- `project_id` — 要读取的项目。默认为工作簿的项目。
- `horizontal` — 设为 `TRUE` 则沿一行列出。默认为 `FALSE`，即沿一列列出。

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

列出所选项目中某个表的列名。

- `table_name` — 表在 PlaidCloud 中的名称。
- `column_filter` — 数据类型，例如 `"text"`，仅列出该类型的列。省略则列出所有列。
- `orientation` — `"vertical"`（默认）表示沿一列列出，`"horizontal"` 表示沿一行列出。

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

列出项目中维度的名称。

- `project_id` — 要读取的项目。默认为工作簿的项目。
- `horizontal` — 设为 `TRUE` 则沿一行列出。默认为 `FALSE`，即沿一列列出。

## 表

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

返回表的各行及标题行，从公式所在单元格开始溢出。空值以空白单元格返回。

- `table_name` — 表在 PlaidCloud 中的名称。
- `project_id` — 要读取的项目。默认为工作簿的项目。
- `limit` — 返回的最大行数。默认为 1,048,575，即工作表在标题行之下最多可容纳的行数。

`GET_TABLE` 返回所有列。若要选择列或筛选行，请改为[从任务窗格检索该表](/zh-cn/reference/cli/plaidxl/retrieve/#检索表)。

## 层次结构

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

布局维度的节点，从 `start_node` 开始，向下遍历其所有后代。每一代比其父级多缩进四个空格，并且 Excel 分级显示组可让您折叠和展开每个级别。

- `dimension_name` — 维度的名称，或其在项目中的路径。
- `start_node` — 起始节点，例如维度的根节点。
- `hierarchy` — 要遵循的[备用层次结构](/zh-cn/guides/dimensions/dimensions/#备用属性层次结构)。默认为 `"main"`。
- `orientation` — `"vertical"`（默认）表示将节点沿一列向下列出，`"horizontal"` 表示沿一行向右列出。
- `generation_limit` — 返回的代数，`start_node` 算作第一代：`2` 返回起始节点及其子节点。省略则返回所有代。

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

沿一列返回 `start_node` 以及 `drill_key` 所要求的其下节点，按代缩进，并以 Excel 分级显示分组。

- `dimension_name` — 维度的名称，或其在项目中的路径。
- `start_node` — 开始钻取的节点。
- `drill_key` — 钻取的深度，来自 [`DRILL_KEY`](#drill_key)：所有后代、仅叶节点、若干级别，或一个代数范围。
- `hierarchy` — 要遵循的备用层次结构。默认为 `"main"`。

例如，`=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` 会列出 **Total**，后面跟着其下的每个叶节点区域。

[功能区上的展开命令](/zh-cn/reference/cli/plaidxl/ribbon/#drill-functions)可对您在两个单元格中输入的维度和节点执行相同的操作，无需编写公式。

## 值

`CELL` 和 `CELLS` 计算度量（表中的数值列），并汇总到您在一个或多个维度中选择的节点。可以把每次调用看作报表中的一个交叉点：**EMEA** 在 **FY2026** 的**收入**。

您可以使用下面的构建块函数（通常放在各自的单元格中）来描述交叉点，然后以任意顺序将这些单元格传给 `CELL` 或 `CELLS`：

| 参数 | 构建方式 | 是否必需 |
|---|---|---|
| 要读取的表 | [`TABLE_REPR`](#table_repr) | 恰好一个 |
| 要聚合的列 | `CELL` 使用 [`MEASURE`](#measure)，`CELLS` 使用 [`MEASURES`](#measures) 或多个 `MEASURE` 单元格 | 是 |
| 聚合方式 | [`MEASURE_TYPE`](#measure_type) | 否，默认为 `sum` |
| 对某一列的筛选器 | [`DIMENSION_REPR`](#dimension_repr) | 至少一个，每列一个 |

每个筛选器指定**表中的一列**和一个值。当该列在 PlaidCloud 中链接到某个维度时，该值是一个节点，筛选器会包含在该维度的主层次结构中汇总到此节点的所有内容：在链接到地理维度的 **Region** 列上，节点 **EMEA** 涵盖其下的每个国家。对于未链接到维度的列，筛选器会精确匹配该值。

本页中的示例使用的表，其 **Region** 和 **Period** 列链接到了维度。请使用您自己表中的列名。

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

返回一个数字：度量，在属于您传入的每个节点之下的行上聚合。

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` 显示 EMEA 在 FY2026 的总收入。

包含大量 `CELL` 公式的工作表，每个单元格所需的查找更少，因为 PlaidXL 会在短时间内重用表的列详细信息，而不是为每个单元格都重新获取。如果无法计算某个值，单元格会显示 `#VALUE!`，将鼠标悬停其上会显示 PlaidCloud 报告的原因，例如筛选列不在表中，或节点没有成员。`CELLS` 会为整个结果显示第一个原因。

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

与 `CELL` 类似，但一次处理多个度量。每个度量返回一个数字，沿一列向下，顺序与您列出的顺序一致。

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` 传入 `MEASURES` 的整个溢出结果。`B2:B4` 显示 EMEA 在 FY2026 的收入、成本和数量。

## 构建块

这些函数本身不读取数据。每个函数返回一小段文本，描述计算的某一部分，可直接传给 `CELL`、`CELLS` 或 `DRILL`。请将它们放在您引用的单元格中，这样只需更改一处（例如换一个期间），就会更新所有使用它们的公式。

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

`CELL` 和 `CELLS` 读取的表，按其在所选项目中的名称指定。

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

`CELL` 聚合的数值列。

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

供 `CELLS` 使用的多个度量列，来自一个包含列名的单元格区域。结果会溢出，每列占一个单元格；使用溢出运算符（如 `D2#`）将其传给 `CELLS`。

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

度量的聚合方式。`agg_function` 为下列之一，使用小写：

| 值 | 返回 |
|---|---|
| `sum` | 总和（未传入度量类型时的默认值） |
| `mean` | 平均值 |
| `median` | 中位数 |
| `min` | 最小值 |
| `max` | 最大值 |
| `std` | 标准差 |
| `var` | 方差 |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

`CELL` 和 `CELLS` 的筛选器。对每个要筛选的列各传入一个。

- `dimension_name` — **表中某一列**的名称，即保存维度值的列，例如 `"Region"`。它必须与列名完全一致；不在表中的列会返回错误。
- `start_node` — 要汇总到的节点，例如 `"EMEA"`。对于未链接到维度的列，则是要匹配的值。

引用某个单元格作为节点即可构建网格：`=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`。前后的空格会被忽略，因此可以指向 `DRILL` 布局出的带缩进的节点名称。

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

[`DRILL`](#drill) 在其起始节点之下钻取多远。`d_key` 是纯文本，可以是文字形式，也可以是完整写出的钻取键：

| `d_key` | 钻取到 |
|---|---|
| `"all"` | 所有后代 |
| `"leaves"` | 仅叶节点，即其下没有任何节点的节点 |
| `"1 level"`、`"2 levels"`、… | 向下指定的代数 |
| `">[...]"` | 完整写出的钻取键，如下表所示 |

数字请用阿拉伯数字书写：`"2 levels"`，而不是 `"two levels"`。开头的 `drill` 会被忽略，因此 `"drill 2 levels"` 也可使用。

完整写出的键从起始节点向下计算代数，起始节点为第 0 代，并且始终包含在内。负数从每个分支的叶节点向上计算，因此不规则的层次结构也能按您预期的方式工作。

| 键 | 包含 |
|---|---|
| `>[*]` 或 `>[:]` | 每个节点 |
| `>[]` 或 `>[-1]` | 仅叶节点 |
| `>[n]` | 起始节点及其下 `n` 代。`>[0]` 仅为起始节点。 |
| `>[a:]` | 起始节点，然后是第 `a` 代及其下所有内容 |
| `>[a:b]` | 起始节点，然后是第 `a` 代至第 `b - 1` 代 |
| `>[0:-k]` | 起始节点以及其下至少还有 `k` 代的每个节点，因此每个分支的最后 `k` 代会被排除。`>[0:-1]` 是除叶节点外的所有节点。 |
| `>[a:-k]` | 同上，但从第 `a` 代开始 |

以层次结构 `A` 为例，其子节点为 `B`、`C` 和 `D`，其中 `B` 有 `B1` 和 `B2`，`C` 有 `C1`：

| 键 | 结果 |
|---|---|
| `>[1]` | `A`、`B`、`C`、`D` |
| `>[2]` | `A`、`B`、`B1`、`B2`、`C`、`C1`、`D` |
| `>[]` | `A`、`B1`、`B2`、`C1`、`D` |
| `>[0:-1]` | `A`、`B`、`C` |
| `>[2:]` | `A`、`B1`、`B2`、`C1` |

节点按层次结构顺序列出，每个节点位于其父节点之下，Excel 分级显示组也遵循相同的顺序。键中的空格会被忽略。与上述形式都不匹配的键会返回错误，并列出有效的形式。

<Aside type="caution">
`>[-1]` 和 `>[0:-1]` 的含义与早期版本的 PlaidXL 不同，早期版本中它们是相反的。现在 `>[-1]` 仅返回叶节点，`>[0:-1]` 返回除叶节点外的所有节点。请检查所有手写钻取键的工作簿。文字形式 `"all"`、`"leaves"` 和 `"2 levels"` 保持不变。
</Aside>

<Aside type="note">
`CELL`、`CELLS` 和 `DRILL` 需要这些构建块函数的输出。请使用相应的函数构建每个参数，而不是自己输入文本。
</Aside>

## 从任务窗格插入公式

任务窗格的 **Formulas** 选项卡可为您编写公式。在 **What do you want in the cell?** 下，选择以下之一：

- **A whole table**（`GET_TABLE`）— 选择或输入表，并可选择设置最大行数。
- **One number**（`CELL`）— 选择或输入表，选择 **Column to total** 和 **How to combine the values**。
- **A list of dimension nodes**（`DRILL`）— 选择或输入维度和起始节点，选择 **All levels**、**Lowest level only**，或 **Down** 若干个 **levels**，并可选择设置 **Alternate hierarchy**。

**Formula** 预览会在您填写字段时显示结果。单击 **Insert in active cell** 可将其放入所选单元格，或单击 **Copy** 自行粘贴。在 **Tables** 选项卡上选择表，或在 **Dimensions** 选项卡上选择维度，会填入相应的字段。
