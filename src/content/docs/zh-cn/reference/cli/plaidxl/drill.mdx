**Drill** 命令作用于单个单元格。它们会将一个节点转换为实时的 [`PLAIDXL.DRILL`](/zh-cn/reference/cli/plaidxl/functions/#drill) 公式，然后为您编辑该公式，使布局始终与维度保持关联，并在维度变化时更新。每个命令都位于 **PlaidCloud** 功能区选项卡、**PlaidXL** 右键菜单、**PlaidXL Cell** 选项卡和[键盘快捷键](/zh-cn/reference/cli/plaidxl/ribbon/#键盘快捷键)中。

## 从单元格向下钻取

1. 在单元格中输入维度的一个节点——如 `4000` 之类的 ID，或如 `Revenue` 之类的别名——并选中它。
2. 单击 **Drill down**，然后选择 **One level**、**To lowest level** 或 **All levels**。

该单元格会变成一个 `PLAIDXL.DRILL` 公式，沿列向下列出该节点及其下方的节点，按层代缩进，并分组到 Excel 大纲中，以便您折叠每一层。

PlaidXL 根据单元格上方最近的维度名称确定维度。如果没有，则使用您在该工作表上最后一次钻取的维度。您也可以并排选中两个单元格——一个维度名称和一个节点——钻取会放在节点所在的单元格中。

若要从维度的顶部开始，请选中包含维度名称的单元格，或其下方的空单元格：钻取会放在名称下方，并从维度的顶层节点开始。

### 在钻取内再次钻取

在现有钻取的某一行上使用相同的命令：

- **One level** 就地展开该行的子节点，列表的其余部分保持不变。
- **To lowest level** 和 **All levels** 从该行的节点重新开始钻取。
- **Drill up** 关闭该行上方最近的已展开节点。没有可关闭的节点时，则将钻取的起始节点上移到其父节点。

在包含节点但没有钻取的单元格上，**Drill up** 会将该节点替换为其父节点。

### 从报表值钻取

选中报表中的一个值——`CELL` 或 `CELLS` 公式——**Drill down one level** 会就地展开该值所在行的行标题，使报表在其下方增加下一层明细。**Drill up** 会再次将其关闭。当行标题不属于任何钻取，或就地钻取会导致报表丢失行（例如 **All levels**）时，PlaidXL 会改为打开已为您填好的 **Custom drill**。

### 覆盖与撤消

钻取在写入前不会询问。如果新行所需的单元格中已有内容，PlaidXL 会清除它们，并在消息中说明清除了多少个。每次钻取编辑都是一个 Excel 撤消步骤，因此 **Ctrl+Z** 可以恢复所有内容。任务窗格打开时，消息中还提供 **撤消**，它只还原仍保留钻取所写内容的单元格，并保留您之后所做的任何编辑。

Drill 命令编辑沿列向下的钻取。沿行横向的 `DRILL`——例如报表的列标题——需要在其公式中更改。

## 仅保留与仅移除

选中一个或多个钻取行（也可跨多个钻取），然后：

- **Remove only** 将所选节点及其下方的所有内容从钻取中移除。移除钻取的第一行会清除整个钻取。
- **Keep only** 仅保留所选节点。一个节点会变成仅包含该节点的钻取；多个节点则保留在其最近的共同父节点之下的位置。

两者都会更改钻取的 `exclude` 参数，因此结果保持实时。PlaidXL 最多读取 5,000 个选中的单元格。很长的被移除节点列表会移到名为 **PlaidXL Lists** 的隐藏工作表，公式会引用该工作表。

## 自定义钻取

**Custom drill...** 会在 **Formulas** 选项卡上打开 **A list of dimension nodes**，并根据所选单元格填好内容：

- **Start from node**——留空则从维度顶部开始。
- **How far to drill**——**All levels**、**Lowest level only**、**Down**（向下若干层）、**From level**（从一层到另一层）、**All but the last**（最后若干层除外）或 **Advanced (type the drill key)**（例如 `[1:3]`）。
- **Alternate hierarchy (optional)**。
- **Exclude nodes (optional, one id per line)** 和 **Open nodes (optional, one id per line)**——要排除的节点，以及同时显示其子节点的节点。

字段旁的 **Use selected cell** 会将其指向您选中的单元格或区域，使钻取跟随该单元格。**行** 预览前 10 个节点和总数；单击 **显示全部** 查看更多。单击 **Insert in active cell** 可更改您开始时所用的钻取，或在活动单元格中放入新的钻取；单击 **复制** 可自行粘贴公式。

## 选取成员

**Pick member...** 会针对所选单元格的维度打开成员选取器，并已按该单元格的文本搜索。您也可以从 **维度** 选项卡打开它。

- **Search id or alias** 搜索维度的所有层次结构，并显示每个匹配项的路径。
- 当维度有多个层次结构时，从列表中选择一个层次结构。
- 使用方向键浏览树，用 **空格** 勾选节点，按 **Enter** 插入。

**插入** 将节点的 ID 写入活动单元格并下移一行；若已勾选节点，则从活动单元格开始向下填充这些节点。**Fill down** 和 **Fill right** 将勾选的节点向下或向右写入。双击节点即可插入。如果活动单元格中有钻取，您插入的节点会成为钻取的起始节点。

插入会覆盖已有内容，说明替换了多少个已填充的单元格，并且是一个撤消步骤。

### 添加成员下拉列表

选中应提供选项的单元格——例如期间列——然后在成员选取器中指向一个节点，单击 **Add dropdown**。每个选中的单元格都会获得该节点子节点的下拉列表。该列表是隐藏的 **PlaidXL Lists** 工作表上的一个钻取，因此会随维度变化而更新。单元格保留其值，不在列表中的值仍然允许输入。

跟随实时列表的下拉列表需要 Microsoft 365 版 Excel 或 Excel 2024。**Ctrl+Z** 可移除下拉列表。

## 说明数字

**Explain this number** 会打开 **说明** 选项卡，为每个选中的 PlaidXL 单元格显示一张卡片。它可以说明 `CELL`、`CELLS`、`DRILL`、`TABLE.GET_TABLE`、`METRIC` 和 `METRIC_BREAKDOWN`，包括嵌套在 `IFERROR` 等其他公式中的情况。选中并非 PlaidXL 公式的单元格时，PlaidXL 会说明计算它所依据的 PlaidXL 单元格。

每张卡片显示：

- 该单元格计算的内容——例如，某个表中一列的总和，按每个节点筛选，并列出每个节点下的叶子成员数。
- 当前计算出的值，以及它是否与单元格一致。如果不一致，**Recalculate** 会将单元格更新到最新。
- **Where this comes from**——表数据的最近更新时间、行数，以及构建该表的工作流步骤，每项都链接到 PlaidCloud。
- **Open table in PlaidCloud**、**Drill through to rows** 和 **Copy explanation**。

筛选节点链接到 PlaidCloud 中的该节点，其 **Drill** 按钮会将该节点的子节点添加为行。当单元格显示错误时，卡片会说明原因，并在可能时提供修复方法——**选择项目**，或带有最接近匹配项的 **Pick a member**。

同时说明多个单元格时，卡片每次加载 20 张，末尾有一个按钮用于显示其余卡片。

## 显示明细行

**Show detail rows** 会将 `CELL` 或 `CELLS` 值背后的表行放到一个新工作表上，该工作表以节点和表命名。选中由 PlaidXL 值计算得出的单元格，PlaidXL 就会使用该值。

- 第 1 行描述该值，并链接回该值。
- 第 2 行检查各行加总后是否等于该值：显示 **ties**，或二者相差多少。
- 各行从第 3 行开始，作为 Excel 表。

加载各行时，任务窗格会显示进度并提供 **取消**。对同一个值再次运行 **Show detail rows** 会刷新该工作表，而 **Refresh all tables** 可使其保持最新。明细工作表可以[保存回 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)；保存时只会替换该值背后的行。

<Aside type="tip">
不确定某个单元格在做什么？选中它并按 **Ctrl+Alt+Shift+E**（Mac 上为 **⌘⌥⇧E**）进行说明，或按 **Ctrl+Alt+Shift+Q** 就此[询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。
</Aside>
