**Drill** 命令作用于单个单元格。它们会把节点转换为实时的 [`PLAIDXL.DRILL`](/zh-cn/reference/cli/plaidxl/functions/#drill) 公式，然后为您编辑该公式，使布局始终与维度保持连接，并在维度变化时更新。每个命令都位于 **PlaidCloud** 功能区选项卡、**PlaidXL** 右键菜单、**PlaidXL Cell** 选项卡以及[键盘快捷键](/zh-cn/reference/cli/plaidxl/ribbon/#键盘快捷键)中。

## 从单元格向下钻取

1. 在单元格中输入维度的某个节点（如 `4000` 之类的 ID，或 `Revenue` 之类的别名）并选中它。
2. 点击 **Drill down**，然后点击 **One level**、**To lowest level** 或 **All levels**。

该单元格会变成 `PLAIDXL.DRILL` 公式，沿列向下列出该节点及其下方的节点，按代际缩进，并分组到 Excel 分级显示中，因此可以折叠每一层级。

PlaidXL 根据单元格上方最近的维度名称确定维度。如果没有，则使用您上次在该工作表上钻取的维度。您也可以并排选择两个单元格（维度名称和节点），钻取会放在节点所在的单元格中。

要从维度顶部开始，请选中包含维度名称的单元格，或其下方的空单元格：钻取会从名称下方开始，并从维度的顶层节点起始。

### 在钻取中钻取

对现有钻取的某一行使用相同的命令：

- **One level** 就地展开该行的子节点，其余列表保持不变。
- **To lowest level** 和 **All levels** 从该行的节点重新开始钻取。
- **Drill up** 关闭该行上方最近的已展开节点。如果没有可关闭的节点，则把钻取的起始节点上移到其父节点。

在包含节点但没有钻取的单元格上，**Drill up** 会用其父节点替换该节点。

### 从报表值钻取

选中报表中的某个值（`CELL` 或 `CELLS` 公式），**Drill down one level** 会就地展开该值所在行的行标题，使报表在其下方增加下一级明细。**Drill up** 会再次将其关闭。如果行标题不属于钻取，或就地钻取会导致报表丢失行（如 **All levels** 的情况），PlaidXL 会改为打开已为您填好内容的 **Custom drill**。

### 覆盖和撤消

钻取在写入前从不询问。如果新行所需的单元格中已有内容，PlaidXL 会将其清除，并在消息中说明清除了多少个。如果您的 Excel 版本可以将该编辑合并为一组，则一次钻取只是一个撤消步骤，按 **Ctrl+Z** 即可恢复全部内容；在较旧的版本中可能需要多个步骤。打开任务窗格时，消息中还会提供**撤消**，它只还原仍保留钻取所写内容的单元格，并保留您之后所做的任何编辑。

钻取命令编辑沿列向下的钻取。沿行横向延伸的 `DRILL`（例如报表的列标题）需要在其公式中修改。

## Keep Only 和 Remove Only

选择钻取的一行或多行（也可跨多个钻取），然后：

- **Remove only** 将所选节点及其下方的所有内容从钻取中移除。移除钻取的第一行会清除该钻取。
- **Keep only** 只保留所选节点。一个节点会变成仅包含该节点的钻取；多个节点则保留在其最近的共同父节点之下的位置。

**Remove only** 会把节点添加到钻取的 `exclude` 参数中。**Keep only** 会重写钻取的起始节点、键和 `exclude`。无论哪种方式，结果都保持实时。PlaidXL 最多读取 5,000 个所选单元格。很长的已移除节点列表会移到名为 **PlaidXL Lists** 的隐藏工作表中，由公式引用。

## 自定义钻取

**Custom drill...** 会在 **A list of dimension nodes** 上打开 **Formulas** 选项卡，并根据所选单元格填入内容：

- **Start from node** — 留空则从维度顶部开始。
- **How far to drill** — **All levels**、**Lowest level only**、**Down** 若干层级、**From level** 从一个层级到另一个层级、**All but the last** 若干层级，或 **Advanced (type the drill key)**（如 `[1:3]`）。
- **Alternate hierarchy (optional)**。
- **Exclude nodes (optional, one id per line)** 和 **Open nodes (optional, one id per line)** — 要排除的节点，以及同时显示其子节点的节点。

字段旁的 **Use selected cell** 会让该字段指向您选中的单元格或区域，使钻取跟随该单元格。**行**会预览前 10 个节点和总数；点击**显示全部**可查看更多。点击 **Insert in active cell** 可更改您开始时所用的钻取，或在活动单元格中放入新钻取；点击**复制**可自行粘贴公式。

## 选取成员

**Pick member...** 会针对所选单元格的维度打开成员选取器，并已按单元格的文本搜索。您也可以从**维度**选项卡中打开它。

- **Search id or alias** 搜索维度的所有层次结构，并显示每个匹配项的路径。
- 当维度有多个层次结构时，从列表中选择一个层次结构。
- 用方向键浏览树，用**空格**勾选节点，按 **Enter** 插入。

**插入**会把节点的 ID 写入活动单元格并向下移动一行；勾选了节点时，则从活动单元格开始向下填充这些节点。**Fill down** 和 **Fill right** 会把勾选的节点向下或向右写入。双击节点即可插入。如果活动单元格中有钻取，插入的节点会成为该钻取的起始节点。

插入会覆盖原有内容，并说明替换了多少个已填充的单元格。消息中提供**撤消**，如果您的 Excel 版本可以将该编辑合并为一组，**Ctrl+Z** 可一步撤消。

### 添加成员下拉列表

选择应提供选项的单元格（例如期间列），然后在成员选取器中指向某个节点并点击 **Add dropdown**。每个所选单元格都会获得该节点子节点的下拉列表。该列表是隐藏的 **PlaidXL Lists** 工作表上的一个钻取，因此会随维度变化而更新。单元格会保留其值，不在列表中的值仍然允许。

跟随实时列表的下拉列表需要 Microsoft 365 版 Excel 或 Excel 2024。如果您的 Excel 版本可以将该编辑合并为一组，**Ctrl+Z** 可一步移除下拉列表。

## 说明数值

**Explain this number** 会打开**说明**选项卡，为每个所选的 PlaidXL 单元格显示一张卡片。它可以说明 `CELL`、`CELLS`、`DRILL`、`TABLE.GET_TABLE`、`METRIC` 和 `METRIC_BREAKDOWN`，包括嵌套在 `IFERROR` 等其他公式中的情况。选中不是 PlaidXL 公式的单元格时，PlaidXL 会说明该单元格所依据的 PlaidXL 单元格。

每张卡片显示：

- 该单元格计算的内容，例如表中某一列的总和（按每个节点筛选），以及每个节点下的叶成员数量。
- 当前计算的值，以及它是否与单元格一致。如果不一致，**Recalculate** 会让单元格保持最新。
- **Where this comes from** — 表数据上次更新的时间、行数，以及生成该表的工作流步骤，每项都链接到 PlaidCloud。
- **Open table in PlaidCloud**、**Drill through to rows** 和 **Copy explanation**。

筛选器节点会链接到 PlaidCloud 中的该节点，其 **Drill** 按钮会把该节点的子节点添加为行。单元格显示错误时，卡片会说明原因，并在可能时提供修复方法，如**选择项目**，或带有最接近匹配项的 **Pick a member**。

一次说明多个单元格时，卡片每次加载 20 张，末尾有一个按钮用于显示其余卡片。

## 显示明细行

**Show detail rows** 会把 `CELL` 或 `CELLS` 值背后的表行放到一个新工作表中，工作表以节点和表命名。选中由 PlaidXL 值计算得出的单元格时，PlaidXL 会使用该值。

- 第 1 行描述该值并链接回它。
- 第 2 行检查各行之和是否等于该值：显示 **ties**，或两者相差多少。
- 各行从第 3 行开始，作为 Excel 表格。

加载各行期间，任务窗格会显示进度和**取消**。对同一个值再次运行 **Show detail rows** 会刷新该工作表，**Refresh all tables** 可使其保持最新。明细工作表可以[保存回 PlaidCloud](/zh-cn/reference/cli/plaidxl/retrieve/#将表保存到-plaidcloud)；保存只会替换该值背后的行。

<Aside type="tip">
不确定某个单元格在做什么？选中它并按 **Ctrl+Alt+Shift+E**（Mac 上为 **⌘⌥⇧E**）进行说明，或按 **Ctrl+Alt+Shift+Q** 就此[询问 Weave](/zh-cn/reference/cli/plaidxl/weave/)。
</Aside>
