PlaidCloud 的 Jupyter 集成让数据科学家可以在笔记本环境中使用项目表、运行查询，并将 PlaidCloud 用作后端存储。认证使用 OAuth 令牌，因此同一套凭据可在 CLI、笔记本和 REST API 中通用。

- [命令行](/zh-cn/reference/cli/jupyter/command-line/)：用于脚本化交互的独立 CLI
- [Jupyter 笔记本](/zh-cn/reference/cli/jupyter/jupyter-notebook/)：在笔记本单元格中使用 PlaidCloud
- [OAuth 设置](/zh-cn/reference/cli/jupyter/oauth-setup/)：配置认证
