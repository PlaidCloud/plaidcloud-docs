按 `path_name` 从 `VARIANT` 中提取值。
返回值为 `Variant`；如果任一参数为 `NULL`，则返回 `NULL`。

`GET_PATH` 等同于一连串 `GET` 函数，`path_name` 由字段名拼接而成，字段名前带有句点 (.)、冒号 (:) 或索引运算符（`[index]`）。第一个字段名无需指定前导标识符。

## Analyze 语法

```python
func.get_path(<variant>, <path_name>)
```

## Analyze 示例

```python
func.get_path(func.parse_json('{"k1":[0,1,2], "k2":{"k3":3,"k4":4}}'), 'k2.k4')
┌─────────────────────────────────────────────────────────────────────────────────┐
│ func.get_path(func.parse_json('{"k1":[0,1,2], "k2":{"k3":3,"k4":4}}'), 'k2.k4') │
├─────────────────────────────────────────────────────────────────────────────────┤
│ 4                                                                               │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## SQL 语法

```sql
GET_PATH( <variant>, <path_name> )
```

## 参数

| 参数          | 说明                                   |
|---------------|----------------------------------------|
| `<variant>`   | 包含 ARRAY 或 OBJECT 的 VARIANT 值     |
| `<path_name>` | 由字段名拼接而成的字符串值             |

## 返回类型

VARIANT
