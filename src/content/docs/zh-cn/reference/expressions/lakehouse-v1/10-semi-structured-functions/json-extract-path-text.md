按 `path_name` 从 Json 字符串中提取值。
返回值为 `String`；如果任一参数为 `NULL`，则返回 `NULL`。
此函数等同于 `to_varchar(GET_PATH(PARSE_JSON(JSON), PATH_NAME))`。

## Analyze 语法

```python
func.json_extract_path_text(<expr>, <path_name>)
```

## Analyze 示例

```python
func.json_extract_path_text('{"k1":[0,1,2], "k2":{"k3":3,"k4":4}}', 'k2.k4')
┌──────────────────────────────────────────────────────────────────────────────┐
│ func.json_extract_path_text('{"k1":[0,1,2], "k2":{"k3":3,"k4":4}}', 'k2.k4') │
├──────────────────────────────────────────────────────────────────────────────┤
│ 4                                                                            │
└──────────────────────────────────────────────────────────────────────────────┘
```

## SQL 语法

```sql
JSON_EXTRACT_PATH_TEXT( <expr>, <path_name> )
```

## 参数

| 参数          | 说明                               |
|---------------|------------------------------------|
| `<expr>`      | Json 字符串值                      |
| `<path_name>` | 由字段名拼接而成的字符串值         |

## 返回类型

String
