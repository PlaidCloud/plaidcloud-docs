返回 `h3` 在分辨率 `child_res` 下包含的索引。

## Analyze 语法

```python
func.h3_to_children(h3, child_res)
```

## Analyze 示例

## SQL 语法

```sql
H3_TO_CHILDREN(h3, child_res)
```
