聚合函数。

SUM() 函数计算一组值的总和。

<Aside type="caution">不计入 NULL 值。</Aside>


## Analyze 语法

```python
func.sum(<column>)
```

## Analyze 示例

```python
func.sum(table.quantity).alias('total_quantity_sold')

| total_quantity_sold |
|---------------------|
|         41          |
```

## SQL 语法

```sql
SUM(<expr>)
```

## 参数

| 参数 | 说明              |
|-----------|--------------------------|
| `<expr>`  | 任意数值表达式 |

## 返回类型

如果输入类型为 double，则返回 double，否则返回整数。

## SQL 示例

**创建表并插入示例数据**
```sql
CREATE TABLE sales_data (
  id INT,
  product_id INT,
  quantity INT
);

INSERT INTO sales_data (id, product_id, quantity)
VALUES (1, 1, 10),
       (2, 2, 5),
       (3, 3, 8),
       (4, 4, 3),
       (5, 5, 15);
```

**查询演示：计算产品销售总量**
```sql
SELECT SUM(quantity) AS total_quantity_sold
FROM sales_data;
```

**结果**
```sql
| total_quantity_sold |
|---------------------|
|         41          |
```
