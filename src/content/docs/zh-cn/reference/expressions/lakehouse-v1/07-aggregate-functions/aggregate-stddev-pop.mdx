聚合函数。

STDDEV_POP() 函数返回表达式的总体标准差（VAR_POP() 的平方根）。

<Aside>也可以使用 STD() 或 STDDEV()，二者等效，但不属于标准 SQL。</Aside>

<Aside type="caution">不计入 NULL 值。</Aside>

## Analyze 语法

```python
func.stddev_pop(<expr>)
```

## Analyze 示例

```python
func.stddev_pop(table.score).alias('test_score_stddev_pop')

| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```

## SQL 语法

```sql
STDDEV_POP(<expr>)
STDDEV(<expr>)
STD(<expr>)
```

## 参数

| 参数 | 说明              |
|-----------|--------------------------|
| `<expr>`  | 任意数值表达式 |

## 返回类型

double

## SQL 示例

**创建表并插入示例数据**
```sql
CREATE TABLE test_scores (
  id INT,
  student_id INT,
  score FLOAT
);

INSERT INTO test_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 85),
       (3, 3, 90),
       (4, 4, 95),
       (5, 5, 100);
```

**查询演示：计算考试成绩的总体标准差**
```sql
SELECT STDDEV_POP(score) AS test_score_stddev_pop
FROM test_scores;
```

**结果**
```sql
| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```
