聚合函数。

covar_samp() 函数返回两个数据列的样本协方差（Σ((x - x̅)(y - y̅)) / (n - 1)）。

<Aside type="caution">不计入 NULL 值。</Aside>

## Analyze 语法

```python
func.covar_samp(<expr1>, <expr2>)
```

## Analyze 示例

```python
func.covar_samp(table.items_sold, table.profit).alias('covar_samp_items_profit')

| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```

## SQL 语法

```sql
COVAR_SAMP(<expr1>, <expr2>)
```

## 参数

| 参数 |        说明       |
|-----------| ------------------------ |
| `<expr1>` | 任意数值表达式 |
| `<expr2>` | 任意数值表达式 |

## 返回类型

float64，当 n &lt;= 1 时，返回 +∞。

## SQL 示例

**创建表并插入示例数据**

```sql
CREATE TABLE store_sales (
  id INT,
  store_id INT,
  items_sold INT,
  profit FLOAT
);

INSERT INTO store_sales (id, store_id, items_sold, profit)
VALUES (1, 1, 100, 1000),
       (2, 2, 200, 2000),
       (3, 3, 300, 3000),
       (4, 4, 400, 4000),
       (5, 5, 500, 5000);
```

**查询演示：计算销售件数与利润之间的样本协方差**

```sql
SELECT COVAR_SAMP(items_sold, profit) AS covar_samp_items_profit
FROM store_sales;
```

**结果**

```sql
| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```
