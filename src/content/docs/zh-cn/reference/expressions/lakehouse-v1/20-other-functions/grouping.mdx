返回位掩码，指示哪些 `GROUP BY` 表达式不包含在当前分组集中。位的分配方式为：最右侧的参数对应最低有效位；如果对应的表达式包含在生成当前结果行的分组集的分组条件中，则该位为 0，否则为 1。

## SQL 语法

```sql
GROUPING ( expr [, expr, ...] )
```

<Aside>`GROUPING` 只能与 `GROUPING SETS`、`ROLLUP` 或 `CUBE` 一起使用，且其参数必须在分组集列表中。</Aside>

## 参数

分组集项。

## 返回类型

UInt32。

## SQL 示例

```sql
select a, b, grouping(a), grouping(b), grouping(a,b), grouping(b,a) from t group by grouping sets ((a,b),(a),(b), ()) ;
┌──────┬──────┬─────────────┬─────────────┬────────────────┬────────────────┐
│ a    │ b    │ grouping(a) │ grouping(b) │ grouping(a, b) │ grouping(b, a) │
├──────┼──────┼─────────────┼─────────────┼────────────────┼────────────────┤
│ NULL │ A    │           1 │           0 │              2 │              1 │
│ a    │ NULL │           0 │           1 │              1 │              2 │
│ b    │ A    │           0 │           0 │              0 │              0 │
│ NULL │ NULL │           1 │           1 │              3 │              3 │
│ a    │ A    │           0 │           0 │              0 │              0 │
│ b    │ B    │           0 │           0 │              0 │              0 │
│ b    │ NULL │           0 │           1 │              1 │              2 │
│ a    │ B    │           0 │           0 │              0 │              0 │
│ NULL │ B    │           1 │           0 │              2 │              1 │
└──────┴──────┴─────────────┴─────────────┴────────────────┴────────────────┘
```
