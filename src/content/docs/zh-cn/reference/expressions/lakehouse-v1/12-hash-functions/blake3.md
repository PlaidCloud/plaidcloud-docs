计算字符串的 BLAKE3 256 位校验和。返回值为 64 个十六进制数字组成的字符串；如果参数为 NULL，则返回 NULL。

## Analyze 语法

```python
func.blake3(<expr>)
```

## Analyze 示例

```python
func.blake3('1234567890')

┌──────────────────────────────────────────────────────────────────┐
│ func.blake3('1234567890')                                        │
├──────────────────────────────────────────────────────────────────┤
│ d12e417e04494572b561ba2c12c3d7f9e5107c4747e27b9a8a54f8480c63e841 │
└──────────────────────────────────────────────────────────────────┘
```

## SQL 语法

```sql
BLAKE3(<expr>)
```

## SQL 示例

```sql
SELECT BLAKE3('1234567890');

┌──────────────────────────────────────────────────────────────────┐
│                       blake3('1234567890')                       │
├──────────────────────────────────────────────────────────────────┤
│ d12e417e04494572b561ba2c12c3d7f9e5107c4747e27b9a8a54f8480c63e841 │
└──────────────────────────────────────────────────────────────────┘
```
