将值转换为 String 数据类型，或将 Date 值转换为特定的字符串格式。要自定义 PlaidCloud Lakehouse 中日期和时间的格式，可以使用格式说明符。通过这些说明符，可以定义日期和时间值所需的格式。有关受支持说明符的完整列表，请参阅“格式化日期和时间”。

## Analyze 语法

```python
func.to_string( '<expr>' )
```

## Analyze 示例

```python
func.date_format('1.23'), func.to_string('1.23'), func.to_text('1.23'), func.to_varchar('1.23'), func.json_to_string('1.23')

┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ func.date_format('1.23') │ func.to_string('1.23') │ func.to_text('1.23') │ func.to_varchar('1.23') │ func.json_to_string('1.23') │
├──────────────────────────┼────────────────────────┼──────────────────────┼─────────────────────────┼─────────────────────────────┤
│ 1.23                     │ 1.23                   │ 1.23                 │ 1.23                    │ 1.23                        │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘ 
```

## SQL 语法

```sql
TO_STRING( '<expr>' )

TO_STRING( '<date>', '<format>' )
```

## 别名

- [DATE_FORMAT](../../05-datetime-functions/date-format)

## 返回类型

String。
