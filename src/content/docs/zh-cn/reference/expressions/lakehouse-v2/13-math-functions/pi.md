返回数学常数 π。

## Analyze 语法

```python
func.pi()
```

## Analyze 示例

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## SQL 语法

```sql
PI()
```

## SQL 示例

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
