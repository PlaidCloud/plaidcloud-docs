返回数学常数 e（欧拉数）。

## Analyze 语法

```python
func.e()
```

## Analyze 示例

```python
func.e()

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## SQL 语法

```sql
E()
```

## SQL 示例

```sql
SELECT E();

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
