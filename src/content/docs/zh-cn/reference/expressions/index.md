## 在哪里查找权威语法

PlaidCloud Lakehouse 使用底层引擎的 SQL 函数库。有关函数参数、边界情况和最新行为的具体信息，请在参考此处 PlaidCloud 风格示例的同时查阅上游文档。

- **Lakehouse v1** → [Databend SQL 函数参考](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [StarRocks SQL 函数参考](https://docs.starrocks.io/docs/sql-reference/sql-functions/)（PlaidCloud Lakehouse v2 对应 StarRocks 4.1）
