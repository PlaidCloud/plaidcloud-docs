## 目录文档
[Apache Hive 文档](https://hive.apache.org/docs/latest/)。

## 配置

创建或编辑此连接时会显示以下字段。是否必填取决于您启用的身份验证选项。

### 标识

| 字段 | 类型 | 说明 |
|---|---|---|
| 名称 | 文本 | 此连接的显示名称。 |
| 别名 | 文本（多行） | 可选的连接别名或备注。 |
| 是否启用 | 开关 | 是否启用该连接。禁用可暂停连接而不删除。 |
| 数据库只读 | 开关 | 将连接限制为只读操作。 |
| 访问类型 | 选择 | 此连接的只读、只写或读写访问级别。 |

### 连接

| 字段 | 类型 | 说明 |
|---|---|---|
| 数据库主机 | 文本 | 数据库服务器的主机名或 IP 地址。 |
| 数据库端口 | 数字 | 数据库连接的端口号。 |
| 数据库目录 | 文本 | 要连接的数据库、目录或架构。 |

### 身份验证

| 字段 | 类型 | 说明 |
|---|---|---|
| 数据库用户 | 文本 | 数据库身份验证的用户名。 |
| 使用 SSO | 开关 | 使用单点登录进行身份验证，而不是用户名/密码。 |
| 数据库密码 | 密码 | 数据库身份验证的密码。 |

### SSL / TLS

| 字段 | 类型 | 说明 |
|---|---|---|
| 使用 SSL | 开关 | 使用 SSL/TLS 加密连接。 |
| SSL 模式 | 选择 | SSL 验证模式（例如 disable、require、verify-ca、verify-full）。 |
| SSL 身份验证客户端证书 | 文本（多行） | 用于双向 TLS 身份验证的客户端证书（PEM）。 |
| SSL 身份验证客户端密钥 | 文本（多行） | 用于双向 TLS 身份验证的客户端私钥（PEM）。 |
| SSL 身份验证根证书 | 文本（多行） | 用于验证服务器证书的根 CA 证书（PEM）。 |
| SSL 身份验证证书吊销 | 文本（多行） | 证书吊销列表（如果您的环境使用）。 |

### SSH 隧道

| 字段 | 类型 | 说明 |
|---|---|---|
| 使用 SSH | 开关 | 通过 SSH 堡垒机建立连接隧道。 |
| SSH 主机 | 文本 | SSH 堡垒机主机名。 |
| SSH 端口 | 数字 | SSH 堡垒机端口（默认 22）。 |
| SSH 用户 | 文本 | SSH 堡垒机用户名。 |
| SSH 密码 | 密码 | SSH 堡垒机密码（使用密码身份验证时）。 |
| 使用 SSH 证书 | 开关 | 使用私钥而不是密码向 SSH 堡垒机进行身份验证。 |
| SSH 私钥 | 文本（多行） | 用于堡垒机身份验证的 SSH 私钥（PEM）。 |
| SSH 主机密钥 | 文本（多行） | 用于堡垒机指纹验证的预期 SSH 主机密钥。 |
