PlaidCloud 可连接到团队聊天平台，使工作流能够将通知、警报或状态更新直接发送到团队已在关注的频道中。最常与 [Notify via Slack](/zh-cn/reference/workflow-steps/notifications/notify-via-slack/) 和 [Notify via Microsoft Teams](/zh-cn/reference/workflow-steps/notifications/notify-via-microsoft-teams/) 工作流步骤搭配使用。

## 提供商

- [Slack](/zh-cn/reference/connectors/collaboration/slack/)
- [Microsoft Teams](/zh-cn/reference/connectors/collaboration/teams/)
- [Tableau](/zh-cn/reference/connectors/collaboration/tableau/)
