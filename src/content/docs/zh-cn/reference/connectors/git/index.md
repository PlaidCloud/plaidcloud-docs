PlaidCloud 可连接到 Git 主机，使工作流和 Panel 应用能够从受版本控制的仓库读取内容。适用于获取存放在源代码管理中（而非数据库或文档账户中）的配置、脚本或模板化文件。

## 提供商

- [PlaidCloud Git](/zh-cn/reference/connectors/git/plaidcloud-git/) — 内置于工作区的托管 Git 服务；无需配置服务器 URL 或凭据
- [GitHub](/zh-cn/reference/connectors/git/github/)
- [GitLab](/zh-cn/reference/connectors/git/gitlab/)
- [Bitbucket](/zh-cn/reference/connectors/git/bitbucket/)
- [Azure Repos](/zh-cn/reference/connectors/git/azure-repos/)
- [AWS CodeCommit](/zh-cn/reference/connectors/git/codecommit/)
