## API 文档
[厂商 API 参考](https://developers.paycor.com/explore)涵盖了此连接器的端点。

## Paycor 设置
Paycor API 应用程序的申请和初始化流程比其他 REST 提供商稍微复杂一些。请务必按照其[快速入门页面](https://developers.paycor.com/guides#quickStartLabel)中列出的步骤操作。

您必须记录的关键值如下：
 - 应用程序 OAuth 客户端 ID
 - 应用程序 OAuth 客户端密钥
 - APIm 订阅密钥
 - `current` 应用程序版本的范围密钥

<Aside type="caution">请务必“激活”该应用程序，才能使用</Aside>

请在此处激活，并根据需要选择生产或沙盒：

| 环境 | 激活表单 URL |
|-------------|---------------------|
| 沙盒	  | https://hcm-demo.paycor.com/AppActivation/ClientActivation |
| 生产  | https://hcm.paycor.com/AppActivation/ClientActivation |

<Aside type="danger">如果您在 Paycor 中有多个组织，则每个组织都需要单独的登录。请勿合并它们。开发者门户需要为每个组织提供专用的唯一登录，才能创建用于 REST 访问的、特定于该组织的应用程序。</Aside>

## 配置

创建或编辑此连接时会显示以下字段。

### 标识

| 字段 | 类型 | 说明 |
|---|---|---|
| 名称 | 文本 | 此连接的显示名称。 |
| 别名 | 文本（多行） | 可选的连接别名或备注。 |
| 是否启用 | 开关 | 是否启用该连接。禁用可暂停连接而不删除。 |
| 数据库只读 | 开关 | 将连接限制为只读操作。 |
| 访问类型 | 选择 | 此连接的只读、只写或读写访问级别。 |

### 凭据

请输入您在 [Paycor 设置](#paycor-设置)期间记录的三个值。您无需输入主机或令牌 URL，PlaidCloud 会为您提供 Paycor API 主机和 OAuth2 令牌端点。

| 字段 | 类型 | 说明 |
|---|---|---|
| OAuth2 客户端 ID | 文本 | Paycor 应用注册中的应用程序 OAuth 客户端 ID。 |
| OAuth2 客户端密钥 | 密码 | 应用程序 OAuth 客户端密钥。加密存储。 |
| Paycor 订阅密钥 | 文本 | Paycor 应用程序的 APIm 订阅密钥。 |

## 身份验证

Paycor 使用带授权码授予的 OAuth2，因此输入凭据只是前一半，您还需要完成一次与 Paycor 的登录，以授权 PlaidCloud 拉取您的数据。

1. **输入凭据并保存。** 填写上述三个值并保存连接。
2. **连接。** 点击**连接到 Paycor**。PlaidCloud 会打开 **Paycor 授权窗口**。保存连接后该按钮才可用。
3. **登录并批准。** 在该窗口中登录 Paycor 并批准访问。Paycor 会将您送回 PlaidCloud，PlaidCloud 会在连接上存储**刷新令牌**，此后会使用它自动获取访问令牌。

<Aside type="caution">请允许 PlaidCloud 的弹出窗口。如果授权窗口被阻止，PlaidCloud 会提示您，请允许弹出窗口后再次点击**连接到 Paycor**。</Aside>

API 主机（`apis.paycor.com`）和令牌端点（`https://apis.paycor.com/sts/v1/common/token`）由 PlaidCloud 管理。没有需要填写的 URL 字段，您也无需编辑它们。

### 重新授权已过期的连接

Paycor 访问可能失效：刷新令牌过期或被撤销，或者 Paycor 应用程序被停用。发生这种情况时，使用该连接的工作流将无法通过身份验证并失败。恢复方法如下：

1. 确认 Paycor 应用程序仍处于**激活**状态（请参阅 [Paycor 设置](#paycor-设置)下的激活 URL）。
2. 打开该连接并点击**连接到 Paycor**，重新执行 Paycor 授权，然后登录并批准。这会生成新的刷新令牌，连接随即恢复。

<Aside type="danger">请通过此连接表单来建立和修复 Paycor 连接。通过通用 REST 编辑器或 API 编辑底层连接，可能会覆盖受管的令牌 URL 并导致身份验证失败。</Aside>
