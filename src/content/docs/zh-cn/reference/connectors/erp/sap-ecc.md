一种连接类型同时适用于 SAP ECC 和 SAP S/4HANA。两者的访问方式相同——对应用服务器进行远程函数调用（RFC）——因此 PlaidCloud 不会询问您使用的是哪一代。在**连接**屏幕中，选择**新建 → SAP ECC / S/4HANA 实例**。

[SAP 工作流步骤](/zh-cn/reference/workflow-steps/sap/)均针对此类型的连接运行。要搜索 SAP 并提取表、事务、报表和已保存的 SAP 查询，请参阅[从 SAP ECC / S/4HANA 临时提取数据](/zh-cn/guides/connections/sap-adhoc-extract/)。

## 上游文档

SAP 已移除所有 ECC 文档，目前只提供 [S/4HANA](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE) 的文档。PlaidCloud 使用的 RFC 接口在两者中是通用的。

## 配置

创建或编辑连接时会显示这些字段。

### 账户描述

| 字段 | 类型 | 说明 |
|---|---|---|
| 账户名称 | 文本 | 此连接的显示名称，在步骤选择连接的任何位置显示。必填。 |
| 备忘 | 文本（多行） | 关于连接的可选备注——指向哪个系统、由谁负责。 |

### SAP 环境

| 字段 | 类型 | 说明 |
|---|---|---|
| 客户端 | 文本 | SAP 客户端编号，例如 `100`。必填。 |
| 语言 | 选择 | 以两位 SAP 代码表示的登录语言。默认为 `EN`。必填。 |
| 跟踪级别 | 选择 | RFC 跟踪详细程度——关闭、简要、详细或完整。除非正在诊断连接问题，否则保持关闭。必填。 |
| 连接类型 | 单选 | **使用单一直接连接**可访问一台应用服务器，**使用负载均衡多系统连接**则通过消息服务器访问。下方字段会根据此选择启用。 |

选择**使用单一直接连接**会启用：

| 字段 | 类型 | 说明 |
|---|---|---|
| 主机 | 文本 | 应用服务器的主机名或 IP 地址。 |
| 系统编号 | 文本 | 两位 SAP 系统编号，例如 `00`。 |

选择**使用负载均衡多系统连接**会启用：

| 字段 | 类型 | 说明 |
|---|---|---|
| MS 主机 | 文本 | 消息服务器的主机名或 IP 地址。 |
| MS 服务器 | 文本 | 消息服务器端口或服务名称。 |
| 系统 ID | 文本 | 三字符的 SAP 系统 ID，例如 `PRD`。 |
| 分组 | 文本 | 要进行负载均衡的登录组，例如 `PUBLIC`。 |

### 身份验证凭据

| 字段 | 类型 | 说明 |
|---|---|---|
| 用户 | 文本 | 用于 RFC 调用的 SAP 登录用户。必填。 |
| 密码 | 密码 | 该用户的密码。只写——编辑时留空可保留已存储的密码。 |

### 使用

| 字段 | 类型 | 说明 |
|---|---|---|
| 启用（允许访问） | 开关 | 连接是否可用。清除此项可暂停连接而无需删除。 |
| 只读 | 开关 | 将连接限制为读取操作。 |

### 安全模型

| 字段 | 类型 | 说明 |
|---|---|---|
| 安全模型 | 选择 | 谁可以使用此连接——私有（仅所有者）、仅限指定成员、仅限指定安全组或所有工作区成员。 |

## 测试连接

连接窗口中的**测试连接**会使用上述信息登录并返回结果。编辑现有连接并更改任何设置时，请在测试前重新输入密码——已存储的密码不会与编辑后的值一起发送。
