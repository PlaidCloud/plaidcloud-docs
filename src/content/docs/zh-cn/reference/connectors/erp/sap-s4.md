S/4HANA 没有自己的连接器。它与 SAP ECC 共用一种连接类型，因为 PlaidCloud 通过同一个远程函数调用接口访问两者。在**连接**屏幕中，选择**新建 → SAP ECC / S/4HANA 实例**。

**[SAP ECC 和 S/4HANA 连接器 →](/zh-cn/reference/connectors/erp/sap-ecc/)** — 两代系统的所有配置字段。

## 上游文档

请参阅 [SAP S/4HANA 文档](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE)。
