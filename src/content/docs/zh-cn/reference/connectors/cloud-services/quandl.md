## 连接文档
[Quandl 现已更名为 Nasdaq Data Link。文档见此处](https://docs.data.nasdaq.com/)。

## 设置

此连接器使用特定于供应商的身份验证流程，直接在工作区的 **连接** 屏幕中配置。显示的配置字段取决于租户管理员为该集成预配的凭据。

有关最新的设置细节，请参阅上游 [quandl 文档](https://docs.data.nasdaq.com/)。

如果需要帮助为您的租户设置此连接器，请联系您的客户团队。连接器专用的凭据、环境 URL 以及任何必需的预先配置，通常需要与 PlaidCloud 支持团队协调。
