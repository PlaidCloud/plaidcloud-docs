适用于使用专有协议或非 REST 协议的云数据服务的连接器。这些服务不适合归入数据库或 REST 类别。

## 提供商

- [Quandl](/zh-cn/reference/connectors/cloud-services/quandl/) — 金融和经济数据（NASDAQ Data Link）
