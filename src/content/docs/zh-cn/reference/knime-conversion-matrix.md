PlaidCloud 可将 KNIME 工作流（`.knwf`）和工作流分组（`.knar`）转换为原生高级工作流。导入器会把每个 KNIME 节点映射为一个工作流步骤、项目变量或画布对象，并展平元节点和组件，因此转换后的工作流以云原生方式运行。

98.5% 的 KNIME 节点配置可完整转换，207 个核心节点类型中有 205 个为完整支持。要运行转换，请参阅[迁移 KNIME 工作流](/zh-cn/guides/workflows/migrate-knime-workflows/)。

每个节点都有一个状态：

- **完整**：该节点在 PlaidCloud 步骤中有有效映射。
- **部分**：该节点的常见用法可转换，但有一种独立的*能力模式*未被复现；该模式会被明确指出。
- **不支持**：无法转换；该节点作为已命名的占位符保留在画布上，相应能力需改用原生方式重建。

较旧和已弃用的节点变体列在替代它们的节点之下。

转换后的工作流不会复现的少数行为列在[已知边缘情况](#已知边缘情况)中。

连接器节点会成为其步骤所运行的 PlaidCloud 连接，请参阅[连接外部系统](#连接外部系统)。

## 节点支持

在 207 个核心节点中：205 个完整，2 个部分，0 个不支持。

## 未转换

没有转换路径的节点会作为已命名的占位符保留在画布上。占位符会传递其数据，添加一条指出该 KNIME 节点的警告，并且绝不会导致转换失败：缺失或未绑定的输入只是警告，而不是错误。占位符下游的任何步骤都会被标记，因此缺失的结果绝不会悄无声息。

| REST and web service nodes that sign in | [REST 连接](/zh-cn/reference/connectors/rest/generic-rest/)，在转换时绑定，或在步骤上选取。 |
| Speech Recognizer (IBM Watson) | 指向 Watson 服务 URL 的 REST 连接，其 Basic 登录用户为 `apikey`，密码为您的 API 密钥。 |
| Email Connector, Email Reader, Email Mover | 邮件服务器密码，存放在步骤警告所指出的项目变量中。主机和用户来自 Email Connector。 |
| Password-protected Excel workbooks | 工作簿密码，存放在步骤警告所指出的项目变量中。 |
| LLM connectors and authenticators | AI 步骤上的 LLM 连接。 |
| Views, charts and reporting layout | 无需设置；这些节点不影响数据，并已列入转换报告。 |

转换从不连接任何源系统或目标系统。

## 已知边缘情况

| 节点 | 差异 |
| --- | --- |
| Crosstab | 转换为[Table: Pivot](/zh-cn/reference/workflow-steps/tables/table-pivot/)。尚未复现：少数设置组合的结果与 KNIME 不同。 |
| Loop End (Column Append) | 转换为[表：内联接](/zh-cn/reference/workflow-steps/tables/table-inner-join/)。尚未复现：少数设置组合的结果与 KNIME 不同。 |
| Row Sampler, Table Partitioner, Equal Size Sampling | 使用[Table: KNIME Random Sample](/zh-cn/reference/workflow-steps/tables/table-knime-random-sample/)，带种子的随机抽取会选出与 KNIME 相同的行。抽取所用的表最多可包含 10,000,000 行。 |

## 检查已转换的工作流

行顺序和 RowID 会贯穿读取它们的各个节点，因此依赖行顺序的工作流会在这些节点之间保持顺序。请将已转换工作流的输出与您的 KNIME 工作流的输出进行比较：结构、行数和行值。
