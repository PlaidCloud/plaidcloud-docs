## 描述



通过 PlaidLink 代理触发通知，适用于需要通过 PlaidCloud 无法直接访问的本地系统（内部提醒、内部 Webhook、传统 SMTP）发送通知的情形。

代理接收通知负载，并根据其配置在本地分发。
