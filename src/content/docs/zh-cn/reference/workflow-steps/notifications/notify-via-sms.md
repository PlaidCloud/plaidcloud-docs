## 描述

当工作流需要成员关注时，向工作区成员发送短信。只有自行从用户菜单的**短信提醒**中加入、并已确认美国手机号码的成员才会收到短信。您选择成员或分发列表，无需在步骤中输入电话号码。要加入，请参阅[短信提醒](/zh-cn/guides/workflows/text-alerts/)。

短信仅支持美国号码。请勿在短信中包含健康或财务方面的个人数据。

短信来自同一个 PlaidCloud 提醒号码，内容以 `PlaidCloud [your workspace name]: ` 开头，后接您的消息。请参阅[短信条款](https://plaidcloud.com/sms-terms/)和[短信隐私政策](https://plaidcloud.com/sms-privacy/)。

## 收件人

选择**成员**或**分发列表**。

- **成员**列出您的工作区成员。每个成员显示为**已加入**、**未加入**或**已退订：发送短信 START 到警报号码**。
- **分发列表**向列表中每位已加入的成员发送短信。

未加入的成员不会收到短信。对于该步骤，他们属于问题（参见**短信无法送达时**），默认情况下会改为通过电子邮件收到该消息。

## 消息

编写**消息**。项目变量和工作流变量均可使用，**插入变量**可添加下列任一变量：

| 变量 | 值 |
|---|---|
| `{workflow_name}` | 正在运行的工作流的名称 |
| `{project_name}` | 项目的名称 |
| `{run_url}` | 指向 PlaidCloud 中该运行的链接 |
| `{project}`, `{model}`, `{cloud}`, `{date}` | 现有变量 |

消息下方的计数器显示短信大致占用的字符数和分段数，包括 `PlaidCloud [workspace]:` 前缀和运行链接。超过 3 个分段的短信会被截断。来自公共链接缩短服务的链接会被拒绝。

## 送达

| 设置 | 作用 |
|---|---|
| **短信无法送达时** | **使步骤失败**（默认）或**警告并继续**。未送达的短信绝不会悄无声息：它始终会在步骤上报告。 |
| **通过电子邮件通知短信无法送达的收件人** | 默认开启。短信失败、未加入或已退出的成员会通过电子邮件收到该消息。 |
| **合并重复消息的时间（分钟）** | 默认 60。在此时间内向同一成员重复发送的相同消息不会发送，下一条发出的短信末尾会附上 `(+N similar since HH:MM)`。 |
| **在静默时段暂存短信** | 选择**从**和**至**时间以及时区。原本会在该时间窗口内发出的短信会被暂存，直到窗口结束。 |

每位成员每天最多接收 20 条短信，一个工作区每天最多发送 500 条短信和回退电子邮件，一个步骤一次最多向 50 位成员发送短信。

## 向我发送测试

**向我发送测试**会向您自己的号码发送一条测试短信，并在按钮旁显示结果。如果您尚未加入，将打开**短信提醒**窗口，以便您加入。

## 收件人看到的内容

每条短信都来自提醒号码。回复 **STOP** 会停止 PlaidCloud 向该号码发送的所有短信，回复 **HELP** 则返回联系信息。发送 STOP 之后，成员需向提醒号码发送短信 START 以恢复，然后在**短信提醒**中重新开启短信提醒。在此之前，步骤表单会在该成员旁显示**已退订：发送短信 START 到警报号码**。

工作区管理员可以在成员窗口的**成员信息**选项卡上看到每位成员的短信提醒状态（号码已被遮蔽）。成员自行加入和退出；管理员无法代其操作。

## 输入过号码的步骤

此步骤的早期版本需要移动运营商和手动输入的电话号码。仍以这种方式保存的步骤不会使工作流失败，也不会向所输入的号码发送短信。

- **未选择收件人：** 步骤完成时带有警告，*No text was sent: this step still uses the retired mobile provider and number. Open the step, choose members who've opted in to text alerts, and save it.* 不会发送任何内容。
- **已选择成员或分发列表：** 步骤向这些收件人发送短信，并忽略遗留的运营商和号码。

要修复步骤，请打开它，选择成员或分发列表，然后保存。
