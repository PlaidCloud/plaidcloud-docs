## 描述



通过向 Webhook URL 发送 POST 请求来发送通知，适用于触发自定义的下游操作、提醒集成平台（Zapier、n8n、Make），或驱动不使用一流连接器的 Slack/Teams/Discord 机器人。

负载格式和任何自定义标头均可配置。后续处理由接收服务负责。
