## 说明


从 [@plaidcloud](https://twitter.com/plaidcloud) 发送 Twitter 私信（DM）。



### Twitter 账户


指定从 @plaidcloud 接收私信的 Twitter 账户。该用户必须已关注 @plaidcloud 才能收到消息。用户名前可以加（也可以不加）at 符号（@）。



### 消息


输入所需的消息。Analyze 不允许超过 140 个字符的值。


请注意，项目变量和工作流变量均可用于此转换。


<Aside type="danger">使用变量时，可能会生成超过 140 个字符限制的消息。如果发生这种情况，消息将不会发送，而是会向日志写入以下错误： *Twitter API returned a 403 (Forbidden), There was an error sending your message: The text of your direct message is over 140 characters.</Aside>

## 示例

在此示例中，从 [@PlaidCloud](https://twitter.com/plaidcloud) 向 [@tartansolutions](https://twitter.com/tartansolutions) 发送私信。消息中使用了系统变量。最终消息为“*Analyze Demo is running on #PlaidCloud*”。
