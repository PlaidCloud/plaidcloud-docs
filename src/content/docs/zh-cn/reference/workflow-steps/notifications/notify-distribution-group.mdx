## 描述



向 PlaidCloud 分发列表发送电子邮件通知，分发列表是在工作区设置中管理的具名收件人列表。适用于需要送达特定受众的状态更新、完成通知或错误提醒。

消息由 PlaidCloud 的通知服务发送。分发列表集中管理，因此工作流作者无需在工作流定义中嵌入电子邮件地址。


## 选择 PlaidCloud 分发列表


从下拉菜单中选择一个分发列表。可以使用“工具”创建分发列表。有关创建分发列表的详细信息，请参阅：[PlaidCloud 工具：分发列表](/zh-cn/administration/access/member-management/#管理分发distro列表)。



## 消息


根据需要指定**主题**和**正文**。



请注意，项目变量和工作流变量都可用于此转换，主题行和消息正文中均可使用。



此外，正文中允许使用标准 HTML 代码，以进一步自定义电子邮件消息的外观。


## 示例


在此示例中使用了所有系统变量。此外，还使用了少量 HTML 来设置正文第一行的格式。执行此转换将向分发列表中指定的所有成员发送以下电子邮件：


* 发件人：[info@tartansolutions.com](mailto:info%40tartansolutions.com)（请记住，所有消息都来自此地址）
* 主题：DEMO Analyze Demo Running


<Aside>电子邮件的各个收件人**无法**看到分发列表中其他成员的姓名。</Aside>
