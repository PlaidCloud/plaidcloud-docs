## 描述

通过 [Oracle Fusion 连接](/zh-cn/guides/connections/oracle-fusion/)，经由 Oracle 的 FBDI/BI Publisher 批量提取路径导入 Oracle Fusion Cloud 实体：PlaidCloud 提交导出作业，轮询直至完成，下载生成的文件，并将其写入项目表。当拉取的数据量过大或过慢，不适合直接的 OData/BIP 调用时，请使用此步骤，而不是 [Import Fusion Entity 步骤](/zh-cn/reference/workflow-steps/oracle-fusion/import-fusion-entity/)。

## 配置

| 字段 | 是否必填 | 说明 |
|---|---|---|
| Fusion 连接 | 是 | 用于读取的 Oracle Fusion 连接。 |
| 目标表 | 是 | 写入结果的项目表。每次运行都会完全覆盖该表。 |
| 实体类型 | 是 | 要提取的实体。默认为 `gl_balances`。可选 `gl_balances`、`journal_batches` 之一。 |
| 筛选器 | 否 | 与 [Import Fusion Entity 步骤](/zh-cn/reference/workflow-steps/oracle-fusion/import-fusion-entity/)相同的筛选器集合：对日期、会计期间以及数值余额/金额字段的范围筛选器（`ge`/`le`），以及对离散字段的相等筛选器。在提取作业级别应用。 |

<Aside type="caution">
此步骤会等待异步导出作业，因此对于相同的行数，预计耗时会明显长于 [Import Fusion Entity 步骤](/zh-cn/reference/workflow-steps/oracle-fusion/import-fusion-entity/)。仅当拉取的数据量确实过大、不适合直接的 OData/BIP 调用时才使用它。
</Aside>
