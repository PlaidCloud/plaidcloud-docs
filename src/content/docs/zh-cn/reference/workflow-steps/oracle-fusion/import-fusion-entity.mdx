## 说明

通过 [Oracle Fusion 连接](/zh-cn/guides/connections/oracle-fusion/)将一个 Oracle Fusion Cloud 实体导入到项目表中，直接调用 Fusion 的 OData 或 BI Publisher（BIP）端点。选择连接、实体类型和所需的筛选器即可，步骤会拉取匹配的记录并写入，无需编写 OData 查询。

如果拉取的数据量过大，无法直接调用，请改用 [Import Fusion Bulk Extract 步骤](/zh-cn/reference/workflow-steps/oracle-fusion/import-fusion-bulk-extract/)。

## 配置

| 字段 | 必填 | 备注 |
|---|---|---|
| Fusion 连接 | 是 | 用于读取数据的 Oracle Fusion 连接。 |
| 目标表 | 是 | 写入结果的项目表。每次运行都会完全覆盖该表。 |
| 实体类型 | 是 | 要拉取的实体。默认值为 `gl_balances`。可选 `gl_balances`、`journal_batches` 之一。 |
| 筛选器 | 否 | 对日期、会计期间和数值型余额/金额字段的范围筛选（`ge`/`le`），以及对离散字段（分类账、货币）的等值筛选。每个实体仅允许使用 Oracle Fusion 能够在服务器端实际求值的字段进行筛选，不支持的字段会被拒绝，而不是被悄悄忽略。 |

### 实体与可筛选字段

| 实体类型 | 拉取内容 | 可筛选字段 |
|---|---|---|
| `gl_balances` | 总账科目余额 | 会计期间范围（`ge`/`le`）、科目范围、余额金额范围（`ge`/`le`） |
| `journal_batches` | 日记账批次头和状态 | 日期范围（`ge`/`le`）、会计期间范围（`ge`/`le`） |

<Aside type="note">
范围筛选只需一个边界即可生效，例如 `accounting_date ge 2026-01-01` 不设上界，会拉取该日期起的所有数据。如需精确限定拉取范围，请同时提供上下界。
</Aside>
