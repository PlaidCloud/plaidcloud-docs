通过您的 [Xero 连接](/zh-cn/guides/connections/xero/)读取和写入 Xero 的工作流步骤。导入步骤无需编写查询即可提取 Xero 的 Accounting API 实体；过账步骤通过 PlaidCloud 共享的 ERP 写入管道过账手工日记账、发票、账单、付款和贷项通知单。

## 步骤

- [Xero：导入实体](/zh-cn/reference/workflow-steps/xero/import-xero-entity/) — 科目、联系人、发票、贷项通知单、付款、手工日记账、银行交易、物料、跟踪类别、税率和货币。
- [Xero：过账单据](/zh-cn/reference/workflow-steps/xero/xero-post/) — 过账手工日记账、发票、账单、付款和贷项通知单。
