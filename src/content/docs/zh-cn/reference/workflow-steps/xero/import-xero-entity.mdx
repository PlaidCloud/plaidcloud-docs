## 说明

通过您的 [Xero 连接](/zh-cn/guides/connections/xero/)，将一个 Xero Accounting API 实体（范围限定为该连接所属的组织）导入项目表。选择连接、实体类型和任何筛选条件；该步骤会提取匹配的记录并写入，无需编写查询。

一种步骤类型涵盖十一种实体，从参考数据（会计科目表、联系人、物料、税率、货币）到交易记录（发票、贷项通知单、付款、手工日记账、银行交易）。

## 配置

| 字段 | 是否必填 | 备注 |
|---|---|---|
| Xero 连接 | 是 | 用于读取数据的 Xero 连接。 |
| 目标表 | 是 | 写入结果的项目表。 |
| 实体类型 | 是 | 要提取的实体。默认为**发票**。 |
| 状态 | 否 | 缩小到单个 Xero `Status` 值，例如 `AUTHORISED` 或 `PAID`。 |
| 起始日期 | 否 | 实体 `Date` 的下限，格式为 `YYYY-MM-DD`。 |
| 截止日期 | 否 | 实体 `Date` 的上限，格式为 `YYYY-MM-DD`。 |
| 更新时间晚于 | 否 | 作为修改时间下限发送，因此只返回在此之后发生变更的行。留空则提取全部。 |

<Aside type="note">
**更新时间晚于**是请求端的筛选器，不保存水位线——PlaidCloud 不会记住上次运行停在何处，因此需要每次运行时自行提供下限，才能实现增量效果。
</Aside>

## 实体类型

| 实体类型 | 包含内容 |
|---|---|
| 会计科目表 | 科目代码、名称、类型、类别、税种、状态、报告代码。 |
| 联系人 | 客户和供应商，及其状态、税号和默认货币。 |
| 发票 | 销售和采购发票，包含联系人、日期、状态、合计和应付金额。 |
| 贷项通知单 | 针对销售或采购的贷项通知单，包含联系人、日期、状态和合计。 |
| 付款 | 付款，包含日期、金额、状态和银行账户。 |
| 手工日记账 | 日记账摘要、日期和状态。 |
| 银行交易 | 支出和收入交易，包含日期、状态、合计和对账标记。 |
| 物料 | 库存和服务物料，包含跟踪标记和现有数量。 |
| 跟踪类别 | 跟踪类别名称和状态。 |
| 税率 | 税率名称、类型、状态和有效税率。 |
| 货币 | 货币代码和说明。 |

<Aside type="note">
并非每种实体都支持所有筛选条件——物料和货币两者都不支持，会计科目表和联系人支持状态但不支持日期范围。筛选字段对每种实体都保持可用；Xero 会拒绝实体不支持的筛选条件，因此该步骤会报告错误，而不是返回错误的结果集。
</Aside>

<Aside type="caution">
**组织来自连接，而不是此步骤。** 每个 Xero 请求都指定一个组织，而该组织由连接携带——因此步骤上没有组织字段。若要从第二个组织提取同一实体，请创建指向它的第二个 Xero 连接。
</Aside>
