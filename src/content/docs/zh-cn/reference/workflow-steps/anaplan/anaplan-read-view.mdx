## 描述

通过您的 [Anaplan 连接](/zh-cn/guides/connections/anaplan/)，经由 Anaplan 的大容量读取请求路径，从已保存的 **Anaplan** 视图读取数据。视图**按保存时的原样**读取，此步骤不提供临时的行、列或页选择。要读取不同的切片，请在 Anaplan 中保存另一个视图。

此步骤在步骤菜单的 **Anaplan** 下显示。

该步骤通过 Anaplan 的集成 API **直接连接云端**，不存在本地代理路径。

<Aside type="tip">
此连接器为只读，使用基本（用户名和密码）或 CA 证书凭据进行身份验证，请参阅[身份验证](/zh-cn/guides/connections/anaplan/#身份验证)。Anaplan 的请求配额在整个租户范围内共享，因此请将此步骤的计划与您的其他 Anaplan 工作流错开，请参阅[计划注意事项](/zh-cn/guides/connections/anaplan/#计划方面的注意事项)。
</Aside>

## 配置

### 源和目标

| 字段 | 必填 | 说明 |
|---|---|---|
| Anaplan 连接 | 是 | 用于读取的 [Anaplan 连接](/zh-cn/guides/connections/anaplan/)。 |
| 环境 | 否 | **项目环境**（默认）使用项目的连接环境。**固定环境**始终使用您选择的环境。请参阅[将步骤固定到单一环境](/zh-cn/guides/projects/managing-projects/#将步骤固定到某一环境)。 |
| 工作区 | 否 | 覆盖连接上保存的工作区 ID。可从连接实时发现，也可手动输入。 |
| 模型 | 否 | 覆盖连接上保存的模型 ID。选择工作区后可实时发现，也可手动输入。 |
| 视图 | 是 | 要读取的已保存 Anaplan 视图。选择模型后可实时发现，也可手动输入。 |
| 轮询次数 | 是 | 默认为 120。在步骤拒绝之前，轮询读取请求是否完成的次数，并会指明请求 ID。它绝不会悄悄地提交第二个请求。 |
| 轮询间隔（秒） | 是 | 默认为 5。两次轮询之间等待的秒数。 |
| 目标表 | 是 | 返回的视图加载到的表。 |

## 预览

**源**选项卡上的**预览**会显示此视图读取将生成的列和数据类型，而不运行该步骤。在已锁定的项目中不可用。

## 此步骤无法表示的内容

| 限制 | 含义 |
|---|---|
| 无切片控制 | 视图按保存时的原样读取，不提供行、列或页选择。Anaplan 的页选择器仅在其同步预览端点上有文档说明；此步骤提交的大容量读取请求正文只接受导出类型，没有其他内容。要读取不同的切片，请构建另一个已保存的视图，通常是布尔行项目加一个筛选器。 |
| 仅当行项目位于列上时，才加载声明的类型 | 当行项目位于视图的列轴上时，每个数据列都按其行项目声明的 Anaplan 格式（数字、文本、布尔、日期、时间段或列表）加载并带有类型。当行项目位于行上（常规损益表布局），或视图中根本没有行项目时，每个数据列都以文本加载，并给出带名称的警告，否则一个数据列会跨越多个行项目，从而跨越多种格式，而表列只能保存一种类型。 |
| 页选择器的值不会作为列加载 | 视图中保存的页选择器成员包含在 CSV 标题中并在那里被使用，不会作为列出现在目标表中。 |
| 含糊的数字会被拒绝而不是猜测 | 声明为数字、带有千位分隔符的值，或既可读作普通小数、又可读作欧式写法的值（例如 `1.234`），会按名称被拒绝而不是被解析，除非同一列中的另一个值能确定哪种读法正确。此读取路径没有可用于消除歧义的区域设置字段。能够解析的值会以完整精度加载，没有舍入误差，空白单元格始终加载为空值。 |
| 空视图加载为空，并给出警告 | 筛选器没有匹配任何内容的已保存视图，会用空表替换目标表并给出警告，这是正常结果，不是失败。例外是行轴上没有维度的视图：没有行标签角可用来核实空结果，因此步骤会拒绝，而不是冒着因标题误读而清空表的风险。 |
| 只读 | 绝不会向 Anaplan 写回任何内容。 |
