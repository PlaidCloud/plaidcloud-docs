## 说明

通过 [Anaplan 连接](/zh-cn/guides/connections/anaplan/)，经由 Anaplan 的大容量读取请求路径，从已保存的 **Anaplan** 视图中读取数据。视图**按保存时的原样**读取，此步骤不支持临时的行、列或页选择。若要读取不同的数据切片，请在 Anaplan 中保存另一个视图。

此步骤在步骤菜单的 **Anaplan** 下显示。

此步骤通过 Anaplan 的 Integration API 以**云直连**方式访问 Anaplan，不提供本地代理路径。

<Aside type="tip">
此连接器为只读，使用基本身份验证（用户名和密码）或 CA 证书凭据进行身份验证，请参阅[身份验证](/zh-cn/guides/connections/anaplan/#身份验证)。Anaplan 的请求配额由整个租户共享，因此请将此步骤的计划与其他 Anaplan 工作流错开，请参阅[计划注意事项](/zh-cn/guides/connections/anaplan/#计划方面的注意事项)。
</Aside>

## 配置

### 源和目标

| 字段 | 必填 | 备注 |
|---|---|---|
| Anaplan 连接 | 是 | 用于读取的 [Anaplan 连接](/zh-cn/guides/connections/anaplan/)。 |
| 环境 | 是 | 连接的环境。 |
| 工作区 | 否 | 覆盖连接上保存的工作区 ID。可从连接实时发现，也可手动输入。 |
| 模型 | 否 | 覆盖连接上保存的模型 ID。选择工作区后可实时发现，也可手动输入。 |
| 视图 | 是 | 要读取的已保存 Anaplan 视图。选择模型后可实时发现，也可手动输入。 |
| 轮询次数 | 是 | 默认为 120。在步骤拒绝并指明请求 ID 之前，轮询读取请求是否完成的次数。它绝不会悄悄地提交第二个请求。 |
| 轮询间隔（秒） | 是 | 默认为 5。两次轮询之间等待的秒数。 |
| 目标表 | 是 | 载入返回视图的表。 |

## 此步骤无法表示的内容

| 限制 | 含义 |
|---|---|
| 无切片控制 | 视图按保存时的原样读取，不支持行、列或页选择。Anaplan 的页选择器仅在其同步预览端点中有文档说明；此步骤提交的大容量读取请求正文只接受导出类型，不接受其他内容。若要读取不同的切片，请构建另一个已保存的视图，通常使用布尔型行项目加筛选器。 |
| 仅当行项目位于列上时才载入声明的类型 | 当行项目位于视图的列轴上时，每个数据列都会按其行项目声明的 Anaplan 格式（数字、文本、布尔、日期、时间段或列表）载入为对应类型。当行项目位于行上（常见的损益表布局）或视图中根本没有行项目时，所有数据列都会改为以文本载入，并给出具名警告。原因是一个数据列可能跨越多个行项目，因而涉及多种格式，而表的一列只能有一种类型。 |
| 页选择器的值不会载入为列 | 视图中已保存的页选择器成员包含在 CSV 标题中并在其中被使用，不会作为列出现在目标表中。 |
| 有歧义的数字会被拒绝而不是猜测 | 带有千位分隔符的数字型值，或既可读作普通小数又可读作欧式写法的值（例如 `1.234`），会按名称被拒绝而不会被解析，除非同一列中的另一个值能确定正确的读法。此读取路径没有可用于消除歧义的区域设置字段。能够解析的值会以完整精度载入，没有舍入误差，空白单元格始终载入为空值。 |
| 空视图载入为空，并带有警告 | 如果已保存视图的筛选器没有匹配任何内容，则会用空表替换目标表并发出警告，这属于正常结果，不是失败。例外情况是行轴上没有任何维度的视图：没有行标签角单元格可用来核对空结果，因此步骤会拒绝，以免因误读标题而清空表。 |
| 只读 | 绝不会向 Anaplan 写回任何内容。 |
