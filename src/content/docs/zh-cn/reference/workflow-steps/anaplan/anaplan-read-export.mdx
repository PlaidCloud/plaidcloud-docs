## 说明

通过您的 [Anaplan 连接](/zh-cn/guides/connections/anaplan/)运行一个**已有的** Anaplan 导出操作，并将其生成的文件加载为表。该导出操作必须已存在于模型中（API 无法创建），并且此步骤无法缩小其输出范围：在 Anaplan 中配置为导出什么，加载的就是什么。

此步骤显示在步骤菜单的 **Anaplan** 下。

该步骤通过 Anaplan 的 Bulk API **直接连接云端**，没有本地代理路径。

<Aside type="tip">
此连接器是只读的，使用 Basic（用户名和密码）或 CA 证书凭据进行身份验证，请参阅[身份验证](/zh-cn/guides/connections/anaplan/#身份验证)。Anaplan 的请求预算在整个租户范围内共享，因此请将此步骤的计划与您的其他 Anaplan 工作流错开，请参阅[计划注意事项](/zh-cn/guides/connections/anaplan/#计划方面的注意事项)。
</Aside>

## 配置

### 源和目标

| 字段 | 必填 | 备注 |
|---|---|---|
| Anaplan 连接 | 是 | 用于读取的 [Anaplan 连接](/zh-cn/guides/connections/anaplan/)。 |
| 环境 | 是 | 该连接的环境。 |
| 工作区 | 否 | 覆盖连接上保存的工作区 ID。可从连接实时发现，或手动输入。 |
| 模型 | 否 | 覆盖连接上保存的模型 ID。选定工作区后可实时发现，或手动输入。 |
| 导出 | 是 | 要运行的 Anaplan 导出操作。选定工作区和模型后可实时发现，或手动输入。无法在此处覆盖其选择，它完全按照 Anaplan 中的配置运行。 |
| 轮询次数 | 是 | 默认为 120。在步骤拒绝之前，轮询导出任务是否完成的次数，并会指明任务 ID。它绝不会悄悄地重新提交：Anaplan 没有记载如何区分由同一导出操作生成的两个文件，因此重新提交有可能把错误的文件绑定到本次运行。 |
| 轮询间隔（秒） | 是 | 默认为 5。两次轮询之间等待的秒数。 |
| 目标表 | 是 | 导出结果加载到的表。每一列都以文本形式加载。 |

## 此步骤无法表示的内容

| 限制 | 含义 |
|---|---|
| 需要已有的导出操作 | API 无法创建导出操作，并且此步骤发送的请求不包含任何形式的视点、成员选择或切片参数：在 Anaplan 中配置为输出什么，加载的就是什么。若要更改其生成的内容，请在 Anaplan 中构建或编辑导出操作。 |
| 每一列都以文本形式加载 | Anaplan 发布的用于声明导出列类型的字段，在 Anaplan 自己发布的文档中就前后不一致，因此无法信赖它来为列确定正确的类型，所以不会据此为任何列指定类型，这是有意为之且永久如此。请在下游步骤中转换您需要的列。 |
| 数字按美国格式请求；仍带分组的列会被标记而不是被修正 | 导出任务在提交时要求使用美国数字格式。如果某一列返回时仍带有千位分隔符，就意味着导出没有按该格式呈现：步骤会将该值原样以文本加载并给出警告，指明该列和一个示例值，而不是去猜测哪个字符是小数点。在下游转换之前请检查这样的列：欧式的 `1.234.567` 若被读成 `1.234`，就会小一千倍。 |
| 宁可拒绝也不加载不可靠的提取结果 | 在以下情况下，步骤不会加载任何内容，而不是加载一个看似完整实则不完整的表：导出任务失败或在 Anaplan 中未报告成功；任务被取消；步骤的轮询预算用尽后任务仍在运行；生成的文件完全没有数据；生成的文件无法追溯到生成它的导出；或者读取的行数与 Anaplan 自己报告的该导出的行数不一致。 |
| 只读 | 绝不会向 Anaplan 回写任何内容。 |
