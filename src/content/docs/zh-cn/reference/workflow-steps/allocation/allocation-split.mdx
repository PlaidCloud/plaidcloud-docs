## 说明



将源行中的值拆分为多个部分，并将每一部分路由到不同的目标，比例由驱动因素数据决定。它比 [Allocation Rules 步骤](/zh-cn/reference/workflow-steps/allocation/allocation-rules/)更简单，适用于只需要将值分发出去、而不需要分配维度的情况。

常见模式：取一个总金额，根据驱动因素表中的百分比或权重将其分给多个接收方，并为每个接收方生成一个输出行。

## 数据表设置

**待分摊值表**、**驱动因素数据表**和**分摊结果表**可以动态或静态选择。

### 动态表选择
动态表选项允许使用文本和变量指定表。这在使用由变量驱动的工作流时很有用，此时对表或视图的引用与所指定的变量相关。

下面的示例使用 `current_month` 变量动态指向一个表：

```text
legal_entity/inputs/{current_month}/ledger_values
```

### 静态表选择
如需将特定表用作源，请不要选中 *Dynamic* 框，并使用下拉菜单选择源表。


任何表选择都始终可以使用表资源管理器。单击表选择右侧的“表资源管理器”按钮，将打开表资源管理器窗口。

<Aside>**分摊结果表**必须是表，而不能是视图。</Aside>

### 待分摊值表

此表包含要分摊的值，这些值通常是成本或收入值。


### 驱动因素数据表

驱动因素数据表包含分摊步骤将用来分摊成本的值。


示例：

- 供应链要将成本分配给客户时，可以使用配送数据，以配送次数或配送重量作为驱动因素。
- IT 服务台要将其成本分配给其所支持的部门时，驱动因素数据可以是按成本中心统计的工单数量。

#### 驱动因素数据符号规则
驱动因素数据可以同时包含正值和负值。**Driver Data Sign Rule** 让您决定如何处理冲突的符号。
- **Error on conficting signs**：遇到冲突的符号时，分摊步骤会产生错误并停止。
- **Proceed with warning on conflicting signs**：分摊步骤会同时使用负值和正值的驱动因素值，但会显示警告。
- **Use only positive driver values**：分摊步骤只使用正的驱动因素值，忽略负值。
- **Use only negative driver values**：分摊步骤只使用负的驱动因素值，忽略正值。
- **Use absolute values of driver data**：分摊步骤使用驱动因素数据的绝对值。


### 分摊结果表



#### 将结果追加到目标表
如果选中此框，分摊结果将追加到分摊结果表。
如果未选中此框，则每次运行分摊步骤时都会覆盖分摊结果表。

#### 分摊结果使用单独的列

如果选中此框，则结果表会显示每条已分摊记录的金额，以及实际分摊给每条驱动因素记录的金额。
