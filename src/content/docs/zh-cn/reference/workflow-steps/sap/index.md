三个步骤可搜索 SAP、预览并规划提取，然后将结果保存到表中。一个读取表，一个运行事务或报表，一个运行已保存的 SAP Query。请参阅 [SAP ECC / S/4HANA 临时提取](/zh-cn/guides/connections/sap-adhoc-extract/)。
