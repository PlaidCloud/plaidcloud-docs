## 描述

在 PlaidCloud 只能通过 PlaidLink 代理访问的数据库上执行 SQL，通常是因为数据库位于防火墙后、专用网络中或本地数据中心内。代理在本地运行 SQL，并将成功或失败的结果报告回 PlaidCloud。

可用于在 PlaidCloud 工作流中触发远程存储过程、刷新例程或维护作业，而无需将源数据库暴露到公共互联网。

## 预览查询

在**远程执行：SQL** 步骤中，**源**选项卡上的**预览**最多显示 100 行，而不会运行该语句，因此您可以在运行之前检查 `SELECT`。预览填充变量的方式与运行相同，但不支持 `{x:>9}` 之类的变量格式。它只读取数据：写入数据的语句，或预览无法确认是只读的函数，会被拒绝，并显示*预览仅支持标准 SQL 函数。请运行该步骤以查看结果。*在已锁定的项目中，或对于将 `:name` 占位符与驱动因素表一起使用的语句，预览不可用。对于本页所述的基于代理的步骤，预览也不可用，因为只有代理才能访问这些数据库。

## 每行运行一次语句

**远程执行：SQL** 步骤直接连接数据库而不是通过代理，它可以对表的每一行各运行一次语句，例如为每个输入行调用一个存储过程。将**运行 SQL**设置为**每行一次**，选择**驱动因素表**，并填写**参数**。语句中的每个值都写成 `:name` 占位符，例如 `CALL load_region(:region, :period)`，并在**参数**中将每个占位符映射到提供该值的**驱动列**。每个值都作为绑定参数发送到数据库，绝不会粘贴到语句文本中。

每个参数都需要同时具有名称和驱动列，且同一个参数不能列出两次。当语句中的某个 `:name` 没有映射，或某个映射不在语句中时，表单会给出警告。驱动因素表必须是表，而不能是视图。没有行的驱动因素表会以警告结束并且不运行任何内容，超过 100,000 行的驱动因素表会使步骤失败且不运行其中任何一行，因此请先对其进行筛选。

## 在一个事务中运行脚本

在**远程执行：SQL** 步骤中，勾选**在一个事务中将 SQL 作为语句脚本运行：全部生效或全部不生效**（`transaction`），即可将 SQL 作为语句脚本在单个事务中依次运行，因此要么每条语句都生效，要么都不生效。
