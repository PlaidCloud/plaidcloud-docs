## 说明



通过 PlaidLink 代理在远程数据库上运行 SQL，并将结果集作为项目表带回 PlaidCloud。适用于 PlaidCloud 无法直接访问源数据库（防火墙、仅限 VPN、本地部署）但仍希望从中提取数据的情况。

代理在本地运行查询并将结果流式传输到 PlaidCloud，因此在需要结果之前，凭据和数据都保留在您的网络内。
