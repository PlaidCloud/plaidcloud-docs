## 说明

**Fuzzy Match** 步骤根据字段的近似匹配将两个表的行配对（或对单个表去重）。它在工作流引擎中运行；打包宏的结果近似于 Alteryx 宏。

## 参数

- **Left / Right Tables** 和 **输出表**。
- **记录 ID 列**、**阈值**（0-100）和 **同时输出未匹配的行**。
- **匹配字段**：要匹配的字段及其各自的匹配函数（exact / jaro / levenshtein / bestof / jaro_tfidf / bestof_tfidf）。
