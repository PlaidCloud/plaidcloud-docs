## 说明

**表：删除列** 步骤会将源表的副本写入输出表，并排除您选择的列。其余每一列都保留原有的名称、类型和位置。

## 源和选项

- **源表** 和 **输出表**：要读取的表和要写入的表。
- **要删除的列**：要排除的列。至少选择一列。源表中不存在的列会被忽略，因此即使前面的步骤不再生成该列，此步骤仍可运行。
- **数字顺序前缀** *（可选）*：将以此文本开头的保留列按数字顺序排列，占用它们原有的位置。使用前缀 `Tags_` 时，`Tags_2` 排在 `Tags_10` 之前，而不是之后。
- **列名称表**（`drop_from`）和 **保存名称的列**（`drop_from_column`，默认为 `drop`），位于 **由表指定的列** 部分 *（可选）*：该表在指定列中的单元格各为一个列名称的 JSON 列表，用于指定要排除的更多列。该表在步骤运行时读取。
