## 说明

**表：拆分文本** 步骤在分隔符处拆分一列中的文本，并将拆分出的片段写为新列或新行。列数在步骤运行时根据片段最多的值确定，因此无需事先知道。

## 源和选项

- **源表** 和 **输出表** — 要读取的表和要写入的表。
- **要拆分的列** — 要拆分的列。数字按其文本进行拆分。
- **分隔符** — 片段之间的字面文本。可以是任意长度，且不是模式。空格按输入原样保留。
- **拆分为** — **列** 或 **行**。
  - **列** 写入 `<column>_1`、`<column>_2` 等，数量与片段最多的值相同。片段较少的值在其余列中为 NULL。
  - **行** 每个片段写一行，片段取代原列的位置。空片段仍保留为行。
- **去除每个片段两侧的空格** — 默认开启。
- **保留原始列** — 默认开启。在列模式下，保留被拆分的列。在行模式下，还会把未拆分的值写入 `<column>_original`。

空结果会替换输出表，不会留下先前运行的行。

### 列的其他设置

拆分为列时，**更多拆分选项** 还包含以下设置：

- **片段名称前缀** (`prefix`) — 将片段命名为 `<prefix><n>`，而不是 `<column>_<n>`。**第一个片段的编号** (`start`，默认 1) 是第一个片段的编号。
- **片段列名称** (`names`) — 片段列的名称，按顺序排列。恰好写入这么多列，除非开启 **仅写入与最长值的数量相同的命名列** (`fit`)：此时只写入片段最多的值所拥有的列数。
- **片段类型** (`dtype`) — 片段的类型：`text`（默认）、`integer`、`bigint`、`double`、`boolean`、`date` 或 `timestamp`。无法按该类型读取的片段为 NULL。
- **要去除的字符** (`strip`) — 从每个片段两端去除的字符，取代 **去除每个片段两侧的空格** 所去除的空格。
- **该列保存 KNIME 集合** (`collection`) — 该列保存来自已转换 KNIME 工作流的列表值。其元素就是片段，不使用分隔符：缺失的元素为 NULL，空列表没有片段。

**KNIME 节点** (`knime_config`) 通过此步骤运行 KNIME 的 Line Chopper、Expand Vector 或 Sample and Expand Vector 节点之一：`chopper` 写入一列中前几个以空白分隔的标记，`expand_vector` 将向量列的元素写为列，要保留的位置列在表 **元素位置表** (`source_b`) 中，`sample_expand_vector` 展开元素的随机样本，并将抽样的列名写入 **抽样列名称表** (`targets`) 中的表。
