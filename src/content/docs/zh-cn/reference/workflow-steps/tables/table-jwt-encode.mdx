## 说明

**表：JWT 编码** 步骤会对负载列中的 JSON 签名，并将令牌写入新的文本列，每行一个令牌。输出表是源表的副本，并添加了该列。

## 源和选项

- **源表** 和 **输出表**：要读取的表和要写入的表。
- **算法**：`HS256`、`HS384`、`HS512`、`RS256`、`RS384` 或 `RS512`。
- **载荷列**：保存要签名的 JSON 负载的列。
- **头部列** *（可选）*：保存 JSON 头部的列。它会合并到默认头部 `{"alg": …, "typ": "JWT"}` 之上。
- **密钥列** *（可选）*：保存签名密钥的列。未指定时，步骤使用其连接所保存的密钥进行签名。
- **输出列**：接收令牌的文本列的名称。

转换后的 Savant 分析使用绑定到该步骤的专用连接中保存的密钥进行签名，因此密钥绝不会出现在步骤配置中。请参阅 [Migrate Savant Analyses](/zh-cn/guides/workflows/migrate-savant-analyses/#jwt_encode)。
