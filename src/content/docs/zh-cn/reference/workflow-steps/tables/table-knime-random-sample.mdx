## 说明

**表：KNIME Random Sample** 步骤使用 KNIME 所用的随机数生成器执行 KNIME 节点的随机抽取，因此带种子的节点在 PlaidCloud 中抽取的行或值与在 KNIME 中相同。[已迁移的 KNIME 工作流](/zh-cn/guides/workflows/migrate-knime-workflows/)将此步骤用于 Row Sampler、Table Partitioner、Equal Size Sampling、Bootstrap Sampling、Shuffle、X-Partitioner 以及随机数据生成节点。

抽取会将源表读入工作流，因此表最多只能有 10,000,000 行；更大的表会导致步骤失败。

步骤表单包含用于源表和输出表的 **表** 部分、用于 **方法**、**种子** 和样本大小的 **抽取** 部分，以及用于读取和写入列的 **列** 部分。

## 配置

- `source` 和 `target_frame`：要读取的表和要写入的表。
- `position_column`：保存每行从 0 开始的位置的列。默认为 `_knime_pos`。
- `method`：抽取方式：
  - `random`、`stratified`、`equal_exact` 和 `equal_approximate` 保留 Row Sampler、Table Partitioner 或 Equal Size Sampling 抽取所选行的位置。`class_column` 和 `class_dtype` 指明分层抽取或等量抽取的类别列。
  - 所有其他方法会将其抽取结果与行位置并排写入：`uniform`、`gaussian`、`gamma`、`beta`、`label`、`label_dependent`、`label_from_table`、`boolean`、`mersenne_twister`、`sobol` 和 `halton`（随机数据生成）、`shuffle`、`bootstrap`、`match`（Random Matcher）、`item_insert`（Random Item Inserter）、`stress`（Stresser）、`sample_data`（Sample Data Generator，无源表）、`kfold`（X-Partitioner 折）、`p_square`（按分组的 P² 百分位数估计）、`set_bits`（位向量）、`equal_count_edges`（Binner 的等计数边界）和 `border_texts`（Auto-Binner 的边界文本）。
- `seed`：随机数流的种子。为空时从时钟抽取，与 KNIME 在没有种子时的行为一致，因此每次运行的行都会不同。
- `count`、`percentage` 和 `relative`：要抽取的行数：一个计数，或在使用 `relative` 时为一个百分比。`count_column` 改为从源列获取计数，适用于只有在工作流运行时才能得知的计数。
- `parameters`：抽取方法读取的节点设置，例如 `gaussian` 抽取的分布或 `kfold` 抽取的折数。
- `source_columns` 和 `target_columns`：对于抽取方法，指读取的列和写入的列，位置列在前。
- `source_b` 和 `source_columns_b`：第二个输入，例如 `label_from_table` 的类别表或 `match` 所抽取的表。`target_frame_b` 和 `target_columns_b` 接收 `sample_data` 的聚类中心。
