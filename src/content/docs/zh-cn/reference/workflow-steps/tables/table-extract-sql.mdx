## 描述

通过您自己编写的 SQL `SELECT` 填充目标表。[Table Extract 步骤](/zh-cn/reference/workflow-steps/tables/table-extract/)根据映射的列和表达式构建查询，而此步骤则将查询直接交给 Warehouse，适用于直接用 SQL 表达比在映射器中组装更容易的情况。

当您需要映射器无法涵盖的构造时可以使用它：递归 CTE、映射器无法描述其分区的窗口函数，或者针对多个表的查询（使用联接步骤会让它更复杂）。

## 独有的配置项

### SQL 选择查询

查询文本。请将其格式化为易读的多行缩进 SQL（每行一个列或子句），而不是单个长行；步骤会保留您所写的内容，下一个打开它的人需要阅读。

查询在项目的 Lakehouse 上运行，因此可用的函数是 [Lakehouse v1](/zh-cn/reference/expressions/lakehouse-v1/) 或 [v2](/zh-cn/reference/expressions/lakehouse-v2/) 集合，具体取决于工作区。

<SnippetCommonStepPreview />

与其他 SQL 步骤不同，此步骤不填充变量，因此其预览也不填充。
