## 说明

通过您自己编写的 SQL `SELECT` 填充目标表。[Table Extract](/zh-cn/reference/workflow-steps/tables/table-extract/) 根据映射的列和表达式构建查询，而此步骤则将查询直接交给数据仓库，适用于直接编写 SQL 比在映射器中组装更容易的情况。

当您需要映射器无法覆盖的结构时，可以使用它：例如递归 CTE、映射器无法描述的分区上的窗口函数，或者用联接步骤会变得更复杂的多表查询。

## 专有配置项

### SQL 选择查询

查询文本。请将其格式化为可读的多行缩进 SQL（每行一个列或子句），而不是一整行长文本；步骤会保留您所写的内容，下一个打开它的人需要阅读它。

查询在项目的 lakehouse 上运行，因此可用的函数是 [Lakehouse v1](/zh-cn/reference/expressions/lakehouse-v1/) 或 [v2](/zh-cn/reference/expressions/lakehouse-v2/) 函数集，具体取决于工作区。
