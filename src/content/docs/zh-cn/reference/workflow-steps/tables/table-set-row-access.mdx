## 说明

设置行访问权限步骤会根据源表重新计算受管控列的行访问授权并应用。让该列指向一个表，表中每一行将一个安全组与该组可以查看的一个值配对，此步骤读取这些行并写入生成的授权，使行访问权限随源数据的变化保持最新，无需任何人手动编辑网格。

该列必须已经限制了行，请先在“行访问”网格中进行设置。步骤首次运行时会把该列绑定到源表：该列手动设置的授权会被清除，并由表中的行取代。此后，该列在“行访问”网格中显示为锁定状态，并带有源徽章，在有人点击 **移除绑定** 之前，无法在网格中手动编辑。请参阅“行访问”指南中的[将授权绑定到源表](/zh-cn/administration/access/managing-security-groups-and-assignments/#将授权绑定到源表)。

<Aside type="note" title="用它让授权与变化的数据保持同步">
典型用法是在加载或刷新源表的工作流之后安排运行此步骤，这样新增的分组、移除的值或重新分配的区域会在下次运行时自动同步到行访问权限，而不必靠人记得去手动更新网格。
</Aside>

## 参数

- **项目** — 此步骤要更新其受管控列的项目。
- **列** — 受管控列，从项目的实际列中选取。
- **源表** — 提供（分组，值）行的表。指定与该列当前绑定的表不同的表，会把该列重新绑定到新表。
- **组列** — 源表中用于指定安全组的列。
- **值列** — 源表中用于指定该组可以查看的值的列。

## 行为

每次运行都会读取源表中当前的所有（分组，值）行，并用恰好这一组授权替换该列的授权，源表中不再出现的分组，将失去此步骤先前授予它的全部授权。指向不存在的安全组的行会被跳过，而不会导致步骤失败。更新对 PlaidCloud 自身的查询和 Superset 仪表板的生效方式与手动保存相同，通常在约一分钟内完成。

由于源表决定了谁能看到什么，一旦绑定，只有项目架构师、租户管理员或该项目自己的工作流才能更改其行或删除它。

<Aside type="caution">
此步骤会替换它所管理的 *全部* 授权。如果您手动维护某些列的部分授权，同时又从源表维护其他授权，请把两者放在不同的列上，源绑定列上手动编辑的授权在两次运行之间不会保留。
</Aside>
