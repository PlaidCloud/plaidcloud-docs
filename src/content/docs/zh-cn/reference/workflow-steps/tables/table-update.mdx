## 描述

更新与筛选器匹配的行，并将结果写入目标表。每个源行都会到达目标：匹配筛选器的行带有新值，其他每一行则保持原样。目标的行数始终等于源的行数。

筛选器选择的是哪些行被*更改*，而不是返回哪些行。这正是此步骤与 [Table Extract 步骤](/zh-cn/reference/workflow-steps/tables/table-extract/)的区别：在 Table Extract 中，筛选器会移除不匹配的行。

<Aside type="note" title="此步骤不再更改源表">
它过去会原位更新源表。现在它保持源表不变，并写入单独的目标，因此原始数据仍可用于比较，并且该步骤可在所有 Warehouse 上运行，包括那些不允许原位更改表的 Warehouse。在此更改之前保存的步骤需要先选择目标表才能运行，任何读取源并期望看到已更新行的步骤，都必须改为指向新的目标。
</Aside>

## 更新参数

<SnippetCommonTableSourceAndTarget />

目标必须是与源不同的表：此步骤会读取每个源行并将其写出，因此如果将其指回自己的源，就会把结果追加到刚刚读取的数据中。

<Aside type="note" title="源必须是表，而不是视图">
视图可以被选为**目标**（在这里是个不错的选择：视图不存储数据，每次读取时都会针对源重新计算），但不能作为**源**：此步骤从源表自身的架构获取目标的列列表，而视图不带有该架构。
</Aside>

目标的列始终与源的列一致，因此您无需选择它们。未更新的列会原样传递，包括在此步骤上次打开之后添加到源中的任何列。

## 要更新的列

在**列**选项卡上，为每个要更改的列添加一行，并且恰好设置以下其中一项：

- **常量**：固定值。
- **表达式**：计算，可以引用同一行的其他列。
- **设为 Null**：清空该列。

未列出的列保持不变。

左侧的源列中未列出的**更新列**，会在 ⚠ 警告标志后以红色显示，即使该行带有**常量**、**表达式**或**设为 Null** 也是如此，因为步骤是按确切名称更新该列的。保存带有这类行的步骤时，会打开**发现过时列**对话框，其中提供**全部移除并保存**、**仍然保存**或**取消**。

保存时还会按确切名称，针对源表当前的状态检查每个**更新列**，无论源列列表中列出了什么。表中不存在的更新列会在**缺少源列**对话框中点名，因为步骤运行时会在该列上失败。源列列表本身不会与表核对：此步骤读取的是表的当前状态，而不是该列表。

<Aside type="caution" title="表达式读取的是行的原始值">
表达式看到的是更新*之前*的行，因此两个列可以在单个步骤中安全地互换值。
</Aside>

## 更新用的数据筛选器

在**筛选器**选项卡上，输入用于标识要更改的行的条件。留空则更新每一行。

无法计算其条件的行（最常见的原因是它所测试的列为 null）会被视为不匹配，并原样通过。这与数据库计算同一条件的方式一致。
