## 说明


Table Anti Join 步骤提供两个表之间未匹配的项目集。它返回第一个表中在第二个表里没有匹配项的项目列表，这对于确定哪些记录存在于一个表而不存在于另一个表非常有用。



这一操作也可以通过外联接并对联接的空值进行筛选来完成；不过，反联接转换会以更高效、更直观的方式执行。

<Aside type="note" title="这是左侧排除联接，而不是左联接">
Table Anti Join 步骤保留源 A 中在源 B 里**没有**匹配项的行。其行为由步骤类型固定，因此没有联接类型选择器。如果需要**左联接**——保留源 A 的每一行，并在键匹配时填入源 B 的列——请使用 [Table Outer Join 步骤](/zh-cn/reference/workflow-steps/tables/table-outer-join/)，并将其**联接类型**设置为**左联接**。由于反联接只返回未匹配的源 A 行，其输出仅来自**源 A**；源 B 提供联接键，但不提供输出列。
</Aside>

## 运行时指定名称的列

选择**同时带入运行时指定名称的列**，可将步骤未列出的每个源列按步骤运行时表中的样子原样传递。当前面的步骤（如透视）创建了名称取决于数据的列，导致构建步骤时无法列出它们时，可使用此选项。不选则只写入您列出的列。
