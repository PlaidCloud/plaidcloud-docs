## 说明

**表：期间序列** 步骤会为第一个日期和最后一个日期之间的每个期间写入一行，无论该期间内是否有记录。将该序列联接到汇总数据，可将没有活动的期间显示为零，而不是将其遗漏。

## 源和选项

- **源表** 和 **日期列**：其日期决定边界的表。除非同时给出起始日期和结束日期，否则这两项是必需的；给出时不会读取源表。
- **期间**：**日**、**周**、**月**、**季度**、**年** 或 **十年**。一周从星期一开始。
- **起始日期** *（可选）*：第一个期间。留空则从源表中最早的日期开始。
- **结束日期** *（可选）*：最后一个期间。留空则在源表中最晚的日期结束。起始日期晚于结束日期时，两者会互换并给出警告。
- **输出列**：保存每个期间第一天的日期列的名称。默认为 `Period Start`。
- **输出表**：写入序列的位置。

步骤在达到 100,000 个期间时停止，并给出警告。对于更大的范围，请选择更长的期间或更窄的日期。
