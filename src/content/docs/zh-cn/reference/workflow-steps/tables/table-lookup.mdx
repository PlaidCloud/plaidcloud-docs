## 说明


如果您经常使用 Microsoft Excel 中的 vlookup 函数，Table Lookup 转换会让您感到非常熟悉。它的作用与之基本相同。与 Microsoft Excel 版本不同，PlaidCloud Analyze 的 Table Lookup 转换更加灵活，尤其是允许匹配并返回多个列。

## 示例


### 查找产品维度信息


在此示例中，建模人员需要产品维度表中的信息，才能理解订单事实表。因此，选择 *Import Order Fact* 表作为 **源表**。*Import Product Dim* 表包含所需的查找信息，因此将其选为 **Lookup Table Source**。虽然可以使用筛选器，但没有对查找数据表（或任何其他数据表）应用筛选器。



在 **表数据选择** 部分，所有列都从源数据表映射到目标数据表。



没有对源数据或目标数据应用任何 **数据筛选器**。



最后，使用两个表中都有的 *Product_ID* 字段将源数据表与查找数据表匹配。只有 *Product_Description* 和 *Unit_Cost* 列会被追加到目标数据表，其中 *Unit_Cost* 在此过程中被重命名为 *Retail_Unit_Cost*。



在生成的目标数据表中，已根据 *Product_ID* 列中的匹配值添加了 *Product_Description* 和 *Retail_Unit_Cost* 列。
