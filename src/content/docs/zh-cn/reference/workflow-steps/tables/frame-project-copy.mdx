## 说明

将表从一个项目复制到另一个项目。可用于在项目之间拉取共享的参考表、已发布的结果集或基于维度的查找表，而无需先导出为文件再导回。

两侧都需明确指定——源项目和源表，以及目标项目和目标表。目标项目默认为当前项目，但可以是任何项目，因此步骤可以复制到本项目、从本项目复制出去，或在另外两个项目之间复制。目标表如不存在则会创建，并且必须是表而不是视图。

## 数据共享管理

一次复制最多需要两个数据共享：

- **读取，从源项目到目标项目**，这样源的数据只会落在源共享给的地方。打开**源**项目的**主页**选项卡，在**数据共享管理**下单击**新建数据共享**，选择目标项目，在**允许的操作**下勾选**读取**，然后单击**添加数据共享**。
- **写入，从目标项目到本项目**（即工作流所在的、负责写入的项目）——当目标是另一个项目时需要。打开**目标**项目的**主页**选项卡，在**数据共享管理**下单击**新建数据共享**，选择本项目，在**允许的操作**下勾选**写入**，然后单击**添加数据共享**。

因此，复制到本项目只需要读取共享，而在同一项目内复制则两者都不需要。请参阅[在项目之间共享数据](/zh-cn/guides/projects/managing-projects/#在项目之间共享数据)。

缺少所需的共享时，保存步骤会被拒绝，运行也会失败，并给出指明每个需要添加的共享的消息——例如 *Project 'Sales' can't write to project 'Finance': in project 'Finance', under Data Sharing Management, add a data share for 'Sales' that allows Write.* 被拒绝的运行会保持目标项目原样，不会创建目标表。以变量形式给出的项目会在步骤运行时检查。

该步骤以本项目自身的身份运行，因此无论由谁启动，运行都通过这些共享进行。

## 复制参数

### 读取自

- **源项目**——要从中复制的项目。
- **源表**——要复制的表，从源项目中选择。

### 写入到

- **目标项目**——要复制到的项目。默认为当前项目。
- **目标表**——要写入的表，从目标项目中选择。选择不同的**目标项目**会清除您从旧项目中选择的表；以名称或路径给出的表会被保留，并在新项目中查找。
- **追加到现有数据**——勾选后，将复制的行添加到目标表已有的内容之后。不勾选则用源的行替换该表的行。

已保存但您看不到或已被删除的项目会标记为 **(missing)** 显示，而不会被替换为其他项目。
