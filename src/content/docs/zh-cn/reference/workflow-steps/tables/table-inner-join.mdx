## 说明


用于对两个数据表执行内联接操作，根据指定的联接键将它们合并为一个数据表。


有关内联接方法的更多详细信息，请参阅：[Wikipedia SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## 示例


### 联接汽车制造商与车型


在此示例中，请看以下源数据表。首先是汽车制造商列表。



| Mfg_ID | 制造商 |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

接下来是带有制造商 ID 的汽车车型列表。请注意，有几个车型没有制造商。




| 车型名称         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

要获取按制造商划分的车型列表，适合按 *Mfg_ID* 联接。


首先，指定 **Table 1 Data Selection** 的参数。选择源数据表，并列出所有列。



接下来，指定 **Table 2 Data Selection** 的参数。同样选择源数据表，并列出所有列。



最后，在 **Table Output** 选项卡中设置联接条件。使用 **推测** 按钮，Analyze 会正确识别出 *Mfg_ID* 列作为 **Join Key**。最后，


**目标输出列** 通过 **传播** 按钮自动指定。这实际上包含所有表中的所有列，其中所有联接列只包含一次。请注意，列按字母顺序排序，首先按 *Manufacturer*，其次按 *ModelName*。



正如预期，最终输出只包含在两个表中都有匹配的值。因此，*Porsche* 不会出现，因为它没有车型。同样，


*Batmobile* 没有制造商（它是定制车），所以不包含在内。
