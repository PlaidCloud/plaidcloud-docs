## 说明

将源表中的行添加到现有目标表的末尾。目标中的现有行会被保留；只插入新行。适用于数据增量到达（例如每日提取、每月加载文件）并希望随时间扩充目标表而不是替换它的情形。

如果需要在追加时去重，可在其后接 [Table Union Distinct 步骤](/zh-cn/reference/workflow-steps/tables/table-union-distinct/)；如果有些行要按键更新现有记录，则使用 [Table Upsert 步骤](/zh-cn/reference/workflow-steps/tables/table-upsert/)。

## 保存时的检查内容

- **映射与现有目标表相符。** 目标表已存在时，步骤不能映射该表没有的列，也不能给列指定与表不同的类型。数值和货币视为同一类型。映射中省略的表列是允许的，在追加的行中保持为空。拒绝消息会指明每处差异，例如 *The target columns must match the existing target table 'sales'. Types differ: amount (table: numeric, step: text).* 尚不存在的目标表，或以变量命名的目标表，会在步骤运行时检查。
- **空映射会自动填充。** 选择了源表但没有源列或目标列时，保存会根据源表填充空的一侧，效果与**填充两个映射表**相同。
