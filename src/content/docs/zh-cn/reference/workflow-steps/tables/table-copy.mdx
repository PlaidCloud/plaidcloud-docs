## 说明


创建数据表的副本。




<SnippetCommonTableSourceAndTarget />



执行复制时，Analyze 会先检查目标数据表是否已存在。如果已存在，则不执行任何操作，除非选中 **Allow Overwriting Existing Table** 复选框。选中后，目标表将被覆盖。
