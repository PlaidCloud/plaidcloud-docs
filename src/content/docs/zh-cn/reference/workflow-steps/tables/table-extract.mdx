## 说明


用于将现有 Analyze 数据表中的数据提取到另一个数据表中。用途包括但不限于：


* 排序
* 分组
* 汇总
* 筛选/选取行子集
* 删除多余的列
* 数学运算
* 字符串运算

<Aside>此转换没有独有的功能。所有排序、分组、筛选等操作都可以在其他任何转换中通过 **表数据选择** 和 **数据筛选器** 选项卡完成。</Aside>

## 运行时命名的列

选择 **同时带入运行时指定名称的列**，即可将步骤未列出的所有源列按步骤运行时表中的实际情况原样传递。如果之前的某个步骤（例如透视）生成的列名取决于数据，导致构建步骤时无法列出这些列，就可以使用此选项。关闭此选项则只写入您列出的列。

启用后会出现 **携带列** 部分，而 **由数据命名的列** 部分始终可用。它们包含以下字段：

* **携带方式**（`carry_expression`）——将每个携带列写为此表达式而不是原样写入，其中 `__column__` 代表该携带列。分组步骤正是通过这种方式纳入只有在运行时才确定名称的列；如果没有此表达式，聚合步骤不会携带任何列。**携带列的类型**（`carry_dtype`）设置每个携带列的数据类型（默认为其自身的类型），**携带列的聚合方式**（`carry_agg`）设置聚合步骤如何处理该列（当表达式本身已做聚合时为 `dont_group`）。
* **重命名携带的列**（`carry_rename`）——对名称与正则表达式 `pattern` 匹配、且不与 `keep` 匹配的每个携带列进行重命名，方法是用 `replacement` 替换每处匹配（`\1` 表示分组；设置了 `max` 时只替换相应数量的前几处匹配）。`replacement` 中的 `__index__` 是该列在被重命名列中的位置，从 `start` 开始计数。如果名称已被占用，会追加 ` (#n)`。
* **动态列**（`dynamic_columns`）——由数据命名的目标列，步骤从其源中读取到的每个不同值各对应一组，在步骤运行时写入。每个条目包含 `rows`（基于源的表达式 `key`、`label`、`where` 和 `order`）、使用 `__key__`、`__label__` 和 `__index__` 的 `target` 列或列列表，以及 `after`（新列跟随在其后的目标列，默认为末尾）。值必须是文本、整数、布尔值或 NULL，步骤最多写入 1,000 列，且输出必须是表。
