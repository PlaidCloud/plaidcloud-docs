## 说明


用于对两个数据表执行交叉联接操作，在没有联接键的情况下将它们合并为一个数据表。


任一表上的源筛选器都会在估算联接规模之前应用，因此只要筛选后的行数足够少，即使是针对大型表的带筛选交叉联接也可以运行。

有关交叉联接方法的更多详细信息，请参阅：[Wikipedia SQL Cross Join](https://en.wikipedia.org/wiki/Join_%28SQL%29#Cross_join)

## 运行时指定名称的列

选中 **同时带入运行时指定名称的列**，可将步骤中未列出的每个源列按步骤运行时表中的状态原样传递。当前面的步骤（例如透视）创建了名称取决于数据的列，导致构建步骤时无法列出这些列时，请使用此选项。不选则只写入您列出的列。
