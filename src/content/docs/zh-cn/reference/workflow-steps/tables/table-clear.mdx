## 说明


清除现有数据表的内容，但不删除数据表本身。最终结果是一个包含 0 行的数据表。



<SnippetCommonTableSelectionDynamic />

使用**匹配搜索的表**时，如果**搜索路径**为项目的顶层（`/`）而**搜索文本**为空，则无法保存该步骤，因为这会清除项目中的所有表。请输入要匹配的文本，或选择一个文件夹。
