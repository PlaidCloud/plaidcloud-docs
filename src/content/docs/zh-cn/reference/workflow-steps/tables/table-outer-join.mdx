## 说明


用于对两个数据表执行外联接，根据指定的联接键将它们合并为一个数据表。**联接类型** 控件用于选择要保留的未匹配行：**左联接**、**右联接** 或 **全外联接**。默认为左联接（保留表 A 的每一行，并在键匹配处填入表 B 的列）。


有关外联接方法的更多详细信息，请参阅：[Wikipedia SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## 运行时指定名称的列

选中 **同时带入运行时指定名称的列**，可将步骤中未列出的每个源列按步骤运行时表中的状态原样传递。当前面的步骤（例如透视）创建了名称取决于数据的列，导致构建步骤时无法列出这些列时，请使用此选项。不选则只写入您列出的列。

### 联接类型

选择如何保留未匹配的行：

- **左联接**：保留表 A 的每一行；仅在联接键匹配处填入表 B 的列。这是默认设置。
- **右联接**：保留表 B 的每一行；仅在联接键匹配处填入表 A 的列。
- **全外联接**：保留两个表的每一行，无论另一侧是否有匹配。

## 示例


### 联接汽车制造商与车型


在此示例中，请看以下源数据表。首先是汽车制造商列表。




| Mfg_ID | 制造商 |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


接下来是带有制造商 ID 的汽车车型列表。请注意，有几个车型没有制造商。




| 车型名称          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

要获取按制造商划分的车型列表，适合按 *Mfg_ID* 联接。借助外联接的概念，输出也能显示那些没有任何匹配项的条目。



首先，指定 **Table 1 Data Selection** 的参数。选择源数据表，并列出所有列。



接下来，指定 **Table 2 Data Selection** 的参数。同样选择源数据表，并列出所有列。



最后，在 **Table Output** 选项卡中设置联接条件。使用 **推测** 按钮，Analyze 会正确识别出 *Mfg_ID* 列作为 **Join Key**。由于此示例保留两个表中未匹配的行，请将 **联接类型** 设置为 **全外联接**。最后，


**目标输出列** 通过 **传播** 按钮自动指定。这实际上包含所有表中的所有列，其中所有联接列显然只包含一次。请注意，列按字母顺序排序，首先按 *Manufacturer*，其次按 *ModelName*。



正如预期，最终输出包含两个表中的所有行，无论它们在两个表中是否都有匹配。因此，这次 *Porsche* 虽然没有车型，也确实出现了。此外，*Batmobile*、*Lightning McQueen* 和 *Optimus Prime* 虽然都没有制造商，也包含在结果中。再说了，谁能对它们说“不”呢？
