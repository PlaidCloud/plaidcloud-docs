## 描述

**多表联接**步骤使用可视化的**联接图设计器**，在一次操作中联接多个表（最多 32 个），取代了串联多个双表联接步骤的做法。您可以添加表、在它们的列之间绘制联接、为每个联接选择联接类型和条件，并映射输出列。编辑器有三个选项卡：**Tables & Joins**、**输出列**和 **Post-Join Filter**。

完整的操作说明，请参阅[多表联接步骤指南](/zh-cn/guides/workflows/multi-table-join-step/)。

## 设计器

* **添加表**：将源表作为列卡片放到画布上。每个表都有一个**别名**（用作 `alias.column`），必须以字母或下划线开头，且不能是 SQL 关键字。
* **目标表**：联接结果写入的表；如果不存在则创建。
* **动态**：以引用的方式给出源或目标，而不是从列表中选取：表名称、项目路径（`/03 Results/FACT_GL`），或任一种带有在运行时解析的 `{variable}` 标记。动态源的列在设计时无法读取，因此需要在侧边面板中手动输入。
* **绘制联接**：从一个表的列圆点拖到另一个表的列上即可创建联接；可选的**标签**用于为边命名。
* **入站筛选器**：每个表的筛选器，在联接*之前*应用。
* **从服务器重新获取**：根据最新目录刷新表卡片的列。
* **整理布局** / **适应视图**：自动排列图，或缩放以适应视图；也可手动平移和缩放。
* **撤消** / **重做** / **历史记录**：逐步查看、检查和还原编辑。
* **筛选列…**：缩小表卡片上显示的列。
* **导出**：将联接图下载为 SVG。

## 联接类型

| 类型 | 保留内容 |
|------|-------|
| `INNER` | 在被联接的表之间匹配的行。 |
| `LEFT` | 左表的所有行，以及右表中匹配的行。 |
| `FULL` | 两个表的所有行。 |
| `CROSS` | 行的每一种组合（不允许有条件）。 |

## 条件

每个非交叉联接都有一个或多个条件，以 **AND** / **OR** 组合，可使用运算符 `=`、`<>`、`<`、`<=`、`>`、`>=`、`BETWEEN`、`IS NULL`、`IS NOT NULL`、`IN`、`NOT IN`、`LIKE`、`NOT LIKE`。

条件可以指定名称中含有空格或标点的列，例如 `Build Plant` 或 `Cust (Id)`；该列必须存在于该输入中。包含双引号、反引号、反斜杠或控制字符的名称会被拒绝。

对于 `BETWEEN`，以输入的别名、一个点和一个列组成的边界（`cust.Max Id`）会被读作该输入的列。任何其他边界都是字面文本，包括没有点的单独别名。因此，以别名加点开头的文本边界（例如输入的别名为 `cust` 时的 `cust.2024`）会被读作列，并被报告为缺失。

## 输出

在**列**选项卡上映射结果列；可按需重命名、设置数据类型和聚合。同名的列会自动加上其源别名前缀，以避免冲突。

每一行的值恰好来自三个字段之一，设置多个或一个也不设置都会被拒绝：

| 种类 | 字段 |
|------|--------|
| 源列 | **源别名**（拥有该列的画布别名）加上**源**（`alias.column`）。两者都必填。 |
| 常量 | **常量**：每一行都相同的固定值。 |
| 表达式 | **表达式**：一个 SQLAlchemy 表达式，可以用 `alias.column` 引用任何画布别名。 |

* **从画布选取…**：从画布上每个源的列中勾选列。
* **添加所有源列**：追加每个源的每一列。
* **添加表达式列**：追加一个表达式行并打开表达式编辑器。

<Aside type="caution" title="每个输出列都需要数据类型">
没有**类型**的输出列会使此步骤停止，并指明该列，以便您设置。其他步骤会回退为该输出所读取的源列的类型，而此步骤则不会，这是有意为之：它按源别名为其列编制键，因此在跨多个表的联接中，猜测的类型对错各占一半，被告知应修复哪一列比悄悄转换更有用。
</Aside>

**Post-Join Filter** 选项卡会在联接结果写入之前对其应用可选的筛选器（相当于 SQL 的 `HAVING`），在同一个表达式编辑器中编辑。它以 `result.column_name` 引用输出列；源别名在此处不在作用范围内。

## 运行时指定名称的列

选择**同时带入运行时指定名称的列**，可将步骤未列出的每个源列按步骤运行时表中的原样原封不动地传递。当前面的步骤创建了名称取决于数据的列（例如透视），因而在构建步骤时无法列出它们，请使用此选项。保持关闭则只写入您列出的列。

## 行为

* 联接图是一棵树：每个表恰好通过一条边接入结果（无环），且表不能与自身联接。
* 配置会在您保存步骤时和步骤运行时进行验证；错误会用 ⚠ 标记出有问题的表或联接，保存失败时会切换到包含第一个问题的选项卡，**跳转到问题**可按需导航到该处。输出列表达式和 Post-Join Filter 会在保存时检查；带有运行时指定名称的列的联接会在保存时跳过表达式检查，并在步骤运行时检查。

<Aside type="caution">`CROSS` 联接会生成其输入的笛卡尔积，在大表上代价可能非常高。</Aside>
