## 说明

将表从项目中彻底移除，包括表定义及其所有数据。此操作具有破坏性且不可逆；工作流一旦运行，该表即永久消失。

当工作流中的中间表在下游不再需要时（例如多步转换之后的清理），请使用此步骤。如果只是临时清空表而不移除它，请改用 [Table Clear](/zh-cn/reference/workflow-steps/tables/table-clear/)。
