## 说明

**表：提升标题行** 步骤取输入中的一行，将其值作为列名称，然后删除该行。适用于真正的标题行不在第一行的文件。该步骤在工作流运行时执行，因此名称来自数据。

## 源和选项

- **源表** 和 **输出表**：要读取的表和要写入的表。
- **标题行**：其值用于命名各列的行，从 1 开始计数。该行会从数据中删除。留空则不提升任何标题行，并对已存储的名称应用格式步骤。
- **记录顺序列** *（可选）*：用于为行排序的列。没有它时，行按存储的顺序读取，因此哪一行命名各列可能会因运行而异。
- **输入为空时的列** *（可选）*：输入没有行时要写入的文本列名称，以逗号分隔。

## 格式化步骤

**格式化步骤** 网格的每一行都会更改提升后的名称。

| 设置 | 选项 |
| --- | --- |
| 操作 | **重命名**、**更改类型**、**隐藏**、**填充空白** |
| 匹配器 | **包含**、**开头为**、**结尾为** 或 **为空** |
| 匹配文本 | 要在列名称中匹配的文本。**为空** 不需要。 |
| 重命名方式 | 用于重命名：**替换文本**、**在前面添加** 或 **在后面添加** |
| 替换为 | 重命名或填充使用的新文本 |
| 值 | **更改类型** 使用的类型 |

每个步骤都需要一个操作和一个匹配器，重命名还需要重命名方法及其文本。
