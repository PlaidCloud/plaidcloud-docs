## 说明

当两个表的行数不同时，使工作流失败。可将其用作数据质量关卡，例如确认转换后的表保留了源表的每一行，或确认对账过程没有丢失或重复记录。行数一致时，工作流继续运行；不一致时，该步骤会停止工作流，并将失败消息写入工作流日志。

## 配置

- **左表** — 要统计的第一个表。
- **右表** — 要统计的第二个表。
- **失败消息** — 行数不同时显示的消息。默认为“行数不匹配”。

如果需要针对任意条件而不是行数不匹配来使工作流失败，请比较[引发工作流错误](/zh-cn/reference/workflow-steps/workflow-control/raise-workflow-error/)。
