## 说明


复制现有的 PlaidCloud Analyze 工作流。



## 要复制的工作流


首先，从 **项目** 下拉菜单中选择包含要复制的工作流的项目。



接着，从 **工作流** 下拉菜单中选择要复制的具体工作流。



然后，在 **新建工作流** 字段中输入新的工作流名称。请记住：名称在项目中必须唯一。
