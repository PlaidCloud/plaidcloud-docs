## 说明

在当前工作流的执行过程中触发另一个工作流。当一个流程在逻辑上依赖另一个流程时，可用它将工作流串联起来，例如“月末结账”工作流依次调用“加载实际数据”工作流、“运行分摊”工作流和“发布仪表板”工作流。

被调用的工作流独立运行，可以位于同一项目，也可以位于其他项目。默认情况下，调用方工作流不会等待而是继续运行；如果调用方的后续步骤依赖被调用工作流先完成，请设置**等待处理完成**选项。



## 要运行的工作流


首先，从**项目**下拉菜单中选择包含要运行的工作流的项目。



接着，从**工作流**下拉菜单中选择要运行的具体工作流。



此外，还有一个选项**等待处理完成后再继续。** 选中此复选框会推迟当前工作流的执行，直到被调用的工作流执行完毕。默认情况下该选项处于禁用状态，这意味着包含此转换的当前工作流会与被调用的工作流并行继续处理。
