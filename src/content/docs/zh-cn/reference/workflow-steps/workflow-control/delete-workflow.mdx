## 说明


删除现有的 PlaidCloud Analyze 工作流。



## 要删除的工作流


首先，从 **项目** 下拉菜单中选择包含要删除的工作流的项目。



接着，从 **工作流** 下拉菜单中选择要删除的具体工作流。


<Aside type="danger">删除前不会弹出确认对话框。请确保选择了正确的工作流！</Aside>
