## 说明

通过您的 [Workday Financials 连接](/zh-cn/guides/connections/workday-financials/)，将 Workday Financials 中的数据导入项目表。与 NetSuite、Acumatica 或 Business Central 不同，PlaidCloud 没有一组固定的预置 Workday Financials 实体，而是由您在 Workday 中构建一个 **报表即服务 (RaaS) 报表**，发布并启用 Web 服务访问，然后把报表的 URL 作为提取源提供给此步骤。

## 配置

| 字段 | 必填 | 备注 |
|---|---|---|
| Workday 连接 | 是 | 用于读取的 Workday Financials 连接。 |
| RaaS 报表 URL | 是 | 您在 Workday 中构建并发布的 RaaS 报表的 Web 服务 URL。 |
| 目标表 | 是 | 写入结果的项目表。每次运行都会被完整覆盖。 |
| 筛选器 | 否 | `company`、`ledger`、`period`、`accounting_date`（范围）、`ledger_account`（范围）、`cost_center`。每一项都作为报表参数传递，只有当您的 RaaS 报表定义了匹配的提示时，筛选器才会生效。 |

<Aside type="caution">
如果设置了报表上没有匹配提示的筛选器，会被拒绝，而不是被悄悄忽略。请先在 Workday 中向 RaaS 报表添加该提示，然后再在此处设置筛选器。
</Aside>

<Aside type="note">
由于返回的字段由报表本身定义，导入结果的形态（列名、粒度、包含的维度）取决于您的 RaaS 报表的输出。设计报表时，请考虑目标表预期的形态。
</Aside>
