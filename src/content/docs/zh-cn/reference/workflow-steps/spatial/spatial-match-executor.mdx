## 说明

**Spatial Match (Intersect / Unmatched)** 步骤将每个目标几何与和它相关的全集几何配对，并可输出每个匹配对的**相交几何**（*IntersectPoly*）或**未匹配**的目标行。它是基于 SQL 的[空间匹配](/zh-cn/reference/workflow-steps/spatial/spatial-match/)步骤的补充，后者涵盖普通匹配对的情形；这个由执行器支持的步骤则涵盖数据库 SQL 无法表达的两种输出。

## 源和选项

- **目标表** / **全集表**——要匹配的几何和用于匹配的候选项。
- **输出表**——结果的写入位置。
- **目标几何 / 全集几何**——两侧各自的 WKT 几何列。
- **关系**——相交、位于其内、包含、接触、交叉、重叠、相等或不相交。*相等*仅匹配拓扑上相等的几何，*不相交*匹配不共享任何点的配对；空几何永远不会匹配*不相交*。
- **多条规则**——一次匹配可同时关联多个目标和全集几何列，每条规则有各自的关系。`joiner` 设置决定配对必须满足每条规则（*and*，默认）还是任一规则（*or*）。Savant 转换会生成多规则匹配。未知的关系或 joiner 会使步骤按名称失败，而不是按相交运行。
- **同时输出相交几何（IntersectPoly）**——将每个匹配对的重叠几何作为列添加。
- **输出**——*匹配对*或*未匹配的目标行*。

## 目标和全集映射

每个输入都有一个映射选项卡，列出其列，用于驱动几何选择器，并将列传递到输出。
