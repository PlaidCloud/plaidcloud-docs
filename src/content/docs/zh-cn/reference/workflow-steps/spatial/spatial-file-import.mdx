## 说明

**空间文件导入**步骤将空间文件（MapInfo `.TAB`、ESRI `.shp`、`.kml`、`.geojson` 或 SRC `.geo`）及其附属文件读入表，每个要素一行，并带有 WKT 几何列。它相当于指向空间文件的 Alteryx *Input Data* 工具，在工作流引擎（GDAL）中运行。

## 导入参数

- **源**——文档存储中的空间文件。其附属文件（例如 `.TAB` 的 `.dat`/`.map`/`.id`/`.dbf`，或 shapefile 的 `.shx`/`.dbf`/`.prj`）会自动从同一位置读取。
- **目标表**——要素写入的表。

## 备注

输出架构取自文件，因此无需列映射。SRC `.geo` 文件的专有几何无法读取；其 `.dbf` 属性会被导入，几何值为空。
