## 说明

**Spatial Info** 步骤度量每个几何，并将度量值作为列追加。它相当于 Alteryx 的 *Spatial Info* 工具，在工作流引擎中运行。

度量值为 **WGS84 大地测量值**，而非平面值。这一点很重要：这些度量值的 SQL 形式是以赤道常数缩放的平面度² 值，而该常数不会随纬度升高而随经度缩小，因此会**高估**面积和长度——在美国所处纬度上大约偏高四分之一。采用大地测量方式计算，可在所有数据仓库上得到与 Alteryx 一致的结果。

## 源和选项

- **源表** / **输出表**——输入几何以及度量后的行的写入位置。
- **几何列**——要度量的 WKT 几何列。
- **度量值**——要追加哪些度量值。每个选择都会添加下表中的相应列。
- **球体半径（km）** *（可选）*——在此半径的球体上进行度量。留空则在 WGS84 椭球体上度量。

## 输出列

| 度量值 | 添加的列 | 类型 |
|---|---|---|
| 面积（英里） | `AreaSqMi` | 数值 |
| 面积（千米） | `AreaSqKm` | 数值 |
| 长度（英里） | `LengthMi` | 数值 |
| 长度（千米） | `LengthKm` | 数值 |
| 质心坐标 | `CentroidX`、`CentroidY` | 数值 |
| 外接矩形坐标 | `BR_Left`、`BR_Top`、`BR_Right`、`BR_Bottom` | 数值 |
| 质心对象 | `Centroid` | WKT 几何 |
| 外接矩形对象 | `BoundingRect` | WKT 几何 |
| 外接矩形多边形 | `BoundingRectPolygon` | WKT 几何 |
| 是否有效 | `IsValid` | 布尔值 |
| 对象类型 | `SpatialObjType` | 文本 |
| 部分数 | `NumParts` | 数值 |
| 点数 | `NumPoints` | 数值 |
| 端点坐标 | `EndPointX`、`EndPointY` | 数值 |
| 端点对象 | `EndPoint` | WKT 几何 |

`IsValid` 报告所提供的几何在任何修复之前是否为有效形状。

外接矩形对象和外接矩形多边形在 WKT 中序列化为相同的五顶点环，因此两列的值相同。

## 备注

对象类型、部分数、点数和端点以尽力而为的列名追加——Alteryx 记录了这些度量值，但没有给出输出列的名称，因此确切的名称将由后续工作对照真实工作流进行验证。唯一未转换的信息类型是 **Peano 键**，这是 Alteryx 专有的空间索引，没有公开规范：它会被跳过，并且转换会输出一条指明它的备注，使这一遗漏在转换后的工作流中清晰可见。
