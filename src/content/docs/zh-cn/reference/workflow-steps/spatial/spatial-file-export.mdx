## 说明

**空间：文件导出**步骤将表写入文档账户中的空间文件，每行一个要素：几何来自 WKT 列，其他列作为要素的属性。可与[空间文件导入](/zh-cn/reference/workflow-steps/spatial/spatial-file-import/)搭配使用。

步骤表单包含一个**源和文件**部分，用于设置源表、其列、输出文件以及文件已存在时的处理方式；还包含一个**几何**部分，用于设置几何列和坐标系。[迁移的 KNIME 工作流](/zh-cn/guides/workflows/migrate-knime-workflows/)使用此步骤作为其地理空间文件写入器。

## 配置

- **源表**（`source`）——要导出的表。**源列**（`source_columns`）列出要写入的列。
- **输出文件**（`output_file`）——文件所在的文档账户和路径。扩展名决定格式：`.shp`（ESRI shapefile）、`.geojson` 或 `.json`（GeoJSON）、`.gpkg`（GeoPackage）、`.kml`、`.gml`，以及 `.tab` 和 `.mif`（MapInfo）。由多个文件组成的格式（如 shapefile）会连同其附属文件一起写在旁边。
- **几何列**（`geometry_column`）——以 WKT 形式存放每个要素几何的列。默认为 `SpatialObj`。
- **坐标系**（`crs`）——几何所在的坐标参考系，如 `EPSG:4326`，会随文件一起写入。
- **已存在的文件**（`if_exists`）——**覆盖它**（`overwrite`，默认）会替换已有的文件；**使步骤失败且不写入任何内容**（`fail`）会在写入任何内容之前停止该步骤。
