## 说明

**Spatial Buffer** 步骤将列中的每个几何按固定距离向外扩展，并将缓冲后的几何写入输出列。它相当于 Alteryx 的 *Buffer* 工具，在工作流引擎中运行（几何运算无法用 SQL 表达）。

## 源和选项

- **源表** / **输出表**——输入几何以及结果的写入位置。
- **几何列**——要缓冲的 WKT 几何列。
- **缓冲距离**——每个几何扩展的距离，以几何自身的坐标单位计。

## 列

**列**选项卡将要传递到输出的输入列进行映射；缓冲后的几何列会自动追加。
