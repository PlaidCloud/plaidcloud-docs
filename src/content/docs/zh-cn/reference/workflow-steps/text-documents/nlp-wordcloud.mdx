## 说明

**Text Word Cloud** 步骤根据文本列渲染词云图像。它相当于对应的 Alteryx 工具，并在工作流引擎中运行（ML / NLP / 文档库在执行器作业中运行）。

## 源和选项

- **源 / 输出表** — 输入数据以及写入结果的位置。
- **文本列**、最大词数、图像大小和背景颜色。

## 列

**列** 选项卡将传递的输入列映射到输出。
