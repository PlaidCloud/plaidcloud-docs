## 说明

**Image OCR** 步骤通过 OCR 从图像中提取文本。它相当于对应的 Alteryx 工具，并在工作流引擎中运行（ML / NLP / 文档库在执行器作业中运行）。

## 源和选项

- **源 / 输出表** — 输入数据以及写入结果的位置。
- **图像路径列**。

## 列

**列** 选项卡将传递的输入列映射到输出。
