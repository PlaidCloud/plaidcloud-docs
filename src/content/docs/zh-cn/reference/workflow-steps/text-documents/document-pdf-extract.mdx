## 说明

**PDF Text Extract** 步骤从 PDF 文档中提取文本。它相当于对应的 Alteryx 工具，并在工作流引擎中运行（ML / NLP / 文档库在执行器作业中运行）。

## 源和选项

- **源 / 输出表** — 输入数据以及写入结果的位置。
- **PDF 路径列**（或 PDF 所在的 **目录**）。

## 列

**列** 选项卡将传递的输入列映射到输出。
