## 说明

**Text Topic Model** 步骤发现文本列中的主题。它相当于对应的 Alteryx 工具，并在工作流引擎中运行（ML / NLP / 文档库在执行器作业中运行）。

## 源和选项

- **源 / 输出表** — 输入数据以及写入结果的位置。
- **文本列**、主题数量和词汇表大小。

## 列

**列** 选项卡将传递的输入列映射到输出。

## KNIME 文本处理节点

在 **KNIME 文本处理节点** 组中，选择一个 **KNIME 文本节点** (`node`)，即可通过此步骤运行 KNIME 的某个文本处理节点，例如 `preprocess`、`tagger`、`bag_of_words`、`frequency`、`document_vector`、`keywords`、`topics`、`language`，或嵌入节点。节点自身的设置（例如 **文档列** (`document_column`) 和 **输出列** (`output_column`)）显示在 `knime_config` 中它的旁边。将节点保留为 **（无）** 则运行步骤自身的设置。已转换的 KNIME 工作流会设置相同的键。

在 **KNIME 节点表** 组中，读取第二个表（例如词典、实体列表或词汇表）的节点，会读取 **第二个输入表** (`source_b`)，其列位于 **第二个表的列** (`source_b_columns`) 中。有其他输出的节点会按顺序将它们写入 **其他输出表** (`targets`) 中列出的表。
