## 说明

将 PDF 的文本内容提取到表中。它相当于 Alteryx 的 *PDF to Text* 工具，并在文档库所在的工作流引擎中运行。

使用它可将 PDF 内容转换为工作流其余部分可以筛选、解析和联接的形式。如需页面级和感知版面的提取，请改用 [PDF Text Extract 步骤](/zh-cn/reference/workflow-steps/text-documents/document-pdf-extract/)。

## 源和选项

- **源表** / **输出表** — 指明 PDF 的表，以及写入提取文本的表。
- **列** — 要传递到输出的源列。
