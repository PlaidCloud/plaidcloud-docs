## 说明

通过您的 [Acumatica 连接](/zh-cn/guides/connections/acumatica/)，将一个 Acumatica 基于合约的 REST 实体导入到项目表中。选择连接、实体类型和任意筛选器；该步骤会拉取匹配的记录并写入，无需编写 OData 查询。

这是一个通用的预置步骤：同一个步骤类型涵盖 18 个实体，从主数据/参考数据（科目、子科目、客户、供应商、库存物料）到交易记录（销售发票、账单、销售订单、发货单）。

## 配置

| 字段 | 必填 | 备注 |
|---|---|---|
| Acumatica 连接 | 是 | 用于读取的 Acumatica 连接。 |
| 目标表 | 是 | 写入结果的项目表。每次运行都会完整覆盖该表。 |
| 实体类型 | 是 | 要拉取的实体。默认为 `account`。可选值为 `account`、`ledger`、`financial_period`、`branch`、`currency`、`currency_rate`、`subaccount`、`customer`、`vendor`、`stock_item`、`warehouse`、`employee`、`tax_category`、`sales_invoice`、`bill`、`sales_order`、`shipment`、`project` 之一。 |
| 仅活动 | 否 | 默认开启。对带有 Active 标志的实体筛选 `Active = true`。 |
| 更新时间晚于 | 否 | ISO 日期或日期时间。仅返回此时间之后发生变化的行。这是请求端筛选器，没有持久化游标：每次运行都需要自行提供截止时间。留空则拉取全部。 |
| 筛选器 | 否 | 由 `{field, operator, value}` 子句（`eq`、`ne`、`gt`、`ge`、`lt`、`le`、`contains`）或 `{field, from, to}` 范围组成的数组。每个实体仅允许对 Acumatica 实际能在服务器端求值的字段使用筛选器：不受支持的字段会被拒绝，而不是被悄悄丢弃。 |

<Aside type="note">
试算平衡表、总账交易明细、库存现有量、预算和公司间数据位于 Acumatica 通用查询（Generic Inquiries）之后，而不在这 18 个基于合约的实体中。请在 Acumatica 中构建通用查询，并改用[通用 REST 连接](/zh-cn/reference/connectors/rest/generic-rest/)拉取。
</Aside>

<Aside type="caution">
筛选仅能作用于实体级和标题级字段：单据的行项目维度（例如账单行上的成本中心）无法在服务器端查询。请先拉取该实体，再在导入后于您的工作流中限定行级明细的范围。
</Aside>
