## 说明

通过您的 [OneStream 连接](/zh-cn/guides/connections/onestream-for-data-foundation/)读取 OneStream 工作区中的数据适配器，并将其行加载到表中。对于您列出的每个合并成员，它会调用一次适配器，并用所有成员的行替换目标表。可用它将合并结果引入项目，例如将模型与之对账。

此步骤在步骤菜单中显示于 **OneStream** 下。当您将 OneStream 添加为数据源时，Data Foundation 会使用它。

<Aside type="note">
适配器及其列由您的 OneStream 管理员构建。请参阅 [OneStream 管理员需要做哪些设置](/zh-cn/guides/connections/onestream-for-data-foundation/#onestream-管理员需要设置的内容)。
</Aside>

## 配置

### 源

| 字段 | 必填 | 备注 |
|---|---|---|
| OneStream Connection | 是 | 用于读取的 [OneStream 连接](/zh-cn/guides/connections/onestream-for-data-foundation/)。 |
| Environment | 否 | **项目环境**（默认）使用项目的连接环境。**固定环境**始终使用您选择的环境。请参阅[将步骤固定到单一环境](/zh-cn/guides/projects/managing-projects/#将步骤固定到某一环境)。 |
| Application | 否 | 留空则使用连接上保存的应用程序。步骤必须二者具备其一。 |
| Workspace | 否 | 留空则使用连接上保存的工作区。 |
| Adapter | 是 | 要读取的数据适配器。`Foundation_Results` 是连接页面中描述的适配器。 |
| Adapter Table | 否 | 适配器数据集中的表名。 |
| Run Sequence First | 否 | 读取之前要运行的 Data Management 序列，用于刷新适配器所读取的内容。 |

### 数据切片

| 字段 | 备注 |
|---|---|
| Members | 每行一个合并成员。步骤对每个成员调用一次适配器，并将该成员放入替代变量 `Member`。留空则对适配器的默认成员调用一次。 |
| Substitution Variables | 每行一个 `Name=Value`，例如 `Time=2026M1`。 |
| View | **Year to date**（默认）或 **Periodic**。通过替代变量 `View` 传递给适配器。 |
| Sign | **As stored**（默认）或 **Flip sign**，后者会对每个金额取反。 |
| Amount Scale | 应用于每个金额的乘数。默认为 1。当 OneStream 以千为单位提供值时使用 1000。 |

应用程序、工作区、表、序列、成员和替代值中的变量会在工作流运行时填入。

### 目标

| 字段 | 必填 | 备注 |
|---|---|---|
| Target table | 是 | 行加载到的表。每次运行都会被替换，且必须是表而不是视图。 |

## 输出

目标表包含适配器的列：`entity`、`account`、`time`、`scenario`、`view`、`amount`、`currency`、`flow`、`ud1`、`ud2`、`ud3` 和 `ud4`。除 `amount` 外，每一列都以文本加载；amount 在应用比例和符号之后为数值。

如果适配器没有返回任何行，目标表会被替换为空表，步骤以指出适配器名称的警告结束，而不是错误。
