通过 [Salesforce 连接](/zh-cn/guides/connections/salesforce/)读取 Salesforce 数据的工作流步骤。对象列表、字段列表和每一列的类型都来自组织自身的元数据，因此无需编写查询，也无需猜测类型。

## 步骤

- [Salesforce：查询对象](/zh-cn/reference/workflow-steps/salesforce/query-salesforce-object/)：通过 Bulk API 2.0 将一个标准或自定义对象提取到项目表中，并在 Salesforce 端筛选。
