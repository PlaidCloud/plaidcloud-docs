## 说明



重命名现有的 SAP 盈利能力与成本管理（PCM）模型。适用于方案轮换期间的日常整理（例如期间结账后将“Forecast Q3”改为“Actuals Q3”）或组织结构调整。

新名称在 PCM 服务器内必须唯一。


## 我们的资质


PlaidCloud 是 SAP 官方合作伙伴，也是 SAP PCM 模型设计与实施相关服务的首选供应商。








## 示例


从下拉列表中选择要使用的代理，在“模型信息”字段中输入“From Model Name”和“To Model Name”，勾选“Wait for Copy to Complete”复选框，然后单击“Save and Run Step”。
