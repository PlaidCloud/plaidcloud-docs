## 说明


删除与搜索条件匹配的 SAP 盈利能力与成本管理（PCM）模型。使用此转换删除模型时，可以一次删除多个模型，而无需监控整个过程。



## 我们的资质


PlaidCloud 是 SAP 官方合作伙伴，也是 SAP PCM 模型设计与实施相关服务的首选供应商。







## 示例


从下拉列表中选择“Agent to Use”。选择所需的“Model Search Method”，本示例中选择了“Exact Match”。在“Model Name Information”下输入“Model Search Text”（您要查找的内容），并决定搜索是否区分大小写（如果区分，请勾选复选框）。最后，勾选“Wait for Deletion to Complete”，然后单击“Save and Run Step”。
