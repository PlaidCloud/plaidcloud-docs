### 说明


在同一个模型内复制 SAP 盈利能力与成本管理（PCM）模型的期间。


### 我们的资质


PlaidCloud 是 SAP 官方合作伙伴，也是 SAP PCM 模型设计与实施相关服务的首选供应商。


### 示例


从下拉列表中选择要使用的代理，在“模型信息”字段中输入“Model Name”、“From Period Name”和“To Period Name”。勾选“Wait for Copy to Complete”复选框，然后单击“Save and Run Step”。
