## 描述

**Create Samples（宏）** 步骤重现 Alteryx *Create Samples* 打包宏。它在工作流引擎中运行；打包宏的结果是对 Alteryx 宏的近似。

## 参数

- **源 / 输出表**。
- **Estimation %** 和**随机种子**。
