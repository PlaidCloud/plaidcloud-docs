## 描述

**DateTime Now（宏）** 步骤重现 Alteryx *DateTime Now* 打包宏。它在工作流引擎中运行；打包宏的结果是对 Alteryx 宏的近似。

## 参数

- **输出表**和**输出格式**字符串。

## 输出格式

格式字符串使用 Alteryx DateTime 工具的标记，转换时会原样保留。留空时使用该工具自身的默认值 `day, dd Month, yyyy`，例如 `Tuesday, 04 August, 2026`。

| 标记 | 呈现内容 |
| --- | --- |
| `yyyy` / `yy` | 四位或两位年份 |
| `Month` / `Mon` | 完整或缩写的月份名称 |
| `MM` / `M` | 月份数字，带或不带前导零 |
| `day` / `dy` | 完整或缩写的星期名称 |
| `dd` / `d` | 月中的日期，带或不带前导零 |
| `HH` / `H` | 24 小时制的小时，带或不带前导零 |
| `hh` / `h` | 12 小时制的小时，带或不带前导零 |
| `mm` | 分钟 |
| `ss` | 秒 |
| `tt` | AM 或 PM |

标记区分大小写：`MM` 表示月份，`mm` 表示分钟。
