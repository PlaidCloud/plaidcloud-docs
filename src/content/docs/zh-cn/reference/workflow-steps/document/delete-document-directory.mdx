## 说明


删除 PlaidCloud 文档中已有的目录。



## 要删除的文件夹


首先，从下拉菜单中选择相应的账户。


然后，点击**浏览**按钮选择要删除的目录。


<Aside>文件夹不存在从来不算错误。步骤不执行任何操作，并在存储报告该文件夹缺失时，以指明路径的警告结束。</Aside>


## 仅删除文件

若要清空文件夹但保留它，请勾选**仅删除其中的文件，保留其文件夹**（`files_only`）。随后，**哪些文件**中的选项会缩小删除范围。

* **仅删除其中的文件，保留其文件夹**（`files_only`）— 删除文件夹中的文件，保留该文件夹及其子文件夹。
* **也包括其子文件夹下的文件**（`include_subdirs`）— 与 `files_only` 一起使用时，同时删除其下每个子文件夹中的文件。
* **文件名模式**（`file_name_filter`）— 仅删除名称匹配的文件。**模式类型**为**通配符**或**正则表达式**（`type`），**区分大小写**设置 `case_sensitive`。
* **文件夹名模式**（`folder_name_filter`）— 仅删除名称匹配的文件夹中的文件，形式相同；沿途向下的每个文件夹都必须匹配。
* **扩展名**（`extensions`）— 仅删除具有这些扩展名之一的文件，不含点号。**扩展名区分大小写**（`extensions_case_sensitive`）会按大小写匹配扩展名。
* **包括隐藏文件（名称以点开头）**（`include_hidden_files`）和**包括隐藏文件夹及其下内容**（`include_hidden_folders`）— 取消勾选任一项，即可排除名称以点开头的文件或文件夹。

未找到任何文件时（包括文件夹缺失的情况），步骤不执行任何操作，并以指明路径的警告结束。
