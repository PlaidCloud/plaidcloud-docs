## 说明


删除 PlaidCloud 文档中已有的文件。



## 要删除的文件


首先，从下拉菜单中选择相应的账户。


然后，点击**浏览**按钮选择要删除的文件。

<Aside>如果文件不存在（已被删除），则不执行任何操作。</Aside>
