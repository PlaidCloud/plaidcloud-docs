## 说明


重命名 PlaidCloud 文档中已有的文件。



## 要重命名的文件


首先，从下拉菜单中选择相应的账户。



然后，点击**浏览**按钮选择要重命名的文件。

<Aside>如果重命名后的文件已存在，则不执行任何操作。</Aside>


## 重命名为


输入文件的新名称。
