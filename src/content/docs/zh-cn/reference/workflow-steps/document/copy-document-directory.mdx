## 说明


在 PlaidCloud 文档中复制整个目录。



## 复制目录


首先，从下拉菜单中选择相应的账户。



然后，单击**浏览**按钮选择要复制的目录。



## 选择目标位置


首先，从下拉菜单中选择相应的账户。



然后，单击**浏览**按钮选择复制后目录的目标位置。 



如有需要，可以为复制后的目录指定新名称。为此，只需勾选 **Rename the Copied Folder to:** 复选框并输入新名称。


<Aside>默认行为是覆盖已存在的任何内容。请小心，不要意外覆盖。</Aside>
