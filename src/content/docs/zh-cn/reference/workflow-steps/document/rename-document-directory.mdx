## 说明


重命名 PlaidCloud 文档中已有的目录。



## 要重命名的文件夹


首先，从下拉菜单中选择相应的账户。



然后，点击**浏览**按钮选择要重命名的目录。



## 重命名为


输入目录的新名称。


<Aside>如果重命名后的目录已存在，则不执行任何操作。</Aside>
