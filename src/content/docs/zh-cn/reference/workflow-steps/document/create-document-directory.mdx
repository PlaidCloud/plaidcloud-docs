## 说明


在 PlaidCloud 文档中创建新目录。



## 新建文件夹的位置


首先，从下拉菜单中选择相应的账户。



然后，单击**浏览**按钮选择父目录。



## 新文件夹名称


输入新目录的名称。


<Aside>如果该目录已存在，则不执行任何操作。</Aside>
