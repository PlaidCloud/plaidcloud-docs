## 说明


在 PlaidCloud 文档中复制单个文件。



## 要复制的文件


首先，从下拉菜单中选择相应的账户。



然后，单击**浏览**按钮选择要复制的文件。

除了单个文件，还可以选择**复制与搜索匹配的文件**（复制名称与搜索文本匹配的文件，匹配方式为**精确**、**开头为**、**包含**或**结尾为**），或选择**复制目录中的所有文件**。复制整个文件夹时：

* **保留子文件夹**会将每个文件放在其相对于该文件夹的路径之下，因此副本保留文件夹的结构。如果不选，每个文件都会按其名称直接放入目标文件夹。
* **跳过子文件夹**只复制该文件夹自身的文件，不复制其子文件夹中的文件。

**仅复制名称匹配的文件(正则表达式)** 会将上述任一选择缩小为名称从开头起匹配某个正则表达式的文件，例如 `sales_\d{4}\.csv`。匹配区分大小写。留空则复制所有所选文件。不是有效正则表达式的模式，或重复了本身又会重复的部分（例如 `(a+)+`）的模式，在保存步骤时会被拒绝。

缺失或为空的源文件或文件夹会使步骤以指明路径的警告结束，不复制任何内容。



## 选择目标位置


首先，从下拉菜单中选择相应的账户。



然后，单击**浏览**按钮选择复制后文件的目标位置。



默认情况下，Analyze 不允许覆盖文件。取而代之的是，每个后续副本都会添加一个数字后缀。 



若要覆盖现有文件，只需勾选 **Allow Overwriting Existing File** 复选框。



若要重命名文件，请勾选 **Rename the copied file to** 复选框并输入新名称。

<Aside>更改文件名称时，请务必提供文件扩展名。没有扩展名时文件也能成功创建，但操作系统无法识别其类型。</Aside>


## 其他设置

在**文件已存在时**下，**已存在的文件**（`overwrite_policy`）设置目标位置已有文件时的处理方式：**覆盖复制**（`overwrite`，默认）、**源较新时覆盖复制**（`overwrite_if_newer`）、**保持原样**（`skip`）或**使步骤失败，不复制任何内容**（`fail`）。

使用**复制目录中的所有文件**时，**哪些文件**中的选项可缩小复制范围：

* **子文件夹下的文件**（`include_subdirs`）：**否**只复制该文件夹自身的文件，**是**复制其下的每个文件并保留它们所在的文件夹。不设置则会按名称将每个文件复制到目标文件夹中，如**保留子文件夹**和**跳过子文件夹**所述。
* **文件名模式**（`file_name_filter`）：仅名称匹配的文件。**模式类型**为**通配符**或**正则表达式**（`type`），**区分大小写**用于设置 `case_sensitive`。
* **文件夹名模式**（`folder_name_filter`）：仅名称匹配的文件夹中的文件，形式相同；沿途向下的每个文件夹都必须匹配。
* **扩展名**（`extensions`）：仅具有这些扩展名之一的文件，不带点。**扩展名区分大小写**（`extensions_case_sensitive`）会按大小写匹配扩展名。
* **包括隐藏文件（名称以点开头）**（`include_hidden_files`）和**包括隐藏文件夹及其下内容**（`include_hidden_folders`）：清除其中任一项，可排除名称以点开头的文件或文件夹。
