## 说明

写入一张表，列出文档目录中的文件。可根据现有文件驱动下游步骤，例如循环处理文件夹中的每个文件，或检查上游流程送达了哪些内容。

## 目录

选择文档账户，然后点击**浏览**按钮选取要列出的文件夹。

## 选项

- **文件模式** *（可选）*— 通配符模式，例如 `*.csv`，仅列出匹配的文件。留空则列出全部。
- **包含子目录** — 勾选后，嵌套文件夹中的文件也会被列出。
- **目标表** — 接收列表的表。

## 其他设置

**哪些文件**中的选项用于缩小列表范围：

- **同时列出文件夹，并带 IsFolder 列**（`include_folders`）— 同时将文件夹列为行。此时每一行都会带有末尾的 `IsFolder` 列，文件夹为 true。
- **首先列出目录本身**（`include_root_folder`）— 与 `include_folders` 一起使用时，同时在最前面列出目录本身。
- **文件名模式**（`file_name_filter`）— 仅列出名称匹配的文件。**模式类型**为**通配符**或**正则表达式**（`type`），**区分大小写**设置 `case_sensitive`。
- **文件夹名模式**（`folder_name_filter`）— 仅列出名称匹配的文件夹中的条目，形式相同；沿途向下的每个文件夹都必须匹配。
- **扩展名**（`extensions`）— 仅列出具有这些扩展名之一的文件，不含点号。**扩展名区分大小写**（`extensions_case_sensitive`）会按大小写匹配扩展名。
- **包括隐藏文件（名称以点开头）**（`include_hidden_files`）和**包括隐藏文件夹及其下内容**（`include_hidden_folders`）— 取消勾选任一项，即可排除名称以点开头的文件或文件夹。
