## 说明

**文档：更新 Excel 单元格**步骤（Document: Update Excel Cells）将值写入文档账户中 `.xlsx` 工作簿的各个单元格，工作簿的其余部分保持不变。输入表的每一行指定一个单元格以及要写入的值。该步骤也可以改为根据格式设置指令表对工作簿应用格式。

步骤表单有三组选项：**工作簿**、**单元格**和**格式设置**。迁移的 KNIME 工作流使用该步骤来替代其 Excel 单元格更新和格式设置节点。

工作簿不存在从来不算错误：步骤不会改动它，并以指明路径的警告结束。

## 设置单元格值

- **源表**（`source`）— 包含单元格地址及其新值的表。**源列**（`source_columns`）列出地址列和值列。
- **地址列**（`address_column`）— 保存各单元格地址的列，例如 `A5`，或以从 1 开始的数字表示的 `column:row`。
- **工作簿**（`file`）— 要更新的工作簿，格式为 `{account, path}`。
- **工作表**（`sheet_name`）— 要更新的工作表。如果工作簿中没有该名称的工作表，则会添加一个。
- **为缺失值写入的内容**（`replace_missing`）— 写入所在行没有值的单元格。留空则保持该单元格为空白。

## 设置工作簿格式

将**格式设置指令表**（`source_b`）设置为格式设置指令表，每条指令占一行。**指令列**（`source_b_columns`）指定其类型、标签和参数列。类型为 `font`、`background`、`cell`、`border`、`merge`、`conditional`、`size`、`comment`、`hyperlink`、`sheet_properties` 或 `sheet`，参数以 JSON 形式保存指令的设置。此时**源表**是覆盖在工作表上的控制表：其每个单元格保存适用于该单元格的指令的标签，以逗号分隔。**地址列**和**工作表**不使用。

## 写入副本

- **将更新后的工作簿写入**（`output_file`）— 将更新后的工作簿写入此 `{account, path}`，而不是覆盖原文件。
- **已存在的文件**（`if_exists`）— 与**将更新后的工作簿写入**一起使用时，**覆盖它**（`overwrite`，默认）会替换已存在的文件，**使步骤失败**（`fail`）则会停止步骤。
