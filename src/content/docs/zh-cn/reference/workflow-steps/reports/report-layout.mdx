## 说明

用于排布其子报表部分的**布局**。它等同于对应的 Alteryx *Reporting* / *Portfolio Composer* 工具，在工作流引擎（reportlab / matplotlib）中运行；渲染器的输出是对 Alteryx 输出的近似。

## 源和选项

- **源表**：为此报表部分提供数据的表。
- **输出表**：渲染后的片段写入的表。
- **报表顺序**：此部分在组合报表中的顺序。
- **排列**：垂直（堆叠）或水平（并排）。

如需排布两个输入的各个部分，请将**第二个源表**（`source_b`）设置为第二个输入表。

## 列

**列**选项卡用于映射报表部分可用的源列。
