## 说明

将组合后的报表各部分**渲染**为 PDF 文档。它等同于对应的 Alteryx *Reporting* / *Portfolio Composer* 工具，在工作流引擎（reportlab / matplotlib）中运行；渲染器的输出是对 Alteryx 输出的近似。

## 源和选项

- **源表**：为此报表部分提供数据的表。
- **输出表**：渲染后的片段写入的表。
- **报表顺序**：此部分在组合报表中的顺序。
- **Width / Height**：嵌入图像的大小，单位为像素。
- **输出文件**：渲染文件在文档存储中的路径。

- **输出格式**（`output_format`）：**PDF**（`pdf`，默认），或 **HTML 页面（独立）**（`html`），将报表写为一个独立的 HTML 页面。文件名请使用 `.html` 扩展名。
- **第二个源表**（`source_b`）：第二个输入表，使渲染同时组合两个输入的各个部分。

## 列

**列**选项卡用于映射报表部分可用的源列。
