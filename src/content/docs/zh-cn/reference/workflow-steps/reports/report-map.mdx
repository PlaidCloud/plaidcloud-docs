## 说明

根据源几何数据为组合报表渲染的**地图**。它等同于对应的 Alteryx *Reporting* / *Portfolio Composer* 工具，在工作流引擎（reportlab / matplotlib）中运行；渲染器的输出是对 Alteryx 输出的近似。

## 源和选项

- **源表**：为此报表部分提供数据的表。
- **输出表**：渲染后的片段写入的表。
- **报表顺序**：此部分在组合报表中的顺序。
- **Width / Height**：渲染后地图的大小，单位为像素。

## 主题图例

当图层按某个值着色时，地图会绘制一个图例，列出每个分段的名称。

转换后的 Alteryx Report Map 会沿用原始地图使用的分段名称，典型的主题地图为 *High*、*Above Average*、*Average*、*Below Average*、*Low*，图例会输出这些名称。未命名分段的地图则改用每个分段所覆盖的值范围作为标签。

由于只绘制一个图例，这些名称必须属于同一个图层的分段。出现以下情况时，步骤会停止并给出提示，而不是输出一个看似正确但名称对应了错误分段的图例：

- 着色的值没有覆盖地图所命名的每个分段，因此名称无法与实际绘制的分段匹配；
- 只有部分分段有名称；
- 分段属于多个图层，或有多个图层被着色。

按单个值着色时，每个分段仍以其自身的值命名，因为分段本来就是这个值。

## 列

**列**选项卡用于映射报表部分可用的源列。
