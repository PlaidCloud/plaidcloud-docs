## 说明

组合报表的**文本**块。它等同于对应的 Alteryx *Reporting* / *Portfolio Composer* 工具，在工作流引擎（reportlab / matplotlib）中运行；渲染器的输出是对 Alteryx 输出的近似。

## 源和选项

- **源表**：为此报表部分提供数据的表。
- **输出表**：渲染后的片段写入的表。
- **报表顺序**：此部分在组合报表中的顺序。
- **文本内容**：要渲染的文本。

## 在文本中引用列

文本内容可以用方括号写出列名，该列的值会打印在相应位置，例如 `[Year] Results` 会打印为 `2026 Results`。转换后的 Alteryx Report Text 会保留其文本中已有的任何字段引用，包括 Alteryx 写成 `[Year:A]` 的带格式形式。

整个源表只会组合出一段文本，因此您所引用的列在其读取的每一行上必须具有相同的值。如果该列包含多个值，请先在上游对其汇总，文本块无法同时打印多个值。

`[CurrentYear]` 会打印报表渲染时的年份，无需任何列。

以下规则可确保正常书写的文字不受影响：

- 与某个列匹配的名称一定会被替换。
- 与任何列都不匹配的名称会使步骤停止并给出提示，但仅限于它只可能是引用的情形，即格式紧贴冒号书写，如 `[Quarter:A]`。
- 方括号中的文字会按您所写原样打印。`[12:30]` 仍是时间，`[Note: continued]` 仍是旁注，因为单纯的数字不是列名，而冒号后带空格正是普通文字的写法。

格式本身不会被应用，值会按列中保存的样子打印，因此如果需要千位分隔符或日期格式，请先在上游为该列设置格式。

## 列

**列**选项卡用于映射报表部分可用的源列。
