## 说明


将 Analyze 数据表作为 Microsoft Excel 文件导出到 PlaidCloud Document。PlaidCloud Analyze 支持新版 Microsoft Excel（2007-2016）以及旧版（2000/2003）。



## 导出参数

<SnippetCommonExportFileSelection />



### 目标工作表名称
指定目标工作表名称，默认为 ***Sheet1***。


### 拆分

**拆分**按某一列的值将一张表分到多个输出中：

* **不拆分**（默认）——生成一个工作簿，表数据位于**目标工作表名称**指定的工作表中。
* **单独的文件**——为该列的每个非重复值生成一个工作簿，其中包含该值对应的行。
* **单独的工作表**——生成一个工作簿，为每个非重复值创建一个以该值命名的工作表。不使用**目标工作表名称**。

将**按列拆分**设置为要据以划分的列；该列必须是导出时写入的列。**文件命名依据**设置“单独的文件”如何为每个工作簿命名：**文件名后缀**或**文件名前缀**将该值添加到文件名中，**文件名**则将该值用作完整的文件名。选择**在输出中保留拆分列**，可在每个输出中同时写入拆分列。

值为空白的行不会写入，步骤完成时会给出警告。如果两个值生成相同的工作表名称，“单独的工作表”会停止并指出这些值。

### 选择文件压缩

所有导出的文件均未压缩，但提供以下压缩选项：

* 不压缩
* Zip
* GZip
* BZip2

### 将标题写入第一行
选中此复选框后，表标题会导出到第一行。未选中时，导出的文件中没有标题。

### 文件已存在时

在**更多 Excel 选项**中，**已存在的文件**（`if_exists`）决定工作簿已存在时的处理方式：`replace`（默认）写入新工作簿，`append` 从 A 列开始将行写入工作表最后一个已使用行的下方，`fail` 使步骤停止且不写入任何内容。追加时会先下载工作簿，添加行后再重新上传，因此当两次运行同时向同一文件追加时，最后完成的一次生效。选择**在已有行下方再次写入标题**（`header_on_append`），可在已有行下方再次写入标题行。

### 其他设置

**更多 Excel 选项**还包含以下字段：

* **行排序依据**（`sort_columns`）——按这些源列对写入的行排序，第一个键优先，每个键都有**列**、**升序**和**空值**设置。键列不必写入。**空值**默认为升序时在前、降序时在后。不能与**汇总**或**非重复**一起使用。
* **缺失单元格写为**（`null_as`）——写入每个缺失单元格的文本，数值列也包括在内。
* **已存在的工作表**（`if_sheet_exists`）——选中**写入现有工作簿，保留其格式**（`preserve_format`）且工作簿中已有该工作表时：**使步骤失败**（`fail`）使步骤停止，**保持原样**（`skip`）则保持该工作表不变。默认情况下，**将数据写入其中**会把数据写入该工作表。

## 大小限制

一个 Excel 工作表最多容纳 1,048,576 行（标题行计入其中）和 16,384 列。如果步骤产生的数据超出此范围，会立即停止并告知您，而不是先花费时间生成导出结果，最后得到 Excel 拒绝打开的文件。

即使行数和列数在范围之内，非常大的导出也可能超出文件格式本身允许的上限。出现这种情况时，步骤会报告工作表数据过大。

对于超出这些大小的数据，请改为导出为 CSV 或 Parquet——二者都没有行数限制，生成速度也快得多，占用的存储空间更小。
