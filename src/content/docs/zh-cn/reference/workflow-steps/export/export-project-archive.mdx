## 说明

将项目的完整归档 — 工作流、表定义、维度、变量和设置 — 作为单个文件写入文档账户。可用于在重大更改之前做时间点备份，或将项目交接给另一个工作区。

这归档的是*项目*，而不仅仅是其数据。若只需归档表数据，请使用 [Export to Table Archive 步骤](/zh-cn/reference/workflow-steps/export/export-to-table-archive/)。

## 独有的配置项

### 导出目录和文件名

- **导出目录** — 归档写入的文档账户和文件夹。
- **目标文件** — 归档的文件名。
