## 说明



将 PlaidCloud 表推送到 Quandl（NASDAQ Data Link）数据库。主要面向在 Quandl 上维护已发布数据集，并希望通过 PlaidCloud 工作流刷新这些数据集的组织。

需要 Quandl API 凭据，以及在 Quandl 一侧已配置为可写入的目标数据库。


## 源和目标


请指定以下参数：


* **源表**：要导出的 Analyze 数据表
* **Quandl Connection**：访问 Quandl 数据集需要用户账户，或访问受限的访客账户。这需要在“工具”中设置。有关设置 Quandl 账户连接的详细信息，请参见此处：[PlaidCloud 工具 – 连接](/zh-cn/reference/connectors/)
* **Quandl Code**：使用**搜索**按钮搜索数据集。也可以手动输入数据集，这要求用户输入“[http://www.quandl.com](http://www.quandl.com/)”之后的 URL 部分。例如，要导入微软股票的数据集（可在此处找到：http://www.quandl.com/GOOG/NASDAQ_MSFT），请在 Quandl Code 字段中输入 *GOOG/NASDAQ_MSFT*
* **Dataset Name**：要导出到 Quandl 的数据集名称
* **Dataset Description**：要导出到 Quandl 的数据集描述
