## 说明



将 PlaidCloud 项目表作为 CSV（逗号分隔值）文件写入文档账户。这是最常见的导出格式 — 几乎所有下游系统、电子表格工具和 BI 平台都支持。

可配置项：分隔符（逗号、制表符、竖线、自定义）、引用行为、标题行和编码。

#### 分隔符
导出 CSV 转换用于将数据表导出为保存在 PlaidCloud 文档中的分隔文本文件。这包括但不限于以下分隔符类型：


* Excel CSV（逗号分隔）
* Excel TSV（制表符分隔）
* 用户定义分隔符 –>


	+ 逗号 (,)
	+ 竖线 (|)
	+ 分号 (;)
	+ 制表符
	+ 空格 ( )
	+ 其他/自定义（波浪号、短横线等）

要指定自定义分隔符，请选择 **User Defined Separator –>**，然后选择 **Other –>**，并在文本框中输入自定义分隔符。


#### 特殊字符

**特殊字符**部分允许用户指定如何处理包含引号和转义字符的数据。可从以下设置中选择：

* 特殊字符 (QUOTE_MINIMAL)：为包含特殊字符的字段加引号（即任何会使以相同方言和选项配置的解析器产生混淆的内容）。这是默认设置。
* 全部 (QUOTE_ALL)：无论类型如何，所有内容都加引号。
* 非数字 (QUOTE_NONNUMERIC)：为所有不是整数或浮点数的字段加引号。与读取器一起使用时，未加引号的输入字段会被转换为浮点数。
* 无 (QUOTE_NONE)：输出时不加任何引号。引号字符会连同用户提供的转义字符一起包含在输出中。请注意，只能提供一个转义字符。

默认情况下，带引号字段内的引号会写成两个（`""`）。开启 `escape_quotes` 后，会改为使用转义字符写入，与 Spark 相同：以 `\` 作为转义字符时，字段 `say "hi"` 会写成 `"say \"hi\""`。该设置默认关闭，因此现有的导出不受影响。

默认情况下，包含引号字符的值仅因此就会被加引号。清除**为包含引号字符的值加引号**可在不加外围引号的情况下写入此类值，与 Spark 关闭 `escapeQuotes` 时相同；包含分隔符或换行符的值仍会被加引号。该复选框默认选中。清除后，文件由 PlaidCloud 而不是仓库写入。

将**引号字符**留空可原样写入每个值：不加引号，也不转义。此时包含分隔符或换行符的值读回时会变成更多字段，因此请选择数据中不包含的分隔符。

#### Write Header to First Row
如果选中此复选框，表标题将导出到第一行。否则导出的文件中不会有标题。

#### Include Data Types in Headers
如果选中此复选框，导出文件的标题将包含该列的数据类型。

#### Windows 行尾

最后，**Use Windows Compatible Line Endings** 复选框默认选中，以确保与 Windows 系统兼容。除非在仅使用 unix 的环境中工作，否则建议保持此设置开启。




### 文件已存在时

在**更多 CSV 选项**中，**已存在的文件**（`if_exists`）决定文件已存在时的处理方式：`replace`（默认）写入新文件，`append` 将行添加到现有文件末尾且不带标题行，`fail` 则停止步骤且不写入任何内容。追加会下载该文件、添加行后再上传，因此当两次运行同时向同一个文件追加时，最后完成的那次生效。使用 `append` 时，选中**在已有行下方再次写入标题**（`header_on_append`），即可在已有行下方再次写入标题行。

### 其他设置

**更多 CSV 选项**还包含以下字段：

* **行排序依据**（`sort_columns`）— 按这些源列对写入的行排序，第一个键优先，每个键都有**列**、**升序**和**空值**设置。键列不必写出。**空值**默认为升序时在前、降序时在后。不与**汇总**或**非重复**一起使用。
* **行尾**（`line_ending`）— 每一行的行尾，`\n`、`\r\n` 或 `\r`，用于替代 **Use Windows Compatible Line Endings**。
* **加引号**（`quote_mode`）— 哪些值要加引号：**从不**、**始终**、**除数字和布尔值外的所有值**或**包含分隔符的值**。默认情况下，值在需要时才加引号。
* **结束引号**（`quote_end`）— 结束引号，当它与起始引号不同时使用。
* **值内的结束引号**（`quote_replacement`）— 写在带引号的值内的结束引号位置。留空则将引号写成两个。
* **值内的分隔符**（`delimiter_replacement`）— **加引号**设置为**从不**时，写在值内的分隔符位置。
* **在文件开头写入字节顺序标记**（`write_bom`）— 以字节顺序标记开始文件。
* **小数分隔符**（`decimal_separator`）— 为数字的小数点写入的字符。
* **标题前的行**（`comment_lines`）— 在标题之前原样写入的行的 JSON 数组。
* **Write decimal numbers as Java does**（`scientific_numbers`）— 对 1000 万及以上和 0.001 以下的小数以科学计数法写入，例如 `1.0E10`。
* **按给定名称写入每个文件名，不添加 .csv 或 .tsv**（`keep_file_extension`）— 完全按给定名称写入每个文件名。
* **使用 gzip 时，按给定名称存储文件，不添加 .gz**（`exact_file_name`）— 使用 gzip 压缩时，按给定名称存储文件。
