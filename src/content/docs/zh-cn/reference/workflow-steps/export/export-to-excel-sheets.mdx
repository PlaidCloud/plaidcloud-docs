## 说明

将多个项目表写入同一个 Microsoft Excel 工作簿的不同工作表，并保留带样式模板的格式。每张表填充一个命名工作表；整个工作簿从模板一次性生成，并在一次操作中渲染，因此这些工作表不会像共用同一输出文件的多次单工作表导出那样互相覆盖。

当一个工作簿需要承载多个结果工作表时，请使用此步骤 — 例如带有数据工作表、汇总工作表和参数工作表的格式化报表模板。若只需单个工作表，或使用不带样式的普通工作簿，请改用 [Export to Excel 步骤](/zh-cn/reference/workflow-steps/export/export-to-excel/)。

模板的格式会延续到每个写入的工作表：值、数字格式、字体、填充、边框、合并单元格和列宽。包含数据透视表或图表的模板，在写入其工作表时会丢弃这些对象 — 写入操作不会重现它们。

## 导出参数

### 输出文件

工作簿写入的文档账户和文件夹，以及工作簿的**文件名**。

### 模板文件

工作簿所基于的带样式模板 — 指向现有 `.xlsx` 文件的文档账户和路径，每个写入的工作表都会继承其格式。未指定模板时，如果输出文件已存在，步骤会以该文件为基础。

### 压缩

工作簿默认不压缩写入。可使用 Zip、GZip 或 BZip2 压缩。

## 工作表

**工作表**表中的每个条目填充工作簿中的一个工作表：

| 字段 | 用途 |
| --- | --- |
| 源 | 为该工作表提供行的项目表。 |
| 目标工作表 | 模板中要填充的工作表。 |
| 范围 | 可选的 A1 样式范围（例如 `A1:S1000000`），在写入表之前会清除其中已有的值，周围的模板单元格保持不变。 |
| 写入标题 | 是否写入列名标题行。默认开启。 |
| 列 | 当您不想写入源表的每一列时，按顺序指定要写入的列。 |

表单上还有这些字段：

* **已存在的工作簿**（`if_exists`）— 工作簿已存在时，**使步骤失败且不写入任何内容**（`fail`）会停止步骤。默认值**将工作表写入其中**（`replace`）则会写入它。
* 在工作表条目上，**行排序依据**（`sort_columns`）按这些源列对写入的行排序，第一个键优先，每个键都有**列**、**升序**和**空值**设置；**缺失单元格写为**（`null_as`）是写入该工作表每个缺失单元格的文本，包括数值列；**已存在的工作表**（`if_sheet_exists`）决定工作簿已有该工作表时的处理方式：**使步骤失败**（`fail`）会停止步骤，**保持原样**（`skip`）则保持该工作表不变。

## 大小限制

每个工作表受与单工作表导出相同的 Excel 限制约束：最多 1,048,576 行（标题行计算在内）和 16,384 列。会超出限制的工作表会使步骤停止，而不是生成 Excel 拒绝打开的文件。对于超出这些大小的数据，请改为导出为 CSV 或 Parquet。
