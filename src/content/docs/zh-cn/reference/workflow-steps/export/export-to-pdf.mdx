## 说明

**Export to PDF** 步骤将一个表写为文档账户中的 PDF 文档。它自行读取行，因此中间不会运行导出工作进程。

## 参数

- **源表**——要导出的表。
- **输出文件夹**——写入 PDF 的文档账户和文件夹。
- **文件名**——PDF 的名称。名称缺少 `.pdf` 时会自动添加。
- **将列名写为标题行**——默认开启。标题会在每一页重复。
- **表数据选择**——选择并排列要写入的列。步骤也可以在工作流运行时写入源中的所有列，而不使用列清单。

## 版式

- 页面为纵向 Letter 尺寸，表的列数超过六列时改为横向。
- 行以每 1,000 行为一块写入，每块都重复标题。
- 空值写为空单元格。
- 一页放不下的单元格会被截断并加省略号，步骤会发出警告，列出被截断的列名。
- 工作流引擎有 Unicode 字体时，PDF 使用该字体。没有时 PDF 使用 Helvetica 排版，它只能显示 Latin-1 字符，步骤会发出警告。
