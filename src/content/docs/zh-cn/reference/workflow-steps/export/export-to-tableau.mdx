## 说明

**Publish to Tableau** 步骤将 `.hyper` 提取作为数据源发布到 Tableau Server 或 Tableau Cloud。先用 [Tableau Hyper Export](/zh-cn/reference/workflow-steps/export/export-hyper/) 写出提取文件，再用此步骤发布。步骤使用 [Tableau 连接](/zh-cn/reference/connectors/collaboration/tableau/)上的个人访问令牌登录，分块上传文件，因此文件大小不受单个请求限制，完成后退出登录。

提取文件缺失不是错误。步骤会警告未发布任何内容，工作流继续运行。

## 参数

- **Hyper 提取**——要发布的文档账户中的 `.hyper` 文件。
- **Tableau 连接**——用于发布的 Tableau 连接。
- **数据源名称**——数据源在 Tableau 中的名称。留空则使用提取文件去掉扩展名后的文件名。
- **项目**——要发布到的 Tableau 项目。留空则使用站点的 Default 项目。站点上不存在的项目名称会使步骤失败。
- **如果数据源已存在**——发布模式。参见[模式](#模式)。
- **匹配键**——用于匹配行的列，以逗号分隔的列表表示。**Upsert**、**Update** 和 **Replace Matching Rows** 必须设置。

## 模式

| 模式 | 数据源已存在时 | 数据源不存在时 |
| --- | --- | --- |
| **CreateNew** | 步骤失败。 | 创建数据源。 |
| **Overwrite** | 替换数据源。 | 创建数据源。 |
| **Append** | 将提取中的行添加到数据源。 | 创建数据源。 |
| **Upsert** | 更新匹配键相符的行，并添加其余的行。 | 创建数据源。 |
| **Update** | 更新匹配键相符的行，不添加任何行。 | 发出警告，不做任何更改。 |
| **GroupReplace** | 删除匹配键相符的行，然后插入提取中的行。 | 创建数据源。 |

**Append**、**Upsert**、**Update** 和 **GroupReplace** 会在您选择的项目中按名称查找数据源，未选择项目时在站点的 Default 项目中查找，并发布到查找所在的项目。带键的模式通过 Tableau 的数据更新操作就地更改数据源的行。

## 要求

- 连接的服务器地址必须使用 `https`。使用 `http` 指定的服务器会使步骤失败，因为个人访问令牌会以明文形式在网络上传输。只写主机名时按 `https` 处理。
- 服务器必须可从互联网访问。PlaidCloud 不会发布到专用网络上的 Tableau 服务器。
- 个人访问令牌的所有者需要具有向该项目发布的权限。
