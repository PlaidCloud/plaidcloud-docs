## 说明


将 Analyze 数据表作为 JSON 文件导出到 PlaidCloud Document。数据方向有多个选项（见下文）。



有关 JSON 文件的更多详细信息，请访问 JSON 官方网站：http://json.org/。


<Aside>JSON 文件*不*保留列顺序。源数据表中的列顺序不一定与导出文件中的列顺序一致。</Aside>

### JSON 方向


请看以下数据集：




| ID |  Name  | Gender | State |
|----|--------|--------|-------|
| 1  | Jack   |   M    |   MO  |
| 2  | Jill   |   F    |   MO  |
| 3  | George |   M    |   VA  |
| 4  | Abe    |   M    |   KY  |

JSON 文件可以导出为以下四种数据格式之一：


* Records：数据存储在 Python 字典集中，每一行以 \{Column -> Value, …} 格式存储。例如：**[\{“ID”:1,”Name”:”Jack”,”Gender”:”M”,”State”:”MO”},\{“ID”:2,”Name”:”Jill”,”Gender”:”F”,”State”:”MO”},\{“ID”:3,”Name”:”George”,”Gender”:”M”,”State”:”VA”},\{“ID”:4,”Name”:”Abe”,”Gender”:”M”,”State”:”KY”}]**
* Index：数据存储在嵌套的 Python 字典集中，每一行以 \{Index -> \{Column -> Value, …},…} 格式存储。例如：**\{“0”:\{“ID”:1,”Name”:”Jack”,”Gender”:”M”,”State”:”MO”},”1”:\{“ID”:2,”Name”:”Jill”,”Gender”:”F”,”State”:”MO”},”2”:\{“ID”:3,”Name”:”George”,”Gender”:”M”,”State”:”VA”},”3”:\{“ID”:4,”Name”:”Abe”,”Gender”:”M”,”State”:”KY”}}**
* Split：数据存储在单个 Python 字典集中，值存储在列表中。例如：**\{“columns”:[“ID”,”Name”,”Gender”,”State”],”index”:[0,1,2,3],”data”:[[1,”Jack”,”M”,”MO”],[2,”Jill”,”F”,”MO”],[3,”George”,”M”,”VA”],[4,”Abe”,”M”,”KY”]]}**
* Values：数据存储在多个 Python 列表中。例如：**[[1,”Jack”,”M”,”MO”],[2,”Jill”,”F”,”MO”],[3,”George”,”M”,”VA”],[4,”Abe”,”M”,”KY”]]**


### 日期处理


使用下拉菜单指定**日期格式**。可从以下格式中选择：


* **Epoch (Unix Timestamp – Seconds since 1/1/1970)**
* **ISO 8601 Format (YYYY-MM-DD HH:MM:SS with timeproject offset)**

使用下拉菜单指定**日期单位**。可从以下格式中选择，按精度由低到高排列：


* **秒 (s)**
* **毫秒 (ms)**
* **微秒 (us)**
* **纳秒 (ns)**

### 强制 ASCII


选中此复选框可确保所有字符串都以正确的 ASCII 格式编码。默认启用。



### 输出文件类型


所有导出的文件均未压缩，但提供以下压缩选项：


* Zip
* GZip
* BZip2


### 其他设置

* **已存在的文件**（`if_exists`），位于**文件已存在时**下——**覆盖它**（`overwrite`，默认）会替换已存在的文件；**使步骤失败且不写入任何内容**（`fail`）会在要写入的文件已存在时使步骤停止，且不写入任何内容。
* **行排序依据**（`sort_columns`），位于**行顺序**下——按这些源列对写入的行排序，第一个键优先，每个键都有**列**、**升序**和**空值**设置。键列不必写入。**空值**默认为升序时在前、降序时在后。不能与**汇总**或**非重复**一起使用。
