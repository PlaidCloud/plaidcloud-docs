## 描述

通过 [NetSuite 连接](/zh-cn/guides/connections/netsuite/)将 NetSuite 主数据列表导入项目表。选择一种记录类型（科目、子公司、部门、类别、位置、供应商或客户），步骤会拉取该列表并写入，无需编写或维护 SuiteQL。

主数据是余额和明细拉取所引用的参考数据：总账行以内部 ID 形式携带的科目、子公司和维度。导入所需的列表，即可将这些内部 ID 解析为名称，或用于下游的查找和联接。这是预置的 [NetSuite 导入步骤](/zh-cn/reference/workflow-steps/netsuite/)之一，这些步骤运行在共享的读取层之上，该层会为您刷新 OAuth 令牌、对大型结果分页并重试暂时性错误。

## 配置

| 字段 | 是否必填 | 说明 |
|---|---|---|
| NetSuite 连接 | 是 | 用于读取的 NetSuite 连接，仅显示 NetSuite 类型的连接。 |
| 目标表 | 是 | 写入列表的项目表。每次运行都会完全覆盖该表。 |
| 记录类型 | 是 | 要拉取的主列表：**科目**（默认）、**子公司**、**部门**、**类别**、**位置**、**供应商**或**客户**。 |
| 包含非活动记录 | 否 | 默认关闭，仅返回活动记录。开启后将包含在 NetSuite 中标记为非活动的记录。 |

<Aside type="note">
使用此步骤构建其他 NetSuite 步骤所依赖的小型参考表。例如，先拉取一次**子公司**，将子公司内部 ID 映射为名称，然后再将[导入余额](/zh-cn/reference/workflow-steps/netsuite/import-balances/)或[导入总账明细](/zh-cn/reference/workflow-steps/netsuite/import-gl-detail/)的拉取限制为一家子公司。
</Aside>
