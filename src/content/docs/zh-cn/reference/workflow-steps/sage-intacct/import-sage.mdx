## 说明

通过 Sage 连接导入 Sage Intacct **按维度划分的科目余额**（Intacct 的 `get_accountbalancesbydimensions`），受日期范围和科目范围限定，所选维度会带到每一行。结果是一张试算平衡表：每个科目的每个维度组合一行，包含期初（`startbalance`）、本期（`periodbalance`）和期末（`endbalance`）余额。

可用于试算平衡表或基于余额的损益表。下面的**统计**控件还可以访问 Intacct 的非货币统计科目（人数、面积、数量），因此单个步骤即可拉取财务余额、统计余额或两者，让您无需单独导出即可构建单位指标。如需交易级总账明细，请对 `GLDETAIL` 使用 [Import Sage Intacct Query 步骤](/zh-cn/reference/workflow-steps/sage-intacct/import-intacct-query/)；如需针对任何 Intacct 对象的临时查询，也使用同一步骤并填入对象名称。

## 特有配置项

### 源和目标

- **连接**：要读取的 Sage 连接。
- **公司**：要读取的 Sage 公司。

### 数据选择

- **开始日期** / **结束日期**：报告余额的期间（两者都必填，单独的开始或结束日期会被忽略）。
- **Start account** / **End account**：要包含的科目代码范围。使用 `0000` 和 `9999` 可涵盖所有科目，与编号无关。当下面的**统计**设置为拉取统计科目时，通常采用此选择，因为 Intacct 的统计科目不一定落在您财务科目表的编号范围内。
- **统计**：拉取返回哪一类科目余额：
  - **仅财务（不含统计）**：只返回财务科目余额（常规的试算平衡表拉取）。这是默认值。
  - **财务和统计**：在同一结果中同时返回财务和统计科目余额。
  - **仅统计**：只返回统计科目余额，即人数、面积、数量，以及 Intacct 科目表中与财务科目表并行跟踪的任何其他非货币科目。
- **实体**：要包含的 Sage 实体。
- **维度**：开启您需要作为列的维度：类别、联系人、成本类型、客户、部门、员工、物料、位置、项目组、任务和供应商。
- **Custom dimensions**：要带入的任何其他用户定义维度。

:::caution[Warehouse 复选框不起作用]
步骤配置提供了 **Warehouse** 维度，但工作流运行器并不读取它，该维度不在其构建的集合中，因此开启它不会增加任何列。如果输出中需要 warehouse，请使用 **Custom dimensions**。
:::
