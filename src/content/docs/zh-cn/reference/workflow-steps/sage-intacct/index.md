通过 [Sage Intacct 连接](/zh-cn/guides/connections/sage-intacct/)读取和写入 Sage Intacct 的工作流步骤。可导入科目余额、应付账款账单，或针对任何 Intacct 对象的临时查询结果，也可将日记账分录过账回去，并将支持文档附加到 Intacct 记录。

## 步骤

- [导入 Sage](/zh-cn/reference/workflow-steps/sage-intacct/import-sage/)
- [Import Sage Intacct Query 步骤](/zh-cn/reference/workflow-steps/sage-intacct/import-intacct-query/)
- [Import Sage AP 步骤](/zh-cn/reference/workflow-steps/sage-intacct/import-sage-ap/)
- [Import Sage AP Lines 步骤](/zh-cn/reference/workflow-steps/sage-intacct/import-sage-ap-lines/)
- [Import Intacct Entity 步骤](/zh-cn/reference/workflow-steps/sage-intacct/import-intacct-entity/)：总账明细、余额、分录和维度主数据，支持自动分页。
- [Intacct：过账日记账分录](/zh-cn/reference/workflow-steps/sage-intacct/export-to-sage/)
- [Sage Intacct：附加文档](/zh-cn/reference/workflow-steps/sage-intacct/attach-document/)：将表中的支持文档附加到 Intacct 记录。
