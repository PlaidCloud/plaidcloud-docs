## 说明

通过 Sage Intacct REST API 从 Sage Intacct 导入应付账款账单标题。每一行是一张应付账单，包含后续报表所需的供应商、总账日期、到期日、合计和状态字段。

请使用已配置的 [Sage Intacct REST 连接器](../../../connectors/rest/sage-intacct/)作为源。如需同时拉取行级明细，请将此步骤与 [Import Sage AP Lines 步骤](../import-sage-ap-lines/)搭配使用。

## 特有配置项

* **Sage 连接**：要读取的 Sage Intacct REST 连接。Sage 连接在 **Tools > Connections** 中管理。
* **公司 ID**：要查询的 Intacct 公司。如果您的发送方凭据涵盖多家公司，则为必填项。
* **实体 ID（以逗号分隔）**：将导入限制在一个或多个 Intacct 实体。留空则拉取该用户有权访问的所有实体。
