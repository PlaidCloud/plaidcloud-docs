## 说明

针对任何 Sage Intacct 对象类型运行临时查询并导入结果。与专用的 [Import Sage AP 步骤](../import-sage-ap/)和 [Import Sage AP Lines 步骤](../import-sage-ap-lines/)不同，此步骤允许您面向任何 Intacct 对象（总账、项目、客户、供应商、自定义对象等），并选择所需的字段和筛选器。

分页会自动处理，因此该步骤也适用于超过单个 Intacct API 页的结果集。

## 特有配置项

* **Sage 连接**：要读取的 Sage Intacct REST 连接。Sage 连接在 **Tools > Connections** 中管理。
* **公司 ID**：要查询的 Intacct 公司。
* **实体 ID（以逗号分隔）**：将查询限制在一个或多个 Intacct 实体。留空表示所有实体。
* **对象名称**：要查询的 Intacct 对象，例如 `GLACCOUNT`、`CUSTOMER`、`PROJECT` 或任何自定义对象名称。
* **要导入的字段**：Intacct 字段名称表，带有“启用”复选框。单击 `Lookup Object Fields` 从 Intacct 架构填充列表，然后使用 `Select All` 或 `Select None` 批量切换。
* **筛选器**：筛选器行表。每行包含 `Field`、`Filter Type`、`Value`。筛选器类型包括 `Equal To`、`Not Equal To`、`Less Than`、`Less Than or Equal To`、`Greater Than`、`Greater Than or Equal To`、`Is Null` 和 `Is Not Null`。筛选器在服务器端、分页之前应用。
