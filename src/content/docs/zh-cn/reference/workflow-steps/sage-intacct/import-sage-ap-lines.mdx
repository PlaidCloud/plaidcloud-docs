## 说明

通过 Sage Intacct REST API 从 Sage Intacct 导入应付账款账单的行级明细。每一行是一条账单行，包括总账科目、维度、行金额，以及链接回父级标题的账单键。

将此步骤与 [Import Sage AP 步骤](../import-sage-ap/)搭配使用，可加载两个粒度的数据，用于后续的分摊、报表或对账。

## 特有配置项

* **Sage 连接**：要读取的 Sage Intacct REST 连接。Sage 连接在 **Tools > Connections** 中管理。
* **公司 ID**：要查询的 Intacct 公司。如果您的发送方凭据涵盖多家公司，则为必填项。
* **实体 ID（以逗号分隔）**：将导入限制在一个或多个 Intacct 实体。留空则拉取该用户有权访问的所有实体。
