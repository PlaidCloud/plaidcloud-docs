## 说明

**导入：分隔文档（按位置）** 步骤按位置将分隔文档的所有列读取为文本列，列名为 `Column_1` 至 `Column_N`，并跳过标题行。当标题无法为列命名时使用，例如后续步骤会将某一数据行提升为标题。

## 参数

- **文档**——文件所在的文档账户和路径。以 `.gz` 结尾的路径会被解压。
- **分隔符**——字段分隔符。默认为逗号。
- **引号字符**——默认为双引号。
- **记录号列** *（可选）*——按文件顺序为记录编号的列。留空则不写入。
- **输出表**——写入行的目标位置。

文档缺失不属于错误。步骤会完成并给出一条指明路径的警告，同时写入一个空表。
