## 说明

**Import dBASE** 步骤导入 dBASE（`.dbf`）文件（文件自带架构）。它在工作流引擎中运行；打包宏的结果是对 Alteryx 宏的近似。

dBASE 导入通过临时存储以流式方式处理，而不是将整个文件加载到内存中，因此导入超大文件也不会耗尽内存。文件中的数据类型（小数、日期和时间戳）会保留在目标表中。

## 参数

- **源**——`.dbf` 文件。
- **目标表**——输出表。
- **源文件未更改时跳过重新导入**——如果源文件和步骤设置自上次成功运行以来没有变化，工作流运行会跳过导入。默认开启；取消勾选则始终重新导入。
