## 说明



将 SPSS 数据文件（.sav 和 .zsav 格式）导入 PlaidCloud 项目表。适用于调查数据、社会科学研究数据，或任何需要与基于 SPSS 的工具互操作的管道。

在格式支持的情况下，会保留变量标签和值标签。
