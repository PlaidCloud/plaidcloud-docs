## 说明


将不同项目中某个表的数据复制到当前项目。与 [Export Project Table 步骤](/zh-cn/reference/workflow-steps/export/export-project-table/)相反——是拉取而不是推送。

适用于汇总项目从多个运营项目获取数据，或参考数据集中存放在一个项目中、供其他项目读取的情况。源项目必须授予此项目**读取**数据共享。


## 数据共享管理

![数据共享管理](/images/import_external_project_table_1.png)

在从另一个项目导入表之前，该项目必须允许此项目读取它。打开**源**项目的**主页**选项卡，在**数据共享管理**下点击**新建数据共享**，选择此项目，在**允许的操作**下勾选**读取**，然后点击**添加数据共享**。请参阅[在项目之间共享数据](/zh-cn/guides/projects/managing-projects/#在项目之间共享数据)。

步骤以此项目自身的身份运行，因此无论由谁启动，运行都可通过该共享进行。

## 导入外部项目表

<Aside type="note" title="源表为空">
如果步骤运行时源表没有任何行，导入会带着源为空的警告完成，而不是静默成功——这样很容易发现目标意外为空。最常见的原因是源项目的工作流尚未构建该表；请在导入之前确保源已被填充（对于计划运行，还要确保它先运行）。
</Aside>

<Aside type="note" title="删除源表">
您读取的源表会被视为正在被此步骤使用。如果您尝试删除它，PlaidCloud 会显示引用关系，并要求您确认强制删除——勾选**是否强制删除该表？**并选择**强制删除**——而不是直接删除，即使导入步骤位于共享该数据的另一个项目中也是如此。在这种跨项目的情况下，警告会列出引用关系，但不会指出另一个项目的步骤名称，因为您可能没有访问该步骤的权限。
</Aside>
