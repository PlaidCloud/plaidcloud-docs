## 说明

从 PlaidCloud 文档中导入 Apache Parquet 文件。Parquet 是一种列式存储格式，广泛应用于 Hadoop 生态系统和云数据平台，为大型数据集提供高效的压缩和编码。

Parquet 导入通过临时存储以流式方式处理，而不是将整个文件加载到内存中，因此导入超大文件也不会耗尽内存。文件中的数据类型（小数、日期和时间戳）会保留在目标表中，时间戳列也会保持完整的日期和时间精度。
