## 说明

从 PlaidCloud 文档中导入 Alteryx YXDB 文件。YXDB 是 Alteryx Designer 用来存储数据集及字段元数据的原生二进制文件格式。

YXDB 导入通过临时存储以流式方式处理，而不是将整个文件加载到内存中，因此导入超大文件也不会耗尽内存。文件中的数据类型（小数、日期和时间戳）会保留在目标表中。

如果配置的 `.yxdb` 文件不存在，但同一文件夹中有同名的 `.parquet` 文件，步骤会改为读取该 `.parquet` 文件，并显示相应的警告。转换后的 Alteryx 工作流会将其 `.yxdb` 输出写为同名的 `.parquet` 文件，因此读取这类 `.yxdb` 文件的步骤会自动获取数据。通过搜索文件的导入不使用此回退机制。
