## 说明

从 PlaidCloud 文档中导入 Apache ORC 文件。ORC 是由 Hive 和 Spark 写入的列式存储格式，架构包含在文件中。

步骤表单有三个选项卡：

- **导入参数**——**源文件**（文档账户以及文件或文件夹路径）和**目标表**，以及**删除非 ASCII 字符**（`ascii_only`）、**导入后删除文件**（`delete_file`）和**源文件未更改时跳过重新导入**（`skip_if_unchanged`）。
- **表数据选择**——将源列映射到目标列，并提供**汇总**和**非重复**。**填充**会从 ORC 文件中包含的架构读取列及其类型。
- **数据筛选器**——在汇总之前和之后筛选行。

当文件缺失或为空时，**填充**会返回*没有可填充的内容*，并给出指明路径的警告，同时保留您现有的映射。

[已迁移的 Prophecy 项目](/zh-cn/guides/workflows/migrate-prophecy-projects/)会将此步骤用于 ORC 数据集。
