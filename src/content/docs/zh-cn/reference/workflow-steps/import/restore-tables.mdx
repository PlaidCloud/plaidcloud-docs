## 说明

从由[归档表](/zh-cn/reference/workflow-steps/export/archive-tables/)创建的归档中还原项目表。可用于在项目或工作区之间迁移表数据，或回滚到已暂存的副本。

## 独有配置项

### 源

文档账户中的归档文件。选择器还支持通过搜索进行匹配——精确匹配、开头为、结尾为、包含或通配符——而不是精确路径。

### 覆盖

默认关闭。关闭时，项目中已存在的表保持不变。开启后，会用归档的副本替换现有的表。
