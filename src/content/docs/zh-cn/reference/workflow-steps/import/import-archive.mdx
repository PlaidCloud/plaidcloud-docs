## 说明


将 PlaidCloud 原生归档文件导入回项目表。归档格式会保留列类型、元数据和索引，这些信息在经过 CSV 往返后会丢失。

由 [Export to Table Archive](/zh-cn/reference/workflow-steps/export/export-to-table-archive/) 创建。用于项目备份、工作区或环境之间的迁移，以及类型化数据的可靠传输。
