## 说明


将 HDF5（Hierarchical Data Format 第 5 版）文件导入 PlaidCloud 项目表。HDF5 常见于科学计算、机器学习数据交换，以及任何需要在 Python/R/MATLAB 工具之间往返传递带类型的列式数据的场景。

有关格式规范，请参阅 [HDF Group 的文档](http://www.hdfgroup.org/HDF5/)。

## 独有配置项


### 键名

HDF 文件以路径结构存储数据。需要一个键（路径）作为表在 HDF 文件中的目标位置。大多数情况下，这是 *table*。
