## 说明


将 Google BigQuery 中的数据导入 PlaidCloud 项目表。适用于以 BigQuery 作为主要分析数据仓库的组织，将特定数据集拉取到 PlaidCloud 中，用于进一步的建模或分摊工作。

身份验证使用 Google Cloud 服务账号；源数据集和表在步骤级别配置。
