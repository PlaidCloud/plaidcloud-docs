## 说明


将外部数据库（通过数据库连接器配置）中的一个或多个表导入项目表。支持**增量加载**——只拉取自上次导入以来发生变化的行——以及**表名重映射**——将源表以不同的名称落入 PlaidCloud。

可用于按计划使 PlaidCloud 表与运营源系统保持同步，而无需每次都重新导入每一行。

<Aside title="检查源会读取外部数据库">
对于添加到此步骤的表，**检查源**按钮会直接从已连接的数据库读取该表的当前列，并就地仅刷新该表的映射。当源表的列在您设置步骤之后发生变化时，可使用此按钮，而无需对整个连接重新运行发现。
</Aside>

<Aside title="PostgreSQL 列类型">
在 PostgreSQL 源上，`uuid` 列导入为文本，`json`/`jsonb` 列导入为其 JSON 文本表示。
</Aside>

<Aside title="数值列导入为精确小数">
源中的 `numeric`/`decimal` 列导入为精确的小数值，小数点左侧最多 28 位，右侧最多 10 位。小数位超过 10 位的值会被四舍五入以适配；整数位超过 28 位的值会使导入停止，并指出相应的列。
</Aside>

<Aside type="caution" title="无法放入其列的值会使导入停止">
如果源值无法在不丢失数据的情况下放入其目标列——例如小数落入整数列、数字对于其列来说过大，或 `NaN`/`Infinity` 落入数值列——导入会停止并报错，指出列及其数据类型，而不是静默截断或舍入。请在步骤的数据映射器中，将该列的**类型**设置为能容纳该值的类型，然后重新运行导入。
</Aside>
