## 说明

通过 monday.com 连接，将一个或多个 [monday.com](https://monday.com/) 看板的条目导入项目表。可用于将项目跟踪、需求受理队列或运营任务数据与财务数据一起引入工作流。

## 独有配置项

### 连接配置

用于读取的 monday.com 连接。

### 目标表

每个看板一行：要读取的**看板 ID** 以及写入的项目表。一个步骤可以同时导入多个看板。每个目标必须是表，而不是视图。
