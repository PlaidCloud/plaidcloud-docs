## 说明

从 PlaidCloud 文档存储中导入 IBM DB2 提取文件。当 DB2 服务器只能从本地基础设施访问时，这一步骤很有用：由外部进程将提取文件推送到 PlaidCloud 文档存储，再由此步骤从中读取到项目表。

如需实时访问 DB2（不使用提取文件），请通过标准的 [IBM DB2](../../../connectors/databases/ibm-db2/) 连接，并使用[导入外部数据库表步骤](../import-external-database-tables/)。
