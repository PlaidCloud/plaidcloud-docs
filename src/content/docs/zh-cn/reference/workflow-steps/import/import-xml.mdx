## 说明


将 XML 文件中的表格数据导入 PlaidCloud 项目表。配置用于标识每一“行”的元素路径，并将子元素或属性映射到表的列。

常见于较旧的企业集成、B2B 数据交换（RosettaNet、ebXML）和政府申报格式。


## 记录读取方式

**记录读取方式**用于选择文件如何转换为表：

* **每个记录标记一个表**（默认）——**记录标记**选项卡列出要读取的每个标记，每个标记加载到各自的表中，表名取自**目标表前缀**。
* **每个元素一行**——一个重复元素加载到一个表中，每次出现对应一行。**记录标记**选项卡和**目标表前缀**被禁用。

选择**每个元素一行**时，请设置：

* **XML 元素**——构成一行的元素。留空时，它是第一列的元素，并显示在该字段中。
* **目标表**——要加载的表。
* **列**——每个**子元素或属性**以及它加载到的**列**。所有列都以文本导入。
* **去除值前后的空格**——去除每个值开头和结尾的空白字符。
* **匹配名称时包含其命名空间前缀**——按文件中书写的形式匹配元素和属性名称，包括前缀。

**源文件**、**目标表**以及 XML 元素或至少一列都是必填项。切换模式时，另一种模式的设置会保留在表单中，因此切换回去即可恢复；但保存时会移除您切换离开的那种模式的设置；控件旁边的说明会对此予以提示。

通过表单保存的步骤，会按**记录标记**选项卡上的设置读取其记录标记。
