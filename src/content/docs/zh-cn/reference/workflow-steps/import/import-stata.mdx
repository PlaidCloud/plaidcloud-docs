## 说明


将 Stata 数据文件（.dta）导入 PlaidCloud 项目表。适用于使用 Stata 进行计量经济学或统计分析，并希望将其工作数据集带入 PlaidCloud 做进一步处理的组织。

在 Stata 格式包含变量标签的情况下，会保留这些标签。
