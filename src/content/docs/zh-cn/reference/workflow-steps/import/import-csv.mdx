## 说明

从 PlaidCloud Document 导入分隔文本文件。支持的分隔符类型包括但不限于：
* 逗号（, ）
* 竖线（|）
* 分号（; ）
* 制表符
* 空格（ ）
* @ 符号（@）
* 波浪号（~）
* 冒号（:）

### 检查所选源文件

按下*从源文件推测设置*按钮后，PlaidCloud 会打开文件并对其进行检查，尝试确定数据格式。请务必检查推测出的设置，确保其正确无误。

<Aside>如果选择了文件目录进行导入或使用了搜索，则使用找到的第一个文件进行推测</Aside>

如果某个步骤的文件未产生任何列，则无法保存：保存会因**未检测到列**而中止。当 PlaidCloud 无法读取文件时，消息会说明原因，例如分隔文件不常见的扩展名，或使用了未定义的工作流变量的文件路径。否则，请检查分隔符、引号和转义字符是否与文件匹配，文件是否为分隔文本文件，以及文件是否为空。

### 数据格式

#### 分隔符
如上所述，**检查源**会尝试确定源文件中的分隔符。如果需要其他分隔符，请在此部分指定。用户可以从标准分隔符列表中选择。未设置分隔符的步骤使用逗号。
* 逗号（, ）
* 竖线（|）
* 分号（; ）
* 制表符
* 空格（ ）
* @ 符号（@）
* 波浪号（~）
* 冒号（:）

#### 标题类型

由于 CSV 可能包含也可能不包含标题行，PlaidCloud 提供了使用标题行、忽略标题行或按列顺序确定列对齐方式的方法。
* **无标题行**：CSV 文件不含标题行。使用*数据映射器*中的源列表确定列对齐方式。
* **有标题行 - 使用标题行并覆盖字段列表**：CSV 文件含标题行。使用指定的标题名称，并忽略*数据映射器*中的源列表。
* **有标题行 - 跳过标题行并改用字段列表**：CSV 文件含标题行，但应忽略该标题行。使用*数据映射器*中源列表指定的标题名称。

**标题类型**以 `header_treatment` 存储，两个标题行选项分别对应 `use` 或 `skip`。导入 Excel 还接受 `dynamic`。

#### 日期格式

如果 CSV 文件中的日期不易被识别为日期和时间，此设置会很有用。导入过程会尝试转换日期，但多提供一些信息有助于导入。

如果仓库无法按给定格式读取某个值，该值将存储为空，而不会中止导入。因此，与文件不匹配的格式会生成一列空日期，而导入仍会报告成功。更改此设置后，请先检查导入的列，再使用结果。

<Aside type="caution" title="Lakehouse v2 上的时间列">
在 Lakehouse v2 上，数据类型为**时间**的列无论提供何种日期格式，导入后都为空。用于解析它的仓库函数无法生成单独的时间值。请将该列作为**时间戳**导入并从中读取时间，或将其作为**文本**导入。**日期**和**时间戳**列不受影响。
</Aside>

### 特殊字符

特殊字符输入项控制 PlaidCloud 如何处理某些字符的出现，以及这些字符在处理 CSV 时的含义。
 * **引号字符**：用于标示应作为单个字段处理的一段封闭文本的字符。未设置时为双引号（`"`）。
 * **转义字符**：用于指示后面的字符应按原样处理、不作为特殊字符解释的字符。当字段可能包含分隔符时很有用。未设置时为反斜杠（`\`）。
 * **空字符**：由于 CSV 没有数据类型，此字符用于指明该值应为 NULL，而不是空字符串或 0。
 * **空字段**：在所有 Lakehouse 上，空字段对文本列和数字列都加载为 NULL，因此空白数字为 NULL 而不是 0。仅包含空格的单元格按原样加载。
 * **尾随负号**：某些源系统生成的负数把负号放在末尾，而不是前缀。此设置会将这些值作为负数处理。

### 行选择

对于含有多余记录的输入文件，请将**跳过行数**设置为处理数据之前要跳过的行数。如果文件包含需要先跳过才能到达表格数据的标题块，这会很有用。

跳过的行包括空行。当**标题类型**为**有标题行 - 使用标题行并覆盖字段列表**时，标题从跳过的行之后的第一行读取，因此数据按标题名称映射到目标列。如果文件只包含被跳过的行和一个标题行而没有数据行，则不导入任何内容，步骤仍会完成。

#### 示例：SAP 列表导出

SAP 列表导出（如 KE24、KSB1 或 FAGLL03）在列标题之前以选择块开头，通常带有空行：

```text
Line Item Journal Entries
Company Code: 1000
Posting Date: 2026-09-01 to 2026-09-30

Company Code|Document Number|Posting Date|Amount
1000|100004512|2026-09-03|1,500.00
```

标题位于第 5 行，因此其前有四行。将**跳过行数**设置为 `4`，并将**标题类型**设置为**有标题行 - 使用标题行并覆盖字段列表**。导入会将 `Company Code`、`Document Number`、`Posting Date` 和 `Amount` 读取为列名，第一行数据是标题之后的那一行。

选择 **Keep Quoted Empty Fields ("") As Empty String** 可将带引号的空字段加载为空字符串而不是 NULL。

### 其他设置

**更多 CSV 选项**包含以下字段：

* **编码**（`encoding`）：读取文件所用的 Python 编解码器，用于代替自动检测。无法解码的字节读取为 U+FFFD。
* **分隔符**（`delimiters`）：用于分隔列的所有文本组成的 JSON 数组，用于代替单个分隔符。每个分隔符可以由多个字符组成。选择**连续的多个分隔符视为一个**（`combine_delimiters`）可将连续的多个分隔符视为一个。
* **行分隔符**（`row_delimiter`）：在引号之外结束一行的文本；其他位置的换行符则属于值的一部分。留空时，任何换行符都会结束一行。
* **注释行前缀**（`comment`）：以此文本开头的行不会被导入。**注释**（`comments`）以**开头**和**结尾为**成对的形式列出注释，这些注释在引号之外的任何位置都会被剪除；如果没有**结尾为**，注释持续到行尾。
* **续行符**（`line_continuation`）：位于换行符之前的此文本会将该行与下一行连接起来。
* **结束引号**（`quote_end`）：结束带引号值的引号，当它与**引号字符**不同时使用。选择**带引号的值保留其引号字符**（`keep_quotes`）可保留带引号值的引号字符。
* **将空行作为空值行导入**（`keep_blank_lines`）：空行导入为一行空值，而不是被忽略。
