## 说明

从 PlaidCloud 文档中导入 Apache Avro 文件。Avro 是 Apache Hadoop 项目中基于行的数据序列化格式，会将数据与其架构一起存储，非常适合用于数据管道和流式系统。

## 独有配置项

### 文件修改时间

只读取在某个时间窗口内发生更改的文件。**修改时间晚于**只读取最后修改时间晚于所输入时间的文件，**修改时间早于**只读取最后修改时间早于所输入时间的文件；可以设置其中一个或两个。时间格式为 `YYYY-MM-DDTHH:MM:SS`，例如 `2026-10-01T00:00:00`。除非指明时区，否则时间按 UTC 处理，例如 `2026-10-01T00:00:00-05:00`。时间中可以包含工作流变量，在步骤运行时读取。
