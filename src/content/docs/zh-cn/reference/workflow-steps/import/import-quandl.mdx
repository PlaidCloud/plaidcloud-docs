## 说明

从 Quandl 拥有数百万个数据集的存储库中导入数据集。

有关 Quandl 数据集的更多详细信息，请参阅 Quandl 官方网站：http://www.quandl.com/。

## 独有配置项

### 源数据规范

访问 Quandl 数据集需要用户账户，或访问受限的访客账户。这需要在工具中进行设置。有关设置 Quandl 账户连接的详细信息，请参阅：[PlaidCloud 工具 – 连接](/zh-cn/reference/connectors/)。

所有必要账户设置完成后，从下拉列表中选择相应的账户。

接下来，输入所需 Quandl 代码的条件。可以使用**搜索**功能查找数据集，也可以手动输入数据集，此时需要输入“[http://www.quandl.com](http://www.quandl.com/)”之后的 URL 部分。 

例如，要导入微软股票的数据集（可在此处找到：http://www.quandl.com/GOOG/NASDAQ_MSFT），请在 Quandl 代码字段中输入 *GOOG/NASDAQ_MSFT*。


### 数据选择


导入时可以对 Quandl 数据集进行切片。可用选项包括：


* 开始日期：使用日期选择器选择所需日期。
* 结束日期：使用日期选择器选择所需日期。
* 折叠：按日、周、月、季度或年汇总结果。默认不汇总。
* 转换：汇总计算。
* 行数上限：默认值 0 返回所有行。任何其他正整数值将指定从数据集返回的行数上限。
