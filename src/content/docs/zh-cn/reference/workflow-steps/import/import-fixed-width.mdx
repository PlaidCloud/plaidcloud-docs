## 说明



导入以字符位置而非分隔符来定义列的文本文件——这是经典的大型机 / COBOL 输出格式。按字段配置列边界（起始位置、长度）。

常见于传统 ERP 导出、政府申报文件和银行对账单格式，这些数据按固定列显示排版，而不是按分隔符解析。

固定宽度导入通过临时存储以流式方式处理，而不是将整个文件加载到内存中，因此导入超大文件也不会耗尽内存。

### 标题行

由于 Excel 文件可能包含也可能不包含标题行，PlaidCloud 提供了三种方式：使用标题行、忽略标题行，或使用列顺序来确定列的对齐方式。
* **无标题行**：文件不包含标题行。使用*数据映射器*中的源列表来确定列的对齐方式
* **有标题行 - 使用标题行并覆盖字段列表**：文件有标题行。使用指定的标题名称，并忽略*数据映射器*中的源列表。
* **有标题行 - 跳过标题行并改用字段列表**：文件有标题行，但应忽略。使用*数据映射器*中源列表指定的标题名称。

### 行选择

对于含有多余记录的输入文件，可以指定在处理数据之前要跳过的行数。如果文件中包含必须先跳过才能到达表格数据的标题块，这一设置会很有用。

### 列宽

输入各列的宽度，以逗号或空格分隔。

### 布局

| 设置 | 作用 |
| --- | --- |
| 编码 | 文件的字符集：**UTF-8**（默认）、**EBCDIC（美国，cp037）**、**EBCDIC（国际，cp500）** 或 **拉丁字母-1（Latin-1）**。大型机文件请选择 EBCDIC 代码页。 |
| 跳过的记录数 | 在标题行或数据之前，从文件开头跳过多少条记录。 |
| 末尾丢弃的记录数 | 从文件末尾丢弃多少条记录，例如尾部记录。 |
| 每行一条记录 | 开启（默认）时，每行为一条记录。对于记录首尾相接、没有换行符的文件，请取消勾选；此时每条记录的长度等于各列宽度之和。 |
| 记录之间的字符数 | 当记录并非每行一条时，每条记录之后要跳过多少个字符，例如分隔符。 |
| 去除空白 | 从每个值中去除的空白：**开头和结尾**（默认）、**仅结尾**或**无**。 |
