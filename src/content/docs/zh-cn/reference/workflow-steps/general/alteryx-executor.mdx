## 说明

将带版本的 Alteryx 对等操作作为托管作业运行。对于所需工作依赖 Python 库（Shapely、scikit-learn、NLTK、Tesseract、reportlab）而非数据库 SQL 的 [Alteryx 转换](/zh-cn/guides/workflows/migrate-alteryx-workflows/)，它是通用的承载步骤。

现在，大多数已转换的操作都有各自的一流步骤类型，更易于阅读和编辑。此步骤仍保留给没有专属步骤类型的操作，那些步骤类型在底层也是通过它启动的。

<Aside type="note" title="通常无需手动创作">
  转换会在需要时生成此步骤。只有在要运行没有专属步骤类型的对等操作时，才需要手动添加，例如
  [Spatial Info](/zh-cn/reference/workflow-steps/spatial/spatial-info/)。
</Aside>

## 配置

### 执行器

- **操作**——要运行的对等操作。
- **合约版本**——操作所遵循的执行器合约。默认为 `v1`。

### 输入和输出

- **源** / **目标表**——主要的输入表和输出表。
- **输入表** / **输出表**——供接受或产生多个表的操作使用的其他表。
- **输入工件** / **输出工件**——非表的输入和输出，例如渲染的图像。

### 资源

默认关闭，此时作业获得标准资源。开启高级资源管理后，可显式设置 **CPU** 和**内存**——当操作处理特别大的几何数据或模型训练，而默认分配不够用时，值得这样做。
