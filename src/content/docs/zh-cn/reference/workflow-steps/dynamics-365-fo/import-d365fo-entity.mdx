## 说明

通过您的 [D365 F&O 连接](/zh-cn/guides/connections/dynamics-365-fo/)，将一个 Dynamics 365 Finance & Operations 实体导入到项目表中。选择连接、实体类型、同步模式和任何筛选器；步骤会拉取匹配的记录并写入，无需编写 OData 查询。

这是一个通用的预置步骤 — 一种步骤类型涵盖六个实体，从主数据/参考数据（主科目、货币、客户、供应商、已发布产品）到交易记录（总账日记账标题），既可通过直接的 OData 调用，也可通过异步 DMF 批量提取。

## 配置

| 字段 | 是否必填 | 备注 |
|---|---|---|
| D365 F&O 连接 | 是 | 用于读取的 D365 F&O 连接。 |
| 目标表 | 是 | 结果写入的项目表。每次运行都会被完全覆盖。 |
| 实体类型 | 是 | 要拉取的实体。默认为 `main_accounts`。可选 `main_accounts`、`currencies`、`customers`、`vendors`、`released_products`、`ledger_journal_headers` 之一。 |
| 同步模式 | 是 | 默认为 `odata`。`odata` 直接调用实体的标准 OData 端点。`dmf` 提交异步的数据管理框架（Data Management Framework）导出作业，并在完成后下载结果 — 适用于通过普通 OData 分页拉取时数据量过大或速度过慢的情况。 |
| 筛选器 | 否 | 范围筛选器和相等筛选器，会转换为请求的 OData `$filter`。每个实体只允许对 D365 F&O 能够在服务器端实际计算的字段设置筛选器 — 不支持的字段会被拒绝，而不是被悄悄忽略。 |

### 实体和可筛选字段

| 实体类型 | 拉取内容 | 可筛选字段 |
|---|---|---|
| `main_accounts` | 会计科目表 | 科目范围、维度 |
| `currencies` | 货币主数据 | — |
| `customers` | 客户主数据 | 科目范围 |
| `vendors` | 供应商主数据 | 科目范围 |
| `released_products` | 已发布产品主数据 | — |
| `ledger_journal_headers` | 日记账标题，包括已过账和未过账 | 日期范围、科目范围、维度 |

<Aside type="note">
日期、科目和维度的**范围**筛选器（`ge`/`le` 形式的边界）是限定 `ledger_journal_headers` 拉取范围的主要方式 — 不设边界地拉取交易历史可能会非常庞大。针对生产数据运行之前，请至少为大型实体设置一个边界。
</Aside>

<Aside type="caution">
对于相同的实体和筛选器集合，`dmf`（批量）模式需要等待异步导出作业，速度明显慢于 `odata` 模式。请仅在数据量大到无法通过直接 OData 拉取时才使用它。
</Aside>
