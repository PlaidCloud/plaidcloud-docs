登录工作区后，首先看到的就是启动器。它把您最常使用的内容（项目、工作流、表、仪表板、Panel 应用、维度、数据编辑器和文档）汇集到同一个磁贴页面上，让您无需在各个应用中逐一查找，就能从上次中断的地方继续工作。

## 分区

页面从上到下分为三个分区。分区只有在有内容可显示时才会出现。

- **需要关注**：最近一次运行失败的工作流，让问题在您进入页面时就能浮现。每张卡片都直接链接到失败的运行，已经处理过的可以**关闭**。
- **已固定**：您标记为收藏的所有内容，按固定的先后顺序排列。任何类型的项目都可以固定在这里（请参阅[固定](#固定收藏)）。
- **最近**：您最近打开或编辑过的项目、仪表板和 Panel 应用。

<Aside type="note">
只有项目、仪表板和 Panel 应用会按最近使用时间显示，因为工作流、表、维度、数据编辑器和文档的数量通常太多，无法这样列出。请将经常回访的内容固定下来，它们就会在**已固定**分区中等着您。
</Aside>

## 项目磁贴

项目磁贴可一目了然地概括项目：

| 统计项 | 含义 |
|---|---|
| **工作流运行** | 近期时间窗口内已完成的工作流运行 |
| **上次运行** | 最近一次运行的完成时间 |
| **工作流** | 项目包含的工作流 |
| **表** | 项目包含的表 |
| **记录** | 这些表中的总行数（`~` 表示估计值） |

没有运行历史的项目会显示**上次编辑**，而不是运行数据；数量为零时会完全省略计数。

### 磁贴图像

每个项目磁贴都带有淡化的背景图像。默认是 PlaidCloud 扇形图案，但您可以为项目设置自己的图片，例如客户徽标或其他能一眼识别该工作的图像，使其在繁忙的启动器中脱颖而出。

设置方法：

1. 打开项目并转到其**主页**选项卡。
2. 滚动到左列底部的**启动器磁贴图像**。
3. 选择保存该图像的文档账户，然后**浏览**到图像文件。
4. 使用**清除**恢复默认图像。

图像会淡化显示在统计数据后面，以保证统计数据清晰可读，因此请选择淡化后效果依然不错的图片。宽图比高图更适合磁贴的形状。设置此项需要有编辑项目的权限；只读查看者会看到选取器处于禁用状态。

<Aside type="note">
任何能看到该项目的人都能看到它的磁贴图像，但只有同样有权读取其所在文档账户的人才能获取到该图像。没有该访问权限的查看者只会看到默认的扇形图案。
</Aside>

仪表板磁贴的工作方式不同：它们显示仪表板本身自动生成的缩略图，因此无需选择。

## 打开内容

每张卡片和每个列表行都有一个主要操作，并在适用时提供额外操作：

| 项目 | 打开 | 其他可用操作 |
|---|---|---|
| 项目 | 该项目 | |
| 工作流 | 该工作流 | 运行、打开最近一次运行、实时**正在运行**状态 |
| 表 | 该表 | 在表资源管理器中打开 |
| 维度 | 其层次结构编辑器 | |
| 数据编辑器 | 其所属项目 | |
| 仪表板 | 该仪表板 | 在新选项卡中打开 |
| Panel 应用 | 该应用 | 在新选项卡中打开 |
| Dash 应用 | 该应用 | 在新选项卡中打开 |
| 文档 | 该文件或文件夹 | |

正在运行的工作流会显示实时状态指示器，自动更新，无需刷新。

## 固定（收藏）

单击任意启动器卡片或列表行上的**星标**即可固定它。无论最近使用得多早，已固定的项目始终显示在**已固定**分区中，因此您关心的内容不会滚动到看不见的地方。

您也可以直接在已有的工作位置固定，无需先打开启动器，请查找星标列：

- **项目、工作流、表、维度和数据编辑器**：项目内各自列表中的星标列。
- **仪表板**、**Panel 应用**和 **Dash 应用**：我的仪表板和我的 Panel 应用中的星标列。
- **文档**：在文档浏览器中右键单击文件*或*文件夹，然后选择**固定到启动器**。

在任何位置单击已点亮的星标即可取消固定。在任何位置所做的固定都会立即反映在启动器上。

## 磁贴或列表

使用工具栏中的**磁贴 / 列表**切换开关，在宽松的卡片视图和紧凑的单行列表之间切换。您的选择会被记住，切换是即时的：它会重新绘制已加载的内容，而无需再次获取。

## 按类型筛选

工具栏左侧的芯片行为每种类型提供一个芯片，各自带有图标：**项目**、**仪表板**、**Panel 应用**、**工作流**、**表**、**维度**、**数据编辑器**和**文档**。按下的芯片表示显示该类型；单击它可在**最近**和**已固定**分区中隐藏该类型。您的筛选条件会在两次访问之间保留。

**需要关注**分区从不被筛选：即使对应类型的芯片处于关闭状态，失败的工作流也总会显示出来。

## 搜索和命令

在任意屏幕上按 **Ctrl/Cmd-K**，或单击启动器工具栏中的**搜索**，即可打开命令面板。唯一的例外是过账登记簿，它将 **Ctrl/Cmd-K** 留给自己的面板。

在您输入之前，它会列出两项内容：

- **操作**：可以从这里运行的命令，包括转到主页、项目、仪表板或文档，在浅色和深色外观之间切换，连接您的 AI，以及获取帮助。**转到**操作仅针对工作区拥有的应用显示。
- **最近**：您最近打开的八项内容，最新的在前，包括从启动器或面板中打开的项目、工作流、表、维度、数据编辑器、仪表板、Panel 应用和文档，以及您在任何位置打开的每个项目。从项目内部打开的内容（例如工作流或维度）不会被添加。此列表保存在您的浏览器中，因此不会在设备之间共享，并且与启动器的**最近**分区相互独立（请参阅[分区](#分区)）。

开始输入后，两个列表会同时缩小范围：您输入的字符只需按顺序出现即可，例如输入 `proj` 即可找到**前往项目**，最接近的匹配排在最前。从输入两个字符起，面板还会在项目、工作流、表、仪表板和 Panel 应用中搜索，并将这些结果按类型分组添加在下方，每个结果都带有与看板上相同的打开操作和固定星标。已显示在**最近**下的结果不会重复出现。

- **向上 / 向下**键移动选择。
- **Enter** 运行所选操作或打开所选项目。
- **Escape** 关闭面板。

维度、数据编辑器和文档不可搜索，请通过固定它们、在从启动器打开过之后从**最近**中查找，或从它们所属的项目中访问。

单击结果会将其打开；单击其**星标**会将其固定并使面板保持打开，因此您可以一次固定多项内容。

## 刷新

当您返回启动器且数据已过时，启动器会自动刷新。要立即获取最新内容，请单击工具栏中的**刷新**。

## 从其他位置开始

默认情况下，PlaidCloud 从启动器打开。要改为从其他应用开始，请在选项菜单中关闭**在启动器中启动**。

## 外观（浅色、深色、自动）

顶部工具栏中的**外观**按钮（账户菜单旁边的对比度图标）用于在浅色和深色外观之间切换 PlaidCloud。它适用于所有位置：启动器、每个应用，以及其中的每个窗口和对话框。

| 选项 | 作用 |
| --- | --- |
| **浅色** | 始终使用浅色外观，无论设备如何设置。 |
| **深色** | 始终使用深色外观，无论设备如何设置。 |
| **自动（跟随系统）** | 跟随操作系统的外观设置。 |

**自动（跟随系统）** 是默认设置，并会实时跟踪系统：如果计算机设置为在晚上切换到深色，PlaidCloud 会在同一时刻跟随切换，无需重新加载。选择**浅色**或**深色**会固定外观，此后将忽略系统设置。

<Aside type="note">
您的选择会记录在您所用的浏览器中，因此不会延续到其他浏览器或其他计算机，请在每个浏览器中分别设置一次。清除浏览器的站点数据会将其重置为**自动**。如果浏览器阻止本地存储（某些隐私浏览模式会这样），切换器在当前会话中仍然有效，但下次会从**自动**重新开始。
</Aside>

嵌入的内容保留其自身的颜色：仪表板和 Panel 应用不会受此设置影响而改变样式。
