PlaidCloud 的界面提供十一种语言：

| 语言 | 菜单项 |
|---|---|
| 英语（美国） | English (US) |
| 英语（英国） | English (UK) |
| 德语 | Deutsch |
| 西班牙语 | Español |
| 法语 | Français |
| 葡萄牙语（葡萄牙） | Português (Portugal) |
| 葡萄牙语（巴西） | Português (Brasil) |
| 波兰语 | Polski |
| 日语 | 日本語 |
| 韩语 | 한국어 |
| 中文（简体） | 简体中文 |

所有人起初都使用 English (US)。在您选择语言之前，不会有任何变化。

## 更改语言

1. 在顶部标题栏中，点击**语言**按钮，它位于**外观**按钮旁边。其菜单以各语言自己的名称列出所有语言，因此无论当前显示何种语言，都能找到您的语言。
2. 选择一种语言。
3. 页面会弹出消息，确认 PlaidCloud 将以该语言重新加载。未保存的更改将会丢失，因此请先保存工作。点击**重新加载**继续，或取消以保持现状。

PlaidCloud 会将您的选择保存到您的个人资料，并以新语言重新加载。如需切换回去，以同样的方式选择 **English (US)** 即可。

## 您的选择适用范围

- **其他设备和浏览器。** 您的选择会随您同步。在另一台设备或浏览器上登录同一工作区时，从下一次页面加载起生效。
- **按工作区。** 该选择属于您在某个工作区中的个人资料。如果您使用多个工作区，请在每个工作区中分别设置语言。

## 数字和日期

数字和日期按所选语言的格式显示。例如，在德语中，一千二百三十四点五显示为 `1.234,5`。在波兰语中，1234567.89 显示为 `1 234 567,89`，2026 年 10 月 12 日显示为 `12.10.2026`。日语和中文将该日期显示为 `2026/10/12`，韩语则显示为 `26. 10. 12.`。English (UK) 使用英式拼写和英式格式。

只有显示方式会改变。您保存、导出或发送给集成的值仍保持其通常的格式。

## 使用日语、韩语和中文输入

日语、韩语和中文输入法可在数字字段以及其他限制输入内容的字段中使用。全角数字会在输入时自动转换，因此 `１２３` 会变成 `123`。

## 还有哪些内容会跟随您的语言

PlaidCloud 从服务器发送给您的文本也会跟随您的语言，PlaidCloud 提供的每种语言都是如此：

- **电子邮件。** 系统电子邮件，例如邀请、密码重置、工作流和迁移通知，以及注册、计费和支持类电子邮件。
- **登录屏幕。** 登录、设置密码和已登出屏幕，以及 Keycloak 通过这些屏幕发送的电子邮件。
- **错误消息。** 请求失败时 PlaidCloud 显示的消息，包括界面中、通过 REST API 和通过 JSON-RPC 返回的消息。
- **项目文档 PDF。** PlaidCloud 为记录项目而生成的 PDF。

## PlaidCloud 如何选择语言

| 场景 | 使用的语言 |
|---|---|
| 在 PlaidCloud 内部 | 您通过**语言**按钮选择的语言。您的登录页面和电子邮件也使用同一选择。 |
| 登录前的登录页面及其他屏幕 | 浏览器的语言。 |
| 注册时 | 浏览器的语言。PlaidCloud 会将其存储在您的组织上，发送给该组织的计费和账户电子邮件会使用这一语言。 |

如果您的浏览器或个人资料使用了 PlaidCloud 未提供的语言，文本将以 English (US) 显示。浏览器设置为繁体中文（zh-TW 或 zh-HK）时，服务器文本会回退为 English (US)。

## 仍保持英文的内容

- 工作流和步骤的运行消息与日志，以及活动流。许多人会阅读这些内容，统一使用一种语言有助于保持其可搜索性和一致性。
- AI 助手和 MCP 工具生成的文本。
- 您自己撰写的电子邮件，包括电子邮件模板以及报表步骤发送的电子邮件。
- OpenAPI 文档。
- SQL 和表达式引擎的错误文本。
- 注册屏幕。
- 您创建的内容，例如项目、表和步骤的名称。
