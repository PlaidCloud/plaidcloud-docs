PlaidCloud Git 包含内置的包注册表（用于可分发的工件）和 Git Large File Storage (LFS)（用于存储库中的大型二进制文件）。

## 关于包注册表

包注册表按所有者划分，支持多种生态系统格式，包括 npm、PyPI、Maven、NuGet、RubyGems、容器映像等。包对工作区私有，仅经过身份验证的成员可以访问。

每种包类型在以下位置都有各自的端点：

```
https://git.example.plaidcloud.com/api/packages/you/<type>
```

其中 `<type>` 是生态系统标识符（例如 `npm`、`pypi` 或 `maven`）。

## 向注册表进行身份验证

包管理器操作使用 PlaidCloud Git 用户名，并以个人访问令牌作为密码。有关如何创建令牌，请参阅[存储库](/zh-cn/guides/git/repositories/)。

## 发布包

具体步骤因生态系统而异，但模式相同：将包管理器指向注册表 URL，然后运行其标准发布命令。

对于 npm，请在项目中添加 `.npmrc`，将包的作用域限定到注册表：

```ini
@you:registry=https://git.example.plaidcloud.com/api/packages/you/npm/
//git.example.plaidcloud.com/api/packages/you/npm/:_authToken=YOUR_TOKEN
```

然后照常发布：

```bash
npm publish
```

对于 PyPI、Maven、NuGet 和其他生态系统，请将工具的存储库或源设置配置为对应的注册表 URL，并使用该工具的标准发布命令（例如 `twine upload`、`mvn deploy` 或 `dotnet nuget push`）。

## 安装包

将包管理器指向同一个注册表 URL，然后照常安装。配置好上面的 `.npmrc` 后：

```bash
npm install @you/my-package
```

对于其他生态系统，请在工具配置中将该注册表添加为额外的源，并使用其标准安装命令。

## 使用 Git LFS 管理大文件

Git LFS 会将历史记录中的大文件或二进制文件替换为轻量级指针，并单独存储文件数据，从而保持存储库的快速。每个 PlaidCloud Git 存储库都启用了 LFS。

1. 在计算机上安装一次 LFS 客户端：

   ```bash
   git lfs install
   ```

2. 在存储库内部，告知 LFS 要跟踪哪些文件模式：

   ```bash
   git lfs track "*.parquet"
   ```

   这会创建或更新 `.gitattributes`。提交该文件：

   ```bash
   git add .gitattributes
   git commit -m "Track Parquet files with LFS"
   ```

3. 照常添加并推送，匹配的文件会自动上传到 LFS：

   ```bash
   git add data/large-dataset.parquet
   git commit -m "Add dataset"
   git push origin main
   ```

<Aside type="tip">Git LFS 适用于存放在存储库历史记录中、通过 `git clone` 或 `git pull` 获取的大文件。包注册表适用于使用方通过包管理器安装的、可分发的版本化工件。如果团队成员会执行 `npm install` 或 `pip install`，请使用注册表；如果他们需要将其作为检出的一部分，请使用 LFS。</Aside>
