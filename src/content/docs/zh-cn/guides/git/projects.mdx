项目看板将议题和拉取请求排列到代表工作流各阶段的列中，让整个团队共享一个视图，了解哪些在进行、哪些受阻、哪些已完成。

## 创建看板

1. 打开存储库并选择**项目**选项卡。
2. 选择**新建项目**。
3. 输入看板名称。
4. 选择起始模板（基本的 **To Do / In Progress / Done** 布局是不错的默认选择），或选择空看板从头构建布局。
5. 选择 **Create Project** 以打开看板。

<Aside>从存储库的**项目**选项卡创建的看板属于该存储库。跨工作区中多个存储库的看板由管理员在组织级别的项目区域创建。</Aside>

## 设置列

1. 要添加列，请选择**添加列**，输入标签，然后保存。
2. 要重命名列，请打开其设置并选择**编辑**。
3. 向左或向右拖动列标题可重新排序。
4. 在列的设置中将某一列标记为默认列，所有未指定目标而添加的卡片都会放入该列。

## 添加和移动卡片

- 要添加现有的议题或拉取请求，请打开列的菜单并选择 **Add an item**，然后按标题或编号搜索。
- 要直接在看板上创建新议题，请选择列内的 **+**。议题会保存到存储库，并立即显示为卡片。
- 随着工作的推进，将卡片拖到其他列。卡片的位置反映其当前状态，它本身不会更改议题的标签或负责人。

## 跟踪工作

无需打开单个议题，看板即可让您一目了然地了解团队的工作量。通过以下方式保持其最新：

- 关闭议题或合并拉取请求：卡片会移到已完成列或离开看板，具体取决于看板的自动化设置。
- 在需要看板之外再设置限时目标时，搭配使用 **Milestones**。里程碑跟踪截止日期和完成百分比，而看板跟踪流程。
