PlaidCloud Git 允许您跨工作区成员资格所授权访问的所有存储库，搜索代码、文件、议题和拉取请求。

## 搜索代码

1. 选择任意页面顶部的搜索框并输入查询内容。
2. 按 **Enter** 查看您可访问的所有存储库中的结果。
3. 选择某个结果，可直接跳转到文件中匹配的行。
4. 使用结果页面上的**存储库**和**语言**筛选器缩小结果范围。

<Aside>代码搜索索引默认分支。要搜索其他分支，请浏览到该分支并使用下文介绍的存储库内搜索。</Aside>

## 在存储库内搜索

1. 打开存储库并选择**代码**选项卡。
2. 按 **T**（或选择文件查找框）打开文件查找器。
3. 输入文件名或路径的一部分，列表会随输入实时筛选。
4. 选择文件将其打开，然后使用浏览器的页内查找（**⌘F** / **Ctrl+F**）定位特定的行。

<Aside type="tip">文件查找器按路径段匹配，因此输入 `util/auth` 会找到 `src/util/auth.py`、`lib/util/auth_helper.go` 等类似路径。</Aside>

## 筛选议题和拉取请求

在 **Issues** 或 **Pull Requests** 列表中，可将关键字搜索与 `key:value` 筛选器组合使用：

| 筛选器 | 示例 |
|---|---|
| 未关闭或已关闭状态 | `is:open`、`is:closed` |
| 标签 | `label:bug`、`label:"needs review"` |
| 负责人 | `assignee:you` |
| 作者 | `author:you` |
| 里程碑 | `milestone:"v1.2"` |

直接在搜索框中输入筛选器，可自由组合，并使用**排序**菜单按 **Recently Updated**、**Most Commented**、**Newest** 或**最早**排序。

<Aside>标签名称包含空格时，请用引号括起来：`label:"needs review"`。</Aside>

## 更快找到内容的技巧

- **精确短语**：将多词术语用引号括起来（`"connection pool"`），避免出现嘈杂的部分匹配。
- **限定到某个存储库**：搜索前先打开存储库，使结果更集中。
- **描述性名称会带来回报**：名称清晰具体的存储库和议题，比 `misc` 这类通用名称更容易在搜索中出现。
- **标签是可搜索的元数据**：标注良好的议题比埋没在文字中的议题更容易筛选，因此请一致地应用标签。
