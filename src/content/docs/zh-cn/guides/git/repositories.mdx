存储库保存一个项目的文件、分支和历史记录。本指南介绍如何创建存储库并从计算机连接到它。

## 创建存储库

1. 在工作区中打开 **Git**。
2. 选择右上角的 **+** 菜单，然后选择 **New Repository**。
3. 输入名称，也可以输入简短说明。
4. 选择可见性。新存储库默认为**私有**，仅已获授予访问权限的成员可以看到。
5. 也可以选择 **Initialize Repository**，以添加 README、`.gitignore` 文件和许可证。
6. 选择 **Create Repository**。

贡献者不能直接在工作区的 Git 组织中创建存储库；存储库通过 PlaidCloud 创建。

## 生成个人访问令牌

由于通过 PlaidCloud 登录，账户没有单独的 Git 密码。若要在命令行中通过 HTTPS 克隆或推送，请创建个人访问令牌并用它代替密码。

1. 选择右上角的头像，然后选择**设置**。**Git** 选项卡中的设置卡片也提供了直接前往此页面的链接。
2. 打开**应用程序**选项卡。
3. 在**管理访问令牌**下，输入说明令牌使用位置的名称（例如 `laptop`）。
4. 选择 **write:repository** 权限，使令牌能够克隆和推送。
5. 选择 **Generate Token**。
6. 复制令牌并妥善保存。之后将无法再次查看。

<Aside type="caution">请像对待密码一样对待令牌，任何持有令牌的人都可以在 Git 中以您的身份操作。为每台计算机生成单独的令牌，这样可以撤销其中一个而不影响其他令牌。</Aside>

## 克隆存储库

1. 在工作区中打开 **Git**，选择存储库克隆地址旁边的复制按钮（选择 **How to clone** 可查看设置步骤）。也可以在存储库中选择**代码**，然后复制 **HTTPS** URL。
2. 在终端中使用该 URL 运行 `git clone`：

   ```bash
   git clone <clone URL>
   ```

3. 当 Git 提示输入密码时，粘贴**访问令牌**。使用 URL 中已有的用户名。
4. 使用设置卡片中显示的值，设置 Git 记录在提交中的姓名和电子邮件地址：

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

推送需要贡献者或管理员访问权限；作为查看者，只能读取而不能推送。请参阅[访问级别](/zh-cn/guides/git/#访问级别)。

<Aside>若不想每次推送都重新输入令牌，可以让操作系统的 Git 凭据助手保存它，例如在 macOS 上使用 `git config --global credential.helper osxkeychain`。</Aside>

## 提交并推送更改

在克隆的存储库中执行以下操作：

1. 暂存更改：`git add .`
2. 附带说明记录更改：`git commit -m "Describe what changed"`
3. 将更改发送到 PlaidCloud Git：`git push`

提交会显示在存储库的 **Commits** 和**活动**视图中，以及包含这些提交的任何分支或拉取请求中。

## 管理访问权限和可见性

打开存储库的**设置**选项卡，可重命名存储库、更改其可见性或转移所有权。若要让其他成员参与贡献，请使用**设置 → Collaborators**，按用户名添加，并赋予**读取**、**写入**或**管理员**角色。

<Aside>存储库访问权限还取决于工作区成员身份和安全组。请参阅[访问管理](/zh-cn/administration/access/)，了解它们如何决定谁可以查看和编辑存储库。</Aside>
