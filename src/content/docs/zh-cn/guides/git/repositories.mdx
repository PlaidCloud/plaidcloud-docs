存储库保存一个项目的文件、分支和历史记录。本指南介绍如何创建存储库并从计算机连接到它。

## 创建存储库

1. 从工作区打开 **Git**。
2. 选择右上角的 **+** 菜单，然后选择 **New Repository**。
3. 输入名称，也可以输入简短说明。
4. 选择可见性。新存储库默认为**私有**，只有您授予访问权限的成员才能看到。
5. 可选：选择 **Initialize Repository** 以添加 README、`.gitignore` 和许可证。
6. 选择 **Create Repository**。

## 生成个人访问令牌

由于您通过 PlaidCloud 登录，账户没有单独的 Git 密码。要从命令行通过 HTTPS 克隆或推送，请创建个人访问令牌并用它代替密码。

1. 选择右上角的头像，然后选择**设置**。
2. 打开**应用程序**选项卡。
3. 在 **Manage Access Tokens** 下，输入一个说明令牌使用位置的名称（例如 `laptop`）。
4. 选择存储库的**读取**和**写入**范围，使令牌可以克隆和推送。
5. 选择 **Generate Token**。
6. 复制令牌并妥善保存。之后将无法再次查看。

<Aside type="caution">请像对待密码一样对待令牌：拥有它的任何人都可以在 Git 中以您的身份操作。为每台计算机生成单独的令牌，这样即可撤销其中一个而不影响其他令牌。</Aside>

## 克隆存储库

1. 在 PlaidCloud Git 中打开存储库。
2. 选择**代码**，然后复制 **HTTPS** 克隆 URL。
3. 在终端中，使用该 URL 运行 `git clone`：

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. 当 Git 提示输入凭据时，输入 **PlaidCloud 用户名**，并粘贴**访问令牌**作为密码。

<Aside>为避免每次推送都重新输入令牌，可让操作系统的 Git 凭据助手存储它：在首次推送之前运行 `git config --global credential.helper store`（在 macOS 上为 `osxkeychain`）。</Aside>

## 提交并推送更改

在已克隆的存储库内部：

1. 暂存更改：`git add .`
2. 记录更改并附上消息：`git commit -m "Describe what changed"`
3. 发送到 PlaidCloud Git：`git push`

您的提交会显示在存储库的 **Commits** 和**活动**视图中，以及包含这些提交的任何分支或拉取请求上。

## 管理访问权限和可见性

打开存储库的**设置**选项卡，可重命名存储库、更改其可见性或转移所有权。要让其他成员参与贡献，请使用 **设置 → Collaborators**，按用户名添加他们，并指定**读取**、**写入**或 **Administrator** 角色。

<Aside>存储库访问权限还取决于工作区成员资格和安全组。有关这些如何对应到谁可以查看和编辑存储库，请参阅[访问管理](/zh-cn/administration/access/)。</Aside>
