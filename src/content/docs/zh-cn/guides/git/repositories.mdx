存储库保存一个项目的文件、分支和历史记录。本指南介绍如何创建存储库并从计算机连接到它。

## 创建存储库

1. 在工作区中打开 **Git**。
2. 选择右上角的 **+** 菜单，然后选择 **New Repository**。
3. 输入名称，也可以输入简短说明。
4. 选择可见性。新存储库默认为**私有**，只有获得访问权限的成员才能看到。
5. 也可以选择 **Initialize Repository**，以添加 README、`.gitignore` 和许可证。
6. 选择 **Create Repository**。

## 生成个人访问令牌

由于通过 PlaidCloud 登录，您的账户没有单独的 Git 密码。若要在命令行中通过 HTTPS 克隆或推送，请创建个人访问令牌，并用它代替密码。

1. 选择右上角的头像，然后选择**设置**。**Git** 选项卡中的设置卡片也直接链接到此页面。
2. 打开**应用程序**选项卡。
3. 在 **Manage Access Tokens** 下，输入一个说明令牌使用位置的名称（例如 `laptop`）。
4. 选择 **write:repository** 权限，使令牌可以克隆和推送。
5. 选择 **Generate Token**。
6. 复制令牌并妥善保存。之后将无法再次查看。

<Aside type="caution">请像对待密码一样对待令牌：任何拥有它的人都可以在 Git 中以您的身份操作。为每台计算机分别生成令牌，这样可以撤销其中一个而不影响其他令牌。</Aside>

## 克隆存储库

1. 在工作区中打开 **Git**，选择存储库克隆地址旁边的复制按钮（选择 **How to clone** 可查看设置步骤）。也可以在存储库中选择**代码**并复制 **HTTPS** URL。
2. 在终端中，使用该 URL 运行 `git clone`：

   ```bash
   git clone <clone URL>
   ```

3. Git 提示输入密码时，粘贴**访问令牌**。使用 URL 中已有的用户名。
4. 使用设置卡片中显示的值，设置 Git 在提交中记录的姓名和电子邮件：

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

推送需要 Contributor 或 Administrator 访问权限；作为**查看者**，您可以读取但不能推送。请参阅[访问级别](/zh-cn/guides/git/#访问级别)。

<Aside>为避免每次推送都重新输入令牌，可以让操作系统的 Git 凭据助手存储它，例如在 macOS 上使用 `git config --global credential.helper osxkeychain`。</Aside>

## 提交并推送更改

在已克隆的存储库内：

1. 暂存更改：`git add .`
2. 附带消息记录更改：`git commit -m "Describe what changed"`
3. 将更改发送到 PlaidCloud Git：`git push`

您的提交会显示在存储库的 **Commits** 和**活动**视图中，以及包含这些提交的任何分支或拉取请求上。

## 管理访问权限和可见性

打开存储库的**设置**选项卡，可重命名存储库、更改其可见性或转移所有权。若要让其他成员参与贡献，请使用**设置 → Collaborators**，按用户名添加他们，并指定**读取**、**写入**或**管理员**角色。

<Aside>存储库访问权限也遵循工作区成员身份和安全组。有关这些设置如何对应到谁可以查看和编辑存储库，请参阅[访问管理](/zh-cn/administration/access/)。</Aside>
