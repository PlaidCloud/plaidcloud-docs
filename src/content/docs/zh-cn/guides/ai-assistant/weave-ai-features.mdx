## 说明

工作区管理员决定工作区使用 Weave 的哪些 AI 功能。每项功能都可以单独为工作区中的所有人关闭。在管理员关闭之前，所有功能都处于开启状态。

Weave 的检查和发现项不使用 AI，因此无论您在此做出何种选择，它们都保持开启。

## 开启或关闭功能

1. 点击页眉中的 **Weave** 按钮。
2. 选择其菜单末尾的 **AI 功能…**。
3. 取消勾选要关闭的功能旁的复选框；勾选则重新开启。
4. 点击**保存**。

更改会应用于工作区中任何人发出的下一个 AI 请求，无需任何人退出登录。

**AI 功能…** 仅对工作区管理员显示。其他人若尝试通过 API 更改这些功能，会收到提示：*只有工作区管理员才能开启或关闭 AI 功能。*

## 功能列表

| 功能 | 涵盖范围 | 关闭后 |
|---|---|---|
| **Weave 聊天** | 项目 **Weave** 选项卡上的聊天、**帮助与支持**中的**询问助手**，以及 [PlaidCloud 移动应用](/zh-cn/guides/mobile-app/weave-on-mobile/)中的 Weave。 | **Weave** 选项卡的**聊天**会提示管理员已将其关闭，**帮助与支持**中没有**询问助手**选项卡，在移动应用中提出的问题会被拒绝。 |
| **修复助手** | Weave 发现项上的**修复**，以及日志条目上的 **Weave AI** 选项卡。 | 发现项不再提供**修复**，但**可能先于其所读取的表写入而运行的步骤**下缺少连接器的发现项除外，其**修复**打开的是[同步依赖项](/zh-cn/guides/workflows/sync-dependencies/)，而不是助手。**Weave AI** 选项卡不可用。 |
| **导入和导出助手** | Weave 聊天为您设置文件导入、导入步骤或导出步骤。 | Weave 聊天无法设置这些内容。 |
| **表达式助手** | 表达式编辑器中的助手。 | 表达式编辑器没有助手。 |
| **根据描述生成 SQL** | **提取 SQL**步骤上的[使用 AI 生成 SQL](/zh-cn/guides/ai-assistant/generate-sql-extract/)。 | 该步骤没有**使用 AI 生成 SQL**部分。您仍然可以自己编写 SQL。 |
| **工作流审核摘要** | 工作流**检查**上方由 AI 撰写的摘要。 | **检查**显示其发现项，但不含摘要。 |
| **入门图表** | AI 为您拖入的文件选择第一个图表。 | 改由规则选择图表。 |

更改时已登录的用户在重新加载 PlaidCloud 之前仍会看到该功能，但 Weave 不再为其使用 AI。聊天、修复和表达式助手以及根据描述生成 SQL 都会说明这一点，例如*您的工作区管理员已关闭修复助手。*

<Aside type="note">
这些开关涵盖 PlaidCloud 提供的 AI。工作流中的 AI 步骤使用您自己的 AI 连接，您通过 [MCP](/zh-cn/integrations/ai-coding-agents/) 连接的 AI 工具使用它们自己的模型，因此两者都不受影响。
</Aside>

## 更改记录

每次开启或关闭功能都会记录在工作区的**安全日志**中，包括更改者和时间，例如*已关闭修复助手。*

## 通过 API

`GET /rest/v1/analyze/ai/features` 返回每项功能及其是否开启，格式为 `{"features": [{"feature": "chat", "on": true}, …]}`。功能名称为 `chat`、`fix`、`import_export`、`expression`、`sql_extract`、`review_summary` 和 `starter_chart`。

`PUT /rest/v1/analyze/ai/features` 配合 `{"off": ["fix"], "on": ["chat"]}` 会关闭 `off` 中的功能，并开启 `on` 中的功能。两个列表都未列出的功能保持不变，因此两位管理员更改不同功能时不会互相覆盖。它的响应与 `GET` 相同。只有工作区管理员可以调用它，不是功能的名称，或同时出现在两个列表中的名称，会被拒绝。
