## 说明

当某个数字看起来不对时，首先要问的是它从何而来、发生了什么变化。Weave 会根据项目自身的记录回答这两个问题，也不更改任何内容。

## 为何是这个数字

右键单击某个数字，然后选择 **Why this number**：

- 在**表资源管理器**中，右键单击单元格。回答会在单元格旁边打开。
- 在仪表板中，右键单击图表上的某个点或表格图表中的某个单元格。PlaidCloud 会在新选项卡中打开，并由 Weave 停靠栏在那里作答。

回答会说明：

- 哪个步骤写入该数字，以及位于哪个工作流中；
- 它来自哪里，例如 *它来自 Freight Costs，按 Headcount 拆分。* 对于分摊，会列出动因的名称；
- 该步骤上次运行的时间；
- 如果有已批准的对账读取该数字所在的表，则说明该表上次对平的时间。请参阅[上次对平的时间](#上次对平的时间)。

然后，随着 Weave 逐项算出结果，它会显示该数字的变化情况：

- **Since the run before** — 例如 *在结束于……的运行中增加了 120,100（+10.0%）*，并附有时间。
- **Since last period**，当表有期间列时显示。
- **Input and share**，适用于由分摊写入的合计：变化中有多少来自被拆分的金额，又有多少来自该数字在其中所占的份额。

在准备好之前，每一部分都会显示 *Weave is still working on this…*。**打开**链接会将您带到该步骤和该表，**Weave 如何得知**则说明每一行的来源。

- 当图表读取一个已发布的表，并对某列求合计、平均值、计数或取最小值或最大值时，图表上的点会得到完整回答。对于基于 Weave 无法追溯到单个数字的查询构建的图表，会改为提供它所读取的表。
- 与上一次运行的比较涵盖该步骤在最近 35 天内的最后两次运行，前提是该表的早先版本仍被保留。
- 如果行访问限制了您可以读取的内容，Weave 不会拆分变化。受行级安全保护的表不会与早先版本进行比较。
- **Why this number** 需要可以读取项目表的角色。

## 早先某次运行时的表

在**表资源管理器**中，工具栏中的 **As of** 列表会列出表的早先版本，最新的在前，按写入它们的操作列出：*after Month-End Close ran* 及其时间，并附有步骤；或 *changed outside a workflow run* 及其时间。选择一个版本，即可以只读方式查看表当时的样子。**当前（实时数据）** 会返回实时表。请参阅[表快照](/zh-cn/guides/data/table-snapshots/)。

### 与当前比较

查看早先版本时，单击 **Compare with now**。Weave 会说明：

- 当时和现在各有多少行；
- 有多少行发生了更改、新增或删除，以及哪些列发生了变化，例如 *此后：312 行已更改，4 行新增，无删除。Amount 在 312 行中发生了变化；Headcount 无变化。*；
- 哪些行存在差异，会在网格中标出，最多从 500 行的样本中得出。

单击 **Column shift ▸**，可比较每个数值列当时和现在的分布。

为了匹配行，Weave 需要表的键列。如果尚未设置，Weave 会予以说明，项目架构师可以单击 **Set key columns**。新步骤、联接建议和数据检查也会使用这些键列。

### 从活动和右键菜单

- 在项目的 [Weave 活动历史](/zh-cn/guides/ai-assistant/weave-activity/)中，有关表或步骤的条目带有 **See the data then**，它会在紧接该条目之后的版本处打开该表。
- 在表、工作流或步骤上，右键菜单的 **Weave** 部分有 **What changed** 和 **See it at an earlier run**。

能回溯多远取决于表的早先版本保留多长时间。受行级安全保护的表不会显示早先版本。

## 提出假设分析问题

打开分摊的输出表，然后在停靠栏中向 Weave 提出假设分析问题，例如 *如果运费上涨 8% 会怎样*。Weave 会立即给出结果将如何变化的估算，并标注 *估算：使用今天的份额；未重新运行任何内容。* 您还可以询问对动因的更改，例如将某个动因设为某个值。如果您的措辞可能有多种含义，Weave 会询问您指的是哪一种。

要保留该估算，请选择 **Keep ▾ → As a scenario**。请参阅[将估算保留为方案](/zh-cn/guides/ai-assistant/weave-requests/#将估算保留为方案)。

- Weave 会对由您可以打开的分摊步骤写入的表进行估算。
- 如果行访问隐藏了表的一部分，Weave 不会进行估算，因为合计将不完整。
- Weave 估算的是您指定的更改，而不是撤消早先的某项更改。

## 上次对平的时间

当项目架构师运行已批准的[对账](/zh-cn/guides/ai-assistant/weave-reconciliation/)时，PlaidCloud 会保留结果，并以一句话显示：

- *06:02 与 Cost Pool 对平。*
- *与 Cost Pool 未对平（上次检查时间为 06:02）。*
- 一旦任一方发生变化，会显示 *Not checked since*，表示该表 *was written at* 较晚的某个时间。

这句话会显示在“对账”窗口的 **Last result** 列中、**Why this number** 的回答中，以及[就绪清单](/zh-cn/guides/ai-assistant/weave-readiness/)上。要再次检查，请从表右键菜单的 **Weave** 部分中选择 **Run the check**。它会以您的身份运行读取该表的每个已批准对账。

只有当您可以打开对账读取的每个表，且行访问没有限制您可以读取的内容时，您才能看到保留的结果。
