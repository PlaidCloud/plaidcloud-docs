## 说明

月度摘要统计 Weave 在某个项目中一个月内所做的工作：工作流运行完成时发现的问题、后续检查不再发现的问题、经他人批准而做出的更改，以及被标记为预期的问题。每个数字都是项目 [Weave 活动历史](/zh-cn/guides/ai-assistant/weave-activity/)中条目的计数，您可以打开每个数字背后的条目。

工作区管理员还有一个工作区摘要，其中包含每个项目的相同计数。

整个过程不涉及 AI。没有任何估算：没有可报告内容的月份会如实说明。

## 打开月度摘要

1. 打开项目，选择 **Weave** 选项卡，然后在其中选择**发现项**。
2. 点击工具栏上的**摘要**。
3. 选择一个月份。列表从当前月份开始，显示为例如 **October 2026 so far**，之后是此前的十一个月。

工具栏上的**刷新**会重新读取摘要。与**活动**一样，其角色可以读取项目的步骤、工作流和表的任何人都能看到**摘要**。月份为 UTC 日历月。

## 每个数字统计什么

每个数字旁边都有一句话，说明它统计的内容。摘要只显示数字及其说明；下表第一列中的名称仅供本页使用。

| 数字 | 说明 |
|---|---|
| 发现的问题 | *Weave 在工作流运行完成时发现了 7 个问题。无论被发现多少次，每个只计一次。* |
| 不再发现 | *后续检查在本月不再发现 5 个问题，包括在更早月份首次发现的问题。* |
| Weave 更改后不再发现 | *其中有 2 个问题，在 Weave 经批准对其所涉及的步骤、表或工作流（对于工作流，指其任一步骤）做出更改后不再被发现。这表示事件的先后顺序，并不表示该更改解决了问题。从 Weave 发现问题（或在问题消失后再次发现它）到检查不再发现它的时间中位数：26 小时，涉及 2 个问题。* |
| 所做的更改 | *Weave 做出了 3 项经他人批准的更改。其中 1 项此后已被撤销。* |
| 已标记为预期 | *1 个问题被标记为预期。它并未被修复：Weave 不再将其报告为问题。* |
| 本月问题的当前状况 | *本月发现的 7 个问题中：3 个不再发现，1 个已标记为预期，3 个仍未解决。* |

只有当后续检查在该月不再发现至少一个问题时，才会显示**Weave 更改后不再发现**。只有当 Weave 在该月发现了至少一个问题时，才会显示**本月问题的当前状况**。

点击数字下方的**显示 3 个条目**（只有一个时为**显示条目**），可列出它所统计的活动历史条目及其各自的记录时间，点击**隐藏条目**可将其折叠。背后没有条目的数字没有该按钮。对于本月问题的当前状况，条目按**不再发现**、**已标记为预期**和**仍未解决**分组，每组都带有其计数。

### 数字如何得出

- **发现的问题**统计 Weave 在该月提出的每个问题，每个只计一次，并列出它首次被提出的时间。Weave 在首次发现问题时提出，而不是在每次再次发现它的运行中提出，因此从更早月份延续至今仍未解决的问题不计入，在当月内消失后又重现的问题只计一次。
- **不再发现**统计后续检查在该月内不再发现的每个问题，包括在更早月份首次发现的问题。“不再发现”并不等于已修复：数据可能已经发生变化，使该问题不再显现。请参阅[它记录什么](/zh-cn/guides/ai-assistant/weave-activity/#记录的内容)。
- **Weave 更改后不再发现**统计**不再发现**中的这样一些问题：在 Weave 发现该问题到检查不再发现它之间，Weave 对该问题所涉及的步骤或表，或者（对于涉及工作流的问题）对该工作流中的任一步骤做出了经批准的更改，并且该更改在检查之前没有被撤销。该更改可能出于其他原因而做出，也可以是任何经批准的操作，例如重新运行该步骤：这只描述事件的先后顺序。时间中位数从 Weave 发现问题时起算（即使是在更早的月份），到检查不再发现它为止。对于此前消失后又重现的问题，则从 Weave 再次发现它时起算。
- **所做的更改**统计 Weave 在 AI 助手中经他人批准而执行的每项操作，例如步骤修复、随后的重新运行、新建工作流、表复制等，而不仅仅是对现有设置的编辑。撤销更改本身不算作一项更改；说明中会写明当月的更改中，截至目前（不限时间）有多少已被撤销。您自己做出的更改，以及通过 MCP 连接的 AI 助手所做的更改不会被记录，因此不会被统计。
- **已标记为预期**统计当月有人标记为预期的每个问题。请参阅[将发现项标记为预期](/zh-cn/guides/ai-assistant/weave-tab/#将发现项标记为预期)。
- **本月问题的当前状况**取该月发现的问题，包括在更早月份消失后又重现的问题，并说明每个问题目前的状况。不再发现的问题即使也被标记为预期，仍计入此处；被标记为预期之后又不再被视为预期的问题，计为仍未解决。只有以项目架构师身份运行的检查才会关闭某个问题，因此在其他人运行之后被修复的问题仍可能显示为未解决；请参阅[发现项在运行结束时记录](/zh-cn/guides/ai-assistant/weave-activity/#发现项在运行结束时记录)。

### 不统计什么

摘要只统计活动历史所记录的内容：工作流运行完成时发现的问题，以及通过 Weave 做出的更改。它不统计在报表读取数据之前就被拦截的问题、您接受的草稿和默认值，也不统计节省的时间。Weave 仅在两次运行之间发现的问题（例如未按计划写入的表）不会记录在历史中，因此不统计；Weave 不检查的运行同样不统计，请参阅[历史不记录什么](/zh-cn/guides/ai-assistant/weave-activity/#历史不记录的内容)。

<Aside type="caution">
Weave 只报告其检查所发现的内容。没有发现问题的月份，并不意味着一切正常。
</Aside>

### 没有可报告内容的月份

当该月没有可统计的内容时，摘要会如实说明，而不是显示零，例如 *There's nothing to count for "Cost Model" in September 2026.* 单独的撤销操作或对发现项的评论不计入。

## 您看到的内容取决于您的访问权限

关于您的角色无法打开的步骤、表或工作流的条目，或已不存在的条目，不会计入任何数字，并且会有一条备注说明有多少条目被省略。在行级安全限制了您在项目中可读取的行时，摘要还会省去 Weave 根据表的大小和内容注意到的情况，并对此加以说明。

## 工作区摘要

工作区管理员可以在一个页面上看到每个项目的数字。

1. 点击页眉中的 **Weave** 按钮。
2. 选择其菜单靠近末尾处的**工作区摘要…**。
3. 像在项目摘要中一样选择一个月份。

该窗口列出当月有活动的每个项目，包含**发现的问题**、**不再发现**、**Weave 更改后不再发现**、**所做的更改**和**已标记为预期**，以及带有合计数的**所有项目**一行。它只显示计数。点击项目名称，可打开该项目在同一月份的自有摘要及每个数字背后的条目；这需要有该项目的访问权限。此后已被删除的项目会列为 *A project that no longer exists*，且无法打开。

工作区计数包含每个项目历史中的所有条目。项目自己的摘要会省去其读者无法打开的内容，因此它显示的数字可能比工作区摘要更低。

**工作区摘要…** 仅对工作区管理员显示。其他任何人通过 API 请求工作区摘要时，会被告知 *Only workspace administrators can see the workspace summary. Each project's own summary is on its Weave tab.*

## 通过 API

`GET /rest/v1/analyze/weave/monthly` 返回项目的摘要，需提供 `project_id` 和可选的 `month`，格式为 `YYYY-MM`（省略时为当前月份）。`GET /rest/v1/analyze/weave/monthly/workspace` 返回工作区摘要，使用相同的可选 `month`。格式错误的月份，或尚未开始的月份，会被拒绝。
