## 说明

在步骤上按下**保存**时，PlaidCloud 会检查其设置，并拒绝无法运行的设置，例如无法编译的表达式，或以其类型不允许的方式使用的列。编辑步骤时，Weave 现在会随着您的操作运行其中大部分检查，并在**保存**按钮上方的提示条中显示保存会拒绝的内容：

> 1 个问题，保存时将被拒绝。

每个问题都列在该行下方。当问题指向**表数据选择**选项卡中的某一行时，**转到**会打开该选项卡并选中该行。

这些检查只读取步骤的设置和项目的变量，因此速度很快，也不涉及 AI。它们从不阻止保存：“保存”始终可用，按下时会自行运行所有检查。

<Aside type="note">
“保存”还会检查此提示条没有涵盖的一些内容，例如源表和目标表是否包含步骤所用的列，以及必填字段是否已填写。因此，“未发现问题”表示编辑时运行的检查没有发现问题，并不表示“保存”一定会接受该步骤。
</Aside>

## 提示条的内容

| Weave 显示 | 含义 |
| --- | --- |
| 正在检查此步骤是否有问题… | Weave 正在对您最近的更改运行检查。 |
| 1 个问题，保存时将被拒绝。 | 按当前状态，“保存”会拒绝该步骤。每个问题列在其下方。 |
| 未发现问题。“保存”还会检查更多内容，例如源表和目标表。 | 编辑时运行的检查没有发现问题。“保存”仍会运行自己的检查，包括此提示条跳过的一些检查。 |
| Weave 无法检查此步骤的表达式。… | 步骤的一部分无法检查，原因随后给出。这绝不等于通过。 |
| Weave 暂时无法检查此步骤。“保存”仍会检查。 | 检查未能运行，例如因为服务器繁忙。您的下一次更改会再次发起检查。 |

### 表达式无法检查的原因

| 原因 | 含义 |
| --- | --- |
| 此步骤不在工作流中，因此无法检查其表达式。“保存”也不会检查它们。 | 表达式可以使用工作流变量，因此会在步骤所在的工作流中检查。在任何工作流之外打开的步骤不会被检查，此处和“保存”均如此。 |
| 其中一些表达式位于 Weave 尚无法检查的设置中。 | 步骤将某些表达式保存在这些检查不读取的设置中，例如第二个源的筛选器。其余表达式仍会被检查。 |
| 其列设置是 Weave 尚无法检查的类型。 | 步骤列出列的方式让检查无法编译，多表联接就是如此。 |

如果表达式使用了工作流和项目都未定义的变量，这属于问题，而不是无法检查的原因：“表达式使用了变量 rate，但该变量未在此工作流或项目中定义。”如果存在不属于任何变量名的大括号，例如输入了一半的变量，也同样属于问题：“表达式中有一个大括号不属于变量名。”“保存”会以相同的措辞拒绝这两种情况。

## 在表达式编辑器中

从**表数据选择**选项卡的**表达式**单元格，或从**数据筛选器**选项卡上的**选择数据子集**或**对结果数据应用二级筛选器**打开**表达式编辑器**，编辑器下方会有一行在您输入时检查表达式：

| 编辑器显示 | 含义 |
| --- | --- |
| 正在检查… | Weave 正在检查您刚输入的内容。 |
| 未发现错误。 | 表达式可按“保存”的编译方式通过编译。将鼠标指向该行可查看未涵盖的内容：Weave 检查语法和列名，有些错误只有在步骤运行时才会出现。 |
| 错误：… | “保存”会拒绝该表达式，原因随后给出。语法错误还会标记在其所在行的行号旁边。 |
| 无法检查。… | 由于上述某个原因，无法检查该表达式。 |
| 暂时无法检查。保存步骤时仍会检查。 | 检查未能运行。在步骤上按下**保存**仍会检查该表达式。 |

编辑器依据 Weave 上次检查该步骤时的步骤设置，并代入您的表达式进行检查。如果从其他位置打开，例如表资源管理器，则不显示该行。

## 何时出现

- 在您可以更改的步骤上进行编辑时。对于您的角色而言以只读方式打开的步骤，在编辑时不会被检查。
- 每次更改之后，在您停顿时检查。若更改后设置与之前相同，则不会再次检查。
- 它读取步骤的设置和项目的变量，因此不会产生 AI 调用，也从不查询您的仓库。
