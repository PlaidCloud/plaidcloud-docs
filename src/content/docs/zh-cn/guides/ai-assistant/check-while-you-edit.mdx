## 描述

在步骤上单击**保存**时，PlaidCloud 会检查其设置，并拒绝无法运行的设置，例如无法编译的表达式，或以其类型不允许的方式使用的列。现在，编辑步骤时，Weave 会在您操作的同时运行其中大部分检查，并在**保存**按钮上方的提示条中显示保存会拒绝的内容：

> 1 个问题，保存将被拒绝。

每个问题都列在这一行下方。如果问题指向**列**选项卡上的某一行，**转到**会打开该选项卡并选中该行。

这些检查只读取步骤的设置和项目的变量，因此速度很快，也不涉及 AI。它们从不阻止保存：保存始终可用，并且在您单击保存时会自行运行所有检查。

<Aside type="note">
保存还会检查此提示条不涉及的一些内容，例如源表和目标表是否包含步骤所用的列，以及必填字段是否已填写。因此，“未发现问题”表示编辑时运行的检查都没有发现问题，并不表示保存一定会接受该步骤。
</Aside>

## 提示条显示的内容

| Weave 显示 | 含义 |
| --- | --- |
| 正在检查此步骤是否有问题… | Weave 正在对您的最新更改运行检查。 |
| 1 个问题，保存将被拒绝。 | 保存会按当前状态拒绝该步骤。每个问题列在其下方。 |
| 未发现问题。保存还会检查另外一些内容，例如源表和目标表。 | 编辑时运行的检查没有发现任何问题。保存仍会运行自己的检查，其中包括此提示条跳过的一些检查。 |
| Weave 无法检查此步骤的表达式。… | 步骤的一部分无法检查，后面会说明原因。这绝不表示通过。 |
| Weave 刚才无法检查此步骤。保存时仍会检查。 | 检查未运行，例如因为服务器繁忙。您的下一次更改会再次发起检查。 |

### 表达式无法检查的原因

| 原因 | 含义 |
| --- | --- |
| 此步骤不在工作流中，因此无法检查其表达式。保存时也不会检查。 | 表达式可以使用工作流变量，所以要在步骤所在的工作流中检查。在任何工作流之外打开的步骤既不会在这里检查，也不会在保存时检查。 |
| 部分表达式位于 Weave 尚无法检查的设置中。 | 步骤会把一些表达式保存在这些检查不读取的设置中，例如第二个源的筛选器。其余表达式仍会检查。 |
| 其列设置是 Weave 尚无法检查的类型。 | 步骤以检查无法编译的方式列出其列，例如多表联接。 |

如果表达式使用了工作流和项目都没有定义的变量，这属于问题，而不是无法检查的原因：“表达式使用了变量 rate，但该变量未在此工作流或项目中定义。”同样，如果有一个大括号既不是变量名的开头也不是结尾（例如输入到一半的变量），也属于问题：“表达式中有一个大括号不属于变量名。”保存会用相同的语句拒绝这两种情况。

## 在表达式编辑器中

从**列**选项卡上的**表达式**单元格，或从**筛选器**选项卡上的**选择数据子集**或**对结果数据应用二级筛选器**打开**表达式编辑器**，编辑器下方会有一行在您输入时检查表达式：

| 编辑器显示 | 含义 |
| --- | --- |
| 正在检查… | Weave 正在检查您刚输入的内容。 |
| 未发现错误。 | 表达式可以按保存的编译方式通过编译。将鼠标指向该行可查看此检查未涵盖的内容：Weave 检查语法和列名，有些错误只有在步骤运行时才会出现。 |
| 错误：… | 保存会因所给出的原因拒绝该表达式。语法错误还会在其所在行的行号旁标出。 |
| 无法检查。… | 由于上述某个原因，无法检查该表达式。 |
| 刚才无法检查。保存步骤时仍会检查。 | 检查未运行。在步骤上单击**保存**时仍会检查该表达式。 |

编辑器按 Weave 上次检查该步骤时的步骤设置，并代入您的表达式进行检查。如果从其他位置（例如表资源管理器）打开，则不显示这一行。

## 何时出现

- 在您编辑可更改的步骤时。对于按您的角色以只读方式打开的步骤，编辑时不会进行检查。
- 每次更改后，在您暂停时进行。如果某次更改没有改变设置，则不会再次检查。
- 它读取步骤的设置和项目的变量，因此从不产生 AI 调用，也从不查询您的 Warehouse。
