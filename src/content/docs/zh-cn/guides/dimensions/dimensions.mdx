PlaidCloud 中的维度是**层次结构**，即用于组织成本中心、产品、科目、地区或期间等内容的树形结构。它们是分摊、仪表板和报表用来切分和汇总数据的基础框架。

维度所能承载的不止父子关系。每个节点都可以保存属性、别名和值，因此成本中心层次结构还可以告诉您每个中心使用哪种货币报告、在备用视图中归属于哪个业务单元，以及其运营预算是多少。

维度在每个项目内的**维度**选项卡中管理。

## 主层次结构

每个维度都有一个**主**层次结构。主层次结构定义叶成员的完整集合，维度中任何位置的每个叶节点都必须出现在这里。

可以将主层次结构视为规范的、唯一真实的树。维度中的任何内容都是主层次结构的成员，问题只在于它位于树中的*何处*。

## 备用（属性）层次结构

备用层次结构是主层次结构中叶节点的不同视图。它们可以选取叶节点的子集，以不同的方式对其分组，或使用完全不同的汇总方式。

两种常见模式：

- **子集视图**：将一组特定的叶节点拉入一个专注的树中，用于特定的报表或分摊。备用层次结构会从主层次结构继承其成员的任何更改。
- **不同的汇总**：叶节点相同，父节点不同。例如：主层次结构按部门组织成本中心，而备用层次结构按地区组织同样的成本中心。

## 管理维度

<Aside type="caution">
**决定谁能看到哪些行的维度只能由项目架构师更改**。在通过[行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#维度授权)限制行的项目上，受限列取值所依据的维度只能由项目架构师、租户管理员或项目自身的工作流更改，包括添加、移动、重命名、复制、清除、加载或还原其节点，以及创建、复制、重命名或删除维度本身。其他人会被告知应联系谁。其他维度，以及不限制行的项目上的每个维度，均按下文所述工作。
</Aside>

### 创建

在工具栏的**新建**按钮中选择**新建维度**。输入名称、目录（用于文件夹式组织）和说明性备注。

点击**创建**，维度即可立即使用。也可以在工作流中使用 [Dimension Create 步骤](/zh-cn/reference/workflow-steps/dimensions/dimension-create/)来创建。

### 创建分摊维度

**分摊维度**（也称为**分配维度**）是一种特殊维度，[分摊](/zh-cn/guides/allocations/setup/configure-an-allocation/)步骤会读取它，以决定如何将每条源记录分摊到各个目标。无需逐个节点构建，可使用引导式构建器一次性创建起始维度。

如果您的工作区已启用该功能且您拥有创建维度的权限，请打开**新建**菜单并选择**新建分摊维度**（带有拆分图标标记）。构建器会在四个步骤中的第一步打开：

1. **名称和表**：为维度命名，然后选择其规则所筛选的行所在的**源（值）表**，以及用于分摊金额的**驱动因素表**。
2. **规则筛选器**：勾选充当规则筛选器的源列。已有维度关系的列按原样使用；对于没有维度关系的列，可以附加一个维度，使其值解析为成员。
3. **驱动因素和目标**：在驱动因素表上指定**驱动因素名称**列和**驱动因素值**列，并勾选金额所分摊到的**目标列**。
4. **规则**：填写一个扁平的规则网格。每条规则由一组源筛选值，加上用于该组合的指定驱动因素组成。

点击**完成**，PlaidCloud 会一步创建整个维度。它会出现在维度树中并带有**拆分图标**徽章，表明它是分摊维度而不是普通层次结构。

该维度独立于任何分摊而创建，因此一个分摊维度可以服务多个步骤。要使用它，请将分摊步骤指向它，请参阅[配置分摊](/zh-cn/guides/allocations/setup/configure-an-allocation/)。

### 删除

选择维度，打开**操作**菜单，然后选择**删除维度**。这会移除维度及其所有底层数据。

也可以在工作流中使用 [Dimension Delete 步骤](/zh-cn/reference/workflow-steps/dimensions/dimension-delete/)来删除。

如果想保留维度但重置其内容（清除所有结构、值、别名、属性和备用层次结构），请使用 [Dimension Clear 步骤](/zh-cn/reference/workflow-steps/dimensions/dimension-clear/)，而不是删除。

### 复制

选择维度，打开**操作**，然后选择**复制维度**。为副本指定名称，然后点击**创建副本**。副本包含值、别名、属性和所有备用层次结构。

### 排序

维度管理区域可让您上下移动成员并直接更改父节点。对于大型层次结构，手动操作会很繁琐，请使用 [Dimension Sort 步骤](/zh-cn/reference/workflow-steps/dimensions/dimension-sort/)以编程方式排序。在数据加载或重大重组之后，它能节省大量时间。

## 加载维度

加载维度是指将表格形式的源数据转换为层次结构。PlaidCloud 支持两种数据形态用于加载：

- **父子**：两列，一列为父节点，一列为子节点。每行定义树中的一条边。适用于任意深度、不规则的层次结构。
- **级别**：每个级别一列。逐行，每一列给出该级别的父节点。最适合深度可预测的规则层次结构（例如国家 → 地区 → 城市）。

加载还可以在结构之外同时携带值、别名和属性。有关完整选项，请参阅 [Dimension Load 步骤](/zh-cn/reference/workflow-steps/dimensions/dimension-load/)。

## 节点属性

在层次结构工具栏上切换**属性**，可为维度上定义的每个属性显示一列，例如成本中心的货币、科目的业务单元、产品的类别。

### 添加或编辑属性

1. 点击工具栏上的**新建属性**
2. 在**属性配置**窗口中，输入**属性名称**，选择**属性显示**（**文本**或**标签**），并选择**编辑器类型**，即属性用于数据输入的控件，包括**选择（维度）**、**选择（固定）**、**选择（表）**、**复选框**、**微调框**、**日期选择器**和**数值**
3. 如果编辑器类型需要进一步设置，会出现一个**配置**部分，其中有**编辑配置**按钮
4. 点击**创建**（编辑时为**更新**）进行保存

要更改现有属性的设置，请选择其列，然后从工具栏中选择**编辑属性配置**。**删除属性**会完全移除一个属性；**清除属性**会清除所选条目，**清除属性的所有条目**会在每个节点上清除它。

### 维度类型属性和成员选择器

将属性的**编辑器类型**设置为**选择（维度）**，会将其变为对另一个维度（或同一维度）的层次结构的查找，例如指向地理维度的成本中心“区域”属性。点击**编辑配置**会打开**维度配置**窗口：

- **维度**和**层次结构**：属性从中选取成员的维度和层次结构。在“层次结构”上选择**未指定**，可让选择器显示维度中的每个层次结构。
- **起始节点（可选）**：将选择器限制在某个子树而不是整个层次结构。
- **允许多选**：让单个属性值可以包含多个成员。默认启用；取消勾选可将属性限制为单个成员。
- **特殊情况**：除层次结构的实际成员外，还提供额外的可选条目 **源**和**当前**。

**保存**要求选择维度。层次结构可以保持为**未指定**，这是一种选择，而不是空白。

按此方式配置属性后，在网格中双击其某个单元格即可打开成员选择器，对于[数据编辑器](/zh-cn/guides/projects/managing-data-editors/)网格中映射到维度的列，也会出现同样的树状选择器。无论单元格是否已有值，首次双击就会打开它。

- **全部展开** / **全部折叠**：展开或折叠树的每个分支。
- 点击一个成员（开启“允许多选”时可点击多个成员）即可选中。
- **应用**将属性设置为您当前的选择。
- **清除**移除属性的当前值。
- **取消**关闭选择器，不做任何更改。

<Aside type="note">如果打开选择器时在网格中选中了多行，**应用**会为所有选中的行设置该值，而不仅仅是您双击的那一行，这样设计是为了一次编辑多行。</Aside>

## 维度属性继承

可以将维度配置为让子节点从其祖先继承属性值。要启用此功能，请点击**属性**旁边的下拉菜单，然后选择**继承的属性**。

关于继承行为的说明：

- 继承适用于维度中的**所有**属性，不能只为某一个属性启用而不为其他属性启用。
- 如果在子节点上设置了属性，之后又删除该值，子节点会还原为其父节点的值。当父节点有值时，子节点的属性不能为空。
- 在节点上设置属性会向下传播到其后代，覆盖它们继承的值，直到它们被显式设置。
- 继承会沿树一直向下到叶节点。

## 在层次结构中查找节点

大型维度可能包含数千个成员，因此层次结构窗口提供了两种缩小网格显示范围的方法。两种方法都会隐藏不匹配的节点，而不仅仅是高亮显示，并且都会保留匹配节点的祖先，以便您仍能看到它在树中的位置。

### 筛选框

主窗格底部的**筛选器**框会在您输入时进行筛选。按 **/** 或 Ctrl/Cmd+F 可跳转到该框。它对文本的任何部分进行匹配并忽略大小写，搜索范围包括：

- 节点在层次结构中的名称，以及
- 您当前显示的每个**备用项**、**别名**、**属性**和**值**列。

由于它只搜索屏幕上的列，**视图**菜单中的列选择也同时决定了搜索范围：打开**属性**可通过某个属性中保存的科目代码查找节点，再将其关闭则只搜索名称。以标签形式显示的属性会按任意单个标签进行匹配。

框旁边的 **主 | 两者 | 备用** 开关用于选择筛选器应用于哪棵树。备用窗格隐藏时，它也会隐藏；可通过**视图**菜单中的**显示备用层次结构**显示该窗格。漏斗按钮会清除筛选并恢复完整的树。

<Aside type="note">筛选器框搜索的是每个节点上存储的值。开启**继承的属性**后，显示从祖先继承的值的节点不会按该值匹配，只有实际设置了该值的祖先才会匹配。</Aside>

### 高级筛选器

筛选器框同时搜索所有显示的列，而层次结构工具栏上的**高级**则按列构建精确的条件。它会打开**配置高级维度筛选器**窗口，其中每一行是一个条件：

1. 点击**添加行**
2. 选择一个**列**，可以是维度上的任何属性或聚合列
3. 选择一个**条件**。属性保存文本，因此提供 `=`、`!=` 和 `contains`；聚合保存数字，因此提供 `=`、`!=`、`<`、`>`、`<=` 和 `>=`
4. 可以输入一个要比较的**值**，也可以在**比较对象**下选择另一列，让两列相互比较，二者选其一，不能同时使用 **。比较对象**列出保存相同类型值的其他列，因为拿数字与文本比较，结果无论如何都没有意义
5. 点击**更新**应用

**删除行**会移除所选行，**清除**会清空整个列表。添加多行可进一步缩小范围：节点必须满足每一行，并且也要满足筛选器框中的文本。在每一行都完整之前，**更新**保持禁用，因此未完成的条件绝不会悄悄改变您所看到的内容。

高级条件适用于主层次结构。筛选器框仍然适用于其旁边按钮所选择的窗格。

文本条件与筛选器框一样忽略大小写。`=` 匹配整个值，因此要查找位于较长属性值中的代码，或多标签属性的某个标签中的代码，请使用 `contains`。
