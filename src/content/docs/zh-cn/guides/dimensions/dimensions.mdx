PlaidCloud 中的维度是**层次结构**，即用于组织成本中心、产品、科目、地理区域或时间期间等内容的树状结构。它们是分摊、仪表板和报表用来切片和聚合数据的骨架。

维度承载的不只是父子关系。每个节点都可以保存属性、别名和值，因此成本中心层次结构还能告诉您每个中心使用哪种货币报告、在备用视图中归属于哪个业务单元，以及其运营预算是多少。

维度在每个项目的**维度**选项卡中管理。

## 主层次结构

每个维度都有一个**主**层次结构。主层次结构定义了叶子成员的完整集合：维度中任何位置的每个叶子节点都必须出现在其中。

可以把主层次结构看作规范的、唯一真实的树。维度中的任何内容都是主层次结构的成员，问题只在于它位于树中的*哪个位置*。

## 备用（属性）层次结构

备用层次结构是主层次结构中叶子的不同视图。它们可以选取叶子的子集、以不同方式对其分组，或使用完全不同的汇总方式。

两种常见模式：

- **子集视图**：将特定的一组叶子拉入一棵聚焦的树，用于特定的报表或分摊。备用层次结构会从主层次结构继承其成员的任何更改。
- **不同的汇总**：叶子相同，父级不同。例如，主层次结构按部门组织成本中心，而备用层次结构按地理区域组织同样的成本中心。

## 管理维度

<Aside type="caution">
**决定谁能看到哪些行的维度只能由项目架构师更改。** 在通过[行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#维度授权)限制行的项目中，受限列从中取值的维度只能由项目架构师、租户管理员或项目自己的工作流更改，包括添加、移动、重命名、复制、清除、加载或还原其节点，以及创建、复制、重命名或删除维度本身。其他人会被告知应向谁求助。其他维度，以及未限制任何行的项目中的所有维度，均按下文所述工作。
</Aside>

### 创建

在工具栏中点击**新建**按钮，选择**新建维度**。输入名称、目录（用于文件夹式组织）和说明备注。

点击**创建**，维度即可立即使用。您也可以通过工作流使用 [Dimension Create](/zh-cn/reference/workflow-steps/dimensions/dimension-create/) 步骤来创建。

### 创建分配维度

**分摊维度**（也称为**分配维度**）是一种特殊维度，[分摊](/zh-cn/guides/allocations/setup/configure-an-allocation/)步骤会读取它，以确定每条源记录如何分散到各个目标。无需逐个节点构建，可以使用引导式构建器一次性创建起始维度。

如果您的工作区已启用此功能，并且您有创建维度的权限，请打开**新建**菜单并选择**新建分摊维度**（带有拆分图标）。构建器会打开四个步骤中的第一步：

1. **名称和表**：为维度命名，然后选择规则要筛选其行的**源（值）表**，以及用于分摊金额的**驱动因素表**。
2. **规则筛选器**：勾选作为规则筛选器的源列。已具有维度关系的列会按原样采用；对于没有维度关系的列，可以附加维度，使其值解析为成员。
3. **驱动因素和目标**：在驱动因素表上指定**驱动因素名称**列和**驱动因素值**列，并勾选金额要分摊到的**目标列**。
4. **规则**：填写一个扁平的规则网格。每条规则由一组源筛选值，加上用于该组合的指定驱动因素构成。

点击**完成**，PlaidCloud 会一次性创建整个维度。它会出现在维度树中，并带有**拆分图标**徽章，表明它是分摊维度而非普通层次结构。

维度的创建独立于任何分摊，因此一个分摊维度可以为多个步骤服务。要使用它，请让分摊步骤指向它，参见[配置分摊](/zh-cn/guides/allocations/setup/configure-an-allocation/)。

### 删除

选择维度，打开**操作**菜单，然后选择**删除维度**。这会移除该维度及所有底层数据。

您也可以通过工作流使用 [Dimension Delete](/zh-cn/reference/workflow-steps/dimensions/dimension-delete/) 步骤来删除。

如果想保留维度但重置其内容（清除所有结构、值、别名、属性和备用层次结构），请使用 [Dimension Clear](/zh-cn/reference/workflow-steps/dimensions/dimension-clear/) 步骤，而不是删除。

### 复制

选择维度，打开**操作**，然后选择**复制维度**。为副本指定名称并点击**创建副本**。副本包含值、别名、属性以及所有备用层次结构。

### 排序

维度管理区域允许您上下移动成员并直接更改父级。对于大型层次结构，手动执行这些操作会很繁琐，请使用 [Dimension Sort](/zh-cn/reference/workflow-steps/dimensions/dimension-sort/) 工作流步骤以编程方式排序。在数据加载或重大重构之后，这能节省大量时间。

## 加载维度

加载维度意味着将表格形式的源数据转换为层次结构。PlaidCloud 支持两种数据形式的加载：

- **父子**：两列，一列为父级，一列为子级。每行定义树中的一条边。适用于任意深度的不规则层次结构。
- **级别**：每个级别一列。逐行看，每一列给出该级别的父级。最适合深度可预测的规则层次结构（例如 国家 → 区域 → 城市）。

加载时还可以在结构之外一并携带值、别名和属性。完整的选项集请参阅 [Dimension Load](/zh-cn/reference/workflow-steps/dimensions/dimension-load/) 工作流步骤。

## 节点属性

在层次结构工具栏中切换**属性**，即可为维度上定义的每个属性显示一列，例如成本中心的货币、科目的业务单元、产品的类别。

### 添加或编辑属性

1. 点击工具栏上的**新建属性**
2. 在**属性配置**窗口中，输入**属性名称**，选择**属性显示**（**文本**或**标签**），并选取**编辑器类型**，即属性用于数据输入的控件，包括**选择（维度）**、**选择（固定）**、**选择（表）**、**复选框**、**微调框**、**日期选择器**和**数值**
3. 如果编辑器类型需要进一步设置，会出现带有**编辑配置**按钮的**配置**部分
4. 点击**创建**（编辑时为**更新**）进行保存

要更改现有属性的设置，请选择其列并从工具栏中选择**编辑属性配置**。**删除属性**会彻底移除属性；**清除属性**会清除所选条目，**清除属性的所有条目**会在每个节点上清除该属性。

### 维度类型属性和成员选取器

将属性的**编辑器类型**设为**选择（维度）**，会使其变成对另一个维度的层次结构（或同一维度的层次结构）的查找，例如成本中心的“区域”属性指向地理维度。点击**编辑配置**会打开**维度配置**窗口：

- **维度**和**层次结构**：属性从中选取成员的维度和层次结构。在层次结构上选择**未指定**，可让选取器显示维度中的每个层次结构。
- **起始节点（可选）**：将选取器限制在某个子树，而不是整个层次结构。
- **允许多选**：允许单个属性值保存多个成员。默认启用；取消勾选可将属性限制为单个成员。
- **特殊情况**：提供**源**和**当前**，它们是层次结构的实际成员之外的额外可选条目。

**保存**要求选择维度。层次结构可以保持**未指定**，这是一种选择，而不是空白。

属性以这种方式配置后，双击网格中它的某个单元格即可打开成员选取器；同样的树式选取器也会出现在[数据编辑器](/zh-cn/guides/projects/managing-data-editors/)网格中映射到维度的列上。无论单元格是否已有值，它都会在第一次双击时打开。

- **全部展开** / **全部折叠**：展开或折叠树的每个分支。
- 点击一个成员（或在启用允许多选时点击多个成员）进行选择。
- **应用**会将属性设置为您当前的选择。
- **清除**会移除属性的当前值。
- **取消**会关闭选取器且不做任何更改。

<Aside type="note">如果打开选取器时网格中选中了多行，**应用**会在所有选中的行上设置该值，而不仅仅是您双击的那一行，这是为一次编辑多行而设计的。</Aside>

## 维度属性继承

可以将维度配置为让子级从其祖先继承属性值。要启用此功能，请点击**属性**旁边的下拉菜单并选择**继承的属性**。

有关继承行为的说明：

- 继承适用于维度中的**所有**属性，不能只对某个属性启用而对其他属性不启用。
- 如果您在子级上设置了属性，之后又删除了该值，子级会恢复为其父级的值。当父级有值时，子级不能有空属性。
- 在节点上设置属性会向下传播到其后代，覆盖它们继承的值，直到它们被显式设置。
- 继承会沿着树一直向下到叶子节点。

## 在层次结构中查找节点

大型维度可能包含数千个成员，因此层次结构窗口提供了两种缩小网格显示范围的方式。两种方式都会隐藏不匹配的节点，而不仅仅是高亮显示，并且都会让匹配节点的祖先保持在屏幕上，以便您仍能看到它在树中的位置。

### 筛选器框

窗口底部的**筛选器：** 框会在您输入时进行筛选。它匹配文本的任意部分并忽略大小写，搜索范围包括：

- 节点在层次结构中的名称，以及
- 您当前显示的每个**备用项**、**别名**、**属性**和**值**列。

由于它只搜索屏幕上的列，工具栏上的切换开关同时也决定了搜索范围：打开**属性**可通过某个属性中保存的科目代码查找节点，再次关闭则仅搜索名称。以标签形式显示的属性会匹配任意单个标签。

框旁边的按钮用于选择筛选器应用于哪个窗格：**两者**、**主层次结构**或**备用层次结构**。漏斗按钮会清除筛选器并恢复完整的树。

<Aside type="note">筛选器框搜索的是每个节点上存储的值。启用**继承的属性**后，显示从祖先继承的值的节点不会被该值匹配，只有真正设置了该值的祖先才会匹配。</Aside>

### 高级筛选器

筛选器框同时搜索所有显示的列，而层次结构工具栏上的**高级**则可构建精确的、按列的条件。它会打开**配置高级维度筛选器**窗口，其中每一行是一个条件：

1. 点击**添加行**
2. 选取一个**列**，可以是维度上的任何属性或聚合列
3. 选取一个**条件**。属性保存文本，因此提供 `=`、`!=` 和 `contains`；聚合保存数字，因此提供 `=`、`!=`、`<`、`>`、`<=` 和 `>=`
4. 可以输入要比较的**值**，也可以在**比较对象**下选择另一列，让两列相互比较，二者择一，不能同时使用。**比较对象**会列出保存相同种类值的其他列，因为将数字与文本比较，无论哪种结果都没有意义
5. 点击**更新**应用

**删除行**会移除所选行，**清除**会清空整个列表。添加多行可进一步缩小范围：节点必须满足每一行，也必须满足筛选器框中的文本。在每一行都完整之前，**更新**保持禁用状态，因此未完成的条件不会悄悄改变您看到的内容。

高级条件应用于主层次结构。筛选器框仍应用于其旁边按钮所选择的窗格。

文本条件与筛选器框一样忽略大小写。`=` 匹配整个值，因此要查找位于较长属性值内部、或多标签属性的某个标签中的代码，请使用 `contains`。
