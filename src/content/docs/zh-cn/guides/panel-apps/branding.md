Panel 应用属于某个项目。项目为应用做两件事：应用默认从项目中读取表，同时项目保存应用所使用的颜色和徽标。只需设置一次品牌，项目中的每个应用都会采用。

## 为项目设置品牌

1. 打开项目，进入其 **主页** 选项卡。
2. 在 **Panel App Branding** 组中，单击 **Edit Branding**。
3. 设置任意颜色。单击色板可选取颜色，也可以输入十六进制值，例如 `#0078d4`。
4. 可选择一个徽标。
5. 查看 **预览**，然后单击 **保存**。

只有管理者和架构师可以保存品牌设置。其他项目成员看到的是只读表单。

**Reset to default** 会清除所有颜色和徽标。保存会替换整个品牌，因此留空的颜色会恢复为 PlaidCloud 默认值。

### 颜色

| 设置 | 着色对象 |
|---|---|
| **Brand** | 按钮、活动选项卡、滑块手柄和其他主要控件。 |
| **Brand accent** | 次要强调色。 |
| **Brand hover** | 指针悬停时的主要控件。 |
| **Brand pressed** | 按下时的主要控件。 |
| **Header background** | 应用页眉栏。 |
| **Header text** | 页眉中的标题和用户名。 |
| **Link** | 链接。 |
| **Text on brand** | 位于品牌色控件上的文字。 |

只有这八项设置。颜色必须是 3 位或 6 位十六进制值。表面、正文文字和边框在浅色和深色下都保持 PlaidCloud 的外观，因此品牌设置不会使应用难以阅读。

### 徽标

徽标是项目所在工作区中某个[文档账户](/zh-cn/guides/documents/)里的图片。

1. 将图片上传到文档账户顶层名为 `branding` 的文件夹中。
2. 在 **Edit Branding** 中，选择 **文档账户**，然后在 **Image in the branding/ folder** 下选择图片。

徽标可以是最大 512 KB 的 PNG、JPEG、GIF、WebP 或 SVG 文件。它显示在应用页眉的右侧。图片必须直接位于 `branding/` 中或其内部的文件夹中，并且保存品牌设置的任何人都必须能够读取该账户。

### 更改何时生效

应用在查看者的会话开始时读取其品牌设置。保存的更改会在下次有人打开或重新加载应用时显示。

## 将应用分配到项目

### 发布时

**发布服务器 Panel 应用** 对话框的 **目录设置** 下有一个 **项目** 选择器。选择拥有该应用的项目。发布到某个项目需要有该项目的访问权限。应用发布后，项目即固定；若要移动应用，请按下文所述使用 **分配**。

发布时指定了项目的应用默认读取该项目的表，因此 `table("sales")` 无需项目参数。

### 对于现有应用

1. 打开 **我的 Panel 应用**。
2. 单击要移动的应用所在行上的 **分配** 图标。
3. 选择 **项目**，然后单击 **审核**。
4. 阅读结果。它会列出目前可以打开该应用但不是该项目成员的工作区成员。
5. 单击 **分配**。

审核不会更改任何内容。**我的 Panel 应用** 中的 **项目** 列显示每个应用所属的项目。

### 访问权限

目前，谁可以打开应用不会因其项目而改变：之前可以打开应用的查看者仍然可以。随着时间推移，应用的访问权限将跟随其项目的成员关系，这就是 **审核** 会列出不在项目中的成员的原因，以便您先将他们添加进去。
