Dash 应用与您的 WASM 和服务器 Panel 应用显示在同一个**我的 Panel 应用**屏幕中，其**运行时**列显示 **Dash**，并带有各自的图标，便于区分。本页内容与服务器应用的[使用 Panel 应用](/zh-cn/guides/panel-apps/using/)基本一致，只有一处例外（见下文）：Dash 应用暂不提供 **Usage Metrics**。

## 构建状态

Dash 应用的**状态**列跟踪其构建过程，构建进行期间列表会自动刷新：

- **正在构建…**：PlaidCloud 正在将您的仓库构建为容器。此时应用还没有 URL。
- **就绪**：构建成功。应用的 URL 已生效，其所在行会出现**打开**图标。
- **失败**：构建未能完成。请检查入口点和分支，然后编辑应用以重新发布。

## 重新构建 Dash 应用

点击 Dash 应用所在行的**重新构建**图标，即可在不更改其设置的情况下重新构建并重新部署。应用状态会变回**正在构建…**，PlaidCloud 会再次构建相同的分支和入口点，新构建生效后状态切换回**就绪**。

在依赖项变更、基础镜像更新或构建偶发失败之后，请使用**重新构建**。编辑并保存 Dash 应用同样会触发重新构建，但重新构建本身无需打开编辑表单。

## 锁定应用

点击应用所在行的**锁定**图标，可防止意外更改。Dash 应用处于锁定状态时：

- **编辑**、**移除**和**重新构建**会拒绝执行，并提示应用已锁定。
- **推送到应用分支不会触发重新构建**，自动重新构建会被跳过，直到您解锁应用。解锁后请再次推送（或使用**重新构建**）以使更改生效。
- 打开应用和查看其日志仍然可用，锁定只会阻止更改，不会阻止查看者。

再次点击该图标即可解锁。图标显示应用的当前状态：锁定时为闭合，未锁定时为打开。锁定只是防止意外操作的保护措施，并非安全控制，任何可以编辑 Dash 应用的人也可以将其解锁。

## 打开 Dash 应用

点击就绪应用所在行开头的**打开**图标，即可在新选项卡中启动应用，地址为 `https://<your-tenant-host>/serve/<slug>/`。只有应用**就绪**后才会出现该图标。

Dash 应用在空闲时会缩容到零以节省资源，因此空闲一段时间后的首次打开需要先将其启动。在此期间您会看到 **PlaidCloud 加载屏幕**，而不是空白选项卡，应用准备好后会自动显示。如果应用无法启动，加载屏幕会变成“**This app didn't start**”提示，并带有**重试**按钮；如果问题持续出现，请编辑应用，检查其入口点和分支后重新发布。

> **只要选项卡保持打开，`dcc.Interval`（或任何其他持续轮询）就会使缩容到零失效。** 缩容到零依赖于应用在无人使用时变得安静，即没有正在处理的请求。像 `dcc.Interval` 这样按定时器持续发出请求的组件，只要该选项卡保持打开，就会让应用一直保持唤醒，即使查看者已经离开。如果希望应用在访问间隙缩容，请避免持续轮询，或在页面空闲一段时间后停止该定时器。

## 查看日志

点击 Dash 应用所在行的**查看日志**图标，打开其日志查看器，其中的**运行时**和**构建**选项卡、筛选器、时间范围和详细信息窗格与服务器 Panel 应用相同，完整机制请参见[查看日志](/zh-cn/guides/panel-apps/using/#查看日志服务器应用)。每条运行时日志行都会标记产生该行的会话所属的**用户**，与服务器 Panel 应用相同。

**在当前版本中，Dash 应用不提供 Usage Metrics**：服务器 Panel 应用所在行上的 **Usage Metrics** 图标不会出现在 Dash 应用中，因此暂时无法查看唯一用户数和会话明细。

## 编辑应用

点击 Dash 应用所在行的**铅笔**图标进行编辑。可以更改名称、标识、分支、入口点、CPU、内存、空闲窗口、公共标志、嵌入式服务域和备注。**Git 连接**在应用创建后即固定，并以只读方式显示。没有可编辑的**设计**字段，该设置是 Panel 专有的。保存会重新构建应用，其状态会变回**正在构建…**，直到新构建就绪。

## 移除应用

点击 Dash 应用所在行的**减号**图标并确认。移除后会拆除其构建和部署，应用的 URL 会立即失效。
