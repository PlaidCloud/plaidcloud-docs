## 说明


仪表板支持从静态报表到动态分析的广泛用例。仪表板既能满足复杂的报表需求，又提供直观的点选界面。有时您可能会遇到问题。PlaidCloud 支持团队的成员随时可以为您提供帮助，我们也在下面整理了一些提示，以防您遇到类似的问题。



## **仪表板常见问题与解答**



### 首选浏览器


由于缓存频繁，Google Chrome 通常是使用仪表板的最佳浏览器。如果使用其他浏览器并遇到问题，建议先清除缓存和 Cookie，看是否能解决问题。如果不能，建议切换到 Google Chrome，看问题是否再次出现。



### 同步延迟


* *问题：* 在仪表板区域中取消发布并重新发布表之后，数据似乎没有正确同步。
* *解决方案：* 重新发布表会清除读取该表的每个图表缓存的结果，因此在工作流运行之后打开的仪表板会显示新数据，无需手动刷新。如果没有，请检查运行是否已完成，以及是否重新发布了您预期的表。参见[仪表板缓存](/zh-cn/guides/dashboards/dashboard-caching/)。

### 表同步错误


* *问题：* 使用与之前某个表相同的发布名称重新创建表之后，即使在仪表板上点击刷新、发布、取消发布并重新发布该表，该表仍然无法同步。
* *解决方案：* 使用不同的名称重新发布该表。仪表板的数据模型不允许存在重复的表，或者发布名称和项目 ID 都相同的表。

### 缓存警告


* *问题：* 右上角弹出一条警告，内容为“Loaded data cached **3 hours ago**. Click to force-refresh.”
* *解决方案：* 点击该警告可强制刷新缓存。您也可以点击“Edit dashboard”旁边的下拉菜单，并在其中选择“Force refresh dashboard”。这两种方式都会在系统内部刷新，并且优于刷新网页浏览器本身。结果的保留时长是可以配置的，参见[仪表板缓存](/zh-cn/guides/dashboards/dashboard-caching/)。

### 权限警告


* *问题：* 我已发布的仪表板在每个应该填充数据的部分都显示相同的错误：“This endpoint requires the datasource… permission”
* *解决方案：* 检查数据源是否已过时。很可能是图表从过时的材料中提取数据。如果出现这种情况，请使用新的数据源更新图表。
* *问题：* 我收到与上述相同的权限警告，但我的同事可以查看图表数据。
* *解决方案：* 如果问题是一个人可以看到图表中的数据而另一个人不能，则可能需要由允许类别内的某人为第二个人授予权限。操作方法如下：


	1. 转到 Charts
	2. 选择要授予访问权限的图表旁边的第二个小图标（铅笔和纸）
	3. 点击 Edit Table
	4. 点击 Detail
	5. 点击 Owners，添加要授予访问权限的人员姓名并保存。

<Aside>最佳做法是，每当创建并保存新图表时，就在此时将所有适用的人员添加到 Owners 部分。否则，每次有新的人需要访问时，您都必须回头编辑并添加所有者。</Aside>


### 将修改后的筛选器保存到仪表板


* *问题：* 我在草稿模型中修改了筛选器，想把它们保存到我的仪表板中。但筛选器不在列表中。在我的草稿模型中，有一条警告写着：“There is no chart definition associated with this component, could it have been deleted? Delete this container and save to remove this message.”
* *解决方案：* 转到“Edit Chart”。在那里，确保“Dashboards”部分填写了正确的仪表板。如果为空，请添加正确的仪表板名称。

### 设置数字格式：出现故障


* *问题：* 我的数字格式出现故障且顺序混乱。
* *解决方案：* 出现这种故障最可能的原因是在数值列中使用了 Null。请使用筛选器排除所有 Null 数值列，然后再试一次。如果仍然不行，请查看此处提供的资料：http://bl.ocks.org/zanarmstrong/05c1e95bf7aa16c4768e 或这里：https://github.com/apache-superset/superset-ui/issues。最后，随时欢迎联系 PlaidCloud 支持团队成员。这是一个已知问题，正在开发更为持久的解决方案。

### 设置数字格式


将数字四舍五入到最接近的整数：


1. *请勿使用：* ,.0f
2. *改用：* ,d，或用于美元的 $,d

### 导入现有仪表板


* *问题：* 我在导入现有仪表板时，导出文件出现错误。
* *解决方案：* 首先检查文件。仪表板和数据集从**导出**生成的 ZIP 文件中导入。较旧的 JSON 或 YAML 导出文件会被拒绝，因此请重新导出仪表板，并导入新的 ZIP 文件。
* 然后检查仪表板是否有“Slug”。为此，请打开 Edit Dashboard，第二个部分的标题为 Slug。如果该部分为空或显示“null”，则问题不在于此。否则，slug 必须唯一：将其改为没有其他仪表板使用的内容，再次导出，并导入新文件。
