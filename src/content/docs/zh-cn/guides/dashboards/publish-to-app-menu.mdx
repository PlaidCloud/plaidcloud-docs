您可以从**洞察**将仪表板、Panel 或 Dash 应用，或 JupyterLite 笔记本发布到左侧的应用菜单。您选择的人员随后即可在菜单中产品应用的下方一键打开它。

<Aside>发布到应用菜单只会在菜单中放置一个条目，绝不会授予任何人对该项目的访问权限。只有当某人在其受众中**并且**已经能够打开该项目时，才会看到该条目。</Aside>

## 谁可以发布

您需要能够自己打开该项目，并能够管理它：

| 项目 | 谁可以发布 |
|---|---|
| 仪表板 | 其所有者和工作区管理员，即选择其受众的人员（请参阅[控制谁可以查看仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)），并具有仪表板的写入权限。 |
| Panel 或 Dash 应用 | 具有应用写入权限、且在应用所属项目中的角色高于探索者的成员。已锁定的项目不会阻止您。没有项目的应用可由其创建者或工作区管理员发布。 |
| JupyterLite 笔记本 | 添加该部署的人员或工作区管理员，并具有笔记本的写入权限。 |

**Dashboard Read and Write** 安全组具有仪表板、应用和笔记本的写入权限。

## 发布项目

1. 在**洞察**中，打开**仪表板**、**应用**或**笔记本**。
2. 从项目的行菜单中选择**发布到应用菜单…**，或选中该行并在工具栏中选择**发布到应用菜单…**。当您对该类项目具有写入权限时才会提供此选项，在**仪表板**中则仅对您管理的仪表板提供。
3. 在**发布到应用菜单**对话框中设置条目：
   - **菜单项**是菜单中的标签。它起初是项目的名称，下方的预览会显示条目的最终外观。标签不能比菜单中最宽的产品应用名称更宽；标签过宽时会有提示。
   - **图标**提供由标签首字母组成的字母组合图案或 15 种符号之一，以及一种颜色。第一次选择颜色时会根据标签挑选一种。图标上的小徽章显示该条目是仪表板、应用、笔记本还是 Jupyter Hub。
   - **谁能在菜单中看到**可选择**工作区中的所有人**、**组**或**人员**，一次只能选一种类型。对于**组**或**人员**，至少勾选一项。**组**需要读取安全组的权限，**人员**需要读取成员的权限；没有该权限时，此选项呈灰色。
4. 选择**发布**。

该项目的行随后会显示**已发布**标记。若要日后更改条目，请再次打开**发布到应用菜单…**：对话框会显示已保存的内容，其按钮为**保存**，**取消发布**会将条目从菜单中移除。

### 谁无法打开

在受众下方，对话框会检查受众中有哪些人目前无法打开该项目：

- *无法打开此项目：40 人中有 3 人*表示受众中的 40 人里有 3 人在能够打开该项目之前不会看到该条目。
- *此受众中的所有人都可以打开此项目*表示没有人被遗漏。
- *2 人位于您看不到的项目中*统计的是其访问权限取决于您无法打开的项目的人员，因此对话框无法判断。

对于仪表板，**修复访问权限**会打开其**谁可以看到此内容？** 对话框，在那里保存后会重新进行检查。只有当您能看到工作区成员时才会显示这些数量。

## 条目出现的位置

已发布的条目位于应用菜单中产品应用之后、分隔线下方，顺序由工作区管理员在[已发布的应用](#管理已发布的应用)中设置。每个条目都有其标签和图标。您自己所做的更改会立即看到；其他人会在下次加载 PlaidCloud 时看到。

| 项目 | 打开方式 |
|---|---|
| 仪表板 | 作为 PlaidCloud 内的选项卡 |
| **仅浏览器**的 Panel 应用 | 作为 PlaidCloud 内的选项卡 |
| JupyterLite 笔记本 | 作为 PlaidCloud 内的选项卡 |
| **基于服务器**的 Panel 应用或 Dash 应用 | 在新窗口中 |
| Jupyter Hub | 在新窗口中 |

从菜单打开的选项卡带有标题栏，其中有条目名称、**重新加载**和**在新窗口中打开**。如果该项目在选项卡内不会让您登录，请使用**在新窗口中打开**。

选项卡的地址是可以共享的链接：请参阅[共享链接](/zh-cn/guides/projects/sharing-links/#已发布的菜单条目)。如果您的应用菜单中只有**主页**和已发布的条目，**主页**会在**应用**行中首先列出它们。

### 谁能看到条目

成员在以下两个条件都满足时会看到条目：

- **他们在其受众中：** 工作区中的所有人、其某个组的成员，或其人员之一。
- **他们可以打开该项目：** 他们在洞察中能看到的仪表板；位于他们可以访问的项目中的应用；对于**仅浏览器**应用或 JupyterLite 笔记本，则还需要有权访问提供它的文档账户。

其他任何人都看不到该条目，无论其受众如何。

## 从您的菜单中隐藏条目

右键单击应用菜单中已发布的条目，然后选择**从我的菜单中隐藏**。它只会从您的菜单中消失，出现的消息中的**撤消**可将其恢复。有权使用洞察的成员可以使用隐藏功能。

若要再次显示它，请在洞察导轨中打开**已隐藏的应用**，然后在其行上选择**还原**。不再位于您菜单中的条目会显示**已不在您的菜单中**；**移除**会将其从列表中删除。您隐藏的条目保存在您的账户中，因此在每个浏览器中都会保持隐藏。

## 管理已发布的应用

工作区管理员在洞察导轨的**管理员**下打开**已发布的应用**。它按菜单顺序列出每个条目，包含其**名称**、**类型**、**受众**（**所有人**，或若干组或人员）和**状态**。**打开次数（30 天）** 会为有使用情况访问权限的成员显示每个仪表板被打开的频率。

- **上移**和**下移**设置条目在所有人菜单中的顺序。
- **更改受众…** 会为您可以管理的条目打开**发布到应用菜单**对话框。
- **取消发布**在您确认后，会将条目从其发布对象的所有人的菜单中移除。工作区管理员可以取消发布任何条目。

当已发布的项目被删除时，其条目会离开菜单，**已发布的应用**会显示它一次，并标注**项目已删除、已移除**。从列表中移除 Panel 应用或 JupyterLite 部署也会移除其条目。

## 通过 AI 助手或 MCP 发布

`publication_manage` 通过 MCP 完成同样的操作。其 `kind` 为 `dashboard`、`panelApp`、`jupyterLite` 或 `jupyterHub`，其操作包括：

- `get`、`set`、`delete` 和 `preview` 接受 `kind` 和 `item_id`。`set` 会用一个 `spec` 替换整个条目，其中包含 `label`、可选的 `icon` 和 `color`，以及 `type` 为 `public`、`acl-group` 或 `acl-user` 并带有其 `ids` 的 `audience`。`preview` 接受带有 `audience` 的 `spec`，并返回与对话框相同的数量。
- `list` 按菜单顺序返回您管理的条目（工作区管理员则返回所有条目），范围为您可以读取的类型。
- `reorder` 按新顺序接受 `keys`，每个为 `<kind>:<item_id>`，供工作区管理员使用。

Jupyter Hub 链接只能通过这种方式发布，由工作区管理员使用 `kind` 为 `jupyterHub`、`item_id` 为 `hub` 来完成。`publication_manage` 不适用于 Weave 或代表您行事的其他 AI 代理。
