每个仪表板都有受众，即可以打开它的人员。仪表板的所有者和工作区管理员在 PlaidCloud 中通过同一个对话框、以安全组的方式选择该受众。PlaidCloud 会在仪表板出现的所有位置应用这一选择：主页、我的仪表板、仪表板本身、直接链接、缩略图、PDF 导出和 AI 助手。

<Aside>受众会隐藏仪表板，但不会隐藏其数据。仪表板角色只授予可见性。图表数据仍然遵循项目访问权限，因此打开仪表板的人只能看到其有权访问的项目中的数据。如需限制人们可以看到的行，请使用[行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。</Aside>

## 受众

| 受众 | 谁可以打开仪表板 |
|---|---|
| **项目中的所有人** | 有权访问该仪表板所涉项目的所有人。这是默认设置。 |
| **指定组** | 您所选组的成员，以及仪表板的所有者和工作区管理员。 |
| **仅所有者（草稿）** | 仪表板的所有者和工作区管理员。此前选择的组会保留，并在仪表板再次发布时恢复访问权限。 |
| **未列出** | 不在任何位置列出，但项目中任何拥有链接的人都可以打开。未发布的仪表板最初就是这种状态。 |
| **自定义（Superset 角色）** | 在仪表板服务中直接设置的角色的持有者。PlaidCloud 以只读方式显示这些角色。 |

无论受众如何设置，所有者和工作区管理员始终可以看到仪表板。工作区管理员即仪表板服务的管理员，因此可以看到所有仪表板，包括草稿。主页磁贴和我的仪表板中的徽章会显示仪表板的受众，所有者可以看到自己的草稿和未列出的仪表板，并带有徽章。

## 选择谁可以查看仪表板

1. 打开仪表板的**谁可以看到此内容？** 操作：在主页上的磁贴中、在我的仪表板中的对应行上，或在**受众**列中。
2. 选择**项目中的所有人**、**指定组**或**仅所有者（草稿）**。每个选项都会显示其涵盖的人数。
3. 对于**指定组**，勾选相应的组。列表包含有权访问该仪表板所属项目的组及其成员数，可使用**搜索组**缩小范围。
4. 查看**影响**一行，例如“42 位项目成员中有 28 位将看到此内容”。**查看人员**会列出获得访问权限和失去访问权限的人员，**预览身份…** 会针对您选择的任一成员显示其是否能看到该仪表板以及原因。
5. 选择**保存**。

**始终包含**列出所有者和工作区管理员，他们无法被移除。只有仪表板的所有者和工作区管理员可以更改其受众，其他所有人看到的对话框是只读的。

对话框会告知您的情况：

- 跨多个项目的仪表板会列出有权访问其中任一项目的所有组。无法访问其中某个项目的组会被标记，其成员无法看到所有图表。
- 没有图表的仪表板会显示“添加图表以设置谁可以看到此内容。”
- 已被删除的组显示为“已删除的组（0 人）”，保存后将失去访问权限。空组显示“此组中尚无人员。”
- 带有 Superset 角色的仪表板会显示**自定义（Superset 角色）**。**指定组**会在您所选的组之外保留这些角色；**项目中的所有人**会移除这些角色，需通过**移除角色并保存**确认。
- 如果对话框打开期间有其他人保存了该仪表板，对话框会重新加载并要求您查看后再次保存。

组成员关系的变更大约在一分钟内生效：将某人添加到组后，其即可打开仪表板；将其移除后则无法打开，且无需注销。仪表板服务中仪表板的属性会以只读方式显示相同的受众，并附有指回此对话框的 **Manage in PlaidCloud** 链接。

### 副本保留其受众

仪表板的副本与原仪表板具有相同的受众，因此副本的可见人数永远不会多于其来源。任何可以看到无受众限制的仪表板的人，都可以通过另存为来复制它。限定于某些组的仪表板只有其所有者和工作区管理员可以复制。

## 请求访问

项目中不属于仪表板所指定组的人员在打开该仪表板时，会看到 **Request access** 页面，其中列出仪表板的所有者。他们可以添加一条可选备注并发送请求。其他任何人（无权访问该仪表板所涉的任何项目）只会看到该仪表板不存在或对其不可用。

每位所有者和工作区管理员都会收到一封电子邮件，其中包含请求者及其备注。打开该邮件会显示仪表板的**谁可以看到此内容？** 对话框，其中带有**访问请求**面板：

- **Add one of the groups the requester is already in** 列出包含请求者的组。系统不会替您勾选任何组；选择一个并点击**保存**即可授予访问权限。
- **关闭**会在不授予任何权限的情况下关闭请求。

当此人获得访问权限或有人关闭该请求时，请求即告关闭。如果请求者不属于任何符合条件的组，请在[管理安全组和分配](/zh-cn/administration/access/managing-security-groups-and-assignments/)中将其添加到某个组。

## 仪表板访问审核

工作区管理员可在仪表板工具栏中打开**访问审核**，一次性审核所有仪表板。**仪表板访问审核**列出每个仪表板的受众、组、人数、所有者、上次更改时间和更改者，以及其**数据暴露**情况。

使用**显示**可按以下条件筛选：**受限**、**项目中的所有人**、**仅所有者（草稿）**、**未列出**、**自定义（Superset 角色）**、**受限，但数据未被覆盖**（数据集没有行规则的受限仪表板）或**所有者已离开**。选择某个仪表板可打开其受众对话框；**打开行访问**会转到未覆盖数据集的行访问屏幕。**下载 CSV** 按当前筛选结果导出列表。

审核涵盖您有权访问的项目，如果仪表板还使用了您无法访问的项目，会给出说明。

## 一次更改多个仪表板

在我的仪表板中，最多选择 50 个仪表板并选择**设置受众…**。对话框只提供能够看到所有所选仪表板的组，其**影响**一行汇总所有这些仪表板。完成后，**结果**会报告已更改、已跳过、失败或发生冲突的仪表板数量，并说明每个被跳过的仪表板的原因，例如您不是所有者，或者仪表板带有 Superset 角色而您没有选择**移除 Superset 角色并一并保存**。

## 新仪表板的默认受众

项目可以决定谁能看到基于其数据构建的仪表板。在项目的主页选项卡中，**默认仪表板受众**可以是**项目中的所有人**（默认）或**指定组**，并可指定限制新仪表板的组。

默认值在仪表板首次发布时应用，不适用于已存在的仪表板。所有者已选择受众的仪表板（包括明确选择的**项目中的所有人**）会保留该选择。跨多个项目的仪表板采用其所有默认值中共有的组；如果没有所有默认值共有的组，则它最初是仅限其所有者的草稿。与个别成员而非组共享的项目没有可设置的默认受众。

### 通过 AI 助手或 MCP 设置默认受众

`project_upsert` 使用 `dashboard_default_audience`（分组 ID 列表）设置项目的默认受众。之后在该项目中创建的仪表板会以此受众开始。`[]` 会清除该设置，因此新仪表板对项目中的所有人开放。这些分组必须有权访问该项目，且更改需要项目架构师或工作区管理员权限。您可以通过使用自己登录凭据连接的助手来设置；自主代理会话无法设置。

对于通过安全组 ACL 或个别成员共享的项目，请先创建项目并设置其访问权限，然后在第二次 `project_upsert` 中设置 `dashboard_default_audience`；在创建项目时同时设置会被拒绝。

## 使用 AI 助手

`dashboard_audience_manage` 工具可从 AI 助手和 MCP 服务器完成相同的操作：可以**获取**仪表板的受众、**预览**更改、**设置**受众，以及**请求**或**关闭**访问。
