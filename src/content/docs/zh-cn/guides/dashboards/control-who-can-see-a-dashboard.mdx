每个仪表板都有一个受众，即可以打开它的人员。仪表板的所有者和工作区管理员在 PlaidCloud 中通过一个对话框、以安全组为单位来选择受众。PlaidCloud 会在仪表板出现的所有位置应用这一选择：主页、**仪表板**页面、仪表板本身、直接链接、缩略图、PDF 导出以及 AI 助手。

<Aside>受众隐藏的是仪表板，而不是其数据。仪表板角色仅授予可见性。图表数据仍遵循项目访问权限，因此打开仪表板的人只能看到来自其有权访问的项目的数据。如需限制人员可以看到哪些行，请使用[行访问](/zh-cn/administration/access/managing-security-groups-and-assignments/#管理行访问)。</Aside>

## 受众

| 受众 | 谁可以打开仪表板 |
|---|---|
| **项目中的所有人** | 有权访问仪表板所属项目的所有人。这是默认设置。 |
| **指定组** | 所选分组的成员，以及仪表板的所有者和工作区管理员。 |
| **仅所有者（草稿）** | 仪表板的所有者和工作区管理员。之前选择的分组会被保留，并在仪表板再次发布时重新获得访问权限。 |
| **未列出** | 不在任何位置列出，但项目中任何拥有链接的人都可以打开。未发布的仪表板最初就是这种状态。 |
| **自定义（Superset 角色）** | 直接在仪表板服务中设置的角色的持有者。PlaidCloud 以只读方式显示这些角色。 |

无论受众如何，所有者和工作区管理员始终可以看到仪表板。工作区管理员是仪表板服务的管理员，因此可以看到所有仪表板，包括草稿。主页磁贴和**仪表板**页面上的徽章会显示仪表板的受众，所有者会看到自己的草稿和未列出的仪表板带有徽章。

## 选择谁可以查看仪表板

1. 打开仪表板的**谁可以看到此内容？** 操作：可以从主页上的仪表板磁贴、**仪表板**页面上的仪表板行，或从**受众**列打开。
2. 选择**项目中的所有人**、**指定组**或**仅所有者（草稿）**。每个选项都会显示其覆盖的人数。
3. 对于**指定组**，勾选所需分组。列表中包含有权访问仪表板所属项目的分组及其成员数，可使用**搜索组**缩小范围。
4. 查看**影响**行，例如“42 名项目成员中有 28 名将看到此内容”。**查看人员**会列出获得访问权限和失去访问权限的人员，**预览身份…** 会针对所选的任意成员显示其能否看到该仪表板及原因。
5. 选择**保存**。

**始终包含**会列出所有者和工作区管理员，他们无法被移除。只有仪表板的所有者和工作区管理员才能更改其受众；其他人只能以只读方式查看该对话框。

对话框会提示以下信息：

- 跨多个项目的仪表板会列出有权访问其中任一项目的所有分组。无法访问其中某个项目的分组会被标记，其成员将无法看到全部图表。
- 没有图表的仪表板会显示“添加图表以设置谁可以看到此内容。”
- 已删除的分组显示为“已删除的组（0 人）”，并在保存时失去访问权限。空分组会显示“此组中尚无人员。”
- 带有 Superset 角色的仪表板会显示**自定义（Superset 角色）**。**指定组**会在所选分组之外保留这些角色；**项目中的所有人**会在您通过**移除角色并保存**确认后移除这些角色。
- 如果对话框打开期间其他人保存了该仪表板，对话框会重新加载，并要求您重新检查并再次保存。

分组成员身份的变更大约在一分钟内生效：将某人添加到分组后，对方即可打开仪表板；将其移除后则无法打开，无需注销。仪表板服务中的仪表板属性会以只读方式显示相同的受众，并提供 **Manage in PlaidCloud** 链接以返回此对话框。

### 副本保留其受众

仪表板的副本与原始仪表板具有相同的受众，因此副本的可见人数绝不会多于其来源。任何能够看到没有受众限制的仪表板的人，都可以通过“另存为”复制该仪表板。限定于分组的仪表板只能由其所有者和工作区管理员复制。

## 申请访问权限

项目中不属于仪表板分组的人员打开该仪表板时，会看到 **Request access** 页面，其中列出了仪表板的所有者。他们可以添加可选备注并发送请求。其他人（无权访问仪表板的任何项目）只会看到该仪表板不存在或对其不可用。

每位所有者和工作区管理员都会收到一封电子邮件，其中包含请求者及其备注。等待您处理的请求也会计入仪表板**概览**上的**需要关注**。打开该项会弹出仪表板的**谁可以看到此内容**对话框，其中带有**访问请求**面板：

- **添加请求者已所在的分组之一**会列出包含请求者的分组。系统不会替您勾选任何分组；选择一个分组并选择**保存**即可授予访问权限。
- **关闭**会关闭请求，不授予任何权限。

当请求者获得访问权限或有人关闭请求时，请求即会关闭。如果请求者不属于任何符合条件的分组，请在[管理安全组和分配](/zh-cn/administration/access/managing-security-groups-and-assignments/)中将其添加到某个分组。

## 仪表板访问审核

工作区管理员可在仪表板导航栏的**管理员**下打开**访问审核**，一次性审计所有仪表板。**仪表板访问审核**会列出每个仪表板的受众、分组、人数、所有者、上次更改时间和更改人，以及其**数据暴露**。

使用**显示**按以下条件筛选：**受限**、**项目中的所有人**、**仅所有者（草稿）**、**未列出**、**自定义（Superset 角色）**、**受限，但数据未被覆盖**（即其数据集没有行规则的受限仪表板）或**所有者已离开**。选择某个仪表板可打开其受众对话框；**打开行访问**会转到未覆盖数据集的行访问屏幕。**下载 CSV**会按当前筛选结果导出列表。

审核范围涵盖您有权访问的项目；如果某个仪表板还使用了您无法访问的项目，审核中会予以说明。

## 批量更改仪表板

在**仪表板**页面上，选择最多 50 个仪表板，然后选择**设置受众…**。该对话框仅提供能够看到所有所选仪表板的分组，其**影响**行会汇总所有仪表板的数据。完成后，**结果**会报告有多少仪表板已更改、被跳过、失败或存在冲突，并说明每个被跳过的仪表板的原因，例如不属于您的仪表板，或在未选择**移除 Superset 角色并一并保存**时带有 Superset 角色的仪表板。

## 新仪表板的默认受众

项目可以决定谁能看到基于其数据构建的仪表板。在项目的主页选项卡中，**默认仪表板受众**可以是**项目中的所有人**（默认）或**指定组**，后者需指定新仪表板所限定的分组。

默认设置在仪表板首次发布时应用，绝不会应用于已存在的仪表板。所有者已选择受众的仪表板（包括明确选择**项目中的所有人**的仪表板）会保留该选择。跨多个项目的仪表板会采用所有项目默认设置中共有的分组；如果没有所有项目共有的分组，该仪表板会以草稿形式提供给其所有者。与单个成员（而非分组）共享的项目没有可设置的默认受众。

### 通过 AI 助手或 MCP 设置默认受众

`project_upsert` 通过 `dashboard_default_audience`（一个分组 ID 列表）设置项目的默认受众。之后在该项目中创建的仪表板将以该受众开始。`[]` 会清除该设置，使新仪表板对项目中的所有人开放。这些分组必须有权访问该项目，且该变更需要项目架构师或工作区管理员才能执行。可以通过使用您自己的登录信息连接的助手进行此变更；自主代理会话无法设置此项。

对于通过安全组 ACL 或与单个成员共享的项目，请先创建项目并设置其访问权限，然后在第二次 `project_upsert` 中设置 `dashboard_default_audience`；在创建项目时设置该项会被拒绝。

## 使用 AI 助手

`dashboard_audience_manage` 工具可通过 AI 助手和 MCP 服务器执行相同操作：它可以**获取**仪表板的受众、**预览**变更、**设置**受众，以及**请求**或**驳回**访问。
