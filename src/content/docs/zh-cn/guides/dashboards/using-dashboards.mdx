## 概览

仪表板可让您基于有权访问的任意项目或工作区中的数据构建交互式视图。一个仪表板可以组合来自多个项目的表，将可视化与原始数据探索结合起来，既可用于常规报表，也可用于临时分析。仪表板无需更改任何配置，即可从小型参考表扩展到十亿行级别的数据集。

## 仪表板账户

首次从 PlaidCloud 打开仪表板时，系统会自动为您设置仪表板账户，无需手动创建。您能看到哪些内容，取决于您在 PlaidCloud 工作区中的成员身份和所属的安全组。

<Aside>请在 PlaidCloud 中添加、更改和移除人员，而不是在仪表板服务内操作，详见[管理工作区成员](/zh-cn/administration/access/overview/managing-workspace-members/)。直接在仪表板服务中创建用户账户是仅限管理员的操作，以这种方式创建的账户与您的工作区成员身份没有关联。</Aside>

## 您能看到哪些仪表板

PlaidCloud 中的仪表板列表显示您有权访问的项目所属的已发布仪表板。这是常见情况，涵盖几乎所有仪表板。

仪表板的所有者和工作区管理员可以将其限制给特定的安全组。受限的仪表板只会列示给这些组的成员，以及所有者和工作区管理员（他们可以看到所有仪表板）。未设置限制的仪表板会列示给所有有权访问其项目的人，因此限制某个仪表板永远不会改变其他仪表板的可见范围。

如果列表中缺少某个仪表板，有两点值得了解：

- **受限的仪表板不仅无法打开，还会从列表中隐藏。** 如果您有权访问该仪表板所在的项目并打开其链接，将看到 **Request access** 页面；否则请联系所有者，而不要认为它已被删除。
- **您的仪表板账户必须已存在，受限的仪表板才能到达您这里。** 该账户会在您首次从 PlaidCloud 打开仪表板时创建，并在此时应用您所属的组。

<Aside>在 PlaidCloud 中通过 **谁可以看到此内容？** 设置谁可以看到仪表板，详见[控制谁可以看到仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)。项目访问权限仍然叠加生效：看到某个仪表板绝不意味着您能获得无权访问的项目中的数据。</Aside>

## 从我的仪表板打开仪表板

在 **我的仪表板** 中，单击仪表板所在行开头的 **打开** 图标，即可在新选项卡中打开该仪表板。双击该行也可以打开。

### 行操作菜单

PlaidCloud 中每个带有逐行操作的列表（包括我的仪表板）都有一个行操作菜单。可以通过行开头的 **⋯** 按钮、右键单击该行，或工具栏中的 **操作** 菜单打开它。菜单的布局始终相同：

1. **打开**、**详细信息** 和 **编辑**，按此顺序排列。
2. 该列表自身的操作，例如 **访问**、**组**、**重置密码** 或 **克隆**。
3. **删除** 或 **移除**，位于最后。

各组之间用分隔线隔开。不适用于所选行的操作会保留在原位置但呈灰色，因此菜单项不会在不同行之间移动。

有两个菜单项会显示快捷键。按 **Enter** 键执行的菜单项（即打开该行）显示 **Enter**。按 **Delete** 键执行的菜单项显示 **Del**（Mac 上为 **Backspace**）。

如果列表中每行只有一个操作，则在行开头显示该操作的图标，而不是 **⋯**。单击该图标即可执行操作；具有破坏性的操作仍会要求您确认。无法执行该操作的行不显示图标。

## 会话过期后打开仪表板链接

如果在打开仪表板链接时您的会话已过期，系统会要求您登录，然后将您带到该仪表板，而不是仪表板主页。

## 显示控件

显示控件是筛选器栏中的一种控件，让任何查看仪表板的人无需打开图表进行编辑，就能更改图表的分组依据，例如将“Region”换成“Product Line”。仪表板编辑者可以在筛选器栏的设置菜单中添加并配置显示控件：选择 **Add or edit filters and controls**，然后在 **新建** 菜单中选择 **Add display control**。

### 限制显示哪些列

默认情况下，显示控件的下拉列表会列出底层数据集中标记为 **Is filterable** 的所有列。在列很多的数据集上，这可能意味着要在数百个列中滚动才能找到所需的那一列。

现在，每个显示控件的配置面板中都有自己的 **Available columns** 字段。将其设置为特定的列列表后，该控件的下拉列表就只提供这些列。留空则控件的行为与之前完全一致，提供所有可筛选的列，因此任何仪表板都无需做任何更改即可照常工作。

要限制显示控件：

1. 从筛选器栏的设置菜单中打开 **Add or edit filters and controls**。
2. 选择要限制的显示控件，或添加新的显示控件。
3. 在 **Available columns** 中，搜索并选择希望查看者看到的列。
4. 保存。

### 与“Is Filterable”的相互作用

**Available columns** 只提供数据集中已标记为 **Is filterable** 的列，即在该范围内进一步缩小，而不会绕过它。取消某列的 **Is filterable** 仍会在所有位置移除该列：包括 **Available columns**、临时筛选器、原生筛选器，以及基于该数据集构建的每个图表中的 **Simple Metric** 选择器。

正因为这种影响范围很广，才有了 **Available columns**。在它出现之前，缩短显示控件下拉列表的唯一办法是取消不想提供的列的 **Is filterable**，而这同时也会让这些列从该数据集上每个图表的指标选择器中消失。请对图表可能用作指标或临时筛选器的每一列保持 **Is filterable** 为选中状态，并使用各显示控件自己的 **Available columns** 来决定该控件在其 **分组依据** 下拉列表中显示什么。

<Aside type="caution">重命名或删除 **Available columns** 列表中的某一列，系统不会自动发现：控件在下次打开时只会提供更少的列，且没有任何警告。重命名或移除数据集列之后，请重新检查显示控件的 **Available columns**。</Aside>

### 保存位置

**Available columns** 与该控件的其余设置一起，按显示控件分别保存。它会随仪表板一起导出和导入，并且不会影响任何其他控件，无论是在同一仪表板上，还是在基于同一数据集构建的其他仪表板上。

## 编辑表

创建新表后收到的消息也会引导您编辑表配置。虽然有更多高级功能可用于编辑配置，但我们先从有限且更简单的部分开始。要编辑表配置：

1. 单击所需表的编辑图标
2. 单击“List Columns”选项卡
3. 按需排列列
4. 单击“Save”

这样可以定义在探索数据时如何使用表中的特定列。

* **Groupable：** 如果希望用户按某个字段对指标进行分组
* **Filterable：** 如果需要按某个字段进行筛选
* **Count Distinct：** 如果希望获得此字段的不重复计数
* **求和：** 如果这是要求和的指标
* **最小值：** 如果这是要收集基本汇总统计信息的指标
* **最大值：** 如果这是要收集基本汇总统计信息的指标
* **Is temporal：** 任何日期或时间字段都应选中此项

## 探索数据

要开始探索数据，只需单击所需的表。默认情况下，将显示表视图。

### 获取数据计数

要获取表中所有记录的计数：

1. 将筛选器更改为“Since”
2. 输入所需的起始筛选条件

	* 可以使用简单的短语，例如“3 years ago”
3. 输入所需的截止筛选条件

	* 时间上限默认为“now”
4. 选择“分组依据”标题
5. 在指标部分输入“Count”
6. 选择“COUNT(*)”
7. 单击“Query”按钮

随后即可在表中看到结果。

**如果要查找特定字段或限制条件的计数：**

1. 在“分组依据”字段中输入所需的限制条件
2. 运行查询

<Aside>在限制条件中使用“measurement”时，它指的是所取测量值的数值，具体取决于测量类型。因此，应确保“filter”部分下的测量类型相同（例如 weather_description 和 Maximum temperature）。</Aside>

### 限制结果数量

如果只需要一定数量的结果，例如前 10 条：

1. 选择“Options”
2. 在“Row Limit”部分输入所需的最大结果数
3. 单击“Query”

### 其他可视化工具

要将缩写的值展开为完整长度：

1. 选择“Edit Table Config”
2. 单击“List Sql Metric”
3. 单击“Edit Metric”
4. 单击“D3Format”

要编辑度量单位：

1. 选择“Edit Table Config”
2. 单击“List Sql Metric”
3. 单击“Edit Metric”
4. 单击“SQL Expression”

要更改图表类型：

1. 滚动到“Chart Options”
2. 填写必填字段
3. 单击“Query”

在这里可以设置坐标轴标签、边距、刻度等。
