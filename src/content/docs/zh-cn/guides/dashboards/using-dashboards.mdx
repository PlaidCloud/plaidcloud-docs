## 概览

仪表板可用于基于您有权访问的任何项目或工作区中的数据构建交互式视图。一个仪表板可以合并来自多个项目的表，将可视化与原始数据探索相结合，同时满足常规报表和临时分析的需求。仪表板无需更改配置，即可从小型参考表扩展到数十亿行的数据集。

## 仪表板账户

首次从 PlaidCloud 打开仪表板时，系统会自动为您设置仪表板账户，因此无需手动创建任何内容。您能看到的内容取决于您的 PlaidCloud 工作区成员身份和安全组。

<Aside>请在 PlaidCloud 中添加、更改和移除人员，而不是在仪表板服务内部进行，请参阅[管理工作区成员](/zh-cn/administration/access/overview/managing-workspace-members/)。直接在仪表板服务中创建用户账户是仅限管理员的操作，以这种方式创建的账户不会与您的工作区成员身份关联。</Aside>

## 您能看到哪些仪表板

PlaidCloud 中的**仪表板**页面会显示属于您有权访问的项目的已发布仪表板。这是常见情况，涵盖了几乎所有仪表板。

仪表板的所有者和工作区管理员可以将其限定于特定的安全组。受限仪表板只会向这些分组的成员列出，同时也会向其所有者和工作区管理员列出，后者可以看到所有仪表板。没有限制的仪表板会向有权访问其项目的所有人列出，因此限制某个仪表板绝不会改变其他仪表板的可见人员。

如果您的列表中缺少某个仪表板，有两点值得了解：

- **受限仪表板会从列表中隐藏，而不仅仅是无法打开。** 如果您可以访问该仪表板的项目并打开其链接，就会看到 **Request access** 页面；否则，请询问所有者，而不要以为它已被删除。
- **您的仪表板账户必须存在，受限仪表板才能对您可见。** 该账户会在您首次从 PlaidCloud 打开仪表板时为您创建，届时您的分组也会随之生效。

<Aside>在 PlaidCloud 中通过**谁可以看到此内容？** 设置谁可以查看仪表板，请参阅[控制谁可以查看仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)。项目访问权限仍会在此基础上生效：看到仪表板绝不会让您获得无法访问的项目中的数据。</Aside>

## 仪表板工作区

**仪表板**打开后，左侧为导航栏，旁边为所选的页面。无法打开某个页面的成员看不到对应的项。

| 导航栏项 | 显示内容 |
|---|---|
| **概览** | **仪表板**、**对所有人可见**、**受限**、**由您管理**、**就绪的应用**和**失败的应用**磁贴。选择某个磁贴可打开已筛选的对应列表。**最近打开和收藏**会列出您最近在此设备上打开或加星标的内容。**需要关注**会列出失败的应用和等待您处理的访问请求，并附带**审核**，用于打开您管理的仪表板。**最近 30 天打开次数最多**会向拥有使用情况访问权限的成员显示。 |
| **仪表板** | 您可以看到的仪表板。在列表上方选择**全部**、**由您管理**或**收藏**。列包括**受众**、**所有者**和**打开次数（30 天）**。**导入仪表板归档…** 和**设置受众…** 位于工具栏中。 |
| **应用** | 基于您的项目构建的 Panel、Dash 和浏览器应用，附带**类型**、**状态**和**项目**。状态会实时更新。**新建应用**包含**服务器**和其他应用类型，**应用库**可从模板开始。 |
| **笔记本** | 您的 JupyterLite 部署。 |
| **访问审核** | 位于**管理员**下，供工作区管理员使用。请参阅[控制谁可以查看仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#仪表板访问审核)。 |
| **打开导航器** | 位于导航栏底部。在新选项卡中打开仪表板服务。 |

**仪表板**和**应用**旁边的计数显示您可以看到的数量。

## 从仪表板页面打开仪表板

在**仪表板**页面上，单击仪表板行开头的**打开**图标，即可在新选项卡中打开该仪表板。双击该行也可以打开。

### 行操作菜单

PlaidCloud 中每个带有逐行操作的列表（包括**仪表板**页面）都有一个行操作菜单。可以通过行开头的 **⋯** 按钮、右键单击该行，或通过工具栏中的**操作**菜单打开它。该菜单的布局始终相同：

1. **打开**、**详细信息**和**编辑**，依此顺序排列。
2. 列表自身的操作，例如**访问**、**组**、**重置密码**或**克隆**。
3. **删除**或**移除**，位于最后。

各组之间以分隔线隔开。不适用于所选行的操作仍保留在原位，但显示为灰色，因此菜单项的位置在不同行之间不会变化。

有两个菜单项会显示快捷键。按 **Enter** 键运行的菜单项（用于打开该行）显示 **Enter**。按 **Delete** 键运行的菜单项显示 **Del**（在 Mac 上为 **Backspace**）。

如果列表中的行只有一个操作，则会在行开头显示该操作的图标，而不是 **⋯**。单击该图标即可运行该操作；破坏性操作仍会要求您确认。无法执行该操作的行不显示图标。

## 会话过期后打开仪表板链接

如果打开仪表板链接时您的会话已过期，系统会要求您登录，然后将您带到该仪表板，而不是仪表板主页。

## 显示控件

显示控件是一种筛选栏控件，可让查看仪表板的任何人更改图表的分组依据（例如，将“地区”替换为“产品线”），而无需打开图表进行编辑。仪表板编辑者可从筛选栏的设置菜单中添加和配置显示控件：选择 **Add or edit filters and controls**，然后从**新建**菜单中选择 **Add display control**。

### 限制显示哪些列

默认情况下，显示控件的下拉列表会列出底层数据集中标记为 **Is filterable** 的每一列。对于宽数据集，这可能意味着需要滚动浏览数百列才能找到所需的列。

现在，每个显示控件的配置面板中都有自己的 **Available columns** 字段。将其设置为特定的列清单后，该控件的下拉列表就只提供这些列。将其留空，控件的行为将与以前完全相同，提供所有可筛选的列；任何仪表板都无需进行更改即可照常工作。

限制显示控件：

1. 从筛选栏的设置菜单中打开 **Add or edit filters and controls**。
2. 选择要限制的显示控件，或添加一个新的显示控件。
3. 在 **Available columns** 中，搜索并选择希望查看者看到的列。
4. 保存。

### 与“Is Filterable”的交互方式

**Available columns** 只会提供数据集中已标记为 **Is filterable** 的列：它会进一步缩小该列表，而不会绕过它。取消勾选某列的 **Is filterable** 仍会将其从所有位置移除：从 **Available columns**、临时筛选器、原生筛选器，以及基于该数据集构建的每个图表的 **Simple Metric** 选择器中移除。

正是由于影响范围如此之广，才有了 **Available columns**。在此之前，缩短显示控件下拉列表的唯一方法，是对不希望在其中提供的列取消勾选 **Is filterable**，而这同时也会在该数据集上每个图表的指标选择器中隐藏这些列。对于图表可能需要用作指标或临时筛选器的每一列，请保持勾选 **Is filterable**，并使用每个显示控件自己的 **Available columns** 来决定该控件在其“分组依据”下拉列表中显示哪些内容。

<Aside type="caution">重命名或删除显示控件 **Available columns** 列表中的列不会被自动发现：控件下次打开时只会提供更少的列，且不会发出任何警告。重命名或移除数据集列后，请重新检查显示控件上的 **Available columns**。</Aside>

### 保存位置

**Available columns** 按显示控件保存，与该控件的其余设置一起保存。它会随仪表板一起导出和导入，并且不会影响任何其他控件，无论是同一仪表板上的控件，还是基于同一数据集构建的其他仪表板上的控件。

## 编辑表


创建新表后收到的消息也会引导您编辑表配置。虽然有更多高级功能可用于编辑配置，但我们先从有限且较简单的部分开始。编辑表配置：


1. 单击所需表的编辑图标
2. 单击“List Columns”选项卡
3. 根据需要排列列
4. 单击“保存”

这样就可以定义在探索数据时如何使用表中的特定列。


* **可分组：** 如果希望用户按特定字段对指标进行分组
* **可筛选：** 如果需要按特定字段进行筛选
* **去重计数：** 如果希望获取此字段的去重计数
* **求和：** 如果这是需要求和的指标
* **最小值：** 如果这是需要收集基本汇总统计信息的指标
* **最大值：** 如果这是需要收集基本汇总统计信息的指标
* **是否为时间：** 任何日期或时间字段都应勾选此项

## 探索数据


要开始探索数据，只需单击所需的表。默认情况下，系统会显示表视图。



### 获取数据计数


获取表中所有记录的计数：


1. 将筛选器更改为“Since”
2. 输入所需的起始筛选条件


	* 可以使用简单的短语，例如“3 years ago”
3. 输入所需的截止筛选条件


	* 时间上限默认为“now”
4. 选择“分组依据”标题
5. 在指标部分中键入“Count”
6. 选择“COUNT(*)”
7. 单击“Query”按钮

随后应能在表中看到结果。

**如果要查找特定字段或限制条件的计数：**

1. 在“分组依据”字段中键入所需的限制条件
2. 运行查询

<Aside>在限制条件中使用“measurement”时，它指的是所取测量值，而测量值取决于测量类型。因此，应确保“筛选器部分（例如 weather_description 和 Maximum temperature）”下的测量类型相同。</Aside>

### 限制结果数量

如果只需要一定数量的结果，例如前 10 个：

1. 选择“Options”
2. 在“Row Limit”部分中键入所需的最大结果数
3. 单击“Query”

### 其他可视化工具

将缩写值展开为完整长度：

1. 选择“Edit Table Config”
2. 单击“List Sql Metric”
3. 单击“Edit Metric”
4. 单击“D3Format”

编辑度量单位：


1. 选择“Edit Table Config”
2. 单击“List Sql Metric”
3. 单击“Edit Metric”
4. 单击“SQL Expression”

更改图表类型：


1. 滚动到“Chart Options”
2. 填写必填字段
3. 单击“Query”

在此可以设置坐标轴标签、边距、刻度等。
