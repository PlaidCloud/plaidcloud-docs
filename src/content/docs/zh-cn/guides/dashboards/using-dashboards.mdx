## 概览

仪表板可让您基于有权访问的任何项目或工作区的数据构建交互式视图。单个仪表板可以合并来自多个项目的表，将可视化内容与原始数据探索混合在一起，既可用于固定报表，也可用于临时分析。仪表板无需更改配置，即可从小型参考表扩展到十亿行级的数据集。

## 仪表板账户

首次从 PlaidCloud 打开仪表板时，系统会为您设置好仪表板账户，因此无需手动创建任何内容。您能看到什么取决于您在 PlaidCloud 工作区中的成员身份和所属的安全组。

<Aside>请在 PlaidCloud 中添加、更改和移除人员，而不是在仪表板服务内进行，请参阅[管理工作区成员](/zh-cn/administration/access/overview/managing-workspace-members/)。直接在仪表板服务中创建用户账户是仅限管理员的操作，以这种方式创建的账户与您的工作区成员身份无关。</Aside>

## 您能看到哪些仪表板

PlaidCloud 中的**仪表板**页面显示属于您有权访问的项目的已发布仪表板。这是常见情况，涵盖几乎所有仪表板。

仪表板的所有者和工作区管理员可以将其限制为特定的安全组。受限的仪表板仅对这些组的成员列出，同时也对其所有者和工作区管理员列出，后者可以看到每个仪表板。没有限制的仪表板会列给所有有权访问其项目的人，因此限制某一个仪表板绝不会改变其他仪表板的可见范围。

如果您的列表中缺少某个仪表板，有两点值得了解：

- **受限的仪表板会从列表中隐藏，而不仅仅是无法打开。** 如果您有权访问该仪表板的项目并打开其链接，会看到**请求访问**页面；否则请询问所有者，而不要假定它已被删除。
- **受限的仪表板要到达您这里，您的仪表板账户必须已存在。** 它会在您首次从 PlaidCloud 打开仪表板时为您创建，您所属的组也会在那时应用。

<Aside>在 PlaidCloud 中使用**谁可以看到此内容？** 来设置谁可以看到仪表板，请参阅[控制谁可以看到仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)。项目访问权限仍然在此基础上适用：能看到某个仪表板绝不意味着您能获得您无法访问的项目中的数据。</Aside>

## 仪表板工作区

**仪表板**打开时左侧是导航栏，旁边是您选择的页面。无法打开某个页面的成员不会看到该页面的项目。页面顶部有标题，通常带有简短的副标题，其操作位于旁边的页眉中。

| 导航栏项目 | 显示内容 |
|---|---|
| **概览** | 包含**仪表板**、**对所有人可见**、**受限**、**您管理的**、**就绪的应用**和**失败的应用**的图块。选择图块可打开其列表，并已完成筛选。**最近打开和收藏**列出您最近在此设备上打开或加星标的内容。**需要关注**列出失败的应用和等待您处理的访问请求，并带有**审核**，可打开您管理的仪表板。**最近 30 天打开最多**显示给有使用情况访问权限的成员。 |
| **仪表板** | 您能看到的仪表板。在列表上方选择**全部**、**您管理的**或**收藏**。列包括**受众**、**所有者**和**打开次数（30 天）**。**导入仪表板归档…** 和**设置受众…** 位于工具栏中。 |
| **应用** | 基于您的项目构建的 Panel、Dash 和浏览器应用，带有**类型**、**状态**和**项目**。状态会实时更新。**新建应用**菜单中有一个 **Panel 应用**标题，其下是 **Studio**、**仅浏览器**和**基于服务器**，然后是 **Dash 应用**和**从应用库…**。**类型**列使用相同的名称。 |
| **笔记本** | 您的 JupyterLite 部署。 |
| **访问审核** | 位于**管理员**下，供工作区管理员使用。请参阅[控制谁可以看到仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#仪表板访问审核)。 |
| **打开导航器 ↗** | 位于导航栏底部。箭头表示它是唯一在自己的窗口中打开的项目：在新选项卡中打开仪表板服务。 |

**仪表板**和**应用**旁边的计数显示您能看到的数量。

## 从仪表板页面打开仪表板

在**仪表板**页面上，点击仪表板行开头的**打开**图标，即可在新选项卡中将其打开。双击该行同样可以打开。

### 行操作菜单

PlaidCloud 中每个带有逐行操作的列表（包括**仪表板**页面）都有行操作菜单。可以通过行开头的 **⋯** 按钮、右键点击该行，或工具栏中的**操作**菜单打开它。菜单的布局始终相同：

1. **打开**、**详细信息**和**编辑**，按此顺序。
2. 列表自己的操作，例如**访问**、**组**、**重置密码**或**克隆**。
3. **删除**或**移除**，位于最后。

分隔线将各组分开。不适用于所选行的操作会保持在原位但显示为灰色，因此项目绝不会在不同行之间移动位置。

有两个项目会显示快捷键。按 **Enter** 键所运行的项目会打开该行，并显示 **Enter**。按 **Delete** 键所运行的项目显示 **Del**（在 Mac 上为 **Backspace**）。

如果列表的行只有一个操作，则在行的开头显示该操作的图标，而不是 **⋯**。点击图标即可运行该操作；具有破坏性的操作仍会要求您确认。无法执行该操作的行不显示图标。

### 标准、宽松和卡片视图

PlaidCloud 工作区应用中的列表（例如**仪表板**、**应用**、ERP **登记簿**和 Identity **成员**）在工具栏中有一个**视图**菜单，提供三种选择：

- **Standard rows**：紧凑列表，每行占一行。
- **Roomy rows**：同一列表，每行周围留有更多空间。
- **Cards**：每行一张卡片。**仪表板**卡片显示仪表板的缩略图，ERP 登记簿卡片显示金额、日期、实体、连接和单据。

卡片的行为与列表相同：选择一张卡片，按住 Shift 扩展选择范围，从**视图**菜单中排序和选择列，右键点击可使用**复制**和该行的操作，并且在带有收藏功能的列表（例如**仪表板**和**应用**）中，点击星标即可收藏。

## 询问数字为何如此

在仪表板上，右键点击图表上的某个点或表格图表中的某个单元格，然后选择 **Why this number**。PlaidCloud 会在新选项卡中打开，Weave 会说明哪个步骤写入了该数值、它来自何处，以及与上次运行相比有何变化。请参阅[数字为何如此](/zh-cn/guides/ai-assistant/weave-numbers/#为何是这个数字)。

## 会话过期后打开仪表板链接

如果您打开仪表板链接时会话已过期，系统会要求您登录，然后带您前往该仪表板，而不是仪表板主页。

## 显示控件

显示控件是一种筛选栏控件，可让查看仪表板的任何人更改图表的分组依据（例如将“Region”换成“Product Line”），而无需打开图表进行编辑。仪表板编辑者可从筛选栏的设置菜单中添加和配置显示控件：选择 **Add or edit filters and controls**，然后从**新建**菜单中选择 **Add display control**。

### 限制显示哪些列

默认情况下，显示控件的下拉列表会列出底层数据集中标记为 **Is filterable** 的每一列。在列很多的数据集上，这可能意味着要在数百列中滚动才能找到所需的列。

现在，每个显示控件的配置面板中都有自己的 **Available columns** 字段。将其设置为特定的列列表，控件的下拉列表就只提供这些列。留空则控件的行为与之前完全相同，提供每个可筛选的列，无需对任何仪表板做任何更改，它们就能像以往一样继续工作。

限制显示控件的步骤：

1. 从筛选栏的设置菜单中打开 **Add or edit filters and controls**。
2. 选择要限制的显示控件，或添加新控件。
3. 在 **Available columns** 中，搜索并选择您希望查看者看到的列。
4. 保存。

### 与“Is filterable”的相互作用

**Available columns** 只提供数据集中已标记为 **Is filterable** 的列，它是在该列表的基础上进一步缩小范围，而不会绕过它。取消勾选某一列的 **Is filterable** 仍会在所有地方将其移除：从 **Available columns**、临时筛选器、原生筛选器，以及基于该数据集构建的每个图表的 **Simple Metric** 选择器中移除。

正因为影响范围如此之广，才有了 **Available columns**。在它出现之前，缩短显示控件下拉列表的唯一方法是取消勾选不希望在其中提供的列的 **Is filterable**，而这也会使这些列从该数据集上每个图表的指标选择器中隐藏。请对图表可能需要用作指标或临时筛选器的每一列都保持勾选 **Is filterable**，并使用每个显示控件自己的 **Available columns** 来决定该控件在其“分组依据”下拉列表中显示什么。

<Aside type="caution">重命名或删除显示控件 **Available columns** 列表中的列时，系统不会自动捕获，控件在下次打开时只会提供更少的列，且不会有任何警告。重命名或移除数据集的列后，请重新检查显示控件上的 **Available columns**。</Aside>

### 保存位置

**Available columns** 与该控件的其余设置一起按显示控件保存。它会随仪表板一起导出和导入，并且对任何其他控件都没有影响，无论是在同一个仪表板上，还是在基于同一数据集构建的任何其他仪表板上。

## 编辑表


创建新表后收到的消息还会引导您编辑表配置。虽然有更高级的功能可用于编辑配置，但我们将从有限且更简单的部分开始。编辑表配置的步骤：


1. 点击所需表的编辑图标
2. 点击“List Columns”选项卡
3. 按需排列列
4. 点击“保存”

这样您可以定义在探索数据时希望如何使用表中的特定列。


* **Groupable**：如果您希望用户按特定字段对指标进行分组
* **Filterable**：如果您需要按特定字段进行筛选
* **Count Distinct**：如果您想获取此字段的不同值计数
* **求和**：如果这是您想要求和的指标
* **最小值**：如果这是您想收集基本汇总统计信息的指标
* **最大值**：如果这是您想收集基本汇总统计信息的指标
* **Is temporal**：任何日期或时间字段都应勾选此项

## 探索数据


要开始探索数据，只需点击所需的表。默认情况下，将显示表视图。



### 获取数据计数


获取表中所有记录的计数：


1. 将筛选器更改为“Since”
2. 输入所需的 since 筛选条件


	* 可以使用简单的短语，例如“3 years ago”
3. 输入所需的 until 筛选条件


	* 时间上限默认为“now”
4. 选择“分组依据”标题
5. 在指标部分输入“Count”
6. 选择“COUNT(*)”
7. 点击“Query”按钮

随后您应该会在表中看到结果。

**如果要查找特定字段或限制条件的计数：**

1. 在“分组依据”字段中输入所需的限制条件
2. 运行查询

<Aside>在限制条件中使用“measurement”时，它指的是所测量的值，这取决于测量的类型。因此，您应确保在“筛选器部分（例如 weather_description 和 Maximum temperature）”下的测量类型相同。</Aside>

### 限制结果数量

如果您只需要一定数量的结果，例如前 10 条：

1. 选择“Options”
2. 在“Row Limit”部分输入所需的最大结果数
3. 点击“Query”

### 其他可视化工具

将缩写值扩展为完整长度：

1. 选择“Edit Table Config”
2. 点击“List Sql Metric”
3. 点击“Edit Metric”
4. 点击“D3Format”

编辑度量单位：


1. 选择“Edit Table Config”
2. 点击“List Sql Metric”
3. 点击“Edit Metric”
4. 点击“SQL Expression”

更改图表类型：


1. 滚动到“Chart Options”
2. 填写必填字段
3. 点击“Query”

在此处可以设置坐标轴标签、边距、刻度等。
