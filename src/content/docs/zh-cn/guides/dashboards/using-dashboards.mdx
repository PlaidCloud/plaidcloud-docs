## 概览

仪表板可让您基于有权访问的任何项目或工作区中的数据构建交互式视图。单个仪表板可以合并来自多个项目的表，将可视化与原始数据探索结合起来，既可用于固定报告，也可用于临时分析。仪表板无需更改配置，即可从小型参考表扩展到十亿行级别的数据集。

## 仪表板账户

首次从 PlaidCloud 打开仪表板时，系统会自动为您设置仪表板账户，因此无需手动创建任何内容。您能看到的内容取决于您在 PlaidCloud 工作区中的成员身份和所属安全组。

<Aside>请在 PlaidCloud 中添加、更改和移除人员，而不是在仪表板服务内进行，请参阅[管理工作区成员](/zh-cn/administration/access/overview/managing-workspace-members/)。直接在仪表板服务中创建用户账户是仅限管理员的操作，以这种方式创建的账户与您的工作区成员身份没有关联。</Aside>

## 您能看到哪些仪表板

PlaidCloud 中的**仪表板**页面会显示属于您可访问项目的已发布仪表板。这是常见情形，涵盖了几乎所有仪表板。

仪表板的所有者和工作区管理员可以将其限定到特定的安全组。受限仪表板仅列示给这些组的成员，以及其所有者和工作区管理员（他们可以看到所有仪表板）。没有限制的仪表板会列示给所有有权访问其项目的人，因此限制某个仪表板绝不会改变其他仪表板的可见范围。

如果列表中缺少某个仪表板，有两点值得了解：

- **受限仪表板会从列表中隐藏，而不仅仅是无法打开。** 如果您可以访问该仪表板所在的项目并打开其链接，会看到 **Request access** 页面；否则请联系所有者，而不要假定它已被删除。
- **您的仪表板账户必须已存在，受限仪表板才能到达您面前。** 该账户在您首次从 PlaidCloud 打开仪表板时创建，您所属的组也会在那时应用。

<Aside>在 PlaidCloud 中使用**谁可以看到此内容？**设置谁可以看到仪表板，请参阅[控制谁可以查看仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)。项目访问权限仍然叠加生效：能看到某个仪表板绝不意味着您可以获得无法访问的项目中的数据。</Aside>

## 仪表板工作区

**仪表板**打开时，左侧是侧栏，旁边是所选页面。无法打开某个页面的成员看不到该页面对应的项目。每个页面顶部都有标题和简短的副标题，其操作位于旁边的页眉中。

| 侧栏项目 | 显示内容 |
|---|---|
| **概览** | 以下图块：**仪表板**、**对所有人可见**、**受限**、**您管理的**、**应用就绪**和**应用失败**。选择某个图块可打开其列表，且已完成筛选。**最近打开和收藏**列出您最近在此设备上打开或加星标的内容。**需要关注**列出失败的应用和等待您处理的访问请求，并附带**审核**，它会打开您管理的仪表板。**最近 30 天打开最多**会向拥有使用情况访问权限的成员显示。 |
| **仪表板** | 您能看到的仪表板。在列表上方选择**全部**、**您管理的**或**收藏**。列包括**受众**、**所有者**和**打开次数（30 天）**。工具栏中有**导入仪表板归档…**和**设置受众…**。 |
| **应用** | 基于您的项目构建的 Panel、Dash 和浏览器应用，附带**类型**、**状态**和**项目**。状态会实时更新。**新建应用**包含**服务器**和其他应用类型，**应用库**则从模板开始。 |
| **笔记本** | 您的 JupyterLite 部署。 |
| **访问审核** | 位于**管理员**下，供工作区管理员使用。请参阅[控制谁可以查看仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/#仪表板访问审核)。 |
| **打开导航器 ↗** | 位于侧栏底部。箭头表示它是唯一会在自己的窗口中打开的项目：即在新选项卡中打开仪表板服务。 |

**仪表板**和**应用**旁边的计数显示您能看到的数量。

## 从仪表板页面打开仪表板

在**仪表板**页面上，单击仪表板所在行开头的**打开**图标，即可在新选项卡中打开它。双击该行同样可以打开。

### 行操作菜单

PlaidCloud 中每个带有逐行操作的列表（包括**仪表板**页面）都有行操作菜单。可通过行首的 **⋯** 按钮、右键单击该行，或工具栏中的**操作**菜单打开它。该菜单的布局始终相同：

1. **打开**、**详细信息**和**编辑**，按此顺序排列。
2. 列表自身的操作，例如**访问**、**组**、**重置密码**或**克隆**。
3. **删除**或**移除**，排在最后。

分隔线将各组隔开。不适用于所选行的操作仍保留在原位但呈灰色，因此各项不会在不同行之间移动。

有两个项目会显示快捷键。**Enter** 键所执行的项目（即打开该行）显示 **Enter**。**Delete** 键所执行的项目显示 **Del**（Mac 上为 **Backspace**）。

如果列表的行只有一项操作，则在行首显示该操作的图标，而不是 **⋯**。单击该图标即可执行操作；具有破坏性的操作仍会要求您确认。无法执行该操作的行不显示图标。

### 标准、宽松和卡片视图

PlaidCloud 工作区应用中的列表，例如**仪表板**、**应用**、ERP **登记簿**和“身份”**成员**，在工具栏中都有**视图**菜单，提供三种选择：

- **标准行**：紧凑列表，每行一行内容。
- **宽松行**：同一列表，每行周围留有更多空间。
- **卡片**：每行一张卡片。**仪表板**卡片显示仪表板的缩略图，ERP 登记簿卡片显示金额、日期、实体、连接和文档。

卡片的行为与列表相同：选择卡片，按住 Shift 扩展选择，从**视图**菜单中排序和选择列，右键单击可使用**复制**和该行的操作，单击星标可将其收藏。

## 会话过期后打开仪表板链接

如果在打开仪表板链接时会话已过期，系统会要求您登录，然后带您转到该仪表板，而不是仪表板主页。

## 显示控件

显示控件是筛选栏中的一种控件，可让任何查看仪表板的人更改图表的分组依据，例如将“区域”换成“产品线”，而无需打开图表进行编辑。仪表板编辑者可从筛选栏的设置菜单添加和配置显示控件：选择 **Add or edit filters and controls**，然后从**新建**菜单中选择 **Add display control**。

### 限制显示哪些列

默认情况下，显示控件的下拉列表会列出底层数据集中标记为 **Is filterable** 的每一列。在列很多的数据集中，这可能意味着需要在数百列中滚动才能找到所需的列。

现在，每个显示控件的配置面板中都有自己的 **Available columns** 字段。将其设置为特定的列列表后，该控件的下拉列表只提供这些列。将其留空时，控件的行为与以前完全相同，提供每个可筛选的列，因此任何仪表板都无需更改即可照常工作。

限制显示控件的步骤：

1. 从筛选栏的设置菜单中打开 **Add or edit filters and controls**。
2. 选择要限制的显示控件，或添加一个新的显示控件。
3. 在 **Available columns** 中，搜索并选择希望查看者看到的列。
4. 保存。

### 与“Is Filterable”的相互影响

**Available columns** 只会提供数据集中已标记为 **Is filterable** 的列，它是在该列表的基础上进一步缩小范围，而不会绕过它。取消选中某列的 **Is filterable** 仍会将其从所有位置移除：从 **Available columns**、临时筛选器、原生筛选器，以及基于该数据集构建的每个图表的 **Simple Metric** 选取器中移除。

这种广泛的影响范围正是 **Available columns** 存在的原因。在它出现之前，缩短显示控件下拉列表的唯一方法是取消选中不想在其中提供的那些列的 **Is filterable**，而这也会让这些列从该数据集上每个图表的指标选取器中消失。请对图表可能需要用作指标或临时筛选器的每一列保持选中 **Is filterable**，并使用每个显示控件自己的 **Available columns** 来决定该控件在其分组依据下拉列表中显示什么。

<Aside type="caution">重命名或删除显示控件 **Available columns** 列表中的列时，系统不会自动发现这一情况，控件在下次打开时只是提供更少的列，且没有任何警告。重命名或删除数据集的列之后，请重新检查显示控件的 **Available columns**。</Aside>

### 保存位置

**Available columns** 与该控件的其他设置一起按显示控件保存。它会随仪表板一起导出和导入，并且不会影响任何其他控件，无论是同一仪表板上的还是基于同一数据集构建的其他仪表板上的控件。

## 编辑表


创建新表后收到的消息也会指引您编辑表配置。虽然有更多高级功能可用于编辑配置，但我们将从有限且更简单的部分开始。编辑表配置：


1. 单击所需表的编辑图标
2. 单击“List Columns”选项卡
3. 按需排列列
4. 单击“Save”

这样您就可以在探索数据时，定义希望如何使用表中的特定列。


* **可分组：** 如果希望用户按某个特定字段对指标分组
* **可筛选：** 如果需要对某个特定字段进行筛选
* **不重复计数：** 如果希望获得此字段的不重复计数
* **求和：** 如果这是希望求和的指标
* **最小值：** 如果这是希望收集基本汇总统计信息的指标
* **最大值：** 如果这是希望收集基本汇总统计信息的指标
* **是否为时间字段：** 任何日期或时间字段都应选中此项

## 探索数据


要开始探索数据，只需单击所需的表。默认情况下，您将看到表视图。



### 获取数据计数


获取表中所有记录的计数：


1. 将筛选器更改为“Since”
2. 输入所需的起始筛选条件


	* 可以使用简单的短语，例如“3 years ago”
3. 输入所需的截止筛选条件


	* 时间上限默认为“now”
4. 选择“分组依据”标题
5. 在指标部分输入“Count”
6. 选择“COUNT(*)”
7. 单击“Query”按钮

随后您应该会在表中看到结果。

**如果要查找特定字段或限制条件的计数：**

1. 在“分组依据”字段中输入所需的限制条件
2. 运行查询

<Aside>在限制条件中使用“measurement”时，它指的是所采集的测量值，具体取决于测量类型。因此，应确保“筛选器部分（例如 weather_description 和 Maximum temperature）”下的测量类型相同。</Aside>

### 限制结果数量

如果只需要一定数量的结果，例如前 10 条：

1. 选择“Options”
2. 在“Row Limit”部分输入所需的最大结果数
3. 单击“Query”

### 其他可视化工具

将缩写的值展开为完整长度：

1. 选择“Edit Table Config”
2. 单击“List Sql Metric”
3. 单击“Edit Metric”
4. 单击“D3Format”

编辑度量单位：


1. 选择“Edit Table Config”
2. 单击“List Sql Metric”
3. 单击“Edit Metric”
4. 单击“SQL Expression”

更改图表类型：


1. 滚动到“Chart Options”
2. 填写必填字段
3. 单击“Query”

在这里可以设置坐标轴标签、边距、刻度等。
