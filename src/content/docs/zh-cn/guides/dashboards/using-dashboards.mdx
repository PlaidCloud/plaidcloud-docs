## 概述

仪表板可让您基于有权访问的任何项目或工作区中的数据构建交互式视图。单个仪表板可以组合来自多个项目的表，将可视化与原始数据探索混合在一起，既可用于常设报表，也可用于临时分析。仪表板可以从小型参考表扩展到十亿行的数据集，无需更改任何配置。

## 仪表板账户

您的仪表板账户会在您首次从 PlaidCloud 打开仪表板时自动为您设置，因此无需手动创建。您能看到什么取决于您在 PlaidCloud 工作区中的成员身份和安全组。

<Aside>请在 PlaidCloud 中而不是在仪表板服务内部添加、更改和移除人员，参见[管理工作区成员](/zh-cn/administration/access/overview/managing-workspace-members/)。直接在仪表板服务中创建用户账户是仅限管理员的操作，以这种方式创建的账户与您的工作区成员身份没有关联。</Aside>

## 您能看到哪些仪表板

PlaidCloud 中的仪表板列表显示属于您有权访问的项目的已发布仪表板。这是常见情况，涵盖几乎所有仪表板。

仪表板的所有者和工作区管理员可以将其限定于特定的安全组。受限的仪表板仅对这些组的成员列出，同时也对其所有者和工作区管理员列出，后者可以看到所有仪表板。没有限制的仪表板会列给有权访问其项目的所有人，因此限制某一个仪表板绝不会改变其他仪表板的可见人员。

如果您的列表中缺少某个仪表板，有两点值得了解：

- **受限的仪表板会从列表中隐藏，而不仅仅是无法打开。** 如果您有权访问该仪表板的项目并打开其链接，会看到 **Request access** 页面；否则请联系所有者，而不要认为它已被删除。
- **您的仪表板账户必须已存在，受限的仪表板才能到达您这里。** 该账户会在您首次从 PlaidCloud 打开仪表板时为您创建，并在此时应用您所属的组。

<Aside>在 PlaidCloud 中使用**谁可以看到此内容？**设置谁可以查看仪表板，参见[控制谁可以查看仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)。项目访问权限仍然叠加适用：看到某个仪表板绝不会让您获得无法访问的项目中的数据。</Aside>

## 显示控件

显示控件是筛选器栏中的一种控件，可让任何查看仪表板的人更改图表的分组依据，例如将“区域”换成“产品线”，而无需打开图表进行编辑。仪表板编辑者从筛选器栏的设置菜单中添加和配置显示控件：选择 **Add or edit filters and controls**，然后从**新建**菜单中选择 **Add display control**。

### 限制显示哪些列

默认情况下，显示控件的下拉列表会列出底层数据集上标记为 **Is filterable** 的每一列。在列很多的数据集上，这可能意味着要滚动浏览数百列才能找到所需的那一列。

现在，每个显示控件在其配置面板中都有自己的 **Available columns** 字段。将其设置为特定的列列表后，该控件的下拉列表就只提供这些列。留空则控件的行为与以前完全一致，提供所有可筛选的列，因此任何仪表板都无需做任何更改即可像以往一样继续工作。

要限制显示控件：

1. 从筛选器栏的设置菜单中打开 **Add or edit filters and controls**。
2. 选择要限制的显示控件，或添加一个新的显示控件。
3. 在 **Available columns** 中，搜索并选择希望查看者看到的列。
4. 保存。

### 它与“Is Filterable”如何交互

**Available columns** 只提供数据集上已标记为 **Is filterable** 的列，它是在该列表基础上进一步缩小范围，而不会绕过它。取消勾选某一列的 **Is filterable** 仍会在所有地方移除该列：包括 **Available columns**、临时筛选器、原生筛选器，以及基于该数据集构建的每个图表的 **Simple Metric** 选择器。

这种影响范围之广，正是 **Available columns** 存在的原因。在它出现之前，缩短显示控件下拉列表的唯一办法，是对不希望在那里提供的列取消勾选 **Is filterable**，而这也会使这些列从该数据集上每个图表的指标选择器中消失。请对图表可能需要作为指标或临时筛选器的每一列保持勾选 **Is filterable**，并使用每个显示控件自己的 **Available columns** 来决定该控件在其“分组依据”下拉列表中显示什么。

<Aside type="caution">重命名或删除位于显示控件 **Available columns** 列表中的列时，不会被自动捕获：该控件在下次打开时只会提供更少的列，且没有任何警告。重命名或移除数据集的列之后，请重新检查显示控件上的 **Available columns**。</Aside>

### 保存位置

**Available columns** 按显示控件保存，与该控件的其余设置一起保存。它会随仪表板一起导出和导入，并且对任何其他控件都没有影响，无论是在同一个仪表板上，还是在基于同一数据集构建的其他仪表板上。

## 编辑表


创建新表后收到的消息也会引导您编辑表配置。虽然有更高级的功能可用于编辑配置，但我们先从有限且更简单的部分开始。要编辑表配置：


1. 点击所需表的编辑图标
2. 点击“List Columns”选项卡
3. 按需排列各列
4. 点击“Save”

这样您就可以定义在探索数据时如何使用表中的特定列。


* **Groupable：** 如果希望用户按特定字段对指标进行分组
* **Filterable：** 如果需要对特定字段进行筛选
* **Count Distinct：** 如果要获取此字段的非重复计数
* **求和：** 如果这是您想要求和的指标
* **最小值：** 如果这是您想要收集基本汇总统计信息的指标
* **最大值：** 如果这是您想要收集基本汇总统计信息的指标
* **Is temporal：** 对于任何日期或时间字段，都应勾选此项

## 探索数据


要开始探索数据，只需点击所需的表。默认情况下，您会看到表视图。



### 获取数据计数


要获取表中所有记录的计数：


1. 将筛选器更改为“Since”
2. 输入所需的起始筛选条件


	* 您可以使用简单的短语，例如“3 years ago”
3. 输入所需的截止筛选条件


	* 时间上限默认为“now”
4. 选择“Group By”标题
5. 在指标部分输入“Count”
6. 选择“COUNT(*)”
7. 点击“Query”按钮

随后您应该能在表中看到结果。

**如果要查找特定字段或限制条件的计数：**

1. 在“Group By”字段中输入所需的限制条件
2. 运行查询

<Aside>在限制条件中使用“measurement”时，它指的是所测量的值，这取决于测量的类型。因此，应确保“filter”部分下的测量类型相同（例如 weather_description 和 Maximum temperature）。</Aside>

### 限制结果数量

如果只需要一定数量的结果，例如前 10 个：

1. 选择“Options”
2. 在“Row Limit”部分输入所需的最大结果数
3. 点击“Query”

### 其他可视化工具

要将缩写的值展开为完整长度：

1. 选择“Edit Table Config”
2. 点击“List Sql Metric”
3. 点击“Edit Metric”
4. 点击“D3Format”

要编辑度量单位：


1. 选择“Edit Table Config”
2. 点击“List Sql Metric”
3. 点击“Edit Metric”
4. 点击“SQL Expression”

要更改图表类型：


1. 滚动到“Chart Options”
2. 填写必填字段
3. 点击“Query”

在这里您可以设置坐标轴标签、边距、刻度等。
