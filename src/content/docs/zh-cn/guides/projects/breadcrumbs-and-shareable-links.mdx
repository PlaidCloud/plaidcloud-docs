Analyze 窗口会层层叠放：项目中的工作流、该工作流中的步骤，以及您为检查结果而打开的表。两项功能让您轻松了解自己所处的位置并返回上一级：每个窗口标题中的**面包屑**，以及**跟随您当前所看内容的 URL**，使任何视图都可以被收藏或粘贴给同事。

## 面包屑

属于某个项目的窗口会在窗口标题栏中以其所属层级作为标题：

```
My Project › Workflow › Nightly Load
```

每一部分称为一个分段，从最外层的容器向内由左至右排列：

1. **项目** — 拥有您当前所看内容的项目。
2. **对象类型** — 工作流、表、步骤、维度或数据编辑器。
3. **对象本身** — 当前的工作流、表、步骤等。最后一个分段就是您当前所在的位置，因此不可点击。

### 使用面包屑导航

选择前两个分段中的任意一个即可向上移动：

| 分段 | 工具提示 | 作用 |
|---|---|---|
| 项目名称 | 打开项目 | 打开该项目；如果已经打开，则将其置于最前 |
| 工作流 | 显示所有工作流 | 打开项目并显示其工作流列表 |
| 表 | 显示所有表 | 打开项目并显示其表列表 |
| 步骤 | 显示所有步骤 | 打开项目并显示其步骤列表 |
| 维度 | 显示所有维度 | 打开项目并显示其维度列表 |
| 数据编辑器 | 显示所有数据编辑器 | 打开项目并显示其数据编辑器列表 |

类型分段是到达同级对象的快捷方式：在某个工作流中点击一下，即可进入同一项目中的完整工作流列表，随时可以打开另一个工作流。

<Aside type="note">
您来自的窗口会保持打开。使用面包屑导航会将项目置于最前，而不会关闭您之前所看的内容，您可以通过屏幕底部的选项卡栏返回该窗口。
</Aside>

### 面包屑出现的位置

- **工作流**窗口 — 标准工作流的步骤网格
- **可视化工作流设计器** — 高级工作流的画布视图
- **表资源管理器**
- 单独打开的**步骤**窗口
- **维度**层次结构窗口
- **数据编辑器**窗口

一个步骤可以属于多个工作流，因此步骤的面包屑显示为 `Project › Step › name`，而不是指明某一个所属工作流。

### 键盘和屏幕阅读器访问

可点击的分段是普通控件：**制表符**可移到它们上面，**Enter** 或**空格**可激活当前获得焦点的分段，因此无需鼠标即可沿层次结构向上移动。每个分段都会被播报为按钮，最后一个分段会被播报为当前页面，`›` 分隔符会被跳过而不会朗读出来。

### 离开有未保存更改的数据编辑器

数据编辑器是唯一一个在面包屑将您带离之前会先询问的窗口。如果您有正在进行的编辑，选择某个分段会显示**未保存的更改**提示，即“*是否关闭数据编辑器而不保存更改？*”，并提供**关闭编辑器**以确认离开。取消该提示，您将留在编辑器中，更改保持不变。

这与编辑器自带的**关闭**按钮所显示的提示相同，因此没有任何离开数据编辑器的途径会在不询问的情况下丢弃工作。

## 可共享链接

地址栏始终显示位于最前的窗口。打开一个工作流，URL 就变成该工作流的链接；打开一个表，URL 就变成该表的链接。这个链接就是您共享的单位。

**要共享您正在查看的内容**，请从浏览器地址栏复制 URL 并发送。任何有权访问该项目的人都会打开同一视图。将其收藏后，以后仍然有效。

### 他人打开链接时会发生什么

打开或刷新链接会恢复**父级上下文**，而不仅仅是那一个窗口。指向工作流的链接也会重新打开其项目，因此您到达时，选项卡栏中已有该项目，而不是只有一个孤零零的窗口，这与您自己导航到那里所到达的位置相同。

### 链接格式

链接以项目优先：先是项目，然后是其中的对象，两者用 `~` 分隔。

```
#p~my-project                        a project
#p~my-project~w~<workflow>           a standard workflow
#p~my-project~c~<workflow>           a workflow in the Visual Workflow Designer
#p~my-project~w~<workflow>~s~<step>  a step within a workflow
#p~my-project~t~<table>              a table in the Table Explorer
#p~my-project~d~<dimension>          a dimension hierarchy
#p~my-project~e~<editor>             a Data Editor
#home                                the Home landing page
```

如果项目有架构名称，链接会使用它（上面的 `my-project`），这使链接可读且稳定。否则使用项目的标识符。两种形式打开的是同一个项目。

<Aside type="note">
在项目优先格式出现之前创建的链接仍然有效。较早的 `?p=…&t=…` 风格链接仍会打开正确的视图，并且地址栏会在您首次导航时自动更新为当前格式。
</Aside>

### 链接无法打开时

如果链接中的对象已被删除，或者您无权访问其项目，链接会打开应用但不显示该视图，而不会失败。关闭地址栏中带有链接的窗口会使 URL 返回到所属项目，因此地址栏绝不会指向已不再打开的内容。
