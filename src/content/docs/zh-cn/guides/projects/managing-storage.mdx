**存储**窗口显示工作区存储的内容、相对于套餐的成本，以及哪些项目和表占用了空间。每个项目还有一个**存储**选项卡，您可以在其中设置每个表保留其历史记录的时长。

## 打开存储窗口

在**项目**屏幕上，存储条显示工作区存储了多少数据。点击**存储详情…** 打开**存储**窗口。点击**刷新**可重新加载。

## 阅读仪表

**本月存储**显示一个包含三个区段的仪表：

| 区段 | 含义 |
|---|---|
| **包含** | 您的套餐包含的存储。 |
| **预留** | 您的组织提前预留的存储。 |
| **按需** | 超出包含和预留部分的存储。 |

仪表下方的卡片显示：

- **当前已存储**：工作区当前存储的数据量。
- **预计平均值**：本月截至目前的平均值，并将最近一天的数值延续到月底。计费使用的是此数字，而不是**当前已存储**。某一天存储量大幅增加并不会决定您的账单。
- **包含**、**由预留额度覆盖**和**按需**：预计平均值如何在各区段之间划分。

**最近 90 天**以图表显示工作区的每日存储量。

工作区管理员还会看到估算的金额，例如按需区段的成本，以及在预留更多存储可以省钱时给出的建议。其他成员只能看到大小。金额只是估算，不是发票。

### 如果删除数据会怎样？

工作区管理员可以在**如果删除数据会怎样？** 中输入一个数量，查看本月平均值会下降多少，以及大约能节省多少费用。该估算假定空间在几天后释放，因为清理是每晚运行的。

## 按项目查看存储

存储窗口中的**项目**列表将每个项目的大小拆分为：

- **当前（GB）**：您的表中目前的数据。
- **历史记录 (GB)**：为时间旅行和还原而保留的较早版本。
- **合计 (GB)**：以上两者之和。
- **30 天 (%)**：项目存储在过去 30 天内的变化幅度。

部分计费存储不属于任何项目，因此显示在标有**已计费的额外开销**的单独行中：

- **备份**
- **文件和文档**
- **容器镜像**
- **工作流临时空间和副本**
- **元数据、清理和未测量**

**其他项目**汇总了您无法打开的项目。

在**项目**屏幕上，**大小**列显示每个项目的存储，文件夹则显示其中各项目的总和。

## 项目存储选项卡

打开项目并点击其**存储**选项卡。它显示项目存储了多少数据，分为当前数据和历史记录，并列出其表：

| 列 | 含义 |
|---|---|
| **表** | 表的名称。 |
| **当前数据** | 表目前保存的内容。 |
| **历史记录** | 为了便于还原而保留的较早版本。 |
| **行** | 表的行数。 |
| **最后更新** | 表最近一次被写入的时间。 |
| **时间旅行** | 表的设置，例如 **3 天**或**继承（1 天）**，以及您可以还原到的最早时间点。 |
| **备注** | **估算**、**未测量**或**正在清理**。 |

列表下方的**建议**指出最容易节省空间的方法：超过 90 天未更改的表、已删除项目中的表，或历史记录比数据本身还大的表。每条建议都有一个按钮：**打开表**、**删除…** 或**时间旅行…**。

## 历史记录与时间旅行

对表的每次写入都会保留该表的早期版本。这些较旧的数据就是它的**历史记录**。**时间旅行**决定表保留这些数据的时长，也决定您可以回溯多久来查看或[还原表](/zh-cn/guides/data/table-snapshots/)。

新项目默认保留 1 天的历史记录。您可以在两个级别控制这一设置：

- **项目默认值。** 在项目的设置中，**默认时间旅行保留期（天）** 是 1 到 90 之间的数字。它适用于每个未设置自身值的表。
- **表。** 在表的设置中，**时间旅行**可选择**继承**（使用项目默认值），或 2、3、5、7、14、30、60 或 90 天之一。

表自身的设置只有在长于项目默认值时才会生效，因此表可以延长其项目的默认值，但不能缩短。若要在某个表上保留更少的历史记录，请降低项目默认值。

更改在下一次夜间清理时生效。调高设置会从此刻起保留历史记录，但无法找回已经过期的历史记录，调高时表的设置窗口会对此给出提示。

<Aside type="caution">当项目或表保留的历史记录比之前少时，下一次夜间清理会删除早于新设置的历史记录。已删除的历史记录无法恢复。若要保留更多，请在该次清理运行之前调高设置。</Aside>

表的可还原范围就是它保留的天数，其设置窗口会显示您可以还原到的最早时间点。按时间点还原最远可回溯到该最早的可还原时间点。

时间旅行期结束后，已删除的数据还会再保留 7 天，可由 PlaidCloud 支持团队恢复。这部分数据不计入您的存储。

## 减少存储

- **删除或移入回收站您不需要的数据。** 对建议使用**删除…**，或删除不再使用的表和项目。
- **降低项目的默认时间旅行。** 设置为**继承**的表随后会保留更少的历史记录。
- **缩短表自身的时间旅行**，适用于之前延长过的表。
- **查看建议**，位于每个项目的**存储**选项卡上。

随着夜间清理的运行，空间会在接下来几天内逐步释放。

## 估算大小与不可用的合计

- **估算**表示 PlaidCloud 尚未测量该表或项目。在夜间测量运行之前，大小是根据表的形态估算的。
- **Snowflake 和 Databricks 项目**将数据保存在您自己的账户中。它们显示估算大小，并且从不计入您的 PlaidCloud 存储。
- **工作区合计不可用**表示刚才无法读取工作区的合计。项目大小以估算值显示。点击**刷新**重试。
- 如果您看到 **You don't have access to storage usage**，请向工作区管理员申请项目的读取权限。
