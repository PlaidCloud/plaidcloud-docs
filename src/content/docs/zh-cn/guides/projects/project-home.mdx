## 说明

**项目主页**是进入项目后的起点。左侧的导航栏列出六个页面：**概览**、**变量**、**计划与传感器**、**访问与共享**、**数据与连接**和**应用与品牌设置**。概览页汇总项目情况，其余五个页面用于更改项目设置。

导航栏上的**变量**徽章显示项目的变量数量，**计划与传感器**徽章显示处于活动状态的计划和传感器数量。

已锁定的项目为只读。其各页面会显示一条横幅，内容为“此项目已锁定，因此为只读。请在“概览”中解锁后再进行更改。”，且页面上的控件均被禁用。

## 概览

![项目主页的概览页，显示项目名称、六个磁贴、Coming up 和项目默认值](/images/projects/project-home-overview.png)

页面顶部显示项目名称，以及项目是**可编辑**还是**只读**。

- **说明。** 单击铅笔图标即可就地编辑说明。按 Enter 保存，按 Escape 取消。
- **标签。** 在**添加标签…**中输入标签，然后单击**添加**。请参阅[使用标签组织工作](/zh-cn/guides/projects/organizing-with-labels/)。
- **锁定**和**解锁**用于在可编辑与只读之间切换项目。

磁贴统计项目中包含的内容：

| 磁贴 | 显示内容 |
|---|---|
| **表** | 项目中的表。 |
| **工作流** | 项目中的工作流。 |
| **步骤** | 所有工作流中的步骤。 |
| **变量** | 项目变量。 |
| **已发布的表** | 您已发布的表。 |
| **数据大小** | 项目的表所存储的数据量。单击可打开**存储**。请参阅[管理存储](/zh-cn/guides/projects/managing-storage/)。 |

如果项目中的某些行已对您筛选，**数据大小**会显示短横线，因为此时合计值不准确。

**Coming up** 列出接下来三次计划运行及其工作流名称，以及处于活动状态的传感器数量。**View schedules ›** 会打开**计划与传感器**。

**项目默认值**显示工作流和步骤在未自行设置时所使用的**环境**、**表存储**、**访问**和 **ERP过账**值。**Change settings ›** 会打开用于更改这些值的页面。

页眉按钮如下：

- **项目报表**会以 **PDF文档**或**交互式HTML**形式生成项目报表。
- **导出归档**会将项目保存为归档。
- **刷新**会重新加载页面上的磁贴和列表。

## 变量

**变量**页面以网格形式列出项目的变量。工作流或步骤通过名称以 `{name}` 引用变量，且工作流自身的变量会覆盖同名的项目变量。

网格显示**名称**、**值**、**备注**、**最后更新**和**操作者**。使用**筛选器**缩小列表范围，使用**新建变量**添加变量，对所选行使用**编辑**或**删除**。

## 计划与传感器

![计划与传感器页面，包含摘要栏和两个网格](/images/projects/project-home-schedules.png)

此页面显示哪些内容会自动启动项目的工作流。摘要栏显示下次运行、处于活动和已暂停状态的计划数量，以及处于活动状态的传感器数量。

- **计划**按时间表运行工作流。网格显示**名称**、**工作流**、**运行次数**（时间表及其时区）、**下次运行**和**状态**。
- **传感器**在有新数据到达时运行工作流。网格显示**名称**、**Watches**、**开始**（工作流）、**Last triggered** 和**状态**。

**状态**为 **Active**、**Paused**，或者对于出现问题的传感器为 **Failing**。每个网格都有 **New schedule** 或**新建传感器**，以及**编辑**、**删除**和**筛选器**。打开**操作**可对所选行执行 **Activate** 或 **Deactivate**。

**Calendar view** 在日历上显示即将进行的运行，便于发现计划冲突。

## 访问与共享

此页面设置谁可以访问项目及其数据。

- **Project access** 设置 **Who can open this project**：**所有工作区成员**、**仅限指定安全组**或**仅限指定成员**。**Edit groups ›** 和 **Edit members ›** 会打开可供选择的列表。
- **Dashboard audience** 设置 **Default audience for new dashboards**：项目中的所有人，或特定分组。每个仪表板可以更改自己的受众。请参阅[控制谁可以查看仪表板](/zh-cn/guides/dashboards/control-who-can-see-a-dashboard/)。
- **数据共享**列出可以读取此项目中表的项目。请参阅[在项目之间共享数据](/zh-cn/guides/projects/managing-projects/#在项目之间共享数据)。

## 数据与连接

![数据与连接页面，包含连接、表存储和 ERP 过账](/images/projects/project-home-data.png)

除非工作流或步骤自行设置，否则这些设置适用于项目中的每个工作流和步骤。

- **连接环境**用于选择步骤在未指定时所使用的凭据。如果项目中的某个连接没有针对所选环境的配置，页面会给出警告。
- **默认文档账户**用于选择步骤读取和写入文件的位置。
- **默认表存储**用于选择新建表的创建位置。
- **Time travel retention** 设置表数据的早期版本保留的天数。继承此设置的表也会保留更长的历史记录。已经过期的历史记录无法恢复。
- **过账模式**设置项目向已连接的 ERP 发送日记账分录的方式。它是项目的上限：工作流运行的过账宽松程度不能超过此设置。**实时**为正常过账。**模拟**会构建并验证，但从不过账，也不联系 ERP。**关闭**会跳过过账步骤。
- **Write authorizations** 显示已授权用于过账的 ERP 连接数量。管理员可以单击 **Manage authorizations ›**。

## 应用与品牌设置

此页面涵盖基于项目数据构建的应用。

- **Panel 应用**显示基于项目构建的应用数量。**Open Panel apps ›** 会打开这些应用，**新建 Studio 应用**会创建一个新应用。
- **Branding** 设置项目的应用所使用的徽标和颜色。**Edit branding ›** 会打开设置。
- **Home tile image** 是显示在主页上项目磁贴中的图片。单击**选择...**可选取图片，单击**清除**可将其移除。
