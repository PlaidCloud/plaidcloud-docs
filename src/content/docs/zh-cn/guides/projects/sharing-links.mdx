PlaidCloud 会让地址栏与您打开的内容保持同步。打开工作流、表、维度，或仪表板、文档、身份中的某个屏幕后，URL 就会成为指向它的**深层链接**：复制该 URL，粘贴到消息或工单中，打开它的人就会进入同一个屏幕。

## 复制链接

1. 打开要共享的屏幕：项目、工作流、表、维度、数据编辑器，或其他应用中的某个屏幕。
2. 从浏览器的地址栏复制完整的 URL。
3. 发送出去。

没有单独的“共享”按钮：地址栏*就是*链接。浏览器的书签功能同样适用于这些 URL，因此经常返回的屏幕可以像其他网页一样加书签。

<Aside type="note">
链接只携带*位置*，不包含查看权限。打开链接的人仍然需要拥有该项目的访问权限。没有访问权限的人将看不到该对象。

指向对方没有的应用（因为其工作区不包含该应用，或尚未获得授权）的链接，会将其带到主页并附带一条说明链接不可用的提示，而不是看起来毫无反应。
</Aside>

## 可以链接到什么

### Analyze

| 屏幕 | 链接结尾 |
|---|---|
| 项目 | `#p~<project>` |
| 工作流（步骤网格） | `#p~<project>~w~<workflow>` |
| 工作流（可视化工作流设计器画布） | `#p~<project>~c~<workflow>` |
| 工作流内的某个步骤 | `…~w~<workflow>~s~<step>` 或 `…~c~<workflow>~s~<step>` |
| 单独的步骤 | `#p~<project>~s~<step>` |
| 表资源管理器 | `#p~<project>~t~<table>` |
| 维度层次结构 | `#p~<project>~d~<dimension>` |
| 数据编辑器 | `#p~<project>~e~<editor>` |
| 主页 | `#home` |

当项目有自定义**架构**时，链接中的项目部分就是该架构，因此链接形如 `#p~acme_budget~w~…`，而不是一长串十六进制字符。使用默认架构的项目则改用项目自身的标识符。两种形式打开的是同一个项目，因此设置架构后，较早的链接仍然有效。

### 仪表板、文档和身份

其他应用中的屏幕直接以名称标识，因此它们的链接读起来就是屏幕本身：

| 应用 | 屏幕 | 链接 |
|---|---|---|
| 仪表板 | 仪表板 | `#dashboard.dashboards` |
| 仪表板 | 应用 | `#dashboard.panel_apps` |
| 仪表板 | 笔记本 | `#dashboard.jupyterlite_deployments` |
| 文档 | 管理 | `#document.accounts` |
| 文档 | 您的账户 | `#document.your_accounts` |
| 文档 | 浏览某个账户的文件 | `#document.browser~…` |
| 身份 | 成员 | `#identity.members` |
| 身份 | 目录 | `#identity.member_directory` |
| 身份 | 分发列表 | `#identity.distro.lists` |
| 身份 | 安全组 | `#identity.security_groups` |
| 身份 | 组审核 | `#identity.security_group_audit` |
| 身份 | 所有范围 | `#identity.scopes` |
| 身份 | 会话 | `#identity.sessions` |
| 身份 | API 客户端 | `#identity.api_client_list` |
| 身份 | 安全日志 | `#identity.security_log` |

有些屏幕会在链接中记住某项设置：成员和成员目录列表各自记住您当时查看的是**全部**、**仅活动**还是**仅显示未激活**，浏览账户则记住是哪个账户，浏览器会将其显示为屏幕名称后的编码后缀。复制并粘贴完整的 URL，即可打开您所在的屏幕；当该屏幕已经打开时再打开链接，会将该窗口置于前台，而不是再叠加一个窗口。

<Aside type="note">
这些链接指向的是屏幕，而不是屏幕内的某条记录。指向成员的链接会打开成员列表，而不会打开某个成员的表单。
</Aside>

## 他人打开链接时会发生什么

- **所属项目也会打开。** 指向工作流、表、步骤、维度或数据编辑器的链接，还会将其所属项目作为屏幕底部的选项卡打开，因此接收者看到的是完整的上下文，而不是一个孤零零的窗口。
- **步骤链接会选中该步骤。** 指向工作流内某个步骤的链接会打开该工作流并高亮显示该步骤；在可视化工作流设计器画布上，该步骤的节点会被选中。
- **维度**在项目未锁定时以可编辑状态打开，在项目锁定时以只读状态打开，这与从项目中打开时适用的规则相同。
- **刷新后仍停留在原处。** 重新加载页面会重新打开链接所指向的内容，而不是让您回到起点。

## 在屏幕之间切换

URL 会跟随您正在查看的内容：

- 打开屏幕会更新地址栏，浏览器的**返回**按钮会带您回到上一个屏幕。
- **无论通过何种方式到达。** 从活动流、主页卡片、**钻取到工作流**操作、“使用位置”列表或日志中打开工作流，都会像从项目的工作流列表中打开一样更新链接，重新打开您已在查看的屏幕同样如此。
- 选择屏幕底部的窗口选项卡，会将该窗口的链接放回地址栏，因此在已打开的屏幕之间切换时，URL 始终保持准确。
- 切换到没有打开任何可链接内容的应用时，会**清除**链接，而不是让它继续指向您刚离开的应用。
- 关闭窗口会将 URL 恢复为您打开它时所在的位置。关闭从工作流画布打开的表，URL 会回到该画布；关闭从项目打开的表，则回到该项目。
- 关闭某个项目的最后一个窗口会清除链接。

## 此更改之前保存的链接

较早的 `#te?p=…&t=…` 样式的链接仍然有效。打开此类链接会将您带到同一位置，并悄悄将地址栏改写为当前形式，因此从那里重新复制，就能得到更新且更易读的链接。
