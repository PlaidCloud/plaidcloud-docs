文档浏览器是双窗格拆分视图：左侧是文件夹树，右侧是文件列表。工具栏带有标签，每一行都有 **⋯** 菜单，大多数操作也可以通过任一窗格中的右键菜单执行。右键菜单会根据所选的是文件夹、文件还是空白区域而显示不同的选项。

账户的根目录本身就是一个可查看的文件夹，左侧的拖放区会直接上传到其中。


**打开文件资源管理器：**

1. 转到**文档 > 浏览**。它会打开您收藏的账户；如果没有收藏的账户，则打开工作区的默认账户。可从页眉中的列表选择其他账户。或者转到**文档 > 您的账户**，双击该账户所在的行，或使用其**打开**图标
2. 若要从已固定的文件开始，请在**概览**的**已固定**中选择该文件。**浏览**会在其所在文件夹处打开，并选中该文件

### 弹出

页眉中的 **Pop out** 会在新的浏览器选项卡中打开当前账户和文件夹，这样在其他页面中工作时仍可保持打开一个浏览器。每个选项卡都保留各自的选择，因此不会跨选项卡传递任何内容。如果在关闭选项卡时上传或导入仍在运行，浏览器会要求您确认。

下面详细介绍各种文件和文件夹操作。


## 上传文件

**拖放：**

1. 浏览到所需的目录
2. 将一个或多个文件从桌面拖到拖放区：左侧的拖放区上传到账户的根目录，右侧的拖放区上传到所选文件夹中

**通过右键菜单：**

1. 浏览到所需的目录
2. 在文件列表中右键单击并选择 `Upload Here`
3. 在操作系统的文件选取器中选择文件

**通过工具栏：**

1. 浏览到所需的目录
2. 单击右侧窗格中的 `Upload` 按钮

<Aside>可以一次上传多个文件。如果目标名称已存在，系统会提示您确认覆盖或取消。</Aside>

文件列表下方的两个虚线拖放区标明了拖放内容将上传到的文件夹：左侧是账户根目录，右侧是所选文件夹。

### 上传和导入面板

文件传输期间，**Uploads and imports** 面板会显示在浏览器下方，没有内容可显示时会自动隐藏。每个上传和每个导入到表的任务各占一行，每行包含名称、状态以及适用的操作：

- 正在运行的上传会显示进度条和**取消**。**全部取消**会停止所有正在运行的上传。
- 失败的上传带有**重试**和**关闭**。它会一直保留，直到您将其关闭，以便您查看失败原因。
- 已完成的上传会在几秒后自动关闭。
- 导入到表的任务会一直保留，直到您将其关闭。完成后，您可以继续使用**预览 ›**、**创建步骤 ›**或**打开步骤 ›**。**停止关注**会停止跟踪仍在运行的导入；导入本身不会被取消。


## 下载文件

1. 浏览到所需的目录
2. 左键单击选择所需的文件
3. 右键单击并选择 `Download`


## 重命名文件

1. 浏览到所需的目录
2. 左键单击选择所需的文件
3. 右键单击并选择 `Rename`


## 移动文件

1. 浏览到所需的目录
2. 左键单击选择所需的文件
3. 拖到目标文件夹中
4. 选择 `Move File`


## 复制文件

1. 浏览到所需的目录
2. 左键单击选择所需的文件
3. 右键单击并选择 `Copy`


## 删除文件

1. 浏览到所需的目录
2. 左键单击选择所需的文件
3. 右键单击并选择 `Delete`


## 创建文件夹

1. 打开账户
2. 单击 `New Top Level Folder`（或右键单击现有文件夹并选择 `New Folder`）
3. 输入文件夹名称
4. 单击 `Create`


## 重命名文件夹

1. 浏览到所需的目录
2. 左键单击选择所需的文件夹
3. 右键单击并选择 `Rename`


## 移动或复制文件夹

1. 浏览到所需的目录
2. 左键单击选择所需的文件夹
3. 拖到目标文件夹中
4. 选择 `Move Folder` 以移动文件夹，或选择 `Copy Folder` 将原文件夹保留在原处

无论哪种方式，文件夹及其中的所有内容都会一并转移。


## 删除文件夹

1. 浏览到所需的目录
2. 左键单击选择所需的文件夹
3. 右键单击并选择 `Delete`


## 下载文件夹内容（zip 文件）

`Download as Zip` 选项会将所选文件夹下的所有文件压缩为单个 `.zip` 并下载。该归档会保留资源管理器中显示的文件夹结构。

1. 浏览到所需的目录
2. 左键单击选择所需的文件夹
3. 右键单击并选择 `Download as ZIP`


## 只读账户

如果账户被标记为只读，上传相关的界面元素（拖放提示、工具栏中的 `Upload` 按钮以及 `Upload Here` 上下文菜单）会自动隐藏。浏览、下载和搜索仍然可用。


## 搜索

若要在整个账户中查找文件，包括跨多个子文件夹或跨多个已连接的账户，请参阅[搜索文档](../searching-documents/)。
