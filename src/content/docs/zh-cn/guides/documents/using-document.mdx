文档浏览器是双窗格拆分视图：左侧为文件夹树，右侧为文件列表。大多数操作都可以通过任一窗格中的右键菜单完成。右键菜单会根据所选的是文件夹、文件还是空白区域而显示不同的选项。

账户的根目录本身也是可查看、可拖放的文件夹：单击它会显示顶层的所有内容，并接受拖放上传。


**打开文件资源管理器：**

1. 转到 **Document > 共享账户**（或 **Private Accounts**）
2. 单击要浏览的账户最左侧的文件夹图标，或双击该账户所在的行

下面详细介绍各种文件和文件夹操作。


## 上传文件

**拖放：**

1. 浏览到所需目录
2. 将一个或多个文件从桌面拖到文件列表上

**通过右键菜单：**

1. 浏览到所需目录
2. 在文件列表中右键单击，然后选择 `Upload Here`
3. 在操作系统的文件选择器中选取文件

**通过工具栏：**

1. 浏览到所需目录
2. 单击右侧窗格上的 `Upload` 按钮

<Aside>可以同时上传多个文件。如果目标名称已存在，系统会提示您确认覆盖或取消。</Aside>


## 下载文件

1. 浏览到所需目录
2. 左键单击以选择所需文件
3. 右键单击并选择 `Download`


## 重命名文件

1. 浏览到所需目录
2. 左键单击以选择所需文件
3. 右键单击并选择 `Rename`


## 移动文件

1. 浏览到所需目录
2. 左键单击以选择所需文件
3. 拖到目标文件夹中
4. 选择 `Move File`


## 复制文件

1. 浏览到所需目录
2. 左键单击以选择所需文件
3. 右键单击并选择 `Copy`


## 删除文件

1. 浏览到所需目录
2. 左键单击以选择所需文件
3. 右键单击并选择 `Delete`


## 创建文件夹

1. 打开账户
2. 单击 `New Top Level Folder`（或右键单击现有文件夹并选择 `New Folder`）
3. 输入文件夹名称
4. 单击 `Create`


## 重命名文件夹

1. 浏览到所需目录
2. 左键单击以选择所需文件夹
3. 右键单击并选择 `Rename`


## 移动或复制文件夹

1. 浏览到所需目录
2. 左键单击以选择所需文件夹
3. 拖到目标文件夹中
4. 选择 `Move Folder` 以移动文件夹，或选择 `Copy Folder` 以保留原文件夹

无论哪种方式，文件夹及其中的所有内容都会一并转移。


## 删除文件夹

1. 浏览到所需目录
2. 左键单击以选择所需文件夹
3. 右键单击并选择 `Delete`


## 下载文件夹内容（zip 文件）

`Download as Zip` 选项会将所选文件夹下的每个文件压缩为单个 `.zip` 并下载。该压缩包保留资源管理器中显示的文件夹结构。

1. 浏览到所需目录
2. 左键单击以选择所需文件夹
3. 右键单击并选择 `Download as ZIP`


## 只读账户

如果账户被标记为只读，上传相关的入口（拖放提示、工具栏上的 `Upload` 按钮和 `Upload Here` 上下文菜单）会自动隐藏。浏览、下载和搜索仍然可用。


## 搜索

要在账户中查找文件，包括跨多个子文件夹或多个已连接账户查找，请参阅[搜索文档](../searching-documents/)。
