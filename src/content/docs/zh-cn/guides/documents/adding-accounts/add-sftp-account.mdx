## SFTP 服务器设置

请向 SFTP 服务器管理员获取以下信息：

1. SFTP 服务器的**主机名或 IP 地址**
2. **SSH 端口**（默认为 `22`）
3. 有权访问目标目录的**用户名**
4. 用于身份验证的**密码**或 **SSH 私钥**
5. 可选：用于严格主机验证的**服务器 SSH 主机密钥指纹**

现在，您已具备将 SFTP 账户添加到 PlaidCloud 文档所需的全部信息。


## PlaidCloud 文档设置

1. 登录 PlaidCloud
2. 选择新文档账户所在的工作区
3. 转到 `Document > Manage Accounts`
4. 选择 `+ New Account` 按钮
5. 选择 `Secure File Transfer (SFTP)` 作为服务类型
6. 填写名称和说明
7. 在**起始路径**字段中输入远程目录路径（例如 `/data/uploads`）
8. 根据使用场景选择合适的**安全模型**。不确定时保留 `Private`。
9. 在身份验证凭据下的 Public Key/User 字段中输入**用户名**
10. 在身份验证凭据下的 Private Key/Password 字段中输入**密码**
11. 切换到 **SSH 配置**选项卡
12. 输入 SFTP 服务器的**主机或 IP 地址**
13. 输入 **SSH 连接端口**（默认为 `22`）
14. 如果使用基于密钥的身份验证而不是密码，请将 **RSA 私钥**粘贴到 RSA Private Key 字段。提供私钥后，私钥优先于密码。已保存的密钥不会再次显示；要改回密码身份验证，请选择**清除已保存的密钥（使用密码）**。
15. 可选：粘贴 **Remote Server RSA Fingerprint** 以进行严格的主机密钥验证。留空则在首次连接时自动填充。
16. 选择“保存”按钮，新的文档账户即可使用

<Aside>保存之前，可以使用 SSH 配置选项卡上的**测试 SSH 连接**按钮测试 SSH 连接。</Aside>
