文档不会自行备份账户的文件。要保留它们的第二份副本（例如保存在另一家云提供商的账户中），请使用工作流复制这些文件，并按计划运行该工作流：

1. 创建工作流，并加入 [Copy Document Directory](/zh-cn/reference/workflow-steps/document/copy-document-directory/) 步骤。
2. 在 **Copy Directory** 下，选择要备份的账户和文件夹。
3. 在 **Select Destination** 下，选择要复制到的账户，以及存放副本的文件夹。
4. 将工作流安排为按计划运行，例如每晚运行。请参阅[计划工作流](/zh-cn/get-started/tutorials/schedule-a-workflow/)。

多个账户可以共用一个备份账户：勾选 **Rename the Copied Folder to:**，并以其来源账户命名，为每份副本指定各自的名称，这样它们的文件夹就不会冲突。

<Aside type="caution">Copy Document Directory 会覆盖目标位置中任何同名的内容，因此每次运行都会替换上一份副本，而不是保留副本的历史记录。</Aside>
