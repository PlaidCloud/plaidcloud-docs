账户有四种访问限制类型可用：私有、工作区、仅限成员和安全组。为用户设置的限制类型可随时在账户表单中编辑。

<Aside>任何账户访问级别都不会泄露用于访问文档的账户凭据。只有账户所有者才能查看凭据。</Aside>

## 更新账户访问


1. 在 PlaidCloud 中选择 `Document > Manage`
2. 打开要更改的账户，然后选择**编辑**
3. 在 `Security Model` 下选择所需的访问级别限制
4. 选择“保存”按钮

<Aside>根据所选的安全模型，可以通过**管理**中账户行上的**谁可以使用**菜单，或账户页面上的**访问**卡片，以不同的选项分配允许访问的成员或安全组。</Aside>


## 限制选项


### 所有工作区成员


这是最简单的访问方式，它向工作区的所有成员提供访问权限，无需额外分配成员。



### 仅限指定成员


此访问设置需要将每个成员分别分配给账户。若与单点登录中根据随身份验证发送的组列表分配成员的选项结合使用，此选项尤其有用。不过，对于成员数量很多的工作区，这种方式往往需要投入超出预期的精力，这时安全组就能派上用场。要仅限指定成员访问：


1. 在**管理**中打开账户的行菜单，选择**谁可以使用**，然后选择**成员**
2. 将所需成员从左侧的 `Unassigned Members` 列拖到右侧的 `Assigned Members` 列
3. 要移除成员，执行相反的操作
4. 选择“保存”按钮

### 仅限指定安全组


使用此选项时，账户的访问权限授予指定的安全组，而不仅仅是个人。当访问限制依赖于与一个或多个安全组的关联时，用户数量大得多的账户管理也会变得简单得多。要编辑已分配的组：


1. 在**管理**中打开账户的行菜单，选择**谁可以使用**，然后选择**组**
2. 将所需的组从左侧的 `Unassigned Groups` 列拖到右侧的 `Assigned Groups` 列
3. 要移除组，执行相反的操作
4. 选择“保存”按钮

### 远程代理


PlaidLink 代理经常使用文档账户来存储文件或在系统之间移动文件。要允许远程代理访问文档账户，必须为代理授予权限。这是一项安全功能，用于限制对潜在敏感信息的不必要访问。要添加代理：


1. 在**管理**中打开账户的行菜单，选择**谁可以使用**，然后选择**代理**
2. 将所需代理从左侧的 `Unassigned Agents` 列拖到右侧的 `Assigned Agents` 列
3. 要移除代理，执行相反的操作
4. 选择“保存”按钮
