账户有四种访问限制类型可用：私有、工作区、仅限成员和安全组。为用户设置的限制类型可随时在账户表单中编辑。

<Aside>任何账户访问级别都不会泄露用于访问文档的账户凭据。只有账户所有者才能查看凭据。</Aside>

## 更新账户访问


1. 在 PlaidCloud 中选择 `Document > Manage Accounts`
2. 对要更改的账户进入编辑模式
3. 选择位于 `Security Model` 下的所需访问级别限制
4. 选择“保存”按钮

<Aside>根据所选的安全模型，在“管理账户”下的账户列表中，分配允许访问的成员或安全组时会有不同的选项。</Aside>


## 限制选项


### 所有工作区成员


此访问方式最为简单，因为它向工作区的所有成员提供访问权限，无需再分配任何成员。



### 仅限指定成员


此访问设置要求将每个成员分配到账户。当与单点登录中根据认证时发送的分组列表分配成员的选项结合使用时，此选项尤其有用。不过，对于成员数量众多的工作区，这种方式往往需要付出比预期更多的精力，此时安全组就派上用场了。要仅选择指定成员：


1. 在“管理账户”列表中选择成员图标
2. 将所需成员从左侧的 `Unassigned Members` 列拖到右侧的 `Assigned Members` 列
3. 要移除成员，请执行相反的操作
4. 选择“保存”按钮

### 仅限指定安全组


使用此选项时，访问账户的权限授予指定的安全组，而不只是个人。由于访问限制依赖于与一个或多个安全组的关联，管理用户数量大得多的账户会变得简单得多。要编辑已分配的分组：


1. 在“管理账户”列表中选择分组图标
2. 将所需分组从左侧的 `Unassigned Groups` 列拖到右侧的 `Assigned Groups` 列
3. 要移除分组，请执行相反的操作
4. 选择“保存”按钮

### 远程代理


PlaidLink 代理经常使用文档账户来存储文件或在系统之间移动文件。要允许远程代理访问文档账户，必须向代理授予权限。这是一项安全功能，用于限制对潜在敏感信息的不必要访问。要添加代理：


1. 在“管理账户”列表中选择代理图标
2. 将所需代理从左侧的 `Unassigned Agents` 列拖到右侧的 `Assigned Agents` 列
3. 要移除代理，请执行相反的操作
4. 选择“保存”按钮
