## 复制步骤


复制步骤通常比每次从头开始更方便。PlaidCloud 支持在同一工作流内、不同工作流之间，甚至在其他项目之间复制步骤，还可以一次选择多个步骤进行复制。在层次结构中选择工作流步骤，然后单击表格顶部的 **复制所选项** 按钮。



所选步骤会被放入剪贴板，随后可粘贴到当前工作流或其他工作流中。

剪贴板保存在浏览器中，因此重新加载页面后仍然有效，并且在您打开的所有 PlaidCloud 标签页之间共享。可以在一个标签页中从某个项目复制，切换到另一个标签页中的项目，然后在那里粘贴。剪贴板不会在不同浏览器之间、不同机器上的浏览器之间共享，也不会与其他任何人共享，切换工作区会清空剪贴板。

所有可以复制步骤的位置共用同一个剪贴板，包括步骤表、按住 Ctrl（或 Cmd）打开工作流时进入的旧版表格，以及高级工作流画布，因此可以在其中任何一处复制，并在其中任何一处粘贴。可以从表格中复制若干步骤并粘贴到高级画布上，反之亦然，用的是同一个剪贴板。



复制步骤会在项目内生成一个重复的步骤，即拥有自己配置、独立于原步骤的新步骤。

同一个步骤在任一工作流的结构中最多只能出现一次。**追加** 和 **插入** 始终粘贴全新的副本，因此不会遇到这一限制。而粘贴对已放置步骤的 *引用*（见下文 **粘贴为链接步骤**）则不同：它是同一个步骤，因此将其粘贴到已包含该步骤的工作流中（包括复制来源的工作流）会被拒绝，并给出指明该步骤的提示信息。请改为将其链接到 *另一个* 工作流。



## 粘贴步骤


选择要复制的步骤并将其放入剪贴板后，可以将这些步骤粘贴到同一工作流或另一个工作流中，甚至可以粘贴到其他项目中。将步骤粘贴到工作流时有两个选项：


* 追加到工作流末尾
* 插入到最后一个所选行之后

追加选项只是将步骤追加到所选工作流的末尾。插入选项会将复制的步骤插入到所选行之后。请注意，如果剪贴板中的多个步骤来自工作流的多个区域，粘贴时会按顺序粘贴，但不会保留它们被复制时的嵌套层次结构信息。粘贴结果只是一个平铺的步骤列表。这可能出乎意料，但比在目标工作流中重建源工作流中存在的全部目录结构更安全。


## 粘贴为链接步骤


**粘贴 → 添加链接步骤（高级）** 会在目标工作流中放置 *同一个* 步骤，而不是它的副本。两处放置的是同一个步骤：在任一工作流中编辑它，两处都会随之改变，因为需要修改的只有一个步骤。


链接步骤只能粘贴到复制来源所在的项目中。链接是对项目所拥有步骤的第二次放置，因此在该项目之外没有意义：如果粘贴到其他项目，PlaidCloud 会拒绝并提示改用 **追加** 或 **插入**，它们会将步骤作为目标项目自己的步骤复制进去。

链接步骤同样不能放入已包含它的工作流中，因为那会使同一个步骤在一个工作流的结构中出现两次，PlaidCloud 会拒绝这样做。如果某次链接操作看似失败而您又重试，最容易遇到这种情况：第一次尝试实际上已经成功，重试会被拒绝，而不是破坏工作流。错误信息会指明该步骤，以便确认它已在其中。


## 在高级画布上复制和粘贴


在高级工作流中，可以使用键盘直接在画布上复制和粘贴步骤，步骤之间的链接也会一并带过去。


选择所需步骤：拖动框选，或单击一个步骤后按住 Shift 或 Ctrl/Cmd 单击以添加更多，然后按 **Ctrl/Cmd+C**。转到要放入这些步骤的工作流（可以在本项目或其他项目中），指向目标位置，然后按 **Ctrl/Cmd+V**。步骤会按原有布局复制进来，并保持选中状态，以便拖动到合适位置。也可以不用键盘完成这两个操作：在画布空白处右键单击，然后选择 **复制 N 个步骤**（选中步骤时显示）或 **在此粘贴 N 个步骤**（剪贴板中有步骤时显示），粘贴的步骤会落在您单击的位置。剪贴板中有步骤时，工具栏会显示“来自 *工作流* 的 N 个步骤”以及一个 **粘贴** 按钮，用于粘贴到当前所见画布区域的中间。


**分组会作为分组粘贴过来。** 单击分组的标题即可同时选中该分组及其所有步骤；复制后，分组框及其成员会作为一个整体粘贴进来。用框选完整框住整个分组，也会以同样方式选中它。


**被复制步骤之间的链接会一并带过来；指向未被复制步骤的链接则不会。** 所选步骤中，如果有步骤的输入来自被留下的步骤，则它粘贴后不带该传入链接，因为另一端没有可连接的对象。发生这种情况时，粘贴操作会给出提示，因此链接丢失绝不会悄无声息。


**粘贴到同一工作流** 时，副本会略有偏移，以免恰好落在原步骤上方。粘贴到非高级工作流（即普通步骤表）时，会丢弃画布布局和链接，仅添加步骤，粘贴操作会提示已这样处理。


**大批量粘贴会自动分批完成。** 没有数量上限，也不会静默丢弃任何内容：粘贴数百个步骤时，只会在处理过程中显示进度，并且可以取消。如果粘贴无法完成，已添加的步骤会被再次移除，不会留下粘贴了一半的工作流；在少数情况下，其中一些步骤无法自动移除，此时提示信息会说明这一点并指出剩余数量，而不是声称已完全回滚。


**要撤销粘贴，** 请在粘贴后立即按 **Ctrl/Cmd+Z**，粘贴的步骤将被移除。一旦协作者修改了工作流，或者您重新加载了工作流，这种一步撤销就会失效，以免误删已不再只属于您的工作成果。


步骤是作为各自独立的新步骤复制的。把 *同一个* 步骤粘贴到多个位置（即上文的链接步骤行为）是步骤表中的操作；在画布上，请使用 **添加步骤** 将引用放入尚未包含该步骤的工作流。
