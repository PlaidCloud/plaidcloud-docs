创建新工作流需要已有项目。如果还没有项目，请参阅[管理项目](/zh-cn/guides/projects/managing-projects/)。

## 步骤

1. 打开要包含该工作流的项目。
2. 切换到 **工作流** 选项卡。
3. 单击工具栏中的 **新建工作流**。
4. 填写表单：
   - **名称**：简短且具有描述性（例如“月度结账 — 加载实际数”）
   - **备注**：可选的较长说明，用于补充背景信息
   - **工作流类型**：标准串行（默认）、标准并行或高级（DAG 画布）。请参阅下文的[选择工作流类型](#选择工作流类型)。
   - **出错时触发修正工作流**：可选；启用后可选择一个修正工作流（请参阅下文的[关于修正工作流](#关于修正工作流)）。
5. 单击 **创建**。

工作流会出现在“工作流”选项卡中，随时可以向其中添加步骤。双击它即可打开[工作流资源管理器](/zh-cn/guides/workflows/workflow-explorer/)并开始构建。

## 查看源表最后一次更改的时间

在步骤表单中，表选择器会在所选表下方显示一行灰色的 **最后更新时间**，包含日期和时间（按您的本地时间），方便一眼判断数据是否为最新。将鼠标悬停在该行上可查看完整文本。当所选内容为动态选择，或该表从未更新过时，此行会隐藏。

## 选择工作流类型

创建工作流时选择的 **工作流类型** 决定了其步骤的排列和运行方式。默认值为 **标准串行**，可在“新建工作流”表单的类型选择器中设置。

| 类型 | 步骤的排列和运行方式 |
|------|--------------------------------|
| **标准串行** | 步骤从 **步骤列表** 运行，按顺序逐个运行。 |
| **标准并行** | 步骤从 **步骤列表** 运行，在依赖关系允许的情况下并行运行。 |
| **高级（DAG 画布）** | 步骤布置在 **可视化画布** 上，按依赖顺序运行，相互独立的分支并行运行。高级类型还提供断点、容器、从此处运行、模拟和实时协作功能。 |

第四种类型 **宏** 是带有已声明输入和输出的可复用、可调用工作流，即将推出，目前在选择器中显示为禁用。

:::note
同一个步骤在一个工作流中只能出现一次。如果插入、复制、克隆或导入步骤会使其第二次出现在同一工作流中，该操作会被拒绝并指明该步骤，因此今后不会再产生这种状态。如果此项修复之前的某个工作流仍有步骤出现在两处，则 **标准串行** 运行会立即失败并给出指明重复步骤的错误；在选定结束步骤处停止的 **标准并行** 运行同样如此（请参阅[运行工作流中的一段步骤](/zh-cn/guides/workflows/running-a-range-of-steps-in-a-workflow/)），因为运行到某个结束点也是按顺序运行的。**标准并行** 运行到完成时会容忍该重复，只运行一次。无论哪种情况，删除重复的步骤即可修复工作流，删除步骤从不受限制。
:::

如果希望从一开始就使用[可视化工作流设计器](/zh-cn/guides/workflows/advanced-workflows/)，请在此选择 **高级（DAG 画布）**。这一选择并非永久：之后可以在工作流列表中使用 **转换为高级…** 将标准工作流升级。

## 关于修正工作流

如果新工作流以错误结束，PlaidCloud 可以自动运行一个 **修正工作流** 作为响应。这适用于：

- 向 Slack 频道、电子邮件分发组或 Webhook 发送通知，以便有人调查
- 触发回滚或清理工作流，恢复到已知的良好状态
- 将失败情况记录到审计表

修正工作流是可选的。现在可以留空，需要时再配置。修正工作流只在最终失败时触发，不会因单个步骤的警告而触发。
