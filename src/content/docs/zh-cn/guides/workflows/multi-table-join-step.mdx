## 描述

**多表联接**步骤可在一次操作中联接多个表。无需串联一系列双表联接（那样会丢失全局视图，还要重复相同的输出映射），您可以把所有表布置在可视化的**联接图设计器**中，在它们的列之间绘制联接，并生成一个结果表。

它针对分析联接中最常见的形态而设计：一个事实表联接多个维度表或查找表。一次最多可联接 32 个表。

<Aside type="note">此步骤取代了串联多个内联接/外联接步骤的做法。一个步骤、一张图、一次输出映射，并且可以共享查看表之间如何关联的统一视图。</Aside>

## 添加多表联接

像添加其他步骤一样添加它，并选择**多表联接**（位于步骤菜单的**表**组下，或从[高级工作流画布](/zh-cn/guides/workflows/advanced-workflows/)上的面板中拖入）。该步骤的编辑器有三个选项卡：

1. **源**：用于添加表和绘制联接的可视化设计器。
2. **列**：结果表将包含的列。
3. **筛选器**：应用于联接结果的可选筛选器。

操作时，状态指示器会显示**可以保存**或**未保存的更改**。

## 表和联接

### 添加表

选择**添加表**，将源表放到画布上。每个表显示为一张列出其列的卡片，并获得一个**别名**，这是一个简短的名称，用于在其他位置引用其列（写作 `alias.column`）。别名必须以字母或下划线开头，且不能是 SQL 关键字。可按需添加任意数量（最多 32 个），并选择结果写入的**目标表**。

如果表的列在目录中发生了变化，请使用**从服务器重新获取**，以最新值替换卡片中的列。

### 动态表和变量

源表和**目标表**都可以作为**引用**给出，而不必从列表中选择。在表选择器上勾选**动态**，然后输入以下任一内容：

- 表**名称**：`FACT_GL`
- 项目**路径**：`/03 Results/FACT_GL`

两者都可以包含 `{variable}` 标记，工作流运行时会替换这些标记，因此 `/03 Results/FACT_GL_{year}` 会在由项目变量或工作流变量驱动的每个期间写入不同的表。如果目标表不存在，则会创建。

<Aside type="note">动态**源**无法在设计时读取其列，因为在运行之前并不知道它指向的是哪个表。卡片会显示为空，您需要在侧边面板中手动添加其列，联接则根据这些列绘制。动态**目标**没有这种限制。</Aside>

不匹配的大括号会在保存时被捕获，因此输错的 `FACT_{year` 会在步骤上报告，而不是在运行到一半时失败。

### 绘制联接

从一个表的列圆点拖到另一个表的列上，即可创建**联接**（一条边）。选择一条边即可在右侧打开其编辑器，您可以在其中设置：

- **联接类型：**

  | 类型 | 保留内容 |
  |------|-------|
  | **INNER** | 仅保留匹配的行 |
  | **LEFT** | 左表的所有行 |
  | **FULL** | 两侧的所有行 |
  | **CROSS** | 每个左行与每个右行的组合（无条件） |

- **联接条件**：两个表的列之间的一个或多个比较。使用 **+ 添加条件**可添加更多条件，用 **AND** / **OR** 组合，并可使用全套运算符（`=`、`<>`、`<`、`<=`、`>`、`>=`、`BETWEEN`、`IS NULL`、`IS NOT NULL`、`IN`、`NOT IN`、`LIKE`、`NOT LIKE`）。
- **标签（可选）**：为联接命名（例如 `customer-to-orders`），使图表更易阅读。

设计器将联接图保持为一棵树：每个表恰好通过一个联接接入结果，因此不会有环或含糊的路径，表也不能与自身联接。要移除联接，请选中该边并选择**删除边**。

### 在联接之前筛选表

每个源表都有一个在联接*之前*应用的**入站筛选器**，可用它把表缩减为您关心的行（以 `alias.column` 引用其列）。这与在所有联接*之后*运行的 **Post-Join Filter** 是分开的。

### 设计器工具栏

- **整理布局**会按联接顺序从左到右自动排列表和联接。
- 缩放级别旁的缩放按钮用于放大和缩小视图，**适应**会缩放并居中，使整张图完整显示，**1:1** 会恢复到 100%。鼠标滚轮可缩放，中键单击或按住 Shift 拖动可平移。
- 画布角落的小地图会显示整张图，并用轮廓标出当前可见的部分；在其中单击或拖动即可移到相应位置。小地图按钮可隐藏或显示它，PlaidCloud 会记住您的选择。
- 当表的列很多时，**筛选列…** 可缩小卡片上显示的列。
- **撤消** / **重做**可在您的编辑中后退和前进（Ctrl+Z / Ctrl+Y），**历史记录**会打开一个面板，列出自您打开对话框以来的每一次更改，并带有**还原**。
- 导出按钮会将联接图下载为 PDF，其菜单中有**导出为PDF**和**导出为PNG**，便于用于文档或评审。

## 输出列

在**列**选项卡上，选择结果表将包含的列。可以从任何已联接的表中选取，使用**从画布选取…** 可从所有源的列中直观地选择，或使用**添加所有源列**一次性全部带入。对于每个列，您都可以重命名、设置其数据类型并应用聚合。当两个源列同名时，PlaidCloud 会为它们加上源别名前缀，以避免冲突。

每个输出列的值恰好来自以下三处中的**一处**：

- **源列**：将**源别名**设置为拥有该列的画布别名，将**源**设置为 `alias.column` 引用。两者都是必需的，源列始终会指明其所属的表。
- **常量**：每一行都相同的固定值。
- **表达式**：选择**添加表达式列**可追加一行并打开表达式编辑器。表达式可以用 `alias.column` 引用画布上的**任何**源别名，因此可以用它构建跨多个已联接表的值（跨两个表的 `CASE`、字符串拼接、计算金额）。表达式行的**源别名**和**源**请留空。

填写其中多于一处会报错，一处也不填同样会报错。

**表达式**单元格会打开标准的 PlaidCloud 表达式编辑器，其列浏览器中包含画布上的每个表，并提供函数列表和自动完成。

输出列会跟随画布：如果您在**源**选项卡上重命名某个源，其输出列会移到新的别名下；如果移除某个源，其输出列会被删除，因此永远不会留下指向已不在联接中的表的列。

## Post-Join Filter

**Post-Join Filter** 选项卡会在联接结果写入目标表之前，对其应用可选的筛选器，相当于 SQL 的 `HAVING` 子句。单击该框可打开表达式编辑器；输出列列在其列浏览器中，您以 `result.column_name` 引用它们，此处不包含源别名。框下方的 Available references 列出了您可以使用的所有引用。留空则跳过联接后筛选。

## 验证

PlaidCloud 会在您构建联接时以及步骤运行时对联接进行验证。如果有问题，例如不受支持的配置、环、重复的别名、未设置源/常量/表达式中任何一项（或设置了多项）的输出列，或已不存在的列，选项卡上会出现带数字的 ⚠ 徽章，设计器会标出有问题的表或联接，保存会被拒绝并给出原因。带着未解决的问题保存时，会切换到包含第一个问题的选项卡；**跳转到问题**可按需执行同样的操作。

保存时，PlaidCloud 还会按步骤运行的方式，针对联接自身的输入按别名（`alias.column`）检查每个输出列表达式，并检查 Post-Join Filter。有问题的表达式会在其输出列上报告，有问题的 Post-Join Filter 会在筛选器上报告。如果联接设置了**同时带入运行时指定名称的列**且未进行汇总，则保存时会跳过表达式检查，因为列是在运行时添加的；这些表达式会在步骤运行时检查。每个源的筛选器也会在步骤运行时检查。

<Aside type="tip">`CROSS` 联接会生成所有行的组合，且没有条件。在大表上，这可能代价极高，请谨慎使用。</Aside>

## 运行步骤

多表联接与其他步骤一样运行。它在一次操作中执行所有联接，并将映射后的列写入目标表。
