某些 Alteryx 工作流创建的不只是表，还有文件和可视化输出。PlaidCloud 会将这些步骤转换为云原生工件，这些工件可存储在 Document 中，可从工作流运行历史中查看，并可供下游流程使用。

<Aside type="note">
  工件验证侧重于所生成输出的业务内容和下游可用性。PlaidCloud 生成的云原生工件专为共享、计划运行和可重复审核而设计。
</Aside>

## 工件类型

转换后的工作流可以生成或使用：

- PDF。
- 图像。
- 图表。
- 地图。
- HTML 或报表片段。
- 报表表格和布局。
- 仪表板或洞察式审核工件。
- 模型、NLP、OCR 或文本分析输出。

当转换后的工作流写入工件时，PlaidCloud 会将生成的文件存储在 Document 中。

## 验证报表内容

对于报表和 PDF，请确认：

1. 文件已在预期的 Document 路径中创建。
2. 报表包含预期的表格、标签、章节和值。
3. 图像和徽标出现在预期位置。
4. 页面级布局可满足业务用途。
5. 下游用户可以打开或分发该文件。

当确切的布局很重要时，请将 PlaidCloud 工件与可信的 Alteryx 输出进行比较。

## 验证图表和仪表板

对于图表和仪表板式输出，请确认：

1. 源数据与预期的架构、行数和值相符。
2. 度量、维度和标签正确。
3. 筛选器或参数已正确应用。
4. 生成的图表或仪表板支持预期的审核工作流。

PlaidCloud 可能会创建云原生可视化，而不是重现 Alteryx 桌面专用的渲染器。

## 验证地图

对于地图输出，请确认：

1. 空间输入已成功加载。
2. 坐标参考系行为可以接受。
3. 地图图层包含预期的记录。
4. 标签、边界和几何形状符合业务用途。
5. 任何有意的云原生工件差异均已记录。

对于数据至关重要的地图工作流，还应验证工件背后的几何表。

## 验证 OCR、PDF 和 NLP 输出

对于提取和文本工作流，请确认：

1. 已处理预期的文件。
2. 存在提取的文本、表格、得分、主题或分类。
3. 输出表与预期的架构和行数相符。
4. 值在约定的容差范围内与预期输出一致。
5. 已审核执行器说明。

## 验收记录

对于生产环境迁移，请保留验证记录，其中包括：

- 工作流名称。
- 运行日期。
- Document 输出路径。
- 预期输出来源。
- 验证级别。
- 已接受的云原生工件差异。
- 审批人。
