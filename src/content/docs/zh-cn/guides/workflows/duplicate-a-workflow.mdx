在规划重大更改或使用不同选项复制某个流程时，复制工作流会很有用。副本完全独立，修改副本不会影响原工作流。

在**工作流**表中可以执行两种操作：

* **Duplicate Selected Workflows**：在同一项目内快速原地复制
* **Clone Workflow(s)**：复制到您选择的目标项目（默认为当前项目）


## Duplicate Selected Workflows

1. 打开项目的**工作流**表
2. 选择一个或多个工作流
3. 点击工具栏中的 `Duplicate Selected Workflows`

每个副本都位于同一项目中，名称为原名称加上“ copy”后缀。


## Clone Workflow(s)

需要将工作流复制到另一个项目时使用，例如将工作流从开发项目提升到同级项目。

1. 打开源项目的**工作流**表
2. 选择一个或多个工作流
3. 打开**操作**菜单并点击 `Clone Workflow(s)`
4. 在对话框中选择**目标项目**（默认为当前项目）
5. 点击 `Clone Workflow(s)`

克隆过程中会打开一个进度对话框，显示总体进度条（第 N 个工作流，共 M 个）以及当前正在复制的工作流的逐步进度条。您可以点击 `Run in Background` 关闭对话框并继续工作，克隆会继续进行，完成后会显示通知。

克隆的工作流名称会加上“ copy”后缀，以免与目标项目中的现有内容冲突。

<Aside>克隆会复制工作流定义和步骤配置。工作流引用的项目范围资源（表、维度、连接）必须已存在于目标项目中，否则需要另行克隆这些资源。</Aside>
