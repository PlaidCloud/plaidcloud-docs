Analyze 中的 **Lakehouse** 窗口显示 Lakehouse 上正在运行的内容及其设置方式。窗口左侧的导航栏列出了它的各个页面。

| 页面 | 显示内容 |
|---|---|
| **查询** | 当前正在运行的内容以及最近运行过的内容。 |
| **性能分析** | 查询的执行计划和成本。 |
| **负载** | Lakehouse 的繁忙程度。 |
| **目录** | Lakehouse 目录的命名空间和表，以及每个表的详细信息。 |

在 **Administration** 下，导航栏列出 **Lakehouse catalogs**、**Database users** 和 **Compute**。**Database users** 和 **Compute** 仅对拥有 Lakehouse 管理员角色或 Lakehouse 集群角色的成员显示，因此没有该角色时不会列出这些页面。

## 查询

**Running now** 列出 Lakehouse 上正在运行的查询。**刷新间隔**设置窗口打开期间列表重新读取的频率。选择一个正在运行的查询，然后单击 **Stop query** 即可将其终止。

**历史记录**列出最近的查询，最新的排在最前面。可使用 **Search SQL**、**Any user**、**Any kind** 和 **Any duration** 缩小范围。单击 **Copy SQL** 可复制查询的语句。

要查看查询的运行情况，请双击该查询，或选中它后选择 **Profile this query**。窗口会在该查询的执行计划上打开**性能分析**。

## 目录

**目录**的页眉中有一个用于选择 Lakehouse 目录的选择器。选择一个命名空间以列出其中的表，然后选择一个表以打开其详细信息：

- **列**，包含每列的类型以及是否为必填。
- 当前快照的行数、大小和数据文件。
- **分区**、**位置**和**属性**。
- **历史记录**，每个快照一行，显示其时间、操作以及**新增行数**和**删除行数**。

表的元数据中没有的数值显示为 —。

### 复制时间旅行查询

在**历史记录**中的某个快照上，单击 **Copy query as of this snapshot**。这会复制一条使用 `FOR VERSION AS OF` 读取该表在该快照时状态的查询，可将其粘贴到查询屏幕中。仅默认 Lakehouse 目录支持复制。如需改为在表资源管理器中浏览或还原表的快照，请参阅[表快照](/zh-cn/guides/data/table-snapshots/)。

## Lakehouse 目录、数据库用户和计算

**Lakehouse catalogs** 列出为工作区注册的目录。目录上的**浏览**会在**目录**中打开该目录。

**Database users** 列出可以连接到 Lakehouse 的数据库用户，并可在其中添加、更改和删除这些用户。**Compute** 显示 Lakehouse 计算节点的运行状况，并提供**重启计算**，即在查询卡住时执行的滚动重启。它一次替换一个计算节点，因此在被替换节点上运行的查询会失败，而其他节点会继续处理新查询。两次重启之间有冷却时间。
