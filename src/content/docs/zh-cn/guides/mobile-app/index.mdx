借助 PlaidCloud 应用，您可以在离开办公桌时运行和监控工作流。您可以浏览项目、启动工作流或停止正在运行的工作流、查看每个步骤的状态，并回顾其运行历史记录。在应用中使用 Weave，还可以询问哪里失败了并批准修复。请参阅[移动端的 Weave](/zh-cn/guides/mobile-app/weave-on-mobile/)。

该应用是浏览器中 PlaidCloud 的配套应用，而不是独立的产品。工作流、表和仪表板在 Web 上构建，应用则用于保持它们持续运行。

## 开始之前

- **已有的 PlaidCloud 工作区及其中的账户。** 应用不提供注册功能，需由工作区管理员像往常一样在 Web 上将您添加到工作区。
- **您的工作区名称。** 它是您在浏览器中所用地址的第一部分：对于 `acme.plaid.cloud`，工作区名称为 `acme`。
- **受支持的设备：**

| 设备 | 最低版本 |
| --- | --- |
| iPhone 和 iPad | iOS 或 iPadOS 15.1 |
| Android 手机或平板电脑 | Android 7.0 |

## 安装应用

在设备的应用商店中搜索 **PlaidCloud**，或直接打开商店页面：

- **iPhone 和 iPad：** [App Store 上的 PlaidCloud](https://apps.apple.com/app/id6769620647)
- **Android：** [Google Play 上的 PlaidCloud](https://play.google.com/store/apps/details?id=com.plaidcloud.mobile)

该应用免费。

## 登录

1. 打开应用。第一个屏幕会要求输入**工作区**。
2. 输入工作区名称（例如 `acme`），然后点按**继续**。在 iPhone 和 iPad 上，也可以粘贴完整的工作区地址（例如 `https://acme.plaid.cloud/`），应用只会保留工作区名称。
3. 工作区的登录页面随即打开。它与您在浏览器中看到的页面相同，因此请按平常的方式登录：使用密码和多重身份验证代码，或者在工作区启用了单点登录时使用您所在组织的单点登录。
4. 登录完成后，您会返回应用。

两次会话之间您保持登录状态，应用会在后台续期您的登录。您的凭据只会在工作区自己的登录页面上输入，绝不会在应用本身中输入。应用针对您的工作区使用 OpenID Connect 和 PKCE 进行登录，并将生成的令牌保存在设备的安全存储中。

如果登录没有开始，或者应用提示不存在该名称的工作区，请对照您在浏览器中使用的地址，检查工作区名称的拼写。

<Aside type="note">
应用一次只登录一个工作区。要使用其他工作区，请从**设置**中切换（请参阅[切换工作区或退出登录](#切换工作区或退出登录)）。
</Aside>

## 查找工作流

**项目**选项卡列出您有权访问的项目及其说明。在列表上下拉即可刷新。

点按项目可查看其工作流，按文件夹分组。每个工作流都会显示其当前状态（例如**正在运行**、**已排队**、**已暂停**、**完成**、**错误**或**已停止**）、说明以及上次运行的结束时间。使用顶部的**搜索工作流**，可按工作流名称或说明筛选列表。

在 iPhone 和 iPad 上，应用还会打开到**主页**选项卡。**需要关注**列出上次运行失败的工作流及其错误消息，**最近**列出您最近使用过的项目。点按其中任一项可直接前往。

## 运行和监控工作流

点按工作流将其打开。屏幕顶部显示其状态以及**状态**面板，面板中包含当前或上次运行的**开始时间**和结束时间、**持续时间**以及最新的**消息**。如果工作流出错，错误消息会以红色显示。工作流运行或排队期间，屏幕会自动保持其状态为最新。

底部的控件随工作流的状态而变化：

| 工作流状态 | 控件 |
| --- | --- |
| 正在运行或已排队 | **暂停**、**停止** |
| 其他任何状态 | **运行**、**恢复** |

- **运行**从头开始启动工作流。
- **暂停**会挂起正在运行的工作流；**恢复**从停止处继续运行。修复失败的步骤后，也通过**恢复**继续工作流。
- **停止**结束本次运行。

每个控件在执行前都会要求您确认，例如“**运行此工作流？**”

在控件下方，**配置**显示工作流是否已启用、是否已锁定以及它如何处理错误，**详细信息**显示其所在文件夹和最后更新者。

<Aside type="note">
应用使用与 Web 版 PlaidCloud 相同的权限。如果您无权运行或更改某个工作流，应用会显示**操作失败**及原因，且不会发生任何更改。
</Aside>

## 查看工作流的步骤

点按工作流上的**步骤**，可查看每个步骤及其状态、类型和最新消息。不会运行的步骤会显示**已禁用**徽章，运行嵌套工作流的步骤会显示**子工作流**徽章。

列表的布局取决于工作流的类型：

- **构建为图的工作流**按运行顺序显示其步骤，左侧的线条追踪哪些步骤为哪些步骤提供输入，包括并行运行的步骤。
- **构建为步骤列表的工作流**按顺序显示步骤，并显示每个步骤所在的文件夹。

## 回顾过去的运行

点按工作流上的**运行历史记录**，可查看其近期的运行。每次运行都会显示开始时间、结束方式、耗时以及运行的步骤数。

在 iPhone 和 iPad 上，点按某次运行可查看其引发的任何步骤错误以及日志的最后 200 行，每行都带有时间、级别和步骤。

## 编辑名称、说明和设置

无需回到计算机前，就可以进行小的更改：

- 在项目或工作流上，点按屏幕顶部的**编辑**。
- 在步骤上，点按**步骤**列表中的该步骤。

在**编辑**面板中，可以更改**名称**和**说明**，并开启或关闭**已启用**和**已锁定**。点按**保存**应用更改，或点按**取消**放弃更改。更复杂的操作（更改步骤的设置、添加步骤或重新排列工作流）需要在 Web 版 PlaidCloud 中完成。

## 切换工作区或退出登录

打开**设置**选项卡。**当前工作区**显示您当前登录的工作区。

- **切换工作区**会使您退出当前工作区，并带您回到**工作区**屏幕以登录另一个工作区。
- **退出登录**会使您退出工作区。

两者都会先要求您确认。

<Aside type="note">
当前的 Android 版本包含**项目**和**设置**选项卡。**主页**选项卡以及包含错误和日志行的运行详情仅在 iPhone 和 iPad 应用中提供。
</Aside>
