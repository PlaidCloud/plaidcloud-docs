[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 和会计系统（无论有多少个实例）的数据汇集到一个 Common Finance Model 中。QuickBooks Online 是它可以直接读取的系统之一。本页面面向设置访问权限的 QuickBooks 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码或令牌。

## 发送访问请求

在**主页**的 **Data Foundation** 下打开项目的**系统**页面，在**添加系统**下的**系统**中选择您的系统，然后单击**还没有访问权限？**。该系统会进入等待访问权限状态，并显示一份涵盖项目各个系统的请求。单击**复制请求**可将其粘贴到您自己的邮件中，单击**通过电子邮件发送请求**则会在您的邮件程序中打开，邮件主题为“PlaidCloud 访问权限”。

## QuickBooks 管理员需要设置的内容

<Steps>

1. **选择 PlaidCloud 将代表其操作的 QuickBooks 用户**。在 QuickBooks 本身中，该用户需要能够查看：

   - 会计科目表、客户、供应商、产品和服务、位置以及类别
   - 总账、试算平衡表和损益表报表（可在 Reports 下运行这些报表的用户）
   - 销售交易：发票、销售收据、贷项通知单和退款收据
   - 采购和付款，如果希望将供应商、未清项和付款纳入模型：账单、供应商贷项、费用、客户付款和账单付款
   - 预算和库存估值汇总，如果希望将它们纳入模型（QuickBooks Plus 或 Advanced）

   公司管理员已具备这些权限。受限用户需要开启这些权限。

2. **一次性授权 PlaidCloud**。该用户通过 PlaidCloud 用户发给他们的连接，在 Intuit 的同意屏幕上登录。范围仅限 Accounting（`com.intuit.quickbooks.accounting`）。

3. **每个连接对应一家公司**。如果您有多家 QuickBooks 公司，请在各自的连接上分别授权。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 公司名称，即其在模型中应显示的名称 | 无需输入：连接会读取 QuickBooks 用户所授权的那一家公司 |
| 账簿是否已结账到某个日期（**Settings > Account and Settings > Advanced > Accounting**） | 无需输入：PlaidCloud 从 QuickBooks 读取结账日期 |

在项目的**系统**页面上，PlaidCloud 用户在**添加系统**下的**系统**中选择 QuickBooks Online，然后单击**连接到**加系统名称的按钮。PlaidCloud 会为项目的环境创建连接，并打开 Intuit 的授权窗口。QuickBooks 用户授权后，系统即被添加并开始加载。参见[连接您的 ERP](/zh-cn/guides/projects/data-foundation/#连接-erp)。

在 **System settings** 下，当科目名称尚未说明时，**Retained earnings account** 指定期初损益结转到的权益科目。它是可选的。

## 检查访问权限

返回 PlaidCloud，添加系统后，在**系统**页面上该系统所在的行中单击**测试连接**。它会读取必需的数据集（实体、会计科目表、财务日历、试算平衡表和总账），并将每个数据集显示为**可读取**、**缺少权限**或**错误**。可选数据集不在测试范围内：如果 QuickBooks 拒绝读取其中某项，就绪状态检查会在下次加载后指出它。各数据集读取的内容：

| 数据集 | 在 QuickBooks 中读取的内容 |
|---|---|
| 实体 | 公司信息 |
| 会计科目表 | 会计科目表 |
| 财务日历 | 公司首选项：财年的第一个月和结账日期 |
| 试算平衡表 | 试算平衡表报表，用于期初余额 |
| 总账 | 总账报表 |
| 站点 | 位置（可选） |
| 利润中心 | 类别（可选） |
| 客户 | 客户（可选） |
| 产品 | 产品和服务（可选） |
| 供应商 | 供应商及其付款条件（可选） |
| 月末余额 | 每个月末的试算平衡表报表（可选） |
| 银行余额 | 该月末试算平衡表中银行账户的余额（可选） |
| 销售明细行 | 发票、销售收据、贷项通知单和退款收据（可选） |
| 供应商发票明细行 | 账单、供应商贷项和费用（可选） |
| 未清项 | 每个月末的发票、贷项通知单、账单和供应商贷项，减去已核销的付款（可选） |
| 付款 | 客户付款和账单付款（可选） |
| 预算 | 预算（可选） |
| 库存余额 | 每个月末的库存估值汇总，前提是公司跟踪现有数量（可选） |
| 汇率 | 汇率（可选） |

当数据集显示为**缺少权限**时，测试会指出需要添加的访问权限。请管理员为该用户开启后重新测试。没有预算等可选数据的公司仍会加载其他所有内容。当 QuickBooks 拒绝了构建某个月份的余额、库存、销售、采购、未清项或付款所需的读取时，该月份会保留其已有的行，并在下次加载时重新读取。

QuickBooks 没有交易伙伴、公司间科目或账簿，因此 QuickBooks 公司的行不带这些信息。它也没有部门：其位置即站点，其类别即利润中心。
