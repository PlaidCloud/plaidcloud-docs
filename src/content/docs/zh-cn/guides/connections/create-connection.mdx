**连接**是已保存的配置，使 PlaidCloud 能够访问外部系统，例如数据库、数据湖、ERP、REST API、云服务或 Git 提供商。工作流步骤按名称引用连接，因此端点详细信息和凭据集中在一处，并可在每个需要它们的步骤和项目中重复使用。

连接在 **Tools > Connections** 中管理。

## 创建连接

1. 打开 **Tools > Connections**
2. 单击工具栏中的 `New Connection`，然后从菜单中选择要连接的系统
3. 填写连接表单（选项卡和字段因类型而异，请参阅下文的[连接表单](#连接表单)）
4. 单击 `Create` 保存

新连接会出现在列表中，所有者为您。

<Aside type="note">连接类型列表以及每种类型所需的字段，已在[连接器参考](/zh-cn/reference/connectors/)中编目。对于没有专用连接器的服务，请使用[通用 REST 连接](/zh-cn/reference/connectors/rest/generic-rest/)。</Aside>

## 连接表单

大多数连接会打开多选项卡表单。具体的选项卡取决于类型，但常见的有：

- **连接配置**（REST 为**连接详细信息**）：连接的 `Name`、可选的 `Memo`、主机/端口/数据库（REST 则为主机/身份验证类型）、`Usage` 开关（`Active`）以及 `Security Model`。在数据库连接中，凭据位于此处的**身份验证凭据**组中；在 REST 连接中，凭据有自己的**身份验证**选项卡。
- **SSL 配置**：`Use SSL` 加上 SSL 模式，以及加密连接可选的客户端/根证书。
- **SSH 配置**：`Use SSH` 加上堡垒机主机、端口、用户和密钥，用于通过 SSH 跳板主机建立隧道连接。

密码、令牌和其他凭据字段是只写的：重新打开已保存的连接时它们显示为空，保存时留空则保留已存储的机密。只有想要更改时才需要重新输入值。这涵盖 REST 连接的 API 密钥、OAuth 客户端密钥和 OAuth 刷新令牌。多行凭据同样是只写的，并在您输入或粘贴时被遮盖，包括 NetSuite 私有证书、Anaplan 证书和私钥、Postman API 密钥、Slack 或 Teams 传入 Webhook URL。仅由空格组成的替换值会被拒绝，而不会覆盖已存储的凭据；请清空该字段以保留已保存的值。SQL 或 Git 连接的 SSL 客户端密钥和 SSH 私钥也是只写的，但在您输入时保持可见。其他所有字段在显示连接的任何位置（编辑器中以及通过 API）都显示其真实的已保存值，包括名称上看起来敏感的字段（数据库的只读标志、账户标识符、模式、主机名）；只有真正的凭据才会被遮盖或隐藏。

通过 REST API 和 MCP 时，凭据字段遵循与编辑器相同的规则：发送空字符串，PlaidCloud 会保留已存储的值；发送 `null` 则清除。每个非凭据字段在您发送空值时仍会被清除。

必填字段在保存时进行验证；如果有缺失，表单会切换到包含第一个无效字段的选项卡并对其进行标记。

## 安全模型

连接上的 `Security Model` 控制工作区中谁可以使用它：

| 选项 | 谁可以使用该连接 |
|---|---|
| 私有（仅限所有者） | 仅所有者。 |
| 仅限指定成员 | 所有者加上明确列出的成员。 |
| 仅限指定安全组 | 所有者加上指定安全组的成员。 |
| 所有工作区成员 | 工作区中的所有人。 |

选择 `Specific Members Only` 或 `Specific Security Groups Only` 时，请从列表的 `Actions` 菜单授予访问权限：`Members`（用于 `Specific Members Only`）或 `Groups`（用于 `Specific Security Groups Only`），加上 `Agents` 和 `Owners`，每一项都会打开双列表选取器，用于添加和移除访问权限。只有连接的所有者或工作区管理员才能在那里更改访问权限。其他可以编辑连接的人可以打开连接查看谁有访问权限，但不能更改。工作区管理员可以更改其不拥有的连接的访问权限，以便在其所有者离开时将其移交。

## 环境

一个连接可以为每个**环境**保存不同的配置（例如，同一个连接名称下的开发主机和生产主机）。工具栏中的环境选择器用于选择要查看和编辑哪个环境的配置。

- `New Environment`：添加连接环境
- `Edit Environment`：重命名所选环境
- `Delete Environment`：移除所选环境

列表中的 `Available` 列显示所选连接是否已针对所选环境进行配置。

<Aside type="note">保存配置时会合并到该环境已存储的配置中，因此空白的只写机密绝不会被空值覆盖。</Aside>

环境与 PlaidLink 代理共享，因此项目的环境既可以切换其读取的连接，也可以切换运行其远程步骤的代理。请参阅[代理环境](/zh-cn/reference/cli/plaidlink/agents/#代理环境)。

## 编辑连接

1. 在列表中选择连接
2. 单击工具栏中的 `Edit`（或右键单击该行）
3. 更改字段并单击 `Update`

## 测试连接

测试方式取决于类型：

- **数据库连接**（Databricks、Snowflake、PostgreSQL 和 Redshift）在编辑器中有**测试连接**按钮。它使用您输入的凭据打开连接，并报告成功（及其到达的服务器版本）或失败原因，而不关闭编辑器，因此您可以就地修复并重试。
- 带 SSH 的数据库连接还在 `SSH Config` 选项卡中提供 SSH 隧道测试。
- [通用 REST 连接](/zh-cn/reference/connectors/rest/generic-rest/)有一个 `Testing` 选项卡，可通过已保存的连接发出临时请求。

测试前请先保存连接：测试针对的是已存储的配置。

<Aside type="note">**测试连接**会在某种连接类型的编辑器提供它之后出现，目前为上述数据库类型，外加 [TM1](/zh-cn/guides/connections/tm1/)、[Oracle Essbase](/zh-cn/guides/connections/essbase/)、[HFM/FCCS](/zh-cn/guides/connections/hfm-fccs/)、Salesforce 和 Anaplan。其他 REST 连接（如 NetSuite）尚不提供，请通过工作流步骤发送一个小请求来进行冒烟测试（NetSuite 请参阅[连接到 NetSuite](/zh-cn/guides/connections/netsuite/#对连接进行冒烟测试)）。</Aside>

## 克隆、删除和跟踪使用情况

- **克隆**：复制连接的配置，作为新连接的基础。请参阅[克隆连接](/zh-cn/guides/connections/clone-connection/)。
- **删除**：从工具栏中移除所选连接（系统会要求您确认）。
- **使用位置…**：列出引用该连接的工作流步骤，以便您在编辑或删除之前了解影响。

<Aside type="caution">`Edit`、`Clone` 和 `Delete` 仅适用于您拥有的连接。如果所选行的这些操作呈灰色，则说明您不是所有者：请让所有者进行更改，或让其通过 `Owners` 添加您。</Aside>
