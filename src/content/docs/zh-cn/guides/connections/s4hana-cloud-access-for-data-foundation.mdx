[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例的数据汇集到一个 Common Finance Model 中，SAP S/4HANA Cloud 是它可以直接读取的 ERP 之一。该连接使用 OAuth 2.0 客户端凭据读取租户已发布的 OData 服务，不涉及任何代理。本页面面向进行这些设置的 S/4HANA Cloud 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码或客户端密钥。

## 发送访问请求

在项目的**基础数据**选项卡上，在 **SAP S/4HANA Cloud 连接**下选择**创建新连接**。表单会显示完整的请求。单击**复制请求**可将其粘贴到您自己的邮件中，或单击**通过电子邮件发送请求**，在邮件程序中打开它，主题为“Read-only SAP S/4HANA Cloud access for PlaidCloud (OAuth 2.0 client credentials).”

## S/4HANA Cloud 管理员需要设置的内容

<Steps>

1. **为 PlaidCloud 创建通信用户**，在应用 **Maintain Communication Users** 中进行。其身份验证方法为 OAuth 2.0 或用户名和密码，视您的系统环境而定。

2. **为 PlaidCloud 创建通信系统**，在应用 **Communication Systems** 中进行，以该用户作为入站通信用户，并使用 OAuth 2.0 客户端凭据。

3. **为下面的每个场景创建通信安排**，在应用 **Communication Arrangements** 中进行，均针对步骤 2 中的系统。它们共同公开 PlaidCloud 读取的 OData 服务：

   | 场景 | 服务 |
   |---|---|
   | Company Code | `API_COMPANYCODE_SRV` |
   | G/L Account in Chart of Accounts | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | Cost Center | `API_COSTCENTER_SRV` |
   | Business Partner and Customer | `API_BUSINESS_PARTNER` |
   | Product | `API_PRODUCT_SRV` |
   | Fiscal Year Variant Periods | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | Exchange Rates | `API_EXCHANGERATE_SRV` |
   | Journal Entry Item | `API_JOURNALENTRYITEMBASIC_SRV`（日记账和结转余额） |
   | Billing Document | `API_BILLING_DOCUMENT_SRV`（可选：用于增加已开票销售额、单据和行项目） |

   请授予通信用户对您要报告的每个公司代码的访问权限。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 租户 API 的主机，例如 `my300000-api.s4hana.cloud.sap` | **主机** |
| 客户端 ID | **客户端 ID** |
| 客户端密钥，通过安全的连接表单提供 | **客户端密钥**，由您的团队自行粘贴 |
| 令牌 URL，仅当您的系统环境使用 XSUAA 授权服务器而不是租户自己的服务器（`/sap/bc/sec/oauth2/token`）时需要 | **Token URL (optional)** |
| 范围，仅在使用 XSUAA 授权服务器时需要 | **Scope (optional)** |
| 您加载的每个财年是否已运行 **Carry Forward Balances** | 无需输入。期初余额从中读取。 |

<Aside type="caution">
切勿通过电子邮件发送客户端密钥。**客户端密钥**是机密：它存储在连接上，不会再次显示。
</Aside>

## 检查访问权限

返回 PlaidCloud，输入各值并单击**测试连接**。每个数据集显示为**可读取**、**缺少权限**或**错误**：

| 数据集 | 所需服务 |
|---|---|
| 实体 | `API_COMPANYCODE_SRV` |
| 会计科目表 | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| 部门 | `API_COSTCENTER_SRV` |
| 客户 | `API_BUSINESS_PARTNER` |
| 产品 | `API_PRODUCT_SRV` |
| 汇率 | `API_EXCHANGERATE_SRV` |
| 财务日历 | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| 总账 | `API_JOURNALENTRYITEMBASIC_SRV` |
| 试算平衡表 | `API_JOURNALENTRYITEMBASIC_SRV` |
| 销售明细行 | `API_BILLING_DOCUMENT_SRV`（可选） |

当数据集显示为**缺少权限**时，请管理员添加其服务对应的通信安排后重新测试。销售明细行、预算和库存余额是可选的：不包含其中某项的租户仍会加载其他所有内容。
