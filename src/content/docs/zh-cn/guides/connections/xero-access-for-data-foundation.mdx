[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 和会计系统（无论有多少个实例）的数据汇集到一个 Common Finance Model 中。Xero 是它可以直接读取的系统之一，每个连接对应一个 Xero 组织。本页面面向设置访问权限的 Xero 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码。

## 发送访问请求

在**主页**的 **Data Foundation** 下打开项目的**系统**页面，在**添加系统**下的**系统**中选择您的系统，然后单击**还没有访问权限？**。该系统会进入等待访问权限状态，并显示一份涵盖项目各个系统的请求。单击**复制请求**可将其粘贴到您自己的邮件中，单击**通过电子邮件发送请求**则会在您的邮件程序中打开，邮件主题为“PlaidCloud 访问权限”。

## Xero 管理员需要设置的内容

<Steps>

1. **为您要报告的每个组织授权 PlaidCloud 的 Xero 应用**，以具有 Standard 或 Advanced 角色的用户身份登录。当 PlaidCloud 用户单击**连接到 Xero** 时，Xero 的同意屏幕会请求以下范围：

   | 范围 | Data Foundation 借此读取的内容 |
   |---|---|
   | `offline_access` | 无：它使连接在两次加载之间保持登录状态 |
   | `accounting.settings` | 组织、会计科目表、跟踪类别、项目 |
   | `accounting.contacts` | 客户和供应商 |
   | `accounting.transactions` | 销售发票和贷项通知单、账单和供应商贷项通知单、支出款项交易、付款、超额付款和预付款 |
   | `accounting.reports.read` | 试算平衡表，用于期初余额和每个月末余额，以及预算 |

   Data Foundation 只读取数据，尽管 `accounting.settings`、`accounting.contacts` 和 `accounting.transactions` 也允许更改。总账从 Xero 的日记账中读取，这需要 `accounting.journals.read`，而同意屏幕不会请求该范围。没有它，总账就无法加载。会计科目表、部门、客户和产品仍可加载。

2. **按以下名称设置 PlaidCloud 读取的跟踪类别**：

   - **Department**：每个部门一个选项，名称即您希望其代码显示的样子。
   - **Site** 和 **Profit centre**（可选）：如果您跟踪站点或利润中心，则每个站点或利润中心一个选项。
   - **Intercompany**：每个集团公司一个选项，以该公司的实体代码命名，用于公司间日记账的行。请为公司间科目命名，使科目名称中包含“Intercompany”。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 确认已设置组织的财年年末和期间锁定日期 | 无需输入：PlaidCloud 从 Xero 读取这两项 |

无需发送任何 ID、令牌或密码。在项目的**系统**页面上，PlaidCloud 用户在**添加系统**下的**系统**中选择 Xero 并单击**连接到 Xero**，然后由 Xero 用户登录并授权该应用。连接加载一个组织，在其**组织**字段中选择。

在 **System settings** 下，当科目名称尚未说明时，**Retained earnings account** 指定期初损益结转到的权益科目。它是可选的。

## 检查访问权限

返回 PlaidCloud，添加系统后，在**系统**页面上该系统所在的行中单击**测试连接**。它会读取必需的数据集（实体、会计科目表、财务日历、总账和试算平衡表），并将每个数据集显示为**可读取**、**缺少权限**或**错误**。可选数据集不在测试范围内：如果 Xero 拒绝读取其中某项，就绪状态检查会在下次加载后指出它。

| 数据集 | 所需范围 |
|---|---|
| 实体 | `accounting.settings.read` |
| 会计科目表 | `accounting.settings.read` |
| 财务日历 | `accounting.settings.read` |
| 总账 | `accounting.journals.read` |
| 试算平衡表 | `accounting.reports.read` |
| 部门（可选） | `accounting.settings.read`（Department 跟踪类别） |
| 站点和利润中心（可选） | `accounting.settings.read`（Site 和 Profit centre 跟踪类别） |
| 产品（可选） | `accounting.settings.read` |
| 客户和供应商（可选） | `accounting.contacts.read` |
| 月末余额和银行余额（可选） | `accounting.reports.read`（每个月末的试算平衡表） |
| 销售明细行（可选） | `accounting.transactions.read` |
| 供应商发票明细行（可选） | `accounting.transactions.read`（账单、供应商贷项通知单和支出款项交易） |
| 未清项和付款（可选） | `accounting.transactions.read` |
| 预算（可选） | `accounting.reports.read` |

当数据集显示为**缺少权限**时，测试会指出需要授予的范围。请使用该范围重新授权应用，然后重新测试。没有销售发票或预算的 Xero 组织仍会加载其他所有内容。当 Xero 拒绝了构建某个月份的余额、销售、账单、未清项或付款所需的读取时，该月份会保留其已有的行，并在下次加载时重新读取。

汇率不属于此访问范围：Xero 不发布汇率。请改为提供**汇率**文件。
