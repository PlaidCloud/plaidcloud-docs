[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 和会计系统（无论有多少个实例）的数据汇集到一个 Common Finance Model 中。Xero 是它可以直接读取的系统之一，每个连接对应一个 Xero 组织。本页面面向设置访问权限的 Xero 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码。

## 发送访问请求

在项目的**基础数据**选项卡上，选择**创建新连接**并选取 **Xero**。表单会显示完整的请求。单击**复制请求**可将其粘贴到您自己的邮件中，或单击**通过电子邮件发送请求**，在邮件程序中打开它，主题为“Read-only Xero access for PlaidCloud.”

## Xero 管理员需要设置的内容

<Steps>

1. **为您要报告的每个组织授权 PlaidCloud 的 Xero 应用**，以具有 Standard 或 Advanced 角色的用户身份登录。该应用只请求读取权限：

   | 范围 | 涵盖内容 |
   |---|---|
   | `accounting.settings.read` | 组织、会计科目表、跟踪类别、项目 |
   | `accounting.contacts.read` | 客户 |
   | `accounting.transactions.read` | 销售发票和贷项通知单 |
   | `accounting.journals.read` | 总账：每个已过账的日记账 |
   | `accounting.reports.read` | 试算平衡表，用于期初余额 |

   没有 `accounting.journals.read`，总账就无法加载。会计科目表、部门、客户和产品仍可加载。

2. **按以下名称设置 PlaidCloud 读取的跟踪类别**：

   - **Department**：每个部门一个选项，名称即您希望其代码显示的样子。
   - **Intercompany**：每个集团公司一个选项，以该公司的实体代码命名，用于公司间日记账的行。请为公司间科目命名，使科目名称中包含“Intercompany”。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 组织的租户 ID（Xero 在连接下列出，或位于 `GET /connections`） | **Organisation (tenant) ID** |
| 确认已设置组织的财年年末和期间锁定日期 | 无需输入：PlaidCloud 从 Xero 读取这两项 |

PlaidCloud 用户自行粘贴 **Refresh token**；它是机密，切勿通过电子邮件发送。他们还需选择连接加载所属的**组织**。

在 **System settings** 下，当科目名称尚未说明时，**Retained earnings account** 指定期初损益结转到的权益科目。它是可选的。

## 检查访问权限

返回 PlaidCloud，单击**测试连接**。每个数据集显示为**可读取**、**缺少权限**或**错误**：

| 数据集 | 所需范围 |
|---|---|
| 实体 | `accounting.settings.read` |
| 会计科目表 | `accounting.settings.read` |
| 部门 | `accounting.settings.read`（Department 跟踪类别） |
| 产品 | `accounting.settings.read` |
| 财务日历 | `accounting.settings.read` |
| 客户 | `accounting.contacts.read` |
| 总账 | `accounting.journals.read` |
| 试算平衡表 | `accounting.reports.read` |
| 销售明细行（可选） | `accounting.transactions.read` |
| 预算（可选） | `accounting.reports.read` |

当数据集显示为**缺少权限**时，测试会指出需要授予的范围。请使用该范围重新授权应用，然后重新测试。没有销售发票或预算的 Xero 组织仍会加载其他所有内容。

汇率不属于此访问范围：Xero 不发布汇率。请改为提供**汇率**文件。
