将 PlaidCloud 连接到 **OneStream**，让 Data Foundation 读取您的合并结果，并将其管理集团损益表与之对账。OneStream 通过其连接器获得支持：PlaidCloud 使用 OAuth 2.0 客户端凭据登录，并读取由 OneStream 管理员构建的数据适配器。它只读取。

OneStream 是用于对账的结果来源，而不是分录行的来源：其行会作为模型预算表的 `Consolidated` 方案加载，版本为 `OneStream`。参见[与合并系统对账](/zh-cn/guides/projects/data-foundation/#与合并系统对账)。

<Aside type="note">
适配器的列是您与 OneStream 管理员商定的约定。按本页面构建适配器时，其行会按下文所述加载。请将首次加载的结果与您信任的 OneStream 报表进行比较。
</Aside>

## OneStream 管理员需要设置的内容

项目的**系统**页面会撰写一份访问请求供您发送；参见[连接您的 ERP](/zh-cn/guides/projects/data-foundation/#连接-erp)。其中要求提供以下内容。

1. 在 OneStream 的身份服务中为 PlaidCloud 创建一个使用**客户端凭据**授权的客户端，并配有一个服务用户，该用户只能运行下列适配器：没有 Data Management、加载或合并权限。PlaidCloud 不运行任何 Data Management 序列，因此请按您自己的计划保持适配器所读取结果的更新。

2. 在您要报告的应用程序和工作区中，创建一个名为 **Foundation_Results** 的数据适配器，返回一个包含合并结果的表，且列与下面完全一致：

   | 列 | 内容 |
   |---|---|
   | `entity` | 合并成员：实体、抵销成员或集团合计。 |
   | `account` | 科目代码。仅限基础科目。 |
   | `time` | 月份，格式为 `YYYY-MM`。 |
   | `scenario` | 合并结果用 `Actual`。计划用 `Budget` 或 `Forecast`，作为计划读取。 |
   | `view` | `YTD` 或 `Periodic`。PlaidCloud 只读取您所选视图的行。 |
   | `amount` | 数字，采用报表所显示的符号和比例。 |
   | `currency` | 金额所用的货币：集团的报告货币。 |
   | `flow` | 流量成员。仅限基础成员。 |
   | `ud1` 至 `ud5` | 部门、产品、站点、销售代表和项目成员，行中没有时为 `None`。仅限基础成员。 |
   | `version` | 计划的版本。`Actual` 时保留为 `None` 或留空。 |
   | `version_as_of` | 计划版本所依据的月份，格式为 `YYYY-MM`。`Actual` 时保留为 `None` 或留空。 |
   | `quantity` | 计划行所计划的数量单位，无论视图如何均按月计。`Actual` 时保留为 `None` 或留空。 |

   请提供科目、流量和用户定义维度的基础成员。父级成员的行会使其子级被重复计算。适配器从替代变量 `Member` 读取合并成员，从 `View` 读取视图。

   如果您的计划包含人数或产量，还需创建一个名为 **Foundation_Drivers** 的适配器，其列为 `entity`、`time`、`scenario`、`driver`（例如 `headcount` 或 `units_produced`）、`value`、`unit`（`FTE`、`EA` 等）、`ud1`（部门）、`ud2`（产品）、`ud3`（站点）、`version` 和 `version_as_of`。它以相同方式读取 `Member`，并且是可选的：没有它或无权访问它时，不会加载任何计划动因，就绪状态检查会说明这一点。

3. 要读取的成员：实体、抵销成员和集团合计。

## 创建连接

<Steps>

1. 打开 **Tools > Connections** 并单击 `New Connection`，然后选择 **REST - OneStream**。

2. 填写各字段：

   | 字段 | 值 |
   |---|---|
   | 主机 | OneStream 的基础 URL，以 `https://` 开头。 |
   | 客户端 ID | PlaidCloud 客户端的客户端 ID。 |
   | 客户端密钥 | 其密钥。加密存储，不会再次显示。 |
   | Token URL | 留空则使用主机后接 `/identity/connect/token`。 |
   | 默认应用程序 | 用于未指定应用程序的读取。 |
   | 默认工作区 | 用于未指定工作区的读取。 |
   | 超时（秒） | 默认为 120。 |

3. 单击 `Create`。

</Steps>

也可以在**系统**页面上添加系统时创建连接：在**连接**下选择**新建连接**，即会打开同一个连接编辑器。

## 将其添加到 Data Foundation 项目

在项目的**系统**页面上，像添加任何其他系统一样，使用其连接添加 OneStream（参见[连接您的 ERP](/zh-cn/guides/projects/data-foundation/#连接-erp)）。OneStream 不会列出可供勾选的成员，因此请在**选项**、**公司**下输入要读取的合并成员，以逗号分隔：至少一个。然后在**系统设置**下描述适配器的金额：

| 设置 | 含义 |
|---|---|
| **View member** | 适配器的金额为年初至今时用 `ytd`（默认），否则用 `periodic`。年初至今的行会作为各期间金额加载。 |
| **Sign convention** | `natural`（默认）：每个科目采用其自身的符号，与 OneStream 报告的一致。`debit_positive`：借方为正。 |
| **Amount scale** | 换算为整货币单位的乘数：OneStream 以千为单位提供时为 `1000`。默认为 `1`。 |
| **First month of the fiscal year** | 财年开始的月份，从 `1` 到 `12`，用于将年初至今换算为各期间。默认为 `1`。 |
| **Application**、**Workspace** | 覆盖连接中的设置。留空则使用连接中的设置。 |
| **Adapter results table** | 适配器数据集中的表名。默认为 `Results`。 |
| **Substitution variables** | 为适配器设置的替换变量，每行一个，格式为 `name = value`，例如 `Time = 2026M1`。 |

使用适用于此源的代码映射文件，将 OneStream 成员映射到您的实体。参见[实体对照](/zh-cn/guides/projects/data-foundation/#实体对照表)。该源不读取历史窗口：由适配器自己的替代变量界定范围。

适配器未返回任何行的加载会以警告而不是错误结束，并且表为空。
