[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例中的数据汇集到同一个 Common Finance Model 中，Microsoft Dynamics 365 Business Central 就是它可直接读取的 ERP 之一。该连接使用采用客户端凭据的 Microsoft Entra ID 应用、一个只读权限集，以及几个作为 Web 服务发布的页面对象。本页面面向负责这些设置的 Business Central 管理员，以及向其提出请求的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送客户端密钥。

## 发送访问请求

在项目的 **基础数据** 选项卡上，在 **Business Central 连接** 下选择 **创建新连接**。表单中会显示完整的请求内容。点击 **复制请求** 可将其粘贴到您自己的邮件中，点击 **通过电子邮件发送请求** 则会在您的邮件程序中打开，邮件主题为“Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials)”。

## Business Central 管理员需要完成的设置

<Steps>

1. **在 Microsoft Entra ID 中注册应用**。在 **App registrations > New registration** 下添加客户端密钥，并记下目录（租户）ID、应用程序（客户端）ID 和密钥。

2. **在 Business Central 中添加该应用**。打开 **Microsoft Entra Applications**，添加该应用程序，将其状态设为 **已启用**，并为您需要报告的每个公司授予权限集 **D365 READ** 和 **D365 BASIC**。不要授予写入权限集。

3. **将页面对象发布为 Web 服务**。在 **Search > Web Services > New** 下，按以下服务名称发布这些页面对象，并勾选 **Published**。标准 API 不包含这些对象的字段：

   | 页面 | 服务名称 | 备注 |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | 销货成本；可选 |
   | 120 G/L Budget Entries | `GLBudgetEntries` | 预算；可选 |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | 统计动因；可选 |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | 快捷维度 3 至 8；可选 |
   | 479 Dimension Set Entries | `DimensionSetEntries` | 快捷维度 3 至 8；可选 |

4. **告知 PlaidCloud 用户两项选择**：您的审计调整所使用的来源代码（PlaidCloud 默认为 `ADJUSTMENT`），以及哪个维度代表您的部门（PlaidCloud 默认为全局维度 1，名为 `DEPARTMENT`）。

</Steps>

## 需要回传的信息

| 管理员发送的内容 | 在 PlaidCloud 中填入的位置 |
|---|---|
| 目录（租户）ID | **Directory (tenant) ID** |
| 环境名称，例如 `production` | **环境名称** |
| 应用程序（客户端）ID | **Application (client) ID** |
| 客户端密钥 | **客户端密钥**，通过表单填写，不要通过电子邮件发送 |
| 代表您部门的维度的名称 | 系统设置 `department_dimension` |
| PlaidCloud 可读取的公司 | 在 PlaidCloud 的 **Companies** 下选择（至少一个） |

属于合并公司的公司应填入系统设置 `consolidation_companies`，这样它们的分录就不会被计为某个公司的业务活动。汇率取自一个公司：在系统设置 `rate_company` 中指定该公司，否则 PlaidCloud 会使用第一个公司。

## 检查访问权限

回到 PlaidCloud，填入这些值并点击 **测试连接**。每个数据集会显示为 **可读取**、**缺少权限** 或 **错误**：

| 数据集 | 所需条件 |
|---|---|
| 实体、会计科目表、客户、产品、汇率、试算平衡表 | API 访问权限（权限集 D365 READ） |
| 财务日历 | `AccountingPeriods` Web 服务 |
| 部门 | `DimensionValues` Web 服务 |
| 总账 | `GLEntries` Web 服务 |
| 销售明细行、预算、分摊动因 | 可选 |

数据集缺失时，测试会说明需要添加哪个权限或 Web 服务。请管理员添加后再次测试。销售明细行、预算和分摊动因是可选的：不使用它们的环境仍可加载其他所有数据。
