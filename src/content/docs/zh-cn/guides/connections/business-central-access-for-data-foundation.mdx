[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例的数据汇集到一个 Common Finance Model 中，Microsoft Dynamics 365 Business Central 是它可以直接读取的 ERP 之一。该连接使用带客户端凭据的 Microsoft Entra ID 应用程序、只读权限集，以及若干作为 Web 服务发布的页面。本页面面向进行这些设置的 Business Central 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送客户端密钥。

## 发送访问请求

在项目的**基础数据**选项卡上，在 **Business Central 连接**下选择**创建新连接**。表单会显示完整的请求。单击**复制请求**可将其粘贴到您自己的邮件中，或单击**通过电子邮件发送请求**，在邮件程序中打开它，主题为“Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials).”

## Business Central 管理员需要设置的内容

<Steps>

1. **在 Microsoft Entra ID 中注册应用**。在 **App registrations > New registration** 下添加客户端密钥，并记下目录（租户）ID、应用程序（客户端）ID 和密钥。

2. **在 Business Central 中添加该应用**。打开 **Microsoft Entra Applications**，添加该应用程序，将其状态设置为**已启用**，并为您要报告的每个公司授予权限集 **D365 READ** 和 **D365 BASIC**。不要授予写入权限集。

3. **将页面发布为 Web 服务**。在 **Search > Web Services > New** 下，按完全相同的服务名称发布以下页面，并勾选 **Published**。标准 API 不包含它们的字段：

   | 页面 | 服务名称 | 备注 |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | 销货成本；可选 |
   | 120 G/L Budget Entries | `GLBudgetEntries` | 预算；可选 |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | 统计动因；可选 |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | 快捷维度 3 至 8；可选 |
   | 479 Dimension Set Entries | `DimensionSetEntries` | 快捷维度 3 至 8；可选 |

4. **告知 PlaidCloud 用户两项选择**：审计调整所用的来源代码（PlaidCloud 默认为 `ADJUSTMENT`），以及哪个维度是您的部门（PlaidCloud 默认为全局维度 1，名为 `DEPARTMENT`）。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 目录（租户）ID | **Directory (tenant) ID** |
| 环境名称，例如 `production` | **环境名称** |
| 应用程序（客户端）ID | **Application (client) ID** |
| 客户端密钥 | **客户端密钥**，通过表单输入，而不是通过电子邮件 |
| 作为部门的维度的名称 | 系统设置 `department_dimension` |
| PlaidCloud 可以读取的公司 | 在 PlaidCloud 的 **Companies** 下选择（至少一个） |

属于合并公司的公司放在系统设置 `consolidation_companies` 下，这样其分录就不会被计为某个公司的活动。汇率取自一个公司：在系统设置 `rate_company` 中指定它，否则 PlaidCloud 使用第一个公司。

## 检查访问权限

返回 PlaidCloud，输入各值并单击**测试连接**。每个数据集显示为**可读取**、**缺少权限**或**错误**：

| 数据集 | 所需权限 |
|---|---|
| 实体、会计科目表、客户、产品、汇率、试算平衡表 | API 访问（权限集 D365 READ） |
| 财务日历 | Web 服务 `AccountingPeriods` |
| 部门 | Web 服务 `DimensionValues` |
| 总账 | Web 服务 `GLEntries` |
| 销售明细行、预算、分摊动因 | 可选 |

当缺少某个数据集时，测试会指出需要添加哪个权限或 Web 服务。请管理员添加后重新测试。销售明细行、预算和分摊动因是可选的：不使用它们的环境仍会加载其他所有内容。
