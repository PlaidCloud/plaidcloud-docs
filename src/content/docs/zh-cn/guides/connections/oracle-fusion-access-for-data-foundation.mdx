[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例的数据汇集到一个 Common Finance Model 中，Oracle Fusion Cloud ERP 是它可以直接读取的 ERP 之一。Oracle Fusion 连接使用 OAuth 2.0 客户端凭据、只读集成用户和一小组 BI Publisher 报表。本页面面向进行这些设置的 Oracle Fusion 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码或客户端密钥。

## 发送访问请求

在项目的**基础数据**选项卡上，在 **Oracle Fusion 连接**下选择**创建新连接**。表单会显示完整的请求。单击**复制请求**可将其粘贴到您自己的邮件中，或单击**通过电子邮件发送请求**，在邮件程序中打开它，主题为“Read-only Oracle Fusion Cloud ERP access for PlaidCloud (OAuth 2.0 client credentials).”

## Oracle Fusion 管理员需要设置的内容

<Steps>

1. **创建集成用户**，并为其授予一个职务角色，该角色须能查看您要报告的每个账簿的以下内容：

   - 总账：账簿、会计日历和期间状态、日记账批次、日记账和科目余额（例如具有这些账簿数据访问权限的“General Accountant”）
   - 货币换算汇率（每日汇率）
   - 关键弹性域的段标签、值集及其科目层次结构（树）
   - 应收账款：发票及其分配，以及客户账户
   - 库存项目
   - 对步骤 3 中的 BI Publisher 报表和 ERP Integration Service（ESS 作业）的运行权限

2. **在身份域（IAM）中注册机密应用程序**，使用客户端凭据授权和 Fusion Applications REST API 的范围。复制其客户端 ID 和密钥。

3. **在 `/Custom/PlaidCloud/DataFoundation` 下部署九个 BI Publisher 报表**。每个报表作为 ESS 作业运行，以报表名称作为作业定义，并返回包含请求中所列列的 CSV：

   | 报表 | 返回内容 |
   |---|---|
   | `PlaidCloudKeyFlexLabels` | 每个总账会计科目表的每个段一行：其位置、标签和值集 |
   | `PlaidCloudSegmentValues` | 这些值集的每个值，以及自然科目类型和值层次结构 |
   | `PlaidCloudCalendar` | 每个账簿的会计期间，以及账簿的期间平均汇率类型和期末汇率类型 |
   | `PlaidCloudCodeCombinations` | 代码组合及其段 |
   | `PlaidCloudBalances` | 每个账簿的期初余额 |
   | `PlaidCloudJournalLines` | 日记账行，每次读取一个账簿、期间和平衡段值 |
   | `PlaidCloudCustomers` | 客户账户及其伙伴名称 |
   | `PlaidCloudItems` | 主库存组织的项目 |
   | `PlaidCloudSalesLines` | 每个应收账款发票行一行 |

   每个报表的确切列在**基础数据**选项卡上的请求文本中。报表名称请完全按所示提供。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| Fusion Applications URL 的主机，不含 `https://` | **Pod 主机** |
| 身份域的令牌 URL | **Token URL** |
| REST API 应用程序的范围 | **范围** |
| 步骤 2 中的客户端 ID | **客户端 ID** |
| 步骤 2 中的客户端密钥 | **客户端密钥** |
| PlaidCloud 可以读取的平衡段值 | 在 **Balancing segment values** 下，Fusion 无法列出这些值：在**名称**下输入一个值，或留空以加载所有值 |

请求末尾的列表会一并索要这些值。请通过密码管理器共享客户端密钥，而不是通过电子邮件。PlaidCloud 用户的团队自行将其粘贴到 PlaidCloud 中。

## 检查访问权限

返回 PlaidCloud，输入各值并单击**测试连接**。每个数据集显示为**可读取**、**缺少权限**或**错误**：

| 数据集 | 读取来源 |
|---|---|
| 实体、财务日历、会计科目表、部门 | 账簿，以及关键弹性域标签、段值和日历报表 |
| 汇率 | 每日换算汇率 |
| 总账 | 日记账批次和日记账行报表 |
| 试算平衡表 | 余额报表和代码组合报表 |
| 客户、产品、销售明细行 | 客户、项目和销售明细行报表（可选） |

当缺少某个数据集时，测试会指出需要添加哪个权限。请管理员将其添加到职务角色后重新测试。客户、产品和销售明细行是可选的：不包含它们的 Fusion pod 仍会加载其他所有内容。
