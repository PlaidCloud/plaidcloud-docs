[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例的数据汇集到一个 Common Finance Model 中，Oracle Fusion Cloud ERP 是它可以直接读取的 ERP 之一。Oracle Fusion 连接使用 OAuth 2.0 客户端凭据、只读集成用户和一小组 BI Publisher 报表。本页面面向进行这些设置的 Oracle Fusion 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码或客户端密钥。

## 发送访问请求

在**主页**的 **Data Foundation** 下打开项目的**系统**页面，在**添加系统**下的**系统**中选择您的系统，然后单击**还没有访问权限？**。该系统会进入等待访问权限状态，并显示一份涵盖项目各个系统的请求。单击**复制请求**可将其粘贴到您自己的邮件中，单击**通过电子邮件发送请求**则会在您的邮件程序中打开，邮件主题为“PlaidCloud 访问权限”。

## Oracle Fusion 管理员需要设置的内容

<Steps>

1. **创建集成用户**，并为其授予一个只能查看的自定义职务角色，适用于您要报告的每个账簿。不要使用可以录入、过账或审批任何内容的角色，例如 General Accountant。该角色需要：

   - 总账：账簿、会计日历和期间状态、日记账批次、日记账和科目余额（查询权限，并具有这些账簿的数据访问权限）
   - 货币换算汇率（每日汇率）
   - 关键弹性域的段标签、值集及其科目层次结构（树）
   - 应收账款和应付账款：发票、收款、付款及其分配，以及客户账户和供应商
   - 现金管理银行账户
   - 库存项目和现有数量
   - 对于您部署的每个可选报表，相应的只读访问权限：采购（View Purchase Order、`PO_VIEW_PURCHASE_ORDER_PRIV` 和收货查询，并具有采购业务单元的数据访问权限）、固定资产（资产查询，并具有公司和税务资产账簿的数据访问权限）、成本管理（Review Item Costs，并具有成本组织的数据访问权限）以及预算（总账预算余额查询）
   - 对步骤 3 中的 BI Publisher 报表和 ERP Integration Service（ESS 作业）的运行权限

2. **在身份域（IAM）中注册机密应用程序**，使用客户端凭据授权和 Fusion Applications REST API 的范围。复制其客户端 ID 和密钥。

3. **在 `/Custom/PlaidCloud/DataFoundation` 下部署 BI Publisher 报表**。每个报表作为 ESS 作业运行，以报表名称作为作业定义，并返回包含请求中所列列的 CSV。前六个是必需的：总账基于它们构建。其他报表是可选的：缺少某个报表时，其承载的数据保持为空，其他内容不受影响。

   | 报表 | 返回内容 |
   |---|---|
   | `PlaidCloudKeyFlexLabels` | 每个总账会计科目表的每个段一行：其位置、标签和值集 |
   | `PlaidCloudSegmentValues` | 这些值集的每个值，以及自然科目类型和值层次结构 |
   | `PlaidCloudCalendar` | 每个账簿的会计期间，以及账簿的期间平均汇率类型和期末汇率类型 |
   | `PlaidCloudCodeCombinations` | 代码组合及其段 |
   | `PlaidCloudBalances` | 每个账簿在每个期间（包括调整期间）的余额：期初余额，以及总账用于比较的月末余额 |
   | `PlaidCloudJournalLines` | 日记账行，每次读取一个账簿、期间和平衡段值，并包含每个日记账的录入人和审批人、时间以及它所冲销的日记账 |
   | `PlaidCloudCustomers` | 客户账户及其伙伴名称（可选） |
   | `PlaidCloudItems` | 主库存组织的项目（可选） |
   | `PlaidCloudSalesLines` | 每个应收账款发票行一行（可选） |
   | `PlaidCloudSites` | `GL_SITE` 段的值（可选） |
   | `PlaidCloudSuppliers` | 供应商（可选） |
   | `PlaidCloudArDocuments`、`PlaidCloudReceipts` | 应收账款事务及其核销内容，用于未清项和付款（可选） |
   | `PlaidCloudApInvoices`、`PlaidCloudApPayments` | 应付账款发票及其核销内容，用于未清项和付款（可选） |
   | `PlaidCloudApInvoiceLines` | 每个应付账款发票行一行（可选） |
   | `PlaidCloudBankBalances` | 每个银行账户在每个月末的自身余额（可选） |
   | `PlaidCloudInventory` | 每个项目和子库存在每个月末的现有数量和价值（可选） |
   | `PlaidCloudBudget` | 按月的已批准预算（可选） |
   | `PlaidCloudPurchaseOrders`、`PlaidCloudPurchaseOrderEvents` | 采购订单行，及其收货和匹配的发票（可选） |
   | `PlaidCloudAssets`、`PlaidCloudAssetMovements` | 公司账簿的资产登记簿，以及每项资产在公司账簿和税务账簿中的变动（可选） |
   | `PlaidCloudStandardCosts` | 每个项目每月的标准成本（可选） |

   每个报表的确切列在访问请求文本中。报表名称请完全按所示提供。如果您曾为早期版本部署了 `PlaidCloudBalances` 或 `PlaidCloudApInvoices`，请按请求中的说明扩展它们：`PlaidCloudBalances` 现在必须返回每个期间及其发生额。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| Fusion Applications URL 的主机，不含 `https://` | **Pod 主机** |
| 身份域的令牌 URL | **身份域令牌 URL** |
| REST API 应用程序的范围 | **范围** |
| 步骤 2 中的客户端 ID | **客户端 ID** |
| 步骤 2 中的客户端密钥 | **客户端密钥** |
| PlaidCloud 可以读取的平衡段值 | 在**选项**的**公司**下，Fusion 无法列出这些值：输入这些值，以逗号分隔，或留空以加载所有值 |

请求末尾的列表会一并索要这些值。请通过密码管理器共享客户端密钥，而不是通过电子邮件。PlaidCloud 用户的团队自行将其粘贴到 PlaidCloud 中。

## 检查访问权限

返回 PlaidCloud，添加系统后，在**系统**页面上该系统所在的行中单击**测试连接**。它会为每个必需数据集读取一个对象，并将每个数据集显示为**可读取**、**缺少权限**或**错误**。报表本身在首次加载时运行，可选报表不在测试范围内：缺少的报表或用户无权运行的报表会在下次加载时指出。

| 数据集 | 测试读取的内容 |
|---|---|
| 实体、财务日历、会计科目表、部门、试算平衡表 | 账簿 |
| 汇率 | 每日换算汇率 |
| 总账 | 日记账批次 |

当缺少某个数据集时，测试会指出需要添加哪个权限。请管理员将其添加到职务角色后重新测试。缺少某个可选报表的 Fusion pod 仍会加载其他所有内容：客户、产品、站点和供应商加载为空，其他任何数据集会保留之前加载的内容，直到该报表可以再次读取。

Oracle Fusion 没有可供 Data Foundation 读取的利润中心列表。日记账行的利润中心是其会计科目表的管理段。
