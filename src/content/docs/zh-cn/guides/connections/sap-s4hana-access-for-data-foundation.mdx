[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例的数据汇集到一个 Common Finance Model 中，SAP S/4HANA 是它可以直接读取的 ERP 之一。PlaidCloud 通过安装在您自己网络上的 [PlaidLink](/zh-cn/reference/cli/plaidlink/) 代理，经由 RFC 访问该系统。本页面面向进行这些设置的 SAP 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码。

## 发送访问请求

在**主页**的 **Data Foundation** 下打开项目的**系统**页面，在**添加系统**下的**系统**中选择您的系统，然后单击**还没有访问权限？**。该系统会进入等待访问权限状态，并显示一份涵盖项目各个系统的请求。单击**复制请求**可将其粘贴到您自己的邮件中，单击**通过电子邮件发送请求**则会在您的邮件程序中打开，邮件主题为“PlaidCloud 访问权限”。

## SAP 管理员需要设置的内容

<Steps>

1. **安装 PlaidCloud ABAP 包**（`Z_PLAIDCL_B5_READ_TABLE` 的函数组）到您用于报告的客户端中，并安装可通过 RFC 访问该系统的 PlaidLink 代理。

2. **创建通信用户**，例如 `PLAIDCLOUD_RFC`，其角色包含以下授权：

   - `S_RFC`：执行 `Z_PLAIDCL_B5_READ_TABLE` 的函数组。
   - 对下列表的 `S_TABU_NAM`（显示，`ACTVT` 03）。

   | 表 | 内容 |
   |---|---|
   | `T001` | 公司代码 |
   | `T009`、`T009B`、`T001B` | 会计年度变式和过账期间 |
   | `SKA1`、`SKAT` | 总账科目 |
   | `FAGL_011PC`、`FAGL_011ZC` | 财务报表版本 |
   | `CSKS`、`CSKT` | 成本中心 |
   | `SETHEADER`、`SETNODE` | 成本中心和利润中心分组 |
   | `CEPC`、`CEPCT` | 利润中心（可选） |
   | `KNA1`、`KNVV`、`KNVH` | 客户及其层次结构 |
   | `MARA`、`MAKT`、`T006A` | 物料和单位 |
   | `TCURR`、`TCURF`、`TCURX` | 汇率和货币小数位 |
   | `ACDOCA` | 主账簿的日记账分录及其余额结转 |
   | `VBRK`、`VBRP`、`PRCD_ELEMENTS` | 开票凭证及其条件 |
   | `ACDOCP` | 计划数据 |
   | `COSR` | 统计关键数据 |
   | `T001K`、`MBEW`、`MBEWH` | 评估范围、物料库存价值和标准价格 |
   | `T001W`、`TKA02` | 工厂（作为站点读取），以及每个公司代码的控制范围（可选） |
   | `T016T`、`TKUKT`、`KNVP`、`TSPAT`、`T052U` | 行业和客户分类名称、每个客户的销售员工、产品组和付款条件名称（可选） |
   | `LFA1`、`LFB1` | 供应商（可选） |
   | `RBKP`、`RSEG`、`BKPF` | 供应商发票及其会计凭证（可选） |
   | `EKKO`、`EKPO`、`EKKN`、`EKET`、`EKBE` | 采购订单及其收货和发票（可选） |
   | `ANLA`、`ANLZ`、`ANLB`、`ANKA`、`T095` | 固定资产登记簿（可选） |
   | 经营范围的行项目表（`CE1` 后接其名称） | 按估值的 CO-PA（可选） |

   未清项和付款从 `ACDOCA` 的客户和供应商行中读取，资产变动则从其在资产科目上的过账中读取。

3. **回答会计问题**（见下文）。

</Steps>

### 管理员需要回答的问题

| 管理员告知您 | 您在 PlaidCloud 的**系统设置**下输入 |
|---|---|
| 保存平均汇率的汇率类型。PlaidCloud 对该类型每个月的汇率求平均值。通常为 `M`。 | **Average rate type** |
| 保存期末汇率的汇率类型，即月末汇率。如果未指定，期末汇率为 `M` 汇率。 | **Closing rate type** |
| 用于报告管理损益表和资产负债表的财务报表版本 | **Financial statement version** |
| 其节点中哪些是收入、销货成本、运营费用、非经营性、资产、负债、权益和公司间 | **Account type of each statement node**：每个节点一行，格式为 `node = type`，类型取自该框列出的类型，例如 `Revenue` 或 `Asset`。**Intercompany statement nodes** 指定公司间节点。两者仅在设置了 **Financial statement version** 时适用。 |
| 您报告的每个会计年度是否已运行余额结转（`FAGLGVTR`） | 无需输入。期初余额从中读取。 |
| 每个资产账簿（会计或税务）的折旧范围。第一个是登记簿的折旧范围。PlaidCloud 默认范围 `01` 为会计账簿。 | **Depreciation area of each book** |
| 每种资产事务类型的变动类型，按其首位数字区分。PlaidCloud 默认 `1` 为购置、`2` 为处置、`3` 为转移、`6` 为折旧、`9` 为期初。 | **Movement type of each transaction type** |
| 经营范围的行项目表，如果需要按估值的 CO-PA。未指定时不读取 CO-PA。 | **Operating concern line item table** |
| 每个科目的 CO-PA 值字段，以及其中哪些是成本 | **Value field of each CO-PA account**、**CO-PA cost value fields** |

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 系统 ID 和应用服务器（或消息服务器和登录组） | **主机**和**系统编号**，或者在使用**使用负载均衡多系统连接**时，填写 **MS 主机**、**MS 服务器**、**系统 ID** 和**分组** |
| 客户端 | **客户端** |
| 通信用户的名称 | **用户** |
| 通信用户的密码，通过您的密码管理器提供 | **密码**，由您的团队自行输入 |
| 访问该系统的 PlaidLink 代理的名称 | 系统设置 **PlaidLink agent** |
| PlaidCloud 可以读取的公司代码 | 在**选项**的**公司**下，SAP 无法列出这些代码：输入公司代码，以逗号分隔，或留空以加载所有公司代码 |

<Aside type="caution">
切勿通过电子邮件发送密码。**密码**是机密：它存储在连接上，不会再次显示。
</Aside>

## 检查访问权限

SAP 通过 PlaidLink 代理读取，因此**测试连接**不会读取它：首次加载时才会读取，并指出该用户无权读取的表。各数据集读取的表如下：

| 数据集 | 读取的表 |
|---|---|
| 实体 | `T001` |
| 财务日历 | `T001`、`T009`、`T009B`、`T001B` |
| 汇率 | `TCURR`、`TCURF` |
| 会计科目表 | `SKA1`、`SKAT`、`FAGL_011PC`、`FAGL_011ZC` |
| 部门 | `CSKS`、`CSKT`、`SETHEADER`、`SETNODE` |
| 利润中心 | `CEPC`、`CEPCT`、`SETHEADER`、`SETNODE` |
| 客户 | `KNA1`、`KNVV`、`KNVH` |
| 产品 | `MARA`、`MAKT`、`T006A` |
| 总账 | `ACDOCA` |
| 试算平衡表 | `ACDOCA` 余额结转 |
| 销售明细行 | `VBRK`、`VBRP`、`PRCD_ELEMENTS` |
| 预算 | `ACDOCP` |
| 分摊动因 | `COSR` |
| 库存余额 | `T001K`、`MBEW`、`MBEWH` |
| 站点 | `T001W`、`T001K` |
| 供应商 | `LFA1`、`LFB1` |
| 供应商发票明细行 | `RBKP`、`RSEG`、`BKPF` |
| 采购订单 | `EKKO`、`EKPO`、`EKKN`、`EKET`、`EKBE` |
| 未清项、付款 | `ACDOCA` 客户和供应商行 |
| 固定资产 | `ANLA`、`ANLZ`、`ANLB`、`ANKA`、`T095` |
| 资产变动 | `ACDOCA`，以及 `ANLA`、`ANKA`、`T095` |
| 标准成本 | `T001K`、`MBEW`、`MBEWH` |
| 按估值的 CO-PA | 在 **Operating concern line item table** 中指定的表 |

当加载指出该用户无权读取某个表时，请管理员将该表添加到角色后重新加载。利润中心、站点、供应商、供应商发票明细行、采购订单、未清项、付款、固定资产、资产变动、标准成本、CO-PA、销售明细行、预算、分摊动因和库存余额都是可选的：不包含其中某项的系统仍会加载其他所有内容。某个月份中被 SAP 拒绝读取的未清项或付款会保留其已有的行。

S/4HANA 没有单独保存可供 Data Foundation 读取的月末余额，因此总账会与其自身的试算平衡表进行比较。不过账到任何账簿的折旧范围不会被读取，就绪状态检查会指出它们。
