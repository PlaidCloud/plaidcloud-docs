[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例的数据汇集到一个 Common Finance Model 中，SAP S/4HANA 是它可以直接读取的 ERP 之一。PlaidCloud 通过安装在您自己网络上的 [PlaidLink](/zh-cn/reference/cli/plaidlink/) 代理，经由 RFC 访问该系统。本页面面向进行这些设置的 SAP 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码。

## 发送访问请求

在项目的**基础数据**选项卡上，在 **SAP S/4HANA connection** 下选择**创建新连接**。表单会显示完整的请求和 **How to set up PlaidLink** 链接。单击**复制请求**可将其粘贴到您自己的邮件中，或单击**通过电子邮件发送请求**，在邮件程序中打开它，主题为“Read-only SAP S/4HANA access for PlaidCloud (through PlaidLink).”

## SAP 管理员需要设置的内容

<Steps>

1. **安装 PlaidCloud ABAP 包**（`Z_PLAIDCL_B5_READ_TABLE` 的函数组）到您用于报告的客户端中，并安装可通过 RFC 访问该系统的 PlaidLink 代理。

2. **创建通信用户**，例如 `PLAIDCLOUD_RFC`，其角色包含以下授权：

   - `S_RFC`：执行 `Z_PLAIDCL_B5_READ_TABLE` 的函数组。
   - 对下列表的 `S_TABU_NAM`（显示，`ACTVT` 03）。

   | 表 | 内容 |
   |---|---|
   | `T001` | 公司代码 |
   | `T009`、`T009B`、`T001B` | 会计年度变式和过账期间 |
   | `SKA1`、`SKAT` | 总账科目 |
   | `FAGL_011PC`、`FAGL_011ZC` | 财务报表版本 |
   | `CSKS`、`CSKT` | 成本中心 |
   | `SETHEADER`、`SETNODE` | 成本中心和利润中心分组 |
   | `CEPC`、`CEPCT` | 利润中心（可选） |
   | `KNA1`、`KNVV`、`KNVH` | 客户及其层次结构 |
   | `MARA`、`MAKT`、`T006A` | 物料和单位 |
   | `TCURR`、`TCURF`、`TCURX` | 汇率和货币小数位 |
   | `ACDOCA` | 主账簿的日记账分录及其余额结转 |
   | `VBRK`、`VBRP`、`PRCD_ELEMENTS` | 开票凭证及其条件 |
   | `ACDOCP` | 计划数据 |
   | `COSR` | 统计关键数据 |
   | `T001K`、`MBEW`、`MBEWH` | 评估范围和物料库存价值 |

3. **回答会计问题**（见下文）。

</Steps>

### 管理员需要回答的问题

| 管理员告知您 | 您在 PlaidCloud 的 System settings 下输入 |
|---|---|
| 保存平均汇率的汇率类型。PlaidCloud 对该类型每个月的汇率求平均值。通常为 `M`。 | `average_rate_type` |
| 保存期末汇率的汇率类型，即月末汇率。如果未指定，期末汇率为 `M` 汇率。 | `closing_rate_type` |
| 用于报告管理损益表和资产负债表的财务报表版本 | `fsv` |
| 其节点中哪些是收入、销货成本、运营费用、非经营性、资产、负债、权益和公司间 | 公司间节点用 `intercompany_nodes`。表单中没有其他节点类型的字段。 |
| 您报告的每个会计年度是否已运行余额结转（`FAGLGVTR`） | 无需输入。期初余额从中读取。 |

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 系统 ID 和应用服务器（或消息服务器和登录组） | **Application server** 和**系统编号** |
| 客户端 | **客户端** |
| 通信用户的名称 | **用户** |
| 通信用户的密码，通过您的密码管理器提供 | **密码**，由您的团队自行粘贴 |
| 访问该系统的 PlaidLink 代理的名称 | System settings 下的 `agent` |
| PlaidCloud 可以读取的公司代码 | 在 **Company codes** 下，系统在加载之前无法列出这些代码：在**名称**下输入一个公司代码，或留空以加载所有公司代码 |

<Aside type="caution">
切勿通过电子邮件发送密码。**密码**是机密：它存储在连接上，不会再次显示。
</Aside>

## 检查访问权限

返回 PlaidCloud，输入各值并单击**测试连接**。每个数据集显示为**可读取**、**缺少权限**或**错误**：

| 数据集 | 读取的表 |
|---|---|
| 实体 | `T001` |
| 财务日历 | `T001`、`T009`、`T009B`、`T001B` |
| 汇率 | `TCURR`、`TCURF` |
| 会计科目表 | `SKA1`、`SKAT`、`FAGL_011PC`、`FAGL_011ZC` |
| 部门 | `CSKS`、`CSKT`、`SETHEADER`、`SETNODE` |
| 利润中心 | `CEPC`、`CEPCT`、`SETHEADER`、`SETNODE` |
| 客户 | `KNA1`、`KNVV`、`KNVH` |
| 产品 | `MARA`、`MAKT`、`T006A` |
| 总账 | `ACDOCA` |
| 试算平衡表 | `ACDOCA` 余额结转 |
| 销售明细行 | `VBRK`、`VBRP`、`PRCD_ELEMENTS` |
| 预算 | `ACDOCP` |
| 分摊动因 | `COSR` |
| 库存余额 | `T001K`、`MBEW`、`MBEWH` |

当数据集显示为**缺少权限**时，请管理员将该表添加到角色后重新测试。利润中心、销售明细行、预算、分摊动因和库存余额是可选的：不包含其中某项的系统仍会加载其他所有内容。
