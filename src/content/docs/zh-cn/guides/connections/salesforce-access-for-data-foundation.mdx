[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个系统（无论有多少个实例）的数据汇集到一个 Common Finance Model 中。Salesforce 是它可以直接读取的系统之一。Salesforce 是 CRM 来源，而不是总账：它提供客户、产品和销售管道，从不提供总账分录。本页面面向设置访问权限的 Salesforce 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码或安全令牌。

## 发送访问请求

在项目的**基础数据**选项卡上，选择**创建新连接**并选取 **Salesforce**。表单会显示完整的请求。单击**复制请求**可将其粘贴到您自己的邮件中，或单击**通过电子邮件发送请求**，在邮件程序中打开它，主题为“Read-only Salesforce access for PlaidCloud (OAuth 2.0 client credentials).”

## Salesforce 管理员需要设置的内容

<Steps>

1. **创建 External Client App**，在 **Setup > Apps > External Client Apps > New** 下进行；如果您的组织仍有 Connected App，也可以创建 Connected App：

   - 启用 OAuth 设置，并且仅勾选 **Enable Client Credentials Flow**（不使用授权码流或密码流）。
   - **OAuth 范围**：通过 API 管理用户数据（`api`）。
   - **Run As**：专用的集成用户（步骤 2）。

2. **为集成用户授予配置文件或权限集**，包含：

   - API Enabled
   - 对 Account（包括 Account Number 字段）、Product2、Opportunity、OpportunityLineItem 和 Organization（用于默认货币）的读取权限
   - View All Data，或使其能够看到您要报告的所有商机的共享设置

   Salesforce 会将 PlaidCloud 可读取的每一行和每个字段限制在该用户可见的范围内。

3. **从应用中复制 Consumer Key（客户端 ID）和 Consumer Secret**，以及组织的 My Domain URL，例如 `https://yourcompany.my.salesforce.com`。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| My Domain URL | **My Domain URL** |
| 客户端 ID（Consumer Key） | **客户端 ID** |
| 客户端密钥（Consumer Secret），通过安全的连接表单提供，而不是通过电子邮件 | **客户端密钥** |

在**实体**下，于**名称**中输入该 Salesforce 组织的销售管道所属的实体：组织没有可列出的实体。一个组织对应一个实体，因此两个组织就是两个连接。

## 检查访问权限

返回 PlaidCloud，单击**测试连接**。每个数据集显示为**可读取**、**缺少权限**或**错误**：

| 数据集 | 在 Salesforce 中读取的内容 |
|---|---|
| 客户 | Account |
| 产品 | Product2 |
| 销售管道 | Opportunity 和 OpportunityLineItem，附带科目编号 |

这三项都是可选的。当其中一项显示为**缺少权限**时，请管理员为集成用户添加对该对象的读取权限后重新测试。

销售管道金额采用商机的货币。只使用一种货币的组织没有这样的字段，因此 PlaidCloud 使用 Organization 中组织的默认货币，否则使用实体的货币。
