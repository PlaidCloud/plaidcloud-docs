[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个系统（无论有多少个实例）的数据汇集到一个 Common Finance Model 中。Salesforce 是它可以直接读取的系统之一。Salesforce 是 CRM 来源，而不是总账：它提供客户、产品、销售管道、销售代表、营销活动、其财务月份和订单，从不提供总账分录。本页面面向设置访问权限的 Salesforce 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码或安全令牌。

## 发送访问请求

在**主页**的 **Data Foundation** 下打开项目的**系统**页面，在**添加系统**下的**系统**中选择您的系统，然后单击**还没有访问权限？**。该系统会进入等待访问权限状态，并显示一份涵盖项目各个系统的请求。单击**复制请求**可将其粘贴到您自己的邮件中，单击**通过电子邮件发送请求**则会在您的邮件程序中打开，邮件主题为“PlaidCloud 访问权限”。

## Salesforce 管理员需要设置的内容

<Steps>

1. **创建 External Client App**，在 **Setup > Apps > External Client Apps > New** 下进行；如果您的组织仍有 Connected App，也可以创建 Connected App：

   - 启用 OAuth 设置，并且仅勾选 **Enable Client Credentials Flow**（不使用授权码流或密码流）。
   - **OAuth 范围**：通过 API 管理用户数据（`api`）。
   - **Run As**：专用的集成用户（步骤 2）。

2. **为集成用户授予配置文件或权限集**，包含：

   - API Enabled
   - 对 Account（包括 Account Number 字段）、Product2、Opportunity、OpportunityLineItem 和 Organization（用于默认货币）的读取权限
   - 对 User（销售代表）、Campaign（营销活动，作为项目读取）、FiscalYearSettings 和 Period（财务月份）、OpportunityHistory 和 OpportunityStage（每个月末时的销售管道状态），以及 Order 和 OrderItem（订单，需启用 Orders）的读取权限，如果希望将它们纳入模型
   - View All Data，或使其能够看到您要报告的所有商机的共享设置

   Salesforce 会将 PlaidCloud 可读取的每一行和每个字段限制在该用户可见的范围内。

3. **从应用中复制 Consumer Key（客户端 ID）和 Consumer Secret**，以及组织的 My Domain URL，例如 `https://yourcompany.my.salesforce.com`。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| My Domain URL | **My Domain**：只填域名，例如 `yourcompany`；`.my.salesforce.com` 会自动添加 |
| 客户端 ID（Consumer Key） | **客户端 ID** |
| 客户端密钥（Consumer Secret），通过安全的连接表单提供，而不是通过电子邮件 | **客户端密钥** |

在**选项**的**公司**下，输入该 Salesforce 组织的销售管道所属的那一个实体：组织没有可列出的实体。一个组织对应一个实体，因此两个组织就是两个连接。

## 检查访问权限

返回 PlaidCloud，添加系统后，在**系统**页面上该系统所在的行中单击**测试连接**。每个数据集显示为**可读取**、**缺少权限**或**错误**：

| 数据集 | 在 Salesforce 中读取的内容 |
|---|---|
| 客户 | Account |
| 产品 | Product2 |
| 销售管道 | Opportunity 和 OpportunityLineItem，附带科目编号 |
| 组织的默认货币 | Organization |

这些全部是可选的。当其中一项显示为**缺少权限**时，请管理员为集成用户添加对该对象的读取权限后重新测试。

测试不会读取其他数据集，它们同样都是可选的：

| 数据集 | 在 Salesforce 中读取的内容 |
|---|---|
| 销售代表 | User |
| 项目 | Campaign |
| 财务日历 | FiscalYearSettings 和 Period，仅限月份 |
| 每个过去月末时的销售管道 | OpportunityHistory 和 OpportunityStage |
| 销售订单 | Order 和 OrderItem |

如果 Salesforce 拒绝读取其中某项，下次加载后，**CFM-Accounting - Close and assurance** 仪表板上的就绪状态检查会指出需要为集成用户授予读取权限的对象。某个月份中无法读取的销售管道或订单会保留其已有的行。

销售管道金额采用商机的货币。只使用一种货币的组织没有这样的字段，因此 PlaidCloud 使用 Organization 中组织的默认货币，否则使用实体的货币。
