将 PlaidCloud 连接到 **Anaplan**，工作流即可通过 Anaplan 的大容量读取请求路径读取已保存的视图、运行现有的导出操作，或将一个或多个 Anaplan 列表读取到 PlaidCloud 维度中。该连接以**云直连**方式访问 Anaplan 自己的 Integration API，这些步骤没有本地代理路径。本指南涵盖连接、身份验证、三个读取步骤各自的简要介绍，以及计划方面的注意事项。

<Aside type="note">
此连接器仅限读取。不会向 Anaplan 回写任何内容，没有回写步骤，也没有部分应用模式。
</Aside>

## 前提条件

需要从 Anaplan 工作区管理员处获得：

- 一个 Anaplan **用户名和密码**，或由工作区管理员注册到某个 Anaplan 用户的 **CA 证书及其私钥**，并具有对工作流将读取的工作区和模型的读取权限。参见下文的[身份验证](#身份验证)。
- 要读取的模型的**工作区 ID** 和**模型 ID**，可在 Anaplan 自己的模型设置中查看。创建连接后，也可以通过该连接实时发现这两项。
- 对于 **Anaplan：读取视图**：一个**已保存的视图**，其行、列和筛选器切片正是您想要的。参见下文的 [Anaplan：读取视图](#anaplan读取视图)。
- 对于 **Anaplan：读取导出**：模型中**已存在**的导出操作。
- 对于 **Anaplan：读取列表**：构成要读取的层次结构的 Anaplan **列表**。

## 身份验证

连接具有**身份验证模式**：**基本**（默认）或**证书**。现有连接仍按基本模式正常工作。

- **基本**使用 Anaplan 用户名和密码登录。
- **证书**使用 CA 签发的证书及其私钥登录，二者均以 PEM 文本粘贴。私钥必须是 **RSA 且未加密**，证书必须是 Anaplan 工作区管理员已注册到您的 Anaplan 用户的证书，并由 Anaplan 为您的租户所信任的 CA 签发。PlaidCloud 使用私钥对随机质询进行签名，并按照 Anaplan 自己的证书身份验证流程将其换取 Anaplan 令牌。粘贴证书和私钥后无需其他操作，令牌刷新的方式与基本模式相同。两个字段都会遮蔽粘贴的内容，两项机密与基本模式的密码一样加密存储，切换模式绝不会发送另一种模式的凭据。如果将现有连接从基本模式切换到证书模式，需要粘贴证书和私钥，因为它们不会被沿用。

Anaplan 的多重身份验证适用于使用电子邮件和密码登录的用户。对于自动化的计划连接，证书身份验证是无需密码的选项。

如果粘贴的私钥或证书无法读取、私钥已加密或不是 RSA，或者私钥与证书不匹配，证书模式会在联系 Anaplan 之前拒绝。如果 Anaplan 本身拒绝证书，错误信息会说明证书是否已过期。常见原因是证书未注册到 Anaplan 用户，或 CA 不受您的租户信任。

## 创建连接

<Steps>

1. 打开 **Tools > Connections** 并单击 `New Connection`。

2. 从菜单中选择 **Anaplan**。

3. 填写各字段：

   | 字段 | 值 |
   |---|---|
   | 名称 | 易记的名称，例如 `Anaplan Prod`。 |
   | API 主机 | 可选。留空则使用 Anaplan 的标准地址 `https://api.anaplan.com`。 |
   | 身份验证主机 | 可选。留空则使用 Anaplan 的标准地址 `https://auth.anaplan.com`。 |
   | 身份验证模式 | **基本**（默认）或**证书**。参见上文的[身份验证](#身份验证)。 |
   | 用户名 | Anaplan 账户的用户名。仅限基本模式。 |
   | 密码 | Anaplan 账户的密码。仅限基本模式。 |
   | CA 证书 | 在 Anaplan 中注册的 X.509 证书的 PEM 文本。仅限证书模式。 |
   | 私钥 | 证书的 RSA 私钥的 PEM 文本，未加密。仅限证书模式。 |
   | 默认工作区 ID | 可选。为读取步骤的工作区字段预填的便捷值。 |
   | 默认模型 ID | 可选。为读取步骤的模型字段预填的便捷值。 |
   | 超时（秒） | 默认为 30。 |

4. 单击 `Test Connection`。测试成功时，会报告这些凭据对应的 Anaplan 账户电子邮件。

5. 单击 `Create`。

</Steps>

## Anaplan：读取视图

添加 **Anaplan：读取视图** 步骤，通过 Anaplan 的大容量读取请求路径读取已保存的视图。**视图按其在 Anaplan 中保存时的样子原样读取，此步骤没有行、列或页面选择**。要读取不同的切片，请在 Anaplan 中构建另一个已保存的视图，在 Anaplan 中筛选通常的做法是使用布尔型行项目加已保存的视图。只有当视图把**行项目放在列轴上**时，数据列才会以其声明的 Anaplan 类型加载；如果行项目在行上（普通的损益表布局），或视图中没有行项目，则所有列都以文本加载，并且步骤会给出提示。筛选结果为空的视图会加载一个空表并给出警告。步骤无法明确读取的数值（最常见的是既可能是普通小数，也可能是欧式格式的数值）会被拒绝而不是猜测，除非同一列中的另一个值能确定正确的读法。能够解析的值以完整精度加载，没有舍入误差。完整的字段和行为参考请参见 [Anaplan：读取视图](/zh-cn/reference/workflow-steps/anaplan/anaplan-read-view/)。

## Anaplan：读取导出

添加 **Anaplan：读取导出** 步骤，运行**现有的** Anaplan 导出操作并加载其生成的文件。API 无法创建导出操作，需先在 Anaplan 中构建或编辑；该步骤也无法缩小导出的内容，加载的正是导出操作在 Anaplan 中配置的全部内容。**每一列都以文本加载**。数字按美式格式请求；仍然带有千位分隔符返回的列会原样以文本加载，并给出具名警告，而不是使运行失败。当导出失败、被取消、没有产生数据、在步骤的轮询预算用尽后仍在运行，或者生成的文件无法与该导出对应，或其行数与 Anaplan 自己报告的不一致时，步骤会停止而不加载表。完整参考请参见 [Anaplan：读取导出](/zh-cn/reference/workflow-steps/anaplan/anaplan-read-export/)。

## Anaplan：读取列表

添加 **Anaplan：读取列表** 步骤，将一个或多个 Anaplan 列表读取到 PlaidCloud 维度中。**一个步骤读取整个复合层次结构**：按从根开始的顺序列出它涉及的每个列表（例如先 Region，再 Country，再 Store），而不要拆分到多个步骤中；暂存表在每次运行时都会被替换，因此多个步骤指向同一个暂存表时，各步骤都会清除前一个步骤的行。由于 Anaplan 列表层次结构没有可读取的逐边权重或符号，每条边都以普通的 `+` 汇总。Anaplan 的列表访问控制和子集成员关系不会导入，因为它们是元数据，而不是维度数据。重复的节点 ID、无法解析的父级引用、相互冲突的父级引用，以及与导入的元数据冲突的属性名称，都会在加载任何内容之前被拒绝。完整参考请参见 [Anaplan：读取列表](/zh-cn/reference/workflow-steps/anaplan/anaplan-read-list/)。

## 将 Anaplan 作为 Data Foundation 源

[Data Foundation](/zh-cn/guides/projects/data-foundation/) 可以将 Anaplan 中保存的计划（预算、预测或合并模型的结果）读取到其 Common Finance Model 中。它只引入计划，不引入总账，并且只读取。

Data Foundation 运行模型的一个导出操作，按其保存的样子读取，因此需要先由 Anaplan 管理员构建该导出。**基础数据**选项卡会为其撰写请求。导出必须是一个平面网格，每个实体、期间、科目和部门各占一行，列标题必须与下面完全一致：

| 列 | 内容 |
|---|---|
| `Entity` | 实体代码。 |
| `Period` | 月份，格式为 `YYYY-MM`。 |
| `Account` | 科目代码。 |
| `Department` | 部门代码，计划中没有部门时留空。 |
| `Currency` | 金额的货币。 |
| `Amount` | 不带千位分隔符的纯数字，采用计划保存时的符号（收入为正）。 |

然后在**基础数据**选项卡上将该连接添加为源，与其他连接相同（参见[连接您的 ERP](/zh-cn/guides/projects/data-foundation/#连接-erp)）。新连接要求填写**用户名**、**密码**、**工作区 ID** 和**模型 ID**。Anaplan 不会列出可供勾选的实体，因此表单要求填写一个：在**名称**下输入要保留的导出的实体，或留空以保留所有实体。然后填写**System settings**，它们以下列名称显示：

| 设置 | 含义 |
|---|---|
| `export` | 要运行的导出操作的 ID。 |
| `scenario` | `Budget`（默认）、`Forecast` 或 `Consolidated`，后者用于集团损益表所对账的合并模型结果。 |
| `version` | 标记在每一行上的标签。默认为 `Anaplan`。 |

金额按原样读取，采用自然符号。仍然带有千位分隔符分组返回的列会被标记，而不是猜测，与 [Anaplan：读取导出](/zh-cn/reference/workflow-steps/anaplan/anaplan-read-export/)相同。

## 计划方面的注意事项

Anaplan 的请求速率预算是**租户范围内共享的**，由您的组织针对该 Anaplan 租户运行的所有集成共同使用，而不只是 PlaidCloud，并且 PlaidCloud 不会跨并发运行协调计划。多个 Anaplan 步骤落在同一个 cron 分钟上，可能在其中任何一个完成之前就耗尽该预算。请**错开 Anaplan 工作流的计划**，而不要让它们同时运行。
