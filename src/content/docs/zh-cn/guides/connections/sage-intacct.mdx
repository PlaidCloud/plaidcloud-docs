将 PlaidCloud 连接到 Sage Intacct 并提取财务和会计数据。本指南将带您从 Web 服务凭据开始，直至完成一次可用的提取。字段参考请参阅 [Sage Intacct REST 连接器](/zh-cn/reference/connectors/rest/sage-intacct/)。

## 先决条件

在 Sage Intacct 中，您需要具备：

- 为公司启用 **Web Services**：由 Sage 支持团队为您配置 **Sender ID** 和 **Sender password**，它们将分别成为连接的**客户端 ID** 和**客户端密钥**。
- 一个供 PlaidCloud 使用的 **Web 服务用户**，对查询将读取的**每一个**对象都具有权限。
- 您的**公司 ID**。

开始之前，请记录公司 ID、Web 服务用户名、客户端 ID（Sender ID）和客户端密钥（Sender password）。

<Aside type="caution">客户端 ID/客户端密钥与 Web 服务用户名是相互独立的。客户端 ID/客户端密钥用于向 Sage 验证应用程序的身份；Web 服务用户名与公司 ID 结合，用于验证在您公司内的登录。三者缺一不可，且客户端 ID/客户端密钥属于机密信息。</Aside>

## 创建连接

Intacct 是 **REST 系列**连接。PlaidCloud 提供专用的 **Intacct** 变体（列为 **REST - Intacct**），它会预填 OAuth2 令牌端点，仅需收集下面四个凭据字段。其底层是一个 REST 连接，使用 OAuth2 客户端凭据对 Intacct REST API 进行身份验证。

<Steps>

1. 打开 **Tools > Connections**，然后点击 `New Connection`。

2. 在 **REST** 下，选择 **Intacct**（在菜单中显示为 **REST - Intacct**）。

3. 填写以下字段：

   | 字段 | 值 |
   |---|---|
   | 名称 | 一个易记的名称，例如 `Intacct Prod`。 |
   | 客户端 ID | 您的 Intacct **Sender ID**。 |
   | 客户端密钥 | 您的 Intacct **Sender password**。 |
   | Web 服务用户名 | Web Services 用户的登录名。 |
   | 公司 ID | 您要连接的 Intacct 公司。 |

4. 点击 `Create`。

</Steps>

## 冒烟测试连接

在基于凭据构建内容之前，先确认凭据可用。

<Steps>

1. 向工作流添加一个 [REST 请求步骤](/zh-cn/guides/workflows/rest-request-step/)，并将**连接**设置为您的 Sage Intacct 连接。

2. 让它指向您的用户可见对象的一次小范围、有边界的读取。

3. 点击**发送测试请求**。

</Steps>

<Aside type="caution">
请使用**发送测试请求**，而不是“预览”选项卡。结果为绿色表示客户端 ID/客户端密钥与 Web 服务用户名均已通过身份验证。如果出错，错误信息会附带 Sage 自己的详细信息，通常是 Web Services 用户存在权限缺口，或客户端 ID/客户端密钥有误。
</Aside>

<Aside type="note">
Sage Intacct 请求为**单次请求，无需配置分页**。请不要改动分页控件。
</Aside>

## 提取数据

对于例行提取，Sage Intacct 提供了直接映射到 Intacct 对象的专用导入步骤：

- [Import Sage AP](/zh-cn/reference/workflow-steps/sage-intacct/import-sage-ap/)：应付账款发票标题
- [Import Sage AP Lines](/zh-cn/reference/workflow-steps/sage-intacct/import-sage-ap-lines/)：应付账款发票行明细
- [Import Sage Intacct Query](/zh-cn/reference/workflow-steps/sage-intacct/import-intacct-query/)：针对任意 Intacct 对象的查询
- [Import Intacct Entity](/zh-cn/reference/workflow-steps/sage-intacct/import-intacct-entity/)：总账明细、科目余额、日记账分录、维度主数据（地点、部门、类别）以及销售订单单据，对大型结果集自动进行 `readMore` 分页，并支持 `ge`/`le` 范围筛选器

选择步骤，选择您的 Sage Intacct 连接，设置对象或查询，然后运行。与任何导入一样，请使用真实类型定义金额和日期列，使其以带类型的形式到达，而不是文本。

## 验证和计划

<Steps>

1. 运行该步骤，并检查目标表的行数和列类型。

2. 对于持续的数据馈送，请[为工作流设置计划](/zh-cn/get-started/tutorials/schedule-a-workflow/)。

</Steps>

## 故障排除

| 症状 | 可能原因 |
|---|---|
| 身份验证失败 | 客户端 ID/客户端密钥有误（由 Sage 配置），或 Web 服务用户名有误。 |
| 权限/对象未找到错误 | Web Services 用户对所读取的对象没有权限。 |
| 结果为空或不符合预期 | **公司 ID** 有误。 |
