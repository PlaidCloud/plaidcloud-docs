[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例的数据汇集到一个 Common Finance Model 中，Sage Intacct 是它可以直接读取的 ERP 之一。该连接使用 Intacct Web Services：为 PlaidCloud 设置发送方授权，以及一个只读 Web Services 用户。本页面面向进行这些设置的 Sage Intacct 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码。

## 发送访问请求

在**主页**的 **Data Foundation** 下打开项目的**系统**页面，在**添加系统**下的**系统**中选择您的系统，然后单击**还没有访问权限？**。该系统会进入等待访问权限状态，并显示一份涵盖项目各个系统的请求。单击**复制请求**可将其粘贴到您自己的邮件中，单击**通过电子邮件发送请求**则会在您的邮件程序中打开，邮件主题为“PlaidCloud 访问权限”。

## Sage Intacct 管理员需要设置的内容

<Steps>

1. **将 PlaidCloud 授权为 Web Services 发送方**。在 **Company > Admin > Web Services authorizations** 下，添加 PlaidCloud 提供给您的发送方 ID。请回传发送方 ID 以及 Sage 为其签发的发送方密码。

2. **创建 Web Services 用户**。在 **Company > Admin > Users** 下，创建类型为“Business”且勾选“Web services only”选项的用户，以及对以下对象具有**查看**权限的角色：

   | 区域 | 对象 |
   |---|---|
   | 总账 | 科目、统计账户、日记账分录（所有日记账，包括调整日记账）、科目余额、报告期间、汇率、预算 |
   | 公司 | 实体（位置）、部门、类别、项目 |
   | 应收账款 | 客户、发票、调整、付款 |
   | 应付账款 | 供应商、账单、调整、付款 |
   | 现金管理 | 支票账户 |
   | 库存控制 | 项目 |
   | 订单录入 | 交易（销售发票，以及冲回它们的贷项通知单和退货），如果需要销售数据 |

   请授予该用户对公司顶层以及 PlaidCloud 要报告的每个实体的访问权限。如果您的贷项通知单和退货交易定义的名称不是 Sales Credit Memo 和 Sales Return，请告知 PlaidCloud 用户它们的名称。

3. **允许该用户的 IP 地址**，如果您的公司按 IP 限制 Web Services。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 公司 ID | **公司 ID** |
| Web Services 用户 ID | **Web 服务用户名** |
| 发送方 ID | **客户端 ID** |
| 发送方密码 | **客户端密钥** |
| 贷项通知单和退货交易定义的名称（如果不是默认值） | 系统设置 **Credit memo and return document types**（默认值：Sales Credit Memo、Sales Return） |
| PlaidCloud 可以读取的实体 | 在**选项**的**公司**下勾选，或不勾选以读取全部实体 |

密码请通过密码管理器传递，切勿通过电子邮件发送。PlaidCloud 用户的团队自行将发送方密码输入为**客户端密钥**。属于贵公司自身抵销的实体放在系统设置 **Elimination entities** 下。

## 检查访问权限

返回 PlaidCloud，添加系统后，在**系统**页面上该系统所在的行中单击**测试连接**。它会读取必需的数据集，并将每个数据集显示为**可读取**、**缺少权限**或**错误**。下面标为可选的数据集不在测试范围内：如果 Sage Intacct 拒绝读取其中某项，下次加载后，**CFM-Accounting - Close and assurance** 仪表板上的就绪状态检查会指出需要授权的对象。

| 数据集 | 所需权限 |
|---|---|
| 实体 | 公司：实体（查看） |
| 会计科目表 | 总账：科目和统计账户（查看） |
| 部门 | 公司：部门（查看） |
| 客户 | 应收账款：客户（查看） |
| 产品 | 库存控制：项目（查看） |
| 汇率 | 总账：汇率（查看） |
| 财务日历 | 总账：报告期间（查看） |
| 试算平衡表 | 总账：科目余额（查看） |
| 总账 | 总账：日记账分录（查看） |
| 月末余额（可选） | 总账：科目余额（查看） |
| 银行余额（可选） | 现金管理：支票账户（查看），以及月末余额 |
| 站点（可选） | 公司：实体（位置）（查看） |
| 利润中心（可选） | 公司：类别（查看） |
| 项目（可选） | 公司：项目（查看） |
| 供应商（可选） | 应付账款：供应商（查看） |
| 销售明细行（可选） | 订单录入：交易（查看） |
| 供应商发票明细行（可选） | 应付账款：账单和调整（查看） |
| 未清项和付款（可选） | 应收账款：发票、调整和付款，以及应付账款：账单、调整和付款（查看） |
| 预算（可选） | 总账：预算（查看） |
| 分摊动因（可选） | 总账：科目余额（查看） |

当缺少某个数据集时，测试会指出需要添加的权限。请管理员将其添加到角色后重新测试。不使用某个可选数据集的公司仍会加载其他所有内容。当 Sage Intacct 拒绝了构建某个月份的供应商发票、未清项或付款所需的读取时，该月份会保留其已有的行，并在下次加载时重新读取。

日记账的录入人、录入时间、审批人及其冲销的内容从日记账的批次中读取。无法读取批次的角色会使这些信息为空。
