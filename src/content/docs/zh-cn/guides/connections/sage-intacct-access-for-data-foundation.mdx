[Data Foundation](/zh-cn/guides/projects/data-foundation/) 将您连接的每个 ERP 系统和实例的数据汇集到一个 Common Finance Model 中，Sage Intacct 是它可以直接读取的 ERP 之一。该连接使用 Intacct Web Services：为 PlaidCloud 设置发送方授权，以及一个只读 Web Services 用户。本页面面向进行这些设置的 Sage Intacct 管理员，也面向请求管理员进行设置的 PlaidCloud 用户。

PlaidCloud 只读取数据。切勿通过电子邮件发送密码。

## 发送访问请求

在项目的**基础数据**选项卡上，在 **Sage Intacct 连接**下选择**创建新连接**。表单会显示完整的请求。单击**复制请求**可将其粘贴到您自己的邮件中，或单击**通过电子邮件发送请求**，在邮件程序中打开它，主题为“Read-only Sage Intacct access for PlaidCloud (Web Services).”

## Sage Intacct 管理员需要设置的内容

<Steps>

1. **将 PlaidCloud 授权为 Web Services 发送方**。在 **Company > Admin > Web Services authorizations** 下，添加 PlaidCloud 提供给您的发送方 ID。请回传发送方 ID 以及 Sage 为其签发的发送方密码。

2. **创建 Web Services 用户**。在 **Company > Admin > Users** 下，创建类型为“Business”且勾选“Web services only”选项的用户，以及对以下对象具有**查看**权限的角色：

   | 区域 | 对象 |
   |---|---|
   | 总账 | 科目、日记账分录（所有日记账，包括调整日记账）、科目余额、报告期间、汇率、预算 |
   | 公司 | 实体（位置）、部门、类别、项目 |
   | 应收账款 | 客户 |
   | 库存控制 | 项目 |
   | 订单录入 | 交易（销售发票，以及冲回它们的贷项通知单和退货），如果需要销售数据 |

   请授予该用户对公司顶层以及 PlaidCloud 要报告的每个实体的访问权限。如果您的贷项通知单和退货交易定义的名称不是 Sales Credit Memo 和 Sales Return，请告知 PlaidCloud 用户它们的名称。

3. **允许该用户的 IP 地址**，如果您的公司按 IP 限制 Web Services。

</Steps>

## 需要回传的内容

| 管理员发送 | 在 PlaidCloud 中输入为 |
|---|---|
| 公司 ID | **公司 ID** |
| Web Services 用户 ID | **Web services user ID** |
| Web Services 用户的密码 | **Web services password** |
| 发送方 ID | **Sender ID** |
| 发送方密码 | **Sender password** |
| 贷项通知单和退货交易定义的名称（如果不是默认值） | 系统设置 `credit_documents`（默认值：Sales Credit Memo、Sales Return） |
| PlaidCloud 可以读取的实体 | 在 PlaidCloud 的 **Entities** 下选择 |

密码请通过密码管理器传递，切勿通过电子邮件发送。PlaidCloud 用户的团队自行将 **Web services password** 和 **Sender password** 粘贴到 PlaidCloud 中。属于贵公司自身抵销的实体放在系统设置 `elimination_entities` 下。

## 检查访问权限

返回 PlaidCloud，输入各值并单击**测试连接**。每个数据集显示为**可读取**、**缺少权限**或**错误**：

| 数据集 | 所需权限 |
|---|---|
| 实体 | 公司：实体（查看） |
| 会计科目表 | 总账：科目和统计账户（查看） |
| 部门 | 公司：部门（查看） |
| 客户 | 应收账款：客户（查看） |
| 产品 | 库存控制：项目（查看） |
| 汇率 | 总账：汇率（查看） |
| 财务日历 | 总账：报告期间（查看） |
| 试算平衡表 | 总账：科目余额（查看） |
| 总账 | 总账：日记账分录（查看） |
| 销售明细行 | 订单录入：交易（查看） |
| 预算 | 总账：预算（查看） |
| 分摊动因 | 总账：科目余额（查看） |

当缺少某个数据集时，测试会指出需要添加的权限。请管理员将其添加到角色后重新测试。销售明细行、预算和分摊动因是可选的：不使用它们的公司仍会加载其他所有内容。
