*~20 Minuten · Add-in installieren, anmelden, eine Tabelle abrufen, eine Live-Formel schreiben*

Wenn Ihr Arbeitsalltag ohnehin auf Tabellenkalkulationen basiert, müssen Sie Excel nicht verlassen, um mit PlaidCloud zu arbeiten. **PlaidXL** ist das PlaidCloud-Add-in für Excel: Es holt Projekttabellen in Arbeitsblätter, aktualisiert sie auf Abruf und ergänzt Formeln, die aggregierte Werte direkt aus PlaidCloud-Daten berechnen. Am Ende dieses Tutorials stammen Ihre Eingaben aus maßgeblichen Projekttabellen statt aus einer Kopie, die veraltet, sobald jemand einen Workflow erneut ausführt.

## Was Sie tun werden

1. Das PlaidXL-Add-in installieren.
2. Sich anmelden und ein Projekt auswählen.
3. Eine Tabelle in ein Arbeitsblatt abrufen und anschließend aktualisieren.
4. Formeln schreiben, die die Tabellen des Projekts auflisten und eine Summe berechnen.

## Voraussetzungen

- Excel für Microsoft 365 oder Excel 2021 oder höher unter Windows oder Mac.
- Ein PlaidCloud-Konto. Wenn Sie für PlaidCloud Single Sign-on verwenden, nutzen Sie es auch hier – PlaidXL meldet Sie über dieselbe Identität an.
- Ein Projekt, das Sie öffnen können und das mindestens eine Tabelle mit Daten und einer numerischen Spalte enthält. Jedes Projekt, auf das Sie bereits Zugriff haben, eignet sich. Wenn Sie noch keines haben, bringt Sie [Von CSV zur Antwort](/de/get-started/tutorials/csv-to-answer/) eine Tabelle in PlaidCloud.

<Aside>PlaidXL liest mit Ihren Berechtigungen. Sie sehen die Projekte und Tabellen, die Ihr Konto in PlaidCloud ohnehin sehen kann – nicht mehr –, und PlaidXL ändert eine Tabelle nur, wenn Sie sie zurückspeichern und bestätigen.</Aside>

## Schritt 1: Das Add-in installieren

1. Öffnen Sie in Excel **Insert → Add-ins**. (In älteren Mac-Versionen **Insert → Store**.)
2. Geben Sie `PlaidCloud` in das Suchfeld ein.
3. Wählen Sie das Add-in **PlaidCloud** aus und klicken Sie auf **Hinzufügen**.

Auf dem Menüband erscheint eine Registerkarte **PlaidCloud**. Sie installieren das Add-in einmal pro Computer, nicht pro Arbeitsmappe.

<Aside type="tip">Sehen Sie die Registerkarte **PlaidCloud** nicht? Schließen Sie alle Excel-Fenster und öffnen Sie Excel erneut. Wenn Ihre Organisation Add-ins verwaltet, muss Ihr Microsoft-365-Administrator es möglicherweise für Sie bereitstellen. Siehe [PlaidXL installieren](/de/reference/cli/plaidxl/install/).</Aside>

## Schritt 2: Anmelden und ein Projekt auswählen

1. Öffnen Sie eine neue Arbeitsmappe und klicken Sie auf **PlaidCloud → Open PlaidXL**.
2. Geben Sie die E-Mail-Adresse ein, die Sie für PlaidCloud verwenden, und klicken Sie auf **Sign In**.
3. Wenn Sie mehreren Workspaces angehören, wählen Sie unter **Select a workspace** einen aus und klicken Sie auf **Sign In**.
4. Lassen Sie das Pop-up zu, wenn Excel danach fragt, und melden Sie sich wie gewohnt an – mit Passwort und Zwei-Faktor-Code oder per Single Sign-on.

Die Kopfzeile des Aufgabenbereichs zeigt Ihren Workspace an. Klicken Sie in der Kopfzeile auf den Projektnamen, um Ihre Projekte zu öffnen, und klicken Sie dann auf Ihr Projekt. Die Arbeitsmappe merkt es sich. Seine Tabellen erscheinen auf der Registerkarte **Tables**.

## Schritt 3: Eine Tabelle abrufen

1. Klicken Sie auf der Registerkarte **Tables** auf eine Tabelle. **Rows** und **Columns** zeigen ihre Größe.
2. Deaktivieren Sie unter **Column** alle Spalten, die Sie nicht benötigen. Weniger Spalten laden schneller.
3. Lassen Sie **Matching Worksheet** ausgewählt und klicken Sie auf **Retrieve Table**.

Die Tabelle landet in einem neuen Arbeitsblatt, das nach ihr benannt ist, und ist sofort einsatzbereit: eine fett formatierte Kopfzeile, die beim Scrollen sichtbar bleibt, Filter für jede Spalte und ein benannter Bereich über die Daten. Eine Tabelle mit dem Namen **Sample data** landet im Blatt `Sample_data` mit dem benannten Bereich `_Sample_data`, sodass Formeln, die den Bereich verwenden, mit den wachsenden Daten mitwachsen.

Erstellen Sie darauf Formeln, PivotTables und Diagramme, wie Sie es in jedem anderen Blatt tun würden.

## Schritt 4: Aktualisieren

Wenn sich die Tabelle in PlaidCloud ändert – ein Workflow wird erneut ausgeführt, neue Daten werden geladen –, klicken Sie im Aufgabenbereich oder auf dem Menüband auf **Refresh All Tables**. Die Blattregisterkarte wird während der Aktualisierung gelb und grün, sobald sie aktuell ist. Jede Tabelle, die Sie in die Arbeitsmappe abgerufen haben, wird mit den von Ihnen gewählten Spalten und dem gewählten Filter aktualisiert.

## Schritt 5: Eine Live-Formel schreiben

Der Aufgabenbereich kopiert Tabellen hinein. PlaidXL-Formeln gehen weiter: Sie berechnen aus PlaidCloud-Daten in jeder beliebigen Zelle.

1. Listen Sie auf einem neuen Blatt die Tabellen des Projekts in `A1` auf:

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   Die Namen laufen in Spalte A nach unten.

2. Listen Sie in `C1` die Spalten Ihrer Tabelle auf und ersetzen Sie `Sample data` durch den Namen Ihrer Tabelle:

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. Wählen Sie aus dieser Liste eine numerische Spalte und eine Textspalte mit einem Wert, den Sie darin kennen. Summieren Sie die numerische Spalte für diesen Wert und ersetzen Sie die Namen durch Ihre eigenen:

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` zeigt die Summe von **amount** für die Zeilen, in denen **Region** den Wert **EMEA** hat – in PlaidCloud berechnet, live in Ihrem Blatt. Ändern Sie den Wert in `E3`, und die Summe folgt.

Wenn die Spalte mit einer [Dimension](/de/guides/dimensions/dimensions/) verknüpft ist, kann der Wert ein beliebiger Knoten darin sein, und die Summe aggregiert alles unterhalb dieses Knotens. So summiert ein PlaidXL-Bericht eine Region, eine Abteilung oder ein Jahr aus den Detailzeilen.
