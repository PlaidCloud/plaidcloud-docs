*ca. 20 Minuten · das Add-in installieren, anmelden, eine Tabelle abrufen, eine Live-Formel schreiben*

Wenn Ihr Arbeitstag ohnehin aus Tabellenkalkulationen besteht, müssen Sie Excel nicht verlassen, um mit PlaidCloud zu arbeiten. **PlaidXL** ist das PlaidCloud-Add-in für Excel: Es holt Projekttabellen in Arbeitsblätter, aktualisiert sie auf Abruf und ergänzt Formeln, die verdichtete Werte direkt aus PlaidCloud-Daten berechnen. Am Ende dieses Tutorials stammen Ihre Eingaben aus maßgeblichen Projekttabellen statt aus einem Copy-and-paste, das veraltet, sobald jemand einen Workflow erneut ausführt.

## Was Sie tun werden

1. Das PlaidXL-Add-in installieren.
2. Sich anmelden und ein Projekt wählen.
3. Eine Tabelle in ein Arbeitsblatt abrufen und anschließend aktualisieren.
4. Formeln schreiben, die die Tabellen des Projekts auflisten und eine Summe berechnen.

## Voraussetzungen

- Excel für Microsoft 365 oder Excel 2021 oder neuer, unter Windows oder Mac.
- Ein PlaidCloud-Konto. Wenn Sie für PlaidCloud Single Sign-on verwenden, nutzen Sie es auch hier – PlaidXL meldet sich über dieselbe Identität an.
- Ein Projekt, das Sie öffnen können und das mindestens eine Tabelle mit Daten und einer numerischen Spalte enthält. Jedes Projekt, auf das Sie Zugriff haben, eignet sich. Wenn Sie noch keins haben, bringt [Von der CSV-Datei zur Antwort](/de/get-started/tutorials/csv-to-answer/) eine Tabelle in PlaidCloud.

<Aside>PlaidXL liest mit Ihren Berechtigungen. Sie sehen die Projekte und Tabellen, die Ihr Konto in PlaidCloud bereits sehen kann – nicht mehr – und PlaidXL ändert sie nie.</Aside>

## Schritt 1: Das Add-in installieren

1. Öffnen Sie in Excel **Einfügen → Add-Ins**. (In älteren Mac-Versionen **Einfügen → Store**.)
2. Geben Sie `PlaidCloud` in das Suchfeld ein.
3. Wählen Sie das Add-in **PlaidCloud** aus und klicken Sie auf **Hinzufügen**.

Auf dem Menüband erscheint eine Registerkarte **PlaidCloud**. Sie installieren es einmal pro Computer, nicht pro Arbeitsmappe.

<Aside type="tip">Sehen Sie die Registerkarte **PlaidCloud** nicht? Schließen Sie alle Excel-Fenster und öffnen Sie Excel neu. Wenn Ihre Organisation Add-ins verwaltet, muss Ihr Microsoft-365-Administrator es möglicherweise für Sie bereitstellen. Siehe [Install PlaidXL](/de/reference/cli/plaidxl/install/).</Aside>

## Schritt 2: Anmelden und ein Projekt wählen

1. Öffnen Sie eine neue Arbeitsmappe und klicken Sie auf **PlaidCloud → Show Taskpane**.
2. Geben Sie die E-Mail-Adresse ein, die Sie für PlaidCloud verwenden, und klicken Sie auf **Sign In**.
3. Wenn Sie mehreren Workspaces angehören, wählen Sie einen unter **Select a tenant** aus und klicken Sie auf **Sign In**.
4. Lassen Sie das Pop-up zu, wenn Excel danach fragt, und melden Sie sich wie gewohnt an – mit Kennwort und Zwei-Faktor-Code oder per Single Sign-on.

Der Aufgabenbereich zeigt **Connected to** Ihre Workspace-ID **as** Ihr Benutzername, darunter Ihre Projekte. Klicken Sie auf Ihr Projekt. Seine Tabellen erscheinen auf der Registerkarte **Tabellen**.

## Schritt 3: Eine Tabelle abrufen

1. Klicken Sie auf der Registerkarte **Tabellen** auf eine Tabelle. **Zeilen** und **Spalten** zeigen ihre Größe.
2. Deaktivieren Sie unter **Spalte** alle Spalten, die Sie nicht benötigen. Weniger Spalten laden schneller.
3. Lassen Sie **Matching Worksheet** ausgewählt und klicken Sie auf **Retrieve Table**.

Die Tabelle landet in einem neuen Arbeitsblatt, das nach ihr benannt ist, und ist sofort einsatzbereit: eine fett formatierte Kopfzeile, die beim Scrollen sichtbar bleibt, Filter auf jeder Spalte und ein benannter Bereich über den Daten. Eine Tabelle mit dem Namen **Sample data** landet auf dem Blatt `Sample_data` mit dem benannten Bereich `_Sample_data`, sodass Formeln, die den Bereich verwenden, mit den Daten wachsen.

Erstellen Sie Formeln, PivotTables und Diagramme darauf, wie Sie es auf jedem anderen Blatt tun würden.

## Schritt 4: Aktualisieren

Wenn sich die Tabelle in PlaidCloud ändert – ein Workflow wird erneut ausgeführt, neue Daten werden geladen –, klicken Sie im Aufgabenbereich oder auf dem Menüband auf **Refresh All Tables**. Die Blattregisterkarte wird gelb, während sie aktualisiert wird, und grün, wenn sie aktuell ist. Jede Tabelle, die Sie in die Arbeitsmappe abgerufen haben, wird mit den von Ihnen gewählten Spalten und dem gewählten Filter aktualisiert.

## Schritt 5: Eine Live-Formel schreiben

Der Aufgabenbereich kopiert Tabellen hinein. PlaidXL-Formeln gehen weiter: Sie berechnen in jeder Zelle aus PlaidCloud-Daten.

1. Listen Sie auf einem neuen Blatt in `A1` die Tabellen des Projekts auf:

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   Die Namen laufen in Spalte A nach unten.

2. Listen Sie in `C1` die Spalten Ihrer Tabelle auf und ersetzen Sie `Sample data` durch den Namen Ihrer Tabelle:

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. Wählen Sie aus dieser Liste eine numerische Spalte und eine Textspalte mit einem Wert, von dem Sie wissen, dass er darin vorkommt. Summieren Sie die numerische Spalte für diesen Wert und ersetzen Sie dabei die Namen durch Ihre eigenen:

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` zeigt die Summe von **amount** für die Zeilen, in denen **Region** gleich **EMEA** ist – in PlaidCloud berechnet, live in Ihrem Blatt. Ändern Sie den Wert in `E3`, und die Summe folgt.

Ist die Spalte mit einer [Dimension](/de/guides/dimensions/dimensions/) verknüpft, kann der Wert ein beliebiger Knoten darin sein, und die Summe verdichtet alles unterhalb dieses Knotens. So summiert ein PlaidXL-Bericht eine Region, eine Abteilung oder ein Jahr aus den Detailzeilen.
