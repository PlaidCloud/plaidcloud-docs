In diesem Tutorial richten Sie einen KI-Coding-Agenten so ein, dass er über das **Model Context Protocol** (MCP) mit Ihrem PlaidCloud-Workspace interagiert. Nach der Konfiguration können Sie den Agenten direkt aus Ihrem Editor bitten, Tabellen zu lesen, Workflows auszuführen, Umlagen aufzubauen und Fragen zu Ihren Daten zu beantworten.

Dauert etwa 20 Minuten. Funktioniert mit Claude Code, Cursor, Claude Desktop, ChatGPT, GitHub Copilot und jedem MCP-kompatiblen Client.

## Was Sie aufbauen

Eine funktionierende Verbindung zwischen Ihrem KI-Coding-Agenten und Ihrem PlaidCloud-Workspace, über die der Agent Folgendes kann:

- Projekte, Tabellen, Workflows und Dimensionen auflisten
- Tabelleninhalte lesen
- Workflow-Definitionen prüfen
- Workflow-Ausführungen auslösen
- Fragen zu Ihren Daten beantworten, ohne dass Sie den Kontext wechseln müssen

## Voraussetzungen

- Ein PlaidCloud-Workspace ([starten Sie eine kostenlose Testversion](https://app.plaidcloud.com), falls Sie noch keinen haben)
- Ein KI-Coding-Agent, den Sie bereits verwenden – Claude Code, Cursor, Claude Desktop, ChatGPT, Copilot oder Gemini
- Der Agent muss MCP unterstützen (die meisten aktuellen KI-Werkzeuge tun das)

## Schritt 1: Die MCP-URL Ihres Workspace finden

Jeder PlaidCloud-Workspace stellt einen MCP-Endpunkt bereit unter:

```text
https://<your-workspace>.plaid.cloud/mcp
```

Ersetzen Sie `<your-workspace>` durch die Subdomain Ihres Workspace – dieselbe, die Sie für die Anmeldung an der PlaidCloud-Benutzeroberfläche verwenden.

## Schritt 2: Ein Authentifizierungs-Token abrufen

<Steps>

1. Rufen Sie in einem Browser, in dem Sie bei PlaidCloud angemeldet sind, Folgendes auf:
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. Kopieren Sie das auf der Seite angezeigte Bearer-Token. Bewahren Sie es sicher auf – es gewährt denselben Zugriff wie Ihr Konto.

</Steps>

<Aside type="caution">
Behandeln Sie das Token wie ein Passwort. Es umgeht die interaktive Authentifizierung und handelt in Ihrem Namen. Falls es offengelegt wird, widerrufen Sie es über denselben Endpunkt.
</Aside>

## Schritt 3: Ihren Agenten konfigurieren

<Tabs>

<TabItem label="Claude Code">

Führen Sie in Ihrem Terminal Folgendes aus:

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

Für die Authentifizierung mit statischem Token (kein OAuth-Ablauf, einfacher bei langen Sitzungen) öffnen Sie die URL aus Schritt 2 in einem Browser, kopieren das angezeigte Konfigurations-Snippet und fügen es in Ihre Datei `.mcp.json` ein.

Alle Optionen finden Sie unter [Claude-Code-Einrichtung](/de/integrations/ai-coding-agents/claude-code/).

</TabItem>

<TabItem label="Cursor">

Rufen Sie unter `https://<your-workspace>.plaid.cloud/mcp/setup/token` ein Bearer-Token ab und fügen Sie Folgendes zu Ihrer Cursor-MCP-Konfiguration hinzu:

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

Alle Optionen finden Sie unter [Cursor-Einrichtung](/de/integrations/ai-coding-agents/cursor/).

</TabItem>

<TabItem label="Claude Desktop">

Öffnen Sie Settings → Developer → MCP Servers und fügen Sie Folgendes hinzu:

- **Server-URL**: `https://<your-workspace>.plaid.cloud/mcp`
- Verwenden Sie die OAuth-Anmeldung, wenn Sie dazu aufgefordert werden

Alle Optionen finden Sie unter [Claude-Desktop-Einrichtung](/de/integrations/ai-coding-agents/claude-desktop/).

</TabItem>

<TabItem label="ChatGPT">

1. Settings → Connectors → Add custom connector
2. Geben Sie ein:
   - **Name**: `PlaidCloud`
   - **MCP-Server-URL**: `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT leitet Sie für die OAuth-Anmeldung zu PlaidCloud weiter. Genehmigen Sie die Verbindung.
4. Aktivieren Sie den Connector in jeder Unterhaltung, in der er verwendet werden soll.

Alle Optionen finden Sie unter [ChatGPT-Einrichtung](/de/integrations/ai-coding-agents/chatgpt/).

</TabItem>

<TabItem label="Copilot">

Rufen Sie ein Bearer-Token ab und fügen Sie es zu `.vscode/mcp.json` hinzu:

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

VSCode liest diese Datei beim Start und bei jeder Dateiänderung.

Alle Optionen finden Sie unter [Copilot-Einrichtung](/de/integrations/ai-coding-agents/copilot/).

</TabItem>

</Tabs>

## Schritt 4: Die Verbindung überprüfen

Stellen Sie dem Agenten eine einfache Frage:

> „Liste die Projekte in meinem PlaidCloud-Workspace auf."

Der Agent sollte mit Ihrer Projektliste antworten. Falls nicht, lesen Sie die Hinweise zur Fehlerbehebung weiter unten.

## Schritt 5: Echte Aufgaben ausprobieren

Probieren Sie nach der Verbindung Folgendes aus:

- **Ihre Daten erkunden**: „Welche Spalten hat die Tabelle `sales` in meinem Quickstart-Projekt?"
- **Einen Workflow ausführen**: „Löse den Workflow `monthly_close` im Projekt Financials aus und sag mir Bescheid, wenn er abgeschlossen ist."
- **Etwas aufbauen**: „Erstelle in meinem Workflow Test einen Table Lookup-Schritt, der Bestellungen auf die letzten 30 Tage filtert."

Die Antworten des Agenten beruhen auf dem tatsächlichen Zustand Ihres Workspace – nicht auf allgemeinen Aussagen.

## Fehlerbehebung

Wenn der Agent PlaidCloud nicht erreicht oder Authentifizierungsfehler zurückgibt:

- **Token abgelaufen** – Erneuern Sie es unter `https://<your-workspace>.plaid.cloud/mcp/setup/token`
- **Falsche Scopes** – Einige Werkzeuge erfordern bestimmte PlaidCloud-Scopes (z. B. `analyze.workflow.write`). Führen Sie im Agenten `mcp_introspect(name='<tool>')` aus, um die erforderlichen Scopes anzuzeigen
- **Workspace-Subdomain falsch** – Prüfen Sie sie durch die Anmeldung an der PlaidCloud-Benutzeroberfläche; die Subdomain ist der Teil vor `.plaid.cloud`

Weitere Informationen finden Sie unter [Fehlerbehebung für KI-Coding-Agenten](/de/integrations/ai-coding-agents/troubleshooting/).
