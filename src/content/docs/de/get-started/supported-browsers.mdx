PlaidCloud läuft in Ihrem Webbrowser, es muss nichts installiert werden. Erforderlich ist einer dieser Browser in der angegebenen oder einer neueren Version.

## Mindestversionen

| Browser | Mindestversion |
| --- | --- |
| Google Chrome | 94 |
| Microsoft Edge | 94 |
| Mozilla Firefox | 93 |
| Safari auf einem Mac | 16.4 |
| Beliebiger Browser auf einem iPad oder iPhone | iPadOS oder iOS 16.4 |

Die meisten Browser aktualisieren sich selbst, ein aktueller Browser liegt daher bereits deutlich über diesen Versionen.

## iPad und iPhone

Browser-Apps auf einem iPad oder iPhone, auch Chrome und Firefox, basieren auf der Engine von Safari. Entscheidend ist dort die iPadOS- oder iOS-Version des Geräts, nicht die verwendete Browser-App. Zum Aktualisieren öffnen Sie **Einstellungen** > **Allgemein** > **Softwareupdate**.

<Aside type="caution">
Das iPad Air 2 und das iPad mini 4 lassen sich nicht über iPadOS 15 hinaus aktualisieren, daher läuft PlaidCloud auf ihnen nicht. Verwenden Sie stattdessen einen Computer oder ein neueres iPad.
</Aside>

## Was ein älterer Browser anzeigt

Ein älterer Browser lädt PlaidCloud nicht. Er zeigt eine Seite **PlaidCloud needs a newer browser** an, die die oben genannten Versionen nennt. Aktualisieren Sie den Browser oder öffnen Sie PlaidCloud in einem der hier aufgeführten Browser.
