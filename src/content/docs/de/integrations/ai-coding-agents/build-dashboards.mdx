Verbinden Sie Ihren KI-Assistenten mit dem [MCP-Server](../getting-started/) von PlaidCloud und bitten Sie ihn um ein Diagramm oder ein ganzes Dashboard über eine Tabelle oder Ansicht in Ihrem Projekt. Der PlaidCloud-Connector ist der einzige, den Sie brauchen. Der Assistent arbeitet in Ihrem Namen, daher können Sie nur Daten in Diagrammen darstellen, die Sie ohnehin öffnen können, und der [Zeilenzugriff](/de/guides/dashboards/control-who-can-see-a-dashboard/) gilt wie überall sonst.

> Erstelle ein Diagramm des *Nettoumsatzes pro Monat* aus der Tabelle Sales Results und füge es einem neuen Dashboard namens Sales Overview hinzu.

## Bevor Sie beginnen

- **Veröffentlichen Sie zuerst die Tabelle.** Ein Diagramm lässt sich nur über eine Tabelle oder Ansicht erstellen, die in PlaidCloud veröffentlicht ist. Ist sie es nicht, fordert der Assistent Sie auf, sie zu veröffentlichen, und Sie stellen Ihre Anfrage danach erneut.
- **Öffnen Sie die Dashboard-Website einmal.** Mitglieder, die die Dashboard-Website noch nie geöffnet haben, müssen sie vor ihrer ersten Anfrage einmal öffnen. Bis dahin meldet der Assistent, dass Ihr Konto noch nicht eingerichtet ist.
- **Verwenden Sie eine angemeldete Verbindung.** Diagramme und Dashboards erstellt ein Assistent, den Sie selbst verbunden und bei dem Sie sich selbst angemeldet haben. Microsoft 365 Copilot, der In-App-Assistent von PlaidCloud, Workflow-Schritte und Dienstkonten können sie nicht erstellen.

## Diagramme

Bitten Sie um ein Diagramm, indem Sie sagen, was gemessen und wie es aufgeteilt werden soll. Der Assistent wählt die Tabelle, den Diagrammtyp und die Einstellungen.

| Einstellung | Funktion |
| --- | --- |
| **Typ** | `table`, `bar`, `line`, `pie` oder `big_number`. |
| **Kennzahlen** | Eine Spalte und die Art der Aggregation: `SUM`, `COUNT`, `AVG`, `MIN`, `MAX` oder `COUNT_DISTINCT`. `SUM` und `AVG` erfordern eine numerische Spalte. |
| **X** | Die Kategorie- oder Zeitspalte für ein Balken- oder Liniendiagramm. Ein `big_number`-Diagramm fügt eine Trendlinie hinzu, wenn Sie ihm eine solche Spalte angeben. |
| **Zeitgranularität** | Gruppiert eine Zeitspalte nach `day`, `week`, `month`, `quarter` oder `year`. |
| **Gruppieren nach** | Spalten, nach denen die Zahlen aufgeteilt werden. Ein Kreisdiagramm nimmt genau eine. |
| **Filter** | Eine Spalte, ein Vergleich (`=`, `!=`, `>`, `<`, `>=`, `<=`, `LIKE`, `ILIKE`, `NOT LIKE`, `IN` oder `NOT IN`) und ein Wert. `IN` und `NOT IN` nehmen eine Liste. |

Der Assistent erhält einen Link zum Diagramm und eine Stichprobe seiner Daten. Bitten Sie ihn, die Stichprobe mit Ihrer Frage abzugleichen, bevor Sie sich auf das Diagramm verlassen.

### Ein Diagramm bearbeiten

Der Assistent bearbeitet ein Diagramm, dessen Eigentümer Sie sind, indem er dessen `chart_id` übergibt. Ohne sie erzeugt eine wiederholte Anfrage ein zweites Diagramm. Weisen Sie den Assistenten daher an, das gerade erstellte Diagramm zu bearbeiten, statt es erneut zu erstellen.

### Berechnete Kennzahlen

Der Diagramm-Builder summiert Spalten. Für eine berechnete Kennzahl, etwa die Marge oder den Umsatz pro Einheit, fügen Sie diese zuerst als Spalte in einer PlaidCloud-[Ansicht](../getting-started/#labels-und-ansichten) hinzu, veröffentlichen die Ansicht und stellen diese Spalte im Diagramm dar. Bitten Sie den Assistenten, die Ansicht für Sie zu erstellen.

## Dashboards

Bitten Sie um ein Dashboard aus Diagrammen, die Sie erstellt haben.

- **Ein neues Dashboard** wird mit der **Standardzielgruppe für Dashboards** Ihres Projekts veröffentlicht. Hat das Projekt keine, kann jeder im Projekt es sehen. Wie Sie ändern, wer es sieht, erfahren Sie unter [Festlegen, wer ein Dashboard sehen kann](/de/guides/dashboards/control-who-can-see-a-dashboard/).
- **Das Hinzufügen zu einem vorhandenen Dashboard** funktioniert bei Dashboards, deren Eigentümer Sie sind, und entfernt nie ein Diagramm, das bereits darauf ist. Konnten einige Diagramme nicht hinzugefügt werden, bitten Sie den Assistenten, die Anfrage für die übrigen erneut auszuführen.
- **Ein Projekt pro Dashboard.** Alle Diagramme auf einem Dashboard müssen aus demselben Projekt stammen. Für ein zweites Projekt erstellen Sie ein zweites Dashboard.

<Aside>
  Die Zielgruppe verbirgt das Dashboard vor Personen, die es nicht sehen sollen. Die Daten in jedem Diagramm unterliegen weiterhin dem Projektzugriff und dem Zeilenzugriff.
</Aside>

## Wenn etwas schiefgeht

| Meldung | Was zu tun ist |
| --- | --- |
| Die Tabelle ist nicht veröffentlicht | Veröffentlichen Sie die Tabelle oder Ansicht in PlaidCloud und fragen Sie dann erneut. |
| Ihr Konto existiert noch nicht | Öffnen Sie die Dashboard-Website einmal und fragen Sie dann erneut. |
| Nicht Eigentümer dieses Diagramms oder Dashboards | Sie können nur Diagramme und Dashboards bearbeiten, deren Eigentümer Sie sind. Bitten Sie stattdessen um ein neues. |
| Eine Spalte oder Aggregation ist ungültig | Prüfen Sie die Spaltennamen und verwenden Sie `SUM` oder `AVG` nur für numerische Spalten. |
| Zeitüberschreitung beim Dienst | Das Diagramm oder Dashboard existiert möglicherweise bereits. Prüfen Sie die Dashboard-Website, bevor Sie erneut fragen. |
