Der [Agent-Modus](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot) von GitHub Copilot in VSCode unterstützt MCP-Server über eine auf Workspace oder Benutzer bezogene Datei `.vscode/mcp.json` (Workspace) oder die globale VSCode-Datei `mcp.json` (Benutzer).

<Aside type="note">Suchen Sie **Microsoft 365 Copilot** – den Assistenten in Teams und der Microsoft-365-App – statt GitHub Copilot in Ihrer IDE? Siehe [Microsoft 365 Copilot](/de/integrations/microsoft-365-copilot/).</Aside>

Sie können diese Schritte auch aus dem Fenster **Ihre KI verbinden** von PlaidCloud erreichen – GitHub Copilot finden Sie auf der Registerkarte **Andere**, neben Gemini CLI und Codex CLI.

<Aside>Die MCP-Unterstützung von Copilot hängt von der Copilot-Tarifstufe und der Einstellung `chat.mcp.enabled` in VSCode ab. Stellen Sie sicher, dass beide aktiviert sind, bevor Sie Server konfigurieren.</Aside>

## Einrichtung

1. Besorgen Sie sich ein Bearer-Token, indem Sie `https://<your-workspace>.plaid.cloud/mcp/setup/token` in einem Browser aufrufen, in dem Sie bei PlaidCloud angemeldet sind.

2. Öffnen Sie in VSCode die Befehlspalette und führen Sie **MCP: Add Server** aus, oder erstellen Sie `.vscode/mcp.json` direkt:

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. Laden Sie VSCode neu. Öffnen Sie das Copilot-Chatfenster, stellen Sie das Moduslistenfeld auf **Agent** und prüfen Sie, ob die PlaidCloud-Werkzeuge in der Werkzeugliste erscheinen (üblicherweise als `plaidcloud_*` angezeigt).

## Verwendung

Bitten Sie Copilot, PlaidCloud-Vorgänge direkt auszuführen:

- „Finde alle Workflows im Projekt `Q4 Forecast`, deren letzte Ausführung fehlgeschlagen ist.“
- „Zeig mir das Schema der Tabelle `customers` und schlage Indizes vor.“
- „Führe den Workflow `daily-load` aus und melde den Status der Ausführung.“

Copilot wählt das passende Werkzeug, führt es aus und zitiert die Ergebnisse in seiner Antwort. Bei destruktiven Vorgängen (Löschen, Organisieren, Upsert ohne `dry_run`) bittet es in der Regel um Bestätigung – prüfen Sie die geplante Aktion, bevor Sie genehmigen.

## Das Token aktualisieren

VSCode liest `.vscode/mcp.json` beim Start und bei Dateiänderungen. Wenn das Token abläuft, laden Sie `https://<your-workspace>.plaid.cloud/mcp/setup/token` neu und überschreiben Sie den Wert von `Authorization` – VSCode lädt den Server automatisch neu.

## Auf bestimmte Werkzeuge beschränken

Wenn Sie begrenzen möchten, welche PlaidCloud-Werkzeuge Copilot aufrufen kann, verwenden Sie die Werkzeug-Positivliste pro Server in VSCode (Einstellungen → Copilot → MCP → serverspezifische Werkzeugauswahl). Das ist hilfreich für schreibgeschützte Sitzungen oder um verändernde Werkzeuge (`*_upsert`, `*_run`) hinter einer ausdrücklichen erneuten Aktivierung zu halten.
