Die Unterstützung von ChatGPT für vom Benutzer hinzugefügte MCP-Server wird noch ausgerollt und variiert je nach Tarifstufe und Oberfläche. Diese Seite beschreibt, was heute funktioniert.

## ChatGPT Pro / Plus / Team – Konnektoren

Wenn Ihr ChatGPT-Tarif die Oberfläche **Konnektoren** bereitstellt (Einstellungen → Konnektoren), können Sie PlaidCloud als benutzerdefinierten MCP-Konnektor hinzufügen:

1. Gehen Sie zu **Einstellungen → Konnektoren → Benutzerdefinierten Konnektor hinzufügen**.
2. Geben Sie ein:
   - **Name**: `PlaidCloud`
   - **MCP-Server-URL**: `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT leitet Sie für die OAuth-Anmeldung zu PlaidCloud weiter. Nach der Anmeldung zeigt PlaidCloud eine Seite **Anfrage für Anwendungszugriff** an, auf der die anfragende Anwendung und die Weiterleitungs-URI genannt werden, an die die Anmeldedaten gesendet werden – prüfen Sie vor der Genehmigung, ob diese mit ChatGPT übereinstimmen.
4. Aktivieren Sie den Konnektor in jeder Unterhaltung, die ihn verwenden können soll.

<Aside>Die Oberfläche „Konnektoren“ ist möglicherweise nicht für jedes Konto oder jede Region sichtbar. Wenn Sie „Benutzerdefinierten Konnektor hinzufügen“ nicht sehen, erlaubt Ihr Tarif oder die Richtlinie Ihres Workspace derzeit keine vom Benutzer hinzugefügten MCP-Server – verwenden Sie die Umgehungslösung unten.</Aside>

## ChatGPT Enterprise

Enterprise-Administratoren können MCP-Konnektoren über die Admin-Konsole auf Workspace-Ebene festlegen. Folgen Sie derselben OAuth-Einrichtung wie oben, rechnen Sie aber mit einem Genehmigungsschritt Ihres Administrators für den Workspace, bevor der Konnektor nutzbar wird.

## Umgehungslösung – benutzerdefinierte GPTs mit REST-Aktionen

Wenn Ihr Konto keine benutzerdefinierten MCP-Konnektoren unterstützt, können Sie PlaidCloud trotzdem aus ChatGPT steuern, und zwar über ein **benutzerdefiniertes GPT**, das die REST-API von PlaidCloud als OpenAPI-Aktion aufruft:

1. Die REST-Oberfläche von PlaidCloud wird durch das OpenAPI-Dokument unter `https://<your-tenant>.plaidcloud.org/openapi_rest.json` beschrieben.
2. Erstellen Sie in ChatGPT ein benutzerdefiniertes GPT (GPTs erkunden → Erstellen) und importieren Sie unter **Aktionen** diese URL (oder fügen Sie das JSON ein).
3. Konfigurieren Sie die Authentifizierung als **OAuth** und verweisen Sie auf die Keycloak-Endpunkte von PlaidCloud. Ihr PlaidCloud-Administrator kann Ihnen die Realm-URLs und die Client-ID nennen.

Dabei werden die Werkzeugnamenskonventionen von MCP gegen direkte REST-Endpunkte getauscht – für das Modell etwas umständlicher zu navigieren, aber funktional gleichwertig für die Lese- und Schreibvorgänge, die PlaidCloud bereitstellt.

## Warum MCP nicht immer verfügbar ist

Die MCP-Unterstützung von OpenAI entwickelt sich weiter, und die verfügbaren Oberflächen (Konnektoren-Oberfläche, Aktionsschema usw.) unterscheiden sich je nach Tarifstufe und ändern sich im Lauf der Zeit. Wenn der offizielle Weg über **Konnektoren** für Ihr Konto offen ist, bevorzugen Sie ihn – er hat eine integrierte OAuth-Aktualisierung und ein Werkzeugaufruf-Erlebnis, das dem Rest dieses Abschnitts entspricht. Der Rückgriff auf benutzerdefinierte GPT-Aktionen ist nur nötig, wenn MCP für Ihr Konto noch nicht bereitgestellt wird.
