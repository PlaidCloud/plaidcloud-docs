Dimensionen sind die Hierarchien von PlaidCloud – die Bäume, mit denen Sie Kostenstellen, Produkte, Konten, Geografie, Zeiträume oder jede andere aggregierte Struktur organisieren. Sie sind die Grundlage, auf der Umlagen, Dashboards und Berichte aufbauen.

## Wann Sie eine Dimension verwenden sollten

Greifen Sie zu einer Dimension, wenn Sie:

- Werte von den Blättern zu den Eltern aggregieren möchten (Kosten nach Abteilung summieren, dann nach Region, dann nach Unternehmen)
- von einer Menge von Zeilen auf eine andere umlegen möchten, basierend auf einer gemeinsamen Hierarchie (IT-Kosten auf Geschäftseinheiten verteilen)
- ein Dashboard nach einer Struktur aufteilen möchten, die tiefer ist als eine flache Liste (Drilldown von Kontinent → Land → Stadt)
- dieselbe Gruppierungslogik an mehreren Stellen anwenden möchten – definieren Sie den Baum einmal und verweisen Sie überall darauf

Wenn Ihre Daten bereits flach und eindimensional sind, brauchen Sie keine Dimension. Eine normale Tabelle genügt.

## Wie Dimensionen aufgebaut sind

Jede Dimension hat eine **Haupthierarchie** – den kanonischen Baum, in dem jedes Blatt genau einmal registriert ist. Darüber hinaus können Sie **Alternativhierarchien** anlegen, die dieselben Blätter unter anderen Eltern neu aggregieren (z. B. gruppiert der Hauptbaum Kostenstellen nach Abteilung, eine Alternative nach Region).

Jeder Knoten im Baum kann Eigenschaften, Aliase und Werte tragen, sodass eine Hierarchie mehr ist als ein Baum aus Namen – sie ist eine Struktur mit Metadaten, auf die Umlagen und Berichte verweisen können.

Informationen zum Erstellen, Kopieren, Sortieren und Verwalten von Dimensionen finden Sie unter [Dimensionen (Hierarchien) verwenden](/de/guides/dimensions/dimensions/).

## Wie Dimensionen geladen werden

Dimensionen werden in der Regel über einen Workflow aus einer Quelltabelle befüllt:

- **Eltern-Kind-Format** – zwei Spalten (Eltern, Kind), eine Kante pro Zeile
- **Ebenenformat** – eine Spalte pro Hierarchieebene, ein vollständiger Pfad pro Zeile

Den Ladevorgang beschreibt [Dimensionen laden und entladen](/de/guides/dimensions/loading-unloading/), alle Optionen finden Sie beim Workflow-Schritt [Dimension Load](/de/reference/workflow-steps/dimensions/dimension-load/).
