Der Dokumentenbrowser ist eine geteilte Ansicht mit zwei Bereichen: links der Ordnerbaum, rechts die Dateiliste. Die Symbolleisten sind beschriftet, jede Zeile hat ein Menü **⋯**, und die meisten Vorgänge sind in beiden Bereichen auch über ein Kontextmenü per Rechtsklick verfügbar. Das Kontextmenü zeigt unterschiedliche Optionen, je nachdem, ob ein Ordner, eine Datei oder leerer Platz ausgewählt ist.

Das Stammverzeichnis eines Kontos ist selbst ein anzeigbarer Ordner, und die linke Ablagezone lädt direkt dorthin hoch.


**So öffnen Sie den Datei-Explorer:**

1. Wechseln Sie zu **Dokument > Durchsuchen**. Es öffnet Ihr Favoritenkonto oder das Standardkonto des Workspace, wenn Sie keinen Favoriten haben. Wählen Sie in der Kopfzeile der Seite ein anderes Konto aus der Liste. Oder wechseln Sie zu **Dokument > Your accounts** und doppelklicken Sie auf die Zeile des Kontos oder verwenden Sie sein Symbol **Öffnen**
2. Um mit einer angehefteten Datei zu beginnen, wählen Sie sie unter **Pinned** auf der **Übersicht** aus. **Durchsuchen** öffnet sich in ihrem Ordner mit der ausgewählten Datei

### Pop out

**Pop out** in der Kopfzeile der Seite öffnet das aktuelle Konto und den aktuellen Ordner in einem neuen Browser-Tab, sodass Sie einen Browser geöffnet lassen können, während Sie auf anderen Seiten arbeiten. Jeder Tab behält seine eigene Auswahl, es wird also nichts übernommen. Wenn beim Schließen des Tabs noch Uploads oder Importe laufen, bittet Ihr Browser um Bestätigung.

Die verschiedenen Datei- und Ordnervorgänge werden im Folgenden beschrieben.


## Eine Datei hochladen

**Drag-and-drop:**

1. Wechseln Sie zum gewünschten Verzeichnis
2. Ziehen Sie eine oder mehrere Dateien von Ihrem Desktop auf eine Ablagezone: Die linke lädt in das Stammverzeichnis des Kontos hoch, die rechte in den ausgewählten Ordner

**Über das Kontextmenü:**

1. Wechseln Sie zum gewünschten Verzeichnis
2. Klicken Sie in der Dateiliste mit der rechten Maustaste und wählen Sie `Upload Here`
3. Wählen Sie die Dateien in der Dateiauswahl des Betriebssystems aus

**Über die Symbolleiste:**

1. Wechseln Sie zum gewünschten Verzeichnis
2. Klicken Sie im rechten Bereich auf die Schaltfläche `Upload`

<Aside>Mehrere Dateien können gleichzeitig hochgeladen werden. Existiert ein Zielname bereits, werden Sie aufgefordert, das Überschreiben zu bestätigen oder abzubrechen.</Aside>

Die zwei gestrichelten Ablagezonen unter der Dateiliste benennen den Ordner, in den eine Ablage hochlädt: links das Kontostammverzeichnis, rechts der ausgewählte Ordner.

### Bereich „Uploads and imports“

Der Bereich **Uploads and imports** erscheint unter dem Browser, solange Dateien übertragen werden, und blendet sich aus, wenn es nichts anzuzeigen gibt. Er hat eine Zeile pro Upload und eine pro Import in eine Tabelle, jeweils mit Name, Status und den passenden Aktionen:

- Ein laufender Upload zeigt einen Fortschrittsbalken und **Abbrechen**. **Cancel all** stoppt jeden laufenden Upload.
- Ein fehlgeschlagener Upload hat **Wiederholen** und **Schließen**. Er bleibt bestehen, bis Sie ihn schließen, damit Sie den Grund lesen können.
- Ein abgeschlossener Upload schließt sich nach wenigen Sekunden selbst.
- Ein Import in eine Tabelle bleibt bestehen, bis Sie ihn schließen. Wenn er abgeschlossen ist, können Sie mit **Preview ›**, **Create step ›** oder **Open step ›** fortfahren. **Nicht mehr beobachten** beendet die Verfolgung eines noch laufenden Imports; der Import selbst wird nicht abgebrochen.


## Eine Datei herunterladen

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Download`


## Eine Datei umbenennen

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Rename`


## Eine Datei verschieben

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus
3. Ziehen Sie sie in den Zielordner
4. Wählen Sie `Move File`


## Eine Datei kopieren

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Copy`


## Eine Datei löschen

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Delete`


## Einen Ordner erstellen

1. Öffnen Sie das Konto
2. Klicken Sie auf `New Top Level Folder` (oder klicken Sie mit der rechten Maustaste auf einen vorhandenen Ordner und wählen Sie `New Folder`)
3. Geben Sie einen Ordnernamen ein
4. Klicken Sie auf `Create`


## Einen Ordner umbenennen

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie den gewünschten Ordner mit einem Linksklick aus
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Rename`


## Einen Ordner verschieben oder kopieren

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie den gewünschten Ordner mit einem Linksklick aus
3. Ziehen Sie ihn in den Zielordner
4. Wählen Sie `Move Folder`, um ihn zu verschieben, oder `Copy Folder`, um das Original an seinem Platz zu belassen

Ein Ordner und alles darin werden in beiden Fällen übernommen.


## Einen Ordner löschen

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie den gewünschten Ordner mit einem Linksklick aus
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Delete`


## Ordnerinhalte herunterladen (ZIP-Datei)

Die Option `Download as Zip` komprimiert jede Datei unterhalb des ausgewählten Ordners in eine einzelne `.zip`-Datei und lädt sie herunter. Das Archiv behält die im Explorer angezeigte Ordnerstruktur bei.

1. Wechseln Sie zum gewünschten Verzeichnis
2. Wählen Sie den gewünschten Ordner mit einem Linksklick aus
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Download as ZIP`


## Schreibgeschützte Konten

Ist ein Konto als schreibgeschützt markiert, werden Upload-Elemente (Ablagehinweise, die Schaltfläche `Upload` der Symbolleiste und das Kontextmenü `Upload Here`) automatisch ausgeblendet. Durchsuchen, Herunterladen und Suchen funktionieren weiterhin.


## Suche

Zum Auffinden von Dateien in einem Konto – auch über viele Unterordner oder mehrere verbundene Konten hinweg – siehe [Dokumente durchsuchen](../searching-documents/).
