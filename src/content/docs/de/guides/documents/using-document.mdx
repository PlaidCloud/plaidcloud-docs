Der Document-Browser ist eine geteilte Ansicht mit zwei Bereichen: links die Ordnerstruktur, rechts die Dateiliste. Die Symbolleisten sind beschriftet, jede Zeile hat ein Menü **⋯**, und die meisten Vorgänge sind in beiden Bereichen auch über das Kontextmenü (Rechtsklick) verfügbar. Das Kontextmenü zeigt unterschiedliche Optionen, je nachdem, ob ein Ordner, eine Datei oder leerer Bereich ausgewählt ist.

Das Stammverzeichnis eines Kontos ist selbst ein anzeigbarer Ordner. Wenn Sie Dateien auf leeren Platz in der Ordnerstruktur ziehen, werden sie direkt dort hochgeladen.


**So öffnen Sie den Datei-Explorer:**

1. Gehen Sie zu **Document > Durchsuchen**. Es öffnet Ihr Favoritenkonto oder, falls Sie keines haben, das Standardkonto des Workspace. Wählen Sie ein anderes Konto aus der Liste in der Kopfzeile der Seite. Oder gehen Sie zu **Document > Ihre Konten** und doppelklicken Sie auf die Zeile des Kontos oder verwenden Sie dessen Symbol **Dateien durchsuchen**
2. Um mit einer angehefteten Datei zu beginnen, wählen Sie sie in der **Übersicht** unter **Angeheftet** aus. **Durchsuchen** öffnet sich in ihrem Ordner mit ausgewählter Datei

### Abdocken

**Ablösen** in der Kopfzeile der Seite öffnet das aktuelle Konto und den aktuellen Ordner in einer neuen Browser-Registerkarte, sodass Sie einen Browser geöffnet lassen können, während Sie auf anderen Seiten arbeiten. Jede Registerkarte behält ihre eigene Auswahl, es wird also nichts übernommen.

Die verschiedenen Datei- und Ordnervorgänge werden unten beschrieben.


## Datei hochladen

**Per Drag-and-drop:**

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Ziehen Sie eine oder mehrere Dateien von Ihrem Desktop und legen Sie sie ab:
   - auf der Dateiliste rechts, um in den dort angezeigten Ordner hochzuladen
   - auf einem Ordner in der Pfadleiste über der Dateiliste, **Stamm** eingeschlossen, um in diesen Ordner hochzuladen
   - auf einem Ordner in der Struktur links, um in diesen Ordner hochzuladen
   - auf der Zeile **Stamm** oder auf leerem Platz in der Struktur links, um in das Stammverzeichnis des Kontos hochzuladen

**Über das Kontextmenü:**

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Klicken Sie mit der rechten Maustaste in die Dateiliste und wählen Sie `Upload Here`.
3. Wählen Sie die Dateien im Dateiauswahldialog des Betriebssystems aus.

**Über die Symbolleiste:**

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Klicken Sie im rechten Bereich auf die Schaltfläche `Upload`.

<Aside>Es können mehrere Dateien gleichzeitig hochgeladen werden. Wenn der Zielname bereits existiert, werden Sie aufgefordert, das Überschreiben zu bestätigen oder abzubrechen.</Aside>

Die Beschriftung **Ziehen Sie mehrere Dateien zum Hochladen hierher** erinnert Sie daran, dass Sie mehrere Dateien gleichzeitig ablegen können.

### Bereich „Uploads and imports“

Der Bereich **Uploads and imports** erscheint unter dem Browser, während Dateien übertragen werden, und blendet sich aus, wenn nichts anzuzeigen ist. Er enthält eine Zeile pro Upload und eine pro Import in eine Tabelle, jeweils mit Name, Status und den passenden Aktionen:

- Ein laufender Upload zeigt einen Fortschrittsbalken und **Abbrechen**. **Alle abbrechen** stoppt alle laufenden Uploads.
- Ein fehlgeschlagener Upload bietet **Wiederholen** und **Schließen**. Er bleibt bestehen, bis Sie ihn schließen, damit Sie den Grund lesen können.
- Ein abgeschlossener Upload schließt sich nach einigen Sekunden von selbst.
- Ein Import in eine Tabelle bleibt bestehen, bis Sie ihn schließen. Wenn er abgeschlossen ist, können Sie mit **Vorschau ›**, **Schritt erstellen ›** oder **Schritt öffnen ›** fortfahren. **Nicht mehr beobachten** beendet die Verfolgung eines noch laufenden Imports; der Import selbst wird nicht abgebrochen.


## Datei herunterladen

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus.
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Download`.


## Datei umbenennen

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus.
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Rename`.


## Datei verschieben

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus.
3. Ziehen Sie sie in den Zielordner oder auf die Zeile **Stamm**, um sie in das Stammverzeichnis des Kontos zu verschieben.


## Datei kopieren

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus.
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Copy`.


## Datei löschen

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie die gewünschte Datei mit einem Linksklick aus.
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Delete`.


## Ordner erstellen

1. Öffnen Sie das Konto.
2. Klicken Sie auf `New Top Level Folder` (oder klicken Sie mit der rechten Maustaste auf einen vorhandenen Ordner und wählen Sie `New Folder`).
3. Geben Sie einen Ordnernamen ein.
4. Klicken Sie auf `Create`.


## Ordner umbenennen

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie den gewünschten Ordner mit einem Linksklick aus.
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Rename`.


## Ordner verschieben oder kopieren

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie den gewünschten Ordner mit einem Linksklick aus.
3. Ziehen Sie ihn in den Zielordner oder auf die Zeile **Stamm**, um ihn in das Stammverzeichnis des Kontos zu verschieben.
4. Wählen Sie `Move Folder`, um ihn zu verschieben, oder `Copy Folder`, um das Original an seinem Platz zu belassen.

Ein Ordner und sein gesamter Inhalt werden in beiden Fällen übernommen.


## Ordner löschen

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie den gewünschten Ordner mit einem Linksklick aus.
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Delete`.


## Ordnerinhalt herunterladen (ZIP-Datei)

Die Option `Download as Zip` komprimiert alle Dateien unterhalb des ausgewählten Ordners in eine einzelne `.zip`-Datei und lädt sie herunter. Das Archiv behält die im Explorer angezeigte Ordnerstruktur bei.

1. Wechseln Sie zum gewünschten Verzeichnis.
2. Wählen Sie den gewünschten Ordner mit einem Linksklick aus.
3. Klicken Sie mit der rechten Maustaste und wählen Sie `Download as ZIP`.


## Schreibgeschützte Konten

Wenn ein Konto als schreibgeschützt markiert ist, werden die Upload-Funktionen (Drag-Hinweise, die Symbolleistenschaltfläche `Upload` und der Kontextmenüeintrag `Upload Here`) automatisch ausgeblendet. Durchsuchen, Herunterladen und Suchen funktionieren weiterhin.


## Suche

Informationen zum Finden von Dateien in einem Konto, auch über viele Unterordner oder mehrere verbundene Konten hinweg, finden Sie unter [Dokumente durchsuchen](../searching-documents/).
