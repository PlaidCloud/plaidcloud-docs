## FTP-Server-Einrichtung

Stellen Sie sicher, dass Ihr FTP-Serveradministrator Ihnen Folgendes zur Verfügung stellt:

1. Die **FTP-Server-URL** (z. B. `ftp://ftp.yourcompany.com` oder `ftp://192.168.1.100`)
2. Einen **Benutzernamen** mit Zugriff auf das Zielverzeichnis
3. Ein **Kennwort** zur Authentifizierung

<Aside>FTP überträgt Zugangsdaten und Daten im Klartext. Erwägen Sie für den Produktionseinsatz stattdessen SFTP, das den gesamten Datenverkehr über SSH verschlüsselt. Verwenden Sie FTP nur für die Verbindung mit Altsystemen, die SFTP nicht unterstützen.</Aside>

Damit haben Sie nun alles, was Sie brauchen, um Ihr FTP-Konto zu PlaidCloud Document hinzuzufügen.


## PlaidCloud-Document-Einrichtung

1. Melden Sie sich bei PlaidCloud an
2. Wählen Sie den Workspace, in dem sich das neue Dokumentenkonto befinden soll
3. Gehen Sie zu `Document > Manage Accounts`
4. Klicken Sie auf die Schaltfläche `+ New Account`
5. Wählen Sie `FTP` als **Diensttyp**
6. Geben Sie einen Namen und eine Beschreibung ein
7. Geben Sie die **FTP-Server-URL** in das Feld **Startpfad** ein (z. B. `ftp://ftp.yourcompany.com`)
8. Wählen Sie ein für Ihren Anwendungsfall geeignetes **Sicherheitsmodell**. Wenn Sie unsicher sind, belassen Sie es bei `Private`.
9. Geben Sie den **Benutzernamen** unter Authentifizierungsdaten in das Feld Benutzername ein
10. Geben Sie das **Kennwort** unter Authentifizierungsdaten in das Feld Kennwort ein
11. Klicken Sie auf die Schaltfläche „Speichern“, und Ihr neues Dokumentenkonto ist aktiv
