## WebDAV-Server-Einrichtung

Stellen Sie sicher, dass Ihnen vom Administrator Ihres WebDAV-Servers Folgendes vorliegt:

1. Die **WebDAV-Endpunkt-URL** (z. B. `https://nextcloud.yourcompany.com/remote.php/dav/files/username/`)
2. Ein **Benutzername** mit Zugriff auf das Zielverzeichnis
3. Ein **Kennwort** oder app-spezifisches Kennwort zur Authentifizierung

<Aside>Viele Cloud-Dienste bieten eine WebDAV-Schnittstelle. Nextcloud verwendet beispielsweise `https://your-server/remote.php/dav/files/{username}/` und ownCloud `https://your-server/remote.php/webdav/`. Die korrekte URL finden Sie in der Dokumentation Ihres Anbieters.</Aside>

Sie haben nun alles, was Sie benötigen, um Ihr WebDAV-Konto zu PlaidCloud Document hinzuzufügen.


## PlaidCloud-Document-Einrichtung

1. Melden Sie sich bei PlaidCloud an.
2. Wählen Sie den Workspace aus, in dem sich das neue Dokumentenkonto befinden soll.
3. Gehen Sie zu `Document > Manage Accounts`.
4. Wählen Sie die Schaltfläche `+ New Account`.
5. Wählen Sie `WebDAV` als **Diensttyp**.
6. Geben Sie einen Namen und eine Beschreibung ein.
7. Geben Sie die vollständige **WebDAV-Endpunkt-URL** in das Feld **Startpfad** ein (z. B. `https://nextcloud.yourcompany.com/remote.php/dav/files/username/`).
8. Wählen Sie ein für Ihren Anwendungsfall geeignetes **Sicherheitsmodell**. Lassen Sie es auf `Private`, wenn Sie unsicher sind.
9. Geben Sie den **Benutzernamen** unter Authentifizierungsdaten in das Feld Benutzername ein.
10. Geben Sie das **Kennwort** unter Authentifizierungsdaten in das Feld Kennwort ein.
11. Wählen Sie die Schaltfläche Speichern, und Ihr neues Dokumentenkonto ist aktiv.
