## SFTP-Server-Einrichtung

Stellen Sie sicher, dass Ihnen vom Administrator Ihres SFTP-Servers Folgendes vorliegt:

1. Der **Hostname oder die IP-Adresse** des SFTP-Servers
2. Der **SSH-Port** (Standard ist `22`)
3. Ein **Benutzername** mit Zugriff auf das Zielverzeichnis
4. Entweder ein **Kennwort** oder ein **privater SSH-Schlüssel** zur Authentifizierung
5. Optional der **SSH-Host-Key-Fingerabdruck des Servers** für eine strenge Hostprüfung

Sie haben nun alles, was Sie benötigen, um Ihr SFTP-Konto zu PlaidCloud Document hinzuzufügen.


## PlaidCloud-Document-Einrichtung

1. Melden Sie sich bei PlaidCloud an.
2. Wählen Sie den Workspace aus, in dem sich das neue Dokumentenkonto befinden soll.
3. Gehen Sie zu `Document > Manage Accounts`.
4. Wählen Sie die Schaltfläche `+ New Account`.
5. Wählen Sie `Secure File Transfer (SFTP)` als **Diensttyp**.
6. Geben Sie einen Namen und eine Beschreibung ein.
7. Geben Sie den Pfad des Remote-Verzeichnisses in das Feld **Startpfad** ein (z. B. `/data/uploads`).
8. Wählen Sie ein für Ihren Anwendungsfall geeignetes **Sicherheitsmodell**. Lassen Sie es auf `Private`, wenn Sie unsicher sind.
9. Geben Sie den **Benutzernamen** unter Authentifizierungsdaten in das Feld Public Key/User ein.
10. Geben Sie das **Kennwort** unter Authentifizierungsdaten in das Feld Private Key/Password ein.
11. Wechseln Sie zur Registerkarte **SSH-Konfiguration**.
12. Geben Sie den **Host oder die IP-Adresse** des SFTP-Servers ein.
13. Geben Sie den **SSH-Verbindungsport** ein (Standard `22`).
14. Wenn Sie anstelle eines Kennworts schlüsselbasierte Authentifizierung verwenden, fügen Sie den **privaten RSA-Schlüssel** in das Feld RSA Private Key ein. Wenn ein privater Schlüssel angegeben ist, hat er Vorrang vor dem Kennwort. Der gespeicherte Schlüssel wird nie wieder angezeigt. Um zur Kennwortauthentifizierung zurückzukehren, wählen Sie **Gespeicherten Schlüssel löschen (Kennwort verwenden)**.
15. Fügen Sie optional den **Remote Server RSA Fingerprint** für eine strenge Host-Key-Prüfung ein. Lassen Sie das Feld leer, damit es bei der ersten Verbindung automatisch gefüllt wird.
16. Wählen Sie die Schaltfläche Speichern, und Ihr neues Dokumentenkonto ist aktiv.

<Aside>Sie können die SSH-Verbindung vor dem Speichern mit der Schaltfläche **SSH-Verbindung testen** auf der Registerkarte SSH-Konfiguration testen.</Aside>
