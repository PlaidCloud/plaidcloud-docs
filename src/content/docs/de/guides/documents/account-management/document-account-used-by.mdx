Bevor Sie ein Dokumentenkonto stilllegen, ersetzen oder neu aufbauen, finden Sie heraus, was alles darauf zugreift, und verlagern Sie diese Verwendungen dann auf ein anderes Konto.

## Sehen, wo ein Konto verwendet wird

1. Wählen Sie `Document > Manage Accounts`.
2. Wählen Sie in der Zeile des Kontos das Symbol **Used By**.

Der **Verwendungsnachweis** listet jede Verwendung mit Projekt, Typ, Name und der Art auf, wie das Konto verwendet wird:

| Spalte | Werte |
| --- | --- |
| Typ | Schritt, Workflow oder Projektstandard |
| Verwendet | Direkt; Container-Bedingung; Projektstandard; oder Variable (möglicherweise verwendet) |

Schritte und Workflows, die Ihre Rolle nicht sehen kann, werden mitgezählt, aber nicht benannt. Die Liste wird projektweise zusammengestellt und weist darauf hin, wenn sie möglicherweise unvollständig ist oder welche Projekte nie durchsucht wurden.

App-Runner-Manifeste und Projektkachelbilder werden nicht durchsucht. Eine Verwendung über eine Variable wird aufgeführt, und Sie aktualisieren diese Variable manuell.

## Ein Konto neu zuweisen

1. Wählen Sie im **Verwendungsnachweis** **Re-point...**.
2. Wählen Sie das Konto, zu dem gewechselt werden soll, und klicken Sie dann auf **Vorschau**.
3. Prüfen Sie die Verwendungen. Es wurde noch nichts geändert. Deaktivieren Sie alle, die Sie unverändert lassen möchten.
4. Wählen Sie **Re-point** und bestätigen Sie.

Jede Verwendung zeigt dann ihr Ergebnis: **Changed**, **Changed since the preview**, **Not allowed**, **Project is locked**, **No longer exists** oder **Refused**. Eine fehlgeschlagene Verwendung hält die anderen nicht auf. Das Ändern eines Projektstandards erfordert einen Architect oder Workspace-Administrator.

Verwendungen über Variablen werden nie geändert. Die Vorschau nennt jede Variable und den Schritt, der manuell zu aktualisieren ist.

<Aside type="caution">Wenn Sie auf ein persönliches temporäres Laufwerk (Personal Temp Drive) umstellen, werden Workflows als das Projekt ausgeführt, das dieses Laufwerk nicht öffnen kann, und die umgestellten Schritte schlagen bei der Ausführung fehl. PlaidCloud warnt Sie für jedes betroffene Projekt.</Aside>

## Einen KI-Assistenten verwenden

* Der KI-Assistent in einem Projekt kann eine Neuzuweisung vorschlagen. Er zeigt die Änderungen auf einer Genehmigungskarte und wendet sie erst nach Ihrer Genehmigung an.
* Über MCP listet `document_account_describe(include=['used_by'])` die Verwendungen auf, und `document_account_repoint` zeigt eine Neuzuweisung in der Vorschau und wendet sie an.
