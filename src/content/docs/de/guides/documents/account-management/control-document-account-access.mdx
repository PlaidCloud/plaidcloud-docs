Für ein Konto stehen vier Arten von Zugriffsbeschränkungen zur Verfügung: Privat, Workspace, Nur Mitglieder und Sicherheitsgruppe. Die für einen Benutzer festgelegte Art der Beschränkung kann jederzeit im Kontoformular geändert werden.

<Aside>Keine der Zugriffsstufen eines Kontos gibt die Zugangsdaten preis, mit denen auf die Dokumente zugegriffen wird. Nur Kontoinhaber können die Zugangsdaten einsehen.</Aside>

## Kontozugriff aktualisieren


1. Wählen Sie in PlaidCloud `Document > Manage Accounts`
2. Öffnen Sie den Bearbeitungsmodus für das Konto, das Sie ändern möchten
3. Wählen Sie unter `Security Model` die gewünschte Stufe der Zugriffsbeschränkung
4. Klicken Sie auf die Schaltfläche „Speichern“

<Aside>Je nach gewähltem Sicherheitsmodell gibt es unterschiedliche Optionen, um in der Kontoliste unter „Konten verwalten“ festzulegen, welche Mitglieder oder Sicherheitsgruppen Zugriff haben.</Aside>


## Beschränkungsoptionen


### Alle Arbeitsbereichsmitglieder


Dieser Zugriff ist der einfachste, da er allen Mitgliedern des Workspace Zugriff gewährt und keine zusätzliche Zuweisung von Mitgliedern erfordert.



### Nur bestimmte Mitglieder


Diese Zugriffseinstellung erfordert die Zuweisung jedes einzelnen Mitglieds zu einem Konto. Die Option ist besonders nützlich in Kombination mit der Single-Sign-On-Option, Mitglieder anhand einer mit der Authentifizierung gesendeten Gruppenliste zuzuweisen. Bei Workspaces mit vielen Mitgliedern kann dieser Ansatz jedoch oft mehr Aufwand bedeuten als gewünscht – hier sind Sicherheitsgruppen hilfreich. So wählen Sie nur bestimmte Mitglieder aus:


1. Wählen Sie in der Liste „Konten verwalten“ das Mitgliedersymbol
2. Ziehen Sie die gewünschten Mitglieder aus der Spalte `Unassigned Members` links in die Spalte `Assigned Members` rechts
3. Um Mitglieder zu entfernen, gehen Sie umgekehrt vor
4. Klicken Sie auf die Schaltfläche „Speichern“

### Nur bestimmte Sicherheitsgruppen


Mit dieser Option wird die Berechtigung für den Zugriff auf ein Konto bestimmten Sicherheitsgruppen statt nur einzelnen Personen erteilt. Wenn sich Zugriffsbeschränkungen auf die Zugehörigkeit zu einer oder mehreren Sicherheitsgruppen stützen, wird die Verwaltung von Konten mit deutlich größeren Benutzerzahlen wesentlich einfacher. So bearbeiten Sie die zugewiesenen Gruppen:


1. Wählen Sie in der Liste „Konten verwalten“ das Gruppensymbol
2. Ziehen Sie die gewünschten Gruppen aus der Spalte `Unassigned Groups` links in die Spalte `Assigned Groups` rechts
3. Um Gruppen zu entfernen, gehen Sie umgekehrt vor
4. Klicken Sie auf die Schaltfläche „Speichern“

### Remote-Agents


PlaidLink-Agents verwenden häufig Dokumentenkonten, um Dateien zu speichern oder zwischen Systemen zu verschieben. Damit Remote-Agents auf Dokumentenkonten zugreifen können, MUSS ihnen die Berechtigung erteilt worden sein. Dies ist eine Sicherheitsfunktion, die unerwünschten Zugriff auf potenziell sensible Informationen einschränkt. So fügen Sie Agents hinzu:


1. Wählen Sie in der Liste „Konten verwalten“ das Agent-Symbol
2. Ziehen Sie die gewünschten Agents aus der Spalte `Unassigned Agents` links in die Spalte `Assigned Agents` rechts
3. Um Agents zu entfernen, gehen Sie umgekehrt vor
4. Klicken Sie auf die Schaltfläche „Speichern“
