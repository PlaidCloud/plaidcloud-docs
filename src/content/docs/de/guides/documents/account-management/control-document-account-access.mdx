Für ein Konto stehen vier Arten von Zugriffsbeschränkungen zur Verfügung: Privat, Workspace, Nur Mitglieder und Sicherheitsgruppe. Die für einen Benutzer festgelegte Beschränkung können Sie jederzeit im Kontoformular ändern.

<Aside>Keine der Zugriffsstufen für Konten gibt die Zugangsdaten preis, mit denen auf die Dokumente zugegriffen wird. Nur Kontoeigentümer und Workspace-Administratoren können die Zugangsdaten einsehen.</Aside>

## Kontozugriff aktualisieren


1. Wählen Sie in PlaidCloud `Document > Manage` aus
2. Öffnen Sie das Konto, das Sie ändern möchten, und wählen Sie **Bearbeiten** aus
3. Wählen Sie unter `Security Model` die gewünschte Zugriffsbeschränkung aus
4. Klicken Sie auf die Schaltfläche „Speichern“

<Aside>Je nach gewähltem Sicherheitsmodell stehen im Menü **Who can use it** in der Kontozeile unter **Verwalten** oder auf der Karte **Zugriff** der Kontoseite unterschiedliche Optionen zur Verfügung, um festzulegen, welche Mitglieder oder Sicherheitsgruppen Zugriff erhalten.</Aside>


## Beschränkungsoptionen


### Alle Arbeitsbereichsmitglieder


Dieser Zugriff ist der einfachste, da er allen Mitgliedern des Workspace Zugriff gewährt und keine zusätzliche Zuweisung von Mitgliedern erfordert.



### Nur bestimmte Mitglieder


Bei dieser Einstellung muss jedes Mitglied einzeln einem Konto zugewiesen werden. Diese Option ist besonders nützlich in Kombination mit der Single-Sign-On-Option, Mitglieder anhand einer mit der Authentifizierung gesendeten Gruppenliste zuzuweisen. Bei Workspaces mit sehr vielen Mitgliedern ist dieser Ansatz jedoch oft aufwendiger als gewünscht; hier sind Sicherheitsgruppen hilfreich. So wählen Sie nur bestimmte Mitglieder aus:


1. Öffnen Sie in **Verwalten** das Zeilenmenü des Kontos, wählen Sie **Who can use it** und anschließend **Mitglieder**
2. Aktivieren Sie die Mitglieder, die Zugriff haben sollen, und deaktivieren Sie die übrigen. Verwenden Sie das Filterfeld, um Personen zu finden, oder fügen Sie eine Liste von E-Mail-Adressen ein
3. Klicken Sie auf **Mitglieder aktualisieren**

### Nur bestimmte Sicherheitsgruppen


Bei dieser Option wird die Berechtigung für den Zugriff auf ein Konto bestimmten Sicherheitsgruppen statt nur einzelnen Personen erteilt. Wenn Zugriffsbeschränkungen auf der Zugehörigkeit zu einer oder mehreren Sicherheitsgruppen beruhen, wird die Verwaltung von Konten mit deutlich mehr Benutzern erheblich einfacher. So bearbeiten Sie die zugewiesenen Gruppen:


1. Öffnen Sie in **Verwalten** das Zeilenmenü des Kontos, wählen Sie **Who can use it** und anschließend **Gruppen**
2. Aktivieren Sie die Gruppen, die Zugriff haben sollen, und deaktivieren Sie die übrigen
3. Klicken Sie auf **Gruppen aktualisieren**

### Remote-Agenten


PlaidLink-Agenten verwenden häufig Dokumentenkonten, um Dateien zu speichern oder zwischen Systemen zu verschieben. Damit Remote-Agenten auf Dokumentenkonten zugreifen können, MUSS den Agenten die Berechtigung erteilt werden. Dies ist eine Sicherheitsfunktion, die unerwünschten Zugriff auf potenziell sensible Informationen begrenzt. So fügen Sie Agenten hinzu:


1. Öffnen Sie in **Verwalten** das Zeilenmenü des Kontos, wählen Sie **Who can use it** und anschließend **Agenten**
2. Aktivieren Sie die Agenten, die Zugriff haben sollen, und deaktivieren Sie die übrigen
3. Klicken Sie auf **Agenten aktualisieren**

Der Filter, das Einfügen einer Liste von E-Mail-Adressen, die Anzeigen **Will add** und **Will remove** und die übrigen Steuerelemente sind in jeder Auswahl identisch. Siehe [Zuweisen mit der Auswahl](/de/administration/access/managing-security-groups-and-assignments/#zuweisen-mit-der-auswahl).
