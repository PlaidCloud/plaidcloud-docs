## Beschreibung

Wenn Sie bei einem Schritt auf **Speichern** klicken, prüft PlaidCloud dessen Einstellungen und lehnt
alles ab, was nicht ausgeführt werden kann, etwa einen Ausdruck, der nicht kompiliert, oder eine Spalte, die
auf eine Weise verwendet wird, die ihr Typ nicht zulässt. Während Sie einen Schritt bearbeiten, führt Weave jetzt die meisten
dieser Prüfungen laufend aus und zeigt in einem Streifen direkt oberhalb der Schaltflächen
**Speichern** an, was Speichern ablehnen würde:

> 1 Problem, das Speichern ablehnen wird.

Jedes Problem wird unter dieser Zeile aufgelistet. Wenn es eine Zeile auf der Registerkarte **Spalten** benennt, öffnet **Gehe zu** diese Registerkarte mit der markierten Zeile.

Die Prüfungen lesen nur die Einstellungen des Schritts und die Variablen Ihres Projekts, sodass sie
schnell sind, und es ist keine KI beteiligt. Sie blockieren das Speichern nie: Speichern bleibt
verfügbar und führt beim Klicken selbst jede Prüfung aus.

<Aside type="note">
Speichern prüft außerdem einige Dinge, die dieser Streifen nicht prüft, etwa ob die Quell-
und Zieltabellen die Spalten haben, die der Schritt verwendet, und ob erforderliche Felder
ausgefüllt sind. „Keine Probleme gefunden“ bedeutet also, dass keine der während der Bearbeitung ausgeführten Prüfungen
etwas gefunden hat – nicht, dass Speichern den Schritt akzeptiert.
</Aside>

## Was der Streifen anzeigt

| Weave meldet | Bedeutung |
| --- | --- |
| Weave prüft diesen Schritt auf Probleme… | Weave führt die Prüfungen für Ihre letzte Änderung aus. |
| 1 Problem, das Speichern ablehnen wird. | Speichern würde den Schritt in seinem aktuellen Zustand ablehnen. Jedes Problem wird darunter aufgelistet. |
| Keine Probleme gefunden. Speichern prüft noch einige weitere Dinge, etwa die Quell- und Zieltabellen. | Die während der Bearbeitung ausgeführten Prüfungen haben nichts gefunden. Speichern führt weiterhin eigene Prüfungen aus, darunter einige, die dieser Streifen auslässt. |
| Weave konnte die Ausdrücke dieses Schritts nicht prüfen. … | Ein Teil des Schritts konnte nicht geprüft werden; der Grund folgt. Das ist nie ein bestandener Test. |
| Weave konnte diesen Schritt gerade nicht prüfen. Speichern prüft ihn weiterhin. | Die Prüfung wurde nicht ausgeführt, zum Beispiel weil der Server ausgelastet war. Ihre nächste Änderung fordert sie erneut an. |

### Warum Ausdrücke nicht geprüft werden konnten

| Grund | Bedeutung |
| --- | --- |
| Dieser Schritt befindet sich nicht in einem Workflow, daher können seine Ausdrücke nicht geprüft werden. Speichern prüft sie ebenfalls nicht. | Ausdrücke können Workflow-Variablen verwenden und werden daher im Workflow des Schritts geprüft. Ein Schritt, den Sie außerhalb eines Workflows geöffnet haben, wird weder hier noch von Speichern geprüft. |
| Einige seiner Ausdrücke stehen in Einstellungen, die Weave noch nicht prüfen kann. | Der Schritt hält einige Ausdrücke in Einstellungen, die diese Prüfungen nicht lesen, etwa im Filter einer zweiten Quelle. Die übrigen werden weiterhin geprüft. |
| Seine Spaltenkonfiguration kann Weave noch nicht prüfen. | Der Schritt listet seine Spalten auf eine Weise auf, die die Prüfung nicht kompilieren kann, wie es bei einem Mehrtabellen-Join der Fall ist. |

Ein Ausdruck, der eine Variable verwendet, die weder der Workflow noch das Projekt definiert,
ist ein Problem und kein Grund: „Ein Ausdruck verwendet die Variable rate, die in diesem Workflow oder Projekt nicht
definiert ist.“ Das Gleiche gilt für eine geschweifte Klammer, die keinen Variablennamen beginnt oder beendet,
wie bei einer halb eingegebenen Variablen: „Ein Ausdruck enthält eine geschweifte Klammer, die nicht
Teil eines Variablennamens ist.“ Speichern lehnt beides mit denselben Sätzen ab.

## Im Ausdruckseditor

Öffnen Sie den **Ausdruckseditor** über eine Zelle **Ausdruck** auf der Registerkarte **Spalten** oder über **Teilmenge der Daten auswählen** bzw. **Sekundären Filter auf Ergebnisdaten anwenden** auf der Registerkarte **Filter**, und eine Zeile unter dem Editor prüft
den Ausdruck während der Eingabe:

| Der Editor meldet | Bedeutung |
| --- | --- |
| Prüfung läuft… | Weave prüft, was Sie gerade eingegeben haben. |
| Keine Fehler gefunden. | Der Ausdruck lässt sich so kompilieren, wie Speichern ihn kompiliert. Zeigen Sie auf die Zeile, um zu lesen, was dabei nicht abgedeckt ist: Weave prüft die Syntax und die Spaltennamen; manche Fehler zeigen sich erst bei der Ausführung des Schritts. |
| Fehler: … | Speichern würde den Ausdruck aus dem genannten Grund ablehnen. Ein Syntaxfehler wird zusätzlich in seiner Zeile neben der Zeilennummer markiert. |
| Nicht prüfbar. … | Der Ausdruck konnte aus einem der oben genannten Gründe nicht geprüft werden. |
| Gerade nicht prüfbar. Beim Speichern des Schritts wird er weiterhin geprüft. | Die Prüfung wurde nicht ausgeführt. Ein Klick auf **Speichern** beim Schritt prüft den Ausdruck weiterhin. |

Der Editor prüft anhand der Einstellungen des Schritts in dem Stand, in dem Weave den Schritt zuletzt
geprüft hat, mit Ihrem eingesetzten Ausdruck. Wenn er von anderer Stelle geöffnet wird,
etwa vom Tabellen-Explorer, zeigt er keine Zeile an.

## Wann sie erscheint

- Während Sie einen Schritt bearbeiten, den Sie ändern können. Ein Schritt, der für Ihre
  Rolle schreibgeschützt geöffnet wird, wird während der Bearbeitung nicht geprüft.
- Nach jeder Änderung, sobald Sie pausieren. Eine Änderung, die die Einstellungen
  unverändert lässt, wird nicht erneut geprüft.
- Sie liest die Einstellungen des Schritts und die Variablen des Projekts, verursacht daher nie
  einen KI-Aufruf und fragt nie Ihr Warehouse ab.
