## Beschreibung

Wenn Sie bei einem Schritt auf **Speichern** klicken, prüft PlaidCloud dessen Einstellungen und lehnt alle ab, die nicht ausgeführt werden können, etwa einen Ausdruck, der nicht kompiliert, oder eine Spalte, die auf eine Weise verwendet wird, die ihr Typ nicht zulässt. Während Sie einen Schritt bearbeiten, führt Weave die meisten dieser Prüfungen jetzt laufend aus und zeigt in einem Streifen direkt über den **Speichern**-Schaltflächen, was Speichern ablehnen würde:

> 1 problem that Save will refuse.

Jedes Problem wird unter dieser Zeile aufgeführt. Nennt es eine Zeile auf der Registerkarte **Tabellendatenauswahl**, öffnet **Gehe zu** diese Registerkarte mit ausgewählter Zeile.

Die Prüfungen lesen nur die Einstellungen des Schritts und die Variablen Ihres Projekts. Sie sind daher schnell, und es ist keine KI beteiligt. Sie blockieren das Speichern nie: Speichern bleibt verfügbar und führt beim Klicken selbst jede Prüfung aus.

<Aside type="note">
Speichern prüft auch einige Dinge, die dieser Streifen nicht prüft, etwa ob die Quell- und Zieltabellen die vom Schritt verwendeten Spalten enthalten und ob erforderliche Felder ausgefüllt sind. „No problems found" bedeutet daher, dass keine der beim Bearbeiten ausgeführten Prüfungen etwas gefunden hat – nicht, dass Speichern den Schritt akzeptiert.
</Aside>

## Was der Streifen anzeigt

| Weave zeigt | Bedeutung |
| --- | --- |
| Weave prüft diesen Schritt auf Probleme… | Weave führt die Prüfungen für Ihre letzte Änderung aus. |
| 1 problem that Save will refuse. | Speichern würde den Schritt in seinem aktuellen Zustand ablehnen. Jedes Problem wird darunter aufgeführt. |
| No problems found. Save checks a few more things, such as the source and target tables. | Die beim Bearbeiten ausgeführten Prüfungen haben nichts gefunden. Speichern führt weiterhin eigene Prüfungen aus, darunter einige, die dieser Streifen auslässt. |
| Weave couldn't check this step's expressions. … | Ein Teil des Schritts konnte nicht geprüft werden; der Grund folgt. Das gilt nie als bestanden. |
| Weave couldn't check this step just now. Save still checks it. | Die Prüfung wurde nicht ausgeführt, zum Beispiel weil der Server ausgelastet war. Ihre nächste Änderung löst eine neue Anfrage aus. |

### Warum Ausdrücke nicht geprüft werden konnten

| Grund | Bedeutung |
| --- | --- |
| This step isn't in a workflow, so its expressions can't be checked. Save doesn't check them either. | Ausdrücke können Workflow-Variablen verwenden, daher werden sie im Workflow des Schritts geprüft. Ein Schritt, den Sie außerhalb eines Workflows geöffnet haben, wird weder hier noch von Speichern geprüft. |
| Some of its expressions are in settings Weave can't check yet. | Der Schritt hält einige Ausdrücke in Einstellungen, die diese Prüfungen nicht lesen, etwa im Filter einer zweiten Quelle. Die übrigen werden weiterhin geprüft. |
| Its column setup is one Weave can't check yet. | Der Schritt führt seine Spalten auf eine Weise auf, die die Prüfung nicht kompilieren kann, wie es bei einem Mehrtabellen-Join der Fall ist. |

Ein Ausdruck, der eine Variable verwendet, die weder der Workflow noch das Projekt definiert, ist ein Problem und kein Grund: „An expression uses the variable rate, which isn't defined in this workflow or project." Das Gleiche gilt für eine Klammer, die keinen Variablennamen beginnt oder beendet, wie bei einer halb getippten Variable: „An expression has a brace that isn't part of a variable name." Speichern lehnt beide mit denselben Sätzen ab.

## Im Ausdruckseditor

Öffnen Sie den **Ausdruckseditor** über eine **Ausdruck**-Zelle auf der Registerkarte **Tabellendatenauswahl** oder über **Teilmenge der Daten auswählen** oder **Sekundären Filter auf Ergebnisdaten anwenden** auf der Registerkarte **Datenfilter**. Eine Zeile unter dem Editor prüft den Ausdruck beim Tippen:

| Der Editor zeigt | Bedeutung |
| --- | --- |
| Checking… | Weave prüft, was Sie gerade getippt haben. |
| No errors found. | Der Ausdruck kompiliert so, wie Speichern ihn kompiliert. Zeigen Sie auf die Zeile, um zu lesen, was dabei nicht erfasst wird: Weave prüft die Syntax und die Spaltennamen; manche Fehler zeigen sich erst, wenn der Schritt ausgeführt wird. |
| Error: … | Speichern würde den Ausdruck aus dem angegebenen Grund ablehnen. Ein Syntaxfehler wird zusätzlich in seiner Zeile neben der Zeilennummer markiert. |
| Couldn't check. … | Der Ausdruck konnte aus einem der oben genannten Gründe nicht geprüft werden. |
| Couldn't check just now. Saving the step still checks it. | Die Prüfung wurde nicht ausgeführt. Wenn Sie beim Schritt auf **Speichern** klicken, wird der Ausdruck trotzdem geprüft. |

Der Editor prüft anhand der Einstellungen des Schritts, wie sie bei der letzten Prüfung des Schritts durch Weave waren, wobei Ihr Ausdruck eingesetzt wird. Von anderer Stelle geöffnet, etwa im Tabellen-Explorer, zeigt er keine Zeile an.

## Wann sie erscheint

- Während Sie einen Schritt bearbeiten, den Sie ändern können. Ein Schritt, der für Ihre Rolle schreibgeschützt geöffnet wird, wird beim Bearbeiten nicht geprüft.
- Nach jeder Änderung, sobald Sie kurz innehalten. Eine Änderung, die die Einstellungen unverändert lässt, wird nicht erneut geprüft.
- Sie liest die Einstellungen des Schritts und die Variablen des Projekts, verursacht also nie einen KI-Aufruf und fragt nie Ihr Warehouse ab.
