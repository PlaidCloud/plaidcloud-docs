## Beschreibung

Weave kann Ihnen eine E-Mail senden, sodass Sie von einem Problem erfahren, ohne
PlaidCloud geöffnet zu halten. Es gibt zwei Arten von E-Mails, und Sie
schalten jede für sich selbst ein:

- **Eine Benachrichtigung**, wenn eine Workflow-Ausführung endet und Weave ein
  schwerwiegendes Problem findet, das Sie sich ansehen sollten: eine
  fehlgeschlagene Ausführung oder ein Workflow, Schritt oder Zeitplan, der so
  eingerichtet ist, dass er nicht funktionieren kann. Sie erhalten sie für die
  Probleme, über die Weave Sie in PlaidCloud informieren würde, meist weil Sie
  den Workflow zuletzt ausgeführt haben oder Ihnen das Problem zugewiesen wurde.
- **Eine tägliche Zusammenfassung** der Probleme, über die Weave Sie informiert
  hat und die Sie noch nicht gelesen haben, gesendet zu der Zeit, die Sie
  wählen.

Beides ist ausgeschaltet, bis Sie es einschalten.

## Weave-E-Mail einschalten

1. Klicken Sie in der Kopfzeile auf die Schaltfläche **Weave**.
2. Wählen Sie **Weave-E-Mail…**.
3. Aktivieren Sie unter **Ihre E-Mail** eine der beiden Optionen oder beide:
   - **Mir eine E-Mail senden, wenn Weave ein schwerwiegendes Problem findet, das ich mir ansehen sollte**
   - **Mir täglich eine Zusammenfassung der Probleme senden, über die Weave mich informiert hat und die ich noch nicht gelesen habe**,
     und wählen Sie die **Zeit** dafür.
4. Klicken Sie auf **Speichern**.

Zeiten gelten in Ihrer eigenen Zeitzone, nämlich der, die Ihr Browser beim
Klicken auf **Speichern** verwendet. Das Fenster zeigt sie neben **Zeit** an.
Wenn Sie die tägliche Zusammenfassung nach dieser Tageszeit einschalten, kommt
die erste innerhalb einer Stunde.

Wenn PlaidCloud beim Klicken auf **Speichern** nicht erreichbar ist, zeigt das
Fenster *Ihre E-Mail-Einstellungen konnten nicht gespeichert werden. Versuchen Sie es gleich noch einmal.* an und bleibt geöffnet.

Um die E-Mails zu beenden, deaktivieren Sie die Kontrollkästchen und klicken Sie
auf **Speichern**.

## Was eine E-Mail enthält

Jede E-Mail nennt das Projekt sowie den Workflow, Schritt, die Tabelle oder die
Kennzahl jedes Problems zusammen mit der Art des Problems, zum Beispiel
*"Month End" (workflow) — Last run failed*. Sie verlinkt auf die Registerkarte
**Weave** des Projekts, auf der Sie den vollständigen Befund lesen können.

Eine E-Mail enthält nie Zahlen oder Werte aus Ihren Daten. Der Satz, den Weave
in PlaidCloud anzeigt, kann sie zitieren, deshalb lässt die E-Mail ihn weg.

Weave prüft, was Sie sehen dürfen, bevor etwas gesendet wird. Jede E-Mail wird
aus den Prüfungen von Weave erstellt, die als Sie ausgeführt werden. Sie nennt
daher nie etwas, das Ihre Zugriffsrechte verbergen, und Sie erhalten nichts über
ein Projekt, das Sie nicht mehr öffnen können.

Die tägliche Zusammenfassung listet ein Problem auf, bis Sie es auf der
Registerkarte **Weave** lesen oder das Problem verschwindet. Ein Problem, über
das Sie gestern benachrichtigt wurden und das Sie nicht gelesen haben, steht
also auch in der heutigen Zusammenfassung. Wenn nichts ungelesen ist, wird keine
Zusammenfassung gesendet.

## Für Administratoren

Workspace-Administratoren sehen im selben Fenster einen Abschnitt **Workspace**.

- **Weave darf Mitgliedern dieses Arbeitsbereichs E-Mails senden** ist
  eingeschaltet, bis Sie es deaktivieren. Ist es ausgeschaltet, sendet Weave an
  niemanden E-Mails, und das Fenster jedes Mitglieds zeigt *Ihr
  Arbeitsbereich-Administrator hat Weave-E-Mails ausgeschaltet.*
- **Ruhezeiten**, **Von** einer Stunde **Bis** zu einer anderen, halten
  Benachrichtigungen zurück. Ruhezeiten gelten in der eigenen Zeitzone jedes
  Mitglieds und können über Mitternacht hinausgehen, zum Beispiel von 20:00 bis
  07:00 Uhr. Eine Benachrichtigung, die während der Ruhezeiten entsteht, wird
  gesendet, wenn diese enden, sofern das Problem noch besteht und das Mitglied
  es nicht gelesen hat. Ruhezeiten wirken sich nicht auf die tägliche
  Zusammenfassung aus, die zu der Zeit gesendet wird, die jedes Mitglied
  gewählt hat.

Jede Änderung wird im Sicherheitsprotokoll des Workspace festgehalten, mit der
Angabe, wer sie wann vorgenommen hat, zum Beispiel *Turned off Weave email.*

<Aside type="note">
Weave sendet E-Mails an die Adresse im PlaidCloud-Konto jedes Mitglieds. Ein
Mitglied, dessen Konto deaktiviert ist, erhält keine E-Mails.
</Aside>
