## Beschreibung

Daten in Dashboards lassen sich um Kennzahlen erweitern.  Jedes Dataset enthält einen Abschnitt für Kennzahlen.  Kennzahlen können mit SQL im PostgreSQL-Dialekt geschrieben und geändert werden.

<SnippetDashboardsCommonNavigateToDataset />

## Beispiele
Berechnete Spalten sind in der Regel zusätzliche Spalten, die durch die Kombination von Logik und vorhandenen Spalten entstehen.

### Ein Datum in Text umwandeln
```sql
to_char("week_ending_sol_del_req", 'YYYY-mm-dd')
```

### Verschiedene SUM-Beispiele
```sql
SUM(Value)

SUM(-1*"value_usd_mkp") / (0.0001+SUM(-1*"value_usd_base"))

(SUM("Value_USD_VAT")/SUM("Value_USD_HEADER"))*100

sum(delivery_cases) where Material_Type = Gloves

sum("total_cost") / sum("delivery_count")
```


### Verschiedene CASE-Beispiele
```sql
CASE WHEN
SUM("distance_dc_xd") = 0 THEN 0
ELSE
sum("XD")/sum("distance_dc_xd")
END

sum(CASE
WHEN "FUNCTION" = 'OM' THEN "VALUE__FC"
ELSE 0.0
END)
```


### Count
```sql
count(*)
```


### First und Cast
```sql
public.first(cast("PRETAX_SEQ" AS NUMERIC))
```


### Round
```sql
round(Sum("GROSS PROFIT"),0)
```


### Concat
```sql
concat("GCOA","CC Code")
```
