## Beschreibung

Daten in Dashboards lassen sich um berechnete Spalten erweitern.  Jedes Dataset enthält einen Abschnitt für berechnete Spalten.  Berechnete Spalten können mit SQL im PostgreSQL-Dialekt geschrieben und geändert werden.

<SnippetDashboardsCommonNavigateToDataset />

## Beispiele
### Count
```sql
COUNT(*)
```

### Min
```sql
min("MyColumnName")
```

### Max
```sql
max("MyColumnName")
```

### Coalesce (nützlich, um zum Beispiel Nullwerte in 0.0 umzuwandeln)
```sql
coalesce("BaselineCost",0.0)
```

### Substring
```sql
substring("PERIOD",6,2)
```

### Cast
```sql
CAST("YEAR" AS integer)-1
```

### Concat
```sql
concat("Biller Entity" , ' ', "Country_biller")
```

### To_char
```sql
to_char("date_created", 'YYYY-mm-dd')
```

### Left
```sql
left("period",4)
```

### Divide
Division, mit einem Behelf, um Fehler durch Division durch null zu vermeiden
```sql
sum("so_infull")/(count(*)+0.00001)
```
<Aside>Besser ist es, auf einen Nenner mit Null oder NULL zu prüfen und dann mit Coalesce auf null zu setzen, statt die Division zu versuchen.</Aside>


### Bedingte Anweisung
```sql
CASE WHEN "Field_A"= 'Foo' THEN max(coalesce("Value_A",0.0)) - max(coalesce("Value_B",0.0)) END
```
```sql
CASE WHEN "sol_otif_pod_missing" = 1 THEN
'POD is missing.'
ELSE
'POD exists.'
END
```
```sql
case when "Customer DC" = "origin_dc" or "order_reason_type" = 'Off Schedule' or "mot_type" = 'UPS' then
    'Yes'
else
    'No'
end
```
```sql
CASE WHEN "module_type" is NULL THEN '---' ELSE "module_type" END
```
```sql
CASE WHEN "NODE_TYPE" = 'External' THEN '3rd Party' ELSE "ENTITY_LOCATION_DESCRIPTION" END
```

### Concatenate
```sql
concat("Class",' > ',"Product Family",' > ',"Meta Series")
```
