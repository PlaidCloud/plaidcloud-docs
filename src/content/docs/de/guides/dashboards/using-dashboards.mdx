## Übersicht

Mit Dashboards erstellen Sie interaktive Ansichten über Daten aus jedem Projekt oder Workspace, auf den Sie Zugriff haben. Ein einzelnes Dashboard kann Tabellen aus mehreren Projekten kombinieren, Visualisierungen mit der Rohdatenexploration verbinden und sowohl ständige Berichte als auch Ad-hoc-Analysen bedienen. Dashboards skalieren ohne Konfigurationsänderungen von kleinen Referenztabellen bis zu Datensätzen mit Milliarden von Zeilen.

## Dashboard-Konten

Ihr Dashboard-Konto wird für Sie eingerichtet, wenn Sie zum ersten Mal ein Dashboard aus PlaidCloud öffnen, sodass Sie nichts von Hand erstellen müssen. Was Sie sehen können, ergibt sich aus Ihrer Mitgliedschaft im PlaidCloud-Workspace und Ihren Sicherheitsgruppen.

<Aside>Fügen Sie Personen in PlaidCloud hinzu, ändern Sie sie dort und entfernen Sie sie dort, anstatt im Dashboard-Dienst – siehe [Workspace-Mitglieder verwalten](/de/administration/access/overview/managing-workspace-members/). Das Erstellen eines Benutzerkontos direkt im Dashboard-Dienst ist eine Aktion, die Administratoren vorbehalten ist, und ein auf diese Weise erstelltes Konto ist nicht mit Ihrer Workspace-Mitgliedschaft verbunden.</Aside>

## Welche Dashboards Sie sehen

Die Seite **Dashboards** in PlaidCloud zeigt die veröffentlichten Dashboards der Projekte, auf die Sie Zugriff haben. Das ist der Normalfall und deckt nahezu jedes Dashboard ab.

Die Eigentümer eines Dashboards und Workspace-Administratoren können es auf bestimmte Sicherheitsgruppen beschränken. Ein eingeschränktes Dashboard wird nur für Mitglieder dieser Gruppen aufgelistet, zusammen mit seinen Eigentümern und den Workspace-Administratoren, die jedes Dashboard sehen. Ein Dashboard ohne Einschränkung wird jedem aufgelistet, der Zugriff auf seine Projekte hat, sodass das Einschränken eines Dashboards nie ändert, wer die anderen sieht.

Zwei Dinge sind gut zu wissen, wenn ein Dashboard in Ihrer Liste fehlt:

- **Ein eingeschränktes Dashboard wird aus der Liste ausgeblendet, nicht nur vor dem Öffnen.** Wenn Sie auf das Projekt des Dashboards zugreifen und seinen Link öffnen können, sehen Sie eine Seite **Request access**; andernfalls fragen Sie den Eigentümer, anstatt anzunehmen, dass es gelöscht wurde.
- **Ihr Dashboard-Konto muss existieren, damit Sie ein eingeschränktes Dashboard erreichen.** Es wird für Sie erstellt, wenn Sie zum ersten Mal ein Dashboard aus PlaidCloud öffnen, und Ihre Gruppen werden dann angewendet.

<Aside>Legen Sie in PlaidCloud mit **Wer kann das sehen?** fest, wer ein Dashboard sehen kann – siehe [Steuern, wer ein Dashboard sehen kann](/de/guides/dashboards/control-who-can-see-a-dashboard/). Der Projektzugriff gilt zusätzlich: Ein Dashboard zu sehen gibt Ihnen nie Daten aus einem Projekt, das Sie nicht erreichen können.</Aside>

## Der Dashboards-Workspace

**Dashboards** öffnet sich mit einer Leiste links und der von Ihnen gewählten Seite daneben. Mitglieder, die eine Seite nicht öffnen können, sehen deren Eintrag nicht. Seiten haben oben einen Titel, oft mit einem kurzen Untertitel, und ihre Aktionen in der Kopfzeile daneben.

| Eintrag der Leiste | Was er zeigt |
|---|---|
| **Übersicht** | Kacheln für **Dashboards**, **Visible to everyone**, **Eingeschränkt**, **You manage**, **Apps ready** und **Apps failed**. Wählen Sie eine Kachel aus, um ihre bereits gefilterte Liste zu öffnen. **Recently opened and favorites** listet auf, was Sie auf diesem Gerät zuletzt geöffnet oder mit einem Stern markiert haben. **Erfordert Aufmerksamkeit** listet fehlgeschlagene Apps und auf Sie wartende Zugriffsanfragen auf, mit **Prüfen**, das die von Ihnen verwalteten Dashboards öffnet. **Most opened in the last 30 days** wird Mitgliedern mit Zugriff auf die Nutzungsdaten angezeigt. |
| **Dashboards** | Die Dashboards, die Sie sehen können. Wählen Sie über der Liste **Alle**, **You manage** oder **Favoriten**. Zu den Spalten gehören **Zielgruppe**, **Eigentümer** und **Opens (30 days)**. **Import dashboard archive…** und **Zielgruppe festlegen…** befinden sich in der Symbolleiste. |
| **Apps** | Panel-, Dash- und Browser-Apps, die auf Ihren Projekten aufbauen, mit **Art**, **Status** und **Projekt**. Der Status wird live aktualisiert. Das Menü **New app** hat die Überschrift **Panel-App** über **Studio**, **Browser only** und **Server based**, dann **Dash-App** und **From gallery…**. Die Spalte **Typ** verwendet dieselben Namen. |
| **Notebooks** | Ihre JupyterLite-Bereitstellungen. |
| **Access review** | Unter **Administrator**, für Workspace-Administratoren. Siehe [Steuern, wer ein Dashboard sehen kann](/de/guides/dashboards/control-who-can-see-a-dashboard/#dashboard-zugriffsprüfung). |
| **Open navigator ↗** | Unten in der Leiste. Der Pfeil kennzeichnet ihn als den einen Eintrag, der ein eigenes Fenster öffnet: den Dashboard-Dienst in einem neuen Tab. |

Die Zahlen neben **Dashboards** und **Apps** zeigen, wie viele Sie sehen können.

## Ein Dashboard über die Seite „Dashboards“ öffnen

Klicken Sie auf der Seite **Dashboards** auf das Symbol **Öffnen** am Anfang der Zeile eines Dashboards, um es in einem neuen Tab zu öffnen. Auch ein Doppelklick auf die Zeile öffnet es.

### Das Menü mit den Zeilenaktionen

Jede Liste in PlaidCloud mit Aktionen pro Zeile, einschließlich der Seite **Dashboards**, hat ein Menü mit Zeilenaktionen. Öffnen Sie es über die Schaltfläche **⋯** am Anfang einer Zeile, per Rechtsklick auf die Zeile oder über das Menü **Aktionen** in der Symbolleiste. Das Menü hat immer denselben Aufbau:

1. **Öffnen**, **Details** und **Bearbeiten**, in dieser Reihenfolge.
2. Die eigenen Aktionen der Liste, etwa **Zugriff**, **Gruppen**, **Passwort zurücksetzen** oder **Klonen**.
3. **Löschen** oder **Entfernen**, zuletzt.

Ein Trennstrich trennt die Gruppen. Eine Aktion, die für die ausgewählte Zeile nicht zutrifft, bleibt an ihrem Platz, ist aber ausgegraut, sodass sich Einträge von Zeile zu Zeile nie verschieben.

Zwei Einträge zeigen ein Tastaturkürzel. Der Eintrag, den die Taste **Eingabetaste** ausführt und der die Zeile öffnet, zeigt **Eingabetaste**. Der Eintrag, den die Taste **Entf** ausführt, zeigt **Entf** (**Rücktaste** auf einem Mac).

Eine Liste, deren Zeilen nur eine Aktion haben, zeigt statt **⋯** das Symbol dieser Aktion am Anfang der Zeile. Klicken Sie auf das Symbol, um die Aktion auszuführen; eine destruktive Aktion verlangt weiterhin eine Bestätigung. Zeilen, die die Aktion nicht ausführen können, zeigen kein Symbol.

### Standard-, Großzügige und Kartenansicht

Listen in den Workspace-Apps von PlaidCloud, etwa **Dashboards**, **Apps**, das ERP-**Register** und die Identity-**Mitglieder**, haben in der Symbolleiste ein Menü **Ansicht** mit drei Optionen:

- **Standard rows**: die kompakte Liste, eine Zeile pro Eintrag.
- **Roomy rows**: dieselbe Liste mit mehr Platz um jede Zeile.
- **Cards**: eine Karte pro Zeile. Karten bei **Dashboards** zeigen eine Vorschau des Dashboards, und ERP-Registerkarten zeigen Betrag, Datum, Entität, Verbindung und Beleg.

Karten verhalten sich wie die Liste: Wählen Sie eine Karte aus, erweitern Sie die Auswahl mit der Umschalttaste, sortieren Sie und wählen Sie Spalten im Menü **Ansicht**, klicken Sie mit der rechten Maustaste für **Kopieren** und die Aktionen der Zeile und klicken Sie in Listen mit Favoriten, etwa **Dashboards** und **Apps**, auf den Stern, um sie als Favorit zu markieren.

## Fragen, warum eine Zahl so ist, wie sie ist

Klicken Sie in einem Dashboard mit der rechten Maustaste auf einen Punkt in einem Diagramm oder auf eine Zelle in einem Tabellendiagramm und wählen Sie
**Why this number**. PlaidCloud öffnet sich in einem neuen Tab, und Weave sagt, welcher Schritt den Wert schreibt, woher er stammt und wie er sich seit der vorherigen Ausführung verändert hat. Siehe
[Warum eine Zahl so ist, wie sie ist](/de/guides/ai-assistant/weave-numbers/#warum-diese-zahl).

## Einen Dashboard-Link öffnen, nachdem Ihre Sitzung abgelaufen ist

Wenn Ihre Sitzung abgelaufen ist, während Sie einen Link zu einem Dashboard öffnen, werden Sie aufgefordert, sich anzumelden, und gelangen dann zu diesem Dashboard statt zur Startseite der Dashboards.

## Anzeigesteuerelemente

Ein Anzeigesteuerelement ist ein Steuerelement der Filterleiste, mit dem jeder, der ein Dashboard ansieht, ändern kann, wonach ein Diagramm gruppiert ist – zum Beispiel „Region“ gegen „Produktlinie“ tauschen –, ohne das Diagramm zum Bearbeiten zu öffnen. Ein Dashboard-Editor fügt Anzeigesteuerelemente im Einstellungsmenü der Filterleiste hinzu und konfiguriert sie dort: Wählen Sie **Add or edit filters and controls** und dann im Menü **Neu** den Eintrag **Add display control**.

### Einschränken, welche Spalten erscheinen

Standardmäßig listet das Dropdown eines Anzeigesteuerelements jede Spalte des zugrunde liegenden Datasets auf, die mit **Is filterable** markiert ist. Bei einem breiten Dataset kann das bedeuten, durch Hunderte von Spalten zu scrollen, um die gewünschte zu finden.

Jedes Anzeigesteuerelement hat jetzt in seinem Konfigurationsbereich ein eigenes Feld **Available columns**. Legen Sie es auf eine bestimmte Liste von Spalten fest, und das Dropdown des Steuerelements bietet nur diese Spalten an. Lassen Sie es leer, und das Steuerelement verhält sich genau wie zuvor und bietet jede filterbare Spalte an – kein Dashboard braucht Änderungen, um weiterhin so zu funktionieren wie bisher.

So schränken Sie ein Anzeigesteuerelement ein:

1. Öffnen Sie **Add or edit filters and controls** im Einstellungsmenü der Filterleiste.
2. Wählen Sie das Anzeigesteuerelement aus, das Sie einschränken möchten, oder fügen Sie ein neues hinzu.
3. Suchen Sie unter **Available columns** die Spalten aus, die Betrachter sehen sollen, und wählen Sie sie aus.
4. Speichern Sie.

### Wie dies mit „Is Filterable“ zusammenwirkt

**Available columns** bietet nur Spalten an, die im Dataset bereits mit **Is filterable** markiert sind – die Liste wird weiter eingegrenzt, nicht umgangen. Das Deaktivieren von **Is filterable** bei einer Spalte entfernt sie weiterhin überall: aus **Available columns**, aus Ad-hoc-Filtern, aus nativen Filtern und aus der Auswahl **Simple Metric** in jedem Diagramm, das auf diesem Dataset aufbaut.

Diese große Reichweite ist genau der Grund, warum es **Available columns** gibt. Davor war die einzige Möglichkeit, das Dropdown eines Anzeigesteuerelements zu verkürzen, **Is filterable** bei den Spalten zu deaktivieren, die dort nicht angeboten werden sollten – was dieselben Spalten auch aus der Kennzahlauswahl jedes Diagramms in diesem Dataset ausblendete. Lassen Sie **Is filterable** bei jeder Spalte aktiviert, die ein Diagramm als Kennzahl oder Ad-hoc-Filter benötigen könnte, und verwenden Sie das **Available columns** jedes Anzeigesteuerelements, um zu bestimmen, was dieses Steuerelement in seinem Dropdown „Group By“ zeigt.

<Aside type="caution">Das Umbenennen oder Löschen einer Spalte, die in der Liste **Available columns** eines Anzeigesteuerelements steht, wird nicht automatisch erkannt – das Steuerelement bietet beim nächsten Öffnen einfach weniger Spalten an, ohne Warnung. Prüfen Sie **Available columns** Ihrer Anzeigesteuerelemente erneut, nachdem Sie Dataset-Spalten umbenannt oder entfernt haben.</Aside>

### Wo es gespeichert wird

**Available columns** wird pro Anzeigesteuerelement gespeichert, zusammen mit den übrigen Einstellungen dieses Steuerelements. Es wandert beim Export und Import mit dem Dashboard und hat keinen Einfluss auf ein anderes Steuerelement – weder im selben Dashboard noch in einem anderen Dashboard, das aus demselben Dataset erstellt wurde.

## Eine Tabelle bearbeiten


Die Meldung, die Sie nach dem Erstellen einer neuen Tabelle erhalten, verweist auch auf das Bearbeiten der Tabellenkonfiguration. Es gibt fortgeschrittenere Funktionen zum Bearbeiten der Konfiguration, wir beginnen aber mit einem begrenzten und einfacheren Teil. So bearbeiten Sie die Tabellenkonfiguration:


1. Klicken Sie auf das Bearbeiten-Symbol der gewünschten Tabelle.
2. Klicken Sie auf die Registerkarte „List Columns“.
3. Ordnen Sie die Spalten wie gewünscht an.
4. Klicken Sie auf „Speichern“.

Damit legen Sie fest, wie Sie bestimmte Spalten Ihrer Tabelle beim Erkunden Ihrer Daten verwenden möchten.


* **Groupable:** Wenn Benutzer Kennzahlen nach einem bestimmten Feld gruppieren sollen
* **Filterable:** Wenn Sie nach einem bestimmten Feld filtern müssen
* **Count Distinct:** Wenn Sie die Anzahl der eindeutigen Werte dieses Felds ermitteln möchten
* **Summe:** Wenn dies eine Kennzahl ist, die Sie summieren möchten
* **Min:** Wenn dies eine Kennzahl ist, für die Sie grundlegende zusammenfassende Statistiken erfassen möchten
* **Max:** Wenn dies eine Kennzahl ist, für die Sie grundlegende zusammenfassende Statistiken erfassen möchten
* **Is temporal:** Dies sollte für alle Datums- oder Zeitfelder aktiviert sein

## Ihre Daten erkunden


Um mit der Erkundung Ihrer Daten zu beginnen, klicken Sie einfach auf die gewünschte Tabelle. Standardmäßig wird Ihnen eine Tabellenansicht angezeigt.



### Eine Datenanzahl ermitteln


So ermitteln Sie die Anzahl aller Datensätze in der Tabelle:


1. Ändern Sie den Filter auf „Since“.
2. Geben Sie den gewünschten Since-Filter ein.


	* Sie können einfache Formulierungen wie „3 years ago“ verwenden.
3. Geben Sie den gewünschten Until-Filter ein.


	* Die Obergrenze für die Zeit ist standardmäßig „now“.
4. Wählen Sie die Kopfzeile „Gruppieren nach“ aus.
5. Geben Sie im Bereich für Kennzahlen „Count“ ein.
6. Wählen Sie „COUNT(*)“ aus.
7. Klicken Sie auf die Schaltfläche „Query“.

Anschließend sollten Sie Ihre Ergebnisse in der Tabelle sehen.

**Wenn Sie die Anzahl für ein bestimmtes Feld oder eine bestimmte Einschränkung ermitteln möchten:**

1. Geben Sie die gewünschte(n) Einschränkung(en) im Feld „Gruppieren nach“ ein.
2. Führen Sie die Abfrage aus.

<Aside>Wenn Sie in einer Einschränkung „measurement“ verwenden, bezieht sich das auf den Wert der erfassten Messung, der vom Messtyp abhängt. Stellen Sie daher sicher, dass die Messtypen im „Filterbereich“ identisch sind (z. B. weather_description und Maximum temperature).</Aside>

### Die Anzahl der Ergebnisse einschränken

Wenn Sie nur eine bestimmte Anzahl von Ergebnissen benötigen, etwa die obersten 10:

1. Wählen Sie „Options“ aus.
2. Geben Sie im Bereich „Row Limit“ die gewünschte maximale Ergebnisanzahl ein.
3. Klicken Sie auf „Query“.

### Zusätzliche Visualisierungswerkzeuge

So erweitern Sie abgekürzte Werte auf ihre volle Länge:

1. Wählen Sie „Edit Table Config“ aus.
2. Klicken Sie auf „List Sql Metric“.
3. Klicken Sie auf „Edit Metric“.
4. Klicken Sie auf „D3Format“.

So ändern Sie die Maßeinheit:


1. Wählen Sie „Edit Table Config“ aus.
2. Klicken Sie auf „List Sql Metric“.
3. Klicken Sie auf „Edit Metric“.
4. Klicken Sie auf „SQL Expression“.

So ändern Sie den Diagrammtyp:


1. Scrollen Sie zu „Chart Options“.
2. Füllen Sie die erforderlichen Felder aus.
3. Klicken Sie auf „Query“.

Von hier aus können Sie Achsenbeschriftungen, Ränder, Teilstriche usw. festlegen.
