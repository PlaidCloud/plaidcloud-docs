## Übersicht

Mit Dashboards erstellen Sie interaktive Ansichten über Daten aus jedem Projekt oder Workspace, auf den Sie Zugriff haben. Ein einzelnes Dashboard kann Tabellen aus mehreren Projekten kombinieren, Visualisierungen mit roher Exploration mischen und sowohl Standardberichte als auch Ad-hoc-Analysen bedienen. Dashboards skalieren von kleinen Referenztabellen bis zu Datasets mit Milliarden von Zeilen, ohne dass die Konfiguration geändert werden muss.

## Dashboard-Konten

Ihr Dashboard-Konto wird beim ersten Öffnen eines Dashboards aus PlaidCloud automatisch für Sie eingerichtet, Sie müssen also nichts von Hand erstellen. Was Sie sehen können, ergibt sich aus Ihrer Mitgliedschaft im PlaidCloud-Workspace und Ihren Sicherheitsgruppen.

<Aside>Fügen Sie Personen in PlaidCloud hinzu, ändern oder entfernen Sie sie dort – nicht im Dashboard-Dienst; siehe [Workspace-Mitglieder verwalten](/de/administration/access/overview/managing-workspace-members/). Das direkte Anlegen eines Benutzerkontos im Dashboard-Dienst ist eine reine Administratoraktion, und ein so erstelltes Konto ist nicht mit Ihrer Workspace-Mitgliedschaft verknüpft.</Aside>

## Welche Dashboards Sie sehen

Die Dashboard-Liste in PlaidCloud zeigt die veröffentlichten Dashboards der Projekte, auf die Sie Zugriff haben. Das ist der Normalfall und betrifft fast jedes Dashboard.

Die Eigentümer eines Dashboards und die Workspace-Administratoren können es auf bestimmte Sicherheitsgruppen beschränken. Ein eingeschränktes Dashboard wird nur den Mitgliedern dieser Gruppen aufgelistet, zusammen mit seinen Eigentümern und den Workspace-Administratoren, die jedes Dashboard sehen. Ein Dashboard ohne Einschränkung wird allen aufgelistet, die Zugriff auf seine Projekte haben; die Einschränkung eines Dashboards ändert daher nie, wer die anderen sieht.

Zwei Dinge sollten Sie wissen, falls ein Dashboard in Ihrer Liste fehlt:

- **Ein eingeschränktes Dashboard ist aus der Liste verborgen, nicht nur vor dem Öffnen.** Wenn Sie auf das Projekt des Dashboards zugreifen und seinen Link öffnen können, sehen Sie eine Seite **Request access**; andernfalls fragen Sie den Eigentümer, statt anzunehmen, es sei gelöscht worden.
- **Ihr Dashboard-Konto muss existieren, damit ein eingeschränktes Dashboard Sie erreicht.** Es wird beim ersten Öffnen eines Dashboards aus PlaidCloud für Sie erstellt, und Ihre Gruppen werden dann angewendet.

<Aside>Legen Sie in PlaidCloud mit **Wer kann das sehen?** fest, wer ein Dashboard sehen kann – siehe [Steuern, wer ein Dashboard sehen kann](/de/guides/dashboards/control-who-can-see-a-dashboard/). Der Projektzugriff gilt zusätzlich weiterhin: Ein sichtbares Dashboard gibt Ihnen nie Daten aus einem Projekt, das Sie nicht erreichen können.</Aside>

## Einen Dashboard-Link nach Ablauf der Sitzung öffnen

Wenn Ihre Sitzung abgelaufen ist, während Sie den Link zu einem Dashboard öffnen, werden Sie zur Anmeldung aufgefordert und gelangen danach zu diesem Dashboard statt zur Startseite der Dashboards.

## Anzeigesteuerungen

Eine Anzeigesteuerung ist ein Steuerelement der Filterleiste, mit dem jeder, der ein Dashboard ansieht, ändern kann, wonach ein Diagramm gruppiert ist – zum Beispiel „Region“ gegen „Produktlinie“ tauschen –, ohne das Diagramm zur Bearbeitung zu öffnen. Ein Dashboard-Editor fügt Anzeigesteuerungen über das Einstellungsmenü der Filterleiste hinzu und konfiguriert sie dort: Wählen Sie **Add or edit filters and controls** und dann im Menü **Neu** den Eintrag **Add display control**.

### Einschränken, welche Spalten erscheinen

Standardmäßig listet das Dropdown einer Anzeigesteuerung jede Spalte des zugrunde liegenden Datasets auf, die als **Is filterable** markiert ist. Bei einem breiten Dataset können das Hunderte Spalten sein, durch die Sie scrollen müssen, um die gewünschte zu finden.

Jede Anzeigesteuerung hat nun in ihrem Konfigurationsbereich ein eigenes Feld **Available columns**. Legen Sie dort eine bestimmte Liste von Spalten fest, und das Dropdown der Steuerung bietet nur diese Spalten an. Lassen Sie es leer, verhält sich die Steuerung genau wie zuvor und bietet jede filterbare Spalte an – kein Dashboard braucht Änderungen, um weiterhin wie bisher zu funktionieren.

So schränken Sie eine Anzeigesteuerung ein:

1. Öffnen Sie im Einstellungsmenü der Filterleiste **Add or edit filters and controls**.
2. Wählen Sie die Anzeigesteuerung aus, die Sie einschränken möchten, oder fügen Sie eine neue hinzu.
3. Suchen Sie in **Available columns** die Spalten, die Betrachter sehen sollen, und wählen Sie sie aus.
4. Speichern Sie.

### Zusammenspiel mit „Is filterable“

**Available columns** bietet immer nur Spalten an, die im Dataset bereits als **Is filterable** markiert sind – es verengt diese Liste weiter, geht aber nicht an ihr vorbei. Wenn Sie **Is filterable** bei einer Spalte deaktivieren, entfernt das sie weiterhin überall: aus **Available columns**, aus Ad-hoc-Filtern, aus nativen Filtern und aus der Auswahl **Simple Metric** jedes Diagramms, das auf diesem Dataset aufbaut.

Genau diese große Reichweite ist der Grund, warum es **Available columns** gibt. Zuvor ließ sich das Dropdown einer Anzeigesteuerung nur verkürzen, indem man **Is filterable** bei den nicht gewünschten Spalten deaktivierte – wodurch dieselben Spalten auch in der Kennzahlenauswahl jedes Diagramms dieses Datasets verschwanden. Lassen Sie **Is filterable** bei jeder Spalte aktiviert, die ein Diagramm als Kennzahl oder Ad-hoc-Filter benötigen könnte, und bestimmen Sie mit dem eigenen Feld **Available columns** jeder Anzeigesteuerung, was diese Steuerung in ihrem Dropdown „Group By“ zeigt.

<Aside type="caution">Das Umbenennen oder Löschen einer Spalte, die in der Liste **Available columns** einer Anzeigesteuerung steht, wird nicht automatisch erkannt – die Steuerung bietet beim nächsten Öffnen einfach weniger Spalten an, ohne Warnung. Prüfen Sie **Available columns** Ihrer Anzeigesteuerungen erneut, nachdem Sie Dataset-Spalten umbenannt oder entfernt haben.</Aside>

### Wo es gespeichert wird

**Available columns** wird pro Anzeigesteuerung zusammen mit den übrigen Einstellungen dieser Steuerung gespeichert. Es wandert mit dem Dashboard durch Export und Import und hat keinen Einfluss auf andere Steuerungen – weder im selben Dashboard noch in einem anderen Dashboard, das auf demselben Dataset aufbaut.

## Eine Tabelle bearbeiten


Die Meldung, die Sie nach dem Erstellen einer neuen Tabelle erhalten, weist Sie auch darauf hin, die Tabellenkonfiguration zu bearbeiten. Es gibt zwar erweiterte Funktionen zum Bearbeiten der Konfiguration, wir beginnen aber mit einem begrenzten und einfacheren Teil. So bearbeiten Sie die Tabellenkonfiguration:


1. Klicken Sie auf das Bearbeiten-Symbol der gewünschten Tabelle
2. Klicken Sie auf die Registerkarte „List Columns“
3. Ordnen Sie die Spalten nach Wunsch an
4. Klicken Sie auf „Speichern“

Damit legen Sie fest, wie Sie bestimmte Spalten Ihrer Tabelle beim Erkunden Ihrer Daten verwenden möchten.


* **Groupable:** Wenn Benutzer Kennzahlen nach einem bestimmten Feld gruppieren sollen
* **Filterable:** Wenn Sie nach einem bestimmten Feld filtern müssen
* **Count Distinct:** Wenn Sie die eindeutige Anzahl dieses Felds erhalten möchten
* **Summe:** Wenn dies eine Kennzahl ist, die Sie summieren möchten
* **Min:** Wenn dies eine Kennzahl ist, für die Sie grundlegende zusammenfassende Statistiken erfassen möchten
* **Max:** Wenn dies eine Kennzahl ist, für die Sie grundlegende zusammenfassende Statistiken erfassen möchten
* **Is temporal:** Dies sollte für alle Datums- und Zeitfelder aktiviert sein

## Ihre Daten erkunden


Um Ihre Daten zu erkunden, klicken Sie einfach auf die gewünschte Tabelle. Standardmäßig wird Ihnen eine Tabellenansicht angezeigt.



### Eine Datenanzahl ermitteln


So ermitteln Sie die Anzahl aller Datensätze in der Tabelle:


1. Ändern Sie den Filter auf „Since“
2. Geben Sie den gewünschten Since-Filter ein


	* Sie können einfache Formulierungen wie „3 years ago“ verwenden
3. Geben Sie den gewünschten Until-Filter ein


	* Die Obergrenze für die Zeit ist standardmäßig „now“
4. Wählen Sie die Kopfzeile „Gruppieren nach“
5. Geben Sie im Bereich „Metrics“ „Count“ ein
6. Wählen Sie „COUNT(*)“
7. Klicken Sie auf die Schaltfläche „Query“

Anschließend sollten Sie Ihre Ergebnisse in der Tabelle sehen.

**Wenn Sie die Anzahl für ein bestimmtes Feld oder eine bestimmte Einschränkung ermitteln möchten:**

1. Geben Sie die gewünschten Einschränkungen im Feld „Gruppieren nach“ ein
2. Führen Sie die Abfrage aus

<Aside>Wenn Sie in einer Einschränkung „measurement“ verwenden, bezieht sich das auf den Wert der erfassten Messung, der vom Messtyp abhängt. Stellen Sie daher sicher, dass die Messtypen im „Filterbereich“ identisch sind (z. B. weather_description und Maximum temperature).</Aside>

### Die Ergebnisanzahl begrenzen

Wenn Sie nur eine bestimmte Anzahl von Ergebnissen benötigen, etwa die obersten 10:

1. Wählen Sie „Options“
2. Geben Sie im Bereich „Row Limit“ die gewünschte maximale Ergebnisanzahl ein
3. Klicken Sie auf „Query“

### Zusätzliche Visualisierungswerkzeuge

So erweitern Sie abgekürzte Werte auf ihre volle Länge:

1. Wählen Sie „Edit Table Config“
2. Klicken Sie auf „List Sql Metric“
3. Klicken Sie auf „Edit Metric“
4. Klicken Sie auf „D3Format“

So bearbeiten Sie die Maßeinheit:


1. Wählen Sie „Edit Table Config“
2. Klicken Sie auf „List Sql Metric“
3. Klicken Sie auf „Edit Metric“
4. Klicken Sie auf „SQL Expression“

So ändern Sie den Diagrammtyp:


1. Scrollen Sie zu „Chart Options“
2. Füllen Sie die erforderlichen Felder aus
3. Klicken Sie auf „Query“

Von hier aus können Sie Achsenbeschriftungen, Ränder, Teilstriche usw. festlegen.
