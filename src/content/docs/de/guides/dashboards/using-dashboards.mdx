## Überblick

Mit Dashboards erstellen Sie interaktive Ansichten über Daten aus jedem Projekt oder Workspace, auf das Sie Zugriff haben. Ein einzelnes Dashboard kann Tabellen aus mehreren Projekten kombinieren, Visualisierungen mit der reinen Datenexploration verbinden und sowohl dauerhafte Berichte als auch Ad-hoc-Analysen bedienen. Dashboards skalieren ohne Konfigurationsänderungen von kleinen Referenztabellen bis zu Datensätzen mit Milliarden von Zeilen.

## Dashboard-Konten

Ihr Dashboard-Konto wird für Sie eingerichtet, sobald Sie zum ersten Mal ein Dashboard aus PlaidCloud öffnen. Sie müssen also nichts manuell erstellen. Was Sie sehen können, ergibt sich aus Ihrer Mitgliedschaft im PlaidCloud-Workspace und Ihren Sicherheitsgruppen.

<Aside>Fügen Sie Personen in PlaidCloud hinzu, ändern Sie sie und entfernen Sie sie dort, nicht im Dashboard-Dienst – siehe [Workspace-Mitglieder verwalten](/de/administration/access/overview/managing-workspace-members/). Das direkte Erstellen eines Benutzerkontos im Dashboard-Dienst ist Administratoren vorbehalten, und ein so erstelltes Konto ist nicht mit Ihrer Workspace-Mitgliedschaft verbunden.</Aside>

## Welche Dashboards Sie sehen

Die Dashboard-Liste in PlaidCloud zeigt die veröffentlichten Dashboards der Projekte, auf die Sie Zugriff haben. Das ist der Normalfall und betrifft nahezu alle Dashboards.

Die Eigentümer eines Dashboards und Workspace-Administratoren können es auf bestimmte Sicherheitsgruppen beschränken. Ein eingeschränktes Dashboard wird nur den Mitgliedern dieser Gruppen sowie seinen Eigentümern und den Workspace-Administratoren aufgelistet, die jedes Dashboard sehen. Ein Dashboard ohne Einschränkung wird allen aufgelistet, die Zugriff auf seine Projekte haben. Das Einschränken eines Dashboards ändert also nie, wer die anderen sieht.

Zwei Dinge sollten Sie wissen, wenn ein Dashboard in Ihrer Liste fehlt:

- **Ein eingeschränktes Dashboard ist in der Liste ausgeblendet, nicht nur beim Öffnen.** Wenn Sie Zugriff auf das Projekt des Dashboards haben und seinen Link öffnen, sehen Sie eine Seite **Request access**; andernfalls fragen Sie den Eigentümer, statt anzunehmen, dass es gelöscht wurde.
- **Ihr Dashboard-Konto muss existieren, damit Sie ein eingeschränktes Dashboard erhalten.** Es wird für Sie erstellt, sobald Sie zum ersten Mal ein Dashboard aus PlaidCloud öffnen, und Ihre Gruppen werden dabei angewendet.

<Aside>Legen Sie in PlaidCloud mit **Wer kann das sehen?** fest, wer ein Dashboard sehen kann – siehe [Steuern, wer ein Dashboard sehen kann](/de/guides/dashboards/control-who-can-see-a-dashboard/). Der Projektzugriff gilt weiterhin zusätzlich: Ein Dashboard zu sehen gibt Ihnen nie Daten aus einem Projekt, auf das Sie keinen Zugriff haben.</Aside>

## Ein Dashboard aus „Meine Dashboards“ öffnen

Klicken Sie in **Meine Dashboards** auf das Symbol **Öffnen** am Anfang der Zeile eines Dashboards, um es in einer neuen Registerkarte zu öffnen. Auch ein Doppelklick auf die Zeile öffnet es.

### Das Zeilenaktionsmenü

Jede Liste in PlaidCloud mit Aktionen pro Zeile, einschließlich Meine Dashboards, hat ein Zeilenaktionsmenü. Öffnen Sie es über die Schaltfläche **⋯** am Zeilenanfang, per Rechtsklick auf die Zeile oder über das Menü **Aktionen** in der Symbolleiste. Das Menü hat immer denselben Aufbau:

1. **Öffnen**, **Details** und **Bearbeiten**, in dieser Reihenfolge.
2. Die eigenen Aktionen der Liste, etwa **Zugriff**, **Gruppen**, **Passwort zurücksetzen** oder **Klonen**.
3. **Löschen** oder **Entfernen** als Letztes.

Ein Trennstrich teilt die Gruppen. Eine Aktion, die auf die ausgewählte Zeile nicht zutrifft, bleibt an ihrem Platz, ist aber ausgegraut, sodass sich Einträge von Zeile zu Zeile nie verschieben.

Zwei Einträge zeigen eine Tastenkombination. Der Eintrag, den die Taste **Enter** ausführt und der die Zeile öffnet, zeigt **Enter**. Der Eintrag, den die Taste **Entf** ausführt, zeigt **Del** (auf einem Mac **Backspace**).

Eine Liste, deren Zeilen nur eine Aktion haben, zeigt am Zeilenanfang statt **⋯** das Symbol dieser Aktion. Klicken Sie auf das Symbol, um die Aktion auszuführen; eine destruktive Aktion verlangt weiterhin eine Bestätigung. Zeilen, die die Aktion nicht ausführen können, zeigen kein Symbol.

## Einen Dashboard-Link öffnen, nachdem Ihre Sitzung abgelaufen ist

Wenn Ihre Sitzung abgelaufen ist, während Sie einen Link zu einem Dashboard öffnen, werden Sie zur Anmeldung aufgefordert und anschließend zu diesem Dashboard geleitet, statt zur Startseite der Dashboards.

## Anzeigesteuerelemente

Ein Anzeigesteuerelement ist ein Steuerelement der Filterleiste, mit dem jeder Betrachter eines Dashboards ändern kann, wonach ein Diagramm gruppiert wird – zum Beispiel „Region“ gegen „Produktlinie“ tauschen –, ohne das Diagramm zum Bearbeiten zu öffnen. Ein Dashboard-Bearbeiter fügt Anzeigesteuerelemente über das Einstellungsmenü der Filterleiste hinzu und konfiguriert sie dort: Wählen Sie **Add or edit filters and controls** und dann im Menü **Neu** die Option **Add display control**.

### Einschränken, welche Spalten erscheinen

Standardmäßig listet das Dropdown eines Anzeigesteuerelements jede Spalte des zugrunde liegenden Datensatzes auf, die mit **Is filterable** markiert ist. Bei einem breiten Datensatz kann das Hunderte von Spalten bedeuten, durch die Sie scrollen müssen, um die gewünschte zu finden.

Jedes Anzeigesteuerelement hat jetzt in seinem Konfigurationsbereich ein eigenes Feld **Available columns**. Legen Sie dort eine bestimmte Liste von Spalten fest, und das Dropdown des Steuerelements bietet nur diese Spalten an. Lassen Sie es leer, verhält sich das Steuerelement wie bisher und bietet jede filterbare Spalte an – kein Dashboard muss angepasst werden, um weiterhin wie gewohnt zu funktionieren.

So schränken Sie ein Anzeigesteuerelement ein:

1. Öffnen Sie **Add or edit filters and controls** im Einstellungsmenü der Filterleiste.
2. Wählen Sie das Anzeigesteuerelement aus, das Sie einschränken möchten, oder fügen Sie ein neues hinzu.
3. Suchen Sie unter **Available columns** die Spalten, die Betrachter sehen sollen, und wählen Sie sie aus.
4. Speichern Sie.

### Zusammenspiel mit „Is Filterable“

**Available columns** bietet immer nur Spalten an, die im Datensatz bereits mit **Is filterable** markiert sind – es schränkt diese Liste weiter ein, umgeht sie aber nicht. Wenn Sie **Is filterable** bei einer Spalte deaktivieren, entfernt das sie weiterhin überall: aus **Available columns**, aus Ad-hoc-Filtern, aus nativen Filtern und aus der Auswahl **Simple Metric** jedes Diagramms, das auf diesem Datensatz aufbaut.

Genau wegen dieser großen Reichweite gibt es **Available columns**. Davor ließ sich das Dropdown eines Anzeigesteuerelements nur kürzen, indem Sie **Is filterable** bei den Spalten deaktivierten, die dort nicht angeboten werden sollten – wodurch dieselben Spalten auch in der Kennzahlauswahl jedes Diagramms dieses Datensatzes verschwanden. Lassen Sie **Is filterable** bei jeder Spalte aktiviert, die ein Diagramm als Kennzahl oder Ad-hoc-Filter benötigen könnte, und legen Sie mit dem eigenen Feld **Available columns** jedes Anzeigesteuerelements fest, was dieses Steuerelement in seinem Dropdown „Gruppieren nach“ zeigt.

<Aside type="caution">Wenn Sie eine Spalte umbenennen oder löschen, die in der Liste **Available columns** eines Anzeigesteuerelements steht, wird das nicht automatisch erkannt – das Steuerelement bietet beim nächsten Öffnen einfach weniger Spalten an, ohne Warnung. Prüfen Sie **Available columns** Ihrer Anzeigesteuerelemente erneut, nachdem Sie Spalten des Datensatzes umbenannt oder entfernt haben.</Aside>

### Wo es gespeichert wird

**Available columns** wird pro Anzeigesteuerelement gespeichert, zusammen mit den übrigen Einstellungen dieses Steuerelements. Es wandert beim Export und Import mit dem Dashboard und hat keine Auswirkung auf andere Steuerelemente – weder im selben Dashboard noch in anderen Dashboards, die auf demselben Datensatz aufbauen.

## Eine Tabelle bearbeiten


Die Meldung, die Sie nach dem Erstellen einer neuen Tabelle erhalten, verweist auch auf das Bearbeiten der Tabellenkonfiguration. Es gibt zwar fortgeschrittenere Funktionen zum Bearbeiten der Konfiguration, wir beginnen aber mit einem begrenzten und einfacheren Teil. So bearbeiten Sie die Tabellenkonfiguration:


1. Klicken Sie auf das Bearbeiten-Symbol der gewünschten Tabelle
2. Klicken Sie auf die Registerkarte „List Columns“
3. Ordnen Sie die Spalten nach Wunsch an
4. Klicken Sie auf „Save“

Damit legen Sie fest, wie Sie bestimmte Spalten Ihrer Tabelle bei der Datenexploration verwenden möchten.


* **Groupable:** Wenn Benutzer Kennzahlen nach einem bestimmten Feld gruppieren sollen
* **Filterable:** Wenn Sie nach einem bestimmten Feld filtern müssen
* **Count Distinct:** Wenn Sie die Anzahl der eindeutigen Werte dieses Felds erhalten möchten
* **Summe:** Wenn dies eine Kennzahl ist, die Sie summieren möchten
* **Min:** Wenn dies eine Kennzahl ist, für die Sie grundlegende zusammenfassende Statistiken erheben möchten
* **Max:** Wenn dies eine Kennzahl ist, für die Sie grundlegende zusammenfassende Statistiken erheben möchten
* **Is temporal:** Aktivieren Sie dies für alle Datums- und Zeitfelder

## Ihre Daten erkunden


Um Ihre Daten zu erkunden, klicken Sie einfach auf die gewünschte Tabelle. Standardmäßig wird Ihnen eine Tabellenansicht angezeigt.



### Eine Datenanzahl ermitteln


So ermitteln Sie die Anzahl aller Datensätze in der Tabelle:


1. Ändern Sie den Filter auf „Since“
2. Geben Sie den gewünschten Since-Filter ein


	* Sie können einfache Ausdrücke wie „3 years ago“ verwenden
3. Geben Sie den gewünschten Until-Filter ein


	* Die Obergrenze für die Zeit ist standardmäßig „now“
4. Wählen Sie die Kopfzeile „Gruppieren nach“
5. Geben Sie „Count“ in den Bereich „Metrics“ ein
6. Wählen Sie „COUNT(*)“
7. Klicken Sie auf die Schaltfläche „Query“

Anschließend sollten Sie Ihre Ergebnisse in der Tabelle sehen.

**Wenn Sie die Anzahl für ein bestimmtes Feld oder eine bestimmte Einschränkung ermitteln möchten:**

1. Geben Sie die gewünschten Einschränkungen im Feld „Gruppieren nach“ ein
2. Führen Sie die Abfrage aus

<Aside>Wenn Sie „measurement“ in einer Einschränkung verwenden, bezieht es sich auf den Wert der erfassten Messung, der vom Messungstyp abhängt. Stellen Sie daher sicher, dass die Messungstypen im „Filterbereich“ übereinstimmen (z. B. weather_description und Maximum temperature).</Aside>

### Die Anzahl der Ergebnisse begrenzen

Wenn Sie nur eine bestimmte Anzahl von Ergebnissen benötigen, etwa die Top 10:

1. Wählen Sie „Options“
2. Geben Sie im Bereich „Row Limit“ die gewünschte maximale Ergebnisanzahl ein
3. Klicken Sie auf „Query“

### Zusätzliche Visualisierungswerkzeuge

So erweitern Sie abgekürzte Werte auf ihre volle Länge:

1. Wählen Sie „Edit Table Config“
2. Klicken Sie auf „List Sql Metric“
3. Klicken Sie auf „Edit Metric“
4. Klicken Sie auf „D3Format“

So bearbeiten Sie die Maßeinheit:


1. Wählen Sie „Edit Table Config“
2. Klicken Sie auf „List Sql Metric“
3. Klicken Sie auf „Edit Metric“
4. Klicken Sie auf „SQL Expression“

So ändern Sie den Diagrammtyp:


1. Scrollen Sie zu „Chart Options“
2. Füllen Sie die erforderlichen Felder aus
3. Klicken Sie auf „Query“

Von hier aus können Sie Achsenbeschriftungen, Ränder, Teilstriche usw. festlegen.
