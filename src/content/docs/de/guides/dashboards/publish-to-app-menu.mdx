Sie können ein Dashboard, eine Panel- oder Dash-App oder ein JupyterLite-Notebook aus **Erkenntnisse** im App-Menü links veröffentlichen. Die von Ihnen ausgewählten Personen öffnen es dann mit einem Klick aus dem Menü, unterhalb der Produkt-Apps.

<Aside>Das Veröffentlichen im App-Menü legt einen Eintrag im Menü an. Es gewährt niemandem Zugriff auf das Element. Eine Person sieht den Eintrag nur, wenn sie zu seiner Zielgruppe gehört **und** das Element bereits öffnen kann.</Aside>

## Wer veröffentlichen kann

Sie müssen das Element selbst öffnen und verwalten können:

| Element | Wer es veröffentlichen kann |
|---|---|
| Dashboard | Seine Eigentümer und Workspace-Administratoren, also die Personen, die seine Zielgruppe festlegen (siehe [Steuern, wer ein Dashboard sehen kann](/de/guides/dashboards/control-who-can-see-a-dashboard/)), mit Schreibzugriff auf Dashboards. |
| Panel- oder Dash-App | Mitglieder mit Schreibzugriff auf Apps, die im Projekt der App eine Rolle oberhalb von Explorer haben. Ein gesperrtes Projekt hindert Sie nicht daran. Eine App ohne Projekt kann von der Person veröffentlicht werden, die sie erstellt hat, oder von einem Workspace-Administrator. |
| JupyterLite-Notebook | Die Person, die die Bereitstellung hinzugefügt hat, oder ein Workspace-Administrator, mit Schreibzugriff auf Notebooks. |

Die Sicherheitsgruppe **Dashboard Read and Write** gewährt Schreibzugriff auf Dashboards, Apps und Notebooks.

## Ein Element veröffentlichen

1. Öffnen Sie in **Erkenntnisse** **Dashboards**, **Apps** oder **Notebooks**.
2. Wählen Sie **Im App-Menü veröffentlichen…** im Zeilenmenü des Elements, oder markieren Sie die Zeile und wählen Sie **Im App-Menü veröffentlichen…** in der Symbolleiste. Die Aktion wird angeboten, wenn Sie Schreibzugriff auf diese Art von Element haben, und bei **Dashboards** nur für die Dashboards, die Sie verwalten.
3. Legen Sie im Dialog **Im App-Menü veröffentlichen** den Eintrag fest:
   - **Menüeintrag** ist die Bezeichnung im Menü. Sie beginnt mit dem Namen des Elements, und eine Vorschau darunter zeigt den Eintrag so, wie er aussehen wird. Die Bezeichnung darf nicht breiter sein als der Name der breitesten Produkt-App im Menü; eine zu breite Bezeichnung wird entsprechend gemeldet.
   - **Symbol** bietet ein Monogramm aus den Anfangsbuchstaben der Bezeichnung oder eines von 15 Symbolen sowie eine Farbe. Die erste Farbauswahl wählt eine passend zur Bezeichnung. Ein kleines Abzeichen am Symbol zeigt, ob der Eintrag ein Dashboard, eine App, ein Notebook oder Jupyter Hub ist.
   - **Wer es im Menü sieht** ist **Alle im Arbeitsbereich**, **Gruppen** oder **Personen**, jeweils nur ein Typ. Aktivieren Sie bei **Gruppen** oder **Personen** mindestens einen Eintrag. **Gruppen** erfordert Zugriff zum Lesen von Sicherheitsgruppen und **Personen** Zugriff zum Lesen von Mitgliedern; ohne diesen Zugriff ist die Auswahl ausgegraut.
4. Wählen Sie **Veröffentlichen**.

In der Zeile des Elements erscheint dann eine Markierung **Veröffentlicht**. Um den Eintrag später zu ändern, öffnen Sie **Im App-Menü veröffentlichen…** erneut: Der Dialog zeigt, was gespeichert ist, seine Schaltfläche heißt **Speichern**, und **Veröffentlichung aufheben** nimmt den Eintrag aus dem Menü.

### Wer es nicht öffnen kann

Unter der Zielgruppe prüft der Dialog, wer in der Zielgruppe das Element heute nicht öffnen kann:

- *Dieses Element kann nicht geöffnet werden: 3 von 40* bedeutet, dass drei der vierzig Personen in der Zielgruppe den Eintrag erst sehen, wenn sie das Element öffnen können.
- *Alle in dieser Zielgruppe können dieses Element öffnen* bedeutet, dass niemand ausgeschlossen ist.
- *2 Personen in Projekten, die Sie nicht sehen können* zählt Personen, deren Zugriff von Projekten abhängt, die Sie nicht öffnen können, sodass der Dialog es nicht beurteilen kann.

Bei einem Dashboard öffnet **Zugriff korrigieren** den Dialog **Wer kann das sehen?**, und die Prüfung läuft nach dem Speichern dort erneut. Die Zahlen werden nur angezeigt, wenn Sie die Mitglieder des Workspaces sehen können.

## Wo der Eintrag erscheint

Veröffentlichte Einträge folgen im App-Menü auf die Produkt-Apps, unter einem Trennstrich, in der Reihenfolge, die ein Workspace-Administrator unter [Veröffentlichte Apps](#veröffentlichte-apps-verwalten) festlegt. Jeder hat seine Bezeichnung und sein Symbol. Eine Änderung, die Sie selbst vornehmen, sehen Sie sofort; andere Personen sehen sie, sobald sie PlaidCloud das nächste Mal laden.

| Element | Wird geöffnet |
|---|---|
| Dashboard | Als Registerkarte innerhalb von PlaidCloud |
| **Nur Browser**-Panel-App | Als Registerkarte innerhalb von PlaidCloud |
| JupyterLite-Notebook | Als Registerkarte innerhalb von PlaidCloud |
| **Serverbasierte** Panel-App oder Dash-App | In einem neuen Fenster |
| Jupyter Hub | In einem neuen Fenster |

Eine aus dem Menü geöffnete Registerkarte hat eine Kopfzeile mit dem Namen des Eintrags, **Neu laden** und **In neuem Fenster öffnen**. Wenn das Element Sie in der Registerkarte nicht anmeldet, verwenden Sie **In neuem Fenster öffnen**.

Die Adresse einer Registerkarte ist ein Link darauf, den Sie teilen können: siehe [Links teilen](/de/guides/projects/sharing-links/#veröffentlichte-menüeinträge). Wenn Ihr App-Menü nur **Startseite** und veröffentlichte Einträge enthält, listet **Startseite** sie zuerst in einer Zeile **Apps** auf.

### Wer einen Eintrag sieht

Ein Mitglied sieht einen Eintrag, wenn beides zutrifft:

- **Es gehört zu seiner Zielgruppe:** alle im Workspace, ein Mitglied einer seiner Gruppen oder eine seiner Personen.
- **Es kann das Element öffnen:** ein Dashboard, das es in Erkenntnisse sehen kann; eine App in einem Projekt, auf das es zugreifen kann; und bei einer **Nur Browser**-App oder einem JupyterLite-Notebook Zugriff auf das Dokumentenkonto, aus dem sie bereitgestellt werden.

Alle anderen sehen den Eintrag nicht, unabhängig von seiner Zielgruppe.

## Einen Eintrag in Ihrem Menü ausblenden

Klicken Sie im App-Menü mit der rechten Maustaste auf einen veröffentlichten Eintrag und wählen Sie **In meinem Menü ausblenden**. Er verschwindet nur aus Ihrem Menü, und **Rückgängig** in der angezeigten Meldung bringt ihn zurück. Das Ausblenden wird Mitgliedern angeboten, die Erkenntnisse haben.

Um ihn wieder anzuzeigen, öffnen Sie **Ausgeblendete Apps** in der Leiste von Erkenntnisse und wählen **Wiederherstellen** in seiner Zeile. Ein Eintrag, der nicht mehr in Ihrem Menü ist, zeigt **Nicht mehr in Ihrem Menü**; **Entfernen** nimmt ihn aus der Liste. Die Einträge, die Sie ausblenden, werden mit Ihrem Konto gespeichert und bleiben daher in jedem Browser ausgeblendet.

## Veröffentlichte Apps verwalten

Workspace-Administratoren öffnen **Veröffentlichte Apps** unter **Administrator** in der Leiste von Erkenntnisse. Die Seite listet jeden Eintrag in der Reihenfolge des Menüs mit **Name**, **Art**, **Zielgruppe** (**Alle Personen** oder eine Anzahl von Gruppen oder Personen) und **Status**. **Aufrufe (30 Tage)** zeigt für Mitglieder mit Zugriff auf die Nutzungsdaten, wie oft jedes Dashboard geöffnet wurde.

- **Nach oben** und **Nach unten** legen die Reihenfolge der Einträge im Menü aller fest.
- **Zielgruppe ändern…** öffnet den Dialog **Im App-Menü veröffentlichen** für einen Eintrag, den Sie verwalten können.
- **Veröffentlichung aufheben** nimmt einen Eintrag nach Ihrer Bestätigung aus dem Menü aller, für die er veröffentlicht ist. Workspace-Administratoren können jeden Eintrag aufheben.

Wird ein veröffentlichtes Element gelöscht, verschwindet sein Eintrag aus dem Menü, und **Veröffentlichte Apps** zeigt ihn einmal mit **Element gelöscht, entfernt**. Das Entfernen einer Panel-App oder einer JupyterLite-Bereitstellung aus ihrer Liste entfernt auch ihren Eintrag.

## Über den KI-Assistenten oder MCP veröffentlichen

`publication_manage` leistet dasselbe über MCP. Sein `kind` ist `dashboard`, `panelApp`, `jupyterLite` oder `jupyterHub`, und seine Aktionen sind:

- `get`, `set`, `delete` und `preview` nehmen ein `kind` und eine `item_id` entgegen. `set` ersetzt den gesamten Eintrag durch eine `spec` aus `label`, einem optionalen `icon` und `color` sowie einer `audience` vom `type` `public`, `acl-group` oder `acl-user` mit ihren `ids`. `preview` nimmt eine `spec` mit einer `audience` entgegen und liefert dieselben Zahlen wie der Dialog.
- `list` liefert die Einträge, die Sie verwalten, oder für einen Workspace-Administrator jeden Eintrag, in der Reihenfolge des Menüs, für die Arten, die Sie lesen können.
- `reorder` nimmt `keys` in der neuen Reihenfolge entgegen, jeweils `<kind>:<item_id>`, und ist für Workspace-Administratoren gedacht.

Der Jupyter-Hub-Link wird nur auf diesem Weg veröffentlicht, durch einen Workspace-Administrator, mit `kind` `jupyterHub` und `item_id` `hub`. `publication_manage` steht Weave oder anderen KI-Agenten, die in Ihrem Auftrag handeln, nicht zur Verfügung.
