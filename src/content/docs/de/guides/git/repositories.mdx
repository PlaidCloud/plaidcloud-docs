Ein Repository enthält die Dateien, Branches und den Verlauf eines Projekts. Diese Anleitung führt Sie durch das Erstellen eines Repositorys und die Verbindung damit von Ihrem Computer aus.

## Repository erstellen

1. Öffnen Sie **Git** in Ihrem Workspace.
2. Wählen Sie das Menü **+** oben rechts und dann **New Repository**.
3. Geben Sie einen Namen und optional eine kurze Beschreibung ein.
4. Wählen Sie die Sichtbarkeit. Neue Repositorys sind standardmäßig **Privat**: Nur Mitglieder, denen Sie Zugriff gewähren, können sie sehen.
5. Wählen Sie optional **Initialize Repository**, um eine README, eine `.gitignore` und eine Lizenz hinzuzufügen.
6. Wählen Sie **Create Repository**.

## Persönliches Zugriffstoken generieren

Da Sie sich über PlaidCloud anmelden, hat Ihr Konto kein separates Git-Kennwort. Um über die Befehlszeile per HTTPS zu klonen oder zu pushen, erstellen Sie ein persönliches Zugriffstoken und verwenden es anstelle eines Kennworts.

1. Wählen Sie oben rechts Ihren Avatar und dann **Einstellungen**.
2. Öffnen Sie die Registerkarte **Anwendungen**.
3. Geben Sie unter **Manage Access Tokens** einen Namen ein, der beschreibt, wo Sie das Token verwenden (zum Beispiel `laptop`).
4. Wählen Sie die Repository-Bereiche **read** und **write**, damit das Token klonen und pushen kann.
5. Wählen Sie **Generate Token**.
6. Kopieren Sie das Token und bewahren Sie es sicher auf. Sie können es später nicht erneut anzeigen.

<Aside type="caution">Behandeln Sie das Token wie ein Kennwort – jeder, der es besitzt, kann in Git in Ihrem Namen handeln. Generieren Sie pro Computer ein eigenes Token, damit Sie eines widerrufen können, ohne die anderen zu beeinträchtigen.</Aside>

## Repository klonen

1. Öffnen Sie das Repository in PlaidCloud Git.
2. Wählen Sie **Code** und kopieren Sie dann die **HTTPS**-Klon-URL.
3. Führen Sie in einem Terminal `git clone` mit dieser URL aus:

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. Wenn Git nach Anmeldedaten fragt, geben Sie Ihren **PlaidCloud-Benutzernamen** ein und fügen Sie das **Zugriffstoken** als Kennwort ein.

<Aside>Damit Sie das Token nicht bei jedem Push erneut eingeben müssen, lassen Sie es vom Git-Credential-Helper Ihres Betriebssystems speichern: Führen Sie vor Ihrem ersten Push `git config --global credential.helper store` aus (unter macOS `osxkeychain`).</Aside>

## Änderungen committen und pushen

Aus einem geklonten Repository heraus:

1. Stagen Sie Ihre Änderungen: `git add .`
2. Halten Sie sie mit einer Nachricht fest: `git commit -m "Describe what changed"`
3. Senden Sie sie an PlaidCloud Git: `git push`

Ihre Commits erscheinen in den Ansichten **Commits** und **Aktivität** des Repositorys sowie in jedem Branch und Pull Request, der sie enthält.

## Zugriff und Sichtbarkeit verwalten

Öffnen Sie die Registerkarte **Einstellungen** eines Repositorys, um es umzubenennen, seine Sichtbarkeit zu ändern oder das Eigentum zu übertragen. Damit andere Mitglieder mitwirken können, verwenden Sie **Einstellungen → Collaborators** und fügen Sie sie per Benutzername mit der Rolle **Lesen**, **Schreiben** oder **Administrator** hinzu.

<Aside>Der Repository-Zugriff folgt außerdem Ihrer Workspace-Mitgliedschaft und Ihren Sicherheitsgruppen. Wie diese zuordnen, wer ein Repository sehen und bearbeiten darf, erfahren Sie unter [Zugriffsverwaltung](/de/administration/access/).</Aside>
