Ein Repository enthält die Dateien, Branches und den Verlauf eines Projekts. Diese Anleitung zeigt, wie Sie ein Repository erstellen und von Ihrem Computer aus damit arbeiten.

## Ein Repository erstellen

1. Öffnen Sie **Git** in Ihrem Workspace.
2. Wählen Sie oben rechts das Menü **+** und dann **New Repository**.
3. Geben Sie einen Namen und optional eine kurze Beschreibung ein.
4. Wählen Sie die Sichtbarkeit. Neue Repositories sind standardmäßig **Privat** – nur Mitglieder, denen Sie Zugriff gewähren, können sie sehen.
5. Wählen Sie optional **Initialize Repository**, um eine README, eine `.gitignore` und eine Lizenz hinzuzufügen.
6. Wählen Sie **Create Repository**.

## Ein persönliches Zugriffstoken erzeugen

Da Sie sich über PlaidCloud anmelden, hat Ihr Konto kein separates Git-Passwort. Um über die Befehlszeile per HTTPS zu klonen oder zu pushen, erstellen Sie ein persönliches Zugriffstoken und verwenden es anstelle eines Passworts.

1. Wählen Sie oben rechts Ihren Avatar und dann **Einstellungen**. Der Hinweis auf der Registerkarte **Git** verlinkt ebenfalls direkt auf diese Seite.
2. Öffnen Sie die Registerkarte **Anwendungen**.
3. Geben Sie unter **Manage Access Tokens** einen Namen ein, der beschreibt, wo Sie das Token verwenden (zum Beispiel `laptop`).
4. Wählen Sie die Berechtigung **write:repository**, damit das Token klonen und pushen kann.
5. Wählen Sie **Generate Token**.
6. Kopieren Sie das Token und bewahren Sie es an einem sicheren Ort auf. Sie können es später nicht mehr einsehen.

<Aside type="caution">Behandeln Sie das Token wie ein Passwort – jeder, der es besitzt, kann in Git in Ihrem Namen handeln. Erzeugen Sie für jeden Rechner ein eigenes Token, damit Sie eines widerrufen können, ohne die anderen zu beeinträchtigen.</Aside>

## Ein Repository klonen

1. Öffnen Sie **Git** in Ihrem Workspace und wählen Sie in der Zeile des Repositorys **Copy clone URL**. Sie können auch im Repository **Code** wählen und die **HTTPS**-URL kopieren.
2. Führen Sie in einem Terminal `git clone` mit dieser URL aus:

   ```bash
   git clone <clone URL>
   ```

3. Wenn Git nach einem Passwort fragt, fügen Sie das **Zugriffstoken** ein. Verwenden Sie den Benutzernamen, der bereits in der URL steht.
4. Legen Sie Name und E-Mail-Adresse fest, die Git in Ihren Commits speichert, mit den Werten, die der Hinweis anzeigt:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

Zum Pushen benötigen Sie Zugriff als Contributor oder Administrator; mit Lesezugriff können Sie klonen, aber nicht pushen. Siehe [Zugriffsstufen](/de/guides/git/#zugriffsstufen).

<Aside>Damit Sie das Token nicht bei jedem Push erneut eingeben müssen, können Sie es vom Git-Credential-Helper Ihres Betriebssystems speichern lassen, zum Beispiel mit `git config --global credential.helper osxkeychain` unter macOS.</Aside>

## Änderungen committen und pushen

Aus einem geklonten Repository heraus:

1. Stagen Sie Ihre Änderungen: `git add .`
2. Halten Sie sie mit einer Nachricht fest: `git commit -m "Describe what changed"`
3. Senden Sie sie an PlaidCloud Git: `git push`

Ihre Commits erscheinen in den Ansichten **Commits** und **Aktivität** des Repositorys sowie in jedem Branch und Pull Request, der sie enthält.

## Zugriff und Sichtbarkeit verwalten

Öffnen Sie die Registerkarte **Einstellungen** eines Repositorys, um es umzubenennen, seine Sichtbarkeit zu ändern oder den Besitz zu übertragen. Damit andere Mitglieder mitarbeiten können, verwenden Sie **Einstellungen → Collaborators** und fügen sie per Benutzername mit der Rolle **Lesen**, **Schreiben** oder **Administrator** hinzu.

<Aside>Der Repository-Zugriff richtet sich auch nach Ihrer Workspace-Mitgliedschaft und Ihren Sicherheitsgruppen. Unter [Zugriffsverwaltung](/de/administration/access/) erfahren Sie, wie diese bestimmen, wer ein Repository sehen und bearbeiten darf.</Aside>
