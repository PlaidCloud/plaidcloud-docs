PlaidCloud Git enthält eine integrierte Paket-Registry für verteilbare Artefakte sowie Git Large File Storage (LFS) für große Binärdateien in Ihren Repositorys.

## Über die Paket-Registry

Die Paket-Registry gilt pro Eigentümer und unterstützt eine breite Palette von Ökosystemformaten – npm, PyPI, Maven, NuGet, RubyGems, Container-Images und mehr. Pakete sind privat für Ihren Workspace und nur für authentifizierte Mitglieder zugänglich.

Jeder Pakettyp hat einen eigenen Endpunkt unter:

```
https://git.example.plaidcloud.com/api/packages/you/<type>
```

wobei `<type>` die Kennung des Ökosystems ist (zum Beispiel `npm`, `pypi` oder `maven`).

## Bei der Registry authentifizieren

Paketmanager-Vorgänge verwenden Ihren PlaidCloud-Git-Benutzernamen und ein persönliches Zugriffstoken als Kennwort. Wie Sie ein Token erstellen, erfahren Sie unter [Repositorys](/de/guides/git/repositories/).

## Paket veröffentlichen

Die Schritte unterscheiden sich je nach Ökosystem, das Muster ist jedoch gleich: Richten Sie Ihren Paketmanager auf die Registry-URL aus und führen Sie dessen Standardbefehl zum Veröffentlichen aus.

Fügen Sie für npm Ihrem Projekt eine `.npmrc` hinzu, um Pakete auf die Registry zu begrenzen:

```ini
@you:registry=https://git.example.plaidcloud.com/api/packages/you/npm/
//git.example.plaidcloud.com/api/packages/you/npm/:_authToken=YOUR_TOKEN
```

Veröffentlichen Sie dann wie gewohnt:

```bash
npm publish
```

Für PyPI, Maven, NuGet und andere Ökosysteme setzen Sie die Repository- oder Quelleneinstellung des Werkzeugs auf die passende Registry-URL und verwenden den Standardbefehl zum Veröffentlichen dieses Werkzeugs (zum Beispiel `twine upload`, `mvn deploy` oder `dotnet nuget push`).

## Paket installieren

Richten Sie Ihren Paketmanager auf dieselbe Registry-URL aus und installieren Sie wie gewohnt. Mit der obigen `.npmrc`:

```bash
npm install @you/my-package
```

Fügen Sie bei anderen Ökosystemen die Registry als zusätzliche Quelle in der Konfiguration Ihres Werkzeugs hinzu und verwenden Sie dessen Standardbefehl zum Installieren.

## Große Dateien mit Git LFS

Git LFS hält Ihr Repository schnell, indem es große oder binäre Dateien im Verlauf durch schlanke Zeiger ersetzt und die Dateidaten separat speichert. LFS ist für jedes PlaidCloud-Git-Repository aktiviert.

1. Installieren Sie den LFS-Client einmalig auf Ihrem Computer:

   ```bash
   git lfs install
   ```

2. Legen Sie innerhalb Ihres Repositorys fest, welche Dateimuster LFS verfolgen soll:

   ```bash
   git lfs track "*.parquet"
   ```

   Dadurch wird `.gitattributes` erstellt oder aktualisiert. Committen Sie diese Datei:

   ```bash
   git add .gitattributes
   git commit -m "Track Parquet files with LFS"
   ```

3. Fügen Sie Dateien wie gewohnt hinzu und pushen Sie sie – passende Dateien werden automatisch zu LFS hochgeladen:

   ```bash
   git add data/large-dataset.parquet
   git commit -m "Add dataset"
   git push origin main
   ```

<Aside type="tip">Git LFS ist für große Dateien gedacht, die im Verlauf eines Repositorys liegen und mit `git clone` oder `git pull` abgerufen werden. Die Paket-Registry dient versionierten, verteilbaren Artefakten, die Verbraucher mit einem Paketmanager installieren. Wenn Teammitglieder es mit `npm install` oder `pip install` installieren sollen, verwenden Sie die Registry; wenn sie es als Teil eines Checkouts benötigen, verwenden Sie LFS.</Aside>
