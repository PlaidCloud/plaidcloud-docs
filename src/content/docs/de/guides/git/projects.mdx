Ein Projektboard ordnet Issues und Pull Requests in Spalten an, die Phasen Ihres Workflows darstellen, und gibt dem gesamten Team einen gemeinsamen Überblick darüber, was in Arbeit, was blockiert und was erledigt ist.

## Board erstellen

1. Öffnen Sie das Repository und wählen Sie die Registerkarte **Projekte**.
2. Wählen Sie **Neues Projekt**.
3. Geben Sie einen Namen für das Board ein.
4. Wählen Sie eine Startvorlage – ein einfaches Layout **To Do / In Progress / Done** ist ein guter Standard – oder wählen Sie ein leeres Board, um das Layout von Grund auf aufzubauen.
5. Wählen Sie **Create Project**, um das Board zu öffnen.

<Aside>Ein Board, das über die Registerkarte **Projekte** eines Repositorys erstellt wird, gehört zu diesem Repository. Boards, die mehrere Repositorys Ihres Workspace umfassen, erstellt ein Administrator im Projektbereich auf Organisationsebene.</Aside>

## Spalten einrichten

1. Um eine Spalte hinzuzufügen, wählen Sie **Spalte hinzufügen**, geben Sie eine Bezeichnung ein und speichern Sie.
2. Um eine Spalte umzubenennen, öffnen Sie ihre Einstellungen und wählen Sie **Bearbeiten**.
3. Ziehen Sie die Spaltenköpfe nach links oder rechts, um sie neu anzuordnen.
4. Markieren Sie in den Einstellungen eine Spalte als Standard – jede Karte, die ohne bestimmtes Ziel hinzugefügt wird, landet dort.

## Karten hinzufügen und verschieben

- Um ein vorhandenes Issue oder einen Pull Request hinzuzufügen, öffnen Sie das Menü einer Spalte und wählen Sie **Add an item**. Suchen Sie dann nach Titel oder Nummer danach.
- Um direkt auf dem Board ein neues Issue zu erstellen, wählen Sie **+** in einer Spalte. Das Issue wird im Repository gespeichert und sofort als Karte angezeigt.
- Ziehen Sie eine Karte in eine andere Spalte, wenn die Arbeit voranschreitet. Die Position der Karte spiegelt ihren aktuellen Status wider; sie ändert von sich aus weder die Bezeichnungen noch die Zuständigen des Issues.

## Arbeit verfolgen

Das Board vermittelt Ihnen auf einen Blick die Arbeitslast Ihres Teams, ohne einzelne Issues zu öffnen. Halten Sie es aktuell, indem Sie:

- ein Issue schließen oder einen Pull Request mergen – die Karte wandert je nach Automatisierungseinstellungen Ihres Boards in eine Erledigt-Spalte oder verlässt das Board.
- das Board mit **Meilensteinen** kombinieren, wenn Sie neben der Kanban-Ansicht ein zeitlich begrenztes Ziel wünschen. Meilensteine erfassen ein Fälligkeitsdatum und den Fertigstellungsgrad; das Board erfasst den Arbeitsfluss.
