Mit PlaidCloud Git durchsuchen Sie Code, Dateien, Issues und Pull Requests in allen Repositorys, auf die Ihre Workspace-Mitgliedschaft Ihnen Zugriff gibt.

## Code durchsuchen

1. Wählen Sie das Suchfeld oben auf einer beliebigen Seite und geben Sie Ihre Suchanfrage ein.
2. Drücken Sie **Enter**, um Ergebnisse aus allen Repositorys zu sehen, auf die Sie zugreifen können.
3. Wählen Sie ein Ergebnis, um direkt zur Datei an der passenden Zeile zu springen.
4. Grenzen Sie die Ergebnisse auf der Ergebnisseite mit den Filtern **Repository** und **Sprache** ein.

<Aside>Die Codesuche indiziert den Standard-Branch. Um einen anderen Branch zu durchsuchen, wechseln Sie zu diesem Branch und verwenden Sie die unten beschriebene Suche innerhalb des Repositorys.</Aside>

## Innerhalb eines Repositorys suchen

1. Öffnen Sie ein Repository und wählen Sie die Registerkarte **Code**.
2. Drücken Sie **T** (oder wählen Sie das Feld der Dateisuche), um die Dateisuche zu öffnen.
3. Geben Sie einen Teil eines Dateinamens oder Pfads ein – die Liste wird während der Eingabe gefiltert.
4. Wählen Sie eine Datei, um sie zu öffnen, und verwenden Sie dann die Suchfunktion Ihres Browsers (**⌘F** / **Strg+F**), um eine bestimmte Zeile zu finden.

<Aside type="tip">Die Dateisuche vergleicht Pfadsegmente. Wenn Sie `util/auth` eingeben, werden daher `src/util/auth.py`, `lib/util/auth_helper.go` und ähnliche Pfade angezeigt.</Aside>

## Issues und Pull Requests filtern

Kombinieren Sie in der Liste **Issues** oder **Pull Requests** die Stichwortsuche mit `key:value`-Filtern:

| Filter | Beispiel |
|---|---|
| Zustand offen oder geschlossen | `is:open`, `is:closed` |
| Bezeichnung | `label:bug`, `label:"needs review"` |
| Zuständige | `assignee:you` |
| Autor | `author:you` |
| Meilenstein | `milestone:"v1.2"` |

Geben Sie Filter direkt in das Suchfeld ein, kombinieren Sie sie beliebig und ordnen Sie über das Menü **Sortieren** nach **Zuletzt aktualisiert**, **Am meisten kommentiert**, **Neuestes** oder **Ältestes**.

<Aside>Setzen Sie einen Bezeichnungsnamen in Anführungszeichen, wenn er Leerzeichen enthält: `label:"needs review"`.</Aside>

## Tipps zum schnelleren Finden

- **Exakte Wortgruppen** – setzen Sie Begriffe aus mehreren Wörtern in Anführungszeichen (`"connection pool"`), um störende Teiltreffer zu vermeiden.
- **Auf ein Repository eingrenzen** – öffnen Sie das Repository vor der Suche, damit die Ergebnisse fokussiert bleiben.
- **Aussagekräftige Namen zahlen sich aus** – Repositorys und Issues mit klaren, spezifischen Namen erscheinen in der Suche deutlich zuverlässiger als solche mit generischen Namen wie `misc`.
- **Bezeichnungen sind durchsuchbare Metadaten** – ein gut bezeichnetes Issue lässt sich leichter filtern als eines, das in Fließtext vergraben ist, wenden Sie Bezeichnungen daher konsequent an.
