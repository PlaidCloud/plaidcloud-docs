[Data Foundation](/de/guides/projects/data-foundation/) führt die Daten aller ERP-Systeme und Instanzen, die Sie verbinden, in einem Common Finance Model zusammen, und SAP ECC ist eines der ERP-Systeme, die es direkt liest. PlaidCloud erreicht das System über einen [PlaidLink](/de/reference/cli/plaidlink/)-Agent, der in Ihrem eigenen Netzwerk installiert ist, per RFC. Diese Seite richtet sich an den SAP-Administrator, der das einrichtet, und an den PlaidCloud-Benutzer, der ihn darum bittet.

PlaidCloud liest Daten ausschließlich. Niemand sendet ein Kennwort per E-Mail.

## Zugriffsanfrage senden

Wählen Sie auf der Seite **Systeme** des Projekts, unter **Data Foundation** in **Startseite**, unter **System hinzufügen** im Feld **System** Ihr System aus und klicken Sie auf **Noch keinen Zugang?**. Das System wartet dann auf den Zugang, und es wird eine Anfrage angezeigt, die alle Systeme des Projekts abdeckt. Klicken Sie auf **Anfrage kopieren**, um sie in Ihre eigene Nachricht einzufügen, oder auf **Anfrage per E-Mail senden**, um sie in Ihrem E-Mail-Programm mit dem Betreff „Zugang zu PlaidCloud“ zu öffnen.

## Was der SAP-Administrator einrichtet

<Steps>

1. **Installieren Sie das PlaidCloud-ABAP-Paket** (Funktionsgruppe von `Z_PLAIDCL_B5_READ_TABLE`) in dem Mandanten, aus dem Sie berichten, und installieren Sie einen PlaidLink-Agent, der das System per RFC erreichen kann.

2. **Erstellen Sie einen Kommunikationsbenutzer**, zum Beispiel `PLAIDCLOUD_RFC`, mit einer Rolle, die diese Berechtigungen enthält:

   - `S_RFC`: die Funktionsgruppe von `Z_PLAIDCL_B5_READ_TABLE` ausführen.
   - `S_TABU_NAM` (Anzeige, `ACTVT` 03) für die folgenden Tabellen.

   | Tabellen | Was sie enthalten |
   |---|---|
   | `T001` | Buchungskreise |
   | `T009`, `T009B`, `T001B` | Geschäftsjahresvarianten und Buchungsperioden |
   | `SKA1`, `SKAT` | Sachkonten |
   | `FAGL_011PC`, `FAGL_011ZC` | Bilanz-/GuV-Struktur |
   | `CSKS`, `CSKT` | Kostenstellen |
   | `SETHEADER`, `SETNODE` | Kostenstellen- und Profitcenter-Gruppen |
   | `CEPC`, `CEPCT` | Profitcenter (optional) |
   | `KNA1`, `KNVV`, `KNVH` | Kunden und ihre Hierarchie |
   | `MARA`, `MAKT`, `T006A` | Materialien und Einheiten |
   | `TCURR`, `TCURF`, `TCURX` | Wechselkurse und Währungsdezimalstellen |
   | `BKPF`, `BSEG` | Buchhaltungsbelege und ihre Positionen |
   | `FAGLFLEXT` oder, im klassischen Hauptbuch, `GLT0` | Hauptbuchsummen |
   | `CSKB`, `CSKU`, `COEP` | Kostenarten und Controlling-Positionen: Umlagen und Verteilungen |
   | `COSP`, `COSS`, `COSR` | Kostenstellenplan und statistische Kennzahlen (optional) |
   | `VBRK`, `VBRP`, `KONV` | Fakturabelege und ihre Preiskonditionen (optional) |
   | `T001K`, `MBEW`, `MBEWH` | Bewertungskreise, Materialbestandswerte und Standardpreise (optional) |
   | `T001W`, `TKA02` | Werke, gelesen als Standorte, und der Kostenrechnungskreis jedes Buchungskreises (optional) |
   | `T016T`, `TKUKT`, `KNVP`, `TSPAT`, `T052U` | Namen der Branchen und Kundenklassifizierungen, der Vertriebsmitarbeiter jedes Kunden, Sparten und Namen der Zahlungsbedingungen (optional) |
   | `T012K`, `T012T` | Hausbankkonten, für Banksalden (optional) |
   | `LFA1`, `LFB1` | Lieferanten (optional) |
   | `RBKP`, `RSEG` | Lieferantenrechnungen (optional) |
   | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` | Bestellungen sowie ihre Wareneingänge und Rechnungen (optional) |
   | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095`, `ANLC`, `ANEP`, `ANEA`, `ANLP` | Das Anlagenverzeichnis und seine Bewegungen (optional) |
   | Die Einzelpostentabelle des Ergebnisbereichs (`CE1` gefolgt von seinem Namen) | CO-PA nach Bewertung (optional) |

   Offene Posten und Zahlungen werden aus den Debitoren- und Kreditorenpositionen von `BSEG` mit ihren `BKPF`-Köpfen gelesen.

3. **Beantworten Sie die Buchhaltungsfragen** (siehe unten).

</Steps>

### Fragen, die der Administrator beantwortet

| Der Administrator teilt Ihnen mit | Eingabe in PlaidCloud unter **Systemeinstellungen** |
|---|---|
| Den Wechselkurstyp, der den Durchschnittskurs enthält. PlaidCloud bildet den Durchschnitt der Kurse dieses Typs je Monat. Oft ist es `M`. | **Average rate type** |
| Den Wechselkurstyp, der den Stichtagskurs enthält, seinen Kurs am Monatsende. Wenn Sie keinen nennen, ist der Stichtagskurs der Kurs `M`. | **Closing rate type** |
| Ob das System das neue Hauptbuch (`FAGLFLEXT`) oder das klassische (`GLT0`) betreibt | **General ledger totals table** |
| Die Bilanz-/GuV-Struktur, die die Management-GuV und die Bilanz berichtet | **Financial statement version** |
| Welche ihrer Knoten Umsatzerlöse, Herstellungskosten der verkauften Waren, Betriebsaufwand, nicht betrieblich, Aktiva, Passiva, Eigenkapital und Intercompany sind | **Account type of each statement node**: eine Zeile je Knoten im Format `node = type`, mit einem Typ, den das Feld auflistet, zum Beispiel `Revenue` oder `Asset`. **Intercompany statement nodes** benennt die Intercompany-Knoten. Beide gelten nur, wenn **Financial statement version** gesetzt ist. |
| Dass der Saldovortrag für jedes Geschäftsjahr, über das Sie berichten, ausgeführt wurde (`FAGLGVTR` oder `F.16` im klassischen Hauptbuch) | Nichts einzugeben. Die Eröffnungssalden werden aus der Summentabelle gelesen. |
| Den Abschreibungsbereich jedes Anlagenbuchs, handelsrechtlich oder steuerlich. Der erste ist der des Anlagenverzeichnisses. PlaidCloud geht davon aus, dass Bereich `01` das handelsrechtliche Buch ist. | **Depreciation area of each book** |
| Die Bewegungsart jeder Anlagentransaktionsart, nach ihrer ersten Ziffer. PlaidCloud geht von `1` Zugang, `2` Abgang, `3` Umbuchung, `6` Abschreibung und `9` Eröffnung aus. | **Movement type of each transaction type** |
| Die Einzelpostentabelle des Ergebnisbereichs, wenn Sie CO-PA nach Bewertung möchten. Ist keine angegeben, wird kein CO-PA gelesen. | **Operating concern line item table** |
| Das CO-PA-Wertfeld jedes Kontos und welche davon Kosten sind | **Value field of each CO-PA account**, **CO-PA cost value fields** |

## Was zurückzusenden ist

| Der Administrator sendet | Eingabe in PlaidCloud als |
|---|---|
| Die System-ID und den Anwendungsserver (oder Meldungsserver und Anmeldegruppe) | **Host** und **Systemnummer** oder, mit **Lastverteilte Mehrsystemverbindung verwenden**, **MS-Host**, **MS-Server**, **System-ID** und **Gruppe** |
| Den Mandanten | **Mandant** |
| Den Namen des Kommunikationsbenutzers | **Benutzer** |
| Das Kennwort des Kommunikationsbenutzers über Ihren Kennwortmanager | **Kennwort**, das Ihr Team selbst eingibt |
| Den Namen des PlaidLink-Agents, der das System erreicht | Die Systemeinstellung **PlaidLink agent** |
| Die Buchungskreise, die PlaidCloud lesen darf | Unter **Optionen**, **Gesellschaften**, die SAP nicht auflisten kann: Geben Sie die Buchungskreise durch Kommas getrennt ein oder lassen Sie das Feld leer, um jeden Buchungskreis zu laden |

<Aside type="caution">
Senden Sie das Kennwort nie per E-Mail. **Kennwort** ist ein Geheimnis: Es wird in der Verbindung gespeichert und nie wieder angezeigt.
</Aside>

## Zugriff prüfen

SAP wird über einen PlaidLink-Agent gelesen, daher liest **Verbindung testen** es nicht: Das erste Laden liest es und nennt eine Tabelle, die der Benutzer nicht lesen darf. Jedes Dataset liest:

| Dataset | Tabellen, die es liest |
|---|---|
| Entitäten | `T001` |
| Geschäftskalender | `T001`, `T009`, `T009B`, `T001B` |
| Wechselkurse | `TCURR`, `TCURF` |
| Kontenplan | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC`, `CSKB`, `CSKU` |
| Abteilungen | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| Profitcenter | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| Kunden | `KNA1`, `KNVV`, `KNVH` |
| Produkte | `MARA`, `MAKT`, `T006A` |
| Hauptbuch | `BKPF`, `BSEG`, `COEP` |
| Saldenliste | `FAGLFLEXT` oder `GLT0` |
| Verkaufspositionen | `VBRK`, `VBRP`, `KONV` |
| Budget | `COSP`, `COSS` |
| Verteilungstreiber | `COSR` |
| Lagerbestände | `MBEW`, `MBEWH`, `T001K` |
| Monatsendsaldo | `FAGLFLEXT` oder `GLT0`, der Saldo zu jedem Monatsende |
| Banksalden | `T012K`, `T012T`, mit dem Monatsendsaldo des Sachkontos jeder Hausbank |
| Standorte | `T001W`, `T001K` |
| Lieferanten | `LFA1`, `LFB1` |
| Lieferantenrechnungspositionen | `RBKP`, `RSEG`, `BKPF` |
| Bestellungen | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` |
| Offene Posten, Zahlungen | `BSEG`-Debitoren- und -Kreditorenpositionen, `BKPF` |
| Anlagen | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095` |
| Anlagenbewegungen | `ANLC`, `ANEP`, `ANEA`, `ANLP` |
| Standardkosten | `T001K`, `MBEW`, `MBEWH` |
| CO-PA nach Bewertung | Die in **Operating concern line item table** genannte Tabelle |

Nennt ein Ladevorgang eine Tabelle, die der Benutzer nicht lesen darf, bitten Sie den Administrator, sie der Rolle hinzuzufügen, und laden Sie erneut. Profitcenter, Verkaufspositionen, Budget, Verteilungstreiber, Lagerbestände und jedes Dataset ab Monatsendsaldo abwärts sind optional: Ein System, das eines davon nicht enthält, lädt trotzdem alles andere. Banksalden, offene Posten oder Zahlungen eines Monats, die SAP verweigert, behalten die Zeilen, die sie bereits hatten.

Hausbankkonten, die sich ein Sachkonto teilen, haben gemeinsam eine Saldenzeile, da das Sachkonto einen Saldo hat.
