[Data Foundation](/de/guides/projects/data-foundation/) führt die Daten aller ERP-Systeme und Instanzen, die Sie verbinden, in einem Common Finance Model zusammen, und Sage Intacct ist eines der ERP-Systeme, die es direkt liest. Die Verbindung nutzt Intacct Web Services: eine Sender-Autorisierung für PlaidCloud und einen schreibgeschützten Web-Services-Benutzer. Diese Seite richtet sich an den Sage-Intacct-Administrator, der das einrichtet, und an den PlaidCloud-Benutzer, der ihn darum bittet.

PlaidCloud liest Daten ausschließlich. Niemand sendet ein Kennwort per E-Mail.

## Zugriffsanfrage senden

Wählen Sie auf der Seite **Systeme** des Projekts, unter **Data Foundation** in **Startseite**, unter **System hinzufügen** im Feld **System** Ihr System aus und klicken Sie auf **Noch keinen Zugang?**. Das System wartet dann auf den Zugang, und es wird eine Anfrage angezeigt, die alle Systeme des Projekts abdeckt. Klicken Sie auf **Anfrage kopieren**, um sie in Ihre eigene Nachricht einzufügen, oder auf **Anfrage per E-Mail senden**, um sie in Ihrem E-Mail-Programm mit dem Betreff „Zugang zu PlaidCloud“ zu öffnen.

## Was der Sage-Intacct-Administrator einrichtet

<Steps>

1. **Autorisieren Sie PlaidCloud als Web-Services-Sender.** Fügen Sie unter **Company > Admin > Web Services authorizations** die Sender-ID hinzu, die PlaidCloud Ihnen genannt hat. Senden Sie die Sender-ID und das von Sage dafür ausgestellte Sender-Kennwort zurück.

2. **Erstellen Sie einen Web-Services-Benutzer.** Erstellen Sie unter **Company > Admin > Users** einen Benutzer vom Typ „Business“ mit der Option „Web services only“ und eine Rolle mit der Berechtigung **View** für:

   | Bereich | Objekte |
   |---|---|
   | Hauptbuch | Konten, Statistische Konten, Journalbuchungen (alle Journale, einschließlich Anpassungsjournale), Kontensalden, Berichtsperioden, Wechselkurse, Budgets |
   | Unternehmen | Entitäten (Standorte), Abteilungen, Klassen, Projekte |
   | Debitorenbuchhaltung | Kunden, Rechnungen, Anpassungen, Zahlungen |
   | Kreditorenbuchhaltung | Lieferanten, Lieferantenrechnungen, Anpassungen, Zahlungen |
   | Cash Management | Girokonten |
   | Bestandsverwaltung | Artikel |
   | Auftragserfassung | Transaktionen (Verkaufsrechnungen sowie die Gutschriften und Retouren, die sie zurücknehmen), wenn Sie Verkäufe möchten |

   Geben Sie dem Benutzer Zugriff auf die oberste Ebene des Unternehmens und auf jede Entität, über die PlaidCloud berichtet. Wenn Ihre Transaktionsdefinitionen für Gutschriften und Retouren nicht Sales Credit Memo und Sales Return heißen, teilen Sie dem PlaidCloud-Benutzer deren Namen mit.

3. **Lassen Sie die IP-Adresse des Benutzers zu**, wenn Ihr Unternehmen Web Services per IP einschränkt.

</Steps>

## Was zurückzusenden ist

| Der Administrator sendet | Eingabe in PlaidCloud als |
|---|---|
| Die Unternehmens-ID | **Unternehmens-ID** |
| Die Web-Services-Benutzer-ID | **Benutzername des Webservice-Benutzers** |
| Die Sender-ID | **Client-ID** |
| Das Sender-Kennwort | **Client-Secret** |
| Die Namen Ihrer Transaktionsdefinitionen für Gutschriften und Retouren, falls nicht die Standardwerte | Die Systemeinstellung **Credit memo and return document types** (Standardwerte: Sales Credit Memo, Sales Return) |
| Die Entitäten, die PlaidCloud lesen darf | Unter **Optionen**, **Gesellschaften**: Aktivieren Sie sie, oder keine für alle |

Kennwörter gehen über Ihren Kennwortmanager, nie per E-Mail. Das Team des PlaidCloud-Benutzers gibt das Sender-Kennwort selbst als **Client-Secret** ein. Entitäten, die die eigenen Eliminierungen Ihres Unternehmens sind, kommen in die Systemeinstellung **Elimination entities**.

## Zugriff prüfen

Klicken Sie danach in PlaidCloud, sobald das System hinzugefügt ist, in seiner Zeile auf der Seite **Systeme** auf **Verbindung testen**. Der Test liest die erforderlichen Datasets und zeigt jedes als **Lesbar**, **Fehlende Berechtigung** oder **Fehler** an. Die unten gekennzeichneten optionalen sind nicht Teil des Tests: Verweigert Sage Intacct eines davon, nennen die Bereitschaftsprüfungen auf dem Dashboard **CFM-Accounting - Close and assurance** nach dem nächsten Laden das Objekt, für das eine Berechtigung zu erteilen ist.

| Dataset | Erforderliche Berechtigung |
|---|---|
| Entitäten | Unternehmen: Entitäten (View) |
| Kontenplan | Hauptbuch: Konten und statistische Konten (View) |
| Abteilungen | Unternehmen: Abteilungen (View) |
| Kunden | Debitorenbuchhaltung: Kunden (View) |
| Produkte | Bestandsverwaltung: Artikel (View) |
| Wechselkurse | Hauptbuch: Wechselkurse (View) |
| Geschäftskalender | Hauptbuch: Berichtsperioden (View) |
| Saldenliste | Hauptbuch: Kontensalden (View) |
| Hauptbuch | Hauptbuch: Journalbuchungen (View) |
| Monatsendsaldo (optional) | Hauptbuch: Kontensalden (View) |
| Banksalden (optional) | Cash Management: Girokonten (View), mit dem Monatsendsaldo |
| Standorte (optional) | Unternehmen: Entitäten (Standorte) (View) |
| Profitcenter (optional) | Unternehmen: Klassen (View) |
| Projekte (optional) | Unternehmen: Projekte (View) |
| Lieferanten (optional) | Kreditorenbuchhaltung: Lieferanten (View) |
| Verkaufspositionen (optional) | Auftragserfassung: Transaktionen (View) |
| Lieferantenrechnungspositionen (optional) | Kreditorenbuchhaltung: Lieferantenrechnungen und Anpassungen (View) |
| Offene Posten und Zahlungen (optional) | Debitorenbuchhaltung: Rechnungen, Anpassungen und Zahlungen sowie Kreditorenbuchhaltung: Lieferantenrechnungen, Anpassungen und Zahlungen (View) |
| Budget (optional) | Hauptbuch: Budgets (View) |
| Verteilungstreiber (optional) | Hauptbuch: Kontensalden (View) |

Fehlt ein Dataset, nennt der Test die Berechtigung, die hinzuzufügen ist. Bitten Sie den Administrator, sie der Rolle hinzuzufügen, und testen Sie erneut. Ein Unternehmen, das ein optionales Dataset nicht verwendet, lädt trotzdem alles andere. Verweigert Sage Intacct einen Lesezugriff, aus dem die Lieferantenrechnungen, offenen Posten oder Zahlungen eines Monats aufgebaut werden, behält dieser Monat die Zeilen, die er bereits hatte, und wird beim nächsten Laden erneut gelesen.

Wer ein Journal erfasst hat, wann, wer es genehmigt hat und was es storniert, wird aus dem Stapel des Journals gelesen. Eine Rolle, die den Stapel nicht lesen kann, lässt diese Angaben leer.
