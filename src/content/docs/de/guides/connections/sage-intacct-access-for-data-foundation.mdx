[Data Foundation](/de/guides/projects/data-foundation/) führt die Daten aller ERP-Systeme und Instanzen, die Sie verbinden, in einem Common Finance Model zusammen, und Sage Intacct ist eines der ERP-Systeme, die es direkt liest. Die Verbindung nutzt Intacct Web Services: eine Sender-Autorisierung für PlaidCloud und einen schreibgeschützten Web-Services-Benutzer. Diese Seite richtet sich an den Sage-Intacct-Administrator, der das einrichtet, und an den PlaidCloud-Benutzer, der ihn darum bittet.

PlaidCloud liest Daten ausschließlich. Niemand sendet ein Kennwort per E-Mail.

## Zugriffsanfrage senden

Wählen Sie auf der Registerkarte **Foundation** des Projekts unter **Sage-Intacct-Verbindung** die Option **Neue Verbindung erstellen**. Das Formular zeigt die vollständige Anfrage. Klicken Sie auf **Anfrage kopieren**, um sie in Ihre eigene Nachricht einzufügen, oder auf **Anfrage per E-Mail senden**, um sie in Ihrem E-Mail-Programm mit dem Betreff „Read-only Sage Intacct access for PlaidCloud (Web Services)“ zu öffnen.

## Was der Sage-Intacct-Administrator einrichtet

<Steps>

1. **Autorisieren Sie PlaidCloud als Web-Services-Sender.** Fügen Sie unter **Company > Admin > Web Services authorizations** die Sender-ID hinzu, die PlaidCloud Ihnen genannt hat. Senden Sie die Sender-ID und das von Sage dafür ausgestellte Sender-Kennwort zurück.

2. **Erstellen Sie einen Web-Services-Benutzer.** Erstellen Sie unter **Company > Admin > Users** einen Benutzer vom Typ „Business“ mit der Option „Web services only“ und eine Rolle mit der Berechtigung **View** für:

   | Bereich | Objekte |
   |---|---|
   | Hauptbuch | Konten, Journalbuchungen (alle Journale, einschließlich Anpassungsjournale), Kontensalden, Berichtsperioden, Wechselkurse, Budgets |
   | Unternehmen | Entitäten (Standorte), Abteilungen, Klassen, Projekte |
   | Debitorenbuchhaltung | Kunden |
   | Bestandsverwaltung | Artikel |
   | Auftragserfassung | Transaktionen (Verkaufsrechnungen sowie die Gutschriften und Retouren, die sie zurücknehmen), wenn Sie Verkäufe möchten |

   Geben Sie dem Benutzer Zugriff auf die oberste Ebene des Unternehmens und auf jede Entität, über die PlaidCloud berichtet. Wenn Ihre Transaktionsdefinitionen für Gutschriften und Retouren nicht Sales Credit Memo und Sales Return heißen, teilen Sie dem PlaidCloud-Benutzer deren Namen mit.

3. **Lassen Sie die IP-Adresse des Benutzers zu**, wenn Ihr Unternehmen Web Services per IP einschränkt.

</Steps>

## Was zurückzusenden ist

| Der Administrator sendet | Eingabe in PlaidCloud als |
|---|---|
| Die Unternehmens-ID | **Unternehmens-ID** |
| Die Web-Services-Benutzer-ID | **Web-Services-Benutzer-ID** |
| Das Kennwort des Web-Services-Benutzers | **Web-Services-Kennwort** |
| Die Sender-ID | **Sender-ID** |
| Das Sender-Kennwort | **Sender-Kennwort** |
| Die Namen Ihrer Transaktionsdefinitionen für Gutschriften und Retouren, falls nicht die Standardwerte | Die Systemeinstellung `credit_documents` (Standardwerte: Sales Credit Memo, Sales Return) |
| Die Entitäten, die PlaidCloud lesen darf | In PlaidCloud unter **Entitäten** ausgewählt |

Kennwörter gehen über Ihren Kennwortmanager, nie per E-Mail. Das Team des PlaidCloud-Benutzers fügt das **Web-Services-Kennwort** und das **Sender-Kennwort** selbst in PlaidCloud ein. Entitäten, die die eigenen Eliminierungen Ihres Unternehmens sind, kommen in die Systemeinstellung `elimination_entities`.

## Zugriff prüfen

Geben Sie in PlaidCloud die Werte ein und klicken Sie auf **Verbindung testen**. Jedes Dataset wird als **Lesbar**, **Fehlende Berechtigung** oder **Fehler** angezeigt:

| Dataset | Erforderliche Berechtigung |
|---|---|
| Entitäten | Unternehmen: Entitäten (View) |
| Kontenplan | Hauptbuch: Konten und statistische Konten (View) |
| Abteilungen | Unternehmen: Abteilungen (View) |
| Kunden | Debitorenbuchhaltung: Kunden (View) |
| Produkte | Bestandsverwaltung: Artikel (View) |
| Wechselkurse | Hauptbuch: Wechselkurse (View) |
| Geschäftskalender | Hauptbuch: Berichtsperioden (View) |
| Saldenliste | Hauptbuch: Kontensalden (View) |
| Hauptbuch | Hauptbuch: Journalbuchungen (View) |
| Verkaufspositionen | Auftragserfassung: Transaktionen (View) |
| Budget | Hauptbuch: Budgets (View) |
| Verteilungstreiber | Hauptbuch: Kontensalden (View) |

Fehlt ein Dataset, nennt der Test die Berechtigung, die hinzuzufügen ist. Bitten Sie den Administrator, sie der Rolle hinzuzufügen, und testen Sie erneut. Verkaufspositionen, Budget und Verteilungstreiber sind optional: Ein Unternehmen, das sie nicht verwendet, lädt trotzdem alles andere.
