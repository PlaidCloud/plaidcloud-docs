## Beschreibung

Beim Klonen wird die Konfiguration einer bestehenden Verbindung dupliziert — Host, Port, Optionen, Verweis auf die Anmeldedaten —, sodass Sie einige Felder bearbeiten und sie als neue Verbindung speichern können, statt jede Einstellung neu einzugeben.

Das Klonen funktioniert für jeden Typ einer externen Datenverbindung: Datenbank, ERP, REST, Cloud-Dienst, Git und Dokument.


## Verbindung klonen

1. Öffnen Sie **Tools > Connections**
2. Wählen Sie die Verbindung aus, die Sie kopieren möchten
3. Klicken Sie in der Symbolleiste auf `Clone` (oder klicken Sie mit der rechten Maustaste auf die Zeile und wählen Sie `Clone`)
4. Bearbeiten Sie den Namen der neuen Verbindung und alle Felder, die abweichen sollen
5. Klicken Sie auf `Save`


## Aktionen nur für Eigentümer

`Edit`, `Clone` und `Delete` stehen nur für Verbindungen zur Verfügung, die Ihnen gehören. Sind diese Symbolleistenschaltflächen für die ausgewählte Zeile ausgegraut, sind Sie nicht der Eigentümer — bitten Sie den Eigentümer, die Verbindung für Sie zu klonen, oder lassen Sie sich von ihm über `Edit Owners` als zusätzlichen Eigentümer hinzufügen.

<Aside>Beim Klonen wird die Konfiguration kopiert, nicht aber Testergebnisse oder Ausführungsverlauf. Testen Sie die geklonte Verbindung, bevor Sie sich in einem Workflow auf sie verlassen.</Aside>
