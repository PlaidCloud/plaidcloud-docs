[Data Foundation](/de/guides/projects/data-foundation/) führt die Daten aller ERP-Systeme und Instanzen, die Sie verbinden, in einem Common Finance Model zusammen, und Oracle E-Business Suite ist eines der ERP-Systeme, die es direkt liest. PlaidCloud erreicht EBS über einen [PlaidLink](/de/reference/cli/plaidlink/)-Agent, der in Ihrem Netzwerk installiert ist, nie direkt. Diese Seite richtet sich an den EBS-Administrator, der das einrichtet, und an den PlaidCloud-Benutzer, der ihn darum bittet.

PlaidCloud liest Daten ausschließlich. Niemand sendet ein Kennwort per E-Mail.

## Zugriffsanfrage senden

Wählen Sie auf der Registerkarte **Foundation** des Projekts unter **Oracle-E-Business-Suite-Verbindung** die Option **Neue Verbindung erstellen**. Das Formular zeigt die vollständige Anfrage und einen Link **PlaidLink einrichten**. Klicken Sie auf **Anfrage kopieren**, um sie in Ihre eigene Nachricht einzufügen, oder auf **Anfrage per E-Mail senden**, um sie in Ihrem E-Mail-Programm mit dem Betreff „Read-only Oracle E-Business Suite access for PlaidCloud (through PlaidLink)“ zu öffnen.

## Was der EBS-Administrator einrichtet

<Steps>

1. **Installieren Sie PlaidLink** auf einem Server, der die EBS-Datenbank erreichen kann, und registrieren Sie es in PlaidCloud.

2. **Erteilen Sie SELECT** an den APPS-Schema-Benutzer von PlaidLink (oder einen schreibgeschützten Schema-Benutzer mit Synonymen auf die APPS-Objekte) für:

   | Bereich | Objekte |
   |---|---|
   | Hauptbuch | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES` |
   | Flexfields | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | Verkauf (optional) | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |

3. **Benennen Sie einen Anwendungsbenutzer** (`FND_USER`) und eine Verantwortlichkeit, die jedes Ledger und jeden Balancing-Segment-Wert sehen kann, über die Sie berichten möchten.

4. **Beschreiben Sie den Kontenplan.** Geben Sie an, welche Segmente das Balancing-Segment, das natürliche Konto, die Kostenstelle und das Intercompany-Segment sind (ihre Segmentqualifizierer). PlaidCloud typisiert ein Aufwandskonto als Herstellungskosten der verkauften Waren, wenn es selbst oder ein übergeordneter Wert darüber als Cost of Goods Sold, Cost of Sales oder Cost of Revenue beschrieben ist. Ein Konto typisiert es als nicht betrieblich, wenn eine der Beschreibungen Zinserträge oder -aufwendungen, Finanzerträge oder -kosten, Fremdwährung, Ertragsteueraufwand oder sonstige Erträge und Aufwendungen nennt. Teilen Sie PlaidCloud mit, wenn Ihre übergeordneten Werte andere Begriffe dafür verwenden.

5. **Bestätigen Sie die Kurstypen.** Jedes primäre Ledger nennt seine Kurstypen für den Periodendurchschnitt und das Periodenende in den Umrechnungsoptionen des Ledgers. PlaidCloud rechnet mit den Tageskursen dieser beiden Typen um.

</Steps>

<Aside type="caution">
Die falsche Verantwortlichkeit liefert ohne Fehlermeldung die Zeilen eines anderen Ledgers zurück. Bestätigen Sie sie mit dem Verantwortlichen für Ihr Hauptbuch.
</Aside>

## Was zurückzusenden ist

| Der Administrator sendet | Eingabe in PlaidCloud als |
|---|---|
| Den Datenbank-Host | **Datenbank-Host** |
| Den Datenbankport | **Datenbankport** (1521, sofern Sie ihn nicht ändern) |
| Den Dienstnamen | **Dienstname** |
| Den APPS-Schema-Benutzer | **APPS-Schema-Benutzer** |
| Das APPS-Schema-Kennwort über das sichere Verbindungsformular | **APPS-Schema-Kennwort**, das Ihr Team selbst einfügt |
| Den `FND_USER` | **Anwendungsbenutzer (FND_USER)** |
| Den Schlüssel der Verantwortlichkeit | **Schlüssel der Verantwortlichkeit** |
| Die Balancing-Segment-Werte, die PlaidCloud lesen darf | Unter **Balancing-Segment-Werte**, die das System vor einem Ladevorgang nicht auflisten kann: Geben Sie unter **Name** einen Wert ein oder lassen Sie das Feld leer, um jede Entität des primären Ledgers zu laden |

Der PlaidLink-Agent, der die Instanz erreicht, wird in den Systemeinstellungen als `agent` ausgewählt.

<Aside type="caution">
Senden Sie das Kennwort nie per E-Mail. **APPS-Schema-Kennwort** ist ein Geheimnis: Es wird in der Verbindung gespeichert und nie wieder angezeigt.
</Aside>

## Zugriff prüfen

Geben Sie in PlaidCloud die Werte ein und klicken Sie auf **Verbindung testen**. Jedes Dataset wird als **Lesbar**, **Fehlende Berechtigung** oder **Fehler** angezeigt:

| Dataset | Objekte, die es liest |
|---|---|
| Entitäten | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| Geschäftskalender | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| Kontenplan | `GL_CODE_COMBINATIONS`, die Flexfield-Tabellen |
| Abteilungen | `GL_CODE_COMBINATIONS`, die Flexfield-Tabellen |
| Wechselkurse | `GL_DAILY_RATES` |
| Hauptbuch | `GL_JE_HEADERS`, `GL_JE_LINES` |
| Saldenliste | `GL_BALANCES` |
| Kunden | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES` (optional) |
| Produkte | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` (optional) |
| Verkaufspositionen | Die `RA_CUSTOMER_TRX`-Tabellen (optional) |

Zeigt ein Dataset **Fehlende Berechtigung**, bitten Sie den Administrator, SELECT auf die Objekte zu erteilen, und testen Sie erneut. Kunden, Produkte und Verkaufspositionen sind optional: Eine Instanz, die sie nicht verwendet, lädt trotzdem alles andere.
