[Data Foundation](/de/guides/projects/data-foundation/) führt die Daten aller ERP-Systeme und Instanzen, die Sie verbinden, in einem Common Finance Model zusammen, und SAP S/4HANA ist eines der ERP-Systeme, die es direkt liest. PlaidCloud erreicht das System über einen [PlaidLink](/de/reference/cli/plaidlink/)-Agent, der in Ihrem eigenen Netzwerk installiert ist, per RFC. Diese Seite richtet sich an den SAP-Administrator, der das einrichtet, und an den PlaidCloud-Benutzer, der ihn darum bittet.

PlaidCloud liest Daten ausschließlich. Niemand sendet ein Kennwort per E-Mail.

## Zugriffsanfrage senden

Wählen Sie auf der Registerkarte **Foundation** des Projekts unter **SAP-S/4HANA-Verbindung** die Option **Neue Verbindung erstellen**. Das Formular zeigt die vollständige Anfrage und einen Link **PlaidLink einrichten**. Klicken Sie auf **Anfrage kopieren**, um sie in Ihre eigene Nachricht einzufügen, oder auf **Anfrage per E-Mail senden**, um sie in Ihrem E-Mail-Programm mit dem Betreff „Read-only SAP S/4HANA access for PlaidCloud (through PlaidLink)“ zu öffnen.

## Was der SAP-Administrator einrichtet

<Steps>

1. **Installieren Sie das PlaidCloud-ABAP-Paket** (Funktionsgruppe von `Z_PLAIDCL_B5_READ_TABLE`) in dem Mandanten, aus dem Sie berichten, und installieren Sie einen PlaidLink-Agent, der das System per RFC erreichen kann.

2. **Erstellen Sie einen Kommunikationsbenutzer**, zum Beispiel `PLAIDCLOUD_RFC`, mit einer Rolle, die diese Berechtigungen enthält:

   - `S_RFC`: die Funktionsgruppe von `Z_PLAIDCL_B5_READ_TABLE` ausführen.
   - `S_TABU_NAM` (Anzeige, `ACTVT` 03) für die folgenden Tabellen.

   | Tabellen | Was sie enthalten |
   |---|---|
   | `T001` | Buchungskreise |
   | `T009`, `T009B`, `T001B` | Geschäftsjahresvarianten und Buchungsperioden |
   | `SKA1`, `SKAT` | Sachkonten |
   | `FAGL_011PC`, `FAGL_011ZC` | Bilanz-/GuV-Struktur |
   | `CSKS`, `CSKT` | Kostenstellen |
   | `SETHEADER`, `SETNODE` | Kostenstellen- und Profitcenter-Gruppen |
   | `CEPC`, `CEPCT` | Profitcenter (optional) |
   | `KNA1`, `KNVV`, `KNVH` | Kunden und ihre Hierarchie |
   | `MARA`, `MAKT`, `T006A` | Materialien und Einheiten |
   | `TCURR`, `TCURF`, `TCURX` | Wechselkurse und Währungsdezimalstellen |
   | `ACDOCA` | Journalbuchungen des führenden Ledgers und sein Saldovortrag |
   | `VBRK`, `VBRP`, `PRCD_ELEMENTS` | Fakturabelege und ihre Konditionen |
   | `ACDOCP` | Plandaten |
   | `COSR` | Statistische Kennzahlen |
   | `T001K`, `MBEW`, `MBEWH` | Bewertungskreise und Materialbestandswerte |

3. **Beantworten Sie die Buchhaltungsfragen** (siehe unten).

</Steps>

### Fragen, die der Administrator beantwortet

| Der Administrator teilt Ihnen mit | Eingabe in PlaidCloud unter Systemeinstellungen |
|---|---|
| Den Wechselkurstyp, der den Durchschnittskurs enthält. PlaidCloud bildet den Durchschnitt der Kurse dieses Typs je Monat. Oft ist es `M`. | `average_rate_type` |
| Den Wechselkurstyp, der den Stichtagskurs enthält, seinen Kurs am Monatsende. Wenn Sie keinen nennen, ist der Stichtagskurs der Kurs `M`. | `closing_rate_type` |
| Die Bilanz-/GuV-Struktur, die die Management-GuV und die Bilanz berichtet | `fsv` |
| Welche ihrer Knoten Umsatzerlöse, Herstellungskosten der verkauften Waren, Betriebsaufwand, nicht betrieblich, Aktiva, Passiva, Eigenkapital und Intercompany sind | `intercompany_nodes` für die Intercompany-Knoten. Für die anderen Knotentypen hat das Formular kein Feld. |
| Dass der Saldovortrag (`FAGLGVTR`) für jedes Geschäftsjahr, über das Sie berichten, ausgeführt wurde | Nichts einzugeben. Die Eröffnungssalden werden daraus gelesen. |

## Was zurückzusenden ist

| Der Administrator sendet | Eingabe in PlaidCloud als |
|---|---|
| Die System-ID und den Anwendungsserver (oder Meldungsserver und Anmeldegruppe) | **Anwendungsserver** und **Systemnummer** |
| Den Mandanten | **Mandant** |
| Den Namen des Kommunikationsbenutzers | **Benutzer** |
| Das Kennwort des Kommunikationsbenutzers über Ihren Kennwortmanager | **Kennwort**, das Ihr Team selbst einfügt |
| Den Namen des PlaidLink-Agents, der das System erreicht | `agent` unter Systemeinstellungen |
| Die Buchungskreise, die PlaidCloud lesen darf | Unter **Buchungskreise**, die das System vor einem Ladevorgang nicht auflisten kann: Geben Sie unter **Name** einen Buchungskreis ein oder lassen Sie das Feld leer, um jeden Buchungskreis zu laden |

<Aside type="caution">
Senden Sie das Kennwort nie per E-Mail. **Kennwort** ist ein Geheimnis: Es wird in der Verbindung gespeichert und nie wieder angezeigt.
</Aside>

## Zugriff prüfen

Geben Sie in PlaidCloud die Werte ein und klicken Sie auf **Verbindung testen**. Jedes Dataset wird als **Lesbar**, **Fehlende Berechtigung** oder **Fehler** angezeigt:

| Dataset | Tabellen, die es liest |
|---|---|
| Entitäten | `T001` |
| Geschäftskalender | `T001`, `T009`, `T009B`, `T001B` |
| Wechselkurse | `TCURR`, `TCURF` |
| Kontenplan | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC` |
| Abteilungen | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| Profitcenter | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| Kunden | `KNA1`, `KNVV`, `KNVH` |
| Produkte | `MARA`, `MAKT`, `T006A` |
| Hauptbuch | `ACDOCA` |
| Saldenliste | `ACDOCA`, Saldovortrag |
| Verkaufspositionen | `VBRK`, `VBRP`, `PRCD_ELEMENTS` |
| Budget | `ACDOCP` |
| Verteilungstreiber | `COSR` |
| Lagerbestände | `T001K`, `MBEW`, `MBEWH` |

Zeigt ein Dataset **Fehlende Berechtigung**, bitten Sie den Administrator, die Tabelle der Rolle hinzuzufügen, und testen Sie erneut. Profitcenter, Verkaufspositionen, Budget, Verteilungstreiber und Lagerbestände sind optional: Ein System, das eines davon nicht enthält, lädt trotzdem alles andere.
