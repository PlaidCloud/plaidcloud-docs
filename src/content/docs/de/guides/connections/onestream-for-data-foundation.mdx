Verbinden Sie PlaidCloud mit **OneStream**, damit Data Foundation Ihre konsolidierten Ergebnisse lesen und seine Management-Gewinn- und Verlustrechnung des Konzerns darauf abstimmen kann. OneStream wird über seinen Konnektor unterstützt: PlaidCloud meldet sich mit OAuth-2.0-Client-Credentials an und liest einen Datenadapter, den Ihr OneStream-Administrator erstellt. Es wird nur gelesen. Wenn Sie eine Data-Management-Sequenz angeben, führt PlaidCloud diese Sequenz zuerst aus, um zu aktualisieren, was der Adapter liest, und sonst nichts.

OneStream ist eine Quelle von Ergebnissen, auf die abgestimmt wird, nicht von Hauptbuchzeilen: Seine Zeilen landen als Szenario `Consolidated` der Budgettabelle des Modells, Version `OneStream`. Siehe [Mit Ihrem Konsolidierungssystem abstimmen](/de/guides/projects/data-foundation/#auf-ihr-konsolidierungssystem-abstimmen).

<Aside type="note">
Die Spalten des Adapters sind ein Vertrag, den Sie und Ihr OneStream-Administrator vereinbaren. Wird der Adapter nach dieser Seite gebaut, landen seine Zeilen wie unten beschrieben. Vergleichen Sie die Ergebnisse des ersten Ladens mit einem OneStream-Bericht, dem Sie vertrauen.
</Aside>

## Was Ihr OneStream-Administrator einrichtet

Die Registerkarte **Foundation** formuliert eine Zugriffsanfrage, die Sie versenden. Sie bittet um Folgendes.

1. Einen Client für PlaidCloud im Identitätsdienst von OneStream, der den Grant **Client Credentials** verwendet, mit einem Dienstbenutzer, der den Adapter ausführen darf und – falls PlaidCloud zuvor die Ergebnisse aktualisieren soll – die Data-Management-Sequenz.

2. In der Anwendung und dem Workspace, über die Sie berichten, einen Datenadapter namens **Foundation_Results**, der eine Tabelle der konsolidierten Ergebnisse mit genau diesen Spalten zurückgibt:

   | Spalte | Enthält |
   |---|---|
   | `entity` | Das Konsolidierungsmitglied: eine Entität, ein Eliminierungsmitglied oder die Konzernsumme. |
   | `account` | Den Kontocode. Nur Basiskonten. |
   | `time` | Den Monat im Format `YYYY-MM`. |
   | `scenario` | Das Szenario. |
   | `view` | `YTD` oder `Periodic`. PlaidCloud liest nur die Zeilen der von Ihnen gewählten Ansicht. |
   | `amount` | Eine Zahl, mit dem Vorzeichen und dem Maßstab, die Ihre Berichte zeigen. |
   | `currency` | Die Währung, in der der Betrag angegeben ist: die Berichtswährung Ihres Konzerns. |
   | `flow`, `ud1`, `ud2`, `ud3`, `ud4` | Flow- und benutzerdefinierte Dimensionen. Nur Basismitglieder. |

   Liefern Sie Basismitglieder der Konto-, Flow- und benutzerdefinierten Dimensionen. Die Zeile eines übergeordneten Mitglieds würde seine untergeordneten Mitglieder doppelt zählen. Der Adapter liest das Konsolidierungsmitglied aus der Substitutionsvariablen `Member` und die Ansicht aus `View`.

3. Die zu lesenden Mitglieder: die Entitäten, die Eliminierungsmitglieder und die Konzernsumme.

## Verbindung erstellen

<Steps>

1. Öffnen Sie **Tools > Connections** und klicken Sie auf `New Connection`, und wählen Sie dann **OneStream**. Oder erstellen Sie sie auf der Registerkarte **Foundation**, wenn Sie die Quelle hinzufügen.

2. Füllen Sie die Felder aus:

   | Feld | Wert |
   |---|---|
   | Host | Die OneStream-Basis-URL, beginnend mit `https://`. |
   | Client-ID | Die Client-ID des PlaidCloud-Clients. |
   | Client-Secret | Dessen Secret. Verschlüsselt gespeichert und nie wieder angezeigt. |
   | Token URL | Leer lassen, um den Host gefolgt von `/identity/connect/token` zu verwenden. |
   | Standardanwendung | Wird von einem Lesevorgang verwendet, der seine Anwendung leer lässt. |
   | Standard-Workspace | Wird von einem Lesevorgang verwendet, der seinen Workspace leer lässt. |
   | Timeout (Sekunden) | Standardmäßig 120. |

3. Klicken Sie auf `Create`.

</Steps>

## Zu einem Data-Foundation-Projekt hinzufügen

Fügen Sie die Verbindung auf der Registerkarte **Foundation** wie jede andere als Quelle hinzu (siehe [ERP verbinden](/de/guides/projects/data-foundation/#erp-verbinden)) und wählen Sie die zu lesenden Konsolidierungsmitglieder. Beantworten Sie dann, was die Beträge des Adapters beschreibt:

| Einstellung | Bedeutung |
|---|---|
| Mitglieder | Die zu lesenden Konsolidierungsmitglieder, je ein Aufruf des Adapters pro Mitglied. |
| Ansicht | Ob die Beträge des Adapters kumuliert (Standard) oder periodisch sind. Kumulierte Zeilen landen als periodische Beträge. |
| Vorzeichen | **Natürlich**: jedes Konto mit seinem eigenen Vorzeichen, wie OneStream es berichtet (Standard). **Soll positiv**: Soll-Beträge positiv. |
| Maßstab | Der Multiplikator auf ganze Währungseinheiten: `1000`, wenn OneStream Tausender liefert. |
| Startmonat des Geschäftsjahres | Der Monat, in dem Ihr Geschäftsjahr beginnt, zum Umrechnen von kumuliert in periodisch. |
| Anwendung, Workspace | Überschreiben die der Verbindung. |
| Substitutionsvariablen | Zusätzliche Variablen, die der Adapter liest, zum Beispiel `Time=2026M1`. |
| Data-Management-Sequenz | Eine Sequenz, die vor dem Lesen ausgeführt wird, um zu aktualisieren, was der Adapter liest. |

Ordnen Sie die OneStream-Mitglieder Ihren Entitäten mit einer Codezuordnungsdatei zu, die für diese Quelle gilt. Siehe [Entitätszuordnung](/de/guides/projects/data-foundation/#entitätszuordnung). Die Quelle liest kein Verlaufsfenster: Die eigenen Substitutionsvariablen des Adapters begrenzen es.

Ein Ladevorgang, bei dem der Adapter keine Zeilen zurückgibt, endet mit einer Warnung, nicht mit einem Fehler, und die Tabelle ist leer.
