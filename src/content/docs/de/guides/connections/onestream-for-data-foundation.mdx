Verbinden Sie PlaidCloud mit **OneStream**, damit Data Foundation Ihre konsolidierten Ergebnisse lesen und seine Management-Konzern-Gewinn- und Verlustrechnung darauf abstimmen kann. OneStream wird über seinen Konnektor unterstützt: PlaidCloud meldet sich mit OAuth-2.0-Client-Anmeldedaten an und liest einen Datenadapter, den Ihr OneStream-Administrator erstellt. Es liest ausschließlich.

OneStream ist eine Quelle von Ergebnissen, auf die abgestimmt wird, nicht von Hauptbuchzeilen: Seine Zeilen werden als Szenario `Consolidated` der Budgettabelle des Modells in der Version `OneStream` geladen. Siehe [Auf Ihr Konsolidierungssystem abstimmen](/de/guides/projects/data-foundation/#mit-ihrem-konsolidierungssystem-abstimmen).

<Aside type="note">
Die Spalten des Adapters sind ein Vertrag, den Sie und Ihr OneStream-Administrator vereinbaren. Wird der Adapter gemäß dieser Seite erstellt, werden seine Zeilen wie unten beschrieben geladen. Vergleichen Sie die Ergebnisse des ersten Ladevorgangs mit einem OneStream-Bericht, dem Sie vertrauen.
</Aside>

## Was Ihr OneStream-Administrator einrichtet

Die Seite **Systeme** des Projekts verfasst eine Zugriffsanfrage, die Sie senden; siehe [ERP verbinden](/de/guides/projects/data-foundation/#ihr-erp-verbinden). Sie verlangt Folgendes.

1. Einen Client für PlaidCloud im Identitätsdienst von OneStream, der den Grant **Client Credentials** verwendet, mit einem Dienstbenutzer, der nur die unten aufgeführten Adapter ausführen darf: keine Rechte für Data Management, Laden oder Konsolidierung. PlaidCloud führt keine Data-Management-Sequenz aus; halten Sie die Ergebnisse, die die Adapter lesen, daher nach Ihrem eigenen Zeitplan aktuell.

2. In der Anwendung und im Workspace, über die Sie berichten, einen Datenadapter mit dem Namen **Foundation_Results**, der eine Tabelle der konsolidierten Ergebnisse mit genau diesen Spalten zurückgibt:

   | Spalte | Enthält |
   |---|---|
   | `entity` | Das Konsolidierungselement: eine Entität, ein Eliminierungselement oder die Konzernsumme. |
   | `account` | Den Kontocode. Nur Basiskonten. |
   | `time` | Den Monat im Format `YYYY-MM`. |
   | `scenario` | `Actual` für die konsolidierten Ergebnisse. `Budget` oder `Forecast` für einen Plan, der als Plan gelesen wird. |
   | `view` | `YTD` oder `Periodic`. PlaidCloud liest nur die Zeilen der gewählten Ansicht. |
   | `amount` | Eine Zahl, in dem Vorzeichen und Maßstab, die Ihre Berichte zeigen. |
   | `currency` | Die Währung, in der der Betrag angegeben ist: die Berichtswährung Ihres Konzerns. |
   | `flow` | Das Flow-Element. Nur Basiselemente. |
   | `ud1` bis `ud5` | Die Elemente für Abteilung, Produkt, Standort, Vertriebsmitarbeiter und Projekt, `None`, wenn die Zeile keines hat. Nur Basiselemente. |
   | `version` | Die Version eines Plans. Lassen Sie sie für `Actual` auf `None` oder leer. |
   | `version_as_of` | Der Monat im Format `YYYY-MM`, zu dem die Version eines Plans erstellt wurde. Lassen Sie ihn für `Actual` auf `None` oder leer. |
   | `quantity` | Die Einheiten, für die eine Planzeile geplant ist, pro Monat, unabhängig von der Ansicht. Lassen Sie sie für `Actual` auf `None` oder leer. |

   Liefern Sie Basiselemente der Konto-, Flow- und benutzerdefinierten Dimensionen. Die Zeile eines übergeordneten Elements würde seine untergeordneten Elemente doppelt zählen. Der Adapter liest das Konsolidierungselement aus der Substitutionsvariablen `Member` und die Ansicht aus `View`.

   Enthält Ihr Plan Mitarbeiterzahlen oder produzierte Einheiten, erstellen Sie zusätzlich einen Adapter mit dem Namen **Foundation_Drivers** mit den Spalten `entity`, `time`, `scenario`, `driver` (zum Beispiel `headcount` oder `units_produced`), `value`, `unit` (`FTE`, `EA` und so weiter), `ud1` (Abteilung), `ud2` (Produkt), `ud3` (Standort), `version` und `version_as_of`. Er liest `Member` auf dieselbe Weise und ist optional: Ohne ihn oder ohne Zugriff darauf werden keine geplanten Treiber geladen, und die Bereitschaftsprüfungen weisen darauf hin.

3. Die zu lesenden Elemente: die Entitäten, die Eliminierungselemente und die Konzernsumme.

## Verbindung erstellen

<Steps>

1. Öffnen Sie **Tools > Connections**, klicken Sie auf `New Connection` und wählen Sie dann **REST - OneStream**.

2. Füllen Sie die Felder aus:

   | Feld | Wert |
   |---|---|
   | Host | Die Basis-URL von OneStream, beginnend mit `https://`. |
   | Client-ID | Die Client-ID des PlaidCloud-Clients. |
   | Client-Secret | Dessen Secret. Verschlüsselt gespeichert und nie wieder angezeigt. |
   | Token-URL | Leer lassen, um den Host gefolgt von `/identity/connect/token` zu verwenden. |
   | Standardanwendung | Wird von einem Lesevorgang verwendet, der seine Anwendung leer lässt. |
   | Standard-Workspace | Wird von einem Lesevorgang verwendet, der seinen Workspace leer lässt. |
   | Timeout (Sekunden) | Standardmäßig 120. |

3. Klicken Sie auf `Create`.

</Steps>

Sie können die Verbindung auch erstellen, wenn Sie das System auf der Seite **Systeme** hinzufügen: Wählen Sie unter **Verbindung** die Option **Neue Verbindung**, und derselbe Verbindungseditor wird geöffnet.

## Zu einem Data-Foundation-Projekt hinzufügen

Fügen Sie OneStream auf der Seite **Systeme** des Projekts wie jedes andere System mit seiner Verbindung hinzu (siehe [ERP verbinden](/de/guides/projects/data-foundation/#ihr-erp-verbinden)). OneStream listet keine Elemente zum Ankreuzen auf; geben Sie daher unter **Optionen**, **Gesellschaften** die zu lesenden Konsolidierungselemente durch Kommas getrennt ein: mindestens eines. Beschreiben Sie dann unter **Systemeinstellungen** die Beträge des Adapters:

| Einstellung | Bedeutung |
|---|---|
| **View member** | `ytd` (Standard), wenn die Beträge des Adapters kumuliert seit Jahresbeginn sind, oder `periodic`. Kumulierte Zeilen werden als Periodenbeträge geladen. |
| **Sign convention** | `natural` (Standard): jedes Konto in seinem eigenen Vorzeichen, wie OneStream es berichtet. `debit_positive`: Soll positiv. |
| **Amount scale** | Der Multiplikator auf ganze Währungseinheiten: `1000`, wenn OneStream Tausender liefert. Standardmäßig `1`. |
| **First month of the fiscal year** | Der Monat, in dem Ihr Geschäftsjahr beginnt, von `1` bis `12`, zum Umrechnen von kumuliert in periodisch. Standardmäßig `1`. |
| **Application**, **Workspace** | Überschreiben die der Verbindung. Leer lassen, um die der Verbindung zu verwenden. |
| **Adapter results table** | Der Tabellenname innerhalb des Datensatzes des Adapters. Standardmäßig `Results`. |
| **Substitution variables** | Die für den Adapter gesetzten Substitutionsvariablen, eine pro Zeile im Format `name = value`, zum Beispiel `Time = 2026M1`. |

Ordnen Sie die OneStream-Elemente Ihren Entitäten mit einer Code-Map-Datei zu, die für diese Quelle gilt. Siehe [Entitätszuordnung](/de/guides/projects/data-foundation/#entitätszuordnung). Die Quelle liest kein Verlaufsfenster: Die eigenen Substitutionsvariablen des Adapters begrenzen sie.

Ein Ladevorgang, bei dem der Adapter keine Zeilen zurückgibt, endet mit einer Warnung, nicht mit einem Fehler, und die Tabelle ist leer.
