Verbinden Sie PlaidCloud mit **OneStream**, damit Data Foundation Ihre konsolidierten Ergebnisse lesen und seine Management-Konzern-Gewinn- und Verlustrechnung darauf abstimmen kann. OneStream wird über seinen Konnektor unterstützt: PlaidCloud meldet sich mit OAuth-2.0-Client-Anmeldedaten an und liest einen Datenadapter, den Ihr OneStream-Administrator erstellt. Es liest ausschließlich. Wenn Sie eine Data-Management-Sequenz angeben, führt PlaidCloud diese Sequenz zuerst aus, um aufzufrischen, was der Adapter liest, und sonst nichts.

OneStream ist eine Quelle von Ergebnissen, auf die abgestimmt wird, nicht von Hauptbuchzeilen: Seine Zeilen werden als Szenario `Consolidated` der Budgettabelle des Modells in der Version `OneStream` geladen. Siehe [Auf Ihr Konsolidierungssystem abstimmen](/de/guides/projects/data-foundation/#mit-ihrem-konsolidierungssystem-abstimmen).

<Aside type="note">
Die Spalten des Adapters sind ein Vertrag, den Sie und Ihr OneStream-Administrator vereinbaren. Wird der Adapter gemäß dieser Seite erstellt, werden seine Zeilen wie unten beschrieben geladen. Vergleichen Sie die Ergebnisse des ersten Ladevorgangs mit einem OneStream-Bericht, dem Sie vertrauen.
</Aside>

## Was Ihr OneStream-Administrator einrichtet

Die Registerkarte **Foundation** verfasst eine Zugriffsanfrage, die Sie senden. Sie verlangt Folgendes.

1. Einen Client für PlaidCloud im Identitätsdienst von OneStream, der den Grant **Client Credentials** verwendet, mit einem Dienstbenutzer, der den Adapter ausführen darf und, wenn PlaidCloud die Ergebnisse zuerst aktualisieren soll, die Data-Management-Sequenz.

2. In der Anwendung und im Workspace, über die Sie berichten, einen Datenadapter mit dem Namen **Foundation_Results**, der eine Tabelle der konsolidierten Ergebnisse mit genau diesen Spalten zurückgibt:

   | Spalte | Enthält |
   |---|---|
   | `entity` | Das Konsolidierungselement: eine Entität, ein Eliminierungselement oder die Konzernsumme. |
   | `account` | Den Kontocode. Nur Basiskonten. |
   | `time` | Den Monat im Format `YYYY-MM`. |
   | `scenario` | Das Szenario. |
   | `view` | `YTD` oder `Periodic`. PlaidCloud liest nur die Zeilen der gewählten Ansicht. |
   | `amount` | Eine Zahl, in dem Vorzeichen und Maßstab, die Ihre Berichte zeigen. |
   | `currency` | Die Währung, in der der Betrag angegeben ist: die Berichtswährung Ihres Konzerns. |
   | `flow`, `ud1`, `ud2`, `ud3`, `ud4` | Flow- und benutzerdefinierte Dimensionen. Nur Basiselemente. |

   Liefern Sie Basiselemente der Konto-, Flow- und benutzerdefinierten Dimensionen. Die Zeile eines übergeordneten Elements würde seine untergeordneten Elemente doppelt zählen. Der Adapter liest das Konsolidierungselement aus der Substitutionsvariablen `Member` und die Ansicht aus `View`.

3. Die zu lesenden Elemente: die Entitäten, die Eliminierungselemente und die Konzernsumme.

## Verbindung erstellen

<Steps>

1. Öffnen Sie **Tools > Connections**, klicken Sie auf `New Connection` und wählen Sie dann **REST - OneStream**.

2. Füllen Sie die Felder aus:

   | Feld | Wert |
   |---|---|
   | Host | Die Basis-URL von OneStream, beginnend mit `https://`. |
   | Client-ID | Die Client-ID des PlaidCloud-Clients. |
   | Client-Secret | Dessen Secret. Verschlüsselt gespeichert und nie wieder angezeigt. |
   | Token-URL | Leer lassen, um den Host gefolgt von `/identity/connect/token` zu verwenden. |
   | Standardanwendung | Wird von einem Lesevorgang verwendet, der seine Anwendung leer lässt. |
   | Standard-Workspace | Wird von einem Lesevorgang verwendet, der seinen Workspace leer lässt. |
   | Timeout (Sekunden) | Standardmäßig 120. |

3. Klicken Sie auf `Create`.

</Steps>

Sie können die Verbindung auch beim Hinzufügen der Quelle auf der Registerkarte **Foundation** erstellen: Wählen Sie **Neue Verbindung erstellen** und füllen Sie **API-Host-URL**, **Client-ID**, **Client-Secret**, **Token-URL**, **Anwendung** und **Workspace** aus, die dasselbe bedeuten wie die obigen Felder.

## Zu einem Data-Foundation-Projekt hinzufügen

Fügen Sie die Verbindung auf der Registerkarte **Foundation** wie jede andere als Quelle hinzu (siehe [ERP verbinden](/de/guides/projects/data-foundation/#erp-verbinden)). OneStream listet keine Elemente zum Ankreuzen auf, daher fragt das Formular nach dem zu lesenden Konsolidierungselement: Geben Sie es unter **Name** ein. Beschreiben Sie dann unter **Systemeinstellungen** die Beträge des Adapters. Die Einstellungen werden unter diesen Namen angezeigt:

| Einstellung | Bedeutung |
|---|---|
| `view` | `ytd` (Standard), wenn die Beträge des Adapters kumuliert seit Jahresbeginn sind, oder `periodic`. Kumulierte Zeilen werden als Periodenbeträge geladen. |
| `sign` | `natural` (Standard): jedes Konto in seinem eigenen Vorzeichen, wie OneStream es berichtet. `debit_positive`: Soll positiv. |
| `scale` | Der Multiplikator auf ganze Währungseinheiten: `1000`, wenn OneStream Tausender liefert. Standardmäßig `1`. |
| `fy_start_month` | Der Monat, in dem Ihr Geschäftsjahr beginnt, von `1` bis `12`, zum Umrechnen von kumuliert in periodisch. Standardmäßig `1`. |
| `application`, `workspace` | Überschreiben die der Verbindung. Leer lassen, um die der Verbindung zu verwenden. |
| `table` | Der Tabellenname innerhalb des Datensatzes des Adapters. Standardmäßig `Results`. |
| `sequence` | Eine Data-Management-Sequenz, die vor dem Lesen ausgeführt wird, um aufzufrischen, was der Adapter liest. |

Ordnen Sie die OneStream-Elemente Ihren Entitäten mit einer Code-Map-Datei zu, die für diese Quelle gilt. Siehe [Entitätszuordnung](/de/guides/projects/data-foundation/#entitätszuordnung). Die Quelle liest kein Verlaufsfenster: Die eigenen Substitutionsvariablen des Adapters begrenzen sie.

Ein Ladevorgang, bei dem der Adapter keine Zeilen zurückgibt, endet mit einer Warnung, nicht mit einem Fehler, und die Tabelle ist leer.
