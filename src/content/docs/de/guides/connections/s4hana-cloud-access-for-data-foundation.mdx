[Data Foundation](/de/guides/projects/data-foundation/) führt die Daten aller ERP-Systeme und Instanzen, die Sie verbinden, in einem Common Finance Model zusammen, und SAP S/4HANA Cloud ist eines der ERP-Systeme, die es direkt liest. Die Verbindung liest die freigegebenen OData-Dienste des Mandanten mit OAuth-2.0-Client-Anmeldedaten; ein Agent ist nicht beteiligt. Diese Seite richtet sich an den S/4HANA-Cloud-Administrator, der das einrichtet, und an den PlaidCloud-Benutzer, der ihn darum bittet.

PlaidCloud liest Daten ausschließlich. Niemand sendet ein Kennwort oder ein Client-Secret per E-Mail.

## Zugriffsanfrage senden

Wählen Sie auf der Registerkarte **Foundation** des Projekts unter **SAP-S/4HANA-Cloud-Verbindung** die Option **Neue Verbindung erstellen**. Das Formular zeigt die vollständige Anfrage. Klicken Sie auf **Anfrage kopieren**, um sie in Ihre eigene Nachricht einzufügen, oder auf **Anfrage per E-Mail senden**, um sie in Ihrem E-Mail-Programm mit dem Betreff „Read-only SAP S/4HANA Cloud access for PlaidCloud (OAuth 2.0 client credentials)“ zu öffnen.

## Was der S/4HANA-Cloud-Administrator einrichtet

<Steps>

1. **Erstellen Sie einen Kommunikationsbenutzer** für PlaidCloud in der App **Maintain Communication Users**. Seine Authentifizierungsmethode ist OAuth 2.0 oder Benutzername und Kennwort, je nach Anforderung Ihrer Systemlandschaft.

2. **Erstellen Sie ein Kommunikationssystem** für PlaidCloud in der App **Communication Systems**, mit diesem Benutzer für die eingehende Kommunikation und OAuth-2.0-Client-Anmeldedaten.

3. **Erstellen Sie für jedes der folgenden Szenarien eine Kommunikationsvereinbarung** in der App **Communication Arrangements**, jeweils für das System aus Schritt 2. Zusammen stellen sie die OData-Dienste bereit, die PlaidCloud liest:

   | Szenario | Dienst |
   |---|---|
   | Company Code | `API_COMPANYCODE_SRV` |
   | G/L Account in Chart of Accounts | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | Cost Center | `API_COSTCENTER_SRV` |
   | Business Partner and Customer | `API_BUSINESS_PARTNER` |
   | Product | `API_PRODUCT_SRV` |
   | Fiscal Year Variant Periods | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | Exchange Rates | `API_EXCHANGERATE_SRV` |
   | Journal Entry Item | `API_JOURNALENTRYITEMBASIC_SRV` (das Journal und der Saldovortrag) |
   | Billing Document | `API_BILLING_DOCUMENT_SRV` (optional: ergänzt fakturierte Umsätze, Belege und Positionen) |

   Geben Sie dem Kommunikationsbenutzer Zugriff auf jeden Buchungskreis, über den Sie berichten.

</Steps>

## Was zurückzusenden ist

| Der Administrator sendet | Eingabe in PlaidCloud als |
|---|---|
| Den Host der API des Mandanten, zum Beispiel `my300000-api.s4hana.cloud.sap` | **Host** |
| Die Client-ID | **Client-ID** |
| Das Client-Secret über das sichere Verbindungsformular | **Client-Secret**, das Ihr Team selbst einfügt |
| Die Token-URL, nur wenn Ihre Systemlandschaft statt des eigenen Autorisierungsservers des Mandanten (`/sap/bc/sec/oauth2/token`) einen XSUAA-Autorisierungsserver verwendet | **Token-URL (optional)** |
| Den Bereich, nur mit einem XSUAA-Autorisierungsserver | **Bereich (optional)** |
| Ob **Carry Forward Balances** für jedes zu ladende Geschäftsjahr ausgeführt wurde | Nichts einzugeben. Die Eröffnungssalden werden daraus gelesen. |

<Aside type="caution">
Senden Sie das Client-Secret nie per E-Mail. **Client-Secret** ist ein Geheimnis: Es wird in der Verbindung gespeichert und nie wieder angezeigt.
</Aside>

## Zugriff prüfen

Geben Sie in PlaidCloud die Werte ein und klicken Sie auf **Verbindung testen**. Jedes Dataset wird als **Lesbar**, **Fehlende Berechtigung** oder **Fehler** angezeigt:

| Dataset | Erforderlicher Dienst |
|---|---|
| Entitäten | `API_COMPANYCODE_SRV` |
| Kontenplan | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| Abteilungen | `API_COSTCENTER_SRV` |
| Kunden | `API_BUSINESS_PARTNER` |
| Produkte | `API_PRODUCT_SRV` |
| Wechselkurse | `API_EXCHANGERATE_SRV` |
| Geschäftskalender | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| Hauptbuch | `API_JOURNALENTRYITEMBASIC_SRV` |
| Saldenliste | `API_JOURNALENTRYITEMBASIC_SRV` |
| Verkaufspositionen | `API_BILLING_DOCUMENT_SRV` (optional) |

Zeigt ein Dataset **Fehlende Berechtigung**, bitten Sie den Administrator, die Kommunikationsvereinbarung für den zugehörigen Dienst hinzuzufügen, und testen Sie erneut. Verkaufspositionen, Budget und Lagerbestände sind optional: Ein Mandant, der eines davon nicht enthält, lädt trotzdem alles andere.
