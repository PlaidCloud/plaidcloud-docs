PlaidCloud konvertiert räumliche Alteryx-Workflows in erweiterte Workflows, die aus
[Geodaten-Schritten](/de/reference/workflow-steps/spatial/) bestehen. Für jedes Tool der
Alteryx-Palette „Spatial" gibt es eine Konvertierungsroute – die
[Tabelle zur Abdeckung räumlicher Tools](/de/reference/alteryx-conversion-matrix/#abdeckung-der-räumlichen-tools)
führt sie Tool für Tool auf, zusammen mit den bekannten Lücken.

Dieser Leitfaden behandelt die praktische Durchführung: die Dateien paketieren, den Import ausführen und
das Ergebnis validieren. Was die Schritte nach der Konvertierung leisten, lesen Sie unter
[Geodatenanalyse](/de/guides/workflows/geospatial-analytics/).

## Räumliche Eingaben paketieren

Sammeln Sie vor dem Import alle räumlichen Abhängigkeiten. Ein konvertierter Workflow kann nur die Dateien
lesen, die Sie mitgebracht haben.

- Shapefile-Gruppen: `.shp` mit `.shx`, `.dbf` und `.prj`.
- MapInfo-Gruppen: `.tab` mit `.map`, `.id` und `.dat`.
- KML- und GeoJSON-Dateien.
- Lookup-Tabellen, die räumliche und nicht räumliche Datensätze verknüpfen.
- Die erwarteten räumlichen Ausgaben für die Validierung.

Legen Sie die zugehörigen Begleitdateien jeder Gruppe im selben Ordner ab wie die Hauptdatei –
[Spatial File Import](/de/reference/workflow-steps/spatial/spatial-file-import/)
liest sie von dort.

<Aside type="caution" title="Die .geo-GeoFile wird nicht konvertiert">
  Das proprietäre binäre Format `.geo` von Alteryx kann nicht gelesen werden. Die Konvertierung bricht
  dabei kontrolliert ab, statt einen Import zu erzeugen, der zur Laufzeit abstürzt. Exportieren Sie
  diese Ebenen vor dem Import erneut als Shapefile oder GeoJSON.
</Aside>

## So werden räumliche Tools konvertiert

Die Konvertierung wählt die einfachste Route, die das richtige Ergebnis liefert, und die Route
bestimmt, wie der Schritt skaliert.

**Datenbankroute (SQL).** Create Points und Distance werden zu
[Table Extract-Ausdrücken](/de/reference/workflow-steps/spatial/spatial-sql-recipes/);
Spatial Match und Find Nearest werden zu
[Räumlicher Abgleich](/de/reference/workflow-steps/spatial/spatial-match/) und
[Spatial Find Nearest](/de/reference/workflow-steps/spatial/spatial-find-nearest/).
Diese laufen vollständig im Warehouse und skalieren daher mit der Tabelle.

**Route über die Workflow-Engine.** Alles, was Geometrie umformt – Buffer, Trade
Area, Generalize, Smooth, Process, Poly-Build, Poly-Split, Make Grid, Combine,
Spatial Info und der räumliche Dateiimport – läuft in der Workflow-Engine mit
Shapely und GDAL, weil sich diese Arbeit nicht in Datenbank-SQL ausdrücken lässt.

**Berichte.** Map und Report Map werden zu
[Report Map](/de/reference/workflow-steps/reports/report-map/)-Schritten; die gepackten Makros Heat Map
und Pie Wedge Trade Area werden zu
[Schritten für gepackte Makros](/de/reference/workflow-steps/macros/).

Jeder konvertierte Schritt ist ein vollwertiger Schritttyp, den Sie öffnen, bearbeiten und von Hand
neu aufbauen können. Make Grid und Poly-Split sind die Ausnahme: Sie werden konvertiert und laufen, lassen sich
vorerst aber nur über die API oder MCP konfigurieren, nicht über ein Designer-Formular. Die Eingabevoraussetzungen
der räumlichen Tools finden Sie unter
[Bekannte räumliche Voraussetzungen](/de/reference/alteryx-conversion-matrix/#bekannte-räumliche-voraussetzungen).

## Geometrie validieren

Vergleichen Sie für die Übereinstimmung der räumlichen Ausgaben Folgendes:

1. Ausgabeschema.
2. Zeilenanzahl.
3. Werte der Schlüsselfelder.
4. Geometriewerte oder aus der Geometrie abgeleitete Messwerte.
5. Verhalten des Koordinatenbezugssystems.
6. Entfernungen, Flächen und vereinfachte Geometrie innerhalb einer akzeptierten Toleranz.

Die Zeilenreihenfolge muss nicht übereinstimmen, es sei denn, der Workflow hängt von der Sortierung ab.

<Aside type="note" title="Flächen und Längen können abweichen – meist zum Besseren">
  [Spatial Info](/de/reference/workflow-steps/spatial/spatial-info/) misst
  geodätisch auf dem WGS84-Sphäroid. Wenn Sie mit einer planaren
  Messung vergleichen, erwarten Sie bei US-Breitengraden eine Abweichung von etwa 25 %; der geodätische
  Wert entspricht dem von Alteryx.
</Aside>

## Räumliche Artefakte validieren

Prüfen Sie bei Karten und Kartenberichten Folgendes:

1. Die Kartenebenen enthalten die erwarteten Datensätze.
2. Beschriftungen und gruppierte Features sind korrekt.
3. Grenzen, Punkte und Polygone erscheinen an den erwarteten Stellen.
4. Das Artefakt ist für nachgelagerte Prüfer verwendbar.
5. Jede beabsichtigte Abweichung bei cloudnativen Artefakten ist dokumentiert.

Berichts-Renderer sind eine Annäherung an die Alteryx-Ausgabe – validieren Sie die Tabelle
hinter einer Karte, bevor Sie das visuelle Layout vergleichen.

## Häufige räumliche Probleme

| Symptom | Prüfung |
| --- | --- |
| Der Import liefert Zeilen mit leerer Geometrie | Begleitdateien liegen im selben Ordner |
| Koordinaten landen an der falschen Stelle | Projektionsdatei (`.prj`) vorhanden; die Koordinaten von Create Points sind Gleitkomma- oder Ganzzahlwerte (×1.000.000) für Längen- und Breitengrad – projizierte Koordinaten müssen zuvor im Workflow nach WGS84 umprojiziert werden |
| Flächen oder Längen weichen vom Original ab | Planare gegenüber geodätischer Messung, siehe Hinweis oben |
| Eine Spalte von Spatial Info fehlt | Das Maß ist der [Peano-Schlüssel](/de/reference/alteryx-conversion-matrix/#bekannte-räumliche-voraussetzungen), das einzige Maß ohne öffentliche Spezifikation; die Konvertierung nennt ihn in einem Hinweis |
| Einzugsgebiete haben die falsche Größe | Die Dimensionierung nach Fahrzeit wird nicht konvertiert – nur ein fester Radius |
| Ein Find-Nearest-Schritt lehnt seine Entfernung ab | Der Schritt für die nächste Entfernung misst nur in Meilen, Kilometern, Metern oder Fuß; Yards, Seemeilen und Fahrzeit werden abgelehnt, ebenso eine maximale Entfernung, die keine Zahl ist |
| Ein räumliches Tool lehnt sich selbst benennend ab | Geocoder hat kein PlaidCloud-Äquivalent – es benötigt einen Geocoding-Dienst und Referenzdaten, die die Plattform nicht mitbringt; die Ablehnung nennt das Tool und den Grund |
| Zeilenanzahlen weichen ab | In beiden Ausführungen dieselben Quelldaten verwendet |
