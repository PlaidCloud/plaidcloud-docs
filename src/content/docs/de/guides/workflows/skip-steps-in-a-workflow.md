Schritte im Workflow können so eingestellt werden, dass sie bei der Workflow-Ausführung übersprungen werden. Das kann nützlich sein, wenn es Debugging-Schritte oder alte Schritte gibt, die Sie noch nicht vollständig aus dem Workflow entfernen möchten.

Um diese Option festzulegen, deaktivieren Sie in der Workflow-Tabelle das Kontrollkästchen **Aktiviert** des Schritts. Die Änderung wird gespeichert, sobald Sie darauf klicken, ohne separates Speichern. Der Schritt wird dann nicht mehr als Teil des Workflows ausgeführt, kann aber weiterhin über die Einzelschrittausführung ausgeführt werden.



Schritte, die deaktiviert wurden, tragen in der Schritthierarchie-Tabelle des Workflows eine Deaktiviert-Markierung.
