## Das Workflow-Protokoll anzeigen


Alles, was in einem Workflow passiert, etwa ausgeführte Schritte oder auftretende Warnungen, wird im Workflow-Protokoll festgehalten. Dieses Protokoll können Sie im Bereich **Projekt** auf der Registerkarte **Protokoll** ansehen. Das Workflow-Protokoll ist auch im Projektprotokoll enthalten, falls Sie eine umfassendere Ansicht der Protokolle mehrerer Workflows wünschen.

Wenn Sie im [Visuellen Workflow-Designer](/de/guides/workflows/advanced-workflows/) arbeiten, öffnet die Schaltfläche **Protokolle anzeigen** in der Symbolleiste dieselbe Protokollansicht, bereits auf den geöffneten Workflow gefiltert.



Im Protokollviewer können Sie das Protokoll sortieren und filtern sowie die Details eines bestimmten Protokolleintrags ansehen.



## Das Workflow-Protokoll leeren


Es kann gelegentlich wünschenswert sein, das Workflow-Protokoll zu leeren. Wählen Sie im Protokollviewer die Schaltfläche **Protokoll leeren**. Dadurch wird das Protokoll für den ausgewählten Workflow geleert, wodurch auch die Protokolleinträge aus dem Protokoll auf Projektebene entfernt werden.
