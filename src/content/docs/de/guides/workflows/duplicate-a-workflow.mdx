Das Kopieren eines Workflows ist nützlich, wenn Sie größere Änderungen planen oder einen Prozess mit anderen Optionen replizieren möchten. Kopien sind vollständig unabhängig – das Ändern einer Kopie wirkt sich nicht auf das Original aus.

In der Tabelle **Workflows** stehen zwei Aktionen zur Verfügung:

* **Duplicate Selected Workflows** – schnelle Kopie an Ort und Stelle im selben Projekt
* **Workflow(s) klonen** – Kopie in ein Zielprojekt Ihrer Wahl (Standard ist das aktuelle Projekt)


## Duplicate Selected Workflows

1. Öffnen Sie die Tabelle **Workflows** des Projekts
2. Wählen Sie einen oder mehrere Workflows aus
3. Klicken Sie in der Symbolleiste auf `Duplicate Selected Workflows`

Jeder Klon landet im selben Projekt, wobei an den Namen des Originals „ copy“ angehängt wird.


## Workflow(s) klonen

Verwenden Sie dies, wenn Sie Workflows in ein anderes Projekt kopieren möchten – zum Beispiel, um sie von einem Entwicklungsprojekt in ein benachbartes Projekt zu überführen.

1. Öffnen Sie die Tabelle **Workflows** des Quellprojekts
2. Wählen Sie einen oder mehrere Workflows aus
3. Öffnen Sie das Menü **Aktionen** und klicken Sie auf `Clone Workflow(s)`
4. Wählen Sie im Dialog das **Zielprojekt** (Standard ist das aktuelle Projekt)
5. Klicken Sie auf `Clone Workflow(s)`

Während das Klonen läuft, öffnet sich ein Fortschrittsdialog mit einem Gesamtbalken (Workflow N von M) und einem Balken pro Schritt für den Workflow, der gerade kopiert wird. Sie können auf `Run in Background` klicken, um den Dialog zu schließen und weiterzuarbeiten – das Klonen läuft weiter, und nach Abschluss erscheint eine Benachrichtigung.

An die Namen geklonter Workflows wird „ copy“ angehängt, damit sie nicht mit etwas kollidieren, das bereits im Zielprojekt vorhanden ist.

<Aside>Das Klonen kopiert die Workflow-Definition und die Schrittkonfiguration. Projektbezogene Ressourcen, auf die der Workflow verweist (Tabellen, Dimensionen, Verbindungen), müssen im Zielprojekt bereits vorhanden sein, oder Sie müssen sie separat klonen.</Aside>
