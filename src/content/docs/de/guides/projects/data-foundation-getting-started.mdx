Diese Anleitung führt Sie von einem neuen Projekt zu einem geladenen, geprüften Modell, das Berichte, Kennzahlen und KI-Assistenten lesen, und übergibt es dann. Sie folgt den acht Punkten der Checkliste **Einrichtung** auf der Registerkarte **Foundation** des Projekts, ergänzt um einen Schritt, in dem Sie die Dinge so benennen, wie Ihr Unternehmen es tut. Jeder Schritt verweist auf den Teil von [Data Foundation: Das Common Finance Model](/de/guides/projects/data-foundation/), der ihn ausführlich behandelt.

## Bevor Sie beginnen

- Sie müssen Projekte erstellen können und, bei einem gemeinsam genutzten Projekt, dessen Architect sein.
- Halten Sie die Anmeldedaten für jedes ERP-System bereit, das Sie verbinden möchten. Wenn Sie sie nicht haben, verfasst die Registerkarte **Foundation** eine Zugriffsanfrage für Ihren ERP-Administrator. Siehe [ERP verbinden](/de/guides/projects/data-foundation/#erp-verbinden).
- Entscheiden Sie, welche Vorlage passt. **Enterprise Profitability** erstellt die Gewinn- und Verlustrechnung und die Margenbrücken. **Cost to Serve** ergänzt die Kosten der Betreuung jedes Kunden. **Operational Transfer Pricing** prüft den Gewinn jeder Entität anhand Ihrer Richtlinienbandbreiten. Alle drei lesen dasselbe Common Finance Model. Siehe [Mit einer Vorlage auf dem Modell aufbauen](/de/guides/projects/data-foundation/#mit-einer-vorlage-auf-dem-modell-aufbauen).

## Welche Systeme das Modell speisen können

Jede der folgenden Seiten richtet sich an den Administrator, der den Zugriff gewährt, und entspricht der Zugriffsanfrage, die die Registerkarte **Foundation** verfasst. ## Die Einrichtungs-Checkliste durchgehen

<Steps>

1. **Erstellen Sie das Projekt.** Öffnen Sie in Analyze **Projekte** und klicken Sie auf **Neues Projekt**. Wählen Sie unter **Starten mit** eine Vorlage. Um das Modell auszuprobieren, bevor Sie etwas verbinden, aktivieren Sie **Mit Beispieldaten starten**: Das Projekt führt sofort ein erstes **Laden** aus, und die Registerkarte **Foundation** zeigt ein vollständiges Beispiel. Um ein Modell wiederzuverwenden, das Sie oder eine Kollegin bzw. ein Kollege gespeichert haben, wählen Sie **From a template file...**. Siehe [Als meine Vorlage speichern](/de/guides/projects/data-foundation/#als-eigene-vorlage-speichern).

2. **Daten verbinden.** Wählen Sie auf der Registerkarte **Foundation** eine bestehende Verbindung aus oder erstellen Sie eine, klicken Sie auf **Verbindung testen**, aktivieren Sie die zu ladenden Entitäten, legen Sie **Monate Verlauf** fest und klicken Sie auf **Verbinden**. Um ein weiteres System oder eine weitere Instanz einzubinden, wiederholen Sie dies und aktivieren Sie **Add this as another source instead of replacing the current one**. Fügen Sie eine Datei für Daten außerhalb Ihrer ERP-Systeme hinzu. Siehe [ERP verbinden](/de/guides/projects/data-foundation/#erp-verbinden) und [Quellen](/de/guides/projects/data-foundation/#quellen).

3. **Daten laden.** Klicken Sie auf **Laden**. Dabei wird jede Quelle in das Modell überführt, in Ihre Berichtswährung umgerechnet und geprüft. **Was zu tun ist** listet auf, was Ihre Aufmerksamkeit braucht, das Wichtigste zuerst. Siehe [Daten laden](/de/guides/projects/data-foundation/#daten-laden).

4. **Beantworten Sie die Fragen, die das Laden aufwirft.** Wo Quellen denselben Code für verschiedene Dinge verwenden, fragt **Codes waiting for your answer**, ob sie dasselbe bedeuten. Wo zwei Quellen dieselben Monate abdecken, steht **Choose which source counts from when** zur Verfügung. Klicken Sie auf **Apply changes**, um neu aufzubauen, ohne erneut aus den ERP-Systemen zu ziehen. Statt einzeln zu antworten, können Sie den Assistenten bitten, Antworten vorzuschlagen. Siehe [Codes quellenübergreifend zuordnen](/de/guides/projects/data-foundation/#codes-quellenübergreifend-zuordnen) und [Offene Fragen mit Ask klären](/de/guides/projects/data-foundation/#offene-fragen-mit-ask-klären).

5. **Prüfen, ob die Summen übereinstimmen.** Das Raster **Bereitschaft** zeigt eine Zeile je Entität, Periode und Prüfung. Eine Zahl, die Sie anzweifeln, lässt sich mit **Explain this number** öffnen, was sie aufschlüsselt in das, was das Hauptbuch enthält, was hinein- und herausumgelegt wurde und was im Konzern eliminiert wurde. Siehe [Bereitschaftsprüfungen](/de/guides/projects/data-foundation/#bereitschaftsprüfungen) und [Eine Zahl erklären](/de/guides/projects/data-foundation/#eine-zahl-erklären).

6. **Hierarchien prüfen.** Klicken Sie auf **Open hierarchies**, prüfen Sie die Hierarchien Entität, Konto und Abteilung und aktivieren Sie dann **Ich habe sie geprüft**. Siehe [Hierarchien](/de/guides/projects/data-foundation/#hierarchien).

7. **Benennen Sie die Dinge so, wie Ihr Unternehmen es tut.** Geben Sie unter **Business names** Kategorien, GuV-Zeilen, Kennzahlen und Spalten die Namen, die Ihr Unternehmen verwendet. Berichte, Kennzahlen und der Assistent zeigen sie an. Siehe [Geschäftsbezeichnungen](/de/guides/projects/data-foundation/#business-names). Wenn die Kostenverteilung des Modells nicht Ihrer Arbeitsweise entspricht, ändern Sie sie unter **Actions > Allocations...**. Siehe [Umlageregeln](/de/guides/projects/data-foundation/#umlageregeln).

8. **Halten Sie es aktuell.** Sobald ein Ladevorgang erfolgreich war, klicken Sie auf **Nächtlich aktualisieren**. Richten Sie optional ein [Board-Paket](/de/guides/projects/data-foundation/#board-pack) ein, das eine Excel-Arbeitsmappe und ein PDF des GuV-Dashboards in einen von Ihnen gewählten Ordner schreibt, auf Abruf oder nach einem Zeitplan, den Sie seinem Workflow geben.

9. **Teilen, dokumentieren und übergeben.** Geben Sie das Projekt für Ihr Team frei, klicken Sie auf **Download evidence pack** für einen Nachweis dessen, was geladen wurde und wie es abgestimmt ist, und machen Sie, wenn Sie das Projekt für einen Kunden eingerichtet haben, dessen Owner zum Architect und entfernen Sie sich dann selbst. Siehe [Projekt übergeben](/de/guides/projects/data-foundation/#das-projekt-übergeben).

</Steps>

<Aside type="tip">
Vor einer großen Änderung an Quellen oder Zuordnungen müssen Sie nichts vorher kopieren: Ein Wiederherstellungspunkt wird automatisch erstellt, und **Actions > Restore...** setzt das Projekt zurück. Siehe [Wiederherstellungspunkte](/de/guides/projects/data-foundation/#wiederherstellungspunkte).
</Aside>

## Was Sie am Ende haben

- Ein Common Finance Model mit einem Kontenplan, einem Satz Entitäten und einer Berichtswährung sowie eine Management-Konzern-Gewinn- und Verlustrechnung mit eliminierten Intercompany-Beziehungen.
- Ein Modell, Kennzahlen und ein Analysepfad, an die sich Ihr Team und der Assistent mit Fragen wenden können.
- Eine nächtliche Aktualisierung und optional ein Board-Paket.
- Ein Nachweispaket und ein Projekt, das der Owner Ihres Kunden verwaltet.
