Diese Anleitung führt Sie von einem neuen Projekt zu einem geladenen, geprüften Modell, das Berichte, Kennzahlen und KI-Assistenten lesen, und übergibt es anschließend. Sie folgt den acht Punkten der Checkliste **Einrichtung** auf der Registerkarte **Foundation** des Projekts. Jeder Schritt verweist auf den Teil von [Data Foundation: Das Common Finance Model](/de/guides/projects/data-foundation/), der ihn ausführlich behandelt.

## Bevor Sie beginnen

- Sie müssen Projekte erstellen können und bei einem gemeinsam genutzten Projekt dessen Architect sein.
- Halten Sie die Zugangsdaten für jedes ERP bereit, das Sie verbinden möchten. Wenn Sie sie nicht haben, formuliert die Registerkarte **Foundation** eine Zugriffsanfrage für Ihren ERP-Administrator. Siehe [ERP verbinden](/de/guides/projects/data-foundation/#erp-verbinden).
- Entscheiden Sie, welche Vorlage passt. **Enterprise Profitability** baut die Gewinn- und Verlustrechnung und Margenbrücken auf. **Cost to Serve** ergänzt die Kosten der Betreuung jedes Kunden. **Operational Transfer Pricing** prüft den Gewinn jeder Entität gegen Ihre Richtwertbereiche. Alle drei lesen dasselbe Common Finance Model. Siehe [Mit einer Vorlage auf dem Modell aufbauen](/de/guides/projects/data-foundation/#mit-einer-vorlage-auf-dem-modell-aufbauen).

## Welche Systeme das Modell speisen können

| SAP S/4HANA, SAP ECC | Das Verbindungsformular formuliert eine Zugriffsanfrage für Ihren SAP-Administrator. |
| SAP S/4HANA Cloud | [Mit SAP S/4HANA Cloud verbinden](/de/guides/connections/s4hana-cloud/) |
| Oracle E-Business Suite | Das Verbindungsformular formuliert eine Zugriffsanfrage für Ihren Oracle-Administrator. |

## Die Einrichtungs-Checkliste durchgehen

<Steps>

1. **Das Projekt erstellen.** Öffnen Sie in Analyze **Projekte** und klicken Sie auf **Neues Projekt**. Wählen Sie unter **Starten mit** eine Vorlage. Um das Modell auszuprobieren, bevor Sie etwas verbinden, aktivieren Sie **Mit Beispieldaten starten**: Das Projekt führt sofort ein erstes **Laden** aus, und die Registerkarte **Foundation** zeigt ein vollständiges Beispiel. Um ein Modell wiederzuverwenden, das Sie oder ein Kollege gespeichert haben, wählen Sie **From a template file...**. Siehe [Als meine Vorlage speichern](/de/guides/projects/data-foundation/#als-meine-vorlage-speichern).

2. **Daten verbinden.** Wählen Sie auf der Registerkarte **Foundation** eine bestehende Verbindung aus oder erstellen Sie eine, klicken Sie auf **Verbindung testen**, aktivieren Sie die zu ladenden Entitäten, legen Sie **Monate Verlauf** fest und klicken Sie auf **Verbinden**. Um ein weiteres System oder eine weitere Instanz einzubinden, wiederholen Sie dies und aktivieren Sie **Add this as another source instead of replacing the current one**. Fügen Sie eine Datei für Daten außerhalb Ihrer ERPs hinzu. Siehe [ERP verbinden](/de/guides/projects/data-foundation/#erp-verbinden) und [Quellen](/de/guides/projects/data-foundation/#quellen).

3. **Daten laden.** Klicken Sie auf **Laden**. Dabei wird jede Quelle in das Modell überführt, in Ihre Berichtswährung umgerechnet und geprüft. **Was zu tun ist** listet auf, was Ihre Aufmerksamkeit braucht, das Wichtigste zuerst. Siehe [Daten laden](/de/guides/projects/data-foundation/#daten-laden).

4. **Die Fragen beantworten, die das Laden aufwirft.** Wo Quellen denselben Code für verschiedene Dinge verwenden, fragt **Codes waiting for your answer**, ob sie dasselbe bedeuten. Wo zwei Quellen dieselben Monate abdecken, gilt **Choose which source counts from when**. Klicken Sie auf **Apply changes**, um neu aufzubauen, ohne erneut aus den ERPs zu laden. Statt einzeln zu antworten, können Sie den Assistenten bitten, Antworten vorzuschlagen. Siehe [Codes quellenübergreifend zuordnen](/de/guides/projects/data-foundation/#codes-quellenübergreifend-zuordnen) und [Offene Fragen mit Ask klären](/de/guides/projects/data-foundation/#offene-fragen-mit-ask-klären).

5. **Prüfen, ob die Summen übereinstimmen.** Das Raster **Bereitschaft** zeigt eine Zeile je Entität, Periode und Prüfung. Eine Zahl, an der Sie zweifeln, lässt sich mit **Explain this number** öffnen, das sie aufschlüsselt in das, was das Hauptbuch enthält, was hinein- und herausumgelegt wurde und was im Konzern eliminiert wurde. Siehe [Bereitschaftsprüfungen](/de/guides/projects/data-foundation/#bereitschaftsprüfungen) und [Eine Zahl erklären](/de/guides/projects/data-foundation/#eine-zahl-erklären).

6. **Hierarchien prüfen.** Klicken Sie auf **Open hierarchies**, prüfen Sie die Hierarchien für Entität, Konto und Abteilung und aktivieren Sie dann **Ich habe sie geprüft**. Siehe [Hierarchien](/de/guides/projects/data-foundation/#hierarchien).

7. **Dinge so benennen, wie Ihr Unternehmen es tut.** Geben Sie unter **Business names** Kategorien, GuV-Zeilen, Kennzahlen und Spalten die Namen, die Ihr Unternehmen verwendet. Berichte, Kennzahlen und der Assistent zeigen sie an. Siehe [Geschäftsbezeichnungen](/de/guides/projects/data-foundation/#geschäftsbezeichnungen). Wenn die Kostenverteilung des Modells nicht Ihrer Arbeitsweise entspricht, ändern Sie sie unter **Aktionen > Umlagen...**. Siehe [Umlageregeln](/de/guides/projects/data-foundation/#umlageregeln).

8. **Aktuell halten.** Klicken Sie nach einem erfolgreichen Laden auf **Nächtlich aktualisieren**. Richten Sie optional ein [Board Pack](/de/guides/projects/data-foundation/#board-pack) ein, das eine Excel-Arbeitsmappe und ein PDF des Dashboards der Gewinn- und Verlustrechnung in einen Ordner Ihrer Wahl schreibt.

9. **Teilen, dokumentieren und übergeben.** Geben Sie das Projekt für Ihr Team frei, klicken Sie auf **Download evidence pack** für einen Nachweis, was geladen wurde und wie es abgestimmt ist, und machen Sie, falls Sie das Projekt für einen Kunden eingerichtet haben, dessen Eigentümer zum Architect und entfernen Sie sich danach selbst. Siehe [Das Projekt übergeben](/de/guides/projects/data-foundation/#das-projekt-übergeben).

</Steps>

<Aside type="tip">
Vor einer größeren Änderung an Quellen oder Zuordnungen müssen Sie nicht erst etwas kopieren: Ein Wiederherstellungspunkt wird automatisch erstellt, und **Aktionen > Wiederherstellen...** stellt das Projekt wieder her. Siehe [Wiederherstellungspunkte](/de/guides/projects/data-foundation/#wiederherstellungspunkte).
</Aside>

## Was Sie am Ende haben

- Ein Common Finance Model mit einem Kontenplan, einem Satz Entitäten und einer Berichtswährung sowie eine Management-Konzern-Gewinn- und Verlustrechnung mit eliminierten Intercompany-Beträgen.
- Ein Modell, Kennzahlen und ein Analysepfad, an die Ihr Team und der Assistent Fragen stellen können.
- Eine nächtliche Aktualisierung und optional ein Board Pack.
- Ein Nachweispaket und ein Projekt, das der Eigentümer Ihres Kunden verwaltet.
