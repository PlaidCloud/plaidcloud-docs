PlaidCloud hält die Adressleiste im Einklang mit dem, was Sie geöffnet haben. Öffnen Sie einen Workflow, eine Tabelle, eine Dimension oder einen Bildschirm in Dashboards, Dokumenten oder Identität, und die URL wird zu einem **Deep-Link** dorthin – kopieren Sie diese URL, fügen Sie sie in eine Nachricht oder ein Ticket ein, und wer sie öffnet, landet auf demselben Bildschirm.

## Einen Link kopieren

1. Öffnen Sie den Bildschirm, den Sie teilen möchten – ein Projekt, einen Workflow, eine Tabelle, eine Dimension, einen Dateneditor oder einen Bildschirm in einer der anderen Apps.
2. Kopieren Sie die gesamte URL aus der Adressleiste Ihres Browsers.
3. Senden Sie sie weiter.

Es gibt keine separate Schaltfläche „Teilen“: Die Adressleiste *ist* der Link. Auch die Lesezeichenfunktion Ihres Browsers funktioniert mit diesen URLs, sodass ein Bildschirm, zu dem Sie oft zurückkehren, wie jede andere Webseite als Lesezeichen gespeichert werden kann.

<Aside type="note">
Ein Link enthält nur den *Ort*, nicht die Berechtigung, ihn zu sehen. Wer den Link öffnet, benötigt weiterhin Zugriff auf das Projekt. Wer ihn nicht hat, sieht das Objekt nicht.

Ein Link in eine App, die jemand nicht hat – weil sein Workspace sie nicht enthält oder sie ihm nicht gewährt wurde –, führt ihn mit einem Hinweis, dass der Link nicht verfügbar war, zur Startseite, statt scheinbar nichts zu tun.
</Aside>

## Worauf Sie verlinken können

### Analyze

| Bildschirm | Der Link endet mit |
|---|---|
| Projekt | `#p~<project>` |
| Workflow (Schrittraster) | `#p~<project>~w~<workflow>` |
| Workflow (Arbeitsfläche des Visueller Workflow-Designer) | `#p~<project>~c~<workflow>` |
| Ein Schritt innerhalb eines Workflows | `…~w~<workflow>~s~<step>` oder `…~c~<workflow>~s~<step>` |
| Ein Schritt für sich | `#p~<project>~s~<step>` |
| Tabellen-Explorer | `#p~<project>~t~<table>` |
| Dimensionshierarchie | `#p~<project>~d~<dimension>` |
| Dateneditor | `#p~<project>~e~<editor>` |
| Startseite | `#home` |

Der Projektteil des Links ist das **Schema** Ihres Projekts, wenn es ein benutzerdefiniertes hat, sodass Links als `#p~acme_budget~w~…` statt als Hexadezimalfolge zu lesen sind. Projekte mit dem Standardschema verwenden stattdessen die eigene Kennung des Projekts. Beide Formen öffnen dasselbe Projekt, sodass ein älterer Link nach dem Festlegen eines Schemas weiter funktioniert.

### Dashboards, Dokumente und Identität

Bildschirme in den anderen Apps werden direkt benannt, sodass ihre Links wie der Bildschirm selbst lauten:

| App | Bildschirm | Link |
|---|---|---|
| Dashboards | Dashboards | `#dashboard.dashboards` |
| Dashboards | Apps | `#dashboard.panel_apps` |
| Dashboards | Notebooks | `#dashboard.jupyterlite_deployments` |
| Dokumente | Verwalten | `#document.accounts` |
| Dokumente | Ihre Konten | `#document.your_accounts` |
| Dokumente | Dateien eines Kontos durchsuchen | `#document.browser~…` |
| Identität | Mitglieder | `#identity.members` |
| Identität | Verzeichnis | `#identity.member_directory` |
| Identität | Verteilerlisten | `#identity.distro.lists` |
| Identität | Sicherheitsgruppen | `#identity.security_groups` |
| Identität | Gruppenaudit | `#identity.security_group_audit` |
| Identität | Alle Bereiche | `#identity.scopes` |
| Identität | Sitzungen | `#identity.sessions` |
| Identität | API-Clients | `#identity.api_client_list` |
| Identität | Sicherheitsprotokoll | `#identity.security_log` |

Einige Bildschirme merken sich eine Einstellung im Link – die Listen Mitglieder und Mitgliederverzeichnis behalten jeweils, ob Sie **Alle**, **Nur aktive** oder **Nur inaktive** angesehen haben, und das Durchsuchen eines Kontos behält, welches Konto –, die Ihr Browser als codierten Zusatz nach dem Bildschirmnamen anzeigt. Kopieren Sie die gesamte URL und fügen Sie sie ein, und sie öffnet den Bildschirm, auf dem Sie waren; öffnen Sie sie, wenn dieser Bildschirm bereits geöffnet ist, bringt sie dieses Fenster nach vorn, statt ein zweites zu stapeln.

<Aside type="note">
Diese Links benennen den Bildschirm, nicht einen Datensatz darin. Ein Link zu Mitglieder öffnet die Mitgliederliste; er öffnet nicht das Formular eines einzelnen Mitglieds.
</Aside>

## Was passiert, wenn jemand einen Link öffnet

- **Das zugehörige Projekt wird ebenfalls geöffnet.** Ein Link zu einem Workflow, einer Tabelle, einem Schritt, einer Dimension oder einem Dateneditor öffnet auch das zugehörige Projekt als Registerkarte am unteren Bildschirmrand, sodass der Empfänger mit dem umgebenden Kontext ankommt statt mit einem einzelnen, frei schwebenden Fenster.
- **Ein Schrittlink wählt den Schritt aus.** Ein Link zu einem Schritt innerhalb eines Workflows öffnet den Workflow und hebt diesen Schritt hervor – auf der Arbeitsfläche des Visueller Workflow-Designer wird der Knoten des Schritts ausgewählt.
- **Eine Dimension wird bearbeitungsbereit geöffnet**, wenn das Projekt entsperrt ist, und schreibgeschützt, wenn es gesperrt ist – nach derselben Regel wie beim Öffnen aus dem Projekt.
- **Aktualisieren behält Ihre Position bei.** Das erneute Laden der Seite öffnet erneut, was der Link benennt, statt Sie zum Anfang zurückzuwerfen.

## Zwischen Bildschirmen wechseln

Die URL folgt dem, was Sie ansehen:

- Das Öffnen eines Bildschirms aktualisiert die Adressleiste, und die Schaltfläche **Zurück** Ihres Browsers bringt Sie zum vorherigen zurück.
- **Egal, wie Sie dorthin gelangt sind.** Das Öffnen eines Workflows aus dem Aktivitätsstrom, einer Karte auf der Startseite, einer Aktion **Zum Workflow wechseln**, einer Verwendungsliste oder dem Protokoll aktualisiert den Link genauso wie das Öffnen aus der Workflow-Liste des Projekts – ebenso das erneute Öffnen des Bildschirms, auf dem Sie sich bereits befinden.
- Das Auswählen der Registerkarte eines Fensters am unteren Bildschirmrand stellt den Link dieses Fensters wieder in der Adressleiste ein, sodass die URL beim Wechseln zwischen geöffneten Bildschirmen korrekt bleibt.
- Das Wechseln zu einer App, in der nichts Verlinkbares geöffnet ist, **leert** den Link, statt ihn auf die App zeigen zu lassen, die Sie gerade verlassen haben.
- Das Schließen eines Fensters stellt die URL auf den Ort zurück, von dem aus Sie es geöffnet haben. Schließen Sie eine Tabelle, die Sie von der Arbeitsfläche eines Workflows geöffnet haben, kehrt die URL zu dieser Arbeitsfläche zurück; schließen Sie eine aus einem Projekt geöffnete, kehrt sie zum Projekt zurück.
- Das Schließen des letzten Fensters eines Projekts leert den Link.

## Vor dieser Änderung gespeicherte Links

Links im älteren Stil `#te?p=…&t=…` funktionieren weiterhin. Das Öffnen eines solchen Links führt Sie an dieselbe Stelle und schreibt die Adressleiste stillschweigend in die aktuelle Form um, sodass Sie von dort den neueren, besser lesbaren Link erneut kopieren können.
