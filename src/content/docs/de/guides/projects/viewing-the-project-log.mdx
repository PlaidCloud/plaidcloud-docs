## Das Projektprotokoll anzeigen und sortieren

Wenn in einem Projekt Aktionen stattfinden, etwa das Zuweisen neuer Mitglieder oder das Ausführen von Workflows, speichert das Projektprotokoll die Ereignisse. Das Projektprotokoll fasst die Ansicht aller einzelnen Workflow-Protokolle zusammen, um einen umfassenderen Überblick über die Projektaktivitäten zu geben. PlaidCloud ermöglicht es außerdem, ein Projektprotokoll zu sortieren und zu filtern und die Details eines bestimmten Protokolleintrags anzuzeigen.


**So zeigen Sie das Projektprotokoll an:**
1. Öffnen Sie Analyze
2. Wählen Sie „Projekte“ aus
3. Klicken Sie auf das Protokollsymbol

**So sortieren und filtern Sie das Projektprotokoll:**
1. Klicken Sie auf das kleine Symbol rechts vom Protokoll und links von der „Protokollnachricht“
2. Wählen Sie die gewünschten Kriterien aus

**So zeigen Sie die Details eines bestimmten Protokolleintrags an:**
1. Klicken Sie mit der rechten Maustaste auf den gewünschten Protokolleintrag
2. Details finden Sie im Feld „Log Message“

## Das Projektprotokoll leeren

Es kann von Zeit zu Zeit wünschenswert sein, das Projektprotokoll zu leeren.

<Aside>Beim Leeren des Projektprotokolls werden auch alle Unterprotokolle jedes Workflows gelöscht</Aside>

**So leeren Sie das Projektprotokoll:**
1. Öffnen Sie Analyze
2. Wählen Sie „Projekte“ aus
3. Klicken Sie auf das Protokollsymbol
4. Klicken Sie auf die Schaltfläche „Clear Log“
