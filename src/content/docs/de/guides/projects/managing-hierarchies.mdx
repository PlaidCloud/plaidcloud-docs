PlaidCloud ermöglicht es, Hierarchien einschließlich Labels zu organisieren und zu verwalten. Hierarchien stehen allen Workflows innerhalb eines Projekts zur Verfügung.



PlaidCloud organisiert Hierarchien über ein pfadbasiertes System, wie Sie es von der Navigation durch eine Reihe von Ordnern kennen, was eine flexiblere und logischere Organisation (Steuerungshierarchie) der Hierarchien erlaubt. Mit diesem System lassen sich Hierarchien innerhalb einer Steuerungshierarchie verschieben, oder es lassen sich mehrere Verweise auf eine Hierarchie von verschiedenen Stellen der Steuerungshierarchie aus (alternative Hierarchien) anlegen. Die Verwaltung von Hierarchien auf diese Weise ermöglicht es, dass die Struktur den betrieblichen Anforderungen, dem Reporting und der Kontrolle entspricht.



## Suchen


So suchen Sie nach Hierarchien:


1. Verwenden Sie das Filterfeld unten links in der Steuerungshierarchie.
2. Der Suchfilter durchsucht Hierarchienamen und Labels nach Treffern und zeigt die Ergebnisse oben in der Steuerungshierarchie an.


## Verschieben


So verschieben Sie eine Hierarchie innerhalb der Steuerungshierarchie:


1. Ziehen Sie sie in den Ordner, in dem Sie sie ablegen möchten.


## Umbenennen


So benennen Sie eine Hierarchie um:


1. Klicken Sie mit der rechten Maustaste auf die Hierarchie.
2. Wählen Sie die Option zum Umbenennen.
3. Geben Sie den neuen Namen ein und speichern Sie ihn.
4. Die Hierarchie ist nun umbenannt, behält aber ihre ursprüngliche eindeutige Kennung.


## Leeren


Sie können eine einzelne Hierarchie oder mehrere Hierarchien leeren.


So leeren Sie eine Hierarchie:


1. Wählen Sie die Hierarchien in der Steuerungshierarchie aus.
2. Klicken Sie in der oberen Symbolleiste auf die Schaltfläche „Leeren“.


## Löschen


### Sie können eine einzelne Hierarchie oder mehrere Hierarchien löschen


So löschen Sie eine Hierarchie:


1. Wählen Sie die Hierarchien in der Steuerungshierarchie aus.
2. Klicken Sie in der oberen Symbolleiste auf die Schaltfläche „Löschen“.

Beim Löschen wird geprüft, ob die Hierarchie von Workflow-Schritten, Tabellen oder Ansichten verwendet wird. Ist das der Fall, werden Sie aufgefordert, diese Zuordnungen zu entfernen.

<Aside>Sie können die Hierarchie(n) auch erzwungen löschen. Das erzwungene Löschen von Hierarchien lässt Verweise unterbrochen zurück und sollte daher sparsam verwendet werden.</Aside>



## Neue Verzeichnisstruktur erstellen


So erstellen Sie einen neuen Ordner:


1. Klicken Sie in der Symbolleiste auf die Schaltfläche „Neuer Ordner“.

So fügen Sie einem vorhandenen Ordner einen Ordner hinzu:


1. Klicken Sie mit der rechten Maustaste auf den Ordner.
2. Wählen Sie „Neuer Ordner“.


## Hierarchie für Ansichtsrollen markieren


So zeigen Sie Hierarchien nach Rollen an:


1. Klicken Sie auf die Kontrollkästchen „Explorer“ oder „Manager“.

So zeigen Sie Hierarchien an, die aktualisiert werden müssen:


1. Wählen Sie die Hierarchien in der Steuerungshierarchie aus.
2. Wählen Sie im Menü „Aktionen“ der oberen Symbolleiste die gewünschte Ansichtsrolle.


## Memos zur Beschreibung des Tabelleninhalts


So fügen Sie einer Hierarchie ein Memo hinzu:


1. Wählen Sie die Hierarchie aus.
2. Aktualisieren Sie das Memo im Kontextformular rechts.


## Weitere Hierarchieattribute anzeigen


So zeigen und bearbeiten Sie weitere Hierarchieattribute:


1. Wählen Sie eine Hierarchie aus.
2. Sehen Sie sich das Hierarchie-Kontextformular rechts an.


## Eine Hierarchie duplizieren


So duplizieren Sie eine Hierarchie:



1. Wählen Sie die Hierarchie aus.


2. Klicken Sie in der oberen Symbolleiste auf die Schaltfläche „Duplizieren“.
