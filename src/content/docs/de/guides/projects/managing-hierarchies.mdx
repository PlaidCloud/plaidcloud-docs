PlaidCloud ermöglicht es, Hierarchien einschließlich ihrer Beschriftungen zu organisieren und zu verwalten. Hierarchien stehen allen Workflows innerhalb eines Projekts zur Verfügung.



PlaidCloud organisiert Hierarchien über ein pfadbasiertes System, ähnlich wie Sie durch eine Reihe von Ordnern navigieren. Das ermöglicht eine flexiblere und logischere Organisation (Steuerungshierarchie) der Hierarchien. In diesem System können Hierarchien innerhalb einer Steuerungshierarchie verschoben werden, oder es können mehrere Verweise auf eine Hierarchie von verschiedenen Stellen der Steuerungshierarchie aus angelegt werden (alternative Hierarchien). Mit dieser Art der Verwaltung kann die Struktur den betrieblichen Anforderungen, dem Reporting und der Steuerung entsprechen.



## Suchen


So suchen Sie nach Hierarchien:


1. Verwenden Sie **Filter** am unteren Rand der Liste neben der Zeilenanzahl (drücken Sie **/** oder Strg/Cmd+F, um direkt dorthin zu springen)
2. Der Suchfilter durchsucht die Namen und Beschriftungen der Hierarchien nach Treffern und zeigt die Ergebnisse in der Hierarchie an


## Verschieben


So verschieben Sie eine Hierarchie innerhalb der Steuerungshierarchie:


1. Ziehen Sie sie in den Ordner, in dem Sie sie ablegen möchten


## Umbenennen


So benennen Sie eine Hierarchie um:


1. Klicken Sie mit der rechten Maustaste auf die Hierarchie
2. Wählen Sie die Option zum Umbenennen
3. Geben Sie den neuen Namen ein und speichern Sie ihn
4. Die Hierarchie ist nun umbenannt, behält aber ihren ursprünglichen eindeutigen Bezeichner


## Leeren


Sie können eine einzelne Hierarchie oder mehrere Hierarchien leeren.


So leeren Sie eine Hierarchie:


1. Wählen Sie die Hierarchien in der Steuerungshierarchie aus
2. Klicken Sie in der oberen Symbolleiste auf die Schaltfläche „Leeren“


## Löschen


### Sie können eine einzelne Hierarchie oder mehrere Hierarchien löschen.


So löschen Sie eine Hierarchie:


1. Wählen Sie die Hierarchien in der Steuerungshierarchie aus
2. Klicken Sie in der oberen Symbolleiste auf die Schaltfläche „Löschen“

Beim Löschen wird geprüft, ob die Hierarchie von Workflow-Schritten, Tabellen oder Ansichten verwendet wird. Ist das der Fall, werden Sie aufgefordert, diese Zuordnungen zu entfernen.

<Aside>Sie können die Hierarchien auch erzwungen löschen. Beim erzwungenen Löschen bleiben Verweise defekt zurück, daher sollten Sie diese Option sparsam einsetzen.</Aside>



## Neue Verzeichnisstruktur erstellen


So erstellen Sie einen neuen Ordner:


1. Klicken Sie in der Symbolleiste auf die Schaltfläche „Neuer Ordner“

So fügen Sie einem vorhandenen Ordner einen Ordner hinzu:


1. Klicken Sie mit der rechten Maustaste auf den Ordner
2. Wählen Sie „Neuer Ordner“.

Wenn die Auswahl in einem Ordner liegt, enthält die Eingabeaufforderung für den Namen des neuen Ordners außerdem **Auf oberster Ebene erstellen**. Aktivieren Sie das Kontrollkästchen, um den neuen Ordner stattdessen auf der obersten Ebene des Projekts anzulegen.


## Hierarchie für Ansichtsrollen markieren


So zeigen Sie Hierarchien nach Rollen an:


1. Klicken Sie auf die Kontrollkästchen „Explorer“ oder „Manager“

So zeigen Sie Hierarchien an, die aktualisiert werden müssen:


1. Wählen Sie die Hierarchien in der Steuerungshierarchie aus
2. Wählen Sie im Menü „Aktionen“ der oberen Symbolleiste die gewünschte Ansichtsrolle aus


## Notizen zur Beschreibung des Tabelleninhalts


So fügen Sie einer Hierarchie eine Notiz hinzu:


1. Wählen Sie die Hierarchie aus
2. Aktualisieren Sie die Notiz im Kontextformular rechts


## Weitere Hierarchieattribute anzeigen


So zeigen und bearbeiten Sie weitere Hierarchieattribute an:


1. Wählen Sie eine Hierarchie aus
2. Sehen Sie sich das Kontextformular der Hierarchie rechts an


## Hierarchie duplizieren


So duplizieren Sie eine Hierarchie:



1. Wählen Sie die Hierarchie aus


2. Klicken Sie in der oberen Symbolleiste auf die Schaltfläche „Duplizieren“
