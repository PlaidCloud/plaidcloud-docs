## Beschreibung

**Bezeichnungen** sind frei wählbare Tags, die Sie den Objekten eines Projekts zuweisen: dem Projekt selbst, seinen Workflows, Schritten, Tabellen, Dimensionen, Dateneditoren und benutzerdefinierten Funktionen. Damit gruppieren Sie zusammengehörige Elemente nach dem, was für Sie wichtig ist (eine Arbeitsphase, ein Quellsystem, ein Verantwortlicher, ein Release), und finden diese Elemente später schnell wieder.

Bezeichnungen werden in Kleinbuchstaben gespeichert und überall dort, wo das Objekt erscheint, als kleine Chips angezeigt. Ein einheitlicher Satz von Bezeichnungen ist daher eine unkomplizierte Möglichkeit, ein großes Projekt zu gliedern.

## Wo Sie Bezeichnungen verwalten

Jedes mit Tags versehbare Objekt hat in seinem Detailpanel ein Feld **Bezeichnungen**:

- **Projektbezeichnungen**: auf der Projektstartseite
- **Workflow-Bezeichnungen**, **Schrittbezeichnungen**, **Tabellenbezeichnungen**, **Dimensionsbezeichnungen**, **Dateneditor-Bezeichnungen** und **UDF-Bezeichnungen**: im Detailpanel des jeweiligen Elements
- **Bezeichnungen**: auf der Registerkarte **Allgemein** des Formulars eines Workflow-Schritts

Das Feld listet die aktuellen Bezeichnungen des Objekts als Chips auf und bietet ein Eingabefeld zum Hinzufügen weiterer, mit einer Schaltfläche **Hinzufügen** daneben.

## Eine Bezeichnung hinzufügen

1. Klicken Sie an eine beliebige Stelle im Feld **Bezeichnungen**, um den Cursor im Eingabefeld zu platzieren.
2. Geben Sie den Text der Bezeichnung ein.
3. Klicken Sie auf **Hinzufügen** oder drücken Sie **Enter** (oder geben Sie ein Komma ein), um sie hinzuzufügen.

Die neue Bezeichnung erscheint als Chip, und das Eingabefeld wird geleert, sodass Sie eine weitere hinzufügen können. Die Chips umbrechen beim Hinzufügen von Bezeichnungen auf mehrere Zeilen, damit nichts verborgen bleibt.

<Aside type="note">
Bezeichnungen werden automatisch in Kleinbuchstaben umgewandelt. Wenn die eingegebene Bezeichnung bereits auf diesem Objekt vorhanden ist, teilt PlaidCloud Ihnen das mit und fügt kein Duplikat hinzu.
</Aside>

<Aside type="note">
Bei einem Workflow-Schritt, den Sie zum ersten Mal erstellen, werden eingegebene Bezeichnungen zurückgehalten, bis Sie den Schritt speichern, und ihm dann zugewiesen. Jedes andere Feld **Bezeichnungen** speichert jede Bezeichnung sofort beim Hinzufügen.
</Aside>

## Eine Bezeichnung entfernen

- Klicken Sie auf das **×** an einem Chip, um diese Bezeichnung zu entfernen, oder
- drücken Sie bei leerem Eingabefeld die **Rücktaste**, um den letzten Chip zu entfernen.

## Elemente nach Bezeichnung finden

Bezeichnungen erscheinen als Chips in der Spalte **Bezeichnungen** der Projektlisten, etwa Workflows, Schritte und Tabellen. Um eine Liste auf die Elemente mit einer bestimmten Bezeichnung einzugrenzen, geben Sie die Bezeichnung in das Filterfeld der Liste ein. Die Suche gleicht den Text der Bezeichnung zusammen mit dem Elementnamen ab. Bewegen Sie den Mauszeiger über einen Chip, der zu lang für seine Spalte ist, um die vollständige Bezeichnung anzuzeigen.
