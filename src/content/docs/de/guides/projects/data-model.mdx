Tabellen in einem Projekt verwenden oft dieselben Spaltennamen: `Period`, `Org`, `Account`. Ein **Projektelement** beschreibt einen solchen Namen einmal für das gesamte Projekt. Jede Tabelle mit einer Spalte dieses Namens zeigt dann dieselbe Beschreibung, Maske und Dimension, sodass Sie nicht auf Dutzenden von Tabellen dieselbe Notiz erneut eingeben müssen.

Die Seite **Datenmodell** in der [Project Home](/de/guides/projects/project-home/) listet die Elemente eines Projekts auf, zeigt, welche Tabellen jedes Element gemeinsam nutzen, und markiert, wo die Tabellen voneinander abweichen.

## Was ein Element enthält

| Einstellung | Funktion |
|---|---|
| **Name** | Der Spaltenname, den das Element beschreibt, genau so geschrieben wie in den Spalten. |
| **Beschreibung** | Was die Spalte enthält. Spalten ohne eigene Notiz zeigen diese Beschreibung. |
| **Typ** | Der Datentyp, den das Projekt für diese Spalte erwartet. Er wird geprüft, nicht angewendet. Siehe [Typkonflikte](#typkonflikte). |
| **Maske** | Eine numerische Maske. Spalten ohne eigene Maske verwenden diese. |
| **Dimension** | Eine Dimension, aus der die Werte der Spalte stammen. Spalten ohne eigene Dimension verwenden diese. |
| **Aliase** | Andere Spaltennamen mit derselben Bedeutung. |

## Wie eine Spalte ein Element erhält

Eine Spalte wird an ein Element gebunden, wenn ihre Spalten-ID mit dem Namen oder einem der Aliase des Elements übereinstimmt. Die Übereinstimmung ist exakt: `period` und `Period` sind verschiedene Namen. Fügen Sie also `period` als Alias von `Period` hinzu, wenn Sie beide möchten.

Fügen Sie ein Element hinzu oder löschen Sie es, und jede passende Spalte folgt.

## Was eine Spalte von ihrem Element übernimmt

Eine gebundene Spalte übernimmt **Beschreibung**, **Maske** und **Dimension** des Elements, wo ihr eigener Wert leer ist. Ein Wert, den Sie in der Spalte selbst festlegen, hat immer Vorrang. Das Element ändert nie, was in einer Tabelle gespeichert ist: Löschen Sie es, und jede Spalte kehrt genau zu dem zurück, was sie vorher hatte.

Der **Typ** wird nicht vom Element übernommen.

## Die Seite Datenmodell öffnen

Öffnen Sie das Projekt und wählen Sie in der Leiste der [Project Home](/de/guides/projects/project-home/) **Datenmodell**. Das Zähler-Badge der Leiste zeigt, wie viele Elemente das Projekt hat. Sie können die Seite auch von einer Spalte aus öffnen:

- Aktivieren Sie im Tabellen-Explorer **Spalteneigenschaften** und wählen Sie eine Spalte aus. Die Zeile **Element** zeigt das Element der Spalte oder, wenn sie keines hat und Sie das Projekt bearbeiten können, **Zu einem Element machen**. Klicken Sie darauf, um die Seite Datenmodell für dieses Element zu öffnen, oder für ein neues Element, das mit Beschreibung, Maske und Dimension der Spalte beginnt.
- In der Liste dessen, was eine Dimension verwendet, öffnet eine Zeile namens **Projektelement** die Seite Datenmodell.

Jeder, der das Projekt öffnen kann, sieht die Seite. Zum Erstellen, Ändern oder Löschen von Elementen benötigen Sie Schreibzugriff auf das Projekt, und das Projekt darf nicht gesperrt sein. Andernfalls zeigt die Seite „Sie können das Datenmodell hier einsehen, aber nicht ändern.“

## Ein Element erstellen

1. Klicken Sie auf der Seite **Datenmodell** auf **Neues Element**.
2. Geben Sie einen **Namen** ein. Füllen Sie nach Bedarf **Beschreibung**, **Typ**, **Maske** und **Dimension** aus. Lassen Sie **Typ** auf **Beliebiger Typ**, um jeden Typ zu akzeptieren.
3. Geben Sie unter **Aliase** weitere Spaltennamen mit derselben Bedeutung ein, einen pro Zeile.
4. Klicken Sie auf **Speichern**.

Ein Element kann keinen Namen oder Alias erhalten, den bereits ein anderes Element hat. Um ein Element zu ändern, klicken Sie auf den Stift (**Element bearbeiten**) daneben. Wenn Sie es umbenennen, bleibt der alte Name als Alias erhalten, sodass seine Spalten das Element behalten.

Zum Entfernen öffnen Sie das Element, klicken auf **Löschen** und bestätigen mit **Element löschen**. Die Bestätigung nennt, wie viele Tabellen daran gebunden sind. An diesen Tabellen ändert sich nichts, was in ihnen gespeichert ist.

### Vorgeschlagene Elemente

Unter **Vorgeschlagen** listet die Seite Spaltennamen auf, die sich als Elemente lohnen:

- Ein Name, der noch kein Element oder Alias ist und in zwei oder mehr Tabellen vorkommt, wobei der Typ der Spalte ein Join-Schlüssel sein kann (ein unbekannter Typ zählt mit), angezeigt als „*name* ist in *n* Tabellen“. Klicken Sie auf **Element erstellen**, um ihn zu erstellen.
- Ein Name, der mit dem Namen oder einem Alias eines Elements übereinstimmt, wenn Groß- und Kleinschreibung sowie Unterstriche ignoriert werden, auch wenn er nur in einer Tabelle vorkommt, angezeigt als „*name* sieht aus wie *element* (*n* Tabellen)“. Klicken Sie auf **Alias hinzufügen**, um seine Spalten an dieses Element zu binden.

## Das Datenmodell lesen

Mit dem Umschalter **Graph** und **Matrix** über der Arbeitsfläche sehen Sie dieselben Tabellen und Elemente auf zwei Arten.

- **Graph.** Jedes Element ist ein Knotenpunkt, und jede Tabelle ist eine Karte, die mit den Elementen verbunden ist, für die sie eine Spalte hat. Eine **1** an einer Linie kennzeichnet eine Spalte, die der einzige Schlüssel der Tabelle ist. Eine Tabelle mit einem zusammengesetzten Schlüssel aus mehreren Spalten wird nicht markiert. Die Seite öffnet sich mit einem Element und seinen Tabellen. Klicken Sie auf ein Element, um es in den Fokus zu nehmen, klicken Sie auf eine Tabelle, um sie in den Fokus zu nehmen, oder doppelklicken Sie auf eine Tabelle, um sie zu öffnen. Mit den Chips neben **Elemente ausblenden** blenden Sie Elemente, die Sie nicht in der Darstellung haben möchten, aus oder ein.
- **Matrix.** Eine Zeile pro Tabelle und eine Spalte pro Element. Mit **Nach Tabellennamen filtern** schränken Sie die Zeilen ein.

Über dem Graphen zoomen die Zoom-Schaltflächen neben der Zoomstufe die Ansicht hinein und heraus, **Einpassen** zeigt die gesamte Zeichnung, und **1:1** kehrt zu 100 % zurück. Das Mausrad zoomt, und Ziehen der Arbeitsfläche verschiebt die Ansicht. Eine Minimap in der Ecke der Arbeitsfläche zeigt die gesamte Zeichnung, wobei der sichtbare Ausschnitt umrandet ist; klicken oder ziehen Sie darin, um dorthin zu springen. Die Minimap-Schaltfläche blendet sie aus oder ein, und PlaidCloud merkt sich Ihre Wahl. Die Export-Schaltfläche lädt den Graphen als PDF herunter, und ihr Menü enthält **Als PDF exportieren** und **Als PNG exportieren**.

### Typkonflikte

Eine Tabelle, deren Spalte einen anderen Typ hat als die übrigen, wird unter dem Element markiert: „*column* ist in *table* *type*, was sich von den anderen Tabellen unterscheidet.“ Typen werden nach Familie verglichen, sodass eine Ganzzahl und eine Dezimalzahl keinen Konflikt bilden. Hat das Element einen **Typ**, werden die anderen mit dessen Familie verglichen. Andernfalls werden sie mit der Familie verglichen, die die meisten Spalten verwenden, und bei Gleichstand zweier Familien wird die alphabetisch erste verwendet. Ein Konflikt ist nur eine Warnung; er ändert nichts.

Eine Tabelle, die nicht gelesen werden kann, wird ausgelassen und stattdessen auf der Seite mitgezählt, ohne sie anzuhalten.

## Wo Sie Elemente sehen

Elemente erscheinen als Pill mit dem Namen des Elements:

- **Tabellen-Explorer.** Die Spaltenliste hat eine Spalte **Markierungen** mit der Pill, neben den Pills für **Dimension** und **Zeilenzugriff**. Bewegen Sie den Mauszeiger über die Pill, um das Element, seine Beschreibung und seine Dimension zu sehen.
- **Spalteneigenschaften.** Die Zeile **Element** öffnet das Element. Ist **Beschreibung**, **Maske** oder **Dimension** leer, zeigt das Feld „Von Element *name*: *value*“ als Hinweis. Der Hinweis wird nicht mit der Spalte gespeichert.
- **Registerkarte Data Mapping eines Schritts.** Quell- und Zielspalten, die zu einem Element gehören, zeigen nach dem Spaltennamen dessen Pill.

## Elemente über die REST-API und MCP verwenden

Die REST-API liest und ändert Elemente unter `/rest/v1/analyze/projects/{project_id}/elements`:

| Anfrage | Aktion |
|---|---|
| `GET` | Gibt `elements` zurück sowie `index`, der jeden gebundenen Spaltennamen dem Namen seines Elements zuordnet. |
| `PUT` | Erstellt oder ersetzt ein Element anhand von `name`, `memo`, `dtype`, `mask`, `dimension` und `aliases`. Fügen Sie `rename_from` hinzu, um eines umzubenennen. |
| `DELETE` mit `?name=` | Löscht das benannte Element. |
| `GET` `/graph` | Gibt zurück, was die Seite Datenmodell zeigt: jedes Element mit seiner Tabellenanzahl und seinen Typkonflikten, die gebundenen Spalten jeder Tabelle und die Vorschläge. |

Die Tabellenmetadaten geben die in jeder Spalte gespeicherten Werte zurück, nicht die Werte, die sie von einem Element übernimmt. Um herauszufinden, von welchem Element eine Spalte Werte übernimmt, schlagen Sie ihren Namen im `index` aus `GET` elements nach.

Ein über [MCP](/de/integrations/ai-coding-agents/getting-started/) verbundener Assistent verwendet `element_find`, `element_upsert` und `element_delete`. Seine Tabellenbeschreibungen zeigen die Notiz jeder Spalte, wobei der Wert des Elements eingesetzt ist, wo die Spalte keinen hat.
