PlaidCloud hat ein integriertes Hilfesystem, sodass Sie die App für Support nie verlassen müssen. Es gibt zwei Seiten:

- **[Hilfe erhalten](/de/guides/support/getting-help/)**: für alle. Fragen Sie den integrierten Assistenten, eröffnen Sie ein Supportticket, hängen Sie einen Screenshot an und folgen Sie der Unterhaltung, alles direkt in PlaidCloud.
- **[Die Support-Konsole](/de/guides/support/support-console/)**: für Support-Agenten (PlaidCloud-Mitarbeiter und Partner-Agenten). Bearbeiten Sie die Ticketwarteschlange, antworten Sie Kunden, hängen Sie Dateien an, übernehmen Sie Tickets, legen Sie die Priorität fest und eskalieren Sie an PlaidCloud.
- **[Support verwalten](/de/guides/support/managing-support/)**: für Organisationsadministratoren. Fügen Sie Personen zu Ihrer Organisation hinzu, weisen Sie sie als Support-Agenten zu und legen Sie fest, wie Ihr Team über neue Tickets benachrichtigt wird.

Welche Seiten für Sie relevant sind, hängt von Ihrer Rolle ab. Jeder Benutzer kann Hilfe erhalten; Agenten sehen zusätzlich die Konsole **Support**, Organisationsadministratoren zusätzlich **Support Agents**.
