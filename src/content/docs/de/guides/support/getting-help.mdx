## Beschreibung

Hilfe & Support ist in PlaidCloud integriert. Dort können Sie dem KI-Assistenten eine Frage stellen, ein Supportticket bei unserem Team eröffnen, Screenshots anhängen und die gesamte Unterhaltung an einem Ort verfolgen, wobei Sie entweder in der App oder direkt aus Ihrer E-Mail antworten.

## Hilfe & Support öffnen

1. Klicken Sie oben rechts auf Ihren Namen (oder Avatar)
2. Wählen Sie `Help & Support`

Das Fenster öffnet sich mit zwei Registerkarten: **Assistenten fragen** und **Meine Tickets**.

## Zuerst den Assistenten fragen

Die Registerkarte **Assistenten fragen** ist der schnellste Weg zu einer Antwort: Der Assistent kennt den Kontext Ihres Workspace und kann die Dokumentation durchsuchen.

1. Geben Sie Ihre Frage ein und drücken Sie die Eingabetaste
2. Lesen Sie die Antwort. Stellen Sie Folgefragen im selben Thread

Wenn der Assistent das Problem nicht lösen kann, können Sie die Unterhaltung an einen Menschen übergeben. Das Transkript wird dem Ticket beigefügt, sodass unser Team den vollständigen Kontext hat.

## Ein Supportticket eröffnen

1. Öffnen Sie Hilfe & Support und wechseln Sie zur Registerkarte **Meine Tickets**
2. Klicken Sie, um ein neues Ticket zu beginnen
3. Beschreiben Sie Ihre Frage oder Ihr Problem im Nachrichtenfeld
4. (Optional) Klicken Sie auf `Attach`, um einen Screenshot oder eine Datei hinzuzufügen. Siehe [Einen Screenshot anhängen](#einen-screenshot-anhängen) weiter unten
5. Klicken Sie auf `Send`

Ihr Ticket wird erstellt, und unser Team wird benachrichtigt. Sie erhalten außerdem eine E-Mail, die bestätigt, dass das Ticket eröffnet wurde.

<Aside type="note">
Sie können ein Ticket auch nur mit einem angehängten Screenshot absenden. Eine Nachricht ist nicht erforderlich, wenn Sie eine Datei angehängt haben.
</Aside>

## Einen Screenshot anhängen

Mit Screenshots lässt sich ein Problem deutlich leichter diagnostizieren. Sie können Dateien sowohl beim Eröffnen eines Tickets als auch beim Antworten anhängen.

1. Klicken Sie auf `Attach`
2. Wählen Sie eine oder mehrere Dateien aus (Bilder wie PNG/JPG oder Dokumente wie PDF, Nur-Text oder Protokolle)
3. Jede Datei erscheint als Chip. Klicken Sie vor dem Senden auf einen Chip, um ihn zu entfernen
4. Senden Sie die Nachricht

Grenzen: bis zu **10 Dateien** pro Nachricht, jeweils **10 MB**. Angehängte Bilder erscheinen direkt in der Unterhaltung, andere Dateien werden als Download-Link angezeigt.

## Der Unterhaltung folgen

Öffnen Sie ein Ticket aus der Liste **Meine Tickets**, um den gesamten Thread zu sehen. Wenn ein Support-Mitarbeiter antwortet:

- Erhalten Sie eine E-Mail-Benachrichtigung
- Erscheint die Antwort im Thread, wobei Bilder direkt angezeigt werden

## Antworten

Sie können auf zwei Wegen antworten:

- **In der App**: Öffnen Sie das Ticket, tippen Sie in das Antwortfeld, hängen Sie optional mit `Attach` eine Datei an und klicken Sie auf `Reply`.
- **Per E-Mail**: Antworten Sie einfach auf eine beliebige Support-E-Mail, die Sie erhalten. Ihre Antwort wird demselben Ticket hinzugefügt, und alle Dateien, die Sie an die E-Mail anhängen, werden mitgesendet.

## E-Mails zum Ticketstatus

Sie werden bei jedem Schritt per E-Mail informiert:

- Wenn Ihr Ticket **eröffnet** wurde
- Wenn ein Support-Mitarbeiter **antwortet**
- Wenn Ihr Ticket **gelöst** wurde
- Wenn ein gelöstes Ticket **wieder geöffnet** wird
