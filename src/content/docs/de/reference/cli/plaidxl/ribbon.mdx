Die Installation von PlaidXL fügt der Excel-Multifunktionsleiste eine Registerkarte **PlaidCloud** mit sechs Befehlsgruppen hinzu: **Verbinden**, **Einfügen**, **Aktualisieren**, **Drill**, **Schreiben** und **Teilen**. Die gebräuchlichsten sind auch im Kontextmenü **PlaidXL** und auf der Registerkarte **PlaidXL Cell** zu finden, und jeder Befehl mit einer Tastenkombination zeigt diese in seinem Tooltip an.

Kein Befehl ist jemals ausgegraut. Ein Befehl wirkt auf die der ausgewählten Zelle nächstgelegene PlaidXL-Formel, -Tabelle oder den nächstgelegenen Knoten, und wenn es nichts gibt, worauf er wirken kann, öffnet er stattdessen den Teil des Aufgabenbereichs, der weiterhilft.

Führen Sie einen Befehl aus, während Sie abgemeldet sind oder bevor die Arbeitsmappe mit einem Projekt verknüpft ist, öffnet PlaidXL den Aufgabenbereich und meldet **Sign in to run** den Befehl oder **Pick a project to run** ihn. Sobald Sie angemeldet sind, wird der Befehl in der Zelle ausgeführt, von der Sie ausgegangen sind. Haben Sie inzwischen zu einem anderen Blatt gewechselt oder ein anderes Projekt gewählt, wird er nicht ausgeführt, und PlaidXL teilt Ihnen das mit.

## Verbinden

| Befehl | Funktion |
|---|---|
| **Open PlaidXL** | Öffnet den PlaidXL-Aufgabenbereich. |
| **Konto** | Öffnet den Aufgabenbereich, um sich anzumelden oder Ihren Workspace und Ihr Projekt zu wählen. |
| **Shortcuts** | Listet die PlaidXL-Tastenkombinationen auf, damit Sie sie ändern können. Siehe [Tastenkombinationen](#tastenkombinationen). |
| **Help** | Öffnet diese Dokumentation. |

## Einfügen

| Befehl | Funktion |
|---|---|
| **Tabelle...** | Öffnet die Registerkarte **Tabellen**, um [eine Tabelle abzurufen](/de/reference/cli/plaidxl/retrieve/#eine-tabelle-abrufen). |
| **Dimension...** | Öffnet die Registerkarte **Dimensionen**, um eine Dimension abzurufen oder ihre Elemente auszuwählen. |
| **Formula...** | Öffnet die Registerkarte **Formulas**, um [eine PlaidXL-Formel zu erstellen](/de/reference/cli/plaidxl/functions/#eine-formel-über-den-aufgabenbereich-einfügen) für die ausgewählte Zelle. |
| **Pick member...** | Öffnet die Elementauswahl für die Dimension der ausgewählten Zelle. Siehe [Ein Element auswählen](/de/reference/cli/plaidxl/drill/#ein-element-auswählen). |
| **Metric...** | Öffnet eine durchsuchbare Liste der Kennzahlen Ihres Projekts mit ihren aktuellen Werten. Siehe [Eine Kennzahl einfügen](/de/reference/cli/plaidxl/functions/#eine-kennzahl-einfügen). |
| **Build report...** | Öffnet die Registerkarte **Bericht**, um einen Live-Bericht anzulegen. Siehe [Einen Bericht erstellen](/de/reference/cli/plaidxl/build-a-report/). |
| **Weave fragen...** | Öffnet die Registerkarte **Weave** mit der ausgewählten Zelle als Kontext. Siehe [Weave fragen in Excel](/de/reference/cli/plaidxl/weave/). |

## Aktualisieren

Das Menü **Aktualisieren** enthält vier Befehle:

| Befehl | Funktion |
|---|---|
| **Refresh this sheet** | Berechnet die PlaidXL-Formeln auf dem aktiven Blatt neu und ruft seine Tabellen erneut ab. |
| **Refresh selection** | Berechnet die PlaidXL-Formeln in der Auswahl neu und ruft jede Tabelle erneut ab, die die Auswahl berührt. Ist nichts von PlaidXL ausgewählt, aktualisiert es das Blatt. |
| **Refresh all tables** | Ruft jede Tabelle und Dimension in der Arbeitsmappe erneut ab, mit den Spalten und dem Filter, die Sie für jede gewählt haben. |
| **Recalculate PlaidXL formulas** | Berechnet jede PlaidXL-Formel in der Arbeitsmappe neu. |

Was Sie während einer Aktualisierung sehen, steht unter [Tabellen aktualisieren](/de/reference/cli/plaidxl/retrieve/#refresh-all-tables).

**Recalculate PlaidXL formulas** berechnet nur PlaidXL-Formeln neu, ohne eine vollständige Neuberechnung in Excel. Nach Abschluss listet es die neu berechneten Blätter auf und löscht den Rückgängig-Verlauf von Excel. PlaidXL behält die Spaltendetails einer Tabelle 30 Sekunden lang, sodass eine Spalte oder Dimension, die Sie in den letzten 30 Sekunden umbenannt haben, etwas länger brauchen kann, bis sie angezeigt wird.

## Drill

| Befehl | Funktion |
|---|---|
| **Drill down** | Ein Menü: **One level**, **To lowest level**, **All levels** und **Custom drill...** legen die Knoten unterhalb des ausgewählten Knotens an. |
| **Drill up** | Klappt den ausgewählten Knoten zurück zu seinem übergeordneten Knoten. |
| **Keep only** | Behält im Drilldown nur die ausgewählten Knoten. |
| **Remove only** | Entfernt die ausgewählten Knoten samt allem darunter aus dem Drilldown. |
| **Show detail rows** | Legt die Tabellenzeilen hinter dem ausgewählten Wert auf einem eigenen Blatt ab. |
| **Explain this number** | Zeigt, woher der ausgewählte Wert stammt. |

Wählen Sie für einen Drilldown eine einzelne Zelle aus: Die Drilldown-Befehle verwandeln sie in eine Live-Formel `PLAIDXL.DRILL`. Siehe [Drilldown, Elemente auswählen und Zahlen erklären](/de/reference/cli/plaidxl/drill/).

## Schreiben

| Befehl | Funktion |
|---|---|
| **Save sheet to PlaidCloud...** | Schreibt die in dieses Blatt abgerufenen Tabellen sofort nach PlaidCloud zurück. Siehe [Eine Tabelle nach PlaidCloud speichern](/de/reference/cli/plaidxl/retrieve/#eine-tabelle-nach-plaidcloud-speichern). |
| **Undo last write** | Macht den zuletzt nach PlaidCloud eingegebenen Wert oder das letzte Speichern rückgängig, das neueste zuerst. Siehe [Einen Schreibvorgang rückgängig machen](/de/reference/cli/plaidxl/write-values/#einen-schreibvorgang-rückgängig-machen). |

## Teilen

| Befehl | Funktion |
|---|---|
| **Convert to values** | Ein Menü: **Whole workbook** oder **This sheet** ersetzt PlaidXL-Formeln durch ihre aktuellen Werte und merkt sich die Formeln. **Values only (no restore)** ersetzt sie, ohne einen Weg zurück zu behalten. |
| **Restore PlaidXL formulas** | Setzt die Formeln wieder ein, die **Convert to values** ersetzt hat, in jedem Blatt der Arbeitsmappe. |

Verwenden Sie **Convert to values**, um einen Bericht an jemanden zu senden, der PlaidXL oder Zugriff auf das Projekt nicht hat – diese Person sähe sonst Fehler anstelle der PlaidXL-Formeln. Es wandelt jede Formel um, die eine PlaidXL-Funktion aufruft, auch eine innerhalb einer anderen Formel wie `IFERROR`, und lässt Ihre anderen Formeln unverändert. Es läuft sofort, ohne vorher nachzufragen, und teilt mit, wie viele Formeln es umgewandelt hat.

Die Formeln werden mit jedem Blatt aufbewahrt, sodass **Restore PlaidXL formulas** sie auch nach dem Umbenennen oder Verschieben eines Blatts noch findet. Dafür müssen Sie nicht angemeldet sein. Siehe [Eine reine Wertekopie weitergeben](/de/reference/cli/plaidxl/build-a-report/#eine-reine-wertekopie-weitergeben).

<Aside type="caution">
Wandeln Sie eine unter einem neuen Namen gespeicherte Kopie um und lassen Sie Ihren funktionierenden Bericht unverändert. **Values only (no restore)** kann nicht mit **Restore PlaidXL formulas** rückgängig gemacht werden.
</Aside>

## Das Kontextmenü

Klicken Sie mit der rechten Maustaste auf eine Zelle und wählen Sie **PlaidXL** für diese Befehle, die jeweils dem entsprechenden Schaltflächenbefehl der Multifunktionsleiste entsprechen:

- **Drill down one level**, **Drill down to lowest level**, **Drill down all levels**, **Custom drill...**, **Drill up**, **Keep only** und **Remove only**
- **Pick member...**
- **Explain this number** und **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...**, das die Registerkarte **Formulas** für die Zelle öffnet

## Die Registerkarte PlaidXL Cell

Enthält die ausgewählte Zelle eine PlaidXL-Formel, ist sie Teil der Ergebnisse einer PlaidXL-Formel oder liegt sie in einer abgerufenen Tabelle, zeigt Excel neben der Registerkarte **PlaidCloud** eine Registerkarte **PlaidXL Cell** an. Sie bündelt die Befehle für diese Zelle:

- **Drill** – **Drill down** (**One level**, **Lowest level**, **All levels**), **Drill up**, **Keep only** und **Entfernen**
- **Prüfen** – **Erklären**, **Detail rows** und **Weave fragen**
- **Daten** – **Pick member**, **Refresh selection** und **Save sheet**

Die Registerkarte wird wieder ausgeblendet, wenn Sie eine andere Zelle auswählen. Excel-Versionen, die kontextbezogene Registerkarten für Add-ins nicht unterstützen, zeigen sie nicht an; jeder Befehl befindet sich weiterhin auf der Registerkarte **PlaidCloud**.

## Tastenkombinationen

Jede Tastenkombination besteht unter Windows aus **Strg+Alt+Umschalt** und einer Taste, auf dem Mac aus **⌘⌥⇧** und derselben Taste:

| Taste | Befehl |
|---|---|
| **Nach unten** | Eine Ebene nach unten aufschlüsseln |
| **Nach oben** | Nach oben aufschlüsseln |
| **L** | Bis zur untersten Ebene aufschlüsseln |
| **8** | Alle Ebenen aufschlüsseln |
| **D** | Benutzerdefinierter Drilldown |
| **K** | Nur behalten |
| **X** | Nur entfernen |
| **M** | Element auswählen |
| **E** | Diese Zahl erklären |
| **T** | Detailzeilen anzeigen |
| **R** | Dieses Blatt aktualisieren |
| **F** | Auswahl aktualisieren |
| **A** | Alle Tabellen aktualisieren |
| **C** | PlaidXL-Formeln neu berechnen |
| **W** | Blatt in PlaidCloud speichern |
| **Z** | Letzten Schreibvorgang rückgängig machen |
| **P** | PlaidXL öffnen |
| **N** | Eine Formel einfügen |
| **B** | Bericht erstellen |
| **I** | Eine Kennzahl einfügen |
| **Q** | Weave fragen |

Um eine Kombination zu ändern, klicken Sie in der Gruppe **Verbinden** auf **Shortcuts** oder wählen Sie im Kontomenü des Aufgabenbereichs **Keyboard shortcuts**. Klicken Sie neben einem Befehl auf **Set key**, drücken Sie die neue Kombination und klicken Sie auf **Speichern**; **Zurücksetzen** stellt die ursprüngliche wieder her. Eine Kombination, die ein anderer Befehl bereits verwendet, wird markiert, und wenn Sie sie dennoch speichern, wird sie trotzdem wirksam. Einige Office-Versionen lassen Add-ins keine Tastenkombinationen ändern und zeigen die Liste ohne **Set key**.
