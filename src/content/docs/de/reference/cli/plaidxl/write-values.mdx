Ein [`PLAIDXL.CELL`](/de/reference/cli/plaidxl/functions/#cell)-Wert dient nicht nur zum Lesen. Geben Sie eine Zahl darüber ein, und PlaidXL schreibt sie in die dahinterliegende PlaidCloud-Tabelle, setzt die Formel wieder ein und berechnet das Blatt neu, sodass der Bericht die neue Zahl zeigt und alles, was sich daraus aggregiert. So geben Sie ein Budget, eine Prognose oder eine Anpassung direkt in einen Bericht ein.

## Einen Wert eingeben

1. Wählen Sie eine Zelle aus, die eine `PLAIDXL.CELL`-Formel enthält.
2. Geben Sie eine Zahl oder einen der [Codes](#verteilen-anpassen-und-formen) unten ein und drücken Sie **Enter**.

Der Wert wird sofort nach PlaidCloud geschrieben, und der Aufgabenbereich zeigt, was sich geändert hat – zum Beispiel `Jan·East·Revenue 80 → 100 · 14 rows` – mit einer Schaltfläche **Rückgängig**. Fügen Sie einen Wertebereich ein oder füllen Sie ihn aus, und die Werte werden gemeinsam geschrieben.

Eine Zelle nimmt einen eingegebenen Wert an, wenn sie eine einzelne `CELL`-Formel enthält oder ein `CELL`, das mit Zahlen, Zellen oder Namen multipliziert, dividiert oder negiert wird – zum Beispiel `=-PLAIDXL.CELL(...)*$B$1/1000`. PlaidXL rechnet den eingegebenen Wert auf das zurück, was das `CELL` enthalten soll, bevor es schreibt. Die Argumente des `CELL` müssen Zellen oder Text sein, damit PlaidXL erkennen kann, welcher Schnittpunkt geschrieben wird.

Alles andere bleibt so, wie Sie es eingegeben haben:

- Text, der weder eine Zahl noch ein Code ist, bleibt in der Zelle, und die Meldung weist darauf hin, dass nur Zahlen und Anpassungen geschrieben werden.
- Ein über eine andere Formel eingegebener Wert wird nicht geschrieben.
- Das Drücken von **Löschen** bei einem `CELL` setzt seine Formel wieder ein.
- Ein positiver Prozentsatz wie `10%` wird nicht geschrieben; geben Sie `+10%` ein, um den Wert um 10 % zu erhöhen, oder `0.1`, um ihn festzulegen.

### Wie sich die Tabelle ändert

- **Summe** – die Differenz zwischen altem und neuem Wert wird als neue Zeilen hinzugefügt. Sie kopieren die Zeilen, die bereits an diesem Schnittpunkt liegen, wobei jede einen Anteil im Verhältnis zu ihrer Größe übernimmt. An einem leeren Schnittpunkt fügt PlaidXL für jede Kombination von Blattelementen unter den Knoten der Zelle eine Zeile hinzu.
- **Mittelwert**, **Median**, **Min.** und **Max.** – jede Zeile am Schnittpunkt verschiebt sich um die Differenz.
- **Standardabweichung** und **Varianz** – die Zeilen am Schnittpunkt werden um ihren Mittelwert, der gleich bleibt, gestreut oder zusammengezogen.

Ein einzelner Schreibvorgang fügt höchstens 100.000 Zeilen hinzu.

## Verteilen, anpassen und formen

In einer **Summe**-Zelle können Sie einen Code eingeben, um festzulegen, wie der Wert auf die darunterliegenden Blattelemente verteilt wird. Buchstaben können groß oder klein geschrieben werden.

| Eingabe | Was passiert |
|---|---|
| `1200` | Setzt die Zelle auf 1.200, verteilt im Verhältnis zu dem, was jedes Blattelement derzeit enthält. |
| `P1200` | Dasselbe, ausgeschrieben: proportional. |
| `E1200` | Setzt die Zelle auf 1.200, gleichmäßig auf die Blattelemente verteilt. |
| `R1200` | Setzt jedes Blattelement auf 1.200, sodass die Zelle das 1.200-Fache der Elementanzahl zeigt. |
| `1200 like FY2025` | Setzt die Zelle auf 1.200, verteilt in derselben Form wie die Zelle für **FY2025**. |
| `+50` oder `-50%` | Passt den Wert um einen Betrag oder Prozentsatz nach oben oder unten an. |
| `-50` | Setzt die Zelle auf -50. Ein Minuszeichen allein legt einen negativen Wert fest; fügen Sie `%` hinzu, um anzupassen. |
| `H` | Sperrt die Zelle oder hebt die Sperre auf, wenn sie gesperrt ist. |

Zahlen verwenden die Dezimal- und Tausendertrennzeichen Ihres Excel. Bei `like` darf das Element nur zu einer der Dimensionen der Zelle gehören; gehört es zu zweien, verwenden Sie eine Zelle, die es bereits enthält. Eine Form, in der nichts steht, verteilt gleichmäßig.

### Einen Wert sperren

Geben Sie `H` über ein `CELL` ein, um es zu sperren. Eine gesperrte Zelle erhält einen gestrichelten Rahmen, und spätere Schreibvorgänge in andere Zellen derselben Tabelle und Kennzahl lassen sie unverändert: Der neue Wert eines übergeordneten Elements wird auf die Elemente verteilt, die nicht gesperrt sind. Geben Sie `H` erneut ein, um die Sperre aufzuheben. Sperren werden mit der Arbeitsmappe gespeichert. Sind alle Elemente unter einer Zelle gesperrt, wird ein Schreibvorgang darauf abgelehnt.

Codes, Formen und Sperren funktionieren nur bei **Summe**-Zellen.

## Einen Schreibvorgang rückgängig machen

**Strg+Z** in Excel macht einen Schreibvorgang nach PlaidCloud nicht rückgängig. Um einen rückgängig zu machen, klicken Sie in der Meldung auf **Rückgängig** oder in der Gruppe **Schreiben** der Multifunktionsleiste auf **Undo last write** (**Strg+Alt+Umschalt+Z**, auf dem Mac **⌘⌥⇧Z**).

**Undo last write** macht den neuesten aus dieser Arbeitsmappe ausgeführten Schreibvorgang rückgängig, sei es ein eingegebener Wert oder ein [Speichern](/de/reference/cli/plaidxl/retrieve/#eine-tabelle-nach-plaidcloud-speichern); klicken Sie erneut, um den davor rückgängig zu machen. Die Liste wird in der Arbeitsmappe aufbewahrt, bleibt also beim Schließen und erneuten Öffnen der Datei erhalten, und enthält die letzten 100 Schreibvorgänge.

- **Ein eingegebener Wert** wird rückgängig gemacht, indem seine Zeilen umgekehrt werden, und das Blatt wird neu berechnet. Ein Schreibvorgang kann nur einmal rückgängig gemacht werden. Nachdem sich die Spalten der Tabelle geändert haben, ist das nicht mehr möglich.
- **Ein Speichern** setzt die Tabelle auf den Wiederherstellungspunkt zurück, der davor angelegt wurde. Aktualisieren Sie das Blatt, um die wiederhergestellten Zeilen zu sehen.

## Andere schreiben gleichzeitig

Der letzte Schreibvorgang gewinnt. Hat jemand anderes einen Wert geändert, nachdem Sie zuletzt aktualisiert haben, wird Ihr Schreibvorgang dennoch ausgeführt, und die Meldung ergänzt zum Beispiel `was 80, not 75`: PlaidCloud enthielt 80, als Sie eingegeben haben, nicht die 75, die Ihr Blatt zeigte.

## Zeilenzugriff

Ist Ihr Zugriff auf eine Tabelle auf einige Zeilen beschränkt, schreiben Sie nur innerhalb dieser. Ein eingegebener Wert wird auf die Elemente verteilt, die Sie sehen können, und ein Rückgängigmachen, das Zeilen außerhalb Ihres Zugriffs ändern würde, wird abgelehnt.

<Aside>
Das Eingeben von Werten erfordert einen PlaidCloud-Workspace, der sie akzeptiert. Meldet PlaidXL, dass der Workspace in Excel eingegebene Werte noch nicht annimmt, bitten Sie Ihren Administrator, ihn zu aktualisieren.
</Aside>
