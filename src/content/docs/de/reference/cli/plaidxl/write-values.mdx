Ein [`PLAIDXL.CELL`](/de/reference/cli/plaidxl/functions/#cell)-Wert dient nicht nur zum Lesen. Geben Sie eine Zahl darüber ein, und PlaidXL schreibt sie in die dahinterliegende PlaidCloud-Tabelle, stellt die Formel wieder her und berechnet das Blatt neu, sodass der Bericht die neue Zahl und alles zeigt, was darauf aufbaut. So geben Sie ein Budget, eine Prognose oder eine Anpassung direkt in einen Bericht ein.

## Einen Wert eingeben

1. Wählen Sie eine Zelle aus, die eine `PLAIDXL.CELL`-Formel enthält.
2. Geben Sie eine Zahl oder einen der [Codes](#verteilen-anpassen-und-formen) unten ein und drücken Sie **Eingabe**.

Der Wert wird sofort nach PlaidCloud geschrieben, und der Aufgabenbereich zeigt, was sich geändert hat — zum Beispiel `Jan·East·Revenue 80 → 100 · 14 rows` — mit einer Schaltfläche **Rückgängig**. Fügen Sie einen Wertebereich ein oder füllen Sie ihn aus, werden die Werte gemeinsam geschrieben.

Eine Zelle nimmt einen eingegebenen Wert an, wenn sie eine einzelne `CELL`-Formel enthält oder eine `CELL`, die mit Zahlen, Zellen oder Namen multipliziert, dividiert oder negiert wird — zum Beispiel `=-PLAIDXL.CELL(...)*$B$1/1000`. PlaidXL rechnet den eingegebenen Wert auf das zurück, was die `CELL` enthalten soll, bevor es ihn schreibt. Die Argumente der `CELL` müssen Zellen oder Text sein, damit PlaidXL erkennen kann, welcher Schnittpunkt geschrieben werden soll.

Alles andere bleibt so, wie Sie es eingegeben haben:

- Text, der keine Zahl und kein Code ist, bleibt in der Zelle, und die Meldung besagt, dass nur Zahlen und Anpassungen geschrieben werden.
- Ein über einer anderen Formel eingegebener Wert wird nicht geschrieben.
- Drücken von **Entf** auf einer `CELL` stellt ihre Formel wieder her.
- Ein positiver Prozentsatz wie `10%` wird nicht geschrieben; geben Sie `+10%` ein, um den Wert um 10 % zu erhöhen, oder `0.1`, um ihn festzulegen.

Braucht PlaidCloud zu lange für die Antwort oder liefert für eine Zelle keine, besagt die Meldung, dass die Änderung möglicherweise angewendet wurde; prüfen Sie den Wert, bevor Sie erneut schreiben. Bei einer Zelle, die nicht gesendet werden konnte, heißt es, dass nichts geschrieben wurde.

Ein Wert, der unmittelbar vor dem Einfügen oder Löschen von Zeilen oder Spalten eingegeben wird, wird in die Zelle geschrieben, in die Excel ihn verschoben hat. Ein Wert, der in eine Zeile oder Spalte eingegeben wird, die anschließend gelöscht wird, wird nicht geschrieben, und die Meldung nennt, wie viele eingegebene Werte in gelöschten oder verschobenen Zellen lagen.

### Wie sich die Tabelle ändert

- **sum** — die Differenz zwischen altem und neuem Wert wird als neue Zeilen hinzugefügt. Sie kopieren die Zeilen, die bereits an diesem Schnittpunkt liegen, wobei jede einen Anteil proportional zu ihrer Größe übernimmt. An einem leeren Schnittpunkt fügt PlaidXL für jede Kombination von Blattmitgliedern unter den Knoten der Zelle eine Zeile hinzu.
- **mean**, **median**, **min** und **max** — jede Zeile am Schnittpunkt verschiebt sich um die Differenz.
- **std** und **var** — die Zeilen am Schnittpunkt werden um ihren Mittelwert, der gleich bleibt, gestreckt oder gestaucht.

Ein einzelner Schreibvorgang fügt höchstens 100.000 Zeilen hinzu.

## Verteilen, anpassen und formen

Bei einer **sum**-Zelle können Sie einen Code eingeben, der festlegt, wie der Wert auf die darunterliegenden Blattmitglieder verteilt wird. Buchstaben können groß oder klein geschrieben werden.

| Eingabe | Was passiert |
|---|---|
| `1200` | Setzt die Zelle auf 1.200, proportional zu dem verteilt, was jedes Blattmitglied derzeit enthält. |
| `P1200` | Dasselbe, ausgeschrieben: proportional. |
| `E1200` | Setzt die Zelle auf 1.200, gleichmäßig auf die Blattmitglieder verteilt. |
| `R1200` | Setzt jedes Blattmitglied auf 1.200, sodass die Zelle das 1.200-Fache der Mitgliederzahl zeigt. |
| `1200 like FY2025` | Setzt die Zelle auf 1.200, in der gleichen Form verteilt wie die Zelle für **FY2025**. |
| `+50` oder `-50%` | Passt den Wert um einen Betrag oder einen Prozentsatz nach oben oder unten an. |
| `-50` | Setzt die Zelle auf -50. Ein Minuszeichen allein setzt einen negativen Wert; fügen Sie `%` hinzu, um anzupassen. |
| `H` | Fixiert die Zelle oder gibt sie frei, wenn sie fixiert ist. |

Zahlen verwenden die Dezimal- und Tausendertrennzeichen Ihres Excel. Bei `like` darf das Mitglied nur zu einer der Dimensionen der Zelle gehören; gehört es zu zweien, verwenden Sie eine Zelle, die es bereits enthält. Eine Form ohne Inhalt verteilt gleichmäßig.

### Einen Wert fixieren

Geben Sie `H` über einer `CELL` ein, um sie zu fixieren. Eine fixierte Zelle erhält einen gestrichelten Rand, und spätere Schreibvorgänge in andere Zellen derselben Tabelle und desselben Maßes lassen sie unverändert: Der neue Wert eines übergeordneten Elements wird auf die Mitglieder verteilt, die nicht fixiert sind. Geben Sie erneut `H` ein, um sie freizugeben. Eine Fixierung setzt voraus, dass die Argumente der `CELL` Zellen oder Text sind; bei einer Zelle, deren Argument eine Formel ist, rät die Meldung, Zellen zu fixieren, deren Argumente Zellen oder Text sind. Fixierungen werden mit der Arbeitsmappe gespeichert. Sind alle Mitglieder unter einer Zelle fixiert, wird ein Schreibvorgang darauf abgelehnt.

Codes, Formen und Fixierungen funktionieren nur bei **sum**-Zellen.

## Schreibvorgang rückgängig machen

**Strg+Z** in Excel macht einen Schreibvorgang nach PlaidCloud nicht rückgängig. Um einen rückgängig zu machen, klicken Sie in der Meldung auf **Rückgängig** oder in der Gruppe **Schreiben** der Multifunktionsleiste auf **Undo last write** (**Strg+Alt+Umschalt+Z**, auf dem Mac **⌘⌥⇧Z**).

**Undo last write** macht den neuesten aus dieser Arbeitsmappe ausgeführten Schreibvorgang rückgängig, ob eingegebener Wert oder [Speichern](/de/reference/cli/plaidxl/retrieve/#tabelle-in-plaidcloud-speichern); klicken Sie erneut darauf, um den davor liegenden rückgängig zu machen. Die Liste wird in der Arbeitsmappe geführt, übersteht also das Schließen und erneute Öffnen der Datei, und enthält die letzten 100 Schreibvorgänge.

- **Ein eingegebener Wert** wird rückgängig gemacht, indem seine Änderung umgekehrt wird, und das Blatt wird neu berechnet. Ein Schreibvorgang kann einmal rückgängig gemacht werden. Nach einer Änderung der Spalten der Tabelle ist das nicht mehr möglich, ebenso wenig, wenn er unterbrochen wurde, bevor er abgeschlossen war; prüfen Sie dann stattdessen die Zellen, die er geändert hat. Wie die Änderung umgekehrt wird, hängt von der Zelle ab:
  - Ein **sum**-Wert oder ein in eine leere Zelle eingegebener **mean**-Wert wird umgekehrt, indem Zeilen hinzugefügt werden, die die von ihm hinzugefügten Zeilen aufheben; seither in die Zelle geschriebene Zeilen bleiben also erhalten. Eine leere **mean**-Zelle zeigt danach 0 an, nicht leer.
  - Ein in eine leere Zelle eingegebener **median**-, **min**-, **max**-, **std**- oder **var**-Wert wird umgekehrt, indem die Zelle wieder geleert wird; das wird abgelehnt, sobald seither jemand in diese Zelle geschrieben hat.
  - Ein über vorhandene Werte eingegebener **mean**-, **median**-, **min**- oder **max**-Wert verschiebt die Zeilen am Schnittpunkt um die Differenz zurück, einschließlich der seither dort geschriebenen Zeilen.
  - Ein über vorhandene Werte eingegebener **std**- oder **var**-Wert streckt die Zeilen wieder oder staucht sie wieder, einschließlich der seither dort geschriebenen Zeilen. Nach einer Änderung, die Werte gestaucht hat, können die zurückgesetzten Werte in der letzten Dezimalstelle leicht abweichen. Ein auf 0 gesetzter **std**- oder **var**-Wert oder einer, der eingegeben wurde, wo alle Werte gleich waren, stellt die Zeilen wieder her, die die Zelle zuvor hatte, und ersetzt alle seither dort geschriebenen.
- **Ein Speichern** versetzt die Tabelle auf den davor angelegten Wiederherstellungspunkt zurück. Aktualisieren Sie das Blatt, um die wiederhergestellten Zeilen zu sehen.

Nur die Person und der Workspace, die einen Schreibvorgang ausgeführt haben, können ihn rückgängig machen. Der Eintrag einer anderen Person bleibt in der Liste und lautet **This write was made by another user or workspace**. Ein bereits rückgängig gemachter Eintrag lautet **Already undone or no longer available**. Gehört nichts in der Arbeitsmappe Ihnen, lautet die Meldung **Nothing to undo: the writes in this workbook were made by other users or workspaces.** Braucht PlaidCloud zu lange für die Antwort auf ein Rückgängigmachen, besagt die Meldung, dass es möglicherweise angewendet wurde; versuchen Sie **Rückgängig** erneut.

## Gleichzeitiges Schreiben durch andere

Der letzte Schreibvorgang gewinnt. Hat jemand anderes einen Wert geändert, nachdem Sie zuletzt aktualisiert haben, wird Ihr Schreibvorgang dennoch ausgeführt, und die Meldung ergänzt zum Beispiel `was 80, not 75`: PlaidCloud enthielt 80, als Sie eingegeben haben, nicht die 75, die Ihr Blatt zeigte.

## Zeilenzugriff

Ist Ihr Zugriff auf eine Tabelle auf einige Zeilen beschränkt, schreiben Sie nur innerhalb dieser. Ein eingegebener Wert wird auf die Mitglieder verteilt, die Sie sehen können, und ein Rückgängigmachen, das Zeilen außerhalb Ihres Zugriffs ändern würde, wird abgelehnt.

<Aside>
Für die Eingabe von Werten ist ein PlaidCloud-Workspace erforderlich, der sie akzeptiert. Meldet PlaidXL, dass der Workspace in Excel eingegebene Werte noch nicht annimmt, bitten Sie Ihren Administrator, ihn zu aktualisieren.
</Aside>
