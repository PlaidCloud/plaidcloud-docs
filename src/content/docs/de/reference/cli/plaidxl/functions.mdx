PlaidXL fügt Excel Funktionen hinzu, die PlaidCloud-Daten direkt in Zellen lesen. Geben Sie `=PLAIDXL.` in eine Zelle ein, und die Autovervollständigung von Excel listet sie mit einer kurzen Beschreibung jedes Arguments auf.

| Gruppe | Funktionen | Verwendungszweck |
|---|---|---|
| Listen | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Sehen, worauf Sie aufbauen können |
| Tabellen | [`TABLE.GET_TABLE`](#get_table) | Eine ganze Tabelle in einen Bereich lesen |
| Hierarchien | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Die Knoten einer Dimension als Berichtszeilen auslegen |
| Werte | [`CELL`](#cell), [`CELLS`](#cells) | Einen aggregierten Wert für eine beliebige Kombination von Knoten berechnen |
| Bausteine | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Die Tabelle, Kennzahl, Aggregation, Knoten und Drill-Tiefe beschreiben, die `CELL`, `CELLS` und `DRILL` verwenden |

[Bericht mit benutzerdefinierten Funktionen erstellen](/de/reference/cli/plaidxl/build-a-report/) zeigt, wie diese zusammenwirken.

## So funktionieren die Funktionen

- **Zuerst anmelden.** Die Funktionen lesen mit Ihrer PlaidCloud-Anmeldung, daher müssen Sie sich im Aufgabenbereich [anmelden](/de/reference/cli/plaidxl/connect/), bevor Sie sie verwenden.
- **Sie lesen aus dem ausgewählten Projekt.** Jede Funktion liest aus dem im Aufgabenbereich ausgewählten Projekt. `GET_TABLE`, `TBL_LIST` und `DIM_LIST` akzeptieren zusätzlich eine optionale Projekt-ID, um ein anderes Projekt zu lesen, ohne die Auswahl zu ändern. Die Auswahl gilt für alle geöffneten Arbeitsmappen.
- **Ergebnisse breiten sich aus (Spill).** Eine Funktion, die eine Liste oder eine Tabelle zurückgibt, füllt die Zellen darunter (oder rechts daneben). Lassen Sie Platz für die Ergebnisse; wenn etwas im Weg ist, zeigt Excel den Fehler `#SPILL!` an.
- **Zum Übernehmen von Änderungen neu berechnen.** Eine PlaidXL-Formel ruft erneut ab, wenn sich eines ihrer Argumente ändert. Um neue Daten in PlaidCloud oder ein anderes im Aufgabenbereich ausgewähltes Projekt zu übernehmen, erzwingen Sie eine vollständige Neuberechnung — drücken Sie unter Windows **Strg+Alt+F9**. **Refresh All Tables** aktualisiert abgerufene Tabellen, nicht Formeln.
- **Exakte Namen verwenden.** Geben Sie die Namen von Tabellen, Spalten, Dimensionen und Knoten genau so ein, wie sie in PlaidCloud erscheinen.

Argumente in eckigen Klammern sind optional.

## Listen

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Listet die Namen der Projekte auf, die Sie öffnen können, nach Namen sortiert.

- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standardmäßig `FALSE`, also eine Spalte.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Listet die Namen der Tabellen in einem Projekt auf, nach Namen sortiert.

- `project_id` — das zu lesende Projekt. Standardmäßig das im Aufgabenbereich ausgewählte Projekt.
- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standardmäßig `FALSE`, also eine Spalte.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Listet die Spaltennamen einer Tabelle im ausgewählten Projekt auf.

- `table_name` — der Name der Tabelle in PlaidCloud.
- `column_filter` — ein Datentyp, etwa `"text"`, um nur die Spalten dieses Typs aufzulisten. Lassen Sie ihn weg, um jede Spalte aufzulisten.
- `orientation` — `"vertical"` (Standard) für eine Spalte oder `"horizontal"` für eine Zeile.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Listet die Namen der Dimensionen in einem Projekt auf.

- `project_id` — das zu lesende Projekt. Standardmäßig das im Aufgabenbereich ausgewählte Projekt.
- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standardmäßig `FALSE`, also eine Spalte.

## Tabellen

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Gibt die Zeilen einer Tabelle mit einer Kopfzeile zurück, ausgebreitet ab der Zelle der Formel. Leere Werte kommen als leere Zellen zurück.

- `table_name` — der Name der Tabelle in PlaidCloud.
- `project_id` — das zu lesende Projekt. Standardmäßig das im Aufgabenbereich ausgewählte Projekt.
- `limit` — die maximale Anzahl zurückgegebener Zeilen. Standardmäßig 1.048.575, die höchste Anzahl, die ein Arbeitsblatt unter einer Kopfzeile fasst.

`GET_TABLE` gibt jede Spalte zurück. Um Spalten auszuwählen oder Zeilen zu filtern, [rufen Sie die Tabelle stattdessen im Aufgabenbereich ab](/de/reference/cli/plaidxl/retrieve/#tabelle-abrufen).

## Hierarchien

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Legt die Knoten einer Dimension aus, beginnend bei `start_node` und abwärts durch dessen Nachfolger. Jede Generation wird um vier Leerzeichen weiter eingerückt als ihr übergeordneter Knoten, und mit Excel-Gliederungsgruppen können Sie jede Ebene ein- und ausklappen.

- `dimension_name` — der Name der Dimension oder ihr Pfad im Projekt.
- `start_node` — der Knoten, bei dem begonnen wird, etwa die Wurzel der Dimension.
- `hierarchy` — die [alternative Hierarchie](/de/guides/dimensions/dimensions/#alternative-attribut-hierarchien), der gefolgt wird. Standardmäßig `"main"`.
- `orientation` — `"vertical"` (Standard), um Knoten in einer Spalte aufzulisten, oder `"horizontal"`, um sie in einer Zeile aufzulisten.
- `generation_limit` — wie viele Generationen zurückgegeben werden, wobei `start_node` als erste zählt: `2` gibt den Startknoten und seine untergeordneten Knoten zurück. Lassen Sie es weg, um jede Generation zurückzugeben.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

Gibt `start_node` und die darunterliegenden Knoten zurück, die `drill_key` anfordert, in einer Spalte, nach Generation eingerückt und in einer Excel-Gliederung gruppiert.

- `dimension_name` — der Name der Dimension oder ihr Pfad im Projekt.
- `start_node` — der Knoten, von dem aus gedrillt wird.
- `drill_key` — wie weit gedrillt wird, aus [`DRILL_KEY`](#drill_key): jeder Nachfolger, nur die Blätter oder eine Anzahl von Ebenen.
- `hierarchy` — die alternative Hierarchie, der gefolgt wird. Standardmäßig `"main"`.

Beispielsweise listet `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` **Total** gefolgt von jeder darunterliegenden Blattregion auf.

Die [Drill-Befehle im Menüband](/de/reference/cli/plaidxl/ribbon/#drill-functions) leisten dasselbe für eine Dimension und einen Knoten, die Sie in zwei Zellen eingegeben haben, ohne dass Sie eine Formel schreiben müssen.

## Werte

`CELL` und `CELLS` berechnen eine Kennzahl — eine numerische Spalte einer Tabelle —, aggregiert auf die Knoten, die Sie in einer oder mehreren Dimensionen wählen. Stellen Sie sich jeden Aufruf als einen Schnittpunkt in einem Bericht vor: **Umsatz** für **EMEA** in **FY2026**.

Sie beschreiben den Schnittpunkt mit den unten aufgeführten Baustein-Funktionen, in der Regel in eigenen Zellen, und übergeben diese Zellen dann in beliebiger Reihenfolge an `CELL` oder `CELLS`:

| Argument | Erstellt mit | Erforderlich |
|---|---|---|
| Die zu lesende Tabelle | [`TABLE_REPR`](#table_repr) | Genau eine |
| Die zu aggregierende Spalte | [`MEASURE`](#measure) für `CELL`, [`MEASURES`](#measures) oder mehrere `MEASURE`-Zellen für `CELLS` | Ja |
| Wie aggregiert wird | [`MEASURE_TYPE`](#measure_type) | Nein — Standard ist `sum` |
| Ein Filter auf eine Spalte | [`DIMENSION_REPR`](#dimension_repr) | Mindestens einer, einer pro Spalte |

Jeder Filter nennt eine **Spalte der Tabelle** und einen Wert. Ist diese Spalte in PlaidCloud mit einer Dimension verknüpft, ist der Wert ein Knoten, und der Filter schließt alles ein, was in der Haupthierarchie der Dimension zu diesem Knoten aggregiert wird — bei einer **Region**-Spalte, die mit einer Geografie-Dimension verknüpft ist, deckt der Knoten **EMEA** jedes darunterliegende Land ab. Bei einer Spalte, die nicht mit einer Dimension verknüpft ist, entspricht der Filter exakt dem Wert.

Die Beispiele auf dieser Seite verwenden eine Tabelle, deren Spalten **Region** und **Period** mit Dimensionen verknüpft sind. Verwenden Sie die Spaltennamen Ihrer eigenen Tabelle.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Gibt eine Zahl zurück: die Kennzahl, aggregiert über die Zeilen, die unter jedem übergebenen Knoten liegen.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` zeigt den Gesamtumsatz für EMEA in FY2026.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Wie `CELL`, jedoch für mehrere Kennzahlen gleichzeitig. Gibt eine Zahl pro Kennzahl zurück, in einer Spalte, in der Reihenfolge, in der Sie sie aufgeführt haben.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` übergibt das gesamte ausgebreitete Ergebnis von `MEASURES`. `B2:B4` zeigen Umsatz, Kosten und Stückzahl für EMEA in FY2026.

## Bausteine

Diese Funktionen lesen selbst keine Daten. Jede gibt einen kurzen Text zurück, der einen Teil einer Berechnung beschreibt und bereit ist, an `CELL`, `CELLS` oder `DRILL` übergeben zu werden. Legen Sie sie in Zellen ab, auf die Sie verweisen, sodass eine einzige Änderung — etwa eine andere Periode — jede Formel aktualisiert, die sie verwendet.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

Die Tabelle, aus der `CELL` und `CELLS` lesen, über ihren Namen im ausgewählten Projekt.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

Die numerische Spalte, die `CELL` aggregiert.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Mehrere Kennzahlspalten für `CELLS`, aus einem Zellbereich, der Spaltennamen enthält. Das Ergebnis breitet sich mit einer Zelle pro Spalte aus; übergeben Sie es mit dem Spill-Operator an `CELLS`, etwa `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Wie die Kennzahl aggregiert wird. `agg_function` ist einer der folgenden Werte, in Kleinbuchstaben:

| Wert | Gibt zurück |
|---|---|
| `sum` | Die Summe (Standard, wenn Sie keinen Kennzahltyp übergeben) |
| `mean` | Den Durchschnitt |
| `median` | Den mittleren Wert |
| `min` | Den kleinsten Wert |
| `max` | Den größten Wert |
| `std` | Die Standardabweichung |
| `var` | Die Varianz |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

Ein Filter für `CELL` und `CELLS`. Übergeben Sie einen für jede Spalte, nach der Sie filtern möchten.

- `dimension_name` — der Name einer **Spalte in der Tabelle** — der Spalte, die die Werte der Dimension enthält, etwa `"Region"`. Er muss exakt mit dem Spaltennamen übereinstimmen; eine Spalte, die nicht in der Tabelle ist, liefert einen Fehler.
- `start_node` — der Knoten, auf den aggregiert wird, etwa `"EMEA"`. Bei einer Spalte, die nicht mit einer Dimension verknüpft ist, der zu vergleichende Wert.

Verweisen Sie für den Knoten auf eine Zelle, um ein Raster zu erstellen: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Führende und nachgestellte Leerzeichen werden ignoriert, sodass Sie auf die eingerückten Knotennamen verweisen können, die `DRILL` auslegt.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Wie weit [`DRILL`](#drill) unterhalb seines Startknotens geht. `d_key` ist einfacher Text:

| `d_key` | Drillt bis |
|---|---|
| `"all"` | Jeden Nachfolger |
| `"leaves"` | Nur die Blätter — Knoten, unter denen nichts mehr liegt |
| `"1 level"`, `"2 levels"`, … | So viele Generationen nach unten |

Schreiben Sie die Zahl als Ziffern: `"2 levels"`, nicht `"two levels"`. Ein vorangestelltes `drill` wird ignoriert, sodass auch `"drill 2 levels"` funktioniert.

Bei zwei oder mehr Ebenen listet `DRILL` jeweils eine Generation auf — zuerst alle untergeordneten Knoten, dann alle Enkelknoten — statt jeden Knoten direkt unter seinem übergeordneten Knoten. Für ein verschachteltes Layout verwenden Sie `"all"` oder [`GET_DIMENSION`](#get_dimension) mit einem `generation_limit`.

<Aside type="note">
`CELL`, `CELLS` und `DRILL` erwarten die Ausgabe dieser Baustein-Funktionen. Erstellen Sie jedes Argument mit der zugehörigen Funktion, statt den Text selbst einzugeben.
</Aside>
