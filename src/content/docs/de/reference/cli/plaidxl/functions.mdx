PlaidXL fügt Excel Funktionen hinzu, die PlaidCloud-Daten direkt in Zellen einlesen. Geben Sie `=PLAIDXL.` in eine Zelle ein, und die Autovervollständigung von Excel listet sie mit einer kurzen Beschreibung jedes Arguments auf. Auch die Registerkarte **Formulas** des Aufgabenbereichs kann eine Formel für Sie schreiben; siehe [Formel aus dem Aufgabenbereich einfügen](#formel-aus-dem-aufgabenbereich-einfügen).

| Gruppe | Funktionen | Verwendung |
|---|---|---|
| Listen | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Sehen, worauf Sie aufbauen können |
| Tabellen | [`TABLE.GET_TABLE`](#get_table) | Eine ganze Tabelle in einen Bereich einlesen |
| Hierarchien | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Die Knoten einer Dimension als Berichtszeilen darstellen |
| Werte | [`CELL`](#cell), [`CELLS`](#cells) | Einen aggregierten Wert für eine beliebige Kombination von Knoten berechnen |
| Kennzahlen | [`METRIC`](#metric), [`METRIC_BREAKDOWN`](#metric_breakdown) | Eine gesteuerte Geschäftskennzahl so lesen, wie Dashboards sie zeigen |
| Bausteine | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Die Tabelle, das Maß, die Aggregation, die Knoten und die Drill-Tiefe beschreiben, die `CELL`, `CELLS` und `DRILL` verwenden |

[Bericht erstellen](/de/reference/cli/plaidxl/build-a-report/) zeigt, wie diese Funktionen zusammenwirken.

## So funktionieren die Funktionen

- **Zuerst anmelden.** Die Funktionen lesen mit Ihrer PlaidCloud-Anmeldung und Ihren Berechtigungen. [Melden Sie sich](/de/reference/cli/plaidxl/connect/) daher im Aufgabenbereich an, bevor Sie sie verwenden.
- **Sie lesen aus dem Projekt der Arbeitsmappe.** Jede Funktion liest aus dem Projekt, das im Aufgabenbereich mit der Arbeitsmappe verknüpft ist. `GET_TABLE`, `TBL_LIST` und `DIM_LIST` akzeptieren zusätzlich eine optionale Projekt-ID, um ein anderes Projekt zu lesen, ohne die Verknüpfung zu ändern. Jede Arbeitsmappe hat ihr eigenes Projekt, sodass zwei geöffnete Arbeitsmappen aus unterschiedlichen Projekten lesen können.
- **Ergebnisse laufen über.** Eine Funktion, die eine Liste oder eine Tabelle zurückgibt, füllt die Zellen darunter (oder rechts daneben). Lassen Sie Platz für die Ergebnisse; steht etwas im Weg, zeigt Excel den Fehler `#SPILL!`.
- **Neu berechnen, um Änderungen zu übernehmen.** Eine PlaidXL-Formel ruft die Daten erneut ab, wenn sich eines ihrer Argumente ändert. Um neue Daten in PlaidCloud oder ein anderes im Aufgabenbereich verknüpftes Projekt zu übernehmen, verwenden Sie das Menü **Aktualisieren** der Multifunktionsleiste: **Recalculate PlaidXL formulas** berechnet alle PlaidXL-Formeln der Arbeitsmappe neu, **Refresh this sheet** und **Refresh selection** berechnen die jeweils erfassten Formeln neu. **Refresh all tables** aktualisiert abgerufene Tabellen, nicht Formeln. Siehe [Aktualisieren](/de/reference/cli/plaidxl/ribbon/#aktualisieren).
- **Exakte Namen verwenden.** Geben Sie Namen von Tabellen, Spalten, Dimensionen und Knoten genau so ein, wie sie in PlaidCloud erscheinen.

Argumente in eckigen Klammern sind optional.

## Listen

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Listet die Namen der Projekte auf, die Sie öffnen können, nach Namen sortiert.

- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, also eine Spalte.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Listet die Namen der Tabellen eines Projekts auf, nach Namen sortiert.

- `project_id` — das zu lesende Projekt. Standard ist das Projekt der Arbeitsmappe.
- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, also eine Spalte.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Listet die Spaltennamen einer Tabelle im ausgewählten Projekt auf.

- `table_name` — der Name der Tabelle in PlaidCloud.
- `column_filter` — ein Datentyp wie `"text"`, um nur die Spalten dieses Typs aufzulisten. Lassen Sie ihn weg, um alle Spalten aufzulisten.
- `orientation` — `"vertical"` (Standard) für eine Spalte oder `"horizontal"` für eine Zeile.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Listet die Namen der Dimensionen eines Projekts auf.

- `project_id` — das zu lesende Projekt. Standard ist das Projekt der Arbeitsmappe.
- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, also eine Spalte.

## Tabellen

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Gibt die Zeilen einer Tabelle mit einer Kopfzeile zurück, ausgehend von der Zelle der Formel überlaufend. Leere Werte kommen als leere Zellen zurück.

- `table_name` — der Name der Tabelle in PlaidCloud.
- `project_id` — das zu lesende Projekt. Standard ist das Projekt der Arbeitsmappe.
- `limit` — die maximale Anzahl zurückzugebender Zeilen. Standard ist 1.048.575, die größte Anzahl, die ein Arbeitsblatt unterhalb einer Kopfzeile aufnehmen kann.

`GET_TABLE` gibt alle Spalten zurück. Um Spalten auszuwählen oder Zeilen zu filtern, [rufen Sie die Tabelle stattdessen im Aufgabenbereich ab](/de/reference/cli/plaidxl/retrieve/#tabelle-abrufen).

## Hierarchien

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Stellt die Knoten einer Dimension dar, beginnend bei `start_node` und abwärts durch seine Nachfahren. Jede Generation wird um vier Leerzeichen weiter eingerückt als ihr übergeordneter Knoten, und mit Excel-Gliederungsgruppen können Sie jede Ebene ein- und ausklappen.

- `dimension_name` — der Name der Dimension oder ihr Pfad im Projekt.
- `start_node` — der Knoten, bei dem begonnen wird, etwa die Wurzel der Dimension.
- `hierarchy` — die [Alternativhierarchie](/de/guides/dimensions/dimensions/#alternative-attribut-hierarchien), der gefolgt wird. Standard ist `"main"`.
- `orientation` — `"vertical"` (Standard), um Knoten in einer Spalte aufzulisten, oder `"horizontal"`, um sie in einer Zeile aufzulisten.
- `generation_limit` — wie viele Generationen zurückgegeben werden, wobei `start_node` als erste zählt: `2` gibt den Startknoten und seine untergeordneten Knoten zurück. Lassen Sie ihn weg, um alle Generationen zurückzugeben.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy], [exclude], [expand], [orientation])`

Gibt `start_node` und die darunterliegenden Knoten zurück, die `drill_key` anfordert, nach Generation eingerückt und in einer Excel-Gliederung gruppiert.

- `dimension_name` — der Name der Dimension oder ihr Pfad im Projekt.
- `start_node` — der Knoten, von dem aus aufgegliedert wird. Lassen Sie ihn leer (`""`), um bei den obersten Knoten der Dimension zu beginnen. Die Dimension selbst zählt als Generation 0 des Drill-Schlüssels und wird nicht aufgelistet, die obersten Knoten sind also Generation 1: `>[1]` listet nur die obersten Knoten auf, `>[0]` listet nichts auf.
- `drill_key` — wie weit aufgegliedert wird, aus [`DRILL_KEY`](#drill_key): alle Nachfahren, nur die Blätter, eine Anzahl von Ebenen oder ein Bereich von Generationen.
- `hierarchy` — die Alternativhierarchie, der gefolgt wird. Standard ist `"main"`.
- `exclude` — Knoten, die samt allem darunter weggelassen werden: ein Knoten, eine Liste oder ein Zellbereich. Der Startknoten wird nie weggelassen.
- `expand` — Knoten, deren untergeordnete Knoten ebenfalls angezeigt werden, auch unterhalb der Tiefe, die `drill_key` anfordert: ein Knoten, eine Liste oder ein Zellbereich. Es werden nur Knoten geöffnet, die der Drill anzeigt. Um einen Enkelknoten zu öffnen, führen Sie daher auch seinen übergeordneten Knoten auf.
- `orientation` — `"vertical"` (Standard), um Knoten in einer Spalte aufzulisten, oder `"horizontal"`, um sie in einer Zeile ohne Einrückung und nach Spalten gruppiert aufzulisten. Jeder andere Wert ist ein Fehler.

`exclude` und `expand` nehmen Knoten-IDs als Text oder Zahlen entgegen; leere Zellen und Fehler in einem Bereich werden ignoriert. Lassen Sie ein Argument leer (`""`), um es zu überspringen, wie in `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`.

Zum Beispiel listet `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` den Knoten **Gesamt** gefolgt von jeder darunterliegenden Blattregion auf.

Die [Drill-Befehle](/de/reference/cli/plaidxl/drill/) schreiben und bearbeiten `DRILL`-Formeln für Sie: Wählen Sie einen Knoten aus und gliedern Sie nach unten oder oben auf, oder behalten oder entfernen Sie Knoten.

## Werte

`CELL` und `CELLS` berechnen ein Maß — eine numerische Spalte einer Tabelle —, aggregiert auf die von Ihnen gewählten Knoten in einer oder mehreren Dimensionen. Stellen Sie sich jeden Aufruf als einen Schnittpunkt in einem Bericht vor: **Umsatz** für **EMEA** in **FY2026**.

Sie beschreiben den Schnittpunkt mit den unten aufgeführten Baustein-Funktionen, meist in eigenen Zellen, und übergeben diese Zellen dann in beliebiger Reihenfolge an `CELL` oder `CELLS`:

| Argument | Erstellt mit | Erforderlich |
|---|---|---|
| Die zu lesende Tabelle | [`TABLE_REPR`](#table_repr) | Genau eine |
| Die zu aggregierende Spalte | [`MEASURE`](#measure) für `CELL`, [`MEASURES`](#measures) oder mehrere `MEASURE`-Zellen für `CELLS` | Ja |
| Wie aggregiert wird | [`MEASURE_TYPE`](#measure_type) | Nein — Standard ist `sum` |
| Ein Filter auf eine Spalte | [`DIMENSION_REPR`](#dimension_repr) | Mindestens einer, einer pro Spalte |

Jeder Filter nennt eine **Spalte der Tabelle** und einen Wert. Ist diese Spalte in PlaidCloud mit einer Dimension verknüpft, ist der Wert ein Knoten, und der Filter schließt alles ein, was in der Hauptdimension oder in der von Ihnen genannten Hierarchie zu diesem Knoten aggregiert wird — bei einer Spalte **Region**, die mit einer Geografie-Dimension verknüpft ist, umfasst der Knoten **EMEA** jedes darunterliegende Land. Bei einer Spalte, die nicht mit einer Dimension verknüpft ist, entspricht der Filter genau dem Wert.

Die Beispiele auf dieser Seite verwenden eine Tabelle, deren Spalten **Region** und **Period** mit Dimensionen verknüpft sind. Verwenden Sie die Spaltennamen Ihrer eigenen Tabelle.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Gibt eine einzelne Zahl zurück: das Maß, aggregiert über die Zeilen, die unter jedem übergebenen Knoten liegen.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` zeigt den Gesamtumsatz für EMEA in FY2026.

Geben Sie eine Zahl über eine `CELL`-Formel ein, um sie nach PlaidCloud zu schreiben. Siehe [Werte in PlaidCloud eingeben](/de/reference/cli/plaidxl/write-values/).

Ein Blatt voller `CELL`-Formeln wird schnell berechnet: Die `CELL`-Formeln, die zusammen berechnet werden, werden in einer einzigen Anfrage an PlaidCloud gesendet, bis zu 10.000 auf einmal, und PlaidXL verwendet die Spaltendetails einer Tabelle 30 Sekunden lang wieder, statt sie für jede Zelle abzurufen. Kann ein Wert nicht berechnet werden, zeigt die Zelle `#VALUE!`, und beim Daraufzeigen erscheint der von PlaidCloud gemeldete Grund, etwa eine Filterspalte, die nicht in der Tabelle vorhanden ist, oder ein Knoten ohne Mitglieder. `CELLS` zeigt den ersten Grund für das gesamte Ergebnis.

Wenn keine Zeilen übereinstimmen, ist eine `sum` gleich `0`. Jede andere Art der Aggregation (`mean`, `median`, `min`, `max`, `std` oder `var`) hat keinen Wert, den sie liefern kann: Eine `CELL` zeigt `#VALUE!`, und beim Daraufzeigen erscheint **No value for** mit der Aggregation, den Mitgliedern und dem Maß; ein `CELLS`-Element bleibt leer. Excel-Funktionen wie `AVERAGE` überspringen ein leeres `CELLS`-Element, und **Erklären** nennt denselben Grund.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Wie `CELL`, aber für mehrere Maße gleichzeitig. Gibt pro Maß eine Zahl zurück, untereinander in der Reihenfolge, in der Sie die Maße aufgeführt haben.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` übergibt das gesamte übergelaufene Ergebnis von `MEASURES`. `B2:B4` zeigen Umsatz, Kosten und Stückzahlen für EMEA in FY2026.

## Kennzahlen

`METRIC` und `METRIC_BREAKDOWN` lesen eine [Kennzahldefinition](/de/integrations/ai-coding-agents/metric-definitions/) aus dem Projekt der Arbeitsmappe: eine Geschäftszahl wie *Net Revenue*, deren Berechnung in PlaidCloud abgestimmt und festgehalten ist. Der Wert ist derselbe, den Dashboards anzeigen, berechnet mit Ihrem eigenen Zeilenzugriff. **Metric...** in der Multifunktionsleiste listet die Kennzahlen des Projekts mit ihren aktuellen Werten auf und schreibt die Formel für Sie; siehe [Kennzahl einfügen](#kennzahl-einfügen).

Filter sind [`DIMENSION_REPR`](#dimension_repr)-Werte wie bei `CELL`, mit dem Unterschied, dass das erste Argument eine Spalte benennt, nach der die Kennzahl aufgeschlüsselt werden kann. Ein Knoten schließt alles darunter ein. Übergeben Sie einen einzelnen Filter oder einen Bereich oder eine Liste von Filtern; leere Filter werden ignoriert. Eine Formel kann Filter aus mehr als einer Alternativhierarchie verwenden und ein Mitglied einer Alternativhierarchie mit Mitgliedern anderer Dimensionen kombinieren.

### METRIC

`=PLAIDXL.METRIC(name, [filter], ...)`

Gibt eine einzelne Zahl zurück: die Kennzahl für die Zeilen unter jedem übergebenen Filter.

- `name` — der Name der Kennzahl, eines ihrer Synonyme oder ihre ID. Groß- und Kleinschreibung spielen keine Rolle.
- `filter` — ein `DIMENSION_REPR`-Filter. Übergeben Sie so viele, wie Sie benötigen.

```text
=PLAIDXL.METRIC("Net Revenue", PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA"))
```

Wenn keine Zeilen übereinstimmen, gibt `METRIC` `0` zurück; hat die Kennzahl keinen Wert, bleibt die Zelle leer.

### METRIC_BREAKDOWN

`=PLAIDXL.METRIC_BREAKDOWN(name, breakdown, [filter], ...)`

Gibt die nach einer Spalte aufgeteilte Kennzahl zurück: zwei Spalten, jedes Mitglied von `breakdown` neben seinem Wert, der größte Wert zuerst, ohne Kopfzeile.

- `name` — der Name der Kennzahl, eines ihrer Synonyme oder ihre ID.
- `breakdown` — die Spalte, nach der die Kennzahl aufgeschlüsselt wird, eine Spalte, nach der die Kennzahl aufgeschlüsselt werden kann.
- `filter` — ein `DIMENSION_REPR`-Filter. Übergeben Sie so viele, wie Sie benötigen.

```text
=PLAIDXL.METRIC_BREAKDOWN("Net Revenue", "Region")
```

Mitglieder ohne Wert stehen am Ende, mit leerem Wert. Wenn keine Zeilen übereinstimmen, wird eine Zeile zurückgegeben: ein leeres Mitglied und `0`.

### Kennzahlfehler

Eine Kennzahl, die nicht berechnet werden kann, zeigt `#VALUE!`; zeigen Sie auf die Zelle, um den Grund zu sehen:

| Meldung | Was zu tun ist |
|---|---|
| Unbekannte Kennzahl oder unbekannte Spalte | Prüfen Sie den Namen. Gibt es ähnliche Treffer, listet die Meldung sie nach **Did you mean** auf. |
| Der Name passt zu mehr als einer Kennzahl | Verwenden Sie den vollständigen Namen der Kennzahl oder ihre ID. |
| **Your PlaidCloud role doesn't allow reading metrics in this project.** | Bitten Sie einen Projektinhaber um Zugriff. |
| **This PlaidCloud workspace doesn't serve metrics to Excel yet.** | Bitten Sie Ihren Administrator, den Workspace zu aktualisieren. |
| **PlaidCloud is busy; try again in** eine Anzahl von Sekunden | PlaidXL hat es bereits erneut versucht. Berechnen Sie nach der angegebenen Zeit neu. |
| **Choose a project in the PlaidXL pane first.** | Verknüpfen Sie die Arbeitsmappe mit einem Projekt. |
| **This PlaidCloud workspace can't combine an alternate hierarchy with other members yet. Ask your administrator to update the workspace.** | Bitten Sie Ihren Administrator, den Workspace zu aktualisieren. Andere Zellen in derselben Neuberechnung liefern weiterhin Ergebnisse. |

## Bausteine

Diese Funktionen lesen selbst keine Daten. Jede gibt einen kurzen Text zurück, der einen Teil einer Berechnung beschreibt und direkt an `CELL`, `CELLS` oder `DRILL` übergeben werden kann. Legen Sie sie in Zellen ab, auf die Sie verweisen, sodass eine einzige Änderung — etwa eine andere Periode — jede Formel aktualisiert, die sie verwendet.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

Die Tabelle, aus der `CELL` und `CELLS` lesen, anhand ihres Namens im ausgewählten Projekt.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

Die numerische Spalte, die `CELL` aggregiert.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Mehrere Maßspalten für `CELLS`, aus einem Zellbereich, der Spaltennamen enthält. Das Ergebnis läuft mit einer Zelle pro Spalte über; übergeben Sie es mit dem Überlaufoperator, etwa `D2#`, an `CELLS`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Wie das Maß aggregiert wird. `agg_function` ist einer dieser Werte, in Kleinbuchstaben:

| Wert | Gibt zurück |
|---|---|
| `sum` | Die Summe (Standard, wenn Sie keinen Maßtyp übergeben) |
| `mean` | Den Durchschnitt |
| `median` | Den mittleren Wert |
| `min` | Den kleinsten Wert |
| `max` | Den größten Wert |
| `std` | Die Standardabweichung |
| `var` | Die Varianz |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node, [hierarchy])`

Ein Filter für `CELL`, `CELLS`, `METRIC` und `METRIC_BREAKDOWN`. Übergeben Sie einen für jede Spalte, nach der Sie filtern möchten.

- `dimension_name` — der Name einer **Spalte in der Tabelle** — der Spalte, die die Werte der Dimension enthält, etwa `"Region"`. Er muss genau mit dem Spaltennamen übereinstimmen; eine Spalte, die nicht in der Tabelle vorhanden ist, liefert einen Fehler.
- `start_node` — der Knoten, auf den aggregiert wird, etwa `"EMEA"`. Bei einer Spalte, die nicht mit einer Dimension verknüpft ist, der zu vergleichende Wert.
- `hierarchy` — die Alternativhierarchie, über die der Knoten aggregiert wird. Standard ist `"main"`.

Verweisen Sie für den Knoten auf eine Zelle, um ein Raster aufzubauen: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Führende und nachgestellte Leerzeichen werden ignoriert, sodass Sie auf die eingerückten Knotennamen verweisen können, die `DRILL` darstellt.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Wie weit [`DRILL`](#drill) unterhalb seines Startknotens geht. `d_key` ist einfacher Text, entweder eine Wortform oder ein ausgeschriebener Drill-Schlüssel:

| `d_key` | Gliedert auf bis |
|---|---|
| `"all"` | Jeder Nachfahre |
| `"leaves"` | Nur die Blätter, also die Knoten, unter denen nichts liegt |
| `"1 level"`, `"2 levels"`, … | So viele Generationen nach unten |
| `">[...]"` | Der ausgeschriebene Drill-Schlüssel, wie in der nächsten Tabelle |

Schreiben Sie die Zahl als Ziffern: `"2 levels"`, nicht `"two levels"`. Ein vorangestelltes `drill` wird ignoriert, sodass auch `"drill 2 levels"` funktioniert.

Ein ausgeschriebener Schlüssel zählt Generationen ab dem Startknoten nach unten, der Generation 0 ist und immer enthalten ist. Negative Zahlen zählen von den Blättern jedes Zweigs aufwärts, sodass eine unregelmäßige Hierarchie so funktioniert, wie Sie es erwarten.

| Schlüssel | Enthält |
|---|---|
| `>[*]` oder `>[:]` | Jeden Knoten |
| `>[]` oder `>[-1]` | Nur die Blätter |
| `>[n]` | Den Startknoten und `n` Generationen darunter. `>[0]` ist allein der Startknoten. |
| `>[a:]` | Den Startknoten, dann Generation `a` und alles darunter |
| `>[a:b]` | Den Startknoten, dann die Generationen `a` bis `b - 1` |
| `>[0:-k]` | Den Startknoten und jeden Knoten, unter dem mindestens `k` Generationen liegen, sodass die letzten `k` Generationen jedes Zweigs weggelassen werden. `>[0:-1]` ist jeder Knoten außer den Blättern. |
| `>[a:-k]` | Dasselbe, beginnend bei Generation `a` |

Für die Hierarchie `A` mit den untergeordneten Knoten `B`, `C` und `D`, wobei `B` die Knoten `B1` und `B2` und `C` den Knoten `C1` hat:

| Schlüssel | Ergebnis |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Knoten werden in Hierarchiereihenfolge aufgelistet, jeder unter seinem eigenen übergeordneten Knoten, und die Excel-Gliederungsgruppen folgen derselben Reihenfolge. Leerzeichen innerhalb eines Schlüssels werden ignoriert. Ein Schlüssel, der keiner dieser Formen entspricht, liefert einen Fehler, der die gültigen Formen auflistet.

<Aside type="caution">
`>[-1]` und `>[0:-1]` bedeuten etwas anderes als in früheren Versionen von PlaidXL, in denen sie vertauscht waren. `>[-1]` gibt jetzt nur die Blätter zurück und `>[0:-1]` alles außer den Blättern. Prüfen Sie jede Arbeitsmappe, in der ein Drill-Schlüssel von Hand ausgeschrieben wurde. Die Wortformen `"all"`, `"leaves"` und `"2 levels"` sind unverändert.
</Aside>

<Aside type="note">
`CELL`, `CELLS` und `DRILL` erwarten die Ausgabe dieser Baustein-Funktionen. Erstellen Sie jedes Argument mit der zugehörigen Funktion, statt den Text selbst einzugeben.
</Aside>

## Formel aus dem Aufgabenbereich einfügen

Die Registerkarte **Formulas** des Aufgabenbereichs schreibt eine Formel für Sie. Öffnen Sie sie über den Aufgabenbereich, über **Formula...** in der Multifunktionsleiste oder über **Insert formula here...** im Kontextmenü **PlaidXL**. Wählen Sie unter **What do you want in the cell?** eine Option:

- **A whole table** (`GET_TABLE`) — wählen oder geben Sie die Tabelle ein und optional eine maximale Zeilenzahl.
- **One number** (`CELL`) — wählen oder geben Sie die Tabelle ein und legen Sie **Column to total** und **How to combine the values** fest.
- **A list of dimension nodes** (`DRILL`) — wählen oder geben Sie die Dimension und den Startknoten ein, legen Sie fest, wie weit aufgegliedert wird, und optional eine **Alternate hierarchy**, auszuschließende Knoten und zu öffnende Knoten. **Zeilen** zeigt eine Vorschau der Knoten, die der Drill auflistet. Siehe [Benutzerdefinierter Drill](/de/reference/cli/plaidxl/drill/#custom-drill).
- **A business metric** (`METRIC`) — siehe [Kennzahl einfügen](#kennzahl-einfügen).

Die Vorschau **Formula** zeigt das Ergebnis, während Sie die Felder ausfüllen. Klicken Sie auf **Insert in active cell** (oder drücken Sie **Strg+Eingabe**), um sie in die ausgewählte Zelle zu setzen, oder auf **Kopieren**, um sie selbst einzufügen. Wenn Sie auf der Registerkarte **Tables** eine Tabelle oder auf der Registerkarte **Dimensions** eine Dimension auswählen, wird das passende Feld ausgefüllt.

### Kennzahl einfügen

Klicken Sie in der Gruppe **Einfügen** der Multifunktionsleiste auf **Metric...** oder wählen Sie auf der Registerkarte **Formulas** die Option **A business metric**.

1. Geben Sie unter **Metric** einen Teil des Namens oder eines Synonyms einer Kennzahl ein, etwa `revenue`. Jeder Treffer zeigt seinen aktuellen Wert und seine Beschreibung.
2. Wählen Sie mit den Pfeiltasten oder per Klick eine Kennzahl aus.
3. Fügen Sie optional Filter hinzu: Wählen Sie eine **Dimension**, geben Sie einen **Knoten** ein und klicken Sie auf **Filter hinzufügen**.
4. Wählen Sie optional unter **Breakdown by (optional)** eine Spalte, um `METRIC_BREAKDOWN` statt einer einzelnen Zahl zu schreiben.
5. Klicken Sie auf **Insert in active cell** oder **Kopieren**.
