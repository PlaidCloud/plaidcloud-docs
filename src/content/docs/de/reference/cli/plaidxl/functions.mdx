PlaidXL fügt Excel Funktionen hinzu, die PlaidCloud-Daten direkt in Zellen einlesen. Geben Sie `=PLAIDXL.` in eine Zelle ein, und die AutoVervollständigen-Funktion von Excel listet sie mit einer kurzen Beschreibung jedes Arguments auf. Auch die Registerkarte **Formulas** des Aufgabenbereichs kann eine Formel für Sie schreiben; siehe [Formel aus dem Aufgabenbereich einfügen](#formel-aus-dem-aufgabenbereich-einfügen).

| Gruppe | Funktionen | Verwendungszweck |
|---|---|---|
| Listen | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | Sehen, worauf Sie aufbauen können |
| Tabellen | [`TABLE.GET_TABLE`](#get_table) | Eine ganze Tabelle in einen Bereich einlesen |
| Hierarchien | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | Die Knoten einer Dimension als Berichtszeilen anordnen |
| Werte | [`CELL`](#cell), [`CELLS`](#cells) | Einen aggregierten Wert für eine beliebige Kombination von Knoten berechnen |
| Kennzahlen | [`METRIC`](#metric), [`METRIC_BREAKDOWN`](#metric_breakdown) | Eine verwaltete Geschäftskennzahl lesen, so wie Dashboards sie anzeigen |
| Bausteine | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | Die Tabelle, die Kennzahl, die Aggregation, die Knoten und die Drill-Tiefe beschreiben, die `CELL`, `CELLS` und `DRILL` verwenden |

[Einen Bericht erstellen](/de/reference/cli/plaidxl/build-a-report/) zeigt, wie diese Funktionen zusammenarbeiten.

## So funktionieren die Funktionen

- **Zuerst anmelden.** Die Funktionen lesen mit Ihrer PlaidCloud-Anmeldung und Ihren Berechtigungen. [Melden Sie sich](/de/reference/cli/plaidxl/connect/) daher im Aufgabenbereich an, bevor Sie sie verwenden.
- **Sie lesen aus dem Projekt der Arbeitsmappe.** Jede Funktion liest aus dem Projekt, das im Aufgabenbereich mit der Arbeitsmappe verknüpft ist. `GET_TABLE`, `TBL_LIST` und `DIM_LIST` akzeptieren außerdem eine optionale Projekt-ID, um ein anderes Projekt zu lesen, ohne die Verknüpfung zu ändern. Jede Arbeitsmappe hat ihr eigenes Projekt, sodass zwei geöffnete Arbeitsmappen aus unterschiedlichen Projekten lesen können.
- **Ergebnisse werden übergelaufen.** Eine Funktion, die eine Liste oder eine Tabelle zurückgibt, füllt die Zellen darunter (oder rechts davon). Lassen Sie Platz für die Ergebnisse; ist etwas im Weg, zeigt Excel den Fehler `#SPILL!` an.
- **Neu berechnen, um Änderungen zu übernehmen.** Eine PlaidXL-Formel ruft die Daten erneut ab, wenn sich eines ihrer Argumente ändert. Um neue Daten in PlaidCloud oder ein anderes im Aufgabenbereich verknüpftes Projekt zu übernehmen, verwenden Sie das Menü **Aktualisieren** des Menübands: **Recalculate PlaidXL formulas** berechnet jede PlaidXL-Formel der Arbeitsmappe neu, und **Refresh this sheet** und **Refresh selection** berechnen die Formeln neu, die sie abdecken. **Refresh all tables** aktualisiert abgerufene Tabellen, nicht Formeln. Siehe [Aktualisieren](/de/reference/cli/plaidxl/ribbon/#aktualisieren).
- **Exakte Namen verwenden.** Geben Sie Namen von Tabellen, Spalten, Dimensionen und Knoten genau so ein, wie sie in PlaidCloud erscheinen.

Argumente in eckigen Klammern sind optional.

## Listen

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Listet die Namen der Projekte auf, die Sie öffnen können, nach Namen sortiert.

- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, also eine Spalte.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Listet die Namen der Tabellen eines Projekts auf, nach Namen sortiert.

- `project_id` — das Projekt, das gelesen werden soll. Standard ist das Projekt der Arbeitsmappe.
- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, also eine Spalte.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Listet die Spaltennamen einer Tabelle im ausgewählten Projekt auf.

- `table_name` — der Name der Tabelle in PlaidCloud.
- `column_filter` — ein Datentyp wie `"text"`, um nur die Spalten dieses Typs aufzulisten. Lassen Sie ihn weg, um alle Spalten aufzulisten.
- `orientation` — `"vertical"` (der Standard) für eine Spalte oder `"horizontal"` für eine Zeile.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Listet die Namen der Dimensionen eines Projekts auf.

- `project_id` — das Projekt, das gelesen werden soll. Standard ist das Projekt der Arbeitsmappe.
- `horizontal` — `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, also eine Spalte.

## Tabellen

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Gibt die Zeilen einer Tabelle mit einer Kopfzeile zurück, ausgehend von der Zelle der Formel übergelaufen. Leere Werte kommen als leere Zellen zurück.

- `table_name` — der Name der Tabelle in PlaidCloud.
- `project_id` — das Projekt, das gelesen werden soll. Standard ist das Projekt der Arbeitsmappe.
- `limit` — die maximale Anzahl zurückgegebener Zeilen. Standard ist 1.048.575, die größte Anzahl, die ein Arbeitsblatt unterhalb einer Kopfzeile aufnehmen kann.

`GET_TABLE` gibt jede Spalte zurück. Um Spalten auszuwählen oder Zeilen zu filtern, [rufen Sie die Tabelle stattdessen im Aufgabenbereich ab](/de/reference/cli/plaidxl/retrieve/#tabelle-abrufen).

## Hierarchien

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Ordnet die Knoten einer Dimension an, beginnend bei `start_node` und abwärts durch dessen Nachkommen. Jede Generation wird gegenüber ihrem übergeordneten Knoten um vier Leerzeichen weiter eingerückt, und mit Excel-Gliederungsgruppen können Sie jede Ebene zu- und aufklappen.

- `dimension_name` — der Name der Dimension oder ihr Pfad im Projekt.
- `start_node` — der Knoten, bei dem begonnen wird, etwa die Wurzel der Dimension.
- `hierarchy` — die [Alternativhierarchie](/de/guides/dimensions/dimensions/#alternative-attribut-hierarchien), der gefolgt wird. Standard ist `"main"`.
- `orientation` — `"vertical"` (der Standard), um Knoten in einer Spalte nach unten aufzulisten, oder `"horizontal"`, um sie in einer Zeile aufzulisten.
- `generation_limit` — wie viele Generationen zurückgegeben werden, wobei `start_node` als erste zählt: `2` gibt den Startknoten und seine untergeordneten Knoten zurück. Lassen Sie ihn weg, um jede Generation zurückzugeben.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy], [exclude], [expand], [orientation])`

Gibt `start_node` und die darunterliegenden Knoten zurück, die `drill_key` anfordert, nach Generation eingerückt und in einer Excel-Gliederung gruppiert.

- `dimension_name` — der Name der Dimension oder ihr Pfad im Projekt.
- `start_node` — der Knoten, von dem aus aufgeschlüsselt wird. Lassen Sie ihn leer (`""`), um bei den obersten Knoten der Dimension zu beginnen. Die Dimension selbst zählt als Generation 0 des Drill-Schlüssels und wird nicht aufgelistet, die obersten Knoten sind also Generation 1: `>[1]` listet nur die obersten Knoten auf, und `>[0]` listet nichts auf.
- `drill_key` — wie weit aufgeschlüsselt wird, aus [`DRILL_KEY`](#drill_key): jeder Nachkomme, nur die Blätter, eine Anzahl von Ebenen oder ein Bereich von Generationen.
- `hierarchy` — die Alternativhierarchie, der gefolgt wird. Standard ist `"main"`.
- `exclude` — Knoten, die samt allem, was darunter liegt, ausgelassen werden: ein Knoten, eine Liste oder ein Zellbereich. Der Startknoten wird nie ausgelassen.
- `expand` — Knoten, deren untergeordnete Knoten zusätzlich angezeigt werden, auch unterhalb der von `drill_key` angeforderten Tiefe: ein Knoten, eine Liste oder ein Zellbereich. Es werden nur Knoten geöffnet, die der Drill anzeigt. Um einen Enkelknoten zu öffnen, geben Sie daher auch dessen übergeordneten Knoten an.
- `orientation` — `"vertical"` (der Standard), um Knoten in einer Spalte nach unten aufzulisten, oder `"horizontal"`, um sie ohne Einrückung und nach Spalten gruppiert in einer Zeile aufzulisten. Jeder andere Wert ist ein Fehler.

`exclude` und `expand` akzeptieren Knoten-IDs als Text oder Zahlen; leere Zellen und Fehler in einem Bereich werden ignoriert. Lassen Sie ein Argument leer (`""`), um es zu überspringen, wie in `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`.

Beispielsweise listet `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` **Total** gefolgt von jeder darunterliegenden Blattregion auf.

Die [Drill-Befehle](/de/reference/cli/plaidxl/drill/) schreiben und bearbeiten `DRILL`-Formeln für Sie: Wählen Sie einen Knoten aus und schlüsseln Sie ihn auf oder zu, oder behalten oder entfernen Sie Knoten.

## Werte

`CELL` und `CELLS` berechnen eine Kennzahl — eine numerische Spalte einer Tabelle —, aggregiert auf die Knoten, die Sie in einer oder mehreren Dimensionen auswählen. Stellen Sie sich jeden Aufruf als einen Schnittpunkt in einem Bericht vor: **Umsatz** für **EMEA** in **FY2026**.

Sie beschreiben den Schnittpunkt mit den unten beschriebenen Baustein-Funktionen, meist in eigenen Zellen, und übergeben diese Zellen dann in beliebiger Reihenfolge an `CELL` oder `CELLS`:

| Argument | Erstellt mit | Erforderlich |
|---|---|---|
| Die zu lesende Tabelle | [`TABLE_REPR`](#table_repr) | Genau eine |
| Die zu aggregierende Spalte | [`MEASURE`](#measure) für `CELL`, [`MEASURES`](#measures) oder mehrere `MEASURE`-Zellen für `CELLS` | Ja |
| Wie sie aggregiert wird | [`MEASURE_TYPE`](#measure_type) | Nein — Standard ist `sum` |
| Ein Filter auf eine Spalte | [`DIMENSION_REPR`](#dimension_repr) | Mindestens einer, einer pro Spalte |

Jeder Filter benennt eine **Spalte der Tabelle** und einen Wert. Ist diese Spalte in PlaidCloud mit einer Dimension verknüpft, ist der Wert ein Knoten, und der Filter schließt alles ein, was in der Haupthierarchie der Dimension oder in der von Ihnen genannten Hierarchie zu diesem Knoten aggregiert wird — bei einer Spalte **Region**, die mit einer Geografie-Dimension verknüpft ist, deckt der Knoten **EMEA** jedes darunterliegende Land ab. Bei einer Spalte, die nicht mit einer Dimension verknüpft ist, stimmt der Filter exakt mit dem Wert überein.

Die Beispiele auf dieser Seite verwenden eine Tabelle, deren Spalten **Region** und **Period** mit Dimensionen verknüpft sind. Verwenden Sie die Spaltennamen Ihrer eigenen Tabelle.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Gibt eine Zahl zurück: die Kennzahl, aggregiert über die Zeilen, die unter jedem übergebenen Knoten liegen.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` zeigt den Gesamtumsatz für EMEA in FY2026.

Überschreiben Sie ein `CELL` mit einer Zahl, um sie nach PlaidCloud zu schreiben. Siehe [Werte in PlaidCloud eingeben](/de/reference/cli/plaidxl/write-values/).

Ein Blatt voller `CELL`-Formeln wird schnell berechnet: Die `CELL`-Formeln, die zusammen berechnet werden, werden in einer einzigen Anforderung an PlaidCloud gesendet, bis zu 10.000 auf einmal, und PlaidXL verwendet die Spaltendetails einer Tabelle 30 Sekunden lang wieder, statt sie für jede Zelle abzurufen. Kann ein Wert nicht berechnet werden, zeigt die Zelle `#VALUE!` an, und beim Daraufzeigen erscheint der Grund so, wie PlaidCloud ihn gemeldet hat, etwa eine Filterspalte, die nicht in der Tabelle vorhanden ist, oder ein Knoten ohne Mitglieder. `CELLS` zeigt den ersten Grund für das gesamte Ergebnis.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Wie `CELL`, aber für mehrere Kennzahlen auf einmal. Gibt eine Zahl pro Kennzahl zurück, in einer Spalte nach unten, in der Reihenfolge, in der Sie sie aufgeführt haben.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` übergibt das gesamte übergelaufene Ergebnis von `MEASURES`. `B2:B4` zeigen Umsatz, Kosten und Stückzahlen für EMEA in FY2026.

## Kennzahlen

`METRIC` und `METRIC_BREAKDOWN` lesen eine [Kennzahldefinition](/de/integrations/ai-coding-agents/metric-definitions/) aus dem Projekt der Arbeitsmappe: eine Geschäftszahl wie *Nettoumsatz*, deren Berechnung in PlaidCloud vereinbart und festgehalten ist. Der Wert ist derjenige, den Dashboards anzeigen, berechnet mit Ihrem eigenen Zeilenzugriff. **Metric...** im Menüband listet die Kennzahlen des Projekts mit ihren aktuellen Werten auf und schreibt die Formel für Sie; siehe [Kennzahl einfügen](#kennzahl-einfügen).

Filter sind [`DIMENSION_REPR`](#dimension_repr)-Werte wie bei `CELL`, mit dem Unterschied, dass das erste Argument eine Spalte benennt, nach der die Kennzahl aufgeschlüsselt werden kann. Ein Knoten schließt alles darunter ein. Übergeben Sie einen einzelnen Filter oder einen Bereich bzw. eine Liste davon; leere Filter werden ignoriert. Eine Formel kann eine Alternativhierarchie verwenden.

### METRIC

`=PLAIDXL.METRIC(name, [filter], ...)`

Gibt eine Zahl zurück: die Kennzahl für die Zeilen unter jedem übergebenen Filter.

- `name` — der Name der Kennzahl, eines ihrer Synonyme oder ihre ID. Groß- und Kleinschreibung spielt keine Rolle.
- `filter` — ein `DIMENSION_REPR`-Filter. Übergeben Sie so viele, wie Sie benötigen.

```text
=PLAIDXL.METRIC("Net Revenue", PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA"))
```

Stimmen keine Zeilen überein, gibt `METRIC` `0` zurück; hat die Kennzahl keinen Wert, ist die Zelle leer.

### METRIC_BREAKDOWN

`=PLAIDXL.METRIC_BREAKDOWN(name, breakdown, [filter], ...)`

Gibt die nach einer Spalte aufgeteilte Kennzahl zurück: zwei Spalten, jedes Mitglied von `breakdown` neben seinem Wert, der größte Wert zuerst, ohne Kopfzeile.

- `name` — der Name der Kennzahl, eines ihrer Synonyme oder ihre ID.
- `breakdown` — die Spalte, nach der die Kennzahl aufgeschlüsselt wird, eine, nach der die Kennzahl aufgeschlüsselt werden kann.
- `filter` — ein `DIMENSION_REPR`-Filter. Übergeben Sie so viele, wie Sie benötigen.

```text
=PLAIDXL.METRIC_BREAKDOWN("Net Revenue", "Region")
```

Mitglieder ohne Wert stehen zuletzt, mit leerem Wert. Stimmen keine Zeilen überein, wird eine Zeile zurückgegeben: ein leeres Mitglied und `0`.

### Kennzahlfehler

Eine Kennzahl, die nicht berechnet werden kann, zeigt `#VALUE!` an; zeigen Sie auf die Zelle, um den Grund zu sehen:

| Meldung | Was zu tun ist |
|---|---|
| Unbekannte Kennzahl oder unbekannte Spalte | Prüfen Sie den Namen. Gibt es ähnliche Treffer, listet die Meldung sie nach **Did you mean** auf. |
| Der Name stimmt mit mehr als einer Kennzahl überein | Verwenden Sie den vollständigen Namen der Kennzahl oder ihre ID. |
| **Your PlaidCloud role doesn't allow reading metrics in this project.** | Bitten Sie einen Projektinhaber um Zugriff. |
| **This PlaidCloud workspace doesn't serve metrics to Excel yet.** | Bitten Sie Ihren Administrator, den Workspace zu aktualisieren. |
| **PlaidCloud is busy; try again in** eine Anzahl von Sekunden | PlaidXL hat es bereits erneut versucht. Berechnen Sie nach der angegebenen Zeit neu. |
| **Choose a project in the PlaidXL pane first.** | Verknüpfen Sie die Arbeitsmappe mit einem Projekt. |

## Bausteine

Diese Funktionen lesen selbst keine Daten. Jede gibt einen kurzen Text zurück, der einen Teil einer Berechnung beschreibt und direkt an `CELL`, `CELLS` oder `DRILL` übergeben werden kann. Legen Sie sie in Zellen ab, auf die Sie verweisen, sodass eine einzige Änderung — etwa eine andere Periode — jede Formel aktualisiert, die sie verwendet.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

Die Tabelle, aus der `CELL` und `CELLS` lesen, über ihren Namen im ausgewählten Projekt.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

Die numerische Spalte, die `CELL` aggregiert.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Mehrere Kennzahlspalten für `CELLS`, aus einem Zellbereich mit Spaltennamen. Das Ergebnis läuft mit einer Zelle pro Spalte über; übergeben Sie es mit dem Überlaufoperator an `CELLS`, etwa `D2#`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Wie die Kennzahl aggregiert wird. `agg_function` ist einer dieser Werte, in Kleinbuchstaben:

| Wert | Gibt zurück |
|---|---|
| `sum` | Die Summe (der Standard, wenn Sie keinen Kennzahltyp übergeben) |
| `mean` | Den Durchschnitt |
| `median` | Den mittleren Wert |
| `min` | Den kleinsten Wert |
| `max` | Den größten Wert |
| `std` | Die Standardabweichung |
| `var` | Die Varianz |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node, [hierarchy])`

Ein Filter für `CELL`, `CELLS`, `METRIC` und `METRIC_BREAKDOWN`. Übergeben Sie einen für jede Spalte, nach der Sie filtern möchten.

- `dimension_name` — der Name einer **Spalte in der Tabelle** — der Spalte, die die Werte der Dimension enthält, etwa `"Region"`. Er muss exakt mit dem Spaltennamen übereinstimmen; eine Spalte, die nicht in der Tabelle vorhanden ist, gibt einen Fehler zurück.
- `start_node` — der Knoten, zu dem aggregiert wird, etwa `"EMEA"`. Bei einer Spalte, die nicht mit einer Dimension verknüpft ist, der Wert, mit dem abgeglichen wird.
- `hierarchy` — die Alternativhierarchie, über die der Knoten aggregiert wird. Standard ist `"main"`.

Verweisen Sie für den Knoten auf eine Zelle, um ein Raster aufzubauen: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Führende und nachgestellte Leerzeichen werden ignoriert, sodass Sie auf die eingerückten Knotennamen verweisen können, die `DRILL` anordnet.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Wie weit [`DRILL`](#drill) unterhalb seines Startknotens geht. `d_key` ist reiner Text, entweder eine Wortform oder ein ausgeschriebener Drill-Schlüssel:

| `d_key` | Schlüsselt auf bis |
|---|---|
| `"all"` | Jeder Nachkomme |
| `"leaves"` | Nur die Blätter, also die Knoten, unter denen nichts mehr liegt |
| `"1 level"`, `"2 levels"`, … | So viele Generationen abwärts |
| `">[...]"` | Der ausgeschriebene Drill-Schlüssel, wie in der nächsten Tabelle |

Schreiben Sie die Zahl als Ziffern: `"2 levels"`, nicht `"two levels"`. Ein vorangestelltes `drill` wird ignoriert, sodass auch `"drill 2 levels"` funktioniert.

Ein ausgeschriebener Schlüssel zählt Generationen abwärts vom Startknoten, der Generation 0 ist und immer enthalten ist. Negative Zahlen zählen aufwärts von den Blättern jedes Zweigs, sodass eine unregelmäßige Hierarchie so funktioniert, wie Sie es erwarten.

| Schlüssel | Enthält |
|---|---|
| `>[*]` oder `>[:]` | Jeden Knoten |
| `>[]` oder `>[-1]` | Nur die Blätter |
| `>[n]` | Den Startknoten und `n` Generationen darunter. `>[0]` ist der Startknoten allein. |
| `>[a:]` | Den Startknoten, dann Generation `a` und alles darunter |
| `>[a:b]` | Den Startknoten, dann die Generationen `a` bis `b - 1` |
| `>[0:-k]` | Den Startknoten und jeden Knoten, unter dem mindestens `k` Generationen liegen, sodass die letzten `k` Generationen jedes Zweigs weggelassen werden. `>[0:-1]` ist jeder Knoten außer den Blättern. |
| `>[a:-k]` | Dasselbe, beginnend bei Generation `a` |

Für die Hierarchie `A` mit den untergeordneten Knoten `B`, `C` und `D`, wobei `B` die Knoten `B1` und `B2` hat und `C` den Knoten `C1`:

| Schlüssel | Ergebnis |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Knoten werden in Hierarchiereihenfolge aufgelistet, jeder unter seinem eigenen übergeordneten Knoten, und die Excel-Gliederungsgruppen folgen derselben Reihenfolge. Leerzeichen innerhalb eines Schlüssels werden ignoriert. Ein Schlüssel, der keiner dieser Formen entspricht, gibt einen Fehler zurück, der die gültigen Formen auflistet.

<Aside type="caution">
`>[-1]` und `>[0:-1]` bedeuten etwas anderes als in früheren Versionen von PlaidXL, in denen sie vertauscht waren. `>[-1]` gibt jetzt nur die Blätter zurück und `>[0:-1]` alles außer den Blättern. Prüfen Sie jede Arbeitsmappe, in der ein Drill-Schlüssel von Hand ausgeschrieben wurde. Die Wortformen `"all"`, `"leaves"` und `"2 levels"` sind unverändert.
</Aside>

<Aside type="note">
`CELL`, `CELLS` und `DRILL` erwarten die Ausgabe dieser Baustein-Funktionen. Erstellen Sie jedes Argument mit seiner Funktion, statt den Text selbst einzugeben.
</Aside>

## Formel aus dem Aufgabenbereich einfügen

Die Registerkarte **Formulas** des Aufgabenbereichs schreibt eine Formel für Sie. Öffnen Sie sie im Aufgabenbereich, mit **Formula...** im Menüband oder mit **Insert formula here...** im Kontextmenü **PlaidXL**. Wählen Sie unter **What do you want in the cell?** eine Option:

- **A whole table** (`GET_TABLE`) — wählen oder geben Sie die Tabelle ein und optional eine maximale Zeilenanzahl.
- **One number** (`CELL`) — wählen oder geben Sie die Tabelle ein, wählen Sie die **Column to total** und **How to combine the values**.
- **A list of dimension nodes** (`DRILL`) — wählen oder geben Sie die Dimension und den Startknoten ein, wählen Sie, wie weit aufgeschlüsselt wird, und optional eine **Alternativhierarchie**, auszuschließende Knoten und zu öffnende Knoten. **Zeilen** zeigt eine Vorschau der Knoten, die der Drill auflistet. Siehe [Custom Drill](/de/reference/cli/plaidxl/drill/#custom-drill).
- **A business metric** (`METRIC`) — siehe [Kennzahl einfügen](#kennzahl-einfügen).

Die **Formula**-Vorschau zeigt das Ergebnis, während Sie die Felder ausfüllen. Klicken Sie auf **Insert in active cell** (oder drücken Sie **Strg+Enter**), um sie in die ausgewählte Zelle zu setzen, oder auf **Kopieren**, um sie selbst einzufügen. Wenn Sie auf der Registerkarte **Tabellen** eine Tabelle oder auf der Registerkarte **Dimensionen** eine Dimension auswählen, wird das passende Feld ausgefüllt.

### Kennzahl einfügen

Klicken Sie in der Gruppe **Einfügen** des Menübands auf **Metric...** oder wählen Sie auf der Registerkarte **Formulas** die Option **A business metric**.

1. Geben Sie unter **Metric** einen Teil des Namens oder eines Synonyms einer Kennzahl ein, etwa `revenue`. Jeder Treffer zeigt seinen aktuellen Wert und seine Beschreibung.
2. Wählen Sie mit den Pfeiltasten oder per Klick eine Kennzahl aus.
3. Fügen Sie optional Filter hinzu: Wählen Sie eine **Dimension**, geben Sie einen **Knoten** ein und klicken Sie auf **Filter hinzufügen**.
4. Wählen Sie optional unter **Breakdown by (optional)** eine Spalte aus, um `METRIC_BREAKDOWN` statt einer einzelnen Zahl zu schreiben.
5. Klicken Sie auf **Insert in active cell** oder **Kopieren**.
