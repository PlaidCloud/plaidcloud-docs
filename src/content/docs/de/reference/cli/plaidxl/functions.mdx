PlaidXL fügt Excel Funktionen hinzu, die PlaidCloud-Daten direkt in Zellen lesen. Geben Sie `=PLAIDXL.` in eine Zelle ein, und die Autovervollständigung von Excel listet sie mit einer kurzen Beschreibung jedes Arguments auf. Die Registerkarte **Formulas** des Aufgabenbereichs kann ebenfalls eine für Sie schreiben; siehe [Eine Formel über den Aufgabenbereich einfügen](#eine-formel-über-den-aufgabenbereich-einfügen).

| Gruppe | Funktionen | Verwenden Sie sie, um |
|---|---|---|
| Listen | [`LIST_PROJECTS`](#list_projects), [`TABLE.TBL_LIST`](#tbl_list), [`TABLE.GET_COLUMNS`](#get_columns), [`DIMENSION.DIM_LIST`](#dim_list) | zu sehen, worauf Sie aufbauen können |
| Tabellen | [`TABLE.GET_TABLE`](#get_table) | eine ganze Tabelle in einen Bereich zu lesen |
| Hierarchien | [`DIMENSION.GET_DIMENSION`](#get_dimension), [`DRILL`](#drill) | die Knoten einer Dimension als Berichtszeilen anzulegen |
| Werte | [`CELL`](#cell), [`CELLS`](#cells) | einen aggregierten Wert für eine beliebige Kombination von Knoten zu berechnen |
| Bausteine | [`REPR.TABLE_REPR`](#table_repr), [`REPR.MEASURE`](#measure), [`REPR.MEASURES`](#measures), [`REPR.MEASURE_TYPE`](#measure_type), [`REPR.DIMENSION_REPR`](#dimension_repr), [`REPR.DRILL_KEY`](#drill_key) | die Tabelle, die Kennzahl, die Aggregation, die Knoten und die Drill-Tiefe zu beschreiben, die `CELL`, `CELLS` und `DRILL` verwenden |

[Einen Bericht mit benutzerdefinierten Funktionen erstellen](/de/reference/cli/plaidxl/build-a-report/) zeigt, wie diese zusammenarbeiten.

## So funktionieren die Funktionen

- **Melden Sie sich zuerst an.** Die Funktionen lesen mit Ihrer PlaidCloud-Anmeldung, daher müssen Sie sich im Aufgabenbereich [anmelden](/de/reference/cli/plaidxl/connect/), bevor Sie sie verwenden.
- **Sie lesen aus dem Projekt der Arbeitsmappe.** Jede Funktion liest aus dem Projekt, das im Aufgabenbereich mit der Arbeitsmappe verknüpft ist. `GET_TABLE`, `TBL_LIST` und `DIM_LIST` nehmen außerdem eine optionale Projekt-ID entgegen, um ein anderes Projekt zu lesen, ohne die Verknüpfung zu ändern. Jede Arbeitsmappe hat ihr eigenes Projekt, sodass zwei geöffnete Arbeitsmappen aus unterschiedlichen Projekten lesen können.
- **Ergebnisse laufen über.** Eine Funktion, die eine Liste oder eine Tabelle zurückgibt, füllt die Zellen darunter (oder rechts davon). Lassen Sie Platz für die Ergebnisse; steht etwas im Weg, zeigt Excel einen Fehler `#SPILL!` an.
- **Neu berechnen, um Änderungen zu übernehmen.** Eine PlaidXL-Formel ruft erneut ab, wenn sich eines ihrer Argumente ändert. Um neue Daten in PlaidCloud oder ein anderes im Aufgabenbereich verknüpftes Projekt zu übernehmen, erzwingen Sie eine vollständige Neuberechnung – drücken Sie unter Windows **Ctrl+Alt+F9**. **Refresh All Tables** aktualisiert abgerufene Tabellen, nicht Formeln.
- **Verwenden Sie exakte Namen.** Geben Sie Tabellen-, Spalten-, Dimensions- und Knotennamen genau so ein, wie sie in PlaidCloud erscheinen.

Argumente in eckigen Klammern sind optional.

## Listen

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

Listet die Namen der Projekte auf, die Sie öffnen können, nach Namen sortiert.

- `horizontal` – `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, eine Spalte.

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

Listet die Namen der Tabellen in einem Projekt auf, nach Namen sortiert.

- `project_id` – das Projekt, das gelesen werden soll. Standard ist das Projekt der Arbeitsmappe.
- `horizontal` – `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, eine Spalte.

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

Listet die Spaltennamen einer Tabelle im ausgewählten Projekt auf.

- `table_name` – der Name der Tabelle in PlaidCloud.
- `column_filter` – ein Datentyp, etwa `"text"`, um nur die Spalten dieses Typs aufzulisten. Lassen Sie ihn weg, um jede Spalte aufzulisten.
- `orientation` – `"vertical"` (der Standard) für eine Spalte oder `"horizontal"` für eine Zeile.

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

Listet die Namen der Dimensionen in einem Projekt auf.

- `project_id` – das Projekt, das gelesen werden soll. Standard ist das Projekt der Arbeitsmappe.
- `horizontal` – `TRUE`, um in einer Zeile aufzulisten. Standard ist `FALSE`, eine Spalte.

## Tabellen

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

Gibt die Zeilen einer Tabelle mit einer Kopfzeile zurück, ausgehend von der Zelle der Formel überlaufend. Leere Werte kommen als leere Zellen zurück.

- `table_name` – der Name der Tabelle in PlaidCloud.
- `project_id` – das Projekt, das gelesen werden soll. Standard ist das Projekt der Arbeitsmappe.
- `limit` – die maximale Zeilenanzahl, die zurückgegeben wird. Standard ist 1.048.575, die größte Anzahl, die ein Arbeitsblatt unterhalb einer Kopfzeile fasst.

`GET_TABLE` gibt jede Spalte zurück. Um Spalten auszuwählen oder Zeilen zu filtern, [rufen Sie die Tabelle stattdessen über den Aufgabenbereich ab](/de/reference/cli/plaidxl/retrieve/#eine-tabelle-abrufen).

## Hierarchien

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

Legt die Knoten einer Dimension an, beginnend bei `start_node` und über seine Nachkommen nach unten. Jede Generation ist vier Leerzeichen weiter eingerückt als ihr übergeordneter Knoten, und mit Excel-Gliederungsgruppen können Sie jede Ebene ein- und ausklappen.

- `dimension_name` – der Name der Dimension oder ihr Pfad im Projekt.
- `start_node` – der Knoten, bei dem begonnen wird, etwa die Wurzel der Dimension.
- `hierarchy` – die [Alternativhierarchie](/de/guides/dimensions/dimensions/#alternative-attribut-hierarchien), der gefolgt wird. Standard ist `"main"`.
- `orientation` – `"vertical"` (der Standard), um Knoten in einer Spalte nach unten aufzulisten, oder `"horizontal"`, um sie in einer Zeile aufzulisten.
- `generation_limit` – wie viele Generationen zurückgegeben werden, wobei `start_node` als erste zählt: `2` gibt den Startknoten und seine untergeordneten Knoten zurück. Lassen Sie ihn weg, um jede Generation zurückzugeben.

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

Gibt `start_node` und die darunterliegenden Knoten zurück, die `drill_key` anfordert, in einer Spalte nach unten, nach Generation eingerückt und in einer Excel-Gliederung gruppiert.

- `dimension_name` – der Name der Dimension oder ihr Pfad im Projekt.
- `start_node` – der Knoten, von dem aus aufgeschlüsselt wird.
- `drill_key` – wie weit aufgeschlüsselt wird, aus [`DRILL_KEY`](#drill_key): jeder Nachkomme, nur die Blätter, eine Anzahl von Ebenen oder ein Bereich von Generationen.
- `hierarchy` – die Alternativhierarchie, der gefolgt wird. Standard ist `"main"`.

Zum Beispiel listet `=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` **Total** gefolgt von jeder darunterliegenden Blattregion auf.

Die [Erweiterungsbefehle im Menüband](/de/reference/cli/plaidxl/ribbon/#drill-functions) tun dasselbe für eine Dimension und einen Knoten, die Sie in zwei Zellen eingegeben haben, ohne dass Sie eine Formel schreiben müssen.

## Werte

`CELL` und `CELLS` berechnen eine Kennzahl – eine numerische Spalte einer Tabelle –, aggregiert auf die Knoten, die Sie in einer oder mehreren Dimensionen wählen. Stellen Sie sich jeden Aufruf als einen Schnittpunkt in einem Bericht vor: **Umsatz** für **EMEA** in **FY2026**.

Sie beschreiben den Schnittpunkt mit den nachfolgenden Baustein-Funktionen, meist in eigenen Zellen, und übergeben diese Zellen dann in beliebiger Reihenfolge an `CELL` oder `CELLS`:

| Argument | Erstellt mit | Erforderlich |
|---|---|---|
| Die zu lesende Tabelle | [`TABLE_REPR`](#table_repr) | Genau eine |
| Die zu aggregierende Spalte | [`MEASURE`](#measure) für `CELL`, [`MEASURES`](#measures) oder mehrere `MEASURE`-Zellen für `CELLS` | Ja |
| Wie sie aggregiert wird | [`MEASURE_TYPE`](#measure_type) | Nein – Standard ist `sum` |
| Ein Filter auf einer Spalte | [`DIMENSION_REPR`](#dimension_repr) | Mindestens einer, einer pro Spalte |

Jeder Filter nennt eine **Spalte der Tabelle** und einen Wert. Wenn diese Spalte in PlaidCloud mit einer Dimension verknüpft ist, ist der Wert ein Knoten, und der Filter schließt alles ein, was in der Haupthierarchie der Dimension zu diesem Knoten aggregiert wird – bei einer mit einer Geografie-Dimension verknüpften Spalte **Region** deckt der Knoten **EMEA** jedes darunterliegende Land ab. Bei einer Spalte, die nicht mit einer Dimension verknüpft ist, stimmt der Filter exakt mit dem Wert überein.

Die Beispiele auf dieser Seite verwenden eine Tabelle, deren Spalten **Region** und **Period** mit Dimensionen verknüpft sind. Verwenden Sie die Spaltennamen Ihrer eigenen Tabelle.

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

Gibt eine Zahl zurück: die Kennzahl, aggregiert über die Zeilen, die unter jeden von Ihnen übergebenen Knoten fallen.

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` zeigt den Gesamtumsatz für EMEA in FY2026.

Ein Blatt voller `CELL`-Formeln wird schnell neu berechnet: Wenn eine Neuberechnung viele Werte aus derselben Tabelle anfordert, sendet PlaidXL sie gebündelt an PlaidCloud statt eine Anfrage pro Zelle. Wenn ein Wert nicht berechnet werden kann, zeigt die Zelle `#VALUE!` an, und beim Daraufzeigen wird der Grund so angezeigt, wie PlaidCloud ihn gemeldet hat, etwa eine Filterspalte, die nicht in der Tabelle vorhanden ist, oder ein Knoten ohne Mitglieder. `CELLS` zeigt den ersten Grund für das gesamte Ergebnis an.

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

Wie `CELL`, aber für mehrere Kennzahlen gleichzeitig. Gibt eine Zahl pro Kennzahl zurück, in einer Spalte nach unten, in der Reihenfolge, in der Sie sie aufgelistet haben.

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` übergibt das gesamte übergelaufene Ergebnis von `MEASURES`. `B2:B4` zeigen Umsatz, Kosten und Stückzahlen für EMEA in FY2026.

## Bausteine

Diese Funktionen lesen selbst keine Daten. Jede gibt einen kurzen Text zurück, der einen Teil einer Berechnung beschreibt und bereit ist, an `CELL`, `CELLS` oder `DRILL` übergeben zu werden. Legen Sie sie in Zellen ab, auf die Sie verweisen, sodass eine Änderung – etwa eine andere Periode – jede Formel aktualisiert, die sie verwendet.

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

Die Tabelle, aus der `CELL` und `CELLS` lesen, über ihren Namen im ausgewählten Projekt.

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

Die numerische Spalte, die `CELL` aggregiert.

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

Mehrere Kennzahlspalten für `CELLS`, aus einem Zellbereich, der Spaltennamen enthält. Das Ergebnis läuft mit einer Zelle pro Spalte über; übergeben Sie es mit dem Überlaufoperator, etwa `D2#`, an `CELLS`.

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

Wie die Kennzahl aggregiert wird. `agg_function` ist einer der folgenden Werte, in Kleinbuchstaben:

| Wert | Gibt zurück |
|---|---|
| `sum` | Die Summe (der Standard, wenn Sie keinen Kennzahltyp übergeben) |
| `mean` | Den Durchschnitt |
| `median` | Den mittleren Wert |
| `min` | Den kleinsten Wert |
| `max` | Den größten Wert |
| `std` | Die Standardabweichung |
| `var` | Die Varianz |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

Ein Filter für `CELL` und `CELLS`. Übergeben Sie einen für jede Spalte, nach der Sie filtern möchten.

- `dimension_name` – der Name einer **Spalte in der Tabelle** – der Spalte, die die Werte der Dimension enthält, etwa `"Region"`. Er muss exakt mit dem Spaltennamen übereinstimmen; eine Spalte, die nicht in der Tabelle vorhanden ist, liefert einen Fehler.
- `start_node` – der Knoten, auf den aggregiert wird, etwa `"EMEA"`. Bei einer Spalte, die nicht mit einer Dimension verknüpft ist, der Wert, der übereinstimmen soll.

Verweisen Sie für den Knoten auf eine Zelle, um ein Raster zu erstellen: `=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`. Führende und nachgestellte Leerzeichen werden ignoriert, sodass Sie auf die eingerückten Knotennamen zeigen können, die `DRILL` anlegt.

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

Wie weit [`DRILL`](#drill) unterhalb seines Startknotens geht. `d_key` ist Klartext, entweder eine Wortform oder ein ausgeschriebener Drill-Schlüssel:

| `d_key` | Schlüsselt auf bis |
|---|---|
| `"all"` | Jeder Nachkomme |
| `"leaves"` | Nur die Blätter, also die Knoten ohne darunterliegende Knoten |
| `"1 level"`, `"2 levels"`, … | So viele Generationen nach unten |
| `">[...]"` | Der ausgeschriebene Drill-Schlüssel, wie in der nächsten Tabelle |

Schreiben Sie die Zahl als Ziffern: `"2 levels"`, nicht `"two levels"`. Ein vorangestelltes `drill` wird ignoriert, sodass auch `"drill 2 levels"` funktioniert.

Ein ausgeschriebener Schlüssel zählt Generationen ab dem Startknoten nach unten, der Generation 0 ist und immer enthalten ist. Negative Zahlen zählen von den Blättern jedes Zweigs aufwärts, sodass eine unregelmäßige Hierarchie so funktioniert, wie Sie es erwarten.

| Schlüssel | Enthält |
|---|---|
| `>[*]` oder `>[:]` | Jeden Knoten |
| `>[]` oder `>[-1]` | Nur die Blätter |
| `>[n]` | Den Startknoten und `n` Generationen darunter. `>[0]` ist der Startknoten allein. |
| `>[a:]` | Den Startknoten, dann Generation `a` und alles darunter |
| `>[a:b]` | Den Startknoten, dann die Generationen `a` bis `b - 1` |
| `>[0:-k]` | Den Startknoten und jeden Knoten, unter dem mindestens `k` Generationen liegen, sodass die letzten `k` Generationen jedes Zweigs weggelassen werden. `>[0:-1]` ist jeder Knoten außer den Blättern. |
| `>[a:-k]` | Dasselbe, beginnend bei Generation `a` |

Für die Hierarchie `A` mit den untergeordneten Knoten `B`, `C` und `D`, wobei `B` die Knoten `B1` und `B2` und `C` den Knoten `C1` hat:

| Schlüssel | Ergebnis |
|---|---|
| `>[1]` | `A`, `B`, `C`, `D` |
| `>[2]` | `A`, `B`, `B1`, `B2`, `C`, `C1`, `D` |
| `>[]` | `A`, `B1`, `B2`, `C1`, `D` |
| `>[0:-1]` | `A`, `B`, `C` |
| `>[2:]` | `A`, `B1`, `B2`, `C1` |

Knoten werden in Hierarchiereihenfolge aufgelistet, jeder unter seinem eigenen übergeordneten Knoten, und die Excel-Gliederungsgruppen folgen derselben Reihenfolge. Leerzeichen innerhalb eines Schlüssels werden ignoriert. Ein Schlüssel, der keiner dieser Formen entspricht, liefert einen Fehler, der die gültigen Formen auflistet.

<Aside type="caution">
`>[-1]` und `>[0:-1]` bedeuten etwas anderes als in früheren Versionen von PlaidXL, in denen sie vertauscht waren. `>[-1]` gibt jetzt nur die Blätter zurück und `>[0:-1]` alles außer den Blättern. Prüfen Sie jede Arbeitsmappe, in der ein Drill-Schlüssel von Hand geschrieben wurde. Die Wortformen `"all"`, `"leaves"` und `"2 levels"` sind unverändert.
</Aside>

<Aside type="note">
`CELL`, `CELLS` und `DRILL` erwarten die Ausgabe dieser Baustein-Funktionen. Erstellen Sie jedes Argument mit seiner Funktion, statt den Text selbst einzugeben.
</Aside>

## Eine Formel über den Aufgabenbereich einfügen

Die Registerkarte **Formulas** des Aufgabenbereichs schreibt eine Formel für Sie. Wählen Sie unter **What do you want in the cell?** eine Option:

- **A whole table** (`GET_TABLE`) – wählen oder geben Sie die Tabelle ein und optional eine maximale Zeilenanzahl.
- **One number** (`CELL`) – wählen oder geben Sie die Tabelle ein und wählen Sie **Column to total** und **How to combine the values**.
- **A list of dimension nodes** (`DRILL`) – wählen oder geben Sie die Dimension und den Startknoten ein, wählen Sie **All levels**, **Lowest level only** oder **Down** um eine Anzahl von **Ebenen** und optional eine **Alternativhierarchie**.

Die Vorschau **Formula** zeigt das Ergebnis, während Sie die Felder ausfüllen. Klicken Sie auf **Insert in active cell**, um sie in die ausgewählte Zelle einzufügen, oder auf **Kopieren**, um sie selbst einzufügen. Wenn Sie auf der Registerkarte **Tabellen** eine Tabelle oder auf der Registerkarte **Dimensionen** eine Dimension auswählen, wird das passende Feld ausgefüllt.
