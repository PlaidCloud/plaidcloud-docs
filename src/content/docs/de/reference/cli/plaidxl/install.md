Sie installieren PlaidXL einmal pro Computer, nicht einmal pro Arbeitsmappe. Danach befindet sich die Registerkarte **PlaidCloud** in jeder Arbeitsmappe, die Sie öffnen, im Excel-Menüband.

## Bevor Sie beginnen

- Verwenden Sie Excel für Microsoft 365 oder Excel 2021 oder höher unter Windows oder Mac.
- Wenn Ihre Organisation Office-Add-ins zentral verwaltet, muss Ihr Microsoft-365-Administrator PlaidXL möglicherweise für Sie bereitstellen. Wenn Sie Add-ins nicht selbst installieren können, bitten Sie ihn, das Add-in **PlaidCloud** hinzuzufügen.

## Unter Windows installieren

1. Öffnen Sie in Excel **Insert → Add-ins** (in einigen Versionen **Home → Add-ins**).
2. Geben Sie `PlaidCloud` in das Suchfeld für Add-ins ein.
3. Wählen Sie das Add-in **PlaidCloud** aus und klicken Sie auf **Hinzufügen**.

## Auf dem Mac installieren

1. Öffnen Sie in Excel für Mac **Insert → Add-ins**. In älteren Versionen lautet das Menü **Insert → Store**.
2. Geben Sie `PlaidCloud` in das Suchfeld für Add-ins ein.
3. Wählen Sie das Add-in **PlaidCloud** aus und klicken Sie auf **Hinzufügen**.

## Den Aufgabenbereich öffnen

1. Klicken Sie im Menüband auf die Registerkarte **PlaidCloud**.
2. Klicken Sie in der Gruppe **Daten** auf **Open PlaidXL**.

Der PlaidXL-Aufgabenbereich öffnet sich auf der rechten Seite des Fensters und fordert Sie zur Anmeldung auf. Weiter geht es mit [Anmelden](/de/reference/cli/plaidxl/connect/).

Der Aufgabenbereich bleibt zwischen Sitzungen angemeldet, sodass Sie sich meist einmal anmelden und den Aufgabenbereich danach nur noch öffnen, wenn Sie ihn brauchen.

## Wenn PlaidXL nicht erscheint

- Schließen Sie alle Excel-Fenster und öffnen Sie Excel erneut. Ein Add-in wird oft erst nach einem Neustart von Excel im Menüband angezeigt.
- Suchen Sie unter **Insert → My Add-ins** (Windows) oder **Insert → Add-ins → My Add-ins** (Mac) und wählen Sie dort **PlaidCloud** aus.
- Wenn Ihre Organisation Add-ins aus dem Store blockiert, bitten Sie Ihren Microsoft-365-Administrator, es bereitzustellen.

Weitere Lösungen finden Sie auf der Seite [Fehlerbehebung](/de/reference/cli/plaidxl/troubleshooting/).
