## Agent herunterladen

Suchen Sie auf [PlaidCloud.com](https://plaidcloud.com/) in den Releases nach **PlaidLink**.

## Agent extrahieren

Extrahieren Sie die heruntergeladene ZIP-Datei an einen Installationsort Ihrer Wahl. In der Regel ist dies:

```bash
C:\Users\<Username here>\src\plaidlink
```

## Konfigurationsdatei erstellen

<Aside>Wenn Sie von einer früheren Version des Agent aktualisieren, ist die Konfigurationsdatei weiterhin gültig, und Sie können diesen Schritt überspringen.</Aside>

Kopieren Sie die Datei `config-dist.yaml` aus dem Verzeichnis des Agent nach `%ProgramData\plaidcloud\` und benennen Sie diese Kopie in `config.yaml` um.

*(Bearbeiten Sie diese Konfiguration mit den Werten, die Sie aus PlaidCloud erhalten haben.)*

## Dienst des Agent installieren

Führen Sie die Datei `install_windows_service.bat` im Installationsverzeichnis des Agent aus ODER

wechseln Sie in einer Eingabeaufforderung mit Administratorrechten in das Installationsverzeichnis des Agent und führen Sie Folgendes aus:

```bash
.\PlaidLink.exe install
```

## Agent ausführen

<Aside>Zum Installieren eines Windows-Dienstes sind Administratorrechte erforderlich.</Aside>

Geben Sie **`Services`** in die Windows-Suchleiste ein und öffnen Sie die Dienstverwaltung. Suchen Sie in der Liste der Dienste nach **`PlaidCloud Agent`**.

Klicken Sie mit der rechten Maustaste auf den Dienst und wählen Sie **„Starten“**, um den Agent zu starten.

## Updates deaktivieren

Wenn Sie die automatische Update-Funktion des Agent jederzeit deaktivieren möchten, öffnen Sie die **„yaml“**-Konfigurationsdatei des Agent, 
fügen Sie auf der obersten Ebene der Datei die Zeile `freeze_updates: true` hinzu und starten Sie den Dienst des Agent neu. 

<Aside type="caution">Es wird nicht empfohlen, automatische Updates langfristig zu deaktivieren.</Aside>
