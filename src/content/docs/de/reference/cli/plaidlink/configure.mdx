Der PlaidLink-Agent arbeitet mit dem PlaidCloud-Dienst zusammen. Der PlaidLink-Agent stellt die Verbindung bereit, die für den Betrieb mit nicht direkt erreichbaren Systemen wie Datenbanken und Dateisystemen erforderlich ist. Der Agent führt eine Reihe wesentlicher Aktionen aus, darunter:

* Lesen und Schreiben in Datenbanken
* Lesen und Schreiben von Dateien auf Netzlaufwerken und Servern
* Prüfen von Sensorbedingungen
* Interaktion mit SAP ECC und SAP S/4HANA über Remote Function Calls (RFCs)
* Interaktion mit SAP Profitability and Cost Management (PCM)
* Senden von Nachrichten und Benachrichtigungen an Remote-Systeme

## Agent in PlaidCloud erstellen

Die Verwaltung von PlaidLink-Agents erfolgt in PlaidCloud auf der Registerkarte „Analyze“. Der erste Schritt besteht darin, in PlaidCloud eine neue PlaidLink-Agent-Instanz zu erstellen.

### So erstellen Sie einen neuen PlaidLink-Agent

1. Wählen Sie die Registerkarte „Analyze“.
2. Wählen Sie oben das Menü „Tools“.
3. Klicken Sie auf „PlaidLink-Agents“.
4. Erstellen Sie einen neuen Agent mit einem passenden Namen für die Umgebung oder den Server, auf dem er für Remote-Operationen installiert wird.

### So zeigen Sie den öffentlichen und den privaten Schlüssel des Agents an

1. Klicken Sie auf das Symbol „Bearbeiten“, um das Formular anzuzeigen.
2. Am Ende des Formulars finden Sie den öffentlichen und den privaten Schlüssel, die beim Erstellen des Agents zufällig generiert wurden.

Der private Schlüssel erscheint nur für Mitglieder, die Agents bearbeiten dürfen.

<Aside>Notieren Sie sich diese Schlüssel, denn sie werden in der Agent-Konfiguration auf dem Remote-Server verwendet.</Aside>

### So generieren Sie zufällig neue Schlüssel

1. Klicken Sie beim Datensatz des Agents auf das Symbol „Neu generieren“.
2. Vergessen Sie nach der Neugenerierung der Schlüssel nicht, die Agent-Konfigurationsdatei auf dem Remote-Server mit den neuen Schlüsseln zu aktualisieren.

<Aside>Bewahren Sie den öffentlichen und den privaten Schlüssel für die Konfiguration des Remote-Agents im nächsten Schritt auf.</Aside>

## Zugriff auf Dokumentenkonten

Wenn der Agent für das Hoch- oder Herunterladen von Dateien Zugriff auf ein Dokumentenkonto benötigt, muss ihm die Berechtigung für den Zugriff auf das Dokumentenkonto erteilt werden.

### So erteilen Sie Kontozugriff

1. Wählen Sie unter Dokumente in der Leiste **Verwalten**.
2. Klicken Sie nach Anzeige der Kontentabelle auf das Agent-Symbol des Kontos, für das der neue Agent Upload- und Download-Rechte erhalten soll.
3. Ziehen Sie den neuen Agent in die Spalte „Zugewiesene Agenten“.
4. Speichern Sie das Zugriffssteuerungsformular.

<Aside>Agents können nur dann Dateien hoch- und herunterladen, wenn ihnen Zugriff auf ein oder mehrere Dokumentenkonten erteilt wurde.</Aside>

## Zugriff auf Datenverbindungen

Wenn der Agent Zugriff auf eine Datenverbindung wie eine Datenbank benötigt, muss ihm die Berechtigung für den Zugriff auf die Informationen der externen Datenverbindung erteilt werden.


### So erteilen Sie Verbindungszugriff


1. Wählen Sie auf der Registerkarte „Analyze“ das Menü „Tools“.
2. Klicken Sie auf „Externe Datenverbindungen“.
3. Klicken Sie nach Anzeige der Tabelle der Datenverbindungen auf das Agent-Symbol der Verbindung, für die der neue Agent Nutzungsrechte erhalten soll.
4. Ziehen Sie den neuen Agent in die Spalte „Zugewiesene Agenten“ und speichern Sie das Zugriffssteuerungsformular.

<Aside>Die Anmeldedaten von Agent-Datenverbindungen werden unter „Externe Datenverbindungen“ verwaltet.</Aside>
