Der PlaidLink-Agent arbeitet mit dem PlaidCloud-Dienst zusammen. Er stellt die Verbindung bereit, die für die Arbeit mit nicht direkt erreichbaren Systemen wie Datenbanken und Dateisystemen erforderlich ist. Der Agent führt eine Reihe wesentlicher Aktionen aus, darunter:

* Lesen aus und Schreiben in Datenbanken
* Lesen und Schreiben von Dateien auf Netzlaufwerken und Servern
* Prüfen von Sensorbedingungen
* Interaktion mit SAP ECC und SAP S/4HANA über Remote Function Calls (RFCs)
* Interaktion mit SAP Profitability and Cost Management (PCM)
* Senden von Nachrichten und Benachrichtigungen an entfernte Systeme

## Agent in PlaidCloud erstellen

Die Verwaltung von PlaidLink-Agents erfolgt in PlaidCloud auf der Registerkarte Analyze. Der erste Schritt besteht darin, in PlaidCloud eine neue PlaidLink-Agent-Instanz zu erstellen.

### So erstellen Sie einen neuen PlaidLink-Agent

1. Wählen Sie die Registerkarte Analyze
2. Wählen Sie oben das Menü Tools
3. Klicken Sie auf PlaidLink-Agents
4. Erstellen Sie einen neuen Agent mit einem passenden Namen für die Umgebung oder den Server, auf dem er für Remote-Operationen installiert wird

### So zeigen Sie den öffentlichen und den privaten Schlüssel des Agents an

1. Klicken Sie auf das Bearbeiten-Symbol, um das Formular anzuzeigen
2. Am Ende des Formulars finden Sie den öffentlichen und den privaten Schlüssel, die beim Erstellen des Agents zufällig generiert wurden

<Aside>Merken Sie sich diese Schlüssel, denn sie werden in der Agent-Konfiguration auf dem entfernten Server verwendet.</Aside>

### So generieren Sie zufällig neue Schlüssel

1. Klicken Sie beim Datensatz des Agents auf das Symbol zum Neugenerieren
2. Vergessen Sie nach dem Neugenerieren der Schlüssel nicht, die Konfigurationsdatei des Agents auf dem entfernten Server mit den neuen Schlüsseln zu aktualisieren.

<Aside>Bewahren Sie den öffentlichen und den privaten Schlüssel für die Konfiguration des entfernten Agents im nächsten Schritt auf.</Aside>

## Zugriff auf Dokumentenkonten

Wenn der Agent Zugriff auf ein Dokumentenkonto zum Hoch- oder Herunterladen von Dateien benötigt, muss ihm die Berechtigung für den Zugriff auf das Dokumentenkonto erteilt werden.

### So erteilen Sie Kontozugriff

1. Wählen Sie auf der Registerkarte Document die Option Konten verwalten
2. Wenn die Kontentabelle angezeigt wird, klicken Sie beim Konto, für das der neue Agent Upload-/Download-Rechte haben soll, auf das Agent-Symbol
3. Ziehen Sie den neuen Agent in die Spalte Zugewiesene Agenten
4. Speichern Sie das Formular für die Zugriffssteuerung.

<Aside>Agenten können nur dann Dateien hoch- und herunterladen, wenn ihnen der Zugriff auf ein oder mehrere Dokumentenkonten gewährt wurde.</Aside>

## Zugriff auf Datenverbindungen

Wenn der Agent Zugriff auf eine Datenverbindung wie eine Datenbank benötigt, muss ihm die Berechtigung für den Zugriff auf die Informationen der externen Datenverbindung erteilt werden.


### So erteilen Sie Verbindungszugriff


1. Wählen Sie auf der Registerkarte Analyze das Menü Tools
2. Klicken Sie auf Externe Datenverbindungen
3. Wenn die Tabelle der Datenverbindungen angezeigt wird, klicken Sie bei der Verbindung, für die der neue Agent Nutzungsrechte haben soll, auf das Agent-Symbol
4. Ziehen Sie den neuen Agent in die Spalte Zugewiesene Agenten und speichern Sie das Formular für die Zugriffssteuerung.

<Aside>Die Anmeldedaten des Agents für Datenverbindungen werden unter Externe Datenverbindungen verwaltet.</Aside>
