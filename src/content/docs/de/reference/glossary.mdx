Eine zentrale Stelle für Produktbegriffe. Wenn ein Leitfaden oder eine Referenzseite ein Wort aus dieser Liste verwendet, ist damit genau das hier Beschriebene gemeint.

## Konto

Ein PlaidCloud-Login. Ein Konto gehört zu einer oder mehreren Organisationen und erhält Zugriff auf bestimmte Workspaces innerhalb dieser Organisationen.

## KI-Assistent

Eine projektbezogene Chat-Oberfläche in PlaidCloud, um Fragen zu Daten zu stellen, Ausdrücke zu erzeugen und Projekte in natürlicher Sprache zu bearbeiten. Siehe [Leitfaden zum KI-Assistenten](/de/guides/ai-assistant/).

## Umlage

Eine Workflow-Operation, die Werte anhand von Treiberdaten und Regeln von einer Gruppe von Zeilen („Quelle") auf eine andere („Ziel") verteilt. Wird für Verrechnungspreise, Prozesskostenrechnung, IT-Weiterbelastung, Profitabilitätsanalysen und ähnliche Kostenverteilungsprobleme verwendet. Siehe [Umlagen](/de/guides/allocations/).

## Verbindung

Eine gespeicherte Konfiguration, über die PlaidCloud ein externes System erreicht — eine Datenbank, ein Cloud-Speicherkonto, ein ERP-System oder eine REST-API. Verbindungen werden von Workflow-Schritten wiederverwendet, sodass die Zugangsdaten an einer Stelle liegen. Siehe [Verbindungen (Leitfaden)](/de/guides/connections/) · [Konnektoren (Referenz)](/de/reference/connectors/).

## Dash-App

Eine benutzerdefinierte interaktive Anwendung auf Basis von PlaidCloud-Daten, die mit dem Framework Plotly Dash erstellt, aus einem Git-Repository veröffentlicht und gleichwertig zu einer Server-Panel-App gehostet wird. Siehe [Dash-Apps](/de/guides/dash-apps/).

## Dashboard

Eine veröffentlichte, interaktive Ansicht von Projektdaten, die aus Tabellen und Ansichten aufgebaut ist. Siehe [Dashboards](/de/guides/dashboards/).

## Dimension

Eine Hierarchie, die zum Aufteilen und Aggregieren von Daten dient. Kostenstellen, Produkte, Geografie und Zeiträume sind typische Dimensionen. Umlagen nutzen Dimensionen, um zu entscheiden, was auf was verteilt wird. Siehe [Dimensionen](/de/guides/dimensions/).

## Verteilungstreiber

Bei einer Umlage die Daten, die bestimmen, *wie* Werte auf die Ziele verteilt werden. Beispiel: Wenn Sie IT-Kosten anhand der Mitarbeiterzahl auf Geschäftsbereiche umlegen, ist die Tabelle mit den Mitarbeiterzahlen der Verteilungstreiber.

## Lakehouse

Der zugrunde liegende analytische Datenspeicher von PlaidCloud. Die Ausdrucksbibliothek ist nach Lakehouse-Engine versioniert: **Lakehouse v1** (auf Databend basierend) und **Lakehouse v2** (auf StarRocks basierend). Siehe [Ausdrucksreferenz](/de/reference/expressions/).

## MCP

Model Context Protocol — der Standard, den PlaidCloud zur Integration mit KI-Coding-Agenten (Claude Code, Cursor, Copilot usw.) verwendet. Siehe [KI-Coding-Agenten](/de/integrations/ai-coding-agents/).

## Mitglied

Ein Benutzerkonto, das Zugriff auf einen Workspace erhalten hat. Mitglieder werden Sicherheitsgruppen innerhalb des Workspace zugewiesen, die steuern, was sie tun dürfen. Siehe [Zugriffsverwaltung](/de/administration/access/).

## Organisation

Die oberste Abrechnungs- und Identitätsgrenze in PlaidCloud. Eine Organisation enthält einen oder mehrere Workspaces und ein oder mehrere Mitgliedskonten.

## Panel-App

Eine benutzerdefinierte interaktive Anwendung auf Basis von PlaidCloud-Daten, die typischerweise mit dem Panel-Framework erstellt wird. Siehe [Panel-Apps](/de/guides/panel-apps/).

## PlaidLink

Der lokale Konnektor-Daemon von PlaidCloud — läuft als Windows-Dienst, als Unix/Linux/Mac-Daemon oder als Container-Dienst und verbindet PlaidCloud-Workflows mit lokalen Datenquellen. Siehe [PlaidLink-Referenz](/de/reference/cli/plaidlink/).

## PlaidXL

Das PlaidCloud-Add-in für Excel. Es ruft Projekttabellen und Dimensionen in Arbeitsblättern ab, aktualisiert sie und fügt `PLAIDXL`-Formeln hinzu, die aggregierte Werte aus PlaidCloud-Daten berechnen. Siehe [PlaidXL-Referenz](/de/reference/cli/plaidxl/).

## Projekt

Eine Arbeitseinheit innerhalb eines Workspace. Jedes Projekt besitzt eigene Tabellen, Workflows, Dimensionen und einen eigenen Audit-Verlauf. Projekte sind voneinander isoliert — sie teilen keinen Zustand. Siehe [Projekte](/de/guides/projects/).

## Veröffentlichen

Eine Projekttabelle für die externe Nutzung bereitstellen (Dashboards, BI-Tools, nachgelagerte Systeme). Siehe [Daten veröffentlichen](/de/guides/data/publish/).

## Sicherheitsgruppe

Ein Bündel von Berechtigungen innerhalb eines Workspace. Mitglieder werden Sicherheitsgruppen zugewiesen, um ihnen bestimmte Fähigkeiten zu erteilen (Tabellen lesen, Workflows bearbeiten, Mitglieder verwalten usw.). Siehe [Sicherheitsgruppen](/de/administration/access/managing-security-groups-and-assignments/).

## Schritt

Ein einzelner Vorgang innerhalb eines Workflows — eine CSV-Datei importieren, zwei Tabellen verknüpfen, eine Benachrichtigung senden, eine Umlage ausführen. Schritte gibt es in Kategorien (Import, Export, Tabellen, Umlage, Dimension, Dokument, Benachrichtigungen usw.). Siehe [Referenz der Workflow-Schritte](/de/reference/workflow-steps/).

## Tabelle

Strukturierte Daten aus Zeilen und Spalten innerhalb eines Projekts. Tabellen stammen aus Importen, Transformationen oder externen Quellen.

## Ansicht

Ein gespeichertes Abfrageergebnis, das auf einer oder mehreren Tabellen aufbaut. Verhält sich für nachgelagerte Nutzer wie eine Tabelle, aber die zugrunde liegenden Daten werden beim Lesen neu ausgewertet.

## Workflow

Eine Abfolge von Schritten, die auf Tabellen arbeiten. Die Automatisierungseinheit in PlaidCloud. Workflows können sequenziell, parallel, bedingt oder in Schleifen ausgeführt werden. Siehe [Workflows (Leitfaden)](/de/guides/workflows/) · [Workflow-Schritte (Referenz)](/de/reference/workflow-steps/).

## Workspace

Eine isolierte Umgebung innerhalb einer Organisation, in der die eigentliche Arbeit stattfindet. Teams nutzen typischerweise einen Workspace pro Umgebung (Entwicklung, Staging, Produktion) oder pro Geschäftsbereich. Mitglieder erhalten Zugriff auf Workspace-Ebene. Siehe [Zugriffsverwaltung](/de/administration/access/).
