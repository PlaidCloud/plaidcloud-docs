PlaidCloud verbindet sich mit Team-Chat-Plattformen, damit Workflows Benachrichtigungen, Warnungen oder Statusaktualisierungen direkt in Kanäle senden können, die Ihr Team ohnehin im Blick hat. Am häufigsten werden sie zusammen mit den Workflow-Schritten [Notify via Slack](/de/reference/workflow-steps/notifications/notify-via-slack/) und [Notify via Microsoft Teams](/de/reference/workflow-steps/notifications/notify-via-microsoft-teams/) verwendet.
