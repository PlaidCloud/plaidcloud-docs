Gibt die mathematische Konstante e (eulersche Zahl) zurück.

## Analyze-Syntax

```python
func.e()
```

## Analyze-Beispiele

```python
func.e()

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## SQL-Syntax

```sql
E()
```

## SQL-Beispiele

```sql
SELECT E();

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
