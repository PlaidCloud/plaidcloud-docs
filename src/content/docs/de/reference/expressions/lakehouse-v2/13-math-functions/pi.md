Gibt die mathematische Konstante Pi zurück.

## Analyze-Syntax

```python
func.pi()
```

## Analyze-Beispiele

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## SQL-Syntax

```sql
PI()
```

## SQL-Beispiele

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
