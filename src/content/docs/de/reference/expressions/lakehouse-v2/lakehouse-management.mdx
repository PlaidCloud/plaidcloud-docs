## Beschreibung

Der Bereich **Lakehouse** bietet die Verwaltung der Lakehouse-Rechenleistung und der Iceberg-Kataloge Ihres Workspace per Mausklick, ohne PlaidCloud zu verlassen. Öffnen Sie ihn über die Schaltfläche **Lakehouse** in der Haupt-Symbolleiste.

Eine Warehouse-Auswahl am oberen Fensterrand gilt für jede Registerkarte. Der Bereich ist in sieben Registerkarten unterteilt: **Abfragen**, **Profil**, **Katalog**, **Warehouses**, **Benutzer**, **Laden** und **Administrator**.


## Abfragen

Überwachen Sie laufende Abfragen und durchsuchen Sie den Verlauf. Die Registerkarte ist durch eine verschiebbare Trennlinie in einen oberen und einen unteren Bereich geteilt:

* **Wird ausgeführt** — Abfragen, die gerade ausgeführt werden. Die Anzeige wird automatisch in dem Intervall aktualisiert, das Sie in der Symbolleiste wählen.
* **Verlauf** — zuletzt abgeschlossene Abfragen.

**So zeigen Sie den Plan einer Abfrage an:**

1. Klicken Sie am Zeilenanfang auf das Symbol `Profile`
2. Die SQL-Abfrage wird in die Registerkarte **Profil** geladen. Dort können Sie EXPLAIN oder EXPLAIN ANALYZE ausführen

**So beenden Sie laufende Abfragen:**

1. Wählen Sie in der Tabelle **Wird ausgeführt** eine oder mehrere Zeilen aus
2. Klicken Sie in der Symbolleiste auf `Kill selected`
3. Bestätigen Sie im Dialogfeld


## Profil

Führen Sie `EXPLAIN` oder `EXPLAIN ANALYZE` für eine SQL-Anweisung aus und visualisieren Sie den resultierenden Plan als Baum mit Heatmap.

1. Öffnen Sie **Lakehouse > Profil**
2. Fügen Sie eine SQL-Anweisung ein oder geben Sie sie ein
3. Klicken Sie auf `EXPLAIN` (nur Plan) oder `EXPLAIN ANALYZE` (Plan sowie tatsächliche Zeilenanzahlen und Laufzeiten)

Der Plan-Baum hebt die aufwendigsten Knoten hervor, sodass die Engpässe einer langsamen Abfrage auf einen Blick erkennbar sind.


## Katalog

Durchsuchen Sie den Iceberg-Katalog des ausgewählten Warehouses. Der Bereich listet links die Namespaces und rechts die Tabellen auf. Eine Aktionsleiste bietet Vorgänge zum Erstellen und Löschen.

**So erstellen Sie einen Namespace:**

1. Öffnen Sie **Lakehouse > Katalog**
2. Klicken Sie auf `New namespace`
3. Geben Sie den Namen des Namespace ein und bestätigen Sie

**So löschen Sie eine Tabelle:**

1. Wählen Sie den Namespace und dann die Tabelle aus
2. Klicken Sie auf `Drop table`
3. Bestätigen Sie im Dialogfeld

Über eine Liste gelöschter Tabellen am unteren Rand der Registerkarte können Sie kürzlich gelöschte Tabellen mit `UNDROP` wiederherstellen, solange sie wiederherstellbar sind.

<Aside>Destruktive Aktionen (Namespace löschen, Tabelle löschen) sind deaktiviert, wenn das ausgewählte Warehouse das Standard-Warehouse des Workspace ist.</Aside>


## Warehouses

Erstellen, listen und löschen Sie die Iceberg-Warehouses, auf denen Ihr Lakehouse basiert.

**So erstellen Sie ein Warehouse:**

1. Öffnen Sie **Lakehouse > Warehouses**
2. Klicken Sie auf `Add warehouse`
3. Geben Sie einen Warehouse-Namen und die Speicherkonfiguration ein
4. Klicken Sie auf `Add`

**So löschen Sie ein Warehouse:**

1. Wählen Sie die Zeile des Warehouses aus
2. Klicken Sie auf `Delete`
3. Bestätigen Sie im Dialogfeld

<Aside>Das Standard-Warehouse ist geschützt — es kann nicht gelöscht werden.</Aside>

<Aside title="Inaktive Warehouses werden automatisch herunterskaliert">Die Kapazität eines Warehouses zur Abfrageausführung wird auf ein kleines Minimum herunterskaliert, nachdem es eine Weile inaktiv war, und skaliert von selbst wieder hoch, sobald Abfragen eintreffen — ungenutzte Kapazität wird also freigegeben, statt rund um die Uhr berechnet zu werden. Eines ist zu beachten: Die erste Abfrage an ein Warehouse, das eine Weile inaktiv war, kann etwas länger dauern, während die Kapazität wieder bereitgestellt wird. Ein Warehouse mit gleichmäßiger oder hoher Auslastung ist nicht betroffen, und das Warehouse bleibt durchgehend erreichbar — es wird dadurch nie offline genommen.</Aside>


## Benutzer

Verwalten Sie die Datenbankbenutzer, die sich von externen SQL-Clients (DBeaver usw.) mit dem Lakehouse verbinden. Sowohl kennwortbasierte als auch per SSO bereitgestellte Benutzer werden aufgelistet.

**So fügen Sie einen Benutzer hinzu:**

1. Öffnen Sie **Lakehouse > Benutzer**
2. Klicken Sie auf `Add user`
3. Geben Sie Benutzernamen und Kennwort ein
4. Klicken Sie auf `Add`
5. Speichern Sie das Kennwort — es wird nur einmal angezeigt und kann später nicht mehr abgerufen werden

**So setzen Sie ein Kennwort zurück:**

1. Wählen Sie die Zeile des Benutzers aus
2. Klicken Sie auf `Reset password`
3. Speichern Sie das neue Kennwort aus dem Dialogfeld

**So entfernen Sie einen Benutzer:**

1. Wählen Sie die Zeile des Benutzers aus
2. Klicken Sie auf `Drop user`
3. Bestätigen Sie im Dialogfeld


## Laden

Behalten Sie die Cluster-Aktivität auf einen Blick im Auge. Die Registerkarte zeigt eine Reihe von Zählern (aktive Abfragen, aktueller Durchsatz) mit einer darunter liegenden Sparkline, die im selben Abfrageintervall wie die Registerkarte **Abfragen** aktualisiert wird.


## Administrator

Prüfen Sie den Status der Rechen-Workloads und starten Sie die Warehouse-Rechenleistung bei Bedarf neu.

Die Workload-Tabelle listet jede Komponente mit ihrem aktuellen Status auf. Im Abschnitt **Rollierender Neustart** können Sie die Compute-Pods des ausgewählten Warehouses nacheinander neu starten.

**So starten Sie die Rechenleistung neu:**

1. Öffnen Sie **Lakehouse > Administrator**
2. Lesen Sie den Warnhinweis zu möglichen Unterbrechungen
3. Geben Sie die Warehouse-ID in das Bestätigungsfeld ein
4. Klicken Sie auf `Restart compute`

Eine Wartezeit zwischen Neustarts verhindert versehentliche schnelle Wiederholungen. Die verbleibende Wartezeit wird neben der Schaltfläche angezeigt.

<Aside>Ein rollierender Neustart unterbricht aktive Sitzungen kurzzeitig. Stimmen Sie sich vor der Bestätigung mit den Benutzern ab.</Aside>

<Aside title="Inaktives Herunterskalieren und laufende Abfragen">Das automatische Herunterskalieren bei Inaktivität (siehe **Warehouses** oben) greift erst nach einem längeren Zeitraum ohne Abfrageaktivität und unterbricht daher nie eine laufende Abfrage. Wenn das Warehouse eines bestimmten Workspace jederzeit mit voller Kapazität laufen soll, wenden Sie sich an den PlaidCloud-Support, damit die Funktion für diesen Workspace deaktiviert wird.</Aside>
