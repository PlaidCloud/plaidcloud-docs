## Wo Sie die maßgebliche Syntax nachschlagen

PlaidCloud Lakehouse verwendet die SQL-Funktionsbibliotheken der zugrunde liegenden Engines. Details zu den Argumenten einer Funktion, zu Sonderfällen und zum aktuellsten Verhalten finden Sie in der Upstream-Dokumentation, ergänzend zu den PlaidCloud-spezifischen Beispielen hier.

- **Lakehouse v1** → [SQL-Funktionsreferenz von Databend](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [SQL-Funktionsreferenz von StarRocks](https://docs.starrocks.io/docs/sql-reference/sql-functions/) (PlaidCloud Lakehouse v2 folgt StarRocks 4.1)
