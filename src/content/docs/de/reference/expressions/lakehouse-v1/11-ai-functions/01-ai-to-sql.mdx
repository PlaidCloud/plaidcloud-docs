Wandelt Anweisungen in natürlicher Sprache mit dem aktuellen Modell `text-davinci-003` in SQL-Abfragen um.

PlaidCloud Lakehouse bietet eine effiziente Lösung zum Erstellen von SQL-Abfragen, indem OLAP und KI kombiniert werden. Mit dieser Funktion lassen sich in natürlicher Sprache formulierte Anweisungen in SQL-Abfrageanweisungen umwandeln, die zum Tabellenschema passen. Die Funktion kann beispielsweise einen Satz wie "Get all items that cost 10 dollars or less" als Eingabe erhalten und daraus die entsprechende SQL-Abfrage "SELECT * FROM items WHERE price &lt;= 10" als Ausgabe erzeugen.

Siehe die [Upstream-Implementierung](https://github.com/datafuselabs/databend/blob/1e93c5b562bd159ecb0f336bb88fd1b7f9dc4a62/src/query/service/src/table_functions/openai/ai_to_sql.rs).

<Aside>Die generierten SQL-Abfrageanweisungen folgen den PostgreSQL-Standards und müssen daher möglicherweise manuell an die Syntax von PlaidCloud Lakehouse angepasst werden.</Aside>

<Aside>Ab PlaidCloud Lakehouse v1.1.47 unterstützt PlaidCloud Lakehouse den [Azure-OpenAI-Dienst](https://azure.microsoft.com/en-au/products/cognitive-services/openai-service). Diese Integration bietet einen besseren Datenschutz. Um Azure OpenAI zu verwenden, fügen Sie dem Abschnitt `[query]` die folgenden Konfigurationen hinzu: ```sql # Azure OpenAI openai_api_chat_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_embedding_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_version = "2023-03-15-preview" ```</Aside>

<Aside type="caution">PlaidCloud Lakehouse nutzt für `AI_TO_SQL` (Azure) OpenAI, sendet jedoch nur das Tabellenschema an (Azure) OpenAI, nicht die Daten. Die Funktion arbeitet nur, wenn die PlaidCloud-Lakehouse-Konfiguration den `openai_api_key` enthält, andernfalls ist sie inaktiv. Diese Funktion ist in PlaidCloud Lakehouse standardmäßig mit einem Azure-OpenAI-Schlüssel verfügbar. Wenn Sie sie verwenden, erkennen Sie an, dass Ihr Tabellenschema von uns an Azure OpenAI gesendet wird.</Aside>

## Analyze-Syntax

```python
func.ai_to_sql('<natural-language-instruction>')
```

## Analyze-Beispiele

In diesem Beispiel wird mit der Funktion AI_TO_SQL aus einer Anweisung eine SQL-Abfrageanweisung generiert. Die resultierende Anweisung wird anschließend ausgeführt, um die Abfrageergebnisse zu erhalten.

```python
func.ai_to_sql('List the total amount spent by users from the USA who are older than 30 years, grouped by their names, along with the number of orders they made in 2022')
```

Die Funktion gibt als Ausgabe eine SQL-Anweisung zurück:

```sql
*************************** 1. row ***************************
     database: openai
generated_sql: SELECT name, SUM(price) AS total_spent, COUNT(order_id) AS total_orders
               FROM users
                        JOIN orders ON users.id = orders.user_id
               WHERE country = 'USA' AND age > 30 AND order_date BETWEEN '2022-01-01' AND '2022-12-31'
               GROUP BY name;
```

## SQL-Syntax

```sql
USE <your-database>;
SELECT * FROM ai_to_sql('<natural-language-instruction>');
```

<Aside>OpenAI-API-Schlüssel beziehen und konfigurieren - Um Ihren OpenAI-API-Schlüssel zu erhalten, besuchen Sie https://platform.openai.com/account/api-keys und generieren Sie einen neuen Schlüssel. - Konfigurieren Sie die Datei **databend-query.toml** mit der Einstellung openai_api_key. ```toml [query] ... ... openai_api_key = "<your-key>" ```</Aside>

## SQL-Beispiele

In diesem Beispiel wird mit der Funktion AI_TO_SQL aus einer Anweisung eine SQL-Abfrageanweisung generiert. Die resultierende Anweisung wird anschließend ausgeführt, um die Abfrageergebnisse zu erhalten.

1. Bereiten Sie die Daten vor.

```sql
CREATE DATABASE IF NOT EXISTS openai;
USE openai;

CREATE TABLE users(
    id INT,
    name VARCHAR,
    age INT,
    country VARCHAR
);

CREATE TABLE orders(
    order_id INT,
    user_id INT,
    product_name VARCHAR,
    price DECIMAL(10,2),
    order_date DATE
);

-- Insert sample data into the users table
INSERT INTO users VALUES (1, 'Alice', 31, 'USA'),
                         (2, 'Bob', 32, 'USA'),
                         (3, 'Charlie', 45, 'USA'),
                         (4, 'Diana', 29, 'USA'),
                         (5, 'Eva', 35, 'Canada');

-- Insert sample data into the orders table
INSERT INTO orders VALUES (1, 1, 'iPhone', 1000.00, '2022-03-05'),
                          (2, 1, 'OpenAI Plus', 20.00, '2022-03-06'),
                          (3, 2, 'OpenAI Plus', 20.00, '2022-03-07'),
                          (4, 2, 'MacBook Pro', 2000.00, '2022-03-10'),
                          (5, 3, 'iPad', 500.00, '2022-03-12'),
                          (6, 3, 'AirPods', 200.00, '2022-03-14');
```

2. Führen Sie die Funktion AI_TO_SQL mit einer in englischer Sprache formulierten Anweisung als Eingabe aus.

```sql
SELECT * FROM ai_to_sql(
    'List the total amount spent by users from the USA who are older than 30 years, grouped by their names, along with the number of orders they made in 2022');
```

Die Funktion gibt als Ausgabe eine SQL-Anweisung zurück:

```sql
*************************** 1. row ***************************
     database: openai
generated_sql: SELECT name, SUM(price) AS total_spent, COUNT(order_id) AS total_orders
               FROM users
                        JOIN orders ON users.id = orders.user_id
               WHERE country = 'USA' AND age > 30 AND order_date BETWEEN '2022-01-01' AND '2022-12-31'
               GROUP BY name;
```

3. Führen Sie die generierte SQL-Anweisung aus, um die Abfrageergebnisse zu erhalten.

```sql
┌─────────┬─────────────┬─────────────┐
│ name    │ order_count │ total_spent │
├─────────┼─────────────┼─────────────┤
│ Bob     │           2 │     2020.00 │
│ Alice   │           2 │     1020.00 │
│ Charlie │           2 │      700.00 │
└─────────┴─────────────┴─────────────┘
```
