Dieses Dokument bietet einen Überblick über die Funktion ai_embedding_vector in PlaidCloud Lakehouse und zeigt, wie Sie mit ihr Dokument-Embeddings erstellen.

Siehe die [Upstream-Implementierung](https://github.com/datafuselabs/databend/blob/1e93c5b562bd159ecb0f336bb88fd1b7f9dc4a62/src/common/openai/src/embedding.rs).

Standardmäßig verwendet PlaidCloud Lakehouse das Modell [text-embedding-ada](https://platform.openai.com/docs/models/embeddings), um Embeddings zu erzeugen.

<Aside>Ab PlaidCloud Lakehouse v1.1.47 unterstützt PlaidCloud Lakehouse den [Azure-OpenAI-Dienst](https://azure.microsoft.com/en-au/products/cognitive-services/openai-service). Diese Integration bietet einen besseren Datenschutz. Um Azure OpenAI zu verwenden, fügen Sie dem Abschnitt `[query]` die folgenden Konfigurationen hinzu: ```sql # Azure OpenAI openai_api_chat_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_embedding_base_url = "https://<name>.openai.azure.com/openai/deployments/<name>/" openai_api_version = "2023-03-15-preview" ```</Aside>


<Aside type="caution">PlaidCloud Lakehouse nutzt für `AI_EMBEDDING_VECTOR` (Azure) OpenAI und sendet die Daten der Embedding-Spalte an (Azure) OpenAI. Die Funktion arbeitet nur, wenn die PlaidCloud-Lakehouse-Konfiguration den `openai_api_key` enthält, andernfalls ist sie inaktiv. Diese Funktion ist in PlaidCloud Lakehouse standardmäßig mit einem Azure-OpenAI-Schlüssel verfügbar. Wenn Sie sie verwenden, erkennen Sie an, dass Ihre Daten von uns an Azure OpenAI gesendet werden.</Aside>

## Überblick über Ai_embedding_vector

Die Funktion `ai_embedding_vector` in PlaidCloud Lakehouse ist eine integrierte Funktion, die Vektor-Embeddings für Textdaten erzeugt. Sie ist nützlich für Aufgaben der Verarbeitung natürlicher Sprache, etwa Dokumentähnlichkeit, Clustering und Empfehlungssysteme.

Die Funktion nimmt eine Texteingabe entgegen und gibt einen hochdimensionalen Vektor zurück, der die semantische Bedeutung und den Kontext des Eingabetexts repräsentiert. Die Embeddings werden mit vortrainierten Modellen auf großen Textkorpora erstellt und bilden die Beziehungen zwischen Wörtern und Phrasen in einem kontinuierlichen Raum ab.

## Embeddings mit Ai_embedding_vector erstellen

Um mit der Funktion `ai_embedding_vector` Embeddings für ein Textdokument zu erstellen, folgen Sie dem nachstehenden Beispiel.
1. Erstellen Sie eine Tabelle zum Speichern der Dokumente:
```sql
CREATE TABLE documents (
                           id INT,
                           title VARCHAR,
                           content VARCHAR,
                           embedding ARRAY(FLOAT32)
);
```

2. Fügen Sie der Tabelle Beispieldokumente hinzu:
```sql
INSERT INTO documents(id, title, content)
VALUES
    (1, 'A Brief History of AI', 'Artificial intelligence (AI) has been a fascinating concept of science fiction for decades...'),
    (2, 'Machine Learning vs. Deep Learning', 'Machine learning and deep learning are two subsets of artificial intelligence...'),
    (3, 'Neural Networks Explained', 'A neural network is a series of algorithms that endeavors to recognize underlying relationships...'),
```

3. Generieren Sie die Embeddings:
```sql
UPDATE documents SET embedding = ai_embedding_vector(content) WHERE length(embedding) = 0;
```
Nach der Ausführung der Abfrage enthält die Embedding-Spalte der Tabelle die generierten Embeddings.

Die Embeddings werden als Array von `FLOAT32`-Werten in der Embedding-Spalte gespeichert, die den Spaltentyp `ARRAY(FLOAT32)` hat.

Sie können diese Embeddings nun für verschiedene Aufgaben der Verarbeitung natürlicher Sprache verwenden, etwa um ähnliche Dokumente zu finden oder Dokumente anhand ihres Inhalts zu clustern.

4. Prüfen Sie die Embeddings:

```sql
SELECT length(embedding) FROM documents;
┌───────────────────┐
│ length(embedding) │
├───────────────────┤
│              1536 │
│              1536 │
│              1536 │
└───────────────────┘
```
Die obige Abfrage zeigt, dass die generierten Embeddings für jedes Dokument eine Länge von 1536 (Dimensionen) haben.
