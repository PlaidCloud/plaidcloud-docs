Gibt den „hohlen“ Ring von Hexagonen im Rasterabstand von genau `k` vom angegebenen [H3](https://eng.uber.com/h3/)-Index zurück.

## Analyze-Syntax

```python
func.h3_hex_ring(h3, k)
```
