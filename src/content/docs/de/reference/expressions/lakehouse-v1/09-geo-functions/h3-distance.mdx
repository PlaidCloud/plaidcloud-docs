Gibt den Rasterabstand zwischen den beiden angegebenen [H3](https://eng.uber.com/h3/)-Indizes zurück.

<Aside>Mit H3-Abstandsberechnungen lassen sich nur Abstände zwischen Hexagonen berechnen, die Nachbarn sind. Die Verwendung mit Hexagonen, die keine Nachbarn sind, führt zu einem Fehler.</Aside>

### Analyze-Syntax

```python
func.h3_distance(h3, a_h3)
```

## Analyze-Beispiele

```python
func.h3_distance(599119489002373119, 599119491149856767)

┌──────────────────────────────────────────────────────────┐
│ func.h3_distance(599119489002373119, 599119491149856767) │
├──────────────────────────────────────────────────────────┤
│                                                        1 │
└──────────────────────────────────────────────────────────┘
```

## SQL-Syntax

```sql
H3_DISTANCE(h3, a_h3)
```

## SQL-Beispiele

```sql
SELECT H3_DISTANCE(599119489002373119, 599119491149856767);

┌─────────────────────────────────────────────────────┐
│ h3_distance(599119489002373119, 599119491149856767) │
├─────────────────────────────────────────────────────┤
│                                                   1 │
└─────────────────────────────────────────────────────┘
```
