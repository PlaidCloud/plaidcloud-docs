Gibt ein Array mit den [H3](https://eng.uber.com/h3/)-Indizes der k-Ring-Hexagone zurück, die den eingegebenen H3-Index umgeben. Jedes Element dieses Arrays ist ein H3-Index.

## Analyze-Syntax

```python
func.h3_k_ring(h3, k)
```

## Analyze-Beispiele

```python
func.h3_k_ring(644325524701193974, 1)

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                                  func.h3_k_ring(644325524701193974, 1)                                                 │
├────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ [644325524701193974,644325524701193899,644325524701193869,644325524701193970,644325524701193968,644325524701193972,644325524701193897] │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## SQL-Syntax

```sql
H3_K_RING(h3, k)
```
