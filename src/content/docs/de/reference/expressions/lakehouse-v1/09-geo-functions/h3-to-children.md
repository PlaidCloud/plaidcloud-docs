Gibt die von `h3` bei der Auflösung `child_res` enthaltenen Indizes zurück.

## Analyze-Syntax

```python
func.h3_to_children(h3, child_res)
```

## Analyze-Beispiele


## SQL-Syntax

```sql
H3_TO_CHILDREN(h3, child_res)
```
