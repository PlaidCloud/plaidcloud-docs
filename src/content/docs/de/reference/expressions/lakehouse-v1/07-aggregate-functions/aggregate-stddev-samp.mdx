Aggregatfunktion.

Die Funktion STDDEV_SAMP() gibt die Stichproben-Standardabweichung (die Quadratwurzel von VAR_SAMP()) eines Ausdrucks zurück.

<Aside type="caution">NULL-Werte werden nicht mitgezählt.</Aside>

## Analyze-Syntax

```python
func.stddev_samp(<expr>)
```

## Analyze-Beispiele

```python
func.stddev_samp(table.height).alias('height_stddev_samp')

| height_stddev_samp |
|--------------------|
|      0.240         |
```

## SQL-Syntax

```sql
STDDEV_SAMP(<expr>)
```

## Argumente

| Argumente | Beschreibung             |
|-----------|--------------------------|
| `<expr>`  | Beliebiger numerischer Ausdruck |

## Rückgabetyp

double

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**
```sql
CREATE TABLE height_data (
  id INT,
  person_id INT,
  height FLOAT
);

INSERT INTO height_data (id, person_id, height)
VALUES (1, 1, 5.8),
       (2, 2, 6.1),
       (3, 3, 5.9),
       (4, 4, 5.7),
       (5, 5, 6.3);
```

**Abfragedemo: Stichproben-Standardabweichung der Körpergrößen berechnen**
```sql
SELECT STDDEV_SAMP(height) AS height_stddev_samp
FROM height_data;
```

**Ergebnis**
```sql
| height_stddev_samp |
|--------------------|
|      0.240         |
```
