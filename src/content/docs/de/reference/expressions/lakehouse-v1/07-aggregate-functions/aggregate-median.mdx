Aggregatfunktion.

Die Funktion MEDIAN() berechnet den Median einer numerischen Datenfolge.

<Aside type="caution">NULL-Werte werden nicht mitgezählt.</Aside>

## Analyze-Syntax

```python
func.median(<expr>)
```

## Analyze-Beispiele

```python
func.median(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## SQL-Syntax

```sql
MEDIAN(<expr>)
```

## Argumente

| Argumente | Beschreibung             |
|-----------|--------------------------|
| `<expr>`  | Beliebiger numerischer Ausdruck |

## Rückgabetyp

Der Typ des Werts.

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**
```sql
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);
```

**Abfragedemo: Median der Prüfungsergebnisse berechnen**
```sql
SELECT MEDIAN(score) AS median_score
FROM exam_scores;
```

**Ergebnis**
```sql
|  median_score  |
|----------------|
|      85.0      |
```
