Aggregatfunktion.

Die Funktion STDDEV_POP() gibt die Grundgesamtheits-Standardabweichung (die Quadratwurzel von VAR_POP()) eines Ausdrucks zurück.

<Aside>Es können auch STD() oder STDDEV() verwendet werden; sie sind gleichwertig, aber kein Standard-SQL.</Aside>

<Aside type="caution">NULL-Werte werden nicht mitgezählt.</Aside>

## Analyze-Syntax

```python
func.stddev_pop(<expr>)
```

## Analyze-Beispiele

```python
func.stddev_pop(table.score).alias('test_score_stddev_pop')

| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```

## SQL-Syntax

```sql
STDDEV_POP(<expr>)
STDDEV(<expr>)
STD(<expr>)
```

## Argumente

| Argumente | Beschreibung             |
|-----------|--------------------------|
| `<expr>`  | Beliebiger numerischer Ausdruck |

## Rückgabetyp

double

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**
```sql
CREATE TABLE test_scores (
  id INT,
  student_id INT,
  score FLOAT
);

INSERT INTO test_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 85),
       (3, 3, 90),
       (4, 4, 95),
       (5, 5, 100);
```

**Abfragedemo: Grundgesamtheits-Standardabweichung der Testergebnisse berechnen**
```sql
SELECT STDDEV_POP(score) AS test_score_stddev_pop
FROM test_scores;
```

**Ergebnis**
```sql
| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```
