Aggregatfunktion.

Die Funktion QUANTILE_CONT() berechnet das interpolierte Quantil einer numerischen Datenfolge.

<Aside type="caution">NULL-Werte werden nicht mitgezählt.</Aside>

## Analyze-Syntax

```python
func.quantile_cont(<levels>, <expr>)
```

## Analyze-Beispiele

```python
func.quantile_cont(0.5, table.sales_amount).alias('median_sales_amount')

|  median_sales_amount  |
|-----------------------|
|        6000.0         |
```

## SQL-Syntax

```sql
QUANTILE_CONT(<levels>)(<expr>)
    
QUANTILE_CONT(level1, level2, ...)(<expr>)
```

## Argumente

| Argumente   | Beschreibung                                                                                                                                    |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `<level(s)` | Stufe(n) des Quantils. Jede Stufe ist eine konstante Gleitkommazahl von 0 bis 1. Wir empfehlen einen Stufenwert im Bereich [0.01, 0.99]   |
| `<expr>`    | Beliebiger numerischer Ausdruck                                                                                                                 |

## Rückgabetyp

Float64 oder Float64-Array, abhängig von der Anzahl der Stufen.

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**
```sql
CREATE TABLE sales_data (
  id INT,
  sales_person_id INT,
  sales_amount FLOAT
);

INSERT INTO sales_data (id, sales_person_id, sales_amount)
VALUES (1, 1, 5000),
       (2, 2, 5500),
       (3, 3, 6000),
       (4, 4, 6500),
       (5, 5, 7000);
```

**Abfragedemo: 50. Perzentil (Median) des Umsatzbetrags mit Interpolation berechnen**
```sql
SELECT QUANTILE_CONT(0.5)(sales_amount) AS median_sales_amount
FROM sales_data;
```

**Ergebnis**
```sql
|  median_sales_amount  |
|-----------------------|
|        6000.0         |
```
