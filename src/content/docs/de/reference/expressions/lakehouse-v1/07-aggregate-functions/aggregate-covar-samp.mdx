Aggregatfunktion.

Die Funktion covar_samp() gibt die Stichprobenkovarianz (Σ((x - x̅)(y - y̅)) / (n - 1)) zweier Datenspalten zurück.

<Aside type="caution">NULL-Werte werden nicht mitgezählt.</Aside>

## Analyze-Syntax

```python
func.covar_samp(<expr1>, <expr2>)
```

## Analyze-Beispiele

```python
func.covar_samp(table.items_sold, table.profit).alias('covar_samp_items_profit')

| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```

## SQL-Syntax

```sql
COVAR_SAMP(<expr1>, <expr2>)
```

## Argumente

| Argumente |        Beschreibung      |
|-----------| ------------------------ |
| `<expr1>` | Beliebiger numerischer Ausdruck |
| `<expr2>` | Beliebiger numerischer Ausdruck |

## Rückgabetyp

float64; bei n &lt;= 1 wird +∞ zurückgegeben.

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**

```sql
CREATE TABLE store_sales (
  id INT,
  store_id INT,
  items_sold INT,
  profit FLOAT
);

INSERT INTO store_sales (id, store_id, items_sold, profit)
VALUES (1, 1, 100, 1000),
       (2, 2, 200, 2000),
       (3, 3, 300, 3000),
       (4, 4, 400, 4000),
       (5, 5, 500, 5000);
```

**Abfragedemo: Stichprobenkovarianz zwischen verkauften Artikeln und Gewinn berechnen**

```sql
SELECT COVAR_SAMP(items_sold, profit) AS covar_samp_items_profit
FROM store_sales;
```

**Ergebnis**

```sql
| covar_samp_items_profit |
|-------------------------|
|        250000.0         |
```
