Aggregatfunktion.

Die Funktion SUM() berechnet die Summe einer Wertemenge.

<Aside type="caution">NULL-Werte werden nicht mitgezählt.</Aside>


## Analyze-Syntax

```python
func.sum(<column>)
```

## Analyze-Beispiele

```python
func.sum(table.quantity).alias('total_quantity_sold')

| total_quantity_sold |
|---------------------|
|         41          |
```

## SQL-Syntax

```sql
SUM(<expr>)
```

## Argumente

| Argumente | Beschreibung             |
|-----------|--------------------------|
| `<expr>`  | Beliebiger numerischer Ausdruck |

## Rückgabetyp

Ein double, wenn der Eingabetyp double ist, andernfalls eine Ganzzahl.

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**
```sql
CREATE TABLE sales_data (
  id INT,
  product_id INT,
  quantity INT
);

INSERT INTO sales_data (id, product_id, quantity)
VALUES (1, 1, 10),
       (2, 2, 5),
       (3, 3, 8),
       (4, 4, 3),
       (5, 5, 15);
```

**Abfragedemo: Gesamtmenge der verkauften Produkte berechnen**
```sql
SELECT SUM(quantity) AS total_quantity_sold
FROM sales_data;
```

**Ergebnis**
```sql
| total_quantity_sold |
|---------------------|
|         41          |
```
