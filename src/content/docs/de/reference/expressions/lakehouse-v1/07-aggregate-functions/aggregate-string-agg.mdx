Aggregatfunktion.

Die Funktion STRING_AGG() wandelt alle Werte ungleich NULL einer Spalte in eine Zeichenfolge um, getrennt durch das Trennzeichen.

## Analyze-Syntax

```python
func.string_agg(<expr> [, delimiter])
```

## Analyze-Beispiele

```python
func.string_agg(table.language_name).alias('concatenated_languages')

|          concatenated_languages         |
|-----------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```

## SQL-Syntax

```sql
STRING_AGG(<expr>)
STRING_AGG(<expr> [, delimiter])
```

<Aside>Wenn `<expr>` kein Zeichenfolgenausdruck ist, verwenden Sie `::VARCHAR` zur Konvertierung. Beispiel: ```sql SELECT string_agg(number::VARCHAR, '|') AS s FROM numbers(5); ┌───────────┐ │ s │ ├───────────┤ │ 0│1│2│3│4 │ └───────────┘ ```</Aside>

## Argumente

| Argumente   | Beschreibung                                                        |
|-------------|---------------------------------------------------------------------|
| `<expr>`    | Beliebiger Zeichenfolgenausdruck (falls keine Zeichenfolge, mit `::VARCHAR` konvertieren) |
| `delimiter` | Optionale konstante Zeichenfolge; wenn nicht angegeben, wird eine leere Zeichenfolge verwendet |

## Rückgabetyp

Der Zeichenfolgentyp

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**

```sql
CREATE TABLE programming_languages (
  id INT,
  language_name VARCHAR
);

INSERT INTO programming_languages (id, language_name)
VALUES (1, 'Python'),
       (2, 'JavaScript'),
       (3, 'Java'),
       (4, 'C#'),
       (5, 'Ruby');
```

**Abfragedemo: Namen von Programmiersprachen mit einem Trennzeichen verketten**
```sql
SELECT STRING_AGG(language_name, ', ') AS concatenated_languages
FROM programming_languages;
```

**Ergebnis**
```sql
|          concatenated_languages         |
|------------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```
