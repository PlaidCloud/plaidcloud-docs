Berechnet den Median einer numerischen Datenfolge mit dem [t-digest](https://github.com/tdunning/t-digest/blob/master/docs/t-digest-paper/histo.pdf)-Algorithmus.

<Aside type="caution">NULL-Werte werden in die Berechnung nicht einbezogen.</Aside>

## Analyze-Syntax

```python
func.median_tdigest(<expr>)
```

## Analyze-Beispiele

```python
func.median_tdigest(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## SQL-Syntax

```sql
MEDIAN_TDIGEST(<expr>)
```

## Argumente

| Argumente | Beschreibung             |
|-----------|--------------------------|
| `<expr>`  | Beliebiger numerischer Ausdruck |

## Rückgabetyp

Gibt einen Wert mit demselben Datentyp wie die Eingabewerte zurück.

## SQL-Beispiele

```sql
-- Create a table and insert sample data
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);

-- Calculate median exam score
SELECT MEDIAN_TDIGEST(score) AS median_score
FROM exam_scores;

|  median_score  |
|----------------|
|      85.0      |
```
