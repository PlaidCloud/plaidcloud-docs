Aggregatfunktion.

Die Funktion count(distinct ...) berechnet die Anzahl der eindeutigen Werte in einer Wertemenge.

Um bei großen Datensätzen mit wenig Speicher und Zeit ein geschätztes Ergebnis zu erhalten, erwägen Sie [APPROX_COUNT_DISTINCT](../aggregate-approx-count-distinct).

<Aside type="caution">NULL-Werte werden nicht mitgezählt.</Aside>

## Analyze-Syntax

```python
func.count_distinct(<column>)
```

## Analyze-Beispiele

```python
func.count_distinct(table.category).alias('unique_categories')

| unique_categories |
|-------------------|
|         2         |
```

## SQL-Syntax

```sql
COUNT(distinct <expr> ...)
UNIQ(<expr>)
```

## Argumente

| Argumente | Beschreibung                                     |
|-----------|--------------------------------------------------|
| `<expr>`  | Beliebiger Ausdruck, Anzahl der Argumente im Bereich [1, 32] |

## Rückgabetyp

UInt64

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**
```sql
CREATE TABLE products (
  id INT,
  name VARCHAR,
  category VARCHAR,
  price FLOAT
);

INSERT INTO products (id, name, category, price)
VALUES (1, 'Laptop', 'Electronics', 1000),
       (2, 'Smartphone', 'Electronics', 800),
       (3, 'Tablet', 'Electronics', 600),
       (4, 'Chair', 'Furniture', 150),
       (5, 'Table', 'Furniture', 300);
```

**Abfragedemo: Eindeutige Kategorien zählen**

```sql
SELECT COUNT(DISTINCT category) AS unique_categories
FROM products;
```

**Ergebnis**
```sql
| unique_categories |
|-------------------|
|         2         |
```
