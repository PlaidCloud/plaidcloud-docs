Die Funktion COUNT() gibt die Anzahl der Datensätze zurück, die eine SELECT-Abfrage liefert.

<Aside type="caution">NULL-Werte werden nicht mitgezählt.</Aside>

## Analyze-Syntax

```python
func.count(<column>)
```

## Analyze-Beispiele

```python
func.count(table.grade).alias('count_valid_grades')

| count_valid_grades |
|--------------------|
|          4         |
```

## SQL-Syntax

```sql
COUNT(<expr>)
```

## Argumente

| Argumente | Beschreibung                                                                                                                                                    |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<expr>`  | Beliebiger Ausdruck. <br /> Dies kann ein Spaltenname, das Ergebnis einer anderen Funktion oder eine mathematische Operation sein.<br />`*` ist ebenfalls zulässig und steht für reines Zeilenzählen. |

## Rückgabetyp

Eine Ganzzahl.

## SQL-Beispiele

**Tabelle erstellen und Beispieldaten einfügen**
```sql
CREATE TABLE students (
  id INT,
  name VARCHAR,
  age INT,
  grade FLOAT NULL
);

INSERT INTO students (id, name, age, grade)
VALUES (1, 'John', 21, 85),
       (2, 'Emma', 22, NULL),
       (3, 'Alice', 23, 90),
       (4, 'Michael', 21, 88),
       (5, 'Sophie', 22, 92);

```

**Abfragedemo: Studierende mit gültigen Noten zählen**
```sql
SELECT COUNT(grade) AS count_valid_grades
FROM students;
```

**Ergebnis**
```sql
| count_valid_grades |
|--------------------|
|          4         |
```
