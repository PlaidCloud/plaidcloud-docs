Erzeugt den Soundex-Code für eine Zeichenfolge.

- Ein Soundex-Code besteht aus einem Buchstaben, gefolgt von drei Ziffern. Die Implementierung in PlaidCloud Lakehouse gibt mehr als 4 Ziffern zurück, Sie können das Ergebnis aber mit [SUBSTR](../substr) kürzen, um einen Standard-Soundex-Code zu erhalten.
- Alle nicht alphabetischen Zeichen in der Zeichenfolge werden ignoriert.
- Alle internationalen alphabetischen Zeichen außerhalb des Bereichs A–Z werden ignoriert, es sei denn, sie sind der erste Buchstabe.


<Aside>Was ist Soundex? Soundex wandelt eine alphanumerische Zeichenfolge in einen vierstelligen Code um, der darauf basiert, wie die Zeichenfolge im Englischen ausgesprochen klingt. Weitere Informationen finden Sie unter https://en.wikipedia.org/wiki/Soundex</Aside>

Siehe auch: [SOUNDS LIKE](../soundslike)

## Analyze-Syntax

```python
func.soundex(<str>)
```

## Analyze-Beispiele

```python
func.soundex('PlaidCloud Lakehouse')
┌──────────────────────────────────────┐
│ func.soundex('PlaidCloud Lakehouse') │
├──────────────────────────────────────┤
│ D153                                 │
└──────────────────────────────────────┘
```

## SQL-Syntax

```sql
SOUNDEX(<str>)
```

## Argumente

| Argumente | Beschreibung      |
|-----------|-------------------|
| str  | Die Zeichenfolge. |

## Rückgabetyp

Gibt einen Code vom Typ VARCHAR oder den Wert NULL zurück.

## SQL-Beispiele

```sql
SELECT SOUNDEX('PlaidCloud Lakehouse');

---
D153

-- All non-alphabetic characters in the string are ignored.
SELECT SOUNDEX('PlaidCloud Lakehouse!');

---
D153

-- All international alphabetic characters outside the A-Z range are ignored unless they're the first letter.
SELECT SOUNDEX('PlaidCloud Lakehouse，你好');

---
D153

SELECT SOUNDEX('你好，PlaidCloud Lakehouse');

---
你3153

-- SUBSTR the result to get a standard Soundex code.
SELECT SOUNDEX('databend cloud'),SUBSTR(SOUNDEX('databend cloud'),1,4);

soundex('databend cloud')|substring(soundex('databend cloud') from 1 for 4)|
-------------------------+-------------------------------------------------+
D153243                  |D153                                             |

SELECT SOUNDEX(NULL);
┌─────────────────────────────────────┐
│ `SOUNDEX(NULL)`                     │
├─────────────────────────────────────┤
│ <null>                              │
└─────────────────────────────────────┘
```
