Vergleicht die Aussprache zweier Zeichenfolgen anhand ihrer Soundex-Codes. Soundex ist ein phonetischer Algorithmus, der einen Code erzeugt, der die Aussprache einer Zeichenfolge darstellt. So lassen sich Zeichenfolgen näherungsweise nach ihrer Aussprache statt nach ihrer Schreibweise abgleichen. PlaidCloud Lakehouse bietet die Funktion [SOUNDEX](../soundex), mit der Sie den Soundex-Code einer Zeichenfolge ermitteln können.

SOUNDS LIKE wird häufig in der WHERE-Klausel von SQL-Abfragen eingesetzt, um Zeilen per unscharfem Zeichenfolgenabgleich einzugrenzen, etwa bei Namen und Adressen. Siehe [Zeilen filtern](#zeilen-filtern) in den [Beispielen](#sql-beispiele).

<Aside>Die Funktion ist für den näherungsweisen Zeichenfolgenabgleich nützlich, ist aber nicht immer genau. Der Soundex-Algorithmus basiert auf den Ausspracheregeln des Englischen und funktioniert bei Zeichenfolgen aus anderen Sprachen oder Dialekten unter Umständen nicht gut.</Aside>

## Analyze-Syntax

```python
func.sounds_like(<str1>, <str2>)
```

## Analyze-Beispiele

```python
func..sounds_like('Monday', 'Sunday')
┌───────────────────────────────────────┐
│ func..sounds_like('Monday', 'Sunday') │
├───────────────────────────────────────┤
│                                     0 │
└───────────────────────────────────────┘
```

## SQL-Syntax

```sql
<str1> SOUNDS LIKE <str2>
```

## Argumente

| Argumente | Beschreibung |
|-----------|-------------|
| str1, 2   | Die Zeichenfolgen, die Sie vergleichen. |

## Rückgabetyp

Gibt den booleschen Wert 1 zurück, wenn die Soundex-Codes der beiden Zeichenfolgen identisch sind (sie also ähnlich klingen), andernfalls 0.

## SQL-Beispiele

### Zeichenfolgen vergleichen

```sql
SELECT 'two' SOUNDS LIKE 'too'
----
1

SELECT CONCAT('A', 'B') SOUNDS LIKE 'AB';
----
1

SELECT 'Monday' SOUNDS LIKE 'Sunday';
----
0
```

### Zeilen filtern

```sql
SELECT * FROM  employees;

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Mark      |Smythe   | 28|
 0|Johann    |Schmidt  | 51|
 0|Eric      |Doe      | 30|
 0|Sue       |Johnson  | 45|


SELECT * FROM  employees
WHERE  first_name SOUNDS LIKE 'John';

id|first_name|last_name|age|
--+----------+---------+---+
 0|John      |Smith    | 35|
 0|Johann    |Schmidt  | 51|
```
