Extrahiert Schlüssel-Wert-Paare aus einem JSON-Objekt und zerlegt die Struktur in einzelne Zeilen der Ergebnismenge. Jede Zeile stellt ein eigenes Schlüssel-Wert-Paar dar, das aus dem JSON-Eingabeausdruck stammt.

## Analyze Syntax

```python
func.json_each(<json_string>)
```

## Analyze Examples

```python

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ func.json_each(func.parse_json('{"name": "john", "age": 25, "isstudent": false, "grades": [90, 85, 92]}')) │
├────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ ('age','25')                                                                                               │
│ ('grades','[90,85,92]')                                                                                    │
│ ('isStudent','false')                                                                                      │
│ ('name','"John"')                                                                                          │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## SQL Syntax

```sql
JSON_EACH(<json_string>)
```

## Return Type

JSON_EACH gibt eine Menge von Tupeln zurück, die jeweils aus einem STRING-Schlüssel und einem zugehörigen VARIANT-Wert bestehen.

## SQL Examples

```sql
-- Extract key-value pairs from a JSON object representing information about a person
SELECT
  JSON_EACH(
    PARSE_JSON (
      '{"name": "John", "age": 25, "isStudent": false, "grades": [90, 85, 92]}'
    )
  );


┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
```
