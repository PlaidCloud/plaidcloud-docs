Formatiert JSON-Daten, damit sie besser lesbar und übersichtlicher sind. Die Funktion fügt den JSON-Daten automatisch Einrückungen, Zeilenumbrüche und weitere Formatierungen für eine bessere Darstellung hinzu.

## Analyze Syntax

```python
func.json_pretty(<json_string>)
```

## Analyze Examples

```python
func.json_pretty(func.parse_json('{"person": {"name": "bob", "age": 25}, "location": "city"}'))

┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│ func.json_pretty(func.parse_json('{"person": {"name": "bob", "age": 25}, "location": "city"}')) │
│                                         String                                                  │
├─────────────────────────────────────────────────────────────────────────────────────────────────┤
│ {                                                                                               │
│   "location": "City",                                                                           │
│   "person": {                                                                                   │
│     "age": 25,                                                                                  │
│     "name": "Bob"                                                                               │
│   }                                                                                             │
│ }                                                                                               │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## SQL Syntax

```sql
JSON_PRETTY(<json_string>)
```

## Return Type

String.

## SQL Examples

```sql

│   "age": 30,                                         │
```
