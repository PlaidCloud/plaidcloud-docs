Wandelt ein GEOMETRY-Objekt in eine Zeichenfolgendarstellung um. Das Anzeigeformat der Ausgabedaten wird durch die Einstellung `geometry_output_format` gesteuert, die die folgenden Typen enthält:

| Parameter          | Beschreibung                                                                  |
|--------------------|-------------------------------------------------------------------------------|
| GeoJSON (Standard) | Das GEOMETRY-Ergebnis wird als JSON-Objekt im GeoJSON-Format dargestellt.     |
| WKT                | Das GEOMETRY-Ergebnis wird als String im WKT-Format dargestellt.             |
| WKB                | Das GEOMETRY-Ergebnis wird als Binary im WKB-Format dargestellt.              |
| EWKT               | Das GEOMETRY-Ergebnis wird als String im EWKT-Format dargestellt.             |
| EWKB               | Das GEOMETRY-Ergebnis wird als Binary im EWKB-Format dargestellt.             |

## SQL-Syntax

```sql
TO_STRING(<geometry>)
```

## Argumente

| Argumente    | Beschreibung                                          |
|--------------|-------------------------------------------------------|
| `<geometry>` | Das Argument muss ein Ausdruck vom Typ GEOMETRY sein. |

## Rückgabetyp

String.

## SQL-Beispiele

```sql
SET geometry_output_format='GeoJSON';

SELECT
  TO_GEOMETRY(
    ST_GEOMETRYFROMWKT(
      'SRID=4326;LINESTRING(400000 6000000, 401000 6010000)'
    )
  ) AS pipeline_geometry;
```
