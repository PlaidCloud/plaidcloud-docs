## Beschreibung



Sendet eine E-Mail-Benachrichtigung an eine PlaidCloud-Verteilerliste – eine benannte Empfängerliste, die in den Workspace-Einstellungen verwaltet wird. Nützlich für Statusmeldungen, Abschlussbenachrichtigungen oder Fehlerwarnungen, die einen definierten Empfängerkreis erreichen sollen.

Nachrichten werden vom Benachrichtigungsdienst von PlaidCloud gesendet. Verteilerlisten werden zentral verwaltet, sodass Workflow-Autoren keine E-Mail-Adressen in Workflow-Definitionen einbetten müssen.


## PlaidCloud-Verteilerliste auswählen


Wählen Sie im Dropdown-Menü eine einzelne Verteilerliste aus. Verteilerlisten können mit Tools erstellt werden. Einzelheiten zum Erstellen einer Verteilerliste finden Sie hier: [PlaidCloud Tools – Distro](/de/administration/access/member-management/#verteilerlisten-distros-verwalten).



## Nachricht


Geben Sie **Betreff** und **Body** nach Wunsch an.



Bitte beachten Sie, dass sowohl Projektvariablen als auch Workflow-Variablen in dieser Transformation verwendet werden können, sowohl in der Betreffzeile als auch im Nachrichtentext.



Zusätzlich ist im Body Standard-HTML-Code zulässig, um das Aussehen der E-Mail-Nachrichten weiter anzupassen.


## Beispiele


In diesem Beispiel werden alle Systemvariablen verwendet. Zusätzlich wird ein wenig HTML verwendet, um die erste Zeile des Body zu formatieren. Die Ausführung dieser Transformation sendet die folgende E-Mail an alle Mitglieder der angegebenen Verteilerliste:


* VON: [info@tartansolutions.com](mailto:info%40tartansolutions.com) (beachten Sie, dass alle Nachrichten von dieser Adresse kommen)
* Betreff: DEMO Analyze Demo Running


<Aside>Einzelne Empfänger der E-Mail-Nachricht können die Namen anderer Mitglieder der Verteilerliste **nicht** sehen.</Aside>
