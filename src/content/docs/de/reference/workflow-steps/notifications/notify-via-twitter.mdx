## Beschreibung


Senden Sie eine Twitter-Direktnachricht (DM) von [@plaidcloud](https://twitter.com/plaidcloud).



### Twitter-Konto


Geben Sie das Twitter-Konto an, das die DM von @plaidcloud erhalten soll. Dieser Benutzer muss @plaidcloud folgen, um die Nachricht zu erhalten. Dem Benutzernamen darf das At-Zeichen (@) vorangestellt werden, erforderlich ist es nicht.



### Nachricht


Geben Sie die gewünschte Nachricht ein. Analyze lässt keinen Wert mit mehr als 140 Zeichen zu.


Bitte beachten Sie, dass sowohl Projektvariablen als auch Workflow-Variablen in dieser Transformation verwendet werden können.


<Aside type="danger">Bei der Verwendung von Variablen können Nachrichten entstehen, die das Limit von 140 Zeichen überschreiten. In diesem Fall wird die Nachricht NICHT gesendet. Stattdessen wird der folgende Fehler in das Protokoll geschrieben: *Twitter API returned a 403 (Forbidden), There was an error sending your message: The text of your direct message is over 140 characters.</Aside>

## Beispiele

In diesem Beispiel wird eine DM von [@PlaidCloud](https://twitter.com/plaidcloud) an [@tartansolutions](https://twitter.com/tartansolutions) gesendet. In der Nachricht werden Systemvariablen verwendet. Die endgültige Nachricht lautet *Analyze Demo is running on #PlaidCloud*.
