## Beschreibung



Sendet eine Benachrichtigung per POST an eine Webhook-URL – nützlich, um eigene nachgelagerte Aktionen auszulösen, Integrationsplattformen (Zapier, n8n, Make) zu benachrichtigen oder Slack-/Teams-/Discord-Bots anzusteuern, die keine erstklassigen Konnektoren verwenden.

Nutzlastformat und benutzerdefinierte Header sind konfigurierbar. Der empfangende Dienst ist dafür verantwortlich, was danach geschieht.
