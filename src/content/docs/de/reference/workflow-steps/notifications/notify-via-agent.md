## Beschreibung



Löst eine Benachrichtigung über einen PlaidLink-Agent aus – nützlich, wenn Benachrichtigungen über lokale Systeme zugestellt werden müssen (interne Alarmierung, hausinterne Webhooks, Legacy-SMTP), die PlaidCloud nicht direkt erreichen kann.

Der Agent empfängt die Benachrichtigungsnutzlast und verteilt sie entsprechend seiner Konfiguration lokal.
