Workflow-Schritte, die die *gepackten Makros* von Alteryx nachbilden – die Makros, die mit Alteryx ausgeliefert werden, nicht solche, die Sie selbst erstellen. Jeder Schritt läuft in der Workflow-Engine, und sein Ergebnis ist eine Annäherung an das Alteryx-Makro.

Sie unterscheiden sich von [PlaidCloud-Makros](/de/reference/workflow-steps/workflow-control/run-macro/), also wiederverwendbaren Schrittfolgen, die Sie selbst erstellen.
