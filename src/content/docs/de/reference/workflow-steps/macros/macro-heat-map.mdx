## Beschreibung

Der Schritt **Heat Map (Makro)** bildet das gepackte Alteryx-Makro *Heat Map* nach. Er läuft in der Workflow-Engine; die Ergebnisse gepackter Makros sind eine Annäherung an das Alteryx-Makro.

## Parameter

- **Quelle / Ausgabetabellen** und die **Maximale Entfernung**.
