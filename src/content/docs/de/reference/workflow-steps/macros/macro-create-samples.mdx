## Beschreibung

Der Schritt **Create Samples (Makro)** bildet das gepackte Alteryx-Makro *Create Samples* nach. Er läuft in der Workflow-Engine; die Ergebnisse gepackter Makros sind eine Annäherung an das Alteryx-Makro.

## Parameter

- **Quelle / Ausgabetabellen**.
- **Schätzanteil in %** und **Zufalls-Seed**.
