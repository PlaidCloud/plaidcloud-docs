## Beschreibung

Der Schritt **DateTime Now (Makro)** bildet das gepackte Alteryx-Makro *DateTime Now* nach. Er läuft in der Workflow-Engine; die Ergebnisse gepackter Makros sind eine Annäherung an das Alteryx-Makro.

## Parameter

- **Ausgabetabelle** und die Zeichenfolge **Ausgabeformat**.

## Ausgabeformat

Die Formatzeichenfolge verwendet die Token des Alteryx-Tools DateTime, und die Konvertierung übernimmt sie unverändert. Bleibt sie leer, gilt der Standard des Tools, `day, dd Month, yyyy` – zum Beispiel `Tuesday, 04 August, 2026`.

| Token | Ergebnis |
| --- | --- |
| `yyyy` / `yy` | Vier- oder zweistelliges Jahr |
| `Month` / `Mon` | Vollständiger oder abgekürzter Monatsname |
| `MM` / `M` | Monatsnummer, mit oder ohne führende Null |
| `day` / `dy` | Vollständiger oder abgekürzter Wochentagsname |
| `dd` / `d` | Tag des Monats, mit oder ohne führende Null |
| `HH` / `H` | Stunde im 24-Stunden-Format, mit oder ohne führende Null |
| `hh` / `h` | Stunde im 12-Stunden-Format, mit oder ohne führende Null |
| `mm` | Minuten |
| `ss` | Sekunden |
| `tt` | AM oder PM |

Bei den Token wird zwischen Groß- und Kleinschreibung unterschieden: `MM` ist der Monat, `mm` sind die Minuten.
