## Beschreibung

Importiert eine vertragsbasierte Acumatica-REST-Entität über Ihre [Acumatica-Verbindung](/de/guides/connections/acumatica/) in eine Projekttabelle. Wählen Sie die Verbindung, den Entitätstyp und beliebige Filter; der Schritt holt die passenden Datensätze und schreibt sie, ohne dass Sie eine OData-Abfrage verfassen müssen.

Dies ist ein generischer vorgefertigter Schritt — ein Schritttyp deckt 18 Entitäten ab, von Stamm-/Referenzdaten (Konten, Subkonten, Kunden, Lieferanten, Lagerartikel) bis zu Bewegungsdaten (Ausgangsrechnungen, Eingangsrechnungen, Kundenaufträge, Lieferungen).

## Konfiguration

| Feld | Erforderlich | Hinweise |
|---|---|---|
| Acumatica-Verbindung | Ja | Die Acumatica-Verbindung, über die gelesen wird. |
| Zieltabelle | Ja | Die Projekttabelle, in die die Ergebnisse geschrieben werden. Sie wird bei jeder Ausführung vollständig überschrieben. |
| Entitätstyp | Ja | Welche Entität geholt wird. Standard `account`. Einer von `account`, `ledger`, `financial_period`, `branch`, `currency`, `currency_rate`, `subaccount`, `customer`, `vendor`, `stock_item`, `warehouse`, `employee`, `tax_category`, `sales_invoice`, `bill`, `sales_order`, `shipment`, `project`. |
| Nur aktive | Nein | Standardmäßig aktiviert. Filtert auf `Active = true` bei Entitäten, die ein Active-Flag führen. |
| Aktualisiert nach | Nein | ISO-Datum oder -Datum mit Uhrzeit. Es werden nur Zeilen zurückgegeben, die nach diesem Zeitpunkt geändert wurden. Dies ist ein anfrageseitiger Filter ohne gespeicherten Cursor — geben Sie den Stichtag bei jeder Ausführung selbst an. Leer holt alles. |
| Filter | Nein | Ein Array aus Klauseln `{field, operator, value}` (`eq`, `ne`, `gt`, `ge`, `lt`, `le`, `contains`) oder Bereichen `{field, from, to}`. Jede Entität beschränkt Filter auf die Felder, die Acumatica serverseitig tatsächlich auswerten kann — ein nicht unterstütztes Feld wird abgelehnt, nicht stillschweigend verworfen. |

<Aside type="note">
Saldenliste, Hauptbuch-Buchungsdetails, Lagerbestand, Budgets und Intercompany-Daten liegen hinter Acumatica Generic Inquiries, nicht in diesen 18 vertragsbasierten Entitäten. Erstellen Sie die GI in Acumatica und holen Sie sie stattdessen mit einer [generischen REST-Verbindung](/de/reference/connectors/rest/generic-rest/).
</Aside>

<Aside type="caution">
Die Filterung erreicht nur Felder auf Entitäts- und Kopfebene — die Positionsdimensionen eines Dokuments (zum Beispiel eine Kostenstelle in den Positionen einer Eingangsrechnung) sind serverseitig nicht abfragbar. Holen Sie die Entität und grenzen Sie Details auf Positionsebene nach dem Import in Ihrem Workflow ein.
</Aside>
