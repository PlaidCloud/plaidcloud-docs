Trainieren Sie ein Modell auf einer beliebigen Tabelle, führen Sie es als Modelltabelle durch den Workflow und bewerten Sie Datentabellen damit.

## Schritte

- [ML: Modell trainieren](/de/reference/workflow-steps/machine-learning/ml-train/) – ein scikit-learn-Modell (Klassifikation oder Regression) auf einer Quelltabelle anpassen und eine abfragbare Modelltabelle mit dem angepassten Modell, den Parametern, der Merkmalsliste und den Trainingskennzahlen schreiben.
- [ML: Bewerten](/de/reference/workflow-steps/machine-learning/ml-score/) – eine Datentabelle mit einer trainierten Modelltabelle bewerten und eine Vorhersagespalte anfügen.

Wie Assisted-Modeling-Pipelines von Alteryx in diese Schritte konvertiert werden, lesen Sie unter [Alteryx-Workflows migrieren](/de/guides/workflows/migrate-alteryx-workflows/#konvertierung-von-maschinellem-lernen-assisted-modeling).
