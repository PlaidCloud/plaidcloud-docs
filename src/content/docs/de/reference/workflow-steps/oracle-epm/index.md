Workflow-Schritte, die über Ihre [HFM/FCCS-Verbindung](/de/guides/connections/hfm-fccs/) aus Oracle **FCCS** (Financial Consolidation and Close, EPM Cloud) lesen. Ein Finanzbenutzer baut im Schrittformular einen Betrachtungspunkt auf und führt ihn aus, und das zurückgegebene Raster landet automatisch als Projekttabelle – ohne Ticket an das HFM-Team und ohne Konsolidierungswissen.

## Schritte

- [HFM/FCCS: Daten lesen (Ad-hoc)](/de/reference/workflow-steps/oracle-epm/hfm-fccs-read/) – rufen Sie selbst einen Datenausschnitt mit einer Betrachtungspunkt-Auswahl ab; speichert wiederholte Abrufe zwischen, ist bereit für Sicherheit auf Zeilenebene und kann zu einem geplanten wiederkehrenden Ladevorgang hochgestuft werden.
