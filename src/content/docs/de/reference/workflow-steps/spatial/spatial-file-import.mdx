## Beschreibung

Der Schritt **Räumlicher Dateiimport** liest eine räumliche Datei — MapInfo `.TAB`,
ESRI `.shp`, `.kml`, `.geojson` oder SRC `.geo` — samt ihren Begleitdateien in eine
Tabelle, eine Zeile pro Feature mit einer WKT-Geometriespalte. Er entspricht
dem Alteryx-Tool *Input Data*, das auf eine Geodatei zeigt, und läuft in der Workflow-
Engine (GDAL).

## Importparameter

- **Quelle** — die Geodatei im Dokumentenspeicher. Ihre Begleitdateien
  (z. B. `.dat`/`.map`/`.id`/`.dbf` einer `.TAB` oder `.shx`/`.dbf`/`.prj` eines Shapefiles)
  werden automatisch aus demselben Ordner gelesen.
- **Zieltabelle** — die Tabelle, in die die Features geschrieben werden.

## Hinweise

Das Ausgabeschema wird aus der Datei übernommen, es gibt also keine Spaltenzuordnung. Die proprietäre
Geometrie einer SRC-`.geo`-Datei kann nicht gelesen werden; ihre `.dbf`-Attribute werden
mit leeren Geometriewerten importiert.
