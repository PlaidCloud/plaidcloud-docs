## Beschreibung

Der Schritt **Spatial Poly-Build** erstellt aus Punktgeometrien pro
Gruppe ein Polygon (oder eine konvexe Hülle). Er entspricht dem Alteryx-Tool *Poly-Build*
und läuft in der Workflow-Engine.

## Quelle & Optionen

- **Quelltabelle** / **Ausgabetabelle** — die Eingabepunkte und das Ziel, in das das Ergebnis
  geschrieben wird.
- **Punktgeometrie** — die WKT-Punktgeometriespalte, aus der erstellt wird.
- **Gruppieren nach** — eine optionale Spalte, die die Punkte in getrennte Ausgabe-
  polygone gruppiert; lassen Sie das Feld leer, um aus allen Punkten ein einzelnes Polygon zu erstellen.
- **Erstellungstyp** — **Sequenz** löst die gruppierten Punkte zu einem Polygon auf;
  **Konvexe Hülle** erstellt die konvexe Hülle der Punkte.
- **Ausgabespalte** — der Name der Ausgabe-Geometriespalte.

## Spalten

Auf der Registerkarte **Spalten** ordnen Sie die Eingabespalten zu, die in die Ausgabe durchgereicht werden.
