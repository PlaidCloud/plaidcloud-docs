## Ad-hoc-Extraktionsschritte

Drei Schritte durchsuchen SAP, zeigen die Extraktion in einer Vorschau an, planen sie und legen das Ergebnis in einer Tabelle ab. Einer liest eine Tabelle, einer führt eine Transaktion oder einen Bericht aus, und einer führt eine gespeicherte SAP Query aus. Siehe [Ad-hoc-Extraktionen aus SAP ECC / S/4HANA](/de/guides/connections/sap-adhoc-extract/).
