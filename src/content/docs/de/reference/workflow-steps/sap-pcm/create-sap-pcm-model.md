## Beschreibung



Erstellt ein neues, leeres SAP-Profitability-and-Cost-Management-(PCM-)Modell auf dem PCM-Server. Nützlich, um Modelle programmatisch bereitzustellen – zum Beispiel, wenn eine neue Geschäftseinheit oder ein neues Szenario ein eigenes Modell braucht und der Workflow eines anlegen kann, statt auf eine manuelle Einrichtung zu warten.

Die meisten Benutzer kopieren ein bestehendes Modell als Vorlage über [Copy SAP PCM Model](/de/reference/workflow-steps/sap-pcm/copy-sap-pcm-model/), statt leer zu beginnen.


## Unsere Referenzen


PlaidCloud ist ein offizieller SAP-Partner und bevorzugter Dienstleister für Services rund um Entwurf und Implementierung von SAP-PCM-Modellen.








## Beispiele


Wählen Sie in der Dropdown-Liste „Zu verwendender Agent“ aus. Geben Sie „Model Name“ ein und wählen Sie „Model type“ aus der Dropdown-Liste (beides im Abschnitt „Modellinformationen“). Aktivieren Sie das Kontrollkästchen „Wait for Copy to Complete“ und klicken Sie dann auf „Save and Run Step“.
