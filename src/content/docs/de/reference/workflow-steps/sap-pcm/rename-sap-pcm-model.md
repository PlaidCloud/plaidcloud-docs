## Beschreibung



Benennt ein bestehendes SAP-Profitability-and-Cost-Management-(PCM-)Modell um. Nützlich für Aufräumarbeiten bei Szenariowechseln (z. B. „Forecast Q3“ nach dem Periodenabschluss in „Actuals Q3“ umbenennen) oder bei organisatorischen Umstrukturierungen.

Der neue Name muss auf dem PCM-Server eindeutig sein.


## Unsere Referenzen


PlaidCloud ist ein offizieller SAP-Partner und bevorzugter Dienstleister für Services rund um Entwurf und Implementierung von SAP-PCM-Modellen.








## Beispiele


Wählen Sie in der Dropdown-Liste „Zu verwendender Agent“ aus, geben Sie im Feld „Modellinformationen“ „From Model Name“ und „To Model Name“ ein, aktivieren Sie das Kontrollkästchen „Wait for Copy to Complete“ und klicken Sie dann auf „Save and Run Step“.
