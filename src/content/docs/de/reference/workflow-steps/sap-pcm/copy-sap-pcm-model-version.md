### Beschreibung


Kopiert eine Version eines SAP-Profitability-and-Cost-Management-(PCM-)Modells innerhalb desselben Modells.


### Unsere Referenzen


PlaidCloud ist ein offizieller SAP-Partner und bevorzugter Dienstleister für Services rund um Entwurf und Implementierung von SAP-PCM-Modellen.


### Beispiele


Wählen Sie in der Dropdown-Liste „Zu verwendender Agent“ aus und geben Sie im Feld „Modellinformationen“ „Model Name“, „Origin Period Name“ und „Destination Period Name“ ein. Aktivieren Sie das Kontrollkästchen „Wait for Copy to Complete“ und klicken Sie dann auf „Save and Run Step“.
