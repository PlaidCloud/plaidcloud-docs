## Beschreibung


Löscht SAP-Profitability-and-Cost-Management-(PCM-)Modelle, die den Suchkriterien entsprechen. Mit diesem Schritt können Sie viele Modelle löschen, ohne den Vorgang überwachen zu müssen.



## Unsere Referenzen


PlaidCloud ist ein offizieller SAP-Partner und bevorzugter Dienstleister für Services rund um Entwurf und Implementierung von SAP-PCM-Modellen.








## Beispiele


Wählen Sie in der Dropdown-Liste „Zu verwendender Agent“ aus. Wählen Sie die gewünschte „Model Search Method“. In diesem Beispiel haben wir „Exact Match“ gewählt. Geben Sie unter „Model Name Information“ den „Model Search Text“ ein (wonach Sie suchen) und legen Sie fest, ob die Suche zwischen Groß- und Kleinschreibung unterscheidet (wenn ja, aktivieren Sie das Kontrollkästchen). Aktivieren Sie schließlich „Wait for Deletion to Complete“ und klicken Sie auf „Save and Run Step“.
