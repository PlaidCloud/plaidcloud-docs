## Beschreibung


Erstellt einen neuen PlaidCloud-Analyze-Workflow.



## Zu erstellender Workflow


Wählen Sie zuerst im Dropdown-Menü das Projekt aus, in dem der neue Workflow erstellt werden soll.



Geben Sie dann einen Workflow-Namen ein. Der Name muss innerhalb des Projekts eindeutig sein.
