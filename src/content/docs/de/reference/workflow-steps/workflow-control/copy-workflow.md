## Beschreibung


Erstellt eine Kopie eines vorhandenen PlaidCloud-Analyze-Workflows.



## Zu kopierender Workflow


Wählen Sie zuerst im Dropdown-Menü **Projekt** das Projekt aus, das den zu kopierenden Workflow enthält.



Wählen Sie anschließend im Dropdown-Menü **Workflow** den bestimmten Workflow aus, der kopiert werden soll.



Geben Sie dann den neuen Workflow-Namen in das Feld **Neuer Workflow** ein. Beachten Sie: Der Name muss innerhalb des Projekts eindeutig sein.
