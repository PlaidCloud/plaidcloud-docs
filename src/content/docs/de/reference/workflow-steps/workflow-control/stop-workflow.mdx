## Beschreibung


Der Schritt „Workflow beenden“ beendet einen vorhandenen, laufenden Workflow.


<Aside>Wenn der Workflow bei der Ausführung dieses Schritts nicht läuft, wird eine Warnung in das Protokoll geschrieben: *Workflow ist bereits beendet.</Aside>


## Zu beendender Workflow


Wählen Sie zunächst im Dropdown-Menü **Projekt** das Projekt aus, das den zu beendenden Workflow enthält.



Wählen Sie anschließend im Dropdown-Menü **Workflow** den Workflow aus, der beendet werden soll.
