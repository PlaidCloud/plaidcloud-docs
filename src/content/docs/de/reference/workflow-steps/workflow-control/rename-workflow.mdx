## Beschreibung


Benennt einen vorhandenen PlaidCloud-Analyze-Workflow um.

<Aside>Wenn der umbenannte Workflow bereits vorhanden ist, wird ein Fehler in das Protokoll geschrieben: *Workflow \{workflow} in Projekt \{project} ist bereits vorhanden.* Es wird keine Aktion ausgeführt. Dadurch lässt sich die Transformation **Workflow umbenennen** praktisch nur einmal verwenden.</Aside>


## Umzubenennender Workflow


Wählen Sie zunächst im Dropdown-Menü **Projekt** das Projekt aus, das den umzubenennenden Workflow enthält.



Wählen Sie anschließend im Dropdown-Menü **Workflow** den Workflow aus, der umbenannt werden soll.



Geben Sie zuletzt den neuen Workflow-Namen im Feld **Umbenennen in** ein. Beachten Sie, dass der Name innerhalb des Projekts eindeutig sein muss.
