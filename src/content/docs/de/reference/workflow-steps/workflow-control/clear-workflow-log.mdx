## Beschreibung


Leert das Protokoll eines vorhandenen PlaidCloud-Analyze-Workflows.



## Zu leerendes Workflow-Protokoll


Wählen Sie zuerst im Dropdown-Menü **Projekt** das Projekt aus, das das zu leerende Workflow-Protokoll enthält.



Wählen Sie anschließend im Dropdown-Menü **Workflow** das bestimmte Workflow-Protokoll aus, das geleert werden soll.


<Aside type="danger">Es gibt keinen Bestätigungsdialog für das Löschen. Vergewissern Sie sich, dass Sie das richtige Workflow-Protokoll auswählen.</Aside>
