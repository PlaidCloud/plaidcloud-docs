## Beschreibung

Lässt den Workflow fehlschlagen, wenn zwei Tabellen unterschiedliche Zeilenanzahlen haben. Verwenden Sie den Schritt als Gate für die Datenqualität – zum Beispiel, um zu bestätigen, dass eine transformierte Tabelle jede Zeile ihrer Quelle behalten hat oder dass bei einem Abgleich keine Datensätze verloren gegangen oder doppelt vorhanden sind. Stimmen die Anzahlen überein, wird der Workflow fortgesetzt. Weichen sie ab, hält der Schritt den Workflow an und schreibt die Fehlermeldung in das Workflow-Protokoll.

## Konfiguration

- **Linke Tabelle** – die erste Tabelle, deren Zeilen gezählt werden.
- **Rechte Tabelle** – die zweite Tabelle, deren Zeilen gezählt werden.
- **Fehlermeldung** – die Meldung, die angezeigt wird, wenn die Anzahlen abweichen. Standard ist „Die Zeilenanzahlen stimmen nicht überein“.

Verwenden Sie stattdessen [Workflow-Fehler auslösen](/de/reference/workflow-steps/workflow-control/raise-workflow-error/), wenn Sie bei einer beliebigen Bedingung statt bei einer abweichenden Zeilenanzahl fehlschlagen lassen möchten.
