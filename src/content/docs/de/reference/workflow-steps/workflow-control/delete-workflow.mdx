## Beschreibung


Löscht einen vorhandenen PlaidCloud-Analyze-Workflow.



## Zu löschender Workflow


Wählen Sie zuerst im Dropdown-Menü **Projekt** das Projekt aus, das den zu löschenden Workflow enthält.



Wählen Sie anschließend im Dropdown-Menü **Workflow** den bestimmten Workflow aus, der gelöscht werden soll.


<Aside type="danger">Es gibt keinen Bestätigungsdialog für das Löschen. Vergewissern Sie sich, dass Sie den richtigen Workflow auswählen.</Aside>
