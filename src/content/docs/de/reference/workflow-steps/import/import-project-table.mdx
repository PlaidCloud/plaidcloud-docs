## Beschreibung


Kopiert Daten aus einer Tabelle eines anderen Projekts in das aktuelle Projekt. Das Gegenstück zu [Export Project Table](/de/reference/workflow-steps/export/export-project-table/) – holt statt zu übertragen.

Nützlich, wenn ein Konsolidierungsprojekt aus vielen operativen Projekten speist oder wenn Referenzdaten in einem Projekt zentralisiert sind und von anderen gelesen werden. Das Quellprojekt muss diesem Projekt eine Datenfreigabe mit **Lesen** gewähren.


## Datenfreigabe-Verwaltung

![Datenfreigabe-Verwaltung](/images/import_external_project_table_1.png)

Bevor Sie eine Tabelle aus einem anderen Projekt importieren können, muss dieses Projekt dem aktuellen das Lesen erlauben. Öffnen Sie die Registerkarte **Startseite** des **Quell**projekts, klicken Sie unter **Datenfreigabe-Verwaltung** auf **Neue Datenfreigabe**, wählen Sie dieses Projekt, aktivieren Sie unter **Zulässige Vorgänge** die Option **Lesen** und klicken Sie auf **Datenfreigabe hinzufügen**. Siehe [Daten zwischen Projekten freigeben](/de/guides/projects/managing-projects/#daten-zwischen-projekten-freigeben).

Der Schritt läuft mit der eigenen Identität dieses Projekts, sodass eine Ausführung über die Freigabe funktioniert, wer auch immer sie startet.

## Externe Projekttabelle importieren

![Importquelle und -ziel](/images/import_external_project_table_2.png)

### Lesen aus
Wählen Sie das **Quellprojekt** und die **Quelltabelle** in den Dropdown-Listen.

### Schreiben nach

<SnippetCommonImportTargetSelection />

<Aside type="note" title="Leere Quelltabelle">
Wenn die Quelltabelle beim Ausführen des Schritts keine Zeilen enthält, endet der Import mit einer Warnung, dass die Quelle leer war, statt mit einem stillen Erfolg – so fällt eine unerwartet leere Zieltabelle leicht auf. Meist bedeutet das, dass der Workflow des Quellprojekts diese Tabelle noch nicht aufgebaut hatte; stellen Sie sicher, dass die Quelle befüllt ist (und bei geplanten Ausführungen zuerst läuft), bevor der Import läuft.
</Aside>

<Aside type="note" title="Eine Quelltabelle löschen">
Die Quelltabelle, aus der Sie lesen, gilt für diesen Schritt als in Gebrauch. Wenn Sie versuchen, sie zu löschen, zeigt PlaidCloud den Verweis an und verlangt, dass Sie ein erzwungenes Löschen bestätigen – indem Sie **Löschen der Tabelle erzwingen?** aktivieren und **Löschen erzwingen** wählen –, statt einfach zu löschen, auch wenn der Importschritt in einem anderen Projekt liegt, das die Daten teilt. In diesem projektübergreifenden Fall listet die Warnung den Verweis auf, ohne den Schritt des anderen Projekts zu nennen, da Sie darauf möglicherweise keinen Zugriff haben.
</Aside>
