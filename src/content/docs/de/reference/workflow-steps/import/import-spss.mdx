## Beschreibung



Importiert SPSS-Datendateien (Formate .sav und .zsav) in PlaidCloud-Projekttabellen. Nützlich für Umfragedaten, sozialwissenschaftliche Forschungsdaten oder jede Pipeline, die mit SPSS-basierten Werkzeugen zusammenarbeitet.

Variablenbeschriftungen und Wertbeschriftungen bleiben erhalten, soweit das Format sie unterstützt.
