## Beschreibung

Importiert die Elemente eines oder mehrerer [monday.com](https://monday.com/)-Boards über eine monday.com-Verbindung in Projekttabellen. Verwenden Sie den Schritt, um Projektverfolgung, Eingangswarteschlangen oder operative Aufgabendaten zusammen mit Finanzdaten in einen Workflow zu holen.

## Spezifische Konfigurationselemente

### Verbindungskonfiguration

Die monday.com-Verbindung, über die gelesen wird.

### Zieltabelle

Eine Zeile pro Board: die zu lesende **Board-ID** und die Projekttabelle, in die geschrieben wird. Ein einzelner Schritt kann mehrere Boards gleichzeitig importieren. Jedes Ziel muss eine Tabelle sein, keine Ansicht.
