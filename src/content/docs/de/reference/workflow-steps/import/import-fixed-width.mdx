## Beschreibung



Importiert Textdateien, in denen Spalten durch Zeichenpositionen statt durch Trennzeichen definiert sind – das klassische Ausgabeformat von Mainframe und COBOL. Konfigurieren Sie die Spaltengrenzen (Startposition, Länge) pro Feld.

Häufig bei älteren ERP-Exporten, behördlichen Meldungen und Kontoauszugsformaten, bei denen die Daten für die Anzeige in festen Spalten statt für das Parsen mit Trennzeichen aufbereitet wurden.

Importe mit fester Breite werden über temporären Speicher gestreamt, statt die gesamte Datei in den Arbeitsspeicher zu laden, sodass auch sehr große Dateien ohne Speichermangel importiert werden.

### Kopfzeile

Da Excel-Dateien eine Kopfzeile enthalten können oder nicht, bietet PlaidCloud die Möglichkeit, die Kopfzeilen zu verwenden, sie zu ignorieren oder die Spaltenreihenfolge zur Bestimmung der Spaltenausrichtung zu nutzen.
* **Keine Kopfzeile**: Die Datei enthält keine Kopfzeile.  Verwenden Sie die Quellliste im *Data Mapper*, um die Spaltenausrichtung zu bestimmen.
* **Mit Kopfzeile – Kopfzeile verwenden und Feldliste überschreiben**: Die Datei hat eine Kopfzeile.  Verwenden Sie die angegebenen Kopfzeilennamen und ignorieren Sie die Quellliste im *Data Mapper*.
* **Mit Kopfzeile – Kopfzeile überspringen und stattdessen Feldliste verwenden**: Die Datei hat eine Kopfzeile, sie soll aber ignoriert werden.  Verwenden Sie die Namen, die die Quellliste im *Data Mapper* vorgibt.

### Zeilenauswahl

Bei Eingabedateien mit überflüssigen Datensätzen können Sie eine Anzahl von Zeilen angeben, die vor der Verarbeitung der Daten übersprungen werden.  Das ist nützlich, wenn Dateien Kopfblöcke enthalten, die übersprungen werden müssen, bevor die tabellarischen Daten beginnen.

### Spaltenbreiten

Geben Sie die Breiten der Spalten durch Kommas oder Leerzeichen getrennt ein.

### Layout

| Einstellung | Funktion |
| --- | --- |
| Kodierung | Der Zeichensatz der Datei: **UTF-8** (Standard), **EBCDIC (USA, cp037)**, **EBCDIC (International, cp500)** oder **Latin-1**. Wählen Sie für eine Mainframe-Datei eine EBCDIC-Codepage. |
| Zu überspringende Datensätze | Wie viele Datensätze am Anfang der Datei übersprungen werden, vor der Kopfzeile oder den Daten. |
| Am Ende zu verwerfende Datensätze | Wie viele Datensätze am Ende der Datei verworfen werden, etwa ein Abschlussdatensatz. |
| Ein Datensatz pro Zeile | Aktiviert (Standard) ist jede Zeile ein Datensatz. Deaktivieren Sie die Option für eine Datei, deren Datensätze ohne Zeilenumbrüche aneinandergereiht sind; jeder Datensatz ist dann so lang wie die Spaltenbreiten zusammen. |
| Zeichen zwischen Datensätzen | Wenn Datensätze nicht zeilenweise vorliegen: wie viele Zeichen nach jedem Datensatz übersprungen werden, etwa ein Trennzeichen. |
| Leerzeichen entfernen | Die Leerzeichen, die aus jedem Wert entfernt werden: **Führende und nachgestellte** (Standard), **Nur nachgestellte** oder **Keine**. |
