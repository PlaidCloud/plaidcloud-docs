## Beschreibung


Importiert eine PlaidCloud-native Archivdatei zurück in eine Projekttabelle. Das Archivformat bewahrt Spaltentypen, Metadaten und Indizes, die einen CSV-Roundtrip nicht überstehen.

Erstellt von [Export to Table Archive](/de/reference/workflow-steps/export/export-to-table-archive/). Verwendet für Projektsicherungen, Migrationen zwischen Workspaces oder Umgebungen und die zuverlässige Übertragung typisierter Daten.
