## Beschreibung

Importieren Sie eine IBM-DB2-Extraktdatei aus dem PlaidCloud-Document-Speicher. Das ist nützlich, wenn der DB2-Server nur über die lokale Infrastruktur erreichbar ist: Ein externer Prozess legt den Extrakt im PlaidCloud-Document-Speicher ab, und dieser Schritt liest ihn von dort in eine Projekttabelle.

Für den Live-Zugriff auf DB2 (ohne Extraktdatei) verbinden Sie sich über die Standardverbindung [IBM DB2](../../../connectors/databases/ibm-db2/) und verwenden [Externe Datenbanktabellen importieren](../import-external-database-tables/).
