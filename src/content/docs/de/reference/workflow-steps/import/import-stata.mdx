## Beschreibung


Importiert Stata-Datendateien (.dta) in PlaidCloud-Projekttabellen. Nützlich für Organisationen, die Stata für ökonometrische oder statistische Analysen einsetzen und ihre Arbeitsdatensätze zur weiteren Verarbeitung nach PlaidCloud holen.

Variablenbeschriftungen bleiben erhalten, soweit das Stata-Format sie enthält.
