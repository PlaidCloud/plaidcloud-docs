## Beschreibung

Der Schritt **Import dBASE** importiert eine dBASE-Datei (`.dbf`), die ihr eigenes Schema mitbringt. Er läuft in der Workflow-Engine; die Ergebnisse gepackter Makros sind eine Annäherung an das Alteryx-Makro.

dBASE-Importe werden über temporären Speicher gestreamt, statt die gesamte Datei in den Arbeitsspeicher zu laden, sodass auch sehr große Dateien ohne Speichermangel importiert werden. Die Datentypen der Datei – Dezimalzahlen, Datums- und Zeitstempelwerte – bleiben in der Zieltabelle erhalten.

## Parameter

- **Quelle** – die `.dbf`-Datei.
- **Zieltabelle** – die Ausgabetabelle.
- **Erneuten Import überspringen, wenn Quelldateien unverändert sind** – eine Workflow-Ausführung überspringt den Import, wenn die Quelldatei und die Schritteinstellungen seit der letzten erfolgreichen Ausführung unverändert sind. Standardmäßig aktiviert; deaktivieren Sie die Option, um immer neu zu importieren.
