## Spezifische Konfigurationselemente

### Änderungszeit der Datei

Liest nur die Dateien, die in einem Zeitfenster geändert wurden. **Geändert nach** liest nur Dateien, die zuletzt nach der eingegebenen Zeit geändert wurden, und **Geändert vor** nur Dateien, die zuletzt vor dieser Zeit geändert wurden; legen Sie eine der beiden Angaben oder beide fest. Geben Sie eine Zeit als `YYYY-MM-DDTHH:MM:SS` ein, etwa `2026-10-01T00:00:00`. Eine Zeit gilt als UTC, sofern sie keine Zeitzone nennt, etwa `2026-10-01T00:00:00-05:00`. Eine Zeit kann eine Workflow-Variable enthalten, die beim Ausführen des Schritts gelesen wird.
