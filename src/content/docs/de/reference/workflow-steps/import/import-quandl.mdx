## Spezifische Konfigurationselemente

### Angabe der Quelldaten

Für den Zugriff auf Quandl-Datensätze ist ein Benutzerkonto oder ein Gastkonto mit eingeschränktem Zugriff erforderlich. Dieses muss in Tools eingerichtet werden. Einzelheiten zum Einrichten einer Quandl-Kontoverbindung finden Sie hier: [PlaidCloud Tools – Verbindung](/de/reference/connectors/).

Sobald alle erforderlichen Konten eingerichtet sind, wählen Sie das passende Konto aus der Dropdown-Liste.

Geben Sie als Nächstes die Kriterien für den gewünschten Quandl-Code ein. Benutzer können mit der Funktion **Suchen** nach Datensätzen suchen. Alternativ können Datensätze manuell eingegeben werden. Dazu geben Sie den Teil der URL nach „[http://www.quandl.com](http://www.quandl.com/)“ ein. 

Um beispielsweise den Datensatz für die Microsoft-Aktie zu importieren, den Sie hier finden (http://www.quandl.com/GOOG/NASDAQ_MSFT), geben Sie *GOOG/NASDAQ_MSFT* in das Feld Quandl-Code ein.


### Datenauswahl


Quandl-Datensätze lassen sich beim Import eingrenzen. Die verfügbaren Optionen sind:


* Startdatum: Wählen Sie das gewünschte Datum mit der Datumsauswahl.
* Enddatum: Wählen Sie das gewünschte Datum mit der Datumsauswahl.
* Verdichten: Aggregiert die Ergebnisse auf täglicher, wöchentlicher, monatlicher, vierteljährlicher oder jährlicher Basis. Standardmäßig erfolgt keine Aggregation.
* Transformation: Zusammenfassende Berechnungen.
* Zeilenlimit: Der Standardwert 0 liefert alle Zeilen. Jeder andere positive ganzzahlige Wert legt die Höchstzahl der Zeilen fest, die aus dem Datensatz zurückgegeben werden.
