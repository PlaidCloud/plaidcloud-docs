## Beschreibung


Importiert Daten aus Google BigQuery in eine PlaidCloud-Projekttabelle. Nützlich für Organisationen, die BigQuery als primäres Analyse-Warehouse einsetzen und bestimmte Datensätze für die weitere Modellierung oder Umlagearbeit in PlaidCloud übernehmen.

Die Authentifizierung erfolgt über ein Google-Cloud-Dienstkonto; das Quelldatenset und die Quelltabelle werden auf Schrittebene konfiguriert.
