## Beschreibung


Importiert tabellarische Daten aus einer XML-Datei in eine PlaidCloud-Projekttabelle. Konfigurieren Sie den Elementpfad, der jede „Zeile“ identifiziert, und ordnen Sie untergeordnete Elemente oder Attribute Tabellenspalten zu.

Häufig bei älteren Unternehmensintegrationen, B2B-Datenaustausch (RosettaNet, ebXML) und behördlichen Meldeformaten.


## Datensätze lesen als

**Datensätze lesen als** legt fest, wie aus der Datei Tabellen werden:

* **Eine Tabelle pro Datensatz-Tag** (Standard) – die Registerkarte **Datensatz-Tags** listet jedes zu lesende Tag auf, und jedes Tag wird in eine eigene Tabelle geladen, benannt nach dem **Präfix der Zieltabellen**.
* **Eine Zeile pro Element** – ein sich wiederholendes Element wird in eine Tabelle geladen, eine Zeile für jedes Vorkommen. Die Registerkarte **Datensatz-Tags** und das **Präfix der Zieltabellen** sind deaktiviert.

Legen Sie bei **Eine Zeile pro Element** fest:

* **XML-Element** – das Element, das eine Zeile bildet. Bleibt das Feld leer, ist es das Element der ersten Spalte, das im Feld angezeigt wird.
* **Zieltabelle** – die zu ladende Tabelle.
* **Spalten** – jedes **Untergeordnetes Element oder Attribut** und die **Spalte**, in die es geladen wird. Jede Spalte wird als Text importiert.
* **Leerzeichen um Werte entfernen** – entfernt führende und nachgestellte Leerzeichen aus jedem Wert.
* **Namen mit ihrem Namespace-Präfix abgleichen** – gleicht Element- und Attributnamen so ab, wie sie in der Datei stehen, einschließlich des Präfixes.

Quelldatei, Zieltabelle und entweder ein XML-Element oder mindestens eine Spalte sind erforderlich. Beim Wechsel des Modus bleiben die Einstellungen des anderen Modus im Formular erhalten, sodass sie beim Zurückwechseln wiederhergestellt werden, doch beim Speichern werden die Einstellungen des Modus entfernt, von dem Sie weggewechselt sind; ein Hinweis neben dem Steuerelement sagt, was passiert.

Aus dem Formular gespeicherte Schritte lesen ihre Datensatz-Tags so, wie sie auf der Registerkarte **Datensatz-Tags** festgelegt sind.
