## Beschreibung

Importieren Sie JSON-Textdateien aus PlaidCloud Document.

Weitere Einzelheiten zu JSON-Dateien finden Sie auf der offiziellen JSON-Website: http://json.org/.

JSON-Dateien behalten die Spaltenreihenfolge *nicht* bei. Die Spaltenreihenfolge in der Quelldatei spiegelt nicht zwangsläufig die Spaltenreihenfolge in der importierten Datentabelle wider.

JSON-Importe werden über temporären Speicher gestreamt, statt das gesamte Dokument in den Arbeitsspeicher zu laden, sodass auch sehr große Dateien ohne Speichermangel importiert werden. Spalten, die in einem großen Dokument erst spät auftauchen, werden in die importierte Tabelle aufgenommen. Verschachtelte Objekte und Arrays werden als standardmäßiger kompakter JSON-Text importiert, sodass nachgelagerte Schritte sie mit beliebigen JSON-Werkzeugen parsen können.

## Spezifische Konfigurationselemente

### JSON-Datenausrichtung

Betrachten Sie den folgenden Datensatz:

| ID | Name | Gender | State |
| 1 | Jack | M | MO |
| 2 | Jill | F | MO |
| 3 | George | M | VA |
| 4 | Abe | M | KY |

JSON-Dateien können aus einem von drei Datenformaten importiert werden:

* Records: Die Daten werden in Python-Dictionary-Mengen gespeichert, wobei jede Zeile im Format \{Column -> Value, …} abgelegt ist. Zum Beispiel:


```json
[{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" }]
```

* Index: Die Daten werden in verschachtelten Python-Dictionary-Mengen gespeichert, wobei jede Zeile im Format \{Index -> \{Column -> Value, …},…} abgelegt ist. Zum Beispiel:


```json
{ "0": { "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }, "1": { "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }, "2": { "ID": 3, "Name": "George", "Gender": "M", "State": "VA" }, "3": { "ID": 4, "Name": "Abe", "Gender": "M", "State": "KY" } }
```

* Split: Die Daten werden in einer einzelnen Python-Dictionary-Menge gespeichert, die Werte in Listen. Zum Beispiel:


```json
{ "columns": ["ID", "Name", "Gender", "State"], "index": [0, 1, 2, 3], "data": [ [1, "Jack", "M", "MO"], [2, "Jill", "F", "MO"], [3, "George", "M", "VA"], [4, "Abe", "M", "KY"] ] }
```

Zusätzlich zu den oben genannten Formaten wird zeilenweise getrenntes JSON (NDJSON) akzeptiert: ein eigenständiges JSON-Objekt pro Zeile, ohne umschließendes Array. Zum Beispiel:

```json
{ "ID": 1, "Name": "Jack", "Gender": "M", "State": "MO" }
{ "ID": 2, "Name": "Jill", "Gender": "F", "State": "MO" }
```


### Gesamtes Dokument

Um das JSON jeder Datei unverändert zu behalten, wählen Sie unter **Weitere JSON-Optionen** die Option **Jede Datei als eine Zeile mit ihrem gesamten JSON-Dokument importieren** (`whole_document`). Jede Datei wird dann als eine Zeile importiert, die ihr gesamtes JSON-Dokument enthält, wobei Zahlen so bleiben, wie sie geschrieben sind.
