## Beschreibung


Importiert HDF5-Dateien (Hierarchical Data Format Version 5) in PlaidCloud-Projekttabellen. HDF5 ist verbreitet im wissenschaftlichen Rechnen, beim Datenaustausch im maschinellen Lernen und überall dort, wo typisierte, spaltenorientierte Daten zwischen Python-, R- und MATLAB-Werkzeugen hin und her wandern müssen.

Die Formatspezifikation finden Sie in der [Dokumentation der HDF Group](http://www.hdfgroup.org/HDF5/).

## Spezifische Konfigurationselemente


### Schlüsselname

HDF-Dateien speichern Daten in einer Pfadstruktur. Als Ziel für die Tabelle innerhalb der HDF-Datei wird ein Schlüssel (Pfad) benötigt. In den meisten Fällen ist das *table*.
