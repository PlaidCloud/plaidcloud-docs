## Beschreibung


Importiert bestimmte Arbeitsblätter aus einer Google-Sheets-Tabelle in PlaidCloud-Projekttabellen. Nützlich für Ad-hoc-Daten, die in Tabellenkalkulationen liegen – von Fachanwendern gepflegte Treibertabellen, Lookup-Zuordnungen, manuelle Überschreibungen.

Die Authentifizierung erfolgt über eine Google-Verbindung; mehrere Arbeitsblätter einer Tabelle können in einem Schritt importiert werden.

### Quelle und Ziel
#### Google-Konto

Für den Zugriff auf Google-Spreadsheet-Daten ist ein gültiges Google-Benutzerkonto erforderlich. Dieses muss in Tools eingerichtet werden. Einzelheiten zum Einrichten einer Google-Kontoverbindung finden Sie hier: [PlaidCloud Tools – Verbindung](/de/reference/connectors/).

Sobald alle erforderlichen Konten eingerichtet sind, wählen Sie das passende **Google-Konto** aus der Dropdown-Liste.
#### Tabelle

Geben Sie als Nächstes die zu importierende **Tabelle** im Dropdown-Menü an, das alle verfügbaren Dateien enthält, die dem angegebenen **Google-Konto** zugeordnet sind.

<Aside>Stellen Sie sicher, dass das angegebene Benutzerkonto Zugriff auf die angegebene Datei hat, insbesondere wenn die Datei einem anderen Benutzer gehört.</Aside>

### Kopfzeilentyp

Da Google Spreadsheets eine Kopfzeile enthalten können oder nicht, bietet PlaidCloud die Möglichkeit, die Kopfzeilen zu verwenden, sie zu ignorieren oder die Spaltenreihenfolge zur Bestimmung der Spaltenausrichtung zu nutzen.
* **Keine Kopfzeile**: Die Datei enthält keine Kopfzeile.  Verwenden Sie die Quellliste im *Data Mapper*, um die Spaltenausrichtung zu bestimmen.
* **Mit Kopfzeile – Kopfzeile verwenden und Feldliste überschreiben**: Die Datei hat eine Kopfzeile.  Verwenden Sie die angegebenen Kopfzeilennamen und ignorieren Sie die Quellliste im *Data Mapper*.
* **Mit Kopfzeile – Kopfzeile überspringen und stattdessen Feldliste verwenden**: Die Datei hat eine Kopfzeile, sie soll aber ignoriert werden.  Verwenden Sie die Namen, die die Quellliste im *Data Mapper* vorgibt.

### Zu importierende Arbeitsblätter

Da Arbeitsmappen viele Arbeitsblätter mit unterschiedlichen Daten enthalten können, lässt sich auswählen, welche Arbeitsblätter im aktuellen Importvorgang importiert werden sollen.  Die Optionen sind:

* Alle Arbeitsblätter
* Arbeitsblätter, die der Suche entsprechen
* Ausgewählte Arbeitsblätter

#### Arbeitsblattsuche verwenden

Die Suchfunktion für Arbeitsblätter ermöglicht es, Arbeitsblätter einzuschließen, die den Suchkriterien entsprechen.  Die Suchkriterien erlauben:
* **Beginnt mit**: Der Arbeitsblattname beginnt mit dem Suchtext
* **Enthält**: Der Arbeitsblattname enthält den Suchtext
* **Endet mit**: Der Arbeitsblattname endet mit dem Suchtext

#### Blätter in ausgewählter Datei suchen

Die Schaltfläche zum Suchen von Blättern öffnet die Excel-Datei und listet die in der Tabelle verfügbaren Arbeitsblätter auf.  Markieren Sie in der Tabelle die Kontrollkästchen der Arbeitsblätter, die in den Import einbezogen werden sollen.

<Aside>Beim Übernehmen in den *Data Mapper* wird das erste in der Liste gefundene Arbeitsblatt verwendet. Stellen Sie sicher, dass alle Arbeitsblätter, die in den Importschritt einbezogen werden, ein ähnliches Format haben.</Aside>
### Spaltenüberschriften

<Aside>Aufgrund technischer Einschränkungen werden alle Spalten aus Google Spreadsheets als Datentyp String importiert. Die Datentypen Boolean, numerisch und/oder Datum/Uhrzeit müssen im Mapper ausdrücklich angegeben werden.</Aside>
