## Beschreibung

Der Schritt **Import: Getrennt (nach Position)** liest jede Spalte eines getrennten Dokuments nach Position als Textspalten mit den Namen `Column_1` bis `Column_N` und überspringt die Kopfzeile. Verwenden Sie ihn, wenn die Kopfzeile die Spalten nicht benennen kann, zum Beispiel wenn ein späterer Schritt eine Datenzeile zur Kopfzeile befördert.

## Parameter

- **Dokument** – das Dokumentenkonto und der Pfad der Datei. Ein Pfad, der auf `.gz` endet, wird dekomprimiert.
- **Trennzeichen** – das Feldtrennzeichen. Standard ist ein Komma.
- **Anführungszeichen** – Standard ist ein doppeltes Anführungszeichen.
- **Spalte für Datensatznummer** *(optional)* – eine Spalte, die die Datensätze in Dateireihenfolge nummeriert. Lassen Sie das Feld leer, um keine zu schreiben.
- **Ausgabetabelle** – wohin die Zeilen geschrieben werden.

Ein fehlendes Dokument ist kein Fehler. Der Schritt endet mit einer Warnung, die den Pfad nennt, und schreibt eine leere Tabelle.
