## Beschreibung

Importiert Positionsdetails von Kreditorenrechnungen aus Sage Intacct über die Sage-Intacct-REST-API. Jede Zeile ist eine Rechnungsposition, einschließlich Hauptbuchkonto, Dimensionen, Positionsbetrag und dem Rechnungsschlüssel, der auf den übergeordneten Kopfsatz verweist.

Kombinieren Sie diesen Schritt mit [Import Sage AP](../import-sage-ap/), um beide Granularitäten für nachgelagerte Umlagen, Berichte oder Abstimmungen zu laden.

## Besondere Konfigurationselemente

* **Sage-Verbindung** – die Sage-Intacct-REST-Verbindung, aus der gelesen wird. Sage-Verbindungen verwalten Sie unter **Tools > Connections**.
* **Unternehmens-ID** – das Intacct-Unternehmen, das abgefragt wird. Erforderlich, wenn Ihre Sender-Anmeldedaten mehr als ein Unternehmen abdecken.
* **Entitäts-ID(s) (durch Komma getrennt)** – beschränkt den Import auf eine oder mehrere Intacct-Entitäten. Lassen Sie das Feld leer, um alle Entitäten abzurufen, auf die der Benutzer Zugriff hat.
