## Beschreibung

Importiert Kopfsätze von Kreditorenrechnungen aus Sage Intacct über die Sage-Intacct-REST-API. Jede Zeile ist eine Kreditorenrechnung mit Lieferant, Hauptbuchdatum, Fälligkeitsdatum, Summen und Statusfeldern, die für die nachgelagerte Berichterstattung benötigt werden.

Verwenden Sie einen konfigurierten [Sage Intacct REST Connector](../../../connectors/rest/sage-intacct/) als Quelle. Um gleichzeitig Positionsdetails abzurufen, kombinieren Sie diesen Schritt mit [Import Sage AP Lines](../import-sage-ap-lines/).

## Besondere Konfigurationselemente

* **Sage-Verbindung** – die Sage-Intacct-REST-Verbindung, aus der gelesen wird. Sage-Verbindungen verwalten Sie unter **Tools > Connections**.
* **Unternehmens-ID** – das Intacct-Unternehmen, das abgefragt wird. Erforderlich, wenn Ihre Sender-Anmeldedaten mehr als ein Unternehmen abdecken.
* **Entitäts-ID(s) (durch Komma getrennt)** – beschränkt den Import auf eine oder mehrere Intacct-Entitäten. Lassen Sie das Feld leer, um alle Entitäten abzurufen, auf die der Benutzer Zugriff hat.
