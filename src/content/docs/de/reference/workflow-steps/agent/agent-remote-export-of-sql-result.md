## Beschreibung



Führt SQL über einen PlaidLink-Agent auf einer Remote-Datenbank aus und bringt die Ergebnismenge als Projekttabelle zurück in PlaidCloud. Wird verwendet, wenn die Quelldatenbank von PlaidCloud aus nicht direkt erreichbar ist (Firewall, nur per VPN, lokal), Sie aber dennoch Daten daraus holen möchten.

Der Agent führt die Abfrage lokal aus und überträgt das Ergebnis per Stream an PlaidCloud, sodass sowohl Anmeldeinformationen als auch Daten in Ihrem Netzwerk bleiben, bis das Ergebnis benötigt wird.
