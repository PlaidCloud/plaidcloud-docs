## Beschreibung

Importiert eine NetSuite-Stammdatenliste über Ihre [NetSuite-Verbindung](/de/guides/connections/netsuite/) in eine Projekttabelle. Wählen Sie einen Datensatztyp – Konten, Tochtergesellschaften, Abteilungen, Klassen, Standorte, Lieferanten oder Kunden –, und der Schritt ruft die Liste ab und schreibt sie, ohne dass Sie SuiteQL erstellen oder pflegen müssen.

Stammdaten sind die Referenzdaten, auf die die Abrufe von Salden und Details verweisen: die Konten, Tochtergesellschaften und Dimensionen, die Ihre Hauptbuchzeilen als interne IDs tragen. Importieren Sie die benötigte Liste, um diese internen IDs in Namen aufzulösen oder um nachgelagerte Lookups und Joins zu speisen. Dies ist einer der vorgefertigten [NetSuite-Importschritte](/de/reference/workflow-steps/netsuite/), die auf einer gemeinsamen Leseschicht laufen, die das OAuth-Token erneuert, große Ergebnisse seitenweise abruft und vorübergehende Fehler für Sie wiederholt.

## Konfiguration

| Feld | Erforderlich | Hinweise |
|---|---|---|
| NetSuite-Verbindung | Ja | Die NetSuite-Verbindung, über die gelesen wird, gefiltert auf Verbindungen vom Typ NetSuite. |
| Zieltabelle | Ja | Die Projekttabelle, in die die Liste geschrieben wird. Sie wird bei jeder Ausführung vollständig überschrieben. |
| Datensatztyp | Ja | Welche Stammdatenliste abgerufen wird: **account** (Standard), **subsidiary**, **department**, **class**, **location**, **vendor** oder **customer**. |
| Inaktive einbeziehen | Nein | Standardmäßig aus; es werden nur aktive Datensätze zurückgegeben. Aktivieren Sie die Option, um Datensätze einzuschließen, die in NetSuite als inaktiv markiert sind. |

<Aside type="note">
Verwenden Sie diesen Schritt, um die kleinen Referenztabellen aufzubauen, auf die sich die anderen NetSuite-Schritte stützen – rufen Sie zum Beispiel einmal **subsidiary** ab, um die interne ID einer Tochtergesellschaft ihrem Namen zuzuordnen, bevor Sie einen Abruf mit [Salden importieren](/de/reference/workflow-steps/netsuite/import-balances/) oder [Hauptbuchdetails importieren](/de/reference/workflow-steps/netsuite/import-gl-detail/) auf eine Tochtergesellschaft beschränken.
</Aside>
