Workflow-Schritte für Kostenumlage, Weiterbelastung, Verrechnungspreise und ähnliche Probleme der Wertverteilung. Jeder Schritt verteilt Werte aus einer Quellmenge von Zeilen mithilfe von Treiberdaten und einer Methode auf eine Zielmenge.

## Schritte

- [Umlageregeln](/de/reference/workflow-steps/allocation/allocation-rules/) — Umlageregeln mit expliziten Bedingungen definieren und anwenden.
- [Allocation Split](/de/reference/workflow-steps/allocation/allocation-split/) — Quellwerte anhand einer Treibertabelle auf Ziele aufteilen.
- [Regelbasiertes Tagging](/de/reference/workflow-steps/allocation/rule-based-tagging/) — Zeilen vor der Umlage mit Attributen aus einer Dimension taggen.

## Verwandte Themen

- [Umlagen (Leitfaden)](/de/guides/allocations/) — Konzepte und durchgängige Workflows für Umlageprobleme.
- [Dimensionen (Leitfaden)](/de/guides/dimensions/) — die Hierarchien einrichten, auf die Umlagen Werte verteilen.
