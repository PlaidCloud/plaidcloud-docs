## Beschreibung


Kopiert ein ganzes Verzeichnis innerhalb von PlaidCloud Document.



## Verzeichnis kopieren


Wählen Sie zunächst im Dropdown-Menü das passende Konto aus.



Klicken Sie anschließend auf die Schaltfläche **Durchsuchen**, um das Verzeichnis auszuwählen, das Sie kopieren möchten.



## Ziel auswählen


Wählen Sie zunächst im Dropdown-Menü das passende Konto aus.



Klicken Sie anschließend auf die Schaltfläche **Durchsuchen**, um das Ziel für das kopierte Verzeichnis auszuwählen. 



Auf Wunsch kann dem kopierten Verzeichnis ein neuer Name gegeben werden. Aktivieren Sie dazu einfach das Kontrollkästchen **Rename the Copied Folder to:** und geben Sie einen neuen Namen ein.


<Aside>Standardmäßig wird alles überschrieben, was bereits existiert. Achten Sie darauf, nicht versehentlich etwas zu überschreiben.</Aside>
