## Beschreibung


Kopiert eine einzelne Datei innerhalb von PlaidCloud Document.



## Zu kopierende Datei


Wählen Sie zunächst im Dropdown-Menü das passende Konto aus.



Klicken Sie anschließend auf die Schaltfläche **Durchsuchen**, um die Datei auszuwählen, die Sie kopieren möchten.

Statt einer einzelnen Datei können Sie **Dateien kopieren, die der Suche entsprechen** wählen, wodurch die Dateien kopiert werden, deren Namen zu Ihrem Suchtext passen (**Exakt**, **Beginnt mit**, **Enthält** oder **Endet mit**), oder **Alle Dateien im Verzeichnis kopieren**. Wenn Sie einen ganzen Ordner kopieren:

* **Unterordner beibehalten** legt jede Datei unter ihrem Pfad unterhalb des Ordners ab, sodass die Kopie die Struktur des Ordners behält. Ohne diese Option landet jede Datei unter ihrem Namen direkt im Zielordner.
* **Unterordner überspringen** kopiert nur die eigenen Dateien des Ordners, keine aus seinen Unterordnern.

**Nur Dateien kopieren, deren Namen übereinstimmen (regulärer Ausdruck)** schränkt jede dieser Auswahlen auf Dateien ein, deren Name ab dem Anfang einem regulären Ausdruck entspricht, etwa `sales_\d{4}\.csv`. Die Groß-/Kleinschreibung wird beachtet. Lassen Sie das Feld leer, um jede ausgewählte Datei zu kopieren. Ein Muster, das kein gültiger regulärer Ausdruck ist oder einen Teil wiederholt, der sich selbst wiederholt, etwa `(a+)+`, wird beim Speichern des Schritts abgewiesen.

Eine fehlende oder leere Quelldatei bzw. ein fehlender oder leerer Quellordner beendet den Schritt mit einer Warnung, die den Pfad nennt, und es wird nichts kopiert.



## Ziel auswählen


Wählen Sie zunächst im Dropdown-Menü das passende Konto aus.



Klicken Sie anschließend auf die Schaltfläche **Durchsuchen**, um das Ziel für die kopierte Datei auszuwählen.



Standardmäßig lässt Analyze nicht zu, dass Dateien überschrieben werden. Stattdessen wird jeder weiteren Kopie ein numerisches Suffix angehängt. 



Um die vorhandene Datei zu überschreiben, aktivieren Sie einfach das Kontrollkästchen **Allow Overwriting Existing File**.



Um die Datei umzubenennen, aktivieren Sie das Kontrollkästchen **Rename the copied file to** und geben einen neuen Namen ein.

<Aside>Geben Sie beim Ändern des Dateinamens unbedingt eine Dateierweiterung an. Die Datei wird auch ohne Erweiterung erfolgreich erstellt, Betriebssysteme erkennen dann aber ihren Typ nicht.</Aside>


## Zusätzliche Einstellungen

Unter **Wenn die Datei existiert** legt **Eine bereits vorhandene Datei** (`overwrite_policy`) fest, was geschieht, wenn am Ziel bereits eine Datei liegt: **Überschreiben** (`overwrite`, der Standard), **Überschreiben, wenn die Quelle neuer ist** (`overwrite_if_newer`), **Unverändert lassen** (`skip`) oder **Schritt fehlschlagen lassen, nichts kopieren** (`fail`).

Bei **Alle Dateien im Verzeichnis kopieren** schränken die Optionen unter **Welche Dateien** ein, was kopiert wird:

* **Dateien in Unterordnern** (`include_subdirs`) – **Nein** kopiert nur die eigenen Dateien des Ordners und **Ja** kopiert jede Datei darunter unter Beibehaltung ihrer Ordner. Lassen Sie die Option ungesetzt, um jede Datei unter ihrem Namen in den Zielordner zu kopieren, wie es **Unterordner beibehalten** und **Unterordner überspringen** festlegen.
* **Dateinamensmuster** (`file_name_filter`) – nur Dateien, deren Name übereinstimmt. **Mustertyp** ist **Platzhalter** oder **Regulärer Ausdruck** (`type`), und **Groß-/Kleinschreibung beachten** setzt `case_sensitive`.
* **Ordnernamensmuster** (`folder_name_filter`) – nur Dateien in Ordnern, deren Namen übereinstimmen, in derselben Form; jeder Ordner auf dem Weg nach unten muss übereinstimmen.
* **Erweiterungen** (`extensions`) – nur Dateien mit einer dieser Erweiterungen, ohne den Punkt. **Groß-/Kleinschreibung der Erweiterung beachten** (`extensions_case_sensitive`) vergleicht sie unter Beachtung der Groß-/Kleinschreibung.
* **Versteckte Dateien einschließen (Name beginnt mit einem Punkt)** (`include_hidden_files`) und **Versteckte Ordner und deren Inhalt einschließen** (`include_hidden_folders`) – deaktivieren Sie eine der Optionen, um Dateien oder Ordner auszulassen, deren Name mit einem Punkt beginnt.
