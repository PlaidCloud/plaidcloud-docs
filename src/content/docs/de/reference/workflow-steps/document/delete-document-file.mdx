## Beschreibung


Löscht eine vorhandene Datei in PlaidCloud Document.



## Zu löschende Datei


Wählen Sie zuerst das passende Konto im Dropdown-Menü aus.


Klicken Sie anschließend auf die Schaltfläche **Durchsuchen**, um die Datei auszuwählen, die gelöscht werden soll.

<Aside>Wenn die Datei nicht existiert (bereits gelöscht ist), wird keine Aktion ausgeführt.</Aside>
