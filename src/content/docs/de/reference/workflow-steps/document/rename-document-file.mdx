## Beschreibung


Benennt eine vorhandene Datei in PlaidCloud Document um.



## Umzubenennende Datei


Wählen Sie zuerst das passende Konto im Dropdown-Menü aus.



Klicken Sie anschließend auf die Schaltfläche **Durchsuchen**, um die Datei auszuwählen, die umbenannt werden soll.

<Aside>Wenn die umbenannte Datei bereits existiert, wird keine Aktion ausgeführt.</Aside>


## Umbenennen in


Geben Sie den neuen Namen für die Datei ein.
