## Beschreibung


Erstellt ein neues Verzeichnis innerhalb von PlaidCloud Document.



## Speicherort des neuen Ordners


Wählen Sie zunächst im Dropdown-Menü das passende Konto aus.



Klicken Sie anschließend auf die Schaltfläche **Durchsuchen**, um das übergeordnete Verzeichnis auszuwählen.



## Neuer Ordnername


Geben Sie den Namen für das neue Verzeichnis ein.


<Aside>Wenn das Verzeichnis bereits existiert, wird keine Aktion ausgeführt.</Aside>
