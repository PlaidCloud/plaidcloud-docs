## Beschreibung


Benennt ein vorhandenes Verzeichnis in PlaidCloud Document um.



## Umzubenennender Ordner


Wählen Sie zuerst das passende Konto im Dropdown-Menü aus.



Klicken Sie anschließend auf die Schaltfläche **Durchsuchen**, um das Verzeichnis auszuwählen, das umbenannt werden soll.



## Umbenennen in


Geben Sie den neuen Namen für das Verzeichnis ein.


<Aside>Wenn das umbenannte Verzeichnis bereits existiert, wird keine Aktion ausgeführt.</Aside>
