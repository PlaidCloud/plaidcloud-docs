Workflow-Schritte, die über Ihre [Oracle-Essbase-Verbindung](/de/guides/connections/essbase/) aus Oracle **Essbase** lesen: Cube-Daten per Live-MDX-Abfrage und eine Dimensionsgliederung, die in eine PlaidCloud-Dimension geladen wird. Essbase wird **cloud-direkt** über seine REST-API erreicht – für diese Schritte gibt es keinen lokalen Agent-Pfad.

## Schritte

- [Essbase: Cube abfragen](/de/reference/workflow-steps/essbase/essbase-query/) – führt eine Live-MDX-Abfrage gegen einen Cube aus und legt das Ergebnisraster als Tabelle ab. Cloud-direkt.
- [Essbase: Dimension lesen](/de/reference/workflow-steps/essbase/essbase-dimension-read/) – lädt eine Essbase-Dimensionsgliederung in eine PlaidCloud-Dimension. Cloud-direkt.
