## Beschreibung

Entfernt eine Tabelle vollständig aus dem Projekt, sowohl die Tabellendefinition als auch alle zugehörigen Daten. Dies ist destruktiv und nicht umkehrbar: Sobald der Workflow ausgeführt wird, ist die Tabelle weg.

Verwenden Sie diesen Schritt, wenn Zwischentabellen in einem Workflow nachgelagert nicht mehr benötigt werden (zum Beispiel zur Bereinigung nach einer mehrstufigen Transformation). Um eine Tabelle nur vorübergehend zu leeren, ohne sie zu entfernen, verwenden Sie stattdessen [Table Clear (Schritt)](/de/reference/workflow-steps/tables/table-clear/).
