## Beschreibung


Dient dazu, mehrere Datentabellen mit derselben Spaltenstruktur zu einer einzigen Datentabelle zu kombinieren. Zeitreihendaten sind beispielsweise ein idealer Kandidat für diese Transformation. Das Ergebnis enthält alle Datensätze der kombinierten Tabellen.

<Aside>**Union All** entfernt keine Duplikate. Wenn Sie doppelte Datensätze entfernen möchten, verwenden Sie stattdessen **Union Distinct**.</Aside>

## Quellen


Der Abschnitt **Quellen** dient als Sammlung aller Datentabellen, die zusammengefügt werden sollen. In der Regel haben alle Datentabellen dieselbe (oder eine ähnliche) Spaltenstruktur. Zwei Schaltflächen stehen zur Verfügung, um der Liste eine Datentabelle hinzuzufügen:


* **Zeile einfügen**
* **Zeile anhängen**

Zusätzlich zeigt ein Rechtsklick im Fenster **Zu bearbeitende Quelle auswählen** dieselben Optionen an. Ein Rechtsklick auf eine bereits hinzugefügte Tabelle zeigt außerdem die Option **Löschen** an.


Damit die Transformation korrekt ausgeführt wird, muss es im Abschnitt **Quellen** für jede anzuhängende Quelldatentabelle einen Eintrag geben. Diese Einträge werden in der Reihenfolge aufgelistet, in der sie angehängt werden. Um die Reihenfolge anzupassen, zeigt ein Rechtsklick auf eine Tabelle die folgenden Optionen an:


* **Nach unten** (falls zutreffend)
* **An das Ende verschieben** (falls zutreffend)
* **Nach oben** (falls zutreffend)
* **An den Anfang verschieben** (falls zutreffend)

Standardmäßig heißt jede Quelle *New Frame*, aber Modellierer sollten aussagekräftige Namen vergeben, indem sie auf den Namen doppelklicken und ihn entsprechend umbenennen.


<Aside>Beachten Sie, dass der angezeigte Text **nicht** mit dem Namen der Quelldatentabelle zusammenhängt. Wir empfehlen, einen aussagekräftigen Namen zu vergeben, oft denselben wie die Quelldatentabelle, aber bedenken Sie, dass es keinerlei Verbindung zwischen den Namen gibt.</Aside>


## Zieltabelle


Standardmäßig bleibt die **Zieltabelle** leer. Beachten Sie vor der Namensvergabe, dass Datentabellen den Linux-Namenskonventionen folgen müssen. Wir empfehlen daher, dass Namen nur aus alphanumerischen Zeichen bestehen. Analyze entfernt ungültige Zeichen automatisch aus dem Namen. Außerdem begrenzt es die Länge auf 256 Zeichen, fassen Sie sich also kurz!

## Spaltenzuordnung

**Spalten abgleichen nach** unter **Zieltabelle** legt fest, wie die Quellen zueinander ausgerichtet werden:

* **Name** (Standard) — die Spalten jeder Quelle werden anhand des Namens mit denen der ersten Quelle abgeglichen.
* **Position** — die Quellen werden der Reihe nach gestapelt, so wie es `union` von Spark tut. Das Ergebnis übernimmt die Spaltennamen der ersten Quelle, und jede Quelle benötigt dieselbe Anzahl von Spalten. Die Spaltenzuordnung jeder Quelle wird nicht verwendet, daher ist ihre Registerkarte **Spalten** deaktiviert.

Bei **Position** erhält jede Spalte einen Typ, in den jede Quelle passt: Zwei numerische Typen werden zum breiteren, ein Datum und ein Zeitstempel werden zu einem Zeitstempel, und andere Mischungen werden zu Text. Eine boolesche oder binäre Spalte, die mit einem anderen Typ gemischt ist, hat keinen gemeinsamen Typ und lässt den Schritt fehlschlagen, ebenso Quellen mit unterschiedlicher Spaltenanzahl.

Wenn jede Quelltabelle fehlt, endet der Schritt in beiden Modi mit einer Warnung statt mit einem Fehler.

## Was beim Speichern geprüft wird

Jede Quelle muss dieselben Spalten wie die erste Quelle liefern: dieselben Spaltennamen und, wo beide einen deklarieren, denselben Typ. Die Zieltabelle wird aus den Spalten der ersten Quelle aufgebaut. Eine Quelle kann ihre Spalten in anderer Reihenfolge auflisten, weil sie anhand des Namens abgeglichen werden. Das Speichern eines Schritts, dessen Quellen sich unterscheiden, wird abgelehnt, wobei jeder Unterschied benannt wird: *Die Quelle 'east' muss dieselben Spalten wie 'west' liefern: fehlend region; nicht in 'west': area.*

Beim Speichern wird außerdem die Zuordnung jeder Quelle, die eine Quelltabelle, aber keine Quell- oder Zielspalten hat, aus dieser Tabelle gefüllt, so wie es **Beide Zuordnungstabellen füllen** täte.
