## Beschreibung

Füllt eine Zieltabelle mit einem von Ihnen selbst geschriebenen SQL-`SELECT`. Während [Table Extract (Schritt)](/de/reference/workflow-steps/tables/table-extract/) die Abfrage aus zugeordneten Spalten und Ausdrücken aufbaut, übergibt dieser Schritt die Abfrage direkt an das Warehouse. Das eignet sich für Fälle, in denen sich das SQL direkt einfacher formulieren lässt, als es im Mapper zusammenzustellen.

Verwenden Sie ihn, wenn Sie ein Konstrukt benötigen, das der Mapper nicht abdeckt: eine rekursive CTE, eine Fensterfunktion über eine Partition, die der Mapper nicht beschreiben kann, oder eine Abfrage über mehrere Tabellen, die ein Join-Schritt unnötig kompliziert machen würde.

## Spezifische Konfigurationselemente

### SQL-Select-Abfrage

Der Abfragetext. Formatieren Sie ihn als lesbares, mehrzeiliges, eingerücktes SQL (eine Spalte oder Klausel pro Zeile) statt als eine einzige lange Zeile. Der Schritt behält bei, was Sie schreiben, und die nächste Person, die ihn öffnet, muss es lesen können.

Die Abfrage wird im Lakehouse des Projekts ausgeführt, daher stehen je nach Workspace die Funktionen von [Lakehouse v1](/de/reference/expressions/lakehouse-v1/) oder [v2](/de/reference/expressions/lakehouse-v2/) zur Verfügung.
