## Beschreibung


Dient dazu, einen Outer Join auf zwei Datentabellen auszuführen und sie anhand der angegebenen Join-Schlüssel zu einer einzigen Datentabelle zu kombinieren. Das Steuerelement **Verknüpfungstyp** bestimmt, welche nicht übereinstimmenden Zeilen behalten werden — ein **Left**, **Right** oder **Full Outer** Join. Standard ist ein Left Join (jede Zeile aus Tabelle A, wobei die Spalten von Tabelle B ausgefüllt werden, wo die Schlüssel übereinstimmen).


Weitere Einzelheiten zur Methodik des Outer Joins finden Sie hier: [Wikipedia: SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## Zur Laufzeit benannte Spalten

Wählen Sie **Auch zur Laufzeit benannte Spalten übernehmen**, um jede Quellspalte, die der Schritt nicht auflistet, unverändert so durchzureichen, wie die Tabelle sie bei der Ausführung des Schritts hat. Verwenden Sie dies, wenn ein früherer Schritt Spalten erzeugt, deren Namen von den Daten abhängen, etwa ein Pivot, sodass Sie sie beim Aufbau des Schritts nicht auflisten können. Lassen Sie es ausgeschaltet, um nur die Spalten zu schreiben, die Sie auflisten.

### Verknüpfungstyp

Wählen Sie, wie nicht übereinstimmende Zeilen behalten werden:

- **Left Join** — behält jede Zeile aus Tabelle A; die Spalten von Tabelle B werden nur ausgefüllt, wo die Join-Schlüssel übereinstimmen. Das ist der Standard.
- **Right Join** — behält jede Zeile aus Tabelle B; die Spalten von Tabelle A werden nur ausgefüllt, wo die Join-Schlüssel übereinstimmen.
- **Full Outer Join** — behält jede Zeile aus beiden Tabellen, unabhängig davon, ob sie auf der anderen Seite eine Entsprechung hat.

## Beispiele


### Automobilhersteller mit Modellen verknüpfen


Betrachten Sie in diesem Beispiel die folgenden Quelldatentabellen. Zuerst eine Liste von Automobilherstellern.




| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


Als Nächstes eine Liste von Automodellen mit einer Hersteller-ID. Beachten Sie, dass es mehrere Modelle ohne Hersteller gibt.




| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

Um eine Liste der Modelle nach Hersteller zu erhalten, bietet sich ein Join über *Mfg_ID* an. Durch die Nutzung von Outer-Join-Konzepten kann die Ausgabe auch jene Einträge zeigen, die keine Entsprechung haben.



Legen Sie zuerst die Parameter für **Table 1 Data Selection** fest. Die Quelldatentabelle ist ausgewählt, und alle Spalten werden aufgelistet.



Legen Sie als Nächstes die Parameter für **Table 2 Data Selection.** fest. Wieder ist die Quelldatentabelle ausgewählt, und alle Spalten werden aufgelistet.



Zum Schluss werden die Join-Bedingungen auf der Registerkarte **Ausgabe** festgelegt. Mit der Schaltfläche **Erraten** erkennt Analyze korrekt die Spalte *Mfg_ID*, die als **Join Key** verwendet wird. Da dieses Beispiel nicht übereinstimmende Zeilen aus beiden Tabellen behält, setzen Sie den **Verknüpfungstyp** auf **Full Outer Join**. Schließlich werden die 


**Zielausgabespalten** automatisch mit der Schaltfläche **Weitergeben** festgelegt. Dadurch werden effektiv alle Spalten aller Tabellen aufgenommen, wobei Join-Spalten selbstverständlich nur ein einziges Mal enthalten sind. Beachten Sie, dass die Spalten alphabetisch sortiert sind, zuerst nach *Manufacturer* und dann nach *ModelName*.



Wie erwartet enthält die endgültige Ausgabe alle Zeilen aus beiden Tabellen, unabhängig davon, ob sie in beiden Tabellen eine Entsprechung hatten. Daher erscheint *Porsche* diesmal tatsächlich, obwohl es keine Modelle hat. Außerdem sind *Batmobile*, *Lightning McQueen* und *Optimus Prime* im Ergebnis enthalten, obwohl keiner von ihnen einen Hersteller hat. Und wer könnte zu ihnen schon ‚Nein‘ sagen?
