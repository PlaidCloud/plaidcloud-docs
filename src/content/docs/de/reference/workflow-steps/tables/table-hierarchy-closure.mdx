## Beschreibung

Der Schritt **Tabelle: Hierarchieabschluss** verfolgt jede Zeile über ihre Kette übergeordneter Knoten nach oben und schreibt für jede Zeile und jeden ihrer Vorgänger eine Ausgabezeile. Es gibt keine Tiefenbegrenzung. Die Distanzspalte ist 0 für die Zeile selbst, 1 für ihren übergeordneten Knoten usw.

Eine Traversierung endet an einer Wurzel, an einem übergeordneten Knoten, den die Knotentabelle nicht enthält, oder an einem Knoten, dem sie bereits begegnet ist, sodass eine Schleife in den IDs der übergeordneten Knoten nicht endlos laufen kann. Bei einer Schleife bleiben alle Vorgänger bis zum wiederholten Knoten erhalten. Eine Schleife, die keine Wurzel erreicht, endet bei ihrer kleinsten ID.

## Quelle & Optionen

- **Ausgangszeilen für die Traversierung**: die Tabelle, deren Zeilen die Traversierungen starten.
- **ID-Spalte** und **Spalte für übergeordneten Knoten**: die ID jeder Zeile und die ID ihres übergeordneten Knotens. NULL oder die eigene ID der Zeile kennzeichnet eine Wurzel.
- **Knotentabelle** *(optional)*: die Tabelle der Knoten, über die die Traversierung aufsteigt. Lassen Sie das Feld leer, um die Quelltabelle zu verwenden.
- **ID-Spalte der Knoten** und **Spalte für übergeordneten Knoten der Knoten** *(optional)*: standardmäßig die ID- und die Elternspalte. Eine ID mit mehreren Zeilen folgt einer Wurzelzeile, sonst ihrem kleinsten übergeordneten Knoten.
- **Vorgängerspalte**: die Ausgabespalte, die die ID des Vorgängers enthält. Standard ist `Ancestor`.
- **Distanzspalte**: die Anzahl der Schritte von der Startzeile. Standard ist `Distance`.
- **Entlang des Pfads aufgebaute Zeichenfolgen** *(optional)*: eine Zeile pro Textspalte, die beim Aufsteigen der Traversierung aufgebaut wird. Jede Zeile hat:
  - **Ausgabespalte**: die neue Spalte.
  - **Quellspalte**: die Spalte, die als Text gelesen wird, und **Knotenspalte**, die aus der Knotentabelle gelesen wird, wenn sie abweicht.
  - **Trennzeichen**: der Text zwischen den Werten.
  - **Eindeutig**: überspringt einen Wert, den der Text bereits enthält.
  - **Wurzel zuerst**: setzt jeden Vorgänger vor den bisherigen Text.
- **Ausgabetabelle**: wohin das Ergebnis geschrieben wird.

Die Ausgabe enthält die ID- und die Elternspalte, die Vorgänger- und die Distanzspalte sowie eine Textspalte für jede von Ihnen aufgebaute Zeichenfolge.
