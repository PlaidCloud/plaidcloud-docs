## Beschreibung

Fügt Zeilen aus einer Quelltabelle am Ende einer vorhandenen Zieltabelle hinzu. Vorhandene Zeilen in der Zieltabelle bleiben erhalten; es werden nur neue Zeilen eingefügt. Verwenden Sie den Schritt, wenn Daten inkrementell eintreffen (z. B. tägliche Extrakte, monatliche Ladedateien) und die Zieltabelle mit der Zeit wachsen soll, statt ersetzt zu werden.

Wenn Sie beim Anhängen deduplizieren müssen, lassen Sie einen Schritt [Table Union Distinct (Schritt)](/de/reference/workflow-steps/tables/table-union-distinct/) folgen, oder verwenden Sie [Table Upsert (Schritt)](/de/reference/workflow-steps/tables/table-upsert/), wenn einige Zeilen vorhandene Datensätze anhand des Schlüssels aktualisieren.

## Was beim Speichern geprüft wird

- **Die Zuordnung passt zu einer vorhandenen Zieltabelle.** Wenn die Zieltabelle bereits existiert, kann der Schritt keine Spalte zuordnen, die die Tabelle nicht hat, und einer Spalte keinen anderen Typ geben als in der Tabelle. Numerisch und Währung gelten als derselbe Typ. Eine Tabellenspalte, die die Zuordnung auslässt, ist zulässig und bleibt in den angehängten Zeilen leer. Die Ablehnung nennt jeden Unterschied, zum Beispiel *The target columns must match the existing target table 'sales'. Types differ: amount (table: numeric, step: text).* Eine Zieltabelle, die noch nicht existiert, oder eine, die mit einer Variable benannt ist, wird geprüft, wenn der Schritt ausgeführt wird.
- **Eine leere Zuordnung wird für Sie befüllt.** Wenn Sie beim Speichern eine Quelltabelle gewählt haben, aber keine Quell- oder Zielspalten, wird die leere Seite aus der Quelle befüllt, so als hätten Sie **Beide Zuordnungstabellen füllen** gewählt.
