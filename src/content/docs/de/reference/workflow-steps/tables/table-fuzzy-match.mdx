## Beschreibung

Der Schritt **Fuzzy Match** ordnet Zeilen zweier Tabellen anhand ungefährer Feldübereinstimmungen zu (oder entfernt Duplikate in einer Tabelle). Er läuft in der Workflow-Engine; die Ergebnisse gepackter Makros sind eine Annäherung an das Alteryx-Makro.

## Parameter

- **Linke/Rechte Tabelle** und die **Ausgabetabelle**.
- **Datensatz-ID-Spalte**, **Schwellenwert** (0-100) und **Auch nicht übereinstimmende Zeilen ausgeben**.
- **Abgleichsfelder**: die abzugleichenden Felder und die jeweilige Abgleichsfunktion (exact / jaro / levenshtein / bestof / jaro_tfidf / bestof_tfidf).
