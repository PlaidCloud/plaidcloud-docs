## Beschreibung

Der Schritt **Tabelle: JWT codieren** signiert das JSON in einer Nutzdatenspalte und schreibt das Token in eine neue Textspalte, ein Token pro Zeile. Die Ausgabetabelle ist eine Kopie der Quelle mit dieser zusätzlichen Spalte.

## Quelle & Optionen

- **Quelltabelle** und **Ausgabetabelle**: die Tabelle, die gelesen wird, und die Tabelle, in die geschrieben wird.
- **Algorithmus**: `HS256`, `HS384`, `HS512`, `RS256`, `RS384` oder `RS512`.
- **Nutzdatenspalte**: die Spalte mit den zu signierenden JSON-Nutzdaten.
- **Kopfzeilenspalte** *(optional)*: eine Spalte mit einem JSON-Header. Er wird über den Standard-Header `{"alg": …, "typ": "JWT"}` gelegt.
- **Schlüsselspalte** *(optional)*: eine Spalte mit dem Signaturschlüssel. Ohne sie signiert der Schritt mit dem Schlüssel, den seine Verbindung enthält.
- **Ausgabespalte**: der Name der Textspalte, die das Token erhält.

Eine konvertierte Savant-Analyse signiert mit einem Schlüssel, der in einer dem Schritt zugeordneten eigenen Verbindung liegt, sodass der Schlüssel nie in der Schrittkonfiguration erscheint. Siehe [Savant-Analysen migrieren](/de/guides/workflows/migrate-savant-analyses/#jwt_encode).
