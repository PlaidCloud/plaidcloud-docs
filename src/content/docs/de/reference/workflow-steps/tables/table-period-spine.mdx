## Beschreibung

Der Schritt **Tabelle: Periodenreihe** schreibt eine Zeile für jede Periode zwischen einem ersten und einem letzten Datum, unabhängig davon, ob ein Datensatz in sie fällt. Verknüpfen Sie die Periodenreihe mit Ihren zusammengefassten Daten, um eine Periode ohne Aktivität als null darzustellen, statt sie wegzulassen.

## Quelle & Optionen

- **Quelltabelle** und **Datumsspalte**: die Tabelle, deren Datumsangaben die Grenzen festlegen. Sie werden benötigt, sofern Sie nicht sowohl ein erstes als auch ein letztes Datum angeben; in diesem Fall wird die Quelle nicht gelesen.
- **Periode**: **Tag**, **Woche**, **Monat**, **Quartal**, **Jahr** oder **Jahrzehnt**. Eine Woche beginnt am Montag.
- **Erstes Datum** *(optional)*: die erste Periode. Lassen Sie das Feld leer, um mit dem frühesten Datum in der Quelltabelle zu beginnen.
- **Letztes Datum** *(optional)*: die letzte Periode. Lassen Sie das Feld leer, um mit dem spätesten Datum in der Quelltabelle zu enden. Liegt das erste Datum nach dem letzten, werden beide mit einer Warnung vertauscht.
- **Ausgabespalte**: der Name der Datumsspalte, die den ersten Tag jeder Periode enthält. Standard ist `Period Start`.
- **Ausgabetabelle**: wohin die Periodenreihe geschrieben wird.

Der Schritt hält bei 100.000 Perioden an und warnt, wenn dies geschieht. Wählen Sie für einen größeren Bereich eine längere Periode oder engere Datumsgrenzen.
