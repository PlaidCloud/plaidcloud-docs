## Beschreibung

Kopiert eine Tabelle von einem Projekt in ein anderes. Verwenden Sie den Schritt, um eine freigegebene Referenztabelle, eine veröffentlichte Ergebnismenge oder eine dimensionsbasierte Nachschlagetabelle zwischen Projekten zu übertragen, ohne sie in eine Datei zu exportieren und wieder zu importieren.

Beide Seiten werden ausdrücklich benannt — ein Quellprojekt mit Tabelle und ein Zielprojekt mit Tabelle. Das Zielprojekt ist zunächst das aktuelle Projekt, kann aber jedes beliebige Projekt sein; ein Schritt kann also in dieses Projekt hinein, aus ihm heraus oder zwischen zwei anderen kopieren. Die Zieltabelle wird angelegt, falls sie nicht existiert, und muss eine Tabelle sein, keine Ansicht.

## Datenfreigabe-Verwaltung

Für eine Kopie sind bis zu zwei Datenfreigaben nötig:

- **Lesen, vom Quellprojekt zum Zielprojekt**, sodass die Daten der Quelle nur dorthin gelangen, wohin die Quelle sie freigibt. Öffnen Sie im **Quellprojekt** die Registerkarte **Startseite**, klicken Sie unter **Datenfreigabe-Verwaltung** auf **Neue Datenfreigabe**, wählen Sie das Zielprojekt, aktivieren Sie unter **Zulässige Vorgänge** die Option **Lesen** und klicken Sie auf **Datenfreigabe hinzufügen**.
- **Schreiben, vom Zielprojekt zu diesem Projekt** — dem Projekt, in dem der Workflow liegt und das schreibt —, wenn das Ziel ein anderes Projekt ist. Öffnen Sie im **Zielprojekt** die Registerkarte **Startseite**, klicken Sie unter **Datenfreigabe-Verwaltung** auf **Neue Datenfreigabe**, wählen Sie dieses Projekt, aktivieren Sie unter **Zulässige Vorgänge** die Option **Schreiben** und klicken Sie auf **Datenfreigabe hinzufügen**.

Eine Kopie in dieses Projekt hinein braucht also nur die Lesefreigabe, und eine Kopie innerhalb eines Projekts braucht keine von beiden. Siehe [Daten zwischen Projekten freigeben](/de/guides/projects/managing-projects/#daten-zwischen-projekten-freigeben).

Fehlt eine benötigte Freigabe, wird das Speichern des Schritts verweigert und eine Ausführung schlägt fehl, mit einer Meldung, die jede hinzuzufügende Freigabe nennt — zum Beispiel *Project 'Sales' can't write to project 'Finance': in project 'Finance', under Data Sharing Management, add a data share for 'Sales' that allows Write.* Eine verweigerte Ausführung lässt das Zielprojekt unverändert, ohne die Zieltabelle anzulegen. Ein Projekt, das als Variable angegeben ist, wird geprüft, wenn der Schritt ausgeführt wird.

Der Schritt läuft mit der eigenen Identität dieses Projekts, sodass eine Ausführung über die Freigaben funktioniert, wer auch immer sie startet.

## Kopierparameter

### Lesen aus

- **Quellprojekt** — das Projekt, aus dem kopiert wird.
- **Quelltabelle** — die zu kopierende Tabelle, ausgewählt aus dem Quellprojekt.

### Schreiben nach

- **Zielprojekt** — das Projekt, in das kopiert wird. Es ist zunächst das aktuelle Projekt.
- **Zieltabelle** — die zu schreibende Tabelle, ausgewählt aus dem Zielprojekt. Wenn Sie ein anderes **Zielprojekt** wählen, wird eine aus dem bisherigen Projekt gewählte Tabelle zurückgesetzt; eine per Name oder Pfad angegebene Tabelle bleibt erhalten und wird im neuen Projekt gesucht.
- **An vorhandene Daten anfügen** — aktivieren Sie die Option, um die kopierten Zeilen zu dem hinzuzufügen, was die Zieltabelle bereits enthält. Lassen Sie sie deaktiviert, um die Zeilen der Tabelle durch die der Quelle zu ersetzen.

Ein gespeichertes Projekt, das Sie nicht sehen können oder das gelöscht wurde, wird mit **(missing)** markiert angezeigt, statt durch ein anderes Projekt ersetzt zu werden.
