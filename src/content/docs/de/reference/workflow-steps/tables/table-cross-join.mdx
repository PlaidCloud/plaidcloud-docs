## Beschreibung


Führt, wie der Name schon sagt, einen Cross Join auf zwei Datentabellen aus und kombiniert sie ohne Join-Schlüssel zu einer einzigen Datentabelle.


Ein Quellfilter auf einer der beiden Tabellen wird angewendet, bevor die Größe des Joins bestimmt wird. Ein gefilterter Cross Join über große Tabellen wird daher ausgeführt, wenn nach dem Filtern nur noch wenige Zeilen übrig sind.

Weitere Informationen zur Methodik des Cross Join finden Sie hier: [Wikipedia SQL Cross Join](https://en.wikipedia.org/wiki/Join_%28SQL%29#Cross_join)

## Zur Laufzeit benannte Spalten

Wählen Sie **Auch zur Laufzeit benannte Spalten übernehmen**, um jede Quellspalte, die der Schritt nicht aufführt, unverändert weiterzugeben, so wie die Tabelle sie bei der Ausführung des Schritts hat. Verwenden Sie die Option, wenn ein vorheriger Schritt Spalten erzeugt, deren Namen von den Daten abhängen (zum Beispiel ein Pivot), sodass Sie sie beim Erstellen des Schritts nicht auflisten können. Lassen Sie sie deaktiviert, um nur die von Ihnen aufgeführten Spalten zu schreiben.
