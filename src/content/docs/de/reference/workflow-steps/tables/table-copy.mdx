## Beschreibung


Erstellt eine Kopie einer Datentabelle.




<SnippetCommonTableSourceAndTarget />



Beim Kopieren prüft Analyze zunächst, ob die Zieltabelle bereits existiert. Ist dies der Fall, wird keine Aktion ausgeführt, es sei denn, das Kontrollkästchen **Allow Overwriting Existing Table** ist aktiviert. In diesem Fall wird die Zieltabelle überschrieben.
