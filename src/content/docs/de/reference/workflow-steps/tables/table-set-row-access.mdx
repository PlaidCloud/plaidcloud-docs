## Beschreibung

Der Schritt „Zeilenzugriff festlegen“ berechnet die Zeilenzugriff-Berechtigungen einer gesteuerten Spalte aus einer Quelltabelle neu und wendet sie an.
Verweisen Sie mit der Spalte auf eine Tabelle, in der jede Zeile eine Sicherheitsgruppe mit einem Wert verknüpft, den diese Gruppe sehen darf. Der Schritt liest diese Zeilen und schreibt die daraus resultierenden Berechtigungen. So bleibt der Zeilenzugriff aktuell, wenn sich die Quelldaten ändern, ohne dass jemand das Raster von Hand bearbeiten muss.

Die Spalte muss bereits Zeilen einschränken. Richten Sie sie zuerst im Zeilenzugriff-Raster ein. Bei der ersten Ausführung bindet der Schritt die Spalte an die Quelltabelle: Die von Hand festgelegten Berechtigungen der Spalte werden gelöscht und durch die Zeilen der Tabelle ersetzt. Ab dann wird die Spalte im Zeilenzugriff-Raster gesperrt und mit einem Quellensymbol angezeigt, und die manuelle Bearbeitung dort wird abgelehnt, bis jemand auf **Bindung entfernen** klickt. Siehe
[Berechtigungen an eine Quelltabelle binden](/de/administration/access/managing-security-groups-and-assignments/#gewährungen-an-eine-quelltabelle-binden)
in der Anleitung zum Zeilenzugriff.

<Aside type="note" title="Berechtigungen mit sich ändernden Daten synchron halten">
Ein typischer Einsatz ist, diesen Schritt nach dem Workflow zu planen, der die Quelltabelle lädt oder aktualisiert. So gelangen eine neue Gruppe, ein entfernter Wert oder ein neu zugewiesenes Gebiet bei der nächsten Ausführung automatisch in den Zeilenzugriff, statt dass jemand daran denken muss, das Raster von Hand zu aktualisieren.
</Aside>

## Parameter

- **Projekt** — das Projekt, dessen gesteuerte Spalte dieser Schritt aktualisiert.
- **Spalte** — die gesteuerte Spalte, ausgewählt aus den tatsächlichen Spalten des Projekts.
- **Quelltabelle** — die Tabelle, die die (Gruppe, Wert)-Zeilen liefert. Wenn Sie eine andere Tabelle als die angeben, an die die Spalte gebunden ist, wird die Spalte an die neue Tabelle gebunden.
- **Gruppenspalte** — die Spalte der Quelltabelle, die die Sicherheitsgruppe benennt.
- **Wertspalte** — die Spalte der Quelltabelle, die den Wert benennt, den diese Gruppe sehen darf.

## Verhalten

Jede Ausführung liest alle aktuell in der Quelltabelle vorhandenen (Gruppe, Wert)-Zeilen und ersetzt die Berechtigungen der Spalte durch genau diese Menge. Eine Gruppe, die nicht mehr in der Quelltabelle vorkommt, verliert alle Berechtigungen, die dieser Schritt ihr zuvor erteilt hat. Zeilen, die eine nicht vorhandene Sicherheitsgruppe benennen, werden übersprungen, statt den Schritt fehlschlagen zu lassen. Die Aktualisierung erreicht sowohl die eigenen Abfragen von PlaidCloud als auch Superset-Dashboards auf dieselbe Weise wie ein manuelles Speichern, in der Regel innerhalb von etwa einer Minute.

Da die Quelltabelle bestimmt, wer was sieht, können nach der Bindung nur ein Projekt-Architect, ein Mandantenadministrator oder die Workflows des Projekts ihre Zeilen ändern oder sie löschen.

<Aside type="caution">
Dieser Schritt ersetzt die *gesamte* Menge der von ihm verwalteten Berechtigungen. Wenn Sie einen Teil der Berechtigungen einer Spalte von Hand und andere aus einer Quelltabelle pflegen, halten Sie beides in getrennten Spalten. Von Hand bearbeitete Berechtigungen an einer quellgebundenen Spalte bleiben zwischen den Ausführungen nicht erhalten.
</Aside>
