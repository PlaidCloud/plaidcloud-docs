## Beschreibung

Der Schritt **Tabelle: Kopfzeile hochstufen** nimmt eine Zeile der Eingabe, macht ihre Werte zu den Spaltennamen und entfernt diese Zeile anschließend. Verwenden Sie ihn für eine Datei, deren eigentliche Kopfzeile nicht die erste Zeile ist. Der Schritt läuft, wenn der Workflow ausgeführt wird, die Namen stammen also aus den Daten.

## Quelle & Optionen

- **Quelltabelle** und **Ausgabetabelle**: die Tabelle, die gelesen wird, und die Tabelle, in die geschrieben wird.
- **Kopfzeile**: die Zeile, ab 1 gezählt, deren Werte die Spalten benennen. Sie wird aus den Daten entfernt. Lassen Sie das Feld leer, um keine Kopfzeile hochzustufen und die Formatierungsschritte auf die gespeicherten Namen anzuwenden.
- **Spalte für Datensatzreihenfolge** *(optional)*: die Spalte, die die Zeilen in eine Reihenfolge bringt. Ohne sie werden die Zeilen so gelesen, wie sie gespeichert sind, sodass sich von Ausführung zu Ausführung ändern kann, welche Zeile die Spalten benennt.
- **Spalten, wenn die Eingabe leer ist** *(optional)*: durch Kommas getrennte Namen von Textspalten, die geschrieben werden, wenn die Eingabe keine Zeilen hat.

## Formatierungsschritte

Jede Zeile des Rasters **Formatierungsschritte** ändert die hochgestuften Namen.

| Einstellung | Auswahlmöglichkeiten |
| --- | --- |
| Aktion | **Umbenennen**, **Typ ändern**, **Ausblenden**, **Leerwerte füllen** |
| Abgleichsart | **Enthält**, **Beginnt mit**, **Endet mit** oder **Ist leer** |
| Übereinstimmender Text | Der Text, der im Spaltennamen gesucht wird. Für **Ist leer** nicht erforderlich. |
| Umbenennen durch | **Text ersetzen**, **Davor einfügen** oder **Danach einfügen**, für eine Umbenennung |
| Ersetzen durch | Der neue Text für eine Umbenennung oder Füllung |
| Wert | Der Typ für **Typ ändern** |

Jeder Schritt braucht eine Aktion und eine Abgleichsart, und eine Umbenennung braucht eine Umbenennungsmethode und ihren Text.
