## Beschreibung


Wenn Sie die Funktion SVERWEIS (vlookup) in Microsoft Excel regelmäßig verwenden, wird Ihnen der Schritt Table Lookup sehr vertraut vorkommen. Er erfüllt im Wesentlichen dieselbe Aufgabe. Anders als die Microsoft-Excel-Variante bietet der Schritt Table Lookup von PlaidCloud Analyze mehr Flexibilität, insbesondere durch den Abgleich über mehrere Spalten und die Rückgabe mehrerer Spalten.

## Beispiele


### Produktdimensionsinformationen nachschlagen


In diesem Beispiel benötigt der Modellierer Informationen aus der Produktdimensionstabelle, um die Auftragsfaktentabelle zu verstehen. Deshalb ist die Tabelle *Import Order Fact* als **Quelltabelle** ausgewählt. Die Tabelle *Import Product Dim* enthält die gewünschten Nachschlageinformationen und ist daher als **Lookup Table Source** ausgewählt. Obwohl es möglich wäre, werden auf die Nachschlagedatentabelle keine Filter angewendet (ebenso wenig wie auf andere Datentabellen).



Im Abschnitt **Tabellendatenauswahl** werden alle Spalten aus der Quelldatentabelle der Zieldatentabelle zugeordnet. 



Weder auf die Quell- noch auf die Zieldaten werden **Datenfilter** angewendet. 



Zum Schluss wird die Quelldatentabelle über das Feld *Product_ID*, das in beiden Tabellen vorhanden ist, mit der Nachschlagedatentabelle abgeglichen. Nur die Spalten *Product_Description* und *Unit_Cost* werden an die Zieldatentabelle angehängt, wobei *Unit_Cost* dabei in *Retail_Unit_Cost* umbenannt wird. 



In der resultierenden Zieldatentabelle wurden die Spalten *Product_Description* und *Retail_Unit_Cost* auf Basis übereinstimmender Werte in der Spalte *Product_ID* hinzugefügt.
