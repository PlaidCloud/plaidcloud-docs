## Beschreibung


Dient, wie zu erwarten, dazu, einen Inner Join auf zwei Datentabellen auszuführen und sie anhand der angegebenen Join-Schlüssel zu einer einzigen Datentabelle zu kombinieren.


Weitere Einzelheiten zur Methodik des Inner Joins finden Sie hier: [Wikipedia: SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## Zur Laufzeit benannte Spalten

Wählen Sie **Auch zur Laufzeit benannte Spalten übernehmen**, um jede Quellspalte, die der Schritt nicht auflistet, unverändert so durchzureichen, wie die Tabelle sie bei der Ausführung des Schritts hat. Verwenden Sie dies, wenn ein früherer Schritt Spalten erzeugt, deren Namen von den Daten abhängen, etwa ein Pivot, sodass Sie sie beim Aufbau des Schritts nicht auflisten können. Lassen Sie es ausgeschaltet, um nur die Spalten zu schreiben, die Sie auflisten.

## Beispiele


### Automobilhersteller mit Modellen verknüpfen


Betrachten Sie in diesem Beispiel die folgenden Quelldatentabellen. Zuerst eine Liste von Automobilherstellern.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

Als Nächstes eine Liste von Automodellen mit einer Hersteller-ID. Beachten Sie, dass es mehrere Modelle ohne Hersteller gibt.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

Um eine Liste der Modelle nach Hersteller zu erhalten, bietet sich ein Join über *Mfg_ID* an.


Legen Sie zuerst die Parameter für **Table 1 Data Selection** fest. Die Quelldatentabelle ist ausgewählt, und alle Spalten werden aufgelistet.



Legen Sie als Nächstes die Parameter für **Table 2 Data Selection** fest. Wieder ist die Quelldatentabelle ausgewählt, und alle Spalten werden aufgelistet.



Zum Schluss werden die Join-Bedingungen auf der Registerkarte **Ausgabe** festgelegt. Mit der Schaltfläche **Erraten** erkennt Analyze korrekt die Spalte *Mfg_ID*, die als **Join Key** verwendet wird. Schließlich werden die 


**Zielausgabespalten** automatisch mit der Schaltfläche **Weitergeben** festgelegt. Dadurch werden effektiv alle Spalten aller Tabellen aufgenommen, wobei alle Join-Spalten nur ein einziges Mal enthalten sind. Beachten Sie, dass die Spalten alphabetisch sortiert sind, zuerst nach *Manufacturer* und dann nach *ModelName*.



Wie erwartet enthält die endgültige Ausgabe nur Werte, die in beiden Tabellen eine Entsprechung hatten. *Porsche* erscheint daher nicht, weil es keine Modelle hatte. Ebenso hatte der 


*Batmobile* keinen Hersteller (es war eine Sonderanfertigung) und ist deshalb nicht enthalten.
