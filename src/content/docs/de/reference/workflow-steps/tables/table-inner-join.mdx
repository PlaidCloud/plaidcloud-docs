## Beschreibung


Führt, wie der Name schon sagt, einen Inner Join auf zwei Datentabellen aus und kombiniert sie anhand der angegebenen Join-Schlüssel zu einer einzigen Datentabelle.


Weitere Informationen zur Methodik des Inner Join finden Sie hier: [Wikipedia SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## Zur Laufzeit benannte Spalten

Wählen Sie **Auch zur Laufzeit benannte Spalten übernehmen**, um jede Quellspalte, die der Schritt nicht aufführt, unverändert weiterzugeben, so wie die Tabelle sie bei der Ausführung des Schritts hat. Verwenden Sie die Option, wenn ein vorheriger Schritt Spalten erzeugt, deren Namen von den Daten abhängen (zum Beispiel ein Pivot), sodass Sie sie beim Erstellen des Schritts nicht auflisten können. Lassen Sie sie deaktiviert, um nur die von Ihnen aufgeführten Spalten zu schreiben.

## Beispiele


### Automobilhersteller mit Modellen verknüpfen


Betrachten Sie in diesem Beispiel die folgenden Quelldatentabellen. Die erste ist eine Liste von Automobilherstellern.



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

Die nächste ist eine Liste von Automodellen mit einer Hersteller-ID. Beachten Sie, dass es mehrere Modelle ohne Hersteller gibt.




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

Um eine Liste der Modelle nach Hersteller zu erhalten, bietet sich ein Join über *Mfg_ID* an.


Legen Sie zunächst die Parameter für **Table 1 Data Selection** fest. Die Quelldatentabelle ist ausgewählt, und alle Spalten sind aufgelistet.



Legen Sie als Nächstes die Parameter für **Table 2 Data Selection** fest. Auch hier ist die Quelldatentabelle ausgewählt, und alle Spalten sind aufgelistet.



Zum Schluss werden die Join-Bedingungen in der Registerkarte **Table Output** festgelegt. Mit der Schaltfläche **Erraten** erkennt Analyze die Spalte *Mfg_ID* korrekt als **Join Key**. Die 


**Zielausgabespalten** werden anschließend mit der Schaltfläche **Weitergeben** automatisch festgelegt. Damit sind effektiv alle Spalten aller Tabellen enthalten, wobei alle Join-Spalten nur einmal vorkommen. Beachten Sie, dass die Spalten alphabetisch sortiert sind, zuerst nach *Manufacturer* und dann nach *ModelName*.



Wie erwartet enthält die endgültige Ausgabe nur Werte, die in beiden Tabellen eine Übereinstimmung hatten. *Porsche* erscheint deshalb nicht, weil es keine Modelle hatte. Ebenso hatte der 


*Batmobile* keinen Hersteller (es war eine Sonderanfertigung) und ist daher nicht enthalten.
