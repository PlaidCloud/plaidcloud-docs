## Beschreibung


Dient dazu, Daten aus einer vorhandenen Analyze-Datentabelle in eine andere Datentabelle zu extrahieren. Beispiele sind unter anderem:


* Sortieren
* Gruppieren
* Zusammenfassen
* Zeilen filtern bzw. eine Teilmenge bilden
* Überzählige Spalten entfernen
* Mathematische Operationen
* Zeichenfolgenoperationen

<Aside>Dieser Transformationsschritt bietet keine exklusiven Funktionen. Sortieren, Gruppieren, Filtern usw. lassen sich in jedem anderen Transformationsschritt über die Registerkarten **Tabellendatenauswahl** und **Datenfilter** ausführen.</Aside>

## Zur Laufzeit benannte Spalten

Wählen Sie **Auch zur Laufzeit benannte Spalten übernehmen**, um jede Quellspalte, die der Schritt nicht aufführt, unverändert so durchzureichen, wie die Tabelle sie bei der Ausführung des Schritts enthält. Verwenden Sie diese Option, wenn ein vorheriger Schritt Spalten erzeugt, deren Namen von den Daten abhängen, etwa ein Pivot, sodass Sie sie beim Erstellen des Schritts nicht aufführen können. Lassen Sie sie ausgeschaltet, um nur die Spalten zu schreiben, die Sie aufführen.

Wenn die Option eingeschaltet ist, erscheint der Abschnitt **Mitgeführte Spalten**; der Abschnitt **Durch die Daten benannte Spalten** ist immer verfügbar. Sie enthalten diese Felder:

* **Mitführen als** (`carry_expression`) – schreibt jede mitgeführte Spalte als diesen Ausdruck statt unverändert, wobei `__column__` für die mitgeführte Spalte steht. So fasst ein gruppierender Schritt Spalten ein, die nur die Ausführung kennt; ein aggregierender Schritt führt ohne diese Angabe nichts mit. **Typ der mitgeführten Spalten** (`carry_dtype`) legt den Datentyp jeder mitgeführten Spalte fest (Standard: ihr eigener), und **Aggregation der mitgeführten Spalten** (`carry_agg`) legt fest, wie ein aggregierender Schritt sie behandelt (`dont_group`, wenn der Ausdruck aggregiert).
* **Übernommene Spalten umbenennen** (`carry_rename`) – benennt jede mitgeführte Spalte um, deren Name vom regulären Ausdruck `pattern` getroffen und von `keep` nicht getroffen wird, indem `replacement` an die Stelle jedes Treffers gesetzt wird (`\1` für eine Gruppe; die ersten `max` Treffer, sofern angegeben). `__index__` in `replacement` ist die Position der Spalte unter den umbenannten Spalten, gezählt ab `start`. Wird ein Name bereits verwendet, wird ` (#n)` angehängt.
* **Dynamische Spalten** (`dynamic_columns`) – durch die Daten benannte Zielspalten, jeweils ein Satz für jeden eindeutigen Wert, den der Schritt aus seiner Quelle liest, geschrieben bei der Ausführung des Schritts. Jeder Eintrag enthält `rows` (die Ausdrücke `key`, `label`, `where` und `order` über die Quelle), eine Zielspalte oder eine Liste von Zielspalten (`target`), die `__key__`, `__label__` und `__index__` verwendet, sowie `after`, die Zielspalte, auf die die neuen Spalten folgen (Standard: das Ende). Die Werte müssen Text, Ganzzahl, Boolean oder NULL sein, der Schritt schreibt höchstens 1.000 Spalten, und die Ausgabe muss eine Tabelle sein.
