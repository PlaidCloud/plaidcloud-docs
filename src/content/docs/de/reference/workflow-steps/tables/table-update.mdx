## Beschreibung

Aktualisiert die Zeilen, die Ihrem Filter entsprechen, und schreibt das Ergebnis in eine Zieltabelle. Jede
Quellzeile erreicht das Ziel — die dem Filter entsprechenden Zeilen mit Ihren neuen Werten und
jede andere Zeile genau so, wie sie war. Die Zeilenanzahl des Ziels entspricht immer der
Zeilenanzahl der Quelle.

Der Filter bestimmt, welche Zeilen *geändert* werden, nicht welche Zeilen zurückkommen. Das unterscheidet
diesen Schritt vom [Table-Extract-Schritt](/de/reference/workflow-steps/tables/table-extract/),
bei dem der Filter die nicht passenden Zeilen entfernt.

<Aside type="note" title="Dieser Schritt ändert die Quelltabelle nicht mehr">
Früher aktualisierte er die Quelltabelle an Ort und Stelle. Jetzt lässt er die Quelle unangetastet und
schreibt in ein separates Ziel, sodass die Originaldaten für Vergleiche verfügbar bleiben und
der Schritt auf jedem Warehouse läuft — auch auf solchen, die keine Änderung einer Tabelle an Ort und Stelle zulassen.
Vor dieser Änderung gespeicherte Schritte benötigen eine ausgewählte Zieltabelle, bevor sie
laufen, und jeder Schritt, der die Quelle in der Erwartung las, die aktualisierten Zeilen zu sehen,
muss stattdessen auf das neue Ziel zeigen.
</Aside>

## Aktualisierungsparameter

<SnippetCommonTableSourceAndTarget />

Das Ziel muss eine andere Tabelle als die Quelle sein — dieser Schritt liest jede Quellzeile
und schreibt sie aus, sodass ein Zeigen zurück auf die eigene Quelle das Ergebnis an die
gerade gelesenen Daten anhängen würde.

<Aside type="note" title="Die Quelle muss eine Tabelle sein, keine Ansicht">
Ansichten können als **Ziel** gewählt werden (und sind hier eine gute Wahl — eine Ansicht speichert keine
Daten und wertet bei jedem Lesen erneut gegen die Quelle aus), aber nicht als
**Quelle**: Dieser Schritt übernimmt die Spaltenliste des Ziels aus dem eigenen Schema der Quelltabelle,
das eine Ansicht nicht mitbringt.
</Aside>

Die Spalten des Ziels spiegeln immer die der Quelle, daher wählen Sie sie nie aus. Spalten, die Sie
nicht aktualisieren, werden unverändert übernommen, auch jede Spalte, die der Quelle hinzugefügt wurde,
nachdem dieser Schritt zuletzt geöffnet wurde.

## Zu aktualisierende Spalten

Fügen Sie auf der Registerkarte **Spalten** für jede Spalte, die Sie ändern möchten, eine Zeile hinzu und
legen Sie genau eines fest von:

- **Konstante** — ein fester Wert.
- **Ausdruck** — eine Berechnung, die auf andere Spalten derselben Zeile verweisen kann.
- **Auf Null setzen** — leert die Spalte.

Spalten, die Sie nicht auflisten, bleiben unberührt.

Eine **Zu aktualisierende Spalte**, die in den Quellspalten links nicht aufgeführt ist, wird rot hinter einem ⚠-Warnzeichen angezeigt, auch in einer Zeile mit einer **Konstante**, einem **Ausdruck** oder **Auf Null setzen**, weil der Schritt diese Spalte anhand ihres genauen Namens aktualisiert. Das Speichern mit einer solchen Zeile öffnet einen Dialog **Veraltete Spalten gefunden**, der **Alle entfernen und speichern**, **Trotzdem speichern** oder **Abbrechen** anbietet.

Beim Speichern wird außerdem jede **Zu aktualisierende Spalte** anhand ihres genauen Namens gegen die Quelltabelle in ihrem aktuellen Zustand geprüft, unabhängig davon, was die Quellspalten auflisten. Eine Spalte, die die Tabelle nicht hat, wird im Dialog **Fehlende Quellspalten** benannt, weil der Schritt bei der Ausführung daran scheitern würde. Die Liste der Quellspalten selbst wird nicht gegen die Tabelle geprüft: Dieser Schritt liest die Tabelle, wie sie ist, nicht die Liste.

<Aside type="caution" title="Ausdrücke lesen die ursprünglichen Werte der Zeile">
Ein Ausdruck sieht die Zeile so, wie sie *vor* der Aktualisierung war, sodass zwei Spalten
in einem einzigen Schritt gefahrlos ihre Werte tauschen können.
</Aside>

## Datenfilter für die Aktualisierung

Geben Sie auf der Registerkarte **Filter** die Bedingung ein, die die zu
ändernden Zeilen identifiziert. Lassen Sie sie leer, um jede Zeile zu aktualisieren.

Eine Zeile, deren Bedingung nicht ausgewertet werden kann — meist, weil eine darin getestete Spalte
null ist —, gilt als nicht übereinstimmend und wird unverändert durchgereicht. Das entspricht der Art, wie eine
Datenbank dieselbe Bedingung auswertet.
