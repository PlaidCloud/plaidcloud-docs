## Beschreibung

Aktualisiert die Zeilen, die Ihrem Filter entsprechen, und schreibt das Ergebnis in eine Zieltabelle. Jede
Quellzeile gelangt in das Ziel — die dem Filter entsprechenden Zeilen mit Ihren neuen Werten und
alle anderen Zeilen genau so, wie sie waren. Die Zeilenanzahl des Ziels entspricht immer der
Zeilenanzahl der Quelle.

Der Filter legt fest, welche Zeilen *geändert* werden, nicht, welche Zeilen zurückkommen. Darin
unterscheidet sich dieser Schritt vom [Table Extract-Schritt](/de/reference/workflow-steps/tables/table-extract/),
bei dem der Filter die nicht passenden Zeilen entfernt.

<Aside type="note" title="Dieser Schritt ändert die Quelltabelle nicht mehr">
Früher wurde die Quelltabelle direkt aktualisiert. Jetzt bleibt die Quelle unverändert, und
das Ergebnis wird in ein separates Ziel geschrieben. So bleiben die Originaldaten zum Vergleich
verfügbar, und der Schritt läuft auf jedem Warehouse — auch auf solchen, die keine direkte
Änderung einer Tabelle zulassen. Vor dieser Änderung gespeicherte Schritte benötigen eine
ausgewählte Zieltabelle, bevor sie ausgeführt werden können, und jeder Schritt, der die Quelle
in der Erwartung gelesen hat, die aktualisierten Zeilen zu sehen, muss auf das neue Ziel
verweisen.
</Aside>

## Aktualisierungsparameter

<SnippetCommonTableSourceAndTarget />

Das Ziel muss eine andere Tabelle als die Quelle sein — dieser Schritt liest jede Quellzeile
und schreibt sie aus. Würde er auf die eigene Quelle zurückzeigen, würde das Ergebnis an die
gerade gelesenen Daten angehängt.

<Aside type="note" title="Die Quelle muss eine Tabelle sein, keine Ansicht">
Ansichten können als **Ziel** gewählt werden (und sind hier eine gute Wahl — eine Ansicht
speichert keine Daten und wertet sich bei jedem Lesen erneut gegen die Quelle aus), nicht aber
als **Quelle**: Dieser Schritt übernimmt die Spaltenliste des Ziels aus dem eigenen Schema der
Quelltabelle, das eine Ansicht nicht enthält.
</Aside>

Die Spalten des Ziels spiegeln immer die der Quelle, daher wählen Sie sie nie aus. Spalten, die
Sie nicht aktualisieren, werden unverändert übernommen, auch jede Spalte, die der Quelle
hinzugefügt wurde, nachdem dieser Schritt zuletzt geöffnet wurde.

## Zu aktualisierende Spalten

Fügen Sie auf der Registerkarte **Tabellendatenauswahl** für jede Spalte, die Sie ändern möchten, eine Zeile hinzu und
legen Sie genau eine der folgenden Optionen fest:

- **Konstante** — ein fester Wert.
- **Ausdruck** — eine Berechnung, die auf andere Spalten derselben Zeile verweisen kann.
- **Auf Null setzen** — leert die Spalte.

Spalten, die Sie nicht aufführen, bleiben unberührt.

Eine **Zu aktualisierende Spalte**, die in den Quellspalten links nicht aufgeführt ist, wird rot hinter einem ⚠-Warnzeichen angezeigt, auch in einer Zeile mit einer **Konstante**, einem **Ausdruck** oder **Auf Null setzen**, weil der Schritt diese Spalte anhand ihres genauen Namens aktualisiert. Beim Speichern mit einer solchen Zeile öffnet sich ein Dialog **Veraltete Spalten gefunden**, der **Alle entfernen und speichern**, **Trotzdem speichern** oder **Abbrechen** anbietet.

Beim Speichern wird außerdem jede **Zu aktualisierende Spalte** anhand ihres genauen Namens gegen die Quelltabelle in ihrem aktuellen Zustand geprüft, unabhängig davon, was die Quellspalten auflisten. Eine Zu aktualisierende Spalte, die die Tabelle nicht hat, wird im Dialog **Fehlende Quellspalten** benannt, weil der Schritt bei der Ausführung daran scheitern würde. Die Liste der Quellspalten selbst wird nicht gegen die Tabelle geprüft: Dieser Schritt liest die Tabelle so, wie sie ist, nicht die Liste.

<Aside type="caution" title="Ausdrücke lesen die ursprünglichen Werte der Zeile">
Ein Ausdruck sieht die Zeile so, wie sie *vor* der Aktualisierung war, sodass zwei Spalten
in einem einzigen Schritt gefahrlos ihre Werte tauschen können.
</Aside>

## Datenfilter für die Aktualisierung

Geben Sie auf der Registerkarte **Datenfilter für die Aktualisierung** die Bedingung ein, die die zu
ändernden Zeilen bestimmt. Lassen Sie sie leer, um jede Zeile zu aktualisieren.

Eine Zeile, deren Bedingung nicht ausgewertet werden kann — meist weil eine darin geprüfte Spalte
null ist —, gilt als nicht zutreffend und wird unverändert übernommen. Das entspricht der Art, wie eine
Datenbank dieselbe Bedingung auswertet.
