Workflow-Schritte, die über Ihre [Anaplan-Verbindung](/de/guides/connections/anaplan/) aus **Anaplan** lesen: eine gespeicherte Ansicht über den Leseanforderungspfad für große Datenmengen, eine bereits vorhandene Exportaktion über die Bulk API oder eine bzw. mehrere in eine PlaidCloud-Dimension geladene Listen. Anaplan wird **Cloud-direkt** über die Integration API angesprochen – für diese Schritte gibt es keinen Pfad über einen lokalen Agent, und keiner von ihnen schreibt je nach Anaplan zurück.

## Schritte

- [Anaplan: Ansicht lesen](/de/reference/workflow-steps/anaplan/anaplan-read-view/) – eine gespeicherte Ansicht genau so lesen, wie sie gespeichert wurde. Cloud-direkt.
- [Anaplan: Export lesen](/de/reference/workflow-steps/anaplan/anaplan-read-export/) – eine bereits vorhandene Exportaktion ausführen und ihre Datei ablegen. Cloud-direkt.
- [Anaplan: Liste lesen](/de/reference/workflow-steps/anaplan/anaplan-read-list/) – eine oder mehrere Listen in eine PlaidCloud-Dimension lesen. Cloud-direkt.
