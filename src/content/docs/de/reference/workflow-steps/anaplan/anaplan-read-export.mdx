## Beschreibung

Führt über Ihre [Anaplan-Verbindung](/de/guides/connections/anaplan/) eine **bereits vorhandene** Anaplan-Exportaktion aus und legt die erzeugte Datei als Tabelle ab. Die Exportaktion muss im Modell bereits existieren — die API kann keine erstellen —, und dieser Schritt kann nicht einschränken, was sie ausgibt: Was auch immer die Aktion in Anaplan zum Export konfiguriert ist, landet genau so.

Dieser Schritt erscheint im Schrittmenü unter **Anaplan**.

Der Schritt erreicht Anaplan **Cloud-direkt** über dessen Bulk-API — es gibt keinen Pfad über einen lokalen Agent.

<Aside type="tip">
Dieser Konnektor ist schreibgeschützt und authentifiziert sich mit Basic-Anmeldeinformationen (Benutzername und Kennwort) oder mit einem CA-Zertifikat — siehe [Authentifizierung](/de/guides/connections/anaplan/#authentifizierung). Das Anfragebudget von Anaplan wird mandantenweit geteilt; staffeln Sie daher den Zeitplan dieses Schritts gegenüber Ihren anderen Anaplan-Workflows — siehe [Hinweise zum Zeitplan](/de/guides/connections/anaplan/#überlegungen-zum-zeitplan).
</Aside>

## Konfiguration

### Quelle und Ziel

| Feld | Erforderlich | Hinweise |
|---|---|---|
| Anaplan-Verbindung | Ja | Die [Anaplan-Verbindung](/de/guides/connections/anaplan/), über die gelesen wird. |
| Umgebung | Ja | Die Umgebung der Verbindung. |
| Workspace | Nein | Überschreibt die in der Verbindung gespeicherte Workspace-ID. Wird live aus der Verbindung ermittelt oder von Hand eingegeben. |
| Modell | Nein | Überschreibt die in der Verbindung gespeicherte Modell-ID. Wird live ermittelt, sobald ein Workspace gewählt ist, oder von Hand eingegeben. |
| Export | Ja | Die Anaplan-Exportaktion, die ausgeführt wird. Wird live ermittelt, sobald Workspace und Modell gewählt sind, oder von Hand eingegeben. Ihre Auswahl lässt sich hier nicht überschreiben — sie läuft genau so, wie sie in Anaplan konfiguriert ist. |
| Abfrageversuche | Ja | Standard 120. Wie oft die Export-Task auf Abschluss abgefragt wird, bevor der Schritt ablehnt und die Task-ID nennt. Er sendet nie stillschweigend erneut — Anaplan dokumentiert nicht, wie sich zwei von derselben Exportaktion erzeugte Dateien unterscheiden lassen, sodass ein erneutes Senden Gefahr läuft, die falsche Datei an diese Ausführung zu binden. |
| Abfrageintervall (Sekunden) | Ja | Standard 5. Sekunden Wartezeit zwischen den Abfragen. |
| Zieltabelle | Ja | Die Tabelle, in der der Export landet. Jede Spalte landet als Text. |

## Was dieser Schritt nicht abbilden kann

| Einschränkung | Bedeutung |
|---|---|
| Erfordert eine bereits vorhandene Exportaktion | Die API kann keine Exportaktion erstellen, und die Anfrage, die dieser Schritt sendet, enthält keinerlei Point-of-View-, Elementauswahl- oder Slice-Parameter — was die Aktion in Anaplan ausgeben soll, landet genau so. Erstellen oder bearbeiten Sie die Exportaktion in Anaplan, um zu ändern, was sie erzeugt. |
| Jede Spalte landet als Text | Das Feld, das Anaplan zur Deklaration der Spaltentypen eines Exports veröffentlicht, ist in der von Anaplan selbst veröffentlichten Dokumentation in sich widersprüchlich und kann daher nicht zuverlässig verwendet werden, um eine Spalte richtig zu typisieren — keine Spalte wird daraus typisiert, bewusst und dauerhaft. Wandeln Sie die benötigten Spalten in einem nachgelagerten Schritt um. |
| Zahlen werden im US-Format angefordert; eine weiterhin gruppierte Spalte wird markiert, nicht korrigiert | Die Export-Task wird mit der Anforderung der US-Zahlenformatierung übermittelt. Eine Spalte, die dennoch mit Tausendertrennzeichen zurückkommt, bedeutet, dass der Export nicht in diesem Format ausgegeben wird — der Schritt legt den Wert unverändert als Text ab und warnt unter Nennung der Spalte und eines Beispielwerts, statt zu raten, welches Zeichen das Dezimaltrennzeichen ist. Prüfen Sie eine solche Spalte, bevor Sie sie nachgelagert umwandeln: Ein als `1.234` gelesenes `1.234.567` im europäischen Stil ist tausendmal zu klein. |
| Lehnt ab, statt einen unzuverlässigen Extrakt abzulegen | Der Schritt legt nichts ab, statt eine Tabelle, die vollständig aussieht, es aber nicht ist, wenn: die Export-Task fehlschlägt oder in Anaplan keinen Erfolg meldet; die Task abgebrochen wird; die Task noch läuft, nachdem das Abfragebudget des Schritts aufgebraucht ist; die erzeugte Datei überhaupt keine Daten enthält; die erzeugte Datei sich nicht auf den Export zurückführen lässt, der sie erzeugt hat; oder die Anzahl der gelesenen Zeilen von der Zeilenanzahl abweicht, die Anaplan selbst für den Export meldet. |
| Schreibgeschützt | Es wird nie etwas zurück nach Anaplan geschrieben. |
