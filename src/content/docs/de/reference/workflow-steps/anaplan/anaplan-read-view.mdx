## Beschreibung

Liest Daten aus einer gespeicherten **Anaplan**-Ansicht über Ihre [Anaplan-Verbindung](/de/guides/connections/anaplan/) und verwendet dazu den Leseanforderungspfad von Anaplan für große Datenmengen. Die Ansicht wird **genau so gelesen, wie sie gespeichert wurde** — dieser Schritt bietet keine Ad-hoc-Auswahl von Zeilen, Spalten oder Seiten. Um einen anderen Ausschnitt zu lesen, speichern Sie in Anaplan eine andere Ansicht.

Dieser Schritt erscheint im Schrittmenü unter **Anaplan**.

Der Schritt erreicht Anaplan **direkt über die Cloud** mit seiner Integration API — es gibt keinen Pfad über einen lokalen Agent.

<Aside type="tip">
Dieser Konnektor ist schreibgeschützt und authentifiziert sich mit Basic-Anmeldedaten (Benutzername und Passwort) oder CA-Zertifikat — siehe [Authentifizierung](/de/guides/connections/anaplan/#authentifizierung). Das Anfragebudget von Anaplan wird mandantenweit geteilt, daher sollten Sie den Zeitplan dieses Schritts gegenüber Ihren anderen Anaplan-Workflows zeitlich versetzen — siehe [Überlegungen zum Zeitplan](/de/guides/connections/anaplan/#hinweise-zur-zeitplanung).
</Aside>

## Konfiguration

### Quelle und Ziel

| Feld | Erforderlich | Hinweise |
|---|---|---|
| Anaplan-Verbindung | Ja | Die [Anaplan-Verbindung](/de/guides/connections/anaplan/), über die gelesen wird. |
| Umgebung | Nein | **Projektumgebung** (der Standard) verwendet die Verbindungsumgebung des Projekts. **Feste Umgebung** verwendet immer die Umgebung, die Sie auswählen. Siehe [Einen Schritt auf eine Umgebung festlegen](/de/guides/projects/managing-projects/#einen-schritt-an-eine-umgebung-binden). |
| Workspace | Nein | Überschreibt die in der Verbindung gespeicherte Workspace-ID. Wird live aus der Verbindung ermittelt oder von Hand eingegeben. |
| Modell | Nein | Überschreibt die in der Verbindung gespeicherte Modell-ID. Wird live ermittelt, sobald ein Workspace gewählt ist, oder von Hand eingegeben. |
| Ansicht | Ja | Die zu lesende gespeicherte Anaplan-Ansicht. Wird live ermittelt, sobald ein Modell gewählt ist, oder von Hand eingegeben. |
| Abfrageversuche | Ja | Standard 120. Wie oft die Leseanforderung auf Abschluss abgefragt wird, bevor der Schritt ablehnt und die Anforderungs-ID nennt. Es wird nie stillschweigend eine zweite Anforderung abgesendet. |
| Abfrageintervall (Sekunden) | Ja | Standard 5. Sekunden Wartezeit zwischen den Abfragen. |
| Zieltabelle | Ja | Die Tabelle, in die die zurückgegebene Ansicht geladen wird. |

## Vorschau

**Vorschau** auf der Registerkarte **Quelle** zeigt die Spalten und Datentypen an, die dieser Ansichtslesevorgang erzeugen würde, ohne den Schritt auszuführen. Sie ist in einem gesperrten Projekt nicht verfügbar.

## Was dieser Schritt nicht abbilden kann

| Einschränkung | Bedeutung |
|---|---|
| Keine Ausschnittssteuerung | Die Ansicht wird genau so gelesen, wie sie gespeichert ist — ohne Auswahl von Zeilen, Spalten oder Seiten. Der Seitenselektor von Anaplan ist nur für den synchronen Vorschau-Endpunkt dokumentiert; der Body der Leseanforderung für große Datenmengen, den dieser Schritt sendet, enthält einen Exporttyp und sonst nichts. Erstellen Sie eine andere gespeicherte Ansicht — häufig eine boolesche Zeilenposition plus einen Filter —, um einen anderen Ausschnitt zu lesen. |
| Deklarierte Typen werden nur übernommen, wenn sich Zeilenpositionen auf den Spalten befinden | Befinden sich Zeilenpositionen auf der Spaltenachse der Ansicht, wird jede Datenspalte mit dem deklarierten Anaplan-Format ihrer Zeilenposition typisiert geladen (Zahl, Text, Boolesch, Datum, Zeitraum oder Liste). Befinden sich die Zeilenpositionen auf den Zeilen (ein gewöhnliches GuV-Layout) oder fehlen sie in der Ansicht ganz, wird stattdessen jede Datenspalte mit einer benannten Warnung als Text geladen — eine Datenspalte würde sonst viele Zeilenpositionen und damit viele Formate umfassen, während eine Tabellenspalte genau einen Typ enthält. |
| Werte des Seitenselektors werden nicht als Spalten geladen | Die gespeicherten Seitenselektor-Elemente einer Ansicht stehen im CSV-Header und werden dort verarbeitet — sie erscheinen nicht als Spalten in der Zieltabelle. |
| Mehrdeutige Zahlen werden abgelehnt, statt zu raten | Ein als Zahl deklarierter Wert mit Tausendertrennzeichen oder einer, der sich gleichermaßen als einfache Dezimalzahl oder als europäische Schreibweise lesen lässt (zum Beispiel `1.234`), wird unter Nennung des Namens abgelehnt, statt geparst zu werden — es sei denn, ein anderer Wert in derselben Spalte klärt, welche Lesart richtig ist. Dieser Lesepfad hat kein Feld für das Gebietsschema, anhand dessen sich die Mehrdeutigkeit auflösen ließe. Ein Wert, der sich parsen lässt, wird mit voller Genauigkeit und ohne Rundungsfehler geladen, und eine leere Zelle wird immer als leerer Wert geladen. |
| Eine leere Ansicht wird leer geladen, mit einer Warnung | Eine gespeicherte Ansicht, deren Filter nichts trifft, ersetzt die Zieltabelle durch eine leere und warnt — das ist ein gewöhnliches Ergebnis, kein Fehler. Die Ausnahme ist eine Ansicht ohne Dimension auf ihrer Zeilenachse: Es gibt keine Zeilenbezeichnungs-Ecke, anhand derer sich ein leeres Ergebnis überprüfen ließe, daher lehnt der Schritt ab, statt zu riskieren, die Tabelle wegen einer falsch gelesenen Kopfzeile zu leeren. |
| Schreibgeschützt | Es wird nie etwas zurück nach Anaplan geschrieben. |
