## Beschreibung

Liest Daten aus einer gespeicherten **Anaplan**-Ansicht über Ihre [Anaplan-Verbindung](/de/guides/connections/anaplan/), und zwar über den Leseanforderungspfad von Anaplan für große Datenmengen. Die Ansicht wird **genau so gelesen, wie sie gespeichert wurde** – dieser Schritt bietet keine ad-hoc-Auswahl von Zeilen, Spalten oder Seiten. Um einen anderen Ausschnitt zu lesen, speichern Sie in Anaplan eine andere Ansicht.

Dieser Schritt erscheint im Schrittmenü unter **Anaplan**.

Der Schritt greift **Cloud-direkt** über die Integration API auf Anaplan zu – einen Pfad über einen lokalen Agent gibt es nicht.

<Aside type="tip">
Dieser Konnektor ist schreibgeschützt und authentifiziert sich mit Basic-Anmeldedaten (Benutzername und Passwort) oder mit einem CA-Zertifikat – siehe [Authentifizierung](/de/guides/connections/anaplan/#authentifizierung). Das Anfragebudget von Anaplan wird mandantenweit geteilt. Staffeln Sie daher den Zeitplan dieses Schritts gegenüber Ihren anderen Anaplan-Workflows – siehe [Überlegungen zum Zeitplan](/de/guides/connections/anaplan/#überlegungen-zum-zeitplan).
</Aside>

## Konfiguration

### Quelle und Ziel

| Feld | Erforderlich | Hinweise |
|---|---|---|
| Anaplan-Verbindung | Ja | Die [Anaplan-Verbindung](/de/guides/connections/anaplan/), über die gelesen wird. |
| Umgebung | Ja | Die Umgebung der Verbindung. |
| Workspace | Nein | Überschreibt die in der Verbindung gespeicherte Workspace-ID. Wird live über die Verbindung ermittelt oder von Hand eingegeben. |
| Modell | Nein | Überschreibt die in der Verbindung gespeicherte Modell-ID. Wird live ermittelt, sobald ein Workspace gewählt ist, oder von Hand eingegeben. |
| Ansicht | Ja | Die gespeicherte Anaplan-Ansicht, die gelesen wird. Wird live ermittelt, sobald ein Modell gewählt ist, oder von Hand eingegeben. |
| Abfrageversuche | Ja | Standard 120. Gibt an, wie oft die Leseanforderung auf Abschluss abgefragt wird, bevor der Schritt abbricht und die Anforderungs-ID nennt. Es wird nie stillschweigend eine zweite Anforderung gesendet. |
| Abfrageintervall (Sekunden) | Ja | Standard 5. Wartezeit in Sekunden zwischen den Abfragen. |
| Zieltabelle | Ja | Die Tabelle, in der die gelieferte Ansicht abgelegt wird. |

## Was dieser Schritt nicht abbilden kann

| Einschränkung | Bedeutung |
|---|---|
| Keine Steuerung des Ausschnitts | Die Ansicht wird genau so gelesen, wie sie gespeichert wurde – ohne Auswahl von Zeilen, Spalten oder Seiten. Der Seitenselektor von Anaplan ist nur für den synchronen Vorschau-Endpunkt dokumentiert; der Body der Leseanforderung für große Datenmengen, den dieser Schritt sendet, enthält nur einen Exporttyp und sonst nichts. Erstellen Sie eine andere gespeicherte Ansicht – häufig ein boolesches Line Item plus einen Filter –, um einen anderen Ausschnitt zu lesen. |
| Deklarierte Typen werden nur übernommen, wenn sich Line Items auf den Spalten befinden | Befinden sich Line Items auf der Spaltenachse der Ansicht, wird jede Datenspalte mit dem deklarierten Anaplan-Format ihres Line Items typisiert abgelegt (Number, Text, Boolean, Date, Time Period oder List). Befinden sich Line Items auf den Zeilen (ein gewöhnliches GuV-Layout) oder fehlen sie in der Ansicht ganz, wird jede Datenspalte stattdessen als Text abgelegt, mit einer benannten Warnung – eine Datenspalte würde sonst viele Line Items und damit viele Formate umfassen, während eine Tabellenspalte genau einen Typ hat. |
| Werte des Seitenselektors werden nicht als Spalten abgelegt | Die gespeicherten Seitenselektor-Elemente einer Ansicht stehen im CSV-Header und werden dort ausgewertet – in der Zieltabelle erscheinen sie nicht als Spalten. |
| Mehrdeutige Zahlen werden abgewiesen, statt geraten zu werden | Ein als Number deklarierter Wert mit Tausendertrennzeichen oder ein Wert, der sich gleichermaßen als einfache Dezimalzahl oder in europäischer Schreibweise lesen lässt (zum Beispiel `1.234`), wird unter Namensnennung abgewiesen, statt ausgewertet zu werden – es sei denn, ein anderer Wert in derselben Spalte klärt, welche Lesart richtig ist. Dieser Leseweg hat kein Gebietsschemafeld, anhand dessen sich die Mehrdeutigkeit auflösen ließe. Ein Wert, der sich auswerten lässt, wird in voller Genauigkeit ohne Rundungsfehler abgelegt, und eine leere Zelle wird immer als leerer Wert abgelegt. |
| Eine leere Ansicht wird leer abgelegt, mit einer Warnung | Eine gespeicherte Ansicht, deren Filter nichts findet, ersetzt die Zieltabelle durch eine leere und gibt eine Warnung aus – das ist ein gewöhnliches Ergebnis und kein Fehler. Ausgenommen ist eine Ansicht ohne Dimension auf der Zeilenachse: Dort gibt es keine Zeilenbeschriftungs-Ecke, anhand derer sich ein leeres Ergebnis überprüfen ließe, sodass der Schritt abbricht, statt die Tabelle aufgrund eines falsch gelesenen Headers zu leeren. |
| Schreibgeschützt | Es wird nie etwas nach Anaplan zurückgeschrieben. |
