## Beschreibung

Der Schritt **Export to PDF** schreibt eine Tabelle als PDF-Dokument in ein Dokumentenkonto. Er liest die Zeilen selbst, sodass dazwischen kein Export-Worker läuft.

## Parameter

- **Quelltabelle** — die zu exportierende Tabelle.
- **Ausgabeordner** — das Dokumentenkonto und der Ordner, in die das PDF geschrieben wird.
- **Dateiname** — der Name des PDF. `.pdf` wird angehängt, wenn der Name es nicht enthält.
- **Spaltennamen als Kopfzeile schreiben** — standardmäßig aktiviert. Die Kopfzeile wird auf jeder Seite wiederholt.
- **Tabellendatenauswahl** — wählen Sie die geschriebenen Spalten aus und legen Sie ihre Reihenfolge fest. Der Schritt kann statt einer Liste auch alle Spalten schreiben, die die Quelle bei der Ausführung des Workflows hat.

## Layout

- Die Seite hat das Hochformat im Letter-Format und wechselt ins Querformat, wenn die Tabelle mehr als sechs Spalten hat.
- Zeilen werden in Blöcken zu je 1.000 geschrieben, und jeder Block wiederholt die Kopfzeile.
- Ein Nullwert ist eine leere Zelle.
- Eine Zelle, die für eine Seite zu lang ist, wird mit einer Ellipse gekürzt, und der Schritt warnt unter Nennung der gekürzten Spalten.
- Das PDF verwendet eine Unicode-Schriftart, wenn die Workflow-Engine eine hat. Andernfalls wird das PDF in Helvetica gesetzt, die nur Latin-1-Zeichen darstellt, und der Schritt gibt eine Warnung aus.
