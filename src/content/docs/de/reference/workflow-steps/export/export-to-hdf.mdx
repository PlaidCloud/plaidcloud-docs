## Beschreibung


Exportieren Sie eine Analyze-Datentabelle als HDF5-Datei nach PlaidCloud Document.


Weitere Informationen zu HDF5-Dateien finden Sie auf der offiziellen Website der HDF Group: http://www.hdfgroup.org/HDF5/.

<SnippetCommonExportFileSelection />



### Ausgabedateityp


Alle exportierten Dateien sind unkomprimiert, es stehen jedoch die folgenden Komprimierungsoptionen zur Verfügung:


* Zip
* GZip
* BZip2
