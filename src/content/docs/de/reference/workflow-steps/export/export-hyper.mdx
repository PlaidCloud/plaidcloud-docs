## Beschreibung

Der Schritt **Tableau Hyper Export** exportiert eine Tabelle in eine Tableau-Hyper-Datei. Er läuft in der Workflow-Engine; Ergebnisse gepackter Makros sind eine Annäherung an das Alteryx-Makro.

## Parameter

- **Quelltabelle** und der **Pfad der Ausgabedatei**.

Der Tableau-Hyper-Writer ist in der Workflow-Engine nicht verfügbar, daher wird stattdessen eine CSV-Datei geschrieben (eine funktionale Herabstufung).
