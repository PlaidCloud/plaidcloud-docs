## Beschreibung

Der Schritt **Tableau Hyper Export** exportiert eine Tabelle in eine Tableau-Hyper-Datei. Er läuft in der Workflow-Engine; Ergebnisse gepackter Makros sind eine Annäherung an das Alteryx-Makro.

## Parameter

- **Quelltabelle** und der **Pfad der Ausgabedatei**.

Wenn die Quelltabelle nicht existiert oder keine Spalten hat, während keine zugeordnet sind, ist der Schritt erfolgreich, schreibt nichts und protokolliert eine Warnung, die die Quelle und die Ausgabedatei nennt. Eine Quelle ohne Zeilen schreibt einen leeren Extrakt und protokolliert eine entsprechende Warnung.
