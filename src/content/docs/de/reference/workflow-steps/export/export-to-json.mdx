## Beschreibung


Exportieren Sie eine Analyze-Datentabelle als JSON-Datei nach PlaidCloud Document. Für die Datenausrichtung stehen mehrere Optionen zur Verfügung (siehe unten).



Weitere Informationen zu JSON-Dateien finden Sie auf der offiziellen JSON-Website: http://json.org/.


<Aside>JSON-Dateien behalten die Spaltenreihenfolge *nicht* bei. Die Spaltenreihenfolge in der Quelldatentabelle entspricht nicht unbedingt der Spaltenreihenfolge in der exportierten Datei.</Aside>

### JSON-Ausrichtung


Betrachten Sie den folgenden Datensatz:




| ID |  Name  | Geschlecht | Bundesstaat |
|----|--------|--------|-------|
| 1  | Jack   |   M    |   MO  |
| 2  | Jill   |   F    |   MO  |
| 3  | George |   M    |   VA  |
| 4  | Abe    |   M    |   KY  |

JSON-Dateien können in eines von vier Datenformaten exportiert werden:


* Records: Die Daten werden in Python-Dictionary-Mengen gespeichert, wobei jede Zeile im Format \{Spalte -> Wert, …} abgelegt wird. Beispiel: **[\{“ID”:1,”Name”:”Jack”,”Gender”:”M”,”State”:”MO”},\{“ID”:2,”Name”:”Jill”,”Gender”:”F”,”State”:”MO”},\{“ID”:3,”Name”:”George”,”Gender”:”M”,”State”:”VA”},\{“ID”:4,”Name”:”Abe”,”Gender”:”M”,”State”:”KY”}]**
* Index: Die Daten werden in verschachtelten Python-Dictionary-Mengen gespeichert, wobei jede Zeile im Format \{Index -> \{Spalte -> Wert, …},…} abgelegt wird. Beispiel: **\{“0”:\{“ID”:1,”Name”:”Jack”,”Gender”:”M”,”State”:”MO”},”1”:\{“ID”:2,”Name”:”Jill”,”Gender”:”F”,”State”:”MO”},”2”:\{“ID”:3,”Name”:”George”,”Gender”:”M”,”State”:”VA”},”3”:\{“ID”:4,”Name”:”Abe”,”Gender”:”M”,”State”:”KY”}}**
* Split: Die Daten werden in einer einzelnen Python-Dictionary-Menge gespeichert, die Werte liegen in Listen. Beispiel: **\{“columns”:[“ID”,”Name”,”Gender”,”State”],”index”:[0,1,2,3],”data”:[[1,”Jack”,”M”,”MO”],[2,”Jill”,”F”,”MO”],[3,”George”,”M”,”VA”],[4,”Abe”,”M”,”KY”]]}**
* Values: Die Daten werden in mehreren Python-Listen gespeichert. Beispiel: **[[1,”Jack”,”M”,”MO”],[2,”Jill”,”F”,”MO”],[3,”George”,”M”,”VA”],[4,”Abe”,”M”,”KY”]]**


### Datumsbehandlung


Legen Sie das **Datumsformat** im Dropdown-Menü fest. Sie können aus den folgenden Formaten wählen:


* **Epoch (Unix Timestamp – Seconds since 1/1/1970)**
* **ISO 8601 Format (YYYY-MM-DD HH:MM:SS with timeproject offset)**

Legen Sie die **Datumseinheit** im Dropdown-Menü fest. Sie können aus den folgenden Einheiten wählen, aufgeführt in aufsteigender Genauigkeit:


* **Sekunden (s)**
* **Millisekunden (ms)**
* **Mikrosekunden (us)**
* **Nanosekunden (ns)**

### ASCII erzwingen


Aktivieren Sie dieses Kontrollkästchen, damit alle Zeichenfolgen im korrekten ASCII-Format codiert werden. Diese Option ist standardmäßig aktiviert.



### Ausgabedateityp


Alle exportierten Dateien sind unkomprimiert, es stehen jedoch die folgenden Komprimierungsoptionen zur Verfügung:


* Zip
* GZip
* BZip2


### Zusätzliche Einstellungen

* **Eine bereits vorhandene Datei** (`if_exists`), unter **Wenn die Datei existiert** — **Überschreiben** (`overwrite`, Standard) ersetzt eine bereits vorhandene Datei. **Den Schritt fehlschlagen lassen, ohne etwas zu schreiben** (`fail`) beendet den Schritt, ohne etwas zu schreiben, wenn eine Datei, die er schreiben würde, bereits existiert.
* **Zeilen sortieren nach** (`sort_columns`), unter **Zeilenreihenfolge** — sortiert die geschriebenen Zeilen nach diesen Quellspalten, beginnend mit dem ersten Schlüssel, jeweils mit den Einstellungen **Spalte**, **Aufsteigend** und **Nullwerte**. Eine Schlüsselspalte muss nicht geschrieben werden. **Nullwerte** steht bei aufsteigender Sortierung standardmäßig auf „zuerst" und bei absteigender auf „zuletzt". Wird nicht zusammen mit **Zusammenfassen** oder **Eindeutig** verwendet.
