## Beschreibung



Überträgt eine PlaidCloud-Tabelle in eine Quandl-Datenbank (NASDAQ Data Link). Vor allem für Organisationen, die veröffentlichte Datensätze auf Quandl pflegen und diese aus einem PlaidCloud-Workflow aktualisieren möchten.

Erfordert Quandl-API-Zugangsdaten und eine Zieldatenbank, die auf der Quandl-Seite für Schreibzugriff konfiguriert ist.


## Quelle und Ziel


Geben Sie die folgenden Parameter an:


* **Quelltabelle**: Die zu exportierende Analyze-Datentabelle
* **Quandl Connection**: Für den Zugriff auf Quandl-Datensätze ist ein Benutzerkonto oder ein Gastkonto mit eingeschränktem Zugriff erforderlich. Dies muss in den Tools eingerichtet werden. Details zum Einrichten einer Quandl-Kontoverbindung finden Sie hier: [PlaidCloud Tools – Verbindung](/de/reference/connectors/)
* **Quandl Code**: Verwenden Sie die Schaltfläche **Suchen**, um nach Datensätzen zu suchen. Alternativ können Datensätze manuell eingegeben werden. Dazu muss der Benutzer den Teil der URL nach „[http://www.quandl.com](http://www.quandl.com/)“ eingeben. Um beispielsweise den Datensatz für die Microsoft-Aktie zu importieren, der hier zu finden ist (http://www.quandl.com/GOOG/NASDAQ_MSFT), geben Sie *GOOG/NASDAQ_MSFT* in das Feld „Quandl Code“ ein
* **Dataset Name**: Name des Datensatzes, der nach Quandl exportiert wird
* **Dataset Description**: Beschreibung des Datensatzes, der nach Quandl exportiert wird
