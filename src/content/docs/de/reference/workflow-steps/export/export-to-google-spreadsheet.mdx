## Beschreibung


Exportieren Sie eine Analyze-Datentabelle als Google Spreadsheet nach Google Drive. Für diese Transformation ist ein gültiges Google-Konto erforderlich. Die Benutzeranmeldedaten müssen vor der Verwendung der Transformation in PlaidCloud Tools eingerichtet werden.



## Exportparameter


### Quelle und Ziel


Wählen Sie die **Quelltabelle** aus PlaidCloud Document im Dropdown-Menü aus.



Geben Sie als Nächstes die Informationen zur **Zielverbindung** an. Details zum Einrichten einer Google-Docs-Kontoverbindung finden Sie hier: [PlaidCloud Tools – Verbindung](/de/reference/connectors/). Wählen Sie nach dem Einrichten aller erforderlichen Konten das passende Konto aus der Dropdown-Liste aus.



Geben Sie abschließend den **Name der Zieltabelle** und den **Name des Zielarbeitsblatts** an. Aktivieren Sie bei Bedarf das Kontrollkästchen **Daten an vorhandene Arbeitsblattdaten anfügen**, um Daten an ein vorhandenes Arbeitsblatt anzufügen. Wenn das Zielarbeitsblatt noch nicht existiert, wird es erstellt.



Eine noch nicht vorhandene Tabelle wird erstellt, ebenso ein fehlendes Arbeitsblatt. Ein **Name der Zieltabelle**, den mehr als eine Tabelle im Konto trägt, wird abgelehnt. Benennen Sie die Duplikate um, damit der Name eindeutig ist. Werte werden so geschrieben, wie sie eingegeben wurden. Eine Textzelle, die mit `=` beginnt, bleibt also Text und wird nicht zu einer Formel. Ist **Daten an vorhandene Arbeitsblattdaten anfügen** deaktiviert, wird das Arbeitsblatt geleert und auf die Größe der Tabelle angepasst, bevor die Zeilen geschrieben werden.
