## Beschreibung

Der **Text**-Block für einen zusammengesetzten Bericht. Er entspricht dem passenden Alteryx-Tool *Reporting* / *Portfolio Composer* und läuft in der Workflow-Engine (reportlab / matplotlib); der Renderer ist eine Annäherung an die Alteryx-Ausgabe.

## Quelle & Optionen

- **Quelltabelle** – die Daten, die diesen Berichtsteil speisen.
- **Ausgabetabelle** – die Tabelle, in die das gerenderte Snippet geschrieben wird.
- **Berichtsreihenfolge** – die Reihenfolge dieses Teils innerhalb eines zusammengesetzten Berichts.
- **Textinhalt** – der Text, der gerendert wird.

## Auf eine Spalte im Text verweisen

Der Textinhalt kann eine Spalte in eckigen Klammern nennen, und an ihrer Stelle wird
der Wert ausgegeben – `[Year] Results` gibt `2026 Results` aus. Ein konvertierter Alteryx-Report
Text übernimmt alle Feldverweise, die sein Text bereits enthielt, einschließlich der
formatierten Form, die Alteryx als `[Year:A]` schreibt.

Für die gesamte Quelltabelle wird ein einziger Text zusammengesetzt, daher muss eine Spalte, die Sie
nennen, in jeder gelesenen Zeile denselben Wert enthalten. Fassen Sie die Spalte vorgelagert zusammen,
wenn sie mehr als einen Wert enthält – ein Textblock kann nicht mehrere Werte gleichzeitig ausgeben.

`[CurrentYear]` gibt das Jahr aus, in dem der Bericht gerendert wird, und braucht keine Spalte.

Einige Regeln sorgen dafür, dass gewöhnlicher Fließtext sicher bleibt:

- Ein Name, der zu einer Spalte passt, wird immer ersetzt.
- Ein Name, der zu keiner Spalte passt, stoppt den Schritt und meldet das, aber nur dort, wo
  er nichts anderes als ein Verweis sein kann – ein Format, das unmittelbar am
  Doppelpunkt steht, wie in `[Quarter:A]`.
- Text in eckigen Klammern wird so ausgegeben, wie Sie ihn geschrieben haben. `[12:30]` bleibt eine Uhrzeit
  und `[Note: continued]` bleibt ein Einschub, weil eine bloße Zahl kein Spaltenname ist
  und Fließtext nach dem Doppelpunkt ein Leerzeichen setzt.

Das Format selbst wird nicht angewendet – der Wert wird so ausgegeben, wie ihn die Spalte enthält. Formatieren
Sie die Spalte daher vorgelagert, wenn sie Tausendertrennzeichen oder ein Datumslayout benötigt.

## Spalten

Die Registerkarte **Spalten** ordnet die Quellspalten zu, die für den Berichtsteil verfügbar sind.
