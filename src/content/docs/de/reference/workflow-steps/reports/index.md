## Bausteine für Berichte

Konvertierte Alteryx-Berichts-Workflows setzen ein Dokument aus diesen Schritten zusammen. Chart,
Image, Map, Table und Text erzeugen jeweils einen Teil; Layout, Visual Layout und
Overlay ordnen die Teile an; Render schreibt das zusammengesetzte Ergebnis in ein PDF.
