Eine Organisation ist die administrative Grenze für zusammengehörige PlaidCloud-Workspaces. Die Organisationseinstellungen steuern den in der Control Plane angezeigten Namen, die Abrechnungsmetadaten, das SSO-Verhalten und wer die Organisation verwalten darf.

## Organisationsliste

Die Seite **Organizations** zeigt die Organisationen, auf die Sie zugreifen können. In der Tabelle können Sie:

1. Organisationen nach sichtbaren Tabellenfeldern durchsuchen.
2. Die Organisationsliste aktualisieren.
3. Organisationsdetails anzeigen.
4. Organisationseinstellungen bearbeiten, wenn Sie Admin-Zugriff haben.
5. Die Verwaltung des Organisationszugriffs öffnen, wenn Sie Sicherheitszugriff haben.
6. Abrechnungsdatensätze öffnen, wenn Sie Abrechnungszugriff haben.

## Organisationseinstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Name | Anzeigename der Organisation. |
| ID | Stabile Organisationskennung. Sie wird beim Erstellen der Organisation festgelegt. |
| Notiz | Interne Notiz oder Beschreibung, die in der Control Plane angezeigt wird. |
| Tarif | Kommerzieller Tarif: Enterprise, Team oder Free. |
| Steuer-ID | Steuerkennung, die für Abrechnungsdatensätze verwendet wird. |
| Aktiv | Gibt an, ob die Organisation aktiv ist. |
| Gesperrt | Verhindert im aktivierten Zustand normale Änderungen an der Organisation. |
| SSO erforderlich | Verlangt, dass sich Mitglieder über die Single-Sign-On-Konfiguration der Organisation anmelden. |

## Abrechnungsmetadaten

Abrechnungsfelder beschreiben, wie die Organisation abgerechnet wird. Sie gewähren für sich genommen keinen Produktzugriff.

| Einstellung | Optionen |
| --- | --- |
| Abrechnungszyklus | Monatlich, vierteljährlich, halbjährlich, jährlich |
| Abrechnungspreis | Numerischer Abrechnungsbetrag für den gewählten Zyklus. |
| Zahlungsart | Per Bestellung in Rechnung gestellt, kostenlose Testversion, kostenlos, geplante Zahlung |

## SSO-Verhalten

| Einstellung | Beschreibung |
| --- | --- |
| Dynamische Gruppenzuweisung | Erlaubt, dass SSO-Gruppeninformationen die Zuweisung von Organisationsrollen steuern. |
| Dynamische Benutzererstellung | Erlaubt, dass die SSO-Anmeldung automatisch Benutzer erstellt, wenn der Identitätsanbieter einen akzeptierten Benutzer sendet. |
| Name der dynamischen SSO-Gruppenzuweisung | Der SSO-Gruppenname, der für die dynamische Zuweisung verwendet wird. |

<Aside type="note">
	Richten Sie einen Identitätsanbieter für einen Workspace in dessen [Dialog „Single sign-on“](/de/administration/control-plane/workspace-configuration/#single-sign-on) ein; die SAML-Einrichtung ist in den Leitfäden zur Zugriffsverwaltung dokumentiert. Diese Einstellungen der Control Plane legen fest, wie die Organisation die SSO-Konfiguration verwendet, nachdem sie existiert.
</Aside>

## Zugriff verwalten

Verwenden Sie **Manage Access**, um Personen in die Organisation einzuladen und Organisationsrollen zuzuweisen.

1. Öffnen Sie **Organizations**.
2. Wählen Sie die Organisation aus.
3. Öffnen Sie **Manage Access**.
4. Klicken Sie auf **Invite User**, um eine oder mehrere E-Mail-Adressen einzuladen.
5. Wählen Sie die Rollen aus, die jede Person erhalten soll.
6. Fügen Sie optional eine eigene Nachricht hinzu.
7. Senden Sie die Einladung.

Sie können die Rollen akzeptierter Benutzer bearbeiten, akzeptierte Benutzer entfernen oder ausstehende Einladungen abbrechen. Ausstehende Benutzer können erst bearbeitet werden, nachdem sie die Einladung angenommen haben.

## Organisationsrollen

| Rolle | Verwendungszweck |
| --- | --- |
| Admin | Organisationseinstellungen und Änderungen auf Administratorebene. |
| Workspace | Erstellung, Konfiguration, Release sowie Anhalten und Fortsetzen von Workspaces. |
| Sicherheit | Einladungen und Verwaltung von Organisationsrollen. |
| Abrechnung | Zugriff auf Abrechnungsdatensätze. |
