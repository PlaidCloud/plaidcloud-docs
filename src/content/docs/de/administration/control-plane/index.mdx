Die PlaidCloud Control Plane richtet sich an Partner-Administratoren und Kunden-Administratoren, die Organisationen und Workspaces verwalten. Verwenden Sie sie, um Workspaces zu erstellen, die Inhaberschaft von Workspaces zuzuweisen, das Release-Verhalten festzulegen, Workspace-Dienste zu aktivieren, Branding zu konfigurieren und den Zugriff auf Organisationsebene zu verwalten.

<Aside type="note">
	Der Bereich PlaidAdmin ist für die Betriebsmitarbeiter von PlaidCloud vorgesehen. Dieser Leitfaden behandelt nur die Administrationsbereiche für Partner und Kunden.
</Aside>

## Navigation

Verwenden Sie nach der Anmeldung die linke Navigation:

1. Öffnen Sie **Organizations**, um von Ihnen verwaltete Organisationen anzuzeigen oder zu bearbeiten.
2. Öffnen Sie **Workspaces**, um von Ihnen verwaltbare Workspaces anzuzeigen, zu erstellen, zu bearbeiten, anzuhalten, fortzusetzen oder gesammelt zu aktualisieren.
3. Verwenden Sie Ihr Profilmenü, um Ihr Kontoprofil zu aktualisieren oder sich abzumelden.

Die angezeigten Aktionen hängen von Ihren Organisationsrollen ab. So kann beispielsweise ein Benutzer mit Workspace-Zugriff Workspaces einer Organisation verwalten, während ein Benutzer mit Sicherheitszugriff Einladungen und Rollen verwalten kann.

## Rollen

Der Zugriff auf die Organisation wird über diese Rollen gesteuert:

| Rolle | Was sie erlaubt |
| --- | --- |
| Admin | Organisationseinstellungen bearbeiten und die Administration auf Organisationsebene verwalten. |
| Workspace | Workspaces der Organisation erstellen, bearbeiten, anhalten, fortsetzen, löschen und versionieren. |
| Sicherheit | Benutzer einladen, Benutzer entfernen und Organisationsrollen bearbeiten. |
| Abrechnung | Abrechnungsinformationen anzeigen, wenn der Abrechnungszugriff aktiviert ist. |

Rollen werden im Dialog für den Organisationszugriff zugewiesen. Eine ausstehende Einladung wird aktiv, nachdem die eingeladene Person sie angenommen hat.
