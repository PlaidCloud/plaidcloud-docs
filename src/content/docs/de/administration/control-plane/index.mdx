Die PlaidCloud Control Plane richtet sich an Partner-Administratoren und Kunden-Administratoren, die Organisationen und Workspaces verwalten. Damit erstellen Sie Workspaces, weisen die Workspace-Eigentümerschaft zu, legen das Release-Verhalten fest, aktivieren Workspace-Dienste, konfigurieren das Branding und verwalten den Zugriff auf Organisationsebene.

<Aside type="note">
	Der Bereich PlaidAdmin ist für die PlaidCloud-Betriebsmitarbeiter vorgesehen. Dieses Handbuch behandelt nur die Administrationsbereiche für Partner und Kunden.
</Aside>

## Navigation

Verwenden Sie nach der Anmeldung die linke Navigation:

1. Öffnen Sie **Organizations**, um Organisationen anzuzeigen oder zu bearbeiten, die Sie administrieren.
2. Öffnen Sie **Trust Center**, um die Sicherheitsdokumente von PlaidCloud für eine von Ihnen administrierte Organisation herunterzuladen.
3. Öffnen Sie **Workspaces**, um Workspaces, die Sie verwalten können, anzuzeigen, zu erstellen, zu bearbeiten, zu pausieren, fortzusetzen oder gesammelt zu aktualisieren.
4. Verwenden Sie Ihr Profilmenü, um Ihr Kontoprofil zu aktualisieren oder sich abzumelden.

Welche Aktionen Sie sehen, hängt von Ihren Organisationsrollen ab. Beispielsweise kann ein Benutzer mit Workspace-Zugriff die Workspaces einer Organisation verwalten, während ein Benutzer mit Sicherheitszugriff Einladungen und Rollen verwalten kann.

## Rollen

Der Zugriff auf eine Organisation wird über diese Rollen gesteuert:

| Rolle | Berechtigungen |
| --- | --- |
| Administrator | Organisationseinstellungen bearbeiten und die Administration auf Organisationsebene verwalten. |
| Workspace | Workspaces in der Organisation erstellen, bearbeiten, pausieren, fortsetzen, löschen und versionieren. |
| Sicherheit | Benutzer einladen, Benutzer entfernen und Organisationsrollen bearbeiten. |
| Abrechnung | Abrechnungsinformationen anzeigen, wenn der Abrechnungszugriff aktiviert ist. |

Rollen werden im Dialogfeld für den Organisationszugriff zugewiesen. Eine ausstehende Einladung wird aktiv, sobald die eingeladene Person sie annimmt.
