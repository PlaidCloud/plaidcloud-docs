Wenn inaktive Mitglieder nicht in PlaidCloud verbleiben sollen, können Sie sie mithilfe der Ablauffunktionen von PlaidCloud nach einem festgelegten Zeitraum der Inaktivität automatisch aus der Organisation entfernen lassen. Dieser automatische Entzug ruhender Mitglieder kann auf bis zu einen Tag verkürzt werden.

<Aside>Wenn Sie diese Option auf null (0) setzen, werden in der Organisation keine Mitglieder automatisch entfernt.</Aside>


**So legen Sie den Ablauf von Mitgliedern fest:**

1. Wählen Sie oben rechts auf dem Bildschirm das Menü „Organization Settings“ aus
2. Klicken Sie auf „Organization and User Settings“
3. Legen Sie die gewünschte Anzahl von Tagen bis zum Ablauf fest
4. Klicken Sie auf Update
