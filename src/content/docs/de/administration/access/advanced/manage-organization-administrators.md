Organisationen in PlaidCloud bieten einen Bereich auf oberster Ebene, in dem Sie Optionen wie Single Sign-On und die Zugriffsmöglichkeiten von Mitgliedern steuern. Jede Organisation enthält mindestens einen Workspace; Workspaces bilden damit die wichtigste Ebene der Mandantentrennung in PlaidCloud. Ein Workspace hilft dabei, Teams auf bestimmte Interessenbereiche auszurichten und den Zugriff entsprechend abzugrenzen. PlaidCloud erlaubt Organisationen eine unbegrenzte Anzahl von Workspaces.



## Organisationsadministratoren verwalten


Jede Organisation in PlaidCloud kann mehrere Administratoren haben. Administratoren verfügen über besondere Rechte zur Steuerung der Organisation. Sie können unter anderem die Abrechnung verwalten, die Zugriffsverwaltung aktualisieren und Workspaces verwalten. So verwalten Sie Administratoren:


1. Wählen Sie oben rechts auf dem Bildschirm das Menü „Organization Settings“ aus
2. Klicken Sie auf „Administrators“

Daraufhin wird die Tabelle der aktuellen Administratoren angezeigt. Nachdem sich die Tabelle geöffnet hat, können Sie neue Administratoren hinzufügen, bestehende Administratoren löschen oder Administratorrechte ändern.



## Administrator hinzufügen


So fügen Sie einen Administrator hinzu:


1. Wählen Sie oben rechts auf dem Bildschirm das Menü „Organization Settings“ aus
2. Klicken Sie auf „Administrators“
3. Klicken Sie auf die Schaltfläche „Add Organization Administrator“
4. Füllen Sie die erforderlichen Felder aus
5. Klicken Sie auf „Add as Administrator“

## Administrator löschen


So löschen Sie einen Administrator:


1. Wählen Sie oben rechts auf dem Bildschirm das Menü „Organization Settings“ aus
2. Klicken Sie auf „Administrators“
3. Klicken Sie auf das Löschen-Symbol des gewünschten Administrators
4. Bestätigen Sie und klicken Sie auf „Delete as Administrator“
