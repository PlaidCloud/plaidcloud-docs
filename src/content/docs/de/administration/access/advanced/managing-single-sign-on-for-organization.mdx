Jede Organisation kann eine eigene URL ([https://plaidcloud.com/sso](https://plaidcloud.com)/`<custom_name_here>`) haben, über die Mitglieder die in der Konfiguration festgelegte Single-Sign-On-Seite aufrufen.

<Aside>Single Sign-On verwendet SAML-2.0-Protokolle und wird über die Benutzeroberfläche eingerichtet.</Aside>

<Aside type="tip">Damit sich die Benutzer eines Workspace mit Microsoft Entra ID, Okta oder einem anderen OpenID-Connect-Anbieter anmelden können, verwenden Sie den geführten Dialog **Single sign-on** (Enterprise-Single-Sign-On ist in kostenpflichtigen Tarifen enthalten; Kennwort mit MFA und Social-Anmeldung sind in jedem Tarif verfügbar) auf der Seite **Workspaces**. Siehe [Single Sign-On](/de/administration/control-plane/workspace-configuration/#single-sign-on).</Aside>

So erstellen Sie eine benutzerdefinierte URL:

1. Wählen Sie oben rechts auf dem Bildschirm das Menü „Organization Settings“ aus
2. Klicken Sie auf „Single Sign-On Security Credentials“
3. Passen Sie die Single-Sign-On-URL nach Bedarf an
4. Klicken Sie auf „Update Organization SSO Settings“

## Automatisches Erstellen von Benutzern zulassen

Wenn Single Sign-On aktiviert ist, können Sie festlegen, dass Mitglieder nach erfolgreicher Single-Sign-On-Authentifizierung automatisch erstellt werden. Neue Mitglieder erhalten den Standard-Workspace und die Sicherheitsrollen, die in den Organisationseinstellungen festgelegt sind. So erstellen Sie Mitglieder automatisch:

1. Wählen Sie oben rechts auf dem Bildschirm das Menü „Organization Settings“ aus
2. Klicken Sie auf „Organization and User Settings“
3. Aktivieren Sie das Kontrollkästchen „Create Users Automatically from Single Sign-On“
4. Wählen Sie den gewünschten Standard-Workspace aus

Diese Funktion vereinfacht die Mitgliederverwaltung erheblich, da neue Mitglieder automatisch Zugriff erhalten, ohne dass in PlaidCloud eine weitere Einrichtung nötig ist. Werden Mitglieder dagegen aus der Single-Sign-On-Einrichtung entfernt, haben sie keinen Zugriff mehr auf PlaidCloud.


## Zuweisung von Sicherheitsgruppen über Single Sign-On zulassen

Wenn Single Sign-On aktiviert ist, können Sie festlegen, dass zusammen mit der positiven Authentifizierungsmeldung eine Liste von Gruppenzuordnungen übergeben wird. Anhand der Einträge dieser Liste wird ein Mitglied den angegebenen Gruppen zugewiesen und aus allen nicht angegebenen Gruppen entfernt. So lassen sich Zuweisungen von Sicherheitsgruppen effektiv über einen zentralen Benutzerverwaltungsdienst wie Active Directory oder einen anderen LDAP-Dienst verwalten.


<Aside>Ist ein Mitglied in einem Workspace als Administrator gekennzeichnet, behält es vollen Zugriff auf diesen Workspace – unabhängig von der Rolle, die ihm über diesen automatisierten Prozess zugewiesen wird.</Aside>


Ist diese Option aktiviert, werden Sicherheitsrollen bei der nächsten Anmeldung eines Mitglieds anhand der übermittelten Liste zugewiesen. Ist die Option deaktiviert, behalten bestehende Mitglieder ihre aktuellen Sicherheitsrollen, bis sie in PlaidCloud manuell aktualisiert werden.
