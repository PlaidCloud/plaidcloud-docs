Mit Workspaces kann eine Organisation als eigener cloudbasierter Dienst betrieben werden, für kleine wie für große Organisationen. So haben kleine Teams möglicherweise einen einzigen Workspace in ihrer Organisation, während große Organisationen Hunderte spezialisierter Workspaces haben können.



Workspaces steuern Zugriff und Sichtbarkeit und bieten isolierte Bereiche, in denen die Mitglieder einer Organisation arbeiten. Der Zugriff auf Workspaces wird Mitgliedern in einer privaten, mandantenfähigen Umgebung der Organisation zugewiesen. Mit Workspaces können Teams in einigen Workspaces an offenen Projekten zusammenarbeiten und in anderen Workspaces strikte Vertraulichkeit wahren.



Da Workspaces vollständig voneinander isoliert sind, können Daten nicht direkt zwischen Workspaces geteilt oder abgerufen werden. Workspaces können jedoch auf denselben gemeinsamen Dokumentenbereich zugreifen, sodass der Austausch von Dateien zwischen Workspaces bei Bedarf möglich ist.



## Workspaces anzeigen und verwalten


Das Anzeigen und Verwalten von Workspaces innerhalb einer Organisation ist einfach. Sie müssen Inhaber der Organisation sein, um Workspaces zu verwalten. So zeigen Sie Workspaces an und verwalten sie:


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“

Dadurch gelangen Sie zu einer Tabelle mit allen aktuellen Workspaces der Organisation. Von hier aus können Sie Workspaces erstellen, aktualisieren, sperren und löschen, Apps zu Workspaces hinzufügen und den Mitgliederzugriff auf jeden Workspace verwalten.



### Einen Workspace erstellen


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“
3. Klicken Sie auf die Schaltfläche „New Workspace“
4. Füllen Sie die erforderlichen Felder aus
5. Klicken Sie auf „Submit“

<Aside>Standardmäßig wird das Mitglied, das den Workspace erstellt hat, ihm automatisch zugewiesen.</Aside>


### Einen Workspace aktualisieren


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“
3. Klicken Sie auf das Bearbeitungssymbol des gewünschten Workspace
4. Passen Sie die Felder nach Bedarf an
5. Klicken Sie auf „Submit“

### Einen Workspace sperren


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“
3. Deaktivieren Sie das Kontrollkästchen „Active“ des gewünschten Workspace
4. Klicken Sie auf „Submit“

### Einen Workspace löschen


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“
3. Klicken Sie auf das Löschsymbol des gewünschten Workspace
4. Klicken Sie erneut auf „Delete“

<Aside>Das Löschen ist eine dauerhafte Aktion. Dabei werden der Workspace und alle zugehörigen Daten gelöscht. Stellen Sie sicher, dass Sie alles Benötigte gesichert haben, bevor Sie dies tun.</Aside>


### Im Workspace verfügbare Apps verwalten


Standardmäßig werden neuen Workspaces automatisch drei Apps hinzugefügt: Analyze, Document und Identity. Identity kann nicht entfernt werden, da es für die Verwaltung von Zugriff und Rollen in einem Workspace unverzichtbar ist; Analyze und Document können dagegen entfernt werden. So verwalten Sie, welche Apps in einem Workspace verfügbar sind, einschließlich benutzerdefinierter Apps:


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“
3. Klicken Sie auf das App-Symbol des Workspace, dessen zugehörige Apps Sie ändern möchten
4. Wenn Sie eine App entfernen möchten, klicken Sie auf das Löschsymbol der zu entfernenden App und bestätigen Sie das Löschen
5. Wenn Sie eine neue App hinzufügen möchten, klicken Sie auf die Schaltfläche **Add App to Workspace**, wählen Sie die gewünschte App aus, aktivieren Sie das Kontrollkästchen **Enable for Use** und klicken Sie auf die Schaltfläche „create“
