Mitglieder können zwar mit weiteren Workspaces innerhalb einer Organisation verbunden sein, aber jeder Workspace hat eigene Zugriffsbeschränkungen. Mitglieder müssen die Berechtigung erhalten, einen Workspace anzuzeigen und darauf zuzugreifen.



## Mitglieder hinzufügen


So fügen Sie ein Mitglied hinzu:


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“
3. Klicken Sie auf das Mitglieder-Symbol
4. Wählen Sie das gewünschte Mitglied aus und ziehen Sie es in die passende Spalte
5. Klicken Sie auf „Submit“

<Aside>Um Mitglieder zu einem Workspace hinzuzufügen, müssen die Mitglieder Teil der Organisation sein und im Formular zur Mitgliederverwaltung erscheinen. Wenn Sie ein Mitglied hinzufügen möchten, das nicht im Formular zur Mitgliederverwaltung erscheint, müssen Sie das Mitglied zuerst in den Workspace einladen.</Aside>



So senden Sie eine Einladung:


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“
3. Klicken Sie auf das Einladungs-Symbol

Dadurch wird eine E-Mail-Einladung an das Mitglied gesendet. Das Mitglied muss dann auf den Link in der E-Mail klicken und den Anweisungen folgen, um sich anzumelden oder – falls es neu bei PlaidCloud ist – ein Konto zu erstellen. Nach erfolgreicher Anmeldung wird das Mitglied dem Workspace hinzugefügt.



## Mitglieder entfernen


So entfernen Sie ein Mitglied:


1. Wählen Sie im Menü oben rechts im Browser „Organization Settings“
2. Klicken Sie auf „Workspaces“
3. Klicken Sie auf das Mitglieder-Symbol
4. Wählen Sie das gewünschte Mitglied aus und ziehen Sie es in die passende Spalte
5. Klicken Sie auf „Submit“
