PlaidCloud のコントロールプレーンは、組織とワークスペースを管理するパートナー管理者およびお客様の管理者向けです。ワークスペースの作成、ワークスペースの所有権の割り当て、リリース動作の選択、ワークスペースサービスの有効化、ブランディングの設定、組織レベルのアクセス管理に使用します。

<Aside type="note">
	PlaidAdmin エリアは PlaidCloud の運用スタッフ向けです。このガイドで扱うのは、パートナー管理エリアとお客様の管理エリアのみです。
</Aside>

## ナビゲーション

サインイン後、左側のナビゲーションを使用します。

1. **Organizations** を開いて、管理している組織を表示または編集します。
2. **Trust Center** を開いて、管理している組織向けの PlaidCloud のセキュリティドキュメントをダウンロードします。
3. **Workspaces** を開いて、管理できるワークスペースの表示、作成、編集、一時停止、再開、一括更新を行います。
4. プロフィールメニューから、アカウントのプロファイルを更新するか、サインアウトします。

表示される操作は、組織でのロールによって異なります。たとえば、ワークスペースアクセスを持つユーザーは組織のワークスペースを管理でき、セキュリティアクセスを持つユーザーは招待とロールを管理できます。

## ロール

組織へのアクセスは、次のロールで制御されます。

| ロール | できること |
| --- | --- |
| 管理者 | 組織の設定を編集し、組織レベルの管理を行います。 |
| ワークスペース | 組織内のワークスペースの作成、編集、一時停止、再開、削除、バージョン管理を行います。 |
| セキュリティ | ユーザーの招待と削除、組織のロールの編集を行います。 |
| 請求 | 請求アクセスが有効な場合に、請求情報を表示します。 |

ロールは組織のアクセスダイアログから割り当てます。保留中の招待は、招待された人が承諾すると有効になります。
