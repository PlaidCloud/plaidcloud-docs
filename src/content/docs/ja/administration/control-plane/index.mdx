PlaidCloud のコントロールプレーンは、組織とワークスペースを管理するパートナー管理者と顧客管理者向けの機能です。ワークスペースの作成、ワークスペースのオーナーの割り当て、リリース動作の選択、ワークスペースサービスの有効化、ブランディングの設定、組織レベルのアクセス管理に使用します。

<Aside type="note">
	PlaidAdmin 領域は PlaidCloud の運用スタッフ向けです。このガイドでは、パートナーと顧客の管理領域のみを扱います。
</Aside>

## ナビゲーション

サインインしたら、左側のナビゲーションを使用します。

1. **Organizations** を開いて、管理している組織を表示または編集します。
2. **Workspaces** を開いて、管理できるワークスペースを表示、作成、編集、一時停止、再開、または一括更新します。
3. プロフィールメニューを使用して、アカウントのプロフィールを更新するか、サインアウトします。

表示される操作は、組織でのロールによって異なります。たとえば、ワークスペースアクセスを持つユーザーは組織のワークスペースを管理でき、セキュリティアクセスを持つユーザーは招待とロールを管理できます。

## ロール

組織へのアクセスは、次のロールで制御されます。

| ロール | 許可される操作 |
| --- | --- |
| Admin | 組織設定の編集と、組織レベルの管理。 |
| Workspace | 組織内のワークスペースの作成、編集、一時停止、再開、削除、バージョン管理。 |
| Security | ユーザーの招待、ユーザーの削除、組織ロールの編集。 |
| Billing | 請求アクセスが有効な場合の請求情報の表示。 |

ロールは、組織のアクセスダイアログから割り当てます。保留中の招待は、招待された人が承諾すると有効になります。
