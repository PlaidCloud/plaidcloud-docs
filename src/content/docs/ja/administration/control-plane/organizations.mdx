組織は、関連する PlaidCloud ワークスペースをまとめる管理上の境界です。組織設定では、コントロールプレーンに表示される名前、請求メタデータ、SSO の動作、組織を管理できるユーザーを制御します。

## 組織の一覧

**Organizations** ページには、アクセスできる組織が表示されます。テーブルから次の操作ができます。

1. 表示されているテーブルフィールドで組織を検索する。
2. 組織の一覧を更新する。
3. 組織の詳細を表示する。
4. 管理者アクセスがある場合に、組織設定を編集する。
5. セキュリティアクセスがある場合に、組織のアクセス管理を開く。
6. 請求アクセスがある場合に、請求レコードを開く。

## 組織設定

| 設定 | 説明 |
| --- | --- |
| 名前 | 組織の表示名。 |
| ID | 組織の固定識別子。組織の作成時に設定されます。 |
| メモ | コントロールプレーンに表示される社内向けのメモまたは説明。 |
| プラン | 契約プラン（Enterprise、Team、Free）。 |
| 税務 ID | 請求レコードに使用される税務識別子。 |
| 有効 | 組織が有効かどうか。 |
| ロック済み | 有効にすると、通常の組織変更を禁止します。 |
| SSO を必須にする | メンバーに、組織のシングルサインオン構成を通じたサインインを必須にします。 |

## 請求メタデータ

請求フィールドは、組織への請求方法を表します。これらのフィールドだけでは、製品へのアクセスは付与されません。

| 設定 | オプション |
| --- | --- |
| 請求サイクル | 月次、四半期、半年、年次 |
| 請求価格 | 選択したサイクルの請求金額（数値）。 |
| 支払い方法 | PO 請求書払い、無料トライアル、無料、スケジュール払い |

## SSO の動作

| 設定 | 説明 |
| --- | --- |
| 動的グループ割り当て | SSO のグループ情報によって組織ロールを割り当てられるようにします。 |
| 動的ユーザー作成 | ID プロバイダーが承認済みのユーザーを送信した場合に、SSO サインインでユーザーを自動的に作成できるようにします。 |
| SSO 動的グループ割り当て名 | 動的割り当てに使用する SSO グループ名。 |

<Aside type="note">
	ワークスペースの ID プロバイダーは、その [シングルサインオンダイアログ](/ja/administration/control-plane/workspace-configuration/#シングルサインオン)で設定します。SAML の設定については、アクセス管理のガイドで説明しています。ここで説明するコントロールプレーンの設定は、SSO 構成が作成された後に、組織がその構成をどのように使用するかを決定します。
</Aside>

## アクセスの管理

**Manage Access** を使用して、組織にユーザーを招待し、組織ロールを割り当てます。

1. **Organizations** を開きます。
2. 組織を選択します。
3. **Manage Access** を開きます。
4. **Invite User** をクリックして、1 つ以上のメールアドレスを招待します。
5. 各ユーザーに付与するロールを選択します。
6. 必要に応じて、カスタムメッセージを追加します。
7. 招待を送信します。

承諾済みユーザーのロールの編集、承諾済みユーザーの削除、保留中の招待のキャンセルができます。保留中のユーザーは、招待を承諾するまで編集できません。

## 組織ロール

| ロール | 用途 |
| --- | --- |
| Admin | 組織設定と管理者レベルの変更。 |
| Workspace | ワークスペースの作成、構成、リリース、一時停止、再開の操作。 |
| Security | 招待と組織ロールの管理。 |
| Billing | 請求レコードへのアクセス。 |
