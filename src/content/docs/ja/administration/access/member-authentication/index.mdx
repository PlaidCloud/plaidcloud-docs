Identity タブには、安全なメンバープラットフォームを実現するために PlaidCloud が重視するセキュリティ機能と認証機能がまとまっています。PlaidCloud では、次の 3 種類の認証タイプを選択できます。


* パスワードのみ
* 二要素認証
* シングルサインオン

デフォルトの認証タイプはパスワードのみですが、二要素認証を有効にすることもできます。シングルサインオンの SAML 認証プロバイダーを利用できる場合は、PlaidCloud の組織でシングルサインオンを使用するように構成できます。

個人アカウントを作成した場合、デフォルトの認証タイプはパスワードのみです。二要素認証に変更するには、「二要素認証」セクションの手順を参照してください。

<Aside>メンバーは、セキュリティ上の目的や、ワークスペースのメンバーを管理するために、Identity タブにアクセスできる場合があります。新しいメンバーやアクセス権のないメンバーのセキュリティと認証の管理方法については、メインの「Identity」ページを参照してください。</Aside>


## パスワードの変更

二要素認証またはパスワードのみの認証を使用しているメンバーは、右上にある「Member」メニュー（Gravatar アイコン）から簡単にパスワードを変更できます。


**パスワードを変更するには、次の手順に従います。**

1. 右上のアイコン（Gravatar）を選択します


	* 「Member」メニューのアイコンは、ユーザーごとに異なります
2. ドロップダウンメニューの「Change Password」をクリックします
3. 求められた場所に現在のパスワードを入力します
4. 求められた場所に新しいパスワードを入力します
5. 確認のため、パスワードをもう一度入力します
6. 「Update」ボタンをクリックして保存します

<Aside>強力なパスワードのみが受け付けられます。また、新しいパスワードは現在のパスワードと異なるものにする必要があります。</Aside>


## サインアウト


サインアウトするには、右上のアイコン（Gravatar）を選択し、ドロップダウンメニューの「Sign Out」をクリックします。

サインアウトすると PlaidCloud のセッションが終了し、サインアウト済みのページに移動します。PlaidCloud に戻るには、もう一度サインインします。

<Aside>次回 PlaidCloud に戻ったときは、あらためてサインインするよう求められます。</Aside>

管理者は、サインアウト時に ID プロバイダーとのシングルサインオンのセッションも終了するように、PlaidCloud を構成することもできます。


## パスワードのみの認証

パスワードのみの認証は、最もシンプルな選択肢ですが、長く複雑なパスワードを使用しても最も安全性が低い方法です。セキュリティリスクをあまり気にせず、手早く手軽にアクセスしたい場合に適しているかもしれません。パスワードのみの認証は今でも広く使われていますが、代わりに二要素認証を使用することを強くおすすめします。


## 二要素認証


二要素認証（多要素認証）は、「知っているもの」（パスワード）と「持っているもの」（アクセスキー）の両方を必要とするため、パスワードのみの認証よりもセキュリティが大幅に向上します。つまり、パスワードだけではアクセスできません。

パスワードは、悪意のある第三者がアクセスを得るために必要な情報が*たった 1 つ*であるため、セキュリティ上の脅威にさらされやすいという弱点があります。二要素認証では、サインインに*追加の情報*を求めることで、セキュリティをさらに高めます。そのため、PlaidCloud だけでなく、二要素認証に対応している他のウェブサイトでも、アカウントを守るために二要素認証を使用することを**強く**おすすめします。


### 二要素認証の有効化


**二要素認証を有効にして、認証コードの設定を選択するには、次の手順に従います。**


1. 右上のアイコン（Gravatar）を選択します
2. ドロップダウンメニューの「Manage Multi-Factor Authentication」をクリックします
3. 希望する二要素認証コードの受け取り方法を選択します。

### 二要素認証の種類

PlaidCloud では、この追加情報を受け取る方法を 3 つから選べます。

* スマートフォンアプリ（Google Authenticator、Authy、Okta、FreeOTP など）
* テキストメッセージ（SMS）
* Yubico 社の YubiKey（http://yubico.com）

### スマートフォンによる認証


スマートフォンアプリでコードを受け取るには、[iOS](https://itunes.apple.com/us/app/google-authenticator/id388497605?mt=8) または [Android](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2) の端末に、Google Authenticator などの認証アプリをダウンロードする必要があります。他の互換性のある認証アプリも使用できますが、この記事では Google Authenticator アプリを使用することを前提としています。

アプリをダウンロードしたら、アプリを開いて、アプリ内のセットアップ手順に従います。


**認証アプリのセットアップが完了したら、次の手順に従います。**


1. 「+」ボタンをタップします
2. 「Scan barcode」を選択します
3. PlaidCloud の Gravatar アイコンの下にある「Manage Multi-Factor Authentication」を開きます
4. PlaidCloud で「Configure Authenticator」を選択します
5. 指示が表示されたら、スマートフォンで PlaidCloud に表示された QR コードをスキャンします
6. QR コードをスキャンすると、認証アプリに 30 秒ごとに変わる 6 桁の認証コードが表示されます
7. 前の手順から開いたままになっているはずの、PlaidCloud の「Configure SmartPhone Authentication」画面の下部にあるテキストボックスに、このコードを入力します
8. 「Verify」を選択します。
9. コードが有効な場合は、アカウントで二要素認証が有効になり、バックアップコードの一覧が表示されます。
10. 有効にした後で、もう一度「Manage Multi-Factor Authentication」を選択すると、バックアップコードの表示や二要素認証の無効化ができます。

### SMS による認証


**SMS による認証を使用するには、次の手順に従います。**


1. PlaidCloud の Gravatar アイコンの下にある「Manage Multi-Factor Authentication」を開きます
2. PlaidCloud で「Configure SMS」を選択します
3. 携帯電話番号とキャリアを入力します
4. 「Submit」をクリックします
5. 認証コードを含むテキストメッセージが送信されます
6. PlaidCloud に表示されるウィンドウにこのコードを入力します
7. コードが有効な場合は、アカウントで二要素認証が有効になり、ログインするたびに SMS で異なるコードが送信されるので、それを入力します
8. 有効にした後で、もう一度「Manage Multi-Factor Authentication」を選択すると、連絡先情報の更新や二要素認証の無効化ができます。

### YubiKey による認証


Yubico 社が製造するハードウェア認証デバイスである YubiKey を使用する場合、メンバーはアカウントに最大 5 つの YubiKey を登録できます。ワークスペースのアクセスセキュリティを担当する人が管理できる、PlaidCloud 管理の YubiKey プールを用意しているほか、メンバーが一般的な YubiKey を自由に使用することもできます。

<Aside>PlaidCloud の YubiKey プールのキー（PlaidCloud が発行した YubiKey）も、5 つの上限に含まれます。</Aside>

YubiKey 認証を有効にするには、まず YubiKey を 1 つ以上登録する必要があります。



**YubiKey を登録するには、次の手順に従います。**


1. 右上のアイコン（Gravatar）を選択します
2. ドロップダウンメニューの「Change Registered YubiKeys」をクリックします
3. 「My Registered YubiKeys」フォームの空いている場所にカーソルを置きます
4. YubiKey をコンピューターに挿入します
5. YubiKey のワンタイムパスワード（OTP）ボタンを押します
6. OTP が入力されたら、フォームの「Update」ボタンをクリックして保存します

YubiKey を 1 つ以上登録したら、アカウントに設定できます。


**YubiKey を設定するには、次の手順に従います。**


1. Gravatar アイコンを選択します
2. 「Manage Multi-Factor Authentication」をクリックします
3. 「Configure YubiKey」を選択します
4. 表示されたフォームに、YubiKey の OTP のいずれかを入力します。

OTP が有効な場合は、アカウントで二要素認証が有効になり、ログインするたびに YubiKey の OTP を入力する必要があります。



### PlaidCloud の YubiKey プール


管理対象の YubiKey プールを使うと、ワークスペースのメンバーの二要素認証を簡単に管理できます。管理対象のキーには PlaidCloud のロゴが入っており、メンバーに直接発送することも、管理者にまとめて発送することもできます。



管理対象プールには、個別の YubiKey と比べて次の利点があります。


* キーを紛失しても、メンバーがリカバリーコードを保管しなくても簡単に交換できます
* キーの割り当てはポイントアンドクリックで行えます。メンバーがキーを登録する必要はありません
* ポイントアンドクリックのインターフェースで、YubiKey の割り当ての確認とキーの無効化ができます
* 新しいキーを注文して、メンバーに直接発送できます
* 管理対象の YubiKey は、YubiKey の OTP を受け付ける他のサービスとも完全に互換性があります
* メンバーの入れ替わりが発生しても、セキュリティを損なうことなく、YubiKey を他のメンバーに再割り当てできます

**新しいキーを注文するには、次の手順に従います。**


1. Identity を開きます
2. 「Security」タブを選択します
3. ドロップダウンメニューの「PlaidCloud Security Keys」をクリックします
4. フォームの「Order More Keys」ボタンをクリックします

管理対象のキーを注文した場合は、管理対象キーのテーブルに表示されます。



キーの割り当てフォームでは、キーを割り当てる、未割り当てにする、紛失としてマークする、といった操作ができます。また、各キーにはメモを添付して、キーの発行に関する記録を残せます。そのためには、編集アイコンをクリックして、必要な変更を加えます。



管理対象キーの費用は 1 回限りです。使用に伴う継続的な費用は発生しません。管理対象の YubiKey は、1 つあたり 30 ドル（送料別）です。



## リカバリーコードの役割


セキュリティ上の理由から、二要素認証を有効にしているアカウントについては、スマートフォンや YubiKey を紛失しても、PlaidCloud サポートがすぐにアクセスを復元することはできません。リカバリーコードを使うと、スマートフォンや YubiKey を紛失した場合でも、アカウントにアクセスして、そこから再設定できます。



二要素認証の設定が完了すると、ランダムに生成されたリカバリーコードのセットが表示されるので、確認して保存してください。リカバリーコードはすぐに保存することを強くおすすめします。なお、このコードは、二要素認証を有効にした後であれば、いつでもダウンロードできます。詳細については、[二要素認証のリカバリーコードのダウンロード](https://plaidcloud.com/docs/identity/downloading-your-two-factor-authentication-recovery-codes)を参照してください。


<Aside>バックアップコードやバックアップキーを登録していない場合は、はるかに厳格なプロセスが適用され、アクセス要求の真正性を確認して PlaidCloud のセキュリティを維持するために、数日かかることがあります。</Aside>



### YubiKey の紛失


プロフィールの一部として SMS の番号を登録できます。登録済みの YubiKey のセットとリカバリーコードの両方にアクセスできなくなった場合は、バックアップ用の SMS 番号を使ってアカウントに再びアクセスできます。


<Aside>これは自動化されたプロセスではないため、アクセスを回復するまでに時間がかかる場合があります。</Aside>


メンバーが管理対象プールのキーを紛失した場合は、ワークスペースのプール管理者がそのキーを紛失としてマークし、新しいキーを発行できます。これにより、アカウントにアクセスできなくなるリスクや、リカバリーコードを保管しておく手間を減らせます。



キーを紛失としてマークするには、次の手順に従います。


1. Identity を開きます
2. 「Security」を選択します
3. 「PlaidCloud Security Keys」をクリックします
4. 編集アイコンをクリックします
5. 「Key Usage Information」セクションの「Lost」を選択します
6. 「Update」をクリックします

これにより、キーが紛失としてマークされ、新しいキーを発行できるようになります。



## シングルサインオン


シングルサインオンでは、実際の認証処理を外部サービスが行い、PlaidCloud は成功または失敗の応答を受け取るだけです。シングルサインオンを使用すると、複数のアプリケーションにわたるパスワード管理の負担を減らせるほか、従業員の退職時やアクセス制限の適用時にも、適切なメンバー管理を徹底できます。



シングルサインオンは、メンバーにとって最も使いやすい選択肢です。安全性は、外部の提供元が使用する認証プロセスと同等です。シングルサインオンを使うと、パスワードを常に最新の状態に保ち、メンバーが利用する他のサービスと同期させることができます。



シングルサインオンは、裏側でより広範な認証プロセスが必要になり、通常は IT やネットワークセキュリティとの技術的な調整が必要ですが、誰でも利用できます。ただし、一般的には大企業や教育機関で使用されています。



シングルサインオンの設定と管理の詳細については、[組織とワークスペースの管理領域](/ja/administration/access/advanced/managing-single-sign-on-for-organization)を参照してください。
