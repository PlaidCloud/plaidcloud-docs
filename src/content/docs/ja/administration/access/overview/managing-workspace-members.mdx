メンバーは組織内の他のワークスペースにも所属できますが、アクセス制限はワークスペースごとに異なります。ワークスペースを表示してアクセスするには、メンバーに権限を付与する必要があります。



## メンバーの追加


メンバーを追加するには、次の手順に従います。


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします
3. メンバーアイコンをクリックします
4. 追加するメンバーを選択し、適切な列にドラッグします
5. 「Submit」をクリックします

<Aside>ワークスペースにメンバーを追加するには、そのメンバーが組織に所属しており、メンバー管理フォームに表示されている必要があります。メンバー管理フォームに表示されていないメンバーを追加する場合は、先にそのメンバーをワークスペースに招待してください。</Aside>



招待を送信するには、次の手順に従います。


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします
3. 招待アイコンをクリックします

この操作により、メンバーに招待メールが送信されます。メンバーはメール内のリンクをクリックし、案内に従ってログインします。PlaidCloud を初めて利用する場合は、アカウントを作成します。ログインに成功すると、メンバーがワークスペースに追加されます。



## メンバーの削除


メンバーを削除するには、次の手順に従います。


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします
3. メンバーアイコンをクリックします
4. 削除するメンバーを選択し、適切な列にドラッグします
5. 「Submit」をクリックします
