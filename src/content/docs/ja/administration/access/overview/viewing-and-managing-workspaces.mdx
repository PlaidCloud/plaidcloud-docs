ワークスペースを使うと、小規模から大規模までのあらゆる組織が、独自のクラウドベースのサービスとして運用できます。たとえば、小規模なチームでは組織内に 1 つのワークスペースを持ち、大規模な組織では数百の専門的なワークスペースを持つこともあります。



ワークスペースは、アクセスと可視性を管理するとともに、組織のメンバーが作業するための分離された領域を提供します。ワークスペースへのアクセスは、組織向けのプライベートなマルチテナント環境でメンバーに割り当てられます。ワークスペースを使えば、オープンなプロジェクトで共同作業を行うワークスペースと、厳格な機密性を保つワークスペースを使い分けられます。



ワークスペースは完全に分離されているため、ワークスペース間でデータを直接共有したり、アクセスしたりすることはできません。ただし、ワークスペースは同じ共有ドキュメント領域にアクセスできるため、必要に応じてワークスペース間でファイルを共有できます。



## ワークスペースの表示と管理


組織内のワークスペースの表示と管理は簡単です。ワークスペースを管理するには、組織のオーナーである必要があります。ワークスペースを表示して管理するには、次の手順に従います。


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします

組織内の現在のすべてのワークスペースを示すテーブルが表示されます。ここから、ワークスペースの作成、更新、停止、削除、ワークスペースへのアプリの追加、各ワークスペースへのメンバーのアクセス管理ができます。



### ワークスペースの作成


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします
3. 「New Workspace」ボタンをクリックします
4. 必須フィールドに入力します
5. 「Submit」をクリックします

<Aside>デフォルトでは、ワークスペースを作成したメンバーが自動的にそのワークスペースに割り当てられます。</Aside>


### ワークスペースの更新


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします
3. 対象のワークスペースの編集アイコンをクリックします
4. 必要に応じてフィールドを調整します
5. 「Submit」をクリックします

### ワークスペースの停止


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします
3. 対象のワークスペースの「Active」チェックボックスをオフにします
4. 「Submit」をクリックします

### ワークスペースの削除


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします
3. 対象のワークスペースの削除アイコンをクリックします
4. もう一度「Delete」をクリックします

<Aside>削除は元に戻せない操作です。この操作により、ワークスペースと関連するすべてのデータが削除されます。実行する前に、必要なものがすべてバックアップされていることを確認してください。</Aside>


### ワークスペースで利用可能なアプリの管理


デフォルトでは、新しいワークスペースに Analyze、Document、Identity の 3 つのアプリが自動的に追加されます。Identity は、ワークスペース内のアクセスとロールを管理するために不可欠なため削除できませんが、Analyze と Document は削除できます。カスタムアプリを含め、ワークスペースで利用可能なアプリを管理するには、次の手順に従います。


1. ブラウザー右上のメニューから「Organization Settings」を選択します
2. 「Workspaces」をクリックします
3. 関連付けられたアプリを変更するワークスペースのアプリアイコンをクリックします
4. アプリを削除する場合は、削除するアプリの削除アイコンをクリックし、削除を確認します
5. 新しいアプリを追加する場合は、**Add App to Workspace** ボタンをクリックし、追加するアプリを選択して、**Enable for Use** チェックボックスをオンにし、作成ボタンをクリックします
