各組織には、構成で指定したシングルサインオンページにメンバーがアクセスするためのカスタムURL（[https://plaidcloud.com/sso](https://plaidcloud.com)/`<custom_name_here>`）を設定できます。

<Aside>シングルサインオンはSAML 2.0プロトコルを使用し、ユーザーインターフェイスから設定します。</Aside>

<Aside type="tip">ワークスペースのユーザーがMicrosoft Entra ID、Okta、その他のOpenID Connectプロバイダーでサインインできるようにするには、**Workspaces**ページのガイド付き**Single sign-on**ダイアログを使用します（エンタープライズ向けシングルサインオンは有料プランに含まれます。MFA付きパスワードとソーシャルサインインはすべてのプランで利用できます）。[シングルサインオン](/ja/administration/control-plane/workspace-configuration/#シングルサインオン)を参照してください。</Aside>

カスタムURLを作成するには、次の手順を行います。

1. 画面右上の「Organization Settings」メニューを選択します
2. 「Single Sign-On Security Credentials」をクリックします
3. 必要に応じてシングルサインオンのURLを調整します
4. 「Update Organization SSO Settings」をクリックします

## ユーザーの自動作成を許可する

シングルサインオンが有効な場合、シングルサインオン認証の成功に基づいてメンバーを自動的に作成するように設定できます。新しいメンバーには、組織の設定で指定されたデフォルトのワークスペースとセキュリティロールが付与されます。メンバーを自動的に作成するには、次の手順を行います。

1. 画面右上の「Organization Settings」メニューを選択します
2. 「Organization and User Settings」をクリックします
3. 「Create Users Automatically from Single Sign-On」ボックスをオンにします
4. 目的のデフォルトのワークスペースを選択します

この機能を使用すると、新しいメンバーはPlaidCloudで追加の設定をしなくても自動的にアクセスできるようになるため、メンバー管理が大幅に簡単になります。同様に、メンバーがシングルサインオンの対象から外れた場合は、PlaidCloudにもアクセスできなくなります。

## シングルサインオンからのセキュリティグループ割り当てを許可する

シングルサインオンが有効な場合、認証成功のメッセージとあわせてグループの関連付けリストを渡すように設定できます。リストの項目に基づいて、メンバーが指定されたグループに割り当てられ、指定されていないグループからは削除されます。これは、Active Directoryやその他のLDAPサービスなどの一元的なユーザー管理サービスを使用して、セキュリティグループの割り当てを管理する効果的な方法です。

<Aside>メンバーがワークスペース内で管理者に設定されている場合、この自動処理で割り当てられる個別のロールに関係なく、そのワークスペースへのフルアクセスが維持されます。</Aside>

このオプションを有効にすると、メンバーが次にサインインしたときに、提供されたリストを使用してセキュリティロールが割り当てられます。オプションを無効にすると、既存のメンバーは、PlaidCloud内で手動で更新するまで現在のセキュリティロールを保持します。
