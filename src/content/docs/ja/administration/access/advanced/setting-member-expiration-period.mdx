PlaidCloud内に非アクティブなメンバーを残しておきたくない場合は、PlaidCloudの有効期限機能を使用して、一定期間操作がないメンバーを組織から自動的に削除するように設定できます。この休眠メンバーの自動削除は、最短で1日に設定できます。

<Aside>このオプションを0（ゼロ）に設定すると、組織では自動削除が行われません。</Aside>

**メンバーの有効期限を設定するには：**

1. 画面右上の「Organization Settings」メニューを選択します
2. 「Organization and User Settings」をクリックします
3. 有効期限までの日数を設定します
4. 「Update」をクリックします
