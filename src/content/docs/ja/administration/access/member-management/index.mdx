ID では、ワークスペースのメンバーの追加、削除、一時停止ができます。PlaidCloud のメンバーは複数のワークスペースに所属できるため、ワークスペースからメンバーを削除しても、PlaidCloud からメンバーアカウントが削除されることはありません。



## 新規メンバー


### 新規メンバーの招待


メンバーの追加は招待として行います。ロールを選択して 1 つ以上のメールアドレスを入力すると、各アドレスに対して、そのロールを持つ新しいメンバーアカウントが個別に作成されます。

**メンバーを招待するには:**


1. ID を開き、レールの **メンバー** を選択します（または **概要** の **Invite member** を選択します）
2. **Invite member** をクリックします
3. **閲覧者** または **ビルダー** を選択します（[閲覧者とビルダーの違い](#閲覧者とビルダーの違い)を参照してください）
4. 名、姓、言語を入力します
5. メールアドレスを入力します。複数の人を一度に招待するには、1 行に 1 つのアドレスを入力します
6. **Send invite** をクリックします

招待された各アドレスは、選択したロールを持つ新しいメンバーになります。シングルサインオンを強制していないワークスペースでは、招待されたすべてのメンバー（閲覧者もビルダーも）に、パスワード設定リンクが付いた同じ[ウェルカムメール](#新規メンバーへのウェルカムメール)が届きます。シングルサインオンを強制しているワークスペースでは、招待されたメンバーは代わりに ID プロバイダー経由でサインインするため、パスワード設定メールは送信されません。

選択したロールにより、そのメンバーのワークスペースレベルの機能がすぐに付与されます。ビルダーは、プロジェクトへのアクセス権を持つ場所であればどこでも、すぐにコンテンツを作成および編集できます。ただし、招待しただけでは、新しいメンバーが特定のプロジェクトに追加されるわけではありません。個々のプロジェクトへのアクセスは、各プロジェクトのメンバー一覧から、いつでも別に付与してください。

### すでにアカウントを持つ人の追加

アドレスがすでにワークスペースのメンバーのものである場合（シングルサインオンで初めてサインインしたときにアカウントが自動的に作成された人を含みます）、**ワークスペースメンバーを追加** は失敗せずに、その人をワークスペースに追加します。選択したロールやプロジェクトへのアクセスが適用され、すでに付与されている上位のプロジェクトロールが下げられることはありません。アクセス権があることを本人に知らせるため、ウェルカムメールがすぐに送信され、「&lt;email&gt; はすでにこのワークスペースのメンバーです。アクセス権があることを知らせるため、ウェルカムメールを送信しました。」というメモが表示されます。

このウェルカムメールには、通常どおり、またはシングルサインオンでサインインするよう記載されています。パスワード設定リンクはなく、すでに持っているパスワードが置き換えられることもありません。送信に失敗した場合は通知され、メンバー一覧から **ウェルカムメールを再送信** を使用できます。

一部のアカウントは、理由が示されて拒否されます。

- 無効化されたメンバー。**メンバー** で有効にしてから追加してください。
- システムアカウント。
- メールアドレスが確認されていないアカウント。サポートにお問い合わせください。

複数のアドレスを入力した場合、大文字と小文字の違いや余分なスペースにかかわらず、重複は無視されます。

### 閲覧者とビルダーの違い


メンバーのロールは、ワークスペースレベルの機能、つまりプロジェクトにアクセスできるようになった後で何ができるかを決定します。

- **閲覧者** — 読み取り専用アクセス。すべてのプランで無料かつ無制限なので、閲覧者は好きなだけ招待できます。新しい招待のデフォルトのロールです。
- **ビルダー** — コンテンツを作成および編集できます。ビルダーはプランのビルドシート数の上限にカウントされます（Free プランには 1 つ含まれます）。

招待フォームには、ロールを切り替えるたびに更新されるシート使用状況のメモが表示され、選択したロールが無料かビルドシートを使用するか、またプランにシートがいくつ含まれているかが示されます。プランのビルダーシート数の上限に達すると、ビルダーとしての招待、または既存のメンバーのビルダーへの昇格はブロックされます。閲覧者は、すべてのプランで無料かつ無制限なので影響を受けません。さらにビルダーを招待する必要がある場合は、管理者に連絡してシートを追加してください。

### 新規メンバーへのウェルカムメール


新しいメンバーを追加すると、指定されたメールアドレスにウェルカムメールが送信されます。ただし、ワークスペースがシングルサインオンを強制している場合は、設定するパスワードがなく、メールは送信されません。新しいメンバーは ID プロバイダー経由で直接サインインします。メールには **Set your password** リンクが 1 つ含まれています。新しいメンバーはこれをクリックしてパスワードを選択し、サインインします。ワンタイムコードを最初にリクエストする別の手順はありません。リンクは安全で、1 回のみ有効で、24 時間後に期限切れになります。使用前に期限が切れた場合、メンバーはサインインページで新しいリンクをリクエストできます。ウェルカムメールが配信されなかった場合、PlaidCloud は自動的に再試行するため、新しいメンバーが知らないうちにロックアウトされることはありません。**ウェルカムメールを再送信** は、メンバー一覧から新しいウェルカムメールを送信します。すでにパスワードを設定した、またはサインインしたことのあるメンバーに対しては、理由が表示されて拒否されます。配信に失敗した場合は、成功メッセージではなく失敗が通知されます。ウェルカムメールはカスタマイズして、新しいメンバーの PlaidCloud の利用に関連する追加情報を提供できます。



**ウェルカムメールを更新または表示するには:**


1. ID を開きます
2. 「メンバー」タブを選択します
3. ドロップダウンメニューから「Email Welcome Message」をクリックします
4. 必要な追加や変更を行います
5. 「Update」ボタンをクリックします

## ワークスペース管理者の変更

別のワークスペース管理者を変更したり、誰かを管理者にしたりできるのは、ワークスペース管理者のみです。これには、管理者の詳細やメールアドレスの編集、パスワードのリセットまたは設定、無効化、再有効化、削除、セッションの終了、セキュリティグループの変更、グループへの追加と削除が含まれます。管理者でないメンバーは拒否されます。メンバーを管理する権限を持っていても、ユーザー定義関数が実行されるアカウントなど、プロジェクトまたはエージェントのサービスアカウントも同様に拒否されます。変更は、ワークスペース管理者のみが行えることを示すメッセージとともに拒否されます。

管理者でないメンバーの変更は、メンバーを管理する権限を持つ人であれば、これまでどおり行えます。

## ID ワークスペース

**ID** は、左側のレールと、その横に選択したページが表示される形で開きます。ページを開けないメンバーには、その項目は表示されません。ページの上部にはタイトルがあり、多くの場合、短いサブタイトルが付いています。その横のヘッダーにページのアクションがあります。

| レールのセクション | 項目 |
|---|---|
| **ID** | **概要**、**メンバー**、**ディレクトリ**、**セキュリティグループ**、**配布リスト** |
| **セキュリティ** | **セッション**、**セキュリティログ**、**APIクライアント**、**Group audit**、**All scopes** |
| **インサイト** | **利用状況レポート**。レールの横のページとして開きます |

**概要** には、**メンバー**、**アクティブ**、**Never signed in**、**Builder seats**、**Signed in now** のタイル、**アクティブなメンバー** のチャート、**要対応**、過去 7 日間の **Recent security events** が表示されます。**要対応** には、サインインしていないメンバー（**ウェルカムメールを再送信** 付き）と、再確認が必要なアクセス（**確認** 付き）が一覧表示されます。**Invite member** はページヘッダーにあります。読み込めない数値には、その旨が表示され、**再試行** が提示されます。

**メンバー** には、リストの上に **すべて**、**アクティブ**、**非アクティブ** の選択肢と、標準行、ゆったりした行、カードを切り替える **ビュー** メニューがあります（[標準、ゆったり、カードの表示](/ja/guides/dashboards/using-dashboards/#標準ゆったりカードのビュー)を参照してください）。また、**ビルダー** または **閲覧者** を表示する **Seat** 列があります。**メンバー** と **セキュリティグループ** の横にあるレールの件数は、概要がすでに読み取った内容から取得されます。

## メンバーページ

メンバーまたは **Invite member** を選択すると、そのメンバーがページとして開きます。ページには次のカードがあります。

- **プロファイル**: 名前とサインインの詳細。**編集** で変更できます。
- **アクセス**: メンバーの **Seat**（**ビルダー** または **閲覧者**）、**ワークスペース管理者** アクセス、サービスアカウントの **MFA exemption**。
- **Groups and data**: メンバーのセキュリティグループ、行アクセス、Git アクセス。

ページヘッダーには **セッション** と **アクション** メニューがあります。**アクション** には、**ウェルカムメールを再送信**、**パスワードをリセット**、**ログイン履歴**、**削除** があります。保存されていない変更がある状態でページを離れようとすると、PlaidCloud は変更を破棄するかどうかを確認します。

## メンバーの編集と削除

メンバーフォームの保存中または削除中は、2 回目のクリックで二重に送信されないよう、ボタンが無効になります。メンバーを削除すると確認が表示され、メンバー一覧が更新されます。フォームをすでに閉じていても同様です。

## メンバーセッションの表示と管理


**現在のメンバーセッションを表示するには:**


1. ID を開きます
2. レールの **セキュリティ** の下にある **セッション** を選択します。特定のメンバーのセッションを表示するには、そのメンバーのページで **セッション** を選択します

このテーブルでは、セッション情報（現在のセッションと最終アクティビティ）を表示できるほか、必要に応じてセッションを終了できます。



**セッションを終了するには:**


1. ログアウトさせるメンバーを選択します
2. **選択したセッションを終了** をクリックします

## 配布（ディストロ）リストの管理


配布リスト（ディストロ）は、PlaidCloud 内で管理されるメール配布リストです。レポート、ファイル、その他の情報をグループにすばやく送信する簡単な方法を提供します。配布リスト機能では、ワークスペースごとにリストを管理できます。これにより、対象者を過剰または不足してカバーしてしまう可能性のある外部リストに頼る必要がなくなります。



**リストを管理するには:**


1. ID を開きます
2. レールの **配布リスト** を選択します
3. **New list** ボタンをクリックして、新しいリストを作成します
4. ディストロリストフォームのすべての必須フィールドに入力します
5. 「create」ボタンをクリックします

<Aside>ディストロリストには、ワークスペースのメンバーと、メンバー以外の両方を含められます</Aside>



**各リストのワークスペースメンバーを管理するには:**


1. テーブルのワークスペースアイコン（雲）を選択します
2. リストに含めるメンバーにチェックを入れ、含めないメンバーのチェックを外します。フィルターボックスで人を検索したり、メールアドレスの一覧を貼り付けたりできます。[ピッカーを使った割り当て](/ja/administration/access/managing-security-groups-and-assignments/#ピッカーによる割り当て)を参照してください
3. **メンバーを更新** をクリックします
4. メンバー以外を管理するには、地球儀アイコンをクリックします。

## テキストアラートの状況

メンバーのページの **プロファイル** カードには、**テキストアラート** が表示されます。メンバーのマスクされた番号付きの **オプトイン済み**、**未オプトイン**、または **オプトアウト済み** のいずれかです。これは読み取り専用です。メンバーは、ユーザーメニューの **テキストアラート** から、自分でオプトインとオプトアウトを行います。[テキストアラート](/ja/guides/workflows/text-alerts/)を参照してください。
