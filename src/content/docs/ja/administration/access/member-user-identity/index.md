PlaidCloud では、画面左側の「Identity」タブから、認証とロールベースのセキュリティを一元的に管理できます。ID は、メンバー管理、セキュリティ、各種認証プロセスの基盤となります。

メンバー管理には、現在のメンバーの表示や新しいメンバーの追加から、一括メールの送信まで、あらゆる操作が含まれます。

PlaidCloud はセキュリティを最優先に考えています。「Identity」タブのセキュリティ機能では、セキュリティ監査の実施、セキュリティグループや新規メンバー向けのデフォルトのセキュリティグループの設定、各メンバーに承認されたセキュリティレベルの管理ができます。

セキュリティの出発点は認証です。PlaidCloud は、ほとんどのユースケースに対応できるよう、複数の認証オプションを提供しています。

* パスワードのみ
* 二要素認証
* シングルサインオン
