プロジェクトボードは、課題とプルリクエストをワークフローの各段階を表す列に配置し、何が進行中で、何が停止していて、何が完了したかをチーム全体で共有できるようにします。

## ボードの作成

1. リポジトリを開き、**プロジェクト**タブを選択します。
2. **新規プロジェクト**を選択します。
3. ボードの名前を入力します。
4. 開始用のテンプレートを選択します。基本的な **To Do / In Progress / Done** のレイアウトがデフォルトとして適しています。または、空のボードを選択して、レイアウトを一から構築します。
5. **Create Project** を選択して、ボードを開きます。

<Aside>リポジトリの**プロジェクト**タブから作成したボードは、そのリポジトリに属します。ワークスペース内の複数のリポジトリにまたがるボードは、管理者が組織レベルのプロジェクトエリアから作成します。</Aside>

## 列の設定

1. 列を追加するには、**列を追加**を選択し、ラベルを入力して保存します。
2. 列の名前を変更するには、その列の設定を開き、**編集**を選択します。
3. 列のヘッダーを左右にドラッグして、並べ替えます。
4. 列の設定から、いずれか1つの列をデフォルトとして指定します。特定の移動先を指定せずに追加されたカードは、その列に配置されます。

## カードの追加と移動

- 既存の課題またはプルリクエストを追加するには、列のメニューを開いて **Add an item** を選択し、タイトルまたは番号で検索します。
- ボード上で直接新しい課題を作成するには、列内の **+** を選択します。課題はリポジトリに保存され、すぐにカードとして表示されます。
- 作業の進行に合わせて、カードを別の列にドラッグします。カードの位置は現在のステータスを反映します。それだけで課題のラベルや担当者が変更されることはありません。

## 作業の追跡

ボードを使用すると、個々の課題を開かなくても、チームの作業量をひと目で把握できます。次の方法で、ボードを最新の状態に保ちます。

- 課題をクローズするか、プルリクエストをマージします。ボードの自動化設定に応じて、カードは完了の列に移動するか、ボードから削除されます。
- 期限付きの目標をかんばんビューと併用したい場合は、ボードを**マイルストーン**と組み合わせます。マイルストーンは期限と完了率を追跡し、ボードは作業の流れを追跡します。
