PlaidCloud Gitでは、ワークスペースのメンバーシップによってアクセスできるすべてのリポジトリを横断して、コード、ファイル、課題、プルリクエストを検索できます。

## コードの検索

1. 任意のページの上部にある検索ボックスを選択し、検索語を入力します。
2. **Enter** キーを押すと、アクセスできるすべてのリポジトリにわたる結果が表示されます。
3. 結果を選択すると、一致した行のファイルに直接移動します。
4. 結果ページの**リポジトリ**フィルターと**言語**フィルターで、結果を絞り込みます。

<Aside>コード検索では、デフォルトブランチがインデックス化されます。別のブランチを検索するには、そのブランチを参照し、以下で説明するリポジトリ内検索を使用します。</Aside>

## リポジトリ内の検索

1. リポジトリを開き、**コード**タブを選択します。
2. **T** キーを押す（またはファイル検索ボックスを選択する）と、ファイル検索が開きます。
3. ファイル名またはパスの一部を入力します。入力に合わせてリストが絞り込まれます。
4. ファイルを選択して開き、ブラウザーのページ内検索（**⌘F** / **Ctrl+F**）で特定の行を探します。

<Aside type="tip">ファイル検索はパスの各セグメントに一致するため、`util/auth` と入力すると、`src/util/auth.py` や `lib/util/auth_helper.go` などのパスが見つかります。</Aside>

## 課題とプルリクエストの絞り込み

**Issues** または **Pull Requests** のリストでは、キーワード検索と `key:value` 形式のフィルターを組み合わせて使用できます。

| フィルター | 例 |
|---|---|
| オープンまたはクローズの状態 | `is:open`、`is:closed` |
| ラベル | `label:bug`、`label:"needs review"` |
| 担当者 | `assignee:you` |
| 作成者 | `author:you` |
| マイルストーン | `milestone:"v1.2"` |

フィルターは検索ボックスに直接入力し、自由に組み合わせられます。**並べ替え**メニューでは、**最近更新**、**コメントが多い**、**最も新しい**、**最も古い**の順に並べ替えられます。

<Aside>ラベル名にスペースが含まれる場合は、引用符で囲みます：`label:"needs review"`。</Aside>

## 目的のものをより速く見つけるためのヒント

- **完全一致のフレーズ** — 複数語の用語は引用符で囲む（`"connection pool"`）と、不要な部分一致を避けられます。
- **リポジトリに絞り込む** — 検索の前にリポジトリを開いておくと、結果が絞り込まれます。
- **わかりやすい名前が役立つ** — 明確で具体的な名前を持つリポジトリや課題は、`misc` のような一般的な名前よりも、はるかに確実に検索結果に表示されます。
- **ラベルは検索可能なメタデータ** — 適切にラベル付けされた課題は、文章の中に埋もれた課題よりも絞り込みやすいため、ラベルは一貫して適用してください。
