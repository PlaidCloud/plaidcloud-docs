PlaidCloud Gitには、配布可能なアーティファクト用の組み込みパッケージレジストリと、リポジトリ内の大きなバイナリファイル用のGit Large File Storage（LFS）が含まれています。

## パッケージレジストリについて

パッケージレジストリは所有者ごとに用意され、npm、PyPI、Maven、NuGet、RubyGems、コンテナーイメージなど、幅広いエコシステムの形式をサポートしています。パッケージはワークスペース内でプライベートに保たれ、認証されたメンバーのみがアクセスできます。

パッケージの種類ごとに、次の配下に専用のエンドポイントがあります。

```
https://git.example.plaidcloud.com/api/packages/you/<type>
```

`<type>` は、エコシステムの識別子です（たとえば、`npm`、`pypi`、`maven`）。

## レジストリへの認証

パッケージマネージャーの操作では、PlaidCloud Gitのユーザー名と、パスワードとして個人用アクセストークンを使用します。トークンの作成方法については、[リポジトリ](/ja/guides/git/repositories/)を参照してください。

## パッケージの公開

手順はエコシステムによって異なりますが、パターンは同じです。パッケージマネージャーがレジストリのURLを参照するように設定し、標準の公開コマンドを実行します。

npmの場合は、プロジェクトに `.npmrc` を追加して、パッケージのスコープをレジストリに設定します。

```ini
@you:registry=https://git.example.plaidcloud.com/api/packages/you/npm/
//git.example.plaidcloud.com/api/packages/you/npm/:_authToken=YOUR_TOKEN
```

その後は、通常どおり公開します。

```bash
npm publish
```

PyPI、Maven、NuGetなどのエコシステムでは、ツールのリポジトリまたはソースの設定を対応するレジストリのURLに設定し、そのツールの標準の公開コマンド（たとえば、`twine upload`、`mvn deploy`、`dotnet nuget push`）を使用します。

## パッケージのインストール

パッケージマネージャーが同じレジストリのURLを参照するように設定し、通常どおりインストールします。上記の `.npmrc` を設定した状態では、次のようにします。

```bash
npm install @you/my-package
```

ほかのエコシステムでは、ツールの設定にレジストリを追加のソースとして追加し、標準のインストールコマンドを使用します。

## Git LFSによる大きなファイル

Git LFSは、履歴内にある大きなファイルやバイナリファイルを軽量なポインターに置き換え、ファイルデータを別に保存することで、リポジトリの動作を高速に保ちます。LFSは、すべてのPlaidCloud Gitリポジトリで有効になっています。

1. お使いのマシンに、LFSクライアントを一度だけインストールします。

   ```bash
   git lfs install
   ```

2. リポジトリ内で、追跡するファイルパターンをLFSに指定します。

   ```bash
   git lfs track "*.parquet"
   ```

   これにより `.gitattributes` が作成または更新されます。このファイルをコミットします。

   ```bash
   git add .gitattributes
   git commit -m "Track Parquet files with LFS"
   ```

3. 通常どおり追加してプッシュします。一致するファイルは自動的にLFSにアップロードされます。

   ```bash
   git add data/large-dataset.parquet
   git commit -m "Add dataset"
   git push origin main
   ```

<Aside type="tip">Git LFSは、リポジトリの履歴内に存在し、`git clone` または `git pull` で取得される大きなファイルに使用します。パッケージレジストリは、利用者がパッケージマネージャーでインストールする、バージョン管理された配布可能なアーティファクトに使用します。チームメンバーが `npm install` や `pip install` で入手するものにはレジストリを、チェックアウトの一部として必要なものにはLFSを使用してください。</Aside>
