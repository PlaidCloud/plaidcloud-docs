リポジトリには、1つのプロジェクトのファイル、ブランチ、履歴が保存されます。このガイドでは、リポジトリを作成し、コンピューターから接続する手順を説明します。

## リポジトリを作成する

1. ワークスペースから**Git**を開きます。
2. 右上の **+** メニューを選択し、**New Repository**を選択します。
3. 名前を入力します。必要に応じて短い説明も入力します。
4. 公開範囲を選択します。新しいリポジトリはデフォルトで**プライベート**です。アクセスを許可したメンバーだけが表示できます。
5. 必要に応じて**Initialize Repository**を選択し、READMEと`.gitignore`、ライセンスを追加します。
6. **Create Repository**を選択します。

コントリビューターは、ワークスペースのGit組織内に直接リポジトリを作成できません。リポジトリはPlaidCloud経由で作成します。

## 個人用アクセストークンを生成する

PlaidCloud経由でサインインするため、アカウントには別途Gitパスワードがありません。コマンドラインからHTTPSでクローンまたはプッシュするには、個人用アクセストークンを作成し、パスワードの代わりに使用します。

1. 右上のアバターを選択し、**設定**を選択します。**Git**タブのセットアップカードからもこのページに直接移動できます。
2. **アプリケーション**タブを開きます。
3. **アクセストークンの管理**で、トークンの使用場所がわかる名前（例: `laptop`）を入力します。
4. トークンでクローンとプッシュができるように、**write:repository**権限を選択します。
5. **Generate Token**を選択します。
6. トークンをコピーして、安全な場所に保管します。後から再表示することはできません。

<Aside type="caution">トークンはパスワードと同様に扱ってください。トークンを持つ人は誰でも、Gitであなたとして操作できます。マシンごとに別のトークンを生成すると、他のトークンに影響を与えずに1つだけ無効化できます。</Aside>

## リポジトリをクローンする

1. ワークスペースで**Git**を開き、リポジトリのクローン用アドレスの横にあるコピーボタンを選択します（セットアップ手順を確認するには**How to clone**を選択します）。リポジトリ内で**コード**を選択し、**HTTPS**のURLをコピーすることもできます。
2. ターミナルで、そのURLを指定して`git clone`を実行します。

   ```bash
   git clone <clone URL>
   ```

3. Gitからパスワードを求められたら、**アクセストークン**を貼り付けます。ユーザー名には、URLにすでに含まれているものを使用します。
4. セットアップカードに表示された値を使って、Gitがコミットに記録する名前とメールアドレスを設定します。

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

プッシュするにはコントリビューターまたは管理者のアクセス権が必要です。閲覧者は読み取りのみ可能で、プッシュはできません。[アクセスレベル](/ja/guides/git/#アクセスレベル)を参照してください。

<Aside>プッシュのたびにトークンを再入力しなくて済むように、オペレーティングシステムのGit認証情報ヘルパーに保存させることができます。たとえばmacOSでは`git config --global credential.helper osxkeychain`を使用します。</Aside>

## 変更をコミットしてプッシュする

クローンしたリポジトリ内で次の手順を行います。

1. 変更をステージします: `git add .`
2. メッセージを付けて記録します: `git commit -m "Describe what changed"`
3. PlaidCloud Gitに送信します: `git push`

コミットは、リポジトリの**Commits**ビューと**アクティビティ**ビュー、およびそれを含むすべてのブランチやプルリクエストに表示されます。

## アクセスと公開範囲を管理する

リポジトリの**設定**タブを開くと、名前の変更、公開範囲の変更、所有権の移譲ができます。他のメンバーが貢献できるようにするには、**設定 → Collaborators**を使用して、ユーザー名で追加し、**読み取り**、**書き込み**、**管理者**のいずれかのロールを割り当てます。

<Aside>リポジトリへのアクセスは、ワークスペースのメンバーシップとセキュリティグループにも従います。それらがリポジトリを表示、編集できるユーザーにどう対応するかは、[アクセス管理](/ja/administration/access/)を参照してください。</Aside>
