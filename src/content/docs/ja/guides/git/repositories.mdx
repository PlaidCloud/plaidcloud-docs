リポジトリには、1つのプロジェクトのファイル、ブランチ、履歴が格納されます。このガイドでは、リポジトリの作成と、お使いのコンピューターからの接続方法を説明します。

## リポジトリの作成

1. ワークスペースから **Git** を開きます。
2. 右上隅の **+** メニューを選択し、**New Repository** を選択します。
3. 名前と、必要に応じて短い説明を入力します。
4. 公開範囲を選択します。新しいリポジトリはデフォルトで**プライベート**になり、アクセスを許可したメンバーのみが閲覧できます。
5. 必要に応じて **Initialize Repository** を選択し、README、`.gitignore`、ライセンスを追加します。
6. **Create Repository** を選択します。

## 個人用アクセストークンの生成

PlaidCloud経由でサインインするため、アカウントには別途Gitのパスワードがありません。コマンドラインからHTTPS経由でクローンまたはプッシュするには、個人用アクセストークンを作成し、パスワードの代わりに使用します。

1. 右上隅のアバターを選択し、**設定**を選択します。
2. **アプリケーション**タブを開きます。
3. **Manage Access Tokens** で、トークンを使用する場所を示す名前（たとえば `laptop`）を入力します。
4. トークンでクローンとプッシュができるように、リポジトリの**読み取り**と**書き込み**のスコープを選択します。
5. **Generate Token** を選択します。
6. トークンをコピーして、安全な場所に保管します。トークンは再表示できません。

<Aside type="caution">トークンはパスワードと同じように扱ってください。トークンを持っている人は誰でも、Gitであなたとして操作できます。ほかのトークンに影響を与えずに1つだけ無効化できるよう、マシンごとに別々のトークンを生成してください。</Aside>

## リポジトリのクローン

1. PlaidCloud Gitでリポジトリを開きます。
2. **コード**を選択し、**HTTPS**のクローンURLをコピーします。
3. ターミナルで、そのURLを指定して `git clone` を実行します。

   ```bash
   git clone https://git.example.plaidcloud.com/you/my-repo.git
   ```

4. Gitが認証情報の入力を求めたら、**PlaidCloudのユーザー名**を入力し、パスワードとして**アクセストークン**を貼り付けます。

<Aside>プッシュのたびにトークンを入力し直さなくて済むように、OSのGit認証情報ヘルパーに保存させることができます。最初のプッシュの前に `git config --global credential.helper store` を実行します（macOSの場合は `osxkeychain`）。</Aside>

## 変更のコミットとプッシュ

クローンしたリポジトリの中で、次の手順を実行します。

1. 変更をステージします：`git add .`
2. メッセージを付けて記録します：`git commit -m "Describe what changed"`
3. PlaidCloud Gitに送信します：`git push`

コミットは、リポジトリの **Commits** ビューと**アクティビティ**ビュー、およびそのコミットを含むすべてのブランチやプルリクエストに表示されます。

## アクセスと公開範囲の管理

リポジトリの**設定**タブを開くと、名前の変更、公開範囲の変更、所有権の移譲ができます。ほかのメンバーが貢献できるようにするには、**設定 → Collaborators** で、ユーザー名を指定してメンバーを追加し、**読み取り**、**書き込み**、**Administrator** のいずれかのロールを割り当てます。

<Aside>リポジトリへのアクセスは、ワークスペースのメンバーシップやセキュリティグループにも従います。これらがリポジトリを閲覧および編集できるユーザーにどのように対応するかについては、[アクセス管理](/ja/administration/access/)を参照してください。</Aside>
