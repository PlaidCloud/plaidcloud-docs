PlaidCloud Gitは、ワークスペースに組み込まれたプライベートなGitサービスです。各ワークスペースに専用のGitサーバーが用意され、コード、構成、ノートブック、その他のバージョン管理対象ファイルを保存できます。さらに、チームが共同作業に使用する課題、プルリクエスト、プロジェクトボードも利用できます。

PlaidCloudアカウントでサインインするため、ユーザー名やパスワードを別途設定する必要はありません。ワークスペースから **Git** を開くと、すでにサインインした状態になります。新しいリポジトリはデフォルトでプライベートになり、アクセスを許可したメンバーのみが閲覧できます。

## Gitの管理

リポジトリはどのメンバーでも作成できますが、リポジトリとチームをまとめる共有スペースである**組織の作成**には、**Git管理**権限が必要です。この権限は、**ID**でセキュリティグループに権限を追加するか、組み込みの **Git管理**グループにメンバーを追加することで付与します。この権限を持つグループに属するメンバーは、次回Gitにサインインした時点でGit管理者になります。PlaidCloudのサポートスタッフには、この権限が自動的に付与されています。

新しく管理者権限を付与されたメンバーがGitを一度も開いたことがない場合、管理者アクセスを有効にするために、Gitに**2回**サインインする必要があることがあります。最初のサインインでGitアカウントが作成され、権限は次回のサインインで適用されます。

- [コードの検索](/ja/guides/git/searching-code/) — リポジトリ全体でコード、課題、プルリクエストを検索します
