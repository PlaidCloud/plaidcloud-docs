PlaidCloud Gitは、ワークスペースに組み込まれたプライベートなGitサービスです。ワークスペースごとに専用のGitサーバーが用意され、コード、構成、ノートブック、その他のバージョン管理対象ファイルを保存できます。これらをチームで共同作業するための課題、プルリクエスト、プロジェクトボードも利用できます。

PlaidCloudアカウントでサインインするため、ユーザー名やパスワードを別途設定する必要はありません。新しいリポジトリはデフォルトでプライベートになり、アクセス権を付与したメンバーだけが閲覧できます。

## Gitを開く

ワークスペースのアプリ一覧で **Git** を選択します。**Git** タブには、ワークスペースのリポジトリが、名前、説明、デフォルトブランチ、最終更新日時とともに表示され、上部の1行にできることが示されます。リポジトリを選択すると開き、**View all in Git** を選択するとGit Webインターフェースに移動します。PlaidCloudに戻るには、Git内の **← Back to** ワークスペースを使用します。

リポジトリをクローンするには、その行の **Copy clone URL** を選択します。初回はヒントが表示され、必要なものが示されます。

1. コンピューターにGitがインストールされている必要があります。
2. Gitの **Settings → Applications** で、**write:repository** 権限を持つアクセストークンを作成します。ヒントからそのページへ移動できます。
3. Gitがパスワードを求めたら、PlaidCloudのパスワードではなく、トークンを貼り付けます。
4. 表示される2つのコマンド `git config --global user.name` と `user.email` を実行します。これらにはすでにお客様の名前とメールアドレスが入っています。

詳しい手順は[リポジトリ](/ja/guides/git/repositories/)を参照してください。クローンURLをコピーできない場合は、読み取りアクセスのみをお持ちです。詳細は次のセクションを参照してください。

## アクセスレベル

Gitにアクセスできるユーザーは全員、ワークスペースの共有リポジトリを読み取れます。さらに、プッシュできる2つのレベルがあります。

| レベル | できること | 付与元 |
|---|---|---|
| **読み取り** | 共有リポジトリの閲覧とクローン。 | すべてのメンバーのデフォルト。 |
| **Contributor** | 読み取りのすべてに加え、[Panel](/ja/guides/panel-apps/deploy-from-git/)アプリと[Dash](/ja/guides/dash-apps/deploy-from-git/)アプリのコードを置く `apps` リポジトリへのプッシュ。 | **Git Contributors** セキュリティグループ。 |
| **管理者** | Contributorのすべてに加え、`udfs` を含むすべてのリポジトリへのプッシュと、組織の作成。 | **Git Administration** セキュリティグループ。 |

`udfs` リポジトリが管理者に限定されているのは、ユーザー定義関数が、それを呼び出すワークフローのIDで実行されるためです。

読み取りアクセスのみの場合、**Git** タブに、**Git Contributors** への追加を依頼できるワークスペース管理者が最大3人表示されます。

## アプリとUDFからのGit

PanelアプリまたはDashアプリのウィンドウには **リポジトリ** セクションがあり、そのリポジトリ、ブランチ、ビルドステータスが表示されます。プッシュできるメンバーには **Edit in browser** と **Copy clone URL** も表示されます。Gitを使用するUDFのツールバーには **Open** があり、リポジトリをそのブランチでGitで開きます。管理者には **Edit in browser** も表示されます。

## Gitアクセスを付与する

ワークスペースの管理者は、**ID** でメンバーをセキュリティグループに追加するか、独自のグループに権限を追加することで、アクセスを付与します。

1. アプリコードのプッシュを許可するにはメンバーを **Git Contributors** に追加し、Git管理者にするには **Git Administration** に追加します。
2. 新しいメンバー全員にアプリコードへのプッシュ権限を付与するには、**Git Contributors** をデフォルトグループに追加します。**Git Administration** をデフォルトグループにすることはできません。
3. メンバーができることを確認するには、そのメンバーを開いて **Git** タブを選択します。メンバーのGitユーザー名、レベル、そのレベルを付与しているグループが表示されます。

変更は、メンバーが次にGitにサインインしたとき、または **Git** タブを開いたときに反映されます。PlaidCloudのサポートスタッフには、自動的に管理者アクセスが付与されます。
