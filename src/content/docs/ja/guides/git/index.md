PlaidCloud Gitは、ワークスペースに組み込まれたプライベートなGitサービスです。各ワークスペースには専用のGitサーバーがあり、コード、設定、ノートブック、その他のバージョン管理対象ファイルを保存できます。それらをもとにチームが共同作業するための課題、プルリクエスト、プロジェクトボードも利用できます。

PlaidCloudアカウントでサインインするため、別のユーザー名やパスワードを設定する必要はありません。新しいリポジトリはデフォルトでプライベートで、アクセスを許可したメンバーだけが表示できます。

## Gitを開く

ワークスペースのアプリ一覧で **Git** を選択します。**Git** タブが開き、ワークスペースのホスト、お客様のロール、**リポジトリ** の一覧が表示されます。**View all in Git** でGitのWebインターフェースに移動し、**Manage who can push**（グループを管理できる場合）でグループ管理を開き、更新ボタンで再読み込みします。PlaidCloudに戻るには、**← Back to** お使いのワークスペース（Git内）を使用します。

ロール表示にはお客様のレベルとして **管理者**、**コントリビューター**、**閲覧者** のいずれかが表示され、そのレベルでできることが1行で説明されます。各リポジトリの行には、名前、説明（ある場合）、日付付きの **更新**、コピーボタン付きの読み取り専用クローンフィールド、リポジトリをGitで開く **開く** が表示されます。プライベートに作成したリポジトリはこの一覧ではなく、Git内に直接表示されます。

## リポジトリをクローンする

リポジトリの行からクローンアドレスをコピーします。初めてコピーすると、次の手順を示す **Set up Git on your computer** カードが表示されます。**閉じる** を選択すると非表示になり、ヘッダーの **How to clone** で再表示できます。

1. お使いのコンピューターにGitがインストールされている必要があります。
2. **設定 → アプリケーション** で、**write:repository** 権限を持つトークンを作成します。カードにそのページへのリンクがあります。
3. 表示される2つのコマンド `git config --global user.name` と `user.email` で、Gitに自分が誰であるかを伝えます。これらには、お客様の名前とメールアドレスがあらかじめ入力されています。
4. 表示される `git clone` コマンドでリポジトリをクローンします。Gitがパスワードを求めたら、PlaidCloudのパスワードではなく、そのトークンを貼り付けます。

各コマンドには専用のコピーボタンがあります。詳しい手順は [リポジトリ](/ja/guides/git/repositories/) を参照してください。コピーにはプッシュ権限と有効化されたGitアカウントが必要です。コピーボタンが無効な場合は、いずれかのリポジトリを一度開いてアカウントを有効化するか、**閲覧者** の場合は後述のとおりプッシュ権限を依頼してください。

## アクセスレベル

Gitにアクセスできるすべてのユーザーは、ワークスペースの共有リポジトリを読み取れます。プッシュできるレベルはさらに2つあります。

| ロール | できること | 付与元 |
|---|---|---|
| **閲覧者** | 共有リポジトリの表示とクローン。 | すべてのメンバーのデフォルト。 |
| **コントリビューター** | 読み取りのすべてに加え、[Panel](/ja/guides/panel-apps/deploy-from-git/) と [Dash](/ja/guides/dash-apps/deploy-from-git/) のアプリコードを置く `apps` リポジトリへのプッシュ。 | **Git Contributors** セキュリティグループ。 |
| **管理者** | コントリビューターのすべてに加え、`udfs` を含むすべてのリポジトリへのプッシュと、組織の作成。 | **Git Administration** セキュリティグループ。 |

ユーザー定義関数は、それを呼び出すワークフローのIDで実行されるため、`udfs` リポジトリは管理者に限定されています。

**閲覧者** の場合、**Git** タブに、**Git Contributors** への追加を依頼できるワークスペース管理者が最大3人表示されます。

## アプリとUDFからのGit

PanelアプリまたはDashアプリのウィンドウには、リポジトリ、ブランチ、ビルドステータスを示す **リポジトリ** セクションがあり、プッシュできるメンバーには **Edit in browser** と **Copy clone URL** が表示されます。GitベースのUDFのツールバーには、リポジトリを該当ブランチでGitに開く **開く** があり、管理者には **Edit in browser** も表示されます。

## Gitアクセスの付与

ワークスペース管理者は、**ID** でメンバーをセキュリティグループに追加するか、独自のグループに権限を追加することでアクセスを付与します。

1. アプリコードをプッシュできるようにするにはメンバーを **Git Contributors** に、Git管理者にするには **Git Administration** に追加します。
2. 新しいメンバー全員にアプリコードへのプッシュ権限を与えるには、**Git Contributors** をデフォルトグループに追加します。**Git Administration** はデフォルトグループにできません。
3. メンバーができることを確認するには、メンバーを開いて **Git** タブを選択します。メンバーのGitユーザー名、レベル、そのレベルを付与しているグループが表示されます。

変更は、メンバーが次にGitにサインインするか **Git** タブを開いたときに反映されます。メンバーを無効化または削除すると、トークンとSSHキーを含め、そのメンバーのGitアカウントがブロックされます。再有効化すると、ブロックは解除されます。PlaidCloudのサポートスタッフには、自動的に管理者アクセス権があります。
