PlaidCloudの配賦を始めましょう。配賦とは何か、一般的なユースケース（IT部門の費用付け替え、移転価格、活動基準原価計算、収益性分析）、そして最初の配賦を作成するまでのステップバイステップのチュートリアルを紹介します。
