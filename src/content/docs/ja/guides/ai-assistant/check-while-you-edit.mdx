## 説明

ステップで**保存**を押すと、PlaidCloudはその設定をチェックし、実行できない設定を拒否します。たとえば、コンパイルできない式や、タイプで許可されていない使い方をされている列などです。ステップを編集している間、Weaveはこれらのチェックのほとんどを随時実行し、**保存**ボタンのすぐ上のストリップに、保存で拒否される内容を表示します。

> 保存で拒否される問題が1件あります。

各問題は、この行の下に一覧表示されます。**列**タブの行が示されている場合、**移動**をクリックすると、そのタブが開いて該当の行が選択されます。

チェックはステップの設定とプロジェクトの変数だけを読み取るため、すばやく完了し、AIは使用されません。チェックが保存をブロックすることはありません。保存は常に利用でき、保存を押すと、保存自体がすべてのチェックを実行します。

<Aside type="note">
保存では、このストリップがチェックしないこともチェックします。たとえば、ソーステーブルとターゲットテーブルにステップが使用する列があるかどうかや、必須フィールドが入力されているかどうかです。そのため、「問題は見つかりませんでした」は、編集中に実行されるチェックで問題が見つからなかったという意味であり、保存がそのステップを受け入れるという意味ではありません。
</Aside>

## ストリップの表示内容

| Weaveの表示 | 意味 |
| --- | --- |
| このステップに問題がないか確認しています… | Weaveが最新の変更に対してチェックを実行しています。 |
| 保存で拒否される問題が1件あります。 | 現在のままでは、保存はこのステップを拒否します。各問題はその下に一覧表示されます。 |
| 問題は見つかりませんでした。保存では、ソーステーブルやターゲットテーブルなど、さらにいくつかの項目をチェックします。 | 編集中に実行されるチェックでは、何も見つかりませんでした。保存は、このストリップが省略するチェックも含め、独自のチェックを引き続き実行します。 |
| Weaveはこのステップの式をチェックできませんでした。… | ステップの一部をチェックできませんでした。理由が続きます。これは合格ではありません。 |
| Weaveは今、このステップをチェックできませんでした。保存時にチェックされます。 | チェックが実行されませんでした。たとえば、サーバーがビジー状態だった場合などです。次の変更時に再度チェックされます。 |

### 式をチェックできなかった理由

| 理由 | 意味 |
| --- | --- |
| このステップはワークフローに含まれていないため、式をチェックできません。保存でもチェックされません。 | 式ではワークフロー変数を使用できるため、式はステップが属するワークフロー内でチェックされます。ワークフローの外で開いたステップは、ここでも保存時にもチェックされません。 |
| 一部の式は、Weaveがまだチェックできない設定に含まれています。 | ステップは一部の式を、これらのチェックが読み取らない設定（2つ目のソースのフィルターなど）に保持しています。ほかの式は引き続きチェックされます。 |
| 列の設定が、Weaveがまだチェックできない形式です。 | ステップは、複数テーブル結合のように、チェックがコンパイルできない形式で列を一覧にしています。 |

ワークフローにもプロジェクトにも定義されていない変数を使用する式は、理由ではなく問題です。「式で変数rateが使用されていますが、このワークフローまたはプロジェクトで定義されていません。」変数名の始まりでも終わりでもない中かっこも同様で、入力途中の変数がこれに当たります。「式に、変数名の一部ではない中かっこがあります。」保存は、どちらも同じ文言で拒否します。

## 式エディターで

**列**タブの**式**セル、または**フィルター**タブの**データのサブセットを選択**や**結果データに二次フィルターを適用**から**式エディター**を開くと、エディターの下の行が、入力しながら式をチェックします。

| エディターの表示 | 意味 |
| --- | --- |
| チェック中… | Weaveが、入力したばかりの内容をチェックしています。 |
| エラーは見つかりませんでした。 | 式は、保存がコンパイルするのと同じ方法でコンパイルされます。この行にカーソルを合わせると、チェックされない内容を確認できます。Weaveがチェックするのは構文と列名で、一部のエラーはステップの実行時にしか表示されません。 |
| エラー: … | 保存は、示された理由でこの式を拒否します。構文エラーは、その行の行番号の横にもマークされます。 |
| チェックできませんでした。… | 上記のいずれかの理由で、式をチェックできませんでした。 |
| 今はチェックできませんでした。ステップを保存するときにチェックされます。 | チェックが実行されませんでした。ステップで**保存**を押すと、引き続き式がチェックされます。 |

エディターは、Weaveが最後にステップをチェックした時点のステップの設定に対して、入力中の式を当てはめてチェックします。テーブルエクスプローラーなど、ほかの場所から開いた場合は、行は表示されません。

## 表示されるタイミング

- 変更できるステップを編集している間。ご自身のロールで読み取り専用として開くステップは、編集中にチェックされません。
- 変更のたびに、操作が止まってから。設定が変わらなかった変更は、再度チェックされません。
- ステップの設定とプロジェクトの変数を読み取るため、AIの呼び出しが発生することはなく、ウェアハウスにクエリが発行されることもありません。
