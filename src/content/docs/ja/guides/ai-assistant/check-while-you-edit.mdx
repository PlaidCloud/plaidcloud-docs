## 説明

ステップで**保存**を押すと、PlaidCloudはその設定をチェックし、実行できない設定を拒否します。たとえば、コンパイルできない式や、型の制約により使えない方法で使われている列です。ステップの編集中、Weaveはこれらのチェックの大半を随時実行し、**保存**ボタンのすぐ上のストリップに、保存が拒否する内容を表示します。

> 保存が拒否する問題が1件あります。

各問題はこの行の下に一覧表示されます。問題が**テーブルデータの選択**タブの行を指している場合は、**移動**をクリックするとそのタブが開き、該当の行が選択されます。

チェックが読み取るのはステップの設定とプロジェクトの変数だけなので、すばやく完了し、AIは関与しません。チェックが保存を妨げることはありません。保存は常に実行でき、保存を押したときには保存自身がすべてのチェックを実行します。

<Aside type="note">
保存では、このストリップがチェックしない項目もチェックします。たとえば、ソーステーブルとターゲットテーブルにステップが使う列があるかどうか、必須フィールドが入力されているかどうかです。したがって「問題は見つかりませんでした」は、編集中に実行されるチェックでは問題が見つからなかったという意味であり、保存がそのステップを受け付けるという意味ではありません。
</Aside>

## ストリップの表示内容

| Weaveの表示 | 意味 |
| --- | --- |
| このステップに問題がないか確認しています… | Weaveが最新の変更に対してチェックを実行しています。 |
| 保存が拒否する問題が1件あります。 | 現在のままでは、保存がこのステップを拒否します。各問題はその下に一覧表示されます。 |
| 問題は見つかりませんでした。保存では、ソーステーブルとターゲットテーブルなど、さらにいくつかの項目をチェックします。 | 編集中に実行されるチェックでは何も見つかりませんでした。保存は、このストリップが省略する項目を含め、独自のチェックを引き続き実行します。 |
| Weaveはこのステップの式をチェックできませんでした。… | ステップの一部をチェックできませんでした。理由は続けて表示されます。これは合格ではありません。 |
| Weaveは今回このステップをチェックできませんでした。保存時には引き続きチェックされます。 | チェックが実行されませんでした。たとえば、サーバーがビジー状態だった場合です。次の変更時に再度チェックされます。 |

### 式をチェックできなかった理由

| 理由 | 意味 |
| --- | --- |
| このステップはワークフローにないため、式をチェックできません。保存でもチェックされません。 | 式ではワークフロー変数を使えるため、式はステップのワークフロー内でチェックされます。ワークフローの外で開いたステップは、ここでも保存でもチェックされません。 |
| 一部の式は、Weaveがまだチェックできない設定にあります。 | ステップの一部の式が、これらのチェックが読み取らない設定（2つ目のソースのフィルターなど）に保持されています。それ以外の式は引き続きチェックされます。 |
| 列の設定は、Weaveがまだチェックできない形式です。 | 複数テーブル結合のように、ステップの列の指定方法がチェックでコンパイルできない形式になっています。 |

ワークフローにもプロジェクトにも定義されていない変数を使う式は、理由ではなく問題として扱われます。「式で変数rateが使われていますが、このワークフローにもプロジェクトにも定義されていません。」がその例です。入力途中の変数のように、どの変数名の始まりでも終わりでもない波括弧がある場合も同様に問題となり、「式に、変数名の一部ではない波括弧があります。」と表示されます。保存でも、どちらも同じ文言で拒否されます。

## 式エディターでの表示

**テーブルデータの選択**タブの**式**セル、または**データフィルター**タブの**データのサブセットを選択**や**結果データに二次フィルターを適用**から**式エディター**を開くと、エディターの下の行が、入力中の式をチェックします。

| エディターの表示 | 意味 |
| --- | --- |
| チェックしています… | Weaveが入力したばかりの内容をチェックしています。 |
| エラーは見つかりませんでした。 | 式は、保存がコンパイルするのと同じ方法でコンパイルできます。行をポイントすると、このチェックに含まれない内容が表示されます。Weaveがチェックするのは構文と列名であり、一部のエラーはステップの実行時にしか表示されません。 |
| エラー: … | 示された理由により、保存はこの式を拒否します。構文エラーは、行番号の横にある該当行にもマークされます。 |
| チェックできませんでした。… | 上記のいずれかの理由により、式をチェックできませんでした。 |
| 今回はチェックできませんでした。ステップの保存時には引き続きチェックされます。 | チェックが実行されませんでした。ステップで**保存**を押すと、式は引き続きチェックされます。 |

エディターは、Weaveが前回ステップをチェックした時点のステップ設定に、入力中の式を当てはめてチェックします。テーブルエクスプローラーなど、それ以外の場所から開いた場合は、行は表示されません。

## 表示されるタイミング

- 変更可能なステップを編集している間。お使いのロールで読み取り専用として開くステップは、編集中にチェックされません。
- 変更のたびに、入力が止まってから。設定が変わらない変更は、再度チェックされません。
- ステップの設定とプロジェクトの変数を読み取るため、AIの呼び出しは発生せず、ウェアハウスへのクエリも実行されません。
