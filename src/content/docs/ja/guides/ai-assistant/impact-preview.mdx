## 説明

保存済みのステップを開くと、**保存**ボタンの上に、このステップを変更した場合に影響が及ぶ範囲がWeaveによって表示されます。

> このステップへの変更は、2つのワークフローにある8個の下流ステップに影響します。

この文は、このステップが書き込むテーブルを読み取るステップ、それらが書き込む内容を読み取るステップ、というように、最大10ステップ先の下流までを数えたものです。プロジェクトの各ステップの保存済みの設定から読み取るため、結果は即座に表示されます。これらのテーブルをソースとして挙げているステップの正確な数であり、AIは関与しません。この表示は保存の判断材料を提供するためのもので、保存を制限するものではありません。保存はいつでも実行できます。

<Aside type="note">
この文が示すのは、最後に保存された状態のステップです。ステップが書き込むテーブルを変更する場合、保存するまでは、古いテーブルを読み取るステップが一覧に表示されます。それらは、このステップが書き込んだ内容を受け取らなくなるため、影響を受けます。
</Aside>

## 文の意味

| Weaveの表示 | 意味 |
| --- | --- |
| このステップへの変更は、2つのワークフローにある8個の下流ステップに影響します。 | このステップが書き込む内容を、直接または他のステップを経由して読み取るステップが8個あり、それらは合わせて2つのワークフローに存在します。2つのワークフローに存在するステップは、1つのステップとして数えられ、両方のワークフローに属します。 |
| このステップへの変更は、3個の下流ステップに影響します。1つのワークフローに2個、ワークフローなしが1個です。 | どのワークフローにも配置されていない下流のステップも数えられ、**Not in any workflow**の下に一覧表示されます。 |
| このステップへの変更は、3個の下流ステップに影響しますが、いずれもワークフローにありません。 | 影響を受けるステップがすべて未配置です。ステップが1個の場合は、「1個の下流ステップに影響しますが、どのワークフローにもありません。」と表示されます。 |
| このステップへの変更は、少なくとも2つのワークフローにある少なくとも8個の下流ステップに影響します。Weaveは10ステップ先の下流で探索を打ち切りました。 | 読み取り元のつながりが10ステップを超えています。数は合計ではなく下限値であり、文では配置別の内訳は示されません。 |
| … そのうち2個は開けません。 | 影響を受けるステップのうち2個は、お使いのロールからは非表示です。文が正しくなるように数には含まれますが、名前は表示されません。影響を受けるステップがすべて非表示の場合、文は「いずれも開けません。」で終わり、1個の場合は「開けません。」で終わります。 |
| このステップが書き込むテーブルをソースとして挙げている他のステップはありません。 | これらのテーブルのいずれかをソースとして指定しているステップはありません。SQLクエリや式を通じてテーブルに到達するステップは数えられず、**Weaveが把握する方法**にその旨が示されます。 |
| このステップはテーブルを書き込まないため、Weaveが追跡できる下流はありません。 | このステップは、ファイル、メール、ERP転記など、プロジェクトのテーブル以外のものを生成しており、Weaveはそれを誰が使用しているかを追跡できません。 |
| Weaveは、このステップへの変更が及ぼす影響をチェックできませんでした。 | プレビューを読み取れませんでした。つながりをたどるには、ステップ、ワークフロー、テーブルの読み取りアクセスが必要なため、いずれかが欠けているロールにはこの文が表示されます。保存は通常どおり実行できます。 |

## ステップを確認する

**ステップを表示**をクリックすると、影響を受けるステップがワークフローごとに一覧表示されます。開けるワークフローが名前順で先に表示され、開けないワークフローは1つのグループとしてその後に続き、ワークフローに属さないステップが最後に表示されます。ワークフロー内では、最も近い読み取り元のステップが先に表示されます。開けないステップは、名前ではなく一覧の末尾で件数として表示されます。複数のワークフローに存在するステップは、それぞれのワークフローの下に表示され、**Weaveが把握する方法**にもその旨が示されます。一覧が長い場合はスクロールできます。

## Weaveが把握する方法

文の下にある**Weaveが把握する方法**には、Weaveが行ったことと、対象外にしたことが示されます。

- **Weaveが行ったこと** — このステップが書き込む各テーブルから、それを読み取るステップ、さらにそれらが書き込む内容を読み取るステップへと、最大10ステップ先の下流までたどりました。
- **情報源** — このステップが書き込むテーブルと、プロジェクト内のすべてのステップの保存済みの設定です。お使いのロールから非表示のテーブルは開けないテーブルとして一覧表示され、ステップの設定で指定されているがまだ存在しないテーブルは、その名前で一覧表示されます。
- **Weaveが確認しなかったこと** — ソースとして挙げるのではなく、SQLクエリや式を通じてこれらのテーブルに到達するステップ。これらのテーブルを読み取るダッシュボード、ビュー、エクスポート、およびこのプロジェクト外のすべて。影響を受けるステップが失敗するのか、単に異なるデータで実行されるだけなのか。保存していないこのステップへの編集。

## 表示されるタイミング

- 保存済みのステップに対してのみ表示されます。新しいステップや、まだ保存していない複製には、数えるべき読み取り元がありません。
- **保存**の後、ステップを開いたままにしている間は更新されます。保存によって、ステップが書き込むテーブルが変わる場合があるためです。
- プロジェクトの保存済みの設定を読み取るため、AIの呼び出しは発生せず、AIプロバイダーが利用できない場合でも動作し続けます。
