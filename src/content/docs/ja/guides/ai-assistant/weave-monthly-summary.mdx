## 説明

月次サマリーは、プロジェクトで1か月間にWeaveが行ったことを集計します。ワークフローの実行完了時に見つかった問題、後のチェックで検出されなくなった問題、承認されたWeaveによる変更、想定内として記録された問題が対象です。すべての数値は、プロジェクトの[Weaveアクティビティ履歴](/ja/guides/ai-assistant/weave-activity/)にあるエントリの件数で、それぞれの数値の根拠となるエントリを開いて確認できます。

ワークスペースの管理者は、すべてのプロジェクトについて同じ集計を示すワークスペースサマリーも利用できます。

AIは使用しません。推定は行わず、報告する内容がない月は、その旨が表示されます。

## 月次サマリーを開く

1. プロジェクトを開き、**Weave**タブを選択して、その中の**検出事項**を選択します。
2. ツールバーの**サマリー**をクリックします。
3. 月を選択します。リストは、たとえば **October 2026 so far** のように表示される当月から始まり、その前の11か月が続きます。

ツールバーの**更新**でサマリーを再読み込みします。**サマリー**は、**アクティビティ**と同様に、プロジェクトのステップ、ワークフロー、テーブルを読み取れるロールを持つユーザーに表示されます。月はUTCの暦月です。

## 各数値の集計内容

各数値の横には、その数値が何を数えているかを説明する文が表示されます。サマリーに表示されるのは数値とその文だけです。下の表の最初の列の名称は、このページでの呼び名です。

| 数値 | 文 |
|---|---|
| 検出された問題 | *Weave found 7 problems when workflows finished running. Each counts once, however often it was found.* |
| 検出されなくなった | *A later check no longer found 5 problems this month, including any first found in an earlier month.* |
| Weaveの変更後に検出されなくなった | *Of those, 2 were no longer found after a change Weave made, with approval, to the step, table or workflow they were about (for a workflow, to any of its steps). This shows the order of events, not that the change fixed the problem. Median time from Weave finding the problem, or finding it again if it had gone away, to the check that no longer found it: 26 hours, across 2 problems.* |
| 実施した変更 | *Weave made 3 changes that someone approved. 1 of them has since been undone.* |
| 想定内として記録 | *1 problem was marked as expected. It isn't fixed: Weave stops reporting it as a problem.* |
| 今月の問題の現在の状況 | *Of the 7 problems found this month: 3 no longer found, 1 marked as expected, 3 still open.* |

**Weaveの変更後に検出されなくなった**は、その月に後のチェックで少なくとも1つの問題が検出されなくなった場合にのみ表示されます。**今月の問題の現在の状況**は、その月にWeaveが少なくとも1つの問題を見つけた場合にのみ表示されます。

数値の下にある **Show 3 Entries**（エントリが1件の場合は **Show Entry**）をクリックすると、その数値が集計したアクティビティ履歴のエントリが、それぞれが記録された日時とともに一覧表示されます。**エントリを非表示**をクリックすると閉じます。根拠となるエントリがない数値には、ボタンはありません。今月の問題の現在の状況では、エントリは**検出されなくなった**、**想定内として記録**、**未解決**の下にグループ化され、それぞれ件数が付きます。

### 数値の算出方法

- **検出された問題**は、その月にWeaveが発生させた各問題を1回だけ数え、最初に発生した時点を一覧表示します。Weaveは、問題を最初に見つけたときに発生させ、再び見つかった実行のたびには発生させないため、前の月から未解決のままの問題は数えられず、月内に消えて再発した問題は1回として数えられます。
- **検出されなくなった**は、その月中に後のチェックで検出されなくなった各問題を数え、前の月に最初に見つかった問題も含まれます。「検出されなくなった」は修正されたという意味ではありません。問題が表示されなくなるようデータが変わった可能性があります。[記録される内容](/ja/guides/ai-assistant/weave-activity/#記録される内容)を参照してください。
- **Weaveの変更後に検出されなくなった**は、**検出されなくなった**の問題のうち、Weaveがその問題を見つけてから、検出されなくなったチェックまでの間に、問題の対象だったステップまたはテーブル（ワークフローに関する問題の場合は、そのワークフローのいずれかのステップ）に対して、Weaveが承認済みの変更を行い、その変更がチェックの前に取り消されていないものを数えます。変更は別の理由で行われた可能性があり、ステップの再実行など、承認されたあらゆる操作が該当します。これは出来事の順序を示すだけです。中央値の時間は、Weaveが問題を見つけた時点（前の月であっても）から、検出されなくなったチェックまでです。以前に消えて再発した問題の場合は、Weaveが再び見つけた時点からです。
- **実施した変更**は、AIアシスタントで承認を得てWeaveが実行したすべての操作を数えます。ステップの修正、それに続く再実行、新しいワークフロー、テーブルのコピーなどで、既存の設定の編集だけではありません。変更の取り消しは、それ自体は変更として数えられません。文には、その月の変更のうち、現在までにいくつが取り消されたかが示されます。ご自身で行った変更や、MCP経由で接続されたAIアシスタントによる変更は記録されないため、数えられません。
- **想定内として記録**は、その月に誰かが想定内としてマークした各問題を数えます。[検出事項を想定内としてマークする](/ja/guides/ai-assistant/weave-tab/#検出事項を想定内としてマークする)を参照してください。
- **今月の問題の現在の状況**は、その月に見つかった問題（前の月に消えて再発したものを含む）を対象に、現在それぞれがどの状態にあるかを示します。検出されなくなった問題は、想定内としてもマークされていてもそこに数えられます。想定内としてマークされた後、想定内でなくなった問題は、未解決として数えられます。問題を終了できるのはプロジェクトのアーキテクトとして実行されたチェックだけなので、他のユーザーによる実行以降に修正された問題でも、未解決と表示されることがあります。[検出事項は実行終了時に記録される](/ja/guides/ai-assistant/weave-activity/#検出事項は実行の終了時に記録される)を参照してください。

### 集計されないもの

サマリーが集計するのは、アクティビティ履歴に記録されているもの、つまりワークフローの実行完了時に見つかった問題と、Weaveを通じて行われた変更だけです。レポートがデータを読み取る前に検出された問題、承諾したドラフトやデフォルト、節約できた時間は集計されません。テーブルがスケジュールどおりに書き込まれていないなど、実行の合間にのみWeaveが見つける問題は、履歴に記録されないため集計されず、Weaveがチェックしない実行も同様です。[履歴に記録されないもの](/ja/guides/ai-assistant/weave-activity/#履歴に記録されない内容)を参照してください。

<Aside type="caution">
Weaveが報告するのは、チェックで見つかったことだけです。問題が見つからなかった月でも、何も問題がないとは限りません。
</Aside>

### 報告する内容がない月

その月に集計するものがない場合、サマリーはゼロを表示する代わりに、その旨を表示します。たとえば *There's nothing to count for "Cost Model" in September 2026.* のようになります。取り消しのみ、または検出事項へのコメントは、集計されません。

## 表示内容はアクセス権によって異なる

ロールで開けないステップ、テーブル、ワークフローに関するエントリ、またはすでに存在しないものに関するエントリは、どの数値にも集計されず、除外されたエントリの数がメモで示されます。プロジェクト内で読み取れる行が行レベルセキュリティによって制限されている場合、サマリーは、テーブルのサイズや内容からWeaveが気づいたことも除外し、その旨を表示します。

## ワークスペースサマリー

ワークスペースの管理者は、すべてのプロジェクトの数値を1つのページで確認できます。

1. ヘッダーの**Weave**ボタンをクリックします。
2. メニューの末尾近くにある **ワークスペースサマリー…** を選択します。
3. プロジェクトのサマリーと同様に、月を選択します。

ウィンドウには、その月にアクティビティがあった各プロジェクトが、**検出された問題**、**検出されなくなった**、**Weaveの変更後に検出されなくなった**、**実施した変更**、**想定内として記録**とともに一覧表示され、合計を示す**すべてのプロジェクト**の行があります。表示されるのは件数のみです。プロジェクト名をクリックすると、同じ月のそのプロジェクト自身のサマリーが、各数値の根拠となるエントリとともに開きます。そのためにはプロジェクトへのアクセス権が必要です。その後に削除されたプロジェクトは *A project that no longer exists* として一覧表示され、何も開きません。

ワークスペースの集計には、各プロジェクトの履歴にあるすべてのエントリが含まれます。プロジェクト自身のサマリーでは、閲覧者が開けないものは除外されるため、ワークスペースサマリーより低い数値になることがあります。

**ワークスペースサマリー…** が表示されるのは、ワークスペースの管理者のみです。他のユーザーがAPIを通じてワークスペースサマリーを要求すると、*Only workspace administrators can see the workspace summary. Each project's own summary is on its Weave tab.* と表示されます。

## APIを使用する

`GET /rest/v1/analyze/weave/monthly` は、`project_id` と、`YYYY-MM` 形式の任意の `month`（省略すると当月）を指定して、プロジェクトのサマリーを返します。`GET /rest/v1/analyze/weave/monthly/workspace` は、同じく任意の `month` を指定して、ワークスペースサマリーを返します。形式が正しくない月や、まだ始まっていない月は拒否されます。
