## 説明

Weaveは、プロジェクトの各[メトリック](/ja/integrations/ai-coding-agents/metric-definitions/)を1日に1回読み取り、最新の完了した期間を確認します。その期間のメトリックの合計が通常の範囲外であり、顧客、製品、工場などの内訳の1つの項目が、合計に占める通常の割合から想定されるよりはるかに大きく変化していた場合、Weaveはプロジェクトの[Weaveタブ](/ja/guides/ai-assistant/weave-tab/)にそれを報告し、その項目を名指しします。

AIモデルは使用しません。このチェックは固定のルールで、すべての文は、Weaveが読み取った数値からあらかじめ書かれています。

## 検出事項の内容

```
Weave noticed the metric "Revenue": it came to 16.4M in April 2026, against an
average of 11.2M (usual range 8.9M to 13.5M) over the 12 months before.
"Seasonal Specials" (by product_group), usually 2% of the total, rose from an
average of 210.0K to 1.7M, 1.5M of the rise of 5.2M (29%); the other 3.7M came
from elsewhere
```

金額はK、M、Bに短縮され、通貨や単位は表示されません。メトリック定義にはそれらが記録されないためです。暦年の日付列を持つメトリックでは、*April 2026* のように月が示されます。それ以外では、*period 8 of fiscal 2025* のように期間が示されます。

1つの項目の変動が合計全体の変動より大きい場合、検出事項はそのことを述べ、他のすべてが逆方向に動いたことも述べます。以前の期間に値がなかった項目は、それまで値がなかったものとして記述されます。

**Weaveが把握する方法**には、期間、合計、以前の期間の平均、比較した期間の数、通常の範囲、最も大きく動いた項目、およびそれ以外にも通常よりはるかに大きく動いた項目が表示されます。

## Weaveがチェックするメトリック

メトリックは、廃止されておらず、次の条件を満たす場合にチェックされます。

- **日付列**、または**年と期間の列**があり、比較できる期間がある。
- **合計またはカウント**であり、Weaveが各項目の寄与分に分解できる。
- 顧客や工場など、何が動いたかを示す**内訳列**が少なくとも1つある。
- **他のメトリックから計算されていない**。

Weaveは各メトリックの現在のバージョンを、最後に保存したアーキテクトとして、そのアーキテクトが見られる範囲のみで読み取ります。Weaveはプロジェクトごとに最大50個のメトリックをチェックし、保存日時が古いものから順に対象となります。それを超えるものは未チェックとして一覧表示されます。

条件を満たさないメトリック、またはWeaveが読み取れなかったメトリックは、理由とともに **Weaveが未チェック** のものとして一覧表示されます。正常として数えられることはありません。

## チェックの仕組み

**判定される期間。** 日付列を持つメトリックの場合、7日以上前に終了した最新の期間です。そのため、締め処理中にまだ読み込み中の期間は判定されません。日付を持たない年と期間の列を持つメトリックの場合は、値のある最新の通常期間の1つ前の期間です。ただし、12期間の年における13～16期間などの調整期間に値がある場合は、その年の最後の期間です。期間0と調整期間は判定されません。

**通常の範囲。** Weaveは、その期間の合計を、その前の最大12期間と比較し、値のある期間が少なくとも6つ必要です。範囲は、それらの期間のばらつきから求められます。

**季節性のある期間。** 範囲外の合計でも、前の3年のうち少なくとも2年の同じ期間が同様の結果だった場合は報告されません。期間が四半期に分かれるカレンダーでは、5週間の月など、それ以前の四半期の同じ位置と同程度である場合も報告されません。

**動いた項目。** Weaveは、ディメンションに関連付けられた列から始めて、最大5つの内訳列で合計を分割し、変化に占める割合が合計に占める通常の割合よりはるかに大きい場合にのみ項目を名指しします。検出事項は、金額で最も大きく動いた項目から始まります。多数の項目に分散した変化で、それぞれが比例して動いている場合は報告されません。

**後からの調整。** ある期間について問題が報告されると、その後の読み取りが元の値の0.5%以内である限り、数値は最初に読み取った値のまま保たれます。そのため、後から行われた小さな調整によって、新規の問題として再び報告されることはありません。

## Weaveがチェックしないもの

- 1つの項目が際立たない、通常の範囲外の合計。
- 合計が通常の範囲内にとどまっている間の、1つの項目の割合の変化。
- 最初の5つを超える内訳列、または項目と期間全体で50,000を超える値を持つ内訳列。
- その動きが誤りなのか、実際のビジネスの動きなのか。
- 比較にのみ使用される、以前の期間。

## 表示される相手と通知される相手

検出事項は、メトリックを**最後に保存した**ユーザーのものであり、そのユーザーには実行の合間にPlaidCloudで通知されます。他の検出事項と同様に、ダイジェストをオンにしているユーザーの[日次ダイジェスト](/ja/guides/ai-assistant/weave-findings/#ダイジェスト)にも含まれます。最後に保存したユーザーがプロジェクトのアーキテクトでなくなった場合、Weaveは、現在のアーキテクトが保存するまでそのメトリックのチェックを停止します。

プロジェクトを読み取れるユーザーは、Weaveタブで検出事項を確認できます。[行アクセス](/ja/administration/access/managing-security-groups-and-assignments/)があるプロジェクトでは、数値が保存したユーザーのアクセス権で読み取られているため、これらの検出事項を取得するのはアーキテクトのみです。

各検出事項は、最初に報告されたときに、プロジェクトの[Weaveアクティビティ履歴](/ja/guides/ai-assistant/weave-activity/)に記録されます。同じ期間の後の読み取りで問題がもう表示されなくなると、履歴にはWeaveが検出しなくなったことが記録されます。次の期間が締められると、Weaveの日次チェックがその期間に移ったことが記録されます。メトリックが廃止されると、Weaveがチェックを停止したことが記録されます。

## 行へ移動

検出事項の**行へ移動**は、メトリックのソーステーブルでテーブルエクスプローラーを開き、項目、期間、メトリック自身のフィルターで絞り込みます。これにより、変化の背後にある行を確認できます。テーブルを読み取れるユーザーに表示されますが、ソーステーブルだけでは行を示せない、ルックアップテーブルを使用するメトリックでは表示されません。

<Aside type="note">
新たに保存したメトリックは、プロジェクトにすでに50個のメトリックがある場合を除き、1日以内に読み取られます。それまでは、Weaveがまだ読み取っていないものとして一覧表示されます。
</Aside>

## Weaveがメトリックをチェックしなかった場合

| 表示される理由 | 対応 |
| --- | --- |
| 他のメトリックから計算されている | 何もする必要はありません。Weaveは基本メトリックのみをチェックします。 |
| 平均、最小値、最大値、または異なる値のカウントである | 何もする必要はありません。項目ごとに分割できるのは、合計とカウントのみです。 |
| 内訳がない | 顧客などの内訳列を追加して、新しいバージョンを保存します。 |
| 日付または期間の列がない | 時間バインディングを追加して、新しいバージョンを保存します。 |
| 年または期間の列に *2024-01* のような値が含まれている | 時間バインディングを、整数の年と期間の列、または日付列に向けてください。 |
| 数値のある期間が数個しかない | お待ちください。Weaveには以前の期間が6つ必要です。 |
| その期間の数値がない | その期間のデータが読み込まれたことを確認してください。 |
| 最後に保存したユーザーがアーキテクトでなくなった | 現在のアーキテクトに保存してもらってください。 |
| 読み取りに2分を超える時間がかかった | Weaveは翌日に再試行します。 |
| すべての内訳に50,000を超える値がある | その状態の間、Weaveはチェックしません。 |
| 合計が通常の範囲外だが、内訳に50,000を超える値がある | その内訳の1つの項目が変化の原因かどうか、Weaveには判断できません。その内訳をご自身で確認するか、メトリックの内訳列から削除してください。 |
| プロジェクトに50個を超えるメトリックがある | 誰も使っていないメトリックを廃止してください。保存日時が古いものから順にチェックされます。 |
| Weaveが現在のバージョンを読み取れなかった | Weaveは翌日に再試行します。 |
| Weaveの日次チェックが最後に実行されたのが数日前 | PlaidCloudの管理者に問い合わせてください。 |
