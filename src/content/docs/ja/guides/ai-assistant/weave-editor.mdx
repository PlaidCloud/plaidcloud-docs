## 説明

Weaveは、ワークフローエディターとステップのフォームであなたの作業を支援します。提案、カウント、チェックを行いますが、
何かを保存することはありません。提案があなたのものになるのは、それを採用してステップを保存したときだけで、
チェックによって保存が妨げられることはありません。

## ステップのフォームでの提案

ステップのフォームに入力を始めたら、空の欄をクリックします。Weaveに提案がある場合は、欄の下に薄く表示され、
その出所を示す行と**使用**ボタンが付きます。

- 採用するには、**Tab**キーを押すか**使用**をクリックします。
- 破棄するには、**Escape**キーを押すか、そのまま入力を続けます。

Weaveが提案するものは次のとおりです。

- 結合のキー列（`cost_center = cost_center` など）。
- 新しいステップの列マッピング。
- **WHERE**フィルター。
- 空の式のセルと、空の式エディター。

提案の下の行には、*Freightを読み取る他の3つのステップで使用されています*、*Freightの列* などの出所が示されます。
結合の場合は、*これらのキーは、同じ2つのテーブルを結合する、このプロジェクト内の別の結合ステップから取得しています。* と示されます。
キーの名前が似ているだけの場合は、*これらの列は両方のテーブルで似た名前を持っています。保存する前に確認してください。* と示されます。

Weaveは、表示できるステップからのみ提案し、ステップを保存できなくなるようなものは除外します。
すでに値がある欄や、読み取り専用のフォームには提案は表示されません。列マッピングは新しいステップにのみ提案されます。

ステップの右クリックメニュー、コマンドパレット、ドックの`/`リストにある**Suggest settings**を使用すると、
ステップのすべての提案を一度に求めることができます。

## 次に来るもの

キャンバスにステップを追加すると、その右側に**What next?** ボタンが表示されます。クリックすると最大3つのタイルが表示され、
それぞれが**集計**、**ルックアップ**、**エクスポート: CSV**などのステップの種類です。タイルを選択すると、そのステップのフォームが
入力済み・未保存の状態で開きます。

Weaveは、このプロジェクトで次に来ることが最も多いステップを提案します。履歴の少ないプロジェクトでは、代わりに一般的な次のステップが提案されます。
右クリックメニュー、コマンドパレット、ドックの**What comes next?** コマンドでも同じことができます。

## 保存前に行数を数える

ステップのフォームの**保存**の上にある帯には、*最終実行 46,800行、11月11日 06:12 UTCに終了* のように前回の実行の状況が表示されるか、
**Not run yet**と表示されます。

**Count rows**をクリックすると、保存も実行もせずに、表示中の設定でステップが書き込む行数を数えます。

> この変更: 46,912行（最終実行 46,800行、通常は45,100～47,300行、直近8回の実行と比較）

最初の20行を表示するには、**行を表示**をクリックします。カウントの下の行には、ステップの影響が及ぶ範囲が示されます。
出力を読み取るものを確認するには、**ステップを表示**または**ダッシュボードを表示**をクリックします。

- カウントは、Extract、Lookup、Join（内部、外部、アンチ）、Union、Union Allの各ステップで機能します。
  その他のステップでは**No preview for this step type yet**と表示されます。
- カウントできないステップでは、まだ構築されていないテーブルを読み取っているなど、その理由が表示されます。
- カウントは5秒後に停止します。
- 行アクセスによって表示できる行が制限されている場合、カウントは表示できる行が対象となり、その旨が示されます。

ステップの右クリックメニュー、コマンドパレット、ドックの**プレビュー**でも、同じ前回の実行の行とカウントが表示されます。

## キャンバス上でステップのデータを確認する

テーブルに書き込むステップにポインターを合わせます。小さなウィンドウに、テーブル、その行数、ステップの最終実行日時が表示され、
次の操作ができます。

- **最初の行を表示** — 最初の10行をあなたとして読み取り、読み取った時刻とともに保持します。
- **テーブルを開く** — テーブルエクスプローラーでテーブルを開きます。
- **Weave に質問** — そのテーブルを対象にドックを開きます。

プロジェクトのテーブルを読み取れるユーザーなら、ワークフローを閲覧することしかできないメンバーも含め、誰でもこれを確認できます。

## 実行時のチェック

**ワークフローの実行**、ステップの範囲、または**選択を実行**でワークフローを実行すると、Weaveはその設定と構造を、
**チェック**と同じチェックで確認します。問題がなければ何も表示されません。問題がある場合は、キャンバスの上の帯に
*Weaveがワークフロー「Month-End Close」で2件の問題を見つけました* と表示され、その後に最初の問題が続きます。

- **確認**を選択すると、Weaveチェックウィンドウに結果全体が表示されます。
- **実行を停止**を選択すると、実行が停止します。問題が警告ではなくエラーである場合に、実行中に表示されます。

問題のある各ステップにはキャンバス上にマークが付き、ポインターを合わせると問題の内容が表示されます。
Weaveが再びチェックするのは、ステップまたはワークフローへの変更を保存した後だけで、帯が表示されるのは、まだ表示していない問題がある場合だけです。
系統、ウェアハウスの列、行レベルセキュリティは、引き続き**チェック**をクリックしたときにチェックされます。
**チェック**にポインターを合わせると、設定が最後にチェックされた日時が表示されます。

## ステップが失敗したとき

最終実行が失敗したステップには、キャンバス上に赤い点が表示されます。*最終実行は失敗しました。選択すると理由を確認できます。*
ステップを選択すると、インスペクターの**前回の実行エラー**カードにボタンが表示されます。

- Weaveが修正を提案できる場合は**修正**。[AIでワークフローのエラーを修正する](/ja/guides/ai-assistant/fixing-workflow-errors/)を参照してください。
- それ以外の場合と警告の場合は**Weave に質問**。Weaveはエラーを説明し、既知のエラーにはPlaidCloudの既知のエラーのカタログから回答します。

その横の **⋯** には、その他のWeaveの操作があります。他の場所のエラーメッセージでも**Weave に質問**が表示されます。
**アクションに失敗しました**ダイアログ、保存できなかったステップ、開始できなかったワークフロー、失敗したCSVインポートです。

## ワークフローで作業中のWeave

Weaveが構築や修正などのジョブをワークフローで実行している間、キャンバス上でワークフローを閲覧しているユーザーの中にWeaveのアイコンが加わります。
ポインターを合わせると、*Weave, working for* と、Weaveが作業している相手の名前が表示されます。

キャンバスのツールバーのコメントボタンで、ワークフローのコメントが開きます。
[コメントと@Weave](/ja/guides/ai-assistant/weave-team/#コメントとweave)を参照してください。

<Aside type="note">
提案、カウント、キャンバスのウィンドウ、実行時のチェックは、あなたとしてプロジェクトを読み取り、何も変更しません。
</Aside>
