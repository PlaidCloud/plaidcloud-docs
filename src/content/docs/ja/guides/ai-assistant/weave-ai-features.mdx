## 説明

ワークスペースでWeaveのどのAI機能を使用するかは、ワークスペース管理者が決めます。各機能は個別に、ワークスペースの全員に対してオフにできます。管理者がオフにするまで、すべての機能はオンです。

Weaveのチェックと検出事項にはAIが使われていないため、ここでの選択にかかわらずオンのままです。

## 機能をオンまたはオフにする

1. ヘッダーの**Weave**ボタンをクリックします。
2. メニューの末尾にある**AI機能…** を選択します。
3. オフにする機能の横のボックスをクリアします。オンに戻すには、ボックスにチェックを付けます。
4. **保存**をクリックします。

変更は、ワークスペースの誰かが次にAIリクエストを行ったときから適用されます。サインアウトする必要はありません。

**AI機能…** が表示されるのは、ワークスペース管理者だけです。それ以外のユーザーがAPIから機能を変更しようとすると、*Only workspace administrators can turn AI features on or off.*と通知されます。

## 機能一覧

| 機能 | 対象 | オフにした場合 |
|---|---|---|
| **Weaveチャット** | プロジェクトの**Weave**タブのチャット、**ヘルプとサポート**の**アシスタントに質問**、および[PlaidCloudモバイルアプリ](/ja/guides/mobile-app/weave-on-mobile/)のWeave。 | **Weave**タブの**チャット**に、管理者がオフにしたことが表示されます。**ヘルプとサポート**には**アシスタントに質問**タブが表示されません。モバイルアプリでの質問は拒否されます。 |
| **修正アシスタント** | Weaveの検出事項の**修正**と、ログエントリの**Weave AI**タブ。 | 検出事項に**修正**が表示されなくなります。ただし、**Steps that can run before the table they read is written**にあるコネクターの欠落は例外で、その**修正**はアシスタントではなく[依存関係の同期](/ja/guides/workflows/sync-dependencies/)を開きます。**Weave AI**タブは使用できなくなります。 |
| **インポート/エクスポートアシスタント** | ファイルのインポート、インポートステップ、エクスポートステップをWeaveチャットが代わりに設定する機能。 | Weaveチャットでこれらを設定できなくなります。 |
| **式アシスタント** | 式エディター内のアシスタント。 | 式エディターにアシスタントが表示されなくなります。 |
| **説明からSQLを生成** | **SQL抽出**ステップの[Generate SQL with AI](/ja/guides/ai-assistant/generate-sql-extract/)。 | ステップに**Generate SQL with AI**セクションが表示されなくなります。SQLは引き続きご自身で書けます。 |
| **ワークフローレビューの要約** | ワークフローの**チェック**の上に表示される、AIが作成した要約。 | **チェック**には、要約なしで検出事項が表示されます。 |
| **スターターグラフ** | ドロップしたファイルの最初のグラフをAIが選択する機能。 | 代わりにルールがグラフを選択します。 |

変更時にすでにサインインしていたユーザーは、PlaidCloudを再読み込みするまでその機能が表示されたままですが、Weaveはその機能にAIを使用しなくなります。チャット、修正アシスタント、式アシスタント、説明からのSQL生成では、その旨が表示されます。たとえば、*Your workspace administrator has turned off the fix assistant.*のように表示されます。

<Aside type="note">
これらのスイッチが対象とするのは、PlaidCloudが提供するAIです。ワークフロー内のAIステップはお客様ご自身のAI接続を使用し、[MCP](/ja/integrations/ai-coding-agents/)で接続したAIツールはそれぞれのモデルを使用するため、どちらも影響を受けません。
</Aside>

## 変更の記録

機能をオンまたはオフにするたびに、変更したユーザーと日時がワークスペースのセキュリティログに記録されます。たとえば、*Turned off the fix assistant.*のように記録されます。

## APIから操作する

`GET /rest/v1/analyze/ai/features`は、各機能とそれがオンかどうかを、`{"features": [{"feature": "chat", "on": true}, …]}`の形式で返します。機能名は、`chat`、`fix`、`import_export`、`expression`、`sql_extract`、`review_summary`、`starter_chart`です。

`PUT /rest/v1/analyze/ai/features`に`{"off": ["fix"], "on": ["chat"]}`を指定すると、`off`の機能がオフに、`on`の機能がオンになります。どちらのリストにもない機能は変更されないため、2人の管理者が別々の機能を変更しても、互いの変更を打ち消すことはありません。応答は`GET`と同じ形式です。呼び出せるのはワークスペース管理者だけです。機能名ではない名前や、両方のリストに含まれている名前は拒否されます。
