## 説明

プロジェクトのテーブル、ステップ、ワークフローを選択すると、その詳細パネルが開きます。パネルの下部にある**ドキュメント**セクションには、Weaveがプロジェクトの保存済みの設定から作成した、そのアイテムのページが表示されます。

- テーブルの場合は、そのテーブルを書き込むステップと読み取るステップ、および列
- ステップの場合は、ステップの動作と実行場所
- ワークフローの場合は、ステップの順序と、読み取りおよび書き込みを行うテーブル

ページはアイテムを選択するたびに、その時点で保存されている設定から作成されるため、古くなることはなく、手動で更新する必要もありません。AIは使われていないので、AIプロバイダーが利用できない場合でも動作します。新しい説明を入力した場合など、同じ詳細パネルで保存すると、ページは再作成されます。

Weave AI、プロジェクトの**Weave**タブのチャット、MCPで接続したAIアシスタントも、同じページを読み取れます。[AIアシスタント向け](#aiアシスタント向け)を参照してください。

## テーブルのページ

- **説明** — テーブルの**メモ**が引用として表示されます。ステップが作成したテーブルには、PlaidCloudがメモに*Created dynamically*を設定しますが、テーブルについて何も伝えないため表示されません。
- **書き込むステップ**と**読み取るステップ** — 各ステップが、名前、ステップタイプ、所属するワークフローとともに表示されます。ステップが無効になっているワークフローには*（無効）*が付き、どのワークフローにも属さないステップには*ワークフローなし*と表示されます。テーブル名に、このテーブルを指す場合も指さない場合もある変数が含まれるステップは、*変数の値によって*と併記されます。複数のテーブルが共有する名前だけを指定するステップは、たとえば*同じ名前を持つ他の2つのテーブルのどちらかを指す場合を除く*と併記されます。数えられるのは、開けるテーブルだけです。テーブル: クリア、テーブル: ドロップ、テーブル: インプレース削除のステップは、変更するテーブルを書き込むものとして数えられ、テーブルを読み取って同じテーブルに書き戻すステップは、両方に表示されます。
- **このプロジェクトには、このテーブルを読み取るステップはありません。** — このプロジェクトのどのステップも、このテーブルをソースとして挙げていないことを意味します。ダッシュボード、エクスポート、他のプロジェクト、プロジェクトのステップ以外のものは確認されません。
- **列** — 各列とその型です。**列のプロパティ**に説明が設定されている場合は、その説明も表示されます。

## ステップのページ

**動作**には、ステップが行う内容が1つにつき1文で示されます。

| ステップ | ページの表示内容 |
| --- | --- |
| Allocation Split | どのテーブルのどの値を、どの列にまたがって、どのドライバー列を使って分割するか、および各シェアの算出方法です。たとえば、「各`product`のシェアは、その`weight`を、同じ`cost_center`、`year`、`month`の`weight`の合計で割った値です。」のように示されます。列は、ソーステーブルとドライバーテーブルでの名前で表示されます。ステップのソースまたはドライバーに対するフィルターがある場合はその旨が記され、書き込まれるテーブルの名前も示されます。 |
| 配賦: ディメンションで分割 | どのテーブルのどの値を、どのドライバー列を使って分割するか、およびマッピング、パス、サマリーのテーブルを含め、書き込まれるすべてのテーブルです。 |
| インポート | インポートするファイルと、インポート先のテーブルです。 |
| エクスポート | エクスポートするテーブルと、書き込むファイルです。 |
| SQL抽出（ソースの指定なし） | SQLクエリを実行すること、および書き込むテーブルです。 |
| テーブル: クリア、テーブル: ドロップ、テーブル: インプレース削除 | 対象のテーブルをクリアする、ドロップする、または行を削除すること。検索やフォルダーでテーブルを選ぶ場合は、その設定で選ばれるテーブルに対して実行することです。 |
| 外部プロジェクトテーブルのインポート | 別のプロジェクトのテーブルを、このプロジェクトのテーブルにコピーすることです。 |
| 別のワークフローを実行するステップ | 実行するワークフローと、その実行方法です。条件を満たしたとき、ループ内、マクロとして（ソーステーブルの行ごとに1回、並列実行の場合は同時に）、またはインクルードによって実行されます。変数で選択されたワークフローは、ステップが指定した名前で表示され、別のプロジェクトにあるワークフローはその旨が記されます。ループが順に処理するテーブルなど、ステップ自体が読み取るテーブルも一覧表示されます。 |
| その他のステップ | 読み取るテーブルと、書き込むテーブルです。 |

続いてページには、ステップの実行場所が表示されます。ワークフローのステップ一覧と同じ番号で、*ステップ3：*に続けてワークフローが示されます。どのワークフローにも属さない場合は、その旨が示されます。

ステップが変数を通じて指定するテーブルは、その名前に続けて*（変数で指定）*と表示されます。

## ワークフローのページ

- **ステップ** — ワークフローのステップ一覧と同じ番号で、各ステップのタイプと、書き込むテーブル、または実行するワークフローが示されます。インクルードしたワークフローのステップは、ステップ一覧と同じように、その位置に展開されて一覧表示されます。
- **このワークフローの外部からの読み取り** — このワークフローのどのステップよりも先に読み取られる、このワークフローで書き込まれる前のテーブルです。
- **書き込み先** — ワークフローのステップが書き込むテーブルです。

無効なステップは**ステップ**には表示されますが、他の2つのリストには含まれません。無効なステップが書き込むテーブルが外部から読み取られるものとして一覧表示される場合があるため、ページにはその旨が記されます。ワークフローのステップが実行する別のワークフローで使用されるテーブルは、そのワークフロー自身のページに表示されます。

## プロジェクト全体の引き継ぎパック

たとえば契約の終了時にクライアントへプロジェクトを引き継ぐ場合など、すべてのページを一度にダウンロードできます。**プロジェクト**ウィンドウで1つのプロジェクトを選択し、**アクション**メニューまたは右クリックメニューから**引き継ぎパックをダウンロード**を選択します。プロジェクト、そのステップ、ワークフロー、テーブルへの読み取りアクセスが必要です。

パックはプロジェクト名が付いた1つのMarkdownファイル（たとえば*Month End handover.md*）で、ダウンロード時の保存済みの設定から作成されます。冒頭にプロジェクトの説明と含まれる内容の件数が示され、続いて4つのセクションがあります。

- **ワークフロー** — 各ワークフローのページです。他のどのワークフローからも実行されないワークフローが名前順で先に表示され、それぞれの後に、そのワークフローが実行するワークフローが実行順に続きます。2か所から実行されるワークフローは、1回だけ一覧表示されます。
- **テーブル** — 前述のとおり、列とその説明を含む各テーブルのページです。
- **メトリック** — 各メトリック定義の現在のバージョンが、平易な文で示されます。何を測定するか、どのテーブルから、結合するテーブル、使用する行、実績と予算の行、期間、どの軸で分解できるかです。他のメトリックから作られたメトリックは、たとえば*売上を受注数で割った値*のように、その方法が示されます。[メトリック定義](/ja/integrations/ai-coding-agents/metric-definitions/)を参照してください。
- **配賦モデル** — 互いにつながる配賦ステップの各チェーンです。最終となるステップと、各ステップの分割が実行順に示されます。どのワークフローでも実行されないステップは含まれません。モデルにはそのワークフロー名、またはワークフローが共有するフォルダー名が付けられます。そのような名前がない場合、別のモデルと名前が重複する場合、お使いのロールから非表示のものから名前を取る場合は、代わりにそのステップの1つがタイトルになります。配賦モデルには、パック以外に専用のページはありません。

お使いのロールから非表示のものについては、パックも単独のページと同じルールに従います。開けないワークフロー、テーブル、配賦モデルは含まれず、先頭に件数が示されます。たとえば、*開けない2つのワークフローと5つのテーブルは含まれていません。*のように表示されます。開けないステップは、単独のページと同様に、名前が表示されることはありません。

## お使いのロールから非表示のもの

テーブル、ステップ、ワークフローは、マネージャーまたはエクスプローラーのロールから非表示にできます。ページには、お使いのロールから非表示のものの名前は表示されません。

- 開けないステップは件数で示されます。たとえば、*開けないステップがあと2個あります*のように表示され、ワークフローのステップ一覧では番号が保たれます。
- 開けないテーブル、ステップ、ワークフローは、存在しなくなったものと同じ表示になります。たとえば、*開けない、または存在しなくなったテーブル*のように表示されるため、ページから非表示のものの有無を知ることはできません。このようにワークフローの一覧から除外されたステップは、そのステップが書き込むテーブルが外部から読み取られるものとして一覧表示される場合があるため、その旨が記されます。ステップが指定した、開けない、または存在しないテーブルは、ステップが指定した名前に続けて*（開けるテーブルではありません）*と表示され、ワークフローも同様に*（開けるワークフローではありません）*と表示されます。
- お使いのロールから非表示のアイテムのページを要求すると、存在しないものとして応答されます。

アーキテクトはすべてを開けるため、アーキテクトのページには、代わりに*削除されたテーブル*、*（テーブルが見つかりません）*、*削除されたステップ*、*（ワークフローが見つかりません）*と表示されます。

## 対象外の内容

- **行数、サイズ、更新時刻。**
- **SQLテキストや式を通じてのみ到達するテーブル。** ページに一覧表示されるのは、ステップが設定で指定しているテーブルです。
- **未保存の編集。** ページには、保存済みの設定が記述されます。

<Aside type="note">
ページは、データを解釈したり、ステップが正しいかどうかを判断したりしません。保存済みの設定の内容を、平易な言葉で示すだけです。
</Aside>

## AIアシスタント向け

- **Weave AI**は、プロジェクトで開いた会話でテーブル、ステップ、ワークフローについて質問すると、そのページを読み取り、ページの内容に基づいて回答できます。[Weave AIチャット](/ja/guides/ai-assistant/weave-tab/#weave-aiチャット)を参照してください。
- **MCPで接続したAIアシスタント**は、プロジェクト、アイテムの種類（テーブル、ステップ、ワークフロー）、およびそのIDを指定して、`doc_describe`ツールで同じページを読み取れます。ステップ、ワークフロー、テーブルへの読み取りアクセスが必要で、お使いのロールから非表示のものに関しても同じルールに従います。[AIエージェント（MCP）](/ja/integrations/ai-coding-agents/)を参照してください。
