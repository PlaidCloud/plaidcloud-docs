## 説明

数値がおかしく見えるとき、最初に知りたいのは、それがどこから来たのか、そして何が変わったのかです。
Weaveは、AIモデルを呼び出さず、何も変更せずに、プロジェクト自体の記録から両方に答えます。

## この数値の根拠

数値を右クリックして**Why this number**を選択します。

- **テーブルエクスプローラー**では、セルを右クリックします。回答はセルの横に開きます。
- ダッシュボードでは、グラフ上のポイントまたは表グラフのセルを右クリックします。PlaidCloudが新しいタブで開き、
  そこでWeaveドックが回答します。

回答には次の内容が示されます。

- 数値を書き込むステップと、そのワークフロー。
- 数値の元になっているもの。たとえば *Freight Costsから、Headcountで配分されています。* のように示されます。
  配賦の場合は、ドライバーの名前が示されます。
- そのステップの最終実行日時。
- 承認済みの照合が数値のテーブルを読み取っている場合は、そのテーブルが最後に一致した日時。
  [最後に一致した日時](#最後に一致した日時)を参照してください。

その後、Weaveが算出するにつれて、数値がどのように変化したかが表示されます。

- **Since the run before** — *終了した実行で120,100増加（+10.0%）* とその日時のように示されます。
- **Since last period** — テーブルに期間の列がある場合。
- **Input and share** — 配賦によって書き込まれた合計の場合。変化のうち、配分される金額によるものと、
  その中での数値の配分比率によるものがそれぞれどれだけかが示されます。

各部分は、準備ができるまで *Weave is still working on this…* と表示されます。**開く**リンクでステップとテーブルに移動でき、
**Weaveが把握する方法**には各行の出所が示されます。

- グラフのポイントに完全に回答できるのは、グラフが1つの公開テーブルを読み取り、列の合計、平均、件数、最小値、最大値を求める場合です。
  Weaveが1つの数値までたどれないクエリに基づくグラフでは、代わりにグラフが読み取るテーブルが示されます。
- 前回の実行との比較は、直近35日間のステップの最後の2回の実行が対象で、以前のバージョンのテーブルがまだ保持されている必要があります。
- 行アクセスによって読み取れる範囲が制限されている場合、Weaveは変化を分解しません。行レベルセキュリティが適用されたテーブルでは、
  以前のバージョンとの比較はできません。
- **Why this number**には、プロジェクトのテーブルを読み取れるロールが必要です。

## 以前の実行時点のテーブル

**テーブルエクスプローラー**のツールバーにある**時点**リストには、テーブルの以前のバージョンが新しい順に、それを書き込んだものによって表示されます。
*after Month-End Close ran* と日時（ステップ付き）、または *changed outside a workflow run* と日時です。
1つを選択すると、その時点のテーブルが読み取り専用で表示されます。**現在(ライブデータ)** オプションを選択すると、ライブのテーブルに戻ります。
[テーブルのスナップショット](/ja/guides/data/table-snapshots/)を参照してください。

### 現在と比較する

以前のバージョンを表示している間に、**Compare with now**をクリックします。Weaveは次の内容を示します。

- その時点と現在の行数。
- 変更、追加、削除された行の数と、変更された列。たとえば
  *それ以降: 312行が変更、4行が追加、削除はなし。Amountが312行で変更、Headcountは変更なし。* のように示されます。
- 差異のある行。最大500行のサンプルから、グリッド上でマークされます。

**Column shift ▸** をクリックすると、各数値列の分布をその時点と現在で比較できます。

行を照合するには、Weaveにテーブルのキー列が必要です。キー列が設定されていない場合はWeaveがその旨を伝え、
プロジェクトのアーキテクトが**Set key columns**をクリックできます。キー列は、新しいステップ、結合の提案、データのチェックでも使用されます。

### アクティビティと右クリックメニューから

- プロジェクトの[Weaveのアクティビティ履歴](/ja/guides/ai-assistant/weave-activity/)では、テーブルやステップに関するエントリに
  **See the data then**があり、そのエントリの直後のバージョンでテーブルが開きます。
- テーブル、ワークフロー、ステップの右クリックメニューの**Weave**セクションには、**変更内容**と**See it at an earlier run**があります。

どこまでさかのぼれるかは、テーブルの以前のバージョンが保持される期間によって異なります。行レベルセキュリティが適用されたテーブルでは、
以前のバージョンは表示されません。

## ホワットイフを質問する

配賦の出力テーブルを開き、*運賃が8%上がったらどうなるか* のようなホワットイフをドックでWeaveに質問します。
Weaveは、結果がどのように変わるかの見積もりをすぐに示し、*Estimate: uses today's shares; nothing was re-run.* というラベルを付けます。
ドライバーの1つを特定の値に設定するなど、ドライバーの変更について質問することもできます。言葉が複数の意味に取れる場合は、
Weaveがどれを意味するのかを尋ねます。

見積もりを保持するには、**Keep ▾ → As a scenario**を選択します。
[見積もりをシナリオとして保持する](/ja/guides/ai-assistant/weave-requests/#見積もりをシナリオとして保持する)を参照してください。

- Weaveが見積もるのは、開くことができる配賦ステップによって書き込まれたテーブルです。
- 行アクセスによってテーブルの一部が表示されない場合、合計が不完全になるため、Weaveは見積もりを行いません。
- Weaveが見積もるのは指定した変更であり、以前の変更を取り消すことではありません。

## 最後に一致した日時

プロジェクトのアーキテクトが承認済みの[照合](/ja/guides/ai-assistant/weave-reconciliation/)を実行すると、
PlaidCloudはその結果を保持し、1文で表示します。

- *Tied out to Cost Pool at 06:02.*
- *Doesn't tie to Cost Pool, as last checked at 06:02.*
- どちらかの側が変更された後は、*Not checked since* に続けて、テーブルが後の時刻に書き込まれたこと（*was written at*）。

この文は、照合ウィンドウの**Last result**列、**Why this number**への回答、
[準備状況のチェックリスト](/ja/guides/ai-assistant/weave-readiness/)に表示されます。
もう一度チェックするには、テーブルの右クリックメニューの**Weave**セクションで**Run the check**を選択します。
テーブルを読み取る承認済みの照合がすべて、あなたとして実行されます。

保持された結果が表示されるのは、照合が読み取るすべてのテーブルを開くことができ、行アクセスによって読み取れる範囲が制限されていない場合だけです。
