## 説明

Weaveはメールを送信できるため、PlaidCloudを開いたままにしなくても問題を知ることができます。
メールには2種類あり、それぞれ自分でオンにします。

- **アラート**：ワークフローの実行が終了し、Weaveが確認が必要な重大な問題を見つけたときに送信されます。対象は、実行の失敗や、動作しない設定のワークフロー、ステップ、スケジュールです。PlaidCloudでWeaveが通知する問題が対象となり、多くの場合、あなたが最後にワークフローを実行した場合や、誰かがその問題をあなたに割り当てた場合です。
- **毎日の概要**：Weaveから通知された未読の問題の概要で、指定した時刻に送信されます。

どちらも、オンにするまではオフです。

## Weaveメールをオンにする

1. ヘッダーの**Weave**ボタンをクリックします。
2. **Weaveメール…** メニューを選択します。
3. **あなたのメール**で、次のいずれか、または両方にチェックを入れます。
   - **確認が必要な重大な問題をWeaveが見つけたらメールで知らせる**
   - **Weaveから通知された未読の問題の概要を毎日メールで受け取る**。あわせて**時間**を選択します。
4. **保存**をクリックします。

時刻は、あなたのタイムゾーン、つまり**保存**をクリックしたときにブラウザーが使用しているタイムゾーンで扱われます。ウィンドウでは、**時間**の横にそのタイムゾーンが表示されます。その時刻を過ぎてから毎日の概要をオンにした場合、最初の1通は1時間以内に届きます。

**保存**をクリックしたときにPlaidCloudに接続できない場合は、ウィンドウに*メールの設定を保存できませんでした。しばらくしてからもう一度お試しください。*と表示され、ウィンドウは開いたままになります。

メールを停止するには、チェックを外して**保存**をクリックします。

## メールの内容

各メールには、プロジェクトの名前と、問題ごとのワークフロー、ステップ、テーブル、メトリックが、問題の種類とともに記載されます。たとえば、*"Month End" (workflow) — Last run failed* のようになります。メールには、プロジェクトの**Weave**タブへのリンクがあり、そこで検出事項の全文を読めます。

メールに、データの数値や値が含まれることはありません。PlaidCloud上でWeaveが示す文には、それらが引用されることがあるため、メールでは省かれます。

Weaveは、メールを送信する前に、あなたが閲覧できる内容を確認します。各メールは、あなたとして実行したWeaveのチェックから作成されるため、あなたのアクセス権で見えないものが記載されることはなく、開けなくなったプロジェクトについてのメールも届きません。

毎日の概要には、**Weave**タブで読むか、問題が解消されるまで、その問題が掲載されます。そのため、昨日アラートで通知された問題を読んでいなければ、今日の概要にも含まれます。未読の問題がない場合、概要は送信されません。

## 管理者向け

ワークスペース管理者には、同じウィンドウに**ワークスペース**セクションが表示されます。

- **Weaveがこのワークスペースのメンバーにメールを送信することを許可する**は、チェックを外すまでオンです。オフにすると、Weaveは誰にもメールを送信せず、各メンバーのウィンドウに*ワークスペース管理者がWeaveメールをオフにしています。*と表示されます。
- **通知を控える時間帯**では、**開始**の時刻から**終了**の時刻までの間、アラートを保留します。この時間帯は各メンバーのタイムゾーンで適用され、たとえば20:00から07:00のように、深夜をまたいで設定できます。この時間帯にアラートの対象となる問題が見つかった場合、時間帯が終了したときに、問題が残っていて、メンバーが未読であれば送信されます。通知を控える時間帯は毎日の概要には影響せず、概要は各メンバーが選択した時刻に送信されます。

変更はすべて、変更した人と日時とともに、ワークスペースのセキュリティログに記録されます。たとえば、*Turned off Weave email.* のようになります。

<Aside type="note">
Weaveは、各メンバーのPlaidCloudアカウントのメールアドレスにメールを送信します。アカウントが無効化されているメンバーには、メールは送信されません。
</Aside>
