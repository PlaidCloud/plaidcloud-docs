## SFTPサーバーのセットアップ

SFTPサーバーの管理者から、次の情報を入手してください。

1. SFTPサーバーの**ホスト名またはIPアドレス**
2. **SSHポート**（デフォルトは `22`）
3. 対象のディレクトリにアクセスできる**ユーザー名**
4. 認証用の**パスワード**または**SSH秘密鍵**のいずれか
5. 必要に応じて、厳格なホスト検証のための**サーバーのSSHホストキーのフィンガープリント**

これで、SFTPアカウントをPlaidCloud Documentに追加するために必要な情報がすべて揃いました。


## PlaidCloud Documentのセットアップ

1. PlaidCloudにサインインします
2. 新しいドキュメントアカウントを作成するワークスペースを選択します
3. `Document > Manage Accounts` に移動します
4. `+ New Account` ボタンを選択します
5. サービスタイプとして `Secure File Transfer (SFTP)` を選択します
6. 名前と説明を入力します
7. リモートディレクトリのパスを**開始パス**フィールドに入力します（例：`/data/uploads`）
8. 用途に合った**セキュリティモデル**を選択します。迷う場合は `Private` のままにします。
9. **ユーザー名**を、認証情報の下にあるPublic Key/Userフィールドに入力します
10. **パスワード**を、認証情報の下にあるPrivate Key/Passwordフィールドに入力します
11. **SSH構成**タブに移動します
12. SFTPサーバーの**ホストまたはIPアドレス**を入力します
13. **SSH接続ポート**を入力します（デフォルトは `22`）
14. パスワードではなく鍵ベースの認証を使用する場合は、**RSA秘密鍵**をRSA Private Keyフィールドに貼り付けます。秘密鍵を指定した場合は、パスワードよりも優先されます。保存した鍵は再表示されません。パスワード認証に戻すには、**保存されたキーをクリア（パスワードを使用）** を選択します。
15. 厳格なホストキー検証を行う場合は、**Remote Server RSA Fingerprint** を貼り付けます（任意）。空欄のままにすると、初回接続時に自動で入力されます。
16. 保存ボタンを選択すると、新しいドキュメントアカウントが有効になります

<Aside>保存する前に、SSH構成タブの**SSH接続をテスト**ボタンを使用して、SSH接続をテストできます。</Aside>
