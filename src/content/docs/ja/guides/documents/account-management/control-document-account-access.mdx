アカウントには、プライベート、ワークスペース、メンバーのみ、セキュリティグループの 4 種類のアクセス制限を設定できます。ユーザーに設定した制限の種類は、アカウントのフォームからいつでも編集できます。

<Aside>どのアクセスレベルでも、ドキュメントへのアクセスに使用するアカウントの認証情報は表示されません。認証情報を表示できるのは、アカウントの所有者とワークスペース管理者のみです。</Aside>

## アカウントアクセスの更新


1. PlaidCloud で `Document > Manage` を選択します
2. 変更するアカウントを開き、 **編集** を選択します
3. `Security Model` の下にあるアクセスレベルの制限を選択します
4. 保存ボタンを選択します

<Aside>選択した セキュリティモデル に応じて、 **管理** のアカウント行にある **Who can use it** メニュー、またはアカウントページの **アクセス** カードから、アクセスを許可するメンバーやセキュリティグループを割り当てるためのオプションが異なります。</Aside>


## 制限オプション


### すべてのワークスペースメンバー


このアクセスは、ワークスペースのすべてのメンバーにアクセスを付与し、メンバーの追加の割り当てが不要なため、最も簡単です。



### 特定のメンバーのみ


この設定では、各メンバーをアカウントに割り当てる必要があります。認証時に送信されるグループの一覧に基づいてメンバーを割り当てるシングルサインオンのオプションと組み合わせると、特に便利です。ただし、メンバー数の多いワークスペースでは、この方法では想定以上に手間がかかることが多く、そのような場合にセキュリティグループが役立ちます。特定のメンバーのみを選択するには、次の手順を実行します。


1. **管理** でアカウントの行メニューを開き、 **Who can use it** を選び、続けて **メンバー** を選択します
2. アクセスを許可するメンバーにチェックを入れ、許可しないメンバーのチェックを外します。フィルターボックスで人を検索したり、メールアドレスの一覧を貼り付けたりできます
3. **メンバーを更新** をクリックします

### 特定のセキュリティグループのみ


このオプションでは、個々のユーザーだけでなく、特定のセキュリティグループにアカウントへのアクセス権限を付与します。アクセス制限をセキュリティグループとの関連付けに基づかせることで、ユーザー数がはるかに多いアカウントの管理がずっと簡単になります。割り当てられたグループを編集するには、次の手順を実行します。


1. **管理** でアカウントの行メニューを開き、 **Who can use it** を選び、続けて **グループ** を選択します
2. アクセスを許可するグループにチェックを入れ、許可しないグループのチェックを外します
3. **グループを更新** をクリックします

### リモートエージェント


PlaidLink エージェントは、ファイルを保存したり、システム間でファイルを移動したりするために、ドキュメントアカウントをよく使用します。リモートエージェントがドキュメントアカウントにアクセスするには、エージェントに権限が付与されている必要があります。これは、機密性の高い可能性のある情報への不要なアクセスを制限するためのセキュリティ機能です。エージェントを追加するには、次の手順を実行します。


1. **管理** でアカウントの行メニューを開き、 **Who can use it** を選び、続けて **エージェント** を選択します
2. アクセスを許可するエージェントにチェックを入れ、許可しないエージェントのチェックを外します
3. **エージェントを更新** をクリックします

フィルター、メールアドレスの一覧の貼り付け、 **Will add** と **Will remove** のピル、その他のコントロールは、すべてのピッカーで共通です。[ピッカーを使った割り当て](/ja/administration/access/managing-security-groups-and-assignments/#ピッカーを使った割り当て)を参照してください。
