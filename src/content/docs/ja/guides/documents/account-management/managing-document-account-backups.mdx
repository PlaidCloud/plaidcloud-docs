ドキュメントは、アカウントのファイルを自動ではバックアップしません。たとえば別のクラウドプロバイダーのアカウントなどに、ファイルの2つ目のコピーを保管するには、ワークフローでコピーし、スケジュールを設定して実行します。

1. [Copy Document Directory](/ja/reference/workflow-steps/document/copy-document-directory/)ステップを含むワークフローを作成します。
2. **Copy Directory**で、バックアップするアカウントとフォルダーを選択します。
3. **Select Destination**で、コピー先のアカウントと、コピーを配置するフォルダーを選択します。
4. ワークフローを、たとえば毎晩実行されるようにスケジュールします。[ワークフローのスケジュール設定](/ja/get-started/tutorials/schedule-a-workflow/)をご覧ください。

複数のアカウントで1つのバックアップアカウントを共有できます。**Rename the Copied Folder to:** にチェックを入れ、コピー元のアカウントにちなんだ名前を付けて、それぞれのコピーに固有の名前を付けると、フォルダーが衝突しません。

<Aside type="caution">Copy Document Directory ステップは、コピー先に同じ名前のものがあると上書きします。そのため、実行のたびに前回のコピーが置き換えられ、コピーの履歴は残りません。</Aside>
