## 説明

**データプレビュードロワー**は、[ビジュアルワークフローデザイナー](/ja/guides/workflows/advanced-workflows/)の中で、ステップの入力テーブルまたは出力テーブルを直接表示します。キャンバスの下部にドッキングし、型付きでソート可能な列を持つ、**最初の100行**の読み取り専用グリッドです。編集の合間にさっと確認するために作られています。入力または出力のテーブルをクリックして中身を見たり、結合で期待どおりの列ができたか、フィルターが実際に機能したかを確かめたりして、そのまま作業を続けられます。確認のたびに、完全なテーブルエクスプローラーのウィンドウを開く必要はありません。

<Aside type="note">ドロワーでプレビューできるのは、すでに存在するデータです。ステップがまだ出力テーブルを生成していない場合、ドロワーには*「No data yet — run the step to generate this table」*と表示されます。ステップを実行すると、プレビューが表示されます。</Aside>

## プレビューを開く

開き方は4通りあり、いずれも同じドロワーが開きます。

- **ステップのタイルにカーソルを合わせる** — タイルの右下隅に、小さな参照（テーブル）アイコンが表示されます。これをクリックします。
- **ステップを右クリック**して、**出力データをプレビュー**を選択します。
- **インスペクター**で、ステップの**入力**または**出力**セクションにある任意のカードの**目のアイコン**をクリックして、そのテーブルをプレビューします。
- **ステップのタイル**で、タイルの**入力**または**出力**の帯にあるテーブルアイコンをクリックします（ディメンションのアイコンは引き続きディメンションを開き、ファイルのアイコンは引き続きファイルをダウンロードします）。

ドロワーはキャンバスの下にドッキングします。特定のテーブルをクリックした場合はそのテーブルが表示され、そうでない場合はステップの最初のテーブル出力が読み込まれます。

## ステップ間を移動する

ドロワーを開いている間は、**ほかのステップをクリックすると、プレビューがそのステップの出力に切り替わります**。1ステップにつき1クリックです。ステップの連鎖を順にクリックしていくと、各段階でデータの形が変化する様子を確認できます。

ドロワーを閉じるには、ヘッダーの **✕** をクリックするか、**Esc** を押します（ステップが選択されている場合、最初の Esc でドロワーが閉じ、次の Esc で選択が解除されます）。

## ドロワーのヘッダー

ヘッダーには、表示している内容が正確にわかる情報が表示されます。

- **テーブル名**と**Showing first N of ~M rows** — エンジンが合計行数を概算値として報告する場合は、チルダが表示されます。
- **列数**。
- **テーブルセレクター** — プレビューするテーブルを選択します。複数のテーブルを書き込むステップでは、各出力が一覧表示され、最初のものが事前に選択されます。入力をプレビューした場合は、出力より前のリストの先頭に表示されて事前に選択されます。そこから任意の出力に切り替えられます。
- **更新** — プレビューを必要なときに再取得します。
- **テーブルエクスプローラーで開く** — ドロワーに表示中のテーブルを、ワンクリックで完全なエクスプローラーに引き上げます（後述）。
- **✕** — ドロワーを閉じます。

## 実行のたびに最新の状態になる

プレビュー中のステップがドロワーを開いたまま実行されると、実行の完了時にプレビューが**自動的に1回更新**されます。そのため、**このステップを実行**したあとは、ドロワーにはすでに新しいデータが、表示していたものと同じテーブル（入力を含む）で表示されます。出力が変わっていないステップに戻ったときは、再取得せずにそのプレビューが開きます。

## さらに必要なとき: テーブルエクスプローラー

プレビューは意図的にさっと確認するためのもので、作業台ではありません。編集、フィルター、ダウンロードはできません。これらが必要な場合は、ドロワーのヘッダーで**テーブルエクスプローラーで開く**をクリックすると、同じテーブルが、あらゆる機能を備えた完全な[テーブルエクスプローラー](/ja/guides/data/table-explorer/)で開きます。

このボタンが必要になるのは、次の2つの場合です。

- **列数の多いテーブル** — ドロワーには**最初の150列**が表示され、残りはテーブルエクスプローラーで利用できることが示されます。
- **詳しい調査** — 最初の100行を超える内容や、スライスやフィルターが必要な場合です。

## 表示するものがないときのドロワー

- **This step has no table outputs** — ステップがテーブルではなくファイルやディメンションを書き込んでいて、テーブルをクリックせずにプレビューを開いた場合です。入力テーブルをクリックすれば、引き続きプレビューできます。
- **No data yet — run the step to generate this table** — 出力テーブルがまだ作成されていません。ステップを実行してください。
- **Table is empty** — テーブルは存在しますが、行が0件です。
