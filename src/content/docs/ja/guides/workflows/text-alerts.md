ワークフローは、[Notify Via SMS](/ja/reference/workflow-steps/notifications/notify-via-sms/)ステップを使って、対応が必要なときにテキストメッセージで通知できます。ワークフローがあなたにテキストを送信できるのは、あなた自身がオプトインした後のみです。

## テキストアラートをオンにする

1. 右上のユーザーメニューを開き、**テキストアラート**を選択します。
2. **米国の携帯電話番号**を入力します。
3. **この番号でPlaidCloudのワークフローのテキストアラートを受信することに同意します。**にチェックを入れます。その上に表示されている開示事項と、**SMS Terms**および**SMS Privacy Policy**のリンクをお読みください。
4. **コードを送信**をクリックします。PlaidCloudが6桁のコードを、あなたの番号にテキストで送信します。テキストが届くまでに1～2分かかることがあります。
5. 10分以内に**確認コード**を入力し、**確認**をクリックします。

コードを送信すると、ボタンは60秒間カウントダウンした後、**コードを再送信**と表示されます。コードがまだ有効なうちに再送信すると、同じコードがテキストで送信されるため、どちらのテキストが届いても使用できます。コードのリクエストは、電話番号ごとに1日3回、1人あたり1時間に3回までです。

その後、ウィンドウには、マスクされた番号とともに**テキストアラートはオンです**と表示されます。サポートされているのは米国の携帯電話番号のみです。メッセージおよびデータ通信料がかかる場合があり、メッセージの頻度は変動します。

## テキストアラートをオフにする

**テキストアラート**を開いて**テキストアラートを停止**をクリックするか、任意のテキストに**STOP**と返信します。ヘルプが必要な場合は**HELP**と返信してください。

## STOPの後で再びオンにする

STOPと返信すると、あなたの番号へのすべてのテキストがブロックされます。ウィンドウに表示されているアラート番号に**START**とテキストを送信し、その後、新しいコードを送信して確認してください。

## 問題が発生した場合

| メッセージ | 対応 |
|---|---|
| That code is not right | テキストを確認して、もう一度コードを入力してください。 |
| That code has expired | **コードを送信**をクリックして、新しいコードを取得してください。 |
| Too many wrong codes | 誤ったコードを5回入力した後は、**コードを送信**をクリックして、新しいコードを取得してください。 |
| Enter a valid US mobile number | 10桁の米国の携帯電話番号を使用してください。 |
| Too many requests | コードの上限に達しました。数分待ってから、もう一度お試しください。 |
| Text alerts are not available for your workspace right now | 後でもう一度お試しください。 |

健康に関する個人データや財務に関する個人データには、テキストアラートを使用しないでください。お問い合わせ：support@plaidcloud.com。
