このチェックリストは、Alteryx ワークフローを PlaidCloud にインポートする前にご利用ください。パッケージが完全であれば、PlaidCloud は高度なワークフロー、マクロワークフロー、Document に保存される依存関係、制御された実行時入力を、最小限の追加作業で作成できます。

<Aside type="note">
  大規模なポートフォリオの場合は、ポートフォリオ全体に対してこのチェックリストを1回実施し、さらに優先度の高いワークフローファミリーごとにもう一度実施してください。
</Aside>

## ワークフローファイルを収集する

移行の対象となるすべてのワークフローファイルを収集します。

1. 標準ワークフロー: `.yxmd`。
2. 分析アプリ: `.yxwz`。
3. マクロ: `.yxmc`。
4. 他のワークフローから参照されている、入れ子または共有のマクロ。
5. 本番環境で現在も使用されているワークフローのバージョン。

ワークフローとマクロが相互に呼び出し合う場合は、関連するものをまとめて保管してください。PlaidCloud は、これらの関係を利用してマクロワークフローを生成し、マクロの入力ポートと出力ポートを接続します。

## データの依存関係を収集する

ワークフローが読み取り、書き込み、または参照するファイルをパッケージにまとめます。

- CSV、TSV、固定幅、JSON、XML、Excel、Access、YXDB、およびデータベース抽出ファイル。
- Directory ツールまたは Dynamic Input ツールで使用されるフォルダー。
- 検証用の期待される出力ファイル。
- 画像、PDF、テンプレート、マップレイヤーなどのレポート用アセット。
- 結合、数式、置換、照合で使用されるルックアップテーブルとルールテーブル。

ワークフローがローカルのデスクトップパスを参照している場合は、そのファイルまたはフォルダーをインポートパッケージに含め、PlaidCloud がそれを保存する Document のパスを選択してください。

## 空間データのサイドカーファイルを収集する

空間ファイル形式では、複数のファイルをまとめて保管しておく必要があることがよくあります。すべてのサイドカーファイルを同じフォルダーに含めてください。

- `.shp`、`.shx`、`.dbf`、`.prj` などのシェイプファイルのグループ。
- `.tab`、`.map`、`.id`、`.dat` などの MapInfo のグループ。
- KML、GeoJSON、およびその他の単独の空間ファイル。
- ワークフローで使用される投影法または座標参照系のファイル。

サイドカーファイルの欠落は、空間データの検証で差異が生じる一般的な原因です。

## 実行時入力を記録する

分析アプリでは、ユーザーが通常指定する値を記録します。

1. テキスト、数値、日付、ファイル、フォルダーの入力。
2. ドロップダウン、ラジオボタン、チェックボックス、リスト、ツリーでの選択。
3. スケジュール実行や繰り返し実行で使用するデフォルト値。
4. 条件、警告、エラーのトリガーとなる値。

PlaidCloud は、これらの入力を制御されたワークフロー変数に変換します。

## ターゲットの場所を決める

インポートの前に、次の項目を決めておきます。

1. ターゲットとなる PlaidCloud のプロジェクト。
2. ターゲットとなる Document アカウント。
3. インポートしたファイルを保存する、ターゲットの Document フォルダー。
4. 変換後のワークフローとマクロの命名規則。
5. 最初のインポートをステージング用にするか、本番用にするか。

ポートフォリオ全体の移行では、依存関係を監査しやすいように、Document に移行専用のフォルダーを用意してください。

## 検証の根拠を選択する

ワークフローごとに、検証レベルを選択します。

- 構造検証では、ワークフローが実行可能な PlaidCloud の DAG に変換されることを確認します。
- 出力の同一性検証では、スキーマ、行数、行の値を、信頼できる Alteryx の出力と比較します。
- アーティファクト検証では、レポート、PDF、画像、チャート、マップ、モデルの出力を確認します。

出力の同一性が必要な場合は、期待される出力を移行パッケージと一緒に保管してください。

## インポート準備チェックリスト

インポートの前に、次の項目を確認します。

- ワークフロー、アプリ、マクロのファイルがそろっている。
- 参照されているマクロがそろっている。
- 入力ファイルとフォルダーがそろっている。
- 空間データのサイドカーファイルがまとめられている。
- 移行計画に同一性検証が含まれる場合は、期待される出力が用意されている。
- 分析アプリの実行時入力の値が把握されている。
- ターゲットのプロジェクトと Document のパスが選択されている。
- ワークフローに必要な認証情報や外部接続が PlaidCloud で利用できる。
