PlaidCloud の AI アシスタントである Weave は、アプリの中でも使えます。ワークスペースについて質問したり、実行が失敗した理由を調べたり、修正をスマートフォンから承認したりできます。会話は Web 版の PlaidCloud での会話と同じものなので、一方で始めて、もう一方で続けることができます。

## 始める前に

- **アプリをバージョン 1.3.0 以降に更新します。**
- **Weave を利用できる必要があります。** Web 版と同じ Weave へのアクセス権が必要です。ない場合は、**Weave** タブにその旨が表示されます。
- **初回に AI に関する通知に同意します。** [プライバシーと同意](#プライバシーと同意)を参照してください。

## Weave に質問する

1. **Weave** タブを開きます。
2. 「*今日、何が失敗しましたか？*」などの質問を入力して送信します。

回答は、Weave が書き進めるのに合わせて少しずつ表示されます。途中で終了するには**停止**をタップします。回答の下にある高評価または低評価のアイコンをタップすると、回答が役に立ったかどうかをお知らせいただけます。共有アイコンを使うと、回答を共有できます。

Weave が、ある内容の根拠となるステップ、実行、ワークフローを挙げている場合は、回答の下にあるリンクをタップすると開きます。

### 今いる場所から質問する

ワークフロー、実行、失敗したステップの **Ask Weave** をタップすると、Weave はその項目をコンテキストとして開始します。失敗した実行では、「**Why did this run fail?**」や「**How do I fix it?**」を試してみてください。

### 会話を再開する

時計のアイコンをタップすると、保存した会話が表示されます。会話は Web 版の PlaidCloud と共有されます。リストから会話を検索したり、開いたり、名前を変更したり、削除したりできます。削除すると、Web 版からも削除されます。

## Weave の変更を承認する

Weave が自分から何かを変更することはありません。Weave が変更を提案すると、承認カードに、何が行われるか、どの項目が影響を受けるか、元に戻せるかどうかが表示されます。

1. カードを読みます。
2. **承認**をタップし、Face ID、Touch ID、指紋認証、またはデバイスのパスコードで確認します。元に戻せない変更では、先に確認を求められます。提案を破棄するには**却下**をタップします。

確認した後にはじめて、Weave は変更を行い、結果を報告します。Weave が変更を提案した後で何かが変わっていた場合、Weave は実行を拒否し、もう一度確認するよう求めます。

PlaidCloud はサーバー側で承認を確認するため、カードを飛ばすことはできません。Web 版の PlaidCloud での Weave の変更にも、同じ仕組みが適用されます。

## 音声を使う

- **質問を音声で入力する。** マイクをタップして質問を話します。話し終えて約 2 秒の間があくと、Weave が自動的に送信します。途中で止めるには、もう一度マイクをタップします。約 8 秒間何も聞き取れない場合は、マイクがオフになります。
- **話の途中で離れても、何も送信されません。** 話している間に **Weave** タブを離れたり、アプリをバックグラウンドに移したりすると、Weave は聞き取った言葉を送信せずに質問ボックスに残します。送信前に内容を確認できます。
- **音声はスマートフォンの外に出ません。** 音声認識はデバイス上で実行されます。初回は、**マイク**と**音声認識**を許可してください。
- **回答を聞く。** 音声で質問した場合、Weave は回答の短い要約を読み上げます。

## Siri とショートカット

<Aside type="note">
Siri は、AI に関する通知に同意した後、iPhone と iPad で利用できます。デバイスがロックされている場合、Siri はまずロックの解除を求めます。
</Aside>

- 「**What failed in PlaidCloud**」と言うと、Siri が最近の失敗の要約を読み上げます。
- 「**Weave in PlaidCloud**」と言うと、Siri が質問を尋ね、Weave の回答を読み上げます。Siri の回答は読み取り専用です。この方法では、Weave は変更を提案しません。

どちらも**ショートカット**アプリで利用できます。

Android では、アプリのアイコンを長押しして **Ask Weave** をタップすると、質問を入力できる状態で Weave が開きます。

## 通知を受け取る

Weave が作業している間にアプリを離れた場合、回答の準備ができると通知でお知らせします。通知をタップすると回答が開きます。通知には、ワークフロー名や回答のテキストは含まれません。

<Aside type="note">
回答の通知は、iPhone と iPad で利用できます。
</Aside>

## Weave の検出事項とデイリーダイジェスト

**ホーム**タブには **Weave findings** が表示されます。これは、最近のプロジェクトで Weave が見つけた、対応が必要な問題です。タップすると開きます。

毎日の要約を受け取るには、**設定**を開いて **Daily Weave digest** をオンにします。デフォルトではオフです。ダイジェストは、件数のみを記載した 1 件の通知です。

## プライバシーと同意

Weave を初めて開くと、**Before you use Weave** というタイトルの通知が表示されます。そこには、あなたの質問と、Weave が回答に必要とするワークスペースの情報が、PlaidCloud の AI プロバイダーに送信され、PlaidCloud に代わって処理されることが説明されています。Weave を使うには **Agree and continue** をタップします。[PlaidCloud のプライバシーポリシー](https://plaidcloud.com/privacy-policy/)にはプロバイダー名とデータの扱い方が記載されており、[Weaveによるお客様のデータの利用について](/ja/guides/ai-assistant/weave-data-use/)には、各プロバイダーがそのデータに対して何を行えるかが記載されています。

同意を撤回するには、**設定**を開いて **Withdraw AI consent** をタップします。再び同意するまで、Weave、Siri、Weave の通知は停止します。
