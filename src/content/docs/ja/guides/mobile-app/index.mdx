PlaidCloud アプリを使うと、席を離れていてもワークフローを実行し、監視できます。
プロジェクトを閲覧し、ワークフローを開始したり、実行中のワークフローを停止したりできます。各ステップの状態や、実行履歴も確認できます。アプリで
Weave を使えば、何が失敗したかを尋ねて、修正を承認することもできます。
[モバイルでの Weave](/ja/guides/mobile-app/weave-on-mobile/)を参照してください。

このアプリは、ブラウザーで使う PlaidCloud を補完するもので、独立した製品ではありません。
ワークフロー、テーブル、ダッシュボードの構築は Web で行い、アプリはそれらを稼働させ続けるために使います。

## 始める前に

- **既存の PlaidCloud ワークスペースと、そこでのアカウント。** アプリにはサインアップ機能がありません。ワークスペースの管理者が、通常どおり Web 上でワークスペースにあなたを追加します。
- **ワークスペース名。** ブラウザーで使うアドレスの最初の部分です。`acme.plaid.cloud` の場合、ワークスペース名は `acme` です。
- **対応デバイス：**

| デバイス | 最小バージョン |
| --- | --- |
| iPhone と iPad | iOS または iPadOS 15.1 |
| Android スマートフォンまたはタブレット | Android 7.0 |

## アプリをインストールする

お使いのデバイスのアプリストアで **PlaidCloud** を検索するか、ストアのページを直接開きます。

- **iPhone と iPad：** [App Store の PlaidCloud](https://apps.apple.com/app/id6769620647)
- **Android：** [Google Play の PlaidCloud](https://play.google.com/store/apps/details?id=com.plaidcloud.mobile)

アプリは無料です。

## サインインする

1. アプリを開きます。最初の画面で**ワークスペース**の入力を求められます。
2. `acme` などのワークスペース名を入力し、**続行**をタップします。iPhone と iPad では、`https://acme.plaid.cloud/` のようなワークスペースのアドレス全体を貼り付けることもできます。アプリはワークスペース名だけを使用します。
3. ワークスペースのサインインページが開きます。ブラウザーで表示されるものと同じページなので、いつもの方法でサインインします。パスワードと多要素認証コードを使うか、ワークスペースで組織のシングルサインオンを使っている場合はそれを使います。
4. サインインが完了すると、アプリに戻ります。

セッションをまたいでサインインしたままになります。アプリはバックグラウンドでサインインを更新します。認証情報を入力するのはワークスペース自身のサインインページだけで、アプリ内では入力しません。アプリはワークスペースに対して OpenID Connect と PKCE でサインインし、取得したトークンをデバイスのセキュアストレージに保存します。

サインインが始まらない場合や、その名前のワークスペースがないとアプリに表示された場合は、ブラウザーで使っているアドレスと照らして、ワークスペース名のつづりを確認してください。

<Aside type="note">
アプリは一度に 1 つのワークスペースにサインインします。別のワークスペースを使うには、**設定**から切り替えます（[ワークスペースを切り替える、またはサインアウトする](#ワークスペースを切り替えるまたはサインアウトする)を参照）。
</Aside>

## ワークフローを探す

**プロジェクト**タブには、アクセスできるプロジェクトが、各プロジェクトの説明とともに表示されます。リストを下に引っ張ると更新されます。

プロジェクトをタップすると、フォルダーごとにグループ化されたワークフローが表示されます。各ワークフローには、現在の状態（**実行中**、**キュー待ち**、**一時停止中**、**完了**、**エラー**、**停止済み**など）、説明、前回の実行が終了した時刻が表示されます。画面上部の **Search workflows** を使うと、ワークフローの名前や説明でリストを絞り込めます。

iPhone と iPad では、アプリは**ホーム**タブでも開きます。**要対応**には、前回の実行が失敗したワークフローがエラーメッセージとともに一覧表示され、**最近使用**には、最近使ったプロジェクトが一覧表示されます。どちらもタップすると、そこへ直接移動できます。

## ワークフローを実行して監視する

ワークフローをタップして開きます。画面の上部にはワークフローの状態と、**ステータス**パネルが表示されます。パネルには、現在または前回の実行の**開始日時**と**終了日時**、**所要時間**、最新の**メッセージ**が表示されます。ワークフローがエラーになっている場合、エラーメッセージが赤で表示されます。ワークフローが実行中またはキュー待ちの間は、画面の状態が自動的に最新に保たれます。

画面下部のコントロールは、ワークフローの状態によって変わります。

| ワークフローの状態 | コントロール |
| --- | --- |
| 実行中またはキュー待ち | **一時停止**、**停止** |
| それ以外 | **実行**、**再開** |

- **実行**は、ワークフローを最初から開始します。
- **一時停止**は、実行中のワークフローを保留します。**再開**は、止まった位置から続行します。失敗したステップを修正した後でワークフローを続行するときも、**再開**を使います。
- **停止**は、実行を終了します。

どのコントロールも、操作の前に確認を求めます（例：**Run this workflow?**）。確認画面で誤って 2 回タップしても無視されるため、操作は 1 回だけ実行されます。

コントロールの下にある**構成**には、ワークフローが有効かどうか、ロックされているかどうか、エラーの扱いが表示されます。**詳細**には、フォルダーと最終更新者が表示されます。

<Aside type="note">
アプリには、Web 版の PlaidCloud と同じ権限が適用されます。ワークフローの実行や変更が許可されていない場合、アプリは理由とともに**アクションに失敗しました**と表示し、何も変更されません。
</Aside>

## ワークフローのステップを表示する

ワークフローの**ステップ**をタップすると、すべてのステップが、状態、種類、最新のメッセージとともに表示されます。実行されないステップには**無効**バッジが、入れ子のワークフローを実行するステップには **Sub-workflow** バッジが表示されます。

リストの表示方法は、ワークフローの種類によって異なります。

- **グラフとして構築されたワークフロー**では、ステップが実行順に表示されます。左側の線で、どのステップがどのステップにつながるかが示され、並行して実行されるステップも確認できます。
- **ステップのリストとして構築されたワークフロー**では、ステップが順番に表示され、各ステップが入っているフォルダーも表示されます。

## 過去の実行を振り返る

ワークフローの**実行履歴**をタップすると、最近の実行が表示されます。各実行には、開始時刻、終了状態、所要時間、実行したステップ数が表示されます。

iPhone と iPad では、実行をタップすると、その実行で発生したステップのエラーと、ログの最後の 200 行が表示されます。各行には、時刻、レベル、ステップが含まれます。

## 名前、説明、設定を編集する

コンピューターに戻らなくても、小さな変更を行えます。

- プロジェクトまたはワークフローでは、画面上部の**編集**をタップします。
- ステップでは、**ステップ**リストでそのステップをタップします。

**編集**シートでは、**名前**と**説明**を変更したり、**Enabled** と **Locked** のオンとオフを切り替えたりできます。変更を適用するには**保存**を、破棄するには**キャンセル**をタップします。ステップの設定の変更、ステップの追加、ワークフローの並べ替えなど、それ以上の操作は Web 版の PlaidCloud で行います。

## ワークスペースを切り替える、またはサインアウトする

**設定**タブを開きます。**現在のワークスペース**には、サインインしているワークスペースが表示されます。

- **Switch workspace** は、現在のワークスペースからサインアウトし、**ワークスペース**画面に戻ります。そこで別のワークスペースにサインインできます。
- **サインアウト**は、ワークスペースからサインアウトします。

どちらも、最初に確認を求められます。

<Aside type="note">
現在の Android リリースには、**プロジェクト**タブと**設定**タブがあります。**ホーム**タブと、エラーやログ行を含む実行の詳細は、iPhone と iPad のアプリにあります。
</Aside>
