PlaidCloudアプリを使用すると、デスクを離れていてもワークフローを実行して監視できます。プロジェクトの参照、ワークフローの開始や実行中のワークフローの停止、各ステップの状態の確認、実行履歴の振り返りができます。アプリでWeaveを使うと、何が失敗したかを尋ねて、修正を承認することもできます。[モバイルでのWeave](/ja/guides/mobile-app/weave-on-mobile/)を参照してください。

このアプリは、ブラウザー上のPlaidCloudを補完するもので、別の製品ではありません。ワークフロー、テーブル、ダッシュボードはWebで構築し、アプリはそれらを稼働させ続けるために使用します。

## 開始する前に

- **既存のPlaidCloudワークスペースと、そのワークスペース内のアカウント。** アプリにはサインアップ機能がありません。通常どおり、ワークスペースの管理者がWebでワークスペースにあなたを追加します。
- **ワークスペース名。** ブラウザーで使用するアドレスの先頭部分です。`acme.plaid.cloud` の場合、ワークスペース名は `acme` です。
- **サポートされているデバイス：**

| デバイス | 最小バージョン |
| --- | --- |
| iPhoneとiPad | iOSまたはiPadOS 15.1 |
| AndroidスマートフォンまたはAndroidタブレット | Android 7.0 |

## アプリのインストール

お使いのデバイスのアプリストアで **PlaidCloud** を検索するか、次のリンクから直接開きます。

- **iPhoneとiPad：** [App StoreのPlaidCloud](https://apps.apple.com/app/id6769620647)
- **Android：** [Google PlayのPlaidCloud](https://play.google.com/store/apps/details?id=com.plaidcloud.mobile)

アプリは無料です。

## サインイン

1. アプリを開きます。最初の画面で**ワークスペース**の入力を求められます。
2. `acme` などのワークスペース名を入力し、**続行**をタップします。iPhoneとiPadでは、`https://acme.plaid.cloud/` のようなワークスペースのアドレス全体を貼り付けることもできます。アプリはワークスペース名のみを保持します。
3. ワークスペースのサインインページが開きます。ブラウザーで表示されるものと同じページなので、いつもの方法でサインインします。パスワードと多要素認証コードを使用するか、ワークスペースで組織のシングルサインオンを使用している場合はそれを使用します。
4. サインインが完了すると、アプリに戻ります。

セッションをまたいでサインインした状態が維持され、アプリはバックグラウンドでサインインを更新します。認証情報を入力するのはワークスペース自身のサインインページのみで、アプリ自体には入力しません。アプリは、ワークスペースに対してOpenID ConnectとPKCEでサインインし、取得したトークンをデバイスのセキュアストレージに保存します。

サインインが開始されない場合や、その名前のワークスペースがないとアプリに表示される場合は、ワークスペース名のスペルを、ブラウザーで使用しているアドレスと照らし合わせて確認してください。

<Aside type="note">
アプリは一度に1つのワークスペースにサインインします。別のワークスペースを使用するには、**設定**から切り替えます（[ワークスペースの切り替えまたはサインアウト](#ワークスペースの切り替えまたはサインアウト)を参照）。
</Aside>

## ワークフローの検索

**プロジェクト**タブには、アクセスできるプロジェクトが、各プロジェクトの説明とともに一覧表示されます。リストを下に引っ張ると更新されます。

プロジェクトをタップすると、そのワークフローがフォルダーごとにグループ化されて表示されます。各ワークフローには、現在の状態（**実行中**、**キュー待ち**、**一時停止中**、**完了**、**エラー**、**停止済み**など）、説明、直近の実行が終了した日時が表示されます。上部の **Search workflows** を使用して、ワークフローの名前または説明でリストを絞り込みます。

iPhoneとiPadでは、アプリは**ホーム**タブでも開きます。**要対応**には、直近の実行が失敗したワークフローがエラーメッセージとともに表示され、**最近使用**には、最近使ったプロジェクトが表示されます。どちらもタップすると、そこに直接移動します。

## ワークフローの実行と監視

ワークフローをタップして開きます。画面の上部には、ワークフローの状態と、現在または直近の実行の**開始日時**と**終了日時**、**所要時間**、最新の**メッセージ**を示す**ステータス**パネルが表示されます。ワークフローがエラー状態の場合は、エラーメッセージが赤色で表示されます。ワークフローが実行中またはキュー待ちの間、画面は状態を自動的に最新に保ちます。

画面下部のコントロールは、ワークフローの状態によって変わります。

| ワークフローの状態 | コントロール |
| --- | --- |
| 実行中またはキュー待ち | **一時停止**、**停止** |
| それ以外 | **実行**、**再開** |

- **実行**は、ワークフローを最初から開始します。
- **一時停止**は実行中のワークフローを保留し、**再開**は停止した位置から続行します。失敗したステップを修正したあとにワークフローを続行するには、**再開**を使用します。
- **停止**は、実行を終了します。

各コントロールは、動作する前に確認を求めます。たとえば、**Run this workflow?** ダイアログが表示されます。

コントロールの下の**構成**には、ワークフローが有効かどうか、ロックされているかどうか、エラーの処理方法が表示され、**詳細**には、フォルダーと最終更新者が表示されます。

<Aside type="note">
アプリは、Web上のPlaidCloudと同じ権限を使用します。ワークフローの実行や変更が許可されていない場合、アプリは理由とともに**アクションに失敗しました**と表示し、何も変更されません。
</Aside>

## ワークフローのステップの表示

ワークフローの**ステップ**をタップすると、すべてのステップが、状態、種類、最新のメッセージとともに表示されます。実行されないステップには**無効**バッジが表示され、入れ子になったワークフローを実行するステップには **Sub-workflow** バッジが表示されます。

リストのレイアウトは、ワークフローの種類によって異なります。

- **グラフとして構築されたワークフロー**では、ステップが実行順に表示されます。左側の線によって、どのステップがどのステップにつながるか（並行して実行されるステップを含む）がわかります。
- **ステップのリストとして構築されたワークフロー**では、ステップが順番に表示され、各ステップが属するフォルダーも表示されます。

## 過去の実行の振り返り

ワークフローの**実行履歴**をタップすると、最近の実行が表示されます。各実行には、開始日時、終了の状態、所要時間、実行したステップ数が表示されます。

iPhoneとiPadでは、実行をタップすると、その実行で発生したステップのエラーと、ログの最後の200行が、それぞれの時刻、レベル、ステップとともに表示されます。

## 名前、説明、設定の編集

パソコンに戻らなくても、ちょっとした変更を加えられます。

- プロジェクトまたはワークフローでは、画面上部の**編集**をタップします。
- ステップでは、**ステップ**リストでそのステップをタップします。

**編集**シートでは、**名前**と**説明**の変更、**有効**と**Locked**のオンとオフの切り替えができます。**保存**をタップして変更を適用するか、**キャンセル**をタップして破棄します。ステップの設定の変更、ステップの追加、ワークフローの並べ替えなど、それ以上の操作は、Web上のPlaidCloudで行います。

## ワークスペースの切り替えまたはサインアウト

**設定**タブを開きます。**現在のワークスペース**には、サインインしているワークスペースが表示されます。

- **Switch workspace** は、現在のワークスペースからサインアウトし、**ワークスペース**画面に戻って別のワークスペースにサインインできるようにします。
- **サインアウト**は、ワークスペースからサインアウトします。

どちらも、先に確認を求められます。

<Aside type="note">
現在のAndroid版には、**プロジェクト**タブと**設定**タブがあります。**ホーム**タブと、エラーやログの行を含む実行の詳細は、iPhoneとiPad版のアプリにあります。
</Aside>
