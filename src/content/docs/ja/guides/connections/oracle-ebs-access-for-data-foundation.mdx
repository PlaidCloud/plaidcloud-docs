[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP システムとインスタンスのデータを 1 つの Common Finance Model に集約します。Oracle E-Business Suite は、Data Foundation が直接読み取る ERP の 1 つです。PlaidCloud は、ネットワーク内にインストールされた [PlaidLink](/ja/reference/cli/plaidlink/) エージェント経由で EBS にアクセスし、直接接続することはありません。このページは、これを設定する EBS 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードをメールで送らないでください。

## アクセス依頼を送信する

プロジェクトの **Foundation** タブで、**Oracle E-Business Suite接続**の下にある**新しい接続を作成**を選択します。フォームに依頼内容の全文と、**How to set up PlaidLink** リンクが表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「Read-only Oracle E-Business Suite access for PlaidCloud (through PlaidLink)」でメールプログラムに開きます。

## EBS 管理者が設定する内容

<Steps>

1. EBS データベースにアクセスできるサーバーに **PlaidLink をインストール**し、PlaidCloud に登録します。

2. PlaidLink の APPS スキーマユーザー（または APPS オブジェクトへのシノニムを持つ読み取り専用スキーマユーザー）に、次のオブジェクトへの **SELECT を付与**します。

   | 領域 | オブジェクト |
   |---|---|
   | 総勘定元帳 | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS`, `GL_CODE_COMBINATIONS`, `GL_PERIODS`, `GL_PERIOD_STATUSES`, `GL_JE_HEADERS`, `GL_JE_LINES`, `GL_BALANCES`, `GL_DAILY_RATES` |
   | フレックスフィールド | `FND_ID_FLEX_SEGMENTS`, `FND_SEGMENT_ATTRIBUTE_VALUES`, `FND_FLEX_VALUES_VL`, `FND_FLEX_VALUE_NORM_HIERARCHY` |
   | 売上（省略可） | `RA_CUSTOMER_TRX_ALL`, `RA_CUSTOMER_TRX_LINES_ALL`, `RA_CUST_TRX_TYPES_ALL`, `RA_CUST_TRX_LINE_GL_DIST_ALL`, `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`, `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B` |

3. レポート対象のすべての元帳と残高セグメント値を参照できる**アプリケーションユーザー**（`FND_USER`）と責任を指定します。

4. **勘定科目表を記述します。** どのセグメントが残高セグメント、自然勘定科目、コストセンター、会社間セグメントにあたるか（それぞれのセグメント修飾子）を伝えます。PlaidCloud は、費用勘定科目またはその上位の親値が売上原価、売上コスト、収益原価と記述されている場合に、その勘定科目を売上原価として分類します。また、そのいずれかに受取利息または支払利息、金融収益または金融費用、外国為替、法人所得税費用、その他の収益および費用が含まれている場合に、その勘定科目を営業外として分類します。親値でこれらに別の用語を使用している場合は、PlaidCloud に伝えてください。

5. **レートタイプを確認します。** 各プライマリ元帳は、元帳の換算オプションで、期間平均と期間末のレートタイプを指定しています。PlaidCloud は、この 2 つのタイプの日次レートで換算します。

</Steps>

<Aside type="caution">
責任が正しくないと、エラーなしに別の元帳の行が返されます。総勘定元帳の担当者に確認してください。
</Aside>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| データベースホスト | **Database host** |
| データベースのポート | **データベースのポート**（変更しない限り 1521） |
| サービス名 | **サービス名** |
| APPS スキーマユーザー | **APPS schema user** |
| APPS スキーマのパスワード（セキュアな接続フォーム経由） | **APPS schema password**。チームが自分で貼り付けます |
| `FND_USER` | **Application user (FND_USER)** |
| 責任キー | **Responsibility key** |
| PlaidCloud が読み取りを許可される残高セグメント値 | **Balancing segment values** に入力します。ロード前にシステムが一覧表示できないため、**名前**に 1 つの値を入力するか、空白のままにしてプライマリ元帳のすべてのエンティティをロードします |

インスタンスにアクセスする PlaidLink エージェントは、システム設定の `agent` で選択します。

<Aside type="caution">
パスワードをメールで送らないでください。**APPS schema password** はシークレットです。接続に保存され、再表示されません。
</Aside>

## アクセスを確認する

PlaidCloud に戻って値を入力し、**接続をテスト**をクリックします。各データセットは、**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示されます。

| データセット | 読み取るオブジェクト |
|---|---|
| エンティティ | `GL_LEDGERS`, `GL_LEDGER_NORM_SEG_VALS` |
| 会計カレンダー | `GL_PERIODS`, `GL_PERIOD_STATUSES` |
| 勘定科目表 | `GL_CODE_COMBINATIONS`、フレックスフィールドのテーブル |
| 部門 | `GL_CODE_COMBINATIONS`、フレックスフィールドのテーブル |
| 為替レート | `GL_DAILY_RATES` |
| 総勘定元帳 | `GL_JE_HEADERS`, `GL_JE_LINES` |
| 試算表 | `GL_BALANCES` |
| 顧客 | `HZ_CUST_ACCOUNTS`, `HZ_PARTIES`（省略可） |
| 製品 | `MTL_PARAMETERS`, `MTL_SYSTEM_ITEMS_B`（省略可） |
| 売上明細 | `RA_CUSTOMER_TRX` テーブル（省略可） |

データセットが**権限が不足しています**と表示された場合は、管理者にそのオブジェクトへの SELECT の付与を依頼して、もう一度テストしてください。顧客、製品、売上明細は省略可能です。これらを使用しないインスタンスでも、ほかのすべてのデータは読み込まれます。
