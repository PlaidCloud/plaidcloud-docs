[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべてのシステムのデータを、インスタンスの数に関係なく、1 つの Common Finance Model に集約します。Salesforce は、Data Foundation が直接読み取るシステムの 1 つです。Salesforce は元帳ではなく CRM ソースであり、顧客、製品、営業パイプライン、営業担当者、キャンペーン、会計月、受注を提供しますが、総勘定元帳の仕訳は提供しません。このページは、アクセスを設定する Salesforce 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードやセキュリティトークンをメールで送らないでください。

## アクセス依頼を送信する

**ホーム**の **Data Foundation** にあるプロジェクトの**システム**ページで、**システムを追加**の**システム**でお使いのシステムを選択し、**まだアクセス権がありませんか?** ボタンをクリックします。システムはアクセス待ちになり、プロジェクトのシステムを対象とする 1 件の依頼が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「PlaidCloud へのアクセス」でメールプログラムに開きます。

## Salesforce 管理者が設定する内容

<Steps>

1. **Setup > Apps > External Client Apps > New** で **External Client App を作成**します。組織にまだ Connected App がある場合は、Connected App でも構いません。

   - OAuth 設定を有効にし、**Enable Client Credentials Flow** のみにチェックを入れます（認可コードフローとパスワードフローは使用しません）。
   - **OAuth scope:** Manage user data via APIs (`api`)
   - **Run As:** 専用の統合ユーザー（手順 2）

2. 次の内容を持つ**プロファイルまたは権限セットを統合ユーザーに付与**します。

   - API Enabled
   - Account（Account Number フィールドを含む）、Product2、Opportunity、OpportunityLineItem、Organization（デフォルト通貨用）への Read
   - モデルに含める場合は、User（営業担当者）、Campaign（キャンペーン。プロジェクトとして読み取られます）、FiscalYearSettings と Period（会計月）、OpportunityHistory と OpportunityStage（各月末時点のパイプライン）、Order と OrderItem（受注。Orders を有効にしている場合）への Read
   - View All Data、またはレポート対象のすべての商談を参照できる共有設定

   PlaidCloud が読み取れるすべての行とフィールドは、このユーザーが参照できる範囲に Salesforce によって制限されます。

3. アプリから **Consumer Key（クライアント ID）と Consumer Secret** を、組織の My Domain URL（例: `https://yourcompany.my.salesforce.com`）とともにコピーします。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| My Domain URL | **My Domain**：`yourcompany` のようにドメイン名のみを入力します。`.my.salesforce.com` は自動的に付加されます |
| クライアント ID（Consumer Key） | **クライアントID** |
| クライアントシークレット（Consumer Secret）。メールではなく、セキュアな接続フォーム経由 | **クライアントシークレット** |

**オプション**の**会社**には、その Salesforce 組織のパイプラインが属する 1 つのエンティティを入力します。組織には一覧表示できるエンティティがありません。1 つの組織は 1 つのエンティティなので、2 つの組織は 2 つの接続になります。

## アクセスを確認する

PlaidCloud に戻り、システムを追加したら、**システム**ページのそのシステムの行で**接続をテスト**をクリックします。各データセットは、**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示されます。

| データセット | Salesforce で読み取る内容 |
|---|---|
| 顧客 | Account |
| 製品 | Product2 |
| パイプライン | Opportunity と OpportunityLineItem（アカウント番号を含む） |
| 組織のデフォルト通貨 | Organization |

いずれも省略可能です。いずれかが**権限が不足しています**と表示された場合は、管理者に、そのオブジェクトの読み取りアクセスを統合ユーザーに追加するよう依頼して、もう一度テストしてください。

テストでは、その他のデータセットは読み取りません。これらもすべて省略可能です。

| データセット | Salesforce で読み取る内容 |
|---|---|
| 営業担当者 | User |
| プロジェクト | Campaign |
| 会計カレンダー | FiscalYearSettings と Period（月のみ） |
| 過去の各月末時点のパイプライン | OpportunityHistory と OpportunityStage |
| 受注 | Order と OrderItem |

Salesforce がいずれかを拒否した場合、次回のロード後に **CFM-Accounting - Close and assurance** ダッシュボードの準備状況チェックに、統合ユーザーに Read を付与すべきオブジェクトが表示されます。ある月のパイプラインや受注を読み取れない場合、その月は既存の行を保持します。

パイプラインの金額は、商談の通貨で表されます。通貨を 1 つだけ使用している組織にはそのようなフィールドがないため、PlaidCloud は Organization のデフォルト通貨を使用し、それがない場合はエンティティの通貨を使用します。
