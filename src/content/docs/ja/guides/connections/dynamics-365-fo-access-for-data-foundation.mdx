[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP システムとインスタンスのデータを 1 つの Common Finance Model に集約します。Dynamics 365 Finance and Operations は、Data Foundation が直接読み取る ERP の 1 つです。この接続では、マスターデータにはクライアントシークレットを使用する Microsoft Entra ID アプリケーションを、総勘定仕訳帳、補助元帳、銀行残高には Fabric（Synapse）Link の SQL エンドポイントを使用します。このページは、これを設定する Dynamics 365 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。クライアントシークレットや SQL パスワードをメールで送らないでください。

## アクセス依頼を送信する

**ホーム**の **Data Foundation** にあるプロジェクトの**システム**ページで、**システムを追加**の**システム**でお使いのシステムを選択し、**まだアクセス権がありませんか?** ボタンをクリックします。システムはアクセス待ちになり、プロジェクトのシステムを対象とする 1 件の依頼が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「PlaidCloud へのアクセス」でメールプログラムに開きます。

## Dynamics 365 管理者が設定する内容

<Steps>

1. **Microsoft Entra ID にアプリケーションを登録します。** PlaidCloud 用に、クライアントシークレット付きで登録してください。アプリケーション（クライアント）ID、ディレクトリ（テナント）ID、シークレットを控えます。

2. **アプリケーションをユーザーにマップします。** Dynamics 365 の **System administration > Setup > Microsoft Entra ID applications** でクライアント ID を追加し、読み込む法人ごとに次の内容を表示できるロールを持つユーザーにマップします。

   - 総勘定元帳: 法人、会計カレンダー、主勘定、財務ディメンション値、為替レート
   - 売掛金: 顧客と顧客請求書明細
   - 買掛金: 仕入先（省略可）
   - 製品情報管理: リリース済み製品
   - 在庫管理: 手持在庫と在庫トランザクション（省略可）
   - 予算管理: 予算登録エントリ（省略可）

3. **総勘定仕訳帳用に Fabric Link を設定します。** 総勘定仕訳帳の明細は、OData サービスではなく、Fabric（Synapse）Link の SQL エンドポイントから読み取られます。次のテーブルで Fabric Link が有効になっていることを確認し、そのエンドポイントに PlaidCloud 用の読み取り専用 SQL ログインを作成します。

   - `generaljournalaccountentry`
   - `generaljournalentry`
   - `fiscalcalendarperiod`
   - `dimensionattributelevelvalue`。財務ディメンションの組み合わせごとのディメンション値 1 つにつき 1 行で、そのディメンション名を含みます
   - 未決済項目と支払用（省略可）: `custtrans`、`vendtrans`、`custsettlement`、`vendsettlement`
   - 仕入先請求書明細用（省略可）: `vendinvoicetrans`、`vendinvoicejour`
   - 銀行残高用（省略可）: `bankaccounttrans`、`bankaccounttable`

   サイトとプロフィットセンターは、財務ディメンション `Site` と `BusinessUnit` の値です。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| 環境 URL（`https://<name>.operations.dynamics.com`） | **環境URL** |
| ディレクトリ（テナント）ID | **Azure ADテナントID** |
| アプリケーション（クライアント）ID | **クライアントID** |
| 1 つの法人の `dataAreaId` | **法人/会社（dataAreaId）**：接続には 1 つ必要です。Data Foundation は**会社**で選択した法人を読み取ります |
| Fabric Link の SQL エンドポイント、データベース、ログイン | PlaidCloud の個別の SQL 接続。その接続 ID をシステム設定 **Fabric Link SQL connection (its connection ID)** に入力します |
| 売上原価勘定の主勘定カテゴリ（PlaidCloud は `COGS` を想定します） | システム設定 **Cost of goods sold main account categories** |
| 営業外の勘定（利息、法人所得税、為替差損益、その他収益）の主勘定カテゴリ | システム設定 **Non-operating main account categories** |
| 明細の会社間取引先を示す財務ディメンション（PlaidCloud は `IntercompanyPartner` を想定します） | システム設定 **Intercompany partner dimension** |
| PlaidCloud が読み取りを許可される法人 | **オプション**の**会社**：法人にチェックを入れます。どれにもチェックを入れない場合は、すべての法人が対象になります |

クライアントシークレットと SQL ログインのパスワードは、メールで送らないでください。PlaidCloud ユーザーのチームが**クライアントシークレット**を PlaidCloud に自分で貼り付け、SQL ログインは SQL 接続が保持します。連結法人にあたる法人は、システム設定 **Consolidation legal entities** に指定します。これにより、それらの転記は 1 社の活動として計上されません。

## アクセスを確認する

PlaidCloud に戻り、システムを追加したら、**システム**ページのそのシステムの行で**接続をテスト**をクリックします。各データセットは、**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示されます。

| データセット | 必要な権限 |
|---|---|
| エンティティ | 総勘定元帳: 法人の表示 |
| 会計カレンダー | 総勘定元帳: 会計カレンダーの表示 |
| 勘定科目表 | 総勘定元帳: 主勘定の表示 |
| 部門 | 総勘定元帳: 財務ディメンション値の表示 |
| 顧客 | 売掛金: 顧客の表示 |
| 製品 | 製品情報管理: リリース済み製品の表示 |
| 為替レート | 総勘定元帳: 為替レートの表示 |
| 試算表、総勘定元帳 | 総勘定元帳の表示（Fabric Link 経由の仕訳帳） |
| その他のすべてのデータセット | 省略可。テストの対象外 |

データセットが不足している場合、テストにより、追加すべき権限が示されます。管理者にロールへの追加を依頼して、もう一度テストしてください。

省略可能なデータセットは、サイト、プロフィットセンター、仕入先、売上明細、在庫残高、予算、銀行残高、仕入先請求書明細、未決済項目、支払です。いずれかを保持していない環境でも、ほかのすべてのデータは読み込まれます。ある月の銀行残高、仕入先請求書明細、未決済項目、支払を Fabric Link から読み取れない場合、その月は既存の行を保持し、次回のロードで再度読み取られます。

Dynamics 365 には接続で読み取れる残高オブジェクトがないため、月末残高は読み込まれません。元帳は、元帳自体の試算表と比較されます。
