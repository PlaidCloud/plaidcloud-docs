[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP および会計システムのデータを、インスタンスの数に関係なく、1 つの Common Finance Model に集約します。QuickBooks Online は、Data Foundation が直接読み取るシステムの 1 つです。このページは、アクセスを設定する QuickBooks 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードやトークンをメールで送らないでください。

## アクセス依頼を送信する

**ホーム**の **Data Foundation** にあるプロジェクトの**システム**ページで、**システムを追加**の**システム**でお使いのシステムを選択し、**まだアクセス権がありませんか?** ボタンをクリックします。システムはアクセス待ちになり、プロジェクトのシステムを対象とする 1 件の依頼が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「PlaidCloud へのアクセス」でメールプログラムに開きます。

## QuickBooks 管理者が設定する内容

<Steps>

1. **PlaidCloud が代行する QuickBooks ユーザーを選びます。** QuickBooks 上で、そのユーザーには次のものを表示する権限が必要です。

   - 勘定科目表、顧客、仕入先、製品とサービス、ロケーション、クラス
   - 総勘定元帳、試算表、損益計算書のレポート（Reports で実行できるユーザー）
   - 売上取引: 請求書、売上レシート、クレジットメモ、返金レシート
   - モデルに仕入先、未決済項目、支払を含める場合は、購入と支払: 仕入請求書、仕入先クレジット、経費、顧客の支払、仕入請求書の支払
   - モデルに含める場合は、予算と在庫評価サマリー（QuickBooks Plus または Advanced）

   会社の管理者は、すでにこれらの権限を持っています。制限付きユーザーには、これらの権限を有効にする必要があります。

2. **PlaidCloud を 1 回だけ承認します。** そのユーザーが、PlaidCloud ユーザーから送られた接続から、Intuit の同意画面にサインインします。スコープは Accounting（`com.intuit.quickbooks.accounting`）のみです。

3. **1 つの接続につき 1 社です。** 複数の QuickBooks 会社を使用している場合は、それぞれを個別の接続で承認します。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| モデルに表示される会社名 | 入力は不要です。接続は、QuickBooks ユーザーが承認した 1 社を読み取ります |
| 帳簿が特定の日付で締められているかどうか（**Settings > Account and Settings > Advanced > Accounting**） | 入力は不要です。PlaidCloud は、帳簿の締め日を QuickBooks から読み取ります |

PlaidCloud ユーザーは、プロジェクトの**システム**ページで、**システムを追加**の**システム**で QuickBooks Online を選択し、「（システム名）に接続」ボタンをクリックします。PlaidCloud がプロジェクトの環境用の接続を作成し、Intuit の承認ウィンドウを開きます。QuickBooks ユーザーが承認すると、システムが追加され、ロードが始まります。[ERP を接続する](/ja/guides/projects/data-foundation/#erp-を接続する)を参照してください。

**システム設定**の **Retained earnings account** には、勘定科目名からわからない場合に、期首の損益を繰り入れる資本勘定科目の名前を指定します。省略可能です。

## アクセスを確認する

PlaidCloud に戻り、システムを追加したら、**システム**ページのそのシステムの行で**接続をテスト**をクリックします。テストでは、必須のデータセット（エンティティ、勘定科目表、会計カレンダー、試算表、総勘定元帳）を読み取り、それぞれを**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示します。省略可能なデータセットはテストの対象外です。QuickBooks がいずれかを拒否した場合、次回のロード後に準備状況チェックにそのデータセットが表示されます。各データセットが読み取る内容は次のとおりです。

| データセット | QuickBooks で読み取る内容 |
|---|---|
| エンティティ | 会社情報 |
| 会計カレンダー | 会社の設定: 会計年度の開始月と帳簿の締め日 |
| 勘定科目表 | 勘定科目表 |
| 試算表 | 期首残高のための試算表レポート |
| 総勘定元帳 | 総勘定元帳レポート |
| サイト | ロケーション（省略可） |
| 利益センター | クラス（省略可） |
| 顧客 | 顧客（省略可） |
| 製品 | 製品とサービス（省略可） |
| 仕入先 | 仕入先とその支払条件（省略可） |
| 月末残高 | 各月末時点の試算表レポート（省略可） |
| 銀行残高 | その月末の試算表に含まれる銀行口座の残高（省略可） |
| 売上明細 | 請求書、売上レシート、クレジットメモ、返金レシート（省略可） |
| 仕入先請求書明細 | 仕入請求書、仕入先クレジット、経費（省略可） |
| 未決済項目 | 各月末時点の請求書、クレジットメモ、仕入請求書、仕入先クレジットから、それらに消し込まれた支払を差し引いたもの（省略可） |
| 支払 | 顧客の支払と仕入請求書の支払（省略可） |
| 予算 | 予算（省略可） |
| 在庫残高 | 会社が手持数量を追跡している場合、各月末時点の在庫評価サマリー（省略可） |
| 為替レート | 為替レート（省略可） |

データセットが**権限が不足しています**と表示された場合、テストにより、追加すべきアクセスが示されます。管理者にそのユーザーへの有効化を依頼して、もう一度テストしてください。予算などの省略可能なデータがない会社でも、ほかのすべてのデータは読み込まれます。ある月の残高、在庫、売上、購入、未決済項目、支払の作成元となる読み取りを QuickBooks が拒否した場合、その月は既存の行を保持し、次回のロードで再度読み取られます。

QuickBooks には取引先、会社間勘定科目、元帳がないため、QuickBooks 会社の明細にはそれらが含まれません。部門もありません。ロケーションはサイト、クラスはプロフィットセンターになります。
