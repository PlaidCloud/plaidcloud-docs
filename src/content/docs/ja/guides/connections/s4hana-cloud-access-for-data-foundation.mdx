[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP システムとインスタンスのデータを 1 つの Common Finance Model に集約します。SAP S/4HANA Cloud は、Data Foundation が直接読み取る ERP の 1 つです。この接続は、OAuth 2.0 クライアント資格情報を使用して、テナントのリリース済み OData サービスを読み取ります。エージェントは関与しません。このページは、これを設定する S/4HANA Cloud 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードやクライアントシークレットをメールで送らないでください。

## アクセス依頼を送信する

プロジェクトの **Foundation** タブで、**SAP S/4HANA Cloud接続**の下にある**新しい接続を作成**を選択します。フォームに依頼内容の全文が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「Read-only SAP S/4HANA Cloud access for PlaidCloud (OAuth 2.0 client credentials)」でメールプログラムに開きます。

## S/4HANA Cloud 管理者が設定する内容

<Steps>

1. アプリ **Maintain Communication Users** で、PlaidCloud 用の**通信ユーザーを作成**します。認証方法は、お使いのランドスケープに応じて、OAuth 2.0 またはユーザー名とパスワードにします。

2. アプリ **Communication Systems** で、PlaidCloud 用の**通信システムを作成**します。インバウンド通信にはそのユーザーを使用し、OAuth 2.0 クライアント資格情報を設定します。

3. アプリ **Communication Arrangements** で、以下のシナリオごとに**通信アレンジメントを作成**します。すべて手順 2 のシステム用です。これらを合わせて、PlaidCloud が読み取る OData サービスが公開されます。

   | シナリオ | サービス |
   |---|---|
   | 会社コード | `API_COMPANYCODE_SRV` |
   | 勘定科目表の G/L 勘定 | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | コストセンター | `API_COSTCENTER_SRV` |
   | ビジネスパートナーと顧客 | `API_BUSINESS_PARTNER` |
   | 製品 | `API_PRODUCT_SRV` |
   | 会計年度バリアントの期間 | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | 為替レート | `API_EXCHANGERATE_SRV` |
   | 仕訳明細 | `API_JOURNALENTRYITEMBASIC_SRV`（仕訳と繰越残高） |
   | 請求伝票 | `API_BILLING_DOCUMENT_SRV`（省略可: 請求済みの売上、伝票、明細が追加されます） |

   通信ユーザーには、レポート対象のすべての会社コードへのアクセスを付与してください。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| テナントの API のホスト（例: `my300000-api.s4hana.cloud.sap`） | **ホスト** |
| クライアント ID | **クライアントID** |
| クライアントシークレット（セキュアな接続フォーム経由） | **クライアントシークレット**。チームが自分で貼り付けます |
| トークン URL。ランドスケープがテナント独自のもの（`/sap/bc/sec/oauth2/token`）ではなく XSUAA 認可サーバーを使用する場合のみ | **Token URL (optional)** |
| スコープ。XSUAA 認可サーバーを使用する場合のみ | **スコープ（省略可）** |
| 読み込む会計年度ごとに **Carry Forward Balances** が実行済みかどうか | 入力は不要です。期首残高はこれから読み取られます。 |

<Aside type="caution">
クライアントシークレットをメールで送らないでください。**クライアントシークレット**はシークレットです。接続に保存され、再表示されません。
</Aside>

## アクセスを確認する

PlaidCloud に戻って値を入力し、**接続をテスト**をクリックします。各データセットは、**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示されます。

| データセット | 必要なサービス |
|---|---|
| エンティティ | `API_COMPANYCODE_SRV` |
| 勘定科目表 | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| 部門 | `API_COSTCENTER_SRV` |
| 顧客 | `API_BUSINESS_PARTNER` |
| 製品 | `API_PRODUCT_SRV` |
| 為替レート | `API_EXCHANGERATE_SRV` |
| 会計カレンダー | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| 総勘定元帳 | `API_JOURNALENTRYITEMBASIC_SRV` |
| 試算表 | `API_JOURNALENTRYITEMBASIC_SRV` |
| 売上明細 | `API_BILLING_DOCUMENT_SRV`（省略可） |

データセットが**権限が不足しています**と表示された場合は、管理者にそのサービスの通信アレンジメントの追加を依頼して、もう一度テストしてください。売上明細、予算、在庫残高は省略可能です。これらを保持していないテナントでも、ほかのすべてのデータは読み込まれます。
