[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP システムとインスタンスのデータを 1 つの Common Finance Model に集約します。SAP S/4HANA Cloud は、Data Foundation が直接読み取る ERP の 1 つです。この接続は、OAuth 2.0 クライアント資格情報を使用して、テナントのリリース済み OData サービスを読み取ります。エージェントは関与しません。このページは、これを設定する S/4HANA Cloud 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードやクライアントシークレットをメールで送らないでください。

## アクセス依頼を送信する

**ホーム**の **Data Foundation** にあるプロジェクトの**システム**ページで、**システムを追加**の**システム**でお使いのシステムを選択し、**まだアクセス権がありませんか?** ボタンをクリックします。システムはアクセス待ちになり、プロジェクトのシステムを対象とする 1 件の依頼が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「PlaidCloud へのアクセス」でメールプログラムに開きます。

## S/4HANA Cloud 管理者が設定する内容

<Steps>

1. アプリ **Maintain Communication Users** で、PlaidCloud 用の**通信ユーザーを作成**します。認証方法は、お使いのランドスケープに応じて、OAuth 2.0 またはユーザー名とパスワードにします。

2. アプリ **Communication Systems** で、PlaidCloud 用の**通信システムを作成**します。インバウンド通信にはそのユーザーを使用し、OAuth 2.0 クライアント資格情報を設定します。

3. アプリ **Communication Arrangements** で、以下のシナリオごとに**通信アレンジメントを作成**します。すべて手順 2 のシステム用です。これらを合わせて、PlaidCloud が読み取る OData サービスが公開されます。

   | シナリオ | サービス |
   |---|---|
   | 会社コード | `API_COMPANYCODE_SRV` |
   | 勘定科目表の G/L 勘定 | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
   | コストセンター | `API_COSTCENTER_SRV` |
   | ビジネスパートナーと顧客 | `API_BUSINESS_PARTNER` |
   | 製品 | `API_PRODUCT_SRV` |
   | 会計年度バリアントの期間 | `API_FISCALYEARPERIODFORVARIANT_SRV` |
   | 為替レート | `API_EXCHANGERATE_SRV` |
   | 仕訳明細 | `API_JOURNALENTRYITEMBASIC_SRV`（仕訳と繰越残高） |
   | 請求伝票 | `API_BILLING_DOCUMENT_SRV`（省略可: 請求済みの売上、伝票、明細が追加されます） |

   省略可能なデータセット用に、次のサービスを公開するシナリオのアレンジメントも作成します。

   | サービス | 追加されるもの |
   |---|---|
   | `API_JOURNALENTRY_SRV` | 各仕訳の入力者、その日時、および取り消す仕訳 |
   | `API_BUSINESS_PARTNER`（`A_Supplier`） | 仕入先 |
   | `API_PLANT_SRV` | サイトとして読み取られるプラント、および在庫残高のプラント |
   | `API_PROFITCENTER_SRV` | プロフィットセンター |
   | `API_SUPPLIERINVOICE_PROCESS_SRV` | 仕入先請求書明細 |
   | `API_OPLACCTGDOCITEMCUBE_SRV` | 未決済項目と支払、および仕入先請求書の支払期日 |
   | `API_FINPLANNINGDATA_SRV` | 予算 |
   | `API_MATERIAL_STOCK_SRV` | 在庫残高 |

   通信ユーザーには、レポート対象のすべての会社コードへのアクセスを付与してください。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| テナントの API のホスト（例: `https://my300000-api.s4hana.cloud.sap`） | **APIホストURL** |
| トークン URL。テナント独自のもの（`/sap/bc/sec/oauth2/token`）、またはランドスケープで XSUAA 認可サーバーを使用している場合はそのサーバーのもの | **OAuth2トークンURL** |
| クライアント ID | **クライアントID** |
| クライアントシークレット（セキュアな接続フォーム経由） | **クライアントシークレット**。チームが自分で入力します |
| 読み込む会計年度ごとに **Carry Forward Balances** が実行済みかどうか | 入力は不要です。期首残高はこれから読み取られます。 |

<Aside type="caution">
クライアントシークレットをメールで送らないでください。**クライアントシークレット**はシークレットです。接続に保存され、再表示されません。
</Aside>

## アクセスを確認する

PlaidCloud に戻り、システムを追加したら、**システム**ページのそのシステムの行で**接続をテスト**をクリックします。テストでは、必須のデータセットを読み取り、それぞれを**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示します。省略可能なデータセットはテストの対象外です。S/4HANA Cloud がいずれかを拒否した場合、次回のロード後に **CFM-Accounting - Close and assurance** ダッシュボードの準備状況チェックに、通信アレンジメントに追加すべきサービスが表示されます。

| データセット | 必要なサービス |
|---|---|
| エンティティ | `API_COMPANYCODE_SRV` |
| 勘定科目表 | `API_GLACCOUNTINCHARTOFACCOUNTS_SRV` |
| 部門 | `API_COSTCENTER_SRV` |
| 顧客 | `API_BUSINESS_PARTNER` |
| 製品 | `API_PRODUCT_SRV` |
| 為替レート | `API_EXCHANGERATE_SRV` |
| 会計カレンダー | `API_FISCALYEARPERIODFORVARIANT_SRV` |
| 総勘定元帳 | `API_JOURNALENTRYITEMBASIC_SRV` |
| 試算表 | `API_JOURNALENTRYITEMBASIC_SRV` |
| 売上明細 | `API_BILLING_DOCUMENT_SRV`（省略可） |

データセットが**権限が不足しています**と表示された場合は、管理者にそのサービスの通信アレンジメントの追加を依頼して、もう一度テストしてください。売上明細、予算、在庫残高、仕入先、サイト、プロフィットセンター、仕入先請求書明細、未決済項目、支払は省略可能です。いずれかを保持していないテナントでも、ほかのすべてのデータは読み込まれます。ある月の未決済項目や支払を読み取れない場合、またはある月の仕入先請求書明細の読み取りが失敗した場合、その月は既存の行を保持し、次回のロードで再度読み取られます。

これらのサービスは独自の期間ステータスも月末残高も報告しないため、すべての期間が未締めとなり、元帳は元帳自体の試算表と比較されます。
