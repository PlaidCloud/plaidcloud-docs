PlaidCloud を **OneStream** に接続すると、Data Foundation が連結結果を読み取り、管理グループの損益計算書をそれに照合できます。OneStream はそのコネクターでサポートされています。PlaidCloud は OAuth 2.0 クライアント資格情報でサインインし、OneStream 管理者が作成するデータアダプターを読み取ります。読み取り専用です。

OneStream は、元帳明細ではなく、照合先となる結果のソースです。その行は、モデルの予算テーブルの `Consolidated` シナリオ、バージョン `OneStream` として取り込まれます。[連結システムに照合する](/ja/guides/projects/data-foundation/#連結システムとの照合)を参照してください。

<Aside type="note">
アダプターの列は、あなたと OneStream 管理者が合意する取り決めです。アダプターがこのページに従って作成されていれば、その行は以下のとおりに取り込まれます。最初のロードの結果を、信頼できる OneStream レポートと比較してください。
</Aside>

## OneStream 管理者が設定する内容

プロジェクトの**システム**ページが、送信するアクセス依頼を作成します（[ERP を接続する](/ja/guides/projects/data-foundation/#erp-を接続する)を参照）。依頼には次の内容が含まれます。

1. OneStream の ID サービスにある PlaidCloud 用のクライアント。**クライアント資格情報**グラントを使用し、以下のアダプターの実行のみができるサービスユーザーを設定します。Data Management、ロード、連結の権限は付与しません。PlaidCloud は Data Management シーケンスを実行しないため、アダプターが読み取る結果は、独自のスケジュールで最新の状態に保ってください。

2. レポート対象のアプリケーションとワークスペースに、連結結果の 1 つのテーブルを返すデータアダプター **Foundation_Results** を、次の列とまったく同じ構成で作成します。

   | 列 | 内容 |
   |---|---|
   | `entity` | 連結メンバー。エンティティ、消去メンバー、またはグループ合計。 |
   | `account` | 勘定科目コード。基本勘定科目のみ。 |
   | `time` | 月（`YYYY-MM` 形式）。 |
   | `scenario` | 連結結果の場合は `Actual`。計画の場合は `Budget` または `Forecast` で、計画として読み取られます。 |
   | `view` | `YTD` または `Periodic`。PlaidCloud は、選択したビューの行だけを読み取ります。 |
   | `amount` | レポートに表示される符号とスケールの数値。 |
   | `currency` | 金額が表示される通貨。グループの報告通貨です。 |
   | `flow` | フローメンバー。基本メンバーのみ。 |
   | `ud1`～`ud5` | 部門、製品、サイト、営業担当者、プロジェクトのメンバー。行にない場合は `None`。基本メンバーのみ。 |
   | `version` | 計画のバージョン。`Actual` の場合は `None` または空白にします。 |
   | `version_as_of` | 計画のバージョンの作成基準となった月（`YYYY-MM` 形式）。`Actual` の場合は `None` または空白にします。 |
   | `quantity` | 計画の行の計画対象となる数量。ビューにかかわらず月単位です。`Actual` の場合は `None` または空白にします。 |

   勘定科目、フロー、ユーザー定義ディメンションの基本メンバーを提供してください。親メンバーの行があると、その子が二重に計上されます。アダプターは、連結メンバーを置換変数 `Member` から、ビューを `View` から読み取ります。

   計画に人員数や生産数量が含まれる場合は、`entity`、`time`、`scenario`、`driver`（例: `headcount`、`units_produced`）、`value`、`unit`（`FTE`、`EA` など）、`ud1`（部門）、`ud2`（製品）、`ud3`（サイト）、`version`、`version_as_of` の列を持つアダプター **Foundation_Drivers** も作成します。このアダプターも同じ方法で `Member` を読み取り、作成は任意です。このアダプターがない場合、またはアクセスできない場合、計画のドライバーはロードされず、準備状況チェックにその旨が表示されます。

3. 読み取るメンバー: エンティティ、消去メンバー、グループ合計。

## 接続を作成する

<Steps>

1. **Tools > Connections** を開いて `New Connection` をクリックし、**REST - OneStream** を選択します。

2. 各フィールドを入力します。

   | フィールド | 値 |
   |---|---|
   | ホスト | `https://` で始まる OneStream のベース URL。 |
   | クライアントID | PlaidCloud クライアントのクライアント ID。 |
   | クライアントシークレット | そのシークレット。暗号化して保存され、再表示されません。 |
   | Token URL | 空白のままにすると、ホストに `/identity/connect/token` を付けたものが使われます。 |
   | デフォルトアプリケーション | アプリケーションを空白にした読み取りで使われます。 |
   | デフォルトのワークスペース | ワークスペースを空白にした読み取りで使われます。 |
   | タイムアウト（秒） | デフォルトは 120 です。 |

3. `Create` をクリックします。

</Steps>

**システム**ページでシステムを追加する際に、接続を作成することもできます。**接続**で**新しい接続**を選択すると、同じ接続エディターが開きます。

## Data Foundation プロジェクトに追加する

ほかのシステムと同様に、プロジェクトの**システム**ページで、OneStream をその接続とともに追加します（[ERP を接続する](/ja/guides/projects/data-foundation/#erp-を接続する)を参照）。OneStream にはチェックできるメンバーの一覧がないため、**オプション**の**会社**に、読み取る連結メンバーをカンマ区切りで 1 つ以上入力します。続いて、**システム設定**で、アダプターの金額を記述します。

| 設定 | 意味 |
|---|---|
| **View member** | アダプターの金額が年初来の場合は `ytd`（デフォルト）、期間別の場合は `periodic`。年初来の行は、期間別の金額として取り込まれます。 |
| **Sign convention** | `natural`（デフォルト）: 各勘定科目が、OneStream のレポートどおり、その勘定科目自身の符号になります。`debit_positive`: 借方が正になります。 |
| **Amount scale** | 通貨単位全体への乗数。OneStream が千単位で提供する場合は `1000`。デフォルトは `1` です。 |
| **First month of the fiscal year** | 会計年度の開始月（`1` から `12`）。年初来から期間別への変換に使用します。デフォルトは `1` です。 |
| **Application**、**Workspace** | 接続の設定を上書きします。接続の設定を使う場合は空白にします。 |
| **Adapter results table** | アダプターのデータセット内のテーブル名。デフォルトは `Results` です。 |
| **Substitution variables** | アダプターに設定する置換変数。1 行に 1 つずつ `name = value` の形式で指定します（例: `Time = 2026M1`）。 |

このソースに適用されるコードマップファイルで、OneStream のメンバーをエンティティにマッピングします。[エンティティクロスウォーク](/ja/guides/projects/data-foundation/#エンティティ対応表)を参照してください。このソースは履歴ウィンドウを読み取りません。範囲はアダプター自身の置換変数によって制限されます。

アダプターから行が返されないロードは、エラーではなく警告付きで完了し、テーブルは空になります。

## ワークフローでアダプターを読み取る

アダプターを独自のテーブルに読み取るには、[OneStream: Read Adapter](/ja/reference/workflow-steps/onestream/onestream-read-adapter/) を使用します。
