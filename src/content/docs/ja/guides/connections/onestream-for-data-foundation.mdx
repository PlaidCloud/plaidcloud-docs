PlaidCloud を **OneStream** に接続すると、Data Foundation が連結結果を読み取り、管理グループの損益計算書をそれに照合できます。OneStream はそのコネクターでサポートされています。PlaidCloud は OAuth 2.0 クライアント資格情報でサインインし、OneStream 管理者が作成するデータアダプターを読み取ります。読み取り専用です。Data Management シーケンスを指定した場合、PlaidCloud はアダプターが読み取る内容を更新するために、まずそのシーケンスを実行し、それ以外は何も実行しません。

OneStream は、元帳明細ではなく、照合先となる結果のソースです。その行は、モデルの予算テーブルの `Consolidated` シナリオ、バージョン `OneStream` として取り込まれます。[連結システムに照合する](/ja/guides/projects/data-foundation/#連結システムと照合する)を参照してください。

<Aside type="note">
アダプターの列は、あなたと OneStream 管理者が合意する取り決めです。アダプターがこのページに従って作成されていれば、その行は以下のとおりに取り込まれます。最初のロードの結果を、信頼できる OneStream レポートと比較してください。
</Aside>

## OneStream 管理者が設定する内容

**Foundation** タブが、送信するアクセス依頼を作成します。依頼には次の内容が含まれます。

1. OneStream の ID サービスにある PlaidCloud 用のクライアント。**クライアント資格情報**グラントを使用し、アダプターを実行できるサービスユーザーを設定します。PlaidCloud に先に結果を更新させる場合は、Data Management シーケンスも実行できる必要があります。

2. レポート対象のアプリケーションとワークスペースに、連結結果の 1 つのテーブルを返すデータアダプター **Foundation_Results** を、次の列とまったく同じ構成で作成します。

   | 列 | 内容 |
   |---|---|
   | `entity` | 連結メンバー。エンティティ、消去メンバー、またはグループ合計。 |
   | `account` | 勘定科目コード。基本勘定科目のみ。 |
   | `time` | 月（`YYYY-MM` 形式）。 |
   | `scenario` | シナリオ。 |
   | `view` | `YTD` または `Periodic`。PlaidCloud は、選択したビューの行だけを読み取ります。 |
   | `amount` | レポートに表示される符号とスケールの数値。 |
   | `currency` | 金額が表示される通貨。グループの報告通貨です。 |
   | `flow`、`ud1`、`ud2`、`ud3`、`ud4` | フローとユーザー定義ディメンション。基本メンバーのみ。 |

   勘定科目、フロー、ユーザー定義ディメンションの基本メンバーを提供してください。親メンバーの行があると、その子が二重に計上されます。アダプターは、連結メンバーを置換変数 `Member` から、ビューを `View` から読み取ります。

3. 読み取るメンバー: エンティティ、消去メンバー、グループ合計。

## 接続を作成する

<Steps>

1. **Tools > Connections** を開いて `New Connection` をクリックし、**REST - OneStream** を選択します。

2. 各フィールドを入力します。

   | フィールド | 値 |
   |---|---|
   | ホスト | `https://` で始まる OneStream のベース URL。 |
   | クライアントID | PlaidCloud クライアントのクライアント ID。 |
   | クライアントシークレット | そのシークレット。暗号化して保存され、再表示されません。 |
   | Token URL | 空白のままにすると、ホストに `/identity/connect/token` を付けたものが使われます。 |
   | デフォルトアプリケーション | アプリケーションを空白にした読み取りで使われます。 |
   | デフォルトのワークスペース | ワークスペースを空白にした読み取りで使われます。 |
   | タイムアウト（秒） | デフォルトは 120 です。 |

3. `Create` をクリックします。

</Steps>

ソースを追加する際に、**Foundation** タブで接続を作成することもできます。**新しい接続を作成**を選択し、**APIホストURL**、**クライアントID**、**クライアントシークレット**、**Token URL**、**アプリケーション**、**ワークスペース**を入力します。意味は上記のフィールドと同じです。

## Data Foundation プロジェクトに追加する

**Foundation** タブで、ほかの接続と同様に、この接続をソースとして追加します（[ERP を接続する](/ja/guides/projects/data-foundation/#erp-を接続する)を参照）。OneStream にはチェックできるメンバーの一覧がないため、フォームで読み取る連結メンバーの入力を求められます。**名前**に入力してください。続いて、**システム設定**で、アダプターの金額を記述します。設定は次の名前で表示されます。

| 設定 | 意味 |
|---|---|
| `view` | アダプターの金額が年初来の場合は `ytd`（デフォルト）、期間別の場合は `periodic`。年初来の行は、期間別の金額として取り込まれます。 |
| `sign` | `natural`（デフォルト）: 各勘定科目が、OneStream のレポートどおり、その勘定科目自身の符号になります。`debit_positive`: 借方が正になります。 |
| `scale` | 通貨単位全体への乗数。OneStream が千単位で提供する場合は `1000`。デフォルトは `1` です。 |
| `fy_start_month` | 会計年度の開始月（`1` から `12`）。年初来から期間別への変換に使用します。デフォルトは `1` です。 |
| `application`、`workspace` | 接続の設定を上書きします。接続の設定を使う場合は空白にします。 |
| `table` | アダプターのデータセット内のテーブル名。デフォルトは `Results` です。 |
| `sequence` | 読み取り前に実行する Data Management シーケンス。アダプターが読み取る内容を更新します。 |

このソースに適用されるコードマップファイルで、OneStream のメンバーをエンティティにマッピングします。[エンティティクロスウォーク](/ja/guides/projects/data-foundation/#エンティティ対応表)を参照してください。このソースは履歴ウィンドウを読み取りません。範囲はアダプター自身の置換変数によって制限されます。

アダプターから行が返されないロードは、エラーではなく警告付きで完了し、テーブルは空になります。

## ワークフローでアダプターを読み取る

アダプターを独自のテーブルに読み取るには、[OneStream: Read Adapter](/ja/reference/workflow-steps/onestream/onestream-read-adapter/) を使用します。
