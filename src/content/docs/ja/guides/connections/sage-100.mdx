Sage 100 はお客様自身のサーバーにインストールされ、Web API を持たないため、PlaidCloud はネットワーク内の Windows コンピューターで動作する [PlaidLink](/ja/reference/cli/plaidlink/) エージェント経由で接続します。[Data Foundation](/ja/guides/projects/data-foundation/) は、このエージェントを通じて、1 つの Sage 100 の会社の勘定科目表、会計カレンダー、仕訳、期間残高を読み取ります。接続できるほかの ERP システムと同様です。ワークフローから、総勘定元帳の仕訳と買掛金の手動小切手をその会社に転記することもできます。

このページでは、Sage 100 管理者が設定する内容、会社を接続する方法、Data Foundation が読み取る内容、転記時の動作を説明します。

## Sage 100 管理者が設定する内容

以下はすべて、PlaidLink エージェントを実行する 1 台のコンピューター上での作業です。

<Steps>

1. コンピューターに**PlaidLink をインストールして登録**し、PlaidLink 1.2.36 以降を使用し、エージェントはシステムアカウント（LocalSystem、LocalService、NetworkService）ではなく、専用の Windows アカウントで実行します。専用アカウントであれば、PlaidLink は応答しなくなった Sage 100 セッションをクリアできます。システムアカウントではできません。

2. **Sage の 64 ビット ODBC ドライバーをインストールし、64 ビットのシステム DSN を作成します。** エージェントは 64 ビットのプログラムのため、32 ビットのドライバーやデータソースは使用できません。データソースの名前は通常 `SOTAMAS90` で、Sage 100 Standard と Advanced に付属しています。Sage 100 Premium は SQL Server から読み取るため、代わりに Microsoft ODBC Driver for SQL Server が必要です。お使いの Sage 100 のライセンスが ODBC ドライバーとワークステーションを対象としていることを確認してください。

3. **PlaidCloud 用の Sage ユーザーを作成**し、ロールメンテナンスで次のタスクを付与します。

   | 用途 | タスク |
   |---|---|
   | 読み取り | 総勘定元帳：勘定科目表、勘定科目照会、仕訳入力の照会、会計年度と期間の照会。ライブラリマスター：会社メンテナンスの照会。 |
   | 転記（表示だけでなくエントリーを追加する権限が必要） | 総勘定元帳：仕訳入力。買掛金：手動小切手入力。 |

   Premium の場合は、SQL Server 上の Sage 100 データベースへの読み取りアクセス権もそのユーザーに付与します。

4. **同じコンピューターに Sage 100 をワークステーションとしてインストールします。** データソースが会社ファイルを開くために必要で、転記は、ワークステーションのインストールで提供される Sage のビジネスオブジェクトインターフェース（BOI）を通じて行われます。転記の実行中は Sage 100 のワークステーションライセンスを 1 つ使用します。Sage 100 のインストール先フォルダーと、会社が帳簿を管理する通貨を控えておいてください。

5. 最初に接続するための**テスト用の会社**、または会社のコピーを PlaidCloud に用意します。

6. 初回のインストールがブロックされないように、**PlaidLink エージェントをウイルス対策ソフトと Windows SmartScreen で許可します。**

</Steps>

Standard または Advanced のデータソースは 1 つの会社にサインインします。Premium の接続では、1 つのデータベース内の 1 つの会社を指定します。会社ごとに別々に接続してください。

<Aside type="caution">
Sage のパスワードをメールで送信しないでください。**Sage password**はシークレットであり、接続に保存され、二度と表示されません。
</Aside>

### アクセスリクエストを送信する

プロジェクトの**Foundation**タブで、**システムを接続**の**Sage 100 — on-premises**を選択し、**新しい接続を作成**を選択します。フォームには、リクエストの全文、**PlaidLink の設定方法**のリンク、リクエストを自分のメッセージに貼り付けるための**リクエストをコピー**、件名を「Sage 100 access for PlaidCloud」にしてメールプログラムで開く**リクエストをメールで送信**が表示されます。

## 会社を接続する

**Foundation**タブで**ソース**を開き、**システムを接続**（プロジェクトにすでにソースがある場合は**別のシステムを接続**）で**Sage 100 — on-premises**を選択して、**新しい接続を作成**を選択します。**接続名**を入力し、**環境**を選択して、次の設定を入力します。

| 設定 | 入力する内容 |
|---|---|
| **Sage 100 edition** | Premium、Standard、Advanced のいずれか。 |
| **Company code** | Sage 100 の会社のコード。英数字 1～10 文字。 |
| **Company currency** | 会社が帳簿を管理する通貨の 3 文字コード（`USD` など）。必須です。PlaidCloud が通貨を推測することはありません。 |
| **Sage user** | PlaidCloud 用に作成した Sage ユーザー。 |
| **Sage password** | そのユーザーのパスワード。 |
| **Sage 100 install folder on the agent machine** | Sage 100 のインストール先フォルダー。転記に必要です。読み取りには不要です。 |
| **Accounts Payable division** | 手動小切手の転記先となる部門。デフォルトは `00` です。 |
| **SQL Server (Premium)** と **SQL Server database (Premium)** | Premium の場合：Sage 100 のインストールで使用する SQL Server とデータベース。 |
| **ODBC data source (Standard and Advanced)** | Standard と Advanced の場合：エージェントのコンピューター上のシステム DSN。デフォルトは `SOTAMAS90` です。 |

**システム設定**で、**PlaidLink agent**から PlaidLink エージェントを選択し、そこでも**Company currency**に同じコードを設定します。行はその通貨でロードされ、変更するまでは `USD` です。**Document account for the agent's reads**は、エージェントが読み取り中に書き込むファイルを保持し、デフォルトはプロジェクトのドキュメントアカウントです。**Account mask**は Sage 100 の勘定科目の形式で、`#` は 1 文字、それ以外は区切り文字を表します。たとえば `####-###` は、4 文字の主勘定科目、区切り文字、3 文字の部門です。変更するまでは `####` です。

**接続をテスト**をクリックします。Sage 100 の場合、このテストでは接続に必要な値がすべてそろっているかを確認するだけで、Sage 100 にはサインインしません。エージェントがテーブルを読み取るのは、**ロード**をクリックしたときです。続いて、**履歴の月数**を設定し、[ERP を接続する](/ja/guides/projects/data-foundation/#erp-を接続する)の説明に従ってシステムを追加します。接続が提供するエンティティはその会社 1 つだけです。

## Data Foundation が読み取る内容

| データセット | Sage 100 から読み取る内容 |
|---|---|
| エンティティ | 会社。 |
| 会計カレンダー | 会計年度とその期間（1 年あたり最大 13 期間）。終了日が直前の期間と同じ期間は、調整期間です。 |
| 勘定科目表 | 勘定科目マスクでセグメントに分割された総勘定元帳の勘定科目。 |
| 部門 | 勘定科目の部門セグメント（マスクに部門セグメントがある場合）。 |
| 総勘定元帳 | 会計年度と期間ごとの総勘定元帳の転記明細。 |
| 試算表 | 期間の転記履歴：期間ごとの各勘定科目の借方と貸方。最初に読み取る期間には期首残高が付きます。 |

Sage 100 は、製品、顧客、売上明細、為替レートなどのデータセットを供給しません。これらはファイルとして追加してください。Sage 100 は帳簿を単一通貨で管理するため、読み取る為替レートはありません。[Data Foundation カバレッジマトリックス](/ja/reference/data-foundation-coverage-matrix/)を参照してください。

エージェントが読み取れないテーブルや、行のないテーブルは、エラーではなく警告として扱われます。以前のロードで取り込まれた内容はそのまま残り、ロードできるデータセットはロードされ、**準備状況**にそのテーブルが示されます。

## Sage 100 に転記する

**伝票を転記**ステップは、ほかの ERP と同じドキュメントのテーブルから Sage 100 接続に転記します。同じ[転記モード](/ja/guides/workflows/run-a-workflow/#転記モードの選択)を使用します。**シミュレート**では、Sage 100 に接続せずに各ドキュメントを作成して検証します。システムにライブで転記されるのは、実行がライブであり、かつプロジェクトにそのシステムの当日の書き込み承認がある場合に限られます。転記を追跡するには[転記レジスターを確認する](/ja/guides/connections/posting-register/)を、その背後にある台帳については[ERP転記履歴を確認する](/ja/guides/connections/erp-post-history/)を参照してください。

Sage 100 が受け付けるドキュメントは 2 種類です。

| ドキュメント | 転記される内容 | 必要な内容 |
|---|---|---|
| `journal` | 総勘定元帳の仕訳。 | 転記日と、すべての明細行の勘定科目。明細行は 1 セントまで貸借が一致している必要があり、仕訳の説明になる参照は 30 文字以内です。 |
| `payment` | Sage 100 の外部で行われた支払いを、仕入先の未払い請求書に対して記録する買掛金の手動小切手。 | 転記日、そのドキュメントの明細行全体で 1 つの仕入先、各明細行の `invoice_no` と正の金額、銀行コード、7 文字以内の参照（小切手番号になります）。銀行コードは `bank_code` 列、または Sage 100 システムに保存された必須の値で指定します。 |

何かを送信する前に、次の場合は理由とともにドキュメントが停止されます。

- 明細行の通貨が、接続の**Company currency**と異なる。
- `company` 列が、接続の**Company code**とは別の会社を指している。
- 仕訳の日付が Sage 100 で締め済みの期間にある、または支払いが、その金額では未払いでない請求書に対するものである（エージェントが判断できる場合。この 2 つのチェックはライブでの転記のみで実行されます）。

各ドキュメントは Sage 100 のバッチに入力され、PlaidCloud は読み戻して確認してから転記済みとします。表示される状態は次のとおりです。

- **転記済み**：読み戻しで、Sage 100 の転記済みテーブルにドキュメントが見つかった場合のみ。
- **待機中**：ドキュメントがバッチ内にあり、Sage 100 の更新を待っている場合。メッセージは「Entered in Sage, batch *n*」です。エージェントがオンラインの間、PlaidCloud は、このようなドキュメントについて約 1 時間ごとに Sage 100 に再確認し、表示されたら転記済みとして記録します。7 日を過ぎても入力済みのままのドキュメントは、未確認になります。
- **未確認**：Sage 100 に存在するかどうか PlaidCloud が判断できない場合。推測で再送信されることはないため、解決する前に Sage 100 を確認してください。
- **未転記**：Sage 100 がドキュメントを拒否した場合、またはエージェントがドキュメントを受け取らなかった場合（たとえばオフラインのとき）。拒否されたドキュメントは、修正後に再送信できます。

転記済みのドキュメントが二重に転記されることはありません。同じドキュメントを再実行しても、参照によって認識されます。

<Aside type="note">
PlaidLink はエージェントごとに同時に 1 つの Sage 100 セッションしか開かないため、1 つのエージェントからの転記は順番に実行されます。転記は、セッションを最大 1 分間待ち、利用できない場合は拒否されます。Sage 100 では、転記の取消は利用できません。
</Aside>
