[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP および会計システムのデータを、インスタンスの数に関係なく、1 つの Common Finance Model に集約します。Xero は、Data Foundation が直接読み取るシステムの 1 つで、1 つの接続につき 1 つの Xero 組織を読み取ります。このページは、アクセスを設定する Xero 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードをメールで送らないでください。

## アクセス依頼を送信する

**ホーム**の **Data Foundation** にあるプロジェクトの**システム**ページで、**システムを追加**の**システム**でお使いのシステムを選択し、**まだアクセス権がありませんか?** ボタンをクリックします。システムはアクセス待ちになり、プロジェクトのシステムを対象とする 1 件の依頼が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「PlaidCloud へのアクセス」でメールプログラムに開きます。

## Xero 管理者が設定する内容

<Steps>

1. Standard または Advanced ロールを持つユーザーとしてサインインし、レポート対象の組織ごとに **PlaidCloud の Xero アプリを承認**します。PlaidCloud ユーザーが **Xeroに接続**をクリックすると、Xero の同意画面で次のスコープが要求されます。

   | スコープ | Data Foundation が読み取る内容 |
   |---|---|
   | `offline_access` | なし。ロードの間も接続のサインイン状態を維持します |
   | `accounting.settings` | 組織、勘定科目表、トラッキングカテゴリ、品目 |
   | `accounting.contacts` | 顧客と仕入先 |
   | `accounting.transactions` | 売上請求書とクレジットノート、仕入請求書と仕入先クレジットノート、出金取引、支払、過払い、前払い |
   | `accounting.reports.read` | 期首残高と各月末残高のための試算表、および予算 |

   `accounting.settings`、`accounting.contacts`、`accounting.transactions` では変更も可能ですが、Data Foundation は読み取りのみを行います。総勘定元帳は Xero の仕訳から読み取られ、それには `accounting.journals.read` が必要ですが、同意画面ではこのスコープは要求されません。このスコープがないと、総勘定元帳をロードできません。勘定科目表、部門、顧客、製品は引き続きロードされます。

2. 次の名前で、**PlaidCloud が読み取るトラッキングカテゴリを設定**します。

   - **部門:** 部門ごとに 1 つのオプション。コードとして表示したい名前を付けます。
   - **サイト**と**プロフィットセンター**（省略可）: サイトやプロフィットセンターを追跡している場合は、サイトまたはプロフィットセンターごとに 1 つのオプション。
   - **Intercompany:** グループ会社ごとに 1 つのオプション。その会社のエンティティコードを名前にして、会社間仕訳の明細に付けます。会社間勘定科目には、勘定科目名に「Intercompany」が含まれるように名前を付けます。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| 組織の会計年度末と期間ロック日が設定されていることの確認 | 入力は不要です。PlaidCloud は両方を Xero から読み取ります |

送る必要のある ID、トークン、パスワードはありません。PlaidCloud ユーザーが、プロジェクトの**システム**ページで、**システムを追加**の**システム**で Xero を選択して **Xeroに接続**をクリックし、Xero ユーザーがサインインしてアプリを承認します。接続は、**組織**フィールドで選択した 1 つの組織をロードします。

**システム設定**の **Retained earnings account** には、勘定科目名からわからない場合に、期首の損益を繰り入れる資本勘定科目の名前を指定します。省略可能です。

## アクセスを確認する

PlaidCloud に戻り、システムを追加したら、**システム**ページのそのシステムの行で**接続をテスト**をクリックします。テストでは、必須のデータセット（エンティティ、勘定科目表、会計カレンダー、総勘定元帳、試算表）を読み取り、それぞれを**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示します。省略可能なデータセットはテストの対象外です。Xero がいずれかを拒否した場合、次回のロード後に準備状況チェックにそのデータセットが表示されます。

| データセット | 必要なスコープ |
|---|---|
| エンティティ | `accounting.settings.read` |
| 勘定科目表 | `accounting.settings.read` |
| 会計カレンダー | `accounting.settings.read` |
| 総勘定元帳 | `accounting.journals.read` |
| 試算表 | `accounting.reports.read` |
| 部門（省略可） | `accounting.settings.read`（Department トラッキングカテゴリ） |
| サイトと利益センター（省略可） | `accounting.settings.read`（Site と Profit centre トラッキングカテゴリ） |
| 製品（省略可） | `accounting.settings.read` |
| 顧客と仕入先（省略可） | `accounting.contacts.read` |
| 月末残高と銀行残高（省略可） | `accounting.reports.read`（各月末時点の試算表） |
| 売上明細（省略可） | `accounting.transactions.read` |
| 仕入先請求書明細（省略可） | `accounting.transactions.read`（仕入請求書、仕入先クレジットノート、出金取引） |
| 未決済項目と支払（省略可） | `accounting.transactions.read` |
| 予算（省略可） | `accounting.reports.read` |

データセットが**権限が不足しています**と表示された場合、テストにより、付与すべきスコープが示されます。そのスコープを付けてアプリを再承認し、もう一度テストしてください。売上請求書や予算がない Xero 組織でも、ほかのすべてのデータは読み込まれます。ある月の残高、売上、仕入請求書、未決済項目、支払の作成元となる読み取りを Xero が拒否した場合、その月は既存の行を保持し、次回のロードで再度読み取られます。

為替レートはこのアクセスの対象外です。Xero は為替レートを公開していません。代わりに **Currency rates** ファイルで提供してください。
