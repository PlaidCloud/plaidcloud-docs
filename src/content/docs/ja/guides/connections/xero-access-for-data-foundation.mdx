[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP および会計システムのデータを、インスタンスの数に関係なく、1 つの Common Finance Model に集約します。Xero は、Data Foundation が直接読み取るシステムの 1 つで、1 つの接続につき 1 つの Xero 組織を読み取ります。このページは、アクセスを設定する Xero 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードをメールで送らないでください。

## アクセス依頼を送信する

プロジェクトの **Foundation** タブで、**新しい接続を作成**を選択し、**Xero** を選びます。フォームに依頼内容の全文が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「Read-only Xero access for PlaidCloud」でメールプログラムに開きます。

## Xero 管理者が設定する内容

<Steps>

1. Standard または Advanced ロールを持つユーザーとしてサインインし、レポート対象の組織ごとに **PlaidCloud の Xero アプリを承認**します。アプリが要求するのは読み取りアクセスのみです。

   | スコープ | 対象 |
   |---|---|
   | `accounting.settings.read` | 組織、勘定科目表、トラッキングカテゴリ、品目 |
   | `accounting.contacts.read` | 顧客 |
   | `accounting.transactions.read` | 売上請求書とクレジットノート |
   | `accounting.journals.read` | 総勘定元帳: 転記済みのすべての仕訳 |
   | `accounting.reports.read` | 期首残高のための試算表 |

   `accounting.journals.read` がないと、総勘定元帳をロードできません。勘定科目表、部門、顧客、製品は引き続きロードされます。

2. 次の名前で、**PlaidCloud が読み取るトラッキングカテゴリを設定**します。

   - **部門:** 部門ごとに 1 つのオプション。コードとして表示したい名前を付けます。
   - **Intercompany:** グループ会社ごとに 1 つのオプション。その会社のエンティティコードを名前にして、会社間仕訳の明細に付けます。会社間勘定科目には、勘定科目名に「Intercompany」が含まれるように名前を付けます。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| 組織のテナント ID（Xero では接続の下に表示されるほか、`GET /connections` でも確認できます） | **Organisation (tenant) ID** |
| 組織の会計年度末と期間ロック日が設定されていることの確認 | 入力は不要です。PlaidCloud は両方を Xero から読み取ります |

PlaidCloud ユーザーは **Refresh token** を自分で貼り付けます。これはシークレットであり、メールでは送りません。また、接続がロードする**組織**も選択します。

**システム設定**の **Retained earnings account** には、勘定科目名からわからない場合に、期首の損益を繰り入れる資本勘定科目の名前を指定します。省略可能です。

## アクセスを確認する

PlaidCloud に戻って、**接続をテスト**をクリックします。各データセットは、**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示されます。

| データセット | 必要なスコープ |
|---|---|
| エンティティ | `accounting.settings.read` |
| 勘定科目表 | `accounting.settings.read` |
| 部門 | `accounting.settings.read`（Department トラッキングカテゴリ） |
| 製品 | `accounting.settings.read` |
| 会計カレンダー | `accounting.settings.read` |
| 顧客 | `accounting.contacts.read` |
| 総勘定元帳 | `accounting.journals.read` |
| 試算表 | `accounting.reports.read` |
| 売上明細（省略可） | `accounting.transactions.read` |
| 予算（省略可） | `accounting.reports.read` |

データセットが**権限が不足しています**と表示された場合、テストにより、付与すべきスコープが示されます。そのスコープを付けてアプリを再承認し、もう一度テストしてください。売上請求書や予算がない Xero 組織でも、ほかのすべてのデータは読み込まれます。

為替レートはこのアクセスの対象外です。Xero は為替レートを公開していません。代わりに **Currency rates** ファイルで提供してください。
