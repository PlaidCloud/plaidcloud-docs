[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP システムとインスタンスのデータを 1 つの Common Finance Model に集約します。Microsoft Dynamics 365 Business Central は、Data Foundation が直接読み取る ERP の 1 つです。この接続では、クライアント資格情報を使用する Microsoft Entra ID アプリケーション、読み取り専用の権限セット、および Web サービスとして公開されたいくつかのページを使用します。このページは、これを設定する Business Central 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。クライアントシークレットをメールで送らないでください。

## アクセス依頼を送信する

プロジェクトの **Foundation** タブで、**Business Central接続**の下にある**新しい接続を作成**を選択します。フォームに依頼内容の全文が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials)」でメールプログラムに開きます。

## Business Central 管理者が設定する内容

<Steps>

1. **Microsoft Entra ID にアプリを登録します。**  **App registrations > New registration** でクライアントシークレットを追加し、ディレクトリ（テナント）ID、アプリケーション（クライアント）ID、シークレットを控えます。

2. **Business Central にアプリを追加します。** **Microsoft Entra Applications** を開いてアプリケーションを追加し、状態を**有効**に設定して、レポート対象のすべての会社に権限セット **D365 READ** と **D365 BASIC** を付与します。書き込み権限セットは付与しないでください。

3. **ページを Web サービスとして公開します。** **Search > Web Services > New** で、次のページを、まったく同じサービス名で、**Published** にチェックを入れて公開します。標準 API にはこれらのフィールドが含まれていません。

   | ページ | サービス名 | 備考 |
   |---|---|---|
   | 20 G/L Entries | `GLEntries` | |
   | 16 Chart of Accounts | `GLAccounts` | |
   | 100 Accounting Periods | `AccountingPeriods` | |
   | 537 Dimension Values | `DimensionValues` | |
   | 240 Business Units | `BusinessUnits` | |
   | 605 IC Partner List | `ICPartners` | |
   | 5802 Value Entries | `ValueEntries` | 売上原価。省略可 |
   | 120 G/L Budget Entries | `GLBudgetEntries` | 予算。省略可 |
   | Statistical Ledger Entries | `StatisticalLedgerEntries` | 統計ドライバー。省略可 |
   | 118 General Ledger Setup | `GeneralLedgerSetup` | ショートカットディメンション 3～8。省略可 |
   | 479 Dimension Set Entries | `DimensionSetEntries` | ショートカットディメンション 3～8。省略可 |

4. **PlaidCloud ユーザーに次の 2 つの選択内容を伝えます。** 監査修正を転記するソースコード（PlaidCloud は `ADJUSTMENT` を想定します）と、どのディメンションが部門にあたるか（PlaidCloud はグローバルディメンション 1 の `DEPARTMENT` を想定します）。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| ディレクトリ（テナント）ID | **Directory (tenant) ID** |
| 環境名（例: `production`） | **環境名** |
| アプリケーション（クライアント）ID | **Application (client) ID** |
| クライアントシークレット | **クライアントシークレット**。メールではなくフォームから入力します |
| 部門にあたるディメンションの名前 | システム設定 `department_dimension` |
| PlaidCloud が読み取りを許可される会社 | PlaidCloud の **Companies** で選択（1 社以上） |

連結会社にあたる会社は、システム設定 `consolidation_companies` に指定します。これにより、それらの会社の仕訳は 1 社の活動として計上されません。為替レートは 1 社から取得します。システム設定 `rate_company` にその会社を指定してください。指定しない場合、PlaidCloud は最初の会社を使用します。

## アクセスを確認する

PlaidCloud に戻って値を入力し、**接続をテスト**をクリックします。各データセットは、**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示されます。

| データセット | 必要なもの |
|---|---|
| エンティティ、勘定科目表、顧客、製品、為替レート、試算表 | API アクセス（権限セット D365 READ） |
| 会計カレンダー | `AccountingPeriods` Web サービス |
| 部門 | `DimensionValues` Web サービス |
| 総勘定元帳 | `GLEntries` Web サービス |
| 売上明細、予算、配賦ドライバー | 省略可 |

データセットが不足している場合、テストにより、追加すべき権限または Web サービスが示されます。管理者に追加を依頼して、もう一度テストしてください。売上明細、予算、配賦ドライバーは省略可能です。これらを使用しない環境でも、ほかのすべてのデータは読み込まれます。
