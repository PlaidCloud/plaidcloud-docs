[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべてのERPシステムとインスタンスのデータを1つのCommon Finance Modelに集約します。Microsoft Dynamics 365 Business Centralは、Data Foundationが直接読み取るERPの1つです。この接続では、クライアント資格情報を使用するMicrosoft Entra IDアプリケーション、読み取り専用の権限セット、およびWebサービスとして公開したいくつかのページオブジェクトを使用します。このページは、これらを設定するBusiness Central管理者と、管理者に設定を依頼するPlaidCloudユーザーを対象としています。

PlaidCloudはデータの読み取りのみを行います。クライアントシークレットをメールで送信することは決してありません。

## アクセスリクエストの送信

プロジェクトの**Foundation**タブで、**Business Central接続**の下にある**新しい接続を作成**を選択します。フォームにリクエストの全文が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックしてメールプログラムで開きます。件名は「Read-only Business Central access for PlaidCloud (Microsoft Entra ID, client credentials)」です。

## Business Central管理者が設定する内容

<Steps>

1. **Microsoft Entra IDでアプリを登録します。** **App registrations > New registration**でクライアントシークレットを追加し、ディレクトリ（テナント）ID、アプリケーション（クライアント）ID、シークレットを控えておきます。

2. **Business Centralにアプリを追加します。** **Microsoft Entra Applications**を開いてアプリケーションを追加し、状態を**有効**に設定して、レポート対象のすべての会社に対して権限セット**D365 READ**と**D365 BASIC**を付与します。書き込み用の権限セットは付与しないでください。

3. **ページオブジェクトをWebサービスとして公開します。** **Search > Web Services > New**で、次のページオブジェクトを、表のとおりの**サービス名**で、**Published**にチェックを入れて公開します。標準APIにはこれらのフィールドが含まれていません。

   | ページ | サービス名 | 備考 |
   |---|---|---|
   | 20 総勘定元帳エントリ | `GLEntries` | |
   | 16 勘定科目表 | `GLAccounts` | |
   | 100 会計期間 | `AccountingPeriods` | |
   | 537 ディメンション値 | `DimensionValues` | |
   | 240 ビジネスユニット | `BusinessUnits` | |
   | 605 IC取引先一覧 | `ICPartners` | |
   | 5802 値エントリ | `ValueEntries` | 売上原価。任意 |
   | 120 総勘定元帳予算エントリ | `GLBudgetEntries` | 予算。任意 |
   | 統計元帳エントリ | `StatisticalLedgerEntries` | 統計ドライバー。任意 |
   | 118 総勘定元帳設定 | `GeneralLedgerSetup` | ショートカットディメンション3～8。任意 |
   | 479 ディメンションセットエントリ | `DimensionSetEntries` | ショートカットディメンション3～8。任意 |

4. **PlaidCloudユーザーに2つの選択内容を伝えます。** 監査修正の転記に使用するソースコード（PlaidCloudは`ADJUSTMENT`を想定しています）と、部門にあたるディメンション（PlaidCloudはグローバルディメンション1の`DEPARTMENT`を想定しています）です。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloudでの入力先 |
|---|---|
| ディレクトリ（テナント）ID | **Directory (tenant) ID** |
| 環境名（例: `production`） | **環境名** |
| アプリケーション（クライアント）ID | **Application (client) ID** |
| クライアントシークレット | **クライアントシークレット**（メールではなく、フォームから入力） |
| 部門にあたるディメンションの名前 | システム設定`department_dimension` |
| PlaidCloudが読み取ってよい会社 | PlaidCloudの**Companies**で選択（1社以上） |

連結会社にあたる会社は、システム設定`consolidation_companies`に指定します。これにより、連結会社のエントリが会社の活動として集計されなくなります。為替レートは1つの会社から取得します。システム設定`rate_company`でその会社を指定してください。指定しない場合、PlaidCloudは最初の会社を使用します。

## アクセスの確認

PlaidCloudに戻って値を入力し、**接続をテスト**をクリックします。各データセットは、**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示されます。

| データセット | 必要なもの |
|---|---|
| エンティティ、勘定科目表、顧客、製品、為替レート、試算表 | APIアクセス（権限セットD365 READ） |
| 会計カレンダー | `AccountingPeriods`Webサービス |
| 部門 | `DimensionValues`Webサービス |
| 総勘定元帳 | `GLEntries`Webサービス |
| 売上明細、予算、配賦ドライバー | 任意 |

データセットが不足している場合は、追加する権限またはWebサービスがテスト結果に表示されます。管理者に追加を依頼してから、もう一度テストしてください。売上明細、予算、配賦ドライバーは任意です。これらを使用しない環境でも、それ以外のデータはすべて読み込まれます。
