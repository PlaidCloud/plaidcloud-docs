[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP システムとインスタンスのデータを 1 つの Common Finance Model に集約します。SAP ECC は、Data Foundation が直接読み取る ERP の 1 つです。PlaidCloud は、自社ネットワークにインストールされた [PlaidLink](/ja/reference/cli/plaidlink/) エージェント経由で、RFC を使用してシステムにアクセスします。このページは、これを設定する SAP 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードをメールで送らないでください。

## アクセス依頼を送信する

**ホーム**の **Data Foundation** にあるプロジェクトの**システム**ページで、**システムを追加**の**システム**でお使いのシステムを選択し、**まだアクセス権がありませんか?** ボタンをクリックします。システムはアクセス待ちになり、プロジェクトのシステムを対象とする 1 件の依頼が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「PlaidCloud へのアクセス」でメールプログラムに開きます。

## SAP 管理者が設定する内容

<Steps>

1. レポート元のクライアントに **PlaidCloud ABAP パッケージをインストール**し（`Z_PLAIDCL_B5_READ_TABLE` のファンクショングループ）、RFC でシステムにアクセスできる PlaidLink エージェントをインストールします。

2. 次の権限を持つロールを割り当てた**通信ユーザーを作成**します（例: `PLAIDCLOUD_RFC`）。

   - `S_RFC`: `Z_PLAIDCL_B5_READ_TABLE` のファンクショングループを実行します。
   - 以下のテーブルに対する `S_TABU_NAM`（表示、`ACTVT` 03）。

   | テーブル | 保持する内容 |
   |---|---|
   | `T001` | 会社コード |
   | `T009`, `T009B`, `T001B` | 会計年度変式と転記期間 |
   | `SKA1`, `SKAT` | G/L 勘定 |
   | `FAGL_011PC`, `FAGL_011ZC` | 財務諸表バージョン |
   | `CSKS`, `CSKT` | コストセンター |
   | `SETHEADER`, `SETNODE` | コストセンターとプロフィットセンターのグループ |
   | `CEPC`, `CEPCT` | プロフィットセンター（省略可） |
   | `KNA1`, `KNVV`, `KNVH` | 顧客とその階層 |
   | `MARA`, `MAKT`, `T006A` | 品目と単位 |
   | `TCURR`, `TCURF`, `TCURX` | 為替レートと通貨の小数桁 |
   | `BKPF`, `BSEG` | 会計伝票とその明細 |
   | `FAGLFLEXT`、またはクラシック総勘定元帳の場合は `GLT0` | 総勘定元帳の合計 |
   | `CSKB`, `CSKU`, `COEP` | 原価要素と管理会計の明細: 賦課と配賦 |
   | `COSP`, `COSS`, `COSR` | コストセンターの計画と統計キー数値（省略可） |
   | `VBRK`, `VBRP`, `KONV` | 請求伝票とその価格条件（省略可） |
   | `T001K`, `MBEW`, `MBEWH` | 評価領域、品目の在庫評価額、標準価格（省略可） |
   | `T001W`, `TKA02` | サイトとして読み取られるプラント、および各会社コードの管理領域（省略可） |
   | `T016T`, `TKUKT`, `KNVP`, `TSPAT`, `T052U` | 業種と顧客分類の名称、各顧客の営業担当者、製品部門と支払条件の名称（省略可） |
   | `T012K`, `T012T` | 取引銀行口座。銀行残高用（省略可） |
   | `LFA1`, `LFB1` | 仕入先（省略可） |
   | `RBKP`, `RSEG` | 仕入先請求書（省略可） |
   | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` | 発注書とその入庫および請求書（省略可） |
   | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095`, `ANLC`, `ANEP`, `ANEA`, `ANLP` | 固定資産台帳とその異動（省略可） |
   | 事業領域の明細テーブル（`CE1` の後に事業領域名が続くもの） | 評価別 CO-PA（省略可） |

   未決済項目と支払は、`BSEG` の得意先明細と仕入先明細、およびその `BKPF` ヘッダーから読み取られます。

3. **会計に関する質問に回答します**（以下を参照）。

</Steps>

### 管理者が回答する質問

| 管理者があなたに伝える内容 | PlaidCloud の**システム設定**への入力先 |
|---|---|
| 平均レートを保持する為替レートタイプ。PlaidCloud は、そのタイプの各月のレートを平均します。多くの場合 `M` です。 | **Average rate type** |
| 期末レート（月末のレート）を保持する為替レートタイプ。指定しない場合、期末レートは `M` レートになります。 | **Closing rate type** |
| システムが新総勘定元帳（`FAGLFLEXT`）とクラシック総勘定元帳（`GLT0`）のどちらを実行しているか | **General ledger totals table** |
| 管理損益計算書と貸借対照表をレポートする財務諸表バージョン | **Financial statement version** |
| そのノードのうち、収益、売上原価、営業費用、営業外、資産、負債、資本、会社間にあたるもの | **Account type of each statement node**：1 行に 1 つのノードを `node = type` の形式で指定します。タイプには、ボックスに一覧表示されるもの（`Revenue`、`Asset` など）を使用します。会社間ノードは **Intercompany statement nodes** で指定します。どちらも、**Financial statement version** が設定されている場合にのみ適用されます。 |
| レポート対象の会計年度ごとに残高繰越が実行済みであること（`FAGLGVTR`、クラシック総勘定元帳では `F.16`） | 入力は不要です。期首残高は合計テーブルから読み取られます。 |
| 会計用または税務用の各資産台帳の償却領域。最初の領域が資産台帳のものです。PlaidCloud は、領域 `01` を会計用の台帳と想定します。 | **Depreciation area of each book** |
| 各資産取引タイプの異動タイプ（先頭の桁による）。PlaidCloud は、`1` を取得、`2` を除却、`3` を振替、`6` を償却、`9` を期首と想定します。 | **Movement type of each transaction type** |
| 評価別 CO-PA を読み取る場合は、事業領域の明細テーブル。指定しない場合、CO-PA は読み取られません。 | **Operating concern line item table** |
| 各勘定科目の CO-PA 値項目と、そのうち原価にあたるもの | **Value field of each CO-PA account**、**CO-PA cost value fields** |

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| システム ID とアプリケーションサーバー（またはメッセージサーバーとログオングループ） | **ホスト**と**システム番号**、または**負荷分散されたマルチシステム接続を使用**の場合は **MSホスト**、**MSサーバー**、**システムID**、**グループ** |
| クライアント | **クライアント** |
| 通信ユーザーの名前 | **ユーザー** |
| 通信ユーザーのパスワード（パスワードマネージャー経由） | **パスワード**。チームが自分で入力します |
| システムにアクセスする PlaidLink エージェントの名前 | システム設定 **PlaidLink agent** |
| PlaidCloud が読み取りを許可される会社コード | **オプション**の**会社**に入力します。SAP は一覧表示できないため、会社コードをカンマ区切りで入力するか、空のままにしてすべての会社コードをロードします |

<Aside type="caution">
パスワードをメールで送らないでください。**パスワード**はシークレットです。接続に保存され、再表示されません。
</Aside>

## アクセスを確認する

SAP は PlaidLink エージェント経由で読み取られるため、**接続をテスト**では SAP を読み取りません。読み取りは最初のロードで行われ、ユーザーが読み取れないテーブルはその時点で示されます。各データセットが読み取るテーブルは次のとおりです。

| データセット | 読み取るテーブル |
|---|---|
| エンティティ | `T001` |
| 会計カレンダー | `T001`, `T009`, `T009B`, `T001B` |
| 為替レート | `TCURR`, `TCURF` |
| 勘定科目表 | `SKA1`, `SKAT`, `FAGL_011PC`, `FAGL_011ZC`, `CSKB`, `CSKU` |
| 部門 | `CSKS`, `CSKT`, `SETHEADER`, `SETNODE` |
| プロフィットセンター | `CEPC`, `CEPCT`, `SETHEADER`, `SETNODE` |
| 顧客 | `KNA1`, `KNVV`, `KNVH` |
| 製品 | `MARA`, `MAKT`, `T006A` |
| 総勘定元帳 | `BKPF`, `BSEG`, `COEP` |
| 試算表 | `FAGLFLEXT` または `GLT0` |
| 売上明細 | `VBRK`, `VBRP`, `KONV` |
| 予算 | `COSP`, `COSS` |
| 配賦ドライバー | `COSR` |
| 在庫残高 | `MBEW`, `MBEWH`, `T001K` |
| 月末残高 | `FAGLFLEXT` または `GLT0`、各月末時点の残高 |
| 銀行残高 | `T012K`, `T012T`、および各取引銀行の G/L 勘定の月末残高 |
| サイト | `T001W`, `T001K` |
| 仕入先 | `LFA1`, `LFB1` |
| 仕入先請求書明細 | `RBKP`, `RSEG`, `BKPF` |
| 発注書 | `EKKO`, `EKPO`, `EKKN`, `EKET`, `EKBE` |
| 未決済項目、支払 | `BSEG` の得意先明細と仕入先明細、`BKPF` |
| 固定資産 | `ANLA`, `ANLZ`, `ANLB`, `ANKA`, `T095` |
| 資産の異動 | `ANLC`, `ANEP`, `ANEA`, `ANLP` |
| 標準原価 | `T001K`, `MBEW`, `MBEWH` |
| 評価別 CO-PA | **Operating concern line item table** に指定したテーブル |

ロードでユーザーが読み取れないテーブルが示された場合は、管理者にロールへのテーブルの追加を依頼して、もう一度ロードしてください。プロフィットセンター、売上明細、予算、配賦ドライバー、在庫残高、および月末残高以下のすべてのデータセットは省略可能です。いずれかを保持していないシステムでも、ほかのすべてのデータは読み込まれます。ある月の銀行残高、未決済項目、支払を SAP が拒否した場合、その月は既存の行を保持します。

G/L 勘定を共有する取引銀行口座は、G/L 勘定の残高が 1 つであるため、まとめて 1 つの残高行になります。
