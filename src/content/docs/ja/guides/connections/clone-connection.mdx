## 説明

複製すると、既存の接続の構成（ホスト、ポート、オプション、認証情報の参照）が複製されるため、すべての設定を入力し直すことなく、いくつかのフィールドを編集して新しい接続として保存できます。

複製は、データベース、ERP、REST、クラウドサービス、Git、ドキュメントなど、すべての種類の外部データ接続で利用できます。


## 接続を複製する

1. **Tools > Connections**を開きます
2. コピーする接続を選択します
3. ツールバーの`Clone`をクリックします（または行を右クリックして`Clone`を選択します）
4. 新しい接続の名前と、異なる設定にするフィールドを編集します
5. `Save`をクリックします


## 所有者のみのアクション

`Edit`、`Clone`、`Delete`は、ご自身が所有する接続でのみ使用できます。選択した行でこれらのツールバーボタンがグレーアウトしている場合、お客様は所有者ではありません。所有者に接続の複製を依頼するか、`Edit Owners`で追加の所有者として登録してもらってください。

<Aside>複製されるのは構成のみで、テスト結果や実行履歴は複製されません。ワークフローで使用する前に、複製した接続をテストしてください。</Aside>
