[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP システムとインスタンスのデータを 1 つの Common Finance Model に集約します。Oracle Fusion Cloud ERP は、Data Foundation が直接読み取る ERP の 1 つです。Oracle Fusion 接続では、OAuth 2.0 クライアント資格情報、読み取り専用の統合ユーザー、および少数の BI Publisher レポートを使用します。このページは、これを設定する Oracle Fusion 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードやクライアントシークレットをメールで送らないでください。

## アクセス依頼を送信する

**ホーム**の **Data Foundation** にあるプロジェクトの**システム**ページで、**システムを追加**の**システム**でお使いのシステムを選択し、**まだアクセス権がありませんか?** ボタンをクリックします。システムはアクセス待ちになり、プロジェクトのシステムを対象とする 1 件の依頼が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「PlaidCloud へのアクセス」でメールプログラムに開きます。

## Oracle Fusion 管理者が設定する内容

<Steps>

1. **統合ユーザーを作成**し、レポート対象のすべての元帳について、表示のみが可能なカスタムジョブロールを付与します。General Accountant など、入力、転記、承認ができるロールは使用しないでください。ロールには次の内容が必要です。

   - 総勘定元帳: 元帳、会計カレンダーと期間ステータス、仕訳バッチ、仕訳、勘定残高（照会権限と、これらの元帳へのデータアクセス）
   - 通貨換算レート（日次レート）
   - キーフレックスフィールドのセグメントラベル、値セット、およびその勘定科目階層（ツリー）
   - 売掛金と買掛金: 請求書、入金、支払とその配分、および顧客アカウントと仕入先
   - 現金管理の銀行口座
   - 在庫品目と手持数量
   - デプロイする省略可能なレポートごとに、対応する表示専用アクセス: 購買（View Purchase Order、`PO_VIEW_PURCHASE_ORDER_PRIV`、および入荷照会。調達ビジネスユニットへのデータアクセス付き）、固定資産（資産照会。法人台帳と税務台帳へのデータアクセス付き）、原価管理（Review Item Costs。原価組織へのデータアクセス付き）、予算（総勘定元帳の予算残高照会）
   - 手順 3 の BI Publisher レポートと ERP Integration Service（ESS ジョブ）の実行アクセス

2. ID ドメイン（IAM）に、クライアント資格情報グラントと Fusion Applications REST API のスコープを持つ**機密アプリケーションを登録**します。そのクライアント ID とシークレットをコピーします。

3. `/Custom/PlaidCloud/DataFoundation` に **BI Publisher レポートをデプロイ**します。それぞれ ESS ジョブとして、レポート名をジョブ定義にして実行され、依頼に記載された列を持つ CSV を返します。最初の 6 つは必須で、元帳はこれらから作成されます。それ以外は省略可能です。省略したレポートが提供するデータは空のままになり、ほかには影響しません。

   | レポート | 返す内容 |
   |---|---|
   | `PlaidCloudKeyFlexLabels` | 総勘定元帳の各勘定科目表のセグメントごとに 1 行: その位置、ラベル、値セット |
   | `PlaidCloudSegmentValues` | それらの値セットのすべての値。自然勘定科目タイプと値の階層を含む |
   | `PlaidCloudCalendar` | すべての元帳の会計期間。元帳の期間平均と期間末のレートタイプを含む |
   | `PlaidCloudCodeCombinations` | コード組み合わせとそのセグメント |
   | `PlaidCloudBalances` | 調整期間を含む、すべての期間のすべての元帳の残高: 期首残高と、元帳と比較される月末残高 |
   | `PlaidCloudJournalLines` | 仕訳明細。元帳、期間、残高セグメント値ごとに 1 つずつ読み取り。各仕訳の入力者と承認者、その日時、および取り消す仕訳を含む |
   | `PlaidCloudCustomers` | 顧客アカウントとその取引先名（省略可） |
   | `PlaidCloudItems` | マスター在庫組織の品目（省略可） |
   | `PlaidCloudSalesLines` | 売掛金請求書明細ごとに 1 行（省略可） |
   | `PlaidCloudSites` | `GL_SITE` セグメントの値（省略可） |
   | `PlaidCloudSuppliers` | 仕入先（省略可） |
   | `PlaidCloudArDocuments`, `PlaidCloudReceipts` | 売掛金の取引とその消込内容。未決済項目と支払用（省略可） |
   | `PlaidCloudApInvoices`, `PlaidCloudApPayments` | 買掛金の請求書とその消込内容。未決済項目と支払用（省略可） |
   | `PlaidCloudApInvoiceLines` | 買掛金請求書明細ごとに 1 行（省略可） |
   | `PlaidCloudBankBalances` | 各月末時点の各銀行口座自体の残高（省略可） |
   | `PlaidCloudInventory` | 各月末時点のすべての品目と保管場所の手持数量と金額（省略可） |
   | `PlaidCloudBudget` | 月別の承認済み予算（省略可） |
   | `PlaidCloudPurchaseOrders`, `PlaidCloudPurchaseOrderEvents` | 発注明細と、その入荷および照合済み請求書（省略可） |
   | `PlaidCloudAssets`, `PlaidCloudAssetMovements` | 法人台帳の資産台帳と、法人台帳および税務台帳での各資産の異動（省略可） |
   | `PlaidCloudStandardCosts` | 月ごとの各品目の標準原価（省略可） |

   各レポートの正確な列は、アクセス依頼の本文に記載されています。レポート名は、表示されているとおりに指定してください。以前のバージョン用に `PlaidCloudBalances` または `PlaidCloudApInvoices` をデプロイ済みの場合は、依頼の記載に従って拡張してください。`PlaidCloudBalances` は、すべての期間をその期間の取引とともに返す必要があります。

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| `https://` を除いた、Fusion Applications URL のホスト | **Podホスト** |
| ID ドメインのトークン URL | **IDドメインのトークンURL** |
| REST API アプリケーションのスコープ | **スコープ** |
| 手順 2 のクライアント ID | **クライアントID** |
| 手順 2 のクライアントシークレット | **クライアントシークレット** |
| PlaidCloud が読み取りを許可される残高セグメント値 | **オプション**の**会社**に入力します。Fusion は一覧表示できないため、値をカンマ区切りで入力するか、空のままにしてすべてをロードします |

依頼文の最後のリストでは、これらの値をまとめて尋ねています。クライアントシークレットは、メールではなくパスワードマネージャー経由で共有してください。PlaidCloud ユーザーのチームが、自分で PlaidCloud に貼り付けます。

## アクセスを確認する

PlaidCloud に戻り、システムを追加したら、**システム**ページのそのシステムの行で**接続をテスト**をクリックします。テストでは、必須の各データセットについて 1 つのオブジェクトを読み取り、各データセットを**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示します。レポート自体は最初のロード時に実行され、省略可能なレポートはテストの対象外です。存在しないレポートや、ユーザーが実行できないレポートは、次回のロード時に示されます。

| データセット | テストで読み取るもの |
|---|---|
| エンティティ、会計カレンダー、勘定科目表、部門、試算表 | 元帳 |
| 為替レート | 日次換算レート |
| 総勘定元帳 | 仕訳バッチ |

データセットが不足している場合、テストにより、追加すべき権限が示されます。管理者にジョブロールへの追加を依頼して、もう一度テストしてください。省略可能なレポートがない Fusion ポッドでも、ほかのすべてのデータは読み込まれます。顧客、製品、サイト、仕入先は空のまま読み込まれ、その他のデータセットは、レポートを再び読み取れるようになるまで、以前のロードで取り込んだ内容を保持します。

Oracle Fusion には、Data Foundation が読み取るプロフィットセンターの一覧がありません。仕訳明細のプロフィットセンターは、勘定科目表の管理セグメントです。
