[Data Foundation](/ja/guides/projects/data-foundation/)は、接続したすべての ERP システムとインスタンスのデータを 1 つの Common Finance Model に集約します。Sage Intacct は、Data Foundation が直接読み取る ERP の 1 つです。この接続では Intacct Web Services を使用します。PlaidCloud 用の送信者の承認と、読み取り専用の Web Services ユーザーです。このページは、これを設定する Sage Intacct 管理者と、管理者に依頼する PlaidCloud ユーザーを対象としています。

PlaidCloud はデータを読み取るだけです。パスワードをメールで送らないでください。

## アクセス依頼を送信する

プロジェクトの **Foundation** タブで、**Sage Intacct接続**の下にある**新しい接続を作成**を選択します。フォームに依頼内容の全文が表示されます。**リクエストをコピー**をクリックして自分のメッセージに貼り付けるか、**リクエストをメールで送信**をクリックして、件名「Read-only Sage Intacct access for PlaidCloud (Web Services)」でメールプログラムに開きます。

## Sage Intacct 管理者が設定する内容

<Steps>

1. **PlaidCloud を Web Services 送信者として承認します。** **Company > Admin > Web Services authorizations** で、PlaidCloud から提供された Sender ID を追加します。Sender ID と、Sage がそれに対して発行した Sender password を返送してください。

2. **Web Services ユーザーを作成します。** **Company > Admin > Users** で、タイプが「Business」で「Web services only」オプションを持つユーザーと、次の対象に対する**表示**権限を持つロールを作成します。

   | 領域 | オブジェクト |
   |---|---|
   | 総勘定元帳 | 勘定科目、仕訳（調整仕訳を含むすべての仕訳帳）、勘定残高、報告期間、為替レート、予算 |
   | 会社 | エンティティ（ロケーション）、部門、クラス、プロジェクト |
   | 売掛金 | 顧客 |
   | 在庫管理 | 品目 |
   | 受注入力 | トランザクション（売上請求書と、それを取り消すクレジットメモおよび返品）。売上を含める場合 |

   ユーザーには、会社の最上位レベルと、PlaidCloud がレポートするすべてのエンティティへのアクセスを付与してください。クレジットメモと返品のトランザクション定義の名前が Sales Credit Memo と Sales Return でない場合は、その名前を PlaidCloud ユーザーに伝えてください。

3. 会社が IP で Web Services を制限している場合は、**ユーザーの IP アドレスを許可します。**

</Steps>

## 返送する情報

| 管理者が送る情報 | PlaidCloud での入力先 |
|---|---|
| 会社 ID | **会社ID** |
| Web Services ユーザー ID | **Web services user ID** |
| Web Services ユーザーのパスワード | **Web services password** |
| Sender ID | **Sender ID** |
| Sender password | **Sender password** |
| クレジットメモと返品のトランザクション定義の名前（デフォルトでない場合） | システム設定 `credit_documents`（デフォルト: Sales Credit Memo、Sales Return） |
| PlaidCloud が読み取りを許可されるエンティティ | PlaidCloud の**エンティティ**で選択 |

パスワードはパスワードマネージャー経由で受け渡し、メールでは送らないでください。PlaidCloud ユーザーのチームが、**Web services password** と **Sender password** を自分で PlaidCloud に貼り付けます。会社自身の消去用エンティティは、システム設定 `elimination_entities` に指定します。

## アクセスを確認する

PlaidCloud に戻って値を入力し、**接続をテスト**をクリックします。各データセットは、**読み取り可能**、**権限が不足しています**、**エラー**のいずれかで表示されます。

| データセット | 必要な権限 |
|---|---|
| エンティティ | 会社: エンティティ（表示） |
| 勘定科目表 | 総勘定元帳: 勘定科目と統計勘定（表示） |
| 部門 | 会社: 部門（表示） |
| 顧客 | 売掛金: 顧客（表示） |
| 製品 | 在庫管理: 品目（表示） |
| 為替レート | 総勘定元帳: 為替レート（表示） |
| 会計カレンダー | 総勘定元帳: 報告期間（表示） |
| 試算表 | 総勘定元帳: 勘定残高（表示） |
| 総勘定元帳 | 総勘定元帳: 仕訳（表示） |
| 売上明細 | 受注入力: トランザクション（表示） |
| 予算 | 総勘定元帳: 予算（表示） |
| 配賦ドライバー | 総勘定元帳: 勘定残高（表示） |

データセットが不足している場合、テストにより、追加すべき権限が示されます。管理者にロールへの追加を依頼して、もう一度テストしてください。売上明細、予算、配賦ドライバーは省略可能です。これらを使用しない会社でも、ほかのすべてのデータは読み込まれます。
