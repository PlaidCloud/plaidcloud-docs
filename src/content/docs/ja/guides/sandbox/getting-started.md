## サンドボックスとは
PlaidCloud サンドボックスでは、データと PlaidCloud の操作にネイティブなローカルアクセスを持つ独自のカスタムアプリをデプロイできます。サンドボックス環境は、PlaidCloud の利用を拡張するカスタムアプリケーションを構築するための完全なコンピュート環境を提供します。

すべてのカスタムアプリは Kubernetes のデプロイプロセスで実行されるため、Kubernetes オブジェクトの基本的な理解が必要です。シンプルなアプリケーションをデプロイする方法は、[Hello World の例](https://github.com/PlaidCloud/custom-app-template)で確認できます。

## 利用可能なリソース
サンドボックスアプリには、リソースの使用が乱用されないことを前提としたソフトリソース制限があります。必要であれば大量のコンピュートにも対応できますが、デプロイを試みる前にご相談ください。大きなリソースが必要になる見込みの場合は、お問い合わせください。

サンドボックスで実行されるアプリケーションは、Lakehouse と、必要な数の Postgres データベースに直接アクセスできます。Postgres データベースは中規模のデータを扱うように設計されているため、構成やその他のメタデータの保存に最適です。主要なデータの保存には、大量のデータを保存しながらパフォーマンスを維持できる Lakehouse を使用してください。

すべての PlaidCloud API も、データ転送速度を高めるため、公開 URL を使用せずにサンドボックスから直接利用できます。

## イメージの要件

Docker ベースの Kubernetes デプロイをサポートするイメージであれば、カスタムアプリに使用できます。現在サポートされているのは *nix ベースのイメージのみです。Windows ベースのイメージを実行する必要がある場合は、お問い合わせください。

## CI/CD パイプラインとの統合

サンドボックスアプリの Kubernetes デプロイでは、GitOps プロセスを使用します。これにより、イメージのビルドとデプロイに独自の CI/CD プロセスを実装できます。カスタムアプリの Git リポジトリは常に変更が監視されており、更新が行われるとサンドボックスも更新されます。
