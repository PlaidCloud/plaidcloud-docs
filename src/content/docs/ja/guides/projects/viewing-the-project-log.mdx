## プロジェクトログの表示と並べ替え

メンバーの新規割り当てやワークフローの実行など、プロジェクト内で操作が行われると、プロジェクトログにそのイベントが保存されます。プロジェクトログは、個々のワークフローログの表示を統合し、プロジェクトのアクティビティをより包括的に確認できるようにします。PlaidCloud では、プロジェクトログの並べ替えとフィルタリング、および特定のログエントリの詳細の表示もできます。


**プロジェクトログを表示するには、次の手順に従います。**
1. Analyze を開きます
2. 「プロジェクト」を選択します
3. ログアイコンをクリックします

**プロジェクトログを並べ替えてフィルタリングするには、次の手順に従います。**
1. ログの右側、「ログメッセージ」の左側にある小さなアイコンをクリックします
2. 目的の条件を選択します

**特定のログエントリの詳細を表示するには、次の手順に従います。**
1. 目的のログエントリを右クリックします
2. 「ログメッセージ」ボックスで詳細を確認します

## プロジェクトログのクリア

プロジェクトログは、必要に応じてクリアできます

<Aside>プロジェクトログをクリアすると、各ワークフローのサブログもすべて削除されます</Aside>

**プロジェクトログをクリアするには、次の手順に従います。**
1. Analyze を開きます
2. 「プロジェクト」を選択します
3. ログアイコンをクリックします
4. 「Clear Log」ボタンをクリックします
