**オペレーショナル移転価格**テンプレートは、各検証対象会社の利益水準指標を、ポリシーが定める範囲に照らしてテストし、範囲外のエンティティを目標に戻すtrue-upを算出します。[Common Finance Model](/ja/guides/projects/data-foundation/)をベースにしており、**企業収益性**が構築するものをすべて含みます。

<Aside type="note">
これは、年間を通じてポリシーをモニタリングするための管理用ビューです。移転価格の調査報告書や申告書ではありません。
</Aside>

## 仕組み

テンプレートは、エンティティと期間ごとに次の処理を行います。

1. 検証対象会社の損益計算書を、エンティティの**現地通貨**で構築します。これは、そのエンティティが帳簿をつけ、true-upを計上する通貨だからです。収益は、会社間取引と第三者取引に分けられます。
2. 会計年度の年初来で合計します。調整期間は、その年の期間として扱われるため、年の最後の行が通年の値になります。
3. エンティティに適用されているポリシーを特定します。
4. 年初来の値で利益水準指標をパーセントで計算し、範囲と比較します。

## 利益水準指標

エンティティごとに1つの**レンズ**を選択します。

| レンズ | 定義 |
|---|---|
| `ros` | 売上高利益率（ROS）：EBIT ÷ 検証対象会社の売上高。 |
| `ncp` | ネットコストプラス：EBIT ÷ 総コスト。 |
| `resale_minus` | 再販売価格基準：売上総利益 ÷ 売上高。 |

EBITは、収益から売上原価と営業費用を差し引いたものです。営業外の行は含まれません。売上高は、第三者取引と会社間取引を合わせた、エンティティのすべての収益です。利益はそのすべてから生じるためです。

## ポリシーテーブル

範囲は、テーブル`otp_policy_targets`に、エンティティと、ポリシーが有効になる期間ごとに1行で保持されます。このテーブルは自由に編集でき、モデルがこのテーブルに書き込むことはありません。

| 列 | 内容 |
|---|---|
| `entity` | 検証対象会社。 |
| `role` | その役割を示すラベル（例：限定リスクのディストリビューター）。 |
| `lens` | `ros`、`ncp`、または`resale_minus`。 |
| `low`、`target`、`high` | 範囲と目標値（パーセント）。`low <= target <= high`。 |
| `effective_from_period` | 行が有効になる月（`YYYY-MM`形式）。そのエンティティの次の行が有効になるまで有効です。 |

エンティティには、一度に1つのポリシーがあります。レンズや範囲の変更は、より後の`effective_from_period`を持つ新しい行として追加します。サンプルデータには3つの例の行があります。自社のものに置き換えてください。

無効な月、空白のレンズ、low、target、high、順序が正しくない範囲など、判定できない行があると、そのエンティティの結果は推測されずに**incomplete**になります。

## 結果

結果テーブルには、エンティティと期間ごとに、年初来の指標とステータスが表示されます。

| ステータス | 意味 |
|---|---|
| `in` | 範囲内（境界値を含む）。 |
| `below`、`above` | 範囲外。 |
| `n-a` | 基準となる売上高またはコストが正でない。 |
| `incomplete` | ポリシー行に問題があるか、比較に必要な情報が不明。空白が`in`と判定されることはありません。 |

エンティティが範囲外の場合、`true_up_ytd`は、年初来で目標に到達するために検証対象会社に加算する利益（負の場合は差し引く利益）で、現地通貨で表されます。`true_up`は、その期間における変化分であるため、1年分の期間を合計すると、その年のtrue-upになります。true-upは、グループ通貨でも表示されます。

アシスタントとダッシュボード向けのメトリック：**TP true-up**、**Tested-party EBIT**、**Tested-party sales**、**Third-party sales**、**Intercompany sales**、**Tested-party total cost**、**Return on sales**、**Net cost plus**、および評価別の**CO-PA margin**。

## CO-PAマージン

SAP CO-PAをロードした場合、テンプレートは評価別（法定、グループ、プロフィットセンター）のマージンも表示します。評価はそれぞれ独自の値であるため、評価同士を合算しないでください。CO-PAのファイルには1つの評価が含まれ、追加時にそれを確認します。CO-PAファイルで収益が正か負かが示されていない場合は、ファイルのマッピングで、どちらの符号を使うかを尋ねられます。

## プロジェクトの開始

<Steps>

1. Analyzeで**プロジェクト**を開き、**新規プロジェクト**をクリックします。

2. **開始元**で**Operational Transfer Pricing (template)** を選択します。先に作業例を確認するには、**サンプルデータで開始**にチェックを入れます。

3. ERPを接続して、**ロード**を実行します。[Data Foundationを始める](/ja/guides/projects/data-foundation-getting-started/)を参照してください。

4. 検証対象会社と範囲に合わせて`otp_policy_targets`を編集し、**Apply changes**をクリックします。

</Steps>

**Actions > Save as my template...** を使用すると、ポリシーテーブルをプロジェクトとともに保存できます。[マイテンプレートとして保存](/ja/guides/projects/data-foundation/#マイテンプレートとして保存)を参照してください。
