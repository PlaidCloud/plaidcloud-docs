このチュートリアルでは、新しいプロジェクトから、レポート、メトリック、AIアシスタントが参照する、ロード済みでチェック済みのモデルまでを進め、その後に引き渡します。プロジェクトの**Foundation**タブにある**セットアップ**チェックリストの項目に沿って進めます。各ステップには、詳細を扱う[Data Foundation: Common Finance Model](/ja/guides/projects/data-foundation/)の該当部分へのリンクがあります。

## 開始する前に

- プロジェクトを作成できる必要があります。共有プロジェクトの場合は、そのアーキテクトである必要があります。
- 接続する各ERPの認証情報を用意してください。認証情報をお持ちでない場合は、**Foundation**タブがERP管理者向けのアクセスリクエストを作成します。[ERPを接続する](/ja/guides/projects/data-foundation/#erpを接続する)を参照してください。
- 適したテンプレートを決めます。**企業収益性**は、損益計算書とマージンブリッジを構築します。**コスト・トゥ・サーブ**は、各顧客への対応コストを追加します。**オペレーショナル移転価格**は、各エンティティの利益をポリシーの範囲に照らしてテストします。3つとも、同じCommon Finance Modelを参照します。[テンプレートでモデルを拡張する](/ja/guides/projects/data-foundation/#テンプレートでモデルを拡張する)を参照してください。

## モデルにデータを供給できるシステム

Data Foundationは、以下のすべてのシステムから、それぞれのPlaidCloud接続を通じて直接読み取ります。1つのプロジェクトで、複数のシステムと、各システムの複数のインスタンスを組み合わせることができます。

| システム | 接続の設定 |
|---|---|
| NetSuite | [Data Foundation向けのNetSuiteアクセス](/ja/guides/connections/netsuite-access-for-data-foundation/) |
| SAP S/4HANA、SAP ECC | 接続フォームが、SAP管理者向けのアクセスリクエストを作成します。 |
| SAP S/4HANA Cloud | [SAP S/4HANA Cloudに接続](/ja/guides/connections/s4hana-cloud/) |
| Oracle E-Business Suite | 接続フォームが、Oracle管理者向けのアクセスリクエストを作成します。 |
| Oracle Fusion | [Oracle Fusionに接続](/ja/guides/connections/oracle-fusion/) |
| Microsoft Dynamics 365 Finance & Operations | [Dynamics 365 Finance & Operationsに接続](/ja/guides/connections/dynamics-365-fo/) |
| Microsoft Dynamics 365 Business Central | [Business Centralに接続](/ja/guides/connections/business-central/) |
| Sage Intacct | [Sage Intacctに接続](/ja/guides/connections/sage-intacct/) |
| QuickBooks Online | [QuickBooksに接続](/ja/guides/connections/quickbooks/) |
| Xero | [Xeroに接続](/ja/guides/connections/xero/) |
| Workday Financials | [Workday Financialsに接続](/ja/guides/connections/workday-financials/) |
| Salesforce | [Salesforceに接続](/ja/guides/connections/salesforce/) |
| OneStream（連結結果） | [Data Foundation向けOneStream](/ja/guides/connections/onestream-for-data-foundation/) |
| Anaplan（予算、予測、連結結果） | [Data FoundationのソースとしてのAnaplan](/ja/guides/connections/anaplan/#data-foundationのソースとしてのanaplan) |
| ファイル | システムが保持していないデータ用の、CSV、TSV、TXT、Excel、Parquet。[ERP以外のデータ用にファイルを追加する](/ja/guides/projects/data-foundation/#erp以外のデータ用にファイルを追加する)を参照してください。 |

## セットアップチェックリストを進める

<Steps>

1. **プロジェクトを作成します。** Analyzeで**プロジェクト**を開き、**新規プロジェクト**をクリックします。**開始元**でテンプレートを選択します。何も接続せずにモデルを試すには、**サンプルデータで開始**にチェックを入れます。プロジェクトはすぐに最初の**ロード**を実行し、**Foundation**タブに完全な例が表示されます。自分または同僚が保存したモデルを再利用するには、**From a template file...** を選択します。[マイテンプレートとして保存](/ja/guides/projects/data-foundation/#マイテンプレートとして保存)を参照してください。

2. **データを接続します。** **Foundation**タブで、既存の接続を選択するか新しく作成し、**接続をテスト**をクリックして、ロードするエンティティにチェックを入れ、**履歴の月数**を設定して、**接続**をクリックします。別のシステムや別のインスタンスを追加するには、この操作を繰り返し、**Add this as another source instead of replacing the current one**にチェックを入れます。ERP以外のデータにはファイルを追加します。[ERPを接続する](/ja/guides/projects/data-foundation/#erpを接続する)と[ソース](/ja/guides/projects/data-foundation/#ソース)を参照してください。

3. **データをロードします。** **ロード**をクリックします。すべてのソースをモデルに整合させ、報告通貨に換算して、チェックします。**対応**には、確認が必要な項目が重要なものから順に表示されます。[データをロードする](/ja/guides/projects/data-foundation/#データをロードする)を参照してください。

4. **ロードで生じた質問に回答します。** ソース間で同じコードが異なる意味で使われている場合、**Codes waiting for your answer**で、それらが同じ意味かどうかを尋ねられます。2つのソースが同じ月をカバーしている場合は、**Choose which source counts from when**で選択します。**Apply changes**をクリックすると、ERPから再度取得せずに再構築されます。1つずつ回答する代わりに、アシスタントに回答案を提示してもらうこともできます。[ソース間でコードをマッピングする](/ja/guides/projects/data-foundation/#ソース間でコードをマッピングする)と[Askで未解決の質問を解決する](/ja/guides/projects/data-foundation/#askで未解決の質問を解決する)を参照してください。

5. **合計が一致することを確認します。** **準備状況**グリッドには、エンティティ、期間、チェックごとに1行が表示されます。疑わしい数値は**Explain this number**で開くことができ、元帳が保持している額、配賦された額、グループで消去された額に分解されます。[準備状況チェック](/ja/guides/projects/data-foundation/#準備状況チェック)と[数値を説明する](/ja/guides/projects/data-foundation/#数値を説明する)を参照してください。

6. **階層を確認します。** **Open hierarchies**をクリックし、エンティティ、勘定科目、部門の階層を確認して、**確認しました**にチェックを入れます。[階層](/ja/guides/projects/data-foundation/#階層)を参照してください。

7. **自社の呼称に合わせて名前を付けます。** **Business names**で、カテゴリ、損益計算書の行、メトリック、列に、自社で使用している名前を付けます。レポート、メトリック、アシスタントにはこれらが表示されます。[ビジネス名](/ja/guides/projects/data-foundation/#ビジネス名)を参照してください。モデルのコスト配分が自社の運用と合わない場合は、**Actions > Allocations...** で変更します。[配賦ルール](/ja/guides/projects/data-foundation/#配賦ルール)を参照してください。

8. **最新の状態に保ちます。** ロードが成功したら、**夜間に更新**をクリックします。必要に応じて、[ボードパック](/ja/guides/projects/data-foundation/#ボードパック)を設定します。ボードパックは、損益計算書ダッシュボードのExcelワークブックとPDFを、選択したフォルダーに書き出します。

9. **共有、文書化して引き渡します。** プロジェクトをチームと共有し、**Download evidence pack**をクリックして、ロードした内容とその突合状況の記録を取得します。クライアント向けにプロジェクトを設定した場合は、クライアントのオーナーをアーキテクトにしてから、自分自身を削除します。[プロジェクトを引き渡す](/ja/guides/projects/data-foundation/#プロジェクトを引き渡す)を参照してください。

</Steps>

<Aside type="tip">
ソースやマッピングを大きく変更する前に、事前にコピーを作成する必要はありません。リストアポイントが自動的に作成され、**Actions > Restore...** でプロジェクトを元に戻せます。[リストアポイント](/ja/guides/projects/data-foundation/#リストアポイント)を参照してください。
</Aside>

## 完了時に得られるもの

- 1つの勘定科目表、1組のエンティティ、1つの報告通貨を持つCommon Finance Modelと、会社間取引を消去した管理用のグループ損益計算書。
- チームとアシスタントが質問できる、モデル、メトリック、分析パス。
- 夜間更新と、必要に応じてボードパック。
- エビデンスパックと、クライアントのオーナーが管理するプロジェクト。
