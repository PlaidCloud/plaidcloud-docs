PlaidCloud は、アドレスバーを開いている内容に合わせて更新します。ワークフロー、テーブル、ディメンション、またはダッシュボード、ドキュメント、アイデンティティ内の画面を開くと、URL がその画面への**ディープリンク**になります。その URL をコピーしてメッセージやチケットに貼り付けると、開いた相手は同じ画面に移動します。

## リンクのコピー

1. 共有したい画面（プロジェクト、ワークフロー、テーブル、ディメンション、データエディター、または他のアプリ内の画面）を開きます。
2. ブラウザーのアドレスバーから URL 全体をコピーします。
3. それを送信します。

個別の「共有」ボタンはありません。アドレスバーがそのままリンクです。ブラウザーのブックマーク機能もこれらの URL で使えるため、頻繁に戻る画面は、ほかの Web ページと同様にブックマークできます。

<Aside type="note">
リンクが伝えるのは*場所*だけで、それを表示する権限ではありません。リンクを開く人にも、プロジェクトへのアクセス権が必要です。アクセス権のない人にはオブジェクトが表示されません。

ワークスペースにそのアプリが含まれていない、またはアクセス権が付与されていないなどの理由で、持っていないアプリへのリンクを開くと、何も起こらないように見える代わりに、リンクが利用できなかったことを示すメモとともにホームに移動します。
</Aside>

## リンクできる対象

### Analyze

| 画面 | リンクの末尾 |
|---|---|
| プロジェクト | `#p~<project>` |
| ワークフロー（ステップのグリッド） | `#p~<project>~w~<workflow>` |
| ワークフロー（ビジュアルワークフローデザイナーのキャンバス） | `#p~<project>~c~<workflow>` |
| ワークフロー内のステップ | `…~w~<workflow>~s~<step>` または `…~c~<workflow>~s~<step>` |
| 単独のステップ | `#p~<project>~s~<step>` |
| テーブルエクスプローラー | `#p~<project>~t~<table>` |
| ディメンション階層 | `#p~<project>~d~<dimension>` |
| データエディター | `#p~<project>~e~<editor>` |
| ホーム | `#home` |

リンクのプロジェクト部分は、プロジェクトにカスタムの**スキーマ**がある場合はそのスキーマになるため、リンクは 16 進数の文字列ではなく `#p~acme_budget~w~…` のようになります。デフォルトのスキーマのままのプロジェクトでは、代わりにプロジェクト自身の識別子が使われます。どちらの形式でも同じプロジェクトが開くため、スキーマを設定した後も古いリンクは引き続き機能します。

### ダッシュボード、ドキュメント、アイデンティティ

他のアプリの画面は直接名前が付けられているため、リンクは画面そのものを表します。

| アプリ | 画面 | リンク |
|---|---|---|
| ダッシュボード | マイダッシュボード | `#dashboard.dashboards` |
| ダッシュボード | アプリ | `#dashboard.panel_apps` |
| ダッシュボード | Jupyter Lite | `#dashboard.jupyterlite_deployments` |
| ドキュメント | すべてのアカウント | `#document.accounts` |
| ドキュメント | 共有アカウント | `#document.shared_accounts` |
| ドキュメント | プライベートアカウント | `#document.private_accounts` |
| ドキュメント | 1 つのアカウントのファイルの参照 | `#document.browser~…` |
| アイデンティティ | メンバー | `#identity.members` |
| アイデンティティ | メンバーディレクトリ | `#identity.member_directory` |
| アイデンティティ | 配布リスト | `#identity.distro.lists` |
| アイデンティティ | セキュリティグループ | `#identity.security_groups` |
| アイデンティティ | セキュリティグループ監査 | `#identity.security_group_audit` |
| アイデンティティ | スコープ | `#identity.scopes` |
| アイデンティティ | セッション | `#identity.sessions` |
| アイデンティティ | APIクライアント | `#identity.api_client_list` |
| アイデンティティ | セキュリティログ | `#identity.security_log` |

一部の画面は、設定をリンクに記憶します。メンバー一覧とメンバーディレクトリ一覧は、**すべて**、**アクティブのみ**、**非アクティブのみ**のどれを表示していたかをそれぞれ保持し、アカウントの参照ではどのアカウントかを保持します。ブラウザーには、これが画面名の後にエンコードされた接尾辞として表示されます。URL 全体をコピーして貼り付けると、表示していた画面が開きます。その画面がすでに開いている場合は、2 つ目のウィンドウを重ねるのではなく、そのウィンドウが前面に表示されます。

<Aside type="note">
これらのリンクが指すのは画面であり、その中のレコードではありません。メンバーへのリンクはメンバー一覧を開きますが、特定のメンバーのフォームは開きません。
</Aside>

## リンクを開いたときの動作

- **所有プロジェクトも開きます。** ワークフロー、テーブル、ステップ、ディメンション、データエディターへのリンクは、そのプロジェクトも画面下部のタブとして開くため、受信者は単独のウィンドウだけが浮かんだ状態ではなく、周辺のコンテキストとともに表示されます。
- **ステップへのリンクはステップを選択します。** ワークフロー内のステップへのリンクは、ワークフローを開いてそのステップを強調表示します。ビジュアルワークフローデザイナーのキャンバスでは、ステップのノードが選択されます。
- **ディメンションは、プロジェクトのロックが解除されている場合は編集可能な状態で開き**、ロックされている場合は読み取り専用で開きます。これは、プロジェクトから開く場合と同じルールです。
- **更新しても同じ場所に留まります。** ページを再読み込みすると、先頭に戻るのではなく、リンクが指す内容が再び開きます。

## 画面間の移動

URL は、表示している内容に追従します。

- 画面を開くとアドレスバーが更新され、ブラウザーの**戻る**ボタンで前の画面に戻れます。
- **どの方法で開いても同じです。** アクティビティストリーム、ホームカード、**ワークフローにドリルダウン**アクション、「使用箇所」一覧、ログのいずれからワークフローを開いても、プロジェクトのワークフロー一覧から開いた場合と同様にリンクが更新されます。すでに開いている画面を再度開いた場合も同様です。
- 画面下部のウィンドウのタブを選択すると、そのウィンドウのリンクがアドレスバーに戻るため、開いている画面を切り替えても URL が正確に保たれます。
- リンク可能なものが何も開いていないアプリに切り替えると、直前まで開いていたアプリを指したままにせず、リンクが**クリア**されます。
- ウィンドウを閉じると、URL は開いた元の場所に戻ります。ワークフローのキャンバスから開いたテーブルを閉じると、URL はそのキャンバスに戻ります。プロジェクトから開いたテーブルを閉じると、プロジェクトに戻ります。
- プロジェクトの最後のウィンドウを閉じると、リンクがクリアされます。

## この変更以前に保存されたリンク

古い `#te?p=…&t=…` 形式のリンクも引き続き機能します。開くと同じ場所に移動し、アドレスバーが現在の形式に自動的に書き換えられるため、そこから再度コピーすると、より新しく読みやすいリンクが得られます。
