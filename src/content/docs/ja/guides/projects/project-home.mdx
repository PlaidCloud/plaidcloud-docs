## 説明

**プロジェクトホーム**は、プロジェクトでの作業の起点です。左側のレールには、アイコンなしのテキストで7つのページが一覧表示されます。**概要**、**変数**、**スケジュールとセンサー**、**アクセスと共有**、**データと接続**、**データモデル**、**アプリとブランディング**です。概要ではプロジェクトの要約を確認できます。その他の6つのページでは、プロジェクトの設定を変更するか、**データモデル**でテーブルが共有している列を確認します。

レール上の**変数**バッジには、プロジェクトの変数の数が表示されます。**スケジュールとセンサー**バッジには、アクティブなスケジュールとセンサーの数が表示されます。**データモデル**バッジには、プロジェクト要素の数が表示されます。

ロックされたプロジェクトは読み取り専用です。各ページには「このプロジェクトはロックされているため、読み取り専用です。変更するには、概要でロックを解除してください。」というバナーが表示され、コントロールは無効になります。

## 概要

![プロジェクト名、6つのタイル、今後の予定、プロジェクトのデフォルトを表示しているプロジェクトホームの概要ページ](/images/projects/project-home-overview.png)

ページの上部には、プロジェクト名と、プロジェクトが**編集可能**か**読み取り専用**かが表示されます。

- **説明。** 鉛筆アイコンをクリックすると、その場で説明を編集できます。Enter キーを押すと保存され、Escape キーを押すとキャンセルされます。
- **ラベル。** **ラベルを追加…** 欄にラベルを入力し、**追加**をクリックします。[ラベルによる作業の整理](/ja/guides/projects/organizing-with-labels/)を参照してください。
- **ロック**と**ロック解除**で、プロジェクトを編集可能と読み取り専用の間で切り替えます。

タイルには、プロジェクトに含まれるものの数が表示されます。

| タイル | 表示内容 |
|---|---|
| **テーブル** | プロジェクト内のテーブル。 |
| **ワークフロー** | プロジェクト内のワークフロー。 |
| **ステップ** | すべてのワークフローにわたるステップ。 |
| **変数** | プロジェクト変数。 |
| **公開済みテーブル** | 公開したテーブル。 |
| **データサイズ** | データを復元できるように保持されている以前のバージョンを含む、プロジェクトが保存しているすべてのデータ。**プロジェクト**画面のプロジェクトの**サイズ**と同じ数値です。カーソルを合わせると、現在のデータと復元用に保持されている以前のバージョンを個別に確認できます。クリックすると**ストレージ**が開きます。[ストレージの管理](/ja/guides/projects/managing-storage/)を参照してください。 |

プロジェクトの一部の行がフィルターされている場合、合計が正確にならないため、**データサイズ**にはダッシュが表示されます。

**今後の予定**には、次の3件のスケジュールされた実行とそのワークフロー名、およびアクティブなセンサーの数が表示されます。**スケジュールを表示 ›** リンクをクリックすると**スケジュールとセンサー**が開きます。

**プロジェクトのデフォルト**には、ワークフローとステップが独自に設定しない限り使用する**環境**、**テーブルストレージ**、**アクセス**、**ERP転記**の値が表示されます。**設定を変更 ›** リンクをクリックすると、これらを変更するページが開きます。

ヘッダーのボタンは次のとおりです。

- **プロジェクトレポート**は、プロジェクトのレポートを**PDFドキュメント**または**インタラクティブHTML**として作成します。
- **アーカイブのエクスポート**は、プロジェクトをアーカイブとして保存します。
- **更新**は、ページ上のタイルとリストを再読み込みします。

## 変数

**変数**ページには、プロジェクトの変数がグリッドで一覧表示されます。ワークフローまたはステップは変数を名前で `{name}` として参照し、ワークフロー独自の変数は同じ名前のプロジェクト変数より優先されます。

グリッドには**名前**、**値**、**メモ**、**最終更新**、**実行者**が表示されます。**フィルター**で一覧を絞り込み、**新規変数**で変数を追加し、選択した行に対して**編集**または**削除**を使用します。

## スケジュールとセンサー

![概要バーと2つのグリッドがあるスケジュールとセンサーのページ](/images/projects/project-home-schedules.png)

このページには、プロジェクトのワークフローを自動的に開始するものが表示されます。概要バーには、次回の実行、アクティブなスケジュールと一時停止中のスケジュールの数、アクティブなセンサーの数が表示されます。

- **スケジュール**は、タイムテーブルに従ってワークフローを実行します。グリッドには**名前**、**ワークフロー**、**実行タイミング**（タイムテーブルとそのタイムゾーン）、**次回実行**、**ステータス**が表示されます。
- **センサー**は、新しいデータが到着したときにワークフローを実行します。グリッドには**名前**、**監視対象**、**開始**（ワークフロー）、**最終トリガー**、**ステータス**が表示されます。

**ステータス**は**アクティブ**、**一時停止中**、または問題のあるセンサーの場合は**失敗中**です。各グリッドには**新しいスケジュール**または**新しいセンサー**、**編集**、**削除**、**フィルター**があります。**アクション**を開くと、選択した行を**有効化**または**無効化**できます。

**カレンダービュー**では、今後の実行がカレンダー上に表示されるため、スケジュールの競合を見つけることができます。

## アクセスと共有

このページでは、プロジェクトとそのデータにアクセスできるユーザーを設定します。

- **プロジェクトアクセス**では、**このプロジェクトを開けるユーザー**を設定します。**すべてのワークスペースメンバー**、**特定のセキュリティグループのみ**、**特定のメンバーのみ**のいずれかです。**グループを編集 ›** リンクと**メンバーを編集 ›** リンクで、選択元のリストが開きます。
- **ダッシュボードの対象者**では、**新しいダッシュボードのデフォルトの対象者**を設定します。プロジェクト内の全員か、特定のグループです。各ダッシュボードは独自の対象者を変更できます。[ダッシュボードを表示できるユーザーを制御する](/ja/guides/dashboards/control-who-can-see-a-dashboard/)を参照してください。
- **データ共有**には、このプロジェクトのテーブルを読み取ることができるプロジェクトが一覧表示されます。[プロジェクト間でのデータ共有](/ja/guides/projects/managing-projects/#プロジェクト間のデータ共有)を参照してください。

## データと接続

![接続、テーブルストレージ、ERP転記があるデータと接続のページ](/images/projects/project-home-data.png)

これらの設定は、ワークフローまたはステップが独自に設定しない限り、プロジェクト内のすべてのワークフローとステップに適用されます。

- **接続環境**では、プロジェクトのステップが使用する各接続の構成を選択します。これにより、1つのプロジェクトを QA と本番環境の間で切り替えることができます。ステップに[固定環境](/ja/guides/projects/managing-projects/#ステップを1つの環境に固定する)がない限り、すべてのステップがこの設定に従います。変更すると、プロジェクト内に新しい環境の構成を持たない接続がある場合に警告が表示され、固定環境のために追従しないステップの名前が示されます。
- **デフォルトのドキュメントアカウント**では、ステップがファイルを読み書きする場所を選択します。
- **デフォルトのテーブルストレージ**では、新しいテーブルを作成する場所を選択します。
- **タイムトラベル保持期間**では、テーブルデータの以前のバージョンを保持する日数を設定します。この設定を継承するテーブルも、より長い履歴を保持します。すでに期限切れになった履歴は復元できません。
- **転記モード**では、プロジェクトが接続された ERP に仕訳を送信する方法を設定します。これはプロジェクトの上限であり、ワークフローの実行でこの設定より緩い転記を行うことはできません。**本番**は通常どおり転記します。**シミュレート**は仕訳を作成して検証しますが、転記や ERP への接続は行いません。**オフ**は転記ステップをスキップします。
- **書き込み承認**には、転記が承認されている ERP 接続の数が表示されます。管理者は**承認を管理 ›** リンクをクリックできます。

## データモデル

このページには、プロジェクトの要素、つまりテーブルが共有している列名を1回だけ記述したものが一覧表示されます。各要素を共有しているテーブルを確認でき、要素を作成、変更、削除できます。[データモデルとプロジェクト要素](/ja/guides/projects/data-model/)を参照してください。

## アプリとブランディング

このページでは、プロジェクトのデータに基づいて構築されたアプリを扱います。

- **Panelアプリ**には、プロジェクトに基づいて構築されたアプリの数が表示されます。**Panelアプリを開く ›** リンクでアプリが開き、**新しい Studio アプリ**で新しいアプリを作成できます。
- **ブランディング**では、プロジェクトのアプリが使用するロゴと色を設定します。**ブランディングを編集 ›** リンクで設定が開きます。
- **ホームタイル画像**は、ホームページのプロジェクトのタイルに表示される画像です。**選択...** ボタンをクリックして画像を選ぶか、**クリア**をクリックして削除します。
