## 説明

**プロジェクトホーム**は、プロジェクトでの作業の起点です。左側のレールに 6 つのページが並びます。**概要**、**変数**、**スケジュールとセンサー**、**アクセスと共有**、**データと接続**、**アプリとブランディング**です。概要ではプロジェクトの全体像を確認できます。残りの 5 つのページでは、プロジェクトの設定を変更します。

レールの**変数**バッジには、プロジェクトの変数の数が表示されます。**スケジュールとセンサー**バッジには、アクティブなスケジュールとセンサーの数が表示されます。

ロックされたプロジェクトは読み取り専用です。各ページにバナー「このプロジェクトはロックされているため、読み取り専用です。変更するには、概要でロックを解除してください。」が表示され、コントロールは無効になります。

## 概要

![プロジェクト名、6 つのタイル、今後の予定、プロジェクトのデフォルトを表示したプロジェクトホームの概要ページ](/images/projects/project-home-overview.png)

ページの上部には、プロジェクト名と、**編集可能**か**読み取り専用**かが表示されます。

- **説明。** 鉛筆アイコンをクリックすると、その場で説明を編集できます。Enter キーで保存し、Escape キーでキャンセルします。
- **ラベル。** **ラベルを追加…** ボックスにラベルを入力し、**追加**をクリックします。[ラベルによる作業の整理](/ja/guides/projects/organizing-with-labels/)を参照してください。
- **ロック**と**ロック解除**は、プロジェクトを編集可能と読み取り専用の間で切り替えます。

タイルには、プロジェクトが保持するものの数が表示されます。

| タイル | 表示内容 |
|---|---|
| **テーブル** | プロジェクト内のテーブル。 |
| **ワークフロー** | プロジェクト内のワークフロー。 |
| **ステップ** | すべてのワークフローにわたるステップ。 |
| **変数** | プロジェクト変数。 |
| **公開済みテーブル** | 公開したテーブル。 |
| **データサイズ** | プロジェクトのテーブルが保存しているデータ量。クリックすると**ストレージ**が開きます。[ストレージの管理](/ja/guides/projects/managing-storage/)を参照してください。 |

プロジェクトの行の一部があなた向けにフィルターされている場合、合計が正確にならないため、**データサイズ**にはダッシュが表示されます。

**今後の予定**には、次の 3 件のスケジュール実行がワークフロー名とともに表示され、アクティブなセンサーの数も表示されます。**スケジュールを表示 ›** をクリックすると**スケジュールとセンサー**が開きます。

**プロジェクトのデフォルト**には、ワークフローやステップが独自に設定しない限り使用される**環境**、**テーブルストレージ**、**アクセス**、**ERP転記**の値が表示されます。**設定を変更 ›** をクリックすると、それらを変更するページが開きます。

ヘッダーのボタンは次のとおりです。

- **プロジェクトレポート**は、プロジェクトのレポートを **PDFドキュメント**または**インタラクティブHTML**として作成します。
- **アーカイブのエクスポート**は、プロジェクトをアーカイブとして保存します。
- **更新**は、タイルとページ上の一覧を再読み込みします。

## 変数

**変数**ページには、プロジェクトの変数がグリッドに一覧表示されます。ワークフローやステップは、変数を `{name}` という名前で参照します。ワークフロー独自の変数は、同じ名前のプロジェクト変数より優先されます。

グリッドには、**名前**、**値**、**メモ**、**最終更新**、**実行者**が表示されます。**フィルター**で一覧を絞り込み、**新規変数**で追加し、選択した行に対して**編集**または**削除**を使用します。

## スケジュールとセンサー

![サマリーストリップと 2 つのグリッドを表示したスケジュールとセンサーのページ](/images/projects/project-home-schedules.png)

このページには、プロジェクトのワークフローを自動的に開始するものが表示されます。サマリーストリップには、次回の実行、アクティブなスケジュールと一時停止中のスケジュールの数、アクティブなセンサーの数が表示されます。

- **スケジュール**は、時間割に従ってワークフローを実行します。グリッドには、**名前**、**ワークフロー**、**実行回数**（時間割とそのタイムゾーン）、**次回実行**、**ステータス**が表示されます。
- **センサー**は、新しいデータが到着したときにワークフローを実行します。グリッドには、**名前**、**監視対象**、**開始**（ワークフロー）、**最終トリガー**、**ステータス**が表示されます。

**ステータス**は、**アクティブ**、**一時停止**、または問題があるセンサーの場合は**失敗中**です。各グリッドには、**新規スケジュール**または**新しいセンサー**、**編集**、**削除**、**フィルター**があります。**アクション**を開くと、選択した行を**有効化**または**無効化**できます。

**カレンダー表示**では、今後の実行がカレンダー上に表示されるため、スケジュールの競合を見つけられます。

## アクセスと共有

このページでは、プロジェクトとそのデータにアクセスできる対象を設定します。

- **プロジェクトアクセス**では、**このプロジェクトを開けるユーザー**を設定します。選択肢は、**すべてのワークスペースメンバー**、**特定のセキュリティグループのみ**、**特定のメンバーのみ**です。**グループを編集 ›** と **メンバーを編集 ›** をクリックすると、選択用の一覧が開きます。
- **ダッシュボードの対象ユーザー**では、**新しいダッシュボードのデフォルトの対象ユーザー**として、プロジェクト内の全員または特定のグループを設定します。各ダッシュボードは独自の対象ユーザーを変更できます。[ダッシュボードを表示できるユーザーの制御](/ja/guides/dashboards/control-who-can-see-a-dashboard/)を参照してください。
- **データ共有**には、このプロジェクトのテーブルを読み取れるプロジェクトが一覧表示されます。[プロジェクト間でのデータ共有](/ja/guides/projects/managing-projects/#プロジェクト間のデータ共有)を参照してください。

## データと接続

![接続、テーブルストレージ、ERP転記を表示したデータと接続のページ](/images/projects/project-home-data.png)

これらの設定は、ワークフローやステップが独自に設定しない限り、プロジェクト内のすべてのワークフローとステップに適用されます。

- **接続環境**は、ステップが環境を選択していない場合に使用する認証情報を選択します。選択した環境用の設定がない接続がプロジェクトにある場合、ページに警告が表示されます。
- **デフォルトのドキュメントアカウント**は、ステップがファイルを読み書きする場所を選択します。
- **デフォルトのテーブルストレージ**は、新しいテーブルを作成する場所を選択します。
- **タイムトラベル保持期間**は、テーブルデータの以前のバージョンを保持する日数を設定します。この設定を継承するテーブルも、より長い履歴を保持します。すでに期限切れになった履歴は復元できません。
- **転記モード**は、プロジェクトが接続済みの ERP に仕訳を送信する方法を設定します。これはプロジェクトの上限です。ワークフローの実行は、この設定より緩やかに転記することはできません。**本番**は通常どおり転記します。**シミュレート**は作成と検証のみを行い、転記や ERP への接続は行いません。**オフ**は転記ステップをスキップします。
- **書き込み認可**には、転記が認可されている ERP 接続の数が表示されます。管理者は **認可を管理 ›** をクリックできます。

## アプリとブランディング

このページでは、プロジェクトのデータ上に構築されたアプリを扱います。

- **Panelアプリ**には、プロジェクト上に構築されたアプリの数が表示されます。**Panelアプリを開く ›** でアプリが開き、**新しい Studio アプリ**で新規作成を開始します。
- **ブランディング**は、プロジェクトのアプリが使用するロゴと色を設定します。**ブランディングを編集 ›** をクリックすると設定が開きます。
- **ホームタイル画像**は、ホームページのプロジェクトのタイルに表示される画像です。**選択...** をクリックして画像を選ぶか、**クリア**をクリックして削除します。
