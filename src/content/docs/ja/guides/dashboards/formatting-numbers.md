## 数値とその他のデータ型の書式設定

PlaidCloudで数値を書式設定する方法は2つあります。1つはテーブル内の値を直接変換する方法で、もう1つは（より一般的な方法として）表示時に書式設定する方法です。後者であれば、テーブル内の値の精度が失われることなく、ユーザーはより見やすく適切な形で値を確認できます。

ダッシュボードに値を表示するとき、希望する書式にするにはどうすればよいでしょうか。
値を表示する基本的な方法は、ダッシュボード上のチャートオブジェクトを使用することです。チャートには、テーブル、ビッグナンバー、棒グラフなどがあります。値を表示する場所や方法は、チャートオブジェクトごとに多少異なります。たとえばテーブルでは列ごとに書式を変更でき、ビッグナンバーでは数値の書式を変更できます。

書式を変更するには、チャートを編集して `D3 FORMAT` または `NUMBER FORMAT` フィールドを探します。ビッグナンバーのチャートでは、`CUSTOMIZE` タブをクリックすると `NUMBER FORMAT` が表示されます。テーブルでは、`CUSTOMIZE` タブをクリックし、`CUSTOMIZE COLUMN` で数値列（# で表示）を選択すると、`D3 FORMAT` フィールドが表示されます。

デフォルト値は `Adaptive formatting` です。これは値に応じて書式を調整します。ただし、書式を固定したい場合（たとえば $12.23 や 12,345,678）は、ドロップダウンから希望の書式を選択するか、別の値を手動で入力します（フィールドで許可されている場合）。

## D3書式設定とは

D3書式設定は、データの結果を特定の形式で表示するための、構造化された正式な手段です。たとえば、大きな値を 3B（30億）と表示する場合はD3書式で `.3s` とし、3,001,238,383 と表示する場合は `,d` とします。もう1つのよくある例は、ドル値を小数点以下2桁の精度で表示するか、$,d のように最も近いドルに丸めるか、あるいは $,.2f のようにドル記号、カンマ、小数点以下2桁、固定小数点表記で表示するかを決める場合です。
D3の詳細については、次のサイトを参照してください。[GitHub D3](https://github.com/d3/d3-format)


## D3書式の一般的な形式

D3の一般的な構造は次のとおりです。

`[​[fill]align][sign][symbol][0][width][,][.precision][~][type]`

fill には任意の文字（ピリオド、x、その他）を使用できます。fill 文字を指定した場合は、その後に `align` 文字が必要で、次のいずれかである必要があります。

`>` - 使用可能なスペース内で右揃え。（デフォルトの動作。）
`<` - 使用可能なスペース内で左揃え。
`^` - 使用可能なスペース内で中央揃え。
`=` - > と同様ですが、符号と記号がパディングの左側に配置されます。

`sign` には次のものを指定できます。
`-` - ゼロまたは正の数では空白、負の数ではマイナス記号。（デフォルトの動作。）
`+` - ゼロまたは正の数ではプラス記号、負の数ではマイナス記号。
`(` - ゼロまたは正の数では何もなし、負の数では括弧。
（スペース） - ゼロまたは正の数ではスペース、負の数ではマイナス記号。

`symbol` には次のものを指定できます。
`$` - 通貨記号を適用します。

`zero`（0）オプションはゼロパディングを有効にします。これにより、fill は暗黙的に 0、align は = に設定されます。

`width` は最小のフィールド幅を定義します。指定しない場合、幅は内容によって決まります。たとえば 8 を指定すると、フィールドの幅は8文字になります。

`comma`（,）オプションは、カンマを区切り文字（たとえば千の位）として使用できるようにします。

type によって、`precision` は小数点以下の桁数（type が f と % の場合）、または有効桁数（type が ​、g、r、s、p の場合）を表します。precision を指定しない場合、（none）を除くすべての type では 6、（none）では 12 がデフォルトになります。

`tilde` ~ オプションは、すべての書式 type で、意味のない末尾のゼロを削除します。これは、type が r、s、% の場合と組み合わせて使用されることが最も多いオプションです。

`types`
|Type |   説明                                                                                       |
|-----|---------------------------------------------------------------------------------------------|
|f    |固定小数点表記。 **(よく使用)**
|d    |整数に丸めた10進表記。 **(よく使用)**
|%    |100倍して、パーセント記号付きの10進表記にします。 **(よく使用)**
|g    |有効桁数に丸めた10進表記または指数表記。
|r    |有効桁数に丸めた10進表記。
|s    |有効桁数に丸めた、SI接頭辞付きの10進表記。
|p    |100倍して有効桁数に丸め、パーセント記号付きの10進表記にします。

## 例
|式|入力|出力|メモ|

|,d|12345.67|12,346|値を最も近い整数に丸め、カンマを追加します

|$,.2f|12345.67|$12,345.67|$ 記号を追加し、カンマを付け、小数点以下を2桁にします
|$,d|12345.67|$12,346|
|.&lt;10,|151925|151,925...|値の左側にピリオドを入れ、10文字幅にし、カンマを付けます
|0>10|12345|0000012345|値の左側をゼロで埋め、10文字幅にします。コード値の幅を固定するのに便利です
|,.2%|13.215|1,321.50%|カンマを付け、小数点以下を2桁にし、パーセンテージに変換して % 記号を表示します
|x^+$16,.2f|123456|xx+$123,456.00xx| "x" で埋め、中央揃えにし、+/- 記号と $ 記号を付け、16文字幅にし、カンマを付け、小数点以下を2桁にします
