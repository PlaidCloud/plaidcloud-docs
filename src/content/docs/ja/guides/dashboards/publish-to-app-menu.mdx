**インサイト**から、ダッシュボード、PanelアプリまたはDashアプリ、JupyterLiteノートブックを、左側のアプリメニューに公開できます。選択したユーザーは、製品アプリの下にあるメニューから、1クリックでそれを開けます。

<Aside>アプリメニューへの公開は、メニューにエントリーを追加するだけです。項目へのアクセス権が誰かに付与されることはありません。エントリーが表示されるのは、対象ユーザーに含まれ、**かつ**すでにその項目を開ける人だけです。</Aside>

## 公開できるユーザー

自分でその項目を開けることに加えて、管理できる必要があります。

| 項目 | 公開できるユーザー |
|---|---|
| ダッシュボード | 所有者とワークスペース管理者、つまりダッシュボードの対象ユーザーを選択できるユーザー（[ダッシュボードを閲覧できるユーザーを制御する](/ja/guides/dashboards/control-who-can-see-a-dashboard/)を参照）で、ダッシュボードへの書き込みアクセス権を持つ人です。 |
| PanelアプリまたはDashアプリ | アプリへの書き込みアクセス権を持ち、アプリのプロジェクトでエクスプローラーより上のロールを持つメンバーです。プロジェクトがロックされていても公開できます。プロジェクトのないアプリは、作成した人またはワークスペース管理者が公開できます。 |
| JupyterLiteノートブック | デプロイメントを追加した人またはワークスペース管理者で、ノートブックへの書き込みアクセス権を持つ人です。 |

**Dashboard Read and Write**セキュリティグループは、ダッシュボード、アプリ、ノートブックへの書き込みアクセス権を付与します。

## 項目を公開する

1. **インサイト**で、**ダッシュボード**、**アプリ**、または**ノートブック**を開きます。
2. 項目の行メニューから**アプリメニューに公開…** メニュー項目を選択するか、行を選択してツールバーの**アプリメニューに公開…** ボタンを選択します。この操作は、その種類の項目への書き込みアクセス権がある場合に表示され、**ダッシュボード**では、自分が管理するダッシュボードにのみ表示されます。
3. **アプリメニューに公開**ダイアログで、エントリーを設定します。
   - **メニュー項目**は、メニューに表示されるラベルです。最初は項目の名前が入り、その下のプレビューに、エントリーが実際にどう表示されるかが示されます。ラベルは、メニューにある最も幅の広い製品アプリの名前より広くできません。広すぎるラベルには、その旨が表示されます。
   - **アイコン**では、ラベルの頭文字のモノグラムか15種類のシンボルのいずれかと、色を選べます。最初の色は、ラベルから自動的に選ばれます。アイコンの小さなバッジは、エントリーがダッシュボード、アプリ、ノートブック、Jupyter Hubのどれであるかを示します。
   - **メニューで表示される対象**は、**ワークスペースの全員**、**グループ**、**ユーザー**のいずれかで、一度に1種類だけ選べます。**グループ**または**ユーザー**では、少なくとも1つにチェックを付けます。**グループ**にはセキュリティグループを読み取るアクセス権、**ユーザー**にはメンバーを読み取るアクセス権が必要で、権限がない場合、その選択肢はグレー表示になります。
4. **公開**を選択します。

項目の行には、**公開済み**のバッジが表示されます。エントリーを後で変更するには、もう一度**アプリメニューに公開…** メニュー項目を選択します。ダイアログには保存済みの内容が表示され、ボタンは**保存**になり、**公開を取り消す**でエントリーをメニューから外せます。

### 開けない人

対象ユーザーの下で、ダイアログは、対象ユーザーのうち現時点でその項目を開けない人を確認します。

- *この項目を開けません: 40人中3人*は、対象ユーザー40人のうち3人が、その項目を開けるようになるまでエントリーを表示できないという意味です。
- *この対象ユーザー全員がこの項目を開けます*は、除外される人がいないという意味です。
- *自分には見えないプロジェクトにいるユーザー2人*は、アクセス権が自分には開けないプロジェクトに依存しているユーザーの数で、ダイアログでは判定できません。

ダッシュボードでは、**アクセスを修正**で**閲覧できるユーザー**ダイアログが開き、そこで保存すると、チェックが再度実行されます。件数は、ワークスペースのメンバーを閲覧できる場合にのみ表示されます。

## エントリーが表示される場所

公開されたエントリーは、アプリメニューの製品アプリの後ろ、区切り線の下に、ワークスペース管理者が[公開済みアプリ](#公開済みアプリを管理する)で設定した順に表示されます。それぞれにラベルとアイコンが付きます。自分で行った変更はすぐに反映され、他のユーザーには次回 PlaidCloud を読み込んだときに反映されます。

| 項目 | 開き方 |
|---|---|
| ダッシュボード | PlaidCloud 内のタブとして開く |
| **ブラウザのみ**のPanelアプリ | PlaidCloud 内のタブとして開く |
| JupyterLiteノートブック | PlaidCloud 内のタブとして開く |
| **サーバーベース**のPanelアプリまたはDashアプリ | 新しいウィンドウで開く |
| Jupyter Hub | 新しいウィンドウで開く |

メニューから開いたタブには、エントリーの名前、**再読み込み**、**新しいウィンドウで開く**を含むヘッダーがあります。タブ内で項目にサインインされない場合は、**新しいウィンドウで開く**を使用します。

タブのアドレスは、共有できるリンクです。[プロジェクト、ワークフロー、テーブル、アプリ画面へのリンクの共有](/ja/guides/projects/sharing-links/#公開済みメニューエントリー)を参照してください。アプリメニューに**ホーム**と公開済みエントリーしかない場合は、**ホーム**の**アプリ**行に、それらが先頭に表示されます。

### エントリーが表示される人

次の両方に当てはまるメンバーに、エントリーが表示されます。

- **対象ユーザーに含まれている:** ワークスペースの全員、グループのいずれかのメンバー、または指定されたユーザーのいずれかです。
- **その項目を開ける:** インサイトで表示できるダッシュボード、アクセスできるプロジェクト上のアプリです。**ブラウザのみ**のアプリまたはJupyterLiteノートブックの場合は、配信元のドキュメントアカウントへのアクセス権も必要です。

それ以外のユーザーには、対象ユーザーの設定にかかわらず、エントリーは表示されません。

## 自分のメニューからエントリーを非表示にする

アプリメニューで公開済みのエントリーを右クリックし、**自分のメニューから非表示**を選択します。エントリーは自分のメニューからのみ消え、表示されるメッセージの**元に戻す**で戻せます。非表示にする操作は、インサイトを利用できるメンバーに表示されます。

再び表示するには、インサイトのレールで**非表示のアプリ**を開き、その行の**復元**を選択します。メニューにもう表示されないエントリーには**メニューに表示されなくなりました**と表示され、**削除**でリストから外せます。非表示にしたエントリーはアカウントに保存されるため、どのブラウザーでも非表示のままです。

## 公開済みアプリを管理する

ワークスペース管理者は、インサイトのレールの**管理者**の下にある**公開済みアプリ**を開きます。すべてのエントリーがメニューの順に一覧表示され、**名前**、**種類**、**対象ユーザー**（**全員**、またはグループやユーザーの数）、**ステータス**が表示されます。**閲覧数（30日間）** には、利用状況にアクセスできるメンバー向けに、各ダッシュボードが開かれた回数が表示されます。

- **上へ移動**と**下へ移動**で、全員のメニューでのエントリーの順序を設定します。
- **対象を変更…** ボタンは、管理できるエントリーの**アプリメニューに公開**ダイアログを開きます。
- **公開を取り消す**は、確認後、そのエントリーが公開されているすべてのユーザーのメニューからエントリーを外します。ワークスペース管理者は、どのエントリーでも公開を取り消せます。

公開された項目が削除されると、そのエントリーはメニューから消え、**公開済みアプリ**に**項目は削除され、取り除かれました**と1回表示されます。Panelアプリ、またはJupyterLiteデプロイメントを一覧から削除すると、そのエントリーも削除されます。

## AIアシスタントまたはMCPで公開する

`publication_manage` は、MCPで同じ操作を行います。`kind` は `dashboard`、`panelApp`、`jupyterLite`、`jupyterHub` のいずれかで、アクションは次のとおりです。

- `get`、`set`、`delete`、`preview` は、`kind` と `item_id` を受け取ります。`set` は、`label`、省略可能な `icon` と `color`、そして `type` が `public`、`acl-group`、`acl-user` のいずれかで `ids` を持つ `audience` からなる `spec` で、エントリー全体を置き換えます。`preview` は `audience` を含む `spec` を受け取り、ダイアログと同じ件数を返します。
- `list` は、自分が管理するエントリーを、ワークスペース管理者の場合はすべてのエントリーを、読み取り可能な種類について、メニューの順に返します。
- `reorder` は、新しい順序の `keys`（それぞれ `<kind>:<item_id>`）を受け取り、ワークスペース管理者向けです。

Jupyter Hubのリンクは、ワークスペース管理者が `kind` を `jupyterHub`、`item_id` を `hub` にして、この方法でのみ公開できます。`publication_manage` は、Weaveや、自分に代わって動作する他のAIエージェントでは利用できません。
