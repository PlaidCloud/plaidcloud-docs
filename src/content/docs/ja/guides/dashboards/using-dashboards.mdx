## 概要

ダッシュボードを使うと、アクセスできる任意のプロジェクトやワークスペースのデータに対して、インタラクティブなビューを作成できます。1つのダッシュボードで、複数のプロジェクトのテーブルを組み合わせたり、可視化と生データの探索を組み合わせたりでき、定期レポートとアドホック分析の両方に対応します。ダッシュボードは、小さな参照テーブルから数十億行のデータセットまで、設定を変更せずにスケールします。

## ダッシュボードアカウント

ダッシュボードアカウントは、PlaidCloud から初めてダッシュボードを開いたときに自動的に設定されるため、手動で作成する必要はありません。表示できる内容は、PlaidCloud のワークスペースのメンバーシップとセキュリティグループによって決まります。

<Aside>ユーザーの追加、変更、削除は、ダッシュボードサービス内ではなく PlaidCloud で行ってください。詳しくは[ワークスペースメンバーの管理](/ja/administration/access/overview/managing-workspace-members/)をご覧ください。ダッシュボードサービスでユーザーアカウントを直接作成できるのは管理者だけで、その方法で作成したアカウントはワークスペースのメンバーシップと連携しません。</Aside>

## 表示されるダッシュボード

PlaidCloud のダッシュボード一覧には、アクセスできるプロジェクトに属する公開済みのダッシュボードが表示されます。これが通常のケースで、ほぼすべてのダッシュボードが該当します。

ダッシュボードの所有者とワークスペース管理者は、ダッシュボードを特定のセキュリティグループに制限できます。制限されたダッシュボードは、それらのグループのメンバー、所有者、ワークスペース管理者にのみ一覧表示されます。ワークスペース管理者にはすべてのダッシュボードが表示されます。制限のないダッシュボードは、そのプロジェクトにアクセスできる全員に一覧表示されるため、1つのダッシュボードを制限しても、ほかのダッシュボードの表示対象は変わりません。

ダッシュボードが一覧に表示されない場合は、次の2点を確認してください。

- **制限されたダッシュボードは、開けないだけでなく、一覧からも非表示になります。** ダッシュボードのプロジェクトにアクセスでき、そのリンクを開ける場合は、**Request access** ページが表示されます。そうでない場合は、削除されたと決めつけず、所有者に問い合わせてください。
- **制限されたダッシュボードが表示されるには、ダッシュボードアカウントが存在している必要があります。** アカウントは、PlaidCloud から初めてダッシュボードを開いたときに作成され、そのときにグループが適用されます。

<Aside>ダッシュボードを閲覧できるユーザーは、PlaidCloud の**閲覧できるユーザー**で設定します。詳しくは[ダッシュボードを閲覧できるユーザーを制御する](/ja/guides/dashboards/control-who-can-see-a-dashboard/)をご覧ください。プロジェクトのアクセス権は引き続き適用されます。ダッシュボードが表示されても、アクセスできないプロジェクトのデータが表示されることはありません。</Aside>

## 表示コントロール

表示コントロールは、フィルターバーのコントロールで、ダッシュボードを閲覧する誰もが、チャートを開いて編集することなく、チャートのグループ化の基準を変更できます。たとえば「Region」を「Product Line」に切り替えることができます。ダッシュボードの編集者は、フィルターバーの設定メニューから表示コントロールを追加して設定します。**Add or edit filters and controls** を選択し、**新規**メニューから **Add display control** を選択します。

### 表示される列を制限する

デフォルトでは、表示コントロールのドロップダウンには、基になるデータセットで **Is filterable** にマークされているすべての列が一覧表示されます。列数の多いデータセットでは、目的の列を見つけるために数百の列をスクロールすることになりかねません。

すべての表示コントロールには、設定パネルに専用の **Available columns** フィールドがあります。特定の列のリストを設定すると、そのコントロールのドロップダウンにはそれらの列だけが表示されます。空のままにすると、コントロールはこれまでどおり動作し、フィルター可能なすべての列が表示されます。これまでどおり動作させるために、ダッシュボードを変更する必要はありません。

表示コントロールを制限するには、次の手順を実行します。

1. フィルターバーの設定メニューから **Add or edit filters and controls** を開きます。
2. 制限したい表示コントロールを選択するか、新しく追加します。
3. **Available columns** で、閲覧者に表示したい列を検索して選択します。
4. 保存します。

### 「Is Filterable」との関係

**Available columns** で選択できるのは、データセットですでに **Is filterable** にマークされている列だけです。このリストをさらに絞り込むものであり、このリストを迂回することはできません。列の **Is filterable** のチェックを外すと、その列はどこからも削除されます。**Available columns**、アドホックフィルター、ネイティブフィルター、そしてそのデータセットに対して作成されたすべてのチャートの **Simple Metric** ピッカーから削除されます。

この影響範囲の広さが、**Available columns** が存在する理由です。これが導入される前は、表示コントロールのドロップダウンを短くする唯一の方法は、表示したくない列の **Is filterable** のチェックを外すことでした。しかしそうすると、そのデータセットのすべてのチャートのメトリックピッカーからも、同じ列が非表示になってしまいます。チャートがメトリックやアドホックフィルターとして必要とする可能性のあるすべての列で **Is filterable** をオンのままにし、各表示コントロールのグループ化ドロップダウンに何を表示するかは、そのコントロール固有の **Available columns** で決めてください。

<Aside type="caution">表示コントロールの **Available columns** リストにある列の名前を変更したり削除したりしても、自動的には検出されません。コントロールは、次に開いたときに、警告なしに表示する列が少なくなるだけです。データセットの列の名前を変更または削除した後は、表示コントロールの **Available columns** を見直してください。</Aside>

### 保存場所

**Available columns** は、そのコントロールのほかの設定とともに、表示コントロールごとに保存されます。ダッシュボードのエクスポートとインポートでも引き継がれ、同じダッシュボードや、同じデータセットから作成された別のダッシュボードにある、ほかのコントロールには影響しません。

## テーブルの編集


新しいテーブルを作成した後に表示されるメッセージにも、テーブルの設定を編集するよう案内されています。設定を編集するための高度な機能はほかにもありますが、ここでは限定的でシンプルな部分から始めます。テーブルの設定を編集するには、次の手順を実行します。


1. 目的のテーブルの編集アイコンをクリックします
2. 「List Columns」タブをクリックします
3. 列を好みの順に並べます
4. 「Save」をクリックします

これにより、データを探索するときにテーブルの特定の列をどのように使うかを定義できます。


* **グループ化可能**: 特定のフィールドでユーザーがメトリックをグループ化できるようにする場合
* **フィルター可能**: 特定のフィールドでフィルターする必要がある場合
* **個別カウント**: このフィールドの個別カウントを取得する場合
* **合計**: 合計したいメトリックの場合
* **最小**: 基本的な要約統計量を収集したいメトリックの場合
* **最大**: 基本的な要約統計量を収集したいメトリックの場合
* **Is temporal**: 日付または時刻のフィールドにはオンにします

## データの探索


データの探索を始めるには、目的のテーブルをクリックするだけです。デフォルトでは、テーブルビューが表示されます。



### データ件数の取得


テーブル内のすべてのレコードの件数を取得するには、次の手順を実行します。


1. フィルターを「Since」に変更します
2. 目的の since フィルターを入力します


	* 「3 years ago」のような簡単なフレーズを使用できます
3. 目的の until フィルターを入力します


	* 時間の上限のデフォルトは「now」です
4. 「グループ化」ヘッダーを選択します
5. メトリックのセクションに「Count」と入力します
6. 「COUNT(*)」を選択します
7. 「Query」ボタンをクリックします

テーブルに結果が表示されます。

**特定のフィールドや制限条件の件数を調べる場合:**

1. 「グループ化」フィールドに、目的の制限条件を入力します
2. クエリを実行します

<Aside>制限条件に「measurement」を使用すると、取得された測定値を参照します。この値は測定の種類によって異なります。そのため、「filter」セクション（例: weather_description と Maximum temperature）で、測定の種類が同じであることを確認してください。</Aside>

### 結果の件数を制限する

上位10件など、特定の件数の結果だけが必要な場合は、次の手順を実行します。

1. 「Options」を選択します
2. 「Row Limit」セクションに、必要な最大結果件数を入力します
3. 「Query」をクリックします

### 追加の可視化ツール

省略された値を完全な長さに展開するには、次の手順を実行します。

1. 「Edit Table Config」を選択します
2. 「List Sql Metric」をクリックします
3. 「Edit Metric」をクリックします
4. 「D3Format」をクリックします

測定単位を編集するには、次の手順を実行します。


1. 「Edit Table Config」を選択します
2. 「List Sql Metric」をクリックします
3. 「Edit Metric」をクリックします
4. 「SQL Expression」をクリックします

チャートの種類を変更するには、次の手順を実行します。


1. 「Chart Options」までスクロールします
2. 必須フィールドに入力します
3. 「Query」をクリックします

ここから、軸ラベル、余白、目盛りなどを設定できます。
