PlaidCloud のディメンションは**階層**です。コストセンター、製品、勘定科目、地域、期間などを整理するツリー構造で、配賦、ダッシュボード、レポートがデータを切り分けて集計するための土台になります。

ディメンションは、親子関係だけでなく、さらに多くの情報を持てます。各ノードにはプロパティ、エイリアス、値を保持できます。たとえば、コストセンターの階層で、各センターの報告通貨、代替ビューでの所属事業部、運用予算を示すこともできます。

ディメンションは、各プロジェクトの**ディメンション**タブで管理します。

## メイン階層

すべてのディメンションには**メイン**階層があります。メイン階層は、リーフメンバーの完全な集合を定義します。ディメンション内のすべてのリーフノードが、ここに含まれている必要があります。

メイン階層は、唯一の正となる標準のツリーと考えてください。ディメンション内のものはすべてメイン階層のメンバーであり、違いはツリーの*どこに*位置するかだけです。

## 代替（属性）階層

代替階層は、メイン階層のリーフを別の視点で表示するものです。リーフの一部だけを選んだり、異なる方法でグループ化したり、まったく異なるロールアップを使ったりできます。

よくあるパターンは次の2つです。

- **サブセットビュー** — 特定のレポートや配賦のために、特定のリーフを絞り込んだツリーにまとめます。代替階層は、メンバーに対するメイン階層での変更を引き継ぎます。
- **異なるロールアップ** — リーフは同じで、親が異なります。たとえば、メイン階層ではコストセンターを部門別に整理し、代替階層では同じコストセンターを地域別に整理します。

## ディメンションの管理

<Aside type="caution">
**どのユーザーがどの行を見られるかを決めるディメンションは、プロジェクトのアーキテクトだけが変更できます。**[行アクセス](/ja/administration/access/managing-security-groups-and-assignments/#ディメンションの付与)で行を制限しているプロジェクトでは、制限された列が値の取得元としているディメンションは、プロジェクトのアーキテクト、テナント管理者、またはプロジェクト自身のワークフローだけが変更できます。対象となる操作は、ノードの追加、移動、名前の変更、コピー、クリア、読み込み、復元と、ディメンション自体の作成、コピー、名前の変更、削除です。それ以外のユーザーには、誰に依頼すればよいかが表示されます。その他のディメンションや、行を制限していないプロジェクトのすべてのディメンションは、以下で説明するとおりに操作できます。
</Aside>

### 作成

ツールバーの**新規**ボタンから、**新規ディメンション**を選択します。名前、ディレクトリ（フォルダー形式の整理用）、説明メモを入力します。

**作成**をクリックすると、ディメンションがすぐに使用できる状態になります。ワークフローから、[Dimension Create](/ja/reference/workflow-steps/dimensions/dimension-create/)ステップを使って作成することもできます。

### 配賦ディメンションの作成

**配賦ディメンション**（**割り当てディメンション**とも呼びます）は、[配賦](/ja/guides/allocations/setup/configure-an-allocation/)ステップが、各ソースレコードをターゲットにどう分配するかを決めるために読み取る、特別なディメンションです。ノードを1つずつ作成する代わりに、ガイド付きビルダーを使うと、開始用のディメンションを1回の操作で作成できます。

ワークスペースでこの機能が有効で、ディメンションを作成する権限がある場合は、**新規**メニューを開いて**新規配賦ディメンション**（分割アイコン付き）を選択します。ビルダーが、4つの手順のうち最初の手順で開きます。

1. **名前とテーブル** — ディメンションに名前を付け、ルールがフィルターする**ソース（値）テーブル**と、金額の分配基準となる**ドライバーテーブル**を選択します。
2. **ルールフィルター** — ルールフィルターとして機能するソース列にチェックを入れます。すでにディメンションとの関係がある列はそのまま使われます。関係がない列には、値がメンバーに解決されるようにディメンションを関連付けられます。
3. **ドライバーとターゲット** — ドライバーテーブルの**ドライバー名**列と**ドライバー値**列を指定し、金額の分配先となる**ターゲット列**にチェックを入れます。
4. **ルール** — ルールのフラットなグリッドを入力します。各ルールは、ソースフィルターの値の組と、その組み合わせに使う名前付きドライバーで構成されます。

**完了**をクリックすると、PlaidCloud がディメンション全体を1回の操作で作成します。ディメンションツリーでは**分割アイコン**付きで表示され、通常の階層ではなく配賦ディメンションであることを示します。

このディメンションは、どの配賦とも独立して作成されるため、1つの配賦ディメンションを複数のステップで利用できます。使用するには、配賦ステップがこのディメンションを参照するように設定します。詳しくは、[配賦の構成](/ja/guides/allocations/setup/configure-an-allocation/)をご覧ください。

### 削除

ディメンションを選択し、**アクション**メニューを開いて**ディメンションを削除**を選択します。ディメンションと、その基になるすべてのデータが削除されます。

ワークフローから、[Dimension Delete](/ja/reference/workflow-steps/dimensions/dimension-delete/)ステップを使って削除することもできます。

ディメンションは残して内容だけをリセットする（構造、値、エイリアス、プロパティ、代替階層をすべてクリアする）場合は、削除の代わりに[Dimension Clear](/ja/reference/workflow-steps/dimensions/dimension-clear/)ステップを使用します。

### コピー

ディメンションを選択し、**アクション**を開いて**ディメンションをコピー**を選択します。コピーの名前を指定して**コピーを作成**をクリックします。コピーには、値、エイリアス、プロパティ、すべての代替階層が含まれます。

### 並べ替え

ディメンション管理エリアでは、メンバーを上下に移動したり、親を直接変更したりできます。大規模な階層では、手作業での操作は面倒になります。プログラムで並べ替えるには、[Dimension Sort](/ja/reference/workflow-steps/dimensions/dimension-sort/)ワークフローのステップを使用してください。データの読み込み後や大幅な再構成の後に、作業時間を大きく節約できます。

## ディメンションの読み込み

ディメンションの読み込みとは、表形式のソースデータを階層構造に変換することです。PlaidCloud は、読み込みに2種類のデータ形式をサポートしています。

- **親子** — 2つの列で、1つは親、もう1つは子です。各行がツリーの1本のエッジを定義します。深さが任意で不規則な階層にも使用できます。
- **レベル** — レベルごとに1列です。行ごとに、各列がそのレベルでの親を示します。国 → 地域 → 都市のように、深さが予測でき規則的な階層に最適です。

読み込みでは、構造と一緒に、値、エイリアス、プロパティも読み込めます。オプションの全体については、[Dimension Load](/ja/reference/workflow-steps/dimensions/dimension-load/)ワークフローのステップをご覧ください。

## ノードのプロパティ

階層のツールバーで**プロパティ**を切り替えると、ディメンションに定義されたプロパティごとに列が表示されます。たとえば、コストセンターの通貨、勘定科目の事業部、製品のカテゴリなどです。

### プロパティの追加または編集

1. ツールバーの**新規プロパティ**をクリックします
2. **プロパティ構成**ウィンドウで、**プロパティ名**を入力し、**プロパティ表示**（**テキスト**または**タグ**）を選択して、**エディタータイプ**を選びます。エディタータイプは、プロパティのデータ入力に使うコントロールで、**選択（ディメンション）**、**選択（固定）**、**選択（テーブル）**、**チェックボックス**、**スピナー**、**日付選択**、**数値**があります
3. エディタータイプにさらに設定が必要な場合は、**構成**セクションと**構成を編集**ボタンが表示されます
4. **作成**（編集する場合は**更新**）をクリックして保存します

既存のプロパティの設定を変更するには、その列を選択し、ツールバーから**プロパティ構成を編集**を選択します。**プロパティを削除**はプロパティ全体を削除し、**プロパティをクリア**は選択したエントリをクリアし、**プロパティのすべてのエントリをクリア**はすべてのノードにわたってクリアします。

### ディメンション型のプロパティとメンバーピッカー

プロパティの**エディタータイプ**を**選択（ディメンション）** に設定すると、別のディメンション（または同じディメンション）の階層に対するルックアップになります。たとえば、コストセンターの「地域」プロパティが地理ディメンションを指すような場合です。**構成を編集**をクリックすると、**ディメンションの構成**ウィンドウが開きます。

- **ディメンション**と**階層** — プロパティがメンバーを選択する元のディメンションと階層です。階層で**未指定**を選択すると、ピッカーにディメンション内のすべての階層が表示されます。
- **開始ノード（任意）** — ピッカーを、階層全体ではなくサブツリーに限定します。
- **複数選択を許可** — 1つのプロパティ値に複数のメンバーを保持できるようにします。デフォルトでオンです。チェックを外すと、プロパティを1つのメンバーに限定します。
- **特殊なケース** — 階層の実際のメンバーに加えて選択できる追加のエントリとして、**ソース**と**現在**を提供します。

**保存**するには、ディメンションの選択が必要です。階層は**未指定**のままにでき、これは空欄ではなく1つの選択肢です。

プロパティをこのように構成すると、グリッドでそのセルをダブルクリックしてメンバーピッカーを開けます。ディメンションにマップされた列の[データエディター](/ja/guides/projects/managing-data-editors/)グリッドでも、同じツリー形式のピッカーが表示されます。セルにすでに値があるかどうかにかかわらず、最初のダブルクリックで開きます。

- **すべて展開** / **すべて折りたたむ** — ツリーのすべての分岐を開いたり閉じたりします。
- メンバーをクリックして選択します（複数選択を許可がオンの場合は、複数のメンバーを選択できます）。
- **適用**で、プロパティを現在の選択内容に設定します。
- **クリア**で、プロパティの現在の値を削除します。
- **キャンセル**で、何も変更せずにピッカーを閉じます。

<Aside type="note">ピッカーを開いたときにグリッドで複数の行が選択されている場合、**適用**は、ダブルクリックした行だけでなく、選択されているすべての行に値を設定します。これは、多数の行を一度に編集することを意図した動作です。</Aside>

## ディメンションプロパティの継承

ディメンションは、子が祖先からプロパティ値を継承するように構成できます。有効にするには、**プロパティ**の横のドロップダウンをクリックし、**継承されたプロパティ**を選択します。

継承の動作に関する注意点は次のとおりです。

- 継承は、ディメンション内の**すべての**プロパティに適用されます。特定のプロパティだけで有効にすることはできません。
- 子にプロパティを設定した後でその値を削除すると、子は親の値に戻ります。親に値がある場合、子のプロパティを null にすることはできません。
- ノードにプロパティを設定すると、子孫に伝播し、明示的に設定されるまでは、継承された値を上書きします。
- 継承は、ツリーをリーフノードまでたどります。

## 階層内のノードの検索

大きなディメンションには何千ものメンバーがあることがあるため、階層ウィンドウには、グリッドに表示する内容を絞り込む方法が2つあります。どちらも、一致しないノードを強調表示するのではなく非表示にします。また、どちらも一致したノードの祖先を表示したままにするため、ノードがツリーのどこにあるかを確認できます。

### フィルターボックス

ウィンドウ下部の**フィルター:** ボックスは、入力に合わせて絞り込みます。大文字と小文字を区別せず、テキストの一部に一致し、次を検索します。

- 階層内のノードの名前
- 現在表示している**代替**、**エイリアス**、**プロパティ**、**値**の各列すべて

画面に表示されている列だけが検索対象のため、ツールバーの切り替えが検索範囲の切り替えを兼ねます。**プロパティ**をオンにすると、プロパティに保持された勘定コードでノードを検索でき、オフに戻すと名前だけを検索します。タグとして表示されるプロパティは、いずれか1つのタグに一致します。

ボックスの横のボタンで、フィルターを適用するペインとして**両方**、**メイン階層**、**代替階層**のいずれかを選択します。漏斗ボタンはフィルターをクリアして、ツリー全体を元に戻します。

<Aside type="note">フィルターボックスは、各ノードに保存されている値を検索します。**継承されたプロパティ**がオンの場合、祖先から継承した値を表示しているノードは、その値では一致しません。一致するのは、その値が実際に設定されている祖先だけです。</Aside>

### 詳細フィルター

フィルターボックスが表示中のすべての列を一度に検索するのに対し、階層ツールバーの**高度**は、列ごとの詳細な条件を作成します。**詳細ディメンションフィルターの構成**ウィンドウが開き、各行が1つの条件です。

1. **行を追加**をクリックします
2. **列**を選択します。ディメンションのプロパティまたは集計の列を選べます
3. **条件**を選択します。プロパティはテキストを保持するため `=`、`!=`、`contains` が選べます。集計は数値を保持するため `=`、`!=`、`<`、`>`、`<=`、`>=` が選べます
4. 比較する**値**を入力するか、**比較対象**で別の列を選択して2つの列を比較します。どちらか一方であり、両方は指定できません。**比較対象**には、同じ種類の値を保持する他の列が一覧表示されます。数値とテキストの比較では、どちらにしても意味のある結果が得られないためです
5. **更新**をクリックして適用します

**行を削除**は選択した行を削除し、**クリア**はリスト全体を空にします。さらに絞り込むには複数の行を追加します。ノードは、すべての行を満たす必要があり、フィルターボックスにテキストがあればそれも満たす必要があります。**更新**は、すべての行が完成するまで無効のままなので、作成途中の条件が、表示内容を意図せず変えることはありません。

詳細な条件はメイン階層に適用されます。フィルターボックスは引き続き、その横のボタンで選択したペインに適用されます。

テキストの条件は、フィルターボックスと同様に大文字と小文字を区別しません。`=` は値全体に一致するため、長いプロパティ値の中にあるコードや、複数タグのプロパティの1つのタグの中にあるコードを探すには、`contains` を使用してください。
