PlaidCloud のインターフェースは11の言語で利用できます。

| 言語 | メニューの表示 |
|---|---|
| 英語（米国） | English (US) |
| 英語（英国） | English (UK) |
| ドイツ語 | Deutsch |
| スペイン語 | Español |
| フランス語 | Français |
| ポルトガル語（ポルトガル） | Português (Portugal) |
| ポルトガル語（ブラジル） | Português (Brasil) |
| ポーランド語 | Polski |
| 日本語 | 日本語 |
| 韓国語 | 한국어 |
| 中国語（簡体字） | 简体中文 |

最初は誰もが English (US) で表示されます。言語を選択するまでは何も変わりません。

## 言語を変更する

1. 上部のヘッダーで、**外観**ボタンの隣にある**言語**ボタンをクリックします。メニューには各言語がその言語自身の名前で表示されるため、現在どの言語で表示されていても、目的の言語を見つけられます。
2. 言語を選択します。
3. PlaidCloud がその言語で再読み込みされることを知らせるメッセージが表示されます。未保存の変更は失われるため、先に作業内容を保存してください。続行するには**再読み込み**をクリックします。現在の状態のままにするには、キャンセルします。

PlaidCloud は選択内容をプロフィールに保存し、新しい言語で再読み込みします。元に戻すには、同じ手順で **English (US)** を選択します。

## 選択が適用される範囲

- **他のデバイスとブラウザ。** 選択内容は引き継がれます。別のデバイスやブラウザで同じワークスペースにサインインすると、次回のページ読み込みから適用されます。
- **ワークスペースごと。** 選択内容は、1つのワークスペースにおけるプロフィールに紐付きます。複数のワークスペースを使用している場合は、それぞれで言語を設定してください。

## 数値と日付

数値と日付は、選択した言語の形式で表示されます。たとえばドイツ語では、1,234.5 は `1.234,5` と表示されます。ポーランド語では、1234567.89 は `1 234 567,89`、2026年10月12日は `12.10.2026` と表示されます。日本語と中国語ではこの日付が `2026/10/12`、韓国語では `26. 10. 12.` と表示されます。English (UK) では、英国式のスペルと形式が使用されます。

変わるのは表示だけです。保存、エクスポート、連携先への送信を行う値は、通常の形式のままです。

## 日本語、韓国語、中国語での入力

日本語、韓国語、中国語の入力方式は、数値フィールドなど、入力できる内容が制限されるフィールドでも使用できます。全角の数字は入力時に変換されるため、`１２３` は `123` になります。

## 言語に従うその他の項目

サーバーから送信されるテキストも、PlaidCloud が提供するすべての言語で、選択した言語に従います。

- **メール。** 招待、パスワードのリセット、ワークフローや移行に関する通知、サインアップ、請求、サポートのメールなどのシステムメール。
- **サインイン画面。** サインイン、パスワード設定、サインアウト済みの各画面と、そこから Keycloak が送信するメール。
- **エラーメッセージ。** リクエストが失敗したときに PlaidCloud が表示するメッセージ。インターフェース、REST API、JSON-RPC のいずれでも対象です。
- **プロジェクトドキュメントの PDF。** プロジェクトを文書化するために PlaidCloud が生成する PDF。

## PlaidCloud が言語を選ぶ方法

| 場所 | 使用される言語 |
|---|---|
| PlaidCloud 内 | **言語**ボタンで選択した言語。サインインページとメールも同じ選択に従います。 |
| サインイン前のサインイン画面やその他の画面 | ブラウザの言語。 |
| サインアップ | ブラウザの言語。PlaidCloud は組織にこの言語を保存し、組織宛ての請求メールとアカウントメールで使用します。 |

ブラウザまたはプロフィールで PlaidCloud が提供していない言語が使われている場合、テキストは English (US) で表示されます。繁体字中国語（zh-TW または zh-HK）に設定されたブラウザでは、サーバーのテキストは English (US) にフォールバックします。

## 英語のままのもの

- ワークフローとステップの実行メッセージおよびログ、アクティビティストリーム。多くの人が読むため、1つの言語に統一することで、検索しやすく一貫性が保たれます。
- AI アシスタントと MCP ツールのテキスト。
- メールテンプレートやレポートステップから送信されるメールを含め、ご自身で作成したメール。
- OpenAPI ドキュメント。
- SQL エンジンおよび式エンジンのエラーテキスト。
- サインアップ画面。
- プロジェクト、テーブル、ステップの名前など、ご自身が作成したコンテンツ。
