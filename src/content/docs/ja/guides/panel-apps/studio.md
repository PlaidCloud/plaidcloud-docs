Panel Studio は、PlaidCloud 内で Panel アプリを編集するためのエディターです。アプリのファイルをエディターの隣に表示し、開いて確認できる非公開のプレビューをビルドし、準備ができたらアプリを公開します。始めるのに Git リポジトリは必要ありません。

## Panel Studio を開く

- プロジェクトの**ホーム**ボードで、Panel アプリの **Studio で開く**を選択します。
- **アプリ**で、アプリの行にある **Studio** を選択します。

新しいアプリを始めるには、**新規アプリ** > **Studio** を選択します。プロジェクトの**ホーム**タブの**アプリとブランディング**カードの**Studio アプリ**行からも開始できます。テーブルをもとにアプリを作成するには、プロジェクトの**テーブル**タブでテーブルを選択し、**Panel アプリを作成**を選択します。

## アプリを作成する

**新しい Studio アプリ**ダイアログでは、次の 5 つの開始元から選べます。

| 開始元 | 作成されるもの |
|---|---|
| **空のアプリ** | `app.py` と `requirements.txt` だけの最小限のアプリ。 |
| **テーブルから** | 選択したテーブルをもとにしたアプリ。 |
| **ビューから** | プロジェクトのビューをもとにした同様のアプリ。 |
| **別の Studio アプリから** | 既存の Studio アプリのコピー。 |
| **ギャラリーから** | ワークスペースが[アプリギャラリー](/ja/guides/panel-apps/gallery/)に掲載したアプリのコピー。 |

アプリに名前を付け、**プロジェクト**を選択して、**作成**を選択します。Studio が新しいアプリを開き、左側にファイルが一覧表示されます。テーブルまたはビューから作成した場合は、アプリの最初のページを作成するための Weave へのプロンプトが送信できる状態で用意されています。[Panel アプリの作成](/ja/guides/panel-apps/creating/)を参照してください。

## アプリの保存場所

Studio アプリは、ワークスペースの `apps` リポジトリ内（[PlaidCloud Git](/ja/guides/git/)）に、アプリ名を付けたフォルダー（`<app-slug>/`）として保存されます。このリポジトリは、他の Panel アプリが保存されているものと同じです。Studio がアプリ専用のリポジトリを作成することはないため、ソースは他のアプリと並んで `apps` 内で確認、編集できます。

- **ドラフトブランチ。** まだ公開していない作業内容は、`studio-<app-slug>` という名前のブランチに保持されます。**公開**すると、そのブランチからアプリのフォルダーがメインブランチにコピーされます。
- **再ビルド。** `apps` へのプッシュでアプリが再ビルドされるのは、そのアプリのフォルダー、またはリポジトリのルートにある `requirements.txt` が変更された場合だけです。
- **既存のアプリ。** 専用のリポジトリにあった Studio アプリは、自動的にフォルダーへ移動されます。古いリポジトリはアーカイブされ、読み取り専用のまま残り、削除されることはありません。

## 編集

一覧からファイルを選択すると、エディターで編集できます。Python の依存関係は `requirements.txt` に 1 行に 1 パッケージずつ記述します。依存関係はアプリのビルド時にインストールされます。

**Weave に質問**を選択すると、Weave にアプリの作成や変更を任せられます。[Weave で Panel アプリを作成する](/ja/guides/panel-apps/build-with-weave/)を参照してください。

### 保存

**保存**すると、変更内容がドラフトとして保存されます。ライブアプリは変わらず、ドラフトは他のユーザーには表示されません。

### プレビュー

**プレビュー**は、保存済みのドラフトを非公開のコピーとしてビルドし、開きます。プレビューを開けるのは、アプリの編集者だけです。

- プレビューは、保存しないまま 24 時間が経過すると削除されます。
- ワークスペースで同時に持てるプレビューは最大 10 件です。
- 最新の編集内容を確認するには、もう一度保存してから**プレビュー**を選択します。

### 公開

**公開**すると、ライブアプリが保存済みのドラフトに置き換わります。アプリのプロジェクトに対する編集権限が必要で、Studio は先に確認を求めます。

アプリを開いた後に他のユーザーが変更を公開していた場合、Studio はその作業を上書きせず、競合を報告します。アプリを再読み込みし、自分の編集内容を反映し直してから、もう一度公開してください。

## ビルドの状況とエラー

**作成**タブには、最新のビルドの状況が表示され、ビルドの進行に合わせて更新されます。ビルドが失敗すると、タブに各エラーがファイル名と行番号とともに一覧表示されるため、該当の行にすぐ移動できます。`requirements.txt` の依存関係に関する問題には、修正方法のヒントが表示されます。

エラーと警告はエディター上の該当行にも表示されるため、問題の場所をその場で確認できます。

アプリの公開後に各状況が何を意味するかについては、[Panel アプリの使用](/ja/guides/panel-apps/using/#ビルドステータスサーバーアプリ)を参照してください。

## 履歴と復元

**履歴**タブには、アプリの公開済みバージョンがすべて新しい順に、ビルドの状況とともに一覧表示されます。古いバージョンを表示するには、**さらに読み込む**を選択します。

以前のバージョンに戻すには、そのバージョンの**復元**を選択して確認します。復元したバージョンがライブアプリになり、再ビルドされます。未保存のドラフトが失われることはありません。ドラフトはそのまま残り、次に公開したときに、復元したバージョンの上に重ねてライブになります。アプリがすでにそのバージョンと一致している場合、Studio はその旨を表示し、何も変更しません。復元中に他のユーザーが公開した場合、Studio は何も復元せず、もう一度試すよう求めます。

## インサイト

**インサイト**タブには、アプリの利用状況と応答速度が表示されます。直近 7 日、14 日、30 日から選択できます。

| セクション | 表示内容 |
|---|---|
| **1 日あたりのビュー数** | 1 日ごとにアプリが開かれた回数。 |
| **ページの読み込み** | 期間内のページ読み込みから算出した、読み込み時間の中央値と、読み込みの 95 パーセントがそれ以内に収まる時間。 |
| **最も遅いクエリ** | 最も時間のかかったクエリ。実行回数と、中央値、低速側、最も遅い時間を表示します。 |
| **エラー** | 期間内に発生した問題を、エラーの種類とアプリ内の発生箇所別に表示。 |

期間内の操作がインサイトの読み取れる量を超える場合は、数値が一部のみであることが表示されます。ページの読み込みがアプリの[パフォーマンスバジェット](/ja/guides/panel-apps/app-kit/#パフォーマンスバジェット)を超えた場合、インサイトは超過した件数と、遅かったクエリを警告します。インサイトには、クエリが返したデータや、アプリを開いたユーザーの名前は表示されません。

**履歴**タブと**インサイト**タブを使うには、アプリがプロジェクトに割り当てられている必要があります。未割り当てのアプリには、割り当てを促すメッセージが表示されます。

## アラートとダイジェスト

**アラートとダイジェスト**を選択すると、アプリのデータ内の数値を監視して上限を超えたときに通知する設定や、スケジュールに沿って概要を送信する設定ができます。[アラートとダイジェスト](/ja/guides/panel-apps/alerts-and-digests/)を参照してください。

## アプリをギャラリーに掲載する

Studio で **ギャラリー…** ボタンを選択します。**ギャラリーに掲載**を選択すると、そのプロジェクトを閲覧できるユーザーなら誰でも自分のアプリを作成できるテンプレートとして、アプリが掲載されます。掲載を取り下げるには、**ギャラリーから外す**を選択します。このボタンは、プロジェクトに属するアプリで利用できます。プロジェクトへの編集アクセスが必要です。[アプリギャラリー](/ja/guides/panel-apps/gallery/)を参照してください。

## ホームにピン留め

**ホームにピン留め**を選択すると、アプリがプロジェクトの**ホーム**ボードに追加されます。取り除くには、**ホームからピン留めを外す**を選択します。

## アプリを削除する

Panel アプリを削除する前には、確認が求められます。**アプリ**で、アプリの行にある**マイナス**アイコンを使用します。公開の取り消しでも確認が求められます。
