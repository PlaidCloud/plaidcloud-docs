Panel Studio は、PlaidCloud 内でPanelアプリを編集するためのエディターです。アプリのファイルをエディターの横に表示し、開けるプライベートなプレビューを作成し、準備ができたらアプリを公開します。開始するのに Git リポジトリは必要ありません。

## Panel Studio を開く

- プロジェクトの**ホーム**ボードで、Panelアプリの **Studio で開く**を選択します。
- **マイPanelアプリ**で、アプリの行にある **Studio** を選択します。

新しいアプリを始めるには、**新しい Studio アプリ**を選択します。このボタンは**マイPanelアプリ**ツールバーの最初のボタンで、プロジェクトの**ホーム**タブにある **Panel アプリ**ボックスにもあります。テーブルをもとにアプリを作るには、プロジェクトの**テーブル**タブでそのテーブルを選択し、**Panel アプリを作成**を選択します。

## アプリを作成する

**新しい Studio アプリ**ダイアログでは、次の 5 つのうちいずれかから開始できます。

| 開始元 | 作成されるもの |
|---|---|
| **空のアプリ** | `app.py` と `requirements.txt` だけの最小限のアプリ。 |
| **テーブルから** | 選択したテーブルをもとに作成されるアプリ。 |
| **ビューから** | プロジェクトのビューをもとに作成される同様のアプリ。 |
| **別の Studio アプリから** | お使いの Studio アプリのコピー。 |
| **ギャラリーから** | ワークスペースが[アプリギャラリー](/ja/guides/panel-apps/gallery/)に掲載しているアプリのコピー。 |

アプリに名前を付け、**プロジェクト**を選択して、**作成**を選択します。Studio が新しいアプリを開き、左側にファイルが一覧表示されます。テーブルまたはビューから作成した場合は、アプリの最初のページを作成するための Weave へのプロンプトが送信できる状態になっています。[Panelアプリを作成する](/ja/guides/panel-apps/creating/)を参照してください。

## アプリの保存場所

Studio アプリは、[PlaidCloud Git](/ja/guides/git/) にあるワークスペースの `apps` リポジトリ内に、アプリ名を付けたフォルダー（`<app-slug>/`）として保存されます。このリポジトリは、他のPanelアプリが置かれているものと同じです。Studio はアプリ専用のリポジトリを作成しないため、そのソースは他のアプリと並んで `apps` 内で確認、編集できます。

- **下書きブランチ。** まだ公開されていない作業は、`studio-<app-slug>` という名前のブランチに保持されます。**公開**すると、そのブランチからアプリのフォルダーがメインブランチにコピーされます。
- **再ビルド。** `apps` へのプッシュでアプリが再ビルドされるのは、そのアプリのフォルダー、またはリポジトリのルートにある `requirements.txt` が変更された場合のみです。
- **既存のアプリ。** 独自のリポジトリにあった Studio アプリは、自動的にそのフォルダーへ移されます。古いリポジトリはアーカイブされます。読み取り専用のまま残り、削除されることはありません。

## 編集

一覧からファイルを選択すると、エディターで編集できます。Python の依存関係は `requirements.txt` に 1 行に 1 パッケージずつ記述します。これらはアプリのビルド時にインストールされます。

**Weave に質問**を選択すると、Weave にアプリの作成や変更を任せられます。[Weave でPanelアプリを作成する](/ja/guides/panel-apps/build-with-weave/)を参照してください。

### 保存

**保存**すると、変更が下書きとして保存されます。本番アプリは変更されず、他のユーザーが下書きを見ることもありません。

### プレビュー

**プレビュー**は、保存済みの下書きをプライベートなコピーとしてビルドし、開きます。プレビューを開けるのは、そのアプリの編集者だけです。

- プレビューは、保存が行われないまま 24 時間が経過すると削除されます。
- 1 つのワークスペースで同時に作成できるプレビューは最大 10 個です。
- 最新の編集内容を確認するには、もう一度保存してから**プレビュー**を選択します。

### 公開

**公開**すると、本番アプリが保存済みの下書きに置き換わります。アプリのプロジェクトに対する編集権限が必要で、Studio は最初に確認を求めます。

アプリを開いた後に他のユーザーが変更を公開していた場合、Studio はその作業を上書きせず、競合を報告します。アプリを再読み込みし、自分の編集内容を反映してから、もう一度公開してください。

## ビルドステータスとエラー

**作成**タブには、最新のビルドのステータスが表示され、実行中は自動的に更新されます。ビルドが失敗すると、タブにエラーがファイル名と行番号とともに一覧表示されるため、該当の行にすぐ移動できます。`requirements.txt` の依存関係の問題には、修正方法のヒントが付きます。

エラーと警告はエディター内の該当行にもマークされるため、問題をその場で確認できます。

アプリの公開後に各ステータスが何を意味するかについては、[Panelアプリを使用する](/ja/guides/panel-apps/using/#ビルドステータスサーバーアプリ)を参照してください。

## 履歴と復元

**履歴**タブには、アプリの公開済みバージョンが新しい順にすべて一覧表示され、それぞれのビルドステータスも確認できます。古いバージョンを表示するには、**さらに読み込む**を選択します。

以前のバージョンに戻すには、そのバージョンで**復元**を選択して確認します。復元したバージョンが本番アプリとなり、再ビルドされます。保存していない下書きは失われません。下書きとして残り、次に公開したときに、復元したバージョンの上に重ねて本番に反映されます。アプリがすでにそのバージョンと一致している場合、Studio はその旨を伝え、何も変更しません。復元中に他のユーザーが公開した場合、Studio は何も復元せず、再試行を求めます。

## インサイト

**インサイト**タブには、アプリがどのように使われているか、どれくらい速く応答しているかが表示されます。過去 7 日間、14 日間、30 日間から選択できます。

| セクション | 表示内容 |
|---|---|
| **1 日あたりのビュー数** | アプリが 1 日に何回開かれたか。 |
| **ページの読み込み** | 期間内のページ読み込みから算出した、読み込み時間の中央値と、読み込みの 95 パーセントがそれより速く完了した時間。 |
| **最も遅いクエリ** | 最も時間がかかったクエリ。実行回数と、中央値、遅い側、最も遅い時間も表示されます。 |
| **エラー** | 期間内に発生した問題を、エラーの種類とアプリ内で発生した場所別に表示します。 |

期間内のアクティビティがインサイトで読み取れる量を超える場合、数値が一部のみであることが表示されます。ページの読み込みがアプリの[パフォーマンスバジェット](/ja/guides/panel-apps/app-kit/#パフォーマンス予算)を超えると、インサイトは超過した件数と、遅かったクエリを警告します。インサイトには、クエリが返したデータや、アプリを開いたユーザーの名前が表示されることはありません。

**履歴**タブと**インサイト**タブを使用するには、アプリがプロジェクトに割り当てられている必要があります。割り当てられていないアプリには、割り当てを促すメッセージが表示されます。

## アラートとダイジェスト

**アラートとダイジェスト**を選択すると、アプリのデータ内の数値を監視して上限を超えたときに通知する設定や、サマリーをスケジュールに沿って送信する設定ができます。[アラートとダイジェスト](/ja/guides/panel-apps/alerts-and-digests/)を参照してください。

## アプリをギャラリーに掲載する

Studio で **ギャラリー…** ボタンを選択します。**ギャラリーに掲載**を選択すると、そのプロジェクトを閲覧できるユーザーなら誰でも自分のアプリを作成できるテンプレートとして、アプリが掲載されます。掲載を取り消すには、**ギャラリーから外す**を選択します。このボタンは、プロジェクトに属するアプリで使用できます。プロジェクトの編集権限が必要です。[アプリギャラリー](/ja/guides/panel-apps/gallery/)を参照してください。

## ホームにピン留めする

**ホームにピン留め**を選択すると、アプリがプロジェクトの**ホーム**ボードに追加されます。削除するには、**ホームからピン留めを外す**を選択します。

## アプリを削除する

Panelアプリを削除する際は、最初に確認が求められます。**マイPanelアプリ**で、アプリの行にある**マイナス**アイコンを使用します。公開の取り消しでも確認が求められます。
