Panel Studio は、PlaidCloud 内で Panelアプリを編集するためのエディターです。アプリのファイルをエディターの横に表示し、開くことができる非公開のプレビューをビルドして、準備ができたらアプリを公開します。開始するのに Git リポジトリは必要ありません。

## Panel Studio を開く

- プロジェクトの**ホーム**ボードで、Panelアプリの **Studio で開く**を選択します。
- **マイPanelアプリ**で、アプリの行にある **Studio** を選択します。

新しいアプリを始めるには、**新しい Studio アプリ**を選択します。このボタンは、**マイPanelアプリ**のツールバーの最初のボタンであり、プロジェクトの**ホーム**タブの **Panel アプリ**ボックスにもあります。テーブルをもとにアプリを作成するには、プロジェクトの**テーブル**タブでテーブルを選択し、**Panel アプリを作成**を選択します。

## アプリを作成する

**新しい Studio アプリ**ダイアログでは、次の 5 つの開始元から選べます。

| 開始元 | 作成されるもの |
|---|---|
| **空のアプリ** | `app.py` と `requirements.txt` だけの最小限のアプリ。 |
| **テーブルから** | 選択したテーブルをもとに作成されたアプリ。 |
| **ビューから** | プロジェクトのビューをもとに作成された、同様のアプリ。 |
| **別の Studio アプリから** | 自分の Studio アプリのいずれかのコピー。 |
| **ギャラリーから** | ワークスペースが[アプリギャラリー](/ja/guides/panel-apps/gallery/)に掲載しているアプリのコピー。 |

アプリに名前を付け、**プロジェクト**を選んで、**作成**を選択します。Studio で新しいアプリが開き、左側にファイルが一覧表示されます。テーブルまたはビューから作成した場合は、アプリの最初のページを作成する Weave へのプロンプトが送信できる状態になっています。[Panelアプリの作成](/ja/guides/panel-apps/creating/)を参照してください。

## 編集

一覧からファイルを選ぶと、エディターで編集できます。Python の依存関係は、1 行に 1 パッケージずつ `requirements.txt` に記述します。依存関係は、アプリのビルド時にインストールされます。

**Weave に質問**を選択すると、Weave にアプリの作成や変更を任せられます。[Weave で Panelアプリを作成する](/ja/guides/panel-apps/build-with-weave/)を参照してください。

### 保存

**保存**を選択すると、変更内容が下書きとして保存されます。稼働中のアプリは変わらず、下書きは他のユーザーには表示されません。

### プレビュー

**プレビュー**は、保存した下書きを非公開のコピーとしてビルドして開きます。プレビューを開けるのは、そのアプリの編集者だけです。

- プレビューは、保存しないまま 24 時間が経過すると削除されます。
- ワークスペースで同時に作成できるプレビューは最大 10 個です。
- 最新の編集内容を確認するには、もう一度保存してから**プレビュー**を選択します。

### 公開

**公開**は、稼働中のアプリを保存した下書きで置き換えます。アプリのプロジェクトに対する編集権限が必要で、Studio は最初に確認を求めます。

アプリを開いた後に他のユーザーが変更を公開していた場合、Studio はその内容を上書きせず、競合を通知します。アプリを再読み込みし、自分の編集内容を反映させてから、もう一度公開してください。

## ビルドの状態とエラー

**Build** タブには、最新のビルドの状態が表示され、実行中は更新されます。ビルドが失敗すると、このタブに各エラーがファイル名と行番号とともに一覧表示されるため、該当の行にすぐ移動できます。`requirements.txt` の依存関係の問題には、修正方法のヒントが付きます。

エラーと警告はエディターの該当行にも表示されるので、問題の箇所を直接確認できます。

アプリの公開後の各状態の意味については、[Panelアプリを使用する](/ja/guides/panel-apps/using/#ビルドステータスサーバーアプリ)を参照してください。

## 履歴と復元

**履歴**タブには、アプリの公開済みのすべてのバージョンが、新しい順にビルドの状態とともに一覧表示されます。**さらに読み込む**を選択すると、古いバージョンを表示できます。

以前のバージョンに戻すには、そのバージョンの**復元**を選択して確認します。復元したバージョンが稼働中のアプリになり、再ビルドされます。保存していない下書きは失われません。下書きとして残り、次に公開するときに、復元したバージョンの上に重ねて公開されます。アプリがすでにそのバージョンと一致している場合、Studio はその旨を表示し、何も変更しません。復元中に他のユーザーが公開した場合、Studio は何も復元せず、もう一度試すように求めます。

## インサイト

**インサイト**タブには、アプリの利用状況と応答の速さが表示されます。過去 7 日間、14 日間、30 日間から選択できます。

| セクション | 表示される内容 |
|---|---|
| **1 日あたりのビュー数** | 1 日ごとにアプリが開かれた回数。 |
| **ページの読み込み** | その期間のページの読み込みにおける、読み込み時間の中央値と、読み込みの 95 パーセントがそれより速く完了した時間。 |
| **最も遅いクエリ** | 最も時間のかかったクエリ。実行回数と、中央値、遅い側、最も遅い時間が示されます。 |
| **エラー** | その期間に発生した問題。エラーの種類と、アプリ内で発生した場所別に表示されます。 |

期間内のアクティビティがインサイトで読み取れる量を超える場合は、数値が一部のみであることが表示されます。ページの読み込みがアプリの[パフォーマンス予算](/ja/guides/panel-apps/app-kit/#パフォーマンス予算)を超えると、インサイトは超過した件数と、遅かったクエリを警告します。インサイトに、クエリが返したデータやアプリを開いたユーザーの名前が表示されることはありません。

**履歴**タブと**インサイト**タブを使用するには、アプリがプロジェクトに割り当てられている必要があります。割り当てられていないアプリには、割り当てを促すメッセージが表示されます。

## アラートとダイジェスト

**アラートとダイジェスト**を選択すると、アプリのデータにある数値を監視して上限を超えたときに通知する、または一定のスケジュールで概要を送信する通知を設定できます。[アラートとダイジェスト](/ja/guides/panel-apps/alerts-and-digests/)を参照してください。

## アプリをギャラリーに掲載する

Studio で**ギャラリー…** を選択します。**ギャラリーに掲載**を選択すると、そのプロジェクトを閲覧できるユーザーなら誰でも自分のアプリを作成できるテンプレートとして、アプリが掲載されます。**ギャラリーから外す**を選択すると、掲載が削除されます。このボタンは、プロジェクトに属するアプリで使用できます。プロジェクトに対する編集アクセスが必要です。[アプリギャラリー](/ja/guides/panel-apps/gallery/)を参照してください。

## ホームにピン留めする

**ホームにピン留め**を選択すると、アプリがプロジェクトの**ホーム**ボードに追加されます。**ホームからピン留めを外す**を選択すると、削除されます。

## アプリを削除する

Panelアプリを削除する前には、確認が求められます。**マイPanelアプリ**で、アプリの行にある**マイナス**アイコンを使用します。非公開にする場合も、確認が求められます。
