Panel Studioは、PlaidCloud内でPanelアプリを編集するためのエディターです。アプリのファイルをエディターの横に表示し、開けるプライベートなプレビューをビルドし、準備ができたらアプリを公開します。開始にgitリポジトリは必要ありません。

## Panel Studioを開く

- プロジェクトの**ホーム**ボードで、Panelアプリの**Studio で開く**を選択します。
- **マイPanelアプリ**で、アプリの行の**Studio で開く**を選択します。

新しいアプリを開始するには、**新しい Studio アプリ**を選択します。これは**マイPanelアプリ**ツールバーの最初のボタンで、プロジェクトの**ホーム**タブの**Panelアプリ**ボックスにもあります。テーブルを元に作成するには、プロジェクトの**テーブル**タブでテーブルを選択し、**Panel アプリを作成**を選択します。

## アプリを作成する

**新しい Studio アプリ**ダイアログでは、次の5つの開始元から選べます。

| 開始元 | 作成されるもの |
|---|---|
| **空のアプリ** | `app.py`と`requirements.txt`だけの最小限のアプリです。 |
| **テーブルから** | 選択したテーブルを元に作成されるアプリです。 |
| **ビューから** | 同様に、プロジェクトのビューを元に作成されるアプリです。 |
| **別の Studio アプリから** | ご自身のStudioアプリのコピーです。 |
| **ギャラリーから** | ワークスペースが[アプリギャラリー](/ja/guides/panel-apps/gallery/)に掲載したアプリのコピーです。 |

アプリに名前を付け、**プロジェクト**を選択して、**作成**を選択します。Studioが新しいアプリを開き、左側にそのファイルが一覧表示されます。テーブルまたはビューの場合は、アプリの最初のページを作成するためのWeaveのプロンプトがすぐに送信できる状態になっています。[Panelアプリの作成](/ja/guides/panel-apps/creating/)を参照してください。

## 編集

一覧からファイルを選択すると、エディターで編集できます。Pythonの依存関係は、`requirements.txt`に1行に1パッケージずつ記載します。アプリのビルド時にインストールされます。

**Weave に質問**を選択すると、Weaveにアプリの作成や変更を任せられます。[WeaveでPanelアプリを作成する](/ja/guides/panel-apps/build-with-weave/)を参照してください。

### 保存

**保存**は、変更を下書きとして保存します。公開中のアプリは変更されず、下書きが他のユーザーに表示されることもありません。

### プレビュー

**プレビュー**は、保存済みの下書きをプライベートなコピーとしてビルドして開きます。プレビューを開けるのは、アプリの編集者だけです。

- プレビューは、保存しないまま24時間経過すると削除されます。
- 1つのワークスペースに同時に存在できるプレビューは最大10件です。
- 最新の編集内容を確認するには、もう一度保存して**プレビュー**を選択します。

### 公開

**公開**は、公開中のアプリを保存済みの下書きで置き換えます。アプリのプロジェクトの編集権限が必要で、Studioは最初に確認を求めます。

アプリを開いた後で他のユーザーが変更を公開した場合、Studioは相手の作業を上書きせず、競合を報告します。アプリを再読み込みし、自分の編集内容を反映させてから、もう一度公開してください。

## ビルドステータスとエラー

**作成**タブには、最新のビルドのステータスが表示され、実行中は更新されます。ビルドが失敗すると、タブに各エラーがファイル名と行番号とともに一覧表示されるため、その行にすぐ移動できます。`requirements.txt`の依存関係の問題には、修正方法のヒントが付きます。

エラーと警告は、エディター内のその行にもマークされるため、問題をその場で確認できます。

アプリの公開後に各ステータスが意味する内容については、[Panelアプリの使用](/ja/guides/panel-apps/using/#ビルドステータスサーバーアプリ)を参照してください。

## 履歴と復元

**履歴**タブには、アプリの公開済みの全バージョンが、新しい順にビルドステータスとともに一覧表示されます。古いものを表示するには、**さらに読み込む**を選択します。

以前のバージョンに戻すには、そのバージョンの**復元**を選択して確定します。復元したバージョンが公開中のアプリになり、再ビルドされます。未保存の下書きは失われません。下書きとして残り、次回の公開時に、復元したバージョンの上に重ねて公開されます。アプリがすでにそのバージョンと一致している場合、Studioはその旨を通知し、何も変更しません。復元中に他のユーザーが公開した場合、Studioは何も復元せず、再試行を求めます。

## インサイト

**インサイト**タブには、アプリの利用状況と応答の速さが表示されます。直近の7日、14日、30日から選択します。

| セクション | 表示内容 |
|---|---|
| **1日あたりのビュー数** | 1日ごとにアプリが開かれた回数です。 |
| **ページ読み込み** | 期間内のページ読み込みから算出した、読み込み時間の中央値と、読み込みの95パーセントがそれより短く完了する時間です。 |
| **最も遅いクエリ** | 最も時間がかかったクエリです。実行回数と、中央値、遅い側の時間、最も遅い時間が表示されます。 |
| **エラー** | 期間内に発生した問題を、エラーの種類とアプリ内で発生した場所別に示します。 |

期間内のアクティビティがインサイトで読み取れる量を超えている場合は、数値が一部であることが示されます。ページ読み込みがアプリの[パフォーマンス予算](/ja/guides/panel-apps/app-kit/#パフォーマンス予算)を超えた場合、インサイトは超えた件数と、遅かったクエリを警告します。インサイトに、クエリが返したデータや、アプリを開いたユーザーの名前が表示されることはありません。

どちらのタブも、アプリがプロジェクトに割り当てられている必要があります。割り当てられていないアプリには、割り当てを促すメッセージが表示されます。

## アラートとダイジェスト

**アラートとダイジェスト**を選択すると、アプリのデータ内の数値を監視して上限を超えたときに通知する設定や、スケジュールに従ってサマリーを送信する設定ができます。[アラートとダイジェスト](/ja/guides/panel-apps/alerts-and-digests/)を参照してください。

## アプリをギャラリーに掲載する

Studioで **ギャラリー…** ボタンを選択します。**ギャラリーに掲載**を選択すると、プロジェクトを閲覧できるユーザーなら誰でも自分のアプリを作成できるテンプレートとして、アプリが掲載されます。**ギャラリーから外す**を選択すると、削除されます。このボタンは、プロジェクトに属するアプリで使用できます。プロジェクトの編集アクセス権が必要です。[アプリギャラリー](/ja/guides/panel-apps/gallery/)を参照してください。

## ホームに固定する

**ホームにピン留め**を選択すると、アプリがプロジェクトの**ホーム**ボードに追加され、**ホームからピン留めを外す**を選択すると削除されます。

## アプリを削除する

Panelアプリを削除する前には、確認が求められます。**マイPanelアプリ**で、アプリの行の**マイナス**アイコンを使用します。公開の取り消しでも確認が求められます。
