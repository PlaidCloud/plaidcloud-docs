ランチャーは、ワークスペースにサインインした直後に最初に表示される画面です。プロジェクト、ワークフロー、テーブル、ダッシュボード、Panelアプリ、ディメンション、データエディター、ドキュメントなど、最もよく使うものを1ページのタイルにまとめます。各アプリを探し回らなくても、中断したところから作業を再開できます。

## レーン

ページは、上から下へ3つのレーンに整理されています。レーンは、表示する内容がある場合にのみ表示されます。

- **要対応** — 直近の実行が失敗したワークフローです。ランディングした瞬間に問題が目に入ります。各カードは失敗した実行に直接リンクしており、すでに対応した項目は**閉じる**ことができます。
- **ピン留め** — お気に入りとしてマークしたものすべてが、ピン留めした順に表示されます。ここには、あらゆる種類の項目をピン留めできます（[ピン留め](#ピン留めお気に入り)を参照）。
- **最近使用** — 最近開いた、または編集したプロジェクト、ダッシュボード、Panelアプリです。

<Aside type="note">
最近使用した順に表示されるのは、プロジェクト、ダッシュボード、Panelアプリのみです。ワークフロー、テーブル、ディメンション、データエディター、ドキュメントは通常、その方法で一覧表示するには数が多すぎます。繰り返し使うものはピン留めして表示させると、**ピン留め**レーンで待機します。
</Aside>

## プロジェクトのタイル

プロジェクトのタイルには、プロジェクトの概要が表示されます。

| 統計 | 意味 |
|---|---|
| **ワークフローの実行** | 最近の期間に完了したワークフローの実行数 |
| **最終実行** | 直近の実行が完了した日時 |
| **ワークフロー** | プロジェクトに含まれるワークフロー数 |
| **テーブル** | プロジェクトに含まれるテーブル数 |
| **レコード** | それらのテーブル全体の合計行数（`~` は推定値を示します） |

実行履歴のないプロジェクトでは、実行の数値の代わりに**最終編集**が表示されます。件数がゼロの場合は、その項目自体が表示されません。

### タイル画像

各プロジェクトのタイルには、薄く表示された背景画像があります。デフォルトではPlaidCloudのファンですが、顧客のロゴなど、作業をひと目で識別できるプロジェクト専用の画像を設定することもできます。これにより、多くのタイルが並ぶランチャーでも見つけやすくなります。

設定するには、次の手順を実行します。

1. プロジェクトを開き、**ホーム**タブに移動します。
2. 左側の列の下部にある**ランチャータイル画像**までスクロールします。
3. 画像を保管しているドキュメントアカウントを選択し、**参照**で画像ファイルを選択します。
4. デフォルトに戻すには、**クリア**を使用します。

画像は統計を読みやすくするために薄く表示されます。そのため、薄くしても見栄えのするものを選んでください。縦長の画像よりも、タイルの形に合う横長の画像が適しています。これを設定するには、プロジェクトの編集権限が必要です。読み取り専用の閲覧者には、選択項目が無効の状態で表示されます。

<Aside type="note">
プロジェクトを閲覧できる人は誰でもそのタイル画像を見ることができますが、画像が配信されるのは、その画像が保存されているドキュメントアカウントも読み取れる人だけです。そのアクセス権がない閲覧者には、デフォルトのファンが表示されます。
</Aside>

ダッシュボードのタイルは動作が異なります。ダッシュボード自体のサムネイルが自動的に生成されて表示されるため、選択するものはありません。

## 項目を開く

すべてのカードとリストの行には、主となる操作があり、必要に応じて追加の操作も用意されています。

| 項目 | 開く対象 | その他の操作 |
|---|---|---|
| プロジェクト | プロジェクト | |
| ワークフロー | ワークフロー | 実行、最新の実行を開く、ライブの**実行中**ステータス |
| テーブル | テーブル | テーブルエクスプローラーで開く |
| ディメンション | その階層エディター | |
| データエディター | そのプロジェクト | |
| ダッシュボード | ダッシュボード | 新しいタブで開く |
| Panelアプリ | アプリ | 新しいタブで開く |
| Dashアプリ | アプリ | 新しいタブで開く |
| ドキュメント | ファイルまたはフォルダー | |

実行中のワークフローには、自動的に更新されるライブのステータスインジケーターが表示されます。更新する必要はありません。

## ピン留め（お気に入り）

ランチャーのカードまたはリストの行で**スター**をクリックすると、ピン留めされます。ピン留めした項目は、最近いつ使ったかに関係なく常に**ピン留め**レーンに表示されるため、大切なものがスクロールで見えなくなることはありません。

ランチャーを先に開かなくても、普段作業している場所からピン留めすることもできます。スターの列を探してください。

- **プロジェクト、ワークフロー、テーブル、ディメンション、データエディター** — プロジェクト内にある、それぞれのリストのスター列です。
- **ダッシュボード**、**Panelアプリ**、**Dashアプリ** — マイダッシュボードとマイPanelアプリのスター列です。
- **ドキュメント** — ドキュメントブラウザーでファイル*または*フォルダーを右クリックし、**ランチャーにピン留め**を選択します。

点灯しているスターをどこでもクリックすると、ピン留めが解除されます。どこで行ったピン留めも、ランチャーにすぐに反映されます。

## タイルまたはリスト

ツールバーの**タイル / リスト**トグルで、ゆとりのあるカード表示と、1行ずつの高密度なリスト表示を切り替えます。選択した内容は記憶され、切り替えは即座に行われます。すでに読み込まれたデータを再描画するだけで、再取得は行われません。

## 種類による絞り込み

ツールバーの左側にあるチップの行には、種類ごとに専用のアイコンが付いたチップがあります。**プロジェクト**、**ダッシュボード**、**Panelアプリ**、**ワークフロー**、**テーブル**、**ディメンション**、**データエディター**、**ドキュメント**です。チップが押された状態は、その種類が表示されていることを意味します。クリックすると、その種類が**最近使用**レーンと**ピン留め**レーンから非表示になります。絞り込みの設定は、次回以降も記憶されます。

**要対応**レーンは絞り込みの対象にはなりません。失敗したワークフローは、その種類のチップがオフになっていても、常に表示されます。

## 検索とコマンド

任意の画面で **Ctrl/Cmd-K** を押すか、ランチャーのツールバーで**検索**をクリックすると、コマンドパレットが開きます。例外は転記レジスターで、独自のパレットのために **Ctrl/Cmd-K** を使用します。

入力する前に、次の2つが一覧表示されます。

- **アクション** — ここから実行できるコマンドです。ホーム、プロジェクト、ダッシュボード、ドキュメントへの移動、ライトとダークの外観の切り替え、AIの接続、ヘルプの表示などがあります。**移動**アクションは、ワークスペースにあるアプリに対してのみ表示されます。
- **最近使用** — 最後に開いた8件が、新しい順に表示されます。ランチャーまたはパレットから開いたプロジェクト、ワークフロー、テーブル、ディメンション、データエディター、ダッシュボード、Panelアプリ、ドキュメントと、どこからでも開いたすべてのプロジェクトが対象です。プロジェクトの内部（たとえばワークフローやディメンション）から開いたものは追加されません。このリストはブラウザーに保存されるため、デバイス間では共有されません。また、ランチャーの**最近使用**レーン（[レーン](#レーン)を参照）とは別のものです。

入力を始めると、両方のリストが同時に絞り込まれます。入力した文字は順番に現れるだけでよいため、`proj` と入力すると**プロジェクトへ移動**が見つかります。最も近い一致が先頭に表示されます。2文字以上入力すると、パレットはプロジェクト、ワークフロー、テーブル、ダッシュボード、Panelアプリも横断して検索し、それらの結果を種類ごとにグループ化して下に追加します。各結果には、ボード上と同じ「開く」操作とピン留め用のスターが付きます。**最近使用**にすでに表示されている結果は、重複して表示されません。

- **上 / 下**キーで選択を移動します。
- **Enter** キーで、選択したアクションを実行するか、選択した項目を開きます。
- **Escape** キーでパレットを閉じます。

ディメンション、データエディター、ドキュメントは検索できません。これらには、ピン留めするか、ランチャーから一度開いたあとの**最近使用**から、または所属するプロジェクトからアクセスします。

結果をクリックするとその項目が開きます。**スター**をクリックするとパレットを開いたままピン留めされるため、1回の操作で複数の項目をピン留めできます。

## 更新

ランチャーは、戻ってきたときにデータが古くなっていれば、自動的に更新されます。最新の状態をすぐに取得するには、ツールバーの**更新**をクリックします。

## 別の場所から開始する

PlaidCloudは、デフォルトでランチャーで開きます。代わりに別のアプリで開始するには、オプションメニューで**ランチャーで開始**をオフにします。

## 外観（ライト、ダーク、自動）

上部のツールバーにある**外観**ボタン（アカウントメニューの横にあるコントラストのアイコン）で、PlaidCloudのライトとダークの外観を切り替えます。この設定は、ランチャー、すべてのアプリ、その中のすべてのウィンドウとダイアログに適用されます。

| 選択肢 | 動作 |
| --- | --- |
| **ライト** | デバイスの設定に関係なく、常にライトの外観を使用します。 |
| **ダーク** | デバイスの設定に関係なく、常にダークの外観を使用します。 |
| **自動（システム）** | オペレーティングシステムの外観設定に従います。 |

**自動（システム）**がデフォルトで、システムの設定にリアルタイムで追従します。たとえば、コンピューターが夕方にダークへ切り替わる設定の場合、PlaidCloudも同時に切り替わります。再読み込みは不要です。**ライト**または**ダーク**を選択すると外観が固定され、以降はシステムの設定が無視されます。

<Aside type="note">
選択内容は、選択したブラウザーに記憶されるため、別のブラウザーや別のコンピューターには引き継がれません。それぞれで一度設定してください。ブラウザーのサイトデータを消去すると、**自動**にリセットされます。ブラウザーがローカルストレージをブロックしている場合（一部のプライベートブラウジングモードなど）、切り替えはそのセッション中は機能しますが、次回は再び**自動**から始まります。
</Aside>

埋め込みコンテンツは独自の色を保持します。ダッシュボードとPanelアプリのスタイルは、この設定によって変更されません。
