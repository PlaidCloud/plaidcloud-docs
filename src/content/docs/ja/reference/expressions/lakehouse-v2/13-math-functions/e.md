数学定数 e（ネイピア数）を返します。

## Analyzeの構文

```python
func.e()
```

## Analyzeの例

```python
func.e()

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```

## SQLの構文

```sql
E()
```

## SQLの例

```sql
SELECT E();

┌───────────────────┐
│ 2.718281828459045  │
└───────────────────┘
```
