数学定数の円周率を返します。

## Analyzeの構文

```python
func.pi()
```

## Analyzeの例

```python
func.pi()

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```

## SQLの構文

```sql
PI()
```

## SQLの例

```sql
SELECT PI();

┌───────────────────┐
│ 3.141592653589793  │
└───────────────────┘
```
