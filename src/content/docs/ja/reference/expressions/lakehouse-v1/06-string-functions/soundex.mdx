文字列の Soundex コードを生成します。

- Soundex コードは、1文字のアルファベットと3桁の数字で構成されます。PlaidCloud Lakehouse の実装では4桁を超える数字が返されますが、結果に [SUBSTR](../substr) を適用すると標準的な Soundex コードを取得できます。
- 文字列内のアルファベット以外の文字はすべて無視されます。
- A-Z の範囲外にある各国語のアルファベット文字は、先頭の文字である場合を除いてすべて無視されます。


<Aside>Soundex とは何でしょうか。Soundex は、英語で発音したときの響きに基づいて、英数字の文字列を4文字のコードに変換します。詳細については、https://en.wikipedia.org/wiki/Soundex を参照してください。</Aside>

関連項目: [SOUNDS LIKE](../soundslike)

## Analyze の構文

```python
func.soundex(<str>)
```

## Analyze の例

```python
func.soundex('PlaidCloud Lakehouse')
┌──────────────────────────────────────┐
│ func.soundex('PlaidCloud Lakehouse') │
├──────────────────────────────────────┤
│ D153                                 │
└──────────────────────────────────────┘
```

## SQL構文

```sql
SOUNDEX(<str>)
```

## 引数

| 引数 | 説明 |
|-----------|-------------|
| str  | 文字列。 |

## 戻り値の型

VARCHAR 型のコード、または NULL 値を返します。

## SQLの例

```sql
SELECT SOUNDEX('PlaidCloud Lakehouse');

---
D153

-- All non-alphabetic characters in the string are ignored.
SELECT SOUNDEX('PlaidCloud Lakehouse!');

---
D153

-- All international alphabetic characters outside the A-Z range are ignored unless they're the first letter.
SELECT SOUNDEX('PlaidCloud Lakehouse，你好');

---
D153

SELECT SOUNDEX('你好，PlaidCloud Lakehouse');

---
你3153

-- SUBSTR the result to get a standard Soundex code.
SELECT SOUNDEX('databend cloud'),SUBSTR(SOUNDEX('databend cloud'),1,4);

soundex('databend cloud')|substring(soundex('databend cloud') from 1 for 4)|
-------------------------+-------------------------------------------------+
D153243                  |D153                                             |

SELECT SOUNDEX(NULL);
┌─────────────────────────────────────┐
│ `SOUNDEX(NULL)`                     │
├─────────────────────────────────────┤
│ <null>                              │
└─────────────────────────────────────┘
```
