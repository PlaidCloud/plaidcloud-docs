2つの文字列の発音を、Soundex コードによって比較します。Soundex は、文字列の発音を表すコードを生成する音声アルゴリズムで、綴りではなく発音に基づいて文字列をあいまい一致させることができます。PlaidCloud Lakehouse には、文字列から Soundex コードを取得できる [SOUNDEX](../soundex) 関数があります。

SOUNDS LIKE は、名前や住所などをあいまい一致で絞り込むために、SQL クエリの WHERE 句でよく使われます。[例](#行のフィルタリング)の[行のフィルタリング](#sqlの例)を参照してください。

<Aside>この関数はあいまいな文字列一致に役立ちますが、常に正確であるとは限らないことに注意してください。Soundex アルゴリズムは英語の発音規則に基づいているため、他の言語や方言の文字列ではうまく機能しない場合があります。</Aside>

## Analyze の構文

```python
func.sounds_like(<str1>, <str2>)
```

## Analyze の例

```python
func..sounds_like('Monday', 'Sunday')
┌───────────────────────────────────────┐
│ func..sounds_like('Monday', 'Sunday') │
├───────────────────────────────────────┤
│                                     0 │
└───────────────────────────────────────┘
```

## SQL構文

```sql
<str1> SOUNDS LIKE <str2>
```

## 引数

| 引数 | 説明 |
|-----------|-------------|
| str1, 2   | 比較する文字列。 |

## 戻り値の型

2つの文字列の Soundex コードが同じ場合（つまり発音が似ている場合）は Boolean 値の 1 を、それ以外の場合は 0 を返します。

## SQLの例

### 文字列の比較

```sql
SELECT 'two' SOUNDS LIKE 'too'
----
1

SELECT CONCAT('A', 'B') SOUNDS LIKE 'AB';
----
1

SELECT 'Monday' SOUNDS LIKE 'Sunday';
----
0
```

### 行のフィルタリング

```sql
SELECT * FROM  employees;

id|first_name|last_name|age|

SELECT * FROM  employees
```
