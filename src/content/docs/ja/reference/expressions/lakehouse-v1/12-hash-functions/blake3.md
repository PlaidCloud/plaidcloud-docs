文字列のBLAKE3 256ビットチェックサムを計算します。値は64桁の16進数の文字列として返されます。引数がNULLの場合はNULLが返されます。

## Analyzeの構文

```python
func.blake3(<expr>)
```

## Analyzeの例

```python
func.blake3('1234567890')

┌──────────────────────────────────────────────────────────────────┐
│ func.blake3('1234567890')                                        │
├──────────────────────────────────────────────────────────────────┤
│ d12e417e04494572b561ba2c12c3d7f9e5107c4747e27b9a8a54f8480c63e841 │
└──────────────────────────────────────────────────────────────────┘
```

## SQLの構文

```sql
BLAKE3(<expr>)
```

## SQLの例

```sql
SELECT BLAKE3('1234567890');

┌──────────────────────────────────────────────────────────────────┐
│                       blake3('1234567890')                       │
├──────────────────────────────────────────────────────────────────┤
│ d12e417e04494572b561ba2c12c3d7f9e5107c4747e27b9a8a54f8480c63e841 │
└──────────────────────────────────────────────────────────────────┘
```
