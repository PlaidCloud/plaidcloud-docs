SHA-2ファミリーのハッシュ関数（SHA-224、SHA-256、SHA-384、SHA-512）を計算します。ハッシュ長が許可された値のいずれでもない場合、戻り値はNULLです。それ以外の場合、関数の結果は、指定したビット数のハッシュ値を16進数の文字列で表したものになります。

## Analyzeの構文

```python
func.sha2(<expr>, <expr>)
```

## Analyzeの例

```python
func.sha2('1234567890', 0)

┌──────────────────────────────────────────────────────────────────┐
│ func.sha2('1234567890', 0))                                      │
├──────────────────────────────────────────────────────────────────┤
│ c775e7b757ede630cd0aa1113bd102661ab38829ca52a6422ab782862f268646 │
└──────────────────────────────────────────────────────────────────┘
```

## SQLの構文

```sql
SHA2(<expr>, <expr>)
```

## SQLの例

```sql
SELECT SHA2('1234567890', 0);

┌──────────────────────────────────────────────────────────────────┐
│                       sha2('1234567890', 0)                      │

```
