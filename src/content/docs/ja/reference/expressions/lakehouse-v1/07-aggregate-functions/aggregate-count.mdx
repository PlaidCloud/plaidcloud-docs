COUNT() 関数は、SELECT クエリが返すレコード数を返します。

<Aside type="caution">NULL 値はカウントされません。</Aside>

## Analyzeの構文

```python
func.count(<column>)
```

## Analyzeの例

```python
func.count(table.grade).alias('count_valid_grades')

| count_valid_grades |
|--------------------|
|          4         |
```

## SQLの構文

```sql
COUNT(<expr>)
```

## 引数

| 引数 | 説明 |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<expr>`  | 任意の式。 <br /> 列名、別の関数の結果、または数式を指定できます。<br />`*` も指定でき、純粋な行数のカウントを表します。 |

## 戻り値の型

整数。

## SQLの例

**テーブルの作成とサンプルデータの挿入**
```sql
CREATE TABLE students (
  id INT,
  name VARCHAR,
  age INT,
  grade FLOAT NULL
);

INSERT INTO students (id, name, age, grade)
VALUES (1, 'John', 21, 85),
       (2, 'Emma', 22, NULL),
       (3, 'Alice', 23, 90),
       (4, 'Michael', 21, 88),
       (5, 'Sophie', 22, 92);

```

**クエリのデモ: 有効な成績を持つ学生をカウントする**
```sql
SELECT COUNT(grade) AS count_valid_grades
FROM students;
```

**結果**
```sql
| count_valid_grades |
|--------------------|
|          4         |
```
