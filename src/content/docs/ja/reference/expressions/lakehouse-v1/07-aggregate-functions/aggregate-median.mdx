集計関数です。

MEDIAN() 関数は、数値データ列の中央値を計算します。

<Aside type="caution">NULL 値はカウントされません。</Aside>

## Analyzeの構文

```python
func.median(<expr>)
```

## Analyzeの例

```python
func.median(table.score).alias('median_score')

|  median_score  |
|----------------|
|      85.0      |
```

## SQLの構文

```sql
MEDIAN(<expr>)
```

## 引数

| 引数 | 説明              |
|-----------|--------------------------|                                                                                                                 
| `<expr>`  | 任意の数値式 |                                                                                                     

## 戻り値の型

その値の型。

## SQLの例

**テーブルの作成とサンプルデータの挿入**
```sql
CREATE TABLE exam_scores (
  id INT,
  student_id INT,
  score INT
);

INSERT INTO exam_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 90),
       (3, 3, 75),
       (4, 4, 95),
       (5, 5, 85);
```

**クエリのデモ: 試験の中央値を計算する**
```sql
SELECT MEDIAN(score) AS median_score
FROM exam_scores;
```

**結果**
```sql
|  median_score  |
|----------------|
|      85.0      |
```
