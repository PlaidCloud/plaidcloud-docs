[t-digest](https://github.com/tdunning/t-digest/blob/master/docs/t-digest-paper/histo.pdf)アルゴリズムを使用して、数値データ列の近似分位数を計算します。

<Aside type="caution">NULL 値は計算に含まれません。</Aside>

## Analyzeの構文

```python
func.quantile_tdigest(<levels>, <expr>)
```

## Analyzeの例

```python
func.quantile_tdigest([0.5, 0.8], table.sales_amount).alias('sales_amounts')

| sales_amounts         |
|-----------------------+
| [6000.0,7000.0]       |
```

## SQLの構文

```sql
QUANTILE_TDIGEST(<level1>[, <level2>, ...])(<expr>)
```

## 引数

| 引数   | 説明                                                                                                                                     |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `<level n>` | 分位数のレベルは、0 から 1 の定数の浮動小数点数で表します。レベル値は [0.01, 0.99] の範囲で指定することをお勧めします。   |
| `<expr>`    | 任意の数値式                                                                                                                        |

## 戻り値の型

指定した分位数のレベルの数に応じて、Float64 値または Float64 値の配列を返します。

## SQLの例

```sql
-- Create a table and insert sample data
CREATE TABLE sales_data (
  id INT,
  sales_person_id INT,
  sales_amount FLOAT
);

INSERT INTO sales_data (id, sales_person_id, sales_amount)
VALUES (1, 1, 5000),
       (2, 2, 5500),
       (3, 3, 6000),
       (4, 4, 6500),
       (5, 5, 7000);

SELECT QUANTILE_TDIGEST(0.5)(sales_amount) AS median_sales_amount
FROM sales_data;

median_sales_amount|
-------------------+
             6000.0|

SELECT QUANTILE_TDIGEST(0.5, 0.8)(sales_amount)
FROM sales_data;

quantile_tdigest(0.5, 0.8)(sales_amount)|
----------------------------------------+
[6000.0,7000.0]                         |
```
