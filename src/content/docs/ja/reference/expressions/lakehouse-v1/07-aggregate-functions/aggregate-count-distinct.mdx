集計関数です。

count(distinct ...) 関数は、値の集合に含まれる一意な値の数を計算します。

少ないメモリと時間で大規模なデータセットから推定値を得るには、[APPROX_COUNT_DISTINCT](../aggregate-approx-count-distinct)の使用を検討してください。

<Aside type="caution">NULL 値はカウントされません。</Aside>

## Analyzeの構文

```python
func.count_distinct(<column>)
```

## Analyzeの例

```python
func.count_distinct(table.category).alias('unique_categories')

| unique_categories |
|-------------------|
|         2         |
```

## SQLの構文

```sql
COUNT(distinct <expr> ...)
UNIQ(<expr>)
```

## 引数

| 引数 | 説明 |
|-----------|--------------------------------------------------|
| `<expr>`  | 任意の式。引数の数は [1, 32] です |

## 戻り値の型

UInt64

## SQLの例

**テーブルの作成とサンプルデータの挿入**
```sql
CREATE TABLE products (
  id INT,
  name VARCHAR,
  category VARCHAR,
  price FLOAT
);

INSERT INTO products (id, name, category, price)
VALUES (1, 'Laptop', 'Electronics', 1000),
       (2, 'Smartphone', 'Electronics', 800),
       (3, 'Tablet', 'Electronics', 600),
       (4, 'Chair', 'Furniture', 150),
       (5, 'Table', 'Furniture', 300);
```

**クエリのデモ: 一意なカテゴリーの数をカウントする**

```sql
SELECT COUNT(DISTINCT category) AS unique_categories
FROM products;
```

**結果**
```sql
| unique_categories |
|-------------------|
|         2         |
```
