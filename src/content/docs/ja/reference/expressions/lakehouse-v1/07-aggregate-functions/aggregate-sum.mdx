集計関数です。

SUM() 関数は、値の集合の合計を計算します。

<Aside type="caution">NULL 値はカウントされません。</Aside>


## Analyzeの構文

```python
func.sum(<column>)
```

## Analyzeの例

```python
func.sum(table.quantity).alias('total_quantity_sold')

| total_quantity_sold |
|---------------------|
|         41          |
```

## SQLの構文

```sql
SUM(<expr>)
```

## 引数

| 引数 | 説明              |
|-----------|--------------------------|
| `<expr>`  | 任意の数値式 |

## 戻り値の型

入力の型が double の場合は double、それ以外の場合は整数。

## SQLの例

**テーブルの作成とサンプルデータの挿入**
```sql
CREATE TABLE sales_data (
  id INT,
  product_id INT,
  quantity INT
);

INSERT INTO sales_data (id, product_id, quantity)
VALUES (1, 1, 10),
       (2, 2, 5),
       (3, 3, 8),
       (4, 4, 3),
       (5, 5, 15);
```

**クエリのデモ: 販売した製品の合計数量を計算する**
```sql
SELECT SUM(quantity) AS total_quantity_sold
FROM sales_data;
```

**結果**
```sql
| total_quantity_sold |
|---------------------|
|         41          |
```
