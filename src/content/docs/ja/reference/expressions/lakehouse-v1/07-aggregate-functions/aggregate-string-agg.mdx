集計関数です。

STRING_AGG() 関数は、列の NULL ではないすべての値を String に変換し、区切り文字で区切って連結します。

## Analyzeの構文

```python
func.string_agg(<expr> [, delimiter])
```

## Analyzeの例

```python
func.string_agg(table.language_name).alias('concatenated_languages')

|          concatenated_languages         |
|-----------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```

## SQLの構文

```sql
STRING_AGG(<expr>)
STRING_AGG(<expr> [, delimiter])
```

<Aside>`<expr>` が文字列式でない場合は、`::VARCHAR` を使用して変換してください。例: ```sql SELECT string_agg(number::VARCHAR, '|') AS s FROM numbers(5); ┌───────────┐ │ s │ ├───────────┤ │ 0│1│2│3│4 │ └───────────┘ ```</Aside>

## 引数

| 引数   | 説明                                                         |
|-------------|---------------------------------------------------------------------|
| `<expr>`    | 任意の文字列式（文字列でない場合は `::VARCHAR` を使用して変換） |
| `delimiter` | オプションの定数 String。指定しない場合は空の String を使用します        |

## 戻り値の型

String 型

## SQLの例

**テーブルの作成とサンプルデータの挿入**

```sql
CREATE TABLE programming_languages (
  id INT,
  language_name VARCHAR
);

INSERT INTO programming_languages (id, language_name)
VALUES (1, 'Python'),
       (2, 'JavaScript'),
       (3, 'Java'),
       (4, 'C#'),
       (5, 'Ruby');
```

**クエリのデモ: プログラミング言語名を区切り文字で連結する**
```sql
SELECT STRING_AGG(language_name, ', ') AS concatenated_languages
FROM programming_languages;
```

**結果**
```sql
|          concatenated_languages         |
|------------------------------------------|
| Python, JavaScript, Java, C#, Ruby      |
```
