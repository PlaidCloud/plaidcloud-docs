集計関数です。

STDDEV_POP() 関数は、式の母標準偏差（VAR_POP() の平方根）を返します。

<Aside>STD() または STDDEV() も使用できます。これらは同等ですが、標準 SQL ではありません。</Aside>

<Aside type="caution">NULL 値はカウントされません。</Aside>

## Analyzeの構文

```python
func.stddev_pop(<expr>)
```

## Analyzeの例

```python
func.stddev_pop(table.score).alias('test_score_stddev_pop')

| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```

## SQLの構文

```sql
STDDEV_POP(<expr>)
STDDEV(<expr>)
STD(<expr>)
```

## 引数

| 引数 | 説明              |
|-----------|--------------------------|
| `<expr>`  | 任意の数値式 |

## 戻り値の型

double

## SQLの例

**テーブルの作成とサンプルデータの挿入**
```sql
CREATE TABLE test_scores (
  id INT,
  student_id INT,
  score FLOAT
);

INSERT INTO test_scores (id, student_id, score)
VALUES (1, 1, 80),
       (2, 2, 85),
       (3, 3, 90),
       (4, 4, 95),
       (5, 5, 100);
```

**クエリのデモ: テスト成績の母標準偏差を計算する**
```sql
SELECT STDDEV_POP(score) AS test_score_stddev_pop
FROM test_scores;
```

**結果**
```sql
| test_score_stddev_pop |
|-----------------------|
|        7.07107        |
```
