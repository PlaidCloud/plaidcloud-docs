集計関数です。

`QUANTILE_DISC()` 関数は、数値データ列の正確な分位数を計算します。
`QUANTILE` は `QUANTILE_DISC` のエイリアスです。

<Aside type="caution">NULL 値はカウントされません。</Aside>

## Analyzeの構文

```python
func.quantile_disc(<levels>, <expr>)
```

## Analyzeの例

```python
func.quantile_disc([0.25, 0.75], table.salary).alias('salary_quantiles')

|  salary_quantiles   |
|---------------------|
| [55000.0, 65000.0]  |
```

## SQLの構文

```sql
QUANTILE_DISC(<levels>)(<expr>)
    
QUANTILE_DISC(level1, level2, ...)(<expr>)
```

## 引数

| 引数  | 説明                                                                                                                                   |
|------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| `level(s)` | 分位数のレベル。各レベルは 0 から 1 の定数の浮動小数点数です。レベル値は [0.01, 0.99] の範囲で指定することをお勧めします。 |
| `<expr>`   | 任意の数値式                                                                                                                      |

## 戻り値の型

レベルの数に応じて、InputType または InputType の配列。

## SQLの例

**テーブルの作成とサンプルデータの挿入**
```sql
CREATE TABLE salary_data (
  id INT,
  employee_id INT,
  salary FLOAT
);

INSERT INTO salary_data (id, employee_id, salary)
VALUES (1, 1, 50000),
       (2, 2, 55000),
       (3, 3, 60000),
       (4, 4, 65000),
       (5, 5, 70000);
```

**クエリのデモ: 給与の第 25 パーセンタイルと第 75 パーセンタイルを計算する**
```sql
SELECT QUANTILE_DISC(0.25, 0.75)(salary) AS salary_quantiles
FROM salary_data;
```

**結果**
```sql
|  salary_quantiles   |
|---------------------|
| [55000.0, 65000.0]  |
```
