入力のH3インデックスを囲むk-ringの六角形の[H3](https://eng.uber.com/h3/)インデックスを含む配列を返します。この配列の各要素はH3インデックスです。

## Analyze Syntax

```python
func.h3_k_ring(h3, k)
```

## Analyze Examples

```python
func.h3_k_ring(644325524701193974, 1)

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                                  func.h3_k_ring(644325524701193974, 1)                                                 │
├────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ [644325524701193974,644325524701193899,644325524701193869,644325524701193970,644325524701193968,644325524701193972,644325524701193897] │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## SQL Syntax

```sql
H3_K_RING(h3, k)
```
