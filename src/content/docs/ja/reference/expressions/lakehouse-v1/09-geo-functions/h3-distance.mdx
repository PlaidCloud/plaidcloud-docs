指定した2つの[H3](https://eng.uber.com/h3/)インデックス間のグリッド距離を返します。

<Aside>H3の距離計算では、隣接する六角形どうしの距離しか計算できません。隣接していない六角形に使用すると、エラーになります。</Aside>

### Analyze Syntax

```python
func.h3_distance(h3, a_h3)
```

## Analyze Examples

```python
func.h3_distance(599119489002373119, 599119491149856767)

┌──────────────────────────────────────────────────────────┐
│ func.h3_distance(599119489002373119, 599119491149856767) │
├──────────────────────────────────────────────────────────┤
│                                                        1 │
└──────────────────────────────────────────────────────────┘
```

## SQL Syntax

```sql
H3_DISTANCE(h3, a_h3)
```
