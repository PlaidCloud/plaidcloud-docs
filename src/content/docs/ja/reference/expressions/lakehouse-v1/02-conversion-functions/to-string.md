値を文字列データ型に変換します。または、日付の値を特定の文字列形式に変換します。PlaidCloud Lakehouseで日付と時刻の形式をカスタマイズするには、指定子を使用できます。指定子を使用すると、日付と時刻の値に必要な形式を定義できます。サポートされている指定子の一覧については、日付と時刻の書式設定を参照してください。

## Analyzeの構文

```python
func.to_string( '<expr>' )
```

## Analyzeの例

```python
func.date_format('1.23'), func.to_string('1.23'), func.to_text('1.23'), func.to_varchar('1.23'), func.json_to_string('1.23')

┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ func.date_format('1.23') │ func.to_string('1.23') │ func.to_text('1.23') │ func.to_varchar('1.23') │ func.json_to_string('1.23') │
├──────────────────────────┼────────────────────────┼──────────────────────┼─────────────────────────┼─────────────────────────────┤
│ 1.23                     │ 1.23                   │ 1.23                 │ 1.23                    │ 1.23                        │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘ 
```

## SQLの構文

```sql
TO_STRING( '<expr>' )

TO_STRING( '<date>', '<format>' )
```

## 戻り値の型

文字列です。

## SQLの例

```sql

  DATE_FORMAT('1.23'),
  TO_STRING('1.23'),
  TO_TEXT('1.23'),
  TO_VARCHAR('1.23'),
  JSON_TO_STRING('1.23');
```
