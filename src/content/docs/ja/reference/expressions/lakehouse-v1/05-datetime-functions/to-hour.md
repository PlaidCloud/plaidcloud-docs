日時（タイムスタンプ/datetime）を、24 時間制の時（0～23）を表す UInt8 の数値に変換します。
この関数は、時計を進める場合は午前 2 時に 1 時間進め、時計を戻す場合は午前 3 時に 1 時間戻すものとして扱います（これは常に正しいとは限りません。モスクワでも、時計は異なる時刻に 2 回変更されました）。


## Analyze 構文

```python
func.to_hour(<expr>)
```

## Analyze の例

```python
func.to_hour('2023-11-12 09:38:18.165575')

┌────────────────────────────────────────────────────┐
│ func.to_hour('2023-11-12 09:38:18.165575')         │
│                     UInt8                          │
├────────────────────────────────────────────────────┤
│                                                  9 │
└────────────────────────────────────────────────────┘
```

## SQL 構文

```sql
TO_HOUR(<expr>)
```

## 引数

| 引数 | 説明 |
|-----------|-------------|
| `<expr>`  | タイムスタンプ   |

## 戻り値の型

`TINYINT`

## SQL の例

```sql

    to_hour('2023-11-12 09:38:18.165575')
```
