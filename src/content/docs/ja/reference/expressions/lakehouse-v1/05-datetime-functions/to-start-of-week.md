日付または日時（timestamp/datetime）から、その週の初日を返します。
週の初日は日曜日または月曜日で、引数 `mode` で指定します。

## Analyze の構文

```python
func.to_start_of_week(<expr>)
```

## Analyze の例

```python
func.to_start_of_week('2023-11-12 09:38:18.165575')

┌────────────────────────────────────────────────────────────────┐
│ func.to_start_of_week('2023-11-12 09:38:18.165575')            │
│                          Date                                  │
├────────────────────────────────────────────────────────────────┤
│ 2023-11-12                                                     │
└────────────────────────────────────────────────────────────────┘
```

## SQL構文

```sql
TO_START_OF_WEEK(<expr> [, mode])
```

## 引数

| 引数 | 説明                                                                                         |
|-----------|-----------------------------------------------------------------------------------------------------|
| `<expr>`  | 日付/タイムスタンプ                                                                                      |
| `[mode]`  | 省略可能。0の場合は日曜日、それ以外の場合は月曜日を返します。デフォルト値は0です |

## 戻り値の型

`DATE`。「YYYY-MM-DD」形式の日付を返します。

## SQLの例

```sql
SELECT
  to_start_of_week('2023-11-12 09:38:18.165575')

┌────────────────────────────────────────────────┐
│ to_start_of_week('2023-11-12 09:38:18.165575') │
│                      Date                      │
├────────────────────────────────────────────────┤
│ 2023-11-12                                     │
└────────────────────────────────────────────────┘
```
