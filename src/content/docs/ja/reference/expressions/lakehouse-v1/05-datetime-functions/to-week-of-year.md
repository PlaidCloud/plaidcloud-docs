指定した日付が年の何週目にあたるかを計算します。

ISO週番号は次のように決まります。1月4日は常に第1週に含まれます。1月1日が木曜日の場合は、12月29日（月曜日）から1月4日（日曜日）までの週がISO第1週になります。1月1日が金曜日の場合は、1月4日（月曜日）から1月10日（日曜日）までの週がISO第1週になります。

## Analyze の構文

```python
func.to_week_of_year(<expr>)
```

## Analyze の例

```python
func.now(), func.to_week_of_year(func.now()), func.week(func.now()), func.weekofyear(func.now())

┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│       func.now()           │ func.to_week_of_year(func.now()) │ func.week(func.now()) │ func.weekofyear(func.now()) │
├────────────────────────────┼──────────────────────────────────┼───────────────────────┼─────────────────────────────┤
│ 2024-03-14 23:30:04.011624 │                               11 │                    11 │                          11 │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## SQL構文

```sql
TO_WEEK_OF_YEAR(<expr>)
```

## 引数

| 引数 | 説明    |
|-----------|----------------|
| `<expr>`  | 日付/タイムスタンプ |

## エイリアス

- [WEEK](../week)
- [WEEKOFYEAR](../weekofyear)

## 戻り値の型

年内の週番号を表す整数を返します。番号は1から53の範囲です。

## SQLの例

```sql
SELECT NOW(), TO_WEEK_OF_YEAR(NOW()), WEEK(NOW()), WEEKOFYEAR(NOW());

┌───────────────────────────────────────────────────────────────────────────────────────┐
│            now()           │ to_week_of_year(now()) │ week(now()) │ weekofyear(now()) │
├────────────────────────────┼────────────────────────┼─────────────┼───────────────────┤
│ 2024-03-14 23:30:04.011624 │                     11 │          11 │                11 │
└───────────────────────────────────────────────────────────────────────────────────────┘
```
