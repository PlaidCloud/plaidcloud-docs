- [Lakehouse v1の式](./lakehouse-v1/)：PlaidCloud Lakehouseの第1世代で、Databend SQLの関数に基づいています
- [Lakehouse v2の式](./lakehouse-v2/)：Apache Icebergのオープンテーブルフォーマットを採用した、PlaidCloud Lakehouseの第2世代で、StarRocks 4.1のSQL関数に基づいています

## 正式な構文の調べ方

PlaidCloud Lakehouseは、基盤となるエンジンのSQL関数ライブラリを使用しています。関数の引数、エッジケース、最新の動作の詳細については、ここに掲載しているPlaidCloud向けの例とあわせて、アップストリームのドキュメントを参照してください。

- **Lakehouse v1** → [Databend SQL関数リファレンス](https://docs.databend.com/sql/sql-functions/)
- **Lakehouse v2** → [StarRocks SQL関数リファレンス](https://docs.starrocks.io/docs/sql-reference/sql-functions/)（PlaidCloud Lakehouse v2はStarRocks 4.1に準拠しています）
