PlaidCloudはGitホストに接続し、ワークフローやPanelアプリがバージョン管理されたリポジトリから読み取れるようにします。データベースやドキュメントアカウントではなくソース管理に置かれている設定、スクリプト、テンプレートファイルを取得する場合に便利です。

## プロバイダー

- [PlaidCloud Git](/ja/reference/connectors/git/plaidcloud-git/) — ワークスペースに組み込まれたマネージドGitサービス。サーバーURLや資格情報の設定は不要です
- [GitHub](/ja/reference/connectors/git/github/)
- [GitLab](/ja/reference/connectors/git/gitlab/)
- [Bitbucket](/ja/reference/connectors/git/bitbucket/)
- [Azure Repos](/ja/reference/connectors/git/azure-repos/)
- [AWS CodeCommit](/ja/reference/connectors/git/codecommit/)
