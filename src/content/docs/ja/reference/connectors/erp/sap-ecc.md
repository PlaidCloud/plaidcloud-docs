1つの接続タイプで、SAP ECCとSAP S/4HANAの両方に対応します。どちらもアプリケーションサーバーに対するRemote Function Callで同じように接続するため、PlaidCloudはどの世代を使用しているかを尋ねません。**接続**画面で、**New → SAP ECC / S/4HANAインスタンス**を選択します。

[SAPワークフローステップ](/ja/reference/workflow-steps/sap/)はすべて、このタイプの接続に対して実行されます。SAPを検索して、テーブル、トランザクション、レポート、保存済みのSAPクエリを抽出するには、[SAP ECC / S/4HANAからのアドホック抽出](/ja/guides/connections/sap-adhoc-extract/)を参照してください。

## 上流のドキュメント

SAPはECCのドキュメントをすべて削除しており、現在は[S/4HANA](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE)のドキュメントのみを提供しています。PlaidCloudが使用するRFCインターフェースは、両方に共通です。

## 構成

次のフィールドは、接続の作成時または編集時に表示されます。

### アカウントの説明

| フィールド | タイプ | 説明 |
|---|---|---|
| アカウント名 | テキスト | この接続の表示名。ステップで接続を選択する場所に表示されます。必須。 |
| メモ | テキスト（複数行） | 接続に関する任意のメモ（接続先のシステムや担当者など）。 |

### SAP環境

| フィールド | タイプ | 説明 |
|---|---|---|
| クライアント | テキスト | SAPクライアント番号（例：`100`）。必須。 |
| 言語 | 選択 | 2文字のSAPコードで指定するログオン言語。デフォルトは`EN`です。必須。 |
| トレースレベル | 選択 | RFCトレースの詳細度（オフ、簡易、詳細、完全）。接続の問題を診断する場合以外は、オフのままにします。必須。 |
| 接続タイプ | ラジオ | 1つのアプリケーションサーバーに接続するには**単一の直接接続を使用**、メッセージサーバー経由で接続するには**負荷分散されたマルチシステム接続を使用**を選択します。以下のフィールドは、この選択に応じて有効になります。 |

**単一の直接接続を使用**を選択すると、次のフィールドが有効になります。

| フィールド | タイプ | 説明 |
|---|---|---|
| ホスト | テキスト | アプリケーションサーバーのホスト名またはIPアドレス。 |
| システム番号 | テキスト | 2桁のSAPシステム番号（例：`00`）。 |

**負荷分散されたマルチシステム接続を使用**を選択すると、次のフィールドが有効になります。

| フィールド | タイプ | 説明 |
|---|---|---|
| MSホスト | テキスト | メッセージサーバーのホスト名またはIPアドレス。 |
| MSサーバー | テキスト | メッセージサーバーのポートまたはサービス名。 |
| システムID | テキスト | 3文字のSAPシステムID（例：`PRD`）。 |
| グループ | テキスト | 負荷分散の対象とするログオングループ（例：`PUBLIC`）。 |

### 認証情報

| フィールド | タイプ | 説明 |
|---|---|---|
| ユーザー | テキスト | RFC呼び出しに使用するSAPログオンユーザー。必須。 |
| パスワード | パスワード | そのユーザーのパスワード。書き込み専用です。編集時に空白のままにすると、保存済みのパスワードが維持されます。 |

### 使用状況

| フィールド | タイプ | 説明 |
|---|---|---|
| 有効（アクセスを許可） | トグル | 接続を使用できるかどうか。削除せずに接続を一時停止するには、オフにします。 |
| 読み取り専用 | トグル | 接続を読み取り操作に制限します。 |

### セキュリティモデル

| フィールド | タイプ | 説明 |
|---|---|---|
| セキュリティモデル | 選択 | この接続を使用できるユーザー（非公開（所有者のみ）、特定のメンバーのみ、特定のセキュリティグループのみ、すべてのワークスペースメンバー）。 |

## 接続のテスト

接続ウィンドウの**接続をテスト**は、上記の詳細でログオンして結果を報告します。既存の接続を編集して設定を変更した場合は、テストの前にパスワードを再入力してください。保存済みのパスワードは、編集した値と一緒には送信されません。
