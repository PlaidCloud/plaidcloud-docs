S/4HANA専用のコネクタはありません。PlaidCloudは、同じRemote Function Callインターフェースを通じてSAP ECCとS/4HANAの両方に接続するため、1つの接続タイプを共有します。**接続**画面で、**New → SAP ECC / S/4HANAインスタンス**を選択します。

**[SAP ECCとS/4HANAのコネクタ →](/ja/reference/connectors/erp/sap-ecc/)** — 両世代に共通のすべての構成フィールド。

## 上流のドキュメント

[SAP S/4HANAのドキュメント](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE)を参照してください。
