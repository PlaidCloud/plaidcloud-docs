## カタログのドキュメント
[Apache Hiveのドキュメント](https://hive.apache.org/docs/latest/)。

## 設定

この接続の作成時または編集時に、次のフィールドが表示されます。必須かどうかは、有効にする認証オプションによって異なります。

### 識別情報

| フィールド | タイプ | 説明 |
|---|---|---|
| 名前 | テキスト | この接続の表示名。 |
| エイリアス | テキスト（複数行） | 接続に関する任意のエイリアスまたはメモ。 |
| 有効 | トグル | 接続を有効にするかどうか。削除せずに一時停止するには無効にします。 |
| DB読み取り専用 | トグル | 接続を読み取り専用の操作に制限します。 |
| アクセスタイプ | 選択 | この接続の読み取り専用、書き込み専用、読み取り/書き込みのいずれかのアクセスレベル。 |

### 接続

| フィールド | タイプ | 説明 |
|---|---|---|
| DBホスト | テキスト | データベースサーバーのホスト名またはIPアドレス。 |
| DBポート | 数値 | データベース接続のポート番号。 |
| DBカタログ | テキスト | 接続先のデータベース、カタログ、またはスキーマ。 |

### 認証

| フィールド | タイプ | 説明 |
|---|---|---|
| DBユーザー | テキスト | データベース認証用のユーザー名。 |
| SSOを使用 | トグル | ユーザー名/パスワードの代わりにシングルサインオンで認証します。 |
| DBパスワード | パスワード | データベース認証用のパスワード。 |

### SSL / TLS

| フィールド | タイプ | 説明 |
|---|---|---|
| SSLを使用 | トグル | SSL/TLSで接続を暗号化します。 |
| SSLモード | 選択 | SSL検証モード（例：disable、require、verify-ca、verify-full）。 |
| SSL認証クライアント証明書 | テキスト（複数行） | 相互TLS認証用のクライアント証明書（PEM）。 |
| SSL認証クライアントキー | テキスト（複数行） | 相互TLS認証用のクライアント秘密鍵（PEM）。 |
| SSL認証ルート証明書 | テキスト（複数行） | サーバー証明書を検証するためのルートCA証明書（PEM）。 |
| SSL認証証明書失効 | テキスト（複数行） | 環境で使用している場合の証明書失効リスト。 |

### SSHトンネル

| フィールド | タイプ | 説明 |
|---|---|---|
| SSHを使用 | トグル | SSHバスティオン経由で接続をトンネリングします。 |
| SSHホスト | テキスト | SSHバスティオンのホスト名。 |
| SSHポート | 数値 | SSHバスティオンのポート（デフォルトは22）。 |
| SSHユーザー | テキスト | SSHバスティオンのユーザー名。 |
| SSHパスワード | パスワード | SSHバスティオンのパスワード（パスワード認証を使用する場合）。 |
| SSH証明書を使用 | トグル | パスワードの代わりに秘密鍵でSSHバスティオンに認証します。 |
| SSH秘密鍵 | テキスト（複数行） | バスティオン認証用のSSH秘密鍵（PEM）。 |
| SSHホストキー | テキスト（複数行） | バスティオンのフィンガープリントを検証するための想定されるSSHホストキー。 |
