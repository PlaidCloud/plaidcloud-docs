PlaidCloudはチャットプラットフォームに接続し、ワークフローから、チームがすでに見ているチャンネルに通知、アラート、ステータス更新を直接送信できるようにします。多くの場合、[Notify via Slack](/ja/reference/workflow-steps/notifications/notify-via-slack/)ステップや[Notify via Microsoft Teams](/ja/reference/workflow-steps/notifications/notify-via-microsoft-teams/)ステップと組み合わせて使用します。

## プロバイダー

- [Slack](/ja/reference/connectors/collaboration/slack/)
- [Microsoft Teams](/ja/reference/connectors/collaboration/teams/)
- [Tableau](/ja/reference/connectors/collaboration/tableau/)
