独自のプロトコルや非RESTプロトコルを使用するクラウドベースのデータサービス向けのコネクターです。これらは、データベースやRESTのカテゴリーにはうまく当てはまりません。

## プロバイダー

- [Quandl](/ja/reference/connectors/cloud-services/quandl/) — 金融データおよび経済データ（NASDAQ Data Link）
