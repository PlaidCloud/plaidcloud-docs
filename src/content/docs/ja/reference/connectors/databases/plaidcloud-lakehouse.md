**PlaidCloud Lakehouse**は、すべてのPlaidCloudワークスペースに組み込まれている分析用データストアです。このコネクタは主に、あるワークスペースのレイクハウスから別のワークスペースへ読み込む場合や、マルチテナント環境でテナント間でデータを共有する場合に使用します。1つのワークスペース内では、このコネクタを使わなくても、プロジェクトのテーブルに直接アクセスできます。

## 上流のドキュメント
組み込みのPlaidCloud Lakehouseを使用するために必要な構成はごくわずかです。[サービスのドキュメント](https://docs.plaidcloud.com/docs/plaidcloud/analyze/dw/getting-started/)。

## 構成

次のフィールドは、この接続の作成時または編集時に表示されます。必須かどうかは、有効にする認証オプションによって異なります。

### 識別情報

| フィールド | タイプ | 説明 |
|---|---|---|
| 名前 | テキスト | この接続の表示名。 |
| エイリアス | テキスト（複数行） | 接続のエイリアスやメモ（任意）。 |
| 有効 | トグル | 接続が有効かどうか。削除せずに一時停止するには無効にします。 |
| DB読み取り専用 | トグル | 接続を読み取り専用の操作に制限します。 |
| アクセスタイプ | 選択 | この接続のアクセスレベル（読み取り専用、書き込み専用、読み取り/書き込み）。 |

### 接続

| フィールド | タイプ | 説明 |
|---|---|---|
| DBポート | 数値 | データベース接続のポート番号。 |
| DBカタログ | テキスト | 接続先のデータベース、カタログ、またはスキーマ。 |

### 認証

| フィールド | タイプ | 説明 |
|---|---|---|
| DBユーザー | テキスト | データベース認証用のユーザー名。 |
| SSOを使用 | トグル | ユーザー名とパスワードの代わりに、シングルサインオンで認証します。 |
| DBパスワード | パスワード | データベース認証用のパスワード。 |

### SSL / TLS

| フィールド | タイプ | 説明 |
|---|---|---|
| SSLを使用 | トグル | 接続をSSL/TLSで暗号化します。 |
| SSLモード | 選択 | SSL検証モード（例：disable、require、verify-ca、verify-full）。 |
| SSL認証クライアント証明書 | テキスト（複数行） | 相互TLS認証用のクライアント証明書（PEM）。 |
| SSL認証クライアントキー | テキスト（複数行） | 相互TLS認証用のクライアント秘密キー（PEM）。 |
| SSL認証ルート証明書 | テキスト（複数行） | サーバー証明書を検証するためのルートCA証明書（PEM）。 |
| SSL認証証明書失効リスト | テキスト（複数行） | 環境で使用している場合の証明書失効リスト。 |

### SSHトンネル

| フィールド | タイプ | 説明 |
|---|---|---|
| SSHを使用 | トグル | SSH踏み台サーバー経由で接続をトンネリングします。 |
| SSHホスト | テキスト | SSH踏み台サーバーのホスト名。 |
| SSHポート | 数値 | SSH踏み台サーバーのポート（デフォルトは22）。 |
| SSHユーザー | テキスト | SSH踏み台サーバーのユーザー名。 |
| SSHパスワード | パスワード | SSH踏み台サーバーのパスワード（パスワード認証を使用する場合）。 |
| SSH証明書を使用 | トグル | パスワードの代わりに秘密キーでSSH踏み台サーバーに認証します。 |
| SSH秘密キー | テキスト（複数行） | 踏み台サーバーの認証用のSSH秘密キー（PEM）。 |
| SSHホストキー | テキスト（複数行） | 踏み台サーバーのフィンガープリントを検証するための、想定されるSSHホストキー。 |
