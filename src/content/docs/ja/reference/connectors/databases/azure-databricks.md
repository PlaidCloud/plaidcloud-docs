**Azure Databricks**は、Apache Spark、Delta Lake、マネージドノートブック環境をMicrosoft Azure上で組み合わせたものです。このコネクターを使用すると、PlaidCloudのワークフローからDatabricksワークスペースのテーブルを読み書きできます。認証には個人用アクセストークンまたはサービスプリンシパルを使用します。ワークスペースURLとHTTPパスで、対象のSQLウェアハウスを指定します。

## 上流のドキュメント
[Azure Databricksのドキュメント](https://learn.microsoft.com/en-us/azure/databricks/)。

## 設定

これらの項目は、この接続を作成または編集するときに表示されます。必須かどうかは、有効にする認証オプションによって異なります。

### 識別情報

| 項目 | タイプ | 説明 |
|---|---|---|
| 名前 | テキスト | この接続の表示名。 |
| エイリアス | テキスト（複数行） | 接続に関する任意のエイリアスまたはメモ。 |
| 有効 | トグル | 接続が有効かどうか。削除せずに一時停止するには無効にします。 |
| データベース読み取り専用 | トグル | 接続を読み取り専用の操作に制限します。 |
| アクセスタイプ | 選択 | この接続の読み取り専用、書き込み専用、または読み書きのアクセスレベル。 |

### 接続

| 項目 | タイプ | 説明 |
|---|---|---|
| データベースホスト | テキスト | データベースサーバーのホスト名またはIPアドレス。 |
| データベースカタログ | テキスト | 接続先のデータベース、カタログ、またはスキーマ。 |
| データベーススキーマ | テキスト | データベース内のスキーマ名。 |

### 認証

| 項目 | タイプ | 説明 |
|---|---|---|
| データベースユーザー | テキスト | データベース認証のユーザー名。 |
| SSOを使用 | トグル | ユーザー名とパスワードの代わりに、シングルサインオンで認証します。 |
| データベースパスワード | パスワード | データベース認証のパスワード。 |

### SSL / TLS

| 項目 | タイプ | 説明 |
|---|---|---|
| SSLを使用 | トグル | 接続をSSL/TLSで暗号化します。 |
| SSLモード | 選択 | SSL検証モード（例：disable、require、verify-ca、verify-full）。 |
| SSL認証クライアント証明書 | テキスト（複数行） | 相互TLS認証用のクライアント証明書（PEM）。 |
| SSL認証クライアントキー | テキスト（複数行） | 相互TLS認証用のクライアント秘密キー（PEM）。 |
| SSL認証ルート証明書 | テキスト（複数行） | サーバー証明書を検証するためのルートCA証明書（PEM）。 |
| SSL認証証明書失効 | テキスト（複数行） | 環境で証明書失効リストを使用している場合の、そのリスト。 |

### SSHトンネル

| 項目 | タイプ | 説明 |
|---|---|---|
| SSHを使用 | トグル | SSH踏み台サーバー経由で接続をトンネリングします。 |
| SSHホスト | テキスト | SSH踏み台サーバーのホスト名。 |
| SSHポート | 数値 | SSH踏み台サーバーのポート（デフォルトは22）。 |
| SSHユーザー | テキスト | SSH踏み台サーバーのユーザー名。 |
| SSHパスワード | パスワード | パスワード認証を使用する場合の、SSH踏み台サーバーのパスワード。 |
| SSH証明書を使用 | トグル | パスワードの代わりに秘密キーでSSH踏み台サーバーに認証します。 |
| SSH秘密キー | テキスト（複数行） | 踏み台サーバーの認証用のSSH秘密キー（PEM）。 |
| SSHホストキー | テキスト（複数行） | 踏み台サーバーのフィンガープリントを検証するための、想定されるSSHホストキー。 |
