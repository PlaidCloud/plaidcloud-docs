## APIドキュメント
このコネクターのエンドポイントについては、[ベンダーのAPIリファレンス](https://docs.stripe.com/api)を参照してください。

## 設定

この接続の作成時または編集時に、次のフィールドが表示されます。必須かどうかは、有効にする認証オプションによって異なります。

### 識別情報

| フィールド | タイプ | 説明 |
|---|---|---|
| 名前 | テキスト | この接続の表示名。 |
| エイリアス | テキスト（複数行） | 接続に関する任意のエイリアスまたはメモ。 |
| 有効 | トグル | 接続を有効にするかどうか。削除せずに一時停止するには無効にします。 |

### その他

| フィールド | タイプ | 説明 |
|---|---|---|
| ホスト | テキスト | — |
| 認証タイプ | 選択 | — |
| SSL検証を有効化 | トグル | — |
| リダイレクトに従う | トグル | — |
| リダイレクトでHTTPメソッドを維持 | トグル | — |
| リダイレクトで認証を維持 | トグル | — |
| リダイレクトでRefererを削除 | トグル | — |
| 厳格なHTTP | トグル | — |
| URLをエンコード | トグル | URLエンドポイント。 |
| Cookie Jarを無効にする | トグル | — |
| サーバーの暗号スイート | トグル | — |
| 最大リダイレクト数 | 数値 | — |
| テスト用エンドポイント | テキスト | — |
| テスト用メソッド | 選択 | — |
