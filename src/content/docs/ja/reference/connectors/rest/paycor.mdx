## APIドキュメント
このコネクターのエンドポイントについては、[ベンダーのAPIリファレンス](https://developers.paycor.com/explore)を参照してください。

## Paycorのセットアップ
Paycor APIのアプリケーション登録と開始のプロセスは、他のRESTプロバイダーよりも少し手間がかかります。必ず、Paycorの[クイックスタートページ](https://developers.paycor.com/guides#quickStartLabel)に記載された手順を最後まで実施してください。

必ず控えておく必要がある主な値は次のとおりです。
 - アプリケーションのOAuthクライアントID
 - アプリケーションのOAuthクライアントシークレット
 - APImサブスクリプションキー
 - `current`アプリケーションバージョンのスコープキー

<Aside type="caution">アプリケーションを使用できるようにするため、必ず「アクティブ化」してください</Aside>

必要に応じて本番またはサンドボックスを選択し、次の場所でアクティブ化します。

| 環境 | アクティベーションフォームのURL |
|-------------|---------------------|
| サンドボックス | https://hcm-demo.paycor.com/AppActivation/ClientActivation |
| 本番 | https://hcm.paycor.com/AppActivation/ClientActivation |

<Aside type="danger">Paycorに複数の組織がある場合は、組織ごとに別々のログインが必要です。統合しないでください。REST アクセス用の組織固有のアプリケーションを作成するには、開発者ポータルで組織ごとに専用の固有のログインが必要です。</Aside>

## 設定

この接続の作成時または編集時に、次のフィールドが表示されます。

### 識別情報

| フィールド | タイプ | 説明 |
|---|---|---|
| 名前 | テキスト | この接続の表示名。 |
| エイリアス | テキスト（複数行） | 接続に関する任意のエイリアスまたはメモ。 |
| 有効 | トグル | 接続を有効にするかどうか。削除せずに一時停止するには無効にします。 |
| DB読み取り専用 | トグル | 接続を読み取り専用の操作に制限します。 |
| アクセスタイプ | 選択 | この接続の読み取り専用、書き込み専用、読み取り/書き込みのいずれかのアクセスレベル。 |

### 資格情報

[Paycorのセットアップ](#paycorのセットアップ)で控えた3つの値を入力します。ホストやトークンURLを入力する必要はありません。PaycorのAPIホストとOAuth2トークンエンドポイントはPlaidCloudが提供します。

| フィールド | タイプ | 説明 |
|---|---|---|
| OAuth2クライアントID | テキスト | Paycorアプリ登録のアプリケーションOAuthクライアントID。 |
| OAuth2クライアントシークレット | パスワード | アプリケーションOAuthクライアントシークレット。暗号化して保存されます。 |
| Paycorサブスクリプションキー | テキスト | Paycorアプリケーションの APIm サブスクリプションキー。 |

## 認証

PaycorはOAuth2の認可コードグラントを使用するため、資格情報の入力は前半にすぎません。PlaidCloudにデータの取得を許可する、Paycorでの1回限りのログインも完了する必要があります。

1. **資格情報を入力して保存します。** 上記の3つの値を入力し、接続を保存します。
2. **接続します。** **Paycorに接続**をクリックします。PlaidCloudが**Paycor認可ウィンドウ**を開きます。このボタンは、接続を保存すると使用できるようになります。
3. **ログインして承認します。** そのウィンドウでPaycorにサインインし、アクセスを承認します。Paycorからの戻り先はPlaidCloudとなり、接続に**リフレッシュトークン**が保存され、以降はそれを使用してアクセストークンが自動的に取得されます。

<Aside type="caution">PlaidCloudのポップアップを許可してください。認可ウィンドウがブロックされた場合は、PlaidCloudがその旨を通知します。ポップアップを許可して、もう一度**Paycorに接続**をクリックしてください。</Aside>

APIホスト（`apis.paycor.com`）とトークンエンドポイント（`https://apis.paycor.com/sts/v1/common/token`）はPlaidCloudが管理します。入力するURLフィールドはなく、編集する必要もありません。

### 期限切れの接続を再認可する

Paycorへのアクセスは失効することがあります。リフレッシュトークンが期限切れになるか取り消された場合や、Paycorアプリケーションが非アクティブ化された場合です。その場合、接続を使用するワークフローは認証できなくなり、失敗します。復旧するには、次の手順を行います。

1. Paycorアプリケーションがまだ**アクティブ化**されていることを確認します（[Paycorのセットアップ](#paycorのセットアップ)のアクティベーションURLを参照）。
2. 接続を開いて**Paycorに接続**をクリックし、Paycorの認可を再実行して、ログインして承認します。これで新しいリフレッシュトークンが発行され、接続が再開されます。

<Aside type="danger">Paycorの接続の確立と修復は、この接続フォームから行ってください。汎用のREST エディターやAPIを通じて基になる接続を編集すると、管理されているトークンURLが上書きされ、認証が機能しなくなる可能性があります。</Aside>
