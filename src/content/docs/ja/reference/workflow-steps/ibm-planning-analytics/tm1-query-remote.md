## 説明

[TM1: キューブのクエリ](/ja/reference/workflow-steps/ibm-planning-analytics/tm1-query/)のオンプレミス版です。TM1 キューブに対する保存済みの **ビュー** または **MDX** クエリを読み取り、必要に応じて POV（ポイントオブビュー）のスライスを指定してプロジェクトテーブルに書き込む、というまったく同じ読み取りを行います。クラウドから直接呼び出す代わりに、自社ネットワーク上のインストール済みの [PlaidLink エージェント](/ja/reference/cli/plaidlink/)経由でディスパッチされます。TM1 サーバーが自社ネットワーク内からしかアクセスできない場合は、TM1: キューブのクエリの代わりにこのステップを使用します。

このステップは、ステップメニューの **IBM TM1 / Planning Analytics** の下に表示されます。

## TM1: キューブのクエリとの違い

| | TM1: キューブのクエリ | TM1: キューブのクエリ（エージェント） |
|---|---|---|
| トランスポート | REST 経由でクラウド直接 | ネットワーク上の PlaidLink エージェントにディスパッチ |
| 設定フィールド | — | 同一で、必須の **エージェント** が加わります |
| キューブ/ビューの検出 | 接続先のデータベースからライブで検出 | 利用できません。名前を手入力します |
| 保存前のプレビュー | あり | 利用できません |

接続、データベース、ビュー/MDX の選択、POV スライス、ゼロ/空のセルを除外、行数の上限、期間ごとの増分抽出パターンなど、それ以外はすべて、[TM1: キューブのクエリ](/ja/reference/workflow-steps/ibm-planning-analytics/tm1-query/)のページに記載されているとおりに動作します。以下の相違点のみが、このステップに固有です。

## 設定

### ソースとターゲット

| フィールド | 必須 | 備考 |
|---|---|---|
| エージェント | はい | この読み取りのディスパッチ先となる PlaidLink エージェントです。そのビルドには TM1 ハンドラーが含まれている必要があります（下記の[要件](#要件)を参照）。 |
| TM1接続 | はい | 読み取りに使用する [TM1 接続](/ja/guides/connections/tm1/)です。接続の選択ボックスは、選択したエージェントによってフィルターされません。接続はエージェントと別に共有してください（下記を参照）。 |
| 環境 | はい | 接続の環境です。 |
| データベース | はい | クエリ対象の TM1 データベース（インスタンス）です。 |
| キューブ | はい | クエリ対象の TM1 キューブです。手入力します。このステップにはライブでの検出はありません。 |
| ターゲットテーブル | はい | 返されたセルセットを書き込むプロジェクトテーブルです。 |

### スライスとオプション

[TM1: キューブのクエリ](/ja/reference/workflow-steps/ibm-planning-analytics/tm1-query/#スライス)と同じフィールド（ソースモード（ビュー別/MDX別）、ビュー、MDX、POV（ポイントオブビュー）、ゼロ/空のセルを除外、行数の上限）です。いずれも検出ではなく手入力で、プレビューではなくステップの実行時に検証されます。

## エージェント経由の検出なし

TM1: キューブのクエリのキューブ、ビュー、ディメンションの選択ボックスは、ステップの編集中に接続先のサーバーにライブで問い合わせます。このステップには、そのようなライブでの検出はありません。エージェントに到達できるのは実行中のみで、ブラウザーでフォームを開いている間は到達できないためです。キューブ、ビュー、MDX は手入力で、認識されない名前は、黙って失敗するのではなく、明確なエラーとともに実行が失敗します。同じ理由で、**プレビュー** ボタンもありません。プレビューには TM1 への到達が必要ですが、それができるのはエージェントだけです。

## 要件

オンプレミスの TM1 サーバーを読み取るには、次のものが必要です。

- **インストール済みの PlaidLink エージェント。** TM1 サーバーにネットワーク経由でアクセスできるマシン上にあることが必要です。[PlaidLink のインストール](/ja/reference/cli/plaidlink/install/)を参照してください。
- **TM1 ハンドラーを含むそのエージェントのビルド。** PlaidCloud はディスパッチの前にエージェントが通知する機能を確認します。この機能が追加される前のビルドのエージェントは、リクエストに応答できません。**PlaidLink は自動更新されません**。既存のエージェントで TM1 に対応するには、手動で再ビルドまたは再インストールする必要があります。[PlaidLink のアップグレード](/ja/reference/cli/plaidlink/upgrade/)を参照してください。
- **そのエージェントと共有された TM1 接続。** すでに付与されているメンバー/グループのアクセス権に加えて必要です。接続の `Actions > Agents` リストから付与します。[セキュリティモデル](/ja/guides/connections/create-connection/#セキュリティモデル)を参照してください。
