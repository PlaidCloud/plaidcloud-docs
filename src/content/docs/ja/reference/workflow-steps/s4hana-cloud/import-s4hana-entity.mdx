## 説明

[S/4HANA Cloud接続](/ja/guides/connections/s4hana-cloud/)を使用して、SAP S/4HANA Cloud の 1 つのエンティティをプロジェクトテーブルにインポートします。接続、エンティティタイプ、必要なフィルターを選択するだけで、ステップが条件に一致するレコードを取得して書き込みます。OData クエリを自分で作成する必要はありません。

これは汎用の定型ステップで、1 つのステップタイプで 2 つのエンティティに対応します。期末レポート向けの集計済み `trial_balance` キューブと、転記済み取引の詳細を明細行レベルで取得する `journal_entry_items` です。

## 設定

| フィールド | 必須 | 備考 |
|---|---|---|
| S/4HANA接続 | はい | 読み取りに使用する S/4HANA Cloud 接続です。 |
| ターゲットテーブル | はい | 結果の書き込み先となるプロジェクトテーブルです。実行のたびに全体が上書きされます。 |
| エンティティタイプ | はい | 取得するエンティティです。デフォルトは `trial_balance` です。`trial_balance` または `journal_entry_items` のいずれかを指定します。 |
| フィルター | いいえ | リクエストの OData `$filter` に変換される範囲フィルターと等価フィルターです。各エンティティでは、S/4HANA がサーバー側で実際に評価できるフィールドにのみフィルターを使用できます。サポートされていないフィールドは、黙って無視されるのではなく拒否されます。 |

### エンティティとフィルター可能なフィールド

| エンティティタイプ | 取得内容 | OData サービス | フィルター可能なフィールド |
|---|---|---|---|
| `trial_balance` | 集計済みの期末総勘定元帳勘定科目残高 | `API_OPLACCTGDOCITEMCUBE_SRV` | `CompanyCode`、`GLAccount`、`CostCenter`、`ProfitCenter`、`FiscalYear`（範囲）、`FiscalPeriod`（範囲）、`Ledger` |
| `journal_entry_items` | 転記済みの仕訳明細行 | `API_JOURNALENTRYITEMBASIC_SRV` | `CompanyCode`、`GLAccount`、`CostCenter`、`ProfitCenter`、`PostingDate`（範囲）、`FiscalYear`（範囲）、`FiscalPeriod`（範囲）、`Ledger` |

<Aside type="note">
`PostingDate`、`FiscalYear`、`FiscalPeriod` は**範囲**フィルター（`ge`/`le` 形式の境界）を受け付けます。明細行レベルの詳細を無制限に取得すると非常に大規模になる可能性があるため、`journal_entry_items` の取得を絞り込む主な方法です。本番データに対して実行する前に、大規模なエンティティには少なくとも 1 つの境界を設定してください。
</Aside>

<Aside type="caution">
`CostCenter` と `ProfitCenter` は、Communication Scenario で公開されている場合にのみフィルターに使用できます。そのシナリオに含まれていないディメンションは、黙って無視されるのではなく、サポートされていないフィルターとして拒否されます。
</Aside>
