## 説明

**インポート: 区切り形式（位置指定）** ステップは、区切り形式のドキュメントのすべての列を位置で読み取り、`Column_1` から `Column_N` という名前のテキスト列として取り込み、ヘッダー行をスキップします。たとえば後続のステップでデータ行をヘッダーに昇格させる場合など、ヘッダーで列に名前を付けられないときに使用します。

## パラメーター

- **ドキュメント** — ファイルのドキュメントアカウントとパスです。`.gz` で終わるパスは展開されます。
- **区切り文字** — フィールドの区切り文字です。デフォルトはカンマです。
- **引用符文字** — デフォルトは二重引用符です。
- **レコード番号列** *（オプション）* — ファイル内の順序でレコードに番号を付ける列です。何も書き込まない場合は空白にします。
- **出力テーブル** — 行の書き込み先です。

ドキュメントが存在しなくてもエラーにはなりません。ステップは、パスを示す警告を出して完了し、空のテーブルを書き込みます。
