## 説明

PlaidCloud DocumentからApache ORCファイルをインポートします。ORCは、HiveとSparkが書き込む列指向のストレージ形式で、スキーマはファイルに含まれています。

ステップのフォームには3つのタブがあります。

- **インポートパラメーター** — **ソースファイル**（ドキュメントアカウントと、ファイルまたはフォルダーのパス）と**ターゲットテーブル**に加えて、**非ASCII文字を削除**（`ascii_only`）、**インポート後にファイルを削除**（`delete_file`）、**ソースファイルが変更されていない場合は再インポートをスキップ**（`skip_if_unchanged`）を指定します。
- **テーブルデータの選択** — ソース列をターゲット列にマッピングし、**集計**と**重複排除**を指定します。**取り込み**は、ORCファイルに含まれるスキーマから、列とその型を読み取ります。
- **データフィルター** — 集計の前後で行をフィルターします。

ファイルが存在しない場合や空の場合、**取り込み**は警告にパスを示して*取り込む列がありません*と応答し、現在のマッピングはそのまま保持されます。

[移行されたProphecyプロジェクト](/ja/guides/workflows/migrate-prophecy-projects/)では、ORCデータセットにこのステップが使用されます。
