## 説明


Googleスプレッドシートの特定のワークシートを、PlaidCloudのプロジェクトテーブルにインポートします。ビジネスユーザーが管理しているドライバーテーブル、ルックアップ用のマッピング、手動の上書きなど、スプレッドシートにあるアドホックなデータに便利です。

Google接続を介して認証します。1つのスプレッドシートの複数のワークシートを、1つのステップでインポートできます。

## インポートパラメーター


![Googleスプレッドシートのインポート](/images/import_file_google_target.png)
### ソースとターゲット
#### Googleアカウント

Googleスプレッドシートのデータにアクセスするには、有効なGoogleユーザーアカウントが必要です。これにはツールでの設定が必要です。Googleアカウント接続の設定の詳細については、[PlaidCloud Tools – 接続](/ja/reference/connectors/)を参照してください。

必要なアカウントがすべて設定されたら、ドロップダウンリストから適切な**Googleアカウント**を選択します。
#### スプレッドシート

次に、指定した**Googleアカウント**に関連付けられているすべてのファイルを含むドロップダウンメニューから、インポート元の**スプレッドシート**を指定します。

<Aside>指定したユーザーアカウントが、特にファイルが別のユーザーの所有である場合に、指定したファイルにアクセスできることを確認してください。</Aside>

### ヘッダータイプ

Googleスプレッドシートにはヘッダーがある場合とない場合があるため、PlaidCloudでは、ヘッダーを使用する、ヘッダーを無視する、または列の順序で列の対応を決定する、のいずれかを選択できます。
* **ヘッダーなし**: ファイルにヘッダーが含まれていません。*データマッパー*のソースリストを使用して、列の対応を決定します。
* **ヘッダーあり - ヘッダーを使用してフィールドリストを上書き**: ファイルにヘッダーがあります。指定されたヘッダー名を使用し、*データマッパー*のソースリストは無視します。
* **ヘッダーあり - ヘッダーをスキップして代わりにフィールドリストを使用**: ファイルにヘッダーはありますが、無視する必要があります。*データマッパー*のソースリストで指定されたヘッダー名を使用します。

### インポートするワークシート

ブックには異なるデータを持つ多数のワークシートが含まれる場合があるため、現在のインポート処理でインポートするワークシートを選択できます。オプションは次のとおりです。

* すべてのワークシート
* 検索に一致するワークシート
* 選択したワークシート

#### ワークシート検索の使用

ワークシートの検索機能では、検索条件に一致するワークシートを含めることができます。検索条件には次のものがあります。
* **次で始まる**: ワークシート名が検索テキストで始まります。
* **含む**: ワークシート名に検索テキストが含まれます。
* **次で終わる**: ワークシート名が検索テキストで終わります。

#### 選択したファイル内のシートを検索

シートを検索するボタンを押すとExcelファイルが開き、テーブルで使用できるワークシートが一覧表示されます。インポートに含めるワークシートのテーブル内のチェックボックスをオンにします。

<Aside>*データマッパー*を取り込む際には、一覧で最初に見つかったワークシートが使用されます。インポートステップに含めるすべてのワークシートが、同様の形式であることを確認してください。</Aside>
### 列ヘッダー

<Aside>技術的な制限により、Googleスプレッドシートのすべての列は文字列のデータ型としてインポートされます。ブール値、数値、日付/時刻のデータ型は、マッパーで明示的に指定する必要があります。</Aside>
