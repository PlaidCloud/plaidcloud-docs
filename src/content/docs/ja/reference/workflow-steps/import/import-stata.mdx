## 説明


Stataデータファイル（.dta）を、PlaidCloudのプロジェクトテーブルにインポートします。計量経済学や統計分析にStataを使用し、作業用のデータセットをPlaidCloudに取り込んでさらに処理する組織に便利です。

変数ラベルは、Stata形式に含まれている場合に保持されます。
