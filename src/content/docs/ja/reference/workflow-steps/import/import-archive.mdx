## 説明


PlaidCloudネイティブのアーカイブファイルを、プロジェクトのテーブルにインポートし直します。アーカイブ形式では、CSVの往復では失われてしまう列の型、メタデータ、インデックスが保持されます。

[Export to Table Archive ステップ](/ja/reference/workflow-steps/export/export-to-table-archive/)で作成されます。プロジェクトのバックアップ、ワークスペースや環境間の移行、型付きデータの確実な転送に使用します。
