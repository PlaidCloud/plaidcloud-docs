## 説明


HDF5（Hierarchical Data Format version 5）ファイルを、PlaidCloudのプロジェクトテーブルにインポートします。HDF5は、科学計算、機械学習のデータ交換、型付きの列指向データをPython/R/MATLABのツール間でやり取りする必要のあるあらゆる場面で広く使われています。

形式の仕様については、[HDF Groupのドキュメント](http://www.hdfgroup.org/HDF5/)を参照してください。

## 固有の設定項目


### キー名

HDFファイルは、データをパス構造で保存します。HDFファイル内のテーブルの保存先として、キー（パス）が必要です。ほとんどの場合、これは*table*になります。
