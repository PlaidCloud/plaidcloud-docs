## 説明

PlaidCloud Documentストレージ内のIBM DB2抽出ファイルをインポートします。DB2サーバーにオンプレミスのインフラストラクチャからしか到達できない場合に便利です。外部プロセスが抽出ファイルをPlaidCloud Documentストレージにプッシュし、このステップがそこから読み取ってプロジェクトのテーブルに取り込みます。

DB2へライブでアクセスする場合（抽出ファイルを使用しない場合）は、標準の[IBM DB2](../../../connectors/databases/ibm-db2/)接続を使用して接続し、[外部データベーステーブルのインポート](../import-external-database-tables/)を使用します。
