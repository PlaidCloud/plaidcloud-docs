## 説明


外部データベース（データベースコネクターで設定）の1つ以上のテーブルを、プロジェクトのテーブルにインポートします。**差分ロード**（前回のインポート以降に変更された行のみを取得）と、**テーブル名の再マッピング**（ソーステーブルをPlaidCloud内で別の名前で取り込む）をサポートしています。

運用ソースシステムとPlaidCloudのテーブルをスケジュールで同期し続けたい場合に、毎回すべての行を再インポートせずに済ませるために使用します。

<Aside title="ソースを検査は外部データベースを読み取ります">
このステップに追加したテーブルでは、**ソースを検査**ボタンが、接続先のデータベースからそのテーブルの現在の列を直接読み取り、そのテーブルのマッピングだけをその場で更新します。ステップを設定した後にソーステーブルの列が変更された場合に、接続全体の検出を再実行せずに使用できます。
</Aside>

<Aside title="PostgreSQLの列タイプ">
PostgreSQLのソースでは、`uuid` 列はテキストとしてインポートされ、`json`/`jsonb` 列はJSONのテキスト表現としてインポートされます。
</Aside>

<Aside title="数値列は正確な10進数としてインポートされます">
ソースの `numeric`/`decimal` 列は、小数点の左側に最大28桁、右側に最大10桁を保持する正確な10進数値としてインポートされます。小数点以下が10桁を超える値は収まるように丸められ、整数部が28桁を超える値はインポートが停止し、列が示されます。
</Aside>

<Aside type="caution" title="列に収まらない値があるとインポートが停止します">
ソースの値が、データを失わずにターゲット列に収まらない場合（整数列に小数が入る場合、列に対して大きすぎる数値の場合、数値列に `NaN`/`Infinity` が入る場合など）、暗黙的に切り捨てたり丸めたりするのではなく、列とそのデータ型を示すエラーでインポートが停止します。ステップのデータマッパーで、その列の**タイプ**を値を保持できるものに設定してから、インポートを再実行してください。
</Aside>
