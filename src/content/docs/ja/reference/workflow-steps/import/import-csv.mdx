## 説明

PlaidCloud Document から区切りテキストファイルをインポートします。対象となる区切り文字には、次のものが含まれますが、これらに限定されません。
* カンマ（, ）
* パイプ（|）
* セミコロン（; ）
* タブ
* スペース（ ）
* アットマーク（@）
* チルダ（~）
* コロン（:）

### 選択したソースファイルを検査

*ソースファイルから設定を推測*ボタンを押すと、PlaidCloud がファイルを開いて内容を調べ、データ形式の判定を試みます。推測された設定は、必ず内容が正しいかどうかを確認してください。

<Aside>インポート対象としてディレクトリ内のファイルが選択されている場合や検索を使用している場合は、最初に見つかったファイルが推測に使用されます。</Aside>

ファイルから列が検出されないステップは保存できません。保存は**列が検出されませんでした**というメッセージで中止されます。PlaidCloud がファイルを読み取れなかった場合は、その理由がメッセージに表示されます。たとえば、区切りファイルとしては一般的でない拡張子であったり、定義されていないワークフロー変数がファイルパスに使われていたりする場合です。そうでない場合は、区切り文字、引用符文字、エスケープ文字がファイルと一致していること、ファイルが区切りテキストファイルであること、ファイルが空でないことを確認してください。

### データ形式

#### 区切り文字
前述のとおり、**ソースを検査**はソースファイル内の区切り文字の判定を試みます。別の区切り文字を使用する場合は、このセクションで区切り文字を指定します。標準の区切り文字の一覧から選択できます。区切り文字が設定されていないステップでは、カンマが使用されます。
* カンマ（, ）
* パイプ（|）
* セミコロン（; ）
* タブ
* スペース（ ）
* アットマーク（@）
* チルダ（~）
* コロン（:）

#### ヘッダータイプ

CSV にはヘッダーが含まれる場合と含まれない場合があるため、PlaidCloud では、ヘッダーを使用する、ヘッダーを無視する、または列の順序で列の対応を決定する、のいずれかを選択できます。
* **ヘッダーなし**: CSV ファイルにヘッダーがありません。*データマッパー*のソースリストを使用して列の対応を決定します。
* **ヘッダーあり - ヘッダーを使用してフィールドリストを上書き**: CSV ファイルにヘッダーがあります。指定されたヘッダー名を使用し、*データマッパー*のソースリストは無視します。
* **ヘッダーあり - ヘッダーをスキップして代わりにフィールドリストを使用**: CSV ファイルにヘッダーがありますが、無視する必要があります。*データマッパー*のソースリストで指定されたヘッダー名を使用します。

**ヘッダータイプ**は、2 つのヘッダーオプションについて、`header_treatment` に `use` または `skip` として保存されます。Excelのインポートでは `dynamic` も指定できます。

#### 日付形式

この設定は、CSV ファイルに含まれる日付が、日付や時刻としてすぐには認識できない場合に役立ちます。インポート処理では日付の変換を試みますが、少し補足情報があると処理がうまくいきやすくなります。

指定した形式でウェアハウスが読み取れない値は、インポートを停止するのではなく、空の値として保存されます。そのため、ファイルと一致しない形式を指定すると、日付がすべて空の列ができ、インポートは成功したと報告されます。この設定を変更したあとは、結果を利用する前に、インポートされた列を確認してください。

<Aside type="caution" title="Lakehouse v2 の時間列">
データ型が**時間**の列は、指定した日付形式にかかわらず、Lakehouse v2 では空としてインポートされます。解析に使用されるウェアハウスの関数が、時刻のみの値を生成できないためです。この列は**タイムスタンプ**としてインポートして時刻を取り出すか、**テキスト**としてインポートしてください。**日付**列と**タイムスタンプ**列は影響を受けません。
</Aside>

### 特殊文字

特殊文字の入力項目は、PlaidCloud が特定の文字をどのように扱い、CSV の処理においてそれらが何を意味するかを制御します。
 * **引用符文字**: 囲まれたテキストの集まりを、1 つのフィールドとして処理することを示す文字です。未設定の場合は二重引用符（`"`）になります。
 * **エスケープ文字**: 後続の文字を特殊文字として解釈せず、そのまま処理することを示す文字です。フィールドに区切り文字が含まれる可能性がある場合に便利です。未設定の場合はバックスラッシュ（`\`）になります。
 * **Null文字**: CSV にはデータ型がないため、この文字を使うと、値を空の文字列や 0 ではなく NULL として扱うことを示せます。
 * **空のフィールド**: 空のフィールドは、どの Lakehouse でも、テキスト列と数値列のどちらも NULL としてロードされます。そのため、空白の数値は 0 ではなく NULL になります。スペースのみのセルは、そのままロードされます。
 * **末尾のマイナス記号**: 一部のソースシステムでは、負の数を、先頭に付ける代わりに末尾にマイナス記号を付けて出力します。この設定を使うと、それらを負の数として処理します。

### 行の選択

不要なレコードを含む入力ファイルでは、データを処理する前にスキップする行数を**スキップする行**に設定します。ファイルに、表形式のデータに到達する前にスキップしなければならないヘッダーブロックが含まれている場合に便利です。

スキップされる行には空行も含まれます。**ヘッダータイプ**が**ヘッダーあり - ヘッダーを使用してフィールドリストを上書き**の場合、ヘッダーはスキップされた行の次の最初の行から読み取られるため、データはヘッダー名でターゲット列にマッピングされます。スキップされる行とヘッダーだけでデータ行がないファイルは、何もインポートされませんが、ステップは完了します。

#### 例: SAP リストのエクスポート

KE24、KSB1、FAGLL03 などの SAP リストのエクスポートは、列ヘッダーの前に、空行を含むことの多い選択ブロックから始まります。

```text
Line Item Journal Entries
Company Code: 1000
Posting Date: 2026-09-01 to 2026-09-30

Company Code|Document Number|Posting Date|Amount
1000|100004512|2026-09-03|1,500.00
```

ヘッダーは 5 行目にあるため、その前に 4 行あります。**スキップする行**を `4` に、**ヘッダータイプ**を**ヘッダーあり - ヘッダーを使用してフィールドリストを上書き**に設定します。インポートでは `Company Code`、`Document Number`、`Posting Date`、`Amount` が列名として読み取られ、最初のデータ行はヘッダーの次の行になります。

引用符で囲まれた空のフィールドを NULL ではなく空の文字列としてロードするには、**Keep Quoted Empty Fields ("") As Empty String** を選択します。

### 追加設定

**その他の CSV オプション**には、次のフィールドがあります。

* **エンコーディング**（`encoding`）— 検出する代わりに、ファイルの読み取りに使用する Python のコーデックです。デコードできないバイトは U+FFFD として読み取られます。
* **区切り文字**（`delimiters`）— 単一の区切り文字の代わりに、列を区切るすべてのテキストを指定する JSON 配列です。それぞれ複数の文字で指定できます。**連続する区切り文字を 1 つとして扱う**（`combine_delimiters`）を選択すると、連続する複数の区切り文字を 1 つとして扱います。
* **行区切り文字**（`row_delimiter`）— 引用符の外にある場合に行を終了するテキストです。それ以外の場所にある改行は値の一部になります。空白のままにすると、どの改行でも行が終了します。
* **コメント行の接頭辞**（`comment`）— このテキストで始まる行はインポートされません。**コメント**（`comments`）には、**開始文字列**と**次で終わる**のペアでコメントを列挙します。これらは引用符の外にある場合に、その位置で切り取られます。**次で終わる**を指定しない場合、コメントは行末まで続きます。
* **行継続**（`line_continuation`）— 改行の前にこのテキストがあると、その行が次の行と結合されます。
* **終了引用符**（`quote_end`）— **引用符文字**と異なる場合に、引用符で囲まれた値を終了する引用符です。**引用符で囲まれた値は引用符を保持する**（`keep_quotes`）を選択すると、引用符で囲まれた値の引用符文字が保持されます。
* **空行を空の値の行としてインポートする**（`keep_blank_lines`）— 空行を除外せず、空の値の行としてインポートします。
