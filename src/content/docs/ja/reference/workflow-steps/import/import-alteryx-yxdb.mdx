## 説明

PlaidCloud DocumentからAlteryx YXDBファイルをインポートします。YXDBは、Alteryx Designerがデータセットとフィールドのメタデータを保存するために使用するネイティブのバイナリファイル形式です。

YXDBのインポートは、ファイル全体をメモリに読み込むのではなく一時ストレージ経由でストリーミングされるため、非常に大きなファイルでもメモリ不足にならずにインポートできます。ファイルのデータ型（10進数、日付、タイムスタンプ）はターゲットテーブルに保持されます。

設定された `.yxdb` ファイルが存在しなくても、同じフォルダーに同名の `.parquet` ファイルがある場合、ステップはその `.parquet` ファイルを読み取り、その旨の警告を表示します。変換されたAlteryxワークフローは `.yxdb` の出力を同名の `.parquet` ファイルとして書き込むため、それらの `.yxdb` ファイルを読み取るステップは、自動的にデータを取得します。ファイルを検索するインポートでは、このフォールバックは使用されません。
