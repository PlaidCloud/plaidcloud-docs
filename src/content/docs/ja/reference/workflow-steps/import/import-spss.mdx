## 説明



SPSSデータファイル（.savおよび.zsav形式）を、PlaidCloudのプロジェクトテーブルにインポートします。調査データ、社会科学の研究データ、またはSPSSベースのツールと連携するあらゆるパイプラインに便利です。

変数ラベルと値ラベルは、形式がサポートしている場合に保持されます。
