## 説明

**Import dBASE** ステップは、dBASE（`.dbf`）ファイルをインポートします（ファイル自体にスキーマが含まれています）。ワークフローエンジンで実行されます。パッケージ化マクロの結果は、Alteryxマクロの近似です。

dBASEのインポートは、ファイル全体をメモリに読み込むのではなく一時ストレージ経由でストリーミングされるため、非常に大きなファイルでもメモリ不足にならずにインポートできます。ファイルのデータ型（10進数、日付、タイムスタンプ）はターゲットテーブルに保持されます。

## パラメーター

- **ソース** — `.dbf` ファイルです。
- **ターゲットテーブル** — 出力テーブルです。
- **ソースファイルが変更されていない場合は再インポートをスキップ** — ソースファイルとステップの設定が前回の成功した実行以降に変更されていない場合、ワークフローの実行はインポートをスキップします。デフォルトでオンです。常に再インポートするには、チェックを外してください。
