## 説明

PlaidCloud DocumentからApache Parquetファイルをインポートします。Parquetは、Hadoopエコシステムやクラウドデータプラットフォームで広く使われている列指向のストレージ形式で、大規模なデータセットに対して効率的な圧縮とエンコーディングを提供します。

Parquetのインポートは、ファイル全体をメモリに読み込むのではなく一時ストレージ経由でストリーミングされるため、非常に大きなファイルでもメモリ不足にならずにインポートできます。ファイルのデータ型（10進数、日付、タイムスタンプ）はターゲットテーブルに保持され、タイムスタンプ列は日付と時刻の完全な精度を維持します。
