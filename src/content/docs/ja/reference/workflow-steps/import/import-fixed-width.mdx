## 説明



区切り文字ではなく文字位置で列が定義されたテキストファイルをインポートします。メインフレームやCOBOLの出力でおなじみの形式です。フィールドごとに列の境界（開始位置と長さ）を設定します。

データが区切り形式の解析ではなく固定桁の表示用にレイアウトされている、従来のERPエクスポート、政府への提出書類、銀行取引明細の形式でよく使われます。

固定幅のインポートは、ファイル全体をメモリに読み込むのではなく一時ストレージ経由でストリーミングされるため、非常に大きなファイルでもメモリ不足にならずにインポートできます。

### ヘッダー

ファイルにはヘッダーがある場合とない場合があるため、PlaidCloudでは、ヘッダーを使用する、ヘッダーを無視する、または列の順序で列の対応を決定する、のいずれかを選択できます。
* **ヘッダーなし**: ファイルにヘッダーが含まれていません。*データマッパー*のソースリストを使用して、列の対応を決定します。
* **ヘッダーあり - ヘッダーを使用してフィールドリストを上書き**: ファイルにヘッダーがあります。指定されたヘッダー名を使用し、*データマッパー*のソースリストは無視します。
* **ヘッダーあり - ヘッダーをスキップして代わりにフィールドリストを使用**: ファイルにヘッダーはありますが、無視する必要があります。*データマッパー*のソースリストで指定されたヘッダー名を使用します。

### 行の選択

不要なレコードを含む入力ファイルでは、データを処理する前にスキップする行数を指定できます。表形式のデータに到達する前にスキップしなければならないヘッダーブロックがファイルに含まれている場合に便利です。

### 列幅

列の幅を、カンマまたはスペースで区切って入力します。

### レイアウト

| 設定 | 内容 |
| --- | --- |
| エンコーディング | ファイルの文字セットです。**UTF-8**（デフォルト）、**EBCDIC（米国、cp037）**、**EBCDIC（国際、cp500）**、**ラテン1（Latin-1）** から選択します。メインフレームのファイルには、EBCDICのコードページを選択します。 |
| スキップするレコード数 | ヘッダーまたはデータの前に、ファイルの先頭でスキップするレコードの数です。 |
| 末尾で除外するレコード数 | トレーラーレコードなど、ファイルの末尾から除外するレコードの数です。 |
| 1 行に 1 レコード | オン（デフォルト）の場合、各行が1つのレコードになります。レコードが改行なしで連続して並んでいるファイルでは、オフにします。その場合、各レコードの長さは列幅の合計になります。 |
| レコード間の文字数 | レコードが1行に1つでない場合に、区切り文字など、各レコードの後でスキップする文字数です。 |
| 空白の除去 | 各値から除去する空白です。**先頭と末尾**（デフォルト）、**末尾のみ**、**なし**から選択します。 |
