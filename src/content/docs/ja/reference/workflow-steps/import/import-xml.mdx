## 説明


XMLファイルの表形式のデータを、PlaidCloudのプロジェクトテーブルにインポートします。各「行」を識別する要素パスを設定し、子要素または属性をテーブルの列にマッピングします。

従来のエンタープライズ連携、B2Bデータ交換（RosettaNet、ebXML）、政府への提出書類の形式でよく使われます。


## レコードの読み取り形式

**レコードの読み取り形式**は、ファイルをテーブルにする方法を選択します。

* **レコードタグごとに1テーブル**（デフォルト）— **レコードタグ**タブに読み取る各タグが一覧表示され、各タグはそれぞれ独自のテーブルに読み込まれます。テーブル名は**ターゲットテーブルのプレフィックス**から付けられます。
* **要素ごとに1行** — 繰り返される1つの要素が1つのテーブルに読み込まれ、出現ごとに1行になります。**レコードタグ**タブと**ターゲットテーブルのプレフィックス**は無効になります。

**要素ごとに1行**では、次を設定します。

* **XML要素** — 行になる要素です。空白のままにすると、最初の列の要素になり、フィールドに表示されます。
* **ターゲットテーブル** — 読み込み先のテーブルです。
* **列** — 各**子要素または属性**と、それを読み込む**列**です。すべての列はテキストとしてインポートされます。
* **値の前後の空白を削除** — 各値の先頭と末尾の空白を除去します。
* **名前を名前空間プレフィックスとともに照合** — 要素名と属性名を、プレフィックスを含めてファイルに記述されたとおりに照合します。

ソースファイル、ターゲットテーブル、およびXML要素または少なくとも1つの列が必要です。モードを切り替えても、もう一方のモードの設定はフォームに保持されるため、切り戻すと復元されますが、保存すると、切り替えて離れたモードの設定は削除されます。コントロールの横の注記にその内容が表示されます。

フォームから保存されたステップは、**レコードタグ**タブで設定されたとおりにレコードタグを読み取ります。
