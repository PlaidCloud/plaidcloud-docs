## 説明

PlaidCloud DocumentからApache Avroファイルをインポートします。Avroは、Apache Hadoopプロジェクトの行ベースのデータシリアライズ形式で、データとそのスキーマを一緒に保存するため、データパイプラインやストリーミングシステムでの利用に適しています。

## 固有の設定項目

### ファイルの更新日時

指定した期間内に変更されたファイルのみを読み取ります。**この日時より後に更新**は、入力した日時より後に最後に更新されたファイルのみを読み取り、**この日時より前に更新**は、その日時より前に最後に更新されたファイルのみを読み取ります。どちらか一方、または両方を指定できます。日時は `YYYY-MM-DDTHH:MM:SS` の形式で入力します（例: `2026-10-01T00:00:00`）。タイムゾーンを指定しない場合、日時はUTCとして扱われます。タイムゾーンを指定する場合は、`2026-10-01T00:00:00-05:00` のように入力します。日時にはワークフロー変数を含めることができ、その値はステップの実行時に読み取られます。
