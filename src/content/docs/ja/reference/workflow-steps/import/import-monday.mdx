## 説明

monday.com接続を介して、1つ以上の[monday.com](https://monday.com/)ボードのアイテムを、プロジェクトのテーブルにインポートします。プロジェクト管理、受付キュー、運用タスクのデータを、財務データとともにワークフローに取り込むために使用します。

## 固有の設定項目

### 接続の構成

読み取りに使用するmonday.com接続です。

### ターゲットテーブル

ボードごとに1行を指定します。読み取る**ボードID**と、その書き込み先のプロジェクトテーブルです。1つのステップで複数のボードを同時にインポートできます。各ターゲットは、ビューではなくテーブルである必要があります。
