## 説明

PlaidCloud Documentから、Microsoft Excelファイルの特定のワークシートをインポートします。Analyzeは、従来のExcel形式（XP/2003）と新しい形式（2007/2010/2013）の両方をサポートしています。サポートするファイルタイプには、次のものが含まれますが、これらに限定されません。

* XLS
* XLSX
* XLSB
* XLSM

バイナリブック（XLSB）、従来のXLS、ODSファイルでも、XLSXと同じ方法でワークシートとセル範囲をインポートできます。

Excelのインポートは、ブック全体をメモリに読み込むのではなく一時ストレージ経由でストリーミングされるため、非常に大きなファイルでもメモリ不足にならずにインポートできます。ソースのデータ型（10進数、日付、タイムスタンプ）は、テキストを経由せずにターゲットテーブルに保持されます。

### ヘッダー

Excelファイルにはヘッダーがある場合とない場合があるため、PlaidCloudでは、ヘッダーを使用する、ヘッダーを無視する、または列の順序で列の対応を決定する、のいずれかを選択できます。
* **ヘッダーなし**: ファイルにヘッダーが含まれていません。*データマッパー*のソースリストを使用して、列の対応を決定します。
* **ヘッダーあり - ヘッダーを使用してフィールドリストを上書き**: ファイルにヘッダーがあります。指定されたヘッダー名を使用し、*データマッパー*のソースリストは無視します。
* **ヘッダーあり - ヘッダーをスキップして代わりにフィールドリストを使用**: ファイルにヘッダーはありますが、無視する必要があります。*データマッパー*のソースリストで指定されたヘッダー名を使用します。

ヘッダーセルの前後のスペースと改行は、列名から削除されます。

### 行の選択

不要なレコードを含む入力ファイルでは、データを処理する前にスキップする行数を指定できます。表形式のデータに到達する前にスキップしなければならないヘッダーブロックがファイルに含まれている場合に便利です。

空のテキストセルをNULLではなく空の文字列として読み込むには、**Keep Empty Text Cells As Empty String** を選択します。

**その他の Excel オプション**には、次のフィールドがあります。

* **ワークシートで非表示の行を除外する**（`skip_hidden_rows`）— ワークシートで非表示になっている行はインポートされません。
* **数式エラーのセルを空欄ではなくエラーテキスト（#DIV/0!）としてインポートする**（`keep_error_cells`）— 数式エラーのセルは、空欄ではなく `#DIV/0!` などのエラーテキストとしてインポートされます。
* **有効桁数**（`significant_digits`）— 各10進数をこの有効桁数に丸めます。Excelは15桁を保持します。
* **ワークシートの位置**（`sheet_index`）— 名前で選択したワークシートの代わりに、ブック内の0から始まるこの位置にあるワークシートをインポートします。

**インポートするワークシート**で**データを含む最初のシートをインポート**（`sheet_first_with_data`）を選択すると、データを含む最初のワークシートがインポートされ、それより前にある空のワークシートはスキップされます。どのワークシートにもデータがない場合は、ブックの最初のワークシートが読み取られます。

### ブック

**ブックのパスワード変数**は、パスワードで保護されたブックを開きます。パスワード自体ではなく、パスワードを保持するワークフロー変数またはプロジェクト変数（`{xlsx_password}` など）を入力してください。パスワードフィールドに変数参照以外が含まれるステップは、保存時に拒否されるため、パスワードがステップ、そのバージョン、そのコピーに現れることはありません。このルールの導入前に、入力されたパスワードを保持していたステップでは、そのパスワードが自動的に新しいプロジェクト変数に移され（アーキテクトにのみ表示されます）、現在はその変数を参照しています。

### 読み取り対象

インポートの各エントリは、ワークシート、ブックで定義された名前付き範囲、または特定のセル範囲を選択します。この3つは対等であり、1つのインポートで複数のエントリにわたって混在させることができます。

* **ワークシート**: シート全体を、名前で選択して読み取ります。
* **名前付き範囲**: ブック自体が名前を定義している範囲を読み取ります。名前付き範囲はピッカーでワークシートと並べて一覧表示されるため（後述の*選択したファイル内のシートを検索*を参照）、シートを選択するのと同じ方法で選択できます。
* **セル範囲**: ワークシートやブックの名前に対応していない、特定の矩形の範囲を読み取ります。範囲が存在するシートを選択し、`$` の後に範囲を入力します。次の3つの形式をサポートしています。
  * `Sheet1$A1:J100` — 範囲を限定した形式です。
  * `Sheet1$A1:J` — 終端を指定しない形式です。`A1` から、A列からJ列の最終行まで読み取ります。
  * `Sheet1$A:BJ` — 列全体の形式です。シートのA列からBJ列を読み取ります。AlteryxがExcel入力に対して書き込む形式です。

名前付き範囲は、XLSXおよびXLSMのブックから読み取られます。XLSB、XLS、ODSのブックでは、ワークシートとセル範囲を使用できます。

<Aside type="caution">複数の離れた領域を参照する名前付き範囲や、シートの範囲外または逆転している（終了セルが開始セルの上または左にある）セル範囲は、インポートされずにエラーで拒否されます。そのため、インポートが誤ったセルを暗黙的に読み取ることはありません。</Aside>

#### インポートするワークシート

ブックには異なるデータを持つ多数のワークシートが含まれる場合があるため、現在のインポート処理でインポートするワークシートを選択できます。オプションは次のとおりです。

* すべてのワークシート
* 検索に一致するワークシート
* 選択したワークシート

#### ワークシート検索の使用

ワークシートの検索機能では、検索条件に一致するワークシートを含めることができます。検索条件には次のものがあります。
* **次で始まる**: ワークシート名が検索テキストで始まります。
* **含む**: ワークシート名に検索テキストが含まれます。
* **次で終わる**: ワークシート名が検索テキストで終わります。

#### 選択したファイル内のシートを検索

シートを検索するボタンを押すとExcelファイルが開き、テーブルで使用できるワークシートと名前付き範囲が一覧表示されます。インポートに含めるワークシートや名前付き範囲のテーブル内のチェックボックスをオンにします。`.zip` ファイル内のブックも利用できます。そのワークシートと名前付き範囲が一覧表示されます。

<Aside>*データマッパー*を取り込む際には、一覧で最初に見つかったワークシート、名前付き範囲、またはセル範囲が使用されます。インポートステップに含めるすべての項目が、同様の形式であることを確認してください。</Aside>

#### シート対応表

**シート対応表**は、ブックごとに異なるワークシートのセットを読み取ります。読み取るワークシートごとに1行を持つ**シート対応表テーブル**を選択し、その**ブックの列**にはブックのパスまたはファイル名、**シートの列**にはワークシートを保持します。シート対応表が設定されている場合、テーブルに名前のあるブックのみが、それぞれに一覧表示されたワークシートについて、テーブルの行の順序で読み取られます。ワークシートが空白の場合は、ブックの最初のワークシートが読み取られます。

#### 選択したワークシートがないファイル

インポートが複数のファイルを読み取る場合、選択したワークシートが含まれていないファイルや、ワークシート検索に一致するワークシートがないファイルはスキップされます。ステップは、スキップされたファイルとそのファイルにあるワークシートを示す警告を出して完了し、他のファイルは引き続きインポートされます。すべてのファイルがスキップされた場合でも、ステップは成功し、ターゲットテーブルは空のままとなり、その理由を説明する警告が表示されます。ワークシート名は、大文字と小文字も含めて完全に一致する必要があります。

スキップされたファイルは、*Delete Files After Import* がオンになっていてもフォルダーに残り、削除または修正するまで実行のたびに警告が表示されます。複数ファイルのインポートによる警告はステップに表示され、最大5件が一覧表示され、残りは件数で示されます。

<Aside>複数ワークシートのインポートで空のワークシートがあっても、そのワークシートからは0行が読み込まれるだけで、インポートは失敗しません。</Aside>

### 1つのソース列を複数のターゲット列に使用する

1つのソース列で、複数のターゲット列にデータを渡せます。同じソース列を、それぞれ独自の名前、型、式を持つ2つ以上のターゲット行にマッピングします。たとえば、`Amount` をテキスト列として一度読み取り、数値列としてもう一度読み取ったり、同じセルから2つのテキスト列を作成したりできます。数値のターゲットでは、式が実行される前にソースが変換されることはなくなったため、`1,500` のような値を式で先にクリーンアップできます。

これは、データマッパーを使用するCSVのインポート以外のすべてのファイルインポートで同様に機能します。対象は、Excelのインポート、固定幅、JSON、Avro、Parquet、DBF、XML、YXDBです。
