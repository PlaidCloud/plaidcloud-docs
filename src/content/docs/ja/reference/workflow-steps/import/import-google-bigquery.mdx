## 説明


Google BigQueryのデータを、PlaidCloudのプロジェクトテーブルにインポートします。BigQueryを主要な分析ウェアハウスとして使用し、特定のデータセットをPlaidCloudに取り込んで、さらにモデリングや配賦の作業を行う組織に便利です。

認証にはGoogle Cloudのサービスアカウントを使用します。ソースのデータセットとテーブルは、ステップレベルで設定します。
