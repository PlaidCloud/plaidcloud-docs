## 説明

[テーブルのアーカイブ](/ja/reference/workflow-steps/export/archive-tables/)で作成されたアーカイブから、プロジェクトのテーブルを復元します。プロジェクトやワークスペース間でテーブルのデータを移動する場合や、保管しておいたコピーに戻す場合に使用します。

## 固有の設定項目

### ソース

ドキュメントアカウント内のアーカイブファイルです。ピッカーでは、完全一致のパスではなく、完全一致、前方一致、後方一致、部分一致、globによる検索で一致させることもできます。

### 上書き

デフォルトではオフです。オフの場合、プロジェクトにすでに存在するテーブルはそのまま残されます。オンにすると、既存のテーブルがアーカイブされたコピーで置き換えられます。
