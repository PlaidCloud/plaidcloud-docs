## 説明

数百万件のデータセットを持つQuandlのリポジトリからデータセットをインポートします。

Quandlのデータセットの詳細については、Quandlの公式サイト（http://www.quandl.com/）を参照してください。


## 例

まだ例はありません。

## 固有の設定項目

### ソースデータの指定

Quandlのデータセットにアクセスするには、ユーザーアカウント、またはアクセスが制限されたゲストアカウントが必要です。これにはツールでの設定が必要です。Quandlアカウント接続の設定の詳細については、[PlaidCloud Tools – 接続](/ja/reference/connectors/)を参照してください。

必要なアカウントがすべて設定されたら、ドロップダウンリストから適切なアカウントを選択します。

次に、目的のQuandlコードの条件を入力します。データセットを検索するには、**検索**機能を使用できます。または、データセットを手動で入力することもできます。その場合は、「[http://www.quandl.com](http://www.quandl.com/)」の後に続くURLの部分を入力します。

たとえば、Microsoftの株式のデータセット（http://www.quandl.com/GOOG/NASDAQ_MSFT）をインポートするには、Quandlコードフィールドに *GOOG/NASDAQ_MSFT* と入力します。


### データの選択


インポート時に、Quandlのデータセットをスライスできます。使用できるオプションは次のとおりです。


* 開始日: 日付ピッカーを使って、目的の日付を選択します。
* 終了日: 日付ピッカーを使って、目的の日付を選択します。
* Collapse: 結果を日次、週次、月次、四半期、または年次で集計します。デフォルトでは集計されません。
* Transformation: 集計計算です。
* Limit Rows: デフォルト値の0は、すべての行を返します。それ以外の正の整数を指定すると、データセットから返す行数の上限になります。
