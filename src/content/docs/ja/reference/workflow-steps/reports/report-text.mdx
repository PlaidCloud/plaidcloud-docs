## 説明

構成済みレポート用の**テキスト**ブロックです。対応する Alteryx の *Reporting* / *Portfolio Composer* ツールに相当し、ワークフローエンジン（reportlab / matplotlib）上で実行されます。レンダラーによる出力は、Alteryx の出力を近似したものです。

## ソースとオプション

- **ソーステーブル** — このレポート要素に使用するデータです。
- **出力テーブル** — 描画されたスニペットの書き込み先テーブルです。
- **レポート順序** — 構成済みレポート内でのこの要素の順序です。
- **テキスト内容** — 描画するテキストです。

## テキスト内で列を参照する

テキスト内容では、列名を角括弧で囲んで指定でき、その位置に値が出力されます。たとえば `[Year] Results` は `2026 Results` と出力されます。変換された Alteryx の Report Text には、元のテキストに含まれていたフィールド参照がそのまま引き継がれます。Alteryx が `[Year:A]` のように書き出す書式付きの形式も含まれます。

1 つのテキストはソーステーブル全体に対して組み立てられるため、指定した列は、読み取るすべての行で同じ値を持っている必要があります。列が複数の値を持つ場合は、上流で集計してください。テキストブロックは複数の値を同時に出力できません。

`[CurrentYear]` は、レポートを描画する年を出力します。列は必要ありません。

通常の文章を安全に書けるよう、次のルールがあります。

- 列に一致する名前は、常に置き換えられます。
- どの列にも一致しない名前は、参照以外にあり得ない場合に限り、ステップが停止してその旨を通知します。たとえば `[Quarter:A]` のように、コロンに書式を密着させて書いた場合です。
- 角括弧で囲まれた文章は、書いたとおりに出力されます。`[12:30]` は時刻のままで、`[Note: continued]` は補足のままです。数字だけの名前は列名ではなく、コロンの後にスペースを入れるのは文章だからです。

書式そのものは適用されません。値は列が保持するとおりに出力されるため、桁区切りや日付のレイアウトが必要な場合は、上流で列を整形してください。

**列**タブでは、レポート要素で利用できるソース列をマッピングします。
