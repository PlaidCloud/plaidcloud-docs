## 説明

構成済みレポートに配置される**画像**です。対応する Alteryx の *Reporting* / *Portfolio Composer* ツールに相当し、ワークフローエンジン（reportlab / matplotlib）上で実行されます。レンダラーによる出力は、Alteryx の出力を近似したものです。

## ソースとオプション

- **ソーステーブル** — このレポート要素に使用するデータです。
- **出力テーブル** — 描画されたスニペットの書き込み先テーブルです。
- **レポート順序** — 構成済みレポート内でのこの要素の順序です。
- **画像モード** — 静的（インラインの Base64 画像）またはフィールド（行ごとのファイルパス）です。
- **Base64 image** — 静的モードで使用するインライン画像データです。

## 列

**列**タブでは、レポート要素で利用できるソース列をマッピングします。
