## 説明

構成済みのレポート要素を PDF ドキュメントに**描画**します。対応する Alteryx の *Reporting* / *Portfolio Composer* ツールに相当し、ワークフローエンジン（reportlab / matplotlib）上で実行されます。レンダラーによる出力は、Alteryx の出力を近似したものです。

## ソースとオプション

- **ソーステーブル** — このレポート要素に使用するデータです。
- **出力テーブル** — 描画されたスニペットの書き込み先テーブルです。
- **レポート順序** — 構成済みレポート内でのこの要素の順序です。
- **幅 / 高さ** — 埋め込み画像のサイズ（ピクセル単位）です。
- **出力ファイル** — 描画されたファイルのドキュメントストア内のパスです。

- **出力形式**（`output_format`）— **PDF**（`pdf`、デフォルト）、またはレポートを自己完結型の 1 つの HTML ページとして書き出す **HTML ページ (自己完結型)**（`html`）です。ファイル名には `.html` 拡張子を付けてください。
- **2 つ目のソース テーブル**（`source_b`）— 2 つ目の入力テーブルです。これを指定すると、両方の入力の要素を組み立てて描画します。

## 列

**列**タブでは、レポート要素で利用できるソース列をマッピングします。
