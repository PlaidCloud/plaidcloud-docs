## 説明

**パッケージ化マクロ**は、Alteryx の*パッケージ化レポートマクロ*からインポートしたレポートバンドルを描画します。標準の Report ステップであり、バンドルされたマクロ定義はステップとともに自動的に引き継がれ、他の Report ステップと同じレポートアーティファクトの経路でレポート要素が描画されます。

## ソースとオプション

- **ソーステーブル** — このレポート要素に使用するデータです。
- **ターゲットテーブル** — 描画された出力の書き込み先テーブルです。
- **レポート順序** — 構成済みレポート内でのこの要素の位置です。
