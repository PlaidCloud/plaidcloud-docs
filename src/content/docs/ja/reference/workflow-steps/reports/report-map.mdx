## 説明

構成済みレポート用に、ソースのジオメトリから描画される**マップ**です。対応する Alteryx の *Reporting* / *Portfolio Composer* ツールに相当し、ワークフローエンジン（reportlab / matplotlib）上で実行されます。レンダラーによる出力は、Alteryx の出力を近似したものです。

## ソースとオプション

- **ソーステーブル** — このレポート要素に使用するデータです。
- **出力テーブル** — 描画されたスニペットの書き込み先テーブルです。
- **レポート順序** — 構成済みレポート内でのこの要素の順序です。
- **幅 / 高さ** — 描画されるマップのサイズ（ピクセル単位）です。

## テーマ凡例

レイヤーが値によって色分けされている場合、マップには各区分の名前を示す凡例が 1 つ描画されます。

変換された Alteryx の Report Map には、元のマップで使われていた区分名が引き継がれます。一般的なテーマ別マップでは、*High*、*Above Average*、*Average*、*Below Average*、*Low* などで、凡例にはそれらの名前が表示されます。区分名が指定されていないマップでは、各区分に、その区分が対象とする値の範囲がラベルとして表示されます。

凡例は 1 つしか描画されないため、名前は 1 つのレイヤーの区分に属している必要があります。次の場合、ステップは、読み取れるように見えても誤った区分名が付いた凡例を出力する代わりに、停止してその旨を通知します。

- 色分けされた値がマップで名前が付けられたすべての区分に及んでおらず、名前を実際に描画された区分と対応付けられない場合。
- 一部の区分にしか名前が付けられていない場合。
- 区分が複数のレイヤーに属している、または複数のレイヤーが色分けされている場合。

個々の値による色分けでは、各区分はその区分自身の値で名前が付けられます。区分とはそのためのものだからです。
