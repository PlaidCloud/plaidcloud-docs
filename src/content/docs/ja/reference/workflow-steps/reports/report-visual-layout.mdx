## 説明

レポート要素を配置する**ビジュアルレイアウト**です。対応する Alteryx の *Reporting* / *Portfolio Composer* ツールに相当し、ワークフローエンジン（reportlab / matplotlib）上で実行されます。レンダラーによる出力は、Alteryx の出力を近似したものです。

## ソースとオプション

- **ソーステーブル** — このレポート要素に使用するデータです。
- **出力テーブル** — 描画されたスニペットの書き込み先テーブルです。
- **レポート順序** — 構成済みレポート内でのこの要素の順序です。
- **配置** — 縦（積み重ね）または横（並べて配置）です。

## 列

**列**タブでは、レポート要素で利用できるソース列をマッピングします。
