## 説明

構成済みレポート用に、ソースデータから作成する**グラフ**（棒グラフ）です。対応する Alteryx の *Reporting* / *Portfolio Composer* ツールに相当し、ワークフローエンジン（reportlab / matplotlib）上で実行されます。レンダラーによる出力は、Alteryx の出力を近似したものです。

## ソースとオプション

- **ソーステーブル** — このレポート要素に使用するデータです。
- **出力テーブル** — 描画されたスニペットの書き込み先テーブルです。
- **レポート順序** — 構成済みレポート内でのこの要素の順序です。
- **グラフタイトル** — グラフの上に表示されるタイトルです。

## 列

**列**タブでは、レポート要素で利用できるソース列をマッピングします。
