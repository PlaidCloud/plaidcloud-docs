## 説明

**Create Samples (macro)** ステップは、Alteryx の *Create Samples* パッケージ化マクロを再現します。ワークフローエンジン内で実行され、パッケージ化マクロの結果は Alteryx マクロの近似です。

## パラメーター

- **ソース / 出力テーブル**。
- **Estimation %** と**乱数シード**。
