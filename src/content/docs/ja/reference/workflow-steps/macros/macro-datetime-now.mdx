## 説明

**DateTime Now (macro)** ステップは、Alteryx の *DateTime Now* パッケージ化マクロを再現します。ワークフローエンジン内で実行され、パッケージ化マクロの結果は Alteryx マクロの近似です。

## パラメーター

- **出力テーブル**と**出力形式**文字列。

## 出力形式

書式文字列には Alteryx の DateTime ツールのトークンを使用し、変換ではそれらがそのまま引き継がれます。空白のままにすると、ツール自体のデフォルトである `day, dd Month, yyyy` が使用されます（例：`Tuesday, 04 August, 2026`）。

| トークン | 表示内容 |
| --- | --- |
| `yyyy` / `yy` | 4 桁または 2 桁の年 |
| `Month` / `Mon` | 月の正式名または略称 |
| `MM` / `M` | 月の数値（先頭のゼロあり／なし） |
| `day` / `dy` | 曜日の正式名または略称 |
| `dd` / `d` | 日（先頭のゼロあり／なし） |
| `HH` / `H` | 24 時間制の時（先頭のゼロあり／なし） |
| `hh` / `h` | 12 時間制の時（先頭のゼロあり／なし） |
| `mm` | 分 |
| `ss` | 秒 |
| `tt` | AM または PM |

トークンは大文字と小文字が区別されます。`MM` は月、`mm` は分です。
