## 説明

**Heat Map (macro)** ステップは、Alteryx の *Heat Map* パッケージ化マクロを再現します。ワークフローエンジン内で実行され、パッケージ化マクロの結果は Alteryx マクロの近似です。

## パラメーター

- **ソース / 出力テーブル**と**最大距離**。
