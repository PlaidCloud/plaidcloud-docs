Alteryx の*パッケージ化マクロ*（ユーザーが作成するマクロではなく、Alteryx に同梱されているマクロ）を再現するワークフローステップです。いずれもワークフローエンジン内で実行され、その結果は Alteryx マクロの近似です。

これらは、ご自身で作成する再利用可能なステップシーケンスである [PlaidCloud マクロ](/ja/reference/workflow-steps/workflow-control/run-macro/)とは別のものです。
