## 説明

[Anaplan接続](/ja/guides/connections/anaplan/)を通じて、**既存の**Anaplanエクスポートアクションを実行し、生成されたファイルをテーブルとして取り込みます。エクスポートアクションはモデル内にあらかじめ存在している必要があります（APIでは作成できません）。また、このステップは出力内容を絞り込めません。Anaplanでエクスポートするよう構成されているものが、そのまま取り込まれます。

このステップは、ステップメニューの**Anaplan**に表示されます。

このステップは、Bulk APIを通じてAnaplanに**クラウドから直接**アクセスします。オンプレミスのエージェント経由のパスはありません。

<Aside type="tip">
このコネクターは読み取り専用で、Basic（ユーザー名とパスワード）またはCA証明書の資格情報で認証します。[認証](/ja/guides/connections/anaplan/#認証)を参照してください。Anaplanのリクエスト枠はテナント全体で共有されるため、このステップのスケジュールは、他のAnaplanワークフローとずらしてください。[スケジュールに関する考慮事項](/ja/guides/connections/anaplan/#スケジュールに関する注意点)を参照してください。
</Aside>

## 構成

### ソースとターゲット

| フィールド | 必須 | 備考 |
|---|---|---|
| Anaplan接続 | はい | 読み取りに使用する[Anaplan接続](/ja/guides/connections/anaplan/)です。 |
| 環境 | はい | 接続の環境です。 |
| Workspace | いいえ | 接続に保存されているワークスペースIDを上書きします。接続からライブで検出するか、手入力します。 |
| Model | いいえ | 接続に保存されているモデルIDを上書きします。ワークスペースを選択すると、ライブで検出されます。手入力もできます。 |
| Export | はい | 実行するAnaplanのエクスポートアクションです。ワークスペースとモデルを選択すると、ライブで検出されます。手入力もできます。その選択内容はここから上書きできず、Anaplanで構成されたとおりに実行されます。 |
| ポーリング試行回数 | はい | デフォルトは120です。ステップが拒否するまでに、エクスポートタスクの完了を何回ポーリングするかを指定します。拒否時にはタスクIDが示されます。黙って再送信することはありません。同じエクスポートアクションが生成した2つのファイルを区別する方法がAnaplanで文書化されていないため、再送信すると、この実行に誤ったファイルを結び付けるおそれがあります。 |
| Poll Interval (seconds) | はい | デフォルトは5です。ポーリングの間隔を秒で指定します。 |
| ターゲットテーブル | はい | エクスポートの取り込み先のテーブルです。すべての列はテキストとして取り込まれます。 |

## このステップで表現できないこと

| 制限 | 意味 |
|---|---|
| 既存のエクスポートアクションが必要 | APIではエクスポートアクションを作成できません。また、このステップが送信するリクエストには、ポイントオブビュー、メンバー選択、スライスのパラメーターが一切含まれません。Anaplanでアクションが出力するよう構成されているものが、そのまま取り込まれます。出力内容を変更するには、Anaplanでエクスポートアクションを作成または編集してください。 |
| すべての列がテキストとして取り込まれる | エクスポートの列の型を宣言するためにAnaplanが公開しているフィールドは、Anaplan自身が公開しているドキュメント内で不整合があるため、列の型を正しく決定するのに信頼できません。そのため、意図的かつ恒久的に、このフィールドから列の型は決定しません。必要な列は、後続のステップでキャストしてください。 |
| 数値は米国形式で要求される。まだグループ化されている列にはフラグが付き、修正はされない | エクスポートタスクは、米国の数値形式を要求して送信されます。桁区切りがまだ付いた状態で返ってくる列は、エクスポートがその形式で出力されていないことを意味します。その場合、ステップは小数点がどの文字かを推測せず、値を変更せずにテキストとして取り込み、列名と値の例を示して警告します。後続でキャストする前に、そのような列を確認してください。ヨーロッパ式の`1.234.567`を`1.234`として読み取ると、1,000分の1の値になってしまいます。 |
| 信頼できない抽出結果を取り込まずに拒否する | 次の場合、ステップは、完全に見えて実際にはそうではないテーブルを取り込むのではなく、何も取り込みません。エクスポートタスクが失敗した、またはAnaplanで成功が報告されない場合、タスクがキャンセルされた場合、ステップのポーリング回数を使い切ってもタスクがまだ実行中の場合、生成されたファイルにデータがまったくない場合、生成されたファイルを、それを作成したエクスポートに結び付けられない場合、または読み取った行数が、Anaplan自身が報告するそのエクスポートの行数と一致しない場合です。 |
| 読み取り専用 | Anaplanに何かが書き戻されることはありません。 |
