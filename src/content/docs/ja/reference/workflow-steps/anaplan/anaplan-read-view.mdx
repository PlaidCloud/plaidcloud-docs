## 説明

[Anaplan接続](/ja/guides/connections/anaplan/)を通じて、Anaplanの大容量読み取りリクエストパスを使用し、保存済みの**Anaplan**ビューからデータを読み取ります。ビューは**保存されたとおりに**読み取られ、このステップでは行、列、ページを個別に選択することはできません。別のスライスを読み取るには、Anaplanで別のビューを保存してください。

このステップは、ステップメニューの**Anaplan**の下に表示されます。

このステップは、Integration APIを使用して**クラウド直接**でAnaplanに接続します。オンプレミスのエージェント経由のパスはありません。

<Aside type="tip">
このコネクターは読み取り専用で、Basic（ユーザー名とパスワード）またはCA証明書の資格情報で認証します。[認証](/ja/guides/connections/anaplan/#認証)を参照してください。Anaplanのリクエスト予算はテナント全体で共有されるため、他のAnaplanワークフローとこのステップのスケジュールをずらしてください。[スケジュールに関する考慮事項](/ja/guides/connections/anaplan/#スケジュールに関する注意点)を参照してください。
</Aside>

## 設定

### ソースとターゲット

| フィールド | 必須 | 注記 |
|---|---|---|
| Anaplan接続 | はい | 読み取りに使用する[Anaplan接続](/ja/guides/connections/anaplan/)です。 |
| 環境 | はい | 接続の環境です。 |
| ワークスペース | いいえ | 接続に保存されているワークスペースIDを上書きします。接続から動的に検出するか、手動で入力します。 |
| モデル | いいえ | 接続に保存されているモデルIDを上書きします。ワークスペースを選択すると動的に検出されます。手動で入力することもできます。 |
| ビュー | はい | 読み取る保存済みのAnaplanビューです。モデルを選択すると動的に検出されます。手動で入力することもできます。 |
| ポーリング試行回数 | はい | デフォルトは120です。ステップが拒否するまでに、読み取りリクエストの完了をポーリングする回数です。拒否する際はリクエストIDが示されます。2つ目のリクエストが暗黙的に送信されることはありません。 |
| ポーリング間隔（秒） | はい | デフォルトは5です。ポーリングの間隔（秒）です。 |
| ターゲットテーブル | はい | 返されたビューの取り込み先テーブルです。 |

## このステップで表現できないこと

| 制限事項 | 内容 |
|---|---|
| スライスを制御できない | ビューは保存されたとおりに読み取られ、行、列、ページの選択はできません。Anaplanのページセレクターは同期プレビューエンドポイントでのみ文書化されており、このステップが送信する大容量読み取りリクエストの本文では、エクスポートタイプ以外は指定できません。別のスライスを読み取るには、別の保存済みビューを作成してください（多くの場合、ブール型のラインアイテムとフィルターを使用します）。 |
| 宣言された型が適用されるのは、ラインアイテムが列にある場合のみ | ラインアイテムがビューの列軸にある場合、各データ列は、ラインアイテムに宣言されたAnaplanの形式（数値、テキスト、ブール、日付、時間期間、リスト）に従って型付けされて取り込まれます。ラインアイテムが行にある場合（通常の損益計算書レイアウト）や、ビューにまったく含まれていない場合、すべてのデータ列は名前付きの警告とともにテキストとして取り込まれます。1つのデータ列が多数のラインアイテム、つまり多数の形式にまたがる可能性があるのに対し、テーブルの列は1つの型しか持てないためです。 |
| ページセレクターの値は列として取り込まれない | ビューに保存されているページセレクターのメンバーはCSVヘッダーに含まれ、そこで消費されます。ターゲットテーブルの列としては表示されません。 |
| あいまいな数値は推測せずに拒否される | 数値と宣言された値のうち、桁区切りを含むもの、または単純な小数としてもヨーロッパ式の表記としても読めるもの（例: `1.234`）は、同じ列の別の値でどちらの読み方が正しいかが確定しない限り、解析されずに名前を挙げて拒否されます。この読み取りパスには、あいまいさを解消するためのロケールフィールドがありません。解析できた値は丸め誤差なしの完全な精度で取り込まれ、空白のセルは常に空の値として取り込まれます。 |
| 空のビューは警告とともに空として取り込まれる | フィルターに一致するデータがない保存済みビューは、ターゲットテーブルを空のテーブルで置き換え、警告を出します。これは失敗ではなく、通常の結果です。例外は、行軸にディメンションがないビューです。この場合、空の結果を照合するための行ラベルの角がないため、ステップはヘッダーの読み違いでテーブルが空になるリスクを避けるために拒否します。 |
| 読み取り専用 | Anaplanに書き戻されることはありません。 |
