## 説明

[Anaplan接続](/ja/guides/connections/anaplan/)を介して、保存された**Anaplan**ビューのデータを、Anaplanの大容量読み取りリクエストのパスで読み取ります。ビューは**保存されたとおりに**読み取られ、このステップでは行、列、ページを個別に選択することはできません。別のスライスを読み取るには、Anaplanで別のビューを保存してください。

このステップは、ステップメニューの**Anaplan**の下に表示されます。

このステップは、Integration APIを介してAnaplanに**クラウド直接**で到達します。オンプレミスエージェントを経由するパスはありません。

<Aside type="tip">
このコネクターは読み取り専用で、Basic（ユーザー名とパスワード）またはCA証明書の認証情報で認証します。[認証](/ja/guides/connections/anaplan/#認証)を参照してください。Anaplanのリクエスト予算はテナント全体で共有されるため、このステップのスケジュールは、ほかのAnaplanワークフローとずらしてください。[スケジュールに関する考慮事項](/ja/guides/connections/anaplan/#スケジュール上の考慮事項)を参照してください。
</Aside>

## 設定

### ソースとターゲット

| フィールド | 必須 | 備考 |
|---|---|---|
| Anaplan接続 | はい | 読み取りに使用する[Anaplan接続](/ja/guides/connections/anaplan/)です。 |
| 環境 | いいえ | **プロジェクト環境**（デフォルト）は、プロジェクトの接続環境を使用します。**固定環境**は、選択した環境を常に使用します。[ステップを1つの環境に固定する](/ja/guides/projects/managing-projects/#ステップを1つの環境に固定する)を参照してください。 |
| ワークスペース | いいえ | 接続に保存されているワークスペースIDを上書きします。接続からライブで検出するか、手入力します。 |
| モデル | いいえ | 接続に保存されているモデルIDを上書きします。ワークスペースを選択するとライブで検出されるか、手入力します。 |
| ビュー | はい | 読み取る、保存されたAnaplanビューです。モデルを選択するとライブで検出されるか、手入力します。 |
| ポーリング試行回数 | はい | デフォルトは120です。ステップが拒否する前に、読み取りリクエストの完了をポーリングする回数です。リクエストIDが示されます。2つ目のリクエストが黙って送信されることはありません。 |
| ポーリング間隔（秒） | はい | デフォルトは5です。ポーリング間の待機秒数です。 |
| ターゲットテーブル | はい | 返されたビューを取り込むテーブルです。 |

## プレビュー

**ソース**タブの**プレビュー**は、ステップを実行せずに、このビュー読み取りで生成される列とデータ型を表示します。ロックされたプロジェクトでは利用できません。

## このステップで表現できないこと

| 制限事項 | 意味 |
|---|---|
| スライスの制御ができない | ビューは保存されたとおりに読み取られ、行、列、ページの選択はできません。Anaplanのページセレクターは、同期プレビューのエンドポイントでのみ文書化されています。このステップが送信する大容量読み取りリクエストの本文は、エクスポートタイプだけを受け取ります。別のスライスを読み取るには、別の保存済みビューを作成してください（多くの場合、ブール値のラインアイテムとフィルターを組み合わせます）。 |
| 宣言された型が取り込まれるのは、ラインアイテムが列にある場合のみ | ビューの列軸にラインアイテムがある場合、各データ列は、そのラインアイテムで宣言されたAnaplanの形式（数値、テキスト、ブール値、日付、時間期間、リスト）に基づく型で取り込まれます。ラインアイテムが行にある場合（一般的な損益計算書のレイアウト）、またはビューにまったく含まれない場合は、代わりにすべてのデータ列がテキストとして取り込まれ、名前付きの警告が表示されます。データ列が多数のラインアイテム、つまり多数の形式にまたがる可能性がある一方で、テーブルの列は1つの型しか保持できないためです。 |
| ページセレクターの値は列として取り込まれない | ビューに保存されているページセレクターのメンバーはCSVヘッダーに含まれ、そこで消費されます。ターゲットテーブルの列としては表示されません。 |
| あいまいな数値は、推測せずに拒否される | 桁区切り記号を含む数値宣言の値や、通常の小数としてもヨーロッパ式の表記（例: `1.234`）としても同様に読める値は、解析されず、名前を示して拒否されます。ただし、同じ列の別の値によって、どちらの読み方が正しいかが決まる場合は除きます。この読み取りパスには、あいまいさを解決するためのロケールフィールドがありません。解析できた値は、丸め誤差なしの完全な精度で取り込まれ、空白のセルは常に空の値として取り込まれます。 |
| 空のビューは警告付きで空のまま取り込まれる | フィルターに一致するものがない保存済みビューは、ターゲットテーブルを空のテーブルに置き換えて警告します。これは通常の結果であり、失敗ではありません。例外は、行軸にディメンションがないビューです。空の結果を検証するための行ラベルの角がないため、ヘッダーの読み取りミスでテーブルを空にしてしまうリスクを避けるため、ステップは拒否します。 |
| 読み取り専用 | Anaplanには何も書き戻されません。 |
