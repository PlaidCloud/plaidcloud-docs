## 説明


Analyze のデータテーブルを、JSON ファイルとして PlaidCloud Document にエクスポートします。データの向きについては、以下に示すいくつかのオプションがあります。



JSON ファイルの詳細については、JSON の公式サイト（http://json.org/）を参照してください。


<Aside>JSON ファイルでは、列の順序は保持され*ません*。ソースのデータテーブルの列の順序が、エクスポートされるファイルの列の順序と一致するとは限りません。</Aside>

### JSONの向き


次のデータセットを例にします。




| ID |  Name  | Gender | State |
|----|--------|--------|-------|
| 1  | Jack   |   M    |   MO  |
| 2  | Jill   |   F    |   MO  |
| 3  | George |   M    |   VA  |
| 4  | Abe    |   M    |   KY  |

JSON ファイルは、次の 4 つのデータ形式のいずれかでエクスポートできます。


* Records: データは Python のディクショナリとして保存され、各行は \{Column -> Value, …} の形式で保存されます。例: **[\{“ID”:1,”Name”:”Jack”,”Gender”:”M”,”State”:”MO”},\{“ID”:2,”Name”:”Jill”,”Gender”:”F”,”State”:”MO”},\{“ID”:3,”Name”:”George”,”Gender”:”M”,”State”:”VA”},\{“ID”:4,”Name”:”Abe”,”Gender”:”M”,”State”:”KY”}]**
* Index: データは入れ子の Python ディクショナリとして保存され、各行は \{Index -> \{Column -> Value, …},…} の形式で保存されます。例: **\{“0”:\{“ID”:1,”Name”:”Jack”,”Gender”:”M”,”State”:”MO”},”1”:\{“ID”:2,”Name”:”Jill”,”Gender”:”F”,”State”:”MO”},”2”:\{“ID”:3,”Name”:”George”,”Gender”:”M”,”State”:”VA”},”3”:\{“ID”:4,”Name”:”Abe”,”Gender”:”M”,”State”:”KY”}}**
* Split: データは単一の Python ディクショナリとして保存され、値はリストに格納されます。例: **\{“columns”:[“ID”,”Name”,”Gender”,”State”],”index”:[0,1,2,3],”data”:[[1,”Jack”,”M”,”MO”],[2,”Jill”,”F”,”MO”],[3,”George”,”M”,”VA”],[4,”Abe”,”M”,”KY”]]}**
* Values: データは複数の Python リストとして保存されます。例: **[[1,”Jack”,”M”,”MO”],[2,”Jill”,”F”,”MO”],[3,”George”,”M”,”VA”],[4,”Abe”,”M”,”KY”]]**


### 日付の処理


ドロップダウンメニューで **日付形式** を指定します。次の形式から選択します。


* **Epoch (Unix Timestamp – Seconds since 1/1/1970)**
* **ISO 8601 Format (YYYY-MM-DD HH:MM:SS with timeproject offset)**

ドロップダウンメニューで **日付の単位** を指定します。次の形式から選択します。精度の低い順に並んでいます。


* **秒（s）**
* **ミリ秒（ms）**
* **マイクロ秒（us）**
* **ナノ秒（ns）**

### ASCIIを強制


このチェックボックスを選択すると、すべての文字列が正しい ASCII 形式でエンコードされます。これはデフォルトで有効になっています。



### 出力ファイルタイプ


エクスポートされるファイルはすべて非圧縮ですが、次の圧縮オプションを利用できます。


* Zip
* GZip
* BZip2


### 追加設定

* **ファイルが存在する場合** の **すでに存在するファイル**（`if_exists`）— **上書きする**（`overwrite`、デフォルト）は、すでにあるファイルを置き換えます。**何も書き込まずにステップを失敗させる**（`fail`）は、書き込もうとするファイルがすでに存在する場合に、何も書き込まずにステップを停止します。
* **行の順序** の **行の並べ替え**（`sort_columns`）— 書き込む行を、指定したソース列の順に並べ替えます。最初のキーが優先され、各キーに **列**、**昇順**、**NULL 値** を設定します。キー列は書き込まれる列でなくてもかまいません。**NULL 値** のデフォルトは、昇順では先頭、降順では末尾です。**集計** または **重複排除** と併用することはできません。
