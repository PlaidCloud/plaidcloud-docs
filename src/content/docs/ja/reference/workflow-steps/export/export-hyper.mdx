## 説明

**Tableau Hyper Export**ステップは、テーブルをTableau Hyperファイルにエクスポートします。ワークフローエンジン内で実行され、パッケージ化マクロの結果はAlteryxマクロの近似です。

## パラメーター

- **ソーステーブル**と**出力ファイルパス**。

ソーステーブルが存在しない、または列がマッピングされていないときに列がない場合、ステップは成功し、何も書き込まず、ソースと出力ファイルの名前を示す警告をログに記録します。行のないソースは空の抽出ファイルを書き込み、その旨の警告をログに記録します。
