## 説明

**Tableau Hyper Export**ステップは、テーブルをTableau Hyperファイルにエクスポートします。ワークフローエンジン内で実行され、パッケージ化マクロの結果はAlteryxマクロの近似です。

## パラメーター

- **ソーステーブル**と**出力ファイルパス**。

Tableau Hyperライターはワークフローエンジンでは利用できないため、代わりにCSVが書き込まれます（機能のダウングレード）。
