## 説明



PlaidCloud のテーブルを、PlaidCloud ネイティブのアーカイブファイルとしてドキュメントアカウントに書き込みます。アーカイブには、PlaidCloud が把握しているすべての列の型、インデックス、メタデータが保持されます。PlaidCloud のプロジェクト間や環境間でやり取りする場合、CSV より忠実度が高くなります。

アーカイブをプロジェクトに戻すには、[アーカイブのインポート](/ja/reference/workflow-steps/import/import-archive/)と組み合わせて使用します。バックアップ、プロジェクト間の移行、環境間のデータ転送に便利です。
