## 説明


Analyze のデータテーブルを、Google スプレッドシートとして Google ドライブにエクスポートします。この変換を使用するには、有効な Google アカウントが必要です。変換を使用する前に、PlaidCloud Tools でユーザーの認証情報を設定しておく必要があります。



## エクスポートパラメーター


### ソースとターゲット


ドロップダウンメニューから、PlaidCloud Document の **ソーステーブル** を選択します。



次に、**ターゲット接続** の情報を指定します。Google ドキュメントのアカウント接続の設定方法については、[PlaidCloud Tools – 接続](/ja/reference/connectors/) を参照してください。必要なアカウントをすべて設定したら、ドロップダウンリストから該当するアカウントを選択します。



最後に、**ターゲットスプレッドシート名** と **ターゲットワークシート名** を入力します。必要に応じて、**既存のワークシートデータに追加する** チェックボックスを選択すると、既存のワークシートにデータを追加します。ターゲットワークシートがまだ存在しない場合は、作成されます。



まだ存在しないスプレッドシートは作成され、存在しないワークシートも同様に作成されます。アカウント内の複数のスプレッドシートが同じ **ターゲットスプレッドシート名** を持っている場合は拒否されます。名前が一意になるよう、重複しているスプレッドシートの名前を変更してください。値は入力されたとおりに書き込まれるため、`=` で始まるテキストセルはテキストのままで、数式にはなりません。**既存のワークシートデータに追加する** をオフにすると、行を書き込む前に、ワークシートがクリアされ、テーブルのサイズに合わせて変更されます。
