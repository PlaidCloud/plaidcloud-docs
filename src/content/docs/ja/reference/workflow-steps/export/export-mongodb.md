## 説明

プロジェクトテーブルの各行を、ドキュメントとしてMongoDBコレクションに書き込みます。コレクションが存在しない場合は作成されます。このステップは、[MongoDB接続](/ja/reference/connectors/databases/mongodb/)を通じてMongoDBに接続します。

## ソースとターゲット

| 設定 | 必須 | 内容 |
| --- | --- | --- |
| ソーステーブル | はい | 書き込むテーブルです。 |
| MongoDB接続 | はい | 書き込みに使用する接続です。 |
| データベース | いいえ | 書き込み先のデータベースです。空欄にすると、接続の**デフォルトのデータベース**が使用されます。 |
| コレクション | はい | 書き込み先のコレクションです。 |

## 書き込みオプション

| 設定 | 内容 |
| --- | --- |
| 書き込みモード | **行ごとにドキュメントを挿入**（デフォルト）、**一致するドキュメントを置換**、**一致するドキュメントのフィールドを更新**、**一致するドキュメントを置換、なければ挿入**、**一致するドキュメントのフィールドを更新、なければ挿入**のいずれかです。 |
| 照合列 | ドキュメントを特定する列を、カンマ区切りで指定します。挿入以外のすべてのモードで必須です。 |
| 書き込み前にコレクション内のすべてのドキュメントを削除する | 先にコレクションを空にして、今回の実行の行だけが入った状態にします。 |
| 最初の書き込み失敗で停止 | MongoDBが最初に拒否したドキュメントで停止します。オフにすると、残りの処理を続行します。 |
| 書き込みがジャーナルに到達するまで待機する | MongoDBが各バッチをジャーナルに書き込むまで待機します。 |
| Write Concern | 空欄にすると接続の設定を使用します。サーバー数、または `majority` を指定できます。 |
| リクエストあたりのドキュメント数 | 1回のリクエストで送信するドキュメントの数です。 |

挿入では、ステップを実行するたびにドキュメントが再び追加されます。置換または更新のモードでは、ステップを何回実行しても、コレクションの状態は同じです。ワークフローが同じ行に対して2回実行される可能性がある場合は、これらのモードのいずれかを使用してください。
