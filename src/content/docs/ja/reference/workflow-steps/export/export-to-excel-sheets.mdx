## 説明

複数のプロジェクトテーブルを、1つのMicrosoft Excelブックの別々のシートに書き込みます。このとき、書式設定されたテンプレートの書式は保持されます。各テーブルは、名前を付けた1つのシートを埋めます。ブック全体はテンプレートから1回だけ作成され、1回の処理でレンダリングされます。そのため、出力ファイルを共有する単一シートのエクスポートを別々に実行した場合のように、シートが互いに上書きされることはありません。

1つのブックに複数の結果シートを持たせる必要がある場合に、このステップを使用します。たとえば、データシート、サマリーシート、パラメーターシートを持つ、書式設定されたレポートテンプレートです。単一のシートや、書式のない通常のブックには、代わりに[Export to Excel](/ja/reference/workflow-steps/export/export-to-excel/)を使用してください。

テンプレートの書式は、書き込まれる各シートに引き継がれます。対象は、値、数値書式、フォント、塗りつぶし、罫線、セルの結合、列幅です。ピボットテーブルやグラフを含むテンプレートでは、シートが書き込まれる際にそれらのオブジェクトは失われます。書き込みでは再現されません。

## エクスポートパラメーター

### 出力ファイル

ブックの書き込み先となるドキュメントアカウントとフォルダーと、ブックの**ファイル名**です。

### テンプレートファイル

ブックの作成元となる書式設定されたテンプレートです。書き込まれるすべてのシートが書式を引き継ぐ、既存の `.xlsx` ファイルのドキュメントアカウントとパスを指定します。テンプレートを指定しない場合、出力ファイルがすでに存在すれば、ステップはそれを元に作成します。

### 圧縮

ブックは、デフォルトでは非圧縮で書き込まれます。Zip、GZip、BZip2による圧縮を使用できます。

## シート

**シート**テーブルの各エントリが、ブック内の1つのワークシートを埋めます。

| フィールド | 目的 |
| --- | --- |
| ソース | シートの行を提供するプロジェクトテーブルです。 |
| ターゲットシート | 埋める、テンプレート内のシートです。 |
| 範囲 | A1形式の範囲（例：`A1:S1000000`）を任意で指定します。テーブルが書き込まれる前にこの範囲の既存の値がクリアされ、その周囲のテンプレートのセルには手が加えられません。 |
| ヘッダーを書き込む | 列名のヘッダー行を書き込むかどうかです。デフォルトでオンです。 |
| 列 | ソーステーブルのすべての列ではなく、一部の列を書き込む場合に、書き込む列を順序どおりに指定します。 |

フォームには、次のフィールドもあります。

* **既存のブック**（`if_exists`）— **何も書き込まずにステップを失敗させる**（`fail`）は、ブックがすでに存在する場合にステップを停止します。デフォルトの**シートを書き込む**（`replace`）は、書き込みを行います。
* シートのエントリでは、**行の並べ替え**（`sort_columns`）が、書き込まれる行をこれらのソース列で並べ替えます。最初のキーが優先され、それぞれに**列**、**昇順**、**NULL 値**の設定があります。**欠損セルの値**（`null_as`）は、シートの欠損しているすべてのセル（数値列を含む）に書き込まれるテキストです。**既存のシート**（`if_sheet_exists`）は、ブックにすでにそのシートがある場合の動作を決めます。**ステップを失敗させる**（`fail`）はステップを停止し、**そのままにする**（`skip`）はそのシートをそのまま残します。

## サイズの制限

各シートには、単一シートのエクスポートと同じExcelの制限が適用されます。最大1,048,576行（ヘッダー行も含む）と、16,384列です。これを超えるシートは、Excelで開けないファイルが生成されるのではなく、ステップが停止します。これを超えるサイズのデータには、代わりにCSVまたはParquetにエクスポートしてください。
