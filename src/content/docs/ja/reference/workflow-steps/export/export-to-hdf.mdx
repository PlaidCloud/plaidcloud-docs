## 説明


Analyze のデータテーブルを、HDF5 ファイルとして PlaidCloud Document にエクスポートします。


HDF5 ファイルの詳細については、HDF Group の公式サイト（http://www.hdfgroup.org/HDF5/）を参照してください。

<SnippetCommonExportFileSelection />



### 出力ファイルタイプ


エクスポートされるファイルはすべて非圧縮ですが、次の圧縮オプションを利用できます。


* Zip
* GZip
* BZip2
