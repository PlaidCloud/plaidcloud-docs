## 説明



PlaidCloudのプロジェクトテーブルを、CREATE TABLE文とINSERT文を含むSQLファイルとして、ドキュメントアカウントに書き込みます。CSVやParquetではなく、SQLスクリプトを取り込むシステムにデータを引き渡す必要がある場合に便利です。

リモートデータベースに直接読み込む場合は、代わりに適切なデータベースのエクスポートステップまたは[エージェントのリモートインポート](/ja/reference/workflow-steps/agent/agent-remote-import-table-into-sql-database/)を使用してください。その方が高速で、中間ファイルも不要です。

## プレビュー

**プレビュー**は、ステップがソーステーブルから読み取るクエリの最大100行を、実行せずに表示します。**ソース**タブで**プレビュー**をクリックします。行がそれ以上ある場合、プレビューには最初の行のみが表示されていること、すべてを読み取るにはステップを実行する必要があることが表示されます。プレビューは、実行時と同じ方法で変数を埋め込みますが、`{x:>9}`のような変数の書式指定には対応していません。

プレビューはデータの読み取りのみを行います。プレビューが読み取り専用かどうかをチェックできない関数がクエリで使用されている場合は、*Preview only supports standard SQL functions. Run the step to see results.* と表示されます。結果を確認するには、ステップを実行してください。プレビューは、ロックされたプロジェクトでは利用できません。

## 追加設定

**行の順序**の**行の並べ替え**（`sort_columns`）は、書き込まれる行を、これらのソース列の順に並べ替えます。最初のキーが優先され、それぞれに**列**、**昇順**、**NULL 値**の設定があります。キー列は書き込まれなくても構いません。**NULL 値**は、昇順では先頭、降順では末尾がデフォルトです。**集計**や**重複排除**とは併用できません。
