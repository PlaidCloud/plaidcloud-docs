## 説明

プロジェクトの完全なアーカイブ（ワークフロー、テーブル定義、ディメンション、変数、設定）を、単一のファイルとしてドキュメントアカウントに書き込みます。大きな変更の前の時点バックアップや、プロジェクトを別のワークスペースに引き渡す場合に使用します。

これはデータだけでなく、*プロジェクト*をアーカイブします。テーブルデータのみが対象の場合は、[Export to Table Archiveステップ](/ja/reference/workflow-steps/export/export-to-table-archive/)を使用してください。

## 固有の設定項目

### エクスポート先のディレクトリとファイル名

- **エクスポート先ディレクトリ** — アーカイブの書き込み先となるドキュメントアカウントとフォルダーです。
- **ターゲットファイル** — アーカイブのファイル名です。
