## 説明



PlaidCloudのプロジェクトテーブルを、CSV（カンマ区切り値）ファイルとして、ドキュメントアカウントに書き込みます。最も一般的なエクスポート形式で、ほぼすべての下流システム、表計算ツール、BIプラットフォームでサポートされています。

区切り文字（カンマ、タブ、パイプ、カスタム）、引用符の扱い、ヘッダー行、エンコードを設定できます。

#### 区切り文字
Export CSV変換は、データテーブルを、PlaidCloudドキュメントに保存される区切りテキストファイルにエクスポートするために使用します。区切り文字の種類には、次のものがありますが、これらに限りません。


* Excel CSV（カンマ区切り）
* Excel TSV（タブ区切り）
* ユーザー定義の区切り文字 –>


	+ カンマ（,）
	+ パイプ（|）
	+ セミコロン（;）
	+ タブ
	+ スペース（ ）
	+ その他/カスタム（チルダ、ダッシュなど）

カスタムの区切り文字を指定するには、**ユーザー定義の区切り文字 –>** を選択し、続けて**その他 –>** を選択して、テキストボックスにカスタムの区切り文字を入力します。


#### 特殊文字

**特殊文字**セクションでは、引用符やエスケープ文字を含むデータの扱いを指定できます。次の設定から選択します。

* 特殊文字（QUOTE_MINIMAL）：特殊文字を含むフィールドを引用符で囲みます（同じダイアレクトとオプションで構成されたパーサーが混乱する可能性のあるものすべて）。これがデフォルトの設定です。
* すべて（QUOTE_ALL）：型に関係なく、すべてを引用符で囲みます。
* 非数値（QUOTE_NONNUMERIC）：整数または浮動小数点数ではないすべてのフィールドを引用符で囲みます。リーダーで使用すると、引用符で囲まれていない入力フィールドは、浮動小数点数に変換されます。
* なし（QUOTE_NONE）：出力では何も引用符で囲みません。引用符は、ユーザーが指定したエスケープ文字とともに出力に含まれます。指定できるエスケープ文字は1つだけです。

デフォルトでは、引用符で囲まれたフィールド内の引用符は、二重にして書き込まれます（`""`）。代わりにエスケープ文字を使って書き込むには、`escape_quotes` をオンにします。これはSparkと同じ動作です。エスケープ文字が `\` の場合、フィールド `say "hi"` は `"say \"hi\""` として書き込まれます。この設定はデフォルトでオフのため、既存のエクスポートは変わりません。

引用符文字を含む値は、デフォルトでは、それだけの理由で引用符で囲まれます。`escapeQuotes` をオフにしたSparkと同じように、そのような値を周囲に引用符を付けずに書き込むには、**引用符文字を含む値を引用符で囲む**をオフにします。区切り文字や改行を含む値は、引き続き引用符で囲まれます。このチェックボックスはデフォルトでオンです。オフにすると、ファイルはウェアハウスではなくPlaidCloudによって書き込まれます。

**引用符文字**を空にすると、すべての値がそのまま書き込まれます。何も引用符で囲まれず、何もエスケープされません。区切り文字や改行を含む値は、読み戻したときに複数のフィールドとして読み取られるため、データに含まれない区切り文字を選んでください。

#### 先頭行にヘッダーを書き込む
このチェックボックスをオンにすると、テーブルのヘッダーが先頭行にエクスポートされます。オフにすると、エクスポートされるファイルにヘッダーは含まれません。

#### ヘッダーにデータ型を含める
このチェックボックスをオンにすると、エクスポートされるファイルのヘッダーに、列のデータ型が含まれます。

#### Windowsの改行コード

最後に、**Use Windows Compatible Line Endings**チェックボックスは、Windowsシステムとの互換性を確保するため、デフォルトでオンになっています。UNIX専用の環境で作業する場合を除き、この設定はオンのままにしておくことをお勧めします。




### ファイルが存在する場合

**その他の CSV オプション**の**すでに存在するファイル**（`if_exists`）は、ファイルがすでに存在する場合の動作を決めます。`replace`（デフォルト）は新しいファイルを書き込み、`append` はヘッダー行なしで既存ファイルの末尾に行を追加し、`fail` はステップを停止して何も書き込みません。追加では、ファイルをダウンロードして行を追加し、再びアップロードするため、2つの実行が同時に同じファイルに追加する場合は、最後に終了した実行が優先されます。`append` では、**既存の行の下にヘッダーをもう一度書き込む**（`header_on_append`）を選択すると、すでにある行の下にヘッダー行をもう一度書き込みます。

### 追加設定

**その他の CSV オプション**には、次のフィールドもあります。

* **行の並べ替え**（`sort_columns`）— 書き込まれる行を、これらのソース列で並べ替えます。最初のキーが優先され、それぞれに**列**、**昇順**、**NULL 値**の設定があります。キー列は書き込まなくてもかまいません。**NULL 値**は、昇順では先頭、降順では末尾がデフォルトです。**集計**または**重複排除**とは併用できません。
* **改行コード**（`line_ending`）— すべての行の改行コードで、`\n`、`\r\n`、`\r` のいずれかです。**Use Windows Compatible Line Endings**の代わりに使用します。
* **引用符で囲む**（`quote_mode`）— 引用符で囲む値を指定します。**なし**、**常に**、**数値とブール値以外のすべての値**、**区切り文字を含む値**のいずれかです。デフォルトでは、必要な場合に値が引用符で囲まれます。
* **終了引用符**（`quote_end`）— 開始の引用符と異なる場合の、終了の引用符です。
* **値内の終了引用符**（`quote_replacement`）— 引用符で囲まれた値の中にある終了引用符の代わりに書き込まれます。空のままにすると、引用符が二重になります。
* **値内の区切り文字**（`delimiter_replacement`）— **引用符で囲む**を**なし**に設定した場合に、値の中の区切り文字の代わりに書き込まれます。
* **ファイルの先頭にバイト順マークを付ける**（`write_bom`）— ファイルの先頭にバイト順マークを付けます。
* **Write decimal numbers as Java does**（`scientific_numbers`）— 1,000万以上および0.001未満の10進数を、`1.0E10` のような科学表記で書き込みます。
* **.csv や .tsv を付けずに、各ファイル名を指定どおりに書き込む**（`keep_file_extension`）— 各ファイル名を、指定したとおりに書き込みます。
* **gzip の場合、.gz を付けずに指定した名前でファイルを保存する**（`exact_file_name`）— gzip圧縮の場合に、指定した名前のままでファイルを保存します。
* **小数点記号**（`decimal_separator`）— 数値の小数点として書き込まれる文字です。
* **ヘッダーの前の行**（`comment_lines`）— ヘッダーの前にそのまま書き込まれる行の、JSON配列です。
