## 説明

**Publish to Tableau** ステップは、`.hyper` エクストラクトをデータソースとして Tableau Server または Tableau Cloud に公開します。まず [Tableau Hyper Export](/ja/reference/workflow-steps/export/export-hyper/) ステップでエクストラクトを書き出し、次にこのステップで公開します。このステップは、[Tableau 接続](/ja/reference/connectors/collaboration/tableau/)のパーソナルアクセストークンでサインインし、ファイルをチャンクに分けてアップロードするため、1 回のリクエストでファイルサイズが制限されることはありません。アップロード後はサインアウトします。

エクストラクトファイルが見つからない場合もエラーにはなりません。ステップは何も公開されなかったことを警告し、ワークフローは続行されます。

## パラメーター

- **Hyperエクストラクト** — 公開する、ドキュメントアカウント内の `.hyper` ファイルです。
- **Tableau接続** — 公開に使用する Tableau 接続です。
- **データソース名** — Tableau でのデータソースの名前です。空白のままにすると、拡張子を除いたエクストラクトのファイル名が使用されます。
- **プロジェクト** — 公開先の Tableau プロジェクトです。空白のままにすると、サイトのデフォルトプロジェクトが使用されます。サイトに存在しないプロジェクト名を指定すると、ステップは失敗します。
- **データソースが存在する場合** — 公開モードです。[モード](#モード)を参照してください。
- **照合キー** — 行を照合する列を、カンマ区切りのリストで指定します。**アップサート**、**更新**、**一致する行の置換** では必須です。

## モード

| モード | データソースが存在する場合 | 存在しない場合 |
| --- | --- | --- |
| **新規作成** | ステップは失敗します。 | 作成します。 |
| **上書き** | 置き換えます。 | 作成します。 |
| **追加** | エクストラクトの行を追加します。 | 作成します。 |
| **アップサート** | 照合キーが一致する行を更新し、残りを追加します。 | 作成します。 |
| **更新** | 照合キーが一致する行を更新し、追加は行いません。 | 警告を出し、何も変更しません。 |
| **グループ置換** | 照合キーが一致する行を削除してから、エクストラクトの行を挿入します。 | 作成します。 |

**追加**、**アップサート**、**更新**、**グループ置換** は、選択したプロジェクト内で（何も選択していない場合はサイトのデフォルトプロジェクト内で）名前でデータソースを検索し、検索したプロジェクトに公開します。キーを使用するモードは、Tableau のデータ更新アクションを通じて、データソースの行をその場で変更します。

## 要件

- 接続のサーバーアドレスは `https` を使用する必要があります。`http` で指定されたサーバーでは、パーソナルアクセストークンが暗号化されずにネットワークを流れることになるため、ステップは失敗します。ホスト名のみの場合は `https` として扱われます。
- サーバーにはインターネットからアクセスできる必要があります。PlaidCloud は、プライベートネットワーク上の Tableau サーバーには公開しません。
- パーソナルアクセストークンの所有者には、プロジェクトに公開する権限が必要です。
