## 説明



PlaidCloudのテーブルを、Quandl（NASDAQ Data Link）のデータベースにプッシュします。主に、Quandlで公開データセットを管理していて、PlaidCloudのワークフローからそれらを更新したい組織向けです。

Quandl APIの認証情報と、Quandl側で書き込みアクセスが設定されたターゲットデータベースが必要です。


## ソースとターゲット


次のパラメーターを指定します。


* **ソーステーブル**：エクスポートするAnalyzeのデータテーブル
* **Quandl Connection**：Quandlのデータセットにアクセスするには、ユーザーアカウント、またはアクセスが制限されたゲストアカウントが必要です。これにはツールでの設定が必要です。Quandlアカウント接続の設定方法の詳細は、こちらを参照してください：[PlaidCloud Tools – Connection](/ja/reference/connectors/)
* **Quandl Code**：**検索**ボタンを使用してデータセットを検索します。データセットを手動で入力することもできます。その場合は、「[http://www.quandl.com](http://www.quandl.com/)」より後ろのURLの部分を入力する必要があります。たとえば、Microsoftの株式のデータセット（http://www.quandl.com/GOOG/NASDAQ_MSFT にあります）をインポートするには、Quandl Codeフィールドに *GOOG/NASDAQ_MSFT* と入力します
* **Dataset Name**：Quandlにエクスポートするデータセットの名前
* **Dataset Description**：Quandlにエクスポートするデータセットの説明
