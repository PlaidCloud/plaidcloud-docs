## 説明

**ERP: 伝票を転記** は、1つのテーブル内のドキュメントを、[転記レジスター](/ja/guides/connections/posting-register/)で設定されたERPシステムに転記します。このステップではシステムを指定しません。各ドキュメントは、そのエンティティの振り分け先のシステムに送られます（[転記用にERPシステムを設定する](/ja/guides/connections/erp-systems/)を参照）。送信、保留、または停止したすべてのドキュメントは、転記レジスターに記録されます。

何かが送信されるかどうかは、実行の[転記モード](/ja/guides/workflows/run-a-workflow/#転記モードの選択)と、システム自身のモードによって決まります。シミュレートで転記されたドキュメントはチェックされて **転記予定** として記録され、ERPには何も送信されません。このステップには、独自のValidate Only設定はありません。

テーブルの作成方法、シミュレートと本番での実行、実行後の操作については、[ERPシステムに伝票を転記する](/ja/guides/connections/post-documents/)を参照してください。

## 構成

**一般** タブには、3つのセクションと **詳細 ▸** リンクがあります。

- **1 · テーブル** — 転記する **テーブル**。1行が1明細で、`entity` と `doc_number` が同じ行は1つのドキュメントです。ドキュメントは、実行の開始時に固定されます。
- **2 · 列の対応付け** — テーブルの各列がドキュメントのフィールドにどのように対応付けられたか。**名前で一致**、**別名で一致**、または **これを選択しました** です。ステップが認識できない列については、何として使用するかを選択します。
- **3 · 最初の伝票(システムが受け取る形式)** — 最初のドキュメント、そのシステム、明細のプレビュー、テーブルにない列にシステムが指定する固定値、またはまだ作成できない理由。

**詳細 ▸** を開くと、4つの設定が表示されます。

- **担当者の確認待ちにする** — **金額が次の値を超える** 場合、**異常としてフラグ付けされている** 場合、または **常に**、ドキュメントを承認待ちとして保留します。何もチェックしない場合、ここでは何も保留されません。ここでの保留は、システムがすでに保留しているものに追加されるだけです。
- **通知先** — 対応が必要なものがあるときに通知する、**実行を開始した人** または **ユーザーのリスト…**。
- **丸め勘定と上限** — **不均衡な伝票に丸め明細を追加する**。**勘定科目** と **上限** を指定します。チェックを外すと、丸めは行われません。
- **転記済み伝票が変更されて戻ってきたとき** — 確認する（デフォルト：ドキュメントは、2つの選択肢とともに「要対応」に入ります）、または訂正する（取り消して新しいバージョンを転記します。毎期間再実行するステップ向けです）。

ソーステーブルが存在しない、または列や行がない場合はエラーにはなりません。ステップは警告付きで終了し、何も転記しません。
