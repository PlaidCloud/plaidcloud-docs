## 説明

[接続](/ja/reference/connectors/)を通じて、ファイルではなく外部データベースにプロジェクトテーブルを書き込みます。モデリングした結果を、レポート用データベース、データウェアハウス、または基幹システムに書き戻すために使用します。

[外部データベーステーブルのインポート](/ja/reference/workflow-steps/import/import-external-database-tables/)の対となるステップです。1つのステップで複数のテーブルを移動でき、ターゲットテーブルは明示的に選択することも、検索パターンで照合することもできます。

## 固有の設定項目

### 接続

ターゲットデータベースを示すデータ接続です。

### エクスポートタイプ

行を書き込む前に、各ターゲットテーブルをどのように準備するかを指定します。

- **追加のみ** — 既存のテーブルに行を追加します。テーブルが存在しない場合は失敗します。
- **切り捨てて追加** — テーブルを空にして、構造は維持したまま書き込みます。
- **作成して追加** — テーブルがない場合は作成してから、書き込みます。
- **ドロップ、作成して追加** — テーブルをドロップして再作成してから、書き込みます。ソースのスキーマが変更された場合に使用します。

### フレーム名

ステップが実行されるフレームの名前です。

### ターゲットの追加

ターゲットの追加と削除のボタンを使用して、ターゲットテーブルの一覧を作成します。ターゲットを選択すると、右ペインで設定でき、**選択項目を切り替え**で、選択したターゲットのエクスポートを有効または無効にできます。エクスポートでは、ターゲットデータベース内のテーブルはスキャンされません。各ターゲットを自分で追加してください。外部データベース内のテーブルを検出するステップは、[外部データベーステーブルのインポート](/ja/reference/workflow-steps/import/import-external-database-tables/)です。

### ターゲットのタブ

選択したターゲットには3つのタブがあります。

#### ソースとターゲット

エクスポートするプロジェクトテーブルと、その書き込み先を選択します。

- **ソース** — **特定のテーブル**は1つのプロジェクトテーブルを名前で指定し、実行時に名前が変わる場合は**動的**オプションを使用します。**検索に一致するテーブル**は、**検索パス**と**検索テキスト**で見つかったすべてのプロジェクトテーブルを、**完全一致**、**次で始まる**、**含む**、**次で終わる**のいずれかで照合してエクスポートします。
- **ターゲット外部テーブル** — **エクスポートを有効にする**で、ターゲットのオンとオフを切り替えます。**ターゲットスキーマ**と**ターゲットテーブル**で、書き込み先のテーブルを指定します。**ソーステーブルと同じ名前を使用**は、各ソーステーブルの名前をそのまま使用します。

#### テーブルデータの選択

ターゲット用の列マッパーで、専用の全高タブにあります。**ソースを検査**は、プロジェクトのソーステーブルの列をマッパーに読み込みます。

#### データフィルター

ターゲットに書き込む行を絞り込みます。
