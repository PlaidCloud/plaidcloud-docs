## 説明



PlaidCloud の配布グループ（ワークスペース設定で管理される、名前付きの受信者リスト）にメール通知を送信します。ステータスの更新、完了通知、エラーアラートなど、特定の相手に届ける必要がある場合に便利です。

メッセージは PlaidCloud の通知サービスから送信されます。配布グループは一元管理されるため、ワークフローの作成者がワークフロー定義にメールアドレスを埋め込む必要はありません。


## PlaidCloud の配布リストを選択


ドロップダウンメニューから配布リストを 1 つ選択します。配布リストは「ツール」で作成できます。配布リストの作成方法については、[PlaidCloud ツール – 配布リスト](/ja/administration/access/member-management/#配布リストディストロの管理)を参照してください。



## メッセージ


必要に応じて**件名**と**本文**を指定します。



このトランスフォームでは、件名と本文の両方で、プロジェクト変数とワークフロー変数の両方を使用できます（ご注意）。



また、メッセージの見た目をカスタマイズするために、本文には標準的な HTML コードを使用できます。


## 例


この例では、すべてのシステム変数を使用しています。さらに、本文の 1 行目の書式設定に少量の HTML を使用しています。このトランスフォームを実行すると、配布グループに指定されたすべてのメンバーに次のメールが送信されます。


* 差出人: [info@tartansolutions.com](mailto:info%40tartansolutions.com)（すべてのメッセージはこのアドレスから送信されます）
* 件名: DEMO Analyze Demo Running


<Aside>メールの各受信者には、配布リスト上の他のメンバーの名前は**表示されません**。</Aside>
