## 説明



Webhook URL に POST して通知を送信します。独自の下流アクションのトリガー、連携プラットフォーム（Zapier、n8n、Make）へのアラート、標準のコネクターを使用しない Slack/Teams/Discord ボットの駆動に便利です。

ペイロードの形式とカスタムヘッダーは設定可能です。その後の処理は受信側のサービスが担当します。
