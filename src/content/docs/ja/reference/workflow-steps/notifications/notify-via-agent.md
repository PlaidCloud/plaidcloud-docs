## 説明



PlaidLink エージェント経由で通知をトリガーします。PlaidCloud から直接到達できないオンプレミスのシステム（社内のアラート、社内ウェブフック、レガシー SMTP など）を通じて通知を配信する必要がある場合に便利です。

エージェントは通知ペイロードを受け取り、その設定に従ってローカルで送信します。
