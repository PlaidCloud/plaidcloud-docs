## 説明


メール通知を送信します。メッセージは *[info@tartansolutions.com](mailto:info@tartansolutions.com)* のメールアカウントから送信されます。送信側の設定は不要です。



### メールアドレス


任意の数の受信者を指定できます。区切り文字には、セミコロン（;）とカンマ（,）を使用できます。



### CC、BCC、返信先

**CC**（`cc_address`）、**BCC**（`bcc_address`）、**返信先**（`reply_to`）には、受信者と同じ形式のアドレスを指定でき、プロジェクト変数とワークフロー変数を使用できます。CC と BCC の受信者には同じメッセージが届き、返信は返信先のアドレスに送られます。これらはプレーン本文と Jinja テンプレート本文の両方に適用されます。**メッセージ**タブの**その他のメールオプション**で設定します。

### 行ごとに 1 通のメール

**その他のメールオプション**で、**送信**（`request_source`）を**テーブルの行ごとに 1 通のメール**（`table`）に設定し、**ドライバーテーブル**（`driver_table`）を選択すると、1 通のメールではなく、テーブルの行ごとに 1 通のメールを送信します。**メール送信する最大行数**（`row_limit`）は使用する行数の上限で、デフォルトは 10,000 です。ドライバーはビューではなくテーブルである必要があります。

宛先、件名、メッセージ、添付ファイルのパスで `{{row.column}}` を使用すると、各行の値が差し込まれます。ドライバーテーブルに存在しない列を指定すると、ステップは失敗します。宛先（To）アドレスのない行にはメールが送信されず、ステップはその行を示す警告とともに終了します。

行から差し込まれる添付ファイルのパス（`{{row.column}}`）は、フォルダーではなく、存在する 1 つのファイルでなければなりません。これにより、パスが誤って生成された行から他人のファイルが送信されることを防ぎます。そのパスの値が空の行、パスが `..` でフォルダーの外に出る行、ファイルが存在しない行は、添付ファイルなしで送信され、その行を示す警告が出力されます。行ごとの送信にはプレーン本文が必要で、Jinja テンプレート本文では利用できません。

### メッセージ


必要に応じて**件名**と**本文**を指定します。



このトランスフォームでは、件名と本文の両方で、プロジェクト変数とワークフロー変数の両方を使用できます（ご注意）。



また、メッセージの見た目をカスタマイズするために、本文には標準的な HTML コードを使用できます。


### 添付ファイル


メールへのファイルの添付は簡単です。ドキュメントから添付するファイルまたはフォルダーを選択します。フォルダーを選択した場合、フォルダーの内容が個別のファイルとして添付されます。パスでは変数の置換が使用できるため、パーソナライズしたメールを送信する際に添付ファイルをより細かく制御できます。



複数のドキュメントを添付するには、**メールに添付ファイルを追加**をオンにし、**その他のメールオプション**の**その他の添付ファイル**（`attachments`）に、それぞれ**アカウント ID** と**ドキュメントパス**を指定して一覧にします。これらは、選択した添付ファイルとともに送信され、パスには変数と行トークンを同様に使用できます。

### 優先度とプレーンテキスト

**その他のメールオプション**では、**優先度**（`priority`）でメッセージを**低**、**標準**、**高**（`low`、`normal`、`high`）にでき、**送信形式**（`content_type`）を**プレーンテキスト**（`text`）に設定すると、本文は **HTML**（`html`、デフォルト）ではなくプレーンテキストとして送信されます。

### 本文（Jinja テンプレート）


ステップの本文は、1 つ以上の**フレーム**にわたってレンダリングされる **Jinja テンプレート**として記述し、リッチな HTML メールを生成します。各フレームは名前付きの単一テーブル選択で、フレーム名、1 つのワークフローテーブル、任意の列の選択、where フィルター、集計から成ります（結合はありません）。エディターはこのテンプレートを直接開き、フレームの一覧、テンプレート本文、ライブプレビュー、**自分にテスト送信**ボタンが表示されます。プレーンテキストとテンプレートの切り替えはありません。**整形**ボタンと挿入パレット（フレーム用の `render_table(...)`、`{{ cloud }}`、for ループ、通貨／桁区切り／パーセント／日付のフィルター）が、テンプレートの作成を助けます。

テンプレート内では、各フレームを `frames['<Frame Name>'].rows` と `frames['<Frame Name>'].columns` として参照します。単一フレームのテンプレートでは、最初のフレームにバインドされたトップレベルの `rows` / `columns` を使用できます。テンプレートは独立したサンドボックス化されたレンダリングエンジンで処理されます。ワークスペースの値として解決されるのは `cloud` のみで、従来の `{project}` / `{model}` / `{date}` トークンはテンプレート内では解決されません。Jinja による作成機能の導入前に作成されたステップは、従来の本文が自動変換された状態で開きます。安全に変換できない本文はプレーンテキストのフォールバックのままとなり、従来の `{token}` 置換で送信され続けます。利用できるテンプレート変数、`render_table` ヘルパー、メールのサニタイザーを通過する HTML タグと属性、既存の本文の移行方法については、[テンプレート化された HTML メール通知の送信](/ja/guides/workflows/notify-email-templates/)を参照してください。
