ワークフローから Slack 通知を追加するには、2 つの部分から成る手順が必要です。2 つの部分は次のとおりです。


1. Slackウェブフックの外部接続を作成する
2. ワークフローに Slack 通知ステップを追加する

## ワークフローに Slack 通知ステップを追加する


ワークフローへの Slack 通知ステップの追加は、他のステップを追加する場合と同じです。ステップを追加したら、ステップの設定を開いてフォームに入力し、保存します。これで Slack 通知をテストできます。



## ファイルを添付する

**アップロードするファイル**でドキュメントを選択すると、そのドキュメントがメッセージをコメントとしてチャネルに送信されます。ウェブフックではファイルを送れないため、添付ファイルは Slack 接続のボットトークンを通じて送信されます。

- 接続に**ボットトークン**を追加します。これは `files:write` スコープを持つ Slack アプリの `xoxb-` トークンで、アプリをチャネルに招待しておく必要があります。
- ステップには、チャネル名ではなく、`C0123ABCD` のような**チャネル ID** を入力します。Slack のファイルアップロードは ID のみを受け付けるため、ID がないとステップは失敗します。ID を確認するには、Slack でチャネルの詳細を開き、一番下までスクロールします。
- ドキュメントが見つからない場合は、メッセージのみがウェブフックで送信され、ステップはドキュメントのパスを示す警告を出します。

## Slack メッセージの書式設定


Slack には、画像の追加やユーザーへのメンションなど、多くの書式設定オプションがあります。詳細については、[Slack のテキスト書式設定](https://api.slack.com/reference/surfaces/formatting)のドキュメントを参照してください。



## Slackウェブフックの外部接続を作成する


これは、PlaidCloud がお客様に代わって Slack 通知を送信できるようにするための、1 回限りの設定です。Slack では、ウェブフックアプリ（インターネット経由で通知を送信する汎用的な方法）を作成できます。Slack でウェブフックアプリを作成したら、提供された認証情報を PlaidCloud に追加して、利用できるようにします。



### Slack ウェブフックアプリの作成


これらの手順は、Slack の管理者が実行する必要があります。Slack ウェブフックアプリを作成するには、次の手順に従います。


1. Slack でワークスペースのコントロールメニューを開き、`Settings & administration > Manage Apps` を選択します
2. アプリのカテゴリ一覧から `Custom Integrations` を選択します
3. アプリの一覧から `Incoming Webhooks` を選択します
4. `Add to Slack` ボタンを選択します
5. 次の画面で、メッセージを投稿する Slack チャネルを選択して続行します。これは使用されるデフォルトのチャネルですが、通知ごとに上書きでき、特定の個人への DM の送信も可能です。
6. 表示されたウェブフック URL をコピーします。後で使用するため、安全な場所に保管してください。次のような形式です。`https://hooks.slack.com/services/T04QZ1435/G02TGBFTOP8/K9GZrR2ThdJz1uSiL9YeZxoR`
7. 保存する前に、外観、名前、絵文字をカスタマイズできます。これらのカスタマイズはデフォルトにすぎず、PlaidCloud ワークフロー内の各通知ステップで上書きできます。

### PlaidCloud の外部接続の設定


これらの手順は、外部データ接続を作成する権限を持つ PlaidCloud ワークスペースの管理者が実行する必要があります。接続を作成するには、次の手順に従います。


1. `Analyze > Tools > External Data Connections` に移動します
2. `+ New Connection` の選択肢から、Slackウェブフックを選びます
3. 名前と説明を入力し、上記の手順 6 で取得したウェブフック URL を貼り付けます。ここで指定した名前がワークフローステップの選択肢として表示されるため、可能であればわかりやすい名前にしてください。URL を知っている人は誰でもチャネルに投稿できるため、**Webhook URL** フィールドは貼り付け時にマスクされ、接続を開き直すと空白で表示されます。保存済みの URL を維持するには、空白のままにしてください。
4. 添付ファイルを送信するには、Slack アプリのボットトークンを**ボットトークン（ファイルのアップロード用）** フィールドにも貼り付けます。1 つの接続には、ウェブフック URL、ボットトークン、またはその両方を設定できます。ボットトークンはウェブフック URL と同様にマスクされ、接続を開き直すと空白で表示されます。
5. `+ Create` ボタンを選択します
