## 説明


[@plaidcloud](https://twitter.com/plaidcloud) から Twitter のダイレクトメッセージ（DM）を送信します。



### Twitterアカウント


@plaidcloud からの DM を受信する Twitter アカウントを指定します。メッセージを受信するには、このユーザーが @plaidcloud をフォローしている必要があります。ユーザー名の先頭にアットマーク（@）を付けても付けなくても構いません。



### メッセージ


送信するメッセージを入力します。Analyze では、140 文字を超える値は許可されません。


ご注意：このトランスフォームでは、プロジェクト変数とワークフロー変数の両方を使用できます。


<Aside type="danger">変数を使用すると、140 文字の上限を超えるメッセージが生成される場合があります。その場合、メッセージは送信されません。代わりに、次のエラーがログに書き込まれます。*Twitter API returned a 403 (Forbidden), There was an error sending your message: The text of your direct message is over 140 characters.</Aside>

## 例

この例では、[@PlaidCloud](https://twitter.com/plaidcloud) から [@tartansolutions](https://twitter.com/tartansolutions) に DM を送信します。メッセージにはシステム変数を使用しています。最終的なメッセージは、*Analyze Demo is running on #PlaidCloud* になります。
