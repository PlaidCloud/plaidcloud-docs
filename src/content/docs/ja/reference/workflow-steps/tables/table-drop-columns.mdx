## 説明

**テーブル: 列のドロップ** ステップは、選択した列を除いて、ソーステーブルのコピーを出力テーブルに書き込みます。それ以外のすべての列は、名前、型、位置がそのまま維持されます。

## ソースとオプション

- **ソーステーブル** と **出力テーブル** — 読み取るテーブルと書き込むテーブルです。
- **ドロップする列** — 除外する列です。少なくとも1つ選択してください。ソースに存在しない列は無視されるため、前のステップがその列を生成しなくなってもステップは実行されます。
- **数値順序プレフィックス** *（オプション）* — このテキストで始まる、保持される列を、それらが占める位置の中で数値順に並べます。プレフィックスが `Tags_` の場合、`Tags_2` は `Tags_10` の後ではなく前に来ます。
- **テーブルで指定される列** セクションの **列名のテーブル**（`drop_from`）と **名前を保持する列**（`drop_from_column`、デフォルトは `drop`）*（オプション）* — その列のセルがそれぞれ列名のJSONリストになっているテーブルで、除外する列をさらに指定します。このテーブルはステップの実行時に読み取られます。
