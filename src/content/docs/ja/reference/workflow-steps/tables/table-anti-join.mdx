## 説明


Table Anti Joinステップは、2つのテーブル間で一致しない項目のセットを返します。最初のテーブルの項目のうち、2番目のテーブルに一致するものがないものの一覧が返されます。一方のテーブルにあり、もう一方のテーブルにないレコードを特定する際に非常に便利です。



この操作は、外部結合を使用して結合のnull値でフィルターすることでも実現できますが、アンチ結合の変換を使用すると、より効率的で分かりやすく実行できます。

<Aside type="note" title="これは左結合ではなく、左側を除外する結合です">
Table Anti Joinステップは、ソースBに一致するものが**ない**ソースAの行を保持します。動作はステップタイプによって固定されているため、結合タイプのセレクターはありません。**左結合**（ソースAのすべての行を保持し、キーが一致する場合にソースBの列を埋める）が必要な場合は、[Table Outer Join](/ja/reference/workflow-steps/tables/table-outer-join/)ステップを使用し、その**結合タイプ**を**左結合**に設定してください。アンチ結合は一致しないソースAの行のみを返すため、出力は**ソースAのみ**から取得されます。ソースBは結合キーを提供しますが、出力列は提供しません。
</Aside>

## 実行時に指定される列

**実行時に指定された列も引き継ぐ**を選択すると、ステップに記載されていないすべてのソース列が、ステップの実行時にテーブルにある状態のまま、変更されずに渡されます。ピボットなど、前のステップがデータに応じた名前の列を作成するため、ステップの作成時にそれらを記載できない場合に使用します。オフにすると、記載した列のみが書き込まれます。
