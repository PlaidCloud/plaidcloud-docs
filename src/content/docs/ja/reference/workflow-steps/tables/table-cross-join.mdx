## 説明


名前のとおり、2つのデータテーブルに対してクロス結合を実行し、結合キーを使わずに1つのデータテーブルにまとめます。


どちらのテーブルのソースフィルターも、結合のサイズが見積もられる前に適用されます。そのため、大きなテーブルに対するフィルター付きのクロス結合でも、フィルター後の行数が十分に少なければ実行されます。

クロス結合の仕組みについて詳しくは、こちらをご覧ください: [Wikipedia SQL Cross Join](https://en.wikipedia.org/wiki/Join_%28SQL%29#Cross_join)

## 実行時に指定された列

**実行時に指定された列も引き継ぐ** を選択すると、ステップが列挙していないソース列がすべて、ステップの実行時にテーブルにある状態のまま変更されずに渡されます。ピボットなど、名前がデータによって決まる列を前のステップが作成する場合、ステップの作成時にそれらを列挙できないため、このオプションを使用します。オフのままにすると、列挙した列だけが書き込まれます。
