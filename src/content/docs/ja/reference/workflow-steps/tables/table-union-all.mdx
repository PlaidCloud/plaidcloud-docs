## 説明


同じ列構造を持つ複数のデータテーブルを、1つのデータテーブルに結合する際に使用します。たとえば、時系列データはこの変換の代表的な対象です。結果には、結合されたテーブルのすべてのレコードが含まれます。

<Aside>**Union All**は重複を削除しません。重複レコードを削除したい場合は、代わりに**Union Distinct**を使用してください。</Aside>

## ソース


**ソース**セクションは、追加するすべてのデータテーブルのコレクションです。通常、すべてのデータテーブルは同じ（または類似の）列構造を持ちます。データテーブルをリストに追加するためのボタンが2つあります。


* **行を挿入**
* **行を追加**

また、**編集するソースを選択**ウィンドウで右クリックすると、同じオプションが表示されます。すでに追加されているテーブルを右クリックすると、**削除**オプションも表示されます。


変換を正しく実行するには、追加するソースデータテーブルごとに、**ソース**セクションに1つのエントリが必要です。これらのエントリは、追加される順に一覧表示されます。順序を調整するには、テーブルを右クリックすると、次のオプションが表示されます。


* **下へ移動**（該当する場合）
* **末尾へ移動**（該当する場合）
* **上へ移動**（該当する場合）
* **先頭へ移動**（該当する場合）

デフォルトでは、各ソースの名前は*New Frame*ですが、名前をダブルクリックして変更し、分かりやすい名前を付けることをお勧めします。


<Aside>表示されるテキストは、ソースデータテーブルの名前とは**関係ありません**。分かりやすい名前を付けることをお勧めします。多くの場合はソースデータテーブルと同じ名前にしますが、名前の間に関連付けはまったくないことに注意してください。</Aside>


## ターゲットテーブル


デフォルトでは、**ターゲットテーブル**は空白です。名前を付ける前に、データテーブルはLinuxの命名規則に従う必要があることに注意してください。そのため、名前には英数字のみを使用することをお勧めします。Analyzeは、名前から無効な文字を自動的に削除します。また、長さは256文字に制限されるため、簡潔にしてください。

## 列の照合

**ターゲットテーブル**の**列の照合方法**で、ソースの揃え方を選択します。

* **名前**（デフォルト）— 各ソースの列は、名前によって最初のソースの列と照合されます。
* **位置** — ソースは、Sparkの`union`と同様に、順番に積み重ねられます。結果は最初のソースの列名を使用し、すべてのソースの列数が同じである必要があります。各ソースの列マッピングは使用されないため、その**列**タブは無効になります。

**位置**の場合、各列は、すべてのソースが収まる型になります。2つの数値型は、より広い方になり、日付とタイムスタンプはタイムスタンプになり、それ以外の組み合わせはテキストになります。ブール値またはバイナリの列がほかの型と混在すると、共通の型がなく、ステップは失敗します。列数が異なるソースの場合も同様です。

どちらのモードでも、すべてのソーステーブルが存在しない場合、ステップは失敗せずに、警告付きで終了します。

## 保存時にチェックされる内容

すべてのソースは、最初のソースと同じ列を生成する必要があります。同じ列名で、両方が型を宣言している場合は同じ型です。ターゲットテーブルは、最初のソースの列から作成されます。列は名前で照合されるため、ソースの列の順序は異なっていてもかまいません。ソースが異なるステップを保存すると、それぞれの違いが示されて拒否されます: *Source 'east' must produce the same columns as 'west': missing region; not in 'west': area.*

保存時には、ソーステーブルはあるもののソース列またはターゲット列がない各ソースのマッピングも、**両方のマッピングテーブルを入力**と同様に、そのテーブルから入力されます。
