## 説明


名前のとおり、2つのデータテーブルに対して内部結合を実行し、指定した結合キーに基づいて1つのデータテーブルにまとめます。


内部結合の仕組みについて詳しくは、こちらをご覧ください: [Wikipedia SQL Inner Join](http://en.wikipedia.org/wiki/Join_%28SQL%29#Inner_join)

## 実行時に指定された列

**実行時に指定された列も引き継ぐ** を選択すると、ステップが列挙していないソース列がすべて、ステップの実行時にテーブルにある状態のまま変更されずに渡されます。ピボットなど、名前がデータによって決まる列を前のステップが作成する場合、ステップの作成時にそれらを列挙できないため、このオプションを使用します。オフのままにすると、列挙した列だけが書き込まれます。

## 例


### 自動車メーカーとモデルの結合


この例では、次のソースデータテーブルを使用します。1つ目は自動車メーカーの一覧です。



| Mfg_ID | Manufacturer |
|--------|--------------|
| 1      | Aston Martin |
| 2      | Porsche      |
| 3      | Lamborghini  |
| 4      | Ferrari      |
| 5      | Koenigsegg   |

2つ目は、メーカーIDを持つ自動車モデルの一覧です。メーカーのないモデルがいくつかあることに注意してください。




| ModelName         | Mfg_ID |
|-------------------|--------|
| Aventador         |   3    |
| Countach          |   3    |
| DBS               |   1    |
| Enzo              |   4    |
| One-77            |   1    |
| Optimus Prime     |        |
| Batmobile         |        |
| Agera             |   5    |
| Lightning McQueen |        |

メーカーごとのモデルの一覧を取得するには、*Mfg_ID* で結合するのが適切です。


まず、**Table 1 Data Selection** のパラメーターを指定します。ソースデータテーブルが選択され、すべての列が一覧表示されます。



次に、**Table 2 Data Selection** のパラメーターを指定します。ここでもソースデータテーブルが選択され、すべての列が一覧表示されます。



最後に、**テーブル出力** タブで結合条件を設定します。**自動判定** ボタンを使用すると、Analyzeは *Mfg_ID* 列を **結合キー** として使用する列として正しく識別します。最後に、


**ターゲット出力列** は **反映** ボタンを使用して自動的に指定されます。これにより、すべてのテーブルのすべての列が含まれ、結合列は1回だけ含まれます。列は、最初に *Manufacturer*、次に *ModelName* の順にアルファベット順で並べ替えられることに注意してください。



想定どおり、最終的な出力には、両方のテーブルで一致した値だけが含まれます。そのため、*Porsche* にはモデルがないため表示されません。同様に、


*Batmobile* にはメーカーがない（カスタム製作車のため）ので、含まれません。
