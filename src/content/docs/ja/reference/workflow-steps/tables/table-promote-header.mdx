## 説明

**テーブル: ヘッダーの昇格** ステップは、入力の1行を取り出してその値を列名にし、その行を削除します。実際のヘッダーが先頭行にないファイルに使用します。ステップはワークフローの実行時に実行されるため、名前はデータから取得されます。

## ソースとオプション

- **ソーステーブル** と **出力テーブル** — 読み取るテーブルと書き込むテーブルです。
- **ヘッダー行** — 値が列名になる行で、1から数えた行番号で指定します。データからは削除されます。空のままにすると、ヘッダーは昇格されず、保存されている名前に書式設定ステップが適用されます。
- **レコード順序列** *（オプション）* — 行を順序付ける列です。指定しない場合、行は保存されている順序で読み取られるため、どの行が列名になるかは実行のたびに変わる可能性があります。
- **入力が空の場合の列** *（オプション）* — 入力に行がない場合に書き込むテキスト列の名前を、カンマ区切りで指定します。

## 書式設定ステップ

**書式設定ステップ** グリッドの各行が、昇格された名前を変更します。

| 設定 | 選択肢 |
| --- | --- |
| アクション | **名前の変更**、**タイプの変更**、**非表示**、**空白の補完** |
| 照合方法 | **含む**、**次で始まる**、**次で終わる**、**空である** |
| 一致するテキスト | 列名の中で照合するテキストです。**空である** では不要です。 |
| 名前変更の方法 | 名前の変更の場合の **テキストを置換**、**前に追加**、**後ろに追加** |
| 置換後 | 名前の変更または補完の新しいテキストです。 |
| 値 | **タイプの変更** の型です。 |

各ステップにはアクションと照合方法が必要で、名前の変更には名前変更の方法とそのテキストが必要です。
