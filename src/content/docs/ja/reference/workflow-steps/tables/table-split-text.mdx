## 説明

**テーブル: テキストの分割** ステップは、1つの列のテキストを区切り文字で分割し、分割した要素を新しい列または新しい行として書き込みます。列の数はステップの実行時に、要素数が最も多い値に合わせて決まるため、事前に知っておく必要はありません。

## ソースとオプション

- **ソーステーブル** と **出力テーブル** — 読み取るテーブルと、書き込むテーブル。
- **分割する列** — 分割する列。数値は、そのテキストとして分割されます。
- **区切り文字** — 要素の間にあるリテラルテキスト。長さは自由で、パターンではありません。スペースは入力したとおりに保持されます。
- **分割先** — **列** または **行**。
  - **列** は、`<column>_1`、`<column>_2` のように、要素数が最も多い値の数だけ書き込みます。要素数が少ない値では、残りの列はNULLになります。
  - **行** は、要素ごとに1行を書き込み、列の代わりにその要素を入れます。空の要素も行として残ります。
- **各要素の前後のスペースを削除する** — デフォルトでオンです。
- **元の列を保持する** — デフォルトでオンです。列モードでは、分割した列を保持します。行モードでは、分割前の値も `<column>_original` に書き込みます。

結果が空の場合、出力テーブルは置き換えられます。前回の実行の行が残ることはありません。

### 列の追加設定

列に分割する場合、**その他の分割オプション** には次の設定もあります。

- **断片名のプレフィックス**（`prefix`）— 要素を `<column>_<n>` ではなく `<prefix><n>` という名前にします。**最初の部分の番号**（`start`、デフォルトは1）は、最初の要素の番号です。
- **断片の列名**（`names`）— 要素の列の名前を順番に指定します。**最長の値が持つ数だけの名前付き列のみを書き込む**（`fit`）をオンにしない限り、指定した数の列がちょうど書き込まれます。オンにすると、要素数が最も多い値の数だけが書き込まれます。
- **断片の型**（`dtype`）— 要素の型。`text`（デフォルト）、`integer`、`bigint`、`double`、`boolean`、`date`、`timestamp` のいずれかです。その型として読み取れない要素はNULLになります。
- **削除する文字**（`strip`）— **各要素の前後のスペースを削除する** が取り除くスペースの代わりに、各要素の両端から取り除く文字。
- **列は KNIME コレクションを保持している**（`collection`）— 列が、変換されたKNIMEワークフローのリスト値を保持しています。その要素が分割後の要素になり、区切り文字は使用されません。存在しない要素はNULLになり、空のリストには要素がありません。

**KNIME ノード**（`knime_config`）は、KNIMEのLine Chopper、Expand Vector、Sample and Expand Vectorの各ノードのいずれかを、このステップで実行します。`chopper` は列の先頭から空白区切りのトークンを書き込みます。`expand_vector` はベクトル列の要素を列として書き込みます。保持する位置は、**要素位置テーブル**（`source_b`）のテーブルに列挙します。`sample_expand_vector` は要素のランダムなサンプルを展開し、サンプリングされた列名を、**サンプリングされた列名のテーブル**（`targets`）のテーブルに書き込みます。
