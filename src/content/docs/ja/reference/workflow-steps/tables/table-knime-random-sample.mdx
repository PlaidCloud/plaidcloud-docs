## 説明

**Table: KNIME Random Sample** ステップは、KNIMEが使用する乱数ジェネレーターでKNIMEノードのランダム抽出を実行します。そのため、シードを指定したノードは、KNIMEと同じ行または値をPlaidCloudでも抽出します。[移行されたKNIMEワークフロー](/ja/guides/workflows/migrate-knime-workflows/)では、Row Sampler、Table Partitioner、Equal Size Sampling、Bootstrap Sampling、Shuffle、X-Partitioner、およびランダムデータ生成ノードにこのステップが使用されます。

抽出ではソーステーブルをワークフローに読み込むため、対象にできるテーブルは最大10,000,000行です。それより大きなテーブルではステップが失敗します。

ステップのフォームには、ソーステーブルと出力テーブルのための **テーブル** セクション、**メソッド**、**シード**、サンプルサイズのための **抽出** セクション、読み取る列と書き込む列のための **列** セクションがあります。

## 設定

- `source` と `target_frame` — 読み取るテーブルと書き込むテーブルです。
- `position_column` — 各行の0から始まる位置を保持する列です。デフォルトは `_knime_pos` です。
- `method` — 抽出方法です。
  - `random`、`stratified`、`equal_exact`、`equal_approximate` は、Row Sampler、Table Partitioner、Equal Size Samplingの抽出で選択された行の位置を保持します。`class_column` と `class_dtype` は、層化抽出または等サイズ抽出のクラス列を指定します。
  - それ以外のメソッドはすべて、行の位置とともに抽出結果を書き込みます。`uniform`、`gaussian`、`gamma`、`beta`、`label`、`label_dependent`、`label_from_table`、`boolean`、`mersenne_twister`、`sobol`、`halton`（ランダムデータ生成）、`shuffle`、`bootstrap`、`match`（Random Matcher）、`item_insert`（Random Item Inserter）、`stress`（Stresser）、`sample_data`（Sample Data Generator、ソーステーブルなし）、`kfold`（X-Partitionerのフォールド）、`p_square`（グループごとのP²パーセンタイル推定）、`set_bits`（ビットベクトル）、`equal_count_edges`（Binnerの等件数境界）、`border_texts`（Auto-Binnerの境界テキスト）があります。
- `seed` — 乱数ストリームのシードです。空の場合は、シードなしのKNIMEと同様にクロックから抽出されるため、実行のたびに行が異なります。
- `count`、`percentage`、`relative` — 抽出する行数です。件数、または `relative` を指定した場合はパーセンテージで指定します。`count_column` は、ワークフローの実行時にのみ件数がわかる場合に、ソース列から件数を取得します。
- `parameters` — 抽出メソッドが読み取るノードの設定です。たとえば、`gaussian` 抽出の分布や、`kfold` 抽出のフォールド数などがあります。
- `source_columns` と `target_columns` — 抽出メソッドで、読み取る列と書き込む列です。位置列が先頭に来ます。
- `source_b` と `source_columns_b` — 2番目の入力です。たとえば、`label_from_table` のカテゴリテーブルや、`match` が抽出元とするテーブルです。`target_frame_b` と `target_columns_b` は、`sample_data` のクラスター中心を受け取ります。
