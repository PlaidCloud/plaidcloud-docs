## 説明


データテーブルのコピーを作成します。




<SnippetCommonTableSourceAndTarget />



コピーを実行する際、Analyzeはまずターゲットのデータテーブルがすでに存在するかどうかを確認します。存在する場合は、**Allow Overwriting Existing Table** チェックボックスをオンにしていない限り、何も実行されません。オンにしている場合は、ターゲットテーブルが上書きされます。
