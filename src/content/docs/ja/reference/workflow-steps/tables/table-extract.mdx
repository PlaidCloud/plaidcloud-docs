## 説明


既存の Analyze データテーブルから別のデータテーブルにデータを抽出するために使用します。用途の例は次のとおりです（これらに限りません）。


* 並べ替え
* グループ化
* 集計
* 行のフィルター／絞り込み
* 不要な列の削除
* 数値演算
* 文字列操作

<Aside>この変換に固有の機能はありません。並べ替え、グループ化、フィルターなどはすべて、**テーブルデータの選択** タブと **データフィルター** タブを使って他の任意の変換でも実行できます。</Aside>

## 実行時に名前が決まる列

**実行時に指定された列も引き継ぐ** を選択すると、ステップに列挙されていないすべてのソース列を、ステップの実行時点でテーブルにある状態のまま、変更せずに引き継ぎます。ピボットのように、前のステップでデータに応じて名前が決まる列が作成され、ステップの作成時にそれらを列挙できない場合に使用します。列挙した列だけを書き込むには、オフのままにします。

オンにすると **引き継ぐ列** セクションが表示されます。また、**データで名前が決まる列** セクションは常に利用できます。これらには次のフィールドがあります。

* **引き継ぎ方法** (`carry_expression`) — 引き継ぐ各列を、そのままではなくこの式として書き込みます。式の中では `__column__` が引き継ぐ列を表します。グループ化するステップでは、この方法で実行時にしか名前が決まらない列を取り込みます。集計するステップでは、これを指定しないと何も引き継がれません。**引き継ぐ列の型** (`carry_dtype`) は引き継ぐ各列のデータ型を設定し（デフォルトは元の列の型）、**引き継ぐ列の集計** (`carry_agg`) は集計するステップでの扱いを設定します（式で集計する場合は `dont_group`）。
* **引き継ぐ列の名前変更** (`carry_rename`) — 正規表現 `pattern` に一致し、かつ `keep` に一致しない名前を持つ引き継ぎ列について、一致した各部分を `replacement` に置き換えて名前を変更します（グループには `\1` を使用します。設定した場合は最初の `max` 個の一致が対象です）。`replacement` 内の `__index__` は、名前を変更した列の中でのその列の位置で、`start` から数えます。すでに使われている名前には ` (#n)` が付加されます。
* **動的列** (`dynamic_columns`) — データによって名前が決まるターゲット列です。ステップがソースから読み取る重複のない値ごとに 1 セットずつ作成され、ステップの実行時に書き込まれます。各エントリでは、`rows`（ソースに対する式 `key`、`label`、`where`、`order`）、`__key__`、`__label__`、`__index__` を使用する `target` 列または列のリスト、そして新しい列を配置する位置の直前のターゲット列 `after`（デフォルトは末尾）を指定します。値はテキスト、整数、ブール値、または NULL である必要があり、ステップが書き込む列は最大 1,000 列で、出力はテーブルである必要があります。
