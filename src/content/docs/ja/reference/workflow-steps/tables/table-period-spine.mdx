## 説明

**テーブル: 期間スパイン** ステップは、開始日と終了日の間の各期間について、その期間に該当するレコードがあるかどうかにかかわらず、1行を書き込みます。スパインを集計済みのデータに結合すると、アクティビティのない期間を除外せずに、ゼロとして表示できます。

## ソースとオプション

- **ソーステーブル** と **日付列** — 日付が範囲の境界を決めるテーブルです。開始日と終了日の両方を指定しない限り必要で、両方を指定した場合はソースは読み取られません。
- **期間** — **日**、**週**、**月**、**四半期**、**年**、**10年** のいずれかです。週は月曜日から始まります。
- **開始日** *（オプション）* — 最初の期間です。空白のままにすると、ソーステーブルの最も早い日付から開始します。
- **終了日** *（オプション）* — 最後の期間です。空白のままにすると、ソーステーブルの最も遅い日付で終了します。開始日が終了日より後の場合は、警告とともに入れ替えられます。
- **出力列** — 各期間の最初の日を保持する日付列の名前です。デフォルトは `Period Start` です。
- **出力テーブル** — スパインの書き込み先です。

ステップは100,000期間で停止し、停止した場合は警告します。より大きな範囲には、より長い期間またはより狭い日付を選択してください。
