## 説明

ご自身で記述したSQLの `SELECT` から、ターゲットテーブルにデータを入力します。[Table Extract](/ja/reference/workflow-steps/tables/table-extract/) ステップがマッピングされた列と式からクエリを組み立てるのに対し、このステップはクエリをそのままウェアハウスに渡します。マッパーで組み立てるよりSQLで直接記述するほうが簡単な場合に適しています。

再帰CTE、マッパーでは表現できないパーティションに対するウィンドウ関数、結合ステップを使うと複雑になってしまう複数テーブルへのクエリなど、マッパーが対応していない構文が必要なときに使用します。

## 固有の設定項目

### SQL Selectクエリ

クエリのテキストです。1行の長いテキストではなく、1行につき1つの列または句で、読みやすい複数行のインデント付きSQLとして記述してください。ステップは入力した内容をそのまま保持し、次にこのステップを開く人がそれを読むことになります。

クエリはプロジェクトのレイクハウス上で実行されるため、使用できる関数はワークスペースに応じて [Lakehouse v1](/ja/reference/expressions/lakehouse-v1/) または [v2](/ja/reference/expressions/lakehouse-v2/) のセットになります。
