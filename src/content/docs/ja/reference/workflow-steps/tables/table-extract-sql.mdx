## 説明

自分で記述したSQLの`SELECT`から、ターゲットテーブルにデータを入力します。[Table Extract ステップ](/ja/reference/workflow-steps/tables/table-extract/)はマッピングされた列と式からクエリを構築しますが、このステップはクエリをそのままウェアハウスに渡します。マッパーで組み立てるよりも、SQLで直接表現する方が簡単な場合に使用します。

マッパーが対応していない構文が必要な場合に使用してください。再帰CTE、マッパーでは記述できないパーティションに対するウィンドウ関数、結合ステップを使うとかえって複雑になる複数テーブルに対するクエリなどです。

## 固有の設定項目

### SQL Selectクエリ

クエリのテキストです。1行の長い文ではなく、読みやすい複数行のインデント付きSQL（1行に1つの列または句）として整形してください。ステップは記述した内容をそのまま保持し、次にそれを開く人が読むことになります。

クエリはプロジェクトのLakehouseで実行されるため、使用できる関数は、ワークスペースに応じて[Lakehouse v1](/ja/reference/expressions/lakehouse-v1/)または[v2](/ja/reference/expressions/lakehouse-v2/)のセットになります。

<SnippetCommonStepPreview />

ほかのSQLステップとは異なり、このステップは変数を埋め込まないため、そのプレビューでも埋め込まれません。
