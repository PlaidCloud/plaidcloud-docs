## 説明


縦長で幅の狭いデータテーブルを、横長で短いデータテーブルに変換する際に使用します。選択した列が転置され、列名が複数の列にわたる値に変換されます。


最も分かりやすい例は、月が行として並んでいるデータテーブルを考えることです。





このデータテーブルをピボットすると、月の行がすべて列に変換されます。

### ピボット列の選択

**列ヘッダーに変換するカテゴリ列**では、ソーステーブルの中で行にピボットされる列を指定します。
**列の値にピボットする値列**は、ソーステーブルの値を含む列です。
**値の集計オプション**では、データをどのように集計するかを指定します。

どちらの列も、**列**タブのステップの出力列に含まれている必要があります。そうでない場合、保存は拒否されます。たとえば、*The category column 'month' isn't one of the step's output columns.* と表示されます。


フォームには、次のフィールドもあります。

* **各カテゴリの位置を保持する列**（`column_order`）— 各カテゴリの位置を保持するソース列です。ピボットされた列は、名前順ではなく、この列の昇順で並びます。この列でグループ化されることも、書き込まれることもありません。
* **ピボット列名のテンプレート**（`column_name_template`）— ピボットされた各列に、このテキストで名前を付けます。`{value}`はカテゴリの値に置き換えられます（例: `{value}+Sum`）。

## テーブルデータの選択

![Table Pivotのデータ選択](/images/table_pivot_2.png)


テーブルデータの選択タブは、ソースデータテーブルの列をターゲットデータテーブルにマッピングするために使用します。ウィンドウの左側にあるすべてのソース列は、ウィンドウの右側に表示されるターゲットデータテーブルに自動的にマッピングされます。**ソースを検査**メニューボタンを使用すると、ソースからターゲットへ列をマッピングする方法がいくつか追加されます。


* 両方のマッピングテーブルを入力: ソースデータテーブルのすべての値をターゲットデータテーブルに反映します。これがデフォルトです。
* ソースマッピングテーブルのみを入力: ソースデータテーブルのすべての値のみをマッピングします。ソース列の構造が変更された場合に、既存のワークフローを修正するときに便利です。
* ターゲットマッピングテーブルのみを入力: すべての値をターゲットデータテーブルにのみ反映します。

これらの各オプションに加えて、どの選択肢でもソースデータをプレビューできます。

ソーステーブルを選択した状態で、ソース列またはターゲット列がない状態で保存すると、**両方のマッピングテーブルを入力**と同様に、空の側がソースから入力されます。



ソース列とターゲット列のオプションで足りない場合は、ほかの方法でターゲットデータテーブルに列を追加できます。


* **すべてを反映**は、すでに存在していたかどうかにかかわらず、すべてのソース列をターゲットデータテーブルに挿入します。
* **選択を反映**は、選択したソース列のみを挿入します。
* ターゲット側を右クリックして**行を挿入**を選択すると、現在選択している行の直前に行を挿入します。
* ターゲット側を右クリックして**行を追加**を選択すると、ターゲットデータテーブルの末尾（右端）に行を挿入します。


<Aside type="danger">**すべてを反映**を選択すると、すべての列の複製が実質的に作成される場合があります。Analyzeは、列がすでにマッピングされているかどうかをチェックしません。重複する列名が存在しないことを確認してください。</Aside>




ターゲットデータテーブルから列を削除するには、対象の列を選択し、右クリックして**削除**を選択します。



ターゲットデータテーブルの列を並べ替えるには、対象の列を選択し、右クリックして**先頭へ移動**、**上へ移動**、**下へ移動**、**末尾へ移動**のいずれかを選択します。



重複のないオプションのみを返すには、**重複排除**メニューオプションを選択します。ソースの各列にチェックボックスのセットが切り替わって表示されます。重複のない結果のみを返すには、該当する列の横のボックスにチェックを入れるだけです。

<Aside type="danger">ターゲットデータテーブルにソースデータテーブルの一部の列のみが含まれる場合は、ターゲットデータテーブルに含める列**のみ**の横のチェックボックスを選択します。すべてのチェックボックスを選択すると、重複がないように見えない出力になる可能性があります。</Aside>




結果を集計するには、**集計**メニューオプションを選択します。ターゲットデータテーブルの各列にドロップダウンボックスのセットが切り替わって表示されます。次の集計オプションを使用できます。


* グループ化（デフォルトで設定）
* 合計
* 最小
* 最大
* 最初
* 最後
* 件数
* 平均
* 中央値
* 最頻値
* 標準偏差
* 分散
* 積
* 絶対値
* 分位数
* 歪度
* 尖度
* 平均絶対偏差
* 累積合計
* 累積最小
* 累積最大
* 累積積




## データフィルター


柔軟性を最大限に高めるため、データフィルターはソースデータとターゲットデータの両方で利用できます。大規模なデータセットでは、ソースで行をフィルターして除外し、残りの処理をより小さなデータセットで実行すると、特に効果的です。



### データのサブセットを選択


データのサブセットには、有効なPython式を使用できます。詳細と例については、[式](/ja/reference/expressions/)を参照してください。





### 結果データに二次フィルターを適用


データのサブセットには、有効なPython式を使用できます。詳細と例については、[式](/ja/reference/expressions/)を参照してください。



### 最終データテーブルのスライス（制限）


データを制限するには、**行スライサーを適用**ボックスにチェックを入れて、次を指定します。


* **スキップする先頭行数:** スキップするデータの行数です（列ヘッダー行はカウントに含まれません）
* **終了行:** 含めるデータの最後の行です。これは、末尾で破棄する行数を単純に数えるのとは異なります
