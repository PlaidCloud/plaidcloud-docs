## 説明

**テーブル: JWTエンコード** ステップは、ペイロード列のJSONに署名し、トークンを新しいテキスト列に書き込みます。トークンは行ごとに1つです。出力テーブルは、その列が追加されたソースのコピーです。

## ソースとオプション

- **ソーステーブル** と **出力テーブル** — 読み取るテーブルと書き込むテーブルです。
- **アルゴリズム** — `HS256`、`HS384`、`HS512`、`RS256`、`RS384`、`RS512` のいずれかです。
- **ペイロード列** — 署名するJSONペイロードを保持する列です。
- **ヘッダー列** *（オプション）* — JSONヘッダーを保持する列です。デフォルトのヘッダー `{"alg": …, "typ": "JWT"}` に重ねてマージされます。
- **キー列** *（オプション）* — 署名キーを保持する列です。指定しない場合、ステップは接続が保持するキーで署名します。
- **出力列** — トークンを受け取るテキスト列の名前です。

変換されたSavant分析は、ステップにバインドされた専用の接続に保持されたキーで署名するため、キーがステップの設定に現れることはありません。[Savant分析の移行](/ja/guides/workflows/migrate-savant-analyses/#jwt_encode)を参照してください。
