## 説明


Microsoft ExcelのVLOOKUP関数を日常的に使用している方にとって、Table Lookupステップはなじみ深いものです。基本的に同じ機能を実行するために使用します。Microsoft Excelのバージョンとは異なり、PlaidCloud AnalyzeのTable Lookupステップはより柔軟で、特に複数の列での照合と返却が可能です。

## 例


### 製品ディメンション情報のルックアップ


この例では、モデラーが注文ファクトテーブルを理解するために、製品ディメンションテーブルの情報を必要としています。そのため、*Import Order Fact* テーブルを **ソーステーブル** として選択します。*Import Product Dim* テーブルに必要なルックアップ情報が含まれているため、これを **Lookup Table Source** として選択します。利用できますが、ルックアップのデータテーブルにはフィルターを適用しません（ほかのデータテーブルにも適用しません）。



**テーブルデータの選択** セクションでは、ソースのデータテーブルからターゲットのデータテーブルに、すべての列がマッピングされます。 



ソースデータにもターゲットデータにも、**データフィルター** は適用されません。 



最後に、各テーブルにある *Product_ID* フィールドを使用して、ソースのデータテーブルをルックアップのデータテーブルと照合します。ターゲットのデータテーブルには *Product_Description* 列と *Unit_Cost* 列だけが追加され、その際に *Unit_Cost* は *Retail_Unit_Cost* に名前が変更されます。 



結果のターゲットデータテーブルには、*Product_ID* 列の一致する値に基づいて、*Product_Description* 列と *Retail_Unit_Cost* 列が追加されています。
