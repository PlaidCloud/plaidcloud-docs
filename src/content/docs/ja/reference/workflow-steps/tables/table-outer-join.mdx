## 説明


2つのデータテーブルに対して外部結合を実行し、指定した結合キーに基づいて1つのデータテーブルにまとめるために使用します。**結合タイプ** のコントロールで、一致しないどの行を保持するかを選択します。**左**、**右**、**完全外部** のいずれかの結合です。デフォルトは左結合です（テーブルAのすべての行が保持され、キーが一致する場合にテーブルBの列が入力されます）。


外部結合の仕組みについて詳しくは、こちらをご覧ください: [Wikipedia SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## 実行時に指定された列

**実行時に指定された列も引き継ぐ** を選択すると、ステップが列挙していないソース列がすべて、ステップの実行時にテーブルにある状態のまま変更されずに渡されます。ピボットなど、名前がデータによって決まる列を前のステップが作成する場合、ステップの作成時にそれらを列挙できないため、このオプションを使用します。オフのままにすると、列挙した列だけが書き込まれます。

### 結合タイプ

一致しない行をどのように保持するかを選択します。

- **左結合** — テーブルAのすべての行を保持します。テーブルBの列は、結合キーが一致する場合にのみ入力されます。これがデフォルトです。
- **右結合** — テーブルBのすべての行を保持します。テーブルAの列は、結合キーが一致する場合にのみ入力されます。
- **完全外部結合** — 反対側のテーブルに一致する行があるかどうかにかかわらず、両方のテーブルのすべての行を保持します。

## 例


### 自動車メーカーとモデルの結合


この例では、次のソースデータテーブルを使用します。1つ目は自動車メーカーの一覧です。




| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


2つ目は、メーカーIDを持つ自動車モデルの一覧です。メーカーのないモデルがいくつかあることに注意してください。




| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

メーカーごとのモデルの一覧を取得するには、*Mfg_ID* で結合するのが適切です。外部結合の考え方を活用することで、一致するものがない項目も出力に表示できます。



まず、**Table 1 Data Selection** のパラメーターを指定します。ソースデータテーブルが選択され、すべての列が一覧表示されます。



次に、**Table 2 Data Selection** のパラメーターを指定します。ここでもソースデータテーブルが選択され、すべての列が一覧表示されます。



最後に、**テーブル出力** タブで結合条件を設定します。**自動判定** ボタンを使用すると、Analyzeは *Mfg_ID* 列を **結合キー** として使用する列として正しく識別します。この例では両方のテーブルの一致しない行を保持するため、**結合タイプ** を **完全外部結合** に設定します。最後に、


**ターゲット出力列** は **反映** ボタンを使用して自動的に指定されます。これにより、すべてのテーブルのすべての列が含まれ、結合列は当然ながら1回だけ含まれます。列は、最初に *Manufacturer*、次に *ModelName* の順にアルファベット順で並べ替えられることに注意してください。



想定どおり、最終的な出力には、両方のテーブルで一致したかどうかにかかわらず、両方のテーブルのすべての行が含まれます。そのため、今回は *Porsche* がモデルを持たないにもかかわらず表示されます。さらに、*Batmobile*、*Lightning McQueen*、*Optimus Prime* は、いずれもメーカーがないにもかかわらず結果に含まれます。それに、誰がこれらにノーと言えるでしょうか。
