## 説明


2つのデータテーブルに対して外部結合を実行し、指定した結合キーに基づいて1つのデータテーブルに結合する際に使用します。**結合タイプ**のコントロールで、一致しない行のうちどれを保持するかを選択します。**左結合**、**右結合**、**完全外部結合**のいずれかです。デフォルトは左結合です（テーブルAのすべての行を保持し、キーが一致する場合にテーブルBの列が入力されます）。


外部結合の方法の詳細については、こちらを参照してください: [Wikipedia SQL Join](http://en.wikipedia.org/wiki/Join_%28SQL%29)

## 実行時に指定された列

**実行時に指定された列も引き継ぐ**を選択すると、ステップが列挙していないすべてのソース列が、ステップの実行時にテーブルが持っているとおりに、そのまま渡されます。ピボットのように、データに応じて名前が決まる列を前のステップが作成するため、ステップの構築時にそれらを列挙できない場合に使用します。オフのままにすると、列挙した列だけが書き込まれます。

### 結合タイプ

一致しない行をどのように保持するかを選択します。

- **左結合** — テーブルAのすべての行を保持します。テーブルBの列は、結合キーが一致する場合にのみ入力されます。これがデフォルトです。
- **右結合** — テーブルBのすべての行を保持します。テーブルAの列は、結合キーが一致する場合にのみ入力されます。
- **完全外部結合** — もう一方のテーブルに一致する行があるかどうかにかかわらず、両方のテーブルのすべての行を保持します。

## 例


### 自動車メーカーとモデルを結合する


この例では、次のソースデータテーブルを考えます。最初は、自動車メーカーの一覧です。




| Mfg_ID | Manufacturer |
|--------|--------------|
|    1   | Aston Martin |
|    2   | Porsche      |
|    3   | Lamborghini  |
|    4   | Ferrari      |
|    5   | Koenigsegg   |


次は、メーカーIDを持つ自動車モデルの一覧です。メーカーのないモデルがいくつかあることに注意してください。




| ModelName          | Mfg_ID |
|--------------------|--------|
| Aventador          |    3   |
| Countach           |    3   |
| DBS                |    1   |
| Enzo               |    4   |
| One-77             |    1   |
| Optimus Prime      |        |
| Batmobile          |        |
| Agera              |    5   |
| Lightning McQueen  |        |

メーカー別のモデルの一覧を取得するには、*Mfg_ID*で結合するのが適切です。外部結合の考え方を活用することで、出力には、一致するものがない項目も表示できます。



まず、**Table 1 Data Selection**のパラメーターを指定します。ソースデータテーブルが選択され、すべての列が一覧表示されます。



次に、**Table 2 Data Selection.** のパラメーターを指定します。ここでも、ソースデータテーブルが選択され、すべての列が一覧表示されます。



最後に、結合条件を**出力**タブで設定します。**自動判定**ボタンを使用すると、Analyzeは、*Mfg_ID*列を**Join Key**として使用することを正しく特定します。この例では両方のテーブルの一致しない行を保持するため、**結合タイプ**を**完全外部結合**に設定します。最後に、


**ターゲット出力列**は、**反映**ボタンを使用して自動的に指定されます。これにより、すべてのテーブルのすべての列が含まれ、結合列はもちろん1回だけ含まれます。列は、最初に*Manufacturer*、次に*ModelName*の順にアルファベット順に並べ替えられていることに注意してください。



想定どおり、最終的な出力には、両方のテーブルで一致したかどうかにかかわらず、両方のテーブルのすべての行が含まれます。そのため、今回は*Porsche*がモデルを持たないにもかかわらず表示されます。さらに、*Batmobile*、*Lightning McQueen*、*Optimus Prime*は、いずれもメーカーがないにもかかわらず、結果に含まれています。それに、あの3台を「ノー」と言える人がいるでしょうか。
