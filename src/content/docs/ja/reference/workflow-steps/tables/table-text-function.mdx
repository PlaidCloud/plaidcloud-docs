## 説明

**テーブル: テキスト関数** ステップは、各行について、関数が読み取る列にテキスト関数を適用し、その結果をソーステーブルのコピーの新しい列に書き込みます。関数が読み取る列のいずれかがNULLの場合、結果はNULLになります。

## ソースとオプション

- **ソーステーブル** と **出力テーブル** — 読み取るテーブルと、書き込むテーブル。
- **関数** — 適用する関数。フォームには、下の2つの表にある関数が表示され、選択した関数が読み取る引数ごとに、その役割を示すラベルの付いた列フィールドが1つ表示されます。
- **引数の列** — 関数が読み取る列。表に示した順序で指定します。すべて必須です。
- **出力列** — ソースのコピーに追加される列の名前。

| 関数 | 引数 | 結果 |
| --- | --- | --- |
| `levenshtein` | 1番目の列、2番目の列 | 大文字と小文字を区別する編集距離（整数） |
| `soundex` | テキスト | テキスト |
| `json_format` | JSON | 整形されたJSONテキスト |
| `json_field` | JSON、パス | テキスト |
| `json_set_text`、`json_set_number`、`json_set_boolean` | JSON、パス、値 | 値が設定されたJSONテキスト |
| `regex_match` | テキスト、パターン、大文字と小文字を区別する | 真または偽 |
| `regex_search` | テキスト、パターン、出現回数、大文字と小文字を区別する | 位置（整数） |
| `regex_extract` | テキスト、パターン、出現回数、大文字と小文字を区別する | テキスト |
| `regex_replace` | テキスト、パターン、置換文字列、大文字と小文字を区別する | テキスト |
| `to_text_number` | 数値、パターン | テキスト: DecimalFormat形式のパターンで書き出した数値 |
| `to_text_datetime` | 日付/時刻、パターン | テキスト: 日時パターンで書き出した日付 |
| `parse_date` | テキスト、パターン | 日付として読み取ったテキスト |
| `parse_datetime` | テキスト、パターン | 日時として読み取ったテキスト |

変換されたSavant分析にはこれらの関数のいずれも含めることができ、同じように実行されます。フォームに表示されない関数は、保存された列が表示され、保存されたとおりに保持されます。

### その他の関数

**関数** リストには、次の関数もあります。変換されたKNIMEワークフローでも、これらを使用します。

| 関数 | 引数 | 結果 |
| --- | --- | --- |
| `damerau_levenshtein`、`hamming`、`lcs` | 1番目の列、2番目の列 | 対応する編集距離（整数） |
| `jaro`、`jaro_winkler` | 1番目の列、2番目の列 | 1から類似度を引いた値。同じテキストでは0 |
| `ngram_distance` | 1番目の列、2番目の列 | 1から文字バイグラムのDice係数を引いた値 |
| `jaccard_tokens`、`dice_tokens`、`cosine_tokens` | 1番目の列、2番目の列 | 1から2つのテキストの単語集合の類似度を引いた値。どちらかに単語がない場合は1 |
| `java_compare` | 1番目の列、2番目の列 | 最初に異なる文字の差。Javaの `compareTo` と同じ整数 |
| `java_regex` | テキスト、パターン、置換文字列 *（置換モードのみ）* | 列から読み取ったJava正規表現。`matches` と `find` モードでは真または偽、`extract` と `replace` ではテキスト |
| `knime_count` | テキスト、検索テキスト | 検索テキストの出現回数（整数） |
| `knime_binomial`、`long_pow` | 2つの数値 | 二項係数または整数のべき乗。オーバーフローして巻き戻る64ビット演算 |
| `encode`、`decode` | テキスト | 文字セットでのbase64バイトとしてのテキスト、およびその逆 |
| `url_encode` | テキスト | フォームの値としてパーセントエンコードしたテキスト。スペースは `+` で表す |
| `list_sort_numeric` | テキスト | 区切りテキストとして保持されたリストを、数値順に並べ替えたもの |
| `geojson_to_wkt` | JSON、パス | `$.a[0]` などのパスにあるGeoJSONジオメトリ（テキスト自体の場合は `$`）をWKTにしたもの |
| `json_patch_apply` | JSON | JSON PatchまたはMerge Patchを適用したドキュメント |
| `json_diff` | 1番目のJSON、2番目のJSON | 1番目のドキュメントを2番目のドキュメントに変換するJSON Patch |
| `json_schema_check` | JSON | ドキュメントがJSON スキーマに対して持つエラーをJSONで返したもの。エラーがない場合はNULL |
| `json_normalize` | JSON | 正規化されたJSONテキストとしてのドキュメント |
| `json_to_xml`、`xml_to_json` | ドキュメント | XMLまたはJSONに変換したドキュメント |
| `xml_well_formed` | XML | 整形式のXMLの場合はそのテキスト、それ以外はNULL |
| `xslt` | XML、スタイルシート | XSLTスタイルシートで変換したドキュメント |
| `message_text`、`message_tool_calls` | JSON | AIメッセージのテキスト、またはそのツール呼び出しをJSONにしたもの |

関数のオプションは `function_options` に設定します。

- `java_regex` — `mode`: `matches`（デフォルト、テキスト全体）、`find`（どこでも）、`extract`（最初の一致のグループ `group`、デフォルトは0）、`replace`（すべての一致）。`flags` の `i` は大文字と小文字を無視します。
- `knime_count` — `modifiers`: `i` は大文字と小文字を無視し、`w` は空白で区切られた単語全体を数えます。
- `encode` と `decode` — `charset`: Javaの文字セット名。デフォルトはUTF-8です。
- `json_patch_apply` — `patch`: JSON Patchの配列またはMerge Patchのオブジェクト。`merge` はMerge Patchの場合にtrue。`keep` はパッチのテストが失敗したときにドキュメントを保持します。
- `json_schema_check` — `schema`。`fail` は、エラーを返す代わりに最初のエラーでステップを停止します。
- `json_normalize` — `comments` は `/* */` と `//` のコメントを許可します。`fail`（デフォルトはtrue）はJSONではないテキストでステップを停止し、falseにするとNULLになります。
- `json_to_xml` — `root`、`item`、`typed`、`parent_keys`、`namespace`、`text_key`、`text_key_enabled`。`xml_to_json` — `text_key`、`comments`、`pis`。
- `list_sort_numeric` — `separator`。`empty` は要素のないリストに書き込むテキスト、`missing` は存在しない要素のテキストで、最後に並べ替えられます。

デフォルトでは、ステップはソースのすべての列を読み取り、ソースのすべての列に続けて出力列を書き込みます。一部の列だけを読み取るには `source_columns` を設定し、書き込む列を選択して順序を決めるには `target_columns`（それぞれ `{source, target, dtype}`）を設定します。出力列と同じ名前の列は、指定したデータ型でその位置に置き換わります。
