## 説明


既存のデータテーブルの内容を、データテーブル自体を削除せずにクリアします。結果として、行数が0のデータテーブルになります。



<SnippetCommonTableSelectionDynamic />

**検索に一致するテーブル**を選択した場合、**検索パス**がプロジェクトの最上位（`/`）のときは、**検索テキスト**が空のままではステップを保存できません。プロジェクト内のすべてのテーブルがクリアされてしまうためです。一致させるテキストを入力するか、フォルダーを選択してください。
