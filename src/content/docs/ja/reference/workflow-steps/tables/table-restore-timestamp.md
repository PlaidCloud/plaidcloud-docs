## 説明

**テーブル: タイムスタンプへ復元** は、テーブルを、特定の時点以前に作成された最新のスナップショットにその場で置き換えます。期間末の状態、またはうまくいかなかったロードの前の状態にテーブルをロールバックするために使用します。復元はテーブル自体を変更するため、そのテーブルを読み取るすべてのステップとダッシュボードに、復元された行が反映されます。

## 特定の時点へ復元

| 設定 | 必須 | 動作 |
| --- | --- | --- |
| テーブル | はい | 復元するテーブルです。 |
| タイムスタンプ | はい | 特定の時点です。`2026-09-30T23:59:59Z` のようなISO-8601形式の時刻、または1970年からの秒数で指定します。タイムゾーンのない時刻はUTCとして扱われます。`{restore_time}` のようなワークフロー変数も使用できます。 |
| タイムスタンプちょうどに作成されたスナップショットを含める | いいえ | デフォルトではオンです。オフにすると、タイムスタンプより前に作成されたスナップショットにのみ復元します。 |

タイムスタンプ以前に作成されたスナップショットがない場合、ステップは警告付きで完了し、テーブルはそのまま変更されず、ワークフローは続行されます。テーブルが見つからない場合も、警告付きで完了します。名前付きスナップショットのみを保持するストレージエンジンでは、テーブルはタイムスタンプちょうどに作成されたスナップショットにのみ復元できます。戻りたい時点で名前付きスナップショットを作成してください。
