## 説明

**Fuzzy Match** ステップは、フィールドの近似一致に基づいて2つのテーブルの行をペアにします（1つのテーブルの重複排除も可能です）。ワークフローエンジン上で実行されます。パッケージ化マクロの結果は、Alteryxマクロの近似です。

## パラメーター

- **左 / 右のテーブル** と **出力テーブル**。
- **レコードID列**、**しきい値**（0～100）、**一致しない行も出力する**。
- **照合フィールド** — 照合するフィールドと、それぞれの照合関数（exact / jaro / levenshtein / bestof / jaro_tfidf / bestof_tfidf）です。
