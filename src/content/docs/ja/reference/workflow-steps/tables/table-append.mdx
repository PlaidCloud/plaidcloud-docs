## 説明

ソーステーブルの行を、既存のターゲットテーブルの末尾に追加します。ターゲットの既存の行は保持され、新しい行のみが挿入されます。日次の抽出データや月次のロードファイルなど、データが段階的に届き、置き換えるのではなく時間をかけてターゲットを増やしていく場合に使用します。

追加しながら重複を排除する必要がある場合は、続けて[Table Union Distinct](/ja/reference/workflow-steps/tables/table-union-distinct/)ステップを実行するか、一部の行がキーによって既存のレコードを更新する場合は[Table Upsert](/ja/reference/workflow-steps/tables/table-upsert/)ステップを使用します。

## ロードパラメーター

### ソースとターゲット

![ソースとターゲット](/images/table_source_and_target_EN.png)

ソースとターゲットのテーブルを設定するには、まず**ソーステーブル**のドロップダウンメニューから、抽出元のデータテーブルを選択します。次に、**ターゲットテーブル**のドロップダウンから、ターゲットテーブルとして既存のテーブルを選択します。

## 保存時に確認される内容

- **マッピングが既存のターゲットテーブルに適合している。** ターゲットテーブルがすでに存在する場合、ステップは、テーブルにない列をマッピングしたり、テーブルの列と異なる型を列に指定したりすることはできません。数値と通貨は同じ型として扱われます。マッピングに含まれないテーブルの列は許可され、追加される行では空のままになります。拒否された場合は、それぞれの相違が示されます。たとえば、*The target columns must match the existing target table 'sales'. Types differ: amount (table: numeric, step: text).* のようになります。まだ存在しないターゲットテーブルや、変数で指定されたターゲットテーブルは、ステップの実行時にチェックされます。
- **空のマッピングは自動的に補完される。** ソーステーブルを選択しているものの、ソース列またはターゲット列が指定されていない状態で保存すると、**両方のマッピングテーブルを入力**を実行した場合と同様に、空の側がソースから補完されます。
