## 説明

テーブル定義とすべてのデータの両方を含め、テーブルをプロジェクトから完全に削除します。この操作は破壊的で元に戻せません。ワークフローが実行されると、テーブルは失われます。

ワークフロー内の中間テーブルが後続のステップで不要になった場合（たとえば、複数ステップにわたる変換のクリーンアップ）に使用します。テーブルを削除せずに一時的に空にするには、代わりに [Table Clear](/ja/reference/workflow-steps/tables/table-clear/) を使用してください。
