## 説明

**Spatial Buffer**ステップは、列内の各ジオメトリを一定の距離だけ拡張し、バッファーされたジオメトリを出力列に書き込みます。Alteryxの*Buffer*ツールに相当し、ワークフローエンジンで実行されます（ジオメトリの処理はSQLでは表現できません）。

## ソースとオプション

- **ソーステーブル** / **出力テーブル** — 入力ジオメトリと、結果の書き込み先です。
- **ジオメトリ列** — バッファーするWKTジオメトリ列です。
- **バッファー距離** — 各ジオメトリを拡張する距離です。ジオメトリ自身の座標単位で指定します。

## 列

**列**タブでは、出力にそのまま渡す入力列をマッピングします。バッファーされたジオメトリ列は自動的に追加されます。
