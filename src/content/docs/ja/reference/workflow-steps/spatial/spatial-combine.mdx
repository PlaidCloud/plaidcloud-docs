## 説明

**空間結合**ステップは、各グループ内のジオメトリを1つのジオメトリ（和集合）にディゾルブし、グループごとに1行を出力します。Alteryxの*Summarize*ツールの*SpatialObjCombine*アクションに相当し、ワークフローエンジンで実行されます。

## ソースとオプション

- **ソーステーブル** / **出力テーブル** — 入力ジオメトリと、ディゾルブ結果の書き込み先です。
- **ジオメトリ列** — ディゾルブするWKTジオメトリ列です。
- **グループ化** — 列の値の組み合わせごとに各グループが決まります。各グループのジオメトリは1つに結合されます。何も選択しない場合は、すべてが1つのジオメトリに結合されます。
- **出力列** — 出力ジオメトリ列の名前です。
- **アクション** — `spatialobjcombine`はグループを和集合にディゾルブし、`spatialobjconvexhull`はグループを囲む最小の凸ポリゴンを返し、`intersection`はすべてのメンバーが共有する領域のみを保持し（メンバーが互いに離れている場合は空になります）、`envelope`はグループの外接矩形を返します。

## 列

**列**タブでは、出力にそのまま渡す入力列をマッピングします。
