## 説明

## ソースとオプション

- **ソーステーブル** / **出力テーブル** — 入力ジオメトリと、結果の書き込み先です。
- **ジオメトリ列** — 簡略化するWKTジオメトリ列です。
- **許容差** — 簡略化の許容差です。値が大きいほど、ジオメトリは粗くなります。トポロジーは保持されます。

## 列

**列**タブでは、出力にそのまま渡す入力列をマッピングします。
