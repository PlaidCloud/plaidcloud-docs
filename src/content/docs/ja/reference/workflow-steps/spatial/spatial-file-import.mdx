## 説明

**空間ファイルのインポート**ステップは、空間ファイル（MapInfoの`.TAB`、ESRIの`.shp`、`.kml`、`.geojson`、SRCの`.geo`）とそのサイドカーファイルを、フィーチャーごとに1行、WKTジオメトリ列を持つテーブルに読み込みます。空間ファイルを指定したAlteryxの*Input Data*ツールに相当し、ワークフローエンジン（GDAL）で実行されます。

## インポートパラメーター

- **ソース** — ドキュメントストア内の空間ファイルです。サイドカーファイル（`.TAB`の`.dat`/`.map`/`.id`/`.dbf`、シェープファイルの`.shx`/`.dbf`/`.prj`など）は、同じ場所から自動的に読み取られます。
- **ターゲットテーブル** — フィーチャーの書き込み先テーブルです。

## 注記

出力スキーマはファイルから取得されるため、列のマッピングはありません。SRCの`.geo`ファイル独自のジオメトリは読み取れません。その`.dbf`属性は、ジオメトリ値が空の状態でインポートされます。
