## 説明

**Spatial Make Grid** ステップは、長方形の範囲を固定の地上サイズの正方形セルに分割し、セルごとに 1 行を書き込みます。Alteryx の *Make Grid* ツールに相当し、ワークフローエンジン内で実行されます。

範囲をデータから読み取れば、セル数は算術で決まります。縦横それぞれ `ceil(extent ÷ cell size)` であるため、ファンアウトには上限があり、予測可能です。

## ソースとオプション

- **ソーステーブル** / **出力テーブル** — 入力のジオメトリと、セルの書き込み先。
- **ジオメトリ列** — 範囲を分割する対象となる WKT ジオメトリ列。
- **グリッドサイズ**と**単位** — 正方形セル 1 つの地上サイズ。マイル、キロメートル、メートル、フィートで指定します。
- **オブジェクトごとに1つのグリッド** — 設定すると、入力ジオメトリごとに個別のグリッドを描画します。設定しない場合は、レイヤー全体の範囲を 1 つのグリッドで覆います。
- **Clip cells to polygon** — オブジェクトごとのモードで、各セルを所属するポリゴンに合わせてトリミングします。デフォルトはオンです。
- **グリッド名列** — 出力するセルラベル列の名前（デフォルトは `GridName`）。
- **出力列** — 出力するジオメトリ列の名前（デフォルトは `SpatialObj`）。

## 出力列

すべての行に、セルラベルとセルジオメトリが含まれます。オブジェクトごとのモードでは、ソース列もそのまま引き継がれます。レイヤー全体のモードでは、セルは特定の入力行に属さないため、出力はグリッドの 2 列のみになります。

## 注記

グリッドサイズが 0 または負の値の場合、空のグリッドを生成せず、ステップは失敗します。

セルサイズは、選択した地上単位からおおよその度単位のサイズに変換されます。そのため、赤道から離れた場所ではセルがわずかに長方形に見えます。これは、実世界の単位を扱う他の空間ステップと同じ平面近似です。
