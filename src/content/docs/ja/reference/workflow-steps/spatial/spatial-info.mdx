## 説明

**Spatial Info**ステップは、各ジオメトリを測定し、測定値を列として追加します。Alteryxの*Spatial Info*ツールに相当し、ワークフローエンジンで実行されます。

測定値は平面ではなく、**WGS84測地線**に基づきます。これは重要です。これらの測定値のSQL版は、平面の度²の値に赤道定数を掛けたもので、緯度が上がっても経度方向にこの定数が小さくならないため、面積と長さが**過大に**なります（米国の緯度ではおよそ4分の1高くなります）。測地線で計算することで、どのウェアハウスでもAlteryxと一致する単一の結果が得られます。

## ソースとオプション

- **ソーステーブル** / **出力テーブル** — 入力ジオメトリと、測定した行の書き込み先です。
- **ジオメトリ列** — 測定するWKTジオメトリ列です。
- **測定値** — 追加する測定値です。選択した項目ごとに、下記の列が追加されます。
- **球の半径（km）** *(任意)* — この半径の球面上で測定します。WGS84楕円体上で測定する場合は、空白のままにします。

## 出力列

| 測定値 | 追加される列 | 型 |
|---|---|---|
| 面積（マイル） | `AreaSqMi` | 数値 |
| 面積（km） | `AreaSqKm` | 数値 |
| 長さ（マイル） | `LengthMi` | 数値 |
| 長さ（km） | `LengthKm` | 数値 |
| 重心の座標 | `CentroidX`, `CentroidY` | 数値 |
| 外接矩形の座標 | `BR_Left`, `BR_Top`, `BR_Right`, `BR_Bottom` | 数値 |
| 重心オブジェクト | `Centroid` | WKTジオメトリ |
| 外接矩形オブジェクト | `BoundingRect` | WKTジオメトリ |
| 外接矩形ポリゴン | `BoundingRectPolygon` | WKTジオメトリ |
| 有効かどうか | `IsValid` | ブール値 |
| オブジェクトタイプ | `SpatialObjType` | テキスト |
| パーツ数 | `NumParts` | 数値 |
| ポイント数 | `NumPoints` | 数値 |
| 終点の座標 | `EndPointX`, `EndPointY` | 数値 |
| 終点オブジェクト | `EndPoint` | WKTジオメトリ |

`IsValid`は、修復前の、指定されたままのジオメトリが有効な形状かどうかを示します。

外接矩形オブジェクトと外接矩形ポリゴンは、WKTでは同じ5頂点のリングにシリアライズされるため、2つの列は同じ値になります。

## 注記

オブジェクトタイプ、パーツ数、ポイント数、終点は、暫定的な列名で追加されます。Alteryxは測定値を文書化していますが出力列名を定めていないため、正確な名前は後続の作業で実際のワークフローと照合して確認されます。変換されない情報タイプは**ペアノキー**のみです。これはAlteryx独自の空間インデックスで、公開仕様がありません。ペアノキーはスキップされ、変換時にそれを示す注記が出力されるため、変換後のワークフローで省略されたことがわかります。
