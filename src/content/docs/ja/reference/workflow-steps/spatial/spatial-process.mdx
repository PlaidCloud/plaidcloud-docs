## 説明

**空間処理**ステップは、各行の2つのジオメトリ列を1つの結果ジオメトリにまとめます。Alteryxの*Spatial Process*ツールに相当し、ワークフローエンジンで実行されます。

## ソースとオプション

- **ソーステーブル** / **出力テーブル** — 入力ジオメトリと、結果の書き込み先です。
- **最初のジオメトリ** / **2番目のジオメトリ** — まとめる2つのWKTジオメトリ列です。
- **アクション** — まとめ方です。
  - **交差** — 2つのジオメトリの重なり部分。
  - **結合** — 2つのジオメトリを合わせたもの。
  - **最初から2番目を切り取り** — 2番目のジオメトリから最初のジオメトリを消去したもの。
  - **2番目から最初を切り取り** — 最初のジオメトリから2番目のジオメトリを消去したもの。
- **空の結果ジオメトリを破棄** — 結果が空の行をスキップします。
- **出力列** — 出力ジオメトリ列の名前です。

## 列

**列**タブでは、出力にそのまま渡す入力列をマッピングします。
