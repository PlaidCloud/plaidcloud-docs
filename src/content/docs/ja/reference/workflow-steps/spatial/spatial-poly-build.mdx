## ソースとオプション

- **ソーステーブル** / **出力テーブル** — 入力ポイントと、結果の書き込み先です。
- **ポイントジオメトリ** — 作成元となるWKTポイントジオメトリ列です。
- **グループ化** — ポイントをグループ化して、個別の出力ポリゴンにするための任意の列です。すべてのポイントから1つのポリゴンを作成する場合は、空白のままにします。
- **作成タイプ** — **シーケンス**は、グループ化されたポイントをポリゴンにディゾルブします。**凸包**は、ポイントの凸包を作成します。
- **出力列** — 出力ジオメトリ列の名前です。

## 列

**列**タブでは、出力にそのまま渡す入力列をマッピングします。
