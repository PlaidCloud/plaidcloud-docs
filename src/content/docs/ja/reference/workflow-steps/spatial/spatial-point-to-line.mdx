## 説明

**空間: ポイントからライン**ステップは、ポイントを結んでラインにし、`SequenceLine`という名前の列に書き込みます。グループごとに1本のラインを書き込みます。グループを指定しない場合は、すべてのポイントを結んだ1本のラインを書き込みます。

## ソースとオプション

- **ソーステーブル**と**出力テーブル** — 読み取るテーブルと、書き込むテーブルです。
- **ポイント列** — WKTポイントを保持する列です。
- **グループ化** *(任意)* — この列の値ごとに1本のラインを作成します。すべてのポイントを1本のラインにする場合は、空白のままにします。
- **並べ替え列** *(任意)* — ライン内のポイントの順序を決める列です。数値は数値として、それ以外の値はテキストとして並べ替えられます。指定しない場合、ポイントは入力順のままです。
