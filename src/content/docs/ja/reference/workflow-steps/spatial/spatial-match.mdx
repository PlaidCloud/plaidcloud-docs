## 説明

**空間照合**ステップは、*ターゲット*テーブルの各行を、選択した空間関係を満たすジオメトリを持つ*ユニバース*テーブルの行とペアにします。一致したターゲットとユニバースのペアごとに、それぞれの側から選択した列を含む出力行を1行出力します。

Alteryxの*Spatial Match*ツールの一致パスに相当するSQLネイティブな機能です。処理は空間述語結合として完全にデータベース内で実行されるため、行をワークフローエンジンに取り込むことなくスケールできます。

2つのジオメトリ列はどちらも**WKT**（Well-Known Text）形式でジオメトリを保持します。これは、PlaidCloudの他の空間ヘルパーが生成し、利用する形式と同じです。

## ソースとオプション

- **ターゲットテーブル** — 一致を探す*対象*の行です。
- **ユニバーステーブル** — 照合先となる候補の行です。
- **出力テーブル** — 一致したペアの書き込み先テーブルです。
- **ターゲットジオメトリ / ユニバースジオメトリ** — 関係をテストする、両側のWKTジオメトリ列です。
- **関係** — ターゲットジオメトリとユニバースジオメトリの関係です。
  - **交差** — 2つのジオメトリが何らかの点を共有します。
  - **内包** — ターゲットジオメトリがユニバースジオメトリの内側にあります。
  - **含む** — ターゲットジオメトリがユニバースジオメトリを含みます。

一致するユニバースの行がないターゲットの行は、出力から除外されます（これは一致であり、左結合ではありません）。

## ターゲットとユニバースのマッピング

各入力には専用のマッピングタブがあり、そのテーブルで利用できる列が一覧表示されます。上記のジオメトリ選択の候補として使用されるほか、出力で利用できる列にもなります。

## 出力列

出力に含める列と、それぞれがどちら側（ターゲットまたはユニバース）の列かを選択し、必要に応じて名前を変更します。

### 古い列

出力列の行が、その側のマッピングタブである**ターゲットのマッピング**または**ユニバースのマッピング**に、もう表示されていない列を指していることがあります。ステップがこのような行を自動的に削除することはありません。代わりに、列名が⚠警告マークの後ろに赤色で表示され、カーソルを重ねると、どのマッピングにその列がないかが表示されます。列が1つも表示されていないマッピングに対しては、チェックは行われません。

警告が付いた行が残っているステップを保存すると、**古い列が見つかりました**ダイアログに該当する行が一覧表示され、3つの選択肢が表示されます。

- **すべて削除して保存** — 警告が付いた行を削除してから保存します。
- **このまま保存** — ステップをそのまま保存します。
- **キャンセル** — 保存せずにステップに戻ります。

行を残したまま警告を解除するには、マッピングタブにその列を追加し直すか、マッピングに表示されている列を選択します。

## 注記

関係は、PlaidCloudの他の空間ステップと同様に、ジオメトリの座標に基づいて評価されます。

AlteryxのSpatial Matchツールの*交差オブジェクト*出力（重なり部分そのもののジオメトリ）と*Unmatched*出力（一致しないターゲット行）は、代わりに[Spatial Match (Intersect / Unmatched)](/ja/reference/workflow-steps/spatial/spatial-match-executor/)ステップが提供します。どちらもデータベースの述語結合では表現できないため、ワークフローエンジンで実行されます。
