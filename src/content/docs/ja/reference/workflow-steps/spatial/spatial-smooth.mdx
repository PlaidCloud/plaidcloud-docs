## 説明

**Spatial Smooth**ステップは、各ジオメトリを指定したパス数で平滑化します。Alteryxの*Smooth*ツールに相当し、ワークフローエンジンで実行されます。

## ソースとオプション

- **ソーステーブル** / **出力テーブル** — 入力ジオメトリと、結果の書き込み先です。
- **ジオメトリ列** — 平滑化するWKTジオメトリ列です。
- **パス数** — 適用する平滑化のパス数です。

## 列

**列**タブでは、出力にそのまま渡す入力列をマッピングします。
