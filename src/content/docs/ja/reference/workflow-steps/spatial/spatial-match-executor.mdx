## 説明

**Spatial Match (Intersect / Unmatched)**ステップは、各ターゲットジオメトリを、関係があるユニバースジオメトリとペアにします。一致した各ペアの**交差ジオメトリ**（*IntersectPoly*）、または**不一致**のターゲット行のどちらかを出力できます。通常の一致したペアを扱うSQLの[空間照合](/ja/reference/workflow-steps/spatial/spatial-match/)ステップを補完するもので、このエグゼキューターベースのステップは、データベースSQLでは表現できない2種類の出力を扱います。

## ソースとオプション

- **ターゲットテーブル** / **ユニバーステーブル** — 照合するジオメトリと、照合先の候補です。
- **出力テーブル** — 結果の書き込み先です。
- **ターゲットジオメトリ / ユニバースジオメトリ** — 両側のWKTジオメトリ列です。
- **関係** — 交差、内包、含む、接触、横断、重複、等しい、分離のいずれかです。*等しい*は位相的に等しいジオメトリのみに一致し、*分離*は共有する点がないペアに一致します。nullのジオメトリが*分離*に一致することはありません。
- **Multiple Rules** — 照合では、複数のターゲットおよびユニバースのジオメトリ列を同時に関連付けることができ、ルールごとに関係を指定します。`joiner`設定は、ペアがすべてのルールを満たす必要があるか（*and*、デフォルト）、いずれかのルールを満たせばよいか（*or*）を指定します。Savantの変換では、複数ルールの照合が生成されます。不明な関係またはjoinerを指定すると、交差として実行されるのではなく、名前を示してステップが失敗します。
- **交差ジオメトリ（IntersectPoly）も出力** — 一致した各ペアの重なり部分のジオメトリを列として追加します。
- **出力** — *一致したペア*または*一致しないターゲット行*です。

## ターゲットとユニバースのマッピング

各入力には、その列を一覧表示するマッピングタブがあります。ジオメトリの選択候補として使用されるほか、列を出力にそのまま渡すためにも使用されます。
