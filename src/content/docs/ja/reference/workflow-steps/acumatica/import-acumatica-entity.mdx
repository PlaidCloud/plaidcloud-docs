## 説明

[Acumatica接続](/ja/guides/connections/acumatica/)を通じて、Acumaticaのコントラクトベース RESTエンティティを1つ、プロジェクトテーブルにインポートします。接続、エンティティタイプ、必要に応じてフィルターを選ぶと、ステップが一致するレコードを取得して書き込みます。ODataクエリを作成する必要はありません。

これは汎用の定型ステップで、1つのステップタイプで18のエンティティ（マスター/参照データである勘定科目、補助科目、顧客、仕入先、在庫品目から、トランザクションレコードである売上請求書、請求、受注、出荷まで）に対応します。

## 構成

| フィールド | 必須 | 備考 |
|---|---|---|
| Acumatica接続 | はい | 読み取りに使用するAcumatica接続です。 |
| ターゲットテーブル | はい | 結果の書き込み先のプロジェクトテーブルです。実行のたびにすべて上書きされます。 |
| エンティティタイプ | はい | 取得するエンティティです。デフォルトは`account`です。`account`、`ledger`、`financial_period`、`branch`、`currency`、`currency_rate`、`subaccount`、`customer`、`vendor`、`stock_item`、`warehouse`、`employee`、`tax_category`、`sales_invoice`、`bill`、`sales_order`、`shipment`、`project`のいずれかです。 |
| アクティブのみ | いいえ | デフォルトはオンです。Activeフラグを持つエンティティでは`Active = true`でフィルターします。 |
| 更新日時以降 | いいえ | ISO形式の日付または日時です。この日時より後に変更された行のみが返されます。これはリクエスト側のフィルターで、永続化されたカーソルはありません。実行のたびにカットオフを自分で指定してください。空白の場合はすべてを取得します。 |
| Filters | いいえ | `{field, operator, value}`句（`eq`、`ne`、`gt`、`ge`、`lt`、`le`、`contains`）または`{field, from, to}`範囲の配列です。各エンティティでは、Acumaticaがサーバー側で実際に評価できるフィールドにフィルターが限定されます。サポートされていないフィールドは、黙って破棄されずに拒否されます。 |

<Aside type="note">
試算表、総勘定元帳のトランザクション明細、在庫残高、予算、会社間データは、これらの18のコントラクトベースのエンティティではなく、Acumaticaのジェネリック照会の背後にあります。代わりに、Acumaticaでジェネリック照会を作成し、[汎用REST接続](/ja/reference/connectors/rest/generic-rest/)で取得してください。
</Aside>

<Aside type="caution">
フィルターが及ぶのはエンティティレベルとヘッダーレベルのフィールドのみです。ドキュメントの明細行のディメンション（たとえば請求の明細行のコストセンター）は、サーバー側では照会できません。エンティティを取得し、明細レベルの詳細の絞り込みはインポートの後にワークフローで行ってください。
</Aside>
