## 説明

[Oracle Essbase接続](/ja/guides/connections/essbase/)を通じて、Oracle **Essbase**キューブから1つのディメンションアウトラインを読み取り、PlaidCloudディメンションの**メイン階層**に読み込みます。

このステップは、ステップメニューの**Oracle Essbase**の下に表示されます。

このステップは、REST APIを介して**クラウド直結**でEssbaseに接続します。このステップにはオンプレミスのエージェント経由のパスはなく、リモート版もありません。

## 設定

### Essbaseソース

| フィールド | 必須 | 備考 |
|---|---|---|
| 接続 | はい | 読み取りに使用する[Oracle Essbase接続](/ja/guides/connections/essbase/)です。 |
| アプリケーション | はい | 読み取り元のEssbaseアプリケーションです。ピッカーには、接続のサービスアカウントが参照できるアプリケーションが一覧表示されます。接続にデフォルトのアプリケーションが設定されている場合は、あらかじめ選択されています。 |
| キューブ（データベース） | はい | 選択したアプリケーション内で、アウトラインの読み取り元となるキューブです。 |
| ディメンション | はい | アウトラインを読み取るEssbaseディメンションです。 |

### ターゲットのPlaidCloudディメンション

| フィールド | 必須 | 備考 |
|---|---|---|
| ターゲットディメンション | はい | アウトラインの読み込み先のPlaidCloudディメンションです。 |

## このステップで表現できないこと

| 制限事項 | 意味 |
|---|---|
| 共有メンバー | 共有メンバーは、別の親の下で、他のメンバーのデータを再利用します。PlaidCloudのディメンションノードの親は1つだけであるため、共有メンバーは、重複として読み込まれたり黙って破棄されたりすることなく、名前を示して拒否されます。主要なロールアップを独立したPlaidCloudディメンションとして読み取ってください。共有メンバーの2つ目の親は、ここでは表現できません。 |
| ラベルのみのメンバー | ラベルのみのメンバーはナビゲーションのために存在し、それ自体のデータを持つことはありません。下流のどのステップも空であると想定していない通常のメンバーとして読み込まれることなく、名前を示して拒否されます。 |
| Dynamic Calcメンバー | Dynamic Calcメンバーの値は、Essbaseがその都度計算するもので、保存されません。このステップが読み取るのはアウトラインの構造であり、計算されたデータではないため、Dynamic Calcメンバーは、保存されたメンバーであるかのように読み込まれることなく、名前を示して拒否されます。 |
| 属性ディメンション | 属性ディメンションは、基本ディメンションのメンバーを分類するもので、それ自体でファクトの階層になるものではありません。読み取りようとすると、その場で拒否されます。代わりに基本ディメンションを読み取ってください。 |
| 表現できない集計演算子 | PlaidCloudのエッジは、集計フラグ（`+`、`-`、`~`）を持ちます。Essbaseの `+` と `-` の演算子は、そのまま対応づけられます。`*`、`/`、`%` は、単純なロールアップの符号として表現できません。これらを使用するメンバーは、誤った符号で読み込まれることなく、名前を示して拒否されます。 |
| メンバー数の上限を超えるアウトライン | **アウトラインのメンバー総数が5,000を超える**ディメンションアウトラインは、部分的に読み込まれることなく拒否され、エラーには検出された数と上限の両方が示されます。階層のより浅いレベル、またはより小さなサブツリーを読み取って、上限以内に収めてください。 |
