## 説明

PDFのテキスト内容をテーブルに抽出します。Alteryxの *PDF to Text* ツールに相当し、ドキュメント用のライブラリがあるワークフローエンジンで実行されます。

PDFの内容を、ワークフローの残りの部分でフィルター、解析、結合できる形式にするために使用します。ページ単位の抽出やレイアウトを考慮した抽出には、代わりに[PDF Text Extractステップ](/ja/reference/workflow-steps/text-documents/document-pdf-extract/)を使用してください。

## ソースとオプション

- **ソーステーブル** / **出力テーブル** — PDFを指定するテーブルと、抽出したテキストの書き込み先。
- **列** — 出力に渡すソース列。
