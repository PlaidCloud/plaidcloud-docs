## 説明

**PDF Text Extract** ステップは、PDFドキュメントからテキストを抽出します。対応するAlteryxのツールに相当し、ワークフローエンジンで実行されます（ML、NLP、ドキュメント用のライブラリは、エグゼキュータージョブで実行されます）。

## ソースとオプション

- **ソース / 出力テーブル** — 入力データと、結果の書き込み先。
- **PDF path column**（または、PDFの **ディレクトリ**）。

## 列

**列** タブで、出力に渡す入力列をマッピングします。
