## 説明

**Text Topic Model** ステップは、テキスト列からトピックを検出します。対応するAlteryxのツールに相当し、ワークフローエンジンで実行されます（ML、NLP、ドキュメント用のライブラリは、エグゼキュータージョブで実行されます）。

## ソースとオプション

- **ソース / 出力テーブル** — 入力データと、結果の書き込み先。
- **テキスト列**、トピック数、および語彙サイズ。

## 列

**列** タブで、出力に渡す入力列をマッピングします。

## KNIMEテキスト処理ノード

**KNIME テキスト処理ノード** グループで **KNIME テキスト ノード**（`node`）を選択すると、KNIMEのテキスト処理ノードの1つをこのステップで実行できます。たとえば、`preprocess`、`tagger`、`bag_of_words`、`frequency`、`document_vector`、`keywords`、`topics`、`language`、または埋め込みノードです。**ドキュメント列**（`document_column`）や **出力列**（`output_column`）など、ノード自身の設定は、`knime_config` にその横に表示されます。ノードを **（なし）** のままにすると、ステップ自身の設定が実行されます。変換されたKNIMEワークフローでも、同じキーが設定されます。

**KNIME ノードのテーブル** グループでは、辞書、エンティティリスト、語彙など、2つ目のテーブルを読み取るノードは、**2 つ目の入力テーブル**（`source_b`）を、**2 つ目のテーブルの列**（`source_b_columns`）の列で読み取ります。追加の出力を持つノードは、それらを **その他の出力テーブル**（`targets`）に列挙されたテーブルに、順番に書き込みます。
