## 説明

**Text Word Cloud** ステップは、テキスト列からワードクラウド画像を生成します。対応するAlteryxのツールに相当し、ワークフローエンジンで実行されます（ML、NLP、ドキュメント用のライブラリは、エグゼキュータージョブで実行されます）。

## ソースとオプション

- **ソース / 出力テーブル** — 入力データと、結果の書き込み先。
- **テキスト列**、最大単語数、画像サイズ、および背景色。

## 列

**列** タブで、出力に渡す入力列をマッピングします。
