## 説明

バージョン管理された Alteryx パリティ操作を、管理対象のジョブとして実行します。データベースの SQL ではなく、Shapely、scikit-learn、NLTK、Tesseract、reportlab などの Python ライブラリを必要とする [Alteryx 変換](/ja/guides/workflows/migrate-alteryx-workflows/)の汎用的な実行基盤です。

変換された操作の多くには、現在は専用のステップタイプがあり、読みやすく編集もしやすくなっています。このステップは、専用のステップタイプがない操作のために残されており、それらのステップタイプが内部で起動するステップでもあります。

<Aside type="note" title="通常は手作業で作成しません">
  このステップは、必要な場合に変換によって生成されます。手作業で追加するのは、専用のステップタイプがないパリティ操作（たとえば
  [Spatial Info](/ja/reference/workflow-steps/spatial/spatial-info/) ステップ）を実行する場合だけです。
</Aside>

## 設定

### エグゼキューター

- **操作** — 実行するパリティ操作です。
- **Contract version** — 操作が実行されるエグゼキューターのコントラクトです。デフォルトは `v1` です。

### 入力と出力

- **ソース** / **ターゲットテーブル** — 主な入力テーブルと出力テーブルです。
- **入力テーブル** / **出力テーブル** — 複数のテーブルを受け取る、または生成する操作のための追加テーブルです。
- **Input artifacts** / **Output artifacts** — レンダリングされた画像など、テーブル以外の入力と出力です。

### リソース

デフォルトではオフで、その場合ジョブには標準のリソースが割り当てられます。高度なリソース管理をオンにすると、**CPU** と **メモリ** を明示的に設定できます。操作が非常に大きなジオメトリを扱う場合やモデルの学習を行う場合に、デフォルトの割り当てでは足りないときは、これを設定してください。
