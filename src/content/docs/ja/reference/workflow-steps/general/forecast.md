## 説明

**予測**ステップは、入力テーブルから時系列を読み取り、予測モデルを適合させて、将来の予測値を出力テーブルに書き込みます。日付ごとの過去の値があり、ワークフローで再現性のある予測を作成したい場合に使用します。

## 設定

### 予測パラメーター

* **入力テーブル** *（必須）* — 過去の時系列を含むテーブル。
* **出力テーブル** *（必須）* — 予測行を書き込むテーブル。
* **日付列** *（必須）* — 各観測値の日付またはタイムスタンプを含む、マッピングされたターゲット列。デフォルトは `ds` です。
* **値列** *（必須）* — 予測する数値を含む、マッピングされたターゲット列。
* **系列列** *（任意）* — 同じテーブル内の個別の系列（顧客、製品、地域、勘定科目など）を識別する、マッピングされたターゲット列。
* **頻度** — `Auto`、`Hourly`、`Daily`、`Weekly`、`Monthly`、`Quarterly` のいずれかです。入力の日付が疎または不規則な場合は、頻度を明示的に指定します。
* **予測期間** — 予測する将来の期間数。デフォルトは 12 です。
* **モデル** — デフォルトは `Automatic` です。`AutoETS`、`AutoARIMA`、`Seasonal Naive`、`Naive`、`AutoTheta` も選択できます。

### テーブルデータの選択

予測の前に入力テーブルを整形するには、テーブルデータの選択タブを使用します。マッピングされたターゲット列には、**日付列**、**値列**、およびすべての**系列列**を含める必要があります。

**ソースを検査**を使用すると、選択した入力テーブルからマッピングを入力できます。列を調整する前に、マッピングの両側、ソース側のみ、またはターゲット側のみを入力できます。

マッピングにソース列がない場合は、保存が拒否されます（*Source columns are required: use Populate to read them from the input table.*）。また、ターゲット列に**日付列**、**値列**、または**系列列**が含まれていない場合も拒否されます。

### データフィルター

フィルタータブを使用すると、予測の実行前に、行の制限、条件の適用、入力データの集計、結果の絞り込みを行えます。

## 動作

このステップは、選択した予測期間分の予測行を含む出力テーブルを作成または更新します。**系列列**を設定すると、PlaidCloud は各系列を個別に予測し、出力に系列の値を含めます。

## ARIMA モデル、適合、診断

**モデルの設定**セクションには、次のフィールドがあります。

* **モデル** (`forecast_model`) — 上記のモデル（`automatic`、`auto_ets`、`auto_arima`、`seasonal_naive`、`naive`、`auto_theta`）に加えて、**ARIMA**、**季節 ARIMA (SARIMA)**、**回帰子付き季節 ARIMA (SARIMAX)** (`arima`、`sarima`、`sarimax`) では、指定した次数を適合させます。**ARIMA 次数 (p, d, q)** (`order`) は `[p, d, q]`、**季節次数 (P, D, Q, m)** (`seasonal_order`) は `[P, D, Q, s]` (`sarima`、`sarimax`) で、**回帰子の列** (`exog_columns`) は外生回帰子の列を指定します (`sarimax`)。
* **モード** (`mode`) — `forecast`（デフォルト）はすべての系列の予測を書き込みます。`fit` は `arima`、`sarima`、`sarimax` で 1 つの系列を適合させ、モデルをテーブルとして書き込みます。`apply` は **モデルテーブル** (`model_frame`) で指定したモデルテーブルの予測を書き込みます。`sarimax` モデルの場合、入力テーブルには将来の回帰子が含まれます。
* **値の対数を適合** (`log_transform`) — 値の自然対数に対して適合させます。`apply` の場合は、予測値を対数スケールから戻して返すかどうかを指定します。
* **代わりに診断を書き込む** (`diagnostics`) — 予測の代わりに 1 つのテーブルを書き込みます。`model_frame` のモデルの `residuals` または `coefficients`、入力値列の `autocorrelation`（ACF と PACF）または `residual_stats`、あるいは `ljung_box`（モデルの残差、ない場合は入力値列の各ラグについての Q 統計量と p 値）を指定できます。**最大ラグ** (`max_lag`、デフォルトは 40) は `autocorrelation` と `ljung_box` の最大ラグで、**動的に予測 (予測値をフィードバック)** (`dynamic`) を指定すると、`residuals` で動的なサンプル内予測を使用します。
* **KNIME 時系列ノード** (`knime_config`) — 予測の代わりに KNIME の時系列準備ノードを実行します。`aggregate_granularity` は値を年、四半期、月、週、日、時、分、秒に集計し、`align_timestamps` は値を期間に揃えます。

AI アシスタントまたは REST API では、予測区間のレベルである `interval_levels` も設定できます。使用できるレベルは `95` のみです。

## リソース

予測の処理は別のジョブで実行されます。予測にデフォルトの要求より多くの CPU やメモリが必要な場合にのみ、**高度なリソース管理**を有効にします。リソース要求を増やすと、容量がスケジュールされるまで予測の開始が遅れる場合があります。これと合わせて `cpu`（1～7、デフォルトは 1）と `memory`（8～56 GiB、デフォルトは 8）を設定します。
