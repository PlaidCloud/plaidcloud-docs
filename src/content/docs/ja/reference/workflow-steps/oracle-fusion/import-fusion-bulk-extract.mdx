## 説明

[Oracle Fusion 接続](/ja/guides/connections/oracle-fusion/)を使用して、Oracle の FBDI/BI Publisher による一括抽出の経路で Oracle Fusion Cloud のエンティティをインポートします。PlaidCloud はエクスポートジョブを送信し、完了するまでポーリングし、生成されたファイルをダウンロードして、プロジェクトテーブルに書き込みます。OData/BIP の直接呼び出しでは大きすぎる、または遅すぎる取得には、[Import Fusion Entity ステップ](/ja/reference/workflow-steps/oracle-fusion/import-fusion-entity/)の代わりにこのステップを使用します。

## 設定

| フィールド | 必須 | 備考 |
|---|---|---|
| Fusion接続 | はい | 読み取りに使用する Oracle Fusion 接続です。 |
| ターゲットテーブル | はい | 結果の書き込み先のプロジェクトテーブルです。実行のたびに全体が上書きされます。 |
| エンティティタイプ | はい | 抽出するエンティティです。デフォルトは `gl_balances` です。`gl_balances`、`journal_batches` のいずれかです。 |
| フィルター | いいえ | [Import Fusion Entity ステップ](/ja/reference/workflow-steps/oracle-fusion/import-fusion-entity/)と同じフィルターセットです。日付、会計期間、数値の残高／金額フィールドに対する範囲フィルター（`ge`/`le`）と、離散フィールドに対する等価フィルターを使用できます。抽出ジョブのレベルで適用されます。 |

<Aside type="caution">
このステップは非同期のエクスポートジョブを待機するため、同じ行数でも [Import Fusion Entity ステップ](/ja/reference/workflow-steps/oracle-fusion/import-fusion-entity/)よりかなり長くかかります。取得が OData/BIP の直接呼び出しでは本当に大きすぎる場合にのみ使用してください。
</Aside>
