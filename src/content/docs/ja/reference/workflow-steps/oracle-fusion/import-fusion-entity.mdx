## 説明

[Oracle Fusion接続](/ja/guides/connections/oracle-fusion/)を使用して、Oracle Fusion Cloud の 1 つのエンティティをプロジェクトテーブルにインポートします。Fusion の OData エンドポイントまたは BI Publisher（BIP）エンドポイントを直接呼び出します。接続、エンティティタイプ、必要なフィルターを選択するだけで、ステップが条件に一致するレコードを取得して書き込みます。OData クエリを自分で作成する必要はありません。

直接呼び出しでは処理しきれない大規模な取得には、代わりに [Import Fusion Bulk Extractステップ](/ja/reference/workflow-steps/oracle-fusion/import-fusion-bulk-extract/)を使用してください。

## 設定

| フィールド | 必須 | 備考 |
|---|---|---|
| Fusion接続 | はい | 読み取りに使用する Oracle Fusion 接続です。 |
| ターゲットテーブル | はい | 結果の書き込み先となるプロジェクトテーブルです。実行のたびに全体が上書きされます。 |
| エンティティタイプ | はい | 取得するエンティティです。デフォルトは `gl_balances` です。`gl_balances` または `journal_batches` のいずれかを指定します。 |
| フィルター | いいえ | 日付、会計期間、数値の残高/金額フィールドに対する範囲フィルター（`ge`/`le`）と、離散フィールド（元帳、通貨）に対する等価フィルターです。各エンティティでは、Oracle Fusion がサーバー側で実際に評価できるフィールドにのみフィルターを使用できます。サポートされていないフィールドは、黙って無視されるのではなく拒否されます。 |

### エンティティとフィルター可能なフィールド

| エンティティタイプ | 取得内容 | フィルター可能なフィールド |
|---|---|---|
| `gl_balances` | 総勘定元帳の勘定科目残高 | 会計期間の範囲（`ge`/`le`）、勘定科目の範囲、残高金額の範囲（`ge`/`le`） |
| `journal_batches` | 仕訳バッチのヘッダーとステータス | 日付の範囲（`ge`/`le`）、会計期間の範囲（`ge`/`le`） |

<Aside type="note">
範囲フィルターは、片方の境界だけでも使用できます。たとえば、上限を指定せずに `accounting_date ge 2026-01-01` とすると、その日付以降のすべてを取得します。取得範囲を厳密に絞り込むには、両方の境界を指定してください。
</Aside>
