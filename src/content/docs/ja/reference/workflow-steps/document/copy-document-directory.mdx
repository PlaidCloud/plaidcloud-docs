## 説明


PlaidCloud Document内のディレクトリ全体をコピーします。



## ディレクトリのコピー


まず、ドロップダウンメニューから適切なアカウントを選択します。



次に、**参照**ボタンを押して、コピーするディレクトリを選択します。



## 宛先の選択


まず、ドロップダウンメニューから適切なアカウントを選択します。



次に、**参照**ボタンを押して、コピーしたディレクトリの宛先を選択します。 



必要に応じて、コピーしたディレクトリに新しい名前を付けることもできます。その場合は、**Rename the Copied Folder to:** ボックスをオンにして、新しい名前を入力します。


<Aside>デフォルトでは、すでに存在するものは上書きされます。誤って上書きしないよう注意してください。</Aside>
