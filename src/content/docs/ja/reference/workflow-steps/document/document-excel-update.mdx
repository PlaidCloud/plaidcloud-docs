## 説明

**Document: Update Excel Cells**ステップは、ドキュメントアカウント内の `.xlsx` ブックの個々のセルに値を書き込み、ブックのそれ以外の部分はそのまま残します。入力テーブルの各行が、セルと、そこに書き込む値を指定します。代わりに、書式設定指示のテーブルに基づいて、ブックに書式を適用することもできます。

ステップフォームのオプションは、**ブック**、**セル**、**書式設定**の3つのグループに分かれています。KNIMEから移行したワークフローでは、Excelのセル更新ノードと書式設定ノードの代わりにこのステップが使用されます。

存在しないブックはエラーになりません。ステップはブックに触れず、そのパスを示す警告とともに終了します。

## セルの値を設定する

- **ソーステーブル**（`source`）— セルのアドレスと新しい値を持つテーブルです。**ソース列**（`source_columns`）には、アドレス列と値の列を指定します。
- **アドレス列**（`address_column`）— 各セルのアドレスを保持する列です。`A5` のような形式、または1から始まる数値による `column:row` の形式で指定します。
- **ブック**（`file`）— 更新するブックです。`{account, path}` で指定します。
- **シート**（`sheet_name`）— 更新するシートです。ブックにその名前のシートがない場合は、追加されます。
- **欠損値に書き込まれる値**（`replace_missing`）— 行に値がないセルに書き込まれる値です。空のままにすると、セルは空白のままになります。

## ブックの書式を設定する

**書式設定指示テーブル**（`source_b`）に、書式設定指示のテーブルを設定します。1つの指示につき1行です。**指示列**（`source_b_columns`）には、種類、タグ、パラメーターの各列を指定します。種類は `font`、`background`、`cell`、`border`、`merge`、`conditional`、`size`、`comment`、`hyperlink`、`sheet_properties`、`sheet` のいずれかで、パラメーターには指示の設定をJSONで指定します。この場合、**ソーステーブル**はシートに重ねる制御テーブルになります。各セルには、そのセルに適用する指示のタグをカンマ区切りで指定します。**アドレス列**と**シート**は使用されません。

## コピーを書き込む

- **更新したブックの書き込み先**（`output_file`）— 更新したブックを、元のブックに上書きせず、この `{account, path}` に書き込みます。
- **すでに存在するファイル**（`if_exists`）— **更新したブックの書き込み先**を指定した場合に、**上書きする**（`overwrite`、デフォルト）は既存のファイルを置き換え、**ステップを失敗させる**（`fail`）はステップを停止します。
