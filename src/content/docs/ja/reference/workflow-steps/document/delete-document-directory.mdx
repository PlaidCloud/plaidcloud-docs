## 説明


PlaidCloudドキュメント内にある既存のディレクトリを削除します。



## 削除するフォルダー


まず、ドロップダウンメニューから該当するアカウントを選択します。


次に、**参照**ボタンを押して、削除するディレクトリを選択します。


<Aside>存在しないフォルダーはエラーになりません。ステップは何もせず、ストレージがフォルダーの不在を報告した場合は、そのパスを示す警告とともに終了します。</Aside>


## ファイルのみを削除する

フォルダーを残したまま中身を空にするには、**中のファイルだけを削除し、フォルダーは残す**（`files_only`）をオンにします。削除対象は、**対象ファイル**のオプションで絞り込めます。

* **中のファイルだけを削除し、フォルダーは残す**（`files_only`）— フォルダー内のファイルを削除し、フォルダー自体とそのサブフォルダーは残します。
* **サブフォルダー内のファイルも**（`include_subdirs`）— `files_only` と併用すると、配下のすべてのサブフォルダー内のファイルも削除します。
* **ファイル名のパターン**（`file_name_filter`）— 名前が一致するファイルのみが対象です。**パターンの種類**は**ワイルドカード**または**正規表現**（`type`）で、**大文字と小文字を区別する**は `case_sensitive` を設定します。
* **フォルダー名のパターン**（`folder_name_filter`）— 名前が一致するフォルダー内のファイルのみが対象です。形式は同じで、下位に向かう途中のすべてのフォルダーが一致する必要があります。
* **拡張子**（`extensions`）— ドットを付けずに指定した拡張子のいずれかを持つファイルのみが対象です。**拡張子の大文字と小文字を区別する**（`extensions_case_sensitive`）をオンにすると、大文字と小文字を区別して照合します。
* **隠しファイル（ドットで始まる名前）を含める**（`include_hidden_files`）と**隠しフォルダーとその配下を含める**（`include_hidden_folders`）— どちらかをオフにすると、ドットで始まる名前のファイルまたはフォルダーが対象から除外されます。

ファイルが見つからない場合（フォルダーが存在しない場合も含む）、ステップは何もせず、そのパスを示す警告とともに終了します。
