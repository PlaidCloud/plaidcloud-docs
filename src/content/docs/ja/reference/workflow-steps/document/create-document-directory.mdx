## 説明


PlaidCloud Document内に新しいディレクトリを作成します。



## 新しいフォルダーの作成場所


まず、ドロップダウンメニューから適切なアカウントを選択します。



次に、**参照**ボタンを押して、親ディレクトリを選択します。



## 新しいフォルダー名


新しいディレクトリの名前を入力します。


<Aside>ディレクトリがすでに存在する場合、何も行われません。</Aside>
