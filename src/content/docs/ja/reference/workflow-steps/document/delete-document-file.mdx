## 説明


PlaidCloudドキュメント内にある既存のファイルを削除します。



## 削除するファイル


まず、ドロップダウンメニューから該当するアカウントを選択します。


次に、**参照**ボタンを押して、削除するファイルを選択します。

<Aside>ファイルが存在しない場合（すでに削除されている場合）は、何も行われません。</Aside>
