## 説明


PlaidCloud Document内の単一のファイルをコピーします。



## コピーするファイル


まず、ドロップダウンメニューから適切なアカウントを選択します。



次に、**参照**ボタンを押して、コピーするファイルを選択します。

1つのファイルの代わりに、**検索に一致するファイルをコピー**を選択して、名前が検索テキストに一致するファイル（**完全一致**、**次で始まる**、**含む**、**次で終わる**）をコピーするか、**ディレクトリ内のすべてのファイルをコピー**を選択することもできます。フォルダー全体をコピーする場合は次のようになります。

* **サブフォルダーを保持**は、各ファイルをフォルダー以下のパスに配置するため、コピーでもフォルダーの構造が保たれます。これを使用しない場合、すべてのファイルは、名前だけで宛先フォルダーの直下に配置されます。
* **サブフォルダーをスキップ**は、フォルダー自身のファイルのみをコピーし、サブフォルダー内のファイルはコピーしません。

**名前が一致するファイルのみコピー (正規表現)** フィールドは、これらの選択肢のいずれかを、名前が先頭から正規表現に一致するファイル（たとえば`sales_\d{4}\.csv`）に絞り込みます。一致判定では大文字と小文字が区別されます。空白のままにすると、選択したすべてのファイルがコピーされます。有効な正規表現ではないパターンや、`(a+)+`のように、繰り返し自体が繰り返される部分を含むパターンは、ステップの保存時に拒否されます。

ソースのファイルまたはフォルダーが存在しない、または空の場合、ステップはそのパスを示す警告を出して終了し、何もコピーされません。



## 宛先の選択


まず、ドロップダウンメニューから適切なアカウントを選択します。



次に、**参照**ボタンを押して、コピーしたファイルの宛先を選択します。



デフォルトでは、Analyzeはファイルの上書きを許可しません。代わりに、以降のコピーごとに連番のサフィックスが追加されます。 



既存のファイルを上書きするには、**Allow Overwriting Existing File** ボックスをオンにします。



ファイル名を変更するには、**Rename the copied file to** ボックスをオンにして、新しい名前を入力します。

<Aside>ファイル名を変更する際は、必ずファイル拡張子を指定してください。拡張子がなくてもファイルは正常に作成されますが、オペレーティングシステムがファイルの種類を認識できません。</Aside>


## 追加設定

**ファイルが存在する場合**の下にある**すでに存在するファイル**（`overwrite_policy`）で、宛先にすでにファイルがある場合の動作を設定します。**上書きコピーする**（`overwrite`、デフォルト）、**ソースの方が新しい場合は上書きコピーする**（`overwrite_if_newer`）、**そのままにする**（`skip`）、**何もコピーせずにステップを失敗させる**（`fail`）から選択します。

**ディレクトリ内のすべてのファイルをコピー**を選択した場合、**対象ファイル**のオプションでコピーする内容を絞り込みます。

* **サブフォルダー内のファイル**（`include_subdirs`）— **いいえ**はフォルダー自身のファイルのみをコピーし、**はい**はフォルダーの下にあるすべてのファイルを、それぞれのフォルダーを保ったままコピーします。未設定のままにすると、**サブフォルダーを保持**と**サブフォルダーをスキップ**の説明のとおり、すべてのファイルが名前だけで宛先フォルダーの直下にコピーされます。
* **ファイル名のパターン**（`file_name_filter`）— 名前が一致するファイルのみが対象です。**パターンの種類**は**ワイルドカード**または**正規表現**（`type`）で、**大文字と小文字を区別する**は`case_sensitive`を設定します。
* **フォルダー名のパターン**（`folder_name_filter`）— 名前が一致するフォルダー内のファイルのみが対象で、指定方法は同じです。途中のすべてのフォルダーが一致する必要があります。
* **拡張子**（`extensions`）— ドットなしで、これらの拡張子のいずれかを持つファイルのみが対象です。**拡張子の大文字と小文字を区別する**（`extensions_case_sensitive`）は、大文字と小文字を区別して一致させます。
* **隠しファイル（ドットで始まる名前）を含める**（`include_hidden_files`）と**隠しフォルダーとその配下を含める**（`include_hidden_folders`）— どちらかをオフにすると、名前がドットで始まるファイルまたはフォルダーが除外されます。
