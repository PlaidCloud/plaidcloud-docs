## 説明

ダッシュボードをPDFにレンダリングし、ドキュメントアカウントに書き込みます。ダッシュボードをスケジュールに載せたいときに使用します。たとえば、月次決算のパック、ログインしない人への配布、特定の日の数値を記録したスナップショットのアーカイブなどです。

このステップはフィルターデータセットの行ごとにレンダリングを行い、各行の値をダッシュボードのフィルターとして適用します。そのため、1つのステップで、リージョンごとやエンティティごとのPDFセットを1回の実行で生成できます。

## 設定

### ダッシュボード

レンダリングするダッシュボードです。

### フィルターデータセット

レンダリングの元になるテーブルです。1行につき1つのPDFが生成されます。

### 出力パス

PDFの書き込み先となるドキュメントアカウントとフォルダーです。

### オプション

- **PDFの同時生成** — 同時に実行するレンダリングの数です。デフォルトは8です。ダッシュボードが重く、並列レンダリングがタイムアウトする場合は、この値を小さくします。
- **レンダリング待機時間（秒）** — ステップの設定には存在しますが、ワークフローランナーでは**現在適用されていません**。現時点では、設定しても効果はありません。

### ダッシュボードフィルター

ダッシュボード自身のフィルターです。それぞれに**ダッシュボードフィルターID**があります。マッピングを入力するときに、ダッシュボードから読み取られます。

### ソース列のマッピング

フィルターデータセットの列と、各列の使われ方です。**ソースを検査 › マッピングテーブルを入力**を使用して、列とダッシュボードのフィルターを読み取ります。ダッシュボードのフィルターと同じ名前の列は、そのフィルターに対するフィルターとしてタグ付けされます。もう一度入力しても、列にすでに設定した**種類**と**マップ済みフィルター列**は保持されます。

各列の**種類**を設定します。

- **列フィルター** — 列の値が、**マップ済みフィルター列**で指定したダッシュボードフィルターに設定されます。指定するフィルターは、ダッシュボードのフィルターのいずれかでなければなりません。
- **ファイル名** — 列が各PDFのファイル名になります。ファイル名に指定できる列は1つだけです。指定しない場合、ステップは警告を出し、名前を自動的に生成します。
- **フィルターなし** — その列は使用されません。

少なくとも1つの列を**列フィルター**にする必要があります。

## 保存時のチェック内容

次の場合、ステップの保存は拒否され、該当する列が示されます。

- 列フィルターで、かつマップ済みフィルター列を持つ列がない場合 — *Tag at least one source column as a Column Filter, with the Mapped Filter Column it sets.*
- 列フィルターにマップ済みフィルター列がない、またはダッシュボードのフィルターにない名前を指定している場合 — *The Mapped Filter Column 'Region' for source column 'region' isn't one of the dashboard's filters.*
- ファイル名の列が複数ある場合 — *Only one source column can be the File Name; region, entity all are.*
- 列フィルターまたはファイル名の列にデータ型がない場合 — *Source column 'region' has no data type; inspect the source again to refresh it.* ステップフォームで保存した一部のステップでは、列の型が失われており、型が戻るまで毎回の実行が失敗します。**ソースを検査 › マッピングテーブルを入力**を実行して復元してください。列フィルターとファイル名のタグは保持されます。
