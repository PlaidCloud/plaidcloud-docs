## 説明

**ドキュメント: ファイルを暗号化**は、ドキュメントアカウント内の1つのファイルを暗号化し、結果を別のファイルに書き込みます。**ドキュメント: ファイルを復号**はその逆を行います。どちらのステップも設定は同じです。パートナーから暗号化されたファイルを受け取る場合、インポートで読み取る前に復号する場合、エクスポートを別のシステムに送る前に暗号化する場合に使用します。

## ファイル

| 設定 | 必須 | 内容 |
| --- | --- | --- |
| ソースファイル | はい | 暗号化または復号するファイルです。 |
| ターゲットファイル | はい | 書き込むファイルです。再実行したときに自身の出力を処理しないよう、ソースとは別のファイルにする必要があります。 |
| ターゲットファイルの書き込み後にソースファイルを削除する | いいえ | ターゲットファイルが安全に書き込まれた後、ソースファイルを削除します。 |

ソースファイルが存在しなくてもエラーにはなりません。ステップはそのパスを示す警告とともに終了して何も書き込まず、ワークフローは続行されます。ソースファイルが空の場合は、警告とともに空のターゲットファイルが書き込まれます。ただし、空のファイルをAESまたはBlowfishで暗号化した場合は、暗号化された実際のファイルが書き込まれます。Smartsheetのドキュメントアカウントは、ファイルを読み戻せないため使用できません。

## パラメーター

| 設定 | 内容 |
| --- | --- |
| アルゴリズム | 暗号の項目グループで、**AES-128 (16 バイトのキー)**、**AES-192 (24 バイトのキー)**、**AES-256 (32 バイトのキー)**、**Blowfish (4～56 バイトのキー)**、**Excel ブックのパスワード**のいずれかを選択します。 |
| モード | **CBC**（デフォルト）、**ECB**、**GCM**のいずれかです。BlowfishではCBCとECBのみ使用できます。 |
| キー変数 | 暗号化キーを保持するワークフロー変数またはプロジェクト変数です（例：`{aes_key}`）。AESとBlowfishでは必須です。 |
| キーと IV のエンコード | キーとIVの記述形式です。**テキスト (UTF-8)**、**16 進数**、**Base64**から選択します。 |
| 固定 IV | 初期化ベクトルです。空欄にすると、暗号化はファイルの先頭にランダムなIVを付けて開始し、復号ではファイルの先頭からそのIVを読み取ります。GCMの暗号化は常にランダムなIVを使用するため、GCMでは空欄にしてください。 |
| ブックのパスワード変数 | Excelブックに設定する、またはExcelブックから解除するパスワードを保持するワークフロー変数またはプロジェクト変数です（例：`{xlsx_password}`）。**Excel ブックのパスワード**では必須です。 |

CBCとECBはPKCS7でパディングし、GCMは暗号化データの後ろに16バイトの認証タグを追加します。GCMのファイルは最大256 MBまで扱えます。キーまたはIVが誤っている場合、ステップはエラーで停止し、中途半端なファイルは残りません。

## キーは変数に保持する

**キー変数**と**ブックのパスワード変数**には、`{aes_key}` のような変数参照のみを指定でき、キーやパスワードそのものは指定できません。それ以外の値を入力してステップを保存しようとすると拒否されます。シークレットは[ワークフロー変数](/ja/guides/workflows/manage-workflow-variables/)またはプロジェクト変数に保存してください。これにより、1か所で設定でき、ステップ、そのバージョン、コピー、AIアシスタントが読み戻す内容にシークレットが現れることはありません。ステップは、実行時に変数の値を読み取ります。**固定 IV**はパスワードフィールドのため、フォームでは値が非表示になります。

このルールの導入前にキーやパスワードを直接入力していたステップでは、その値が新しいプロジェクト変数に自動的に移され（アーキテクトのみが閲覧可能）、現在はその変数を参照しています。
