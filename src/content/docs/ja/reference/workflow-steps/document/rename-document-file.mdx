## 説明


PlaidCloudドキュメント内にある既存のファイルの名前を変更します。



## 名前を変更するファイル


まず、ドロップダウンメニューから該当するアカウントを選択します。



次に、**参照**ボタンを押して、名前を変更するファイルを選択します。

<Aside>変更後の名前のファイルがすでに存在する場合は、何も行われません。</Aside>


## 名前の変更先


ファイルの新しい名前を入力します。
