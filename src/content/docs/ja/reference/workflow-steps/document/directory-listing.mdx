## 説明

ドキュメントディレクトリ内のファイルを一覧にしたテーブルを書き込みます。存在するファイルに応じて後続のステップを動かしたいときに使用します。たとえば、フォルダー内のすべてのファイルを順に処理したり、上流のプロセスが何を配置したかを確認したりする場合です。

## ディレクトリ

ドキュメントアカウントを選択し、**参照**ボタンを押して一覧にするフォルダーを選びます。

## オプション

- **ファイルパターン** *（任意）* — `*.csv` のような glob を指定すると、一致するファイルのみを一覧にします。空欄のままにすると、すべてを一覧にします。
- **サブディレクトリを含める** — オンにすると、入れ子になったフォルダー内のファイルも一覧に含めます。
- **ターゲットテーブル** — 一覧を受け取るテーブルです。

## 追加設定

**対象ファイル**のオプションで、一覧を絞り込みます。

- **フォルダーも IsFolder 列付きで一覧表示する**（`include_folders`）— フォルダーも行として一覧にします。この場合、すべての行の末尾に `IsFolder` 列が付き、フォルダーの行では true になります。
- **最初にディレクトリ自体を表示する**（`include_root_folder`）— `include_folders` と併用すると、ディレクトリ自体も最初に一覧にします。
- **ファイル名のパターン**（`file_name_filter`）— 名前が一致するファイルのみが対象です。**パターンの種類**は**ワイルドカード**または**正規表現**（`type`）で、**大文字と小文字を区別する**は `case_sensitive` を設定します。
- **フォルダー名のパターン**（`folder_name_filter`）— 名前が一致するフォルダー内のエントリのみが対象です。形式は同じで、下位に向かう途中のすべてのフォルダーが一致する必要があります。
- **拡張子**（`extensions`）— ドットを付けずに指定した拡張子のいずれかを持つファイルのみが対象です。**拡張子の大文字と小文字を区別する**（`extensions_case_sensitive`）をオンにすると、大文字と小文字を区別して照合します。
- **隠しファイル（ドットで始まる名前）を含める**（`include_hidden_files`）と**隠しフォルダーとその配下を含める**（`include_hidden_folders`）— どちらかをオフにすると、ドットで始まる名前のファイルまたはフォルダーが除外されます。
