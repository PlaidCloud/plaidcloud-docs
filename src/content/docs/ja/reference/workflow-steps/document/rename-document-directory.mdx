## 説明


PlaidCloudドキュメント内にある既存のディレクトリの名前を変更します。



## 名前を変更するフォルダー


まず、ドロップダウンメニューから該当するアカウントを選択します。



次に、**参照**ボタンを押して、名前を変更するディレクトリを選択します。



## 名前の変更先


ディレクトリの新しい名前を入力します。


<Aside>変更後の名前のディレクトリがすでに存在する場合は、何も行われません。</Aside>
