## 説明

[Workday Financials接続](/ja/guides/connections/workday-financials/)を通じて、Workday Financialsからプロジェクトテーブルにデータをインポートします。NetSuite、Acumatica、Business Centralとは異なり、PlaidCloudにはあらかじめ用意されたWorkday Financialsのエンティティの固定セットがありません。代わりに、Workdayで**Report-as-a-Service（RaaS）レポート**を作成し、Webサービスアクセスを付けて公開し、そのレポートのURLを抽出元としてこのステップに指定します。

## 設定

| フィールド | 必須 | 備考 |
|---|---|---|
| Workday接続 | はい | 読み取りに使用するWorkday Financials接続。 |
| RaaSレポートのURL | はい | Workdayで作成して公開したRaaSレポートのWebサービスURL。 |
| ターゲットテーブル | はい | 結果の書き込み先のプロジェクトテーブル。実行のたびに全体が上書きされます。 |
| フィルター | いいえ | `company`、`ledger`、`period`、`accounting_date`（範囲）、`ledger_account`（範囲）、`cost_center`。それぞれレポートパラメーターとして渡されます。フィルターが有効になるのは、RaaSレポートに対応するプロンプトが定義されている場合のみです。 |

<Aside type="caution">
レポートに対応するプロンプトがないフィルターを設定すると、無視されるのではなく拒否されます。先にWorkdayのRaaSレポートにプロンプトを追加してから、ここでフィルターを設定してください。
</Aside>

<Aside type="note">
返されるフィールドはレポート自体が定義するため、インポートの形（列名、粒度、含まれるディメンション）は、RaaSレポートが生成するものそのものになります。ターゲットテーブルに期待される形を念頭に置いて、レポートを設計してください。
</Aside>
