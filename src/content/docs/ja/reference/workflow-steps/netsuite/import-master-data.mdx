## 説明

[NetSuite 接続](/ja/guides/connections/netsuite/)を使用して、NetSuite のマスターデータのリストをプロジェクトテーブルにインポートします。勘定科目、子会社、部門、クラス、場所、仕入先、顧客のいずれか 1 つのレコードタイプを選択すると、ステップがそのリストを取得して書き込みます。SuiteQL を作成したり保守したりする必要はありません。

マスターデータは、残高や明細の取得が参照する基準データです。総勘定元帳の行が内部 ID として保持している勘定科目、子会社、ディメンションが該当します。これらの内部 ID を名前に変換したり、下流のルックアップや結合に使用したりするために、必要なリストをインポートします。これは、あらかじめ用意された [NetSuite インポートステップ](/ja/reference/workflow-steps/netsuite/)の 1 つで、共通の読み取りレイヤー上で動作し、OAuth トークンの更新、大きな結果のページング、一時的なエラーの再試行を自動的に行います。

## 設定

| フィールド | 必須 | 備考 |
|---|---|---|
| NetSuite接続 | はい | 読み取りに使用する NetSuite 接続です。タイプが NetSuite の接続に絞り込まれます。 |
| ターゲットテーブル | はい | リストの書き込み先のプロジェクトテーブルです。実行のたびに全体が上書きされます。 |
| レコードタイプ | はい | 取得するマスターリストです。**勘定科目**（デフォルト）、**子会社**、**部門**、**クラス**、**場所**、**仕入先**、**顧客**のいずれかです。 |
| 非アクティブを含める | いいえ | デフォルトではオフで、アクティブなレコードのみを返します。オンにすると、NetSuite で非アクティブとマークされたレコードも含まれます。 |

<Aside type="note">
このステップを使用して、他の NetSuite ステップが利用する小さな参照テーブルを作成できます。たとえば、[残高のインポート](/ja/reference/workflow-steps/netsuite/import-balances/)や [GL明細のインポート](/ja/reference/workflow-steps/netsuite/import-gl-detail/)の取得を 1 つの子会社に限定する前に、**子会社**を一度取得して、子会社の内部 ID を名前に対応付けます。
</Aside>
