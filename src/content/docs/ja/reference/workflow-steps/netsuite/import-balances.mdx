## 説明

[NetSuite 接続](/ja/guides/connections/netsuite/)を使用して、NetSuite の勘定科目残高をプロジェクトテーブルにインポートします。レポート作成の基になる試算表が得られます。接続を選択し、ターゲットテーブルの名前を指定して、期間と子会社を設定すると、ステップが残高を取得して書き込みます。SuiteQL を作成したり保守したりする必要はありません。

これは、あらかじめ用意された [NetSuite インポートステップ](/ja/reference/workflow-steps/netsuite/)の 1 つです。いずれも共通の読み取りレイヤー上で動作し、OAuth トークンの更新、大きな結果のページング、一時的なエラーの再試行を自動的に行うため、1 年分や全子会社の取得でも、手動で調整することなく完全な結果が返されます。トランザクション単位で取得する場合は [NetSuite: GL明細のインポート](/ja/reference/workflow-steps/netsuite/import-gl-detail/)を、勘定科目、子会社などのリストには [NetSuite: マスターデータのインポート](/ja/reference/workflow-steps/netsuite/import-master-data/)を使用してください。

## 設定

| フィールド | 必須 | 備考 |
|---|---|---|
| NetSuite接続 | はい | 読み取りに使用する NetSuite 接続です。タイプが NetSuite の接続に絞り込まれます。 |
| ターゲットテーブル | はい | 残高の書き込み先のプロジェクトテーブルです。実行のたびに全体が上書きされます。 |
| 開始日 | いいえ | 含める最も早い日付（`YYYY-MM-DD`、この日を含む）。空白にすると下限なしになります。終了日と併せて指定すると、NetSuite の SuiteQL の行数上限を超えないよう、取得が自動的に日付単位のチャンクに分割されます。後述の注意を参照してください。 |
| 終了日 | いいえ | 含める最も遅い日付（`YYYY-MM-DD`、この日を含む）。空白にすると上限なしになります。 |
| 子会社 | いいえ | 取得を 1 つの子会社に限定する場合の、NetSuite の子会社の内部 ID です。空白にすると全子会社が対象になります。 |
| 会計帳簿 | いいえ | NetSuite の会計帳簿の内部 ID です。空白にすると**プライマリ帳簿（内部 ID 1）のみ**を取得します。`all` と入力すると、すべての帳簿を合算します。 |
| 勘定科目番号 | いいえ | 取得を 1 つの勘定科目に限定する場合の、総勘定元帳の勘定科目番号（完全一致）です。空白にすると全勘定科目が対象になります。 |
| 転記期間 | いいえ | NetSuite の転記期間／会計期間の内部 ID です。空白にすると全期間が対象になります。 |

<Aside type="caution">
**複数帳簿の勘定科目：** 複数帳簿会計（Multi-Book Accounting）を使用している NetSuite アカウントでは、トランザクション明細ごとに帳簿ごとの行が 1 行ずつ転記されます。会計帳簿を空白にすると**プライマリ帳簿のみ**を取得します。これは標準的な試算表に適した設定です。帳簿をまたぐ合計（帳簿を照合するのではなく合算します）が必要な場合にのみ `all` を設定するか、特定の帳簿のみを対象にする場合はその帳簿の内部 ID を設定してください。
</Aside>

<Aside type="note">
子会社と会計帳簿には、名前ではなく NetSuite の内部 ID を指定します。[NetSuite: マスターデータのインポート](/ja/reference/workflow-steps/netsuite/import-master-data/)（レコードタイプ**子会社**）で内部 ID を一度取得し、小さな参照テーブルとして保持しておいてください。
</Aside>

<Aside type="note">
NetSuite の SuiteQL API は、SuiteAnalytics Connect を使用しない場合、1 回のクエリを約 100,000 行に制限します。開始日と終了日の両方を指定すると、PlaidCloud は取得をこの上限に収まるチャンクに事前に分割するため、1 年分の取得でも何もしなくても完全な結果が返されます。**期間が開いた**取得（開始日または終了日が空白）が上限を超えた場合は、切り詰められた結果を黙って返すのではなく、日付範囲を追加するよう求めるメッセージとともに失敗します。
</Aside>
