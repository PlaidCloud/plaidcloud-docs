## 説明


ワークフローの停止ステップは、実行中の既存のワークフローを停止します。


<Aside>このステップの実行時にワークフローが実行中でない場合は、*Workflow is already stopped. という警告がログに書き込まれます。</Aside>


## 停止するワークフロー


まず、**プロジェクト**ドロップダウンメニューから、停止するワークフローを含むプロジェクトを選択します。



次に、**ワークフロー**ドロップダウンメニューから、停止する特定のワークフローを選択します。
