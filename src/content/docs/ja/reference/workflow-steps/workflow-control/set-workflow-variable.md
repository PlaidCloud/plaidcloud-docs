## 説明


Set Workflow Variable ステップは、ワークフローの実行中に使用するワークフロー変数を設定します。変数名と値には、スペースを含め、有効な文字を任意に組み合わせて使用できます。変数は、波かっこで囲むことでワークフロー内から参照します。たとえば、*a_variable* はトランスフォーム内で *\{a_variable}* として参照するため、数式やフィールド値などで使用できます（例: \{a_variable} * 2）。



## 変数リスト


このテーブルには、ワークフローに登録されているすべての変数が、それぞれの**現在値**と**メモ**とともに一覧表示されます。これらはステップを開くたびに最新の内容が読み込まれるため、設定する前に変数が現在保持している値を確認できます。

変数を設定するには、その行の**設定**にチェックを入れ、**値を設定**の下に新しい値を入力します。ステップの実行時に書き込まれるのはチェックを入れた行だけです。**設定**にチェックを入れずに入力した値は無視されます。まだ登録されていない変数を設定することもできます。行を追加して同じように設定し、ステップを実行すると、その変数が作成されます。
