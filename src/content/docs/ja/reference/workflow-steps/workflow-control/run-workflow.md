## 説明

現在のワークフローの実行の一部として、別のワークフローを起動します。あるプロセスが別のプロセスに論理的に依存している場合に、ワークフローを連鎖させるために使用します。たとえば、「実績をロード」ワークフローを呼び出し、次に「配賦を実行」ワークフロー、さらに「ダッシュボードを公開」ワークフローを呼び出す、月次締めワークフローなどです。

呼び出されたワークフローは独立して実行されます。同じプロジェクトでも別のプロジェクトでも構いません。デフォルトでは、呼び出し元のワークフローは待機せずに続行します。呼び出し元の後続のステップが、呼び出されたワークフローの完了に依存している場合は、**Wait until processing completes** オプションを設定します。



## 実行するワークフロー


まず、**プロジェクト**ドロップダウンメニューから、実行するワークフローを含むプロジェクトを選択します。



次に、**ワークフロー**ドロップダウンメニューから、実行する特定のワークフローを選択します。



さらに、**Wait until processing completes before continuing.** オプションがあります。このチェックボックスを選択すると、呼び出されたワークフローの実行が完了するまで、現在のワークフローの実行が保留されます。デフォルトでは、このオプションは無効です。つまり、このトランスフォームを含む現在のワークフローは、呼び出されたワークフローと並行して処理を続行します。
