## 説明


新しいPlaidCloud Analyzeワークフローを作成します。



## 作成するワークフロー


まず、新しいワークフローを作成するプロジェクトを、ドロップダウンメニューから選択します。



次に、ワークフロー名を入力します。名前はプロジェクト内で一意である必要があります。
