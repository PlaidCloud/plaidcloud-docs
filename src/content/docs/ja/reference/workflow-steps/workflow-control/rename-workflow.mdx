## 説明


既存のPlaidCloud Analyzeワークフローの名前を変更します。

<Aside>変更後の名前のワークフローがすでに存在する場合、*Workflow \{workflow} in project \{project} already exists.* というエラーがログに書き込まれ、何も実行されません。このため、**ワークフローの名前の変更**トランスフォームは実質的に1回しか使用できません。</Aside>


## 名前を変更するワークフロー


まず、**プロジェクト**ドロップダウンメニューから、名前を変更するワークフローを含むプロジェクトを選択します。



次に、**ワークフロー**ドロップダウンメニューから、名前を変更するワークフローを選択します。



最後に、**名前の変更先**フィールドに新しいワークフロー名を入力します。名前はプロジェクト内で一意である必要があります。
