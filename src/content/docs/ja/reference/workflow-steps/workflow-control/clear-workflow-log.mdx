## 説明


既存のPlaidCloud Analyzeワークフローのログをクリアします。



## クリアするワークフローログ


まず、クリアするワークフローログを含むプロジェクトを、**プロジェクト** ドロップダウンメニューから選択します。



次に、クリアする特定のワークフローログを、**ワークフロー** ドロップダウンメニューから選択します。


<Aside type="danger">削除を確認するポップアップダイアログは表示されません。正しいワークフローログを選択していることを確認してください。</Aside>
