## 説明

カスタムメッセージを付けて、ワークフローをエラー状態にします。前のステップで検出されたデータの状態に基づいてワークフローを失敗させる必要がある場合に使用します。たとえば、「行数が0なら失敗する」「主要な検証テーブルにマッピングされていない値があれば失敗する」「残高チェックが一致しなければ失敗する」といった場合です。

[ステップ条件](/ja/guides/workflows/step-conditions/)と組み合わせると、実際に問題が発生したときだけエラーを発生させることができます。このステップが実行されると、ワークフローはただちに停止し、エラーがワークフローログに書き込まれます。修復ワークフローが構成されている場合は、それを起動することもできます。


## ワークフローエラーの発生


主にステップ条件と併用するためのものです。条件が満たされた場合に実行するようステップを設定し、ワークフロー内でエラーを発生させることができます。
