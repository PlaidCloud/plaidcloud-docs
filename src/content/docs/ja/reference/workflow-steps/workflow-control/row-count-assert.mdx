## 説明

2つのテーブルの行数が異なる場合に、ワークフローを失敗させます。データ品質のゲートとして使用します。たとえば、変換後のテーブルがソースのすべての行を保持していることや、照合によってレコードが欠落または重複していないことを確認する場合です。行数が一致するとワークフローは続行され、異なる場合はステップがワークフローを停止し、失敗メッセージをワークフローログに書き込みます。

## 構成

- **左テーブル** — 行数をカウントする1つ目のテーブルです。
- **右テーブル** — 行数をカウントする2つ目のテーブルです。
- **失敗メッセージ** — 行数が異なる場合に表示されるメッセージです。デフォルトは「行数が一致しません」です。

行数の不一致ではなく任意の条件で失敗させる必要がある場合は、[ワークフローエラーの発生](/ja/reference/workflow-steps/workflow-control/raise-workflow-error/)を使用してください。
