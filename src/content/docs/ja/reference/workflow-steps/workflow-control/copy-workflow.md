## 説明


既存のPlaidCloud Analyzeワークフローのコピーを作成します。



## コピーするワークフロー


まず、コピーするワークフローを含むプロジェクトを、**プロジェクト** ドロップダウンメニューから選択します。



次に、コピーする特定のワークフローを、**ワークフロー** ドロップダウンメニューから選択します。



次に、新しいワークフローの名前を **新規ワークフロー** フィールドに入力します。名前はプロジェクト内で一意である必要があることに注意してください。
