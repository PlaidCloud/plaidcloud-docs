[Salesforce接続](/ja/guides/connections/salesforce/)を使用して Salesforce のデータを読み取るワークフローステップです。オブジェクトの一覧、フィールドの一覧、各列の型は組織自身のメタデータから取得されるため、クエリを書く必要も、型を推測する必要もありません。

## ステップ

- [Salesforce: オブジェクトのクエリ](/ja/reference/workflow-steps/salesforce/query-salesforce-object/) — 標準オブジェクトまたはカスタムオブジェクト 1 つを Bulk API 2.0 経由でプロジェクトテーブルに抽出します。フィルターは Salesforce 側で適用されます。
