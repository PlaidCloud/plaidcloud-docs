## 説明


検索条件に一致する SAP Profitability and Cost Management（PCM）モデルを削除します。このトランスフォームを使用すると、処理を監視することなく、多数のモデルをまとめて削除できます。



## 当社の認定実績


PlaidCloud は SAP の公式パートナーであり、SAP PCM のモデル設計と導入に関連するサービスの推奨ベンダーです。







## 例


ドロップダウンから「Agent to Use」を選択します。使用する「Model Search Method」を選択します。この例では「Exact Match」を選択しています。「Model Name Information」の下の「Model Search Text」に検索対象を入力し、大文字と小文字を区別するかどうかを決めます（区別する場合はチェックボックスをオンにします）。最後に「Wait for Deletion to Complete」をオンにして、「Save and Run Step」をクリックします。
