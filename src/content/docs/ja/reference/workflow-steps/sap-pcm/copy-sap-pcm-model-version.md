### 説明


同じモデル内で、SAP Profitability and Cost Management（PCM）モデルのバージョンをコピーします。


### 当社の認定実績


PlaidCloud は SAP の公式パートナーであり、SAP PCM のモデル設計と導入に関連するサービスの推奨ベンダーです。


### 例


ドロップダウンから**使用するエージェント**を選択し、「Model Information」フィールドに「Model Name」、「Origin Period Name」、「Destination Period Name」を入力します。「Wait for Copy to Complete」チェックボックスをオンにしてから、「Save and Run Step」をクリックします。
