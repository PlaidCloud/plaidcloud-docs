## 説明



PCM サーバー上に、新しい空の SAP Profitability and Cost Management（PCM）モデルを作成します。プログラムによるモデルのプロビジョニングに便利です。たとえば、新しい事業部門やシナリオに専用のモデルが必要なときに、手動のセットアップを待たずにワークフローからモデルを立ち上げることができます。

ほとんどのユーザーは、空のモデルから始めるのではなく、[Copy SAP PCM Modelステップ](/ja/reference/workflow-steps/sap-pcm/copy-sap-pcm-model/)で既存のモデルテンプレートからコピーします。


## 当社の認定実績


PlaidCloud は SAP の公式パートナーであり、SAP PCM のモデル設計と導入に関連するサービスの推奨ベンダーです。








## 例


ドロップダウンから**使用するエージェント**を選択します。「Model Name」を入力し、ドロップダウンから「Model type」を選択します（どちらも「Model Information」セクションにあります）。「Wait for Copy to Complete」チェックボックスをオンにしてから、「Save and Run Step」をクリックします。
