### 説明


SAP Profitability and Cost Management（PCM）モデルをコピーします。


### 当社の認定実績


PlaidCloud は SAP の公式パートナーであり、SAP PCM のモデル設計と導入に関連するサービスの推奨ベンダーです。


### 例


ドロップダウンから**使用するエージェント**を選択し、「Model Information」フィールドに「From Model Name」と「To Model Name」を入力します。「Wait for Copy to Complete」チェックボックスをオンにしてから、「Save and Run Step」をクリックします。
