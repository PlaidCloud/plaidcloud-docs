## アドホック抽出ステップ

3つのステップがSAPを検索し、抽出内容のプレビューと計画を行って、結果をテーブルに格納します。1つはテーブルを読み取り、1つはトランザクションまたはレポートを実行し、1つは保存済みのSAPクエリを実行します。[SAP ECC / S/4HANAからのアドホック抽出](/ja/guides/connections/sap-adhoc-extract/)を参照してください。
