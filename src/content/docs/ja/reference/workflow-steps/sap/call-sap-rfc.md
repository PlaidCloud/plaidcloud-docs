## 説明


SAP ECC / S/4HANAのRemote Function Call（RFC）を呼び出し、データを表形式で取得します。取得したデータは、PlaidCloudの変換処理で利用できます。


## データ出力先

RFCの結果を、ファイルまたはテーブルに格納します。

**ファイル**を選択すると、結果を**JSON**、**カンマ区切り**、**タブ区切り**、**パイプ区切り**、または**Parquet**で書き込みます。Parquetファイルの列のデータ型は、テーブルの場合と同じです。

**テーブル**を選択すると、RFCファンクション自体のフィールド定義に基づいたデータ型で、結果を**ターゲットテーブル**に格納します。

| SAPのフィールド型 | 格納される型 |
|---|---|
| 日付 | 日付。空白または初期値の日付は空として格納されます。無効な日付は空として格納され、ステップは該当する列を示す警告付きで終了します。 |
| パック10進数 | 厳密な10進数。小数部が10桁を超える場合、または整数部が28桁を超える場合は、代わりにテキストとして格納され、ステップは該当する列を示す警告付きで終了します。 |
| 整数 | 整数。 |
| `FLOAT` | 倍精度浮動小数点数。 |
| 10進浮動小数点数 | 厳密なテキスト。 |
| `NUMC`、`CHAR` | テキスト（先頭のゼロは保持）。 |
| 時刻 | `HH:MM:SS`形式のテキスト。 |
| 生バイト | 16進テキスト。 |
| `UTCLONG` | テキスト。 |

SAPがファンクションのフィールドを記述できない場合、10進数は代わりに厳密なテキストとして格納されます。

SAPがファンクションを記述できる場合、各パラメーターは期待される型に変換されます。日付は`YYYYMMDD`、時刻は`HHMMSS`、整数と10進数は数値、テキストフィールドはテキストに変換され、構造パラメーターとテーブルパラメーターはフィールドごとに変換されます。整数または10進数のパラメーターに変換できない値がある場合、ステップは失敗します。

## 例


### RFCパラメーター


**使用するエージェント**を選択します。ドロップダウンバーから**ターゲットディレクトリ**を選択し、その下でファイルの保存先となる子フォルダーを参照して選択します。次に、「Target File Name」に適切な名前を付けます。「Function Call Information」で、Function、**戻り値パラメーター**を入力し、パラメーターを選択します。

「Parameters」セクションで**行を挿入**または**行を追加**を選択できるほか、パラメーターに名前を付けて値を設定できます。**最大同時リクエスト数**を選択し、「Wait for RFC to Complete」を選択します。ステップを保存して実行します。



### 詳細な値の反復


このタブの上部で「No Iterators」を選択し、必要に応じて「Save and Run Step」を選択することもできますし、反復を指定することもできます。


ここでは、**反復対象**として「Specify Argument Values」を選択し、引数を作成してから**反復値**に進みます。


**値を編集する反復引数を選択**の横には、行の挿入、**行を追加**、**行を削除**、行を**下へ移動**、行を**末尾へ移動**のオプションがあります。
その下では、同じドロップダウンメニューを使用して**範囲イテレーター**を選択できます。最後のセクションは「Exclusions for Selected Range Iteration」で、行ごとに追加や削除などを行う同じオプションがあります。除外する値は、その下に入力できます。ステップを保存して実行します。
