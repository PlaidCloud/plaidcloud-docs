## 説明

Sage 接続を使用して、Sage Intacct の**ディメンション別勘定科目残高**（Intacct の `get_accountbalancesbydimensions`）をインポートします。日付範囲と勘定科目範囲で絞り込み、選択したディメンションが各行に引き継がれます。結果は試算表となり、勘定科目とディメンションの組み合わせごとに 1 行で、期首（`startbalance`）、期中（`periodbalance`）、期末（`endbalance`）の残高を含みます。

試算表や残高ベースの損益計算書に使用します。下記の**統計**コントロールでは、Intacct の非金額の統計勘定科目（人員数、床面積、単位数）も取得できるため、1 つのステップで財務残高、統計残高、またはその両方を取得でき、別途エクスポートすることなく単位あたりの指標を作成できます。取引レベルの総勘定元帳の詳細には、`GLDETAIL` に対して [Import Sage Intacct Queryステップ](/ja/reference/workflow-steps/sage-intacct/import-intacct-query/)を使用します。任意の Intacct オブジェクトに対するアドホックなクエリにも、同じステップにオブジェクト名を指定して使用します。

## 固有の設定項目

### ソースとターゲット

- **接続** — 読み取りに使用する Sage 接続です。
- **会社** — 読み取り元の Sage 会社です。

### データの選択

- **開始日** / **終了日** — 残高を報告する期間です（どちらも必須です。開始日または終了日のみの指定は無視されます）。
- **Start account** / **End account** — 対象に含める勘定科目コードの範囲です。番号に関係なくすべての勘定科目を対象にするには、`0000` と `9999` を使用します。下記の**統計**で統計勘定科目を取得するように設定している場合は、通常この指定を使用します。Intacct の統計勘定科目は、財務の勘定科目表の番号体系の範囲内にあるとは限らないためです。
- **統計** — 取得する勘定科目残高の種類です。
  - **財務のみ（統計を除く）** — 財務の勘定科目残高のみを返します（通常の試算表の取得）。これがデフォルトです。
  - **財務と統計** — 財務の勘定科目残高と統計の勘定科目残高を、同じ結果にまとめて返します。
  - **統計のみ** — 統計の勘定科目残高のみを返します。人員数、床面積、単位数など、財務の勘定科目表と並行して Intacct の勘定科目表で管理している非金額の勘定科目です。
- **エンティティ** — 対象に含める Sage エンティティです。
- **ディメンション** — 列として取得するディメンションをオンにします。クラス、コンタクト、コストタイプ、顧客、部門、従業員、品目、ロケーション、プロジェクトグループ、タスク、仕入先です。
- **Custom dimensions** — 引き継ぐ、その他のユーザー定義ディメンションです。

:::caution[ウェアハウスのチェックボックスは機能しません]
ステップの設定には**ウェアハウス**ディメンションがありますが、ワークフローランナーはこれを読み取りません。ランナーが構築するディメンションのセットに含まれないため、オンにしても列は追加されません。出力にウェアハウスが必要な場合は、**Custom dimensions** を使用してください。
:::
