## 説明

[Sage Intacct接続](/ja/guides/connections/sage-intacct/)を使用して、Sage Intacct のレコードに補足ドキュメントを添付します。処理は PlaidCloud 共通の ERP 書き込みパイプラインを経由します。ソーステーブルの各行は 1 つのファイルを表し、そのバイト列、ファイル名、添付先となる Intacct レコードのキーを持ちます。ステップはこれを Sage Intacct の補足ドキュメント（`supdoc`）として作成し、そのレコードにリンクします。**Validate Only** では、Intacct に何も作成せずにすべての行をチェックします。結果テーブルには、添付ファイルごとの結果が記録されます。

ワークフローがすでに保持しているファイル（描画済みの請求書 PDF、スキャンした領収書、エクスポートしたレポートなど）を、それらを生成または転記するのと同じ実行の中で、対応する Intacct の取引やレコードに追加するために使用します。[Intacct: 仕訳の転記](/ja/reference/workflow-steps/sage-intacct/export-to-sage/)と組み合わせると効果的です。仕訳を転記したあと、各転記が返した Intacct キーを使って、その裏付け資料を添付します。

## データ形式の規約

添付ファイルのテーブルは、各行が 1 つの完全なファイルと 1 つのレコードに結び付くように、標準ステップを使って上流で構築します。

- **`parent_key`** — ファイルの添付先となる Sage Intacct レコードです。1 行につき 1 つのファイルと 1 つの親を指定します。同じファイルを複数のレコードに添付するには、複数の行で繰り返します。
- **`file_name`** — 補足ドキュメントのファイル名で、拡張子を含みます（`invoice-1043.pdf`）。
- **`mime_type`** — ファイルのコンテンツタイプ（`application/pdf`、`image/png`）です。Intacct がファイルを正しく保存して提供するために使用します。
- **`content_base64`** — 行内に含める、Base64 エンコードされたファイルのバイト列です。

## 設定

### 接続

- **Sage Intacct接続** — 添付に使用する Sage Intacct 接続です。Sage Intacct 接続のみが表示されます。同じ接続で Intacct の読み取りと書き込みの両方を行います。
- **環境** — 接続の環境です。

### データ

- **添付テーブル** — 上記のソーステーブルです。ファイルごとに 1 行で、`parent_key`、`file_name`、`mime_type`、`content_base64` を含みます。
- **結果テーブル** — 出力テーブル ID です。添付ファイルごとに 1 行で、`parent_key`、`file_name`、`supdoc_id`、`status`、`message` を含みます。
- **Validate Only** — デフォルトでオンです。事前チェックのみを行い、各行をチェックして結果テーブルを書き込みますが、Intacct に補足ドキュメントは作成しません。このフィールドが完全に省略されたステップ設定（たとえば REST API、MCP、またはワークフローバンドルのインポートで作成された設定）でも、本番の添付ではなく Validate Only がデフォルトになります。
- **Continue On Error** — デフォルトでオンです。1 つのファイルが失敗しても、残りのファイルの添付を続行します。オフにすると、最初の失敗で停止します。

## 結果テーブル

Validate Only でも本番でも、実行のたびに、ソースの行ごとに 1 行を結果テーブルに書き込みます。

| 列 | 説明 |
|---|---|
| `parent_key` | この添付の対象となる Intacct レコードです。 |
| `file_name` | ソース行のファイル名です。 |
| `supdoc_id` | 添付が成功した場合に、ファイルに対して作成された Sage Intacct の補足ドキュメント ID です。 |
| `status` | この行の結果です。検証済み、添付済み、または失敗のいずれかです。 |
| `message` | 行が失敗した場合の、問題の内容を簡潔に（機密情報を除いて）説明したメッセージです。 |
