## 説明

Sage Intacct REST API を使用して、Sage Intacct から買掛金請求書のヘッダーをインポートします。各行は 1 件の買掛金請求書で、仕入先、総勘定元帳の日付、支払期日、合計、後続のレポートに必要なステータスフィールドを含みます。

ソースとして、設定済みの [Sage Intacct RESTコネクター](../../../connectors/rest/sage-intacct/)を使用します。明細行レベルの詳細も同時に取得するには、このステップを [Import Sage AP Lines](../import-sage-ap-lines/) と組み合わせます。

## 固有の設定項目

* **Sage接続** — 読み取り元となる Sage Intacct REST 接続です。Sage 接続は **Tools > Connections** で管理します。
* **会社ID** — クエリ対象の Intacct 会社です。送信者の認証情報が複数の会社にまたがる場合は必須です。
* **エンティティID（カンマ区切り）** — インポートを 1 つ以上の Intacct エンティティに限定します。ユーザーがアクセスできるすべてのエンティティを取得するには、空白のままにします。
