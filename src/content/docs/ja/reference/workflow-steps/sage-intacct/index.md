[Sage Intacct接続](/ja/guides/connections/sage-intacct/)を使用して Sage Intacct の読み取りと書き込みを行うワークフローステップです。勘定科目残高、買掛金請求書、または任意の Intacct オブジェクトに対するアドホックなクエリの結果をインポートし、仕訳を書き戻し、Intacct のレコードに補足ドキュメントを添付できます。

## ステップ

- [Sageのインポート](/ja/reference/workflow-steps/sage-intacct/import-sage/)
- [Import Sage Intacct Query](/ja/reference/workflow-steps/sage-intacct/import-intacct-query/)
- [Import Sage AP](/ja/reference/workflow-steps/sage-intacct/import-sage-ap/)
- [Import Sage AP Lines](/ja/reference/workflow-steps/sage-intacct/import-sage-ap-lines/)
- [Import Intacct Entity](/ja/reference/workflow-steps/sage-intacct/import-intacct-entity/) — 総勘定元帳の明細、残高、仕訳、ディメンションマスターを、自動ページネーションで取得します。
- [Intacct: 仕訳の転記](/ja/reference/workflow-steps/sage-intacct/export-to-sage/)
- [Sage Intacct: ドキュメントの添付](/ja/reference/workflow-steps/sage-intacct/attach-document/) — テーブルの補足ドキュメントを Intacct のレコードに添付します。
