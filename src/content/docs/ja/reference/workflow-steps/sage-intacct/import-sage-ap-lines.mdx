## 説明

Sage Intacct REST API を使用して、Sage Intacct から買掛金請求書の明細行レベルの詳細をインポートします。各行は 1 件の請求書明細行で、総勘定元帳の勘定科目、ディメンション、明細行の金額、親のヘッダーにリンクする請求書キーを含みます。

このステップを [Import Sage AP](../import-sage-ap/) と組み合わせると、後続の配賦、レポート、照合のために、両方の粒度のデータをロードできます。

## 固有の設定項目

* **Sage接続** — 読み取り元となる Sage Intacct REST 接続です。Sage 接続は **Tools > Connections** で管理します。
* **会社ID** — クエリ対象の Intacct 会社です。送信者の認証情報が複数の会社にまたがる場合は必須です。
* **エンティティID（カンマ区切り）** — インポートを 1 つ以上の Intacct エンティティに限定します。ユーザーがアクセスできるすべてのエンティティを取得するには、空白のままにします。
