## 説明

任意の Sage Intacct オブジェクトタイプに対してアドホックなクエリを実行し、結果をインポートします。専用の [Sage AP](../import-sage-ap/) ステップや [Sage AP Lines](../import-sage-ap-lines/) ステップとは異なり、このステップでは、総勘定元帳、プロジェクト、顧客、仕入先、カスタムオブジェクトなど、任意の Intacct オブジェクトを対象にして、必要なフィールドとフィルターを選択できます。

ページ送りは自動的に処理されるため、このステップは Intacct API の 1 ページを超える結果セットでも使用できます。

## 固有の設定項目

* **Sage接続** — 読み取り元となる Sage Intacct REST 接続です。Sage 接続は **Tools > Connections** で管理します。
* **会社ID** — クエリ対象の Intacct 会社です。
* **エンティティID（カンマ区切り）** — クエリを 1 つ以上の Intacct エンティティに限定します。すべてのエンティティを対象にするには、空白のままにします。
* **オブジェクト名** — クエリ対象の Intacct オブジェクトです。たとえば `GLACCOUNT`、`CUSTOMER`、`PROJECT`、または任意のカスタムオブジェクト名です。
* **インポートするフィールド** — Intacct のフィールド名と、有効のチェックボックスを持つテーブルです。`Lookup Object Fields` をクリックすると、Intacct のスキーマからリストが読み込まれます。`Select All` または `Select None` で一括して切り替えられます。
* **フィルター** — フィルター行のテーブルです。各行は `Field`、`Filter Type`、`Value` で構成されます。フィルタータイプには、`Equal To`、`Not Equal To`、`Less Than`、`Less Than or Equal To`、`Greater Than`、`Greater Than or Equal To`、`Is Null`、`Is Not Null` があります。フィルターは、ページ送りの前にサーバー側で適用されます。
