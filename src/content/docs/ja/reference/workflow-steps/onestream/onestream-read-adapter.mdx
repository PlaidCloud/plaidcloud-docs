## 説明

[OneStream接続](/ja/guides/connections/onestream-for-data-foundation/)を通じて、OneStreamワークスペース内のデータアダプターを読み取り、その行をテーブルに取り込みます。指定した連結メンバーごとにアダプターを1回呼び出し、すべての行でターゲットテーブルを置き換えます。連結結果をプロジェクトに取り込み、たとえばモデルをそれと照合する場合に使用します。

このステップは、ステップメニューの**OneStream**の下に表示されます。Data Foundationは、OneStreamをソースとして追加したときに、このステップを使用します。

<Aside type="note">
アダプターとその列は、OneStream管理者が構築します。[OneStream管理者が設定する内容](/ja/guides/connections/onestream-for-data-foundation/#onestream-管理者が設定する内容)を参照してください。
</Aside>

## 設定

### ソース

| フィールド | 必須 | 注記 |
|---|---|---|
| OneStream接続 | はい | 読み取りに使用する[OneStream接続](/ja/guides/connections/onestream-for-data-foundation/)。 |
| 環境 | いいえ | **プロジェクト環境**（デフォルト）は、プロジェクトの接続環境を使用します。**固定環境**は、選択した環境を常に使用します。[ステップを1つの環境に固定する](/ja/guides/projects/managing-projects/#ステップを1つの環境に固定する)を参照してください。 |
| アプリケーション | いいえ | 空白にすると、接続に保存されているアプリケーションが使用されます。ステップには、どちらか一方が必要です。 |
| ワークスペース | いいえ | 空白にすると、接続に保存されているワークスペースが使用されます。 |
| アダプター | はい | 読み取るデータアダプター。`Foundation_Results`は、接続のページで説明しているアダプターです。 |
| アダプターテーブル | いいえ | アダプターのデータセット内のテーブル名。 |
| 先にシーケンスを実行 | いいえ | アダプターが読み取る内容を更新するために、読み取りの前に実行するData Managementシーケンス。 |

### データスライス

| フィールド | 注記 |
|---|---|
| メンバー | 1行につき1つの連結メンバー。ステップは、メンバーごとに、そのメンバーを置換変数`Member`に設定してアダプターを1回呼び出します。空白にすると、アダプターのデフォルトメンバーで1回呼び出します。 |
| 置換変数 | 1行につき1つの`Name=Value`（例：`Time=2026M1`）。 |
| ビュー | **年初来**（デフォルト）または**期間別**。置換変数`View`でアダプターに渡されます。 |
| 符号 | **保存されたまま**（デフォルト）または**符号を反転**。後者はすべての金額の符号を反転します。 |
| 金額の単位 | すべての金額に適用される乗数。デフォルトは1です。OneStreamが千単位で値を提供する場合は1000を使用します。 |

アプリケーション、ワークスペース、テーブル、シーケンス、メンバー、置換値の中の変数は、ワークフローの実行時に展開されます。

### ターゲット

| フィールド | 必須 | 注記 |
|---|---|---|
| ターゲットテーブル | はい | 行を取り込むテーブル。実行のたびに置き換えられ、ビューではなくテーブルである必要があります。 |

## 出力

ターゲットテーブルには、アダプターの列`entity`、`account`、`time`、`scenario`、`view`、`amount`、`currency`、`flow`、`ud1`、`ud2`、`ud3`、`ud4`が含まれます。`amount`を除くすべての列はテキストとして取り込まれ、amountは単位と符号の適用後に数値になります。

アダプターから行が返されない場合、ターゲットテーブルは空のテーブルに置き換えられ、ステップは、アダプター名を示す警告付きで完了します。エラーにはなりません。
