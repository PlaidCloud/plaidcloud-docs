## 説明

PlaidCloudがPlaidLinkエージェント経由でしか到達できないデータベース（通常は、ファイアウォールの内側、プライベートネットワーク上、またはオンプレミスのデータセンターにあるデータベース）でSQLを実行します。エージェントがSQLをローカルで実行し、成功または失敗をPlaidCloudに報告します。

ソースデータベースをパブリックインターネットに公開することなく、リモートのストアドプロシージャ、更新ルーチン、メンテナンスジョブをPlaidCloudのワークフローの一部として起動する場合に使用します。

## クエリをプレビューする

**リモート実行: SQL**ステップでは、**ソース**タブの**プレビュー**で、ステートメントを実行せずに最大100行が表示されるため、`SELECT`を実行する前に確認できます。プレビューは、実行時と同じ方法で変数を埋め込みますが、`{x:>9}`のような変数の書式指定には対応していません。プレビューはデータの読み取りのみを行います。書き込みを行うステートメントや、プレビューが読み取り専用かどうかをチェックできない関数は、*Preview only supports standard SQL functions. Run the step to see results.* というメッセージで拒否されます。プレビューは、ロックされたプロジェクトや、ドライバーテーブルとともに`:name`プレースホルダーを使用するステートメントでは利用できません。このページで説明しているエージェントベースのステップでは、エージェントだけがそれらのデータベースに到達できるため、プレビューは利用できません。

## 行ごとに1回ステートメントを実行する

エージェントを介さずデータベースに直接接続する**リモート実行: SQL**ステップは、テーブルの行ごとに1回ステートメントを実行できます。たとえば、入力行ごとにストアドプロシージャを呼び出す場合です。**SQLの実行**を**行ごとに1回**に設定し、**ドライバーテーブル**を選択して、**パラメーター**を入力します。ステートメント内の各値を`CALL load_region(:region, :period)`のように`:name`プレースホルダーとして記述し、**パラメーター**で各プレースホルダーを、それを供給する**ドライバー列**にマッピングします。各値はバインドされたパラメーターとしてデータベースに送信され、ステートメントのテキストに埋め込まれることはありません。

すべてのパラメーターに、名前とドライバー列の両方が必要で、同じパラメーターを2回一覧に含めることはできません。ステートメント内の`:name`にマッピングがない場合や、マッピングがステートメントにない場合は、フォームが警告します。ドライバーテーブルはビューではなくテーブルである必要があります。行のないドライバーテーブルは警告付きで終了し、何も実行されません。100,000行を超えるドライバーテーブルは、どの行も実行せずにステップが失敗するため、事前にフィルターしてください。

## スクリプトを1つのトランザクションで実行する

**リモート実行: SQL**ステップで、**SQL を 1 つのトランザクション内のステートメントのスクリプトとして実行する（すべて適用されるか、何も適用されない）**（`transaction`）にチェックを入れると、SQLがステートメントのスクリプトとして、1つのトランザクション内で順に実行されるため、すべてのステートメントが適用されるか、何も適用されないかのどちらかになります。
