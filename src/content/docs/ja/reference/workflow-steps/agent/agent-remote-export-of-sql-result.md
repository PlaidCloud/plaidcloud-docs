## 説明



PlaidLinkエージェントを通じてリモートデータベースでSQLを実行し、結果セットをプロジェクトテーブルとしてPlaidCloudに取り込みます。ソースデータベースにPlaidCloudから直接到達できない（ファイアウォール、VPNのみ、オンプレミス）が、それでもデータを取得したい場合に使用します。

エージェントがオンプレミスでクエリを実行し、結果をPlaidCloudにストリーミングするため、結果が必要になるまで、資格情報とデータの両方がネットワーク内にとどまります。
