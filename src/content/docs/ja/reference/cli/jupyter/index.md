PlaidCloudのJupyter連携を使うと、データサイエンティストはノートブック環境からプロジェクトテーブルを扱い、クエリを実行し、PlaidCloudをバックエンドストアとして利用できます。認証にはOAuthトークンを使用するため、CLI、ノートブック、REST APIで同じ認証情報を使えます。
