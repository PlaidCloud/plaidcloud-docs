## エージェントのダウンロード

[PlaidCloud.com](https://plaidcloud.com/)のリリースで**PlaidLink**を確認します。

## エージェントの展開

ダウンロードしたzipファイルを任意のインストール先に展開します。通常、インストール先は次のとおりです。

```bash
C:\Users\<Username here>\src\plaidlink
```

## 設定ファイルの作成

<Aside>以前のバージョンのエージェントからアップグレードする場合、設定ファイルはそのまま使用できるため、この手順は省略できます。</Aside>

エージェントのディレクトリにある`config-dist.yaml`ファイルを`%ProgramData\plaidcloud\`にコピーし、コピーしたファイルの名前を`config.yaml`に変更します。

*（この設定ファイルを、PlaidCloudから取得した値で編集します）*

## エージェントのサービスのインストール

エージェントのインストールディレクトリにある`install_windows_service.bat`ファイルを実行するか、次の手順を行います。

管理者として開いたコマンドプロンプトからエージェントのインストールディレクトリに移動し、次を実行します。

```bash
.\PlaidLink.exe install
```

## エージェントの実行

<Aside>Windowsサービスをインストールするには、管理者権限が必要です。</Aside>

Windowsの検索バーに **`Services`** と入力して、サービスマネージャーを開きます。サービスの一覧から **`PlaidCloud Agent`** を探します。

サービスを右クリックし、**「開始」** を選択してエージェントを起動します。

## 更新の凍結

エージェントの自動更新機能を無効にしたい場合は、エージェントの **'yaml'** 設定ファイルを開き、ファイルのルートレベルに`freeze_updates: true`という行を追加して、エージェントのサービスを再起動します。

<Aside type="caution">自動更新を無効にした状態を長期間続けることはお勧めしません。</Aside>
