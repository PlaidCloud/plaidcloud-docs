PlaidLinkエージェントは、PlaidCloudサービスと連携して動作します。PlaidLinkエージェントは、データベースやファイルシステムなど、直接アクセスできないシステムを操作するために必要な接続を提供します。エージェントは、次のような重要な処理を実行します。

* データベースの読み取りと書き込み
* ネットワークドライブやサーバーへのファイルの読み取りと書き込み
* センサー条件のチェック
* リモートファンクションコール（RFC）によるSAP ECCおよびSAP S/4HANAとの連携
* SAP Profitability and Cost Management（PCM）との連携
* リモートシステムへのメッセージと通知の送信

## PlaidCloudでエージェントを作成する

PlaidLinkエージェントの管理は、PlaidCloudのAnalyzeタブで行います。最初の手順は、PlaidCloudで新しいPlaidLinkエージェントのインスタンスを作成することです。

### 新しいPlaidLinkエージェントを作成するには

1. Analyzeタブを選択します
2. 上部のツールメニューを選択します
3. PlaidLinkエージェントをクリックします
4. リモート操作のためにインストールする環境またはサーバーに適した名前で、新しいエージェントを作成します

### エージェントの公開鍵と秘密鍵を表示するには

1. 編集アイコンをクリックして、フォームを表示します
2. フォームの下部に、エージェントの作成プロセスでランダムに生成された公開鍵と秘密鍵があります

<Aside>この鍵はリモートサーバーのエージェント設定で使用するため、控えておいてください。</Aside>

### 新しい鍵をランダムに生成するには

1. エージェントレコードの再生成アイコンをクリックします
2. 鍵を再生成したら、リモートサーバー上のエージェント設定ファイルを新しい鍵で更新することを忘れないでください。

<Aside>次の手順でリモートエージェントを設定するために、公開鍵と秘密鍵を保管しておいてください。</Aside>

## ドキュメントアカウントへのアクセス

エージェントがファイルのアップロードまたはダウンロードのためにドキュメントアカウントにアクセスする必要がある場合は、そのドキュメントアカウントへのアクセス権限を付与する必要があります。

### アカウントへのアクセスを付与するには

1. ドキュメントタブで、アカウントの管理を選択します
2. アカウントのテーブルが表示されたら、新しいエージェントにアップロード/ダウンロードの権限を与えるアカウントのエージェントアイコンをクリックします
3. 新しいエージェントを割り当て済みのエージェント列にドラッグします
4. アクセス制御フォームを保存します。

<Aside>エージェントは、1つ以上のドキュメントアカウントへのアクセス権が付与されている場合にのみ、ファイルのアップロードとダウンロードができます。</Aside>

## データ接続へのアクセス

エージェントがデータベースなどのデータ接続にアクセスする必要がある場合は、外部データ接続情報へのアクセス権限を付与する必要があります。


### 接続へのアクセスを付与するには


1. Analyzeタブで、ツールメニューを選択します
2. 外部データ接続をクリックします
3. データ接続のテーブルが表示されたら、新しいエージェントに使用権限を与える接続のエージェントアイコンをクリックします
4. 新しいエージェントを割り当て済みのエージェント列にドラッグし、アクセス制御フォームを保存します。

<Aside>エージェントのデータ接続の認証情報は、外部データ接続で管理されます。</Aside>
