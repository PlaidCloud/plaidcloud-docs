PlaidLinkエージェントは、PlaidCloudサービスと連携して動作します。PlaidLinkエージェントは、データベースやファイルシステムなど、直接アクセスできないシステムと連携するために必要な接続を提供します。エージェントは、次のような重要な処理を実行します。

* データベースの読み取りと書き込み
* ネットワークドライブやサーバーへのファイルの読み取りと書き込み
* センサー条件のチェック
* リモートファンクションコール（RFC）を介したSAP ECCおよびSAP S/4HANAとの連携
* SAP Profitability and Cost Management（PCM）との連携
* リモートシステムへのメッセージと通知の送信

## PlaidCloudでのエージェントの作成

PlaidLinkエージェントの管理は、PlaidCloudのAnalyzeタブで行います。最初の手順は、PlaidCloudで新しいPlaidLinkエージェントのインスタンスを作成することです。

### 新しいPlaidLinkエージェントを作成するには

1. Analyzeタブを選択します
2. 上部のツールメニューを選択します
3. PlaidLinkエージェントをクリックします
4. リモート操作用にインストールする環境またはサーバーに適した名前で、新しいエージェントを作成します

### エージェントの公開鍵と秘密鍵を表示するには

1. 編集アイコンをクリックしてフォームを表示します
2. フォームの下部に、エージェントの作成時にランダムに生成された公開鍵と秘密鍵があります

秘密鍵は、エージェントを編集できるメンバーにのみ表示されます。

<Aside>これらのキーは、リモートサーバー上のエージェントの設定で使用するため、控えておいてください。</Aside>

### 新しいキーをランダムに生成するには

1. エージェントのレコードで再生成アイコンをクリックします
2. キーを再生成したら、リモートサーバー上のエージェント構成ファイルを新しいキーで更新することを忘れないでください。

<Aside>次の手順でリモートエージェントを設定するために、公開鍵と秘密鍵を保管しておいてください。</Aside>

## ドキュメントアカウントへのアクセス

エージェントがファイルのアップロードまたはダウンロードのためにドキュメントアカウントにアクセスする必要がある場合は、そのドキュメントアカウントへのアクセス権限を付与する必要があります。

### アカウントへのアクセスを許可するには

1. ドキュメントで、レールの**管理**を選択します
2. アカウントのテーブルが表示されたら、新しいエージェントにアップロードとダウンロードの権限を付与するアカウントのエージェントアイコンをクリックします
3. 新しいエージェントを「割り当て済みのエージェント」列にドラッグします
4. アクセス制御フォームを保存します。

<Aside>エージェントがファイルをアップロードおよびダウンロードできるのは、1つ以上のドキュメントアカウントへのアクセスが許可されている場合のみです。</Aside>

## データ接続へのアクセス

エージェントがデータベースなどのデータ接続にアクセスする必要がある場合は、外部データ接続情報へのアクセス権限を付与する必要があります。


### 接続へのアクセスを許可するには


1. Analyzeタブでツールメニューを選択します
2. 外部データ接続をクリックします
3. データ接続のテーブルが表示されたら、新しいエージェントに使用権限を付与する接続のエージェントアイコンをクリックします
4. 新しいエージェントを「割り当て済みのエージェント」列にドラッグして、アクセス制御フォームを保存します。

<Aside>エージェントのデータ接続の認証情報は、外部データ接続で管理されます。</Aside>
