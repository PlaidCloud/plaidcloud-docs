**Drill**コマンドは 1 つのセルを対象に動作します。ノードをライブの [`PLAIDXL.DRILL`](/ja/reference/cli/plaidxl/functions/#drill) 数式に変換し、その数式を自動的に編集するため、レイアウトはディメンションとつながったままとなり、ディメンションが変更されると更新されます。各コマンドは、**PlaidCloud**リボンタブ、**PlaidXL**の右クリックメニュー、**PlaidXL Cell**タブ、および[キーボードショートカット](/ja/reference/cli/plaidxl/ribbon/#キーボードショートカット)から使用できます。

## セルからドリルダウンする

1. セルにディメンションのノードを入力して選択します。`4000` のような ID でも、`Revenue` のようなエイリアスでも構いません。
2. **Drill down**をクリックし、**One level**、**To lowest level**、**All levels**のいずれかを選択します。

セルは `PLAIDXL.DRILL` 数式になり、そのノードとその下位のノードが列方向に一覧表示されます。世代ごとにインデントされ、Excel のアウトラインにグループ化されるため、各レベルを折りたたむことができます。

PlaidXL は、セルの上にある最も近いディメンション名からディメンションを判断します。ディメンション名がない場合は、そのシートで最後にドリルしたディメンションを使用します。ディメンション名とノードのように、隣り合う 2 つのセルを選択することもでき、その場合はノードのセルにドリルが入ります。

ディメンションの最上位から開始するには、ディメンション名が入ったセル、またはその下の空のセルを選択します。ドリルは名前の下に配置され、ディメンションの最上位ノードから始まります。

### ドリル内でドリルする

既存のドリルの行に対して、同じコマンドを使用します。

- **One level**は、その行の子ノードをその場で展開し、一覧のそれ以外の部分はそのままにします。
- **To lowest level**と**All levels**は、その行のノードからドリルをやり直します。
- **Drill up**は、その行より上にある最も近い展開済みノードを閉じます。閉じるノードがない場合は、ドリルの開始ノードをその親に移動します。

ノードは入っているがドリルではないセルでは、**Drill up**はノードをその親に置き換えます。

### レポートの値からドリルする

レポートの値（`CELL` または `CELLS` 数式）を選択して**Drill down one level**を実行すると、その値の行の行見出しがその場で展開され、レポートの下にさらに詳細なレベルが追加されます。**Drill up**で再び閉じます。行見出しがドリルの一部でない場合や、**All levels**のようにその場でのドリルによってレポートの行が失われる場合は、PlaidXL は代わりに入力済みの**Custom drill**を開きます。

### 上書きと元に戻す

ドリルは、書き込む前に確認を求めることはありません。新しい行に必要なセルにすでに内容がある場合、PlaidXL はそのセルをクリアし、メッセージでクリアした数を伝えます。お使いの Excel のバージョンで編集をグループ化できる場合、ドリルは 1 回の元に戻す操作となり、**Ctrl+Z**ですべてが元に戻ります。古いバージョンでは、複数回必要になることがあります。タスクペインを開いている場合は、メッセージに**元に戻す**も表示されます。これは、ドリルが書き込んだ内容がまだ残っているセルだけを復元し、その後に編集した内容は保持します。

Drill コマンドは、列方向に展開されるドリルを編集します。レポートの列見出しのように行方向に展開される `DRILL` は、その数式で変更します。

## Keep Only と Remove Only

ドリルの 1 つまたは複数の行を選択します（複数のドリルにまたがっても構いません）。次に、以下のいずれかを実行します。

- **Remove only**は、選択したノードとその下位のすべてをドリルから除外します。ドリルの最初の行を除外すると、ドリルがクリアされます。
- **Keep only**は、選択したノードだけを残します。1 つのノードを選択した場合は、そのノードだけのドリルになります。複数のノードを選択した場合は、最も近い共通の親の下での位置が維持されます。

**Remove only**は、そのノードをドリルの `exclude` 引数に追加します。**Keep only**は、ドリルの開始ノード、キー、`exclude` を書き換えます。どちらの場合も、結果はライブのままです。PlaidXL は最大 5,000 個の選択セルを読み取ります。除外したノードの一覧が非常に長い場合は、数式が参照する**PlaidXL Lists**という非表示シートに移されます。

## Custom Drill

**Custom drill...** は、選択したセルから入力済みの状態で、**A list of dimension nodes**の**Formulas**タブを開きます。

- **Start from node** — 空白のままにすると、ディメンションの最上位から開始します。
- **How far to drill** — **All levels**、**Lowest level only**、一定のレベル数だけ**Down**、あるレベルから別のレベルまでを指定する**From level**、最後の一定のレベル数を除く**All but the last**、または `[1:3]` のようにドリルキーを入力する**Advanced (type the drill key)**。
- **Alternate hierarchy (optional)**。
- **Exclude nodes (optional, one id per line)** と**Open nodes (optional, one id per line)** — 除外するノードと、子ノードも表示するノード。

フィールドの横にある**Use selected cell**は、選択したセルまたは範囲をそのフィールドに指定するため、ドリルはそのセルに追従します。**行数**には、最初の 10 個のノードと合計数がプレビューされます。**すべて表示**をクリックすると、さらに表示されます。**Insert in active cell**をクリックすると、開始元のドリルを変更するか、アクティブセルに新しいドリルを配置します。**コピー**をクリックすると、数式を自分で貼り付けられます。

## メンバーを選択する

**Pick member...** は、選択したセルのディメンションに対するメンバーピッカーを、そのセルのテキストですでに検索した状態で開きます。**ディメンション**タブから開くこともできます。

- **Search id or alias**は、ディメンションのすべての階層を検索し、一致した各項目のパスを表示します。
- ディメンションに複数の階層がある場合は、一覧から階層を選択します。
- 矢印キーでツリーを移動し、**Space**でノードにチェックを付け、**Enter**で挿入します。

**挿入**は、ノードの ID をアクティブセルに書き込み、1 行下に移動します。ノードにチェックが付いている場合は、アクティブセルから下方向に入力します。**Fill down**と**Fill right**は、チェックを付けたノードを下方向または右方向に書き込みます。ノードをダブルクリックしても挿入できます。アクティブセルにドリルが入っている場合、挿入したノードがドリルの開始ノードになります。

挿入は既存の内容を上書きし、置き換えた入力済みセルの数をメッセージで伝えます。メッセージには**元に戻す**が表示されます。お使いの Excel のバージョンで編集をグループ化できる場合、**Ctrl+Z**で 1 回の操作で元に戻せます。

### メンバーのドロップダウンを追加する

選択肢を表示したいセルを選択します（たとえば、期間の列）。次にメンバーピッカーでノードを指定し、**Add dropdown**をクリックします。選択した各セルに、そのノードの子ノードのドロップダウンが追加されます。一覧は、非表示の**PlaidXL Lists**シート上のドリルであるため、ディメンションが変更されると更新されます。セルの値は保持され、一覧にない値も引き続き入力できます。

ライブの一覧に追従するドロップダウンには、Microsoft 365 版 Excel または Excel 2024 が必要です。お使いの Excel のバージョンで編集をグループ化できる場合、**Ctrl+Z**で 1 回の操作でドロップダウンを削除できます。

## 数値を説明する

**Explain this number**は、選択した各 PlaidXL セルのカードを表示した**説明**タブを開きます。`CELL`、`CELLS`、`DRILL`、`TABLE.GET_TABLE`、`METRIC`、`METRIC_BREAKDOWN` を説明でき、`IFERROR` など別の数式の内部にあるものも対象です。PlaidXL 数式ではないセルを選択すると、PlaidXL はそのセルの計算元となっている PlaidXL セルを説明します。

各カードには、次の内容が表示されます。

- セルが何を計算しているか。たとえば、テーブルの列の合計を各ノードで絞り込んだもので、各ノードの下にあるリーフメンバーの数も表示されます。
- 現在計算された値と、それがセルと一致しているかどうか。一致しない場合は、**Recalculate**でセルを最新の状態にします。
- **Where this comes from** — テーブルのデータが最後に更新された日時、行数、テーブルを作成したワークフローのステップ。それぞれ PlaidCloud にリンクされています。
- **PlaidCloudでテーブルを開く**、**Drill through to rows**、**Copy explanation**。

フィルターノードは PlaidCloud のノードにリンクされ、その**Drill**ボタンで、そのノードの子ノードが行として追加されます。セルにエラーが表示されている場合、カードにその理由が示され、可能であれば、**プロジェクトを選択…** ボタンや、最も近い候補を表示する**Pick a member**など、修正方法が提示されます。

多数のセルをまとめて説明する場合、カードは 20 件ずつ読み込まれ、末尾のボタンで残りを表示できます。

## 詳細行を表示する

**Show detail rows**は、`CELL` または `CELLS` の値の裏付けとなるテーブルの行を、ノード名とテーブル名を付けた新しいシートに配置します。PlaidXL の値から計算されているセルを選択すると、PlaidXL はその値を使用します。

- 1 行目には、値の説明とその値へのリンクが表示されます。
- 2 行目では、行の合計が値と一致するかを確認します。**ties**と表示されるか、差額が表示されます。
- 行は 3 行目から、Excel テーブルとして始まります。

行の読み込み中は、タスクペインに進行状況と**キャンセル**が表示されます。同じ値に対して**Show detail rows**をもう一度実行すると、そのシートが更新され、**Refresh all tables**で最新の状態に保たれます。詳細シートは [PlaidCloud に保存し直す](/ja/reference/cli/plaidxl/retrieve/#テーブルを-plaidcloud-に保存する)ことができ、保存ではその値の裏付けとなる行だけが置き換えられます。

<Aside type="tip">
セルが何をしているかわからない場合は、セルを選択して**Ctrl+Alt+Shift+E**（Mac では**⌘⌥⇧E**）を押すと説明が表示されます。**Ctrl+Alt+Shift+Q**を押すと、そのセルについて [Weave に質問](/ja/reference/cli/plaidxl/weave/)できます。
</Aside>
