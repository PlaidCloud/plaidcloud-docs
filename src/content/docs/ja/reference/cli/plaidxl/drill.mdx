**ドリル** コマンドは、1つのセルに対して動作します。ノードをライブの [`PLAIDXL.DRILL`](/ja/reference/cli/plaidxl/functions/#drill) 数式に変換し、その数式を自動で編集します。そのため、レイアウトはディメンションと連動したままで、ディメンションが変わると更新されます。各コマンドは、**PlaidCloud** リボンタブ、**PlaidXL** の右クリックメニュー、**PlaidXL Cell** タブ、および[キーボードショートカット](/ja/reference/cli/plaidxl/ribbon/#キーボードショートカット)から使用できます。

## セルからドリルダウンする

1. ディメンションのノードをセルに入力して選択します。`4000` などのIDや、`Revenue` などのエイリアスを使えます。
2. **Drill down** をクリックし、**One level**、**To lowest level**、**All levels** のいずれかをクリックします。

セルは `PLAIDXL.DRILL` 数式になり、そのノードとその配下のノードを列の下方向に一覧表示します。世代ごとにインデントされ、Excelのアウトラインにグループ化されるため、各レベルを折りたたむことができます。

PlaidXLは、セルの上にある最も近いディメンション名からディメンションを判断します。ディメンション名がない場合は、シートで最後にドリルしたディメンションを使用します。ディメンション名とノードの2つの隣り合うセルを選択することもでき、その場合はドリルはノードのセルに配置されます。

ディメンションの最上位から開始するには、ディメンション名を含むセル、またはその下の空のセルを選択します。ドリルは名前の下に配置され、ディメンションの最上位ノードから始まります。

### ドリル内でドリルする

既存のドリルの行に対して、同じコマンドを使用します。

- **One level** は、その行の子をその場で開き、リストの残りはそのままにします。
- **To lowest level** と **All levels** は、その行のノードからドリルをやり直します。
- **Drill up** は、その行の上にある最も近い開いているノードを閉じます。閉じるノードがない場合は、ドリルの開始ノードをその親に移動します。

ノードを含み、ドリルがないセルでは、**Drill up** はそのノードを親に置き換えます。

### レポートの値からドリルする

レポートの値（`CELL` または `CELLS` 数式）を選択して **Drill down one level** を実行すると、その値の行の行ヘッダーがその場で開き、その下に次のレベルの詳細が追加されます。**Drill up** で再び閉じます。行見出しがドリルの一部でない場合や、**All levels** のように、その場でドリルするとレポートの行が失われる場合は、代わりにPlaidXLが入力済みの **Custom drill** を開きます。

### 上書きと元に戻す

ドリルは、書き込む前に確認を求めません。新しい行に必要なセルにすでに内容がある場合、PlaidXLはそれらをクリアし、メッセージにその数を表示します。ドリルの編集は、Excelの元に戻す操作の1ステップとして記録されるため、**Ctrl+Z** ですべてが元に戻ります。タスクペインが開いている場合は、メッセージに **元に戻す** も表示されます。これは、ドリルが書き込んだ内容のままのセルだけを復元し、その後に編集した内容はそのまま残します。

ドリルコマンドは、列方向に展開するドリルを編集します。レポートの列見出しのように、行方向に展開する `DRILL` は、数式の中で変更します。

## Keep Only と Remove Only

複数のドリルにまたがっても構いませんので、ドリルの行を1つ以上選択して、次の操作を行います。

- **Remove only** は、選択したノードとその配下のすべてをドリルから取り除きます。ドリルの最初の行を削除すると、ドリルがクリアされます。
- **Keep only** は、選択したノードだけを残します。1つのノードの場合は、そのノードだけのドリルになります。複数のノードの場合は、最も近い共通の親の下に、それぞれの位置を維持します。

どちらも、ドリルの `exclude` 引数を変更するため、結果はライブのままです。PlaidXLは最大5,000個の選択セルを読み取ります。削除したノードのリストが非常に長い場合は、**PlaidXL Lists** という非表示のシートに移され、数式はそのシートを参照します。

## Custom Drill

**Custom drill...** ボタンは、選択したセルから入力済みの状態で、**A list of dimension nodes** の **Formulas** タブを開きます。

- **Start from node** — 空白にすると、ディメンションの最上位から開始します。
- **How far to drill** — **All levels**、**Lowest level only**、指定した数のレベルを **Down**、あるレベルから別のレベルまでを **From level**、最後の数レベルを除く **All but the last**、または `[1:3]` のようにドリルキーを入力する **Advanced (type the drill key)** を選択します。
- **Alternate hierarchy (optional)**。
- **Exclude nodes (optional, one id per line)** と **Open nodes (optional, one id per line)** — 除外するノードと、子も合わせて表示するノードです。

フィールドの横にある **Use selected cell** は、選択したセルまたは範囲をそのフィールドに指定するため、ドリルがそのセルに追従します。**行数** は、最初の10ノードと合計をプレビューします。**すべて表示** をクリックすると、さらに表示されます。**Insert in active cell** をクリックすると、開始元のドリルを変更するか、アクティブセルに新しいドリルを配置します。**コピー** をクリックすると、数式を自分で貼り付けることができます。

## メンバーを選択する

**Pick member...** ボタンは、選択したセルのディメンションに対するメンバーピッカーを、セルのテキストで検索済みの状態で開きます。**ディメンション** タブからも開くことができます。

- **Search id or alias** は、ディメンションのすべての階層を検索し、一致した各ノードのパスを表示します。
- ディメンションに複数の階層がある場合は、リストから階層を選択します。
- 矢印キーでツリーを移動し、**Space** でノードをオンにして、**Enter** で挿入します。

**挿入** は、ノードのIDをアクティブセルに書き込み、1行下に移動します。ノードをオンにしている場合は、アクティブセルから下に向かって入力します。**Fill down** と **Fill right** は、オンにしたノードを下方向または右方向に書き込みます。ノードをダブルクリックすると挿入されます。アクティブセルにドリルがある場合、挿入したノードがドリルの開始ノードになります。

挿入すると、既存の内容は上書きされ、置き換えた入力済みセルの数がメッセージに表示されます。これは、元に戻す操作の1ステップです。

### メンバーのドロップダウンを追加する

選択肢を提示したいセル（たとえば期間の列）を選択し、メンバーピッカーでノードを指定して、**Add dropdown** をクリックします。選択した各セルに、そのノードの子のドロップダウンが追加されます。リストは、非表示の **PlaidXL Lists** シート上のドリルなので、ディメンションが変わると更新されます。セルは値を保持し、リストにない値も入力できます。

ライブのリストに追従するドロップダウンには、Microsoft 365版のExcelまたはExcel 2024が必要です。**Ctrl+Z** でドロップダウンが削除されます。

## 数値を説明する

**Explain this number** は、選択した各PlaidXLセルのカードを含む **説明** タブを開きます。`CELL`、`CELLS`、`DRILL`、`TABLE.GET_TABLE`、`METRIC`、`METRIC_BREAKDOWN` を説明します。`IFERROR` などの別の数式に含まれているものも対象です。PlaidXL数式ではないセルを選択すると、PlaidXLは、そのセルの計算元となっているPlaidXLセルを説明します。

各カードには、次の内容が表示されます。

- セルが計算している内容。たとえば、テーブルの列の合計を各ノードでフィルターしたもので、各ノードの配下にあるリーフメンバーの数も表示されます。
- 現在計算された値と、それがセルと一致しているかどうか。一致していない場合は、**Recalculate** でセルが最新になります。
- **Where this comes from** — テーブルのデータが最後に更新された日時、行数、およびテーブルを作成したワークフローのステップ。それぞれPlaidCloudへのリンクが付いています。
- **Open table in PlaidCloud**、**Drill through to rows**、**Copy explanation**。

フィルターノードはPlaidCloud内のノードにリンクし、その **Drill** ボタンで、そのノードの子を行として追加します。セルにエラーが表示されている場合、カードにその理由が表示され、可能な場合は修正方法も提示されます。**Choose a project**、または最も近い候補付きの **Pick a member** です。

多数のセルを一度に説明する場合、カードは20枚ずつ読み込まれ、最後に残りを表示するボタンが表示されます。

## 明細行を表示する

**Show detail rows** は、`CELL` または `CELLS` の値の元になっているテーブルの行を、ノードとテーブルにちなんだ名前の新しいシートに配置します。PlaidXLの値から計算されているセルを選択した場合は、PlaidXLがその値を使用します。

- 1行目には、値の説明と、その値へのリンクが入ります。
- 2行目では、行の合計が値と一致するかどうかを確認します。**ties**（一致）、または差異の大きさが表示されます。
- 行は3行目から、Excelテーブルとして始まります。

行の読み込み中は、タスクペインに進行状況が **キャンセル** とともに表示されます。同じ値に対して **Show detail rows** をもう一度実行すると、そのシートが更新され、**Refresh all tables** で最新の状態に保たれます。明細シートは、[PlaidCloudに保存し直す](/ja/reference/cli/plaidxl/retrieve/#テーブルをplaidcloudに保存する)ことができます。保存では、その値の元になっている行だけが置き換えられます。

<Aside type="tip">
セルが何をしているのかわからない場合は、そのセルを選択して **Ctrl+Alt+Shift+E**（Macでは **⌘⌥⇧E**）を押すと説明が表示されます。**Ctrl+Alt+Shift+Q** を押すと、そのセルについて[Weaveに質問](/ja/reference/cli/plaidxl/weave/)できます。
</Aside>
