PlaidXL は、PlaidCloud のデータをセルに直接読み込む関数を Excel に追加します。セルに `=PLAIDXL.` と入力すると、Excel のオートコンプリートで各関数と引数の簡単な説明が表示されます。タスクペインの **Formulas** タブで数式を作成することもできます。詳しくは、[タスクペインから数式を挿入する](#タスクペインから数式を挿入する)を参照してください。

| グループ | 関数 | 用途 |
|---|---|---|
| 一覧 | [`LIST_PROJECTS`](#list_projects)、[`TABLE.TBL_LIST`](#tbl_list)、[`TABLE.GET_COLUMNS`](#get_columns)、[`DIMENSION.DIM_LIST`](#dim_list) | 利用できるものを確認する |
| テーブル | [`TABLE.GET_TABLE`](#get_table) | テーブル全体を範囲に読み込む |
| 階層 | [`DIMENSION.GET_DIMENSION`](#get_dimension)、[`DRILL`](#drill) | ディメンションのノードをレポートの行として配置する |
| 値 | [`CELL`](#cell)、[`CELLS`](#cells) | 任意のノードの組み合わせについて集計値を計算する |
| 構成要素 | [`REPR.TABLE_REPR`](#table_repr)、[`REPR.MEASURE`](#measure)、[`REPR.MEASURES`](#measures)、[`REPR.MEASURE_TYPE`](#measure_type)、[`REPR.DIMENSION_REPR`](#dimension_repr)、[`REPR.DRILL_KEY`](#drill_key) | `CELL`、`CELLS`、`DRILL` が使用するテーブル、メジャー、集計方法、ノード、ドリルの深さを記述する |

これらを組み合わせた例は、[カスタム関数でレポートを作成する](/ja/reference/cli/plaidxl/build-a-report/)を参照してください。

## 関数の仕組み

- **最初にサインインします。** 関数は PlaidCloud のサインイン情報を使って読み取るため、使用する前にタスクペインから[サインイン](/ja/reference/cli/plaidxl/connect/)してください。
- **ブックのプロジェクトから読み取ります。** すべての関数は、タスクペインでブックにリンクされているプロジェクトから読み取ります。`GET_TABLE`、`TBL_LIST`、`DIM_LIST` は、リンクを変更せずに別のプロジェクトを読み取るためのオプションのプロジェクト ID も受け取ります。プロジェクトはブックごとに設定されるため、開いている 2 つのブックで異なるプロジェクトを読み取ることもできます。
- **結果は展開されます。** リストやテーブルを返す関数は、その下（または右）のセルに結果を展開します。結果を表示する領域を空けておいてください。何かが邪魔をすると、Excel に `#SPILL!` エラーが表示されます。
- **変更を反映するには再計算します。** PlaidXL の数式は、引数のいずれかが変更されると再度データを取得します。PlaidCloud の新しいデータや、タスクペインでリンクした別のプロジェクトを反映するには、完全再計算を実行します。Windows では **Ctrl+Alt+F9** を押します。**Refresh All Tables** は取得したテーブルを更新するものであり、数式は更新しません。
- **正確な名前を使用します。** テーブル、列、ディメンション、ノードの名前は、PlaidCloud に表示されているとおりに入力してください。

角かっこで囲まれた引数は省略可能です。

## 一覧

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

開くことのできるプロジェクトの名前を、名前順に一覧表示します。

- `horizontal` — `TRUE` を指定すると、行方向に一覧表示します。デフォルトは `FALSE` で、列方向です。

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

プロジェクト内のテーブルの名前を、名前順に一覧表示します。

- `project_id` — 読み取るプロジェクトです。デフォルトはブックのプロジェクトです。
- `horizontal` — `TRUE` を指定すると、行方向に一覧表示します。デフォルトは `FALSE` で、列方向です。

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

選択したプロジェクト内のテーブルの列名を一覧表示します。

- `table_name` — PlaidCloud 上のテーブル名です。
- `column_filter` — `"text"` などのデータ型を指定すると、その型の列だけを一覧表示します。省略すると、すべての列を一覧表示します。
- `orientation` — `"vertical"`（デフォルト）は列方向、`"horizontal"` は行方向です。

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

プロジェクト内のディメンションの名前を一覧表示します。

- `project_id` — 読み取るプロジェクトです。デフォルトはブックのプロジェクトです。
- `horizontal` — `TRUE` を指定すると、行方向に一覧表示します。デフォルトは `FALSE` で、列方向です。

## テーブル

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

テーブルの行をヘッダー行付きで返し、数式のあるセルから展開します。空の値は空白のセルとして返されます。

- `table_name` — PlaidCloud 上のテーブル名です。
- `project_id` — 読み取るプロジェクトです。デフォルトはブックのプロジェクトです。
- `limit` — 返す行数の上限です。デフォルトは 1,048,575 で、これはワークシートのヘッダー行の下に収まる最大行数です。

`GET_TABLE` はすべての列を返します。列を選択したり行を絞り込んだりするには、代わりに[タスクペインからテーブルを取得](/ja/reference/cli/plaidxl/retrieve/#テーブルを取得する)してください。

## 階層

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

`start_node` から始めて子孫へ向かって、ディメンションのノードを配置します。各世代は親より 4 スペース多くインデントされ、Excel のアウトライングループによって各レベルを折りたたんだり展開したりできます。

- `dimension_name` — ディメンションの名前、またはプロジェクト内でのパスです。
- `start_node` — 開始するノードです。ディメンションのルートなどを指定します。
- `hierarchy` — たどる[代替階層](/ja/guides/dimensions/dimensions/#代替属性階層)です。デフォルトは `"main"` です。
- `orientation` — `"vertical"`（デフォルト）はノードを列方向に、`"horizontal"` は行方向に一覧表示します。
- `generation_limit` — `start_node` を第 1 世代として数えて、返す世代数を指定します。`2` を指定すると、開始ノードとその子を返します。省略すると、すべての世代を返します。

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

`start_node` と、`drill_key` が指定する下位のノードを、世代ごとにインデントし、Excel のアウトラインにグループ化して列方向に返します。

- `dimension_name` — ディメンションの名前、またはプロジェクト内でのパスです。
- `start_node` — ドリルを開始するノードです。
- `drill_key` — どこまでドリルするかを、[`DRILL_KEY`](#drill_key) で指定します。すべての子孫、リーフのみ、指定した数のレベル、または世代の範囲を指定できます。
- `hierarchy` — たどる代替階層です。デフォルトは `"main"` です。

たとえば、`=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))` は、**Total** に続けて、その下にあるすべてのリーフのリージョンを一覧表示します。

[リボンの展開コマンド](/ja/reference/cli/plaidxl/ribbon/#drill-functions)は、2 つのセルに入力したディメンションとノードに対して、数式を書かずに同じ操作を行います。

## 値

`CELL` と `CELLS` は、テーブルの数値列であるメジャーを、1 つ以上のディメンションで選択したノードまで集計して計算します。各呼び出しは、レポート内の 1 つの交点と考えてください。たとえば、**FY2026** の **EMEA** における**収益**です。

交点は、後述の構成要素関数で記述します。通常は専用のセルに配置し、それらのセルを任意の順序で `CELL` または `CELLS` に渡します。

| 引数 | 作成に使う関数 | 必須 |
|---|---|---|
| 読み取るテーブル | [`TABLE_REPR`](#table_repr) | ちょうど 1 つ |
| 集計する列 | `CELL` の場合は [`MEASURE`](#measure)、`CELLS` の場合は [`MEASURES`](#measures) または複数の `MEASURE` セル | はい |
| 集計方法 | [`MEASURE_TYPE`](#measure_type) | いいえ — デフォルトは `sum` |
| 列に対するフィルター | [`DIMENSION_REPR`](#dimension_repr) | 少なくとも 1 つ、列ごとに 1 つ |

各フィルターは、**テーブルの列**と値を指定します。その列が PlaidCloud でディメンションにリンクされている場合、値はノードとなり、フィルターにはディメンションのメイン階層でそのノードに集約されるすべてが含まれます。たとえば、地理ディメンションにリンクされた **Region** 列では、ノード **EMEA** はその下にあるすべての国を対象とします。ディメンションにリンクされていない列では、フィルターは値と完全に一致するものを対象とします。

このページの例では、**Region** 列と **Period** 列がディメンションにリンクされているテーブルを使用します。実際には、お使いのテーブルの列名を使用してください。

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

1 つの数値を返します。指定したすべてのノードの配下に該当する行にわたって集計したメジャーです。

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1` には、FY2026 の EMEA における収益の合計が表示されます。

`CELL` 数式をシート全体に配置する場合、セルごとの参照回数が少なくて済みます。PlaidXL はセルごとに取得せず、テーブルの列の詳細を短時間再利用するためです。値を計算できない場合、セルには `#VALUE!` が表示され、その上にマウスポインターを置くと、PlaidCloud が報告した理由が表示されます。たとえば、テーブルにないフィルター列や、メンバーのないノードなどです。`CELLS` では、結果全体に対して最初の理由が表示されます。

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

`CELL` と同様ですが、複数のメジャーを一度に処理します。メジャーごとに 1 つの数値を、指定した順序で列方向に返します。

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#` は、`MEASURES` の展開結果全体を渡します。`B2:B4` には、FY2026 の EMEA における収益、コスト、数量が表示されます。

## 構成要素

これらの関数自体はデータを読み取りません。それぞれが、計算の一部を記述した短いテキストを返し、`CELL`、`CELLS`、`DRILL` に渡せる形になっています。参照するセルに配置しておくと、たとえば期間を変更するだけで、それを使用するすべての数式が更新されます。

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

`CELL` と `CELLS` が読み取るテーブルを、選択したプロジェクト内の名前で指定します。

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

`CELL` が集計する数値列です。

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

`CELLS` 用の複数のメジャー列を、列名が入力されたセル範囲から指定します。結果は列ごとに 1 つのセルに展開されます。`D2#` のようにスピル演算子を使って `CELLS` に渡します。

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

メジャーの集計方法です。`agg_function` には、次のいずれかを小文字で指定します。

| 値 | 返す内容 |
|---|---|
| `sum` | 合計（メジャータイプを渡さない場合のデフォルト） |
| `mean` | 平均 |
| `median` | 中央値 |
| `min` | 最小値 |
| `max` | 最大値 |
| `std` | 標準偏差 |
| `var` | 分散 |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

`CELL` と `CELLS` のフィルターです。フィルター対象にする列ごとに 1 つ渡します。

- `dimension_name` — **テーブルの列**の名前です。`"Region"` のように、ディメンションの値を保持する列を指定します。列名と完全に一致する必要があります。テーブルにない列を指定するとエラーが返されます。
- `start_node` — 集約先のノードです。`"EMEA"` などを指定します。ディメンションにリンクされていない列では、一致させる値を指定します。

ノードにセルを参照すると、グリッドを作成できます。`=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)` のようにします。先頭と末尾のスペースは無視されるため、`DRILL` が配置するインデント付きのノード名を参照することもできます。

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

[`DRILL`](#drill) が開始ノードの下をどこまでたどるかを指定します。`d_key` はプレーンテキストで、単語形式またはドリルキーを直接記述した形式のいずれかです。

| `d_key` | ドリルの範囲 |
|---|---|
| `"all"` | すべての子孫 |
| `"leaves"` | リーフのみ。下位に何もないノードです |
| `"1 level"`、`"2 levels"`、… | その数の世代分だけ下 |
| `">[...]"` | 直接記述したドリルキー。次の表を参照してください |

数値は数字で記述します。`"two levels"` ではなく `"2 levels"` と指定します。先頭の `drill` は無視されるため、`"drill 2 levels"` も使用できます。

直接記述したキーは、開始ノードを世代 0 として、そこから下へ世代を数えます。開始ノードは常に含まれます。負の数は各ブランチのリーフから上へ数えるため、不揃いな階層でも想定どおりに動作します。

| キー | 含まれるもの |
|---|---|
| `>[*]` または `>[:]` | すべてのノード |
| `>[]` または `>[-1]` | リーフのみ |
| `>[n]` | 開始ノードと、その下の `n` 世代。`>[0]` は開始ノードのみです。 |
| `>[a:]` | 開始ノードと、世代 `a` 以下のすべて |
| `>[a:b]` | 開始ノードと、世代 `a` から `b - 1` まで |
| `>[0:-k]` | 開始ノードと、下に少なくとも `k` 世代あるすべてのノード。各ブランチの最後の `k` 世代は除外されます。`>[0:-1]` はリーフを除くすべてのノードです。 |
| `>[a:-k]` | 同じですが、世代 `a` から開始します |

`A` を親とし、その子を `B`、`C`、`D` とします。`B` には `B1` と `B2`、`C` には `C1` があります。この階層での結果は次のとおりです。

| キー | 結果 |
|---|---|
| `>[1]` | `A`、`B`、`C`、`D` |
| `>[2]` | `A`、`B`、`B1`、`B2`、`C`、`C1`、`D` |
| `>[]` | `A`、`B1`、`B2`、`C1`、`D` |
| `>[0:-1]` | `A`、`B`、`C` |
| `>[2:]` | `A`、`B1`、`B2`、`C1` |

ノードは階層の順序で、それぞれが自身の親の下に一覧表示され、Excel のアウトライングループも同じ順序に従います。キー内のスペースは無視されます。これらの形式に一致しないキーを指定すると、有効な形式を一覧表示したエラーが返されます。

<Aside type="caution">
`>[-1]` と `>[0:-1]` は、以前のバージョンの PlaidXL とは意味が異なります。以前は逆になっていました。現在は、`>[-1]` はリーフのみを返し、`>[0:-1]` はリーフを除くすべてを返します。ドリルキーを手で直接記述しているブックは見直してください。単語形式の `"all"`、`"leaves"`、`"2 levels"` は変更されていません。
</Aside>

<Aside type="note">
`CELL`、`CELLS`、`DRILL` は、これらの構成要素関数の出力を想定しています。テキストを自分で入力せず、各引数は対応する関数で作成してください。
</Aside>

## タスクペインから数式を挿入する

タスクペインの **Formulas** タブでは、数式を作成できます。**What do you want in the cell?** 欄で、次のいずれかを選択します。

- **A whole table**（`GET_TABLE`）— テーブルを選択または入力し、必要に応じて最大行数を指定します。
- **One number**（`CELL`）— テーブルを選択または入力し、**Column to total** と **How to combine the values** を選択します。
- **A list of dimension nodes**（`DRILL`）— ディメンションと開始ノードを選択または入力し、**All levels**、**Lowest level only**、または指定した数の **levels** の **Down** のいずれかを選択して、必要に応じて **Alternate hierarchy** を指定します。

**Formula** プレビューには、フィールドに入力するのに合わせて結果が表示されます。**Insert in active cell** をクリックすると選択中のセルに挿入され、**Copy** をクリックすると自分で貼り付けることができます。**Tables** タブでテーブルを選択するか、**Dimensions** タブでディメンションを選択すると、対応するフィールドに入力されます。
