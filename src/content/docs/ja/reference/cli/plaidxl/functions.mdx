PlaidXLは、PlaidCloudのデータをセルに直接読み込む関数をExcelに追加します。セルに`=PLAIDXL.`と入力すると、Excelのオートコンプリートに関数が一覧表示され、各引数の簡単な説明も表示されます。作業ウィンドウの**Formulas**タブでも数式を作成できます。[作業ウィンドウから数式を挿入する](#作業ウィンドウから数式を挿入する)を参照してください。

| グループ | 関数 | 用途 |
|---|---|---|
| 一覧 | [`LIST_PROJECTS`](#list_projects)、[`TABLE.TBL_LIST`](#tbl_list)、[`TABLE.GET_COLUMNS`](#get_columns)、[`DIMENSION.DIM_LIST`](#dim_list) | 利用できるものを確認する |
| テーブル | [`TABLE.GET_TABLE`](#get_table) | テーブル全体を範囲に読み込む |
| 階層 | [`DIMENSION.GET_DIMENSION`](#get_dimension)、[`DRILL`](#drill) | ディメンションのノードをレポートの行としてレイアウトする |
| 値 | [`CELL`](#cell)、[`CELLS`](#cells) | ノードの任意の組み合わせについて集計値を計算する |
| 構成要素 | [`REPR.TABLE_REPR`](#table_repr)、[`REPR.MEASURE`](#measure)、[`REPR.MEASURES`](#measures)、[`REPR.MEASURE_TYPE`](#measure_type)、[`REPR.DIMENSION_REPR`](#dimension_repr)、[`REPR.DRILL_KEY`](#drill_key) | `CELL`、`CELLS`、`DRILL`が使用するテーブル、メジャー、集計、ノード、展開の深さを記述する |

[カスタム関数でレポートを作成する](/ja/reference/cli/plaidxl/build-a-report/)では、これらの関数を組み合わせた例を紹介しています。

## 関数の仕組み

- **最初にサインインします。** 関数はPlaidCloudのサインインを使用して読み取るため、使用する前に作業ウィンドウから[サインイン](/ja/reference/cli/plaidxl/connect/)してください。
- **関数はブックのプロジェクトから読み取ります。** すべての関数は、作業ウィンドウでブックにリンクされているプロジェクトから読み取ります。`GET_TABLE`、`TBL_LIST`、`DIM_LIST`は、リンクを変更せずに別のプロジェクトから読み取るためのプロジェクトIDも、省略可能な引数として受け取ります。各ブックには独自のプロジェクトがあるため、開いている2つのブックがそれぞれ別のプロジェクトから読み取ることもできます。
- **結果は展開されます。** リストやテーブルを返す関数は、その下（または右）のセルに結果を展開します。結果のための余白を確保してください。何かが邪魔をしている場合、Excelは`#SPILL!`エラーを表示します。
- **変更を反映するには再計算します。** PlaidXLの数式は、引数のいずれかが変更されると再取得します。PlaidCloudの新しいデータや、作業ウィンドウでリンクした別のプロジェクトを反映するには、完全な再計算を強制します。Windowsでは**Ctrl+Alt+F9**を押します。**Refresh All Tables**が更新するのは取得済みのテーブルであり、数式ではありません。
- **正確な名前を使用します。** テーブル、列、ディメンション、ノードの名前は、PlaidCloudに表示されているとおりに正確に入力してください。

角かっこで囲まれた引数は省略可能です。

## 一覧

### LIST_PROJECTS

`=PLAIDXL.LIST_PROJECTS([horizontal])`

開くことができるプロジェクトの名前を、名前順で一覧表示します。

- `horizontal` — `TRUE`にすると、行方向に一覧表示します。デフォルトは`FALSE`で、列方向です。

### TBL_LIST

`=PLAIDXL.TABLE.TBL_LIST([project_id], [horizontal])`

プロジェクト内のテーブルの名前を、名前順で一覧表示します。

- `project_id` — 読み取るプロジェクト。デフォルトはブックのプロジェクトです。
- `horizontal` — `TRUE`にすると、行方向に一覧表示します。デフォルトは`FALSE`で、列方向です。

### GET_COLUMNS

`=PLAIDXL.TABLE.GET_COLUMNS(table_name, [column_filter], [orientation])`

選択したプロジェクト内のテーブルの列名を一覧表示します。

- `table_name` — PlaidCloudでのテーブルの名前。
- `column_filter` — `"text"`などのデータ型。指定すると、その型の列だけを一覧表示します。省略すると、すべての列を一覧表示します。
- `orientation` — `"vertical"`（デフォルト）は列方向、`"horizontal"`は行方向です。

### DIM_LIST

`=PLAIDXL.DIMENSION.DIM_LIST([project_id], [horizontal])`

プロジェクト内のディメンションの名前を一覧表示します。

- `project_id` — 読み取るプロジェクト。デフォルトはブックのプロジェクトです。
- `horizontal` — `TRUE`にすると、行方向に一覧表示します。デフォルトは`FALSE`で、列方向です。

## テーブル

### GET_TABLE

`=PLAIDXL.TABLE.GET_TABLE(table_name, [project_id], [limit])`

ヘッダー行を含むテーブルの行を、数式のセルから展開して返します。空の値は空白のセルとして返されます。

- `table_name` — PlaidCloudでのテーブルの名前。
- `project_id` — 読み取るプロジェクト。デフォルトはブックのプロジェクトです。
- `limit` — 返す行数の上限。デフォルトは1,048,575で、ワークシートがヘッダー行の下に保持できる最大の行数です。

`GET_TABLE`はすべての列を返します。列を選択したり行をフィルターしたりするには、代わりに[作業ウィンドウからテーブルを取得](/ja/reference/cli/plaidxl/retrieve/#テーブルを取得する)してください。

## 階層

### GET_DIMENSION

`=PLAIDXL.DIMENSION.GET_DIMENSION(dimension_name, start_node, [hierarchy], [orientation], [generation_limit])`

`start_node`から始めて、その子孫を下方向にたどりながら、ディメンションのノードをレイアウトします。各世代は親より4スペース多くインデントされ、Excelのアウトライングループで各レベルを折りたたんだり展開したりできます。

- `dimension_name` — ディメンションの名前、またはプロジェクト内でのそのパス。
- `start_node` — 開始するノード（ディメンションのルートなど）。
- `hierarchy` — たどる[代替階層](/ja/guides/dimensions/dimensions/#代替属性階層)。デフォルトは`"main"`です。
- `orientation` — `"vertical"`（デフォルト）はノードを列方向に、`"horizontal"`は行方向に一覧表示します。
- `generation_limit` — 返す世代数。`start_node`を最初の世代として数えます。`2`を指定すると、開始ノードとその子が返されます。省略すると、すべての世代が返されます。

### DRILL

`=PLAIDXL.DRILL(dimension_name, start_node, drill_key, [hierarchy])`

`start_node`と、`drill_key`が要求するその下のノードを、列方向に返します。世代ごとにインデントされ、Excelのアウトラインにグループ化されます。

- `dimension_name` — ディメンションの名前、またはプロジェクト内でのそのパス。
- `start_node` — 展開の起点となるノード。
- `drill_key` — どこまで展開するか。[`DRILL_KEY`](#drill_key)で指定します。すべての子孫、リーフのみ、レベル数、または世代の範囲を指定できます。
- `hierarchy` — たどる代替階層。デフォルトは`"main"`です。

たとえば、`=PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("leaves"))`は、**Total**に続けて、その下にあるすべてのリーフのリージョンを一覧表示します。

[リボンの展開コマンド](/ja/reference/cli/plaidxl/ribbon/#drill-functions)を使うと、2つのセルに入力したディメンションとノードに対して、数式を書かずに同じ操作ができます。

## 値

`CELL`と`CELLS`は、1つ以上のディメンションで選択したノードに集計されたメジャー（テーブルの数値列）を計算します。それぞれの呼び出しは、レポートの1つの交点（**FY2026**における**EMEA**の**収益**など）と考えてください。

交点は、以下の構成要素の関数で記述します。通常は専用のセルに入力し、それらのセルを`CELL`または`CELLS`に任意の順序で渡します。

| 引数 | 作成に使用する関数 | 必須 |
|---|---|---|
| 読み取るテーブル | [`TABLE_REPR`](#table_repr) | ちょうど1つ |
| 集計する列 | `CELL`には[`MEASURE`](#measure)、`CELLS`には[`MEASURES`](#measures)または複数の`MEASURE`セル | はい |
| 集計方法 | [`MEASURE_TYPE`](#measure_type) | いいえ — デフォルトは`sum` |
| 列に対するフィルター | [`DIMENSION_REPR`](#dimension_repr) | 少なくとも1つ。列ごとに1つ |

各フィルターは、**テーブルの列**と値を指定します。その列がPlaidCloudでディメンションにリンクされている場合、値はノードとなり、フィルターにはディメンションのメイン階層でそのノードに集計されるすべてが含まれます。地理ディメンションにリンクされた**Region**列では、ノード**EMEA**にその下にあるすべての国が含まれます。ディメンションにリンクされていない列では、フィルターは値と完全に一致するものを対象とします。

このページの例では、**Region**列と**Period**列がディメンションにリンクされているテーブルを使用します。ご自身のテーブルの列名を使用してください。

### CELL

`=PLAIDXL.CELL(table, measure, [measure_type], node, [node], ...)`

指定したすべてのノードに該当する行にわたって集計したメジャーを、1つの数値として返します。

```text
A1  =PLAIDXL.REPR.TABLE_REPR("Sales")
A2  =PLAIDXL.REPR.MEASURE("revenue")
A3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
A4  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
A5  =PLAIDXL.REPR.DIMENSION_REPR("Period", "FY2026")
B1  =PLAIDXL.CELL(A1, A2, A3, A4, A5)
```

`B1`には、FY2026におけるEMEAの収益の合計が表示されます。

`CELL`数式だらけのシートでも、再計算は高速です。再計算で同じテーブルから多くの値が要求されると、PlaidXLはセルごとにリクエストを送るのではなく、まとめてPlaidCloudに送信します。値を計算できない場合、セルには`#VALUE!`が表示され、その上にカーソルを合わせると、テーブルに存在しないフィルター列やメンバーのないノードなど、PlaidCloudが報告した理由が表示されます。`CELLS`では、結果全体について最初の理由が表示されます。

### CELLS

`=PLAIDXL.CELLS(table, measures, [measure_type], node, [node], ...)`

`CELL`と同様ですが、複数のメジャーを一度に扱います。メジャーごとに1つの数値を、指定した順序で列方向に返します。

```text
D1:F1  revenue | cost | units
D2     =PLAIDXL.REPR.MEASURES(D1:F1)
B2     =PLAIDXL.CELLS(A1, D2#, A3, A4, A5)
```

`D2#`は、`MEASURES`の展開結果全体を渡します。`B2:B4`には、FY2026におけるEMEAのrevenue、cost、unitsが表示されます。

## 構成要素

これらの関数自体はデータを読み取りません。それぞれが、計算の一部を記述する短いテキストを返し、そのテキストを`CELL`、`CELLS`、`DRILL`に渡します。参照するセルに入力しておくと、たとえば期間を変更するだけで、それを使用するすべての数式が更新されます。

### TABLE_REPR

`=PLAIDXL.REPR.TABLE_REPR(table_name)`

`CELL`と`CELLS`が読み取るテーブル。選択したプロジェクト内での名前で指定します。

### MEASURE

`=PLAIDXL.REPR.MEASURE(column_name)`

`CELL`が集計する数値列。

### MEASURES

`=PLAIDXL.REPR.MEASURES(column_names)`

`CELLS`用の複数のメジャー列。列名を保持するセルの範囲から作成します。結果は列ごとに1セルずつ展開されます。`D2#`のようにスピル演算子を使用して`CELLS`に渡します。

### MEASURE_TYPE

`=PLAIDXL.REPR.MEASURE_TYPE(agg_function)`

メジャーの集計方法。`agg_function`は、次のいずれかを小文字で指定します。

| 値 | 返される値 |
|---|---|
| `sum` | 合計（メジャータイプを渡さない場合のデフォルト） |
| `mean` | 平均 |
| `median` | 中央値 |
| `min` | 最小値 |
| `max` | 最大値 |
| `std` | 標準偏差 |
| `var` | 分散 |

### DIMENSION_REPR

`=PLAIDXL.REPR.DIMENSION_REPR(dimension_name, start_node)`

`CELL`と`CELLS`用のフィルター。フィルターの対象とする列ごとに1つ渡します。

- `dimension_name` — **テーブルの列**の名前。`"Region"`など、ディメンションの値を保持する列です。列名と正確に一致する必要があります。テーブルに存在しない列を指定するとエラーが返されます。
- `start_node` — 集計先のノード（`"EMEA"`など）。ディメンションにリンクされていない列では、一致させる値です。

グリッドを作成するには、ノードにセルを参照します。`=PLAIDXL.REPR.DIMENSION_REPR("Region", $A7)`のように指定します。先頭と末尾のスペースは無視されるため、`DRILL`がレイアウトするインデント付きのノード名を指定できます。

### DRILL_KEY

`=PLAIDXL.REPR.DRILL_KEY(d_key)`

[`DRILL`](#drill)が開始ノードからどこまで下方向に展開するか。`d_key`はプレーンテキストで、単語形式か、記述したドリルキーのいずれかです。

| `d_key` | 展開先 |
|---|---|
| `"all"` | すべての子孫 |
| `"leaves"` | リーフのみ（下に何もないノード） |
| `"1 level"`、`"2 levels"`、… | その世代数だけ下まで |
| `">[...]"` | 次の表のように記述したドリルキー |

数値は数字で記述します。`"two levels"`ではなく`"2 levels"`です。先頭の`drill`は無視されるため、`"drill 2 levels"`も使用できます。

記述したキーは、開始ノードから下方向に世代を数えます。開始ノードは世代0で、常に含まれます。負の数は各ブランチのリーフから上方向に数えるため、不規則な階層でも期待どおりに動作します。

| キー | 含まれるもの |
|---|---|
| `>[*]`または`>[:]` | すべてのノード |
| `>[]`または`>[-1]` | リーフのみ |
| `>[n]` | 開始ノードと、その下の`n`世代。`>[0]`は開始ノードのみです。 |
| `>[a:]` | 開始ノード、続いて世代`a`とその下のすべて |
| `>[a:b]` | 開始ノード、続いて世代`a`から`b - 1`まで |
| `>[0:-k]` | 開始ノードと、その下に少なくとも`k`世代あるすべてのノード。つまり、各ブランチの最後の`k`世代は除外されます。`>[0:-1]`はリーフを除くすべてのノードです。 |
| `>[a:-k]` | 同様ですが、世代`a`から開始します |

階層`A`があり、その子が`B`、`C`、`D`で、`B`には`B1`と`B2`、`C`には`C1`がある場合は、次のようになります。

| キー | 結果 |
|---|---|
| `>[1]` | `A`、`B`、`C`、`D` |
| `>[2]` | `A`、`B`、`B1`、`B2`、`C`、`C1`、`D` |
| `>[]` | `A`、`B1`、`B2`、`C1`、`D` |
| `>[0:-1]` | `A`、`B`、`C` |
| `>[2:]` | `A`、`B1`、`B2`、`C1` |

ノードは階層の順に、それぞれ自身の親の下に一覧表示され、Excelのアウトライングループも同じ順序に従います。キー内のスペースは無視されます。これらの形式のいずれにも一致しないキーを指定すると、有効な形式を一覧表示したエラーが返されます。

<Aside type="caution">
`>[-1]`と`>[0:-1]`は、以前のバージョンのPlaidXLとは意味が異なります。以前は逆の動作でした。現在、`>[-1]`はリーフのみを返し、`>[0:-1]`はリーフを除くすべてを返します。ドリルキーを手書きしたブックは見直してください。単語形式の`"all"`、`"leaves"`、`"2 levels"`は変更されていません。
</Aside>

<Aside type="note">
`CELL`、`CELLS`、`DRILL`は、これらの構成要素の関数の出力を想定しています。各引数は、テキストを自分で入力するのではなく、対応する関数で作成してください。
</Aside>

## 作業ウィンドウから数式を挿入する

作業ウィンドウの**Formulas**タブでは、数式を作成できます。**What do you want in the cell?** という項目で、次のいずれかを選択します。

- **A whole table**（`GET_TABLE`） — テーブルを選択または入力し、必要に応じて最大行数を指定します。
- **One number**（`CELL`） — テーブルを選択または入力し、**Column to total**と**How to combine the values**を選択します。
- **A list of dimension nodes**（`DRILL`） — ディメンションと開始ノードを選択または入力し、**All levels**、**Lowest level only**、または**Down**に続けて**levels**の数を選択し、必要に応じて**代替階層**を指定します。

**Formula**プレビューには、フィールドに入力するにつれて結果が表示されます。**Insert in active cell**をクリックすると選択したセルに挿入され、**コピー**をクリックすると自分で貼り付けられます。**テーブル**タブでテーブルを選択するか、**ディメンション**タブでディメンションを選択すると、対応するフィールドに自動入力されます。
