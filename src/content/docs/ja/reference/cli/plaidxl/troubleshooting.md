## リボンに PlaidCloud タブが表示されない

- すべてのExcelウィンドウを閉じて、Excelを開き直します。新しくインストールしたアドインは、再起動後にしか表示されないことがよくあります。
- **挿入 → 個人用アドイン** を開き、**PlaidCloud** を選択します。
- デスクトップ版のMicrosoft 365のExcel、またはExcel 2021以降を使用していることを確認します。[PlaidXLのインストール](/ja/reference/cli/plaidxl/install/)を参照してください。
- 組織でアドインを管理している場合は、**PlaidCloud** アドインが自分に配布されているかどうかをMicrosoft 365の管理者に確認します。

## サインインのポップアップが開かない

**Sign In** をクリックすると、Excelがポップアップウィンドウを表示してよいか確認します。許可してください。プロンプトを閉じてしまった場合は、もう一度 **Sign In** をクリックします。

ポップアップは開くもののサインインを完了できない場合は、同じメールアドレスでブラウザーからPlaidCloudにサインインしてみてください。パスワードの有効期限切れや、使えなくなった2要素認証デバイスなど、そこで問題がある場合は、まずPlaidCloudで解決する必要があります。[メンバー認証](/ja/administration/access/member-authentication/)を参照してください。

## ワークスペースが一覧に表示されない

**Select a workspace** には、メールアドレスが所属しているワークスペースが一覧表示されます。見つからない場合は、そのワークスペースで使用しているメールアドレスと同じものを入力したことを確認し、ワークスペースの管理者にメンバーであることを確認してもらってください。[ワークスペースメンバーの管理](/ja/administration/access/overview/managing-workspace-members/)を参照してください。

所属している別のワークスペースに移動するには、アカウントメニューを開き、**Switch workspace** を選択します。

## プロジェクト、テーブル、ディメンションが見つからない

PlaidXLには、PlaidCloudでアカウントから見えるものが表示されます。プロジェクトが見つからない場合は、所有者にアクセス権を付与してもらってください。テーブルが見つからない場合は、選択したプロジェクトにそのテーブルが存在し、データがロードされていることを確認してください。一度も書き込まれたことのないテーブルは、選択すると **Unable to get table metadata** と表示されます。

プロジェクト、テーブル、ディメンションの一覧のフォルダーは、折りたたまれた状態で始まります。フォルダー内の項目を探すには、一覧の上部にあるフィルターボックスに名前の一部を入力します。

## テーブルが赤で表示される

テーブルの行数または列数がExcelのワークシートに収まる範囲を超えているか、PlaidCloudがそのサイズを報告できません。取得はでき、収まらない行は後続のシートに続けて配置されますが、複数のシートに分割されたテーブルは保存できません。**高度** を選択して行をフィルターし、不要な列をオフにして、収まるようにしてください。[赤く表示されるテーブル](/ja/reference/cli/plaidxl/retrieve/#赤で表示されるテーブル)を参照してください。

## 取得が遅い

Excelは、幅の広いテーブルで最も遅くなります。不要な列のチェックボックスをオフにし、**高度** で行をフィルターしてください。作業に使うデータだけを取得するほうが高速で、ブックも小さくなります。

大きなテーブルは、Web版のExcelや最新のデスクトップ版Excelでは、はるかに高速に取得および更新されます。古いバージョンのExcelでも動作しますが、高速化の効果はありません。

ペインに **PlaidXL was updated — reload the pane** と表示された場合は、タスクペインを閉じてもう一度開き、再度取得します。PlaidXLが更新されると、ペインは次回の読み込み時に新しいバージョンを取得します。

プルで **This PlaidCloud workspace needs an update for PlaidXL** と表示された場合は、管理者にワークスペースを現行のPlaidCloudリリースに更新するよう依頼してください。

## 数式にエラーが表示される

| 表示内容 | 確認すること |
|---|---|
| `#SPILL!` | 結果に必要なセルに何かが入っています。数式の下または横のセルをクリアしてください。 |
| `#NAME?` | Excelが関数を認識していません。PlaidXLがインストールされていること（リボンに **PlaidCloud** タブがあること）を確認し、スペルを[関数の一覧](/ja/reference/cli/plaidxl/functions/)と照らし合わせてください。 |
| `PLAIDXL` 関数のエラー | サインインしていて、正しいプロジェクトが選択されていることを確認し、テーブル、列、ディメンション、ノードの名前をすべてPlaidCloudと照らし合わせてください。名前は完全に一致している必要があります。 |
| `CELL` がフィルター列が見つからないと報告する | `DIMENSION_REPR` の最初の引数は、ディメンションではなく、テーブルの列です。テーブルの列名を正確に使用してください。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。 |
| `METRIC` または `METRIC_BREAKDOWN` の `#VALUE!` | セルにカーソルを合わせて理由を確認します。[メトリックのエラー](/ja/reference/cli/plaidxl/functions/#メトリックのエラー)を参照してください。 |
| メトリックの `#VALUE!`: **This PlaidCloud workspace can't combine an alternate hierarchy with other members yet. Ask your administrator to update the workspace.** | メトリックで代替階層のメンバーと他のメンバーを組み合わせるには、ワークスペースの更新が必要です。管理者に依頼してください。同じ再計算の他のセルは、引き続き結果を返します。 |
| `CELL` または `CELLS` の `#VALUE!` | セルにカーソルを合わせて、PlaidCloudが示した理由を確認します。たとえば、不明な列、存在しない、またはメンバーのないノード、値の計算上の問題などです。名前をPlaidCloudと照らし合わせてください。 |
| `CELL` が想定外の合計を返す | ノードは、ディメンションにリンクされた列でのみロールアップされます。それ以外の列では、値と完全に一致する必要があります。各フィルターの列とノードを確認してください。 |
| データやプロジェクトを変更しても値が変わらない | リボンの **更新** メニューで **Recalculate PlaidXL formulas** をクリックします。 |
| `MEASURE_TYPE` がエラーを返す | `sum`、`mean`、`median`、`min`、`max`、`std`、`var` のいずれかを、小文字で使用します。 |

## 数式が別のプロジェクトのデータを返す

PlaidXLの関数は、ブックにリンクされたプロジェクトから読み取ります。そのブックでタスクペインを開き、レポートの作成対象のプロジェクトを選択してから、リボンの **更新** メニューで **Recalculate PlaidXL formulas** をクリックします。プロジェクトはブックごとに独立しているため、別のブックで選択しても、このブックは変わりません。[プロジェクトはブックに属する](/ja/reference/cli/plaidxl/retrieve/#プロジェクトはワークブックに属する)を参照してください。

## 別のワークスペースのテーブルがスキップされる

ワークスペースを切り替えた後、**Refresh All Tables** は、このブック内の別のワークスペースのテーブルまたはディメンションが更新されなかったことを知らせ、それらは **On this sheet** にも一覧表示されません。現在のワークスペースでそれぞれのテーブルを再度取得すると、リンクされます。

## 入力した値が書き込まれない

`CELL` の上から入力すると、タスクペインには書き込んだ内容と、書き込まなかったものが理由とともに一覧表示されます。[PlaidCloudへの値の入力](/ja/reference/cli/plaidxl/write-values/)を参照してください。

| 表示内容 | 対応 |
|---|---|
| `PLAIDXL.CELL` を1つだけ含むセルにのみ、入力した値が反映される | 数式が単一の `CELL`（乗算、除算、符号反転を含んでもかまいません）であるセルの上から入力してください。 |
| 引数をここでは読み取れない | `CELL` の引数は、セルまたはテキストである必要があり、ほかの計算式は使えません。 |
| 配分方法、形状、固定は合計にのみ適用される | `E1200`、`1200 like FY2025`、`H` などのコードは、**合計** のセルでのみ機能します。それ以外では、通常の数値を入力してください。 |
| すべてのメンバーが固定されている | `H` で固定を解除してから、もう一度値を入力してください。 |
| ワークスペースがExcelで入力した値にまだ対応していない | 管理者にワークスペースの更新を依頼してください。 |

## 保存が拒否または中断される

保存はすぐに書き込まれ、停止することはまれです。次の場合は停止します。

| 表示内容 | 対応 |
|---|---|
| ヘッダー行が取得した列と一致しなくなった | ヘッダーを取得時の状態に戻すか、テーブルを再度取得してください。 |
| 値を変換できない | 何も書き込まれず、行が一覧表示されます。列のデータ型に合うように値を修正してください。 |
| テーブルが他のシートに続いている | 複数のシートに分割されたテーブルは保存できません。1つのシートに収まるように、フィルター付きで取得してください。 |
| 保存で対応できないフィルターで取得されたテーブル | **AND** で結んだ **等しい** と **in** のルールのフィルターで、またはフィルターなしで、再度取得してください。 |
| 行がアクセス権の範囲外にある | 何も保存されません。その行を削除してから、もう一度保存してください。 |
| 列にExcelのセルの上限である32,767文字を超えるテキストがある | Excelではテキストが途中で切れて表示され、保存するとPlaidCloud側でも切り詰められるため、このテーブルでは保存がオフになります。その列を除いてテーブルを取得すると、保存できます。 |
| テーブルが部分的にしか書き込まれなかった | Excelが直前の更新の一部を拒否しました。テーブルを更新してから、保存してください。 |
| シートがテーブルにリンクされていない | 先にそのシートにテーブルを取得してください。**On this sheet** に一覧表示されるのは、アクティブなシートに取得したテーブルだけです。 |

保存を取り消すには、メッセージの **元に戻す** をクリックするか、リボンの **Undo last write** をクリックします。保存ごとに独自の復元ポイントが7日間保持されるため、保存から7日間は、どの保存でも取り消せます。[テーブルのPlaidCloudへの保存](/ja/reference/cli/plaidxl/retrieve/#テーブルを-plaidcloud-に保存する)を参照してください。
