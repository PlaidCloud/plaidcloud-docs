## PlaidCloudタブがリボンに表示されない

- すべてのExcelウィンドウを閉じて、Excelを開き直します。新しくインストールしたアドインは、再起動後にのみ表示されることがよくあります。
- **Insert → My Add-ins**を開き、**PlaidCloud**を選択します。
- デスクトップ版のMicrosoft 365版Excel、またはExcel 2021以降を使用していることを確認します。[PlaidXLのインストール](/ja/reference/cli/plaidxl/install/)を参照してください。
- 組織でアドインを管理している場合は、**PlaidCloud**アドインが自分に配布されているかどうかをMicrosoft 365管理者に確認します。

## サインインのポップアップが開かない

**サインイン**をクリックすると、Excelからポップアップウィンドウを表示してよいか確認されます。許可してください。確認を閉じてしまった場合は、もう一度**サインイン**をクリックします。

ポップアップは開くもののサインインを完了できない場合は、同じメールアドレスでブラウザーからPlaidCloudにサインインしてみてください。そこで問題がある場合（パスワードの期限切れや、使えなくなった2要素認証のデバイスなど）は、先にPlaidCloudで解決する必要があります。[メンバー認証](/ja/administration/access/member-authentication/)を参照してください。

## ワークスペースが一覧に表示されない

**Select a workspace**には、メールアドレスが属しているワークスペースが一覧表示されます。ワークスペースが表示されない場合は、そのワークスペースで使用しているメールアドレスと同じものを入力したことを確認し、ワークスペースの管理者にメンバーであることを確認してもらってください。[ワークスペースメンバーの管理](/ja/administration/access/overview/managing-workspace-members/)を参照してください。

所属している別のワークスペースに移動するには、アカウントメニューを開き、**Switch workspace**を選択します。

## プロジェクト、テーブル、ディメンションが見つからない

PlaidXLには、アカウントがPlaidCloudで表示できる内容が表示されます。プロジェクトが見つからない場合は、そのオーナーにアクセス権を依頼してください。テーブルが見つからない場合は、選択したプロジェクトにそのテーブルが存在し、データが読み込まれていることを確認してください。一度も書き込まれたことのないテーブルを選択すると、**Unable to get table metadata**と表示されます。

プロジェクト、テーブル、ディメンションの各一覧では、フォルダーは折りたたまれた状態で始まります。フォルダー内の項目を探すには、一覧の上部にあるフィルターボックスに名前の一部を入力します。

## テーブルが赤で表示される

テーブルの行数または列数が、Excelのワークシートに収まる上限を超えています。収まるまで、**高度**を選択して行をフィルターし、不要な列をオフにします。[赤で表示されるテーブル](/ja/reference/cli/plaidxl/retrieve/#赤で表示されるテーブル)を参照してください。

## 取得が遅い

Excelは、幅の広いテーブルで最も遅くなります。不要な列のチェックボックスをオフにし、**高度**で行をフィルターしてください。作業に使用するデータだけを取得すると、処理が速くなり、ブックも小さくなります。

## 数式にエラーが表示される

| 表示される内容 | 確認すること |
|---|---|
| `#SPILL!` | 結果に必要なセルに何かが入っています。数式の下または横のセルをクリアしてください。 |
| `#NAME?` | Excelが関数を認識していません。PlaidXLがインストールされていること（リボンに**PlaidCloud**タブがあること）を確認し、[関数の一覧](/ja/reference/cli/plaidxl/functions/)と照らし合わせてスペルを確認してください。 |
| `PLAIDXL`関数からのエラー | サインインしていて、正しいプロジェクトが選択されていることを確認し、続いて、すべてのテーブル、列、ディメンション、ノードの名前をPlaidCloudと照らし合わせて確認してください。名前は正確に一致している必要があります。 |
| `CELL`がフィルター列が見つからないと報告する | `DIMENSION_REPR`の最初の引数は、ディメンションではなく、テーブルの列です。テーブルの列名を正確に使用してください。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。 |
| `CELL`または`CELLS`が`#VALUE!`を返す | セルにカーソルを合わせて、PlaidCloudが示した理由を確認してください。不明な列、存在しない、またはメンバーのないノード、値の計算での問題などがあります。名前をPlaidCloudと照らし合わせて確認してください。 |
| `CELL`が想定外の合計を返す | ノードが集計されるのは、そのディメンションにリンクされた列に対してのみです。それ以外の列では、値と完全に一致する必要があります。各フィルターの列とノードを確認してください。 |
| データやプロジェクトを変更しても値が変わらない | 完全な再計算を強制します。Windowsでは**Ctrl+Alt+F9**です。 |
| `MEASURE_TYPE`がエラーを返す | `sum`、`mean`、`median`、`min`、`max`、`std`、`var`のいずれかを、小文字で使用してください。 |

## 数式が別のプロジェクトのデータを返す

PlaidXL関数は、ブックにリンクされているプロジェクトから読み取ります。そのブックで作業ウィンドウを開き、レポートの作成対象のプロジェクトを選択してから、完全な再計算を強制してください。各ブックには独自のプロジェクトがあるため、別のブックでプロジェクトを選択しても、このブックには影響しません。[プロジェクトはブックに属する](/ja/reference/cli/plaidxl/retrieve/#プロジェクトはブックに属する)を参照してください。

## 別のワークスペースのテーブルがスキップされる

ワークスペースを切り替えた後、作業ウィンドウには、追跡対象のテーブルのうち、別のワークスペースに属していて**Refresh All Tables**でスキップされるものの件数が表示されます。リンクするには、現在のワークスペースで各テーブルをもう一度取得してください。

## 保存が拒否または停止される

| 表示される内容 | 対応 |
|---|---|
| テーブル内に空の行がある | その下にデータがあるのに空行が2行以上連続していると、保存が停止します。空の行を削除するか入力してから、もう一度保存してください。 |
| 取得後にテーブルが変更された | 他のユーザーがPlaidCloudでテーブルを保存しました。もう一度取得して、編集内容を再適用してください。 |
| 値を変換できない | 何も書き込まれず、該当する行が一覧表示されます。列のデータ型に合わせて値を修正してください。 |
| シートがテーブルにリンクされていない | 先にシートにテーブルを取得してください。**Save to PlaidCloud…** ボタンは、アクティブなシートに取得したテーブルに対してのみ表示されます。 |

保存を元に戻すには、確認メッセージの**Restore previous version**をクリックするか、PlaidCloudでテーブルを開き、**As of**メニューで保存前のバージョンを選択します。復元ポイントは7日間保持されます。[テーブルをPlaidCloudに保存する](/ja/reference/cli/plaidxl/retrieve/#テーブルをplaidcloudに保存する)を参照してください。
