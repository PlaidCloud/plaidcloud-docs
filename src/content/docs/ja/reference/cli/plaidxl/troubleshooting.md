## リボンにPlaidCloudタブが表示されない

- すべてのExcelウィンドウを閉じて、Excelを再起動します。新しくインストールしたアドインは、再起動後に初めて表示されることがよくあります。
- **Insert → My Add-ins**を開いて、**PlaidCloud**を選択します。
- デスクトップ版のMicrosoft 365版Excel、またはExcel 2021以降を使用していることを確認します。[PlaidXLのインストール](/ja/reference/cli/plaidxl/install/)を参照してください。
- 組織でアドインを管理している場合は、**PlaidCloud**アドインが自分に展開されているかどうかをMicrosoft 365の管理者に確認してください。

## サインインのポップアップが開かない

**サインイン**をクリックすると、Excelがポップアップウィンドウを表示するかどうかを確認します。許可してください。プロンプトを閉じてしまった場合は、もう一度**サインイン**をクリックします。

ポップアップは開くものの、サインインを完了できない場合は、同じメールアドレスでブラウザーからPlaidCloudにサインインしてみてください。そこで問題がある場合（パスワードの期限切れや、使えなくなった2要素認証デバイスなど）は、まずPlaidCloudで解決する必要があります。[メンバー認証](/ja/administration/access/member-authentication/)を参照してください。

## ワークスペースが一覧に表示されない

**Select a tenant**には、メールアドレスが属しているワークスペースが一覧表示されます。表示されないものがある場合は、そのワークスペースで使用しているメールアドレスと同じものを入力したことを確認してから、ワークスペースの管理者にメンバーであることを確認してもらってください。[ワークスペースメンバーの管理](/ja/administration/access/overview/managing-workspace-members/)を参照してください。

所属している別のワークスペースに移動するには、**Logout**をクリックして、もう一度サインインします。

## プロジェクト、テーブル、ディメンションが見つからない

PlaidXLには、アカウントがPlaidCloudで表示できるものが表示されます。プロジェクトが見つからない場合は、所有者にアクセスを依頼してください。テーブルが見つからない場合は、選択したプロジェクトにそのテーブルが存在し、データが読み込まれていることを確認してください。一度も書き込まれていないテーブルは、選択すると**Unable to get table metadata**と表示されます。

プロジェクト、テーブル、ディメンションの一覧にあるフォルダーは、折りたたまれた状態で始まります。フォルダー内の項目を探すには、一覧の上部にあるフィルターボックスに名前の一部を入力します。

## テーブルが赤で表示される

テーブルの行数または列数が、Excelのワークシートに収まる上限を超えています。収まるまで、**高度**を選択して行をフィルターし、不要な列をオフにします。[赤で表示されるテーブル](/ja/reference/cli/plaidxl/retrieve/#赤で表示されるテーブル)を参照してください。

## 取得が遅い

Excelは、列数の多いテーブルの処理が最も遅くなります。不要な列のチェックボックスをオフにし、**高度**で行をフィルターします。作業に使用するデータだけを取得すると、速くなり、ブックも小さくなります。

## 数式にエラーが表示される

| 表示される内容 | 確認すること |
|---|---|
| `#SPILL!` | 結果に必要なセルに何かが入力されています。数式の下または横のセルをクリアしてください。 |
| `#NAME?` | Excelが関数を認識していません。PlaidXLがインストールされていること（リボンに**PlaidCloud**タブがあること）を確認し、[関数の一覧](/ja/reference/cli/plaidxl/functions/)でスペルを確認してください。 |
| `PLAIDXL`関数からのエラー | サインインしていて、正しいプロジェクトが選択されていることを確認してから、すべてのテーブル名、列名、ディメンション名、ノード名をPlaidCloudと照合してください。名前は完全に一致する必要があります。 |
| `CELL`がフィルター列が見つからないと報告する | `DIMENSION_REPR`の最初の引数は、ディメンションではなく、テーブルの列です。テーブルの列名を正確に使用してください。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。 |
| `CELL`が0または予期しない合計を返す | ノード名をディメンションと照合してください。存在しないノードは何も集計せず、0を返します。ノードが集計されるのは、そのディメンションにリンクされた列のみです。それ以外の列では、値と完全に一致する必要があります。 |
| データやプロジェクトを変更しても値が変わらない | 完全な再計算を強制します。Windowsでは**Ctrl+Alt+F9**です。 |
| `MEASURE_TYPE`がエラーを返す | `sum`、`mean`、`median`、`min`、`max`、`std`、`var`のいずれかを小文字で使用します。 |

## 数式が別のプロジェクトのデータを返す

PlaidXL関数は、タスクペインで選択したプロジェクトから読み取り、その選択は開いているすべてのブックで共有されます。レポートの作成対象のプロジェクトを選択してから、完全な再計算を強制してください。**デフォルトに設定**を使用すると、プロジェクトがブックに保存され、そのブックでタスクペインを開いたときに選択された状態になります。[デフォルトのプロジェクトを設定する](/ja/reference/cli/plaidxl/retrieve/#デフォルトのプロジェクトを設定する)を参照してください。
