## PlaidCloudタブがリボンに表示されない

- すべてのExcelウィンドウを閉じて、Excelを開き直します。新しくインストールしたアドインは、再起動後にしか表示されないことがよくあります。
- **挿入 → マイ アドイン** を開き、**PlaidCloud** を選択します。
- デスクトップ版のMicrosoft 365用Excel、またはExcel 2021以降を使用していることを確認します。[PlaidXLのインストール](/ja/reference/cli/plaidxl/install/)を参照してください。
- 組織でアドインを管理している場合は、**PlaidCloud** アドインが自分に配布されているかどうかを、Microsoft 365の管理者に確認してください。

## サインインのポップアップが開かない

**Sign In** をクリックすると、Excelがポップアップウィンドウを表示するかどうかを尋ねます。許可してください。プロンプトを閉じてしまった場合は、もう一度 **Sign In** をクリックします。

ポップアップは開くものの、サインインを完了できない場合は、同じメールアドレスでブラウザーからPlaidCloudにサインインしてみてください。パスワードの有効期限切れや、使えなくなった2要素認証デバイスなど、そこで問題が発生している場合は、先にPlaidCloudで解決する必要があります。[メンバー認証](/ja/administration/access/member-authentication/)を参照してください。

## ワークスペースが一覧に表示されない

**Select a workspace** には、メールアドレスが所属しているワークスペースが一覧表示されます。表示されていないものがある場合は、そのワークスペースで使用しているメールアドレスと同じものを入力したかどうかを確認し、ワークスペースの管理者にメンバーであることを確認してもらってください。[ワークスペースメンバーの管理](/ja/administration/access/overview/managing-workspace-members/)を参照してください。

所属している別のワークスペースに移動するには、アカウントメニューを開き、**Switch workspace** を選択します。

## プロジェクト、テーブル、ディメンションが表示されない

PlaidXLには、PlaidCloudでアカウントから見えるものが表示されます。プロジェクトが表示されない場合は、そのオーナーにアクセスを依頼してください。テーブルが表示されない場合は、選択したプロジェクトにそのテーブルが存在し、データが読み込まれているかどうかを確認してください。一度も書き込まれていないテーブルを選択すると、**Unable to get table metadata** と表示されます。

プロジェクト、テーブル、ディメンションの一覧のフォルダーは、折りたたまれた状態で始まります。フォルダー内の項目を探すには、一覧の上部にあるフィルターボックスに名前の一部を入力します。

## テーブルが赤で表示される

テーブルの行数または列数がExcelのワークシートに収まる数を超えているか、PlaidCloudがそのサイズを報告できません。取得はでき、収まらない行は後続のシートに続きますが、複数のシートに分割されたテーブルは保存できません。収まるまで、**高度** を選択して行をフィルターし、不要な列をオフにしてください。[赤で表示されるテーブル](/ja/reference/cli/plaidxl/retrieve/#赤で表示されるテーブル)を参照してください。

## 取得が遅い

Excelは、幅の広いテーブルで最も遅くなります。不要な列のチェックボックスをオフにし、**高度** で行をフィルターしてください。作業に使うデータだけを取得すると、速くなり、ブックも小さくなります。

## 数式にエラーが表示される

| 表示内容 | 確認事項 |
|---|---|
| `#SPILL!` | 結果に必要なセルに何かが入力されています。数式の下または横のセルをクリアしてください。 |
| `#NAME?` | Excelが関数を認識していません。PlaidXLがインストールされていること（リボンに **PlaidCloud** タブがあること）を確認し、[関数の一覧](/ja/reference/cli/plaidxl/functions/)でスペルを確認してください。 |
| `PLAIDXL` 関数からのエラー | サインインしていて、正しいプロジェクトが選択されていることを確認し、テーブル、列、ディメンション、ノードの名前をすべてPlaidCloudと照合してください。名前は完全に一致する必要があります。 |
| `CELL` がフィルター列が見つからないと報告する | `DIMENSION_REPR` の最初の引数は、ディメンションではなく、テーブルの列です。テーブルの列名を正確に指定してください。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。 |
| `METRIC` または `METRIC_BREAKDOWN` からの `#VALUE!` | セルにカーソルを置いて、理由を確認してください。[メトリックのエラー](/ja/reference/cli/plaidxl/functions/#メトリックのエラー)を参照してください。 |
| `CELL` または `CELLS` からの `#VALUE!` | セルにカーソルを置いて、PlaidCloudが示した理由（不明な列、存在しない、またはメンバーのないノード、値の計算上の問題など）を確認してください。名前をPlaidCloudと照合してください。 |
| `CELL` が想定外の合計を返す | ノードが集計されるのは、そのディメンションにリンクされた列だけです。それ以外の列では、値と完全に一致する必要があります。各フィルターの列とノードを確認してください。 |
| データやプロジェクトを変更しても値が変わらない | リボンの **更新** メニューで **Recalculate PlaidXL formulas** をクリックします。 |
| `MEASURE_TYPE` がエラーを返す | `sum`、`mean`、`median`、`min`、`max`、`std`、`var` のいずれかを、小文字で指定してください。 |

## 数式が別のプロジェクトのデータを返す

PlaidXL関数は、ブックにリンクされたプロジェクトから読み取ります。そのブックでタスクペインを開き、レポートを作成したプロジェクトを選択してから、リボンの **更新** メニューで **Recalculate PlaidXL formulas** をクリックします。プロジェクトはブックごとに設定されるため、別のブックで選択しても、このブックは変わりません。[プロジェクトはブックに属する](/ja/reference/cli/plaidxl/retrieve/#プロジェクトはブックに属する)を参照してください。

## 別のワークスペースのテーブルがスキップされる

ワークスペースを切り替えた後、**Refresh All Tables** は、このブックにある別のワークスペースのテーブルまたはディメンションが更新されなかったことを知らせます。それらは **On this sheet** にも一覧表示されません。現在のワークスペースで各テーブルをもう一度取得すると、リンクされます。

## 入力した値が書き込まれない

`CELL` の上に入力すると、タスクペインが書き込んだ内容を表示し、書き込まなかったものがあれば、その理由とともに一覧表示します。[PlaidCloudに値を入力する](/ja/reference/cli/plaidxl/write-values/)を参照してください。

| 表示内容 | 対応 |
|---|---|
| 1つの `PLAIDXL.CELL` だけを含むセルだけが、入力した値を受け付ける | 数式が単一の `CELL`（乗算、除算、符号反転は可）であるセルの上に入力してください。 |
| 引数をここでは読み取れない | `CELL` の引数は、他の計算ではなく、セルまたはテキストである必要があります。 |
| 分散方法、形状、保持は合計にのみ適用される | `E1200`、`1200 like FY2025`、`H` などのコードは、**sum** のセルでのみ使用できます。それ以外では、通常の数値を入力してください。 |
| すべてのメンバーが保持されている | `H` で保持を解除してから、もう一度値を入力してください。 |
| ワークスペースがExcelで入力した値にまだ対応していない | 管理者にワークスペースの更新を依頼してください。 |

## 保存が拒否される、または停止する

保存はすぐに書き込まれ、停止することはまれです。次の場合は停止します。

| 表示内容 | 対応 |
|---|---|
| ヘッダー行が、取得した列と一致しなくなっている | ヘッダーを取得したときの状態に戻すか、テーブルをもう一度取得してください。 |
| 値を変換できない | 何も書き込まれず、行が一覧表示されます。列のデータ型に合うように値を修正してください。 |
| テーブルが他のシートに続いている | 複数のシートに分割されたテーブルは保存できません。1つのシートに収まるように、フィルターを付けて取得してください。 |
| 保存で維持できないフィルターでテーブルが取得された | **AND** で結合した **等しい** と **次のいずれか** のルールのフィルターで、またはフィルターなしで、もう一度取得してください。 |
| 行がご自身の行アクセスの範囲外にある | 何も保存されません。それらの行を削除するか、プロジェクトのアーキテクトに保存を依頼してください。 |
| シートがテーブルにリンクされていない | 先にそのシートにテーブルを取得してください。**On this sheet** に一覧表示されるのは、アクティブなシートに取得したテーブルだけです。 |

保存を元に戻すには、メッセージの **元に戻す** をクリックするか、リボンの **Undo last write** をクリックします。復元ポイントは7日間保持されます。[テーブルをPlaidCloudに保存する](/ja/reference/cli/plaidxl/retrieve/#テーブルをplaidcloudに保存する)を参照してください。
