## PlaidCloud タブがリボンに表示されない

- すべての Excel ウィンドウを閉じて、Excel を開き直します。新しくインストールしたアドインは、再起動後にのみ表示されることがよくあります。
- **挿入 → 個人用アドイン** を開き、**PlaidCloud** を選択します。
- Microsoft 365 のデスクトップ版 Excel、または Excel 2021 以降を使用していることを確認します。[PlaidXL をインストールする](/ja/reference/cli/plaidxl/install/)を参照してください。
- 組織でアドインを管理している場合は、**PlaidCloud** アドインがご自身に展開されているかどうかを、Microsoft 365 の管理者に確認します。

## サインインのポップアップが開かない

**Sign In** をクリックすると、Excel からポップアップウィンドウを表示するかどうかを確認されます。許可してください。プロンプトを閉じてしまった場合は、もう一度 **Sign In** をクリックします。

ポップアップは開くもののサインインを完了できない場合は、同じメールアドレスでブラウザーから PlaidCloud にサインインしてみてください。パスワードの有効期限切れや、使えなくなった二要素認証デバイスなど、そこでの問題は、先に PlaidCloud で解決する必要があります。[メンバー認証](/ja/administration/access/member-authentication/)を参照してください。

## ワークスペースが一覧に表示されない

**Select a workspace** には、お使いのメールアドレスが所属するワークスペースが一覧表示されます。ワークスペースが表示されない場合は、そのワークスペースで使用しているメールアドレスと同じものを入力したことを確認し、ワークスペース管理者にメンバーであることを確認してもらってください。[ワークスペースメンバーの管理](/ja/administration/access/overview/managing-workspace-members/)を参照してください。

所属している別のワークスペースに移動するには、アカウントメニューを開き、**Switch workspace** を選択します。

## プロジェクト、テーブル、ディメンションが表示されない

PlaidXL には、お使いのアカウントが PlaidCloud で参照できるものが表示されます。プロジェクトが表示されない場合は、所有者にアクセス権の付与を依頼してください。テーブルが表示されない場合は、選択したプロジェクトにそのテーブルが存在し、データが読み込まれていることを確認してください。一度も書き込まれたことのないテーブルは、選択すると **Unable to get table metadata** と表示されます。

プロジェクト、テーブル、ディメンションの一覧にあるフォルダーは、最初は折りたたまれています。フォルダー内の項目を探すには、一覧の上部にあるフィルターボックスに名前の一部を入力します。

## テーブルが赤で表示される

テーブルの行数または列数が、Excel のワークシートに収まる上限を超えています。収まるまで、**Advanced** を選択して行をフィルターし、不要な列をオフにしてください。[赤で表示されるテーブル](/ja/reference/cli/plaidxl/retrieve/#赤で表示されるテーブル)を参照してください。

## 取得が遅い

Excel は、幅の広いテーブルで最も遅くなります。不要な列のチェックボックスをオフにし、**Advanced** で行をフィルターしてください。作業に使うデータだけを取得すると、処理が速くなり、ブックのサイズも小さくなります。

## 数式にエラーが表示される

| 表示される内容 | 確認事項 |
|---|---|
| `#SPILL!` | 結果に必要なセルに何かが入力されています。数式の下または横のセルを消去してください。 |
| `#NAME?` | Excel が関数を認識していません。PlaidXL がインストールされていること（リボンに **PlaidCloud** タブがあること）を確認し、[関数の一覧](/ja/reference/cli/plaidxl/functions/)でスペルを確認してください。 |
| `PLAIDXL` 関数のエラー | サインインしていて、正しいプロジェクトが選択されていることを確認してから、テーブル、列、ディメンション、ノードのすべての名前を PlaidCloud と照合してください。名前は完全に一致している必要があります。 |
| `CELL` がフィルター列が見つからないと報告する | `DIMENSION_REPR` の最初の引数は、ディメンションではなく、テーブルの列です。テーブルの列名を正確に指定してください。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。 |
| `CELL` または `CELLS` で `#VALUE!` が表示される | セルにマウスポインターを置いて、PlaidCloud が示した理由を確認してください。不明な列、存在しない、またはメンバーのないノード、値の計算時の問題などがあります。名前を PlaidCloud と照合してください。 |
| `CELL` が想定外の合計を返す | ノードが集約されるのは、そのディメンションにリンクされた列だけです。それ以外の列では、値と完全に一致する必要があります。各フィルターの列とノードを確認してください。 |
| データやプロジェクトを変更しても値が変わらない | 完全再計算を実行します。Windows では **Ctrl+Alt+F9** を押します。 |
| `MEASURE_TYPE` がエラーを返す | `sum`、`mean`、`median`、`min`、`max`、`std`、`var` のいずれかを、小文字で使用してください。 |

## 数式が別のプロジェクトのデータを返す

PlaidXL の関数は、ブックにリンクされているプロジェクトから読み取ります。そのブックでタスクペインを開き、レポートの作成対象のプロジェクトを選択してから、完全再計算を実行してください。プロジェクトはブックごとに設定されるため、別のブックで選択しても、このブックは変わりません。[プロジェクトはブックに属します](/ja/reference/cli/plaidxl/retrieve/#プロジェクトはブックに属します)を参照してください。

## 別のワークスペースのテーブルがスキップされる

ワークスペースを切り替えた後、タスクペインには、別のワークスペースに属していて **Refresh All Tables** でスキップされる追跡対象のテーブルの数が表示されます。リンクするには、現在のワークスペースで各テーブルをもう一度取得してください。

## 保存が拒否または中止される

| 表示される内容 | 対応 |
|---|---|
| テーブル内に空の行がある | 1 行だけの空の行はスキップされます。空の行が 2 行以上続き、その下にデータがある場合は、保存が中止されます。空の行を削除するか入力してから、もう一度保存してください。 |
| 取得した後にテーブルが変更された | 別のユーザーが PlaidCloud でテーブルを保存しました。もう一度取得して、編集内容を再適用してください。（PlaidCloud がこれを確認できるのは一部のテーブルタイプのみです。確認できない場合は、他のユーザーの変更が上書きされることが確認内容で警告されます。） |
| 値を変換できない | 何も書き込まれず、該当する行が一覧表示されます。列のデータ型に合うように値を修正してください。 |
| シートがテーブルにリンクされていない | 先にシートにテーブルを取得してください。**Save to PlaidCloud…** ボタンが表示されるのは、アクティブなシートに取得したテーブルのみです。 |

保存を元に戻すには、確認メッセージの **Restore previous version** をクリックするか、PlaidCloud でテーブルを開き、**As of** メニューで保存前のバージョンを選択します。復元ポイントは 7 日間保持されます。[テーブルを PlaidCloud に保存する](/ja/reference/cli/plaidxl/retrieve/#テーブルを-plaidcloud-に保存する)を参照してください。
