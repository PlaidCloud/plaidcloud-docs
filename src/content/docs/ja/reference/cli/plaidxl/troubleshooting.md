## リボンに PlaidCloud タブが表示されない

- すべての Excel ウィンドウを閉じて、Excel を再起動します。新しくインストールしたアドインは、再起動後にのみ表示されることがよくあります。
- **Insert → My Add-ins**を開き、**PlaidCloud**を選択します。
- デスクトップ版の Microsoft 365 の Excel、または Excel 2021 以降を使用していることを確認します。[PlaidXL をインストールする](/ja/reference/cli/plaidxl/install/)を参照してください。
- 組織でアドインを管理している場合は、**PlaidCloud**アドインが自分に配布されているかどうかを Microsoft 365 の管理者に確認します。

## サインインのポップアップが開かない

**サインイン**をクリックすると、Excel がポップアップウィンドウを表示するかどうかを確認します。許可してください。プロンプトを閉じてしまった場合は、もう一度**サインイン**をクリックします。

ポップアップは開くがサインインを完了できない場合は、ブラウザーで同じメールアドレスを使って PlaidCloud にサインインしてみてください。パスワードの期限切れや、使用できなくなった二要素認証デバイスなど、そちらに問題がある場合は、先に PlaidCloud で解決する必要があります。[メンバー認証](/ja/administration/access/member-authentication/)を参照してください。

## ワークスペースが一覧に表示されない

**Select a workspace**には、メールアドレスが属しているワークスペースが一覧表示されます。見つからない場合は、そのワークスペースで使用しているメールアドレスを入力したことを確認し、ワークスペースの管理者にメンバーであることを確認してもらってください。[ワークスペースメンバーの管理](/ja/administration/access/overview/managing-workspace-members/)を参照してください。

所属している別のワークスペースに移動するには、アカウントメニューを開き、**Switch workspace**を選択します。

## プロジェクト、テーブル、ディメンションが見つからない

PlaidXL には、アカウントが PlaidCloud で閲覧できるものが表示されます。プロジェクトが見つからない場合は、そのオーナーにアクセス権を依頼してください。テーブルが見つからない場合は、選択したプロジェクトにそのテーブルが存在し、データが読み込まれていることを確認してください。一度も書き込まれていないテーブルを選択すると、**Unable to get table metadata**と表示されます。

プロジェクト、テーブル、ディメンションの一覧のフォルダーは、折りたたまれた状態で始まります。フォルダー内の項目を探すには、一覧の上部にあるフィルターボックスに名前の一部を入力します。

## テーブルが赤で表示される

テーブルの行数または列数が Excel ワークシートの上限を超えているか、PlaidCloud がサイズを報告できない状態です。取得は可能で、収まらない行は後続のシートに続きますが、複数のシートに分割されたテーブルは保存できません。**高度**を選択して行を絞り込み、不要な列をオフにして、収まるようにしてください。[赤で表示されるテーブル](/ja/reference/cli/plaidxl/retrieve/#赤で表示されるテーブル)を参照してください。

## 取得が遅い

Excel は、幅の広いテーブルで最も遅くなります。不要な列のチェックボックスをオフにし、**高度**で行を絞り込んでください。作業に使用するデータだけを取得すると、高速になり、ワークブックも小さくなります。

## 数式にエラーが表示される

| 表示される内容 | 確認すること |
|---|---|
| `#SPILL!` | 結果に必要なセルに何かが入っています。数式の下または横のセルをクリアしてください。 |
| `#NAME?` | Excel が関数を認識していません。PlaidXL がインストールされていること（リボンに**PlaidCloud**タブがあること）を確認し、[関数の一覧](/ja/reference/cli/plaidxl/functions/)でスペルを確認してください。 |
| `PLAIDXL` 関数のエラー | サインインしていて、正しいプロジェクトが選択されていることを確認し、テーブル、列、ディメンション、ノードのすべての名前を PlaidCloud と照合してください。名前は正確に一致する必要があります。 |
| `CELL` がフィルター列が見つからないと報告する | `DIMENSION_REPR` の最初の引数は、ディメンションではなくテーブルの列です。テーブルの列名を正確に使用してください。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。 |
| `METRIC` または `METRIC_BREAKDOWN` の `#VALUE!` | セルにカーソルを置いて理由を確認してください。[メトリックのエラー](/ja/reference/cli/plaidxl/functions/#メトリックのエラー)を参照してください。 |
| メトリックの `#VALUE!`: **この PlaidCloud ワークスペースでは、代替階層を他のメンバーと組み合わせることはまだできません。管理者にワークスペースの更新を依頼してください。** | メトリックが代替階層のメンバーを他のメンバーと組み合わせるには、ワークスペースの更新が必要です。管理者に依頼してください。同じ再計算内の他のセルは引き続き値を返します。 |
| `CELL` または `CELLS` の `#VALUE!` | セルにカーソルを置いて、PlaidCloud が示した理由を確認してください。たとえば、不明な列、存在しない、またはメンバーのないノード、値の計算上の問題などです。名前を PlaidCloud と照合してください。 |
| `CELL` が想定外の合計を返す | ノードが集計されるのは、そのディメンションにリンクされた列に限られます。それ以外の列では、値と正確に一致する必要があります。各フィルターの列とノードを確認してください。 |
| データやプロジェクトを変更しても値が変わらない | リボンの**更新**メニューで**Recalculate PlaidXL formulas**をクリックします。 |
| `MEASURE_TYPE` がエラーを返す | `sum`、`mean`、`median`、`min`、`max`、`std`、`var` のいずれかを小文字で使用してください。 |

## 数式が別のプロジェクトのデータを返す

PlaidXL 関数は、ワークブックにリンクされているプロジェクトから読み取ります。そのワークブックでタスクペインを開き、レポートの作成対象のプロジェクトを選択して、リボンの**更新**メニューで**Recalculate PlaidXL formulas**をクリックします。ワークブックごとに独自のプロジェクトがあるため、別のワークブックでプロジェクトを選択しても、このワークブックは変わりません。[プロジェクトはワークブックに属する](/ja/reference/cli/plaidxl/retrieve/#プロジェクトはワークブックに属する)を参照してください。

## 別のワークスペースのテーブルがスキップされる

ワークスペースを切り替えた後、**Refresh All Tables**に、このワークブック内の別のワークスペースのテーブルまたはディメンションが更新されなかったことが表示され、それらは**On this sheet**にも一覧表示されません。現在のワークスペースで各テーブルを再度取得して、リンクしてください。

## 入力した値が書き込まれない

`CELL` に値を上書き入力すると、タスクペインに書き込んだ内容が表示され、書き込まれなかったものは理由とともに一覧表示されます。[PlaidCloud に値を入力する](/ja/reference/cli/plaidxl/write-values/)を参照してください。

| 表示される内容 | 対処方法 |
|---|---|
| 入力した値を受け付けるのは、`PLAIDXL.CELL` が 1 つだけ入ったセルのみです | 数式が単一の `CELL`（乗算、除算、符号反転は可）であるセルに上書き入力してください。 |
| ここでは引数を読み取れません | `CELL` の引数は、他の計算ではなく、セルまたはテキストである必要があります。 |
| 分散方法、シェイプ、保留は合計にのみ適用されます | `E1200`、`1200 like FY2025`、`H` などのコードは、**合計**セルでのみ機能します。それ以外のセルでは、通常の数値を入力してください。 |
| すべてのメンバーが保留されています | `H` で保留を解除してから、もう一度値を入力してください。 |
| このワークスペースは、Excel で入力した値をまだ受け付けません | 管理者にワークスペースの更新を依頼してください。 |

## 保存が拒否または中断される

保存はすぐに書き込まれ、中断されることはほとんどありません。次の場合は中断されます。

| 表示される内容 | 対処方法 |
|---|---|
| ヘッダー行が取得した列と一致しなくなった | ヘッダーを取得時の状態に戻すか、テーブルをもう一度取得してください。 |
| 値を変換できない | 何も書き込まれず、行が一覧表示されます。列のデータ型に合わせて値を修正してください。 |
| テーブルが他のシートに続いている | 複数のシートに分割されたテーブルは保存できません。1 つのシートに収まるよう、フィルターを付けて取得してください。 |
| 保存で保持できないフィルターでテーブルが取得された | **等しい**と**次のいずれか**のルールを AND で結合したフィルター、またはフィルターなしで、もう一度取得してください。 |
| 行がアクセス権の範囲外にある | 何も保存されません。それらの行を削除してから、もう一度保存してください。 |
| シートがテーブルにリンクされていない | 先にテーブルをシートに取得してください。アクティブなシートに取得したテーブルだけが**On this sheet**に一覧表示されます。 |

保存を元に戻すには、メッセージの**元に戻す**、またはリボンの**Undo last write**をクリックします。各保存はそれぞれ独自の復元ポイントを 7 日間保持するため、保存から最大 7 日間は、どの保存でも元に戻せます。[テーブルを PlaidCloud に保存する](/ja/reference/cli/plaidxl/retrieve/#テーブルを-plaidcloud-に保存する)を参照してください。
