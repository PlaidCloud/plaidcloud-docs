PlaidXLタスクペインの **Weave** タブでは、「地域別・月別の2026年の収益」「ヘッドカウントを含むテーブルは？」「この #VALUE! はなぜ？」のように、やりたいことを普通の言葉で[Weave](/ja/guides/ai-assistant/)に依頼すると、ブックの中で作業を実行してくれます。WeaveはあなたとしてPlaidCloudを読み取り、あなたの権限で動作し、PlaidCloud側では何も変更しません。ブックに加えた変更は、巻き戻せます。

## 質問する

1. タスクペインを開いて **Weave** タブをクリックするか、リボンの **挿入** グループで **Weave に質問...** をクリックします。
2. **Weave に質問** に質問を入力し、**Enter** を押すか **質問** をクリックします。**Shift+Enter** で改行し、空のボックスで **Up** を押すと直前の質問が呼び出されます。

Weaveはテーブルから回答するため、ブックがプロジェクトにリンクされている必要があります。Weaveは、選択範囲とアクティブセルを認識しているため、「これを四半期別に合計して」のような質問が、目の前のセルに対して機能します。**キャンセル** は、まだ回答中の応答を停止します。

## Weaveにできること

- **レポートを作成する** — ディメンションをドリルする行と列を作成し、すべてのセルに `PLAIDXL.CELL` の値を配置します。[レポートの作成](/ja/reference/cli/plaidxl/build-a-report/)と同じです。
- **数式を記述する** — 依頼したセルに数式を書き込みます。
- **ドリルする** — [ドリルコマンド](/ja/reference/cli/plaidxl/drill/)のように、ドリル内のノードを開く、閉じる、残す、削除する操作を行います。
- **テーブルを取得する** — 依頼した行にフィルターしたテーブルを、ブックに取得します。取得したほかのテーブルと同様に更新リストに追加されるため、**Refresh all tables** で最新の状態に保たれます。
- **テーブルを探す** — あるデータを含むテーブルを尋ねると、各回答に、そのテーブルを取得する **Pull** ボタンが表示されます。
- **選択する** — 話題にしている範囲を **選択** するか、更新を提案します。

Weaveが記述する数式には、PlaidXL関数と、計算、テキスト、論理、検索、日付、動的配列のための一般的なExcel関数が使用されます。ブックの外部にアクセスする数式や、テキストから参照を作成する数式（`WEBSERVICE`、`HYPERLINK`、`INDIRECT`、`IMAGE` など）、他のファイルを参照する数式は記述しません。

WeaveはPlaidCloudにデータを書き込みません。値を書き戻すには、[`CELL` の上に入力](/ja/reference/cli/plaidxl/write-values/)するか、[シートを保存](/ja/reference/cli/plaidxl/retrieve/#テーブルをplaidcloudに保存する)することを、自分で行ってください。

### Weaveが先に確認する場合

Weaveは、変更が空のセル、PlaidXLのセル、エラーが表示されているセル、または依頼したセルに入る場合は、すぐに実行します。入力済みの内容を置き換える場合は、変更内容を説明して待機します。

- 別の内容が入っているセルへの数式は、**適用** を待ちます。
- 値が入っているセルを置き換えるドリルは、**適用** を待ちます。
- 更新済みのテーブルがすでにあるシートへのテーブルの取得は、**Retrieve** を待ちます。
- 更新は、**更新** を待ちます。

## 変更を巻き戻す

Weaveが行った各変更には **巻き戻し** ボタンがあり、複数の変更を行った回答には **すべて巻き戻し** があります。巻き戻しは、各セルを元の状態に戻します。ただし、その後に自分で変更したセルは対象外で、そのまま残して知らせます。Weaveが新しいシートに配置したレポートやテーブルは、そのシートを削除することで巻き戻されますが、Excelではこれを元に戻せません。お使いのバージョンのExcelが対応している場合は、**Ctrl+Z** でもWeaveの変更を1ステップで元に戻せます。

## 問題が発生した場合

Weaveが記述した数式やアクションがエラーになった場合、Weaveは1回だけ修正を試みます。修正がうまくいかない場合は、元の状態に戻し、試した内容を知らせます。

## セルについて質問する

セルを選択し、**PlaidXL** の右クリックメニューから **Ask Weave about this cell** を選択するか、**PlaidXL Cell** タブの **Weave に質問** をクリックするか、**Ctrl+Alt+Shift+Q**（Macでは **⌘⌥⇧Q**）を押します。**Weave** タブが開き、質問を入力できる状態になります。セルにエラーが表示されている場合は、**Why is this #VALUE!?** のような質問が入力済みになり、準備ができたら送信できます。PlaidXLのセルの場合、Weaveはその数式が何を読み取っているかも把握しています。

## 制限

| 制限 | 値 |
|---|---|
| 質問の長さ | 4,000文字 |
| 1人あたりの質問数 | 1時間に30回 |
| 1回の回答で取得するテーブル | 3 |

会話は、このコンピューター上のブックとプロジェクトごとに、最新の40件まで保持されるため、ペインを開き直しても残っています。再読み込みすると、**巻き戻し** と **適用** のボタンはなくなります。サインアウトするかワークスペースを切り替えると、会話はクリアされます。

<Aside>
Weaveは、ブックにリンクされたプロジェクトから回答します。別のプロジェクトについて質問するには、先にタスクペインのヘッダーでそのプロジェクトを選択してください。
</Aside>
