[サインイン](/ja/reference/cli/plaidxl/connect/)すると、作業ウィンドウにプロジェクトが一覧表示されます。プロジェクトを選択して、そのテーブルとディメンションをブックに取得します。

## プロジェクトを選択する

作業ウィンドウのヘッダーには、ワークスペースと、このブックがリンクされているプロジェクトが表示されます。プロジェクト名をクリックするとプロジェクトの一覧が開き、開くことができるすべてのプロジェクトが、PlaidCloudと同じフォルダー構成で表示されます。フォルダーは折りたたまれた状態で始まります。クリックして開くか、**Filter projects by name**に入力して一覧を絞り込みます。

プロジェクトをクリックして選択します。そのテーブルは**テーブル**タブに、ディメンションは**ディメンション**タブに表示されます。

### プロジェクトはブックに属する

選択したプロジェクトはブックに保存されるため、各ブックには独自のプロジェクトがあります。このプロジェクトは、そのブックでPlaidXLの[カスタム関数](/ja/reference/cli/plaidxl/functions/)と展開コマンドが読み取るプロジェクトです。2つのブックを開くと、それぞれが自身のプロジェクトから読み取り、ブックを開き直すと、作業ウィンドウはそのブックのプロジェクトに戻ります。プロジェクトは、ファイルを開いて、そのプロジェクトへのアクセス権のあるアカウントでサインインしたすべての人に引き継がれます。

プロジェクトは1つのワークスペースに属します。[ワークスペースを切り替える](/ja/reference/cli/plaidxl/connect/#サインアウトまたはワークスペースの切り替え)と、以前のワークスペースのプロジェクトにリンクされていたブックには、プロジェクトを選択するまでプロジェクトが設定されません。以前のワークスペースから取得したテーブルはブックに残りますが、**Refresh All Tables**ではスキップされ、作業ウィンドウにその件数が表示されます。新しいワークスペースでもう一度取得すると、リンクされます。

## テーブルを取得する

1. **テーブル**タブで、テーブルをクリックします。長い一覧の中から探すには、**Filter tables by name**を使用します。各テーブルの横にある**行数**と**列**で、そのサイズがわかります。
2. **列**で、不要な列のチェックボックスをオフにします。最初はすべての列が選択されています。
3. 一部の行だけを取得するには、**高度**を選択してフィルターを作成します。[行をフィルターする](#行をフィルターする)を参照してください。
4. **Select where to place this table**で、次のいずれかを選択します。
   - **Matching Worksheet** — テーブル名が付いたワークシート。シートが存在しない場合はPlaidXLが作成し、存在する場合はセルA1からテーブルを書き込みます。
   - **Current Selection** — アクティブなシートで選択しているセルから開始します。
5. **Retrieve Table**をクリックします。

データはヘッダー行付きで取り込まれ、すぐに作業できる状態になります。ヘッダー行は太字で網掛けになり、列は内容に合わせたサイズになり、フィルターが有効になります。**Matching Worksheet**に取得したテーブルには、さらに次のものが追加されます。

- 固定されたヘッダー行。スクロールしても表示されたままになります。
- データ範囲に対する名前付き範囲。更新時にデータが増えても、これを使用する数式が追従します。名前は、ワークシート名の先頭にアンダースコアを付けたものです。**Sample data**というテーブルは`Sample_data`シートに取り込まれ、名前付き範囲は`_Sample_data`になります。

ワークシートに名前を付ける際、PlaidXLはテーブル名をExcelの上限である31文字に切り詰め、半角のアルファベット（A〜Z）、数字、スペースだけを残し、スペースをアンダースコアに変換します。**Q3 Revenue (EMEA)** というテーブルは、`Q3_Revenue_EMEA`シートに取得されます。アンダースコアとアクセント付き文字も削除されるため、**sales_2024**は`sales2024`シートに取得されます。

<Aside type="tip">幅の広いテーブルは、Excelへの読み込みに時間がかかります。大きなテーブルの取得を最も手早く高速化する方法は、不要な列をオフにすることです。</Aside>

### 赤で表示されるテーブル

テーブルがワークシートに収まらないほど大きい場合（1,048,576行または16,384列を超える場合）、またはPlaidCloudがサイズを報告できない場合（一度も読み込まれたことのないテーブルなど）は、テーブルが赤で表示されます。収まるまで、**高度**で行をフィルターし、列をオフにします。PlaidXLが取得するのは、最大でヘッダー行に加えて1,048,575行で、そこで警告なしに停止します。

## 行をフィルターする

**高度**を選択すると、フィルタービルダーが開きます。各ルールでは、列、比較（**等しい**、**in**、**含む**、**開始文字列**、**空である**など）、および値を選択します。ルールを組み合わせるには、**AND**グループ、**OR**グループ、またはその両方を使用します。

フィルターは値をテキストとして比較するため、完全一致する値とテキストパターンに一致します。数値や日付の範囲は使用できません。範囲を取得するには、必要な値を**in**でフィルターするか、テーブルを取得してからExcelでフィルターしてください。

- 値は引用符なしで入力します。`"EMEA"`ではなく`EMEA`です。
- **in**など、複数の値を取る比較では、値をカンマとスペースで区切ります。`EMEA, APAC, NA`のようにします。

フィルターが適用されるのは、**高度**が選択されている間だけです。PlaidXLは、取得したテーブルごとにフィルターと選択した列を記憶し、更新時にもう一度使用します。

## Refresh All Tables

**Refresh All Tables**は、作業ウィンドウ、またはリボンの**PlaidCloud → データ**にあり、ブックに取得したすべてのテーブルについて、それぞれ選択した列とフィルターで、PlaidCloudから最新のデータを取得します。

実行中は、各テーブルのワークシートタブが黄色になります。そのテーブルが最新の状態になると、緑色になります。データを使用する数式は通常どおり再計算されます。それに基づいて作成したピボットテーブルは、Excelの**Data → Refresh All**で更新します。

PlaidXLは、取得したテーブルの一覧をブックに保存するため、**Refresh All Tables**は、ファイルを開いて、同じプロジェクトへのアクセス権のあるアカウントでサインインしたすべての人が使用できます。

**Retrieve Table**を実行するたびに、そのテーブルが更新リストに追加され、1つだけ削除する方法はありません。各テーブルは1回だけ取得し、更新には**Refresh All Tables**を使用してください。同じテーブルをもう一度取得すると、更新のたびに2回取得されることになります。

<Aside type="caution">
**Current Selection**に取得したテーブルは、**Refresh All Tables**をクリックしたときに**アクティブなシート**の同じセルに更新され、そこにある内容が上書きされます。更新する予定のテーブルは**Matching Worksheet**に取得してください。そうすれば、常にそのテーブル専用のシートに更新されます。

更新では、古いデータを先にクリアせずに上書きします。テーブルの行数や列数が以前より少なくなった場合、前回の取得で追加された余分な行や列がシートに残ります。縮小した可能性のあるテーブルを更新する前に、シートの内容をクリアしてください。
</Aside>

## ディメンションを取得する

**ディメンション**タブには、プロジェクトの[ディメンション](/ja/guides/dimensions/dimensions/)が一覧表示されます。

1. ディメンションをクリックします。探すには、**Filter dimensions by name**を使用します。
2. **Select where to place this dimension**で、**Matching Worksheet**または**Current Selection**を選択します。
3. **Retrieve Dimension**をクリックします。

PlaidXLは、ディメンションのノードを階層の順に1列として書き込みます。ディメンションには列や行のフィルターがなく、**Refresh All Tables**でも更新されません。変更を反映するには、ディメンションをもう一度取得してください。

インデントとExcelのアウトライングループを使って階層をレイアウトする場合や、特定のノードまたは代替階層から開始する場合は、代わりに[`PLAIDXL.DIMENSION.GET_DIMENSION`](/ja/reference/cli/plaidxl/functions/#get_dimension)または[展開コマンド](/ja/reference/cli/plaidxl/ribbon/#drill-functions)を使用します。

## テーブルをPlaidCloudに保存する

ブックに取得したテーブルは、PlaidCloudのテーブルをシート上の内容で置き換える形で、書き戻すことができます。

1. 取得したテーブルがあるワークシートを開きます。**Save this sheet to PlaidCloud**の下に、作業ウィンドウがアクティブなシートにリンクされている各テーブルを、その行数とともに一覧表示します。シートにテーブルがない場合は、先にそこにテーブルを取得するよう、作業ウィンドウに表示されます。
2. テーブルの横にある**Save to PlaidCloud…** ボタンをクリックします。
3. 確認画面で、テーブル、書き込む行数、列を確認してから、**Replace table**をクリックします。

PlaidXLは、テーブルの取得先の場所から、ヘッダー行とその下の行を読み取ります。ヘッダーは、取得した列と一致している必要があり、値は各列のデータ型に変換されます。値を変換できない場合は、何も書き込まれず、失敗した行が一覧表示されます。PlaidCloudの列定義は変更されません。

### 保存される内容

- 空のセルと、エラーが表示されているセルは、空として保存されます。
- テーブルの直下に追加した行は、最初の空行までが含まれます。
- 取得した行の内部にある空行は保持されます。その下にデータがあるのに空行が2行以上連続していると、保存が停止し、削除または入力すべき行が通知されます。

### テーブルを置き換える前に

- **フィルターしたテーブル。** フィルターを使用してテーブルを取得した場合、フィルターで除外されたすべての行がPlaidCloudから削除されます。確認画面でその旨が表示され、チェックボックスをオンにするまで**Replace table**は有効になりません。
- **取得しなかった列。** 一部の列だけを取得した場合、PlaidXLは**Empty columns that were not retrieved?** というメッセージを表示し、該当する列の名前を示します。**Write anyway**をクリックすると、PlaidCloud内のそれらの列が空になります。キャンセルすると、何も書き込まれません。
- **他のユーザーがテーブルを変更した場合。** 取得後にPlaidCloudでテーブルが変更されていると、保存は拒否されます。もう一度取得して、編集内容を再適用してください。
- **復元ポイント。** PlaidXLは、書き込む前に復元ポイントを作成し、7日間保持します。書き込みに失敗した場合は、テーブルが元の状態に戻されます。復元ポイントを作成できないテーブルでは、**Write back without a restore point?** というメッセージが表示され、**Write anyway**をクリックすると、復元ポイントなしで続行します。

保存が成功すると、確認メッセージに**Restore previous version**が表示されます。これをクリックするとPlaidCloudでテーブルが開き、**As of**メニューで、この保存の直前のバージョンを選択できます。
