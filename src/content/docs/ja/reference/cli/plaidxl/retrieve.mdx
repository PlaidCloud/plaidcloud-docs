[サインイン](/ja/reference/cli/plaidxl/connect/)すると、タスクペインにプロジェクトが一覧表示されます。プロジェクトを選択し、そのテーブルとディメンションをブックに取得します。

## プロジェクトを選択する

**プロジェクト**セクションには、開くことができるすべてのプロジェクトが、PlaidCloudで表示されるのと同じフォルダー構成で一覧表示されます。フォルダーは折りたたまれた状態で始まります。クリックして開くか、**Filter projects by name**に入力して一覧を絞り込みます。

プロジェクトをクリックして選択します。そのテーブルは**テーブル**タブに、ディメンションは**ディメンション**タブに表示されます。

選択したプロジェクトは、PlaidXLの[カスタム関数](/ja/reference/cli/plaidxl/functions/)とドリルコマンドが読み取るプロジェクトでもあります。選択内容は、このブックだけでなく、開いているすべてのブックに適用されます。

### デフォルトのプロジェクトを設定する

ブックのタスクペインを開くたびに同じプロジェクトが選択されるようにするには、プロジェクトを選択して**デフォルトに設定**をクリックします。デフォルトはブックに保存されるため、ファイルを開く人にもそのまま引き継がれます。**Clear Default**で解除できます。

## テーブルを取得する

1. **テーブル**タブで、テーブルをクリックします。長い一覧から探すには、**Filter tables by name**を使用します。各テーブルの横にある**行数**と**列**で、サイズがわかります。
2. **列**の下で、不要な列のチェックボックスをオフにします。最初はすべての列が選択されています。
3. 一部の行のみを取得する場合は、**高度**を選択してフィルターを作成します。[行をフィルターする](#行をフィルターする)を参照してください。
4. **Select where to place this table**で、次のいずれかを選択します。
   - **Matching Worksheet** — テーブルにちなんだ名前のワークシート。シートが存在しない場合はPlaidXLが作成し、存在する場合はセルA1からテーブルを書き込みます。
   - **Current Selection** — アクティブなシートで選択したセルから開始します。
5. **Retrieve Table**をクリックします。

データはヘッダー行付きで取り込まれ、すぐに使用できる状態になります。ヘッダー行は太字で網掛けされ、列幅は内容に合わせて調整され、フィルターが有効になります。**Matching Worksheet**に取得したテーブルには、さらに次のものが追加されます。

- 固定されたヘッダー行。スクロールしても表示されたままになります。
- データ範囲に対する名前付き範囲。これを使用する数式は、更新時にデータが増えても追従します。名前は、ワークシート名の先頭にアンダースコアを付けたものです。**Sample data**というテーブルは`Sample_data`シートに取得され、名前付き範囲は`_Sample_data`になります。

ワークシートに名前を付けるとき、PlaidXLはテーブル名をExcelの上限である31文字に切り詰め、半角のアルファベット（A〜Z）、数字、スペースのみを残して、スペースをアンダースコアに変換します。**Q3 Revenue (EMEA)** というテーブルは、`Q3_Revenue_EMEA`シートに取得されます。アンダースコアとアクセント付き文字も削除されるため、**sales_2024**は`sales2024`シートに取得されます。

<Aside type="tip">列数の多いテーブルは、Excelへの読み込みに時間がかかります。不要な列をオフにすることが、大きなテーブルの取得を速くする最も手早い方法です。</Aside>

### 赤で表示されるテーブル

テーブルがワークシートに収まらないほど大きい場合（1,048,576行または16,384列を超える場合）や、読み込まれたことのないテーブルのようにPlaidCloudがサイズを報告できない場合は、テーブルが赤で表示されます。収まるまで、**高度**で行をフィルターし、列をオフにしてください。PlaidXLが取得するのは、ヘッダー行に加えて最大1,048,575行までで、それを超えると警告なしに停止します。

## 行をフィルターする

**高度**を選択すると、フィルタービルダーが開きます。各ルールでは、列、**等しい**、**in**、**含む**、**開始文字列**、**空である**などの比較、および値を指定します。**AND**グループ、**OR**グループ、またはその両方を使用して、ルールを組み合わせます。

フィルターは値をテキストとして比較するため、完全一致の値とテキストパターンに一致します。数値や日付の範囲は使用できません。範囲を取得するには、**in**で必要な値をフィルターするか、テーブルを取得してExcelでフィルターします。

- 値は引用符なしで入力します。`"EMEA"`ではなく`EMEA`と入力します。
- **in**のように複数の値を取る比較では、値をカンマとスペースで区切ります。`EMEA, APAC, NA`のようにします。

フィルターは、**高度**が選択されている間のみ適用されます。PlaidXLは、取得したテーブルごとに、選択したフィルターと列を記憶し、更新時にもう一度使用します。

## Refresh All Tables

**Refresh All Tables**は、タスクペイン、またはリボンの**PlaidCloud → PlaidXL Controls**から実行でき、ブックに取得したすべてのテーブルについて、それぞれ選択した列とフィルターを使って、PlaidCloudから最新のデータを取り込みます。

実行中は、各テーブルのワークシートタブが黄色になります。そのテーブルが最新になると緑色になります。このデータを使用する数式は通常どおり再計算されます。このデータに基づくピボットテーブルは、Excelの**Data → Refresh All**で更新してください。

PlaidXLは取得したテーブルの一覧をブックに保存するため、同じプロジェクトへのアクセス権を持つユーザーがファイルを開いてサインインすれば、**Refresh All Tables**を使用できます。

**Retrieve Table**を実行するたびに、そのテーブルが更新リストに追加され、1つだけ削除する方法はありません。各テーブルは1回だけ取得し、更新には**Refresh All Tables**を使用してください。同じテーブルをもう一度取得すると、更新のたびにそのテーブルが2回取り込まれます。

<Aside type="caution">
**Current Selection**に取得したテーブルは、**Refresh All Tables**をクリックしたときに**アクティブなシート**の同じセルに更新され、既存の内容が上書きされます。更新する予定のテーブルは**Matching Worksheet**に取得してください。そのテーブルは常に専用のシートに更新されます。

更新では、古いデータを先にクリアせずに上書きします。テーブルの行数や列数が以前より少なくなった場合、前回の取得で書き込まれた余分な行や列がシートに残ります。縮小した可能性のあるテーブルを更新する前に、シートの内容をクリアしてください。
</Aside>

## ディメンションを取得する

**ディメンション**タブには、プロジェクトの[ディメンション](/ja/guides/dimensions/dimensions/)が一覧表示されます。

1. ディメンションをクリックします。探すには**Filter dimensions by name**を使用します。
2. **Select where to place this dimension**で、**Matching Worksheet**または**Current Selection**を選択します。
3. **Retrieve Dimension**をクリックします。

PlaidXLは、ディメンションのノードを階層順に1列で書き込みます。ディメンションには列フィルターや行フィルターがなく、**Refresh All Tables**でも更新されません。変更を反映するには、ディメンションをもう一度取得してください。

インデントとExcelのアウトライングループで階層をレイアウトする場合や、特定のノードまたは代替階層から開始する場合は、代わりに[`PLAIDXL.DIMENSION.GET_DIMENSION`](/ja/reference/cli/plaidxl/functions/#get_dimension)または[ドリルコマンド](/ja/reference/cli/plaidxl/ribbon/#drill-functions)を使用します。

## データの変更

PlaidXLはPlaidCloudから読み取るだけで、書き戻すことはありません。取得したシートは自由に編集、並べ替え、数式の追加ができ、プロジェクトには何も変更されません。更新すると、PlaidCloudの最新データがテーブルの範囲に上書きされるため、自分の計算は別のシートで行ってください。

データ自体を変更するには、PlaidCloudで更新します。たとえば、[ワークフロー](/ja/guides/workflows/)や[データエディター](/ja/guides/projects/managing-data-editors/)を使用します。
