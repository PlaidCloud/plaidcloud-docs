[サインイン](/ja/reference/cli/plaidxl/connect/)すると、タスクペインにプロジェクトの一覧が表示されます。プロジェクトを選択し、そのテーブルとディメンションをブックに取得します。

## プロジェクトを選択する

タスクペインのヘッダーには、ワークスペースと、このブックがリンクされているプロジェクトが表示されます。プロジェクト名をクリックするとプロジェクト一覧が開き、開くことのできるすべてのプロジェクトが、PlaidCloud と同じフォルダー構成で表示されます。フォルダーは最初は折りたたまれています。クリックして開くか、**Filter projects by name** に入力して一覧を絞り込みます。

プロジェクトをクリックして選択します。そのテーブルは **Tables** タブに、ディメンションは **Dimensions** タブに表示されます。

### プロジェクトはブックに属します

選択したプロジェクトはブックに保存されるため、プロジェクトはブックごとに設定されます。このプロジェクトが、そのブックで PlaidXL の[カスタム関数](/ja/reference/cli/plaidxl/functions/)とドリルコマンドが読み取る対象になります。2 つのブックを開くと、それぞれが自身のプロジェクトから読み取り、ブックを開き直すと、タスクペインはそのブックのプロジェクトに戻ります。プロジェクトはファイルとともに受け渡され、そのファイルを開いて、アクセス権のあるアカウントでサインインしたユーザーにも引き継がれます。

プロジェクトは 1 つのワークスペースに属します。[ワークスペースを切り替える](/ja/reference/cli/plaidxl/connect/#サインアウトまたはワークスペースの切り替え)と、以前のワークスペースのプロジェクトにリンクされていたブックは、新たにプロジェクトを選択するまでプロジェクトがない状態になります。以前のワークスペースから取得したテーブルはブックに残りますが、**Refresh All Tables** ではスキップされ、タスクペインにその件数が表示されます。新しいワークスペースでもう一度取得すると、リンクされます。

## テーブルを取得する

1. **Tables** タブで、テーブルをクリックします。長い一覧から探すには **Filter tables by name** を使用します。各テーブルの横にある **Rows** と **Columns** で、テーブルの大きさがわかります。
2. **Column** で、不要な列のチェックボックスをオフにします。最初はすべての列が選択されています。
3. 一部の行のみを取得するには、**Advanced** を選択してフィルターを作成します。[行をフィルターする](#行をフィルターする)を参照してください。
4. **Select where to place this table** で、次のいずれかを選択します。
   - **Matching Worksheet** — テーブルと同じ名前のワークシートです。シートが存在しない場合は PlaidXL が作成し、存在する場合はセル A1 からテーブルを書き込みます。
   - **Current Selection** — アクティブなシートで選択しているセルから始めます。
5. **Retrieve Table** をクリックします。

データはヘッダー行付きで取り込まれ、すぐに作業できる状態になります。ヘッダー行は太字で網掛けされ、列幅は内容に合わせて調整され、フィルターが有効になります。**Matching Worksheet** に取得したテーブルには、さらに次の設定が行われます。

- ヘッダー行が固定され、スクロールしても表示されたままになります。
- データ範囲に名前付き範囲が設定され、更新時にデータが増えても、それを使用する数式がデータに追従します。名前は、ワークシート名の前にアンダースコアを付けたものです。たとえば、**Sample data** というテーブルは、シート `Sample_data` に配置され、名前付き範囲は `_Sample_data` になります。

ワークシートに名前を付けるとき、PlaidXL はテーブル名を Excel の上限である 31 文字に切り詰め、半角英字（A～Z）、数字、スペースのみを残して、スペースをアンダースコアに変換します。たとえば、**Q3 Revenue (EMEA)** というテーブルは、シート `Q3_Revenue_EMEA` に取得されます。アンダースコアやアクセント付き文字も削除されるため、**sales_2024** はシート `sales2024` に取得されます。

<Aside type="tip">幅の広いテーブルは Excel への読み込みに時間がかかります。大きなテーブルの取得を速くするには、不要な列をオフにするのが最も効果的です。</Aside>

### 赤で表示されるテーブル

テーブルがワークシートに収まらないほど大きい場合（1,048,576 行または 16,384 列を超える場合）や、読み込まれたことのないテーブルなど、PlaidCloud がサイズを報告できない場合は、テーブルが赤で表示されます。収まるまで、**Advanced** で行をフィルターし、列をオフにしてください。PlaidXL が取得するのは、ヘッダー行に加えて最大 1,048,575 行で、それを超える分は警告なしに取得されません。

## 行をフィルターする

**Advanced** を選択すると、フィルタービルダーが開きます。各ルールでは、列、**equal**、**in**、**contains**、**begins with**、**is empty** などの比較方法、および値を選択します。**AND** グループ、**OR** グループ、またはその両方を使ってルールを組み合わせます。

フィルターは値をテキストとして比較するため、完全一致する値とテキストパターンに一致します。数値や日付の範囲は使用できません。範囲を取得するには、必要な値を **in** で指定してフィルターするか、テーブルを取得してから Excel でフィルターしてください。

- 値は引用符なしで入力します。`"EMEA"` ではなく `EMEA` と入力します。
- **in** など複数の値を取る比較では、値をカンマとスペースで区切ります。`EMEA, APAC, NA` のようにします。

フィルターが適用されるのは、**Advanced** が選択されている間のみです。PlaidXL は、取得したテーブルごとに、フィルターと選択した列を記憶し、更新時に再び使用します。

## Refresh All Tables

**Refresh All Tables** は、タスクペインまたはリボンの **PlaidCloud → Data** にあり、ブックに取得したすべてのテーブルについて、それぞれで選択した列とフィルターを使って、PlaidCloud から最新のデータを取得します。

実行中は、各テーブルのワークシートタブが黄色になります。そのテーブルが最新になると、緑色になります。そのデータを使用する数式は通常どおり再計算されます。そのデータをもとに作成したピボットテーブルは、Excel の **データ → すべて更新** で更新してください。

PlaidXL は、取得したテーブルの一覧をブックに保存します。そのため、同じプロジェクトへのアクセス権を持つユーザーが、ファイルを開いてサインインすれば、**Refresh All Tables** を使用できます。

**Retrieve Table** を実行するたびに、テーブルが更新リストに追加され、リストから削除する方法はありません。各テーブルは 1 回だけ取得し、その後は **Refresh All Tables** で更新してください。同じテーブルをもう一度取得すると、更新のたびにそのテーブルが 2 回取得されます。

<Aside type="caution">
**Current Selection** に取得したテーブルは、**Refresh All Tables** をクリックしたときに**アクティブなシートであれば、どのシートでも**同じセルに更新され、そこにある内容が上書きされます。更新する予定のテーブルは **Matching Worksheet** に取得してください。これらは常に自身のシートに更新されます。

更新では、古いデータを消去せずに上書きします。テーブルの行数または列数が以前より少なくなった場合、前回の取得による余分な行や列がシートに残ります。縮小した可能性のあるテーブルを更新する前に、シートの内容を消去してください。
</Aside>

## ディメンションを取得する

**Dimensions** タブには、プロジェクトの[ディメンション](/ja/guides/dimensions/dimensions/)が一覧表示されます。

1. ディメンションをクリックします。探すには **Filter dimensions by name** を使用します。
2. **Select where to place this dimension** で、**Matching Worksheet** または **Current Selection** を選択します。
3. **Retrieve Dimension** をクリックします。

PlaidXL は、ディメンションのノードを階層の順序で 1 列に書き込みます。ディメンションには列や行のフィルターがなく、**Refresh All Tables** では更新されません。変更を反映するには、ディメンションをもう一度取得してください。

インデントと Excel のアウトライングループ付きで階層を配置する場合や、特定のノードまたは代替階層から開始する場合は、代わりに [`PLAIDXL.DIMENSION.GET_DIMENSION`](/ja/reference/cli/plaidxl/functions/#get_dimension) または[ドリルコマンド](/ja/reference/cli/plaidxl/ribbon/#drill-functions)を使用します。

## テーブルを PlaidCloud に保存する

ブックに取得したテーブルは、PlaidCloud のテーブルをシート上の内容で置き換える形で、保存し直すことができます。

1. 取得したテーブルがあるワークシートに移動します。**Save this sheet to PlaidCloud** の下に、アクティブなシートにリンクされている各テーブルが、行数とともにタスクペインに一覧表示されます。シートにテーブルがない場合、ペインには、先にそこにテーブルを取得するよう表示されます。
2. テーブルの横にある **Save to PlaidCloud…** ボタンをクリックします。
3. テーブル、書き込む行数、列が表示される確認内容を読み、**Replace table** をクリックします。

PlaidXL は、テーブルが取得された場所から、ヘッダー行とその下の行を読み取ります。ヘッダーは、取得した列と一致している必要があり、値は各列のデータ型に変換されます。値を変換できない場合は何も書き込まれず、失敗した行が一覧表示されます。PlaidCloud の列定義はそのまま変わりません。

### 保存される内容

- 空のセルとエラーが表示されているセルは、空として保存されます。
- テーブルのすぐ下に追加した行は、最初の空の行まで含まれます。
- 取得した行の途中にある 1 行だけの空の行はスキップされ、その前後の行は保存されます。空の行が 2 行以上続き、その下にデータがある場合は、保存が中止され、削除または入力が必要な行が通知されます。

### テーブルを置き換える前に

- **フィルターしたテーブル。** フィルターを使ってテーブルを取得した場合、フィルターで除外されたすべての行が PlaidCloud から削除されます。確認内容にその旨が表示され、**Replace table** が有効になる前にチェックボックスをオンにするよう求められます。
- **取得しなかった列。** 一部の列のみを取得した場合、PlaidXL は「**Empty columns that were not retrieved?**」というメッセージを表示し、該当する列を示します。**Write anyway** をクリックすると、PlaidCloud でそれらの列が空になります。キャンセルすると何も書き込まれません。
- **他のユーザーがテーブルを変更した場合。** PlaidCloud が判別できる場合は、取得した後にテーブルが変更されていると保存が拒否されます。もう一度取得して、編集内容を再適用してください。判別できない場合は、確認内容にその旨が表示され、取得した後に他のユーザーが保存した内容は上書きされます。
- **復元ポイント。** PlaidXL は書き込む前に復元ポイントを作成し、7 日間保持します。書き込みに失敗した場合、テーブルは元の状態に戻されます。復元ポイントを作成できないテーブルでは「**Write back without a restore point?**」という確認が表示され、**Write anyway** をクリックすると、復元ポイントなしで続行します。

保存に成功すると、確認メッセージに **Restore previous version** が表示されます。これをクリックすると PlaidCloud でテーブルが開き、**As of** メニューで、今回の保存の直前のバージョンを選択できます。
