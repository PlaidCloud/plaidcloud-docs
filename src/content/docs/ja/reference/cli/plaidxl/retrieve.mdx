[サインイン](/ja/reference/cli/plaidxl/connect/)すると、タスクペインにプロジェクトの一覧が表示されます。プロジェクトを選択して、そのテーブルとディメンションをブックに取得します。

## プロジェクトを選択する

タスクペインのヘッダーには、ワークスペースと、このブックがリンクされているプロジェクトが表示されます。プロジェクト名をクリックするとプロジェクトの一覧が開き、PlaidCloudで表示されるのと同じフォルダー構成で、開くことができるすべてのプロジェクトが表示されます。フォルダーは折りたたまれた状態で始まります。クリックして開くか、**Filter projects by name** に入力して一覧を絞り込みます。ワークスペースに開けるプロジェクトが1つしかない場合は、PlaidXLがブックをそのプロジェクトに自動的にリンクし、ヘッダーに **Linked to** とプロジェクト名、その横に **change** が表示されます。

プロジェクトをクリックして選択します。そのテーブルは **テーブル** タブに、ディメンションは **ディメンション** タブに表示されます。

### プロジェクトはブックに属する

選択したプロジェクトはブックに保存されるため、ブックごとに独自のプロジェクトを持ちます。これは、そのブックでPlaidXLの[カスタム関数](/ja/reference/cli/plaidxl/functions/)とドリルコマンドが読み取るプロジェクトです。2つのブックを開くと、それぞれが自分のプロジェクトから読み取り、ブックを開き直すと、タスクペインはそのプロジェクトに戻ります。プロジェクトは、ファイルとともに、そのファイルを開いてアクセス権のあるアカウントでサインインしたすべての人に引き継がれます。

プロジェクトは1つのワークスペースに属します。[ワークスペースを切り替える](/ja/reference/cli/plaidxl/connect/#サインアウトまたはワークスペースの切り替え)と、以前のワークスペースのプロジェクトにリンクされていたブックは、新しく選択するまでプロジェクトがない状態になります。以前のワークスペースから取得したテーブルとディメンションはブックに残りますが、更新も保存もされません。**Refresh All Tables** は、別のワークスペースのテーブルまたはディメンションが更新されなかったことを知らせます。新しいワークスペースでもう一度取得すると、リンクされます。

## テーブルを取得する

1. **テーブル** タブで、テーブルをクリックします。長い一覧からは **Filter tables by name** で探せます。各テーブルの横にある **行数** と **列** で、そのサイズがわかります。
2. **列** で、不要な列のチェックボックスをオフにします。最初はすべての列が選択されています。
3. 一部の行だけを取得するには、**高度** を選択してフィルターを作成します。[行をフィルターする](#行をフィルターする)を参照してください。
4. **Select where to place this table** で、次のいずれかを選択します。
   - **Matching Worksheet** — テーブルにちなんだ名前のワークシートの、A1セルから配置します。シートが存在しない場合は、PlaidXLが作成します。
   - **Current Selection** — アクティブなシートで選択しているセルから配置します。
5. **Retrieve Table** をクリックします。

データは、PlaidCloudのテーブルにちなんだ名前のExcelテーブルとして取り込まれます。そのため、これを参照する数式、ピボットテーブル、グラフは、データの増減に追従します。数値、日付、時刻には、そのデータ型に適した書式、またはPlaidCloudの列に設定された数値書式が適用されます。テキスト列はテキストとして書式設定されるため、`0012` のようなコードも先頭のゼロが保持されます。テーブルを初めて取得するときは、ヘッダー行が固定され、列幅が内容に合わせて調整されます。

テーブルを配置するセルにすでに、PlaidXLのテーブルではない内容がある場合は、代わりにPlaidXLが新しいシートにテーブルを配置し、その場所を知らせます。

ワークシートに名前を付けるとき、PlaidXLは通常の英字（A〜Z）、数字、アンダースコア、スペースだけを残し、スペースをアンダースコアに変換して、Excelの上限である31文字に切り詰めます。**Q3 Revenue (EMEA)** というテーブルはシート `Q3_Revenue_EMEA` に、**sales_2024** は `sales_2024` に取得されます。アクセント付きの文字は削除されます。

<Aside type="tip">幅の広いテーブルは、Excelへの読み込みに時間がかかります。大きなテーブルの取得を速くするには、不要な列をオフにするのが最も手軽です。</Aside>

### 赤で表示されるテーブル

テーブルの行数が1,048,575を超える場合、列数が16,384を超える場合、または一度も読み込まれていないテーブルのようにPlaidCloudがサイズを報告できない場合、テーブルは赤で表示され、ツールチップに **Too large for an Excel worksheet** と表示されます。それでも取得できます。1つのワークシートに収まらない行は次のワークシートに続き、最初のシートの名前に ` (2)`、` (3)` のように付けた名前になります。複数のシートに分割されたテーブルは、PlaidCloudに保存し直せません。編集する予定がある場合は、収まるまで **高度** で行をフィルターし、列をオフにしてください。

## 行をフィルターする

**高度** を選択すると、フィルタービルダーが開きます。各ルールでは、列、**等しい**、**次のいずれか**、**含む**、**開始文字列**、**空である** などの比較方法、および値を選択します。ルールを組み合わせるには、**AND** グループ、**OR** グループ、またはその両方を使用します。

フィルターは値をテキストとして比較するため、完全一致する値とテキストパターンに一致します。数値や日付の範囲は使用できません。範囲を取得するには、必要な値を **次のいずれか** でフィルターするか、テーブルを取得してからExcelでフィルターしてください。

- 値は引用符なしで入力します。`"EMEA"` ではなく `EMEA` です。
- **次のいずれか** のように複数の値を取る比較では、値をカンマとスペースで区切ります：`EMEA, APAC, NA`。

フィルターは、**高度** が選択されている間だけ適用されます。PlaidXLは、取得したテーブルごとに、フィルターと選択した列を記憶し、更新するときに再び使用します。**AND** で結合した **等しい** と **次のいずれか** のルールだけで作成したフィルターは、[保存](#テーブルをplaidcloudに保存する)で置き換えられる行も決定します。

## すべてのテーブルを更新する

PlaidXLは、ブックに取得したテーブルとディメンションの一覧を保持し、それぞれに選択した列とフィルターで更新します。この一覧はブックに保存されるため、同じプロジェクトへのアクセス権のあるアカウントでファイルを開いてサインインした人なら誰でも、更新できます。

- タスクペインの **Refresh This Sheet** は、アクティブなシートのテーブルを更新します。
- タスクペインの **Refresh All Tables** は、ブック内のすべてのテーブルとディメンションを更新します。
- リボンの **更新** メニューでも、シート、選択範囲、またはすべてのテーブルを更新でき、PlaidXL数式を再計算できます。[更新](/ja/reference/cli/plaidxl/ribbon/#更新)を参照してください。

更新の実行中は、タスクペインにテーブルごとの進行状況（PlaidCloudへのクエリ、続いて書き込まれた行の割合）が **キャンセル** ボタンとともに表示されます。同時に更新されるテーブルは3つで、別の更新を開始すると、すでに実行中の更新に追加されます。完了すると、ペインに各テーブルとその行数、または失敗した理由が一覧表示されます。一覧のテーブルをクリックすると、そのテーブルが選択されます。失敗したテーブルがあっても、他のテーブルは停止しません。

**キャンセル** はPlaidCloudへのクエリを停止し、更新前の状態のままブックを残します。テーブルのデータは、すべての行が届いて初めて置き換えられます。データの書き込み中はExcelの計算が一時停止され、最後に1回だけ実行されます。

### 更新で保持されるもの

テーブルは、現在どこにあっても、同じExcelテーブルに更新されます。**Current Selection** に取得したテーブルは、Excelテーブルを移動したり名前を変更したりした後でも、自分のシートの自分のセルで更新されます。テーブルは新しいデータに合わせて拡大または縮小し、以前の大きな取得で残った行と列はクリアされます。

- **独自の列** — Excelテーブル内で、データの横に追加した列は保持されます。すべての行で同じ数式は、新しい行まで下方向に入力されます。メモなどの他の値は、PlaidCloudでテーブルにキー列がある場合は、行に追従します。なくなった行のメモは、テーブルの下に保持されます。キー列がない場合、メモは位置を基準にその場に残ります。
- **書式** — 列に設定した数値書式は保持されます。

テーブルのワークシートが削除されている場合、そのテーブルはスキップされ、PlaidXLが **Recreate sheet** または **Stop refreshing** を提示します。

### テーブルを更新リストから削除する

**On this sheet** の下に、タスクペインがアクティブなシートに取得した各テーブルとディメンションを、行数と最終更新日時とともに一覧表示します。**Stop refreshing** をクリックすると、更新リストから外されます。データはシートに残り、メッセージに **元に戻す** が表示されます。

すでにリストにあるテーブルの上に取得すると、リストのそのテーブルが置き換えられるため、何度取得しても、テーブルは1回だけ更新されます。各テーブルの横にある **コピー** は、数式で使用するために、そのExcelテーブル名をコピーします。

## ディメンションを取得する

**ディメンション** タブには、プロジェクトの[ディメンション](/ja/guides/dimensions/dimensions/)が一覧表示されます。

1. ディメンションをクリックします。**Filter dimensions by name** で探せます。
2. **Select where to place this dimension** で、**Matching Worksheet** または **Current Selection** を選択します。
3. **Retrieve Dimension** をクリックします。

PlaidXLは、ディメンションのノードを、階層の順序で1列に書き込みます。ディメンションには、列や行のフィルターはありません。**Refresh All Tables** は、テーブルと一緒にディメンションも更新します。

インデントとExcelのアウトライングループ化を使って階層をレイアウトしたい場合や、特定のノードまたは代替階層から開始したい場合は、代わりに[ドリルコマンド](/ja/reference/cli/plaidxl/drill/)または[`PLAIDXL.DRILL`](/ja/reference/cli/plaidxl/functions/#drill)を使用してください。1つのメンバーをセルに配置するには、**ディメンション** タブの **Pick member...** ボタンをクリックします。[メンバーを選択する](/ja/reference/cli/plaidxl/drill/#メンバーを選択する)を参照してください。

## テーブルをPlaidCloudに保存する

ブックに取得したテーブルは、PlaidCloudのテーブルの行をシート上の内容で置き換える形で、保存し直すことができます。

1. 取得したテーブルを含むワークシートに移動します。**On this sheet** の下に、そこに取得された各テーブルがタスクペインに一覧表示されます。ない場合は、先にそこにテーブルを取得するよう、ペインに表示されます。
2. テーブルの横にある **Save to PlaidCloud** をクリックするか、リボンの **書き込み** グループの **Save sheet to PlaidCloud...** ボタンをクリックして（**Ctrl+Alt+Shift+W**、Macでは **⌘⌥⇧W**）、シート上のすべてのテーブルを保存します。

保存は、確認なしですぐに実行されます。メッセージには、保存された行数、知っておくべき事項が表示され、**元に戻す** が表示されます。

PlaidXLは、テーブルのヘッダー行とその下の行を読み取ります。ヘッダーは、取得した列と一致している必要があり、値は各列のデータ型に変換されます。変換できない値がある場合は、何も書き込まれず、失敗した行が一覧表示されます。PlaidCloudの列定義は変更されません。

### 保存される内容

- 空のセルは、空として保存されます。
- 取得した行の途中にある空の行はスキップされます。その下では、最初の空の行でテーブルが終了します。それより下の行は保存されず、メッセージにその行が示されます。
- 取得しなかった列は、PlaidCloudで空になり、メッセージにその列が示されます。
- 取得した後にPlaidCloudでテーブルが変更された場合、保存によってそれが置き換えられ、メッセージにその旨が表示されます。以前の内容は、復元ポイントに保持されます。

### 一部の行だけを置き換える保存

次の場合、保存は自分の行だけを置き換え、テーブルの残りは保持されます。

- **テーブルが、フィルターを使って取得された**場合で、フィルターが **AND** で結合された **等しい** と **次のいずれか** のルールで作成されているとき。フィルターが対象とする行だけが置き換えられます。フィルターの範囲外に追加した行も保存され、メッセージにその数が表示されます。それ以外のフィルターで取得したテーブルは保存できません。そのようなフィルターを使うか、フィルターなしで、もう一度取得してください。
- **シートに、[Show detail rows](/ja/reference/cli/plaidxl/drill/#明細行を表示する)の明細行が表示されている**場合。その値の元になっている行だけが置き換えられます。
- **テーブルへのアクセスが一部の行に限定されている**場合。表示できる行だけが置き換えられるため、他のユーザーの行は保持されます。シートにアクセス権のない行が含まれている場合は、何も保存されず、メッセージにその行が一覧表示されます。それらの行を削除するか、プロジェクトのアーキテクトに保存を依頼してください。

### 保存を元に戻す

PlaidXLは、書き込みの前に復元ポイントを作成し、7日間保持します。書き込みが失敗した場合、テーブルは元の状態に戻り、変更内容はシートに残ります。

保存を元に戻すには、メッセージの **元に戻す** をクリックするか、リボンの **書き込み** グループの **Undo last write** をクリックします。テーブルは保存前の状態に戻ります。一部の行だけを置き換えた保存の場合は、その行だけです。確認するには、シートを更新してください。[書き込みを元に戻す](/ja/reference/cli/plaidxl/write-values/#書き込みを元に戻す)を参照してください。復元ポイントを作成できないテーブルも保存はされますが、メッセージに保存を元に戻せないことが表示されます。
