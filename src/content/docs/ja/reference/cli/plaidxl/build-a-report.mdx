## 開始する前に

- [サインイン](/ja/reference/cli/plaidxl/connect/)して、データを保持するプロジェクトを選択します。
- レポートの対象となる数値列（**revenue**など）を含むテーブルと、レポートに使用するディメンションごとの列（**Region**や**Period**など）が必要です。これらの列は、PlaidCloud内のディメンションにリンクされている必要があります。`CELL`は列名でフィルターし、リンクされた列でのみディメンションを通じてノードを集計します。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。
- 正確な名前がわからない場合は、作業用のシートで`=PLAIDXL.TABLE.TBL_LIST()`、`=PLAIDXL.TABLE.GET_COLUMNS("Sales")`、`=PLAIDXL.DIMENSION.DIM_LIST()`を使うと一覧表示できます。

## レポートを作成する

以下の手順では、メジャー列**revenue**とディメンション列**Region**（行）および**Period**（列）を持つ**Sales**という名前のテーブルを使用します。これらの列は同じ名前のディメンションにリンクされています。名前はご自身のものに置き換えてください。`DRILL`ではディメンションの名前を、`DIMENSION_REPR`ではテーブルの列名を使用します。

<Steps>

1. **測定する対象を記述します。** シートの上部にある3つのセルに、次のように入力します。

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   レポート内のすべての値がこれらのセルを参照するため、たとえば`"sum"`を`"mean"`に変更するなど、1つ変更するだけでレポート全体が変わります。

2. **行をレイアウトします。** `A6`で、行ディメンションを最上位のノードからドリルします。

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **合計**とその子ノードがA列に展開され、親の下にインデントされ、折りたたみできるようにグループ化されます。すべてのレベルを表示するには`"all"`を、最下位のレベルのみを表示するには`"leaves"`を使用します。行のノードを自分で入力する場合は、各セルにノード名を1つずつ入力します。

3. **列をレイアウトします。** 5行目の`B5`から右方向に、列のノードを入力します。たとえば`FY2025`と`FY2026`です。

4. **最初の値を入力します。** `B6`に次を入力します。

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   `$`記号により、テーブル、メジャー、タイプは固定され、行のノードはA列、列のノードは5行目に固定されます。`DRILL`がノード名に追加するインデントは無視されます。

5. **グリッドを埋めます。** `B6`を最後の期間まで右に、最後の行まで下にコピーします。各セルには、その行のリージョンについて、その列の期間の収益が表示されます。

</Steps>

レポート全体に適用されるフィルター（たとえば1つの製品ラインなど）を追加するには、上部のセルに別の`DIMENSION_REPR`（`B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`など）を追加し、すべての`CELL`に`$B$4`を渡します。

行ごとに複数のメジャーを表示するには、[`PLAIDXL.CELLS`](/ja/reference/cli/plaidxl/functions/#cells)と[`PLAIDXL.REPR.MEASURES`](/ja/reference/cli/plaidxl/functions/#measures)を使用します。

## レポートを最新の状態に保つ

- **完全な再計算を強制する**と、現在の値がすべてのPlaidXL数式に取り込まれます。Windowsでは**Ctrl+Alt+F9**を押します。通常の再計算では、数式の引数が変更されない限り、再取得は行われません。
- **スコープを変更する**には、構成要素のセルを編集します。別のテーブル、メジャー、集計、または別の最上位フィルターノードを指定できます。そのセルを使用している数式はすぐに更新されます。
- **別のプロジェクトのレポートを作成する**には、タスクペインでそのプロジェクトを選択してから、完全な再計算を強制します。数式は選択中のプロジェクトから読み取るため、テーブル名、列名、ディメンション名が共通するプロジェクトであれば、同じブックでそれぞれのレポートを作成できます。

## 値のみのコピーを共有する

PlaidXLを持っていない人や、プロジェクトにアクセスできない人には、PlaidXLの数式の代わりにエラーが表示されます。数値を送るには、先に数式を値に置き換えます。

1. レポートを保存し、送信用に別の名前でコピーを保存します。
2. コピーで、**PlaidCloud → Sanitize Workbook**をクリックします。
3. コピーを送信します。

**Sanitize Workbook**は、ブック内のすべての数式を現在の値に置き換えます。**Restore Workbook**は数式を元に戻しますが、`DRILL`のように結果が展開される数式は正しく復元されず、サニタイズ後に変更した内容は上書きされます。元のファイルは必ず保管してください。ライブのレポートを確実に取り戻す方法はそれだけです。[サニタイズと復元](/ja/reference/cli/plaidxl/ribbon/#control-functions)を参照してください。

<Aside type="caution">サニタイズするのは送信用のコピーのみとし、唯一の作業用レポートには絶対に行わないでください。サニタイズは、PlaidXLの関数ではない数式を含め、ブック内のすべての数式に影響します。</Aside>
