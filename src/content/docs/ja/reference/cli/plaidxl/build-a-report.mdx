## 始める前に

- [サインイン](/ja/reference/cli/plaidxl/connect/)して、データを保持するプロジェクトを選択します。ブックはこのプロジェクトを記憶します。
- レポートの対象となる数値列（**revenue**など）を持つテーブルと、レポートの軸とする各ディメンション（**Region**や**Period**など）に対応する列が必要です。これらの列は、PlaidCloudでそのディメンションにリンクされている必要があります。`CELL`は列名でフィルターし、リンクされた列でのみ、ディメンションを通じてノードを集計します。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。
- 正確な名前がわからない場合は、スクラッチ用のシートで`=PLAIDXL.TABLE.TBL_LIST()`、`=PLAIDXL.TABLE.GET_COLUMNS("Sales")`、`=PLAIDXL.DIMENSION.DIM_LIST()`を使用すると一覧を確認できます。

## レポートを作成する

以下の手順では、メジャー列**revenue**、ディメンション列**Region**（行）と**Period**（列）を持つ**Sales**というテーブルを使用します。ディメンション列は、同名のディメンションにリンクされているものとします。名前はご自身のものに置き換えてください。`DRILL`ではディメンションの名前、`DIMENSION_REPR`ではテーブルの列名を使用します。

<Steps>

1. **測定する対象を記述します。** シート上部の3つのセルに、次のように入力します。

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   レポート内のすべての値がこれらのセルを参照するため、たとえば`"sum"`を`"mean"`に変更するなど、1つ変更するだけでレポート全体が変わります。

2. **行を配置します。** `A6`で、行のディメンションを最上位のノードから展開します。

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **Total**とその子ノードがA列に下方向へ展開され、親の下にインデントされ、折りたたみ可能なようにグループ化されます。すべてのレベルを表示するには`"all"`を、最下位のレベルだけを表示するには`"leaves"`を使用します。最下位以外のすべてのレベルなど、より細かく制御するには、`>[0:-1]`のようにキーを直接記述します。[`DRILL_KEY`](/ja/reference/cli/plaidxl/functions/#drill_key)を参照してください。行のノードを自分で入力する場合は、各セルにノード名を1つずつ入力します。

3. **列を配置します。** 5行目に、`B5`から始めて列のノードを横方向に入力します。たとえば`FY2025`と`FY2026`です。

4. **最初の値を入力します。** `B6`に、次のように入力します。

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   `$`記号により、テーブル、メジャー、タイプは固定され、行のノードはA列、列のノードは5行目に固定されます。`DRILL`がノード名に追加するインデントは無視されます。

5. **グリッドを埋めます。** `B6`を最後の期間まで右方向に、最後の行まで下方向にコピーします。各セルには、その行のリージョンのその列の期間におけるrevenueが表示されます。

</Steps>

たとえば1つの製品ラインなど、レポート全体に適用するフィルターを追加するには、上部のセルに`B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`のように`DIMENSION_REPR`をもう1つ追加し、すべての`CELL`に`$B$4`を渡します。

各行に複数のメジャーを表示するには、[`PLAIDXL.CELLS`](/ja/reference/cli/plaidxl/functions/#cells)と[`PLAIDXL.REPR.MEASURES`](/ja/reference/cli/plaidxl/functions/#measures)を使用します。

## レポートを最新の状態に保つ

- **完全な再計算を強制**すると、最新の値がすべてのPlaidXL数式に取り込まれます。Windowsでは**Ctrl+Alt+F9**を押します。通常の再計算では、数式の引数が変更されていない限り、再取得は行われません。
- **スコープを変更**するには、構成要素となるセルを編集します。別のテーブル、メジャー、集計、または別の最上位フィルターノードを指定できます。そのセルを使用している数式は直ちに更新されます。
- **別のプロジェクトのレポートを作成**するには、作業ウィンドウでそのプロジェクトを選択してから、完全な再計算を強制します。数式はブックのプロジェクトから読み取るため、テーブル、列、ディメンションの名前が共通するプロジェクトであれば、同じブックでそれぞれのレポートを作成できます。

## 値のみのコピーを共有する

PlaidXLを持っていない人や、プロジェクトにアクセスできない人には、PlaidXL数式の代わりにエラーが表示されます。数値を送るには、先に数式をその値に置き換えます。

1. レポートを保存し、送信用に別の名前でコピーを保存します。
2. コピーで**PlaidCloud → Convert to values (for sharing)** をクリックし、確定します。
3. コピーを送信します。

**Convert to values (for sharing)** は、ブック内のすべてのPlaidXL数式を現在の値に置き換え、ほかの数式はそのまま残します。**Restore PlaidXL formulas**でPlaidXL数式を元に戻せますが、`DRILL`のように結果が展開される数式は正しく復元されず、変換後に加えた変更は上書きされます。ライブのレポートを確実に取り戻す方法は、元のブックを保管しておくことです。[共有](/ja/reference/cli/plaidxl/ribbon/#共有)を参照してください。

<Aside type="caution">変換するのは送信用のコピーです。作業中の唯一のレポートは絶対に変換しないでください。</Aside>
