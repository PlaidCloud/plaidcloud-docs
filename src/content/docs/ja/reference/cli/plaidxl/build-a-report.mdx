レポートの作成方法は3つあります。自分のデータからサンプルを作成する **Build my first report**、選択した内容でレポートを作成する **レポート** タブ、そして自分で記述する数式です。[Weaveに質問](/ja/reference/cli/plaidxl/weave/)して、普通の言葉でレポートを作ってもらうこともできます。

## はじめに

ブックにPlaidCloudのものが何もない間、タスクペインには **Get started** が表示されます。

- **Build my first report** は、リンクされたプロジェクトから、数値列とレポートの軸にできるディメンションを持つテーブルを選び、そこから新しいシート **PlaidXL sample** にレポートを作成します。隣の **PlaidXL sample data** には、そのテーブルの最大1,000行が配置されます。フィルターのセルを変更すると、レポートが再計算されます。
- **Insert a table** は、**テーブル** タブを開きます。
- **Build a report...** は、**レポート** タブを開きます。

## レポートを作成する

**レポート** タブは、レポート全体のレイアウトを自動で作成します。タスクペインから開くか、リボンの **挿入** グループで **Build report...** をクリックします（**Ctrl+Alt+Shift+B**、Macでは **⌘⌥⇧B**）。

1. **テーブル** — レポート対象のテーブルを選択します。
2. **値** — **Column to total** を選択し、**Combine by** で集計方法（sum、mean、median、std、var、min、max）を選択します。
3. **行数** — **ディメンション**、**開始元**（空白にすると最上位）、**Depth** を選択します。Depthでは **Levels down** の数値、**All levels**、**Lowest level only**、**Drill key** のいずれかを指定します。
4. **列** — **Drill a dimension across the columns** を選択して列にも同じ設定を行います。チェックを外すと、値の列が1つだけになります。
5. **フィルター（任意）** — レポート全体を絞り込むディメンションとノードごとに、**フィルターを追加** をクリックします。

このタブは、テーブルとディメンションがあらかじめ選択された状態で開きます。設定を変更すると、各軸の最初の10ノードと、`12 × 4 = 48 values` のような値の数がプレビュー表示されます。開始ノードがディメンションに存在しない場合は、最も近い候補が表示されるので、その中から選択します。

レポートを開始するセルを選択し、**Build report** をクリックします（または **Ctrl+Enter** を押します）。値が入力されている間は、**キャンセル** をクリックするとレポートを停止して削除します。完了すると、メッセージに **元に戻す** が表示されます。レポートに必要なセルにすでに何かが入力されている場合は、代わりに番号付きの新しい **Report** シートに作成されます。

レポートは、手作業で記述するのと同じ数式で構成されます。

- 上部に、**Table**、**Measure**、**Aggregation** のセルと、フィルターごとのセルがあります。
- 行用に左側へ、列用に上部へ、それぞれ [`DRILL`](/ja/reference/cli/plaidxl/functions/#drill) があります。
- すべての交点に [`CELL`](/ja/reference/cli/plaidxl/functions/#cell) があります。この上に入力すると、[PlaidCloudに値を書き込む](/ja/reference/cli/plaidxl/write-values/)ことができます。

親の行は太字で表示され、見出しは固定されます。レポートを変更するには、レポート内のセルを選択します。**レポート** タブがそのレポートを読み込み、**Rebuild report** でその場で置き換えます。別のレポートを作成する場合は、**Build a new one instead** をクリックします。

### レポートはドリルに追従する

レポートの行や列が変わると（行を下または上にドリルする、ノードを残す、または削除する、ディメンションが変わるなど）、レポートはそれに合わせて行と列を丸ごと挿入または削除します。メッセージには、`Report updated: +3 rows, -1 column` のように変更内容が表示され、**元に戻す** も表示されます。入力した値、メモ、書式、およびレポートの横にある数式は、それぞれのノードに付いたまま残ります。

## 数式で作成する

レポートを手作業で作成するには、数式を自分で記述します。

### 始める前に

- [サインイン](/ja/reference/cli/plaidxl/connect/)して、データを含むプロジェクトを選択します。ブックはその選択を記憶します。
- レポート対象の数値列を持つテーブル（たとえば **revenue**）と、レポートの軸にするディメンションごとの列（たとえば **Region** と **Period**）が必要です。これらの列は、PlaidCloudでそのディメンションにリンクされている必要があります。`CELL` は列名でフィルターし、リンクされた列でのみ、ディメンションを通じてノードを集計します。[値](/ja/reference/cli/plaidxl/functions/#値)を参照してください。
- 正確な名前がわからない場合は、作業用のシートで `=PLAIDXL.TABLE.TBL_LIST()`、`=PLAIDXL.TABLE.GET_COLUMNS("Sales")`、`=PLAIDXL.DIMENSION.DIM_LIST()` を使うと一覧表示できます。

### 数式を記述する

以下の手順では、**Sales** というテーブルを使います。このテーブルには、メジャー列 **revenue** と、同名のディメンションにリンクされたディメンション列 **Region**（行）および **Period**（列）があります。名前は自分のものに置き換えてください。`DRILL` ではディメンション名を、`DIMENSION_REPR` ではテーブルの列名を使います。

<Steps>

1. **測定対象を記述します。** シート上部の3つのセルに、次のように入力します。

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   レポート内のすべての値がこれらのセルを参照するため、たとえば `"sum"` を `"mean"` に変えるなど、1つ変更するとレポート全体が変わります。

2. **行をレイアウトします。** `A6` で、行のディメンションを最上位のノードからドリルします。

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **Total** とその子がA列の下方向にあふれて表示され、親の下にインデントされ、折りたたみできるようにグループ化されます。すべてのレベルを表示するには `"all"`、最下位のレベルだけを表示するには `"leaves"` を使います。葉を除くすべてのレベルなど、より細かく制御するには、キーを直接記述します：`>[0:-1]`。[`DRILL_KEY`](/ja/reference/cli/plaidxl/functions/#drill_key)を参照してください。行のノードを自分で入力する場合は、各セルにノード名を1つずつ入力します。

3. **列をレイアウトします。** 5行目の `B5` から右へ、列のノードを入力します。たとえば `FY2025` と `FY2026` です。または、行方向にドリルすることもできます：`=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`。

4. **最初の値を入力します。** `B6` に、次のように入力します。

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   `$` 記号により、テーブル、メジャー、タイプ、A列の行ノード、5行目の列ノードが固定されます。`DRILL` がノード名に付けるインデントは無視されます。

5. **グリッドを埋めます。** `B6` を最後の期間まで右に、最後の行まで下にコピーします。各セルには、その行のリージョンの、その列の期間の収益が表示されます。

</Steps>

レポート全体に適用されるフィルター（たとえば1つの製品ラインだけ）を追加するには、上部のセルに `DIMENSION_REPR` をもう1つ追加します（例：`B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`）。そして、すべての `CELL` に `$B$4` を渡します。

行ごとに複数のメジャーを表示するには、[`PLAIDXL.CELLS`](/ja/reference/cli/plaidxl/functions/#cells)と[`PLAIDXL.REPR.MEASURES`](/ja/reference/cli/plaidxl/functions/#measures)を使用します。

## レポートを最新に保つ

- リボンの **更新** メニューから **Recalculate PlaidXL formulas** を実行すると、すべてのPlaidXL数式に最新の値が取り込まれます。1つのシートだけの場合は **Refresh this sheet** を実行します。通常のExcelの再計算では、数式の引数が変わらない限り、再度取得されません。
- **スコープを変更する**には、構成要素のセルを編集します。別のテーブル、メジャー、集計、または上部の別のフィルターノードです。そのセルを使用する数式はすぐに更新されます。
- **行をドリルする**には、任意の値または行見出しから[ドリルコマンド](/ja/reference/cli/plaidxl/drill/)を使います。レポートは[それに追従します](#レポートはドリルに追従する)。
- **別のプロジェクトのレポートを作成する**には、タスクペインでそのプロジェクトを選択してから、PlaidXL数式を再計算します。数式はブックのプロジェクトから読み取るため、テーブル、列、ディメンションの名前が共通する各プロジェクトを、同じブックでレポートにできます。

## 値のみのコピーを共有する

PlaidXLを使っていない人や、プロジェクトにアクセスできない人には、PlaidXL数式の代わりにエラーが表示されます。数値を送るには、先に数式を値に置き換えます。

1. レポートを保存し、送付用に別の名前でコピーを保存します。
2. コピーで、**PlaidCloud → Convert to values → Whole workbook** をクリックします。1つのシートだけを変換する場合は **This sheet** をクリックします。
3. コピーを送付します。

**Convert to values** は、すべてのPlaidXL数式を現在の値に置き換え、その他の数式はそのままにします。**Restore PlaidXL formulas** は、シート名を変更した後でも、PlaidXL数式を元のセルに戻し、そこにある内容を置き換えます。**Values only (no restore)** では、元に戻す手段が残りません。元のレポートは必ず保管してください。ライブのレポートを確実に取り戻す方法です。[共有](/ja/reference/cli/plaidxl/ribbon/#共有)を参照してください。

<Aside type="caution">変換するのは、送付するコピーです。唯一の作業用レポートは決して変換しないでください。</Aside>
