PlaidXLをインストールすると、Excelのリボンに **PlaidCloud** タブが追加されます。このタブには、**接続**、**挿入**、**更新**、**ドリル**、**書き込み**、**共有** の6つのコマンドグループがあります。よく使うコマンドは **PlaidXL** の右クリックメニューと **PlaidXL Cell** タブにもあり、キーボードショートカットのあるコマンドは、ツールヒントにそのショートカットが表示されます。

グレーアウトされるコマンドはありません。コマンドは、選択したセルに最も近いPlaidXLの数式、テーブル、またはノードに対して動作します。対象がない場合は、代わりに役立つタスクペインの部分が開きます。

サインアウトしている状態や、ブックがプロジェクトにリンクされる前にコマンドを実行すると、PlaidXLはタスクペインを開き、コマンドについて **Sign in to run**、または **Pick a project to run** と表示します。サインインやプロジェクトの選択が済むと、コマンドは開始したセルで実行されます。その間に別のシートに移動したり、別のプロジェクトを選択したりした場合は、コマンドは実行されず、PlaidXLがその旨を知らせます。

## 接続

| コマンド | 内容 |
|---|---|
| **Open PlaidXL** | PlaidXLタスクペインを開きます。 |
| **アカウント** | タスクペインを開き、サインインするか、ワークスペースとプロジェクトを選択します。 |
| **Shortcuts** | PlaidXLのキーボードショートカットを一覧表示し、変更できます。[キーボードショートカット](#キーボードショートカット)を参照してください。 |
| **Help** | このドキュメントを開きます。 |

## 挿入

| コマンド | 内容 |
|---|---|
| **テーブル...** | **テーブル** タブを開き、[テーブルを取得](/ja/reference/cli/plaidxl/retrieve/#テーブルを取得する)します。 |
| **ディメンション...** | **ディメンション** タブを開き、ディメンションを取得するか、そのメンバーを選択します。 |
| **Formula...** | **Formulas** タブを開き、選択したセルの[PlaidXL数式を作成](/ja/reference/cli/plaidxl/functions/#タスクペインから数式を挿入する)します。 |
| **Pick member...** | 選択したセルのディメンションに対するメンバーピッカーを開きます。[メンバーを選択する](/ja/reference/cli/plaidxl/drill/#メンバーを選択する)を参照してください。 |
| **Metric...** | プロジェクトのメトリックを現在の値とともに、検索可能な一覧で開きます。[メトリックを挿入する](/ja/reference/cli/plaidxl/functions/#メトリックを挿入する)を参照してください。 |
| **Build report...** | **レポート** タブを開き、ライブのレポートをレイアウトします。[レポートを作成する](/ja/reference/cli/plaidxl/build-a-report/)を参照してください。 |
| **Weave に質問...** | 選択したセルをコンテキストとして **Weave** タブを開きます。[ExcelでWeaveに質問](/ja/reference/cli/plaidxl/weave/)を参照してください。 |

## 更新

**更新** メニューには4つのコマンドがあります。

| コマンド | 内容 |
|---|---|
| **Refresh this sheet** | アクティブなシートのPlaidXL数式を再計算し、そのテーブルを再度取得します。 |
| **Refresh selection** | 選択範囲のPlaidXL数式を再計算し、選択範囲が触れるテーブルを再度取得します。PlaidXLのものが何も選択されていない場合は、シートを更新します。 |
| **Refresh all tables** | ブック内のすべてのテーブルとディメンションを、それぞれに選択した列とフィルターで再度取得します。 |
| **Recalculate PlaidXL formulas** | ブック内のすべてのPlaidXL数式を再計算します。 |

更新の実行中に表示される内容については、[テーブルの更新](/ja/reference/cli/plaidxl/retrieve/#すべてのテーブルを更新する)を参照してください。

**Recalculate PlaidXL formulas** は、Excel全体の再計算を行わず、PlaidXL数式だけを再計算します。完了すると、再計算したシートを一覧表示し、Excelの元に戻す履歴をクリアします。PlaidXLはテーブルの列の詳細を30秒間保持するため、直近30秒以内に名前を変更した列やディメンションは、表示されるまで少し時間がかかることがあります。

## ドリル

| コマンド | 内容 |
|---|---|
| **Drill down** | メニュー。**One level**、**To lowest level**、**All levels**、**Custom drill...** で、選択したノードの配下のノードをレイアウトします。 |
| **Drill up** | 選択したノードを、その親に折りたたみます。 |
| **Keep only** | ドリルの中で、選択したノードだけを残します。 |
| **Remove only** | 選択したノードとその配下のすべてを、ドリルから取り除きます。 |
| **Show detail rows** | 選択した値の元になっているテーブルの行を、専用のシートに配置します。 |
| **Explain this number** | 選択した値の出どころを表示します。 |

ドリルするセルを1つ選択します。ドリルコマンドは、そのセルをライブの `PLAIDXL.DRILL` 数式に変換します。[ドリル、メンバーの選択、数値の説明](/ja/reference/cli/plaidxl/drill/)を参照してください。

## 書き込み

| コマンド | 内容 |
|---|---|
| **Save sheet to PlaidCloud...** | このシートに取得したテーブルを、すぐにPlaidCloudに書き戻します。[テーブルをPlaidCloudに保存する](/ja/reference/cli/plaidxl/retrieve/#テーブルを-plaidcloud-に保存する)を参照してください。 |
| **Undo last write** | PlaidCloudに最後に入力した値、または最後の保存を、新しい順に元に戻します。[書き込みを元に戻す](/ja/reference/cli/plaidxl/write-values/#書き込みを元に戻す)を参照してください。 |

## 共有

| コマンド | 内容 |
|---|---|
| **Convert to values** | メニュー。**Whole workbook** または **This sheet** は、PlaidXL数式を現在の値に置き換え、数式を記憶します。**Values only (no restore)** は、元に戻す手段を残さずに置き換えます。 |
| **Restore PlaidXL formulas** | **Convert to values** が置き換えた数式を、ブックのすべてのシートで元に戻します。 |

PlaidXLを持っていない人や、プロジェクトにアクセスできない人にレポートを送る場合は、**Convert to values** を使用してください。そのままだと、PlaidXL数式の場所にエラーが表示されます。PlaidXL関数を呼び出すすべての数式（`IFERROR` などの別の数式に含まれているものも含む）を変換し、他の数式はそのままにします。事前の確認なしにすぐに実行され、変換した数式の数が表示されます。

数式はシートごとに保持されるため、シートの名前を変更したり移動したりした後でも、**Restore PlaidXL formulas** で見つけられます。サインインしている必要はありません。[値のみのコピーを共有する](/ja/reference/cli/plaidxl/build-a-report/#値のみのコピーを共有する)を参照してください。

<Aside type="caution">
変換は、別の名前で保存したコピーに対して行い、作業中のレポートはそのまま残してください。**Values only (no restore)** は、**Restore PlaidXL formulas** では元に戻せません。
</Aside>

## 右クリックメニュー

セルを右クリックして **PlaidXL** を選択すると、次のコマンドが表示されます。それぞれ、対応するリボンのボタンと同じです。

- **Drill down one level**、**Drill down to lowest level**、**Drill down all levels**、**Custom drill...**、**Drill up**、**Keep only**、**Remove only**
- **Pick member...**
- **Explain this number** と **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...**。そのセルに対して **Formulas** タブを開きます

## PlaidXL Cellタブ

選択したセルにPlaidXLの数式がある場合、PlaidXL数式の結果の一部である場合、または取得したテーブルの内部にある場合、Excelは **PlaidCloud** タブの隣に **PlaidXL Cell** タブを表示します。このタブには、そのセル向けのコマンドがまとめられています。

- **ドリル** — **Drill down**（**One level**、**Lowest level**、**All levels**）、**Drill up**、**Keep only**、**削除**
- **検査** — **説明**、**Detail rows**、**Weave に質問**
- **データ** — **Pick member**、**Refresh selection**、**Save sheet**

別のセルを選択すると、タブは再び非表示になります。アドインのコンテキストタブをサポートしていないバージョンのExcelでは表示されませんが、すべてのコマンドは **PlaidCloud** タブにあります。

## キーボードショートカット

すべてのショートカットは、Windowsでは **Ctrl+Alt+Shift** とキー、Macでは **⌘⌥⇧** と同じキーです。

| キー | コマンド |
|---|---|
| **Down** | 1レベル下にドリルダウン |
| **Up** | ドリルアップ |
| **L** | 最下位レベルまでドリルダウン |
| **8** | すべてのレベルをドリルダウン |
| **D** | カスタムドリル |
| **K** | Keep only |
| **X** | Remove only |
| **M** | メンバーの選択 |
| **E** | 数値の説明 |
| **T** | 明細行の表示 |
| **R** | このシートを更新 |
| **F** | 選択範囲を更新 |
| **A** | すべてのテーブルを更新 |
| **C** | PlaidXL数式の再計算 |
| **W** | シートをPlaidCloudに保存 |
| **Z** | 最後の書き込みを元に戻す |
| **P** | PlaidXLを開く |
| **N** | 数式の挿入 |
| **B** | レポートの作成 |
| **I** | メトリックの挿入 |
| **Q** | Weaveに質問 |

変更するには、**接続** グループの **Shortcuts** をクリックするか、タスクペインのアカウントメニューから **Keyboard shortcuts** を選択します。コマンドの横にある **Set key** をクリックし、新しい組み合わせを押して、**保存** をクリックします。**リセット** をクリックすると、元の設定に戻ります。別のコマンドがすでに使用している組み合わせにはフラグが付きますが、そのまま保存しても有効になります。Officeのバージョンによっては、アドインによるショートカットの変更ができず、**Set key** なしで一覧が表示されます。
