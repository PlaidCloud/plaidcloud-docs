PlaidXLをインストールすると、Excelのリボンに**PlaidCloud**タブが追加され、3つのコマンドグループが表示されます。使用する前に、タスクペインから[サインイン](/ja/reference/cli/plaidxl/connect/)してください。ドリルコマンドは、そこで選択したプロジェクトから読み取ります。

## PlaidXL Controls

| コマンド | 動作 |
|---|---|
| **Show Taskpane** | PlaidXLタスクペインを開きます。 |
| **Refresh All Tables** | ブックに取得したすべてのテーブルの最新データを取り込みます。タスクペインのボタンと同じです。[Refresh All Tables](/ja/reference/cli/plaidxl/retrieve/#refresh-all-tables)を参照してください。 |

## Drill Functions

ドリルコマンドは、数式を書かずに、選択したノードの下にディメンションのノードをレイアウトします。

1. 隣り合う2つのセルに、ディメンション名とその中のノードを入力します。たとえば、`A1`に`Region`、`B1`に`EMEA`と入力します。順序は問いません。
2. 両方のセルを選択します。
3. ドリルコマンドをクリックします。

| コマンド | 選択範囲の下に書き込まれるもの |
|---|---|
| **Drill All** | そのノードと、その下のすべてのノード |
| **Drill Leaves** | そのノードと、その下のリーフのみ |
| **Drill One** | そのノードとその子 |

ノードは選択範囲の下に書き込まれ、世代ごとにインデントされ、Excelのアウトラインにグループ化されるため、各レベルを折りたたむことができます。ドリルコマンドは、ディメンションのメイン階層に従います。代替階層をドリルする場合や、ディメンションが変更されたときにレイアウトを更新する場合は、代わりに[`PLAIDXL.DRILL`](/ja/reference/cli/plaidxl/functions/#drill)関数を使用します。

PlaidXLがディメンションまたはノードを見つけられない場合は、PlaidCloudでスペルを確認し、ちょうど2つのセルが選択されていることを確認してください。

## Control Functions

| コマンド | 動作 |
|---|---|
| **Sanitize Workbook** | ブック内のすべての数式を現在の値に置き換え、数式を記憶します。 |
| **Restore Workbook** | **Sanitize Workbook**が置き換えた数式を元に戻します。 |

PlaidXLを持っていない人や、プロジェクトにアクセスできない人にレポートを送る場合は、**Sanitize Workbook**を使用します。そうしないと、PlaidXLの数式の場所にエラーが表示されます。[値のみのコピーを共有する](/ja/reference/cli/plaidxl/build-a-report/#値のみのコピーを共有する)を参照してください。

<Aside type="caution">
**Sanitize Workbook**は、PlaidXLの関数だけでなく、ブック内の*すべての*数式を置き換えます。新しい名前で保存したコピーをサニタイズし、作業用のレポートはそのまま残してください。同じブックを2回目にサニタイズする前に、**Restore Workbook**を実行してください。
</Aside>
