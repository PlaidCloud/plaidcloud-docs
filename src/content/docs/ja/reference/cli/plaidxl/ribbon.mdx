PlaidXL をインストールすると、Excel のリボンに **PlaidCloud** タブが追加されます。タブには、**接続**、**挿入**、**更新**、**ドリル**、**書き込み**、**共有**の 6 つのコマンドグループがあります。よく使うコマンドは **PlaidXL** の右クリックメニューと **PlaidXL Cell** タブにもあり、キーボードショートカットのあるコマンドには、ツールヒントにそのショートカットが表示されます。

グレーアウトされるコマンドはありません。コマンドは、選択したセルに最も近い PlaidXL の数式、テーブル、ノードに対して動作します。対象がない場合は、代わりに役立つタスクペインの該当部分が開きます。

サインアウトしている状態や、ワークブックがプロジェクトにリンクされる前にコマンドを実行すると、PlaidXL はタスクペインを開き、コマンドを実行するには **Sign in to run**、または **Pick a project to run** と表示します。サインインまたは選択が完了すると、操作を開始したセルでコマンドが実行されます。その間に別のシートへ移動したり、別のプロジェクトを選んだりした場合は、コマンドは実行されず、PlaidXL がその旨を知らせます。

## 接続

| コマンド | 動作 |
|---|---|
| **Open PlaidXL** | PlaidXL のタスクペインを開きます。 |
| **アカウント** | タスクペインを開いて、サインインするか、ワークスペースとプロジェクトを選択します。 |
| **Shortcuts** | PlaidXL のキーボードショートカットを一覧表示し、変更できます。[キーボードショートカット](#キーボードショートカット)をご覧ください。 |
| **Help** | このドキュメントを開きます。 |

## 挿入

| コマンド | 動作 |
|---|---|
| **Table...** | **テーブル**タブを開いて、[テーブルを取得](/ja/reference/cli/plaidxl/retrieve/#テーブルを取得する)します。 |
| **Dimension...** | **ディメンション**タブを開いて、ディメンションを取得するか、そのメンバーを選択します。 |
| **Formula...** | **Formulas** タブを開いて、選択したセルの [PlaidXL 数式を作成](/ja/reference/cli/plaidxl/functions/#タスクペインから数式を挿入する)します。 |
| **Pick member...** | 選択したセルのディメンションに対してメンバーピッカーを開きます。[メンバーを選択する](/ja/reference/cli/plaidxl/drill/#メンバーを選択する)をご覧ください。 |
| **Metric...** | プロジェクトのメトリックを検索できる一覧を、現在の値とともに開きます。[メトリックを挿入する](/ja/reference/cli/plaidxl/functions/#メトリックを挿入する)をご覧ください。 |
| **Build report...** | **Report** タブを開いて、ライブレポートをレイアウトします。[レポートを作成する](/ja/reference/cli/plaidxl/build-a-report/)をご覧ください。 |
| **Ask Weave...** | 選択したセルをコンテキストとして **Weave** タブを開きます。[Excel で Weave に質問する](/ja/reference/cli/plaidxl/weave/)をご覧ください。 |

## 更新

**更新**メニューには 4 つのコマンドがあります。

| コマンド | 動作 |
|---|---|
| **Refresh this sheet** | アクティブなシートの PlaidXL 数式を再計算し、そのテーブルを再取得します。 |
| **Refresh selection** | 選択範囲の PlaidXL 数式を再計算し、選択範囲に含まれるテーブルを再取得します。PlaidXL の要素が何も選択されていない場合は、シートを更新します。 |
| **Refresh all tables** | ワークブック内のすべてのテーブルとディメンションを、それぞれに選択した列とフィルターで再取得します。 |
| **Recalculate PlaidXL formulas** | ワークブック内のすべての PlaidXL 数式を再計算します。 |

更新の実行中に表示される内容については、[テーブルを更新する](/ja/reference/cli/plaidxl/retrieve/#すべてのテーブルを更新する)をご覧ください。

**Recalculate PlaidXL formulas** は、Excel 全体の再計算を行わず、PlaidXL 数式のみを再計算します。完了すると、再計算したシートを一覧表示し、Excel の元に戻す履歴をクリアします。PlaidXL はテーブルの列の詳細を 30 秒間保持するため、直近 30 秒以内に名前を変更した列やディメンションは、表示に少し時間がかかる場合があります。

## ドリル

| コマンド | 動作 |
|---|---|
| **Drill down** | メニュー：**One level**、**To lowest level**、**All levels**、**Custom drill...** で、選択したノードの下のノードをレイアウトします。 |
| **Drill up** | 選択したノードを親にたたみます。 |
| **Keep only** | 選択したノードだけをドリルに残します。 |
| **Remove only** | 選択したノードと、その下のすべてをドリルから削除します。 |
| **Show detail rows** | 選択した値の元になっているテーブルの行を、専用のシートに表示します。 |
| **Explain this number** | 選択した値の出どころを表示します。 |

ドリルするには、1 つのセルを選択します。ドリルコマンドは、そのセルをライブの `PLAIDXL.DRILL` 数式に変換します。[ドリル、メンバーの選択、数値の説明](/ja/reference/cli/plaidxl/drill/)をご覧ください。

## 書き込み

| コマンド | 動作 |
|---|---|
| **Save sheet to PlaidCloud...** | このシートに取得したテーブルを、すぐに PlaidCloud に書き戻します。[テーブルを PlaidCloud に保存する](/ja/reference/cli/plaidxl/retrieve/#テーブルを-plaidcloud-に保存する)をご覧ください。 |
| **Undo last write** | PlaidCloud に最後に入力した値、または最後の保存を、新しいものから順に取り消します。[書き込みを取り消す](/ja/reference/cli/plaidxl/write-values/#書き込みを取り消す)をご覧ください。 |

## 共有

| コマンド | 動作 |
|---|---|
| **Convert to values** | メニュー：**Whole workbook** または **This sheet** は、PlaidXL 数式を現在の値に置き換え、数式を記憶します。**Values only (no restore)** は、元に戻す手段を残さずに置き換えます。 |
| **Restore PlaidXL formulas** | **Convert to values** で置き換えた数式を、ワークブックのすべてのシートで元に戻します。 |

PlaidXL を持っていない人や、プロジェクトにアクセスできない人にレポートを送るときは、**Convert to values** を使います。そうしないと、PlaidXL 数式の部分にエラーが表示されてしまいます。PlaidXL の関数を呼び出すすべての数式が変換されます。`IFERROR` など別の数式の中にあるものや、スピルしたセルも対象です。ワークブック内のそれ以外の内容はそのまま残ります。ワークブック全体に対する **Values only (no restore)** は、先に確認が表示されます：**Convert every PlaidXL formula in the workbook to values only? Restore can't bring them back.** それ以外の選択肢はすぐに実行されます。メッセージには、変換された数式の数が表示されます。まだ計算中の数式（`#BUSY!`）は変換されません。メッセージにその数が表示されるので、完了してからもう一度変換してください。

数式はシートごとに保持されるため、シートの名前を変更したり移動したりした後でも、**Restore PlaidXL formulas** で見つかります。サインインしている必要もありません。[値のみのコピーを共有する](/ja/reference/cli/plaidxl/build-a-report/#値のみのコピーを共有する)をご覧ください。

<Aside type="caution">
作業用のレポートはそのまま残し、新しい名前で保存したコピーを変換してください。**Values only (no restore)** は、**Restore PlaidXL formulas** で元に戻せません。
</Aside>

## 右クリックメニュー

セルを右クリックして **PlaidXL** を選ぶと、次のコマンドを利用できます。それぞれリボンのボタンと同じ動作です。

- **Drill down one level**、**Drill down to lowest level**、**Drill down all levels**、**Custom drill...**、**Drill up**、**Keep only**、**Remove only**
- **Pick member...**
- **Explain this number** と **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...** — そのセルの **Formulas** タブを開きます

## PlaidXL Cell タブ

選択したセルに PlaidXL の数式が入っている場合、PlaidXL の数式の結果の一部である場合、または取得したテーブル内にある場合、Excel は **PlaidCloud** タブの隣に **PlaidXL Cell** タブを表示します。このタブには、そのセル向けのコマンドがまとめられています。

- **ドリル** — **Drill down**（**One level**、**Lowest level**、**All levels**）、**Drill up**、**Keep only**、**Remove**
- **検査** — **説明**、**Detail rows**、**Weave に質問**
- **データ** — **Pick member**、**Refresh selection**、**Save sheet**

別のセルを選択すると、タブは再び非表示になります。アドインのコンテキストタブに対応していないバージョンの Excel では表示されませんが、すべてのコマンドは **PlaidCloud** タブにあります。

## キーボードショートカット

すべてのショートカットは、Windows では **Ctrl+Alt+Shift** とキー、Mac では **⌘⌥⇧** と同じキーです。フィールドに入力している間や AltGr を押している間は、ショートカットは動作しません。リボンのコマンドが失敗した場合は、どのコマンドがなぜ失敗したかがメッセージに表示され、タスクペインが非表示の場合は開きます。

| キー | コマンド |
|---|---|
| **Down** | 1 レベルドリルダウン |
| **上へ** | ドリルアップ |
| **L** | 最下位レベルまでドリルダウン |
| **8** | すべてのレベルをドリルダウン |
| **D** | カスタムドリル |
| **K** | Keep only |
| **X** | Remove only |
| **M** | メンバーを選択 |
| **E** | この数値を説明 |
| **T** | 詳細行を表示 |
| **R** | このシートを更新 |
| **F** | 選択範囲を更新 |
| **A** | すべてのテーブルを更新 |
| **C** | PlaidXL 数式を再計算 |
| **W** | シートを PlaidCloud に保存 |
| **Z** | 最後の書き込みを元に戻す |
| **P** | PlaidXL を開く |
| **N** | 数式を挿入 |
| **B** | レポートを作成 |
| **I** | メトリックを挿入 |
| **Q** | Weave に質問 |

ショートカットを変更するには、**接続**グループの **Shortcuts** をクリックするか、タスクペインのアカウントメニューから **Keyboard shortcuts** を選びます。コマンドの横にある **Set key** をクリックして新しい組み合わせを押し、**保存**をクリックします。**リセット**を押すと元に戻ります。別のコマンドがすでに使っている組み合わせにはマークが付きますが、そのまま保存しても有効になります。一部のバージョンの Office ではアドインによるショートカットの変更ができず、**Set key** のない一覧が表示されます。
