PlaidXLをインストールすると、Excelのリボンに**PlaidCloud**タブが追加されます。コマンドは、**Data**、**Drill Functions**、**Share**の3つのグループに分かれています。使用する前に、作業ウィンドウから[サインイン](/ja/reference/cli/plaidxl/connect/)してください。展開コマンドは、作業ウィンドウでブックにリンクされているプロジェクトから読み取ります。

## Data

| コマンド | 動作 |
|---|---|
| **Open PlaidXL** | PlaidXL作業ウィンドウを開きます。 |
| **Refresh All Tables** | ブックに取得したすべてのテーブルの最新データを取得します。作業ウィンドウのボタンと同じです。[Refresh All Tables](/ja/reference/cli/plaidxl/retrieve/#refresh-all-tables)を参照してください。 |

## Drill Functions

展開コマンドは、数式を書かずに、選択したノードの下にディメンションのノードをレイアウトします。

1. 隣り合う2つのセルに、ディメンション名とそのディメンション内のノードを入力します。たとえば、`A1`に`Region`、`B1`に`EMEA`と入力します。順序は問いません。
2. 両方のセルを選択します。
3. 展開コマンドをクリックします。

| コマンド | 選択範囲の下に書き込まれる内容 |
|---|---|
| **Expand all levels** | そのノードと、その下のすべてのノード |
| **Expand to lowest level** | そのノードと、その下のリーフのみ |
| **Expand one level** | そのノードと、その子 |

ノードは選択範囲の下に書き込まれ、世代ごとにインデントされ、Excelのアウトラインにグループ化されるため、各レベルを折りたたむことができます。展開コマンドは、ディメンションのメイン階層に従います。代替階層を展開する場合や、ディメンションが変更されたときにレイアウトを更新する場合は、代わりに[`PLAIDXL.DRILL`](/ja/reference/cli/plaidxl/functions/#drill)関数を使用します。

PlaidXLがディメンションまたはノードを見つけられない場合は、PlaidCloudと照らし合わせてスペルを確認し、ちょうど2つのセルが選択されていることを確認してください。

## Share

| コマンド | 動作 |
|---|---|
| **Convert to values (for sharing)** | ブック内のすべてのPlaidXL数式を現在の値に置き換え、その数式を記憶します。 |
| **Restore PlaidXL formulas** | **Convert to values (for sharing)** で置き換えた数式を元に戻します。 |

PlaidXLを持っていない人や、プロジェクトにアクセスできない人にレポートを送るには、**Convert to values (for sharing)** を使用します。そうしないと、PlaidXL数式の部分にエラーが表示されます。最初にExcelから確認を求められ、**Cancel**を選択しても何も変更されません。PlaidXL関数を呼び出すすべての数式が変換されます。`IFERROR`など、別の数式の内部にあるものも対象です。それ以外の数式はそのまま残ります。[値のみのコピーを共有する](/ja/reference/cli/plaidxl/build-a-report/#値のみのコピーを共有する)を参照してください。

<Aside type="caution">
変換するのは、新しい名前で保存したコピーにして、作業中のレポートはそのままにしておいてください。同じブックをもう一度変換する前に、**Restore PlaidXL formulas**を実行してください。
</Aside>
