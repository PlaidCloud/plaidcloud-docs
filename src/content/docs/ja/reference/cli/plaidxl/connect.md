PlaidXLは、ブラウザーでPlaidCloudにサインインするときと同じ方法で、あなた自身としてサインインします。サーバーのアドレスを入力する必要はなく、パスワードがブックに保存されることもありません。

## サインインする

1. タスクペインを開きます。**PlaidCloud → Open PlaidXL** をクリックするか、**接続** グループの **アカウント** をクリックします。
2. **Enter your email** の下に、PlaidCloudで使用しているメールアドレスを入力し、**Sign In** をクリックします。PlaidXLは次回のためにアドレスを記憶します。
3. メールアドレスが複数のワークスペースに属している場合は、**Select a workspace** から1つ選び、**Sign In** をクリックします。PlaidXLは選択を記憶します。所属するワークスペースが1つだけの場合は、PlaidXLが自動的に選択します。メールアドレスにワークスペースがリンクされていない場合は、ペインにその旨が表示されます。アドレスを確認して、もう一度お試しください。
4. Excelからポップアップウィンドウの許可を求められます。許可してください。
5. ポップアップで、通常どおりの方法でサインインします。
   - **PlaidCloud sign-in** — メールアドレス、パスワード、および設定済みの2要素コードを使用します。
   - **Single sign-on** — すでに組織にサインインしている場合は、この手順がそのまま通過します。そうでない場合は、先に組織のサインインページが開きます。
6. ポップアップに **Authenticated successfully** と表示されたら、自動的に閉じていない場合は閉じます。

タスクペインのヘッダーに、ワークスペースとブックにリンクされたプロジェクトが表示され、その横にアカウントメニューが表示されます。続いて[テーブルとディメンションを操作する](/ja/reference/cli/plaidxl/retrieve/)に進みます。

アカウントの2要素認証やシングルサインオンを設定するには、[メンバー認証](/ja/administration/access/member-authentication/)を参照してください。

### Officeアカウントでサインインする

Microsoft Entra IDの職場アカウントでOfficeにサインインしていて、PlaidXLに保存済みのサインインがない場合は、そのアカウントからワークスペースが検出されるため、メールアドレスを入力する必要はありません。

- **ワークスペースが1つ** — PlaidXLがそのワークスペースへのサインインを開始します。Excelから求められたらポップアップを許可してください。シングルサインオンの場合は、そのまま通過します。Web版のExcelでは、先に **Continue as** のアカウントをクリックします。
- **ワークスペースが複数** — **Select a workspace** から1つ選択します。そのブックを最後に使用したワークスペースが、すでに選択されています。
- **ワークスペースなし** — アドレスが入力済みの状態で、メール画面が開きます。

Officeアカウントとは異なるメールアドレスでサインインすると、PlaidXLがどのアドレスかを表示します。**Log out** した後は、PlaidXLはあなたが自分でサインインするのを待ちます。

### サインイン前のコマンド

サインインする前でも、リボンの任意のPlaidXLコマンドをクリックできます。PlaidXLがタスクペインを開いてサインインやプロジェクトの選択を促し、その後、開始したセルに対してコマンドを実行します。

## サインインを維持する

PlaidXLはこのコンピューターでサインインを維持し、作業中はバックグラウンドでサインインを更新します。後のセッションでタスクペインを開くと、そのままプロジェクトの一覧が表示されます。サインインが完全に期限切れになった場合は、PlaidXLがメールアドレスをもう一度尋ねます。サインインの更新中に一時的なネットワークの問題が発生しても、サインアウトされることはなく、PlaidXLが再試行します。

## 表示される内容

PlaidXLはあなたの権限で読み取ります。表示されるのは、PlaidCloudで開けるプロジェクトと、その中のテーブルとディメンションだけです。プロジェクトやテーブルが表示されない場合は、プロジェクトのオーナーにアクセスを依頼してください。ワークスペースのメンバーシップの仕組みについては、[組織とワークスペースの解説](/ja/administration/access/overview/organizations-and-workspaces-explained/)を参照してください。

## サインアウトまたはワークスペースの切り替え

タスクペインの右上にあるアカウントメニュー（3つの点）をクリックします。名前とワークスペースが表示され、次の3つのコマンドがあります。

- **Keyboard shortcuts** は、PlaidXLのショートカットを一覧表示し、変更できます。[キーボードショートカット](/ja/reference/cli/plaidxl/ribbon/#キーボードショートカット)を参照してください。
- **Switch workspace** はサインアウトしてメール画面に戻るため、**Select a workspace** で別のワークスペースを選択できます。
- **Log out** はサインインを消去して、メール画面に戻ります。

サインインは、開いているすべてのブックで共有されますが、プロジェクトはブックごとに保持されます。ブックのプロジェクトはワークスペースに属しているため、切り替えた後は、以前のワークスペースのプロジェクトにリンクされているブックは、新しく選択するまでプロジェクトがない状態になります。[プロジェクトはブックに属する](/ja/reference/cli/plaidxl/retrieve/#プロジェクトはブックに属する)を参照してください。

## ライトテーマとダークテーマ

タスクペインはOfficeのテーマに従い、テーマを変更すると切り替わります。

## キーボードとスクリーンリーダー

プロジェクト、テーブル、ディメンションの一覧の行はキーボードフォーカスを受け取り、**Enter** と **Space** に反応します。選択された行はスクリーンリーダーで読み上げられ、選択状態と警告状態には色だけでなくアイコンも付きます。
