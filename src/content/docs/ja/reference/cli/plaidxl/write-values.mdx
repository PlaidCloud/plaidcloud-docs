[`PLAIDXL.CELL`](/ja/reference/cli/plaidxl/functions/#cell) の値は、読み取るためだけのものではありません。値の上に数値を入力すると、PlaidXL はその背後にある PlaidCloud のテーブルに書き込み、数式を元に戻して、シートを再計算します。これにより、レポートには新しい数値と、そこから集計されるすべての値が反映されます。この方法で、予算、予測、調整額をレポートに直接入力できます。

## 値を入力する

1. `PLAIDXL.CELL` の数式が入っているセルを選択します。
2. 数値または下記の[コード](#配分調整形状)のいずれかを入力し、**Enter** を押します。

値はすぐに PlaidCloud に書き込まれ、タスクペインに変更内容が表示されます（例：`Jan·East·Revenue 80 → 100 · 14 rows`）。**元に戻す**ボタンも表示されます。値の範囲を貼り付けたりフィルしたりした場合は、まとめて書き込まれます。

入力した値を受け付けるセルは、`CELL` の数式が 1 つだけ入っているセル、または `CELL` に数値・セル・名前を掛ける、割る、または符号を反転する数式が入っているセルです（例：`=-PLAIDXL.CELL(...)*$B$1/1000`）。PlaidXL は、書き込む前に、入力した値から `CELL` が保持すべき値を逆算します。どの交点に書き込むかを PlaidXL が判断できるように、`CELL` の引数はセルまたはテキストである必要があります。

それ以外は、入力したとおりのまま残ります。

- 数値でもコードでもないテキストはセルにそのまま残り、メッセージには数値と調整のみが書き込まれると表示されます。
- 他の数式の上に入力した値は書き込まれません。
- `CELL` で **Delete** を押すと、数式が元に戻ります。
- `10%` のような正の割合は書き込まれません。値を 10% 増やすには `+10%` を、値を設定するには `0.1` を入力してください。

PlaidCloud の応答に時間がかかりすぎた場合や、セルに対して応答がない場合は、変更が適用された可能性があることがメッセージに表示されます。再度書き込む前に値を確認してください。送信できなかったセルについては、何も書き込まれなかったと表示されます。

行や列を挿入または削除する直前に入力した値は、Excel が移動した先のセルに書き込まれます。その後に削除された行や列に入力した値は書き込まれず、削除または移動されたセルにあった入力値の数がメッセージに表示されます。

### テーブルの変更のされ方

- **合計** — 古い値と新しい値の差が、新しい行として追加されます。新しい行はその交点にすでにある行をコピーし、それぞれの大きさに比例した配分を受け取ります。空の交点では、PlaidXL はそのセルのノードの下にあるリーフメンバーの組み合わせごとに 1 行を追加します。
- **平均**、**中央値**、**最小**、**最大** — 交点にあるすべての行が、その差の分だけ移動します。
- **std** と **var** — 交点にある行は、平均を変えずに、平均の周りで広げられるか、縮められます。

1 回の書き込みで追加される行は最大 100,000 行です。

## 配分、調整、形状

**合計**のセルでは、その下にあるリーフメンバーに値をどう分けるかをコードで指定できます。文字は大文字でも小文字でも構いません。

| 入力 | 動作 |
|---|---|
| `1200` | セルを 1,200 に設定し、各リーフメンバーが現在保持している値に比例して分けます。 |
| `P1200` | 同じ動作を明示的に書いたもので、比例配分です。 |
| `E1200` | セルを 1,200 に設定し、リーフメンバーに均等に分けます。 |
| `R1200` | 各リーフメンバーを 1,200 に設定するため、セルにはメンバー数の 1,200 倍が表示されます。 |
| `1200 like FY2025` | セルを 1,200 に設定し、**FY2025** のセルと同じ形状で分けます。 |
| `+50` または `-50%` | 金額または割合で、値を上下に調整します。 |
| `-50` | セルを -50 に設定します。マイナス記号だけの場合は負の値を設定します。調整するには `%` を付けます。 |
| `H` | セルを固定します。固定されている場合は解除します。 |

数値には、Excel の小数点と桁区切りの記号が使われます。`like` を使う場合、メンバーはセルのディメンションのうち 1 つだけに属している必要があります。2 つに属している場合は、すでにそのメンバーを持っているセルを使ってください。中身のない形状は均等に分けられます。

### 値を固定する

`CELL` に `H` を入力すると固定されます。固定されたセルには破線の枠が付き、同じテーブルと指標の他のセルへの以降の書き込みでは変更されません。親の新しい値は、固定されていないメンバーの間で分けられます。もう一度 `H` を入力すると解除されます。固定するには、`CELL` の引数がセルまたはテキストである必要があります。引数が数式であるセルの場合は、引数がセルまたはテキストであるセルを固定するようメッセージで案内されます。固定はワークブックとともに保存されます。セルの下にあるすべてのメンバーが固定されている場合、そのセルへの書き込みは拒否されます。

コード、形状、固定は**合計**のセルでのみ機能します。

## 書き込みを取り消す

Excel の **Ctrl+Z** では、PlaidCloud への書き込みは元に戻せません。取り消すには、メッセージの**元に戻す**をクリックするか、リボンの**書き込み**グループで **Undo last write** をクリックします（**Ctrl+Alt+Shift+Z**、Mac では **⌘⌥⇧Z**）。

**Undo last write** は、入力した値か[保存](/ja/reference/cli/plaidxl/retrieve/#テーブルを-plaidcloud-に保存する)かを問わず、このワークブックから行った最新の書き込みを取り消します。もう一度クリックすると、その前の書き込みが取り消されます。一覧はワークブックに保存されるため、ファイルを閉じて開き直しても残り、直近 100 件の書き込みが保持されます。

- **入力した値**は、その行を逆の操作で戻すことで取り消され、シートが再計算されます。書き込みを取り消せるのは 1 回だけです。テーブルの列が変更された後は取り消せません。
- **保存**は、保存前に作成された復元ポイントにテーブルを戻します。復元された行を表示するには、シートを更新してください。

書き込みを取り消せるのは、その書き込みを行ったユーザーとワークスペースだけです。他のユーザーの項目は一覧に残り、**This write was made by another user or workspace** と表示されます。すでに取り消された項目には **Already undone or no longer available** と表示されます。ワークブック内に自分の書き込みがない場合は、**Nothing to undo: the writes in this workbook were made by other users or workspaces.** というメッセージが表示されます。取り消しに対する PlaidCloud の応答に時間がかかりすぎた場合は、適用された可能性があることがメッセージに表示されます。もう一度**元に戻す**をお試しください。

## 同時に書き込む他のユーザー

最後の書き込みが優先されます。最後に更新した後で他のユーザーが値を変更していても、あなたの書き込みは実行され、メッセージに `was 80, not 75` のような補足が付きます。これは、シートには 75 と表示されていたものの、入力した時点で PlaidCloud の値は 80 だったことを意味します。

## 行アクセス

テーブルへのアクセスが一部の行に限られている場合、書き込めるのはその範囲内だけです。入力した値は、表示できるメンバーの間で分けられ、アクセス範囲外の行を変更してしまう取り消しは拒否されます。

<Aside>
値の入力には、それを受け付ける PlaidCloud ワークスペースが必要です。ワークスペースが Excel での値の入力にまだ対応していないと PlaidXL に表示された場合は、管理者に更新を依頼してください。
</Aside>
