[`PLAIDXL.CELL`](/ja/reference/cli/plaidxl/functions/#cell) の値は、読み取るだけのものではありません。値の上に数値を入力すると、PlaidXLはその裏付けとなるPlaidCloudのテーブルに書き込み、数式を元に戻して、シートを再計算します。そのため、レポートには新しい数値と、そこから集計されるすべてが反映されます。これが、予算、予測、調整をレポートに直接入力する方法です。

## 値を入力する

1. `PLAIDXL.CELL` 数式を含むセルを選択します。
2. 数値、または以下の[コード](#配分調整形状)のいずれかを入力し、**Enter** を押します。

値はすぐにPlaidCloudに書き込まれ、タスクペインには変更内容が表示されます。たとえば `Jan·East·Revenue 80 → 100 · 14 rows` のように表示され、**元に戻す** ボタンも表示されます。値の範囲を貼り付けるか、フィルすると、まとめて書き込まれます。

セルが入力値を受け付けるのは、単一の `CELL` 数式を含む場合、または `CELL` が数値、セル、名前によって乗算、除算、符号反転されている場合です。たとえば `=-PLAIDXL.CELL(...)*$B$1/1000` です。PlaidXLは、入力された値から、`CELL` が保持すべき値を逆算してから書き込みます。PlaidXLがどの交点に書き込むかを判断できるように、`CELL` の引数はセルまたはテキストである必要があります。

それ以外は、入力したままの状態で残ります。

- 数値でもコードでもないテキストはセルに残り、数値と調整のみが書き込まれるというメッセージが表示されます。
- その他の数式の上に入力した値は、書き込まれません。
- `CELL` で **Delete** を押すと、その数式が元に戻ります。
- `10%` のような正のパーセンテージは書き込まれません。値を10%増やすには `+10%`、値を設定するには `0.1` と入力します。

### テーブルの変更のされ方

- **sum** — 古い値と新しい値の差が、新しい行として追加されます。その交点にすでにある行をコピーし、それぞれの大きさに比例した配分を受け取ります。空の交点では、PlaidXLは、セルのノードの配下にあるリーフメンバーの組み合わせごとに1行を追加します。
- **mean**、**median**、**min**、**max** — 交点にあるすべての行が、差の分だけ移動します。
- **std**、**var** — 交点にある行は、平均を変えないまま、平均の周りで広げられるか、狭められます。

1回の書き込みで追加される行は、最大100,000行です。

## 配分、調整、形状

**sum** のセルでは、コードを入力して、その配下のリーフメンバーに値をどう配分するかを選択できます。文字は大文字でも小文字でも構いません。

| 入力 | 動作 |
|---|---|
| `1200` | セルを1,200に設定し、各リーフメンバーが現在保持している値に比例して配分します。 |
| `P1200` | 同じ動作を明示的に記述したもの：比例配分です。 |
| `E1200` | セルを1,200に設定し、リーフメンバーに均等に配分します。 |
| `R1200` | 各リーフメンバーを1,200に設定するため、セルにはメンバー数の1,200倍が表示されます。 |
| `1200 like FY2025` | セルを1,200に設定し、**FY2025** のセルと同じ形で配分します。 |
| `+50` または `-50%` | 値を、金額またはパーセンテージで増減して調整します。 |
| `-50` | セルを-50に設定します。マイナス記号だけの場合は負の値を設定します。調整するには `%` を付けます。 |
| `H` | セルを保持します。すでに保持されている場合は解除します。 |

数値には、Excelの小数点と桁区切りの記号が使用されます。`like` では、メンバーはセルのディメンションのうち1つだけに属している必要があります。2つに属している場合は、すでにそれを持っているセルを使用してください。何も含まれていない形状は、均等に配分されます。

### 値を保持する

`CELL` の上に `H` と入力すると、保持されます。保持されたセルには破線の枠線が付き、同じテーブルとメジャーの他のセルへの後続の書き込みでも、そのまま変更されません。親の新しい値は、保持されていないメンバーに配分されます。もう一度 `H` と入力すると、解除されます。保持はブックとともに保存されます。セルの配下のすべてのメンバーが保持されている場合、そのセルへの書き込みは拒否されます。

コード、形状、保持は、**sum** のセルでのみ機能します。

## 書き込みを元に戻す

Excelの **Ctrl+Z** では、PlaidCloudへの書き込みは取り消されません。取り消すには、メッセージの **元に戻す** をクリックするか、リボンの **書き込み** グループの **Undo last write** をクリックします（**Ctrl+Alt+Shift+Z**、Macでは **⌘⌥⇧Z**）。

**Undo last write** は、このブックから行われた最新の書き込みを元に戻します。入力した値でも、[保存](/ja/reference/cli/plaidxl/retrieve/#テーブルを-plaidcloud-に保存する)でも同様です。もう一度クリックすると、その前の書き込みを元に戻します。この一覧はブックに保持されるため、ファイルを閉じて開き直しても残り、最新の100件の書き込みが保持されます。

- **入力した値**は、その行を逆の操作で元に戻すことで取り消され、シートが再計算されます。書き込みを元に戻せるのは1回だけです。テーブルの列が変更された後は、元に戻せません。
- **保存**は、その前に作成された復元ポイントにテーブルを戻します。復元された行を確認するには、シートを更新してください。

## 同時に書き込む他のユーザー

最後の書き込みが優先されます。最後に更新した後で他のユーザーが値を変更していても、書き込みは実行され、メッセージに `was 80, not 75` のような情報が追加されます。これは、入力した時点でPlaidCloudが保持していた値が、シートに表示されていた75ではなく80だったことを示します。

## 行アクセス

テーブルへのアクセスが一部の行に限定されている場合、書き込めるのはその範囲内のみです。入力した値は、表示できるメンバーに配分され、アクセス範囲外の行を変更することになる元に戻す操作は拒否されます。

<Aside>
値の入力には、それを受け付けるPlaidCloudワークスペースが必要です。ワークスペースがExcelで入力した値にまだ対応していないとPlaidXLに表示された場合は、管理者に更新を依頼してください。
</Aside>
