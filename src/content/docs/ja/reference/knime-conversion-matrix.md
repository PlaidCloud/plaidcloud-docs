PlaidCloud は、KNIME ワークフロー（`.knwf`）とワークフローグループ（`.knar`）をネイティブの高度なワークフローに変換します。インポーターは各 KNIME ノードをワークフローのステップ、プロジェクト変数、またはキャンバスオブジェクトにマッピングし、メタノードとコンポーネントをフラット化するため、変換後のワークフローはクラウドネイティブで実行されます。

KNIME ノード設定の 98.5% が完全に変換され、207 のコアノードタイプのうち 205 が完全対応です。変換の手順については、[KNIME ワークフローの移行](/ja/guides/workflows/migrate-knime-workflows/)を参照してください。

各ノードには次のいずれかのステータスがあります。

- **完全** — ノードに PlaidCloud のステップへの有効なマッピングがあります。
- **一部対応** — ノードは一般的な用途では変換されますが、特定の*機能モード*が1つ再現されません。そのモードは明記されています。
- **未対応** — 変換されません。ノードは名前付きのプレースホルダーとしてキャンバスに残り、その機能はネイティブに再構築します。

ノードの旧バージョンや非推奨バージョンは、それらに置き換わるノードの項に記載しています。

変換後のワークフローで再現されないわずかな動作は、[既知のエッジケース](#既知のエッジケース)に記載しています。

コネクターノードは、そのステップが実行される PlaidCloud の接続になります。詳細は[外部システムへの接続](#外部システムへの接続)を参照してください。

## ノードの対応状況

207 のコアノードのうち、完全対応が 205、一部対応が 2、未対応が 0 です。

## フロー制御とアーカイブ形式

フロー変数、変数のオーバーライド、スイッチ、ループは、その値が変換時に判明している場合に変換されます。ローダーは、確認されているすべてのアーカイブレイアウトを受け付けます。ワークフローのバージョン、メタノード、コンポーネント（アーカイブに保存された本体からインライン化）、グループアーカイブに対応しています。

| ノード | ステータス | PlaidCloud での相当機能 | 変換内容 |
| --- | --- | --- | --- |
| Flow control, variables, and loops | 完全 | プロジェクト変数、除去されたスイッチ、展開されたループ | フロー変数、変数のオーバーライド、スイッチ、ループは、その値が変換時に判明している場合に変換されます。 |
| Archive formats | 完全 | ワークフローのインポート | サポートされているすべての KNIME アーカイブレイアウトを読み取ります。ワークフローのバージョン、メタノード、コンポーネント、グループアーカイブです。 |

## 拡張ノードファミリー

KNIME の拡張ファミリーのノードも、標準の PlaidCloud ステップに変換されます。対象は、データベース、REST と Web サービス、Python・R・Java のスクリプト、機械学習、JSON と XML、テキスト処理、通知とレポート、時系列、地理空間、ビッグデータ、画像処理、化学、ワークフローサービス、およびコアのユーティリティノードの多数の少数派です。変換パスのないノードは、名前付きのプレースホルダーとして保持されます。[未変換](#未変換)を参照してください。

## 未変換

変換パスのないノードは、名前付きのプレースホルダーとしてキャンバスに保持されます。プレースホルダーはデータをそのまま渡し、KNIME ノードの名前を示す警告を追加します。変換が失敗することはありません。欠落している入力やバインドされていない入力は、エラーではなく警告になります。プレースホルダーの下流にあるステップにはフラグが付くため、結果の欠落が見過ごされることはありません。

## 外部システムへの接続

KNIME のコネクターノードは、そのステップが実行される接続になります。認証情報はインポートされないため、各接続はターゲットのワークスペースで選択するものになり、ステップの警告に設定すべき内容が示されます。

| KNIME | PlaidCloud で設定する内容 |
| --- | --- |
| Database connectors | データベース接続。変換時にバインドするか、ステップで選択します。 |
| REST and web service nodes that sign in | [REST 接続](/ja/reference/connectors/rest/generic-rest/)。変換時にバインドするか、ステップで選択します。 |
| Speech Recognizer (IBM Watson) | Watson サービスの URL への REST 接続。Basic 認証のログインはユーザー `apikey` で、パスワードには API キーを使用します。 |
| Email Connector, Email Reader, Email Mover | メールサーバーのパスワード。ステップの警告に示されたプロジェクト変数に設定します。ホストとユーザーは Email Connector から取得されます。 |
| Password-protected Excel workbooks | ブックのパスワード。ステップの警告に示されたプロジェクト変数に設定します。 |
| LLM connectors and authenticators | AIステップの LLM 接続。 |
| Views, charts and reporting layout | 設定は不要です。これらのノードはデータに影響せず、変換レポートに記載されます。 |

変換が、ソースシステムやターゲットシステムに接続することはありません。

## 既知のエッジケース

| ノード | 異なる点 |
| --- | --- |
| Crosstab | [Table: Pivot](/ja/reference/workflow-steps/tables/table-pivot/) に変換されます。まだ再現されないもの: KNIME と結果が異なる、いくつかの設定の組み合わせ。 |

## 変換後のワークフローの確認

行の順序と RowID は、それらを読み取るノードを通じて引き継がれるため、行の順序に依存するワークフローは、それらのノードを通しても順序が保たれます。変換後のワークフローの出力と、元の KNIME ワークフローの出力を比較してください。比較するのは、スキーマ、行数、行の値です。
