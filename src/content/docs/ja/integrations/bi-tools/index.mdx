Power BI、Excel、Tableau、Python、DBeaver などのツールは、PlaidCloud の BI フィードを通じてプロジェクトのテーブルを直接読み取れます。フィードは読み取り専用で、2 つの接続方法があります。

- **OData**: Power BI、Excel、Tableau が、すでに備えている OData コネクタで読み取るフィードです。
- **Arrow Flight SQL**: 独自の SQL ステートメントを受け取り、結果を Arrow として返します。Python、DBeaver、Tableau Desktop 向けです。

各ツールは、プロジェクトに追加して使用する BI フィードクライアント（作成したクライアント ID とシークレット）でサインインします。クライアントは、所有者であるあなたが読み取れる範囲でプロジェクトを読み取ります。

## どの接続を使用すればよいですか

| ツール | 接続方法 |
| --- | --- |
| Power BI Desktop | [OData](/ja/integrations/bi-tools/odata/#power-bi-desktop) |
| Power BI Service | [OData](/ja/integrations/bi-tools/odata/#power-bi-service) |
| Excel | [OData](/ja/integrations/bi-tools/odata/#excel) |
| Tableau Cloud | [OData](/ja/integrations/bi-tools/odata/#tableau) |
| Tableau Desktop と Tableau Server | Arrow Flight SQL JDBC ドライバーを使用する [Flight SQL](/ja/integrations/bi-tools/flight-sql/#tableau-desktop-と-tableau-server)、または [OData](/ja/integrations/bi-tools/odata/#tableau) |
| Python（pandas、polars、DuckDB） | ADBC を使用する [Flight SQL](/ja/integrations/bi-tools/flight-sql/#python) |
| DBeaver | [Flight SQL](/ja/integrations/bi-tools/flight-sql/#dbeaver) |

どちらも、同じクライアントを使用して、同じ行アクセスで同じテーブルを読み取ります。OData は 1 回のリクエストで最大 1,000,000 行を返します。Lakehouse v2 では、より大きなテーブルを[ページ単位で提供](/ja/integrations/bi-tools/odata/#ページ単位で提供されるテーブル)できます。それ以外の場合は、フィルターまたは増分更新で読み取ります。Flight SQL に行数の上限はありません。

OData と Flight SQL では、テーブルと列の名前の付き方が異なります。OData は名前に含まれるスペースや記号をアンダースコアに変えるため、列 `FULL YEAR` は `FULL_YEAR` になります。Flight SQL はプロジェクトが付けた名前をそのまま保持するため、SQL では `"FULL YEAR"` のように引用符で囲みます。

## 外部アクセスを有効にする

BI フィードは、ワークスペースで外部データベースアクセスが有効になっている場合にのみ利用できます。PlaidCloud が、接続を許可するアドレス範囲とともに設定します。有効にする場合や範囲を変更する場合は、PlaidCloud サポートにお問い合わせください。[ワークスペースの設定](/ja/administration/control-plane/workspace-configuration/#lakehouse)を参照してください。

許可するアドレス範囲によって、BI フィードに接続できるアドレスが決まります。

- ツールが接続する元のアドレス範囲（オフィスや VPN など）を CIDR 形式で依頼してください。
- Tableau Cloud のようにクラウドで更新するサービスは、独自のアドレスから接続するため、そのアドレスも許可する必要があります。
- 範囲が設定されていない場合、フィードはどのアドレスからの接続も受け付け、保護はクライアントのシークレットだけになります。
- 拒否するアドレス範囲は BI フィードには適用されません。

<Aside type="note">
Power BI Service は、Microsoft の共有クラウドアドレスから更新を行いますが、そのアドレスは数が多すぎて一覧にできません。Power BI Service から更新するには、PlaidCloud サポートに範囲を設定しないよう依頼してください。フィードはすべてのアドレスを受け付け、クライアントのシークレットだけが保護になります。
</Aside>

## BI フィードクライアントを作成する

1. Analyze で**ツール**を開き、**登録済みシステム(OAuthクライアント)** を選択します。
2. **新しいシステムを登録（OAuthクライアント）** を選択します。
3. **名前**を入力し、**タイプ**で **BI / 外部データフィード**を選択します。
4. **作成**を選択します。
5. **BI フィードクライアントのシークレット**ウィンドウに、**クライアントID**と**クライアントシークレット**が表示されます。シークレットは再表示されないため、今すぐ両方をコピーしてください。

同じウィンドウには、プロジェクトの ID を入れる場所にプレースホルダーを使用したフィードのアドレスも表示されます。各プロジェクトの**アクセスと共有**ページには、そのプロジェクト自身のアドレスが、コピーできる形で表示されます。

**登録済みシステム(OAuthクライアント)** では、BI フィードクライアントの**タイプ**列に **BI / 外部データフィード**と表示されます。API クライアントとは異なり、コピーする構成はなく、シークレットを再度読み取ることもできません。シークレットを紛失した場合や、他の人に見られた可能性がある場合は、クライアントの行で**シークレットを再生成**を選択し、続けて**再生成**を選択します。新しいシークレットは作成時と同様に 1 回だけ表示され、古いシークレットはすぐに使えなくなるため、新しいシークレットを渡すまで、それを使用しているすべてのツールが失敗します。

クライアントがデータを読み取れないようにするには、クライアントを編集して**有効**をオフにするか、削除します。

## クライアントをプロジェクトに追加する

新しいクライアントは、プロジェクトに追加するまで何も読み取りません。

1. プロジェクトの[ホーム](/ja/guides/projects/project-home/#アクセスと共有)を開き、**アクセスと共有**を選択します。
2. **BI フィードクライアント**カードで、**クライアントを追加 ›** を選択します。
3. **BI フィードクライアント**と、その**ロール**として**エクスプローラー**または**マネージャー**を選択します。
4. **追加**を選択します。

<Aside type="caution" title="クライアントに表示されるのは、そのロールに表示されるテーブルだけです">
マネージャーのクライアントには、テーブルの**マネージャー**ボックスがオンの場合にのみそのテーブルが表示され、エクスプローラーのクライアントには、**エクスプローラー**ボックスがオンの場合にのみ表示されます。両方のボックスがオフのテーブルは、どのクライアントも読み取れないため、すべてのテーブルで両方がオフのプロジェクトでは、ツールはサインインできてもテーブルが一覧に表示されません。アーキテクトは、プロジェクトの **Tables** タブでボックスをオンにします。[テーブルを閲覧ロール向けにマークする](/ja/guides/projects/managing-tables-and-views/#閲覧ロール用にテーブルをマークする)を参照してください。
</Aside>

クライアントをアーキテクトにすることはできません。アーキテクトは、ボックスの設定にかかわらずすべてのテーブルを閲覧できるため、フィードに含めるテーブルは、クライアントのロールと、各テーブルのそのロールのボックスで選びます。

クライアントを追加するには、プロジェクトのアーキテクトやワークスペース管理者のように、プロジェクトのアクセスを変更できる必要があり、追加できるのは自分が所有するクライアントだけです。クライアントがない場合は、ウィンドウにその旨が表示され、**登録済みシステムを開く**が提供されます。クライアントを追加できない場合は、カードにその理由が表示されます。

カードには、プロジェクトを読み取るクライアントがそれぞれのロールとともに一覧表示されます。プロジェクトのアーキテクトまたはワークスペース管理者にはすべてのクライアントが、それ以外のユーザーには自分のクライアントだけが表示されます。OData 用のプロジェクトの**フィード URL**と、Flight SQL 用の **JDBC URL** も表示されます。クライアントの行の**削除**で、そのクライアントをプロジェクトから外します。プロジェクトのアーキテクトまたはワークスペース管理者は任意のクライアントを削除でき、所有者は自分のクライアントを削除できます。

## クライアントが読み取る内容

BI フィードクライアントは、作成した人である所有者として読み取ります。

- **テーブル:** [上記](#クライアントをプロジェクトに追加する)のとおり、そのロールに表示されるプロジェクトのテーブルです。ビューは含まれません。
- **行:** 所有者の[行アクセス](/ja/administration/access/managing-security-groups-and-assignments/#行アクセスの管理)で許可されている行だけです。所有者がプロジェクトのアーキテクトであっても同様で、フィードを通じた読み取りでは、所有者のセキュリティグループが行を決定します。
- **所有者に権限がある間:** 所有者は、引き続きプロジェクトを開き、そのテーブルを読み取れる必要があります。プロジェクトへのアクセス権を失った場合や、アカウントが無効になった場合は、1 分以内にクライアントが動作しなくなります。
- **読み取り専用:** クライアントが送信するものでデータを変更することはできません。

<Aside type="caution">
クライアントの ID とシークレットを知っている人は、所有者としてプロジェクトを読み取れます。シークレットはパスワードとして扱い、ツール自身の認証情報の設定に保存し、他の人に見られた可能性がある場合は再生成してください。シークレットは BI フィードでのみ使用できます。REST API、JSON-RPC、MCP サーバーはこのシークレットを拒否します。
</Aside>

## 接続の詳細

アドレスは、入力せずに、プロジェクトの **BI フィードクライアント**カードからコピーしてください。表の `<workspace host>` は、PlaidCloud を開くアドレスです。

| | OData | Flight SQL |
| --- | --- | --- |
| アドレス | `https://odata.<workspace host>/v1/projects/<project id>/` | `grpc+tls://flightsql.<workspace host>:443` |
| JDBC URL | | `jdbc:arrow-flight-sql://flightsql.<workspace host>:443/?useEncryption=true&project_id=<project id>` |
| ユーザー名 | クライアント ID | クライアント ID |
| パスワード | クライアントシークレット | クライアントシークレット |
| プロジェクト | アドレスの一部 | `project_id` 接続プロパティ |

## ツールがサインインできない、またはテーブルが表示されない場合

ツールがフィードにまったく接続できない場合は、ワークスペースで外部データベースアクセスが有効になっていて、ツールの接続元アドレスが許可されているかどうかの確認を、PlaidCloud サポートに依頼してください。接続できた後は、次のメッセージで問題がわかります。

| ツールの表示 | 対応 |
| --- | --- |
| サインインはできるが、テーブルが一覧に表示されない。 | クライアントには、そのロールに表示されるテーブルだけが表示されます。読み取らせたい各テーブルで、クライアントのロールに応じて**マネージャー**または**エクスプローラー**のボックスをオンにします。[クライアントをプロジェクトに追加する](#クライアントをプロジェクトに追加する)を参照してください。 |
| Sign in with the client id and secret of a BI feed client. | ツールがユーザー名とパスワードを送信しませんでした。基本（ユーザー名とパスワード）認証を選択します。 |
| The client id or secret is wrong, or the client is not a BI feed client. | クライアント ID とシークレットを確認します。同じメッセージは、無効または削除されたクライアント、API クライアント、所有者のアカウントが無効なクライアントにも表示されます。 |
| This client may not read this project. | **アクセスと共有**で、クライアントをプロジェクトに追加します。すでに追加されている場合は、所有者がプロジェクトを開けなくなっている可能性があります。 |
| Too many requests. Try again later. (OData)<br />Too many attempts. Try again in … seconds. (Flight SQL) | 同じアドレスから短時間に多数のサインイン試行がありました。しばらく待ってから、正しいシークレットでもう一度試します。 |
| PlaidCloud could not check these credentials just now. Try again shortly. | PlaidCloud 側の一時的な問題です。もう一度試します。 |
| The gateway is busy. Try again shortly. (OData)<br />The gateway is busy. Try again in 30 seconds. (Flight SQL) | フィードが同時に処理できる上限まで読み取りを処理しています。もう一度試します。 |
