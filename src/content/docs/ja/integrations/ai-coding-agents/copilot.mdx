VSCodeのGitHub Copilotの[エージェントモード](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot)は、ワークスペース用の`.vscode/mcp.json`、またはVSCode全体の`mcp.json`（ユーザー用）を通じて、MCPサーバーをサポートしています。

<Aside type="note">IDE上のGitHub Copilotではなく、Teamsやこのアプリに組み込まれたアシスタントである**Microsoft 365 Copilot**をお探しですか？ [Microsoft 365 Copilot](/ja/integrations/microsoft-365-copilot/)を参照してください。</Aside>

これらの手順は、PlaidCloud自身の**AIを接続**ウィンドウからも確認できます。GitHub Copilotは、Gemini CLIやCodex CLIとともに、**その他**タブにあります。

<Aside>CopilotのMCPサポートは、Copilotのプランのティアと、VSCodeの`chat.mcp.enabled`設定によって制限されます。サーバーを設定する前に、両方が有効になっていることを確認してください。</Aside>

## セットアップ

1. PlaidCloudにサインインしているブラウザーで`https://<your-workspace>.plaid.cloud/mcp/setup/token`にアクセスして、ベアラートークンを取得します。

2. VSCodeでコマンドパレットを開いて**MCP: Add Server**を実行するか、`.vscode/mcp.json`を直接作成します。

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. VSCodeを再読み込みします。Copilotのチャットパネルを開き、モードのドロップダウンを**エージェント**に切り替えて、PlaidCloudのツールがツールの一覧に表示されることを確認します（通常は`plaidcloud_*`として表示されます）。

## 使用方法

CopilotにPlaidCloudの操作を直接依頼します。

- 「プロジェクト`Q4 Forecast`で、直近の実行が失敗したワークフローをすべて探してください。」
- 「テーブル`customers`のスキーマを表示して、インデックスを提案してください。」
- 「`daily-load`ワークフローを実行して、実行状況を報告してください。」

Copilotは適切なツールを選んで実行し、結果を返信に引用します。破壊的な操作（削除、整理、`dry_run`なしのアップサート）では、通常、確認を求められます。承認する前に、予定されている操作を確認してください。

## トークンの更新

VSCodeは、起動時とファイルの変更時に`.vscode/mcp.json`を読み取ります。トークンの有効期限が切れたら、`https://<your-workspace>.plaid.cloud/mcp/setup/token`を再読み込みして、`Authorization`の値を上書きしてください。VSCodeはサーバーを自動的に再読み込みします。

## 特定のツールに制限する

CopilotがPlaidCloudのどのツールを呼び出せるかを制限したい場合は、VSCodeのサーバーごとのツール許可リスト（Settings → Copilot → MCP → サーバー別のツール選択）を使用します。読み取り専用のセッションや、変更を行うツール（`*_upsert`、`*_run`）を明示的に再有効化するまで使えないようにしたい場合に役立ちます。
