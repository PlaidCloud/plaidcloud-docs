VSCode の GitHub Copilot の[エージェントモード](https://docs.github.com/copilot/using-github-copilot/copilot-chat-in-ide/using-mcp-with-copilot)は、ワークスペースまたはユーザースコープの `.vscode/mcp.json`（ワークスペース）、またはグローバルな VSCode の `mcp.json`（ユーザー）を通じて、MCP サーバーをサポートしています。

<Aside type="note">IDE の GitHub Copilot ではなく、Teams や Microsoft 365 アプリのアシスタントである **Microsoft 365 Copilot** をお探しですか？ [Microsoft 365 Copilot](/ja/integrations/microsoft-365-copilot/)を参照してください。</Aside>

これらの手順は、PlaidCloud 独自の **AIを接続**ウィンドウ（アバターメニュー内）からも確認できます。GitHub Copilot は、Gemini CLI や Codex CLI とともに、**その他**タブにあります。

<Aside>Copilot の MCP サポートは、Copilot のプランのティアと、VSCode の `chat.mcp.enabled` 設定によって制限されます。サーバーを構成する前に、両方が有効になっていることを確認してください。</Aside>

## セットアップ

1. PlaidCloud にサインインしているブラウザーで `https://<your-workspace>.plaid.cloud/mcp/setup/token` にアクセスし、ベアラートークンを取得します。

2. VSCode でコマンドパレットを開いて **MCP: Add Server** を実行するか、`.vscode/mcp.json` を直接作成します。

    ```json
    {
      "servers": {
        "plaidcloud": {
          "type": "http",
          "url": "https://<your-workspace>.plaid.cloud/mcp",
          "headers": {
            "Authorization": "Bearer eyJhbGc…"
          }
        }
      }
    }
    ```

3. VSCode を再読み込みします。Copilot のチャットパネルを開き、モードのドロップダウンを **Agent** に切り替えて、PlaidCloud のツールがツール一覧に表示されていることを確認します（通常は `plaidcloud_*` として表示されます）。

## 使用方法

Copilot に PlaidCloud の操作を直接依頼します。

- 「プロジェクト `Q4 Forecast` で、最後の実行が失敗したワークフローをすべて見つけて。」
- 「テーブル `customers` のスキーマを表示して、インデックスを提案して。」
- 「`daily-load` ワークフローを実行して、実行ステータスを報告して。」

Copilot は適切なツールを選んで実行し、結果を返信で引用します。破壊的な操作（削除、整理、`dry_run` なしのアップサート）では、通常は確認を求められます。承認する前に、計画された操作を確認してください。

## トークンの更新

VSCode は、起動時とファイルの変更時に `.vscode/mcp.json` を読み取ります。トークンの有効期限が切れたら、`https://<your-workspace>.plaid.cloud/mcp/setup/token` を再読み込みして `Authorization` の値を上書きしてください。VSCode はサーバーを自動的に再読み込みします。

## 特定のツールへの制限

Copilot が呼び出せる PlaidCloud のツールを制限したい場合は、VSCode のサーバーごとのツール許可リストを使用します（設定 → Copilot → MCP → サーバー固有のツール選択）。これは、読み取り専用のセッションや、変更を伴うツール（`*_upsert`、`*_run`）を明示的に再度有効にしないと使えないようにしておきたい場合に便利です。
