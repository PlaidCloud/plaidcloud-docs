コンシューマー向けのClaudeアプリは、[claude.ai](https://claude.ai)のWeb UIもデスクトップアプリも、**Custom Connectors**機能を通じてMCPサーバーをサポートしています。設定は一度だけのOAuthの手続きで、その後は接続がClaudeアカウントに関連付けられ、デバイスをまたいで引き継がれます。

<Aside>Custom Connectorsは、Claude Pro、Max、Team、Enterpriseの各プランで利用できます。TeamとEnterpriseの管理者は、ワークスペースの全員向けにコネクターを固定できます。</Aside>

## セットアップ

1. Claude（Webまたはデスクトップ）で、**Settings → Connectors** を開きます。
2. **Add custom connector** をクリックします。
3. 次の内容を入力します。
   - **名前**：`PlaidCloud`（複数のテナントがある場合は、`PlaidCloud (prod)`、`PlaidCloud (dev)`など）。
   - **サーバーURL**：`https://<your-workspace>.plaid.cloud/mcp`
4. **追加**をクリックします。ClaudeがブラウザーのタブでPlaidCloudのKeycloakログインを開きます。
5. サインインした後、続いて表示される**Application Access Request**ページで承認します。このページには、要求元のアプリケーションと認証情報の送信先となるリダイレクトURIが表示されるため、承認する前に、両方がClaudeと一致していることを確認してください。接続が保存された状態で、Claudeにリダイレクトされます。

これで、コネクターはすべての会話で利用できます。チャット入力欄のコネクターピッカーで、オン／オフを切り替えます。

## 使用方法

有効にすると、Claudeに次のような依頼ができます。

- 「プロジェクト`Q4 Forecast`のワークフローを一覧表示してください。」
- 「`daily-load`ワークフローの直近10件の失敗した実行を表示してください。」
- 「`mcp_recipes`を実行して、ステップのバックフィルに適したものを選んでください。」

Claudeは適切なMCPツールを選んで呼び出し、その応答を返信に反映します。変更を伴う操作では、通常、これから行うことを説明するため、承認する前によく確認してください。

## 複数のテナント

テナントごとに別々のコネクターを追加してください。会話の中でClaudeが区別できるように、それぞれ異なる名前を付けます。特定のチャットで利用できるのは、オンに切り替えたコネクターだけです。本番環境をデフォルトでオフにしておき、確実な場合にだけ有効にすることは、安全のための賢明な習慣です。

## アクセスの更新

Custom ConnectorsにはOAuth更新トークンが保存されるため、再認証が必要になることはまれです。PlaidCloudのパスワードを変更した場合、新しいデバイスを使用する場合、またはサーバー側でセッションが無効化された場合は、コネクターに「needs authentication」と表示されることがあります。コネクターの設定で**Reconnect**をクリックして、OAuthの手順をやり直してください。

## 接続の解除

Settings → Connectors → コネクターをクリック → **削除**の順に選択します。これにより、Claudeアカウントに保存されているOAuthトークンが削除されます。PlaidCloud側のセッションは独立しています。基盤となるKeycloakのセッションを無効にする場合は、PlaidCloudから別途ログアウトしてください。
