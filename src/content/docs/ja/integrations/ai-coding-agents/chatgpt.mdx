ChatGPTでのユーザーによるMCPサーバーの追加のサポートは、まだ順次展開中で、プランのティアや利用する画面によって異なります。このページでは、現時点で動作する方法を説明します。

## ChatGPT Pro / Plus / Team：コネクター

ChatGPTのプランで**コネクター**UI（Settings → コネクター）が利用できる場合は、PlaidCloudをカスタムMCPコネクターとして追加できます。

1. **Settings → コネクター → Add custom connector** の順に選択します。
2. 次の内容を入力します。
   - **名前**：`PlaidCloud`
   - **MCPサーバーのURL**：`https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPTがOAuthログインのためにPlaidCloudへリダイレクトします。サインインすると、PlaidCloudに、要求元のアプリケーションと認証情報の送信先となるリダイレクトURIが表示される**Application Access Request**ページが開きます。承認する前に、これらがChatGPTと一致していることを確認してください。
4. コネクターを使用する会話で、コネクターをオンに切り替えます。

<Aside>コネクターUIは、すべてのアカウントやすべてのリージョンで表示されるとは限りません。「Add custom connector」が表示されない場合は、プランまたはワークスペースのポリシーで、現在ユーザーによるMCPサーバーの追加が許可されていません。その場合は、以下の回避策を使用してください。</Aside>

## ChatGPT Enterprise

Enterpriseの管理者は、管理コンソールからワークスペースレベルでMCPコネクターを固定できます。上記と同じOAuthの設定に従いますが、コネクターを使用できるようになる前に、管理者によるワークスペースの承認手順が必要になります。

## 回避策：REST Actionsを使ったカスタムGPT

アカウントでカスタムMCPコネクターがサポートされていない場合でも、PlaidCloudのREST APIをOpenAPI Actionとして呼び出す**カスタムGPT**を使えば、ChatGPTからPlaidCloudを操作できます。

1. PlaidCloudのRESTインターフェースは、`https://<your-tenant>.plaidcloud.org/openapi_rest.json`のOpenAPIドキュメントで記述されています。
2. ChatGPTでカスタムGPTを作成し（Explore GPTs → Create）、**アクション**でそのURLをインポートします（またはJSONを貼り付けます）。
3. 認証を**OAuth**に設定し、PlaidCloudのKeycloakエンドポイントを指定します。レルムのURLとクライアントIDは、PlaidCloudの管理者から入手できます。

この方法では、MCPのツール名の規約の代わりに、REST エンドポイントを直接使用します。モデルが操作する際にはやや冗長になりますが、PlaidCloudが公開する読み取り/書き込み操作については機能的に同等です。

## MCPが常に利用できるとは限らない理由

OpenAIのMCPサポートは進化を続けており、利用できる画面（コネクターUI、Actionsスキーマなど）は、プランのティアや時期によって変わります。公式の**コネクター**の方法がアカウントで利用できる場合は、そちらを優先してください。OAuthの更新が組み込まれており、このセクションの他のページと同じツール呼び出しの体験が得られます。カスタムGPTのActionsへの切り替えが必要になるのは、アカウントでMCPがまだ利用できない場合のみです。
