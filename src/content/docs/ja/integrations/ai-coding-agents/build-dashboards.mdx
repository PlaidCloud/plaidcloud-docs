AIアシスタントを PlaidCloud の [MCPサーバー](../getting-started/)に接続し、プロジェクト内のテーブルやビューのチャート、またはダッシュボード全体を依頼します。必要なのは PlaidCloud コネクターだけです。アシスタントはあなたとして作成するため、チャートにできるのはあなたがすでに開けるデータだけで、[行アクセス](/ja/guides/dashboards/control-who-can-see-a-dashboard/)もほかの場所と同じように適用されます。

> Sales Results テーブルから*月別の純売上*をチャートにして、Sales Overview という新しいダッシュボードに追加してください。

## 始める前に

- **先にテーブルを公開します。** チャートを作成できるのは、PlaidCloud で公開されているテーブルまたはビューだけです。公開されていない場合はアシスタントが公開するよう伝えるので、公開してから再度依頼します。
- **ダッシュボードサイトを一度開きます。** ダッシュボードサイトを一度も開いたことがないメンバーは、最初の依頼の前に一度開く必要があります。それまでは、アカウントがまだ設定されていないとアシスタントが報告します。
- **サインイン済みの接続を使います。** チャートとダッシュボードを作成できるのは、あなた自身が接続してサインインしたアシスタントです。Microsoft 365 Copilot、PlaidCloud のアプリ内アシスタント、ワークフローのステップ、サービスアカウントでは作成できません。

## チャート

チャートを依頼するときは、何を測定し、どのように分割するかを伝えます。テーブル、チャートの種類、設定はアシスタントが選びます。

| 設定 | 内容 |
| --- | --- |
| **タイプ** | `table`、`bar`、`line`、`pie`、`big_number` のいずれかです。 |
| **メトリック** | 列とその集計方法です：`SUM`、`COUNT`、`AVG`、`MIN`、`MAX`、`COUNT_DISTINCT`。`SUM` と `AVG` には数値列が必要です。 |
| **X** | 棒グラフまたは折れ線グラフのカテゴリ列または時間列です。`big_number` チャートでは、指定するとトレンドラインが追加されます。 |
| **時間粒度** | 時間列を `day`、`week`、`month`、`quarter`、`year` 単位でまとめます。 |
| **グループ化** | 数値を分割する列です。円グラフでは1列だけを指定します。 |
| **フィルター** | 列、比較演算子（`=`、`!=`、`>`、`<`、`>=`、`<=`、`LIKE`、`ILIKE`、`NOT LIKE`、`IN`、`NOT IN`）、値です。`IN` と `NOT IN` にはリストを指定します。 |

アシスタントには、チャートへのリンクとそのデータのサンプルが返されます。チャートを信頼して使う前に、サンプルが質問の内容と合っているかをアシスタントに確認させてください。

### チャートを編集する

アシスタントは、`chart_id` を渡すことで、あなたが所有するチャートを編集します。これを渡さずに同じ依頼を繰り返すと2つ目のチャートが作成されるため、作り直すのではなく、作成したばかりのチャートを編集するようアシスタントに伝えてください。

### 計算メジャー

チャートビルダーは列を集計します。利益率や単位あたり売上などの計算メジャーを使うには、まずそれを PlaidCloud の[ビュー](../getting-started/#ラベルとビュー)に列として追加し、ビューを公開してから、その列をチャートにします。ビューの作成はアシスタントに依頼できます。

## ダッシュボード

作成したチャートからダッシュボードを依頼します。

- **新しいダッシュボード**は、プロジェクトの**デフォルトのダッシュボード対象者**で公開されます。プロジェクトに設定がない場合は、プロジェクトの全員が閲覧できます。閲覧できるユーザーを変更するには、[ダッシュボードを閲覧できるユーザーを制御する](/ja/guides/dashboards/control-who-can-see-a-dashboard/)を参照してください。
- **既存のダッシュボードへの追加**は、あなたが所有するダッシュボードで行え、すでに配置されているチャートが削除されることはありません。一部のチャートを追加できなかった場合は、残りについて再度依頼するようアシスタントに伝えてください。
- **1つのダッシュボードに1つのプロジェクト。** ダッシュボード上のチャートはすべて同じプロジェクトのものである必要があります。別のプロジェクトには、別のダッシュボードを作成します。

<Aside>
  対象者の設定は、閲覧すべきでない人からダッシュボードを隠します。各チャートのデータは、引き続きプロジェクトのアクセス権と行アクセスに従います。
</Aside>

## 問題が発生した場合

| メッセージ | 対応 |
| --- | --- |
| テーブルが公開されていない | PlaidCloud でテーブルまたはビューを公開してから、再度依頼します。 |
| アカウントがまだ存在しない | ダッシュボードサイトを一度開いてから、再度依頼します。 |
| そのチャートまたはダッシュボードの所有者ではない | 編集できるのは、あなたが所有するチャートとダッシュボードだけです。代わりに新しいものを依頼します。 |
| 列または集計が無効 | 列名を確認し、`SUM` と `AVG` は数値列にのみ使います。 |
| サービスがタイムアウトした | チャートやダッシュボードがすでに作成されている可能性があります。再度依頼する前に、ダッシュボードサイトを確認します。 |
