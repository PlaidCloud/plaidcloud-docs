このチュートリアルでは、**Model Context Protocol**（MCP）を使って、AIコーディングエージェントが PlaidCloud ワークスペースを操作できるように設定します。設定が完了すると、エディターから離れることなく、エージェントにテーブルの読み取り、ワークフローの実行、配賦の構築、データに関する質問への回答を依頼できます。

所要時間は約20分です。Claude Code、Cursor、Claude Desktop、ChatGPT、GitHub Copilot のほか、MCP に対応するあらゆるクライアントで利用できます。

## 構築する内容

AIコーディングエージェントと PlaidCloud ワークスペースの間に、次の操作ができる接続を構築します。

- プロジェクト、テーブル、ワークフロー、ディメンションの一覧表示
- テーブルの内容の読み取り
- ワークフロー定義の確認
- ワークフローの実行のトリガー
- コンテキストを切り替えることなく、データに関する質問に回答

## 前提条件

- PlaidCloud ワークスペース（お持ちでない場合は[無料トライアルを開始](https://app.plaidcloud.com)してください）
- すでに使用しているAIコーディングエージェント（Claude Code、Cursor、Claude Desktop、ChatGPT、Copilot、Gemini のいずれか）
- エージェントが MCP に対応していること（現在のほとんどの AI ツールが対応しています）

## ステップ1: ワークスペースの MCP URL を確認する

すべての PlaidCloud ワークスペースは、次の場所に MCP エンドポイントを公開しています。

```text
https://<your-workspace>.plaid.cloud/mcp
```

`<your-workspace>` は、ワークスペースのサブドメインに置き換えてください。PlaidCloud の UI にサインインするときに使用するものと同じです。

## ステップ2: 認証トークンを取得する

<Steps>

1. ブラウザーで PlaidCloud にサインインした状態で、次の URL にアクセスします。
   ```
   https://<your-workspace>.plaid.cloud/mcp/setup/token
   ```
2. ページに表示されたベアラートークンをコピーします。このトークンはあなたのアカウントと同じアクセス権を持つため、安全に保管してください。

</Steps>

<Aside type="caution">
トークンはパスワードと同様に扱ってください。トークンは対話型の認証をバイパスし、あなたに代わって動作します。漏えいした場合は、同じエンドポイントから無効化してください。
</Aside>

## ステップ3: エージェントを設定する

<Tabs>

<TabItem label="Claude Code">

ターミナルで次のコマンドを実行します。

```bash
claude mcp add --transport http plaidcloud https://<your-workspace>.plaid.cloud/mcp
```

静的トークンによる認証（OAuth フローが不要で、長時間のセッションに向いています）を使用する場合は、ステップ2の URL をブラウザーで開き、表示された設定スニペットをコピーして `.mcp.json` ファイルに貼り付けます。

すべてのオプションについては、[Claude Code のセットアップ](/ja/integrations/ai-coding-agents/claude-code/)を参照してください。

</TabItem>

<TabItem label="Cursor">

`https://<your-workspace>.plaid.cloud/mcp/setup/token` からベアラートークンを取得し、Cursor の MCP 設定に次の内容を追加します。

```json
{
  "mcpServers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

すべてのオプションについては、[Cursor のセットアップ](/ja/integrations/ai-coding-agents/cursor/)を参照してください。

</TabItem>

<TabItem label="Claude Desktop">

「Settings」→「Developer」→「MCP Servers」を開き、次の内容を追加します。

- **サーバーURL**: `https://<your-workspace>.plaid.cloud/mcp`
- 求められたら OAuth ログインを使用します

すべてのオプションについては、[Claude Desktop のセットアップ](/ja/integrations/ai-coding-agents/claude-desktop/)を参照してください。

</TabItem>

<TabItem label="ChatGPT">

1. 「Settings」→「Connectors」→「Add custom connector」を開きます
2. 次の内容を入力します。
   - **名前**: `PlaidCloud`
   - **MCPサーバーのURL**: `https://<your-workspace>.plaid.cloud/mcp`
3. ChatGPT が OAuth ログインのために PlaidCloud にリダイレクトします。接続を承認してください。
4. コネクターを使用したい会話の中で、コネクターをオンに切り替えます。

すべてのオプションについては、[ChatGPT のセットアップ](/ja/integrations/ai-coding-agents/chatgpt/)を参照してください。

</TabItem>

<TabItem label="Copilot">

ベアラートークンを取得し、`.vscode/mcp.json` に次の内容を追加します。

```json
{
  "servers": {
    "plaidcloud": {
      "url": "https://<your-workspace>.plaid.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

VSCode は起動時とファイルの変更時にこのファイルを読み込みます。

すべてのオプションについては、[Copilot のセットアップ](/ja/integrations/ai-coding-agents/copilot/)を参照してください。

</TabItem>

</Tabs>

## ステップ4: 接続を確認する

エージェントに簡単な質問をしてみます。

> 「PlaidCloud ワークスペースのプロジェクトを一覧表示してください。」

エージェントがプロジェクトの一覧を返せば成功です。返さない場合は、以下のトラブルシューティングを確認してください。

## ステップ5: 実際のタスクを試す

接続できたら、次のようなことを試してみましょう。

- **データを探索する**: 「Quickstart プロジェクトの `sales` テーブルにはどのような列がありますか?」
- **ワークフローを実行する**: 「Financials プロジェクトの `monthly_close` ワークフローをトリガーして、終了したら教えてください。」
- **何かを構築する**: 「Test ワークフローに、注文を直近30日間に絞り込む Table Lookup ステップを作成してください。」

エージェントの応答は、一般的な回答ではなく、実際のワークスペースの状態に基づいたものになります。

## トラブルシューティング

エージェントが PlaidCloud に接続できない場合や、認証エラーが返される場合は、次の点を確認してください。

- **トークンの有効期限切れ** — `https://<your-workspace>.plaid.cloud/mcp/setup/token` で更新します
- **スコープの不一致** — 一部のツールには特定の PlaidCloud スコープ（例: `analyze.workflow.write`）が必要です。エージェントで `mcp_introspect(name='<tool>')` を実行すると、必要なスコープを確認できます
- **ワークスペースのサブドメインの誤り** — PlaidCloud の UI にサインインして確認します。サブドメインは `.plaid.cloud` の前の部分です

詳細については、[AIコーディングエージェントのトラブルシューティング](/ja/integrations/ai-coding-agents/troubleshooting/)を参照してください。
