*約20分 · アドインのインストール、サインイン、テーブルの取得、ライブ数式の作成*

日々の業務がすでにスプレッドシート中心なら、PlaidCloudを使うためにExcelを離れる必要はありません。**PlaidXL**は、Excel用のPlaidCloudアドインです。プロジェクトのテーブルをワークシートに取り込み、必要なときに更新し、PlaidCloudのデータから直接、集計値を計算する数式を追加します。このチュートリアルを終える頃には、誰かがワークフローを再実行した途端に古くなるコピー＆ペーストではなく、信頼できるプロジェクトテーブルから入力値が得られるようになります。

## 行うこと

1. PlaidXLアドインをインストールします。
2. サインインして、プロジェクトを選択します。
3. テーブルをワークシートに取得し、更新します。
4. プロジェクトのテーブルを一覧表示し、合計を計算する数式を作成します。

## 前提条件

- WindowsまたはMac上の、Microsoft 365版Excel、またはExcel 2021以降。
- PlaidCloudアカウント。PlaidCloudでシングルサインオンを使っている場合は、ここでもそのまま使います。PlaidXLは、同じIDでサインインします。
- 開くことができ、データと数値列を持つテーブルが少なくとも1つあるプロジェクト。すでにアクセスできるプロジェクトであれば、どれでも構いません。まだない場合は、[CSVから答えを出すまで10分](/ja/get-started/tutorials/csv-to-answer/)でテーブルをPlaidCloudに取り込めます。

<Aside>PlaidXLは、あなたの権限で読み取ります。表示されるのは、アカウントがPlaidCloudですでに表示できるプロジェクトとテーブルだけです。それ以上は表示されず、PlaidXLがそれらを変更することもありません。</Aside>

## ステップ1：アドインをインストールする

1. Excelで、**Insert → Add-ins**を開きます（古いバージョンのMacでは**Insert → Store**）。
2. 検索ボックスに `PlaidCloud` と入力します。
3. **PlaidCloud**アドインを選択し、**Add**をクリックします。

リボンに**PlaidCloud**タブが表示されます。インストールはブックごとではなく、コンピューターごとに一度だけ行います。

<Aside type="tip">**PlaidCloud**タブが表示されない場合は、すべてのExcelウィンドウを閉じてから、Excelを開き直してください。組織でアドインを管理している場合は、Microsoft 365管理者による配布が必要なことがあります。[PlaidXLのインストール](/ja/reference/cli/plaidxl/install/)をご覧ください。</Aside>

## ステップ2：サインインしてプロジェクトを選択する

1. 新しいブックを開き、**PlaidCloud → Show Taskpane**をクリックします。
2. PlaidCloudで使用しているメールアドレスを入力し、**Sign In**をクリックします。
3. 複数のワークスペースに所属している場合は、**Select a tenant**から1つ選択し、**Sign In**をクリックします。
4. Excelからポップアップの許可を求められたら許可し、いつもの方法（パスワードと2要素認証コード、またはシングルサインオン）でサインインします。

タスクペインには、**Connected to**の後にワークスペースID、**as**の後にユーザー名が表示され、その下にプロジェクトが並びます。プロジェクトをクリックします。そのテーブルが**テーブル**タブに表示されます。

## ステップ3：テーブルを取得する

1. **テーブル**タブで、テーブルをクリックします。**行数**と**列**に、そのサイズが表示されます。
2. **列**で、不要な列のチェックを外します。列が少ないほど、読み込みは速くなります。
3. **Matching Worksheet**を選択したまま、**Retrieve Table**をクリックします。

テーブルは、その名前が付いた新しいワークシートに取り込まれ、すぐに作業できる状態になります。スクロールしても表示されたままの太字のヘッダー行、すべての列のフィルター、データ範囲の名前付き範囲が設定されます。**Sample data**という名前のテーブルは、シート `Sample_data` に取り込まれ、名前付き範囲 `_Sample_data` が設定されるため、この範囲を使う数式は、データが増えてもそれに追従します。

あとは、通常のシートと同じように、数式、ピボットテーブル、グラフを作成できます。

## ステップ4：更新する

PlaidCloudでテーブルが変更されたとき（ワークフローの再実行や新しいデータの読み込みなど）は、タスクペインまたはリボンの**Refresh All Tables**をクリックします。更新中はシートタブが黄色になり、最新になると緑になります。ブックに取得したすべてのテーブルが、選択した列とフィルターのまま更新されます。

## ステップ5：ライブ数式を作成する

タスクペインは、テーブルをコピーして取り込みます。PlaidXLの数式はさらに一歩進んで、任意のセルでPlaidCloudのデータから計算します。

1. 新しいシートの `A1` に、プロジェクトのテーブルを一覧表示します。

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   名前がA列に展開されます。

2. `C1` に、テーブルの列を一覧表示します。`Sample data` は自分のテーブルの名前に置き換えてください。

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. その一覧から数値列を1つ、そして値が含まれていることがわかっているテキスト列を1つ選びます。その値について、数値列を合計します。名前は自分のものに置き換えてください。

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` には、**Region**が**EMEA**の行における**amount**の合計が表示されます。計算はPlaidCloudで行われ、シート上にライブで反映されます。`E3` の値を変更すると、合計もそれに追従します。

列が[ディメンション](/ja/guides/dimensions/dimensions/)にリンクされている場合、値にはそのディメンション内の任意のノードを指定でき、合計はそのノードの下にあるすべてを集計します。PlaidXLのレポートが、明細行から地域、部門、年度の合計を求める仕組みです。
