*約20分 · アドインのインストール、サインイン、テーブルの取得、ライブ数式の作成*

日々の業務がスプレッドシート中心でも、PlaidCloudを使うためにExcelを離れる必要はありません。**PlaidXL**はExcel用のPlaidCloudアドインで、プロジェクトのテーブルをワークシートに取り込み、必要なときに更新し、PlaidCloudのデータから集計値を直接計算する数式を追加します。このチュートリアルを終えると、誰かがワークフローを再実行した途端に古くなるコピー＆ペーストではなく、信頼できるプロジェクトのテーブルから入力値を取得できるようになります。

## 作業の流れ

1. PlaidXLアドインをインストールします。
2. サインインして、プロジェクトを選択します。
3. テーブルをワークシートに取得し、更新します。
4. プロジェクトのテーブルを一覧表示し、合計を計算する数式を書きます。

## 前提条件

- WindowsまたはMac上の、Microsoft 365版Excel、またはExcel 2021以降。
- PlaidCloudアカウント。PlaidCloudでシングルサインオンを使用している場合は、ここでも同じ方法を使用してください。PlaidXLは同じIDでサインインします。
- 開くことができ、データのあるテーブルと数値列が少なくとも1つ含まれているプロジェクト。アクセス権のあるプロジェクトであればどれでも使用できます。まだプロジェクトがない場合は、[CSVから答えまで](/ja/get-started/tutorials/csv-to-answer/)でテーブルをPlaidCloudに取り込めます。

<Aside>PlaidXLはユーザーの権限で読み取ります。PlaidCloudですでに表示できるプロジェクトとテーブルだけが表示され、それ以外は表示されません。また、PlaidXLがテーブルを変更するのは、保存して確認したときだけです。</Aside>

## ステップ1：アドインをインストールする

1. Excelで**Insert → Add-ins**を開きます（古いバージョンのMacでは**Insert → Store**）。
2. 検索ボックスに`PlaidCloud`と入力します。
3. **PlaidCloud**アドインを選択し、**追加**をクリックします。

リボンに**PlaidCloud**タブが表示されます。インストールはブックごとではなく、コンピューターごとに1回だけ行います。

<Aside type="tip">**PlaidCloud**タブが表示されませんか。すべてのExcelウィンドウを閉じて、Excelを開き直してください。組織でアドインを管理している場合は、Microsoft 365管理者による配布が必要なことがあります。[PlaidXLのインストール](/ja/reference/cli/plaidxl/install/)を参照してください。</Aside>

## ステップ2：サインインしてプロジェクトを選択する

1. 新しいブックを開き、**PlaidCloud → Open PlaidXL**をクリックします。
2. PlaidCloudで使用しているメールアドレスを入力し、**Sign In**をクリックします。
3. 複数のワークスペースに所属している場合は、**Select a workspace**から1つを選択し、**Sign In**をクリックします。
4. Excelからポップアップの許可を求められたら許可し、いつもの方法でサインインします。パスワードと2要素認証コード、またはシングルサインオンです。

作業ウィンドウのヘッダーにワークスペースが表示されます。ヘッダーのプロジェクト名をクリックしてプロジェクトを開き、使用するプロジェクトをクリックします。ブックはこのプロジェクトを記憶します。プロジェクトのテーブルは**Tables**タブに表示されます。

## ステップ3：テーブルを取得する

1. **Tables**タブでテーブルをクリックします。**Rows**と**Columns**にテーブルのサイズが表示されます。
2. **Column**で、不要な列のチェックを外します。列が少ないほど読み込みが速くなります。
3. **Matching Worksheet**を選択したまま、**Retrieve Table**をクリックします。

テーブルは、その名前が付いた新しいワークシートに取り込まれ、すぐに作業できる状態になります。スクロールしても表示されたままの太字のヘッダー行、すべての列のフィルター、データ範囲に対する名前付き範囲が用意されます。**Sample data**というテーブルは`Sample_data`シートに取り込まれ、名前付き範囲は`_Sample_data`になります。そのため、この範囲を使用する数式は、データが増えても追従します。

ほかのシートと同じように、数式、ピボットテーブル、グラフを作成できます。

## ステップ4：更新する

PlaidCloudでテーブルが変更されたとき（ワークフローの再実行や新しいデータの読み込みなど）は、作業ウィンドウまたはリボンの**Refresh All Tables**をクリックします。更新中はシートタブが黄色になり、最新の状態になると緑色になります。ブックに取得したすべてのテーブルが、選択した列とフィルターのまま更新されます。

## ステップ5：ライブ数式を書く

作業ウィンドウはテーブルをコピーして取り込みます。PlaidXLの数式はさらに一歩進んで、任意のセルでPlaidCloudのデータから計算します。

1. 新しいシートの`A1`に、プロジェクトのテーブルを一覧表示します。

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   テーブル名がA列に下方向へ展開されます。

2. `C1`にテーブルの列を一覧表示します。`Sample data`はお使いのテーブル名に置き換えてください。

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. その一覧から数値列を1つ選び、さらに、含まれている値がわかっているテキスト列も1つ選びます。その値に該当する数値列を合計します。名前はお使いのものに置き換えてください。

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4`には、**Region**が**EMEA**である行の**amount**の合計が表示されます。計算はPlaidCloudで行われ、結果はシート上にライブで反映されます。`E3`の値を変更すると、合計もそれに合わせて変わります。

列が[ディメンション](/ja/guides/dimensions/dimensions/)にリンクされている場合、値にはそのディメンション内の任意のノードを指定でき、合計にはそのノード以下のすべてが集計されます。PlaidXLのレポートでは、このようにして明細行から地域、部門、年度の合計を求めます。
