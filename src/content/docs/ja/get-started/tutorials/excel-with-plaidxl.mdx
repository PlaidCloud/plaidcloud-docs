*約20分 · アドインのインストール、サインイン、テーブルの取得、ライブ数式の作成*

日々の業務がすでにスプレッドシート中心であれば、PlaidCloudを使うためにExcelを離れる必要はありません。**PlaidXL**はExcel用のPlaidCloudアドインです。プロジェクトのテーブルをワークシートに取り込み、必要に応じて更新し、PlaidCloudのデータから集計済みの値を直接計算する数式を追加します。このチュートリアルを終えると、誰かがワークフローを再実行した途端に古くなるコピー＆ペーストではなく、信頼できるプロジェクトのテーブルから入力値を取得できるようになります。

## このチュートリアルで行うこと

1. PlaidXLアドインをインストールします。
2. サインインして、プロジェクトを選択します。
3. テーブルをワークシートに取得し、更新します。
4. プロジェクトのテーブルを一覧表示し、合計を計算する数式を作成します。

## 前提条件

- WindowsまたはMac上の、Microsoft 365版のExcel、またはExcel 2021以降。
- PlaidCloudアカウント。PlaidCloudでシングルサインオンを使用している場合は、ここでもそのまま使用してください。PlaidXLは同じIDでサインインします。
- 開くことができるプロジェクトで、データと数値列を持つテーブルが少なくとも1つあるもの。すでにアクセスできるプロジェクトであればどれでも使用できます。まだない場合は、[CSVから答えまで](/ja/get-started/tutorials/csv-to-answer/)でテーブルをPlaidCloudに取り込めます。

<Aside>PlaidXLはあなたの権限で読み取ります。表示されるのは、PlaidCloudですでにアカウントから見えるプロジェクトとテーブルだけです。また、PlaidXLがテーブルを変更するのは、あなた自身が書き込んだときだけです。</Aside>

## ステップ1：アドインをインストールする

1. Excelで **挿入 → アドイン** を開きます。（古いバージョンのMacでは **挿入 → ストア** です。）
2. 検索ボックスに `PlaidCloud` と入力します。
3. **PlaidCloud** アドインを選択し、**追加** をクリックします。

リボンに **PlaidCloud** タブが表示されます。インストールはブックごとではなく、コンピューターごとに1回だけ行います。

<Aside type="tip">**PlaidCloud** タブが表示されない場合は、すべてのExcelウィンドウを閉じてからExcelを開き直してください。組織でアドインを管理している場合は、Microsoft 365の管理者による配布が必要なことがあります。詳しくは[PlaidXLのインストール](/ja/reference/cli/plaidxl/install/)を参照してください。</Aside>

## ステップ2：サインインしてプロジェクトを選択する

1. 新しいブックを開き、**PlaidCloud → Open PlaidXL** をクリックします。
2. PlaidCloudで使用しているメールアドレスを入力し、**Sign In** をクリックします。Officeに職場アカウントでサインインしている場合は、PlaidXLがワークスペースを自動的に見つけることがあります。詳しくは[Officeアカウントでサインインする](/ja/reference/cli/plaidxl/connect/#office-アカウントでサインインする)を参照してください。
3. 複数のワークスペースに所属している場合は、**Select a workspace** から1つ選び、**Sign In** をクリックします。
4. Excelからポップアップの許可を求められたら許可し、通常どおりの方法（パスワードと2要素コード、またはシングルサインオン）でサインインします。

タスクペインのヘッダーにワークスペースが表示されます。ヘッダーのプロジェクト名をクリックしてプロジェクトの一覧を開き、使用するプロジェクトをクリックします。開けるプロジェクトが1つだけの場合は、PlaidXLが自動的にリンクします。ブックはその選択を記憶します。プロジェクトのテーブルは **テーブル** タブに表示されます。

## ステップ3：テーブルを取得する

1. **テーブル** タブでテーブルをクリックします。**行数** と **列** にそのサイズが表示されます。
2. **列** で、不要な列のチェックを外します。列が少ないほど読み込みが速くなります。
3. **Matching Worksheet** を選択したまま、**Retrieve Table** をクリックします。

テーブルは、その名前を付けた新しいワークシートにExcelテーブルとして配置されます。たとえば、**Sample data** というテーブルはシート `Sample_data` に配置されます。スクロールしてもヘッダー行は表示されたままで、すべての列にフィルターが付き、Excelテーブルを参照する数式はデータの増加に合わせて追従します。

他のシートと同じように、このテーブルを元に数式、ピボットテーブル、グラフを作成できます。

## ステップ4：更新する

PlaidCloud側でテーブルが変更されたとき（ワークフローの再実行や新しいデータの読み込みなど）は、タスクペインの **Refresh All Tables** をクリックするか、リボンの **Refresh → Refresh all tables** をクリックします。タスクペインには各テーブルの進行状況が **キャンセル** とともに表示され、完了すると更新された行数が一覧表示されます。ブックに取得したすべてのテーブルが、選択した列とフィルターのまま更新されます。

## ステップ5：ライブ数式を作成する

タスクペインはテーブルをコピーして取り込みます。PlaidXLの数式はさらに一歩進んで、任意のセルでPlaidCloudのデータから計算します。

1. 新しいシートの `A1` に、プロジェクトのテーブルを一覧表示する数式を入力します。

   ```text
   =PLAIDXL.TABLE.TBL_LIST()
   ```

   テーブル名がA列の下方向にあふれて表示されます。

2. `C1` に、`Sample data` を実際のテーブル名に置き換えて、テーブルの列を一覧表示する数式を入力します。

   ```text
   =PLAIDXL.TABLE.GET_COLUMNS("Sample data")
   ```

3. その一覧から数値列を1つ、そして値が確実に含まれているテキスト列を1つ選びます。名前を実際のものに置き換えて、その値に対する数値列の合計を求めます。

   ```text
   E1  =PLAIDXL.REPR.TABLE_REPR("Sample data")
   E2  =PLAIDXL.REPR.MEASURE("amount")
   E3  =PLAIDXL.REPR.DIMENSION_REPR("Region", "EMEA")
   E4  =PLAIDXL.CELL(E1, E2, E3)
   ```

`E4` には、**Region** が **EMEA** である行の **amount** の合計が表示されます。計算はPlaidCloudで行われ、シート上にライブで反映されます。`E3` の値を変更すると、合計もそれに追従します。

列が[ディメンション](/ja/guides/dimensions/dimensions/)にリンクされている場合、値にはそのディメンション内の任意のノードを指定でき、合計はそのノード配下のすべてを集計します。PlaidXLのレポートが、明細行から地域、部門、年度の合計を求めるのはこのためです。
