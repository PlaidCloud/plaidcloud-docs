## 組織、ワークスペース、メンバー

アカウントは**組織**レベルから始まります。組織は課金と ID の境界です。組織の中には1つ以上の**ワークスペース**があり、実際の作業を行う分離された環境です。**メンバー**は組織に所属するユーザーで、特定のワークスペースに対して特定のロールでアクセスを許可されます。

- ほとんどのチームは、環境（開発、ステージング、本番）ごと、または事業部門ごとに1つのワークスペースから始めます。
- ワークスペース内のセキュリティグループによって、各メンバーが実行できる操作を制御します。

詳細：[アクセス管理](/ja/administration/access/)

## プロジェクト

**プロジェクト**は、ワークスペース内の作業単位です。各プロジェクトは、独自のデータ、ワークフロー、ディメンション、監査履歴を所有します。プロジェクト同士は状態を共有せず、分離されています。

プロジェクトを使うことで、個別の分析、業務プロセス、データプロダクトを互いに切り離せます。

詳細：[プロジェクト](/ja/guides/projects/)

## 接続

**接続**は、PlaidCloud がデータベース、クラウドストレージアカウント、ERP、REST API といった外部システムに到達できるようにする、保存済みの設定です。接続はワークフローのステップから再利用されるため、認証情報がステップごとに重複することはありません。

詳細：[接続（タスク）](/ja/guides/connections/) · [コネクター（リファレンス）](/ja/reference/connectors/)

## テーブルとビュー

**テーブル**は、プロジェクト内の構造化データで、SQL テーブルのように行と列で構成されます。テーブルは、インポート、変換、または外部ソースから作成されます。**ビュー**は、テーブルの上に重ねる、保存済みのクエリ結果です。

詳細：[テーブルとビュー](/ja/guides/data/)

## ワークフローとステップ

**ワークフロー**は、テーブルを操作するパイプラインです。各ワークフローは**ステップ**の連なりで、CSV のインポート、2つのテーブルの結合、行のフィルター、JSON へのエクスポート、通知の送信などを行います。ステップは、順次、並列、条件付き、またはループで実行できます。

ステップにはカテゴリがあります。

- **インポート** — データを取り込みます（CSV、Excel、SQL、Parquet、JSON など）。
- **テーブル** — テーブルを変換します（結合、フィルター、アンピボット、ピボット、追加、アップサート）。
- **エクスポート** — データを外部へ書き出します。
- **ドキュメント** — PDF、画像、任意のファイルを扱います。
- **通知** — メール、Slack、Teams、SMS、Webhook でメッセージを送信します。
- **配賦** — コスト配賦モデルを実行します。
- **ディメンション** — 階層を構築および変更します。
- **SAP / SAP-PCM** — SAP 固有の操作を呼び出します。
- **ワークフロー制御** — 変数、ループ、サブワークフロー。

詳細：[ワークフロー（タスク）](/ja/guides/workflows/) · [ワークフローステップ（リファレンス）](/ja/reference/workflow-steps/)

## ディメンション

**ディメンション**は階層で、通常はデータのスライスや集計に使用します。コストセンター、製品、地域、時間などが該当します。ディメンションは、テーブルから構築したり、外部ソースからロードしたり、段階的に変更したりできます。

配賦では、ディメンションを使って*何を何に配賦するか*を決定します。

詳細：[ディメンション](/ja/guides/dimensions/)

## 配賦

**配賦**は、ドライバーデータとルールに基づいて、ある行のセットから別の行のセットへ値を割り振ります。移転価格、活動基準原価計算、IT 部門費の振替、収益性分析など、コストのプールを複数の利用者に分配する必要がある場面を想像してください。

配賦では、テーブル（値、ドライバー、結果）、ディメンション（ルール）、ワークフローのステップ（モデルの実行）を組み合わせます。

詳細：[配賦](/ja/guides/allocations/)

## ダッシュボード

**ダッシュボード**は、プロジェクトデータの公開済みのインタラクティブなビューです。公開済みのテーブルとビューから構築します。

詳細：[ダッシュボード](/ja/guides/dashboards/)

## AI アシスタント

データやワークフローについて質問できる、プロジェクト単位のチャットです。会話は保持され、プロジェクトごとに分離されます。

詳細：[AI アシスタント](/ja/guides/ai-assistant/)

## 全体のつながり

エンドツーエンドの一般的な流れは次のとおりです。

1. ソースシステムへの**接続を設定**します。
2. **プロジェクト**内で、次の処理を行う**ワークフロー**を構築します。
   - 接続を介してデータを**インポート**します（テーブルが作成されます）。
   - テーブルステップで**変換**します。
   - コンテキストを加えるために**ディメンション**と**結合**します。
   - コストを割り振る場合は**配賦**します。
   - 結果を**公開**します。
3. **ダッシュボード**が公開済みのテーブルを読み取ります。
4. **ワークスペースメンバー**は、ダッシュボードを閲覧したり、AI アシスタントを通じて結果を照会したりします。
