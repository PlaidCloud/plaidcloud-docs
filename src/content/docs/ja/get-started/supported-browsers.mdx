PlaidCloud はウェブブラウザー上で動作し、インストールは不要です。以下のいずれかのブラウザーの、記載のバージョン以降が必要です。

## 最小バージョン

| ブラウザー | 最小バージョン |
| --- | --- |
| Google Chrome | 94 |
| Microsoft Edge | 94 |
| Mozilla Firefox | 93 |
| Mac の Safari | 16.4 |
| iPad または iPhone のすべてのブラウザー | iPadOS または iOS 16.4 |

ほとんどのブラウザーは自動で更新されるため、最新の状態に保たれているブラウザーであれば、これらのバージョンを十分に上回っています。

## iPad と iPhone

iPad や iPhone のブラウザーアプリは、Chrome や Firefox を含め、すべて Safari のエンジンをベースにしています。そのため重要なのは、使用しているブラウザーアプリではなく、デバイスの iPadOS または iOS のバージョンです。更新するには、**設定** > **一般** > **ソフトウェアアップデート**を開きます。

<Aside type="caution">
iPad Air 2 と iPad mini 4 は iPadOS 15 より新しいバージョンに更新できないため、PlaidCloud は動作しません。代わりに、コンピューターまたは新しい iPad を使用してください。
</Aside>

## 古いブラウザーで表示される内容

古いブラウザーでは PlaidCloud を読み込めません。上記のバージョンを示す **PlaidCloud needs a newer browser** ページが表示されます。ブラウザーを更新するか、ここに記載されているいずれかのブラウザーで PlaidCloud を開いてください。
