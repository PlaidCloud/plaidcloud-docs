## 追加

- **ステップフォームでのプレビュー。** Import: SQL、Execute: SQL、Extract: SQL、Export: SQL、Salesforce Query では、ステップを実行せずに最大 100 行を表示できます。Anaplan のビューとリストの読み取りでは、生成される列と型が表示されます。**ソース**タブで**プレビュー**をクリックします。変数は実行時と同じように埋め込まれますが、`{x:>9}` のような変数の書式指定はサポートされていません。クエリを受け取るステップでは、プレビューで実行できるのは標準 SQL 関数のみです。それ以外の場合は、ステップを実行するよう案内されます。ロックされたプロジェクトや、Agent ベースの Execute SQL ステップでは使用できません。[SQLのインポート](/ja/reference/workflow-steps/import/import-sql/)および[SQL抽出](/ja/reference/workflow-steps/tables/table-extract-sql/)を参照してください。
- **AI アシスタントでテーブルの公開を取り消し、プロジェクトのデフォルトのダッシュボード対象者を設定できます。** `publish_manage` は、テーブルと、その公開ビュー、およびどのチャートも使用していないダッシュボードデータセットの公開を取り消します。チャートが使用しているデータセットは残ります。また、公開ビューをもとにレポートビューが作成されている場合は、そのビューとデータセットも残りますが、テーブルの公開は取り消されます。`project_upsert` は `dashboard_default_audience`、つまりプロジェクト内の新しいダッシュボードを共有するグループを設定し、`[]` を指定するとクリアされます。[公開の取り消し](/ja/guides/data/publish/#ai-アシスタントまたは-mcp-で公開を取り消す)および[AI アシスタントまたは MCP でデフォルトの対象者を設定する](/ja/guides/dashboards/control-who-can-see-a-dashboard/#ai-アシスタントまたは-mcp-でデフォルトの対象ユーザーを設定する)を参照してください。

## 変更

- **ステップフォームが共通のレイアウトになりました。** タブの名前と順序が統一され、全般、設定、ソース、列、フィルター、出力、詳細設定の順に並びます。ERP 転記フォームには、ヘッダー列と明細列も加わります。必須フィールドには * が付き、保存できなくなるのはステップに必要な項目が欠けている場合のみです。
- **行アクションメニュー（⋯）が、すべてのグリッド行の左端に表示されます。**
- **検証設定のない保存済みの ERP 書き込みステップは、検証のみのモードで開きます。** 対象は SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL および AP Post、Xero エクスポートです。明示的に本番実行に設定されているステップは、そのまま本番実行になります。
- **長時間実行されるジョブの進捗が、どこでも同じ方法で表示されます。**
- **REST、Import REST、Import Postman の各ステップは、ワークスペースのアップグレード時に RESTリクエストに変換されます。** 問題なく変換できないステップは、そのまま残ります。[RESTリクエストステップ](/ja/guides/workflows/rest-request-step/)を参照してください。
- **プロジェクトのアーキテクトは、ダッシュボードで行制限付きテーブルのすべての行を確認できます。** Analyze での表示と同じです。アーキテクトのアクセス権を削除すると、約 1 分後、場合によっては最大 15 分後に反映されます。[行アクセスの管理](/ja/administration/access/managing-security-groups-and-assignments/#行アクセスの管理)を参照してください。
- **セッションの有効期限が切れた後に開いたダッシュボードのリンクは、サインイン後にそのダッシュボードへ移動します。** [ダッシュボードの使用](/ja/guides/dashboards/using-dashboards/)を参照してください。
- **MCP ツールは、認識できないフィールドを無視せずに拒否し、エラーでそのフィールド名を示します。** `workflow_upsert` は `memo` を受け取り、その別名として `description` も受け付けます。[不明なフィールドは拒否される](/ja/integrations/ai-coding-agents/getting-started/#不明なフィールドは拒否される)を参照してください。
