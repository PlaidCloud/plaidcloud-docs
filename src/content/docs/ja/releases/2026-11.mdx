## 追加

- **ステップフォームのプレビュー。** Import: SQL、Execute: SQL、Extract: SQL、Export: SQL、Salesforce Query は、ステップを実行せずに最大 100 行を表示します。Anaplan のビューとリストの読み取りは、生成される列と型を表示します。**ソース**タブで**プレビュー**をクリックします。変数は、実行時と同じように埋め込まれますが、`{x:>9}` のような変数の書式指定には対応していません。プレビューは標準の SQL 関数のみを実行します。それ以外の場合は、ステップを実行するよう案内されます。ロックされたプロジェクトや、エージェントベースの Execute SQL ステップでは利用できません。[SQLのインポート](/ja/reference/workflow-steps/import/import-sql/)と[SQL抽出](/ja/reference/workflow-steps/tables/table-extract-sql/)を参照してください。
- **AI アシスタントがテーブルの公開を取り消し、プロジェクトのデフォルトのダッシュボード対象ユーザーを設定できます。** `publish_manage` は、テーブルの公開を、公開されたビューと、どのチャートも使っていないダッシュボードデータセットとともに取り消します。チャートがまだ使っているデータセットは残ります。また、公開されたビューの上にレポートビューが構築されている場合は、ビューとデータセットも残りますが、テーブルの公開は取り消されます。`project_upsert` は `dashboard_default_audience` を設定します。これは、プロジェクトの新しいダッシュボードを共有するグループで、`[]` を指定するとクリアされます。[公開の取り消し](/ja/guides/data/publish/#ai-アシスタントまたは-mcp-で公開を取り消す)と[AI アシスタントまたは MCP でデフォルトの対象ユーザーを設定する](/ja/guides/dashboards/control-who-can-see-a-dashboard/#ai-アシスタントまたは-mcp-でデフォルトの対象ユーザーを設定する)を参照してください。

- **モバイルの Weave では、音声が 1 回のタップで使えます。** マイクをタップして質問を話すと、話し終えた時点で Weave が送信します。途中で止めるには、もう一度マイクをタップします。何も聞き取れない場合は、自動的にオフになります。話の途中で **Weave** タブを離れたりアプリをバックグラウンドに移したりすると、言葉は送信されずに質問ボックスに残るため、内容を確認できます。実行、一時停止、停止、再開は、確認画面での誤った 2 回タップを無視します。アプリのバージョン 1.3.0 以降が必要です。[音声を使う](/ja/guides/mobile-app/weave-on-mobile/#音声を使う)を参照してください。

## 変更

- **ステップフォームが 1 つのレイアウトに統一されました。** タブは標準の名前と順序（General、Settings、Source、Columns、Filters、Output、Advanced）になり、ERP 転記フォームには Header columns と Line columns が加わります。必須フィールドには * が付き、フォームはステップに必要な項目についてのみ保存をブロックします。
- **行アクションメニュー（⋯）が、すべてのグリッド行の左端に表示されます。**
- **検証設定のない保存済みの ERP 書き込みステップは、検証のみで開きます。** 対象は、SAP Post、SAP Attach、NetSuite Post、Oracle EBS GL と AP の Post、Xero のエクスポートです。本番実行が明示的に設定されたステップは、そのまま本番実行です。
- **長時間実行されるジョブの進行状況が、どこでも同じ方法で表示されます。**
- **REST、Import REST、Import Postman の各ステップは、ワークスペースのアップグレード時に RESTリクエストに変換されます。** きれいに変換できないステップは、そのまま残ります。[RESTリクエストステップ](/ja/guides/workflows/rest-request-step/)を参照してください。
- **プロジェクトのアーキテクトは、ダッシュボードで行が制限されたテーブルのすべての行を確認できます。** Analyze での表示と同じです。アーキテクトのアクセス権を取り消すと、ダッシュボードにも即座に反映されます。これは、ユーザーのロールの変更、ユーザーまたはそのグループのプロジェクトからの削除、プロジェクトのアクセスタイプの変更、プロジェクトの以前のバージョンの復元、セキュリティグループの削除のいずれの場合も同様です。元アーキテクトには、行が制限されたデータのすべての行が表示されなくなります。[行アクセスの管理](/ja/administration/access/managing-security-groups-and-assignments/#行アクセスの管理)を参照してください。
- **セッションの有効期限が切れた後で開いたダッシュボードのリンクは、サインイン後にそのダッシュボードへ移動します。** [ダッシュボードの利用](/ja/guides/dashboards/using-dashboards/)を参照してください。
- **MCP ツールは、認識できないフィールドを無視せず、エラーでそのフィールド名を示して拒否します。** `workflow_upsert` は `memo` を受け付け、その別名として `description` も受け付けます。[不明なフィールドは拒否されます](/ja/integrations/ai-coding-agents/getting-started/#不明なフィールドは拒否される)を参照してください。

## 修正

- **無効なプロジェクト設定が、わかりやすいメッセージで報告されます。** 不明な環境やドキュメントアカウント、すでに使われている、または予約されているスラッグ、無効なストレージタイプや転記モードに対して、汎用的なサーバーエラーではなく、問題を示すメッセージが返されます。REST API では 500 ではなく 400、AI アシスタントまたは MCP では無効な引数のエラーになります。
