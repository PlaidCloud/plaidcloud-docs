## これらのノートの作成方法

各月次サマリーは、その暦月にテナントに提供された実質的な変更をまとめたものです。純粋なインフラストラクチャ作業（イメージの更新、内部リファクタリング、RC の作成、シークレットのローテーション、可観測性のチューニング）は、1件ずつ列挙せず、テーマのラベルにまとめています。お客様に見える機能があった月は、追加 / 変更 / 修正 / セキュリティの構成で明示的に取り上げています。

特定のリリースの詳細については、担当のアカウントチームにお問い合わせください。

今後の月次サマリーは、公開され次第、ここに掲載されます。
