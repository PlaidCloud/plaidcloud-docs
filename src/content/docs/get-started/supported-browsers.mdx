PlaidCloud runs in your web browser, with nothing to install. It needs one of these browsers, at this version or any later one.

## Minimum Versions

| Browser | Minimum version |
| --- | --- |
| Google Chrome | 94 |
| Microsoft Edge | 94 |
| Mozilla Firefox | 93 |
| Safari on a Mac | 16.4 |
| Any browser on an iPad or iPhone | iPadOS or iOS 16.4 |

Most browsers update themselves, so a browser that is kept up to date is already well past these versions.

## iPad and iPhone

Browser apps on an iPad or iPhone, Chrome and Firefox included, are built on Safari's engine. What counts there is the device's iPadOS or iOS version, not which browser app you use. To update it, open **Settings** > **General** > **Software Update**.

<Aside type="caution">
The iPad Air 2 and iPad mini 4 can't be updated past iPadOS 15, so PlaidCloud doesn't run on them. Use a computer or a newer iPad instead.
</Aside>

## What an Older Browser Shows

An older browser doesn't load PlaidCloud. It shows a **PlaidCloud needs a newer browser** page that names the versions above. Update the browser, or open PlaidCloud in one of the browsers listed here.
