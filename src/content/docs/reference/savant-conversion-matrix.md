PlaidCloud converts Savant Labs analyses into native Advanced workflows. The
importer maps each Savant agent to a workflow step, project variable, or
canvas object, so a converted workflow runs cloud-native.

This page is a scorecard. Each agent has a **target status** (what the
converter is designed to deliver) and a **measured status** (what the
measurements show). Measurement is by *step type × config permutation*: every
distinct configuration of an agent is one permutation, and nothing else is
counted.

- **Full** — every permutation of the agent converts and runs its function.
- **Partial** — converts and runs for its common use, while one distinct
  *capability mode* is not reproduced.
- **Not supported** — no conversion; the capability is rebuilt natively
  instead.
- **Unmeasured** — measured status only: no permutation has a result yet.

Measured status is derived mechanically. **Full** requires every permutation to
pass G3. **Partial** means at least one permutation passes G1 and at least one
permutation fails or lacks a G2 or G3 result. **Not supported** means the agent
is a placeholder or no permutation passes G1.

External-system connectors are **connected, not converted** — see
[Connecting to External Systems](#connecting-to-external-systems).

## Analysis Parameters

Savant analysis parameters convert to project variables, and references to them inside node configs are rewritten to the PlaidCloud variable syntax. List, dictionary, and aliased parameter shapes all load.

## Connecting to External Systems

Savant connectors are source and destination targets, not steps, and an export carries no datasets or credentials. PlaidCloud reaches these systems through a connection rather than through a node on the canvas.

| Savant | Where It Goes in PlaidCloud |
| --- | --- |
| Source connector | `source_bindings` maps the Savant node or dataset to a PlaidCloud table or a Document file, read through the matching import step; an unbound source warns and processes nothing |
| Destination: CSV, Excel | An export step ([Export: CSV](/reference/workflow-steps/export/export-to-csv/), [Export: Excel](/reference/workflow-steps/export/export-to-excel/)) |
| Destination: other connectors | The matching export step when PlaidCloud has one for that system; otherwise a CSV or table destination with a warning naming the original target |

Conversion never contacts the source or destination system.

## Validating a Converted Workflow

Validation is by oracle, and the evidence label travels with every result.

- **Parity is claimed only against a real golden** — output from the customer's own system of record, compared row by row.
- **Expected output derived from the spec** shows consistency with the documented behavior and is never reported as parity.

Comparison checks schema, row count, and row values, and ignores row order unless the workflow depends on it.
