Returns the hour from a datetime.

## Analyze Syntax

```python
func.hour(<datetime>)
```

## Analyze Examples

```python
func.hour('2024-06-15 14:30:00')

┌────┐
│ 14  │
└────┘
```

## SQL Syntax

```sql
HOUR(<datetime>)
```

## SQL Examples

```sql
SELECT HOUR('2024-06-15 14:30:00');

┌────┐
│ 14  │
└────┘
```
