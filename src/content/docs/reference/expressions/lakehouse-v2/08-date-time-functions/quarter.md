Returns the quarter of the year from a date (1-4).

## Analyze Syntax

```python
func.quarter(<date>)
```

## Analyze Examples

```python
func.quarter('2024-06-15')

┌───┐
│ 2  │
└───┘
```

## SQL Syntax

```sql
QUARTER(<date>)
```

## SQL Examples

```sql
SELECT QUARTER('2024-06-15');

┌───┐
│ 2  │
└───┘
```
