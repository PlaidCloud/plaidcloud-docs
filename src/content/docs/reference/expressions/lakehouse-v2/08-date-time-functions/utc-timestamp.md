---
title: UTC_TIMESTAMP
description: UTC_TIMESTAMP — returns the current UTC date and time - see syntax, examples, and output.
---

Returns the current UTC date and time.

## Analyze Syntax

```python
func.utc_timestamp()
```

## Analyze Examples

```python
func.utc_timestamp()

┌───────────────────────┐
│ '2024-06-15 18:30:00'  │
└───────────────────────┘
```

## SQL Syntax

```sql
UTC_TIMESTAMP()
```

## SQL Examples

```sql
SELECT UTC_TIMESTAMP();

┌─────────────────────┐
│ 2024-06-15 18:30:00  │
└─────────────────────┘
```
