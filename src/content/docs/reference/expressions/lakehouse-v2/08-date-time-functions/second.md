Returns the second from a datetime.

## Analyze Syntax

```python
func.second(<datetime>)
```

## Analyze Examples

```python
func.second('2024-06-15 14:30:45')

┌────┐
│ 45  │
└────┘
```

## SQL Syntax

```sql
SECOND(<datetime>)
```

## SQL Examples

```sql
SELECT SECOND('2024-06-15 14:30:45');

┌────┐
│ 45  │
└────┘
```
