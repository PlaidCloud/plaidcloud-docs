Returns the current date and time.

## Analyze Syntax

```python
func.now()
```

## Analyze Examples

```python
func.now()

┌───────────────────────┐
│ '2024-06-15 14:30:00'  │
└───────────────────────┘
```

## SQL Syntax

```sql
NOW()
```

## SQL Examples

```sql
SELECT NOW();

┌─────────────────────┐
│ 2024-06-15 14:30:00  │
└─────────────────────┘
```
