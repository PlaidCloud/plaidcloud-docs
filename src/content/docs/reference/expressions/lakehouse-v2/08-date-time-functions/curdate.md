---
title: CURDATE (Lakehouse v2)
description: CURDATE — returns the current date.
---

Returns the current date.

## Analyze Syntax

```python
func.curdate()
```

## Analyze Examples

```python
func.curdate()

┌──────────────┐
│ '2024-06-15'  │
└──────────────┘
```

## SQL Syntax

```sql
CURDATE()
```

## SQL Examples

```sql
SELECT CURDATE();

┌────────────┐
│ 2024-06-15  │
└────────────┘
```
