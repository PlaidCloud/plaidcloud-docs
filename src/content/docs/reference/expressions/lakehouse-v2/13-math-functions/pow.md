Returns a number raised to the power of another number.

## Analyze Syntax

```python
func.pow(<x>, <y>)
```

## Analyze Examples

```python
func.pow(2, 10)

┌────────┐
│ 1024.0  │
└────────┘
```

## SQL Syntax

```sql
POW(<x>, <y>)
```

## SQL Examples

```sql
SELECT POW(2, 10);

┌────────┐
│ 1024.0  │
└────────┘
```
