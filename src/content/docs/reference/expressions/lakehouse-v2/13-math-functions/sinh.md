Returns the hyperbolic sine of a number.

## Analyze Syntax

```python
func.sinh(<x>)
```

## Analyze Examples

```python
func.sinh(0)

┌─────┐
│ 0.0  │
└─────┘
```

## SQL Syntax

```sql
SINH(<x>)
```

## SQL Examples

```sql
SELECT SINH(0);

┌─────┐
│ 0.0  │
└─────┘
```
