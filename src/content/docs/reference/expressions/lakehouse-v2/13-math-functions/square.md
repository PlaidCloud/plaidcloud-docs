Returns the square of a number.

## Analyze Syntax

```python
func.square(<x>)
```

## Analyze Examples

```python
func.square(7)

┌────┐
│ 49  │
└────┘
```

## SQL Syntax

```sql
SQUARE(<x>)
```

## SQL Examples

```sql
SELECT SQUARE(7);

┌────┐
│ 49  │
└────┘
```
