Returns the hyperbolic cosine of a number.

## Analyze Syntax

```python
func.cosh(<x>)
```

## Analyze Examples

```python
func.cosh(0)

┌─────┐
│ 1.0  │
└─────┘
```

## SQL Syntax

```sql
COSH(<x>)
```

## SQL Examples

```sql
SELECT COSH(0);

┌─────┐
│ 1.0  │
└─────┘
```
