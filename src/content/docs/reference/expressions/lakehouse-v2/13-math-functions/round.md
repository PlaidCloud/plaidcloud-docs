Rounds a number to a specified number of decimal places.

## Analyze Syntax

```python
func.round(<x>[, <d>])
```

## Analyze Examples

```python
func.round(3.14159, 2)

┌──────┐
│ 3.14  │
└──────┘
```

## SQL Syntax

```sql
ROUND(<x>[, <d>])
```

## SQL Examples

```sql
SELECT ROUND(3.14159, 2);

┌──────┐
│ 3.14  │
└──────┘
```
