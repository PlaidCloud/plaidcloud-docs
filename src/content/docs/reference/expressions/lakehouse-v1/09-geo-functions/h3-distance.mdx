import { Aside } from '@astrojs/starlight/components';

Returns the grid distance between the the given two [H3](https://eng.uber.com/h3/) indexes.

<Aside>H3 distance calculations can only calculate distances between hexes that are neighbors. Trying to use this with non-neighbor hexes will error.</Aside>

### Analyze Syntax

```python
func.h3_distance(h3, a_h3)
```

## Analyze Examples

```python
func.h3_distance(599119489002373119, 599119491149856767)

┌──────────────────────────────────────────────────────────┐
│ func.h3_distance(599119489002373119, 599119491149856767) │
├──────────────────────────────────────────────────────────┤
│                                                        1 │
└──────────────────────────────────────────────────────────┘
```

## SQL Syntax

```sql
H3_DISTANCE(h3, a_h3)
```
