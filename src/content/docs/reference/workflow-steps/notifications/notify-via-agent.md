## Description



Triggers a notification through a PlaidLink Agent — useful when notifications need to be delivered through on-premises systems (internal alerting, in-house webhooks, legacy SMTP) that aren't reachable from PlaidCloud directly.

The Agent receives the notification payload and dispatches it locally according to its configuration.
