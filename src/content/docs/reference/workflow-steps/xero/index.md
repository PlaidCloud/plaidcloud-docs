Workflow steps that read from and write to Xero over your [Xero connection](/guides/connections/xero/). The import step pulls Xero's Accounting API entities with no query to write; the post step posts manual journals, invoices, bills, payments, and credit notes through PlaidCloud's shared ERP write pipeline.

## Steps

- [Xero: Import Entity](/reference/workflow-steps/xero/import-xero-entity/) — accounts, contacts, invoices, credit notes, payments, manual journals, bank transactions, items, tracking categories, tax rates, and currencies.
- [Xero: Post Document](/reference/workflow-steps/xero/xero-post/) — post manual journals, invoices, bills, payments, and credit notes.
