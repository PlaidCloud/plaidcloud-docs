## Description

Writes project tables to a compressed archive in a document account. Paired with [Restore Tables](/reference/workflow-steps/import/restore-tables/), it moves table data between projects or workspaces, or parks a known-good copy before a destructive change.

## Unique Configuration Items

### Target

The document account and path the archive is written to.

### Compression

- **Snappy** — fastest, moderate archive size
- **Zstandard** — smaller archives, needs a reader on Zstandard 0.8 or later
