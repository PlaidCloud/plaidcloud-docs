## Description

Writes a complete archive of the project — workflows, table definitions, dimensions, variables, and settings — to a document account as a single file. Use it for a point-in-time backup before a large change, or to hand a project to another workspace.

This archives the *project*, not just its data. For table data alone, use [Export to Table Archive](/reference/workflow-steps/export/export-to-table-archive/).

## Unique Configuration Items

### Export Directory and Filename

- **Export directory** — the document account and folder the archive is written to.
- **Target file** — the archive's file name.
