## Description

Posts a trial balance into Sage over a Sage connection. The step takes two tables — a header table describing the journal entry and a lines table holding its individual postings — and writes them as a single transaction.

## Unique Configuration Items

### Sage Connection

The Sage connection to post through.

### Source Columns

Two separate mappings:

- **Header columns** — the journal-entry-level fields.
- **Lines columns** — the per-posting fields.
