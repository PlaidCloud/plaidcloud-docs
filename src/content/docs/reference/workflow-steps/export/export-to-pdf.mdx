## Description

The **Export to PDF** step writes one table as a PDF document in a document account. It reads the rows itself, so no export worker runs in between.

## Parameters

- **Source Table** — the table to export.
- **Output Folder** — the document account and folder the PDF is written to.
- **File Name** — the name of the PDF. `.pdf` is added when the name lacks it.
- **Write column names as a header row** — on by default. The header repeats on every page.
- **Table Data Selection** — choose and order the columns written. The step can also write every column the source has when the workflow runs, in place of a list.

## Layout

- The page is portrait letter size, and turns landscape when the table has more than six columns.
- Rows are written in blocks of 1,000, each block repeating the header.
- A null value is an empty cell.
- A cell too long for one page is cut short with an ellipsis, and the step warns with the names of the columns it cut.
- The PDF uses a Unicode font when the workflow engine has one. Without it the PDF is set in Helvetica, which shows only Latin-1 characters, and the step warns.
