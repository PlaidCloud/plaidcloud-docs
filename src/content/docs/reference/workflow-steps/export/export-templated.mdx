## Description

Renders project tables through an XML template to produce a structured document, instead of the raw column dump the other export steps write. Use it when the receiving system requires a specific XML shape rather than a table.

The project and workflow names are available to the template alongside the table data.

## Unique Configuration Items

### Source Template

The XML template the output is rendered from.

### Target Output

The document account, folder, and file name for the rendered result. The output is written as XML.

### Source Table

Name the tables explicitly, or match them by path and a search rule — exact, starts with, ends with, contains, or glob.
