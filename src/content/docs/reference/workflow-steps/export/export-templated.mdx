## Description

Renders project tables through a template document to produce a formatted file — a populated workbook or a report laid out the way its recipient expects — instead of the raw column dump the other export steps write.

Use it when the shape of the output file is fixed by whoever receives it.

## Unique Configuration Items

### Source Template

The template document the output is rendered from.

### Target Output

The document account, folder, and file name for the rendered result.

### Source Table

Name the tables explicitly, or match them by path and a search rule — exact, starts with, contains, or ends with.
