## Description

The **Tableau Hyper Export** step exports a table to a Tableau Hyper file. It runs in the workflow engine; packaged-macro results are an approximation of the Alteryx macro.

## Parameters

- **Source Table** and the **Output file path**.

The Tableau Hyper writer is unavailable in the workflow engine, so a CSV is written instead (a functional downgrade).
