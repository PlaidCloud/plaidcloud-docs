## Description

The **Tableau Hyper Export** step exports a table to a Tableau Hyper file. It runs in the workflow engine; packaged-macro results are an approximation of the Alteryx macro.

## Parameters

- **Source Table** and the **Output file path**.

When the source table doesn't exist, or has no columns when none are mapped, the step succeeds, writes nothing and logs a warning that names the source and the output file. A source with no rows writes an empty extract and logs a warning that says so.
