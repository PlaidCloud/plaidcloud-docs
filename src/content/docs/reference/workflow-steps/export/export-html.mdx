## Description



Writes a PlaidCloud project table to a document account as an HTML file containing a styled table. Useful for emailable reports, simple web previews, or attaching readable data to notifications.

The output is a self-contained HTML table — for richer reporting layouts, use [Report Single](/reference/workflow-steps/reports/report-single/) which renders RML templates to PDF.

### Bold Rows


Select this checkbox to make the first row (header row) bold font.



### Escape


This option is enabled by default. When the checkbox is selected, the export process will convert the characters *&lt;*, *>*, and *&* to HTML-safe sequences.
