## Description



Writes a PlaidCloud table to a document account as a PlaidCloud-native archive file. The archive preserves all column types, indexes, and metadata that PlaidCloud knows about — better fidelity than CSV for round-tripping between PlaidCloud projects or environments.

Pair with [Import Archive](/reference/workflow-steps/import/import-archive/) to bring the archive back into a project. Useful for backups, project-to-project migrations, and cross-environment data transfer.
