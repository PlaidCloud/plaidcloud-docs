## Description

Writes a project table to a document account as an [Apache Avro](https://avro.apache.org/) file. Avro carries its schema inside the file, so column names and types survive the round trip without a separate schema definition — which makes it a good fit for handing data to a Kafka, Spark, or Hadoop consumer.

Pair it with [Import Avro](/reference/workflow-steps/import/import-avro/) to move tables between projects without losing typing.

## Unique Configuration Items

### Compression

The written file can be compressed on the way out:

* No compression
* Zip
* GZip
* BZip2

### File Name

The file is named after the export's **File Name**, with the `.avro` extension added when the name has no extension. An export named `customers` writes `customers.avro`. When the export writes several tables, each file is named after the export followed by the table's alias, as in `customers_orders.avro`. With **Many Files** on, the export writes a folder of that name holding `data1.avro`, `data2.avro` and so on, each with at most the batch size of rows.
