## Description

Writes a project table to a document account as an [Apache Parquet](https://parquet.apache.org/) file. Parquet stores data by column rather than by row, so it compresses far better than CSV on wide tables and lets a downstream reader load only the columns it needs.

This is usually the right choice for handing large tables to a cloud data platform or a data-science workflow. Types — decimals, dates, and timestamps — are preserved. Pair it with [Import Parquet](/reference/workflow-steps/import/import-parquet/).

## Unique Configuration Items

### Compression

Parquet compresses per column chunk:

* **Snappy** — fastest to read, moderate file size
* **Zstandard** — smaller files, needs a reader on Zstandard 0.8 or later
