## Description

Writes project tables into an external database through a [connection](/reference/connectors/), rather than to a file. Use it to push modelled results back into a reporting database, a data warehouse, or an operational system.

The mirror of [Import External Database Tables](/reference/workflow-steps/import/import-external-database-tables/): several tables move in one step, and the target tables can be selected explicitly or matched by a search pattern.

## Unique Configuration Items

### Connection

The data connection identifying the target database.

### Export Type

How each target table is prepared before rows are written:

- **Append Only** — add rows to the existing table; fails if it does not exist.
- **Truncate then Append** — empty the table, keep its structure, then write.
- **Create then Append** — create the table if it is missing, then write.
- **Drop, Create, then Append** — drop and recreate the table, then write. Use when the source schema has changed.

### Frame Name

The name of the frame the step runs under.

### Adding Targets

Use the add and remove target button to build the list of target tables. Select a target to configure it in the right pane, and use **Toggle Selected** to enable or disable the selected targets for export. Export does not scan the target database for tables; add each target yourself. [Import External Database Tables](/reference/workflow-steps/import/import-external-database-tables/) is the step for discovering tables in an external database.

### Target Tabs

A selected target has three tabs.

#### Source and Target

Choose the project tables to export, and where they land.

- **Source** — **Specific Table** names one project table, with a **Dynamic** option for a name that changes at run time. **Tables Matching Search** exports every project table found by a **Search Path** and **Search Text**, matched as **Exact**, **Starts With**, **Contains**, or **Ends With**.
- **Target External Table** — **Enable for export** turns the target on or off. **Target Schema** and **Target Table** name the destination table. **Use same name as source table** reuses each source table's name.

#### Table Data Selection

The column mapper for the target, on its own full-height tab. **Inspect Source** reads the project source table's columns into the mapper.

#### Data Filters

Filter the rows written to the target.
