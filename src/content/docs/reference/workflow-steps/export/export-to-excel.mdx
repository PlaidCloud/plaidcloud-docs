## Description


Export an Analyze data table to PlaidCloud Document as a Microsoft Excel file. PlaidCloud Analyze supports modern versions of Microsoft Excel (2007-2016) as well as legacy versions (2000/2003).



## Export Parameters

<SnippetCommonExportFileSelection />



### Target Sheet Name
Specify the target sheet name, the default is ***Sheet1***


### Selecting File Compression

All exported files are uncompressed, but the following compression options are available:

* No Compression
* Zip
* GZip
* BZip2

### Write Header to First Row
If this checkbox is selected the table headers will be exported to the first row. If it is not there will be no headers in the exported file.

## Size Limits

An Excel worksheet holds at most 1,048,576 rows (the header row counts towards
this) and 16,384 columns. A step that would produce more stops straight away and
tells you so, rather than spending the export producing a file Excel then refuses
to open.

Very large exports can also exceed what the file format itself allows, even when
the row and column counts are within range. If that happens the step reports that
the sheet data is too large.

For data beyond these sizes, export to CSV or Parquet instead — neither has a row
limit, and both are considerably faster to produce and smaller to store.
