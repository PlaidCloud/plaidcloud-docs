## Description

The **Publish to Tableau** step publishes a `.hyper` extract to Tableau Server or Tableau Cloud as a data source. Write the extract first with [Tableau Hyper Export](/reference/workflow-steps/export/export-hyper/), then publish it with this step. The step signs in with the personal access token on a [Tableau connection](/reference/connectors/collaboration/tableau/), uploads the file in chunks, so file size is not limited by a single request, and signs out.

A missing extract file is not an error. The step warns that nothing was published and the workflow continues.

## Parameters

- **Hyper Extract** — the `.hyper` file in a document account to publish.
- **Tableau Connection** — the Tableau connection to publish through.
- **Data Source Name** — the name of the data source in Tableau. Leave blank to use the extract's file name without its extension.
- **Project** — the Tableau project to publish into. Leave blank to use the site's Default project. A project name Tableau doesn't have on the site fails the step.
- **If the Data Source Exists** — the publish mode. See [Modes](#modes).
- **Match Keys** — the columns that match rows, as a comma-separated list. Required for **Upsert**, **Update**, and **Replace Matching Rows**.

## Modes

| Mode | When the Data Source Exists | When It Doesn't |
| --- | --- | --- |
| **CreateNew** | The step fails. | Creates it. |
| **Overwrite** | Replaces it. | Creates it. |
| **Append** | Adds the extract's rows to it. | Creates it. |
| **Upsert** | Updates rows whose match keys match and adds the rest. | Creates it. |
| **Update** | Updates rows whose match keys match and adds none. | Warns and changes nothing. |
| **GroupReplace** | Deletes the rows whose match keys match, then inserts the extract's rows. | Creates it. |

**Append**, **Upsert**, **Update**, and **GroupReplace** look the data source up by name in the project you chose, or in the site's Default project when you chose none, and publish to the project they looked in. The keyed modes change the data source's rows in place, through Tableau's update-data actions.

## Requirements

- The connection's server address must use `https`. A server named with `http` fails the step, because the personal access token would cross the network in the clear. A bare host name is read as `https`.
- The server must be reachable from the internet. PlaidCloud doesn't publish to a Tableau server on a private network.
- The personal access token's owner needs permission to publish to the project.
