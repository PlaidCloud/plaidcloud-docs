## Description

The **Spatial: Centroid** step appends the geometric center of each geometry to every input row, as a WKT point in a column named `Centroid`. All input columns pass through.

## Source & Options

- **Source Table** and **Output Table** — the table to read and the table to write.
- **Geometry column** — the WKT geometry column to measure.
