## Description

The **Spatial: Line to Polygon** step closes each line into a ring and writes it to a column named `Polygon`. A line with fewer than three points gives an empty polygon.

## Source & Options

- **Source Table** and **Output Table** — the table to read and the table to write.
- **Line column** — the column holding the WKT lines to close.
