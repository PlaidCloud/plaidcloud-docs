## Description

The **Spatial: Reproject** step transforms the WKT geometry of every row from one coordinate reference system to another and writes the result to an output table, with the other columns passed through.

The step form has a **Tables** section for the source and output tables and their columns, and a **Projection** section for the geometry column, the two coordinate systems and the output column. [Migrated KNIME workflows](/guides/workflows/migrate-knime-workflows/) use this step for their projection nodes.

## Configuration

- **Source Table** (`source`) and **Output Table** (`target_frame`) — the table to read and the table to write.
- **Geometry Column** (`geometry_column`) — the column holding each geometry as WKT. The default is `SpatialObj`.
- **From Coordinate System** (`source_crs`) — the coordinate reference system the geometries are in, such as `EPSG:4326`.
- **To Coordinate System** (`target_crs`) — the coordinate reference system to project them to, such as `EPSG:3857`.
- **Projected Geometry Column** (`output_column`) — the column that receives the projected geometry. Leave it empty to replace the geometry column itself.
- **Source Columns** (`source_columns`) and **Output Columns** (`target_columns`) — the columns read and the columns passed through, with their data types.

A row with no geometry keeps an empty projected geometry.
