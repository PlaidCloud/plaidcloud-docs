## Description

The **Spatial: Reproject** step transforms the WKT geometry of every row from one coordinate reference system to another and writes the result to an output table, with the other columns passed through.

Create and set the step with an AI assistant or the REST API; it does not have a step form yet. [Migrated KNIME workflows](/guides/workflows/migrate-knime-workflows/) use this step for their projection nodes.

## Configuration

- `source` and `target_frame` — the table to read and the table to write.
- `geometry_column` — the column holding each geometry as WKT. The default is `SpatialObj`.
- `source_crs` — the coordinate reference system the geometries are in, such as `EPSG:4326`.
- `target_crs` — the coordinate reference system to project them to, such as `EPSG:3857`.
- `output_column` — the column that receives the projected geometry. Leave it empty to replace the geometry column itself.
- `source_columns` and `target_columns` — the columns read and the columns passed through, with their data types.

A row with no geometry keeps an empty projected geometry.
