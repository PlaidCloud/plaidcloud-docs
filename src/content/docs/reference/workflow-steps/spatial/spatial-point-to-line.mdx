## Description

The **Spatial: Point to Line** step joins points into a line, written to a column named `SequenceLine`. It writes one line for each group, or one line for all the points when you give no group.

## Source & Options

- **Source Table** and **Output Table** — the table to read and the table to write.
- **Point column** — the column holding the WKT points.
- **Group by** *(optional)* — one line for each value of this column. Leave blank to make all points one line.
- **Order by** *(optional)* — the column that orders the points in a line. Numbers sort as numbers and other values as text. Without it, points keep their input order.
