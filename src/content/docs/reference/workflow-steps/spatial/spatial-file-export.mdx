## Description

The **Spatial: File Export** step writes a table to a spatial file in a Document account, one feature per row: the geometry from a WKT column and the other columns as the feature's attributes. Pair it with [Spatial File Import](/reference/workflow-steps/spatial/spatial-file-import/).

Create and set the step with an AI assistant or the REST API; it does not have a step form yet. [Migrated KNIME workflows](/guides/workflows/migrate-knime-workflows/) use this step for their geospatial file writers.

## Configuration

- `source` — the table to export. `source_columns` lists the columns written.
- `output_file` — the Document account and path of the file. The extension picks the format: `.shp` (ESRI shapefile), `.geojson` or `.json` (GeoJSON), `.gpkg` (GeoPackage), `.kml`, `.gml`, or `.tab` and `.mif` (MapInfo). A format made of several files, such as a shapefile, is written with its companion files beside it.
- `geometry_column` — the column holding each feature's geometry as WKT. The default is `SpatialObj`.
- `crs` — the coordinate reference system the geometries are in, such as `EPSG:4326`, written with the file.
- `if_exists` — `overwrite` (default) replaces a file that is already there; `fail` stops the step before anything is written.
