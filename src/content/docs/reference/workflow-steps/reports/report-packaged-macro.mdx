## Description

The **Packaged Macro** renders a report bundle imported from an Alteryx *packaged report macro*. It is a first-class Report step: the bundled macro definition is carried along with the step automatically, and the piece renders through the same report-artifact path as the other Report steps.

## Source & Options

- **Source Table** — the data feeding this report piece.
- **Target Table** — the table the rendered output is written to.
- **Report Order** — the position of this piece within a composed report.
