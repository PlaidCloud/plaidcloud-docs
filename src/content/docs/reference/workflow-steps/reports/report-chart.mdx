## Description

The **Chart** (bar chart) of the source data for a composed report. It is the equivalent of the matching Alteryx *Reporting* / *Portfolio Composer* tool and runs in the workflow engine (reportlab / matplotlib); the renderer is an approximation of the Alteryx output.

## Source & Options

- **Source Table** — the data feeding this report piece.
- **Output Table** — the table the rendered snippet is written to.
- **Report order** — the order of this piece within a composed report.
- **Chart title** — the title shown above the chart.

## Columns

The **Columns** tab maps the source columns available to the report piece.
