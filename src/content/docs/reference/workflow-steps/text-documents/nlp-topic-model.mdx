## Description

The **Text Topic Model** step discovers topics across a text column. It is the equivalent of the matching Alteryx tool and runs in the workflow engine (the ML / NLP / document libraries run in the executor job).

## Source & Options

- **Source / Output tables** — the input data and where the result is written.
- **Text column**, number of topics, and vocabulary size.

## Columns

The **Columns** tab maps the input columns passed through to the output.
