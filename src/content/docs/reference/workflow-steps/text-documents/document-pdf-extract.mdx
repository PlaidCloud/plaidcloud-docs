## Description

The **PDF Text Extract** step extracts text from PDF documents. It is the equivalent of the matching Alteryx tool and runs in the workflow engine (the ML / NLP / document libraries run in the executor job).

## Source & Options

- **Source / Output tables** — the input data and where the result is written.
- **PDF path column** (or a **directory** of PDFs).

## Columns

The **Columns** tab maps the input columns passed through to the output.
