## Description

The **Text Pre-process** step cleans and normalizes a text column. It is the equivalent of the matching Alteryx tool and runs in the workflow engine (the ML / NLP / document libraries run in the executor job).

## Source & Options

- **Source / Output tables** — the input data and where the result is written.
- **Text column**, output column, and toggles (remove digits / punctuation / stopwords, lemmatize).

## Columns

The **Columns** tab maps the input columns passed through to the output.

## KNIME Text Processing Nodes

A converted KNIME workflow sets `knime_config` to run one of KNIME's Text Processing nodes with this step, named by `node` — for example `preprocess`, `tagger`, `bag_of_words`, `frequency`, `document_vector`, `keywords`, `topics`, `language`, or the embedding nodes — with that node's own settings beside it, such as `document_column` and `output_column`. A node that reads a second table, such as a dictionary, entity list, or vocabulary, reads `source_b` with the columns in `source_b_columns`, and a node with further outputs writes them to the tables listed in `targets`, in order. An AI assistant or the REST API can set the same keys.
