## Description

Writes the workspace's members into a project table. Use it to report on access, reconcile a member list against an HR feed, or drive a downstream step from who currently has access.

## Configuration

### Information to Include

On by default: **Last Name**, **First Name**, **Email**, **Username**, **Member Creation Date**, and **Last Login Timestamp**.

### Additional Settings

Off by default:

- **Include Deactivated Members** — widen the output beyond active members.
- **Login History Mode** — return login history rather than only the last login.
