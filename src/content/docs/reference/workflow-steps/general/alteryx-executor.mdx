## Description

The **Alteryx Executor** step runs a named Alteryx executor operation directly in the parity-image job. This is the shared engine that the first-class Spatial, Machine Learning, Report, and NLP steps delegate to.

Most users should reach for those dedicated steps instead — they present each operation with a purpose-built form. This step is mainly for editing workflows converted from Alteryx before those operations became dedicated steps, where the operation is still expressed as a raw executor call.

## Configuration

- **Operation** *(required)* — the executor operation id to run.
- **Version** — the operation version. Defaults to `v1`.
- **Source Table** — the input data for the operation.
- **Target Table** — the table the operation writes its result to.
- **Advanced Resource Management** — when checked, override the default job resources:
  - **CPU** — the number of CPUs allocated to the job.
  - **Memory (GiB)** — the memory allocated to the job.
