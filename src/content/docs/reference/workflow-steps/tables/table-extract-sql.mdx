## Description

Populates a target table from a SQL `SELECT` you write yourself. Where [Table Extract](/reference/workflow-steps/tables/table-extract/) builds the query from mapped columns and expressions, this step hands the query straight to the warehouse — for the cases where the SQL is easier to express directly than to assemble in the mapper.

Reach for it when you need a construct the mapper does not cover: a recursive CTE, a window function over a partition the mapper cannot describe, or a query against several tables that a join step would make more convoluted.

## Unique Configuration Items

### SQL Select Query

The query text. Format it as readable, multi-line, indented SQL — one column or clause per line — rather than a single long line; the step preserves what you write and the next person to open it has to read it.

The query runs on the project's lakehouse, so the available functions are the [Lakehouse v1](/reference/expressions/lakehouse-v1/) or [v2](/reference/expressions/lakehouse-v2/) set, depending on the workspace.
