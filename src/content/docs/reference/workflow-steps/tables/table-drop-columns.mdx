## Description

The **Table: Drop Columns** step writes a copy of the source table to the output table, leaving out the columns you choose. Every other column keeps its name, type, and position.

## Source & Options

- **Source Table** and **Output Table** — the table to read and the table to write.
- **Columns to drop** — the columns to leave out. Choose at least one. A column the source doesn't have is ignored, so the step still runs when an earlier step stops producing it.
- **Numeric order prefix** *(optional)* — put the kept columns that start with this text in numeric order, in the positions they occupy. With the prefix `Tags_`, `Tags_2` comes before `Tags_10` instead of after it.
- `drop_from` and `drop_from_column` *(set with an AI assistant or the REST API)* — a table whose `drop_from_column` cells (default column `drop`), each a JSON list of column names, name more columns to leave out. The table is read when the step runs.
