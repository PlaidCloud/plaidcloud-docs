## Description


Clear the contents of an existing data table without deleting the actual data table. The end result is a data table with 0 rows.



<SnippetCommonTableSelectionDynamic />

With **Tables Matching Search**, the step won't save with an empty **Search Text** while the **Search Path** is the project's top level (`/`), because that would clear every table in the project. Enter text to match, or choose a folder.
