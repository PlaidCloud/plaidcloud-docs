## Description

Copies a table from one project to another. Use it to pull a shared reference table, a published result set, or a dimension-backed lookup between projects without exporting to a file and importing it back.

Both sides are named explicitly — a source project and table, and a target project and table. The target table is created if it does not exist, and must be a table rather than a view.

## Data Sharing Management

The source project has to let the target project read it. Open the **source** project's **Home** tab, and under **Data Sharing Management** click **New Data Share**, select the target project, tick **Read** under **Allowed Operations**, and click **Add Data Share**. See [Sharing Data Between Projects](/guides/projects/managing-projects/#sharing-data-between-projects).

The step runs as this project's own identity, so a run works through the share whoever starts it.

## Unique Configuration Items

### Write To

- **Replace** (default) — the target table is rewritten from the source.
- **Append** — the copied rows are added to whatever the target table already holds.
