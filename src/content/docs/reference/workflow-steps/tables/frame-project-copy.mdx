## Description

Copies a table from a different project into this one. Use it to pull a shared reference table, a published result set, or a dimension-backed lookup from an upstream project without exporting to a file and importing it back.

The source project must be one this workspace can read.

## Unique Configuration Items

### Write To

- **Replace** (default) — the target table is rewritten from the source.
- **Append** — the copied rows are added to whatever the target table already holds.
