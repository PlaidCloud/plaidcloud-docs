## Description

Copies a table from one project to another. Use it to pull a shared reference table, a published result set, or a dimension-backed lookup between projects without exporting to a file and importing it back.

Both sides are named explicitly — a source project and table, and a target project and table. The target project starts as the current project, but can be any project, so a step can copy into this project, out of it, or between two others. The target table is created if it does not exist, and must be a table rather than a view.

## Data Sharing Management

A copy needs up to two data shares:

- **Read, from the source project to the target project**, so the source's data lands only where the source shares it. Open the **source** project's **Home** tab, and under **Data Sharing Management** click **New Data Share**, select the target project, tick **Read** under **Allowed Operations**, and click **Add Data Share**.
- **Write, from the target project to this project** — the project the workflow is in, which does the writing — when the target is another project. Open the **target** project's **Home** tab, and under **Data Sharing Management** click **New Data Share**, select this project, tick **Write** under **Allowed Operations**, and click **Add Data Share**.

So a copy into this project needs only the Read share, and a copy within one project needs neither. See [Sharing Data Between Projects](/guides/projects/managing-projects/#sharing-data-between-projects).

Without a share it needs, saving the step is refused and a run fails, with a message naming each share to add — for example *Project 'Sales' can't write to project 'Finance': in project 'Finance', under Data Sharing Management, add a data share for 'Sales' that allows Write.* A refused run leaves the target project as it was, without creating the target table. A project given as a variable is checked when the step runs.

The step runs as this project's own identity, so a run works through the shares whoever starts it.

## Copy Parameters

### Read From

- **Source Project** — the project to copy from.
- **Source Table** — the table to copy, chosen from the source project.

### Write To

- **Target Project** — the project to copy into. It starts as the current project.
- **Target Table** — the table to write, chosen from the target project. Picking a different **Target Project** clears a table you chose from the old one; a table given by name or path is kept, and found in the new project.
- **Append to Existing Data** — tick to add the copied rows to whatever the target table already holds. Leave it unticked to replace the table's rows with the source's.

A saved project that you can't see, or that has been deleted, is shown marked **(missing)** rather than being swapped for another project.
