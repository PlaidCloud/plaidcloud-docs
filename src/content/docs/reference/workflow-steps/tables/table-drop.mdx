## Description

Removes a table from the project entirely — both the table definition and all of its data. This is destructive and irreversible; once the workflow runs, the table is gone.

Use this when intermediate tables in a workflow are no longer needed downstream (cleanup after a multi-step transformation, for example). For temporarily emptying a table without removing it, use [Table Clear](/reference/workflow-steps/tables/table-clear/) instead.
