## Description

The **Table: Period Spine** step writes one row for each period between a first and a last date, whether or not any record falls in it. Join the spine to your summarized data to show a period with no activity as zero instead of leaving it out.

## Source & Options

- **Source Table** and **Date column** — the table whose dates set the bounds. They're needed unless you give both a first and a last date, and the source isn't read when you do.
- **Period** — **Day**, **Week**, **Month**, **Quarter**, **Year**, or **Decade**. A week starts on Monday.
- **First date** *(optional)* — the first period. Leave blank to start at the earliest date in the source table.
- **Last date** *(optional)* — the last period. Leave blank to end at the latest date in the source table. A first date after the last date is swapped with a warning.
- **Output column** — the name of the date column holding each period's first day. The default is `Period Start`.
- **Output Table** — where the spine is written.

The step stops at 100,000 periods and warns when it does. Choose a longer period or narrower dates for a larger range.
