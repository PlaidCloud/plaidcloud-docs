## Description

Adds rows from a source table to the end of an existing target table. Existing rows in the target are preserved; only new rows are inserted. Use this when you have data arriving incrementally (e.g., daily extracts, monthly load files) and want to grow the target over time rather than replacing it.

If you need to deduplicate as you append, follow with a [Table Union Distinct](/reference/workflow-steps/tables/table-union-distinct/) step, or use [Table Upsert](/reference/workflow-steps/tables/table-upsert/) if some rows update existing records by key.

## What's Checked When You Save

- **The mapping fits an existing target table.** When the target table already exists, the step can't map a column the table doesn't have, or give a column a different type from the table's. Numeric and currency count as the same type. A table column the mapping leaves out is allowed, and is left empty in the appended rows. The refusal names each difference, for example *The target columns must match the existing target table 'sales'. Types differ: amount (table: numeric, step: text).* A target table that doesn't exist yet, or one named with a variable, is checked when the step runs.
- **An empty mapping is filled for you.** Saving with a source table chosen but no source or no target columns fills the empty side from the source, as **Populate Both Mapping Tables** would.
