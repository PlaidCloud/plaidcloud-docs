## Description

The **Table: Promote Header** step takes one row of the input and makes its values the column names, then removes that row. Use it for a file whose real header isn't the first line. The step runs when the workflow runs, so the names come from the data.

## Source & Options

- **Source Table** and **Output Table** — the table to read and the table to write.
- **Header row** — the row, counted from 1, whose values name the columns. It's removed from the data. Leave it empty to promote no header and apply the format steps to the stored names.
- **Record order column** *(optional)* — the column that puts the rows in order. Without it, rows are read as stored, so which row names the columns can change from run to run.
- **Columns when the input is empty** *(optional)* — comma-separated names of text columns to write when the input has no rows.

## Format Steps

Each row of the **Format Steps** grid changes the promoted names.

| Setting | Choices |
| --- | --- |
| Action | **Rename**, **Change type**, **Hide**, **Fill blanks** |
| Matcher | **Contains**, **Starts with**, **Ends with**, or **Is empty** |
| Matching text | The text to match in the column name. Not needed for **Is empty**. |
| Rename by | **Replacing text**, **Adding before**, or **Adding after**, for a rename |
| Replace with | The new text for a rename or fill |
| Value | The type for **Change type** |

Each step needs an action and a matcher, and a rename needs a rename method and its text.
