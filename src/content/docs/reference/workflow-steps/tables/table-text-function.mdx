## Description

The **Table: Text Function** step applies a text function to one or two columns of each row and writes the result to a new column of a copy of the source table. A NULL in any column the function reads gives NULL.

## Source & Options

- **Source Table** and **Output Table** — the table to read and the table to write.
- **Function** — the native form offers **Levenshtein distance**, the case-sensitive edit distance between two columns, as a whole number.
- **First column** and **Second column** — the columns the function reads, in order.
- **Output column** — the name of the column added to the copy of the source.

A converted Savant analysis can also carry these functions, which run the same way and show their stored settings when you open the step:

| Function | Result |
| --- | --- |
| `soundex` | Text |
| `json_format` | Pretty-printed JSON text |
| `json_field` | Text |
| `json_set_text`, `json_set_number`, `json_set_boolean` | JSON text with the value set |
| `regex_match` | True or false |
| `regex_search` | Position, as a whole number |
| `regex_extract`, `regex_replace` | Text |
