## Ad-Hoc Extract Steps

Three steps search SAP, preview and plan the extract, and land the result in a table. One reads a table, one runs a transaction or report, and one runs a saved SAP Query. See [Ad-Hoc Extracts from SAP ECC / S/4HANA](/guides/connections/sap-adhoc-extract/).
