## Description



Imports text files where columns are defined by character positions rather than delimiters — the classic mainframe / COBOL output format. Configure column boundaries (start position, length) per field.

Common with legacy ERP exports, government filings, and bank statement formats where data has been laid out for fixed-column display rather than delimited parsing.

Fixed-width imports stream through temporary storage rather than loading the whole file into memory, so very large files import without running out of memory.

### Header

Since Excel files may or may not contain headers, PlaidCloud provides a way to either use the headers, ignore headers, or use column order to determine the column alignment.
* **No Header**: The file contains no header.  Use the source list in the *Data Mapper* to determine the column alignment
* **Has Header - Use Header and Override Field List**: The file has a header.  Use the header names specified and ignore the source list in the *Data Mapper*.
* **Has Header - Skip Header and Use Field List Instead**: The file has a header but it should be ignored.  Use the header names specified by the source list in the *Data Mapper*.

### Row Selection

For input files with extraneous records, you can specify a number of rows to skip before processing the data.  This is useful if files contain header blocks that must be skipped before arriving at the tabular data.

### Column Widths

Enter the widths of the columns seperated with commas or spaces.

### Layout

| Setting | What it does |
| --- | --- |
| Encoding | The file's character set: **UTF-8** (the default), **EBCDIC (US, cp037)**, **EBCDIC (International, cp500)**, or **Latin-1**. Choose an EBCDIC code page for a mainframe file. |
| Records to Skip | How many records to skip at the start of the file, before the header or the data. |
| Records to Drop at End | How many records to drop from the end of the file, such as a trailer record. |
| One Record per Line | On (the default), each line is a record. Clear it for a file whose records are laid end to end with no line breaks; each record is then as long as the column widths together. |
| Characters Between Records | When records aren't one per line, how many characters to skip after each record, such as a separator. |
| Strip Blanks | The blanks removed from each value: **Leading and Trailing** (the default), **Trailing Only**, or **None**. |
