## Description

Restores project tables from an archive created by [Archive Tables](/reference/workflow-steps/export/archive-tables/). Use it to move table data between projects or workspaces, or to roll back to a parked copy.

## Unique Configuration Items

### Source

The archive file in a document account.

### Overwrite

Off by default. When off, a table that already exists in the project is left alone. Turn it on to replace existing tables with the archived copies.
