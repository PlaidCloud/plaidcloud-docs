## Description

The **Import: Delimited (by position)** step reads every column of a delimited document by position, as text columns named `Column_1` to `Column_N`, and skips the header line. Use it when the header can't name the columns, for example when a later step promotes a data row to the header.

## Parameters

- **Document** — the document account and path of the file. A path ending in `.gz` is decompressed.
- **Delimiter** — the field delimiter. The default is a comma.
- **Quote character** — the default is a double quote.
- **Record number column** *(optional)* — a column that numbers the records in file order. Leave blank to write none.
- **Output Table** — where the rows are written.

A missing document isn't an error. The step finishes with a warning that names the path and writes an empty table.
