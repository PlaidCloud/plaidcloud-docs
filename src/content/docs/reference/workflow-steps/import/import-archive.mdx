## Description


Imports a PlaidCloud-native archive file back into a project table. The archive format preserves column types, metadata, and indexes that don't survive a CSV round-trip.

Created by [Export to Table Archive](/reference/workflow-steps/export/export-to-table-archive/). Used for project backups, migrations between workspaces or environments, and reliable transfer of typed data.
