## Description

Import Apache ORC files from PlaidCloud Document. ORC is a columnar storage format written by Hive and Spark, with the schema carried in the file.

Create and set the step with an AI assistant or the REST API; it does not have a step form yet. Its configuration keys are `input_file` (the Document account and file path), `target_frame` (the target table), `source_columns` and `target_columns` (the column mapping), `source_where`, `having`, `distinct` and `aggregate` (filtering and summarizing), `delete_file`, `ascii_only` and `skip_if_unchanged`. [Migrated Prophecy projects](/guides/workflows/migrate-prophecy-projects/) use this step for ORC datasets.
