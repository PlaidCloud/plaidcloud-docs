## Description

Imports the items of a [monday.com](https://monday.com/) board into a project table over a monday.com connection. Use it to bring project tracking, intake queues, or operational task data into a workflow alongside financial data.

## Unique Configuration Items

### Connection Configuration

The monday.com connection to read through.

### Target Table

**Board ID** — the monday.com board whose items are imported.
