## Description

Imports the items of one or more [monday.com](https://monday.com/) boards into project tables over a monday.com connection. Use it to bring project tracking, intake queues, or operational task data into a workflow alongside financial data.

## Unique Configuration Items

### Connection Configuration

The monday.com connection to read through.

### Target Table

One row per board: the **board ID** to read and the project table it is written to. A single step can import several boards at once. Each target must be a table, not a view.
