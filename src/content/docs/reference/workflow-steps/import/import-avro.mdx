## Description

Import Apache Avro files from PlaidCloud Document. Avro is a row-based data serialization format from the Apache Hadoop project that stores data along with its schema, making it well suited for use in data pipelines and streaming systems.

## Unique Configuration Items

### File Modified Time

Read only the files changed in a window of time. **Modified After** reads only files last modified after the time you enter, and **Modified Before** only files last modified before it; set either or both. Enter a time as `YYYY-MM-DDTHH:MM:SS`, such as `2026-10-01T00:00:00`. A time is UTC unless it names a zone, such as `2026-10-01T00:00:00-05:00`. A time can hold a workflow variable, which is read when the step runs.
