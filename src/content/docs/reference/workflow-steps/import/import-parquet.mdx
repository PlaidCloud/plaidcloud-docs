## Description

Import Apache Parquet files from PlaidCloud Document. Parquet is a columnar storage format widely used in the Hadoop ecosystem and cloud data platforms, offering efficient compression and encoding for large datasets.

Parquet imports stream through temporary storage rather than loading the whole file into memory, so very large files import without running out of memory. The file's data types — decimals, dates, and timestamps — are preserved in the target table, and timestamp columns keep their full date and time-of-day precision.
