## Description


Imports HDF5 (Hierarchical Data Format version 5) files into PlaidCloud project tables. HDF5 is common in scientific computing, machine learning data exchange, and any setting where typed, columnar data needs to round-trip between Python/R/MATLAB tooling.

See the [HDF Group's documentation](http://www.hdfgroup.org/HDF5/) for the format specification.

## Unique Configuration Items


### Key Name

HDF files store data in a path structure. A key (path) is needed as the destination for the table within the HDF file. In most situations, this will be *table*.
