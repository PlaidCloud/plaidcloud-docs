## Description


Imports tabular data from an XML file into a PlaidCloud project table. Configure the element path that identifies each 'row' and map child elements or attributes to table columns.

Common with older enterprise integrations, B2B data exchange (RosettaNet, ebXML), and government filing formats.


## Read Records As

**Read Records As** chooses how the file becomes tables:

* **One Table Per Record Tag** (default) — the **Record Tags** tab lists each tag to read, and each tag loads into its own table, named from the **Target Tables Prefix**.
* **One Row Per Element** — one repeating element loads into one table, a row for each occurrence. The **Record Tags** tab and **Target Tables Prefix** are disabled.

With **One Row Per Element**, set:

* **XML Element** — the element that makes a row. Left blank, it is the first column's element, shown in the field.
* **Target Table** — the table to load.
* **Columns** — each **Child Element or Attribute** and the **Column** it loads into. Every column is imported as text.
* **Trim Spaces Around Values** — strip leading and trailing whitespace from each value.
* **Match Names With Their Namespace Prefix** — match element and attribute names as written in the file, prefix included.

Source File, Target Table, and either an XML Element or at least one column are required. Switching modes keeps the other mode's settings in the form, so switching back restores them, but saving removes the settings of the mode you switched away from; a note beside the control says what.

Steps saved from the form read their record tags as set on the **Record Tags** tab.
