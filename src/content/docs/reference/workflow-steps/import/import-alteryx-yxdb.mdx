## Description

Import Alteryx YXDB files from PlaidCloud Document. YXDB is the native binary file format used by Alteryx Designer to store datasets along with field metadata.

YXDB imports stream through temporary storage rather than loading the whole file into memory, so very large files import without running out of memory. The file's data types — decimals, dates, and timestamps — are preserved in the target table.
