## Description

Imports Sage general ledger detail over a Sage connection, bounded by a date range and an account range, with the dimensions you select carried onto each row.

Use this when you want GL detail on a familiar shape. For an ad-hoc query against any Intacct object, use [Import Sage Intacct Query](/reference/workflow-steps/import/import-intacct-query/) instead.

## Unique Configuration Items

### Source and Target

- **Connection** — the Sage connection to read through.
- **Company** — the Sage company to read from.

### Data Selection

- **Start date** / **End date** — the posting-date window to import.
- **Start account** / **End account** — the account-code range to include.
- **Entities** — the Sage entities to include.
- **Dimensions** — switch on the dimensions you want as columns: class, contact, cost type, customer, department, employee, item, location, project group, task, vendor, and warehouse.
- **Custom dimensions** — any additional user-defined dimensions to carry through.
