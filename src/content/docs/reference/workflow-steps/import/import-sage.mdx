## Description

Imports Sage Intacct **account balances by dimension** over a Sage connection (Intacct's `get_accountbalancesbydimensions`), bounded by a date range and an account range, with the dimensions you select carried onto each row. The result is a trial balance: one row per account per dimension combination, carrying an opening (`startbalance`), period (`periodbalance`), and ending (`endbalance`) balance.

Use this for a trial balance or a balances-based P&L. The **Statistical** control (below) also reaches Intacct's non-monetary statistical accounts — headcount, square footage, units — so a single step can pull financial balances, statistical balances, or both, letting you build per-unit metrics without a separate export. For transaction-level general ledger detail, use [Import Sage Intacct Query](/reference/workflow-steps/import/import-intacct-query/) against `GLDETAIL`; for an ad-hoc query against any Intacct object, use the same step with your object name.

## Unique Configuration Items

### Source and Target

- **Connection** — the Sage connection to read through.
- **Company** — the Sage company to read from.

### Data Selection

- **Start date** / **End date** — the period the balances are reported over (both are required; a lone start or end date is ignored).
- **Start account** / **End account** — the account-code range to include. Use `0000` and `9999` to cover every account regardless of number — the usual choice when **Statistical** below is set to pull statistical accounts, since Intacct's statistical accounts aren't guaranteed to sit inside your financial chart's numbering.
- **Statistical** — which kind of account balances the pull returns:
  - **Financial only (exclude statistical)** — returns only financial account balances (the normal trial-balance pull). This is the default.
  - **Financial + statistical** — returns financial and statistical account balances together in the same result.
  - **Statistical only** — returns only statistical account balances: headcount, square footage, units, and any other non-monetary accounts your Intacct chart tracks alongside the financial one.
- **Entities** — the Sage entities to include.
- **Dimensions** — switch on the dimensions you want as columns: class, contact, cost type, customer, department, employee, item, location, project group, task, and vendor.
- **Custom dimensions** — any additional user-defined dimensions to carry through.

:::caution[The Warehouse checkbox does nothing]
The step configuration offers a **Warehouse** dimension, but the workflow runner
does not read it — the dimension is absent from the set it builds, so switching
it on adds no column. Use **Custom dimensions** if you need warehouse on the
output.
:::
