## Description


Imports data from Google BigQuery into a PlaidCloud project table. Useful for organizations using BigQuery as a primary analytics warehouse and pulling specific datasets into PlaidCloud for further modeling or allocation work.

Authentication uses a Google Cloud service account; the source dataset and table are configured at the step level.
