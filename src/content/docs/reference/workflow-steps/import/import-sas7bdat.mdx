## Description



Imports SAS data files (.sas7bdat format) into PlaidCloud project tables. Useful for organizations migrating from SAS-based analytics or interoperating with SAS-using teams.

Column types, lengths, and labels are preserved as faithfully as PlaidCloud's data model allows.
