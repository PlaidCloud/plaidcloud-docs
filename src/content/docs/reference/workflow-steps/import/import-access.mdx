## Description

Reads a Microsoft Access database file from a document account and imports its tables — one project table per Access table, named with a prefix you choose.

Because an Access file holds many tables, this step imports the file as a whole rather than mapping a single table's columns.

## Unique Configuration Items

### Source

The Access database file in a document account. The file picker also supports matching by search rather than an exact path, with a recursive option and a rule for reconciling schema differences across matched files.

### Target

**Table prefix** — prepended to each imported table's name, so one file's tables stay grouped and do not collide with another import's.

### Skip if Unchanged

On by default. A workflow run skips the import entirely — download included — when the source file has not changed since the last run.
