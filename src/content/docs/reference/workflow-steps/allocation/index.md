Workflow steps for cost allocation, chargeback, transfer pricing, and similar value-distribution problems. Each step spreads values from a source set of rows to a target set using driver data and a method.

## Steps

- [Allocation Rules](/reference/workflow-steps/allocation/allocation-rules/) — define and apply allocation rules with explicit conditions.
- [Allocation Split](/reference/workflow-steps/allocation/allocation-split/) — split source values across targets using a driver table.
- [Rule-Based Tagging](/reference/workflow-steps/allocation/rule-based-tagging/) — tag rows with attributes from a dimension before allocating.
