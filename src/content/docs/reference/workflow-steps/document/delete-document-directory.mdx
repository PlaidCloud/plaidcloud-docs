## Description


Delete an existing directory from within PlaidCloud Document.



## Folder to Delete


First, select the appropriate account from the dropdown menu.


Next, press the **Browse** button to select the directory to delete.


<Aside>A folder that isn't there is never an error. The step does nothing, and finishes with a warning naming the path when the storage reports the folder missing.</Aside>


## Delete Only the Files

To clear a folder but keep it, set these options with an AI assistant or the REST API; the step form doesn't show them yet.

* `files_only` — delete the files in the folder and leave the folder and its subfolders in place.
* `include_subdirs` — with `files_only`, also delete the files in every subfolder below it.
* `file_name_filter` — only files whose name matches, given as `pattern`, `type` (`wildcard` or `regex`) and `case_sensitive`.
* `folder_name_filter` — only files in folders whose names match, in the same form; every folder on the way down must match.
* `extensions` — only files with one of these extensions, without the dot. `extensions_case_sensitive` matches them with case.
* `include_hidden_files` and `include_hidden_folders` — clear either to leave out files or folders whose name starts with a dot.

When no files are found, including when the folder is missing, the step does nothing and finishes with a warning naming the path.
