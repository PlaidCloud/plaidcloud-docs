## Description


Delete an existing directory from within PlaidCloud Document.



## Folder to Delete


First, select the appropriate account from the dropdown menu.


Next, press the **Browse** button to select the directory to delete.


<Aside>A folder that isn't there is never an error. The step does nothing, and finishes with a warning naming the path when the storage reports the folder missing.</Aside>


## Delete Only the Files

To clear a folder but keep it, check **Delete only the files in it, leaving its folders** (`files_only`). The **Which Files** options then narrow what is deleted.

* **Delete only the files in it, leaving its folders** (`files_only`) — delete the files in the folder and leave the folder and its subfolders in place.
* **Also the files below its subfolders** (`include_subdirs`) — with `files_only`, also delete the files in every subfolder below it.
* **File Name Pattern** (`file_name_filter`) — only files whose name matches. **Pattern Type** is **Wildcard** or **Regular expression** (`type`), and **Match case** sets `case_sensitive`.
* **Folder Name Pattern** (`folder_name_filter`) — only files in folders whose names match, in the same form; every folder on the way down must match.
* **Extensions** (`extensions`) — only files with one of these extensions, without the dot. **Match the extension's case** (`extensions_case_sensitive`) matches them with case.
* **Include hidden files (a name starting with a dot)** (`include_hidden_files`) and **Include hidden folders and what is below them** (`include_hidden_folders`) — clear either to leave out files or folders whose name starts with a dot.

When no files are found, including when the folder is missing, the step does nothing and finishes with a warning naming the path.
