## Description

The **Document: Update Excel Cells** step writes values into individual cells of an `.xlsx` workbook in a Document account, leaving the rest of the workbook as it is. Each row of the input table names a cell and the value to write there. The step can instead apply formatting to the workbook, driven by a table of formatting instructions.

The step form has three groups of options: **Workbook**, **Cells**, and **Formatting**. Migrated KNIME workflows use this step for their Excel cell updater and formatter nodes.

A workbook that isn't there is never an error: the step leaves it alone and finishes with a warning naming the path.

## Set Cell Values

- **Source Table** (`source`) — the table of cell addresses and their new values. **Source Columns** (`source_columns`) lists the address column and the value columns.
- **Address Column** (`address_column`) — the column holding each cell address, such as `A5`, or `column:row` as numbers from 1.
- **Workbook** (`file`) — the workbook to update, `{account, path}`.
- **Sheet** (`sheet_name`) — the sheet to update. A sheet of that name is added when the workbook has none.
- **Written for a Missing Value** (`replace_missing`) — written to a cell whose row holds no value. Leave it empty to leave the cell blank.

## Format the Workbook

Set **Formatting Instructions Table** (`source_b`) to a table of formatting instructions, with one row for each instruction. **Instruction Columns** (`source_b_columns`) names its Kind, Tag and Params columns. Kind is `font`, `background`, `cell`, `border`, `merge`, `conditional`, `size`, `comment`, `hyperlink`, `sheet_properties` or `sheet`, and Params holds the instruction's settings as JSON. **Source Table** is then a control table laid over the sheet: each of its cells holds the comma-separated tags of the instructions that apply to that cell. **Address Column** and **Sheet** are not used.

## Write a Copy

- **Write the Updated Workbook To** (`output_file`) — write the updated workbook to this `{account, path}` instead of over the original.
- **A File That Exists** (`if_exists`) — with **Write the Updated Workbook To**, **Overwrite it** (`overwrite`, the default) replaces a file that is already there and **Fail the step** (`fail`) stops the step.
