## Description

Writes a table listing the files in a document directory. Use it to drive downstream steps from whatever files are present — for example, to loop over every file in a folder or to check what an upstream process delivered.

## Directory

Select a document account, then press the **Browse** button to pick the folder to list.

## Options

- **File Pattern** *(optional)* — a glob such as `*.csv` to list only matching files. Leave blank to list everything.
- **Include Subdirectories** — when checked, files in nested folders are listed as well.
- **Target Table** — the table that receives the listing.

## Additional Settings

An AI assistant or the REST API can also set these keys:

- `include_folders` — also list folders, as rows. Every row then carries a trailing `IsFolder` column, true for a folder.
- `include_root_folder` — with `include_folders`, also list the directory itself, first.
- `file_name_filter` — only files whose name matches, given as `pattern`, `type` (`wildcard` or `regex`) and `case_sensitive`.
- `folder_name_filter` — only entries in folders whose names match, in the same form; every folder on the way down must match.
- `extensions` — only files with one of these extensions, without the dot. `extensions_case_sensitive` matches them with case.
- `include_hidden_files` and `include_hidden_folders` — clear either to leave out files or folders whose name starts with a dot.
