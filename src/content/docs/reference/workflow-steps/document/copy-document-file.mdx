## Description


Copy a single file within PlaidCloud Document.



## File to Copy


First, select the appropriate account from the dropdown menu.



Next, press the **Browse** button to select the file you’d like to copy.

Instead of one file, you can choose **Copy Files Matching Search**, which copies the files whose names match your search text (**Exact**, **Starts With**, **Contains**, or **Ends With**), or **Copy All Files in Directory**. When you copy a whole folder:

* **Keep Subfolders** lands each file under its path below the folder, so the copy keeps the folder's structure. Without it, every file lands directly in the destination folder by its name.
* **Skip Subfolders** copies only the folder's own files, none from its subfolders.

**Only Copy Files Whose Names Match (Regular Expression)** narrows any of these choices to the files whose name matches a regular expression from its start, such as `sales_\d{4}\.csv`. Matching is case-sensitive. Leave it blank to copy every chosen file. A pattern that isn't a valid regular expression, or that repeats a part which itself repeats, such as `(a+)+`, is refused when you save the step.

A source file or folder that is missing or empty finishes the step with a warning naming the path, and nothing is copied.



## Select Destination


First, select the appropriate account from the dropdown menu.



Next, press the **Browse** button to select the destination for the copied file.



By default, Analyze will not allow files to be overwritten. Instead, a numerical suffix will be added to each subsequent copy. 



To overwrite the existing file, simply check the **Allow Overwriting Existing File** box.



To rename the file, check the **Rename the copied file to** box and type in a new name.

<Aside>Be sure to provide a file extension when changing the name of the file. The file will be created successfully without an extension, but operating systems won’t know its type.</Aside>


## Additional Settings

Under **If the File Exists**, **A File That Exists** (`overwrite_policy`) sets what happens when a file is already at the destination: **Copy over it** (`overwrite`, the default), **Copy over it when the source is newer** (`overwrite_if_newer`), **Leave it as it is** (`skip`), or **Fail the step, copying nothing** (`fail`).

With **Copy All Files in Directory**, the **Which Files** options narrow what is copied:

* **Files Below Subfolders** (`include_subdirs`) — **No** copies only the folder's own files and **Yes** copies every file below it, keeping their folders. Leave it unset to copy every file into the destination folder by its name, as **Keep Subfolders** and **Skip Subfolders** say.
* **File Name Pattern** (`file_name_filter`) — only files whose name matches. **Pattern Type** is **Wildcard** or **Regular expression** (`type`), and **Match case** sets `case_sensitive`.
* **Folder Name Pattern** (`folder_name_filter`) — only files in folders whose names match, in the same form; every folder on the way down must match.
* **Extensions** (`extensions`) — only files with one of these extensions, without the dot. **Match the extension's case** (`extensions_case_sensitive`) matches them with case.
* **Include hidden files (a name starting with a dot)** (`include_hidden_files`) and **Include hidden folders and what is below them** (`include_hidden_folders`) — clear either to leave out files or folders whose name starts with a dot.
