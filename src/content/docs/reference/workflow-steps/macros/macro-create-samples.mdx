## Description

The **Create Samples (macro)** step reproduces the Alteryx *Create Samples* packaged macro. It runs in the workflow engine; packaged-macro results are an approximation of the Alteryx macro.

## Parameters

- **Source / Output tables**.
- **Estimation %** and **Random seed**.
