## Description

The **Heat Map (macro)** step reproduces the Alteryx *Heat Map* packaged macro. It runs in the workflow engine; packaged-macro results are an approximation of the Alteryx macro.

## Parameters

- **Source / Output tables** and the **Max distance**.
