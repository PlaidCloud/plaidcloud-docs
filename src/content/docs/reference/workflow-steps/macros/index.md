Workflow steps that reproduce the Alteryx *packaged macros* — the macros that ship with Alteryx rather than ones you author. Each runs in the workflow engine, and its result is an approximation of the Alteryx macro.

These are distinct from [PlaidCloud Macros](/reference/workflow-steps/workflow-control/run-macro/), which are reusable step sequences you build yourself.
