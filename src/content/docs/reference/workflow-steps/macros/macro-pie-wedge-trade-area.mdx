## Description

The **Pie Wedge Trade Area (macro)** step reproduces the Alteryx *Pie Wedge Trade Area* packaged macro. It runs in the workflow engine; packaged-macro results are an approximation of the Alteryx macro.

## Parameters

- **Customers / Stores tables**, the **Output Table**, and the **Buffer size**.
