## Description

Imports data from Workday Financials over your [Workday Financials connection](/guides/connections/workday-financials/) into a project table. Unlike NetSuite, Acumatica, or Business Central, PlaidCloud has no fixed set of canned Workday Financials entities — instead, you build a **Report-as-a-Service (RaaS) report** in Workday, publish it with Web Service access, and give this step the report's URL as its extract source.

## Configuration

| Field | Required | Notes |
|---|---|---|
| Workday Connection | Yes | The Workday Financials connection to read through. |
| RaaS Report URL | Yes | The Web Service URL of the RaaS report you built and published in Workday. |
| Target Table | Yes | The project table the results are written to. It is overwritten in full on every run. |
| Filters | No | `company`, `ledger`, `period`, `accounting_date` (range), `ledger_account` (range), `cost_center`. Each is passed as a report parameter — a filter only takes effect if your RaaS report defines a matching prompt. |

<Aside type="caution">
Setting a filter with no matching prompt on the report is rejected, not silently ignored. Add the prompt to the RaaS report in Workday first, then set the filter here.
</Aside>

<Aside type="note">
Because the report itself defines the fields returned, the shape of your import — column names, grain, included dimensions — is whatever your RaaS report produces. Design the report with the target table's expected shape in mind.
</Aside>
