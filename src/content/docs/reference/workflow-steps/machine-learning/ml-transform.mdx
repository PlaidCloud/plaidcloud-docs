## Description

The **ML Transform** step transforms features (impute / encode / scale). It is the equivalent of the matching Alteryx tool and runs in the workflow engine (the ML / NLP / document libraries run in the executor job); results are an approximation of the Alteryx tool pending validation.

## Source & Options

- **Source / Output tables** — the input data and where the result is written.
- **Transformer** — the transform to apply.

## Columns

The **Columns** tab maps the input columns passed through to the output.
