## Description

The **ML Train Regressor** step trains a regression model. It is the equivalent of the matching Alteryx tool and runs in the workflow engine (the ML / NLP / document libraries run in the executor job); results are an approximation of the Alteryx tool pending validation.

## Source & Options

- **Source / Output tables** — the input data and where the result is written.
- **Target variable**, **Algorithm**, and the **numeric / categorical features**.

## Columns

The **Columns** tab maps the input columns passed through to the output.
