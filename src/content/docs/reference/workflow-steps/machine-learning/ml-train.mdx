## Description

The **ML Train Model** step trains a model from a labelled table. It is the equivalent of the matching Alteryx tool and runs in the workflow engine (the ML / NLP / document libraries run in the executor job); results are an approximation of the Alteryx tool pending validation.

## Source & Options

- **Source / Output tables** — the input data and where the result is written.
- **Target variable** — the column to predict.
- **Algorithm** — the model algorithm.
- **Numeric / Categorical features** — which columns to use and how to treat them.

## Columns

The **Columns** tab maps the input columns passed through to the output.
