title: Stop PCM Model Calculation
description: Stop a running SAP PCM model calculation from a PlaidCloud workflow step to halt processing when errors or issues are detected.
---

## Description



Aborts an in-progress SAP PCM model calculation. Useful when a calculation is taking too long, was started with bad input data, or needs to be stopped to free server resources for a higher-priority job.

If no calculation is currently running, the step writes a warning to the workflow log and continues.


## Our Credentials


PlaidCloud is an official SAP Partner and a preferred vendor of services related to SAP PCM model design and implementation.




## Examples


Select Agent to Use from the dropdown, enter “Model Name”, click the “Wait for Copy to Complete” check box, then click “Save and Run Step”.
