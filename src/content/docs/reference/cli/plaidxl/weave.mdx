The **Weave** tab of the PlaidXL task pane lets you ask [Weave](/guides/ai-assistant/) for what you want in plain words — "revenue by region by month for 2026", "what tables have headcount?", "why is this #VALUE!?" — and it does the work in the workbook. Weave reads PlaidCloud as you, with your permissions, and changes nothing there. What it changes in the workbook, you can revert.

## Ask a Question

1. Open the task pane and click the **Weave** tab, or click **Ask Weave...** in the **Insert** group of the ribbon.
2. Type your question in **Ask Weave** and press **Enter** or click **Ask**. **Shift+Enter** starts a new line, and **Up** in an empty box brings back your last question.

The workbook must be linked to a project, since Weave answers from its tables. Weave sees what you've selected and the active cell, so a question like "total this by quarter" works on the cells in front of you. **Cancel** stops an answer that's still coming.

## What Weave Can Do

- **Build a report** — rows and columns that drill a dimension, with a `PLAIDXL.CELL` value in every cell, the same as [Build report](/reference/cli/plaidxl/build-a-report/).
- **Write a formula** into the cells you asked about.
- **Drill** — open, close, keep or remove nodes in a drill, like the [Drill commands](/reference/cli/plaidxl/drill/).
- **Retrieve a table** into the workbook, filtered to the rows you asked for. It's added to the refresh list like any table you retrieve, so **Refresh all tables** keeps it current.
- **Find tables** — when you ask which tables hold something, each answer comes with a **Pull** button that retrieves that table.
- **Select** the range it's talking about, or suggest a refresh.

Weave writes formulas that use PlaidXL functions and common Excel functions for math, text, logic, lookups, dates and dynamic arrays. It doesn't write formulas that reach outside the workbook or build references from text, such as `WEBSERVICE`, `HYPERLINK`, `INDIRECT` or `IMAGE`, or that refer to other files.

Weave doesn't write data to PlaidCloud. To write values back, [type them over a `CELL`](/reference/cli/plaidxl/write-values/) or [save a sheet](/reference/cli/plaidxl/retrieve/#save-a-table-to-plaidcloud) yourself.

### When Weave Asks First

Weave acts straight away when its change goes into empty cells, PlaidXL cells, cells showing an error, or the cells you asked about. When it would replace something you've entered, it describes the change and waits:

- A formula over a cell that holds something else waits for **Apply**.
- A drill that would replace cells holding values waits for **Apply**.
- Retrieving a table onto a sheet that already holds refreshed tables waits for **Retrieve**.
- A refresh waits for **Refresh**.

## Revert a Change

Each change Weave makes has a **Revert** button, and an answer that made several has **Revert all**. Revert puts each cell back as it was, except a cell you've changed since, which it keeps and tells you so. A report or table Weave put on a new sheet is reverted by deleting that sheet, which Excel can't undo. Where your version of Excel supports it, **Ctrl+Z** also undoes a Weave change in one step.

## When Something Goes Wrong

If a formula or action Weave wrote ends in an error, Weave tries once to fix it. If the fix doesn't work, it puts the original back and says what it tried.

## Ask About a Cell

Select a cell, then choose **Ask Weave about this cell** from the **PlaidXL** right-click menu, click **Ask Weave** on the **PlaidXL Cell** tab, or press **Ctrl+Alt+Shift+Q** (**⌘⌥⇧Q** on Mac). The **Weave** tab opens ready for your question. If the cell shows an error, the question is filled in for you — **Why is this #VALUE!?**, for example — and you send it when you're ready. For a PlaidXL cell, Weave also knows what the formula reads.

## Limits

| Limit | Value |
|---|---|
| Length of a question | 4,000 characters |
| Questions per person | 30 an hour |
| Tables retrieved in one answer | 3 |

The conversation is kept for each workbook and project on this computer, up to its last 40 entries, so it's still there when you reopen the pane. After a reload the **Revert** and **Apply** buttons are gone. Signing out or switching workspace clears the conversation.

<Aside>
Weave answers from the project linked to the workbook. To ask about another project, choose it in the task pane header first.
</Aside>
