A PlaidXL report is an ordinary Excel grid: a dimension's nodes down the side, another dimension's nodes across the top, and a `PLAIDXL.CELL` formula at each intersection that rolls up a measure from a PlaidCloud table. Because the numbers are formulas, the report recalculates against current data instead of being rebuilt every month.

There are three ways to build one: **Build my first report** for a sample from your own data, the **Report** tab for a report you choose, and formulas you write yourself. You can also [ask Weave](/reference/cli/plaidxl/weave/) for one in plain words.

## Get Started

While a workbook holds nothing from PlaidCloud, the task pane shows **Get started**:

- **Build my first report** picks a table in the linked project that has a numeric column and a dimension to report by, and builds a report from it on a new sheet named **PlaidXL sample**, with up to 1,000 of the table's rows on **PlaidXL sample data** beside it. Change a filter cell and the report recalculates.
- **Insert a table** opens the **Tables** tab.
- **Build a report...** opens the **Report** tab.

## Build the Report

The **Report** tab lays out a whole report for you. Open it from the task pane, or click **Build report...** in the **Insert** group of the ribbon (**Ctrl+Alt+Shift+B**, or **⌘⌥⇧B** on Mac).

1. **Table** — pick the table to report on.
2. **Value** — choose the **Column to total** and how to **Combine by**: sum, mean, median, std, var, min or max.
3. **Rows** — choose the **Dimension**, where to **Start from** (blank for the top) and the **Depth**: a number of **Levels down**, **All levels**, **Lowest level only**, or a **Drill key**.
4. **Columns** — select **Drill a dimension across the columns** and choose the same for the columns, or leave it clear for a single column of values.
5. **Filters (optional)** — click **Add a filter** for each dimension and node to filter the whole report by.

The tab opens with a table and dimensions already chosen, and previews the first 10 nodes of each axis and the number of values, such as `12 × 4 = 48 values`, as you change them. A start node that isn't in the dimension shows the closest matches to choose from.

Select the cell where the report should start and click **Build report** (or press **Ctrl+Enter**). While the values fill in, **Cancel** stops and removes the report. When it's done, the message offers **Undo**. If the cells the report needs already hold something, it goes on a new, numbered **Report** sheet instead.

The report is made of the same formulas you'd write by hand:

- At the top, cells for the **Table**, **Measure** and **Aggregation**, and one for each filter.
- A [`DRILL`](/reference/cli/plaidxl/functions/#drill) down the side for the rows, and one across the top for the columns.
- A [`CELL`](/reference/cli/plaidxl/functions/#cell) at every intersection, which you can type over to [write a value to PlaidCloud](/reference/cli/plaidxl/write-values/).

Parent rows are bold, and the headings are frozen. To change a report, select a cell in it: the **Report** tab loads it, and **Rebuild report** replaces it in place. Click **Build a new one instead** to start a separate report.

### The Report Follows Its Drills

When a report's rows or columns change — you drill a row down or up, keep or remove nodes, or the dimension changes — the report inserts or deletes whole rows and columns to match, and the message says what changed, such as `Report updated: +3 rows, -1 column`, with **Undo**. Values you've typed, notes, formats and formulas beside the report stay with their node.

## Build It With Formulas

To build a report by hand, write the formulas yourself.

### Before You Start

- [Sign in](/reference/cli/plaidxl/connect/) and select the project that holds your data. The workbook remembers it.
- You need a table with a numeric column to report on, such as **revenue**, and a column for each dimension you'll report by, such as **Region** and **Period**, linked to that dimension in PlaidCloud. `CELL` filters by column name, and rolls a node up through its dimension only on a linked column. See [Values](/reference/cli/plaidxl/functions/#values).
- Not sure of the exact names? `=PLAIDXL.TABLE.TBL_LIST()`, `=PLAIDXL.TABLE.GET_COLUMNS("Sales")` and `=PLAIDXL.DIMENSION.DIM_LIST()` list them on a scratch sheet.

### Write the Formulas

The steps use a table named **Sales** with the measure column **revenue** and the dimension columns **Region** (rows) and **Period** (columns), linked to dimensions of the same names. Swap in your own names — in `DRILL` use the dimension's name, and in `DIMENSION_REPR` the table's column name.

<Steps>

1. **Describe what you're measuring.** In three cells at the top of the sheet, enter:

   ```text
   B1  =PLAIDXL.REPR.TABLE_REPR("Sales")
   B2  =PLAIDXL.REPR.MEASURE("revenue")
   B3  =PLAIDXL.REPR.MEASURE_TYPE("sum")
   ```

   Every value in the report refers to these cells, so changing one — `"mean"` instead of `"sum"`, say — changes the whole report.

2. **Lay out the rows.** In `A6`, drill the row dimension from its top node:

   ```text
   A6  =PLAIDXL.DRILL("Region", "Total", PLAIDXL.REPR.DRILL_KEY("1 level"))
   ```

   **Total** and its children spill down column A, indented under their parent and grouped so you can collapse them. Use `"all"` for every level, or `"leaves"` for just the bottom level. For finer control, such as every level except the leaves, write the key out: `>[0:-1]`. See [`DRILL_KEY`](/reference/cli/plaidxl/functions/#drill_key). To type the row nodes yourself instead, put one node name in each cell.

3. **Lay out the columns.** Type the column nodes across row 5, starting in `B5` — for example `FY2025` and `FY2026`. Or drill them across the row: `=PLAIDXL.DRILL("Period", "FY2026", PLAIDXL.REPR.DRILL_KEY("1 level"), "main", "", "", "horizontal")`.

4. **Fill the first value.** In `B6`, enter:

   ```text
   =PLAIDXL.CELL($B$1, $B$2, $B$3, PLAIDXL.REPR.DIMENSION_REPR("Region", $A6), PLAIDXL.REPR.DIMENSION_REPR("Period", B$5))
   ```

   The `$` signs keep the table, measure and type fixed, the row node in column A, and the column node in row 5. The indentation `DRILL` adds to node names is ignored.

5. **Fill the grid.** Copy `B6` across to your last period and down to your last row. Each cell shows revenue for its row's region in its column's period.

</Steps>

To add a filter that applies to the whole report — one product line, say — add another `DIMENSION_REPR` in a cell at the top, such as `B4  =PLAIDXL.REPR.DIMENSION_REPR("Product", "Hardware")`, and pass `$B$4` to every `CELL`.

To show several measures for each row, use [`PLAIDXL.CELLS`](/reference/cli/plaidxl/functions/#cells) with [`PLAIDXL.REPR.MEASURES`](/reference/cli/plaidxl/functions/#measures).

## Keep the Report Current

- **Recalculate PlaidXL formulas** from the ribbon's **Refresh** menu to pull current values into every PlaidXL formula, or **Refresh this sheet** for one sheet. An ordinary Excel recalculation doesn't fetch again unless a formula's arguments changed.
- **Change the scope** by editing a building-block cell: another table, measure or aggregation, or another top-level filter node. Formulas that use the cell update straight away.
- **Drill the rows** from any value or row heading with the [drill commands](/reference/cli/plaidxl/drill/), and the report [follows](#the-report-follows-its-drills).
- **Report on another project** by selecting it in the task pane, then recalculating PlaidXL formulas. The formulas read from the workbook's project, so the same workbook can report on each project that shares the table, column and dimension names.

## Share a Values-Only Copy

People without PlaidXL, or without access to the project, see errors in place of PlaidXL formulas. To send them the numbers, replace the formulas with their values first:

1. Save your report, then save a copy under a new name for sending.
2. In the copy, click **PlaidCloud → Convert to values → Whole workbook**, or **This sheet** to convert one sheet.
3. Send the copy.

**Convert to values** replaces every PlaidXL formula with its current value and leaves other formulas alone. **Restore PlaidXL formulas** puts the PlaidXL formulas back in their cells, replacing what's there, even after you rename a sheet. **Values only (no restore)** keeps no way back. Keep your original — it's the reliable way to get your live report back. See [Share](/reference/cli/plaidxl/ribbon/#share).

<Aside type="caution">Convert the copy you're sending, never your only working report.</Aside>
