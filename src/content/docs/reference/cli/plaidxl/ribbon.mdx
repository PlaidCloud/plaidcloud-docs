Installing PlaidXL adds a **PlaidCloud** tab to the Excel ribbon, with three groups of commands. [Sign in](/reference/cli/plaidxl/connect/) from the task pane before you use them; the drill commands read from the project selected there.

## PlaidXL Controls

| Command | What it does |
|---|---|
| **Show Taskpane** | Opens the PlaidXL task pane. |
| **Refresh All Tables** | Pulls current data for every table retrieved into the workbook — the same as the button in the task pane. See [Refresh All Tables](/reference/cli/plaidxl/retrieve/#refresh-all-tables). |

## Drill Functions

The drill commands lay out a dimension's nodes below a node you choose, without writing a formula.

1. In two cells side by side, type a dimension name and a node in it — for example `Region` in `A1` and `EMEA` in `B1`. The order doesn't matter.
2. Select both cells.
3. Click a drill command:

| Command | Writes below the selection |
|---|---|
| **Drill All** | The node and every node beneath it |
| **Drill Leaves** | The node and only the leaves beneath it |
| **Drill One** | The node and its children |

The nodes are written below your selection, indented by generation and grouped in an Excel outline so you can collapse each level. Drill commands follow the dimension's main hierarchy. To drill an alternate hierarchy, or to have the layout update when the dimension changes, use the [`PLAIDXL.DRILL`](/reference/cli/plaidxl/functions/#drill) function instead.

If PlaidXL can't find the dimension or node, check the spelling against PlaidCloud and make sure exactly two cells are selected.

## Control Functions

| Command | What it does |
|---|---|
| **Sanitize Workbook** | Replaces every formula in the workbook with its current value, and remembers the formulas. |
| **Restore Workbook** | Puts back the formulas that **Sanitize Workbook** replaced. |

Use **Sanitize Workbook** to send a report to someone who doesn't have PlaidXL or access to the project — they'd otherwise see errors where the PlaidXL formulas are. See [Share a Values-Only Copy](/reference/cli/plaidxl/build-a-report/#share-a-values-only-copy).

<Aside type="caution">
**Sanitize Workbook** replaces *every* formula in the workbook, not only PlaidXL functions. Sanitize a copy saved under a new name and keep your working report as it is. Run **Restore Workbook** before you sanitize the same workbook a second time.
</Aside>
