Installing PlaidXL adds a **PlaidCloud** tab to the Excel ribbon, with six groups of commands: **Connect**, **Insert**, **Refresh**, **Drill**, **Write** and **Share**. The most common ones are also on the **PlaidXL** right-click menu and the **PlaidXL Cell** tab, and every command that has a keyboard shortcut shows it in its tooltip.

No command is ever greyed out. A command acts on the nearest PlaidXL formula, table or node to the selected cell, and when there's nothing for it to act on, it opens the part of the task pane that helps instead.

If you run a command while you're signed out, or before the workbook is linked to a project, PlaidXL opens the task pane and says **Sign in to run** the command, or **Pick a project to run** it. Once you're in, the command runs on the cell you started from. If you've moved to another sheet or chosen another project in the meantime, it doesn't run and PlaidXL tells you so.

## Connect

| Command | What it does |
|---|---|
| **Open PlaidXL** | Opens the PlaidXL task pane. |
| **Account** | Opens the task pane to sign in, or to choose your workspace and project. |
| **Shortcuts** | Lists the PlaidXL keyboard shortcuts so you can change them. See [Keyboard Shortcuts](#keyboard-shortcuts). |
| **Help** | Opens this documentation. |

## Insert

| Command | What it does |
|---|---|
| **Table...** | Opens the **Tables** tab to [retrieve a table](/reference/cli/plaidxl/retrieve/#retrieve-a-table). |
| **Dimension...** | Opens the **Dimensions** tab to retrieve a dimension or pick its members. |
| **Formula...** | Opens the **Formulas** tab to [build a PlaidXL formula](/reference/cli/plaidxl/functions/#insert-a-formula-from-the-task-pane) for the selected cell. |
| **Pick member...** | Opens the member picker on the selected cell's dimension. See [Pick a Member](/reference/cli/plaidxl/drill/#pick-a-member). |
| **Metric...** | Opens a searchable list of your project's metrics, with their current values. See [Insert a Metric](/reference/cli/plaidxl/functions/#insert-a-metric). |
| **Build report...** | Opens the **Report** tab to lay out a live report. See [Build a Report](/reference/cli/plaidxl/build-a-report/). |
| **Ask Weave...** | Opens the **Weave** tab with the selected cell as context. See [Ask Weave in Excel](/reference/cli/plaidxl/weave/). |

## Refresh

The **Refresh** menu holds four commands:

| Command | What it does |
|---|---|
| **Refresh this sheet** | Recalculates the PlaidXL formulas on the active sheet and retrieves its tables again. |
| **Refresh selection** | Recalculates the PlaidXL formulas in the selection and retrieves any table the selection touches. With nothing from PlaidXL selected, it refreshes the sheet. |
| **Refresh all tables** | Retrieves every table and dimension in the workbook again, with the columns and filter you chose for each. |
| **Recalculate PlaidXL formulas** | Recalculates every PlaidXL formula in the workbook. |

See [Refresh Tables](/reference/cli/plaidxl/retrieve/#refresh-all-tables) for what you see while a refresh runs.

**Recalculate PlaidXL formulas** recalculates PlaidXL formulas only, without a full Excel recalculation. When it's done, it lists the sheets it recalculated and clears Excel's undo history. PlaidXL keeps a table's column details for 30 seconds, so a column or dimension you renamed in the last 30 seconds can take a moment longer to show.

## Drill

| Command | What it does |
|---|---|
| **Drill down** | A menu: **One level**, **To lowest level**, **All levels** and **Custom drill...** lay out the nodes beneath the selected node. |
| **Drill up** | Collapses the selected node back to its parent. |
| **Keep only** | Keeps only the selected nodes in the drill. |
| **Remove only** | Removes the selected nodes, and everything under them, from the drill. |
| **Show detail rows** | Puts the table rows behind the selected value on a sheet of their own. |
| **Explain this number** | Shows where the selected value comes from. |

Select a single cell to drill: the drill commands turn it into a live `PLAIDXL.DRILL` formula. See [Drill, Pick Members and Explain Numbers](/reference/cli/plaidxl/drill/).

## Write

| Command | What it does |
|---|---|
| **Save sheet to PlaidCloud...** | Writes the tables retrieved into this sheet back to PlaidCloud, straight away. See [Save a Table to PlaidCloud](/reference/cli/plaidxl/retrieve/#save-a-table-to-plaidcloud). |
| **Undo last write** | Undoes the last value you typed into PlaidCloud or the last save, newest first. See [Undo a Write](/reference/cli/plaidxl/write-values/#undo-a-write). |

## Share

| Command | What it does |
|---|---|
| **Convert to values** | A menu: **Whole workbook** or **This sheet** replaces PlaidXL formulas with their current values and remembers the formulas. **Values only (no restore)** replaces them without keeping a way back. |
| **Restore PlaidXL formulas** | Puts back the formulas that **Convert to values** replaced, in every sheet of the workbook. |

Use **Convert to values** to send a report to someone who doesn't have PlaidXL or access to the project — they'd otherwise see errors where the PlaidXL formulas are. It converts every formula that calls a PlaidXL function, including one inside another formula such as `IFERROR`, and the cells it spills into. Everything else in the workbook is left as it is. **Values only (no restore)** across the whole workbook asks first: **Convert every PlaidXL formula in the workbook to values only? Restore can't bring them back.** The other choices run straight away. The message says how many formulas were converted. A formula still calculating (`#BUSY!`) isn't converted; the message counts them, so convert again when they finish.

The formulas are kept with each sheet, so **Restore PlaidXL formulas** still finds them after you rename or move a sheet. It doesn't need you to be signed in. See [Share a Values-Only Copy](/reference/cli/plaidxl/build-a-report/#share-a-values-only-copy).

<Aside type="caution">
Convert a copy saved under a new name and keep your working report as it is. **Values only (no restore)** can't be undone with **Restore PlaidXL formulas**.
</Aside>

## The Right-Click Menu

Right-click a cell and choose **PlaidXL** for these commands, each the same as its ribbon button:

- **Drill down one level**, **Drill down to lowest level**, **Drill down all levels**, **Custom drill...**, **Drill up**, **Keep only** and **Remove only**
- **Pick member...**
- **Explain this number** and **Show detail rows**
- **Refresh selection**
- **Ask Weave about this cell**
- **Insert formula here...**, which opens the **Formulas** tab for the cell

## The PlaidXL Cell Tab

When the selected cell holds a PlaidXL formula, is part of a PlaidXL formula's results, or is inside a retrieved table, Excel shows a **PlaidXL Cell** tab beside the **PlaidCloud** tab. It gathers the commands for that cell:

- **Drill** — **Drill down** (**One level**, **Lowest level**, **All levels**), **Drill up**, **Keep only** and **Remove**
- **Inspect** — **Explain**, **Detail rows** and **Ask Weave**
- **Data** — **Pick member**, **Refresh selection** and **Save sheet**

The tab hides again when you select another cell. Versions of Excel that don't support add-in contextual tabs don't show it; every command is still on the **PlaidCloud** tab.

## Keyboard Shortcuts

Every shortcut is **Ctrl+Alt+Shift** and a key on Windows, or **⌘⌥⇧** and the same key on Mac. Shortcuts don't fire while you're typing in a field or holding AltGr. If a ribbon command fails, a message says which command failed and why, and the task pane opens if it was hidden.

| Key | Command |
|---|---|
| **Down** | Drill down one level |
| **Up** | Drill up |
| **L** | Drill down to lowest level |
| **8** | Drill down all levels |
| **D** | Custom drill |
| **K** | Keep only |
| **X** | Remove only |
| **M** | Pick member |
| **E** | Explain this number |
| **T** | Show detail rows |
| **R** | Refresh this sheet |
| **F** | Refresh selection |
| **A** | Refresh all tables |
| **C** | Recalculate PlaidXL formulas |
| **W** | Save sheet to PlaidCloud |
| **Z** | Undo last write |
| **P** | Open PlaidXL |
| **N** | Insert a formula |
| **B** | Build report |
| **I** | Insert a metric |
| **Q** | Ask Weave |

To change one, click **Shortcuts** in the **Connect** group, or choose **Keyboard shortcuts** from the account menu in the task pane. Click **Set key** beside a command, press the new combination, and click **Save**; **Reset** puts the original back. A combination another command already uses is flagged, and saving it anyway still takes effect. Some versions of Office don't let add-ins change shortcuts, and show the list without **Set key**.
